Titre: Utiliser le calcul littéral

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> calculer avec des puissances et des racines carrées, développer et factoriser à l’aide des identités remarquables, résoudre des équations et des inéquations, et étudier le signe d’un produit à l’aide d’un tableau de signes.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Puissances</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Règles de calcul :</strong> pour $a \neq 0$, $b \neq 0$ et $n$, $m$ entiers relatifs :</p>
            <div style="text-align:center; margin:10px 0 0 0;">$a^n \times a^m = a^{n+m}$ ; $\frac{a^n}{a^m} = a^{n-m}$ ; $(a^n)^m = a^{n \times m}$ ; $(ab)^n = a^n b^n$ ; $a^{-n} = \frac{1}{a^n}$ ; $a^0 = 1$</div>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $\frac{2^5 \times 2^{-2}}{2^4} = 2^{5 - 2 - 4} = 2^{-1} = \frac{1}{2}$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> $(-3)^2 = 9$ mais $-3^2 = -9$ ; et $2^3 + 2^4$ ne se simplifie pas en $2^7$ (la règle concerne les produits, pas les sommes).
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Racines carrées</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> pour $a \ge 0$, $\sqrt{a}$ est le nombre positif dont le carré vaut $a$ : $(\sqrt{a})^2 = a$. Par exemple $\sqrt{49} = 7$.</p>
        </div>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriétés (démonstrations au programme) :</strong></p>
            <p style="margin:6px 0 0 0;">• Pour $a \ge 0$ et $b \ge 0$ : $\sqrt{ab} = \sqrt{a} \times \sqrt{b}$. <em>Preuve :</em> $\sqrt{a}\sqrt{b}$ est positif et $(\sqrt{a}\sqrt{b})^2 = (\sqrt{a})^2(\sqrt{b})^2 = ab$ ; c’est donc la racine carrée de $ab$.</p>
            <p style="margin:6px 0 0 0;">• Pour $a \gt 0$ et $b \gt 0$ : $\sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$. <em>Preuve :</em> $(\sqrt{a} + \sqrt{b})^2 = a + b + 2\sqrt{a}\sqrt{b} \gt a + b = (\sqrt{a + b})^2$, et deux nombres positifs sont rangés comme leurs carrés.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$ ; $\sqrt{\frac{9}{16}} = \frac{3}{4}$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> $\sqrt{9 + 16} = \sqrt{25} = 5$ alors que $\sqrt{9} + \sqrt{16} = 7$ : la racine d’une somme n’est pas la somme des racines.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Développer et factoriser</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Identités remarquables :</strong> pour tous réels $a$ et $b$,</p>
            <div style="text-align:center; margin:10px 0 0 0;">$(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$</div>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Développer</strong> transforme un produit en somme : $(2x - 3)^2 = 4x^2 - 12x + 9$. <strong>Factoriser</strong> transforme une somme en produit, avec un facteur commun ou une identité :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $(x + 1)(2x - 5) + (x + 1)(x + 2) = (x + 1)(3x - 3)$ ; $\quad 9x^2 - 25 = (3x - 5)(3x + 5)$
        </div>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Contrôle :</strong> on vérifie une factorisation en redéveloppant, ou en remplaçant $x$ par une valeur simple ($x = 0$, $x = 1$) dans les deux écritures.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Résoudre des équations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="margin:0 0 8px 0;">• <strong>Premier degré :</strong> $ax + b = 0$ avec $a \neq 0$ donne $x = -\frac{b}{a}$.</p>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Équation produit nul :</strong> un produit est nul si et seulement si l’un de ses facteurs est nul : $A \times B = 0 \iff A = 0$ ou $B = 0$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $(2x - 4)(x + 1) = 0 \iff x = 2$ ou $x = -1$.</p>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Équation $x^2 = a$ :</strong> si $a \gt 0$, deux solutions $\sqrt{a}$ et $-\sqrt{a}$ ; si $a = 0$, une solution $0$ ; si $a \lt 0$, aucune solution.</p>
        </div>
        [IMAGE_2]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong> devant une équation du second degré, on ramène tout d’un même côté, on factorise, puis on applique la règle du produit nul. Exemple : $x^2 = 5x \iff x^2 - 5x = 0 \iff x(x - 5) = 0 \iff x = 0$ ou $x = 5$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Inéquations et tableaux de signes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Règle :</strong> on peut ajouter un même nombre aux deux membres d’une inégalité ; si l’on multiplie ou divise par un nombre <strong>négatif</strong>, on <strong>change le sens</strong> de l’inégalité.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $-2x + 6 \le 0 \iff -2x \le -6 \iff x \ge 3$ (division par $-2$, le sens change).</p>
        [IMAGE_3]
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Signe de $ax + b$ :</strong> il s’annule en $-\frac{b}{a}$ ; il est du signe de $a$ à droite de cette valeur et du signe contraire à gauche.</p>
        </div>
        <p style="font-size:1em;">Pour un produit, on dresse un <strong>tableau de signes</strong> : une ligne par facteur, puis on applique la règle des signes. Ici $(2x - 4)(-x + 3) \gt 0 \iff x \in \,]2\,;3[$.</p>
        [IMAGE_4]
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> pour un quotient $\frac{A}{B}$, la valeur qui annule $B$ est <strong>interdite</strong> : on la marque d’une double barre dans le tableau et elle n’est jamais solution.
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $a^n \times a^m = a^{n+m}$ et $a^{-n} = \frac{1}{a^n}$ ; $\sqrt{ab} = \sqrt{a}\sqrt{b}$ mais $\sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$ ; $(a \pm b)^2 = a^2 \pm 2ab + b^2$ et $(a + b)(a - b) = a^2 - b^2$ ; produit nul : un des facteurs est nul ; $x^2 = a$ a deux solutions si $a \gt 0$ ; multiplier par un négatif change le sens d’une inégalité ; signe d’un produit : tableau de signes. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
