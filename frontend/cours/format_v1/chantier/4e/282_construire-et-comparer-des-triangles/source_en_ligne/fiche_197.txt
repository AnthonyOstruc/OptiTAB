Titre: Résumé : Construire et comparer des triangles

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : inégalité triangulaire, angles, constructions, cas d'égalité, rédaction. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Construire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Triangle possible si : plus grand côté $<$ somme des deux autres ($=$ : aplati).</p>
<p style="margin:6px 0 0 0;">• Somme des angles : $180°$.</p>
[IMAGE_1]
<p style="margin:6px 0 0 0;">• Trois longueurs : deux arcs de cercle. Deux longueurs et l'angle compris, ou une longueur et deux angles : rapporteur.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Les cas d'égalité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">• <strong>CCC</strong>, <strong>CAC</strong> (angle COMPRIS), <strong>ACA</strong> (angles ADJACENTS au côté).</p>
<p style="margin:6px 0 0 0;">• Rédaction : triangles nommés dans l'ordre, trois égalités justifiées, cas cité, conclusion.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Comparer la plus petite longueur à la somme des autres (c'est la PLUS GRANDE qu'il faut tester).</p>
<p style="margin:6px 0 0 0;">2️⃣ Croire que trois angles égaux suffisent (tailles différentes possibles).</p>
<p style="margin:6px 0 0 0;">3️⃣ Utiliser un angle qui n'est pas entre les deux côtés connus (pas un cas CAC).</p>
<p style="margin:6px 0 0 0;">4️⃣ Mal associer les sommets en écrivant les triangles égaux.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour démontrer que deux longueurs ou deux angles sont égaux, je cherche deux triangles égaux qui les contiennent comme éléments correspondants.</p>
</div>
