Titre: Fonctions sinus et cosinus

<!-- optitab:1 -->
::: objectifs
Connaître les dérivées de sinus et cosinus, étudier leurs variations, résoudre des équations et inéquations trigonométriques sur un intervalle, et étudier une fonction trigonométrique en exploitant périodicité et parité.
:::

## I. Rappels

::: definition
- $\cos^2 x + \sin^2 x = 1$ ; $-1 \le \cos x \le 1$ ; $-1 \le \sin x \le 1$.
- $\cos$ et $\sin$ sont $2\pi$-périodiques ; $\cos$ est paire, $\sin$ est impaire.
- Valeurs remarquables en $0$, $\frac{\pi}{6}$, $\frac{\pi}{4}$, $\frac{\pi}{3}$, $\frac{\pi}{2}$ et angles associés.
:::

[IMAGE_1]

## II. Dérivées

::: propriete
$\sin$ et $\cos$ sont dérivables sur $\mathbb{R}$, avec

$(\sin x)' = \cos x$ et $(\cos x)' = -\sin x$

Plus généralement, $\big(\sin(ax + b)\big)' = a\cos(ax + b)$ et $\big(\cos(ax + b)\big)' = -a\sin(ax + b)$. En particulier, $\lim\limits_{x \to 0} \frac{\sin x}{x} = \sin'(0) = 1$.
:::

[IMAGE_2]

::: exemple
$\big(\cos(3x - 1)\big)' = -3\sin(3x - 1)$ ; $(x\sin x)' = \sin x + x\cos x$ ; $(\sin^2 x)' = 2\sin x\cos x$.
:::

## III. Variations

::: propriete
Sur $[-\pi\,;\pi]$, $\cos$ est croissante sur $[-\pi\,;0]$ et décroissante sur $[0\,;\pi]$ ; $\sin$ est croissante sur $\left[-\frac{\pi}{2}\,;\frac{\pi}{2}\right]$ et décroissante sur $\left[\frac{\pi}{2}\,;\pi\right]$ et sur $\left[-\pi\,;-\frac{\pi}{2}\right]$.
:::

::: tableau Variations de $\cos$ sur $[-\pi\,;\pi]$
x : -\pi, 0, \pi
-\sin(x) : , +, z, -,
\cos(x) : -/-1, +/1, -/-1
:::

::: remarque Réduire l’étude
Une fonction $T$-périodique s’étudie sur un intervalle de longueur $T$ ; si elle est de plus paire ou impaire, on peut se limiter à $\left[0\,;\frac{T}{2}\right]$ puis compléter par symétrie.
:::

## IV. Équations et inéquations

::: propriete
$\cos x = \cos a \iff x = a + 2k\pi$ ou $x = -a + 2k\pi$ ; $\sin x = \sin a \iff x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$ ($k$ entier).
:::

::: exemple
Dans $[0\,;2\pi[$, $\cos x = \frac{1}{2} \iff x = \frac{\pi}{3}$ ou $x = \frac{5\pi}{3}$ ; dans $[0\,;2\pi]$, $\sin x \ge \frac{1}{2} \iff x \in \left[\frac{\pi}{6}\,;\frac{5\pi}{6}\right]$ (lecture sur le cercle).
:::

::: attention
Sur un intervalle de longueur $2\pi$, une équation $\cos x = a$ avec $-1 \lt a \lt 1$ a **deux** solutions ; on vérifie toujours qu’elles appartiennent à l’intervalle demandé.
:::

## V. Étude d’une fonction trigonométrique

::: exemple
$f(x) = \sin(2x)$. Comme $\sin(2(x + \pi)) = \sin(2x + 2\pi) = \sin(2x)$, $f$ est $\pi$-périodique ; elle est impaire. On a $f'(x) = 2\cos(2x)$, positive sur $\left[0\,;\frac{\pi}{4}\right]$, négative sur $\left[\frac{\pi}{4}\,;\frac{3\pi}{4}\right]$ et positive sur $\left[\frac{3\pi}{4}\,;\pi\right]$ : maximum $1$ en $\frac{\pi}{4}$, minimum $-1$ en $\frac{3\pi}{4}$.
:::

[IMAGE_4]

**Limite :** pour $x \gt 0$, $-\frac{1}{x} \le \frac{\cos x}{x} \le \frac{1}{x}$, donc $\lim\limits_{x \to +\infty} \frac{\cos x}{x} = 0$ (gendarmes) ; en revanche, $\cos x$ n’a pas de limite en $+\infty$.

::: retenir
$(\sin x)' = \cos x$, $(\cos x)' = -\sin x$, $\big(\cos(ax + b)\big)' = -a\sin(ax + b)$ ; $\lim\limits_{x \to 0} \frac{\sin x}{x} = 1$ ; étude réduite grâce à la périodicité et à la parité ; équations résolues sur le cercle (deux solutions par tour) ; gendarmes pour les limites avec $\sin$ et $\cos$. Fiche de synthèse dans l’onglet Fiches !
:::
