Titre: Résumé : Équations et fonctions polynômes du second degré

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : formes d’un trinôme, discriminant, racines, factorisation et signe. Programme de Première.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Discriminant et racines</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\Delta = b^2 - 4ac$ ; si $\Delta \gt 0$ : $x = \frac{-b \pm \sqrt{\Delta}}{2a}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $\Delta = 0$ : racine double $-\frac{b}{2a}$ ; $\Delta \lt 0$ : pas de racine réelle.</p>
<p style="margin:6px 0 0 0;">2️⃣ Forme canonique : $a(x - \alpha)^2 + \beta$, $\alpha = -\frac{b}{2a}$, $\beta = f(\alpha)$, sommet $S(\alpha\,;\beta)$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $x_1 + x_2 = -\frac{b}{a}$ et $x_1x_2 = \frac{c}{a}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Factorisation et signe</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\Delta \gt 0$ : $f(x) = a(x - x_1)(x - x_2)$ ; $\Delta = 0$ : $f(x) = a(x - x_0)^2$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Signe de $a$ à l’extérieur des racines, signe contraire entre elles.</p>
<p style="margin:6px 0 0 0;">3️⃣ $a \gt 0$ : minimum en $\alpha$ ; $a \lt 0$ : maximum en $\alpha$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Mal calculer $b^2$ quand $b \lt 0$ : $(-6)^2 = 36$, pas $-36$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier le coefficient $a$ dans la forme factorisée.</p>
<p style="margin:6px 0 0 0;">3️⃣ Se tromper de signe dans $\alpha = -\frac{b}{2a}$ ou dans la forme canonique $(x - \alpha)^2$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Calculer $\Delta$ pour une équation qui se résout directement : $x^2 = 9$, $x(x - 2) = 0$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> sommet → forme canonique ; racines et signe → $\Delta$ puis forme factorisée ; je contrôle avec la somme et le produit des racines.</p>
</div>
