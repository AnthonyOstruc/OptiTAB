Titre: Résumé : Inconnues et équations simples

<!-- optitab:1 -->
::: objectifs
Retenir l'essentiel : vocabulaire, test d'une égalité, opérations inverses, méthode de mise en équation et erreurs classiques.
:::

## I. Vocabulaire

- **Inconnue** : nombre cherché, désigné par une lettre ($x$, $n$, $t$…).
- **Équation** : égalité contenant une inconnue, par exemple $x + 8 = 20$ ou $3n = 21$.
- **Solution** : nombre qui rend l'égalité vraie quand on remplace la lettre.
- $3n$ signifie $3 \times n$.

::: methode Tester si un nombre est solution
Remplacer la lettre dans **chaque membre**, calculer chaque membre **séparément**, comparer.

Pour $x = 4$ : $5 \times 4 - 3 = 17$ et $2 \times 4 + 9 = 17$, donc $4$ est solution de $5x - 3 = 2x + 9$.
:::

## II. Opérations inverses

| Équation | Solution |
|---|---|
| $x + b = c$ | $x = c - b$ |
| $x - b = c$ | $x = c + b$ |
| $ax = c$ ($a \neq 0$) | $x = c \div a = \frac{c}{a}$ |
| $\frac{x}{a} = c$ ($a \neq 0$) | $x = c \times a$ |

[IMAGE_1]

- $x + 9 = 4$ donne $x = 4 - 9 = -5$ (une solution peut être négative).
- $4x = 7$ donne $x = 1{,}75$ ; $3x = 2$ donne $x = \frac{2}{3}$ (nombre quotient).
- $\frac{x}{3} = 1$ donne $x = 3$.
- $2x = 0$ et $\frac{x}{2} = 0$ ont pour solution $0$.

## III. Résoudre un problème

1. Choisir l'inconnue (avec son unité).
2. Traduire par une égalité ; un schéma en barres aide.
3. Résoudre par l'opération inverse.
4. Vérifier dans l'énoncé et conclure par une phrase.

[IMAGE_2]

Deux opérations : on les défait **en partant de la dernière**. Pour $3$ cahiers et une règle à $2$ € payés $11$ € : $11 - 2 = 9$, puis $9 \div 3 = 3$ € par cahier.

## IV. Les erreurs classiques

::: attention À éviter
1. Ajouter au lieu de soustraire : pour $x + 5 = 12$, $x = 7$ et non $17$.
2. Soustraire au lieu de diviser : pour $3x = 12$, $x = 4$ et non $9$.
3. Inverser le quotient : pour $3x = 2$, $x = \frac{2}{3}$ et non $\frac{3}{2}$.
4. Oublier de vérifier : remplacer la lettre par la valeur trouvée détecte presque toutes les erreurs.
5. Donner une réponse absurde : un nombre de personnes est entier, un prix est positif.
:::
