📚 Objectif pédagogique : retenir l’essentiel : règles, limites, croissances comparées, dérivée de $\displaystyle e^u$, étude de fonction. Programme de Terminale.

I. Règles et limites

$\displaystyle \lim\limits_{x \to +\infty} \frac{e^x}{x^n} = +\infty$ et $\displaystyle \lim\limits_{x \to -\infty} x^ne^x = 0$

[IMAGE_1]

1️⃣ $\displaystyle e^{a + b} = e^ae^b$ ; $\displaystyle e^{-a} = \frac{1}{e^a}$ ; $\displaystyle e^x \gt 0$ ; $\displaystyle e^x \ge 1 + x$.

2️⃣ $\displaystyle \lim\limits_{+\infty} e^x = +\infty$ ; $\displaystyle \lim\limits_{-\infty} e^x = 0$ ; $\displaystyle \lim\limits_{x \to 0} \frac{e^x - 1}{x} = 1$.

3️⃣ $\displaystyle e^a \lt e^b \iff a \lt b$.

II. Dériver et étudier

[IMAGE_2]

1️⃣ $\displaystyle (e^u)' = u'e^u$ ; $\displaystyle \left(e^{ax + b}\right)' = a\,e^{ax + b}$.

2️⃣ $\displaystyle (u\,e^v)' = u'e^v + uv'e^v = (u' + uv')e^v$ : on factorise par l’exponentielle.

3️⃣ Le signe de $\displaystyle f'$ est celui du facteur devant $\displaystyle e^{\ldots}$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Oublier $\displaystyle u'$ en dérivant $\displaystyle e^u$.

2️⃣ Conclure « $\displaystyle \frac{\infty}{\infty}$ » sans utiliser les croissances comparées.

3️⃣ Faire un tableau de signes pour $\displaystyle e^{\ldots}$ : c’est toujours positif.

4️⃣ Croire qu’une valeur limite est atteinte.

🏆 Réflexe : étude de $\displaystyle f(x) = P(x)e^{ax + b}$ → je factorise $\displaystyle f'(x)$ par l’exponentielle et j’étudie le signe du reste.
