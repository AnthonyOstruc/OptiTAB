Titre: Résumé : Fonction Exponentielle

<!-- optitab:1 -->
::: objectifs
Maîtriser la fonction exponentielle : définition, propriétés algébriques, dérivée, variations, limites et applications.
:::

## I. Définition

::: definition Fonction exponentielle
Il existe une unique fonction dérivable sur $\mathbb{R}$ notée $\exp$ telle que :

- $\exp'(x) = \exp(x)$ pour tout $x \in \mathbb{R}$
- $\displaystyle \exp(0) = 1$

*Notation : $\exp(x)$ ou $e^x$*
:::

::: definition Le nombre $\displaystyle e$
$$e = \exp(1) \approx 2,718$$
:::

## II. Propriétés algébriques

::: theoreme
Pour tous réels $x$ et $y$ :
:::

| Propriété | Formule |
|---|---|
| Produit | $\displaystyle e^{x+y} = e^x \times e^y$ |
| Quotient | $\displaystyle e^{x-y} = \frac{e^x}{e^y}$ |
| Puissance | $\displaystyle (e^x)^n = e^{nx}$ ($\displaystyle n \in \mathbb{Z}$) |
| Inverse | $\displaystyle e^{-x} = \frac{1}{e^x}$ |

## III. Dérivée et variations

| Fonction | Dérivée |
|---|---|
| $\displaystyle e^x$ | $\displaystyle (e^x)' = e^x$ |
| $\displaystyle e^{ax+b}$ | $\displaystyle (e^{ax+b})' = a e^{ax+b}$ |

::: theoreme Variations
La fonction exponentielle est **strictement croissante** sur $\mathbb{R}$.

Pour tous réels $x$ et $y$ : si $x < y$, alors $e^x < e^y$.
:::

## IV. Limites et signe

| Propriété | Valeur |
|---|---|
| Signe | $\displaystyle e^x > 0$ pour tout $\displaystyle x \in \mathbb{R}$ |
| Limite en $\displaystyle -\infty$ | $\displaystyle \lim_{x \to -\infty} e^x = 0$ |
| Limite en $\displaystyle +\infty$ | $\displaystyle \lim_{x \to +\infty} e^x = +\infty$ |

## V. Équations et inéquations

::: methode Résoudre les équations et inéquations exponentielles
| Type | Résolution |
|---|---|
| Équation | $\displaystyle e^a = e^b \Leftrightarrow a = b$ |
| Inéquation | $\displaystyle e^a < e^b \Leftrightarrow a < b$ |
:::

## VI. Fonctions exponentielles particulières

| Fonction | Propriétés |
|---|---|
| $\displaystyle e^{kt}$ avec $\displaystyle k > 0$ | Croissance exponentielle <br> Strictement croissante <br> $\displaystyle \lim_{t \to +\infty} e^{kt} = +\infty$ |
| $\displaystyle e^{-kt}$ avec $\displaystyle k > 0$ | Décroissance exponentielle <br> Strictement décroissante <br> $\displaystyle \lim_{t \to +\infty} e^{-kt} = 0$ |

## VII. Erreurs fréquentes

| Piège fréquent | Correction |
|---|---|
| $\displaystyle e^a \times e^b \neq e^{ab}$ | C'est $\displaystyle e^{a+b}$ (additionner les exposants) |
| $\displaystyle (e^x)^n \neq e^{x^n}$ | C'est $\displaystyle e^{nx}$ (multiplier l'exposant) |
| $\displaystyle e^a + e^b \neq e^{a+b}$ | Il n'y a pas de simplification pour la somme |
| $\displaystyle e^x$ peut être négatif | Non, $\displaystyle e^x > 0$ pour tout $\displaystyle x$ |
| $\displaystyle e^0 = 0$ | Non, $\displaystyle e^0 = 1$ |

## VIII. Formules essentielles — mémo rapide

| Notion | Formule essentielle |
|---|---|
| Produit | $\displaystyle e^{x+y} = e^x \times e^y$ |
| Quotient | $\displaystyle e^{x-y} = \frac{e^x}{e^y}$ |
| Puissance | $\displaystyle (e^x)^n = e^{nx}$ |
| Dérivée | $\displaystyle (e^x)' = e^x$ |
| Limites | $\displaystyle \lim_{x \to -\infty} e^x = 0$ et $\displaystyle \lim_{x \to +\infty} e^x = +\infty$ |

## IX. Méthodologie — stratégie de résolution

| Type de problème | Méthode recommandée |
|---|---|
| Simplifier une expression | Utiliser $\displaystyle e^{a+b} = e^a \times e^b$ et $\displaystyle e^{a-b} = \frac{e^a}{e^b}$ |
| Résoudre une équation | Ramener à $\displaystyle e^a = e^b$ puis utiliser $\displaystyle a = b$ |
| Résoudre une inéquation | Utiliser la croissance : $\displaystyle e^a < e^b \Leftrightarrow a < b$ |
| Dériver une fonction | Pour $\displaystyle e^{ax+b}$ : dérivée = $\displaystyle a e^{ax+b}$ |
| Calculer une limite | Retenir : $\displaystyle \lim_{x \to -\infty} e^x = 0$ et $\displaystyle \lim_{x \to +\infty} e^x = +\infty$ |
