=== Découverte - Fonctions Trigonométriques - Calculs de Base
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Calculer les valeurs exactes des expressions trigonométriques suivantes.

1. Calculer $\displaystyle\sin\left(\frac{\pi}{6}\right) + \cos\left(\frac{\pi}{3}\right)$
2. Calculer $\displaystyle\tan\left(\frac{\pi}{4}\right) - \sin\left(\frac{\pi}{2}\right)$
3. Calculer $\displaystyle\sin^2\left(\frac{\pi}{4}\right) + \cos^2\left(\frac{\pi}{4}\right)$
4. Calculer $\displaystyle\frac{\sin\left(\frac{\pi}{6}\right)}{\cos\left(\frac{\pi}{6}\right)}$
5. Calculer $\displaystyle\sin\left(\frac{\pi}{3}\right) \cdot \cos\left(\frac{\pi}{6}\right)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle\sin\left(\frac{\pi}{6}\right) + \cos\left(\frac{\pi}{3}\right)$

::: methode
Utilisation des valeurs remarquables
:::

::: etape Valeurs remarquables (issues du cercle trigonométrique)
- $\displaystyle\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$
- $\displaystyle\cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$
:::

::: etape Calcul
$$\frac{1}{2} + \frac{1}{2} = 1$$
:::

::: resultat
$$\sin\left(\frac{\pi}{6}\right) + \cos\left(\frac{\pi}{3}\right) = 1$$
:::

## Question 2 : Calculer $\displaystyle\tan\left(\frac{\pi}{4}\right) - \sin\left(\frac{\pi}{2}\right)$

::: methode
Utilisation des valeurs remarquables
:::

::: etape Valeurs remarquables (issues du cercle trigonométrique)
- $\displaystyle\tan\left(\frac{\pi}{4}\right) = 1$
- $\displaystyle\sin\left(\frac{\pi}{2}\right) = 1$
:::

::: etape Calcul
$$1 - 1 = 0$$
:::

::: resultat
$$\tan\left(\frac{\pi}{4}\right) - \sin\left(\frac{\pi}{2}\right) = 0$$
:::

## Question 3 : Calculer $\displaystyle\sin^2\left(\frac{\pi}{4}\right) + \cos^2\left(\frac{\pi}{4}\right)$

::: methode
Relation fondamentale de la trigonométrie
:::

::: etape Valeurs remarquables (issues du cercle trigonométrique)
- $\displaystyle\sin\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$
- $\displaystyle\cos\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$
:::

::: etape Calcul direct
$$
\begin{aligned}
\left(\frac{\sqrt{2}}{2}\right)^2 + \left(\frac{\sqrt{2}}{2}\right)^2 &= \frac{2}{4} + \frac{2}{4} \\
&= 1
\end{aligned}
$$
:::

::: etape Ou utilisation de la relation fondamentale
$\sin^2(x) + \cos^2(x) = 1$ pour tout $x$
:::

::: resultat
$$\sin^2\left(\frac{\pi}{4}\right) + \cos^2\left(\frac{\pi}{4}\right) = 1$$
:::

## Question 4 : Calculer $\displaystyle\frac{\sin\left(\frac{\pi}{6}\right)}{\cos\left(\frac{\pi}{6}\right)}$

::: methode
Définition de la tangente
:::

::: etape Valeurs remarquables (issues du cercle trigonométrique)
- $\displaystyle\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$
- $\displaystyle\cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$
:::

::: etape Calcul
$$
\begin{aligned}
\frac{\frac{1}{2}}{\frac{\sqrt{3}}{2}} &= \frac{1}{2} \times \frac{2}{\sqrt{3}} \\
&= \frac{1}{\sqrt{3}} \\
&= \frac{\sqrt{3}}{3}
\end{aligned}
$$
:::

::: etape Vérification
$$
\begin{aligned}
\tan\left(\frac{\pi}{6}\right) &= \frac{1}{\sqrt{3}} \\
&= \frac{\sqrt{3}}{3}
\end{aligned}
$$
:::

::: resultat
$$\frac{\sin\left(\frac{\pi}{6}\right)}{\cos\left(\frac{\pi}{6}\right)} = \frac{\sqrt{3}}{3}$$
:::

## Question 5 : Calculer $\displaystyle\sin\left(\frac{\pi}{3}\right) \cdot \cos\left(\frac{\pi}{6}\right)$

::: methode
Utilisation des valeurs remarquables
:::

::: etape Valeurs remarquables (issues du cercle trigonométrique)
- $\displaystyle\sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$
- $\displaystyle\cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$
:::

::: etape Calcul
$$\frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2} = \frac{3}{4}$$
:::

::: resultat
$$\sin\left(\frac{\pi}{3}\right) \cdot \cos\left(\frac{\pi}{6}\right) = \frac{3}{4}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle\sin\left(\frac{\pi}{6}\right) + \cos\left(\frac{\pi}{3}\right) = 1$
2. $\displaystyle\tan\left(\frac{\pi}{4}\right) - \sin\left(\frac{\pi}{2}\right) = 0$
3. $\displaystyle\sin^2\left(\frac{\pi}{4}\right) + \cos^2\left(\frac{\pi}{4}\right) = 1$
4. $\displaystyle\frac{\sin\left(\frac{\pi}{6}\right)}{\cos\left(\frac{\pi}{6}\right)} = \frac{\sqrt{3}}{3}$
5. $\displaystyle\sin\left(\frac{\pi}{3}\right) \cdot \cos\left(\frac{\pi}{6}\right) = \frac{3}{4}$

=== Entraînement - Fonctions Trigonométriques - Dérivées
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer les dérivées des fonctions trigonométriques suivantes.

1. Calculer la dérivée de $\displaystyle f(x) = \sin(3x)$
2. Calculer la dérivée de $\displaystyle g(x) = x^2 \cos(x)$
3. Calculer la dérivée de $\displaystyle h(x) = \tan(x^2 + 1)$
4. Calculer la dérivée de $\displaystyle k(x) = \sin(x) \cos(x)$
5. Calculer la dérivée de $\displaystyle m(x) = \frac{\sin(x)}{x}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer la dérivée de $\displaystyle f(x) = \sin(3x)$

::: methode
Dérivée d'une fonction composée
:::

::: etape Identification
$f(x) = \sin(u(x))$ avec $u(x) = 3x$
:::

::: etape Dérivée de $\displaystyle u$
$$u'(x) = 3$$
:::

::: etape Formule de dérivation
$$(\sin(u))' = \cos(u) \cdot u'$$
:::

::: etape Calcul
$$f'(x) = \cos(3x) \cdot 3 = 3\cos(3x)$$
:::

::: resultat
$$f'(x) = 3\cos(3x)$$
:::

## Question 2 : Calculer la dérivée de $\displaystyle g(x) = x^2 \cos(x)$

::: methode
Dérivée d'un produit
:::

::: etape Identification
$g(x) = u(x) \cdot v(x)$ avec $u(x) = x^2$ et $v(x) = \cos(x)$
:::

::: etape Dérivées
$u'(x) = 2x$ et $v'(x) = -\sin(x)$
:::

::: etape Formule du produit
$$(uv)' = u'v + uv'$$
:::

::: etape Calcul
$$
\begin{aligned}
g'(x) &= 2x \cdot \cos(x) + x^2 \cdot (-\sin(x)) \\
&= 2x\cos(x) - x^2\sin(x)
\end{aligned}
$$
:::

::: resultat
$$g'(x) = 2x\cos(x) - x^2\sin(x)$$
:::

## Question 3 : Calculer la dérivée de $\displaystyle h(x) = \tan(x^2 + 1)$

::: methode
Dérivée d'une fonction composée
:::

::: etape Identification
$h(x) = \tan(u(x))$ avec $u(x) = x^2 + 1$
:::

::: etape Dérivée de $\displaystyle u$
$$u'(x) = 2x$$
:::

::: etape Formule de dérivation
$$(\tan(u))' = \frac{1}{\cos^2(u)} \cdot u'$$
:::

::: etape Calcul
$$
\begin{aligned}
h'(x) &= \frac{1}{\cos^2(x^2 + 1)} \cdot 2x \\
&= \frac{2x}{\cos^2(x^2 + 1)}
\end{aligned}
$$
:::

::: resultat
$$h'(x) = \frac{2x}{\cos^2(x^2 + 1)}$$
:::

## Question 4 : Calculer la dérivée de $\displaystyle k(x) = \sin(x) \cos(x)$

::: methode
Dérivée d'un produit
:::

::: etape Identification
$k(x) = u(x) \cdot v(x)$ avec $u(x) = \sin(x)$ et $v(x) = \cos(x)$
:::

::: etape Dérivées
$u'(x) = \cos(x)$ et $v'(x) = -\sin(x)$
:::

::: etape Formule du produit
$$(uv)' = u'v + uv'$$
:::

::: etape Calcul
$$
\begin{aligned}
k'(x) &= \cos(x) \cdot \cos(x) + \sin(x) \cdot (-\sin(x)) \\
&= \cos^2(x) - \sin^2(x)
\end{aligned}
$$
:::

::: etape Simplification
$\displaystyle k'(x) = \cos(2x)$ (formule de duplication)
:::

::: resultat
$$k'(x) = \cos(2x)$$
:::

## Question 5 : Calculer la dérivée de $\displaystyle m(x) = \frac{\sin(x)}{x}$

::: methode
Dérivée d'un quotient
:::

::: etape Identification
$m(x) = \frac{u(x)}{v(x)}$ avec $u(x) = \sin(x)$ et $v(x) = x$
:::

::: etape Dérivées
$u'(x) = \cos(x)$ et $v'(x) = 1$
:::

::: etape Formule du quotient
$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$
:::

::: etape Calcul
$$
\begin{aligned}
m'(x) &= \frac{\cos(x) \cdot x - \sin(x) \cdot 1}{x^2} \\
&= \frac{x\cos(x) - \sin(x)}{x^2}
\end{aligned}
$$
:::

::: resultat
$m'(x) = \frac{x\cos(x) - \sin(x)}{x^2}$ pour $x \neq 0$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle f'(x) = 3\cos(3x)$
2. $\displaystyle g'(x) = 2x\cos(x) - x^2\sin(x)$
3. $\displaystyle h'(x) = \frac{2x}{\cos^2(x^2 + 1)}$
4. $\displaystyle k'(x) = \cos(2x)$
5. $\displaystyle m'(x) = \frac{x\cos(x) - \sin(x)}{x^2}$

Énoncé:

Résoudre les équations trigonométriques suivantes.

1. Résoudre $\displaystyle\sin(x) = \frac{1}{2}$ sur $\displaystyle [0, 2\pi[$
2. Résoudre $\displaystyle\cos(x) = -\frac{\sqrt{2}}{2}$ sur $\displaystyle [0, 2\pi[$
3. Résoudre $\displaystyle\tan(x) = 1$ sur $\displaystyle [0, 2\pi[$
4. Résoudre $\displaystyle 2\sin^2(x) - 3\sin(x) + 1 = 0$ sur $\displaystyle [0, 2\pi[$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle\sin(x) = \frac{1}{2}$ sur $\displaystyle [0, 2\pi[$

::: methode
Équation trigonométrique élémentaire
:::

::: etape Valeur remarquable
$$\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$$
:::

::: etape Solutions générales
$\displaystyle\sin(x) = \sin\left(\frac{\pi}{6}\right)$

- $x = \frac{\pi}{6} + 2k\pi$ ou $x = \pi - \frac{\pi}{6} + 2k\pi = \frac{5\pi}{6} + 2k\pi$
:::

::: etape Sur $\displaystyle [0, 2\pi[$
$k = 0$ donne $x = \frac{\pi}{6}$ et $x = \frac{5\pi}{6}$
:::

::: resultat
$$S = \left\{\frac{\pi}{6}, \frac{5\pi}{6}\right\}$$
:::

## Question 2 : Résoudre $\displaystyle\cos(x) = -\frac{\sqrt{2}}{2}$ sur $\displaystyle [0, 2\pi[$

::: methode
Équation trigonométrique élémentaire
:::

::: etape Valeur remarquable
$$\cos\left(\frac{3\pi}{4}\right) = -\frac{\sqrt{2}}{2}$$
:::

::: etape Solutions générales
$\displaystyle\cos(x) = \cos\left(\frac{3\pi}{4}\right)$

- $x = \frac{3\pi}{4} + 2k\pi$ ou $x = -\frac{3\pi}{4} + 2k\pi = \frac{5\pi}{4} + 2k\pi$
:::

::: etape Sur $\displaystyle [0, 2\pi[$
$k = 0$ donne $x = \frac{3\pi}{4}$ et $x = \frac{5\pi}{4}$
:::

::: resultat
$$S = \left\{\frac{3\pi}{4}, \frac{5\pi}{4}\right\}$$
:::

## Question 3 : Résoudre $\displaystyle\tan(x) = 1$ sur $\displaystyle [0, 2\pi[$

::: methode
Équation trigonométrique élémentaire
:::

::: etape Valeur remarquable
$$\tan\left(\frac{\pi}{4}\right) = 1$$
:::

::: etape Solutions générales
$\displaystyle\tan(x) = \tan\left(\frac{\pi}{4}\right)$

- $\displaystyle x = \frac{\pi}{4} + k\pi$
:::

::: etape Sur $\displaystyle [0, 2\pi[$
$k = 0$ donne $x = \frac{\pi}{4}$ et $k = 1$ donne $x = \frac{\pi}{4} + \pi = \frac{5\pi}{4}$
:::

::: resultat
$$S = \left\{\frac{\pi}{4}, \frac{5\pi}{4}\right\}$$
:::

## Question 4 : Résoudre $\displaystyle 2\sin^2(x) - 3\sin(x) + 1 = 0$ sur $\displaystyle [0, 2\pi[$

::: methode
Équation du second degré en $\sin(x)$
:::

::: etape Changement de variable
$X = \sin(x)$, donc $2X^2 - 3X + 1 = 0$
:::

::: etape Résolution
$\displaystyle\Delta = 9 - 8 = 1$

- $X_1 = \frac{3 + 1}{4} = 1$ et $X_2 = \frac{3 - 1}{4} = \frac{1}{2}$
:::

::: etape Retour à $\displaystyle\sin(x)$
- $\sin(x) = 1$ : $x = \frac{\pi}{2}$ sur $[0, 2\pi[$
- $\sin(x) = \frac{1}{2}$ : $x = \frac{\pi}{6}$ ou $x = \frac{5\pi}{6}$ sur $[0, 2\pi[$
:::

::: resultat
$$S = \left\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}\right\}$$
:::

## Question 5 : Résoudre $\displaystyle\sin(2x) = \cos(x)$ sur $[0, 2\pi[$

::: methode
Utilisation des formules trigonométriques
:::

::: etape Formule de duplication
$$\sin(2x) = 2\sin(x)\cos(x)$$
:::

::: etape Équation
$$2\sin(x)\cos(x) = \cos(x)$$
:::

::: etape Factorisation
$$\cos(x)(2\sin(x) - 1) = 0$$
:::

::: etape Solutions
- $\cos(x) = 0$ : $x = \frac{\pi}{2}$ ou $x = \frac{3\pi}{2}$ sur $[0, 2\pi[$
- $2\sin(x) - 1 = 0$ : $\sin(x) = \frac{1}{2}$ : $x = \frac{\pi}{6}$ ou $x = \frac{5\pi}{6}$ sur $[0, 2\pi[$
:::

::: resultat
$$S = \left\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{3\pi}{2}\right\}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle S = \left\{\frac{\pi}{6}, \frac{5\pi}{6}\right\}$
2. $\displaystyle S = \left\{\frac{3\pi}{4}, \frac{5\pi}{4}\right\}$
3. $\displaystyle S = \left\{\frac{\pi}{4}, \frac{5\pi}{4}\right\}$
4. $\displaystyle S = \left\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}\right\}$
5. $\displaystyle S = \left\{\frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{3\pi}{2}\right\}$

## Question 1 : Étudier la fonction $\displaystyle f(x) = \sin(x) + \cos(x)$ sur $\displaystyle [0, 2\pi]$

::: methode
Étude complète d'une fonction trigonométrique
:::

::: remarque
On peut transformer $f$ sous la forme : $f(x) = \sqrt{2}\sin\left(x + \frac{\pi}{4}\right)$

- Cette forme permet de voir directement l'amplitude ($\sqrt{2}$) et le déphasage ($+\frac{\pi}{4}$)
:::

::: etape Dérivée
$$f'(x) = \cos(x) - \sin(x)$$
:::

::: etape Résolution $\displaystyle f'(x) = 0$
$\displaystyle\cos(x) = \sin(x) \Rightarrow \tan(x) = 1$

- Solutions : $\displaystyle x = \frac{\pi}{4} + k\pi$
- Sur $[0, 2\pi]$ : $x = \frac{\pi}{4}$ et $x = \frac{5\pi}{4}$
:::

::: etape Signe de $\displaystyle f'(x)$
- Sur $[0, \frac{\pi}{4}[$ : $f'(x) > 0$ (croissante)
- Sur $]\frac{\pi}{4}, \frac{5\pi}{4}[$ : $f'(x) < 0$ (décroissante)
- Sur $]\frac{5\pi}{4}, 2\pi]$ : $f'(x) > 0$ (croissante)
:::

::: etape Extremums
- Maximum en $x = \frac{\pi}{4}$ : $f\left(\frac{\pi}{4}\right) = \sqrt{2}$ (car $f(x) = \sin x + \cos x = \sqrt{2}\,\sin\left(x + \frac{\pi}{4}\right)$)
- Minimum en $x = \frac{5\pi}{4}$ : $f\left(\frac{5\pi}{4}\right) = -\sqrt{2}$ (même formule : minimum quand $\sin\left(x + \frac{\pi}{4}\right) = -1$)
:::

::: point Tableau de signes et variations
::: tableau
x : 0, \frac{\pi}{4}, \frac{5\pi}{4}, 2\pi
f'(x) : , +, z, -, z, +,
f(x) : -/1, +/\sqrt{2}, -/-\sqrt{2}, +/1
:::
:::

::: resultat
$f$ croît sur $[0, \frac{\pi}{4}]$ et $[\frac{5\pi}{4}, 2\pi]$, décroît sur $[\frac{\pi}{4}, \frac{5\pi}{4}]$
:::

## Question 3 : Étudier la fonction $\displaystyle h(x) = \frac{\sin(x)}{1 + \cos(x)}$ sur $\displaystyle [0, 2\pi[$

::: methode
Étude d'une fonction rationnelle trigonométrique
:::

::: etape Domaine
$1 + \cos(x) \neq 0 \Rightarrow \cos(x) \neq -1 \Rightarrow x \neq \pi + 2k\pi$

- Sur $[0, 2\pi[$ : $x \neq \pi$
:::

::: remarque
On peut montrer que $\displaystyle h(x) = \frac{\sin(x)}{1 + \cos(x)} = \tan\left(\frac{x}{2}\right)$

- Cette identité simplifie grandement l'étude de la fonction
:::

::: etape Dérivée (forme quotient)
- Identification : $u(x) = \sin(x)$, $v(x) = 1 + \cos(x)$
- Dérivées : $u'(x) = \cos(x)$, $v'(x) = -\sin(x)$
- Formule du quotient : $\displaystyle \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$

Calcul :

$$
\begin{aligned}
h'(x) &= \frac{\cos(x)(1 + \cos(x)) - \sin(x)(-\sin(x))}{(1 + \cos(x))^2} \\
&= \frac{\cos(x) + \cos^2(x) + \sin^2(x)}{(1 + \cos(x))^2} \\
&= \frac{\cos(x) + 1}{(1 + \cos(x))^2} \\
&= \frac{1}{1 + \cos(x)}
\end{aligned}
$$
:::

::: etape Signe de $\displaystyle h'(x)$
$h'(x) > 0$ sur $[0, \pi[ \cup ]\pi, 2\pi[$

- Justification : $-1 \leq \cos(x) \leq 1 \Rightarrow 1 + \cos(x) \geq 0$ et, sur le domaine étudié, $1 + \cos(x) > 0$.
- Donc $\displaystyle h'(x) = \frac{1}{1 + \cos(x)} > 0$.
:::

::: etape Comportement
- $h$ est croissante sur $[0, \pi[$ et $]\pi, 2\pi[$
- $\lim_{x \to \pi^-} h(x) = +\infty$ et $\lim_{x \to \pi^+} h(x) = -\infty$
- Asymptote verticale en $\displaystyle x = \pi$
Avec $h(x) = \tan\left(\frac{x}{2}\right)$ (remarque précédente) :

$$
\begin{aligned}
\lim_{x \to 2\pi^-} h(x) &= \lim_{x \to 2\pi^-} \tan\left(\frac{x}{2}\right) \\
&= \tan(\pi) \\
&= 0
\end{aligned}
$$
:::

::: point Tableau de signes et variations
::: tableau
x : 0, \pi, 2\pi
h'(x) : , +, d, +,
h(x) : -/0, +D-/+\infty/-\infty, +/0
:::
:::

::: resultat
$h$ est croissante sur son domaine avec une asymptote verticale en $x = \pi$
:::

## Question 4 : Étudier la fonction $\displaystyle k(x) = \sin(x) \cos(x)$ sur $[0, 2\pi]$

::: methode
Utilisation des formules trigonométriques
:::

::: etape Simplification
$$k(x) = \sin(x)\cos(x) = \frac{1}{2}\sin(2x)$$
:::

::: etape Dérivée
$$k'(x) = \cos(2x)$$
:::

## Question 2 : Étudier la fonction $\displaystyle f(x) = \frac{\sin(x)}{1 + \sin(x)}$ sur $[0, 2\pi]$

::: methode
Étude d'une fonction rationnelle trigonométrique
:::

::: etape Domaine
$\displaystyle 1 + \sin(x) \neq 0 \Rightarrow \sin(x) \neq -1 \Rightarrow x \neq \frac{3\pi}{2} + 2k\pi$

- Sur $[0, 2\pi]$ : $x \neq \frac{3\pi}{2}$
:::

::: etape Dérivée (quotient)
- Formule : $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ avec $u = \sin(x)$ et $v = 1 + \sin(x)$
- $u' = \cos(x)$ et $v' = \cos(x)$

$$
\begin{aligned}
f'(x) &= \frac{\cos(x)(1 + \sin(x)) - \sin(x)\cos(x)}{(1 + \sin(x))^2} \\
&= \frac{\cos(x) + \cos(x)\sin(x) - \sin(x)\cos(x)}{(1 + \sin(x))^2} \\
&= \frac{\cos(x)}{(1 + \sin(x))^2}
\end{aligned}
$$
:::

::: etape Signe de $\displaystyle f'(x)$
- $f'(x) = \frac{\cos(x)}{(1 + \sin(x))^2}$ où $(1 + \sin(x))^2 > 0$ sur le domaine de $f$
- Donc le signe de $f'(x)$ dépend uniquement de $\cos(x)$
- $f'(x) > 0$ sur $[0, \frac{\pi}{2}[ \cup ]\frac{3\pi}{2}, 2\pi]$ (où $\cos(x) > 0$)
- $f'(x) < 0$ sur $]\frac{\pi}{2}, \frac{3\pi}{2}[$ (où $\cos(x) < 0$)
:::

::: etape Comportement
- Maximum en $x = \frac{\pi}{2}$ : $f\left(\frac{\pi}{2}\right) = \frac{1}{2}$
- **Comportement en $x = \frac{3\pi}{2}$ (asymptote verticale) :**
  - Quand $x \to \frac{3\pi}{2}$, le numérateur tend vers $-1$ et le dénominateur tend vers $0$ par valeurs positives : $\lim_{x \to \frac{3\pi}{2}} f(x) = -\infty$ (à gauche comme à droite)
  - Sur $\left]\frac{3\pi}{2}, 2\pi\right]$, $f$ est croissante (car $f'(x) > 0$) et remonte de $-\infty$ à $f(2\pi) = 0$
:::

::: point Tableau de signes et variations

:::

## Question 4 : Calculer la dérivée seconde de $\displaystyle g(x) = \sin(x^2)$

Dérivation composée répétée
:::

- $\displaystyle g'(x) = 2x \times \cos(x^2) = 2x\cos(x^2)$
:::

::: etape Deuxième dérivée (produit)

- $\displaystyle g''(x) = 2\cos(x^2) - 4x^2\sin(x^2)$
:::

::: resultat
$$g''(x) = 2\cos(x^2) - 4x^2\sin(x^2)$$

## Question 2 : Calculer $\displaystyle\lim_{x \to 0} \frac{1 - \cos(x)}{x^2}$

::: methode
Utilisation des formules trigonométriques
:::

::: etape Formule trigonométrique à utiliser
- $\displaystyle 1 - \cos(x) = 2\sin^2\left(\frac{x}{2}\right)$ (formule de l'angle moitié)
:::

::: etape Application de la formule
- $\displaystyle\frac{1 - \cos(x)}{x^2} = \frac{2\sin^2\left(\frac{x}{2}\right)}{x^2}$
:::

::: etape Transformation pour utiliser la limite fondamentale
$$
\begin{aligned}
\frac{2\sin^2\left(\frac{x}{2}\right)}{x^2} &= 2 \cdot \frac{\sin^2\left(\frac{x}{2}\right)}{x^2} \\
&= 2 \cdot \frac{\sin^2\left(\frac{x}{2}\right)}{4\left(\frac{x}{2}\right)^2} \\
&= \frac{1}{2} \cdot \frac{\sin^2\left(\frac{x}{2}\right)}{\left(\frac{x}{2}\right)^2} \\
&= \frac{1}{2} \cdot \left[\frac{\sin\left(\frac{x}{2}\right)}{\frac{x}{2}}\right]^2
\end{aligned}
$$
:::

::: etape Calcul de la limite
- On utilise $\displaystyle\lim_{x \to 0} \frac{\sin(x)}{x} = 1$

$$
\begin{aligned}
\lim_{x \to 0} \frac{1 - \cos(x)}{x^2} &= \frac{1}{2} \cdot \left[\lim_{x \to 0}\frac{\sin\left(\frac{x}{2}\right)}{\frac{x}{2}}\right]^2 \\
&= \frac{1}{2} \cdot 1^2 \\
&= \frac{1}{2}
\end{aligned}
$$
:::

::: resultat
$$\lim_{x \to 0} \frac{1 - \cos(x)}{x^2} = \frac{1}{2}$$

## Question 3 : Calculer $\displaystyle\lim_{x \to \frac{\pi}{2}} \frac{\tan(x)}{x - \frac{\pi}{2}}$

:::

::: etape Transformation
$$
\begin{aligned}
\tan(x) &= \frac{\sin\left(u + \frac{\pi}{2}\right)}{\cos\left(u + \frac{\pi}{2}\right)} \\
&= \frac{\cos(u)}{-\sin(u)} \\
&= -\frac{\cos(u)}{\sin(u)}
\end{aligned}
$$

::: etape Limite
$$\lim_{u \to 0} \frac{-\frac{\cos(u)}{\sin(u)}}{u} = -\lim_{u \to 0} \frac{\cos(u)}{u\sin(u)}$$

- On écrit $\displaystyle -\frac{\cos(u)}{u\sin(u)} = -\frac{\cos(u)}{u^2} \times \frac{u}{\sin(u)}$

- Donc $\displaystyle \lim_{u \to 0} -\frac{\cos(u)}{u\sin(u)} = -\infty$

$$1 + \cos(2x) = 1 + 2\cos^2(x) - 1 = 2\cos^2(x)$$

\end{aligned}

$$\frac{\sin(2x)}{1 + \cos(2x)} = \tan(x)$$

## Question 5 : Calculer $\displaystyle\sin\left(\frac{5\pi}{12}\right)$

=== Problème - Fonctions Trigonométriques - Intégration et Applications

Étapes:
<!-- optitab:1 -->
::: rappel Calcul d'une intégrale
$\displaystyle\int_a^b f(x)\, dx = F(b) - F(a)$, où $F$ est une primitive de $f$ sur $[a, b]$.
:::

::: point Primitives trigonométriques utilisées
- $\displaystyle\int \sin(x)\, dx = -\cos(x) + C$
- $\displaystyle\int \cos(x)\, dx = \sin(x) + C$
- $\displaystyle\int \tan(x)\, dx = -\ln|\cos(x)| + C$
- $\displaystyle\int \sin(ax)\, dx = -\frac{\cos(ax)}{a} + C$
:::

## Question 1 : Calculer $\displaystyle\int_0^{\pi} \sin(x) \, dx$

::: point Primitive
$$F(x) = -\cos(x) + C$$
:::

::: point Évaluation
$F(\pi) = -\cos(\pi) = -(-1) = 1$ et $F(0) = -\cos(0) = -1$
:::

::: point Calcul
$$
\begin{aligned}
\int_0^{\pi} \sin(x)\, dx &= [-\cos(x)]_0^{\pi} \\
&= 1 - (-1) \\
&= 2
\end{aligned}
$$
:::

::: resultat
$$\int_0^{\pi} \sin(x)\, dx = 2$$
:::

## Question 2 : Calculer $\displaystyle\int_0^{\frac{\pi}{2}} \cos^2(x) \, dx$

::: point Formule trigonométrique
$\displaystyle\cos^2(x) = \frac{1 + \cos(2x)}{2}$ (formule de linéarisation)
:::

::: point Transformation
$$
\begin{aligned}
\int_0^{\frac{\pi}{2}} \cos^2(x)\, dx &= \int_0^{\frac{\pi}{2}} \frac{1 + \cos(2x)}{2}\, dx \\
&= \frac{1}{2}\int_0^{\frac{\pi}{2}} (1 + \cos(2x))\, dx
\end{aligned}
$$
:::

::: point Primitive
$$
\begin{aligned}
F(x) &= \frac{1}{2}\left(x + \frac{\sin(2x)}{2}\right) + C \\
&= \frac{x}{2} + \frac{\sin(2x)}{4} + C
\end{aligned}
$$
:::

::: point Évaluation
$F\left(\frac{\pi}{2}\right) = \frac{\pi}{4} + \frac{\sin(\pi)}{4} = \frac{\pi}{4} + 0 = \frac{\pi}{4}$ et $F(0) = 0 + \frac{\sin(0)}{4} = 0$
:::

::: point Calcul
$$
\begin{aligned}
\int_0^{\frac{\pi}{2}} \cos^2(x)\, dx &= \left[\frac{x}{2} + \frac{\sin(2x)}{4}\right]_0^{\frac{\pi}{2}} \\
&= \frac{\pi}{4} - 0 \\
&= \frac{\pi}{4}
\end{aligned}
$$
:::

::: resultat
$$\int_0^{\frac{\pi}{2}} \cos^2(x)\, dx = \frac{\pi}{4}$$
:::

## Question 3 : Calculer $\displaystyle\int \sin(x)\cos(x) \, dx$

::: point Formule trigonométrique
$\displaystyle\sin(x)\cos(x) = \frac{\sin(2x)}{2}$ (formule de duplication)
:::

::: point Transformation
$$
\begin{aligned}
\int \sin(x)\cos(x)\, dx &= \int \frac{\sin(2x)}{2}\, dx \\
&= \frac{1}{2}\int \sin(2x)\, dx
\end{aligned}
$$
:::

::: point Primitive
$$
\begin{aligned}
F(x) &= \frac{1}{2} \times \left(-\frac{\cos(2x)}{2}\right) + C \\
&= -\frac{\cos(2x)}{4} + C
\end{aligned}
$$
:::

::: resultat
$$\int \sin(x)\cos(x)\, dx = -\frac{\cos(2x)}{4} + C$$
:::

## Question 4 : Calculer $\displaystyle\int_0^{\pi} \sin(2x) \, dx$

::: point Primitive
$$F(x) = -\frac{\cos(2x)}{2} + C$$
:::

::: point Évaluation
$F(\pi) = -\frac{\cos(2\pi)}{2} = -\frac{1}{2}$ et $F(0) = -\frac{\cos(0)}{2} = -\frac{1}{2}$
:::

::: point Calcul
$$
\begin{aligned}
\int_0^{\pi} \sin(2x)\, dx &= \left[-\frac{\cos(2x)}{2}\right]_0^{\pi} \\
&= -\frac{1}{2} - \left(-\frac{1}{2}\right) \\
&= 0
\end{aligned}
$$
:::

::: resultat
$$\int_0^{\pi} \sin(2x)\, dx = 0$$
:::

## Question 5 : Calculer $\displaystyle\int_0^{\frac{\pi}{4}} \tan(x) \, dx$

::: point Transformation
$$\tan(x) = \frac{\sin(x)}{\cos(x)}$$
:::

::: etape Forme $-\dfrac{u'}{u}$
Avec $u(x) = \cos(x)$ : $u'(x) = -\sin(x)$ et $u(x) > 0$ sur $\left[0, \frac{\pi}{4}\right]$, donc

$$\tan(x) = \frac{\sin(x)}{\cos(x)} = -\frac{u'(x)}{u(x)}$$
:::

::: point Primitive
$$F(x) = -\ln(\cos(x))$$
:::

::: point Évaluation
$F\left(\frac{\pi}{4}\right) = -\ln\left|\cos\left(\frac{\pi}{4}\right)\right| = -\ln\left(\frac{\sqrt{2}}{2}\right)$ et $F(0) = -\ln|\cos(0)| = -\ln(1) = 0$
:::

::: point Calcul
$$
\begin{aligned}
\int_0^{\frac{\pi}{4}} \tan(x)\, dx &= \left[-\ln|\cos(x)|\right]_0^{\frac{\pi}{4}} \\
&= -\ln\left(\frac{\sqrt{2}}{2}\right) - 0
\end{aligned}
$$
:::

::: point Simplification
$$
\begin{aligned}
-\ln\left(\frac{\sqrt{2}}{2}\right) &= \ln\left(\frac{2}{\sqrt{2}}\right) \\
&= \ln(\sqrt{2}) \\
&= \frac{1}{2}\ln(2)
\end{aligned}
$$
:::

::: resultat
$$\int_0^{\frac{\pi}{4}} \tan(x)\, dx = \frac{1}{2}\ln(2)$$
:::
