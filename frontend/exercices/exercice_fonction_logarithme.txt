=== Application de la Fonction Logarithme : Propriétés Algébriques
Difficulté: easy

Énoncé: Simplifier les expressions logarithmiques suivantes en utilisant les propriétés du logarithme népérien.

**Question 1 : Simplifier $\ln(12)$ en utilisant les propriétés du logarithme**

**Question 2 : Simplifier $\ln(x^4)$ et $\ln(\sqrt{x})$**

**Question 3 : Simplifier $\ln(e^{2x+1})$ et $\ln(e^{x^2}) + \ln(e^{3x})$**

**Question 4 : Calculer $\ln(1)$, $\ln(e)$, $\ln(e^3)$ et $\ln(\sqrt{e})$**

**Question 5 : Résoudre $\ln(x) = 2$ et $\ln(x+1) = 0$**

Étapes:

**Question 1 : Simplification d'expressions avec produit et quotient**
    ● $\displaystyle\ln(12) = \ln(3 \times 4) = \ln(3) + \ln(4) = \ln(3) + \ln(2^2) = \ln(3) + 2\ln(2)$
    ● $\displaystyle\ln\left(\frac{18}{6}\right) = \ln(18) - \ln(6) = \ln(3 \times 6) - \ln(6) = \ln(3) + \ln(6) - \ln(6) = \ln(3)$
    ● $\displaystyle\ln(2 \times 5 \times 3) = \ln(2) + \ln(5) + \ln(3)$
    $\\$
**Question 2 : Simplification d'expressions avec puissances**
    ● $\displaystyle\ln(x^4) = 4\ln(x)$
    ● $\displaystyle\ln(\sqrt{x}) = \ln(x^{1/2}) = \frac{1}{2}\ln(x)$
    ● $\displaystyle\ln(x^3 \times y^2) = \ln(x^3) + \ln(y^2) = 3\ln(x) + 2\ln(y)$
    ● $\displaystyle\ln\left(\frac{x^2}{y^3}\right) = \ln(x^2) - \ln(y^3) = 2\ln(x) - 3\ln(y)$
    $\\$
**Question 3 : Simplification d'expressions complexes**
    ● $\displaystyle\ln(e^{2x+1}) = 2x + 1$
    ● $\displaystyle\ln(e^{x^2}) + \ln(e^{3x}) = x^2 + 3x$
    ● $\displaystyle\ln\left(\frac{e^{2x}}{e^{x+1}}\right) = \ln(e^{2x}) - \ln(e^{x+1}) = 2x - (x+1) = x - 1$
    ● $\displaystyle\ln(\sqrt{e^{4x}}) = \ln(e^{4x})^{1/2} = \ln(e^{2x}) = 2x$
    $\\$
**Question 4 : Calcul de valeurs numériques**
    ● $\displaystyle\ln(1) = 0$ (propriété fondamentale)
    ● $\displaystyle\ln(e) = 1$ (définition de e)
    ● $\displaystyle\ln(e^3) = 3$
    ● $\displaystyle\ln\left(\frac{1}{e^2}\right) = \ln(e^{-2}) = -2$
    ● $\displaystyle\ln(\sqrt{e}) = \ln(e^{1/2}) = \frac{1}{2}$
    $\\$
**Question 5 : Résolution d'équations simples**
    ● $\displaystyle\ln(x) = 2 \Rightarrow x = e^2$
    ● $\displaystyle\ln(x+1) = 0 \Rightarrow x + 1 = e^0 = 1 \Rightarrow x = 0$
    ● $\displaystyle\ln(2x) = 1 \Rightarrow 2x = e^1 = e \Rightarrow x = \frac{e}{2}$
    ● $\displaystyle\ln(x^2) = 4 \Rightarrow x^2 = e^4 \Rightarrow x = e^2$ ou $x = -e^2$ (mais $x > 0$ donc $x = e^2$)

Solution:
1. $\displaystyle\ln(12) = \ln(3) + 2\ln(2)$ ; $\displaystyle\ln\left(\frac{18}{6}\right) = \ln(3)$ ; $\displaystyle\ln(30) = \ln(2) + \ln(3) + \ln(5)$
2. $\displaystyle\ln(x^4) = 4\ln(x)$ ; $\displaystyle\ln(\sqrt{x}) = \frac{1}{2}\ln(x)$ ; $\displaystyle\ln(x^3y^2) = 3\ln(x) + 2\ln(y)$
3. $\displaystyle\ln(e^{2x+1}) = 2x + 1$ ; $\displaystyle\ln(e^{x^2}) + \ln(e^{3x}) = x^2 + 3x$ ; $\displaystyle\ln(\sqrt{e^{4x}}) = 2x$
4. $\displaystyle\ln(1) = 0$ ; $\displaystyle\ln(e) = 1$ ; $\displaystyle\ln(e^3) = 3$ ; $\displaystyle\ln(e^{-2}) = -2$ ; $\displaystyle\ln(\sqrt{e}) = \frac{1}{2}$
5. $\displaystyle x = e^2$ ; $\displaystyle x = 0$ ; $\displaystyle x = \frac{e}{2}$ ; $\displaystyle x = e^2$

=== Dérivation des Fonctions Logarithmiques
Difficulté: medium

Énoncé: Calculer les dérivées des fonctions suivantes en utilisant les règles de dérivation du logarithme népérien.

**Question 1 : Calculer la dérivée de $f(x) = \ln(x)$ et $f(x) = \ln(2x)$**

**Question 2 : Calculer la dérivée de $f(x) = \ln(x^2 + 1)$ et $f(x) = \ln(2x^2 - 3x + 1)$**

**Question 3 : Calculer la dérivée de $f(x) = x \ln(x)$ et $f(x) = \frac{\ln(x)}{x}$**

**Question 4 : Calculer la dérivée de $f(x) = \ln(\ln(x))$ et $f(x) = \ln\left(\frac{x + 1}{x - 1}\right)$**

**Question 5 : Calculer $f'(0)$ pour $f(x) = \ln(2x + 1)$ et $f'(e)$ pour $f(x) = x \ln(x)$**

Étapes:

**Question 1 : Dérivées de fonctions logarithmiques simples**
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(x)$</span>
        - Formule utilisée : $\displaystyle(\ln(x))' = \frac{1}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{1}{x}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(2x)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = 2x$
        - $\displaystyle u' = 2$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{2}{2x} = \frac{1}{x}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(3x + 1)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = 3x + 1$
        - $\displaystyle u' = 3$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{3}{3x + 1}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(x^2)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = x^2$
        - $\displaystyle u' = 2x$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{2x}{x^2} = \frac{2}{x}$</span>
    $\\$
**Question 2 : Dérivées de fonctions composées**
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(x^2 + 1)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = x^2 + 1$
        - $\displaystyle u' = 2x$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{2x}{x^2 + 1}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(2x^2 - 3x + 1)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = 2x^2 - 3x + 1$
        - $\displaystyle u' = 4x - 3$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{4x - 3}{2x^2 - 3x + 1}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(\sqrt{x^2 + 4})$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = \sqrt{x^2 + 4}$
        - $\displaystyle u' = \frac{2x}{2\sqrt{x^2 + 4}} = \frac{x}{\sqrt{x^2 + 4}}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{x}{\sqrt{x^2 + 4}} \times \frac{1}{\sqrt{x^2 + 4}} = \frac{x}{x^2 + 4}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(e^{2x} + 1)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = e^{2x} + 1$
        - $\displaystyle u' = 2e^{2x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{2e^{2x}}{e^{2x} + 1}$</span>
    $\\$
**Question 3 : Dérivées de produits et quotients**
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = x \ln(x)$</span>
        - Formule utilisée : $\displaystyle(uv)' = u'v + uv'$ avec $u = x$ et $v = \ln(x)$
        - $\displaystyle u' = 1$ et $\displaystyle v' = \frac{1}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = 1 \times \ln(x) + x \times \frac{1}{x} = \ln(x) + 1$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = x^2 \ln(x)$</span>
        - Formule utilisée : $\displaystyle(uv)' = u'v + uv'$ avec $u = x^2$ et $v = \ln(x)$
        - $\displaystyle u' = 2x$ et $v' = \frac{1}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = 2x \ln(x) + x^2 \times \frac{1}{x} = 2x \ln(x) + x = x(2\ln(x) + 1)$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \frac{\ln(x)}{x}$</span>
        - Formule utilisée : $\displaystyle\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ avec $u = \ln(x)$ et $v = x$
        - $u' = \frac{1}{x}$ et $v' = 1$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{\frac{1}{x} \times x - \ln(x) \times 1}{x^2} = \frac{1 - \ln(x)}{x^2}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \frac{x}{\ln(x)}$</span>
        - Formule utilisée : $\displaystyle\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ avec $u = x$ et $v = \ln(x)$
        - $\displaystyle u' = 1$ et $\displaystyle v' = \frac{1}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{1 \times \ln(x) - x \times \frac{1}{x}}{(\ln(x))^2} = \frac{\ln(x) - 1}{(\ln(x))^2}$</span>
    $\\$
**Question 4 : Dérivées de fonctions complexes**
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(\ln(x))$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = \ln(x)$
        - $u' = \frac{1}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{1}{\ln(x)} \times \frac{1}{x} = \frac{1}{x \ln(x)}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(x^2 + 2x + 1)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = x^2 + 2x + 1$
        - $\displaystyle u' = 2x + 2 = 2(x + 1)$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{2(x + 1)}{(x + 1)^2} = \frac{2}{x + 1}$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln\left(\frac{x + 1}{x - 1}\right)$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = \frac{x + 1}{x - 1}$
        - $\displaystyle u' = \frac{1 \times (x - 1) - (x + 1) \times 1}{(x - 1)^2} = \frac{-2}{(x - 1)^2}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(x) = \frac{-2}{(x - 1)^2} \times \frac{x - 1}{x + 1} = \frac{-2}{(x + 1)(x - 1)}$</span>
    $\\$
**Question 5 : Calcul de dérivées en un point**
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(2x + 1)$ en $x = 0$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = 2x + 1$
        - $\displaystyle u' = 2$
        - $\displaystyle f'(x) = \frac{2}{2x + 1}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(0) = \frac{2}{1} = 2$</span>
   $\\$    
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = x \ln(x)$ en $x = e$</span>
        - Formule utilisée : $\displaystyle(uv)' = u'v + uv'$ avec $u = x$ et $v = \ln(x)$
        - $\displaystyle u' = 1$ et $\displaystyle v' = \frac{1}{x}$
        - $\displaystyle f'(x) = \ln(x) + 1$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(e) = \ln(e) + 1 = 1 + 1 = 2$</span>
       $\\$
    ● <span style="color: #2c3e50; font-weight: bold;">$f(x) = \ln(x^2)$ en $x = 1$</span>
        - Formule utilisée : $\displaystyle(\ln(u))' = \frac{u'}{u}$ avec $u = x^2$
        - $\displaystyle u' = 2x$
        - $\displaystyle f'(x) = \frac{2x}{x^2} = \frac{2}{x}$
        - <span style="color: #e74c3c; font-weight: bold;">$\displaystyle f'(1) = 2$</span>

Solution:
1. $\displaystyle f'(x) = \frac{1}{x}$ ; $\displaystyle f'(x) = \frac{1}{x}$ ; $\displaystyle f'(x) = \frac{3}{3x + 1}$ ; $\displaystyle f'(x) = \frac{2}{x}$
2. $\displaystyle f'(x) = \frac{2x}{x^2 + 1}$ ; $\displaystyle f'(x) = \frac{4x - 3}{2x^2 - 3x + 1}$ ; $\displaystyle f'(x) = \frac{x}{x^2 + 4}$ ; $\displaystyle f'(x) = \frac{2e^{2x}}{e^{2x} + 1}$
3. $\displaystyle f'(x) = \ln(x) + 1$ ; $\displaystyle f'(x) = x(2\ln(x) + 1)$ ; $\displaystyle f'(x) = \frac{1 - \ln(x)}{x^2}$ ; $\displaystyle f'(x) = \frac{\ln(x) - 1}{(\ln(x))^2}$
4. $\displaystyle f'(x) = \frac{1}{x \ln(x)}$ ; $\displaystyle f'(x) = \frac{2}{x + 1}$ ; $\displaystyle f'(x) = \frac{-2}{(x + 1)(x - 1)}$
5. $\displaystyle f'(0) = 2$ ; $\displaystyle f'(e) = 2$ ; $\displaystyle f'(1) = 2$

=== Étude Complète d'une Fonction avec Logarithme
Difficulté: hard

Énoncé: Étudier complètement la fonction $f(x) = x^2 \ln(x)$ sur $]0, +\infty[$ : domaine de définition, dérivée, sens de variation, limites, tableau de variations et représentation graphique.

**Question 1 : Déterminer le domaine de définition de $f(x) = x^2 \ln(x)$**

**Question 2 : Calculer la dérivée $f'(x)$ de la fonction $f(x) = x^2 \ln(x)$**

**Question 3 : Étudier le sens de variation et déterminer les extremums**

**Question 4 : Calculer $\lim_{x \to 0^+} f(x)$ et $\lim_{x \to +\infty} f(x)$**

**Question 5 : Dresser le tableau de variations complet**

Étapes:

**Question 1 : Domaine de définition et continuité**
    ● Domaine de définition : $\displaystyle D_f = ]0, +\infty[$ (nécessaire pour $\ln(x)$)
    ● La fonction est continue sur son domaine de définition
    ● La fonction est dérivable sur $\displaystyle ]0, +\infty[$
    $\\$
**Question 2 : Calcul de la dérivée première**
    ● $f(x) = x^2 \ln(x)$ est un produit : $\displaystyle u(x) = x^2$ et $\displaystyle v(x) = \ln(x)$
    ● $\displaystyle u'(x) = 2x$ et $\displaystyle v'(x) = \frac{1}{x}$
    ● $\displaystyle f'(x) = u'(x)v(x) + u(x)v'(x) = 2x \ln(x) + x^2 \times \frac{1}{x} = 2x \ln(x) + x = x(2\ln(x) + 1)$
    $\\$
**Question 3 : Sens de variation et extremums**
    ● $\displaystyle f'(x) = x(2\ln(x) + 1)$
    ● $\displaystyle x > 0$ sur le domaine, donc le signe de $f'(x)$ dépend de $\displaystyle 2\ln(x) + 1$
    ● $\displaystyle 2\ln(x) + 1 = 0 \Leftrightarrow \ln(x) = -\frac{1}{2} \Leftrightarrow x = e^{-1/2} = \frac{1}{\sqrt{e}}$
    ● Pour $\displaystyle x > \frac{1}{\sqrt{e}}$ : $\displaystyle 2\ln(x) + 1 > 0$ donc $\displaystyle f'(x) > 0$ (fonction croissante)
    ● Pour $\displaystyle 0 < x < \frac{1}{\sqrt{e}}$ : $\displaystyle 2\ln(x) + 1 < 0$ donc $\displaystyle f'(x) < 0$ (fonction décroissante)
    ● Minimum en $\displaystyle x = \frac{1}{\sqrt{e}}$ : $\displaystyle f\left(\frac{1}{\sqrt{e}}\right) = \frac{1}{e} \ln\left(\frac{1}{\sqrt{e}}\right) = \frac{1}{e} \times \left(-\frac{1}{2}\right) = -\frac{1}{2e}$
    $\\$
**Question 4 : Calcul des limites**
    ● En $\displaystyle 0^+$ : $\displaystyle\lim_{x \to 0^+} x^2 \ln(x) = \lim_{x \to 0^+} x^2 \times (-\infty) = 0 \times (-\infty) = 0$ (limite de référence)
    ● En $\displaystyle +\infty$ : $\displaystyle\lim_{x \to +\infty} x^2 \ln(x) = +\infty \times +\infty = +\infty$
    $\\$

5. Fonction décroissante sur $]0, \frac{1}{\sqrt{e}}]$, croissante sur $[\frac{1}{\sqrt{e}}, +\infty[$

=== Résolution d'Équations Logarithmiques
Difficulté: medium

Énoncé: Résoudre les équations logarithmiques suivantes en utilisant les propriétés du logarithme népérien.

**Question 1 : Résoudre $\ln(x) = 3$ et $\ln(x + 2) = 1$**

**Question 2 : Résoudre $\ln(x + 1) = \ln(2x - 3)$ et $\ln(x^2 - 1) = \ln(x + 1)$**

**Question 3 : Résoudre $\ln(x) + \ln(x + 1) = \ln(2)$ et $\ln(x^2) - \ln(x) = 1$**

**Question 4 : Résoudre $\ln(x + 1) - \ln(x - 1) = \ln(3)$ et $\ln(x^2 - 4) = \ln(x + 2)$**

**Question 5 : Vérifier que les solutions trouvées sont correctes**

Étapes:

**Question 1 : Équations simples avec logarithme**

    **a) Résoudre $\displaystyle\ln(x) = 3$**
        - Propriété : $\displaystyle\ln(x) = a \Rightarrow x = e^a$
        - Solution : $\displaystyle x = e^3$
    $\\$
    **b) Résoudre $\displaystyle\ln(x + 2) = 1$**
        - Propriété : $\displaystyle\ln(x + 2) = 1 \Rightarrow x + 2 = e^1 = e$
        - Solution : $\displaystyle x = e - 2$
    $\\$
    **c) Résoudre $\displaystyle\ln(2x - 1) = 0$**
        - Propriété : $\displaystyle\ln(2x - 1) = 0 \Rightarrow 2x - 1 = e^0 = 1$
        - Calcul : $\displaystyle 2x = 2$ donc $\displaystyle x = 1$
    $\\$
    **d) Résoudre $\displaystyle\ln(x^2) = 4$**
        - Propriété : $\displaystyle\ln(x^2) = 4 \Rightarrow x^2 = e^4$
        - Solution : $\displaystyle x = e^2$ (car $\displaystyle x > 0$)
    $\\$
**Question 2 : Équations avec égalité de logarithmes**

    **a) Résoudre $\displaystyle\ln(x + 1) = \ln(2x - 3)$**
        - Propriété : $\displaystyle\ln(u) = \ln(v) \Rightarrow u = v$
        - Équation : $\displaystyle x + 1 = 2x - 3$
        - Résolution : $\displaystyle 1 + 3 = 2x - x$ donc $\displaystyle x = 4$
        - Vérification : $\displaystyle x = 4 > 0$, $\displaystyle 4 + 1 = 5 > 0$ et $\displaystyle 2 \times 4 - 3 = 5 > 0$ ✓
    $\\$
    **b) Résoudre $\displaystyle\ln(x^2 - 1) = \ln(x + 1)$**
        - Propriété : $\displaystyle\ln(u) = \ln(v) \Rightarrow u = v$
        - Équation : $\displaystyle x^2 - 1 = x + 1$ donc $\displaystyle x^2 - x - 2 = 0$
        - Solutions : $\displaystyle x = 2$ ou $\displaystyle x = -1$
        - Condition : $\displaystyle x > 0$ donc $\displaystyle x = 2$
    $\\$
**Question 3 : Équations nécessitant des transformations**

    **a) Résoudre $\displaystyle\ln(x) + \ln(x + 1) = \ln(2)$**
        - Propriété : $\displaystyle\ln(a) + \ln(b) = \ln(ab)$
        - Transformation : $\displaystyle\ln(x(x + 1)) = \ln(2)$

=== Étude Complète des Fonctions Logarithmiques Composées
Difficulté: easy

Énoncé: Étudier la fonction $\displaystyle f(x) = \ln(x^2 + 2x + 2)$ définie sur $\mathbb{R}$.

**Question 1 : Déterminer le domaine de définition de $f$**

**Question 2 : Calculer la dérivée $\displaystyle f'(x)$ et déterminer son signe**

**Question 3 : Étudier les limites aux bornes du domaine et à l'infini**

**Question 4 : Déterminer les extremums éventuels de $f$**

**Question 5 : Tracer le tableau de variations de $f$**

Étapes:

**Question 1 : Domaine de définition**

**Étape 1 : Identifier la contrainte**
La fonction $\ln$ n'est définie que pour les arguments strictement positifs :
$\displaystyle x^2 + 2x + 2 > 0$
    $\\$
**Étape 2 : Étudier le signe du trinôme**
$\displaystyle P(x) = x^2 + 2x + 2$
