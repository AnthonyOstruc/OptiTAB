=== Proportionnalité (bases) - Programme 6ème
Difficulté: easy
Ordre: 6

Titre: Proportionnalité (bases) : Reconnaître, compléter des tableaux, utiliser le coefficient
Description: Cours complet sur la proportionnalité en 6ème : reconnaître une situation de proportionnalité, compléter un tableau de proportionnalité simple, utiliser le coefficient de proportionnalité dans des cas faciles, exemples concrets (prix au kilo, recettes, cartes à l'échelle, agrandissements), calculs par multiplication ou division, identifier les cas où ce n'est pas proportionnel.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6; font-size:1em;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce que la proportionnalité ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Situation de proportionnalité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux grandeurs sont <strong>proportionnelles</strong> quand, en multipliant (ou en divisant) une grandeur par un nombre, l'autre grandeur est multipliée (ou divisée) par le <strong>même nombre</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela signifie qu'il existe un nombre constant, appelé <strong>coefficient de proportionnalité</strong>, qui permet de passer de la première grandeur à la seconde.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple simple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si <strong>1 livre</strong> coûte <strong>5 €</strong>, alors :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>2 livres</strong> coûtent <strong>10 €</strong> (on multiplie par 2)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 livres</strong> coûtent <strong>15 €</strong> (on multiplie par 3)</li>
                <li style="margin:0; text-align:left;"><strong>4 livres</strong> coûtent <strong>20 €</strong> (on multiplie par 4)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le prix est proportionnel au nombre de livres. Le coefficient de proportionnalité est <strong>5</strong> (prix pour 1 livre).</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour reconnaître la proportionnalité, on peut se demander : "Si je double (ou triple) une grandeur, est-ce que l'autre double (ou triple) aussi ?" Si oui, c'est proportionnel !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Reconnaître une situation de proportionnalité</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Comment reconnaître la proportionnalité ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode pour reconnaître</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour reconnaître une situation de proportionnalité, on peut :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier si en multipliant une grandeur par un nombre, l'autre est multipliée par le même nombre</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier si le rapport (division) entre les deux grandeurs est toujours le même</li>
                <li style="margin:0; text-align:left;">Observer si on peut représenter la situation dans un tableau à deux colonnes</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Situation proportionnelle - Prix au kilo</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Des pommes sont vendues <strong>3 € le kilogramme</strong>.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">1 kg coûte 3 €</li>
                <li style="margin:0 0 12px 0; text-align:left;">2 kg coûtent 6 € (on multiplie par 2)</li>
                <li style="margin:0 0 12px 0; text-align:left;">3 kg coûtent 9 € (on multiplie par 3)</li>
                <li style="margin:0; text-align:left;">5 kg coûtent 15 € (on multiplie par 5)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>✅ C'est proportionnel</strong> : le prix est toujours multiplié par le même nombre que la quantité.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Situation non proportionnelle - Remise sur la quantité</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un magasin propose : "1 livre à 10 € ou 3 livres à 25 €".</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">1 livre coûte 10 €</li>
                <li style="margin:0 0 12px 0; text-align:left;">3 livres coûtent 25 € (et non 30 €)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si c'était proportionnel, 3 livres devraient coûter 3 × 10 = 30 €.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>❌ Ce n'est pas proportionnel</strong> : il y a une remise, donc le prix ne suit pas la règle de multiplication simple.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Le coefficient de proportionnalité</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et utilisation</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Coefficient de proportionnalité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>coefficient de proportionnalité</strong> est le nombre par lequel on multiplie la première grandeur pour obtenir la seconde.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On le trouve en divisant une valeur de la deuxième grandeur par la valeur correspondante de la première grandeur.</p>
        </div>

                <li style="margin:0 0 12px 0; text-align:left;">Coefficient = Prix ÷ Quantité = 5 ÷ 1 = <strong>5</strong></li>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Calculs par multiplication et division</h2>

            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">

            <p style="margin:8px 0; text-align:left; font-size:1em;">On sait que <strong>1 litre de jus</strong> coûte <strong>3 €</strong>. Combien coûtent <strong>7 litres</strong> ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Coefficient = 3 (prix pour 1 litre)</li>
                <li style="margin:0; text-align:left;">Prix pour 7 litres = 7 × 3 = <strong>21 €</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Calcul par division</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On sait que <strong>6 pommes</strong> coûtent <strong>12 €</strong>. Combien coûte <strong>1 pomme</strong> ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Prix pour 1 pomme = 12 ÷ 6 = <strong>2 €</strong></li>
                <li style="margin:0; text-align:left;">On vient de trouver le coefficient de proportionnalité : 2</li>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Cas où ce n'est pas proportionnel</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Identifier les situations non proportionnelles</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Quand ce n'est pas proportionnel ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une situation <strong>n'est pas proportionnelle</strong> quand on ne peut pas multiplier (ou diviser) une grandeur par un nombre pour obtenir l'autre grandeur multipliée (ou divisée) par le même nombre.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Exemple 1 : Prix avec frais fixes</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un taxi facture <strong>5 € de prise en charge</strong> + <strong>2 € par kilomètre</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tableau des prix :</p>
            
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Distance (en km)</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Prix (en €)</th>
                    </tr>
                </thead>
                <tbody>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">1</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>7</strong> (5 + 2)</td>
                    </tr>
                    <tr style="background:#e8f4f8;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">2</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>9</strong> (5 + 4)</td>
                    </tr>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">3</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>11</strong> (5 + 6)</td>
                    </tr>
                </tbody>
            </table>

            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si c'était proportionnel, 2 km devraient coûter : 7 × 2 = 14 €</li>
                <li style="margin:0; text-align:left;">Or, 2 km coûtent seulement 9 € (il y a le frais fixe de 5 €)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>❌ Ce n'est pas proportionnel</strong> : il y a un frais fixe qui ne change pas.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Exemple 2 : Remise sur quantité</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un magasin propose : "<strong>1 livre à 10 €</strong> ou <strong>3 livres à 25 €</strong>".</p>
            
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">

                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Prix (en €)</th>
                    </tr>
                </thead>
                <tbody>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">1</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>10</strong></td>
                    </tr>
                    <tr style="background:#e8f4f8;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">3</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>25</strong></td>
                    </tr>
                </tbody>
            </table>

            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si c'était proportionnel, 3 livres devraient coûter : 10 × 3 = 30 €</li>
                <li style="margin:0; text-align:left;">Or, 3 livres coûtent 25 € (il y a une remise de 5 €)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>❌ Ce n'est pas proportionnel</strong> : le prix par livre diminue quand on en achète plusieurs.</p>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Exemple 3 : Âge et taille</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La taille d'un enfant n'est <strong>pas proportionnelle</strong> à son âge.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un enfant de 5 ans mesure environ 110 cm.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un enfant de 10 ans ne mesure pas 110 × 2 = 220 cm (ce serait impossible !).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En réalité, un enfant de 10 ans mesure environ 140 cm.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>❌ Ce n'est pas proportionnel</strong> : la croissance n'est pas linéaire, elle ralentit avec l'âge.</p>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>💡 Comment vérifier si c'est proportionnel ?</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour vérifier si une situation est proportionnelle, on peut :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Calculer le coefficient pour chaque ligne du tableau</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si tous les coefficients sont identiques, c'est proportionnel</li>
                <li style="margin:0; text-align:left;">Si les coefficients sont différents, ce n'est pas proportionnel</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exemple : Dans le tableau du taxi, les coefficients sont 7 (pour 1 km), 4,5 (pour 2 km), 3,67 (pour 3 km)... Ils sont différents, donc ce n'est pas proportionnel.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Tableau récapitulatif</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résumé des méthodes</h3>

        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50; width:30%;">Notion</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50; width:70%;">Méthode / Exemple</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Reconnaître la proportionnalité</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Vérifier si en multipliant une grandeur par un nombre, l'autre est multipliée par le même nombre</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Coefficient de proportionnalité</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Diviser une valeur de la 2ème grandeur par la valeur correspondante de la 1ère grandeur. Exemple : 10 ÷ 2 = 5</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Compléter un tableau (vers le bas)</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Multiplier par le coefficient. Exemple : 4 × 5 = 20</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Compléter un tableau (vers le haut)</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Diviser par le coefficient. Exemple : 15 ÷ 5 = 3</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Exemples proportionnels</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Prix au kilo, recettes (avec proportionnalité), cartes à l'échelle, agrandissements</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Exemples non proportionnels</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:left;">Prix avec frais fixes, remises sur quantité, âge et taille</td>
                </tr>
            </tbody>
        </table>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour trouver le coefficient</strong> : toujours utiliser une ligne complète du tableau</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour vérifier</strong> : calculer le coefficient sur plusieurs lignes pour s'assurer qu'il est toujours le même</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour compléter un tableau</strong> : bien identifier si on doit multiplier ou diviser</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Attention aux unités</strong> : vérifier que les unités sont cohérentes (€/kg, cm/km, etc.)</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier le résultat</strong> : s'assurer que le résultat a du sens dans la situation</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondre multiplication et division</strong> : toujours se demander "dois-je multiplier ou diviser ?"</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier de vérifier si c'est proportionnel</strong> : ne pas supposer que toutes les situations sont proportionnelles</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Utiliser le mauvais coefficient</strong> : vérifier que le coefficient est calculé correctement</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier les unités</strong> : toujours inclure les unités dans les réponses (€, kg, cm, km, etc.)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas vérifier le résultat</strong> : le résultat doit avoir du sens (un prix ne peut pas être négatif, par exemple)</li>
                <li style="margin:0; text-align:left;"><strong>Se tromper dans le sens</strong> : bien identifier quelle grandeur on cherche (prix, quantité, distance, etc.)</li>
            </ul>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>💡 Méthode complète pour résoudre un problème de proportionnalité :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire attentivement</strong> le problème et identifier les grandeurs</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérifier si c'est proportionnel</strong> (ou le problème le précise)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Construire un tableau</strong> à deux colonnes</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Calculer le coefficient</strong> à partir d'une ligne complète</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Compléter le tableau</strong> en multipliant ou divisant par le coefficient</li>
                <li style="margin:0; text-align:left;"><strong>Répondre</strong> avec une phrase complète qui inclut les unités</li>
            </ol>
        </div>
