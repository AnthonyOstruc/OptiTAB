Titre: Résumé : Développer, factoriser et prouver

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel du calcul littéral : substitution, réduction, distributivité, factorisation, identités remarquables et démonstrations. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Développer et réduire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle k(a+b) = ka + kb$ &nbsp;&nbsp; $\displaystyle (a+b)(c+d) = ac + ad + bc + bd$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• $\displaystyle -(a-b) = -a + b$ : le moins change tous les signes.</p>
<p style="margin:6px 0 0 0;">• Substituer avec des <strong>parenthèses</strong> : pour $\displaystyle x = -2$, $\displaystyle 3x^2 = 3 \times (-2)^2 = 12$.</p>
<p style="margin:6px 0 0 0;">• $\displaystyle 3x + 2x = 5x$ mais $\displaystyle 3x + 2$ ne se réduit pas.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Factoriser</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;"><strong>Trois réflexes, dans l'ordre :</strong></p>
<p style="margin:6px 0 0 0;">① <strong>Facteur commun</strong> : $\displaystyle 6x^2 - 9x = 3x(2x-3)$ ; $\displaystyle 3x(x-2) + 5(x-2) = (x-2)(3x+5)$.</p>
<p style="margin:6px 0 0 0;">② <strong>Différence de carrés</strong> : $\displaystyle a^2 - b^2 = (a-b)(a+b)$, ex. $\displaystyle 4x^2 - 25 = (2x-5)(2x+5)$.</p>
<p style="margin:6px 0 0 0;">③ <strong>Carré reconnu</strong> : $\displaystyle x^2 + 10x + 25 = (x+5)^2$.</p>
<p style="margin:8px 0 0 0;"><strong>Contrôle :</strong> redévelopper doit redonner l'expression de départ.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Identités remarquables</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:420px;">
<p style="margin:0; font-weight:bold;">$\displaystyle (a+b)^2 = a^2 + 2ab + b^2$</p>
<p style="margin:6px 0 0 0; font-weight:bold;">$\displaystyle (a-b)^2 = a^2 - 2ab + b^2$</p>
<p style="margin:6px 0 0 0; font-weight:bold;">$\displaystyle (a-b)(a+b) = a^2 - b^2$</p>
</div>
<p style="margin:0;"><strong>Calcul astucieux :</strong> $\displaystyle 99^2 = (100-1)^2 = 9\,801$ ; $\displaystyle 103 \times 97 = 10\,000 - 9 = 9\,991$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Démontrer avec une lettre</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Programme de calcul :</strong> nommer $\displaystyle x$ le nombre choisi, traduire chaque étape, transformer. Ex. : $\displaystyle 3(x+4) - 3x = 12$ pour tout $\displaystyle x$.</p>
<p style="margin:6px 0 0 0;">• <strong>Parité :</strong> pair $= 2n$, impair $= 2n+1$. Ex. : $\displaystyle (2n+1)^2 = 2(2n^2+2n)+1$, impair.</p>
<p style="margin:6px 0 0 0;">• <strong>Entiers consécutifs :</strong> $\displaystyle n$, $\displaystyle n+1$, $\displaystyle n+2$… Ex. : somme de trois consécutifs $= 3(n+1)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ $\displaystyle (a+b)^2 \neq a^2 + b^2$ : ne jamais oublier le double produit $\displaystyle 2ab$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Substituer un négatif sans parenthèses : $\displaystyle (-2)^2 = 4$, pas $\displaystyle -4$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Réduire $\displaystyle 3x + 2$ en $\displaystyle 5x$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire qu'un exemple numérique démontre une identité : seul le calcul littéral le fait.</p>
</div>
