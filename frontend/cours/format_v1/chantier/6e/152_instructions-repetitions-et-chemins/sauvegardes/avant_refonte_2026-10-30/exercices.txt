=== Découverte - Instructions, répétitions et chemins - 1. Lire une donnée et prévoir une sortie
Id: 3608
Difficulté: easy
Image: instructions_6e_1_1_f7ae47989b3e2a2e9386.png,instructions_6e_1_1_corrige_b29ebf56e6039e126efd.png

Énoncé:
<!-- optitab:1 -->
Le programme demande un nombre, puis affiche le résultat de « 2 × réponse + 3 ». Le bloc « réponse » lit la donnée saisie ; cette donnée n’est pas modifiée.

[IMAGE_1]

1. Quelle est l’entrée du programme ? Quelle est sa sortie ?
2. Quel calcul est effectué pour l’entrée 2 ?
3. Prévoir le nombre affiché pour cette entrée.
4. Quel nombre est affiché si on saisit 0 ?
5. On imbrique autrement les blocs pour calculer 2 × (réponse + 3). Quel résultat obtient-on pour l’entrée 2 ?
6. Les deux organisations de blocs représentent-elles la même formule ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Quelle est l’entrée du programme ? Quelle est sa sortie ?

::: methode
L’entrée est la donnée demandée ; la sortie est le résultat affiché après le calcul.
:::

::: resultat
Entrée : le nombre saisi. Sortie : 2 fois ce nombre, plus 3.
:::

## Question 2 : Quel calcul est effectué pour l’entrée 2 ?

::: methode
Remplacer le bloc réponse par la donnée saisie, sans changer les opérations.
:::

::: resultat
$\displaystyle 2\times 2+3$.
:::

## Question 3 : Prévoir le nombre affiché pour cette entrée.

::: methode
Effectuer la multiplication avant l’addition ; la donnée saisie reste inchangée.
:::

::: etape $\displaystyle 2\times 2+3=7$
:::

::: resultat
7.
:::

## Question 4 : Quel nombre est affiché si on saisit 0 ?

::: methode
Remplacer réponse par zéro ; seul le terme ajouté subsiste.
:::

::: etape $\displaystyle 2\times0+3=3$
:::

::: resultat
3.
:::

## Question 5 : On imbrique autrement les blocs pour calculer 2 × (réponse + 3). Quel résultat obtient-on pour l’entrée 2 ?

::: methode
Les blocs imbriqués imposent les parenthèses : additionner avant de multiplier change le programme.
:::

::: etape $\displaystyle 2(2+3)=10$
:::

::: resultat
10.
:::

## Question 6 : Les deux organisations de blocs représentent-elles la même formule ? Justifier.

::: methode
Développer la formule avec parenthèses : l’ajout est alors multiplié par le facteur. Un exemple de résultats différents suffit aussi à distinguer les programmes.
:::

::: resultat
Non : le premier affiche 7, le second 10 pour la même entrée.
:::

[IMAGE_2]

**À retenir :** En 6e, on lit une donnée saisie pour calculer une formule. Prévoir la sortie avant d’exécuter et contrôler l’imbrication des blocs.

Solution:
<!-- optitab:1 -->
1. Entrée : le nombre saisi. Sortie : 2 fois ce nombre, plus 3.
2. $\displaystyle 2\times 2+3$.
3. 7.
4. 3.
5. 10.
6. Non : le premier affiche 7, le second 10 pour la même entrée.

=== Découverte - Instructions, répétitions et chemins - 2. Programmer le tracé d’un carré
Id: 3609
Difficulté: easy
Image: instructions_6e_1_2_5088ff6e08ad2ae98d2f.png,instructions_6e_1_2_corrige_4495f242ba37a943b4b6.png

Énoncé:
<!-- optitab:1 -->
Un lutin part d’un point A, orienté vers la droite, stylo baissé. Il exécute : « répéter 4 fois : avancer de 10 pas ; tourner à gauche de 90° ». Un pas est une unité de longueur.

[IMAGE_1]

1. Combien de déplacements le programme exécute-t-il ?
2. Quelle distance totale le lutin parcourt-il ?
3. Quel angle total a-t-il tourné ?
4. Quelle figure obtient-on ? Justifier.
5. Quelle est la position et l’orientation finales du lutin ?
6. On enlève la dernière rotation seulement. Le dessin change-t-il ? L’état final change-t-il ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien de déplacements le programme exécute-t-il ?

::: methode
La boucle répète son contenu quatre fois ; il y a une instruction avancer par tour.
:::

::: resultat
4 déplacements.
:::

## Question 2 : Quelle distance totale le lutin parcourt-il ?

::: methode
Additionner les quatre déplacements de même longueur. Cette distance est le périmètre du tracé.
:::

::: etape $\displaystyle 4\times 10=40$
:::

::: resultat
40 pas.
:::

## Question 3 : Quel angle total a-t-il tourné ?

::: methode
Une rotation de 90° est exécutée à chaque tour de boucle, y compris le dernier.
:::

::: etape $\displaystyle 4\times90=360$
:::

::: resultat
360°, soit un tour complet.
:::

## Question 4 : Quelle figure obtient-on ? Justifier.

::: methode
Quatre côtés égaux sont tracés avec quatre angles droits. Après quatre déplacements, le lutin revient au point de départ.
:::

::: resultat
Un carré de côté 10 pas.
:::

## Question 5 : Quelle est la position et l’orientation finales du lutin ?

::: methode
Suivre les déplacements droite, haut, gauche, bas ; la quatrième rotation ramène l’orientation initiale.
:::

::: resultat
Au point A, orienté vers la droite.
:::

## Question 6 : On enlève la dernière rotation seulement. Le dessin change-t-il ? L’état final change-t-il ?

::: methode
Une rotation sans déplacement ne dessine pas de segment ; elle modifie seulement l’orientation du lutin.
:::

::: resultat
Le carré reste identique, mais le lutin termine orienté vers le bas : il lui manque le dernier quart de tour.
:::

[IMAGE_2]

**À retenir :** Distinguer le dessin, la position et l’orientation. Une boucle compacte plusieurs instructions, mais chaque instruction est exécutée dans l’ordre.

Solution:
<!-- optitab:1 -->
1. 4 déplacements.
2. 40 pas.
3. 360°, soit un tour complet.
4. Un carré de côté 10 pas.
5. Au point A, orienté vers la droite.
6. Le carré reste identique, mais le lutin termine orienté vers le bas : il lui manque le dernier quart de tour.

=== Découverte - Instructions, répétitions et chemins - 3. Coder un escalier avec une répétition
Id: 3610
Difficulté: easy
Image: instructions_6e_1_3_c73a82deebd195a0695e.png,instructions_6e_1_3_corrige_90e82f91864b7a1013ba.png

Énoncé:
<!-- optitab:1 -->
Un robot part du point D, dirigé vers la droite. Il répète 5 fois : « avancer de 1 case ; tourner à gauche d’un quart de tour ; avancer de 1 case ; tourner à droite d’un quart de tour ».

[IMAGE_1]

1. Combien d’instructions avancer y a-t-il dans une répétition ?
2. Décrire la première marche.
3. Combien de cases le robot parcourt-il en tout ?
4. Où arrive-t-il par rapport à son point de départ ?
5. Quelle est son orientation finale ?
6. Que changer pour obtenir deux marches supplémentaires ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien d’instructions avancer y a-t-il dans une répétition ?

::: methode
Une répétition contient toute la séquence située après répéter ; lire chaque instruction dans l’ordre.
:::

::: resultat
Deux instructions avancer.
:::

## Question 2 : Décrire la première marche.

::: methode
Le robot avance d’abord à droite, puis tourne et avance vers le haut ; la dernière rotation prépare la marche suivante.
:::

::: resultat
Une case à droite puis une case vers le haut ; il est de nouveau dirigé vers la droite.
:::

## Question 3 : Combien de cases le robot parcourt-il en tout ?

::: methode
Chaque marche comprend deux déplacements d’une case ; multiplier par le nombre de marches.
:::

::: etape $\displaystyle 2\times5=10$
:::

::: resultat
10 cases.
:::

## Question 4 : Où arrive-t-il par rapport à son point de départ ?

::: methode
Chaque marche ajoute une case horizontalement et une verticalement ; compter les deux directions séparément.
:::

::: resultat
5 cases à droite et 5 cases au-dessus de D.
:::

## Question 5 : Quelle est son orientation finale ?

::: methode
Dans une marche, les quarts de tour à gauche puis à droite se compensent ; chaque marche se termine dans l’orientation initiale.
:::

::: resultat
Vers la droite.
:::

## Question 6 : Que changer pour obtenir deux marches supplémentaires ?

::: methode
Le dessin d’une marche reste identique ; seul le nombre de répétitions doit augmenter.
:::

::: resultat
Remplacer 5 répétitions par 7 répétitions ; le robot parcourra 14 cases.
:::

[IMAGE_2]

**À retenir :** Décrire le chemin, la position finale et l’orientation séparément. Une rotation seule ne fait pas avancer le robot.

Solution:
<!-- optitab:1 -->
1. Deux instructions avancer.
2. Une case à droite puis une case vers le haut ; il est de nouveau dirigé vers la droite.
3. 10 cases.
4. 5 cases à droite et 5 cases au-dessus de D.
5. Vers la droite.
6. Remplacer 5 répétitions par 7 répétitions ; le robot parcourra 14 cases.
