Titre: Résumé : Calcul littéral et distributivité

<!-- optitab:1 -->
::: objectifs
Retenir l'essentiel : écrire et calculer une expression, réduire, développer (simple et double distributivité), factoriser, prouver.
:::

## I. Écrire et calculer

- Conventions : $3 \times x = 3x$ ; $x \times x = x^2$ ; $2 \times (x + 1) = 2(x + 1)$ ; $1 \times x = x$.
- Traduire une phrase : la **dernière opération** donne la nature de l'expression. « Le triple de $x$, diminué de $5$ » : $3x - 5$ ; « le triple de $x - 5$ » : $3(x - 5)$.
- Calculer une valeur : remplacer la lettre **entre parenthèses**, puis respecter les priorités. Pour $x = -2$ : $5x^2 - 3x + 1 = 5 \times 4 + 6 + 1 = 27$.

## II. Réduire

| Expression | Forme réduite |
|---|---|
| $x + x$ | $2x$ |
| $x \times x$ | $x^2$ |
| $6x - 4 + 2x^2 - 9x + 7$ | $2x^2 - 3x + 3$ |
| $4x \times 5x$ | $20x^2$ |

$3x + 2$ et $2x^2 + 3x$ ne se réduisent pas : termes de natures différentes.

## III. Développer

::: formule
$$k(a + b) = ka + kb$$
:::

[IMAGE_1]

- Exemple : $-3(2x - 5) = -6x + 15$.
- Un « $-$ » devant une parenthèse change le signe de **chaque** terme : $9 - (4x - 1) = 10 - 4x$.

::: formule
$$(a + b)(c + d) = ac + ad + bc + bd$$
:::

[IMAGE_2]

Exemple : quatre produits, puis on réduit.
$$
\begin{aligned}
(3x + 2)(x - 4) &= 3x^2 - 12x + 2x - 8 \\
&= 3x^2 - 10x - 8
\end{aligned}
$$

## IV. Factoriser

::: formule
$$ka + kb = k(a + b)$$
:::

- $6x + 21 = 3(2x + 7)$ ; $5x^2 - 4x = x(5x - 4)$ ; $8x + 8 = 8(x + 1)$.
- Prendre le plus grand facteur commun, puis **contrôler en redéveloppant**.

## V. Prouver

- Nombres entiers : pair $2n$ ; impair $2n + 1$ ; consécutifs $n$ et $n + 1$.
- Programme de calcul : écrire l'expression obtenue avec $x$, puis développer et réduire. Exemple : $2(x + 7) - 2x = 14$.
- Égalité **fausse** : un contre-exemple suffit. Égalité **toujours vraie** : un calcul avec la lettre, jamais des exemples.

::: attention Les erreurs classiques
1. $x + x = x^2$ (faux : $2x$) et $3x + 2x = 5x^2$ (faux : $5x$).
2. $3(x + 5) = 3x + 5$ (faux : $3x + 15$).
3. $-(4x - 1) = -4x - 1$ (faux : $-4x + 1$).
4. $(x + 3)(x + 2) = x^2 + 6$ (faux : il manque $3x$ et $2x$).
5. $8x + 8 = 8x$ (faux : $8(x + 1)$).
6. Croire qu'un exemple qui marche prouve une égalité.
:::

::: conseil Réflexe
Après un développement ou une factorisation, je teste avec une valeur simple ($x = 1$ ou $x = 10$) : les deux expressions doivent donner le même nombre.
:::
