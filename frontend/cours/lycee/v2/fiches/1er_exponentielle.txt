Titre: Résumé : Fonction exponentielle

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : définition, règles de calcul, signe, variations et dérivée de l’exponentielle. Programme de Première.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et règles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\exp' = \exp$, $e^0 = 1$, $e^{a + b} = e^a \times e^b$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $e^{-a} = \frac{1}{e^a}$ ; $e^{a - b} = \frac{e^a}{e^b}$ ; $(e^a)^n = e^{na}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $e^x \gt 0$ pour tout $x$ ; $\exp$ strictement croissante ; tangente en $0$ : $y = x + 1$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $e^a = e^b \iff a = b$ ; $e^a \lt e^b \iff a \lt b$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Dériver et étudier</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\left(e^{ax + b}\right)' = a\,e^{ax + b}$ ; $e^{kx}$ croissante si $k \gt 0$, décroissante si $k \lt 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Dans $f'(x) = (\ldots)\,e^{x}$, le signe est celui de la parenthèse.</p>
<p style="margin:6px 0 0 0;">3️⃣ $(e^{na})$ est géométrique de raison $e^a$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire $e^{a + b} = e^a + e^b$ : c’est un produit.</p>
<p style="margin:6px 0 0 0;">2️⃣ Chercher une solution à $e^x = 0$ ou $e^x \lt 0$ : il n’y en a pas.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier le facteur $a$ en dérivant $e^{ax + b}$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Étudier le signe de $e^x$ dans un tableau : il est toujours positif.</p>
</div>
