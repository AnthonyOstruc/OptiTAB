=== Découverte - Racines - Calculs de Base
Id: 1891
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Calculer les racines suivantes en détaillant les étapes.

1. Calculer $\displaystyle \sqrt{49}$
2. Calculer $\displaystyle \sqrt{144}$
3. Calculer $\displaystyle \sqrt[3]{8}$
4. Calculer $\displaystyle \sqrt[3]{-27}$
5. Calculer $\displaystyle \sqrt{0{,}25}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle \sqrt{49}$

::: methode
Calcul d'une racine carrée simple
:::

::: etape Chercher le nombre dont le carré est 49
- On cherche $x$ tel que $x^2 = 49$
:::

::: etape Tester les carrés connus
- $\displaystyle 7^2 = 7 \times 7 = 49$
:::

::: etape Vérification
- $\sqrt{49} = 7$ car $7^2 = 49$
:::

::: resultat
$$\sqrt{49} = 7$$
:::

## Question 2 : Calculer $\displaystyle \sqrt{144}$

::: methode
Racine carrée d'un carré parfait
:::

::: etape Chercher le nombre dont le carré est 144
- On cherche $x$ tel que $x^2 = 144$
:::

::: etape Utiliser les carrés connus
- $\displaystyle 12^2 = 144$
:::

::: etape Vérification
- $\sqrt{144} = 12$ car $12^2 = 144$
:::

::: resultat
$$\sqrt{144} = 12$$
:::

## Question 3 : Calculer $\displaystyle \sqrt[3]{8}$

::: methode
Calcul d'une racine cubique
:::

::: etape Chercher le nombre dont le cube est 8
- On cherche $x$ tel que $x^3 = 8$
:::

::: etape Tester les cubes connus
- $\displaystyle 2^3 = 2 \times 2 \times 2 = 8$
:::

::: etape Vérification
- $\sqrt[3]{8} = 2$ car $2^3 = 8$
:::

::: resultat
$$\sqrt[3]{8} = 2$$
:::

## Question 4 : Calculer $\displaystyle \sqrt[3]{-27}$

::: methode
Racine cubique d'un nombre négatif
:::

::: etape Observer que le nombre est négatif
- La racine cubique existe pour les nombres négatifs
- On cherche $x$ tel que $x^3 = -27$
:::

::: etape Décomposer en valeur absolue
- $\displaystyle |-27| = 27$
- $\sqrt[3]{27} = 3$ car $3^3 = 27$
:::

::: etape Appliquer le signe
- $\displaystyle (-3)^3 = -27$
- Donc $\displaystyle \sqrt[3]{-27} = -3$
:::

::: resultat
$$\sqrt[3]{-27} = -3$$
:::

## Question 5 : Calculer $\displaystyle \sqrt{0{,}25}$

::: methode
Racine carrée d'un décimal
:::

::: etape Convertir en fraction
- $\displaystyle 0{,}25 = \frac{25}{100} = \frac{1}{4}$
:::

::: etape Appliquer la propriété de la racine d'un quotient
$$
\begin{aligned}
\sqrt{\frac{1}{4}} &= \frac{\sqrt{1}}{\sqrt{4}} \\
&= \frac{1}{2}
\end{aligned}
$$
:::

::: etape Vérification
- $\displaystyle \left(\frac{1}{2}\right)^2 = \frac{1}{4} = 0{,}25$
:::

::: resultat
$$\sqrt{0{,}25} = 0{,}5$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \sqrt{49} = 7$
2. $\displaystyle \sqrt{144} = 12$
3. $\displaystyle \sqrt[3]{8} = 2$
4. $\displaystyle \sqrt[3]{-27} = -3$
5. $\displaystyle \sqrt{0{,}25} = 0{,}5$

=== Entraînement - Racines - Opérations
Id: 1893
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Effectuer les opérations suivantes avec des racines.

1. Calculer $\displaystyle 3\sqrt{2} + 5\sqrt{2}$
2. Calculer $\displaystyle \sqrt{3} \times \sqrt{12}$
3. Calculer $\displaystyle \frac{\sqrt{18}}{\sqrt{2}}$
4. Calculer $\displaystyle \sqrt{18} + \sqrt{50} - \sqrt{2}$
5. Calculer $\displaystyle 2\sqrt{3} \times 4\sqrt{5}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle 3\sqrt{2} + 5\sqrt{2}$

::: methode
Addition de racines identiques
:::

::: etape Observer que les racines sont identiques
- Les deux termes contiennent $\displaystyle \sqrt{2}$
- On peut factoriser
:::

::: etape Appliquer la règle $\displaystyle a\sqrt{c} + b\sqrt{c} = (a+b)\sqrt{c}$
$$
\begin{aligned}
3\sqrt{2} + 5\sqrt{2} &= (3+5)\sqrt{2} \\
&= 8\sqrt{2}
\end{aligned}
$$
:::

::: resultat
$$3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}$$
:::

## Question 2 : Calculer $\displaystyle \sqrt{3} \times \sqrt{12}$

::: methode
Produit de racines
:::

::: rappel Propriété utilisée
- $\sqrt{a} \times \sqrt{b} = \sqrt{a \times b}$ (avec $a \geq 0, b \geq 0$)
:::

::: etape Appliquer la propriété
$$
\begin{aligned}
\sqrt{3} \times \sqrt{12} &= \sqrt{3 \times 12} \\
&= \sqrt{36}
\end{aligned}
$$
:::

::: etape Calculer
- $\displaystyle \sqrt{36} = 6$
:::

::: resultat
$$\sqrt{3} \times \sqrt{12} = 6$$
:::

## Question 3 : Calculer $\displaystyle \frac{\sqrt{18}}{\sqrt{2}}$

::: methode
Quotient de racines
:::

::: rappel Propriété utilisée
- $\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ (avec $a \geq 0, b > 0$)
:::

::: etape Appliquer la propriété
$$
\begin{aligned}
\frac{\sqrt{18}}{\sqrt{2}} &= \sqrt{\frac{18}{2}} \\
&= \sqrt{9}
\end{aligned}
$$
:::

::: etape Calculer
- $\displaystyle \sqrt{9} = 3$
:::

::: resultat
$$\frac{\sqrt{18}}{\sqrt{2}} = 3$$
:::

## Question 4 : Calculer $\displaystyle \sqrt{18} + \sqrt{50} - \sqrt{2}$

::: methode
Simplification puis addition
:::

::: etape Simplifier chaque racine
- $\displaystyle \sqrt{18} = \sqrt{9 \times 2} = 3\sqrt{2}$
- $\displaystyle \sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$
- $\displaystyle \sqrt{2}$ reste inchangé
:::

::: etape Remplacer dans l'expression
- $\displaystyle \sqrt{18} + \sqrt{50} - \sqrt{2} = 3\sqrt{2} + 5\sqrt{2} - \sqrt{2}$
:::

::: etape Additionner les termes semblables
$$= (3 + 5 - 1)\sqrt{2} = 7\sqrt{2}$$
:::

::: resultat
$$\sqrt{18} + \sqrt{50} - \sqrt{2} = 7\sqrt{2}$$
:::

## Question 5 : Calculer $\displaystyle 2\sqrt{3} \times 4\sqrt{5}$

::: methode
Produit avec coefficients
:::

::: etape Séparer les coefficients et les racines
- Coefficients : $\displaystyle 2 \times 4 = 8$
- Racines : $\displaystyle \sqrt{3} \times \sqrt{5} = \sqrt{15}$
:::

::: etape Combiner
- $\displaystyle 2\sqrt{3} \times 4\sqrt{5} = 8\sqrt{15}$
:::

::: resultat
$$2\sqrt{3} \times 4\sqrt{5} = 8\sqrt{15}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3\sqrt{2} + 5\sqrt{2} = 8\sqrt{2}$
2. $\displaystyle \sqrt{3} \times \sqrt{12} = 6$
3. $\displaystyle \frac{\sqrt{18}}{\sqrt{2}} = 3$
4. $\displaystyle \sqrt{18} + \sqrt{50} - \sqrt{2} = 7\sqrt{2}$
5. $\displaystyle 2\sqrt{3} \times 4\sqrt{5} = 8\sqrt{15}$

=== Entraînement - Racines - Rationalisation
Id: 1894
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Rationaliser les dénominateurs des expressions suivantes.

1. Rationaliser $\displaystyle \frac{1}{\sqrt{2}}$
2. Rationaliser $\displaystyle \frac{3}{\sqrt{5}}$
3. Rationaliser $\displaystyle \frac{2}{\sqrt{3} + 1}$
4. Rationaliser $\displaystyle \frac{5}{\sqrt{7} - 2}$
5. Rationaliser $\displaystyle \frac{\sqrt{6}}{\sqrt{2}}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Rationaliser $\displaystyle \frac{1}{\sqrt{2}}$

::: methode
Rationalisation simple
:::

::: etape Identifier le type
- Dénominateur : $\displaystyle \sqrt{2}$ (racine simple)
- Multiplier par $\displaystyle \frac{\sqrt{2}}{\sqrt{2}}$
:::

::: etape Multiplier numérateur et dénominateur
$$
\begin{aligned}
\frac{1}{\sqrt{2}} &= \frac{1}{\sqrt{2}} \times \frac{\sqrt{2}}{\sqrt{2}} \\
&= \frac{\sqrt{2}}{(\sqrt{2})^2}
\end{aligned}
$$
:::

::: etape Simplifier
- $\displaystyle = \frac{\sqrt{2}}{2}$
:::

::: resultat
$$\frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$
:::

## Question 2 : Rationaliser $\displaystyle \frac{3}{\sqrt{5}}$

::: methode
Rationalisation avec coefficient
:::

::: etape Multiplier par $\displaystyle \frac{\sqrt{5}}{\sqrt{5}}$
- $\displaystyle \frac{3}{\sqrt{5}} = \frac{3}{\sqrt{5}} \times \frac{\sqrt{5}}{\sqrt{5}}$
:::

::: etape Calculer
- Numérateur : $\displaystyle 3 \times \sqrt{5} = 3\sqrt{5}$
- Dénominateur : $\displaystyle (\sqrt{5})^2 = 5$
:::

::: etape Écrire le résultat
- $\displaystyle \frac{3}{\sqrt{5}} = \frac{3\sqrt{5}}{5}$
:::

::: resultat
$$\frac{3}{\sqrt{5}} = \frac{3\sqrt{5}}{5}$$
:::

## Question 3 : Rationaliser $\displaystyle \frac{2}{\sqrt{3} + 1}$

::: methode
Rationalisation par le conjugué
:::

::: etape Identifier le conjugué
- Dénominateur : $\displaystyle \sqrt{3} + 1$
- Conjugué : $\displaystyle \sqrt{3} - 1$
:::

::: etape Multiplier par le conjugué
- $\displaystyle \frac{2}{\sqrt{3} + 1} = \frac{2}{\sqrt{3} + 1} \times \frac{\sqrt{3} - 1}{\sqrt{3} - 1}$
:::

::: etape Développer le numérateur
- $\displaystyle 2(\sqrt{3} - 1) = 2\sqrt{3} - 2$
:::

::: etape Développer le dénominateur (identité remarquable)
$$
\begin{aligned}
(\sqrt{3} + 1)(\sqrt{3} - 1) &= (\sqrt{3})^2 - 1^2 \\
&= 3 - 1 \\
&= 2
\end{aligned}
$$
:::

::: etape Simplifier
$$
\begin{aligned}
\frac{2\sqrt{3} - 2}{2} &= \frac{2(\sqrt{3} - 1)}{2} \\
&= \sqrt{3} - 1
\end{aligned}
$$
:::

::: resultat
$$\frac{2}{\sqrt{3} + 1} = \sqrt{3} - 1$$
:::

## Question 4 : Rationaliser $\displaystyle \frac{5}{\sqrt{7} - 2}$

::: methode
Multiplication par le conjugué
:::

::: etape Identifier le conjugué
- Dénominateur : $\displaystyle \sqrt{7} - 2$
- Conjugué : $\displaystyle \sqrt{7} + 2$
:::

::: etape Multiplier
- $\displaystyle \frac{5}{\sqrt{7} - 2} = \frac{5}{\sqrt{7} - 2} \times \frac{\sqrt{7} + 2}{\sqrt{7} + 2}$
:::

::: etape Développer le numérateur
- $\displaystyle 5(\sqrt{7} + 2) = 5\sqrt{7} + 10$
:::

::: etape Développer le dénominateur
$$
\begin{aligned}
(\sqrt{7} - 2)(\sqrt{7} + 2) &= (\sqrt{7})^2 - 2^2 \\
&= 7 - 4 \\
&= 3
\end{aligned}
$$
:::

::: etape Résultat final
- $\displaystyle \frac{5\sqrt{7} + 10}{3}$
:::

::: resultat
$$\frac{5}{\sqrt{7} - 2} = \frac{5\sqrt{7} + 10}{3}$$
:::

## Question 5 : Rationaliser $\displaystyle \frac{\sqrt{6}}{\sqrt{2}}$

::: methode
Quotient de racines
:::

::: etape Utiliser la propriété du quotient
$$
\begin{aligned}
\frac{\sqrt{6}}{\sqrt{2}} &= \sqrt{\frac{6}{2}} \\
&= \sqrt{3}
\end{aligned}
$$
:::

::: methode alternative
Rationalisation classique

$$
\begin{aligned}
\frac{\sqrt{6}}{\sqrt{2}} \times \frac{\sqrt{2}}{\sqrt{2}} &= \frac{\sqrt{12}}{2} \\
&= \frac{2\sqrt{3}}{2} \\
&= \sqrt{3}
\end{aligned}
$$
:::

::: resultat
$$\frac{\sqrt{6}}{\sqrt{2}} = \sqrt{3}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$
2. $\displaystyle \frac{3}{\sqrt{5}} = \frac{3\sqrt{5}}{5}$
3. $\displaystyle \frac{2}{\sqrt{3} + 1} = \sqrt{3} - 1$
4. $\displaystyle \frac{5}{\sqrt{7} - 2} = \frac{5\sqrt{7} + 10}{3}$
5. $\displaystyle \frac{\sqrt{6}}{\sqrt{2}} = \sqrt{3}$

=== Maîtrise - Racines - Expressions Très Complexes
Id: 1899
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes nécessitant une maîtrise complète des techniques de simplification.

1. Simplifier $\displaystyle \frac{\sqrt{72} + \sqrt{128}}{\sqrt{8}} - \sqrt{2}$
2. Simplifier $\displaystyle (\sqrt{8} + \sqrt{18})(\sqrt{8} - \sqrt{18})$
3. Simplifier $\displaystyle \frac{(\sqrt{50} - \sqrt{32})^2}{\sqrt{2}}$
4. Simplifier $\displaystyle \sqrt{48} \times \sqrt{27} - \sqrt{162} + \sqrt{24} \times \sqrt{54}$
5. Simplifier $\displaystyle \frac{\sqrt{180} + \sqrt{245} - \sqrt{80}}{\sqrt{5}}$
6. Simplifier $\displaystyle (\sqrt{75} + \sqrt{12})^2 - (\sqrt{75} - \sqrt{12})^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \frac{\sqrt{72} + \sqrt{128}}{\sqrt{8}} - \sqrt{2}$

::: methode
Simplification par étapes multiples
:::

::: etape Simplifier les racines au numérateur
- $\displaystyle \sqrt{72} = \sqrt{36 \times 2} = 6\sqrt{2}$
- $\displaystyle \sqrt{128} = \sqrt{64 \times 2} = 8\sqrt{2}$
- Numérateur : $\displaystyle 6\sqrt{2} + 8\sqrt{2} = 14\sqrt{2}$
:::

::: etape Simplifier le dénominateur
- $\displaystyle \sqrt{8} = \sqrt{4 \times 2} = 2\sqrt{2}$
:::

::: etape Simplifier la fraction
- $\displaystyle \frac{14\sqrt{2}}{2\sqrt{2}} = \frac{14}{2} = 7$
:::

::: etape Soustraire $\displaystyle \sqrt{2}$
- $\displaystyle 7 - \sqrt{2}$
:::

::: resultat
$$\frac{\sqrt{72} + \sqrt{128}}{\sqrt{8}} - \sqrt{2} = 7 - \sqrt{2}$$
:::

## Question 2 : Simplifier $\displaystyle (\sqrt{8} + \sqrt{18})(\sqrt{8} - \sqrt{18})$

::: methode
Identité remarquable $\displaystyle (a+b)(a-b) = a^2 - b^2$
:::

::: etape Appliquer l'identité remarquable
$$
\begin{aligned}
(\sqrt{8} + \sqrt{18})(\sqrt{8} - \sqrt{18}) &= (\sqrt{8})^2 - (\sqrt{18})^2 \\
&= 8 - 18 \\
&= -10
\end{aligned}
$$
:::

::: methode alternative
Simplification puis calcul

- $\sqrt{8} = 2\sqrt{2}$ et $\sqrt{18} = 3\sqrt{2}$

$$
\begin{aligned}
(2\sqrt{2} + 3\sqrt{2})(2\sqrt{2} - 3\sqrt{2}) &= (5\sqrt{2})(-\sqrt{2}) \\
&= -5 \times 2 \\
&= -10
\end{aligned}
$$
:::

::: resultat
$$(\sqrt{8} + \sqrt{18})(\sqrt{8} - \sqrt{18}) = -10$$
:::

## Question 3 : Simplifier $\displaystyle \frac{(\sqrt{50} - \sqrt{32})^2}{\sqrt{2}}$

::: methode
Développement d'un carré puis simplification
:::

::: etape Simplifier $\sqrt{50}$ et $\sqrt{32}$
- $\displaystyle \sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$
- $\displaystyle \sqrt{32} = \sqrt{16 \times 2} = 4\sqrt{2}$
:::

::: etape Calculer la différence
$$
\begin{aligned}
\sqrt{50} - \sqrt{32} &= 5\sqrt{2} - 4\sqrt{2} \\
&= \sqrt{2}
\end{aligned}
$$
:::

::: etape Élever au carré
- $\displaystyle (\sqrt{2})^2 = 2$
:::

::: etape Diviser par $\displaystyle \sqrt{2}$
$$
\begin{aligned}
\frac{2}{\sqrt{2}} &= \frac{2}{\sqrt{2}} \times \frac{\sqrt{2}}{\sqrt{2}} \\
&= \frac{2\sqrt{2}}{2} \\
&= \sqrt{2}
\end{aligned}
$$
:::

::: resultat
$$\frac{(\sqrt{50} - \sqrt{32})^2}{\sqrt{2}} = \sqrt{2}$$
:::

## Question 4 : Simplifier $\displaystyle \sqrt{48} \times \sqrt{27} - \sqrt{162} + \sqrt{24} \times \sqrt{54}$

::: methode
Produits de racines puis simplification
:::

::: rappel
Propriété $\sqrt{a} \times \sqrt{b} = \sqrt{a \times b}$ (avec $a \geq 0, b \geq 0$)
:::

::: etape Calculer $\displaystyle \sqrt{48} \times \sqrt{27}$
$$
\begin{aligned}
\sqrt{48} \times \sqrt{27} &= \sqrt{48 \times 27} \\
&= \sqrt{1296}
\end{aligned}
$$

- $\sqrt{1296} = 36$ (car $36^2 = 1296$)
:::

::: etape Simplifier $\displaystyle \sqrt{162}$
- $\displaystyle 162 = 81 \times 2 = 9^2 \times 2$
- $\displaystyle \sqrt{162} = 9\sqrt{2}$
:::

::: etape Calculer $\displaystyle \sqrt{24} \times \sqrt{54}$
$$
\begin{aligned}
\sqrt{24} \times \sqrt{54} &= \sqrt{24 \times 54} \\
&= \sqrt{1296}
\end{aligned}
$$

- $\displaystyle \sqrt{1296} = 36$
:::

::: etape Combiner tous les termes
$$
\begin{aligned}
\sqrt{48} \times \sqrt{27} - \sqrt{162} + \sqrt{24} \times \sqrt{54} &= 36 - 9\sqrt{2} + 36 \\
&= 72 - 9\sqrt{2}
\end{aligned}
$$
:::

::: resultat
$$\sqrt{48} \times \sqrt{27} - \sqrt{162} + \sqrt{24} \times \sqrt{54} = 72 - 9\sqrt{2}$$
:::

## Question 5 : Simplifier $\displaystyle \frac{\sqrt{180} + \sqrt{245} - \sqrt{80}}{\sqrt{5}}$

::: methode
Simplification du numérateur puis division
:::

::: etape Simplifier $\displaystyle \sqrt{180}$
- $\displaystyle 180 = 36 \times 5 = 6^2 \times 5$
- $\displaystyle \sqrt{180} = 6\sqrt{5}$
:::

::: etape Simplifier $\displaystyle \sqrt{245}$
- $\displaystyle 245 = 49 \times 5 = 7^2 \times 5$
- $\displaystyle \sqrt{245} = 7\sqrt{5}$
:::

::: etape Simplifier $\displaystyle \sqrt{80}$
- $\displaystyle 80 = 16 \times 5 = 4^2 \times 5$
- $\displaystyle \sqrt{80} = 4\sqrt{5}$
:::

::: etape Calculer le numérateur
$$
\begin{aligned}
\sqrt{180} + \sqrt{245} - \sqrt{80} &= 6\sqrt{5} + 7\sqrt{5} - 4\sqrt{5} \\
&= (6 + 7 - 4)\sqrt{5} \\
&= 9\sqrt{5}
\end{aligned}
$$
:::

::: etape Diviser par $\displaystyle \sqrt{5}$
- $\displaystyle \frac{9\sqrt{5}}{\sqrt{5}} = 9$
:::

::: resultat
$$\frac{\sqrt{180} + \sqrt{245} - \sqrt{80}}{\sqrt{5}} = 9$$
:::

## Question 6 : Simplifier $\displaystyle (\sqrt{75} + \sqrt{12})^2 - (\sqrt{75} - \sqrt{12})^2$

::: methode
Identité remarquable $\displaystyle a^2 - b^2 = (a+b)(a-b)$
:::

::: etape Poser $a = \sqrt{75} + \sqrt{12}$ et $b = \sqrt{75} - \sqrt{12}$
- Formule : $\displaystyle a^2 - b^2 = (a+b)(a-b)$
:::

::: etape Calculer $\displaystyle a + b$
$$
\begin{aligned}
a + b &= (\sqrt{75} + \sqrt{12}) + (\sqrt{75} - \sqrt{12}) \\
&= 2\sqrt{75}
\end{aligned}
$$
:::

::: etape Calculer $\displaystyle a - b$
$$
\begin{aligned}

## Question 1 : Démontrer que $\displaystyle \frac{1}{\sqrt{2} - 1} = \sqrt{2} + 1$

::: etape Développer le dénominateur
$$
\begin{aligned}
(\sqrt{2} - 1)(\sqrt{2} + 1) &= (\sqrt{2})^2 - 1^2 \\
&= 2 - 1 \\
&= 1
\end{aligned}

Simplification par étapes

## Question 4 : Calculer $\displaystyle (\sqrt{5} + \sqrt{3})(\sqrt{5} - \sqrt{3})$ puis en déduire la valeur de $\displaystyle \frac{1}{\sqrt{5} + \sqrt{3}}$ sous forme rationalisée.

\end{aligned}

::: etape Simplifier

- Dénominateur : $2$ (d'après l'étape 1)
- $\displaystyle \frac{1}{\sqrt{5} + \sqrt{3}} = \frac{\sqrt{5} - \sqrt{3}}{2}$
