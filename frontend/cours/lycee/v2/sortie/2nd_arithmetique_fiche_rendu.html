📚 Objectif pédagogique : retenir l’essentiel : multiples et diviseurs, parité, nombres premiers et décomposition. Programme de Seconde.

I. Multiples, diviseurs, parité

$\displaystyle a$ multiple de $\displaystyle b$ $\displaystyle \iff$ $\displaystyle a = k \times b$ ($\displaystyle k$ entier)

• La somme de deux multiples de $\displaystyle a$ est un multiple de $\displaystyle a$ : $\displaystyle ka + k'a = (k + k')a$.

• Pair : $\displaystyle n = 2k$ ; impair : $\displaystyle n = 2k + 1$ ; le carré d’un impair est impair.

• Divisible par $\displaystyle 3$ ou $\displaystyle 9$ : la somme des chiffres l’est.

II. Nombres premiers

1️⃣ Premier : exactement deux diviseurs, $\displaystyle 1$ et lui-même.

2️⃣ Test : diviser par les premiers $\displaystyle p$ tels que $\displaystyle p^2 \le n$.

3️⃣ Décomposition unique en facteurs premiers :

4️⃣ Fraction irréductible : $\displaystyle \frac{84}{126} = \frac{2^2 \times 3 \times 7}{2 \times 3^2 \times 7} = \frac{2}{3}$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Dire que $\displaystyle 1$ est premier.

2️⃣ Confondre « multiple de » et « diviseur de » : $\displaystyle 4$ divise $\displaystyle 36$, $\displaystyle 36$ est un multiple de $\displaystyle 4$.

3️⃣ Croire qu’un exemple démontre une propriété générale : il faut écrire $\displaystyle n = 2k + 1$.

4️⃣ Laisser un facteur non premier dans une décomposition : $\displaystyle 360 = 2^3 \times 3^2 \times 5$, pas $\displaystyle 8 \times 45$.

🏆 Réflexe : « pour tout entier » → j’écris $\displaystyle 2k$ ou $\displaystyle 2k + 1$ ; « simplifier » ou « partager équitablement » → je décompose en facteurs premiers.
