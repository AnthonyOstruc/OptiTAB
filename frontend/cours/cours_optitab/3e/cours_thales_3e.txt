    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Le théorème de Thalès</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Les deux configurations</h3>
        <p style="font-size:1em;">Le théorème de Thalès s'utilise lorsque <strong>deux droites sécantes en $\displaystyle A$</strong> sont coupées par <strong>deux droites parallèles</strong>. On rencontre deux situations :</p>
        <p style="font-size:1em;"><strong>1) La configuration « emboîtée » :</strong> le point $\displaystyle M$ est sur le segment $\displaystyle [AB]$ et le point $\displaystyle N$ est sur le segment $\displaystyle [AC]$. Le petit triangle $\displaystyle AMN$ est « emboîté » dans le grand triangle $\displaystyle ABC$.</p>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>2) La configuration « papillon » :</strong> le point $\displaystyle A$ est situé <strong>entre</strong> $\displaystyle M$ et $\displaystyle B$, et entre $\displaystyle N$ et $\displaystyle C$. Les deux triangles se touchent uniquement au point $\displaystyle A$, comme les ailes d'un papillon.</p>
        [IMAGE_2]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Énoncé du théorème</h3>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Théorème de Thalès</strong></p>
            <p style="margin:8px 0 0 0;">Si :</p>
            <p style="margin:4px 0 0 0;">• les points $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ sont alignés ;</p>
            <p style="margin:4px 0 0 0;">• les points $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ sont alignés ;</p>
            <p style="margin:4px 0 0 0;">• les droites $\displaystyle (MN)$ et $\displaystyle (BC)$ sont <strong>parallèles</strong> ;</p>
            <p style="margin:8px 0 0 0;">alors :</p>
        </div>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle \frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$
        </div>
        <p style="font-size:1em;">Les longueurs utilisées sont toutes <strong>positives</strong>. Ce théorème fonctionne de la même façon dans la configuration emboîtée et dans la configuration papillon.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À retenir :</strong> dans chaque rapport, le numérateur et le dénominateur sont des <strong>côtés qui se correspondent</strong> : tous les côtés du <strong>petit</strong> triangle $\displaystyle AMN$ sont au numérateur, tous les côtés du <strong>grand</strong> triangle $\displaystyle ABC$ sont au dénominateur. On ne mélange jamais les deux !
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calculer une longueur avec le théorème de Thalès</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">La méthode en 4 étapes</h3>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>① Vérifier les hypothèses :</strong> citer les alignements et le parallélisme donnés dans l'énoncé.</p>
            <p style="margin:8px 0 0 0;"><strong>② Citer le théorème</strong> et écrire l'égalité des trois rapports.</p>
            <p style="margin:8px 0 0 0;"><strong>③ Choisir le rapport</strong> qui contient la longueur cherchée et un rapport dont on connaît les deux longueurs.</p>
            <p style="margin:8px 0 0 0;"><strong>④ Résoudre avec le produit en croix</strong> et conclure avec l'unité.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple rédigé n°1 (configuration emboîtée)</h3>
        <p style="font-size:1em;"><em>$\displaystyle M$ est sur $\displaystyle [AB]$, $\displaystyle N$ est sur $\displaystyle [AC]$ et $\displaystyle (MN) \parallel (BC)$. On donne $\displaystyle AM = 3$ cm, $\displaystyle AB = 5$ cm et $\displaystyle AC = 7$ cm. Calculer $\displaystyle AN$.</em></p>
        <p style="font-size:1em;"><strong>Rédaction modèle :</strong></p>
        <p style="font-size:1em;">Les points $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ sont alignés, les points $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ sont alignés et $\displaystyle (MN) \parallel (BC)$.</p>
        <p style="font-size:1em;">D'après le <strong>théorème de Thalès</strong> :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle \frac{AM}{AB} = \frac{AN}{AC}$ &nbsp; donc &nbsp; $\displaystyle \frac{3}{5} = \frac{AN}{7}$
        </div>
        <p style="font-size:1em;">Avec le <strong>produit en croix</strong> :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle AN = \frac{3 \times 7}{5} = \frac{21}{5} = 4{,}2 \text{ cm}$
        </div>
        <p style="font-size:1em;">On vérifie la cohérence : $\displaystyle AN = 4{,}2$ cm est bien <strong>plus petit</strong> que $\displaystyle AC = 7$ cm, ce qui est normal puisque le triangle $\displaystyle AMN$ est une réduction du triangle $\displaystyle ABC$.</p>
    </div>

    <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
        <strong>⚠️ Attention — l'erreur la plus fréquente :</strong> ne pas confondre $\displaystyle AM$ et $\displaystyle MB$ ! Le théorème utilise les longueurs <strong>à partir du point $\displaystyle A$</strong> (le sommet commun). Si l'énoncé donne $\displaystyle MB$, il faut d'abord reconstituer le côté entier : si $\displaystyle M$ est entre $\displaystyle A$ et $\displaystyle B$, alors $\displaystyle AB = AM + MB$. La longueur $\displaystyle MB$ ne doit <strong>jamais</strong> apparaître dans les rapports de Thalès.
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple rédigé n°2 (configuration papillon)</h3>
        <p style="font-size:1em;"><em>Les points $\displaystyle M$, $\displaystyle A$, $\displaystyle B$ sont alignés dans cet ordre, ainsi que $\displaystyle N$, $\displaystyle A$, $\displaystyle C$. On a $\displaystyle (MN) \parallel (BC)$, $\displaystyle AM = 2$ cm, $\displaystyle AB = 6$ cm et $\displaystyle AC = 9$ cm. Calculer $\displaystyle AN$.</em></p>
        <p style="font-size:1em;">Les alignements et le parallélisme sont donnés : le théorème de Thalès s'applique aussi dans la configuration papillon, avec les mêmes rapports :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle \frac{AM}{AB} = \frac{AN}{AC}$ &nbsp; donc &nbsp; $\displaystyle \frac{2}{6} = \frac{AN}{9}$ &nbsp; d'où &nbsp; $\displaystyle AN = \frac{2 \times 9}{6} = 3 \text{ cm}$
        </div>
        <p style="font-size:1em;">Les longueurs restent positives : le fait que $\displaystyle M$ et $\displaystyle N$ soient « de l'autre côté » de $\displaystyle A$ ne change rien aux calculs.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. La réciproque du théorème de Thalès</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démontrer que deux droites sont parallèles</h3>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Réciproque du théorème de Thalès</strong></p>
            <p style="margin:8px 0 0 0;">Si :</p>
            <p style="margin:4px 0 0 0;">• les points $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ sont alignés <strong>dans le même ordre</strong> que les points $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ ;</p>
            <p style="margin:4px 0 0 0;">• $\displaystyle \dfrac{AM}{AB} = \dfrac{AN}{AC}$ ;</p>
            <p style="margin:8px 0 0 0;">alors les droites $\displaystyle (MN)$ et $\displaystyle (BC)$ sont <strong>parallèles</strong>.</p>
        </div>
        [IMAGE_3]
        <p style="font-size:1em;"><strong>Exemple rédigé :</strong> <em>$\displaystyle M$ est sur $\displaystyle [AB]$, $\displaystyle N$ est sur $\displaystyle [AC]$, avec $\displaystyle AM = 4$ cm, $\displaystyle AB = 10$ cm, $\displaystyle AN = 6$ cm et $\displaystyle AC = 15$ cm. Montrer que $\displaystyle (MN) \parallel (BC)$.</em></p>
        <p style="font-size:1em;">On calcule séparément les deux rapports :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle \frac{AM}{AB} = \frac{4}{10} = \frac{2}{5}$ &nbsp; et &nbsp; $\displaystyle \frac{AN}{AC} = \frac{6}{15} = \frac{2}{5}$
        </div>
        <p style="font-size:1em;">Les rapports sont <strong>égaux</strong> et les points $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ et $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ sont alignés dans le même ordre. D'après la <strong>réciproque du théorème de Thalès</strong>, les droites $\displaystyle (MN)$ et $\displaystyle (BC)$ sont parallèles.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Montrer que deux droites ne sont PAS parallèles</h3>
        <p style="font-size:1em;">Si les rapports $\displaystyle \dfrac{AM}{AB}$ et $\displaystyle \dfrac{AN}{AC}$ sont <strong>différents</strong>, alors les droites ne sont pas parallèles : si elles l'étaient, le théorème de Thalès imposerait l'égalité des rapports.</p>
        <p style="font-size:1em;"><strong>Exemple :</strong> $\displaystyle AM = 2$, $\displaystyle AB = 5$, $\displaystyle AN = 3$, $\displaystyle AC = 7$. On compare avec les <strong>produits en croix</strong> :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle 2 \times 7 = 14$ &nbsp; et &nbsp; $\displaystyle 3 \times 5 = 15$ &nbsp; or &nbsp; $\displaystyle 14 \neq 15$ &nbsp; donc &nbsp; $\displaystyle \frac{2}{5} \neq \frac{3}{7}$
        </div>
        <p style="font-size:1em;">Les droites $\displaystyle (MN)$ et $\displaystyle (BC)$ ne sont donc <strong>pas parallèles</strong>.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> pour comparer deux rapports, utilisez les <strong>produits en croix</strong> ou des fractions exactes, <strong>jamais des valeurs arrondies</strong> : deux quotients arrondis peuvent sembler égaux alors qu'ils ne le sont pas. Et n'oubliez pas de vérifier que les points sont alignés <strong>dans le même ordre</strong> avant d'appliquer la réciproque.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les triangles semblables</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et reconnaissance</h3>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> deux triangles sont <strong>semblables</strong> lorsque leurs angles sont <strong>égaux deux à deux</strong>.</p>
        </div>
        <p style="font-size:1em;">Comme la somme des angles d'un triangle vaut toujours $\displaystyle 180^\circ$, il suffit de vérifier que <strong>deux paires d'angles</strong> sont égales : la troisième l'est automatiquement.</p>
        [IMAGE_4]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À retenir :</strong> pour bien associer les sommets, on fait correspondre les <strong>angles égaux</strong> : le sommet de l'angle rouge avec le sommet de l'angle rouge, etc. Les <strong>côtés correspondants</strong> sont alors les côtés opposés aux angles égaux.
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Côtés, périmètres et aires</h3>
        <p style="font-size:1em;">Si deux triangles sont semblables, leurs côtés correspondants sont <strong>proportionnels</strong> : on passe du petit au grand en multipliant toutes les longueurs par un même nombre $\displaystyle k > 0$, appelé <strong>coefficient d'agrandissement</strong> (ou de réduction si $\displaystyle k < 1$).</p>
        <div style="overflow-x:auto; margin:15px 0;">
<table style="width:100%; min-width:300px; border-collapse:collapse; margin:0; border:2px solid #3498db; background:#ffffff;">
            <thead>
                <tr style="background:#3498db;">
                    <th style="border:1px solid #2b7bb9; padding:10px 12px; text-align:center; vertical-align:middle; background:#3498db; color:#ffffff; font-weight:700;">Grandeur</th>
                    <th style="border:1px solid #2b7bb9; padding:10px 12px; text-align:center; vertical-align:middle; background:#3498db; color:#ffffff; font-weight:700;">Multipliée par</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f4f8fc;">
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">Longueurs des côtés</td>
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">$\displaystyle k$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">Périmètre</td>
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">$\displaystyle k$</td>
                </tr>
                <tr style="background:#f4f8fc;">
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">Aire</td>
                    <td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">$\displaystyle k^2$</td>
                </tr>
            </tbody>
        </table>
</div>
        <p style="font-size:1em;"><strong>Exemple :</strong> si $\displaystyle k = 3$, les côtés et le périmètre sont multipliés par $\displaystyle 3$, mais l'aire est multipliée par $\displaystyle 3^2 = 9$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> l'aire n'est <strong>pas</strong> multipliée par $\displaystyle k$ mais par $\displaystyle k^2$. C'est une erreur très fréquente au brevet !
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Applications concrètes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Mesurer une hauteur inaccessible grâce aux ombres</h3>
        <p style="font-size:1em;">Le théorème de Thalès permet de mesurer des longueurs <strong>inaccessibles</strong> : hauteur d'un arbre, d'un immeuble, largeur d'une rivière… C'est d'ailleurs ainsi que Thalès aurait mesuré la hauteur de la grande pyramide d'Égypte !</p>
        [IMAGE_5]
        <p style="font-size:1em;"><strong>Exemple rédigé :</strong> <em>un bâton vertical de $\displaystyle 1$ m projette une ombre de $\displaystyle 1{,}5$ m. Au même instant, un arbre vertical projette une ombre de $\displaystyle 9$ m sur le même sol horizontal. Calculer la hauteur $\displaystyle h$ de l'arbre.</em></p>
        <p style="font-size:1em;">Les rayons du soleil sont parallèles, le bâton et l'arbre sont perpendiculaires au sol : les deux triangles formés (objet, ombre, rayon) sont <strong>semblables</strong>. Les longueurs sont donc proportionnelles :</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle \frac{h}{1} = \frac{9}{1{,}5}$ &nbsp; donc &nbsp; $\displaystyle h = \frac{9 \times 1}{1{,}5} = 6 \text{ m}$
        </div>
        <p style="font-size:1em;">L'arbre mesure $\displaystyle 6$ mètres.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Comment rédiger au brevet ?</h3>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Check-list de rédaction :</strong></p>
            <p style="margin:6px 0 0 0;">✔️ Je cite les <strong>alignements</strong> des points (et leur ordre pour la réciproque).</p>
            <p style="margin:6px 0 0 0;">✔️ Je cite le <strong>parallélisme</strong> (donné ou démontré).</p>
            <p style="margin:6px 0 0 0;">✔️ Je nomme le <strong>théorème</strong> utilisé (Thalès ou sa réciproque).</p>
            <p style="margin:6px 0 0 0;">✔️ J'écris l'<strong>égalité des rapports</strong>, puis je remplace par les valeurs.</p>
            <p style="margin:6px 0 0 0;">✔️ Je résous avec le <strong>produit en croix</strong>.</p>
            <p style="margin:6px 0 0 0;">✔️ Je <strong>conclus</strong> par une phrase, avec l'<strong>unité</strong>.</p>
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L'essentiel :</strong> Thalès = <strong>alignements + parallèles → rapports égaux</strong> (pour calculer une longueur). Réciproque = <strong>alignements dans le même ordre + rapports égaux → parallèles</strong>. Triangles semblables = <strong>angles égaux → côtés proportionnels</strong>, périmètres $\displaystyle \times\, k$ et aires $\displaystyle \times\, k^2$. Retrouvez la fiche de synthèse de ce chapitre dans l'onglet Fiches !</p>
    </div>
