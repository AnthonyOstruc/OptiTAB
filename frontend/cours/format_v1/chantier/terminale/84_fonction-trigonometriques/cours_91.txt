Titre: Fonctions sinus et cosinus

<!-- optitab:1 -->
::: objectifs
Connaître les dérivées, les variations et les courbes des fonctions sinus et cosinus ; résoudre une équation ou une inéquation trigonométrique sur un intervalle en s’aidant du cercle ; étudier une fonction trigonométrique en exploitant sa périodicité et sa parité.
:::

## I. Rappels : le cercle trigonométrique

::: definition Cosinus et sinus d’un réel
Dans un repère orthonormé $(O\,;I,J)$, le cercle trigonométrique est le cercle de centre $O$ et de rayon $1$, parcouru dans le sens direct. À tout réel $x$ correspond un unique point $M(x)$ de ce cercle : $\cos x$ est son **abscisse** et $\sin x$ son **ordonnée**.
:::

[IMAGE_3]

::: propriete
Pour tout réel $x$ :

$$\cos^2 x + \sin^2 x = 1$$

$$-1 \le \cos x \le 1 \quad \text{et} \quad -1 \le \sin x \le 1$$
:::

| $x$ | $\cos x$ | $\sin x$ |
|---|---|---|
| $0$ | $1$ | $0$ |
| $\dfrac{\pi}{6}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ |
| $\dfrac{\pi}{4}$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ |
| $\dfrac{\pi}{3}$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ |
| $\dfrac{\pi}{2}$ | $0$ | $1$ |
| $\pi$ | $-1$ | $0$ |

## II. Périodicité, parité et courbes

::: propriete
Pour tout réel $x$ :
- $\cos(x + 2\pi) = \cos x$ et $\sin(x + 2\pi) = \sin x$ : les fonctions $\cos$ et $\sin$ sont **périodiques de période $2\pi$** ;
- $\cos(-x) = \cos x$ : la fonction $\cos$ est **paire**, sa courbe est symétrique par rapport à l’axe des ordonnées ;
- $\sin(-x) = -\sin x$ : la fonction $\sin$ est **impaire**, sa courbe est symétrique par rapport à l’origine.
:::

[IMAGE_1]

::: methode Réduire l’intervalle d’étude
- Une fonction $f$ est périodique de période $T$ si, pour tout $x$, $f(x + T) = f(x)$ : on l’étudie sur un intervalle de longueur $T$, puis on complète la courbe par translations.
- Si de plus $f$ est paire ou impaire, on peut se limiter à $\left[0\,;\frac{T}{2}\right]$ et compléter par symétrie.
:::

::: exemple
Pour $f(x) = \cos(2x)$ : $f(x + \pi) = \cos(2x + 2\pi) = \cos(2x) = f(x)$, donc $f$ est périodique de période $\pi$ ; et $f(-x) = \cos(-2x) = \cos(2x) = f(x)$, donc $f$ est paire. Il suffit de l’étudier sur $\left[0\,;\frac{\pi}{2}\right]$.
:::

## III. Dérivées et variations

::: propriete Dérivées
Les fonctions $\sin$ et $\cos$ sont dérivables sur $\mathbb{R}$ et, pour tout réel $x$ :

$$\sin'(x) = \cos x \qquad \cos'(x) = -\sin x$$

Plus généralement, pour tous réels $a$ et $b$ :

$$\big(\sin(ax + b)\big)' = a\cos(ax + b)$$

$$\big(\cos(ax + b)\big)' = -a\sin(ax + b)$$
:::

[IMAGE_2]

::: propriete Une limite remarquable
Le nombre dérivé de $\sin$ en $0$ vaut $\cos 0 = 1$. Comme $\frac{\sin x}{x} = \frac{\sin x - \sin 0}{x - 0}$ est un taux d’accroissement :

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
:::

::: exemple
- $\big(\cos(3x - 1)\big)' = -3\sin(3x - 1)$.
- Forme $uv$ : $(x\sin x)' = 1 \times \sin x + x \times \cos x$, donc $(x\sin x)' = \sin x + x\cos x$.
- $\left(\sin^2 x\right)' = 2\sin x \times \sin'(x) = 2\sin x\cos x$ (forme $u^2$, de dérivée $2uu'$).
:::

::: propriete Variations sur $[-\pi\,;\pi]$
- $\cos'(x) = -\sin x$ est positive sur $[-\pi\,;0]$ et négative sur $[0\,;\pi]$.
- $\sin'(x) = \cos x$ est positive sur $\left[-\frac{\pi}{2}\,;\frac{\pi}{2}\right]$ et négative ailleurs sur $[-\pi\,;\pi]$.
:::

::: tableau Variations de $\cos$ sur $[-\pi\,;\pi]$
x : -\pi, 0, \pi
-\sin x : z, +, z, -, z
\cos x : -/-1, +/1, -/-1
:::

::: tableau Variations de $\sin$ sur $[-\pi\,;\pi]$
x : -\pi, -\frac{\pi}{2}, \frac{\pi}{2}, \pi
\cos x : , -, z, +, z, -,
\sin x : +/0, -/-1, +/1, -/0
:::

## IV. Équations et inéquations

::: propriete Équations $\cos x = \cos a$ et $\sin x = \sin a$
Pour tous réels $x$ et $a$ ($k$ désigne un entier relatif) :
- $\cos x = \cos a \iff x = a + 2k\pi$ ou $x = -a + 2k\pi$ ;
- $\sin x = \sin a \iff x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$.
:::

::: methode Résoudre $\cos x \ge a$ sur $[-\pi\,;\pi]$
1. Trouver un réel $\alpha$ de $[0\,;\pi]$ tel que $\cos \alpha = a$.
2. Sur le cercle, tracer la droite verticale d’équation $x = a$ : elle coupe le cercle aux points $M(\alpha)$ et $M(-\alpha)$.
3. Lire l’arc des points dont l’abscisse est supérieure ou égale à $a$, puis écrire l’intervalle correspondant.

Pour $\sin x \ge a$, on trace la droite horizontale d’équation $y = a$.
:::

::: exemple Résoudre $\cos x \ge \frac{1}{2}$ sur $[-\pi\,;\pi]$
On a $\cos\frac{\pi}{3} = \frac{1}{2}$. Les points du cercle d’abscisse supérieure ou égale à $\frac{1}{2}$ forment l’arc vert, qui va de $M\left(-\frac{\pi}{3}\right)$ à $M\left(\frac{\pi}{3}\right)$ :

$$S = \left[-\frac{\pi}{3}\,;\frac{\pi}{3}\right]$$
:::

[IMAGE_5]

::: attention
Sur un intervalle de longueur $2\pi$, une équation $\cos x = a$ avec $-1 \lt a \lt 1$ a **deux** solutions. On vérifie toujours que les solutions trouvées appartiennent à l’intervalle demandé.
:::

## V. Étude d’une fonction trigonométrique

::: exemple Étude de $f(x) = \sin(2x)$
- **Période et parité.** $f(x + \pi) = \sin(2x + 2\pi) = \sin(2x) = f(x)$ : $f$ est périodique de période $\pi$. De plus $f(-x) = \sin(-2x) = -f(x)$ : $f$ est impaire. On l’étudie sur $[0\,;\pi]$.
- **Dérivée.** $f'(x) = 2\cos(2x)$. Pour $x \in [0\,;\pi]$, on a $2x \in [0\,;2\pi]$, et $\cos(2x) \ge 0$ si et seulement si $2x \in \left[0\,;\frac{\pi}{2}\right] \cup \left[\frac{3\pi}{2}\,;2\pi\right]$, c’est-à-dire $x \in \left[0\,;\frac{\pi}{4}\right] \cup \left[\frac{3\pi}{4}\,;\pi\right]$.
:::

::: tableau Variations de $f$ sur $[0\,;\pi]$
x : 0, \frac{\pi}{4}, \frac{3\pi}{4}, \pi
f'(x) : , +, z, -, z, +,
f(x) : -/0, +/1, -/-1, +/0
:::

[IMAGE_4]

::: methode Limites avec sinus et cosinus
$\sin x$ et $\cos x$ n’ont pas de limite en $+\infty$ ; on les encadre entre $-1$ et $1$, puis on conclut par le théorème des gendarmes ou par comparaison. Par exemple, pour $x \gt 0$ :

$$-\frac{1}{x} \le \frac{\cos x}{x} \le \frac{1}{x}$$

Comme $\lim\limits_{x \to +\infty} \frac{1}{x} = 0$, on obtient $\lim\limits_{x \to +\infty} \frac{\cos x}{x} = 0$.
:::

::: retenir
- $\sin' = \cos$, $\cos' = -\sin$ ; $\big(\cos(ax + b)\big)' = -a\sin(ax + b)$ ; $\lim\limits_{x \to 0} \frac{\sin x}{x} = 1$.
- Avant d’étudier une fonction trigonométrique : période et parité, pour réduire l’intervalle d’étude.
- Équations et inéquations : on lit les solutions sur le cercle (deux solutions par tour en général).
- Limites en l’infini : encadrement par $-1$ et $1$, puis gendarmes ou comparaison.
- Fiche de synthèse dans l’onglet Fiches !
:::
