=== Découverte - Le dé équilibré
Id: 2338
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On lance un dé équilibré à six faces numérotées de $1$ à $6$.

1. Combien y a-t-il d'issues ? Sont-elles équiprobables ?
2. Calculer la probabilité d'obtenir un nombre pair.
3. Calculer la probabilité d'obtenir un multiple de $3$.
4. Calculer la probabilité d'obtenir un nombre premier.
5. Calculer la probabilité d'obtenir un nombre strictement supérieur à $4$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les issues

::: methode
Une issue est un résultat possible : on liste les faces du dé.
:::

::: etape Liste des issues
Les issues sont $1$, $2$, $3$, $4$, $5$ et $6$. Le dé est équilibré : chaque face a la même chance de sortir.
:::

::: resultat
Il y a $6$ issues, équiprobables.
:::

## Question 2 : Un nombre pair

::: methode
Équiprobabilité : $P = \dfrac{\text{issues favorables}}{\text{issues possibles}}$.
:::

::: etape Issues favorables
$2$, $4$ et $6$ : $3$ issues sur $6$.
:::

::: resultat
$P(\text{pair}) = \dfrac{3}{6} = \dfrac{1}{2}$
:::

## Question 3 : Un multiple de 3

::: etape Issues favorables
$3$ et $6$ : $2$ issues sur $6$.
:::

::: resultat
$P(\text{multiple de } 3) = \dfrac{2}{6} = \dfrac{1}{3}$
:::

## Question 4 : Un nombre premier

::: etape Issues favorables
Un nombre premier a exactement deux diviseurs : $2$, $3$ et $5$. Le nombre $1$ n'est pas premier (un seul diviseur).
:::

::: resultat
$P(\text{premier}) = \dfrac{3}{6} = \dfrac{1}{2}$
:::

## Question 5 : Strictement supérieur à 4

::: etape Issues favorables
« Strictement supérieur à $4$ » exclut le $4$ : $5$ et $6$.
:::

::: resultat
$P(\text{supérieur à } 4) = \dfrac{2}{6} = \dfrac{1}{3}$
:::

::: attention Erreur fréquente
Compter $1$ parmi les nombres premiers, ou inclure $4$ dans « strictement supérieur à $4$ ». Toujours écrire la liste des issues favorables avant de calculer.
:::

Solution:
<!-- optitab:1 -->
1. $6$ issues équiprobables
2. $\dfrac{1}{2}$
3. $\dfrac{1}{3}$
4. $\dfrac{1}{2}$
5. $\dfrac{1}{3}$

=== Découverte - Le sac de boules colorées
Id: 2339
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un sac contient $5$ boules rouges, $3$ bleues et $2$ vertes, indiscernables au toucher. On tire une boule au hasard.

[IMAGE_1]

1. Combien d'issues équiprobables l'expérience compte-t-elle ?
2. Calculer la probabilité de tirer une boule rouge.
3. Calculer la probabilité de tirer une boule bleue, puis celle de tirer une boule verte.
4. Calculer la probabilité de ne pas tirer une boule rouge.
5. Léo affirme : « Il y a trois couleurs, donc chaque couleur a une chance sur trois. » Expliquer son erreur.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les issues

::: methode
Chaque boule est une issue ; les boules étant indiscernables au toucher, elles ont toutes la même chance d'être tirées.
:::

::: etape Nombre de boules
$5 + 3 + 2 = 10$ boules.
:::

::: resultat
$10$ issues équiprobables.
:::

## Question 2 : Une boule rouge

::: methode
$$P = \frac{\text{issues favorables}}{\text{issues possibles}}$$
:::

::: etape Calcul
$5$ boules rouges sur $10$ boules : $\dfrac{5}{10}$.
:::

::: resultat
$P(\text{rouge}) = \dfrac{1}{2}$
:::

## Question 3 : Une boule bleue, une boule verte

::: etape Bleue
$3$ boules bleues sur $10$ : $\dfrac{3}{10}$.
:::

::: etape Verte
$2$ boules vertes sur $10$ : $\dfrac{2}{10} = \dfrac{1}{5}$.
:::

::: resultat
$P(\text{bleue}) = \dfrac{3}{10}$ et $P(\text{verte}) = \dfrac{1}{5}$
:::

## Question 4 : Ne pas tirer une rouge

::: methode
« Ne pas tirer une rouge » est l'événement contraire de « tirer une rouge ».
:::

::: etape Événement contraire
$$P(\text{non rouge}) = 1 - P(\text{rouge}) = 1 - \frac{1}{2} = \frac{1}{2}$$
:::

::: etape Contrôle
Les boules non rouges sont les $3 + 2 = 5$ bleues et vertes : $\dfrac{5}{10} = \dfrac{1}{2}$.
:::

::: resultat
$P(\text{non rouge}) = \dfrac{1}{2}$
:::

## Question 5 : L'erreur de Léo

::: etape Comparaison
D'après la question 2, $P(\text{rouge}) = \dfrac{1}{2}$, et non $\dfrac{1}{3}$.
:::

::: resultat
Les couleurs n'ont pas le même nombre de boules : ce sont les **boules** qui sont équiprobables, pas les couleurs.
:::

::: attention Erreur fréquente
Compter les catégories (couleurs) au lieu de compter les objets (boules).
:::

Solution:
<!-- optitab:1 -->
1. $10$ issues
2. $\dfrac{1}{2}$
3. $\dfrac{3}{10}$ et $\dfrac{1}{5}$
4. $\dfrac{1}{2}$
5. Les couleurs ne sont pas équiprobables : ce sont les boules qui le sont.

=== Découverte - Issues, événements et contraires
Id: 2340
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Douze cartes numérotées de $1$ à $12$ sont retournées et mélangées. On en tire une au hasard. On considère les événements :

- $A$ : « obtenir un nombre pair » ;
- $B$ : « obtenir un multiple de $5$ » ;
- $C$ : « obtenir un multiple de $3$ ».

1. Combien y a-t-il d'issues ? Lister les issues qui réalisent $A$, $B$ et $C$.
2. Calculer $P(A)$, $P(B)$ et $P(C)$.
3. Décrire l'événement contraire de $A$ et calculer sa probabilité.
4. Les événements $A$ et $B$ sont-ils incompatibles ? Et les événements $B$ et $C$ ?
5. Calculer la probabilité d'obtenir un multiple de $5$ ou un multiple de $3$.
6. Quelle est la probabilité d'obtenir $13$ ? D'obtenir un nombre inférieur ou égal à $12$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les issues

::: etape Issues de l'expérience
Les $12$ cartes sont équiprobables : issues $1$, $2$, …, $12$.
:::

::: etape Issues favorables
- $A$ : $2$, $4$, $6$, $8$, $10$, $12$ ($6$ issues) ;
- $B$ : $5$, $10$ ($2$ issues) ;
- $C$ : $3$, $6$, $9$, $12$ ($4$ issues).
:::

::: resultat
$12$ issues ; $A$ en compte $6$, $B$ en compte $2$, $C$ en compte $4$.
:::

## Question 2 : Les probabilités

::: methode
Équiprobabilité : favorables ÷ possibles, puis simplification.
:::

::: resultat
- $P(A) = \dfrac{6}{12} = \dfrac{1}{2}$
- $P(B) = \dfrac{2}{12} = \dfrac{1}{6}$
- $P(C) = \dfrac{4}{12} = \dfrac{1}{3}$
:::

## Question 3 : Le contraire de A

::: etape Description
Le contraire de « obtenir un nombre pair » est « obtenir un nombre impair » : $1$, $3$, $5$, $7$, $9$, $11$.
:::

::: etape Calcul
$$P(\text{non } A) = 1 - P(A) = 1 - \frac{1}{2} = \frac{1}{2}$$
:::

::: resultat
$P(\text{non } A) = \dfrac{1}{2}$
:::

## Question 4 : Incompatibles ?

::: methode
Deux événements sont incompatibles s'ils n'ont aucune issue commune.
:::

::: etape A et B
L'issue $10$ est paire et multiple de $5$ : $A$ et $B$ peuvent se réaliser en même temps.
:::

::: etape B et C
$B$ : $5$, $10$ ; $C$ : $3$, $6$, $9$, $12$. Aucune issue commune.
:::

::: resultat
$A$ et $B$ ne sont pas incompatibles ; $B$ et $C$ sont incompatibles.
:::

## Question 5 : B ou C

::: methode
$B$ et $C$ sont incompatibles : on peut additionner leurs probabilités.
:::

::: etape Calcul
$$P(B \text{ ou } C) = P(B) + P(C) = \frac{2}{12} + \frac{4}{12} = \frac{6}{12}$$
:::

::: resultat
$P(B \text{ ou } C) = \dfrac{1}{2}$
:::

## Question 6 : Impossible et certain

::: etape Obtenir 13
Aucune carte ne porte $13$ : aucune issue favorable, événement impossible.
:::

::: etape Inférieur ou égal à 12
Toutes les cartes conviennent : événement certain.
:::

::: resultat
$P(\text{obtenir } 13) = 0$ et $P(\text{inférieur ou égal à } 12) = 1$
:::

::: attention Erreur fréquente
Additionner $P(A) + P(B)$ alors que $A$ et $B$ ont l'issue $10$ en commun : elle serait comptée deux fois.
:::

Solution:
<!-- optitab:1 -->
1. $12$ issues ; $A$ : $2, 4, 6, 8, 10, 12$ ; $B$ : $5, 10$ ; $C$ : $3, 6, 9, 12$
2. $\dfrac{1}{2}$ ; $\dfrac{1}{6}$ ; $\dfrac{1}{3}$
3. « obtenir un nombre impair » : $\dfrac{1}{2}$
4. $A$ et $B$ : non (issue $10$) ; $B$ et $C$ : oui
5. $\dfrac{1}{2}$
6. $0$ (impossible) et $1$ (certain)

=== Découverte - Une roue à secteurs égaux
Id: 2341
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une roue est partagée en huit secteurs de même angle, numérotés de $1$ à $8$. On la fait tourner ; la flèche désigne un secteur au hasard.

[IMAGE_1]

1. Justifier que les huit secteurs ont la même probabilité d'être désignés.
2. Quelle est la probabilité d'obtenir le numéro $5$ ?
3. Quelle est la probabilité d'obtenir un multiple de $3$ ?
4. Quelle est la probabilité d'obtenir un nombre pair ?
5. Quelle est la probabilité d'obtenir un numéro inférieur ou égal à $6$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'équiprobabilité

::: etape Angle d'un secteur
Les $8$ secteurs se partagent le tour complet : $360° \div 8 = 45°$ chacun.
:::

::: resultat
Les secteurs ont tous le même angle ($45°$) : ils sont équiprobables, chacun de probabilité $\dfrac{1}{8}$.
:::

## Question 2 : Le numéro 5

::: etape Issues favorables
Un seul secteur porte le $5$.
:::

::: resultat
$P(5) = \dfrac{1}{8}$
:::

## Question 3 : Un multiple de 3

::: etape Issues favorables
$3$ et $6$ : $2$ secteurs sur $8$.
:::

::: resultat
$P(\text{multiple de } 3) = \dfrac{2}{8} = \dfrac{1}{4}$
:::

## Question 4 : Un nombre pair

::: etape Issues favorables
$2$, $4$, $6$ et $8$ (en vert) : $4$ secteurs sur $8$.
:::

[IMAGE_2]

::: resultat
$P(\text{pair}) = \dfrac{4}{8} = \dfrac{1}{2}$
:::

## Question 5 : Inférieur ou égal à 6

::: methode
Passer par le contraire est plus rapide : le contraire est « obtenir $7$ ou $8$ ».
:::

::: etape Calcul
$$P(\text{inférieur ou égal à } 6) = 1 - \frac{2}{8} = \frac{6}{8}$$
:::

::: resultat
$P(\text{inférieur ou égal à } 6) = \dfrac{3}{4}$
:::

::: retenir
Ce sont les angles **égaux** des secteurs qui justifient l'équiprobabilité. Sur une roue à secteurs inégaux, ce calcul serait faux.
:::

Solution:
<!-- optitab:1 -->
1. Même angle de $45°$ pour chaque secteur
2. $\dfrac{1}{8}$
3. $\dfrac{1}{4}$
4. $\dfrac{1}{2}$
5. $\dfrac{3}{4}$

=== Découverte - Deux pièces et un arbre
Id: 2342
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On lance deux pièces équilibrées l'une après l'autre et on note le côté obtenu : $P$ (pile) ou $F$ (face).

[IMAGE_1]

1. Recopier et compléter l'arbre avec les probabilités sur les branches.
2. Lister toutes les issues de l'expérience.
3. Quelle est la probabilité de chaque issue ?
4. Calculer la probabilité d'obtenir exactement une fois « face ».
5. Calculer la probabilité d'obtenir au moins une fois « face ».

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter l'arbre

::: etape Probabilités des branches
Chaque pièce est équilibrée : à chaque lancer, $P$ et $F$ ont chacun la probabilité $\dfrac{1}{2}$.
:::

[IMAGE_2]

::: resultat
Toutes les branches portent $\dfrac{1}{2}$.
:::

## Question 2 : Les issues

::: methode
Chaque chemin, de la racine à une extrémité, donne une issue (1er lancer, puis 2e).
:::

::: resultat
$4$ issues : $PP$, $PF$, $FP$, $FF$.
:::

## Question 3 : Probabilité d'une issue

::: etape Produit le long d'un chemin
$P(PF) = \dfrac{1}{2} \times \dfrac{1}{2} = \dfrac{1}{4}$, et de même pour chaque chemin.
:::

::: resultat
Chaque issue a pour probabilité $\dfrac{1}{4}$.
:::

## Question 4 : Exactement une fois « face »

::: etape Chemins favorables
$PF$ et $FP$ (en vert sur l'arbre).
:::

::: etape Somme des chemins
$$\frac{1}{4} + \frac{1}{4} = \frac{2}{4}$$
:::

::: resultat
$P(\text{exactement une face}) = \dfrac{1}{2}$
:::

## Question 5 : Au moins une fois « face »

::: methode
Le contraire de « au moins une face » est « aucune face », c'est-à-dire $PP$.
:::

::: etape Calcul
$$1 - P(PP) = 1 - \frac{1}{4}$$
:::

::: resultat
$P(\text{au moins une face}) = \dfrac{3}{4}$
:::

::: attention Erreur fréquente
Croire qu'il n'y a que trois issues (« deux piles », « deux faces », « un de chaque ») : $PF$ et $FP$ sont deux issues distinctes, l'ordre compte.
:::

Solution:
<!-- optitab:1 -->
1. Toutes les branches portent $\dfrac{1}{2}$.
2. $PP$, $PF$, $FP$, $FF$
3. $\dfrac{1}{4}$
4. $\dfrac{1}{2}$
5. $\dfrac{3}{4}$

=== Découverte - Fréquence observée et probabilité
Id: 2343
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Lina lance $100$ fois une pièce de monnaie et obtient $46$ fois « face ».

1. Calculer la fréquence de « face » dans cette série.
2. Quelle est la probabilité d'obtenir « face » avec une pièce équilibrée ?
3. Ce résultat prouve-t-il que la pièce est déséquilibrée ?
4. Lina recommence $100$ lancers. Obtiendra-t-elle encore $46$ « face » ?
5. Que se passe-t-il en général quand on augmente beaucoup le nombre de lancers ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La fréquence

::: methode
Fréquence $= \dfrac{\text{nombre de fois où l'événement est observé}}{\text{nombre total d'essais}}$.
:::

::: resultat
$f = \dfrac{46}{100} = 0{,}46$
:::

## Question 2 : La probabilité

::: etape Équiprobabilité
Une pièce équilibrée a deux issues équiprobables, pile et face : $1$ issue favorable sur $2$.
:::

::: resultat
$P(\text{face}) = \dfrac{1}{2} = 0{,}5$
:::

## Question 3 : Une preuve de déséquilibre ?

::: etape Écart
$0{,}5 - 0{,}46 = 0{,}04$. Sur seulement $100$ lancers, la fréquence fluctue naturellement autour de la probabilité.
:::

::: resultat
Non : un écart de $0{,}04$ sur $100$ lancers est tout à fait courant avec une pièce équilibrée.
:::

## Question 4 : Une nouvelle série

::: resultat
Pas forcément : la fréquence varie d'une série à l'autre (c'est le hasard), alors que la probabilité reste $0{,}5$.
:::

## Question 5 : Beaucoup de lancers

::: etape Ce que montre une simulation
Sur $2\,000$ lancers simulés, la fréquence de « face » varie beaucoup au début, puis se rapproche de $0{,}5$.
:::

[IMAGE_1]

::: resultat
Sur un grand nombre de lancers, la fréquence se stabilise autour de la probabilité $0{,}5$.
:::

::: retenir
Fréquence : observée, elle varie. Probabilité : théorique, elle est fixe. Plus il y a d'essais, plus la fréquence est une bonne estimation de la probabilité.
:::

Solution:
<!-- optitab:1 -->
1. $0{,}46$
2. $0{,}5$
3. Non, l'écart est normal sur $100$ lancers.
4. Pas forcément.
5. Elle se stabilise autour de $0{,}5$.

=== Découverte - Le jeu de 32 cartes
Id: 2344
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On tire une carte au hasard dans un jeu de $32$ cartes : $4$ couleurs (cœur et carreau sont rouges, pique et trèfle sont noirs) et, dans chaque couleur, $8$ cartes : $7$, $8$, $9$, $10$, valet, dame, roi, as.

1. Calculer la probabilité de tirer un cœur.
2. Calculer la probabilité de tirer un as.
3. Calculer la probabilité de tirer l'as de cœur.
4. Calculer la probabilité de tirer une figure (valet, dame ou roi).
5. Calculer la probabilité de tirer une carte rouge.

Étapes:
<!-- optitab:1 -->
## Question 1 : Un cœur

::: methode
Les $32$ cartes sont équiprobables : on compte les cartes favorables.
:::

::: etape Calcul
$8$ cœurs sur $32$ cartes.
:::

::: resultat
$P(\text{cœur}) = \dfrac{8}{32} = \dfrac{1}{4}$
:::

## Question 2 : Un as

::: etape Calcul
Un as par couleur : $4$ as sur $32$.
:::

::: resultat
$P(\text{as}) = \dfrac{4}{32} = \dfrac{1}{8}$
:::

## Question 3 : L'as de cœur

::: etape Calcul
Une seule carte est à la fois un as et un cœur.
:::

::: resultat
$P(\text{as de cœur}) = \dfrac{1}{32}$
:::

## Question 4 : Une figure

::: etape Nombre de figures
$3$ figures par couleur et $4$ couleurs : $3 \times 4 = 12$ figures.
:::

::: resultat
$P(\text{figure}) = \dfrac{12}{32} = \dfrac{3}{8}$
:::

## Question 5 : Une carte rouge

::: etape Nombre de cartes rouges
Cœurs et carreaux : $8 + 8 = 16$ cartes.
:::

::: resultat
$P(\text{rouge}) = \dfrac{16}{32} = \dfrac{1}{2}$
:::

::: attention Erreur fréquente
Compter l'as parmi les figures : au jeu de cartes, les figures sont seulement le valet, la dame et le roi.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{1}{4}$
2. $\dfrac{1}{8}$
3. $\dfrac{1}{32}$
4. $\dfrac{3}{8}$
5. $\dfrac{1}{2}$

=== Entraînement - La somme de deux dés
Id: 2345
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On lance deux dés équilibrés à six faces et on additionne les deux résultats. Le tableau à double entrée donne toutes les sommes possibles.

[IMAGE_1]

1. Combien de cases (issues équiprobables) le tableau compte-t-il ?
2. Calculer la probabilité d'obtenir une somme égale à $7$.
3. Calculer la probabilité d'obtenir une somme égale à $2$.
4. Calculer la probabilité d'obtenir une somme supérieure ou égale à $10$.
5. Les sommes de $2$ à $12$ sont-elles équiprobables ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le nombre d'issues

::: etape Lignes et colonnes
$6$ résultats pour le premier dé, $6$ pour le second : $6 \times 6$ cases.
:::

::: resultat
$36$ issues équiprobables (les dés sont équilibrés).
:::

## Question 2 : Somme égale à 7

::: methode
On colorie les cases favorables, puis on les compte.
:::

[IMAGE_2]

::: etape Cases favorables
$(1\,;6)$, $(2\,;5)$, $(3\,;4)$, $(4\,;3)$, $(5\,;2)$, $(6\,;1)$ : $6$ cases.
:::

::: resultat
$P(\text{somme } 7) = \dfrac{6}{36} = \dfrac{1}{6}$
:::

## Question 3 : Somme égale à 2

::: etape Cases favorables
Seule la case $(1\,;1)$ donne $2$.
:::

::: resultat
$P(\text{somme } 2) = \dfrac{1}{36}$
:::

## Question 4 : Somme supérieure ou égale à 10

[IMAGE_3]

::: etape Cases favorables
Somme $10$ : $3$ cases ; somme $11$ : $2$ cases ; somme $12$ : $1$ case. Total : $6$ cases.
:::

::: resultat
$P(\text{somme} \geqslant 10) = \dfrac{6}{36} = \dfrac{1}{6}$
:::

## Question 5 : Sommes équiprobables ?

::: etape Comparaison
La somme $7$ occupe $6$ cases, la somme $2$ une seule : $\dfrac{6}{36} \neq \dfrac{1}{36}$.
:::

::: resultat
Non : ce sont les $36$ cases (couples) qui sont équiprobables, pas les $11$ sommes.
:::

::: attention Erreur fréquente
Dire « il y a $11$ sommes possibles, donc chacune a la probabilité $\dfrac{1}{11}$ ».
:::

Solution:
<!-- optitab:1 -->
1. $36$
2. $\dfrac{1}{6}$
3. $\dfrac{1}{36}$
4. $\dfrac{1}{6}$
5. Non : la somme $7$ a $6$ cases, la somme $2$ une seule.

=== Entraînement - Deux tirages avec remise
Id: 2346
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un sac contient $3$ boules rouges ($R$) et $2$ boules bleues ($B$), indiscernables au toucher. On tire une boule, on note sa couleur, on la **remet** dans le sac, puis on tire une seconde boule.

[IMAGE_1]

1. Expliquer pourquoi les probabilités du second tirage sont les mêmes que celles du premier, puis compléter l'arbre.
2. Calculer la probabilité d'obtenir deux boules rouges.
3. Calculer la probabilité d'obtenir deux boules bleues.
4. Calculer la probabilité d'obtenir deux boules de couleurs différentes.
5. Vérifier que la somme des probabilités des quatre issues vaut $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter l'arbre

::: etape Le rôle de la remise
La boule est remise : au second tirage, le sac contient encore $3$ rouges et $2$ bleues sur $5$ boules.
:::

::: etape Probabilités des branches
À chaque tirage : $P(R) = \dfrac{3}{5}$ et $P(B) = \dfrac{2}{5}$.
:::

[IMAGE_2]

::: resultat
Les branches du second tirage portent $\dfrac{3}{5}$ (vers $R$) et $\dfrac{2}{5}$ (vers $B$).
:::

## Question 2 : Deux rouges

::: methode
On multiplie les probabilités le long du chemin $R$ puis $R$.
:::

::: resultat
$P(RR) = \dfrac{3}{5} \times \dfrac{3}{5} = \dfrac{9}{25}$
:::

## Question 3 : Deux bleues

::: resultat
$P(BB) = \dfrac{2}{5} \times \dfrac{2}{5} = \dfrac{4}{25}$
:::

## Question 4 : Couleurs différentes

::: etape Chemins favorables
$RB$ et $BR$ (en vert) :

$$P(RB) = \frac{3}{5} \times \frac{2}{5} = \frac{6}{25}$$

=== Entraînement - Retrouver le nombre de boules
Id: 2349
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un sac contient $6$ boules rouges et $b$ boules bleues, indiscernables au toucher. La probabilité de tirer une boule rouge est $\dfrac{2}{5}$.

1. Exprimer le nombre total de boules en fonction de $b$.
2. Écrire une équation traduisant l'énoncé.
3. Résoudre cette équation.
4. Vérifier le résultat.
5. Combien de boules rouges faudrait-il ajouter pour que la probabilité de tirer une rouge soit $\dfrac{1}{2}$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Nombre total de boules

::: resultat
Le sac contient $6 + b$ boules.
:::

## Question 2 : L'équation

::: etape Probabilité de rouge
$$P(\text{rouge}) = \frac{\text{rouges}}{\text{total}} = \frac{6}{6 + b}$$
:::

::: resultat
$\dfrac{6}{6 + b} = \dfrac{2}{5}$
:::

## Question 3 : Résolution

::: methode
Égalité de deux quotients : on utilise les produits en croix.
:::

::: etape Calcul
$$
\begin{aligned}
6 \times 5 &= 2 \times (6 + b) \\
30 &= 12 + 2b \\
18 &= 2b \\
b &= 9
\end{aligned}
$$
:::

::: resultat
Il y a $9$ boules bleues.
:::

## Question 4 : Vérification

::: resultat
$\dfrac{6}{6 + 9} = \dfrac{6}{15} = \dfrac{2}{5}$ : c'est bien la probabilité annoncée.
:::

## Question 5 : Ajouter des rouges

::: etape Raisonnement
Pour $P(\text{rouge}) = \dfrac{1}{2}$, il faut autant de rouges que de bleues : $9$ rouges.
:::

::: etape Calcul
$9 - 6 = 3$. Contrôle : $\dfrac{9}{18} = \dfrac{1}{2}$.
:::

::: resultat
Il faut ajouter $3$ boules rouges.
:::

::: attention Erreur fréquente
Écrire $\dfrac{6}{b} = \dfrac{2}{5}$ : le dénominateur est le nombre **total** de boules, $6 + b$.
:::

Solution:
<!-- optitab:1 -->
1. $6 + b$
2. $\dfrac{6}{6 + b} = \dfrac{2}{5}$
3. $b = 9$
4. $\dfrac{6}{15} = \dfrac{2}{5}$
5. $3$ boules rouges

$6 \times 6 = 36$ issues équiprobables.

::: etape Quand le produit est-il impair ?

<!-- optitab:1 -->

## Question 1 : L'arbre des possibles

::: etape Probabilités des branches
Entrées : $\dfrac{1}{3}$ chacune ; plats : $\dfrac{1}{2}$ chacun.
:::

[IMAGE_1]

::: resultat
$3 \times 2 = 6$ menus différents.
:::

## Question 2 : Soupe et pâtes

::: resultat
$P(\text{soupe et pâtes}) = \dfrac{1}{3} \times \dfrac{1}{2} = \dfrac{1}{6}$
:::

## Question 3 : Du poisson

::: etape Chemins favorables (en vert)
Soupe-poisson, melon-poisson, taboulé-poisson : $3$ chemins de probabilité $\dfrac{1}{6}$.
:::

::: resultat
$P(\text{poisson}) = 3 \times \dfrac{1}{6} = \dfrac{1}{2}$
:::

## Question 4 : Pas de melon

::: resultat
$P(\text{melon}) = \dfrac{1}{3}$, donc $P(\text{pas de melon}) = 1 - \dfrac{1}{3} = \dfrac{2}{3}$.
:::

## Question 5 : Avec un dessert

::: etape Nombre de menus
Chacun des $6$ menus se prolonge par $4$ desserts : $6 \times 4 = 24$ menus.
:::

::: resultat
$24$ menus complets équiprobables ; un menu précis a la probabilité $\dfrac{1}{24}$.
:::

::: attention Erreur fréquente
Additionner les choix ($3 + 2 = 5$ menus) au lieu de les multiplier : chaque entrée se combine avec chaque plat.
:::

Solution:
<!-- optitab:1 -->
1. $6$ menus
2. $\dfrac{1}{6}$
3. $\dfrac{1}{2}$
4. $\dfrac{2}{3}$
5. $24$ menus ; $\dfrac{1}{24}$

=== Type brevet - Le dé truqué
Id: 2357
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un dé à six faces est truqué : la face $6$ a une probabilité de $\dfrac{1}{4}$ ; les cinq autres faces ont toutes la même probabilité.

1. Quelle est la probabilité de ne pas obtenir $6$ ?
2. Calculer la probabilité de chacune des autres faces.
3. Calculer la probabilité d'obtenir un nombre pair.
4. On lance ce dé $400$ fois. Environ combien de $6$ peut-on s'attendre à obtenir ?
5. Sur ces $400$ lancers, on a obtenu $98$ fois le $6$. Ce résultat est-il cohérent avec le trucage annoncé ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Ne pas obtenir 6

::: resultat
$P(\text{non } 6) = 1 - \dfrac{1}{4} = \dfrac{3}{4}$
:::

## Question 2 : Les autres faces

::: methode
Les faces $1$ à $5$ se partagent également la probabilité $\dfrac{3}{4}$.
:::

::: etape Calcul
$$\frac{3}{4} \div 5 = \frac{3}{4} \times \frac{1}{5} = \frac{3}{20}$$
:::

::: etape Contrôle
$$5 \times \frac{3}{20} + \frac{1}{4} = \frac{15}{20} + \frac{5}{20} = 1$$
:::

::: resultat
Chacune des faces $1$ à $5$ a la probabilité $\dfrac{3}{20}$.
:::

## Question 3 : Un nombre pair

::: etape Faces paires
$2$, $4$ et $6$ : on additionne leurs probabilités (issues incompatibles).
:::

::: etape Calcul
$$
\begin{aligned}
P(\text{pair}) &= \frac{3}{20} + \frac{3}{20} + \frac{1}{4} \\
&= \frac{3}{20} + \frac{3}{20} + \frac{5}{20} \\
&= \frac{11}{20}
\end{aligned}
$$
:::

::: resultat
$P(\text{pair}) = \dfrac{11}{20}$
:::

## Question 4 : Sur 400 lancers

::: resultat
$400 \times \dfrac{1}{4} = 100$ : environ $100$ fois le $6$.
:::

## Question 5 : Cohérent ?

::: etape Fréquence observée
$$f = \frac{98}{400} = 0{,}245$$

On compare avec la probabilité $\dfrac{1}{4} = 0{,}25$.
:::

::: resultat
Oui : la fréquence $0{,}245$ est très proche de la probabilité $0{,}25$.
:::

::: attention Erreur fréquente
Utiliser $\dfrac{1}{6}$ ou $\dfrac{3}{6}$ pour un dé truqué : la formule « favorables ÷ possibles » n'est valable qu'en situation d'équiprobabilité.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{3}{4}$
2. $\dfrac{3}{20}$
3. $\dfrac{11}{20}$
4. Environ $100$
5. Oui : $0{,}245 \approx 0{,}25$

=== Type brevet - Le stand de la kermesse
Id: 2358
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
À la kermesse du collège, un joueur tire un jeton au hasard dans un sac contenant trois jetons numérotés $1$, $2$ et $3$, puis fait tourner une roue partagée en quatre secteurs égaux numérotés de $1$ à $4$. Il additionne les deux nombres obtenus. Il gagne si la somme est égale à $5$.

[IMAGE_1]

1. Construire un tableau à double entrée donnant toutes les sommes possibles. Combien y a-t-il d'issues ?
2. Calculer la probabilité de gagner.
3. Calculer la probabilité de perdre.
4. Un joueur affirme : « la somme $7$ est aussi probable que la somme $5$ ». A-t-il raison ?
5. Sur une journée, $200$ parties ont été jouées et $46$ ont été gagnées. Calculer la fréquence de gain. Ce résultat est-il cohérent avec la question 2 ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le tableau des sommes

::: methode
Jeton en ligne, roue en colonne ; les cases où la somme vaut $5$ sont en vert.
:::

[IMAGE_2]

::: resultat
$3 \times 4 = 12$ issues équiprobables (jetons tirés au hasard, secteurs égaux).
:::

## Question 2 : Gagner

::: etape Cases favorables
$(1\,;4)$, $(2\,;3)$, $(3\,;2)$ : $3$ cases sur $12$.
:::

::: resultat
$P(\text{gagner}) = \dfrac{3}{12} = \dfrac{1}{4}$
:::

## Question 3 : Perdre

::: resultat
$P(\text{perdre}) = 1 - \dfrac{1}{4} = \dfrac{3}{4}$
:::

## Question 4 : La somme 7

::: etape Cases donnant 7
Seule la case $(3\,;4)$ : $P(\text{somme } 7) = \dfrac{1}{12}$.
:::

::: resultat
Non : $\dfrac{1}{12} < \dfrac{3}{12}$, la somme $7$ est trois fois moins probable que la somme $5$.
:::

## Question 5 : Fréquence de gain

::: etape Calcul
$f = \dfrac{46}{200} = 0{,}23$, à comparer avec $\dfrac{1}{4} = 0{,}25$.
:::

::: resultat
La fréquence $0{,}23$ est proche de $0{,}25$ : c'est cohérent avec une probabilité de gain de $\dfrac{1}{4}$.
:::

::: attention Erreur fréquente
Penser que les sommes possibles ($2$ à $7$) sont équiprobables : on compte les **cases** du tableau, pas les valeurs de la somme.
:::

Solution:
<!-- optitab:1 -->
1. $12$ issues
2. $\dfrac{1}{4}$
3. $\dfrac{3}{4}$
4. Non : $\dfrac{1}{12}$ contre $\dfrac{3}{12}$
5. $0{,}23$ : cohérent avec $0{,}25$
