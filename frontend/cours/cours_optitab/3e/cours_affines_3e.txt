=== Fonctions linéaires et affines - Programme 3ème
Difficulté: medium
Ordre: 9
Images: affines_3e_droites.png

Titre: Fonctions linéaires et affines
Description: Cours complet de 3ème sur les fonctions linéaires et affines : définitions, représentations graphiques, pente et ordonnée à l'origine, détermination d'une expression à partir de deux points, et comparaison de modèles de tarifs.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> reconnaître une fonction linéaire ou affine, tracer une droite et lire ses paramètres (pente, ordonnée à l'origine), retrouver une expression à partir de deux points, et comparer des modèles de tarifs.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Deux familles de fonctions</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Fonction linéaire :</strong> $\displaystyle f(x) = ax$. Elle modélise une <strong>proportionnalité</strong> ; sa représentation est une droite passant par l'<strong>origine</strong>.</p>
            <p style="margin:8px 0 0 0;"><strong>Fonction affine :</strong> $\displaystyle g(x) = ax + b$. Sa représentation est une droite ; $\displaystyle b = g(0)$ est l'<strong>ordonnée à l'origine</strong> et $\displaystyle a$ est la <strong>pente</strong> (ou coefficient directeur).</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Exemple :</strong> pour $\displaystyle g(x) = 2x - 3$ : le point $\displaystyle (0\ ;\ -3)$ est sur la droite, et quand l'abscisse augmente de 1, l'ordonnée augmente de 2. Les points $\displaystyle (0\ ;\ -3)$ et $\displaystyle (2\ ;\ 1)$ suffisent pour tracer la droite.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Lecture de la pente :</strong> $\displaystyle a > 0$ → droite montante ; $\displaystyle a < 0$ → droite descendante ; $\displaystyle a = 0$ → fonction constante (droite horizontale).
        </div>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> « affine » n'implique pas « proportionnel » ! Il faut en plus $\displaystyle b = 0$ pour obtenir une fonction linéaire.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Retrouver une expression</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Méthode — à partir de deux points</strong> $\displaystyle (x_1\ ;\ y_1)$ et $\displaystyle (x_2\ ;\ y_2)$ avec $\displaystyle x_1 \neq x_2$ :</p>
            <div style="text-align:center; margin:10px 0 0 0;">$\displaystyle a = \frac{y_2 - y_1}{x_2 - x_1}$</div>
            <p style="margin:8px 0 0 0;">puis utiliser $\displaystyle y_1 = ax_1 + b$ pour retrouver $\displaystyle b$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple rédigé :</strong> une droite passe par $\displaystyle (1\ ;\ 5)$ et $\displaystyle (4\ ;\ 11)$. Sa pente est $\displaystyle \frac{11 - 5}{4 - 1} = 2$, puis $\displaystyle 5 = 2 \times 1 + b$ donne $\displaystyle b = 3$. La fonction est $\displaystyle f(x) = 2x + 3$.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Cas linéaire :</strong> pour une fonction LINÉAIRE, un seul point suffit : si $\displaystyle f(6) = 21$, alors $\displaystyle a = \frac{21}{6} = 3{,}5$ et $\displaystyle f(x) = 3{,}5x$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Comparer deux modèles</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Méthode — comparer deux tarifs :</strong></p>
            <p style="margin:6px 0 0 0;">① Résoudre l'<strong>égalité</strong> des deux expressions pour repérer le seuil ;</p>
            <p style="margin:4px 0 0 0;">② Tester une valeur de part et d'autre du seuil ;</p>
            <p style="margin:4px 0 0 0;">③ Revenir au <strong>nombre entier</strong> d'unités si la situation l'exige.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> offres $\displaystyle A(n) = 20 + 3n$ et $\displaystyle B(n) = 8 + 5n$ : l'égalité donne $\displaystyle n = 6$ (38 €). Avant 6 séances, B est moins chère ; au-delà, A gagne.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> une droite <strong>verticale</strong> ne représente pas une fonction (une même entrée aurait plusieurs images). Et une formule affine doit être justifiée par le modèle ou les données : toutes les courbes ne sont pas des droites !
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L'essentiel :</strong> linéaire = $\displaystyle ax$ (origine, proportionnalité) ; affine = $\displaystyle ax + b$ (pente $\displaystyle a$, ordonnée à l'origine $\displaystyle b$) ; deux points → $\displaystyle a = \frac{y_2 - y_1}{x_2 - x_1}$ puis $\displaystyle b$ ; comparaison de tarifs → égalité pour le seuil, tests de part et d'autre. Fiche de synthèse dans l'onglet Fiches !</p>
    </div>
