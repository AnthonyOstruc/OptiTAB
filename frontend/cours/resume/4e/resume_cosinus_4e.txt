===Résumé Cosinus dans le triangle rectangle 4ème

Titre: Résumé : Cosinus dans le triangle rectangle

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : la définition du cosinus, les trois calculs types et l'usage de la calculatrice. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. La définition</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$ABC$ rectangle en $A$ : $\cos \widehat{B} = \dfrac{BA}{BC} = \dfrac{\text{adjacent}}{\text{hypoténuse}}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Le cosinus d'un angle aigu est compris entre $0$ et $1$.</p>
<p style="margin:6px 0 0 0;">• Il ne dépend que de l'angle, pas de la taille du triangle.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Les trois calculs types</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Côté adjacent : $AB = BC \times \cos \widehat{B}$ (on multiplie).</p>
<p style="margin:6px 0 0 0;">2️⃣ Hypoténuse : $BC = \dfrac{AB}{\cos \widehat{B}}$ (on divise).</p>
<p style="margin:6px 0 0 0;">3️⃣ Angle : $\cos \widehat{B} = \dfrac{AB}{BC}$, puis touche cos⁻¹ (mode degrés).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Utiliser le cosinus dans un triangle qui n'est pas rectangle.</p>
<p style="margin:6px 0 0 0;">2️⃣ Prendre le côté opposé au lieu du côté adjacent.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier le mode degrés de la calculatrice.</p>
<p style="margin:6px 0 0 0;">4️⃣ Trouver un cosinus supérieur à $1$ (hypoténuse placée en haut) sans réagir.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> triangle rectangle + un angle aigu → cosinus ; deux longueurs connues sans angle → Pythagore ; les deux angles aigus font $90°$ à eux deux.</p>
</div>
