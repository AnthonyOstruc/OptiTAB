=== Découverte - Écrire les rapports de Thalès
Id: 2087
Difficulté: easy
Image: thales_3e_ex01.png

Énoncé:
<!-- optitab:1 -->
Sur la figure, le point $M$ appartient au segment $[AB]$, le point $N$ appartient au segment $[AC]$ et les droites $(MN)$ et $(BC)$ sont parallèles.

[IMAGE_1]

1. Citer les trois hypothèses qui permettent d'appliquer le théorème de Thalès.
2. Écrire l'égalité des trois rapports donnée par le théorème.
3. Quel côté du triangle $ABC$ correspond au côté $[MN]$ du triangle $AMN$ ?
4. On sait que $\dfrac{AM}{AB} = \dfrac{1}{2}$. Que vaut $\dfrac{AN}{AC}$ ?
5. Vrai ou faux : le rapport $\dfrac{MB}{AB}$ fait partie des rapports de Thalès.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les trois hypothèses

::: methode
Avant d'utiliser le théorème, on vérifie deux alignements et un parallélisme.
:::

::: etape Lire l'énoncé
- $M \in [AB]$ : les points $A$, $M$, $B$ sont alignés.
- $N \in [AC]$ : les points $A$, $N$, $C$ sont alignés.
- L'énoncé dit que $(MN) \parallel (BC)$.
:::

::: resultat
Les hypothèses sont : $A$, $M$, $B$ alignés ; $A$, $N$, $C$ alignés ; $(MN) \parallel (BC)$.
:::

## Question 2 : L'égalité des rapports

::: methode
Côtés du petit triangle $AMN$ au numérateur, côtés correspondants du grand triangle $ABC$ au dénominateur.
:::

::: etape Associer les côtés
$[AM]$ est porté par $[AB]$, $[AN]$ par $[AC]$, et $[MN]$ est parallèle à $[BC]$.
:::

[IMAGE_2]

::: resultat
$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

## Question 3 : Le côté qui correspond à $[MN]$

::: etape Côtés parallèles
$[MN]$ et $[BC]$ sont les deux côtés parallèles : ils se correspondent.
:::

::: resultat
Le côté $[MN]$ correspond au côté $[BC]$.
:::

## Question 4 : Valeur de $\dfrac{AN}{AC}$

::: etape Les rapports sont égaux
D'après la question 2, $\dfrac{AN}{AC} = \dfrac{AM}{AB}$.
:::

::: resultat
$\dfrac{AN}{AC} = \dfrac{1}{2}$ : $N$ est le milieu de $[AC]$.
:::

## Question 5 : Le rapport $\dfrac{MB}{AB}$

::: etape Que représente $MB$ ?
$[MB]$ n'est pas un côté du triangle $AMN$ : c'est le morceau restant de $[AB]$.
:::

::: resultat
Faux : les rapports de Thalès n'utilisent que des longueurs mesurées depuis le sommet commun $A$ (et $MN$, $BC$).
:::

::: attention Erreur fréquente
Mélanger les triangles dans un rapport, par exemple écrire $\dfrac{AM}{MB}$ : tous les numérateurs viennent du triangle $AMN$, tous les dénominateurs du triangle $ABC$.
:::

Solution:
<!-- optitab:1 -->
1. $A$, $M$, $B$ alignés ; $A$, $N$, $C$ alignés ; $(MN) \parallel (BC)$.
2. $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$
3. $[BC]$
4. $\dfrac{AN}{AC} = \dfrac{1}{2}$
5. Faux.

=== Découverte - Calculer deux longueurs dans un triangle emboîté
Id: 2088
Difficulté: easy
Image: thales_3e_ex02.png

Énoncé:
<!-- optitab:1 -->
Le point $M$ est sur $[AB]$, le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$. On donne $AM = 3$ cm, $AB = 5$ cm, $AC = 10$ cm et $BC = 7{,}5$ cm.

[IMAGE_1]

1. Écrire l'égalité des rapports donnée par le théorème de Thalès.
2. Calculer $AN$.
3. Calculer $MN$.
4. Vérifier que les résultats sont cohérents avec la figure.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'égalité des rapports

::: methode
On cite les hypothèses, puis on écrit les trois rapports.
:::

::: etape Hypothèses
$A$, $M$, $B$ sont alignés, $A$, $N$, $C$ sont alignés et $(MN) \parallel (BC)$.
:::

::: resultat
D'après le théorème de Thalès : $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$, soit $\dfrac{3}{5} = \dfrac{AN}{10} = \dfrac{MN}{7{,}5}$.
:::

## Question 2 : Calculer $AN$

::: methode
On garde le rapport connu $\dfrac{3}{5}$ et le rapport qui contient $AN$, puis produit en croix.
:::

::: etape Produit en croix
$$\frac{3}{5} = \frac{AN}{10} \quad\text{donc}\quad AN = \frac{3 \times 10}{5} = \frac{30}{5} = 6$$
:::

::: resultat
$AN = 6$ cm.
:::

## Question 3 : Calculer $MN$

::: etape Produit en croix
$$\frac{3}{5} = \frac{MN}{7{,}5} \quad\text{donc}\quad MN = \frac{3 \times 7{,}5}{5} = \frac{22{,}5}{5} = 4{,}5$$
:::

[IMAGE_2]

::: resultat
$MN = 4{,}5$ cm.
:::

## Question 4 : Cohérence

::: etape Comparer
Le triangle $AMN$ est une réduction du triangle $ABC$ de rapport $\dfrac{3}{5} = 0{,}6$ : ses côtés doivent être plus courts.

$AN = 6 < 10 = AC$ et $MN = 4{,}5 < 7{,}5 = BC$.
:::

::: resultat
Les résultats sont cohérents : chaque côté de $AMN$ vaut $0{,}6$ fois le côté correspondant de $ABC$.
:::

::: attention Erreur fréquente
Écrire $\dfrac{5}{3}$ au lieu de $\dfrac{3}{5}$ : on trouverait $AN \approx 16{,}7$ cm, plus grand que $AC$, ce qui est impossible puisque $N$ est sur $[AC]$.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{3}{5} = \dfrac{AN}{10} = \dfrac{MN}{7{,}5}$
2. $AN = 6$ cm
3. $MN = 4{,}5$ cm
4. $6 < 10$ et $4{,}5 < 7{,}5$ : cohérent (rapport de réduction $0{,}6$).

=== Découverte - Reconnaître une configuration de Thalès
Id: 2089
Difficulté: easy
Image: thales_3e_ex03.png

Énoncé:
<!-- optitab:1 -->
On donne trois figures. Dans chacune, les points qui semblent alignés le sont.

[IMAGE_1]

1. Pour chaque figure, dire si l'on peut appliquer le théorème de Thalès. Justifier.
2. Écrire l'égalité des rapports pour la figure (a).
3. Dans la figure (b), écrire l'égalité des rapports, puis calculer $OH$ sachant que $OE = 2$ cm, $OG = 5$ cm et $OF = 3$ cm.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le théorème s'applique-t-il ?

::: methode
Il faut deux droites sécantes (les alignements) et deux droites parallèles **données** par l'énoncé.
:::

::: etape Figure (a)
$R$, $U$, $S$ alignés ; $R$, $V$, $T$ alignés ; $(UV) \parallel (ST)$ : configuration emboîtée.
:::

::: etape Figure (b)
$E$, $O$, $G$ alignés ; $F$, $O$, $H$ alignés ; $(EF) \parallel (GH)$ : configuration papillon.
:::

::: etape Figure (c)
Les droites $(PQ)$ et $(JK)$ ont l'air parallèles, mais l'énoncé ne le dit pas : on ne peut pas l'affirmer d'après le dessin.
:::

::: resultat
Le théorème s'applique aux figures (a) et (b), pas à la figure (c).
:::

## Question 2 : Rapports dans la figure (a)

::: etape Petit triangle et grand triangle
Le petit triangle est $RUV$, le grand est $RST$ ; $[UV]$ correspond à $[ST]$.
:::

::: resultat
$$\frac{RU}{RS} = \frac{RV}{RT} = \frac{UV}{ST}$$
:::

## Question 3 : Figure (b) et calcul de $OH$

::: methode
En configuration papillon, on écrit les rapports depuis le point d'intersection $O$, exactement comme en configuration emboîtée.
:::

::: etape Égalité des rapports
Les points $E$, $O$, $G$ et $F$, $O$, $H$ sont alignés et $(EF) \parallel (GH)$. D'après le théorème de Thalès :
$$\frac{OE}{OG} = \frac{OF}{OH} = \frac{EF}{GH}$$
:::

::: etape Produit en croix
$$\frac{2}{5} = \frac{3}{OH} \quad\text{donc}\quad 2 \times OH = 5 \times 3 = 15 \quad\text{donc}\quad OH = \frac{15}{2} = 7{,}5$$
:::

[IMAGE_2]

::: resultat
$OH = 7{,}5$ cm.
:::

::: attention Erreur fréquente
Appliquer le théorème parce que des droites « ont l'air » parallèles : un parallélisme se lit dans l'énoncé ou se démontre, jamais sur le dessin.
:::

Solution:
<!-- optitab:1 -->
1. Oui pour (a) (emboîtée) et (b) (papillon) ; non pour (c) : le parallélisme n'est pas donné.
2. $\dfrac{RU}{RS} = \dfrac{RV}{RT} = \dfrac{UV}{ST}$
3. $\dfrac{OE}{OG} = \dfrac{OF}{OH} = \dfrac{EF}{GH}$ ; $OH = 7{,}5$ cm.

=== Découverte - Reconstituer le côté entier
Id: 2090
Difficulté: easy
Image: thales_3e_ex04.png,thales_3e_ex04_solution.png

Énoncé:
<!-- optitab:1 -->
Le point $M$ est sur $[AB]$, le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$. On donne $AM = 3$ cm, $MB = 2$ cm et $AC = 12$ cm.

[IMAGE_1]

1. Calculer $AB$.
2. Calculer $AN$.
3. En déduire $NC$.
4. Vérifier que $\dfrac{AN}{AC}$ est égal à $\dfrac{AM}{AB}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $AB$

::: methode
$M$ est sur le segment $[AB]$ : la longueur $AB$ est la somme des deux morceaux.
:::

::: etape Addition
$$AB = AM + MB = 3 + 2 = 5$$
:::

::: resultat
$AB = 5$ cm.
:::

## Question 2 : Calculer $AN$

::: methode
Théorème de Thalès avec les longueurs mesurées depuis $A$.
:::

::: etape Égalité des rapports
$A$, $M$, $B$ alignés, $A$, $N$, $C$ alignés et $(MN) \parallel (BC)$. D'après le théorème de Thalès :
$$\frac{AM}{AB} = \frac{AN}{AC} \quad\text{soit}\quad \frac{3}{5} = \frac{AN}{12}$$
:::

::: etape Produit en croix
$$AN = \frac{3 \times 12}{5} = \frac{36}{5} = 7{,}2$$
:::

::: resultat
$AN = 7{,}2$ cm.
:::

## Question 3 : En déduire $NC$

::: etape Soustraction
$N$ est sur $[AC]$, donc $NC = AC - AN = 12 - 7{,}2 = 4{,}8$.
:::

[IMAGE_2]

::: resultat
$NC = 4{,}8$ cm.
:::

## Question 4 : Vérification

::: etape Calcul du rapport
$$\frac{AN}{AC} = \frac{7{,}2}{12} = 0{,}6$$

$$\frac{AM}{AB} = \frac{3}{5} = 0{,}6$$
:::

::: resultat
Les deux rapports valent $0{,}6$ : le calcul est confirmé.
:::

::: attention Erreur fréquente
Écrire $\dfrac{AM}{MB} = \dfrac{AN}{NC}$ avec $\dfrac{3}{2}$ : $MB$ n'est pas un côté du grand triangle. On reconstitue d'abord $AB = AM + MB$.
:::

Solution:
<!-- optitab:1 -->
1. $AB = 5$ cm
2. $AN = 7{,}2$ cm
3. $NC = 4{,}8$ cm
4. $\dfrac{7{,}2}{12} = 0{,}6 = \dfrac{3}{5}$

=== Découverte - Inconnue au dénominateur
Id: 2222
Difficulté: easy
Image: thales_3e_ex_d5.png

Énoncé:
<!-- optitab:1 -->
Le point $M$ est sur $[AB]$, le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$. On donne $AM = 6$ cm, $AN = 4$ cm et $AC = 10$ cm.

[IMAGE_1]

1. Écrire l'égalité de rapports qui contient $AB$.
2. Calculer $AB$.
3. Calculer $MB$.
4. Quel est le rapport d'agrandissement qui fait passer du triangle $AMN$ au triangle $ABC$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'égalité utile

::: methode
On garde le rapport qui contient l'inconnue $AB$ et le rapport entièrement connu $\dfrac{AN}{AC}$.
:::

::: resultat
D'après le théorème de Thalès ($A$, $M$, $B$ et $A$, $N$, $C$ alignés, $(MN) \parallel (BC)$) : $\dfrac{AM}{AB} = \dfrac{AN}{AC}$, soit $\dfrac{6}{AB} = \dfrac{4}{10}$.
:::

## Question 2 : Calculer $AB$

::: methode
Le produit en croix fonctionne aussi quand l'inconnue est au dénominateur.
:::

::: etape Produit en croix
$$4 \times AB = 6 \times 10 = 60 \quad\text{donc}\quad AB = \frac{60}{4} = 15$$
:::

::: resultat
$AB = 15$ cm.
:::

## Question 3 : Calculer $MB$

::: etape Soustraction
$M$ est sur $[AB]$ : $MB = AB - AM = 15 - 6 = 9$.
:::

[IMAGE_2]

::: resultat
$MB = 9$ cm.
:::

## Question 4 : Le rapport d'agrandissement

::: etape Grand sur petit
$$k = \frac{AC}{AN} = \frac{10}{4} = 2{,}5$$
Contrôle : $AM \times 2{,}5 = 6 \times 2{,}5 = 15 = AB$.
:::

::: resultat
Le triangle $ABC$ est un agrandissement de $AMN$ de rapport $2{,}5$.
:::

::: attention Erreur fréquente
Écrire $AB = \dfrac{6 \times 4}{10} = 2{,}4$ : on obtient un côté $AB$ plus petit que $AM$, ce qui est impossible puisque $M$ est sur $[AB]$. Toujours contrôler la cohérence.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{6}{AB} = \dfrac{4}{10}$
2. $AB = 15$ cm
3. $MB = 9$ cm
4. $k = 2{,}5$

=== Découverte - Triangles semblables reconnus par leurs angles
Id: 2223
Difficulté: easy
Image: thales_3e_ex01.png

Énoncé:
<!-- optitab:1 -->
Les triangles $ABC$ et $DEF$ ont les angles indiqués sur la figure : $\widehat{A} = 50^\circ$, $\widehat{B} = 60^\circ$, $\widehat{D} = 70^\circ$ et $\widehat{E} = 50^\circ$.

[IMAGE_1]

1. Calculer $\widehat{C}$ et $\widehat{F}$.
2. Les triangles $ABC$ et $DEF$ sont-ils semblables ? Justifier.
3. Associer chaque sommet de $ABC$ au sommet correspondant de $DEF$.
4. Quel côté de $DEF$ correspond au côté $[AB]$ ?
5. Un triangle $GHI$ a deux angles de $50^\circ$ et $80^\circ$. Est-il semblable à $ABC$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les angles manquants

::: methode
La somme des angles d'un triangle vaut $180^\circ$.
:::

::: etape Calculs
$$\widehat{C} = 180^\circ - 50^\circ - 60^\circ = 70^\circ$$

$$\widehat{F} = 180^\circ - 70^\circ - 50^\circ = 60^\circ$$
:::

[IMAGE_2]

::: resultat
$\widehat{C} = 70^\circ$ et $\widehat{F} = 60^\circ$.
:::

## Question 2 : Semblables ?

::: methode
Deux triangles sont semblables quand leurs angles sont égaux deux à deux.
:::

::: etape Comparer
$ABC$ a pour angles $50^\circ$, $60^\circ$, $70^\circ$ ; $DEF$ a pour angles $70^\circ$, $50^\circ$, $60^\circ$.
:::

::: resultat
Les deux triangles ont les mêmes angles : ils sont semblables.
:::

## Question 3 : Correspondance des sommets

::: etape Sommets d'angles égaux
$\widehat{A} = \widehat{E} = 50^\circ$, $\widehat{B} = \widehat{F} = 60^\circ$, $\widehat{C} = \widehat{D} = 70^\circ$.
:::

::: resultat
$A \leftrightarrow E$, $B \leftrightarrow F$, $C \leftrightarrow D$.
:::

## Question 4 : Le côté correspondant à $[AB]$

::: etape Utiliser la correspondance
$A$ correspond à $E$ et $B$ correspond à $F$.
:::

::: resultat
Le côté $[AB]$ correspond au côté $[EF]$.
:::

## Question 5 : Le triangle $GHI$

::: etape Troisième angle
$180^\circ - 50^\circ - 80^\circ = 50^\circ$ : les angles de $GHI$ sont $50^\circ$, $50^\circ$, $80^\circ$.
:::

::: resultat
Non : $GHI$ n'a pas d'angle de $60^\circ$, ses angles ne sont pas ceux de $ABC$.
:::

::: attention Erreur fréquente
Associer les sommets dans l'ordre des lettres ($A$ avec $D$, $B$ avec $E$…). On associe toujours les sommets des angles **égaux**.
:::

Solution:
<!-- optitab:1 -->
1. $\widehat{C} = 70^\circ$ et $\widehat{F} = 60^\circ$
2. Oui : mêmes angles $50^\circ$, $60^\circ$, $70^\circ$.
3. $A \leftrightarrow E$, $B \leftrightarrow F$, $C \leftrightarrow D$
4. $[EF]$
5. Non (angles $50^\circ$, $50^\circ$, $80^\circ$).

=== Découverte - Vrai ou faux sur Thalès et sa réciproque
Id: 2224
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pour chaque affirmation, dire si elle est vraie ou fausse, en justifiant. Les points $M$ et $N$ sont sur les droites $(AB)$ et $(AC)$.

1. Le théorème de Thalès s'applique dès que deux droites sont parallèles, sans autre condition.
2. Dans une configuration de Thalès, $\dfrac{AM}{AB} = \dfrac{AN}{AC}$.
3. Le théorème de Thalès ne s'applique pas dans la configuration papillon.
4. Si $\dfrac{AM}{AB} = \dfrac{AN}{AC}$, alors $(MN) \parallel (BC)$, quel que soit l'ordre des points.
5. Le théorème de Thalès sert à calculer des longueurs ; sa réciproque sert à démontrer que deux droites sont parallèles.

Étapes:
<!-- optitab:1 -->
## Question 1 : Parallèles sans alignements ?

::: methode
Relire les hypothèses du théorème.
:::

::: etape Les hypothèses
Il faut deux droites sécantes en $A$ (points $A$, $M$, $B$ alignés et $A$, $N$, $C$ alignés) **et** le parallélisme $(MN) \parallel (BC)$.
:::

::: resultat
Faux : les alignements sont indispensables.
:::

## Question 2 : L'égalité des rapports

::: etape Conclusion du théorème
Le théorème donne $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$, donc en particulier l'égalité des deux premiers rapports.
:::

::: resultat
Vrai.
:::

## Question 3 : La configuration papillon

::: etape Les deux configurations
Le théorème s'applique aussi quand $A$ est entre $M$ et $B$ et entre $N$ et $C$, avec les mêmes rapports.
:::

::: resultat
Faux.
:::

## Question 4 : L'ordre des points

::: methode
Chercher un contre-exemple : $M$ sur $[AB]$ et $N$ de l'autre côté de $A$.
:::

::: etape Un contre-exemple
$AM = 2$, $AB = 4$, $AN = 3$, $AC = 6$, avec $M \in [AB]$ mais $A$ entre $N$ et $C$. Alors $\dfrac{AM}{AB} = \dfrac{2}{4} = \dfrac{1}{2}$ et $\dfrac{AN}{AC} = \dfrac{3}{6} = \dfrac{1}{2}$, pourtant la droite $(MN)$ coupe la droite $(BC)$.
:::

[IMAGE_1]

::: resultat
Faux : la réciproque exige que les points soient alignés **dans le même ordre**.
:::

## Question 5 : Les deux usages

::: etape Hypothèse et conclusion
- Théorème : on sait que les droites sont parallèles, on en déduit des rapports (donc des longueurs).
- Réciproque : on sait que les rapports sont égaux, on en déduit que les droites sont parallèles.
:::

::: resultat
Vrai.
:::

::: retenir
Théorème : **parallèles $\Rightarrow$ rapports égaux**. Réciproque : **rapports égaux et même ordre $\Rightarrow$ parallèles**.
:::

Solution:
<!-- optitab:1 -->
1. Faux : il faut aussi les alignements.
2. Vrai.
3. Faux : la configuration papillon fonctionne aussi.
4. Faux : il faut le même ordre des points (contre-exemple ci-dessus).
5. Vrai.

=== Entraînement - Démontrer un parallélisme avec la réciproque
Id: 2091
Difficulté: medium
Image: thales_3e_ex05.png,thales_3e_ex05_solution.png

Énoncé:
<!-- optitab:1 -->
Les points $A$, $M$, $B$ sont alignés dans cet ordre, ainsi que les points $A$, $N$, $C$. On donne $AM = 4$ cm, $AB = 10$ cm, $AN = 6$ cm, $AC = 15$ cm et $BC = 10$ cm.

[IMAGE_1]

1. Calculer et simplifier les rapports $\dfrac{AM}{AB}$ et $\dfrac{AN}{AC}$.
2. Démontrer que les droites $(MN)$ et $(BC)$ sont parallèles.
3. Calculer $MN$.
4. On place le point $P$ sur $[AC]$ tel que $AP = 9$ cm. Les droites $(MP)$ et $(BC)$ sont-elles parallèles ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les deux rapports

::: methode
On calcule chaque rapport séparément et on le simplifie.
:::

::: etape Simplifications
$$\frac{AM}{AB} = \frac{4}{10} = \frac{2}{5}$$

$$\frac{AN}{AC} = \frac{6}{15} = \frac{2}{5}$$
:::

::: resultat
Les deux rapports valent $\dfrac{2}{5}$.
:::

## Question 2 : Le parallélisme

::: methode
Réciproque du théorème de Thalès : rapports égaux **et** points alignés dans le même ordre.
:::

::: etape Rédaction
$\dfrac{AM}{AB} = \dfrac{AN}{AC}$ et les points $A$, $M$, $B$ et $A$, $N$, $C$ sont alignés dans le même ordre.
:::

::: resultat
D'après la réciproque du théorème de Thalès, les droites $(MN)$ et $(BC)$ sont parallèles.
:::

## Question 3 : Calculer $MN$

::: methode
Maintenant que le parallélisme est démontré, le théorème de Thalès s'applique.
:::

::: etape Troisième rapport
$$\frac{MN}{BC} = \frac{2}{5} \quad\text{donc}\quad MN = \frac{2}{5} \times 10 = 4$$
:::

[IMAGE_2]

::: resultat
$MN = 4$ cm.
:::

## Question 4 : Le point $P$

::: etape Comparer les rapports
$$\frac{AM}{AB} = \frac{2}{5} = \frac{6}{15}$$

$$\frac{AP}{AC} = \frac{9}{15}$$
Comme $6 \neq 9$, $\dfrac{AM}{AB} \neq \dfrac{AP}{AC}$.
:::

::: resultat
Les droites $(MP)$ et $(BC)$ ne sont pas parallèles : si elles l'étaient, le théorème de Thalès donnerait l'égalité des rapports.
:::

::: attention Erreur fréquente
Utiliser $\dfrac{MN}{BC}$ pour démontrer le parallélisme : $MN$ ne se calcule qu'**après** avoir prouvé que les droites sont parallèles.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{2}{5}$
2. Réciproque du théorème de Thalès : $(MN) \parallel (BC)$.
3. $MN = 4$ cm
4. Non : $\dfrac{9}{15} \neq \dfrac{6}{15}$.

=== Entraînement - Prouver que deux droites ne sont pas parallèles
Id: 2092
Difficulté: medium
Image: thales_3e_ex06.png,thales_3e_ex06_solution.png

Énoncé:
<!-- optitab:1 -->
Les points $A$, $M$, $B$ sont alignés dans cet ordre, ainsi que les points $A$, $N$, $C$. On donne $AM = 3$ cm, $AB = 8$ cm, $AN = 5$ cm et $AC = 12$ cm.

[IMAGE_1]

1. Écrire les rapports $\dfrac{AM}{AB}$ et $\dfrac{AN}{AC}$.
2. Un élève calcule $\dfrac{3}{8} \approx 0{,}4$ et $\dfrac{5}{12} \approx 0{,}4$ et conclut que les droites sont parallèles. Que penser de sa méthode ?
3. Comparer les deux rapports avec les produits en croix et conclure.
4. Quelle longueur $AN'$ faudrait-il pour que $(MN')$ soit parallèle à $(BC)$, avec $N'$ sur $[AC]$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les rapports

::: resultat
$\dfrac{AM}{AB} = \dfrac{3}{8}$ et $\dfrac{AN}{AC} = \dfrac{5}{12}$.
:::

## Question 2 : La méthode de l'élève

::: etape Valeurs plus précises
$\dfrac{3}{8} = 0{,}375$ et $\dfrac{5}{12} = 0{,}4166\ldots$ : les arrondis au dixième sont égaux, mais les nombres ne le sont pas.
:::

::: resultat
Méthode fausse : on ne compare jamais des rapports avec des valeurs arrondies.
:::

## Question 3 : Comparaison exacte

::: methode
$\dfrac{a}{b} = \dfrac{c}{d}$ équivaut à $a \times d = b \times c$.
:::

::: etape Produits en croix
$$3 \times 12 = 36$$

$$8 \times 5 = 40$$

$$36 \neq 40$$
:::

::: resultat
$\dfrac{AM}{AB} \neq \dfrac{AN}{AC}$ : les droites $(MN)$ et $(BC)$ ne sont pas parallèles (si elles l'étaient, le théorème de Thalès imposerait l'égalité des rapports).
:::

## Question 4 : La bonne position

::: etape Égalité voulue
Il faut $\dfrac{AN'}{12} = \dfrac{3}{8}$, donc $AN' = \dfrac{3 \times 12}{8} = \dfrac{36}{8} = 4{,}5$.
:::

[IMAGE_2]

::: resultat
Avec $AN' = 4{,}5$ cm, la réciproque du théorème de Thalès donne $(MN') \parallel (BC)$.
:::

::: attention Erreur fréquente
Conclure « parallèles » parce que la figure le suggère ou parce que les arrondis coïncident : seule une égalité **exacte** permet d'utiliser la réciproque.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{3}{8}$ et $\dfrac{5}{12}$
2. Faux : $0{,}375 \neq 0{,}4166\ldots$ ; on ne compare pas des arrondis.
3. $36 \neq 40$ : $(MN)$ et $(BC)$ ne sont pas parallèles.
4. $AN' = 4{,}5$ cm

Énoncé:
<!-- optitab:1 -->
Les points $M$, $A$, $B$ sont alignés dans cet ordre, ainsi que les points $N$, $A$, $C$. Les droites $(MN)$ et $(BC)$ sont parallèles. On donne $AM = 3$ cm, $AB = 5$ cm, $AC = 8$ cm et $BC = 6$ cm.

::: methode
Le théorème de Thalès s'applique de la même façon en configuration papillon.

::: etape Égalité des rapports
$M$, $A$, $B$ alignés, $N$, $A$, $C$ alignés et $(MN) \parallel (BC)$. D'après le théorème de Thalès :
$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC} \quad\text{soit}\quad \frac{3}{5} = \frac{AN}{8} = \frac{MN}{6}$$
:::

::: etape Produit en croix
$$AN = \frac{3 \times 8}{5} = \frac{24}{5} = 4{,}8$$

$$MN = \frac{3 \times 6}{5} = \frac{18}{5} = 3{,}6$$

[IMAGE_2]

$MN = 3{,}6$ cm.

## Question 3 : $MB$ et $NC$

$A$ est **entre** $M$ et $B$ : on additionne.

::: etape Additions
$$MB = MA + AB = 3 + 5 = 8$$

$$NC = NA + AC = 4{,}8 + 8 = 12{,}8$$
:::

::: resultat
$MB = 8$ cm et $NC = 12{,}8$ cm.
:::

## Question 4 : Rapport de réduction

::: etape Petit sur grand

::: resultat
$AMN$ est une réduction de $ABC$ de rapport $0{,}6$.

Solution:
<!-- optitab:1 -->
1. $AN = 4{,}8$ cm
2. $MN = 3{,}6$ cm
3. $MB = 8$ cm et $NC = 12{,}8$ cm
4. $k = 0{,}6$

Deux triangles dont les angles sont égaux deux à deux sont semblables.

3. $k = 1{,}5$
4. $DE = 12$ cm et $AC = 7$ cm

Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Deux triangles sont semblables. Un côté du petit triangle mesure $4$ cm et le côté correspondant du grand triangle mesure $10$ cm. Le petit triangle a un périmètre de $15$ cm et une aire de $12$ cm².

[IMAGE_1]

1. Calculer le rapport d'agrandissement $k$.
2. Calculer le périmètre du grand triangle.
3. Calculer l'aire du grand triangle.
4. Un élève trouve $30$ cm² pour l'aire du grand triangle. Quelle erreur a-t-il commise ?
5. Un troisième triangle, semblable aux deux autres, a une aire $4$ fois plus grande que celle du petit triangle. Par quel nombre ses côtés sont-ils multipliés ?

<!-- optitab:1 -->
## Question 1 : Le rapport $k$

::: etape Grand sur petit
$$k = \frac{10}{4} = 2{,}5$$
:::

$k = 2{,}5$.
:::

## Question 2 : Le périmètre

::: methode
Les longueurs, donc le périmètre, sont multipliées par $k$.

::: etape Calcul
$$15 \times 2{,}5 = 37{,}5$$

::: resultat
Le périmètre du grand triangle est $37{,}5$ cm.

Les aires sont multipliées par $k^2$.

$$12 \times 6{,}25 = 75$$

[IMAGE_2]

L'aire du grand triangle est $75$ cm².

Les côtés sont multipliés par $2$.

2. $37{,}5$ cm

Énoncé:

On considère trois triangles (longueurs en cm) :

=== Entraînement - Réciproque en configuration papillon
Id: 2228
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Les points $M$, $A$, $B$ sont alignés dans cet ordre, ainsi que les points $N$, $A$, $C$. On donne $AM = 2{,}4$ cm, $AB = 4$ cm, $AN = 3$ cm, $AC = 5$ cm et $BC = 6{,}5$ cm.

[IMAGE_1]

1. Calculer les rapports $\dfrac{AM}{AB}$ et $\dfrac{AN}{AC}$.
2. Démontrer que les droites $(MN)$ et $(BC)$ sont parallèles.
3. Calculer $MN$.
4. Calculer la distance $MB$.

Étapes:
<!-- optitab:1 -->

::: etape Calculs
$$\frac{AM}{AB} = \frac{2{,}4}{4} = 0{,}6$$

$$\frac{AN}{AC} = \frac{3}{5} = 0{,}6$$
:::

::: resultat
Les deux rapports valent $0{,}6$.

## Question 2 : Le parallélisme

::: methode
Réciproque du théorème de Thalès : rapports égaux et points alignés dans le même ordre.

::: etape L'ordre des points
$M$, $A$, $B$ sont alignés dans cet ordre et $N$, $A$, $C$ aussi : dans les deux cas, $A$ est entre les deux autres points. L'ordre est le même.

$\dfrac{AM}{AB} = \dfrac{AN}{AC}$ et les points sont alignés dans le même ordre : d'après la réciproque du théorème de Thalès, $(MN) \parallel (BC)$.

[IMAGE_2]

::: resultat
$MN = 3{,}9$ cm.
:::

## Question 4 : Distance $MB$

$A$ est entre $M$ et $B$ : $MB = MA + AB = 2{,}4 + 4 = 6{,}4$.
:::

::: resultat
$MB = 6{,}4$ cm.
:::

::: attention Erreur fréquente
Oublier de citer l'ordre des points. Ici, il faut dire que $A$ est entre $M$ et $B$ **et** entre $N$ et $C$.
:::

Solution:
<!-- optitab:1 -->

2. Réciproque du théorème de Thalès (même ordre) : $(MN) \parallel (BC)$.

=== Problème - Une équation pour trouver une longueur
Id: 2095
Difficulté: hard
Image: thales_3e_ex09.png,thales_3e_ex09_solution.png

Énoncé:
<!-- optitab:1 -->
Le point $M$ est sur $[AB]$, le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$. On donne $AM = 4$ cm, $MB = x$ cm, $AN = 6$ cm, $NC = 3$ cm et $BC = 7{,}5$ cm.

[IMAGE_1]

1. Exprimer $AB$ en fonction de $x$, puis calculer $AC$.
2. Écrire l'égalité donnée par le théorème de Thalès avec $AM$, $AB$, $AN$ et $AC$.
3. Résoudre l'équation obtenue.
4. Vérifier le résultat, puis calculer $MN$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les côtés entiers

::: etape Additions
$M \in [AB]$ : $AB = AM + MB = 4 + x$.

$N \in [AC]$ : $AC = AN + NC = 6 + 3 = 9$.
:::

::: resultat
$AB = 4 + x$ et $AC = 9$ cm.
:::

## Question 2 : L'équation

::: etape Théorème de Thalès
$A$, $M$, $B$ alignés, $A$, $N$, $C$ alignés et $(MN) \parallel (BC)$ :
$$\frac{AM}{AB} = \frac{AN}{AC} \quad\text{soit}\quad \frac{4}{4 + x} = \frac{6}{9}$$
:::

::: resultat
$\dfrac{4}{4 + x} = \dfrac{2}{3}$ (en simplifiant $\dfrac{6}{9}$).
:::

## Question 3 : Résoudre

::: methode
Produit en croix, puis équation du premier degré.
:::

::: etape Calcul
$$
\begin{aligned}
2(4 + x) &= 4 \times 3 \\
8 + 2x &= 12 \\
2x &= 4 \\
x &= 2
\end{aligned}
$$
:::

::: resultat
$x = 2$ : $MB = 2$ cm.
:::

## Question 4 : Vérification et $MN$

::: etape Vérification
$AB = 4 + 2 = 6$ et $\dfrac{4}{6} = \dfrac{2}{3}$ : c'est bien le rapport $\dfrac{AN}{AC}$.
:::

::: etape Calcul de $MN$
$$\frac{MN}{BC} = \frac{2}{3} \quad\text{donc}\quad MN = \frac{2}{3} \times 7{,}5 = 5$$
:::

[IMAGE_2]

::: resultat
$MN = 5$ cm.
:::

::: attention Erreur fréquente
Écrire $\dfrac{4}{x} = \dfrac{6}{3}$ avec les morceaux $MB$ et $NC$ : ce n'est pas une égalité de Thalès. On revient toujours aux longueurs depuis $A$.
:::

Solution:
<!-- optitab:1 -->
1. $AB = 4 + x$ ; $AC = 9$ cm
2. $\dfrac{4}{4 + x} = \dfrac{6}{9}$
3. $x = 2$
4. $\dfrac{4}{6} = \dfrac{6}{9}$ ; $MN = 5$ cm

=== Problème - Corriger une rédaction fausse
Id: 2096
Difficulté: hard
Image: thales_3e_ex10.png,thales_3e_ex10_solution.png

Énoncé:
<!-- optitab:1 -->
Le point $M$ est sur $[AB]$, le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$. On donne $AM = 3$ cm, $AB = 8$ cm, $AC = 16$ cm et $BC = 12$ cm. Pour calculer $NC$, un élève écrit : « D'après le théorème de Thalès, $\dfrac{AM}{AB} = \dfrac{NC}{AC}$. »

[IMAGE_1]

1. Expliquer pourquoi l'égalité écrite par l'élève est fausse.
2. Écrire l'égalité correcte et calculer $AN$.
3. En déduire $NC$.
4. Calculer $MN$.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'erreur

::: methode
Chaque numérateur doit être un côté du triangle $AMN$.
:::

::: etape Les côtés de $AMN$
Les côtés de $AMN$ sont $[AM]$, $[AN]$ et $[MN]$. $[NC]$ n'en fait pas partie : c'est le morceau de $[AC]$ qui reste après $N$.
:::

::: resultat
Le côté qui correspond à $[AC]$ est $[AN]$, pas $[NC]$ : l'égalité de l'élève est fausse.
:::

## Question 2 : Égalité correcte et $AN$

::: etape Théorème de Thalès
$$\frac{AM}{AB} = \frac{AN}{AC} \quad\text{soit}\quad \frac{3}{8} = \frac{AN}{16}$$
:::

::: etape Produit en croix
$$AN = \frac{3 \times 16}{8} = 6$$
:::

::: resultat
$AN = 6$ cm.
:::

## Question 3 : En déduire $NC$

::: etape Soustraction
$NC = AC - AN = 16 - 6 = 10$.
:::

[IMAGE_2]

::: resultat
$NC = 10$ cm. (Avec l'égalité de l'élève, on aurait trouvé $NC = 6$ cm : c'est faux.)
:::

## Question 4 : Calculer $MN$

::: etape Troisième rapport
$$\frac{MN}{BC} = \frac{3}{8} \quad\text{donc}\quad MN = \frac{3 \times 12}{8} = 4{,}5$$
:::

::: resultat
$MN = 4{,}5$ cm.
:::

::: retenir
Pour $NC$ ou $MB$ : on calcule d'abord la longueur depuis $A$ avec le théorème de Thalès, **puis** on soustrait (configuration emboîtée).
:::

Solution:
<!-- optitab:1 -->
1. $[NC]$ n'est pas un côté du triangle $AMN$ : c'est $[AN]$ qui correspond à $[AC]$.
2. $\dfrac{3}{8} = \dfrac{AN}{16}$ ; $AN = 6$ cm
3. $NC = 10$ cm
4. $MN = 4{,}5$ cm

## Question 1 : Les hypothèses

## Question 2 : L'égalité de rapports

::: methode
On utilise le rapport entièrement connu $\dfrac{MN}{BC}$ et celui qui contient l'inconnue $x$.
:::

::: etape Côté entier
$M$ est entre $A$ et $B$ : $AB = AM + MB = x + 6$.
:::

::: resultat
D'après le théorème de Thalès : $\dfrac{AM}{AB} = \dfrac{MN}{BC}$, soit $\dfrac{x}{x + 6} = \dfrac{12}{15}$.
:::

## Question 3 : Résoudre

::: etape Produit en croix
$$
\begin{aligned}
15x &= 12(x + 6) \\
15x &= 12x + 72 \\
3x &= 72 \\
x &= 24
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
La rivière mesure $24$ m de large (distance $AM$).
:::

## Question 4 : Vérification

::: etape Rapports
$AB = 24 + 6 = 30$ ; $\dfrac{AM}{AB} = \dfrac{24}{30} = 0{,}8$ et $\dfrac{MN}{BC} = \dfrac{12}{15} = 0{,}8$.
:::

::: resultat
Les deux rapports sont égaux : le résultat est juste.
:::

::: attention Erreur fréquente
Écrire $\dfrac{x}{6} = \dfrac{12}{15}$ : $MB = 6$ m n'est pas un côté du grand triangle. Le grand triangle est $ABC$, son côté est $AB = x + 6$.
:::

Solution:
<!-- optitab:1 -->
1. Droites sécantes en $A$ et $(MN) \parallel (BC)$ : configuration de Thalès.
2. $AB = x + 6$ ; $\dfrac{x}{x + 6} = \dfrac{12}{15}$
3. $AM = 24$ m
4. $\dfrac{24}{30} = \dfrac{12}{15} = 0{,}8$

=== Type brevet - Hauteur d'un phare
Id: 2230
Difficulté: hard
Image: thales_3e_phare.png

Énoncé:
<!-- optitab:1 -->
Pour estimer la hauteur d'un phare, Léa pose l'œil au niveau du sol, au point $A$. Elle plante un bâton vertical de $2$ m à $3$ m de $A$. En visant depuis $A$, le sommet du bâton et le sommet $S$ du phare sont alignés. Le pied du phare est à $39$ m de $A$. Le sol est horizontal et le phare est vertical.

[IMAGE_1]

1. Expliquer pourquoi le bâton et le phare sont parallèles.
2. Calculer la hauteur $h$ du phare.
3. Vérifier le résultat avec le rapport d'agrandissement.
4. Calculer la distance $AS$ entre l'œil de Léa et le sommet du phare. Arrondir au dixième de mètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Bâton et phare parallèles

::: etape Deux perpendiculaires
Le bâton et le phare sont verticaux, donc tous deux perpendiculaires au sol horizontal.
:::

::: resultat
Deux droites perpendiculaires à une même droite sont parallèles : le bâton et le phare sont parallèles.
:::

## Question 2 : La hauteur $h$

::: methode
Configuration de Thalès emboîtée : les droites « sol » et « ligne de visée » sont sécantes en $A$, coupées par deux parallèles.
:::

::: etape Égalité des rapports
D'après le théorème de Thalès :
$$\frac{3}{39} = \frac{2}{h}$$
:::

::: etape Produit en croix
$$3h = 2 \times 39 = 78 \quad\text{donc}\quad h = \frac{78}{3} = 26$$
:::

::: resultat
Le phare mesure $26$ m.
:::

## Question 3 : Vérification

::: etape Rapport d'agrandissement
$$k = \frac{39}{3} = 13$$

$$2 \times 13 = 26$$
:::

::: resultat
On retrouve $h = 26$ m.
:::

## Question 4 : La distance $AS$

::: methode
Le triangle formé par $A$, le pied du phare et $S$ est rectangle au pied du phare : théorème de Pythagore.
:::

::: etape Théorème de Pythagore
$$
\begin{aligned}
AS^2 &= 39^2 + 26^2 \\
&= 1\,521 + 676 \\
&= 2\,197
\end{aligned}
$$
:::

::: etape Racine carrée
$AS = \sqrt{2\,197} \approx 46{,}87$.
:::

[IMAGE_2]

::: resultat
$AS \approx 46{,}9$ m.
:::

::: attention Erreur fréquente
Écrire $\dfrac{3}{39} = \dfrac{h}{2}$ : on mélange les deux triangles. Au numérateur, le petit triangle (bâton) ; au dénominateur, le grand (phare).
:::

Solution:
<!-- optitab:1 -->
1. Tous deux sont perpendiculaires au sol, donc parallèles.
2. $h = 26$ m
3. $k = 13$ et $2 \times 13 = 26$
4. $AS = \sqrt{2\,197} \approx 46{,}9$ m

=== Problème - Agrandir une photo
Id: 2231
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une photo rectangulaire mesure $10$ cm sur $15$ cm. On en fait un agrandissement dont le grand côté mesure $45$ cm.

[IMAGE_1]

1. Calculer le rapport d'agrandissement $k$.
2. Calculer le petit côté de l'agrandissement.
3. Calculer l'aire des deux photos et vérifier que l'aire est multipliée par $k^2$.
4. Un tirage de $20$ cm sur $40$ cm est-il un agrandissement de la photo ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le rapport

::: etape Grands côtés correspondants
$$k = \frac{45}{15} = 3$$
:::

::: resultat
$k = 3$.
:::

## Question 2 : Le petit côté

::: etape Multiplier par $k$
$$10 \times 3 = 30$$
:::

[IMAGE_2]

::: resultat
L'agrandissement mesure $30$ cm sur $45$ cm.
:::

## Question 3 : Les aires

::: etape Calculs
$$10 \times 15 = 150 \text{ cm}^2$$

$$30 \times 45 = 1\,350 \text{ cm}^2$$
:::

::: etape Rapport des aires
$$\frac{1\,350}{150} = 9 = 3^2 = k^2$$
:::

::: resultat
L'aire passe de $150$ cm² à $1\,350$ cm² : elle est multipliée par $9 = k^2$.
:::

## Question 4 : Le tirage $20 \times 40$

::: methode
Un agrandissement multiplie **toutes** les longueurs par le même nombre.
:::

::: etape Comparer les quotients
$$\frac{20}{10} = 2$$

$$\frac{40}{15} = \frac{8}{3} \approx 2{,}67$$
:::

::: resultat
Non : les deux côtés ne sont pas multipliés par le même nombre, la photo serait déformée.
:::

::: attention Erreur fréquente
Croire que l'aire est multipliée par $3$ : les deux dimensions sont multipliées par $3$, donc l'aire par $3 \times 3 = 9$.
:::

Solution:
<!-- optitab:1 -->
1. $k = 3$
2. $30$ cm
3. $150$ cm² et $1\,350$ cm² ; $\dfrac{1\,350}{150} = 9 = 3^2$
4. Non : $2 \neq \dfrac{8}{3}$.

=== Type brevet - Démontrer un parallélisme puis calculer
Id: 2232
Difficulté: hard
Image: thales_3e_p7.png

Énoncé:
<!-- optitab:1 -->
Sur la figure, les points $A$, $M$, $B$ sont alignés dans cet ordre, ainsi que les points $A$, $N$, $C$. On donne $AM = 4{,}5$ cm, $AB = 6$ cm, $AN = 7{,}5$ cm, $AC = 10$ cm et $MN = 6$ cm.

[IMAGE_1]

1. Démontrer que les droites $(MN)$ et $(BC)$ sont parallèles.
2. Calculer $BC$.
3. Démontrer que le triangle $AMN$ est rectangle en $M$.
4. En déduire que le triangle $ABC$ est rectangle en $B$.
5. Calculer les aires des triangles $AMN$ et $ABC$, puis vérifier que leur quotient est égal au carré du rapport de réduction.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le parallélisme

::: methode
Réciproque du théorème de Thalès.
:::

::: etape Rapports
$$\frac{AM}{AB} = \frac{4{,}5}{6} = 0{,}75$$

$$\frac{AN}{AC} = \frac{7{,}5}{10} = 0{,}75$$
:::

::: resultat
Les rapports sont égaux et les points sont alignés dans le même ordre : d'après la réciproque du théorème de Thalès, $(MN) \parallel (BC)$.
:::

## Question 2 : Calculer $BC$

::: etape Théorème de Thalès
$$\frac{MN}{BC} = 0{,}75 \quad\text{donc}\quad BC = \frac{6}{0{,}75} = 8$$
:::

::: resultat
$BC = 8$ cm.
:::

## Question 3 : $AMN$ rectangle en $M$

::: methode
Réciproque du théorème de Pythagore : on compare le carré du plus grand côté à la somme des carrés des deux autres.
:::

::: etape Calculs séparés
Le plus grand côté est $[AN]$ :
$$AN^2 = 7{,}5^2 = 56{,}25$$
$$
\begin{aligned}
AM^2 + MN^2 &= 4{,}5^2 + 6^2 \\
&= 20{,}25 + 36 \\
&= 56{,}25
\end{aligned}
$$
:::

::: resultat
$AN^2 = AM^2 + MN^2$ : d'après la réciproque du théorème de Pythagore, $AMN$ est rectangle en $M$.
:::

## Question 4 : $ABC$ rectangle en $B$

::: etape Perpendiculaire et parallèle
$(MN) \perp (AB)$ et $(BC) \parallel (MN)$. Si deux droites sont parallèles, toute droite perpendiculaire à l'une est perpendiculaire à l'autre : $(BC) \perp (AB)$.
:::

[IMAGE_2]

::: resultat
Le triangle $ABC$ est rectangle en $B$. (Contrôle : $6^2 + 8^2 = 100 = 10^2$.)
:::

## Question 5 : Les aires

::: etape Aires des triangles rectangles
$$\mathcal{A}_{AMN} = \frac{4{,}5 \times 6}{2} = 13{,}5 \text{ cm}^2$$

$$\mathcal{A}_{ABC} = \frac{6 \times 8}{2} = 24 \text{ cm}^2$$
:::

::: etape Quotient
$$\frac{13{,}5}{24} = 0{,}5625 = 0{,}75^2$$
:::

::: resultat
Le quotient des aires vaut $0{,}5625$, c'est bien le carré du rapport de réduction $k = 0{,}75$.
:::

::: attention Erreur fréquente
Utiliser $\dfrac{MN}{BC}$ dans la question 1 : $BC$ n'est pas connu et ce rapport ne sert pas pour la réciproque.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{4{,}5}{6} = \dfrac{7{,}5}{10} = 0{,}75$, même ordre : $(MN) \parallel (BC)$.
2. $BC = 8$ cm
3. $7{,}5^2 = 56{,}25 = 4{,}5^2 + 6^2$ : rectangle en $M$.
4. $(BC) \parallel (MN)$ et $(MN) \perp (AB)$, donc $(BC) \perp (AB)$.
5. $13{,}5$ cm² et $24$ cm² ; $\dfrac{13{,}5}{24} = 0{,}5625 = 0{,}75^2$
