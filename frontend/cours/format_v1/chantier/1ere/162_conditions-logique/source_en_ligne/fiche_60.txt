<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Conditions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ Comparaisons : <code>==</code>, <code>!=</code>, <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, <code>&gt;=</code> → <code>True</code> ou <code>False</code>.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle x \in [a\,;b]$ : <code>a &lt;= x and x &lt;= b</code>.</p>
<p style="margin:6px 0 0 0;">3️⃣ Divisibilité : <code>n % d == 0</code>.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Choisir</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ <code>if</code> … <code>elif</code> … <code>else</code> : un seul bloc exécuté.</p>
<p style="margin:6px 0 0 0;">2️⃣ Deux-points en fin de ligne, blocs indentés de 4 espaces.</p>
<p style="margin:6px 0 0 0;">3️⃣ Flottants : <code>abs(x - y) &lt; 1e-9</code> au lieu de <code>x == y</code>.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire <code>=</code> au lieu de <code>==</code> dans un test.</p>
<p style="margin:6px 0 0 0;">2️⃣ Confondre <code>and</code> et <code>or</code> pour un intervalle.</p>
<p style="margin:6px 0 0 0;">3️⃣ Mettre un cas général avant un cas particulier dans une suite d’<code>elif</code>.</p>
<p style="margin:6px 0 0 0;">4️⃣ Tester l’égalité de deux flottants avec <code>==</code>.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je teste ma fonction sur un exemple par branche (chaque <code>if</code>, <code>elif</code> et <code>else</code>).</p>
</div>
