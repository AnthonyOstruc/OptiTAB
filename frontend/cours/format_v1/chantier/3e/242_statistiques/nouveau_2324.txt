Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur 40 réponses à un sondage : 10 choisissent A, 18 choisissent B et 12 choisissent C. On veut représenter ces résultats par un diagramme circulaire.

1. Quel angle représente une réponse dans le diagramme circulaire ?
2. Calculer les trois angles du diagramme.
3. Vérifier que leur somme vaut 360°.
4. Calculer la fréquence de la réponse B en pourcentage.
5. Retrouver l'angle de B à partir de sa fréquence.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'angle d'une réponse

::: methode
Les $40$ réponses se partagent le disque entier, soit $360^\circ$.
:::

::: etape Partager $360^\circ$
$$\frac{360^\circ}{40} = 9^\circ$$
:::

::: resultat
Une réponse est représentée par un angle de $9^\circ$.
:::

## Question 2 : Les trois angles

::: methode
Angle d'un secteur = effectif × angle d'une réponse.
:::

::: etape Calculer chaque angle
- A : $10 \times 9^\circ = 90^\circ$ ;
- B : $18 \times 9^\circ = 162^\circ$ ;
- C : $12 \times 9^\circ = 108^\circ$.
:::

::: resultat
Les angles sont $90^\circ$ (A), $162^\circ$ (B) et $108^\circ$ (C).
:::

## Question 3 : La vérification

::: methode
Les secteurs remplissent tout le disque : la somme des angles doit faire un tour complet.
:::

::: etape Additionner
$$90 + 162 + 108 = 360$$
:::

[IMAGE_1]

::: resultat
La somme vaut bien $360^\circ$ : le diagramme est complet.
:::

## Question 4 : La fréquence de B

::: etape Effectif de B ÷ effectif total
$$\frac{18}{40} = 0{,}45 = \frac{45}{100}$$
:::

::: resultat
La fréquence de B est $45\ \%$.
:::

## Question 5 : L'angle à partir de la fréquence

::: methode
Angle = $360^\circ \times$ fréquence.
:::

::: etape Calculer
$$360^\circ \times 0{,}45 = 162^\circ$$
:::

::: resultat
On retrouve l'angle de B : $162^\circ$, comme à la question 2.
:::

::: attention Erreur fréquente
Prendre l'effectif ou le pourcentage comme angle : l'angle de B n'est ni $18^\circ$ ni $45^\circ$, mais $18 \times 9^\circ = 162^\circ$.
:::

::: retenir
Angle $= 360^\circ \times$ fréquence ; la somme des angles vaut $360^\circ$.
:::

Solution:
<!-- optitab:1 -->
1. $9^\circ$
2. $90^\circ$, $162^\circ$, $108^\circ$
3. $90 + 162 + 108 = 360$
4. $45\ \%$
5. $360^\circ \times 0{,}45 = 162^\circ$
