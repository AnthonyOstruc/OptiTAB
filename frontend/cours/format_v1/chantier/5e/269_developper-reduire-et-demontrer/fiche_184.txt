Titre: Résumé : Développer, réduire et démontrer

<!-- optitab:1 -->
::: objectifs
Retenir l'essentiel : somme ou produit, distributivité simple, réduire, tester une égalité, démontrer ou trouver un contre-exemple.
:::

## I. Somme ou produit

- La **dernière opération** donne la nature : $4x + 2$ est une somme, $4(x + 2)$ est un produit.
- Somme : on additionne des **termes**. Produit : on multiplie des **facteurs**.

## II. Distributivité simple

[IMAGE_1]

::: formule
$$k(a + b) = ka + kb \qquad\qquad k(a - b) = ka - kb$$
:::

- **Développer** (produit → somme) : $3(x + 5) = 3x + 15$ ; $2(4a - 3) = 8a - 6$.
- **Factoriser** (somme → produit) : $5x + 20 = 5(x + 4)$ ; $4x + 4 = 4(x + 1)$.
- **Calcul mental** : $8 \times 103 = 800 + 24 = 824$ ; $45 \times 7 + 45 \times 3 = 45 \times 10 = 450$.

## III. Réduire

- On regroupe les termes en $x$ : $ax + bx = (a + b)x$.
- Exemples : $3x + 5x = 8x$ ; $7x - 2x = 5x$ ; $x + x + x = 3x$ ; $1{,}5x + 0{,}5x = 2x$.
- Avec des nombres seuls, on les regroupe à part : $2a + 3 + 4a = 6a + 3$.
- Développer puis réduire : $2(x + 4) + 3x = 2x + 8 + 3x = 5x + 8$.

## IV. Tester, démontrer, réfuter

- **Tester** une égalité : remplacer la lettre par une valeur, calculer chaque membre séparément.
- **Démontrer** qu'une propriété est toujours vraie : raisonner avec une lettre. Exemple : $2p + 2q = 2(p + q)$, donc la somme de deux nombres pairs est paire.
- **Réfuter** : un seul **contre-exemple** suffit. $2x + 3 = 5x$ est fausse pour $x = 2$ ($7 \neq 10$).

::: attention Les erreurs classiques
1. Oublier de multiplier le second terme : $3(x + 5) \neq 3x + 5$.
2. Réduire ce qui ne se réduit pas : $3x + 5 \neq 8x$.
3. Confondre $x + x = 2x$ et $x \times x = x^2$.
4. Oublier le $1$ en factorisant : $4x + 4 = 4(x + 1)$.
5. Croire que quelques essais réussis prouvent une propriété.
:::
