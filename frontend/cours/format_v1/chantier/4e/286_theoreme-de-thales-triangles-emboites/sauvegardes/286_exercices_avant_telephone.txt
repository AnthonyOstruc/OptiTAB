=== Découverte - Reconnaître des triangles emboîtés
Id: 3629
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur les trois figures, deux segments marqués d'une même petite flèche sont portés par des droites parallèles.

[IMAGE_1]

1. Figure a : sur quels côtés du triangle $ABC$ se trouvent les points $M$ et $N$ ? Que peut-on dire des droites $(MN)$ et $(BC)$ ?
2. Figure a : peut-on appliquer le théorème de Thalès ? Si oui, écrire l'égalité des trois rapports.
3. Figure b : les segments $[PQ]$ et $[FG]$ semblent parallèles. Peut-on appliquer le théorème de Thalès ?
4. Figure c : quel est le sommet commun aux deux triangles emboîtés ? Écrire l'égalité des trois rapports.
5. Écrire les trois conditions à vérifier avant d'utiliser le théorème de Thalès.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les points et les droites de la figure a

::: methode
On regarde sur quels segments sont placés les points, puis on lit le codage.
:::

::: etape La position des points
$M$ est sur le côté $[AB]$ et $N$ est sur le côté $[AC]$ : ce sont les deux côtés qui partent du sommet $A$.
:::

::: etape Le codage
Les segments $[MN]$ et $[BC]$ portent la même petite flèche : les droites qui les portent sont parallèles.
:::

::: resultat
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$.
:::

## Question 2 : Le théorème dans la figure a

::: methode
On vérifie les trois conditions, puis on écrit les rapports « petit triangle sur grand triangle ».
:::

::: etape Les trois conditions
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$ : elles sont toutes réunies.
:::

::: etape Le petit et le grand triangle
Le petit triangle est $AMN$, le grand triangle est $ABC$. Les côtés correspondants sont $[AM]$ et $[AB]$, $[AN]$ et $[AC]$, $[MN]$ et $[BC]$.
:::

::: resultat
Oui. D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

[IMAGE_2]

## Question 3 : La figure b

::: etape Les conditions
$P$ est sur $[EF]$ et $Q$ est sur $[EG]$, mais aucune flèche ni aucune phrase n'indique que $(PQ)$ et $(FG)$ sont parallèles.
:::

::: resultat
Non : le parallélisme n'est ni donné ni démontré, on ne peut pas utiliser le théorème de Thalès.
:::

::: attention Erreur fréquente
Se fier à l'œil. Deux droites peuvent sembler parallèles sur un dessin sans l'être : le parallélisme doit être donné ou démontré.
:::

## Question 4 : La figure c

::: methode
Le sommet commun est l'extrémité commune des deux côtés qui portent les points.
:::

::: etape Le sommet commun
$U$ est sur $[SR]$ et $V$ est sur $[ST]$ : ces deux côtés partent du sommet $S$. De plus, $(UV) \parallel (RT)$.
:::

::: etape Les côtés correspondants
Petit triangle $SUV$, grand triangle $SRT$ : $[SU]$ correspond à $[SR]$, $[SV]$ à $[ST]$, et les côtés parallèles $[UV]$ et $[RT]$ se correspondent.
:::

::: resultat
Le sommet commun est $S$ et, d'après le théorème de Thalès :

$$\frac{SU}{SR} = \frac{SV}{ST} = \frac{UV}{RT}$$
:::

::: retenir
Le sommet commun n'est pas toujours en haut de la figure, et le côté parallèle n'est pas toujours horizontal. On le repère grâce aux deux côtés qui portent les points.
:::

## Question 5 : Les trois conditions

::: resultat
Dans un triangle $ABC$ :

- $M$ est un point du côté $[AB]$ ;
- $N$ est un point du côté $[AC]$ ;
- les droites $(MN)$ et $(BC)$ sont parallèles.
:::

Solution:
<!-- optitab:1 -->
1. $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$.
2. Oui : $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$.
3. Non : le parallélisme de $(PQ)$ et $(FG)$ n'est pas donné.
4. Sommet $S$ : $\dfrac{SU}{SR} = \dfrac{SV}{ST} = \dfrac{UV}{RT}$.
5. $M \in [AB]$, $N \in [AC]$, $(MN) \parallel (BC)$.

=== Découverte - Nommer les triangles et écrire les rapports
Id: 3630
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $U$ est un point de $[RS]$, $V$ est un point de $[RT]$ et les droites $(UV)$ et $(ST)$ sont parallèles.

[IMAGE_1]

1. Quel est le sommet commun aux deux triangles emboîtés ?
2. Quel est le petit triangle ? Quel est le grand triangle ?
3. Recopier et compléter : $[RU]$ correspond à …, $[RV]$ correspond à …, $[UV]$ correspond à … .
4. Écrire l'égalité des trois rapports.
5. On donne $RU = 2$ cm, $RS = 5$ cm et $RV = 3$ cm. Quels rapports faut-il utiliser pour calculer $RT$ ?
6. Calculer $RT$, puis $VT$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le sommet commun

::: etape
Les points $U$ et $V$ sont sur les côtés $[RS]$ et $[RT]$, qui partent tous les deux du point $R$.
:::

::: resultat
Le sommet commun est $R$.
:::

## Question 2 : Les deux triangles

::: etape
La parallèle $(UV)$ découpe un petit triangle près du sommet $R$ ; le grand triangle a pour troisième côté $[ST]$.
:::

::: resultat
Le petit triangle est $RUV$, le grand triangle est $RST$.
:::

## Question 3 : Les côtés correspondants

::: methode
Deux côtés se correspondent s'ils sont sur la même droite issue de $R$, ou s'ils sont parallèles.
:::

::: etape
$[RU]$ et $[RS]$ sont sur la droite $(RS)$ ; $[RV]$ et $[RT]$ sont sur la droite $(RT)$ ; $[UV]$ et $[ST]$ sont parallèles.
:::

::: resultat
$[RU]$ correspond à $[RS]$, $[RV]$ correspond à $[RT]$ et $[UV]$ correspond à $[ST]$.
:::

## Question 4 : L'égalité des rapports

::: methode
En haut, les côtés du petit triangle $RUV$ ; en bas, les côtés correspondants du grand triangle $RST$.
:::

::: resultat
D'après le théorème de Thalès :

$$\frac{RU}{RS} = \frac{RV}{RT} = \frac{UV}{ST}$$
:::

::: retenir
Chaque rapport compare deux côtés correspondants : le côté du petit triangle en haut, celui du grand triangle en bas, toujours dans le même ordre.
:::

## Question 5 : Le choix des rapports

::: methode
On garde le rapport entièrement connu et le rapport qui contient la longueur cherchée.
:::

::: etape
$\dfrac{RU}{RS} = \dfrac{2}{5}$ est entièrement connu ; $\dfrac{RV}{RT}$ contient $RT$. Le rapport $\dfrac{UV}{ST}$ ne sert pas : on ne connaît ni $UV$ ni $ST$.
:::

::: resultat
$$\frac{RU}{RS} = \frac{RV}{RT} \quad\text{soit}\quad \frac{2}{5} = \frac{3}{RT}$$
:::

## Question 6 : Les longueurs $RT$ et $VT$

::: etape Le produit en croix
$$2 \times RT = 5 \times 3 \quad\text{donc}\quad RT = \frac{5 \times 3}{2} = \frac{15}{2} = 7{,}5$$
:::

::: etape La longueur $VT$
$V$ est sur $[RT]$, donc $VT = RT - RV = 7{,}5 - 3 = 4{,}5$.
:::

::: resultat
$RT = 7{,}5$ cm et $VT = 4{,}5$ cm.
:::

[IMAGE_2]

::: attention Erreur fréquente
Écrire $RT = \dfrac{2 \times 3}{5} = 1{,}2$ cm en multipliant les mauvais nombres. Contrôle : $RT$ est un côté du grand triangle, il doit être plus long que $RV = 3$ cm.
:::

Solution:
<!-- optitab:1 -->
1. $R$
2. Petit triangle $RUV$, grand triangle $RST$.
3. $[RS]$, $[RT]$, $[ST]$
4. $\dfrac{RU}{RS} = \dfrac{RV}{RT} = \dfrac{UV}{ST}$
5. $\dfrac{2}{5} = \dfrac{3}{RT}$
6. $RT = 7{,}5$ cm ; $VT = 4{,}5$ cm

=== Découverte - Un premier calcul de longueur
Id: 3631
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On donne $AM = 3$ cm, $AB = 5$ cm, $AC = 10$ cm et $BC = 8$ cm.

[IMAGE_1]

1. Justifier que l'on peut utiliser le théorème de Thalès.
2. Écrire l'égalité des trois rapports, puis remplacer par les longueurs connues.
3. Calculer $AN$.
4. Calculer $MN$.
5. Calculer $NC$.
6. Calculer $\dfrac{AN}{AC}$ et $\dfrac{MN}{BC}$. Que remarque-t-on ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La justification

::: etape Les trois conditions
$M$ est sur $[AB]$, $N$ est sur $[AC]$, et les droites $(MN)$ et $(BC)$ sont parallèles (énoncé et codage).
:::

::: resultat
Les trois conditions sont réunies : on peut appliquer le théorème de Thalès dans le triangle $ABC$.
:::

## Question 2 : L'égalité des rapports

::: etape L'égalité
$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

::: resultat
$$\frac{3}{5} = \frac{AN}{10} = \frac{MN}{8}$$
:::

## Question 3 : La longueur $AN$

::: methode
On garde $\dfrac{3}{5} = \dfrac{AN}{10}$ et on fait un produit en croix.
:::

::: etape Le produit en croix
$$AN = \frac{3 \times 10}{5} = \frac{30}{5} = 6$$
:::

::: resultat
$AN = 6$ cm.
:::

::: retenir La rédaction modèle
Dans le triangle $ABC$, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès, $\dfrac{AM}{AB} = \dfrac{AN}{AC}$, donc $\dfrac{3}{5} = \dfrac{AN}{10}$ et $AN = \dfrac{3 \times 10}{5} = 6$ cm.
:::

## Question 4 : La longueur $MN$

::: methode
On garde cette fois $\dfrac{3}{5} = \dfrac{MN}{8}$.
:::

::: etape Le produit en croix
$$MN = \frac{3 \times 8}{5} = \frac{24}{5} = 4{,}8$$
:::

::: resultat
$MN = 4{,}8$ cm.
:::

[IMAGE_2]

## Question 5 : La longueur $NC$

::: etape
$N$ est sur le segment $[AC]$, donc $NC = AC - AN = 10 - 6 = 4$.
:::

::: resultat
$NC = 4$ cm.
:::

::: attention Erreur fréquente
Chercher $NC$ directement avec le théorème : $NC$ n'apparaît dans aucun rapport. On calcule d'abord $AN$, puis on soustrait.
:::

## Question 6 : Les rapports

::: etape Les deux quotients
$$\frac{AN}{AC} = \frac{6}{10} = 0{,}6$$

$$\frac{MN}{BC} = \frac{4{,}8}{8} = 0{,}6$$
:::

::: resultat
Les deux rapports sont égaux à $\dfrac{AM}{AB} = \dfrac{3}{5} = 0{,}6$ : c'est exactement ce qu'affirme le théorème de Thalès.
:::

::: retenir
Ce nombre commun $0{,}6$ est le coefficient de réduction : chaque côté du petit triangle mesure $0{,}6$ fois le côté correspondant du grand.
:::

Solution:
<!-- optitab:1 -->
1. $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$.
2. $\dfrac{3}{5} = \dfrac{AN}{10} = \dfrac{MN}{8}$
3. $AN = 6$ cm
4. $MN = 4{,}8$ cm
5. $NC = 4$ cm
6. Les deux rapports valent $0{,}6$, comme $\dfrac{AM}{AB}$.

=== Découverte - Le coefficient de réduction
Id: 3632
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On donne $AM = 4$ cm, $AB = 10$ cm, $AC = 12$ cm et $BC = 15$ cm.

[IMAGE_1]

1. Calculer le coefficient $k = \dfrac{AM}{AB}$.
2. Que représente ce coefficient pour les triangles $AMN$ et $ABC$ ?
3. Calculer $AN$ à l'aide de $k$.
4. Calculer $MN$ à l'aide de $k$.
5. Calculer le périmètre du triangle $ABC$ et celui du triangle $AMN$. Vérifier que le périmètre de $AMN$ est égal à $k$ fois celui de $ABC$.
6. Par quel nombre faut-il multiplier les longueurs du triangle $AMN$ pour obtenir celles du triangle $ABC$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le coefficient

::: etape Le quotient
$$k = \frac{AM}{AB} = \frac{4}{10} = 0{,}4$$
:::

::: resultat
$k = 0{,}4$.
:::

## Question 2 : Le sens du coefficient

::: etape Le théorème de Thalès
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$, donc $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC} = 0{,}4$.
:::

::: resultat
Le triangle $AMN$ est une réduction du triangle $ABC$ de coefficient $0{,}4$ : chaque côté de $AMN$ mesure $0{,}4$ fois le côté correspondant de $ABC$.
:::

::: retenir
Un coefficient plus petit que $1$ correspond à une réduction ; un coefficient plus grand que $1$, à un agrandissement.
:::

## Question 3 : La longueur $AN$

::: methode
$\dfrac{AN}{AC} = k$, donc $AN = k \times AC$.
:::

::: etape
$AN = 0{,}4 \times 12 = 4{,}8$.
:::

::: resultat
$AN = 4{,}8$ cm.
:::

## Question 4 : La longueur $MN$

::: etape
$\dfrac{MN}{BC} = k$, donc $MN = 0{,}4 \times 15 = 6$.
:::

::: resultat
$MN = 6$ cm.
:::

[IMAGE_2]

## Question 5 : Les périmètres

::: etape Périmètre de $ABC$
$10 + 12 + 15 = 37$ cm.
:::

::: etape Périmètre de $AMN$
$4 + 4{,}8 + 6 = 14{,}8$ cm.
:::

::: etape Vérification
$0{,}4 \times 37 = 14{,}8$.
:::

::: resultat
Les périmètres valent $37$ cm et $14{,}8$ cm, et on a bien $14{,}8 = 0{,}4 \times 37$.
:::

::: retenir
Chaque côté est multiplié par $0{,}4$, donc leur somme aussi : dans une réduction, le périmètre est multiplié par le même coefficient que les longueurs.
:::

## Question 6 : L'agrandissement

::: methode
Pour revenir du petit triangle au grand, on cherche le nombre par lequel multiplier $AM$ pour obtenir $AB$.
:::

::: etape Le coefficient d'agrandissement
$$\frac{AB}{AM} = \frac{10}{4} = 2{,}5$$
:::

::: etape Vérification
$4{,}8 \times 2{,}5 = 12 = AC$ et $6 \times 2{,}5 = 15 = BC$.
:::

::: resultat
On multiplie par $2{,}5$ : le triangle $ABC$ est un agrandissement du triangle $AMN$ de coefficient $2{,}5$.
:::

::: attention Erreur fréquente
Croire que l'on revient au grand triangle en multipliant encore par $0{,}4$, ou en ajoutant un nombre. On multiplie par $\dfrac{1}{0{,}4} = 2{,}5$.
:::

Solution:
<!-- optitab:1 -->
1. $k = 0{,}4$
2. $AMN$ est une réduction de $ABC$ de coefficient $0{,}4$.
3. $AN = 4{,}8$ cm
4. $MN = 6$ cm
5. $37$ cm et $14{,}8$ cm ; $0{,}4 \times 37 = 14{,}8$.
6. Par $2{,}5$.

=== Découverte - Reconstituer un côté entier
Id: 3633
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On donne $AM = 4$ cm, $MB = 6$ cm, $AN = 6$ cm et $MN = 5$ cm.

[IMAGE_1]

1. Calculer $AB$.
2. Écrire l'égalité des trois rapports avec les longueurs connues.
3. Calculer $AC$.
4. Calculer $NC$.
5. Calculer $BC$.
6. Léo a écrit : « $\dfrac{AM}{MB} = \dfrac{MN}{BC}$ ». Expliquer son erreur et ce qu'elle donnerait pour $BC$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le côté $AB$

::: methode
Le point $M$ partage le côté $[AB]$ en deux morceaux : on les additionne.
:::

::: etape
$AB = AM + MB = 4 + 6 = 10$.
:::

::: resultat
$AB = 10$ cm.
:::

## Question 2 : L'égalité des rapports

::: etape
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

::: resultat
$$\frac{4}{10} = \frac{6}{AC} = \frac{5}{BC}$$
:::

## Question 3 : La longueur $AC$

::: methode
Produit en croix avec $\dfrac{4}{10} = \dfrac{6}{AC}$.
:::

::: etape
$$4 \times AC = 10 \times 6 \quad\text{donc}\quad AC = \frac{60}{4} = 15$$
:::

::: resultat
$AC = 15$ cm.
:::

## Question 4 : La longueur $NC$

::: etape
$NC = AC - AN = 15 - 6 = 9$.
:::

::: resultat
$NC = 9$ cm.
:::

## Question 5 : La longueur $BC$

::: etape
$$\frac{4}{10} = \frac{5}{BC} \quad\text{donc}\quad BC = \frac{10 \times 5}{4} = \frac{50}{4} = 12{,}5$$
:::

::: resultat
$BC = 12{,}5$ cm.
:::

[IMAGE_2]

## Question 6 : L'erreur de Léo

::: etape L'erreur
Dans le théorème, chaque dénominateur est un côté entier du grand triangle : $AB$, $AC$ ou $BC$. Léo a mis le morceau $MB$ à la place de $AB$.
:::

::: etape Ce que donnerait son égalité
$$\frac{4}{6} = \frac{5}{BC} \quad\text{donc}\quad BC = \frac{6 \times 5}{4} = 7{,}5$$
:::

::: resultat
Léo aurait dû écrire $\dfrac{AM}{AB} = \dfrac{MN}{BC}$. Son égalité donne $BC = 7{,}5$ cm au lieu de $12{,}5$ cm : le résultat est faux.
:::

::: attention Erreur fréquente
Quand l'énoncé donne $AM$ et $MB$, le réflexe est de calculer d'abord le côté entier $AB = AM + MB$, avant d'écrire les rapports.
:::

Solution:
<!-- optitab:1 -->
1. $AB = 10$ cm
2. $\dfrac{4}{10} = \dfrac{6}{AC} = \dfrac{5}{BC}$
3. $AC = 15$ cm
4. $NC = 9$ cm
5. $BC = 12{,}5$ cm
6. Il a mis $MB$ au lieu de $AB$ ; il trouverait $7{,}5$ cm au lieu de $12{,}5$ cm.

=== Découverte - Compléter un tableau de proportionnalité
Id: 3634
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On a rangé les longueurs connues, en cm, dans un tableau.

[IMAGE_1]

| Triangle | sur $(AB)$ | sur $(AC)$ | parallèle |
|---|---|---|---|
| $AMN$ | $AM = 2$ | $AN = \ldots$ | $MN = \ldots$ |
| $ABC$ | $AB = 8$ | $AC = 6$ | $BC = 9$ |

1. Pourquoi les longueurs du triangle $AMN$ sont-elles proportionnelles à celles du triangle $ABC$ ?
2. Par quel nombre faut-il multiplier la ligne du triangle $ABC$ pour obtenir celle du triangle $AMN$ ?
3. Calculer $AN$ et $MN$, puis recopier le tableau complété.
4. Par quel nombre faut-il multiplier la ligne du triangle $AMN$ pour obtenir celle du triangle $ABC$ ? Vérifier avec $AN$.
5. On déplace $M$ sur $[AB]$ pour avoir $AM = 6$ cm, en gardant $(MN) \parallel (BC)$. Calculer les nouvelles longueurs $AN$ et $MN$.

Étapes:
<!-- optitab:1 -->
## Question 1 : La proportionnalité

::: etape
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès : $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$.
:::

::: resultat
Les trois quotients sont égaux : les longueurs du triangle $AMN$ sont proportionnelles à celles du triangle $ABC$, d'après le théorème de Thalès.
:::

## Question 2 : Le coefficient

::: methode
Dans la première colonne, les deux longueurs sont connues.
:::

::: etape
$$\frac{AM}{AB} = \frac{2}{8} = 0{,}25$$
:::

::: resultat
On multiplie la ligne de $ABC$ par $0{,}25$.
:::

## Question 3 : Les longueurs $AN$ et $MN$

::: etape La longueur $AN$
$AN = 0{,}25 \times 6 = 1{,}5$.
:::

::: etape La longueur $MN$
$MN = 0{,}25 \times 9 = 2{,}25$.
:::

::: resultat
$AN = 1{,}5$ cm et $MN = 2{,}25$ cm.

| Triangle | sur $(AB)$ | sur $(AC)$ | parallèle |
|---|---|---|---|
| $AMN$ | $2$ | $1{,}5$ | $2{,}25$ |
| $ABC$ | $8$ | $6$ | $9$ |
:::

[IMAGE_2]

## Question 4 : Le coefficient inverse

::: etape
$$\frac{AB}{AM} = \frac{8}{2} = 4$$
:::

::: etape Vérification
$AN \times 4 = 1{,}5 \times 4 = 6 = AC$.
:::

::: resultat
On multiplie la ligne de $AMN$ par $4$ : le triangle $ABC$ est un agrandissement de $AMN$ de coefficient $4$.
:::

::: retenir
Pour passer du petit triangle au grand, on multiplie par l'inverse du coefficient de réduction : ici $\dfrac{1}{0{,}25} = 4$.
:::

## Question 5 : Une nouvelle position de $M$

::: etape Le nouveau coefficient
$$\frac{AM}{AB} = \frac{6}{8} = 0{,}75$$
:::

::: etape Les nouvelles longueurs
$AN = 0{,}75 \times 6 = 4{,}5$ et $MN = 0{,}75 \times 9 = 6{,}75$.
:::

::: resultat
$AN = 4{,}5$ cm et $MN = 6{,}75$ cm.
:::

::: attention Erreur fréquente
Garder l'ancien coefficient $0{,}25$ : dès que $M$ bouge, le coefficient $\dfrac{AM}{AB}$ change et il faut le recalculer.
:::

Solution:
<!-- optitab:1 -->
1. Théorème de Thalès : $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$.
2. Par $0{,}25$.
3. $AN = 1{,}5$ cm ; $MN = 2{,}25$ cm.
4. Par $4$ : $1{,}5 \times 4 = 6$.
5. $AN = 4{,}5$ cm ; $MN = 6{,}75$ cm.

=== Découverte - Choisir les bons rapports
Id: 3635
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la figure, $H$ est un point de $[EF]$, $K$ est un point de $[EG]$ et les droites $(HK)$ et $(FG)$ sont parallèles.

[IMAGE_1]

1. Quel est le sommet commun ? Quel est le petit triangle ? Quel est le grand triangle ?
2. Pour chaque égalité, dire si elle est juste ou fausse, en justifiant.
   - a) $\dfrac{EH}{EF} = \dfrac{EK}{EG}$
   - b) $\dfrac{EH}{HF} = \dfrac{HK}{FG}$
   - c) $\dfrac{HK}{FG} = \dfrac{EK}{EG}$
   - d) $\dfrac{EH}{EF} = \dfrac{HK}{EG}$
   - e) $\dfrac{EF}{EH} = \dfrac{FG}{HK}$
   - f) $\dfrac{EH}{EF} = \dfrac{EG}{EK}$
3. On donne $EH = 3$ cm, $EF = 5$ cm et $FG = 6$ cm. Choisir une égalité juste, puis calculer $HK$.
4. On donne aussi $EG = 7$ cm. Calculer $EK$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les deux triangles

::: etape
$H$ et $K$ sont sur les côtés $[EF]$ et $[EG]$, qui partent du sommet $E$.
:::

::: resultat
Le sommet commun est $E$ ; le petit triangle est $EHK$, le grand triangle est $EFG$. D'après le théorème de Thalès :

$$\frac{EH}{EF} = \frac{EK}{EG} = \frac{HK}{FG}$$
:::

## Question 2 : Juste ou fausse ?

::: methode
Une égalité est juste si chaque rapport compare deux côtés correspondants, avec le même triangle en haut dans les deux rapports.
:::

::: etape a) et c) : justes
Ce sont deux des trois rapports de Thalès : petit triangle en haut, côté correspondant du grand triangle en bas.
:::

::: etape b) : fausse
$HF$ n'est pas un côté du grand triangle : c'est un morceau du côté $[EF]$. Le dénominateur doit être le côté entier $EF$.
:::

::: etape d) : fausse
$[HK]$ correspond au côté parallèle $[FG]$, pas à $[EG]$.
:::

::: etape e) : juste
Les deux rapports de Thalès $\dfrac{EH}{EF}$ et $\dfrac{HK}{FG}$ ont été retournés tous les deux : le grand triangle est en haut dans les deux rapports. Deux fractions égales ont des inverses égaux.
:::

::: etape f) : fausse
Le petit triangle est en haut dans le premier rapport et en bas dans le second : on mélange les deux triangles.
:::

::: resultat
Justes : a), c) et e). Fausses : b), d) et f).
:::

::: attention Erreur fréquente
Retourner un seul rapport, comme dans f). On peut retourner tous les rapports, jamais un seul.
:::

## Question 3 : La longueur $HK$

::: methode
On garde le rapport entièrement connu $\dfrac{EH}{EF}$ et celui qui contient $HK$.
:::

::: etape
$$\frac{EH}{EF} = \frac{HK}{FG} \quad\text{donc}\quad \frac{3}{5} = \frac{HK}{6}$$
:::

::: etape Le produit en croix
$$HK = \frac{3 \times 6}{5} = \frac{18}{5} = 3{,}6$$
:::

::: resultat
$HK = 3{,}6$ cm.
:::

## Question 4 : La longueur $EK$

::: etape
$$\frac{EH}{EF} = \frac{EK}{EG} \quad\text{donc}\quad \frac{3}{5} = \frac{EK}{7}$$
:::

::: etape Le produit en croix
$$EK = \frac{3 \times 7}{5} = \frac{21}{5} = 4{,}2$$
:::

::: resultat
$EK = 4{,}2$ cm.
:::

[IMAGE_2]

Solution:
<!-- optitab:1 -->
1. Sommet $E$ ; petit triangle $EHK$, grand triangle $EFG$.
2. Justes : a), c), e). Fausses : b), d), f).
3. $HK = 3{,}6$ cm
4. $EK = 4{,}2$ cm

=== Entraînement - L'ombre d'un arbre
Id: 3636
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
À un moment de la journée, un bâton vertical $[BM]$ de $1{,}5$ m a une ombre $[SB]$ de $2$ m. On a placé le bâton pour que l'extrémité $S$ de son ombre soit aussi celle de l'ombre $[SC]$ d'un arbre vertical $[CN]$ ; cette ombre $[SC]$ mesure $12$ m. Les points $S$, $B$, $C$ sont alignés sur le sol horizontal ; les points $S$, $M$, $N$ sont alignés sur un rayon de soleil.

[IMAGE_1]

1. Pourquoi les droites $(BM)$ et $(CN)$ sont-elles parallèles ?
2. Quels sont les deux triangles emboîtés ? Quel est leur sommet commun ?
3. Écrire l'égalité des trois rapports.
4. Calculer la hauteur $CN$ de l'arbre.
5. Le triangle $SBM$ est rectangle en $B$. Calculer $SM$.
6. En déduire la longueur $SN$ du rayon de soleil entre le sol et le sommet de l'arbre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les parallèles

::: methode
On cherche une droite à laquelle les deux droites sont perpendiculaires.
:::

::: etape
Le bâton et l'arbre sont verticaux, et le sol est horizontal : les droites $(BM)$ et $(CN)$ sont toutes les deux perpendiculaires à la droite $(SC)$.
:::

::: resultat
Deux droites perpendiculaires à une même droite sont parallèles : $(BM) \parallel (CN)$.
:::

::: retenir
C'est le réflexe des problèmes concrets : des objets verticaux (bâton, arbre, poteau, mur) sont parallèles entre eux.
:::

## Question 2 : Les deux triangles

::: etape
$B$ est sur $[SC]$ et $M$ est sur $[SN]$ : les deux côtés $[SC]$ et $[SN]$ partent du point $S$.
:::

::: resultat
Le petit triangle $SBM$ est emboîté dans le grand triangle $SCN$ ; leur sommet commun est $S$.
:::

## Question 3 : L'égalité des rapports

::: methode
En haut le petit triangle $SBM$, en bas le grand triangle $SCN$, côté par côté.
:::

::: resultat
$B \in [SC]$, $M \in [SN]$ et $(BM) \parallel (CN)$. D'après le théorème de Thalès :

$$\frac{SB}{SC} = \frac{SM}{SN} = \frac{BM}{CN}$$
:::

## Question 4 : La hauteur de l'arbre

::: etape On remplace
$$\frac{SB}{SC} = \frac{BM}{CN} \quad\text{donc}\quad \frac{2}{12} = \frac{1{,}5}{CN}$$
:::

::: etape Le produit en croix
$$CN = \frac{12 \times 1{,}5}{2} = \frac{18}{2} = 9$$
:::

::: resultat
L'arbre mesure $9$ m.
:::

::: attention Erreur fréquente
Écrire $\dfrac{2}{12} = \dfrac{CN}{1{,}5}$ en mettant l'arbre en haut : le petit triangle (le bâton) doit être en haut dans les deux rapports. Contrôle : l'arbre est plus haut que le bâton.
:::

## Question 5 : La longueur $SM$

::: methode
Théorème de Pythagore dans le triangle $SBM$ rectangle en $B$ : l'hypoténuse est $[SM]$.
:::

::: etape
$$SM^2 = SB^2 + BM^2 = 2^2 + 1{,}5^2 = 4 + 2{,}25 = 6{,}25$$
:::

::: resultat
$SM = \sqrt{6{,}25} = 2{,}5$ m.
:::

## Question 6 : La longueur $SN$

::: etape On remplace
$$\frac{SB}{SC} = \frac{SM}{SN} \quad\text{donc}\quad \frac{2}{12} = \frac{2{,}5}{SN}$$
:::

::: etape Le produit en croix
$$SN = \frac{12 \times 2{,}5}{2} = \frac{30}{2} = 15$$
:::

::: resultat
$SN = 15$ m.
:::

[IMAGE_2]

::: point Vérification
Le triangle $SCN$ est rectangle en $C$ : $SC^2 + CN^2 = 144 + 81 = 225 = 15^2$.
:::

Solution:
<!-- optitab:1 -->
1. $(BM)$ et $(CN)$ sont perpendiculaires au sol $(SC)$.
2. $SBM$ et $SCN$, de sommet commun $S$.
3. $\dfrac{SB}{SC} = \dfrac{SM}{SN} = \dfrac{BM}{CN}$
4. $CN = 9$ m
5. $SM = 2{,}5$ m
6. $SN = 15$ m

=== Entraînement - Des longueurs décimales
Id: 3637
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On donne $AM = 2{,}4$ cm, $AB = 6$ cm, $AN = 3$ cm et $MN = 3{,}2$ cm.

[IMAGE_1]

1. Calculer le coefficient de réduction $k = \dfrac{AM}{AB}$.
2. Calculer $AC$.
3. Calculer $BC$.
4. Calculer $MB$ et $NC$.
5. Calculer le périmètre du quadrilatère $MBCN$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le coefficient

::: etape
$$k = \frac{AM}{AB} = \frac{2{,}4}{6} = 0{,}4$$
:::

::: resultat
$k = 0{,}4$ : chaque côté du triangle $AMN$ mesure $0{,}4$ fois le côté correspondant de $ABC$.
:::

## Question 2 : La longueur $AC$

::: methode
$M \in [AB]$, $N \in [AC]$, $(MN) \parallel (BC)$ : d'après le théorème de Thalès, $\dfrac{AM}{AB} = \dfrac{AN}{AC}$.
:::

::: etape On remplace
$$\frac{2{,}4}{6} = \frac{3}{AC}$$
:::

::: etape Le produit en croix
$$AC = \frac{6 \times 3}{2{,}4} = \frac{18}{2{,}4} = 7{,}5$$
:::

::: resultat
$AC = 7{,}5$ cm.
:::

::: point Vérification
$k \times AC = 0{,}4 \times 7{,}5 = 3 = AN$.
:::

## Question 3 : La longueur $BC$

::: etape On remplace
$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{2{,}4}{6} = \frac{3{,}2}{BC}$$
:::

::: etape Le produit en croix
$$BC = \frac{6 \times 3{,}2}{2{,}4} = \frac{19{,}2}{2{,}4} = 8$$
:::

::: resultat
$BC = 8$ cm.
:::

::: attention Erreur fréquente
Multiplier $MN$ par $k$ : $0{,}4 \times 3{,}2 = 1{,}28$. On cherche un côté du **grand** triangle, il doit être plus long que $MN$ : on divise par $k$, ou on fait le produit en croix.
:::

## Question 4 : Les longueurs $MB$ et $NC$

::: etape La longueur $MB$
$MB = AB - AM = 6 - 2{,}4 = 3{,}6$.
:::

::: etape La longueur $NC$
$NC = AC - AN = 7{,}5 - 3 = 4{,}5$.
:::

::: resultat
$MB = 3{,}6$ cm et $NC = 4{,}5$ cm.
:::

## Question 5 : Le périmètre de $MBCN$

::: methode
Le périmètre est la somme des longueurs des quatre côtés $[MB]$, $[BC]$, $[CN]$ et $[NM]$.
:::

::: etape
$$MB + BC + CN + NM = 3{,}6 + 8 + 4{,}5 + 3{,}2 = 19{,}3$$
:::

::: resultat
Le périmètre du quadrilatère $MBCN$ est $19{,}3$ cm.
:::

[IMAGE_2]

::: retenir
Le côté $[MN]$ appartient à la fois au petit triangle et au quadrilatère $MBCN$ : il compte dans les deux périmètres.
:::

Solution:
<!-- optitab:1 -->
1. $k = 0{,}4$
2. $AC = 7{,}5$ cm
3. $BC = 8$ cm
4. $MB = 3{,}6$ cm ; $NC = 4{,}5$ cm
5. $19{,}3$ cm

=== Entraînement - Deux parallèles dans un triangle
Id: 3638
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M$ et $P$ sont sur $[AB]$, $N$ et $Q$ sont sur $[AC]$, et les droites $(MN)$, $(PQ)$ et $(BC)$ sont parallèles. On donne $AM = 2$ cm, $MP = 3$ cm, $PB = 3$ cm, $AN = 3$ cm et $MN = 2{,}5$ cm.

[IMAGE_1]

1. Calculer $AP$ et $AB$.
2. Écrire l'égalité des trois rapports dans le triangle $ABC$ avec la parallèle $(MN)$.
3. Calculer $AC$.
4. Calculer $BC$.
5. En utilisant la parallèle $(PQ)$, calculer $AQ$ et $PQ$.
6. Calculer $NQ$ et $QC$. Que remarque-t-on ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les longueurs $AP$ et $AB$

::: etape
$AP = AM + MP = 2 + 3 = 5$ et $AB = AP + PB = 5 + 3 = 8$.
:::

::: resultat
$AP = 5$ cm et $AB = 8$ cm.
:::

## Question 2 : L'égalité avec $(MN)$

::: etape
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

::: resultat
$$\frac{2}{8} = \frac{3}{AC} = \frac{2{,}5}{BC}$$
:::

## Question 3 : La longueur $AC$

::: etape
$$AC = \frac{8 \times 3}{2} = \frac{24}{2} = 12$$
:::

::: resultat
$AC = 12$ cm.
:::

## Question 4 : La longueur $BC$

::: etape
$$BC = \frac{8 \times 2{,}5}{2} = \frac{20}{2} = 10$$
:::

::: resultat
$BC = 10$ cm.
:::

## Question 5 : Avec la parallèle $(PQ)$

::: methode
Nouvelle configuration dans le même triangle : $P \in [AB]$, $Q \in [AC]$ et $(PQ) \parallel (BC)$.
:::

::: etape L'égalité
$$\frac{AP}{AB} = \frac{AQ}{AC} = \frac{PQ}{BC}$$

On remplace par les longueurs connues :

$$\frac{5}{8} = \frac{AQ}{12} = \frac{PQ}{10}$$
:::

::: etape Les produits en croix
$$AQ = \frac{5 \times 12}{8} = 7{,}5$$

$$PQ = \frac{5 \times 10}{8} = 6{,}25$$
:::

::: resultat
$AQ = 7{,}5$ cm et $PQ = 6{,}25$ cm.
:::

::: attention Erreur fréquente
Écrire $\dfrac{MP}{AB}$ ou $\dfrac{3}{8}$ : les rapports partent toujours du sommet commun $A$, donc on utilise $AP = 5$ cm.
:::

## Question 6 : Les longueurs $NQ$ et $QC$

::: etape
$NQ = AQ - AN = 7{,}5 - 3 = 4{,}5$ et $QC = AC - AQ = 12 - 7{,}5 = 4{,}5$.
:::

::: resultat
$NQ = QC = 4{,}5$ cm : comme $MP = PB$, les parallèles découpent aussi $[NC]$ en deux segments de même longueur.
:::

[IMAGE_2]

::: retenir
Une même figure peut contenir plusieurs configurations de Thalès : on précise toujours quelle parallèle on utilise.
:::

Solution:
<!-- optitab:1 -->
1. $AP = 5$ cm ; $AB = 8$ cm
2. $\dfrac{2}{8} = \dfrac{3}{AC} = \dfrac{2{,}5}{BC}$
3. $AC = 12$ cm
4. $BC = 10$ cm
5. $AQ = 7{,}5$ cm ; $PQ = 6{,}25$ cm
6. $NQ = QC = 4{,}5$ cm

=== Entraînement - La charpente d'un toit
Id: 3639
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La coupe d'un toit est un triangle $ABC$ isocèle en $A$, avec $AB = AC = 6$ m et $BC = 9$ m. Une poutre $[MN]$ relie les deux pentes, avec $M \in [AB]$, $N \in [AC]$ et $AM = 2$ m. La poutre $[MN]$ et le haut du mur $[BC]$ sont horizontaux.

[IMAGE_1]

1. Pourquoi les droites $(MN)$ et $(BC)$ sont-elles parallèles ?
2. Calculer la longueur $MN$ de la poutre.
3. Calculer $AN$, puis $MB$.
4. $H$ est le milieu de $[BC]$ et $(AH)$ est perpendiculaire à $(BC)$. Calculer la hauteur $AH$ du toit, arrondie au centième.
5. La droite $(AH)$ coupe $[MN]$ en $K$. Avec le théorème de Thalès dans le triangle $ABH$, calculer $AK$, puis la hauteur $KH$ de la poutre au-dessus du mur, arrondies au centième.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les parallèles

::: etape
La poutre et le haut du mur sont horizontaux, et ils sont dans le même plan vertical (celui de la coupe).
:::

::: resultat
Les droites $(MN)$ et $(BC)$ sont parallèles.
:::

## Question 2 : La longueur de la poutre

::: methode
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$ : théorème de Thalès dans le triangle $ABC$.
:::

::: etape On remplace
$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{2}{6} = \frac{MN}{9}$$
:::

::: etape Le produit en croix
$$MN = \frac{2 \times 9}{6} = \frac{18}{6} = 3$$
:::

::: resultat
La poutre mesure $3$ m.
:::

## Question 3 : Les longueurs $AN$ et $MB$

::: etape La longueur $AN$
$$\frac{AM}{AB} = \frac{AN}{AC} \quad\text{donc}\quad \frac{2}{6} = \frac{AN}{6} \quad\text{et}\quad AN = 2$$
:::

::: etape La longueur $MB$
$MB = AB - AM = 6 - 2 = 4$.
:::

::: resultat
$AN = 2$ m et $MB = 4$ m.
:::

::: retenir
Le petit triangle $AMN$ est une réduction du triangle isocèle $ABC$ : il est lui aussi isocèle en $A$.
:::

## Question 4 : La hauteur $AH$

::: methode
Théorème de Pythagore dans le triangle $ABH$ rectangle en $H$, avec $BH = 9 \div 2 = 4{,}5$ m.
:::

::: etape
$$AH^2 = AB^2 - BH^2 = 6^2 - 4{,}5^2 = 36 - 20{,}25 = 15{,}75$$
:::

::: resultat
$AH = \sqrt{15{,}75} \approx 3{,}97$ m.
:::

## Question 5 : La hauteur de la poutre

::: methode
Dans le triangle $ABH$ : $M \in [AB]$, $K \in [AH]$ et $(MK) \parallel (BH)$, car $(MN) \parallel (BC)$.
:::

::: etape Le théorème de Thalès dans $ABH$
$$\frac{AM}{AB} = \frac{AK}{AH} \quad\text{donc}\quad \frac{2}{6} = \frac{AK}{\sqrt{15{,}75}}$$
:::

::: etape Les longueurs $AK$ et $KH$
$$AK = \frac{\sqrt{15{,}75}}{3} \approx 1{,}32$$

$$KH = AH - AK \approx 2{,}65$$
:::

::: resultat
$AK \approx 1{,}32$ m : la poutre est à environ $2{,}65$ m au-dessus du mur.
:::

[IMAGE_2]

::: attention Erreur fréquente
Arrondir trop tôt. On garde la valeur exacte $\sqrt{15{,}75}$ (ou toute la valeur affichée par la calculatrice) et on n'arrondit qu'à la fin.
:::

Solution:
<!-- optitab:1 -->
1. Les deux sont horizontales, dans le même plan vertical.
2. $MN = 3$ m
3. $AN = 2$ m ; $MB = 4$ m
4. $AH \approx 3{,}97$ m
5. $AK \approx 1{,}32$ m ; $KH \approx 2{,}65$ m

=== Entraînement - Une longueur inconnue x
Id: 3640
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On donne $MB = 4$ cm, $AN = 3$ cm et $NC = 6$ cm. On cherche la longueur $AM$, notée $x$.

[IMAGE_1]

1. Exprimer $AB$ en fonction de $x$.
2. Calculer $AC$.
3. Écrire l'égalité $\dfrac{AM}{AB} = \dfrac{AN}{AC}$ en fonction de $x$.
4. À l'aide d'un produit en croix, montrer que $9x = 3x + 12$.
5. Résoudre cette équation et vérifier le résultat.
6. On mesure $MN = 2{,}5$ cm. Calculer $BC$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $AB$ en fonction de $x$

::: etape
$M$ est sur $[AB]$, donc $AB = AM + MB = x + 4$.
:::

::: resultat
$AB = x + 4$.
:::

## Question 2 : La longueur $AC$

::: etape
$AC = AN + NC = 3 + 6 = 9$.
:::

::: resultat
$AC = 9$ cm.
:::

## Question 3 : L'égalité en fonction de $x$

::: etape On remplace
$AM$ par $x$, $AB$ par $x + 4$, $AN$ par $3$ et $AC$ par $9$.
:::

::: resultat
$$\frac{x}{x + 4} = \frac{3}{9}$$
:::

::: attention Erreur fréquente
Écrire $\dfrac{x}{4}$ : le dénominateur est le côté entier $AB = x + 4$, pas le morceau $MB$.
:::

## Question 4 : Le produit en croix

::: etape
$$9 \times x = 3 \times (x + 4)$$
:::

::: etape On développe
$$3 \times (x + 4) = 3x + 12$$
:::

::: resultat
$$9x = 3x + 12$$
:::

## Question 5 : La résolution

::: etape
$$\begin{aligned}
9x - 3x &= 12 \\
6x &= 12 \\
x &= 2
\end{aligned}$$
:::

::: point Vérification
$\dfrac{AM}{AB} = \dfrac{2}{6} = \dfrac{1}{3}$ et $\dfrac{AN}{AC} = \dfrac{3}{9} = \dfrac{1}{3}$ : les rapports sont égaux.
:::

::: resultat
$AM = 2$ cm.
:::

::: retenir
Quand une longueur inconnue apparaît dans un côté entier, on la nomme $x$, on exprime le côté entier en fonction de $x$ et on résout une équation.
:::

## Question 6 : La longueur $BC$

::: etape On remplace
$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{2}{6} = \frac{2{,}5}{BC}$$
:::

::: etape Le produit en croix
$$BC = \frac{6 \times 2{,}5}{2} = \frac{15}{2} = 7{,}5$$
:::

::: resultat
$BC = 7{,}5$ cm.
:::

[IMAGE_2]

Solution:
<!-- optitab:1 -->
1. $AB = x + 4$
2. $AC = 9$ cm
3. $\dfrac{x}{x + 4} = \dfrac{3}{9}$
4. $9x = 3(x + 4) = 3x + 12$
5. $x = 2$, donc $AM = 2$ cm.
6. $BC = 7{,}5$ cm

=== Entraînement - Corriger des erreurs
Id: 3641
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur la figure, $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$, avec $AM = 3$ cm, $MB = 2$ cm, $AC = 7{,}5$ cm et $BC = 8$ cm. Trois élèves proposent des calculs.

[IMAGE_1]

1. Calculer $AB$.
2. Zoé veut calculer $MN$. Elle écrit : « $\dfrac{AM}{AB} = \dfrac{MN}{AC}$, donc $MN = \dfrac{3 \times 7{,}5}{5} = 4{,}5$ cm ». Quelle est son erreur ?
3. Calculer correctement $MN$.
4. Tom veut calculer $AN$. Il écrit : « $\dfrac{AM}{AB} = \dfrac{AN}{NC}$ ». Quelle est son erreur ?
5. Sami écrit : « $\dfrac{3}{5} = \dfrac{AN}{7{,}5}$, donc $AN = \dfrac{5 \times 7{,}5}{3} = 12{,}5$ cm ». Montrer que son résultat est impossible, trouver son erreur, puis calculer correctement $AN$ et $NC$.
6. Contrôler les résultats en calculant les trois rapports.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le côté $AB$

::: etape
$AB = AM + MB = 3 + 2 = 5$.
:::

::: resultat
$AB = 5$ cm.
:::

## Question 2 : L'erreur de Zoé

::: methode
On vérifie que chaque rapport compare deux côtés correspondants.
:::

::: etape
$[MN]$ est parallèle à $[BC]$ : c'est à $[BC]$ qu'il correspond, pas à $[AC]$.
:::

::: resultat
Zoé a associé $[MN]$ au mauvais côté. Il fallait écrire $\dfrac{AM}{AB} = \dfrac{MN}{BC}$.
:::

## Question 3 : La longueur $MN$

::: etape
$$\frac{3}{5} = \frac{MN}{8} \quad\text{donc}\quad MN = \frac{3 \times 8}{5} = \frac{24}{5} = 4{,}8$$
:::

::: resultat
$MN = 4{,}8$ cm.
:::

## Question 4 : L'erreur de Tom

::: etape
Le dénominateur doit être le côté entier du grand triangle : $AC$, pas le morceau $NC$.
:::

::: resultat
Tom a mis $NC$ au lieu de $AC$. Il fallait écrire $\dfrac{AM}{AB} = \dfrac{AN}{AC}$.
:::

## Question 5 : L'erreur de Sami

::: etape Le résultat est impossible
$N$ est sur le segment $[AC]$, donc $AN$ doit être plus petit que $AC = 7{,}5$ cm. Or Sami trouve $12{,}5$ cm.
:::

::: etape L'erreur
Son égalité est juste, mais son produit en croix est faux. De $\dfrac{3}{5} = \dfrac{AN}{7{,}5}$, on tire $5 \times AN = 3 \times 7{,}5$ : il faut multiplier $3$ par $7{,}5$, puis diviser par $5$. Sami a multiplié $5$ par $7{,}5$ et divisé par $3$.
:::

::: etape Le bon calcul
$$AN = \frac{3 \times 7{,}5}{5} = \frac{22{,}5}{5} = 4{,}5$$

$$NC = 7{,}5 - 4{,}5 = 3$$
:::

::: resultat
Sami a inversé les nombres du produit en croix. En réalité, $AN = 4{,}5$ cm et $NC = 3$ cm.
:::

::: attention Erreur fréquente
Ne pas contrôler la vraisemblance : un côté du petit triangle est toujours plus court que le côté correspondant du grand triangle.
:::

## Question 6 : Le contrôle

::: etape Les trois rapports
$$\frac{AM}{AB} = \frac{3}{5} = 0{,}6$$

$$\frac{AN}{AC} = \frac{4{,}5}{7{,}5} = 0{,}6$$

$$\frac{MN}{BC} = \frac{4{,}8}{8} = 0{,}6$$
:::

::: resultat
Les trois rapports valent $0{,}6$ : les résultats $MN = 4{,}8$ cm et $AN = 4{,}5$ cm sont cohérents.
:::

[IMAGE_2]

::: retenir Deux contrôles rapides
- Chaque côté du petit triangle est plus court que le côté correspondant du grand.
- Les trois rapports donnent le même nombre $k$.
:::

Solution:
<!-- optitab:1 -->
1. $AB = 5$ cm
2. $[MN]$ correspond à $[BC]$, pas à $[AC]$.
3. $MN = 4{,}8$ cm
4. Il a mis $NC$ au lieu de $AC$.
5. $AN > AC$ est impossible ; produit en croix inversé. $AN = 4{,}5$ cm ; $NC = 3$ cm.
6. Les trois rapports valent $0{,}6$.

=== Entraînement - Un triangle rectangle et une parallèle
Id: 3642
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $B$, avec $AB = 8$ cm et $BC = 6$ cm. Le point $M$ est sur $[AB]$ avec $AM = 2$ cm ; le point $N$ est sur $[AC]$ et $(MN) \parallel (BC)$.

[IMAGE_1]

1. Calculer $AC$.
2. Écrire l'égalité des trois rapports avec les longueurs connues.
3. Calculer $MN$.
4. Calculer $AN$.
5. Démontrer que le triangle $AMN$ est rectangle en $M$.
6. Vérifier le résultat de la question 4 avec le théorème de Pythagore dans le triangle $AMN$.

Étapes:
<!-- optitab:1 -->
## Question 1 : La longueur $AC$

::: methode
Théorème de Pythagore dans le triangle $ABC$ rectangle en $B$ : l'hypoténuse est $[AC]$.
:::

::: etape
$$AC^2 = AB^2 + BC^2 = 8^2 + 6^2 = 64 + 36 = 100$$
:::

::: resultat
$AC = \sqrt{100} = 10$ cm.
:::

## Question 2 : L'égalité des rapports

::: etape
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
:::

::: resultat
$$\frac{2}{8} = \frac{AN}{10} = \frac{MN}{6}$$
:::

## Question 3 : La longueur $MN$

::: etape
$$MN = \frac{2 \times 6}{8} = \frac{12}{8} = 1{,}5$$
:::

::: resultat
$MN = 1{,}5$ cm.
:::

## Question 4 : La longueur $AN$

::: etape
$$AN = \frac{2 \times 10}{8} = \frac{20}{8} = 2{,}5$$
:::

::: resultat
$AN = 2{,}5$ cm.
:::

## Question 5 : L'angle droit en $M$

::: methode
On utilise la propriété : si deux droites sont parallèles, toute droite perpendiculaire à l'une est perpendiculaire à l'autre.
:::

::: etape
Le triangle $ABC$ est rectangle en $B$, donc $(BC) \perp (AB)$. Or $(MN) \parallel (BC)$.
:::

::: resultat
$(MN) \perp (AB)$ : le triangle $AMN$ est rectangle en $M$.
:::

[IMAGE_2]

## Question 6 : La vérification

::: etape Les deux membres
$$AM^2 + MN^2 = 2^2 + 1{,}5^2 = 4 + 2{,}25 = 6{,}25$$

$$AN^2 = 2{,}5^2 = 6{,}25$$
:::

::: resultat
$AM^2 + MN^2 = AN^2$ : l'égalité de Pythagore est vérifiée, ce qui confirme $AN = 2{,}5$ cm.
:::

::: attention Erreur fréquente
Écrire l'égalité de Pythagore avec la mauvaise hypoténuse. Dans $AMN$ rectangle en $M$, l'hypoténuse est le côté opposé à l'angle droit : $[AN]$.
:::

::: retenir
Deux outils, un même résultat : le théorème de Thalès calcule des longueurs grâce aux parallèles, le théorème de Pythagore grâce aux angles droits.
:::

Solution:
<!-- optitab:1 -->
1. $AC = 10$ cm
2. $\dfrac{2}{8} = \dfrac{AN}{10} = \dfrac{MN}{6}$
3. $MN = 1{,}5$ cm
4. $AN = 2{,}5$ cm
5. $(MN) \parallel (BC)$ et $(BC) \perp (AB)$, donc $(MN) \perp (AB)$.
6. $4 + 2{,}25 = 6{,}25 = 2{,}5^2$

=== Problème - Mesurer un arbre par visée
Id: 3643
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour mesurer un arbre, Lina s'allonge sur le sol, l'œil au point $O$. Hugo, qui mesure $1{,}8$ m, se place debout en $H$, à $4$ m de $O$, de sorte que Lina voie le sommet $T$ de sa tête exactement aligné avec le sommet $S$ de l'arbre. Le pied $B$ de l'arbre est à $20$ m de $O$. Le sol est horizontal ; Hugo et l'arbre sont verticaux.

[IMAGE_1]

1. Justifier que les droites $(HT)$ et $(BS)$ sont parallèles.
2. Écrire l'égalité des trois rapports en précisant le sommet commun.
3. Calculer la hauteur $BS$ de l'arbre.
4. Calculer la distance $OT$ entre l'œil de Lina et le sommet de la tête d'Hugo, arrondie au centième.
5. La sœur d'Hugo mesure $1{,}35$ m. À quelle distance de $O$ doit-elle se placer pour réaliser le même alignement avec cet arbre ?
6. Plus loin, Hugo se place à $5$ m de $O$, et le pied d'un autre arbre est à $30$ m de $O$. Quelle est la hauteur de cet arbre ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les parallèles

::: etape
Hugo et l'arbre sont verticaux, et le sol est horizontal : les droites $(HT)$ et $(BS)$ sont perpendiculaires à la droite $(OB)$.
:::

::: resultat
Deux droites perpendiculaires à une même droite sont parallèles : $(HT) \parallel (BS)$.
:::

## Question 2 : L'égalité des rapports

::: etape Les deux triangles
$H \in [OB]$ et $T \in [OS]$ : le petit triangle $OHT$ est emboîté dans le grand triangle $OBS$, de sommet commun $O$.
:::

::: resultat
$H \in [OB]$, $T \in [OS]$ et $(HT) \parallel (BS)$. D'après le théorème de Thalès :

$$\frac{OH}{OB} = \frac{OT}{OS} = \frac{HT}{BS}$$
:::

## Question 3 : La hauteur de l'arbre

::: etape On remplace
$$\frac{OH}{OB} = \frac{HT}{BS} \quad\text{donc}\quad \frac{4}{20} = \frac{1{,}8}{BS}$$
:::

::: etape Le produit en croix
$$BS = \frac{20 \times 1{,}8}{4} = \frac{36}{4} = 9$$
:::

::: resultat
L'arbre mesure $9$ m.
:::

[IMAGE_2]

::: retenir
La visée remplace une hauteur inaccessible par trois mesures faciles à faire au sol : $OH$, $OB$ et la taille d'Hugo.
:::

## Question 4 : La distance $OT$

::: methode
Le triangle $OHT$ est rectangle en $H$ : théorème de Pythagore, l'hypoténuse est $[OT]$.
:::

::: etape
$$OT^2 = OH^2 + HT^2 = 4^2 + 1{,}8^2 = 16 + 3{,}24 = 19{,}24$$
:::

::: resultat
$OT = \sqrt{19{,}24} \approx 4{,}39$ m.
:::

## Question 5 : La sœur d'Hugo

::: methode
Même configuration avec la sœur en $H'$ : cette fois, on connaît la hauteur ($1{,}35$ m) et on cherche la distance $OH'$.
:::

::: etape On remplace
$$\frac{OH'}{OB} = \frac{1{,}35}{BS} \quad\text{donc}\quad \frac{OH'}{20} = \frac{1{,}35}{9}$$
:::

::: etape Le produit en croix
$$OH' = \frac{20 \times 1{,}35}{9} = \frac{27}{9} = 3$$
:::

::: resultat
Elle doit se placer à $3$ m de $O$.
:::

::: point Vérification
Plus petite qu'Hugo, elle doit être plus près de Lina : $3 < 4$.
:::

## Question 6 : Un autre arbre

::: etape On remplace
On note $h$ la hauteur de cet arbre.

$$\frac{5}{30} = \frac{1{,}8}{h}$$
:::

::: etape Le produit en croix
$$h = \frac{30 \times 1{,}8}{5} = \frac{54}{5} = 10{,}8$$
:::

::: resultat
Cet arbre mesure $10{,}8$ m.
:::

::: attention Erreur fréquente
Écrire $\dfrac{5}{30} = \dfrac{h}{1{,}8}$ : on obtiendrait $h = 0{,}3$ m, absurde pour un arbre. Le petit triangle (Hugo) reste en haut dans les deux rapports.
:::

Solution:
<!-- optitab:1 -->
1. $(HT)$ et $(BS)$ sont perpendiculaires au sol $(OB)$.
2. Sommet $O$ : $\dfrac{OH}{OB} = \dfrac{OT}{OS} = \dfrac{HT}{BS}$
3. $BS = 9$ m
4. $OT \approx 4{,}39$ m
5. À $3$ m de $O$.
6. $10{,}8$ m

=== Problème - Une clôture sur un plan
Id: 3644
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Voici le plan d'un terrain triangulaire $ABC$, à l'échelle $\dfrac{1}{1\,000}$. Une clôture $[MN]$, parallèle au côté $[BC]$, isole un potager $AMN$, avec $M \in [AB]$ et $N \in [AC]$. Sur le plan, on mesure $AM = 3$ cm, $MB = 4{,}5$ cm, $AC = 9$ cm et $BC = 6$ cm.

[IMAGE_1]

1. Calculer $AB$ sur le plan. Quelles sont les longueurs réelles des trois côtés du terrain, en mètres ?
2. Calculer $AN$ et $MN$ sur le plan.
3. Quelle est la longueur réelle de la clôture ?
4. La clôture coûte $12{,}50$ € le mètre. Quel est son prix ?
5. Le propriétaire préfère une clôture de $36$ m, toujours parallèle à $[BC]$. À quelle distance réelle du point $A$ faut-il placer $M$ ? Où placer $M$ sur le plan ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les longueurs du terrain

::: methode
À l'échelle $\dfrac{1}{1\,000}$, $1$ cm sur le plan représente $1\,000$ cm $= 10$ m dans la réalité.
:::

::: etape Sur le plan
$AB = AM + MB = 3 + 4{,}5 = 7{,}5$ cm.
:::

::: etape Dans la réalité
- $AB$ : $7{,}5 \times 10 = 75$ m ;
- $AC$ : $9 \times 10 = 90$ m ;
- $BC$ : $6 \times 10 = 60$ m.
:::

::: resultat
Sur le plan, $AB = 7{,}5$ cm. Les côtés du terrain mesurent $75$ m, $90$ m et $60$ m.
:::

## Question 2 : Les longueurs $AN$ et $MN$ sur le plan

::: methode
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$ : théorème de Thalès dans le triangle $ABC$ du plan.
:::

::: etape L'égalité
$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$

On remplace par les longueurs connues :

$$\frac{3}{7{,}5} = \frac{AN}{9} = \frac{MN}{6}$$
:::

::: etape Les produits en croix
$$AN = \frac{3 \times 9}{7{,}5} = 3{,}6$$

$$MN = \frac{3 \times 6}{7{,}5} = 2{,}4$$
:::

::: resultat
Sur le plan, $AN = 3{,}6$ cm et $MN = 2{,}4$ cm.
:::

## Question 3 : La longueur réelle de la clôture

::: etape
$2{,}4$ cm sur le plan représentent $2{,}4 \times 10 = 24$ m.
:::

::: resultat
La clôture mesure $24$ m.
:::

[IMAGE_2]

::: retenir
Un plan est une réduction de la réalité : les rapports de Thalès sont les mêmes sur le plan et sur le terrain. On peut calculer sur le plan puis convertir, ou convertir d'abord puis calculer.
:::

## Question 4 : Le prix de la clôture

::: etape
$24 \times 12{,}50 = 300$.
:::

::: resultat
La clôture coûte $300$ €.
:::

## Question 5 : Une clôture de $36$ m

::: methode
On travaille avec les longueurs réelles : on connaît $MN = 36$ m, $BC = 60$ m et $AB = 75$ m, on cherche $AM$.
:::

::: etape On remplace
$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{AM}{75} = \frac{36}{60}$$
:::

::: etape Le produit en croix
$$AM = \frac{75 \times 36}{60} = \frac{2\,700}{60} = 45$$
:::

::: etape Sur le plan
$45$ m $= 4\,500$ cm, et $4\,500 \div 1\,000 = 4{,}5$ cm.
:::

::: resultat
Il faut placer $M$ à $45$ m du point $A$, soit à $4{,}5$ cm de $A$ sur le plan.
:::

::: attention Erreur fréquente
Mélanger les unités dans un même rapport, par exemple $\dfrac{3 \text{ cm}}{75 \text{ m}}$. Dans une égalité de Thalès, toutes les longueurs sont dans la même unité.
:::

Solution:
<!-- optitab:1 -->
1. $AB = 7{,}5$ cm sur le plan ; $75$ m, $90$ m et $60$ m.
2. $AN = 3{,}6$ cm ; $MN = 2{,}4$ cm
3. $24$ m
4. $300$ €
5. À $45$ m de $A$, soit $4{,}5$ cm sur le plan.

=== Problème - La distance à travers un étang
Id: 3645
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Les points $B$ et $C$ sont sur les bords opposés d'un étang. Pour connaître la distance $BC$, on a planté des piquets : $M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. On a mesuré $AM = 12$ m, $MB = 36$ m, $AN = 13$ m et $MN = 15$ m.

[IMAGE_1]

1. Pourquoi ne peut-on pas mesurer directement $BC$ avec un décamètre ?
2. Calculer $AB$.
3. Calculer la distance $BC$.
4. Calculer $AC$, puis $NC$.
5. Un canard traverse l'étang en ligne droite de $B$ à $C$, à la vitesse de $0{,}5$ m/s. Combien de temps met-il ?
6. Un promeneur va de $B$ à $C$ en passant par $A$. Combien de mètres de plus que le canard parcourt-il ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Pourquoi un calcul ?

::: etape
L'eau sépare $B$ et $C$ : on ne peut pas tendre le décamètre au-dessus de l'étang.
:::

::: resultat
$BC$ est une distance inaccessible : on la calcule avec le théorème de Thalès, à partir de longueurs mesurées sur la terre ferme.
:::

## Question 2 : La longueur $AB$

::: etape
$AB = AM + MB = 12 + 36 = 48$.
:::

::: resultat
$AB = 48$ m.
:::

## Question 3 : La distance $BC$

::: etape On remplace
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$. D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{12}{48} = \frac{15}{BC}$$
:::

::: etape Le produit en croix
$$BC = \frac{48 \times 15}{12} = \frac{720}{12} = 60$$
:::

::: resultat
$BC = 60$ m.
:::

[IMAGE_2]

::: attention Erreur fréquente
Utiliser $MB = 36$ m au dénominateur : $\dfrac{12}{36} = \dfrac{15}{BC}$ donnerait $45$ m. Le dénominateur est le côté entier $AB = 48$ m.
:::

## Question 4 : Les longueurs $AC$ et $NC$

::: etape La longueur $AC$
$$\frac{12}{48} = \frac{13}{AC} \quad\text{donc}\quad AC = \frac{48 \times 13}{12} = 52$$
:::

::: etape La longueur $NC$
$NC = AC - AN = 52 - 13 = 39$.
:::

::: resultat
$AC = 52$ m et $NC = 39$ m.
:::

## Question 5 : Le canard

::: methode
À vitesse constante : durée $=$ distance $\div$ vitesse.
:::

::: etape
$60 \div 0{,}5 = 120$ s, et $120$ s $= 2$ min.
:::

::: resultat
Le canard met $2$ minutes.
:::

## Question 6 : Le promeneur

::: etape Le chemin du promeneur
$BA + AC = 48 + 52 = 100$ m.
:::

::: etape La différence
$100 - 60 = 40$ m.
:::

::: resultat
Le promeneur parcourt $40$ m de plus que le canard.
:::

::: retenir
Le trajet en ligne droite est le plus court : dans le triangle $ABC$, $BC < BA + AC$.
:::

Solution:
<!-- optitab:1 -->
1. L'eau sépare $B$ et $C$.
2. $AB = 48$ m
3. $BC = 60$ m
4. $AC = 52$ m ; $NC = 39$ m
5. $120$ s, soit $2$ min.
6. $40$ m de plus.

=== Problème - Un rectangle dans un triangle
Id: 3646
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ a pour base $BC = 12$ cm et pour hauteur $AH = 8$ cm, avec $H \in [BC]$. Le rectangle $MNPQ$ a ses sommets $M$ sur $[AB]$, $N$ sur $[AC]$, $P$ et $Q$ sur $[BC]$. Sa hauteur $MQ$ est notée $x$, en cm. La droite $(MN)$ coupe $[AH]$ en $K$.

[IMAGE_1]

1. Pourquoi les droites $(MN)$ et $(BC)$ sont-elles parallèles ?
2. Dans cette question et la suivante, $x = 3$. Calculer $AK$.
3. Dans le triangle $ABH$, montrer que $\dfrac{AM}{AB} = \dfrac{5}{8}$. En déduire $MN$, puis l'aire du rectangle.
4. Montrer que, pour tout $x$ compris entre $0$ et $8$, $MN = 12 - 1{,}5x$.
5. Calculer l'aire du rectangle pour $x = 2$, $x = 4$ et $x = 6$. Laquelle est la plus grande ?
6. Pour quelle valeur de $x$ le rectangle $MNPQ$ est-il un carré ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les parallèles

::: etape
$MNPQ$ est un rectangle : ses côtés opposés $[MN]$ et $[QP]$ sont parallèles.
:::

::: resultat
La droite $(QP)$ est la droite $(BC)$, donc $(MN) \parallel (BC)$.
:::

## Question 2 : La longueur $AK$

::: etape
$(MN) \parallel (BC)$ et $(AH) \perp (BC)$ : le quadrilatère $MKHQ$ est un rectangle, donc $KH = MQ = 3$ cm.
:::

::: etape
$AK = AH - KH = 8 - 3 = 5$.
:::

::: resultat
$AK = 5$ cm.
:::

## Question 3 : Le cas $x = 3$

::: methode
Théorème de Thalès deux fois : d'abord dans le triangle $ABH$ avec $(MK) \parallel (BH)$, puis dans le triangle $ABC$ avec $(MN) \parallel (BC)$.
:::

::: etape Dans le triangle $ABH$
$M \in [AB]$, $K \in [AH]$ et $(MK) \parallel (BH)$, donc :

$$\frac{AM}{AB} = \frac{AK}{AH} = \frac{5}{8}$$
:::

::: etape Dans le triangle $ABC$
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$, donc :

$$\frac{MN}{BC} = \frac{AM}{AB} = \frac{5}{8} \quad\text{et}\quad MN = \frac{5 \times 12}{8} = 7{,}5$$
:::

::: etape L'aire du rectangle
$7{,}5 \times 3 = 22{,}5$.
:::

::: resultat
$MN = 7{,}5$ cm et l'aire du rectangle vaut $22{,}5$ cm².
:::

[IMAGE_2]

::: retenir
Le rapport $\dfrac{AM}{AB}$ sert de « pont » entre les deux configurations de Thalès.
:::

## Question 4 : Le cas général

::: etape Le rapport
$KH = x$, donc $AK = 8 - x$ et, comme à la question 3, $\dfrac{MN}{BC} = \dfrac{AM}{AB} = \dfrac{AK}{AH} = \dfrac{8 - x}{8}$.
:::

::: etape Le calcul de $MN$
$$\begin{aligned}
MN &= 12 \times \frac{8 - x}{8} \\
&= 1{,}5 \times (8 - x) \\
&= 12 - 1{,}5x
\end{aligned}$$
:::

::: resultat
Pour tout $x$ compris entre $0$ et $8$ : $MN = 12 - 1{,}5x$.
:::

::: point Vérification
Pour $x = 3$ : $12 - 1{,}5 \times 3 = 12 - 4{,}5 = 7{,}5$, comme à la question 3.
:::

## Question 5 : Trois aires

::: methode
Aire du rectangle $= MN \times MQ = (12 - 1{,}5x) \times x$.
:::

::: etape Pour $x = 2$
$MN = 12 - 3 = 9$ et l'aire vaut $9 \times 2 = 18$ cm².
:::

::: etape Pour $x = 4$
$MN = 12 - 6 = 6$ et l'aire vaut $6 \times 4 = 24$ cm².
:::

::: etape Pour $x = 6$
$MN = 12 - 9 = 3$ et l'aire vaut $3 \times 6 = 18$ cm².
:::

::: resultat
Parmi ces trois valeurs, l'aire la plus grande est $24$ cm², obtenue pour $x = 4$.
:::

::: attention Erreur fréquente
Croire que le rectangle le plus haut est le plus grand : quand $x$ augmente, $MN$ diminue.
:::

## Question 6 : Le carré

::: etape La condition
$MNPQ$ est un carré lorsque $MN = MQ$, c'est-à-dire $12 - 1{,}5x = x$.
:::

::: etape La résolution
$$\begin{aligned}
12 &= x + 1{,}5x \\
12 &= 2{,}5x \\
x &= 12 \div 2{,}5 = 4{,}8
\end{aligned}$$
:::

::: resultat
Pour $x = 4{,}8$ cm, le rectangle $MNPQ$ est un carré de côté $4{,}8$ cm.
:::

::: point Vérification
$MN = 12 - 1{,}5 \times 4{,}8 = 12 - 7{,}2 = 4{,}8 = MQ$.
:::

Solution:
<!-- optitab:1 -->
1. Côtés opposés du rectangle : $(MN) \parallel (QP)$, c'est-à-dire $(BC)$.
2. $AK = 5$ cm
3. $MN = 7{,}5$ cm ; aire $22{,}5$ cm²
4. $MN = 12 \times \dfrac{8 - x}{8} = 12 - 1{,}5x$
5. $18$ cm², $24$ cm², $18$ cm² : la plus grande pour $x = 4$.
6. $x = 4{,}8$ cm

=== Type brevet - L'escabeau
Id: 3647
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Les deux montants $[AB]$ et $[AC]$ d'un escabeau mesurent $2$ m. Une chaîne $[MN]$ de $0{,}4$ m est fixée à $0{,}5$ m du sommet sur chaque montant : $AM = AN = 0{,}5$ m. Quand l'escabeau est ouvert, la chaîne est tendue et horizontale ; le sol est horizontal.

[IMAGE_1]

## Partie A : L'escabeau ouvert

1. Pourquoi les droites $(MN)$ et $(BC)$ sont-elles parallèles ?
2. Calculer l'écartement $BC$ des pieds de l'escabeau.
3. $H$ est le milieu de $[BC]$ et $(AH) \perp (BC)$. Calculer la hauteur $AH$ de l'escabeau, arrondie au centième.

## Partie B : Régler la chaîne

1. On fixe la chaîne à $0{,}8$ m du sommet sur chaque montant, sans changer l'écartement $BC$. Quelle doit être sa longueur ?
2. La notice impose un écartement au sol d'au moins $1{,}5$ m. Une chaîne de $0{,}35$ m fixée à $0{,}5$ m du sommet convient-elle ?
3. Quelle longueur minimale doit avoir une chaîne fixée à $0{,}5$ m du sommet pour respecter la notice ?

Étapes:
<!-- optitab:1 -->
## Partie A : L'escabeau ouvert

## Question 1 : Les parallèles

::: etape
La chaîne tendue et le sol sont horizontaux, et ils sont dans le même plan vertical (celui de l'escabeau).
:::

::: resultat
Les droites $(MN)$ et $(BC)$ sont parallèles.
:::

## Question 2 : L'écartement $BC$

::: methode
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$ : théorème de Thalès dans le triangle $ABC$.
:::

::: etape On remplace
$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{donc}\quad \frac{0{,}5}{2} = \frac{0{,}4}{BC}$$
:::

::: etape Le produit en croix
$$BC = \frac{2 \times 0{,}4}{0{,}5} = \frac{0{,}8}{0{,}5} = 1{,}6$$
:::

::: resultat
L'écartement des pieds est $BC = 1{,}6$ m.
:::

## Question 3 : La hauteur $AH$

::: methode
Théorème de Pythagore dans le triangle $ABH$ rectangle en $H$, avec $BH = 1{,}6 \div 2 = 0{,}8$ m.
:::

::: etape
$$AH^2 = AB^2 - BH^2 = 2^2 - 0{,}8^2 = 4 - 0{,}64 = 3{,}36$$
:::

::: resultat
$AH = \sqrt{3{,}36} \approx 1{,}83$ m.
:::

[IMAGE_2]

::: attention Erreur fréquente
Écrire $AH^2 = AB^2 + BH^2$ : $[AB]$ est l'hypoténuse du triangle $ABH$, on soustrait.
:::

## Partie B : Régler la chaîne

## Question 1 : La chaîne fixée plus bas

::: etape On remplace
$AM = 0{,}8$ m et $BC = 1{,}6$ m ne change pas :

$$\frac{0{,}8}{2} = \frac{MN}{1{,}6} \quad\text{donc}\quad MN = \frac{0{,}8 \times 1{,}6}{2} = 0{,}64$$
:::

::: resultat
La chaîne doit mesurer $0{,}64$ m, soit $64$ cm.
:::

::: point Vérification
Plus la chaîne est fixée bas, plus elle est longue : $0{,}64 > 0{,}4$.
:::

## Question 2 : Une chaîne de $0{,}35$ m

::: etape L'écartement obtenu
$$\frac{0{,}5}{2} = \frac{0{,}35}{BC} \quad\text{donc}\quad BC = \frac{2 \times 0{,}35}{0{,}5} = 1{,}4$$
:::

::: resultat
Non : l'écartement serait de $1{,}4$ m, et $1{,}4 < 1{,}5$.
:::

## Question 3 : La longueur minimale

::: methode
On veut $BC = 1{,}5$ m au moins ; on cherche la longueur $L$ de la chaîne qui donne exactement $1{,}5$ m.
:::

::: etape
$$\frac{0{,}5}{2} = \frac{L}{1{,}5} \quad\text{donc}\quad L = \frac{0{,}5 \times 1{,}5}{2} = 0{,}375$$
:::

::: resultat
La chaîne doit mesurer au moins $0{,}375$ m, soit $37{,}5$ cm.
:::

::: retenir
Le rapport $\dfrac{AM}{AB} = \dfrac{0{,}5}{2} = 0{,}25$ ne change pas : la chaîne mesure toujours le quart de l'écartement.
:::

Solution:
<!-- optitab:1 -->
**Partie A**
1. La chaîne et le sol sont horizontaux, dans le même plan vertical.
2. $BC = 1{,}6$ m
3. $AH \approx 1{,}83$ m

**Partie B**
1. $0{,}64$ m
2. Non : $BC = 1{,}4$ m $< 1{,}5$ m.
3. $37{,}5$ cm au minimum.

=== Type brevet - La rampe d'accès
Id: 3648
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une rampe $[AB]$ permet d'atteindre une porte située à $0{,}6$ m au-dessus du sol. Le point $C$, au pied de la porte, est à $12$ m de $A$ sur le sol horizontal, et $[CB]$ est vertical. Trois supports verticaux $[DR]$, $[ES]$ et $[FT]$ sont placés à $3$ m, $6$ m et $9$ m de $A$, avec $D$, $E$, $F$ sur $[AC]$ et $R$, $S$, $T$ sur $[AB]$.

[IMAGE_1]

## Partie A : Les supports

1. Pourquoi les supports sont-ils parallèles à $(CB)$ ?
2. Calculer la hauteur $DR$ du premier support.
3. Calculer $ES$ et $FT$.
4. Quelle longueur totale de tube faut-il pour les trois supports ?

## Partie B : La rampe

1. Calculer la longueur $AB$ de la rampe, arrondie au centième.
2. La pente d'une rampe est le quotient de la hauteur par la longueur horizontale. Calculer la pente de cette rampe en pourcentage. La norme d'accessibilité impose une pente d'au plus $5\ \%$ : est-elle respectée ?
3. Une autre porte est à $0{,}8$ m au-dessus du sol. Quelle longueur horizontale minimale doit avoir sa rampe pour respecter la norme ?

Étapes:
<!-- optitab:1 -->
## Partie A : Les supports

## Question 1 : Les parallèles

::: etape
Les supports et $[CB]$ sont verticaux, donc perpendiculaires au sol $(AC)$.
:::

::: resultat
Deux droites perpendiculaires à une même droite sont parallèles : $(DR)$, $(ES)$ et $(FT)$ sont parallèles à $(CB)$.
:::

## Question 2 : Le premier support

::: methode
$D \in [AC]$, $R \in [AB]$ et $(DR) \parallel (CB)$ : théorème de Thalès dans le triangle $ACB$, de sommet commun $A$.
:::

::: etape On remplace
$$\frac{AD}{AC} = \frac{DR}{CB} \quad\text{donc}\quad \frac{3}{12} = \frac{DR}{0{,}6}$$
:::

::: etape Le produit en croix
$$DR = \frac{3 \times 0{,}6}{12} = \frac{1{,}8}{12} = 0{,}15$$
:::

::: resultat
Le premier support mesure $0{,}15$ m.
:::

## Question 3 : Les deux autres supports

::: etape Le support $[ES]$
$$\frac{6}{12} = \frac{ES}{0{,}6} \quad\text{donc}\quad ES = \frac{6 \times 0{,}6}{12} = 0{,}3$$
:::

::: etape Le support $[FT]$
$$\frac{9}{12} = \frac{FT}{0{,}6} \quad\text{donc}\quad FT = \frac{9 \times 0{,}6}{12} = 0{,}45$$
:::

::: resultat
$ES = 0{,}3$ m et $FT = 0{,}45$ m.
:::

[IMAGE_2]

::: retenir
La hauteur de la rampe est proportionnelle à la distance au point $A$ : $0{,}05$ m de hauteur par mètre au sol.
:::

## Question 4 : La longueur de tube

::: etape
$0{,}15 + 0{,}3 + 0{,}45 = 0{,}9$.
:::

::: resultat
Il faut $0{,}9$ m de tube.
:::

## Partie B : La rampe

## Question 1 : La longueur de la rampe

::: methode
Le triangle $ACB$ est rectangle en $C$ : théorème de Pythagore, l'hypoténuse est $[AB]$.
:::

::: etape
$$AB^2 = AC^2 + CB^2 = 12^2 + 0{,}6^2 = 144 + 0{,}36 = 144{,}36$$
:::

::: resultat
$AB = \sqrt{144{,}36} \approx 12{,}01$ m.
:::

::: attention Erreur fréquente
Croire que la rampe mesure $12$ m comme sa longueur au sol : inclinée, elle est un peu plus longue.
:::

## Question 2 : La pente

::: etape Le quotient
$$\frac{CB}{AC} = \frac{0{,}6}{12} = 0{,}05 = \frac{5}{100}$$
:::

::: etape Avec un support
$\dfrac{DR}{AD} = \dfrac{0{,}15}{3} = 0{,}05$ aussi : la pente est la même tout le long de la rampe.
:::

::: resultat
La pente est de $5\ \%$ : la norme est respectée, tout juste.
:::

## Question 3 : Une autre porte

::: methode
Avec une pente de $5\ \%$, la hauteur vaut $0{,}05$ fois la longueur horizontale.
:::

::: etape
$$\frac{0{,}8}{L} = 0{,}05 \quad\text{donc}\quad L = \frac{0{,}8}{0{,}05} = 16$$
:::

::: resultat
La rampe doit avoir une longueur horizontale d'au moins $16$ m.
:::

Solution:
<!-- optitab:1 -->
**Partie A**
1. Ils sont tous perpendiculaires au sol $(AC)$.
2. $DR = 0{,}15$ m
3. $ES = 0{,}3$ m ; $FT = 0{,}45$ m
4. $0{,}9$ m

**Partie B**
1. $AB \approx 12{,}01$ m
2. $5\ \%$ : la norme est respectée.
3. $16$ m au moins.

=== Type brevet - La largeur d'une rivière
Id: 3649
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour mesurer la largeur d'une rivière sans la traverser, Inès repère un arbre $A$ sur l'autre rive. Elle plante un piquet $M$ sur sa rive, juste en face de $A$, puis un piquet $B$ en reculant de $8$ m dans l'alignement de $A$ et $M$. Elle plante ensuite un piquet $N$ sur la rive et un piquet $C$ tels que $A$, $N$, $C$ soient alignés et $(BC) \parallel (MN)$. Elle mesure $MN = 15$ m et $BC = 20$ m. On note $x$ la largeur $AM$, en mètres.

[IMAGE_1]

## Partie A : Mettre en équation

1. Exprimer $AB$ en fonction de $x$.
2. Écrire l'égalité de Thalès qui relie $AM$, $AB$, $MN$ et $BC$.
3. À l'aide d'un produit en croix, montrer que $20x = 15x + 120$.
4. Résoudre cette équation. Quelle est la largeur de la rivière ?
5. Vérifier le résultat en calculant $\dfrac{AM}{AB}$ et $\dfrac{MN}{BC}$.

## Partie B : Exploiter la méthode

1. À un autre endroit, Inès recule toujours de $8$ m, puis mesure $MN = 15$ m et $BC = 25$ m. Quelle est la largeur de la rivière à cet endroit ?
2. Au premier endroit, on veut construire une passerelle qui dépasse de $3$ m sur chaque rive. Quelle est sa longueur ?

Étapes:
<!-- optitab:1 -->
## Partie A : Mettre en équation

## Question 1 : $AB$ en fonction de $x$

::: etape
$M$ est sur $[AB]$, donc $AB = AM + MB = x + 8$.
:::

::: resultat
$AB = x + 8$.
:::

## Question 2 : L'égalité de Thalès

::: etape
$M \in [AB]$, $N \in [AC]$ et $(MN) \parallel (BC)$ : le petit triangle $AMN$ est emboîté dans le grand triangle $ABC$, de sommet commun $A$.
:::

::: resultat
D'après le théorème de Thalès :

$$\frac{AM}{AB} = \frac{MN}{BC} \quad\text{soit}\quad \frac{x}{x + 8} = \frac{15}{20}$$
:::

## Question 3 : Le produit en croix

::: etape
$$20 \times x = 15 \times (x + 8)$$
:::

::: etape On développe
$$15 \times (x + 8) = 15x + 120$$
:::

::: resultat
$$20x = 15x + 120$$
:::

## Question 4 : La résolution

::: etape
$$\begin{aligned}
20x - 15x &= 120 \\
5x &= 120 \\
x &= 24
\end{aligned}$$
:::

::: resultat
La rivière mesure $24$ m de large.
:::

[IMAGE_2]

::: attention Erreur fréquente
Écrire $\dfrac{x}{8} = \dfrac{15}{20}$ : le dénominateur est le côté entier $AB = x + 8$, pas le morceau $MB$.
:::

## Question 5 : La vérification

::: etape
$$\frac{AM}{AB} = \frac{24}{32} = 0{,}75$$

$$\frac{MN}{BC} = \frac{15}{20} = 0{,}75$$
:::

::: resultat
Les deux rapports sont égaux : la largeur $24$ m est juste.
:::

## Partie B : Exploiter la méthode

## Question 1 : Un autre endroit

::: etape L'équation
$$\frac{x}{x + 8} = \frac{15}{25} \quad\text{donc}\quad 25x = 15x + 120$$
:::

::: etape La résolution
$10x = 120$, donc $x = 12$.
:::

::: resultat
À cet endroit, la rivière mesure $12$ m de large.
:::

::: point Vérification
$\dfrac{12}{20} = 0{,}6$ et $\dfrac{15}{25} = 0{,}6$.
:::

## Question 2 : La passerelle

::: etape
$24 + 3 + 3 = 30$.
:::

::: resultat
La passerelle mesure $30$ m.
:::

::: retenir
Quand l'inconnue est un morceau d'un côté, on la nomme $x$, on écrit le côté entier en fonction de $x$ et on résout une équation.
:::

Solution:
<!-- optitab:1 -->
**Partie A**
1. $AB = x + 8$
2. $\dfrac{x}{x + 8} = \dfrac{15}{20}$
3. $20x = 15(x + 8) = 15x + 120$
4. $x = 24$ : la rivière mesure $24$ m.
5. Les deux rapports valent $0{,}75$.

**Partie B**
1. $12$ m
2. $30$ m
