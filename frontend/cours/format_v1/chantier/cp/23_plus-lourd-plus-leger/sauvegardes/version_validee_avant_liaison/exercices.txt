===
Découverte - Lire une balance
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
La balance est réglée. Compare les boîtes A et B.

[IMAGE_1]

1. Quel plateau est le plus bas ?
2. Quelle boîte est la plus lourde ?
3. Quelle boîte est la plus légère ?
4. Les deux boîtes ont-elles la même masse ?
5. Comment vérifier en échangeant les deux boîtes ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel plateau est le plus bas ?

::: methode
Compare leur hauteur.
:::

::: etape Raisonner
Le plateau de droite descend davantage.
:::

::: resultat
Le plateau B.
:::

## Question 2 : Quelle boîte est la plus lourde ?

::: methode
Le côté le plus bas porte la masse la plus grande.
:::

::: etape Raisonner
B est sur le plateau le plus bas.
:::

::: resultat
B.
:::

## Question 3 : Quelle boîte est la plus légère ?

::: methode
Compare avec la boîte la plus lourde.
:::

::: etape Raisonner
A est sur le plateau le plus haut.
:::

::: resultat
A.
:::

## Question 4 : Les deux boîtes ont-elles la même masse ?

::: methode
Des masses égales garderaient les plateaux au même niveau.
:::

::: etape Raisonner
Ici les plateaux sont à des hauteurs différentes.
:::

::: resultat
Non.
:::

## Question 5 : Comment vérifier en échangeant les deux boîtes ?

::: methode
Place A à droite et B à gauche.
:::

::: etape Raisonner
La boîte B doit encore faire descendre son nouveau côté.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
B doit rester la plus lourde.
:::

Solution:
<!-- optitab:1 -->
1. Le plateau B.
2. B.
3. A.
4. Non.
5. B doit rester la plus lourde.

Énoncé:
<!-- optitab:1 -->

[IMAGE_1]

1. Entre A et B, lequel est le plus léger ?
2. Entre B et C, lequel est le plus léger ?
3. Quelle boîte est la plus légère des trois ?
4. Quelle boîte se place au milieu du rangement ?
5. Range les boîtes de la plus légère à la plus lourde.

Étapes:
<!-- optitab:1 -->

## Question 1 : Entre A et B, lequel est le plus léger ?

::: methode
Relis la première comparaison.
:::

::: etape Raisonner

:::

::: resultat
B.
:::

## Question 2 : Entre B et C, lequel est le plus léger ?

::: methode
Relis la seconde comparaison.
:::

::: etape Raisonner
B est plus lourd ; C est donc plus léger.
:::

::: resultat
C.
:::

## Question 3 : Quelle boîte est la plus légère des trois ?

::: methode
Cherche celle qui est plus légère que B.

::: etape Raisonner

:::

::: resultat
C.
:::

## Question 4 : Quelle boîte se place au milieu du rangement ?

::: methode
Elle est plus lourde que C et plus légère que A.
:::

::: etape Raisonner
Ces deux comparaisons désignent B.
:::

::: resultat

## Question 5 : Range les boîtes de la plus légère à la plus lourde.

:::

5. C, puis B, puis A.
