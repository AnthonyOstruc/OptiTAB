Titre: Les automatismes du brevet : tout le programme en une fiche

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif :</strong> réviser en une fois les résultats et les méthodes à connaître par cœur pour la partie « automatismes » du brevet (20 minutes, sans calculatrice).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Nombres et calculs</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Priorités : parenthèses, puissances, multiplications et divisions, puis additions et soustractions.</p>
<p style="margin:6px 0 0 0;">• Fractions : $\displaystyle \frac{a}{b} + \frac{c}{b} = \frac{a + c}{b}$ ; $\displaystyle \frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$ ; diviser, c'est multiplier par l'inverse.</p>
<p style="margin:6px 0 0 0;">• Puissances : $\displaystyle a^m \times a^n = a^{m + n}$ ; $\displaystyle (a^m)^n = a^{mn}$ ; $\displaystyle 10^{-n} = \frac{1}{10^n}$.</p>
<p style="margin:6px 0 0 0;">• Écriture scientifique : $\displaystyle a \times 10^n$ avec $\displaystyle 1 \leq a < 10$.</p>
<p style="margin:6px 0 0 0;">• Racines : $\displaystyle \sqrt{a^2} = a$ (pour $\displaystyle a \geq 0$) ; $\displaystyle \sqrt{ab} = \sqrt{a} \times \sqrt{b}$.</p>
<p style="margin:6px 0 0 0;">• Divisibilité : par 2 (chiffre des unités pair), par 3 ou 9 (somme des chiffres), par 5 (unités 0 ou 5).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calcul littéral et équations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:0 auto 12px auto; text-align:center; max-width:560px;">
<p style="margin:0; font-weight:bold;">$\displaystyle (a + b)^2 = a^2 + 2ab + b^2$ &nbsp;&nbsp; $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$</p>
<p style="margin:6px 0 0 0; font-weight:bold;">$\displaystyle (a + b)(a - b) = a^2 - b^2$</p>
</div>
<p style="margin:0;">• Équation du premier degré : isoler $\displaystyle x$ en faisant la même opération dans les deux membres.</p>
<p style="margin:6px 0 0 0;">• Produit nul : $\displaystyle A \times B = 0$ équivaut à $\displaystyle A = 0$ ou $\displaystyle B = 0$.</p>
<p style="margin:6px 0 0 0;">• $\displaystyle x^2 = a$ avec $\displaystyle a > 0$ : deux solutions $\displaystyle \sqrt{a}$ et $\displaystyle -\sqrt{a}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Proportionnalité, grandeurs et fonctions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Augmenter de $\displaystyle t\ \%$ : $\displaystyle \times \left(1 + \frac{t}{100}\right)$ ; diminuer de $\displaystyle t\ \%$ : $\displaystyle \times \left(1 - \frac{t}{100}\right)$.</p>
<p style="margin:6px 0 0 0;">• Vitesse : $\displaystyle v = \frac{d}{t}$ ; 1 h = 60 min ; $\displaystyle 1$ m/s $\displaystyle = 3{,}6$ km/h.</p>
<p style="margin:6px 0 0 0;">• Volumes : $\displaystyle 1$ dm³ $\displaystyle = 1$ L ; $\displaystyle 1$ m³ $\displaystyle = 1\,000$ L ; $\displaystyle 1$ m² $\displaystyle = 10\,000$ cm².</p>
<p style="margin:6px 0 0 0;">• Image : on calcule $\displaystyle f(a)$ ; antécédent : on résout $\displaystyle f(x) = b$.</p>
<p style="margin:6px 0 0 0;">• Linéaire $\displaystyle f(x) = ax$ (proportionnalité, droite par l'origine) ; affine $\displaystyle f(x) = ax + b$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Géométrie</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Pythagore (triangle rectangle) : $\displaystyle \text{hyp}^2 = a^2 + b^2$ ; réciproque pour prouver un angle droit.</p>
<p style="margin:6px 0 0 0;">• Thalès (droites parallèles) : rapports de longueurs égaux ; réciproque pour prouver un parallélisme.</p>
<p style="margin:6px 0 0 0;">• Trigonométrie : $\displaystyle \cos = \frac{\text{adj}}{\text{hyp}}$, $\displaystyle \sin = \frac{\text{opp}}{\text{hyp}}$, $\displaystyle \tan = \frac{\text{opp}}{\text{adj}}$.</p>
<p style="margin:6px 0 0 0;">• Volumes : prisme et cylindre $\displaystyle \mathcal{B} \times h$ ; pyramide et cône $\displaystyle \frac{\mathcal{B} \times h}{3}$ ; boule $\displaystyle \frac{4}{3}\pi r^3$.</p>
<p style="margin:6px 0 0 0;">• Agrandissement de rapport $\displaystyle k$ : longueurs $\displaystyle \times k$, aires $\displaystyle \times k^2$, volumes $\displaystyle \times k^3$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Statistiques et probabilités</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Moyenne : somme des valeurs (pondérées par les effectifs) divisée par l'effectif total.</p>
<p style="margin:6px 0 0 0;">• Médiane : valeur du milieu de la série RANGÉE ; étendue : plus grande moins plus petite valeur.</p>
<p style="margin:6px 0 0 0;">• Probabilité (issues équiprobables) : $\displaystyle \frac{\text{nombre d'issues favorables}}{\text{nombre d'issues possibles}}$, toujours entre 0 et 1.</p>
<p style="margin:6px 0 0 0;">• Événement contraire : $\displaystyle P(\overline{A}) = 1 - P(A)$ ; arbre : multiplier le long d'un chemin.</p>
</div>
