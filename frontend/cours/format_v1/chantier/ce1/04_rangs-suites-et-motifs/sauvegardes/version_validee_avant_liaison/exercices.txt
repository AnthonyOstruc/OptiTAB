Découverte - Le motif AB
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
La suite commence par A B A B A B et continue toujours avec le même motif. On compte depuis la gauche.

[IMAGE_1]

1. Quel est le motif le plus court qui se répète ?
2. Quelle lettre se trouve au rang 39 ?
3. Quelle lettre se trouve au rang 38 ?
4. Quelle lettre se trouve au rang 40 ?
5. Quelle lettre se trouve au rang 41 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel est le motif le plus court qui se répète ?

::: methode
Repère le premier groupe qui recommence sans changement.
:::

::: etape Raisonner
Après A B, les mêmes 2 lettres recommencent dans le même ordre.
:::

::: resultat
A B : 2 lettres.
:::

## Question 2 : Quelle lettre se trouve au rang 39 ?

::: methode
Fais des groupes complets du motif, puis cherche la place dans le dernier groupe.
:::

::: etape Raisonner
$19\times2=38$. Il reste 1 lettre après ces groupes.
:::

::: resultat
La lettre A.
:::

## Question 3 : Quelle lettre se trouve au rang 38 ?

::: methode
Recule d’une lettre dans le motif, en reprenant à la fin si nécessaire.
:::

::: etape Raisonner
Juste avant A, le motif porte B.
:::

::: resultat
La lettre B.
:::

## Question 4 : Quelle lettre se trouve au rang 40 ?

::: methode
Avance d’une lettre ; après la fin du motif, reprends au début.
:::

::: etape Raisonner
Juste après A, le motif porte B.
:::

::: resultat
La lettre B.
:::

## Question 5 : Quelle lettre se trouve au rang 41 ?

::: methode
Ajouter un motif complet garde la même place dans le motif.
:::

::: etape Raisonner
$39+2=41$ : on avance de 2 lettres et on retrouve A.
:::

::: resultat
La lettre A.
:::

Solution:
<!-- optitab:1 -->
1. A B : 2 lettres.
2. La lettre A.
3. La lettre B.
4. La lettre B.
5. La lettre A.

Découverte - Une arrivée à la course
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un coureur arrive 63e ; les arrivées sont toutes à des places différentes.

1. Combien de coureurs sont arrivés avant lui ?
2. Quel rang précède le sien ?
3. Quel rang suit le sien ?
4. Quel est le rang d’un coureur ayant 69 coureurs devant lui ?
5. Parmi les 70 premiers, combien sont derrière le coureur arrivé 63e ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de coureurs sont arrivés avant lui ?

::: methode
Retire le coureur lui-même du nombre des 63 premiers.
:::

::: etape Raisonner
$63-1=62$.
:::

::: resultat
62 coureurs.
:::

## Question 2 : Quel rang précède le sien ?

::: methode
Recule d’une place.
:::

::: etape Raisonner
$63-1=62$.
:::

::: resultat
62e.
:::

## Question 3 : Quel rang suit le sien ?

::: methode
Avance d’une place.
:::

::: etape Raisonner
$63+1=64$.
:::

::: resultat
64e.
:::

## Question 4 : Quel est le rang d’un coureur ayant 69 coureurs devant lui ?

::: methode
Ajoute sa propre place au nombre de coureurs qui le précèdent.
:::

::: etape Raisonner
$69+1=70$.
:::

::: resultat
70e.
:::

## Question 5 : Parmi les 70 premiers, combien sont derrière le coureur arrivé 63e ?

::: methode
Ne compte pas les 63 premiers, qui incluent ce coureur.
:::

::: etape Raisonner
$70-63=7$ ; ce sont les rangs 64 à 70.
:::

::: resultat
7 coureurs.
:::

Solution:
<!-- optitab:1 -->
1. 62 coureurs.
2. 62e.
3. 64e.
4. 70e.
5. 7 coureurs.

Entraînement - De dix en dix
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La règle indiquée par les premiers nombres continue de la même manière.

1. Continue : 125 ; 135 ; 145 ; … ; …
2. Écris les quatre premiers nombres.
3. Quel nombre vient après 165 ?
4. Combien de nombres as-tu écrits dans la suite complète de la première question ?
5. Un camarade recopie le dernier nombre au rang suivant. Explique pourquoi cela ne convient pas.

Étapes:
<!-- optitab:1 -->

## Question 1 : Continue : 125 ; 135 ; 145 ; … ; …

::: methode
Compare les écarts 135 − 125 et 145 − 135, puis ajoute encore dix à chaque rang.
:::

::: etape Raisonner
$135-125=10$ et $145-135=10$. On ajoute 10 : $145+10=155$ et $155+10=165$.
:::

::: resultat
$155$ ; $165$.
:::

## Question 2 : Écris les quatre premiers nombres.

::: methode
Pars de 125 et ajoute dix trois fois pour écrire quatre nombres.
:::

::: etape Raisonner
On part de 125 ; les quatre premiers nombres sont 125, 135, 145, 155.
:::

::: resultat
125 ; 135 ; 145 ; 155.
:::

## Question 3 : Quel nombre vient après 165 ?

::: methode
Ajoute dix à 165, comme entre les nombres précédents.
:::

::: etape Raisonner
$165+10=175$.
:::

::: resultat
$175$.
:::

## Question 4 : Combien de nombres as-tu écrits dans la suite complète de la première question ?

::: methode
Compte les rangs à partir de 1, sans sauter de nombre.
:::

::: etape Raisonner
La suite complétée est : 125, 135, 145, 155, 165.
:::

::: resultat
5 nombres.
:::

## Question 5 : Un camarade recopie le dernier nombre au rang suivant. Explique pourquoi cela ne convient pas.

::: methode
Compare la réponse du camarade à 165 augmenté de dix.
:::

::: etape Raisonner
Après 165, la règle donne 175 et non 165. Le nombre doit donc encore augmenter.
:::

::: resultat
Il faut écrire $175$, pas $165$.
:::

Solution:
<!-- optitab:1 -->
1. $155$ ; $165$.
2. 125 ; 135 ; 145 ; 155.
3. $175$.
4. 5 nombres.
5. Il faut écrire $175$, pas $165$.

::: resultat
$128$.
:::

## Question 4 : Combien de nombres as-tu écrits dans la suite complète de la première question ?

Compte les rangs à partir de 1, sans sauter de nombre.
:::

6 nombres.

2. 2 ; 4 ; 8 ; 16.
3. $128$.
4. 6 nombres.
5. Il faut écrire $128$, pas $64$.

::: etape Raisonner

::: resultat
$29$.

Problème - Dans la file
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Tu es 37e dans une file de 100 personnes. On compte depuis le début de la file.

1. Combien de personnes sont derrière toi ?
2. Combien de personnes sont devant toi ?
3. Vérifie le total en réunissant les personnes devant, toi et celles derrière.
4. Si tu avances d’une place, quel est ton nouveau rang ?
5. À cette nouvelle place, combien de personnes sont derrière toi ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de personnes sont derrière toi ?

::: methode
Retire les 37 premières personnes, y compris toi, du total.
:::

::: etape Raisonner
$100-37=63$.
:::

::: resultat
63 personnes.
:::

## Question 2 : Combien de personnes sont devant toi ?

::: methode
Dans les 37 premières personnes, enlève ta propre place.
:::

::: etape Raisonner
$37-1=36$.
:::

::: resultat
36 personnes.
:::

## Question 3 : Vérifie le total en réunissant les personnes devant, toi et celles derrière.

::: methode
Ta place compte pour une seule personne.
:::

::: etape Raisonner
$36+1+63=100$.
:::

::: resultat
On retrouve 100 personnes.
:::

## Question 4 : Si tu avances d’une place, quel est ton nouveau rang ?

::: methode
Avancer vers le début diminue le rang d’une unité.
:::

::: etape Raisonner
$37-1=36$.
:::

::: resultat
36e.
:::

## Question 5 : À cette nouvelle place, combien de personnes sont derrière toi ?

::: methode
Le total reste 100 ; retire les 36 premières personnes.
:::

::: etape Raisonner
$100-36=64$.
:::

::: resultat
64 personnes.
:::

Solution:
<!-- optitab:1 -->
1. 63 personnes.
2. 36 personnes.
3. On retrouve 100 personnes.
4. 36e.
5. 64 personnes.
