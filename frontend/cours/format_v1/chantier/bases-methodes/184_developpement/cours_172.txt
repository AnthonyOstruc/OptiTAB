Titre: Développements d'Expressions Algébriques

<!-- optitab:1 -->
## Introduction

**Développer une expression**, c'est transformer un **produit** en une **somme**.

::: definition
**Produit** $\displaystyle \xrightarrow[\text{}]{\text{Développer}}$ **Somme**

Exemple : $\displaystyle 3(x + 2) \xrightarrow[\text{}]{\text{}} 3x + 6$
:::

::: definition Pourquoi développer ?
- Pour simplifier des expressions complexes
- Pour résoudre des équations
- Pour comparer des expressions
- Pour calculer plus facilement
:::

## I. La distributivité simple

### Règle fondamentale

::: definition
$$k(a + b) = ka + kb$$
:::

::: methode
On multiplie le facteur **extérieur** par **chaque terme** de la parenthèse.
:::

### Exemples progressifs

::: exemple
Développer $\displaystyle 5(x + 3)$

::: methode
On multiplie 5 par chaque terme
:::

$$\displaystyle 5(x + 3) = 5 \times x + 5 \times 3$$

$$\displaystyle = 5x + 15$$
:::

::: exemple
Développer $\displaystyle -3(2x - 7)$

::: methode
Attention aux signes !
:::

$$\displaystyle -3(2x - 7) = (-3) \times 2x + (-3) \times (-7)$$

$$\displaystyle = -6x + 21$$
:::

::: exemple
Développer $\displaystyle 2x(3x - 5)$

$$\displaystyle 2x(3x - 5) = 2x \times 3x - 2x \times 5$$

$$\displaystyle = 6x^2 - 10x$$
:::

::: attention Règle des signes
- $(+) \times (+) = (+)$
- $(+) \times (-) = (-)$
- $(-) \times (+) = (-)$
- $(-) \times (-) = (+)$
:::

### Cas avec plusieurs termes

::: definition
$$k(a + b + c) = ka + kb + kc$$
:::

::: exemple
Développer $\displaystyle 4(x^2 - 2x + 3)$

$$\displaystyle 4(x^2 - 2x + 3) = 4x^2 - 8x + 12$$
:::

## II. La double distributivité

### Règle générale

::: definition
$$(a + b)(c + d) = ac + ad + bc + bd$$
:::

::: methode
Chaque terme de la **première parenthèse** multiplie **chaque terme** de la **deuxième parenthèse**.
:::

::: exemple Visualisation
::: definition
$$(a + b)(c + d)$$

$$a \times c$$

(premier × premier)

$$a \times d$$

(premier × deuxième)

$$b \times c$$

(deuxième × premier)

$$b \times d$$

(deuxième × deuxième)
:::
:::

### Exemples détaillés

::: exemple
Développer $\displaystyle (x + 3)(x + 5)$

::: etape $x$ multiplie chaque terme de $(x + 5)$
$$x \times x + x \times 5 = x^2 + 5x$$
:::

::: etape $3$ multiplie chaque terme de $(x + 5)$
$$3 \times x + 3 \times 5 = 3x + 15$$
:::

::: etape On additionne tout
$$x^2 + 5x + 3x + 15$$
:::

::: resultat
$$(x + 3)(x + 5) = x^2 + 8x + 15$$
:::
:::

::: exemple
Développer $\displaystyle (2x - 1)(x + 4)$

$$\displaystyle (2x - 1)(x + 4) = 2x \times x + 2x \times 4 - 1 \times x - 1 \times 4$$

$$\displaystyle = 2x^2 + 8x - x - 4$$

$$\displaystyle = 2x^2 + 7x - 4$$
:::

::: exemple
Développer $\displaystyle (3x + 2)(2x - 5)$

$$\displaystyle = 3x \times 2x + 3x \times (-5) + 2 \times 2x + 2 \times (-5)$$

$$\displaystyle = 6x^2 - 15x + 4x - 10$$

$$\displaystyle = 6x^2 - 11x - 10$$
:::

## III. Développements avec identités remarquables

Les identités remarquables permettent de développer **plus rapidement** certaines expressions.

### Les trois identités principales

::: methode
**1.** $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$

**2.** $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$

**3.** $\displaystyle (a + b)(a - b) = a^2 - b^2$
:::

### Exemples d'application

::: exemple
Développer $\displaystyle (x + 4)^2$

::: methode Identité utilisée
$$(a + b)^2 = a^2 + 2ab + b^2$$
:::

::: exemple
Avec $a = x$ et $b = 4$ :
:::

$$\displaystyle (x + 4)^2 = x^2 + 2 \times x \times 4 + 4^2 = x^2 + 8x + 16$$
:::

::: exemple
Développer $\displaystyle (2x - 3)^2$

::: methode Identité utilisée
$$(a - b)^2 = a^2 - 2ab + b^2$$
:::

::: exemple
Avec $a = 2x$ et $b = 3$ :
:::

$$\displaystyle (2x - 3)^2 = (2x)^2 - 2 \times 2x \times 3 + 3^2 = 4x^2 - 12x + 9$$
:::

::: exemple
Développer $\displaystyle (x + 7)(x - 7)$

::: methode Identité utilisée
$$(a + b)(a - b) = a^2 - b^2$$
:::

$$\displaystyle (x + 7)(x - 7) = x^2 - 7^2 = x^2 - 49$$
:::

## IV. Développements complexes

### Développer puis réduire

::: methode
1. Développer chaque produit séparément
2. Enlever les parenthèses en faisant attention aux signes
3. Regrouper les termes semblables
4. Simplifier l'expression finale
:::

::: exemple
Développer et réduire $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5)$

::: etape Développer chaque produit
$$(x + 2)(x + 3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$$

$$(x - 1)(x + 5) = x^2 + 5x - x - 5 = x^2 + 4x - 5$$
:::

::: etape Additionner
$$(x^2 + 5x + 6) + (x^2 + 4x - 5)$$
:::

::: etape Regrouper les termes
$$x^2 + x^2 + 5x + 4x + 6 - 5$$
:::

::: resultat
$$2x^2 + 9x + 1$$
:::
:::

::: exemple
Développer et réduire $\displaystyle (x + 1)^2 - (x - 2)^2$

::: etape Développer chaque carré
$$(x + 1)^2 = x^2 + 2x + 1$$

$$(x - 2)^2 = x^2 - 4x + 4$$
:::

::: etape Soustraire (attention aux signes !)
$$(x^2 + 2x + 1) - (x^2 - 4x + 4) = x^2 + 2x + 1 - x^2 + 4x - 4$$
:::

::: resultat
$$6x - 3$$
:::
:::

::: attention
Quand on soustrait une expression entre parenthèses, il faut changer **tous les signes** !

Exemple : $a - (b - c) = a - b + c$
:::

### Développements avec plusieurs parenthèses

::: exemple
Développer $\displaystyle (x + 2)(x - 3)(x + 1)$

::: methode
On développe deux parenthèses à la fois
:::

::: etape Développer $(x + 2)(x - 3)$
$$(x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6$$
:::

::: etape Multiplier le résultat par $(x + 1)$
$$
\begin{aligned}
(x^2 - x - 6)(x + 1) &= x^2 \times x + x^2 \times 1 - x \times x - x \times 1 - 6 \times x - 6 \times 1 \\
&= x^3 + x^2 - x^2 - x - 6x - 6
\end{aligned}
$$
:::

::: resultat
$$x^3 - 7x - 6$$
:::
:::

## V. Méthode générale

::: methode Démarche complète pour développer
1. **Observer l'expression :** Y a-t-il des identités remarquables ?
2. **Choisir la méthode :** Distributivité simple, double, ou identité remarquable
3. **Développer :** Appliquer la formule en faisant attention aux signes
4. **Réduire :** Regrouper les termes semblables
5. **Ordonner :** Écrire le résultat par ordre décroissant des puissances
6. **Vérifier :** Compter le nombre de termes (aide à éviter les erreurs)
:::

::: conseil Pour gagner du temps
- Reconnaître les identités remarquables en priorité
- Faire les calculs mentalement pour les coefficients simples
- Regrouper directement les termes semblables pendant le développement
- Vérifier en remplaçant $x$ par une valeur simple (ex: $x = 1$)
:::

## VI. Erreurs fréquentes et conseils

::: attention
- **Erreur n°1 :** Oublier de multiplier tous les termes $2(x + 3) = 2x + 3$ $2(x + 3) = 2x + 6$
- **Erreur n°2 :** Se tromper dans les signes $-3(x - 2) = -3x - 6$ $-3(x - 2) = -3x + 6$
- **Erreur n°3 :** Oublier un terme dans la double distributivité $(x + 2)(x + 3) = x^2 + 6$ $(x + 2)(x + 3) = x^2 + 5x + 6$
- **Erreur n°4 :** Confondre $(a + b)^2$ et $a^2 + b^2$ $(x + 3)^2 = x^2 + 9$ $(x + 3)^2 = x^2 + 6x + 9$
- **Erreur n°5 :** Mal enlever les parenthèses lors d'une soustraction $x - (2x - 5) = x - 2x - 5$ $x - (2x - 5) = x - 2x + 5$
:::

::: conseil POUR RÉUSSIR
- **Conseil n°1 :** Toujours écrire toutes les multiplications, même évidentes
- **Conseil n°2 :** Mettre les signes négatifs entre parenthèses : $(-3)$ plutôt que $-3$
- **Conseil n°3 :** Vérifier le nombre de termes attendus (aide à ne rien oublier)
- **Conseil n°4 :** Regrouper les termes semblables dès que possible
- **Conseil n°5 :** S'entraîner régulièrement pour gagner en rapidité
- **Conseil n°6 :** Vérifier son résultat en testant avec une valeur simple
:::
