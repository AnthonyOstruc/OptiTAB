=== Problème - Diviseurs et nombres premiers : lire et modifier un programme
Id: 1974
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On étudie des programmes qui combinent variables, conditions et boucles : il faut les lire, les simuler, puis les modifier ou les compléter.

1. Qu’affiche le programme suivant ? Quel est son rôle ?

   ```python
   n = 15
   nb = 0
   for i in range(1, n + 1):
       if n % i == 0:
           nb = nb + 1
   print(nb)
   ```

2. Modifier le programme de la question 1 pour qu’il **affiche** les diviseurs de `n` au lieu de les compter.
3. Qu’affiche le programme suivant ? Expliquer son rôle.

   ```python
   n = 7
   nb = 0
   for i in range(1, n + 1):
       if n % i == 0:
           nb = nb + 1
   if nb == 2:
       print(n, "est premier")
   else:
       print(n, "non premier")
   ```

4. On additionne les nombres impairs $1 + 3 + 5 + \cdots$ jusqu’à ce que la somme dépasse $100$. Écrire un programme qui affiche le nombre d’impairs additionnés et la somme obtenue.
5. Compléter la ligne `if ...:` du programme suivant pour qu’il affiche tous les nombres premiers compris entre $2$ et $20$. Qu’affiche-t-il alors ?

   ```python
   for n in range(2, 21):
       c = 0
       for i in range(1, n + 1):
           if n % i == 0:
               c = c + 1
       if ...:
           print(n)
   ```

Étapes:
<!-- optitab:1 -->
## Question 1 : Rôle du premier programme

::: methode
Repérer les structures (une boucle `for` qui contient un test `if`), puis simuler le programme.
:::

::: etape La boucle
`range(1, n + 1)` donne les entiers de $1$ à $15$ : la variable `i` prend successivement ces $15$ valeurs.
:::

::: etape Le test
`n % i == 0` est vrai lorsque le reste de la division de $15$ par `i` est nul, c’est-à-dire lorsque `i` **divise** $15$. Cela arrive pour `i` égal à $1$, $3$, $5$ et $15$.
:::

::: etape Le compteur
La variable `nb` est un **compteur** : elle part de $0$ et augmente de $1$ à chaque diviseur trouvé : il vaut $4$ à la fin de la boucle.
:::

::: resultat
Le programme affiche `4` : il **compte les diviseurs** de `n`.
:::

## Question 2 : Afficher les diviseurs

::: methode
Quand `i` divise `n`, on affiche `i` au lieu d’augmenter le compteur ; le compteur devient inutile.
:::

::: resultat
```python
n = 15
for i in range(1, n + 1):
    if n % i == 0:
        print(i)
```

Le programme affiche $1$, $3$, $5$ puis $15$, un nombre par ligne.
:::

## Question 3 : Test de primalité

::: methode
Le programme compte les diviseurs de $7$ puis teste si ce nombre vaut $2$.
:::

::: etape Diviseurs de 7
| `i` | `7 % i` | `i` divise $7$ ? | `nb` |
|---|---|---|---|
| $1$ | $0$ | oui | $1$ |
| $2$ | $1$ | non | $1$ |
| $3$ | $1$ | non | $1$ |
| $4$ | $3$ | non | $1$ |
| $5$ | $2$ | non | $1$ |
| $6$ | $1$ | non | $1$ |
| $7$ | $0$ | oui | $2$ |
:::

::: etape Le test final
Après la boucle, `nb == 2` est vrai : Python exécute le bloc du `if`.
:::

::: resultat
```console
7 est premier
```

Le programme teste si `n` est **premier** : un nombre premier a exactement deux diviseurs, $1$ et lui-même.
:::

## Question 4 : Somme d’impairs jusqu’à dépasser 100

::: methode
On ne sait pas combien d’impairs il faudra : boucle `while`, avec un accumulateur `S`, la variable `impair` qui augmente de $2$ à chaque tour et un compteur `k`.
:::

::: etape Initialisation
`S = 0` (rien n’est encore ajouté), `impair = 1` (premier impair), `k = 0` (aucun tour).
:::

::: etape Condition de la boucle
On veut **dépasser** $100$ : on continue **tant que** `S <= 100`.
:::

```python
S = 0
impair = 1
k = 0
while S <= 100:
    S = S + impair
    impair = impair + 2
    k = k + 1
print(k, S)
```

```console
11 121
```

::: point Vérification
Les sommes successives sont les carrés $1, 4, 9, \ldots, 100, 121$. Après $10$ impairs, $S = 100$ : la condition `100 <= 100` est encore vraie, donc on ajoute $21$ et $S = 121$.
:::

::: resultat
Il faut additionner $11$ impairs ($1 + 3 + \cdots + 21$) ; la somme vaut alors $121$.
:::

::: attention
Avec `while S < 100`, la boucle s’arrêterait à $S = 100$, qui ne **dépasse** pas $100$.
:::

## Question 5 : Afficher les nombres premiers jusqu’à 20

::: methode
La boucle intérieure est celle de la question 3 : elle compte les diviseurs de `n` dans `c`. La boucle extérieure fait varier `n` de $2$ à $20$.
:::

::: etape La condition à écrire
`n` est premier lorsqu’il a exactement deux diviseurs : on complète par `if c == 2:`.
:::

::: etape Le rôle de c = 0
`c = 0` est **dans** la boucle extérieure : le compteur repart de zéro pour chaque nouvelle valeur de `n`.
:::

```python
for n in range(2, 21):
    c = 0
    for i in range(1, n + 1):
        if n % i == 0:
            c = c + 1
    if c == 2:
        print(n)
```

::: resultat
Le programme affiche $2$, $3$, $5$, $7$, $11$, $13$, $17$, $19$ (un nombre par ligne).
:::

::: attention
Si `c = 0` était placé avant la première boucle, les diviseurs de tous les nombres s’additionneraient : seul $2$ serait affiché.
:::

Solution:
<!-- optitab:1 -->
1. Le programme affiche `4` : il compte les diviseurs de `n` ($1$, $3$, $5$, $15$).
2. On remplace `nb = nb + 1` par `print(i)` (et on supprime le compteur) : affichage $1$, $3$, $5$, $15$.
3. Il affiche `7 est premier` : il teste si `n` a exactement deux diviseurs.
4. Boucle `while S <= 100` : $11$ impairs, somme $121$.
5. `if c == 2:` ; affichage $2$, $3$, $5$, $7$, $11$, $13$, $17$, $19$.

=== Découverte - Affectation et séquence d’instructions
Id: 1969
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On exécute des séquences d’instructions Python et on détermine les valeurs des variables.

1. Quelle est la valeur de `x` après les instructions suivantes ?

   ```python
   x = 3
   x = x + 7
   x = x * 2
   ```

2. Quelles sont les valeurs de `a` et `b` après les instructions suivantes ?

   ```python
   a = 5
   b = a + 3
   a = a + 1
   ```

3. On veut échanger les valeurs de `a` et `b`. Expliquer pourquoi le code suivant ne fonctionne pas, puis le corriger.

   ```python
   a = 4
   b = 9
   a = b
   b = a
   ```

4. Quelle est la valeur de `s` après les instructions suivantes ?

   ```python
   a = 10
   b = 4
   s = a + b
   a = 20
   ```

5. Écrire une séquence d’instructions qui range les notes $12$, $15$ et $9$ dans trois variables, calcule leur moyenne et l’affiche.

Étapes:
<!-- optitab:1 -->
## Question 1 : Valeur finale de x

::: methode
Exécuter les instructions dans l’ordre, de haut en bas : à chaque affectation, on calcule le membre de droite avec la valeur **actuelle** de `x`.
:::

::: etape Tableau de suivi
| Instruction | Calcul | `x` |
|---|---|---|
| `x = 3` | – | $3$ |
| `x = x + 7` | $3 + 7$ | $10$ |
| `x = x * 2` | $10 \times 2$ | $20$ |
:::

::: resultat
`x` vaut $20$.
:::

## Question 2 : Valeurs de a et b

::: methode
`b` est calculée avec la valeur de `a` **au moment** de l’affectation ; ensuite, `b` ne dépend plus de `a`.
:::

::: etape Tableau de suivi
| Instruction | `a` | `b` |
|---|---|---|
| `a = 5` | $5$ | – |
| `b = a + 3` | $5$ | $8$ |
| `a = a + 1` | $6$ | $8$ |
:::

::: resultat
$a = 6$ et $b = 8$.
:::

::: attention
`b = a + 3` n’est pas une relation permanente : modifier `a` ensuite ne change pas `b`.
:::

## Question 3 : Échanger deux variables

::: methode
Simuler le code proposé, puis sauvegarder une valeur dans une variable auxiliaire avant de l’écraser.
:::

::: etape Simuler le code proposé
| Instruction | `a` | `b` |
|---|---|---|
| `a = 4` | $4$ | – |
| `b = 9` | $4$ | $9$ |
| `a = b` | $9$ | $9$ |
| `b = a` | $9$ | $9$ |

À la ligne `a = b`, l’ancienne valeur $4$ de `a` est **perdue** : les deux variables valent $9$.
:::

[IMAGE_1]

::: etape Correction
On sauvegarde `a` dans une variable `temp` avant de l’écraser.
:::

```python
a = 4
b = 9
temp = a
a = b
b = temp
print(a, b)
```

```console
9 4
```

::: resultat
Le code échoue car `a` est écrasée avant d’être recopiée dans `b`. On utilise une variable auxiliaire : `temp = a`, puis `a = b`, puis `b = temp`.
:::

## Question 4 : Valeur de s

::: methode
Repérer le moment où `s` est calculée.
:::

::: etape Tableau de suivi
| Instruction | `a` | `b` | `s` |
|---|---|---|---|
| `a = 10` | $10$ | – | – |
| `b = 4` | $10$ | $4$ | – |
| `s = a + b` | $10$ | $4$ | $14$ |
| `a = 20` | $20$ | $4$ | $14$ |
:::

::: resultat
$s = 14$ : `s` a été calculée avant la modification de `a`.
:::

## Question 5 : Calculer une moyenne

::: methode
Une variable par note, puis la formule $\dfrac{n_1 + n_2 + n_3}{3}$, avec des parenthèses.
:::

```python
n1 = 12
n2 = 15
n3 = 9
moyenne = (n1 + n2 + n3) / 3
print(moyenne)
```

```console
12.0
```

::: resultat
$\dfrac{12 + 15 + 9}{3} = \dfrac{36}{3} = 12$ : le programme affiche `12.0` (une division `/` donne un flottant).
:::

::: attention
Sans parenthèses, `n1 + n2 + n3 / 3` calcule $12 + 15 + 3 = 30$.
:::

Solution:
<!-- optitab:1 -->
1. $x = 20$.
2. $a = 6$ et $b = 8$.
3. Après `a = b`, l’ancienne valeur de `a` est perdue ; correction : `temp = a`, `a = b`, `b = temp`.
4. $s = 14$.
5. `moyenne = (n1 + n2 + n3) / 3` ; affichage `12.0`.

=== Découverte - Écrire une formule combinant des variables
Id: 1970
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On traduit des formules mathématiques en instructions Python. On dispose de la ligne `from math import pi`, qui donne la valeur de $\pi$.

1. Écrire un programme qui calcule et affiche l’aire $A = \pi r^2$ d’un disque de rayon $r = 5$.
2. Quelle valeur le programme suivant affiche-t-il ?

   ```python
   a = 6
   b = 4
   c = a ** 2 + b ** 2
   print(c)
   ```

3. Traduire en Python la formule $E = \dfrac{a + b}{2}$ avec $a = 7$ et $b = 13$. Pourquoi les parenthèses sont-elles nécessaires ?
4. Avec $a = 7$ et $b = 13$, calculer `a + b / 2` et `(a + b) / 2`.
5. Écrire un programme qui calcule le volume $V = \dfrac{4}{3}\pi r^3$ d’une boule de rayon $r = 3$.
6. Une durée de $200$ minutes s’écrit en heures et minutes. Écrire deux formules qui calculent le nombre d’heures `h` et le nombre de minutes restantes `m`, à partir de `t = 200`.

Étapes:
<!-- optitab:1 -->
## Question 1 : Aire d’un disque

::: methode
Traduire chaque opération : le produit s’écrit `*`, la puissance `**`.
:::

::: etape Traduction
$\pi r^2 = \pi \times r^2$ s’écrit `pi * r ** 2`.
:::

```python
from math import pi
r = 5
A = pi * r ** 2
print(A)
```

```console
78.53981633974483
```

::: resultat
$A = 25\pi \approx 78{,}54$ : le programme affiche `78.53981633974483`.
:::

::: attention
`pi r ** 2` ou `pi(r ** 2)` provoquent une erreur : le signe `*` ne s’omet jamais.
:::

## Question 2 : Valeur affichée

::: methode
Appliquer les priorités : les puissances `**` avant l’addition.
:::

::: etape Calcul
$$
\begin{aligned}
c &= 6^2 + 4^2 \\
&= 36 + 16 \\
&= 52
\end{aligned}
$$
:::

::: resultat
Le programme affiche `52`.
:::

## Question 3 : Formule de la moyenne

::: methode
La barre de fraction regroupe tout le numérateur : en Python, on le met entre parenthèses.
:::

```python
a = 7
b = 13
E = (a + b) / 2
print(E)
```

```console
10.0
```

::: resultat
`E = (a + b) / 2` donne $\dfrac{20}{2} = 10$ (affiché `10.0`). Les parenthèses sont nécessaires car la division `/` est prioritaire sur l’addition.
:::

## Question 4 : Effet des parenthèses

::: methode
Calculer les deux expressions en respectant les priorités.
:::

::: etape Sans parenthèses
`a + b / 2` : la division d’abord, $13 / 2 = 6{,}5$, puis $7 + 6{,}5 = 13{,}5$.
:::

::: etape Avec parenthèses
`(a + b) / 2` : la somme d’abord, $7 + 13 = 20$, puis $20 / 2 = 10$.
:::

::: resultat
`a + b / 2` vaut `13.5` et `(a + b) / 2` vaut `10.0` : seule la seconde est la moyenne.
:::

## Question 5 : Volume d’une boule

::: methode
Écrire $\dfrac{4}{3}$ avec `/`, puis les produits et la puissance.
:::

```python
from math import pi
r = 3
V = 4 / 3 * pi * r ** 3
print(V)
```

```console
113.09733552923254
```

::: etape Vérification à la main
$$
\begin{aligned}
V &= \frac{4}{3} \times \pi \times 27 \\
&= 36\pi \\
&\approx 113{,}10
\end{aligned}
$$
:::

::: resultat
$V = 36\pi \approx 113{,}10$.
:::

## Question 6 : Convertir une durée

::: methode
Une heure vaut $60$ minutes : le nombre d’heures est le **quotient entier** de $200$ par $60$, les minutes restantes sont le **reste**.
:::

::: etape Division euclidienne
$200 = 60 \times 3 + 20$ : le quotient est $3$, le reste $20$.
:::

[IMAGE_1]

```python
t = 200
h = t // 60
m = t % 60
print(h, m)
```

```console
3 20
```

::: resultat
`h = t // 60` et `m = t % 60` : $200$ minutes font $3$ h $20$ min.
:::

::: attention
`t / 60` donne `3.3333333333333335` : ce n’est pas un nombre d’heures et de minutes.
:::

Solution:
<!-- optitab:1 -->
1. `A = pi * r ** 2` ; affichage `78.53981633974483` ($A = 25\pi \approx 78{,}54$).
2. `52`.
3. `E = (a + b) / 2` vaut `10.0` ; la division est prioritaire sur l’addition.
4. `a + b / 2` vaut `13.5` et `(a + b) / 2` vaut `10.0`.
5. `V = 4 / 3 * pi * r ** 3` ; $V = 36\pi \approx 113{,}10$.
6. `h = t // 60` et `m = t % 60` : $3$ h $20$ min.

=== Découverte - Variables et types en Python
Id: 1968
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On travaille sur les types de variables en Python : `int`, `float`, `str` et `bool`.

1. Donner le type de chacune des valeurs suivantes : `42`, `3.14`, `True`, `"Bonjour"`.
2. On exécute les instructions ci-dessous. Donner la valeur et le type de chaque variable.

   ```python
   a = 7
   b = 2.0
   c = a > 10
   d = "maths"
   ```

3. Quelle est la différence entre `3` et `3.0` ? Quel est le type de `6 / 2` ?
4. Parmi les noms de variables suivants, lesquels sont valides en Python ?

   `age`, `2ndNom`, `ma_variable`, `for`, `moyenne_classe`.
5. L’instruction `print("Résultat : " + 5)` provoque une erreur. Pourquoi ? Comment la corriger ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Types des valeurs

::: methode
Observer l’écriture de la valeur : chiffres sans point, avec un point, mot `True` / `False`, ou texte entre guillemets.
:::

::: etape Analyse
| Valeur | Écriture | Type |
|---|---|---|
| `42` | entier, sans point | `int` |
| `3.14` | avec un point décimal | `float` |
| `True` | vrai ou faux | `bool` |
| `"Bonjour"` | texte entre guillemets | `str` |
:::

::: resultat
`42` : `int` ; `3.14` : `float` ; `True` : `bool` ; `"Bonjour"` : `str`.
:::

## Question 2 : Valeur et type de chaque variable

::: methode
Exécuter chaque affectation ; pour `c`, évaluer d’abord la comparaison.
:::

::: etape La comparaison
`a > 10` compare $7$ et $10$ : $7 \gt 10$ est faux, donc `c` vaut `False`.

::: etape Tableau
| Variable | Valeur | Type |
|---|---|---|
| `a` | `7` | `int` |
| `b` | `2.0` | `float` |
| `c` | `False` | `bool` |
| `d` | `"maths"` | `str` |
:::

::: resultat
`a` : `7` (`int`) ; `b` : `2.0` (`float`) ; `c` : `False` (`bool`) ; `d` : `"maths"` (`str`).
:::

## Question 3 : 3 ou 3.0 ?

::: methode
Le point décimal fait le type ; la division `/` donne toujours un flottant.
:::

::: etape Comparer
`3` est un entier (`int`), `3.0` un flottant (`float`) : ils ont la même valeur mathématique, mais pas le même type.
:::

```python
print(type(3), type(3.0))
print(6 / 2, type(6 / 2))
```

```console
<class 'int'> <class 'float'>
3.0 <class 'float'>
```

::: resultat
`3` est un `int`, `3.0` un `float`. `6 / 2` vaut `3.0`, de type `float` (`6 // 2` donne l’entier `3`).
:::

## Question 4 : Noms de variables valides

::: methode
Un nom commence par une lettre ou `_`, ne contient que des lettres, des chiffres et `_`, et n’est pas un mot réservé.
:::

::: etape Vérifier chaque nom
- `age` : valide.
- `2ndNom` : invalide, il commence par un chiffre.
- `ma_variable` : valide.
- `for` : invalide, c’est un mot réservé (boucle `for`).
- `moyenne_classe` : valide.
:::

::: resultat
Valides : `age`, `ma_variable`, `moyenne_classe`. Invalides : `2ndNom` et `for`.
:::

## Question 5 : Mélanger texte et nombre

::: methode
Le signe `+` additionne deux nombres ou **colle** deux chaînes, mais ne mélange pas les deux types.
:::

::: etape L’erreur
`"Résultat : "` est une chaîne (`str`) et `5` un entier (`int`) : Python affiche une erreur `TypeError`.
:::

::: etape Deux corrections
- Convertir le nombre en chaîne : `"Résultat : " + str(5)`.
- Ou séparer par une virgule dans `print`, qui accepte plusieurs valeurs.
:::

```python
print("Résultat : " + str(5))
print("Résultat :", 5)
```

```console
Résultat : 5
Résultat : 5
```

::: resultat
On ne peut pas additionner un `str` et un `int` : on écrit `"Résultat : " + str(5)` ou `print("Résultat :", 5)`.
:::

Solution:
<!-- optitab:1 -->
1. `42` : `int` ; `3.14` : `float` ; `True` : `bool` ; `"Bonjour"` : `str`.
2. `a = 7` (`int`), `b = 2.0` (`float`), `c = False` (`bool`), `d = "maths"` (`str`).
3. Même valeur, types différents (`int` et `float`) ; `6 / 2` vaut `3.0`, de type `float`.
4. Valides : `age`, `ma_variable`, `moyenne_classe` ; invalides : `2ndNom`, `for`.
5. `TypeError` (chaîne + entier) ; corriger avec `str(5)` ou `print("Résultat :", 5)`.

=== Entraînement - Boucle bornée for et accumulateur
Id: 1972
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On écrit et on simule des boucles `for` avec des accumulateurs.

1. Qu’affiche le programme suivant ?

   ```python
   for i in range(5):
       print(i)
   ```

2. Qu’affiche le programme suivant ?

   ```python
   s = 0
   for i in range(1, 5):
       s = s + i
   print(s)
   ```

3. Compléter le programme suivant pour qu’il calcule le produit $1 \times 2 \times 3 \times 4 \times 5$.

   ```python
   n = 5
   p = ...
   for i in range(..., ...):
       p = ...
   print(p)
   ```

4. Faire le tableau de suivi (valeurs de `i` et `s` à chaque tour) du programme suivant. Qu’affiche-t-il ?

   ```python
   s = 0
   for i in range(2, 8, 2):
       s = s + i
   print(s)
   ```

5. Écrire un programme qui affiche les carrés des entiers de $1$ à $10$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les valeurs de range(5)

::: methode
`range(5)` donne $5$ valeurs, en commençant à $0$ : la dernière est $4$.
:::

::: resultat
```console
0
1
2
3
4
```
:::

::: attention
`range(5)` ne contient pas $5$ : la borne de fin est exclue.
:::

## Question 2 : Somme avec accumulateur

::: methode
`range(1, 5)` donne $1, 2, 3, 4$ ; à chaque tour, on ajoute `i` à `s`.
:::

::: etape Tableau de suivi
| | début | tour 1 | tour 2 | tour 3 | tour 4 |
|---|---|---|---|---|---|
| `i` | – | $1$ | $2$ | $3$ | $4$ |
| `s` | $0$ | $1$ | $3$ | $6$ | $10$ |
:::

::: resultat
Le programme affiche `10`, c’est-à-dire $1 + 2 + 3 + 4$.
:::

## Question 3 : Compléter pour un produit

::: methode
Pour un produit, l’accumulateur démarre à $1$ (multiplier par $1$ ne change rien) ; `i` doit aller de $1$ à $n$ **inclus**.
:::

::: etape Les trois trous

=== Entraînement - Boucle while et compteur : la balle qui rebondit

Difficulté: medium

Énoncé:

h = 160
n = 0

print(n)

## Question 4 : Avec while h > 10

Refaire le test au moment critique, quand `h` vaut $10$.

=== Type examen - Le vol de Syracuse : boucles et conditions
Id: 5566
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On part d’un entier `u`. S’il est pair, on le divise par $2$ ; s’il est impair, on le multiplie par $3$ et on ajoute $1$. On recommence jusqu’à obtenir $1$. La suite des valeurs obtenues s’appelle le « vol » de l’entier de départ.

```python
u = 6
etapes = 0
while u != 1:
    if u % 2 == 0:
        u = u // 2
    else:
        u = 3 * u + 1
    etapes = etapes + 1
print(etapes)
```

1. Faire le tableau de suivi du programme. Qu’affiche-t-il ?
2. Pourquoi écrit-on `u // 2` et non `u / 2` ?
3. Qu’affiche le programme si la première ligne est `u = 7` ?
4. Modifier le programme pour qu’il affiche aussi la plus grande valeur prise par `u` (l’« altitude maximale » du vol). Qu’affiche-t-il pour `u = 7` ?
5. Écrire un programme qui affiche, pour chaque entier de départ de $1$ à $10$, le nombre d’étapes de son vol. Quel entier de départ donne le vol le plus long ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Tableau de suivi pour u = 6

À chaque tour : tester la parité de `u` avec `u % 2 == 0`, appliquer la bonne instruction, puis ajouter $1$ au compteur `etapes`. La boucle s’arrête dès que `u` vaut $1$.
:::

::: etape Tableau de suivi
| Tour | Nouvelle valeur de `u` | `etapes` |
|---|---|---|
| début | $6$ | $0$ |
| 1 | $6$ pair : $6 / 2 = 3$ | $1$ |
| 2 | $3$ impair : $3 \times 3 + 1 = 10$ | $2$ |
| 3 | $10$ pair : $5$ | $3$ |
| 4 | $5$ impair : $16$ | $4$ |
| 5 | $16$ pair : $8$ | $5$ |
| 6 | $8$ pair : $4$ | $6$ |
| 7 | $4$ pair : $2$ | $7$ |
| 8 | $2$ pair : $1$ | $8$ |

Après le $8^{e}$ tour, `u` vaut $1$ : le test `u != 1` est faux, la boucle s’arrête.
:::

[IMAGE_1]

```console
8
```

::: resultat
Le vol de $6$ est $6$, $3$, $10$, $5$, $16$, $8$, $4$, $2$, $1$ : le programme affiche `8`.
:::

## Question 2 : u // 2 ou u / 2 ?

::: methode
Penser au type du résultat.
:::

::: etape Les deux divisions
- `u // 2` est le quotient entier : `6 // 2` vaut `3`, de type `int`.
- `u / 2` donne toujours un `float` : `6 / 2` vaut `3.0`. Toutes les valeurs suivantes seraient des flottants : `10.0`, `5.0`…
:::

::: resultat
Comme `u` est pair, `u // 2` est exactement la moitié de `u` et `u` reste un entier (`int`), ce qui correspond au problème. Avec `/`, `u` deviendrait un `float`.
:::

## Question 3 : Le vol de 7

::: methode
Appliquer la règle jusqu’à obtenir $1$, en comptant les étapes.
:::

::: etape Les valeurs successives
$7 \to 22 \to 11 \to 34 \to 17 \to 52 \to 26 \to 13 \to 40$

$40 \to 20 \to 10 \to 5 \to 16 \to 8 \to 4 \to 2 \to 1$

On compte $8 + 8 = 16$ flèches, c’est-à-dire $16$ étapes.
:::

```python
u = 7
etapes = 0
while u != 1:
    if u % 2 == 0:
        u = u // 2
    else:
        u = 3 * u + 1
    etapes = etapes + 1
print(etapes)
```

```console
16
```

::: resultat
Pour `u = 7`, le programme affiche `16`.
:::

## Question 4 : L’altitude maximale

::: methode
Ajouter une variable `m` qui garde la plus grande valeur rencontrée : on l’initialise avec la valeur de départ, puis, à chaque tour, on la remplace si `u` est plus grand.
:::

```python
u = 7
etapes = 0
m = u
while u != 1:
    if u % 2 == 0:
        u = u // 2
    else:
        u = 3 * u + 1
    etapes = etapes + 1
    if u > m:
        m = u
print(etapes, m)
```

```console
16 52
```

::: resultat
Le programme affiche `16 52` : le vol de $7$ dure $16$ étapes et monte jusqu’à $52$.
:::

::: attention
Le test `if u > m:` doit être **dans** la boucle (même retrait que `etapes = etapes + 1`) : placé après la boucle, il ne comparerait que la dernière valeur, $1$.
:::

## Question 5 : Les vols de 1 à 10

::: methode
Une boucle `for` parcourt les entiers de départ `d` ; pour chacun, on recopie le programme précédent dans la boucle. Les compteurs sont remis à zéro **pour chaque** `d`.
:::

```python
for d in range(1, 11):
    u = d
    e = 0
    while u != 1:
        if u % 2 == 0:
            u = u // 2
        else:
            u = 3 * u + 1
        e = e + 1
    print(d, e)
```

```console
1 0
2 1
3 7
4 2
5 5
6 8
7 16
8 3
9 19
10 6
```

::: resultat
Le vol le plus long est celui de $9$ : $19$ étapes.
:::

::: attention
- `range(1, 11)` va de $1$ à $10$ : la borne $11$ est exclue.
- `u = d` et `e = 0` sont dans la boucle `for` : sinon, le deuxième vol partirait de $1$ avec le compteur du premier.
:::

::: remarque Pour aller plus loin
Pour tous les entiers essayés, le vol finit par atteindre $1$. Mais personne n’a jamais démontré que c’est vrai pour **tous** les entiers : c’est la conjecture de Syracuse, un problème encore ouvert.
:::

Solution:
<!-- optitab:1 -->
1. Vol de $6$ : $6$, $3$, $10$, $5$, $16$, $8$, $4$, $2$, $1$ ; affichage `8`.
2. `u // 2` garde un entier (`int`) ; `u / 2` donnerait un `float`.
3. `16`.
4. Variable `m = u` avant la boucle et `if u > m: m = u` dans la boucle ; pour $7$ : affichage `16 52`.
5. Boucle `for d in range(1, 11)` contenant le programme ; le vol le plus long est celui de $9$ ($19$ étapes).
