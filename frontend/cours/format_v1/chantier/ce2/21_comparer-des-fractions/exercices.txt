=== Découverte - Comparer des fractions — atelier 1
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Compare les fractions des deux bandes et explique.
2. Sur deux bandes identiques, quelle part est la plus petite : un huitième ou un quart ?
3. Écris $\dfrac{3}{4}$ avec des huitièmes.
4. Combien de huitièmes séparent les deux coloriages ?
5. Quelle fraction manque à $\dfrac{3}{4}$ pour couvrir le tout ?

[IMAGE_1]

Étapes:
<!-- optitab:1 -->
## Question 1 : Compare les fractions des deux bandes et explique.

::: methode
Prends des bandes de même longueur et compare les portions recouvertes.
:::

::: etape Je raisonne
On représente chaque fraction par des parts égales du même tout.

$\dfrac{3}{8}$ < $\dfrac{3}{4}$ : on prend trois parts, mais les huitièmes sont plus petits.
:::

::: resultat
$\dfrac{3}{8}$ < $\dfrac{3}{4}$ : on prend trois parts, mais les huitièmes sont plus petits.
:::

## Question 2 : Sur deux bandes identiques, quelle part est la plus petite : un huitième ou un quart ?

::: methode
Prends des bandes de même longueur et compare les portions recouvertes.
:::

::: etape Je raisonne
Le même tout est partagé en plus de parts dans la première bande.
:::

::: resultat
$\dfrac{1}{8}$ < $\dfrac{1}{4}$.
:::

## Question 3 : Écris $\dfrac{3}{4}$ avec des huitièmes.

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
Chaque quart contient deux huitièmes.
:::

::: resultat
$\dfrac{3}{4}$ = $\dfrac{6}{8}$.
:::

## Question 4 : Combien de huitièmes séparent les deux coloriages ?

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
On compare 6 huitièmes à 3 huitièmes.
:::

::: resultat
$\dfrac{3}{8}$.
:::

## Question 5 : Quelle fraction manque à $\dfrac{3}{4}$ pour couvrir le tout ?

::: methode
Compte les parts du tout, puis retire les parts déjà prises dans la même unité de partage.
:::

::: etape Je raisonne
Le tout contient quatre quarts.
:::

::: resultat
$\dfrac{1}{4}$.
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{3}{8}$ < $\dfrac{3}{4}$ : on prend trois parts, mais les huitièmes sont plus petits.
2. $\dfrac{1}{8}$ < $\dfrac{1}{4}$.
3. $\dfrac{3}{4}$ = $\dfrac{6}{8}$.
4. $\dfrac{3}{8}$.
5. $\dfrac{1}{4}$.

Id: nouveau-2
Difficulté: easy

3. Combien de dixièmes séparent $\dfrac{3}{10}$ et $\dfrac{7}{10}$ ?

5. Un gâteau identique est partagé entre deux enfants : l’un prend $\dfrac{7}{10}$, l’autre $\dfrac{3}{10}$. Peut-on donner ces parts ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Complète avec < ou > : $\dfrac{5}{12}$ … $\dfrac{8}{12}$ ; $\dfrac{7}{10}$ … $\dfrac{3}{10}$.

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
On représente chaque fraction par des parts égales du même tout.

< ; >.
:::

::: resultat
< ; >.
:::

## Question 2 : Combien de douzièmes séparent $\dfrac{5}{12}$ et $\dfrac{8}{12}$ ?

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
Les parts ont la même taille ; on compte les parts supplémentaires.
:::

::: resultat
$\dfrac{3}{12}$.
:::

## Question 3 : Combien de dixièmes séparent $\dfrac{3}{10}$ et $\dfrac{7}{10}$ ?

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
On retire 3 parts aux 7 parts.
:::

::: resultat
$\dfrac{4}{10}$.
:::

## Question 4 : Écris une fraction entre $\dfrac{5}{12}$ et $\dfrac{8}{12}$.

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
On garde les mêmes parts et on choisit 6 ou 7 parts.
:::

::: resultat
Par exemple $\dfrac{6}{12}$.
:::

## Question 5 : Un gâteau identique est partagé entre deux enfants : l’un prend $\dfrac{7}{10}$, l’autre $\dfrac{3}{10}$. Peut-on donner ces parts ?

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
On réunit les dixièmes pris par les enfants.
:::

::: resultat

:::

Solution:
<!-- optitab:1 -->
1. < ; >.
2. $\dfrac{3}{12}$.
3. $\dfrac{4}{10}$.
4. Par exemple $\dfrac{6}{12}$.

::: etape Je raisonne
On représente chaque fraction par des parts égales du même tout.

$\dfrac{2}{5}$ = $\dfrac{4}{10}$ ; donc $\dfrac{2}{5}$ < $\dfrac{5}{10}$.
:::

::: resultat
$\dfrac{2}{5}$ = $\dfrac{4}{10}$ ; donc $\dfrac{2}{5}$ < $\dfrac{5}{10}$.

## Question 2 : Combien de dixièmes représente un cinquième ?

::: methode
Utilise le schéma pour relier chaque donnée à la quantité qu’elle représente.
:::

::: etape Je raisonne

:::

::: methode
Compte les parts du tout, puis retire les parts déjà prises dans la même unité de partage.
:::

::: etape Je raisonne
$\dfrac{2}{5}$ vaut $\dfrac{4}{10}$ ; on complète jusqu’à $\dfrac{5}{10}$.
:::

::: resultat
$\dfrac{1}{10}$.

Prends des bandes de même longueur et compare les portions recouvertes.
:::

::: etape Je raisonne

::: resultat

## Question 4 : Écris $\dfrac{4}{12}$ avec des tiers.

::: methode
Compare des parts de même taille ; si nécessaire, redécoupe une des bandes.
:::

::: etape Je raisonne
Quatre douzièmes recouvrent un tiers du tout.
:::

::: resultat
$\dfrac{4}{12}$ = $\dfrac{1}{3}$.
:::

## Question 5 : Compare $\dfrac{2}{12}$ et $\dfrac{2}{6}$ sur le même tout.

::: methode
Prends des bandes de même longueur et compare les portions recouvertes.
:::

::: etape Je raisonne
Deux sixièmes valent quatre douzièmes.
:::

::: resultat
$\dfrac{2}{12}$ < $\dfrac{2}{6}$.
:::

Solution:
<!-- optitab:1 -->
1. À numérateur égal, les douzièmes sont plus petits que les sixièmes. Donc $\dfrac{4}{12}$ < $\dfrac{4}{6}$.
2. $\dfrac{4}{6}$ = $\dfrac{8}{12}$.
3. $\dfrac{4}{12}$.
4. $\dfrac{4}{12}$ = $\dfrac{1}{3}$.
5. $\dfrac{2}{12}$ < $\dfrac{2}{6}$.
