    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition générale d'un nombre complexe</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition formelle</h3>
        
        <p>Un <strong>nombre complexe</strong> est un nombre qui peut s'écrire sous la forme $\displaystyle z = x + y\,\mathrm{i}$ où $x$ et $y$ sont des nombres réels, et $\mathrm{i}$ est l'unité imaginaire définie par $\displaystyle \mathrm{i}^2 = -1$.</p>
        
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p>On dit que $z$ est un <strong>nombre complexe</strong> si :</p>
            <p style="margin:8px 0;">$$z = x + y\,\mathrm{i} \quad \text{avec } x,y \in \mathbb{R}$$</p>
        </div>

        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Notation :</strong> L'ensemble des nombres complexes est noté $\displaystyle \mathbb{C}$. Le nombre $x$ est appelé <em>partie réelle</em> et $y$ est appelé <em>partie imaginaire</em> de $z$.
        </div>

        <div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>💡 Interprétation :</strong> Les nombres complexes étendent l'ensemble des nombres réels en ajoutant une dimension "imaginaire".
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Forme algébrique et propriétés</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>
        
        <p>La <strong>forme algébrique</strong> d'un nombre complexe $z$ est l'écriture $\displaystyle z = x + y\,\mathrm{i}$ où $x = \Re(z)$ et $y = Im(z)$.</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p>On dit que $z$ est sous <strong>forme algébrique</strong> si :</p>
            <p style="margin:8px 0;">$$z = \Re(z) + Im(z)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>$\displaystyle z_1 = 3 + 4\mathrm{i}$ : partie réelle = 3, partie imaginaire = 4</li>
                <li>$\displaystyle z_2 = -2 + 5\mathrm{i}$ : partie réelle = -2, partie imaginaire = 5</li>
                <li>$\displaystyle z_3 = 7$ : partie réelle = 7, partie imaginaire = 0 (nombre réel)</li>
                <li>$\displaystyle z_4 = 2\mathrm{i}$ : partie réelle = 0, partie imaginaire = 2 (imaginaire pur)</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriétés :</strong> Un nombre complexe est réel si sa partie imaginaire est nulle, et imaginaire pur si sa partie réelle est nulle.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Opérations sur les nombres complexes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Addition et soustraction</h3>
        
        <p>Pour deux nombres complexes $\displaystyle z_1 = x_1 + y_1\,\mathrm{i}$ et $\displaystyle z_2 = x_2 + y_2\,\mathrm{i}$ :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p><strong>Addition :</strong></p>
            <p style="margin:8px 0;">$$z_1 + z_2 = (x_1 + x_2) + (y_1 + y_2)\,\mathrm{i}$$</p>
            <p><strong>Soustraction :</strong></p>
            <p style="margin:8px 0;">$$z_1 - z_2 = (x_1 - x_2) + (y_1 - y_2)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle (3 + 2\mathrm{i}) + (1 - 4\mathrm{i}) = (3+1) + (2-4)\mathrm{i} = 4 - 2\mathrm{i}$
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Multiplication</h3>
        
        <p>Pour multiplier deux nombres complexes, on développe en utilisant $\displaystyle \mathrm{i}^2 = -1$ :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p>$$z_1 \cdot z_2 = (x_1x_2 - y_1y_2) + (x_1y_2 + x_2y_1)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle (2 + 3\mathrm{i})(1 - 2\mathrm{i}) = 2 - 4\mathrm{i} + 3\mathrm{i} - 6\mathrm{i}^2 = 2 - \mathrm{i} + 6 = 8 - \mathrm{i}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Conjugué et module</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conjugué d'un nombre complexe</h3>
        
        <p>Le <strong>conjugué</strong> du nombre complexe $\displaystyle z = x + y\,\mathrm{i}$ est le nombre $\displaystyle \overline{z} = x - y\,\mathrm{i}$.</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$\overline{z} = x - y\,\mathrm{i}$$
        </div>
        
        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriétés du conjugué :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>$\displaystyle \overline{\overline{z}} = z$</li>
                <li>$\displaystyle \overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$</li>
                <li>$\displaystyle \overline{z_1 \cdot z_2} = \overline{z_1} \cdot \overline{z_2}$</li>
                <li>$\displaystyle z$ est réel si et seulement si $\displaystyle \overline{z} = z$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Module d'un nombre complexe</h3>
        
        <p>Le <strong>module</strong> du nombre complexe $\displaystyle z = x + y\,\mathrm{i}$ est le nombre réel positif $\displaystyle |z| = \sqrt{x^2 + y^2}$.</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$|z| = \sqrt{x^2 + y^2}$$
        </div>
        
        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriétés du module :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>$\displaystyle |z|^2 = z \cdot \overline{z}$</li>
                <li>$\displaystyle |z_1 \cdot z_2| = |z_1| \cdot |z_2|$</li>
                <li>$\displaystyle |z_1 + z_2| \leq |z_1| + |z_2|$ (inégalité triangulaire)</li>
                <li>$\displaystyle |z| = 0$ si et seulement si $\displaystyle z = 0$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Division et inverse</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Inverse d'un nombre complexe</h3>
        
        <p>Pour calculer l'inverse d'un nombre complexe non nul $\displaystyle z = x + y\,\mathrm{i}$, on utilise le conjugué :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$\frac{1}{z} = \frac{\overline{z}}{|z|^2} = \frac{x - y\,\mathrm{i}}{x^2 + y^2}$$
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle\frac{1}{3 + 4\mathrm{i}} = \frac{3 - 4\mathrm{i}}{3^2 + 4^2} = \frac{3 - 4\mathrm{i}}{25} = \frac{3}{25} - \frac{4}{25}\mathrm{i}$
        </div>
        </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Division de deux nombres complexes</h3>
        
        <p>Pour diviser $z_1$ par $\displaystyle z_2 \neq 0$, on multiplie le numérateur et le dénominateur par le conjugué du dénominateur :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$\frac{z_1}{z_2} = \frac{z_1 \cdot \overline{z_2}}{|z_2|^2}$$
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle \frac{2 + \mathrm{i}}{1 - 3\mathrm{i}} = \frac{(2 + \mathrm{i})(1 + 3\mathrm{i})}{(1 - 3\mathrm{i})(1 + 3\mathrm{i})} = \frac{2 + 6\mathrm{i} + \mathrm{i} + 3\mathrm{i}^2}{1 + 9} = \frac{2 + 7\mathrm{i} - 3}{10} = \frac{-1 + 7\mathrm{i}}{10}$
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Pourquoi multiplier par le conjugué ?</h3>
        
        <p>Lorsqu'on divise deux nombres complexes, le dénominateur contient généralement une partie imaginaire. Pour obtenir un résultat sous forme algébrique (sans $\mathrm{i}$ au dénominateur), on utilise une <strong>astuce</strong> :</p>

        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>📐 Le principe :</strong> Si $\displaystyle z = x + y\,\mathrm{i}$, alors $\displaystyle z \cdot \overline{z} = (x + y\,\mathrm{i})(x - y\,\mathrm{i}) = x^2 + y^2$ (nombre réel)
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Explication détaillée :</strong>
            <div style="margin:8px 0;">
                $\displaystyle (x + y\,\mathrm{i})(x - y\,\mathrm{i}) = x^2 - x \cdot y\,\mathrm{i} + x \cdot y\,\mathrm{i} - y^2\,\mathrm{i}^2$<br>
                $\displaystyle = x^2 - y^2\,\mathrm{i}^2 = x^2 - y^2(-1) = x^2 + y^2$
            </div>
            <p style="margin:8px 0;"><strong>Résultat :</strong> Le produit d'un nombre complexe par son conjugué donne toujours un nombre réel positif (le carré du module).</p>
        </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Application pratique :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Multiplier le numérateur ET le dénominateur par le conjugué du dénominateur</li>
                <li>Le dénominateur devient un nombre réel (carré du module)</li>
                <li>On peut alors diviser normalement et obtenir une forme algébrique</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple concret :</strong> Pour $\displaystyle \frac{1}{3 + 4\mathrm{i}}$<br>
            <div style="margin:8px 0;">
                • Conjugué de $\displaystyle (3 + 4\mathrm{i})$ : $\displaystyle (3 - 4\mathrm{i})$<br>
                • $\displaystyle (3 + 4\mathrm{i})(3 - 4\mathrm{i}) = 3^2 + 4^2 = 9 + 16 = 25$ (réel !)<br>
                • $\displaystyle \frac{1}{3 + 4\mathrm{i}} = \frac{3 - 4\mathrm{i}}{25} = \frac{3}{25} - \frac{4}{25}\mathrm{i}$
            </div>
        </div>

        <div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>💡 Méthode à retenir :</strong> Toujours multiplier par le conjugué du dénominateur pour "rationaliser" et éliminer la partie imaginaire du dénominateur.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Représentation géométrique</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Plan complexe</h3>
        
        <p>À tout nombre complexe $\displaystyle z = x + y\,\mathrm{i}$, on associe le point $M(x, y)$ du plan muni d'un repère orthonormé.</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p>Le <strong>plan complexe</strong> associe :</p>
            <p style="margin:8px 0;">$$z = x + y\,\mathrm{i} \leftrightarrow M(x, y)$$</p>
        </div>

        <div style="text-align:center; margin:20px 0;">
            [IMAGE_1]
        </div>

        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Interprétation :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>L'axe des abscisses représente les nombres réels</li>
                <li>L'axe des ordonnées représente les imaginaires purs</li>
                <li>Le module $\displaystyle |z|$ est la distance $OM$ à l'origine</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriété :</strong> Le conjugué $\displaystyle \overline{z}$ correspond au symétrique de $\displaystyle z$ par rapport à l'axe des abscisses.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Argument et forme trigonométrique</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Argument d'un nombre complexe</h3>
        
        <p>Pour $\displaystyle z \neq 0$, un <strong>argument</strong> de $z$ est l'angle orienté $(\vec{u}, \vec{OM})$ où $\vec{u}$ est le vecteur unitaire de l'axe des abscisses.</p>
        

        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            <p>On note $\arg(z)$ l'argument principal :</p>
            <p style="margin:8px 0;">$$\arg(z) \in ]-\pi, \pi]$$</p>
        </div>

        <div style="text-align:center; margin:20px 0;">
        [IMAGE_2]
    </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Calcul de l'argument par quadrants :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li><strong>Quadrant I</strong> ($x > 0$, $y > 0$) : $\displaystyle \arg(z) = \arctan\left(\frac{y}{x}\right) = \theta \in \left]0, \frac{\pi}{2}\right[$</li>
                <li><strong>Quadrant II</strong> ($x < 0$, $y \geq 0$) : $\displaystyle \arg(z) = \arctan\left(\frac{y}{x}\right) + \pi = \pi - \theta \in \left]\frac{\pi}{2}, \pi\right]$</li>
                <li><strong>Quadrant III</strong> ($x < 0$, $y < 0$) : $\displaystyle \arg(z) = \arctan\left(\frac{y}{x}\right) - \pi = -\pi + \theta \in \left]-\pi, -\frac{\pi}{2}\right[$</li>
                <li><strong>Quadrant IV</strong> ($x > 0$, $y < 0$) : $\displaystyle \arg(z) = \arctan\left(\frac{y}{x}\right) = -\theta \in \left]-\frac{\pi}{2}, 0\right[$</li>
            </ul>
            <p style="margin:8px 0; font-size:0.9em;"><strong>Où :</strong> $\displaystyle \theta = \arctan\left(\frac{|y|}{|x|}\right) \in \left]0, \frac{\pi}{2}\right[$</p>
        </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Cas particuliers sur les axes :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li><strong>Axe réel positif</strong> ($x > 0$, $y = 0$) : $\displaystyle \arg(z) = 0$</li>
                <li><strong>Axe imaginaire positif</strong> ($x = 0$, $y > 0$) : $\displaystyle \arg(z) = \frac{\pi}{2}$</li>
                <li><strong>Axe réel négatif</strong> ($x < 0$, $y = 0$) : $\displaystyle \arg(z) = \pi$</li>
                <li><strong>Axe imaginaire négatif</strong> ($x = 0$, $y < 0$) : $\displaystyle \arg(z) = -\frac{\pi}{2}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Forme trigonométrique</h3>
        
        <p>Tout nombre complexe $\displaystyle z \neq 0$ peut s'écrire sous forme trigonométrique :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$z = |z|(\cos\theta + \mathrm{i}\sin\theta)$$
        </div>
        
        <p>où $\displaystyle \theta = \arg(z)$.</p>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle z = 1 + \mathrm{i}$ a pour module $\displaystyle |z| = \sqrt{2}$ et argument $\displaystyle \arg(z) = \frac{\pi}{4}$<br>
            Donc $\displaystyle z = \sqrt{2}\left(\cos\frac{\pi}{4} + \mathrm{i}\sin\frac{\pi}{4}\right)$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Formule de Moivre et puissances</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formule de Moivre</h3>
        
        <p>Si $\displaystyle z = |z|(\cos\theta + \mathrm{i}\sin\theta)$, alors pour tout entier naturel $n$ :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$z^n = |z|^n(\cos(n\theta) + \mathrm{i}\sin(n\theta))$$
        </div>
        
        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriétés des arguments :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>$\displaystyle \arg(z_1 \cdot z_2) \equiv \arg(z_1) + \arg(z_2) \pmod{2\pi}$</li>
                <li>$\displaystyle \arg\left(\frac{z_1}{z_2}\right) \equiv \arg(z_1) - \arg(z_2) \pmod{2\pi}$</li>
                <li>$\displaystyle \arg(z^n) \equiv n \cdot \arg(z) \pmod{2\pi}$</li>
                <li>$\displaystyle \arg(\overline{z}) \equiv -\arg(z) \pmod{2\pi}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple détaillé : Calcul de puissance</h3>
        
        <p><strong>Énoncé :</strong> Calculer $(1 + \mathrm{i})^8$.</p>
        
        <p><strong>Résolution :</strong></p>
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <ul style="margin:0; padding-left:20px;">
                <li><strong>Étape 1 :</strong> Calculer le module : $\displaystyle |1 + \mathrm{i}| = \sqrt{1^2 + 1^2} = \sqrt{2}$</li>
                <li><strong>Étape 2 :</strong> Calculer l'argument : $\displaystyle \arg(1 + \mathrm{i}) = \frac{\pi}{4}$</li>
                <li><strong>Étape 3 :</strong> Appliquer la formule de Moivre</li>
            </ul>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Calcul :</strong>
            <div style="margin:8px 0; text-align:left;">
                $\displaystyle (1 + \mathrm{i})^8 = (\sqrt{2})^8\left(\cos\left(8 \times \frac{\pi}{4}\right) + \mathrm{i}\sin\left(8 \times \frac{\pi}{4}\right)\right)$<br>
                $\displaystyle (1 + \mathrm{i})^8 = (\sqrt{2})^8(\cos(2\pi) + \mathrm{i}\sin(2\pi))$<br>
                $\displaystyle (1 + \mathrm{i})^8 = 16(1 + 0) = 16$
            </div>
        </div>
        
        <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
            <strong>✅ Réponse :</strong> $\displaystyle (1 + \mathrm{i})^8 = 16$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Forme exponentielle </h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formule d'Euler</h3>
        
        <p>La formule d'Euler permet d'écrire :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta$$
        </div>
        
        <p>Donc tout nombre complexe $\displaystyle z \neq 0$ s'écrit sous <strong>forme exponentielle</strong> :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$z = |z| \cdot e^{\mathrm{i}\theta}$$
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle z = 1 + \mathrm{i} = \sqrt{2} \cdot e^{\mathrm{i}\frac{\pi}{4}}$
        </div>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">X. Équations complexes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Équations du second degré</h3>
        
        
        <p>L'équation $\displaystyle az^2 + bz + c = 0$ ($\displaystyle a \neq 0$) admet toujours des solutions dans $\mathbb{C}$.</p>

        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>📐 Méthode de résolution :</strong>
            <ol style="margin:8px 0; padding-left:20px;">
                <li><strong>Calculer le discriminant :</strong> $\displaystyle \Delta = b^2 - 4ac$</li>
                <li><strong>Si $\Delta \geq 0$ :</strong> Solutions réelles classiques</li>
                <li><strong>Si $\Delta < 0$ :</strong> Solutions complexes conjuguées</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Cas $\Delta < 0$ (solutions complexes) :</strong>
            <div style="margin:8px 0;">
                $\displaystyle \Delta = -|\Delta| = -|\Delta| \times \mathrm{i}^2 = |\Delta| \mathrm{i}^2$<br>
                Donc $\displaystyle \sqrt{\Delta} = \mathrm{i}\sqrt{|\Delta|}$<br>
                Solutions : $\displaystyle z = \frac{-b \pm \mathrm{i}\sqrt{|\Delta|}}{2a}$
            </div>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple détaillé :</strong> Résoudre $\displaystyle z^2 - 2z + 5 = 0$<br>
            <div style="margin:8px 0;">
                <strong>Étape 1 :</strong> Calculer le discriminant<br>
                $\displaystyle \Delta = b^2 - 4ac = (-2)^2 - 4 \times 1 \times 5 = 4 - 20 = -16$<br><br>
                
                <strong>Étape 2 :</strong> Comme $\Delta < 0$, les solutions sont complexes<br>
                $\displaystyle \sqrt{\Delta} = \sqrt{-16} = \mathrm{i}\sqrt{16} = 4\mathrm{i}$<br><br>
                
                <strong>Étape 3 :</strong> Appliquer la formule<br>
                $\displaystyle z = \frac{-b \pm \sqrt{\Delta}}{2a} = \frac{-(-2) \pm 4\mathrm{i}}{2 \times 1} = \frac{2 \pm 4\mathrm{i}}{2}$<br>
                $\displaystyle z_1 = \frac{2 + 4\mathrm{i}}{2} = 1 + 2\mathrm{i}$<br>
                $\displaystyle z_2 = \frac{2 - 4\mathrm{i}}{2} = 1 - 2\mathrm{i}$
            </div>
        </div>

        <div style="background:#f3e5f5; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #9c27b0;">
            <strong>🟣 Propriété importante :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Les solutions complexes d'une équation à coefficients réels sont conjuguées</li>
                <li>Si $\displaystyle z_1$ est solution, alors $\displaystyle \overline{z_1}$ l'est aussi</li>
                <li>Somme des racines : $\displaystyle z_1 + z_2 = -\frac{b}{a}$</li>
                <li>Produit des racines : $\displaystyle z_1 \times z_2 = \frac{c}{a}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Racines n-ièmes de l'unité</h3>
        
        <p>Les solutions de $\displaystyle z^n = 1$ sont les racines n-ièmes de l'unité :</p>
        
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $$z_k = e^{\mathrm{i}\frac{2k\pi}{n}} = \cos\frac{2k\pi}{n} + \mathrm{i}\sin\frac{2k\pi}{n}$$
        </div>

        <p>pour $\displaystyle k = 0, 1, \ldots, n-1$. Elles forment les sommets d'un polygone régulier inscrit dans le cercle unité.</p>
        
    
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> Les racines 6-ièmes de l'unité sont :<br>
            $\displaystyle z_0 = 1$, $\displaystyle z_1 = e^{\mathrm{i}\frac{\pi}{3}} = \frac{1}{2} + \mathrm{i}\frac{\sqrt{3}}{2}$, $\displaystyle z_2 = e^{\mathrm{i}\frac{2\pi}{3}} = -\frac{1}{2} + \mathrm{i}\frac{\sqrt{3}}{2}$<br>
            $\displaystyle z_3 = -1$, $\displaystyle z_4 = e^{\mathrm{i}\frac{4\pi}{3}} = -\frac{1}{2} - \mathrm{i}\frac{\sqrt{3}}{2}$, $\displaystyle z_5 = e^{\mathrm{i}\frac{5\pi}{3}} = \frac{1}{2} - \mathrm{i}\frac{\sqrt{3}}{2}$
        </div>

        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XI. Transformations géométriques</h2>
    
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Transformations de base</h3>
        
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Transformation</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Effet géométrique</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto z + z_0$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Translation de vecteur $\displaystyle \overrightarrow{OO_0}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto kz$ ($\displaystyle k \in \mathbb{R}^*$)</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Homothétie de centre $O$, rapport $\displaystyle k$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto e^{\mathrm{i}\varphi}z$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Rotation de centre $O$, angle $\displaystyle \varphi$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto \overline{z}$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Symétrie par rapport à l'axe réel</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> La transformation $\displaystyle f(z) = (1 + \mathrm{i})z$<br>
            $\displaystyle |1 + \mathrm{i}| = \sqrt{2}$ et $\displaystyle \arg(1 + \mathrm{i}) = \frac{\pi}{4}$<br>
            Donc $f$ = homothétie de rapport $\displaystyle \sqrt{2}$ + rotation d'angle $\displaystyle \frac{\pi}{4}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XII. Méthodes pratiques</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Passage de la forme algébrique à la forme trigonométrique</h3>
        
        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>📐 Étapes :</strong>
            <ol style="margin:8px 0; padding-left:20px;">
                <li>Calculer le module : $\displaystyle r = |z| = \sqrt{x^2 + y^2}$</li>
                <li>Déterminer un argument : résoudre $\displaystyle \cos\theta = \frac{x}{r}$ et $\displaystyle \sin\theta = \frac{y}{r}$</li>
                <li>Vérifier le quadrant selon les signes de $x$ et $y$</li>
                <li>Conclure : $\displaystyle z = r(\cos\theta + \mathrm{i}\sin\theta)$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple guidé :</strong> Convertir $\displaystyle z = -\sqrt{3} + \mathrm{i}$<br>
            • $\displaystyle r = \sqrt{(-\sqrt{3})^2 + 1^2} = 2$<br>
            • $\displaystyle \cos\theta = \frac{-\sqrt{3}}{2}$, $\displaystyle \sin\theta = \frac{1}{2}$<br>
            • Quadrant II, donc $\displaystyle \theta = \frac{5\pi}{6}$<br>
            • $\displaystyle z = 2(\cos\frac{5\pi}{6} + \mathrm{i}\sin\frac{5\pi}{6})$
        </div>
        </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XIII. Erreurs fréquentes et conseils</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fdf2f2; padding:12px; border-radius:4px; margin-bottom:10px;">
            <strong>❌ Pièges à éviter :</strong>
            <div style="margin:8px 0;">
                <ul style="margin:0; padding-left:20px;">
                    <li>Oublier que $\displaystyle \mathrm{i}^2 = -1$ lors des développements</li>
                    <li>Confondre conjugué $\displaystyle \overline{z}$ et opposé $\displaystyle -z$</li>
                    <li>Mauvais quadrant pour l'argument (vérifier les signes de $x$ et $y$)</li>
                    <li>Écrire $\displaystyle |z_1 + z_2| = |z_1| + |z_2|$ (faux en général)</li>
                    <li>Oublier le facteur $\displaystyle r^n$ dans la formule de Moivre</li>
                    <li>Utiliser les formules de trigonométrie sans vérifier le quadrant</li>
                    <li>Confondre module et argument dans les calculs</li>
            </ul>
        </div>
    </div>

        <div style="background:#f0f9f0; padding:12px; border-radius:4px;">
            <strong>✅ Conseils méthodologiques :</strong>
            <div style="margin:8px 0;">
                <ul style="margin:0; padding-left:20px;">
                    <li>Utiliser le conjugué pour rationaliser les dénominateurs</li>
                    <li>Passer en trigonométrique pour produits/quotients/puissances</li>
                    <li>Vérifier systématiquement le quadrant pour l'argument</li>
                    <li>Utiliser l'inégalité triangulaire : $\displaystyle |z_1 + z_2| \leq |z_1| + |z_2|$</li>
                    <li>Penser géométriquement : module = distance, argument = angle</li>
                    <li>Mémoriser les valeurs trigonométriques des angles remarquables</li>
                    <li>Faire des calculs intermédiaires clairs pour éviter les erreurs</li>
            </ul>
            </div>
        </div>
    </div>
