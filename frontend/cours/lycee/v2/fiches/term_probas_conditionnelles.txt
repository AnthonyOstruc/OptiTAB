<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Conditionnement</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$P(B) = P(A)P_A(B) + P(\overline{A})P_{\overline{A}}(B)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $P(A \cap B) = P(A) \times P_A(B)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Inversion : $P_B(A) = \frac{P(A \cap B)}{P(B)}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Chemin = produit ; événement = somme des chemins.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Indépendance</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Indépendants : $P(A \cap B) = P(A)P(B)$ ou $P_A(B) = P(B)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $A$ et $B$ indépendants $\Rightarrow \overline{A}$ et $B$ indépendants.</p>
<p style="margin:6px 0 0 0;">3️⃣ Épreuves indépendantes : on multiplie ; « au moins un » → $1 - P(\text{aucun})$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre $P_A(B)$ et $P_B(A)$ (fiabilité d’un test et diagnostic).</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier un chemin dans les probabilités totales.</p>
<p style="margin:6px 0 0 0;">3️⃣ Confondre indépendants et incompatibles.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de compter tous les chemins (« exactement 2 » = 3 chemins).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> l’énoncé donne $P_A(B)$ et demande $P_B(A)$ → arbre, probabilités totales pour $P(B)$, puis division.</p>
</div>
