📚 Objectif pédagogique : retenir l’essentiel : radian, cosinus et sinus, valeurs remarquables, angles associés. Programme de Première.

I. Cercle et valeurs remarquables

$\displaystyle M(t)\,(\cos t\,;\sin t)$ et $\displaystyle \cos^2 t + \sin^2 t = 1$

[IMAGE_1]

1️⃣ $\displaystyle \pi$ rad $\displaystyle = 180°$ ; un tour $\displaystyle = 2\pi$ ; $\displaystyle t$ et $\displaystyle t + 2k\pi$ donnent le même point.

2️⃣ $\displaystyle -1 \le \cos t \le 1$ et $\displaystyle -1 \le \sin t \le 1$.

3️⃣ $\displaystyle \cos$ paire, $\displaystyle \sin$ impaire, période $\displaystyle 2\pi$.

II. Angles associés

[IMAGE_2]

1️⃣ $\displaystyle \cos(-x) = \cos x$ ; $\displaystyle \sin(-x) = -\sin x$.

2️⃣ $\displaystyle \cos(\pi - x) = -\cos x$ ; $\displaystyle \sin(\pi - x) = \sin x$.

3️⃣ $\displaystyle \cos(\pi + x) = -\cos x$ ; $\displaystyle \sin(\pi + x) = -\sin x$ ; $\displaystyle \cos\left(\frac{\pi}{2} - x\right) = \sin x$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Calculatrice en degrés au lieu de radians.

2️⃣ Inverser les valeurs : $\displaystyle \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$ mais $\displaystyle \cos\frac{\pi}{3} = \frac{1}{2}$.

3️⃣ Oublier une solution : $\displaystyle \cos x = \frac{1}{2}$ a deux solutions par tour.

4️⃣ Écrire $\displaystyle \cos(a + b) = \cos a + \cos b$.

🏆 Réflexe : je place toujours le point sur le cercle trigonométrique avant de calculer : le signe de $\displaystyle \cos$ et de $\displaystyle \sin$ se lit sur la figure.
