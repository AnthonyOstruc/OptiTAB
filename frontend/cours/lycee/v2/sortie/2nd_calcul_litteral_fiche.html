I. Les règles de calcul

$\displaystyle (a + b)^2 = a^2 + 2ab + b^2$ ; $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$ ; $\displaystyle (a + b)(a - b) = a^2 - b^2$

• Puissances : $\displaystyle a^n a^m = a^{n+m}$ ; $\displaystyle (a^n)^m = a^{nm}$ ; $\displaystyle a^{-n} = \frac{1}{a^n}$.

• Racines : $\displaystyle \sqrt{ab} = \sqrt{a}\sqrt{b}$ ($\displaystyle a, b \ge 0$) ; $\displaystyle \sqrt{50} = 5\sqrt{2}$.

II. Équations, inéquations, signe

1️⃣ Produit nul : $\displaystyle A \times B = 0 \iff A = 0$ ou $\displaystyle B = 0$.

2️⃣ $\displaystyle x^2 = a$ : $\displaystyle \pm\sqrt{a}$ si $\displaystyle a \gt 0$ ; $\displaystyle 0$ si $\displaystyle a = 0$ ; aucune solution si $\displaystyle a \lt 0$.

3️⃣ Multiplier ou diviser par un négatif change le sens de l’inégalité.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Écrire $\displaystyle (a + b)^2 = a^2 + b^2$ : il manque le double produit $\displaystyle 2ab$.

2️⃣ Écrire $\displaystyle \sqrt{a + b} = \sqrt{a} + \sqrt{b}$ : faux ($\displaystyle \sqrt{25} \neq 3 + 4$).

3️⃣ Diviser par $\displaystyle x$ pour résoudre $\displaystyle x^2 = 5x$ : on perd la solution $\displaystyle 0$ ; il faut factoriser.

4️⃣ Oublier de changer le sens en divisant par un négatif : $\displaystyle -2x \le -6 \iff x \ge 3$.

🏆 Réflexe : équation ou inéquation de degré 2 → tout d’un côté, factoriser, puis produit nul ou tableau de signes.
