=== Factorisation - Expressions avec Fractions
Id: 1464
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes contenant des fractions ou des coefficients rationnels.

1. Factoriser $\displaystyle \dfrac{1}{2}x + 2$
2. Factoriser $\displaystyle x^2 - \dfrac{1}{4}$
3. Factoriser $\displaystyle \dfrac{1}{4}x^2 + x + 1$
4. Factoriser $\displaystyle 2x^2 - \dfrac{1}{2}x$
5. Factoriser $\displaystyle \dfrac{9}{4}x^2 - 25$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle \dfrac{1}{2}x + 2$

::: methode
Facteur commun avec fraction
:::

::: etape Identifier le facteur commun
- $\displaystyle \dfrac{1}{2}x = \dfrac{1}{2} \times x$
- $\displaystyle 2 = \dfrac{1}{2} \times 4$
- Facteur commun : $\displaystyle \dfrac{1}{2}$
:::

::: etape Factoriser
- $\displaystyle \dfrac{1}{2}x + 2 = \dfrac{1}{2}(x + 4)$
:::

::: point Vérification
$$\dfrac{1}{2}(x + 4) = \dfrac{x}{2} + 2$$
:::

::: resultat
$$\dfrac{1}{2}x + 2 = \dfrac{1}{2}(x + 4)$$
:::

## Question 2 : Factoriser $\displaystyle x^2 - \dfrac{1}{4}$

::: methode
Identité remarquable (différence de carrés)
:::

::: etape Reconnaître la différence de carrés
- $\displaystyle x^2 - \dfrac{1}{4} = x^2 - \left(\dfrac{1}{2}\right)^2$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle x^2 - \dfrac{1}{4} = \left(x - \dfrac{1}{2}\right)\left(x + \dfrac{1}{2}\right)$
:::

::: point Vérification
$$\left(x - \dfrac{1}{2}\right)\left(x + \dfrac{1}{2}\right) = x^2 - \dfrac{1}{4}$$
:::

::: resultat
$$x^2 - \dfrac{1}{4} = \left(x - \dfrac{1}{2}\right)\left(x + \dfrac{1}{2}\right)$$
:::

## Question 3 : Factoriser $\displaystyle \dfrac{1}{4}x^2 + x + 1$

::: methode
Identité remarquable avec coefficient fractionnaire
:::

::: etape Reconnaître l'identité remarquable
- $\displaystyle \dfrac{1}{4}x^2 = \left(\dfrac{1}{2}x\right)^2$
- $\displaystyle 1 = 1^2$
- Vérifier : $\displaystyle x = 2 \times \dfrac{1}{2}x \times 1$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle \dfrac{1}{4}x^2 + x + 1 = \left(\dfrac{1}{2}x + 1\right)^2$
:::

::: point Vérification
$$\left(\dfrac{1}{2}x + 1\right)^2 = \dfrac{1}{4}x^2 + x + 1$$
:::

::: resultat
$$\dfrac{1}{4}x^2 + x + 1 = \left(\dfrac{1}{2}x + 1\right)^2$$
:::

## Question 4 : Factoriser $\displaystyle 2x^2 - \dfrac{1}{2}x$

::: methode
Facteur commun
:::

::: etape Identifier le facteur commun
- $\displaystyle 2x^2 = 2x \times x$
- $\displaystyle \dfrac{1}{2}x = 2x \times \dfrac{1}{4}$
- Facteur commun : $2x$ ou mieux : $\dfrac{x}{2}$ pour simplifier
- On peut aussi factoriser par $x$ : $2x^2 - \dfrac{1}{2}x = x\left(2x - \dfrac{1}{2}\right)$
:::

::: etape Factoriser avec facteur commun $\dfrac{x}{2}$
- $\displaystyle 2x^2 - \dfrac{1}{2}x = \dfrac{x}{2}(4x - 1)$
:::

::: point Vérification
$$\dfrac{x}{2}(4x - 1) = 2x^2 - \dfrac{x}{2}$$
:::

::: resultat
$2x^2 - \dfrac{1}{2}x = \dfrac{x}{2}(4x - 1)$ ou $x\left(2x - \dfrac{1}{2}\right)$
:::

## Question 5 : Factoriser $\displaystyle \dfrac{9}{4}x^2 - 25$

::: methode
Identité remarquable (différence de carrés)
:::

::: etape Reconnaître la différence de carrés
- $\displaystyle \dfrac{9}{4}x^2 = \left(\dfrac{3}{2}x\right)^2$
- $\displaystyle 25 = 5^2$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle \dfrac{9}{4}x^2 - 25 = \left(\dfrac{3}{2}x - 5\right)\left(\dfrac{3}{2}x + 5\right)$
:::

::: etape Simplifier en multipliant par $2$ pour éliminer les fractions
- $\displaystyle = \dfrac{1}{4}(3x - 10)(3x + 10)$
:::

::: point Vérification
$$
\begin{aligned}
\dfrac{1}{4}(3x - 10)(3x + 10) &= \dfrac{1}{4}(9x^2 - 100) \\
&= \dfrac{9}{4}x^2 - 25
\end{aligned}
$$
:::

::: resultat
$\dfrac{9}{4}x^2 - 25 = \left(\dfrac{3}{2}x - 5\right)\left(\dfrac{3}{2}x + 5\right)$ ou $\dfrac{1}{4}(3x - 10)(3x + 10)$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \dfrac{1}{2}x + 2 = \dfrac{1}{2}(x + 4)$
2. $\displaystyle x^2 - \dfrac{1}{4} = \left(x - \dfrac{1}{2}\right)\left(x + \dfrac{1}{2}\right)$
3. $\displaystyle \dfrac{1}{4}x^2 + x + 1 = \left(\dfrac{1}{2}x + 1\right)^2$
4. $2x^2 - \dfrac{1}{2}x = \dfrac{x}{2}(4x - 1)$ ou $x\left(2x - \dfrac{1}{2}\right)$
5. $\dfrac{9}{4}x^2 - 25 = \left(\dfrac{3}{2}x - 5\right)\left(\dfrac{3}{2}x + 5\right)$ ou $\dfrac{1}{4}(3x - 10)(3x + 10)$

=== Factorisation - Expressions avec Plusieurs Variables
Id: 1465
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes contenant plusieurs variables.

1. Factoriser $\displaystyle 3x + 6y$
2. Factoriser $\displaystyle x^2 - y^2$
3. Factoriser $\displaystyle x^2 + 2xy + y^2$
4. Factoriser $\displaystyle 2xy + 4x - 3y - 6$
5. Factoriser $\displaystyle x^2y - xy^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle 3x + 6y$

::: methode
Facteur commun
:::

::: etape Identifier le facteur commun
- $\displaystyle 3x = 3 \times x$
- $\displaystyle 6y = 3 \times 2y$
- Facteur commun : $\displaystyle 3$
:::

::: etape Factoriser
- $\displaystyle 3x + 6y = 3(x + 2y)$
:::

::: point Vérification
$$3(x + 2y) = 3x + 6y$$
:::

::: resultat
$$3x + 6y = 3(x + 2y)$$
:::

## Question 2 : Factoriser $\displaystyle x^2 - y^2$

::: methode
Identité remarquable (différence de carrés)
:::

::: etape Reconnaître la différence de carrés
- $\displaystyle x^2 - y^2 = (x)^2 - (y)^2$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle x^2 - y^2 = (x - y)(x + y)$
:::

::: point Vérification
$$(x - y)(x + y) = x^2 - y^2$$
:::

::: resultat
$$x^2 - y^2 = (x - y)(x + y)$$
:::

## Question 3 : Factoriser $\displaystyle x^2 + 2xy + y^2$

::: methode
Identité remarquable (carré d'une somme)
:::

::: etape Reconnaître l'identité remarquable
- $x^2$ est le carré de $x$, donc $a = x$
- $y^2$ est le carré de $y$, donc $b = y$
- Vérifier : $\displaystyle 2xy = 2 \times x \times y$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle x^2 + 2xy + y^2 = (x + y)^2$
:::

::: point Vérification
$$(x + y)^2 = x^2 + 2xy + y^2$$
:::

::: resultat
$$x^2 + 2xy + y^2 = (x + y)^2$$
:::

## Question 4 : Factoriser $\displaystyle 2xy + 4x - 3y - 6$

::: methode
Factorisation par groupement
:::

::: etape Grouper les termes par paires
- $\displaystyle 2xy + 4x - 3y - 6 = (2xy + 4x) + (-3y - 6)$
:::

::: etape Factoriser chaque groupe
- Premier groupe : $\displaystyle 2xy + 4x = 2x(y + 2)$
- Deuxième groupe : $\displaystyle -3y - 6 = -3(y + 2)$
:::

::: etape Factoriser le facteur commun
- $\displaystyle 2x(y + 2) - 3(y + 2) = (y + 2)(2x - 3)$
:::

::: point Vérification
$$
\begin{aligned}
(y + 2)(2x - 3) &= 2xy - 3y + 4x - 6 \\
&= 2xy + 4x - 3y - 6
\end{aligned}
$$
:::

::: resultat
$$2xy + 4x - 3y - 6 = (y + 2)(2x - 3)$$
:::

## Question 5 : Factoriser $\displaystyle x^2y - xy^2$

::: methode
Facteur commun avec plusieurs variables
:::

::: etape Identifier le facteur commun
- $\displaystyle x^2y = xy \times x$
- $\displaystyle xy^2 = xy \times y$
- Facteur commun : $xy$ (plus petit exposant pour chaque variable)
:::

::: etape Factoriser
- $\displaystyle x^2y - xy^2 = xy(x - y)$
:::

::: point Vérification
$$xy(x - y) = x^2y - xy^2$$
:::

::: resultat
$$x^2y - xy^2 = xy(x - y)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3x + 6y = 3(x + 2y)$
2. $\displaystyle x^2 - y^2 = (x - y)(x + y)$
3. $\displaystyle x^2 + 2xy + y^2 = (x + y)^2$
4. $\displaystyle 2xy + 4x - 3y - 6 = (y + 2)(2x - 3)$
5. $\displaystyle x^2y - xy^2 = xy(x - y)$

=== Factorisation - Facteur Commun
Id: 1457
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes en identifiant le facteur commun.

1. Factoriser $\displaystyle 3x + 6$
2. Factoriser $\displaystyle 5x^2 - 10x$
3. Factoriser $\displaystyle 4x^3 + 8x^2 - 12x$
4. Factoriser $\displaystyle 2(x+1) + 3(x+1)$
5. Factoriser $\displaystyle 6x^2 - 9x + 12$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle 3x + 6$

::: methode
Factorisation par facteur commun
:::

::: etape Identifier le facteur commun
- $\displaystyle 3x = 3 \times x$
- $\displaystyle 6 = 3 \times 2$
- Facteur commun : $\displaystyle 3$
:::

::: etape Mettre le facteur commun en évidence
- $\displaystyle 3x + 6 = 3 \times x + 3 \times 2$
:::

::: etape Factoriser
- $\displaystyle = 3(x + 2)$
:::

::: point Vérification
$$3(x + 2) = 3x + 6$$
:::

::: resultat
$$3x + 6 = 3(x + 2)$$
:::

## Question 2 : Factoriser $\displaystyle 5x^2 - 10x$

::: methode
Factorisation par facteur commun
:::

::: etape Identifier le facteur commun
- $\displaystyle 5x^2 = 5x \times x$
- $\displaystyle 10x = 5x \times 2$
- Facteur commun : $5x$ (coefficient $5$ et $x$ avec exposant $1$)
:::

::: etape Mettre le facteur commun en évidence
- $\displaystyle 5x^2 - 10x = 5x \times x - 5x \times 2$
:::

::: etape Factoriser
- $\displaystyle = 5x(x - 2)$
:::

::: point Vérification
$$5x(x - 2) = 5x^2 - 10x$$
:::

::: resultat
$$5x^2 - 10x = 5x(x - 2)$$
:::

## Question 3 : Factoriser $\displaystyle 4x^3 + 8x^2 - 12x$

::: methode
Factorisation par facteur commun
:::

::: etape Identifier le facteur commun numérique
- $\displaystyle PGCD(4, 8, 12) = 4$
:::

::: etape Identifier le facteur commun littéral
- Plus petit exposant de $x$ : $x^1$
- Facteur commun : $\displaystyle 4x$
:::

::: etape Mettre le facteur commun en évidence
- $\displaystyle 4x^3 + 8x^2 - 12x = 4x \times x^2 + 4x \times 2x - 4x \times 3$
:::

::: etape Factoriser
- $\displaystyle = 4x(x^2 + 2x - 3)$
:::

::: point Vérification
$$4x(x^2 + 2x - 3) = 4x^3 + 8x^2 - 12x$$
:::

::: resultat
$$4x^3 + 8x^2 - 12x = 4x(x^2 + 2x - 3)$$
:::

## Question 4 : Factoriser $\displaystyle 2(x+1) + 3(x+1)$

::: methode
Factorisation par facteur commun (expression entre parenthèses)
:::

::: etape Identifier le facteur commun
- Les deux termes contiennent $\displaystyle (x+1)$
- Facteur commun : $\displaystyle (x+1)$
:::

::: etape Mettre le facteur commun en évidence
- $\displaystyle 2(x+1) + 3(x+1) = (x+1)(2 + 3)$
:::

::: etape Simplifier
- $\displaystyle = (x+1) \times 5 = 5(x+1)$
:::

::: point Vérification
$$5(x+1) = 5x + 5 = 2(x+1) + 3(x+1)$$
:::

::: resultat
$$2(x+1) + 3(x+1) = 5(x+1)$$
:::

## Question 5 : Factoriser $\displaystyle 6x^2 - 9x + 12$

::: methode
Factorisation par facteur commun
:::

::: etape Identifier le facteur commun numérique
- $\displaystyle PGCD(6, 9, 12) = 3$
:::

::: etape Vérifier s'il y a un facteur commun littéral
- Pas de $x$ dans le terme constant $12$
- Facteur commun : $\displaystyle 3$ seulement
:::

::: etape Mettre le facteur commun en évidence
- $\displaystyle 6x^2 - 9x + 12 = 3 \times 2x^2 - 3 \times 3x + 3 \times 4$
:::

::: etape Factoriser
- $\displaystyle = 3(2x^2 - 3x + 4)$
:::

::: point Vérification
$$3(2x^2 - 3x + 4) = 6x^2 - 9x + 12$$
:::

::: resultat
$$6x^2 - 9x + 12 = 3(2x^2 - 3x + 4)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3x + 6 = 3(x + 2)$
2. $\displaystyle 5x^2 - 10x = 5x(x - 2)$
3. $\displaystyle 4x^3 + 8x^2 - 12x = 4x(x^2 + 2x - 3)$
4. $\displaystyle 2(x+1) + 3(x+1) = 5(x+1)$
5. $\displaystyle 6x^2 - 9x + 12 = 3(2x^2 - 3x + 4)$

=== Factorisation - Factorisations Avancées Combinées
Id: 1466
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes en combinant plusieurs méthodes de factorisation.

1. Factoriser $\displaystyle x^3 + 2x^2 - x - 2$
2. Factoriser $\displaystyle 4x^2 - 8x + 4 - y^2$
3. Factoriser $\displaystyle x^4 + 2x^2 + 1$
4. Factoriser $\displaystyle 2x^3 - 8x$
5. Factoriser $\displaystyle x^2 - 6x + 9 - 4y^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle x^3 + 2x^2 - x - 2$

::: methode
Groupement puis factorisation
:::

::: etape Grouper les termes
- $\displaystyle x^3 + 2x^2 - x - 2 = (x^3 + 2x^2) + (-x - 2)$
:::

::: etape Factoriser chaque groupe
- Premier groupe : $\displaystyle x^3 + 2x^2 = x^2(x + 2)$
- Deuxième groupe : $\displaystyle -x - 2 = -1(x + 2)$
:::

::: etape Factoriser le facteur commun
- $\displaystyle x^2(x + 2) - 1(x + 2) = (x + 2)(x^2 - 1)$
:::

::: etape Factoriser $x^2 - 1$ (différence de carrés)
- $\displaystyle x^2 - 1 = (x - 1)(x + 1)$
:::

::: etape Factorisation complète
- $\displaystyle x^3 + 2x^2 - x - 2 = (x + 2)(x - 1)(x + 1)$
:::

::: point Vérification
$$
\begin{aligned}
(x + 2)(x - 1)(x + 1) &= (x + 2)(x^2 - 1) \\
&= x^3 + 2x^2 - x - 2
\end{aligned}
$$
:::

::: resultat
$$x^3 + 2x^2 - x - 2 = (x + 2)(x - 1)(x + 1)$$
:::

## Question 2 : Factoriser $\displaystyle 4x^2 - 8x + 4 - y^2$

::: methode
Identité remarquable puis différence de carrés
:::

::: etape Factoriser le trinôme en facteur commun d'abord
- $\displaystyle 4x^2 - 8x + 4 = 4(x^2 - 2x + 1)$
:::

::: etape Reconnaître l'identité remarquable
- $\displaystyle x^2 - 2x + 1 = (x - 1)^2$
:::

::: etape Réécrire l'expression
- $\displaystyle 4x^2 - 8x + 4 - y^2 = 4(x - 1)^2 - y^2$
:::

::: etape Appliquer la différence de carrés
$$
\begin{aligned}
4(x - 1)^2 - y^2 &= (2(x - 1))^2 - y^2 \\
&= (2(x - 1) - y)(2(x - 1) + y) \\
&= (2x - 2 - y)(2x - 2 + y)
\end{aligned}
$$
:::

::: resultat
$$4x^2 - 8x + 4 - y^2 = (2x - 2 - y)(2x - 2 + y)$$
:::

## Question 3 : Factoriser $\displaystyle x^4 + 2x^2 + 1$

::: methode
Identité remarquable
:::

::: etape Reconnaître l'identité remarquable
- $\displaystyle x^4 = (x^2)^2$
- $\displaystyle 1 = 1^2$
- Vérifier : $\displaystyle 2x^2 = 2 \times x^2 \times 1$
:::

::: etape Appliquer l'identité remarquable
- $\displaystyle x^4 + 2x^2 + 1 = (x^2 + 1)^2$
:::

::: point Vérification
$$(x^2 + 1)^2 = x^4 + 2x^2 + 1$$
:::

::: remarque
$x^2 + 1$ ne se factorise pas dans $\mathbb{R}$ (discriminant négatif)
:::

::: resultat
$$x^4 + 2x^2 + 1 = (x^2 + 1)^2$$
:::

## Question 4 : Factoriser $\displaystyle 2x^3 - 8x$

::: methode
Facteur commun puis différence de carrés
:::

::: etape Identifier le facteur commun
- Facteur commun : $\displaystyle 2x$
- $\displaystyle 2x^3 - 8x = 2x(x^2 - 4)$
:::

::: etape Factoriser $x^2 - 4$ (différence de carrés)
- $\displaystyle x^2 - 4 = (x - 2)(x + 2)$
:::

::: etape Factorisation complète
- $\displaystyle 2x^3 - 8x = 2x(x - 2)(x + 2)$
:::

::: point Vérification
$$2x(x - 2)(x + 2) = 2x(x^2 - 4) = 2x^3 - 8x$$
:::

::: resultat
$$2x^3 - 8x = 2x(x - 2)(x + 2)$$
:::

## Question 5 : Factoriser $\displaystyle x^2 - 6x + 9 - 4y^2$

::: methode
Identité remarquable puis différence de carrés
:::

::: etape Reconnaître l'identité remarquable dans le trinôme
- $x^2 - 6x + 9 = (x - 3)^2$ (car $9 = 3^2$ et $6x = 2 \times x \times 3$)
:::

::: etape Réécrire l'expression
- $\displaystyle x^2 - 6x + 9 - 4y^2 = (x - 3)^2 - 4y^2$
:::

::: etape Appliquer la différence de carrés
$$
\begin{aligned}
(x - 3)^2 - 4y^2 &= (x - 3)^2 - (2y)^2 \\
&= ((x - 3) - 2y)((x - 3) + 2y) \\
&= (x - 3 - 2y)(x - 3 + 2y)
\end{aligned}
$$
:::

::: point Vérification
$$
\begin{aligned}
(x - 3 - 2y)(x - 3 + 2y) &= (x - 3)^2 - 4y^2 \\
&= x^2 - 6x + 9 - 4y^2
\end{aligned}
$$
:::

::: resultat
$$x^2 - 6x + 9 - 4y^2 = (x - 3 - 2y)(x - 3 + 2y)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle x^3 + 2x^2 - x - 2 = (x + 2)(x - 1)(x + 1)$
2. $\displaystyle 4x^2 - 8x + 4 - y^2 = (2x - 2 - y)(2x - 2 + y)$
3. $\displaystyle x^4 + 2x^2 + 1 = (x^2 + 1)^2$
4. $\displaystyle 2x^3 - 8x = 2x(x - 2)(x + 2)$
5. $\displaystyle x^2 - 6x + 9 - 4y^2 = (x - 3 - 2y)(x - 3 + 2y)$

=== Factorisation - Factorisations Complexes
Id: 1463
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes en combinant plusieurs méthodes.

1. Factoriser $\displaystyle 4x^2 - 12x + 9 - x^2 + 4$
2. Factoriser $\displaystyle x^4 - 1$
3. Factoriser $\displaystyle 2x^3 + 4x^2 - 6x$
4. Factoriser $\displaystyle x^2 + 2x + 1 - y^2$
5. Factoriser $\displaystyle 3x^2 - 12x + 12$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle 4x^2 - 12x + 9 - x^2 + 4$

::: methode
Réduire puis factoriser
:::

::: etape Réduire l'expression
- $\displaystyle 4x^2 - 12x + 9 - x^2 + 4 = 3x^2 - 12x + 13$
:::

::: etape Vérifier s'il y a un facteur commun
- Pas de facteur commun évident
:::

::: etape Calculer le discriminant du trinôme
$$
\begin{aligned}
\Delta &= (-12)^2 - 4 \times 3 \times 13 \\
&= 144 - 156 \\
&= -12
\end{aligned}
$$

- $\displaystyle \Delta < 0$, donc pas de racines réelles
:::

::: etape Conclusion
- L'expression ne se factorise pas dans $\mathbb{R}$
:::

::: resultat
L'expression $4x^2 - 12x + 9 - x^2 + 4 = 3x^2 - 12x + 13$ ne se factorise pas dans $\mathbb{R}$ (discriminant négatif)
:::

## Question 2 : Factoriser $\displaystyle x^4 - 1$

::: methode
Différence de carrés successive
:::

::: etape Reconnaître la première différence de carrés
- $\displaystyle x^4 - 1 = (x^2)^2 - 1^2 = (x^2 - 1)(x^2 + 1)$
:::

::: etape Factoriser $\displaystyle x^2 - 1$
- $\displaystyle x^2 - 1 = (x - 1)(x + 1)$
:::

::: etape Factoriser complètement
- $\displaystyle x^4 - 1 = (x^2 - 1)(x^2 + 1) = (x - 1)(x + 1)(x^2 + 1)$
- Note : $x^2 + 1$ ne se factorise pas dans $\mathbb{R}$ (discriminant négatif)
:::

::: resultat
$$x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)$$
:::

## Question 3 : Factoriser $\displaystyle 2x^3 + 4x^2 - 6x$

::: methode
Facteur commun puis trinôme
:::

::: etape Identifier le facteur commun
- Facteur commun : $2x$ (PGCD des coefficients : $2$, et $x$ avec exposant $1$)
- $\displaystyle 2x^3 + 4x^2 - 6x = 2x(x^2 + 2x - 3)$
:::

::: etape Factoriser le trinôme $\displaystyle x^2 + 2x - 3$
- Chercher deux nombres dont la somme est $2$ et le produit est $-3$
- Les nombres sont $3$ et $-1$ (car $3 + (-1) = 2$ et $3 \times (-1) = -3$)
:::

::: etape Factoriser complètement
- $\displaystyle x^2 + 2x - 3 = (x + 3)(x - 1)$
- $\displaystyle 2x^3 + 4x^2 - 6x = 2x(x + 3)(x - 1)$
:::

::: resultat
$$2x^3 + 4x^2 - 6x = 2x(x + 3)(x - 1)$$
:::

## Question 4 : Factoriser $\displaystyle x^2 + 2x + 1 - y^2$

::: methode
Identité remarquable puis différence de carrés
:::

::: etape Reconnaître l'identité remarquable
- $\displaystyle x^2 + 2x + 1 = (x + 1)^2$
:::

::: etape Réécrire l'expression
- $\displaystyle x^2 + 2x + 1 - y^2 = (x + 1)^2 - y^2$
:::

::: etape Appliquer la différence de carrés
$$
\begin{aligned}
(x + 1)^2 - y^2 &= ((x + 1) - y)((x + 1) + y) \\
&= (x + 1 - y)(x + 1 + y)
\end{aligned}
$$
:::

::: resultat
$$x^2 + 2x + 1 - y^2 = (x + 1 - y)(x + 1 + y)$$
:::

## Question 5 : Factoriser $\displaystyle 3x^2 - 12x + 12$

=== Factorisation - Méthode du Discriminant
Id: 1461
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser les trinômes suivants en utilisant la méthode du discriminant.

1. Factoriser $\displaystyle 2x^2 - x - 3$
2. Factoriser $\displaystyle x^2 - 6x + 9$
3. Factoriser $\displaystyle 3x^2 + 5x - 2$
4. Factoriser $\displaystyle x^2 + 4x + 4$
5. Factoriser $\displaystyle 2x^2 + 7x + 3$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle 2x^2 - x - 3$

::: methode
Méthode du discriminant
:::

::: etape Identifier les coefficients
- $a = 2$, $b = -1$, $c = -3$
:::

::: etape Calculer le discriminant
$$
\begin{aligned}
\Delta &= b^2 - 4ac \\
&= (-1)^2 - 4 \times 2 \times (-3) \\
&= 1 + 24 \\
&= 25
\end{aligned}
$$

- $\Delta > 0$, donc deux racines distinctes
:::

::: etape Calculer les racines
$$
\begin{aligned}
x_1 &= \dfrac{-b - \sqrt{\Delta}}{2a} \\
&= \dfrac{1 - \sqrt{25}}{4} \\
&= \dfrac{1 - 5}{4} \\
&= -\dfrac{1}{2}
\end{aligned}
$$

$$
\begin{aligned}
x_2 &= \dfrac{-b + \sqrt{\Delta}}{2a} \\
&= \dfrac{1 + \sqrt{25}}{4} \\
&= \dfrac{1 + 5}{4} \\
&= \dfrac{3}{2}
\end{aligned}
$$
:::

::: etape Factoriser
$$
\begin{aligned}
2x^2 - x - 3 &= 2(x - x_1)(x - x_2) \\
&= 2\left(x - \left(-\dfrac{1}{2}\right)\right)\left(x - \dfrac{3}{2}\right) \\
&= 2\left(x + \dfrac{1}{2}\right)\left(x - \dfrac{3}{2}\right) \\
&= (2x + 1)(x - 3)
\end{aligned}
$$
:::

::: point Vérification
$$(2x + 1)(x - 3) = 2x^2 - 6x + x - 3 = 2x^2 - x - 3$$
:::

::: resultat
$$2x^2 - x - 3 = (2x + 1)(x - 3)$$
:::

## Question 2 : Factoriser $\displaystyle x^2 - 6x + 9$

::: methode
Méthode du discriminant
:::

::: etape Identifier les coefficients
- $a = 1$, $b = -6$, $c = 9$
:::

::: etape Calculer le discriminant
$$
\begin{aligned}
\Delta &= b^2 - 4ac \\
&= (-6)^2 - 4 \times 1 \times 9 \\
&= 36 - 36 \\
&= 0
\end{aligned}
$$

- $\displaystyle \Delta = 0$, donc racine double
:::

::: etape Calculer la racine double
- $\displaystyle x_0 = \dfrac{-b}{2a} = \dfrac{6}{2} = 3$
:::

::: etape Factoriser
- $\displaystyle x^2 - 6x + 9 = (x - x_0)^2 = (x - 3)^2$
:::

::: point Vérification
$$(x - 3)^2 = x^2 - 6x + 9$$
:::

::: resultat
$$x^2 - 6x + 9 = (x - 3)^2$$
:::

## Question 3 : Factoriser $\displaystyle 3x^2 + 5x - 2$

::: methode
Méthode du discriminant

::: etape Identifier les coefficients
- $a = 3$, $b = 5$, $c = -2$
:::

::: etape Calculer le discriminant
$$

\end{aligned}

&= -2
\end{aligned}

$$
\begin{aligned}
x_2 &= \dfrac{-b + \sqrt{\Delta}}{2a} \\

&= \dfrac{-5 + 7}{6} \\
&= \dfrac{1}{3}
\end{aligned}
$$
:::

::: etape Factoriser
$$
\begin{aligned}
3x^2 + 5x - 2 &= 3(x - x_1)(x - x_2) \\
&= 3(x - (-2))\left(x - \dfrac{1}{3}\right) \\
&= 3(x + 2)\left(x - \dfrac{1}{3}\right) \\
&= (x + 2)(3x - 1)
\end{aligned}
$$
:::

::: point Vérification
$$(x + 2)(3x - 1) = 3x^2 - x + 6x - 2 = 3x^2 + 5x - 2$$
:::

::: resultat

## Question 4 : Factoriser $\displaystyle x^2 + 4x + 4$

## Question 5 : Factoriser $\displaystyle 2x^2 + 7x + 3$
