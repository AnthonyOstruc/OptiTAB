Titre: Résumé : Théorème de Thalès et triangles semblables

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel du chapitre : le théorème de Thalès (calculer une longueur), sa réciproque (démontrer un parallélisme), les triangles semblables et les rapports des périmètres et des aires. Ce résumé couvre les notions exigibles au programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Le théorème de Thalès</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème de Thalès</strong></p>
<p style="margin:5px 0 0 0;">Si $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ et $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ sont alignés et si $\displaystyle (MN) \parallel (BC)$, alors :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:420px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$</p>
</div>
<p style="margin:5px 0 0 0;"><em style="font-size:0.9em;">Petit triangle au numérateur, grand triangle au dénominateur — valable dans les deux configurations.</em></p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calculer une longueur</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0 0 8px 0;"><strong>Méthode en 4 étapes :</strong></p>
<p style="margin:4px 0 0 0;">① Citer les <strong>alignements</strong> et le <strong>parallélisme</strong>.</p>
<p style="margin:4px 0 0 0;">② Citer le <strong>théorème de Thalès</strong> et écrire les rapports.</p>
<p style="margin:4px 0 0 0;">③ Garder le rapport avec l'<strong>inconnue</strong> et un rapport <strong>entièrement connu</strong>.</p>
<p style="margin:4px 0 0 0;">④ <strong>Produit en croix</strong>, puis conclure avec l'unité.</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:420px;">
<p style="margin:0; font-weight:bold;">$\displaystyle \frac{a}{b} = \frac{c}{d} \;\Longleftrightarrow\; a \times d = b \times c$</p>
</div>
<p style="margin:8px 0 0 0;"><strong>Exemple :</strong> $\displaystyle \frac{3}{5} = \frac{AN}{7}$ donne $\displaystyle AN = \frac{3 \times 7}{5} = 4{,}2$ cm.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. La réciproque (démontrer un parallélisme)</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Réciproque du théorème de Thalès</strong></p>
<p style="margin:5px 0 0 0;">Si $\displaystyle A$, $\displaystyle M$, $\displaystyle B$ et $\displaystyle A$, $\displaystyle N$, $\displaystyle C$ sont alignés <strong>dans le même ordre</strong> et si $\displaystyle \dfrac{AM}{AB} = \dfrac{AN}{AC}$, alors $\displaystyle (MN) \parallel (BC)$.</p>
</div>
<p style="margin:8px 0 0 0;"><strong>Rapports différents ?</strong> Alors les droites ne sont <strong>pas parallèles</strong> (sinon Thalès imposerait l'égalité). On compare toujours avec les <strong>produits en croix</strong>, jamais avec des arrondis.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Triangles semblables</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition :</strong> deux triangles sont <strong>semblables</strong> si leurs angles sont égaux deux à deux (deux paires d'angles égaux suffisent). Leurs côtés correspondants sont alors <strong>proportionnels</strong> (coefficient $\displaystyle k$).</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Utiliser $\displaystyle MB$ ou $\displaystyle NC$ dans les rapports : Thalès n'utilise que les longueurs <strong>depuis le sommet $\displaystyle A$</strong>. Reconstituer d'abord : $\displaystyle AB = AM + MB$ (emboîtée).</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier de citer « alignés <strong>dans le même ordre</strong> » pour la réciproque.</p>
<p style="margin:6px 0 0 0;">3️⃣ Comparer des rapports avec des <strong>arrondis</strong> au lieu des produits en croix.</p>
<p style="margin:6px 0 0 0;">4️⃣ Multiplier l'aire par $\displaystyle k$ au lieu de $\displaystyle k^2$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> « deux droites sécantes + deux droites parallèles » → Thalès pour <strong>calculer</strong> ; « montrer que des droites sont parallèles » → <strong>réciproque</strong> ; « ombre, échelle, agrandissement » → <strong>triangles semblables</strong>. Toujours conclure par une phrase avec l'unité !</p>
</div>
