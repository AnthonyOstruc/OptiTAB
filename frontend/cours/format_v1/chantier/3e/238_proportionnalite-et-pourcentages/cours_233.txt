Titre: Proportionnalité et pourcentages

<!-- optitab:1 -->
::: objectifs
- Reconnaître une situation de proportionnalité dans un tableau ou sur un graphique.
- Calculer une quatrième proportionnelle (passage à l'unité, coefficient, produit en croix).
- Partager une quantité selon un ratio ; utiliser une échelle.
- Appliquer un pourcentage, une hausse ou une baisse avec un coefficient multiplicateur.
- Retrouver une valeur initiale, calculer un pourcentage d'évolution, enchaîner deux évolutions.
:::

## I. Reconnaître une situation de proportionnalité

::: definition Grandeurs proportionnelles
Deux grandeurs sont **proportionnelles** si l'on obtient les valeurs de l'une en multipliant les valeurs de l'autre par un même nombre, appelé **coefficient de proportionnalité**.
:::

### 1. Dans un tableau

Un tableau est un tableau de proportionnalité si tous les quotients « deuxième ligne $\div$ première ligne » sont égaux.

[IMAGE_1]

::: exemple
Quantité ($2$ ; $5$ ; $8$ kg), prix ($7$ ; $17{,}5$ ; $28$ €) : $\dfrac{7}{2} = \dfrac{17{,}5}{5} = \dfrac{28}{8} = 3{,}5$. Le prix est proportionnel à la masse, le coefficient est $3{,}5$ (le prix d'un kilogramme : $3{,}50$ €).
:::

### 2. Sur un graphique

::: propriete
Une situation de proportionnalité est représentée par des points **alignés sur une droite qui passe par l'origine** du repère. Réciproquement, des points alignés avec l'origine traduisent une situation de proportionnalité.
:::

[IMAGE_2]

::: attention
Un tarif avec une partie fixe (par exemple $5$ € de frais, plus $2$ € par colis) n'est **pas** proportionnel : sa droite ne passe pas par l'origine. Deux grandeurs qui augmentent ensemble ne sont pas forcément proportionnelles.
:::

## II. Calculer une quatrième proportionnelle

::: methode Trois façons de calculer
- **Passage à l'unité** : on calcule la valeur pour $1$, puis on multiplie.
- **Coefficient** : on multiplie par le coefficient de proportionnalité.
- **Produit en croix** : si $\dfrac{a}{b} = \dfrac{c}{d}$, alors $a \times d = b \times c$.
:::

::: exemple
$3$ kg de pommes coûtent $7{,}20$ €. Combien coûtent $5$ kg ?

- Passage à l'unité : $1$ kg coûte $7{,}20 \div 3 = 2{,}40$ €, donc $5$ kg coûtent $5 \times 2{,}40 = 12$ €.
- Produit en croix : $\dfrac{5 \times 7{,}20}{3} = 12$ €.
:::

## III. Ratios et échelles

::: definition Ratio
Partager une quantité selon le **ratio** $a : b$, c'est la partager en $a + b$ parts égales : $a$ parts pour la première personne, $b$ parts pour la seconde.
:::

::: exemple
Partager $35$ L selon le ratio $2 : 3$ : il y a $2 + 3 = 5$ parts de $35 \div 5 = 7$ L, soit $2 \times 7 = 14$ L et $3 \times 7 = 21$ L.
:::

::: definition Échelle
Sur un plan ou une carte, les longueurs sont proportionnelles aux longueurs réelles. L'**échelle** est le coefficient de proportionnalité :

$$\text{échelle} = \frac{\text{longueur sur le plan}}{\text{longueur réelle}}$$

les deux longueurs étant exprimées dans la **même unité**.
:::

::: exemple
À l'échelle $\dfrac{1}{500}$, $1$ cm sur le plan représente $500$ cm, soit $5$ m dans la réalité.
:::

## IV. Pourcentages et coefficient multiplicateur

::: propriete Appliquer un pourcentage
Prendre $t\ \%$ d'une quantité, c'est la multiplier par $\dfrac{t}{100}$.
:::

::: exemple
$30\ \%$ de $250$ : $250 \times \dfrac{30}{100} = 250 \times 0{,}3 = 75$.
:::

::: propriete Hausse et baisse
- Augmenter une valeur de $t\ \%$, c'est la multiplier par $1 + \dfrac{t}{100}$.
- Diminuer une valeur de $t\ \%$, c'est la multiplier par $1 - \dfrac{t}{100}$.

Ce nombre est le **coefficient multiplicateur**.
:::

[IMAGE_3]

::: exemple
- Hausse de $8\ \%$ : coefficient $1{,}08$. Un abonnement de $75$ € passe à $75 \times 1{,}08 = 81$ €.
- Baisse de $15\ \%$ : coefficient $0{,}85$. Un prix de $80$ € devient $80 \times 0{,}85 = 68$ €.
:::

::: methode Retrouver la valeur initiale
On **divise** la valeur finale par le coefficient multiplicateur. Après une hausse de $8\ \%$, un abonnement coûte $81$ € : il coûtait $81 \div 1{,}08 = 75$ €.
:::

::: attention
Pour retrouver le prix de départ, on ne retire pas $8\ \%$ de $81$ € : les $8\ \%$ portent sur le prix **de départ**, pas sur le prix final ($81 \times 0{,}92 = 74{,}52 \neq 75$).
:::

## V. Pourcentage d'évolution et évolutions successives

::: propriete Pourcentage d'évolution
Quand une valeur passe de $V_i$ à $V_f$, le taux d'évolution est :

$$t = \frac{V_f - V_i}{V_i}$$

On l'écrit en pourcentage. Il est positif pour une hausse, négatif pour une baisse.
:::

::: exemple
Un effectif passe de $160$ à $184$ personnes : $t = \dfrac{184 - 160}{160} = \dfrac{24}{160} = 0{,}15$, soit une hausse de $15\ \%$.
:::

::: propriete Évolutions successives
Pour enchaîner deux évolutions, on **multiplie** leurs coefficients multiplicateurs. On n'additionne jamais les pourcentages.
:::

[IMAGE_4]

::: exemple
Une hausse de $20\ \%$ suivie d'une baisse de $20\ \%$ : $1{,}2 \times 0{,}8 = 0{,}96$. Au total, c'est une **baisse de $4\ \%$**, et non un retour à la valeur de départ.
:::

::: attention Points ou pourcentage ?
Une part qui passe de $12\ \%$ à $15\ \%$ augmente de $3$ **points** de pourcentage ; en valeur relative, c'est une hausse de $\dfrac{3}{12} = 25\ \%$.
:::

::: retenir
- Proportionnalité : quotients égaux ; graphique : droite passant par l'origine.
- Ratio $a : b$ : $a + b$ parts égales.
- Hausse de $t\ \%$ : $\times \left(1 + \dfrac{t}{100}\right)$ ; baisse de $t\ \%$ : $\times \left(1 - \dfrac{t}{100}\right)$.
- Valeur initiale : on **divise** par le coefficient.
- Évolutions successives : on **multiplie** les coefficients.
:::
