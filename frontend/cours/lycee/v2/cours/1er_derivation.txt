=== Dérivation - Programme Première

Titre: Dérivation

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> calculer un taux de variation et un nombre dérivé, déterminer l’équation d’une tangente, connaître les dérivées usuelles et les règles de calcul, puis utiliser le signe de la dérivée pour étudier les variations et les extremums d’une fonction.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Nombre dérivé</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> le <strong>taux de variation</strong> de $f$ entre $a$ et $a + h$ ($h \neq 0$) est $\frac{f(a + h) - f(a)}{h}$ : c’est la pente de la sécante $(AM)$. Si ce taux tend vers un nombre réel quand $h$ tend vers $0$, $f$ est <strong>dérivable en $a$</strong> et ce nombre est le <strong>nombre dérivé</strong> $f'(a)$.</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Exemple :</strong> pour $f(x) = x^2$ et $a = 1$ : $\frac{(1 + h)^2 - 1}{h} = \frac{2h + h^2}{h} = 2 + h$, qui tend vers $2$. Donc $f'(1) = 2$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Tangente à une courbe</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété (démonstration au programme) :</strong> la <strong>tangente</strong> à la courbe de $f$ au point d’abscisse $a$ est la droite passant par $A(a\,;f(a))$ de pente $f'(a)$. Son équation est :</p>
            <div style="text-align:center; margin:10px 0 0 0;">$y = f'(a)(x - a) + f(a)$</div>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> cette droite a une équation $y = f'(a)x + p$ ; elle passe par $A$, donc $f(a) = f'(a)a + p$, d’où $p = f(a) - f'(a)a$ et le résultat.</p>
        </div>
        [IMAGE_2]
        <p style="font-size:1em;"><strong>Exemple :</strong> pour $f(x) = x^2$ en $a = 1$ : $f(1) = 1$ et $f'(1) = 2$, donc $T : y = 2(x - 1) + 1 = 2x - 1$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonctions dérivées usuelles</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Formules :</strong></p>
            <p style="margin:6px 0 0 0;">• $f(x) = k$ (constante) : $f'(x) = 0$ ; $f(x) = mx + p$ : $f'(x) = m$.</p>
            <p style="margin:6px 0 0 0;">• $f(x) = x^n$ ($n \ge 1$ entier) : $f'(x) = nx^{n-1}$ ; par exemple $(x^2)' = 2x$ et $(x^3)' = 3x^2$.</p>
            <p style="margin:6px 0 0 0;">• $f(x) = \frac{1}{x}$ sur $]-\infty\,;0[$ ou $]0\,;+\infty[$ : $f'(x) = -\frac{1}{x^2}$.</p>
            <p style="margin:6px 0 0 0;">• $f(x) = \sqrt{x}$ sur $]0\,;+\infty[$ : $f'(x) = \frac{1}{2\sqrt{x}}$.</p>
        </div>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Démonstrations au programme :</strong></p>
            <p style="margin:6px 0 0 0;">• Carré : $\frac{(x + h)^2 - x^2}{h} = 2x + h \rightarrow 2x$.</p>
            <p style="margin:6px 0 0 0;">• Inverse : $\frac{1}{h}\left(\frac{1}{x + h} - \frac{1}{x}\right) = \frac{-1}{x(x + h)} \rightarrow -\frac{1}{x^2}$.</p>
            <p style="margin:6px 0 0 0;">• Racine carrée en $0$ : $\frac{\sqrt{h} - \sqrt{0}}{h} = \frac{1}{\sqrt{h}}$ devient aussi grand que l’on veut, donc $\sqrt{\phantom{x}}$ n’est <strong>pas dérivable en $0$</strong>.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Règles de calcul</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Opérations :</strong> $(u + v)' = u' + v'$ ; $(ku)' = ku'$ ; $(uv)' = u'v + uv'$ ; $\left(\frac{1}{v}\right)' = -\frac{v'}{v^2}$ ; $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ ; et $\big(g(ax + b)\big)' = a\,g'(ax + b)$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve pour le produit (au programme) :</em> $\frac{u(x + h)v(x + h) - u(x)v(x)}{h} = \frac{u(x + h) - u(x)}{h}\,v(x + h) + u(x)\,\frac{v(x + h) - v(x)}{h}$, qui tend vers $u'(x)v(x) + u(x)v'(x)$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemples :</strong></p>
        <p style="font-size:1em;">• $f(x) = (2x + 1)(x^2 - 3)$ : $f'(x) = 2(x^2 - 3) + (2x + 1) \times 2x = 6x^2 + 2x - 6$.</p>
        <p style="font-size:1em;">• $g(x) = \frac{3x - 1}{x + 2}$ : $g'(x) = \frac{3(x + 2) - (3x - 1) \times 1}{(x + 2)^2} = \frac{7}{(x + 2)^2}$.</p>
        <p style="font-size:1em;">• $h(x) = \sqrt{4x + 1}$ : $h'(x) = 4 \times \frac{1}{2\sqrt{4x + 1}} = \frac{2}{\sqrt{4x + 1}}$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> la dérivée d’un produit n’est pas le produit des dérivées : $(uv)' \neq u'v'$. Dans un quotient, l’ordre compte : c’est $u'v - uv'$ au numérateur.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Dérivée et variations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Théorème :</strong> soit $f$ dérivable sur un intervalle $I$. Si $f' \ge 0$ sur $I$, $f$ est croissante sur $I$ ; si $f' \le 0$ sur $I$, $f$ est décroissante sur $I$. Si $f'$ s’annule en $a$ <strong>en changeant de signe</strong>, $f$ admet un extremum local en $a$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $f(x) = x^3 - 3x$. On a $f'(x) = 3x^2 - 3 = 3(x - 1)(x + 1)$, positif à l’extérieur de $[-1\,;1]$ et négatif entre $-1$ et $1$.</p>
        [IMAGE_3]
        [IMAGE_4]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode d’étude :</strong> calculer $f'(x)$, la factoriser, dresser le tableau de signes de $f'$, en déduire le tableau de variations de $f$ et compléter avec les images des valeurs remarquables.
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $f'(a)$ est la limite du taux de variation et la pente de la tangente $y = f'(a)(x - a) + f(a)$ ; $(x^n)' = nx^{n-1}$, $\left(\frac{1}{x}\right)' = -\frac{1}{x^2}$, $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$ ; $(uv)' = u'v + uv'$, $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ ; signe de $f'$ → variations de $f$. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
