=== Découverte - Dériver des fonctions exponentielles
Id: 1291
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Les fonctions suivantes sont définies et dérivables sur $\mathbb{R}$. Calculer leur dérivée.

1. $f(x) = 3e^x - 2x + 1$
2. $g(x) = e^{3x}$
3. $h(x) = e^{-2x+1}$
4. $k(x) = 5e^{0{,}4x} - e^{-x}$
5. $m(x) = (x + 1)e^x$

Étapes:
<!-- optitab:1 -->
## Question 1 : Dériver $f(x) = 3e^x - 2x + 1$

::: methode
On dérive terme à terme, avec $\left(e^x\right)' = e^x$.
:::

::: etape Dérivée de chaque terme
- $\left(3e^x\right)' = 3e^x$ (une constante multiplicative se conserve) ;
- $(-2x)' = -2$ ;
- $(1)' = 0$.
:::

::: resultat
$$f'(x) = 3e^x - 2$$
:::

## Question 2 : Dériver $g(x) = e^{3x}$

::: methode
Pour tous réels $a$ et $b$ : $\left(e^{ax+b}\right)' = a\,e^{ax+b}$.
:::

::: etape Identifier $a$
$g(x) = e^{ax+b}$ avec $a = 3$ et $b = 0$.
:::

::: resultat
$$g'(x) = 3e^{3x}$$
:::

## Question 3 : Dériver $h(x) = e^{-2x+1}$

::: methode
Même formule, avec $a = -2$ et $b = 1$.
:::

::: etape Calcul
$$h'(x) = (-2) \times e^{-2x+1}$$
:::

::: resultat
$$h'(x) = -2e^{-2x+1}$$
:::

::: attention
Erreur fréquente : écrire $h'(x) = e^{-2x+1}$ en oubliant le facteur $a = -2$. Seule $e^x$ est égale à sa dérivée.
:::

## Question 4 : Dériver $k(x) = 5e^{0{,}4x} - e^{-x}$

::: methode
On dérive chaque terme avec $\left(e^{ax}\right)' = a\,e^{ax}$.
:::

::: etape Premier terme ($a = 0{,}4$)
$$\left(5e^{0{,}4x}\right)' = 5 \times 0{,}4\,e^{0{,}4x} = 2e^{0{,}4x}$$
:::

::: etape Second terme ($a = -1$)
$$\left(-e^{-x}\right)' = -(-1)e^{-x} = e^{-x}$$
:::

::: resultat
$$k'(x) = 2e^{0{,}4x} + e^{-x}$$
:::

## Question 5 : Dériver $m(x) = (x + 1)e^x$

::: methode
$m$ est un produit $u \times v$ : $(uv)' = u'v + uv'$.
:::

::: etape Identifier $u$ et $v$
$u(x) = x + 1$, donc $u'(x) = 1$ ; $v(x) = e^x$, donc $v'(x) = e^x$.
:::

::: etape Appliquer la formule et factoriser
$$
\begin{aligned}
m'(x) &= 1 \times e^x + (x + 1)e^x \\
&= (1 + x + 1)e^x \\
&= (x + 2)e^x
\end{aligned}
$$
:::

::: resultat
$$m'(x) = (x + 2)e^x$$
:::

::: retenir
On factorise toujours la dérivée par l’exponentielle : comme $e^x > 0$, le signe de $m'(x)$ est celui de $x + 2$.
:::

Solution:
<!-- optitab:1 -->
1. $f'(x) = 3e^x - 2$
2. $g'(x) = 3e^{3x}$
3. $h'(x) = -2e^{-2x+1}$
4. $k'(x) = 2e^{0{,}4x} + e^{-x}$
5. $m'(x) = (x + 2)e^x$

=== Découverte - Signe, variations et tangente en 0
Id: 1290
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On a tracé la courbe $\mathcal{C}$ de la fonction exponentielle et sa tangente $T$ au point $A$ d’abscisse $0$.

[IMAGE_1]

1. Sans calculatrice, donner le signe de $e^{-3}$, puis, pour tout réel $x$, le signe de $-2e^x$ et de $e^x + 1$.
2. Comparer $e^2$ et $e^3$, puis $e^{-1}$ et $e^{-0{,}5}$. Justifier.
3. Calculer $\exp(0)$ et $\exp'(0)$. En déduire une équation de $T$.
4. Utiliser $T$ pour donner une valeur approchée de $e^{0{,}1}$, puis comparer avec la valeur donnée par la calculatrice.
5. Dresser le tableau de signes de $(x - 2)e^x$ sur $\mathbb{R}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Signes

::: methode
Pour tout réel $X$, $e^X > 0$ : une exponentielle est toujours strictement positive.
:::

::: etape Les trois expressions
- $e^{-3} > 0$ (avec $X = -3$).
- $e^x > 0$, donc $-2e^x < 0$ : multiplier par $-2$ change le signe.
- $e^x > 0$, donc $e^x + 1 > 1 > 0$.
:::

::: resultat
$e^{-3} > 0$ ; pour tout réel $x$, $-2e^x < 0$ et $e^x + 1 > 0$.
:::

::: attention
$e^{-3}$ n’est pas négatif : l’exposant est négatif, mais le nombre $e^{-3} = \dfrac{1}{e^3}$ est positif.
:::

## Question 2 : Comparaisons

::: methode
La fonction exponentielle est strictement croissante : $a < b \iff e^a < e^b$.
:::

::: etape Comparer les exposants
- $2 < 3$, donc $e^2 < e^3$.
- $-1 < -0{,}5$, donc $e^{-1} < e^{-0{,}5}$.
:::

::: resultat
$e^2 < e^3$ et $e^{-1} < e^{-0{,}5}$.
:::

## Question 3 : Équation de la tangente $T$

::: methode
La tangente en $a$ a pour équation $y = f'(a)(x - a) + f(a)$.
:::

::: etape Valeurs en $0$
$\exp(0) = e^0 = 1$ (définition) et $\exp'(0) = \exp(0) = 1$, car $\exp' = \exp$.
:::

::: etape Équation
$$
\begin{aligned}
y &= \exp'(0)(x - 0) + \exp(0) \\
&= x + 1
\end{aligned}
$$
La droite $T$ passe par $A(0\,;\,1)$ et a pour coefficient directeur $1$ : quand $x$ augmente de $1$, $y$ augmente de $1$.

[IMAGE_2]
:::

::: resultat
$$T : y = x + 1$$
:::

## Question 4 : Valeur approchée de $e^{0{,}1}$

::: methode
Près du point de contact, la courbe et la tangente sont très proches : $e^h \approx h + 1$ pour $h$ proche de $0$.
:::

::: etape Approximation
Avec $h = 0{,}1$ : $e^{0{,}1} \approx 0{,}1 + 1 = 1{,}1$.
:::

::: etape Comparaison
La calculatrice donne $e^{0{,}1} \approx 1{,}10517$. L’écart est d’environ $0{,}005$ : l’approximation est bonne. La valeur approchée est un peu trop petite, car la courbe est au-dessus de sa tangente.
:::

::: resultat
$e^{0{,}1} \approx 1{,}1$ (valeur exacte $1{,}10517\ldots$).
:::

## Question 5 : Signe de $(x - 2)e^x$

::: methode
Dans un produit, le facteur $e^x$ est toujours positif : le signe est celui de l’autre facteur.
:::

::: etape Tableau de signes
$x - 2 = 0 \iff x = 2$, et $x - 2 > 0 \iff x > 2$.

::: tableau
x : -\infty, 2, +\infty
x - 2 : , -, z, +,
e^x : , +, , +,
(x-2)e^x : , -, z, +,
:::
:::

::: resultat
$(x - 2)e^x < 0$ sur $]{-\infty}\,;\,2[$, $(x - 2)e^x = 0$ pour $x = 2$, et $(x - 2)e^x > 0$ sur $]2\,;+\infty[$.
:::

Solution:
<!-- optitab:1 -->
1. $e^{-3} > 0$ ; $-2e^x < 0$ et $e^x + 1 > 0$ pour tout réel $x$.
2. $e^2 < e^3$ et $e^{-1} < e^{-0{,}5}$ (exponentielle strictement croissante).
3. $\exp(0) = \exp'(0) = 1$, donc $T : y = x + 1$.
4. $e^{0{,}1} \approx 1{,}1$ (calculatrice : $1{,}10517\ldots$).
5. $(x - 2)e^x$ est négatif avant $2$, nul en $2$, positif après $2$.

=== Découverte - Propriétés algébriques et calculs
Id: 1289
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dans les questions 1 à 5, écrire l’expression sous la forme d’une seule exponentielle ($x$ désigne un réel).

1. $A = e^{2x+3} \times e^{-x}$
2. $B = \dfrac{e^{3x}}{e^{2x+1}}$
3. $C = \left(e^x\right)^2 \times e^{-3x}$
4. $D = \dfrac{e^{x+2} \times e^{3x-1}}{e^{2x}}$
5. $E = \dfrac{\left(e^{-x}\right)^3 \times e^{4x+1}}{e}$
6. Montrer que, pour tout réel $x$, $\left(e^x + e^{-x}\right)^2 - \left(e^x - e^{-x}\right)^2 = 4$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $A = e^{2x+3} \times e^{-x}$

::: methode
Produit : on additionne les exposants, $e^a \times e^b = e^{a+b}$.
:::

::: etape Calcul
$$
\begin{aligned}
A &= e^{(2x+3) + (-x)} \\
&= e^{x+3}
\end{aligned}
$$
:::

::: resultat
$$A = e^{x+3}$$
:::

## Question 2 : $B = \dfrac{e^{3x}}{e^{2x+1}}$

::: methode
Quotient : on soustrait les exposants, $\dfrac{e^a}{e^b} = e^{a-b}$.
:::

::: etape Calcul
$$
\begin{aligned}
B &= e^{3x - (2x + 1)} \\
&= e^{3x - 2x - 1} \\
&= e^{x-1}
\end{aligned}
$$
:::

::: resultat
$$B = e^{x-1}$$
:::

::: attention
Les parenthèses sont indispensables : on soustrait **tout** l’exposant $2x + 1$, d’où le $-1$.
:::

## Question 3 : $C = \left(e^x\right)^2 \times e^{-3x}$

::: methode
Puissance : $\left(e^a\right)^n = e^{na}$, puis on traite le produit.
:::

::: etape Calcul
$$
\begin{aligned}
C &= e^{2x} \times e^{-3x} \\
&= e^{2x - 3x} \\
&= e^{-x}
\end{aligned}
$$
:::

::: resultat
$$C = e^{-x}$$
:::

## Question 4 : $D = \dfrac{e^{x+2} \times e^{3x-1}}{e^{2x}}$

::: methode
On regroupe d’abord le numérateur, puis on divise.
:::

::: etape Numérateur
$$e^{x+2} \times e^{3x-1} = e^{(x+2) + (3x-1)} = e^{4x+1}$$
:::

::: etape Quotient
$$D = \frac{e^{4x+1}}{e^{2x}} = e^{4x + 1 - 2x} = e^{2x+1}$$
:::

::: resultat
$$D = e^{2x+1}$$
:::

## Question 5 : $E = \dfrac{\left(e^{-x}\right)^3 \times e^{4x+1}}{e}$

::: methode
On écrit $e = e^1$ pour n’avoir que des exponentielles.
:::

::: etape Calcul
$$
\begin{aligned}
E &= \frac{e^{-3x} \times e^{4x+1}}{e^1} \\
&= \frac{e^{x+1}}{e^1} \\
&= e^{x+1-1} \\
&= e^{x}
\end{aligned}
$$
:::

::: resultat
$$E = e^x$$
:::

## Question 6 : Une identité

::: methode
On développe avec les identités remarquables, puis on utilise $e^x \times e^{-x} = e^0 = 1$.
:::

::: etape Développer
On pose $a = e^x$ et $b = e^{-x}$.
$$
\begin{aligned}
(a + b)^2 - (a - b)^2 &= \left(a^2 + 2ab + b^2\right) \\
&\quad - \left(a^2 - 2ab + b^2\right) \\
&= 4ab
\end{aligned}
$$
:::

::: etape Conclure
$$4ab = 4e^x \times e^{-x} = 4e^{x - x} = 4e^0 = 4$$
:::

::: resultat
Pour tout réel $x$, $\left(e^x + e^{-x}\right)^2 - \left(e^x - e^{-x}\right)^2 = 4$.
:::

::: attention
$\left(e^x\right)^2 = e^{2x}$, et non $e^{x^2}$.
:::

Solution:
<!-- optitab:1 -->
1. $A = e^{x+3}$
2. $B = e^{x-1}$
3. $C = e^{-x}$
4. $D = e^{2x+1}$
5. $E = e^x$
6. Le développement donne $4e^x e^{-x} = 4e^0 = 4$.

=== Entraînement - Équations et inéquations
Id: 1293
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les équations et inéquations suivantes.

1. $e^{2x+1} = e^{x-3}$
2. $e^{3x-6} = 1$
3. $e^{4x} = e \times e^x$
4. $e^{x-1} < e^{2x+3}$
5. $e^{-x} \geqslant \dfrac{1}{e^2}$
6. $e^x = -3$

Étapes:
<!-- optitab:1 -->
## Question 1 : $e^{2x+1} = e^{x-3}$

::: methode
$e^a = e^b \iff a = b$ : on compare les exposants.
:::

::: etape Résolution
$$
\begin{aligned}
e^{2x+1} = e^{x-3} &\iff 2x + 1 = x - 3 \\
&\iff x = -4
\end{aligned}
$$
:::

::: resultat
$$S = \{-4\}$$
:::

## Question 2 : $e^{3x-6} = 1$

::: methode
On écrit $1 = e^0$.
:::

::: etape Résolution
$$
\begin{aligned}
e^{3x-6} = e^0 &\iff 3x - 6 = 0 \\
&\iff x = 2
\end{aligned}
$$
:::

::: resultat
$$S = \{2\}$$
:::

## Question 3 : $e^{4x} = e \times e^x$

::: methode
On écrit le second membre sous la forme d’une seule exponentielle : $e \times e^x = e^1 \times e^x = e^{x+1}$.
:::

::: etape Résolution
$$
\begin{aligned}
e^{4x} = e^{x+1} &\iff 4x = x + 1 \\
&\iff 3x = 1 \\
&\iff x = \frac{1}{3}
\end{aligned}
$$
:::

::: resultat
$$S = \left\{\frac{1}{3}\right\}$$
:::

## Question 4 : $e^{x-1} < e^{2x+3}$

::: methode
L’exponentielle est strictement croissante : $e^a < e^b \iff a < b$ (même sens).
:::

::: etape Résolution
$$
\begin{aligned}
e^{x-1} < e^{2x+3} &\iff x - 1 < 2x + 3 \\
&\iff -4 < x
\end{aligned}
$$
:::

::: resultat
$$S = \,]{-4}\,;+\infty[$$
:::

## Question 5 : $e^{-x} \geqslant \dfrac{1}{e^2}$

::: methode
On écrit $\dfrac{1}{e^2} = e^{-2}$, puis on compare les exposants.
:::

::: etape Comparer les exposants
$$
\begin{aligned}
e^{-x} \geqslant e^{-2} &\iff -x \geqslant -2 \\
&\iff x \leqslant 2
\end{aligned}
$$
:::

::: resultat
$$S = \,]{-\infty}\,;\,2]$$
:::

::: attention
En multipliant les deux membres de $-x \geqslant -2$ par $-1$, on **change le sens** de l’inégalité.
:::

## Question 6 : $e^x = -3$

::: methode
Une exponentielle est toujours strictement positive.
:::

::: etape Raisonnement
Pour tout réel $x$, $e^x > 0$, donc $e^x$ ne peut pas valoir $-3$. Graphiquement, la courbe de l’exponentielle, toujours au-dessus de l’axe des abscisses, ne coupe jamais la droite d’équation $y = -3$.

[IMAGE_1]
:::

::: resultat
L’équation n’a aucune solution : $S = \varnothing$.
:::

Solution:
<!-- optitab:1 -->
1. $S = \{-4\}$
2. $S = \{2\}$
3. $S = \left\{\dfrac{1}{3}\right\}$
4. $S = \,]{-4}\,;+\infty[$
5. $S = \,]{-\infty}\,;\,2]$
6. $S = \varnothing$

=== Entraînement - Comparer l'exponentielle et sa tangente en 0
Id: 1298
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie sur $\mathbb{R}$ par $f(x) = e^x - x$. Voici sa courbe $\mathcal{C}_f$.

[IMAGE_1]

1. Quel minimum de $f$ peut-on conjecturer à l’aide du graphique ?
2. Calculer $f'(x)$.
3. Résoudre l’inéquation $e^x > 1$. En déduire le signe de $f'(x)$.
4. Dresser le tableau de variations de $f$ et démontrer la conjecture de la question 1.
5. En déduire que, pour tout réel $x$, $e^x \geqslant x + 1$. Interpréter graphiquement ce résultat.
6. Appliquer l’inégalité avec $x = 0{,}1$, puis avec $x = -0{,}1$. En déduire que $1{,}1 \leqslant e^{0{,}1} \leqslant \dfrac{10}{9}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Conjecture

::: etape Lecture graphique
Le point le plus bas de $\mathcal{C}_f$ semble être le point de coordonnées $(0\,;\,1)$.
:::

::: resultat
Conjecture : $f$ admet un minimum égal à $1$, atteint en $x = 0$.
:::

## Question 2 : Dérivée

::: methode
$\left(e^x\right)' = e^x$ et $(x)' = 1$.
:::

::: resultat
$$f'(x) = e^x - 1$$
:::

## Question 3 : Signe de $f'(x)$

::: methode
On écrit $1 = e^0$ et on compare les exposants.
:::

::: etape Résoudre $e^x > 1$
$$e^x > 1 \iff e^x > e^0 \iff x > 0$$
De même, $e^x < 1 \iff x < 0$ et $e^x = 1 \iff x = 0$.
:::

::: resultat
$f'(x) < 0$ pour $x < 0$, $f'(0) = 0$ et $f'(x) > 0$ pour $x > 0$.
:::

## Question 4 : Variations et minimum

::: etape Valeur en $0$
$$f(0) = e^0 - 0 = 1$$
:::

::: point Tableau de variations
::: tableau
x : -\infty, 0, +\infty
f'(x) : , -, z, +,
f(x) : +/, -/1, +/
:::
:::

::: etape Illustration
[IMAGE_2]
:::

::: resultat
$f$ est décroissante sur $]{-\infty}\,;\,0]$ et croissante sur $[0\,;+\infty[$ : son minimum sur $\mathbb{R}$ est $f(0) = 1$. La conjecture est démontrée.
:::

## Question 5 : L’inégalité $e^x \geqslant x + 1$

::: methode
Un minimum égal à $1$ signifie : $f(x) \geqslant 1$ pour tout réel $x$.
:::

::: etape Traduire
Pour tout réel $x$ :
$$e^x - x \geqslant 1 \iff e^x \geqslant x + 1$$
L’égalité n’a lieu que pour $x = 0$.
:::

::: etape Interprétation graphique
La droite $y = x + 1$ est la tangente à la courbe de l’exponentielle en $0$. L’inégalité signifie que la courbe de l’exponentielle est **au-dessus de cette tangente** ; elles ne se touchent qu’au point $(0\,;\,1)$.

[IMAGE_3]
:::

::: resultat
Pour tout réel $x$, $e^x \geqslant x + 1$ : la courbe de l’exponentielle est au-dessus de sa tangente en $0$.
:::

## Question 6 : Encadrement de $e^{0{,}1}$

::: etape Avec $x = 0{,}1$
$$e^{0{,}1} \geqslant 0{,}1 + 1 = 1{,}1$$
:::

::: etape Avec $x = -0{,}1$
$e^{-0{,}1} \geqslant 0{,}9$. Or $e^{-0{,}1} = \dfrac{1}{e^{0{,}1}}$, donc $\dfrac{1}{e^{0{,}1}} \geqslant 0{,}9$.

Les deux membres étant strictement positifs, on passe aux inverses en changeant le sens :
$$e^{0{,}1} \leqslant \frac{1}{0{,}9} = \frac{10}{9}$$
:::

::: resultat
$$1{,}1 \leqslant e^{0{,}1} \leqslant \frac{10}{9} \approx 1{,}111$$
La calculatrice donne bien $e^{0{,}1} \approx 1{,}105$.
:::

::: attention
La fonction inverse est décroissante sur $]0\,;+\infty[$ : le passage aux inverses de deux nombres positifs **inverse** le sens de l’inégalité.
:::

Solution:
<!-- optitab:1 -->
1. Minimum conjecturé : $1$, atteint en $0$.
2. $f'(x) = e^x - 1$
3. $e^x > 1 \iff x > 0$ : $f'$ est négative sur $]{-\infty}\,;\,0[$ et positive sur $]0\,;+\infty[$.
4. $f$ décroît puis croît ; minimum $f(0) = 1$.
5. $e^x - x \geqslant 1$, soit $e^x \geqslant x + 1$ : la courbe est au-dessus de sa tangente en $0$.
6. $e^{0{,}1} \geqslant 1{,}1$ et $\dfrac{1}{e^{0{,}1}} \geqslant 0{,}9$, d’où $1{,}1 \leqslant e^{0{,}1} \leqslant \dfrac{10}{9}$.

=== Problème - Étude d'un produit avec l'exponentielle
Id: 1294
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère la fonction $g$ définie sur $\mathbb{R}$ par $g(x) = xe^x$, et sa courbe $\mathcal{C}_g$ ci-dessous.

[IMAGE_1]

1. Calculer $g'(x)$.
2. Étudier le signe de $g'(x)$ et dresser le tableau de variations de $g$.
3. Déterminer le minimum de $g$ sur $\mathbb{R}$ (valeur exacte et arrondi au millième).
4. Résoudre l’équation $g(x) = 0$, puis donner le signe de $g(x)$.
5. Déterminer une équation de la tangente $T$ à $\mathcal{C}_g$ au point d’abscisse $0$.
6. Montrer que $g(x) - x = x\left(e^x - 1\right)$, puis étudier la position de $\mathcal{C}_g$ par rapport à $T$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Dérivée

::: methode
$g = uv$ avec $u(x) = x$ et $v(x) = e^x$ : $(uv)' = u'v + uv'$.
:::

::: etape Calcul
$u'(x) = 1$ et $v'(x) = e^x$.
$$
\begin{aligned}
g'(x) &= 1 \times e^x + x \times e^x \\
&= (x + 1)e^x
\end{aligned}
$$
:::

::: resultat
$$g'(x) = (x + 1)e^x$$
:::

## Question 2 : Signe de $g'(x)$ et variations

::: methode
$e^x > 0$ : $g'(x)$ a le signe de $x + 1$.
:::

::: etape Signe de $x + 1$
$x + 1 = 0 \iff x = -1$ ; $x + 1 > 0 \iff x > -1$.
:::

::: point Tableau de variations
::: tableau
x : -\infty, -1, +\infty
x + 1 : , -, z, +,
e^x : , +, , +,
g'(x) : , -, z, +,
g(x) : +/, -/-\frac{1}{e}, +/
:::
:::

::: resultat
$g$ est décroissante sur $]{-\infty}\,;\,-1]$ et croissante sur $[-1\,;+\infty[$.
:::

## Question 3 : Minimum

::: etape Calcul de $g(-1)$
$$g(-1) = (-1) \times e^{-1} = -\frac{1}{e}$$
:::

::: resultat
Le minimum de $g$ sur $\mathbb{R}$ est $g(-1) = -\dfrac{1}{e} \approx -0{,}368$. Pour tout réel $x$, $xe^x \geqslant -\dfrac{1}{e}$.
:::

## Question 4 : Zéro et signe de $g$

::: methode
$e^x > 0$ : $g(x) = xe^x$ a le signe de $x$ et s’annule seulement quand $x = 0$.
:::

::: etape Équation

=== Problème - Équations et inéquations avancées
Id: 1297
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les équations et inéquations suivantes.

1. $e^{x^2} = e^{3x-2}$
2. $e^{x^2-4x+3} \geqslant 1$
3. $e^{2x} - (1 + e)e^x + e = 0$ (on pourra poser $X = e^x$)
4. $e^{2x} + e^x - 2 > 0$
5. $e^{x+1} > 2e^{x-1}$
6. $\left(x^2 - 1\right)e^{-x} \leqslant 0$

Étapes:
<!-- optitab:1 -->
## Question 1 : $e^{x^2} = e^{3x-2}$

::: methode
On compare les exposants, puis on résout une équation du second degré.
:::

::: etape Comparer les exposants
$$
\begin{aligned}
e^{x^2} = e^{3x-2} &\iff x^2 = 3x - 2 \\
&\iff x^2 - 3x + 2 = 0
\end{aligned}
$$
:::

::: etape Second degré
$\Delta = (-3)^2 - 4 \times 1 \times 2 = 1 > 0$, donc deux racines :
$$x_1 = \frac{3 - 1}{2} = 1 \qquad x_2 = \frac{3 + 1}{2} = 2$$
:::

::: resultat
$$S = \{1\,;\,2\}$$
:::

## Question 2 : $e^{x^2-4x+3} \geqslant 1$

::: methode
$1 = e^0$ : l’inéquation équivaut à $x^2 - 4x + 3 \geqslant 0$.
:::

::: etape Racines du trinôme
$\Delta = 16 - 12 = 4$, racines $\dfrac{4 - 2}{2} = 1$ et $\dfrac{4 + 2}{2} = 3$ : $x^2 - 4x + 3 = (x - 1)(x - 3)$.
:::

::: etape Signe du trinôme
Le coefficient de $x^2$ est positif : le trinôme est positif à l’extérieur des racines.

[IMAGE_1]
:::

::: tableau
x : -\infty, 1, 3, +\infty
x^2 - 4x + 3 : , +, z, -, z, +,
:::

::: resultat
$$S = \,]{-\infty}\,;\,1] \cup [3\,;+\infty[$$
:::

## Question 3 : $e^{2x} - (1 + e)e^x + e = 0$

::: methode
Comme $e^{2x} = \left(e^x\right)^2$, on pose $X = e^x$ (avec $X > 0$) : on obtient une équation du second degré en $X$.
:::

::: etape Équation en $X$
$$X^2 - (1 + e)X + e = 0$$
:::

::: etape Racines
$$
\begin{aligned}
\Delta &= (1 + e)^2 - 4e \\
&= 1 + 2e + e^2 - 4e \\
&= (e - 1)^2
\end{aligned}
$$
Comme $e - 1 > 0$, $\sqrt{\Delta} = e - 1$, d’où :
$$
\begin{aligned}
X_1 &= \frac{(1 + e) - (e - 1)}{2} = 1 \\
X_2 &= \frac{(1 + e) + (e - 1)}{2} = e
\end{aligned}
$$
Contrôle : $(X - 1)(X - e) = X^2 - (1 + e)X + e$.
:::

::: etape Retour à $x$
Les deux valeurs sont strictement positives, donc acceptables :
- $e^x = 1 = e^0 \iff x = 0$ ;
- $e^x = e = e^1 \iff x = 1$.
:::

::: resultat
$$S = \{0\,;\,1\}$$
:::

## Question 4 : $e^{2x} + e^x - 2 > 0$

::: methode
On pose $X = e^x > 0$ et on factorise $X^2 + X - 2$.
:::

::: etape Factorisation
$X = 1$ est racine évidente ($1 + 1 - 2 = 0$) ; le produit des racines vaut $-2$, donc l’autre racine est $-2$ :
$$X^2 + X - 2 = (X - 1)(X + 2)$$
:::

::: etape Utiliser $X > 0$
Comme $X = e^x > 0$, on a $X + 2 > 0$ : le produit a le signe de $X - 1$.
$$
\begin{aligned}
(X - 1)(X + 2) > 0 &\iff X > 1 \\
&\iff e^x > e^0 \\
&\iff x > 0
\end{aligned}
$$
:::

::: resultat
$$S = \,]0\,;+\infty[$$
:::

::: attention
La racine $X = -2$ ne donne aucune solution : $e^x$ ne peut pas être négatif. Il faut toujours tenir compte de la condition $X > 0$.
:::

## Question 5 : $e^{x+1} > 2e^{x-1}$

::: methode
On divise les deux membres par $e^{x-1}$, qui est strictement positif : le sens ne change pas.
:::

::: etape Diviser
$$\frac{e^{x+1}}{e^{x-1}} = e^{(x+1) - (x-1)} = e^2$$
L’inéquation équivaut donc à $e^2 > 2$.
:::

::: etape Conclure
$e^2 \approx 7{,}39 > 2$ : cette inégalité est vraie, quel que soit $x$.
:::

::: resultat
$$S = \mathbb{R}$$
:::

## Question 6 : $\left(x^2 - 1\right)e^{-x} \leqslant 0$

::: methode
$e^{-x} > 0$ : le produit a le signe de $x^2 - 1$.
:::

::: etape Signe de $x^2 - 1$
$x^2 - 1 = (x - 1)(x + 1)$ a pour racines $-1$ et $1$ ; le coefficient de $x^2$ est positif, donc le trinôme est négatif entre les racines.
:::

::: tableau
x : -\infty, -1, 1, +\infty
x^2 - 1 : , +, z, -, z, +,
e^{-x} : , +, , +, , +,
(x^2-1)e^{-x} : , +, z, -, z, +,
:::

::: resultat
$$S = [-1\,;\,1]$$
:::

Solution:
<!-- optitab:1 -->
1. $S = \{1\,;\,2\}$
2. $S = \,]{-\infty}\,;\,1] \cup [3\,;+\infty[$
3. $S = \{0\,;\,1\}$
4. $S = \,]0\,;+\infty[$
5. $S = \mathbb{R}$
6. $S = [-1\,;\,1]$

## Question 1 : Le principe

$$
\begin{aligned}
f(x + h) &\approx f(x) + h\,f(x) \\

\end{aligned}

Avancer d’un pas $h$ revient (environ) à multiplier par $1 + h$.

::: resultat
$f(x + h) \approx (1 + h)f(x)$ pour $h$ proche de $0$.
:::

## Question 2 : Pas $h = 0{,}5$

::: etape Calcul
On multiplie par $1{,}5$ à chaque pas :

::: resultat
$y_1 = 1{,}5$ et $y_2 = 2{,}25$ : $e \approx 2{,}25$ avec ce pas.

## Question 3 : Pas $h = 0{,}25$

On multiplie par $1{,}25$ à chaque pas :

| $k$ | $0$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|---|
| $x = 0{,}25k$ | $0$ | $0{,}25$ | $0{,}5$ | $0{,}75$ | $1$ |
| $y_k$ | $1$ | $1{,}25$ | $1{,}5625$ | $1{,}953125$ | $2{,}44140625$ |
:::

::: etape Les deux constructions
[IMAGE_2]

Les deux lignes brisées restent sous la courbe ; celle de pas $0{,}25$ en est plus proche.
:::

::: resultat
Avec $h = 0{,}25$ : $f(1) \approx y_4 \approx 2{,}441$, meilleure approximation de $e$ que $2{,}25$.
:::

## Question 4 : Une suite géométrique

::: etape Nature de la suite
$y_{k+1} = (1 + h)\,y_k$ : $(y_k)$ est géométrique de premier terme $y_0 = 1$ et de raison $1 + h = 1 + \dfrac{1}{n}$.
:::

::: etape Terme général
$y_k = y_0 \times (1 + h)^k = \left(1 + \dfrac{1}{n}\right)^k$. Après $n$ pas, on arrive en $x = n \times \dfrac{1}{n} = 1$.
:::

::: resultat
$$y_n = \left(1 + \frac{1}{n}\right)^n \approx f(1) = e$$
:::

## Question 5 : Programme

::: methode
À chaque passage dans la boucle, on remplace $y$ par $y + h \times y$, c’est-à-dire $(1 + h)\,y$.
:::

::: etape Fonction complétée
```python
def euler(n):
    h = 1 / n
    y = 1
    for k in range(n):
        y = y + h * y
    return y
```
:::

::: resultat
La ligne manquante est `y = y + h * y` (ou `y = (1 + h) * y`).

## Question 6 : Conclusion

| $n$ | $10$ | $100$ | $1\,000$ |
|---|---|---|---|

Les valeurs augmentent et se rapprochent de $e$ ; elles restent inférieures à $e$.

Plus le nombre de pas $n$ est grand, plus $\left(1 + \dfrac{1}{n}\right)^n$ est proche de $e \approx 2{,}71828$.

2. $y_1 = 1{,}5$ ; $y_2 = 2{,}25$.

5. `y = y + h * y`
6. Les valeurs se rapprochent de $e \approx 2{,}718$ quand $n$ augmente.

=== Problème - Démontrer les propriétés de l'exponentielle
Id: 4942
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On admet qu’il existe une unique fonction $\exp$, dérivable sur $\mathbb{R}$, telle que $\exp' = \exp$ et $\exp(0) = 1$. On rappelle que, si $u$ est dérivable sur $\mathbb{R}$, la fonction $x \mapsto u(ax + b)$ a pour dérivée $x \mapsto a\,u'(ax + b)$. Le but est de démontrer les propriétés du cours à partir de cette seule définition.

**Partie A — L’exponentielle ne s’annule pas**

On pose $g(x) = \exp(x) \times \exp(-x)$ pour tout réel $x$.

**A1.** Montrer que $g'(x) = 0$ pour tout réel $x$.

**A2.** En déduire que $\exp(x) \times \exp(-x) = 1$, puis que $\exp(x) \neq 0$ pour tout réel $x$.

**Partie B — La relation fonctionnelle**

Soit $b$ un réel fixé. On pose $k(x) = \exp(x + b) \times \exp(-x)$.

**B1.** Montrer que $k$ est constante et que $k(x) = \exp(b)$.

**B2.** En déduire que, pour tous réels $a$ et $b$, $\exp(a + b) = \exp(a) \times \exp(b)$.

**Partie C — Signe et variations**

**C1.** Montrer que, pour tout réel $x$, $\exp(x) = \left(\exp\left(\dfrac{x}{2}\right)\right)^2$. En déduire que $\exp(x) > 0$.

**C2.** En déduire le sens de variation de la fonction exponentielle.

**C3.** Montrer que $\exp(2a) = \left(\exp(a)\right)^2$ et $\exp(3a) = \left(\exp(a)\right)^3$ pour tout réel $a$.

Étapes:
<!-- optitab:1 -->
## Partie A : l’exponentielle ne s’annule pas

## Question A1 : Dérivée de $g$

::: methode
Règle du produit, et dérivée de $x \mapsto \exp(-x)$ avec $a = -1$, $b = 0$.
:::

::: etape Dérivée de $x \mapsto \exp(-x)$
$$
\begin{aligned}
\left(\exp(-x)\right)' &= -1 \times \exp'(-x) \\
&= -\exp(-x)
\end{aligned}
$$
:::

::: etape Règle du produit
$$
\begin{aligned}
g'(x) &= \exp'(x)\exp(-x) \\
&\quad + \exp(x) \times \left(-\exp(-x)\right) \\
&= \exp(x)\exp(-x) \\
&\quad - \exp(x)\exp(-x) \\
&= 0
\end{aligned}
$$
:::

::: resultat
$g'(x) = 0$ pour tout réel $x$.
:::

## Question A2 : Conséquences

::: methode
Une fonction dont la dérivée est nulle sur $\mathbb{R}$ est constante.
:::

::: etape $g$ est constante
Pour tout réel $x$ :
$$
\begin{aligned}
g(x) &= g(0) \\
&= \exp(0) \times \exp(0) \\
&= 1
\end{aligned}
$$
:::

::: etape Non-annulation
Si l’on avait $\exp(x_0) = 0$ pour un réel $x_0$, on aurait $g(x_0) = 0 \times \exp(-x_0) = 0 \neq 1$ : c’est impossible.
:::

::: resultat
Pour tout réel $x$ : $\exp(x)\exp(-x) = 1$ et $\exp(x) \neq 0$ ; ainsi $\exp(-x) = \dfrac{1}{\exp(x)}$.
:::

## Partie B : la relation fonctionnelle

## Question B1 : $k$ est constante

::: etape Dérivée de $x \mapsto \exp(x + b)$
Avec $a = 1$ :
$$
\begin{aligned}
\left(\exp(x + b)\right)' &= \exp'(x + b) \\
&= \exp(x + b)
\end{aligned}
$$
:::

::: etape Règle du produit
$$
\begin{aligned}
k'(x) &= \exp(x + b)\exp(-x) \\
&\quad + \exp(x + b) \times \left(-\exp(-x)\right) \\
&= 0
\end{aligned}
$$
Les deux termes sont opposés. Donc $k$ est constante, et pour tout réel $x$ :
$$
\begin{aligned}
k(x) &= k(0) \\
&= \exp(b) \times \exp(0) \\
&= \exp(b)
\end{aligned}
$$
:::

::: resultat
Pour tout réel $x$ : $\exp(x + b)\exp(-x) = \exp(b)$.
:::

## Question B2 : Conclusion

::: etape Multiplier par $\exp(x)$
D’après la partie A, $\exp(-x) \times \exp(x) = 1$, donc :
$$\exp(x + b) = \exp(b) \times \exp(x)$$
:::

::: resultat
Avec $x = a$ : $\exp(a + b) = \exp(a) \times \exp(b)$ pour tous réels $a$ et $b$.
:::

## Partie C : signe et variations

## Question C1 : Signe

::: etape Relation fonctionnelle avec $a = b = \dfrac{x}{2}$
$$\exp(x) = \exp\left(\frac{x}{2} + \frac{x}{2}\right) = \left(\exp\left(\frac{x}{2}\right)\right)^2$$
:::

::: etape Conclusion
Un carré est positif ou nul, donc $\exp(x) \geqslant 0$. Or $\exp(x) \neq 0$ (partie A).
:::

::: resultat
Pour tout réel $x$, $\exp(x) > 0$.
:::

## Question C2 : Variations

::: etape Signe de la dérivée
$\exp'(x) = \exp(x) > 0$ pour tout réel $x$.
:::

::: resultat
La fonction exponentielle est strictement croissante sur $\mathbb{R}$.
:::

## Question C3 : Puissances

::: etape Avec la relation fonctionnelle
$$
\begin{aligned}
\exp(2a) &= \exp(a + a) = \left(\exp(a)\right)^2 \\
\exp(3a) &= \exp(2a + a) \\
&= \exp(2a) \times \exp(a) \\
&= \left(\exp(a)\right)^3
\end{aligned}
$$
:::

::: resultat
$\exp(2a) = \left(\exp(a)\right)^2$ et $\exp(3a) = \left(\exp(a)\right)^3$ ; en continuant, $\exp(na) = \left(\exp(a)\right)^n$.
:::

::: retenir
Toutes les propriétés de l’exponentielle découlent de $\exp' = \exp$ et $\exp(0) = 1$, grâce à une même idée : une fonction de dérivée nulle est constante.
:::

Solution:
<!-- optitab:1 -->
- A1. $g'(x) = \exp(x)\exp(-x) - \exp(x)\exp(-x) = 0$.
- A2. $g$ est constante égale à $g(0) = 1$, donc $\exp(x) \neq 0$.
- B1. $k'(x) = 0$ et $k(0) = \exp(b)$.
- B2. $\exp(a + b) = \exp(a)\exp(b)$.
- C1. $\exp(x) = \left(\exp\left(\frac{x}{2}\right)\right)^2 \geqslant 0$ et $\exp(x) \neq 0$, donc $\exp(x) > 0$.
- C2. $\exp' = \exp > 0$ : strictement croissante.
- C3. $\exp(2a) = \exp(a)^2$, $\exp(3a) = \exp(a)^3$.
