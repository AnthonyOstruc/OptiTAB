📚 Objectif pédagogique : retenir l’essentiel : équations de droites, pente, parallélisme et systèmes. Programme de Seconde.

I. Équations d’une droite

$\displaystyle ax + by + c = 0$, vecteur directeur $\displaystyle (-b\,;a)$

[IMAGE_1]

1️⃣ Non verticale : $\displaystyle y = mx + p$ avec $\displaystyle m = \frac{y_B - y_A}{x_B - x_A}$ et $\displaystyle p$ l’ordonnée à l’origine.

2️⃣ Verticale : $\displaystyle x = k$ (pas de pente).

3️⃣ $\displaystyle M \in (AB) \iff \det(\overrightarrow{AM}, \overrightarrow{AB}) = 0$.

II. Parallèles ou sécantes ?

[IMAGE_2]

1️⃣ Parallèles $\displaystyle \iff$ vecteurs directeurs colinéaires $\displaystyle \iff ab' - a'b = 0$ (ou $\displaystyle m = m'$).

2️⃣ Sécantes : le point d’intersection est la solution du système.

3️⃣ Résolution par substitution ou par combinaison, puis vérification dans les deux équations.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Inverser la pente : c’est $\displaystyle \frac{\Delta y}{\Delta x}$, pas $\displaystyle \frac{\Delta x}{\Delta y}$.

2️⃣ Oublier le cas $\displaystyle x_A = x_B$ : la droite est verticale, d’équation $\displaystyle x = x_A$.

3️⃣ Prendre $\displaystyle (a\,;b)$ comme vecteur directeur de $\displaystyle ax + by + c = 0$ : c’est $\displaystyle (-b\,;a)$.

4️⃣ Ne pas vérifier la solution d’un système dans les deux équations.

🏆 Réflexe : deux points → je calcule la pente puis $\displaystyle p$ ; un point et un vecteur → j’écris $\displaystyle \det(\overrightarrow{AM}, \vec{u}) = 0$ ; deux droites → je compare les pentes avant de résoudre.
