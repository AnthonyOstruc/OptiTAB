===Résumé Translations, agrandissements et réductions 4ème

Titre: Résumé : Translations, agrandissements et réductions

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : la translation, sa construction, ses propriétés, et le coefficient d'agrandissement ou de réduction. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. La translation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:480px;">
<p style="margin:0; font-weight:bold;">Translation qui transforme $A$ en $A'$ : glissement de même direction, même sens, même longueur. $M \mapsto M'$ ⟺ $AA'M'M$ parallélogramme.</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Elle conserve les longueurs, les angles, les aires, l'alignement, le parallélisme.</p>
<p style="margin:6px 0 0 0;">• Sur quadrillage : on compte les carreaux (par exemple $3$ à droite, $2$ en haut).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Agrandir, réduire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Toutes les longueurs sont multipliées par $k$ ; les angles ne changent pas.</p>
<p style="margin:6px 0 0 0;">2️⃣ $k > 1$ : agrandissement ; $0 < k < 1$ : réduction ; $k = \dfrac{\text{nouvelle longueur}}{\text{longueur de départ}}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Échelle $\dfrac{1}{50}$ : $1$ cm sur le plan $= 50$ cm en réalité.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre translation et symétrie (la translation ne retourne pas la figure).</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $AA'MM'$ au lieu de $AA'M'M$ pour le parallélogramme.</p>
<p style="margin:6px 0 0 0;">3️⃣ Multiplier les angles par $k$ dans un agrandissement.</p>
<p style="margin:6px 0 0 0;">4️⃣ Ajouter une même longueur à tous les côtés au lieu de les multiplier.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> figure identique déplacée sans tourner → translation ; même forme mais taille différente → agrandissement ou réduction, on cherche $k$ en divisant deux longueurs correspondantes.</p>
</div>
