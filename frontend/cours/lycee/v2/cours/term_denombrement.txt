Titre: Combinatoire et dénombrement

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> utiliser les principes additif et multiplicatif, dénombrer les $k$-uplets, les arrangements, les permutations et les combinaisons, connaître les propriétés des coefficients binomiaux (symétrie, relation de Pascal) et choisir le bon modèle de dénombrement.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Principes de dénombrement</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;">• <strong>Principe additif :</strong> si $A$ et $B$ sont disjoints, $\text{card}(A \cup B) = \text{card}(A) + \text{card}(B)$.</p>
            <p style="margin:6px 0 0 0;">• <strong>Principe multiplicatif :</strong> $\text{card}(A \times B) = \text{card}(A) \times \text{card}(B)$ : on multiplie les nombres de choix de chaque étape.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> un menu propose $3$ entrées, $4$ plats et $2$ desserts : il y a $3 \times 4 \times 2 = 24$ menus différents.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. $k$-uplets</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété :</strong> le nombre de $k$-uplets (listes ordonnées de $k$ éléments, répétitions permises) d’un ensemble à $n$ éléments est $n^k$.</p>
            <p style="margin:6px 0 0 0;"><strong>Conséquence (démonstration au programme) :</strong> un ensemble à $n$ éléments possède $2^n$ parties. <em>Preuve :</em> une partie est caractérisée par un $n$-uplet de « oui / non » (on prend ou non chaque élément), et il y en a $2^n$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> un code de carte bancaire à $4$ chiffres : $10^4 = 10\,000$ possibilités.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Arrangements et permutations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriétés :</strong> le nombre de $k$-uplets d’éléments <strong>distincts</strong> (arrangements) d’un ensemble à $n$ éléments est $n(n - 1)\cdots(n - k + 1) = \frac{n!}{(n - k)!}$. Pour $k = n$, on obtient les <strong>permutations</strong> : $n! = n \times (n - 1) \times \cdots \times 1$ (avec $0! = 1$).</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Exemples :</strong> podium (or, argent, bronze) parmi $10$ coureurs : $10 \times 9 \times 8 = 720$ ; anagrammes du mot « MATHS » : $5! = 120$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Combinaisons</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition et propriété :</strong> une <strong>combinaison</strong> de $k$ éléments est une partie à $k$ éléments (sans ordre, sans répétition). Leur nombre est le coefficient binomial $\binom{n}{k} = \frac{n!}{k!\,(n - k)!}$.</p>
            <p style="margin:6px 0 0 0;"><strong>Propriétés :</strong> $\binom{n}{0} = \binom{n}{n} = 1$ ; $\binom{n}{k} = \binom{n}{n - k}$ ; $\sum\limits_{k=0}^{n} \binom{n}{k} = 2^n$.</p>
            <p style="margin:6px 0 0 0;"><strong>Relation de Pascal (démonstration au programme) :</strong> $\binom{n}{k} + \binom{n}{k + 1} = \binom{n + 1}{k + 1}$. <em>Preuve :</em> parmi les parties à $k + 1$ éléments d’un ensemble à $n + 1$ éléments, on distingue celles qui contiennent un élément fixé $a$ ($\binom{n}{k}$ choix des autres) et celles qui ne le contiennent pas ($\binom{n}{k + 1}$).</p>
        </div>
        [IMAGE_2]
        <p style="font-size:1em;"><strong>Exemples :</strong> nombre de mains de $5$ cartes dans un jeu de $32$ : $\binom{32}{5} = 201\,376$. Mains contenant exactement $2$ as : $\binom{4}{2} \times \binom{28}{3} = 6 \times 3\,276 = 19\,656$.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Calculatrice :</strong> $\binom{n}{k}$ s’obtient avec la touche « nCr » (ou « Combinaison ») ; en Python, <code>from math import comb</code> puis <code>comb(32, 5)</code>.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Choisir le bon modèle</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        [IMAGE_3]
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> un tirage <strong>simultané</strong> ne tient pas compte de l’ordre (combinaisons) ; des tirages <strong>successifs sans remise</strong> en tiennent compte (arrangements) ; <strong>avec remise</strong>, on obtient des $k$-uplets.
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $k$-uplets : $n^k$ ; arrangements : $\frac{n!}{(n - k)!}$ ; permutations : $n!$ ; combinaisons : $\binom{n}{k} = \frac{n!}{k!(n - k)!}$ ; $\binom{n}{k} = \binom{n}{n - k}$ ; Pascal : $\binom{n}{k} + \binom{n}{k + 1} = \binom{n + 1}{k + 1}$ ; un ensemble à $n$ éléments a $2^n$ parties. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
