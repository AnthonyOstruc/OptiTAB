## I. Coefficient multiplicateur {Collège}

[IMAGE_1]

| Évolution | Coefficient multiplicateur |
|---|---|
| Hausse de $t\,\%$ | $1 + \dfrac{t}{100}$ |
| Baisse de $t\,\%$ | $1 - \dfrac{t}{100}$ |

::: retenir
Augmenter ou diminuer une valeur d’un pourcentage, c’est la **multiplier** par son coefficient multiplicateur : valeur finale $=$ valeur initiale $\times$ coefficient.
:::

## II. Tableau des hausses et des baisses {Collège}

| Hausse | Coefficient | Baisse | Coefficient |
|---|---|---|---|
| +1 % | 1,01 | −1 % | 0,99 |
| +2 % | 1,02 | −2 % | 0,98 |
| +5 % | 1,05 | −5 % | 0,95 |
| +10 % | 1,1 | −10 % | 0,9 |
| +15 % | 1,15 | −15 % | 0,85 |
| +20 % | 1,2 | −20 % | 0,8 |
| +25 % | 1,25 | −25 % | 0,75 |
| +30 % | 1,3 | −30 % | 0,7 |
| +50 % | 1,5 | −50 % | 0,5 |
| +100 % | 2 | −75 % | 0,25 |

::: exemple
Un vélo à $250$ € augmente de $8\,\%$ : $250 \times 1{,}08 = 270$ €. Il est ensuite soldé à $-25\,\%$ : $270 \times 0{,}75 = 202{,}50$ €.
:::

## III. Évolutions successives {Collège}

Pour enchaîner des évolutions, on **multiplie** les coefficients, on n’additionne pas les pourcentages.

| Évolutions | Calcul | Évolution globale |
|---|---|---|
| +10 % puis +10 % | 1,1 × 1,1 = 1,21 | +21 % |
| +20 % puis −20 % | 1,2 × 0,8 = 0,96 | −4 % |
| −20 % puis +20 % | 0,8 × 1,2 = 0,96 | −4 % |
| +50 % puis −50 % | 1,5 × 0,5 = 0,75 | −25 % |
| +10 % puis −10 % | 1,1 × 0,9 = 0,99 | −1 % |
| +5 % puis +5 % | 1,05 × 1,05 = 1,1025 | +10,25 % |
| −10 % puis −10 % | 0,9 × 0,9 = 0,81 | −19 % |

::: attention Erreur fréquente
$+20\,\%$ puis $-20\,\%$ ne fait pas $0\,\%$ : $1{,}2 \times 0{,}8 = 0{,}96$, soit une **baisse de $4\,\%$**.
:::

## IV. Évolution réciproque {Collège}

Pour revenir à la valeur de départ, on **divise** par le coefficient. Par exemple, après une hausse de 20 %, on divise par $1{,}2$, ce qui correspond à une baisse d’environ $16{,}67\,\%$.

| Évolution | Évolution réciproque |
|---|---|
| +10 % | ≈ −9,09 % |
| +20 % | ≈ −16,67 % |
| +25 % | −20 % |
| +50 % | ≈ −33,33 % |
| +100 % | −50 % |
| −10 % | ≈ +11,11 % |
| −20 % | +25 % |
| −25 % | ≈ +33,33 % |
| −50 % | +100 % |

## V. Taux d’évolution {Collège}

::: formule Taux d’évolution entre une valeur initiale $V_i$ et une valeur finale $V_f$
$$t = \frac{V_f - V_i}{V_i} \times 100$$
:::

::: exemple
Un loyer passe de $800$ € à $840$ € : $t = \dfrac{840 - 800}{800} \times 100 = +5\,\%$.
:::

## VI. TVA, remises et soldes {Collège}

| Situation | Calcul |
|---|---|
| Prix TTC avec une TVA à 20 % | prix HT × 1,2 |
| Prix HT à partir du prix TTC (TVA à 20 %) | prix TTC ÷ 1,2 |
| TVA à 10 % (restauration…) | prix HT × 1,1 |
| TVA à 5,5 % (alimentation, livres…) | prix HT × 1,055 |
| Remise de 30 % | prix × 0,7 |
| Deux remises de 10 % | prix × 0,9 × 0,9 = prix × 0,81 (soit −19 %) |

## VII. Taux d’évolution moyen {Lycée}

Si une valeur subit $n$ évolutions de coefficient global $C$, le taux moyen par période est $t_m$ tel que :
$$(1 + t_m)^n = C \quad \text{donc} \quad 1 + t_m = C^{1/n}$$

::: exemple
Une hausse de $21\,\%$ en deux ans correspond à $1{,}21^{1/2} = 1{,}1$, soit $+10\,\%$ par an en moyenne (et non $+10{,}5\,\%$).
:::
