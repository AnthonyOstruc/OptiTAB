=== Découverte - Suivre un script pas à pas
Id: 2443
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère le script suivant.

[IMAGE_1]

1. Donner la valeur de x après chacun des trois blocs de la famille « Variables » (en orange).
2. Quelle valeur le lutin dit-il ?
3. On échange les blocs « ajouter 5 à x » et « mettre x à x × 2 ». Quelle valeur le lutin dit-il alors ?
4. Dans le script de départ, on remplace $3$ par un nombre $a$. Exprimer la valeur dite en fonction de $a$, puis développer.
5. Par quel nombre faut-il remplacer $3$ pour que le lutin dise $30$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La valeur de x après chaque bloc

::: methode
On exécute les blocs de haut en bas, en partant toujours de la **dernière** valeur de x, et on note tout dans un tableau d'exécution.
:::

::: etape Tableau d'exécution
| Bloc exécuté | Calcul | x |
|---|---|---|
| mettre x à 3 | — | $3$ |
| ajouter 5 à x | $3 + 5$ | $8$ |
| mettre x à x × 2 | $8 \times 2$ | $16$ |
:::

::: resultat
x vaut successivement $3$, $8$, puis $16$.
:::

## Question 2 : La valeur dite

::: etape Le bloc « dire x »
C'est le dernier bloc : il affiche la valeur de x à ce moment-là, donc après les trois blocs de la question 1.
:::

::: resultat
Le lutin dit $16$.
:::

## Question 3 : Les blocs échangés

::: methode
On refait le tableau d'exécution avec le nouvel ordre des blocs (en vert).
:::

[IMAGE_2]

::: etape Tableau d'exécution
| Bloc exécuté | Calcul | x |
|---|---|---|
| mettre x à 3 | — | $3$ |
| mettre x à x × 2 | $3 \times 2$ | $6$ |
| ajouter 5 à x | $6 + 5$ | $11$ |
:::

::: resultat
Le lutin dit $11$ : l'ordre des instructions change le résultat.
:::

## Question 4 : La valeur dite en fonction de $a$

::: methode
On suit les blocs avec $a$ à la place de $3$. Le bloc « mettre x à x × 2 » multiplie **tout** le résultat précédent par $2$ : il faut des parenthèses.
:::

::: etape Suivre les blocs avec $a$
- Après « ajouter 5 à x » : x vaut $a + 5$.
- Après « mettre x à x × 2 » : x vaut $(a + 5) \times 2$.
:::

::: etape Développer
$$(a + 5) \times 2 = a \times 2 + 5 \times 2 = 2a + 10$$
:::

::: resultat
Le lutin dit $(a + 5) \times 2 = 2a + 10$.
:::

## Question 5 : Obtenir 30

::: etape Résoudre l'équation $2a + 10 = 30$
$$
\begin{aligned}
2a + 10 &= 30 \\
2a &= 20 \\
a &= 10
\end{aligned}
$$
:::

::: point Vérification
$(10 + 5) \times 2 = 15 \times 2 = 30$.
:::

::: resultat
Il faut remplacer $3$ par $10$.
:::

::: attention Erreur fréquente
Écrire $a + 5 \times 2$ : le script ajoute $5$ **avant** de multiplier, donc on écrit $(a + 5) \times 2$, avec des parenthèses.
:::

Solution:
<!-- optitab:1 -->
1. $3$ ; $8$ ; $16$
2. $16$
3. $11$
4. $(a + 5) \times 2 = 2a + 10$
5. $10$

=== Découverte - Compléter un programme de calcul
Id: 2444
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Voici un programme de calcul :

- choisir un nombre ;
- lui ajouter $4$ ;
- multiplier le résultat par $3$ ;
- annoncer le résultat.

Lina le programme avec Scratch. Voici son script, avec trois cases A, B et C à compléter.

[IMAGE_1]

1. Que faut-il placer dans les cases A, B et C ?
2. Quel résultat le lutin dit-il si l'on répond $2$ ? si l'on répond $-4$ ? si l'on répond $0{,}5$ ?
3. On note $x$ le nombre choisi. Exprimer le résultat en fonction de $x$, puis développer.
4. Quel nombre faut-il choisir pour que le lutin dise $30$ ?
5. Tom a placé le bloc « mettre x à x × 3 » **avant** le bloc « ajouter 4 à x ». Quel résultat son script donne-t-il pour $2$ ? Programme-t-il le même calcul ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter le script

::: methode
On traduit chaque étape du programme par un bloc. Le nombre tapé par l'utilisateur est rangé dans le bloc **réponse** ; on applique ensuite les opérations dans l'ordre.
:::

::: etape Les trois cases
- Case A : x doit recevoir le nombre choisi, c'est-à-dire **réponse** (famille Capteurs).
- Case B : on ajoute $4$ à x.
- Case C : on multiplie x par $3$.
:::

[IMAGE_2]

::: resultat
A : réponse ; B : $4$ ; C : $3$.
:::

## Question 2 : Trois essais

::: methode
On suit le script avec chaque réponse : d'abord « ajouter 4 », puis « × 3 ».
:::

::: etape Calculs
- Réponse $2$ : $2 + 4 = 6$, puis $6 \times 3 = 18$.
- Réponse $-4$ : $-4 + 4 = 0$, puis $0 \times 3 = 0$.
- Réponse $0{,}5$ : $0{,}5 + 4 = 4{,}5$, puis $4{,}5 \times 3 = 13{,}5$.
:::

::: resultat
Le lutin dit $18$, puis $0$, puis $13{,}5$.
:::

## Question 3 : Le résultat en fonction de $x$

::: methode
Avec $x$ : « ajouter 4 » donne $x + 4$ ; la multiplication par $3$ porte sur **toute** cette expression.
:::

::: etape Développer
$$3(x + 4) = 3 \times x + 3 \times 4 = 3x + 12$$
:::

::: resultat
Le résultat est $3(x + 4) = 3x + 12$.
:::

## Question 4 : Obtenir 30

::: etape Résoudre l'équation $3x + 12 = 30$
$$
\begin{aligned}
3x + 12 &= 30 \\
3x &= 18 \\
x &= 6
\end{aligned}
$$
:::

::: point Vérification
$(6 + 4) \times 3 = 10 \times 3 = 30$.
:::

::: resultat
Il faut choisir $6$.
:::

## Question 5 : Le script de Tom

::: etape Avec $2$
Tom multiplie d'abord : $2 \times 3 = 6$, puis il ajoute : $6 + 4 = 10$.
:::

::: etape Avec un nombre $x$ quelconque
Le script de Tom calcule $3x + 4$, alors que le programme demande $3(x + 4) = 3x + 12$.
:::

::: resultat
Le script de Tom dit $10$ pour $2$ (au lieu de $18$) : il ne programme pas le même calcul.
:::

::: retenir
« demander … et attendre » est l'**entrée** du programme (la valeur tapée va dans **réponse**) ; « dire » est sa **sortie**. L'ordre des blocs traduit l'ordre des étapes du calcul.
:::

Solution:
<!-- optitab:1 -->
1. A : réponse ; B : $4$ ; C : $3$
2. $18$ ; $0$ ; $13{,}5$
3. $3(x + 4) = 3x + 12$
4. $6$
5. $10$ ; non, son script calcule $3x + 4$.

=== Découverte - Une boucle « répéter n fois »
Id: 2445
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère le script suivant.

[IMAGE_1]

1. Combien de fois le bloc « ajouter 3 à x » est-il exécuté ?
2. Donner la valeur de x à la fin de chaque tour de boucle.
3. Quelle valeur le lutin dit-il ?
4. Combien de fois le bloc « dire x » est-il exécuté ? Pourquoi ?
5. Que faut-il modifier pour que le lutin dise $30$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Nombre d'exécutions

::: methode
On regarde où est placé le bloc : il est **dans** la mâchoire du bloc « répéter 4 fois ».
:::

::: resultat
Le bloc « ajouter 3 à x » est exécuté $4$ fois, une fois par tour.
:::

## Question 2 : Les valeurs de x

::: methode
x part de $0$ ; à chaque tour, on ajoute $3$ à la dernière valeur.
:::

::: etape Tableau d'exécution
| Tour | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| x à la fin du tour | $3$ | $6$ | $9$ | $12$ |
:::

::: resultat
x vaut $3$, $6$, $9$, puis $12$.
:::

## Question 3 : La valeur dite

::: etape Après la boucle
Le bloc « dire x » est exécuté quand la boucle est terminée, avec la dernière valeur de x.
:::

::: resultat
Le lutin dit $12$.
:::

## Question 4 : Le bloc « dire x »

::: etape Sa place dans le script
Il est emboîté **sous** le bloc « répéter », et non dans sa mâchoire : il n'est pas répété.
:::

::: resultat
Une seule fois, car il est placé après la boucle.
:::

## Question 5 : Obtenir 30

::: methode
Chaque tour ajoute $3$ : la valeur dite est $3 \times (\text{nombre de tours})$.
:::

::: etape Nombre de tours
$$3 \times n = 30 \quad \text{donc} \quad n = \frac{30}{3} = 10$$
:::

[IMAGE_2]

::: resultat
Il faut remplacer « répéter 4 fois » par « répéter 10 fois » (bloc vert).
:::

::: attention Erreur fréquente
Confondre les blocs **dans** la boucle (exécutés à chaque tour) et les blocs **après** la boucle (exécutés une seule fois).
:::

Solution:
<!-- optitab:1 -->
1. $4$ fois
2. $3$ ; $6$ ; $9$ ; $12$
3. $12$
4. Une seule fois : il est après la boucle.
5. « répéter 10 fois »

=== Découverte - Un test « si … alors … sinon »
Id: 2446
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le script suivant compare le nombre choisi à $10$.

[IMAGE_1]

1. Que dit le lutin si l'on répond $9$ ?
2. Que dit-il si l'on répond $10$ ?
3. Que dit-il si l'on répond $14$ ?
4. Quel est le plus grand nombre entier pour lequel il dit « petit » ?
5. Que dit-il pour $9{,}99$ ? pour $-20$ ?
6. On veut que le lutin dise « petit » aussi pour $10$. Par quelle condition faut-il remplacer « x < 10 » ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Réponse 9

::: methode
On évalue la condition « x < 10 » : si elle est vraie, on exécute la branche « alors » ; sinon, la branche « sinon ».
:::

::: etape Condition
$9 < 10$ est **vraie**.
:::

::: resultat
Le lutin dit « petit ».
:::

## Question 2 : Réponse 10

::: etape Condition
$10 < 10$ est **fausse** : $10$ n'est pas strictement inférieur à $10$. On passe dans la branche « sinon ».
:::

::: resultat
Le lutin dit « grand ».
:::

## Question 3 : Réponse 14

::: etape Condition
$14 < 10$ est fausse.
:::

::: resultat
Le lutin dit « grand ».
:::

## Question 4 : Le plus grand entier « petit »

::: etape
Le lutin dit « petit » exactement quand $x < 10$. Le plus grand entier strictement inférieur à $10$ est $9$.
:::

::: resultat
$9$.
:::

## Question 5 : Réponses $9{,}99$ et $-20$

::: etape Conditions
$9{,}99 < 10$ est vraie ; $-20 < 10$ est vraie.
:::

::: resultat
Le lutin dit « petit » dans les deux cas.
:::

## Question 6 : Inclure 10

::: methode
« petit » doit être dit quand $x < 10$ **ou** $x = 10$ : on combine deux conditions avec le bloc « ou ».
:::

[IMAGE_2]

::: resultat
On remplace la condition par « (x < 10) ou (x = 10) » (en vert). Remplacer $10$ par $11$ ne convient pas : $10{,}5$ serait alors « petit ».
:::

::: retenir
Pour tester un script qui contient une condition, essayer **toujours** la valeur frontière (ici $10$).
:::

Solution:
<!-- optitab:1 -->
1. petit
2. grand
3. grand
4. $9$
5. petit ; petit
6. « (x < 10) ou (x = 10) »

=== Découverte - Se repérer sur la scène
Id: 2447
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la scène, l'abscisse x va de $-240$ à $240$ et l'ordonnée y de $-180$ à $180$. L'orientation $0$ est vers le haut, $90$ vers la droite, $180$ vers le bas et $-90$ vers la gauche. Au départ, le stylo est relevé.

[IMAGE_1]

1. Où se trouve le lutin après le bloc « aller à x : −100 y : 50 » ? On appelle $A$ ce point. Ce déplacement est-il tracé ?
2. Vers où le lutin regarde-t-il après « s'orienter à 90 » ? Quelles sont ses coordonnées après « avancer de 80 pas » (point $B$) ?
3. Quelles sont ses coordonnées après « ajouter −90 à y » (point $C$) ? Ce déplacement est-il horizontal ou vertical ?
4. Où se trouve-t-il à la fin du script (point $D$) ?
5. Calculer la longueur totale du tracé, puis le représenter dans un repère.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le point A

::: etape « aller à x : −100 y : 50 »
Le lutin est placé au point d'abscisse $-100$ et d'ordonnée $50$. Le stylo n'est mis en position d'écriture qu'**après** ce bloc : le déplacement n'est pas tracé.
:::

::: resultat
$A(-100\ ;\ 50)$ ; ce déplacement n'est pas tracé.
:::

## Question 2 : Le point B

::: methode
Orientation $90$ : le lutin regarde vers la droite. Avancer vers la droite augmente l'abscisse, l'ordonnée ne change pas.
:::

::: etape Calcul
$x = -100 + 80 = -20$ et $y = 50$.
:::

::: resultat
Le lutin regarde vers la droite ; $B(-20\ ;\ 50)$.
:::

## Question 3 : Le point C

::: etape « ajouter −90 à y »
Seule l'ordonnée change : $y = 50 + (-90) = -40$ ; l'abscisse reste $-20$. Le stylo est baissé : ce segment vertical est tracé.
:::

::: resultat
$C(-20\ ;\ -40)$ ; le déplacement est vertical, vers le bas.
:::

## Question 4 : Le point D

::: etape « s'orienter à −90 », puis « avancer de 60 pas »
Le lutin regarde vers la gauche : l'abscisse diminue de $60$, soit $x = -20 - 60 = -80$ ; $y$ reste $-40$.
:::

::: resultat
$D(-80\ ;\ -40)$, le lutin regardant vers la gauche.
:::

## Question 5 : Le tracé

::: etape Les positions successives
- « aller à x : −100 y : 50 » : $A(-100\ ;\ 50)$, déplacement non tracé.
- « avancer de 80 pas » : $B(-20\ ;\ 50)$, segment de longueur $80$.
- « ajouter −90 à y » : $C(-20\ ;\ -40)$, segment de longueur $90$.
- « avancer de 60 pas » : $D(-80\ ;\ -40)$, segment de longueur $60$.
:::

::: etape Longueur totale
$$80 + 90 + 60 = 230$$
:::

[IMAGE_2]

::: resultat
Le tracé est la ligne brisée $ABCD$ (en vert), de longueur $230$.
:::

::: attention Erreur fréquente
Penser que « avancer » augmente toujours x : le lutin avance dans la direction où il **regarde** ; avec l'orientation $-90$, l'abscisse diminue.
:::

Solution:
<!-- optitab:1 -->
1. $A(-100\ ;\ 50)$ ; non tracé
2. Vers la droite ; $B(-20\ ;\ 50)$
3. $C(-20\ ;\ -40)$ ; vertical
4. $D(-80\ ;\ -40)$
5. $230$

=== Découverte - Tracer un carré avec le stylo
Id: 2448
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
« tourner ↺ » fait tourner le lutin dans le sens inverse des aiguilles d'une montre.

[IMAGE_1]

1. Quelles sont les coordonnées du lutin après le premier « avancer de 40 pas » ?
2. Vers où le lutin regarde-t-il après le premier « tourner ↺ de 90 degrés » ?
3. Quelle figure est tracée ? Donner les coordonnées de ses sommets.
4. Quelle est la longueur totale tracée ?
5. Comment modifier le script pour tracer un triangle équilatéral de côté $40$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Après le premier déplacement

::: methode
Le lutin part de $(0\ ;\ 0)$ orienté vers la droite (orientation $90$) : avancer de $40$ augmente l'abscisse de $40$.
:::

::: resultat
$(40\ ;\ 0)$.
:::

## Question 2 : Après le premier quart de tour

::: etape « tourner ↺ de 90 degrés »
Un quart de tour dans le sens inverse des aiguilles d'une montre : le lutin qui regardait vers la droite regarde maintenant vers le haut.
:::

::: resultat
Vers le haut (orientation $0$).
:::

## Question 3 : La figure tracée

::: etape Tour par tour : position après « avancer », orientation après « tourner »
- Tour 1 : $(40\ ;\ 0)$, puis orientation $0$ (haut).
- Tour 2 : $(40\ ;\ 40)$, puis orientation $-90$ (gauche).
- Tour 3 : $(0\ ;\ 40)$, puis orientation $180$ (bas).
- Tour 4 : $(0\ ;\ 0)$, puis orientation $90$ (droite).
:::

::: etape Conclusion
Quatre côtés de longueur $40$ et quatre angles droits : c'est un carré.
:::

[IMAGE_2]

::: resultat
Un carré de côté $40$, de sommets $(0\ ;\ 0)$, $(40\ ;\ 0)$, $(40\ ;\ 40)$ et $(0\ ;\ 40)$.
:::

## Question 4 : La longueur tracée

::: etape Calcul
Le stylo trace $4$ segments de longueur $40$ : $4 \times 40 = 160$.
:::

::: resultat
La longueur tracée est $160$.
:::

## Question 5 : Un triangle équilatéral

::: methode
Pour revenir au point de départ, les rotations doivent faire un tour complet : $360^\circ$. Avec $3$ côtés, le lutin tourne de $\dfrac{360}{3} = 120^\circ$ à chaque sommet.
:::

[IMAGE_3]

::: etape Le tracé obtenu
Trois côtés de $40$ et trois rotations de $120^\circ$ : le lutin revient en $(0\ ;\ 0)$, orienté vers la droite.
:::

[IMAGE_4]

::: resultat
« répéter 3 fois » et « tourner ↺ de 120 degrés » (en vert).
:::

::: attention Erreur fréquente
Tourner de $60^\circ$ (l'angle **intérieur** du triangle) : le lutin tourne de l'angle **extérieur**, $180^\circ - 60^\circ = 120^\circ$.
:::

Solution:
<!-- optitab:1 -->
1. $(40\ ;\ 0)$
2. Vers le haut (orientation $0$)
3. Un carré de sommets $(0\ ;\ 0)$, $(40\ ;\ 0)$, $(40\ ;\ 40)$, $(0\ ;\ 40)$
4. $160$
5. « répéter 3 fois » et « tourner ↺ de 120 degrés »

=== Découverte - Une somme cumulée
Id: 2449
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère le script suivant, qui utilise deux variables s et n.

[IMAGE_1]

1. Donner les valeurs de s et de n à la fin de chacun des cinq tours.
2. Quelle valeur le lutin dit-il ?
3. Quelle est la valeur de n à la fin du script ?
4. Quel calcul ce script effectue-t-il ?
5. Quelle valeur dirait-il avec « répéter 10 fois » ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le tableau des valeurs

::: methode
Au départ, s vaut $0$ et n vaut $1$. À chaque tour, on ajoute n à s, **puis** on augmente n de $1$ : on respecte cet ordre.
:::

::: etape Tableau d'exécution
| Tour | s | n |
|---|---|---|
| départ | $0$ | $1$ |
| 1 | $0 + 1 = 1$ | $2$ |
| 2 | $1 + 2 = 3$ | $3$ |
| 3 | $3 + 3 = 6$ | $4$ |
| 4 | $6 + 4 = 10$ | $5$ |
| 5 | $10 + 5 = 15$ | $6$ |
:::

::: resultat
s vaut $1$, $3$, $6$, $10$, $15$ et n vaut $2$, $3$, $4$, $5$, $6$.
:::

## Question 2 : La valeur dite

::: etape
Le bloc « dire s » est après la boucle : on lit la dernière valeur de s dans le tableau.
:::

::: resultat
Le lutin dit $15$.
:::

## Question 3 : La valeur finale de n

::: etape
n part de $1$ et augmente de $1$ à chacun des $5$ tours : $1 + 5 = 6$.
:::

::: resultat
n vaut $6$.
:::

## Question 4 : Le calcul effectué

::: etape
À chaque tour, on ajoute à s la valeur de n : $1$, puis $2$, $3$, $4$ et $5$.
:::

::: resultat
Le script calcule la somme $1 + 2 + 3 + 4 + 5 = 15$.
:::

## Question 5 : Avec 10 tours

::: methode
s cumule alors les entiers de $1$ à $10$ ; on les regroupe par paires de somme $11$.
:::

::: etape Calcul
$$(1 + 10) + (2 + 9) + (3 + 8) + (4 + 7) + (5 + 6) = 5 \times 11 = 55$$
:::

::: resultat
Le lutin dirait $55$.
:::

::: attention Erreur fréquente
Inverser les deux blocs de la boucle : si n augmente **avant** d'être ajouté, le script calcule $2 + 3 + 4 + 5 + 6 = 20$.
:::

Solution:
<!-- optitab:1 -->
1. s : $1$ ; $3$ ; $6$ ; $10$ ; $15$ — n : $2$ ; $3$ ; $4$ ; $5$ ; $6$
2. $15$
3. $6$
4. $1 + 2 + 3 + 4 + 5$
5. $55$

=== Entraînement - Une boucle « répéter jusqu'à »
Id: 2450
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère le script suivant.

[IMAGE_1]

1. Donner les valeurs successives de x.
2. Combien de tours la boucle effectue-t-elle ?
3. Quelle valeur le lutin dit-il ?
4. On remplace « ajouter 6 à x » par « ajouter 5 à x ». Combien de tours la boucle fait-elle ? Quelle valeur est dite ?
5. On remplace par « ajouter 0 à x ». Que se passe-t-il ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les valeurs de x

::: methode
La condition « x > 20 » est testée **avant** chaque tour : si elle est fausse, on fait un tour ; dès qu'elle est vraie, la boucle s'arrête.
:::

::: etape Tableau d'exécution
| Tour | x avant le tour | x > 20 ? | x à la fin du tour |
|---|---|---|---|
| 1 | $0$ | non | $6$ |
| 2 | $6$ | non | $12$ |
| 3 | $12$ | non | $18$ |
| 4 | $18$ | non | $24$ |
| — | $24$ | oui : arrêt | — |
:::

::: resultat
x vaut $0$, puis $6$, $12$, $18$ et $24$.
:::

## Question 2 : Le nombre de tours

::: etape
On compte les lignes « non » du tableau : $18 > 20$ est faux, mais $24 > 20$ est vrai.
:::

::: resultat
La boucle fait $4$ tours.
:::

## Question 3 : La valeur dite

::: etape
Le bloc « dire x » est exécuté à la sortie de la boucle, avec la première valeur qui a rendu la condition vraie.
:::

::: resultat
Le lutin dit $24$.
:::

## Question 4 : Avec « ajouter 5 à x »

::: etape Valeurs successives
$0$, $5$, $10$, $15$, $20$, $25$. Attention : $20 > 20$ est **faux**, il faut donc encore un tour.
:::

::: resultat
$5$ tours ; le lutin dit $25$.
:::

## Question 5 : Avec « ajouter 0 à x »

::: etape
x reste égal à $0$ : la condition $0 > 20$ est toujours fausse.
:::

::: resultat
La boucle ne s'arrête jamais : c'est une boucle infinie, le lutin ne dit rien.
:::

::: attention Erreur fréquente
Croire que la boucle s'arrête « à 20 » : elle s'arrête à la **première** valeur qui rend la condition vraie ($24$, ou $25$ à la question 4).
:::

Solution:
<!-- optitab:1 -->

=== Problème - Un programme de calcul mystère
Id: 2458
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère le script suivant.

[IMAGE_1]

1. Quel résultat obtient-on en choisissant $5$ ?

3. Et en choisissant $2{,}5$ ? Quelle conjecture peut-on faire ?
4. Démontrer cette conjecture pour un nombre $n$ quelconque.
5. Par quel nombre faut-il remplacer $8$ pour que le résultat soit toujours $5$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Avec 5

::: methode
On suit les blocs dans l'ordre : r reçoit n × 4, puis on ajoute $8$, on divise par $4$ et on soustrait n.
:::

::: etape Tableau d'exécution
| Bloc exécuté | Calcul | r |
|---|---|---|
| mettre r à n × 4 | $5 \times 4$ | $20$ |
| ajouter 8 à r | $20 + 8$ | $28$ |
| mettre r à r / 4 | $28 \div 4$ | $7$ |
| mettre r à r − n | $7 - 5$ | $2$ |
:::

::: resultat
Le lutin dit $2$.
:::

## Question 2 : Avec −3

::: etape Calculs
$-3 \times 4 = -12$ ; $-12 + 8 = -4$ ; $-4 \div 4 = -1$ ; $-1 - (-3) = -1 + 3 = 2$.
:::

::: resultat
Le lutin dit $2$.
:::

## Question 3 : Avec 2,5

::: etape Calculs
$2{,}5 \times 4 = 10$ ; $10 + 8 = 18$ ; $18 \div 4 = 4{,}5$ ; $4{,}5 - 2{,}5 = 2$.
:::

::: resultat
On obtient encore $2$. Conjecture : le résultat est toujours égal à $2$.
:::

## Question 4 : La démonstration

::: methode
Trois exemples ne suffisent pas : on fait le calcul avec une lettre, valable pour tous les nombres.
:::

::: etape Calcul littéral
$$
\begin{aligned}
r &= \frac{4n + 8}{4} - n \\
&= \frac{4n}{4} + \frac{8}{4} - n \\
&= n + 2 - n \\
&= 2
\end{aligned}
$$
:::

::: resultat
Pour tout nombre $n$, le résultat vaut $2$ : la conjecture est démontrée.
:::

## Question 5 : Obtenir toujours 5

::: etape Avec un nombre $a$ à la place de 8
$$\frac{4n + a}{4} - n = n + \frac{a}{4} - n = \frac{a}{4}$$
:::

::: etape Résoudre
$$\frac{a}{4} = 5 \quad \text{donc} \quad a = 20$$
:::

::: resultat
Il faut remplacer $8$ par $20$.
:::

::: attention Erreur fréquente
Considérer que trois exemples **prouvent** la conjecture : seul le calcul littéral la démontre pour tous les nombres.
:::

Solution:
<!-- optitab:1 -->
1. $2$
2. $2$
3. $2$ ; le résultat est toujours $2$.
4. $\dfrac{4n + 8}{4} - n = n + 2 - n = 2$
5. $20$

« tourner ↺ » tourne dans le sens inverse des aiguilles d'une montre, « tourner ↻ » dans le sens des aiguilles d'une montre.

[IMAGE_1]

1. Quelle est la position du lutin à la fin du premier tour de boucle ?
2. Quelle est son orientation à la fin de chaque tour ?
3. Quelle est sa position finale ?
4. Quelle est la longueur totale tracée ?
5. Sur quelle droite se trouvent les « nez de marche » $(20\ ;\ 20)$, $(40\ ;\ 40)$… ? Que faut-il modifier pour tracer $8$ marches de $15$ ? Où arrive alors le lutin ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le premier tour

::: etape Le premier tour, bloc par bloc
- Départ : $(0\ ;\ 0)$, vers la droite (orientation $90$).
- « avancer de 20 pas » : $(20\ ;\ 0)$.
- « tourner ↺ de 90 degrés » : vers le haut (orientation $0$).
- « avancer de 20 pas » : $(20\ ;\ 20)$.
- « tourner ↻ de 90 degrés » : de nouveau vers la droite (orientation $90$).
:::

::: resultat
$(20\ ;\ 20)$.
:::

## Question 2 : L'orientation

::: etape
Dans chaque tour, le lutin tourne de $90^\circ$ dans un sens, puis de $90^\circ$ dans l'autre : les deux rotations se compensent.
:::

::: resultat
À la fin de chaque tour, il regarde vers la droite (orientation $90$).
:::

## Question 3 : La position finale

::: etape
Chaque tour ajoute $20$ à x et $20$ à y ; il y a $5$ tours : $5 \times 20 = 100$.
:::

[IMAGE_2]

::: resultat
$(100\ ;\ 100)$.
:::

## Question 4 : La longueur tracée

::: etape
Chaque tour trace deux segments de $20$ :
$$5 \times (20 + 20) = 200$$
:::

::: resultat
La longueur tracée est $200$.
:::

## Question 5 : La droite et la modification

::: etape Les nez de marche
Les points $(20\ ;\ 20)$, $(40\ ;\ 40)$, …, $(100\ ;\ 100)$ ont une ordonnée égale à leur abscisse : ils sont sur la droite d'équation $y = x$.
:::

::: etape 8 marches de 15
On remplace « répéter 5 fois » par « répéter 8 fois », et $20$ par $15$ dans les deux blocs « avancer ». Arrivée : $8 \times 15 = 120$.
:::

::: resultat
Droite d'équation $y = x$ ; avec « répéter 8 fois » et « avancer de 15 pas » (deux fois), le lutin arrive en $(120\ ;\ 120)$.
:::

::: retenir
Pour suivre un lutin, noter à chaque étape sa **position** et son **orientation**.
:::

Solution:
<!-- optitab:1 -->
1. $(20\ ;\ 20)$
2. Vers la droite (orientation $90$)
3. $(100\ ;\ 100)$
4. $200$
5. $y = x$ ; « répéter 8 fois » et « avancer de 15 pas » ; arrivée en $(120\ ;\ 120)$

=== Problème - Des polygones réguliers
Id: 2460
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Le bloc personnalisé « polygone » a deux paramètres : le nombre de côtés n et la longueur d'un côté.

[IMAGE_1]

1. Que trace « polygone (6) (30) » ? De quel angle le lutin tourne-t-il à chaque sommet ?
2. Calculer le périmètre de la figure tracée.
3. Quel appel faut-il écrire pour tracer un triangle équilatéral de côté $50$ ? De quel angle le lutin tourne-t-il ?
4. Un élève veut tracer un pentagone régulier ($5$ côtés). Il fait tourner son lutin de $108^\circ$ à chaque sommet. Que se passe-t-il ? Quel angle faut-il ?
5. Que trace « polygone (36) (5) » ? Calculer son périmètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : « polygone (6) (30) »

::: methode
Le bloc répète n fois « avancer de côté ; tourner de 360 / n degrés » : n côtés égaux, et un tour complet de $360^\circ$ à la fin.
:::

::: etape Avec n = 6 et côté = 30
Six côtés de $30$ ; à chaque sommet, le lutin tourne de $\dfrac{360}{6} = 60^\circ$.
:::

[IMAGE_2]

::: resultat
Un hexagone régulier de côté $30$ ; le lutin tourne de $60^\circ$ à chaque sommet.
:::

## Question 2 : Le périmètre

::: etape
Périmètre d'un polygone régulier $=$ nombre de côtés $\times$ longueur d'un côté :
$$6 \times 30 = 180$$
:::

::: resultat
Le périmètre est $180$.
:::

## Question 3 : Le triangle équilatéral

::: etape
Un triangle équilatéral a $3$ côtés égaux : n $= 3$ et côté $= 50$ ; l'angle de rotation est $\dfrac{360}{3} = 120^\circ$.
:::

::: resultat
« polygone (3) (50) » : le lutin tourne de $120^\circ$ à chaque sommet.
:::

## Question 4 : Le pentagone

::: etape L'erreur
$108^\circ$ est l'angle **intérieur** du pentagone régulier. Après $5$ rotations, le lutin a tourné de $5 \times 108^\circ = 540^\circ$, et non de $360^\circ$ : la figure ne se referme pas (tracé orange en pointillés).
:::

::: etape Le bon angle
Le lutin doit tourner de l'angle **extérieur** :
$$\frac{360}{5} = 72^\circ = 180^\circ - 108^\circ$$
:::

[IMAGE_3]

::: resultat
La figure ne se referme pas ; il faut tourner de $72^\circ$ (pentagone vert).
:::

## Question 5 : « polygone (36) (5) »

::: etape
Avec n $= 36$, le lutin tourne de $\dfrac{360}{36} = 10^\circ$ à chaque sommet : beaucoup de petits côtés, qui tournent peu.
:::

::: resultat
Un polygone régulier à $36$ côtés, qui ressemble à un cercle ; périmètre : $36 \times 5 = 180$.
:::

::: retenir
Polygone régulier à $n$ côtés : le lutin tourne de $\dfrac{360}{n}$ degrés, l'angle **extérieur**.
:::

Solution:
<!-- optitab:1 -->
1. Un hexagone régulier de côté $30$ ; $60^\circ$
2. $180$
3. « polygone (3) (50) » ; $120^\circ$
4. La figure ne se referme pas ; $72^\circ$
5. Un polygone à $36$ côtés, presque un cercle ; $180$

=== Problème - Le jeu du nombre secret
Id: 2461
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Dans ce jeu, l'ordinateur choisit un nombre secret que le joueur doit deviner.

[IMAGE_1]

1. Quel est le rôle du bloc « mettre secret à nombre aléatoire entre 1 et 100 » ?
2. Le nombre secret est $37$. Le joueur propose $50$, puis $25$, puis $37$. Quels messages le lutin dit-il ?
3. Quelle valeur le lutin dit-il à la fin de cette partie ? Que représente-t-elle ?
4. Un joueur propose un nombre au hasard entre $1$ et $100$. Quelle est la probabilité qu'il trouve du premier coup ?
5. Un joueur propose toujours le nombre situé au milieu des nombres encore possibles. Expliquer pourquoi $7$ essais lui suffisent toujours.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le nombre secret

::: resultat
Ce bloc, exécuté une seule fois avant la boucle, choisit au hasard un entier entre $1$ et $100$ : c'est le nombre à deviner.
:::

## Question 2 : Les messages

::: methode
À chaque tour : le joueur propose un nombre (réponse), essais augmente de $1$, puis on compare réponse au secret.
:::

::: etape Tour par tour (secret = 37)
- Proposition $50$ : essais vaut $1$ ; $50 < 37$ est faux, $50 > 37$ est vrai : « Plus petit ! ».
- Proposition $25$ : essais vaut $2$ ; $25 < 37$ est vrai : « Plus grand ! ».
- Proposition $37$ : essais vaut $3$ ; les deux conditions sont fausses : aucun message. Avant le tour suivant, réponse $=$ secret est vrai : la boucle s'arrête.
:::

::: resultat
« Plus petit ! », puis « Plus grand ! » ; pour $37$, aucun message, et la boucle s'arrête car réponse $=$ secret.
:::

## Question 3 : La valeur finale

::: etape
Après la boucle, le lutin dit essais, qui a augmenté de $1$ à chaque proposition.
:::

::: resultat
Le lutin dit $3$ : c'est le nombre d'essais du joueur.
:::

## Question 4 : Du premier coup

::: etape
Les $100$ nombres de $1$ à $100$ ont la même chance d'être proposés, et un seul est le secret.
:::

::: resultat
$\dfrac{1}{100}$.
:::

## Question 5 : La stratégie du milieu

::: methode
Si l'essai est faux, le message indique de quel côté chercher : il reste au plus la **moitié** des nombres encore possibles.
:::

::: etape Nombres encore possibles après chaque essai raté
$$100 \to 50 \to 25 \to 12 \to 6 \to 3 \to 1$$
Après $6$ essais ratés, il reste au plus un nombre : le $7$e essai est forcément le bon.
:::

::: resultat
$7$ essais suffisent toujours. Cela vient de $2^6 = 64 < 100 \leq 2^7 = 128$.
:::

::: retenir
Couper en deux à chaque étape (la **dichotomie**) est la stratégie la plus rapide.
:::

Solution:
<!-- optitab:1 -->
1. Choisir le nombre secret au hasard
2. « Plus petit ! » ; « Plus grand ! » ; aucun message
3. $3$, le nombre d'essais
4. $\dfrac{1}{100}$
5. Chaque essai raté divise au moins par deux les possibilités : $100 \to 50 \to 25 \to 12 \to 6 \to 3 \to 1$.

=== Type brevet - Une frise de triangles

Énoncé:
<!-- optitab:1 -->
On a écrit le bloc personnalisé « triangle » et le script principal ci-dessous.

[IMAGE_1]

1. Que trace l'instruction « triangle (20) » ? Pourquoi le lutin tourne-t-il de $120^\circ$ à chaque sommet ?
2. Quelles sont la valeur de longueur et la position du lutin à la fin du premier passage dans la boucle ?
3. Parmi les trois dessins ci-dessous, lequel le script produit-il ? Justifier.

4. Quelle est la longueur totale tracée ?

<!-- optitab:1 -->
## Question 1 : Le bloc « triangle »

::: etape Le tracé de « triangle (20) »
Le bloc répète $3$ fois « avancer de 20 pas ; tourner ↺ de 120 degrés » : trois côtés de longueur $20$, et le lutin revient à son point de départ après $3 \times 120^\circ = 360^\circ$.

Les angles d'un triangle équilatéral mesurent $60^\circ$ ; le lutin tourne de l'angle extérieur : $180^\circ - 60^\circ = 120^\circ$.

Un triangle équilatéral de côté $20$ ; le lutin tourne de $120^\circ = \dfrac{360}{3}$, l'angle extérieur.

::: etape Bloc par bloc

On compare la taille des triangles et l'espace entre eux avec ce que fait le script.

- longueur augmente de $20$ à chaque passage : les triangles **grandissent** ($20$, $40$, $60$, $80$). Le dessin C, aux triangles égaux, ne convient pas.

C'est le dessin B.

Les quatre triangles ont pour côtés $20$, $40$, $60$ et $80$ ; chacun a trois côtés :

=== Type brevet - La somme de deux dés
Id: 2463
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Le script suivant simule $1\,000$ lancers de deux dés équilibrés à six faces.

[IMAGE_1]

1. Que représentent les variables d1 et d2 ? Quelles sont les valeurs possibles de d1 + d2 ?
2. Que compte la variable compteur ? Que représente le nombre dit par le lutin ?
3. Combien y a-t-il d'issues (d1 ; d2) équiprobables ? Lesquelles donnent une somme égale à $7$ ? En déduire la probabilité d'obtenir une somme égale à $7$.
4. Le lutin dit $0{,}171$. Ce résultat est-il surprenant ?
5. On veut maintenant estimer la probabilité d'obtenir un **double** (deux faces identiques). Quelle condition faut-il placer dans le bloc « si » ? Quelle valeur le lutin devrait-il dire environ ?
6. On remplace $7$ par $12$ dans le script de départ. Autour de combien de succès peut-on s'attendre ? Quelle somme est la plus probable ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les variables d1 et d2

::: etape
d1 et d2 reçoivent chacune un entier au hasard entre $1$ et $6$ : ce sont les résultats des deux dés. La plus petite somme est $1 + 1 = 2$, la plus grande $6 + 6 = 12$.
:::

::: resultat
Les faces des deux dés ; la somme peut valoir $2$, $3$, …, $12$ (onze valeurs).
:::

## Question 2 : Le compteur et la valeur dite

::: etape
compteur augmente de $1$ chaque fois que d1 + d2 $= 7$ ; à la fin, le lutin dit compteur / 1000.
:::

::: resultat
compteur compte les lancers dont la somme vaut $7$ ; le lutin dit la **fréquence** de la somme $7$ sur $1\,000$ lancers.
:::

## Question 3 : La probabilité de la somme 7

::: etape Les issues
Chaque dé a $6$ faces : $6 \times 6 = 36$ couples (d1 ; d2), tous équiprobables.
:::

::: etape Les issues de somme 7
$(1\ ;\ 6)$, $(2\ ;\ 5)$, $(3\ ;\ 4)$, $(4\ ;\ 3)$, $(5\ ;\ 2)$, $(6\ ;\ 1)$ : $6$ issues.
:::

::: etape La probabilité
$$P(\text{somme } 7) = \frac{6}{36} = \frac{1}{6}$$
:::

::: resultat
$36$ issues ; $6$ donnent $7$ ; la probabilité est $\dfrac{1}{6}$.
:::

## Question 4 : Une fréquence de 0,171

::: etape Comparer
$\dfrac{1}{6} \approx 0{,}167$ : l'écart avec $0{,}171$ est d'environ $0{,}004$.
:::

::: resultat
Non : sur $1\,000$ lancers, la fréquence est proche de la probabilité $\dfrac{1}{6}$, sans lui être égale.
:::

## Question 5 : Estimer la probabilité d'un double

::: etape La condition
Un double, c'est d1 $=$ d2 : on remplace la condition par « d1 = d2 ».
:::

[IMAGE_2]

::: etape La probabilité
Il y a $6$ doubles parmi les $36$ issues : $\dfrac{6}{36} = \dfrac{1}{6} \approx 0{,}167$.
:::

::: resultat
Condition « d1 = d2 » (en vert) ; le lutin devrait dire environ $0{,}167$.
:::

## Question 6 : La somme 12

::: etape
Une seule issue donne $12$ : $(6\ ;\ 6)$. Probabilité $\dfrac{1}{36}$, donc environ $\dfrac{1\,000}{36} \approx 28$ succès.
:::

::: etape Comparer les sommes
| Somme | Nombre d'issues sur $36$ |
|---|---|
| $2$ ou $12$ | $1$ |
| $3$ ou $11$ | $2$ |
| $4$ ou $10$ | $3$ |
| $5$ ou $9$ | $4$ |
| $6$ ou $8$ | $5$ |
| $7$ | $6$ |
:::

::: resultat
Environ $28$ succès ; la somme $7$ est la plus probable ($6$ issues sur $36$).
:::

::: attention Erreur fréquente
Croire que les onze sommes sont équiprobables : on raisonne sur les $36$ **couples** (d1 ; d2), qui eux le sont.
:::

Solution:
<!-- optitab:1 -->
1. Les faces des deux dés ; de $2$ à $12$
2. Le nombre de sommes égales à $7$ ; la fréquence de la somme $7$
3. $36$ issues ; $(1\ ;\ 6)$, $(2\ ;\ 5)$, $(3\ ;\ 4)$, $(4\ ;\ 3)$, $(5\ ;\ 2)$, $(6\ ;\ 1)$ ; $\dfrac{1}{6}$
4. Non : $0{,}171$ est proche de $\dfrac{1}{6} \approx 0{,}167$.
5. « d1 = d2 » ; environ $0{,}167$
6. Environ $28$ ; la somme $7$
