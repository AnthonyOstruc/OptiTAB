Titre: Résumé : Fonction exponentielle : limites et études

::: objectifs
Retenir l’essentiel : règles de calcul, limites, croissances comparées, dérivée de $e^u$, étude de fonction. Programme de Terminale.
:::

## I. Règles et limites

1. $e^{a + b} = e^a e^b$ ; $e^{-a} = \frac{1}{e^a}$ ; $\left(e^a\right)^n = e^{na}$ ; $e^x \gt 0$ ; $e^x \ge 1 + x$.
2. $e^a = e^b \iff a = b$ et $e^a \lt e^b \iff a \lt b$.
3. $\lim\limits_{x \to +\infty} e^x = +\infty$ ; $\lim\limits_{x \to -\infty} e^x = 0$ ; $\lim\limits_{x \to 0} \frac{e^x - 1}{x} = 1$.

[IMAGE_1]

::: formule Croissances comparées (pour tout entier $n \ge 1$)
$$\lim_{x \to +\infty} \frac{e^x}{x^n} = +\infty$$

$$\lim_{x \to +\infty} x^n e^{-x} = 0 \qquad \lim_{x \to -\infty} x^n e^x = 0$$
:::

En l’infini, l’exponentielle l’emporte sur toute puissance de $x$ : on factorise par le terme dominant, puis on conclut.

## II. Dériver et étudier

1. $\left(e^u\right)' = u' e^u$ ; $\left(e^{ax + b}\right)' = a\,e^{ax + b}$.
2. $\left(u\,e^v\right)' = u' e^v + u v' e^v = \left(u' + u v'\right) e^v$ : on factorise par l’exponentielle.
3. Le signe de $f'$ est celui du facteur devant $e^{\ldots}$, qui est toujours strictement positif.

::: tableau Exemple : $f(x) = x e^{-x}$, $f'(x) = (1 - x)\,e^{-x}$
x : -\infty, 1, +\infty
f'(x) : , +, z, -,
f(x) : -/-\infty, +/\frac{1}{e}, -/0
:::

## III. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Oublier $u'$ en dérivant $e^u$ : $\left(e^{x^2}\right)' = 2x\,e^{x^2}$.
2. Conclure sur « $\frac{\infty}{\infty}$ » sans utiliser les croissances comparées.
3. Étudier le signe de $e^{\ldots}$ dans un tableau de signes : c’est toujours strictement positif.
4. Croire qu’une valeur limite est atteinte.
:::

::: remarque Réflexe
Étude de $f(x) = P(x)\,e^{ax + b}$ : je factorise $f'(x)$ par l’exponentielle et j’étudie le signe du reste.
:::
