## Question 1 : Moyenne et médiane initiales

::: methode
Moyenne = somme ÷ nombre de valeurs ; la série est déjà rangée, avec $5$ valeurs (effectif impair).
:::

::: etape La moyenne
$$\frac{1\,800 + 1\,900 + 2\,000 + 2\,100 + 2\,200}{5} = \frac{10\,000}{5} = 2\,000$$
:::

::: etape La médiane
Rang $\dfrac{5 + 1}{2} = 3$ : la 3ᵉ valeur est $2\,000$.
:::

::: resultat
Moyenne : $2\,000$ € ; médiane : $2\,000$ €.
:::

## Question 2 : La nouvelle moyenne

::: etape Nouvelle somme, nouvel effectif
Somme : $10\,000 + 9\,000 = 19\,000$ ; effectif : $6$.
:::

::: etape Diviser
$$\frac{19\,000}{6} \approx 3\,166{,}67$$
:::

::: resultat
La nouvelle moyenne est d'environ $3\,167$ €.
:::

## Question 3 : La nouvelle médiane

::: etape Série rangée de 6 valeurs
$1\,800\ ;\ 1\,900\ ;\ 2\,000\ ;\ 2\,100\ ;\ 2\,200\ ;\ 9\,000$
:::

::: etape Valeurs centrales (rangs 3 et 4)
$$\frac{2\,000 + 2\,100}{2} = 2\,050$$
:::

::: resultat
La nouvelle médiane est $2\,050$ €.
:::

## Question 4 : L'indicateur qui a le plus changé

::: etape Comparer les variations
- Moyenne : $3\,167 - 2\,000 = 1\,167$ € de plus environ ;
- Médiane : $2\,050 - 2\,000 = 50$ € de plus.
:::

::: resultat
C'est la moyenne qui a le plus changé (environ $+1\,167$ € contre $+50$ €).
:::

## Question 5 : Le salaire « typique »

::: methode
Un indicateur « typique » doit ressembler à la plupart des valeurs.
:::

::: etape Comparer à la moyenne
$5$ salariés sur $6$ gagnent moins de $3\,167$ € : la moyenne ne ressemble à presque personne.
:::

::: resultat
La médiane ($2\,050$ €) est la plus représentative : une valeur extrême déforme la moyenne mais presque pas la médiane.
:::

::: attention Erreur fréquente
Croire que la médiane bouge autant que la moyenne : une valeur extrême déplace beaucoup la moyenne, mais très peu la médiane.
:::

::: retenir
Face à des valeurs extrêmes, la médiane décrit mieux la situation « typique ».
:::

Solution:
<!-- optitab:1 -->
1. $2\,000$ € et $2\,000$ €
2. Environ $3\,167$ €
3. $2\,050$ €
4. La moyenne
5. La médiane (peu sensible aux valeurs extrêmes)
