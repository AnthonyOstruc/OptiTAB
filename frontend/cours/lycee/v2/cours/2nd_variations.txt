Titre: Étudier les variations et les extremums d’une fonction

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> définir une fonction croissante ou décroissante, lire et dresser un tableau de variations, déterminer un maximum ou un minimum, relier le signe de la pente d’une fonction affine à ses variations, et démontrer les variations des fonctions de référence.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Sens de variation</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> soit $f$ une fonction définie sur un intervalle $I$.</p>
            <p style="margin:6px 0 0 0;">• $f$ est <strong>croissante</strong> sur $I$ si pour tous $u$ et $v$ de $I$ : $u \lt v \Rightarrow f(u) \le f(v)$.</p>
            <p style="margin:6px 0 0 0;">• $f$ est <strong>décroissante</strong> sur $I$ si pour tous $u$ et $v$ de $I$ : $u \lt v \Rightarrow f(u) \ge f(v)$.</p>
            <p style="margin:6px 0 0 0;">Avec des inégalités strictes, on parle de fonction <strong>strictement</strong> croissante ou décroissante. Une fonction croissante ou décroissante sur $I$ est dite <strong>monotone</strong> sur $I$.</p>
        </div>
        [IMAGE_1]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Image mentale :</strong> une fonction croissante « monte » quand on lit la courbe de gauche à droite et conserve l’ordre ; une fonction décroissante « descend » et inverse l’ordre.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Tableau de variations et extremums</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> $M$ est le <strong>maximum</strong> de $f$ sur $I$ si $f(x) \le M$ pour tout $x$ de $I$ et s’il existe $a$ dans $I$ tel que $f(a) = M$. Le <strong>minimum</strong> se définit de même avec $f(x) \ge m$. Maximum et minimum sont des <strong>extremums</strong>.</p>
        </div>
        [IMAGE_2]
        <p style="font-size:1em;">Le <strong>tableau de variations</strong> résume la courbe : les flèches indiquent le sens de variation, et on écrit aux extrémités des flèches les images des valeurs remarquables.</p>
        [IMAGE_3]
        <p style="font-size:1em;"><strong>Lecture :</strong> sur $[-3\,;5]$, le maximum de $f$ est $3$, atteint en $x = 2$, et le minimum est $-2$, atteint en $x = -1$. On en déduit par exemple que $-2 \le f(x) \le 3$ pour tout $x$ de $[-3\,;5]$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> un extremum dépend de l’intervalle. Sur $[-3\,;0]$, le maximum de cette fonction est $2$, atteint en $-3$ (une borne), et non $3$. Le maximum est une valeur de $f(x)$ ; l’endroit où il est atteint est une valeur de $x$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonctions affines</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété :</strong> la fonction affine $f(x) = mx + p$ est strictement croissante sur $\mathbb{R}$ si $m \gt 0$, strictement décroissante si $m \lt 0$, constante si $m = 0$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> pour $u \lt v$, $f(v) - f(u) = (mv + p) - (mu + p) = m(v - u)$, qui a le signe de $m$ puisque $v - u \gt 0$.</p>
        </div>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Taux de variation :</strong> le quotient $\frac{f(v) - f(u)}{v - u}$ vaut $m$ pour une fonction affine : c’est la pente de la droite.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Variations des fonctions de référence</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété (démonstrations au programme) :</strong> on compare $f(u)$ et $f(v)$ en étudiant le signe de $f(v) - f(u)$ pour $u \lt v$.</p>
            <p style="margin:6px 0 0 0;">• Carré, sur $[0\,;+\infty[$ : $v^2 - u^2 = (v - u)(v + u) \gt 0$, donc croissante.</p>
            <p style="margin:6px 0 0 0;">• Inverse, sur $]0\,;+\infty[$ : $\frac{1}{v} - \frac{1}{u} = \frac{u - v}{uv} \lt 0$, donc décroissante.</p>
            <p style="margin:6px 0 0 0;">• Racine carrée, sur $[0\,;+\infty[$ : $\sqrt{v} - \sqrt{u} = \frac{v - u}{\sqrt{v} + \sqrt{u}} \gt 0$, donc croissante.</p>
        </div>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> un ou deux exemples numériques ne prouvent pas qu’une fonction est croissante : il faut raisonner avec des réels $u \lt v$ quelconques.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Approcher un maximum avec Python</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">On calcule les images de $n + 1$ valeurs régulièrement espacées de $[a\,;b]$ et on garde la plus grande (méthode par <strong>balayage</strong>) :</p>
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">def maximum(f, a, b, n):
    h = (b - a) / n
    m = f(a)
    for k in range(1, n + 1):
        x = a + k &#42; h
        if f(x) &gt; m:
            m = f(x)
    return m</div>
        <p style="font-size:1em;"><strong>Exemple :</strong> avec $f(x) = -x^2 + 4x$ sur $[0\,;5]$ et $n = 100$, la fonction renvoie environ $4$ : c’est bien le maximum, atteint en $x = 2$.</p>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> croissante : $u \lt v \Rightarrow f(u) \le f(v)$ (ordre conservé) ; décroissante : ordre inversé ; le tableau de variations résume la courbe et donne les extremums ; un extremum dépend de l’intervalle ; affine : variations données par le signe de $m$ ; pour démontrer, on étudie le signe de $f(v) - f(u)$. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
