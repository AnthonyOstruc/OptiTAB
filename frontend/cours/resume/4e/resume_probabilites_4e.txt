<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : vocabulaire, calcul d'une probabilité, événement contraire, fréquence, deux épreuves. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Calculer</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Équiprobabilité : $\displaystyle P(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$.</p>
[IMAGE_1]
<p style="margin:6px 0 0 0;">• Impossible : $0$ ; certain : $1$ ; somme des probabilités des issues : $1$.</p>
<p style="margin:6px 0 0 0;">• Contraire : $P(\text{non } A) = 1 - P(A)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Fréquences et deux épreuves</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Sur un GRAND nombre d'essais, la fréquence se rapproche de la probabilité.</p>
<p style="margin:6px 0 0 0;">• Deux dés : tableau de $36$ issues équiprobables ; $P(\text{somme } 7) = \frac{6}{36} = \frac{1}{6}$.</p>
[IMAGE_2]
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Donner une probabilité supérieure à $1$ ou négative.</p>
<p style="margin:6px 0 0 0;">2️⃣ Croire que les sommes de deux dés sont équiprobables.</p>
<p style="margin:6px 0 0 0;">3️⃣ Penser qu'après plusieurs « pile », « face » devient plus probable.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre la fréquence observée sur peu d'essais avec la probabilité.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je liste d'abord TOUTES les issues (avec un tableau si besoin), je vérifie qu'elles sont équiprobables, puis je compte les issues favorables.</p>
</div>
