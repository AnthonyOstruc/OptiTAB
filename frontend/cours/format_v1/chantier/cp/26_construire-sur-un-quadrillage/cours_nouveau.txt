Titre: La géométrie plane : construire sur quadrillage
<!-- optitab:1 -->
::: objectifs
Je reproduis et je complète une figure.
:::

## I. J’observe et je manipule

::: methode Avec le matériel
Repère un sommet d’un modèle. Compte les carreaux le long de chaque côté et reproduis la figure à côté.
:::

[IMAGE_1]

## II. Je comprends

::: definition Les repères
Je repère les sommets avant de tracer.

Je compte les carreaux, pas seulement les traits du quadrillage.

Pour ces carrés et rectangles, les côtés suivent les lignes du quadrillage.
:::

## III. Je fais pas à pas

::: methode
1. Je repère les sommets du modèle.
2. Je compte les carreaux entre les sommets.
3. Je place les mêmes sommets sur le quadrillage vide.
4. Je les relie à la règle et je compare les deux figures.
:::
::: exemple
Un rectangle de 4 carreaux sur 2 carreaux a deux grands côtés de 4 et deux petits de 2.
:::

## IV. À toi de jouer

::: exemple
Trace un carré de 3 carreaux de côté sur ta feuille.
:::
::: resultat Je vérifie
Les quatre côtés mesurent chacun 3 carreaux.
:::
::: attention
Compte les espaces entre les lignes : quatre carreaux relient cinq lignes. Un carreau n’est pas toujours un centimètre.
:::
::: retenir
Pour ces carrés et rectangles, les côtés suivent les lignes du quadrillage.

Carré : quatre côtés de même longueur.
:::
