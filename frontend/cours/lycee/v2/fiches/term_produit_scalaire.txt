<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Plans et vecteurs normaux</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\vec{n}\,(a\,;b\,;c)$ normal $\iff \mathcal{P} : ax + by + cz + d = 0$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $\vec{u} \cdot \vec{v} = xx' + yy' + zz'$ ; $\|\vec{u}\| = \sqrt{x^2 + y^2 + z^2}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Droite $\perp$ plan $\iff$ orthogonale à deux droites sécantes du plan.</p>
<p style="margin:6px 0 0 0;">3️⃣ Plans parallèles : normaux colinéaires ; perpendiculaires : normaux orthogonaux.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Projeté et distance</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\overrightarrow{MH} = t\,\vec{n}$ et $H \in \mathcal{P}$ : on trouve $t$, puis $H$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Distance de $M$ au plan : $MH$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $H$ est le point du plan le plus proche de $M$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Vérifier l’orthogonalité à une seule droite du plan.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier de calculer $d$ avec un point du plan.</p>
<p style="margin:6px 0 0 0;">3️⃣ Confondre vecteur normal et vecteur directeur d’un plan.</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire que deux droites orthogonales sont forcément sécantes.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour écrire l’équation d’un plan, il me faut un point et un vecteur normal ; pour un normal, je cherche un vecteur orthogonal à deux vecteurs non colinéaires du plan.</p>
</div>
