Titre: Résumé : Polynômes du Second Degré

<!-- optitab:1 -->
::: objectifs
Maîtriser les polynômes du second degré : formes (développée, canonique, factorisée), discriminant, racines, résolution d'équations, signe, factorisation. Applications pratiques.
:::

## I. Définitions et formes

::: definition Polynôme du second degré
Une fonction polynôme du second degré (ou trinôme) est définie sur $\mathbb{R}$ par :

::: formule
$$f(x) = ax^2 + bx + c$$
:::

où $a$, $b$ et $c$ sont des réels avec $a \neq 0$.
:::

| Forme | Expression et utilisation |
|---|---|
| **Développée réduite** | $\displaystyle f(x) = ax^2 + bx + c$ <br> Utilisation : calculer l'image, additionner/soustraire |
| **Canonique** | $\displaystyle f(x) = a(x-\alpha)^2 + \beta$ <br> Utilisation : variations, extremums (sommet en $\displaystyle (\alpha, \beta)$) |
| **Factorisée** | $\displaystyle f(x) = a(x-x_1)(x-x_2)$ (2 racines) <br> ou $\displaystyle f(x) = a(x-x_0)^2$ (racine double) <br> Utilisation : équations, signe |

## II. Discriminant et racines

::: definition Discriminant
Pour $\displaystyle f(x) = ax^2 + bx + c$, le discriminant est :

::: formule
$$\Delta = b^2 - 4ac$$
:::
:::

| Cas | Nombre de racines |
|---|---|
| $\displaystyle \Delta > 0$ | Deux racines distinctes $\displaystyle x_1$ et $\displaystyle x_2$ |
| $\displaystyle \Delta = 0$ | Une racine double $\displaystyle x_0 = -\frac{b}{2a}$ |
| $\displaystyle \Delta < 0$ | Aucune racine réelle |

::: methode Comment utiliser le graphique du sommet de la parabole
Le graphique montre la parabole représentant une fonction polynôme du second degré :

1. Le **sommet** $S(\alpha, \beta)$ est le point d'extremum de la parabole
2. Si $a > 0$ : la parabole est tournée vers le haut ($\cup$), le sommet est un **minimum**
3. Si $a < 0$ : la parabole est tournée vers le bas ($\cap$), le sommet est un **maximum**
4. L'axe de symétrie de la parabole est la droite verticale passant par le sommet : $x = \alpha$
5. Les coordonnées du sommet sont : $\alpha = -\frac{b}{2a}$ et $\beta = f(\alpha) = -\frac{\Delta}{4a}$
:::

## III. Résolution d'équations

::: theoreme Résolution de $\displaystyle ax^2 + bx + c = 0$
On calcule $\displaystyle \Delta = b^2 - 4ac$ :
:::

| Cas | Solutions |
|---|---|
| $\displaystyle \Delta > 0$ | $\displaystyle x_1 = \frac{-b-\sqrt{\Delta}}{2a}$ <br> $\displaystyle x_2 = \frac{-b+\sqrt{\Delta}}{2a}$ |
| $\displaystyle \Delta = 0$ | $\displaystyle x_0 = -\frac{b}{2a}$ (racine double) |
| $\displaystyle \Delta < 0$ | Aucune solution réelle |

## IV. Relations coefficients-racines

| Relation | Formule |
|---|---|
| Somme des racines | $\displaystyle x_1 + x_2 = -\frac{b}{a}$ |
| Produit des racines | $\displaystyle x_1 \times x_2 = \frac{c}{a}$ |

::: remarque Utilisation
Ces relations permettent de vérifier les racines ou de les trouver rapidement par essais (exemple : $x^2 - 5x + 6 = 0$ → somme = 5, produit = 6 → racines : 2 et 3).
:::

## V. Forme canonique

::: theoreme Forme canonique
Tout polynôme $\displaystyle f(x) = ax^2 + bx + c$ peut s'écrire :

::: formule
$$f(x) = a(x-\alpha)^2 + \beta$$
:::

avec $\alpha = -\frac{b}{2a}$ et $\beta = f(\alpha) = -\frac{\Delta}{4a}$

Le sommet de la parabole est le point $S(\alpha, \beta)$.
:::

| Coefficient $\displaystyle a$ | Variations et extremum |
|---|---|
| $\displaystyle a > 0$ | Décroissante sur $\displaystyle ]-\infty, \alpha]$ <br> Croissante sur $\displaystyle [\alpha, +\infty[$ <br> **Minimum** en $\displaystyle x = \alpha$ (parabole $\displaystyle \cup$) |
| $\displaystyle a < 0$ | Croissante sur $\displaystyle ]-\infty, \alpha]$ <br> Décroissante sur $\displaystyle [\alpha, +\infty[$ <br> **Maximum** en $\displaystyle x = \alpha$ (parabole $\displaystyle \cap$) |

::: definition Tableau de variation
Pour $f(x) = ax^2 + bx + c$ avec $\alpha = -\frac{b}{2a}$ et $\beta = f(\alpha)$ :
:::

::: remarque Cas 1 : $a > 0$ (parabole $\cup$)
:::

::: tableau
x : -\infty, \alpha, +\infty
Variation de $f$ : +/+\infty, -/\beta, +/+\infty
:::

*Minimum en $x = \alpha$, valeur : $f(\alpha) = \beta$*

::: remarque Cas 2 : $a < 0$ (parabole $\cap$)
:::

::: tableau
x : -\infty, \alpha, +\infty
Variation de $f$ : -/-\infty, +/\beta, -/-\infty
:::

*Maximum en $x = \alpha$, valeur : $f(\alpha) = \beta$*

## VI. Signe d'un polynôme

| Cas | Signe de $\displaystyle f(x)$ |  |  |  |  |  |  |
|---|---|---|---|---|---|---|---|
| $\displaystyle \Delta > 0$, $\displaystyle a > 0$, Racines : $\displaystyle x_1 < x_2$ |  |  |  |  |  |  |  |
| $\displaystyle x$ $\displaystyle -\infty$ $\displaystyle x_1$ $\displaystyle x_2$ $\displaystyle +\infty$ Signe de $\displaystyle f(x)$ $+$ $0$ $-$ $0$ $+$ |  |  |  |  |  |  |  |
| $\displaystyle x$ | $\displaystyle -\infty$ |  | $\displaystyle x_1$ |  | $\displaystyle x_2$ |  | $\displaystyle +\infty$ |
| Signe de $\displaystyle f(x)$ |  | $+$ | $0$ | $-$ | $0$ | $+$ |  |
| $\displaystyle \Delta > 0$, $\displaystyle a < 0$, Racines : $\displaystyle x_1 < x_2$ |  |  |  |  |  |  |  |
| $\displaystyle x$ $\displaystyle -\infty$ $\displaystyle x_1$ $\displaystyle x_2$ $\displaystyle +\infty$ Signe de $\displaystyle f(x)$ $-$ $0$ $+$ $0$ $-$ |  |  |  |  |  |  |  |
| $\displaystyle x$ | $\displaystyle -\infty$ |  | $\displaystyle x_1$ |  | $\displaystyle x_2$ |  | $\displaystyle +\infty$ |
| Signe de $\displaystyle f(x)$ |  | $-$ | $0$ | $+$ | $0$ | $-$ |  |
| $\displaystyle \Delta = 0$ <br> Racine double : $\displaystyle x_0$ | $\displaystyle f(x_0) = 0$ <br> $\displaystyle f(x)$ a le même signe que $\displaystyle a$ pour tout $\displaystyle x \neq x_0$ |  |  |  |  |  |  |
| $\displaystyle \Delta < 0$ | $\displaystyle f(x)$ a le même signe que $\displaystyle a$ pour tout $\displaystyle x \in \mathbb{R}$ |  |  |  |  |  |  |

## VII. Stratégies de factorisation

| Stratégie | Méthode |
|---|---|
| **Racine évidente** | Tester $\displaystyle 0, 1, -1, 2, -2, \ldots$ <br> Exemple : $\displaystyle f(2) = 0$ → $\displaystyle 2$ est racine |
| **Somme et produit** | Utiliser $\displaystyle x_1 + x_2 = -\frac{b}{a}$ et $\displaystyle x_1 \times x_2 = \frac{c}{a}$ <br> Chercher deux nombres avec cette somme et ce produit |
| **Identités remarquables** | $\displaystyle a^2 - b^2 = (a-b)(a+b)$ <br> $\displaystyle (a+b)^2 = a^2 + 2ab + b^2$ <br> $\displaystyle (a-b)^2 = a^2 - 2ab + b^2$ |
| **Formules générales** | Calculer $\displaystyle \Delta$ puis utiliser : <br> • Si $\displaystyle \Delta > 0$ : $\displaystyle f(x) = a(x-x_1)(x-x_2)$ <br> • Si $\displaystyle \Delta = 0$ : $\displaystyle f(x) = a(x-x_0)^2$ |

## VIII. Choix de la forme adaptée

| Type de problème | Forme à utiliser |
|---|---|
| Calculer $\displaystyle f(x_0)$ | **Forme développée** : $\displaystyle f(x) = ax^2 + bx + c$ |
| Résoudre $\displaystyle f(x) = 0$ | **Forme factorisée** ou discriminant |
| Étudier le signe | **Forme factorisée** : $\displaystyle f(x) = a(x-x_1)(x-x_2)$ |
| Trouver extremum | **Forme canonique** : $\displaystyle f(x) = a(x-\alpha)^2 + \beta$ <br> Sommet en $\displaystyle (\alpha, \beta)$ |
| Variations | **Forme canonique** : signe de $\displaystyle a$ et position de $\displaystyle \alpha$ |

## IX. Erreurs fréquentes

| Piège fréquent | Correction |
|---|---|
| Oublier le coefficient $\displaystyle a$ dans la forme factorisée | $\displaystyle f(x) = a(x-x_1)(x-x_2)$ <br> **Ne pas oublier $\displaystyle a$ !** |
| Erreur de signe dans le discriminant | $\displaystyle \Delta = b^2 - 4ac$ <br> Attention au signe moins devant $\displaystyle 4ac$ |
| Confondre $\displaystyle x_1$ et $\displaystyle x_2$ | $\displaystyle x_1 = \frac{-b-\sqrt{\Delta}}{2a}$ (le plus petit) <br> $\displaystyle x_2 = \frac{-b+\sqrt{\Delta}}{2a}$ (le plus grand) |
| Oublier le cas $\displaystyle \Delta = 0$ | Si $\displaystyle \Delta = 0$ : il y a **une racine double** $\displaystyle x_0 = -\frac{b}{2a}$ |
| Signe incorrect | Si $\displaystyle a > 0$ : $\displaystyle f(x) < 0$ **entre** les racines <br> Si $\displaystyle a < 0$ : $\displaystyle f(x) > 0$ **entre** les racines |
| Forme canonique : oublier le signe moins | $\displaystyle \alpha = -\frac{b}{2a}$ <br> **Attention au signe moins !** |
| Division par zéro | Vérifier que $\displaystyle a \neq 0$ avant d'appliquer les formules |

## X. Formules essentielles — mémo rapide

| Formule | Expression |
|---|---|
| Discriminant | $\displaystyle \Delta = b^2 - 4ac$ |
| Racines ($\displaystyle \Delta > 0$) | $\displaystyle x_1 = \frac{-b-\sqrt{\Delta}}{2a}$ <br> $\displaystyle x_2 = \frac{-b+\sqrt{\Delta}}{2a}$ |
| Racine double ($\displaystyle \Delta = 0$) | $\displaystyle x_0 = -\frac{b}{2a}$ |
| Somme des racines | $\displaystyle x_1 + x_2 = -\frac{b}{a}$ |
| Produit des racines | $\displaystyle x_1 \times x_2 = \frac{c}{a}$ |
| Forme canonique | $\displaystyle f(x) = a(x-\alpha)^2 + \beta$ <br> avec $\displaystyle \alpha = -\frac{b}{2a}$ et $\displaystyle \beta = -\frac{\Delta}{4a}$ |
| Forme factorisée | $\displaystyle f(x) = a(x-x_1)(x-x_2)$ (si $\displaystyle \Delta > 0$) <br> $\displaystyle f(x) = a(x-x_0)^2$ (si $\displaystyle \Delta = 0$) |

## XI. Méthodologie — stratégie de résolution

| Type de problème | Méthode recommandée |
|---|---|
| Résoudre $\displaystyle ax^2 + bx + c = 0$ | 1. Calculer $\displaystyle \Delta = b^2 - 4ac$ <br> 2. Selon le signe de $\displaystyle \Delta$ : <br> • $\displaystyle \Delta > 0$ : deux solutions <br> • $\displaystyle \Delta = 0$ : une solution double <br> • $\displaystyle \Delta < 0$ : aucune solution |
| Factoriser un polynôme | 1. Tester des racines évidentes ($\displaystyle 0, 1, -1, 2, -2$) <br> 2. Sinon, calculer $\displaystyle \Delta$ et utiliser les formules <br> 3. Vérifier avec somme et produit des racines |
| Étudier le signe | 1. Mettre sous forme factorisée <br> 2. Identifier les racines <br> 3. Faire un tableau de signes <br> 4. Attention au signe de $\displaystyle a$ |
| Trouver un extremum | 1. Mettre sous forme canonique <br> 2. Identifier $\displaystyle \alpha = -\frac{b}{2a}$ et $\displaystyle \beta = f(\alpha)$ <br> 3. Le sommet est $\displaystyle S(\alpha, \beta)$ <br> 4. Si $\displaystyle a > 0$ : minimum, si $\displaystyle a < 0$ : maximum |
| Résoudre une inéquation | 1. Mettre sous forme factorisée <br> 2. Étudier le signe <br> 3. Utiliser le tableau de signes pour conclure |

::: remarque Points de vigilance
- Toujours vérifier que $a \neq 0$ avant d'appliquer les formules
- Pour le signe, utiliser la forme factorisée et faire attention au signe de $a$
- Vérifier les racines en les remplaçant dans l'équation initiale
- Utiliser les relations somme/produit pour vérifier ou trouver rapidement les racines
:::
