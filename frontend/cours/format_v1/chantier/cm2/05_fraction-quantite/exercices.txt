=== Découverte - Deux tiers des jetons
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Que représente une part quand on cherche les $\frac{2}{3}$ de 24 jetons ?
2. Combien de jetons prend-on ?
3. Combien de jetons reste-t-il ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Partager le tout en autant de groupes que le dénominateur.
:::

::: etape Raisonner avec les données
$24\div3=8$. Une part contient 8 jetons.
:::

::: resultat 
8 jetons.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Prendre le nombre de parts indiqué par le numérateur.
:::

::: etape Raisonner avec les données
$8\times2=16$.
:::

::: resultat 
16 jetons.
:::

## Question 3 : Vérifier et conclure

::: methode 
Soustraire la partie prise au total.
:::

::: etape Raisonner avec les données
$24-16=8$.
:::

::: resultat 
8 jetons.
:::

Solution:
<!-- optitab:1 -->
1. 8 jetons.
2. 16 jetons.
3. 8 jetons.

2. Calculer le produit sous la forme d’une fraction.
3. Donner la longueur totale sous la forme entier plus fraction, en mètres.

<!-- optitab:1 -->

::: methode 
Le facteur entier indique le nombre de répétitions.
:::

::: etape Raisonner avec les données

:::

::: resultat

:::

## Question 2 : Expliquer le raisonnement

::: methode 
Multiplier le nombre de parts, conserver leur taille.
:::

::: etape Raisonner avec les données
$3\times5=15$ parts de taille $\frac{1}{4}$.

::: resultat 
$\frac{15}{4}$.

## Question 3 : Vérifier et conclure

::: methode 
Former les unités complètes avec les parts.
:::

::: etape Raisonner avec les données

:::

::: resultat 
$3+\frac{3}{4}$ m.
:::

<!-- optitab:1 -->

=== Problème - Choisir et justifier une préparation
Id: nouveau-21
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. On réserve $\frac{7}{12}$ de 180 feuilles. Combien de feuilles sont réservées ?
2. Il faut 100 feuilles pour l’atelier. La réserve suffit-elle ?
3. Combien de feuilles du stock total resteront après l’atelier, si on utilise exactement le besoin ?
4. Si l’on réserve seulement les deux tiers du stock, peut-on encore couvrir le même besoin de 100 feuilles ? Comparer les deux réserves.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Calculer la part du stock disponible pour l’atelier.
:::

::: etape Raisonner avec les données
$180\div12=15$, puis $15\times7=105$.
:::

::: resultat 
105 feuilles.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Comparer besoin et quantité réservée.
:::

::: etape Raisonner avec les données
La réserve contient 105 feuilles pour un besoin de 100. L’écart vaut $105-100=5$.
:::

::: resultat 
Oui, 5 feuilles en plus.
:::

## Question 3 : Vérifier et conclure

::: methode 
Le total de départ reste le tout ; retirer le besoin réel.
:::

::: etape Raisonner avec les données
$180-100=80$. Réserver des feuilles ne les consomme pas encore.
:::

::: resultat 
80 feuilles.
:::

## Question 4 : Chercher et justifier

::: methode 
Calculer le nouveau prélèvement et garder le même stock de départ.

:::

::: resultat 
Oui : 120 feuilles réservées, soit 15 de plus et une marge de 20.
:::

Solution:
<!-- optitab:1 -->
1. 105 feuilles.
2. Oui, 5 feuilles en plus.
3. 80 feuilles.
4. Oui : 120 feuilles réservées, soit 15 de plus et une marge de 20.
