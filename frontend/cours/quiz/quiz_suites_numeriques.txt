Titre: Quiz Suites Numériques — Niveau Simple
Instructions: Vérifiez les fondamentaux (définitions, termes, sommes de base)
Difficulté: easy
Images:

Question: On appelle suite numérique toute application
A: $\displaystyle u : \mathbb{R} \to \mathbb{R}$
B: $\displaystyle u : \mathbb{N}\ \text{(ou } \{ n \ge n_0 \} ) \to \mathbb{R}$
C: $\displaystyle u : \mathbb{Z} \to \mathbb{C}$
D: $\displaystyle u : \mathbb{N} \to \mathbb{N}$
Correct: B
Explication: $\displaystyle \text{Par définition, une suite est une fonction définie sur } \mathbb{N} \text{ (éventuellement à partir d’un rang) vers } \mathbb{R}. $

Question: Une suite est dite explicite lorsque
A: $\displaystyle u_{n+1} \ \text{ dépend de } \ u_n$
B: $\displaystyle u_n = f(n) \ \text{ sans dépendre des termes précédents}$
C: $\displaystyle u_{n+1} = a\,u_n + b$
D: $\displaystyle u_{n+1} = q\,u_n$
Correct: B
Explication: $\displaystyle \text{Explicite} \ \Leftrightarrow \ u_n = f(n). $

Question: Soit $(u_n)$ arithmétique avec $\displaystyle u_0 = 5$ et $\displaystyle r = 3$. Calculer $\displaystyle u_{10}$.
A: $\displaystyle 23$
B: $\displaystyle 32$
C: $\displaystyle 35$
D: $\displaystyle 38$
Correct: C
Explication: $\displaystyle u_{10} = u_0 + 10 r = 5 + 30 = 35. $

Question: Soit $(v_n)$ arithmétique avec $\displaystyle v_1 = -2$ et $\displaystyle r = 4$. Calculer $\displaystyle v_{15}$.
A: $\displaystyle 46$
B: $\displaystyle 50$
C: $\displaystyle 54$
D: $\displaystyle 58$
Correct: C
Explication: $\displaystyle v_0 = v_1 - r = -6, \ \ v_{15} = v_0 + 15 r = -6 + 60 = 54. $

Question: $(w_n)$ arithmétique, $\displaystyle w_0 = 12$, $\displaystyle r = -2$. La valeur de $\displaystyle w_8$ est
A: $\displaystyle -2$
B: $\displaystyle -4$
C: $\displaystyle -6$
D: $\displaystyle 0$
Correct: B
Explication: $\displaystyle w_8 = 12 + 8 (-2) = -4. $

Question: Somme arithmétique : $\displaystyle S = 1 + 2 + \cdots + 100$ vaut
A: $\displaystyle 5000$
B: $\displaystyle 5050$
C: $\displaystyle 5100$
D: $\displaystyle 5150$
Correct: B
Explication: $\displaystyle S = \frac{100 (1 + 100)}{2} = 5050. $

Question: $(g_n)$ géométrique, $\displaystyle g_0 = 2$, $\displaystyle q = 3$. Calculer $\displaystyle g_5$.
A: $\displaystyle 162$
B: $\displaystyle 216$
C: $\displaystyle 486$
D: $\displaystyle 729$
Correct: C
Explication: $\displaystyle g_5 = 2 \cdot 3^{5} = 486. $

Question: $(h_n)$ géométrique, $\displaystyle h_0 = 5$, $\displaystyle q = \tfrac{1}{2}$. Calculer $\displaystyle h_6$.
A: $\displaystyle \frac{5}{32}$
B: $\displaystyle \frac{5}{48}$
C: $\displaystyle \frac{5}{64}$
D: $\displaystyle \frac{5}{96}$
Correct: C
Explication: $\displaystyle h_6 = 5 \left( \tfrac{1}{2} \right)^{6} = \tfrac{5}{64}. $

Question: Somme géométrique avec $\displaystyle u_0 = 1$, $\displaystyle q = 2$ : $\displaystyle S_5 = u_0 + \cdots + u_5 =$
A: $\displaystyle 31$
B: $\displaystyle 63$
C: $\displaystyle 64$
D: $\displaystyle 127$
Correct: B
Explication: $\displaystyle S_5 = \frac{1 - 2^{6}}{1 - 2} = 63. $

Question: Sens de variation de $\displaystyle t_n = \frac{1}{n+1}$ (pour $\displaystyle n \ge 0$)
A: $\displaystyle \text{Croissante}$
B: $\displaystyle \text{Décroissante}$
C: $\displaystyle \text{Constante}$
D: $\displaystyle \text{Non monotone}$
Correct: B
Explication: $\displaystyle t_{n+1} - t_n = \frac{1}{n+2} - \frac{1}{n+1} < 0. $

Titre: Quiz Suites Numériques — Niveau Moyen
Instructions: Variations, limites, récurrence simple, arithmético-géométriques
Difficulté: medium
Images:

Question: Pour étudier la variation par différences, on examine
A: $\displaystyle u_{n+1} u_n$
B: $\displaystyle u_{n+1} - u_n$
C: $\displaystyle \frac{u_{n+1}}{u_n} \ \text{uniquement}$
D: $\displaystyle u_n - n$
Correct: B
Explication: $\displaystyle \text{Le signe de } (u_{n+1} - u_n) \text{ donne la monotonie. }$

Question: Limite de $\displaystyle u_n = \frac{2n + 3}{n + 1}$ quand $\displaystyle n \to +\infty$
A: $\displaystyle 1$
B: $\displaystyle 2$
C: $\displaystyle +\infty$
D: $\displaystyle 0$
Correct: B
Explication: $\displaystyle \frac{2 + \frac{3}{n}}{1 + \frac{1}{n}} \to 2. $

Question: Limite de $\displaystyle v_n = \frac{3n^2 - 2n + 1}{n^2 + 5}$ quand $\displaystyle n \to +\infty$
A: $\displaystyle 0$
B: $\displaystyle 1$
C: $\displaystyle 2$
D: $\displaystyle 3$
Correct: D
Explication: $\displaystyle \frac{3n^2}{n^2} \to 3. $

Question: $(q_n)$ géométrique avec $\displaystyle q \in (0,1)$. Alors $\displaystyle \lim_{n \to \infty} q^n$
A: $\displaystyle 1$
B: $\displaystyle 0$
C: $\displaystyle +\infty$
D: $\displaystyle \text{N’existe pas}$
Correct: B
Explication: $\displaystyle q^n \to 0 \ \text{si} \ 0 < q < 1. $

Question: Suite arithmético-géométrique $\displaystyle u_{n+1} = a\,u_n + b$ (avec $\displaystyle a \ne 1$). Le point fixe $\displaystyle \ell$ vérifie
A: $\displaystyle \ell = \frac{b}{1-a}$
B: $\displaystyle \ell = \frac{1-a}{b}$
C: $\displaystyle \ell = a + b$
D: $\displaystyle \ell = ab$
Correct: A
Explication: $\displaystyle \ell = a \ell + b \Rightarrow (1-a) \ell = b. $

Question: Pour $\displaystyle u_{n+1} = a\,u_n + b$ (avec $\displaystyle a \ne 1$), poser $\displaystyle v_n = u_n - \ell$ donne
A: $\displaystyle (v_n) \ \text{arithmétique de raison } a$
B: $\displaystyle (v_n) \ \text{géométrique de raison } a$
C: $\displaystyle (v_n) \ \text{constante}$
D: $\displaystyle \text{Sans structure}$
Correct: B
Explication: $\displaystyle v_{n+1} = a\,v_n. $

Question: $\displaystyle u_0 = 1$, $\displaystyle u_{n+1} = \frac{2u_n + 3}{u_n + 2}$. La limite $\displaystyle \ell$ (si elle existe) vérifie
A: $\displaystyle \ell = 1$
B: $\displaystyle \ell^2 = 3$
C: $\displaystyle \ell^2 = 2$
D: $\displaystyle \ell = 0$
Correct: B
Explication: $\displaystyle \ell = \frac{2\ell + 3}{\ell + 2} \Rightarrow \ell^2 = 3. $

Question: $(w_n)$ définie par $\displaystyle w_0 = 2$, $\displaystyle w_{n+1} = 3 w_n - 1$. Le type de la relation est
A: $\displaystyle \text{Arithmétique}$
B: $\displaystyle \text{Géométrique}$
C: $\displaystyle \text{Arithmético-géométrique}$
D: $\displaystyle \text{Explicite}$
Correct: C
Explication: $\displaystyle a w_n + b \ \text{avec} \ a = 3, \ b = -1. $

Question: $(t_n)$ arithmétique, $\displaystyle t_0 = -7$, $\displaystyle r = 4$. La somme des $\displaystyle 30$ premiers termes vaut
A: $\displaystyle 1460$
B: $\displaystyle 1500$
C: $\displaystyle 1530$
D: $\displaystyle 1560$
Correct: C
Explication: $\displaystyle t_{29} = 109, \ \ S_{29} = \frac{30 (-7 + 109)}{2} = 1530. $

Question: $(s_n)$ géométrique, $\displaystyle s_0 = 4$, $\displaystyle q = \tfrac{1}{2}$. Alors $\displaystyle S_4 = s_0 + \cdots + s_4 =$
A: $\displaystyle 2$
B: $\displaystyle \frac{31}{4}$
C: $\displaystyle 4$
D: $\displaystyle 8$
Correct: B
Explication: $\displaystyle S_4 = 4 \, \frac{1 - (1/2)^{5}}{1 - 1/2} = \frac{31}{4}. $

Titre: Quiz Suites Numériques — Niveau Difficile
Instructions: Expressions fermées, convergence, points fixes et pièges
Difficulté: hard
Images:

Question: Soit $\displaystyle u_0 = 1$, $\displaystyle u_{n+1} = 2 u_n + 3$. Une expression correcte de $\displaystyle u_n$ est
A: $\displaystyle u_n = 2^{n} + 3$
B: $\displaystyle u_n = 2^{\,n+2} - 3$
C: $\displaystyle u_n = 3 \cdot 2^{n} - 1$
D: $\displaystyle u_n = 2^{\,n+1} + 1$
Correct: B
Explication: $\displaystyle \ell = -3, \ \ u_n = \ell + (u_0 - \ell) 2^{n} = -3 + 4 \cdot 2^{n} = 2^{\,n+2} - 3. $

Question: Soit $\displaystyle v_0 = 5$, $\displaystyle v_{n+1} = \tfrac{1}{2} \, v_n + 2$. Alors $\displaystyle v_n$
A: $\displaystyle 2 + \left( \tfrac{1}{2} \right)^{n}$
B: $\displaystyle 4 + \left( \tfrac{1}{2} \right)^{n}$
C: $\displaystyle 4 - \left( \tfrac{1}{2} \right)^{n}$
D: $\displaystyle 2 \cdot \left( \tfrac{1}{2} \right)^{n}$
Correct: B
Explication: $\displaystyle \ell = 4, \ \ v_n = 4 + \left( \tfrac{1}{2} \right)^{n}. $

Question: $\displaystyle w_0 = 0$, $\displaystyle w_{n+1} = 3 w_n - 6$. Alors $\displaystyle \lim_{n \to \infty} w_n$
A: $\displaystyle 0$
B: $\displaystyle 3$
C: $\displaystyle +\infty$
D: $\displaystyle -\infty$
Correct: D
Explication: $\displaystyle w_n = 3 - 3^{\,n+1} \to -\infty. $

Question: $\displaystyle t_{n+1} = \frac{t_n + 6}{t_n + 2}$, $\displaystyle t_0 = 2$. Alors $\displaystyle (t_n)$ est
A: $\displaystyle \text{Strictement croissante vers } 2$
B: $\displaystyle \text{Constante égale à } 2$
C: $\displaystyle \text{Strictement décroissante vers } 0$
D: $\displaystyle \text{Divergente}$
Correct: B
Explication: $\displaystyle t_1 = \frac{2 + 6}{2 + 2} = 2, \ \text{donc } t_n \equiv 2. $

Question: Soit $\displaystyle u_0 = 1$, $\displaystyle u_{n+1} = \frac{2 u_n + 3}{u_n + 2}$. Pour $\displaystyle u_n > 0$, le signe de $\displaystyle u_{n+1} - u_n$ est celui de
A: $\displaystyle u_n - 3$
B: $\displaystyle 3 - u_n^{2}$
C: $\displaystyle u_n^{2} - 3$
D: $\displaystyle 2 - u_n$
Correct: B
Explication: $\displaystyle u_{n+1} - u_n = \frac{3 - u_n^{2}}{u_n + 2}. $

Question: On considère $\displaystyle a \in (-1,1) \setminus \{ 0 \}$ et $\displaystyle u_{n+1} = a \, u_n + b$. Alors
A: $\displaystyle (u_n) \ \text{diverge toujours}$
B: $\displaystyle (u_n) \ \text{converge vers } 0$
C: $\displaystyle (u_n) \ \text{converge vers } \frac{b}{1-a}$
D: $\displaystyle (u_n) \ \text{est périodique}$
Correct: C
Explication: $\displaystyle |a| < 1 \Rightarrow u_n \to \ell = \frac{b}{1-a}. $

Question: $(x_n)$ géométrique avec $\displaystyle x_0 < 0$, $\displaystyle q > 1$. Alors
A: $\displaystyle \text{Croissante vers } 0$
B: $\displaystyle \text{Alterne de signe}$
C: $\displaystyle \text{Reste négative et } |x_n| \to +\infty$
D: $\displaystyle \text{Tend vers } 0$
Correct: C
Explication: $\displaystyle x_n = x_0 \, q^{n} < 0 \ \text{et} \ |x_n| \to +\infty. $

Question: $(s_n)$ arithmético-géométrique $\displaystyle s_{n+1} = 0{,}8 \, s_n + 4$, $\displaystyle s_0 = 10$. Alors $\displaystyle \lim_{n \to \infty} s_n$
A: $\displaystyle 0$
B: $\displaystyle +\infty$
C: $\displaystyle -\infty$
D: $\displaystyle 20$
Correct: D
Explication: $\displaystyle \ell = \frac{4}{1 - 0{,}8} = 20, \ \ |0{,}8| < 1. $

Question: Soit $\displaystyle u_n = \frac{n - 5}{2 n^2 + 3}$. Alors $\displaystyle \lim_{n \to \infty} u_n$ et le bon raisonnement sont
A: $\displaystyle +\infty, \ \text{car numérateur } \sim n$
B: $\displaystyle 0, \ \text{car le dénominateur d’ordre } n^2 \text{ domine}$
C: $\displaystyle \frac{1}{2}, \ \text{par comparaison des premiers termes}$
D: $\displaystyle \text{N’existe pas, car } u_n \text{ change de signe}$
Correct: B
Explication: $\displaystyle u_n \sim \frac{n}{2 n^2} = \frac{1}{2 n} \to 0. $

Question: Piège — Somme géométrique : pour $\displaystyle q = 1$, on a
A: $\displaystyle S_n = u_0 \, \frac{1 - 1^{\,n+1}}{1 - 1}$
B: $\displaystyle S_n = (n + 1) \, u_0$
C: $\displaystyle S_n = \frac{u_0 + u_n}{2}$
D: $\displaystyle S_n = 0$
Correct: B
Explication: $\displaystyle \text{La formule fractionnaire ne s’applique pas à } q = 1 ; \ \ S_n = (n + 1) u_0. $
