                            <td style="border:1px solid #ddd; padding:10px; text-align:left;">Légumes</td>

                <li style="margin:0 0 12px 0; text-align:left;"><strong>Fruits :</strong> 5 garçons, donc 10 - 5 = <strong>5 filles</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pâtes :</strong> 2 garçons, donc 2 - 2 = <strong>0 filles</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérification garçons :</strong> 3 + 5 + 2 = 10 ✓</li>
                <li style="margin:0; text-align:left;"><strong>Vérification filles :</strong> 5 + 5 + 0 = 10 ✓</li>

                <li style="margin:0 0 12px 0; text-align:left;">Si on connaît le total et une partie, on fait : <strong>Total - Partie connue = Partie à trouver</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour vérifier, on additionne les lignes et les colonnes pour voir si les totaux correspondent</li>
                <li style="margin:0; text-align:left;">Les totaux en ligne et en colonne doivent être cohérents avec les données</li>
            </ul>

            <strong>💡 Comment lire un tableau à double entrée :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire les en-têtes de lignes et colonnes</strong> : comprendre les deux caractéristiques</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Repérer l'intersection</strong> : trouver où se croisent la ligne et la colonne qui t'intéressent</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire la valeur</strong> : c'est la donnée à l'intersection</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier les totaux</strong> : s'assurer que les lignes et colonnes "Total" sont correctes</li>
            </ol>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les diagrammes en bâtons</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et lecture</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Qu'est-ce qu'un diagramme en bâtons ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>diagramme en bâtons</strong> (ou <strong>diagramme en barres</strong>) représente des données sous forme de <strong>barres</strong> verticales ou horizontales.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>hauteur</strong> (ou la longueur) de chaque barre est <strong>proportionnelle</strong> à la valeur qu'elle représente.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est une façon visuelle de comparer des données.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Lecture d'un diagramme en bâtons (vertical)</strong>

                        <span style="font-size:0.85em; color:#666; margin-top:2px;">12</span>

                        <div style="background:#3498db; width:40px; height:70px; margin-bottom:5px; border-radius:4px 4px 0 0;"></div>
                        <span style="font-size:0.9em; font-weight:700;">Danse</span>
                        <span style="font-size:0.85em; color:#666; margin-top:2px;">7</span>
                    </div>
                </div>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Questions :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Quelle activité a le plus de participants ? <strong>Football (barre la plus haute : 12)</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Quelle activité a le moins de participants ? <strong>Natation (barre la plus basse : 5)</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Combien d'élèves de plus font du football que de la danse ? <strong>12 - 7 = 5 élèves</strong></li>
                <li style="margin:0; text-align:left;">Combien d'élèves font du sport au total ? <strong>12 + 8 + 5 + 7 = 32 élèves</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Comment construire un diagramme en bâtons</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Données :</strong> Dans une classe, 15 élèves préfèrent les maths, 10 préfèrent le français, 8 préfèrent l'histoire, et 5 préfèrent les sciences.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode pour construire un diagramme en bâtons :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Tracer deux axes</strong> : un axe horizontal (abscisse) et un axe vertical (ordonnée)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Graduer l'axe vertical</strong> : de 0 jusqu'à la valeur maximale (ici 0 à 20, par exemple)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Placer les catégories</strong> sur l'axe horizontal : Maths, Français, Histoire, Sciences</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Tracer une barre</strong> pour chaque catégorie : la hauteur correspond au nombre d'élèves</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ajouter un titre</strong> et <strong>légender</strong> les axes</li>
                <li style="margin:0; text-align:left;"><strong>Écrire les valeurs</strong> au-dessus ou à côté de chaque barre</li>
            </ol>

            <div style="background:#f0f0f0; padding:20px; border-radius:6px; margin:15px 0; border:2px solid #3498db;">
                <p style="margin:8px 0; text-align:center; font-weight:700; color:#2c3e50;">Préférences des élèves par matière</p>

                        <span style="font-size:0.9em; font-weight:700;">Maths</span>

                    <div style="display:flex; flex-direction:column; align-items:center; flex:1;">
                        <span style="font-size:0.85em; color:#666; margin-bottom:4px;">10</span>
                        <div style="background:#3498db; width:40px; height:100px; margin-bottom:5px; border-radius:4px 4px 0 0;"></div>
                        <span style="font-size:0.9em; font-weight:700;">Français</span>
                    </div>

                        <span style="font-size:0.85em; color:#666; margin-bottom:4px;">8</span>

                        <span style="font-size:0.9em; font-weight:700;">Histoire</span>

                        <span style="font-size:0.85em; color:#666; margin-bottom:4px;">5</span>

                        <span style="font-size:0.9em; font-weight:700;">Sciences</span>

        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conseils pour construire un diagramme en bâtons :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Choisir une <strong>échelle adaptée</strong> : si la valeur maximale est 15, graduer jusqu'à 20 pour avoir de la marge</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Toutes les barres doivent avoir la même largeur</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Respecter les proportions</strong> : une valeur deux fois plus grande doit avoir une barre deux fois plus haute</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Espacer les barres</strong> régulièrement pour une meilleure lisibilité</li>
                <li style="margin:0; text-align:left;"><strong>Colorier</strong> les barres pour les rendre plus visibles (et utiliser la même couleur ou des couleurs différentes selon le contexte)</li>
            </ul>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les diagrammes circulaires (très simples)</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et lecture</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Qu'est-ce qu'un diagramme circulaire ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>diagramme circulaire</strong> (ou <strong>camembert</strong>) représente des données sous forme de <strong>parts d'un cercle</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Chaque <strong>part</strong> (secteur) correspond à une catégorie, et la <strong>taille de la part</strong> est proportionnelle à la valeur qu'elle représente.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est utile pour voir la <strong>répartition</strong> d'un tout.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Lecture d'un diagramme circulaire</strong>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les graphiques cartésiens (graphiques dans un repère)</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Représenter des données dans un repère</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Qu'est-ce qu'un graphique cartésien ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">
                Un <strong>graphique cartésien</strong> représente des données à l'aide de <strong>points placés dans un repère</strong> :
            </p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">un <strong>axe horizontal</strong> (axe des abscisses) pour la première grandeur (par exemple : le temps, les jours, les classes…)</li>
                <li style="margin:0 0 12px 0; text-align:left;">un <strong>axe vertical</strong> (axe des ordonnées) pour la deuxième grandeur (par exemple : une distance, une température, un nombre d'élèves…)</li>
                <li style="margin:0; text-align:left;">chaque point représente une <strong>valeur</strong> des deux grandeurs en même temps.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Température en fonction du jour</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">
                On a mesuré la température chaque jour à 14h :
            </p>
            <div style="margin:12px 0; overflow-x:auto;">
                <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
                    <thead>
                        <tr style="background:#3498db; color:white;">
                            <th style="border:1px solid #ddd; padding:12px; text-align:left; font-weight:700;">Jour</th>
                            <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Lundi</th>
                            <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Mardi</th>
                            <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Mercredi</th>
                            <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Jeudi</th>
                            <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Vendredi</th>
                        </tr>
                    </thead>
                    <tbody>
                        <tr style="background:#f8f9fa;">
                            <td style="border:1px solid #ddd; padding:10px; text-align:left;">Température (°C)</td>
                            <td style="border:1px solid #ddd; padding:10px; text-align:center;">18</td>
                            <td style="border:1px solid #ddd; padding:10px; text-align:center;">20</td>
                            <td style="border:1px solid #ddd; padding:10px; text-align:center;">22</td>
                            <td style="border:1px solid #ddd; padding:10px; text-align:center;">19</td>
                            <td style="border:1px solid #ddd; padding:10px; text-align:center;">21</td>
                        </tr>
                    </tbody>
                </table>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Construction du graphique :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Tracer deux axes perpendiculaires (horizontal et vertical).</li>
                <li style="margin:0 0 12px 0; text-align:left;">Sur l'<strong>axe horizontal</strong>, placer les jours : Lundi, Mardi, Mercredi, Jeudi, Vendredi.</li>
                <li style="margin:0 0 12px 0; text-align:left;">Sur l'<strong>axe vertical</strong>, graduer les températures (par exemple de 16°C à 24°C).</li>
                <li style="margin:0 0 12px 0; text-align:left;">Placer un point pour chaque jour : 
                    par exemple, pour le mardi, placer un point à la hauteur de 20°C au-dessus de \"Mardi\".</li>
                <li style="margin:0; text-align:left;">Relier éventuellement les points dans l'ordre des jours pour voir l'<strong>évolution</strong> de la température.</li>
            </ol>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Comment lire un graphique cartésien :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Lire d'abord le <strong>titre</strong> et ce que représentent les <strong>axes</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour un point donné, regarder sa position : 
                    <br>→ sur l'axe horizontal : la première grandeur (ici, le jour),
                    <br>→ sur l'axe vertical : la valeur associée (ici, la température).</li>
                <li style="margin:0; text-align:left;">Observer la forme globale de la courbe pour décrire une évolution : 
                    <br>par exemple, \"La température augmente du lundi au mercredi puis diminue légèrement le jeudi\".</li>
            </ul>
        </div>
    </div>

            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Données :</strong> Dans un collège, il y a 120 élèves en 6ème, 100 élèves en 5ème, 95 élèves en 4ème, et 90 élèves en 3ème.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Consigne :</strong> Construis un diagramme en bâtons représentant ces données.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Tracer deux axes perpendiculaires</li>
                <li style="margin:0 0 12px 0; text-align:left;">Graduer l'axe vertical de 0 à 130 (pour avoir de la marge)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Placer sur l'axe horizontal : 6ème, 5ème, 4ème, 3ème</li>
                <li style="margin:0 0 12px 0; text-align:left;">Tracer une barre pour chaque niveau : hauteur = nombre d'élèves</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ajouter un titre : "Nombre d'élèves par niveau"</li>
                <li style="margin:0; text-align:left;">Écrire les valeurs : 120, 100, 95, 90</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour lire un tableau :</strong> toujours commencer par lire les en-têtes pour comprendre ce que représentent les colonnes et lignes</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour un tableau à double entrée :</strong> vérifier que les totaux en lignes et colonnes sont cohérents</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour lire un diagramme en bâtons :</strong> observer la hauteur des barres et lire les valeurs exactes si elles sont indiquées</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour construire un diagramme :</strong> choisir une échelle adaptée (pas trop grande, pas trop petite)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Respecter les proportions :</strong> si une valeur est deux fois plus grande, sa représentation doit être deux fois plus grande</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Toujours ajouter un titre</strong> et légender les axes pour que le graphique soit compréhensible</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérifier ses calculs :</strong> s'assurer que les totaux sont corrects quand on complète un tableau</li>
                <li style="margin:0; text-align:left;"><strong>Utiliser des couleurs différentes</strong> pour les diagrammes pour améliorer la lisibilité</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas lire les en-têtes</strong> : lire directement les nombres sans comprendre ce qu'ils représentent</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Erreurs de calcul dans les totaux</strong> : oublier d'additionner ou faire des erreurs de calcul</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Échelle inadaptée</strong> : choisir une graduation trop petite ou trop grande, ce qui rend le graphique illisible</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas respecter les proportions</strong> : faire des barres de hauteurs approximatives au lieu de mesurer précisément</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier le titre ou les légendes</strong> : créer un graphique sans titre ni légende, rendant impossible son interprétation</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Barres de largeurs différentes</strong> : toutes les barres d'un diagramme doivent avoir la même largeur</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondre les axes</strong> : mettre les catégories sur le mauvais axe (horizontal/vertical)</li>
                <li style="margin:0; text-align:left;"><strong>Ne pas vérifier la cohérence</strong> : ne pas vérifier que les totaux correspondent entre les lignes et colonnes</li>
            </ul>
        </div>
    </div>
