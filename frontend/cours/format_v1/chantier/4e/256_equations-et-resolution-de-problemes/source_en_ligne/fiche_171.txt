Titre: Résumé : Équations et résolution de problèmes

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : tester une solution, résoudre une équation du premier degré, mettre un problème en équation. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Résoudre</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• Même opération dans les <strong>deux membres</strong> : $+$, $-$, $\times$ ou $:$ par un nombre non nul.</p>
<p style="margin:6px 0 0 0;">• $5x - 3 = 2x + 9$ → $3x - 3 = 9$ → $3x = 12$ → $x = 4$.</p>
<p style="margin:6px 0 0 0;">• Parenthèses : on développe d'abord. Fractions : on multiplie par un dénominateur commun.</p>
<p style="margin:6px 0 0 0;">• $1 = 3$ à la fin : aucune solution ; $2 = 2$ : tous les nombres sont solutions.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Mettre en équation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">• Choisir l'inconnue, traduire l'énoncé, résoudre, <strong>vérifier dans l'énoncé</strong>, conclure par une phrase.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Ne modifier qu'un seul membre de l'équation.</p>
<p style="margin:6px 0 0 0;">2️⃣ Changer de membre sans changer de signe : $3x - 7 = 5$ donne $3x = 12$, pas $3x = -2$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Diviser par le coefficient en oubliant son signe : $-2x = 8$ donne $x = -4$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de vérifier, ou répondre sans phrase ni unité.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> une solution trouvée se vérifie TOUJOURS en la remplaçant dans l'équation de départ : les deux membres doivent être égaux.</p>
</div>
