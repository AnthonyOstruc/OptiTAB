<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les bases</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">Équiprobabilité : $\displaystyle P(A) = \frac{\text{issues favorables}}{\text{issues totales}}$</p>
<p style="margin:6px 0 0 0; font-weight:bold;">$\displaystyle 0 \leq P(A) \leq 1$ &nbsp;&nbsp; $\displaystyle P(\text{non } A) = 1 - P(A)$</p>
</div>
<p style="margin:0;">• Impossible : 0 ; certain : 1. Justifier l'équiprobabilité (dé équilibré, boules indiscernables…).</p>
<p style="margin:6px 0 0 0;">• Compter les <strong>objets</strong> (boules, cartes), pas les catégories (couleurs).</p>
<p style="margin:6px 0 0 0;">• « Au moins un » → passer par le contraire « aucun ».</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Deux étapes : arbres et tableaux</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• Arbre pondéré : <strong>multiplier</strong> le long d'un chemin ; <strong>additionner</strong> les chemins favorables.</p>
<p style="margin:6px 0 0 0;">• Tableau à double entrée : deux dés → 36 couples équiprobables ($P(\text{somme } 7) = \frac{6}{36}$) ; les SOMMES ne sont pas équiprobables.</p>
<p style="margin:6px 0 0 0;">• 3 R + 2 B : avec remise $\displaystyle P(RR) = \frac{3}{5} \times \frac{3}{5} = \frac{9}{25}$ ; sans remise $\displaystyle \frac{3}{5} \times \frac{2}{4} = \frac{3}{10}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fréquences</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">Fréquence observée = succès ÷ essais. Sur un <strong>grand</strong> nombre d'essais, elle se stabilise près de la probabilité — sans jamais prédire le prochain résultat.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Croire que des catégories d'effectifs différents sont équiprobables.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier d'actualiser la composition dans un tirage sans remise.</p>
<p style="margin:6px 0 0 0;">3️⃣ Additionner des probabilités d'événements compatibles (double comptage).</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre fréquence observée et probabilité, ou croire que le hasard « a de la mémoire ».</p>
</div>
