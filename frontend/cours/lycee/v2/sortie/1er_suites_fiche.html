📚 Objectif pédagogique : retenir l’essentiel : modes de génération, variations, suites arithmétiques et géométriques, sommes. Programme de Première.

I. Arithmétique ou géométrique ?

[IMAGE_1]

1️⃣ Arithmétique : $\displaystyle u_{n+1} = u_n + r$, $\displaystyle u_n = u_0 + nr = u_p + (n - p)r$.

2️⃣ Géométrique : $\displaystyle u_{n+1} = q u_n$, $\displaystyle u_n = u_0 q^n$.

3️⃣ Variations : signe de $\displaystyle u_{n+1} - u_n$ (ou de $\displaystyle r$ ; ou position de $\displaystyle q$ par rapport à $\displaystyle 1$ si $\displaystyle u_0 \gt 0$).

II. Sommes

$\displaystyle 1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$

[IMAGE_2]

• Pour $\displaystyle q \neq 1$ : $\displaystyle 1 + q + \cdots + q^n = \frac{1 - q^{n+1}}{1 - q}$.

• Hausse de $\displaystyle t\,\%$ chaque année → suite géométrique de raison $\displaystyle 1 + \frac{t}{100}$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Confondre $\displaystyle u_{n+1}$ (terme suivant) et $\displaystyle u_n + 1$.

2️⃣ Écrire $\displaystyle u_n = u_1 + nr$ quand la suite commence à $\displaystyle u_1$ : c’est $\displaystyle u_n = u_1 + (n - 1)r$.

3️⃣ Mal compter les termes d’une somme : de $\displaystyle q^0$ à $\displaystyle q^n$, il y en a $\displaystyle n + 1$.

4️⃣ Prendre $\displaystyle q = 0{,}03$ pour une hausse de $\displaystyle 3\,\%$ au lieu de $\displaystyle q = 1{,}03$.

🏆 Réflexe : je calcule $\displaystyle u_{n+1} - u_n$ et $\displaystyle \frac{u_{n+1}}{u_n}$ : différence constante → arithmétique, quotient constant → géométrique.
