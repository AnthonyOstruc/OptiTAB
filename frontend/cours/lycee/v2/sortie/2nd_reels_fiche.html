📚 Objectif pédagogique : retenir l’essentiel : les ensembles de nombres, les intervalles, la valeur absolue et l’encadrement. Programme de Seconde.

I. Les ensembles de nombres

$\displaystyle \mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$

[IMAGE_1]

• Décimal : $\displaystyle \frac{k}{10^n}$, écriture finie ; rationnel : $\displaystyle \frac{p}{q}$, écriture finie ou périodique.

• Irrationnel : ni fraction, ni écriture périodique ($\displaystyle \sqrt{2}$, $\displaystyle \pi$).

II. Intervalles et distances

[IMAGE_2]

1️⃣ $\displaystyle x \in [a\,;b] \iff a \le x \le b$ ; $\displaystyle x \in [a\,;+\infty[ \iff x \ge a$.

2️⃣ $\displaystyle |x|$ = distance de $\displaystyle x$ à $\displaystyle 0$ ; distance entre $\displaystyle a$ et $\displaystyle b$ : $\displaystyle |b - a|$.

3️⃣ $\displaystyle |x - a| \le r \iff x \in [a - r\,;a + r]$ : $\displaystyle |x - 3| \le 2 \iff x \in [1\,;5]$.

4️⃣ Encadrement à $\displaystyle 10^{-n}$ près : $\displaystyle a \le x \le b$ avec $\displaystyle b - a = 10^{-n}$, comme $\displaystyle 1{,}41 \le \sqrt{2} \le 1{,}42$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Fermer le crochet du côté de l’infini : on écrit $\displaystyle [2\,;+\infty[$.

2️⃣ Oublier qu’un crochet ouvert exclut la borne : $\displaystyle 5 \notin [2\,;5[$.

3️⃣ Écrire une valeur absolue négative : $\displaystyle |-7| = 7$.

4️⃣ Croire qu’un nombre est irrationnel parce que la calculatrice affiche beaucoup de décimales : $\displaystyle \frac{1}{7}$ est rationnel.

🏆 Réflexe : une inégalité → je la dessine sur la droite graduée puis je l’écris en intervalle ; « $\displaystyle |x - a| \le r$ » → je lis « $\displaystyle x$ est à une distance au plus $\displaystyle r$ de $\displaystyle a$ ».
