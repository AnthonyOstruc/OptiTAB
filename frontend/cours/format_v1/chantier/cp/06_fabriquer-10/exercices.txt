2. Complète : $9+\ldots=10$.
3. Complète : $10=\ldots+0$.

## Question 1 : Combien faut-il ajouter pour remplir la boîte ?

::: methode
Manipuler et calculer dans l’ordre.
:::

::: etape Raisonner

[IMAGE_2]
:::

::: etape Vérifier
Je vérifie les calculs : $7+3=10$.
:::

::: resultat
3 jetons : 7 + 3 = 10.
:::

## Question 2 : Complète : $9+\ldots=10$.

::: methode
Compter les places qui manquent.
:::

::: etape Raisonner

:::

::: resultat

:::

## Question 3 : Complète : $10=\ldots+0$.

::: methode

:::

::: etape Raisonner

:::

::: resultat

:::

:::
