## RÈGLES DE FORMATAGE

### 📝 TAILLE DE POLICE
- **Titres et sous-titres** : Taille par défaut (h2, h3, etc.)
- **Tous les autres textes** : `font-size:1em` (paragraphes, listes, tableaux, etc.)

### 🧮 FORMULES MATHÉMATIQUES
- **Dans les exemples/exercices** : `$\displaystyle...$` avec `text-align:left` et `font-size:1em`
- **Dans les définitions (fond bleu)** : `$\displaystyle...$` avec `text-align:center` et `font-size:1em`
- **Toujours utiliser** : `\displaystyle` pour des formules plus grandes et lisibles
- **Format uniforme** : Toutes les formules utilisent le délimiteur `$` simple (pas `$$`)
- **Règle importante** : Les définitions principales (fond bleu #e8f4fd) doivent TOUJOURS être centrées

## CONSEILS D'UTILISATION

1. **Cohérence** : Maintenir cette palette dans tous les chapitres
2. **Hiérarchie** : Bleu pour les concepts fondamentaux, orange pour les méthodes, gris pour les exemples
3. **Contraste** : Assurer une bonne lisibilité avec du texte foncé sur fonds pâles
4. **Formatage** : Respecter `font-size:1em` pour tous les textes sauf titres/sous-titres
5. **Formules** : Utiliser `\displaystyle` pour toutes les formules mathématiques
6. **Évolution** : Adapter si nécessaire pour de nouveaux types de contenu
