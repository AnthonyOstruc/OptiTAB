    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Variable aléatoire et loi</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> une <strong>variable aléatoire</strong> $X$ associe un nombre réel à chaque issue d’une expérience aléatoire. L’événement « $X$ prend la valeur $a$ » est noté $\{X = a\}$.</p>
            <p style="margin:6px 0 0 0;">La <strong>loi de probabilité</strong> de $X$ donne, pour chaque valeur $x_i$ prise par $X$, la probabilité $p_i = P(X = x_i)$ ; on a $p_1 + p_2 + \cdots + p_n = 1$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> on lance un dé équilibré. On gagne $5$ € si l’on obtient $6$, $1$ € pour $2$ ou $4$, et on perd $2$ € sinon. Le gain $X$ suit la loi :</p>
        <table style="border-collapse:collapse; margin:12px auto; text-align:center;">
            <tr><th style="border:1px solid #bdc3c7; padding:6px 14px; background:#e8f4fd;">$x_i$</th><td style="border:1px solid #bdc3c7; padding:6px 14px;">$-2$</td><td style="border:1px solid #bdc3c7; padding:6px 14px;">$1$</td><td style="border:1px solid #bdc3c7; padding:6px 14px;">$5$</td></tr>
            <tr><th style="border:1px solid #bdc3c7; padding:6px 14px; background:#e8f4fd;">$P(X = x_i)$</th><td style="border:1px solid #bdc3c7; padding:6px 14px;">$\frac{3}{6} = \frac{1}{2}$</td><td style="border:1px solid #bdc3c7; padding:6px 14px;">$\frac{2}{6} = \frac{1}{3}$</td><td style="border:1px solid #bdc3c7; padding:6px 14px;">$\frac{1}{6}$</td></tr>
        </table>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Espérance, variance, écart type</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définitions :</strong></p>
            <p style="margin:6px 0 0 0;">• <strong>Espérance</strong> : $E(X) = p_1x_1 + p_2x_2 + \cdots + p_nx_n$ (valeur moyenne de $X$).</p>
            <p style="margin:6px 0 0 0;">• <strong>Variance</strong> : $V(X) = p_1(x_1 - E(X))^2 + \cdots + p_n(x_n - E(X))^2$, qui vaut aussi $E(X^2) - E(X)^2$.</p>
            <p style="margin:6px 0 0 0;">• <strong>Écart type</strong> : $\sigma(X) = \sqrt{V(X)}$ (dispersion des valeurs autour de $E(X)$).</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $E(X) = \frac{1}{2} \times (-2) + \frac{1}{3} \times 1 + \frac{1}{6} \times 5 = \frac{-6 + 2 + 5}{6} = \frac{1}{6} \approx 0{,}17$ €. Ensuite $E(X^2) = \frac{1}{2} \times 4 + \frac{1}{3} \times 1 + \frac{1}{6} \times 25 = 6{,}5$, donc $V(X) = 6{,}5 - \frac{1}{36} = \frac{233}{36} \approx 6{,}47$ et $\sigma(X) \approx 2{,}54$ €.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation :</strong> sur un grand nombre de parties, le joueur gagne en moyenne environ $0{,}17$ € par partie. Un jeu est <strong>équitable</strong> si $E(X) = 0$, favorable au joueur si $E(X) \gt 0$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Transformation affine</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriétés :</strong> pour tous réels $a$ et $b$, $E(aX + b) = aE(X) + b$, $V(aX + b) = a^2V(X)$ et $\sigma(aX + b) = |a|\,\sigma(X)$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve pour l’espérance :</em> $\sum p_i(ax_i + b) = a\sum p_ix_i + b\sum p_i = aE(X) + b$, puisque $\sum p_i = 1$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> si tous les gains sont doublés puis augmentés d’un bonus de $1$ €, le nouveau gain est $Y = 2X + 1$ : $E(Y) = \frac{2}{6} + 1 = \frac{4}{3}$ et $\sigma(Y) = 2\sigma(X) \approx 5{,}09$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> la constante $b$ ne change pas la dispersion : $V(X + b) = V(X)$. Et le coefficient $a$ est <strong>au carré</strong> dans la variance.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Simulation</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">from random import randint

def gain():
    d = randint(1, 6)
    if d == 6:
        return 5
    elif d % 2 == 0:
        return 1
    else:
        return -2

def moyenne(n):
    s = 0
    for i in range(n):
        s = s + gain()
    return s / n</div>
