=== Équations Différentielles - Programme Bac France Terminal
Difficulté: medium
Ordre: 8

Titre: Équations Différentielles : Résolution et Modélisation
Description: Cours sur les équations différentielles linéaires du premier ordre selon le programme du bac français : forme y' = a y + b, méthodes de résolution et applications concrètes.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce qu'une équation différentielle ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="">Une <strong>équation différentielle</strong> est une équation qui met en relation une fonction inconnue $\displaystyle y(x)$ avec sa dérivée $\displaystyle y'(x)$ :</p>
            $\displaystyle y' = f(x, y)$
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Au programme du bac :</strong> On étudie principalement les équations différentielles linéaires du premier ordre de la forme <strong>$\displaystyle y' = a y + b$</strong> où $\displaystyle a$ et $\displaystyle b$ sont des constantes.
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">$\displaystyle y' = 2y$ (croissance exponentielle)</li>
                <li style="margin:0; text-align:left;">$\displaystyle y' = -3y + 5$ (équation complète)</li>
                <li style="margin:0; text-align:left;">$\displaystyle y' = y - 2$ (décroissance avec terme constant)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Méthodes de résolution</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résolution générale de y' = a y + b</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style=""><strong>Solution générale :</strong></p>
            $\displaystyle y(x) = C e^{a x} - \dfrac{b}{a} \quad (\text{si } a \neq 0)$
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>⚡ Méthode :</strong> 1. Résoudre l'équation homogène 2. Trouver une solution particulière 3. Additionner
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> $\displaystyle y' = 2y + 4$
            <div style="margin:10px auto; text-align:left;">
                <p style="margin:8px 0;"><strong>Équation homogène :</strong> $\displaystyle y' - 2y = 0 \Rightarrow y_h = C e^{2x}$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> Constante $\displaystyle y_p = k$</p>
                <p style="margin:8px 0;">$\displaystyle 0 = 2k + 4 \Rightarrow k = -2$</p>
                <p style="margin:8px 0;"><strong>Solution générale :</strong> $\displaystyle y = C e^{2x} - 2$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> $\displaystyle y' = -y + 3$
            <div style="margin:10px auto; text-align:left;">
                <p style="margin:8px 0;"><strong>Équation homogène :</strong> $\displaystyle y' + y = 0 \Rightarrow y_h = C e^{-x}$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> Constante $\displaystyle y_p = k$</p>
                <p style="margin:8px 0;">$\displaystyle 0 = -k + 3 \Rightarrow k = 3$</p>
                <p style="margin:8px 0;"><strong>Solution générale :</strong> $\displaystyle y = C e^{-x} + 3$</p>
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conditions initiales</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="">La constante $\displaystyle C$ est déterminée par une <strong>condition initiale</strong> :</p>
            $\displaystyle y(x_0) = y_0$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle y' = 2y + 4$ avec $\displaystyle y(0) = 1$
            <div style="margin:10px auto; text-align:left;">
                <p style="margin:8px 0;">Solution générale : $\displaystyle y = C e^{2x} - 2$</p>
                <p style="margin:8px 0;">$\displaystyle y(0) = 1 \Rightarrow 1 = C - 2 \Rightarrow C = 3$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> $\displaystyle y = 3 e^{2x} - 2$</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Applications concrètes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation de la croissance</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Croissance exponentielle :</strong> $\displaystyle P' = k P$ (population, capital, réactions chimiques)
            <p style="margin:8px 0;">Solution : $\displaystyle P(t) = P_0 e^{k t}$</p>
            <p style="margin:8px 0;"><strong>Exemple :</strong> Population : $\displaystyle P' = 0,05 P$, $\displaystyle P(0) = 1000$</p>
            <div style="margin:10px auto; text-align:left;">
                $\displaystyle P(t) = 1000 e^{0,05 t}$
                $\displaystyle P(10) = 1000 e^{0,5} \approx 1649 \text{ individus}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Décroissance radioactive :</strong> $\displaystyle N' = -\lambda N$
            <p style="margin:8px 0;">Solution : $\displaystyle N(t) = N_0 e^{-\lambda t}$</p>
            <p style="margin:8px 0;"><strong>Demi-vie :</strong> $\displaystyle T_{1/2} = \dfrac{\ln 2}{\lambda}$</p>
            <p style="margin:8px 0;"><strong>Exemple :</strong> Carbone 14 : $\displaystyle \lambda = 0,00012$, $\displaystyle T_{1/2} \approx 5770$ ans</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation physique</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Refroidissement d'un corps :</strong> $\displaystyle T' = -k (T - T_a)$
            <p style="margin:8px 0;">Où $\displaystyle T_a$ est la température ambiante</p>
            <p style="margin:8px 0;">Solution : $\displaystyle T(t) = T_a + (T_0 - T_a) e^{-k t}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Circuit électrique :</strong> $\displaystyle i' + \dfrac{R}{L} i = \dfrac{E}{L}$
            <p style="margin:8px 0;">Courant : $\displaystyle i(t) = \dfrac{E}{R} (1 - e^{-\frac{R}{L} t})$</p>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Méthodes alternatives</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Séparation des variables</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="">Pour les équations de la forme $\displaystyle y' = g(x) h(y)$, on sépare les variables :</p>
            $\displaystyle\dfrac{dy}{h(y)} = g(x) \, dx$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle y' = 2 x y$
            <div style="margin:10px auto; text-align:left;">
                $\displaystyle\dfrac{dy}{y} = 2x \, dx \quad (y > 0)$
                $\displaystyle\ln y = x^2 + C$
                $\displaystyle y = e^{x^2 + C} = K e^{x^2}$
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vérification des solutions</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <p><strong>Méthode :</strong> Dériver la solution proposée et vérifier si elle satisfait l'équation différentielle</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Vérifier que $\displaystyle y = 2 e^{2x} - 2$ satisfait $\displaystyle y' = 2y + 4$
            <div style="margin:10px auto; text-align:left;">
                $\displaystyle y' = 4 e^{2x}, \quad 2y + 4 = 2(2 e^{2x} - 2) + 4 = 4 e^{2x} - 4 + 4 = 4 e^{2x}$
                <p style="margin:8px 0; color:#2e7d32;">✅ Solution correcte !</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Exercices d'application</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exercices de base</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 1 :</strong> Résoudre $\displaystyle y' = 3y - 6$ avec $\displaystyle y(0) = 4$
            <p style="margin:8px 0; color:#666;">Solution : $\displaystyle y = 2 + 2 e^{3x}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 2 :</strong> Modéliser la décroissance radioactive : $\displaystyle N' = -0,02 N$ avec $\displaystyle N(0) = 100$
            <p style="margin:8px 0; color:#666;">Solution : $\displaystyle N(t) = 100 e^{-0,02 t}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 3 :</strong> Résoudre $\displaystyle y' = -2y + 10$ avec $\displaystyle y(0) = 1$
            <p style="margin:8px 0; color:#666;">Solution : $\displaystyle y = 5 - 4 e^{-2x}$</p>
        </div>
    </div>


    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef2f2; border-radius:6px; border-left:6px solid #ef4444; padding:15px; margin:12px 0;">
            <strong>❌ Erreurs fréquentes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Oublier la constante d'intégration</li>
                <li style="margin:0; text-align:left;">Mauvais signe pour l'équation homogène</li>
                <li style="margin:0; text-align:left;">Erreur dans le calcul de la solution particulière</li>
                <li style="margin:0; text-align:left;">Oublier d'appliquer la condition initiale</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la solution obtenue</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Identifier la forme $\displaystyle y' = a y + b$ avec $\displaystyle a$ et $\displaystyle b$ constantes</li>
                <li style="margin:0; text-align:left;">Résoudre d'abord l'équation homogène $\displaystyle y' = a y$</li>
                <li style="margin:0; text-align:left;">Trouver une solution particulière constante</li>
                <li style="margin:0; text-align:left;">Appliquer la condition initiale pour trouver $\displaystyle C$</li>
                <li style="margin:0; text-align:left;">Vérifier toujours en dérivant la solution</li>
                <li style="margin:0; text-align:left;">Être attentif aux unités dans les applications</li>
            </ul>
        </div>
    </div>
