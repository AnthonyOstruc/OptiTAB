=== Équations Différentielles - Programme Bac France Terminal
Difficulté: medium
Ordre: 8

Titre: Équations Différentielles : Résolution et Modélisation
Description: Cours sur les équations différentielles linéaires du premier ordre selon le programme du bac français : forme y' = a y + b, méthodes de résolution et applications concrètes.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce qu'une équation différentielle ?</h3>

        <div style="text-align:center; font-size:1.3em; margin:15px 0; padding:12px; background:#f8f9fa; border-radius:4px;">
            <p>Une <strong>équation différentielle</strong> est une équation qui met en relation une fonction inconnue $y(x)$ avec sa dérivée $y'(x)$ :</p>
            $$y' = f(x, y)$$
        </div>

        <div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>💡 Au programme du bac :</strong> On étudie principalement les équations différentielles linéaires du premier ordre de la forme <strong>$y' = a y + b$</strong> où $a$ et $b$ sont des constantes.
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>$y' = 2y$ (croissance exponentielle)</li>
                <li>$y' = -3y + 5$ (équation complète)</li>
                <li>$y' = y - 2$ (décroissance avec terme constant)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Méthodes de résolution</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résolution générale de y' = a y + b</h3>

        <div style="text-align:center; font-size:1.3em; margin:15px 0; padding:12px; background:#f8f9fa; border-radius:4px;">
            <p><strong>Solution générale :</strong></p>
            $$y(x) = C e^{a x} - \dfrac{b}{a} \quad (\text{si } a \neq 0)$$
        </div>

        <div style="background:#fff8dc; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #ffa500;">
            <strong>⚡ Méthode :</strong> 1. Résoudre l'équation homogène 2. Trouver une solution particulière 3. Additionner
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemple 1 :</strong> $y' = 2y + 4$
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                <p style="margin:8px 0;"><strong>Équation homogène :</strong> $y' - 2y = 0 \Rightarrow y_h = C e^{2x}$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> Constante $y_p = k$</p>
                <p style="margin:8px 0;">$0 = 2k + 4 \Rightarrow k = -2$</p>
                <p style="margin:8px 0;"><strong>Solution générale :</strong> $y = C e^{2x} - 2$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemple 2 :</strong> $y' = -y + 3$
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                <p style="margin:8px 0;"><strong>Équation homogène :</strong> $y' + y = 0 \Rightarrow y_h = C e^{-x}$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> Constante $y_p = k$</p>
                <p style="margin:8px 0;">$0 = -k + 3 \Rightarrow k = 3$</p>
                <p style="margin:8px 0;"><strong>Solution générale :</strong> $y = C e^{-x} + 3$</p>
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conditions initiales</h3>

        <div style="text-align:center; font-size:1.2em; margin:15px 0; padding:12px; background:#f8f9fa; border-radius:4px;">
            <p>La constante $C$ est déterminée par une <strong>condition initiale</strong> :</p>
            $$y(x_0) = y_0$$
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemple :</strong> $y' = 2y + 4$ avec $y(0) = 1$
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                <p style="margin:8px 0;">Solution générale : $y = C e^{2x} - 2$</p>
                <p style="margin:8px 0;">$y(0) = 1 \Rightarrow 1 = C - 2 \Rightarrow C = 3$</p>
                <p style="margin:8px 0;"><strong>Solution particulière :</strong> $y = 3 e^{2x} - 2$</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Applications concrètes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation de la croissance</h3>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Croissance exponentielle :</strong> $P' = k P$ (population, capital, réactions chimiques)
            <p style="margin:8px 0;">Solution : $P(t) = P_0 e^{k t}$</p>
            <p style="margin:8px 0;"><strong>Exemple :</strong> Population : $P' = 0,05 P$, $P(0) = 1000$</p>
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                $$P(t) = 1000 e^{0,05 t}$$
                $$P(10) = 1000 e^{0,5} \approx 1649 \text{ individus}$$
            </div>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Décroissance radioactive :</strong> $N' = -\lambda N$
            <p style="margin:8px 0;">Solution : $N(t) = N_0 e^{-\lambda t}$</p>
            <p style="margin:8px 0;"><strong>Demi-vie :</strong> $T_{1/2} = \dfrac{\ln 2}{\lambda}$</p>
            <p style="margin:8px 0;"><strong>Exemple :</strong> Carbone 14 : $\lambda = 0,00012$, $T_{1/2} \approx 5770$ ans</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation physique</h3>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Refroidissement d'un corps :</strong> $T' = -k (T - T_a)$
            <p style="margin:8px 0;">Où $T_a$ est la température ambiante</p>
            <p style="margin:8px 0;">Solution : $T(t) = T_a + (T_0 - T_a) e^{-k t}$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Circuit électrique :</strong> $i' + \dfrac{R}{L} i = \dfrac{E}{L}$
            <p style="margin:8px 0;">Courant : $i(t) = \dfrac{E}{R} (1 - e^{-\frac{R}{L} t})$</p>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Méthodes alternatives</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Séparation des variables</h3>

        <div style="text-align:center; font-size:1.2em; margin:15px 0; padding:12px; background:#f8f9fa; border-radius:4px;">
            <p>Pour les équations de la forme $y' = g(x) h(y)$, on sépare les variables :</p>
            $$\dfrac{dy}{h(y)} = g(x) \, dx$$
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemple :</strong> $y' = 2 x y$
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                $$\dfrac{dy}{y} = 2x \, dx \quad (y > 0)$$
                $$\ln y = x^2 + C$$
                $$y = e^{x^2 + C} = K e^{x^2}$$
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vérification des solutions</h3>

        <div style="text-align:center; font-size:1.2em; margin:15px 0; padding:12px; background:#f8f9fa; border-radius:4px;">
            <p><strong>Méthode :</strong> Dériver la solution proposée et vérifier si elle satisfait l'équation différentielle</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exemple :</strong> Vérifier que $y = 2 e^{2x} - 2$ satisfait $y' = 2y + 4$
            <div style="margin:10px auto; max-width:fit-content; text-align:left;">
                $$y' = 4 e^{2x}, \quad 2y + 4 = 2(2 e^{2x} - 2) + 4 = 4 e^{2x} - 4 + 4 = 4 e^{2x}$$
                <p style="margin:8px 0; color:#2e7d32;">✅ Solution correcte !</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Exercices d'application</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exercices de base</h3>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exercice 1 :</strong> Résoudre $y' = 3y - 6$ avec $y(0) = 4$
            <p style="margin:8px 0; color:#666;">Solution : $y = 2 + 2 e^{3x}$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exercice 2 :</strong> Modéliser la décroissance radioactive : $N' = -0,02 N$ avec $N(0) = 100$
            <p style="margin:8px 0; color:#666;">Solution : $N(t) = 100 e^{-0,02 t}$</p>
        </div>

        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0;">
            <strong>Exercice 3 :</strong> Résoudre $y' = -2y + 10$ avec $y(0) = 1$
            <p style="margin:8px 0; color:#666;">Solution : $y = 5 - 4 e^{-2x}$</p>
        </div>
    </div>


    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fdf2f2; padding:15px; border-radius:6px; margin-bottom:15px;">
            <strong>❌ Erreurs fréquentes :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Oublier la constante d'intégration</li>
                <li>Mauvais signe pour l'équation homogène</li>
                <li>Erreur dans le calcul de la solution particulière</li>
                <li>Oublier d'appliquer la condition initiale</li>
                <li>Ne pas vérifier la solution obtenue</li>
            </ul>
        </div>

        <div style="background:#f0f9f0; padding:15px; border-radius:6px;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Identifier la forme $y' = a y + b$ avec $a$ et $b$ constantes</li>
                <li>Résoudre d'abord l'équation homogène $y' = a y$</li>
                <li>Trouver une solution particulière constante</li>
                <li>Appliquer la condition initiale pour trouver $C$</li>
                <li>Vérifier toujours en dérivant la solution</li>
                <li>Être attentif aux unités dans les applications</li>
            </ul>
        </div>
    </div>

</div>
