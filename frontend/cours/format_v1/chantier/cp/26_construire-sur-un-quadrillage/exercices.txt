Découverte - Copier un rectangle
Id: 5489
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Reproduis le rectangle sur le quadrillage vide.

[IMAGE_1]

1. Combien de carreaux mesure un grand côté ?
2. Combien mesure un petit côté ?
3. Comment commences-tu ta reproduction ?
4. Comment termines-tu le contour ?
5. Comment contrôles-tu la copie ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de carreaux mesure un grand côté ?

::: methode
Compte les espaces du modèle.
:::

::: etape Raisonner
Chaque grand côté suit quatre carreaux.
:::

::: resultat
4 carreaux.
:::

## Question 2 : Combien mesure un petit côté ?

::: methode
Compte la hauteur du modèle.
:::

::: etape Raisonner
Il faut deux carreaux.
:::

::: resultat
2 carreaux.
:::

## Question 3 : Comment commences-tu ta reproduction ?

::: methode
Place un sommet puis suis une ligne du quadrillage.
:::

::: etape Raisonner
Trace un premier côté de quatre carreaux.
:::

::: resultat
Par un côté de 4 carreaux.
:::

## Question 4 : Comment termines-tu le contour ?

::: methode
Respecte les longueurs du modèle.
:::

::: etape Raisonner
Ajoute deux côtés de deux carreaux et l’autre côté de quatre.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Un rectangle de 4 carreaux sur 2.
:::

## Question 5 : Comment contrôles-tu la copie ?

::: methode
Compare les côtés et les positions des sommets.
:::

::: etape Raisonner
Les quatre côtés doivent suivre les lignes du quadrillage.
:::

::: resultat
Deux côtés de 4, deux de 2, avec les mêmes sommets.
:::

Solution:
<!-- optitab:1 -->
1. 4 carreaux.
2. 2 carreaux.
3. Par un côté de 4 carreaux.
4. Un rectangle de 4 carreaux sur 2.
5. Deux côtés de 4, deux de 2, avec les mêmes sommets.

Découverte - Compléter un rectangle
Id: 5491
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Deux côtés sont déjà tracés : le haut mesure 4 carreaux et le côté gauche 2 carreaux. Complète le rectangle.

[IMAGE_1]

1. Quels côtés manquent ?
2. Combien de carreaux doit mesurer le côté droit ?
3. Combien de carreaux doit mesurer le bas ?
4. Ajoute les côtés manquants.
5. Comment vérifies-tu ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quels côtés manquent ?

::: methode
Compare au contour d’un rectangle fermé.
:::

::: etape Raisonner
Il manque le côté droit et le côté du bas.
:::

::: resultat
Le côté droit et le bas.
:::

## Question 2 : Combien de carreaux doit mesurer le côté droit ?

::: methode
Il doit avoir la même hauteur que le côté gauche.
:::

::: etape Raisonner
Le côté gauche mesure deux carreaux.
:::

::: resultat
2 carreaux.
:::

## Question 3 : Combien de carreaux doit mesurer le bas ?

::: methode
Il doit correspondre au côté du haut.
:::

::: etape Raisonner
Le haut mesure quatre carreaux.
:::

::: resultat
4 carreaux.
:::

## Question 4 : Ajoute les côtés manquants.

::: methode
Marque le coin manquant sur un croisement.
:::

::: etape Raisonner
Descends de deux carreaux depuis le coin droit du haut, puis relie au coin gauche du bas.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Le rectangle est fermé, de 4 carreaux sur 2.
:::

## Question 5 : Comment vérifies-tu ?

::: methode
Compare les côtés opposés.
:::

::: etape Raisonner
Les deux longueurs sont quatre et les deux hauteurs sont deux.
:::

::: resultat
Deux côtés de 4 et deux côtés de 2 carreaux.
:::

Solution:
<!-- optitab:1 -->
1. Le côté droit et le bas.
2. 2 carreaux.
3. 4 carreaux.
4. Le rectangle est fermé, de 4 carreaux sur 2.
5. Deux côtés de 4 et deux côtés de 2 carreaux.

[IMAGE_1]

2. Quelle longueur auront ces côtés ?
3. Où places-tu les deux sommets du bas ?
4. Trace les côtés manquants.
5. Pourquoi ne faut-il pas ajouter un côté de 2 carreaux ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de côtés faut-il ajouter ?

::: methode
Un carré a quatre côtés, un est déjà tracé.
:::

::: etape Raisonner
Il en manque trois.
:::

::: resultat
3 côtés.
:::

## Question 2 : Quelle longueur auront ces côtés ?

::: methode
Tous les côtés du carré sont égaux.

:::

::: resultat
3 carreaux chacun.
:::

## Question 3 : Où places-tu les deux sommets du bas ?

::: methode
Pars des extrémités du côté déjà tracé.
:::

::: etape Raisonner
Descends de trois carreaux depuis chaque extrémité.
:::

::: resultat
Trois carreaux plus bas.
:::

## Question 4 : Trace les côtés manquants.

::: methode
Suis les lignes du quadrillage et ferme la figure.
:::

::: etape Raisonner

:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat

## Question 5 : Pourquoi ne faut-il pas ajouter un côté de 2 carreaux ?

::: etape Raisonner

Solution:
<!-- optitab:1 -->
1. 3 côtés.
2. 3 carreaux chacun.
3. Trois carreaux plus bas.
4. Un carré de 3 carreaux de côté.
5. Le côté ne serait pas aussi long que les autres.

1. Comment vas-tu de A à B ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment vas-tu de A à B ?

::: methode

:::

::: etape Raisonner

:::

::: resultat
4 carreaux vers la droite.
:::

::: methode
Compte les carreaux verticalement.
:::

::: etape Raisonner

:::

::: resultat
3 carreaux vers le haut.
:::

## Question 3 : Comment places-tu B sur la copie ?

::: methode
Reproduis le premier déplacement depuis A.
:::

::: etape Raisonner
Avance de quatre carreaux à droite.
:::

::: resultat
Quatre carreaux à droite de A.
:::

## Question 4 : Comment places-tu C puis fermes-tu ?

::: methode
Reproduis la montée depuis B.
:::

::: etape Raisonner

::: etape Vérifier
[IMAGE_2]
:::

::: resultat

Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Trace un carré de 4 carreaux de côté. Ajoute un trait pour obtenir deux rectangles identiques.

[IMAGE_1]

1. Quelle longueur ont les côtés du carré ?
2. Où peux-tu placer le trait vertical de partage ?
3. Trace le carré puis ce trait.
4. Quelles sont les dimensions de chaque rectangle ?
5. Peux-tu faire un partage horizontal à la place ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle longueur ont les côtés du carré ?

::: methode
Lis la mesure demandée.
:::

::: etape Raisonner
Chaque côté mesure quatre carreaux.
:::

::: resultat
4 carreaux.
:::

## Question 2 : Où peux-tu placer le trait vertical de partage ?

::: methode
Cherche deux largeurs égales.
:::

::: etape Raisonner
$2+2=4$. Le trait passe à deux carreaux du bord gauche.
:::

::: resultat
À 2 carreaux du bord gauche.
:::

## Question 3 : Trace le carré puis ce trait.

::: methode
Suis la ligne verticale qui partage la largeur.
:::

::: etape Raisonner
Le trait relie le haut et le bas du carré.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Deux rectangles identiques.
:::

## Question 4 : Quelles sont les dimensions de chaque rectangle ?

::: methode
Compte largeur et hauteur après le partage.
:::

::: etape Raisonner
Chaque partie a deux carreaux de large et quatre de haut.
:::

::: resultat
2 carreaux sur 4 carreaux.
:::

## Question 5 : Peux-tu faire un partage horizontal à la place ?

::: methode
Le carré a aussi une hauteur de quatre carreaux.
:::

::: etape Raisonner
Un trait à deux carreaux du bas donnerait aussi deux rectangles identiques.
:::

::: resultat
Oui, à 2 carreaux du bas.
:::

Solution:
<!-- optitab:1 -->
1. 4 carreaux.

5. Oui, à 2 carreaux du bas.

5. Comment contrôles-tu l’assemblage ?

::: etape Raisonner

::: resultat

## Question 3 : Quels bords dois-tu rapprocher pour retrouver le rectangle ?

::: methode
Pense au trait de découpe.
:::

::: etape Raisonner
Les deux longs côtés obliques correspondent à la diagonale coupée.

::: resultat

::: methode
