Titre: Résumé : Équations Différentielles

<!-- optitab:1 -->
::: definition Résumé
Équations différentielles - formules essentielles.
:::

## I. Définitions

| Type | Forme |
|---|---|
| **Équation différentielle** | $\displaystyle y' = f(x, y)$ |
| **Linéaire 1er ordre** | $\displaystyle y' + p(x)y = q(x)$ |
| **Coefficients constants** | $\displaystyle y' = a y + b$ |

## II. Solutions : y' = ay + b

| Équation | Solution générale |
|---|---|
| $\displaystyle y' = ay + b$ ($\displaystyle a \neq 0$) | $\displaystyle y(x) = C e^{a x} - \dfrac{b}{a}$ |
| $\displaystyle y' = b$ ($\displaystyle a = 0$) | $\displaystyle y(x) = bx + C$ |
| Condition initiale | $\displaystyle y(x_0) = y_0$ détermine $\displaystyle C$ |

## III. Applications

| Modèle | Équation | Solution |
|---|---|---|
| **Croissance** | $\displaystyle P' = k P$ | $\displaystyle P(t) = P_0 e^{kt}$ |
| **Décroissance** | $\displaystyle N' = -\lambda N$ | $\displaystyle N(t) = N_0 e^{-\lambda t}$ |
| **Refroidissement** | $\displaystyle T' = -k(T - T_a)$ | $\displaystyle T(t) = T_a + (T_0 - T_a)e^{-kt}$ |
| **Circuit RC** | $\displaystyle \tau i' + i = \dfrac{E}{R}$ | $\displaystyle i(t) = \dfrac{E}{R}(1 - e^{-t/\tau})$ |

## IV. Second ordre : y'' + ay' + by = 0

| Discriminant $\displaystyle \Delta = a^2 - 4b$ | Solution générale |
|---|---|
| $\displaystyle \Delta > 0$ : racines $\displaystyle r_1, r_2$ | $\displaystyle y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$ |
| $\displaystyle \Delta = 0$ : racine double $\displaystyle r$ | $\displaystyle y = (C_1 + C_2 x) e^{rx}$ |
| $\displaystyle \Delta < 0$ : $\displaystyle r = \alpha \pm i\beta$ | $\displaystyle y = e^{\alpha x}(C_1 \cos(\beta x) + C_2 \sin(\beta x))$ |

## V. Formules de référence

| Équation | Solution |
|---|---|
| $\displaystyle y' = ky$ | $\displaystyle y = Ce^{kx}$ |
| $\displaystyle y' = ay + b$ | $\displaystyle y = Ce^{ax} - \dfrac{b}{a}$ |
| $\displaystyle y'' + \omega^2y = 0$ | $\displaystyle y = A\cos(\omega x) + B\sin(\omega x)$ |
| Demi-vie radioactive | $\displaystyle T_{1/2} = \dfrac{\ln 2}{\lambda}$ |
| Variables séparables | $\displaystyle y' = g(x)h(y) \Rightarrow \int \dfrac{dy}{h(y)} = \int g(x)\,dx$ |

## VI. Erreurs à éviter

|  | Erreur fréquente |
|---|---|
| **1** | Oublier la constante d'intégration $\displaystyle C$ |
| **2** | Erreur de signe dans l'équation homogène : $\displaystyle y' = ay$ donne $\displaystyle Ce^{ax}$ (pas $\displaystyle Ce^{-ax}$) |
| **3** | Mauvais calcul de la solution particulière : pour $\displaystyle y' = ay + b$, c'est $\displaystyle -\dfrac{b}{a}$ (pas $\displaystyle \dfrac{b}{a}$) |
| **4** | Oublier d'appliquer la condition initiale pour déterminer $\displaystyle C$ |
| **5** | Confondre discriminant 1er ordre ($\displaystyle b^2 - 4ac$) et 2nd ordre ($\displaystyle a^2 - 4b$) |
| **6** | Ne pas vérifier la solution en la substituant dans l'équation originale |
