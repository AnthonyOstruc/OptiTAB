## I. Le cercle complet {Lycée}

[IMAGE_1]

::: definition Cercle trigonométrique
C’est le cercle de centre $O$ et de rayon $1$, orienté dans le sens inverse des aiguilles d’une montre. Pour le point $M$ associé à l’angle $x$, **$\cos x$ est l’abscisse** et **$\sin x$ est l’ordonnée**.
:::

## II. Tableau des valeurs remarquables {Lycée}

| Angle | $\cos$ | $\sin$ | $\tan$ |
|---|---|---|---|
| $0$ ($0^\circ$) | $1$ | $0$ | $0$ |
| $\dfrac{\pi}{6}$ ($30^\circ$) | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{3}$ |
| $\dfrac{\pi}{4}$ ($45^\circ$) | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $1$ |
| $\dfrac{\pi}{3}$ ($60^\circ$) | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $\sqrt{3}$ |
| $\dfrac{\pi}{2}$ ($90^\circ$) | $0$ | $1$ | non définie |
| $\dfrac{2\pi}{3}$ ($120^\circ$) | $-\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $-\sqrt{3}$ |
| $\dfrac{3\pi}{4}$ ($135^\circ$) | $-\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $-1$ |
| $\dfrac{5\pi}{6}$ ($150^\circ$) | $-\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $-\dfrac{\sqrt{3}}{3}$ |
| $\pi$ ($180^\circ$) | $-1$ | $0$ | $0$ |
| $\dfrac{7\pi}{6}$ ($210^\circ$) | $-\dfrac{\sqrt{3}}{2}$ | $-\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{3}$ |
| $\dfrac{5\pi}{4}$ ($225^\circ$) | $-\dfrac{\sqrt{2}}{2}$ | $-\dfrac{\sqrt{2}}{2}$ | $1$ |
| $\dfrac{4\pi}{3}$ ($240^\circ$) | $-\dfrac{1}{2}$ | $-\dfrac{\sqrt{3}}{2}$ | $\sqrt{3}$ |
| $\dfrac{3\pi}{2}$ ($270^\circ$) | $0$ | $-1$ | non définie |
| $\dfrac{5\pi}{3}$ ($300^\circ$) | $\dfrac{1}{2}$ | $-\dfrac{\sqrt{3}}{2}$ | $-\sqrt{3}$ |
| $\dfrac{7\pi}{4}$ ($315^\circ$) | $\dfrac{\sqrt{2}}{2}$ | $-\dfrac{\sqrt{2}}{2}$ | $-1$ |
| $\dfrac{11\pi}{6}$ ($330^\circ$) | $\dfrac{\sqrt{3}}{2}$ | $-\dfrac{1}{2}$ | $-\dfrac{\sqrt{3}}{3}$ |

::: conseil Astuce de mémorisation
De $0$ à $\dfrac{\pi}{2}$, le sinus vaut successivement $\dfrac{\sqrt{0}}{2}$, $\dfrac{\sqrt{1}}{2}$, $\dfrac{\sqrt{2}}{2}$, $\dfrac{\sqrt{3}}{2}$ et $\dfrac{\sqrt{4}}{2}$ ; le cosinus prend les mêmes valeurs dans l’ordre inverse.
:::

## III. Signes selon le quart de cercle {Lycée}

[IMAGE_2]

| Quart de cercle | Signes |
|---|---|
| Premier : $0 < x < \dfrac{\pi}{2}$ | $\cos x > 0$ et $\sin x > 0$ |
| Deuxième : $\dfrac{\pi}{2} < x < \pi$ | $\cos x < 0$ et $\sin x > 0$ |
| Troisième : $\pi < x < \dfrac{3\pi}{2}$ | $\cos x < 0$ et $\sin x < 0$ |
| Quatrième : $\dfrac{3\pi}{2} < x < 2\pi$ | $\cos x > 0$ et $\sin x < 0$ |

## IV. Degrés et radians {Lycée}

::: formule Conversion
$$x_{\text{rad}} = x_{\text{deg}} \times \frac{\pi}{180} \qquad x_{\text{deg}} = x_{\text{rad}} \times \frac{180}{\pi}$$
:::

| Degrés | Radians |
|---|---|
| $1^\circ$ | $\dfrac{\pi}{180}$ |
| $15^\circ$ | $\dfrac{\pi}{12}$ |
| $30^\circ$ | $\dfrac{\pi}{6}$ |
| $45^\circ$ | $\dfrac{\pi}{4}$ |
| $60^\circ$ | $\dfrac{\pi}{3}$ |
| $90^\circ$ | $\dfrac{\pi}{2}$ |
| $180^\circ$ | $\pi$ |
| $270^\circ$ | $\dfrac{3\pi}{2}$ |
| $360^\circ$ | $2\pi$ |

Un radian vaut environ $57{,}3^\circ$.

## V. Mesure principale {Lycée}

::: definition Mesure principale
Un angle a une infinité de mesures, qui diffèrent d’un multiple de $2\pi$. Sa **mesure principale** est celle qui appartient à $]{-\pi}\,;\pi]$.
:::

::: exemple Mesure principale de $\dfrac{17\pi}{6}$
$\dfrac{17\pi}{6} - 2\pi = \dfrac{5\pi}{6}$, qui appartient à $]{-\pi}\,;\pi]$ : la mesure principale est $\dfrac{5\pi}{6}$.
:::

::: retenir Périodicité
$$\cos(x + 2k\pi) = \cos x \qquad \sin(x + 2k\pi) = \sin x$$
pour tout entier relatif $k$.
:::
