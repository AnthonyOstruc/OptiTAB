## Question 3 : Quel contrôle permet de distinguer le dessin d’un carré ?

::: methode
Utiliser l’équerre.
:::
::: etape Placer l’outil
Placer les côtés de l’équerre sur deux côtés consécutifs.
:::
::: etape Comparer l’ouverture
Sur cette construction, les côtés ne forment pas un angle droit.

::: resultat
L’absence d’angle droit montre que ce losange n’est pas un carré.
