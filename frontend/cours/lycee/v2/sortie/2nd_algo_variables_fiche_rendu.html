📚 Objectif pédagogique : retenir l’essentiel : variables, affectation, conditions et boucles en Python. Programme de Seconde.

I. Variables et affectation

1️⃣ Types : int, float, str, bool.

2️⃣ = affecte une valeur ; == teste une égalité.

3️⃣ // quotient entier, % reste, ** puissance.

II. Conditions et boucles

1️⃣ if … elif … else : choisir selon une condition.

2️⃣ for i in range(n) : $\displaystyle n$ répétitions, i de $\displaystyle 0$ à $\displaystyle n - 1$.

3️⃣ while condition : répéter tant que la condition est vraie.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Écrire = au lieu de == dans une condition.

2️⃣ Oublier les deux-points ou l’indentation après if, for, while.

3️⃣ Croire que range(5) va jusqu’à $\displaystyle 5$ : il s’arrête à $\displaystyle 4$.

4️⃣ Écrire une boucle while dont la condition reste toujours vraie.
