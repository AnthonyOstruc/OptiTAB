## I. Les 24 lettres {Collège}

[IMAGE_1]

| Lettres | Nom et usages en maths et en sciences |
|---|---|
| $\alpha$ $\;\mathrm{A}$ | **alpha** : angles ; coefficients ; racines d’un trinôme ; rayonnement α |
| $\beta$ $\;\mathrm{B}$ | **bêta** : angles ; racines d’un trinôme ; rayonnement β |
| $\gamma$ $\;\Gamma$ | **gamma** : angles ; rayonnement γ ; Γ : fonction gamma |
| $\delta$ $\;\Delta$ | **delta** : Δ : discriminant, variation (Δt, Δx) ; δ : petite quantité |
| $\varepsilon$ $\;\mathrm{E}$ | **epsilon** (« epsilonne ») : quantité aussi petite qu’on veut (limites) ; permittivité |
| $\zeta$ $\;\mathrm{Z}$ | **zêta** (« dzêta ») : fonction zêta de Riemann |
| $\eta$ $\;\mathrm{H}$ | **êta** : rendement ; viscosité |
| $\theta$ $\;\Theta$ | **thêta** (« têta ») : angle ; température |
| $\iota$ $\;\mathrm{I}$ | **iota** : très peu utilisée |
| $\kappa$ $\;\mathrm{K}$ | **kappa** : courbure ; conductivité thermique |
| $\lambda$ $\;\Lambda$ | **lambda** : longueur d’onde ; valeur propre ; paramètre d’une loi |
| $\mu$ $\;\mathrm{M}$ | **mu** : préfixe micro (µm) ; moyenne ; coefficient de frottement |
| $\nu$ $\;\mathrm{N}$ | **nu** : fréquence |
| $\xi$ $\;\Xi$ | **xi** (« ksi ») : variable auxiliaire |
| $o$ $\;\mathrm{O}$ | **omicron** (« omicronne ») : presque jamais utilisée (confusion avec o) |
| $\pi$ $\;\Pi$ | **pi** : π ≈ 3,14159 ; Π : produit de plusieurs termes |
| $\rho$ $\;\mathrm{P}$ | **rhô** (« rô ») : masse volumique ; coefficient de corrélation |
| $\sigma$ $\;\Sigma$ | **sigma** : σ : écart type ; Σ : somme de plusieurs termes |
| $\tau$ $\;\mathrm{T}$ | **tau** (« tô ») : constante de temps ; taux |
| $\upsilon$ $\;\Upsilon$ | **upsilon** (« upsilonne ») : très peu utilisée |
| $\varphi$ $\;\Phi$ | **phi** (« fi ») : angle, déphasage ; nombre d’or ; Φ : flux, loi normale |
| $\chi$ $\;\mathrm{X}$ | **khi** (« ki ») : loi du khi-deux (χ²) |
| $\psi$ $\;\Psi$ | **psi** : fonction d’onde (physique quantique) |
| $\omega$ $\;\Omega$ | **oméga** : ω : vitesse angulaire, pulsation ; Ω : ohm, univers des possibles |

Dans chaque case, la minuscule est écrite avant la majuscule. Plusieurs majuscules ($\mathrm{A}$, $\mathrm{B}$, $\mathrm{E}$, $\mathrm{H}$, $\mathrm{P}$, $\mathrm{X}$…) ont la même forme qu’une lettre latine.

## II. Les plus utilisées selon le niveau {Collège}

| Niveau | Lettres et sens |
|---|---|
| Collège | $\pi$ : périmètre et aire du disque ; $\alpha$, $\beta$ : angles |
| Lycée | $\Delta$ : discriminant ; $\Sigma$ : somme ; $\theta$ : angle ; $\mu$ et $\sigma$ : moyenne et écart type ; $\lambda$ : paramètre d’une loi |
| Supérieur | $\varepsilon$ et $\delta$ : petites quantités ; $\lambda$ : valeur propre ; $\chi^2$ : test du khi-deux ; $\Gamma$ : fonction gamma |
| Physique | $\lambda$ : longueur d’onde ; $\rho$ : masse volumique ; $\omega$ : pulsation ; $\Omega$ : ohm ; $\Delta$ : variation |

## III. Lettres à ne pas confondre {Collège}

| Lettre grecque | À ne pas confondre avec |
|---|---|
| $\nu$ (nu) | la lettre latine $v$ |
| $\rho$ (rhô) | la lettre latine $p$ |
| $\omega$ (oméga) | la lettre latine $w$ |
| $\eta$ (êta) | la lettre latine $n$ |
| $\chi$ (khi) | la lettre latine $x$ |
| $\kappa$ (kappa) | la lettre latine $k$ |
| $\upsilon$ (upsilon) | la lettre latine $u$ |
| $\iota$ (iota) | la lettre latine $i$ |

::: retenir Variantes d’écriture
Certaines lettres ont deux formes, qui désignent la même lettre : $\varepsilon$ et $\epsilon$, $\theta$ et $\vartheta$, $\varphi$ et $\phi$, $\rho$ et $\varrho$. Le sigma final, en fin de mot grec, s’écrit ς.
:::

## IV. Écrire les lettres grecques en LaTeX {Supérieur}

On tape le nom de la lettre précédé d’une barre oblique inverse : `\alpha` donne $\alpha$, `\pi` donne $\pi$. Pour la majuscule, le nom commence par une capitale : `\Delta` donne $\Delta$, `\Omega` donne $\Omega$.

| Cas particulier | Écriture |
|---|---|
| Majuscules identiques aux lettres latines | on tape la lettre latine : `A`, `B`, `E`… |
| Omicron | on tape `o` |
| Variantes | `\varepsilon`, `\vartheta`, `\varphi`, `\varrho` |
