=== Découverte - Le sommet de ABC
Id: nouveau-1
Difficulté: easy
Énoncé:
<!-- optitab:1 -->
On considère l’angle $\widehat{ABC}$.

1. Quel est son sommet ?
2. Nommer ses deux côtés.
3. Écrire un autre nom du même angle.

Étapes:
<!-- optitab:1 -->
## Question 1 : Quel est son sommet ?

::: methode
Lire la lettre du milieu.
:::

::: etape Raisonnement
Dans ABC, la lettre centrale est B.
:::

::: resultat
Le sommet est $B$.
:::

## Question 2 : Nommer ses deux côtés.

::: methode
Partir du sommet vers les deux autres points.
:::

::: etape Raisonnement
Les demi-droites commencent toutes deux en B, puis passent par A et C.
:::

::: resultat
Les côtés sont $[BA)$ et $[BC)$.
:::

## Question 3 : Écrire un autre nom du même angle.

::: methode
Échanger les lettres des côtés sans déplacer le sommet.
:::

::: etape Raisonnement
Les mêmes côtés peuvent être nommés dans l’ordre inverse ; B reste au milieu.
:::

::: resultat
$\widehat{CBA}$.
:::

Solution:
<!-- optitab:1 -->
1. Le sommet est $B$.
2. Les côtés sont $[BA)$ et $[BC)$.
3. $\widehat{CBA}$.

=== Découverte - Le coin de feuille : test 1
Id: nouveau-2
Difficulté: easy
Énoncé:
<!-- optitab:1 -->
Un gabarit d’angle droit est superposé à trois angles. L’angle A est moins ouvert, B coïncide exactement avec le gabarit et C est plus ouvert, sans atteindre un angle plat.

1. Classer A et justifier.
2. Classer B et donner sa mesure.
3. Classer C et expliquer pourquoi un trait plus court ne change rien.

Étapes:
<!-- optitab:1 -->
## Question 1 : Classer A et justifier.

::: methode
Comparer au gabarit droit.
:::

::: etape Raisonnement
A est plus petit que l’angle droit : c’est la définition d’un angle aigu.
:::

::: resultat
A est aigu.
:::

## Question 2 : Classer B et donner sa mesure.

::: methode
Utiliser la coïncidence avec le gabarit.
:::

::: etape Raisonnement
Les côtés de B et ceux du coin de feuille se superposent ; un angle droit mesure 90 degrés.
:::

::: resultat
$B$ est droit : $90^\circ$.
:::

## Question 3 : Classer C et expliquer pourquoi un trait plus court ne change rien.

::: methode
Distinguer ouverture et longueur.
:::

::: etape Raisonnement
C est entre l’angle droit et l’angle plat. Raccourcir un côté ne fait pas pivoter la demi-droite.
:::

::: resultat
C est obtus ; raccourcir les traits ne change pas son ouverture.
:::

[IMAGE_1]

Solution:
<!-- optitab:1 -->
1. A est aigu.
2. $B$ est droit : $90^\circ$.
3. C est obtus ; raccourcir les traits ne change pas son ouverture.

=== Découverte - Comparer avec la même unité : 2 et 3 reports
Id: nouveau-3
Difficulté: easy
Énoncé:
<!-- optitab:1 -->
Un petit gabarit G tient exactement 2 fois dans l’angle A et 3 fois dans l’angle B, sans recouvrement. Toutes les ouvertures restent inférieures à un angle plat.

1. Quel angle est le plus grand ?
2. Combien de gabarits faut-il ajouter à A pour obtenir B ?
3. Pourquoi ne peut-on pas remplacer G par un gabarit différent seulement pour B ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Quel angle est le plus grand ?

::: methode
Comparer les nombres de gabarits identiques.
:::

::: etape Raisonnement
Le même gabarit est reporté 2 fois pour A et 3 fois pour B ; 3 est plus grand que 2.
:::

::: resultat
B est plus grand que A.
:::

## Question 2 : Combien de gabarits faut-il ajouter à A pour obtenir B ?

::: methode
Chercher la différence des nombres de reports.
:::

::: etape Raisonnement
On complète 2 reports jusqu’à 3 : $3-2=1$.
:::

::: resultat
Il faut 1 gabarits.
:::

## Question 3 : Pourquoi ne peut-on pas remplacer G par un gabarit différent seulement pour B ?

::: methode
Conserver une même unité de comparaison.
:::

::: etape Raisonnement
Un report d’un grand gabarit n’a pas la même ouverture qu’un report d’un petit. Les nombres ne seraient plus comparables.
:::

::: resultat
La comparaison exige le même gabarit pour A et B.
:::

Solution:
<!-- optitab:1 -->
1. B est plus grand que A.
2. Il faut 1 gabarits.
3. La comparaison exige le même gabarit pour A et B.

=== Découverte - Un angle déplacé : atelier 1
Id: nouveau-4
Difficulté: easy
Énoncé:
<!-- optitab:1 -->
Dessine un angle aigu quelconque sur une feuille. Place ailleurs un point S et trace une demi-droite d’origine S.

1. Décrire comment reproduire l’angle en S.
2. Comment vérifier que les angles sont égaux ?
3. Faut-il garder les mêmes longueurs de traits ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Décrire comment reproduire l’angle en S.

::: methode
Transporter un gabarit au calque.
:::

::: etape Raisonnement
Décalquer les deux côtés et le sommet ; poser le sommet sur S et un côté sur la demi-droite donnée ; reporter le second côté.
:::

::: resultat
Reproduction au calque : sommet en S, premier côté aligné, second côté reporté.
:::

## Question 2 : Comment vérifier que les angles sont égaux ?

::: methode
Tester la superposition des deux côtés.
:::

::: etape Raisonnement
Reposer le calque sur chaque angle ; si les deux côtés coïncident en même temps, les ouvertures sont égales.
:::

::: resultat
Les deux côtés doivent se superposer simultanément.
:::

## Question 3 : Faut-il garder les mêmes longueurs de traits ?

::: methode
Se concentrer sur l’ouverture.
:::

::: etape Raisonnement
Les traits ne sont qu’une partie des demi-droites. Les prolonger ne modifie pas leurs directions.
:::

::: resultat
Non : seule l’ouverture doit être conservée.
:::

Solution:
<!-- optitab:1 -->
1. Reproduction au calque : sommet en S, premier côté aligné, second côté reporté.
2. Les deux côtés doivent se superposer simultanément.
3. Non : seule l’ouverture doit être conservée.

=== Découverte - Assembler 45 degrés et 45 degrés

<!-- optitab:1 -->
Deux gabarits déjà fournis mesurent $ 45^\circ$ et $45^\circ$.

3. Comparer cette somme à un angle droit.

Étapes:

Juxtaposer les gabarits.
:::

::: etape Raisonnement

:::

::: resultat
Même sommet, un côté commun et aucun recouvrement.

::: methode
Additionner les mesures des angles juxtaposés.
:::

::: etape Raisonnement
$45+45=90$.
:::

::: resultat
La somme mesure $90^\circ$.
:::

## Question 3 : Comparer cette somme à un angle droit.

::: methode
Utiliser 90 degrés comme repère.
:::

::: etape Raisonnement
Un angle droit mesure $90^\circ$ ; la somme mesure $90^\circ$.
:::

::: resultat
C’est un angle droit.
:::

Solution:
<!-- optitab:1 -->
1. Même sommet, un côté commun et aucun recouvrement.
2. La somme mesure $90^\circ$.
3. C’est un angle droit.

Parts superposables et somme égale à l’angle de départ.

=== Entraînement - Reproduire un angle obtus sur une nouvelle demi-droite - Parcours 2
Id: nouveau-11
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un angle obtus est dessiné sur une feuille. Ailleurs, on place un point T et on trace une demi-droite d’origine T.

1. Comment reproduire cet angle en T sans rapporteur ?
2. Comment contrôler la reproduction ?
3. Un élève a obtenu un angle aigu. Sa reproduction peut-elle être correcte ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Comment reproduire cet angle en T sans rapporteur ?

::: methode
Fabriquer puis déplacer un gabarit de l’ouverture.
:::

::: etape Raisonner
Décalquer les deux côtés de l’angle, placer le sommet du gabarit en T, faire coïncider un côté avec la demi-droite donnée, puis tracer le second côté.
:::

::: resultat
Utiliser un gabarit ou un calque, en conservant l’ouverture obtuse.
:::

## Question 2 : Comment contrôler la reproduction ?

::: methode
Superposer les deux ouvertures.
:::

::: etape Raisonner
Faire coïncider les sommets et un côté ; vérifier que le second côté coïncide aussi.
:::

::: resultat
La superposition des deux côtés confirme l’égalité des angles.
:::

## Question 3 : Un élève a obtenu un angle aigu. Sa reproduction peut-elle être correcte ?

::: methode
Comparer les deux angles au gabarit d’angle droit.
:::

::: etape Raisonner
L’angle initial est plus ouvert qu’un angle droit ; un angle aigu est moins ouvert. Ils ne peuvent donc pas se superposer.
:::

::: resultat
Non : il n’a pas conservé l’ouverture de l’angle obtus.
:::

Solution:
<!-- optitab:1 -->
1. Utiliser un gabarit ou un calque, en conservant l’ouverture obtuse.
2. La superposition des deux côtés confirme l’égalité des angles.
3. Non : il n’a pas conservé l’ouverture de l’angle obtus.

## Question 1 : Quelle mesure représente G ?

Partager 90 degrés en deux.

$90\div2=45$.

$45^\circ$.

Comparer les sommes au droit.

A aigu ; B droit ; C obtus.

Compléter jusqu’à deux angles droits.

Un angle plat contient quatre G ; C en contient trois, donc il en manque un.

1. $45^\circ$.

=== Problème - Retrouver deux ouvertures
Id: nouveau-17
Difficulté: hard
Énoncé:
<!-- optitab:1 -->
Deux angles A et B, juxtaposés, forment un angle droit. B est le double de A.

1. Combien de copies de A remplissent l’angle droit ?
2. Calculer les mesures de A et B.
3. Peut-on obtenir A en pliant une seule fois un angle droit en deux ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien de copies de A remplissent l’angle droit ?

::: methode
Remplacer B par deux copies de A.
:::

::: etape Raisonnement
A suivi de B revient à juxtaposer A, A et A.
:::

::: resultat
Trois copies de A.
:::

## Question 2 : Calculer les mesures de A et B.

::: methode
Partager puis doubler.
:::

::: etape Raisonnement
$90\div3=30$ ; $2\times30=60$.
:::

::: resultat
$A=30^\circ$ et $B=60^\circ$.
:::

## Question 3 : Peut-on obtenir A en pliant une seule fois un angle droit en deux ?

::: methode
Comparer le partage demandé et le pliage.
:::

::: etape Raisonnement
Le pliage en deux donne 45 degrés, alors que A vaut 30 degrés.
:::

::: resultat
Non : un tel pli donne 45 degrés.
:::

Solution:
<!-- optitab:1 -->
1. Trois copies de A.
2. $A=30^\circ$ et $B=60^\circ$.
3. Non : un tel pli donne 45 degrés.

=== Problème - Le gabarit retourné
Id: nouveau-18
Difficulté: hard
Énoncé:
<!-- optitab:1 -->
Sur un calque, Noé reproduit un angle aigu. Il retourne le calque puis l’aligne au nouveau sommet, avec un côté sur la demi-droite donnée.

1. L’ouverture change-t-elle quand on retourne le calque ?
2. Pourquoi deux reproductions peuvent-elles se trouver de part et d’autre de la demi-droite ?
3. Quelle précision ajouter pour obtenir une seule position ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L’ouverture change-t-elle quand on retourne le calque ?

::: methode
Utiliser la superposition.
:::

::: etape Raisonnement
Retourner le calque ne déforme pas les côtés : l’angle est seulement présenté de l’autre côté.
:::

::: resultat
Non, la même ouverture est conservée.
:::

## Question 2 : Pourquoi deux reproductions peuvent-elles se trouver de part et d’autre de la demi-droite ?

::: methode
Repérer les positions possibles.
:::

::: etape Raisonnement
Le deuxième côté peut se tracer dans chacun des deux demi-plans ; les deux gabarits ont la même ouverture.
:::

::: resultat
Il existe deux positions symétriques de même ouverture.
:::

## Question 3 : Quelle précision ajouter pour obtenir une seule position ?

::: methode
Lever l’ambiguïté du programme.
:::

::: etape Raisonnement
Indiquer le côté de la demi-droite ou de la droite support où placer l’angle.
:::

::: resultat
Préciser le côté où tracer le second côté de l’angle.
:::

Solution:
<!-- optitab:1 -->
1. Non, la même ouverture est conservée.
2. Il existe deux positions symétriques de même ouverture.
3. Préciser le côté où tracer le second côté de l’angle.

=== Problème - Une ouverture de 135 degrés sans rapporteur
Id: nouveau-19
Difficulté: hard
Énoncé:
<!-- optitab:1 -->
On dispose d’un coin de feuille et d’un calque, sans rapporteur.

1. Fabriquer un gabarit de 45 degrés.
2. Construire 135 degrés.
3. Retrouver cette ouverture à partir d’un angle plat.

Étapes:
<!-- optitab:1 -->
## Question 1 : Fabriquer un gabarit de 45 degrés.

::: methode
Plier le droit en deux.
:::

::: etape Raisonnement
Superposer les côtés du coin droit par pliage ; chaque moitié représente $90\div2=45$ degrés.
:::

::: resultat
Une moitié de coin droit.
:::

## Question 2 : Construire 135 degrés.

::: methode
Juxtaposer le droit et sa moitié.
:::

::: etape Raisonnement
Reporter le coin droit, puis le demi-angle contre son dernier côté au même sommet, sans chevauchement : $90+45=135$.
:::

::: resultat
Un droit suivi d’un demi-droit.
:::

## Question 3 : Retrouver cette ouverture à partir d’un angle plat.

::: methode
Retirer une moitié d’angle droit.
:::

::: etape Raisonnement
Deux coins droits donnent 180 degrés. Retirer un gabarit de 45 degrés laisse $180-45=135$.
:::

::: resultat
Un plat privé de 45 degrés.
:::

Solution:
<!-- optitab:1 -->
1. Une moitié de coin droit.
2. Un droit suivi d’un demi-droit.
3. Un plat privé de 45 degrés.

=== Problème - Deux pliages, puis une somme
Id: nouveau-20
Difficulté: hard
Énoncé:
<!-- optitab:1 -->
On partage un angle droit en deux par pliage, puis chaque moitié encore en deux.

1. Combien de petites parts égales obtient-on ?
2. Quelle est la mesure de trois petites parts ?
3. Combien de petites parts faut-il ajouter pour retrouver le droit ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien de petites parts égales obtient-on ?

::: methode
Doubler le nombre de parts à chaque pliage.
:::

::: etape Raisonnement
Deux moitiés sont chacune partagées en deux : $2\times2=4$.
:::

::: resultat
Quatre parts égales.
:::

## Question 2 : Quelle est la mesure de trois petites parts ?

::: methode
Calculer une part puis sa triple somme.
:::

::: etape Raisonnement
$90\div4=22{,}5$ ; $3\times22{,}5=67{,}5$.
:::

::: resultat
$67{,}5^\circ$.
:::

## Question 3 : Combien de petites parts faut-il ajouter pour retrouver le droit ?

::: methode
Compléter quatre parts.
:::

::: etape Raisonnement
Trois des quatre petites parts sont déjà présentes ; $4-3=1$.
:::

::: resultat
Une petite part de 22,5 degrés.
:::

Solution:
<!-- optitab:1 -->
1. Quatre parts égales.
2. $67{,}5^\circ$.
3. Une petite part de 22,5 degrés.

=== Problème - Un éventail incomplet
Id: nouveau-21
Difficulté: hard
Énoncé:
<!-- optitab:1 -->
Un éventail plat doit contenir huit secteurs égaux. Deux secteurs juxtaposés forment un angle droit. Pour l’instant, six secteurs sont présents.

1. Quelle est la mesure d’un secteur ?
2. La description de l’éventail plat est-elle possible ?
3. Combien de ces secteurs faut-il pour un éventail plat ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Quelle est la mesure d’un secteur ?

::: methode
Partager l’angle droit.
:::

::: etape Raisonnement
Deux secteurs valent 90 degrés, donc un secteur vaut $90\div2=45$ degrés.
:::

::: resultat
$45^\circ$.
:::

## Question 2 : La description de l’éventail plat est-elle possible ?

::: methode
Comparer huit secteurs à un angle plat.
:::

::: etape Raisonnement
Huit secteurs de 45 degrés donnent $8\times45=360$ degrés, tandis qu’un angle plat vaut 180 degrés.
:::

::: resultat
Non : huit secteurs formeraient un tour complet, pas un angle plat.
:::

## Question 3 : Combien de ces secteurs faut-il pour un éventail plat ?

::: methode
Chercher le nombre de 45 degrés dans 180 degrés.
:::

::: etape Raisonnement
$180\div45=4$.
:::

::: resultat
Quatre secteurs suffisent.
:::

Solution:
<!-- optitab:1 -->
1. $45^\circ$.
2. Non : huit secteurs formeraient un tour complet, pas un angle plat.
3. Quatre secteurs suffisent.
