[IMAGE_2]
:::

:::

::: resultat

:::

## Question 2 : Complète : $24+\ldots=39$.

::: methode
Retrouver la quantité ajoutée.
:::

::: etape Raisonner
Je passe de 24 à 39. $24+15=39$.
:::

::: resultat
Il manque 15.
:::

::: methode

:::

::: etape Raisonner

:::

::: resultat

::: methode
