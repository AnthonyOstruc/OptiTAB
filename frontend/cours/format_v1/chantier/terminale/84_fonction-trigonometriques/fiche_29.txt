Titre: Résumé : Fonctions sinus et cosinus

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : périodicité et parité, dérivées, variations, équations et inéquations sur le cercle, étude d’une fonction trigonométrique. Programme de Terminale.
:::

## I. Courbes et dérivées

1. $\cos$ et $\sin$ sont périodiques de période $2\pi$ ; $\cos$ est paire, $\sin$ est impaire.
2. $\cos^2 x + \sin^2 x = 1$ ; $-1 \le \cos x \le 1$ ; $-1 \le \sin x \le 1$.

::: formule
$\sin'(x) = \cos x \qquad \cos'(x) = -\sin x$
:::

3. $\big(\sin(ax + b)\big)' = a\cos(ax + b)$ ; $\big(\cos(ax + b)\big)' = -a\sin(ax + b)$.
4. $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ (nombre dérivé de $\sin$ en $0$).

## II. Variations, équations, inéquations

::: tableau Variations de $\cos$ sur $[-\pi\,;\pi]$
x : -\pi, 0, \pi
-\sin x : z, +, z, -, z
\cos x : -/-1, +/1, -/-1
:::

1. $\cos x = \cos a \iff x = a + 2k\pi$ ou $x = -a + 2k\pi$.
2. $\sin x = \sin a \iff x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$.
3. Inéquation : droite verticale $x = a$ (pour $\cos$) ou horizontale $y = a$ (pour $\sin$), puis lecture de l’arc sur le cercle.

## III. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Oublier le signe moins : $\cos'(x) = -\sin x$.
2. Oublier le facteur $a$ en dérivant $\cos(ax + b)$.
3. Ne donner qu’une solution sur un tour complet.
4. Chercher une limite de $\cos x$ en $+\infty$ : elle n’existe pas, on encadre.
:::

::: remarque Réflexe
Fonction trigonométrique à étudier → période et parité d’abord, puis étude sur l’intervalle réduit.
:::
