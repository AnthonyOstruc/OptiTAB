=== Découverte — Placer l’image d’un point à 1 carreau de l’axe
Id: 3524
Difficulté: easy
Image: symetrie_1_1.png

Énoncé:
<!-- optitab:1 -->
L’axe $(d)$ est vertical. Sur un quadrillage d’unité $1$ cm, $A$ se trouve à $1$ carreau à droite de l’axe. Construire son image $A\prime$. La figure corrigée comporte aussi un rectangle pour contrôler les alignements.

1. Où placer $A\prime$ ?
2. Calculer $AA\prime$.
3. Quelle propriété définit l’axe pour ce segment ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Où placer $A\prime$ ?

::: methode
Compter perpendiculairement à l’axe.
:::
::: etape Fixer la hauteur
L’image est sur la même ligne horizontale que $A$.
:::
::: etape Reporter la distance
Compter $1$ carreau à gauche de l’axe.
:::
::: resultat
$A\prime$ est à $1$ carreau de l’autre côté, à la même hauteur.
:::

## Question 2 : Calculer $AA\prime$.

::: methode
Doubler la distance à l’axe.
:::
::: etape Décomposer au pied
Le pied est le milieu de $[AA\prime]$.
:::
::: etape Additionner
$1+1=2$ cm.
:::
::: resultat
$AA\prime=2$ cm.
:::

## Question 3 : Quelle propriété définit l’axe pour ce segment ?

::: methode
Relier image et médiatrice.
:::
::: etape Observer la perpendicularité
Le segment $[AA\prime]$ est horizontal et l’axe vertical.
:::
::: etape Observer le milieu
Les deux côtés du pied ont la même longueur.
:::
::: resultat
L’axe est la médiatrice de $[AA\prime]$.
:::

### Figure de contrôle

Le tracé vert montre les éléments construits ou la figure obtenue. Les dessins peuvent être réduits ; utiliser les données écrites pour construire sur papier.

::: attention
Reporter perpendiculairement à l’axe, à la même distance de l’autre côté. Un point situé sur l’axe reste fixe.
:::

Solution:
<!-- optitab:1 -->
1. $A\prime$ est à $1$ carreau de l’autre côté, à la même hauteur.
2. $AA\prime=2$ cm.
3. L’axe est la médiatrice de $[AA\prime]$.

Découverte — Reproduire un rectangle de 2 cm sur 3 cm
Id: 3527
Difficulté: easy
Image: symetrie_2_1.png

Énoncé:
<!-- optitab:1 -->
Sur un quadrillage de côté $1$ cm, $ABCD$ est un rectangle situé à droite de l’axe vertical : $A$ est à $1$ carreau de l’axe, $AB=2$ cm et $AD=3$ cm. Construire son image.

1. Construire les images des quatre sommets.
2. Donner les dimensions du rectangle image.
3. Calculer son périmètre.

Étapes:
<!-- optitab:1 -->

## Question 1 : Construire les images des quatre sommets.

::: methode
Reporter les distances sur des perpendiculaires.
:::
::: etape Placer chaque image
Pour chaque sommet, rester sur sa ligne horizontale et compter autant de carreaux de l’autre côté.
:::
::: etape Relier dans l’ordre
Relier $A\prime$, $B\prime$, $C\prime$, $D\prime$, puis revenir à $A\prime$.
:::
::: resultat
Le rectangle vert est l’image demandée.
:::

## Question 2 : Donner les dimensions du rectangle image.

::: methode
Utiliser la conservation des longueurs.
:::
::: etape Associer les côtés
$[A\prime B\prime]$ est l’image de $[AB]$, et $[A\prime D\prime]$ celle de $[AD]$.
:::
::: etape Conserver les mesures
Les longueurs restent $2$ cm et $3$ cm.
:::
::: resultat
$A\prime B\prime=2$ cm et $A\prime D\prime=3$ cm.
:::

## Question 3 : Calculer son périmètre.

::: methode
Utiliser les dimensions conservées.
:::
::: etape Écrire le calcul
$P=2\times(2+3)$.
:::
::: etape Effectuer
$P=2\times5=10$ cm.
:::
::: resultat
Le périmètre vaut $10$ cm.
:::

### Figure de contrôle

[IMAGE_1]

Le tracé vert montre les éléments construits ou la figure obtenue. Les dessins peuvent être réduits ; utiliser les données écrites pour construire sur papier.

::: attention
Reporter perpendiculairement à l’axe, à la même distance de l’autre côté. Un point situé sur l’axe reste fixe.
:::

Solution:
<!-- optitab:1 -->
1. Le rectangle vert est l’image demandée.
2. $A\prime B\prime=2$ cm et $A\prime D\prime=3$ cm.
3. Le périmètre vaut $10$ cm.

Découverte — Contrôler un point fixe et une image : distance 1
Id: 3530
Difficulté: easy
Image: symetrie_3_1.png

Énoncé:
<!-- optitab:1 -->
La figure représente un rectangle et son image. On ajoute $H$, pied de la perpendiculaire de $A$ à l’axe vertical ; $AH=1$ cm. $H$ appartient à l’axe.

1. Quelle est l’image de $H$ ?
2. Que donne une seconde symétrie de $A\prime$ par rapport au même axe ?
3. Pourquoi un point placé à droite de l’axe ne peut-il pas être sa propre image ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle est l’image de $H$ ?

::: methode
Reconnaître les points de l’axe.
:::
::: etape Utiliser l’appartenance
$H$ est sur l’axe.
:::
::: etape Appliquer la propriété
Un point de l’axe reste fixe.
:::
::: resultat
L’image de $H$ est $H$.
:::

## Question 2 : Que donne une seconde symétrie de $A\prime$ par rapport au même axe ?

::: methode
Revenir sur la même perpendiculaire.
:::
::: etape Identifier le premier échange
$A$ et $A\prime$ sont à même distance, de part et d’autre.
:::
::: etape Échanger à nouveau
Le second report ramène au point de départ.
:::
::: resultat
L’image de $A\prime$ est $A$.
:::

## Question 3 : Pourquoi un point placé à droite de l’axe ne peut-il pas être sa propre image ?

::: methode
Utiliser le milieu du segment d’images.
:::
::: etape Observer sa distance
Un point hors de l’axe a une distance strictement positive à celui-ci.
:::
::: etape Reporter de l’autre côté
Son image est distincte, dans l’autre demi-plan.
:::
::: resultat
Seuls les points de l’axe sont fixes.
:::

Solution:

Entraînement — Construire avec un axe oblique : 1 et 3 carreaux
Id: 3533
Difficulté: medium
Image: symetrie_4_1.png

Énoncé:
<!-- optitab:1 -->
Un quadrillage carré est repéré par son coin inférieur gauche. L’axe est la diagonale montante du quadrillage. $P$ se trouve à $1$ carreau vers la droite et $3$ vers le haut à partir de ce coin.

1. Placer l’image $P\prime$ sur le quadrillage.
2. Dans quelle direction est le segment $[PP\prime]$ ?
3. Pourquoi garder la même hauteur serait-il une erreur ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Placer l’image $P\prime$ sur le quadrillage.

::: methode
Utiliser le pliage suivant la diagonale.
:::
::: etape Échanger les deux décomptes
Le pli échange la direction horizontale avec la direction verticale.
:::
::: etape Placer le point
Compter $3$ carreaux à droite et $1$ vers le haut.
:::
::: resultat
$P\prime$ est à $3$ carreaux à droite et $1$ vers le haut.
:::

## Question 2 : Dans quelle direction est le segment $[PP\prime]$ ?

::: methode
Contrôler la perpendicularité.
:::
::: etape Relier les deux points
Le segment descend vers la droite tandis que l’axe monte.
:::
::: etape Vérifier à l’équerre
Les deux directions diagonales d’un carré sont perpendiculaires.
:::
::: resultat
$[PP\prime]$ est perpendiculaire à l’axe.
:::

## Question 3 : Pourquoi garder la même hauteur serait-il une erreur ?

::: methode
Tenir compte de l’orientation de l’axe.
:::
::: etape Comparer les axes
Un report horizontal convient à un axe vertical.
:::
::: etape Adapter à l’axe oblique
Ici il faut reporter sur une perpendiculaire oblique, pas horizontalement.
:::
::: resultat
La même hauteur ne respecte pas la perpendicularité imposée.
:::

### Figure de contrôle

[IMAGE_1]

Le tracé vert montre les éléments construits ou la figure obtenue. Les dessins peuvent être réduits ; utiliser les données écrites pour construire sur papier.

::: attention
Reporter perpendiculairement à l’axe, à la même distance de l’autre côté. Un point situé sur l’axe reste fixe.
:::

Solution:
<!-- optitab:1 -->
1. $P\prime$ est à $3$ carreaux à droite et $1$ vers le haut.
2. $[PP\prime]$ est perpendiculaire à l’axe.
3. La même hauteur ne respecte pas la perpendicularité imposée.

Le tracé vert montre les éléments construits ou la figure obtenue. Les dessins peuvent être réduits ; utiliser les données écrites pour construire sur papier.

::: attention
Reporter perpendiculairement à l’axe, à la même distance de l’autre côté. Un point situé sur l’axe reste fixe.
:::

Solution:
<!-- optitab:1 -->
1. La figure possède 1 axe(s).
2. Les droites vertes réalisent ces pliages.
3. Non ; un axe peut passer par des milieux de côtés.
