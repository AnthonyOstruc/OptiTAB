=== Découverte - 1. Reconnaître une instruction
Id: 3608
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une personne reçoit : « avancer d’une case ; tourner à gauche ; avancer de deux cases ».



1. Combien d’instructions contient la séquence ?
2. Pourquoi faut-il respecter l’ordre ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien d’instructions contient la séquence ?

::: methode
Compter les ordres élémentaires dans l’ordre.
:::

::: etape Décomposer la séquence
Avancer, tourner et avancer sont trois ordres distincts.
:::

::: resultat
3.
:::

## Question 2 : Pourquoi faut-il respecter l’ordre ?

::: methode
Chaque ordre agit sur la position ou l’orientation atteinte.
:::

::: etape Comprendre la séquence
Tourner avant ou après le déplacement peut changer la direction suivie.
:::

::: resultat
L’ordre peut changer le résultat.
:::

::: retenir
Une séquence est une liste ordonnée d’instructions.
:::

Solution:
<!-- optitab:1 -->
1. 3.
2. L’ordre peut changer le résultat.

Attendu : $6+2=8$, puis $8\times2=16$. La sortie 14 peut provenir d’un échange des deux calculs : $6\times2+2=14$. Ce test seul ne permet pas d’identifier une erreur unique.
:::

::: resultat
16. Une erreur possible est de doubler 6 avant d’ajouter 2.
:::

::: retenir
Un programme est contrôlé avec des entrées choisies et des sorties attendues.
:::

Solution:
<!-- optitab:1 -->
1. Demander un nombre ; lui ajouter 2 ; doubler le résultat ; afficher ce résultat.
2. 16. Une erreur possible est de doubler 6 avant d’ajouter 2.
