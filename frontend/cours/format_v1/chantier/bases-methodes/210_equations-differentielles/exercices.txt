=== Découverte - Équations Différentielles - Vérification de Solutions
Id: 1663
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Vérifier que les fonctions suivantes sont des solutions des équations différentielles données.

1. Vérifier que $\displaystyle y = 3 e^{2x} - 2$ est solution de $\displaystyle y' = 2y + 4$
2. Vérifier que $\displaystyle T = 20 + 80 e^{-0,1 t}$ est solution de $\displaystyle T' = -0,1 (T - 20)$
3. Vérifier que $\displaystyle P = 100 e^{0,05 t}$ est solution de $\displaystyle P' = 0,05 P$
4. Expliquer pourquoi la vérification est importante

Étapes:
<!-- optitab:1 -->
## Question 1 : Vérifier $\displaystyle y = 3 e^{2x} - 2$

::: methode
Vérification par dérivation
:::

::: etape Dérivée
$$y' = 3 \times 2 e^{2x} = 6 e^{2x}$$
:::

::: etape Membre de droite
$$
\begin{aligned}
2y + 4 &= 2(3 e^{2x} - 2) + 4 \\
&= 6 e^{2x} - 4 + 4 \\
&= 6 e^{2x}
\end{aligned}
$$
:::

::: etape Vérification
$\displaystyle y' = 2y + 4$ Solution correcte
:::

## Question 2 : Vérifier $\displaystyle T = 20 + 80 e^{-0,1 t}$

::: methode
Vérification par dérivation
:::

::: etape Dérivée
$$T' = 80 \times (-0,1) e^{-0,1 t} = -8 e^{-0,1 t}$$
:::

::: etape Membre de droite
$$
\begin{aligned}
-0,1 (T - 20) &= -0,1 (20 + 80 e^{-0,1 t} - 20) \\
&= -0,1 (80 e^{-0,1 t}) \\
&= -8 e^{-0,1 t}
\end{aligned}
$$
:::

::: etape Vérification
$\displaystyle T' = -0,1 (T - 20)$ Solution correcte
:::

## Question 3 : Vérifier $\displaystyle P = 100 e^{0,05 t}$

::: methode
Vérification par dérivation
:::

::: etape Dérivée
$$P' = 100 \times 0,05 e^{0,05 t} = 5 e^{0,05 t}$$
:::

::: etape Membre de droite
$$0,05 P = 0,05 \times 100 e^{0,05 t} = 5 e^{0,05 t}$$
:::

::: etape Vérification
$\displaystyle P' = 0,05 P$ Solution correcte
:::

## Question 4 : Importance de la vérification

::: methode
Analyse des avantages
:::

::: etape Détection d'erreurs
Permet de détecter les erreurs de calcul
:::

::: etape Validation
Confirme la validité de la solution obtenue
:::

::: etape Applications
Essentiel dans les applications pratiques
:::

::: etape Simplicité
Méthode simple et rapide à appliquer
:::

Solution:
<!-- optitab:1 -->
1. $y = 3 e^{2x} - 2$ est solution de $y' = 2y + 4$
2. $T = 20 + 80 e^{-0,1 t}$ est solution de $T' = -0,1 (T - 20)$
3. $P = 100 e^{0,05 t}$ est solution de $P' = 0,05 P$
4. La vérification est cruciale pour valider les solutions

=== Entraînement - Équations Différentielles - Circuit Électrique RC
Id: 1659
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un circuit RC est composé d'une résistance $R = 1000 \Omega$ et d'un condensateur $C = 10 \mu F$. Une tension $E = 5 V$ est appliquée. L'équation différentielle régissant la tension $u(t)$ aux bornes du condensateur est : $R C \frac{du}{dt} + u = E$.

1. Résoudre l'équation différentielle avec la condition initiale
2. Déterminer la tension après 0,02 seconde
3. Calculer la constante de temps du circuit
4. Étudier le comportement à long terme

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre l'équation différentielle avec la condition initiale

::: methode
Équation différentielle linéaire du premier ordre
:::

::: etape Équation
$$1000 \times 10^{-5} u' + u = 5$$
:::

::: etape Simplification
$$0,01 u' + u = 5$$
:::

::: etape Forme standard
$$u' + 100 u = 500$$
:::

::: etape Forme
$y' = a y + b$ avec $a = -100$, $b = 500$
:::

::: etape Solution générale
$$y(t) = C e^{a t} - \frac{b}{a} = C e^{-100 t} + 5$$
:::

::: etape Condition initiale
$$u(0) = 0$$
:::

::: etape Détermination de la constante
$$0 = C + 5 \Rightarrow C = -5$$
:::

::: etape Solution particulière
$$u(t) = 5 (1 - e^{-100 t})$$
:::

## Question 2 : Déterminer la tension après 0,02 seconde

::: methode
Application numérique
:::

::: etape Calcul
$\displaystyle u(0,02) = 5 (1 - e^{-100 \times 0,02}) = 5 (1 - e^{-2}) \approx 5 (1 - 0,1353) = 5 \times 0,8647 \approx 4,3235$ V
:::

## Question 3 : Calculer la constante de temps

::: methode
Définition de la constante de temps
:::

::: etape Constante de temps
$\displaystyle \tau = R C = 1000 \times 10^{-5} = 0,01$ seconde
:::

::: etape Après $\displaystyle 5\tau$
$\displaystyle u(0,05) = 5 (1 - e^{-5}) \approx 5 (1 - 0,0067) \approx 4,9665$ V
:::

::: etape Interprétation
Le condensateur se charge à 99,33% de la tension finale
:::

## Question 4 : Étudier le comportement à long terme

::: methode
Calcul de limite
:::

::: etape Solution
$$u(t) = 5 (1 - e^{-100 t})$$
:::

::: etape
Quand $t \to +\infty$, le terme $e^{-100 t} \to 0$ (puisque $-100t \to -\infty$)
:::

::: etape Limite
$\displaystyle u(t) \to 5 (1 - 0) = 5$ V
:::

::: etape Résultat
$\displaystyle\lim_{t \to +\infty} u(t) = 5$ V
:::

::: etape Interprétation
La tension tend vers la tension d'alimentation
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle u(t) = 5 (1 - e^{-100 t})$
2. $\displaystyle u(0,02) \approx 4,3235$ V
3. Constante de temps $\displaystyle \tau = 0,01$ s
4. $\displaystyle\lim_{t \to +\infty} u(t) = 5$ V

=== Entraînement - Équations Différentielles - Croissance Démographique
Id: 1654
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère une population dont le taux de croissance est proportionnel à la population actuelle selon l'équation différentielle : $P' = 0,03 P$.

1. Résoudre l'équation différentielle générale
2. Déterminer la population après 10 ans (avec $\displaystyle P(0) = 5000$)
3. Calculer quand la population atteindra 10 000 habitants

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre l'équation différentielle générale

::: methode
Équation différentielle linéaire du premier ordre
:::

::: etape Équation
$$P' = 0,03 P$$
:::

::: etape Forme
$y' = a y + b$ avec $a = 0,03$, $b = 0$
:::

::: etape Solution générale
$$
\begin{aligned}
y(t) &= C e^{a t} - \frac{b}{a} \\
&= C e^{0,03 t} - 0 \\
&= C e^{0,03 t}
\end{aligned}
$$
:::

## Question 2 : Déterminer la population après 10 ans

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale
$$P(0) = 5000$$
:::

::: etape Détermination de la constante
$$5000 = K e^{0} \Rightarrow K = 5000$$
:::

::: etape Solution particulière
$$P(t) = 5000 e^{0,03 t}$$
:::

::: etape Calcul après 10 ans
$\displaystyle P(10) = 5000 e^{0,3} \approx 5000 \times 1,34986 = 6749$ habitants
:::

## Question 3 : Quand la population atteindra-t-elle 10 000 habitants ?

::: methode
Résolution d'équation exponentielle
:::

::: etape Équation à résoudre
$$5000 e^{0,03 t} = 10000$$
:::

::: etape Simplification
$$e^{0,03 t} = 2$$
:::

::: etape Application du logarithme
$$0,03 t = \ln 2$$
:::

::: etape Calcul du temps
$\displaystyle t = \frac{\ln 2}{0,03} \approx \frac{0,693}{0,03} \approx 23,1$ ans
:::

Solution:
<!-- optitab:1 -->
1. Solution générale : $P(t) = C e^{0,03 t}$ ; Solution avec condition initiale : $P(t) = 5000 e^{0,03 t}$
2. $\displaystyle P(10) \approx 6749$ habitants
3. $\displaystyle t \approx 23,1$ ans

Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une population suit la loi de croissance $P' = 0,02 P + 50$, où 50 représente un apport constant (immigration).

1. Résoudre l'équation différentielle générale
2. Déterminer la population après 5 ans (avec $\displaystyle P(0) = 1000$)
3. Calculer quand la population atteindra 2000 habitants
4. Étudier le comportement à long terme

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre l'équation différentielle générale

::: methode
Équation différentielle linéaire du premier ordre
:::

::: etape Équation
$$P' = 0,02 P + 50$$
:::

::: etape Forme
$y' = a y + b$ avec $a = 0,02$, $b = 50$
:::

::: etape Solution générale
$$
\begin{aligned}
y(t) &= C e^{a t} - \frac{b}{a} \\
&= C e^{0,02 t} - \frac{50}{0,02} \\
&= C e^{0,02 t} - 2500
\end{aligned}
$$
:::

## Question 2 : Déterminer la population après 5 ans

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale
$$P(0) = 1000$$
:::

::: etape Détermination de la constante
$$1000 = C - 2500 \Rightarrow C = 3500$$
:::

::: etape Solution particulière
$$P(t) = 3500 e^{0,02 t} - 2500$$
:::

::: etape Calcul après 5 ans
$\displaystyle P(5) = 3500 e^{0,1} - 2500 \approx 3500 \times 1,1052 - 2500 \approx 3868 - 2500 = 1368$ habitants
:::

## Question 3 : Quand la population atteindra 2000 habitants

::: methode
Résolution d'équation exponentielle
:::

::: etape Équation à résoudre
$$3500 e^{0,02 t} - 2500 = 2000$$
:::

::: etape Simplification
$$3500 e^{0,02 t} = 4500$$
:::

::: etape Division
$$e^{0,02 t} = \frac{4500}{3500} = 1,2857$$
:::

::: etape Application du logarithme
$$0,02 t = \ln 1,2857 \approx 0,2518$$
:::

::: etape Calcul du temps
$\displaystyle t = \frac{0,2518}{0,02} = 12,59$ ans
:::

## Question 4 : Étudier le comportement à long terme

::: methode
Analyse des limites
:::

::: etape Fonction
$$P(t) = 3500 e^{0,02 t} - 2500$$
:::

::: etape Le terme $3500 e^{0,02 t}$ croît exponentiellement vers $+\infty$
:::

::: etape Le terme $\displaystyle -2500$ reste constant
:::

::: etape Limite
$\lim_{t \to +\infty} P(t) = +\infty$ (croissance exponentielle due au terme positif)
:::

::: etape Interprétation
La population croît indéfiniment à cause de l'apport constant
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle P(t) = 3500 e^{0,02 t} - 2500$
2. $\displaystyle P(5) \approx 1368$ habitants
3. $\displaystyle t \approx 12,59$ ans
4. $\displaystyle\lim_{t \to +\infty} P(t) = +\infty$

Énoncé:
<!-- optitab:1 -->
On considère un échantillon radioactif qui suit la loi de décroissance : $\frac{dN}{dt} = -\lambda N$, où $N(t)$ est le nombre de noyaux radioactifs à l'instant $t$ et $\lambda = 0,02 \text{ min}^{-1}$.

1. Résoudre l'équation différentielle par séparation des variables
2. Déterminer $\displaystyle N(t)$ (avec $\displaystyle N(0) = 1000$ noyaux)
3. Calculer la demi-vie de cet élément
4. Déterminer le temps pour qu'il ne reste que 100 noyaux

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre par séparation des variables

::: methode
Séparation des variables
:::

::: etape Équation
$$\frac{dN}{dt} = -\lambda N$$
:::

::: etape Séparation
$$\frac{dN}{N} = -\lambda dt$$
:::

::: etape Intégration
$$\ln N = -\lambda t + C$$
:::

::: etape Solution générale
$N(t) = N_0 e^{-\lambda t}$ (où $N_0$ est le nombre initial de noyaux)
:::

## Question 2 : Déterminer $\displaystyle N(t)$

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale
$$N(0) = 1000$$
:::

::: etape Détermination de $\displaystyle N_0$
$$N(0) = N_0 e^{0} = N_0 = 1000$$
:::

::: etape Solution particulière
$$N(t) = 1000 e^{-0,02 t}$$
:::

## Question 3 : Calculer la demi-vie

::: methode
Définition de la demi-vie
:::

::: etape Demi-vie
$$N(t) = 500$$
:::

::: etape Équation
$$1000 e^{-0,02 t} = 500$$
:::

::: etape Simplification
$$e^{-0,02 t} = 0,5$$
:::

::: etape Application du logarithme
$$-0,02 t = \ln 0,5 = -\ln 2$$
:::

::: etape Calcul
$\displaystyle t = \frac{\ln 2}{0,02} \approx \frac{0,693}{0,02} = 34,65$ minutes
:::

## Question 4 : Temps pour 100 noyaux

::: methode
Résolution d'équation exponentielle
:::

::: etape Équation
$$1000 e^{-0,02 t} = 100$$
:::

::: etape Simplification
$$e^{-0,02 t} = 0,1$$
:::

::: etape Application du logarithme
$$-0,02 t = \ln 0,1 = -2,3026$$
:::

::: etape Calcul
$\displaystyle t = \frac{2,3026}{0,02} = 115,13$ minutes
:::

Solution:
<!-- optitab:1 -->
1. Solution générale : $N(t) = N_0 e^{-\lambda t}$ ; Solution avec $N_0 = 1000$ : $N(t) = 1000 e^{-0,02 t}$
2. $\displaystyle N(t) = 1000 e^{-0,02 t}$
3. Demi-vie $\displaystyle \approx 34,65$ minutes
4. $\displaystyle t \approx 115,13$ minutes pour 100 noyaux

=== Entraînement - Équations Différentielles - Décroissance Radioactive (Uranium)

Un échantillon d'uranium-238 suit la loi de décroissance radioactive : $N' = -\lambda N$, avec $\lambda = 4,9 \times 10^{-18} \text{ s}^{-1}$ (demi-vie ≈ 4,5 milliards d'années).

1. Résoudre l'équation différentielle avec la condition initiale
2. Déterminer la quantité restante après 1 milliard d'années
3. Calculer la demi-vie théorique
4. Comparer avec la demi-vie expérimentale de 4,5 milliards d'années

Séparation des variables
:::

::: etape Équation
$$\frac{dN}{dt} = -\lambda N$$
:::

::: etape Séparation des variables
$$\frac{dN}{N} = -\lambda dt$$
:::

::: etape Intégration

::: etape Solution générale

## Question 2 : Déterminer la quantité restante après 1 milliard d'années

Conversion d'unités et application numérique

=== Entraînement - Équations Différentielles - Mélange de Solutions
Id: 1655
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un réservoir contient 100 litres d'eau pure. On y ajoute une solution saline à raison de $2 \text{ L/min}$ avec une concentration de $0,5 \text{ kg/L}$. Le mélange est agité uniformément et s'écoule à raison de $2 \text{ L/min}$.

1. Établir l'équation différentielle pour la quantité de sel $\displaystyle Q(t)$
2. Résoudre l'équation différentielle (avec $\displaystyle Q(0) = 0$)
3. Déterminer la quantité de sel après 30 minutes
4. Étudier le comportement à long terme

Étapes:
<!-- optitab:1 -->
## Question 1 : Établir l'équation différentielle

::: methode
Bilan de masse
:::

::: etape Principe général
$$\frac{dQ}{dt} = \text{flux entrant de sel} - \text{flux sortant de sel}$$
:::

::: etape Taux d'entrée de sel
$$2 \text{ L/min} \times 0,5 \text{ kg/L} = 1 \text{ kg/min}$$
:::

::: etape Taux de sortie de sel
$$\frac{Q(t)}{100} \text{ kg/L} \times 2 \text{ L/min} = \frac{Q(t)}{50} \text{ kg/min}$$
:::

::: etape Équation différentielle
$$Q'(t) = 1 - \frac{Q(t)}{50}$$
:::

::: etape Forme standard
$$Q'(t) + \frac{1}{50} Q = 1$$
:::

## Question 2 : Résoudre l'équation différentielle

::: methode
Équation différentielle linéaire du premier ordre
:::

::: etape Forme
$y' = a y + b$ avec $a = -\frac{1}{50}$, $b = 1$
:::

::: etape Solution générale
$$
\begin{aligned}
y(t) &= C e^{a t} - \frac{b}{a} \\
&= C e^{-\frac{t}{50}} - \frac{1}{-\frac{1}{50}} \\
&= C e^{-\frac{t}{50}} + 50
\end{aligned}
$$
:::

::: etape Condition initiale
$$Q(0) = 0$$
:::

::: etape Détermination de la constante
$$0 = C + 50 \Rightarrow C = -50$$
:::

::: etape Solution particulière
$$Q(t) = 50 (1 - e^{-\frac{t}{50}})$$
:::

## Question 3 : Déterminer la quantité de sel après 30 minutes

::: methode
Application numérique
:::

::: etape Calcul
$$
\begin{aligned}
Q(30) &= 50 (1 - e^{-\frac{30}{50}}) \\
&= 50 (1 - e^{-0,6})
\end{aligned}
$$
:::

::: etape Valeur numérique
$$e^{-0,6} \approx 0,5488$$
:::

::: etape Résultat final
$\displaystyle Q(30) \approx 50 (1 - 0,5488) = 50 \times 0,4512 \approx 22,56$ kg
:::

## Question 4 : Étudier le comportement à long terme

::: methode
Calcul de limite
:::

::: etape Calcul de la limite
$\displaystyle\lim_{t \to +\infty} Q(t) = \lim_{t \to +\infty} 50 (1 - e^{-\frac{t}{50}}) = 50 (1 - e^{-\infty}) = 50 (1 - 0) = 50$ kg
:::

::: etape Interprétation
À long terme, la quantité de sel tend vers 50 kg (équilibre entrée = sortie)
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle Q'(t) = 1 - \frac{Q(t)}{50}$
2. $\displaystyle Q(t) = 50 (1 - e^{-\frac{t}{50}})$
3. $\displaystyle Q(30) \approx 22,56$ kg
4. $\displaystyle\lim_{t \to +\infty} Q(t) = 50$ kg

Un corps chaud à $80°C$ est placé dans une pièce à $20°C$. La loi de refroidissement de Newton stipule que le taux de refroidissement est proportionnel à la différence de température : $T' = -k (T - 20)$.

Sachant que $\displaystyle k = 0,1 \text{ min}^{-1}$ :

1. Résoudre l'équation différentielle générale
2. Déterminer la constante d'intégration
3. Déterminer la température après 10 minutes

<!-- optitab:1 -->
## Question 1 : Résoudre l'équation différentielle générale

::: methode
Équation différentielle linéaire du premier ordre

::: etape Équation
$$T' = -0,1 (T - 20)$$
:::

::: etape Forme
$y' = a y + b$ avec $a = -0,1$, $b = 2$
:::

::: etape Solution générale
$$
\begin{aligned}
y(t) &= C e^{a t} - \frac{b}{a} \\
&= C e^{-0,1 t} - \frac{2}{-0,1} \\
&= C e^{-0,1 t} + 20
\end{aligned}
$$
:::

## Question 2 : Déterminer la constante d'intégration

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale à $\displaystyle t = 0$
$$T(0) = 80$$
:::

::: etape Substitution
$$80 = C e^{0} + 20 = C + 20$$
:::

::: etape Résolution
$$C = 80 - 20 = 60$$
:::

::: etape Solution particulière
$$T(t) = 60 e^{-0,1 t} + 20$$
:::

## Question 3 : Déterminer la température après 10 minutes

::: methode
Application numérique
:::

::: etape Calcul
$$T(10) = 60 e^{-0,1 \times 10} + 20 = 60 e^{-1} + 20$$
:::

::: etape Valeur numérique
$$e^{-1} \approx 0,3679$$
:::

::: etape Résultat final
$$T(10) \approx 60 \times 0,3679 + 20 \approx 22,07 + 20 = 42,07°C$$
:::

## Question 4 : Calculer quand la température atteindra $\displaystyle 25°C$

::: methode
Résolution d'équation exponentielle
:::

::: etape Équation à résoudre
$$60 e^{-0,1 t} + 20 = 25$$
:::

::: etape Simplification
$$60 e^{-0,1 t} = 5$$
:::

::: etape Division
$$
\begin{aligned}
e^{-0,1 t} &= \frac{5}{60} \\
&= \frac{1}{12} \approx 0,0833
\end{aligned}
$$
:::

::: etape Application du logarithme
$$-0,1 t = \ln \frac{1}{12} = -\ln 12 \approx -2,485$$
:::

::: etape Calcul du temps
$\displaystyle t = \frac{2,485}{0,1} = 24,85$ minutes
:::

Solution:
<!-- optitab:1 -->
1. Solution générale : $\displaystyle T(t) = C e^{-0,1 t} + 20$
2. Avec $T(0) = 80°C$ : $C = 60$, donc $T(t) = 60 e^{-0,1 t} + 20$
3. $\displaystyle T(10) \approx 42,07°C$
4. $\displaystyle t \approx 24,85$ minutes

=== Entraînement - Équations Différentielles - Séparation des Variables (Température)
Id: 1661
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La température $T(t)$ d'un objet suit l'équation différentielle $T' = -k (T - T_a)$, où $T_a = 25°C$ est la température ambiante et $k = 0,02 \text{ min}^{-1}$.

1. Résoudre l'équation par séparation des variables
2. Déterminer $\displaystyle T(t)$ (avec $\displaystyle T(0) = 100°C$)
3. Calculer la température après 1 heure
4. Déterminer le temps pour atteindre $\displaystyle 30°C$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre par séparation des variables

::: methode
Séparation des variables
:::

::: etape Équation
$$\frac{dT}{dt} = -0,02 (T - 25)$$
:::

::: etape Séparation
$$\frac{dT}{T - 25} = -0,02 dt$$
:::

::: etape Intégration
$$\ln(T - 25) = -0,02 t + K$$
:::

::: etape Forme exponentielle
$$T - 25 = K e^{-0,02 t}$$
:::

::: etape Solution générale
$$T(t) = 25 + K e^{-0,02 t}$$
:::

## Question 2 : Déterminer $\displaystyle T(t)$

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale
$$T(0) = 100$$
:::

::: etape Détermination de la constante
$$100 - 25 = K e^{0} \Rightarrow K = 75$$
:::

::: etape Solution particulière
$$T(t) = 25 + 75 e^{-0,02 t}$$
:::

## Question 3 : Température après 1 heure (60 minutes)

::: methode
Application numérique
:::

::: etape Calcul
$$T(60) = 25 + 75 e^{-0,02 \times 60} = 25 + 75 e^{-1,2}$$
:::

::: etape Valeur numérique
$$e^{-1,2} \approx 0,3012$$
:::

::: etape Résultat final
$$T(60) \approx 25 + 75 \times 0,3012 \approx 25 + 22,59 = 47,59°C$$
:::

## Question 4 : Temps pour atteindre $\displaystyle 30°C$

::: methode
Résolution d'équation exponentielle
:::

::: etape Équation à résoudre
$$25 + 75 e^{-0,02 t} = 30$$
:::

::: etape Simplification
$$75 e^{-0,02 t} = 5$$
:::

::: etape Division
$$e^{-0,02 t} = \frac{5}{75} = 0,0667$$
:::

::: etape Application du logarithme
$$-0,02 t = \ln 0,0667 \approx -2,708$$
:::

::: etape Calcul du temps
$\displaystyle t = \frac{2,708}{0,02} = 135,4$ minutes ≈ 2h15
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle T(t) = 25 + 75 e^{-0,02 t}$
2. $\displaystyle T(t) = 25 + 75 e^{-0,02 t}$
3. $\displaystyle T(60) \approx 47,59°C$
4. $\displaystyle t \approx 135,4$ minutes (2h15)

=== Problème - Équations Différentielles - Croissance Logistique
Id: 1662
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une population suit la loi logistique $\displaystyle P' = 0,1 P (1 - P/1000)$, où 1000 est la capacité maximale.

1. Résoudre l'équation différentielle par séparation des variables
2. Déterminer $\displaystyle P(t)$ (avec $\displaystyle P(0) = 100$)
3. Calculer la population après 20 unités de temps
4. Étudier le comportement à long terme

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre par séparation des variables

::: methode
Séparation des variables avec fractions partielles
:::

::: etape Équation différentielle
$$\frac{dP}{dt} = 0,1 P (1 - P/1000)$$
:::

::: etape Séparation
$$\frac{dP}{P(1 - P/1000)} = 0,1 \, dt$$
:::

::: etape Réécriture de la fraction
$$\frac{1}{P(1 - P/1000)} = \frac{1000}{P(1000 - P)}$$
:::

::: etape Décomposition en fractions partielles
$$\frac{1000}{P(1000 - P)} = \frac{A}{P} + \frac{B}{1000 - P}$$
:::

::: etape Résolution
$\displaystyle A(1000 - P) + B P = 1000$

Pour $P=0$ : $A = 1$

Pour $P=1000$ : $B = 1$
:::

::: etape Intégration
$$\frac{1}{P} + \frac{1}{1000 - P} = 0,1 \, dt$$
:::

::: etape Calcul des intégrales
$$\int \frac{dP}{P} + \int \frac{dP}{1000 - P} = 0,1 \int dt$$
:::

::: etape Résultat
$$\ln|P| - \ln|1000 - P| = 0,1 t + C$$
:::

::: etape Simplification
$$\ln \left| \frac{P}{1000 - P} \right| = 0,1 t + C$$
:::

::: etape Forme exponentielle
$\frac{P}{1000 - P} = K e^{0,1 t}$ (où $K = e^C$)
:::

::: etape Résolution pour $\displaystyle P(t)$
$$P = K e^{0,1 t} (1000 - P)$$
:::

::: etape Développement
$$P = 1000 K e^{0,1 t} - K e^{0,1 t} P$$
:::

::: etape Regroupement
$$P + K e^{0,1 t} P = 1000 K e^{0,1 t}$$
:::

::: etape Factorisation
$$P (1 + K e^{0,1 t}) = 1000 K e^{0,1 t}$$
:::

::: etape Solution générale
$$P(t) = \frac{1000 K e^{0,1 t}}{1 + K e^{0,1 t}}$$
:::

## Question 2 : Déterminer $\displaystyle P(t)$

::: methode
Utilisation de la condition initiale
:::

::: etape Condition initiale
$$P(0) = 100$$
:::

::: etape Substitution
$$100 = \frac{1000 K}{1 + K}$$
:::

::: etape Résolution
$$100 (1 + K) = 1000 K$$
:::

::: etape Développement
$$100 + 100 K = 1000 K$$
:::

::: etape Simplification
$$100 = 900 K$$
:::

::: etape Constante
$$K = \frac{100}{900} = \frac{1}{9}$$
:::

::: etape Solution particulière
$$
\begin{aligned}
P(t) &= \frac{1000 \times (1/9) e^{0,1 t}}{1 + (1/9) e^{0,1 t}} \\
&= \frac{(1000/9) e^{0,1 t}}{1 + (1/9) e^{0,1 t}} \\
&= \frac{1000 e^{0,1 t}}{9 + e^{0,1 t}}
\end{aligned}
$$
:::

## Question 3 : Population après 20 unités de temps

::: methode
Application numérique
:::

::: etape Calcul
$$
\begin{aligned}
P(20) &= \frac{1000 e^{0,1 \times 20}}{9 + e^{2}} \\
&= \frac{1000 e^{2}}{9 + e^{2}} \\
&= \frac{1000 \times 7,389}{9 + 7,389} \\
&= \frac{7389}{16,389} \approx 450,9
\end{aligned}
$$
:::

## Question 4 : Comportement à long terme

::: methode
Calcul de limite
:::

::: etape Limite
$$
\begin{aligned}
\lim_{t \to +\infty} P(t) &= \frac{1000 \times \infty}{9 + \infty} \\
&= 1000
\end{aligned}
$$
:::

::: etape Interprétation
La population tend vers la capacité maximale de 1000
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle P(t) = \frac{1000 e^{0,1 t}}{9 + e^{0,1 t}}$
2. $\displaystyle P(t) = \frac{1000 e^{0,1 t}}{9 + e^{0,1 t}}$
3. $\displaystyle P(20) \approx 450,9$
4. $\displaystyle\lim_{t \to +\infty} P(t) = 1000$
