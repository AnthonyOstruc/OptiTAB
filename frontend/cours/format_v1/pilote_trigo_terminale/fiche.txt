Titre: Résumé : Fonctions sinus et cosinus

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : dérivées, variations, équations et étude des fonctions trigonométriques. Programme de Terminale.
:::

## I. Dérivées

::: formule
$(\sin x)' = \cos x$ et $(\cos x)' = -\sin x$
:::

[IMAGE_1]

1. $\big(\sin(ax + b)\big)' = a\cos(ax + b)$ ; $\big(\cos(ax + b)\big)' = -a\sin(ax + b)$.
2. $\displaystyle \lim\limits_{x \to 0} \frac{\sin x}{x} = 1$.
3. Périodes : $2\pi$ pour $\sin x$, $\frac{2\pi}{a}$ pour $\sin(ax)$.

## II. Variations et équations

::: tableau Variations de $\cos$ sur $[-\pi\,;\pi]$
x : -\pi, 0, \pi
-\sin(x) : , +, z, -,
\cos(x) : -/-1, +/1, -/-1
:::

1. $\displaystyle \cos x = \cos a \iff x = \pm a + 2k\pi$.
2. $\sin x = \sin a \iff x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$.
3. Inéquations : lecture sur le cercle trigonométrique.

## III. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Oublier le signe moins : $\displaystyle (\cos x)' = -\sin x$.
2. Oublier le facteur $a$ en dérivant $\cos(ax + b)$.
3. Ne donner qu’une solution sur un tour complet.
4. Chercher une limite de $\cos x$ en $+\infty$ : elle n’existe pas.
:::

::: remarque Réflexe
Fonction trigonométrique à étudier → période et parité d’abord, puis étude sur une demi-période.
:::
