=== Découverte - Traduire une phrase par une expression
Id: 2579
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
En calcul littéral, on peut supprimer le signe $\times$ devant une lettre ou une parenthèse, et $x \times x$ s'écrit $x^2$.

1. Écrire plus simplement $3 \times x$, $x \times x$, $1 \times y$ et $x \times 7$.
2. Écrire plus simplement $2 \times a \times 5$ et $x \times 4 \times x$.
3. Traduire par une expression : « le double de $x$, augmenté de $3$ ».
4. Traduire : « la somme de $x$ et de son triple ». Réduire l'expression obtenue.
5. Traduire : « le carré de la somme de $x$ et de $1$ ».
6. Traduire par une phrase l'expression $4(x - 2)$, puis l'expression $4x - 2$. Sont-elles égales ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Appliquer les conventions

::: methode
On supprime le signe $\times$ devant une lettre et on écrit le nombre en premier.
:::

::: etape Les quatre écritures
- $3 \times x = 3x$ ;
- $x \times x = x^2$ (« $x$ au carré ») ;
- $1 \times y = y$ (multiplier par $1$ ne change rien) ;
- $x \times 7 = 7x$ (le nombre s'écrit devant la lettre).
:::

::: resultat
$3x$ ; $x^2$ ; $y$ ; $7x$
:::

## Question 2 : Simplifier des produits

::: methode
Dans un produit, on peut changer l'ordre des facteurs : on regroupe les nombres d'un côté, les lettres de l'autre.
:::

::: etape Premier produit
$$2 \times a \times 5 = 2 \times 5 \times a = 10a$$
:::

::: etape Second produit
$$x \times 4 \times x = 4 \times x \times x = 4x^2$$
:::

::: resultat
$2 \times a \times 5 = 10a$ et $x \times 4 \times x = 4x^2$.
:::

## Question 3 : Le double augmenté de $3$

::: methode
On repère la dernière opération : « augmenté de » est une addition, effectuée en dernier.
:::

::: etape Traduire morceau par morceau
Le double de $x$ s'écrit $2x$ ; augmenté de $3$, on obtient $2x + 3$.
:::

::: resultat
$$2x + 3$$
:::

## Question 4 : Un nombre et son triple

::: etape Traduire
Le triple de $x$ est $3x$ ; la somme de $x$ et de son triple est $x + 3x$.
:::

::: etape Réduire
$x = 1x$, donc $x + 3x = 1x + 3x = 4x$.
:::

::: resultat
$$x + 3x = 4x$$
:::

## Question 5 : Le carré d'une somme

::: methode
La dernière opération est le carré : il porte sur **toute** la somme, qu'il faut donc mettre entre parenthèses.
:::

::: etape Traduire
La somme de $x$ et de $1$ s'écrit $x + 1$ ; son carré est $(x + 1)^2$.
:::

::: resultat
$$(x + 1)^2$$
:::

::: attention Erreur fréquente
Écrire $x + 1^2$ : le carré ne porterait que sur $1$, et l'expression vaudrait simplement $x + 1$.
:::

## Question 6 : De l'expression à la phrase

::: etape L'expression $4(x - 2)$
La dernière opération est la multiplication par $4$ : c'est « le produit de $4$ par la différence de $x$ et de $2$ », ou « le quadruple de la différence de $x$ et de $2$ ».
:::

::: etape L'expression $4x - 2$
La dernière opération est la soustraction : c'est « le quadruple de $x$, diminué de $2$ ».
:::

::: etape Comparer avec une valeur
Pour $x = 5$ : $4(5 - 2) = 4 \times 3 = 12$, alors que $4 \times 5 - 2 = 20 - 2 = 18$.
:::

::: resultat
$4(x - 2)$ : le quadruple de la différence de $x$ et de $2$ ; $4x - 2$ : le quadruple de $x$, diminué de $2$. Elles ne sont pas égales ($12 \neq 18$ pour $x = 5$).
:::

::: retenir
Pour lire une expression, on cherche la **dernière** opération effectuée : elle donne son nom (somme, différence, produit, carré).
:::

Solution:
<!-- optitab:1 -->
1. $3x$ ; $x^2$ ; $y$ ; $7x$
2. $10a$ ; $4x^2$
3. $2x + 3$
4. $x + 3x = 4x$
5. $(x + 1)^2$
6. Le quadruple de $x - 2$ ; le quadruple de $x$ diminué de $2$ ; non égales

=== Découverte - Calculer la valeur d'une expression
Id: 2580
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère les expressions $A = 3x^2 - 2x + 5$ et $B = (2x - 1)(x + 3)$.

1. Calculer $A$ pour $x = 2$.
2. Calculer $A$ pour $x = -1$.
3. Calculer $A$ pour $x = 0$, puis pour $x = 0{,}5$.
4. Calculer $B$ pour $x = 2$.
5. Calculer $B$ pour $x = -3$. Pourquoi ce résultat était-il prévisible ?
6. Léo a calculé $A$ pour $x = -2$ et a trouvé $13$. Trouver son erreur et donner le bon résultat.

Étapes:
<!-- optitab:1 -->
## Question 1 : $A$ pour $x = 2$

::: methode
On remplace $x$ par sa valeur, on rétablit les signes $\times$ sous-entendus, puis on respecte les priorités : puissances, produits, puis sommes et différences.
:::

::: etape Remplacer et calculer
$$
\begin{aligned}
A &= 3 \times 2^2 - 2 \times 2 + 5 \\
&= 3 \times 4 - 4 + 5 \\
&= 12 - 4 + 5 \\
&= 13
\end{aligned}
$$
:::

::: resultat
Pour $x = 2$, $A = 13$.
:::

## Question 2 : $A$ pour $x = -1$

::: etape Remplacer, entre parenthèses
$$
\begin{aligned}
A &= 3 \times (-1)^2 - 2 \times (-1) + 5 \\
&= 3 \times 1 + 2 + 5 \\
&= 10
\end{aligned}
$$
On a utilisé $(-1)^2 = (-1) \times (-1) = 1$ et $-2 \times (-1) = +2$.
:::

::: resultat
Pour $x = -1$, $A = 10$.
:::

::: attention Erreur fréquente
Écrire $3 \times -1^2$ sans parenthèses : on calculerait $-1^2 = -1$ et on trouverait un faux résultat.
:::

## Question 3 : $A$ pour $x = 0$ et pour $x = 0{,}5$

::: etape Pour $x = 0$
$A = 3 \times 0^2 - 2 \times 0 + 5 = 0 - 0 + 5 = 5$.
:::

::: etape Pour $x = 0{,}5$
$$
\begin{aligned}
A &= 3 \times 0{,}5^2 - 2 \times 0{,}5 + 5 \\
&= 3 \times 0{,}25 - 1 + 5 \\
&= 0{,}75 - 1 + 5 \\
&= 4{,}75
\end{aligned}
$$
:::

::: resultat
Pour $x = 0$, $A = 5$ ; pour $x = 0{,}5$, $A = 4{,}75$.
:::

## Question 4 : $B$ pour $x = 2$

::: methode
$B$ est un produit : on calcule chaque parenthèse, puis on multiplie.
:::

::: etape Les deux facteurs
$2 \times 2 - 1 = 3$ et $2 + 3 = 5$.
:::

::: resultat
Pour $x = 2$, $B = 3 \times 5 = 15$.
:::

## Question 5 : $B$ pour $x = -3$

::: etape Les deux facteurs
$2 \times (-3) - 1 = -6 - 1 = -7$ et $-3 + 3 = 0$.
:::

::: etape Le produit
$B = (-7) \times 0 = 0$.
:::

::: resultat
Pour $x = -3$, $B = 0$. C'était prévisible : le facteur $x + 3$ est nul pour $x = -3$, et un produit dont un facteur est nul est nul.
:::

## Question 6 : L'erreur de Léo

::: etape Le bon calcul
$$
\begin{aligned}
A &= 3 \times (-2)^2 - 2 \times (-2) + 5 \\
&= 3 \times 4 + 4 + 5 \\
&= 21
\end{aligned}
$$
:::

::: etape Retrouver l'erreur
Léo a calculé $3 \times 4 - 4 + 5 = 13$ : il a écrit $-2 \times (-2) = -4$. Or deux nombres de même signe ont un produit positif : $-2 \times (-2) = +4$.
:::

::: resultat
Léo s'est trompé de signe sur $-2 \times (-2)$ ; le bon résultat est $A = 21$.
:::

::: retenir
Pour remplacer une lettre par un nombre négatif, on l'écrit **entre parenthèses**, puis on applique la règle des signes à chaque produit.
:::

Solution:
<!-- optitab:1 -->
1. $A = 13$
2. $A = 10$
3. $5$ ; $4{,}75$
4. $B = 15$
5. $B = 0$ (le facteur $x + 3$ est nul)
6. Erreur de signe sur $-2 \times (-2)$ ; $A = 21$

=== Découverte - Réduire une expression
Id: 2581
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Réduire une expression, c'est l'écrire avec le moins de termes possible, en regroupant les termes de même nature.

1. Réduire $3x + 5x$.
2. Réduire $7a - 2 + 3a + 9$.
3. Réduire $4x^2 + 3x - x^2 + x$.
4. Réduire $5y - 8y + 2$.
5. Réduire les produits $2x \times 3x$ et $5 \times (-4x)$.
6. Expliquer la différence entre $x + x$ et $x \times x$, en testant avec $x = 5$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Une somme de termes en $x$

::: etape Compter les $x$
$3$ fois $x$ plus $5$ fois $x$, c'est $3 + 5 = 8$ fois $x$.
:::

::: resultat
$$3x + 5x = 8x$$
:::

## Question 2 : Des lettres et des nombres

::: methode
On regroupe les termes en $a$ entre eux et les nombres entre eux.
:::

::: etape Regrouper
$$
\begin{aligned}
7a - 2 + 3a + 9 &= (7a + 3a) + (-2 + 9) \\
&= 10a + 7
\end{aligned}
$$
:::

::: resultat
$$7a - 2 + 3a + 9 = 10a + 7$$
:::

::: attention Erreur fréquente
Écrire $17a$ : $10a$ et $7$ ne sont pas de même nature, ils ne s'additionnent pas.
:::

## Question 3 : Des termes en $x^2$ et en $x$

::: etape Regrouper
$$
\begin{aligned}
4x^2 + 3x - x^2 + x &= (4x^2 - x^2) + (3x + x) \\
&= 3x^2 + 4x
\end{aligned}
$$
On utilise $-x^2 = -1x^2$ et $x = 1x$.
:::

::: resultat
$$4x^2 + 3x - x^2 + x = 3x^2 + 4x$$
:::

## Question 4 : Un coefficient négatif

::: etape Regrouper les termes en $y$
$5y - 8y = (5 - 8)y = -3y$ ; le nombre $2$ reste seul.
:::

::: resultat
$$5y - 8y + 2 = -3y + 2$$
:::

## Question 5 : Des produits

::: methode
Dans un produit, on multiplie les nombres entre eux, puis les lettres entre elles.
:::

::: etape Premier produit
$$2x \times 3x = 2 \times 3 \times x \times x = 6x^2$$
:::

::: etape Second produit
$$5 \times (-4x) = 5 \times (-4) \times x = -20x$$
:::

::: resultat
$2x \times 3x = 6x^2$ et $5 \times (-4x) = -20x$.
:::

## Question 6 : Somme ou produit ?

::: etape $x + x$
On ajoute deux fois $x$ : $x + x = 2x$. Pour $x = 5$ : $5 + 5 = 10$.
:::

::: etape $x \times x$
On multiplie $x$ par lui-même : $x \times x = x^2$. Pour $x = 5$ : $5 \times 5 = 25$.
:::

::: resultat
$x + x = 2x$ alors que $x \times x = x^2$ : pour $x = 5$, on obtient $10$ d'un côté et $25$ de l'autre.
:::

::: retenir
Un test avec une valeur simple permet de détecter une erreur de réduction : si les deux expressions donnent des nombres différents, elles ne sont pas égales.
:::

Solution:
<!-- optitab:1 -->
1. $8x$
2. $10a + 7$
3. $3x^2 + 4x$
4. $-3y + 2$
5. $6x^2$ ; $-20x$
6. $x + x = 2x$ ; $x \times x = x^2$ (pour $x = 5$ : $10$ et $25$)

=== Découverte - Compter des allumettes
Id: 2582
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On aligne des carrés construits avec des allumettes, comme sur la figure.

[IMAGE_1]

1. Combien faut-il d'allumettes pour $1$, $2$ et $3$ carrés ? Pour $4$ et $5$ carrés ?
2. Montrer que, pour $n$ carrés, il faut $3n + 1$ allumettes.
3. Un camarade propose l'expression $4 + 3(n - 1)$. A-t-il raison ? Justifier par un calcul.
4. Combien d'allumettes faut-il pour $100$ carrés ?
5. Avec $61$ allumettes, combien de carrés peut-on construire ?
6. Peut-on utiliser exactement $100$ allumettes ? Si oui, pour combien de carrés ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compter les allumettes

::: etape Lire la figure
$1$ carré : $4$ allumettes ; $2$ carrés : $7$ ; $3$ carrés : $10$.
:::

::: etape Continuer la régularité
Chaque carré ajouté réutilise un côté du carré précédent : il demande $3$ allumettes de plus. $4$ carrés : $10 + 3 = 13$ ; $5$ carrés : $13 + 3 = 16$.
:::

::: resultat
$4$ ; $7$ ; $10$ ; $13$ ; $16$ allumettes.
:::

## Question 2 : L'expression $3n + 1$

::: methode
On compte d'une façon qui fonctionne pour n'importe quel nombre $n$ de carrés.
:::

::: etape Découper la rangée
On place d'abord une allumette verticale (en orange) ; chaque carré ajoute ensuite $3$ allumettes : en haut, en bas et à droite (en vert).
:::

[IMAGE_2]

::: etape Traduire
Pour $n$ carrés : $1 + 3 \times n = 3n + 1$ allumettes.
:::

::: point Vérification
Pour $n = 3$ : $3 \times 3 + 1 = 10$, comme sur la figure.
:::

::: resultat
Pour $n$ carrés, il faut $3n + 1$ allumettes.
:::

## Question 3 : Une autre expression

::: methode
Deux expressions sont égales si l'une se transforme en l'autre : on développe et on réduit.
:::

::: etape Développer et réduire
$$
\begin{aligned}
4 + 3(n - 1) &= 4 + 3n - 3 \\
&= 3n + 1
\end{aligned}
$$
:::

::: resultat
Oui, il a raison : $4 + 3(n - 1) = 3n + 1$. Il compte $4$ allumettes pour le premier carré, puis $3$ pour chacun des $n - 1$ carrés suivants.
:::

::: retenir
Deux façons de compter peuvent donner deux expressions différentes mais égales : on le prouve en développant et en réduisant.
:::

## Question 4 : Pour $100$ carrés

::: etape Remplacer $n$ par $100$
$3 \times 100 + 1 = 300 + 1 = 301$.
:::

::: resultat
Il faut $301$ allumettes.
:::

## Question 5 : Avec $61$ allumettes

::: methode
On cherche $n$ tel que $3n + 1 = 61$ : on « remonte » les calculs.
:::

::: etape Remonter les calculs
$3n + 1 = 61$, donc $3n = 61 - 1 = 60$, puis $n = 60 : 3 = 20$.
:::

::: point Vérification
$3 \times 20 + 1 = 61$.
:::

::: resultat
Avec $61$ allumettes, on construit $20$ carrés.
:::

## Question 6 : Exactement $100$ allumettes ?

::: etape Remonter les calculs
$3n + 1 = 100$, donc $3n = 99$, puis $n = 99 : 3 = 33$, qui est bien un nombre entier.
:::

::: resultat
Oui : avec $33$ carrés, on utilise $3 \times 33 + 1 = 100$ allumettes.
:::

::: attention Erreur fréquente
Croire que $100$ est impossible parce que $100$ n'est pas un multiple de $3$ : c'est $100 - 1 = 99$ qui doit être un multiple de $3$.
:::

Solution:
<!-- optitab:1 -->
1. $4$ ; $7$ ; $10$ ; $13$ ; $16$
2. $1 + 3n = 3n + 1$
3. Oui : $4 + 3(n - 1) = 3n + 1$
4. $301$ allumettes
5. $20$ carrés
6. Oui, $33$ carrés

=== Découverte - Développer avec la simple distributivité
Id: 2583
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le grand rectangle ci-dessous a pour largeur $3$ et pour longueur $x + 4$. Son aire peut s'écrire $3(x + 4)$, ou comme la somme des aires des deux petits rectangles.

[IMAGE_1]

1. Écrire l'aire de chaque petit rectangle, puis développer $3(x + 4)$.
2. Développer $5(2a - 3)$.
3. Développer $-2(x - 6)$.
4. Développer $x(x + 5)$.
5. Développer $-(3x - 7)$.
6. Développer, puis réduire $4(2x + 1) - 3(x - 2)$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le modèle des aires

::: etape Les deux petits rectangles
Le rectangle de gauche mesure $3$ sur $x$ : son aire est $3 \times x = 3x$. Celui de droite mesure $3$ sur $4$ : son aire est $3 \times 4 = 12$.
:::

[IMAGE_2]

::: etape Comparer les deux écritures de l'aire
L'aire du grand rectangle vaut $3(x + 4)$, et aussi $3x + 12$.
:::

::: resultat
$$3(x + 4) = 3x + 12$$
:::

## Question 2 : Avec une soustraction

::: methode
$k(a - b) = ka - kb$ : on multiplie $5$ par chaque terme de la parenthèse.
:::

::: etape Distribuer
$$5(2a - 3) = 5 \times 2a - 5 \times 3 = 10a - 15$$
:::

::: resultat
$$5(2a - 3) = 10a - 15$$
:::

## Question 3 : Un facteur négatif

::: methode
On multiplie $-2$ par chaque terme, en appliquant la règle des signes.
:::

::: etape Distribuer
$-2 \times x = -2x$ et $-2 \times (-6) = +12$.
:::

::: resultat
$$-2(x - 6) = -2x + 12$$
:::

::: attention Erreur fréquente
Écrire $-2x - 12$ : le produit $(-2) \times (-6)$ est **positif**, il vaut $+12$.
:::

## Question 4 : Un facteur littéral

::: etape Distribuer
$$x(x + 5) = x \times x + x \times 5 = x^2 + 5x$$
:::

::: resultat
$$x(x + 5) = x^2 + 5x$$
:::

## Question 5 : Le signe moins devant une parenthèse

::: methode
$-(3x - 7)$ signifie $-1 \times (3x - 7)$ : le signe « $-$ » change le signe de chaque terme.
:::

::: etape Distribuer $-1$
$-1 \times 3x = -3x$ et $-1 \times (-7) = +7$.
:::

::: resultat
$$-(3x - 7) = -3x + 7$$
:::

## Question 6 : Deux développements, puis réduire

::: etape Développer chaque produit
$4(2x + 1) = 8x + 4$ et $-3(x - 2) = -3x + 6$.
:::

::: etape Réduire
$$
\begin{aligned}
4(2x + 1) - 3(x - 2) &= 8x + 4 - 3x + 6 \\
&= 5x + 10
\end{aligned}
$$
:::

::: point Vérification
Pour $x = 1$ : $4 \times 3 - 3 \times (-1) = 12 + 3 = 15$ et $5 \times 1 + 10 = 15$.
:::

::: resultat
$$4(2x + 1) - 3(x - 2) = 5x + 10$$
:::

::: attention Erreur fréquente
Écrire $-3(x - 2) = -3x - 6$ : on oublie que $(-3) \times (-2) = +6$.
:::

Solution:
<!-- optitab:1 -->
1. $3x$ et $12$ ; $3(x + 4) = 3x + 12$
2. $10a - 15$
3. $-2x + 12$
4. $x^2 + 5x$
5. $-3x + 7$
6. $5x + 10$

=== Découverte - Factoriser avec un facteur commun
Id: 2584
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Factoriser une somme, c'est l'écrire comme un produit, en repérant un facteur commun : $ka + kb = k(a + b)$.

Le rectangle ci-dessous a pour largeur $5$. Il est formé de deux rectangles d'aires $5x$ et $15$.

[IMAGE_1]

1. Quelles sont les longueurs des deux petits rectangles ? En déduire la longueur du grand rectangle, puis une factorisation de $5x + 15$.
2. Factoriser $12a - 18$ avec le plus grand facteur commun possible.
3. Factoriser $x^2 + 7x$.
4. Factoriser $3x^2 - 6x$.
5. Factoriser $7y + 7$.
6. Vérifier les réponses des questions 2 et 4 en développant.

Étapes:
<!-- optitab:1 -->
## Question 1 : Retrouver les dimensions

::: methode
Aire d'un rectangle $=$ largeur $\times$ longueur : on cherche le nombre qui, multiplié par $5$, donne chaque aire.
:::

::: etape Les deux longueurs
$5 \times x = 5x$ : la longueur du rectangle de gauche est $x$. $5 \times 3 = 15$ : celle du rectangle de droite est $3$.
:::

[IMAGE_2]

::: etape Le grand rectangle
Sa longueur est $x + 3$ et sa largeur $5$ : son aire vaut $5(x + 3)$. C'est aussi $5x + 15$.
:::

::: resultat
$$5x + 15 = 5(x + 3)$$
:::

## Question 2 : Le plus grand facteur commun

::: methode
On cherche le plus grand nombre qui divise à la fois $12$ et $18$ : c'est $6$.
:::

::: etape Faire apparaître le facteur commun
$$12a - 18 = 6 \times 2a - 6 \times 3 = 6(2a - 3)$$
:::

::: resultat
$$12a - 18 = 6(2a - 3)$$
:::

::: attention Erreur fréquente
Écrire $2(6a - 9)$ : c'est juste, mais incomplet, car $6a - 9$ se factorise encore par $3$.
:::

## Question 3 : Une lettre en facteur

::: etape Faire apparaître le facteur commun
$$x^2 + 7x = x \times x + x \times 7 = x(x + 7)$$
:::

::: resultat
$$x^2 + 7x = x(x + 7)$$
:::

## Question 4 : Un nombre et une lettre en facteur

::: etape Écrire chaque terme comme un produit
$3x^2 = 3x \times x$ et $6x = 3x \times 2$ : le facteur commun est $3x$.
:::

::: etape Factoriser
$$3x^2 - 6x = 3x \times x - 3x \times 2 = 3x(x - 2)$$
:::

::: resultat
$$3x^2 - 6x = 3x(x - 2)$$
:::

## Question 5 : Un facteur caché

::: etape Écrire $7$ comme un produit
$7 = 7 \times 1$, donc $7y + 7 = 7 \times y + 7 \times 1$.
:::

::: resultat
$$7y + 7 = 7(y + 1)$$
:::

::: attention Erreur fréquente
Écrire $7y + 7 = 7y$ ou $7(y + 0)$ : quand un terme est égal au facteur commun, il reste $1$ dans la parenthèse.
:::

## Question 6 : Vérifier en développant

::: etape Question 2
$6(2a - 3) = 6 \times 2a - 6 \times 3 = 12a - 18$.
:::

::: etape Question 4
$3x(x - 2) = 3x \times x - 3x \times 2 = 3x^2 - 6x$.
:::

::: resultat
On retrouve les expressions de départ : les deux factorisations sont justes.
:::

::: retenir
Factoriser est l'opération inverse de développer : on contrôle toujours une factorisation en redéveloppant.
:::

Solution:
<!-- optitab:1 -->
1. $x$ et $3$ ; longueur $x + 3$ ; $5x + 15 = 5(x + 3)$

=== Découverte - Dire si une égalité est vraie ou fausse
Id: 2585
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pour chaque égalité, dire si elle est vraie pour tous les nombres $x$, ou fausse. Justifier.

1. $(x + 3)^2 = x^2 + 9$
2. $2(x + 5) = 2x + 10$
3. $x^2 \geqslant x$ pour tout nombre $x$.
4. $3x + 2x = 5x^2$. Tester d'abord avec $x = 1$, puis avec $x = 2$.
5. $-(x - 4) = -x - 4$
6. $x(x + 1) - x = x^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Le carré d'une somme

::: methode
Pour montrer qu'une égalité est fausse, il suffit d'un **contre-exemple** : une valeur de $x$ pour laquelle les deux membres sont différents.
:::

::: etape Tester $x = 1$
$(1 + 3)^2 = 4^2 = 16$ et $1^2 + 9 = 1 + 9 = 10$.
:::

::: resultat
Faux : pour $x = 1$, on obtient $16 \neq 10$.
:::

## Question 2 : Une distributivité

::: methode
Pour montrer qu'une égalité est toujours vraie, on transforme un membre jusqu'à obtenir l'autre.
:::

::: etape Développer
$2(x + 5) = 2 \times x + 2 \times 5 = 2x + 10$.
:::

::: resultat
Vrai pour tout nombre $x$ : c'est la simple distributivité.
:::

## Question 3 : Le carré est-il toujours plus grand ?

::: etape Tester un nombre entre $0$ et $1$
Pour $x = 0{,}5$ : $x^2 = 0{,}5 \times 0{,}5 = 0{,}25$, et $0{,}25 < 0{,}5$.
:::

::: resultat
Faux : pour $x = 0{,}5$, le carré est plus petit que le nombre.
:::

## Question 4 : Un test qui trompe

::: etape Tester $x = 1$
$3 \times 1 + 2 \times 1 = 5$ et $5 \times 1^2 = 5$ : l'égalité est vraie pour cette valeur.
:::

::: etape Tester $x = 2$
$3 \times 2 + 2 \times 2 = 10$ et $5 \times 2^2 = 20$ : $10 \neq 20$.
:::

::: resultat
Faux : $3x + 2x = 5x$, et non $5x^2$. Le test avec $x = 1$ ne prouvait rien.
:::

::: retenir
Un exemple qui marche ne prouve pas qu'une égalité est toujours vraie ; un seul contre-exemple prouve qu'elle est fausse.
:::

## Question 5 : Le signe moins

::: etape Développer
$-(x - 4) = -x + 4$ : le signe « $-$ » change le signe de chaque terme.
:::

::: etape Contre-exemple
Pour $x = 0$ : $-(0 - 4) = 4$ et $-0 - 4 = -4$.
:::

::: resultat
Faux : on a oublié de changer le signe de $-4$.
:::

## Question 6 : Une égalité à démontrer

::: etape Développer et réduire le membre de gauche
$$
\begin{aligned}
x(x + 1) - x &= x^2 + x - x \\
&= x^2
\end{aligned}
$$
:::

::: resultat
Vrai pour tout nombre $x$.
:::

::: attention Erreur fréquente
Se contenter de vérifier l'égalité pour deux ou trois valeurs : seul le calcul littéral la prouve pour **tous** les nombres.
:::

Solution:
<!-- optitab:1 -->
1. Faux ($x = 1$ : $16 \neq 10$)
2. Vrai
3. Faux ($x = 0{,}5$ : $0{,}25 < 0{,}5$)
4. Faux ($x = 2$ : $10 \neq 20$)
5. Faux : $-(x - 4) = -x + 4$
6. Vrai

=== Entraînement - Développer avec la double distributivité
Id: 2586
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le grand rectangle ci-dessous a pour dimensions $x + 3$ et $x + 2$. Il est découpé en quatre rectangles.

[IMAGE_1]

1. Exprimer l'aire de chacun des quatre rectangles, puis développer et réduire $(x + 3)(x + 2)$.
2. Développer et réduire $(2x + 1)(x + 4)$.
3. Développer et réduire $(x - 3)(x + 5)$.
4. Développer et réduire $(2a - 1)(3a - 2)$.
5. Développer et réduire $(x + 4)^2$.
6. Vérifier le résultat de la question 1 en remplaçant $x$ par $10$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le modèle des aires

::: methode
L'aire du grand rectangle est égale à la somme des aires des quatre rectangles qui le composent.
:::

::: etape Les quatre aires
$x \times x = x^2$ ; $3 \times x = 3x$ ; $x \times 2 = 2x$ ; $3 \times 2 = 6$.
:::

[IMAGE_2]

::: etape Additionner, puis réduire
$$
\begin{aligned}
(x + 3)(x + 2) &= x^2 + 3x + 2x + 6 \\
&= x^2 + 5x + 6
\end{aligned}
$$
:::

::: resultat
$$(x + 3)(x + 2) = x^2 + 5x + 6$$
:::

## Question 2 : Avec un coefficient

::: methode
Chaque terme de la première parenthèse multiplie chaque terme de la seconde : on écrit les quatre produits, puis on réduit.
:::

::: etape Les quatre produits
$2x \times x = 2x^2$ ; $2x \times 4 = 8x$ ; $1 \times x = x$ ; $1 \times 4 = 4$.
:::

::: etape Réduire
$$
\begin{aligned}
(2x + 1)(x + 4) &= 2x^2 + 8x + x + 4 \\
&= 2x^2 + 9x + 4
\end{aligned}
$$
:::

::: resultat
$$(2x + 1)(x + 4) = 2x^2 + 9x + 4$$
:::

## Question 3 : Avec un signe moins

::: etape Les quatre produits
$x \times x = x^2$ ; $x \times 5 = 5x$ ; $-3 \times x = -3x$ ; $-3 \times 5 = -15$.
:::

::: etape Réduire
$$
\begin{aligned}
(x - 3)(x + 5) &= x^2 + 5x - 3x - 15 \\
&= x^2 + 2x - 15
\end{aligned}
$$
:::

::: resultat
$$(x - 3)(x + 5) = x^2 + 2x - 15$$
:::

## Question 4 : Deux signes moins

::: etape Les quatre produits
$2a \times 3a = 6a^2$ ; $2a \times (-2) = -4a$ ; $-1 \times 3a = -3a$ ; $(-1) \times (-2) = +2$.
:::

::: etape Réduire
$$
\begin{aligned}
(2a - 1)(3a - 2) &= 6a^2 - 4a - 3a + 2 \\
&= 6a^2 - 7a + 2
\end{aligned}
$$
:::

::: resultat
$$(2a - 1)(3a - 2) = 6a^2 - 7a + 2$$
:::

::: attention Erreur fréquente
Écrire $-2$ pour le dernier produit : deux nombres négatifs ont un produit positif, $(-1) \times (-2) = +2$.
:::

## Question 5 : Un carré

::: methode
$(x + 4)^2 = (x + 4)(x + 4)$ : c'est un produit de deux sommes, on applique la double distributivité.
:::

::: etape Les quatre produits
$x \times x = x^2$ ; $x \times 4 = 4x$ ; $4 \times x = 4x$ ; $4 \times 4 = 16$.
:::

::: etape Réduire
$$
\begin{aligned}
(x + 4)^2 &= x^2 + 4x + 4x + 16 \\
&= x^2 + 8x + 16
\end{aligned}
$$
:::

::: resultat
$$(x + 4)^2 = x^2 + 8x + 16$$
:::

::: attention Erreur fréquente
Écrire $(x + 4)^2 = x^2 + 16$ : on oublie les deux produits $4x$. Pour $x = 1$, on aurait $25 \neq 17$.
:::

## Question 6 : Vérifier avec $x = 10$

::: etape Avant le développement
$(10 + 3)(10 + 2) = 13 \times 12 = 156$.
:::

::: etape Après le développement
$$
\begin{aligned}
10^2 + 5 \times 10 + 6 &= 100 + 50 + 6 \\
&= 156
\end{aligned}
$$
:::

::: resultat
On trouve $156$ dans les deux cas : le développement de la question 1 est confirmé.
:::

::: retenir
Tester avec $x = 10$ est très efficace : les termes en $x^2$, en $x$ et les nombres se lisent comme des centaines, des dizaines et des unités.
:::

Solution:
<!-- optitab:1 -->
1. $x^2 + 5x + 6$
2. $2x^2 + 9x + 4$
3. $x^2 + 2x - 15$
4. $6a^2 - 7a + 2$
5. $x^2 + 8x + 16$
6. $156$ dans les deux cas

=== Entraînement - Exprimer le périmètre et l'aire d'un rectangle
Id: 2587
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un rectangle a pour longueur $2x + 3$ et pour largeur $x$ (en cm), avec $x > 0$.

[IMAGE_1]

1. Exprimer le périmètre $P$ du rectangle en fonction de $x$, sous forme réduite.
2. Exprimer l'aire $A$ du rectangle en fonction de $x$, sous forme développée.
3. Calculer le périmètre et l'aire pour $x = 4$.
4. Pour quelle valeur de $x$ le périmètre vaut-il $42$ cm ?
5. Calculer alors l'aire du rectangle.
6. Quand $x$ double (de $4$ à $8$), l'aire double-t-elle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le périmètre

::: methode
Périmètre d'un rectangle $= 2 \times (\text{longueur} + \text{largeur})$.
:::

::: etape Écrire, puis réduire
$$
\begin{aligned}
P &= 2(2x + 3 + x) \\
&= 2(3x + 3) \\
&= 6x + 6
\end{aligned}
$$
:::

::: resultat
$$P = 6x + 6$$
:::

## Question 2 : L'aire

::: methode
Aire d'un rectangle $=$ longueur $\times$ largeur, puis on développe avec la simple distributivité.
:::

::: etape Développer
$$A = x(2x + 3) = x \times 2x + x \times 3 = 2x^2 + 3x$$
:::

[IMAGE_2]

::: resultat
$$A = 2x^2 + 3x$$
:::

## Question 3 : Pour $x = 4$

::: etape Le périmètre
$P = 6 \times 4 + 6 = 24 + 6 = 30$.
:::

::: etape L'aire
$A = 2 \times 4^2 + 3 \times 4 = 2 \times 16 + 12 = 44$.
:::

::: point Vérification
Pour $x = 4$, le rectangle mesure $2 \times 4 + 3 = 11$ cm sur $4$ cm : $2 \times (11 + 4) = 30$ et $11 \times 4 = 44$.
:::

::: resultat
Pour $x = 4$ : $P = 30$ cm et $A = 44$ cm².
:::

## Question 4 : Un périmètre de $42$ cm

::: methode
On cherche $x$ tel que $6x + 6 = 42$ : on « remonte » les calculs.
:::

::: etape Remonter les calculs
$6x + 6 = 42$, donc $6x = 42 - 6 = 36$, puis $x = 36 : 6 = 6$.
:::

::: resultat
Le périmètre vaut $42$ cm pour $x = 6$.
:::

## Question 5 : L'aire correspondante

::: etape Remplacer $x$ par $6$
$A = 2 \times 6^2 + 3 \times 6 = 2 \times 36 + 18 = 90$.
:::

::: point Vérification
Le rectangle mesure $15$ cm sur $6$ cm, et $15 \times 6 = 90$.
:::

::: resultat
L'aire vaut alors $90$ cm².
:::

## Question 6 : Doubler $x$

::: etape Pour $x = 8$
$A = 2 \times 8^2 + 3 \times 8 = 128 + 24 = 152$.
:::

::: etape Comparer
Si l'aire doublait, elle vaudrait $2 \times 44 = 88$ cm². Or elle vaut $152$ cm².
:::

::: resultat
Non : quand $x$ passe de $4$ à $8$, l'aire passe de $44$ cm² à $152$ cm², elle fait bien plus que doubler.
:::

::: attention Erreur fréquente
Croire que l'aire est proportionnelle à $x$ : elle contient un terme en $x^2$, qui est multiplié par $4$ quand $x$ double.
:::

Solution:
<!-- optitab:1 -->
1. $P = 6x + 6$
2. $A = 2x^2 + 3x$
3. $30$ cm ; $44$ cm²
4. $x = 6$
5. $90$ cm²
6. Non : $44$ cm² $\to$ $152$ cm²

=== Entraînement - Comparer deux programmes de calcul
Id: 2588
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère les deux programmes de calcul suivants.

[IMAGE_1]

1. Appliquer les deux programmes au nombre $5$.
2. Appliquer les deux programmes au nombre $-2$.
3. On note $x$ le nombre de départ. Écrire l'expression obtenue avec le programme A, puis la réduire.
4. Écrire l'expression obtenue avec le programme B, puis la réduire.
5. Que peut-on conclure ?
6. Programme C : « Choisir un nombre. Le multiplier par la somme de ce nombre et de $2$. Soustraire le carré du nombre de départ. » Montrer qu'il donne toujours le même résultat que A et B.

Étapes:
<!-- optitab:1 -->
## Question 1 : Avec $5$

::: methode
On applique les étapes dans l'ordre, une ligne par étape.
:::

::: etape Programme A
$5 + 3 = 8$ ; $8 \times 2 = 16$ ; $16 - 6 = 10$.
:::

::: etape Programme B
$5 \times 4 = 20$ ; $20 - 5 = 15$ ; $15 - 5 = 10$.
:::

::: resultat
Avec $5$, les deux programmes donnent $10$.
:::

## Question 2 : Avec $-2$

::: etape Programme A
$-2 + 3 = 1$ ; $1 \times 2 = 2$ ; $2 - 6 = -4$.
:::

::: etape Programme B
$(-2) \times 4 = -8$ ; $-8 - (-2) = -8 + 2 = -6$ ; $-6 - (-2) = -6 + 2 = -4$.
:::

::: resultat
Avec $-2$, les deux programmes donnent $-4$.
:::

## Question 3 : Le programme A avec $x$

::: methode
On écrit l'expression obtenue après chaque étape ; on met des parenthèses quand une opération porte sur tout le résultat précédent.
:::

::: etape Traduire
- Choisir un nombre : $x$ ;
- ajouter $3$ : $x + 3$ ;
- multiplier par $2$ : $2(x + 3)$ ;
- soustraire $6$ : $2(x + 3) - 6$.
:::

::: etape Développer et réduire
$$
\begin{aligned}
2(x + 3) - 6 &= 2x + 6 - 6 \\
&= 2x
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
Le programme A donne $2(x + 3) - 6 = 2x$.
:::

::: attention Erreur fréquente
Écrire $x + 3 \times 2 - 6$ : sans parenthèses, seul $3$ serait multiplié par $2$.
:::

## Question 4 : Le programme B avec $x$

::: etape Traduire
- Choisir un nombre : $x$ ;
- multiplier par $4$ : $4x$ ;
- soustraire le nombre de départ : $4x - x$ ;
- le soustraire encore : $4x - x - x$.
:::

::: etape Réduire
$4x - x - x = (4 - 1 - 1)x = 2x$.
:::

[IMAGE_3]

::: resultat
Le programme B donne $4x - x - x = 2x$.
:::

## Question 5 : Conclure

::: etape Comparer les deux expressions
Les deux programmes donnent $2x$, quel que soit le nombre $x$ choisi.
:::

::: resultat
Les programmes A et B donnent toujours le même résultat : le double du nombre de départ.
:::

::: retenir
Des exemples permettent de faire une **conjecture** ; le calcul littéral la **démontre** pour tous les nombres.
:::

## Question 6 : Le programme C

::: etape Traduire
La somme du nombre et de $2$ est $x + 2$ ; on obtient $x(x + 2)$, puis on soustrait $x^2$ : $x(x + 2) - x^2$.
:::

::: etape Développer et réduire
$$
\begin{aligned}
x(x + 2) - x^2 &= x^2 + 2x - x^2 \\
&= 2x
\end{aligned}
$$
:::

::: point Vérification
Avec $5$ : $5 \times 7 - 25 = 35 - 25 = 10$, comme A et B.
:::

::: resultat
Le programme C donne aussi $2x$ : il donne toujours le même résultat que A et B.
:::

Solution:
<!-- optitab:1 -->
1. $10$ et $10$
2. $-4$ et $-4$
3. $2(x + 3) - 6 = 2x$
4. $4x - x - x = 2x$
5. Ils donnent toujours le double du nombre de départ
6. $x(x + 2) - x^2 = 2x$

=== Entraînement - Corriger des erreurs de calcul littéral
Id: 2589
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Dans son contrôle, Tom a écrit les six égalités suivantes. Elles sont **toutes fausses**.

1. $5x + 3 = 8x$
2. $4(x + 6) = 4x + 6$
3. $-(2x - 9) = -2x - 9$
4. $2x \times 4x = 8x$
5. $(x + 4)(x + 1) = x^2 + 4$
6. $10x - 15 = 5(2x + 3)$

Pour chaque égalité, prouver qu'elle est fausse avec un contre-exemple, puis écrire le calcul correct.

Étapes:
<!-- optitab:1 -->
## Question 1 : $5x + 3 = 8x$

::: methode
Un contre-exemple est une valeur de $x$ pour laquelle les deux membres sont différents ; $x = 0$ ou $x = 1$ sont souvent les plus simples.
:::

::: etape Contre-exemple
Pour $x = 0$ : $5 \times 0 + 3 = 3$ et $8 \times 0 = 0$ ; $3 \neq 0$.
:::

::: etape Corriger
$5x$ et $3$ ne sont pas de même nature : $5x + 3$ ne se réduit pas.
:::

::: resultat
$5x + 3$ est déjà réduite : elle n'est pas égale à $8x$.
:::

## Question 2 : $4(x + 6) = 4x + 6$

::: etape Contre-exemple
Pour $x = 0$ : $4 \times 6 = 24$ et $4 \times 0 + 6 = 6$ ; $24 \neq 6$.
:::

::: etape Corriger
Le facteur $4$ multiplie **chaque** terme : $4(x + 6) = 4 \times x + 4 \times 6$.
:::

::: resultat
$$4(x + 6) = 4x + 24$$
:::

## Question 3 : $-(2x - 9) = -2x - 9$

::: etape Contre-exemple
Pour $x = 0$ : $-(0 - 9) = 9$ et $-2 \times 0 - 9 = -9$ ; $9 \neq -9$.
:::

::: etape Corriger
Le signe « $-$ » devant la parenthèse change le signe de **chaque** terme, donc aussi celui de $-9$.
:::

::: resultat
$$-(2x - 9) = -2x + 9$$
:::

## Question 4 : $2x \times 4x = 8x$

::: etape Un test qui ne suffit pas
Pour $x = 1$ : $2 \times 4 = 8$ et $8 \times 1 = 8$. Les deux membres sont égaux : $x = 1$ n'est **pas** un contre-exemple.
:::

::: etape Contre-exemple
Pour $x = 2$ : $4 \times 8 = 32$ et $8 \times 2 = 16$ ; $32 \neq 16$.
:::

::: etape Corriger
$2x \times 4x = 2 \times 4 \times x \times x = 8x^2$.
:::

::: resultat
$$2x \times 4x = 8x^2$$
:::

::: retenir
Si une valeur donne deux résultats égaux, elle ne prouve rien : on essaie une autre valeur.
:::

## Question 5 : $(x + 4)(x + 1) = x^2 + 4$

::: etape Contre-exemple
Pour $x = 1$ : $(1 + 4)(1 + 1) = 5 \times 2 = 10$ et $1^2 + 4 = 5$ ; $10 \neq 5$.
:::

::: etape Corriger avec les quatre produits
$x \times x = x^2$ ; $x \times 1 = x$ ; $4 \times x = 4x$ ; $4 \times 1 = 4$. Tom a oublié les deux rectangles d'aires $x$ et $4x$.
:::

[IMAGE_1]

::: etape Réduire
$$
\begin{aligned}
(x + 4)(x + 1) &= x^2 + x + 4x + 4 \\
&= x^2 + 5x + 4
\end{aligned}
$$
:::

::: resultat
$$(x + 4)(x + 1) = x^2 + 5x + 4$$
:::

## Question 6 : $10x - 15 = 5(2x + 3)$

::: etape Contre-exemple
Pour $x = 0$ : $10 \times 0 - 15 = -15$ et $5 \times (0 + 3) = 15$ ; $-15 \neq 15$.
:::

::: etape Corriger
$10x - 15 = 5 \times 2x - 5 \times 3$ : le signe « $-$ » se retrouve dans la parenthèse.
:::

::: point Vérification
$5(2x - 3) = 10x - 15$.
:::

::: resultat
$$10x - 15 = 5(2x - 3)$$
:::

::: attention Erreur fréquente
Changer un signe en factorisant : on contrôle toujours une factorisation en redéveloppant.
:::

Solution:
<!-- optitab:1 -->
1. $x = 0$ : $3 \neq 0$ ; $5x + 3$ ne se réduit pas
2. $x = 0$ : $24 \neq 6$ ; $4x + 24$
3. $x = 0$ : $9 \neq -9$ ; $-2x + 9$
4. $x = 2$ : $32 \neq 16$ ; $8x^2$
5. $x = 1$ : $10 \neq 5$ ; $x^2 + 5x + 4$
6. $x = 0$ : $-15 \neq 15$ ; $5(2x - 3)$

=== Entraînement - Supprimer des parenthèses et réduire
Id: 2590
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer, puis réduire chaque expression.

1. $A = 5 - (2x - 3)$
2. $B = 3x - (-x + 4)$
3. $C = 2(x - 1) - (x + 5)$
4. $D = -3(2 - x) + 4x$
5. $E = x(x - 2) - 2(x - 2)$
6. $F = (x + 1)(x - 1) - x^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : L'expression $A$

::: methode
Des parenthèses précédées d'un signe « $-$ » se suppriment en changeant le signe de chaque terme.
:::

::: etape Supprimer les parenthèses, puis réduire
$$
\begin{aligned}
A &= 5 - 2x + 3 \\
&= 8 - 2x
\end{aligned}
$$
:::

::: resultat
$$A = 8 - 2x$$
:::

## Question 2 : L'expression $B$

::: etape Supprimer les parenthèses
$-(-x + 4) = x - 4$ : les deux signes changent.
:::

::: etape Réduire
$$
\begin{aligned}
B &= 3x + x - 4 \\
&= 4x - 4
\end{aligned}
$$
:::

::: resultat
$$B = 4x - 4$$
:::

## Question 3 : L'expression $C$

::: etape Développer chaque morceau
$2(x - 1) = 2x - 2$ et $-(x + 5) = -x - 5$.
:::

::: etape Réduire
$$
\begin{aligned}
C &= 2x - 2 - x - 5 \\
&= x - 7
\end{aligned}
$$
:::

::: resultat
$$C = x - 7$$
:::

::: attention Erreur fréquente
Écrire $-x + 5$ en supprimant la seconde parenthèse : le signe « $-$ » s'applique **aussi** au $5$.
:::

## Question 4 : L'expression $D$

::: etape Développer
$-3 \times 2 = -6$ et $-3 \times (-x) = +3x$, donc $-3(2 - x) = -6 + 3x$.
:::

::: etape Réduire
$$
\begin{aligned}
D &= -6 + 3x + 4x \\
&= 7x - 6
\end{aligned}
$$
:::

::: resultat
$$D = 7x - 6$$
:::

## Question 5 : L'expression $E$

::: etape Développer chaque morceau
$x(x - 2) = x^2 - 2x$ et $-2(x - 2) = -2x + 4$.
:::

::: etape Réduire
$$
\begin{aligned}
E &= x^2 - 2x - 2x + 4 \\
&= x^2 - 4x + 4
\end{aligned}
$$
:::

::: resultat
$$E = x^2 - 4x + 4$$
:::

## Question 6 : L'expression $F$

::: etape Double distributivité
$$
\begin{aligned}
(x + 1)(x - 1) &= x^2 - x + x - 1 \\
&= x^2 - 1
\end{aligned}
$$
:::

::: etape Réduire
$F = x^2 - 1 - x^2 = -1$.
:::

::: point Vérification
Pour $x = 5$ : $6 \times 4 - 25 = 24 - 25 = -1$.
:::

::: resultat
$F = -1$ : l'expression vaut toujours $-1$, quel que soit $x$.
:::

::: retenir
Après développement et réduction, une expression peut devenir un simple nombre : elle ne dépend plus de $x$.
:::

Solution:
<!-- optitab:1 -->
1. $A = 8 - 2x$
2. $B = 4x - 4$
3. $C = x - 7$
4. $D = 7x - 6$
5. $E = x^2 - 4x + 4$
6. $F = -1$

=== Entraînement - Associer des expressions égales
Id: 2591
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère les cinq expressions suivantes.

- $A = 2(3x + 4)$
- $B = (x + 2)(x + 5)$
- $C = 3x(x + 2)$
- $D = 5 - 2(x - 1)$
- $E = (2x - 1)(x + 4)$

Voici six expressions réduites : $6x + 8$ ; $3x^2 + 6x$ ; $7 - 2x$ ; $2x^2 + 7x - 4$ ; $x^2 + 7x + 10$ ; $6x + 4$.

1. Développer et réduire $A$ et $C$.
2. Développer et réduire $B$.
3. Développer et réduire $D$.
4. Développer et réduire $E$.
5. Associer chaque expression $A$, $B$, $C$, $D$ et $E$ à l'expression réduite qui lui est égale.
6. Une expression réduite est en trop. Montrer avec un contre-exemple qu'elle n'est pas égale à $A$, puis la factoriser.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les expressions $A$ et $C$

::: methode
Simple distributivité : le facteur devant la parenthèse multiplie chaque terme.
:::

::: etape Développer $A$
$A = 2 \times 3x + 2 \times 4 = 6x + 8$.
:::

::: etape Développer $C$
$C = 3x \times x + 3x \times 2 = 3x^2 + 6x$.
:::

::: resultat
$A = 6x + 8$ et $C = 3x^2 + 6x$.
:::

## Question 2 : L'expression $B$

::: etape Les quatre produits
$x \times x = x^2$ ; $x \times 5 = 5x$ ; $2 \times x = 2x$ ; $2 \times 5 = 10$.
:::

::: etape Réduire
$$
\begin{aligned}
B &= x^2 + 5x + 2x + 10 \\
&= x^2 + 7x + 10
\end{aligned}
$$
:::

::: resultat
$$B = x^2 + 7x + 10$$
:::

## Question 3 : L'expression $D$

::: etape Développer
$-2(x - 1) = -2x + 2$.
:::

::: etape Réduire
$$
\begin{aligned}
D &= 5 - 2x + 2 \\
&= 7 - 2x
\end{aligned}
$$
:::

::: point Vérification
Pour $x = -1$ : $5 - 2 \times (-2) = 9$ et $7 - 2 \times (-1) = 9$.
:::

::: resultat
$$D = 7 - 2x$$
:::

## Question 4 : L'expression $E$

::: etape Les quatre produits
$2x \times x = 2x^2$ ; $2x \times 4 = 8x$ ; $-1 \times x = -x$ ; $-1 \times 4 = -4$.
:::

::: etape Réduire
$$
\begin{aligned}
E &= 2x^2 + 8x - x - 4 \\
&= 2x^2 + 7x - 4
\end{aligned}
$$
:::

::: resultat
$$E = 2x^2 + 7x - 4$$
:::

::: attention Erreur fréquente
Oublier le signe « $-$ » de $-1$ : le troisième produit vaut $-x$, et le dernier $-4$.
:::

## Question 5 : Associer

| Expression | Forme réduite |
|---|---|
| $A = 2(3x + 4)$ | $6x + 8$ |
| $B = (x + 2)(x + 5)$ | $x^2 + 7x + 10$ |
| $C = 3x(x + 2)$ | $3x^2 + 6x$ |
| $D = 5 - 2(x - 1)$ | $7 - 2x$ |
| $E = (2x - 1)(x + 4)$ | $2x^2 + 7x - 4$ |

::: resultat
$A = 6x + 8$ ; $B = x^2 + 7x + 10$ ; $C = 3x^2 + 6x$ ; $D = 7 - 2x$ ; $E = 2x^2 + 7x - 4$.
:::

## Question 6 : L'expression en trop

::: etape Repérer l'intrus
Il reste $6x + 4$, qui ressemble à $A = 6x + 8$.
:::

::: etape Contre-exemple
Pour $x = 0$ : $A = 2 \times 4 = 8$ et $6 \times 0 + 4 = 4$ ; $8 \neq 4$. Donc $6x + 4 \neq A$.
:::

::: etape Factoriser
Le plus grand facteur commun de $6x$ et $4$ est $2$ :
$$
\begin{aligned}
6x + 4 &= 2 \times 3x + 2 \times 2 \\
&= 2(3x + 2)
\end{aligned}
$$
:::

::: resultat
$6x + 4$ est en trop ; elle n'est pas égale à $A$ ($8 \neq 4$ pour $x = 0$) et $6x + 4 = 2(3x + 2)$.
:::

::: attention Erreur fréquente
Croire que $2(3x + 4) = 6x + 4$ : le facteur $2$ multiplie aussi le $4$.
:::

Solution:
<!-- optitab:1 -->
1. $A = 6x + 8$ ; $C = 3x^2 + 6x$
2. $B = x^2 + 7x + 10$
3. $D = 7 - 2x$
4. $E = 2x^2 + 7x - 4$
5. $A$, $B$, $C$, $D$, $E$ associées comme ci-dessus
6. $6x + 4$ ($x = 0$ : $8 \neq 4$) ; $6x + 4 = 2(3x + 2)$

=== Entraînement - Démontrer des propriétés des nombres entiers
Id: 2592
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On utilise des lettres pour démontrer des propriétés vraies pour tous les nombres entiers. On note $n$ un nombre entier.

1. Calculer la somme $7 + 8 + 9$. Est-elle un multiple de $3$ ?
2. Démontrer que la somme de trois entiers consécutifs $n$, $n + 1$ et $n + 2$ est toujours un multiple de $3$.
3. Calculer $11 + 13$. Est-ce un multiple de $4$ ?
4. Deux nombres impairs consécutifs s'écrivent $2n + 1$ et $2n + 3$. Démontrer que leur somme est toujours un multiple de $4$.
5. Calculer $4 \times 5 + 5$. Comparer avec $5^2$.
6. Démontrer que $n(n + 1) + (n + 1) = (n + 1)^2$ pour tout entier $n$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Un premier essai

::: etape Calculer
$7 + 8 + 9 = 24$ et $24 = 3 \times 8$.
:::

::: resultat
Oui, $24$ est un multiple de $3$.
:::

## Question 2 : La démonstration

::: methode
Pour montrer qu'un nombre est un multiple de $3$, on l'écrit sous la forme $3 \times (\text{un entier})$.
:::

::: etape Additionner et réduire
$$
\begin{aligned}
n + (n + 1) + (n + 2) &= n + n + n + 1 + 2 \\
&= 3n + 3
\end{aligned}
$$
:::

::: etape Factoriser par $3$
$3n + 3 = 3 \times n + 3 \times 1 = 3(n + 1)$, et $n + 1$ est un entier.
:::

::: resultat
La somme de trois entiers consécutifs s'écrit $3(n + 1)$ : c'est toujours un multiple de $3$.
:::

## Question 3 : Deux nombres impairs

::: etape Calculer
$11 + 13 = 24$ et $24 = 4 \times 6$.
:::

::: resultat
Oui, $24$ est un multiple de $4$.
:::

## Question 4 : La démonstration pour les impairs

::: etape Additionner et réduire
$$
\begin{aligned}
(2n + 1) + (2n + 3) &= 2n + 2n + 1 + 3 \\
&= 4n + 4
\end{aligned}
$$
:::

::: etape Factoriser par $4$
$4n + 4 = 4(n + 1)$, et $n + 1$ est un entier.
:::

::: resultat
La somme de deux nombres impairs consécutifs s'écrit $4(n + 1)$ : c'est toujours un multiple de $4$.
:::

## Question 5 : Un produit plus un nombre

::: etape Calculer
$4 \times 5 + 5 = 20 + 5 = 25$, et $5^2 = 25$.
:::

::: resultat
On obtient $25 = 5^2$ : le carré du plus grand des deux nombres.
:::

## Question 6 : La démonstration

::: methode
On développe les deux membres séparément, puis on compare les formes réduites.
:::

::: etape Membre de gauche
$$
\begin{aligned}
n(n + 1) + (n + 1) &= n^2 + n + n + 1 \\
&= n^2 + 2n + 1
\end{aligned}
$$
:::

::: etape Membre de droite (double distributivité)
$$
\begin{aligned}
(n + 1)^2 &= (n + 1)(n + 1) \\
&= n^2 + n + n + 1 \\
&= n^2 + 2n + 1
\end{aligned}
$$
:::

::: resultat
Les deux membres sont égaux à $n^2 + 2n + 1$ : l'égalité est vraie pour tout entier $n$.
:::

::: attention Erreur fréquente
Penser que les essais des questions 1, 3 et 5 suffisent : chacun ne vérifie qu'un seul cas. Seul le calcul avec $n$ prouve la propriété pour tous les entiers.
:::

Solution:
<!-- optitab:1 -->
1. $24 = 3 \times 8$ : oui
2. $3n + 3 = 3(n + 1)$
3. $24 = 4 \times 6$ : oui
4. $4n + 4 = 4(n + 1)$
5. $25 = 5^2$
6. Les deux membres valent $n^2 + 2n + 1$

=== Problème - La piscine et sa margelle
Id: 2593
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un bassin rectangulaire mesure $2x$ mètres sur $x$ mètres. Il est entouré d'une margelle (un rebord dallé) de $1$ m de large.

[IMAGE_1]

1. Exprimer, en fonction de $x$, les dimensions du grand rectangle formé par le bassin et la margelle.
2. Exprimer l'aire de ce grand rectangle sous forme développée et réduite.
3. En déduire que l'aire de la margelle vaut $6x + 4$.
4. Calculer l'aire de la margelle pour $x = 4$, et vérifier avec les dimensions.
5. Le dallage coûte $45$ € le m². Quel est le prix de la margelle pour $x = 4$ ?
6. Pour quelle valeur de $x$ la margelle a-t-elle une aire de $40$ m² ? Donner alors les dimensions du bassin.
7. Retrouver l'expression $6x + 4$ en découpant la margelle en bandes et en coins.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les dimensions extérieures

::: methode
La margelle ajoute $1$ m de chaque côté du bassin, donc $2$ m à chaque dimension.
:::

::: etape Ajouter la margelle
Longueur : $2x + 1 + 1 = 2x + 2$ ; largeur : $x + 1 + 1 = x + 2$.
:::

::: resultat
Le grand rectangle mesure $2x + 2$ mètres sur $x + 2$ mètres.
:::

::: attention Erreur fréquente
N'ajouter que $1$ m à chaque dimension : la margelle est présente des **deux** côtés du bassin.
:::

## Question 2 : L'aire du grand rectangle

::: etape Les quatre produits
$2x \times x = 2x^2$ ; $2x \times 2 = 4x$ ; $2 \times x = 2x$ ; $2 \times 2 = 4$.
:::

::: etape Réduire
$$
\begin{aligned}
(2x + 2)(x + 2) &= 2x^2 + 4x + 2x + 4 \\
&= 2x^2 + 6x + 4
\end{aligned}
$$
:::

::: resultat
L'aire du grand rectangle vaut $2x^2 + 6x + 4$ m².
:::

## Question 3 : L'aire de la margelle

::: methode
Aire de la margelle $=$ aire du grand rectangle $-$ aire du bassin.
:::

::: etape Aire du bassin
$2x \times x = 2x^2$.
:::

::: etape Soustraire
$$2x^2 + 6x + 4 - 2x^2 = 6x + 4$$
:::

::: resultat
L'aire de la margelle vaut $6x + 4$ m².
:::

## Question 4 : Pour $x = 4$

::: etape Avec la formule
$6 \times 4 + 4 = 24 + 4 = 28$.
:::

::: point Vérification
Le bassin mesure $8$ m sur $4$ m et le grand rectangle $10$ m sur $6$ m : $10 \times 6 - 8 \times 4 = 60 - 32 = 28$.
:::

::: resultat
Pour $x = 4$, l'aire de la margelle vaut $28$ m².
:::

## Question 5 : Le prix

::: etape Calculer
$28 \times 45 = 1\,260$.
:::

::: resultat
La margelle coûte $1\,260$ €.
:::

## Question 6 : Une margelle de $40$ m²

::: etape Remonter les calculs
$6x + 4 = 40$, donc $6x = 36$, puis $x = 36 : 6 = 6$.
:::

::: point Vérification
Le bassin mesure $12$ m sur $6$ m, le grand rectangle $14$ m sur $8$ m : $14 \times 8 - 12 \times 6 = 112 - 72 = 40$.
:::

::: resultat
$x = 6$ : le bassin mesure $12$ m sur $6$ m.
:::

## Question 7 : Découper la margelle

::: etape Les bandes le long des côtés
Deux bandes de $2x$ sur $1$ (aire $2x$ chacune) et deux bandes de $x$ sur $1$ (aire $x$ chacune) : $2x + 2x + x + x = 6x$.
:::

::: etape Les quatre coins
Quatre carrés de $1$ m sur $1$ m : $4 \times 1 = 4$.
:::

[IMAGE_2]

::: resultat
Aire de la margelle $= 6x + 4$ : les bandes donnent $6x$ (le périmètre du bassin) et les quatre coins donnent $4$.
:::

::: retenir
Interpréter chaque terme d'une expression sur la figure permet de vérifier qu'elle est juste.
:::

Solution:
<!-- optitab:1 -->
1. $2x + 2$ m sur $x + 2$ m
2. $2x^2 + 6x + 4$
3. $2x^2 + 6x + 4 - 2x^2 = 6x + 4$
4. $28$ m²
5. $1\,260$ €
6. $x = 6$ ; bassin de $12$ m sur $6$ m
7. $6x$ (bandes) $+ 4$ (coins)

=== Problème - Le carré magique littéral
Id: 2594
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère le tableau suivant, où $x$ est un nombre quelconque.

[IMAGE_1]

1. Calculer et réduire la somme de chaque ligne.
2. Calculer et réduire la somme de chaque colonne.
3. Calculer et réduire la somme de chaque diagonale. Le carré est-il magique ?
4. Compléter le carré pour $x = 5$. Que remarque-t-on ?
5. Quelle valeur faut-il donner à $x$ pour que la somme magique vaille $30$ ? Donner alors les neuf nombres.
6. Compléter le carré pour $x = -2$ et vérifier la somme d'une ligne.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les lignes

::: methode
On regroupe d'un côté les termes en $x$, de l'autre les nombres.
:::

::: etape Ligne 1
$(x - 3) + (x + 2) + (x + 1) = 3x + (-3 + 2 + 1) = 3x + 0 = 3x$.
:::

::: etape Lignes 2 et 3
$(x + 4) + x + (x - 4) = 3x + 0 = 3x$ et $(x - 1) + (x - 2) + (x + 3) = 3x + 0 = 3x$.
:::

::: resultat
Chaque ligne a pour somme $3x$.
:::

## Question 2 : Les colonnes

::: etape Colonne 1
$(x - 3) + (x + 4) + (x - 1) = 3x + (-3 + 4 - 1) = 3x$.
:::

::: etape Colonnes 2 et 3
$(x + 2) + x + (x - 2) = 3x$ et $(x + 1) + (x - 4) + (x + 3) = 3x$.
:::

::: resultat
Chaque colonne a pour somme $3x$.
:::

## Question 3 : Les diagonales

::: etape Les deux diagonales
$(x - 3) + x + (x + 3) = 3x$ et $(x + 1) + x + (x - 1) = 3x$.
:::

::: resultat
Les lignes, les colonnes et les diagonales ont toutes pour somme $3x$ : le carré est magique, quel que soit $x$.
:::

::: retenir
Dans chaque somme, les nombres se compensent et il reste $3x$ : c'est le calcul littéral qui prouve que le carré est magique pour **tous** les nombres $x$.
:::

## Question 4 : Pour $x = 5$

::: etape Remplacer $x$ par $5$
Ligne 1 : $5 - 3 = 2$ ; $5 + 2 = 7$ ; $5 + 1 = 6$. On procède de même pour les autres cases.
:::

[IMAGE_2]

::: resultat
On obtient les nombres entiers de $1$ à $9$, chacun une fois, avec une somme magique de $3 \times 5 = 15$.
:::

## Question 5 : Une somme magique de $30$

::: etape Trouver $x$
La somme magique vaut $3x$ : $3x = 30$, donc $x = 10$.
:::

::: etape Les neuf nombres
Ligne 1 : $7$ ; $12$ ; $11$. Ligne 2 : $14$ ; $10$ ; $6$. Ligne 3 : $9$ ; $8$ ; $13$.
:::

::: point Vérification
$7 + 12 + 11 = 30$ et $7 + 10 + 13 = 30$.
:::

::: resultat
$x = 10$ : on obtient les nombres entiers de $6$ à $14$.
:::

## Question 6 : Pour $x = -2$

::: etape Remplacer $x$ par $-2$
Ligne 1 : $-5$ ; $0$ ; $-1$. Ligne 2 : $2$ ; $-2$ ; $-6$. Ligne 3 : $-3$ ; $-4$ ; $1$.
:::

::: etape Vérifier une ligne
$-5 + 0 + (-1) = -6$, et $3 \times (-2) = -6$.
:::

::: resultat
Le carré reste magique, avec une somme magique de $-6$.
:::

::: attention Erreur fréquente
Se tromper de signe en remplaçant : pour $x = -2$, $x - 3 = -2 - 3 = -5$ (et non $-1$).
:::

Solution:
<!-- optitab:1 -->
1. $3x$ pour chaque ligne
2. $3x$ pour chaque colonne
3. Oui, somme magique $3x$
4. $2, 7, 6$ / $9, 5, 1$ / $4, 3, 8$ : les entiers de $1$ à $9$, somme $15$
5. $x = 10$ : $7, 12, 11$ / $14, 10, 6$ / $9, 8, 13$
6. $-5, 0, -1$ / $2, -2, -6$ / $-3, -4, 1$ ; somme $-6$

=== Problème - Le tour de magie
Id: 2595
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un magicien propose le tour suivant : « Choisis un nombre entier. Calcule son carré. Retire le carré du nombre entier qui le précède. Donne-moi le résultat : je devine ton nombre ! »

[IMAGE_1]

1. Faire le tour avec $7$, puis avec $10$.
2. On note $n$ le nombre choisi. Développer $(n - 1)^2$ à l'aide de la double distributivité.
3. Démontrer que le résultat du tour est toujours $2n - 1$.
4. Un spectateur annonce $25$. Quel nombre avait-il choisi ?
5. Expliquer la méthode du magicien pour deviner le nombre.
6. Utiliser ce résultat pour calculer mentalement $51^2 - 50^2$ et $1\,001^2 - 1\,000^2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux essais

::: etape Avec $7$
Le nombre qui précède $7$ est $6$ : $7^2 - 6^2 = 49 - 36 = 13$.
:::

::: etape Avec $10$
Le nombre qui précède $10$ est $9$ : $10^2 - 9^2 = 100 - 81 = 19$.
:::

::: resultat
On obtient $13$ avec $7$, et $19$ avec $10$.
:::

## Question 2 : Développer $(n - 1)^2$

::: methode
$(n - 1)^2 = (n - 1)(n - 1)$ : on écrit les quatre produits, puis on réduit.
:::

::: etape Les quatre produits
$n \times n = n^2$ ; $n \times (-1) = -n$ ; $(-1) \times n = -n$ ; $(-1) \times (-1) = +1$.
:::

::: etape Réduire
$$
\begin{aligned}
(n - 1)^2 &= n^2 - n - n + 1 \\
&= n^2 - 2n + 1
\end{aligned}
$$
:::

::: resultat
$$(n - 1)^2 = n^2 - 2n + 1$$
:::

::: attention Erreur fréquente
Écrire $(n - 1)^2 = n^2 - 1$ : on oublie les deux produits $-n$ et le signe de $(-1) \times (-1) = +1$. Pour $n = 7$, on aurait $48$ au lieu de $36$.
:::

## Question 3 : La démonstration

::: methode
Le tour calcule $n^2 - (n - 1)^2$ : on remplace $(n - 1)^2$ par sa forme développée, **entre parenthèses**.
:::

::: etape Remplacer et supprimer les parenthèses
$$
\begin{aligned}
n^2 - (n - 1)^2 &= n^2 - (n^2 - 2n + 1) \\
&= n^2 - n^2 + 2n - 1 \\
&= 2n - 1
\end{aligned}
$$
:::

[IMAGE_2]

::: point Vérification
Pour $n = 7$ : $2 \times 7 - 1 = 13$ ; pour $n = 10$ : $2 \times 10 - 1 = 19$.
:::

::: resultat
Quel que soit l'entier $n$ choisi, le résultat du tour est $2n - 1$.
:::

## Question 4 : Retrouver le nombre

::: etape Remonter les calculs
$2n - 1 = 25$, donc $2n = 26$, puis $n = 26 : 2 = 13$.
:::

::: point Vérification
$13^2 - 12^2 = 169 - 144 = 25$.
:::

::: resultat
Le spectateur avait choisi $13$.
:::

## Question 5 : La méthode du magicien

::: etape Défaire les calculs
Le résultat est « le double du nombre, moins $1$ ». Pour retrouver le nombre, on fait les opérations inverses dans l'ordre inverse : on ajoute $1$, puis on divise par $2$.
:::

::: resultat
Le magicien ajoute $1$ au résultat annoncé, puis divise par $2$.
:::

::: retenir
Pour « défaire » un programme de calcul, on applique les opérations inverses dans l'ordre inverse.
:::

## Question 6 : Calcul mental

::: etape $51^2 - 50^2$
C'est le tour avec $n = 51$ : $2 \times 51 - 1 = 101$.
:::

::: etape $1\,001^2 - 1\,000^2$
C'est le tour avec $n = 1\,001$ : $2 \times 1\,001 - 1 = 2\,001$.
:::

::: resultat
$51^2 - 50^2 = 101$ et $1\,001^2 - 1\,000^2 = 2\,001$.
:::

Solution:
<!-- optitab:1 -->
1. $13$ ; $19$
2. $(n - 1)^2 = n^2 - 2n + 1$
3. $n^2 - (n^2 - 2n + 1) = 2n - 1$
4. $13$
5. Ajouter $1$, puis diviser par $2$
6. $101$ ; $2\,001$

=== Problème - Calculer mentalement grâce à la distributivité
Id: 2596
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
La distributivité permet de calculer de tête des produits qui semblent difficiles.

1. En écrivant $101 = 100 + 1$, calculer $37 \times 101$.
2. En écrivant $99 = 100 - 1$, calculer $56 \times 99$.
3. Calculer $17 \times 23 + 17 \times 77$ en factorisant.
4. Calculer $4{,}7 \times 13 - 4{,}7 \times 3$ en factorisant.
5. En écrivant $21 = 20 + 1$ et $32 = 30 + 2$, calculer $21 \times 32$ avec la double distributivité.
6. Pour élever au carré un nombre qui se termine par $5$, on multiplie son nombre de dizaines par le nombre suivant, puis on écrit $25$ à droite. Par exemple, pour $35^2$ : $3 \times 4 = 12$, donc $35^2 = 1\,225$. Vérifier cette règle pour $15^2$ et $45^2$.
7. Un nombre qui se termine par $5$ s'écrit $10n + 5$, où $n$ est son nombre de dizaines. Démontrer que $(10n + 5)^2 = 100n(n + 1) + 25$, puis calculer $85^2$ de tête.

Étapes:
<!-- optitab:1 -->
## Question 1 : $37 \times 101$

::: methode
On décompose $101$ en $100 + 1$, puis on applique $k(a + b) = ka + kb$.
:::

::: etape Développer
$$
\begin{aligned}
37 \times 101 &= 37 \times (100 + 1) \\
&= 3\,700 + 37 \\
&= 3\,737
\end{aligned}
$$
:::

::: resultat
$$37 \times 101 = 3\,737$$
:::

## Question 2 : $56 \times 99$

::: etape Développer
$$
\begin{aligned}
56 \times 99 &= 56 \times (100 - 1) \\
&= 5\,600 - 56 \\
&= 5\,544
\end{aligned}
$$
:::

::: resultat
$$56 \times 99 = 5\,544$$
:::

## Question 3 : $17 \times 23 + 17 \times 77$

::: methode
Les deux produits ont le facteur commun $17$ : on applique $ka + kb = k(a + b)$.
:::

::: etape Factoriser
$$
\begin{aligned}
17 \times 23 + 17 \times 77 &= 17 \times (23 + 77) \\
&= 17 \times 100 \\
&= 1\,700
\end{aligned}
$$
:::

::: resultat
$$17 \times 23 + 17 \times 77 = 1\,700$$
:::

## Question 4 : $4{,}7 \times 13 - 4{,}7 \times 3$

::: etape Factoriser par $4{,}7$
$$
\begin{aligned}
4{,}7 \times 13 - 4{,}7 \times 3 &= 4{,}7 \times (13 - 3) \\
&= 4{,}7 \times 10 \\
&= 47
\end{aligned}
$$
:::

::: resultat
$$4{,}7 \times 13 - 4{,}7 \times 3 = 47$$
:::

## Question 5 : $21 \times 32$

::: methode
$(a + b)(c + d) = ac + ad + bc + bd$ : le rectangle de $21$ sur $32$ se découpe en quatre rectangles faciles à calculer.
:::

::: etape Les quatre produits
$20 \times 30 = 600$ ; $20 \times 2 = 40$ ; $1 \times 30 = 30$ ; $1 \times 2 = 2$.
:::

[IMAGE_1]

::: etape Additionner
$21 \times 32 = 600 + 40 + 30 + 2 = 672$.
:::

::: resultat
$$21 \times 32 = 672$$
:::

## Question 6 : Vérifier la règle

::: etape Pour $15^2$
$1$ dizaine : $1 \times 2 = 2$, la règle donne $225$. Et $15 \times 15 = 225$.
:::

::: etape Pour $45^2$
$4$ dizaines : $4 \times 5 = 20$, la règle donne $2\,025$. Et $45 \times 45 = 2\,025$.
:::

::: resultat
La règle fonctionne pour $15^2 = 225$ et pour $45^2 = 2\,025$.
:::

## Question 7 : Démontrer la règle

::: methode
On développe $(10n + 5)^2 = (10n + 5)(10n + 5)$ avec la double distributivité, puis on factorise une partie de l'expression.
:::

::: etape Les quatre produits
$10n \times 10n = 100n^2$ ; $10n \times 5 = 50n$ ; $5 \times 10n = 50n$ ; $5 \times 5 = 25$.
:::

::: etape Réduire, puis factoriser par $100n$
$$
\begin{aligned}
(10n + 5)^2 &= 100n^2 + 50n + 50n + 25 \\
&= 100n^2 + 100n + 25 \\
&= 100n(n + 1) + 25
\end{aligned}
$$
:::

::: etape Interpréter
$n(n + 1)$ est le produit du nombre de dizaines par le nombre suivant ; le multiplier par $100$ revient à écrire deux zéros à sa droite, que l'on remplace par $25$ en ajoutant $25$.
:::

::: etape Calculer $85^2$
$n = 8$ : $8 \times 9 = 72$, donc $85^2 = 7\,200 + 25 = 7\,225$.
:::

::: resultat
$(10n + 5)^2 = 100n(n + 1) + 25$ : la règle est démontrée, et $85^2 = 7\,225$.
:::

::: attention Erreur fréquente
Écrire $(10n + 5)^2 = 100n^2 + 25$ : on oublie les deux produits $50n$, et la règle ne s'explique plus.
:::

Solution:
<!-- optitab:1 -->
1. $3\,737$
2. $5\,544$
3. $17 \times 100 = 1\,700$
4. $4{,}7 \times 10 = 47$
5. $600 + 40 + 30 + 2 = 672$
6. $15^2 = 225$ ; $45^2 = 2\,025$
7. $(10n + 5)^2 = 100n(n + 1) + 25$ ; $85^2 = 7\,225$

=== Type brevet - La boîte sans couvercle
Id: 2597
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Dans une plaque de carton de $30$ cm sur $20$ cm, on découpe un carré de côté $x$ cm à chaque coin, puis on relève les bords pour former une boîte sans couvercle.

[IMAGE_1]

1. Pour $x = 3$, donner les dimensions de la boîte (longueur, largeur et hauteur).
2. Calculer le volume de la boîte pour $x = 3$.
3. Exprimer, en fonction de $x$, la longueur et la largeur du fond de la boîte.
4. Quelles sont les valeurs possibles de $x$ ? Justifier.
5. Développer et réduire l'aire du fond $(30 - 2x)(20 - 2x)$. Vérifier avec $x = 4$.
6. Le volume de la boîte vaut $V = x(30 - 2x)(20 - 2x)$. Recopier et compléter le tableau, puis donner la valeur entière de $x$ qui donne le plus grand volume.

| $x$ (cm) | $V$ (cm³) |
|---|---|
| $1$ | |
| $2$ | |
| $3$ | $1\,008$ |
| $4$ | |
| $5$ | |
| $6$ | |
| $7$ | |
| $8$ | |
| $9$ | |

Étapes:
<!-- optitab:1 -->
## Question 1 : Les dimensions pour $x = 3$

::: methode
On retire un carré de côté $x$ à chaque bout de chaque côté de la plaque : chaque dimension diminue de $2x$. La hauteur de la boîte est le côté $x$ du carré découpé.
:::

::: etape Calculer
Longueur : $30 - 2 \times 3 = 24$ ; largeur : $20 - 2 \times 3 = 14$ ; hauteur : $3$.
:::

::: resultat
Pour $x = 3$, la boîte mesure $24$ cm sur $14$ cm, et $3$ cm de haut.
:::

## Question 2 : Le volume pour $x = 3$

::: etape Volume d'un pavé droit
$V = 24 \times 14 \times 3 = 336 \times 3 = 1\,008$.
:::

::: resultat
Pour $x = 3$, le volume vaut $1\,008$ cm³.
:::

## Question 3 : Le fond en fonction de $x$

::: etape Généraliser la question 1
On remplace $3$ par $x$ : longueur $30 - 2x$ et largeur $20 - 2x$.
:::

[IMAGE_2]

::: resultat
Le fond mesure $30 - 2x$ cm sur $20 - 2x$ cm.
:::

## Question 4 : Les valeurs possibles de $x$

::: etape Deux conditions
Il faut $x > 0$ pour découper vraiment un carré, et une largeur positive : $20 - 2x > 0$, c'est-à-dire $2x < 20$, soit $x < 10$.
:::

::: resultat
$x$ doit être strictement compris entre $0$ et $10$.
:::

::: attention Erreur fréquente
Ne regarder que la longueur ($30 - 2x > 0$, soit $x < 15$) : c'est la largeur, plus petite, qui limite $x$.
:::

## Question 5 : L'aire du fond

::: etape Les quatre produits
$30 \times 20 = 600$ ; $30 \times (-2x) = -60x$ ; $-2x \times 20 = -40x$ ; $(-2x) \times (-2x) = 4x^2$.
:::

::: etape Réduire
On note $F = (30 - 2x)(20 - 2x)$ l'aire du fond.
$$
\begin{aligned}
F &= 600 - 60x - 40x + 4x^2 \\
&= 4x^2 - 100x + 600
\end{aligned}
$$
:::

::: point Vérification pour $x = 4$
Avec la forme développée :
$$
\begin{aligned}
F &= 4 \times 16 - 100 \times 4 + 600 \\
&= 64 - 400 + 600 \\
&= 264
\end{aligned}
$$
Avec les dimensions : $22 \times 12 = 264$.
:::

::: resultat
L'aire du fond vaut $4x^2 - 100x + 600$ cm².
:::

::: attention Erreur fréquente
Écrire $-4x^2$ pour le dernier produit : $(-2x) \times (-2x)$ est un produit de deux facteurs négatifs, il est positif.
:::

## Question 6 : Le plus grand volume

::: methode
Pour chaque valeur, on calcule la longueur, la largeur, puis le produit par la hauteur $x$.

::: etape Quelques calculs
- $x = 1$ : $1 \times 28 \times 18 = 504$ ;
- $x = 4$ : $4 \times 22 \times 12 = 1\,056$ ;
- $x = 5$ : $5 \times 20 \times 10 = 1\,000$ ;
- $x = 9$ : $9 \times 12 \times 2 = 216$.

|---|---|
| $1$ | $504$ |
| $2$ | $832$ |
| $3$ | $1\,008$ |
| $4$ | $1\,056$ |
| $5$ | $1\,000$ |
| $6$ | $864$ |
| $7$ | $672$ |
| $8$ | $448$ |
| $9$ | $216$ |

::: resultat
Parmi les valeurs entières, $x = 4$ donne le plus grand volume : $1\,056$ cm³.
:::

::: retenir
Un tableau de valeurs permet de repérer la valeur qui rend une grandeur la plus grande possible.
:::

Solution:
<!-- optitab:1 -->

2. $1\,008$ cm³

=== Type brevet - Comparer les aires d'un rectangle et d'un carré
Id: 2598
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On compare le rectangle $A$, de dimensions $x + 5$ et $x + 1$, et le carré $B$, de côté $x + 3$ (en cm, avec $x > 0$).

[IMAGE_1]

1. Calculer le périmètre de $A$ et celui de $B$ pour $x = 2$.
2. Exprimer les deux périmètres en fonction de $x$. Que remarque-t-on ?
3. Calculer les deux aires pour $x = 2$.
4. Exprimer l'aire de $A$ en fonction de $x$, sous forme développée et réduite.
5. Exprimer l'aire de $B$ en fonction de $x$, sous forme développée et réduite.
6. Démontrer que le carré $B$ a toujours une aire plus grande que le rectangle $A$, et préciser de combien.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les périmètres pour $x = 2$

::: etape Le rectangle $A$
Il mesure $7$ cm sur $3$ cm : $2 \times (7 + 3) = 20$.
:::

::: etape Le carré $B$
Son côté mesure $5$ cm : $4 \times 5 = 20$.
:::

::: resultat
Pour $x = 2$, les deux périmètres valent $20$ cm.
:::

## Question 2 : Les périmètres en fonction de $x$

::: etape Le rectangle $A$
$$
\begin{aligned}
2(x + 5 + x + 1) &= 2(2x + 6) \\
&= 4x + 12
\end{aligned}
$$
:::

::: etape Le carré $B$
$4(x + 3) = 4x + 12$.
:::

::: resultat
Les deux périmètres valent $4x + 12$ : ils sont toujours égaux.
:::

## Question 3 : Les aires pour $x = 2$

::: etape Calculer
$A$ : $7 \times 3 = 21$ ; $B$ : $5 \times 5 = 25$.
:::

::: resultat
Pour $x = 2$, les aires valent $21$ cm² et $25$ cm².
:::

## Question 4 : L'aire de $A$

::: etape Les quatre produits
$x \times x = x^2$ ; $x \times 1 = x$ ; $5 \times x = 5x$ ; $5 \times 1 = 5$.
:::

::: etape Réduire
$$
\begin{aligned}
(x + 5)(x + 1) &= x^2 + x + 5x + 5 \\
&= x^2 + 6x + 5
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
L'aire de $A$ vaut $x^2 + 6x + 5$ cm².
:::

## Question 5 : L'aire de $B$

::: etape Les quatre produits
$(x + 3)^2 = (x + 3)(x + 3)$ : $x \times x = x^2$ ; $x \times 3 = 3x$ ; $3 \times x = 3x$ ; $3 \times 3 = 9$.
:::

::: etape Réduire
$$
\begin{aligned}
(x + 3)^2 &= x^2 + 3x + 3x + 9 \\
&= x^2 + 6x + 9
\end{aligned}
$$
:::

[IMAGE_3]

::: resultat
L'aire de $B$ vaut $x^2 + 6x + 9$ cm².
:::

::: attention Erreur fréquente
Écrire $(x + 3)^2 = x^2 + 9$ : on oublie les deux rectangles d'aire $3x$.
:::

## Question 6 : Comparer les aires

::: methode
Pour comparer deux expressions, on calcule leur différence et on la réduit.
:::

::: etape Calculer la différence
Aire de $B$ moins aire de $A$ :
$$(x^2 + 6x + 9) - (x^2 + 6x + 5)$$
$$= x^2 + 6x + 9 - x^2 - 6x - 5$$
$$= 4$$
:::

::: point Vérification
Pour $x = 2$ : $25 - 21 = 4$.
:::

::: resultat
Pour tout $x > 0$, l'aire du carré $B$ dépasse celle du rectangle $A$ de $4$ cm².
:::

::: retenir
Deux figures de même périmètre n'ont pas forcément la même aire.
:::

Solution:
<!-- optitab:1 -->
1. $20$ cm et $20$ cm
2. $4x + 12$ pour les deux : toujours égaux
3. $21$ cm² et $25$ cm²
4. $x^2 + 6x + 5$
5. $x^2 + 6x + 9$
6. $B - A = 4$ cm² pour tout $x$

=== Type brevet - Vrai ou faux en calcul littéral
Id: 2599
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour chacune des six affirmations, dire si elle est vraie ou fausse. On rappelle que toutes les réponses doivent être justifiées.

1. Affirmation 1 : « Pour $x = -3$, l'expression $2x^2 - 5x$ vaut $3$. »
2. Affirmation 2 : « Pour tout nombre $x$, $(3x - 2)(x + 4) = 3x^2 + 10x - 8$. »
3. Affirmation 3 : « Une forme factorisée de $12x^2 - 8x$ est $4x(3x - 2)$. »
4. Affirmation 4 : « Pour tout nombre $x$, $5 - 2(x - 3) = 3x - 3$. »
5. Affirmation 5 : « Avec le programme de calcul ci-dessous, le résultat est toujours égal au nombre de départ augmenté de $5$. »
6. Affirmation 6 : « La somme de trois nombres entiers consécutifs est toujours un multiple de $6$. »

[IMAGE_1]

Étapes:
<!-- optitab:1 -->
## Question 1 : Affirmation 1

::: methode
On remplace $x$ par $-3$ entre parenthèses, puis on respecte les priorités.
:::

::: etape Calculer
$$
\begin{aligned}
2 \times (-3)^2 - 5 \times (-3) &= 2 \times 9 + 15 \\
&= 33
\end{aligned}
$$
:::

::: resultat
Faux : pour $x = -3$, l'expression vaut $33$, et non $3$.
:::

## Question 2 : Affirmation 2

::: etape Les quatre produits
$3x \times x = 3x^2$ ; $3x \times 4 = 12x$ ; $-2 \times x = -2x$ ; $-2 \times 4 = -8$.
:::

::: etape Réduire
$$
\begin{aligned}
(3x - 2)(x + 4) &= 3x^2 + 12x - 2x - 8 \\
&= 3x^2 + 10x - 8
\end{aligned}
$$
:::

::: resultat
Vrai : le développement donne exactement $3x^2 + 10x - 8$.
:::

## Question 3 : Affirmation 3

::: methode
On contrôle une factorisation en redéveloppant.
:::

::: etape Redévelopper
$$
\begin{aligned}
4x(3x - 2) &= 4x \times 3x - 4x \times 2 \\
&= 12x^2 - 8x
\end{aligned}
$$
:::

::: resultat
Vrai : $12x^2 - 8x = 4x(3x - 2)$.
:::

## Question 4 : Affirmation 4

::: etape Développer et réduire le membre de gauche
$$
\begin{aligned}
5 - 2(x - 3) &= 5 - 2x + 6 \\
&= 11 - 2x
\end{aligned}
$$
:::

::: etape Contre-exemple
Pour $x = 0$ : $11 - 2 \times 0 = 11$, alors que $3 \times 0 - 3 = -3$ ; $11 \neq -3$.
:::

::: resultat
Faux : $5 - 2(x - 3) = 11 - 2x$, et $x = 0$ est un contre-exemple.
:::

## Question 5 : Affirmation 5

::: methode
On applique le programme à un nombre quelconque $x$ et on écrit l'expression obtenue après chaque étape.
:::

::: etape Traduire le programme
- Choisir un nombre : $x$ ;
- multiplier par $4$ : $4x$ ;
- ajouter $10$ : $4x + 10$ ;
- diviser par $2$ : $\dfrac{4x + 10}{2}$ ;
- soustraire le nombre de départ : $\dfrac{4x + 10}{2} - x$.
:::

::: etape Simplifier
On divise chaque terme par $2$ :
$$
\begin{aligned}
\dfrac{4x + 10}{2} - x &= 2x + 5 - x \\
&= x + 5
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
Vrai : pour tout nombre $x$, le programme donne $x + 5$, le nombre de départ augmenté de $5$.
:::

::: attention Erreur fréquente
Ne diviser que $10$ par $2$ et écrire $4x + 5$ : la division porte sur **tout** le résultat $4x + 10$.
:::

## Question 6 : Affirmation 6

::: etape Un premier essai qui fonctionne
$1 + 2 + 3 = 6$ : c'est un multiple de $6$.
:::

::: etape Un contre-exemple
$2 + 3 + 4 = 9$, et $9$ n'est pas un multiple de $6$.
:::

::: resultat
Faux : $2 + 3 + 4 = 9$ est un contre-exemple. La somme $3n + 3 = 3(n + 1)$ est toujours un multiple de $3$, mais pas toujours de $6$.
:::

::: retenir
Un exemple qui fonctionne ne prouve pas une affirmation ; un seul contre-exemple suffit à prouver qu'elle est fausse.
:::

Solution:
<!-- optitab:1 -->
1. Faux : l'expression vaut $33$
2. Vrai : $3x^2 + 12x - 2x - 8 = 3x^2 + 10x - 8$
3. Vrai : $4x(3x - 2) = 12x^2 - 8x$
4. Faux : $5 - 2(x - 3) = 11 - 2x$ ($x = 0$ : $11 \neq -3$)
5. Vrai : le programme donne $x + 5$
6. Faux : $2 + 3 + 4 = 9$
