Titre: Comparer et placer jusqu’à 1 000

<!-- optitab:1 -->
::: objectifs
Je compare des nombres et je lis le pas d’une graduation.
:::

## I. Je construis et j’observe

::: methode Avec du matériel ou un dessin
Écris 306 et 360 sur deux étiquettes. Les deux nombres ont trois centaines. Compare alors leurs dizaines : aucune dans 306, six dans 360.
:::

[IMAGE_1]

## II. Je comprends

::: definition
Je compare d’abord les centaines, puis les dizaines, puis les unités.

Sur une graduation, je cherche la valeur d’un intervalle.

Encadrer un nombre, c’est le placer entre deux nombres.
:::

## III. Je sais faire

::: methode Les gestes pour réussir
1. Je compare les centaines ; si elles sont égales, je compare les dizaines, puis les unités.
2. Sur une ligne, je cherche combien vaut l’espace entre deux traits voisins.
3. Pour encadrer, je choisis une borne plus petite et une borne plus grande.
:::

::: exemple Un raisonnement expliqué
$306<360$ car, après les trois centaines communes, 0 dizaine est inférieur à 6 dizaines.

Sur la ligne de 300 à 400, dix intervalles égaux donnent un pas de 10 : après 300 viennent 310, 320, 330.

$500<568<600$ et $560<568<570$. Le second encadrement est plus précis.
:::

## IV. J’essaie et je vérifie

::: exemple À toi de chercher
Une ligne porte 240, 250, 260. Quel nombre est trois intervalles après 260 ?
:::

::: resultat Je vérifie
Le pas est 10. On passe par 270, 280 puis 290 : $260+30=290$.
:::

::: attention L’erreur à éviter
On compare d’abord les centaines : 490 est plus petit que 509, même si son chiffre des dizaines est plus grand.
:::

::: retenir
Je compare d’abord les centaines, puis les dizaines, puis les unités.

Sur une graduation, je cherche la valeur d’un intervalle.

Encadrer un nombre, c’est le placer entre deux nombres.
:::
