<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Vecteur normal à une droite</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Vecteur normal à une droite</strong></p>
<p style="margin:5px 0 0 0;">Un vecteur $\displaystyle \vec{n}$ est <strong>normal</strong> à une droite $\displaystyle \Delta$ s'il est orthogonal à tout vecteur directeur de $\displaystyle \Delta$.</p>
<p style="margin:5px 0 0 0;">Si $\displaystyle \vec{n}$ est normal à $\displaystyle \Delta$ et si $\displaystyle \vec{d}$ est un vecteur directeur de $\displaystyle \Delta$, alors :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{n} \cdot \vec{d} = 0$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Vecteur normal et équation cartésienne</strong></p>
<p style="margin:5px 0 0 0;">Une droite $\displaystyle \Delta$ a pour équation cartésienne $\displaystyle ax + by + c = 0$ (avec $\displaystyle (a, b) \neq (0, 0)$).</p>
<p style="margin:5px 0 0 0;">Alors le vecteur $\displaystyle \vec{n}(a, b)$ est un <strong>vecteur normal</strong> à la droite $\displaystyle \Delta$.</p>
<p style="margin:5px 0 0 0;">De plus, le vecteur $\displaystyle \vec{d}(-b, a)$ est un <strong>vecteur directeur</strong> de la droite $\displaystyle \Delta$.</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_1]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Équation cartésienne avec point et vecteur normal</strong></p>
<p style="margin:5px 0 0 0;">Une droite passant par un point $\displaystyle A(x_A, y_A)$ et de vecteur normal $\displaystyle \vec{n}(a, b)$ (avec $\displaystyle (a, b) \neq (0, 0)$) a pour équation cartésienne :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle a(x - x_A) + b(y - y_A) = 0$</p>
</div>
<p style="margin:5px 0 0 0;">Ce qui s'écrit aussi : $\displaystyle ax + by + c = 0$ où $\displaystyle c = -(ax_A + by_A)$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Vecteurs colinéaires</strong></p>
<p style="margin:5px 0 0 0;">Deux vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ sont dits <strong>colinéaires</strong> s'il existe un réel $\displaystyle k$ (non nul) tel que :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \vec{v} = k\vec{u}$</p>
<p style="margin:5px 0 0 0;">Cela signifie que les vecteurs ont la même direction (ils sont parallèles).</p>
<p style="margin:5px 0 0 0;">Dans une base orthonormée, deux vecteurs $\displaystyle \vec{u}(x_1, y_1)$ et $\displaystyle \vec{v}(x_2, y_2)$ sont colinéaires si et seulement si :</p>
<p style="margin:5px 0 0 0;">$\displaystyle x_1 y_2 - x_2 y_1 = 0$ (déterminant nul)</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#f3e5f5; border-left:4px solid #9c27b0; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Propriété - Position relative de deux droites</strong></p>
<p style="margin:5px 0 0 0;">Soient deux droites :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \Delta_1 : a_1 x + b_1 y + c_1 = 0$ et $\displaystyle \Delta_2 : a_2 x + b_2 y + c_2 = 0$</p>
<p style="margin:5px 0 0 0;">Les vecteurs normaux sont respectivement $\displaystyle \vec{n_1}(a_1, b_1)$ et $\displaystyle \vec{n_2}(a_2, b_2)$.</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Les droites sont <strong>parallèles</strong> si les vecteurs normaux $\displaystyle (a_1, b_1)$ et $\displaystyle (a_2, b_2)$ sont <strong>colinéaires</strong></li>
<li style="margin:0 0 8px 0;">Les droites sont <strong>sécantes</strong> sinon</li>
<li style="margin:0;">Les droites sont <strong>confondues</strong> si elles sont parallèles et qu'elles ont au moins un point commun</li>
</ul>
</div>
</div>

<div style="text-align:center; margin:20px 0;">

</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Projeté orthogonal d'un point sur une droite</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Projeté orthogonal</strong></p>
<p style="margin:5px 0 0 0;">Soient $\displaystyle M$ un point et $\displaystyle \Delta$ une droite. Il existe un <strong>unique</strong> point $\displaystyle H$ de $\displaystyle \Delta$ tel que $\displaystyle \overrightarrow{MH} \perp \Delta$ : c'est le <strong>projeté orthogonal</strong> de $\displaystyle M$ sur $\displaystyle \Delta$.</p>
<p style="margin:5px 0 0 0;">Le projeté orthogonal est le point de $\displaystyle \Delta$ le plus proche de $\displaystyle M$.</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_3]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Distance d'un point à une droite</strong></p>
<p style="margin:5px 0 0 0;">Soient un point $\displaystyle M(x_M, y_M)$ et une droite $\displaystyle \Delta : ax + by + c = 0$, avec $\displaystyle (a, b) \neq (0, 0)$.</p>
<p style="margin:5px 0 0 0;">La distance de $\displaystyle M$ à $\displaystyle \Delta$ est :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle d(M, \Delta) = \frac{|ax_M + by_M + c|}{\sqrt{a^2 + b^2}}$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Méthode - Coordonnées du projeté orthogonal</strong></p>
<p style="margin:5px 0 0 0;">Pour déterminer les coordonnées du projeté orthogonal $\displaystyle H$ d'un point $\displaystyle M(x_M, y_M)$ sur une droite $\displaystyle \Delta : ax + by + c = 0$ :</p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Le vecteur $\displaystyle \vec{n}(a, b)$ est normal à $\displaystyle \Delta$</li>
<li style="margin:0 0 8px 0;">Le point $\displaystyle H$ appartient à $\displaystyle \Delta$ et $\displaystyle \overrightarrow{MH}$ est colinéaire à $\displaystyle \vec{n}$</li>
<li style="margin:0 0 8px 0;">Il existe un réel $\displaystyle t$ tel que $\displaystyle \overrightarrow{MH} = t\vec{n}$</li>
<li style="margin:0;">On utilise que $\displaystyle H$ appartient à $\displaystyle \Delta$ pour déterminer $\displaystyle t$</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Équation de cercle</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Équation d'un cercle</strong></p>
<p style="margin:5px 0 0 0;">Un cercle $\displaystyle \mathcal{C}$ de centre $\displaystyle \Omega(x_0, y_0)$ et de rayon $\displaystyle R$ (avec $\displaystyle R > 0$) a pour équation :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle (x - x_0)^2 + (y - y_0)^2 = R^2$</p>
</div>
<p style="margin:5px 0 0 0;">En développant, on obtient la forme développée :</p>
<p style="margin:5px 0 0 0;">$\displaystyle x^2 + y^2 - 2x_0 x - 2y_0 y + x_0^2 + y_0^2 - R^2 = 0$</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_4]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Forme générale d'une équation de cercle</strong></p>
<p style="margin:5px 0 0 0;">Toute équation de la forme :</p>
<p style="margin:5px 0 0 0;">$\displaystyle x^2 + y^2 + ax + by + c = 0$</p>
<p style="margin:5px 0 0 0;">peut représenter un cercle (ou un point, ou l'ensemble vide).</p>
<p style="margin:5px 0 0 0;">Pour déterminer le centre et le rayon, on met l'équation sous forme canonique :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \left(x + \frac{a}{2}\right)^2 + \left(y + \frac{b}{2}\right)^2 = \frac{a^2 + b^2 - 4c}{4}$</p>
</div>
<p style="margin:5px 0 0 0;">Le centre est $\displaystyle \Omega\left(-\frac{a}{2}, -\frac{b}{2}\right)$ et le rayon est $\displaystyle R = \frac{1}{2}\sqrt{a^2 + b^2 - 4c}$ (si $\displaystyle a^2 + b^2 - 4c > 0$).</p>
<p style="margin:5px 0 0 0;">Si $\displaystyle a^2 + b^2 - 4c = 0$, c'est l'équation d'un point.</p>
<p style="margin:5px 0 0 0;">Si $\displaystyle a^2 + b^2 - 4c < 0$, c'est l'ensemble vide.</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Parabole représentative d'une fonction polynôme du second degré</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Axe de symétrie d'une parabole</strong></p>
<p style="margin:5px 0 0 0;">La courbe représentative de la fonction $\displaystyle f(x) = ax^2 + bx + c$ (avec $\displaystyle a \neq 0$) est une <strong>parabole</strong>.</p>
<p style="margin:5px 0 0 0;">Cette parabole admet pour <strong>axe de symétrie</strong> la droite verticale d'équation :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle x = -\frac{b}{2a}$</p>
</div>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_5]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Coordonnées du sommet</strong></p>
<p style="margin:5px 0 0 0;">Le <strong>sommet</strong> de la parabole d'équation $\displaystyle y = ax^2 + bx + c$ (avec $\displaystyle a \neq 0$) est le point d'intersection de la parabole avec son axe de symétrie.</p>
<p style="margin:5px 0 0 0;">Ses coordonnées sont :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$</p>
</div>
<p style="margin:5px 0 0 0;">où $\displaystyle f(x) = ax^2 + bx + c$.</p>
<p style="margin:5px 0 0 0;">En utilisant la forme canonique, le sommet est $\displaystyle S(\alpha, \beta)$ où :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \alpha = -\frac{b}{2a}$ et $\displaystyle \beta = f(\alpha) = c - \frac{b^2}{4a}$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>⚡ Orientation de la parabole :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Si $\displaystyle a > 0$ : la parabole est <strong>tournée vers le haut</strong> (elle admet un <strong>minimum</strong> au sommet)</li>
<li style="margin:0;">Si $\displaystyle a < 0$ : la parabole est <strong>tournée vers le bas</strong> (elle admet un <strong>maximum</strong> au sommet)</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Utiliser un repère pour étudier une configuration</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Méthode pour étudier une configuration :</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;"><strong>Choisir un repère adapté :</strong> Placer l'origine et les axes de manière à simplifier les calculs (sur des points particuliers, des axes de symétrie, etc.)</li>
<li style="margin:0 0 8px 0;"><strong>Déterminer les coordonnées des points :</strong> Dans le repère choisi, donner les coordonnées de tous les points de la configuration</li>
<li style="margin:0 0 8px 0;"><strong>Écrire les équations :</strong> Utiliser les équations de droites, cercles, paraboles selon les besoins</li>
<li style="margin:0 0 8px 0;"><strong>Résoudre le problème :</strong> Utiliser les outils de géométrie repérée (produit scalaire, distances, intersections, etc.)</li>
<li style="margin:0;"><strong>Interpréter les résultats :</strong> Donner une réponse géométrique claire</li>
</ol>
</div>

<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Cercle (forme générale)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle x^2 + y^2 + ax + by + c = 0$<br/>Centre : $\displaystyle \left(-\frac{a}{2}, -\frac{b}{2}\right)$<br/>Rayon : $\displaystyle \frac{1}{2}\sqrt{a^2 + b^2 - 4c}$ (si $\displaystyle > 0$)</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Parabole $\displaystyle y = ax^2 + bx + c$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Axe de symétrie : $\displaystyle x = -\frac{b}{2a}$<br/>Sommet : $\displaystyle S\left(-\frac{b}{2a}, f\left(-\frac{b}{2a}\right)\right)$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Distance d'un point à une droite</td>
<td style="border:none; padding:18px 16px;">$\displaystyle d(M(x_M, y_M), \Delta : ax + by + c = 0) = \frac{|ax_M + by_M + c|}{\sqrt{a^2 + b^2}}$</td>
</tr>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Méthodologie — stratégie de résolution</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ffa500; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(255,165,0,0.15); table-layout:fixed;">

<tr style="background:linear-gradient(135deg, #ffa500 0%, #ff8c00 100%); color:white;">

<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Déterminer une équation de droite</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Si point et vecteur normal : $\displaystyle a(x - x_A) + b(y - y_A) = 0$<br/>2. Si point et vecteur directeur : utiliser l'équation paramétrique ou trouver un vecteur normal</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Déterminer le projeté orthogonal</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">1. Utiliser que $\displaystyle \overrightarrow{MH}$ est colinéaire au vecteur normal<br/>2. Écrire $\displaystyle H = M + t\vec{n}$<br/>3. Utiliser que $\displaystyle H$ appartient à la droite pour trouver $\displaystyle t$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Reconnaître une équation de cercle</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Mettre sous forme canonique : $\displaystyle (x - x_0)^2 + (y - y_0)^2 = R^2$<br/>2. Vérifier que $\displaystyle a^2 + b^2 - 4c > 0$<br/>3. Déterminer centre et rayon</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Déterminer l'axe de symétrie et le sommet d'une parabole</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">1. Axe de symétrie : $\displaystyle x = -\frac{b}{2a}$<br/>2. Sommet : calculer $\displaystyle f\left(-\frac{b}{2a}\right)$<br/>3. Vérifier l'orientation selon le signe de $\displaystyle a$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Étudier une configuration géométrique</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Choisir un repère adapté (origine sur des points particuliers)<br/>2. Déterminer les coordonnées des points<br/>3. Utiliser les outils de géométrie repérée (produit scalaire, distances)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Démontrer qu'un triangle est rectangle</td>
<td style="border:none; padding:18px 16px;">Calculer les produits scalaires des vecteurs formés par les côtés<br/>Si un produit scalaire est nul, le triangle est rectangle au sommet correspondant</td>

<p style="margin:0;"><strong>💡 Points de vigilance :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Toujours vérifier que le repère est orthonormé avant d'utiliser les formules avec coordonnées</li>
<li style="margin:0 0 8px 0;">Pour une droite $\displaystyle ax + by + c = 0$, ne pas confondre vecteur normal $\displaystyle (a, b)$ et vecteur directeur $\displaystyle (-b, a)$</li>
<li style="margin:0 0 8px 0;">Pour reconnaître un cercle, toujours mettre sous forme canonique et vérifier la condition $\displaystyle a^2 + b^2 - 4c > 0$</li>
<li style="margin:0 0 8px 0;">Pour l'axe de symétrie d'une parabole, attention au signe : $\displaystyle x = -\frac{b}{2a}$</li>
<li style="margin:0 0 8px 0;">Choisir un repère adapté qui simplifie les calculs (origine sur des points particuliers, axes sur des axes de symétrie)</li>
<li style="margin:0;">Vérifier que les points trouvés (projeté orthogonal, intersections) appartiennent bien aux objets géométriques</li>
