=== Équations Différentielles - Programme Bac France Terminal
Difficulté: medium
Ordre: 8

Titre: Équations Différentielles : Résolution et Modélisation
Description: Cours sur les équations différentielles linéaires du premier ordre selon le programme du bac français : forme y' = a y + b, méthodes de résolution et applications concrètes.

        <p style="margin:8px 0; text-align:left; font-size:0.95em;">Les sections I à V couvrent le cœur du programme de Terminale sur les équations différentielles. Les parties marquées <strong>"🌟 Bonus"</strong> sont des approfondissements utiles mais ne sont pas strictement exigibles au Bac.</p>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce qu'une équation différentielle ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Équation différentielle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>équation différentielle</strong> est une équation qui met en relation une fonction inconnue $\displaystyle y(x)$ avec sa dérivée $\displaystyle y'(x)$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y' = f(x, y)$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Au programme du bac :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On étudie principalement les équations différentielles linéaires du premier ordre de la forme <strong>$\displaystyle y' = a y + b$</strong> où $\displaystyle a$ et $\displaystyle b$ sont des constantes.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y' = 2y$ (croissance exponentielle)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y' = -3y + 5$ (équation complète)</li>
                <li style="margin:0; text-align:left;">$\displaystyle y' = y - 2$ (décroissance avec terme constant)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Méthodes de résolution</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résolution générale de y' = a y + b</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Solution générale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour l'équation différentielle $\displaystyle y' = a y + b$ avec $\displaystyle a \neq 0$, la solution générale est :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x) = C e^{a x} - \frac{b}{a}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle C$ est une constante réelle déterminée par la condition initiale.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre l'équation homogène $\displaystyle y' = a y$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Trouver une solution particulière de $\displaystyle y' = a y + b$</li>
                <li style="margin:0; text-align:left;">Additionner les deux solutions</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2y + 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Équation homogène :</strong> $\displaystyle y' - 2y = 0 \Rightarrow y_h = C e^{2x}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Solution particulière :</strong> On cherche une solution constante $\displaystyle y_p = k$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle 0 = 2k + 4 \Rightarrow k = -2$</li>
                <li style="margin:0; text-align:left;"><strong>Solution générale :</strong> $\displaystyle y = C e^{2x} - 2$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = -y + 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Équation homogène :</strong> $\displaystyle y' + y = 0 \Rightarrow y_h = C e^{-x}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Solution particulière :</strong> On cherche une solution constante $\displaystyle y_p = k$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle 0 = -k + 3 \Rightarrow k = 3$</li>
                <li style="margin:0; text-align:left;"><strong>Solution générale :</strong> $\displaystyle y = C e^{-x} + 3$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conditions initiales</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Condition initiale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La constante $\displaystyle C$ est déterminée par une <strong>condition initiale</strong> :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:200px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x_0) = y_0$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2y + 4$ avec $\displaystyle y(0) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Solution générale : $\displaystyle y = C e^{2x} - 2$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y(0) = 1 \Rightarrow 1 = C - 2 \Rightarrow C = 3$</li>
                <li style="margin:0; text-align:left;"><strong>Solution particulière :</strong> $\displaystyle y = 3 e^{2x} - 2$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Applications concrètes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation de la croissance</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Croissance exponentielle :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle P' = k P$ (population, capital, réactions chimiques)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle P(t) = P_0 e^{k t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Exemple :</strong> Population : $\displaystyle P' = 0,05 P$, $\displaystyle P(0) = 1000$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle P(t) = 1000 e^{0,05 t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle P(10) = 1000 e^{0,5} \approx 1649$ individus</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Décroissance radioactive :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle N' = -\lambda N$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle N(t) = N_0 e^{-\lambda t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Demi-vie :</strong> $\displaystyle T_{1/2} = \frac{\ln 2}{\lambda}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Exemple :</strong> Carbone 14 : $\displaystyle \lambda = 0,00012$, $\displaystyle T_{1/2} \approx 5770$ ans</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation physique</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Refroidissement d'un corps :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle T' = -k (T - T_a)$ où $\displaystyle T_a$ est la température ambiante</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle T(t) = T_a + (T_0 - T_a) e^{-k t}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Circuit électrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle i' + \frac{R}{L} i = \frac{E}{L}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Courant : $\displaystyle i(t) = \frac{E}{R} \left(1 - e^{-\frac{R}{L} t}\right)$</p>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Méthodes alternatives</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Séparation des variables</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Séparation des variables</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour les équations de la forme $\displaystyle y' = g(x) h(y)$, on sépare les variables :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \frac{dy}{h(y)} = g(x) \, dx$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2 x y$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \frac{dy}{y} = 2x \, dx$ (pour $\displaystyle y > 0$)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln y = x^2 + C$</li>
                <li style="margin:0; text-align:left;">$\displaystyle y = e^{x^2 + C} = K e^{x^2}$ où $\displaystyle K = e^C$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vérification des solutions</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dériver la solution proposée et vérifier si elle satisfait l'équation différentielle.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Vérifier que $\displaystyle y = 2 e^{2x} - 2$ satisfait $\displaystyle y' = 2y + 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle y' = 4 e^{2x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 2y + 4 = 2(2 e^{2x} - 2) + 4 = 4 e^{2x} - 4 + 4 = 4 e^{2x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em; color:#2e7d32;">✅ Solution correcte !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Exercices d'application</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exercices de base</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 3y - 6$ avec $\displaystyle y(0) = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em; color:#666;"><em>Solution : $\displaystyle y = 2 + 2 e^{3x}$</em></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Modéliser la décroissance radioactive : $\displaystyle N' = -0,02 N$ avec $\displaystyle N(0) = 100$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em; color:#666;"><em>Solution : $\displaystyle N(t) = 100 e^{-0,02 t}$</em></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 3 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = -2y + 10$ avec $\displaystyle y(0) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em; color:#666;"><em>Solution : $\displaystyle y = 5 - 4 e^{-2x}$</em></p>
        </div>
    </div>


    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Oublier la constante d'intégration $\displaystyle C$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mauvais signe pour l'équation homogène</li>
                <li style="margin:0 0 12px 0; text-align:left;">Erreur dans le calcul de la solution particulière</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier d'appliquer la condition initiale</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la solution obtenue</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Identifier la forme $\displaystyle y' = a y + b$ avec $\displaystyle a$ et $\displaystyle b$ constantes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre d'abord l'équation homogène $\displaystyle y' = a y$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Trouver une solution particulière constante</li>
                <li style="margin:0 0 12px 0; text-align:left;">Appliquer la condition initiale pour trouver $\displaystyle C$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier toujours en dérivant la solution</li>
                <li style="margin:0; text-align:left;">Être attentif aux unités dans les applications</li>
            </ul>
        </div>
    </div>
