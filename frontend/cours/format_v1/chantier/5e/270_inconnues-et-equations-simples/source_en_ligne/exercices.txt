=== Découverte - Inconnues - 2 pochettes pour 14 €
Id: 2897
Difficulté: easy
Image: v1_n270_ex2897_2_schema_parametre.png

Énoncé: <!-- optitab:1 -->
2 pochettes identiques coûtent ensemble 14 €. Un emballage facultatif coûte 2 € en plus. On appelle x le prix d’une pochette, en euros.

1. Que représente x, et dans quelle unité ?
2. Écrire l’équation qui permet de retrouver ce prix.
3. Retrouver le prix d’une pochette.
4. Vérifier le prix trouvé dans l’égalité initiale.
5. Quel est le montant à payer si on prend aussi l’emballage ?
6. Le prix total des seules pochettes augmente de 6 €, pour le même nombre de pochettes. Quelle est la hausse par pochette ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Que représente x, et dans quelle unité ?

::: methode
Identifier la quantité inconnue.
:::

::: etape Nommer le prix recherché
Toutes les pochettes ont le même prix. x désigne le prix d’une seule pochette, en euros.
:::

::: resultat
Le prix d’une pochette, en euros.
:::

## Question 2 : Écrire l’équation qui permet de retrouver ce prix.

::: methode
Le prix total des pochettes est un produit.
:::

::: etape Traduire les données
Les 2 pochettes coûtent $2x$ euros au total ; donc $2x=14$.
:::

::: resultat
$2x=14$.
:::

## Question 3 : Retrouver le prix d’une pochette.

::: methode
Partager le prix total en parts égales.
:::

::: etape Diviser par le nombre de pochettes
$x=14\div2=7$.
:::

::: resultat
$7$ € par pochette.
:::

## Question 4 : Vérifier le prix trouvé dans l’égalité initiale.

::: methode
Reconstituer le prix des pochettes.
:::

::: etape Multiplier le prix unitaire
$2\times7=14$ : on retrouve le montant annoncé.
:::

::: resultat
La réponse est vérifiée.
:::

## Question 5 : Quel est le montant à payer si on prend aussi l’emballage ?

::: methode
Ajouter la dépense facultative une seule fois.
:::

::: etape Calculer la facture complète
$14+2=16$ €.
:::

::: etape Lire le schéma de bilan
Dans le schéma, $n=2$, $b=2$ et $T=16$. Le total T comprend cette fois l’emballage.

[IMAGE_2]
:::

::: resultat
16 €.
:::

## Question 6 : Le prix total des seules pochettes augmente de 6 €, pour le même nombre de pochettes. Quelle est la hausse par pochette ?

::: methode
Répartir la hausse sur le même nombre d’objets.
:::

::: etape Partager la hausse
$6\div2=3$ € par pochette.
:::

::: etape Calculer le nouveau prix
$7+3=10$ €.
:::

::: resultat
Hausse : $3$ € par pochette ; nouveau prix : $10$ €.
:::

::: retenir Le bon réflexe
L’équation du prix unitaire porte sur les seules pochettes. L’emballage est une dépense distincte, ajoutée ensuite si on le choisit.
:::

Solution:
<!-- optitab:1 -->
1. Le prix d’une pochette, en euros.
2. $2x=14$.
3. $7$ € par pochette.
4. La réponse est vérifiée.
5. 16 €.
6. Hausse : $3$ € par pochette ; nouveau prix : $10$ €.

=== Découverte - Inconnues et équations simples - 7. Retrouver le nombre partagé
Id: 2900
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Un programme demande un nombre x, le partage en 9 parts égales et affiche 0. On cherche le nombre choisi au départ.

1. Écrire l’équation du programme.
2. Quelle opération permet de retrouver x ?
3. Résoudre l’équation.
4. Vérifier la solution dans le programme.
5. Un autre programme multiplie x par 9 et affiche 0. Quelle est sa solution ?
6. Une équation demande-t-elle toujours un nombre strictement positif ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Écrire l’équation du programme.

::: methode
Traduire le partage par une division.
:::

::: etape Nommer l’inconnue
Le nombre choisi est partagé en 9 parts égales ; chaque part vaut 0.
:::

::: resultat
L’équation est $\frac{x}{9}=0$.
:::

## Question 2 : Quelle opération permet de retrouver x ?

::: methode
Utiliser l’opération inverse de la division.
:::

::: etape Traduire la situation
Pour retrouver le nombre avant le partage, multiplier la valeur d’une part par le nombre de parts.
:::

::: resultat
Il faut multiplier 0 par 9.
:::

## Question 3 : Résoudre l’équation.

::: methode
Effectuer la multiplication inverse.
:::

::: etape Retrouver la donnée manquante
$$x=0\times9=0$$
:::

::: resultat
La solution est $x=0$.
:::

## Question 4 : Vérifier la solution dans le programme.

::: methode
Remettre la valeur trouvée dans le programme.
:::

::: etape Effectuer l’opération inverse
$$0\div9=0$$
:::

::: resultat
On retrouve bien le résultat affiché.
:::

## Question 5 : Un autre programme multiplie x par 9 et affiche 0. Quelle est sa solution ?

::: methode
Chercher le nombre dont le produit par un nombre non nul est zéro.
:::

::: etape Vérifier la valeur trouvée
$$9\times0=0$$
:::

::: resultat
La solution est $x=0$.
:::

## Question 6 : Une équation demande-t-elle toujours un nombre strictement positif ?

::: methode
Distinguer l’équation et les contraintes de la situation.
:::

::: etape Interpréter la réponse
Le deuxième programme accepte zéro et donne bien zéro. Une équation d’addition peut aussi avoir une solution négative : $x+6=2$ donne $x=-4$.
:::

::: resultat
Non. Zéro ou un nombre négatif peut convenir si le contexte l’autorise.
:::

::: retenir Le bon réflexe
Nommer l’inconnue et son unité, défaire l’opération, puis remplacer la lettre dans l’égalité initiale pour vérifier.
:::

Solution:
<!-- optitab:1 -->
1. L’équation est $\frac{x}{9}=0$.
2. Il faut multiplier 0 par 9.
3. La solution est $x=0$.
4. On retrouve bien le résultat affiché.
5. La solution est $x=0$.
6. Non. Zéro ou un nombre négatif peut convenir si le contexte l’autorise.

=== Découverte - Inconnues - Multiplication et division à trous
Id: 2898
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Chaque coefficient de multiplication ou diviseur indiqué est non nul.

1. Résoudre $4x=18$.
2. Résoudre $2x=0$.
3. Résoudre $\frac{x}{3}=7$.
4. Pourquoi $4x=18$ n’a-t-elle pas de solution entière, alors qu’elle a une solution décimale ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre $4x=18$.

::: methode
Partager 18 en quatre parts égales.
:::

::: etape Diviser par le coefficient
$x=18\div4=4{,}5$.
:::

::: etape Vérifier
$4\times4{,}5=18$.
:::

::: resultat
$x=4{,}5$.
:::

## Question 2 : Résoudre $2x=0$.

::: methode
Chercher le nombre dont le double est nul.
:::

::: etape Diviser
$x=0\div2=0$.
:::

::: etape Vérifier
$2\times0=0$.
:::

::: resultat
$x=0$.
:::

## Question 3 : Résoudre $\frac{x}{3}=7$.

::: methode
Défaire le partage en multipliant.
:::

::: etape Reconstituer le tout
$x=7\times3=21$.
:::

::: etape Vérifier
$21\div3=7$.
:::

::: resultat
$x=21$.
:::

## Question 4 : Pourquoi $4x=18$ n’a-t-elle pas de solution entière, alors qu’elle a une solution décimale ?

::: methode
Préciser la nature du nombre demandé.
:::

::: etape Comparer aux multiples entiers
$4\times4=16$ et $4\times5=20$ : 18 est entre deux multiples entiers consécutifs de 4.
:::

::: etape Interpréter la solution
$4{,}5$ est décimal, mais pas entier.
:::

::: resultat
Aucun entier ne convient ; le décimal 4,5 convient.
:::

::: retenir Le bon réflexe
Défaire une multiplication demande une division ; défaire une division demande une multiplication. Zéro peut être une solution.
:::

Solution:
<!-- optitab:1 -->
1. $x=4{,}5$.
2. $x=0$.
3. $x=21$.
4. Aucun entier ne convient ; le décimal 4,5 convient.

=== Découverte - Inconnues - Retrouver le terme d’une addition
Id: 2896
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Retrouver le nombre caché par une opération inverse, puis vérifier dans l’égalité initiale.

1. Résoudre $x+7=19$.
2. Résoudre $x+2{,}5=6{,}2$.
3. Résoudre $x+6=2$.
4. Faut-il toujours refuser une solution négative ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre $x+7=19$.

::: methode
Retirer 7 du total.
:::

::: etape Retrouver le nombre
$x=19-7=12$.
:::

::: etape Vérifier
$12+7=19$.
:::

::: resultat
$x=12$.
:::

## Question 2 : Résoudre $x+2{,}5=6{,}2$.

::: methode
Soustraire le terme ajouté.
:::

::: etape Calculer la différence
$x=6{,}2-2{,}5=3{,}7$.
:::

::: etape Vérifier
$3{,}7+2{,}5=6{,}2$.
:::

::: resultat
$x=3{,}7$.
:::

## Question 3 : Résoudre $x+6=2$.

::: methode
La différence peut être négative.
:::

::: etape Retrouver le terme manquant
$x=2-6=-4$.
:::

::: etape Vérifier
$-4+6=2$.
:::

::: resultat
$x=-4$.
:::

## Question 4 : Faut-il toujours refuser une solution négative ?

::: methode
Vérifier à la fois l’égalité et le sens de la situation.
:::

::: etape Distinguer les contraintes
Une température peut être négative ; le prix d’un objet ordinaire ne le peut pas. Dans une équation sans contrainte de contexte, un nombre négatif peut parfaitement convenir.
:::

::: resultat
Non ; cela dépend du contexte, puis de la vérification.
:::

::: retenir Le bon réflexe
On défait une addition par une soustraction. Le signe de la solution se contrôle dans l’égalité de départ.
:::

Solution:
<!-- optitab:1 -->
1. $x=12$.
2. $x=3{,}7$.
3. $x=-4$.
4. Non ; cela dépend du contexte, puis de la vérification.

=== Entraînement - Inconnues - Fractions simples et opérations inverses
Id: 2903
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Résoudre par le sens des opérations, sans utiliser de règle générale de division de fractions.

1. Résoudre $\frac{x}{4}=\frac32$.
2. Résoudre $\frac32x=9$.
3. Résoudre $x+\frac34=\frac54$.
4. Ces trois équations ont-elles toutes la même solution ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre $\frac{x}{4}=\frac32$.

::: methode
Multiplier la valeur d’une part par le nombre de parts.
:::

::: etape Interpréter la fraction
$\frac32=1{,}5$.
:::

::: etape Reconstituer le tout
$x=1{,}5\times4=6$. Vérification : $6\div4=1{,}5$.
:::

::: resultat
$x=6$.
:::

## Question 2 : Résoudre $\frac32x=9$.

::: methode
Remplacer le coefficient par un décimal connu.
:::

::: etape Réécrire
$\frac32=1{,}5$, donc on cherche le nombre dont le produit par 1,5 vaut 9.
:::

::: etape Diviser et vérifier
$x=9\div1{,}5=6$. Vérification par le sens de la fraction : $(6\div2)\times3=9$.
:::

::: resultat
$x=6$.
:::

## Question 3 : Résoudre $x+\frac34=\frac54$.

::: methode
Soustraire des fractions de même dénominateur.
:::

::: etape Retirer trois quarts
$$
\begin{aligned}
x &= \frac54-\frac34 \\
&= \frac24 \\
&= \frac12
\end{aligned}
$$
:::

::: etape Vérifier
$\frac12+\frac34=\frac24+\frac34=\frac54$.
:::

::: resultat
$x=\frac12$.
:::

## Question 4 : Ces trois équations ont-elles toutes la même solution ?

::: methode
Comparer les valeurs obtenues, pas seulement les symboles.
:::

::: etape Rassembler les solutions
Les deux premières donnent 6 ; la troisième donne $\frac12$. Elles n’ont donc pas toutes la même solution.
:::

::: resultat
Non : 6, 6 et 1/2.
:::

::: retenir Le bon réflexe
Un coefficient fractionnaire simple peut parfois être lu comme un décimal connu. On n’a pas besoin d’une règle de division de fractions pour ces calculs.
:::

Solution:
<!-- optitab:1 -->
1. $x=6$.
2. $x=6$.
3. $x=\frac12$.
4. Non : 6, 6 et 1/2.

=== Entraînement - Inconnues - Modéliser une distance et un prix
Id: 2901
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Pour chaque situation, nommer l’inconnue, écrire une équation à une opération, puis répondre avec son unité.

1. Une randonnée mesure 12,5 km. On a parcouru 7,8 km. Quelle distance reste-t-il ?
2. Un ruban de 18 m est partagé en 4 morceaux égaux. Quelle est la longueur d’un morceau ?
3. Cinq stylos identiques coûtent 7,50 €. Quel est leur prix unitaire ?
4. Une température augmente de 6 °C et atteint 2 °C. Quelle était sa valeur initiale ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Une randonnée mesure 12,5 km. On a parcouru 7,8 km. Quelle distance reste-t-il ?

::: methode
Le parcours déjà fait et le reste forment le parcours total.
:::

::: etape Traduire
En notant x le reste en km : $x+7{,}8=12{,}5$.
:::

::: etape Résoudre et vérifier
$x=12{,}5-7{,}8=4{,}7$, et $4{,}7+7{,}8=12{,}5$.
:::

::: resultat
Il reste 4,7 km.
:::

## Question 2 : Un ruban de 18 m est partagé en 4 morceaux égaux. Quelle est la longueur d’un morceau ?

::: methode
Quatre longueurs identiques reconstituent le ruban.
:::

::: etape Traduire
En notant ℓ la longueur en m : $4\ell=18$.
:::

::: etape Résoudre et vérifier
$\ell=18\div4=4{,}5$, et $4\times4{,}5=18$.
:::

::: resultat
Chaque morceau mesure 4,5 m.
:::

## Question 3 : Cinq stylos identiques coûtent 7,50 €. Quel est leur prix unitaire ?

::: methode
Partager le prix total entre les cinq stylos.
:::

::: etape Traduire
Si p est le prix d’un stylo en euros, $5p=7{,}50$.
:::

::: etape Résoudre et vérifier
$p=7{,}50\div5=1{,}50$, et $5\times1{,}50=7{,}50$.
:::

::: resultat
1,50 € par stylo.
:::

## Question 4 : Une température augmente de 6 °C et atteint 2 °C. Quelle était sa valeur initiale ?

::: methode
La température initiale augmentée de 6 donne la finale.
:::

::: etape Traduire
Si t est la température initiale : $t+6=2$.
:::

::: etape Résoudre et vérifier
$t=2-6=-4$, et $-4+6=2$.
:::

::: resultat
$-4$ °C.
:::

::: retenir Le bon réflexe
Le même calcul inverse sert dans des contextes différents. Nommer l’inconnue et son unité évite de confondre un prix total, un prix unitaire, une distance et une température.
:::

Solution:
<!-- optitab:1 -->
1. Il reste 4,7 km.
2. Chaque morceau mesure 4,5 m.
3. 1,50 € par stylo.
4. $-4$ °C.

=== Problème - Inconnues - Détecter les fausses résolutions
Id: 2908
Difficulté: hard

Énoncé: <!-- optitab:1 -->
Trois élèves proposent des résultats. Contrôler chaque raisonnement dans l’équation de départ.

1. Ana écrit : pour $x+(-4)=3$, « $x=3-4=-1$ ». Corriger.
2. Bilal refuse la valeur $\frac35$ pour $5x=3$, car « ce n’est pas un entier ». A-t-il raison ?
3. Chloé refuse $x=-2$ pour $x+7=5$. Que montre la vérification ?
4. On cherche maintenant un entier x tel que 4x = 18. Quelle est la réponse ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Ana écrit : pour $x+(-4)=3$, « $x=3-4=-1$ ». Corriger.

::: methode
Chercher le nombre auquel on retire 4 pour obtenir 3.
:::

::: etape Tester le résultat proposé
$-1+(-4)=-5$, et non 3 : la proposition ne convient pas.
:::

::: etape Utiliser la bonne opération inverse
$x=3+4=7$. Vérification : $7+(-4)=3$.
:::

::: resultat
$x=7$.
:::

## Question 2 : Bilal refuse la valeur $\frac35$ pour $5x=3$, car « ce n’est pas un entier ». A-t-il raison ?

::: methode
Relier le quotient à une division décimale.
:::

::: etape Calculer la solution
$x=3\div5=\frac35=0{,}6$.
:::

::: etape Vérifier et conclure
$5\times0{,}6=3$. Sans contrainte de nombre entier dans l’énoncé, cette solution est autorisée.
:::

::: resultat
Non : $x=\frac35=0{,}6$ convient.
:::

## Question 3 : Chloé refuse $x=-2$ pour $x+7=5$. Que montre la vérification ?

::: methode
Tester l’égalité avant d’écarter un signe.
:::

::: etape Substituer
$-2+7=5$.
:::

::: etape Conclure
La valeur proposée rend l’égalité vraie. Aucun contexte n’impose ici un nombre positif.
:::

::: resultat
$x=-2$ convient.
:::

## Question 4 : On cherche maintenant un entier x tel que 4x = 18. Quelle est la réponse ?

::: methode
Tenir compte de la contrainte annoncée.
:::

::: etape Retrouver la seule valeur numérique possible
$18\div4=4{,}5$.
:::

::: etape Appliquer la contrainte
4,5 n’est pas un entier. Il n’existe donc pas d’entier satisfaisant la demande, même si l’équation admet cette solution décimale.
:::

::: resultat
Aucune solution entière ; la solution décimale serait 4,5.
:::

::: attention Le bon réflexe
Une vérification se fait dans l’égalité de départ. Ensuite, le contexte peut imposer des contraintes supplémentaires : signe, unité ou nombre entier.
:::

Solution:
<!-- optitab:1 -->
1. $x=7$.
2. Non : $x=\frac35=0{,}6$ convient.
3. $x=-2$ convient.
4. Aucune solution entière ; la solution décimale serait 4,5.

=== Problème - Inconnues - Préparer huit flacons
Id: 2914
Difficulté: hard

Énoncé: <!-- optitab:1 -->
Un bidon vide pèse 1,2 kg. Rempli, il pèse 4,8 kg. Son contenu est réparti également dans 8 flacons. Chaque flacon vide pèse 50 g.

1. Quelle est la masse du contenu du bidon ? Nommer l’inconnue et écrire l’équation.
2. Quelle masse de contenu reçoit un flacon ? Écrire une équation à une opération.
3. Exprimer cette masse en grammes.
4. Combien pèse un flacon rempli ?
5. Combien de kilogrammes de contenu faudrait-il pour remplir 10 flacons de la même façon ? Le bidon suffit-il ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Quelle est la masse du contenu du bidon ? Nommer l’inconnue et écrire l’équation.

::: methode
Séparer la masse du récipient et celle du contenu.
:::

::: etape Traduire
En notant m la masse du contenu en kg, $m+1{,}2=4{,}8$.
:::

::: etape Résoudre et vérifier
$m=4{,}8-1{,}2=3{,}6$ kg ; $3{,}6+1{,}2=4{,}8$.
:::

::: resultat
Le contenu pèse 3,6 kg.
:::

## Question 2 : Quelle masse de contenu reçoit un flacon ? Écrire une équation à une opération.

::: methode
Huit masses identiques reconstituent les 3,6 kg.
:::

::: etape Traduire
Si x est la masse en kg reçue par un flacon, $8x=3{,}6$.
:::

::: etape Partager et vérifier
$x=3{,}6\div8=0{,}45$ kg ; $8\times0{,}45=3{,}6$.
:::

::: resultat
0,45 kg par flacon.
:::

## Question 3 : Exprimer cette masse en grammes.

::: methode
Convertir avant d’ajouter une masse en grammes.
:::

::: etape Convertir
$0{,}45\times1\,000=450$ g.
:::

::: resultat
450 g de contenu.
:::

## Question 4 : Combien pèse un flacon rempli ?

::: methode
Ajouter le récipient à son contenu dans la même unité.
:::

::: etape Ajouter les masses
$450+50=500$ g.
:::

::: resultat
500 g.
:::

## Question 5 : Combien de kilogrammes de contenu faudrait-il pour remplir 10 flacons de la même façon ? Le bidon suffit-il ?

::: methode
Calculer la demande totale puis comparer à la réserve.
:::

::: etape Calculer la quantité nécessaire
$10\times0{,}45=4{,}5$ kg.
:::

::: etape Mesurer le manque
$4{,}5-3{,}6=0{,}9$ kg.
:::

::: resultat
Il faudrait 4,5 kg ; le bidon ne suffit pas, il manque 0,9 kg.
:::

::: attention Le bon réflexe
Chaque équation traduit une seule relation simple. Dans un problème en plusieurs étapes, on réutilise le résultat précédent en précisant ce qu’il mesure.
:::

Solution:
<!-- optitab:1 -->
1. Le contenu pèse 3,6 kg.
2. 0,45 kg par flacon.
3. 450 g de contenu.
4. 500 g.
5. Il faudrait 4,5 kg ; le bidon ne suffit pas, il manque 0,9 kg.
