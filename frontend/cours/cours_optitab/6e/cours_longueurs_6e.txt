    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les unités de longueur</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Les unités principales</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Unités de longueur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour mesurer une longueur, on utilise des <strong>unités</strong>. En France, on utilise principalement :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>mm</strong> (millimètre) : très petites longueurs</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>cm</strong> (centimètre) : longueurs moyennes</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>m</strong> (mètre) : longueurs importantes</li>
                <li style="margin:0; text-align:left;"><strong>km</strong> (kilomètre) : très grandes distances</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples concrets :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">L'épaisseur d'une pièce : <strong>2 mm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">La largeur d'un doigt : <strong>1 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">La longueur d'un bureau : <strong>1,20 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">La distance Paris-Lyon : <strong>460 km</strong></li>
                <li style="margin:0; text-align:left;">La hauteur d'une porte : <strong>2,10 m</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour choisir la bonne unité, pensez à la taille de l'objet : plus l'objet est petit, plus l'unité est petite (mm ou cm), plus l'objet est grand, plus l'unité est grande (m ou km).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Convertir des longueurs</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode de conversion</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment convertir ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour convertir une longueur :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer les unités de départ et d'arrivée</li>
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser la relation entre ces unités</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si on passe à une unité <strong>plus petite</strong>, on <strong>multiplie</strong></li>
                <li style="margin:0; text-align:left;">Si on passe à une unité <strong>plus grande</strong>, on <strong>divise</strong></li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Convertir en centimètres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Convertir <strong>3 m</strong> en centimètres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On passe de m (mètre) à cm (centimètre), donc à une unité <strong>plus petite</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On sait que <strong>1 m = 100 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc <strong>3 m = 3 × 100 = 300 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> 3 m = <strong>300 cm</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Convertir en mètres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Convertir <strong>250 cm</strong> en mètres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On passe de cm (centimètre) à m (mètre), donc à une unité <strong>plus grande</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On sait que <strong>1 m = 100 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc <strong>250 cm = 250 ÷ 100 = 2,5 m</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> 250 cm = <strong>2,5 m</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Convertir en kilomètres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Convertir <strong>5000 m</strong> en kilomètres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On passe de m (mètre) à km (kilomètre), donc à une unité <strong>plus grande</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On sait que <strong>1 km = 1000 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc <strong>5000 m = 5000 ÷ 1000 = 5 km</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> 5000 m = <strong>5 km</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Convertir en millimètres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Convertir <strong>5 cm</strong> en millimètres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On passe de cm (centimètre) à mm (millimètre), donc à une unité <strong>plus petite</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On sait que <strong>1 cm = 10 mm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc <strong>5 cm = 5 × 10 = 50 mm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> 5 cm = <strong>50 mm</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour ne pas se tromper :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Vers une unité <strong>plus petite</strong> = on <strong>multiplie</strong> (il faut plus de petites unités pour faire la même longueur)</li>
                <li style="margin:0; text-align:left;">Vers une unité <strong>plus grande</strong> = on <strong>divise</strong> (il faut moins de grandes unités pour faire la même longueur)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III bis. Comparer des longueurs</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode de comparaison</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment comparer deux longueurs ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer deux longueurs, on les écrit dans <strong>la même unité</strong>, puis on compare les nombres.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Comparer 120 cm et 1,2 m</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On convertit dans la même unité : <strong>1,2 m = 120 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On compare : <strong>120 cm</strong> et <strong>120 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> <strong>120 cm = 1,2 m</strong> (elles sont égales)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Comparer 3,5 km et 3500 m</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On convertit dans la même unité : <strong>3500 m = 3,5 km</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On compare : <strong>3,5 km</strong> et <strong>3,5 km</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> <strong>3,5 km = 3500 m</strong> (elles sont égales)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Comparer 150 cm et 1,40 m</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On convertit dans la même unité : <strong>150 cm = 1,50 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On compare : <strong>1,50 m</strong> et <strong>1,40 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Comme <strong>1,50 > 1,40</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> <strong>150 cm > 1,40 m</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer, pense à mettre les deux longueurs dans la même unité. Ensuite, compare les nombres comme d'habitude (<strong>&gt;</strong>, <strong>&lt;</strong>, ou <strong>=</strong>).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Mesurer une longueur à la règle</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Utiliser une règle graduée</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment mesurer avec une règle ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour mesurer une longueur à la règle :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Placer la règle le long de l'objet à mesurer</li>
                <li style="margin:0 0 12px 0; text-align:left;">Alignement : le début de l'objet doit être sur le <strong>0</strong> de la règle</li>
                <li style="margin:0 0 12px 0; text-align:left;">Lire la graduation où se trouve l'autre extrémité de l'objet</li>
                <li style="margin:0; text-align:left;">Noter la mesure avec l'unité (cm ou mm selon la règle)</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Mesurer un segment</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut mesurer la longueur d'un segment AB.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On place le point A sur le <strong>0</strong> de la règle</li>
                <li style="margin:0 0 12px 0; text-align:left;">On lit où se trouve le point B</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si B est sur la graduation <strong>7</strong>, alors AB = <strong>7 cm</strong></li>
                <li style="margin:0; text-align:left;">Si B est entre <strong>7</strong> et <strong>8</strong>, on peut lire <strong>7,5 cm</strong> par exemple</li>
            </ul>
        </div>

        <div style="text-align:center; margin:15px 0;">

        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Erreurs courantes à éviter :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas commencer à <strong>0</strong> : si on commence à 1 cm et que l'objet arrive à 6 cm, la longueur est <strong>6 - 1 = 5 cm</strong> (pas 6 cm !)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier l'unité : toujours noter <strong>cm</strong> ou <strong>mm</strong></li>
                <li style="margin:0; text-align:left;">Lire de travers : la règle doit être bien alignée avec l'objet</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une règle, les grandes graduations indiquent les <strong>centimètres</strong> (cm) et les petites graduations indiquent les <strong>millimètres</strong> (mm). Il y a 10 mm entre chaque cm.</p>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Estimer une longueur</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Choisir l'unité adaptée</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Estimation d'une longueur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Avant de mesurer, il faut <strong>estimer</strong> la longueur pour choisir l'unité la plus adaptée. Cela permet de vérifier que notre mesure est réaliste.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Longueur d'une cour de récréation</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Faut-il mesurer en mètres ou en kilomètres ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Une cour de récréation mesure généralement entre <strong>20 m</strong> et <strong>50 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Un kilomètre correspond à <strong>1000 m</strong>, c'est beaucoup trop !</li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> On mesure en <strong>mètres</strong> (m), pas en kilomètres.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Épaisseur d'un cahier</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Faut-il mesurer en millimètres ou en mètres ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">L'épaisseur d'un cahier est très petite, environ <strong>5 mm</strong> ou <strong>1 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Un mètre correspond à <strong>100 cm</strong>, c'est beaucoup trop grand !</li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> On mesure en <strong>millimètres</strong> (mm) ou <strong>centimètres</strong> (cm).</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Distance entre la maison et le collège</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Faut-il mesurer en mètres ou en kilomètres ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">La distance entre la maison et le collège peut être de <strong>500 m</strong> à <strong>5 km</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les distances assez longues, on utilise généralement les <strong>kilomètres</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> On mesure en <strong>kilomètres</strong> (km) pour une distance importante, ou en <strong>mètres</strong> (m) si c'est proche.</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour choisir la bonne unité, pense à la taille de l'objet ou de la distance :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Très petit</strong> (doigt, épaisseur) → <strong>mm</strong> ou <strong>cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Moyen</strong> (bureau, salle) → <strong>m</strong> ou <strong>cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Très grand</strong> (distance entre villes) → <strong>km</strong></li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Mesures en contexte</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Situations de la vie quotidienne</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Longueur d'un bureau</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un bureau mesure <strong>120 cm</strong> de longueur.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Questions :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Combien mesure-t-il en mètres ? <strong>120 cm = 120 ÷ 100 = 1,20 m</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Combien mesure-t-il en millimètres ? <strong>120 cm = 120 × 10 = 1200 mm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> Le bureau mesure <strong>1,20 m</strong> ou <strong>1200 mm</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Longueur d'une salle</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une salle de classe mesure <strong>8 m</strong> de longueur et <strong>6 m</strong> de largeur.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Questions :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Quelle est sa longueur en centimètres ? <strong>8 m = 8 × 100 = 800 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Quelle est sa largeur en centimètres ? <strong>6 m = 6 × 100 = 600 cm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> La salle mesure <strong>800 cm</strong> de longueur et <strong>600 cm</strong> de largeur.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Distance sur un plan</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur un plan à l'échelle, <strong>1 cm</strong> représente <strong>100 m</strong> en réalité.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur ce plan, la distance entre deux bâtiments mesure <strong>5 cm</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quelle est la distance réelle entre les deux bâtiments ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Sur le plan : <strong>5 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">En réalité : <strong>5 × 100 = 500 m</strong></li>
                <li style="margin:0; text-align:left;">On peut aussi dire : <strong>500 m = 0,5 km</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> La distance réelle est de <strong>500 m</strong> (ou <strong>0,5 km</strong>).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Parcours sportif</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un coureur parcourt <strong>3,5 km</strong> lors d'une course.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Combien de mètres a-t-il parcourus ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On passe de km à m, donc à une unité <strong>plus petite</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On sait que <strong>1 km = 1000 m</strong></li>
                <li style="margin:0; text-align:left;">Donc <strong>3,5 km = 3,5 × 1000 = 3500 m</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> Le coureur a parcouru <strong>3500 m</strong>.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Éviter les mélanges d'unités</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Importance de l'unité unique</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règle importante</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour faire des calculs (addition, soustraction), toutes les longueurs doivent être exprimées dans <strong>la même unité</strong>.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>❌ Erreur à éviter :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On ne peut <strong>pas</strong> additionner directement :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>2 m + 50 cm = ?</strong> ❌</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il faut d'abord convertir dans la même unité !</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Addition de longueurs</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut calculer : <strong>2 m + 50 cm</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Convertir toutes les longueurs dans la même unité (par exemple en cm)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>2 m = 2 × 100 = 200 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>50 cm = 50 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Additionner : <strong>200 cm + 50 cm = 250 cm</strong></li>
                <li style="margin:0; text-align:left;">On peut aussi dire : <strong>250 cm = 2,5 m</strong></li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> 2 m + 50 cm = <strong>250 cm</strong> ou <strong>2,5 m</strong></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Soustraction de longueurs</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut calculer : <strong>1,5 m - 30 cm</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Convertir toutes les longueurs dans la même unité (par exemple en cm)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>1,5 m = 1,5 × 100 = 150 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>30 cm = 30 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Soustraire : <strong>150 cm - 30 cm = 120 cm</strong></li>
                <li style="margin:0; text-align:left;">On peut aussi dire : <strong>120 cm = 1,20 m</strong></li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> 1,5 m - 30 cm = <strong>120 cm</strong> ou <strong>1,20 m</strong></p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Avant de faire un calcul avec des longueurs :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier si toutes les longueurs ont la même unité</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si non, convertir toutes dans la même unité</li>
                <li style="margin:0; text-align:left;">Ensuite seulement, faire le calcul</li>
            </ol>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour choisir l'unité de conversion, regardez l'unité la plus présente dans votre calcul. Si vous avez surtout des mètres et centimètres, convertissez tout en centimètres.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour convertir</strong> : identifier d'abord si on va vers une unité plus petite (multiplier) ou plus grande (diviser)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour comparer des longueurs</strong> : toujours les mettre dans la même unité avant de comparer les nombres</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour mesurer à la règle</strong> : toujours placer le début de l'objet sur le <strong>0</strong> de la règle</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour choisir l'unité adaptée</strong> : penser à la taille de l'objet (très petit → mm/cm, moyen → m, très grand → km)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour faire des calculs</strong> : convertir toutes les longueurs dans la même unité avant d'additionner ou soustraire</li>
                <li style="margin:0; text-align:left;"><strong>Pour vérifier une mesure</strong> : estimer d'abord la longueur pour vérifier que le résultat est réaliste</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de convertir dans la même unité avant de comparer ou calculer des longueurs</li>
                <li style="margin:0 0 12px 0; text-align:left;">Se tromper dans la conversion : multiplier au lieu de diviser (ou inversement)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier l'unité dans la réponse (toujours écrire <strong>cm</strong>, <strong>m</strong>, <strong>km</strong>, etc.)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mélanger les unités dans un calcul (par exemple : additionner 2 m + 50 cm sans convertir)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas commencer à <strong>0</strong> sur la règle : si on commence à 1 cm et arrive à 6 cm, la longueur est <strong>5 cm</strong> (pas 6 cm)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre les relations : penser que 1 m = 10 cm au lieu de 1 m = 100 cm</li>
                <li style="margin:0 0 12px 0; text-align:left;">Choisir une unité inadaptée : mesurer l'épaisseur d'un cahier en mètres au lieu de millimètres</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la cohérence du résultat : si on mesure un bureau et qu'on trouve 150 km, c'est évident que c'est faux !</li>
            </ul>
        </div>
    </div>
