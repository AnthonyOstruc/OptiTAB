Titre: Comprendre le hasard

<!-- optitab:1 -->
::: objectifs
Savoir qu’une probabilité est un nombre compris entre 0 et 1. Calculer une probabilité dans une situation d’équiprobabilité. Comparer les résultats d’essais répétés à une probabilité calculée.
:::

::: remarque Avant de commencer
« a chances sur b » au CM2 ; fractions, décimaux, pourcentages.
:::

## 1. Du langage des chances au nombre

::: definition
Une expérience est aléatoire quand on connaît les résultats possibles, appelés issues, sans pouvoir prévoir lequel se produira. La probabilité d’un événement est un nombre compris entre 0 et 1 : 0 pour un événement impossible, 1 pour un événement certain.
:::

[IMAGE_1]

## 2. Recenser les possibilités et calculer

::: propriete
Quand toutes les issues ont la même chance de se produire, on parle d’équiprobabilité. La probabilité d’un événement est alors le quotient du nombre d’issues favorables par le nombre total d’issues : « $a$ chances sur $b$ » devient le nombre $\frac ab$.
:::

::: exemple
Avec un dé équilibré à six faces, la probabilité d’obtenir 6 est $\frac16$ ; celle d’obtenir un nombre pair est $\frac36=\frac12$, car 2, 4 et 6 conviennent.
:::

## 3. Relier les écritures et comparer

::: remarque Changer d’écriture
Une probabilité peut s’écrire avec une fraction, un décimal ou un pourcentage : $\frac12=0{,}5=50$ % ; $\frac14=0{,}25=25$ %. Pour comparer deux probabilités, on les écrit sous la même forme.
:::

::: remarque Recenser deux étapes
Pour deux pièces lancées, un arbre ou un tableau recense les 4 issues PP, PF, FP et FF, qui sont équiprobables : obtenir une pile et une face a donc 2 chances sur 4.
:::

## 4. Observer des essais répétés

::: definition
Quand on répète une expérience, la fréquence d’un résultat est le quotient de son nombre d’apparitions par le nombre d’essais.
:::

[IMAGE_2]

::: propriete
Quand le nombre d’essais devient grand, la fréquence se rapproche en général de la probabilité. On ne peut pourtant jamais prévoir le résultat d’un essai : le hasard n’a pas de mémoire.
:::
