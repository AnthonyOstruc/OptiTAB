=== Découverte - Lire et écrire les grands nombres
Id: 3167
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère le nombre $N = 6\,052\,708\,300$.

[IMAGE_1]

1. Recopier le tableau de numération et y placer le nombre $N$.
2. Écrire le nombre $N$ en lettres.
3. Écrire en chiffres :
   - a) quarante-mille-six-cent-cinq ;
   - b) trois millions deux-cent-mille ;
   - c) neuf milliards dix-huit millions sept-cents.
4. Écrire en lettres :
   - a) $70\,080$ ;
   - b) $200\,000\,000$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Placer $N$ dans le tableau

::: methode
Partir de la droite : les trois derniers chiffres vont dans la classe des unités, les trois suivants dans celle des mille, et ainsi de suite.
:::

::: etape Former les classes
$N = 6\,052\,708\,300$ se découpe en $6 \mid 052 \mid 708 \mid 300$ : $6$ milliards, $52$ millions, $708$ mille et $300$ unités.
:::

[IMAGE_2]

::: resultat
Classe des milliards : $6$ ; des millions : $052$ ; des mille : $708$ ; des unités : $300$.
:::

## Question 2 : Écrire $N$ en lettres

::: methode
Lire chaque classe comme un nombre de trois chiffres, suivi du nom de la classe (sauf pour la classe des unités).
:::

::: etape Lire classe par classe
- $6$ milliards : « six milliards » ;
- $052$ millions : « cinquante-deux millions » ;
- $708$ mille : « sept-cent-huit-mille » ;
- $300$ : « trois-cents » (le « s » de cents, car $300$ termine le nombre).
:::

::: resultat
$N$ = six milliards cinquante-deux millions sept-cent-huit-mille-trois-cents.
:::

## Question 3 : Écrire en chiffres

::: methode
Repérer chaque classe nommée, écrire chaque classe avec trois chiffres et compléter les classes absentes par $000$.
:::

::: etape a) quarante-mille-six-cent-cinq
Classe des mille : $40$ ; classe des unités : $605$. On obtient $40\,605$.
:::

::: etape b) trois millions deux-cent-mille
Millions : $3$ ; mille : $200$ ; unités : aucune, donc $000$. On obtient $3\,200\,000$.
:::

::: etape c) neuf milliards dix-huit millions sept-cents
Milliards : $9$ ; millions : $018$ ; mille : aucun, donc $000$ ; unités : $700$. On obtient $9\,018\,000\,700$.
:::

::: resultat
a) $40\,605$ ; b) $3\,200\,000$ ; c) $9\,018\,000\,700$.
:::

## Question 4 : Écrire en lettres

::: methode
Découper en classes, puis appliquer les règles : « mille » est invariable, « vingt » et « cent » prennent un « s » quand ils sont multipliés et terminent le nombre, ou quand ils sont suivis de « millions ».
:::

::: etape a) $70\,080$
$70$ mille et $80$ unités : « soixante-dix-mille-quatre-vingts ». Quatre-vingts prend un « s » : il termine le nombre.
:::

::: etape b) $200\,000\,000$
$200$ millions : « deux-cents millions ». Cents prend un « s » : il est multiplié par deux, et le mot qui suit, « millions », est un nom et non un mot-nombre.
:::

::: resultat
a) soixante-dix-mille-quatre-vingts ; b) deux-cents millions.
:::

::: attention Erreur fréquente
Oublier les zéros d'une classe vide : « neuf milliards dix-huit millions sept-cents » ne s'écrit pas $9\,018\,700$. Chaque classe, sauf la première, a **toujours trois chiffres**.
:::

Solution:
<!-- optitab:1 -->
1. $6 \mid 052 \mid 708 \mid 300$ : milliards $6$, millions $052$, mille $708$, unités $300$.
2. Six milliards cinquante-deux millions sept-cent-huit-mille-trois-cents.
3. a) $40\,605$ ; b) $3\,200\,000$ ; c) $9\,018\,000\,700$.
4. a) soixante-dix-mille-quatre-vingts ; b) deux-cents millions.

=== Découverte - Dixièmes et centièmes en images
Id: 3170
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dans la figure A, l'unité est la bande entière, partagée en $10$ parts égales. Dans les figures B, C et D, l'unité est un grand carré, partagé en $100$ petits carrés égaux.

[IMAGE_1]

1. Quelle fraction de l'unité représente une part de la bande ? un petit carré ? une colonne d'un grand carré ?
2. Pour les figures A, B et D, écrire le nombre représenté par la partie coloriée sous la forme d'une fraction décimale, puis avec une virgule.
3. Dans la figure B, combien de colonnes entières et combien de petits carrés isolés sont coloriés ? Compléter : $0{,}36 = \ldots$ dixièmes $+ \ldots$ centièmes.
4. La figure C représente un nombre plus grand que $1$. L'écrire sous la forme d'un nombre mixte, puis d'une fraction décimale, puis avec une virgule.
5. Combien de petits carrés faut-il colorier dans un grand carré pour représenter $0{,}6$ ? et pour représenter $0{,}06$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les parts de l'unité

::: methode
Compter en combien de parts égales l'unité est partagée.
:::

::: etape Bande et carré
- La bande est partagée en $10$ : une part est **un dixième**, $\frac{1}{10}$.
- Le carré est partagé en $100$ : un petit carré est **un centième**, $\frac{1}{100}$.
- Le carré compte $10$ colonnes égales : une colonne est un dixième, et elle contient $10$ petits carrés, donc $\frac{1}{10} = \frac{10}{100}$.
:::

::: resultat
Une part de la bande : $\frac{1}{10}$ ; un petit carré : $\frac{1}{100}$ ; une colonne : $\frac{1}{10} = \frac{10}{100}$.
:::

## Question 2 : Figures A, B et D

::: methode
Compter les parts coloriées : c'est le numérateur. Le dénominateur est le nombre de parts de l'unité.
:::

::: etape Compter
- Figure A : $7$ parts sur $10$ : $\frac{7}{10}$, sept dixièmes.
- Figure B : $3$ colonnes de $10$ et $6$ petits carrés, soit $30 + 6 = 36$ petits carrés : $\frac{36}{100}$.
- Figure D : $4$ petits carrés : $\frac{4}{100}$, quatre centièmes.
:::

::: etape Écrire avec une virgule
Les dixièmes s'écrivent au premier rang après la virgule, les centièmes au deuxième :
$$\frac{7}{10} = 0{,}7 \qquad \frac{36}{100} = 0{,}36 \qquad \frac{4}{100} = 0{,}04$$
:::

[IMAGE_2]

::: resultat
A : $\frac{7}{10} = 0{,}7$ ; B : $\frac{36}{100} = 0{,}36$ ; D : $\frac{4}{100} = 0{,}04$.
:::

## Question 3 : Dixièmes et centièmes de la figure B

::: methode
Une colonne entière est un dixième ; un petit carré isolé est un centième.
:::

::: etape Lire la figure
$3$ colonnes entières et $6$ petits carrés isolés sont coloriés.
:::

::: resultat
$0{,}36 = 3$ dixièmes $+ 6$ centièmes.
:::

## Question 4 : La figure C

::: methode
Un grand carré entièrement colorié représente une unité entière ; le second carré donne la partie plus petite que $1$.
:::

::: etape Nombre mixte
Premier carré : $1$ unité. Second carré : $4$ colonnes et $5$ petits carrés, soit $45$ centièmes. Donc le nombre est $1 + \frac{45}{100}$.
:::

::: etape Fraction décimale et virgule
Une unité vaut $100$ centièmes :
$$1 + \frac{45}{100} = \frac{100}{100} + \frac{45}{100} = \frac{145}{100} = 1{,}45$$
:::

::: resultat
$1 + \frac{45}{100} = \frac{145}{100} = 1{,}45$.
:::

## Question 5 : Représenter $0{,}6$ et $0{,}06$

::: methode
Traduire chaque nombre en centièmes, car un petit carré est un centième.
:::

::: etape Convertir en centièmes
- $0{,}6 = \frac{6}{10} = \frac{60}{100}$ : $60$ petits carrés, soit $6$ colonnes entières.
- $0{,}06 = \frac{6}{100}$ : $6$ petits carrés.
:::

::: resultat
$60$ petits carrés pour $0{,}6$ ; $6$ petits carrés pour $0{,}06$.
:::

::: attention Erreur fréquente
Confondre $0{,}6$ et $0{,}06$ : le chiffre $6$ n'est pas au même rang. $0{,}6$ compte six **dixièmes** (six colonnes), $0{,}06$ six **centièmes** (six petits carrés) : le premier est dix fois plus grand.
:::

Solution:
<!-- optitab:1 -->
1. Une part de la bande : $\frac{1}{10}$ ; un petit carré : $\frac{1}{100}$ ; une colonne : $\frac{1}{10} = \frac{10}{100}$.
2. A : $\frac{7}{10} = 0{,}7$ ; B : $\frac{36}{100} = 0{,}36$ ; D : $\frac{4}{100} = 0{,}04$.
3. $3$ colonnes et $6$ petits carrés : $0{,}36 = 3$ dixièmes $+ 6$ centièmes.
4. $1 + \frac{45}{100} = \frac{145}{100} = 1{,}45$.
5. $60$ petits carrés pour $0{,}6$ ; $6$ pour $0{,}06$.

=== Découverte - Fractions décimales et écriture à virgule
Id: 3169
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire chaque fraction décimale avec une virgule.
   - a) $\frac{3}{10}$ ; b) $\frac{27}{100}$ ; c) $\frac{9}{1\,000}$
   - d) $\frac{47}{10}$ ; e) $\frac{2\,305}{100}$ ; f) $\frac{6}{100}$
2. Écrire chaque nombre sous la forme d'une fraction décimale.
   - a) $0{,}7$ ; b) $0{,}25$ ; c) $0{,}048$
   - d) $3{,}6$ ; e) $12{,}09$ ; f) $5{,}002$
3. Compléter : $0{,}5 = \frac{\ldots}{10} = \frac{\ldots}{100} = \frac{\ldots}{1\,000}$.
4. Tom a écrit : « $\frac{6}{100} = 0{,}6$ ». Expliquer son erreur et corriger.

Étapes:
<!-- optitab:1 -->
## Question 1 : De la fraction décimale à la virgule

::: methode
Le dénominateur indique le rang du dernier chiffre : $10 \to$ dixièmes (1 chiffre après la virgule), $100 \to$ centièmes (2 chiffres), $1\,000 \to$ millièmes (3 chiffres). On complète par des zéros si besoin.
:::

::: etape a), b) et c)
- a) $\frac{3}{10}$ : trois dixièmes, $0{,}3$.
- b) $\frac{27}{100}$ : vingt-sept centièmes, le $7$ est aux centièmes : $0{,}27$.
- c) $\frac{9}{1\,000}$ : le $9$ est aux millièmes, il faut deux zéros avant lui : $0{,}009$.
:::

::: etape d), e) et f)
- d) $\frac{47}{10}$ : le $7$ est aux dixièmes : $4{,}7$.
- e) $\frac{2\,305}{100}$ : le $5$ est aux centièmes : $23{,}05$.
- f) $\frac{6}{100}$ : le $6$ est aux centièmes : $0{,}06$.
:::

::: resultat
a) $0{,}3$ ; b) $0{,}27$ ; c) $0{,}009$ ; d) $4{,}7$ ; e) $23{,}05$ ; f) $0{,}06$.
:::

## Question 2 : De la virgule à la fraction décimale

::: methode
Regarder le rang du dernier chiffre écrit : il donne le dénominateur. Le numérateur est le nombre écrit sans la virgule (sans les zéros inutiles du début).
:::

::: etape a), b) et c)
- a) $0{,}7$ se termine aux dixièmes : $\frac{7}{10}$.
- b) $0{,}25$ se termine aux centièmes : $\frac{25}{100}$.
- c) $0{,}048$ se termine aux millièmes : $\frac{48}{1\,000}$.
:::

::: etape d), e) et f)
- d) $3{,}6$ se termine aux dixièmes : $\frac{36}{10}$.
- e) $12{,}09$ se termine aux centièmes : $\frac{1\,209}{100}$.
- f) $5{,}002$ se termine aux millièmes : $\frac{5\,002}{1\,000}$.
:::

::: resultat
a) $\frac{7}{10}$ ; b) $\frac{25}{100}$ ; c) $\frac{48}{1\,000}$ ; d) $\frac{36}{10}$ ; e) $\frac{1\,209}{100}$ ; f) $\frac{5\,002}{1\,000}$.
:::

## Question 3 : Écritures égales de $0{,}5$

::: methode
Utiliser les liens : $1$ dixième $= 10$ centièmes $= 100$ millièmes.
:::

::: etape Convertir
$0{,}5$, c'est $5$ dixièmes, soit $5 \times 10 = 50$ centièmes, soit $5 \times 100 = 500$ millièmes.
:::

::: resultat
$0{,}5 = \frac{5}{10} = \frac{50}{100} = \frac{500}{1\,000}$.
:::

## Question 4 : L'erreur de Tom

::: methode
Lire la fraction à voix haute : le dénominateur dit dans quel rang placer le dernier chiffre.
:::

::: etape Lire la fraction
$\frac{6}{100}$ se lit « six centièmes » : le $6$ doit être au rang des centièmes, le deuxième après la virgule. Tom l'a placé au rang des dixièmes : $0{,}6$ vaut six dixièmes, c'est-à-dire $\frac{6}{10}$.
:::

::: resultat
$\frac{6}{100} = 0{,}06$ (et non $0{,}6$, qui vaut $\frac{6}{10}$).
:::

::: retenir
Avec une virgule, il y a autant de chiffres après la virgule que de zéros au dénominateur de la fraction décimale : $\frac{9}{1\,000} = 0{,}009$ (trois zéros, trois chiffres).
:::

Solution:
<!-- optitab:1 -->
1. a) $0{,}3$ ; b) $0{,}27$ ; c) $0{,}009$ ; d) $4{,}7$ ; e) $23{,}05$ ; f) $0{,}06$.
2. a) $\frac{7}{10}$ ; b) $\frac{25}{100}$ ; c) $\frac{48}{1\,000}$ ; d) $\frac{36}{10}$ ; e) $\frac{1\,209}{100}$ ; f) $\frac{5\,002}{1\,000}$.
3. $0{,}5 = \frac{5}{10} = \frac{50}{100} = \frac{500}{1\,000}$.
4. $\frac{6}{100} = 0{,}06$ ; Tom a placé le $6$ au rang des dixièmes.

=== Entraînement - Partie entière et valeur des chiffres
Id: 3168
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une balance de laboratoire affiche une masse de $306{,}048$ g.

[IMAGE_1]

1. Recopier le tableau de numération et y placer le nombre $306{,}048$.
2. Donner la partie entière et la partie décimale de ce nombre.
3. Chiffres et valeurs.
   - a) Donner le chiffre des dizaines, le chiffre des dixièmes et le chiffre des millièmes.
   - b) Quelle est la valeur du chiffre $4$ ? du chiffre $8$ ? Les écrire avec une fraction décimale, puis avec une virgule.
4. Compléter la décomposition : $306{,}048 = 300 + \ldots + \frac{4}{\ldots} + \frac{\ldots}{1\,000}$.
5. Écrire avec une virgule le nombre formé de :
   - a) $5$ dizaines, $2$ unités et $7$ centièmes ;
   - b) $4 + \frac{3}{10} + \frac{9}{1\,000}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Placer le nombre dans le tableau

::: methode
Placer d'abord le chiffre des unités, celui qui est juste à gauche de la virgule, puis les autres chiffres de part et d'autre.
:::

::: etape Partie entière, puis partie décimale
- À gauche de la virgule : $3$ centaines, $0$ dizaine, $6$ unités.
- À droite de la virgule : $0$ dixième, $4$ centièmes, $8$ millièmes.
:::

[IMAGE_2]

::: resultat
$306{,}048$ : centaines $3$, dizaines $0$, unités $6$, dixièmes $0$, centièmes $4$, millièmes $8$.
:::

## Question 2 : Partie entière et partie décimale

::: methode
La partie entière est le nombre écrit à gauche de la virgule ; la partie décimale est ce qui reste, plus petit que $1$.
:::

::: etape Séparer
$$306{,}048 = 306 + 0{,}048$$
:::

::: resultat
Partie entière : $306$ ; partie décimale : $0{,}048$.
:::

## Question 3 : Chiffres et valeurs

::: methode
Le rang d'un chiffre donne sa valeur : un chiffre des centièmes vaut ce nombre de centièmes.
:::

::: etape a) Lire les chiffres dans le tableau
Chiffre des dizaines : $0$ ; chiffre des dixièmes : $0$ ; chiffre des millièmes : $8$.
:::

::: etape b) Valeurs des chiffres $4$ et $8$
- Le $4$ est au rang des centièmes : il vaut $\frac{4}{100} = 0{,}04$.
- Le $8$ est au rang des millièmes : il vaut $\frac{8}{1\,000} = 0{,}008$.
:::

::: resultat
a) $0$ ; $0$ ; $8$. b) Le $4$ vaut $\frac{4}{100} = 0{,}04$ ; le $8$ vaut $\frac{8}{1\,000} = 0{,}008$.
:::

## Question 4 : La décomposition

::: methode
Additionner les valeurs des chiffres non nuls, rang par rang.
:::

::: etape Valeur de chaque chiffre non nul
$3$ centaines $= 300$ ; $6$ unités $= 6$ ; $4$ centièmes $= \frac{4}{100}$ ; $8$ millièmes $= \frac{8}{1\,000}$.
:::

::: resultat
$$306{,}048 = 300 + 6 + \frac{4}{100} + \frac{8}{1\,000}$$
:::

## Question 5 : Écrire un nombre à partir de ses chiffres

::: methode
Placer chaque chiffre à son rang et écrire $0$ dans les rangs vides situés entre deux chiffres.
:::

::: etape a) $5$ dizaines, $2$ unités et $7$ centièmes
Partie entière : $52$. Dixièmes : aucun, donc $0$ ; centièmes : $7$. On obtient $52{,}07$.
:::

::: etape b) $4 + \frac{3}{10} + \frac{9}{1\,000}$
$4$ unités, $3$ dixièmes, $0$ centième, $9$ millièmes : $4{,}309$.
:::

::: resultat
a) $52{,}07$ ; b) $4{,}309$.
:::

::: attention Erreur fréquente
Oublier un zéro intérieur : $4 + \frac{3}{10} + \frac{9}{1\,000}$ ne s'écrit pas $4{,}39$, qui voudrait dire $3$ dixièmes et $9$ **centièmes**. Le zéro réserve le rang des centièmes.
:::

Solution:
<!-- optitab:1 -->
1. Centaines $3$, dizaines $0$, unités $6$ ; dixièmes $0$, centièmes $4$, millièmes $8$.
2. Partie entière $306$ ; partie décimale $0{,}048$.
3. a) $0$ ; $0$ ; $8$. b) $\frac{4}{100} = 0{,}04$ ; $\frac{8}{1\,000} = 0{,}008$.
4. $306{,}048 = 300 + 6 + \frac{4}{100} + \frac{8}{1\,000}$.
5. a) $52{,}07$ ; b) $4{,}309$.

=== Entraînement - Le chiffre des… ou le nombre de… ?
Id: 3171
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
1. On considère le nombre $7\,485\,213\,906$.
   - a) Quel est le chiffre des millions ? Quel est le nombre de millions ?
   - b) Quel est le chiffre des centaines de mille ? Quel est le nombre de milliers ?
   - c) Quel est le chiffre des milliards ?
2. On considère le nombre $52{,}836$.
   - a) Quel est le chiffre des dixièmes ? Quel est le nombre de dixièmes ?
   - b) Quel est le nombre de centièmes ?
3. Léa affirme : « Dans $6{,}25$, il y a $25$ dixièmes. » A-t-elle raison ? Donner le nombre de dixièmes, puis le nombre de centièmes de $6{,}25$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Dans $7\,485\,213\,906$

::: methode
Le **chiffre des…** est le seul chiffre écrit à ce rang. Le **nombre de…** s'obtient en gardant tous les chiffres situés à gauche de ce rang, ce rang compris.
:::

::: etape Repérer les classes
$7 \mid 485 \mid 213 \mid 906$ : milliards $7$, millions $485$, mille $213$, unités $906$.
:::

::: etape a) Les millions
Le rang des millions est le dernier chiffre de la classe des millions : $5$. En gardant tout ce qui est à gauche, ce rang compris, on lit $7\,485$.
:::

[IMAGE_1]

::: etape b) Les centaines de mille et les milliers
- Le chiffre des centaines de mille est le premier chiffre de la classe des mille : $2$.
- Nombre de milliers : on garde tout jusqu'au rang des mille : $7\,485\,213$.
:::

::: etape c) Les milliards
La classe des milliards ne contient qu'un chiffre : $7$.
:::

::: resultat
a) Chiffre des millions : $5$ ; nombre de millions : $7\,485$. b) Chiffre des centaines de mille : $2$ ; nombre de milliers : $7\,485\,213$. c) Chiffre des milliards : $7$.
:::

## Question 2 : Dans $52{,}836$

::: methode
Pour un nombre décimal, le nombre de dixièmes se lit aussi en gardant tous les chiffres jusqu'au rang des dixièmes, sans la virgule.
:::

::: etape a) Les dixièmes
Le chiffre des dixièmes est le premier après la virgule : $8$. Les $52$ unités valent $520$ dixièmes ; avec les $8$ dixièmes, cela fait $520 + 8 = 528$ dixièmes.
:::

::: etape b) Les centièmes
Les $52$ unités valent $5\,200$ centièmes, et $0{,}83 = 83$ centièmes : $5\,200 + 83 = 5\,283$ centièmes (il reste $6$ millièmes).
:::

::: resultat
a) Chiffre des dixièmes : $8$ ; nombre de dixièmes : $528$. b) Nombre de centièmes : $5\,283$.
:::

## Question 3 : L'affirmation de Léa

::: methode
Convertir les unités entières en dixièmes avant d'ajouter les dixièmes.
:::

::: etape Compter les dixièmes
$6{,}25 = 6 + \frac{2}{10} + \frac{5}{100}$. Les $6$ unités valent $60$ dixièmes ; avec $2$ dixièmes, on obtient $62$ dixièmes, et il reste $5$ centièmes.
:::

::: etape Compter les centièmes
$6{,}25 = \frac{625}{100}$ : il y a $625$ centièmes.
:::

::: resultat
Non : $6{,}25$ contient $62$ dixièmes (et $5$ centièmes), soit $625$ centièmes. Les « $25$ » de Léa sont des centièmes.
:::

::: attention Erreur fréquente
Répondre au « nombre de… » avec un seul chiffre : dans $7\,485\,213\,906$, il n'y a pas $5$ millions mais $7\,485$ millions, car les $7$ milliards contiennent déjà $7\,000$ millions.
:::

Solution:
<!-- optitab:1 -->
1. a) $5$ ; $7\,485$. b) $2$ ; $7\,485\,213$. c) $7$.
2. a) $8$ ; $528$ dixièmes. b) $5\,283$ centièmes.
3. Non : $62$ dixièmes (et $5$ centièmes), soit $625$ centièmes.

=== Entraînement - Plusieurs écritures d'un même nombre
Id: 3172
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
1. Parmi les écritures suivantes, lesquelles sont égales à $3{,}4$ ?
   - a) $\frac{34}{10}$ ; b) $3 + \frac{4}{100}$ ; c) $\frac{340}{100}$ ; d) $3 + \frac{4}{10}$
   - e) $\frac{34}{100}$ ; f) $3{,}40$ ; g) $3{,}04$ ; h) $3 + \frac{40}{100}$
2. Écrire chaque fraction décimale sous la forme d'un nombre mixte, puis avec une virgule.
   - a) $\frac{2\,375}{1\,000}$ ; b) $\frac{1\,204}{100}$ ; c) $\frac{89}{10}$
3. Écrire chaque nombre mixte sous la forme d'une fraction décimale, puis avec une virgule.
   - a) $5 + \frac{7}{100}$ ; b) $18 + \frac{3}{10}$ ; c) $1 + \frac{25}{1\,000}$
4. Réécrire chaque nombre sans ses zéros inutiles : $05{,}30$ ; $40{,}050$ ; $300{,}0$ ; $0{,}700$.
5. Un entier et un pourcentage.
   - a) Écrire le nombre entier $14$ avec une fraction décimale de dénominateur $10$, puis de dénominateur $100$.
   - b) Écrire $35\,\%$ sous la forme d'une fraction décimale, puis avec une virgule.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les écritures de $3{,}4$

::: methode
Transformer chaque écriture en écriture à virgule, puis comparer avec $3{,}4$ : $3$ unités et $4$ dixièmes.
:::

::: etape Les écritures égales à $3{,}4$
- a) $\frac{34}{10} = 3{,}4$ ;
- c) $\frac{340}{100} = 3{,}40 = 3{,}4$ ;
- d) $3 + \frac{4}{10} = 3{,}4$ ;
- f) $3{,}40 = 3{,}4$ (zéro final) ;
- h) $3 + \frac{40}{100} = 3 + \frac{4}{10} = 3{,}4$.
:::

::: etape Les écritures différentes
- b) $3 + \frac{4}{100} = 3{,}04$ : $4$ centièmes, et non $4$ dixièmes ;
- e) $\frac{34}{100} = 0{,}34$ ;
- g) $3{,}04$ : $0$ dixième et $4$ centièmes.
:::

::: resultat
Sont égales à $3{,}4$ : a), c), d), f) et h).
:::

## Question 2 : De la fraction décimale au nombre mixte

::: methode
Chercher le plus grand nombre d'unités entières contenu dans la fraction : $1 = \frac{10}{10} = \frac{100}{100} = \frac{1\,000}{1\,000}$.
:::

::: etape a) $\frac{2\,375}{1\,000}$
$$
\begin{aligned}
\frac{2\,375}{1\,000} &= \frac{2\,000}{1\,000} + \frac{375}{1\,000}\\
&= 2 + \frac{375}{1\,000} = 2{,}375
\end{aligned}
$$
:::

::: etape b) $\frac{1\,204}{100}$
$$
\begin{aligned}
\frac{1\,204}{100} &= \frac{1\,200}{100} + \frac{4}{100}\\
&= 12 + \frac{4}{100} = 12{,}04
\end{aligned}
$$
:::

::: etape c) $\frac{89}{10}$
$$
\begin{aligned}
\frac{89}{10} &= \frac{80}{10} + \frac{9}{10}\\
&= 8 + \frac{9}{10} = 8{,}9
\end{aligned}
$$
:::

::: resultat
a) $2 + \frac{375}{1\,000} = 2{,}375$ ; b) $12 + \frac{4}{100} = 12{,}04$ ; c) $8 + \frac{9}{10} = 8{,}9$.
:::

## Question 3 : Du nombre mixte à la fraction décimale

::: methode
Écrire la partie entière avec le même dénominateur que la fraction, puis ajouter les numérateurs.
:::

::: etape a) $5 + \frac{7}{100}$
$$
\begin{aligned}
5 + \frac{7}{100} &= \frac{500}{100} + \frac{7}{100}\\
&= \frac{507}{100} = 5{,}07
\end{aligned}
$$
:::

::: etape b) $18 + \frac{3}{10}$
$$
\begin{aligned}
18 + \frac{3}{10} &= \frac{180}{10} + \frac{3}{10}\\
&= \frac{183}{10} = 18{,}3
\end{aligned}
$$
:::

::: etape c) $1 + \frac{25}{1\,000}$
$$
\begin{aligned}
1 + \frac{25}{1\,000} &= \frac{1\,000}{1\,000} + \frac{25}{1\,000}\\
&= \frac{1\,025}{1\,000} = 1{,}025
\end{aligned}
$$
:::

::: resultat
a) $\frac{507}{100} = 5{,}07$ ; b) $\frac{183}{10} = 18{,}3$ ; c) $\frac{1\,025}{1\,000} = 1{,}025$.
:::

## Question 4 : Les zéros inutiles

::: methode
Sont inutiles : les zéros au début de la partie entière et les zéros à la fin de la partie décimale. Les zéros intérieurs sont indispensables.
:::

::: etape Nombre par nombre
- $05{,}30$ : le $0$ du début et le $0$ de la fin sont inutiles : $5{,}3$.
- $40{,}050$ : seul le dernier $0$ est inutile ; le $0$ des unités et le $0$ des dixièmes réservent des rangs : $40{,}05$.
- $300{,}0$ : la partie décimale est nulle : $300$ (les zéros de $300$ sont indispensables).
- $0{,}700$ : $0{,}7$ (le $0$ de la partie entière reste, pour indiquer $0$ unité).
:::

::: resultat
$5{,}3$ ; $40{,}05$ ; $300$ ; $0{,}7$.
:::

## Question 5 : Un entier et un pourcentage

::: methode
Un entier, c'est un nombre de dixièmes ou de centièmes : $1 = \frac{10}{10} = \frac{100}{100}$. Un pourcentage est une fraction de dénominateur $100$.
:::

::: etape a) L'entier $14$
$14$ unités $= 14 \times 10 = 140$ dixièmes $= 14 \times 100 = 1\,400$ centièmes.
:::

::: etape b) $35\,\%$
$35\,\%$ se lit « $35$ pour cent », c'est-à-dire $35$ centièmes : $\frac{35}{100} = 0{,}35$.
:::

::: resultat
a) $14 = \frac{140}{10} = \frac{1\,400}{100}$ : un entier est un nombre décimal. b) $35\,\% = \frac{35}{100} = 0{,}35$.
:::

::: retenir
Un même nombre a plusieurs écritures : $3{,}4 = \frac{34}{10} = \frac{340}{100} = 3 + \frac{4}{10} = 3{,}40$. Pour passer de l'une à l'autre, on utilise $1 = 10$ dixièmes $= 100$ centièmes $= 1\,000$ millièmes.
:::

Solution:
<!-- optitab:1 -->
1. a) $\frac{34}{10}$ ; c) $\frac{340}{100}$ ; d) $3 + \frac{4}{10}$ ; f) $3{,}40$ ; h) $3 + \frac{40}{100}$.
2. a) $2 + \frac{375}{1\,000} = 2{,}375$ ; b) $12 + \frac{4}{100} = 12{,}04$ ; c) $8 + \frac{9}{10} = 8{,}9$.
3. a) $\frac{507}{100} = 5{,}07$ ; b) $\frac{183}{10} = 18{,}3$ ; c) $\frac{1\,025}{1\,000} = 1{,}025$.
4. $5{,}3$ ; $40{,}05$ ; $300$ ; $0{,}7$.
5. a) $14 = \frac{140}{10} = \frac{1\,400}{100}$. b) $35\,\% = \frac{35}{100} = 0{,}35$.

=== Problème - Lire des longueurs sur une règle graduée
Id: 3177
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Sur la règle ci-dessous, l'unité est le centimètre ; chaque centimètre est partagé en $10$ millimètres. En dessous, une loupe agrandit la partie de la règle comprise entre $3{,}2$ cm et $3{,}3$ cm, partagée elle aussi en $10$ parts égales.

[IMAGE_1]

1. Quelle fraction du centimètre représente un millimètre ? Quelle fraction du centimètre représente une petite graduation de la loupe ?
2. Pour chacun des points $A$, $B$ et $C$, écrire sa distance au zéro de la règle, en centimètres, sous la forme d'une fraction décimale, puis avec une virgule. Lorsque cette distance dépasse $1$ cm, l'écrire aussi comme un nombre mixte.
3. Placer sur la règle le point $D$ situé à $\frac{46}{10}$ cm du zéro, et le point $E$ situé à $1 + \frac{5}{10}$ cm du zéro.
4. Le point $F$ est sur la loupe. Écrire sa distance au zéro avec une virgule, puis sous la forme d'une fraction décimale et d'un nombre mixte. Quelle est sa partie entière ?
5. Combien de millimètres séparent le zéro de la règle du point $C$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Valeur des graduations

::: methode
Compter en combien de parts égales est partagé l'intervalle considéré.
:::

::: etape Sur la règle
Un centimètre est partagé en $10$ millimètres : $1$ mm $= \frac{1}{10}$ cm, un dixième de centimètre.
:::

::: etape Sur la loupe
L'intervalle de $3{,}2$ à $3{,}3$ mesure un dixième de centimètre et il est partagé en $10$ : chaque petite graduation vaut un dixième de dixième, c'est-à-dire un centième de centimètre, $\frac{1}{100}$ cm.
:::

::: resultat
$1$ mm $= \frac{1}{10}$ cm ; une graduation de la loupe $= \frac{1}{100}$ cm.
:::

## Question 2 : Les points $A$, $B$ et $C$

::: methode
Compter les millimètres (dixièmes) depuis le zéro : c'est le numérateur de la fraction de dénominateur $10$.
:::

::: etape Le point $A$
$A$ est à $7$ graduations du zéro, avant le $1$ : $\frac{7}{10}$ cm $= 0{,}7$ cm (moins de $1$ cm, pas de nombre mixte).
:::

::: etape Les points $B$ et $C$
- $B$ est $3$ graduations après le $2$ : $2$ cm $+ 3$ mm, soit $20 + 3 = 23$ dixièmes : $\frac{23}{10} = 2 + \frac{3}{10} = 2{,}3$.
- $C$ est $8$ graduations après le $3$ : $30 + 8 = 38$ dixièmes : $\frac{38}{10} = 3 + \frac{8}{10} = 3{,}8$.
:::

[IMAGE_2]

::: resultat
$A$ : $\frac{7}{10} = 0{,}7$ cm ; $B$ : $\frac{23}{10} = 2 + \frac{3}{10} = 2{,}3$ cm ; $C$ : $\frac{38}{10} = 3 + \frac{8}{10} = 3{,}8$ cm.
:::

## Question 3 : Placer $D$ et $E$

::: methode
Transformer chaque écriture en écriture à virgule pour repérer le centimètre, puis le millimètre.
:::

::: etape Le point $D$
$\frac{46}{10} = \frac{40}{10} + \frac{6}{10} = 4 + \frac{6}{10} = 4{,}6$ : $6$ graduations après le $4$.
:::

::: etape Le point $E$
$1 + \frac{5}{10} = 1{,}5$ : $5$ graduations après le $1$, au milieu entre $1$ et $2$.
:::

::: resultat
$D$ à $4{,}6$ cm et $E$ à $1{,}5$ cm du zéro (points verts de la figure de la question 2).
:::

## Question 4 : Le point $F$

::: methode
La loupe commence à $3{,}2$ ; chaque graduation ajoute un centième.
:::

::: etape Lire la loupe
$F$ est à $6$ graduations après $3{,}2$ : $3{,}2 + 6$ centièmes $= 3{,}26$.
:::

::: etape Les autres écritures
$$3{,}26 = \frac{326}{100} = \frac{300}{100} + \frac{26}{100} = 3 + \frac{26}{100}$$
:::

::: resultat
$F$ : $3{,}26$ cm $= \frac{326}{100}$ cm $= 3 + \frac{26}{100}$ cm ; partie entière : $3$.
:::

## Question 5 : Le point $C$ en millimètres

::: methode
$1$ cm $= 10$ mm : le nombre de millimètres est le nombre de dixièmes de centimètre.
:::

::: etape Convertir
$C$ est à $\frac{38}{10}$ cm, c'est-à-dire $38$ dixièmes de centimètre, soit $38$ mm ($3$ cm $= 30$ mm, plus $8$ mm).
:::

::: resultat
$38$ mm séparent le zéro du point $C$.
:::

::: attention Erreur fréquente
Lire $3{,}26$ comme « $3$ et $26$ graduations de la règle » : sur la loupe, chaque graduation est un **centième** de centimètre. $3{,}26$ cm, c'est $3$ cm, $2$ mm et $6$ centièmes de centimètre.
:::

Solution:
<!-- optitab:1 -->
1. $1$ mm $= \frac{1}{10}$ cm ; une graduation de la loupe $= \frac{1}{100}$ cm.
2. $A$ : $\frac{7}{10} = 0{,}7$ ; $B$ : $\frac{23}{10} = 2 + \frac{3}{10} = 2{,}3$ ; $C$ : $\frac{38}{10} = 3 + \frac{8}{10} = 3{,}8$ (en cm).
3. $D$ à $4{,}6$ cm, $E$ à $1{,}5$ cm du zéro.
4. $3{,}26 = \frac{326}{100} = 3 + \frac{26}{100}$ ; partie entière $3$.
5. $38$ mm.

=== Problème - Les mesures du goûter
Id: 3173
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour préparer le goûter de la classe, Inès note les quantités suivantes.

| Produit | Quantité |
|---|---|
| Jus de pomme | $1$ L $250$ mL |
| Farine | $2$ kg $75$ g |
| Ruban pour décorer | $3$ m $8$ cm |

On rappelle que $1$ L $= 1\,000$ mL, $1$ kg $= 1\,000$ g et $1$ m $= 100$ cm.

1. Exprimer chaque quantité dans la petite unité : en mL, en g et en cm.
2. Exprimer chaque quantité dans la grande unité (L, kg, m) sous la forme d'une fraction décimale, puis d'un nombre mixte, puis avec une virgule.
3. Hugo écrit : « $2$ kg $75$ g $= 2{,}75$ kg ». Expliquer son erreur. Quelle masse l'écriture $2{,}75$ kg désigne-t-elle réellement ?
4. Sur une canette, on lit « $0{,}33$ L » ; sur un paquet de sucre, « $0{,}8$ kg ». Exprimer ces quantités en mL et en g.
5. Inès voudrait $2$ L de jus. Combien de millilitres lui manque-t-il ? Écrire cette quantité en litres avec une virgule.

Étapes:
<!-- optitab:1 -->
## Question 1 : Dans la petite unité

::: methode
Convertir la partie dans la grande unité ($\times 1\,000$ ou $\times 100$), puis ajouter le reste.
:::

::: etape Les trois conversions
- Jus : $1$ L $= 1\,000$ mL, donc $1\,000 + 250 = 1\,250$ mL.
- Farine : $2$ kg $= 2\,000$ g, donc $2\,000 + 75 = 2\,075$ g.
- Ruban : $3$ m $= 300$ cm, donc $300 + 8 = 308$ cm.
:::

::: resultat
$1\,250$ mL ; $2\,075$ g ; $308$ cm.
:::

## Question 2 : Dans la grande unité

::: methode
$1$ mL $= \frac{1}{1\,000}$ L, $1$ g $= \frac{1}{1\,000}$ kg et $1$ cm $= \frac{1}{100}$ m : le nombre trouvé à la question 1 est le numérateur.
:::

::: etape Le jus
$$
\begin{aligned}
1\,250 \text{ mL} &= \frac{1\,250}{1\,000} \text{ L}\\
&= 1 \text{ L} + \frac{250}{1\,000} \text{ L}\\
&= 1{,}25 \text{ L}
\end{aligned}
$$
($1{,}250$ L $= 1{,}25$ L : le zéro final est inutile.)
:::

::: etape La farine
$$
\begin{aligned}
2\,075 \text{ g} &= \frac{2\,075}{1\,000} \text{ kg}\\
&= 2 \text{ kg} + \frac{75}{1\,000} \text{ kg}\\
&= 2{,}075 \text{ kg}
\end{aligned}
$$
:::

::: etape Le ruban
$$
\begin{aligned}
308 \text{ cm} &= \frac{308}{100} \text{ m}\\
&= 3 \text{ m} + \frac{8}{100} \text{ m}\\
&= 3{,}08 \text{ m}
\end{aligned}
$$
:::

::: resultat
Jus : $\frac{1\,250}{1\,000} = 1 + \frac{250}{1\,000} = 1{,}25$ L ; farine : $\frac{2\,075}{1\,000} = 2 + \frac{75}{1\,000} = 2{,}075$ kg ; ruban : $\frac{308}{100} = 3 + \frac{8}{100} = 3{,}08$ m.
:::

## Question 3 : L'erreur d'Hugo

::: methode
Lire le rang de chaque chiffre après la virgule : dans des kilogrammes, le rang des millièmes correspond aux grammes.
:::

::: etape Ce que valent les $75$ g
$75$ g $= \frac{75}{1\,000}$ kg $= 0{,}075$ kg : le $7$ est au rang des centièmes et le $5$ au rang des millièmes. Il faut un $0$ au rang des dixièmes : $2{,}075$ kg.
:::

::: etape Ce que vaut $2{,}75$ kg
$2{,}75$ kg $= 2 + \frac{75}{100}$ kg $= 2 + \frac{750}{1\,000}$ kg, soit $2$ kg $750$ g.
:::

::: resultat
Hugo a oublié le zéro des dixièmes : $2$ kg $75$ g $= 2{,}075$ kg. L'écriture $2{,}75$ kg désigne $2$ kg $750$ g.
:::

## Question 4 : La canette et le sucre

::: methode
Écrire le nombre en millièmes, car $1$ mL et $1$ g sont des millièmes de litre et de kilogramme.
:::

::: etape La canette
$0{,}33$ L $= \frac{33}{100}$ L $= \frac{330}{1\,000}$ L, soit $330$ mL.
:::

::: etape Le sucre
$0{,}8$ kg $= \frac{8}{10}$ kg $= \frac{800}{1\,000}$ kg, soit $800$ g.
:::

::: resultat
$0{,}33$ L $= 330$ mL ; $0{,}8$ kg $= 800$ g.
:::

## Question 5 : Le jus qui manque

::: methode
Calculer dans la petite unité, puis revenir en litres.
:::

::: etape Calculer en millilitres
$2$ L $= 2\,000$ mL et $2\,000 - 1\,250 = 750$ mL.
:::

::: etape Revenir en litres
$750$ mL $= \frac{750}{1\,000}$ L $= \frac{75}{100}$ L $= 0{,}75$ L.
:::

::: resultat
Il manque $750$ mL, c'est-à-dire $0{,}75$ L.
:::

::: attention Erreur fréquente
Écrire « $2$ kg $75$ g » sous la forme $2{,}75$ kg : les grammes sont des **millièmes** de kilogramme, ils doivent occuper trois chiffres après la virgule. $75$ g $= 0{,}075$ kg.
:::

Solution:
<!-- optitab:1 -->
1. $1\,250$ mL ; $2\,075$ g ; $308$ cm.
2. $\frac{1\,250}{1\,000} = 1 + \frac{250}{1\,000} = 1{,}25$ L ; $\frac{2\,075}{1\,000} = 2 + \frac{75}{1\,000} = 2{,}075$ kg ; $\frac{308}{100} = 3 + \frac{8}{100} = 3{,}08$ m.
3. $2$ kg $75$ g $= 2{,}075$ kg ; $2{,}75$ kg $= 2$ kg $750$ g.
4. $330$ mL ; $800$ g.
5. $750$ mL, soit $0{,}75$ L.

=== Problème - Des grands nombres pour décrire le monde
Id: 3174
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. La distance moyenne entre la Terre et le Soleil est d'environ cent-cinquante millions de kilomètres. Celle entre Neptune et le Soleil est d'environ $4{,}5$ milliards de kilomètres.
   - a) Écrire ces deux distances en chiffres.
   - b) Combien de millions de kilomètres la distance entre Neptune et le Soleil représente-t-elle ?
   - c) Écrire $4{,}5$ milliards en lettres, sans virgule.
2. Selon l'ONU, la population mondiale a atteint huit milliards d'habitants en novembre $2022$ ; elle était de quatre milliards en $1974$.
   - a) Écrire ces deux nombres en chiffres.
   - b) De combien de millions d'habitants la population a-t-elle augmenté entre $1974$ et $2022$ ?
3. Au $1^{\text{er}}$ janvier $2025$, la France comptait environ $68{,}6$ millions d'habitants. Écrire ce nombre en chiffres, puis donner son nombre de milliers.
4. Une usine fabrique $2\,450\,000\,000$ vis par an. Elle les range dans des boîtes de $1\,000$ vis, puis place les boîtes dans des cartons de $1\,000$ boîtes. Combien de boîtes remplit-elle ? Combien de cartons ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les distances dans le système solaire

::: methode
Un million s'écrit $1\,000\,000$ et un milliard $1\,000\,000\,000$, c'est-à-dire mille millions. Un dixième de milliard vaut donc cent millions.
:::

::: etape a) Écrire en chiffres
- Cent-cinquante millions : classe des millions $150$, puis deux classes vides : $150\,000\,000$ km.
- $4{,}5$ milliards $= 4$ milliards $+ 5$ dixièmes de milliard. Un dixième de milliard, c'est $1\,000\,000\,000 \div 10 = 100\,000\,000$ ; donc $5$ dixièmes de milliard valent $500$ millions. On obtient $4\,500\,000\,000$ km.
:::

::: etape b) En millions
$4$ milliards $= 4\,000$ millions ; avec les $500$ millions : $4\,500$ millions. On le lit aussi dans $4\,500\,000\,000$ en gardant les chiffres jusqu'au rang des millions.
:::

::: etape c) En lettres
$4 \mid 500 \mid 000 \mid 000$ : « quatre milliards cinq-cents millions ».
:::

::: resultat
a) $150\,000\,000$ km et $4\,500\,000\,000$ km. b) $4\,500$ millions de km. c) Quatre milliards cinq-cents millions.
:::

## Question 2 : La population mondiale

::: methode
Écrire chaque nombre en chiffres, puis compter les millions de chacun.
:::

::: etape a) Écrire en chiffres
Huit milliards : $8\,000\,000\,000$ ; quatre milliards : $4\,000\,000\,000$.
:::

::: etape b) L'augmentation
$8$ milliards $= 8\,000$ millions et $4$ milliards $= 4\,000$ millions ; $8\,000 - 4\,000 = 4\,000$.
:::

::: resultat
a) $8\,000\,000\,000$ et $4\,000\,000\,000$. b) La population a augmenté de $4\,000$ millions d'habitants (quatre milliards).
:::

## Question 3 : La population de la France

::: methode
$68{,}6$ millions, c'est $68$ millions et $6$ dixièmes de million ; un dixième de million vaut $100\,000$.
:::

::: etape Écrire en chiffres
- $6$ dixièmes de million : $6 \times 100\,000 = 600\,000$ ;
- $68{,}6$ millions : $68\,000\,000 + 600\,000 = 68\,600\,000$.
:::

::: etape Le nombre de milliers
On garde les chiffres jusqu'au rang des mille : $68\,600$.
:::

::: resultat
$68\,600\,000$ habitants, soit $68\,600$ milliers.
:::

## Question 4 : Les vis de l'usine

::: methode
Remplir des boîtes de $1\,000$ vis revient à compter les milliers ; remplir des cartons de $1\,000$ boîtes revient à compter les milliers de milliers, c'est-à-dire les millions.
:::

::: etape Les boîtes
Nombre de milliers de $2\,450\,000\,000$ : $2\,450\,000$. L'usine remplit $2\,450\,000$ boîtes.
:::

::: etape Les cartons
$1$ carton $= 1\,000$ boîtes $= 1\,000 \times 1\,000 = 1\,000\,000$ vis. Le nombre de millions de $2\,450\,000\,000$ est $2\,450$ : il faut $2\,450$ cartons.
:::

::: resultat
$2\,450\,000$ boîtes et $2\,450$ cartons.
:::

::: attention Erreur fréquente
Écrire $4{,}5$ milliards sous la forme $4\,000\,000\,005$ ou $4\,005\,000\,000$ : le $5$ est au rang des **dixièmes de milliard**, c'est-à-dire des centaines de millions. $4{,}5$ milliards $= 4\,500\,000\,000$.
:::

Solution:
<!-- optitab:1 -->
1. a) $150\,000\,000$ km ; $4\,500\,000\,000$ km. b) $4\,500$ millions de km. c) Quatre milliards cinq-cents millions.
2. a) $8\,000\,000\,000$ ; $4\,000\,000\,000$. b) $4\,000$ millions d'habitants.
3. $68\,600\,000$ ; $68\,600$ milliers.
4. $2\,450\,000$ boîtes ; $2\,450$ cartons.

=== Synthèse - Enquête sur deux nombres mystères
Id: 3181
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
**Partie A : un grand nombre**

« Je suis un nombre entier. J'ai $2$ milliards, $9$ millions et $40$ milliers ; ma classe des unités ne contient que des zéros. »

1. Placer ce nombre dans un tableau de numération et l'écrire en chiffres.
2. L'écrire en lettres.
3. Donner son nombre de millions et son chiffre des dizaines de mille.

**Partie B : un nombre décimal**

« J'ai $3$ unités et aucun centième. Mon chiffre des dixièmes est $4$ ; mon chiffre des millièmes est le double de mon chiffre des dixièmes. Je n'ai aucun autre chiffre différent de zéro. »

4. Placer ce nombre dans un tableau de numération et l'écrire avec une virgule.
5. Donner sa partie entière et sa partie décimale.
6. L'écrire sous la forme d'une fraction décimale, d'un nombre mixte, puis d'une décomposition $\ldots + \frac{\ldots}{10} + \frac{\ldots}{100} + \frac{\ldots}{1\,000}$.
7. Quel est son nombre de centièmes ?
8. Sami propose $3{,}48$. Expliquer pourquoi ce n'est pas le nombre mystère.

Étapes:
<!-- optitab:1 -->
## Partie A : Un grand nombre

## Question 1 : Écrire le nombre en chiffres

::: methode
Remplir le tableau classe par classe, avec trois chiffres par classe (sauf la première) ; une classe sans indication est remplie de zéros.
:::

::: etape Classe par classe
Milliards : $2$ ; millions : $009$ ; mille : $040$ ; unités : $000$.
:::

[IMAGE_1]

::: resultat
Le nombre est $2\,009\,040\,000$.
:::

## Question 2 : Écrire en lettres

::: methode
Lire chaque classe suivie de son nom.
:::

::: etape Lire les classes
« deux milliards » ; « neuf millions » ; « quarante-mille » ; la classe des unités, $000$, ne se lit pas.
:::

::: resultat
Deux milliards neuf millions quarante-mille.
:::

## Question 3 : Nombre de millions, chiffre des dizaines de mille

::: methode
Le nombre de millions se lit avec tous les chiffres jusqu'au rang des millions ; le chiffre des dizaines de mille est le chiffre du milieu de la classe des mille.
:::

::: etape Lire
- $2\,009 \mid 040\,000$ : nombre de millions $2\,009$.
- Classe des mille : $040$ ; son chiffre du milieu est $4$.
:::

::: resultat
Nombre de millions : $2\,009$ ; chiffre des dizaines de mille : $4$.
:::

## Partie B : Un nombre décimal

## Question 4 : Écrire le nombre avec une virgule

::: methode
Traduire chaque indice en un chiffre placé à son rang, puis compléter les rangs vides par des zéros.
:::

::: etape Les indices un par un
- $3$ unités : chiffre des unités $3$ ;
- chiffre des dixièmes : $4$ ;
- aucun centième : chiffre des centièmes $0$ ;
- chiffre des millièmes : le double de $4$, soit $2 \times 4 = 8$.
:::

[IMAGE_2]

::: resultat
Le nombre mystère est $3{,}408$.
:::

## Question 5 : Partie entière et partie décimale

::: methode
Séparer ce qui est à gauche de la virgule et ce qui reste.
:::

::: etape Séparer
$$3{,}408 = 3 + 0{,}408$$
:::

::: resultat
Partie entière : $3$ ; partie décimale : $0{,}408$.
:::

## Question 6 : Trois autres écritures

::: methode
Le dernier chiffre est aux millièmes : la fraction décimale a pour dénominateur $1\,000$.
:::

::: etape Fraction décimale et nombre mixte
$$
\begin{aligned}
3{,}408 &= \frac{3\,408}{1\,000} = \frac{3\,000}{1\,000} + \frac{408}{1\,000}\\
&= 3 + \frac{408}{1\,000}
\end{aligned}
$$
:::

::: etape Décomposition
$$3{,}408 = 3 + \frac{4}{10} + \frac{0}{100} + \frac{8}{1\,000}$$
:::

::: resultat
$\frac{3\,408}{1\,000}$ ; $3 + \frac{408}{1\,000}$ ; $3 + \frac{4}{10} + \frac{0}{100} + \frac{8}{1\,000}$.
:::

## Question 7 : Le nombre de centièmes

::: methode
Garder tous les chiffres jusqu'au rang des centièmes, sans la virgule.
:::

::: etape Compter
$3$ unités $= 300$ centièmes ; $4$ dixièmes $= 40$ centièmes ; $0$ centième. En tout : $300 + 40 + 0 = 340$ centièmes (il reste $8$ millièmes).
:::

::: resultat
Le nombre de centièmes est $340$.
:::

## Question 8 : La proposition de Sami

::: methode
Vérifier chaque indice sur le nombre proposé.
:::

::: etape Tester $3{,}48$
Dans $3{,}48$, le chiffre des centièmes est $8$ : cela contredit « aucun centième ». De plus, $3{,}48$ n'a pas de chiffre des millièmes : $3{,}48 = 3{,}480$.
:::

::: resultat
$3{,}48$ a $8$ centièmes et $0$ millième, alors que le nombre mystère n'a aucun centième et $8$ millièmes : Sami a oublié le zéro des centièmes.
:::

::: retenir
Un zéro intérieur « réserve » un rang : sans lui, les chiffres suivants changent de rang et de valeur. $3{,}408 \neq 3{,}48$.
:::

Solution:
<!-- optitab:1 -->
1. $2\,009\,040\,000$.
2. Deux milliards neuf millions quarante-mille.
3. Nombre de millions : $2\,009$ ; chiffre des dizaines de mille : $4$.
4. $3{,}408$.
5. Partie entière $3$ ; partie décimale $0{,}408$.
6. $\frac{3\,408}{1\,000}$ ; $3 + \frac{408}{1\,000}$ ; $3 + \frac{4}{10} + \frac{0}{100} + \frac{8}{1\,000}$.
7. $340$ centièmes.
8. $3{,}48$ a $8$ centièmes ; le nombre mystère n'en a aucun : c'est $3{,}408$.
