Titre: Résumé : Équations du Premier Degré — Résolution et Applications

<!-- optitab:1 -->
## I. Équations simples

| Principe | Formule |
|---|---|
| **Forme générale** | $\displaystyle ax + b = 0$ (avec $\displaystyle a \neq 0$) → $\displaystyle x = -\dfrac{b}{a}$ |
| **Cas général** | $\displaystyle ax + b = cx + d$ → $\displaystyle (a-c)x = d-b$ → $\displaystyle x = \dfrac{d-b}{a-c}$ (si $\displaystyle a \neq c$) |

| Étape | Méthode de résolution |
|---|---|
| **1** | **Isoler** les termes en $\displaystyle x$ d'un côté et les constantes de l'autre |
| **2** | **Réduire** les termes semblables |
| **3** | **Diviser** par le coefficient de $\displaystyle x$ |
| **4** | **Vérifier** la solution dans l'équation initiale |

| Exemples |
|---|
| $\displaystyle 3x + 5 = 0 \Rightarrow x = -\dfrac{5}{3}$ <br> $\displaystyle 2x - 7 = 3x + 1 \Rightarrow -x = 8 \Rightarrow x = -8$ |

## II. Équations avec développements

| Principe | Méthode |
|---|---|
| **Développer d'abord** | Supprimer les parenthèses, puis réduire et résoudre comme au I |

| Exemple |
|---|
| $\displaystyle 2(x+3) = 4x - 1 \Rightarrow 2x+6 = 4x-1 \Rightarrow -2x = -7 \Rightarrow x = \dfrac{7}{2}$ |

## III. Équations avec fractions

| Méthode | Description |
|---|---|
| **Dénominateur commun** | Mettre au même dénominateur et réduire, puis résoudre |
| **Produit en croix** | Pour $\displaystyle \dfrac{A}{B} = \dfrac{C}{D}$ : $\displaystyle AD = BC$ (avec $\displaystyle B,D \neq 0$) |

| Exemples |
|---|
| $\displaystyle \dfrac{x}{2} + 3 = 5 \Rightarrow \dfrac{x}{2} = 2 \Rightarrow x = 4$ <br> $\displaystyle \dfrac{x+1}{3} = \dfrac{x-2}{2} \Rightarrow 2(x+1) = 3(x-2) \Rightarrow x = 8$ |

::: attention Important
La solution ne doit annuler **aucun dénominateur** de l'équation initiale.
:::

## IV. Cas particuliers

| Situation | Conclusion |
|---|---|
| **Équation normale** : $\displaystyle ax = b$ ($\displaystyle a \neq 0$) | Solution unique : $\displaystyle x = \dfrac{b}{a}$ |
| **Impossible** : $\displaystyle 0 = b$ ($\displaystyle b \neq 0$) | Aucune solution |
| **Indéterminée** : $\displaystyle 0 = 0$ | Infinité de solutions (tout réel convient) |

## V. Méthode générale et stratégie

| Étape | Ordre de travail |
|---|---|
| **1** | **Développer** si nécessaire (supprimer les parenthèses) |
| **2** | **Réduire** les deux membres |
| **3** | **Transposer** : regrouper les $\displaystyle x$ d'un côté, constantes de l'autre |
| **4** | **Diviser** par le coefficient de $\displaystyle x$ |
| **5** | **Vérifier** dans l'équation de départ |

## VI. Problèmes et applications

| Méthode |
|---|
| Lire → Traduire en équation → Résoudre → Vérifier → Conclure (phrase réponse) |

| Exemple | Résultat |
|---|---|
| Un nombre augmenté de 7 vaut le triple du même nombre diminué de 5 | $\displaystyle x+7 = 3x-5 \Rightarrow x = 6$ |

## VII. Erreurs fréquentes et conseils

| ERREURS À ÉVITER |
|---|
| Oublier de changer le signe en transposant Oublier de développer les parenthèses Diviser seulement un côté Oublier les valeurs interdites (dénominateurs) Confondre « aucune solution » et « infinité de solutions » |

| CONSEILS |
|---|
| Toujours développer puis réduire Utiliser le produit en croix ou le dénominateur commun Vérifier systématiquement la solution dans l'équation initiale |

## VIII. Formules rapides — mémo

| Notion | Formule |
|---|---|
| **Équation simple** | $\displaystyle ax + b = 0 \Rightarrow x = -\dfrac{b}{a}$ |
| **Forme générale** | $\displaystyle ax + b = cx + d \Rightarrow x = \dfrac{d-b}{a-c}$ (si $\displaystyle a\neq c$) |
| **Produit en croix** | $\displaystyle \dfrac{A}{B} = \dfrac{C}{D} \Rightarrow AD = BC$ |
| **Vérification** | Remplacer $\displaystyle x$ trouvé dans l'équation de départ |

## IX. Points clés à retenir

| Notion | À retenir |
|---|---|
| **Méthode** | Développer → Réduire → Transposer → Diviser → Vérifier |
| **Fractions** | Produit en croix / Dénominateur commun, puis vérifier les valeurs interdites |
| **Cas particuliers** | Unique solution, aucune solution, ou infinité de solutions selon la forme obtenue |
| **Problèmes** | Lire → Traduire → Résoudre → Vérifier → Conclure |
