=== Développements - Attention aux Signes
Id: 1432
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes en faisant très attention aux signes.

1. Développer $\displaystyle -(x - 3)$
2. Développer $\displaystyle -2(x + 4)$
3. Développer $\displaystyle -(2x - 5)$
4. Développer $\displaystyle 3 - 2(x - 1)$
5. Développer $\displaystyle x - (2x - 3)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle -(x - 3)$

::: methode
Distributivité avec facteur $-1$
:::

::: etape Interpréter $-(x - 3)$ comme $-1(x - 3)$
- $\displaystyle -(x - 3) = -1(x - 3)$
:::

::: etape Appliquer la distributivité
- $\displaystyle -1(x - 3) = -1 \times x + (-1) \times (-3)$
:::

::: etape Calculer en faisant attention aux signes
- $\displaystyle = -x + 3$
:::

::: resultat
$$-(x - 3) = -x + 3$$
:::

## Question 2 : Développer $\displaystyle -2(x + 4)$

::: methode
Distributivité avec facteur négatif
:::

::: etape Appliquer la distributivité
- $\displaystyle -2(x + 4) = (-2) \times x + (-2) \times 4$
:::

::: etape Calculer
- $\displaystyle = -2x - 8$
:::

::: resultat
$$-2(x + 4) = -2x - 8$$
:::

## Question 3 : Développer $\displaystyle -(2x - 5)$

::: methode
Distributivité avec facteur $-1$
:::

::: etape Appliquer la distributivité
$$
\begin{aligned}
-(2x - 5) &= -1(2x - 5) \\
&= -1 \times 2x + (-1) \times (-5)
\end{aligned}
$$
:::

::: etape Calculer
- $\displaystyle = -2x + 5$
:::

::: resultat
$$-(2x - 5) = -2x + 5$$
:::

## Question 4 : Développer $\displaystyle 3 - 2(x - 1)$

::: methode
Distributivité puis soustraction
:::

::: etape Développer $\displaystyle -2(x - 1)$
- $\displaystyle -2(x - 1) = -2x + 2$
:::

::: etape Soustraire de $\displaystyle 3$
- $\displaystyle 3 - 2(x - 1) = 3 - (2x - 2) = 3 - 2x + 2$
:::

::: etape Réduire
- $\displaystyle = -2x + 5$
:::

::: resultat
$$3 - 2(x - 1) = -2x + 5$$
:::

## Question 5 : Développer $\displaystyle x - (2x - 3)$

::: methode
Soustraction d'une expression entre parenthèses
:::

::: etape Attention
soustraire revient à changer tous les signes

- $\displaystyle x - (2x - 3) = x - 2x + 3$
:::

::: etape Réduire
- $\displaystyle = -x + 3$
:::

::: resultat
$$x - (2x - 3) = -x + 3$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle -(x - 3) = -x + 3$
2. $\displaystyle -2(x + 4) = -2x - 8$
3. $\displaystyle -(2x - 5) = -2x + 5$
4. $\displaystyle 3 - 2(x - 1) = -2x + 5$
5. $\displaystyle x - (2x - 3) = -x + 3$

=== Développements - Développer puis Réduire
Id: 1430
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer et réduire les expressions suivantes.

1. Développer et réduire $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5)$
2. Développer et réduire $\displaystyle (x + 1)^2 - (x - 2)^2$
3. Développer et réduire $\displaystyle 3(x + 2) - 2(x - 1) + x$
4. Développer et réduire $\displaystyle (x + 3)^2 - (x - 1)(x + 1)$
5. Développer et réduire $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer et réduire $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5)$

::: methode
Développer chaque produit puis réduire
:::

::: etape Développer le premier produit
- $\displaystyle (x + 2)(x + 3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$
:::

::: etape Développer le deuxième produit
- $\displaystyle (x - 1)(x + 5) = x^2 + 5x - x - 5 = x^2 + 4x - 5$
:::

::: etape Additionner les deux résultats
- $\displaystyle (x^2 + 5x + 6) + (x^2 + 4x - 5) = x^2 + x^2 + 5x + 4x + 6 - 5$
:::

::: etape Réduire les termes semblables
- $\displaystyle = 2x^2 + 9x + 1$
:::

::: resultat
$$(x + 2)(x + 3) + (x - 1)(x + 5) = 2x^2 + 9x + 1$$
:::

## Question 2 : Développer et réduire $\displaystyle (x + 1)^2 - (x - 2)^2$

::: methode
Utiliser les identités remarquables puis soustraire
:::

::: etape Développer chaque carré
- $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
- $\displaystyle (x - 2)^2 = x^2 - 4x + 4$
:::

::: etape Soustraire (attention aux signes !)
- $\displaystyle (x^2 + 2x + 1) - (x^2 - 4x + 4) = x^2 + 2x + 1 - x^2 + 4x - 4$
:::

::: etape Réduire les termes semblables
- $\displaystyle = 6x - 3$
:::

::: resultat
$$(x + 1)^2 - (x - 2)^2 = 6x - 3$$
:::

## Question 3 : Développer et réduire $\displaystyle 3(x + 2) - 2(x - 1) + x$

::: methode
Distributivité puis réduction
:::

::: etape Développer chaque terme
- $\displaystyle 3(x + 2) = 3x + 6$
- $\displaystyle -2(x - 1) = -2x + 2$
:::

::: etape Regrouper tous les termes
- $\displaystyle 3x + 6 - 2x + 2 + x = (3x - 2x + x) + (6 + 2)$
:::

::: etape Réduire
- $\displaystyle = 2x + 8$
:::

::: resultat
$$3(x + 2) - 2(x - 1) + x = 2x + 8$$
:::

## Question 4 : Développer et réduire $\displaystyle (x + 3)^2 - (x - 1)(x + 1)$

::: methode
Identités remarquables puis réduction
:::

::: etape Développer le carré
- $\displaystyle (x + 3)^2 = x^2 + 6x + 9$
:::

::: etape Utiliser l'identité remarquable pour le produit
- $\displaystyle (x - 1)(x + 1) = x^2 - 1$
:::

::: etape Soustraire
- $\displaystyle (x^2 + 6x + 9) - (x^2 - 1) = x^2 + 6x + 9 - x^2 + 1$
:::

::: etape Réduire
- $\displaystyle = 6x + 10$
:::

::: resultat
$$(x + 3)^2 - (x - 1)(x + 1) = 6x + 10$$
:::

## Question 5 : Développer et réduire $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4)$

::: methode
Développer puis réduire
:::

::: etape Développer le carré
- $\displaystyle (x - 3)^2 = x^2 - 6x + 9$
- $\displaystyle 2(x - 3)^2 = 2(x^2 - 6x + 9) = 2x^2 - 12x + 18$
:::

::: etape Développer le produit
- $\displaystyle (x + 1)(x - 4) = x^2 - 4x + x - 4 = x^2 - 3x - 4$
:::

::: etape Soustraire
- $\displaystyle (2x^2 - 12x + 18) - (x^2 - 3x - 4) = 2x^2 - 12x + 18 - x^2 + 3x + 4$
:::

::: etape Réduire
- $\displaystyle = x^2 - 9x + 22$
:::

::: resultat
$$2(x - 3)^2 - (x + 1)(x - 4) = x^2 - 9x + 22$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5) = 2x^2 + 9x + 1$
2. $\displaystyle (x + 1)^2 - (x - 2)^2 = 6x - 3$
3. $\displaystyle 3(x + 2) - 2(x - 1) + x = 2x + 8$
4. $\displaystyle (x + 3)^2 - (x - 1)(x + 1) = 6x + 10$
5. $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4) = x^2 - 9x + 22$

=== Développements - Distributivité Simple
Id: 1427
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes en utilisant la distributivité simple.

1. Développer $\displaystyle 3(x + 4)$
2. Développer $\displaystyle -2(3x - 5)$
3. Développer $\displaystyle 5(2x + 1)$
4. Développer $\displaystyle 4(x^2 - 2x + 3)$
5. Développer $\displaystyle -3(4x - 7)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle 3(x + 4)$

::: methode
Distributivité simple $\displaystyle k(a + b) = ka + kb$
:::

::: etape Identifier les éléments
- Facteur extérieur : $\displaystyle k = 3$
- Termes dans la parenthèse : $a = x$ et $b = 4$
:::

::: etape Appliquer la distributivité
- $\displaystyle 3(x + 4) = 3 \times x + 3 \times 4$
:::

::: etape Calculer
- $\displaystyle = 3x + 12$
:::

::: resultat
$$3(x + 4) = 3x + 12$$
:::

## Question 2 : Développer $\displaystyle -2(3x - 5)$

::: methode
Distributivité simple avec attention aux signes
:::

::: etape Identifier les éléments
- Facteur extérieur : $\displaystyle k = -2$
- Termes dans la parenthèse : $a = 3x$ et $b = -5$
:::

::: etape Appliquer la distributivité
- $\displaystyle -2(3x - 5) = (-2) \times 3x + (-2) \times (-5)$
:::

::: etape Calculer en faisant attention aux signes
- $\displaystyle = -6x + 10$
- Attention : $(-2) \times (-5) = +10$ (moins par moins = plus)
:::

::: resultat
$$-2(3x - 5) = -6x + 10$$
:::

## Question 3 : Développer $\displaystyle 5(2x + 1)$

::: methode
Distributivité simple
:::

::: etape Appliquer la distributivité
- $\displaystyle 5(2x + 1) = 5 \times 2x + 5 \times 1$
:::

::: etape Calculer
- $\displaystyle = 10x + 5$
:::

::: resultat
$$5(2x + 1) = 10x + 5$$
:::

## Question 4 : Développer $\displaystyle 4(x^2 - 2x + 3)$

::: methode
Distributivité simple avec plusieurs termes
:::

::: etape Appliquer la distributivité
- $\displaystyle 4(x^2 - 2x + 3) = 4 \times x^2 + 4 \times (-2x) + 4 \times 3$
:::

::: etape Calculer
- $\displaystyle = 4x^2 - 8x + 12$
:::

::: resultat
$$4(x^2 - 2x + 3) = 4x^2 - 8x + 12$$
:::

## Question 5 : Développer $\displaystyle -3(4x - 7)$

::: methode
Distributivité simple avec facteur négatif
:::

::: etape Appliquer la distributivité
- $\displaystyle -3(4x - 7) = (-3) \times 4x + (-3) \times (-7)$
:::

::: etape Calculer en faisant attention aux signes
- $\displaystyle = -12x + 21$
- Attention : $\displaystyle (-3) \times (-7) = +21$
:::

::: resultat
$$-3(4x - 7) = -12x + 21$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3(x + 4) = 3x + 12$
2. $\displaystyle -2(3x - 5) = -6x + 10$
3. $\displaystyle 5(2x + 1) = 10x + 5$
4. $\displaystyle 4(x^2 - 2x + 3) = 4x^2 - 8x + 12$
5. $\displaystyle -3(4x - 7) = -12x + 21$

=== Développements - Double Distributivité
Id: 1428
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes en utilisant la double distributivité.

1. Développer $\displaystyle (x + 3)(x + 5)$
2. Développer $\displaystyle (2x - 1)(x + 4)$
3. Développer $\displaystyle (3x + 2)(2x - 5)$
4. Développer $\displaystyle (x - 2)(x - 3)$
5. Développer $\displaystyle (4x + 1)(3x - 2)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle (x + 3)(x + 5)$

::: methode
Double distributivité $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$
:::

::: etape Identifier les éléments
- Première parenthèse : $a = x$, $b = 3$
- Deuxième parenthèse : $c = x$, $d = 5$
:::

::: etape Appliquer la double distributivité
- $\displaystyle (x + 3)(x + 5) = x \times x + x \times 5 + 3 \times x + 3 \times 5$
:::

::: etape Calculer chaque produit
- $\displaystyle = x^2 + 5x + 3x + 15$
:::

::: etape Réduire les termes semblables
- $\displaystyle = x^2 + 8x + 15$
:::

::: resultat
$$(x + 3)(x + 5) = x^2 + 8x + 15$$
:::

## Question 2 : Développer $\displaystyle (2x - 1)(x + 4)$

::: methode
Double distributivité avec attention aux signes
:::

::: etape Appliquer la double distributivité
- $\displaystyle (2x - 1)(x + 4) = 2x \times x + 2x \times 4 + (-1) \times x + (-1) \times 4$
:::

::: etape Calculer chaque produit
- $\displaystyle = 2x^2 + 8x - x - 4$
:::

::: etape Réduire les termes semblables
- $\displaystyle = 2x^2 + 7x - 4$
:::

::: resultat
$$(2x - 1)(x + 4) = 2x^2 + 7x - 4$$
:::

## Question 3 : Développer $\displaystyle (3x + 2)(2x - 5)$

::: methode
Double distributivité
:::

::: etape Appliquer la double distributivité
- $\displaystyle (3x + 2)(2x - 5) = 3x \times 2x + 3x \times (-5) + 2 \times 2x + 2 \times (-5)$
:::

::: etape Calculer chaque produit
- $\displaystyle = 6x^2 - 15x + 4x - 10$
:::

::: etape Réduire les termes semblables
- $\displaystyle = 6x^2 - 11x - 10$
:::

::: resultat
$$(3x + 2)(2x - 5) = 6x^2 - 11x - 10$$
:::

## Question 4 : Développer $\displaystyle (x - 2)(x - 3)$

::: methode
Double distributivité
:::

::: etape Appliquer la double distributivité
- $\displaystyle (x - 2)(x - 3) = x \times x + x \times (-3) + (-2) \times x + (-2) \times (-3)$
:::

::: etape Calculer chaque produit
- $\displaystyle = x^2 - 3x - 2x + 6$
:::

::: etape Réduire les termes semblables
- $\displaystyle = x^2 - 5x + 6$
:::

::: resultat
$$(x - 2)(x - 3) = x^2 - 5x + 6$$

## Question 5 : Développer $\displaystyle (4x + 1)(3x - 2)$

::: methode
Double distributivité
:::

::: etape Appliquer la double distributivité
- $\displaystyle (4x + 1)(3x - 2) = 4x \times 3x + 4x \times (-2) + 1 \times 3x + 1 \times (-2)$
:::

::: etape Calculer chaque produit
- $\displaystyle = 12x^2 - 8x + 3x - 2$
:::

::: etape Réduire les termes semblables
- $\displaystyle = 12x^2 - 5x - 2$
:::

::: resultat
$$(4x + 1)(3x - 2) = 12x^2 - 5x - 2$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 3)(x + 5) = x^2 + 8x + 15$
2. $\displaystyle (2x - 1)(x + 4) = 2x^2 + 7x - 4$
3. $\displaystyle (3x + 2)(2x - 5) = 6x^2 - 11x - 10$
4. $\displaystyle (x - 2)(x - 3) = x^2 - 5x + 6$
5. $\displaystyle (4x + 1)(3x - 2) = 12x^2 - 5x - 2$

=== Développements - Double Distributivité Avancée
Id: 1434
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes en utilisant la double distributivité avec des expressions plus complexes.

1. Développer $\displaystyle (x + 2)(x^2 - 3x + 1)$
2. Développer $\displaystyle (2x - 1)(x^2 + x - 2)$
3. Développer $\displaystyle (x^2 + 1)(x - 3)$
4. Développer $\displaystyle (3x - 2)(2x^2 - x + 5)$
5. Développer $\displaystyle (x^2 - 2x + 1)(x + 1)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle (x + 2)(x^2 - 3x + 1)$

::: methode
Double distributivité étendue
:::

::: etape
Multiplier chaque terme de la première parenthèse par chaque terme de la deuxième

- $\displaystyle x \times x^2 = x^3$
- $\displaystyle x \times (-3x) = -3x^2$
- $\displaystyle x \times 1 = x$
- $\displaystyle 2 \times x^2 = 2x^2$
- $\displaystyle 2 \times (-3x) = -6x$
- $\displaystyle 2 \times 1 = 2$
:::

::: etape Additionner tous les produits
- $\displaystyle (x + 2)(x^2 - 3x + 1) = x^3 - 3x^2 + x + 2x^2 - 6x + 2$
:::

::: etape Réduire les termes semblables
- $\displaystyle = x^3 + (-3x^2 + 2x^2) + (x - 6x) + 2 = x^3 - x^2 - 5x + 2$
:::

::: resultat
$$(x + 2)(x^2 - 3x + 1) = x^3 - x^2 - 5x + 2$$
:::

## Question 2 : Développer $\displaystyle (2x - 1)(x^2 + x - 2)$

::: methode
Double distributivité étendue
:::

::: etape Multiplier chaque terme
- $\displaystyle 2x \times x^2 = 2x^3$
- $\displaystyle 2x \times x = 2x^2$
- $\displaystyle 2x \times (-2) = -4x$
- $\displaystyle (-1) \times x^2 = -x^2$
- $\displaystyle (-1) \times x = -x$
- $\displaystyle (-1) \times (-2) = 2$
:::

::: etape Additionner
- $\displaystyle (2x - 1)(x^2 + x - 2) = 2x^3 + 2x^2 - 4x - x^2 - x + 2$
:::

::: etape Réduire
- $\displaystyle = 2x^3 + (2x^2 - x^2) + (-4x - x) + 2 = 2x^3 + x^2 - 5x + 2$
:::

::: resultat
$$(2x - 1)(x^2 + x - 2) = 2x^3 + x^2 - 5x + 2$$
:::

## Question 3 : Développer $\displaystyle (x^2 + 1)(x - 3)$

::: methode
Double distributivité
:::

::: etape Multiplier chaque terme
- $\displaystyle x^2 \times x = x^3$
- $\displaystyle x^2 \times (-3) = -3x^2$
- $\displaystyle 1 \times x = x$
- $\displaystyle 1 \times (-3) = -3$
:::

::: etape Additionner
- $\displaystyle (x^2 + 1)(x - 3) = x^3 - 3x^2 + x - 3$
:::

::: resultat
$$(x^2 + 1)(x - 3) = x^3 - 3x^2 + x - 3$$
:::

## Question 4 : Développer $\displaystyle (3x - 2)(2x^2 - x + 5)$

::: methode
Double distributivité étendue
:::

::: etape Multiplier chaque terme
- $\displaystyle 3x \times 2x^2 = 6x^3$
- $\displaystyle 3x \times (-x) = -3x^2$
- $\displaystyle 3x \times 5 = 15x$
- $\displaystyle (-2) \times 2x^2 = -4x^2$
- $\displaystyle (-2) \times (-x) = 2x$
- $\displaystyle (-2) \times 5 = -10$
:::

::: etape Additionner
- $\displaystyle (3x - 2)(2x^2 - x + 5) = 6x^3 - 3x^2 + 15x - 4x^2 + 2x - 10$
:::

::: etape Réduire
- $\displaystyle = 6x^3 + (-3x^2 - 4x^2) + (15x + 2x) - 10 = 6x^3 - 7x^2 + 17x - 10$
:::

::: resultat
$$(3x - 2)(2x^2 - x + 5) = 6x^3 - 7x^2 + 17x - 10$$
:::

## Question 5 : Développer $\displaystyle (x^2 - 2x + 1)(x + 1)$

::: methode
Double distributivité étendue
:::

::: etape Multiplier chaque terme
- $\displaystyle x^2 \times x = x^3$
- $\displaystyle x^2 \times 1 = x^2$
- $\displaystyle (-2x) \times x = -2x^2$
- $\displaystyle (-2x) \times 1 = -2x$
- $\displaystyle 1 \times x = x$
- $\displaystyle 1 \times 1 = 1$
:::

::: etape Additionner
- $\displaystyle (x^2 - 2x + 1)(x + 1) = x^3 + x^2 - 2x^2 - 2x + x + 1$
:::

::: etape Réduire
- $\displaystyle = x^3 + (x^2 - 2x^2) + (-2x + x) + 1 = x^3 - x^2 - x + 1$
:::

::: resultat
$$(x^2 - 2x + 1)(x + 1) = x^3 - x^2 - x + 1$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 2)(x^2 - 3x + 1) = x^3 - x^2 - 5x + 2$
2. $\displaystyle (2x - 1)(x^2 + x - 2) = 2x^3 + x^2 - 5x + 2$
3. $\displaystyle (x^2 + 1)(x - 3) = x^3 - 3x^2 + x - 3$
4. $\displaystyle (3x - 2)(2x^2 - x + 5) = 6x^3 - 7x^2 + 17x - 10$
5. $\displaystyle (x^2 - 2x + 1)(x + 1) = x^3 - x^2 - x + 1$

=== Développements - Expressions avec Fractions
Id: 1433
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes contenant des fractions.

1. Développer $\displaystyle \dfrac{1}{2}(x + 4)$
2. Développer $\displaystyle \dfrac{2}{3}(3x - 6)$
3. Développer $\displaystyle \left(x + \dfrac{1}{2}\right)\left(x + \dfrac{1}{3}\right)$
4. Développer $\displaystyle \left(x - \dfrac{1}{4}\right)^2$
5. Développer $\displaystyle \dfrac{1}{3}(x + 6) - \dfrac{1}{2}(x - 4)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle \dfrac{1}{2}(x + 4)$

::: methode
Distributivité avec fraction
:::

::: etape Appliquer la distributivité
- $\displaystyle \dfrac{1}{2}(x + 4) = \dfrac{1}{2} \times x + \dfrac{1}{2} \times 4$
:::

::: etape Calculer
- $\displaystyle = \dfrac{x}{2} + \dfrac{4}{2} = \dfrac{x}{2} + 2$
:::

::: resultat
$$\dfrac{1}{2}(x + 4) = \dfrac{x}{2} + 2$$
:::

## Question 2 : Développer $\displaystyle \dfrac{2}{3}(3x - 6)$

::: methode
Distributivité avec fraction
:::

::: etape Appliquer la distributivité
- $\displaystyle \dfrac{2}{3}(3x - 6) = \dfrac{2}{3} \times 3x - \dfrac{2}{3} \times 6$
:::

::: etape Calculer et simplifier
- $\displaystyle = \dfrac{6x}{3} - \dfrac{12}{3} = 2x - 4$
:::

::: resultat
$$\dfrac{2}{3}(3x - 6) = 2x - 4$$
:::

## Question 3 : Développer $\displaystyle \left(x + \dfrac{1}{2}\right)\left(x + \dfrac{1}{3}\right)$

::: methode
Double distributivité avec fractions
:::

::: etape Appliquer la double distributivité
- $\displaystyle \left(x + \dfrac{1}{2}\right)\left(x + \dfrac{1}{3}\right) = x \times x + x \times \dfrac{1}{3} + \dfrac{1}{2} \times x + \dfrac{1}{2} \times \dfrac{1}{3}$
:::

::: etape Calculer
- $\displaystyle = x^2 + \dfrac{x}{3} + \dfrac{x}{2} + \dfrac{1}{6}$
:::

::: etape Réduire les termes en $\displaystyle x$
$$
\begin{aligned}
\dfrac{x}{3} + \dfrac{x}{2} &= \dfrac{2x}{6} + \dfrac{3x}{6} \\
&= \dfrac{5x}{6}
\end{aligned}
$$
:::
