Titre: Résumé : Utiliser le calcul littéral

::: objectifs
Retenir l’essentiel : puissances, racines carrées, fractions, identités remarquables, équations, inéquations, signe et comparaison. Programme de Seconde.
:::

## I. Les règles de calcul

::: formule
$(a + b)^2 = a^2 + 2ab + b^2$
:::

::: formule
$(a - b)^2 = a^2 - 2ab + b^2$
:::

::: formule
$(a + b)(a - b) = a^2 - b^2$
:::

[IMAGE_1]

- Puissances : $a^n a^m = a^{n+m}$ ; $\dfrac{a^n}{a^m} = a^{n-m}$ ; $(a^n)^m = a^{nm}$ ; $a^{-n} = \dfrac{1}{a^n}$.
- Racines ($a, b \ge 0$) : $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ; $\sqrt{50} = 5\sqrt{2}$ ; $\sqrt{a^2} = \lvert a \rvert$ pour tout réel $a$.
- Fractions : $\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{ad + bc}{bd}$ ; diviser par $\dfrac{c}{d}$, c’est multiplier par $\dfrac{d}{c}$.

## II. Équations, inéquations, signe

1. Produit nul : $A \times B = 0 \iff A = 0$ ou $B = 0$.
2. Quotient nul : $\dfrac{A}{B} = 0 \iff A = 0$ et $B \neq 0$.
3. $x^2 = a$ : $-\sqrt{a}$ et $\sqrt{a}$ si $a \gt 0$ ; $0$ si $a = 0$ ; aucune solution si $a \lt 0$.
4. Multiplier ou diviser par un négatif change le sens de l’inégalité.
5. Comparer : étudier le signe de $A - B$, ou comparer $\dfrac{A}{B}$ à $1$ si $A$ et $B$ sont positifs.
6. $ax + b$ a le signe de $a$ à droite de $-\dfrac{b}{a}$ ; un produit se traite par un tableau de signes, par exemple pour $(2x - 4)(-x + 3)$ :

::: tableau
x : -\infty, 2, 3, +\infty
2x-4 : , -, z, +, t, +,
-x+3 : , +, t, +, z, -,
Produit : , -, z, +, z, -,
:::

## III. Les pièges à éviter

::: attention Les 5 erreurs classiques
1. Écrire $(a + b)^2 = a^2 + b^2$ : il manque le double produit $2ab$.
2. Écrire $\sqrt{a + b} = \sqrt{a} + \sqrt{b}$ : faux ($\sqrt{25} \neq 3 + 4$).
3. Diviser par $x$ pour résoudre $x^2 = 5x$ : on perd la solution $0$ ; il faut factoriser.
4. Oublier de changer le sens en divisant par un négatif : $-2x \le -6 \iff x \ge 3$.
5. Garder comme solution une valeur interdite (qui annule un dénominateur).
:::

::: remarque Réflexe
Équation ou inéquation de degré 2 : tout d’un côté, factoriser, puis produit nul ou tableau de signes.
:::
