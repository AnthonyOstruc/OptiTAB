=== Identités Remarquables - Applications Mixtes
Id: 1049
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Simplifier ou transformer les expressions suivantes en combinant plusieurs identités remarquables.

1. Simplifier $\displaystyle (x + 1)^2 - (x - 1)^2$
2. Simplifier $\displaystyle (x + 2)^3 + (x - 2)^3$
3. Factoriser $\displaystyle x^4 - 1$
4. Simplifier $\displaystyle (x + 1)^2 + (x - 1)^2$
5. Factoriser $\displaystyle x^6 - 64$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle (x + 1)^2 - (x - 1)^2$

::: methode
Utiliser la différence de deux carrés $A^2 - B^2 = (A - B)(A + B)$
:::

::: etape Identifier $A$ et $B$
- $\displaystyle A = (x + 1)$
- $\displaystyle B = (x - 1)$
:::

::: etape Appliquer la différence de carrés
- $\displaystyle (x + 1)^2 - (x - 1)^2 = ((x + 1) - (x - 1))((x + 1) + (x - 1))$
:::

::: etape Simplifier les parenthèses
- $\displaystyle (x + 1) - (x - 1) = x + 1 - x + 1 = 2$
- $\displaystyle (x + 1) + (x - 1) = x + 1 + x - 1 = 2x$
:::

::: etape Écrire le résultat
- $\displaystyle (x + 1)^2 - (x - 1)^2 = 2 \times 2x = 4x$
:::

::: point Vérification
Pour $x = 1$ : $(2)^2 - (0)^2 = 4$ et $4 \times 1 = 4$
:::

::: resultat
$$(x + 1)^2 - (x - 1)^2 = 4x$$
:::

## Question 2 : Simplifier $\displaystyle (x + 2)^3 + (x - 2)^3$

::: methode
Développer séparément puis réduire, ou reconnaître une forme particulière
:::

::: etape Développer $(x + 2)^3$ en utilisant l'identité au cube
$$
\begin{aligned}
(x + 2)^3 &= x^3 + 3x^2 \times 2 + 3x \times 4 + 8 \\
&= x^3 + 6x^2 + 12x + 8
\end{aligned}
$$
:::

::: etape Développer $(x - 2)^3$ en utilisant l'identité au cube
$$
\begin{aligned}
(x - 2)^3 &= x^3 - 3x^2 \times 2 + 3x \times 4 - 8 \\
&= x^3 - 6x^2 + 12x - 8
\end{aligned}
$$
:::

::: etape Additionner les deux développements
- $\displaystyle (x + 2)^3 + (x - 2)^3 = (x^3 + 6x^2 + 12x + 8) + (x^3 - 6x^2 + 12x - 8)$
:::

::: etape Réduire
$$
\begin{aligned}
= x^3 + 6x^2 + 12x + 8 + x^3 - 6x^2 + 12x - 8 &= (x^3 + x^3) + (6x^2 - 6x^2) + (12x + 12x) + (8 - 8) \\
&= 2x^3 + 24x
\end{aligned}
$$
:::

::: etape Factoriser si possible
- $\displaystyle = 2x(x^2 + 12)$
:::

::: point Vérification
Pour $x = 1$ : $3^3 + (-1)^3 = 27 - 1 = 26$ et $2 + 24 = 26$
:::

::: resultat
$$(x + 2)^3 + (x - 2)^3 = 2x^3 + 24x = 2x(x^2 + 12)$$
:::

## Question 3 : Factoriser $\displaystyle x^4 - 1$

::: methode
Reconnaître une différence de carrés, puis factoriser à nouveau
:::

::: etape Identifier une différence de carrés
- $\displaystyle x^4 - 1 = (x^2)^2 - 1^2 = (x^2 - 1)(x^2 + 1)$
:::

::: etape Factoriser à nouveau $x^2 - 1$ (nouvelle différence de carrés)
- $\displaystyle x^2 - 1 = (x - 1)(x + 1)$
:::

::: etape Écrire le résultat complet
- $\displaystyle x^4 - 1 = (x^2 - 1)(x^2 + 1) = (x - 1)(x + 1)(x^2 + 1)$
:::

::: remarque
$x^2 + 1$ ne se factorise pas dans $\mathbb{R}$ (il n'y a pas de racines réelles)
:::

::: point Vérification
Pour $x = 2$ : $16 - 1 = 15$ et $(2 - 1)(2 + 1)(4 + 1) = 1 \times 3 \times 5 = 15$
:::

::: resultat
$$x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)$$
:::

## Question 4 : Simplifier $\displaystyle (x + 1)^2 + (x - 1)^2$

::: methode
Développer chaque carré puis réduire
:::

::: etape Développer $(x + 1)^2$ en utilisant l'identité remarquable
- $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
:::

::: etape Développer $(x - 1)^2$ en utilisant l'identité remarquable
- $\displaystyle (x - 1)^2 = x^2 - 2x + 1$
:::

::: etape Additionner les deux développements
- $\displaystyle (x + 1)^2 + (x - 1)^2 = (x^2 + 2x + 1) + (x^2 - 2x + 1)$
:::

::: etape Réduire
$$
\begin{aligned}
= x^2 + 2x + 1 + x^2 - 2x + 1 &= (x^2 + x^2) + (2x - 2x) + (1 + 1) \\
&= 2x^2 + 2
\end{aligned}
$$
:::

::: etape Factoriser si possible
- $\displaystyle = 2(x^2 + 1)$
:::

::: point Vérification
Pour $x = 1$ : $2^2 + 0^2 = 4$ et $2 \times 2 = 4$
:::

::: resultat
$$(x + 1)^2 + (x - 1)^2 = 2x^2 + 2 = 2(x^2 + 1)$$
:::

## Question 5 : Factoriser $\displaystyle x^6 - 64$

::: methode
Reconnaître une différence de cubes (ou de carrés à plusieurs niveaux)
:::

::: etape Identifier les cubes
- $\displaystyle x^6 = (x^2)^3$
- $\displaystyle 64 = 4^3$
:::

::: etape Appliquer la différence de cubes
$$
\begin{aligned}
x^6 - 64 &= (x^2)^3 - 4^3 \\
&= (x^2 - 4)((x^2)^2 + 4x^2 + 16) \\
&= (x^2 - 4)(x^4 + 4x^2 + 16)
\end{aligned}
$$
:::

::: etape Factoriser à nouveau $x^2 - 4$ (différence de carrés)
- $\displaystyle x^2 - 4 = (x - 2)(x + 2)$
:::

::: etape Écrire le résultat
$$
\begin{aligned}
x^6 - 64 &= (x^2 - 4)(x^4 + 4x^2 + 16) \\
&= (x - 2)(x + 2)(x^4 + 4x^2 + 16)
\end{aligned}
$$
:::

::: remarque
$x^4 + 4x^2 + 16$ ne se factorise pas facilement dans $\mathbb{R}$
:::

::: point Vérification
Pour $x = 2$ : $64 - 64 = 0$ et $(2 - 2)(2 + 2)(16 + 16 + 16) = 0$
:::

::: resultat
$$x^6 - 64 = (x - 2)(x + 2)(x^4 + 4x^2 + 16)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 1)^2 - (x - 1)^2 = 4x$
2. $\displaystyle (x + 2)^3 + (x - 2)^3 = 2x^3 + 24x = 2x(x^2 + 12)$
3. $\displaystyle x^4 - 1 = (x - 1)(x + 1)(x^2 + 1)$
4. $\displaystyle (x + 1)^2 + (x - 1)^2 = 2x^2 + 2 = 2(x^2 + 1)$
5. $\displaystyle x^6 - 64 = (x - 2)(x + 2)(x^4 + 4x^2 + 16)$

=== Identités Remarquables - Binôme de Newton

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle (x + 2)^4$

::: methode
Utiliser le binôme de Newton avec le triangle de Pascal
:::

::: etape Consulter le triangle de Pascal pour la ligne $n = 4$
- Coefficients : $1$, $4$, $6$, $4$, $1$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = x$
- $\displaystyle b = 2$
:::

::: etape Appliquer la formule avec les coefficients
- $\displaystyle (x + 2)^4 = 1 \times x^4 \times 2^0 + 4 \times x^3 \times 2^1 + 6 \times x^2 \times 2^2 + 4 \times x^1 \times 2^3 + 1 \times x^0 \times 2^4$
:::

::: etape Calculer chaque terme
- $\displaystyle 1 \times x^4 = x^4$
- $\displaystyle 4 \times x^3 \times 2 = 8x^3$
- $\displaystyle 6 \times x^2 \times 4 = 24x^2$
- $\displaystyle 4 \times x \times 8 = 32x$
- $\displaystyle 1 \times 16 = 16$
:::

::: etape Écrire le résultat
- $\displaystyle (x + 2)^4 = x^4 + 8x^3 + 24x^2 + 32x + 16$
:::

::: point Vérification
Pour $x = 1$ : $(1 + 2)^4 = 81$ et $1 + 8 + 24 + 32 + 16 = 81$
:::

::: resultat
$$(x + 2)^4 = x^4 + 8x^3 + 24x^2 + 32x + 16$$
:::

=== Identités Remarquables - Carrés (Développement)
Id: 1043
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes en utilisant les identités remarquables.

1. Développer $\displaystyle (x + 3)^2$
2. Développer $\displaystyle (x - 4)^2$
3. Développer $\displaystyle (2x + 5)^2$
4. Développer $\displaystyle (3x - 1)^2$
5. Développer $\displaystyle (x + 7)(x - 7)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle (x + 3)^2$

::: methode
Utiliser l'identité remarquable $(a + b)^2 = a^2 + 2ab + b^2$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = x$
- $\displaystyle b = 3$
:::

::: etape Appliquer l'identité
- $\displaystyle (x + 3)^2 = x^2 + 2 \times x \times 3 + 3^2$
:::

::: etape Calculer
- $\displaystyle = x^2 + 6x + 9$
:::

::: point Vérification
Pour $x = 1$ : $(1 + 3)^2 = 16$ et $1 + 6 + 9 = 16$
:::

::: resultat
$$(x + 3)^2 = x^2 + 6x + 9$$
:::

## Question 2 : Développer $\displaystyle (x - 4)^2$

::: methode
Utiliser l'identité remarquable $(a - b)^2 = a^2 - 2ab + b^2$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = x$
- $\displaystyle b = 4$
:::

::: etape Appliquer l'identité
- $\displaystyle (x - 4)^2 = x^2 - 2 \times x \times 4 + 4^2$
:::

::: etape Calculer
- $\displaystyle = x^2 - 8x + 16$
:::

::: point Vérification
Pour $x = 1$ : $(1 - 4)^2 = 9$ et $1 - 8 + 16 = 9$
:::

::: resultat
$$(x - 4)^2 = x^2 - 8x + 16$$
:::

## Question 3 : Développer $\displaystyle (2x + 5)^2$

::: methode
Utiliser l'identité remarquable $(a + b)^2 = a^2 + 2ab + b^2$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = 2x$
- $\displaystyle b = 5$
:::

::: etape Appliquer l'identité
- $\displaystyle (2x + 5)^2 = (2x)^2 + 2 \times (2x) \times 5 + 5^2$
:::

::: etape Calculer
- $\displaystyle = 4x^2 + 20x + 25$
:::

::: point Vérification
Pour $x = 1$ : $(2 + 5)^2 = 49$ et $4 + 20 + 25 = 49$
:::

::: resultat
$$(2x + 5)^2 = 4x^2 + 20x + 25$$
:::

## Question 4 : Développer $\displaystyle (3x - 1)^2$

::: methode
Utiliser l'identité remarquable $(a - b)^2 = a^2 - 2ab + b^2$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = 3x$
- $\displaystyle b = 1$
:::

::: etape Appliquer l'identité
- $\displaystyle (3x - 1)^2 = (3x)^2 - 2 \times (3x) \times 1 + 1^2$
:::

::: etape Calculer
- $\displaystyle = 9x^2 - 6x + 1$
:::

::: point Vérification
Pour $x = 1$ : $(3 - 1)^2 = 4$ et $9 - 6 + 1 = 4$
:::

::: resultat
$$(3x - 1)^2 = 9x^2 - 6x + 1$$
:::

## Question 5 : Développer $\displaystyle (x + 7)(x - 7)$

::: methode
Utiliser l'identité remarquable $(a + b)(a - b) = a^2 - b^2$
:::

::: etape Identifier $a$ et $b$
- $\displaystyle a = x$
- $\displaystyle b = 7$
:::

::: etape Appliquer l'identité
- $\displaystyle (x + 7)(x - 7) = x^2 - 7^2$
:::

::: etape Calculer
- $\displaystyle = x^2 - 49$
:::

::: point Vérification
Pour $x = 5$ : $(5 + 7)(5 - 7) = 12 \times (-2) = -24$ et $25 - 49 = -24$
:::

::: resultat
$$(x + 7)(x - 7) = x^2 - 49$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 3)^2 = x^2 + 6x + 9$
2. $\displaystyle (x - 4)^2 = x^2 - 8x + 16$
3. $\displaystyle (2x + 5)^2 = 4x^2 + 20x + 25$
4. $\displaystyle (3x - 1)^2 = 9x^2 - 6x + 1$
5. $\displaystyle (x + 7)(x - 7) = x^2 - 49$

=== Identités Remarquables - Carrés (Factorisation)
Id: 1044
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Factoriser les expressions suivantes en reconnaissant les identités remarquables.

1. Factoriser $\displaystyle x^2 + 10x + 25$
2. Factoriser $\displaystyle x^2 - 12x + 36$
3. Factoriser $\displaystyle 4x^2 - 1$
4. Factoriser $\displaystyle 9x^2 - 24x + 16$
5. Factoriser $\displaystyle x^2 - 64$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle x^2 + 10x + 25$

::: methode
Reconnaître la forme $\displaystyle a^2 + 2ab + b^2 = (a + b)^2$
:::

::: etape Identifier les carrés parfaits
- $x^2 = (x)^2$ donc $a = x$
- $25 = 5^2$ donc $b = 5$
:::

::: etape Vérifier le double produit
- $2ab = 2 \times x \times 5 = 10x$ (correspond au terme du milieu)
:::

::: etape Factoriser
- $\displaystyle x^2 + 10x + 25 = (x + 5)^2$
:::

::: point Vérification
Développer $\displaystyle (x + 5)^2 = x^2 + 10x + 25$
:::

::: resultat
$$x^2 + 10x + 25 = (x + 5)^2$$
:::

## Question 2 : Factoriser $\displaystyle x^2 - 12x + 36$

::: methode
Reconnaître la forme $\displaystyle a^2 - 2ab + b^2 = (a - b)^2$
:::

::: etape Identifier les carrés parfaits
- $x^2 = (x)^2$ donc $a = x$
- $36 = 6^2$ donc $b = 6$
:::

::: etape Vérifier le double produit
- $2ab = 2 \times x \times 6 = 12x$ (correspond au terme du milieu)
:::

::: etape Factoriser
- $\displaystyle x^2 - 12x + 36 = (x - 6)^2$
:::

::: point Vérification
Développer $\displaystyle (x - 6)^2 = x^2 - 12x + 36$
:::

::: resultat
$$x^2 - 12x + 36 = (x - 6)^2$$
:::

## Question 3 : Factoriser $\displaystyle 4x^2 - 1$

::: methode
Reconnaître la différence de deux carrés $a^2 - b^2 = (a + b)(a - b)$
:::

::: etape Identifier les carrés
- $4x^2 = (2x)^2$ donc $a = 2x$
- $1 = 1^2$ donc $b = 1$
:::

::: etape Appliquer l'identité
- $\displaystyle 4x^2 - 1 = (2x)^2 - 1^2 = (2x + 1)(2x - 1)$
:::

::: point Vérification
Développer $\displaystyle (2x + 1)(2x - 1) = 4x^2 - 1$
:::

::: resultat
$$4x^2 - 1 = (2x + 1)(2x - 1)$$
:::

## Question 4 : Factoriser $\displaystyle 9x^2 - 24x + 16$

::: methode
Reconnaître la forme $\displaystyle a^2 - 2ab + b^2 = (a - b)^2$
:::

::: etape Identifier les carrés parfaits
- $9x^2 = (3x)^2$ donc $a = 3x$
- $16 = 4^2$ donc $b = 4$
:::

::: etape Vérifier le double produit
- $2ab = 2 \times 3x \times 4 = 24x$ (correspond au terme du milieu)
:::

::: etape Factoriser
- $\displaystyle 9x^2 - 24x + 16 = (3x - 4)^2$
:::

::: point Vérification
Développer $\displaystyle (3x - 4)^2 = 9x^2 - 24x + 16$
:::

::: resultat
$$9x^2 - 24x + 16 = (3x - 4)^2$$
:::

## Question 5 : Factoriser $\displaystyle x^2 - 64$

::: methode
Reconnaître la différence de deux carrés $a^2 - b^2 = (a + b)(a - b)$
:::

::: etape Identifier les carrés
- $x^2 = (x)^2$ donc $a = x$
- $64 = 8^2$ donc $b = 8$
:::

::: etape Appliquer l'identité
- $\displaystyle x^2 - 64 = x^2 - 8^2 = (x + 8)(x - 8)$
:::

::: point Vérification
Développer $\displaystyle (x + 8)(x - 8) = x^2 - 64$
:::

::: resultat
$$x^2 - 64 = (x + 8)(x - 8)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle x^2 + 10x + 25 = (x + 5)^2$
2. $\displaystyle x^2 - 12x + 36 = (x - 6)^2$

## Question 1 : Factoriser $\displaystyle x^3 + 8$

::: methode
Reconnaître la somme de deux cubes $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
:::

::: etape Identifier les cubes
- $x^3 = (x)^3$ donc $a = x$

:::

::: etape Appliquer l'identité
- $\displaystyle x^3 + 8 = x^3 + 2^3 = (x + 2)(x^2 - 2x + 4)$
:::

::: etape Vérifier le second facteur
- $\displaystyle a^2 - ab + b^2 = x^2 - x \times 2 + 2^2 = x^2 - 2x + 4$
:::

::: point Vérification
Développer $\displaystyle (x + 2)(x^2 - 2x + 4) = x^3 - 2x^2 + 4x + 2x^2 - 4x + 8 = x^3 + 8$

:::

## Question 2 : Factoriser $\displaystyle x^3 - 27$

::: methode

- $27 = 3^3$ donc $b = 3$

$$x^3 - 27 = (x - 3)(x^2 + 3x + 9)$$

## Question 3 : Factoriser $\displaystyle 8x^3 - 1$

::: methode
Reconnaître la différence de deux cubes $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$

::: resultat

=== Identités Remarquables - Factorisations Avancées

4. Factoriser $\displaystyle x^2 - 4y^2 + 4x + 4$
5. Factoriser $\displaystyle 9x^2 - 24xy + 16y^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $\displaystyle x^4 - 81$

::: methode
Reconnaître une différence de carrés à plusieurs niveaux
:::

::: etape Identifier une première différence de carrés
- $\displaystyle x^4 - 81 = (x^2)^2 - 9^2 = (x^2 - 9)(x^2 + 9)$
:::

::: etape Factoriser à nouveau $x^2 - 9$ (différence de carrés)
- $\displaystyle x^2 - 9 = x^2 - 3^2 = (x - 3)(x + 3)$
:::

::: etape Écrire le résultat complet
$$
\begin{aligned}
x^4 - 81 &= (x^2 - 9)(x^2 + 9) \\
&= (x - 3)(x + 3)(x^2 + 9)
\end{aligned}
$$
:::

::: remarque
$x^2 + 9$ ne se factorise pas dans $\mathbb{R}$ (pas de racines réelles)
:::

::: point Vérification
Pour $x = 3$ : $81 - 81 = 0$ et $(3 - 3)(3 + 3)(9 + 9) = 0$
:::

::: resultat
$$x^4 - 81 = (x - 3)(x + 3)(x^2 + 9)$$
:::

## Question 2 : Factoriser $\displaystyle 16x^4 - 1$

::: methode
Reconnaître une différence de carrés à plusieurs niveaux
:::

::: etape Identifier une première différence de carrés
- $\displaystyle 16x^4 - 1 = (4x^2)^2 - 1^2 = (4x^2 - 1)(4x^2 + 1)$
:::

::: etape Factoriser à nouveau $4x^2 - 1$ (différence de carrés)
- $\displaystyle 4x^2 - 1 = (2x)^2 - 1^2 = (2x - 1)(2x + 1)$
:::

::: etape Écrire le résultat complet
$$
\begin{aligned}
16x^4 - 1 &= (4x^2 - 1)(4x^2 + 1) \\
&= (2x - 1)(2x + 1)(4x^2 + 1)
\end{aligned}
$$
:::

::: remarque
$4x^2 + 1$ ne se factorise pas dans $\mathbb{R}$ (pas de racines réelles)
:::

::: point Vérification
Pour $x = \dfrac{1}{2}$ : $16 \times \dfrac{1}{16} - 1 = 1 - 1 = 0$ et $(1 - 1)(1 + 1)(1 + 1) = 0$
:::

::: resultat
$$16x^4 - 1 = (2x - 1)(2x + 1)(4x^2 + 1)$$
:::

## Question 3 : Factoriser $\displaystyle x^2 + 10x + 25 - y^2$

Regrouper les termes puis utiliser une identité remarquable

::: resultat

=== Identités Remarquables - Problèmes Appliqués
Id: 1052
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Utiliser les identités remarquables pour simplifier et résoudre les problèmes suivants.

1. Montrer que $\displaystyle (x + 3)^2 - (x - 3)^2 = 12x$
2. Développer puis simplifier $\displaystyle (x + 2)(x - 2) + (x + 1)^2$
3. Factoriser $\displaystyle x^2 - 6x + 9 - 4$
4. Simplifier $\displaystyle \dfrac{(x + 1)^2 - 1}{x}$ (avec $\displaystyle x \neq 0$)$
5. Montrer que $\displaystyle (x + y)^2 - (x - y)^2 = 4xy$

Étapes:
<!-- optitab:1 -->
## Question 1 : Montrer que $\displaystyle (x + 3)^2 - (x - 3)^2 = 12x$

::: methode
Utiliser la différence de deux carrés $A^2 - B^2 = (A - B)(A + B)$
:::

::: etape Identifier $A$ et $B$
- $\displaystyle A = (x + 3)$
- $\displaystyle B = (x - 3)$
:::

::: etape Appliquer la différence de carrés
- $\displaystyle (x + 3)^2 - (x - 3)^2 = ((x + 3) - (x - 3))((x + 3) + (x - 3))$
:::

::: etape Simplifier les parenthèses
- $\displaystyle (x + 3) - (x - 3) = x + 3 - x + 3 = 6$
- $\displaystyle (x + 3) + (x - 3) = x + 3 + x - 3 = 2x$
:::

::: etape Multiplier
- $\displaystyle (x + 3)^2 - (x - 3)^2 = 6 \times 2x = 12x$
:::

::: point Vérification
Pour $x = 2$ : $(5)^2 - (-1)^2 = 25 - 1 = 24$ et $12 \times 2 = 24$
:::

::: resultat
$$(x + 3)^2 - (x - 3)^2 = 12x$$
:::

## Question 2 : Développer puis simplifier $\displaystyle (x + 2)(x - 2) + (x + 1)^2$

::: methode
Utiliser les identités remarquables puis réduire
:::

::: etape Appliquer la différence de carrés
- $\displaystyle (x + 2)(x - 2) = x^2 - 4$
:::

::: etape Développer le carré
- $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
:::

::: etape Additionner les deux expressions
- $\displaystyle (x + 2)(x - 2) + (x + 1)^2 = (x^2 - 4) + (x^2 + 2x + 1)$
:::

::: etape Réduire
$$
\begin{aligned}
= x^2 - 4 + x^2 + 2x + 1 &= (x^2 + x^2) + 2x + (-4 + 1) \\
&= 2x^2 + 2x - 3
\end{aligned}
$$
:::

::: point Vérification
Pour $x = 1$ : $(3)(-1) + (2)^2 = -3 + 4 = 1$ et $2 + 2 - 3 = 1$
:::

::: resultat
$$(x + 2)(x - 2) + (x + 1)^2 = 2x^2 + 2x - 3$$
:::

## Question 3 : Factoriser $\displaystyle x^2 - 6x + 9 - 4$

::: methode
Regrouper les termes puis utiliser des identités remarquables
:::

::: etape Calculer d'abord les constantes
- $\displaystyle x^2 - 6x + 9 - 4 = x^2 - 6x + 5$
:::

::: etape Reconnaître que $x^2 - 6x + 9$ est un carré parfait
- $\displaystyle x^2 - 6x + 9 = (x - 3)^2$
:::

::: etape Réécrire l'expression
- $\displaystyle x^2 - 6x + 9 - 4 = (x - 3)^2 - 4$
:::

::: etape Appliquer la différence de carrés
$$
\begin{aligned}
(x - 3)^2 - 4 &= (x - 3)^2 - 2^2 \\
&= ((x - 3) - 2)((x - 3) + 2)
\end{aligned}
$$
:::

::: etape Simplifier
- $\displaystyle = (x - 3 - 2)(x - 3 + 2) = (x - 5)(x - 1)$
:::

::: point Vérification
Pour $x = 0$ : $0 - 0 + 9 - 4 = 5$ et $(-5)(-1) = 5$
:::

::: resultat
$$x^2 - 6x + 9 - 4 = (x - 5)(x - 1)$$
:::

## Question 4 : Simplifier $\displaystyle \dfrac{(x + 1)^2 - 1}{x}$ (avec $\displaystyle x \neq 0$)$

::: methode
Développer le numérateur puis simplifier
:::

::: etape Développer $\displaystyle (x + 1)^2$
- $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
:::

::: etape Calculer le numérateur
- $\displaystyle (x + 1)^2 - 1 = x^2 + 2x + 1 - 1 = x^2 + 2x$
:::

::: etape Factoriser le numérateur
- $\displaystyle x^2 + 2x = x(x + 2)$
:::

::: etape Simplifier la fraction
- $\dfrac{(x + 1)^2 - 1}{x} = \dfrac{x(x + 2)}{x} = x + 2$ (avec $x \neq 0$)
:::

::: point Vérification
Pour $x = 1$ : $\dfrac{(2)^2 - 1}{1} = \dfrac{3}{1} = 3$ et $1 + 2 = 3$
:::

::: resultat
$\dfrac{(x + 1)^2 - 1}{x} = x + 2$ (avec $x \neq 0$)
:::

## Question 5 : Montrer que $\displaystyle (x + y)^2 - (x - y)^2 = 4xy$

::: methode
Utiliser la différence de deux carrés $A^2 - B^2 = (A - B)(A + B)$
:::

::: etape Identifier $A$ et $B$
- $\displaystyle A = (x + y)$
- $\displaystyle B = (x - y)$
:::

::: etape Appliquer la différence de carrés
- $\displaystyle (x + y)^2 - (x - y)^2 = ((x + y) - (x - y))((x + y) + (x - y))$
:::

::: etape Simplifier les parenthèses
- $\displaystyle (x + y) - (x - y) = x + y - x + y = 2y$
- $\displaystyle (x + y) + (x - y) = x + y + x - y = 2x$
:::

::: etape Multiplier
- $\displaystyle (x + y)^2 - (x - y)^2 = 2y \times 2x = 4xy$
:::

::: point Vérification
Pour $x = 2$, $y = 3$ : $(5)^2 - (-1)^2 = 25 - 1 = 24$ et $4 \times 2 \times 3 = 24$
:::

::: resultat
$$(x + y)^2 - (x - y)^2 = 4xy$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x + 3)^2 - (x - 3)^2 = 12x$
2. $\displaystyle (x + 2)(x - 2) + (x + 1)^2 = 2x^2 + 2x - 3$
3. $\displaystyle x^2 - 6x + 9 - 4 = (x - 5)(x - 1)$
4. $\dfrac{(x + 1)^2 - 1}{x} = x + 2$ (avec $x \neq 0$)
5. $\displaystyle (x + y)^2 - (x - y)^2 = 4xy$

=== Identités Remarquables - Trois Termes
Id: 1048
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer les expressions suivantes avec trois termes en utilisant l'identité remarquable $(a + b + c)^2$.

1. Développer $\displaystyle (x + y + 1)^2$
2. Développer $\displaystyle (x + 2 + z)^2$
3. Développer $\displaystyle (2x + y + 3)^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $\displaystyle (x + y + 1)^2$

::: methode
Utiliser l'identité remarquable $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$
:::

::: etape Identifier $a$, $b$ et $c$
- $\displaystyle a = x$
- $\displaystyle b = y$
- $\displaystyle c = 1$
:::

::: etape Calculer les carrés
- $\displaystyle a^2 = x^2$
- $\displaystyle b^2 = y^2$
- $\displaystyle c^2 = 1^2 = 1$
:::

::: etape Calculer les doubles produits
- $\displaystyle 2ab = 2xy$
- $\displaystyle 2ac = 2x$
- $\displaystyle 2bc = 2y$
:::

::: etape Écrire le résultat
- $\displaystyle (x + y + 1)^2 = x^2 + y^2 + 1 + 2xy + 2x + 2y$
:::

::: point Vérification
Pour $x = 1$, $y = 1$ : $(1 + 1 + 1)^2 = 9$ et $1 + 1 + 1 + 2 + 2 + 2 = 9$
:::

::: resultat
$$(x + y + 1)^2 = x^2 + y^2 + 1 + 2xy + 2x + 2y$$
:::

## Question 2 : Développer $\displaystyle (x + 2 + z)^2$

::: methode
Utiliser l'identité remarquable $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$
:::

::: etape Identifier $a$, $b$ et $c$
- $\displaystyle a = x$
- $\displaystyle b = 2$
- $\displaystyle c = z$
:::

::: etape Calculer les carrés

- $\displaystyle b^2 = 4$
- $\displaystyle c^2 = z^2$
:::

::: etape Calculer les doubles produits

- $\displaystyle 2ac = 2xz$

::: point Vérification

## Question 3 : Développer $\displaystyle (2x + y + 3)^2$

::: methode
Utiliser l'identité remarquable $(a + b + c)^2 = a^2 + b^2 + c^2 + 2ab + 2ac + 2bc$

::: etape Identifier $a$, $b$ et $c$

- $\displaystyle c = 3$

::: etape Calculer les carrés

- $\displaystyle b^2 = y^2$
- $\displaystyle c^2 = 9$

::: etape Calculer les doubles produits
- $\displaystyle 2ab = 2 \times 2x \times y = 4xy$

- $\displaystyle 2bc = 2 \times y \times 3 = 6y$
:::

::: etape Écrire le résultat
- $\displaystyle (2x + y + 3)^2 = 4x^2 + y^2 + 9 + 4xy + 12x + 6y$
:::

::: point Vérification
Pour $x = 1$, $y = 1$ : $(2 + 1 + 3)^2 = 36$ et $4 + 1 + 9 + 4 + 12 + 6 = 36$
:::

::: resultat
$$(2x + y + 3)^2 = 4x^2 + y^2 + 9 + 4xy + 12x + 6y$$
:::

## Question 4 : Développer $\displaystyle (x - y + 1)^2$
