=== Découverte - Savoir si un point appartient à une courbe
Id: 2035
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Soit $f$ la fonction définie sur $\mathbb{R}$ par $f(x) = x^2 - 3x + 1$. On note $\mathcal{C}_f$ sa courbe représentative, tracée ci-dessous.

[IMAGE_1]

1. Le point $A(2\,;-1)$ appartient-il à $\mathcal{C}_f$ ?
2. Le point $B(-1\,;5)$ appartient-il à $\mathcal{C}_f$ ?
3. Le point $C(0\,;0)$ appartient-il à $\mathcal{C}_f$ ?
4. Donner les coordonnées du point de $\mathcal{C}_f$ d’abscisse $3$.
5. Déterminer par le calcul les abscisses des points de $\mathcal{C}_f$ d’ordonnée $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le point $A(2\,;-1)$

::: methode
Un point $M(a\,;b)$ appartient à $\mathcal{C}_f$ si et seulement si $b = f(a)$ : on calcule l’image de l’abscisse et on la compare à l’ordonnée.
:::

::: etape Calculer l’image de l’abscisse $x_A = 2$
$$f(2) = 2^2 - 3 \times 2 + 1 = 4 - 6 + 1 = -1$$
:::

::: etape Comparer avec l’ordonnée $y_A = -1$
$f(2) = -1 = y_A$.
:::

::: resultat
$A \in \mathcal{C}_f$.
:::

## Question 2 : Le point $B(-1\,;5)$

::: methode
Même méthode : calculer $f(-1)$ et comparer à $y_B$.
:::

::: etape Calculer $f(-1)$
$$f(-1) = (-1)^2 - 3 \times (-1) + 1 = 1 + 3 + 1 = 5$$
:::

::: resultat
$f(-1) = 5 = y_B$, donc $B \in \mathcal{C}_f$.
:::

::: attention
Mettre $-1$ entre parenthèses : $(-1)^2 = 1$, alors que $-1^2 = -1$.
:::

## Question 3 : Le point $C(0\,;0)$

::: methode
Calculer $f(0)$ et comparer à $y_C = 0$.
:::

::: etape Calculer $f(0)$
$$f(0) = 0^2 - 3 \times 0 + 1 = 1$$
:::

::: resultat
$f(0) = 1 \neq 0$, donc $C \notin \mathcal{C}_f$ : le point de $\mathcal{C}_f$ d’abscisse $0$ est $(0\,;1)$, pas $(0\,;0)$.
:::

## Question 4 : Point de $\mathcal{C}_f$ d’abscisse $3$

::: methode
Sur $\mathcal{C}_f$, le point d’abscisse $a$ a pour ordonnée $f(a)$.
:::

::: etape Calculer $f(3)$
$$f(3) = 3^2 - 3 \times 3 + 1 = 9 - 9 + 1 = 1$$
:::

::: resultat
Le point de $\mathcal{C}_f$ d’abscisse $3$ est $(3\,;1)$.
:::

## Question 5 : Points de $\mathcal{C}_f$ d’ordonnée $1$

::: methode
Chercher les points d’ordonnée $1$, c’est résoudre l’équation $f(x) = 1$.
:::

::: etape Écrire l’équation et tout passer à gauche
$$
\begin{aligned}
f(x) = 1 &\iff x^2 - 3x + 1 = 1 \\
&\iff x^2 - 3x = 0
\end{aligned}
$$
:::

::: etape Factoriser par $x$
$$x^2 - 3x = 0 \iff x(x - 3) = 0$$
:::

::: etape Appliquer la règle du produit nul
$x = 0$ ou $x - 3 = 0$, soit $x = 0$ ou $x = 3$.
:::

::: resultat
Les abscisses cherchées sont $0$ et $3$ : ce sont les points $(0\,;1)$ et $(3\,;1)$.
:::

[IMAGE_2]

::: retenir
Les points d’ordonnée $k$ s’obtiennent en résolvant $f(x) = k$ : graphiquement, ce sont les intersections de $\mathcal{C}_f$ avec la droite $y = k$.
:::

Solution:
<!-- optitab:1 -->
1. $f(2) = -1$ : oui, $A \in \mathcal{C}_f$.
2. $f(-1) = 5$ : oui, $B \in \mathcal{C}_f$.
3. $f(0) = 1 \neq 0$ : non, $C \notin \mathcal{C}_f$.
4. $(3\,;1)$.
5. $x = 0$ ou $x = 3$.

=== Découverte - Lire des images et des antécédents dans une table de valeurs
Id: 2037
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une fonction $f$ est définie sur $[-3\,;3]$. On a relevé les valeurs suivantes.

| $x$ | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|---|---|---|
| $f(x)$ | $5$ | $2$ | $0$ | $-1$ | $0$ | $2$ | $5$ |

1. Donner $f(-2)$, $f(0)$ et $f(3)$.
2. Donner les antécédents de $0$ par $f$ figurant dans la table.
3. Le point $P(2\,;2)$ appartient-il à la courbe $\mathcal{C}_f$ ?
4. Parmi les valeurs de la table, quelles sont les solutions de $f(x) = 2$ ?
5. Parmi les valeurs de $x$ de la table, pour lesquelles a-t-on $f(x) \le 0$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire des images

::: methode
L’image de $a$ se lit dans la colonne de $a$, sur la ligne $f(x)$.
:::

::: etape Lecture dans la table
- Colonne $x = -2$ : $f(-2) = 2$.
- Colonne $x = 0$ : $f(0) = -1$.
- Colonne $x = 3$ : $f(3) = 5$.
:::

::: resultat
$f(-2) = 2$, $f(0) = -1$ et $f(3) = 5$.
:::

## Question 2 : Antécédents de $0$

::: methode
On cherche $0$ sur la ligne $f(x)$, puis on lit les valeurs de $x$ correspondantes.
:::

::: etape Lecture dans la table
La valeur $0$ apparaît deux fois : $f(-1) = 0$ et $f(1) = 0$.
:::

::: resultat
Dans la table, les antécédents de $0$ sont $-1$ et $1$.
:::

::: attention
Une table ne donne que quelques valeurs : la fonction pourrait avoir d’autres antécédents de $0$ entre deux colonnes. On répond donc « d’après la table ».
:::

## Question 3 : Le point $P(2\,;2)$

::: methode
$P(a\,;b) \in \mathcal{C}_f$ si et seulement si $f(a) = b$.
:::

::: etape Comparer $f(2)$ et l’ordonnée de $P$
La table donne $f(2) = 2$, et $P$ a pour ordonnée $2$.
:::

::: resultat
$f(2) = 2$, donc $P \in \mathcal{C}_f$.
:::

## Question 4 : Solutions de $f(x) = 2$ dans la table

::: methode
Résoudre $f(x) = 2$, c’est chercher les antécédents de $2$.
:::

::: etape Lecture dans la table
$f(-2) = 2$ et $f(2) = 2$.
:::

[IMAGE_1]

Sur le graphique des points de la table, ce sont les deux points situés sur la droite $y = 2$.

::: resultat
Parmi les valeurs de la table, les solutions sont $-2$ et $2$.
:::

## Question 5 : Valeurs de $x$ telles que $f(x) \le 0$

::: methode
On repère sur la ligne $f(x)$ les valeurs négatives ou nulles.
:::

::: etape Lecture dans la table
$f(-1) = 0$, $f(0) = -1$ et $f(1) = 0$ ; toutes les autres valeurs sont strictement positives.
:::

[IMAGE_2]

Graphiquement, on garde les points situés sur l’axe des abscisses ou en dessous.

::: resultat
Parmi les valeurs de la table, $f(x) \le 0$ pour $x \in \{-1\,;0\,;1\}$.
:::

::: attention
$\le 0$ signifie « négatif **ou nul** » : $-1$ et $1$ (où $f(x) = 0$) font partie des réponses.
:::

Solution:
<!-- optitab:1 -->
1. $f(-2) = 2$, $f(0) = -1$, $f(3) = 5$.
2. $-1$ et $1$.
3. Oui, car $f(2) = 2$.
4. $x = -2$ ou $x = 2$.
5. $x \in \{-1\,;0\,;1\}$.

=== Découverte - Tracer une courbe à partir d’une table de valeurs
Id: 2036
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie sur $\mathbb{R}$ par $f(x) = x^2 - 4$. On veut tracer sa courbe $\mathcal{C}_f$ sur $[-3\,;3]$.

1. Compléter la table de valeurs.

| $x$ | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|---|---|---|
| $f(x)$ | … | … | … | … | … | … | … |

2. Placer les points $(x\,;f(x))$ dans le repère ci-dessous, puis tracer $\mathcal{C}_f$.

[IMAGE_1]

3. La courbe $\mathcal{C}_f$ coupe-t-elle l’axe des abscisses ? Si oui, en quels points ?
4. Donner les antécédents de $0$ par $f$.
5. La fonction $f$ est-elle paire, impaire, ou ni l’une ni l’autre ? Quelle symétrie de la courbe le confirme ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter la table de valeurs

::: methode
On remplace $x$ par chaque valeur, en mettant les nombres négatifs entre parenthèses.
:::

::: etape Calcul des images
- $f(-3) = (-3)^2 - 4 = 9 - 4 = 5$
- $f(-2) = (-2)^2 - 4 = 4 - 4 = 0$
- $f(-1) = (-1)^2 - 4 = 1 - 4 = -3$
- $f(0) = 0^2 - 4 = -4$
- $f(1) = 1 - 4 = -3$, $f(2) = 4 - 4 = 0$, $f(3) = 9 - 4 = 5$
:::

::: resultat
| $x$ | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|---|---|---|
| $f(x)$ | $5$ | $0$ | $-3$ | $-4$ | $-3$ | $0$ | $5$ |
:::

## Question 2 : Placer les points et tracer la courbe

::: methode
Chaque colonne de la table donne un point $(x\,;f(x))$ ; on relie les points par une courbe régulière (pas par des segments).
:::

::: etape Liste des points
$(-3\,;5)$, $(-2\,;0)$, $(-1\,;-3)$, $(0\,;-4)$, $(1\,;-3)$, $(2\,;0)$, $(3\,;5)$.
:::

[IMAGE_2]

::: resultat
La courbe obtenue est une parabole, de point le plus bas $(0\,;-4)$.
:::

## Question 3 : Intersection avec l’axe des abscisses

::: methode
Sur l’axe des abscisses, l’ordonnée est nulle : on résout $f(x) = 0$.
:::

::: etape Résoudre $x^2 - 4 = 0$
$$
\begin{aligned}
x^2 - 4 = 0 &\iff (x - 2)(x + 2) = 0 \\
&\iff x = 2 \text{ ou } x = -2
\end{aligned}
$$
:::

::: resultat
Oui : $\mathcal{C}_f$ coupe l’axe des abscisses aux points $(-2\,;0)$ et $(2\,;0)$.
:::

## Question 4 : Antécédents de $0$

::: methode
Un antécédent de $0$ est une solution de $f(x) = 0$.
:::

::: resultat
D’après la question 3, les antécédents de $0$ sont $-2$ et $2$.
:::

## Question 5 : Parité de $f$

::: methode
$\mathbb{R}$ est symétrique par rapport à $0$ ; on calcule $f(-x)$ pour tout réel $x$ et on compare à $f(x)$.
:::

::: etape Calculer $f(-x)$
$$f(-x) = (-x)^2 - 4 = x^2 - 4 = f(x)$$
:::

::: resultat
$f$ est **paire** : sa courbe est symétrique par rapport à l’axe des ordonnées, ce que montre la table ($f(-3) = f(3)$, $f(-2) = f(2)$, $f(-1) = f(1)$).
:::

Solution:
<!-- optitab:1 -->
1. $5$ ; $0$ ; $-3$ ; $-4$ ; $-3$ ; $0$ ; $5$.
2. Parabole passant par les sept points, de point le plus bas $(0\,;-4)$.
3. Oui, en $(-2\,;0)$ et $(2\,;0)$.
4. $-2$ et $2$.
5. $f$ est paire (symétrie par rapport à l’axe des ordonnées).

=== Entraînement - Reconnaître une fonction paire ou impaire
Id: 2040
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Les fonctions suivantes sont définies sur $\mathbb{R}$, ensemble symétrique par rapport à $0$.

1. La fonction $f : x \mapsto x^2 - 5$ est-elle paire, impaire, ou ni l’une ni l’autre ?
2. La fonction $g : x \mapsto x^3 - x$ est-elle paire, impaire, ou ni l’une ni l’autre ?
3. La fonction $h : x \mapsto x^3 + x^2$ est-elle paire, impaire, ou ni l’une ni l’autre ?
4. Une fonction $u$ est paire et le point $A(2\,;-3)$ appartient à sa courbe. Donner un autre point de la courbe de $u$.
5. Une fonction $v$ est impaire et le point $B(4\,;1)$ appartient à sa courbe. Donner un autre point de la courbe de $v$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Parité de $f(x) = x^2 - 5$

::: methode
Calculer $f(-x)$ pour tout réel $x$, puis comparer à $f(x)$ et à $-f(x)$.
:::

::: etape Calculer $f(-x)$
$$f(-x) = (-x)^2 - 5 = x^2 - 5 = f(x)$$
:::

::: resultat
$f$ est **paire** : sa courbe est symétrique par rapport à l’axe des ordonnées.
:::

[IMAGE_1]

## Question 2 : Parité de $g(x) = x^3 - x$

::: methode
Même méthode : $(-x)^3 = -x^3$ (puissance impaire).
:::

::: etape Calculer $g(-x)$
$$
\begin{aligned}
g(-x) &= (-x)^3 - (-x) \\
&= -x^3 + x \\
&= -(x^3 - x) = -g(x)
\end{aligned}
$$
:::

::: resultat
$g$ est **impaire** : sa courbe est symétrique par rapport à l’origine.
:::

[IMAGE_2]

## Question 3 : Parité de $h(x) = x^3 + x^2$

::: methode
Pour montrer qu’une fonction n’est ni paire ni impaire, un contre-exemple numérique suffit.
:::

::: etape Calculer $h(1)$ et $h(-1)$
- $h(1) = 1^3 + 1^2 = 2$
- $h(-1) = (-1)^3 + (-1)^2 = -1 + 1 = 0$
:::

::: etape Conclure
- $h(-1) \neq h(1)$ (car $0 \neq 2$) : $h$ n’est pas paire.
- $h(-1) \neq -h(1)$ (car $0 \neq -2$) : $h$ n’est pas impaire.
:::

::: resultat
$h$ n’est **ni paire ni impaire** : sa courbe n’a aucune des deux symétries.
:::

[IMAGE_3]

::: attention
La somme d’une fonction paire ($x^2$) et d’une fonction impaire ($x^3$) n’est en général ni paire ni impaire.
:::

## Question 4 : Point symétrique (fonction paire)

::: methode
Si $u$ est paire et $(a\,;b)$ est sur sa courbe, alors $u(-a) = u(a) = b$ : le point $(-a\,;b)$ est aussi sur la courbe.
:::

::: etape Appliquer à $A(2\,;-3)$
$u(-2) = u(2) = -3$ : on change seulement le signe de l’abscisse.
:::

::: resultat
$A'(-2\,;-3)$ appartient à la courbe de $u$ (symétrique de $A$ par rapport à l’axe des ordonnées).
:::

## Question 5 : Point symétrique (fonction impaire)

::: methode
Si $v$ est impaire et $(a\,;b)$ est sur sa courbe, alors $v(-a) = -v(a) = -b$ : le point $(-a\,;-b)$ est aussi sur la courbe.
:::

::: etape Appliquer à $B(4\,;1)$
$v(-4) = -v(4) = -1$ : on change le signe des deux coordonnées.
:::

::: resultat
$B'(-4\,;-1)$ appartient à la courbe de $v$ (symétrique de $B$ par rapport à l’origine).
:::

Solution:
<!-- optitab:1 -->
1. $f(-x) = f(x)$ : $f$ est paire.
2. $g(-x) = -g(x)$ : $g$ est impaire.
3. $h(1) = 2$ et $h(-1) = 0$ : $h$ n’est ni paire ni impaire.
4. $A'(-2\,;-3)$.
5. $B'(-4\,;-1)$.

=== Entraînement - Résoudre f(x) = g(x) et f(x) ≥ g(x) graphiquement puis par le calcul
Id: 2039
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère les fonctions $f$ et $g$ définies sur $\mathbb{R}$ par $f(x) = x^2 - 2$ et $g(x) = x$. Leurs courbes $\mathcal{C}_f$ (parabole) et $\mathcal{C}_g$ (droite) sont tracées ci-dessous.

[IMAGE_1]

1. Résoudre graphiquement l’équation $f(x) = g(x)$.
2. Donner les coordonnées des points d’intersection de $\mathcal{C}_f$ et $\mathcal{C}_g$.
3. Résoudre graphiquement l’inéquation $f(x) \ge g(x)$.
4. Démontrer que, pour tout réel $x$, $f(x) - g(x) = (x + 1)(x - 2)$.
5. Résoudre par le calcul $f(x) = g(x)$, puis $f(x) \ge g(x)$ à l’aide d’un tableau de signes. Comparer avec les lectures graphiques.

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre graphiquement $f(x) = g(x)$

::: methode
Les solutions de $f(x) = g(x)$ sont les abscisses des points d’intersection des deux courbes.
:::

::: etape Repérer les intersections
La parabole et la droite se coupent en deux points, d’abscisses $-1$ et $2$.
:::

[IMAGE_2]

::: resultat
Graphiquement, $f(x) = g(x) \iff x = -1$ ou $x = 2$.
:::

## Question 2 : Coordonnées des points d’intersection

::: methode
Un point d’intersection d’abscisse $a$ a pour ordonnée $f(a)$, qui est aussi égale à $g(a)$.
:::

::: etape Calculer les ordonnées
- $f(-1) = (-1)^2 - 2 = -1$ et $g(-1) = -1$ ;
- $f(2) = 2^2 - 2 = 2$ et $g(2) = 2$.
:::

::: resultat
Les points d’intersection sont $(-1\,;-1)$ et $(2\,;2)$.
:::

## Question 3 : Résoudre graphiquement $f(x) \ge g(x)$

::: methode
On cherche les abscisses des points où la parabole est **au-dessus** de la droite (ou la coupe).
:::

::: etape Lire la position des courbes
- À gauche de $-1$ et à droite de $2$, la parabole est au-dessus de la droite.
- Entre $-1$ et $2$, elle est en dessous.
- En $-1$ et en $2$, les courbes se coupent : il y a égalité, valeurs comprises car l’inégalité est large.
:::

[IMAGE_3]

::: resultat
Graphiquement, l’ensemble des solutions de $f(x) \ge g(x)$ est

$$S = {]-\infty\,;-1]} \cup [2\,;+\infty[$$
:::

## Question 4 : Factoriser $f(x) - g(x)$

::: methode
Pour démontrer une égalité, on développe le membre factorisé et on compare.
:::

::: etape Développer $(x + 1)(x - 2)$
$$
\begin{aligned}
(x + 1)(x - 2) &= x^2 - 2x + x - 2 \\
&= x^2 - x - 2
\end{aligned}
$$
:::

::: etape Calculer $f(x) - g(x)$
$$f(x) - g(x) = x^2 - 2 - x = x^2 - x - 2$$
:::

::: resultat
Pour tout réel $x$, $f(x) - g(x) = (x + 1)(x - 2)$.
:::

## Question 5 : Résolution par le calcul

::: methode
Comparer $f(x)$ et $g(x)$, c’est étudier le signe de la différence $f(x) - g(x)$.
:::

::: etape Équation
$$
\begin{aligned}
f(x) = g(x) &\iff (x + 1)(x - 2) = 0 \\
&\iff x = -1 \text{ ou } x = 2
\end{aligned}
$$
:::

::: etape Tableau de signes de $(x + 1)(x - 2)$
$x + 1$ s’annule en $-1$ et $x - 2$ en $2$ ; chacun est négatif avant sa valeur d’annulation et positif après (coefficient de $x$ égal à $1 \gt 0$).
:::

::: tableau
x : -\infty, -1, 2, +\infty
x+1 : , -, z, +, t, +,
x-2 : , -, t, -, z, +,
Produit : , +, z, -, z, +,
:::

::: resultat
$f(x) \ge g(x) \iff (x + 1)(x - 2) \ge 0$, donc

$$S = {]-\infty\,;-1]} \cup [2\,;+\infty[$$

Le calcul confirme les lectures graphiques.
:::

::: attention
Ne pas « diviser » ou simplifier une inéquation par une expression en $x$ : on passe tout d’un côté, on factorise et on étudie le signe.
:::

Solution:
<!-- optitab:1 -->
1. $x = -1$ ou $x = 2$.
2. $(-1\,;-1)$ et $(2\,;2)$.
3. $x \in {]-\infty\,;-1]} \cup [2\,;+\infty[$.
4. $(x + 1)(x - 2) = x^2 - x - 2 = f(x) - g(x)$.
5. $S = \{-1\,;2\}$ pour l’équation ; $S = {]-\infty\,;-1]} \cup [2\,;+\infty[$ pour l’inéquation.

=== Entraînement - Résoudre f(x) = k et f(x) ≥ k sur une ligne brisée
Id: 2038
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une fonction $f$ est définie sur $[-3\,;5]$ par sa courbe $\mathcal{C}_f$ : la ligne brisée qui relie, dans cet ordre, les points $A(-3\,;1)$, $B(-1\,;4)$, $C(2\,;-2)$ et $D(5\,;1)$.

[IMAGE_1]

1. Lire $f(-1)$, $f(2)$ et $f(5)$.
2. Résoudre graphiquement $f(x) = 0$.
3. Résoudre graphiquement $f(x) = 1$.
4. Résoudre graphiquement $f(x) \ge 1$.
5. Résoudre graphiquement $f(x) \le 0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire des images

::: methode
Les points $B$, $C$, $D$ sont sur $\mathcal{C}_f$ : l’ordonnée de chacun est l’image de son abscisse.
:::

::: etape Lecture
- $B(-1\,;4)$ donne $f(-1) = 4$ ;
- $C(2\,;-2)$ donne $f(2) = -2$ ;
- $D(5\,;1)$ donne $f(5) = 1$.
:::

::: resultat
$f(-1) = 4$, $f(2) = -2$ et $f(5) = 1$.
:::

## Question 2 : Résoudre $f(x) = 0$

::: methode
Les solutions sont les abscisses des points où $\mathcal{C}_f$ coupe l’axe des abscisses (droite $y = 0$).
:::

::: etape Lecture sur la figure
Le segment $[AB]$ reste au-dessus de l’axe (ordonnées entre $1$ et $4$). Le segment $[BC]$ coupe l’axe en $x = 1$ et le segment $[CD]$ le coupe en $x = 4$.
:::

[IMAGE_2]

::: etape Vérification par le calcul
- $[BC]$ descend de $6$ unités quand $x$ augmente de $3$ : pente $-2$, donc $f(x) = -2x + 2$ sur $[-1\,;2]$, et $-2x + 2 = 0 \iff x = 1$.
- $[CD]$ monte de $3$ unités quand $x$ augmente de $3$ : pente $1$, donc $f(x) = x - 4$ sur $[2\,;5]$, et $x - 4 = 0 \iff x = 4$.
:::

::: resultat
$f(x) = 0 \iff x = 1$ ou $x = 4$.
:::

## Question 3 : Résoudre $f(x) = 1$

::: methode
On trace la droite horizontale $y = 1$ et on lit les abscisses de ses points d’intersection avec $\mathcal{C}_f$.
:::

::: etape Lecture sur la figure
La droite $y = 1$ passe par $A$ (abscisse $-3$) et par $D$ (abscisse $5$), et coupe $[BC]$ en un troisième point.
:::

::: etape Abscisse du point sur $[BC]$
$$-2x + 2 = 1 \iff -2x = -1 \iff x = \frac{1}{2}$$
:::

[IMAGE_3]

::: resultat
$f(x) = 1 \iff x \in \left\{-3\,;\frac{1}{2}\,;5\right\}$.
:::

## Question 4 : Résoudre $f(x) \ge 1$

::: methode
On cherche les abscisses des points de $\mathcal{C}_f$ situés sur ou au-dessus de la droite $y = 1$.
:::

::: etape Lecture morceau par morceau
- De $A$ jusqu’au point d’abscisse $\frac{1}{2}$, la courbe est au-dessus de $y = 1$ (ou dessus aux bornes) : $x \in \left[-3\,;\frac{1}{2}\right]$.
- Entre $\frac{1}{2}$ et $5$, la courbe est sous la droite, sauf au point $D$ où $f(5) = 1$ : on garde $x = 5$.
:::

[IMAGE_4]

::: resultat
$$S = \left[-3\,;\frac{1}{2}\right] \cup \{5\}$$
:::

::: attention
Ne pas oublier les points isolés : en $x = 5$, $f(5) = 1$ vérifie bien $f(x) \ge 1$.

## Question 5 : Résoudre $f(x) \le 0$

::: methode
On cherche les abscisses des points de $\mathcal{C}_f$ situés sur ou sous l’axe des abscisses.
:::

::: etape Lecture sur la figure
La courbe passe sous l’axe en $x = 1$ et revient sur l’axe en $x = 4$ ; partout ailleurs elle est au-dessus.
:::

[IMAGE_5]

::: resultat
$f(x) \le 0 \iff x \in [1\,;4]$.
:::

Solution:
<!-- optitab:1 -->
1. $f(-1) = 4$, $f(2) = -2$, $f(5) = 1$.
2. $x = 1$ ou $x = 4$.
3. $x \in \left\{-3\,;\frac{1}{2}\,;5\right\}$.
4. $x \in \left[-3\,;\frac{1}{2}\right] \cup \{5\}$.
5. $x \in [1\,;4]$.

=== Entraînement - Utiliser la parité pour compléter une table
Id: 2041
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Deux fonctions $f$ et $g$ sont définies sur $[-3\,;3]$ ; $f$ est **paire** et $g$ est **impaire**. On connaît les valeurs suivantes.

| $x$ | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|---|---|---|
| $f(x)$ | … | … | … | $1$ | $4$ | $7$ | $10$ |
| $g(x)$ | … | … | … | $0$ | $2$ | $5$ | $9$ |

1. Calculer $f(-1)$, $f(-2)$ et $f(-3)$.
2. Calculer $g(-1)$, $g(-2)$ et $g(-3)$.
3. Compléter la table.
4. Donner deux antécédents de $7$ par $f$.
5. Donner un antécédent de $-9$ par $g$.
6. Expliquer pourquoi on a forcément $g(0) = 0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $f(-1)$, $f(-2)$, $f(-3)$

::: methode
$f$ est paire : pour tout $x$ de $[-3\,;3]$, $f(-x) = f(x)$.
:::

::: etape Appliquer la parité
- $f(-1) = f(1) = 4$
- $f(-2) = f(2) = 7$
- $f(-3) = f(3) = 10$
:::

::: resultat
$f(-1) = 4$, $f(-2) = 7$ et $f(-3) = 10$.
:::

## Question 2 : Calculer $g(-1)$, $g(-2)$, $g(-3)$

::: methode
$g$ est impaire : pour tout $x$ de $[-3\,;3]$, $g(-x) = -g(x)$.
:::

::: etape Appliquer l’imparité
- $g(-1) = -g(1) = -2$
- $g(-2) = -g(2) = -5$
- $g(-3) = -g(3) = -9$
:::

::: resultat
$g(-1) = -2$, $g(-2) = -5$ et $g(-3) = -9$.
:::

::: attention
Pour une fonction impaire, on change le signe de l’image : $g(-2) = -5$, et non $5$.
:::

## Question 3 : Compléter la table

::: methode
On reporte les valeurs des questions 1 et 2.
:::

::: resultat
| $x$ | $-3$ | $-2$ | $-1$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|---|---|---|
| $f(x)$ | $10$ | $7$ | $4$ | $1$ | $4$ | $7$ | $10$ |
| $g(x)$ | $-9$ | $-5$ | $-2$ | $0$ | $2$ | $5$ | $9$ |
:::

[IMAGE_1]

Les points obtenus (en vert) sont les symétriques des points connus : par rapport à l’axe des ordonnées pour $f$, par rapport à l’origine pour $g$.

## Question 4 : Deux antécédents de $7$ par $f$

::: methode
Un antécédent de $7$ est un nombre $x$ tel que $f(x) = 7$.
:::

::: etape Lecture et parité
$f(2) = 7$, et par parité $f(-2) = f(2) = 7$.
:::

::: resultat
$-2$ et $2$ sont deux antécédents de $7$ par $f$.
:::

## Question 5 : Un antécédent de $-9$ par $g$

::: methode
On cherche $x$ tel que $g(x) = -9$ ; on connaît $g(3) = 9$.
:::

::: etape Utiliser l’imparité
$g(-3) = -g(3) = -9$.
:::

::: resultat
$-3$ est un antécédent de $-9$ par $g$.
:::

## Question 6 : Pourquoi $g(0) = 0$

::: methode
On applique la définition de l’imparité avec $x = 0$.
:::

::: etape Écrire l’égalité pour $x = 0$
$g(-0) = -g(0)$, soit $g(0) = -g(0)$, donc $2g(0) = 0$.
:::

::: resultat
$g(0) = 0$ : la courbe d’une fonction impaire définie en $0$ passe par l’origine.
:::

Solution:
<!-- optitab:1 -->
1. $f(-1) = 4$, $f(-2) = 7$, $f(-3) = 10$.
2. $g(-1) = -2$, $g(-2) = -5$, $g(-3) = -9$.
3. Ligne $f$ : $10$ ; $7$ ; $4$. Ligne $g$ : $-9$ ; $-5$ ; $-2$.
4. $-2$ et $2$.
5. $-3$.
6. $g(0) = -g(0)$, donc $g(0) = 0$.

=== Entraînement - Résoudre une inéquation produit avec un tableau de signes
Id: 2042
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère l’expression $P(x) = (x - 2)(x + 3)$, définie pour tout réel $x$.

1. Résoudre l’équation $P(x) = 0$.
2. Donner le signe de $x - 2$ selon les valeurs de $x$.
3. Donner le signe de $x + 3$ selon les valeurs de $x$.
4. Dresser le tableau de signes de $P(x)$, puis résoudre $P(x) \le 0$.
5. Résoudre $P(x) \gt 0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $(x - 2)(x + 3) = 0$

::: methode
Un produit est nul si et seulement si l’un au moins de ses facteurs est nul.
:::

::: etape Annuler chaque facteur
- $x - 2 = 0 \iff x = 2$
- $x + 3 = 0 \iff x = -3$
:::

::: resultat
$P(x) = 0 \iff x = -3$ ou $x = 2$.
:::

## Question 2 : Signe de $x - 2$

::: methode
Résoudre l’inéquation $x - 2 \gt 0$ donne directement le signe.
:::

::: etape Résolution
$x - 2 \gt 0 \iff x \gt 2$ ; de même $x - 2 \lt 0 \iff x \lt 2$.
:::

::: resultat
$x - 2$ est négatif sur ${]-\infty\,;2[}$, nul en $2$, positif sur ${]2\,;+\infty[}$.
:::

## Question 3 : Signe de $x + 3$

::: methode
Même méthode : $x + 3 \gt 0 \iff x \gt -3$.
:::

::: resultat
$x + 3$ est négatif sur ${]-\infty\,;-3[}$, nul en $-3$, positif sur ${]-3\,;+\infty[}$.
:::

## Question 4 : Tableau de signes et $P(x) \le 0$

::: methode
On range les valeurs d’annulation dans l’ordre croissant ($-3$ puis $2$), on reporte le signe de chaque facteur, puis on applique la règle des signes colonne par colonne.
:::

::: etape Tableau de signes
Ligne de $P(x)$ : deux facteurs de même signe donnent « $+$ », deux facteurs de signes contraires donnent « $-$ ».
:::

::: tableau
x : -\infty, -3, 2, +\infty
x+3 : , -, z, +, t, +,
x-2 : , -, t, -, z, +,
P(x) : , +, z, -, z, +,
:::

::: etape Lire les solutions
$P(x) \le 0$ : on garde la colonne « $-$ » et les deux valeurs où $P(x) = 0$ (inégalité large).
:::

[IMAGE_1]

::: resultat
$P(x) \le 0 \iff x \in [-3\,;2]$.
:::

## Question 5 : Résoudre $P(x) \gt 0$

::: methode
On garde les colonnes « $+$ », sans les valeurs d’annulation (inégalité stricte).
:::

[IMAGE_2]

::: resultat
$$S = {]-\infty\,;-3[} \cup {]2\,;+\infty[}$$
:::

::: attention
Inégalité stricte : crochets ouverts en $-3$ et $2$, car $P(-3) = P(2) = 0$ n’est pas strictement positif.
:::

Solution:
<!-- optitab:1 -->
1. $x = -3$ ou $x = 2$.
2. Négatif sur ${]-\infty\,;2[}$, nul en $2$, positif sur ${]2\,;+\infty[}$.
3. Négatif sur ${]-\infty\,;-3[}$, nul en $-3$, positif sur ${]-3\,;+\infty[}$.
4. $S = [-3\,;2]$.
5. $S = {]-\infty\,;-3[} \cup {]2\,;+\infty[}$.

=== Entraînement - Résoudre une inéquation quotient avec un tableau de signes
Id: 2043
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère l’expression $Q(x) = \dfrac{2x - 3}{x + 1}$.

1. Pour quelles valeurs de $x$ l’expression $Q(x)$ est-elle définie ?
2. Résoudre l’équation $Q(x) = 0$.
3. Étudier le signe de $2x - 3$ et celui de $x + 1$.
4. Dresser le tableau de signes de $Q(x)$, puis résoudre $Q(x) \ge 0$.
5. Résoudre $Q(x) \lt 0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Valeur interdite

::: methode
Un quotient n’est défini que si son dénominateur est non nul.
:::

::: etape Annulation du dénominateur
$x + 1 = 0 \iff x = -1$.
:::

::: resultat
$Q(x)$ est définie pour $x \in \mathbb{R} \setminus \{-1\}$ : $-1$ est la **valeur interdite**.
:::

## Question 2 : Résoudre $Q(x) = 0$

::: methode
Un quotient est nul si et seulement si son numérateur est nul (et son dénominateur non nul).
:::

::: etape Annuler le numérateur
$$2x - 3 = 0 \iff 2x = 3 \iff x = \frac{3}{2}$$
:::

::: etape Vérifier que la valeur est autorisée
$\frac{3}{2} \neq -1$ : la valeur est autorisée.
:::

::: resultat
$Q(x) = 0 \iff x = \frac{3}{2}$.
:::

## Question 3 : Signe de chaque facteur

::: methode
Une expression $ax + b$ (avec $a \neq 0$) a le signe de $a$ à droite de sa valeur d’annulation, le signe contraire à gauche.
:::

::: etape Signe de $2x - 3$
$a = 2 \gt 0$ : $2x - 3$ est négatif pour $x \lt \frac{3}{2}$, nul en $\frac{3}{2}$, positif pour $x \gt \frac{3}{2}$.
:::

::: etape Signe de $x + 1$
$a = 1 \gt 0$ : $x + 1$ est négatif pour $x \lt -1$, nul en $-1$, positif pour $x \gt -1$.
:::

::: resultat
$2x - 3$ change de signe en $\frac{3}{2}$ et $x + 1$ en $-1$ ; tous deux passent de « $-$ » à « $+$ ».
:::

## Question 4 : Tableau de signes et $Q(x) \ge 0$

::: methode
Même règle des signes que pour un produit ; la valeur interdite $-1$ est marquée d’une double barre.
:::

::: etape Tableau de signes
Valeurs rangées dans l’ordre croissant : $-1 \lt \frac{3}{2}$. Double barre en $-1$ sur la ligne de $Q(x)$.
:::

::: tableau
x : -\infty, -1, \frac{3}{2}, +\infty
2x-3 : , -, t, -, z, +,
x+1 : , -, z, +, t, +,
Q(x) : , +, d, -, z, +,
:::

::: etape Lire les solutions
On garde les colonnes « $+$ » et la valeur $\frac{3}{2}$ (où $Q(x) = 0$), mais **jamais** $-1$ (valeur interdite).
:::

[IMAGE_1]

::: resultat
$$S = {]-\infty\,;-1[} \cup \left[\frac{3}{2}\,;+\infty\right[$$
:::

::: attention
Même si l’inégalité est large, le crochet est ouvert en $-1$ : $Q(-1)$ n’existe pas.
:::

## Question 5 : Résoudre $Q(x) \lt 0$

::: methode
On garde la colonne « $-$ », sans les bornes : en $-1$ le quotient n’existe pas, en $\frac{3}{2}$ il est nul.
:::

[IMAGE_2]

::: resultat
$$S = \left]-1\,;\frac{3}{2}\right[$$
:::

Solution:
<!-- optitab:1 -->
1. $\mathbb{R} \setminus \{-1\}$.
2. $x = \frac{3}{2}$.
3. $2x - 3$ : $-$ puis $+$ (change en $\frac{3}{2}$) ; $x + 1$ : $-$ puis $+$ (change en $-1$).
4. $S = {]-\infty\,;-1[} \cup \left[\frac{3}{2}\,;+\infty\right[$.
5. $S = \left]-1\,;\frac{3}{2}\right[$.

=== Problème - Comparer deux tarifs de taxi
Id: 2044
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une compagnie de taxis propose deux tarifs pour une course de $x$ kilomètres ($x \ge 0$).

- Tarif A : prise en charge de $3$ €, puis $2$ € par kilomètre. On note $f(x)$ le prix en euros.
- Tarif B : prise en charge de $8$ €, puis $1$ € par kilomètre. On note $g(x)$ le prix en euros.

1. Exprimer $f(x)$ et $g(x)$ en fonction de $x$, et préciser l’ensemble de définition.
2. Calculer $f(4)$ et $g(4)$. Quel tarif est le moins cher pour $4$ km ?
3. Résoudre $f(x) = g(x)$ et interpréter le résultat.
4. Résoudre l’inéquation $f(x) \le g(x)$ et interpréter le résultat.
5. Quel tarif choisir pour une course de $20$ km ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Expressions et ensemble de définition

::: methode
Un prix « fixe + prix par kilomètre $\times$ nombre de kilomètres » se modélise par une fonction affine.
:::

::: etape Tarif A
$3$ € fixes et $2$ € par kilomètre : $f(x) = 2x + 3$.
:::

::: etape Tarif B
$8$ € fixes et $1$ € par kilomètre : $g(x) = x + 8$.
:::

::: etape Ensemble de définition
$x$ est une distance : $x \ge 0$.
:::

[IMAGE_1]

::: resultat
$f(x) = 2x + 3$ et $g(x) = x + 8$, définies sur $[0\,;+\infty[$.
:::

## Question 2 : Comparer pour $4$ km

::: methode
On calcule les deux prix puis on les compare.
:::

::: etape Calculs
- $f(4) = 2 \times 4 + 3 = 11$
- $g(4) = 4 + 8 = 12$
:::

::: resultat
Pour $4$ km, le tarif A est le moins cher : $11$ € contre $12$ €.
:::

## Question 3 : Résoudre $f(x) = g(x)$

::: methode
On résout une équation du premier degré : les termes en $x$ d’un côté, les nombres de l’autre.
:::

::: etape Résolution
$$
\begin{aligned}
f(x) = g(x) &\iff 2x + 3 = x + 8 \\
&\iff 2x - x = 8 - 3 \\
&\iff x = 5
\end{aligned}
$$
:::

::: etape Prix commun
$f(5) = 2 \times 5 + 3 = 13$ et $g(5) = 5 + 8 = 13$.
:::

[IMAGE_2]

::: resultat
Pour $5$ km, les deux tarifs coûtent le même prix, $13$ € : les droites se coupent au point $(5\,;13)$.
:::

## Question 4 : Résoudre $f(x) \le g(x)$

::: methode
On résout l’inéquation comme l’équation, puis on tient compte de l’ensemble de définition.
:::

::: etape Résolution
$$
\begin{aligned}
f(x) \le g(x) &\iff 2x + 3 \le x + 8 \\
&\iff x \le 5
\end{aligned}
$$
:::

::: etape Tenir compte de $x \ge 0$
On obtient $x \in [0\,;5]$ : sur cet intervalle, la droite du tarif A est sous celle du tarif B.
:::

[IMAGE_3]

::: resultat
Le tarif A est le moins cher (ou au même prix) pour une course de $0$ à $5$ km.
:::

## Question 5 : Course de $20$ km

::: methode
$20 \gt 5$ : d’après la question 4, le tarif B est alors le moins cher ; on le confirme par le calcul.
:::

::: etape Calculs
- $f(20) = 2 \times 20 + 3 = 43$
- $g(20) = 20 + 8 = 28$
:::

[IMAGE_4]

::: resultat
Pour $20$ km, on choisit le tarif B : $28$ € au lieu de $43$ €, soit $15$ € d’économie.
:::

Solution:
<!-- optitab:1 -->
1. $f(x) = 2x + 3$, $g(x) = x + 8$, sur $[0\,;+\infty[$.
2. $f(4) = 11$ et $g(4) = 12$ : tarif A.
3. $x = 5$ : même prix ($13$ €) pour $5$ km.
4. $x \in [0\,;5]$ : tarif A jusqu’à $5$ km.
5. Tarif B ($28$ € contre $43$ €).

=== Entraînement - Résoudre graphiquement f(x) = k et f(x) < k sur une courbe
Id: 3748
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une fonction $f$, définie sur $[-2\,;2]$, est représentée par la courbe $\mathcal{C}_f$ ci-dessous.

[IMAGE_1]

1. Lire $f(-2)$, $f(0)$ et $f(1)$.
2. Résoudre graphiquement $f(x) = 1$, puis $f(x) = -1$.
3. L’équation $f(x) = 2$ a-t-elle des solutions ?
4. Résoudre graphiquement l’inéquation $f(x) \lt 1$.
5. On admet que $f(x) = \dfrac{x^3 - 3x}{2}$. Résoudre par le calcul l’équation $f(x) = 0$.
6. En déduire l’ensemble des solutions de $f(x) \gt 0$, à l’aide de la courbe.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire des images

::: methode
On part de l’abscisse sur l’axe horizontal, on rejoint la courbe, puis on lit l’ordonnée.
:::

::: etape Lecture
- Le point de $\mathcal{C}_f$ d’abscisse $-2$ a pour ordonnée $-1$.
- La courbe passe par l’origine.
- Le point d’abscisse $1$ a pour ordonnée $-1$.
:::

::: resultat
$f(-2) = -1$, $f(0) = 0$ et $f(1) = -1$.
:::

## Question 2 : Résoudre $f(x) = 1$ et $f(x) = -1$

::: methode
On trace la droite horizontale $y = k$ et on lit les **abscisses** des points d’intersection avec $\mathcal{C}_f$.
:::

::: etape Droite $y = 1$
Elle touche la courbe en deux points, d’abscisses $-1$ et $2$.
:::

::: etape Droite $y = -1$
Elle touche la courbe en deux points, d’abscisses $-2$ et $1$.
:::

[IMAGE_2]

::: resultat
- $f(x) = 1 \iff x = -1$ ou $x = 2$ ;
- $f(x) = -1 \iff x = -2$ ou $x = 1$.
:::

## Question 3 : L’équation $f(x) = 2$

::: methode
On regarde si la droite $y = 2$ rencontre la courbe.
:::

::: etape Lecture
Sur $[-2\,;2]$, toutes les ordonnées des points de $\mathcal{C}_f$ sont comprises entre $-1$ et $1$ : la droite $y = 2$ est entièrement au-dessus de la courbe.
:::

::: resultat
L’équation $f(x) = 2$ n’a **aucune** solution : $S = \varnothing$.
:::

## Question 4 : Résoudre $f(x) \lt 1$

::: methode
On cherche les abscisses des points de $\mathcal{C}_f$ situés **strictement sous** la droite $y = 1$.
:::

::: etape Lecture
La courbe est sous la droite $y = 1$ sur tout l’intervalle, sauf en deux points où elle la touche : $x = -1$ et $x = 2$. Ces deux valeurs sont exclues car $f(x) = 1$ n’est pas strictement inférieur à $1$.
:::

[IMAGE_3]

::: resultat
$$S = {[-2\,;-1[} \cup {]-1\,;2[}$$
:::

::: attention
En $x = -1$, la courbe touche la droite sans la traverser : il faut quand même exclure $-1$, d’où la réunion de deux intervalles.
:::

## Question 5 : Résoudre $f(x) = 0$ par le calcul

::: methode
On factorise $x^3 - 3x$ par $x$, puis on utilise la règle du produit nul.
:::

::: etape Se ramener au numérateur
$$f(x) = 0 \iff \frac{x^3 - 3x}{2} = 0 \iff x^3 - 3x = 0$$
:::

::: etape Factoriser
$$x^3 - 3x = x(x^2 - 3) = x\left(x - \sqrt{3}\right)\left(x + \sqrt{3}\right)$$
:::

::: etape Produit nul
$x = 0$ ou $x = \sqrt{3}$ ou $x = -\sqrt{3}$ ; ces trois valeurs sont dans $[-2\,;2]$ car $\sqrt{3} \approx 1{,}73$.
:::

::: resultat
$$S = \left\{-\sqrt{3}\,;0\,;\sqrt{3}\right\}$$

La courbe coupe l’axe des abscisses en ces trois points.
:::

::: remarque
Sur la figure, on lit environ $-1{,}7$ et $1{,}7$ : seul le calcul donne les valeurs exactes $\pm\sqrt{3}$.
:::

## Question 6 : Résoudre $f(x) \gt 0$

::: methode
On cherche les abscisses des points de $\mathcal{C}_f$ strictement au-dessus de l’axe des abscisses, en utilisant les valeurs exactes de la question 5.
:::

::: etape Lecture
- Entre $-\sqrt{3}$ et $0$, la courbe est au-dessus de l’axe.
- Entre $\sqrt{3}$ et $2$, elle est aussi au-dessus de l’axe ; $2$ est compris car $f(2) = 1 \gt 0$.
- Sur $\left[-2\,;-\sqrt{3}\right]$ et sur $\left[0\,;\sqrt{3}\right]$, elle est sous l’axe ou le touche : ces valeurs sont exclues.
:::

[IMAGE_4]

::: resultat
$$S = \left]-\sqrt{3}\,;0\right[ \cup \left]\sqrt{3}\,;2\right]$$
:::

Solution:
<!-- optitab:1 -->
1. $f(-2) = -1$, $f(0) = 0$, $f(1) = -1$.
2. $f(x) = 1 \iff x \in \{-1\,;2\}$ ; $f(x) = -1 \iff x \in \{-2\,;1\}$.
3. Non : $S = \varnothing$.
4. $x \in {[-2\,;-1[} \cup {]-1\,;2[}$.
5. $x \in \left\{-\sqrt{3}\,;0\,;\sqrt{3}\right\}$.
6. $x \in \left]-\sqrt{3}\,;0\right[ \cup \left]\sqrt{3}\,;2\right]$.

===

=== Problème - Enclos rectangulaire d’aire au moins 21 m²
Id: 3749
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Avec une clôture de $20$ m, on construit un enclos rectangulaire. On note $x$ la longueur d’un côté, en mètres ($0 \lt x \lt 10$), et $A(x)$ l’aire de l’enclos, en m².

[IMAGE_1]

1. Justifier que l’autre côté mesure $10 - x$, puis que $A(x) = x(10 - x)$.
2. Calculer $A(2)$ et $A(4)$.
3. La courbe de $A$ est tracée ci-dessous. Résoudre graphiquement $A(x) = 21$, puis $A(x) \ge 21$.

[IMAGE_2]

4. Démontrer que, pour tout réel $x$, $A(x) - 21 = (x - 3)(7 - x)$.
5. Résoudre $A(x) \ge 21$ par le calcul, à l’aide d’un tableau de signes.
6. Conclure : quelles longueurs de côté permettent d’obtenir un enclos d’au moins $21$ m² ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Expression de l’aire

::: methode
Le périmètre d’un rectangle de côtés $x$ et $\ell$ vaut $2x + 2\ell$.
:::

::: etape Autre côté
$$
\begin{aligned}
2x + 2\ell = 20 &\iff x + \ell = 10 \\
&\iff \ell = 10 - x
\end{aligned}
$$
:::

::: etape Aire
Aire d’un rectangle : longueur $\times$ largeur, donc $A(x) = x(10 - x)$.
:::

::: resultat
L’autre côté mesure $10 - x$ et $A(x) = x(10 - x)$ pour $x \in {]0\,;10[}$.
:::

## Question 2 : Calculer $A(2)$ et $A(4)$

::: methode
On remplace $x$ par la valeur dans $A(x) = x(10 - x)$.
:::

::: etape Calculs
- $A(2) = 2 \times (10 - 2) = 2 \times 8 = 16$
- $A(4) = 4 \times (10 - 4) = 4 \times 6 = 24$
:::

::: resultat
$A(2) = 16$ m² et $A(4) = 24$ m².
:::

## Question 3 : Résolution graphique

::: methode
On trace la droite horizontale $y = 21$ : les solutions sont des abscisses, lues sur l’axe horizontal.
:::

::: etape Équation $A(x) = 21$
La droite $y = 21$ coupe la courbe en deux points, d’abscisses $3$ et $7$.
:::

::: etape Inéquation $A(x) \ge 21$
La courbe est au-dessus de la droite (ou la touche) entre ces deux abscisses, bornes comprises.
:::

[IMAGE_3]

::: resultat
Graphiquement :

- $A(x) = 21 \iff x = 3$ ou $x = 7$ ;
- $A(x) \ge 21 \iff x \in [3\,;7]$.
:::

## Question 4 : Factorisation de $A(x) - 21$

::: methode
On développe le membre de droite et on compare avec $A(x) - 21$ développé.
:::

::: etape Développer $(x - 3)(7 - x)$
$$
\begin{aligned}
(x - 3)(7 - x) &= 7x - x^2 - 21 + 3x \\
&= -x^2 + 10x - 21
\end{aligned}
$$
:::

::: etape Développer $A(x) - 21$
$$
\begin{aligned}
A(x) - 21 &= 10x - x^2 - 21 \\
&= -x^2 + 10x - 21
\end{aligned}
$$
:::

::: resultat
Pour tout réel $x$, $A(x) - 21 = (x - 3)(7 - x)$.
:::

## Question 5 : Résolution par le calcul

::: methode
$A(x) \ge 21$ équivaut à $A(x) - 21 \ge 0$, soit $(x - 3)(7 - x) \ge 0$ : on étudie le signe de ce produit sur ${]0\,;10[}$.
:::

::: etape Signe de chaque facteur
- $x - 3$ : coefficient $1 \gt 0$, négatif avant $3$, positif après.
- $7 - x$ : coefficient $-1 \lt 0$, **positif** avant $7$, négatif après.
:::

::: etape Tableau de signes sur ${]0\,;10[}$

::: tableau
x : 0, 3, 7, 10
x-3 : , -, z, +, t, +,
7-x : , +, t, +, z, -,
Produit : , -, z, +, z, -,
:::
:::

::: resultat
$A(x) \ge 21 \iff x \in [3\,;7]$ : le calcul confirme la lecture graphique.
:::

::: attention
Le facteur $7 - x$ a un coefficient de $x$ négatif : il est positif **à gauche** de $7$. C’est l’erreur la plus fréquente dans ce type de tableau.
:::

## Question 6 : Conclusion

::: methode
On traduit l’ensemble des solutions dans le contexte de l’enclos.
:::

::: resultat
L’aire est d’au moins $21$ m² lorsque le côté $x$ mesure entre $3$ m et $7$ m (l’autre côté mesure alors entre $7$ m et $3$ m).
:::

Solution:
<!-- optitab:1 -->
1. $2x + 2\ell = 20$ donne $\ell = 10 - x$, et $A(x) = x(10 - x)$.
2. $A(2) = 16$ et $A(4) = 24$.
3. $A(x) = 21 \iff x \in \{3\,;7\}$ ; $A(x) \ge 21 \iff x \in [3\,;7]$.
4. $(x - 3)(7 - x) = -x^2 + 10x - 21 = A(x) - 21$.
5. $S = [3\,;7]$.
6. Côté compris entre $3$ m et $7$ m.
