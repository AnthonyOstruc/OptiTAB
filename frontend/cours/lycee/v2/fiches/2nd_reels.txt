<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les ensembles de nombres</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Décimal : $\frac{k}{10^n}$, écriture finie ; rationnel : $\frac{p}{q}$, écriture finie ou périodique.</p>
<p style="margin:6px 0 0 0;">• Irrationnel : ni fraction, ni écriture périodique ($\sqrt{2}$, $\pi$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Intervalles et distances</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $x \in [a\,;b] \iff a \le x \le b$ ; $x \in [a\,;+\infty[ \iff x \ge a$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $|x|$ = distance de $x$ à $0$ ; distance entre $a$ et $b$ : $|b - a|$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $|x - a| \le r \iff x \in [a - r\,;a + r]$ : $|x - 3| \le 2 \iff x \in [1\,;5]$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Encadrement à $10^{-n}$ près : $a \le x \le b$ avec $b - a = 10^{-n}$, comme $1{,}41 \le \sqrt{2} \le 1{,}42$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Fermer le crochet du côté de l’infini : on écrit $[2\,;+\infty[$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier qu’un crochet ouvert exclut la borne : $5 \notin [2\,;5[$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Écrire une valeur absolue négative : $|-7| = 7$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire qu’un nombre est irrationnel parce que la calculatrice affiche beaucoup de décimales : $\frac{1}{7}$ est rationnel.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> une inégalité → je la dessine sur la droite graduée puis je l’écris en intervalle ; « $|x - a| \le r$ » → je lis « $x$ est à une distance au plus $r$ de $a$ ».</p>
</div>
