Titre: Le repérage dans l’espace : positions et déplacements
<!-- optitab:1 -->
::: objectifs
Je décris une position et je suis des instructions.
:::

## I. J’observe et je manipule

::: methode Avec le matériel
Cache un objet dans la classe. Donne un indice avec « sous », « sur », « entre » ou « à gauche de ». Puis fais un petit trajet.
:::

[IMAGE_1]

## II. Je comprends

::: definition Les repères
Je précise par rapport à quoi je situe l’objet.

Sur le plan, je repère la porte, les tables et le tableau.

Avancer dépend du sens dans lequel le personnage regarde.
:::

## III. Je fais pas à pas

::: methode
1. Je repère le départ et le sens du regard.
2. J’exécute une instruction à la fois.
3. Tourner change le regard, sur place. Avancer déplace le pion.
4. Je vérifie la place d’arrivée et le sens du regard.
:::
::: exemple
Le pion regarde vers le haut. Il avance de deux cases, tourne à droite, puis avance d’une case.
:::

## IV. À toi de jouer

::: exemple
Mets un crayon à droite de ton cahier, puis sous le cahier.
:::
::: resultat Je vérifie
Vérifier les positions avec l’enfant et le repère choisi.
:::
::: attention
La droite du pion dépend de son regard. Tourner à droite ne signifie pas avancer vers la droite du dessin.
:::
::: retenir
Tourner : changer de direction sur place.

Avancer : se déplacer dans le sens du regard.

Reculer : aller dans le sens opposé, sans se retourner.
:::
