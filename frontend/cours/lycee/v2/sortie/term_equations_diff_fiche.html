📚 Objectif pédagogique : retenir l’essentiel : solutions de $\displaystyle y' = ay$, $\displaystyle y' = ay + b$, $\displaystyle y' = ay + f$ et condition initiale. Programme de Terminale.

I. Résoudre

$\displaystyle y' = ay + b$ : $\displaystyle y = Ce^{ax} - \frac{b}{a}$

[IMAGE_1]

1️⃣ $\displaystyle y' = ay$ : $\displaystyle y = Ce^{ax}$.

2️⃣ $\displaystyle y' = ay + f$ : $\displaystyle y = y_p + Ce^{ax}$ avec $\displaystyle y_p$ solution particulière.

3️⃣ Condition $\displaystyle y(x_0) = y_0$ → une seule valeur de $\displaystyle C$.

II. Modéliser

[IMAGE_2]

1️⃣ « Variation proportionnelle à la quantité » → $\displaystyle y' = ay$.

2️⃣ « Variation proportionnelle à l’écart avec une valeur $\displaystyle L$ » → $\displaystyle y' = a(y - L)$, solution constante $\displaystyle L$.

3️⃣ Si $\displaystyle a \lt 0$, les solutions tendent vers la solution constante.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Écrire $\displaystyle y = Ce^{ax} + \frac{b}{a}$ : c’est $\displaystyle -\frac{b}{a}$.

2️⃣ Utiliser la condition initiale avant d’avoir la solution complète.

3️⃣ Oublier la constante $\displaystyle C$ (il y a une infinité de solutions).

4️⃣ Mal identifier $\displaystyle a$ et $\displaystyle b$ : $\displaystyle T' = -0{,}1(T - 20)$ donne $\displaystyle a = -0{,}1$ et $\displaystyle b = 2$.

🏆 Réflexe : je mets l’équation sous la forme $\displaystyle y' = ay + b$, je cherche la solution constante, puis j’ajoute $\displaystyle Ce^{ax}$ et j’utilise la condition initiale.
