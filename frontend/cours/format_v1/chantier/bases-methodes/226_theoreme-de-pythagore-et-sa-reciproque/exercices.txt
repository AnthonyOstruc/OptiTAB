=== Application - Problème - Échelle contre un mur
Id: 2077
Difficulté: medium
Image: pythagore_echelle_5_12_13.png

Énoncé:
<!-- optitab:1 -->
Une échelle de longueur $13$ m est posée contre un mur vertical. Le pied de l'échelle est à $5$ m du mur.

On note $\displaystyle h$ la hauteur atteinte sur le mur.

1. Expliquer pourquoi on peut utiliser le théorème de Pythagore.
2. Calculer la hauteur $\displaystyle h$.
3. Une fenêtre est à $\displaystyle 11$ m du sol. L'échelle atteint-elle la fenêtre ?
4. Avec la même échelle (13 m), quelle est la distance maximale au mur si on veut atteindre $10$ m de hauteur ?

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Justification

::: remarque
Le mur est vertical et le sol est horizontal, donc ils sont perpendiculaires.
:::

::: resultat
Le triangle formé est rectangle : on peut appliquer Pythagore.
:::

## Question 2 : Calculer $\displaystyle h$

::: methode
Dans le triangle rectangle, l'échelle est l'hypoténuse.
:::

::: etape $\displaystyle 13^2=5^2+h^2$
:::

::: etape $\displaystyle h^2=13^2-5^2=169-25=144$
:::

::: etape $\displaystyle h=\sqrt{144}=12$
:::

::: resultat
$$h=12\ \text{m}$$
:::

## Question 3 : Atteindre la fenêtre

::: point Comparaison
$h=12$ m et la fenêtre est à $11$ m.
:::

::: resultat
$h=12$ m $\ge 11$ m, donc l'échelle dépasse la hauteur de la fenêtre : oui, elle l'atteint.
:::

## Question 4 : Distance maximale pour atteindre 10 m

::: methode
Pythagore avec hauteur $\displaystyle 10$ m.
:::

::: etape $\displaystyle 13^2=d^2+10^2$
:::

::: etape $\displaystyle d^2=169-100=69$
:::

::: etape $\displaystyle d=\sqrt{69}\approx 8{,}3$
:::

::: resultat
$\displaystyle d\approx 8{,}3\ \text{m}$ (au dixième près)
:::

Solution:
<!-- optitab:1 -->
1. Sol $\perp$ mur $\Rightarrow$ triangle rectangle
2. $\displaystyle h=12\ \text{m}$
3. Oui
4. $\displaystyle d=\sqrt{69}\ \text{m}\approx 8{,}3\ \text{m}$

=== Application - Repère - Distances et triangle rectangle
Id: 2078
Difficulté: medium
Image: pythagore_repere_distance_ABC.png

Énoncé:
<!-- optitab:1 -->
Dans un repère orthonormé $\displaystyle (O;I;J)$, on considère les points $\displaystyle A(2\,;\,-1)$, $\displaystyle B(8\,;\,3)$ et $\displaystyle C(2\,;\,3)$.

1. Calculer les longueurs $\displaystyle AC$ et $\displaystyle BC$.
2. En utilisant Pythagore, calculer la longueur $\displaystyle AB$ (valeur exacte).
3. Donner une valeur approchée de $\displaystyle AB$ au centième près.
4. Vérifier que le triangle $\displaystyle ABC$ est rectangle en $\displaystyle C$.

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Calculer $\displaystyle AC$ et $\displaystyle BC$

::: methode
Dans un repère orthonormé :

- Si deux points ont la même abscisse, la distance est la différence d'ordonnées.
- Si deux points ont la même ordonnée, la distance est la différence d'abscisses.
:::

::: point Calcul
- $\displaystyle AC=|3-(-1)|=4$
- $\displaystyle BC=|8-2|=6$
:::

::: resultat
$AC=4$ et $BC=6$
:::

## Question 2 : Calculer $\displaystyle AB$ (exact)

::: methode
Le triangle $ABC$ a un angle droit en $C$ (segments vertical et horizontal), donc :

- $\displaystyle AB^2=AC^2+BC^2$
:::

::: etape $\displaystyle AB^2=4^2+6^2=16+36=52$
:::

::: etape $\displaystyle AB=\sqrt{52}=\sqrt{4\times 13}=2\sqrt{13}$
:::

::: resultat
$$AB=2\sqrt{13}$$
:::

## Question 3 : Valeur approchée

::: point Calcul
$$2\sqrt{13}\approx 7{,}21$$
:::

::: resultat
$$AB\approx 7{,}21$$
:::

## Question 4 : Vérifier que le triangle est rectangle en $\displaystyle C$

::: methode
Segments $[AC]$ vertical et $[BC]$ horizontal $\Rightarrow$ perpendiculaires.
:::

::: methode 2 (réciproque)
$AB^2=52$ et $AC^2+BC^2=16+36=52$ donc $AB^2=AC^2+BC^2$.
:::

::: resultat
Le triangle $ABC$ est rectangle en $C$.
:::

Solution:
<!-- optitab:1 -->
1. $AC=4$ et $BC=6$
2. $\displaystyle AB=2\sqrt{13}$
3. $\displaystyle AB\approx 7{,}21$
4. Triangle rectangle en $\displaystyle C$

=== Approfondissement - Triangle isocèle - Hauteur, aire et Pythagore
Id: 2082
Difficulté: medium
Image: pythagore_triangle_isocele_10_10_12.png

Énoncé:
<!-- optitab:1 -->
Dans le triangle $\displaystyle ABC$ isocèle en $\displaystyle A$, on donne $\displaystyle AB=AC=10$ cm et $\displaystyle BC=12$ cm.

On note $\displaystyle H$ le pied de la hauteur issue de $\displaystyle A$ sur $\displaystyle (BC)$.

1. Justifier que $\displaystyle H$ est le milieu de $\displaystyle [BC]$ puis calculer $\displaystyle BH$.
2. Calculer la longueur $\displaystyle AH$.
3. Calculer l’aire du triangle $\displaystyle ABC$.
4. Calculer le périmètre du triangle $\displaystyle ABC$.

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Milieu de $\displaystyle [BC]$

::: rappel Propriété
Dans un triangle isocèle, la hauteur issue du sommet principal est aussi une médiane.
:::

::: resultat
$H$ est le milieu de $[BC]$.
:::

::: point Calcul
$$BH=\dfrac{BC}{2}=\dfrac{12}{2}=6$$
:::

::: resultat
$$BH=6\ \text{cm}$$
:::

## Question 2 : Calculer $\displaystyle AH$

::: methode
Pythagore dans le triangle $ABH$ rectangle en $H$.
:::

::: etape $\displaystyle AB^2=AH^2+BH^2$
:::

::: etape $\displaystyle AH^2=AB^2-BH^2=10^2-6^2=100-36=64$
:::

::: etape $\displaystyle AH=\sqrt{64}=8$
:::

::: resultat
$$AH=8\ \text{cm}$$
:::

## Question 3 : Aire du triangle

::: methode
$\mathcal{A}=\dfrac{\text{base}\times\text{hauteur}}{2}$ avec base $BC$ et hauteur $AH$.
:::

::: point Calcul
$$\mathcal{A}=\dfrac{12\times 8}{2}=48$$
:::

::: resultat
$$\mathcal{A}=48\ \text{cm}^2$$
:::

## Question 4 : Périmètre

::: point Calcul
$$P=AB+AC+BC=10+10+12=32$$
:::

::: resultat
$$P=32\ \text{cm}$$
:::

Solution:
<!-- optitab:1 -->
1. $H$ milieu $\Rightarrow BH=6\ \text{cm}$
2. $\displaystyle AH=8\ \text{cm}$
3. $\displaystyle \mathcal{A}=48\ \text{cm}^2$
4. $\displaystyle P=32\ \text{cm}$

=== Bonus - Loi d'Al-Kashi - Pythagore généralisé
Id: 2081
Difficulté: hard
Image: alkashi_triangle_6_8_60.png

Énoncé:
<!-- optitab:1 -->
Dans le triangle $\displaystyle ABC$, on donne $\displaystyle AB=6$ cm, $\displaystyle AC=8$ cm et $\displaystyle \widehat{BAC}=60^\circ$.

1. Écrire la formule d'Al-Kashi permettant de calculer $\displaystyle BC^2$.
2. Calculer la longueur $BC$ (valeur exacte puis valeur approchée au centième près).
3. Vérifier que si $\displaystyle \widehat{BAC}=90^\circ$, on retrouve le théorème de Pythagore (donner $\displaystyle BC$ dans ce cas).

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Formule d'Al-Kashi

::: rappel
$BC$ est le côté opposé à l'angle $\widehat{BAC}$ (côté en face du sommet $A$).
:::

::: rappel Formule
$$BC^2=AB^2+AC^2-2\times AB\times AC\times \cos(\widehat{BAC})$$
:::

## Question 2 : Calculer $\displaystyle BC$

::: methode
Appliquer la formule avec $\displaystyle \cos(60^\circ)=\dfrac{1}{2}$.
:::

::: etape $\displaystyle BC^2=6^2+8^2-2\times 6\times 8\times \cos(60^\circ)$
:::

::: etape $\displaystyle BC^2=36+64-96\times \dfrac{1}{2}=100-48=52$
:::

::: etape $\displaystyle BC=\sqrt{52}=\sqrt{4\times 13}=2\sqrt{13}$
:::

::: point Valeur approchée
$$2\sqrt{13}\approx 7{,}21$$
:::

::: resultat
$$BC=2\sqrt{13}\ \text{cm}\approx 7{,}21\ \text{cm}$$
:::

## Question 3 : Cas particulier $\displaystyle 90^\circ$ (Pythagore)

::: remarque
$\displaystyle \cos(90^\circ)=0$.
:::

::: point Calcul
$$BC^2=6^2+8^2-2\times 6\times 8\times 0=36+64=100$$
:::

::: resultat
$\displaystyle BC=\sqrt{100}=10$ (on retrouve Pythagore).
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle BC^2=AB^2+AC^2-2\times AB\times AC\times \cos(\widehat{BAC})$
2. $\displaystyle BC=2\sqrt{13}\ \text{cm}\approx 7{,}21\ \text{cm}$
3. Si $\widehat{BAC}=90^\circ$, alors $BC=10\ \text{cm}$

=== Challenge - Repère - Point variable et condition d'angle droit
Id: 2085
Difficulté: hard
Image: pythagore_repere_point_variable.png

Énoncé:
<!-- optitab:1 -->
Dans un repère orthonormé, on considère $\displaystyle A(0\,;\,0)$ et $\displaystyle B(10\,;\,0)$.

Le point $\displaystyle C$ est sur la droite d’équation $\displaystyle y=3$, donc $\displaystyle C(x\,;\,3)$ avec $\displaystyle x$ un réel.

1. Exprimer $\displaystyle AC^2$ et $\displaystyle BC^2$ en fonction de $\displaystyle x$.
2. Déterminer les valeurs de $\displaystyle x$ pour que le triangle $\displaystyle ABC$ soit rectangle en $\displaystyle C$.
3. Donner les coordonnées possibles de $\displaystyle C$.
4. Calculer l’aire du triangle $\displaystyle ABC$ pour ces positions de $\displaystyle C$.

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Écrire les distances au carré

::: methode
$\displaystyle XY^2=(x_Y-x_X)^2+(y_Y-y_X)^2$.
:::

::: point Calcul
- $\displaystyle AC^2=(x-0)^2+(3-0)^2=x^2+9$
- $\displaystyle BC^2=(x-10)^2+(3-0)^2=(x-10)^2+9$
:::

## Question 2 : Condition « rectangle en $\displaystyle C$ »

::: methode
Si le triangle est rectangle en $C$, alors $AB$ est l’hypoténuse :

- $\displaystyle AB^2=AC^2+BC^2$
:::

::: etape $\displaystyle AB^2=10^2=100$
:::

::: etape $\displaystyle 100=(x^2+9)+\big((x-10)^2+9\big)$
:::

::: etape $\displaystyle 100=2x^2-20x+118$
:::

::: etape $\displaystyle 0=x^2-10x+9=(x-1)(x-9)$
:::

::: resultat
$x=1$ ou $x=9$
:::

## Question 3 : Coordonnées de $\displaystyle C$

::: resultat
$C(1\,;\,3)$ ou $C(9\,;\,3)$.
:::

## Question 4 : Aire

::: remarque
Si le triangle est rectangle en $C$, alors

- $\displaystyle \mathcal{A}=\dfrac{AC\times BC}{2}$.
:::

::: point Pour
$\displaystyle C(1\,;\,3)$

- $\displaystyle AC^2=1^2+3^2=10 \Rightarrow AC=\sqrt{10}$
- $\displaystyle BC^2=9^2+3^2=90 \Rightarrow BC=3\sqrt{10}$
:::

::: point Aire
$$
\begin{aligned}
\mathcal{A} &= \dfrac{\sqrt{10}\times 3\sqrt{10}}{2} \\
&= \dfrac{3\times 10}{2} \\
&= 15
\end{aligned}
$$
:::

::: resultat
L’aire vaut $15$ (même résultat pour $C(9\,;\,3)$).
:::

Solution:
<!-- optitab:1 -->
1. $AC^2=x^2+9$ et $BC^2=(x-10)^2+9$
2. $x=1$ ou $x=9$
3. $C(1\,;\,3)$ ou $C(9\,;\,3)$
4. Aire $\displaystyle =15$

:::

::: point Égalité
$$(x+8)^2=x^2+(x+4)^2$$
:::

## Question 2 : Résoudre

::: etape Développer
$$x^2+16x+64=x^2+(x^2+8x+16)$$
:::

::: etape $\displaystyle x^2+16x+64=2x^2+8x+16$
:::

::: etape $\displaystyle 0=x^2-8x-48$
:::

::: etape $\displaystyle x^2-8x-48=(x-12)(x+4)$
:::

::: etape $x=12$ ou $x=-4$
:::

::: resultat
Comme $x>0$, on garde $x=12$.
:::

## Question 3 : Longueurs du triangle

::: point Calcul
$x=12 \Rightarrow x+4=16$ et $x+8=20$
:::

::: resultat
Côtés : $12$ cm, $16$ cm, hypoténuse $20$ cm
:::

## Question 4 : Aire et périmètre

::: point Aire
$$\mathcal{A}=\dfrac{12\times 16}{2}=96\ \text{cm}^2$$
:::

::: point Périmètre
$$P=12+16+20=48\ \text{cm}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x+8)^2=x^2+(x+4)^2$
2. $\displaystyle x=12$
3. Longueurs : $12$ cm, $16$ cm, $20$ cm
4. $\mathcal{A}=96\ \text{cm}^2$ et $P=48\ \text{cm}$

=== Maîtrise - Réciproque et contraposée - Triangle rectangle, acutangle ou obtusangle

Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour chaque triangle ci-dessous, déterminer s'il est rectangle. S'il n'est pas rectangle, préciser s'il est acutangle ou obtusangle.

Triangles (en cm) :

• Triangle 1 : $\displaystyle 6,\ 8,\ 10$

• Triangle 2 : $\displaystyle 5,\ 7,\ 9$

2. Étudier le triangle 2.
3. Étudier le triangle 3.

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Triangle 1 : $\displaystyle 6,\ 8,\ 10$

::: methode
Comparer $c^2$ (côté le plus long) à $a^2+b^2$.

$$10$$
:::

::: etape $10^2=100$ et $6^2+8^2=36+64=100$

::: methode
Comparer $c^2$ à $a^2+b^2$.

::: etape Plus grand côté
$$9$$

::: etape $9^2=81$ et $5^2+7^2=25+49=74$
:::

:::

1. Triangle 1 : rectangle

=== Maîtrise - Rectangle - Retrouver les dimensions (périmètre + diagonale)
Id: 2083
Difficulté: hard
Image: pythagore_rectangle_perimetre_diagonale_34_13.png

Énoncé:
<!-- optitab:1 -->
$ABCD$ est un rectangle. On sait que son périmètre vaut $34$ cm et que sa diagonale $AC$ mesure $13$ cm.

1. Noter $\displaystyle AB=x$ et exprimer $\displaystyle BC$ en fonction de $\displaystyle x$.
2. Écrire l’égalité de Pythagore dans le triangle $\displaystyle ABC$.
3. Déterminer les longueurs $\displaystyle AB$ et $\displaystyle BC$.
4. Calculer l’aire du rectangle $\displaystyle ABCD$.

Étapes:
<!-- optitab:1 -->
[IMAGE_1]

## Question 1 : Relation avec le périmètre

::: rappel Formule
$\displaystyle P=2(AB+BC)$.
:::

::: etape $\displaystyle 34=2(x+BC)\Longrightarrow x+BC=17$
:::

::: resultat
$$BC=17-x$$
:::

## Question 2 : Pythagore

::: point Justification
Dans un rectangle, $\widehat{ABC}=90^\circ$ donc $\triangle ABC$ est rectangle en $B$.
:::

::: point Égalité
$$AC^2=AB^2+BC^2$$
:::

::: point Donc
$$13^2=x^2+(17-x)^2$$
:::

## Question 3 : Déterminer $\displaystyle AB$ et $\displaystyle BC$

::: methode
Développer puis résoudre l’équation.
:::

::: etape $\displaystyle 169=x^2+(17-x)^2=x^2+(289-34x+x^2)$
:::

::: etape $\displaystyle 169=2x^2-34x+289 \Longrightarrow 0=2x^2-34x+120$
:::

::: etape $\displaystyle 0=x^2-17x+60$
:::

::: etape $\displaystyle x^2-17x+60=(x-5)(x-12)$
:::

::: etape $x=5$ ou $x=12$
:::

::: resultat
Les côtés valent $5$ cm et $12$ cm (dans un ordre ou l’autre).
:::

::: point Choix
Si on veut $AB$ le plus grand : $AB=12$ cm et $BC=5$ cm.
:::

## Question 4 : Aire du rectangle $\displaystyle ABCD$

::: methode
$$\mathcal{A}=AB\times BC=x\times(17-x)$$
:::

::: etape Pour $\displaystyle x=5$
$$\mathcal{A}=5\times 12=60\ \text{cm}^2$$
:::

::: etape Pour $\displaystyle x=12$
$$\mathcal{A}=12\times 5=60\ \text{cm}^2$$
:::

::: resultat
L'aire ne dépend pas de l'ordre des côtés : $\mathcal{A}=60\ \text{cm}^2$.
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle BC=17-x$
2. $\displaystyle 13^2=x^2+(17-x)^2$
3. $AB=12\ \text{cm}$ et $BC=5\ \text{cm}$ (ou inversement)
4. Aire $\displaystyle =12\times 5=60\ \text{cm}^2$
