[IMAGE_1]

1. Combien d’objets a A ?
2. Combien d’objets a B ?
3. Quelle somme a B ?
4. Qui a le plus d’argent ?
5. Avoir plus de pièces veut-il toujours dire avoir plus d’argent ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien d’objets a A ?

::: methode
Compte le billet, sans lire sa valeur.
:::

::: etape Raisonner

:::

::: resultat
1 objet.
:::

::: methode
Compte les pièces.
:::

::: etape Raisonner

:::

::: resultat
4 objets.
:::

## Question 3 : Quelle somme a B ?

::: methode
Réunis la valeur des quatre pièces.
:::

::: etape Raisonner
$2+2=4$, puis$4+2=6$, puis$6+2=8$.
:::

::: resultat
8 €.
:::

## Question 4 : Qui a le plus d’argent ?

::: methode
Compare les sommes, pas le nombre d’objets.
:::

::: etape Raisonner
$10>8$.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
A a le plus d’argent.
:::

## Question 5 : Avoir plus de pièces veut-il toujours dire avoir plus d’argent ?

:::

::: etape Raisonner

:::

::: resultat

:::

Solution:
<!-- optitab:1 -->

2. 4 objets.

2. Combien reste-t-il à former ?
3. Combien de pièces de 2 € faut-il ajouter ?

5. Pourquoi trois objets ne suffisent-ils pas ?

<!-- optitab:1 -->

::: methode
Compte de dix en dix.
:::

::: etape Raisonner

:::

::: resultat
2 billets.
:::

## Question 2 : Combien reste-t-il à former ?

::: methode
Complète les vingt euros.
:::

::: etape Raisonner
$24-20=4$
:::

::: resultat
4 €.
:::

## Question 3 : Combien de pièces de 2 € faut-il ajouter ?

::: methode
Réunis deux pièces identiques.
:::

::: etape Raisonner
$2+2=4$.
:::

::: resultat
2 pièces de 2 €.
:::

## Question 4 : Combien d’objets utilises-tu en tout ?

::: methode
Compte les billets et les pièces.
:::

::: etape Raisonner
$2+2=4$ objets.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
4 objets.
:::

## Question 5 : Pourquoi trois objets ne suffisent-ils pas ?

::: methode
