Titre: Résumé : Représenter algébriquement et graphiquement les fonctions

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : image, antécédent, courbe, résolutions graphique et algébrique, parité. Programme de Seconde.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Image, antécédent, courbe</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$M(a\,;b) \in \mathcal{C}_f \iff b = f(a)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Image : on calcule $f(a)$ ou on lit l’ordonnée du point d’abscisse $a$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Antécédents de $k$ : on résout $f(x) = k$ ou on lit les abscisses sur la droite $y = k$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Paire : $f(-x) = f(x)$ ; impaire : $f(-x) = -f(x)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Résoudre des équations et inéquations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $f(x) = g(x)$ : abscisses des points d’intersection des deux courbes.</p>
<p style="margin:6px 0 0 0;">2️⃣ $f(x) \le g(x)$ : abscisses des points où $\mathcal{C}_f$ est sous $\mathcal{C}_g$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Par le calcul : tout passer à gauche, factoriser, tableau de signes.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre image (lue sur l’axe des ordonnées) et antécédent (lu sur l’axe des abscisses).</p>
<p style="margin:6px 0 0 0;">2️⃣ Donner des ordonnées comme solutions d’une inéquation : les solutions sont des valeurs de $x$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier les crochets : $\le$ inclut les bornes, $\lt$ les exclut.</p>
<p style="margin:6px 0 0 0;">4️⃣ Garder une valeur interdite dans l’ensemble des solutions d’une inéquation-quotient.</p>
</div>
