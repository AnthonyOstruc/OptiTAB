===
Découverte - Douze jetons pour deux
Id: 5426
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Prends 12 jetons. Partage-les entre 2 enfants. Chacun doit recevoir autant.

[IMAGE_1]

1. Combien d’objets faut-il partager ?
2. Combien de parts égales faut-il faire ?
3. Distribue un objet à chacun, puis recommence. Combien chacun reçoit-il ?
4. Vérifie le total avec une addition.
5. Comment sais-tu que le partage est équitable ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien d’objets faut-il partager ?

::: methode
Compter le tout.
:::

::: etape Raisonner
Le tout contient 12 objets.
:::

::: resultat
Il faut partager 12 objets.
:::

## Question 2 : Combien de parts égales faut-il faire ?

::: methode
Compter les enfants.
:::

::: etape Raisonner
Un enfant reçoit une part. Il y a 2 enfants.
:::

::: resultat
Il faut 2 parts égales.
:::

## Question 3 : Distribue un objet à chacun, puis recommence. Combien chacun reçoit-il ?

::: methode
Faire des tours de distribution.
:::

::: etape Raisonner
Je donne un objet à chacun à chaque tour. Après 6 tours, tout est distribué.

[IMAGE_2]
:::

::: resultat
Chacun reçoit 6 objets.
:::

## Question 4 : Vérifie le total avec une addition.

::: methode
Réunir les parts égales.
:::

::: etape Raisonner
Je compte une part par enfant.
:::

::: resultat
$6+6=12$.
:::

## Question 5 : Comment sais-tu que le partage est équitable ?

::: methode
Comparer les parts.
:::

::: etape Raisonner
Chaque enfant reçoit 6 objets. Il n’en reste aucun.
:::

::: resultat
Le partage est équitable : 6 objets pour chacun.
:::

Solution:
<!-- optitab:1 -->
1. Il faut partager 12 objets.
2. Il faut 2 parts égales.
3. Chacun reçoit 6 objets.
4. $6+6=12$.
5. Le partage est équitable : 6 objets pour chacun.

Découverte - Des paquets de cinq
Id: 5427
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Prends 15 jetons. Fais des paquets de 5 jetons. Les cadres sont une aide. Tu peux en laisser vides.

[IMAGE_1]

1. Combien de jetons faut-il utiliser ?
2. Combien faut-il dans un paquet ?
3. Construis les paquets. Combien obtiens-tu de paquets complets ?
4. Écris une addition pour vérifier.
5. Reste-t-il des jetons sans paquet ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de jetons faut-il utiliser ?

::: methode
Lire le total à ranger.
:::

::: etape Raisonner
Je prends exactement 15 jetons.
:::

::: resultat
Il faut 15 jetons.
:::

## Question 2 : Combien faut-il dans un paquet ?

::: methode
Lire la taille demandée.
:::

::: etape Raisonner
Je mets 5 jetons ensemble. Je fais pareil pour chaque paquet.
:::

::: resultat
Il faut 5 jetons par paquet.
:::

## Question 3 : Construis les paquets. Combien obtiens-tu de paquets complets ?

::: methode
Former un paquet après l’autre.
:::

::: etape Raisonner
Je prends 5 jetons à chaque fois. Je peux faire 3 paquets.

[IMAGE_2]
:::

::: resultat
J’obtiens 3 paquets.
:::

## Question 4 : Écris une addition pour vérifier.

::: methode
Réunir tous les paquets.
:::

::: etape Raisonner
Il y a 3 nombres dans l’addition.
:::

::: resultat
$5+5+5=15$.
:::

## Question 5 : Reste-t-il des jetons sans paquet ?

::: methode
Compter ce qui n’a pas été rangé.
:::

::: etape Raisonner
Les paquets utilisent les 15 jetons. $15-15=0$.
:::

::: resultat
Il reste 0 jeton.
:::

Solution:
<!-- optitab:1 -->
1. Il faut 15 jetons.
2. Il faut 5 jetons par paquet.
3. J’obtiens 3 paquets.
4. $5+5+5=15$.
5. Il reste 0 jeton.
