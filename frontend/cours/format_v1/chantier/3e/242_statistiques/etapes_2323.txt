## Question 1 : L'effectif total

::: methode
L'effectif total est la somme des effectifs (deuxième ligne du tableau).
:::

::: etape Additionner
$$2 + 3 + 6 + 5 + 4 = 20$$
:::

::: resultat
L'effectif total est $20$ élèves.
:::

## Question 2 : La somme pondérée

::: methode
On multiplie chaque note par son effectif, puis on additionne les produits.
:::

::: etape Produits
$$6 \times 2 + 8 \times 3 + 10 \times 6 + 12 \times 5 + 16 \times 4$$
:::

::: etape Additionner
$$12 + 24 + 60 + 60 + 64 = 220$$
:::

::: resultat
La somme pondérée vaut $220$.
:::

## Question 3 : La moyenne

::: methode
Moyenne pondérée = somme pondérée ÷ effectif total.
:::

::: etape Diviser
$$\frac{220}{20} = 11$$
:::

::: resultat
La moyenne de la classe est $11$.
:::

## Question 4 : La médiane

::: methode
Effectif $20$ (pair) : la médiane est la moyenne des valeurs de rangs $10$ et $11$. Les effectifs cumulés donnent les rangs sans écrire toute la série.
:::

::: etape Effectifs cumulés
On ajoute une ligne : chaque case donne le nombre d'élèves ayant une note inférieure ou égale à celle de la colonne.
:::

[IMAGE_2]

::: etape Lire les rangs 10 et 11
$5$ élèves ont $8$ ou moins et $11$ élèves ont $10$ ou moins : les rangs $6$ à $11$ portent la note $10$. Les 10ᵉ et 11ᵉ valeurs valent donc $10$.
:::

::: resultat
La médiane est $\dfrac{10 + 10}{2} = 10$.
:::

## Question 5 : L'étendue

::: methode
Étendue = plus grande note − plus petite note (première ligne du tableau).
:::

::: etape Calculer
$$16 - 6 = 10$$
:::

::: resultat
L'étendue est $10$ points.
:::

::: attention Erreur fréquente
Calculer la moyenne des notes sans les effectifs : $\dfrac{6 + 8 + 10 + 12 + 16}{5} = 10{,}4$ est faux ; la bonne moyenne pondérée est $11$. De même, l'étendue se calcule avec les notes, pas avec les effectifs.
:::

::: retenir
Les effectifs cumulés permettent de trouver les rangs centraux sans écrire toute la série.
:::

Solution:
<!-- optitab:1 -->
1. $20$
2. $220$
3. $11$
4. $10$
5. $10$
