=== Découverte - Calcul littéral - 1. Écrire avec des lettres
Id: 2579
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
En calcul littéral, on peut supprimer le signe $\times$ devant une lettre ou une parenthèse, et $x \times x$ s'écrit $x^2$.

1. Écrire plus simplement $\displaystyle 3 \times x$, $\displaystyle x \times x$ et $\displaystyle 1 \times y$.
2. Écrire plus simplement $\displaystyle 2 \times a \times 5$ et $\displaystyle x \times 4 \times x$.
3. Traduire par une expression : « le double de $\displaystyle x$, augmenté de $\displaystyle 3$ ».
4. Traduire : « la somme de $\displaystyle x$ et de son triple ». Réduire l'expression obtenue.
5. Traduire : « le carré de la somme de $\displaystyle x$ et de $\displaystyle 1$ ».
6. Traduire en phrase l'expression $\displaystyle 4(x - 2)$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les conventions

::: etape $3 \times x = 3x$ ; $x \times x = x^2$ ; $1 \times y = y$.
:::

::: resultat
$3x$ ; $x^2$ ; $y$
:::

## Question 2 : Des produits à simplifier

::: methode
Dans un produit, on peut changer l'ordre des facteurs : on regroupe les nombres d'un côté, les lettres de l'autre.
:::

::: etape $\displaystyle 2 \times a \times 5 = 2 \times 5 \times a = 10a$
:::

::: etape $\displaystyle x \times 4 \times x = 4 \times x \times x = 4x^2$
:::

::: resultat
$10a$ et $4x^2$
:::

## Question 3 : Le double augmenté de 3

::: etape Le double de $\displaystyle x$
$2x$ ; augmenté de $3$ : $+ 3$.
:::

::: resultat
$$2x + 3$$
:::

## Question 4 : Un nombre et son triple

::: etape $\displaystyle x + 3x$
:::

::: etape $x = 1x$, donc $1x + 3x = 4x$.
:::

::: resultat
$$x + 3x = 4x$$
:::

## Question 5 : Le carré d'une somme

::: methode
On repère la dernière opération : c'est le carré, qui porte sur toute la somme.
:::

::: etape La somme
$x + 1$ ; son carré : $(x + 1)^2$.
:::

::: resultat
$$(x + 1)^2$$
:::

**Erreur fréquente :** Écrire $x + 1^2$ : le carré ne porterait que sur $1$, ce qui ne traduit pas la phrase.

## Question 6 : De l'expression à la phrase

::: etape $\displaystyle 4(x - 2)$ est un produit
$4$ multiplie la différence $x - 2$.
:::

::: resultat
« Le produit de $4$ par la différence de $x$ et de $2$ » (ou « le quadruple de $x$ diminué de $2$ »).
:::

**À retenir :** Pour lire une expression, on cherche la DERNIÈRE opération effectuée : elle donne le nom de l'expression (somme, produit, carré…).

Solution:
<!-- optitab:1 -->
1. $3x$ ; $x^2$ ; $y$
2. $10a$ ; $4x^2$
3. $\displaystyle 2x + 3$
4. $\displaystyle 4x$
5. $\displaystyle (x + 1)^2$
6. Le quadruple de la différence $x - 2$

=== Découverte - Calcul littéral - 2. Calculer la valeur d'une expression
Id: 2580
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère les expressions $\displaystyle A = 3x^2 - 2x + 5$ et $\displaystyle B = (2x - 1)(x + 3)$.

1. Calculer $\displaystyle A$ pour $\displaystyle x = 2$.
2. Calculer $\displaystyle A$ pour $\displaystyle x = -1$.
3. Calculer $\displaystyle A$ pour $\displaystyle x = 0$ et pour $\displaystyle x = 0{,}5$.
4. Calculer $\displaystyle B$ pour $\displaystyle x = 2$.
5. Calculer $\displaystyle B$ pour $\displaystyle x = -3$. Pourquoi ce résultat était-il prévisible ?
6. Calculer $\displaystyle A$ pour $\displaystyle x = -2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : A pour x = 2

::: methode
On remplace $x$ par $2$ en gardant les signes $\times$ cachés, puis on applique les priorités (puissance, produits, sommes).
:::

::: etape $\displaystyle A = 3 \times 2^2 - 2 \times 2 + 5 = 3 \times 4 - 4 + 5$
:::

::: resultat
$$A = 12 - 4 + 5 = 13$$
:::

## Question 2 : A pour x = −1

::: etape $\displaystyle A = 3 \times (-1)^2 - 2 \times (-1) + 5$
:::

::: etape $(-1)^2 = 1$ et $-2 \times (-1) = 2$, donc $A = 3 + 2 + 5$.
:::

::: resultat
$$A = 10$$
:::

**Erreur fréquente :** Écrire $3 \times -1^2$ : sans parenthèses, on calculerait $-1^2 = -1$ et on obtiendrait un faux résultat.

## Question 3 : A pour x = 0 et x = 0,5

::: etape $\displaystyle x = 0$
$\displaystyle A = 0 - 0 + 5 = 5$.
:::

::: etape $\displaystyle x = 0{,}5$
$\displaystyle A = 3 \times 0{,}25 - 1 + 5 = 0{,}75 - 1 + 5 = 4{,}75$.
:::

::: resultat
$5$ et $4{,}75$
:::

## Question 4 : B pour x = 2

::: etape $2x - 1 = 3$ et $x + 3 = 5$.
:::

::: resultat
$$B = 3 \times 5 = 15$$
:::

## Question 5 : B pour x = −3

::: etape $2 \times (-3) - 1 = -7$ et $-3 + 3 = 0$.
:::

::: resultat
$B = (-7) \times 0 = 0$ : la deuxième parenthèse est nulle, donc le produit est nul.
:::

**À retenir :** Un produit est nul dès qu'un de ses facteurs est nul.

## Question 6 : A pour x = −2

::: etape $\displaystyle A = 3 \times (-2)^2 - 2 \times (-2) + 5 = 3 \times 4 + 4 + 5$
:::

::: resultat
$$A = 21$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 13$
2. $\displaystyle 10$
3. $5$ ; $4{,}75$
4. $\displaystyle 15$
5. $\displaystyle 0$
6. $\displaystyle 21$

=== Découverte - Calcul littéral - 3. Réduire une expression
Id: 2581
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Réduire une expression, c'est l'écrire avec le moins de termes possible, en regroupant les termes de même nature.

1. Réduire $\displaystyle 3x + 5x$.
2. Réduire $\displaystyle 7a - 2 + 3a + 9$.
3. Réduire $\displaystyle 4x^2 + 3x - x^2 + x$.
4. Réduire $\displaystyle 5y - 8y + 2$.
5. Réduire $\displaystyle 2x \times 3x$.
6. Expliquer la différence entre $\displaystyle x + x$ et $\displaystyle x \times x$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Une somme de termes en x

::: etape
$3$ fois $x$ plus $5$ fois $x$, c'est $8$ fois $x$.
:::

::: resultat
$$8x$$
:::

## Question 2 : Lettres et nombres

::: methode
On regroupe les termes en $a$ entre eux et les nombres entre eux.
:::

::: etape $7a + 3a = 10a$ et $-2 + 9 = 7$.
:::

::: resultat
$$10a + 7$$
:::

**Erreur fréquente :** Écrire $17a$ : on ne peut pas additionner $10a$ et $7$, ce ne sont pas des termes de même nature.

## Question 3 : Termes en x² et termes en x

::: etape $4x^2 - x^2 = 3x^2$ et $3x + x = 4x$.
:::

::: resultat
$$3x^2 + 4x$$
:::

## Question 4 : Un coefficient négatif

::: etape $\displaystyle 5y - 8y = -3y$
:::

::: resultat
$$-3y + 2$$
:::

## Question 5 : Un produit

::: etape $\displaystyle 2x \times 3x = 2 \times 3 \times x \times x$
:::

::: resultat
$$6x^2$$
:::

## Question 6 : Somme ou produit ?

::: etape $\displaystyle x + x$
on ajoute deux fois $x$, cela fait $2x$.
:::

::: etape $\displaystyle x \times x$
on multiplie $x$ par lui-même, cela fait $x^2$.
:::

::: resultat
$x + x = 2x$ alors que $x \times x = x^2$. Par exemple pour $x = 5$ : $10$ et $25$.
:::

**À retenir :** Un test avec une valeur simple permet de détecter une erreur de réduction.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 8x$
2. $\displaystyle 10a + 7$
3. $\displaystyle 3x^2 + 4x$
4. $\displaystyle -3y + 2$
5. $\displaystyle 6x^2$
6. $x + x = 2x$ ; $x \times x = x^2$

=== Découverte - Calcul littéral - 4. Les allumettes
Id: 2582
Difficulté: easy
Image: calcul_litteral_4e_allumettes.png

Énoncé:
<!-- optitab:1 -->
On aligne des carrés faits avec des allumettes, comme sur la figure.

[IMAGE_1]

1. Combien faut-il d'allumettes pour $\displaystyle 1$, $\displaystyle 2$ et $\displaystyle 3$ carrés ? Pour $\displaystyle 4$ et $\displaystyle 5$ carrés ?
2. Montrer que, pour $\displaystyle n$ carrés, il faut $\displaystyle 3n + 1$ allumettes.
3. Un camarade propose $\displaystyle 4 + 3(n - 1)$. A-t-il raison ? Justifier par un calcul.
4. Combien d'allumettes faut-il pour $\displaystyle 100$ carrés ?
5. Avec $\displaystyle 61$ allumettes, combien de carrés peut-on construire ?
6. Peut-on utiliser exactement $\displaystyle 100$ allumettes ? Si oui, pour combien de carrés ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compter les allumettes

::: etape $\displaystyle 1$ carré
$4$ ; $2$ carrés : $7$ ; $3$ carrés : $10$.
:::

::: etape Chaque carré ajouté demande $3$ allumettes de plus
$4$ carrés : $13$ ; $5$ carrés : $16$.
:::

::: resultat
$4$ ; $7$ ; $10$ ; $13$ ; $16$
:::

## Question 2 : L'expression 3n + 1

::: methode
On compte d'une façon qui marche pour tous les nombres de carrés.
:::

::: etape
Une allumette verticale au départ, puis chaque carré ajoute $3$ allumettes (haut, bas, droite).
:::

::: resultat
$1 + 3n$, soit $3n + 1$ allumettes.
:::

**Vérification :** $n = 3$ : $3 \times 3 + 1 = 10$

## Question 3 : Une autre expression

::: etape $\displaystyle 4 + 3(n - 1) = 4 + 3n - 3$
:::

::: etape $\displaystyle = 3n + 1$
:::

::: resultat
Oui : les deux expressions sont égales (il compte le premier carré, puis $3$ par carré suivant).
:::

**À retenir :** Deux façons de compter peuvent donner deux expressions différentes mais égales : on le prouve en développant et en réduisant.

## Question 4 : 100 carrés

::: etape $\displaystyle 3 \times 100 + 1$
:::

::: resultat
$\displaystyle 301$ allumettes
:::

## Question 5 : Avec 61 allumettes

::: etape $3n + 1 = 61$, donc $3n = 60$.
:::

::: etape $\displaystyle n = 60 : 3 = 20$
:::

::: resultat
$\displaystyle 20$ carrés.
:::

## Question 6 : Exactement 100 allumettes ?

::: etape $3n + 1 = 100$, donc $3n = 99$ et $n = 33$, qui est un entier.
:::

::: resultat
Oui, avec $33$ carrés : $3 \times 33 + 1 = 100$.
:::

**Erreur fréquente :** Croire que $100$ est impossible parce qu'il n'est pas multiple de $3$ : c'est $100 - 1 = 99$ qui doit être un multiple de $3$.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 4, 7, 10, 13, 16$
2. $\displaystyle 1 + 3n = 3n + 1$
3. Oui : $\displaystyle 4 + 3(n - 1) = 3n + 1$
4. $\displaystyle 301$
5. $\displaystyle 20$ carrés
6. Oui : $\displaystyle 33$ carrés

=== Découverte - Calcul littéral - 5. La simple distributivité
Id: 2583
Difficulté: easy
Image: calcul_litteral_4e_trois_x4.png

Énoncé:
<!-- optitab:1 -->
L'aire du grand rectangle ci-dessous peut s'écrire de deux façons : $3 \times (x + 4)$, ou comme la somme des aires des deux petits rectangles.

[IMAGE_1]

1. Écrire l'aire de chaque petit rectangle, puis développer $\displaystyle 3(x + 4)$.
2. Développer $\displaystyle 5(2a - 3)$.
3. Développer $\displaystyle -2(x - 6)$.
4. Développer $\displaystyle x(x + 5)$.
5. Développer $\displaystyle -(3x - 7)$.
6. Développer puis réduire $\displaystyle 4(2x + 1) - 3(x - 2)$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le modèle des aires

::: etape Petit rectangle bleu
$3 \times x = 3x$ ; orange : $3 \times 4 = 12$.
:::

::: etape Aire totale
$\displaystyle 3x + 12$.
:::

::: resultat
$$3(x + 4) = 3x + 12$$
:::

## Question 2 : Avec une soustraction

::: etape $\displaystyle 5 \times 2a - 5 \times 3$
:::

::: resultat
$$10a - 15$$
:::

## Question 3 : Un facteur négatif

::: methode
On multiplie $-2$ par chaque terme, en respectant la règle des signes.
:::

::: etape $-2 \times x = -2x$ et $-2 \times (-6) = 12$.
:::

::: resultat
$$-2x + 12$$
:::

**Erreur fréquente :** Écrire $-2x - 12$ : $(-2) \times (-6) = +12$.

## Question 4 : Un facteur littéral

::: etape $\displaystyle x \times x + x \times 5$
:::

::: resultat
$$x^2 + 5x$$
:::

## Question 5 : Le signe moins devant une parenthèse

::: etape $\displaystyle -(3x - 7) = -1 \times (3x - 7) = -3x + 7$
:::

::: resultat
$$-3x + 7$$
:::

**À retenir :** Un signe « − » devant une parenthèse change le signe de CHAQUE terme de la parenthèse.

## Question 6 : Deux développements

::: etape $\displaystyle 4(2x + 1) = 8x + 4$
:::

::: etape $\displaystyle -3(x - 2) = -3x + 6$
:::

::: etape $\displaystyle 8x + 4 - 3x + 6 = 5x + 10$
:::

::: resultat
$$5x + 10$$
:::

**Vérification :** Pour $x = 1$ : $4 \times 3 - 3 \times (-1) = 15$ et $5 + 10 = 15$

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3x + 12$
2. $\displaystyle 10a - 15$
3. $\displaystyle -2x + 12$
4. $\displaystyle x^2 + 5x$
5. $\displaystyle -3x + 7$
6. $\displaystyle 5x + 10$

=== Découverte - Calcul littéral - 6. Factoriser
Id: 2584
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Factoriser une somme, c'est l'écrire comme un produit, en repérant un facteur commun : $ka + kb = k(a + b)$.

1. Factoriser $\displaystyle 5x + 15$.
2. Factoriser $\displaystyle 12a - 18$ avec le plus grand facteur commun possible.
3. Factoriser $\displaystyle x^2 + 7x$.
4. Factoriser $\displaystyle 3x^2 - 6x$.
5. Factoriser $\displaystyle 7y + 7$.
6. Vérifier les réponses des questions 2 et 4 en développant.

Étapes:
<!-- optitab:1 -->
## Question 1 : Un facteur numérique

::: etape $\displaystyle 5x + 15 = 5 \times x + 5 \times 3$
:::

::: resultat
$$5(x + 3)$$
:::

## Question 2 : Le plus grand facteur commun

::: methode
On cherche le plus grand nombre qui divise $12$ et $18$ : c'est $6$.
:::

::: etape $\displaystyle 12a - 18 = 6 \times 2a - 6 \times 3$
:::

::: resultat
$$6(2a - 3)$$
:::

**Erreur fréquente :** Écrire $2(6a - 9)$ : c'est juste, mais incomplet ; on peut encore mettre $3$ en facteur.

## Question 3 : Un facteur littéral

::: etape $\displaystyle x^2 + 7x = x \times x + x \times 7$
:::

::: resultat
$$x(x + 7)$$
:::

## Question 4 : Nombre et lettre en facteur

::: etape $3x^2 = 3x \times x$ et $6x = 3x \times 2$.
:::

::: resultat
$$3x(x - 2)$$
:::

## Question 5 : Un facteur caché

::: etape $\displaystyle 7y + 7 = 7 \times y + 7 \times 1$
:::

::: resultat
$$7(y + 1)$$
:::

**À retenir :** Quand un terme est égal au facteur commun, il reste $1$ dans la parenthèse (et non $0$).

## Question 6 : Vérifier en développant

::: etape $\displaystyle 6(2a - 3) = 12a - 18$
:::

::: etape $\displaystyle 3x(x - 2) = 3x^2 - 6x$
:::

::: resultat
On retrouve les expressions de départ : les factorisations sont justes.
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 5(x + 3)$
2. $\displaystyle 6(2a - 3)$
3. $\displaystyle x(x + 7)$
4. $\displaystyle 3x(x - 2)$
5. $\displaystyle 7(y + 1)$
6. Les développements redonnent les sommes de départ

=== Découverte - Calcul littéral - 7. Vrai ou faux ?
Id: 2585
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pour chaque affirmation, dire si elle est vraie pour tous les nombres $x$ ou fausse, en justifiant.

1. $\displaystyle (x + 3)^2 = x^2 + 9$
2. $\displaystyle 2(x + 5) = 2x + 10$
3. $\displaystyle x^2 \geq x$ pour tout nombre $\displaystyle x$.
4. $\displaystyle 3x + 2x = 5x^2$. Tester d'abord avec $\displaystyle x = 1$, puis avec $\displaystyle x = 2$.
5. $\displaystyle -(x - 4) = -x - 4$
6. $\displaystyle x(x + 1) - x = x^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Le carré d'une somme

::: methode
Pour montrer qu'une égalité est fausse, un contre-exemple suffit.
:::

::: etape Pour $\displaystyle x = 1$
$(1 + 3)^2 = 16$ et $1^2 + 9 = 10$.
:::

::: resultat
Faux : $\displaystyle 16 \neq 10$.
:::

## Question 2 : Une distributivité

::: etape On développe
$\displaystyle 2(x + 5) = 2x + 2 \times 5 = 2x + 10$.
:::

::: resultat
Vrai pour tout $x$ (c'est la distributivité).
:::

## Question 3 : Le carré est-il plus grand ?

::: etape Pour $\displaystyle x = 0{,}5$
$\displaystyle x^2 = 0{,}25 < 0{,}5$.
:::

::: resultat
Faux : pour $x = 0{,}5$, le carré est plus petit que le nombre.
:::

## Question 4 : Un test qui trompe

::: etape Pour $\displaystyle x = 1$
$3 + 2 = 5$ et $5 \times 1^2 = 5$ : l'égalité est vraie pour cette valeur !
:::

::: etape Pour $\displaystyle x = 2$
$6 + 4 = 10$ et $5 \times 4 = 20$.
:::

::: resultat
Faux : $3x + 2x = 5x$, pas $5x^2$. L'exemple $x = 1$ ne prouvait rien.
:::

**À retenir :** Un exemple qui marche ne prouve pas qu'une égalité est toujours vraie ; un contre-exemple prouve qu'elle est fausse.

## Question 5 : Le signe moins

::: etape $\displaystyle -(x - 4) = -x + 4$
:::

::: resultat
Faux : on a oublié de changer le signe de $-4$.
:::

## Question 6 : Une égalité à démontrer

::: etape $\displaystyle x(x + 1) - x = x^2 + x - x$
:::

::: etape $\displaystyle = x^2$
:::

::: resultat
Vrai pour tout $\displaystyle x$.
:::

**Erreur fréquente :** Se contenter de vérifier pour deux ou trois valeurs : seul le calcul littéral prouve l'égalité pour TOUS les nombres.

Solution:
<!-- optitab:1 -->
1. Faux ($x = 1$ : $16 \neq 10$)
2. Vrai
3. Faux ($\displaystyle 0{,}25 < 0{,}5$)
4. Faux ($x = 2$ : $10 \neq 20$)
5. Faux : $\displaystyle -(x - 4) = -x + 4$
6. Vrai

=== Entraînement - Calcul littéral - 1. La double distributivité
Id: 2586
Difficulté: medium
Image: calcul_litteral_4e_double_ex.png,calcul_litteral_4e_double_ex_solution.png

Énoncé:
<!-- optitab:1 -->
Le grand rectangle ci-dessous a pour dimensions $x + 3$ et $x + 2$. Il est découpé en quatre rectangles.

[IMAGE_1]

1. Exprimer l'aire de chacun des quatre rectangles, puis développer $\displaystyle (x + 3)(x + 2)$.
2. Développer et réduire $\displaystyle (2x + 1)(x + 4)$.
3. Développer et réduire $\displaystyle (x - 3)(x + 5)$.
4. Développer et réduire $\displaystyle (2a - 1)(3a - 2)$.
5. Développer et réduire $\displaystyle (x + 4)^2$.
6. Vérifier le résultat de la question 1 en remplaçant $\displaystyle x$ par $\displaystyle 10$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le modèle des aires

::: etape Les quatre aires
$x \times x = x^2$ ; $3 \times x = 3x$ ; $x \times 2 = 2x$ ; $3 \times 2 = 6$.
:::

::: etape $x^2 + 3x + 2x + 6$, puis on réduit $3x + 2x = 5x$.
:::

::: resultat
$$(x + 3)(x + 2) = x^2 + 5x + 6$$
:::

[IMAGE_2]

## Question 2 : Avec un coefficient

::: methode
Chaque terme de la première parenthèse multiplie chaque terme de la seconde : $4$ produits.
:::

::: etape $\displaystyle 2x \times x + 2x \times 4 + 1 \times x + 1 \times 4 = 2x^2 + 8x + x + 4$
:::

::: resultat
$$2x^2 + 9x + 4$$
:::

## Question 3 : Avec un signe moins

::: etape $\displaystyle x \times x + x \times 5 - 3 \times x - 3 \times 5 = x^2 + 5x - 3x - 15$
:::

::: resultat
$$x^2 + 2x - 15$$
:::

## Question 4 : Deux signes moins

::: etape $\displaystyle 2a \times 3a - 2a \times 2 - 1 \times 3a + (-1) \times (-2) = 6a^2 - 4a - 3a + 2$
:::

::: resultat
$$6a^2 - 7a + 2$$
:::

**Erreur fréquente :** Écrire $-2$ pour le dernier produit : $(-1) \times (-2) = +2$.

## Question 5 : Un carré

::: etape $\displaystyle (x + 4)^2 = (x + 4)(x + 4) = x^2 + 4x + 4x + 16$
:::

::: resultat
$$x^2 + 8x + 16$$
:::

**Erreur fréquente :** Écrire $(x + 4)^2 = x^2 + 16$ : on oublie les deux produits « croisés » $4x$.

## Question 6 : Une vérification

::: etape Avant développement
$\displaystyle (10 + 3)(10 + 2) = 13 \times 12 = 156$.
:::

::: etape Après
$$10^2 + 5 \times 10 + 6 = 100 + 50 + 6 = 156$$
:::

::: resultat
On trouve $\displaystyle 156$ dans les deux cas.
:::

**À retenir :** Tester avec $x = 10$ est très efficace : les termes se lisent comme des centaines, dizaines et unités.

Solution:
<!-- optitab:1 -->
1. $\displaystyle x^2 + 5x + 6$
2. $\displaystyle 2x^2 + 9x + 4$
3. $\displaystyle x^2 + 2x - 15$
4. $\displaystyle 6a^2 - 7a + 2$
5. $\displaystyle x^2 + 8x + 16$
6. $\displaystyle 156 = 156$

=== Entraînement - Calcul littéral - 2. Périmètre et aire avec x
Id: 2587
Difficulté: medium
Image: calcul_litteral_4e_rectangle.png

Énoncé:
<!-- optitab:1 -->
Un rectangle a pour longueur $\displaystyle 2x + 3$ et pour largeur $\displaystyle x$ (en cm), avec $\displaystyle x > 0$.

[IMAGE_1]

1. Exprimer le périmètre $\displaystyle P$ du rectangle en fonction de $\displaystyle x$, sous forme réduite.
2. Exprimer l'aire $\displaystyle A$ du rectangle en fonction de $\displaystyle x$, sous forme développée.
3. Calculer le périmètre et l'aire pour $\displaystyle x = 4$.
4. Pour quelle valeur de $\displaystyle x$ le périmètre vaut-il $\displaystyle 42$ cm ?
5. Calculer alors l'aire du rectangle.
6. Quand $\displaystyle x$ double (de $\displaystyle 4$ à $\displaystyle 8$), l'aire double-t-elle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le périmètre

Périmètre d'un rectangle : $\displaystyle 2 \times (\text{longueur} + \text{largeur})$.

::: resultat
$$A = 2x^2 + 3x$$

## Question 3 : Pour x = 4

::: etape $\displaystyle P = 6 \times 4 + 6 = 30$ cm.
:::

::: etape $\displaystyle A = 2 \times 16 + 3 \times 4 = 32 + 12 = 44$ cm².
:::

::: resultat
$P = 30$ cm et $A = 44$ cm².

## Question 4 : Un périmètre de 42 cm

::: etape $\displaystyle x = 36 : 6 = 6$

::: resultat

:::

=== Entraînement - Calcul littéral - 3. Des programmes de calcul

Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Programme A : « Choisir un nombre. Ajouter $\displaystyle 3$. Multiplier par $\displaystyle 2$. Soustraire $\displaystyle 6$. »

Programme B : « Choisir un nombre. Le multiplier par $4$. Soustraire le nombre de départ. Soustraire encore le nombre de départ. »

1. Appliquer les deux programmes au nombre $\displaystyle 5$.
2. Appliquer les deux programmes au nombre $\displaystyle -2$.
3. On note $x$ le nombre de départ. Écrire l'expression obtenue avec le programme A, puis la réduire.
4. Écrire l'expression obtenue avec le programme B, puis la réduire.
5. Que peut-on conclure ?
6. Programme C : « Choisir un nombre. Le multiplier par la somme de ce nombre et de $2$. Soustraire le carré du nombre de départ. » Montrer qu'il donne aussi le même résultat.

Étapes:
<!-- optitab:1 -->
## Question 1 : Avec 5

::: etape A
$5 + 3 = 8$ ; $8 \times 2 = 16$ ; $16 - 6 = 10$.
:::

::: etape B
$5 \times 4 = 20$ ; $20 - 5 = 15$ ; $15 - 5 = 10$.
:::

::: resultat
$10$ et $10$.
:::

## Question 2 : Avec −2

::: etape A
$-2 + 3 = 1$ ; $1 \times 2 = 2$ ; $2 - 6 = -4$.
:::

::: etape B
$-2 \times 4 = -8$ ; $-8 - (-2) = -6$ ; $-6 - (-2) = -4$.
:::

::: resultat
$-4$ et $-4$.
:::

## Question 3 : Le programme A

::: etape $\displaystyle (x + 3) \times 2 - 6 = 2x + 6 - 6$
:::

::: resultat
$$2x$$
:::

## Question 4 : Le programme B

::: etape $\displaystyle 4x - x - x$
:::

::: resultat
$$2x$$
:::

## Question 5 : La conclusion

::: etape Les deux expressions se réduisent à $2x$ pour tout $x$.
:::

::: resultat
Les deux programmes donnent toujours le même résultat : le double du nombre de départ.
:::

**À retenir :** Deux exemples suggèrent une conjecture ; le calcul littéral la démontre pour tous les nombres.

## Question 6 : Le programme C

::: etape $\displaystyle x(x + 2) - x^2 = x^2 + 2x - x^2$
:::

::: etape $\displaystyle = 2x$
:::

::: resultat
Le programme C donne aussi $2x$ : il est équivalent aux deux autres.
:::

**Vérification :** Avec $5$ : $5 \times 7 - 25 = 35 - 25 = 10$

Solution:
<!-- optitab:1 -->
1. $10$ ; $10$
2. $-4$ ; $-4$
3. $\displaystyle 2(x + 3) - 6 = 2x$
4. $\displaystyle 4x - x - x = 2x$
5. Ils donnent toujours $\displaystyle 2x$
6. $\displaystyle x(x + 2) - x^2 = 2x$

=== Entraînement - Calcul littéral - 4. La bordure du tapis
Id: 2589
Difficulté: medium
Image: calcul_litteral_4e_tapis.png,calcul_litteral_4e_tapis_solution.png

Énoncé:
<!-- optitab:1 -->
Un tapis carré de côté $x$ mètres est posé au centre d'une pièce carrée. Il reste tout autour une bordure de parquet de $1$ m de large.

[IMAGE_1]

1. Exprimer le côté de la pièce en fonction de $\displaystyle x$.
2. Exprimer l'aire de la bordure comme une différence de deux aires.
3. Développer et réduire cette expression.
4. Vérifier avec $\displaystyle x = 3$.
5. Factoriser l'expression obtenue et l'interpréter en découpant la bordure en quatre rectangles.
6. Quelle doit être la taille du tapis pour que la bordure ait une aire de $\displaystyle 30$ m² ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le côté de la pièce

::: etape La bordure ajoute $1$ m de chaque côté
$\displaystyle x + 1 + 1$.
:::

::: resultat
$$x + 2$$
:::

## Question 2 : L'aire de la bordure

::: methode
Aire de la bordure = aire de la pièce − aire du tapis.
:::

::: resultat
$$(x + 2)^2 - x^2$$
:::

## Question 3 : Développer

::: etape $\displaystyle (x + 2)^2 = (x + 2)(x + 2) = x^2 + 2x + 2x + 4 = x^2 + 4x + 4$
:::

::: etape $\displaystyle x^2 + 4x + 4 - x^2$
:::

::: resultat
$$4x + 4$$
:::

## Question 4 : Vérification

::: etape Avec $\displaystyle x = 3$
pièce $5^2 = 25$, tapis $3^2 = 9$, bordure $25 - 9 = 16$.
:::

::: etape Formule
$$4 \times 3 + 4 = 16$$
:::

::: resultat
On trouve $\displaystyle 16$ m² dans les deux cas.
:::

## Question 5 : Factoriser et interpréter

::: etape $\displaystyle 4x + 4 = 4(x + 1)$
:::

::: etape
La bordure se découpe en $4$ rectangles identiques de $x + 1$ sur $1$ (voir figure).
:::

::: resultat
$4(x + 1)$ : quatre bandes de longueur $x + 1$ et de largeur $1$.
:::

[IMAGE_2]

**À retenir :** Une même aire peut se calculer de plusieurs façons : les expressions obtenues sont égales.

## Question 6 : Une bordure de 30 m²

::: etape $4x + 4 = 30$, donc $4x = 26$.
:::

::: etape $\displaystyle x = 26 : 4 = 6{,}5$
:::

::: resultat
Un tapis de $\displaystyle 6{,}5$ m de côté.
:::

**Vérification :** $\displaystyle 8{,}5^2 - 6{,}5^2 = 72{,}25 - 42{,}25 = 30$

Solution:
<!-- optitab:1 -->
1. $\displaystyle x + 2$
2. $\displaystyle (x + 2)^2 - x^2$
3. $\displaystyle 4x + 4$
4. $\displaystyle 16$ m²
5. $4(x + 1)$ : $4$ bandes de $(x + 1) \times 1$
6. $\displaystyle 6{,}5$ m

=== Entraînement - Calcul littéral - 5. Supprimer les parenthèses
Id: 2590
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer puis réduire chaque expression.

1. $\displaystyle A = 5 - (2x - 3)$
2. $\displaystyle B = 3x - (-x + 4)$
3. $\displaystyle C = 2(x - 1) - (x + 5)$
4. $\displaystyle D = -3(2 - x) + 4x$
5. $\displaystyle E = x(x - 2) - 2(x - 2)$
6. $\displaystyle F = (x + 1)(x - 1) - x^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : L'expression A

::: methode
Un « − » devant une parenthèse change le signe de chaque terme.
:::

::: etape $\displaystyle A = 5 - 2x + 3$
:::

::: resultat
$$A = 8 - 2x$$
:::

## Question 2 : L'expression B

::: etape $\displaystyle B = 3x + x - 4$
:::

::: resultat
$$B = 4x - 4$$
:::

## Question 3 : L'expression C

::: etape $\displaystyle C = 2x - 2 - x - 5$
:::

::: resultat
$$C = x - 7$$
:::

**Erreur fréquente :** Écrire $-x + 5$ en supprimant la seconde parenthèse : le signe « − » s'applique AUSSI au $5$.

## Question 4 : L'expression D

::: etape $-3 \times 2 = -6$ et $-3 \times (-x) = 3x$.
:::

::: etape $\displaystyle D = -6 + 3x + 4x$
:::

::: resultat
$$D = 7x - 6$$
:::

## Question 5 : L'expression E

::: etape $x(x - 2) = x^2 - 2x$ et $-2(x - 2) = -2x + 4$.
:::

::: resultat
$$E = x^2 - 4x + 4$$
:::

## Question 6 : L'expression F

::: etape $\displaystyle (x + 1)(x - 1) = x^2 - x + x - 1 = x^2 - 1$
:::

::: etape $\displaystyle F = x^2 - 1 - x^2$
:::

::: resultat
$F = -1$ : l'expression vaut toujours $-1$, quel que soit $x$.
:::

**Vérification :** Pour $x = 5$ : $6 \times 4 - 25 = -1$

**À retenir :** Après développement, une expression peut devenir une constante : elle ne dépend plus de $x$.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 8 - 2x$
2. $\displaystyle 4x - 4$
3. $\displaystyle x - 7$
4. $\displaystyle 7x - 6$
5. $\displaystyle x^2 - 4x + 4$
6. $\displaystyle -1$

=== Entraînement - Calcul littéral - 6. Les tables alignées
Id: 2591
Difficulté: medium
Image: calcul_litteral_4e_tables.png

Énoncé:
<!-- optitab:1 -->
Pour un repas, on aligne des tables carrées. Une personne peut s'asseoir de chaque côté libre d'une table.

[IMAGE_1]

1. Combien de personnes peut-on asseoir avec $\displaystyle 1$, $\displaystyle 2$ et $\displaystyle 3$ tables ?
2. Montrer qu'avec $\displaystyle n$ tables, on peut asseoir $\displaystyle 2n + 2$ personnes.
3. Combien de personnes avec $\displaystyle 50$ tables ?
4. Combien de tables faut-il pour asseoir $\displaystyle 30$ personnes ?
5. Léa propose l'expression $4n - 2(n - 1)$. Expliquer son raisonnement, puis montrer qu'elle a raison.
6. Hugo propose $\displaystyle 2(n + 1)$. Montrer que les trois expressions sont égales.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les premiers cas

::: etape $\displaystyle 1$ table
$4$ places ; $2$ tables : $6$ places ; $3$ tables : $8$ places.
:::

::: resultat
$4$ ; $6$ ; $8$
:::

## Question 2 : Le cas général

::: etape
Il y a $n$ places d'un côté de la rangée, $n$ de l'autre, et $2$ aux deux bouts.
:::

::: resultat
$\displaystyle n + n + 2 = 2n + 2$ personnes.
:::

## Question 3 : Avec 50 tables

::: etape $\displaystyle 2 \times 50 + 2$
:::

::: resultat
$\displaystyle 102$ personnes
:::

## Question 4 : Pour 30 personnes

::: etape $2n + 2 = 30$, donc $2n = 28$.
:::

::: resultat
$\displaystyle n = 14$ tables.
:::

## Question 5 : L'expression de Léa

::: etape
Léa compte $4$ places par table ($4n$), puis enlève $2$ places à chaque jonction entre deux tables : il y a $n - 1$ jonctions.
:::

::: etape $\displaystyle 4n - 2(n - 1) = 4n - 2n + 2 = 2n + 2$
:::

::: resultat
Léa a raison.
:::

**À retenir :** Un même dénombrement peut se faire de plusieurs façons ; le développement prouve qu'elles donnent le même résultat.

## Question 6 : L'expression de Hugo

::: etape $\displaystyle 2(n + 1) = 2n + 2$
:::

::: resultat
Les trois expressions sont égales : Hugo a écrit la forme factorisée.
:::

**Erreur fréquente :** Croire qu'une seule des trois réponses est la « bonne » : des expressions égales sont toutes justes.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 4, 6, 8$
2. $\displaystyle 2n + 2$
3. $\displaystyle 102$
4. $\displaystyle 14$ tables
5. $\displaystyle 4n - 2(n - 1) = 2n + 2$
6. $\displaystyle 2(n + 1) = 2n + 2$

=== Entraînement - Calcul littéral - 7. Démontrer des propriétés des nombres
Id: 2592
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On utilise des lettres pour démontrer des propriétés vraies pour tous les nombres entiers. On note $n$ un nombre entier.

1. Calculer la somme de $\displaystyle 7$, $\displaystyle 8$ et $\displaystyle 9$. Est-elle un multiple de $\displaystyle 3$ ?
2. Démontrer que la somme de trois entiers consécutifs $n$, $n + 1$ et $n + 2$ est toujours un multiple de $3$.
3. Calculer $\displaystyle 11 + 13$. Est-ce un multiple de $\displaystyle 4$ ?
4. Deux nombres impairs consécutifs s'écrivent $2n + 1$ et $2n + 3$. Démontrer que leur somme est toujours un multiple de $4$.
5. Calculer $\displaystyle 4 \times 5 + 5$. Comparer avec $\displaystyle 5^2$.
6. Démontrer que $\displaystyle n(n + 1) + (n + 1) = (n + 1)^2$ pour tout entier $\displaystyle n$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Un premier essai

::: etape $\displaystyle 7 + 8 + 9 = 24 = 3 \times 8$
:::

::: resultat
Oui, $24$ est un multiple de $3$.
:::

## Question 2 : La preuve

::: etape $\displaystyle n + (n + 1) + (n + 2) = 3n + 3$
:::

::: etape $\displaystyle 3n + 3 = 3(n + 1)$
:::

::: resultat
La somme s'écrit $3 \times (n + 1)$ : c'est un multiple de $3$, pour tout entier $n$.
:::

**À retenir :** Pour montrer qu'un nombre est multiple de $3$, on l'écrit sous la forme $3 \times (\text{entier})$.

## Question 3 : Deux impairs

::: etape $\displaystyle 11 + 13 = 24 = 4 \times 6$
:::

::: resultat
Oui.
:::

## Question 4 : La preuve pour les impairs

::: etape $\displaystyle (2n + 1) + (2n + 3) = 4n + 4$
:::

::: etape $\displaystyle 4n + 4 = 4(n + 1)$
:::

::: resultat
La somme est toujours un multiple de $4$.
:::

## Question 5 : Un produit plus un nombre

::: etape $\displaystyle 4 \times 5 + 5 = 20 + 5 = 25$
:::

::: resultat
$25 = 5^2$ : on obtient le carré du plus grand des deux nombres.
:::

## Question 6 : La preuve

::: etape $\displaystyle n(n + 1) + (n + 1) = n^2 + n + n + 1 = n^2 + 2n + 1$
:::

::: etape $\displaystyle (n + 1)^2 = (n + 1)(n + 1) = n^2 + n + n + 1 = n^2 + 2n + 1$
:::

::: resultat
Les deux expressions sont égales : la propriété est vraie pour tout $n$.
:::

**Erreur fréquente :** Penser que les essais des questions 1, 3 et 5 suffisent : ils ne vérifient qu'un seul cas chacun.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 24 = 3 \times 8$
2. $\displaystyle 3n + 3 = 3(n + 1)$
3. $\displaystyle 24 = 4 \times 6$
4. $\displaystyle 4(n + 1)$
5. $\displaystyle 25 = 5^2$
6. Les deux valent $\displaystyle n^2 + 2n + 1$

=== Problème - Calcul littéral - 1. La piscine et sa margelle

Difficulté: hard
Image: calcul_litteral_4e_piscine.png

Énoncé:
<!-- optitab:1 -->
Un bassin rectangulaire mesure $2x$ mètres sur $x$ mètres. Il est entouré d'une margelle (un rebord dallé) de $1$ m de large.

[IMAGE_1]

1. Exprimer les dimensions du rectangle formé par le bassin et la margelle.

7. Expliquer l'expression $\displaystyle 6x + 4$ à l'aide du périmètre du bassin.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les dimensions extérieures

::: etape On ajoute $\displaystyle 1$ m de chaque côté
$2x + 2$ et $x + 2$.
:::

::: resultat
$2x + 2$ sur $x + 2$.
:::

## Question 2 : L'aire du grand rectangle

::: etape $\displaystyle (2x + 2)(x + 2) = 2x \times x + 2x \times 2 + 2 \times x + 2 \times 2$
:::

::: etape $\displaystyle = 2x^2 + 4x + 2x + 4$
:::

::: resultat
$$2x^2 + 6x + 4$$
:::

## Question 3 : L'aire de la margelle

::: etape Aire du bassin
$\displaystyle 2x \times x = 2x^2$.

::: etape $\displaystyle 2x^2 + 6x + 4 - 2x^2$
:::

::: resultat
$$6x + 4$$
:::

::: etape $\displaystyle 6 \times 4 + 4 = 28$ m².
:::

::: etape Vérification
$$10 \times 6 - 8 \times 4 = 60 - 32 = 28$$

::: resultat
$\displaystyle 28$ m²
:::

## Question 5 : Le prix

::: etape $\displaystyle 28 \times 45$
:::

::: resultat
$\displaystyle 1\,260$ €
:::

## Question 6 : Une margelle de 40 m²

::: resultat
$x = 6$ : le bassin mesure $12$ m sur $6$ m.

**Vérification :** $\displaystyle 14 \times 8 - 12 \times 6 = 112 - 72 = 40$

les bandes de $1$ m le long des côtés ont une aire de $6x$.

::: resultat
Margelle = bandes le long des côtés ($6x$) + quatre coins ($4$).
:::

**À retenir :** Interpréter chaque terme d'une expression aide à vérifier qu'elle est juste.

Solution:
<!-- optitab:1 -->

3. $\displaystyle 6x + 4$

=== Problème - Calcul littéral - 2. Le carré magique littéral

Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère le tableau suivant, où $\displaystyle x$ est un nombre quelconque.

[IMAGE_1]

1. Calculer et réduire la somme de chaque ligne.
2. Calculer et réduire la somme de chaque colonne.
3. Calculer et réduire la somme de chaque diagonale. Le carré est-il magique ?

<!-- optitab:1 -->
## Question 1 : Les lignes

::: etape $\displaystyle (x - 3) + (x + 2) + (x + 1) = 3x + 0 = 3x$
:::

::: etape $(x + 4) + x + (x - 4) = 3x$ et $(x - 1) + (x - 2) + (x + 3) = 3x$
:::

::: resultat
Chaque ligne a pour somme $\displaystyle 3x$.
:::

## Question 2 : Les colonnes

::: etape $\displaystyle (x - 3) + (x + 4) + (x - 1) = 3x$
:::

::: etape $(x + 2) + x + (x - 2) = 3x$ et $(x + 1) + (x - 4) + (x + 3) = 3x$
:::

::: resultat
Chaque colonne a pour somme $\displaystyle 3x$.
:::

## Question 3 : Les diagonales

::: etape $(x - 3) + x + (x + 3) = 3x$ et $(x + 1) + x + (x - 1) = 3x$
:::

::: resultat
Toutes les sommes valent $3x$ : le carré est magique quel que soit $x$.
:::

$2, 7, 6$ ; ligne 2 : $9, 5, 1$ ; ligne 3 : $4, 3, 8$.

::: etape $3x = 30$, donc $x = 10$.
:::

::: etape Ligne 1
$7, 12, 11$ ; ligne 2 : $14, 10, 6$ ; ligne 3 : $9, 8, 13$.
:::

::: resultat
$x = 10$ : les nombres de $6$ à $14$.
:::

::: etape Ligne 1
$-5, 0, -1$ ; ligne 2 : $2, -2, -6$ ; ligne 3 : $-3, -4, 1$.
:::

::: etape Ligne 1
$$-5 + 0 + (-1) = -6 = 3 \times (-2)$$
:::

::: resultat
Le carré reste magique, de somme $-6$.
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 3x$ pour chaque ligne
2. $\displaystyle 3x$ pour chaque colonne
3. Oui, somme magique $\displaystyle 3x$
4. $2, 7, 6 / 9, 5, 1 / 4, 3, 8$ ; somme $15$
5. $\displaystyle x = 10$
6. Somme $\displaystyle -6$

=== Problème - Calcul littéral - 3. Le tour de magie
Id: 2595
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un magicien propose : « Choisis un nombre entier. Calcule son carré. Retire le carré du nombre qui le précède. Donne-moi le résultat : je devine ton nombre ! »

1. Faire le tour avec $\displaystyle 7$, puis avec $\displaystyle 10$.
2. Développer $\displaystyle (n - 1)^2$ à l'aide de la double distributivité.
3. Démontrer que le résultat du tour est toujours $\displaystyle 2n - 1$.
4. Un spectateur annonce $\displaystyle 25$. Quel nombre avait-il choisi ?
5. Expliquer la méthode du magicien pour deviner le nombre.
6. Utiliser ce résultat pour calculer mentalement $\displaystyle 51^2 - 50^2$ et $\displaystyle 1\,001^2 - 1\,000^2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux essais

::: etape Avec $\displaystyle 7$
$\displaystyle 7^2 - 6^2 = 49 - 36 = 13$.
:::

::: etape Avec $\displaystyle 10$
$\displaystyle 10^2 - 9^2 = 100 - 81 = 19$.
:::

::: resultat
$13$ et $19$.
:::

## Question 2 : Développer (n − 1)²

::: etape $\displaystyle (n - 1)(n - 1) = n^2 - n - n + 1$
:::

::: resultat
$$(n - 1)^2 = n^2 - 2n + 1$$
:::

**Erreur fréquente :** Écrire $(n - 1)^2 = n^2 - 1$ : on oublie le double produit $-2n$.

## Question 3 : La démonstration

::: etape $\displaystyle n^2 - (n - 1)^2 = n^2 - (n^2 - 2n + 1)$
:::

::: etape $\displaystyle = n^2 - n^2 + 2n - 1$
:::

::: resultat
Le résultat vaut toujours $\displaystyle 2n - 1$.
:::

**Vérification :** $n = 7$ : $2 \times 7 - 1 = 13$ ; $n = 10$ : $19$

## Question 4 : Retrouver le nombre

::: etape $2n - 1 = 25$, donc $2n = 26$.
:::

::: resultat
$$n = 13$$
:::

## Question 5 : La méthode du magicien

::: etape Si le résultat vaut $2n - 1$, alors $(2n - 1 + 1) : 2 = n$.
:::

::: resultat
Il ajoute $1$ au résultat, puis divise par $2$.
:::

**À retenir :** Pour « défaire » un calcul, on applique les opérations inverses dans l'ordre inverse.

## Question 6 : Calcul mental

::: etape $\displaystyle 51^2 - 50^2 = 2 \times 51 - 1 = 101$.
:::

::: etape $\displaystyle 1\,001^2 - 1\,000^2 = 2 \times 1\,001 - 1 = 2\,001$.
:::

::: resultat
$101$ et $2\,001$.
:::

Solution:
<!-- optitab:1 -->
1. $13$ ; $19$
2. $\displaystyle n^2 - 2n + 1$
3. $\displaystyle 2n - 1$
4. $\displaystyle 13$
5. Ajouter $1$, puis diviser par $2$
6. $101$ ; $2\,001$

=== Problème - Calcul littéral - 4. Du calcul mental grâce au calcul littéral
Id: 2596
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
La double distributivité permet de calculer mentalement certains produits.

1. Développer $\displaystyle (a + 1)(a - 1)$. En déduire $\displaystyle 21 \times 19$.
2. Développer $\displaystyle (a + b)(a - b)$.
3. En déduire $\displaystyle 102 \times 98$ sans calculatrice.
4. Développer $\displaystyle (a + 1)^2$. En déduire $\displaystyle 31^2$.
5. Développer $\displaystyle (a - 1)^2$. En déduire $\displaystyle 99^2$.
6. Calculer $\displaystyle 48 \times 52$ avec la question 2.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le produit (a + 1)(a − 1)

::: etape $\displaystyle a \times a - a \times 1 + 1 \times a - 1 \times 1 = a^2 - a + a - 1$
:::

::: etape $\displaystyle = a^2 - 1$
:::

::: resultat
$(a + 1)(a - 1) = a^2 - 1$, donc $21 \times 19 = (20 + 1)(20 - 1) = 400 - 1 = 399$.
:::

## Question 2 : Le produit (a + b)(a − b)

::: etape $\displaystyle a^2 - ab + ab - b^2$
:::

::: resultat
$$(a + b)(a - b) = a^2 - b^2$$
:::

## Question 3 : Le produit 102 × 98

::: etape $\displaystyle 102 \times 98 = (100 + 2)(100 - 2)$
:::

::: etape $\displaystyle = 100^2 - 2^2 = 10\,000 - 4$
:::

::: resultat
$$9\,996$$
:::

## Question 4 : Le carré 31²

::: etape $\displaystyle (a + 1)^2 = a^2 + a + a + 1 = a^2 + 2a + 1$
:::

::: etape $\displaystyle 31^2 = (30 + 1)^2 = 900 + 60 + 1$
:::

::: resultat
$$961$$
:::

## Question 5 : Le carré 99²

::: etape $\displaystyle (a - 1)^2 = a^2 - 2a + 1$
:::

::: etape $\displaystyle 99^2 = (100 - 1)^2 = 10\,000 - 200 + 1$
:::

::: resultat
$$9\,801$$
:::

**Erreur fréquente :** Écrire $99^2 = 10\,000 - 1$ : on oublie le terme $-2a = -200$.

## Question 6 : Le produit 48 × 52

::: etape $\displaystyle 48 \times 52 = (50 - 2)(50 + 2) = 50^2 - 2^2$
:::

::: etape $\displaystyle = 2\,500 - 4$
:::

::: resultat
$$2\,496$$
:::

**À retenir :** Repérer deux nombres symétriques autour d'un nombre rond ($48$ et $52$ autour de $50$) permet d'utiliser $(a + b)(a - b) = a^2 - b^2$.

Solution:
<!-- optitab:1 -->
1. $a^2 - 1$ ; $399$
2. $\displaystyle a^2 - b^2$
3. $\displaystyle 9\,996$
4. $\displaystyle 961$
5. $\displaystyle 9\,801$
6. $\displaystyle 2\,496$

=== Problème - Calcul littéral - 5. La boîte sans couvercle
Id: 2597
Difficulté: hard
Image: calcul_litteral_4e_boite.png

Énoncé:
<!-- optitab:1 -->
Dans une plaque de carton de $30$ cm sur $20$ cm, on découpe un carré de côté $x$ cm à chaque coin, puis on plie les bords pour former une boîte sans couvercle.

[IMAGE_1]

1. Pour $\displaystyle x = 3$, donner les dimensions de la boîte (longueur, largeur, hauteur).
2. Calculer le volume de la boîte pour $\displaystyle x = 3$.
3. Exprimer, en fonction de $\displaystyle x$, la longueur et la largeur du fond de la boîte.
4. Développer et réduire l'aire du fond $\displaystyle (30 - 2x)(20 - 2x)$. Vérifier avec $\displaystyle x = 4$.
5. Calculer le volume de la boîte pour $x = 1$, $2$, $4$, $5$ et $6$. Quelle valeur entière de $x$ donne le plus grand volume ?
6. Quelles sont les valeurs possibles de $\displaystyle x$ ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les dimensions pour x = 3

::: etape Longueur
$30 - 2 \times 3 = 24$ cm ; largeur : $20 - 2 \times 3 = 14$ cm.
:::

::: etape La hauteur est le côté du carré découpé.
:::

::: resultat
$24$ cm ; $14$ cm ; $3$ cm.
:::

## Question 2 : Le volume pour x = 3

::: etape $\displaystyle 24 \times 14 \times 3 = 336 \times 3$
:::

::: resultat
$\displaystyle 1\,008$ cm³
:::

## Question 3 : Le fond en fonction de x

::: etape On retire $x$ à chaque extrémité de chaque côté.
:::

::: resultat
Longueur $30 - 2x$ ; largeur $20 - 2x$.
:::

## Question 4 : L'aire du fond

::: etape $\displaystyle 30 \times 20 - 30 \times 2x - 2x \times 20 + 2x \times 2x = 600 - 60x - 40x + 4x^2$
:::

::: etape Vérification pour $\displaystyle x = 4$
$4 \times 16 - 100 \times 4 + 600 = 264$ et $22 \times 12 = 264$
:::

::: resultat
$$4x^2 - 100x + 600$$
:::

## Question 5 : Le meilleur volume

::: methode
Volume = aire du fond × hauteur $= x(30 - 2x)(20 - 2x)$.
:::

::: etape $\displaystyle x = 1$
$1 \times 28 \times 18 = 504$ ; $x = 2$ : $2 \times 26 \times 16 = 832$.
:::

::: etape $\displaystyle x = 4$
$4 \times 22 \times 12 = 1\,056$ ; $x = 5$ : $5 \times 20 \times 10 = 1\,000$ ; $x = 6$ : $6 \times 18 \times 8 = 864$.
:::

::: resultat
Parmi les entiers, $x = 4$ donne le plus grand volume : $1\,056$ cm³.
:::

**À retenir :** Un tableau de valeurs permet de repérer où une grandeur est la plus grande.

## Question 6 : Les valeurs possibles

::: etape
Il faut $x > 0$ (on découpe vraiment) et $20 - 2x > 0$, c'est-à-dire $x < 10$.
:::

::: resultat
$x$ doit être compris entre $0$ et $10$ (exclus).
:::

**Erreur fréquente :** Ne regarder que la longueur ($30 - 2x > 0$, soit $x < 15$) : c'est la largeur qui limite.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 24 \times 14 \times 3$
2. $\displaystyle 1\,008$ cm³
3. $30 - 2x$ et $20 - 2x$
4. $\displaystyle 4x^2 - 100x + 600$
5. $x = 4$ ($1\,056$ cm³)
6. $\displaystyle 0 < x < 10$

=== Problème - Calcul littéral - 6. Même périmètre, aires différentes
Id: 2598
Difficulté: hard
Image: calcul_litteral_4e_deux_rectangles.png

Énoncé:
<!-- optitab:1 -->
On compare le rectangle $\displaystyle A$, de dimensions $\displaystyle x + 5$ et $\displaystyle x + 1$, et le carré $\displaystyle B$, de côté $\displaystyle x + 3$ (en cm, avec $\displaystyle x > 0$).

[IMAGE_1]

1. Calculer le périmètre de $\displaystyle A$ et celui de $\displaystyle B$ pour $\displaystyle x = 2$.
2. Exprimer les deux périmètres en fonction de $\displaystyle x$. Que remarque-t-on ?
3. Calculer les deux aires pour $\displaystyle x = 2$.
4. Exprimer l'aire de $\displaystyle A$ en fonction de $\displaystyle x$, sous forme développée.
5. Exprimer l'aire de $\displaystyle B$ en fonction de $\displaystyle x$, sous forme développée.
6. Démontrer que $B$ a toujours une aire plus grande que $A$, et préciser de combien.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les périmètres pour x = 2

::: etape $\displaystyle A$
$7$ sur $3$, périmètre $2 \times (7 + 3) = 20$ cm.
:::

::: etape $\displaystyle B$
côté $5$, périmètre $4 \times 5 = 20$ cm.
:::

::: resultat
$20$ cm et $20$ cm.
:::

## Question 2 : Les périmètres en fonction de x

::: etape $\displaystyle A$
$\displaystyle 2(x + 5 + x + 1) = 2(2x + 6) = 4x + 12$.
:::

::: etape $\displaystyle B$
$\displaystyle 4(x + 3) = 4x + 12$.
:::

::: resultat
Les deux périmètres sont toujours égaux.
:::

## Question 3 : Les aires pour x = 2

::: etape $\displaystyle A$
$7 \times 3 = 21$ cm² ; $B$ : $5^2 = 25$ cm².
:::

::: resultat
$21$ cm² et $25$ cm².
:::

## Question 4 : L'aire de A

::: etape $\displaystyle (x + 5)(x + 1) = x^2 + x + 5x + 5$
:::

::: resultat
$$x^2 + 6x + 5$$
:::

## Question 5 : L'aire de B

::: etape $\displaystyle (x + 3)^2 = (x + 3)(x + 3) = x^2 + 3x + 3x + 9$
:::

::: resultat
$$x^2 + 6x + 9$$
:::

## Question 6 : La comparaison

::: etape $\displaystyle (x^2 + 6x + 9) - (x^2 + 6x + 5) = 9 - 5 = 4$
:::

::: resultat
Le carré $B$ a toujours $4$ cm² de plus que le rectangle $A$.
:::

**Vérification :** Pour $x = 2$ : $25 - 21 = 4$

**À retenir :** Pour comparer deux expressions, on calcule leur différence et on la réduit.

Solution:
<!-- optitab:1 -->
1. $20$ cm ; $20$ cm
2. $\displaystyle 4x + 12$ pour les deux
3. $21$ ; $25$
4. $\displaystyle x^2 + 6x + 5$
5. $\displaystyle x^2 + 6x + 9$
6. $B - A = 4$ cm² pour tout $x$

=== Problème - Calcul littéral - 7. Choisir le bon tarif
Id: 2599
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une piscine propose trois tarifs. Tarif A : $8$ € l'entrée. Tarif B : un abonnement annuel de $30$ € puis $5$ € l'entrée. Tarif C : $120$ € par an, entrées illimitées. On note $x$ le nombre d'entrées dans l'année.

1. Exprimer le prix payé avec chaque tarif en fonction de $\displaystyle x$.
2. Calculer le prix de chaque tarif pour $\displaystyle 5$ entrées, puis pour $\displaystyle 20$ entrées.
3. Pour $\displaystyle 10$ entrées, que remarque-t-on ?
4. Montrer que le tarif B coûte autant que le tarif C pour $\displaystyle 18$ entrées.
5. Calculer, pour $x = 30$, l'économie réalisée avec le tarif C par rapport au tarif A.
6. Quel tarif conseiller selon le nombre d'entrées ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les trois expressions

::: etape A
$8$ € par entrée ; B : $30$ € fixes plus $5$ € par entrée ; C : prix fixe.
:::

::: resultat
$P_A = 8x$ ; $P_B = 30 + 5x$ ; $P_C = 120$.
:::

## Question 2 : Deux exemples

::: etape $\displaystyle x = 5$
A $= 40$ € ; B $= 30 + 25 = 55$ € ; C $= 120$ €.
:::

::: etape $\displaystyle x = 20$
A $= 160$ € ; B $= 30 + 100 = 130$ € ; C $= 120$ €.
:::

::: resultat
Pour $5$ entrées, A est le moins cher ; pour $20$ entrées, C est le moins cher.
:::

## Question 3 : Pour 10 entrées

::: etape A
$8 \times 10 = 80$ € ; B : $30 + 50 = 80$ €.
:::

::: resultat
Les tarifs A et B coûtent le même prix ($80$ €).
:::

## Question 4 : B contre C

::: etape $\displaystyle 30 + 5 \times 18 = 30 + 90 = 120$
:::

::: resultat
Pour $18$ entrées, B et C coûtent tous deux $120$ €.
:::

## Question 5 : L'économie pour 30 entrées

::: etape A
$8 \times 30 = 240$ € ; C : $120$ €.
:::

::: resultat
$\displaystyle 240 - 120 = 120$ € d'économie.
:::

## Question 6 : Le conseil

::: etape Moins de $\displaystyle 10$ entrées
A ; de $10$ à $18$ entrées : B (A et B égaux à $10$) ; plus de $18$ entrées : C.
:::

::: resultat
Tarif A jusqu'à $10$ entrées, B entre $10$ et $18$, C au-delà de $18$ entrées.
:::

**À retenir :** Traduire chaque tarif par une expression permet de les comparer pour n'importe quel nombre d'entrées.

**Erreur fréquente :** Choisir C « parce qu'il est illimité » : pour quelques entrées, c'est le plus cher !

Solution:
<!-- optitab:1 -->
1. $8x$ ; $30 + 5x$ ; $120$
2. $5$ : $40 / 55 / 120$ ; $20$ : $160 / 130 / 120$
3. A et B : $\displaystyle 80$ €
4. $\displaystyle 120$ € tous les deux
5. $\displaystyle 120$ €
6. A si $\displaystyle x 18$
