===Résumé Les primitives Terminale

Titre: Résumé : Les primitives

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : définition, primitives à une constante près, tableau usuel et formes composées. Programme de Terminale.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$F$ primitive de $f$ $\iff F' = f$ ; toutes les primitives : $F + C$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Une condition $F(x_0) = y_0$ fixe la constante $C$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $x^n \to \frac{x^{n+1}}{n + 1}$ ; $\frac{1}{x} \to \ln x$ ; $\frac{1}{x^2} \to -\frac{1}{x}$ ; $\frac{1}{\sqrt{x}} \to 2\sqrt{x}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $e^x \to e^x$ ; $\cos x \to \sin x$ ; $\sin x \to -\cos x$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Formes composées</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $u'u^n \to \frac{u^{n+1}}{n + 1}$ ; $\frac{u'}{u^2} \to -\frac{1}{u}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\frac{u'}{u} \to \ln u$ ($u \gt 0$) ; $\frac{u'}{\sqrt{u}} \to 2\sqrt{u}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $u'e^u \to e^u$ ; $e^{ax + b} \to \frac{1}{a}e^{ax + b}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Dériver au lieu de primitiver.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier la constante d’ajustement : $xe^{x^2} \to \frac{1}{2}e^{x^2}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier le signe moins : $\sin x \to -\cos x$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Écrire $\ln u$ sans vérifier que $u \gt 0$ sur l’intervalle.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je repère $u$ et $u'$, j’ajuste par une constante, puis je vérifie en dérivant.</p>
</div>
