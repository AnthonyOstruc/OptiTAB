Titre: Factorisation & Mise en Forme Factorisée - Méthodes et Techniques

<!-- optitab:1 -->
## Introduction

La **factorisation** consiste à transformer une **somme** ou une **différence** en un **produit** de facteurs. C'est l'opération inverse du développement.

::: definition Idée clé
: Factoriser, c'est trouver un **facteur commun** ou reconnaître une **forme remarquable** pour écrire une expression sous forme de produit.
:::

## I. Factorisation par facteur commun

### Principe

::: methode
Identifier un facteur commun à tous les termes et le mettre en évidence
:::

::: methode Démarche
1. **Observer :** tous les termes ont-ils un facteur commun ? (nombre, lettre, expression)
2. **Identifier :** trouver le **PGCD** des coefficients et les lettres communes avec le plus petit exposant
3. **Factoriser :** mettre le facteur commun devant une parenthèse
4. **Vérifier :** développer pour valider le résultat
:::

::: exemple
Factoriser $\displaystyle 3x + 6$

::: exemple
Facteur commun : $3$ (car $3x = 3 \times x$ et $6 = 3 \times 2$)
:::

$$\displaystyle 3x + 6 = 3(x + 2)$$
:::

::: exemple
Factoriser $\displaystyle 5x^2 - 10x$

::: exemple
Facteur commun : $5x$ (coefficient $5$ et $x$ avec exposant $1$)
:::

$$\displaystyle 5x^2 - 10x = 5x(x - 2)$$
:::

::: exemple
Factoriser $\displaystyle 4x^3 + 8x^2 - 12x$

::: etape
Facteur commun numérique : $PGCD(4, 8, 12) = 4$ **Étape 2 :** Facteur commun littéral : $x$ avec exposant $1$ (plus petit exposant)
:::

::: exemple
Facteur commun : $\displaystyle 4x$
:::

$$\displaystyle 4x^3 + 8x^2 - 12x = 4x(x^2 + 2x - 3)$$
:::

::: exemple
Factoriser $\displaystyle 2(x+1) + 3(x+1)$

::: exemple
Facteur commun : $\displaystyle (x+1)$
:::

$$\displaystyle 2(x+1) + 3(x+1) = (x+1)(2 + 3) = (x+1) \times 5 = 5(x+1)$$
:::

## II. Factorisation par groupement

### Principe

::: methode
Grouper les termes par paires qui ont un facteur commun, puis factoriser chaque groupe
:::

::: exemple
Factoriser $\displaystyle ax + ay + bx + by$

::: etape
Grouper : $(ax + ay) + (bx + by)$ **Étape 2 :** Facteur commun dans chaque groupe : $a(x+y) + b(x+y)$
:::

$$\displaystyle ax + ay + bx + by = a(x+y) + b(x+y) = (x+y)(a+b)$$
:::

::: exemple
Factoriser $\displaystyle x^2 + 3x + 2x + 6$

::: etape
Grouper : $(x^2 + 3x) + (2x + 6)$ **Étape 2 :** Facteur commun : $x(x+3) + 2(x+3)$
:::

$$\displaystyle x^2 + 3x + 2x + 6 = x(x+3) + 2(x+3) = (x+3)(x+2)$$
:::

::: exemple
Factoriser $\displaystyle 2x^2 - 4x + 3x - 6$

::: etape
Grouper : $(2x^2 - 4x) + (3x - 6)$ **Étape 2 :** Facteur commun : $2x(x-2) + 3(x-2)$
:::

$$\displaystyle 2x^2 - 4x + 3x - 6 = 2x(x-2) + 3(x-2) = (x-2)(2x+3)$$
:::

## III. Factorisation avec les identités remarquables

### Reconnaître les formes

::: definition Les trois identités remarquables
:::

::: definition
$$a^2 + 2ab + b^2 = (a+b)^2$$
:::

::: definition
$$a^2 - 2ab + b^2 = (a-b)^2$$
:::

::: definition
$$a^2 - b^2 = (a+b)(a-b)$$
:::

::: exemple
Factoriser $\displaystyle x^2 + 6x + 9$

::: exemple
Reconnaître : $a^2 + 2ab + b^2$ avec $a=x$, $b=3$ (car $9 = 3^2$ et $6x = 2 \times x \times 3$)
:::

$$\displaystyle x^2 + 6x + 9 = (x + 3)^2$$
:::

::: exemple
Factoriser $\displaystyle 4x^2 - 12x + 9$

::: exemple
Reconnaître : $a^2 - 2ab + b^2$ avec $a=2x$, $b=3$ (car $4x^2 = (2x)^2$, $9 = 3^2$, $12x = 2 \times 2x \times 3$)
:::

$$\displaystyle 4x^2 - 12x + 9 = (2x - 3)^2$$
:::

::: exemple
Factoriser $\displaystyle 25x^2 - 16$

::: exemple
Différence de deux carrés : $a^2 - b^2$ avec $a=5x$, $b=4$ (car $25x^2 = (5x)^2$, $16 = 4^2$)
:::

$$\displaystyle 25x^2 - 16 = (5x - 4)(5x + 4)$$
:::

::: conseil
Pour une différence de carrés $a^2 - b^2$, penser à $(a-b)(a+b)$. Pour reconnaître $a^2 \pm 2ab + b^2$, vérifier que le terme du milieu est bien le double produit.
:::

## IV. Factorisation de trinômes du second degré

### Forme générale

::: definition Trinôme
$ax^2 + bx + c$ avec $a \neq 0$
:::

::: methode
Trouver deux nombres $\alpha$ et $\beta$ tels que :

- $\displaystyle \alpha + \beta = \dfrac{b}{a}$ (somme)
- $\displaystyle \alpha \times \beta = \dfrac{c}{a}$ (produit)

Alors : $\displaystyle ax^2 + bx + c = a(x-\alpha)(x-\beta)$
:::

::: methode
$$\Delta = b^2 - 4ac$$

| Condition | Nature des racines | Factorisation |
|---|---|---|
| **$\displaystyle \Delta > 0$** | Deux racines $\displaystyle x_1$ et $\displaystyle x_2$ | $\displaystyle ax^2+bx+c = a(x-x_1)(x-x_2)$ |
| **$\displaystyle \Delta = 0$** | Racine double $\displaystyle x_0$ | $\displaystyle ax^2+bx+c = a(x-x_0)^2$ |
| **$\displaystyle \Delta < 0$** | Pas de racines réelles | Pas de factorisation réelle |
:::

::: exemple (discriminant)
Factoriser $\displaystyle 2x^2 - x - 3$

::: exemple
$a=2$, $b=-1$, $c=-3$ ; $\Delta = (-1)^2 - 4\times 2 \times (-3) = 1 + 24 = 25$ ; $x_1 = \dfrac{1-\sqrt{25}}{4} = -\dfrac{1}{2}$, $x_2 = \dfrac{1+\sqrt{25}}{4} = \dfrac{3}{2}$.
:::

$$\displaystyle 2x^2 - x - 3 = 2\big(x + \dfrac{1}{2}\big)\big(x - \dfrac{3}{2}\big) = (2x+1)(x-3)$$
:::

::: exemple
Factoriser $\displaystyle x^2 + 5x + 6$

::: methode
Chercher deux nombres dont la somme est $5$ et le produit est $6$ Les nombres sont $2$ et $3$ (car $2 + 3 = 5$ et $2 \times 3 = 6$)
:::

$$\displaystyle x^2 + 5x + 6 = (x + 2)(x + 3)$$
:::

::: exemple
Factoriser $\displaystyle x^2 - 7x + 12$

::: methode
Chercher deux nombres dont la somme est $7$ et le produit est $12$ Les nombres sont $3$ et $4$ (car $3 + 4 = 7$ et $3 \times 4 = 12$)
:::

$$\displaystyle x^2 - 7x + 12 = (x - 3)(x - 4)$$
:::

::: exemple
Factoriser $\displaystyle 2x^2 + 7x + 3$

::: etape
$\dfrac{b}{a} = \dfrac{7}{2}$, $\dfrac{c}{a} = \dfrac{3}{2}$ **Étape 2 :** Chercher deux nombres dont la somme est $\dfrac{7}{2}$ et le produit est $\dfrac{3}{2}$ Les nombres sont $\dfrac{1}{2}$ et $3$ (car $\dfrac{1}{2} + 3 = \dfrac{7}{2}$ et $\dfrac{1}{2} \times 3 = \dfrac{3}{2}$)
:::

$$\displaystyle 2x^2 + 7x + 3 = 2\left(x - \left(-\dfrac{1}{2}\right)\right)(x - (-3)) = 2\left(x + \dfrac{1}{2}\right)(x + 3) = (2x + 1)(x + 3)$$
:::

::: attention
Si le trinôme a un coefficient $a \neq 1$, ne pas oublier de factoriser par $a$ avant de chercher les racines !
:::

## V. Mise en forme factorisée

### Principe

::: objectifs
Écrire une expression sous la forme $k(x-\alpha_1)(x-\alpha_2)\cdots(x-\alpha_n)$ où $k$ est un facteur constant et les $\alpha_i$ sont les racines
:::

::: etape
1. **Factoriser :** utiliser les méthodes précédentes (facteur commun, identités, etc.)
2. **Identifier les racines :** valeurs de $x$ qui annulent chaque facteur
3. **Ordonner :** mettre la forme factorisée avec facteur constant en premier
4. **Simplifier :** réduire les expressions dans les facteurs
:::

::: exemple
Mettre sous forme factorisée $3x^2 - 12x$

::: etape Facteur commun : $3x$ **Étape 2 :** Factoriser : $3x(x - 4)$
:::

::: resultat
Forme factorisée : $3x^2 - 12x = 3x(x - 4)$ Racines : $x = 0$ et $x = 4$
:::
:::

::: exemple
Mettre sous forme factorisée $x^2 - 9$

::: exemple
Différence de carrés : $\displaystyle x^2 - 9 = x^2 - 3^2$
:::

::: resultat
Forme factorisée : $x^2 - 9 = (x - 3)(x + 3)$ Racines : $x = 3$ et $x = -3$
:::
:::

::: exemple
Mettre sous forme factorisée $2x^2 + 8x + 8$

::: etape
Facteur commun : $2$ $2x^2 + 8x + 8 = 2(x^2 + 4x + 4)$ **Étape 2 :** Identité remarquable : $x^2 + 4x + 4 = (x + 2)^2$
:::

::: resultat
Forme factorisée : $2x^2 + 8x + 8 = 2(x + 2)^2$ Racine double : $x = -2$
:::
:::

::: exemple
Mettre sous forme factorisée $x^3 - 4x$

::: etape
Facteur commun : $x$ $x^3 - 4x = x(x^2 - 4)$ **Étape 2 :** Différence de carrés : $x^2 - 4 = (x - 2)(x + 2)$
:::

::: resultat
Forme factorisée : $x^3 - 4x = x(x - 2)(x + 2)$ Racines : $x = 0$, $x = 2$, $x = -2$
:::
:::

## VI. Méthode générale et stratégie

::: methode Ordre de recherche à suivre
1. **Facteur commun :** y a-t-il un facteur commun à tous les termes ?
2. **Identités remarquables :** reconnaître $a^2 \pm 2ab + b^2$ ou $a^2 - b^2$
3. **Groupement :** peut-on grouper les termes par paires ?
4. **Trinôme :** pour $ax^2 + bx + c$, chercher deux nombres dont la somme et le produit sont connus
5. **Combinaison :** utiliser plusieurs méthodes successivement
:::

::: exemple
Factoriser $\displaystyle 4x^2 - 12x + 9 - x^2 + 4$

::: etape
Réduire : $4x^2 - 12x + 9 - x^2 + 4 = 3x^2 - 12x + 13$ **Étape 2 :** Identifier : pas de facteur commun évident, pas d'identité remarquable **Étape 3 :** Chercher les racines du trinôme $3x^2 - 12x + 13$
:::

::: attention
Le discriminant $\Delta = (-12)^2 - 4 \times 3 \times 13 = 144 - 156 = -12 < 0$ Ce trinôme n'a pas de racines réelles, donc il n'est pas factorisable dans $\mathbb{R}$.
:::
:::

## VII. Cas particuliers et astuces

::: exemple Cas 1
Factorisation de $x^n - 1$ (avec $n$ pair)

$$\displaystyle x^4 - 1 = (x^2 - 1)(x^2 + 1) = (x-1)(x+1)(x^2 + 1)$$
:::

::: exemple Cas 2
Factorisation avec $\sqrt{x}$ ou expressions complexes

::: resultat
$x\sqrt{x} + 2\sqrt{x} = \sqrt{x}(x + 2)$ (facteur commun $\sqrt{x}$)
:::
:::

::: conseil
- Toujours commencer par chercher un **facteur commun** (numérique et littéral)
- Reconnaître les **formes remarquables** avant de faire des calculs complexes
- Vérifier le résultat en **développant** la forme factorisée
- Pour les trinômes, si le discriminant $\Delta < 0$, la factorisation n'est pas possible dans $\mathbb{R}$
- Dans la forme factorisée, les racines sont les valeurs qui annulent chaque facteur
:::

## VIII. Erreurs fréquentes et conseils

::: attention
- **Oublier le facteur commun :** écrire $2x + 4 = 2(x + 2)$ et non $2x + 4 = 2x + 2$
- **Mauvais signe :** $x^2 - 9 = (x-3)(x+3)$ et non $(x-3)(x-3)$
- **Facteur commun partiel :** dans $2x + 3x$, le facteur commun est $x$, pas $2x$
- **Oublier de factoriser complètement :** $4x^2 - 8x = 4x(x-2)$ et non $2(2x^2 - 4x)$
- **Confondre factorisation et développement :** factoriser transforme une somme en produit
- **Oublier le coefficient :** dans $2x^2 + 4x$, factoriser par $2x$ donne $2x(x+2)$
:::

::: conseil
- Toujours vérifier en **développant** le résultat obtenu
- Pour le facteur commun, prendre le **PGCD** des coefficients et les lettres communes avec le **plus petit exposant**
- Dans une différence de carrés $a^2 - b^2$, penser à $(a-b)(a+b)$
- Pour les trinômes, lister les **diviseurs** du terme constant pour trouver plus rapidement
- La forme factorisée permet de **lire directement les racines** de l'expression
- Si une expression ne se factorise pas dans $\mathbb{R}$, elle peut parfois se factoriser dans $\mathbb{C}$
:::
