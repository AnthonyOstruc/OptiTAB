=== Suites numériques - Programme Première

Titre: Suites numériques

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> définir une suite de façon explicite ou par récurrence, la représenter, étudier son sens de variation, maîtriser les suites arithmétiques et géométriques (terme général, sommes, variations) et approcher intuitivement leur comportement quand $n$ devient grand.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Généralités</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> une <strong>suite</strong> $(u_n)$ associe à chaque entier naturel $n$ un réel $u_n$, appelé <strong>terme de rang $n$</strong>.</p>
            <p style="margin:6px 0 0 0;">• Forme <strong>explicite</strong> : $u_n = f(n)$, on calcule directement chaque terme. Ex. : $u_n = n^2 - 1$ donne $u_3 = 8$.</p>
            <p style="margin:6px 0 0 0;">• Forme <strong>récurrente</strong> : on donne $u_0$ et une relation $u_{n+1} = f(u_n)$. Ex. : $v_0 = 2$ et $v_{n+1} = 3v_n - 1$ donnent $v_1 = 5$ puis $v_2 = 14$.</p>
        </div>
        <p style="font-size:1em;">On représente une suite par le <strong>nuage de points</strong> de coordonnées $(n\,;u_n)$.</p>
        [IMAGE_1]
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> $u_{n+1}$ (terme suivant) n’est pas $u_n + 1$ (terme augmenté de $1$). Avec une forme récurrente, il faut calculer tous les termes précédents pour obtenir $u_{10}$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Sens de variation</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> $(u_n)$ est <strong>croissante</strong> si $u_{n+1} \ge u_n$ pour tout $n$, <strong>décroissante</strong> si $u_{n+1} \le u_n$ pour tout $n$.</p>
        </div>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthodes :</strong> étudier le signe de $u_{n+1} - u_n$ ; si tous les termes sont strictement positifs, comparer $\frac{u_{n+1}}{u_n}$ à $1$ ; si $u_n = f(n)$, utiliser les variations de $f$ sur $[0\,;+\infty[$.
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $u_n = n^2 - 4n$. On calcule $u_{n+1} - u_n = (n + 1)^2 - 4(n + 1) - n^2 + 4n = 2n - 3$, positif dès que $n \ge 2$ : la suite est croissante à partir du rang $2$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Suites arithmétiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition et propriétés :</strong> $(u_n)$ est <strong>arithmétique de raison $r$</strong> si $u_{n+1} = u_n + r$ pour tout $n$. Alors $u_n = u_0 + nr$, et plus généralement $u_n = u_p + (n - p)r$. Elle est croissante si $r \gt 0$, décroissante si $r \lt 0$ ; ses points sont alignés.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $u_0 = 5$ et $r = 3$ : $u_{10} = 5 + 10 \times 3 = 35$.</p>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété (démonstration au programme) :</strong> pour tout entier $n \ge 1$, $1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> on écrit $S = 1 + 2 + \cdots + n$ puis $S = n + (n - 1) + \cdots + 1$. En additionnant terme à terme, on obtient $n$ fois $n + 1$ : $2S = n(n + 1)$.</p>
        </div>
        [IMAGE_2]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À retenir :</strong> $1 + 2 + \cdots + 100 = \frac{100 \times 101}{2} = 5\,050$. Pour des termes consécutifs d’une suite arithmétique : somme $=$ nombre de termes $\times \frac{\text{premier} + \text{dernier}}{2}$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Suites géométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition et propriétés :</strong> $(u_n)$ est <strong>géométrique de raison $q$</strong> si $u_{n+1} = q \times u_n$ pour tout $n$. Alors $u_n = u_0 \times q^n$. Si $u_0 \gt 0$ : croissante quand $q \gt 1$, décroissante quand $0 \lt q \lt 1$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> un capital de $1\,000$ € placé à $3\,\%$ par an devient $u_n = 1\,000 \times 1{,}03^n$ après $n$ années : au bout de $10$ ans, $u_{10} \approx 1\,343{,}92$ €.</p>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété (démonstration au programme) :</strong> pour $q \neq 1$, $1 + q + q^2 + \cdots + q^n = \frac{1 - q^{n+1}}{1 - q}$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> si $S = 1 + q + \cdots + q^n$, alors $qS = q + q^2 + \cdots + q^{n+1}$. Par différence, presque tout se simplifie : $S - qS = 1 - q^{n+1}$, d’où le résultat.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $1 + 2 + 4 + \cdots + 2^9 = \frac{1 - 2^{10}}{1 - 2} = 1\,023$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> la somme $1 + q + \cdots + q^n$ compte $n + 1$ termes, d’où l’exposant $n + 1$. Une hausse de $3\,\%$ correspond à $q = 1{,}03$, pas à $q = 0{,}03$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Comportement quand $n$ devient grand</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">On observe (tableur, calculatrice, graphique) si les termes se rapprochent d’un nombre, ou deviennent aussi grands que l’on veut. Par exemple, $q^n$ se rapproche de $0$ si $0 \lt q \lt 1$, et devient aussi grand que l’on veut si $q \gt 1$.</p>
        [IMAGE_3]
        <p style="font-size:1em;"><strong>Algorithme de seuil :</strong> au bout de combien d’années le capital précédent dépasse-t-il $2\,000$ € ?</p>
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">def seuil(A):
    n = 0
    u = 1000
    while u &lt; A:
        u = 1.03 &#42; u
        n = n + 1
    return n</div>
        <p style="font-size:1em;"><code>seuil(2000)</code> renvoie $24$ : en effet $1\,000 \times 1{,}03^{23} \approx 1\,973{,}59$ et $1\,000 \times 1{,}03^{24} \approx 2\,032{,}79$.</p>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> arithmétique : $u_{n+1} = u_n + r$, $u_n = u_0 + nr$, $1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$ ; géométrique : $u_{n+1} = qu_n$, $u_n = u_0q^n$, $1 + q + \cdots + q^n = \frac{1 - q^{n+1}}{1 - q}$ ; variations par le signe de $u_{n+1} - u_n$ ; un algorithme avec <code>while</code> détermine un seuil. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
