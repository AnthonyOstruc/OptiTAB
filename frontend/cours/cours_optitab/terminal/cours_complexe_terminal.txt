    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition générale d'un nombre complexe</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition formelle</h3>
        
        <p>Un <strong>nombre complexe</strong> est un nombre qui peut s'écrire sous la forme $\displaystyle z = x + y\,\mathrm{i}$ où $x$ et $y$ sont des nombres réels, et $\mathrm{i}$ est l'unité imaginaire définie par $\displaystyle \mathrm{i}^2 = -1$.</p>
        
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p>On dit que $z$ est un <strong>nombre complexe</strong> si :</p>
            <p style="margin:8px 0;">$$\displaystyle z = x + y\,\mathrm{i} \quad \text{avec } x,y \in \mathbb{R}$$</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>Notation :</strong> L'ensemble des nombres complexes est noté $\displaystyle \mathbb{C}$. Le nombre $x$ est appelé <em>partie réelle</em> et $y$ est appelé <em>partie imaginaire</em> de $z$.
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation :</strong> Les nombres complexes étendent l'ensemble des nombres réels en ajoutant une dimension "imaginaire".
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Forme algébrique et propriétés</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>
        
        <p>La <strong>forme algébrique</strong> d'un nombre complexe $z$ est l'écriture $\displaystyle z = x + y\,\mathrm{i}$ où $x = \Re(z)$ et $y = Im(z)$.</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p>On dit que $z$ est sous <strong>forme algébrique</strong> si :</p>
            <p style="margin:8px 0;">$$\displaystyle z = \Re(z) + Im(z)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>⚖️ Égalité de nombres complexes :</strong> Deux nombres complexes sont égaux si et seulement si ils ont la même partie réelle ET la même partie imaginaire :
            <div style="margin:10px 0; text-align:left;">
                $\displaystyle z_1 = z_2 \Leftrightarrow \begin{cases} \Re(z_1) = \Re(z_2) \\ Im(z_1) = Im(z_2) \end{cases}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">$\displaystyle z_1 = 3 + 4\mathrm{i}$ : partie réelle = 3, partie imaginaire = 4</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_2 = -2 + 5\mathrm{i}$ : partie réelle = -2, partie imaginaire = 5</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_3 = 7$ : partie réelle = 7, partie imaginaire = 0 (nombre réel)</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_4 = 2\mathrm{i}$ : partie réelle = 0, partie imaginaire = 2 (imaginaire pur)</li>
            </ul>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriétés :</strong> Un nombre complexe est réel si sa partie imaginaire est nulle, et imaginaire pur si sa partie réelle est nulle.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Opérations sur les nombres complexes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Addition et soustraction</h3>
        
        <p>Pour deux nombres complexes $\displaystyle z_1 = x_1 + y_1\,\mathrm{i}$ et $\displaystyle z_2 = x_2 + y_2\,\mathrm{i}$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p><strong>Addition :</strong></p>
            <p style="margin:8px 0;">$$\displaystyle z_1 + z_2 = (x_1 + x_2) + (y_1 + y_2)\,\mathrm{i}$$</p>
            <p><strong>Soustraction :</strong></p>
            <p style="margin:8px 0;">$$\displaystyle z_1 - z_2 = (x_1 - x_2) + (y_1 - y_2)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle (3 + 2\mathrm{i}) + (1 - 4\mathrm{i}) = (3+1) + (2-4)\mathrm{i} = 4 - 2\mathrm{i}$
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Multiplication</h3>
        
        <p>Pour multiplier deux nombres complexes, on développe en utilisant $\displaystyle \mathrm{i}^2 = -1$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p>$$\displaystyle z_1 \cdot z_2 = (x_1x_2 - y_1y_2) + (x_1y_2 + x_2y_1)\,\mathrm{i}$$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle (2 + 3\mathrm{i})(1 - 2\mathrm{i}) = 2 - 4\mathrm{i} + 3\mathrm{i} - 6\mathrm{i}^2 = 2 - \mathrm{i} + 6 = 8 - \mathrm{i}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Conjugué et module</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conjugué d'un nombre complexe</h3>
        
        <p>Le <strong>conjugué</strong> du nombre complexe $\displaystyle z = x + y\,\mathrm{i}$ est le nombre $\displaystyle \overline{z} = x - y\,\mathrm{i}$.</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle \overline{z} = x - y\,\mathrm{i}$$
        </div>
        
        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriétés du conjugué :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">$\displaystyle \overline{\overline{z}} = z$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \overline{z_1 + z_2} = \overline{z_1} + \overline{z_2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \overline{z_1 \cdot z_2} = \overline{z_1} \cdot \overline{z_2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle z$ est réel si et seulement si $\displaystyle \overline{z} = z$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Module d'un nombre complexe</h3>
        
        <p>Le <strong>module</strong> du nombre complexe $\displaystyle z = x + y\,\mathrm{i}$ est le nombre réel positif $\displaystyle |z| = \sqrt{x^2 + y^2}$.</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle |z| = \sqrt{x^2 + y^2}$$
        </div>
        
        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriétés du module :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">$\displaystyle |z|^2 = z \cdot \overline{z}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle |z_1 \cdot z_2| = |z_1| \cdot |z_2|$</li>
                <li style="margin:0; text-align:left;">$\displaystyle |z_1 + z_2| \leq |z_1| + |z_2|$ (inégalité triangulaire)</li>
                <li style="margin:0; text-align:left;">$\displaystyle |z| = 0$ si et seulement si $\displaystyle z = 0$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Division et inverse</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Inverse d'un nombre complexe</h3>
        
        <p>Pour calculer l'inverse d'un nombre complexe non nul $\displaystyle z = x + y\,\mathrm{i}$, on utilise le conjugué :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle \dfrac{1}{z} = \dfrac{\overline{z}}{|z|^2} = \dfrac{x - y\,\mathrm{i}}{x^2 + y^2}$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle\dfrac{1}{3 + 4\mathrm{i}} = \dfrac{3 - 4\mathrm{i}}{3^2 + 4^2} = \dfrac{3 - 4\mathrm{i}}{25} = \dfrac{3}{25} - \dfrac{4}{25}\mathrm{i}$
        </div>
        </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Division de deux nombres complexes</h3>
        
        <p>Pour diviser $z_1$ par $\displaystyle z_2 \neq 0$, on multiplie le numérateur et le dénominateur par le conjugué du dénominateur :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle \dfrac{z_1}{z_2} = \dfrac{z_1 \cdot \overline{z_2}}{|z_2|^2}$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle \dfrac{2 + \mathrm{i}}{1 - 3\mathrm{i}} = \dfrac{(2 + \mathrm{i})(1 + 3\mathrm{i})}{(1 - 3\mathrm{i})(1 + 3\mathrm{i})} = \dfrac{2 + 6\mathrm{i} + \mathrm{i} + 3\mathrm{i}^2}{1 + 9} = \dfrac{2 + 7\mathrm{i} - 3}{10} = \dfrac{-1 + 7\mathrm{i}}{10}$
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Pourquoi multiplier par le conjugué ?</h3>
        
        <p>Lorsqu'on divise deux nombres complexes, le dénominateur contient généralement une partie imaginaire. Pour obtenir un résultat sous forme algébrique (sans $\mathrm{i}$ au dénominateur), on utilise une <strong>astuce</strong> :</p>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Le principe :</strong> Si $\displaystyle z = x + y\,\mathrm{i}$, alors $\displaystyle z \cdot \overline{z} = (x + y\,\mathrm{i})(x - y\,\mathrm{i}) = x^2 + y^2$ (nombre réel)
        </div>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Explication détaillée :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle (x + y\,\mathrm{i})(x - y\,\mathrm{i}) = x^2 - x \cdot y\,\mathrm{i} + x \cdot y\,\mathrm{i} - y^2\,\mathrm{i}^2$</li>
                <li style="margin:0; text-align:left;">$\displaystyle = x^2 - y^2\,\mathrm{i}^2 = x^2 - y^2(-1) = x^2 + y^2$</li>
            </ul>
            <p style="margin:8px 0;"><strong>Résultat :</strong> Le produit d'un nombre complexe par son conjugué donne toujours un nombre réel positif (le carré du module).</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Application pratique :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Multiplier le numérateur ET le dénominateur par le conjugué du dénominateur</li>
                <li style="margin:0; text-align:left;">Le dénominateur devient un nombre réel (carré du module)</li>
                <li style="margin:0; text-align:left;">On peut alors diviser normalement et obtenir une forme algébrique</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple concret :</strong> Pour $\displaystyle \dfrac{1}{3 + 4\mathrm{i}}$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">Conjugué de $\displaystyle (3 + 4\mathrm{i})$ : $\displaystyle (3 - 4\mathrm{i})$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle (3 + 4\mathrm{i})(3 - 4\mathrm{i}) = 3^2 + 4^2 = 9 + 16 = 25$ (réel !)</li>
                <li style="margin:0; text-align:left;">$\displaystyle \dfrac{1}{3 + 4\mathrm{i}} = \dfrac{3 - 4\mathrm{i}}{25} = \dfrac{3}{25} - \dfrac{4}{25}\mathrm{i}$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode à retenir :</strong> Toujours multiplier par le conjugué du dénominateur pour "rationaliser" et éliminer la partie imaginaire du dénominateur.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Représentation géométrique</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Plan complexe</h3>
        
        <p>À tout nombre complexe $\displaystyle z = x + y\,\mathrm{i}$, on associe le point $M(x, y)$ du plan muni d'un repère orthonormé.</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p>Le <strong>plan complexe</strong> associe :</p>
            <p style="margin:8px 0;">$$\displaystyle z = x + y\,\mathrm{i} \leftrightarrow M(x, y)$$</p>
        </div>

        <div style="text-align:center; margin:20px 0;">
            [IMAGE_1]
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>Interprétation :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">L'axe des abscisses représente les nombres réels</li>
                <li style="margin:0; text-align:left;">L'axe des ordonnées représente les imaginaires purs</li>
                <li style="margin:0; text-align:left;">Le module $\displaystyle |z|$ est la distance $OM$ à l'origine</li>
            </ul>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriété :</strong> Le conjugué $\displaystyle \overline{z}$ correspond au symétrique de $\displaystyle z$ par rapport à l'axe des abscisses.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Argument et forme trigonométrique</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Argument d'un nombre complexe</h3>
        
        <p>Pour $\displaystyle z \neq 0$, un <strong>argument</strong> de $z$ est l'angle orienté $(\vec{u}, \vec{OM})$ où $\vec{u}$ est le vecteur unitaire de l'axe des abscisses.</p>
        

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p>On note $\arg(z)$ l'argument principal :</p>
            <p style="margin:8px 0;">$$\displaystyle \arg(z) \in ]-\pi, \pi]$$</p>
        </div>

        <div style="text-align:center; margin:20px 0;">
        [IMAGE_2]
    </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Calcul de l'argument par quadrants :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Quadrant I</strong> ($x > 0$, $y > 0$) : $\displaystyle \arg(z) = \arctan\left(\dfrac{y}{x}\right) = \theta \in \left]0, \dfrac{\pi}{2}\right[$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Quadrant II</strong> ($x < 0$, $y \geq 0$) : $\displaystyle \arg(z) = \arctan\left(\dfrac{y}{x}\right) + \pi = \pi - \theta \in \left]\dfrac{\pi}{2}, \pi\right]$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Quadrant III</strong> ($x < 0$, $y < 0$) : $\displaystyle \arg(z) = \arctan\left(\dfrac{y}{x}\right) - \pi = -\pi + \theta \in \left]-\pi, -\dfrac{\pi}{2}\right[$</li>
                <li style="margin:0; text-align:left;"><strong>Quadrant IV</strong> ($x > 0$, $y < 0$) : $\displaystyle \arg(z) = \arctan\left(\dfrac{y}{x}\right) = -\theta \in \left]-\dfrac{\pi}{2}, 0\right[$</li>
            </ul>
            <p style="margin:8px 0;"><strong>Où :</strong> $\displaystyle \theta = \arctan\left(\dfrac{|y|}{|x|}\right) \in \left]0, \dfrac{\pi}{2}\right[$</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Cas particuliers sur les axes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Axe réel positif</strong> ($x > 0$, $y = 0$) : $\displaystyle \arg(z) = 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Axe imaginaire positif</strong> ($x = 0$, $y > 0$) : $\displaystyle \arg(z) = \dfrac{\pi}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Axe réel négatif</strong> ($x < 0$, $y = 0$) : $\displaystyle \arg(z) = \pi$</li>
                <li style="margin:0; text-align:left;"><strong>Axe imaginaire négatif</strong> ($x = 0$, $y < 0$) : $\displaystyle \arg(z) = -\dfrac{\pi}{2}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Forme trigonométrique</h3>
        
        <p>Tout nombre complexe $\displaystyle z \neq 0$ peut s'écrire sous forme trigonométrique :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z = |z|(\cos\theta + \mathrm{i}\sin\theta)$$
        </div>
        
        <p>où $\displaystyle \theta = \arg(z)$.</p>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle z = 1 + \mathrm{i}$ a pour module $\displaystyle |z| = \sqrt{2}$ et argument $\displaystyle \arg(z) = \dfrac{\pi}{4}$
            Donc $\displaystyle z = \sqrt{2}\left(\cos\dfrac{\pi}{4} + \mathrm{i}\sin\dfrac{\pi}{4}\right)$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Formule de Moivre et puissances</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formule de Moivre</h3>
        
        <p>Si $\displaystyle z = |z|(\cos\theta + \mathrm{i}\sin\theta)$, alors pour tout entier naturel $n$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z^n = |z|^n(\cos(n\theta) + \mathrm{i}\sin(n\theta))$$
        </div>
        
        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriétés des arguments :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \arg(z_1 \cdot z_2) \equiv \arg(z_1) + \arg(z_2) \pmod{2\pi}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \arg\left(\dfrac{z_1}{z_2}\right) \equiv \arg(z_1) - \arg(z_2) \pmod{2\pi}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \arg(z^n) \equiv n \cdot \arg(z) \pmod{2\pi}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \arg(\overline{z}) \equiv -\arg(z) \pmod{2\pi}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple détaillé : Calcul de puissance</h3>
        
        <p><strong>Énoncé :</strong> Calculer $(1 + \mathrm{i})^8$.</p>
        
        <p><strong>Résolution :</strong></p>
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;"><strong>Étape 1 :</strong> Calculer le module : $\displaystyle |1 + \mathrm{i}| = \sqrt{1^2 + 1^2} = \sqrt{2}$</li>
                <li style="margin:0; text-align:left;"><strong>Étape 2 :</strong> Calculer l'argument : $\displaystyle \arg(1 + \mathrm{i}) = \dfrac{\pi}{4}$</li>
                <li style="margin:0; text-align:left;"><strong>Étape 3 :</strong> Appliquer la formule de Moivre</li>
            </ul>
        </div>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Calcul :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle (1 + \mathrm{i})^8 = (\sqrt{2})^8\left(\cos\left(8 \times \dfrac{\pi}{4}\right) + \mathrm{i}\sin\left(8 \times \dfrac{\pi}{4}\right)\right)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle (1 + \mathrm{i})^8 = (\sqrt{2})^8(\cos(2\pi) + \mathrm{i}\sin(2\pi))$</li>
                <li style="margin:0; text-align:left;">$\displaystyle (1 + \mathrm{i})^8 = 16(1 + 0) = 16$</li>
            </ul>
        </div>
        
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Réponse :</strong> $\displaystyle (1 + \mathrm{i})^8 = 16$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Forme exponentielle </h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formule d'Euler</h3>
        
        <p>La formule d'Euler permet d'écrire :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle e^{\mathrm{i}\theta} = \cos\theta + \mathrm{i}\sin\theta$$
        </div>
        
        <p>Donc tout nombre complexe $\displaystyle z \neq 0$ s'écrit sous <strong>forme exponentielle</strong> :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z = |z| \cdot e^{\mathrm{i}\theta}$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle z = 1 + \mathrm{i} = \sqrt{2} \cdot e^{\mathrm{i}\dfrac{\pi}{4}}$
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Formules d'Euler inversées (linéarisation) :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \cos\theta = \dfrac{e^{\mathrm{i}\theta} + e^{-\mathrm{i}\theta}}{2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \sin\theta = \dfrac{e^{\mathrm{i}\theta} - e^{-\mathrm{i}\theta}}{2\mathrm{i}}$</li>
            </ul>
            <p style="margin:8px 0;">Ces formules permettent de linéariser des expressions trigonométriques et de calculer des puissances de cos et sin.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">X. Formules de sommes et factorisations</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Somme géométrique de raison complexe</h3>
        
        <p>Pour tout nombre complexe $\displaystyle z \neq 1$ et tout entier naturel $n \geq 1$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle 1 + z + z^2 + \cdots + z^{n-1} = \sum_{k=0}^{n-1} z^k = \dfrac{z^n - 1}{z - 1}$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Calculer $\displaystyle S = 1 + e^{\mathrm{i}\dfrac{\pi}{6}} + e^{\mathrm{i}\dfrac{\pi}{3}} + e^{\mathrm{i}\dfrac{\pi}{2}}$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;">On reconnaît une somme géométrique de premier terme $\displaystyle 1$, de raison $\displaystyle q = e^{\mathrm{i}\dfrac{\pi}{6}}$ et de $\displaystyle 4$ termes</li>
                <li style="margin:0; text-align:left;">Application de la formule : $\displaystyle S = \dfrac{e^{\mathrm{i}\dfrac{4\pi}{6}} - 1}{e^{\mathrm{i}\dfrac{\pi}{6}} - 1} = \dfrac{e^{\mathrm{i}\dfrac{2\pi}{3}} - 1}{e^{\mathrm{i}\dfrac{\pi}{6}} - 1}$</li>
            </ul>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Cas particulier :</strong> Pour les racines n-ièmes de l'unité ($\displaystyle z = e^{\mathrm{i}\dfrac{2k\pi}{n}}$), on a $\displaystyle z^n = 1$, donc :
            <p style="margin:10px 0; text-align:left;">
                $\displaystyle \sum_{k=0}^{n-1} e^{\mathrm{i}\dfrac{2k\pi}{n}} = \dfrac{e^{\mathrm{i}2\pi} - 1}{e^{\mathrm{i}\dfrac{2\pi}{n}} - 1} = \dfrac{1 - 1}{e^{\mathrm{i}\dfrac{2\pi}{n}} - 1} = 0$
            </p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Factorisation $z^n - a^n$</h3>
        
        <p>Pour tous nombres complexes $z$ et $a$, et tout entier naturel $n \geq 1$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z^n - a^n = (z - a)(z^{n-1} + z^{n-2}a + z^{n-3}a^2 + \cdots + za^{n-2} + a^{n-1})$$
        </div>

        <p>Ou sous forme compacte avec le symbole somme :</p>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z^n - a^n = (z - a)\sum_{k=0}^{n-1} z^{n-1-k}a^k$$
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>💡 Remarque :</strong> Cette formule généralise les identités remarquables :
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Pour $n = 2$ : $\displaystyle z^2 - a^2 = (z - a)(z + a)$</li>
                <li style="margin:0; text-align:left;">Pour $n = 3$ : $\displaystyle z^3 - a^3 = (z - a)(z^2 + za + a^2)$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Factoriser $\displaystyle z^5 - 1$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Factorisation classique :</strong> $\displaystyle z^5 - 1 = (z - 1)(z^4 + z^3 + z^2 + z + 1)$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Avec les racines 5-ièmes de l'unité :</strong></li>
                <li style="margin:0; text-align:left;">$\displaystyle z^5 - 1 = (z - 1)(z - e^{\mathrm{i}\dfrac{2\pi}{5}})(z - e^{\mathrm{i}\dfrac{4\pi}{5}})(z - e^{-\mathrm{i}\dfrac{4\pi}{5}})(z - e^{-\mathrm{i}\dfrac{2\pi}{5}})$</li>
            </ul>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Application :</strong> Si $z$ est une racine n-ième de $a$ (c'est-à-dire $\displaystyle z^n = a$), alors $z$ est racine du polynôme $\displaystyle X^n - a$.
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Factorisation $z^n + a^n$ (cas n impair)</h3>
        
        <p>Pour $n$ impair, on peut aussi factoriser $\displaystyle z^n + a^n$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z^n + a^n = (z + a)(z^{n-1} - z^{n-2}a + z^{n-3}a^2 - \cdots - za^{n-2} + a^{n-1})$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> $\displaystyle z^3 + a^3 = (z + a)(z^2 - za + a^2)$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XI. Équations complexes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Équations du second degré</h3>
        
        
        <p>L'équation $\displaystyle az^2 + bz + c = 0$ ($\displaystyle a \neq 0$) admet toujours des solutions dans $\displaystyle \mathbb{C}$.</p>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode de résolution :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;"><strong>Calculer le discriminant :</strong> $\displaystyle \Delta = b^2 - 4ac$</li>
                <li style="margin:0; text-align:left;"><strong>Si $\displaystyle \Delta \geq 0$ :</strong> Solutions réelles classiques</li>
                <li style="margin:0; text-align:left;"><strong>Si $\displaystyle \Delta < 0$ :</strong> Solutions complexes conjuguées</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Cas $\Delta < 0$ (solutions complexes) :</strong>
            <div style="margin:8px 0;">
                $\displaystyle \Delta = -|\Delta| = -|\Delta| \times \mathrm{i}^2 = |\Delta| \mathrm{i}^2$
                Donc $\displaystyle \sqrt{\Delta} = \mathrm{i}\sqrt{|\Delta|}$
                Solutions : $\displaystyle z = \dfrac{-b \pm \mathrm{i}\sqrt{|\Delta|}}{2a}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple détaillé :</strong> Résoudre $\displaystyle z^2 - 2z + 5 = 0$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Étape 1 :</strong> Calculer le discriminant : $\displaystyle \Delta = b^2 - 4ac = (-2)^2 - 4 \times 1 \times 5 = 4 - 20 = -16$</li>
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Étape 2 :</strong> Comme $\displaystyle \Delta < 0$, les solutions sont complexes : $\displaystyle \sqrt{\Delta} = \sqrt{-16} = \mathrm{i}\sqrt{16} = 4\mathrm{i}$</li>
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Étape 3 :</strong> Appliquer la formule : $\displaystyle z = \dfrac{-b \pm \sqrt{\Delta}}{2a} = \dfrac{-(-2) \pm 4\mathrm{i}}{2 \times 1} = \dfrac{2 \pm 4\mathrm{i}}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_1 = \dfrac{2 + 4\mathrm{i}}{2} = 1 + 2\mathrm{i}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_2 = \dfrac{2 - 4\mathrm{i}}{2} = 1 - 2\mathrm{i}$</li>
            </ul>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriété importante :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Les solutions complexes d'une équation à coefficients réels sont conjuguées</li>
                <li style="margin:0; text-align:left;">Si $\displaystyle z_1$ est solution, alors $\displaystyle \overline{z_1}$ l'est aussi</li>
                <li style="margin:0; text-align:left;">Somme des racines : $\displaystyle z_1 + z_2 = -\dfrac{b}{a}$</li>
                <li style="margin:0; text-align:left;">Produit des racines : $\displaystyle z_1 \times z_2 = \dfrac{c}{a}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Racines n-ièmes de l'unité</h3>
        
        <p>Les solutions de $\displaystyle z^n = 1$ sont les racines n-ièmes de l'unité :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            $$\displaystyle z_k = e^{\mathrm{i}\dfrac{2k\pi}{n}} = \cos\dfrac{2k\pi}{n} + \mathrm{i}\sin\dfrac{2k\pi}{n}$$
        </div>

        <p>pour $\displaystyle k = 0, 1, \ldots, n-1$. Elles forment les sommets d'un polygone régulier inscrit dans le cercle unité.</p>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Les racines 6-ièmes de l'unité sont :
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_0 = 1$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_1 = e^{\mathrm{i}\dfrac{\pi}{3}} = \dfrac{1}{2} + \mathrm{i}\dfrac{\sqrt{3}}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_2 = e^{\mathrm{i}\dfrac{2\pi}{3}} = -\dfrac{1}{2} + \mathrm{i}\dfrac{\sqrt{3}}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_3 = -1$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_4 = e^{\mathrm{i}\dfrac{4\pi}{3}} = -\dfrac{1}{2} - \mathrm{i}\dfrac{\sqrt{3}}{2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_5 = e^{\mathrm{i}\dfrac{5\pi}{3}} = \dfrac{1}{2} - \mathrm{i}\dfrac{\sqrt{3}}{2}$</li>
            </ul>
        </div>
              <div style="text-align:center; margin:20px 0;">
            [IMAGE_3]
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Propriété importante :</strong> La somme des racines n-ièmes de l'unité est nulle :
            <div style="margin:10px 0; text-align:left;">
                $\displaystyle \sum_{k=0}^{n-1} e^{\mathrm{i}\dfrac{2k\pi}{n}} = 0$
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Racines n-ièmes d'un nombre complexe quelconque</h3>
        
        <p>Pour résoudre l'équation $\displaystyle z^n = a$ où $\displaystyle a \neq 0$ est un nombre complexe donné :</p>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;">Écrire $a$ sous forme exponentielle : $\displaystyle a = |a| \cdot e^{\mathrm{i}\theta}$</li>
                <li style="margin:0 0 24px 0; text-align:left;">Une solution particulière est : $\displaystyle z_0 = \sqrt[n]{|a|} \cdot e^{\mathrm{i}\dfrac{\theta}{n}}$</li>
                <li style="margin:0; text-align:left;">Les $n$ solutions sont : $\displaystyle z_k = z_0 \cdot e^{\mathrm{i}\dfrac{2k\pi}{n}}$ pour $k = 0, 1, \ldots, n-1$</li>
            </ol>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p><strong>Formule générale :</strong></p>
            $$\displaystyle z_k = \sqrt[n]{|a|} \cdot e^{\mathrm{i}\dfrac{\theta + 2k\pi}{n}} \quad \text{pour } k = 0, 1, \ldots, n-1$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple détaillé :</strong> Résoudre $\displaystyle z^3 = -8$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Étape 1 :</strong> Écrire $\displaystyle -8$ sous forme exponentielle : $\displaystyle -8 = 8 \cdot e^{\mathrm{i}\pi}$ (car $\displaystyle \arg(-8) = \pi$)</li>
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Étape 2 :</strong> Calculer les solutions : $\displaystyle z_k = \sqrt[3]{8} \cdot e^{\mathrm{i}\dfrac{\pi + 2k\pi}{3}} = 2 \cdot e^{\mathrm{i}\dfrac{\pi(1 + 2k)}{3}}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour $\displaystyle k = 0$ : $\displaystyle z_0 = 2e^{\mathrm{i}\dfrac{\pi}{3}} = 2\left(\cos\dfrac{\pi}{3} + \mathrm{i}\sin\dfrac{\pi}{3}\right) = 2\left(\dfrac{1}{2} + \mathrm{i}\dfrac{\sqrt{3}}{2}\right) = 1 + \mathrm{i}\sqrt{3}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour $\displaystyle k = 1$ : $\displaystyle z_1 = 2e^{\mathrm{i}\pi} = -2$</li>
                <li style="margin:0; text-align:left;">Pour $\displaystyle k = 2$ : $\displaystyle z_2 = 2e^{\mathrm{i}\dfrac{5\pi}{3}} = 1 - \mathrm{i}\sqrt{3}$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XI. Transformations géométriques</h2>
    
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Transformations de base</h3>
        
        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Transformation</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Effet géométrique</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto z + z_0$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Translation de vecteur $\displaystyle \overrightarrow{OO_0}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto kz$ ($\displaystyle k \in \mathbb{R}^*$)</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Homothétie de centre $O$, rapport $\displaystyle k$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto e^{\mathrm{i}\varphi}z$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Rotation de centre $O$, angle $\displaystyle \varphi$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z \mapsto \overline{z}$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">Symétrie par rapport à l'axe réel</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> La transformation $\displaystyle f(z) = (1 + \mathrm{i})z$
            $\displaystyle |1 + \mathrm{i}| = \sqrt{2}$ et $\displaystyle \arg(1 + \mathrm{i}) = \dfrac{\pi}{4}$
            Donc $f$ = homothétie de rapport $\displaystyle \sqrt{2}$ + rotation d'angle $\displaystyle \dfrac{\pi}{4}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XII. Affixes et applications géométriques</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Notion d'affixe</h3>
        
        <p>Dans le plan complexe muni d'un repère orthonormé direct $\displaystyle (O; \vec{u}, \vec{v})$ :</p>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>Définitions :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;"><strong>Affixe d'un point :</strong> Le nombre complexe $z$ tel que $\displaystyle M(x, y) \leftrightarrow z = x + y\,\mathrm{i}$</li>
                <li style="margin:0; text-align:left;"><strong>Affixe d'un vecteur :</strong> Si $\displaystyle \vec{w} = \overrightarrow{AB}$ avec $A(z_A)$ et $B(z_B)$, alors l'affixe de $\vec{w}$ est $\displaystyle z_{\vec{w}} = z_B - z_A$</li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p><strong>Notation :</strong> On note $\displaystyle z_M$ l'affixe du point $M$ et $\displaystyle z_{\overrightarrow{AB}}$ l'affixe du vecteur $\displaystyle \overrightarrow{AB}$</p>
            $$\displaystyle z_{\overrightarrow{AB}} = z_B - z_A$$
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Applications géométriques fondamentales</h3>
        
        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Propriété géométrique</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Traduction complexe</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Distance entre deux points $A$ et $B$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle AB = |z_B - z_A|$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;">Milieu $I$ du segment $[AB]$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z_I = \dfrac{z_A + z_B}{2}$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Barycentre $G$ de $(A, \alpha)$ et $(B, \beta)$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z_G = \dfrac{\alpha z_A + \beta z_B}{\alpha + \beta}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;">Addition vectorielle $\displaystyle \overrightarrow{AB} + \overrightarrow{CD}$</td>
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z_{\overrightarrow{AB} + \overrightarrow{CD}} = z_{\overrightarrow{AB}} + z_{\overrightarrow{CD}}$</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Soit $\displaystyle A(2 + 3\mathrm{i})$ et $\displaystyle B(-1 + \mathrm{i})$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Distance :</strong> $\displaystyle AB = |(-1 + \mathrm{i}) - (2 + 3\mathrm{i})| = |-3 - 2\mathrm{i}|$</li>
                <li style="margin:0 0 24px 0; text-align:left;">$\displaystyle AB = \sqrt{9 + 4} = \sqrt{13}$</li>
                <li style="margin:0 0 24px 0; text-align:left;"><strong>Milieu :</strong> $\displaystyle z_I = \dfrac{(2 + 3\mathrm{i}) + (-1 + \mathrm{i})}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle z_I = \dfrac{1 + 4\mathrm{i}}{2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle z_I = \dfrac{1}{2} + 2\mathrm{i}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Ensembles de points dans le plan complexe</h3>
        
        <p>On peut caractériser des ensembles géométriques à l'aide d'équations complexes :</p>
        
        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Équation complexe</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Ensemble géométrique</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle |z - a| = r$ ($r > 0$)</td>
                    <td style="border:1px solid #ddd; padding:10px;">Cercle de centre $A(a)$ et de rayon $r$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle |z - a| < r$</td>
                    <td style="border:1px solid #ddd; padding:10px;">Disque ouvert de centre $A(a)$ et de rayon $r$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle |z - a| = |z - b|$</td>
                    <td style="border:1px solid #ddd; padding:10px;">Médiatrice du segment $[AB]$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle \arg(z - a) = \theta$ $\displaystyle [\pi]$</td>
                    <td style="border:1px solid #ddd; padding:10px;">Demi-droite d'origine $A(a)$ et d'angle $\theta$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle \arg\left(\dfrac{z - b}{z - a}\right) = \theta$ $\displaystyle [2\pi]$</td>
                    <td style="border:1px solid #ddd; padding:10px;">Arc de cercle passant par $A$ et $B$ avec angle orienté $\displaystyle (\overrightarrow{AM}, \overrightarrow{BM}) = \theta$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px; text-align:center;">$\displaystyle z = z_0 + t \cdot w$ ($\displaystyle t \in \mathbb{R}$)</td>
                    <td style="border:1px solid #ddd; padding:10px;">Droite passant par $A(z_0)$ de vecteur directeur d'affixe $w$</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> Déterminer l'ensemble des points $M$ tels que $\displaystyle |z - 2\mathrm{i}| = 3$
            <div style="margin:8px 0;">
                C'est le cercle de centre $\displaystyle A(2\mathrm{i})$, c'est-à-dire $A(0, 2)$, et de rayon $3$.
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> Déterminer l'ensemble des points $M$ tels que $\displaystyle |z - 1| = |z + 1|$
            <div style="margin:8px 0;">
                C'est la médiatrice du segment $[AB]$ où $\displaystyle A(-1)$ et $\displaystyle B(1)$.
                Cette médiatrice est l'axe des imaginaires purs (axe des ordonnées).
            </div>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>🟣 Méthode :</strong> Pour identifier un ensemble de points :
            <ol style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Identifier la forme de l'équation (module, argument, etc.)</li>
                <li style="margin:0; text-align:left;">Repérer les paramètres (centre, rayon, angle...)</li>
                <li style="margin:0; text-align:left;">Conclure sur la nature géométrique de l'ensemble</li>
            </ol>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Angles et rapports</h3>
        
        <p>Pour trois points $A$, $B$ et $M$ distincts d'affixes respectives $z_A$, $z_B$ et $z$ :</p>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p><strong>Angle orienté :</strong></p>
            $$\displaystyle \left(\overrightarrow{MA}, \overrightarrow{MB}\right) = \arg\left(\dfrac{z_B - z}{z_A - z}\right) \quad [2\pi]$$
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0; text-align:left;">
            <p><strong>Rapport de distances :</strong></p>
            $$\displaystyle \dfrac{MB}{MA} = \left|\dfrac{z_B - z}{z_A - z}\right|$$
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Soit $\displaystyle A(1)$, $\displaystyle B(\mathrm{i})$ et $\displaystyle M(1 + \mathrm{i})$
            <div style="margin:8px 0;">
                $\displaystyle \dfrac{z_B - z_M}{z_A - z_M} = \dfrac{\mathrm{i} - (1 + \mathrm{i})}{1 - (1 + \mathrm{i})} = \dfrac{-1}{-\mathrm{i}} = \dfrac{1}{\mathrm{i}} = -\mathrm{i}$
                Donc $\displaystyle \left(\overrightarrow{MA}, \overrightarrow{MB}\right) = \arg(-\mathrm{i}) = -\dfrac{\pi}{2} \quad [2\pi]$
                Le triangle $MAB$ est rectangle en $M$.
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XIII. Méthodes pratiques</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Passage de la forme algébrique à la forme trigonométrique</h3>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Étapes :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">Calculer le module : $\displaystyle r = |z| = \sqrt{x^2 + y^2}$</li>
                <li style="margin:0; text-align:left;">Déterminer un argument : résoudre $\displaystyle \cos\theta = \dfrac{x}{r}$ et $\displaystyle \sin\theta = \dfrac{y}{r}$</li>
                <li style="margin:0; text-align:left;">Vérifier le quadrant selon les signes de $x$ et $y$</li>
                <li style="margin:0; text-align:left;">Conclure : $\displaystyle z = r(\cos\theta + \mathrm{i}\sin\theta)$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple guidé :</strong> Convertir $\displaystyle z = -\sqrt{3} + \mathrm{i}$
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 24px 0; text-align:left;">Calcul du module : $\displaystyle r = \sqrt{(-\sqrt{3})^2 + 1^2} = 2$</li>
                <li style="margin:0 0 24px 0; text-align:left;">Calcul de $\displaystyle \cos\theta$ et $\displaystyle \sin\theta$ : $\displaystyle \cos\theta = \dfrac{-\sqrt{3}}{2}$, $\displaystyle \sin\theta = \dfrac{1}{2}$</li>
                <li style="margin:0 0 24px 0; text-align:left;">Détermination de l'argument : Quadrant II, donc $\displaystyle \theta = \dfrac{5\pi}{6}$</li>
                <li style="margin:0; text-align:left;">Forme polaire : $\displaystyle z = 2\left(\cos\dfrac{5\pi}{6} + \mathrm{i}\sin\dfrac{5\pi}{6}\right)$</li>
            </ul>
        </div>
        </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">XIV. Erreurs fréquentes et conseils</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef2f2; border-radius:6px; border-left:6px solid #ef4444; padding:15px; margin:12px 0;">
            <strong>❌ Pièges à éviter :</strong>
            <div style="margin:8px 0;">
                <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                    <li style="margin:0; text-align:left;">Oublier que $\displaystyle \mathrm{i}^2 = -1$ lors des développements</li>
                    <li style="margin:0; text-align:left;">Confondre conjugué $\displaystyle \overline{z}$ et opposé $\displaystyle -z$</li>
                    <li style="margin:0; text-align:left;">Mauvais quadrant pour l'argument (vérifier les signes de $x$ et $y$)</li>
                    <li style="margin:0; text-align:left;">Écrire $\displaystyle |z_1 + z_2| = |z_1| + |z_2|$ (faux en général)</li>
                    <li style="margin:0; text-align:left;">Oublier le facteur $\displaystyle r^n$ dans la formule de Moivre</li>
                    <li style="margin:0; text-align:left;">Utiliser les formules de trigonométrie sans vérifier le quadrant</li>
                    <li style="margin:0; text-align:left;">Confondre module et argument dans les calculs</li>
            </ul>
        </div>
    </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <div style="margin:8px 0;">
                <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                    <li style="margin:0; text-align:left;">Utiliser le conjugué pour rationaliser les dénominateurs</li>
                    <li style="margin:0; text-align:left;">Passer en trigonométrique pour produits/quotients/puissances</li>
                    <li style="margin:0; text-align:left;">Vérifier systématiquement le quadrant pour l'argument</li>
                    <li style="margin:0; text-align:left;">Utiliser l'inégalité triangulaire : $\displaystyle |z_1 + z_2| \leq |z_1| + |z_2|$</li>
                    <li style="margin:0; text-align:left;">Penser géométriquement : module = distance, argument = angle</li>
                    <li style="margin:0; text-align:left;">Mémoriser les valeurs trigonométriques des angles remarquables</li>
                    <li style="margin:0; text-align:left;">Faire des calculs intermédiaires clairs pour éviter les erreurs</li>
            </ul>
            </div>
        </div>
    </div>
