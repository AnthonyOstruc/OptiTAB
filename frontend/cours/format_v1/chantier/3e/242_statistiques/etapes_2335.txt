## Question 1 : La somme actuelle

::: methode
Somme = nombre de notes × moyenne.
:::

::: etape Calculer
$4$ contrôles de moyenne $11$ : $4 \times 11 = 44$.
:::

::: resultat
La somme des $4$ premières notes est $44$.
:::

## Question 2 : L'objectif total

::: etape Somme visée
Moyenne $12$ sur $6$ contrôles : $6 \times 12 = 72$.
:::

::: resultat
Lina doit atteindre une somme totale de $72$ points.
:::

## Question 3 : Les deux derniers contrôles

::: etape Ce qui manque
$$72 - 44 = 28$$
:::

::: etape Interpréter
$28$ points sur $2$ contrôles, soit $\dfrac{28}{2} = 14$ de moyenne sur ces deux contrôles.
:::

::: resultat
Elle doit obtenir $28$ points sur les $2$ derniers contrôles.
:::

## Question 4 : La note du 6ᵉ contrôle

::: etape Retirer la note du 5ᵉ contrôle
$$28 - 13 = 15$$
:::

::: etape Vérification
$$\frac{44 + 13 + 15}{6} = \frac{72}{6} = 12$$
:::

::: resultat
Il lui faut $15$ au 6ᵉ contrôle.
:::

## Question 5 : Une moyenne de 14 ?

::: etape Somme nécessaire
$6 \times 14 = 84$, donc il manque $84 - 44 = 40$ points sur $2$ contrôles.
:::

::: etape Comparer au maximum
Deux notes sur $20$ font au plus $20 + 20 = 40$.
:::

::: resultat
C'est possible, mais seulement avec $20$ et $20$, la note maximale aux deux contrôles.
:::

::: attention Erreur fréquente
Chercher la note en faisant la moyenne entre la moyenne actuelle et la moyenne visée : on raisonne sur les **sommes** de notes.
:::

::: retenir
Les problèmes de moyenne « à atteindre » se résolvent avec les SOMMES.
:::

Solution:
<!-- optitab:1 -->
1. $44$
2. $72$
3. $28$
4. $15$
5. Oui, avec $20$ et $20$ uniquement
