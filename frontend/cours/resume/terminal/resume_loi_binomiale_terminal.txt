===Résumé Loi Binomiale Terminal

Titre: Résumé : La Loi Binomiale

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> Maîtriser la loi binomiale : schéma de Bernoulli, calcul de probabilités, espérance, variance, et applications pratiques. Ce résumé couvre les notions exigibles au programme de Terminale.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Schéma de Bernoulli</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Schéma de Bernoulli</strong></p>
<p style="margin:5px 0 0 0;">Expérience aléatoire avec <strong>deux issues</strong> :</p>
<ul style="margin:5px 0 0 0; padding-left:20px;">
<li style="margin:5px 0;">Succès (S) avec probabilité $\displaystyle p$</li>
<li style="margin:5px 0;">Échec (É) avec probabilité $\displaystyle q = 1 - p$</li>
</ul>
<p style="margin:5px 0 0 0;"><em style="font-size:0.9em;">Relation : $\displaystyle p + q = 1$</em></p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Loi binomiale</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Loi binomiale</strong></p>
<p style="margin:5px 0 0 0;">On répète $\displaystyle n$ fois de manière <strong>indépendante</strong> un schéma de Bernoulli de paramètre $\displaystyle p$.</p>
<p style="margin:5px 0 0 0;">La variable aléatoire $\displaystyle X$ qui compte le <strong>nombre de succès</strong> suit une <strong>loi binomiale</strong> de paramètres $\displaystyle n$ et $\displaystyle p$.</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:250px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle X \sim \mathcal{B}(n, p)$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Condition</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Exigence</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Indépendance</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Les $\displaystyle n$ répétitions doivent être indépendantes</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Probabilité constante</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">La probabilité $\displaystyle p$ est identique à chaque répétition</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Valeurs possibles</td>
<td style="border:none; padding:18px 16px;">$\displaystyle X \in \{0, 1, 2, \ldots, n\}$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Calcul des probabilités</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Formule de la loi binomiale</strong></p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle X \sim \mathcal{B}(n, p)$ et $\displaystyle k \in \{0, 1, 2, \ldots, n\}$ :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:450px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle P(X = k) = \binom{n}{k} \times p^k \times (1-p)^{n-k}$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Coefficient binomial</strong></p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \binom{n}{k} = \frac{n!}{k!(n-k)!}$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Propriété</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Valeur</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \binom{n}{0}$ et $\displaystyle \binom{n}{n}$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle 1$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \binom{n}{k}$ (symétrie)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \binom{n}{k} = \binom{n}{n-k}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">$\displaystyle \binom{n}{1}$ et $\displaystyle \binom{n}{n-1}$</td>
<td style="border:none; padding:18px 16px;">$\displaystyle n$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Probabilités cumulées</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Probabilité</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Formule</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Au plus $\displaystyle k$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle P(X \leq k) = \sum_{i=0}^{k} P(X = i)$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Au moins $\displaystyle k$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle P(X \geq k) = \sum_{i=k}^{n} P(X = i)$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Relation utile</td>
<td style="border:none; padding:18px 16px;">$\displaystyle P(X \geq k) = 1 - P(X \leq k-1)$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Espérance et variance</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Espérance et variance</strong></p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle X \sim \mathcal{B}(n, p)$ :</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Paramètre</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Formule</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Espérance</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle E(X) = np$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Variance</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle V(X) = np(1-p)$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Écart-type</td>
<td style="border:none; padding:18px 16px;">$\displaystyle \sigma(X) = \sqrt{np(1-p)}$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Piège fréquent</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Correction</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre "exactement $\displaystyle k$" et "au plus $\displaystyle k$"</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">$\displaystyle P(X = k) \neq P(X \leq k)$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier l'indépendance</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Les $\displaystyle n$ répétitions doivent être indépendantes</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Se tromper dans l'identification de $\displaystyle p$</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Bien identifier ce qui constitue un "succès"</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Confondre $\displaystyle \binom{n}{k}$ et $\displaystyle \binom{k}{n}$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \binom{n}{k} = \frac{n!}{k!(n-k)!}$ avec $\displaystyle n \geq k$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; padding:18px 16px;">Oublier de vérifier $\displaystyle 0 \leq k \leq n$</td>
<td style="border:none; padding:18px 16px;">$\displaystyle k$ doit être entre $\displaystyle 0$ et $\displaystyle n$</td>
</tr>
</tbody>
</table>
</div>

</tr>
</tbody>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Méthodologie — stratégie de résolution</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ffa500; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(255,165,0,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ffa500 0%, #ff8c00 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Type de problème</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Méthode recommandée</th>
</tr>
</thead>
<tbody>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Identifier la loi</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Vérifier : répétitions indépendantes, même probabilité $\displaystyle p$, deux issues</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer $\displaystyle P(X = k)$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Utiliser : $\displaystyle P(X = k) = \binom{n}{k} \times p^k \times (1-p)^{n-k}$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer $\displaystyle P(X \leq k)$</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Sommer : $\displaystyle P(X = 0) + P(X = 1) + \ldots + P(X = k)$ ou utiliser la calculatrice</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer $\displaystyle P(X \geq k)$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Utiliser : $\displaystyle P(X \geq k) = 1 - P(X \leq k-1)$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; padding:18px 16px;">Calculer espérance/variance</td>
<td style="border:none; padding:18px 16px;">Utiliser : $\displaystyle E(X) = np$ et $\displaystyle V(X) = np(1-p)$</td>
</tr>
</tbody>
</table>
</div>
