Titre: Résumé : Développements d'Expressions Algébriques

<!-- optitab:1 -->
## I. Définition et principe

| Concept | Description |
|---|---|
| **Développement** | Transformer un **produit** en une **somme** |
| **Principe** | $\displaystyle 3(x + 2) \xrightarrow[\text{}]{\text{Développer}} 3x + 6$ |
| **Objectif** | Simplifier des expressions, résoudre des équations, comparer des expressions |

## II. Distributivité simple

| Type | Formule |
|---|---|
| **Distributivité simple** | $\displaystyle k(a + b) = ka + kb$ |
| **Plusieurs termes** | $\displaystyle k(a + b + c) = ka + kb + kc$ |

::: methode
On multiplie le facteur **extérieur** par **chaque terme** de la parenthèse.
:::

| Règle des signes |
|---|
| $(+) \times (+) = (+)$ | $(+) \times (-) = (-)$ | $(-) \times (+) = (-)$ | $(-) \times (-) = (+)$ |

## III. Double distributivité

| Type | Formule |
|---|---|
| **Double distributivité** | $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$ |

::: methode
Chaque terme de la **première parenthèse** multiplie **chaque terme** de la **deuxième parenthèse**.
:::

| Produit | Résultat |
|---|---|
| **$(a + b)(c + d)$** | $\displaystyle a \times c$ (premier × premier) + $\displaystyle a \times d$ (premier × deuxième) + $\displaystyle b \times c$ (deuxième × premier) + $\displaystyle b \times d$ (deuxième × deuxième) |

## IV. Identités remarquables

| Identité | Formule |
|---|---|
| **Carré d'une somme** | $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$ |
| **Carré d'une différence** | $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$ |
| **Produit remarquable** | $\displaystyle (a + b)(a - b) = a^2 - b^2$ |

::: methode
Les identités remarquables permettent de développer **plus rapidement** certaines expressions.
:::

## V. Développements complexes

| Étape | Méthode |
|---|---|
| **1** | Développer chaque produit séparément |
| **2** | Enlever les parenthèses en faisant attention aux signes |
| **3** | Regrouper les termes semblables |
| **4** | Simplifier l'expression finale |

::: attention
Quand on soustrait une expression entre parenthèses, il faut changer **tous les signes** ! Exemple : $a - (b - c) = a - b + c$
:::

## VI. Méthode générale

| Étape | Méthode |
|---|---|
| **1** | Observer l'expression : Y a-t-il des identités remarquables ? |
| **2** | Choisir la méthode : Distributivité simple, double, ou identité remarquable |
| **3** | Développer : Appliquer la formule en faisant attention aux signes |
| **4** | Réduire : Regrouper les termes semblables |
| **5** | Ordonner : Écrire le résultat par ordre décroissant des puissances |
| **6** | Vérifier : Compter le nombre de termes (aide à éviter les erreurs) |

## VII. Erreurs fréquentes et conseils

| Notion | À retenir |
|---|---|
| **Multiplier tous les termes** | $\displaystyle 2(x + 3) = 2x + 6$ et non $\displaystyle 2x + 3$ (ne pas oublier de multiplier tous les termes) |
| **Signes dans le développement** | $\displaystyle -3(x - 2) = -3x + 6$ et non $\displaystyle -3x - 6$ (attention à la double négative) |
| **Double distributivité** | $\displaystyle (x + 2)(x + 3) = x^2 + 5x + 6$ (ne pas oublier un terme dans la double distributivité) |
| **Identités remarquables** | $\displaystyle (x + 3)^2 = x^2 + 6x + 9$ et non $\displaystyle x^2 + 9$ (ne pas confondre $\displaystyle (a + b)^2$ et $\displaystyle a^2 + b^2$) |
| **Soustraction avec parenthèses** | $\displaystyle x - (2x - 5) = x - 2x + 5$ et non $\displaystyle x - 2x - 5$ (changer tous les signes quand on soustrait) |
| **Vérification** | Vérifier le nombre de termes attendus et tester avec une valeur simple (ex: $\displaystyle x = 1$) |

### Points clés à retenir

| Notion | À retenir |
|---|---|
| **Distributivité simple** | $\displaystyle k(a + b) = ka + kb$ : multiplier le facteur extérieur par chaque terme |
| **Double distributivité** | $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$ : chaque terme de la première parenthèse multiplie chaque terme de la deuxième |
| **Identités remarquables** | $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$ <br> $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$ <br> $\displaystyle (a + b)(a - b) = a^2 - b^2$ |
| **Signes** | Attention aux règles des signes : <br> $\displaystyle (+) \times (+) = (+)$ <br> $\displaystyle (+) \times (-) = (-)$ <br> $\displaystyle (-) \times (+) = (-)$ <br> $\displaystyle (-) \times (-) = (+)$ |
| **Soustraction** | Quand on soustrait une expression entre parenthèses, changer **tous les signes** : $\displaystyle a - (b - c) = a - b + c$ |
| **Méthode générale** | Observer → Choisir la méthode → Développer → Réduire → Ordonner → Vérifier |
| **Vérification** | Toujours vérifier en comptant le nombre de termes et en testant avec une valeur simple (ex: $\displaystyle x = 1$) |
