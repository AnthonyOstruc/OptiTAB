📚 Objectif pédagogique : retenir l’essentiel : dérivées, variations, équations et étude des fonctions trigonométriques. Programme de Terminale.

I. Dérivées

$\displaystyle (\sin x)' = \cos x$ et $\displaystyle (\cos x)' = -\sin x$

[IMAGE_1]

1️⃣ $\displaystyle \big(\sin(ax + b)\big)' = a\cos(ax + b)$ ; $\displaystyle \big(\cos(ax + b)\big)' = -a\sin(ax + b)$.

2️⃣ $\displaystyle \lim\limits_{x \to 0} \frac{\sin x}{x} = 1$.

3️⃣ Périodes : $\displaystyle 2\pi$ pour $\displaystyle \sin x$, $\displaystyle \frac{2\pi}{a}$ pour $\displaystyle \sin(ax)$.

II. Variations et équations

[IMAGE_2]

1️⃣ $\displaystyle \cos x = \cos a \iff x = \pm a + 2k\pi$.

2️⃣ $\displaystyle \sin x = \sin a \iff x = a + 2k\pi$ ou $\displaystyle x = \pi - a + 2k\pi$.

3️⃣ Inéquations : lecture sur le cercle trigonométrique.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Oublier le signe moins : $\displaystyle (\cos x)' = -\sin x$.

2️⃣ Oublier le facteur $\displaystyle a$ en dérivant $\displaystyle \cos(ax + b)$.

3️⃣ Ne donner qu’une solution sur un tour complet.

4️⃣ Chercher une limite de $\displaystyle \cos x$ en $\displaystyle +\infty$ : elle n’existe pas.
