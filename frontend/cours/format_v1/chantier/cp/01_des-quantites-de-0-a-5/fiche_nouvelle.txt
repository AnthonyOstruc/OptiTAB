Titre: Les nombres entiers : de 0 à 5

<!-- optitab:1 -->
::: retenir
Pour savoir combien il y a d’objets, je touche chaque objet une seule fois. Le dernier nombre dit donne la quantité.
:::

Voici quatre jetons.

[IMAGE_1]

::: propriete
0 : zéro ; 1 : un ; 2 : deux ; 3 : trois ; 4 : quatre ; 5 : cinq.
:::

::: methode
Je déplace les objets déjà comptés. Je ne compte pas deux fois le même.
:::

::: exemple
4 jetons déplacés restent 4 jetons. Une boîte vide contient 0 jeton.
:::

::: attention
Réciter les nombres ne suffit pas. Je touche chaque objet une seule fois.
:::
