=== Découverte - Partager un rectangle
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Explique les deux parties du rectangle et donne le produit total.

[IMAGE_1]

2. Calcule la partie des dizaines : $30\times 7$.

3. Calcule la partie des unités : $4\times 7$.

4. Réunis les deux parties : $210+28$.

5. Recommence avec un objet de plus dans chacun des 7 groupes : $35\times 7$.

Étapes:
<!-- optitab:1 -->

## Question 1 : Je cherche et j’explique

::: methode
Je repère ce qui est demandé, puis j’applique la méthode du chapitre.
:::

::: etape Mon raisonnement
Je sépare $34$ en $30$ et $4$.

$30\times 7 = 210$ ; $4\times 7 = 28$.

Je réunis les deux produits : $210+28 = 238$.

$$
34\times 7 = 238
$$
:::

::: resultat
30 × 7 = 210 ; 4 × 7 = 28 ; 210 + 28 = 238.
:::

## Question 2 : Je cherche et j’explique

::: methode
Je sépare un facteur en deux parties, je multiplie les deux parties puis je réunis.
:::

::: etape Mon raisonnement
Je sépare $30$ en $30$ et $0$.

$30\times 7 = 210$ ; $0\times 7 = 0$.

Je réunis les deux produits : $210+0 = 210$.

$$
30\times 7 = 210
$$
:::

::: resultat
$30\times 7 = 210$
:::

## Question 3 : Je cherche et j’explique

::: methode
Je retrouve le produit dans une table ou je m’appuie sur un produit connu.
:::

::: etape Mon raisonnement
Je retrouve le résultat dans la table de multiplication.

$$
4\times 7 = 28
$$
:::

::: resultat
$4\times 7 = 28$
:::

## Question 4 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $0+8 = 8$.

J'écris 8 ; il n'y a pas de retenue.

Pour les dizaines, je calcule $1+2 = 3$.

J'écris 3 ; il n'y a pas de retenue.

Pour les centaines, je calcule $2+0 = 2$.

$$
210+28 = 238
$$
:::

::: resultat
$210+28 = 238$
:::

## Question 5 : Je cherche et j’explique

::: methode
Je sépare un facteur en deux parties, je multiplie les deux parties puis je réunis.
:::

::: etape Mon raisonnement
Je sépare $35$ en $30$ et $5$.

$30\times 7 = 210$ ; $5\times 7 = 35$.

Je réunis les deux produits : $210+35 = 245$.

$$
35\times 7 = 245
$$
:::

::: resultat
$35\times 7 = 245$
:::

Solution:
<!-- optitab:1 -->
1. 30 × 7 = 210 ; 4 × 7 = 28 ; 210 + 28 = 238.
2. $30\times 7 = 210$
