<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Boucle for</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ <code>range(n)</code> : $\displaystyle 0$ à $\displaystyle n - 1$ ; <code>range(a, b)</code> : $\displaystyle a$ à $\displaystyle b - 1$ ; <code>range(a, b, p)</code> : pas $\displaystyle p$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Somme : <code>s = 0</code> puis <code>s = s + …</code> ; compteur : <code>c = c + 1</code>.</p>
<p style="margin:6px 0 0 0;">3️⃣ Terme $\displaystyle u_n$ d’une suite récurrente : $\displaystyle n$ applications de la relation.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Boucle while</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ <code>while condition:</code> répète tant que la condition est vraie.</p>
<p style="margin:6px 0 0 0;">2️⃣ Seuil : on fait avancer $\displaystyle n$ et $\displaystyle u$ ensemble, on renvoie $\displaystyle n$ à la sortie.</p>
<p style="margin:6px 0 0 0;">3️⃣ <code>break</code> sort immédiatement de la boucle.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier que <code>range(1, 10)</code> s’arrête à $\displaystyle 9$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Initialiser l’accumulateur dans la boucle.</p>
<p style="margin:6px 0 0 0;">3️⃣ Écrire la condition d’arrêt au lieu de la condition pour continuer.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de mettre à jour la variable testée : boucle infinie.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> nombre de tours connu → <code>for</code> ; « jusqu’à ce que » → <code>while</code> avec la condition contraire.</p>
</div>
