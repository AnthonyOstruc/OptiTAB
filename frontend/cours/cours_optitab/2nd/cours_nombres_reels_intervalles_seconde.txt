    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. L'ensemble ℝ des nombres réels et la droite numérique</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition de ℝ</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - L'ensemble ℝ</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ensemble des <strong>nombres réels</strong>, noté $\displaystyle \mathbb{R}$, contient tous les nombres que nous utilisons en mathématiques :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Les nombres entiers : $\displaystyle \mathbb{Z} = \{..., -2, -1, 0, 1, 2, ...\}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Les nombres décimaux : $\displaystyle \mathbb{D}$ (nombres avec un nombre fini de chiffres après la virgule)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Les nombres rationnels : $\displaystyle \mathbb{Q}$ (fractions de nombres entiers)</li>
                <li style="margin:0; text-align:left;">Les nombres irrationnels (comme $\displaystyle \sqrt{2}$, $\displaystyle \pi$, etc.)</li>
            </ul>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ensemble $\displaystyle \mathbb{R}$ est "complet" : il n'y a pas de "trous" entre les nombres. Tous les nombres que nous pouvons représenter sur une droite graduée appartiennent à $\displaystyle \mathbb{R}$.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Correspondance avec la droite numérique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il existe une <strong>correspondance bijective</strong> entre l'ensemble $\displaystyle \mathbb{R}$ et les points d'une droite graduée :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">À chaque nombre réel correspond un <strong>unique point</strong> de la droite</li>
                <li style="margin:0; text-align:left;">À chaque point de la droite correspond un <strong>unique nombre réel</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette droite est appelée <strong>droite numérique</strong> ou <strong>droite des réels</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur la droite numérique :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Le point d'abscisse $\displaystyle 0$ correspond au nombre $\displaystyle 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Le point d'abscisse $\displaystyle 2,5$ correspond au nombre décimal $\displaystyle 2,5$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Le point d'abscisse $\displaystyle \sqrt{2}$ correspond au nombre irrationnel $\displaystyle \sqrt{2} \approx 1,414$</li>
                <li style="margin:0; text-align:left;">Le point d'abscisse $\displaystyle -\frac{3}{4}$ correspond au nombre rationnel $\displaystyle -0,75$</li>
            </ul>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Intervalles de ℝ</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et notations</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Intervalle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>intervalle</strong> de $\displaystyle \mathbb{R}$ est un ensemble de nombres réels compris entre deux bornes (qui peuvent être $\displaystyle -\infty$ ou $\displaystyle +\infty$).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les intervalles permettent de décrire des ensembles de nombres vérifiant des inégalités.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Types d'intervalles</strong></p>

                    <tr style="background:#ffffff;">
                        <td style="border:1px solid #ddd; padding:10px; font-family:monospace;">$\displaystyle ]a, b[$</td>
                        <td style="border:1px solid #ddd; padding:10px;">$\displaystyle \{x \in \mathbb{R} \mid a < x < b\}$</td>

                        <td style="border:1px solid #ddd; padding:10px; font-family:monospace;">$\displaystyle ]a, +\infty[$</td>

                        <td style="border:1px solid #ddd; padding:10px;">Ouvert à droite</td>
                    </tr>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:10px; font-family:monospace;">$\displaystyle ]-\infty, +\infty[$</td>

        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> L'intervalle $\displaystyle [2, 5]$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est l'ensemble des nombres réels $\displaystyle x$ tels que $\displaystyle 2 \leq x \leq 5$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres $\displaystyle 2$, $\displaystyle 3,5$, $\displaystyle 4$ et $\displaystyle 5$ appartiennent à cet intervalle.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres $\displaystyle 1,9$ et $\displaystyle 5,1$ n'appartiennent pas à cet intervalle.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> L'intervalle $\displaystyle ]-3, 2[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est l'ensemble des nombres réels $\displaystyle x$ tels que $\displaystyle -3 < x < 2$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres $\displaystyle -2,5$, $\displaystyle 0$ et $\displaystyle 1,9$ appartiennent à cet intervalle.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres $\displaystyle -3$ et $\displaystyle 2$ n'appartiennent <strong>pas</strong> à cet intervalle (bornes exclues).</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> L'intervalle $\displaystyle [4, +\infty[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est l'ensemble des nombres réels $\displaystyle x$ tels que $\displaystyle x \geq 4$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres $\displaystyle 4$, $\displaystyle 10$, $\displaystyle 100$ appartiennent à cet intervalle.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le nombre $\displaystyle 3,9$ n'appartient pas à cet intervalle.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Crochet tourné vers l'intérieur [ ou ] :</strong> la borne est <strong>incluse</strong> (inégalité large $\displaystyle \leq$ ou $\displaystyle \geq$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Crochet tourné vers l'extérieur ] ou [ :</strong> la borne est <strong>exclue</strong> (inégalité stricte $\displaystyle <$ ou $\displaystyle >$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Avec $\displaystyle +\infty$ ou $\displaystyle -\infty$ :</strong> on utilise toujours un crochet ouvert $\displaystyle ]$ ou $\displaystyle [$ car l'infini n'est pas un nombre</li>
                <li style="margin:0; text-align:left;"><strong>Pour vérifier si un nombre appartient :</strong> remplacer $\displaystyle x$ par ce nombre dans l'inégalité</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Valeur absolue et distance</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition de la valeur absolue</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Valeur absolue</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout nombre réel $\displaystyle a$, la <strong>valeur absolue</strong> de $\displaystyle a$, notée $\displaystyle |a|$, est définie par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px; font-weight:bold;">
                $\displaystyle |a| = \begin{cases} a & \text{si } a \geq 0 \\ -a & \text{si } a < 0 \end{cases}$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La valeur absolue d'un nombre est toujours <strong>positive ou nulle</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle |5| = 5$ (car $\displaystyle 5 \geq 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle |-3| = -(-3) = 3$ (car $\displaystyle -3 < 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle |0| = 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle |-\sqrt{2}| = \sqrt{2}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle |\pi - 4| = 4 - \pi$ (car $\displaystyle \pi - 4 < 0$)</li>
            </ul>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation géométrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La valeur absolue $\displaystyle |a|$ représente la <strong>distance</strong> entre le nombre $\displaystyle a$ et $\displaystyle 0$ sur la droite numérique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : $\displaystyle |5| = 5$ signifie que $\displaystyle 5$ est à une distance de $\displaystyle 5$ unités de $\displaystyle 0$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Distance entre deux nombres réels</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Distance entre deux nombres</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour deux nombres réels $\displaystyle a$ et $\displaystyle b$, la <strong>distance</strong> entre $\displaystyle a$ et $\displaystyle b$ est :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle d(a, b) = |b - a| = |a - b|$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette distance est toujours <strong>positive ou nulle</strong>, et elle est nulle si et seulement si $\displaystyle a = b$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Distance entre $\displaystyle 3$ et $\displaystyle 7$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle d(3, 7) = |7 - 3| = |4| = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance est de $\displaystyle 4$ unités.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Distance entre $\displaystyle -2$ et $\displaystyle 5$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle d(-2, 5) = |5 - (-2)| = |7| = 7$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance est de $\displaystyle 7$ unités.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Distance entre $\displaystyle \sqrt{2}$ et $\displaystyle 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle d(\sqrt{2}, 2) = |2 - \sqrt{2}| = 2 - \sqrt{2} \approx 0,586$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Caractérisation d'un intervalle centré</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Intervalle centré</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout nombre réel $\displaystyle a$ et tout nombre réel positif $\displaystyle r > 0$, l'intervalle $\displaystyle [a - r, a + r]$ peut être caractérisé par :</p>
            <div style="background:#f3e5f5; border:3px solid #9c27b0; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px; font-weight:bold;">
                $\displaystyle [a - r, a + r] = \{x \in \mathbb{R} \mid |x - a| \leq r\}$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cet intervalle est l'ensemble des nombres réels dont la <strong>distance à $\displaystyle a$ est inférieure ou égale à $\displaystyle r$</strong>.</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Justification :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dire que $\displaystyle |x - a| \leq r$ signifie que la distance entre $\displaystyle x$ et $\displaystyle a$ est inférieure ou égale à $\displaystyle r$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela équivaut à : $\displaystyle -r \leq x - a \leq r$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En ajoutant $\displaystyle a$ de chaque côté : $\displaystyle a - r \leq x \leq a + r$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce qui correspond exactement à l'intervalle $\displaystyle [a - r, a + r]$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> L'intervalle $\displaystyle [2, 6]$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle a = 4$ (centre) et $\displaystyle r = 2$ (rayon).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cet intervalle peut s'écrire : $\displaystyle \{x \in \mathbb{R} \mid |x - 4| \leq 2\}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle |x - 4| \leq 2 \Leftrightarrow -2 \leq x - 4 \leq 2 \Leftrightarrow 2 \leq x \leq 6$ ✓</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> L'intervalle $\displaystyle [-1, 5]$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle a = 2$ (centre) et $\displaystyle r = 3$ (rayon).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cet intervalle peut s'écrire : $\displaystyle \{x \in \mathbb{R} \mid |x - 2| \leq 3\}$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Trouver l'intervalle correspondant à $\displaystyle |x + 3| \leq 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On écrit : $\displaystyle |x + 3| = |x - (-3)| \leq 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle a = -3$ et $\displaystyle r = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'intervalle est : $\displaystyle [-3 - 4, -3 + 4] = [-7, 1]$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Nombres décimaux et encadrements</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">L'ensemble 𝔻 des nombres décimaux</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Nombre décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>nombre décimal</strong> est un nombre qui peut s'écrire sous la forme $\displaystyle \frac{a}{10^n}$ où $\displaystyle a$ est un entier relatif et $\displaystyle n$ est un entier naturel.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ensemble des nombres décimaux est noté $\displaystyle \mathbb{D}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 3,5 = \frac{35}{10}$ est un nombre décimal</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle -0,125 = \frac{-125}{1000} = \frac{-1}{8}$ est un nombre décimal</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 7 = \frac{7}{1} = \frac{70}{10}$ est un nombre décimal</li>
                <li style="margin:0; text-align:left;">$\displaystyle \frac{1}{3} = 0,333...$ n'est <strong>pas</strong> un nombre décimal (développement décimal infini)</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tout nombre décimal a un <strong>développement décimal fini</strong> (un nombre fini de chiffres après la virgule).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Réciproquement, si un nombre a un développement décimal fini, alors c'est un nombre décimal.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Encadrement décimal d'un nombre réel</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Encadrement décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>encadrement décimal</strong> d'un nombre réel $\displaystyle x$ à $\displaystyle 10^{-n}$ près (avec $\displaystyle n \in \mathbb{N}$) est une inégalité de la forme :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px; font-weight:bold;">
                $\displaystyle d \leq x < d + 10^{-n}$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle d$ est un nombre décimal.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'<strong>amplitude</strong> de l'encadrement est $\displaystyle 10^{-n}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Encadrement de $\displaystyle \pi$ à $\displaystyle 10^{-2}$ près</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle 3,14 \leq \pi < 3,15$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'amplitude est $\displaystyle 0,01 = 10^{-2}$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Encadrement de $\displaystyle \sqrt{2}$ à $\displaystyle 10^{-3}$ près</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle 1,414 \leq \sqrt{2} < 1,415$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'amplitude est $\displaystyle 0,001 = 10^{-3}$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Encadrement de $\displaystyle \frac{1}{7}$ à $\displaystyle 10^{-4}$ près</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle 0,1428 \leq \frac{1}{7} < 0,1429$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'amplitude est $\displaystyle 0,0001 = 10^{-4}$.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour donner un encadrement décimal à $\displaystyle 10^{-n}$ près d'un nombre $\displaystyle x$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Calculer une valeur approchée de $\displaystyle x$ avec $\displaystyle n+1$ décimales</li>
                <li style="margin:0 0 18px 0; text-align:left;">Tronquer à $\displaystyle n$ décimales pour obtenir la borne inférieure $\displaystyle d$</li>
                <li style="margin:0; text-align:left;">Ajouter $\displaystyle 10^{-n}$ pour obtenir la borne supérieure $\displaystyle d + 10^{-n}$</li>
            </ol>
        </div>
        <div style="background:#ebf4ff; border-radius:6px; border-left:6px solid #1d4ed8; padding:15px; margin:12px 0;">
            <h3 style="margin-top:0; font-size:1.05em;">Encadrement décimal vs arrondi / chiffres significatifs</h3>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>encadrement</strong> donne un intervalle précis où le nombre se trouve : on sait que $\displaystyle x$ est entre deux bornes. Un <strong>arrondi</strong> fournit une valeur unique (souvent à un certain nombre de chiffres significatifs) qui est la meilleure approximation dans ce cadre.</p>
            <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:12px; margin:12px 0;">
                <p style="margin:0; text-align:left; font-size:0.97em;"><strong>Exemple 1 (prix)</strong> : une dépense de $\displaystyle 12{,}3478$ € est arrondie à deux décimales pour la caisse, soit $\displaystyle 12{,}35$ € (2 chiffres après la virgule). En parallèle, on peut encadrer ce montant : $\displaystyle 12{,}34 \leq 12{,}3478 < 12{,}35$.</p>
            </div>
            <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:12px; margin:12px 0;">
                <p style="margin:0; text-align:left; font-size:0.97em;"><strong>Exemple 2 (longueur)</strong> : une longueur mesurée à $\displaystyle 3{,}4562\text{ m}$ peut être arrondie à trois chiffres significatifs en donnant $\displaystyle 3{,}46\text{ m}$, tandis que l'encadrement 100‰ donne $\displaystyle 3{,}45 \leq x < 3{,}46$.</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'encadrement est utile pour garantir une marge d'erreur, alors que l'arrondi facilite les calculs et les comparaisons quantitatives, en particulier lorsqu'on précise le nombre de chiffres significatifs adaptés à la situation.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Nombres rationnels et irrationnels</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">L'ensemble ℚ des nombres rationnels</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Nombre rationnel</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>nombre rationnel</strong> est un nombre qui peut s'écrire sous la forme $\displaystyle \frac{p}{q}$ où $\displaystyle p$ et $\displaystyle q$ sont des entiers relatifs avec $\displaystyle q \neq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ensemble des nombres rationnels est noté $\displaystyle \mathbb{Q}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \frac{3}{4}$ est un nombre rationnel</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle -5 = \frac{-5}{1}$ est un nombre rationnel</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 0,75 = \frac{3}{4}$ est un nombre rationnel</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \frac{1}{3} = 0,333...$ est un nombre rationnel</li>
                <li style="margin:0; text-align:left;">Tout nombre décimal est un nombre rationnel</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tout nombre rationnel a un <strong>développement décimal périodique</strong> (ou fini, qui est un cas particulier de périodique).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : $\displaystyle \frac{1}{3} = 0,\overline{3}$ (la période est $\displaystyle 3$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \frac{1}{7} = 0,\overline{142857}$ (la période est $\displaystyle 142857$)</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Nombres irrationnels</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Nombre irrationnel</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>nombre irrationnel</strong> est un nombre réel qui <strong>n'est pas rationnel</strong>, c'est-à-dire qui ne peut pas s'écrire sous la forme $\displaystyle \frac{p}{q}$ avec $\displaystyle p$ et $\displaystyle q$ entiers ($\displaystyle q \neq 0$).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ensemble des nombres irrationnels est noté $\displaystyle \mathbb{R} \setminus \mathbb{Q}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples classiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle \sqrt{2}$</strong> : nombre irrationnel (démontré ci-dessous)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle \pi$</strong> : nombre irrationnel (démontré en classes supérieures)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle e$</strong> : nombre irrationnel (base du logarithme népérien)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle \sqrt{3}$</strong>, $\displaystyle \sqrt{5}$ : nombres irrationnels</li>
                <li style="margin:0; text-align:left;">En général, si $\displaystyle n$ est un entier qui n'est pas un carré parfait, alors $\displaystyle \sqrt{n}$ est irrationnel</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un nombre irrationnel a un <strong>développement décimal illimité non périodique</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : $\displaystyle \sqrt{2} = 1,414213562373095...$ (développement infini, non périodique)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \pi = 3,141592653589793...$ (développement infini, non périodique)</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démonstration : 1/3 n'est pas décimal</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le nombre rationnel $\displaystyle \frac{1}{3}$ n'est <strong>pas</strong> un nombre décimal.</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Supposons par l'absurde que $\displaystyle \frac{1}{3}$ soit un nombre décimal.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Alors il existe un entier $\displaystyle a$ et un entier naturel $\displaystyle n$ tels que :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \frac{1}{3} = \frac{a}{10^n}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En multipliant par $\displaystyle 3 \times 10^n$ de chaque côté :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 10^n = 3a$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle 10^n$ est divisible par $\displaystyle 3$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Or, $\displaystyle 10^n = 2^n \times 5^n$ n'est divisible que par $\displaystyle 2$ et $\displaystyle 5$, pas par $\displaystyle 3$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est une contradiction. Donc $\displaystyle \frac{1}{3}$ n'est pas un nombre décimal. ✓</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <h3 style="color:#34495e; margin-top:0;">Démonstration : $\sqrt{2}$ est irrationnel</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le nombre réel $\displaystyle \sqrt{2}$ est <strong>irrationnel</strong>.</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration par l'absurde :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Supposons que $\displaystyle \sqrt{2}$ soit rationnel.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Alors il existe deux entiers naturels $\displaystyle p$ et $\displaystyle q$ (avec $\displaystyle q \neq 0$) tels que :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sqrt{2} = \frac{p}{q}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut supposer que la fraction $\displaystyle \frac{p}{q}$ est irréductible (simplifiée au maximum).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En élevant au carré : $\displaystyle 2 = \frac{p^2}{q^2}$, donc $\displaystyle p^2 = 2q^2$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle p^2$ est pair, ce qui implique que $\displaystyle p$ est pair (si $\displaystyle p$ était impair, $\displaystyle p^2$ serait impair).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Écrivons $\displaystyle p = 2k$ avec $\displaystyle k \in \mathbb{N}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Alors : $\displaystyle p^2 = 4k^2 = 2q^2$, donc $\displaystyle 2k^2 = q^2$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle q^2$ est pair, ce qui implique que $\displaystyle q$ est pair.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Mais alors $\displaystyle p$ et $\displaystyle q$ sont tous les deux pairs, donc la fraction $\displaystyle \frac{p}{q}$ n'est pas irréductible (on peut diviser par $\displaystyle 2$).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est une contradiction avec notre hypothèse.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle \sqrt{2}$ est irrationnel. ✓</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Remarque :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette démonstration utilise le <strong>raisonnement par l'absurde</strong> : on suppose le contraire de ce qu'on veut prouver, et on montre que cela mène à une contradiction.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Algorithme : encadrement de $\sqrt{2}$ par balayage</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Principe de l'algorithme</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Objectif</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Déterminer par balayage un encadrement de $\displaystyle \sqrt{2}$ d'amplitude inférieure ou égale à $\displaystyle 10^{-n}$ (où $\displaystyle n$ est un entier naturel donné).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Principe :</strong> On teste successivement les nombres décimaux jusqu'à trouver deux décimaux consécutifs $\displaystyle d$ et $\displaystyle d + 10^{-n}$ tels que $\displaystyle d^2 \leq 2 < (d + 10^{-n})^2$.</p>

                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace; color:#e74c3c;">=A2+0.01</td>
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace; color:#e74c3c;">=A3$\ast$A3</td>
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace; color:#e74c3c;">=B3<2</td>
                    </tr>
                    <tr style="background:#ffffff;">
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-weight:bold; background:#e8f4f8;">...</td>
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace;">...</td>
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace;">...</td>
                        <td style="border:1px solid #ddd; padding:8px; text-align:center; font-family:monospace;">...</td>
                    </tr>
                </tbody>
            </table>
            <p style="margin:8px 0; text-align:left; font-size:0.9em; color:#7f8c8d;"><em>Les formules en rouge sont à recopier vers le bas. On cherche la première ligne où $\displaystyle d^2 \geq 2$. Pour $\displaystyle n = 2$ (précision $10^{-2}$), on trouve $\displaystyle 1,41 \leq \sqrt{2} < 1,42$.</em></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple d'exécution :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle n = 3$ (précision $10^{-3}$) :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">On teste $\displaystyle d = 1,414$ : $\displaystyle 1,414^2 = 1,999396 < 2$ ✓</li>
                <li style="margin:0 0 18px 0; text-align:left;">On teste $\displaystyle d = 1,415$ : $\displaystyle 1,415^2 = 2,002225 \geq 2$ ✗</li>
                <li style="margin:0; text-align:left;">Donc : $\displaystyle 1,414 \leq \sqrt{2} < 1,415$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Approfondissements possibles</h2>

    <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:12px; margin:12px 0;">
        <p style="margin:0; text-align:left; font-size:0.95em;"><strong>🌟 Approfondissement (bonus) :</strong> Les développements suivants enrichissent votre culture mathématique mais ne sont pas strictement exigibles pour les évaluations.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Développement décimal illimité d'un nombre réel</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Développement décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tout nombre réel $\displaystyle x$ admet un <strong>développement décimal</strong> (fini ou illimité).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce développement est de la forme :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle x = a_0,a_1a_2a_3...$ où $\displaystyle a_0$ est un entier et $\displaystyle a_1, a_2, a_3, ...$ sont des chiffres de $\displaystyle 0$ à $\displaystyle 9$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Développement fini :</strong> $\displaystyle 3,75 = 3,75000...$ (une infinité de zéros)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Développement périodique :</strong> $\displaystyle \frac{1}{3} = 0,3333... = 0,\overline{3}$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Développement périodique :</strong> $\displaystyle \frac{1}{7} = 0,142857142857... = 0,\overline{142857}$</li>
                <li style="margin:0; text-align:left;"><strong>Développement non périodique :</strong> $\displaystyle \sqrt{2} = 1,414213562373095...$ (pas de période)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Périodicité du développement décimal des rationnels</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>Propriété (bonus) :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un nombre réel est <strong>rationnel</strong> si et seulement si son développement décimal est <strong>périodique</strong> (ou fini, qui est un cas particulier de périodique avec période $\displaystyle 0$).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples d'observation :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> $\displaystyle \frac{1}{3} = 0,\overline{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La période est $\displaystyle 3$ (un seul chiffre qui se répète).</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> $\displaystyle \frac{1}{7} = 0,\overline{142857}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La période est $\displaystyle 142857$ (six chiffres qui se répètent).</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> $\displaystyle \frac{1}{6} = 0,1\overline{6}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il y a une partie non périodique ($\displaystyle 1$) puis une période ($\displaystyle 6$).</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 4 :</strong> $\displaystyle \sqrt{2} = 1,414213562373095...$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le développement est <strong>non périodique</strong>, donc $\displaystyle \sqrt{2}$ est irrationnel.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Remarque culture :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La longueur de la période d'un nombre rationnel $\displaystyle \frac{p}{q}$ (avec $\displaystyle q \neq 0$) est toujours inférieure ou égale à $\displaystyle q-1$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple, pour $\displaystyle \frac{1}{7}$, la période a une longueur de $\displaystyle 6$ (qui est $\displaystyle 7-1$).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes générales</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pratiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Vérifier l'appartenance à un intervalle :</strong> Remplacer $\displaystyle x$ par le nombre dans l'inégalité</li>
                <li style="margin:0; text-align:left;"><strong>Notation des intervalles :</strong> Crochet vers l'intérieur = inclus, crochet vers l'extérieur = exclu</li>
                <li style="margin:0; text-align:left;"><strong>Valeur absolue :</strong> $\displaystyle |a|$ est toujours positif ou nul, $\displaystyle |a| = |-a|$</li>
                <li style="margin:0; text-align:left;"><strong>Distance :</strong> $\displaystyle d(a, b) = |b - a| = |a - b|$</li>
                <li style="margin:0; text-align:left;"><strong>Intervalle centré :</strong> $\displaystyle [a - r, a + r] = \{x \mid |x - a| \leq r\}$</li>
                <li style="margin:0; text-align:left;"><strong>Encadrement décimal :</strong> Utiliser la troncature pour obtenir la borne inférieure</li>
                <li style="margin:0; text-align:left;"><strong>Rationnel vs irrationnel :</strong> Rationnel = peut s'écrire $\displaystyle \frac{p}{q}$, irrationnel = développement non périodique</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Intervalles :</strong> Ne pas confondre $\displaystyle [a, b]$ (fermé) et $\displaystyle ]a, b[$ (ouvert)</li>
                <li style="margin:0; text-align:left;"><strong>Infini :</strong> Avec $\displaystyle +\infty$ ou $\displaystyle -\infty$, toujours utiliser un crochet ouvert</li>
                <li style="margin:0; text-align:left;"><strong>Valeur absolue :</strong> $\displaystyle |a|$ n'est pas toujours égal à $\displaystyle a$ (seulement si $\displaystyle a \geq 0$)</li>
                <li style="margin:0; text-align:left;"><strong>Distance :</strong> La distance est toujours positive, $\displaystyle d(a, b) = d(b, a)$</li>
                <li style="margin:0; text-align:left;"><strong>Décimal vs rationnel :</strong> Tous les décimaux sont rationnels, mais tous les rationnels ne sont pas décimaux</li>
                <li style="margin:0; text-align:left;"><strong>Encadrement :</strong> Attention à l'inégalité large $\displaystyle \leq$ ou stricte $\displaystyle <$ selon le contexte</li>
                <li style="margin:0; text-align:left;"><strong>Développement décimal :</strong> Un développement fini est un cas particulier de développement périodique (période 0)</li>
            </ul>
        </div>
