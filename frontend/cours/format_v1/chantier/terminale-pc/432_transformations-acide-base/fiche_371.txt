Titre: Résumé : Transformations acide-base

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : acides et bases de Brönsted, couples, équation d’une réaction acide-base, schémas de Lewis, espèces amphotères, pH. Programme de spécialité de Terminale.
:::

## I. Acides, bases, couples

1. **Acide** : cède un ion $\ce{H+}$. **Base** : capte un ion $\ce{H+}$.
2. Couple acide/base, demi-équation : $\text{acide} = \text{base} + \ce{H+}$ (un $\mathrm{H}$ et une charge $+1$ de plus pour l’acide).
3. **Réaction acide-base** : $\text{acide}_1 + \text{base}_2 \longrightarrow \text{base}_1 + \text{acide}_2$. On additionne la demi-équation de l’acide (sens « cède $\ce{H+}$ ») et celle de la base (sens « capte $\ce{H+}$ ») : les $\ce{H+}$ s’éliminent.
4. $\longrightarrow$ : transformation totale ; $\rightleftharpoons$ : transformation non totale.

::: formule Exemple
$$\ce{CH3COOH + NH3 -> CH3COO- + NH4+}$$
:::

## II. Couples à connaître

- $\ce{H3O+}/\ce{H2O}$ : ion oxonium / eau.
- $\ce{H2O}/\ce{HO-}$ : eau / ion hydroxyde.
- $\ce{CO2,H2O}/\ce{HCO3-}$ : $\ce{CO2}$ dissous / hydrogénocarbonate.
- $\ce{HCO3-}/\ce{CO3^2-}$ : hydrogénocarbonate / carbonate.
- $\ce{R-COOH}/\ce{R-COO-}$ : acide carboxylique / carboxylate.
- $\ce{R-NH3+}/\ce{R-NH2}$ : ion ammonium / amine.

**Amphotère** : acide d’un couple et base d’un autre. Exemples : $\ce{H2O}$, $\ce{HCO3-}$.

- $\ce{-COOH}$ cède l’hydrogène de la liaison $\mathrm{O{-}H}$, très polarisée.
- L’azote d’une amine capte $\ce{H+}$ grâce à son doublet non liant.
- Charge d’un atome $=$ électrons de valence $-$ électrons non liants $-$ liaisons. Oxygène du carboxylate : $6 - 6 - 1 = -1$. Azote de l’ammonium : $5 - 0 - 4 = +1$.

## IV. Le pH

::: formule Définition ($c^\circ = 1\ \mathrm{mol\cdot L^{-1}}$)
$$\mathrm{pH} = -\log\left(\frac{[\ce{H3O+}]}{c^\circ}\right)$$

$$[\ce{H3O+}] = c^\circ \times 10^{-\mathrm{pH}}$$
:::

1. $[\ce{H3O+}]$ multipliée par $10$ : le pH diminue de $1$.
2. À $25\ ^\circ\mathrm{C}$ : acide si $\mathrm{pH} \lt 7$, neutre si $\mathrm{pH} = 7$, basique si $\mathrm{pH} \gt 7$.
3. Décimales du pH $=$ chiffres significatifs de $[\ce{H3O+}]$ : $2{,}5 \times 10^{-4}\ \mathrm{mol\cdot L^{-1}} \leftrightarrow \mathrm{pH} = 3{,}60$.
4. Acide chlorhydrique (réaction totale avec l’eau) : $[\ce{H3O+}] = c$, une dilution d’un facteur $10$ augmente le pH de $1$.

## V. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Écrire $\ce{H2SO4}/\ce{SO4^2-}$ : un couple ne diffère que d’**un seul** ion $\ce{H+}$.
2. Laisser des ions $\ce{H+}$ dans l’équation de la réaction : ils doivent s’éliminer.
3. Placer la charge de l’ion carboxylate sur le carbone : elle est sur un oxygène.
4. Arrondir le pH sans respecter la règle des chiffres significatifs.
:::
