=== Équations du Premier Degré - Avec Développements
Id: 1025
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre les équations du premier degré suivantes nécessitant un développement.

1. Résoudre $\displaystyle 2(x + 3) = 4x - 1$
2. Résoudre $\displaystyle 3(x - 2) - 2(x + 1) = x + 4$
3. Résoudre $\displaystyle 5(x + 1) = 2(x - 3) + 11$
4. Résoudre $\displaystyle 4(x - 1) + 3 = 2x + 7$
5. Résoudre $\displaystyle 2(3x + 1) = 3(x - 2) + 8$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle 2(x + 3) = 4x - 1$

::: methode
Développer puis résoudre
:::

::: etape Développer le membre de gauche
- $\displaystyle 2(x + 3) = 2x + 6$
:::

::: etape L'équation devient
$$2x + 6 = 4x - 1$$
:::

::: etape Transposer les termes
- $\displaystyle 2x - 4x = -1 - 6$
:::

::: etape Simplifier
- $\displaystyle -2x = -7$
:::

::: etape Diviser par $\displaystyle -2$
- $\displaystyle x = \dfrac{7}{2}$
:::

::: point Vérification
Pour $\displaystyle x = \dfrac{7}{2}$ :

$$
\begin{aligned}
2\left(\dfrac{7}{2} + 3\right) &= 2\left(\dfrac{7}{2} + \dfrac{6}{2}\right) \\
&= 2 \times \dfrac{13}{2} \\
&= 13
\end{aligned}
$$

- $\displaystyle 4 \times \dfrac{7}{2} - 1 = 14 - 1 = 13$
:::

::: resultat
L'équation admet une solution : $x = \dfrac{7}{2}$
:::

## Question 2 : Résoudre $\displaystyle 3(x - 2) - 2(x + 1) = x + 4$

::: methode
Développer puis résoudre
:::

::: etape Développer les parenthèses
- $\displaystyle 3(x - 2) = 3x - 6$
- $\displaystyle 2(x + 1) = 2x + 2$
- $\displaystyle 3(x - 2) - 2(x + 1) = 3x - 6 - 2x - 2 = x - 8$
:::

::: etape L'équation devient
$$x - 8 = x + 4$$
:::

::: etape Transposer les termes
- $\displaystyle x - x = 4 + 8$
:::

::: etape Simplifier
- $\displaystyle 0 = 12$
:::

::: resultat
Cette égalité est fausse. L'équation n'a aucune solution.
:::

::: resultat
L'équation n'admet aucune solution.
:::

## Question 3 : Résoudre $\displaystyle 5(x + 1) = 2(x - 3) + 11$

::: methode
Développer puis résoudre
:::

::: etape Développer les deux membres
- $\displaystyle 5(x + 1) = 5x + 5$
- $\displaystyle 2(x - 3) + 11 = 2x - 6 + 11 = 2x + 5$
:::

::: etape L'équation devient
$$5x + 5 = 2x + 5$$
:::

::: etape Transposer les termes
- $\displaystyle 5x - 2x = 5 - 5$
:::

::: etape Simplifier
- $\displaystyle 3x = 0$
:::

::: etape Diviser par $\displaystyle 3$
- $\displaystyle x = 0$
:::

::: point Vérification
- Pour $x = 0$ : $5(0 + 1) = 5 \times 1 = 5$
- $\displaystyle 2(0 - 3) + 11 = 2(-3) + 11 = -6 + 11 = 5$
:::

::: resultat
L'équation admet une solution : $x = 0$
:::

## Question 4 : Résoudre $\displaystyle 4(x - 1) + 3 = 2x + 7$

::: methode
Développer puis résoudre
:::

::: etape Développer le membre de gauche
- $\displaystyle 4(x - 1) + 3 = 4x - 4 + 3 = 4x - 1$
:::

::: etape L'équation devient
$$4x - 1 = 2x + 7$$
:::

::: etape Transposer les termes
- $\displaystyle 4x - 2x = 7 + 1$
:::

::: etape Simplifier
- $\displaystyle 2x = 8$
:::

::: etape Diviser par $\displaystyle 2$
- $\displaystyle x = 4$
:::

::: point Vérification
- Pour $x = 4$ : $4(4 - 1) + 3 = 4 \times 3 + 3 = 12 + 3 = 15$
- $\displaystyle 2(4) + 7 = 8 + 7 = 15$
:::

::: resultat
L'équation admet une solution : $x = 4$
:::

## Question 5 : Résoudre $\displaystyle 2(3x + 1) = 3(x - 2) + 8$

::: methode
Développer puis résoudre
:::

::: etape Développer les deux membres
- $\displaystyle 2(3x + 1) = 6x + 2$
- $\displaystyle 3(x - 2) + 8 = 3x - 6 + 8 = 3x + 2$
:::

::: etape L'équation devient
$$6x + 2 = 3x + 2$$
:::

::: etape Transposer les termes
- $\displaystyle 6x - 3x = 2 - 2$
:::

::: etape Simplifier
- $\displaystyle 3x = 0$
:::

::: etape Diviser par $\displaystyle 3$
- $\displaystyle x = 0$
:::

::: point Vérification
- Pour $x = 0$ : $2(3(0) + 1) = 2(1) = 2$
- $\displaystyle 3(0 - 2) + 8 = 3(-2) + 8 = -6 + 8 = 2$
:::

::: resultat
L'équation admet une solution : $x = 0$
:::

Solution:
<!-- optitab:1 -->
1. $2(x + 3) = 4x - 1$ : $x = \dfrac{7}{2}$
2. $\displaystyle 3(x - 2) - 2(x + 1) = x + 4$ : Aucune solution
3. $5(x + 1) = 2(x - 3) + 11$ : $x = 0$
4. $4(x - 1) + 3 = 2x + 7$ : $x = 4$
5. $2(3x + 1) = 3(x - 2) + 8$ : $x = 0$

=== Équations du Premier Degré - Avec Fractions
Id: 1026
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre les équations du premier degré suivantes contenant des fractions.

1. Résoudre $\displaystyle \dfrac{x}{2} + 3 = 5$
2. Résoudre $\displaystyle \dfrac{x + 1}{3} = \dfrac{x - 2}{2}$
3. Résoudre $\displaystyle \dfrac{2x - 1}{4} + \dfrac{x}{3} = 1$
4. Résoudre $\displaystyle \dfrac{x}{5} - 2 = \dfrac{x + 1}{3}$
5. Résoudre $\displaystyle \dfrac{3x + 2}{2} = \dfrac{x - 1}{4} + 5$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle \dfrac{x}{2} + 3 = 5$

::: methode
Isoler la fraction puis multiplier par le dénominateur
:::

::: etape Isoler la fraction
- $\displaystyle \dfrac{x}{2} = 5 - 3 = 2$
:::

::: etape Multiplier par $\displaystyle 2$
- $\displaystyle x = 2 \times 2 = 4$
:::

::: point Vérification
- Pour $x = 4$ : $\dfrac{4}{2} + 3 = 2 + 3 = 5$
:::

::: resultat
L'équation admet une solution : $x = 4$
:::

## Question 2 : Résoudre $\displaystyle \dfrac{x + 1}{3} = \dfrac{x - 2}{2}$

::: methode
Produit en croix
:::

::: etape Appliquer le produit en croix
- $\displaystyle 2(x + 1) = 3(x - 2)$
:::

::: etape Développer
- $\displaystyle 2x + 2 = 3x - 6$
:::

::: etape Transposer les termes
- $\displaystyle 2x - 3x = -6 - 2$
:::

::: etape Simplifier
- $\displaystyle -x = -8$
:::

::: etape Multiplier par $\displaystyle -1$
- $\displaystyle x = 8$
:::

::: point Vérification
- Pour $x = 8$ : $\dfrac{8 + 1}{3} = \dfrac{9}{3} = 3$
- $\displaystyle \dfrac{8 - 2}{2} = \dfrac{6}{2} = 3$
:::

::: resultat
L'équation admet une solution : $x = 8$
:::

## Question 3 : Résoudre $\displaystyle \dfrac{2x - 1}{4} + \dfrac{x}{3} = 1$

::: methode
Mettre au même dénominateur
:::

::: etape Dénominateur commun
$$12$$
:::

::: etape Multiplier toute l'équation par $12$
- $\displaystyle 12 \times \dfrac{2x - 1}{4} + 12 \times \dfrac{x}{3} = 12 \times 1$
:::

::: etape Simplifier
- $\displaystyle 3(2x - 1) + 4x = 12$
:::

::: etape Développer
- $\displaystyle 6x - 3 + 4x = 12$
:::

::: etape Réduire
- $\displaystyle 10x - 3 = 12$
:::

::: etape Transposer
- $\displaystyle 10x = 12 + 3 = 15$
:::

::: etape Diviser par $\displaystyle 10$
- $\displaystyle x = \dfrac{15}{10} = \dfrac{3}{2}$
:::

::: point Vérification
Pour $\displaystyle x = \dfrac{3}{2}$ :

$$
\begin{aligned}
\dfrac{2 \times \dfrac{3}{2} - 1}{4} + \dfrac{\dfrac{3}{2}}{3} &= \dfrac{3 - 1}{4} + \dfrac{1}{2} \\
&= \dfrac{2}{4} + \dfrac{1}{2} \\
&= \dfrac{1}{2} + \dfrac{1}{2} \\
&= 1
\end{aligned}
$$
:::

::: resultat
L'équation admet une solution : $x = \dfrac{3}{2}$
:::

## Question 4 : Résoudre $\displaystyle \dfrac{x}{5} - 2 = \dfrac{x + 1}{3}$

::: methode
Mettre au même dénominateur
:::

::: etape Dénominateur commun
$$15$$
:::

::: etape Multiplier toute l'équation par $15$
- $\displaystyle 15 \times \dfrac{x}{5} - 15 \times 2 = 15 \times \dfrac{x + 1}{3}$
:::

::: etape Simplifier
- $\displaystyle 3x - 30 = 5(x + 1)$
:::

::: etape Développer
- $\displaystyle 3x - 30 = 5x + 5$
:::

::: etape Transposer les termes
- $\displaystyle 3x - 5x = 5 + 30$
:::

::: etape Simplifier
- $\displaystyle -2x = 35$
:::

::: etape Diviser par $\displaystyle -2$
- $\displaystyle x = -\dfrac{35}{2}$
:::

::: point Vérification
Pour $\displaystyle x = -\dfrac{35}{2}$ :

$$
\begin{aligned}
\dfrac{-\dfrac{35}{2}}{5} - 2 &= -\dfrac{35}{10} - 2 \\
&= -\dfrac{7}{2} - \dfrac{4}{2} \\
&= -\dfrac{11}{2}
\end{aligned}
$$

$$
\begin{aligned}
\dfrac{-\dfrac{35}{2} + 1}{3} &= \dfrac{-\dfrac{33}{2}}{3} \\
&= -\dfrac{33}{6} \\
&= -\dfrac{11}{2}
\end{aligned}
$$
:::

::: resultat
L'équation admet une solution : $x = -\dfrac{35}{2}$
:::

## Question 5 : Résoudre $\displaystyle \dfrac{3x + 2}{2} = \dfrac{x - 1}{4} + 5$

::: methode
Mettre au même dénominateur
:::

::: etape Dénominateur commun
$$4$$
:::

::: etape Multiplier toute l'équation par $4$
- $\displaystyle 4 \times \dfrac{3x + 2}{2} = 4 \times \dfrac{x - 1}{4} + 4 \times 5$
:::

::: etape Simplifier
- $\displaystyle 2(3x + 2) = x - 1 + 20$
:::

::: etape Développer et simplifier
- $\displaystyle 6x + 4 = x + 19$
:::

::: etape Transposer les termes
- $\displaystyle 6x - x = 19 - 4$
:::

::: etape Simplifier
- $\displaystyle 5x = 15$
:::

::: etape Diviser par $\displaystyle 5$
- $\displaystyle x = 3$
:::

::: point Vérification
- Pour $x = 3$ : $\dfrac{3(3) + 2}{2} = \dfrac{11}{2}$

$$
\begin{aligned}
\dfrac{3 - 1}{4} + 5 &= \dfrac{2}{4} + 5 \\
&= \dfrac{1}{2} + 5 \\
&= \dfrac{11}{2}
\end{aligned}
$$
:::

::: resultat
L'équation admet une solution : $x = 3$
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{x}{2} + 3 = 5$ : $x = 4$
2. $\dfrac{x + 1}{3} = \dfrac{x - 2}{2}$ : $x = 8$
3. $\dfrac{2x - 1}{4} + \dfrac{x}{3} = 1$ : $x = \dfrac{3}{2}$
4. $\dfrac{x}{5} - 2 = \dfrac{x + 1}{3}$ : $x = -\dfrac{35}{2}$
5. $\dfrac{3x + 2}{2} = \dfrac{x - 1}{4} + 5$ : $x = 3$

&= \dfrac{37}{3}
\end{aligned}

## Question 1 : Un commerçant a vendu 45 objets. Le nombre d'objets vendus le premier jour est le double de ceux vendus le second jour, et le total est 45. Combien d'objets a-t-il vendus chaque jour ?

## Question 4 : Un train parcourt 240 km à vitesse constante. S'il avait roulé 10 km/h plus vite, il aurait mis 30 minutes de moins. Quelle est la vitesse du train ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $v$ la vitesse du train (en km/h)
- Temps actuel : $\displaystyle t = \dfrac{240}{v}$ (en heures)
- Vitesse plus rapide : $\displaystyle v + 10$ (en km/h)
- Temps avec vitesse plus rapide : $t' = \dfrac{240}{v + 10}$ (en heures)
:::

::: etape Traduire le problème en équation
- $30$ minutes = $\dfrac{1}{2}$ heure
- $\displaystyle \dfrac{240}{v} - \dfrac{240}{v + 10} = \dfrac{1}{2}$
:::

::: etape Multiplier par $\displaystyle 2v(v + 10)$
- $\displaystyle 2(v + 10) \times 240 - 2v \times 240 = v(v + 10)$
- $\displaystyle 480(v + 10) - 480v = v(v + 10)$
:::

::: etape Développer
- $\displaystyle 480v + 4800 - 480v = v^2 + 10v$
- $\displaystyle 4800 = v^2 + 10v$
:::

::: etape Mettre sous forme standard
- $\displaystyle v^2 + 10v - 4800 = 0$
:::

::: remarque
Cette équation est du second degré. On peut la résoudre par discriminant.

$$
\begin{aligned}
\Delta &= 10^2 - 4 \times 1 \times (-4800) \\
&= 100 + 19200 \\
&= 19300
\end{aligned}
$$
:::

::: point Solution positive
$v = \dfrac{-10 + \sqrt{19300}}{2} = \dfrac{-10 + 10\sqrt{193}}{2} = -5 + 5\sqrt{193}$ ≈ $64,3$ km/h
:::

::: point Vérification
- $t = \dfrac{240}{64,3} ≈ 3,73$ h = $3$ h $44$ min
- $t' = \dfrac{240}{74,3} ≈ 3,23$ h = $3$ h $14$ min
- Différence : $3$ h $44$ min - $3$ h $14$ min = $30$ min
:::

::: resultat
La vitesse du train est environ $64,3$ km/h (ou $\dfrac{-10 + \sqrt{19300}}{2}$ km/h)
:::

=== Équations du Premier Degré - Problèmes et Applications
Id: 1028
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre les problèmes suivants en les mettant en équation puis en résolvant.

1. Un nombre augmenté de 7 est égal au triple de ce nombre diminué de 5. Quel est ce nombre ?
2. La somme de trois nombres consécutifs est égale à 24. Quels sont ces nombres ?
3. Le double d'un nombre augmenté de 3 est égal au triple de ce nombre diminué de 1. Quel est ce nombre ?
4. Un père a 35 ans et son fils a 7 ans. Dans combien d'années le père aura-t-il le triple de l'âge du fils ?
5. Un rectangle a une longueur de 8 cm de plus que sa largeur. Si le périmètre est de 44 cm, quelles sont les dimensions du rectangle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Un nombre augmenté de 7 est égal au triple de ce nombre diminué de 5. Quel est ce nombre ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $\displaystyle x$ le nombre cherché
:::

::: etape Traduire le problème en équation
- « Un nombre augmenté de 7 » : $\displaystyle x + 7$
- « Le triple de ce nombre diminué de 5 » : $3x - 5$
- L'équation est : $\displaystyle x + 7 = 3x - 5$
:::

::: etape Résoudre l'équation
- $\displaystyle x - 3x = -5 - 7$
- $\displaystyle -2x = -12$
- $\displaystyle x = 6$
:::

::: point Vérification
- $\displaystyle 6 + 7 = 13$
- $\displaystyle 3 \times 6 - 5 = 18 - 5 = 13$
:::

::: resultat
Le nombre cherché est $\displaystyle 6$
:::

## Question 2 : La somme de trois nombres consécutifs est égale à 24. Quels sont ces nombres ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $\displaystyle x$ le premier nombre
- Alors les autres sont $x + 1$ et $x + 2$
:::

::: etape Traduire le problème en équation
- $\displaystyle x + (x + 1) + (x + 2) = 24$
:::

::: etape Simplifier
- $\displaystyle 3x + 3 = 24$
:::

::: etape Résoudre
- $\displaystyle 3x = 21$
- $\displaystyle x = 7$
:::

::: point Vérification
- $\displaystyle 7 + 8 + 9 = 24$
:::

::: resultat
Les trois nombres sont $7$, $8$ et $9$
:::

## Question 3 : Le double d'un nombre augmenté de 3 est égal au triple de ce nombre diminué de 1. Quel est ce nombre ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $\displaystyle x$ le nombre cherché
:::

::: etape Traduire le problème en équation
- « Le double d'un nombre augmenté de 3 » : $2x + 3$
- « Le triple de ce nombre diminué de 1 » : $3x - 1$
- L'équation est : $\displaystyle 2x + 3 = 3x - 1$
:::

::: etape Résoudre l'équation
- $\displaystyle 2x - 3x = -1 - 3$
- $\displaystyle -x = -4$
- $\displaystyle x = 4$
:::

::: point Vérification
- $\displaystyle 2 \times 4 + 3 = 8 + 3 = 11$
- $\displaystyle 3 \times 4 - 1 = 12 - 1 = 11$
:::

::: resultat
Le nombre cherché est $\displaystyle 4$
:::

## Question 4 : Un père a 35 ans et son fils a 7 ans. Dans combien d'années le père aura-t-il le triple de l'âge du fils ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $x$ le nombre d'années cherché
:::

::: etape Traduire le problème en équation
- Dans $x$ années, le père aura $35 + x$ ans
- Dans $x$ années, le fils aura $7 + x$ ans
- L'équation est : $\displaystyle 35 + x = 3(7 + x)$
:::

::: etape Développer et résoudre
- $\displaystyle 35 + x = 21 + 3x$
- $\displaystyle 35 - 21 = 3x - x$
- $\displaystyle 14 = 2x$
- $\displaystyle x = 7$
:::

::: point Vérification
- Dans 7 ans, le père aura $\displaystyle 35 + 7 = 42$ ans
- Dans 7 ans, le fils aura $\displaystyle 7 + 7 = 14$ ans
- $\displaystyle 3 \times 14 = 42$
:::

::: resultat
Dans $7$ ans, le père aura le triple de l'âge du fils.
:::

## Question 5 : Un rectangle a une longueur de 8 cm de plus que sa largeur. Si le périmètre est de 44 cm, quelles sont les dimensions du rectangle ?

::: methode
Mise en équation puis résolution
:::

::: etape Soit $\displaystyle x$ la largeur (en cm)
- Alors la longueur est $\displaystyle x + 8$ (en cm)
:::

::: etape Traduire le problème en équation
Le périmètre :

$$
\begin{aligned}
2 \times \text{longueur} + 2 \times \text{largeur} &= 2(x + 8) + 2x \\
&= 44
\end{aligned}
$$
:::

::: etape Développer et résoudre
- $\displaystyle 2x + 16 + 2x = 44$
- $\displaystyle 4x + 16 = 44$
- $\displaystyle 4x = 28$
- $\displaystyle x = 7$
:::

::: etape Calculer les dimensions
- Largeur : $\displaystyle x = 7$ cm
- Longueur : $\displaystyle x + 8 = 7 + 8 = 15$ cm
:::

::: point Vérification
- Périmètre : $\displaystyle 2 \times 15 + 2 \times 7 = 30 + 14 = 44$
:::

::: resultat
Le rectangle a une largeur de $7$ cm et une longueur de $15$ cm.
:::

Solution:
<!-- optitab:1 -->
1. Le nombre cherché est $\displaystyle 6$
2. Les trois nombres sont $7$, $8$ et $9$
3. Le nombre cherché est $\displaystyle 4$
4. Dans $7$ ans, le père aura le triple de l'âge du fils
5. Le rectangle a une largeur de $7$ cm et une longueur de $15$ cm

=== Équations du Premier Degré - Résolution Simple
Id: 1023
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Résoudre les équations du premier degré suivantes.

1. Résoudre $\displaystyle 3x + 5 = 0$
2. Résoudre $\displaystyle 2x - 7 = 0$
3. Résoudre $\displaystyle -4x + 8 = 0$
4. Résoudre $\displaystyle 5x - 10 = 0$
5. Résoudre $\displaystyle -x + 3 = 0$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle 3x + 5 = 0$

::: methode
Isoler $x$ en transposant et en divisant
:::

::: etape Transposer le terme constant
- $\displaystyle 3x = -5$
:::

::: etape Diviser par le coefficient de $x$
- $\displaystyle x = -\dfrac{5}{3}$
:::

::: point Vérification
- Pour $x = -\dfrac{5}{3}$ : $3 \times \left(-\dfrac{5}{3}\right) + 5 = -5 + 5 = 0$
:::

::: resultat
L'équation admet une solution : $x = -\dfrac{5}{3}$
:::

## Question 2 : Résoudre $\displaystyle 2x - 7 = 0$

::: methode
Isoler $x$ en transposant et en divisant
:::

::: etape Transposer le terme constant
- $\displaystyle 2x = 7$
:::

::: etape Diviser par le coefficient de $x$
- $\displaystyle x = \dfrac{7}{2}$
:::

::: point Vérification
- Pour $x = \dfrac{7}{2}$ : $2 \times \dfrac{7}{2} - 7 = 7 - 7 = 0$
:::

::: resultat
L'équation admet une solution : $x = \dfrac{7}{2}$
:::

## Question 3 : Résoudre $\displaystyle -4x + 8 = 0$

::: methode
Isoler $x$ en transposant et en divisant
:::

::: etape Transposer le terme constant
- $\displaystyle -4x = -8$
:::

::: etape Diviser par le coefficient de $x$
- $\displaystyle x = \dfrac{-8}{-4} = 2$
:::

::: point Vérification
- Pour $x = 2$ : $-4 \times 2 + 8 = -8 + 8 = 0$
:::

::: resultat
L'équation admet une solution : $x = 2$
:::

## Question 4 : Résoudre $\displaystyle 5x - 10 = 0$

::: methode
Isoler $x$ en transposant et en divisant
:::

::: etape Transposer le terme constant
- $\displaystyle 5x = 10$
:::

::: etape Diviser par le coefficient de $x$
- $\displaystyle x = \dfrac{10}{5} = 2$
:::

::: point Vérification
- Pour $x = 2$ : $5 \times 2 - 10 = 10 - 10 = 0$
:::

::: resultat
L'équation admet une solution : $x = 2$
:::

## Question 5 : Résoudre $\displaystyle -x + 3 = 0$

::: methode
Isoler $x$ en transposant et en divisant
:::

::: etape Transposer le terme constant
- $\displaystyle -x = -3$
:::

::: etape Multiplier par $-1$ (ou diviser par $-1$)
- $\displaystyle x = 3$
:::

::: point Vérification
- Pour $x = 3$ : $-3 + 3 = 0$
:::

::: resultat
L'équation admet une solution : $x = 3$
:::

Solution:
<!-- optitab:1 -->
1. $3x + 5 = 0$ : $x = -\dfrac{5}{3}$
2. $2x - 7 = 0$ : $x = \dfrac{7}{2}$
3. $-4x + 8 = 0$ : $x = 2$
4. $5x - 10 = 0$ : $x = 2$
5. $-x + 3 = 0$ : $x = 3$
