Titre: Résumé : Équations et mise en équation

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : résolution des équations du premier degré, produits nuls, équations de carrés, mise en équation et validation. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Équations du premier degré</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Règles :</strong> ajouter/soustraire une même quantité aux deux membres ; multiplier/diviser par un même nombre <strong>non nul</strong>.</p>
</div>
[IMAGE_1]
<p style="margin:0;"><strong>Méthode :</strong> ① développer ; ② $\displaystyle x$ d'un côté, constantes de l'autre ; ③ isoler $\displaystyle x$ ; ④ <strong>vérifier</strong>.</p>
<p style="margin:6px 0 0 0;"><strong>Exemple :</strong> $\displaystyle 5x - 7 = 2x + 8 \Rightarrow 3x = 15 \Rightarrow x = 5$ (les deux membres valent 18 ✔️).</p>
<p style="margin:6px 0 0 0;"><strong>Fractions :</strong> multiplier TOUS les termes par un dénominateur commun.</p>
<p style="margin:6px 0 0 0;"><strong>Cas limites :</strong> $\displaystyle 2x+3 = 2x+5$ : aucune solution ; $\displaystyle 2(x+3) = 2x+6$ : tous les réels.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Produits nuls et carrés</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">Produit nul ⟺ au moins un facteur nul</p>
</div>
<p style="margin:0;">$\displaystyle (x-4)(2x+3) = 0 \Rightarrow x = 4$ ou $\displaystyle x = -\frac{3}{2}$.</p>
<p style="margin:8px 0 0 0;"><strong>Équation $\displaystyle x^2 = a$ :</strong> $\displaystyle a < 0$ → aucune solution ; $\displaystyle a = 0$ → $\displaystyle x = 0$ ; $\displaystyle a > 0$ → deux solutions $\displaystyle \pm\sqrt{a}$.</p>
<p style="margin:6px 0 0 0;"><strong>Piège :</strong> pour $\displaystyle x^2 = 5x$, factoriser $\displaystyle x(x-5) = 0$ ; diviser par $\displaystyle x$ perdrait la solution 0 !</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Mettre en équation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">① <strong>Choisir l'inconnue</strong> (sens + unité) ; ② exprimer les autres quantités en fonction de $\displaystyle x$ ; ③ traduire l'égalité ; ④ résoudre ; ⑤ <strong>revenir au contexte</strong> (entier ? positif ?).</p>
<p style="margin:8px 0 0 0;"><strong>Traductions :</strong> « double » → $\displaystyle 2x$ ; « dans $\displaystyle a$ ans » → $\displaystyle x+a$ ; « le reste des 28 billets » → $\displaystyle 28-x$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier la solution négative de $\displaystyle x^2 = 49$ (il y a $\displaystyle 7$ ET $\displaystyle -7$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Diviser par l'inconnue (perte de la solution 0).</p>
<p style="margin:6px 0 0 0;">3️⃣ Avec des fractions : oublier de multiplier le second membre.</p>
<p style="margin:6px 0 0 0;">4️⃣ Ne pas vérifier la solution dans l'équation INITIALE et dans le contexte.</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> forme factorisée → produit nul ; « trouver le nombre » → mise en équation ; la vérification écrite rapporte toujours des points !</p>
</div>
