## I. Vocabulaire

| Mot | Sens |
|---|---|
| réduire | regrouper les termes de même nature |
| développer | transformer un produit en somme |
| factoriser | transformer une somme en produit |

- Réduire : $3x + 2x - 1 = 5x - 1$.
- Développer : $3(x + 2) = 3x + 6$.
- Factoriser : $3x + 6 = 3(x + 2)$.

Pour calculer une valeur : remplacer la lettre **entre parenthèses** ; $(-2)^2 = 4$.

## II. Développer

::: formule
$$k(a + b) = ka + kb$$
:::

::: formule

- Écrire les quatre produits, puis réduire.
- $-(a - b) = -a + b$ : le « $-$ » change tous les signes.

## III. Identités remarquables

::: formule
$$(a + b)^2 = a^2 + 2ab + b^2$$
:::

::: formule
$$(a - b)^2 = a^2 - 2ab + b^2$$
:::

::: formule
$$(a + b)(a - b) = a^2 - b^2$$
:::

## IV. Factoriser

1. Facteur commun : $6x^2 - 9x = 3x(2x - 3)$.
2. Parenthèse en facteur : $3x(x - 2) + 5(x - 2) = (x - 2)(3x + 5)$.
3. Différence de deux carrés : $x^2 - 81 = (x - 9)(x + 9)$.
4. Toujours contrôler en redéveloppant.

## V. Démontrer

- Nombre quelconque : $x$ ; entier pair : $2n$ ; impair : $2n + 1$ ; consécutifs : $n$, $n + 1$, $n + 2$.
- Programme de calcul : traduire avec $x$, puis développer et réduire.
- Des exemples ne démontrent rien ; un contre-exemple suffit pour réfuter.

::: attention Erreurs classiques
1. $(a + b)^2 = a^2 + b^2$ : faux, il manque $2ab$.
2. $3x + 2 = 5x$ : faux, termes de natures différentes.
3. $-2(x - 3) = -2x - 6$ : faux, $-2 \times (-3) = +6$.
4. $5x + 5 = 5x$ ou $5(x + 0)$ : faux, c'est $5(x + 1)$.
:::
