Titre: La fonction logarithme népérien

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> définir le logarithme népérien à partir de l’exponentielle, utiliser ses propriétés algébriques, connaître sa dérivée, ses variations, ses limites et les croissances comparées, et résoudre des équations, inéquations et problèmes de seuil.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> pour tout réel $x \gt 0$, l’équation $e^y = x$ admet une unique solution, notée $\ln x$ (logarithme népérien de $x$). Ainsi, pour $x \gt 0$ et $y$ réel : $y = \ln x \iff e^y = x$.</p>
            <p style="margin:6px 0 0 0;"><strong>Conséquences :</strong> $\ln 1 = 0$ ; $\ln e = 1$ ; $e^{\ln x} = x$ pour $x \gt 0$ ; $\ln(e^x) = x$ pour tout réel $x$.</p>
        </div>
        [IMAGE_1]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Propriétés algébriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété fondamentale (démonstration au programme) :</strong> pour tous réels $a \gt 0$ et $b \gt 0$, $\ln(ab) = \ln a + \ln b$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> $e^{\ln a + \ln b} = e^{\ln a}e^{\ln b} = ab = e^{\ln(ab)}$, et l’exponentielle est injective.</p>
            <p style="margin:6px 0 0 0;"><strong>Conséquences :</strong> $\ln\frac{1}{a} = -\ln a$ ; $\ln\frac{a}{b} = \ln a - \ln b$ ; $\ln(a^n) = n\ln a$ ; $\ln\sqrt{a} = \frac{1}{2}\ln a$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemples :</strong> $\ln 8 = 3\ln 2$ ; $\ln\frac{1}{9} = -2\ln 3$ ; $\ln\sqrt{e} = \frac{1}{2}$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> $\ln(a + b) \neq \ln a + \ln b$, et $\ln x$ n’existe que pour $x \gt 0$ : on commence toujours par déterminer le domaine.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Étude de la fonction ln</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Dérivée (démonstration au programme) :</strong> $\ln$ est dérivable sur $]0\,;+\infty[$ et $(\ln x)' = \frac{1}{x}$. <em>Preuve :</em> en dérivant $e^{\ln x} = x$, on obtient $(\ln x)'\,e^{\ln x} = 1$, soit $(\ln x)' \times x = 1$.</p>
            <p style="margin:6px 0 0 0;"><strong>Conséquences :</strong> $\ln$ est strictement croissante sur $]0\,;+\infty[$ ; $\ln a = \ln b \iff a = b$ et $\ln a \lt \ln b \iff a \lt b$ ; $\ln x \lt 0$ sur $]0\,;1[$ et $\ln x \gt 0$ sur $]1\,;+\infty[$.</p>
            <p style="margin:6px 0 0 0;"><strong>Limites :</strong> $\lim\limits_{x \to +\infty} \ln x = +\infty$ ; $\lim\limits_{x \to 0^+} \ln x = -\infty$ ; $\lim\limits_{x \to 0} \frac{\ln(1 + x)}{x} = 1$.</p>
        </div>
        [IMAGE_2]
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Croissances comparées :</strong> $\lim\limits_{x \to +\infty} \frac{\ln x}{x} = 0$ et $\lim\limits_{x \to 0^+} x\ln x = 0$ ; plus généralement $\frac{\ln x}{x^n} \to 0$ en $+\infty$.</p>
        </div>
        [IMAGE_3]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Fonction $\ln u$ :</strong> si $u$ est dérivable et strictement positive, $(\ln u)' = \frac{u'}{u}$. Par exemple $\big(\ln(x^2 + 1)\big)' = \frac{2x}{x^2 + 1}$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Équations, inéquations et seuils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;"><strong>Exemples :</strong></p>
        <p style="font-size:1em;">• $e^{x} = 5 \iff x = \ln 5$ ; $\ln x \le 2 \iff 0 \lt x \le e^2$.</p>
        <p style="font-size:1em;">• $\ln(2x - 1) = \ln(x + 3)$ : domaine $x \gt \frac{1}{2}$ ; alors $2x - 1 = x + 3$, d’où $x = 4$, qui convient.</p>
        <p style="font-size:1em;">• Seuil : $2^n \gt 1\,000 \iff n\ln 2 \gt \ln 1\,000 \iff n \gt \frac{\ln 1\,000}{\ln 2} \approx 9{,}97$, donc $n \ge 10$. De même $0{,}8^n \lt 0{,}001 \iff n \gt \frac{\ln 0{,}001}{\ln 0{,}8} \approx 30{,}96$, donc $n \ge 31$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> diviser par $\ln q$ change le sens de l’inégalité quand $0 \lt q \lt 1$, car alors $\ln q \lt 0$.
        </div>
        [IMAGE_4]
        <p style="font-size:1em;"><strong>Demi-vie :</strong> le carbone 14 suit $N(t) = N_0\,e^{-\lambda t}$. La quantité est divisée par deux au bout de $T$ tel que $e^{-\lambda T} = \frac{1}{2}$, soit $T = \frac{\ln 2}{\lambda}$. Avec $T = 5\,730$ ans, $\lambda = \frac{\ln 2}{5\,730} \approx 1{,}21 \times 10^{-4}$ par an.</p>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $y = \ln x \iff e^y = x$ ($x \gt 0$) ; $\ln(ab) = \ln a + \ln b$, $\ln(a^n) = n\ln a$ ; $(\ln x)' = \frac{1}{x}$, $(\ln u)' = \frac{u'}{u}$ ; $\ln$ croissante, $\lim\limits_{0^+} \ln = -\infty$, $\lim\limits_{+\infty} \ln = +\infty$, $\frac{\ln x}{x} \to 0$ ; on « prend le ln » pour résoudre $q^n \gt A$. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
