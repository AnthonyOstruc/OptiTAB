===Résumé Étudier les variations et les extremums d’une fonction Seconde

Titre: Résumé : Étudier les variations et les extremums d’une fonction

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : sens de variation, tableau de variations, extremums. Programme de Seconde.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Croissante ou décroissante</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">croissante : $u \lt v \Rightarrow f(u) \le f(v)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Décroissante : $u \lt v \Rightarrow f(u) \ge f(v)$ (l’ordre est inversé).</p>
<p style="margin:6px 0 0 0;">• Affine $mx + p$ : croissante si $m \gt 0$, décroissante si $m \lt 0$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Tableau de variations et extremums</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Les flèches donnent le sens de variation, les nombres aux extrémités sont des images.</p>
<p style="margin:6px 0 0 0;">2️⃣ Maximum sur $I$ : la plus grande valeur de $f(x)$, atteinte en au moins un $x$ de $I$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Ici, sur $[-3\,;5]$ : maximum $3$ en $x = 2$, minimum $-2$ en $x = -1$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre le maximum (valeur de $f(x)$) et l’endroit où il est atteint (valeur de $x$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier que l’extremum dépend de l’intervalle étudié (penser aux bornes).</p>
<p style="margin:6px 0 0 0;">3️⃣ Comparer deux images situées sur des intervalles de monotonie différents.</p>
<p style="margin:6px 0 0 0;">4️⃣ « Démontrer » une variation avec seulement quelques valeurs numériques.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour prouver une variation, je prends $u \lt v$ dans l’intervalle et j’étudie le signe de $f(v) - f(u)$.</p>
</div>
