<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les règles de calcul</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:520px;">
<p style="margin:0; font-weight:bold;">$(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Puissances : $a^n a^m = a^{n+m}$ ; $(a^n)^m = a^{nm}$ ; $a^{-n} = \frac{1}{a^n}$.</p>
<p style="margin:6px 0 0 0;">• Racines : $\sqrt{ab} = \sqrt{a}\sqrt{b}$ ($a, b \ge 0$) ; $\sqrt{50} = 5\sqrt{2}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Équations, inéquations, signe</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Produit nul : $A \times B = 0 \iff A = 0$ ou $B = 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $x^2 = a$ : $\pm\sqrt{a}$ si $a \gt 0$ ; $0$ si $a = 0$ ; aucune solution si $a \lt 0$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Multiplier ou diviser par un négatif change le sens de l’inégalité.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire $(a + b)^2 = a^2 + b^2$ : il manque le double produit $2ab$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $\sqrt{a + b} = \sqrt{a} + \sqrt{b}$ : faux ($\sqrt{25} \neq 3 + 4$).</p>
<p style="margin:6px 0 0 0;">3️⃣ Diviser par $x$ pour résoudre $x^2 = 5x$ : on perd la solution $0$ ; il faut factoriser.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de changer le sens en divisant par un négatif : $-2x \le -6 \iff x \ge 3$.</p>
</div>
