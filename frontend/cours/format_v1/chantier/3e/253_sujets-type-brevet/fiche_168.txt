Titre: Résumé : l'essentiel pour le jour du brevet

<!-- optitab:1 -->
::: objectifs
Revoir en une fois les formules, propriétés et réflexes du programme de 3e à connaître le jour de l'épreuve : partie 1 (automatismes, $20$ minutes, sans calculatrice, $6$ points) et partie 2 (problèmes, 1 h 40, $14$ points dont $2$ pour la rédaction).
:::

## I. Nombres et calculs

- **Priorités** : parenthèses, puissances, puis $\times$ et $\div$, puis $+$ et $-$.
- **Relatifs** : $a - (-b) = a + b$ ; le produit de deux nombres de même signe est positif.
- **Fractions** : même dénominateur pour additionner ou soustraire ; pour multiplier, numérateurs et dénominateurs entre eux ; diviser par une fraction, c'est multiplier par son inverse (formules ci-dessous).
- **Puissances** : $a^m \times a^n = a^{m + n}$ ; $\dfrac{a^m}{a^n} = a^{m - n}$ ; $\left(a^m\right)^n = a^{mn}$ ; $10^{-n} = \dfrac{1}{10^n}$.
- **Écriture scientifique** : $a \times 10^n$ avec $1 \leqslant a < 10$, par exemple $0{,}000\,32 = 3{,}2 \times 10^{-4}$.
- **Racine carrée** : $\sqrt{a}$ est le nombre positif dont le carré vaut $a$ ; $\sqrt{a^2} = a$ pour $a \geqslant 0$.
- **Arithmétique** : divisibilité par $2$ (chiffre des unités pair), $3$ ou $9$ (somme des chiffres), $5$ (unités $0$ ou $5$) ; un nombre premier a exactement deux diviseurs, $1$ et lui-même ; le plus grand nombre de lots identiques est le plus grand diviseur commun.

$$\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd} \qquad \frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}$$

## II. Calcul littéral et équations

::: formule
$$(a + b)^2 = a^2 + 2ab + b^2$$
$$(a - b)^2 = a^2 - 2ab + b^2$$
$$(a - b)(a + b) = a^2 - b^2$$
:::

- **Développer** : $k(a + b) = ka + kb$ et $(a + b)(c + d) = ac + ad + bc + bd$.
- **Factoriser** : repérer un facteur commun ($6x + 9 = 3(2x + 3)$) ou une identité ($x^2 - 49 = (x - 7)(x + 7)$).
- **Équation du premier degré** : même opération dans les deux membres pour isoler $x$, puis vérifier.
- **Produit nul** : $A \times B = 0$ équivaut à $A = 0$ ou $B = 0$.
- **Équation $x^2 = a$** : deux solutions $\sqrt{a}$ et $-\sqrt{a}$ si $a > 0$ ; une seule, $0$, si $a = 0$ ; aucune si $a < 0$.

## III. Proportionnalité, pourcentages, grandeurs

| Situation | Calcul |
|---|---|
| $t\ \%$ d'une quantité | $\times \dfrac{t}{100}$ |
| Hausse de $t\ \%$ | $\times \left(1 + \dfrac{t}{100}\right)$ |
| Baisse de $t\ \%$ | $\times \left(1 - \dfrac{t}{100}\right)$ |
| Valeur avant une évolution | $\div$ coefficient multiplicateur |
| Pourcentage d'évolution | $\dfrac{\text{arrivée} - \text{départ}}{\text{départ}} \times 100$ |

- **Vitesse** : $v = \dfrac{d}{t}$, $d = v \times t$, $t = \dfrac{d}{v}$ ; 1 h 30 min $= 1{,}5$ h ; $1$ m/s $= 3{,}6$ km/h.
- **Conversions** : $1$ m² $= 10\,000$ cm² ; $1$ m³ $= 1\,000$ L ; $1$ dm³ $= 1$ L ; $1$ cm³ $= 1$ mL.
- **Échelle** : longueur sur le plan $=$ longueur réelle $\times$ échelle (même unité).

## IV. Fonctions

- **Image** de $a$ : $f(a)$, lue sur l'axe des ordonnées ; **antécédent** de $b$ : solution de $f(x) = b$, lue sur l'axe des abscisses.
- **Fonction linéaire** $f(x) = ax$ : proportionnalité, droite passant par l'origine ; $a = \dfrac{f(x)}{x}$.
- **Fonction affine** $f(x) = ax + b$ : droite de coefficient directeur $a$ et d'ordonnée à l'origine $b$ ; $a = \dfrac{f(x_2) - f(x_1)}{x_2 - x_1}$.
- **Comparer deux tarifs** : résoudre l'équation « prix 1 $=$ prix 2 », puis lire sur le graphique quelle droite est en dessous de l'autre.

## V. Géométrie plane

::: theoreme Théorème de Pythagore et sa réciproque
Si $ABC$ est rectangle en $A$, alors $BC^2 = AB^2 + AC^2$ ($[BC]$ est l'hypoténuse). Réciproquement, si $BC^2 = AB^2 + AC^2$, alors $ABC$ est rectangle en $A$.
:::

::: theoreme Théorème de Thalès et sa réciproque
Si les points $A$, $M$, $B$ et $A$, $N$, $C$ sont alignés et si $(MN) \parallel (BC)$, alors :
$$\frac{AM}{AB} = \frac{AN}{AC} = \frac{MN}{BC}$$
Réciproquement, si les points sont alignés **dans le même ordre** et si $\dfrac{AM}{AB} = \dfrac{AN}{AC}$, alors $(MN) \parallel (BC)$.
:::

::: formule Trigonométrie dans le triangle rectangle
$$\cos(\widehat{A}) = \frac{\text{côté adjacent}}{\text{hypoténuse}}$$
$$\sin(\widehat{A}) = \frac{\text{côté opposé}}{\text{hypoténuse}}$$
$$\tan(\widehat{A}) = \frac{\text{côté opposé}}{\text{côté adjacent}}$$
:::

- **Angles** : somme des angles d'un triangle $= 180^\circ$ ; un triangle isocèle a deux angles égaux à la base.
- **Triangles semblables** : mêmes angles, longueurs proportionnelles.
- **Transformations** : symétries axiale et centrale, translation, rotation conservent longueurs, angles et aires ; une homothétie de rapport $k$ multiplie les longueurs par $|k|$.
- **Aires** : rectangle $L \times \ell$ ; triangle $\dfrac{b \times h}{2}$ ; disque $\pi r^2$ ; périmètre du cercle $2\pi r$.

## VI. Géométrie dans l'espace

| Solide | Volume |
|---|---|
| Pavé droit | $L \times \ell \times h$ |
| Prisme droit | $\mathcal{B} \times h$ |
| Cylindre | $\pi r^2 h$ |
| Pyramide | $\dfrac{\mathcal{B} \times h}{3}$ |
| Cône | $\dfrac{\pi r^2 h}{3}$ |
| Boule de rayon $r$ | $\dfrac{4}{3}\pi r^3$ |

::: retenir Agrandissement et réduction de rapport $k$
Les longueurs sont multipliées par $k$, les aires par $k^2$ et les volumes par $k^3$.
:::

## VII. Statistiques et probabilités

- **Moyenne** : somme des valeurs (multipliées par leurs effectifs) divisée par l'effectif total.
- **Médiane** : on **range** la série ; effectif impair, valeur du milieu ; effectif pair, moyenne des deux valeurs du milieu.
- **Étendue** : plus grande valeur − plus petite valeur. **Fréquence** : effectif ÷ effectif total.
- **Diagramme circulaire** : angle $=$ fréquence $\times 360^\circ$.
- **Probabilité** (issues équiprobables) : $\dfrac{\text{issues favorables}}{\text{issues possibles}}$, toujours entre $0$ et $1$ ; $P(\text{non } A) = 1 - P(A)$.
- **Arbre** : on multiplie le long d'un chemin, on additionne les chemins qui réalisent l'événement.

## VIII. Algorithmique et rédaction

- **Scratch** : suivre les variables ligne par ligne dans un tableau ; « répéter $n$ fois » exécute $n$ fois le contenu de la boucle ; « s'orienter à $90$ » tourne le lutin vers la droite.
- **Rédaction ($2$ points)** : hypothèses, propriété, calcul, phrase de conclusion avec l'unité ; « $\approx$ » pour un arrondi, fait à la fin.
