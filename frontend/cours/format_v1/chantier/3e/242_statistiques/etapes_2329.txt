## Question 1 : Les moyennes

::: methode
Moyenne = somme des valeurs ÷ nombre de valeurs ($4$ pour chaque série).
:::

::: etape Série A
$$\frac{9 + 10 + 10 + 11}{4} = \frac{40}{4} = 10$$
:::

::: etape Série B
$$\frac{2 + 10 + 10 + 18}{4} = \frac{40}{4} = 10$$
:::

::: resultat
Les deux séries ont la même moyenne : $10$.
:::

## Question 2 : Les médianes

::: methode
Les séries sont déjà rangées ; effectif $4$ (pair) : médiane = moyenne des 2ᵉ et 3ᵉ valeurs.
:::

::: etape Calculer
- A : $\dfrac{10 + 10}{2} = 10$ ;
- B : $\dfrac{10 + 10}{2} = 10$.
:::

::: resultat
Les deux séries ont la même médiane : $10$.
:::

## Question 3 : Les étendues

::: methode
Étendue = plus grande valeur − plus petite valeur.
:::

::: etape Calculer
- A : $11 - 9 = 2$ ;
- B : $18 - 2 = 16$.
:::

::: resultat
Étendue de A : $2$ ; étendue de B : $16$.
:::

## Question 4 : La série la plus dispersée

::: methode
L'étendue mesure la dispersion : plus elle est grande, plus les valeurs sont écartées.
:::

::: resultat
La série B est la plus dispersée (étendue $16$ contre $2$).
:::

## Question 5 : La leçon

::: etape Bilan
Même moyenne ($10$), même médiane ($10$), mais des étendues très différentes ($2$ et $16$).
:::

::: resultat
La moyenne seule ne suffit pas : il faut un indicateur de **position** et un indicateur de **dispersion**.
:::

::: attention Erreur fréquente
Conclure que deux séries de même moyenne se ressemblent : il faut aussi comparer la médiane et l'étendue.
:::

::: retenir
Pour comparer deux séries : position (moyenne, médiane) ET dispersion (étendue).
:::

Solution:
<!-- optitab:1 -->
1. $10$ et $10$
2. $10$ et $10$
3. $2$ et $16$
4. B
5. Il faut aussi un indicateur de dispersion
