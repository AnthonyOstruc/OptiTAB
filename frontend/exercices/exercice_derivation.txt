**Question 4 : Écrire l'équation de la tangente à la courbe de $f$ au point d'abscisse $x = -1$**

    ● Formule générale de la tangente : $y - f(a) = f'(a)(x - a)$
    ● Point d'application : $x = -1$, $y = f(-1) = 12$
    ● Pente de la tangente : $f'(-1) = 6(-1)^2 - 6(-1) - 12 = 6(1) + 6 - 12 = 6 + 6 - 12 = 0$
    ● Application : $y - 12 = 0 \times (x - (-1))$
    ● Simplification : $y - 12 = 0$
    ● Donc $y = 12$

Solution:
1. $f'(x) = 6x^2 - 6x - 12$
2. $f$ croissante sur $]-\infty, -1]$, décroissante sur $[-1, 2]$, croissante sur $[2, +\infty[$
3. Maximum local en $x = -1$ : $f(-1) = 12$, minimum local en $x = 2$ : $f(2) = -15$
4. $y = 12$

=== Dérivation - Fonctions Usuelles
Difficulté: easy

Énoncé: Calculer les dérivées des fonctions suivantes :

1. $f(x) = 5x^4 - 3x^2 + 7x - 2$
2. $g(x) = \sqrt{x} + \frac{1}{x^2}$
3. $h(x) = e^{3x} + \ln(x^2 + 1)$
4. $k(x) = \sin(2x) + \cos(x^2)$
5. $m(x) = \frac{x^3 - 2x + 1}{x^2}$

**Question 1 : Dériver la fonction polynomiale $f(x) = 5x^4 - 3x^2 + 7x - 2$**

**Question 2 : Dériver la fonction $g(x) = \sqrt{x} + \frac{1}{x^2}$**

**Question 3 : Dériver la fonction composée $h(x) = e^{3x} + \ln(x^2 + 1)$**

**Question 4 : Dériver la fonction trigonométrique $k(x) = \sin(2x) + \cos(x^2)$**

**Question 5 : Dériver la fonction rationnelle $m(x) = \frac{x^3 - 2x + 1}{x^2}$**

Étapes:

**Question 1 : Dériver la fonction polynomiale $f(x) = 5x^4 - 3x^2 + 7x - 2$**
    ● Identifier le type de fonction : polynôme
    ● Appliquer la formule $(x^n)' = nx^{n-1}$ pour chaque terme
    ● Dériver terme par terme :
    ● $(5x^4)' = 5 \times 4x^3 = 20x^3$
    ● $(-3x^2)' = -3 \times 2x = -6x$
    ● $(7x)' = 7 \times 1 = 7$
    ● $(-2)' = 0$
    ● Donc : $f'(x) = 20x^3 - 6x + 7$
    $\\$
**Question 2 : Dériver la fonction $g(x) = \sqrt{x} + \frac{1}{x^2}$**
    ● Identifier les fonctions : $\sqrt{x}$ et $\frac{1}{x^2}$
    ● Appliquer $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$
    ● Appliquer $(\frac{1}{x^n})' = -\frac{n}{x^{n+1}}$
    ● On dérive chaque terme :
    ● $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$
    ● $\left(\frac{1}{x^2}\right)' = -\frac{2}{x^3}$
    ● Donc : $g'(x) = \frac{1}{2\sqrt{x}} - \frac{2}{x^3}$
    $\\$
**Question 3 : Dériver la fonction composée $h(x) = e^{3x} + \ln(x^2 + 1)$**
    ● Identifier les fonctions composées : $e^{3x}$ et $\ln(x^2 + 1)$
    ● Appliquer $(e^{u})' = u' \times e^{u}$
    ● Appliquer $(\ln(u))' = \frac{u'}{u}$
    ● On dérive chaque terme :
    ● $(e^{3x})' = 3 \times e^{3x} = 3e^{3x}$
    ● $(\ln(x^2 + 1))' = \frac{2x}{x^2 + 1}$
    ● Donc : $h'(x) = 3e^{3x} + \frac{2x}{x^2 + 1}$
    $\\$
**Question 4 : Dériver la fonction trigonométrique $k(x) = \sin(2x) + \cos(x^2)$**
    ● Identifier les fonctions composées : $\sin(2x)$ et $\cos(x^2)$
    ● Appliquer $(\sin(u))' = u' \times \cos(u)$
    ● Appliquer $(\cos(u))' = -u' \times \sin(u)$
    ● On dérive chaque terme :
    ● $(\sin(2x))' = 2 \times \cos(2x) = 2\cos(2x)$
    ● $(\cos(x^2))' = -2x \times \sin(x^2) = -2x\sin(x^2)$
    ● Donc : $k'(x) = 2\cos(2x) - 2x\sin(x^2)$
    $\\$
**Question 5 : Dériver la fonction rationnelle $m(x) = \frac{x^3 - 2x + 1}{x^2}$**
    ● Identifier le type : quotient de polynômes
    ● Appliquer la formule $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
    ● On pose $u(x) = x^3 - 2x + 1$ et $v(x) = x^2$
    ● $u'(x) = 3x^2 - 2$, $v'(x) = 2x$
    ● On applique la formule du quotient :
    ● $m'(x) = \frac{u'v - uv'}{v^2} = \frac{(3x^2 - 2) \times x^2 - (x^3 - 2x + 1) \times 2x}{(x^2)^2}$
    ● $m'(x) = \frac{3x^4 - 2x^2 - 2x^4 + 4x^2 - 2x}{x^4}$
    ● $m'(x) = \frac{x^4 + 2x^2 - 2x}{x^4} = \frac{x^3 + 2x - 2}{x^3}$
    ● Donc : $m'(x) = \frac{x^3 + 2x - 2}{x^3}$ pour $x \neq 0$

Solution:
1. $f'(x) = 20x^3 - 6x + 7$
2. $g'(x) = \frac{1}{2\sqrt{x}} - \frac{2}{x^3}$
3. $h'(x) = 3e^{3x} + \frac{2x}{x^2 + 1}$
4. $k'(x) = 2\cos(2x) - 2x\sin(x^2)$
5. $m'(x) = \frac{x^3 + 2x - 2}{x^3}$ pour $x \neq 0$

=== Dérivation - Fonction Rationnelle et Optimisation

    ● Numérateur : $x^2 + 4x + 3 = (x+1)(x+3)$ (discriminant : $\Delta = 16 - 12 = 4$)
    ● Dénominateur : $x^2 - 1 = (x-1)(x+1)$ (identité remarquable)
    ● Pour $x \neq -1$ : $f(x) = \frac{(x+1)(x+3)}{(x-1)(x+1)} = \frac{x+3}{x-1}$

=== Dérivation - Définition et Calculs
Difficulté: easy

Énoncé: On considère la fonction $f(x) = x^2 + 3x - 2$ définie sur $\mathbb{R}$.

**Question 1 : Calculer $f'(2)$ par définition**

**Question 2 : Calculer $f'(x)$ par les formules de dérivation**

**Question 3 : Vérifier que les deux méthodes donnent le même résultat**

**Question 4 : Déterminer l'équation de la tangente à la courbe au point d'abscisse $x = 2$**

Étapes:

**Question 1 : Calculer $f'(2)$ par définition**

**Étape 1 : Application de la définition**
    ● Définition de la dérivée : $f'(2) = \displaystyle\lim_{h \to 0} \frac{f(2 + h) - f(2)}{h}$
    $\\$
**Étape 2 : Calcul de $f(2 + h)$**
    ● $f(2 + h) = (2 + h)^2 + 3(2 + h) - 2$
    ● Développement : $f(2 + h) = 4 + 4h + h^2 + 6 + 3h - 2$
    ● Simplification : $f(2 + h) = h^2 + 7h + 8$
    $\\$
**Étape 3 : Calcul de $f(2)$**
    ● $f(2) = 2^2 + 3 \cdot 2 - 2 = 4 + 6 - 2 = 8$
    $\\$
**Étape 4 : Calcul du taux d'accroissement**
    ● Différence : $f(2 + h) - f(2) = (h^2 + 7h + 8) - 8 = h^2 + 7h$
    ● Taux : $\frac{f(2 + h) - f(2)}{h} = \frac{h^2 + 7h}{h} = h + 7$
    $\\$
**Étape 5 : Calcul de la limite**
    ● $f'(2) = \displaystyle\lim_{h \to 0} (h + 7) = 7$
    $\\$
**Question 2 : Calculer $f'(x)$ par les formules de dérivation**
    ● Dérivée de $x^2$ : $(x^2)' = 2x$
    ● Dérivée de $3x$ : $(3x)' = 3$
    ● Dérivée de $-2$ : $(-2)' = 0$
    ● Donc : $f'(x) = 2x + 3$
    $\\$
**Question 3 : Vérifier que les deux méthodes donnent le même résultat**
    ● Par définition : $f'(2) = 7$
    ● Par les formules : $f'(2) = 2 \cdot 2 + 3 = 4 + 3 = 7$
    ● Les deux méthodes donnent bien le même résultat : $f'(2) = 7$
    $\\$
**Question 4 : Déterminer l'équation de la tangente au point d'abscisse $x = 2$**
    ● Point de contact : $A(2, f(2)) = A(2, 8)$
    ● Coefficient directeur : $f'(2) = 7$
    ● Équation de la tangente : $y - 8 = 7(x - 2)$
    ● Développement : $y - 8 = 7x - 14$
    ● Donc : $y = 7x - 6$

Solution:
1. $f'(2) = 7$ (par définition)
2. $f'(x) = 2x + 3$ (par les formules)
3. Vérification : $f'(2) = 7$ dans les deux cas
4. Tangente en $x = 2$ : $y = 7x - 6$

    ● <span style="font-size:1.05em;">$\Delta = 1 + 24 = 25$, racines $x = \frac{-1 \pm 5}{2}$</span>
