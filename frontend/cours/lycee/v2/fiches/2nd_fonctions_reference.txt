<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : courbes, variations et parité des fonctions carré, inverse, racine carrée et cube. Programme de Seconde.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les quatre fonctions de référence</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ $x^2$ : décroissante sur $]-\infty\,;0]$, croissante sur $[0\,;+\infty[$, minimum $0$ en $0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\frac{1}{x}$ : décroissante sur $]-\infty\,;0[$ et sur $]0\,;+\infty[$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\sqrt{x}$ : croissante sur $[0\,;+\infty[$.</p>
<p style="margin:6px 0 0 0;">4️⃣ $x^3$ : croissante sur $\mathbb{R}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Équations et comparaisons</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$x^2 = a$ avec $a \gt 0$ $\iff$ $x = -\sqrt{a}$ ou $x = \sqrt{a}$</p>
</div>
[IMAGE_2]
<p style="margin:0;">• Paire : $f(-x) = f(x)$ (symétrie d’axe des ordonnées) ; impaire : $f(-x) = -f(x)$ (symétrie de centre $O$).</p>
<p style="margin:6px 0 0 0;">• Sur $[0\,;1]$ : $x^3 \le x^2 \le x$ ; sur $[1\,;+\infty[$ : $x \le x^2 \le x^3$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier la solution négative : $x^2 = 9$ donne $x = -3$ ou $x = 3$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Dire que $\frac{1}{x}$ est décroissante sur $\mathbb{R}^{*}$ : c’est sur chaque intervalle séparément.</p>
<p style="margin:6px 0 0 0;">3️⃣ Calculer $\sqrt{x}$ pour $x \lt 0$ ou $\frac{1}{x}$ pour $x = 0$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire que $x^2 \ge x$ toujours : $0{,}5^2 = 0{,}25 \lt 0{,}5$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour comparer $f(a)$ et $f(b)$, je vérifie que $a$ et $b$ sont dans un même intervalle où $f$ est monotone : croissante → même ordre, décroissante → ordre inversé.</p>
</div>
