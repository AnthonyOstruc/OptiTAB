Titre: Résumé : Transformations et homothéties

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : symétries, translation, rotation, homothéties, effets sur les longueurs, les aires et les volumes, frises et rosaces. Programme de 3ème.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les quatre transformations « isométriques »</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• <strong>Symétrie axiale</strong> : l'axe est la médiatrice de $\displaystyle [AA']$ (miroir).</p>
<p style="margin:6px 0 0 0;">• <strong>Symétrie centrale</strong> : le centre est le milieu de $\displaystyle [AA']$ (demi-tour).</p>
<p style="margin:6px 0 0 0;">• <strong>Translation</strong> : tous les points glissent du même déplacement.</p>
<p style="margin:6px 0 0 0;">• <strong>Rotation</strong> : tous les points tournent du même angle autour d'un centre.</p>
<div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:12px; margin:12px 0 0 0;">
<strong>💡 À retenir :</strong> elles conservent les longueurs, les angles, les aires, l'alignement et le parallélisme.
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. L'homothétie de centre O et de rapport k</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:0 auto 12px auto; text-align:center; max-width:500px;">
<p style="margin:0; font-weight:bold;">$\displaystyle O$, $\displaystyle A$, $\displaystyle A'$ alignés et $\displaystyle OA' = |k| \times OA$</p>
<p style="margin:6px 0 0 0;">Dans un repère, centre $\displaystyle O$ : $\displaystyle (x\ ;\ y) \to (kx\ ;\ ky)$</p>
</div>
<p style="margin:0;">• $\displaystyle k > 0$ : même côté de $\displaystyle O$ ; $\displaystyle k < 0$ : de part et d'autre.</p>
<p style="margin:6px 0 0 0;">• $\displaystyle |k| > 1$ : agrandissement ; $\displaystyle |k| < 1$ : réduction ; $\displaystyle k = -1$ : symétrie centrale.</p>
<p style="margin:6px 0 0 0;">• Longueurs $\displaystyle \times |k|$ ; aires $\displaystyle \times k^2$ ; volumes $\displaystyle \times |k|^3$ ; angles conservés.</p>
<p style="margin:6px 0 0 0;">• Exemple : $\displaystyle k = -3$ → périmètre $\times 3$, aire $\times 9$, volume $\times 27$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Frises et rosaces</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Frise</strong> : un motif répété par translations ; du motif 1 au motif $\displaystyle n$ : $\displaystyle n - 1$ déplacements.</p>
<p style="margin:6px 0 0 0;">• <strong>Rosace</strong> de $\displaystyle n$ motifs : rotations de $\displaystyle \frac{360^\circ}{n}$ (8 motifs → 45°).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Donner une longueur négative avec $\displaystyle k < 0$ : on multiplie par $\displaystyle |k|$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Multiplier une aire par $\displaystyle k$ au lieu de $\displaystyle k^2$ (ou un volume par $\displaystyle k^2$ au lieu de $\displaystyle |k|^3$).</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier le sens d'une rotation (horaire ou anti-horaire).</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire qu'une aire permet de trouver le signe de $\displaystyle k$ : elle ne donne que $\displaystyle |k|$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> agrandissement / réduction / maquette / section d'une pyramide → homothétie : trouver $\displaystyle |k|$ par un rapport de longueurs, puis $\displaystyle k^2$ pour les aires et $\displaystyle |k|^3$ pour les volumes.</p>
</div>
