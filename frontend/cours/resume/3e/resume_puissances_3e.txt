<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Puissances</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;">$\displaystyle a^n = a \times a \times \cdots \times a$ ($\displaystyle n$ facteurs) ; $\displaystyle a^0 = 1$ ; $\displaystyle a^{-n} = \dfrac{1}{a^n}$ (pour $\displaystyle a \neq 0$).</p>
</div>

<p style="margin:0;"><strong>Signes :</strong> $\displaystyle (-5)^2 = 25$ mais $\displaystyle -5^2 = -25$ ; puissance paire → positif, impaire → négatif.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Notation scientifique</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:420px;">
<p style="margin:0; font-weight:bold;">$\displaystyle c \times 10^p$ avec $\displaystyle 1 \leq c < 10$ et $\displaystyle p$ entier</p>
</div>
<p style="margin:0;">$\displaystyle 74\,000\,000 = 7{,}4 \times 10^7$ ; $\displaystyle 0{,}000\,092 = 9{,}2 \times 10^{-5}$.</p>
<p style="margin:6px 0 0 0;"><strong>Calculs :</strong> regrouper coefficients et puissances, puis <strong>normaliser</strong> : $\displaystyle (3 \times 10^5)(4 \times 10^{-2}) = 12 \times 10^3 = 1{,}2 \times 10^4$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Racines carrées</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;">$\displaystyle \sqrt{a}$ : l'unique nombre <strong>positif ou nul</strong> dont le carré vaut $\displaystyle a$ ($\displaystyle a \geq 0$) ; $\displaystyle (\sqrt{a})^2 = a$ ; $\displaystyle \sqrt{ab} = \sqrt{a}\sqrt{b}$.</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Simplifier : $\displaystyle \sqrt{72} = \sqrt{36 \times 2} = 6\sqrt{2}$.</p>
<p style="margin:6px 0 0 0;">• Encadrer : $\displaystyle 6^2 = 36 < 37 < 37{,}21 = 6{,}1^2$ donc $\displaystyle 6 < \sqrt{37} < 6{,}1$.</p>
<p style="margin:6px 0 0 0;">• Géométrie : côté d'un carré d'aire $\displaystyle A$ : $\displaystyle \sqrt{A}$ ; l'équation $\displaystyle x^2 = a$ (avec $\displaystyle a > 0$) a deux solutions : $\displaystyle \sqrt{a}$ et $\displaystyle -\sqrt{a}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ $\displaystyle a^m + a^n \neq a^{m+n}$ : les règles des exposants ne concernent pas les sommes.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle \sqrt{a+b} \neq \sqrt{a} + \sqrt{b}$ : contre-exemple $\displaystyle \sqrt{25} = 5 \neq 7 = \sqrt{9} + \sqrt{16}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier de normaliser : $\displaystyle 24 \times 10^3$ n'est pas une notation scientifique.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre $\displaystyle (-5)^2 = 25$ et $\displaystyle -5^2 = -25$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> « très grand / très petit nombre » → notation scientifique ; « aire d'un carré » → racine carrée ; garder les valeurs <strong>exactes</strong> ($\displaystyle \sqrt{2}$, $\displaystyle 5\sqrt{2}$…) et n'arrondir qu'à la fin avec $\displaystyle \approx$.</p>
</div>
