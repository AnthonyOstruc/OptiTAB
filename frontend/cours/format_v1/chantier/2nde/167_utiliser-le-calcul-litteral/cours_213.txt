Titre: Utiliser le calcul littéral

<!-- optitab:1 -->
::: objectifs
Calculer avec des puissances, des racines carrées et des fractions ; développer et factoriser à l’aide des identités remarquables ; choisir la forme adaptée d’une expression ; résoudre des équations et des inéquations, en particulier à l’aide d’un tableau de signes ; comparer deux quantités.
:::

## I. Puissances entières relatives

::: definition
Pour un réel $a \neq 0$ et un entier naturel $n \ge 1$ : $a^n = a \times a \times \dots \times a$ ($n$ facteurs), $a^0 = 1$ et $a^{-n} = \dfrac{1}{a^n}$.
:::

::: propriete Règles de calcul
Pour $a \neq 0$, $b \neq 0$ et $n$, $m$ entiers relatifs :

- produit : $a^n \times a^m = a^{n+m}$ ;
- quotient : $\dfrac{a^n}{a^m} = a^{n-m}$ ;
- puissance d’une puissance : $(a^n)^m = a^{n \times m}$ ;
- puissance d’un produit : $(ab)^n = a^n b^n$ ;
- puissance d’un quotient : $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$.
:::

::: exemple
$$
\begin{aligned}
\frac{2^5 \times 2^{-2}}{2^4} &= 2^{5 - 2 - 4} \\
&= 2^{-1} = \frac{1}{2}
\end{aligned}
$$

De même, $10^3 \times 10^{-5} = 10^{-2} = 0{,}01$.
:::

::: attention
$(-3)^2 = 9$ mais $-3^2 = -9$ : l’exposant ne porte que sur ce qui est juste avant lui. Et $2^3 + 2^4 \neq 2^7$ : les règles concernent les **produits**, jamais les sommes.
:::

## II. Racines carrées

::: definition
Pour $a \ge 0$, $\sqrt{a}$ est le nombre **positif** dont le carré vaut $a$ : $\sqrt{a} \ge 0$ et $(\sqrt{a})^2 = a$. Par exemple, $\sqrt{49} = 7$.
:::

::: propriete
Pour tout réel $a$, $\sqrt{a^2} = \lvert a \rvert$. Par exemple, $\sqrt{(-5)^2} = \sqrt{25} = 5 = \lvert -5 \rvert$.
:::

::: theoreme
- Pour $a \ge 0$ et $b \ge 0$ : $\sqrt{ab} = \sqrt{a} \times \sqrt{b}$ et, si $b \gt 0$, $\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}$.
- Pour $a \gt 0$ et $b \gt 0$ : $\sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$.
:::

::: demonstration
- $\sqrt{a}\sqrt{b}$ est positif et $(\sqrt{a}\sqrt{b})^2 = (\sqrt{a})^2(\sqrt{b})^2 = ab$ : c’est donc le nombre positif dont le carré vaut $ab$, c’est-à-dire $\sqrt{ab}$.
- On compare les carrés de deux nombres positifs :
$$
\begin{aligned}
(\sqrt{a} + \sqrt{b})^2 &= a + b + 2\sqrt{a}\sqrt{b} \\
&\gt a + b = (\sqrt{a + b})^2
\end{aligned}
$$
car $2\sqrt{a}\sqrt{b} \gt 0$. Or deux nombres positifs sont rangés dans le même ordre que leurs carrés : $\sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$.
:::

::: exemple
- $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$
- $\sqrt{\dfrac{9}{16}} = \dfrac{\sqrt{9}}{\sqrt{16}} = \dfrac{3}{4}$
- $\dfrac{3}{\sqrt{5}} = \dfrac{3 \times \sqrt{5}}{\sqrt{5} \times \sqrt{5}} = \dfrac{3\sqrt{5}}{5}$
:::

::: attention
$\sqrt{9 + 16} = \sqrt{25} = 5$ alors que $\sqrt{9} + \sqrt{16} = 7$ : la racine d’une somme n’est pas la somme des racines.
:::

## III. Fractions et expressions fractionnaires

::: propriete Règles de calcul
Pour des réels $a$, $c$ et des réels non nuls $b$, $d$ :

- somme : $\dfrac{a}{b} + \dfrac{c}{d} = \dfrac{ad + bc}{bd}$ ;
- produit : $\dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}$ ;
- diviser par $\dfrac{c}{d}$ (avec $c \neq 0$), c’est multiplier par son inverse $\dfrac{d}{c}$.
:::

::: methode Additionner des fractions littérales
On écarte les **valeurs interdites** (celles qui annulent un dénominateur), puis on réduit au même dénominateur.
:::

::: exemple
Pour $x \neq 0$ et $x \neq -1$ :

$$
\begin{aligned}
\frac{1}{x} + \frac{2}{x + 1} &= \frac{x + 1}{x(x + 1)} + \frac{2x}{x(x + 1)} \\
&= \frac{3x + 1}{x(x + 1)}
\end{aligned}
$$
:::

## IV. Développer, factoriser, choisir la forme

::: propriete Identités remarquables
Pour tous réels $a$ et $b$ :

- $(a + b)^2 = a^2 + 2ab + b^2$
- $(a - b)^2 = a^2 - 2ab + b^2$
- $(a + b)(a - b) = a^2 - b^2$
:::

Pour $a$ et $b$ positifs, l’aire du grand carré de côté $a + b$ est la somme des aires des quatre morceaux :

[IMAGE_1]

**Développer**, c’est transformer un produit en somme : $(2x - 3)^2 = 4x^2 - 12x + 9$. **Factoriser**, c’est transformer une somme en produit, grâce à un facteur commun ou à une identité remarquable. La distributivité $k(a + b) = ka + kb$ se lit dans les deux sens, comme le montrent les aires :

[IMAGE_4]

::: exemple
Facteur commun $(x + 1)$ :
$$
\begin{aligned}
&(x + 1)(2x - 5) + (x + 1)(x + 2) \\
&= (x + 1)\big[(2x - 5) + (x + 2)\big] \\
&= (x + 1)(3x - 3) \\
&= 3(x + 1)(x - 1)
\end{aligned}
$$

Identité $a^2 - b^2$ :
$$
\begin{aligned}
9x^2 - 25 &= (3x)^2 - 5^2 \\
&= (3x - 5)(3x + 5)
\end{aligned}
$$
:::

::: conseil Choisir la forme adaptée
- Forme **développée** : pour calculer une image comme $f(0)$, ou résoudre une équation $f(x) = c$ où $c$ est le terme constant.
- Forme **factorisée** : pour résoudre $f(x) = 0$ ou étudier le signe de $f(x)$.
:::

::: remarque Contrôle
On vérifie une factorisation en redéveloppant, ou en remplaçant $x$ par une valeur simple ($x = 0$, $x = 1$) dans les deux écritures.
:::

## V. Équations

::: propriete Équation du premier degré
Pour $a \neq 0$ : $ax + b = 0 \iff x = -\dfrac{b}{a}$.
:::

::: methode Exprimer une variable en fonction des autres
On isole la variable en appliquant aux deux membres les opérations inverses. Par exemple :
- avec $U = RI$ et $I \neq 0$ : $R = \dfrac{U}{I}$ ;
- avec $3x + 5y = 20$ : $5y = 20 - 3x$, donc $y = \dfrac{20 - 3x}{5}$.
:::

::: theoreme Équation produit nul
Un produit est nul si et seulement si l’un au moins de ses facteurs est nul :
$$A \times B = 0 \iff A = 0 \text{ ou } B = 0$$
:::

::: exemple
$(2x - 4)(x + 1) = 0 \iff 2x - 4 = 0$ ou $x + 1 = 0 \iff x = 2$ ou $x = -1$.
:::

::: propriete Équation $x^2 = a$
- Si $a \gt 0$ : deux solutions, $-\sqrt{a}$ et $\sqrt{a}$.
- Si $a = 0$ : une solution, $0$.
- Si $a \lt 0$ : aucune solution (un carré est toujours positif).
:::

Graphiquement, les solutions de $x^2 = 4$ sont les abscisses des points d’intersection de la parabole $y = x^2$ et de la droite $y = 4$ ; la droite $y = -1$ ne coupe pas la parabole. Les solutions de $x^2 \lt 4$ sont les abscisses des points de la parabole situés **sous** la droite : $S = {]-2\,;2[}$ (en vert).

[IMAGE_2]

::: methode Équation du second degré en Seconde
On ramène tout dans un même membre, on factorise, puis on applique la règle du produit nul :
$$x^2 = 5x \iff x^2 - 5x = 0 \iff x(x - 5) = 0$$
donc $x = 0$ ou $x = 5$.
:::

::: attention
Ne jamais diviser par $x$ pour résoudre $x^2 = 5x$ : on perdrait la solution $x = 0$.
:::

::: propriete Équation quotient nul
$\dfrac{A}{B} = 0 \iff A = 0$ et $B \neq 0$.
:::

## VI. Inéquations, signe et comparaison

::: propriete Règles
- On peut ajouter ou soustraire un même nombre aux deux membres d’une inégalité.
- On peut multiplier ou diviser les deux membres par un même nombre **positif** non nul : le sens est conservé.
- Si l’on multiplie ou divise par un nombre **négatif** non nul, on **change le sens** de l’inégalité.
:::

::: exemple
$-2x + 6 \le 0 \iff -2x \le -6 \iff x \ge 3$ (division par $-2$ : le sens change). L’ensemble des solutions est $S = {[3\,;+\infty[}$.
:::

[IMAGE_3]

::: propriete Signe de $ax + b$ (avec $a \neq 0$)
$ax + b$ s’annule en $-\dfrac{b}{a}$ ; il est du signe de $a$ à droite de cette valeur et du signe contraire à gauche.
:::

::: methode Résoudre une inéquation produit
On ramène l’inéquation à la forme « produit $\gt 0$ » (ou $\lt$, $\ge$, $\le$), on dresse un **tableau de signes** (une ligne par facteur), puis on applique la règle des signes.
:::

::: exemple
Résolution de $(2x - 4)(-x + 3) \gt 0$ : $2x - 4$ s’annule en $2$ ($a = 2 \gt 0$) et $-x + 3$ s’annule en $3$ ($a = -1 \lt 0$). Tableau de signes :
:::

::: tableau
x : -\infty, 2, 3, +\infty
2x-4 : , -, z, +, t, +,
-x+3 : , +, t, +, z, -,
Produit : , -, z, +, z, -,
:::

Le produit est strictement positif pour $x \in {]2\,;3[}$ : $S = {]2\,;3[}$.

::: attention
Pour un quotient $\dfrac{A}{B}$, la valeur qui annule $B$ est **interdite** : on la marque d’une double barre dans le tableau, et elle n’est jamais solution.
:::

::: methode Comparer deux quantités
- **Différence** : $A \ge B \iff A - B \ge 0$ ; on étudie le signe de $A - B$.
- **Quotient** (quand $A \gt 0$ et $B \gt 0$) : $A \ge B \iff \dfrac{A}{B} \ge 1$.
:::

::: exemple
Pour tout réel $x$ :
$$
\begin{aligned}
&(x + 3)^2 - (x + 2)(x + 4) \\
&= (x^2 + 6x + 9) - (x^2 + 6x + 8) \\
&= 1
\end{aligned}
$$
La différence est strictement positive, donc $(x + 3)^2 \gt (x + 2)(x + 4)$.
:::

::: retenir
- $a^n \times a^m = a^{n+m}$, $a^{-n} = \dfrac{1}{a^n}$ ; $\sqrt{ab} = \sqrt{a}\sqrt{b}$ mais $\sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$ ; $\sqrt{a^2} = \lvert a \rvert$.
- $(a \pm b)^2 = a^2 \pm 2ab + b^2$ et $(a + b)(a - b) = a^2 - b^2$.
- Produit nul : l’un des facteurs est nul ; $x^2 = a$ a deux solutions si $a \gt 0$.
- Multiplier ou diviser par un négatif change le sens d’une inégalité.
- Signe d’un produit ou d’un quotient : tableau de signes (valeur interdite exclue).

Fiche de synthèse dans l’onglet Fiches !
:::
