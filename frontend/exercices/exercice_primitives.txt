=== Primitives - Calculs de Base
Difficulté: easy

Énoncé: Calculer les primitives suivantes en utilisant les primitives élémentaires.

**Question 1 :** Calculer $\displaystyle\int (3x^2 + 2)\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int 5x^4\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int (7 - 4x)\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int e^x\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int \cos(x)\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int (3x^2 + 2)\, dx$

    ● **Formule :** Linéarité : $\displaystyle\int (af(x) + bg(x))\, dx = a\int f(x)\, dx + b\int g(x)\, dx$
    
    $\\$
    
    ● **Application :** $\displaystyle a = 3$, $\displaystyle f(x) = x^2$, $\displaystyle b = 2$, $\displaystyle g(x) = 1$
    
    $\\$
    
    ● **Étape 1 :** Séparer : $\displaystyle\int (3x^2 + 2)\, dx = 3\int x^2\, dx + 2\int 1\, dx$
    
    $\\$
    
    ● **Étape 2 :** Primitives : $\displaystyle\int x^2\, dx = \frac{x^3}{3}$, $\displaystyle\int 1\, dx = x$
    
    $\\$
    
    ● **Résultat :** $\displaystyle x^3 + 2x + C$
    
    $\\$

**Question 2 :** Calculer $\displaystyle\int 5x^4\, dx$

    ● **Formule :** Puissance : $\displaystyle\int x^n\, dx = \frac{x^{n+1}}{n+1} + C$ pour $\displaystyle n\neq -1$
    
    $\\$
    
    ● **Application :** $\displaystyle n = 4$, $\displaystyle\int x^4\, dx = \frac{x^{4+1}}{4+1} = \frac{x^5}{5}$
    
    $\\$
    
    ● **Étape 1 :** Application : $\displaystyle\int 5x^4\, dx = 5\int x^4\, dx$
    
    $\\$
    
    ● **Étape 2 :** Calcul : $\displaystyle 5\cdot \frac{x^5}{5} = x^5 + C$
    
    $\\$

**Question 3 :** Calculer $\displaystyle\int (7 - 4x)\, dx$

    ● **Formule :** Linéarité : $\displaystyle\int (af(x) + bg(x))\, dx = a\int f(x)\, dx + b\int g(x)\, dx$
    
    $\\$
    
    ● **Application :** $\displaystyle a = 7$, $\displaystyle f(x) = 1$, $\displaystyle b = -4$, $\displaystyle g(x) = x$
    
    $\\$
    
    ● **Calcul :** $\displaystyle 7x - 2x^2 + C$
    
    $\\$

**Question 4 :** Calculer $\displaystyle\int e^x\, dx$

    ● **Formule :** Exponentielle : $\displaystyle\int e^x\, dx = e^x + C$
    
    $\\$
    
    ● **Application :** Fonction exponentielle simple
    
    $\\$
    
    ● **Résultat :** $\displaystyle e^x + C$
    
    $\\$

**Question 5 :** Calculer $\displaystyle\int \cos(x)\, dx$

    ● **Formule :** Cosinus : $\displaystyle\int \cos(x)\, dx = \sin(x) + C$
    
    $\\$
    
    ● **Application :** Fonction cosinus simple
    
    $\\$
    
    ● **Résultat :** $\displaystyle \sin(x) + C$

Solution:
1. $\displaystyle x^3 + 2x + C$
2. $\displaystyle x^5 + C$
3. $\displaystyle 7x - 2x^2 + C$
4. $\displaystyle e^x + C$
5. $\displaystyle \sin(x) + C$

=== Primitives - Linéarité et Combinaisons
Difficulté: easy

Énoncé: Utiliser la linéarité pour décomposer et intégrer.

**Question 1 :** Calculer $\displaystyle\int (2x^3 - 5x + 4)\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int (x^2 + 3x + 1)\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int (6\,e^x - 3)\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int (4\cos(x) - 2\sin(x))\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int (\sqrt{x} + \frac{1}{\sqrt{x}})\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int (2x^3 - 5x + 4)\, dx$

    ● **Formule :** Linéarité : $\displaystyle\int (af(x) + bg(x))\, dx = a\int f(x)\, dx + b\int g(x)\, dx$
    
    $\\$
    
    ● **Application :** $\displaystyle a = 2$, $\displaystyle f(x) = x^3$, $\displaystyle b = -5$, $\displaystyle g(x) = x$, $\displaystyle c = 4$, $\displaystyle h(x) = 1$
    
    $\\$
    
    ● **Calcul :** $\displaystyle 2\cdot \frac{x^4}{4} - 5\cdot \frac{x^2}{2} + 4x + C = \frac{x^4}{2} - \frac{5x^2}{2} + 4x + C$
    
    $\\$

**Question 2 :** Calculer $\displaystyle\int (x^2 + 3x + 1)\, dx$

    ● **Formule :** Linéarité + Puissances : $\displaystyle\int x^n\, dx = \frac{x^{n+1}}{n+1} + C$
    
    $\\$
    
    ● **Application :** $\displaystyle\int x^2\, dx = \frac{x^3}{3}$, $\displaystyle\int x\, dx = \frac{x^2}{2}$, $\displaystyle\int 1\, dx = x$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \frac{x^3}{3} + \frac{3x^2}{2} + x + C$
    
    $\\$

**Question 3 :** Calculer $\displaystyle\int (6\,e^x - 3)\, dx$

    ● **Formule :** Linéarité + Exponentielle : $\displaystyle\int e^x\, dx = e^x + C$
    
    $\\$
    
    ● **Application :** $\displaystyle\int e^x\, dx = e^x$, $\displaystyle\int 1\, dx = x$
    
    $\\$
    
    ● **Résultat :** $\displaystyle 6e^x - 3x + C$
    
    $\\$

**Question 4 :** Calculer $\displaystyle\int (4\cos(x) - 2\sin(x))\, dx$

    ● **Formule :** Trigonométriques : $\displaystyle\int \cos(x)\, dx = \sin(x) + C$, $\displaystyle\int \sin(x)\, dx = -\cos(x) + C$
    
    $\\$
    
    ● **Application :** $\displaystyle\int \cos(x)\, dx = \sin(x)$, $\displaystyle\int \sin(x)\, dx = -\cos(x)$
    
    $\\$
    
    ● **Résultat :** $\displaystyle 4\sin(x) + 2\cos(x) + C$
    
    $\\$

**Question 5 :** Calculer $\displaystyle\int (\sqrt{x} + \frac{1}{\sqrt{x}})\, dx$

    ● **Formule :** Puissances : $\displaystyle\int x^n\, dx = \frac{x^{n+1}}{n+1} + C$ pour $\displaystyle n\neq -1$
    
    $\\$
    
    ● **Application :** $\displaystyle\sqrt{x} = x^{1/2}$, $\displaystyle\frac{1}{\sqrt{x}} = x^{-1/2}$ → $\displaystyle\int x^{1/2}\, dx = \frac{x^{3/2}}{3/2} = \frac{2}{3}x^{3/2}$, $\displaystyle\int x^{-1/2}\, dx = \frac{x^{1/2}}{1/2} = 2x^{1/2}$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \int (x^{1/2} + x^{-1/2})\, dx = \frac{2}{3}x^{3/2} + 2x^{1/2} + C$

Solution:
1. $\displaystyle \frac{x^4}{2} - \frac{5x^2}{2} + 4x + C$
2. $\displaystyle \frac{x^3}{3} + \frac{3x^2}{2} + x + C$
3. $\displaystyle 6e^x - 3x + C$
4. $\displaystyle 4\sin(x) + 2\cos(x) + C$
5. $\displaystyle \frac{2}{3}x^{3/2} + 2x^{1/2} + C$

=== Primitives - Exponentielles et Trigonométriques
Difficulté: medium

Énoncé: Calculer des primitives impliquant $\displaystyle e^{ax+b}$, $\displaystyle \sin$ et $\displaystyle \cos$.

**Question 1 :** Calculer $\displaystyle\int e^{3x}\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int e^{2x + 1}\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int \sin(2x)\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int \cos(5x)\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int (3e^{x} - 2\cos(2x))\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int e^{3x}\, dx$

    ● **Formule :** Exponentielle composée : $\displaystyle\int e^{ax+b}\, dx = \frac{1}{a}e^{ax+b} + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int e^{3x}\, dx = \frac{1}{3}e^{3x} + C$

**Question 2 :** Calculer $\displaystyle\int e^{2x+1}\, dx$

    ● **Formule :** Exponentielle composée : $\displaystyle\int e^{ax+b}\, dx = \frac{1}{a}e^{ax+b} + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int e^{2x+1}\, dx = \frac{1}{2}e^{2x+1} + C$

**Question 3 :** Calculer $\displaystyle\int \sin(2x)\, dx$

    ● **Formule :** Sinus composé : $\displaystyle\int \sin(ax+b)\, dx = -\frac{1}{a}\cos(ax+b) + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int \sin(2x)\, dx = -\frac{1}{2}\cos(2x) + C$

**Question 4 :** Calculer $\displaystyle\int \cos(5x)\, dx$

    ● **Formule :** Cosinus composé : $\displaystyle\int \cos(ax+b)\, dx = \frac{1}{a}\sin(ax+b) + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int \cos(5x)\, dx = \frac{1}{5}\sin(5x) + C$

**Question 5 :** Calculer $\displaystyle\int (3e^{x} - 2\cos(2x))\, dx$

    ● **Formule :** Linéarité + Exponentielle + Cosinus composé
    
    $\\$
    
    ● **Résultat :** $\displaystyle 3e^{x} - 2\cdot \frac{1}{2}\sin(2x) + C = 3e^x - \sin(2x) + C$

Solution:
1. $\displaystyle \frac{1}{3}e^{3x} + C$
2. $\displaystyle \frac{1}{2}e^{2x+1} + C$
3. $\displaystyle -\frac{1}{2}\cos(2x) + C$
4. $\displaystyle \frac{1}{5}\sin(5x) + C$
5. $\displaystyle 3e^x - \sin(2x) + C$

=== Primitives - Fonctions Rationnelles Simples
Difficulté: medium

Énoncé: Intégrer des fonctions rationnelles simples.

**Question 1 :** Calculer $\displaystyle\int \frac{1}{x}\, dx$ ($\displaystyle x\neq 0$)
$\\$
**Question 2 :** Calculer $\displaystyle\int \frac{2x}{x^2 + 1}\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int \frac{1}{x^2 + 4}\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int \frac{3x+2}{x^2 + 1}\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int \frac{5}{2x - 3}\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int \frac{1}{x}\, dx$ ($\displaystyle x\neq 0$)

    ● **Formule :** Inverse : $\displaystyle\int \frac{1}{x}\, dx = \ln|x| + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int \frac{1}{x}\, dx = \ln|x| + C$

**Question 2 :** Calculer $\displaystyle\int \frac{2x}{x^2 + 1}\, dx$

    ● **Formule :** Substitution : $\displaystyle u = x^2 + 1$, $\displaystyle du = 2x\,dx$ → $\displaystyle\int \frac{du}{u} = \ln|u| + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \ln(x^2 + 1) + C$

**Question 3 :** Calculer $\displaystyle\int \frac{1}{x^2 + 4}\, dx$

    ● **Formule :** Arctangente : $\displaystyle\int \frac{1}{x^2 + a^2}\, dx = \frac{1}{a}\arctan\left(\frac{x}{a}\right) + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int \frac{1}{x^2 + 2^2}\, dx = \frac{1}{2}\arctan\left(\frac{x}{2}\right) + C$

**Question 4 :** Calculer $\displaystyle\int \frac{3x+2}{x^2 + 1}\, dx$

    ● **Formule :** Décomposition + Substitution + Arctangente
    
    $\\$
    
    ● **Décomposition :** $\displaystyle\frac{3x+2}{x^2+1} = \frac{3x}{x^2+1} + \frac{2}{x^2+1}$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \frac{3}{2}\ln(x^2+1) + 2\arctan(x) + C$

**Question 5 :** Calculer $\displaystyle\int \frac{5}{2x - 3}\, dx$

    ● **Formule :** Inverse composé : $\displaystyle\int \frac{1}{ax+b}\, dx = \frac{1}{a}\ln|ax+b| + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle\int \frac{5}{2x - 3}\, dx = \frac{5}{2}\ln|2x - 3| + C$

Solution:
1. $\displaystyle \ln|x| + C$
2. $\displaystyle \ln(x^2 + 1) + C$
3. $\displaystyle \frac{1}{2}\arctan\left(\frac{x}{2}\right) + C$
4. $\displaystyle \frac{3}{2}\ln(x^2+1) + 2\arctan(x) + C$
5. $\displaystyle \frac{5}{2}\ln|2x - 3| + C$

=== Primitives - Substitution (Changement de variable)
Difficulté: medium

Énoncé: Utiliser un changement de variable adapté.

**Question 1 :** Calculer $\displaystyle\int 2x(x^2 + 1)^3\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int \frac{2x}{x^2 + 1}\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int x e^{x^2}\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int \frac{1}{\sqrt{2x + 3}}\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int \frac{1}{(x+1)^2}\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int 2x(x^2 + 1)^3\, dx$

    ● **Formule :** Substitution : $\displaystyle u = x^2 + 1$, $\displaystyle du = 2x\, dx$ → $\displaystyle\int u^3\, du = \frac{u^4}{4} + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \frac{(x^2+1)^4}{4} + C$

**Question 2 :** Calculer $\displaystyle\int \frac{2x}{x^2 + 1}\, dx$

    ● **Formule :** Substitution : $\displaystyle u = x^2 + 1$, $\displaystyle du = 2x\, dx$ → $\displaystyle\int \frac{du}{u} = \ln|u| + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \ln|x^2+1| + C$

**Question 3 :** Calculer $\displaystyle\int x e^{x^2}\, dx$

    ● **Formule :** Substitution : $\displaystyle u = x^2$, $\displaystyle du = 2x\, dx$ → $\displaystyle\int e^u \cdot \frac{du}{2} = \frac{1}{2}e^u + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \frac{1}{2}e^{x^2} + C$

**Question 4 :** Calculer $\displaystyle\int \frac{1}{\sqrt{2x + 3}}\, dx$

    ● **Formule :** Substitution : $\displaystyle u = 2x + 3$, $\displaystyle du = 2\, dx$ → $\displaystyle\int \frac{1}{\sqrt{u}}\cdot \frac{du}{2} = \sqrt{u} + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \sqrt{2x+3} + C$

**Question 5 :** Calculer $\displaystyle\int \frac{1}{(x+1)^2}\, dx$

    ● **Formule :** Puissance négative : $\displaystyle\int (x+1)^{-2}\, dx = -\frac{1}{x+1} + C$
    
    $\\$
    
    ● **Résultat :** $\displaystyle -\frac{1}{x+1} + C$

Solution:
1. $\displaystyle \frac{(x^2+1)^4}{4} + C$
2. $\displaystyle \ln|x^2+1| + C$
3. $\displaystyle \frac{1}{2}e^{x^2} + C$
4. $\displaystyle \sqrt{2x+3} + C$
5. $\displaystyle -\frac{1}{x+1} + C$

=== Primitives - Intégration par Parties (1)
Difficulté: medium

Énoncé: Appliquer la formule $\displaystyle\int u\, dv = uv - \int v\, du$.

**Question 1 :** Calculer $\displaystyle\int x e^x\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int x \cos(x)\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int \ln(x)\, dx$ ($\displaystyle x>0$)
$\\$
**Question 4 :** Calculer $\displaystyle\int x^2 \sin(x)\, dx$ (une itération supplémentaire requise)
$\\$
**Question 5 :** Calculer $\displaystyle\int x e^{2x}\, dx$

Étapes:

**Question 1 :** Calculer $\displaystyle\int x e^x\, dx$

    ● **Formule :** Intégration par parties : $\displaystyle\int u\, dv = uv - \int v\, du$
    
    $\\$
    
    ● **Choix :** $\displaystyle u = x$, $\displaystyle dv = e^x dx$ → $\displaystyle du = dx$, $\displaystyle v = e^x$
    
    $\\$
    
    ● **Calcul :** $\displaystyle \int x e^x dx = x e^x - \int e^x dx = e^x(x - 1) + C$

**Question 2 :** Calculer $\displaystyle\int x \cos(x)\, dx$

    ● **Formule :** Intégration par parties : $\displaystyle\int u\, dv = uv - \int v\, du$
    
    $\\$
    
    ● **Choix :** $\displaystyle u = x$, $\displaystyle dv = \cos(x) dx$ → $\displaystyle du = dx$, $\displaystyle v = \sin(x)$
    
    $\\$
    
    ● **Résultat :** $\displaystyle x\sin(x) + \cos(x) + C$

**Question 3 :** Calculer $\displaystyle\int \ln(x)\, dx$ ($\displaystyle x>0$)

    ● **Formule :** Intégration par parties : $\displaystyle\int u\, dv = uv - \int v\, du$
    
    $\\$
    
    ● **Choix :** $\displaystyle u = \ln(x)$, $\displaystyle dv = dx$ → $\displaystyle du = \frac{1}{x}dx$, $\displaystyle v = x$
    
    $\\$
    
    ● **Résultat :** $\displaystyle x\ln(x) - x + C$

**Question 4 :** Calculer $\displaystyle\int x^2 \sin(x)\, dx$

    ● **Formule :** Intégration par parties (deux fois) : $\displaystyle\int u\, dv = uv - \int v\, du$
    
    $\\$
    
    ● **Première IPP :** $\displaystyle u = x^2$, $\displaystyle dv = \sin(x)dx$ → $\displaystyle du = 2x dx$, $\displaystyle v = -\cos(x)$
    
    $\\$
    
    ● **Deuxième IPP :** $\displaystyle \int x\cos(x) dx$ via IPP précédente.

**Question 5 :** Calculer $\displaystyle\int x e^{2x}\, dx$

    ● **Formule :** Intégration par parties : $\displaystyle\int u\, dv = uv - \int v\, du$
    
    $\\$
    
    ● **Choix :** $\displaystyle u = x$, $\displaystyle dv = e^{2x}dx$ → $\displaystyle v = \frac{1}{2}e^{2x}$
    
    $\\$
    
    ● **Résultat :** $\displaystyle \frac{x}{2}e^{2x} - \frac{1}{4}e^{2x} + C = e^{2x}\left(\frac{x}{2} - \frac{1}{4}\right) + C$

Solution:
1. $\displaystyle e^x(x - 1) + C$
2. $\displaystyle x\sin(x) + \cos(x) + C$
3. $\displaystyle x\ln(x) - x + C$
4. $\displaystyle -x^2\cos(x) + 2(x\sin(x) + \cos(x)) + C$
5. $\displaystyle e^{2x}\left(\frac{x}{2} - \frac{1}{4}\right) + C$

=== Primitives - Intégration par Parties (2)
Difficulté: hard

Énoncé: Entraînement supplémentaire sur l'intégration par parties.

**Question 1 :** Calculer $\displaystyle\int x^2 e^x\, dx$
$\\$
**Question 2 :** Calculer $\displaystyle\int x\ln(x)\, dx$ ($\displaystyle x>0$)
$\\$
**Question 3 :** Calculer $\displaystyle\int x\sin(2x)\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int (x+1)e^x\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int x^2 \cos(x)\, dx$

Étapes:

**Question 1 :** IPP deux fois ($\displaystyle u = x^2$, $\displaystyle dv = e^x dx$), résultat attendu $\displaystyle e^x(x^2 - 2x + 2) + C$

**Question 2 :** $\displaystyle u = \ln(x)$, $\displaystyle dv = x dx$ → $\displaystyle v = \frac{x^2}{2}$, résultat $\displaystyle \frac{x^2}{2}\ln(x) - \frac{x^2}{4} + C$

**Question 3 :** $\displaystyle u = x$, $\displaystyle dv = \sin(2x)dx$ → $\displaystyle v = -\frac{1}{2}\cos(2x)$, résultat $\displaystyle -\frac{x}{2}\cos(2x) + \frac{1}{4}\sin(2x) + C$

**Question 4 :** Linéarité + primitive de $\displaystyle e^x$ : $\displaystyle \int (x+1)e^x dx = e^x(x+1) + C$

**Question 5 :** IPP deux fois (analogue à 1), résultat $\displaystyle x^2\sin(x) + 2x\cos(x) - 2\sin(x) + C$

Solution:
1. $\displaystyle e^x(x^2 - 2x + 2) + C$
2. $\displaystyle \frac{x^2}{2}\ln(x) - \frac{x^2}{4} + C$
3. $\displaystyle -\frac{x}{2}\cos(2x) + \frac{1}{4}\sin(2x) + C$
4. $\displaystyle e^x(x+1) + C$
5. $\displaystyle x^2\sin(x) + 2x\cos(x) - 2\sin(x) + C$

=== Primitives - Mélanges Classiques
Difficulté: medium

Énoncé: Intégrer des combinaisons mixtes.

$\\$
**Question 2 :** Calculer $\displaystyle\int (x \sin(x))\, dx$
$\\$
**Question 3 :** Calculer $\displaystyle\int (e^x + \cos(x))\, dx$
$\\$
**Question 4 :** Calculer $\displaystyle\int (x^2 + e^{2x})\, dx$
$\\$
**Question 5 :** Calculer $\displaystyle\int (\frac{1}{x} + \frac{1}{x^2})\, dx$ ($\displaystyle x\neq 0$)

Étapes:

**Question 2 :** IPP → $\displaystyle -x\cos(x) + \sin(x) + C$

=== Primitives - Applications et Modélisation
Difficulté: hard

Énoncé: Exercices d'application avec primitives pour des modèles simples.

**Question 1 :** Trouver $\displaystyle F$ telle que $\displaystyle F'(x) = 3e^{2x} - 4$ et $\displaystyle F(0) = 1$
$\\$
**Question 2 :** Trouver $\displaystyle F$ telle que $\displaystyle F'(x) = x - \cos(x)$ et $\displaystyle F(\pi) = 0$
$\\$
**Question 3 :** Trouver $\displaystyle F$ telle que $\displaystyle F'(x) = \frac{2}{x+1}$, $\displaystyle x>-1$, et $\displaystyle F(0) = 2$
$\\$
**Question 4 :** Trouver $\displaystyle F$ telle que $\displaystyle F'(x) = (x+1)e^x$ et $\displaystyle F(0) = 0$
$\\$
**Question 5 :** Trouver $\displaystyle F$ telle que $\displaystyle F'(x) = \frac{1}{\sqrt{2x+3}}$ et $\displaystyle F(0) = 0$

Étapes:

**Question 1 :** Primitive générale : $\displaystyle F(x) = \frac{3}{2}e^{2x} - 4x + C$; $\displaystyle F(0)=1 \Rightarrow \frac{3}{2} - 0 + C = 1 \Rightarrow C = -\frac{1}{2}$

**Question 2 :** $\displaystyle F(x) = \frac{x^2}{2} - \sin(x) + C$; $\displaystyle F(\pi)=0 \Rightarrow \frac{\pi^2}{2} - 0 + C = 0 \Rightarrow C = -\frac{\pi^2}{2}$

**Question 3 :** $\displaystyle F(x) = 2\ln(x+1) + C$; $\displaystyle F(0)=2 \Rightarrow 2\ln 1 + C = 2 \Rightarrow C=2$

**Question 4 :** $\displaystyle F(x) = (x+1)e^x + C$; $\displaystyle F(0)=0 \Rightarrow 1 + C = 0 \Rightarrow C = -1$

**Question 5 :** $\displaystyle F(x) = \sqrt{2x+3} + C$; $\displaystyle F(0)=0 \Rightarrow \sqrt{3} + C = 0 \Rightarrow C = -\sqrt{3}$

Solution:
1. $\displaystyle F(x) = \frac{3}{2}e^{2x} - 4x - \frac{1}{2}$
2. $\displaystyle F(x) = \frac{x^2}{2} - \sin(x) - \frac{\pi^2}{2}$
3. $\displaystyle F(x) = 2\ln(x+1) + 2$
4. $\displaystyle F(x) = (x+1)e^x - 1$
5. $\displaystyle F(x) = \sqrt{2x+3} - \sqrt{3}$
