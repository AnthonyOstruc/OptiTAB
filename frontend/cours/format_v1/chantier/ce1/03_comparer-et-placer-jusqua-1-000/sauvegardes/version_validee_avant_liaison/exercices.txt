===
Découverte - Les pas de dix
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la ligne, deux graduations voisines sont séparées de 10.

[IMAGE_1]

1. Complète les trois graduations sans étiquette.
2. Combien y a-t-il d’intervalles de 400 à 500 ?
3. Quelle graduation vient juste avant 450 ?
4. Quelle graduation vient deux intervalles après 480 ?
5. Range les trois nombres trouvés du plus grand au plus petit.

Étapes:
<!-- optitab:1 -->

## Question 1 : Complète les trois graduations sans étiquette.

::: methode
Compte les intervalles depuis 400 ; chacun vaut 10.
:::

::: etape Raisonner
Deux intervalles après 400 : $400+20=420$ ; cinq : $400+50=450$ ; huit : $400+80=480$.
:::

::: resultat
$420$ ; $450$ ; $480$.
:::

## Question 2 : Combien y a-t-il d’intervalles de 400 à 500 ?

::: methode
Compte les espaces entre deux traits, en ajoutant dix à chaque passage.
:::

::: etape Raisonner
400, 410, 420, 430, 440, 450, 460, 470, 480, 490, 500 : dix passages.
:::

::: resultat
10 intervalles.
:::

## Question 3 : Quelle graduation vient juste avant 450 ?

::: methode
Recule d’un pas de dix.
:::

::: etape Raisonner
$450-10=440$.
:::

::: resultat
$440$.
:::

## Question 4 : Quelle graduation vient deux intervalles après 480 ?

::: methode
Avance deux fois de dix.
:::

::: etape Raisonner
$480+10=490$ puis $490+10=500$.
:::

::: resultat
$500$.
:::

## Question 5 : Range les trois nombres trouvés du plus grand au plus petit.

::: methode
Sur une ligne, les nombres augmentent vers la droite.
:::

::: etape Raisonner
480 est à droite de 450, lui-même à droite de 420.
:::

::: resultat
$480>450>420$.
:::

Solution:
<!-- optitab:1 -->
1. $420$ ; $450$ ; $480$.
2. 10 intervalles.
3. $440$.
4. $500$.
5. $480>450>420$.

Découverte - Comparer les bons rangs
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On compare les couples 306 et 360 ; 721 et 719 ; 500 et 500.

1. Complète les trois comparaisons avec le signe qui convient.
2. Quel nombre est le plus petit parmi les six nombres écrits ?
3. Range 306, 360 et 500 dans l’ordre croissant.
4. Encadre 719 entre deux dizaines consécutives.
5. Quel nombre est juste après 719 ? Compare-le à 721.

Étapes:
<!-- optitab:1 -->

## Question 1 : Complète les trois comparaisons avec le signe qui convient.

::: methode
Compare les centaines, puis les dizaines si les centaines sont égales.
:::

::: etape Raisonner
306 et 360 ont 3 centaines : 0 dizaine est inférieur à 6 dizaines. 721 et 719 ont 7 centaines : 2 dizaines dépassent 1 dizaine. Les deux derniers nombres sont identiques.
:::

::: resultat
$306<360$ ; $721>719$ ; $500=500$.
:::

## Question 2 : Quel nombre est le plus petit parmi les six nombres écrits ?

::: methode
Repère la plus petite centaine puis la plus petite dizaine.
:::

::: etape Raisonner
Les nombres à 3 centaines précèdent les autres ; 306 précède 360.
:::

::: resultat
$306$.
:::

## Question 3 : Range 306, 360 et 500 dans l’ordre croissant.

::: methode
Place d’abord les nombres à trois centaines, puis le nombre à cinq centaines.
:::

::: etape Raisonner
Entre les deux nombres à trois centaines, 306 a moins de dizaines.
:::

::: resultat
$306<360<500$.
:::

## Question 4 : Encadre 719 entre deux dizaines consécutives.

::: methode
Cherche la dizaine juste avant et celle juste après.
:::

::: etape Raisonner
719 dépasse 710 mais n’atteint pas 720.
:::

::: resultat
$710<719<720$.
:::

## Question 5 : Quel nombre est juste après 719 ? Compare-le à 721.

::: methode
Ajoute une unité puis compare les unités.
:::

::: etape Raisonner
$719+1=720$ ; 720 et 721 ont les mêmes centaines et dizaines, mais $0<1$.
:::

::: resultat
$720<721$.
:::

Solution:
<!-- optitab:1 -->
1. $306<360$ ; $721>719$ ; $500=500$.
2. $306$.
3. $306<360<500$.
4. $710<719<720$.
5. $720<721$.

Découverte - Cinq étiquettes à ranger
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Les étiquettes portent 423 ; 342 ; 432 ; 324 ; 400.

1. Range les cinq nombres du plus petit au plus grand.
2. Quel est le plus grand nombre ?
3. Quel nombre vient immédiatement avant 423 dans ce rangement ?
4. Encadre 342 entre deux centaines consécutives.
5. Insère 430 à sa place dans le rangement.

Étapes:
<!-- optitab:1 -->

## Question 1 : Range les cinq nombres du plus petit au plus grand.

::: methode
Regroupe par centaines puis compare les dizaines et les unités.
:::

::: etape Raisonner
Les nombres à 3 centaines sont 324 et 342 ; les autres sont 400, 423, 432. Dans chaque groupe, on compare ensuite les dizaines.
:::

::: resultat
$324<342<400<423<432$.
:::

## Question 2 : Quel est le plus grand nombre ?

::: methode
Choisis le nombre à droite dans le rangement croissant.
:::

::: etape Raisonner
432 vient après tous les autres nombres.
:::

::: resultat
$432$.
:::

## Question 3 : Quel nombre vient immédiatement avant 423 dans ce rangement ?

::: methode
Relis les étiquettes dans l’ordre trouvé.
:::

::: etape Raisonner
Le rangement contient 400, puis 423, puis 432.
:::

::: resultat
$400$.
:::

## Question 4 : Encadre 342 entre deux centaines consécutives.

::: methode
Une centaine commence par un multiple de cent.
:::

::: etape Raisonner
342 a 3 centaines et reste inférieur à 4 centaines.
:::

::: resultat
$300<342<400$.
:::

## Question 5 : Insère 430 à sa place dans le rangement.

::: methode
Compare 430 aux nombres à quatre centaines.
:::

::: etape Raisonner
430 dépasse 423 mais a 2 unités de moins que 432.
:::

::: resultat
$324<342<400<423<430<432$.
:::

Solution:
<!-- optitab:1 -->
1. $324<342<400<423<432$.
2. $432$.
3. $400$.
4. $300<342<400$.
5. $324<342<400<423<430<432$.

Entraînement - Autour de 568
Id: nouveau-4
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On cherche à situer 568 avec précision.

1. Encadre 568 entre deux centaines consécutives.
2. Encadre 568 entre deux dizaines consécutives.
3. Quelle est la distance entre 560 et 568 ?
4. Quelle est la distance entre 568 et 570 ?
5. 568 est-il plus près de 560 ou de 570 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Encadre 568 entre deux centaines consécutives.

::: methode
Lis le chiffre des centaines et prends la centaine suivante.
:::

::: etape Raisonner
568 dépasse 500 et reste inférieur à 600.
:::

::: resultat
$500<568<600$.
:::

## Question 2 : Encadre 568 entre deux dizaines consécutives.

::: methode
Prends la dizaine inférieure et ajoute dix pour la suivante.
:::

::: etape Raisonner
568 contient 56 dizaines et 8 unités ; la dizaine suivante est 570.
:::

::: resultat
$560<568<570$.
:::

## Question 3 : Quelle est la distance entre 560 et 568 ?

::: methode
Cherche le complément de 560 à 568.
:::

::: etape Raisonner
$568-560=8$.
:::

::: resultat
8 unités.
:::

## Question 4 : Quelle est la distance entre 568 et 570 ?

::: methode
Complète 568 jusqu’à la dizaine suivante.
:::

::: etape Raisonner
$570-568=2$.
:::

::: resultat
2 unités.
:::

## Question 5 : 568 est-il plus près de 560 ou de 570 ?

::: methode
Compare les deux distances calculées.
:::

::: etape Raisonner
La distance à 570 est 2 et celle à 560 est 8 ; $2<8$.
:::

::: resultat
568 est plus près de 570.
:::

Solution:
<!-- optitab:1 -->
1. $500<568<600$.
2. $560<568<570$.
3. 8 unités.
4. 2 unités.
5. 568 est plus près de 570.

Id: nouveau-6

Énoncé:
<!-- optitab:1 -->
Les traits avancent de 100 en 100. Le point A est marqué.

[IMAGE_1]

1. Quel nombre le point A représente-t-il ?
2. Quel est le nombre au trait juste avant A ?
3. Quel est le nombre deux traits après A ?
4. Combien d’intervalles séparent A de 1 000 ?
5. Place B au nombre 400. Est-il à gauche ou à droite de A ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel nombre le point A représente-t-il ?

::: methode
Compte les intervalles de cent depuis zéro.
:::

::: etape Raisonner
A se trouve six intervalles après zéro : $6\times100=600$.
:::

::: resultat
$600$.
:::

## Question 2 : Quel est le nombre au trait juste avant A ?

::: methode
Recule d’un intervalle de cent.
:::

::: etape Raisonner
$600-100=500$.
:::

::: resultat
$500$.
:::

## Question 3 : Quel est le nombre deux traits après A ?

::: methode
Avance de deux centaines.
:::

::: etape Raisonner
$600+200=800$.
:::

::: resultat
$800$.
:::

## Question 4 : Combien d’intervalles séparent A de 1 000 ?

::: methode
Compte les passages par 700, 800, 900 et 1 000.
:::

::: etape Raisonner
Quatre passages ajoutent quatre centaines : $600+400=1000$.
:::

::: resultat
4 intervalles.
:::

## Question 5 : Place B au nombre 400. Est-il à gauche ou à droite de A ?

::: methode
Les nombres les plus petits sont à gauche.
:::

::: etape Raisonner
$400<600$ ; B se place quatre intervalles après zéro.
:::

::: resultat
B est à gauche de A.

Solution:
<!-- optitab:1 -->
1. $600$.
2. $500$.
3. $800$.

5. B est à gauche de A.

Problème - Deux écoles
Id: nouveau-7
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une école accueille 398 élèves, une autre 403 élèves.

1. Quelle école a le plus d’élèves ?
2. Quel effectif est inférieur à 400 ?
3. Combien faut-il ajouter à 398 pour atteindre 400 ?
4. Combien dépasse-t-on 400 avec 403 ?
5. Quel est l’écart entre les deux effectifs ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle école a le plus d’élèves ?

::: methode
Compare d’abord les centaines.
:::

::: etape Raisonner
403 a quatre centaines ; 398 n’en a que trois.
:::

::: resultat
$403>398$ : la seconde école.
:::

## Question 2 : Quel effectif est inférieur à 400 ?

::: methode
Compare chaque effectif à la centaine 400.
:::

::: etape Raisonner
398 est avant 400 ; 403 est après.
:::

::: resultat
$398<400$.
:::

## Question 3 : Combien faut-il ajouter à 398 pour atteindre 400 ?

::: methode
Avance unité par unité jusqu’à 400.
:::

::: etape Raisonner
$398+2=400$.
:::

::: resultat
2 élèves.
:::

## Question 4 : Combien dépasse-t-on 400 avec 403 ?

::: methode
Cherche le complément de 400 à 403.
:::

::: etape Raisonner
$403-400=3$.
:::

::: resultat
3 élèves.
:::

## Question 5 : Quel est l’écart entre les deux effectifs ?

::: methode
Passe par 400 et réunis les deux petits écarts.
:::

::: etape Raisonner
De 398 à 400 : 2 ; de 400 à 403 : 3. $2+3=5$.
:::

::: resultat
5 élèves.
:::

Solution:
<!-- optitab:1 -->
1. $403>398$ : la seconde école.
2. $398<400$.
3. 2 élèves.
4. 3 élèves.
5. 5 élèves.

Compare deux graduations voisines.

1 unité.

243, 244, 245, 246 : le quatrième passage arrive à 246.

Recule de quatre unités.

::: etape Raisonner
$242-4=238$.

Problème - Les centaines d’abord
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Lina range 509 avant 490 parce que 0 est plus petit que 9.

1. Explique son erreur et écris le bon ordre.
2. Encadre 509 entre deux centaines consécutives.
3. Encadre 490 et 509 par une même centaine placée entre eux.
4. Combien manque-t-il à 490 pour atteindre 500 ?
5. Quel est l’écart entre 490 et 509 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Explique son erreur et écris le bon ordre.

::: methode
Compare les centaines avant les dizaines.
:::

::: etape Raisonner
490 a 4 centaines ; 509 en a 5. Les dizaines ne décident donc pas de cette comparaison.
:::

::: resultat
$490<509$.
:::

## Question 2 : Encadre 509 entre deux centaines consécutives.

::: methode
Repère les centaines voisines.
:::

::: etape Raisonner
509 dépasse 500 et reste inférieur à 600.
:::

::: resultat
$500<509<600$.
:::

## Question 3 : Encadre 490 et 509 par une même centaine placée entre eux.

::: methode
Cherche la centaine qui termine les quatre centaines et commence les cinq centaines.
:::

::: etape Raisonner
490 est avant 500 ; 509 est après 500.
:::

::: resultat
$490<500<509$.
:::

## Question 4 : Combien manque-t-il à 490 pour atteindre 500 ?

::: methode
Cherche le complément à la centaine suivante.
:::

::: etape Raisonner
$500-490=10$.
:::

::: resultat
10 unités.
:::

## Question 5 : Quel est l’écart entre 490 et 509 ?

::: methode
Passe par 500.
:::

::: etape Raisonner
De 490 à 500 : 10 ; de 500 à 509 : 9. $10+9=19$.
:::

::: resultat
19 unités.
:::

Solution:
<!-- optitab:1 -->
1. $490<509$.
2. $500<509<600$.
3. $490<500<509$.
4. 10 unités.
5. 19 unités.
