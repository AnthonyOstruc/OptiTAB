=== Découverte - Lire deux doubles
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Explique chaque flèche et écris le produit obtenu.

[IMAGE_1]

2. Trouve le premier double de $18$.

3. Double encore le premier résultat.

4. Double une troisième fois pour obtenir huit groupes.

5. Combien de doubles successifs faut-il pour multiplier par 4, puis par 8 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Je cherche et j’explique

::: methode
Je repère ce qui est demandé, puis j’applique la méthode du chapitre.
:::

::: etape Mon raisonnement
Je double : $18+18 = 36$.

Je double : $36+36 = 72$.

$$
18\times 4 = 72
$$
:::

::: resultat
18 → 36 → 72. On double deux fois, donc 18 × 4 = 72.
:::

## Question 2 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $8+8 = 16$.

J'écris 6 et je reporte 1 au rang suivant.

Pour les dizaines, je calcule $1+1+1 = 3$.

$$
18+18 = 36
$$
:::

::: resultat
$18+18 = 36$
:::

## Question 3 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $6+6 = 12$.

J'écris 2 et je reporte 1 au rang suivant.

Pour les dizaines, je calcule $3+3+1 = 7$.

$$
36+36 = 72
$$
:::

::: resultat
$36+36 = 72$
:::

## Question 4 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $2+2 = 4$.

J'écris 4 ; il n'y a pas de retenue.

Pour les dizaines, je calcule $7+7 = 14$.

$$
72+72 = 144
$$
:::

::: resultat
$72+72 = 144$
:::

## Question 5 : Je cherche et j’explique

::: methode
Je compte les groupes après chaque double.
:::

::: etape Mon raisonnement
Un double fait deux groupes ; le double suivant fait quatre groupes ; le troisième fait huit groupes.
:::

::: resultat
Deux doubles donnent le produit par 4 ; trois doubles donnent le produit par 8.
:::

Solution:
<!-- optitab:1 -->
1. 18 → 36 → 72. On double deux fois, donc 18 × 4 = 72.
2. $18+18 = 36$
3. $36+36 = 72$
4. $72+72 = 144$
5. Deux doubles donnent le produit par 4 ; trois doubles donnent le produit par 8.

4. $300+300 = 600$
5. Deux doubles donnent le produit par 4 ; trois doubles donnent le produit par 8.

===
=== Entraînement - Compter les groupes doublés
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. Lina double 23 puis ajoute encore 23 pour calculer 23 × 4. Corrige.

2. Trouve le premier double de $23$.

3. Double encore le premier résultat.

4. Double une troisième fois pour obtenir huit groupes.

5. Combien de doubles successifs faut-il pour multiplier par 4, puis par 8 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Je cherche et j’explique

::: methode
Je repère ce qui est demandé, puis j’applique la méthode du chapitre.
:::

::: etape Mon raisonnement
Doubler 23 puis ajouter 23 ne donne que trois groupes. Pour quatre groupes, je double le premier double.

Je double : $23+23 = 46$.

Je double : $46+46 = 92$.

$$
23\times 4 = 92
$$
:::

::: resultat
Elle n’a que trois groupes. Il faut doubler 46 : 92.
:::

## Question 2 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $3+3 = 6$.

J'écris 6 ; il n'y a pas de retenue.

Pour les dizaines, je calcule $2+2 = 4$.

$$
23+23 = 46
$$
:::

::: resultat
$23+23 = 46$
:::

## Question 3 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $6+6 = 12$.

J'écris 2 et je reporte 1 au rang suivant.

Pour les dizaines, je calcule $4+4+1 = 9$.

$$
46+46 = 92
$$
:::

::: resultat
$46+46 = 92$
:::

## Question 4 : Je cherche et j’explique

::: methode
J’aligne les unités et je commence à droite ; j’échange dix unités d’un rang contre une du rang suivant.
:::

::: etape Mon raisonnement
Pour les unités, je calcule $2+2 = 4$.

J'écris 4 ; il n'y a pas de retenue.

Pour les dizaines, je calcule $9+9 = 18$.

$$
92+92 = 184
$$
:::

::: resultat
$92+92 = 184$
:::

## Question 5 : Je cherche et j’explique

::: methode
Je compte les groupes après chaque double.
:::

::: etape Mon raisonnement
Un double fait deux groupes ; le double suivant fait quatre groupes ; le troisième fait huit groupes.
:::

::: resultat
Deux doubles donnent le produit par 4 ; trois doubles donnent le produit par 8.
:::

Solution:
<!-- optitab:1 -->
1. Elle n’a que trois groupes. Il faut doubler 46 : 92.
2. $23+23 = 46$
3. $46+46 = 92$
4. $92+92 = 184$
5. Deux doubles donnent le produit par 4 ; trois doubles donnent le produit par 8.
