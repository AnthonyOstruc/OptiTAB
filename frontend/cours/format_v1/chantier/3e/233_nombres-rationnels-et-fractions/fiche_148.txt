Titre: Résumé : Nombres rationnels et fractions

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : fractions égales et irréductibles, les quatre opérations, fraction d’une quantité, comparaison.
:::

## I. Nombres rationnels

- **Rationnel** : nombre qui s’écrit $\dfrac{a}{b}$ avec $a$, $b$ entiers et $b \neq 0$ ; c’est le nombre qui, multiplié par $b$, donne $a$.
- **Fractions égales** : $\dfrac{a}{b} = \dfrac{a \times k}{b \times k}$ pour $k \neq 0$.
- **Irréductible** : on décompose en facteurs premiers et on simplifie : $\dfrac{84}{120} = \dfrac{2^2 \times 3 \times 7}{2^3 \times 3 \times 5} = \dfrac{7}{10}$.

## II. Les quatre opérations

| Opération | Règle |
|---|---|
| Somme, différence | dénominateur commun, puis $\dfrac{a}{d} + \dfrac{b}{d} = \dfrac{a + b}{d}$ |
| Produit | $\dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{a \times c}{b \times d}$ |
| Quotient | $\dfrac{a}{b} \div \dfrac{c}{d} = \dfrac{a}{b} \times \dfrac{d}{c}$ |
| Fraction de $Q$ | $\dfrac{a}{b}$ de $Q$ $= \dfrac{a}{b} \times Q$ |

- Priorités : parenthèses, puissances, $\times$ et $\div$, puis $+$ et $-$.
- Inverse de $\dfrac{c}{d}$ : $\dfrac{d}{c}$ (leur produit vaut $1$).

## III. Comparer, arrondir

- Comparer : même dénominateur positif, puis comparer les numérateurs : $\dfrac{2}{3} = \dfrac{8}{12} \lt \dfrac{9}{12} = \dfrac{3}{4}$.
- Négatifs : le plus loin de zéro est le plus petit : $-\dfrac{5}{6} \lt -\dfrac{3}{4}$.
- Valeur exacte $\dfrac{9}{7}$, valeur approchée $\dfrac{9}{7} \approx 1{,}29$ : on arrondit à la fin.

## IV. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Additionner les dénominateurs : $\dfrac{1}{2} + \dfrac{1}{3} = \dfrac{5}{6}$, pas $\dfrac{2}{5}$.
2. Simplifier un terme d’une somme : $\dfrac{8 + 4}{4} = 3$, pas $8 + 1$.
3. Inverser la mauvaise fraction : on inverse le **diviseur**.
4. Additionner des fractions de touts différents : « les $\dfrac{2}{3}$ du reste » se calcule sur le reste.
:::

::: conseil Réflexe brevet
Je repère le tout de référence, je garde les valeurs exactes, je donne une fraction irréductible et je vérifie que les parts redonnent le tout.
:::
