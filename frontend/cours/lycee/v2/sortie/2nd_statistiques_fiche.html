📚 Objectif pédagogique : retenir l’essentiel : proportions, évolutions, indicateurs de position et de dispersion. Programme de Seconde.

I. Information chiffrée

$\displaystyle CM = 1 + t = \frac{V_1}{V_0}$

[IMAGE_1]

1️⃣ Proportion : $\displaystyle p = \frac{n_A}{n_E}$ ; pourcentage de pourcentage : $\displaystyle p_{A/F} = p_{A/E} \times p_{E/F}$.

2️⃣ Évolutions successives : on multiplie les coefficients.

3️⃣ Évolution réciproque : coefficient $\displaystyle \frac{1}{CM}$.

II. Statistique descriptive

[IMAGE_2]

1️⃣ Moyenne pondérée : $\displaystyle \bar{x} = \frac{n_1x_1 + \cdots + n_px_p}{N}$ ; transformée $\displaystyle ax + b$ → moyenne $\displaystyle a\bar{x} + b$.

2️⃣ Médiane, $\displaystyle Q_1$, $\displaystyle Q_3$ : sur la série rangée ($\displaystyle 25\,\%$, $\displaystyle 50\,\%$, $\displaystyle 75\,\%$ des valeurs).

3️⃣ Dispersion : écart interquartile $\displaystyle Q_3 - Q_1$ ; écart type $\displaystyle \sigma$ (calculatrice).

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Additionner des pourcentages d’évolution : $\displaystyle +10\,\%$ puis $\displaystyle -10\,\%$ donne $\displaystyle -1\,\%$.

2️⃣ Croire que la réciproque d’une hausse de $\displaystyle 25\,\%$ est une baisse de $\displaystyle 25\,\%$ : c’est $\displaystyle -20\,\%$.

3️⃣ Chercher la médiane ou les quartiles sans avoir rangé les valeurs.

4️⃣ Oublier les effectifs dans une moyenne pondérée.

🏆 Réflexe : une évolution en pourcentage → je passe au coefficient multiplicateur ; une série → je donne un indicateur de position et un indicateur de dispersion.
