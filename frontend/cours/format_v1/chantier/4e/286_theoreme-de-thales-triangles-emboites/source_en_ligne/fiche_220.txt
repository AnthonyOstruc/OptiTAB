Titre: Résumé : Théorème de Thalès (triangles emboîtés)

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : la configuration des triangles emboîtés, l'égalité des trois rapports et la méthode de calcul. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Le théorème</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:520px;">
<p style="margin:0; font-weight:bold;">$M \in [AB]$, $N \in [AC]$, $(MN) \parallel (BC)$ ⟹ $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• En haut : le <strong>petit</strong> triangle $AMN$ ; en bas : le <strong>grand</strong> triangle $ABC$.</p>
<p style="margin:6px 0 0 0;">• Les longueurs sont <strong>proportionnelles</strong> : $AMN$ est une réduction de $ABC$ de coefficient $k = \dfrac{AM}{AB}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. La méthode</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Vérifier les trois conditions (points sur les côtés, droites parallèles).</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire l'égalité des trois rapports, puis remplacer par les valeurs connues.</p>
<p style="margin:6px 0 0 0;">3️⃣ Garder deux rapports et faire un produit en croix : $\dfrac{3}{5} = \dfrac{AN}{10}$ donne $AN = \dfrac{3 \times 10}{5} = 6$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Appliquer le théorème sans parallèles justifiées.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $MB$ au lieu de $AB$ (ou $NC$ au lieu de $AC$) au dénominateur.</p>
<p style="margin:6px 0 0 0;">3️⃣ Mélanger les triangles : petit en haut pour un rapport, grand en haut pour un autre.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de contrôler : un côté du petit triangle doit être plus court que le côté correspondant du grand.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> deux droites parallèles qui coupent les deux côtés d'un angle → Thalès ; deux droites perpendiculaires à une même troisième → elles sont parallèles !</p>
</div>
