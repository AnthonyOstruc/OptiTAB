===TABLEAUX - RÈGLES GÉNÉRALES

IMPORTANT : 
- Maximum 2 colonnes (pour compatibilité mobile)
- Largeur des colonnes : 50% chacune (égales)
- Utiliser table-layout: fixed
- Bordures arrondies (border-radius: 8px)
- Ombres légères (box-shadow)
- Headers avec gradients

===POLICE ET TYPOGRAPHIE

- Police principale : Arial, sans-serif
- Taille titre section : par défaut (h2)
- Taille header tableau : 1.05em
- Font-weight header : 600
- Line-height général : 1.6

===ESPACEMENTS

- Padding conteneur principal : 20px
- Padding encadrés : 15px
- Padding tableaux : 14px 16px (header), 12px 16px (cellules)
- Margin entre sections : 15px 0
- Border-radius : 8px (tableaux), 6px (encadrés), 12px (conteneur principal)

===RÈGLES IMPORTANTES

1. TOUJOURS utiliser table-layout: fixed pour les tableaux
2. TOUJOURS définir width: 50% sur chaque colonne <th>
3. MAXIMUM 2 colonnes par tableau
4. Dernière ligne du tbody : pas de border-bottom
5. Alterner les couleurs de lignes (#f8f9fa pour la ligne neutre)
6. Utiliser border-collapse: separate pour les coins arrondis
7. overflow: hidden sur les tableaux pour les coins arrondis
