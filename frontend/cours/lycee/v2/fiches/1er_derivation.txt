<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : nombre dérivé, tangente, formules de dérivation, lien avec les variations. Programme de Première.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Nombre dérivé et tangente</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$T : y = f'(a)(x - a) + f(a)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $f'(a)$ = limite de $\frac{f(a + h) - f(a)}{h}$ quand $h \rightarrow 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $(x^n)' = nx^{n-1}$ ; $\left(\frac{1}{x}\right)' = -\frac{1}{x^2}$ ; $(\sqrt{x})' = \frac{1}{2\sqrt{x}}$ ($x \gt 0$).</p>
<p style="margin:6px 0 0 0;">3️⃣ $(uv)' = u'v + uv'$ ; $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ ; $\big(g(ax + b)\big)' = a\,g'(ax + b)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Variations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $f' \ge 0$ sur $I$ → $f$ croissante ; $f' \le 0$ → $f$ décroissante.</p>
<p style="margin:6px 0 0 0;">2️⃣ $f'$ s’annule en changeant de signe → extremum local.</p>
<p style="margin:6px 0 0 0;">3️⃣ Méthode : $f'(x)$, factorisation, signe, variations, valeurs.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Dériver un produit comme $u'v'$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Inverser $u'v$ et $uv'$ dans la formule du quotient.</p>
<p style="margin:6px 0 0 0;">3️⃣ Confondre $f(a)$ et $f'(a)$ dans l’équation de la tangente.</p>
<p style="margin:6px 0 0 0;">4️⃣ Conclure à un extremum dès que $f'(a) = 0$ : il faut un changement de signe ($x^3$ en $0$).</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> variations demandées → je dérive, je factorise $f'(x)$ et je fais son tableau de signes.</p>
</div>
