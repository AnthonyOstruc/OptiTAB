=== Découverte - Pythagore - 1. Reconnaître l'hypoténuse
Id: 3188
Difficulté: easy
Image: pythagore_4e_trois_triangles.png

Énoncé:
<!-- optitab:1 -->
Voici trois triangles rectangles. Les angles droits sont codés.

[IMAGE_1]

1. Dans le triangle ①, quelle est l'hypoténuse ? Écrire l'égalité de Pythagore.
2. Dans le triangle ②, quelle est l'hypoténuse ? Écrire l'égalité de Pythagore.
3. Dans le triangle ③, quelle est l'hypoténuse ? Écrire l'égalité de Pythagore.
4. Comment repère-t-on l'hypoténuse, même quand le triangle est « penché » ?
5. Dans le triangle ③, $\displaystyle GH = 5$ et $\displaystyle HK = 12$ (en cm). Calculer $\displaystyle GK$.
6. Vérifier que l'hypoténuse calculée est bien le plus long côté du triangle ③.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle 1

::: methode
L'hypoténuse est le côté opposé à l'angle droit.
:::

::: etape L'angle droit est en $\displaystyle A$
le côté opposé est $\displaystyle [BC]$.
:::

::: resultat
$[BC]$ ; $BC^2 = AB^2 + AC^2$.
:::

## Question 2 : Le triangle 2

::: etape L'angle droit est en $\displaystyle F$
le côté opposé est $\displaystyle [DE]$.
:::

::: resultat
$[DE]$ ; $DE^2 = DF^2 + FE^2$.
:::

## Question 3 : Le triangle 3

::: etape L'angle droit est en $\displaystyle H$
le côté opposé est $\displaystyle [GK]$.
:::

::: resultat
$[GK]$ ; $GK^2 = GH^2 + HK^2$.
:::

## Question 4 : Repérer l'hypoténuse

::: etape Les deux autres côtés partent du sommet de l'angle droit.
:::

::: resultat
C'est le côté qui ne touche pas le sommet de l'angle droit ; c'est aussi le plus long côté.
:::

**Erreur fréquente :** Croire que l'hypoténuse est toujours « en bas » ou « oblique » : seule la position de l'angle droit compte.

## Question 5 : Le calcul de GK

::: etape $\displaystyle GK^2 = 5^2 + 12^2 = 25 + 144 = 169$
:::

::: resultat
$\displaystyle GK = \sqrt{169} = 13$ cm
:::

## Question 6 : Le plus long côté

::: etape $13 > 12$ et $13 > 5$.
:::

::: resultat
$\displaystyle [GK]$ est bien le plus long côté.
:::

**À retenir :** L'hypoténuse est toujours plus longue que chaque côté de l'angle droit : c'est un bon moyen de contrôle.

Solution:
<!-- optitab:1 -->
1. $[BC]$ ; $BC^2 = AB^2 + AC^2$
2. $[DE]$ ; $DE^2 = DF^2 + FE^2$
3. $[GK]$ ; $GK^2 = GH^2 + HK^2$
4. Le côté opposé à l'angle droit
5. $\displaystyle 13$ cm
6. $\displaystyle 13 > 12 > 5$

=== Découverte - Pythagore - 2. Calculer l'hypoténuse
Id: 3189
Difficulté: easy
Image: pythagore_4e_9_12.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle ABC$ est rectangle en $\displaystyle A$, avec $\displaystyle AB = 9$ cm et $\displaystyle AC = 12$ cm.

[IMAGE_1]

1. Quelle est l'hypoténuse du triangle $\displaystyle ABC$ ?
2. Écrire l'égalité de Pythagore pour ce triangle.
3. Calculer $\displaystyle BC^2$.
4. En déduire $\displaystyle BC$.
5. Calculer le périmètre et l'aire du triangle $\displaystyle ABC$.
6. Calculer la longueur de la hauteur issue de $\displaystyle A$, en utilisant l'aire.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'hypoténuse

::: etape L'angle droit est en $\displaystyle A$.
:::

::: resultat
$$[BC]$$
:::

## Question 2 : L'égalité de Pythagore

::: etape Le triangle est rectangle en $\displaystyle A$
on peut appliquer le théorème.
:::

::: resultat
$$BC^2 = AB^2 + AC^2$$
:::

## Question 3 : Le carré de l'hypoténuse

::: etape $\displaystyle BC^2 = 9^2 + 12^2 = 81 + 144$
:::

::: resultat
$$BC^2 = 225$$
:::

## Question 4 : La longueur BC

::: etape $BC = \sqrt{225}$ ($BC$ est une longueur, donc positive).
:::

::: resultat
$\displaystyle BC = 15$ cm
:::

**Rédaction :** Le triangle $ABC$ est rectangle en $A$. D'après le théorème de Pythagore : $BC^2 = AB^2 + AC^2 = 81 + 144 = 225$, donc $BC = 15$ cm.

## Question 5 : Périmètre et aire

::: etape Périmètre
$\displaystyle 9 + 12 + 15 = 36$ cm.
:::

::: etape Aire
$\displaystyle \frac{AB \times AC}{2} = \frac{9 \times 12}{2} = 54$ cm².
:::

::: resultat
$36$ cm et $54$ cm².
:::

## Question 6 : La hauteur issue de A

::: methode
L'aire vaut aussi $\frac{BC \times h}{2}$, où $h$ est la hauteur relative à $[BC]$.
:::

::: etape $\frac{15 \times h}{2} = 54$, donc $15h = 108$ et $h = 7{,}2$.
:::

::: resultat
$\displaystyle 7{,}2$ cm
:::

**À retenir :** Dans un triangle rectangle, les deux côtés de l'angle droit sont des hauteurs l'un pour l'autre : l'aire se calcule directement.

Solution:
<!-- optitab:1 -->
1. $\displaystyle [BC]$
2. $\displaystyle BC^2 = AB^2 + AC^2$
3. $\displaystyle 225$
4. $\displaystyle 15$ cm
5. $36$ cm ; $54$ cm²
6. $\displaystyle 7{,}2$ cm

=== Découverte - Pythagore - 3. Calculer un côté de l'angle droit
Id: 3190
Difficulté: easy
Image: pythagore_4e_17_8.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle DEF$ est rectangle en $\displaystyle E$, avec $\displaystyle DF = 17$ cm et $\displaystyle DE = 8$ cm.

[IMAGE_1]

1. Quelle est l'hypoténuse ? Écrire l'égalité de Pythagore.
2. Exprimer $\displaystyle EF^2$ en fonction de $\displaystyle DF^2$ et $\displaystyle DE^2$.
3. Calculer $\displaystyle EF^2$, puis $\displaystyle EF$.
4. Calculer le périmètre du triangle $\displaystyle DEF$.
5. Calculer l'aire du triangle $\displaystyle DEF$.
6. Calculer la hauteur relative à l'hypoténuse (au centième).

Étapes:
<!-- optitab:1 -->
## Question 1 : L'égalité

::: etape L'angle droit est en $\displaystyle E$
l'hypoténuse est $\displaystyle [DF]$.
:::

::: resultat
$$DF^2 = DE^2 + EF^2$$
:::

## Question 2 : Isoler EF²

::: methode
On cherche un côté de l'angle droit : on SOUSTRAIT.
:::

::: resultat
$$EF^2 = DF^2 - DE^2$$
:::

## Question 3 : Le calcul

::: etape $\displaystyle EF^2 = 17^2 - 8^2 = 289 - 64 = 225$
:::

::: resultat
$\displaystyle EF = 15$ cm
:::

**Erreur fréquente :** Additionner $289 + 64 = 353$ : on obtiendrait un côté plus long que l'hypoténuse, ce qui est impossible.

## Question 4 : Le périmètre

::: etape $\displaystyle 17 + 8 + 15$
:::

::: resultat
$\displaystyle 40$ cm
:::

## Question 5 : L'aire

::: etape $\displaystyle \frac{DE \times EF}{2} = \frac{8 \times 15}{2}$
:::

::: resultat
$\displaystyle 60$ cm²
:::

## Question 6 : La hauteur relative à [DF]

::: etape $\frac{17 \times h}{2} = 60$, donc $h = \frac{120}{17} \approx 7{,}06$.
:::

::: resultat
Environ $\displaystyle 7{,}06$ cm.
:::

**À retenir :** Pour un côté de l'angle droit, on soustrait : $\text{côté}^2 = \text{hypoténuse}^2 - \text{autre côté}^2$.

Solution:
<!-- optitab:1 -->
1. $\displaystyle DF^2 = DE^2 + EF^2$
2. $\displaystyle EF^2 = DF^2 - DE^2$
3. $\displaystyle 15$ cm
4. $\displaystyle 40$ cm
5. $\displaystyle 60$ cm²
6. $\displaystyle \approx 7{,}06$ cm

=== Découverte - Pythagore - 4. Une racine non entière
Id: 3191
Difficulté: easy
Image: pythagore_4e_5_7.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle GHK$ est rectangle en $\displaystyle G$, avec $\displaystyle GH = 7$ cm et $\displaystyle GK = 5$ cm.

[IMAGE_1]

1. Calculer $\displaystyle HK^2$.
2. Donner la valeur exacte de $\displaystyle HK$.
3. Entre quels entiers consécutifs $HK$ est-il compris ? Justifier sans calculatrice.
4. Donner une valeur approchée de $\displaystyle HK$ au dixième, puis au centième.
5. Calculer une valeur approchée du périmètre du triangle au dixième.
6. Dans un autre triangle rectangle, l'hypoténuse mesure $10$ cm et un côté de l'angle droit $6$ cm. Calculer le troisième côté.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le carré de l'hypoténuse

::: etape $\displaystyle HK^2 = GH^2 + GK^2 = 49 + 25$
:::

::: resultat
$$HK^2 = 74$$
:::

## Question 2 : La valeur exacte

::: etape $\displaystyle 74$ n'est pas un carré parfait
on garde la racine.
:::

::: resultat
$\displaystyle HK = \sqrt{74}$ cm
:::

## Question 3 : L'encadrement

::: etape $64 < 74 < 81$, c'est-à-dire $8^2 < 74 < 9^2$.
:::

::: resultat
$$8 < HK < 9$$
:::

## Question 4 : Les valeurs approchées

::: etape La calculatrice affiche $\displaystyle \sqrt{74} \approx 8{,}602$.
:::

::: resultat
$HK \approx 8{,}6$ cm (au dixième) et $\approx 8{,}60$ cm (au centième).
:::

## Question 5 : Le périmètre

::: etape $\displaystyle 7 + 5 + \sqrt{74} \approx 12 + 8{,}602 = 20{,}602$
:::

::: resultat
Environ $\displaystyle 20{,}6$ cm.
:::

**Erreur fréquente :** Arrondir $\sqrt{74}$ à $9$ avant d'additionner : on obtiendrait $21$ au lieu de $20{,}6$.

## Question 6 : Un autre triangle

::: etape $\displaystyle x^2 = 10^2 - 6^2 = 100 - 36 = 64$
:::

::: resultat
$\displaystyle x = 8$ cm
:::

**À retenir :** On garde la valeur exacte ($\sqrt{74}$) dans les calculs et on n'arrondit qu'à la fin.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 74$
2. $\displaystyle \sqrt{74}$ cm
3. $\displaystyle 8 < \sqrt{74} < 9$
4. $\approx 8{,}6$ ; $\approx 8{,}60$
5. $\displaystyle \approx 20{,}6$ cm
6. $\displaystyle 8$ cm

=== Découverte - Pythagore - 5. La réciproque
Id: 3192
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un triangle $\displaystyle ABC$ a pour côtés $\displaystyle AB = 20$ cm, $\displaystyle AC = 21$ cm et $\displaystyle BC = 29$ cm.

1. Quel est le plus long côté ?
2. Calculer le carré du plus long côté.
3. Calculer la somme des carrés des deux autres côtés.
4. Que peut-on en conclure ? Quel théorème utilise-t-on ?
5. En quel sommet se trouve l'angle droit ?
6. Le triangle de côtés $\displaystyle 7$ cm, $\displaystyle 24$ cm et $\displaystyle 25$ cm est-il rectangle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le plus long côté

::: etape $\displaystyle 29 > 21 > 20$.
:::

::: resultat
$[BC]$ ($29$ cm).
:::

## Question 2 : Son carré

::: etape $\displaystyle BC^2 = 29^2$
:::

::: resultat
$$841$$
:::

## Question 3 : La somme des deux autres carrés

::: etape $\displaystyle AB^2 + AC^2 = 400 + 441$
:::

::: resultat
$$841$$
:::

## Question 4 : La conclusion

::: methode
On compare les deux résultats calculés SÉPARÉMENT.
:::

::: etape $\displaystyle BC^2 = AB^2 + AC^2$
:::

::: resultat
D'après la réciproque du théorème de Pythagore, le triangle $ABC$ est rectangle.
:::

**Rédaction :** Dans le triangle $ABC$, $[BC]$ est le plus long côté ; $BC^2 = 841$ et $AB^2 + AC^2 = 841$. Comme $BC^2 = AB^2 + AC^2$, d'après la réciproque du théorème de Pythagore, $ABC$ est rectangle en $A$.

## Question 5 : L'angle droit

::: etape L'angle droit est opposé au plus long côté $[BC]$.
:::

::: resultat
En $\displaystyle A$.
:::

**Erreur fréquente :** Placer l'angle droit en $B$ ou en $C$ : il est TOUJOURS opposé à l'hypoténuse.

## Question 6 : Le triangle 7, 24, 25

::: etape $25^2 = 625$ et $7^2 + 24^2 = 49 + 576 = 625$.
:::

::: resultat
Oui, il est rectangle (angle droit opposé au côté de $25$ cm).
:::

**À retenir :** On n'écrit jamais l'égalité $BC^2 = AB^2 + AC^2$ avant de l'avoir vérifiée : on calcule chaque membre séparément.

Solution:
<!-- optitab:1 -->
1. $\displaystyle [BC]$
2. $\displaystyle 841$
3. $\displaystyle 841$
4. Rectangle (réciproque)
5. En $\displaystyle A$
6. Oui

=== Découverte - Pythagore - 6. La contraposée
Id: 3193
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On veut savoir si certains triangles sont rectangles.

1. Un triangle a pour côtés $6$ cm, $7$ cm et $9$ cm. Calculer le carré du plus long côté et la somme des carrés des deux autres.
2. Ce triangle est-il rectangle ? Quel théorème utilise-t-on ?
3. Sur une figure à main levée, ce triangle « a l'air » rectangle. Pourquoi ne peut-on pas s'y fier ?
4. Le triangle de côtés $\displaystyle 8$ cm, $\displaystyle 15$ cm et $\displaystyle 17$ cm est-il rectangle ?
5. Le triangle de côtés $\displaystyle 1{,}5$ m, $\displaystyle 2$ m et $\displaystyle 2{,}5$ m est-il rectangle ?
6. Le triangle de côtés $\displaystyle 4$ cm, $\displaystyle 5$ cm et $\displaystyle 6$ cm est-il rectangle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les calculs

::: etape Plus long côté
$9$ ; $9^2 = 81$.
:::

::: etape $\displaystyle 6^2 + 7^2 = 36 + 49 = 85$.
:::

::: resultat
$81$ et $85$.
:::

## Question 2 : La conclusion

::: etape $\displaystyle 81 \neq 85$
:::

::: resultat
Le triangle n'est pas rectangle, d'après la contraposée du théorème de Pythagore.
:::

## Question 3 : Ne pas se fier au dessin

::: etape Seul le calcul permet de conclure.
:::

::: resultat
Un dessin n'est pas une preuve : $81$ et $85$ sont proches, l'angle est proche de $90°$ mais pas droit.
:::

## Question 4 : 8, 15, 17

::: etape $17^2 = 289$ et $8^2 + 15^2 = 64 + 225 = 289$.
:::

::: resultat
Oui, rectangle.
:::

## Question 5 : 1,5 ; 2 ; 2,5

::: etape $2{,}5^2 = 6{,}25$ et $1{,}5^2 + 2^2 = 2{,}25 + 4 = 6{,}25$.
:::

::: resultat
Oui, rectangle.
:::

## Question 6 : 4, 5, 6

::: etape $6^2 = 36$ et $4^2 + 5^2 = 41$.
:::

::: resultat
Non, il n'est pas rectangle.
:::

**À retenir :** Égalité → rectangle (réciproque) ; pas d'égalité → non rectangle (contraposée).

**Erreur fréquente :** Écrire « $36 = 41$ donc… » : on ne peut pas écrire d'égalité fausse ; on écrit $36 \neq 41$.

Solution:
<!-- optitab:1 -->
1. $81$ ; $85$
2. Non (contraposée)
3. Le dessin ne prouve rien
4. Oui
5. Oui
6. Non

=== Découverte - Pythagore - 7. Les triplets pythagoriciens
Id: 3194
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un triplet pythagoricien est un triplet d'entiers $(a ; b ; c)$ tel que $a^2 + b^2 = c^2$ : ce sont les côtés d'un triangle rectangle.

1. Vérifier que $\displaystyle (3 ; 4 ; 5)$ est un triplet pythagoricien.
2. On multiplie chaque nombre par $\displaystyle 2$. Le triplet $\displaystyle (6 ; 8 ; 10)$ est-il pythagoricien ?
3. Et le triplet $\displaystyle (30 ; 40 ; 50)$ ?
4. Vérifier que $\displaystyle (5 ; 12 ; 13)$ est un triplet pythagoricien.
5. Trouver $\displaystyle c$ tel que $\displaystyle (9 ; 40 ; c)$ soit un triplet pythagoricien.
6. Trouver $\displaystyle b$ tel que $\displaystyle (11 ; b ; 61)$ soit un triplet pythagoricien.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triplet (3 ; 4 ; 5)

::: etape $\displaystyle 3^2 + 4^2 = 9 + 16 = 25 = 5^2$
:::

::: resultat
Oui.
:::

## Question 2 : Le triplet (6 ; 8 ; 10)

::: etape $\displaystyle 36 + 64 = 100 = 10^2$
:::

::: resultat
Oui.
:::

## Question 3 : Le triplet (30 ; 40 ; 50)

::: etape $\displaystyle 900 + 1\,600 = 2\,500 = 50^2$
:::

::: resultat
Oui : multiplier un triplet par un même nombre donne encore un triplet.
:::

**À retenir :** Un triangle agrandi reste rectangle : multiplier les trois côtés par $k$ conserve l'angle droit.

## Question 4 : Le triplet (5 ; 12 ; 13)

::: etape $\displaystyle 25 + 144 = 169 = 13^2$
:::

::: resultat
Oui.
:::

## Question 5 : Trouver c

::: etape $\displaystyle c^2 = 81 + 1\,600 = 1\,681$
:::

::: resultat
$$c = \sqrt{1\,681} = 41$$
:::

## Question 6 : Trouver b

::: methode
$61$ est le plus grand nombre : c'est l'hypoténuse, on soustrait.
:::

::: etape $\displaystyle b^2 = 61^2 - 11^2 = 3\,721 - 121 = 3\,600$
:::

::: resultat
$$b = 60$$
:::

**Erreur fréquente :** Additionner $3\,721 + 121$ : $61$ est l'hypoténuse, $b$ est un côté de l'angle droit.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 9 + 16 = 25$
2. $\displaystyle 36 + 64 = 100$
3. Oui
4. $\displaystyle 25 + 144 = 169$
5. $\displaystyle 41$
6. $\displaystyle 60$

=== Entraînement - Pythagore - 1. L'échelle contre le mur
Id: 3195
Difficulté: medium
Image: pythagore_4e_echelle.png

Énoncé:
<!-- optitab:1 -->
Une échelle de $4{,}5$ m est appuyée contre un mur vertical. Son pied est à $1{,}2$ m du mur, sur un sol horizontal.

[IMAGE_1]

1. Pourquoi le triangle $\displaystyle ABC$ est-il rectangle ? En quel sommet ?
2. Calculer la hauteur $\displaystyle AC$ atteinte par l'échelle (au centimètre).
3. Une fenêtre a son rebord à $\displaystyle 4$ m de haut. L'échelle l'atteint-elle ?
4. On écarte le pied de l'échelle à $2$ m du mur. Quelle hauteur atteint-elle alors (au centimètre) ?
5. À quelle distance du mur faut-il placer le pied pour que l'échelle atteigne exactement $4{,}2$ m (au centimètre) ?
6. L'échelle peut-elle atteindre une hauteur de $\displaystyle 4{,}5$ m ? Expliquer.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'angle droit

::: etape Le mur est vertical et le sol horizontal
ils sont perpendiculaires.
:::

::: resultat
$ABC$ est rectangle en $A$ ; l'hypoténuse est l'échelle $[BC]$.
:::

## Question 2 : La hauteur atteinte

::: etape $\displaystyle AC^2 = BC^2 - AB^2 = 4{,}5^2 - 1{,}2^2 = 20{,}25 - 1{,}44 = 18{,}81$
:::

::: etape $\displaystyle AC = \sqrt{18{,}81} \approx 4{,}337$
:::

::: resultat
Environ $\displaystyle 4{,}34$ m.
:::

## Question 3 : La fenêtre

::: etape $\displaystyle 4{,}34 > 4$
:::

::: resultat
Oui, l'échelle dépasse le rebord de la fenêtre.
:::

## Question 4 : Pied à 2 m

::: etape $\displaystyle AC^2 = 20{,}25 - 4 = 16{,}25$
:::

::: etape $\displaystyle AC = \sqrt{16{,}25} \approx 4{,}031$
:::

::: resultat
Environ $4{,}03$ m : plus on écarte le pied, moins l'échelle monte haut.
:::

## Question 5 : Atteindre 4,2 m

::: etape $\displaystyle AB^2 = 4{,}5^2 - 4{,}2^2 = 20{,}25 - 17{,}64 = 2{,}61$
:::

::: etape $\displaystyle AB = \sqrt{2{,}61} \approx 1{,}616$
:::

::: resultat
Environ $\displaystyle 1{,}62$ m du mur.
:::

## Question 6 : Atteindre 4,5 m ?

::: etape La hauteur est un côté de l'angle droit
elle est plus courte que l'hypoténuse ($4{,}5$ m).
:::

::: resultat
Non, sauf si l'échelle est parfaitement verticale (pied collé au mur), ce qui est dangereux.
:::

**À retenir :** Dans un triangle rectangle, chaque côté de l'angle droit est plus court que l'hypoténuse.

Solution:
<!-- optitab:1 -->
1. Rectangle en $\displaystyle A$
2. $\displaystyle \approx 4{,}34$ m
3. Oui
4. $\displaystyle \approx 4{,}03$ m
5. $\displaystyle \approx 1{,}62$ m
6. Non

=== Entraînement - Pythagore - 2. Couper par la diagonale
Id: 3196
Difficulté: medium
Image: pythagore_4e_terrain_hand.png

Énoncé:
<!-- optitab:1 -->
Un terrain de handball est un rectangle de $40$ m sur $20$ m. Un joueur va du coin $A$ au coin $C$.

[IMAGE_1]

1. Quelle distance parcourt-il en longeant les côtés $\displaystyle [AB]$ et $\displaystyle [BC]$ ?
2. Pourquoi le triangle $\displaystyle ABC$ est-il rectangle ?
3. Calculer la longueur de la diagonale $\displaystyle [AC]$ (valeur exacte, puis au centième).
4. Combien de mètres économise-t-il en coupant par la diagonale ? Quel pourcentage du trajet par les côtés (au dixième) ?
5. Il court à $\displaystyle 5$ m/s. Combien de secondes gagne-t-il (au centième) ?
6. Sur un terrain carré de $20$ m de côté, quel pourcentage de trajet gagne-t-on par la diagonale (au dixième) ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Par les côtés

::: etape $\displaystyle 40 + 20$
:::

::: resultat
$\displaystyle 60$ m
:::

## Question 2 : L'angle droit

::: etape Le coin $B$ du terrain est un angle droit.
:::

::: resultat
Les côtés d'un rectangle sont perpendiculaires : $ABC$ est rectangle en $B$.
:::

## Question 3 : La diagonale

::: etape $\displaystyle AC^2 = 40^2 + 20^2 = 1\,600 + 400 = 2\,000$
:::

::: etape $\displaystyle AC = \sqrt{2\,000} \approx 44{,}72$
:::

::: resultat
$\displaystyle \sqrt{2\,000} \approx 44{,}72$ m.
:::

## Question 4 : L'économie

::: etape $\displaystyle 60 - 44{,}72 = 15{,}28$ m.
:::

::: etape $\displaystyle \frac{15{,}28}{60} \approx 0{,}255$
:::

::: resultat
$15{,}28$ m, soit environ $25{,}5$ %.
:::

## Question 5 : Le gain de temps

::: etape $\displaystyle 15{,}28 : 5 \approx 3{,}06$
:::

::: resultat
Environ $\displaystyle 3{,}06$ s.
:::

## Question 6 : Un terrain carré

::: etape Diagonale
$\sqrt{20^2 + 20^2} = \sqrt{800} \approx 28{,}28$ m ; par les côtés : $40$ m.
:::

::: etape $\displaystyle \frac{40 - 28{,}28}{40} \approx 0{,}293$
:::

::: resultat
Environ $\displaystyle 29{,}3$ %.
:::

**À retenir :** Le « raccourci » par la diagonale d'un rectangle se calcule toujours avec Pythagore.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 60$ m
2. Coin du rectangle
3. $\displaystyle \approx 44{,}72$ m
4. $15{,}28$ m ; $\approx 25{,}5$ %
5. $\displaystyle \approx 3{,}06$ s

Énoncé:

Voici six raisonnements faux. Pour chacun, expliquer l'erreur puis corriger.

2. « $\displaystyle BC^2 = 6^2 + 8^2 = 14^2$. »

<!-- optitab:1 -->

::: etape Erreur
on additionne les CARRÉS, pas les longueurs.
:::

::: etape $\displaystyle BC^2 = 9 + 16 = 25$
:::

::: resultat
$$BC = 5$$
:::

## Question 2 : Un carré mal calculé

::: etape Erreur
$6^2 + 8^2 = 36 + 64 = 100$, et $100 \neq 14^2 = 196$.
:::

::: resultat
$BC^2 = 100$, donc $BC = 10$.

::: etape Erreur
$[BC]$ est un côté de l'angle droit ; on soustrait.
:::

::: resultat
$BC^2 = 100 - 36 = 64$, donc $BC = 8$.

## Question 4 : Le mauvais sommet

l'angle droit est opposé au plus long côté $[BC]$.

::: resultat
Le triangle est rectangle en $\displaystyle A$.

::: etape Erreur
$\displaystyle 36 \neq 41$.
:::

::: resultat
Le triangle n'est pas rectangle (contraposée).

## Question 6 : Un angle droit non justifié

::: etape Erreur
le théorème de Pythagore ne s'applique que dans un triangle rectangle.
:::

::: resultat
Sans angle droit connu, on ne peut pas calculer $BC$ ainsi.
:::

=== Problème - Pythagore - 5. La spirale de Théodore
Id: 3206
Difficulté: hard
Image: pythagore_4e_spirale.png

Énoncé:
<!-- optitab:1 -->
On construit une spirale de triangles rectangles. On part de $OA_1 = 1$ cm. Chaque triangle $OA_nA_{n+1}$ est rectangle en $A_n$, avec $A_nA_{n+1} = 1$ cm.

[IMAGE_1]

1. Calculer $\displaystyle OA_2$ (valeur exacte puis au centième).
2. Calculer $\displaystyle OA_3$ et $\displaystyle OA_4$.
3. Exprimer $\displaystyle OA_{n+1}^2$ en fonction de $\displaystyle OA_n^2$.
4. En déduire $\displaystyle OA_n^2$, puis $\displaystyle OA_n$, en fonction de $\displaystyle n$.
5. Pour quelles valeurs de $n$ inférieures à $20$ la longueur $OA_n$ est-elle un nombre entier ?
6. Combien de triangles faut-il construire pour obtenir $\displaystyle OA_n = 4$ cm ?

Étapes:
<!-- optitab:1 -->
## Question 1 : OA2

::: etape $\displaystyle OA_2^2 = OA_1^2 + A_1A_2^2 = 1 + 1 = 2$
:::

::: resultat
$\displaystyle OA_2 = \sqrt{2} \approx 1{,}41$ cm
:::

## Question 2 : OA3 et OA4

::: etape $OA_3^2 = 2 + 1 = 3$, donc $OA_3 = \sqrt{3} \approx 1{,}73$.
:::

::: etape $OA_4^2 = 3 + 1 = 4$, donc $OA_4 = 2$.
:::

::: resultat
$\sqrt{3}$ cm et $2$ cm.
:::

## Question 3 : La relation

::: methode
Le triangle $OA_nA_{n+1}$ est rectangle en $A_n$, d'hypoténuse $[OA_{n+1}]$.
:::

::: etape $\displaystyle OA_{n+1}^2 = OA_n^2 + A_nA_{n+1}^2$
:::

::: resultat
$$OA_{n+1}^2 = OA_n^2 + 1$$
:::

## Question 4 : La formule générale

::: etape Le carré augmente de $1$ à chaque triangle et vaut $1$ au départ.
:::

::: resultat
$OA_n^2 = n$, donc $OA_n = \sqrt{n}$.
:::

## Question 5 : Les longueurs entières

::: etape $\sqrt{n}$ est entier si $n$ est un carré parfait
$1$, $4$, $9$, $16$.
:::

::: resultat
$n = 1$, $4$, $9$ ou $16$ (longueurs $1$, $2$, $3$, $4$ cm).
:::

## Question 6 : Atteindre 4 cm

::: etape $OA_{16} = \sqrt{16} = 4$ ; on part de $A_1$ et chaque triangle ajoute un point.
:::

::: resultat
Il faut $15$ triangles (de $OA_1A_2$ à $OA_{15}A_{16}$).
:::

**Erreur fréquente :** Répondre $16$ : le premier segment $[OA_1]$ existe déjà, il faut $16 - 1 = 15$ triangles.

**À retenir :** La spirale de Théodore permet de construire à la règle et à l'équerre les longueurs $\sqrt{2}$, $\sqrt{3}$, $\sqrt{5}$…

Solution:
<!-- optitab:1 -->
1. $\displaystyle \sqrt{2} \approx 1{,}41$
2. $\sqrt{3}$ ; $2$
3. $\displaystyle OA_{n+1}^2 = OA_n^2 + 1$
4. $\displaystyle OA_n = \sqrt{n}$
5. $1$ ; $4$ ; $9$ ; $16$
6. $\displaystyle 15$ triangles

=== Problème - Pythagore - 6. La navigation du voilier
Id: 3207
Difficulté: hard
Image: pythagore_4e_voilier.png,pythagore_4e_voilier_solution.png

Énoncé:
<!-- optitab:1 -->
Un voilier quitte le port $P$. Il navigue $15$ km vers le nord jusqu'au point $N$, puis $8$ km vers l'est jusqu'au point $E$, et enfin $9$ km vers le sud jusqu'au point $F$.

[IMAGE_1]

1. Quelle distance totale le voilier a-t-il parcourue ?
2. Pourquoi le triangle $\displaystyle PNE$ est-il rectangle en $\displaystyle N$ ?
3. Calculer la distance $\displaystyle PE$ entre le port et le point $\displaystyle E$.
4. Montrer que le point $\displaystyle F$ est situé $\displaystyle 8$ km à l'est et $\displaystyle 6$ km au nord du port.
5. Calculer la distance $\displaystyle PF$ à laquelle le voilier se trouve du port à la fin.
6. Le voilier avance à $8$ km/h. Combien de temps a duré la navigation ? Combien de temps aurait-il mis en allant directement de $P$ à $F$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La distance parcourue

::: etape $\displaystyle 15 + 8 + 9$
:::

::: resultat
$\displaystyle 32$ km
:::

## Question 2 : L'angle droit en N

::: etape Le trajet $[PN]$ va vers le nord et $[NE]$ vers l'est.
:::

::: resultat
Les directions nord et est sont perpendiculaires.
:::

## Question 3 : La distance PE

::: etape $\displaystyle PE^2 = 15^2 + 8^2 = 225 + 64 = 289$
:::

::: resultat
$\displaystyle PE = 17$ km
:::

## Question 4 : La position de F

::: etape Vers l'est
seulement les $8$ km de $N$ à $E$.
:::

::: etape Vers le nord
$15$ km, puis retour de $9$ km vers le sud : $15 - 9 = 6$ km.
:::

::: resultat
$F$ est $8$ km à l'est et $6$ km au nord de $P$.
:::

## Question 5 : La distance PF

::: etape On forme un triangle rectangle de côtés $8$ km et $6$ km
$\displaystyle PF^2 = 64 + 36 = 100$.
:::

::: resultat
$\displaystyle PF = 10$ km
:::

[IMAGE_2]

**Erreur fréquente :** Calculer $\sqrt{17^2 - 9^2}$ : le triangle $PEF$ n'est pas rectangle en $F$.

## Question 6 : Les durées

::: etape $\displaystyle 32 : 8 = 4$ h.
:::

::: etape Direct
$10 : 8 = 1{,}25$ h $= 1$ h $15$ min.
:::

::: resultat
$4$ h de navigation ; $1$ h $15$ min en ligne droite.
:::

**À retenir :** Pour une distance « à vol d'oiseau », on additionne séparément les déplacements est-ouest et nord-sud, puis on applique Pythagore.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 32$ km
2. Nord ⊥ est
3. $\displaystyle 17$ km
4. $8$ km est, $6$ km nord
5. $\displaystyle 10$ km
6. $4$ h ; $1$ h $15$ min

=== Problème - Pythagore - 7. Le format d'un écran
Id: 3208
Difficulté: hard
Image: pythagore_4e_ecran.png

Énoncé:
<!-- optitab:1 -->
La taille d'un écran se mesure par sa diagonale, en pouces ($1$ pouce $= 2{,}54$ cm). Un téléviseur de $55$ pouces a un format $16 : 9$ : sa largeur vaut $16k$ et sa hauteur $9k$ (en cm).

[IMAGE_1]

1. Convertir la diagonale en centimètres.
2. Montrer que la diagonale $\displaystyle d$ vérifie $\displaystyle d^2 = 337k^2$.
3. En déduire $k$ (au millième), puis la largeur et la hauteur de l'écran (au dixième).
4. Calculer l'aire de l'écran en m² (au centième).
5. Un ancien téléviseur de même diagonale avait un format $4 : 3$ (largeur $4k$, hauteur $3k$, diagonale $5k$). Calculer ses dimensions et son aire (au centième de m²).
6. Quel écran a la plus grande surface ? Conclure.

Étapes:
<!-- optitab:1 -->
## Question 1 : La diagonale en cm

::: etape $\displaystyle 55 \times 2{,}54$
:::

::: resultat
$\displaystyle 139{,}7$ cm
:::

## Question 2 : La relation

::: etape D'après Pythagore
$\displaystyle d^2 = (16k)^2 + (9k)^2 = 256k^2 + 81k^2$.
:::

::: resultat
$$d^2 = 337k^2$$
:::

## Question 3 : Les dimensions

::: etape
$k^2 = \frac{139{,}7^2}{337} = \frac{19\,516{,}09}{337} \approx 57{,}911$, donc $k \approx 7{,}610$.
:::

::: etape Largeur
$16 \times 7{,}610 \approx 121{,}8$ cm ; hauteur : $9 \times 7{,}610 \approx 68{,}5$ cm.
:::

::: resultat
Environ $121{,}8$ cm sur $68{,}5$ cm.
:::

**Vérification :** $\displaystyle \sqrt{121{,}8^2 + 68{,}5^2} \approx 139{,}7$

## Question 4 : L'aire du 16 : 9

::: etape $121{,}8 \times 68{,}5 \approx 8\,343$ cm² $\approx 0{,}83$ m².
:::

::: resultat
Environ $\displaystyle 0{,}83$ m².
:::

## Question 5 : L'écran 4 : 3

::: etape $5k = 139{,}7$ donne $k = 27{,}94$
largeur $4k = 111{,}76$ cm, hauteur $3k = 83{,}82$ cm.
:::

::: etape Aire
$111{,}76 \times 83{,}82 \approx 9\,368$ cm² $\approx 0{,}94$ m².
:::

::: resultat
$111{,}76$ cm sur $83{,}82$ cm ; environ $0{,}94$ m².
:::

## Question 6 : La comparaison

::: etape $\displaystyle 0{,}94 > 0{,}83$
:::

::: resultat
À diagonale égale, l'écran $4 : 3$ a une surface plus grande : la diagonale seule ne suffit pas à comparer deux écrans.
:::

**À retenir :** Le triplet $(3 ; 4 ; 5)$ rend le format $4 : 3$ très simple : la diagonale vaut exactement $5k$.

**Erreur fréquente :** Croire que deux écrans de même diagonale ont la même surface.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 139{,}7$ cm
2. $\displaystyle d^2 = 337k^2$
3. $k \approx 7{,}610$ ; $121{,}8$ × $68{,}5$ cm
4. $\displaystyle \approx 0{,}83$ m²
5. $111{,}76 \times 83{,}82$ ; $\approx 0{,}94$ m²
6. Le $4 : 3$ ($0{,}94$ m² contre $0{,}83$ m²)
