<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : radian, cosinus et sinus, valeurs remarquables, angles associés. Programme de Première.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Cercle et valeurs remarquables</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$M(t)\,(\cos t\,;\sin t)$ et $\cos^2 t + \sin^2 t = 1$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $\pi$ rad $= 180°$ ; un tour $= 2\pi$ ; $t$ et $t + 2k\pi$ donnent le même point.</p>
<p style="margin:6px 0 0 0;">2️⃣ $-1 \le \cos t \le 1$ et $-1 \le \sin t \le 1$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\cos$ paire, $\sin$ impaire, période $2\pi$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Angles associés</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\cos(-x) = \cos x$ ; $\sin(-x) = -\sin x$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\cos(\pi - x) = -\cos x$ ; $\sin(\pi - x) = \sin x$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\cos(\pi + x) = -\cos x$ ; $\sin(\pi + x) = -\sin x$ ; $\cos\left(\frac{\pi}{2} - x\right) = \sin x$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Calculatrice en degrés au lieu de radians.</p>
<p style="margin:6px 0 0 0;">2️⃣ Inverser les valeurs : $\cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$ mais $\cos\frac{\pi}{3} = \frac{1}{2}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier une solution : $\cos x = \frac{1}{2}$ a deux solutions par tour.</p>
<p style="margin:6px 0 0 0;">4️⃣ Écrire $\cos(a + b) = \cos a + \cos b$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je place toujours le point sur le cercle trigonométrique avant de calculer : le signe de $\cos$ et de $\sin$ se lit sur la figure.</p>
</div>
