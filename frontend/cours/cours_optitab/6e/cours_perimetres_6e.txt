    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce que le périmètre ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Périmètre d'une figure</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>périmètre</strong> d'une figure géométrique est la <strong>longueur totale de son contour</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il s'exprime dans une unité de longueur : <strong>cm</strong>, <strong>m</strong>, <strong>km</strong>, etc.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples concrets :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le périmètre d'un <strong>terrain de foot</strong> : on fait le tour complet du terrain</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le périmètre d'une <strong>salle de classe</strong> : on mesure la longueur totale des murs</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le périmètre d'un <strong>jardin rectangulaire</strong> : on additionne les longueurs de tous les côtés</li>
                <li style="margin:0; text-align:left;">Le périmètre d'une <strong>clôture</strong> : c'est la longueur totale de la clôture</li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment calculer le périmètre ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer le périmètre d'une figure, on <strong>additionne les longueurs de tous ses côtés</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Périmètre = somme des longueurs des côtés</strong></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Figure quelconque</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit une figure avec les côtés suivants : <strong>5 cm</strong>, <strong>3 cm</strong>, <strong>4 cm</strong> et <strong>6 cm</strong>.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_1]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On additionne tous les côtés : <strong>5 + 3 + 4 + 6 = 18 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>18 cm</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour visualiser le périmètre, imagine que tu fais le tour de la figure en marchant le long de ses côtés. Le périmètre, c'est la distance totale que tu parcours !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Périmètre du carré</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et formule</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le carré</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>carré</strong> est un quadrilatère qui a <strong>4 côtés de même longueur</strong> et <strong>4 angles droits</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tous les côtés ont la même longueur : on appelle cette longueur <strong>c</strong> (côté).</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Formule du périmètre du carré</strong></p>
             <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:500px;">
                 <p style="margin:0; font-size:1.1em; font-weight:700; color:#2c3e50;"><strong>P = 4 × c</strong></p>
             </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où <strong>P</strong> est le périmètre et <strong>c</strong> est la longueur d'un côté.</p>
        </div>
        <div style="text-align:center; margin:10px 0;">[IMAGE_8]</div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Carré simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un carré a un côté de <strong>5 cm</strong>. Calculer son périmètre.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_2]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le côté <strong>c = 5 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Formule : <strong>P = 4 × c</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>P = 4 × 5 = 20 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>20 cm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 5 + 5 + 5 + 5 = 20 cm ✓</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour le carré, il suffit de multiplier la longueur d'un côté par 4. C'est très simple car tous les côtés sont identiques !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Périmètre du rectangle</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et formule</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le rectangle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>rectangle</strong> est un quadrilatère qui a <strong>4 angles droits</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il a deux côtés plus longs (les <strong>longueurs</strong>, notées <strong>L</strong>) et deux côtés plus courts (les <strong>largeurs</strong>, notées <strong>l</strong>).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les côtés opposés ont la même longueur.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Formule du périmètre du rectangle</strong></p>
             <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:500px;">
                 <p style="margin:0; font-size:1.1em; font-weight:700; color:#2c3e50;"><strong>P = 2 × (L + l)</strong></p>
             </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où <strong>P</strong> est le périmètre, <strong>L</strong> est la longueur et <strong>l</strong> est la largeur.</p>
        </div>
        <div style="text-align:center; margin:10px 0;">[IMAGE_9]</div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il ne faut pas confondre la <strong>longueur</strong> (le côté le plus long) et la <strong>largeur</strong> (le côté le plus court).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans la formule <strong>P = 2 × (L + l)</strong> : on additionne d'abord L + l, puis on multiplie par 2.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Rectangle simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle a une longueur de <strong>8 cm</strong> et une largeur de <strong>3 cm</strong>. Calculer son périmètre.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_3]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">La longueur <strong>L = 8 cm</strong> et la largeur <strong>l = 3 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Formule : <strong>P = 2 × (L + l)</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>P = 2 × (8 + 3) = 2 × 11 = 22 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>22 cm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 8 + 3 + 8 + 3 = 22 cm ✓</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Pourquoi cette formule ?</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle a 2 longueurs et 2 largeurs. On pourrait écrire : <strong>P = L + L + l + l = 2×L + 2×l</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En factorisant, on obtient : <strong>P = 2 × (L + l)</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette formule est plus rapide à utiliser !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Problèmes inverses : retrouver une dimension à partir du périmètre</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Utiliser les formules à l'envers</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Utiliser les formules dans les deux sens</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les formules de périmètre peuvent être utilisées <strong>dans les deux sens</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Dans un sens</strong> : on connaît les dimensions, on calcule le périmètre</li>
                <li style="margin:0; text-align:left;"><strong>Dans l'autre sens</strong> : on connaît le périmètre, on cherche une dimension manquante</li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Pour le carré : trouver le côté à partir du périmètre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on connaît le périmètre <strong>P</strong> d'un carré, on peut trouver la longueur d'un côté <strong>c</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On utilise la formule <strong>P = 4 × c</strong>, donc <strong>c = P ÷ 4</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Carré - trouver le côté</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un carré a un périmètre de <strong>24 cm</strong>. Quelle est la longueur d'un côté ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On connaît le périmètre <strong>P = 24 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Formule : <strong>P = 4 × c</strong>, donc <strong>c = P ÷ 4</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>c = 24 ÷ 4 = 6 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Un côté mesure <strong>6 cm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 4 × 6 = 24 cm ✓</p>
        </div>

        <!-- Exemple 2 (carré - autre exemple) supprimé -->

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Pour le rectangle : trouver une dimension à partir du périmètre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on connaît le périmètre <strong>P</strong> d'un rectangle et une des deux dimensions (longueur <strong>L</strong> ou largeur <strong>l</strong>), on peut trouver l'autre dimension.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On utilise la formule <strong>P = 2 × (L + l)</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Étape par étape :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On calcule <strong>L + l = P ÷ 2</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Si on cherche <strong>l</strong>, alors <strong>l = (P ÷ 2) - L</strong></li>
                <li style="margin:0; text-align:left;">Si on cherche <strong>L</strong>, alors <strong>L = (P ÷ 2) - l</strong></li>
            </ol>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il faut faire attention à bien suivre les étapes : d'abord diviser le périmètre par 2, puis soustraire la dimension connue.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Rectangle - trouver la largeur</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle a un périmètre de <strong>22 cm</strong> et une longueur de <strong>8 cm</strong>. Quelle est sa largeur ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On connaît le périmètre <strong>P = 22 cm</strong> et la longueur <strong>L = 8 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Formule : <strong>P = 2 × (L + l)</strong>, donc <strong>L + l = P ÷ 2</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>L + l = 22 ÷ 2 = 11 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc : <strong>l = 11 - L = 11 - 8 = 3 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> La largeur est de <strong>3 cm</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 2 × (8 + 3) = 2 × 11 = 22 cm ✓</p>
        </div>

            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Identifier</strong> ce qui est connu (périmètre, dimension) et ce qui est inconnu</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Écrire</strong> la formule du périmètre</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Transformer</strong> la formule pour isoler la dimension inconnue</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Calculer</strong> étape par étape</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> le résultat en recalculant le périmètre</li>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Périmètre de figures simples</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Triangle et autres polygones</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode générale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer le périmètre d'une figure qui n'est ni un carré ni un rectangle, on additionne les longueurs de tous ses côtés.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Triangle</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un triangle a trois côtés mesurant <strong>5 cm</strong>, <strong>6 cm</strong> et <strong>7 cm</strong>. Calculer son périmètre.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_5]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On additionne les trois côtés : <strong>5 + 6 + 7 = 18 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>18 cm</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Pentagone (5 côtés)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un pentagone a des côtés mesurant <strong>4 cm</strong>, <strong>5 cm</strong>, <strong>6 cm</strong>, <strong>4 cm</strong> et <strong>7 cm</strong>. Calculer son périmètre.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_6]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On additionne tous les côtés : <strong>4 + 5 + 6 + 4 + 7 = 26 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>26 cm</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour ne rien oublier, dessine la figure et marque la longueur de chaque côté. Puis additionne-les tous, un par un.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Périmètre de figures composées</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Figures composées de plusieurs formes</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Figure composée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>figure composée</strong> est formée de plusieurs figures simples assemblées (par exemple : deux rectangles collés).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer son périmètre, on doit identifier <strong>seulement les côtés du contour extérieur</strong> de la figure.</p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention importante :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Lors du calcul du périmètre d'une figure composée, on ne compte <strong>pas</strong> les côtés qui sont à l'intérieur de la figure (côtés communs entre les figures simples).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On compte uniquement les côtés qui forment le <strong>contour extérieur</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Deux rectangles accolés (un petit à gauche d’un grand)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a un grand rectangle de <strong>8 cm</strong> de longueur et <strong>5 cm</strong> de hauteur. On lui accole à gauche, en bas, un petit rectangle de <strong>3 cm</strong> de longueur et <strong>3 cm</strong> de hauteur (voir figure).</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_4]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On suit le <strong>contour extérieur</strong> en partant du coin inférieur gauche. Soit <strong>h</strong> la hauteur du petit rectangle (ici, h est la hauteur du petit rectangle, non indiquée sur la figure).</li>
                <li style="margin:0 0 12px 0; text-align:left;">Bas total : <strong>3 + 8 = 11 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté droit du grand : <strong>5 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Dessus du grand : <strong>8 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Descente sur la "marche" intérieure : <strong>5 − h</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Dessus du petit : <strong>3 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté gauche du petit : <strong>h</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>P = (11) + 5 + 8 + (5 − h) + 3 + h = 32 cm</strong> (le <strong>h</strong> s'annule, le résultat ne dépend donc pas de la hauteur du petit rectangle).</li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>32 cm</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Rectangle avec un carré accolé</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle (L = <strong>8 cm</strong>, l = <strong>5 cm</strong>) a un carré (côté = <strong>3 cm</strong>) accolé sur un côté de <strong>5 cm</strong>.</p>
            <div style="text-align:center; margin:15px 0;">
                [IMAGE_7]
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On trace le <strong>contour extérieur</strong> :</li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté du bas : <strong>8 + 3 = 11 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté droit : <strong>5 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté du haut (partie droite) : <strong>8 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté du haut (partie gauche) : <strong>3 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Côté gauche : <strong>3 cm + 2 cm</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Calcul : <strong>P = 11 + 5 + 8 + 3 + (3 + 2) = 32 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le périmètre est de <strong>32 cm</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pour les figures composées :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Dessiner</strong> ou visualiser la figure</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Identifier</strong> le contour extérieur (trace le tour de la figure avec ton doigt)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas compter</strong> les côtés à l'intérieur (où les figures sont collées)</li>
                <li style="margin:0; text-align:left;"><strong>Additionner</strong> toutes les longueurs du contour extérieur</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Applications pratiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Situations de la vie quotidienne</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Périmètre d'un terrain</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un terrain rectangulaire a une longueur de <strong>25 m</strong> et une largeur de <strong>15 m</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quelle longueur de clôture faut-il pour entourer ce terrain ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On calcule le périmètre : <strong>P = 2 × (25 + 15) = 2 × 40 = 80 m</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Il faut <strong>80 m</strong> de clôture pour entourer le terrain.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Périmètre d'un jardin carré</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un jardin carré a un côté de <strong>12 m</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quelle est la longueur totale du contour du jardin ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On calcule le périmètre : <strong>P = 4 × 12 = 48 m</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le contour du jardin mesure <strong>48 m</strong>.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Bande décorative autour d'une salle</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut mettre une bande décorative autour d'une salle rectangulaire de <strong>10 m</strong> de longueur et <strong>6 m</strong> de largeur.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quelle longueur de bande faut-il acheter ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On calcule le périmètre : <strong>P = 2 × (10 + 6) = 2 × 16 = 32 m</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Il faut acheter <strong>32 m</strong> de bande décorative.</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII bis. Pour aller plus loin</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Enrichissement (optionnel)</h3>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Longueur d'un cercle (périmètre du cercle)</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>périmètre d'un cercle</strong> est aussi appelé la <strong>circonférence</strong> ou la <strong>longueur du cercle</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer le périmètre d'un cercle, on utilise la formule :</p>
             <div style="background:#f3e8ff; border:3px solid #9333ea; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:500px;">
                 <p style="margin:0; font-size:1.1em; font-weight:700; color:#2c3e50;"><strong>P = 2 × π × r</strong></p>
             </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où <strong>P</strong> est le périmètre, <strong>r</strong> est le rayon du cercle, et <strong>π</strong> (pi) est un nombre spécial approximativement égal à <strong>3,14</strong>.</p>
        </div>
        <div style="text-align:center; margin:10px 0;">[IMAGE_10]</div>
        <div style="padding:15px; margin:12px 0;">
            <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
                <strong>Exemple :</strong>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Un cercle a un rayon de <strong>4 cm</strong>. Quel est son périmètre ?</p>
                <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong> <strong>P = 2 × 3,14 × 4 = 25,12 cm</strong></p>
            </div>
            <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
                <strong>💡 Note :</strong>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Cette formule sera étudiée plus en détail au collège. Pour l'instant, il suffit de savoir qu'elle existe et qu'elle permet de calculer la longueur d'un cercle.</p>
            </div>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Même périmètre, formes différentes</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Des figures géométriques différentes peuvent avoir le <strong>même périmètre</strong> tout en ayant des <strong>formes et des surfaces différentes</strong>.</p>
        </div>
        <div style="padding:15px; margin:12px 0;">
            <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
                <strong>Exemple 1 : Carré et rectangle avec même périmètre</strong>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Un carré de côté <strong>5 cm</strong> a un périmètre de <strong>4 × 5 = 20 cm</strong>.</p>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle de longueur <strong>6 cm</strong> et de largeur <strong>4 cm</strong> a aussi un périmètre de <strong>2 × (6 + 4) = 20 cm</strong>.</p>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Ces deux figures ont donc le <strong>même périmètre</strong> (20 cm), mais elles ont des <strong>formes différentes</strong> : une est un carré, l'autre est un rectangle.</p>
            </div>
            <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
                <strong>Exemple 2 : Différentes formes avec même périmètre</strong>
                <p style="margin:8px 0; text-align:left; font-size:1em;">On peut créer de nombreuses figures différentes avec le même périmètre de <strong>24 cm</strong> :</p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                    <li style="margin:0 0 12px 0; text-align:left;">Un carré de côté <strong>6 cm</strong> : P = 4 × 6 = 24 cm</li>
                    <li style="margin:0 0 12px 0; text-align:left;">Un rectangle de longueur <strong>10 cm</strong> et largeur <strong>2 cm</strong> : P = 2 × (10 + 2) = 24 cm</li>
                    <li style="margin:0 0 12px 0; text-align:left;">Un rectangle de longueur <strong>8 cm</strong> et largeur <strong>4 cm</strong> : P = 2 × (8 + 4) = 24 cm</li>
                    <li style="margin:0; text-align:left;">Et bien d'autres encore !</li>
                </ul>
            </div>
            <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
                <strong>💡 Concept important :</strong>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Le périmètre mesure la <strong>longueur du contour</strong> d'une figure, tandis que l'<strong>aire</strong> mesure la <strong>surface</strong> à l'intérieur de la figure.</p>
                <p style="margin:8px 0; text-align:left; font-size:1em;">On peut avoir :</p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                    <li style="margin:0 0 12px 0; text-align:left;">Le <strong>même périmètre</strong> mais des <strong>aires différentes</strong></li>
                    <li style="margin:0; text-align:left;">La <strong>même aire</strong> mais des <strong>périmètres différents</strong></li>
                </ul>
                <p style="margin:8px 0; text-align:left; font-size:1em;">Le périmètre et l'aire sont deux grandeurs <strong>indépendantes</strong> : l'un ne détermine pas automatiquement l'autre !</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Tableau récapitulatif</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résumé des formules</h3>

        <div style="margin:12px 0;">
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Figure</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Formule</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Exemple</th>
                    </tr>
                </thead>
                <tbody>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Carré</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>P = 4 × c</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Si c = 5 cm, alors P = 4 × 5 = 20 cm</td>
                    </tr>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Rectangle</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>P = 2 × (L + l)</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Si L = 8 cm et l = 3 cm, alors P = 2 × (8 + 3) = 22 cm</td>
                    </tr>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Figure quelconque</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>P = somme des côtés</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Si côtés = 5, 3, 4, 6 cm, alors P = 5 + 3 + 4 + 6 = 18 cm</td>
                    </tr>
                </tbody>
            </table>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Problèmes inverses :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Carré</strong> : Si P = 24 cm, alors <strong>c = P ÷ 4 = 24 ÷ 4 = 6 cm</strong></li>
                <li style="margin:0; text-align:left;"><strong>Rectangle</strong> : Si P = 22 cm et L = 8 cm, alors <strong>l = (P ÷ 2) - L = (22 ÷ 2) - 8 = 11 - 8 = 3 cm</strong></li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Points clés à retenir :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le périmètre est la <strong>longueur du contour</strong> d'une figure</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour un <strong>carré</strong> : <strong>P = 4 × c</strong> (ou <strong>c = P ÷ 4</strong> pour trouver le côté)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour un <strong>rectangle</strong> : <strong>P = 2 × (L + l)</strong> (ou <strong>l = (P ÷ 2) - L</strong> pour trouver une dimension)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour une figure quelconque : on <strong>additionne tous les côtés</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour une figure composée : on compte <strong>uniquement le contour extérieur</strong></li>
                <li style="margin:0; text-align:left;">Les formules peuvent être utilisées <strong>dans les deux sens</strong> : pour calculer le périmètre ou pour retrouver une dimension</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour le carré</strong> : retenir que <strong>P = 4 × côté</strong> (très simple car tous les côtés sont égaux)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour le rectangle</strong> : retenir que <strong>P = 2 × (L + l)</strong> - ne pas oublier les parenthèses !</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour une figure quelconque</strong> : dessiner la figure et noter la longueur de chaque côté, puis additionner</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour une figure composée</strong> : imaginer que tu fais le tour de la figure et ne compte que les côtés extérieurs</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérifier l'unité</strong> : toujours s'assurer que toutes les longueurs sont dans la même unité (cm, m, etc.)</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier la cohérence</strong> : le périmètre doit être réaliste (par exemple, un rectangle de 5 cm × 3 cm ne peut pas avoir un périmètre de 100 cm !)</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre <strong>périmètre</strong> et <strong>aire</strong> : le périmètre est une longueur (cm, m), l'aire est une surface (cm², m²)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier les <strong>parenthèses</strong> dans la formule du rectangle : écrire <strong>2 × L + l</strong> au lieu de <strong>2 × (L + l)</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre <strong>longueur</strong> et <strong>largeur</strong> dans un rectangle (L = côté le plus long, l = côté le plus court)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour une figure composée : <strong>compter deux fois</strong> les côtés où les figures sont collées (il ne faut compter que le contour extérieur !)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier l'<strong>unité</strong> dans la réponse (toujours écrire <strong>cm</strong>, <strong>m</strong>, etc.)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mélanger les <strong>unités</strong> dans un calcul : convertir toutes les longueurs dans la même unité avant de calculer</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la <strong>cohérence du résultat</strong> : si tu trouves un périmètre très grand ou très petit par rapport à la taille de la figure, vérifie tes calculs</li>
            </ul>
