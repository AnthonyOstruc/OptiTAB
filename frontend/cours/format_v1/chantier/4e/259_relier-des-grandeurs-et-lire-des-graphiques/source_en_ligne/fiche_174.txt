Titre: Résumé : Relier des grandeurs et lire des graphiques

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : formule, tableau, graphique ; lire et interpréter une courbe. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Trois représentations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Formule</strong> : $A = c^2$ ; <strong>tableau</strong> : $c = 1, 2, 3$ donne $A = 1, 4, 9$ ; <strong>graphique</strong> : les points $(c ; A)$.</p>
[IMAGE_2]
<p style="margin:6px 0 0 0;">• Points alignés avec l'origine → proportionnalité.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Lire et interpréter</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• Une valeur : axe horizontal → courbe → axe vertical.</p>
<p style="margin:6px 0 0 0;">• Quand une valeur est atteinte : axe vertical → courbe (parfois plusieurs points) → axe horizontal.</p>
<p style="margin:6px 0 0 0;">• Maximum, minimum ; « augmente », « diminue », « reste constante » (palier horizontal).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Inverser les axes (lire l'heure sur l'axe des températures).</p>
<p style="margin:6px 0 0 0;">2️⃣ Mal lire la graduation (un carreau ne vaut pas toujours $1$).</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier une des solutions quand la courbe atteint deux fois une valeur.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre la forme du graphique avec la forme réelle (un graphique distance-temps n'est pas le dessin du chemin).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> avant de lire, je repère ce que représente chaque axe et son unité ; après avoir lu, je vérifie si possible avec la formule.</p>
</div>
