<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les trois briques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:480px;">
<p style="margin:0; font-weight:bold;">Boucle (répéter) • Variable (mettre, ajouter) • Condition (si… alors… sinon)</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Répéter $4$ fois « avancer $100$, tourner $90°$ » dessine un carré.</p>
<p style="margin:6px 0 0 0;">• Polygone régulier à $n$ côtés : tourner de $\dfrac{360}{n}$ degrés à chaque tour.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Les bons réflexes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Lire le script de haut en bas, une instruction à la fois.</p>
<p style="margin:6px 0 0 0;">2️⃣ Faire un tableau de suivi des variables à chaque tour de boucle.</p>
<p style="margin:6px 0 0 0;">3️⃣ Tester les cas limites d'une condition (par exemple $17$ et $18$ pour « $> 17$ »).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre « mettre » (remplacer) et « ajouter » (augmenter).</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier « stylo en position d'écriture » : rien n'est dessiné.</p>
<p style="margin:6px 0 0 0;">3️⃣ Tourner de l'angle intérieur au lieu de l'angle extérieur ($120°$ et non $60°$ pour un triangle équilatéral).</p>
<p style="margin:6px 0 0 0;">4️⃣ Écrire une boucle « répéter jusqu'à » dont la condition ne devient jamais vraie (boucle infinie).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> une action qui se répète → boucle ; une valeur à mémoriser → variable ; un choix → condition ; un programme qui ne marche pas → tableau de suivi pour trouver l'erreur.</p>
</div>
