===
Découverte - Deux achats à additionner
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pose et calcule 4,56 € + 15,30 €.

1. Écris toutes les sommes en euros avec deux chiffres pour les centimes.
2. Comment faut-il aligner les nombres pour poser l’addition ?
3. Additionne les centimes. Faut-il reporter un euro ?
4. Termine l’addition posée et donne le total.
5. Vérifie le total en calculant seulement en centimes.

Étapes:
<!-- optitab:1 -->

## Question 1 : Écris toutes les sommes en euros avec deux chiffres pour les centimes.

::: methode
Convertis les centimes en euros et complète les euros entiers par ,00.
:::

::: etape Raisonner
4,56 € = 4 euros et 56 centimes ; 15,30 € = 15 euros et 30 centimes
:::

::: resultat
$4{,}56$ € ; $15{,}30$ €.
:::

## Question 2 : Comment faut-il aligner les nombres pour poser l’addition ?

::: methode
Place les unités de même valeur les unes sous les autres.
:::

::: etape Raisonner
Les virgules sont alignées : euros sous euros, dizaines de centimes sous dizaines de centimes, centimes sous centimes.
:::

::: resultat
Aligne les virgules et les colonnes de même valeur.
:::

## Question 3 : Additionne les centimes. Faut-il reporter un euro ?

::: methode
Cent centimes s’échangent contre un euro.
:::

::: etape Raisonner
56 + 30 = 86 centimes.
:::

::: resultat
86 centimes, sans euro à reporter.
:::

## Question 4 : Termine l’addition posée et donne le total.

::: methode
Ajoute les euros et le report éventuel, puis écris deux chiffres pour les centimes.
:::

::: etape Raisonner
$$
\begin{array}{r}4{,}56\\+15{,}30\\\hline 19{,}86\end{array}
$$
:::

::: resultat
$19{,}86$ €.
:::

## Question 5 : Vérifie le total en calculant seulement en centimes.

::: methode
Convertis chaque prix en centimes puis additionne.
:::

::: etape Raisonner
$456+1530=1986$.
:::

::: resultat
1986 centimes, soit $19{,}86$ €.
:::

Solution:
<!-- optitab:1 -->
1. $4{,}56$ € ; $15{,}30$ €.
2. Aligne les virgules et les colonnes de même valeur.
3. 86 centimes, sans euro à reporter.
4. $19{,}86$ €.
5. 1986 centimes, soit $19{,}86$ €.

Entraînement - Une différence de prix
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Pose et calcule $24{,}56$ € − $15{,}30$ €.

1. Quelle somme faut-il placer sur la première ligne ?
2. Comment dois-tu aligner les prix ?
3. Peut-on retirer les centimes directement ?
4. Termine la soustraction posée.
5. Vérifie avec une addition.

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle somme faut-il placer sur la première ligne ?

::: methode
La différence se calcule en retirant le second prix du premier.
:::

::: etape Raisonner
On commence par $24{,}56$ €, puis on retire $15{,}30$ €.
:::

::: resultat
$24{,}56$ €.
:::

## Question 2 : Comment dois-tu aligner les prix ?

::: methode
Les mêmes unités doivent se correspondre.
:::

::: etape Raisonner
Écris les virgules dans la même colonne, puis euros sous euros et centimes sous centimes.
:::

::: resultat
Les virgules et les unités de même valeur sont alignées.
:::

## Question 3 : Peut-on retirer les centimes directement ?

::: methode
Compare les deux nombres de centimes.
:::

::: etape Raisonner
Le premier nombre de centimes suffit : aucun échange n’est nécessaire.
:::

::: resultat
$56-30=26$ centimes.
:::

## Question 4 : Termine la soustraction posée.

::: methode
Retire les euros en tenant compte de l’échange éventuel.
:::

::: etape Raisonner
$$
\begin{array}{r}24{,}56\\-15{,}30\\\hline 9{,}26\end{array}
$$
:::

::: resultat
$9{,}26$ €.
:::

## Question 5 : Vérifie avec une addition.

::: methode
Ajoute la somme retirée au résultat.
:::

::: etape Raisonner
$926+1530=2456$ centimes.
:::

::: resultat
On retrouve $24{,}56$ €.
:::

Solution:
<!-- optitab:1 -->
1. $24{,}56$ €.
2. Les virgules et les unités de même valeur sont alignées.
3. $56-30=26$ centimes.
4. $9{,}26$ €.
5. On retrouve $24{,}56$ €.

Problème - Réparer un mauvais alignement
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Noé veut calculer 7,85 € + 68 centimes. Il écrit 68 sous les euros, comme si les 68 centimes étaient 68 €.

1. Pourquoi le calcul de Noé est-il faux ?
2. Écris correctement 68 centimes en euros.
3. Comment faut-il poser l’opération ?
4. Calcule la bonne somme.
5. Comment voir que 75,85 € ne peut pas être le bon résultat ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Pourquoi le calcul de Noé est-il faux ?

::: methode
Vérifie l’unité de chaque nombre.
:::

::: etape Raisonner
Les 68 sont des centimes, pas des euros.
:::

::: resultat
Il a confondu euros et centimes.
:::

## Question 2 : Écris correctement 68 centimes en euros.

::: methode
Il n’y a aucun euro entier.
:::

::: etape Raisonner
On écrit zéro avant la virgule et 68 après.
:::

::: resultat
0,68 €.
:::

## Question 3 : Comment faut-il poser l’opération ?

::: methode
Aligne les virgules et les colonnes de même valeur.
:::

::: etape Raisonner
Écris 0,68 sous 7,85, avec les deux virgules alignées.
:::

::: resultat
7,85 € et 0,68 € alignés par leur virgule.
:::

## Question 4 : Calcule la bonne somme.

::: methode
Échange les 153 centimes contre un euro et 53 centimes.
:::

::: etape Raisonner
$$
\begin{array}{r}7{,}85\\+0{,}68\\\hline 8{,}53\end{array}
$$
:::

::: resultat
8,53 €.
:::

## Question 5 : Comment voir que 75,85 € ne peut pas être le bon résultat ?

::: methode
Compare l’augmentation avec un euro.
:::

::: etape Raisonner
Ajouter 68 centimes augmente le prix de moins d’un euro. Le résultat reste donc entre 7,85 € et 8,85 €.
:::

::: resultat
75,85 € est beaucoup trop grand ; le total juste est 8,53 €.
:::

Solution:
<!-- optitab:1 -->
1. Il a confondu euros et centimes.
2. 0,68 €.
3. 7,85 € et 0,68 € alignés par leur virgule.
4. 8,53 €.
5. 75,85 € est beaucoup trop grand ; le total juste est 8,53 €.
