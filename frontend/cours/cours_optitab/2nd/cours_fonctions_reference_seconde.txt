    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">0. Fonction affine</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et propriétés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction affine</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>fonction affine</strong> est la fonction définie sur $\displaystyle \mathbb{R}$ par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle f(x) = ax + b$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle a$ et $\displaystyle b$ sont des nombres réels.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle a$ est le coefficient directeur et $\displaystyle b$ est l'ordonnée à l'origine.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle a > 0$ : la fonction affine est <strong>croissante</strong> sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle a < 0$ : la fonction affine est <strong>décroissante</strong> sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0; text-align:left;">Si $\displaystyle a = 0$ : la fonction affine est <strong>constante</strong> : $\displaystyle f(x) = b$</li>
            </ul>
            [IMAGE_7]
        </div>
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(x) = 2x + 3$ (croissante)</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle g(x) = -3x + 1$ (décroissante)</li>
                <li style="margin:0; text-align:left;">$\displaystyle h(x) = 5$ (constante)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Fonction carré</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et propriétés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction carré</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>fonction carré</strong> est la fonction définie sur $\displaystyle \mathbb{R}$ par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle f(x) = x^2$
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations et parité</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">La fonction carré est <strong>décroissante</strong> sur $\displaystyle ]-\infty; 0]$ et <strong>croissante</strong> sur $\displaystyle [0; +\infty[$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Elle admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">La fonction carré est <strong>paire</strong> : $\displaystyle f(-x) = f(x)$ pour tout $\displaystyle x \in \mathbb{R}$</li>
                <li style="margin:0; text-align:left;">Sa courbe représentative est une <strong>parabole</strong> de sommet $\displaystyle O(0; 0)$ et d'axe de symétrie l'axe des ordonnées</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(2) = 2^2 = 4$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(-3) = (-3)^2 = 9$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(0) = 0^2 = 0$ (minimum)</li>
                <li style="margin:0; text-align:left;">Pour comparer : $\displaystyle f(-5) = 25$ et $\displaystyle f(5) = 25$ (fonction paire)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Courbe représentative</h3>

        [IMAGE_1]

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Image mentale - Parabole :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative de la fonction carré est une <strong>parabole</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Symétrique par rapport à l'axe des ordonnées</li>
                <li style="margin:0 0 18px 0; text-align:left;">Sommet à l'origine $\displaystyle O(0; 0)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Orientée vers le haut (concavité vers le haut)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Points caractéristiques : $\displaystyle (-2; 4)$, $\displaystyle (-1; 1)$, $\displaystyle (0; 0)$, $\displaystyle (1; 1)$, $\displaystyle (2; 4)$</li>
                <li style="margin:0; text-align:left;">La courbe passe par tous les points de la forme $\displaystyle (a; a^2)$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Fonction inverse</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et propriétés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction inverse</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>fonction inverse</strong> est la fonction définie sur $\displaystyle \mathbb{R}^{\ast} = \mathbb{R} \setminus \{0\}$ par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle f(x) = \frac{1}{x}$
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations et parité</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">La fonction inverse est <strong>décroissante</strong> sur $\displaystyle ]-\infty; 0[$ et <strong>décroissante</strong> sur $\displaystyle ]0; +\infty[$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Elle n'admet ni maximum ni minimum</li>
                <li style="margin:0 0 18px 0; text-align:left;">La fonction inverse est <strong>impaire</strong> : $\displaystyle f(-x) = -f(x)$ pour tout $\displaystyle x \in \mathbb{R}^{\ast}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Sa courbe représentative est une <strong>hyperbole</strong> de centre $\displaystyle O(0; 0)$ et symétrique par rapport à l'origine</li>
                <li style="margin:0; text-align:left;">Les axes de coordonnées sont des <strong>asymptotes</strong> : la courbe s'en approche sans jamais les toucher</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(2) = \frac{1}{2} = 0,5$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(-4) = \frac{1}{-4} = -0,25$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f\left(\frac{1}{3}\right) = \frac{1}{\frac{1}{3}} = 3$</li>
                <li style="margin:0; text-align:left;">Pour comparer : $\displaystyle f(-2) = -0,5$ et $\displaystyle f(2) = 0,5$ (fonction impaire : $\displaystyle f(-2) = -f(2)$)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Courbe représentative</h3>

        [IMAGE_2]

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Image mentale - Hyperbole :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative de la fonction inverse est une <strong>hyperbole</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Symétrique par rapport à l'origine $\displaystyle O$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Deux branches : une dans le quadrant I (x > 0, y > 0) et une dans le quadrant III (x < 0, y < 0)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Asymptotes : l'axe des abscisses (y = 0) et l'axe des ordonnées (x = 0)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Points caractéristiques : $\displaystyle (-2; -0,5)$, $\displaystyle (-1; -1)$, $\displaystyle (1; 1)$, $\displaystyle (2; 0,5)$</li>
                <li style="margin:0; text-align:left;">La courbe s'approche de plus en plus des axes sans jamais les toucher</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonction racine carrée</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et propriétés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction racine carrée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>fonction racine carrée</strong> est la fonction définie sur $\displaystyle [0; +\infty[$ par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle f(x) = \sqrt{x}$
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">La fonction racine carrée est <strong>croissante</strong> sur $\displaystyle [0; +\infty[$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Elle admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour tout $\displaystyle x \geq 0$, on a $\displaystyle \sqrt{x} \geq 0$</li>
                <li style="margin:0; text-align:left;">Sa courbe représentative est une <strong>demi-parabole</strong> orientée vers la droite</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(0) = \sqrt{0} = 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(4) = \sqrt{4} = 2$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(9) = \sqrt{9} = 3$</li>
                <li style="margin:0; text-align:left;">$\displaystyle f(25) = \sqrt{25} = 5$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Courbe représentative</h3>

        [IMAGE_3]

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Image mentale - Demi-parabole :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative de la fonction racine carrée est une <strong>demi-parabole</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Définie uniquement pour $\displaystyle x \geq 0$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Commence à l'origine $\displaystyle O(0; 0)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Croissante et concave vers le bas</li>
                <li style="margin:0 0 18px 0; text-align:left;">Points caractéristiques : $\displaystyle (0; 0)$, $\displaystyle (1; 1)$, $\displaystyle (4; 2)$, $\displaystyle (9; 3)$, $\displaystyle (16; 4)$</li>
                <li style="margin:0; text-align:left;">La courbe passe par tous les points de la forme $\displaystyle (a^2; a)$ pour $\displaystyle a \geq 0$</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Fonction cube</h2>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Comparaison d'images et résolution d'équations/inéquations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Comparer f(a) et f(b)</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Comparaison numérique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer $\displaystyle f(a)$ et $\displaystyle f(b)$ numériquement :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Calculer $\displaystyle f(a)$ et $\displaystyle f(b)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Comparer les valeurs obtenues</li>
                <li style="margin:0; text-align:left;">Utiliser les variations de la fonction si nécessaire</li>
            </ol>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Comparaison graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer $\displaystyle f(a)$ et $\displaystyle f(b)$ graphiquement :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Placer les points $\displaystyle A(a; f(a))$ et $\displaystyle B(b; f(b))$ sur la courbe</li>
                <li style="margin:0 0 18px 0; text-align:left;">Comparer les ordonnées de ces points</li>
                <li style="margin:0; text-align:left;">Utiliser les variations de la fonction : si $\displaystyle f$ est croissante et $\displaystyle a < b$, alors $\displaystyle f(a) < f(b)$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction carré $\displaystyle f(x) = x^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comparer $\displaystyle f(-3)$ et $\displaystyle f(2)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(-3) = (-3)^2 = 9$ et $\displaystyle f(2) = 2^2 = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(-3) > f(2)$ (car la fonction carré est décroissante sur $\displaystyle ]-\infty; 0]$ et croissante sur $\displaystyle [0; +\infty[$)</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction racine carrée $\displaystyle f(x) = \sqrt{x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comparer $\displaystyle f(4)$ et $\displaystyle f(9)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(4) = \sqrt{4} = 2$ et $\displaystyle f(9) = \sqrt{9} = 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle 4 < 9$ et $\displaystyle f$ est croissante, on a $\displaystyle f(4) < f(9)$ ✓</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résoudre f(x) = k</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Résolution algébrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) = k$ algébriquement :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction affine :</strong> $\displaystyle mx + p = k \Longleftrightarrow x = \frac{k - p}{m}$ (si $\displaystyle m \neq 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction carré :</strong> $\displaystyle x^2 = k \Longleftrightarrow x = \sqrt{k}$ ou $\displaystyle x = -\sqrt{k}$ (si $\displaystyle k \geq 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction inverse :</strong> $\displaystyle \frac{1}{x} = k \Longleftrightarrow x = \frac{1}{k}$ (si $\displaystyle k \neq 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction racine carrée :</strong> $\displaystyle \sqrt{x} = k \Longleftrightarrow x = k^2$ (si $\displaystyle k \geq 0$)</li>
                <li style="margin:0; text-align:left;"><strong>Fonction cube :</strong> $\displaystyle x^3 = k \Longleftrightarrow x = \sqrt[3]{k}$</li>
            </ul>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Résolution graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) = k$ graphiquement :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la droite horizontale d'équation $\displaystyle y = k$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les points d'intersection avec la courbe $\displaystyle \mathcal{C}_f$</li>
                <li style="margin:0; text-align:left;">Lire les abscisses de ces points d'intersection</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Résoudre $\displaystyle x^2 = 9$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle x^2 = 9 \Longleftrightarrow x = 3$ ou $\displaystyle x = -3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les solutions sont $\displaystyle S = \{-3; 3\}$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Résoudre $\displaystyle \frac{1}{x} = 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \frac{1}{x} = 2 \Longleftrightarrow x = \frac{1}{2}$ (et $\displaystyle x \neq 0$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = \left\{\frac{1}{2}\right\}$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Résoudre $\displaystyle \sqrt{x} = 5$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sqrt{x} = 5 \Longleftrightarrow x = 5^2 = 25$ (avec $\displaystyle x \geq 0$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = \{25\}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résoudre f(x) < k (ou f(x) > k)</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Résolution algébrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) < k$ ou $\displaystyle f(x) > k$ algébriquement :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction affine :</strong> Utiliser les propriétés des inégalités (attention au signe du coefficient directeur)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction carré :</strong> Utiliser le tableau de variations et la parité</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction inverse :</strong> Attention au signe de $\displaystyle x$ (étudier séparément $\displaystyle x > 0$ et $\displaystyle x < 0$)</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction racine carrée :</strong> Utiliser la croissance de la fonction</li>
                <li style="margin:0; text-align:left;"><strong>Fonction cube :</strong> Utiliser la croissance de la fonction</li>
            </ul>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Résolution graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) < k$ graphiquement :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la droite horizontale d'équation $\displaystyle y = k$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les parties de la courbe $\displaystyle \mathcal{C}_f$ situées <strong>en dessous</strong> de cette droite</li>
                <li style="margin:0; text-align:left;">Lire les abscisses correspondantes</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle f(x) > k$, repérer les parties de la courbe situées <strong>au-dessus</strong> de la droite.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Résoudre $\displaystyle x^2 < 9$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On résout d'abord $\displaystyle x^2 = 9$ : $\displaystyle x = 3$ ou $\displaystyle x = -3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme la fonction carré est décroissante sur $\displaystyle ]-\infty; 0]$ et croissante sur $\displaystyle [0; +\infty[$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle x^2 < 9 \Longleftrightarrow -3 < x < 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = ]-3; 3[$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Résoudre $\displaystyle \sqrt{x} < 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On doit avoir $\displaystyle x \geq 0$ (domaine de définition)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme la fonction racine carrée est croissante : $\displaystyle \sqrt{x} < 3 \Longleftrightarrow x < 9$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = [0; 9[$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Résoudre $\displaystyle \frac{1}{x} > 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On doit avoir $\displaystyle x \neq 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Cas 1 :</strong> Si $\displaystyle x > 0$ : $\displaystyle \frac{1}{x} > 2 \Longleftrightarrow 1 > 2x \Longleftrightarrow x < \frac{1}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle 0 < x < \frac{1}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Cas 2 :</strong> Si $\displaystyle x < 0$ : $\displaystyle \frac{1}{x} > 2$ est impossible car $\displaystyle \frac{1}{x} < 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = \left]0; \frac{1}{2}\right[$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Démonstration : Position relative des courbes y = x, y = x², y = x³</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Étude pour x ≥ 0</h3>

        <div style="background:#e0f7fa; border-radius:6px; border-left:6px solid #00bcd4; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>🎯 Objectif et Méthode</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut comparer $\displaystyle x$, $\displaystyle x^2$ et $\displaystyle x^3$ pour $\displaystyle x \geq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong> On étudie le signe de la différence entre deux termes consécutifs.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">$\displaystyle x^2 - x = x(x - 1)$</li>
                <li style="margin:0; text-align:left;">$\displaystyle x^3 - x^2 = x^2(x - 1)$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle x \geq 0$, les termes $\displaystyle x$ et $\displaystyle x^2$ sont positifs. Le signe de la différence dépend donc uniquement du signe de $\displaystyle x - 1$.</p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>1️⃣ Cas où $\displaystyle 0 \leq x < 1$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ici, $\displaystyle x < 1$ donc $\displaystyle x - 1 < 0$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">$\displaystyle x^2 - x < 0 \Longrightarrow x^2 < x$</li>
                <li style="margin:0; text-align:left;">$\displaystyle x^3 - x^2 < 0 \Longrightarrow x^3 < x^2$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong> Sur $\displaystyle [0; 1[$, on a <strong>$\displaystyle x^3 \leq x^2 \leq x$</strong>.</p>
        </div>

        <div style="background:#d1fae5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>2️⃣ Cas où $\displaystyle x > 1$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ici, $\displaystyle x > 1$ donc $\displaystyle x - 1 > 0$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">$\displaystyle x^2 - x > 0 \Longrightarrow x^2 > x$</li>
                <li style="margin:0; text-align:left;">$\displaystyle x^3 - x^2 > 0 \Longrightarrow x^3 > x^2$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong> Sur $\displaystyle ]1; +\infty[$, on a <strong>$\displaystyle x \leq x^2 \leq x^3$</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Illustration graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur un graphique, pour $\displaystyle x \geq 0$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Entre $\displaystyle 0$ et $\displaystyle 1$ : la droite $\displaystyle y = x$ est la plus haute, puis $\displaystyle y = x^2$, puis $\displaystyle y = x^3$ (la plus basse)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Au point $\displaystyle (1; 1)$ : les trois courbes se croisent</li>
                <li style="margin:0; text-align:left;">Pour $\displaystyle x > 1$ : la courbe $\displaystyle y = x^3$ est la plus haute, puis $\displaystyle y = x^2$, puis la droite $\displaystyle y = x$ (la plus basse)</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes générales</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pratiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Images mentales :</strong> Mémoriser la forme des courbes (parabole, hyperbole, demi-parabole, cubique) pour les reconnaître rapidement</li>
                <li style="margin:0; text-align:left;"><strong>Domaine de définition :</strong> Toujours vérifier le domaine avant de résoudre une équation ou inéquation</li>
                <li style="margin:0; text-align:left;"><strong>Fonction carré :</strong> Paire, décroissante sur $\displaystyle ]-\infty; 0]$, croissante sur $\displaystyle [0; +\infty[$, minimum en 0</li>
                <li style="margin:0; text-align:left;"><strong>Fonction inverse :</strong> Impaire, décroissante sur chaque intervalle, asymptotes en $\displaystyle x = 0$ et $\displaystyle y = 0$</li>
                <li style="margin:0; text-align:left;"><strong>Fonction racine carrée :</strong> Définie sur $\displaystyle [0; +\infty[$, croissante, commence à l'origine</li>
                <li style="margin:0; text-align:left;"><strong>Fonction cube :</strong> Impaire, croissante sur tout $\displaystyle \mathbb{R}$, passe par l'origine</li>
                <li style="margin:0; text-align:left;"><strong>Comparaison d'images :</strong> Utiliser les variations de la fonction : si $\displaystyle f$ est croissante et $\displaystyle a < b$, alors $\displaystyle f(a) < f(b)$</li>
                <li style="margin:0; text-align:left;"><strong>Résolution graphique :</strong> Tracer la droite horizontale $\displaystyle y = k$ et repérer les intersections avec la courbe</li>
                <li style="margin:0; text-align:left;"><strong>Résolution algébrique :</strong> Utiliser les propriétés spécifiques de chaque fonction (parité, variations, domaine)</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Fonction inverse :</strong> Ne pas oublier que $\displaystyle x \neq 0$ (division par zéro)</li>
                <li style="margin:0; text-align:left;"><strong>Fonction racine carrée :</strong> Ne pas oublier que $\displaystyle x \geq 0$ (racine carrée d'un nombre négatif n'existe pas dans $\displaystyle \mathbb{R}$)</li>
                <li style="margin:0; text-align:left;"><strong>Fonction carré :</strong> Attention : $\displaystyle x^2 = k$ a deux solutions si $\displaystyle k > 0$ (une positive, une négative), une seule si $\displaystyle k = 0$, aucune si $\displaystyle k < 0$</li>
                <li style="margin:0; text-align:left;"><strong>Fonction inverse :</strong> Pour les inéquations, étudier séparément les cas $\displaystyle x > 0$ et $\displaystyle x < 0$ (le sens de l'inégalité peut changer)</li>
                <li style="margin:0; text-align:left;"><strong>Comparaison :</strong> Ne pas confondre "croissante" et "décroissante" : une fonction croissante conserve l'ordre, une décroissante l'inverse</li>
                <li style="margin:0; text-align:left;"><strong>Parité :</strong> Ne pas confondre "paire" (symétrie par rapport à l'axe des ordonnées) et "impaire" (symétrie par rapport à l'origine)</li>
                <li style="margin:0; text-align:left;"><strong>Position relative :</strong> Pour $\displaystyle x \geq 0$, attention à l'ordre qui change selon que $\displaystyle x < 1$ ou $\displaystyle x > 1$</li>
                <li style="margin:0; text-align:left;"><strong>Résolution d'inéquations :</strong> Toujours vérifier le domaine de définition avant de donner la solution finale</li>
                <li style="margin:0; text-align:left;"><strong>Graphique :</strong> Pour $\displaystyle f(x) < k$, repérer les parties de la courbe en dessous de la droite $\displaystyle y = k$</li>
            </ul>
        </div>
