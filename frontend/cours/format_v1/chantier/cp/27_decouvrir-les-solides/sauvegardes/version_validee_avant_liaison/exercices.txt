Énoncé:

Observe les solides A,B,C,D,E. Les dessins montrent des objets en volume.

[IMAGE_1]

1. Comment s’appelle A ?
2. Comment s’appelle B ?
3. Comment s’appelle C ?
4. Reconnais D.
5. Reconnais E.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment s’appelle A ?

::: methode
Observe les faces carrées comme celles d’un dé.
:::

::: etape Raisonner
Ses six faces sont des carrés de même taille.
:::

::: resultat
Un cube.
:::

## Question 2 : Comment s’appelle B ?

::: methode
Pense à une boîte à chaussures.
:::

::: etape Raisonner
La boîte est allongée et ses faces sont rectangulaires.
:::

::: resultat
Un pavé droit.
:::

## Question 3 : Comment s’appelle C ?

::: methode
Pense à une balle.
:::

::: etape Raisonner
L’objet est tout rond et n’a pas de face plate.
:::

::: resultat
Une boule.
:::

## Question 4 : Reconnais D.

::: methode
Pense à une boîte de conserve.
:::

::: etape Raisonner
Deux bases rondes sont reliées par une surface courbe.
:::

::: resultat
Un cylindre.
:::

## Question 5 : Reconnais E.

::: methode
Pense à un chapeau de fête pointu.
:::

::: etape Raisonner
Il a une base ronde et une pointe.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Un cône.
:::

<!-- optitab:1 -->
1. Un cube.
2. Un pavé droit.
3. Une boule.
4. Un cylindre.
5. Un cône.

5. Comment décris-tu le cube avec ses faces ?

<!-- optitab:1 -->

:::

:::

::: resultat

:::

::: methode

::: etape Raisonner

::: etape Raisonner

::: resultat

::: etape Raisonner

:::

<!-- optitab:1 -->
1. Un carré.
2. 6 faces.
3. Non.
4. En marquant les faces comptées.
5. Un cube a 6 faces carrées.

Entraînement - Assembler un cube
Id: nouveau-6
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Avec un adulte, prépare six carrés cartonnés identiques de 3 cm de côté. Assemble-les avec du ruban adhésif pour fermer un cube. Le modèle des faces est réduit.

[IMAGE_1]

1. Combien de faces prépares-tu ?
2. Pourquoi les carrés ont-ils tous la même taille ?
3. Comment relies-tu les faces ?
4. Que doit donner l’assemblage terminé ?
5. Comment contrôles-tu la construction ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de faces prépares-tu ?

::: methode
Un cube possède six faces.
:::

::: etape Raisonner
Il faut six carrés, chacun pour une face.
:::

::: resultat
6 faces.
:::

## Question 2 : Pourquoi les carrés ont-ils tous la même taille ?

::: methode
Les faces doivent pouvoir se rejoindre.
:::

::: etape Raisonner
Les bords voisins doivent avoir la même longueur.
:::

::: resultat
Pour que les bords se rejoignent.
:::

## Question 3 : Comment relies-tu les faces ?

::: methode
Fais correspondre les côtés des carrés.
:::

::: etape Raisonner
Colle bord contre bord, en t’aidant d’un cube réel.
:::

::: resultat
Bord contre bord.
:::

## Question 4 : Que doit donner l’assemblage terminé ?

::: methode
Ferme le dessus et le dessous aussi.
:::

::: etape Raisonner
Les six faces forment une boîte fermée en forme de cube.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Un cube fermé.
:::

## Question 5 : Comment contrôles-tu la construction ?

::: methode
Tourne ton objet et regarde chaque côté.
:::

::: etape Raisonner
Il faut six faces carrées, sans trou entre les faces.
:::

::: resultat
Six faces carrées jointives, sans trou.
:::

Solution:
<!-- optitab:1 -->
1. 6 faces.
2. Pour que les bords se rejoignent.
3. Bord contre bord.
4. Un cube fermé.
5. Six faces carrées jointives, sans trou.

<!-- optitab:1 -->

5. Comment contrôles-tu les faces ?

<!-- optitab:1 -->

## Question 1 : Combien de rectangles prépares-tu en tout ?

::: methode

:::

::: etape Raisonner
$2+2+2=6$.
:::

::: resultat
6 rectangles.
:::

::: methode
Observe les faces qui se font face sur une boîte.

::: etape Raisonner

::: resultat

::: resultat
