===Résumé Géométrie repérée Première

Titre: Résumé : Géométrie repérée

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : vecteur normal, projeté orthogonal, équation de cercle, axe d’une parabole. Programme de Première.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Droites et vecteur normal</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$ax + by + c = 0$ : $\vec{n}\,(a\,;b)$ normal, $\vec{u}\,(-b\,;a)$ directeur</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Droite par $A$ de normal $\vec{n}$ : $a(x - x_A) + b(y - y_A) = 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Perpendiculaires $\iff$ normaux orthogonaux $\iff mm' = -1$ (non verticales).</p>
<p style="margin:6px 0 0 0;">3️⃣ Projeté $H$ de $M$ : intersection de $d$ et de la perpendiculaire passant par $M$ ; distance $MH$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Cercles et paraboles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Cercle de centre $\Omega(a\,;b)$, rayon $r$ : $(x - a)^2 + (y - b)^2 = r^2$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Reconnaître un cercle : compléter les carrés en $x$ et en $y$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Parabole $y = ax^2 + bx + c$ : axe de symétrie $x = -\frac{b}{2a}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre vecteur normal $(a\,;b)$ et vecteur directeur $(-b\,;a)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $r$ au lieu de $r^2$ dans l’équation du cercle.</p>
<p style="margin:6px 0 0 0;">3️⃣ Se tromper de signe sur le centre : $(x + 1)^2$ correspond à $a = -1$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de vérifier que le projeté trouvé est bien sur $d$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> angle droit dans un repère → produit scalaire nul → vecteur normal → équation de droite.</p>
</div>
