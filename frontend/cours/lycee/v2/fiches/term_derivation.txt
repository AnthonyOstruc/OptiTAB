<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : dérivée d’une composée, dérivée seconde, convexité, point d’inflexion. Programme de Terminale.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Fonctions composées</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$(v \circ u)'(x) = v'(u(x)) \times u'(x)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $(e^u)' = u'e^u$ ; $(u^n)' = nu'u^{n-1}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $(\sqrt{u})' = \frac{u'}{2\sqrt{u}}$ ; $\left(\frac{1}{u}\right)' = -\frac{u'}{u^2}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\big(g(ax + b)\big)' = a\,g'(ax + b)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Convexité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Convexe : courbe au-dessus de ses tangentes $\iff f'$ croissante $\iff f'' \ge 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Concave : courbe en dessous $\iff f'' \le 0$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Point d’inflexion : $f''$ s’annule en changeant de signe ; la courbe traverse sa tangente.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier le facteur $u'$ : $(e^{3x})' = 3e^{3x}$, pas $e^{3x}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Étudier le signe de $f'$ au lieu de $f''$ pour la convexité.</p>
<p style="margin:6px 0 0 0;">3️⃣ Conclure à un point d’inflexion dès que $f''(a) = 0$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre convexe (« en creux ») et croissante.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> inégalité du type $f(x) \ge$ « une droite » → je pense à la convexité et à la tangente.</p>
</div>
