    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition du logarithme népérien</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition comme fonction réciproque</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction logarithme népérien</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction <strong>logarithme népérien</strong>, notée $\displaystyle \ln$, est la fonction réciproque de la fonction exponentielle.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x > 0$, $\displaystyle \ln(x)$ est l'unique réel tel que :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle e^{\ln(x)} = x$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}$, on a aussi :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \ln(e^x) = x$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le logarithme népérien "annule" l'exponentielle et vice versa. Si $\displaystyle y = e^x$, alors $\displaystyle x = \ln(y)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les courbes représentatives de $\displaystyle \exp$ et $\displaystyle \ln$ sont symétriques par rapport à la droite d'équation $\displaystyle y = x$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Domaine de définition et ensemble image</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Domaine et image</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Domaine de définition :</strong> $\displaystyle D_{\ln} = ]0, +\infty[$ (strictement positif)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ensemble image :</strong> $\displaystyle \ln(]0, +\infty[) = \mathbb{R}$ (tout réel atteint)</li>
            </ul>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Important :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le logarithme népérien n'est défini que pour les nombres strictement positifs. Pour $\displaystyle x \leq 0$, $\displaystyle \ln(x)$ n'existe pas dans les réels.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Propriétés algébriques du logarithme</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Règles de calcul fondamentales</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Propriétés algébriques du logarithme</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tous réels $\displaystyle x, y > 0$ et tout rationnel $\displaystyle q$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Produit :</strong> $\displaystyle \ln(xy) = \ln(x) + \ln(y)$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Quotient :</strong> $\displaystyle \ln\left(\frac{x}{y}\right) = \ln(x) - \ln(y)$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Puissance :</strong> $\displaystyle \ln(x^q) = q \ln(x)$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Valeurs particulières :</strong> $\displaystyle \ln(1) = 0$ et $\displaystyle \ln(e) = 1$</li>
                <li style="margin:0; text-align:left;"><strong>Relation avec l'exponentielle :</strong> $\displaystyle \ln(e^x) = x$ et $\displaystyle e^{\ln(x)} = x$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Règle mnémotechnique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les logarithmes <strong>s'additionnent</strong> pour un produit, se <strong>soustraient</strong> pour un quotient, et se <strong>multiplient</strong> par l'exposant pour une puissance.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples d'application :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(12) = \ln(3 \times 4) = \ln(3) + \ln(4) = \ln(3) + 2\ln(2)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln\left(\frac{16}{9}\right) = \ln(16) - \ln(9) = 4\ln(2) - 2\ln(3)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(\sqrt{x^3}) = \ln(x^{3/2}) = \frac{3}{2} \ln(x)$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \ln(e^{3x-1}) + \ln(e^{x+2}) = (3x-1) + (x+2) = 4x + 1$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Dérivée et variations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Dérivée du logarithme népérien</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Dérivée du logarithme népérien</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction logarithme népérien est dérivable sur $\displaystyle ]0, +\infty[$ et pour tout $\displaystyle x > 0$ :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:250px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle (\ln(x))' = \frac{1}{x}$</p>
            </div>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On admet que la fonction logarithme népérien est dérivable sur $\displaystyle ]0, +\infty[$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par définition, pour tout $\displaystyle x > 0$ : $\displaystyle e^{\ln(x)} = x$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En dérivant les deux membres par rapport à $\displaystyle x$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle e^{\ln(x)} \times (\ln(x))' = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle e^{\ln(x)} = x$, on obtient :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle x \times (\ln(x))' = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle (\ln(x))' = \frac{1}{x}$ ✓</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Dérivée d'une composée avec le logarithme</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle u$ est une fonction dérivable et strictement positive sur un intervalle $\displaystyle I$, alors :</p>
            <div style="background:#f3e5f5; border:3px solid #9c27b0; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle (\ln(u))' = \frac{u'}{u}$</p>
            </div>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour dériver $\displaystyle \ln(u(x))$, on obtient $\displaystyle \frac{u'}{u}$, et non simplement $\displaystyle \frac{1}{u}$ ! Il ne faut pas oublier le numérateur $\displaystyle u'$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de calculs de dérivées :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle (\ln(2x + 1))' = \frac{2}{2x + 1}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle (\ln(x^2 - 1))' = \frac{2x}{x^2 - 1}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle (x^2 \ln(x))' = 2x \ln(x) + x = x(2\ln(x) + 1)$ (produit)</li>
                <li style="margin:0; text-align:left;">$\displaystyle \left(\frac{\ln(x)}{x^2}\right)' = \frac{1 - 2\ln(x)}{x^3}$ (quotient)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Sens de variation</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">

            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction logarithme népérien est <strong>strictement croissante</strong> sur $\displaystyle ]0, +\infty[$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En effet, pour tout $\displaystyle x > 0$ : $\displaystyle \ln'(x) = \frac{1}{x} > 0$.</p>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Limites et courbe représentative</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Limites du logarithme népérien</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Limites du logarithme népérien</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \lim_{x \to 0^+} \ln(x) = -\infty$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \lim_{x \to +\infty} \ln(x) = +\infty$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \ln(1) = 0$ et $\displaystyle \ln(e) = 1$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation graphique :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En $\displaystyle 0^+$, $\displaystyle \ln(x)$ tend vers $\displaystyle -\infty$ : <strong>asymptote verticale</strong> d'équation $\displaystyle x = 0$</li>
                <li style="margin:0 0 12px 0; text-align:left;">En $\displaystyle +\infty$, $\displaystyle \ln(x)$ tend vers $\displaystyle +\infty$ mais <strong>très lentement</strong></li>
                <li style="margin:0; text-align:left;">Le point $\displaystyle (1, 0)$ est l'<strong>intercept à l'origine</strong></li>
            </ul>
        </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Lien entre les courbes représentatives de $\displaystyle \exp$ et $\displaystyle \ln$</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>🔗 Propriété - Symétrie des courbes :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les courbes représentatives des fonctions $\displaystyle \exp$ et $\displaystyle \ln$ sont <strong>symétriques</strong> par rapport à la droite d'équation $\displaystyle y = x$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela découle du fait que $\displaystyle \ln$ est la fonction réciproque de $\displaystyle \exp$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle (0, 1)$ sur la courbe de $\displaystyle \exp$ correspond au point $\displaystyle (1, 0)$ sur la courbe de $\displaystyle \ln$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle (1, e)$ sur la courbe de $\displaystyle \exp$ correspond au point $\displaystyle (e, 1)$ sur la courbe de $\displaystyle \ln$</li>
                <li style="margin:0; text-align:left;">L'asymptote horizontale $\displaystyle y = 0$ pour $\displaystyle \exp$ en $\displaystyle -\infty$ correspond à l'asymptote verticale $\displaystyle x = 0$ pour $\displaystyle \ln$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Croissance comparée</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Croissance comparée du logarithme et des puissances</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Croissance comparée en $\displaystyle +\infty$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout entier naturel $\displaystyle n \geq 1$ :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \lim_{x \to +\infty} \frac{\ln(x)}{x^n} = 0$</p>
            </div>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \lim_{x \to +\infty} \frac{x^n}{\ln(x)} = +\infty$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Autrement dit : <strong>le logarithme croît moins vite que toute puissance de $\displaystyle x$</strong> en $\displaystyle +\infty$.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Croissance comparée en $\displaystyle 0^+$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout entier naturel $\displaystyle n \geq 1$ :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \lim_{x \to 0^+} x^n \ln(x) = 0$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Autrement dit : <strong>le logarithme est "écrasé" par les puissances</strong> en $\displaystyle 0^+$.</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration - Limite de $\displaystyle x \ln(x)$ en $\displaystyle 0^+$ :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On pose $\displaystyle t = \frac{1}{x}$, donc $\displaystyle x = \frac{1}{t}$ et quand $\displaystyle x \to 0^+$, on a $\displaystyle t \to +\infty$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle x \ln(x) = \frac{1}{t} \ln\left(\frac{1}{t}\right) = \frac{1}{t} \times (-\ln(t)) = -\frac{\ln(t)}{t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">D'après la croissance comparée en $\displaystyle +\infty$ : $\displaystyle \lim_{t \to +\infty} \frac{\ln(t)}{t} = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle \lim_{x \to 0^+} x \ln(x) = 0$ ✓</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples d'utilisation :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \lim_{x \to +\infty} \frac{\ln(x)}{x^2} = 0$ (le logarithme est "écrasé" par $\displaystyle x^2$)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \lim_{x \to +\infty} \frac{x^3}{\ln(x)} = +\infty$ (les puissances l'emportent sur le logarithme)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \lim_{x \to 0^+} x^2 \ln(x) = 0$ (le logarithme est "écrasé" par $\displaystyle x^2$)</li>
                <li style="margin:0; text-align:left;">$\displaystyle \lim_{x \to 0^+} \sqrt{x} \ln(x) = 0$ (même avec une puissance fractionnaire)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Équations et inéquations logarithmiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de résolution d'équations</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode 1 - Égalité de deux logarithmes :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \ln(a) = \ln(b) \quad \Leftrightarrow \quad a = b \quad (a, b > 0)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si deux logarithmes sont égaux, leurs arguments sont égaux.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode 2 - Logarithme égal à un nombre :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \ln(x) = k \quad \Leftrightarrow \quad x = e^k \quad (k \in \mathbb{R})$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le résultat est toujours positif.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle \ln(x+2) = \ln(3x-1)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(x+2) = \ln(3x-1) \quad \Leftrightarrow \quad x + 2 = 3x - 1$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \Leftrightarrow \quad 3 = 2x$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \Leftrightarrow \quad x = \frac{3}{2}$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle x = 1,5 > 0$, $\displaystyle 1,5 + 2 = 3,5 > 0$ et $\displaystyle 3 \times 1,5 - 1 = 3,5 > 0$ ✓</p>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $\displaystyle S = \left\{\frac{3}{2}\right\}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle \ln(x) = 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \ln(x) = 2 \quad \Leftrightarrow \quad x = e^2$</p>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $\displaystyle S = \{e^2\}$ (environ $\displaystyle 7,389$)
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de résolution d'inéquations</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Conservation de l'ordre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction logarithme népérien est <strong>strictement croissante</strong> sur $\displaystyle ]0, +\infty[$, donc elle <strong>conserve l'ordre</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(a) < \ln(b) \quad \Leftrightarrow \quad a < b \quad (a, b > 0)$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \ln(a) \leq \ln(b) \quad \Leftrightarrow \quad a \leq b \quad (a, b > 0)$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre une inéquation logarithmique, on compare les arguments en conservant le sens de l'inégalité.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle \ln(x+1) < \ln(2x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(x+1) < \ln(2x) \quad \Leftrightarrow \quad x + 1 < 2x$ (avec $\displaystyle x+1 > 0$ et $\displaystyle 2x > 0$, soit $\displaystyle x > 0$)</li>
                <li style="margin:0; text-align:left;">$\displaystyle \Leftrightarrow \quad 1 < x$</li>
            </ul>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $\displaystyle S = ]1, +\infty[$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle \ln(x) \geq -1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \ln(x) \geq -1 \quad \Leftrightarrow \quad x \geq e^{-1} = \frac{1}{e}$ (avec $\displaystyle x > 0$)</p>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $\displaystyle S = \left[\frac{1}{e}, +\infty\right[$ (soit environ $\displaystyle [0,368 ; +\infty[$)
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Applications et étude de fonction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple complet : Étude de $\displaystyle f(x) = x \ln(x)$</h3>
        <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Énoncé :</strong> Étudier la fonction $\displaystyle f(x) = x \ln(x)$ sur $\displaystyle ]0, +\infty[$</p>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 1 :</strong> Domaine de définition
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f$ est définie sur $\displaystyle ]0, +\infty[$ (nécessaire pour $\displaystyle \ln(x)$)</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 2 :</strong> Calcul de la dérivée
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f$ est un produit $\displaystyle u \times v$ avec $\displaystyle u(x) = x$ et $\displaystyle v(x) = \ln(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle u'(x) = 1$ et $\displaystyle v'(x) = \frac{1}{x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f'(x) = 1 \times \ln(x) + x \times \frac{1}{x} = \ln(x) + 1$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 3 :</strong> Signe de $\displaystyle f'(x)$
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f'(x) = \ln(x) + 1$</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln(x) + 1 = 0 \Leftrightarrow \ln(x) = -1 \Leftrightarrow x = e^{-1} = \frac{1}{e}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour $\displaystyle x > \frac{1}{e}$, $\displaystyle \ln(x) > -1$ donc $\displaystyle f'(x) > 0$</li>
                <li style="margin:0; text-align:left;">Pour $\displaystyle 0 < x < \frac{1}{e}$, $\displaystyle \ln(x) < -1$ donc $\displaystyle f'(x) < 0$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 4 :</strong> Limites
            <p style="margin:8px 0; text-align:left; font-size:1em;">En $\displaystyle 0^+$ : forme indéterminée "$\displaystyle 0 \times (-\infty)$"</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \lim_{x \to 0^+} x \ln(x) = 0$ (limite de référence démontrée ci-dessus)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En $\displaystyle +\infty$ : $\displaystyle \lim_{x \to +\infty} x \ln(x) = +\infty$ (car $\displaystyle x$ l'emporte sur $\displaystyle \ln(x)$)</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 5 :</strong> Tableau de variations

                    <td style="border-top:0; border-left:0; border-bottom:1px solid #ddd; border-right:0; padding:12px; text-align:center; font-size:1.1em;">$\displaystyle 0$</td>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conclusion :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle f$ est <strong>décroissante</strong> sur $\displaystyle \left]0, \frac{1}{e}\right]$ de $\displaystyle 0$ à $\displaystyle -\frac{1}{e}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle f$ admet un <strong>minimum</strong> en $\displaystyle x = \frac{1}{e}$ : $\displaystyle f\left(\frac{1}{e}\right) = -\frac{1}{e} \approx -0,368$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle f$ est <strong>croissante</strong> sur $\displaystyle \left[\frac{1}{e}, +\infty\right[$ de $\displaystyle -\frac{1}{e}$ à $\displaystyle +\infty$</li>
                <li style="margin:0 0 12px 0; text-align:left;">L'axe des ordonnées ($\displaystyle x = 0$) est <strong>asymptote verticale</strong></li>
                <li style="margin:0; text-align:left;">L'axe des abscisses ($\displaystyle y = 0$) est <strong>asymptote horizontale</strong> en $\displaystyle 0^+$</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. 🌟 Bonus - Algorithme de Briggs</h2>

    <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:15px; margin:15px 0;">
        <p style="margin:0; text-align:left; font-size:1em;"><strong>🌟 Approfondissement :</strong> L'algorithme de Briggs est une méthode historique pour calculer des logarithmes. Cette section est un approfondissement culturel qui enrichit votre compréhension des méthodes numériques.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Principe de l'algorithme de Briggs</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Méthode de Briggs (approximation du logarithme) :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'algorithme de Briggs utilise la propriété : $\displaystyle \ln(x) = \ln\left(\frac{x}{e}\right) + 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En itérant cette relation, on peut approcher le logarithme d'un nombre donné.</p>
        </div>

        <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
            <span style="color:#ff79c6;">def</span> briggs_log(x, iterations=<span style="color:#bd93f9;">10</span>):<br>
            &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">if</span> x <= <span style="color:#bd93f9;">0</span>:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">return</span> <span style="color:#ff79c6;">None</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;result = <span style="color:#bd93f9;">0</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#bd93f9;">range</span>(iterations):<br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">while</span> x > <span style="color:#bd93f9;">2.718</span>:  <span style="color:#6272a4;"># e ≈ 2.718</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;x = x / <span style="color:#bd93f9;">2.718</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;result += <span style="color:#bd93f9;">1</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">while</span> x < <span style="color:#bd93f9;">1</span>:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;x = x * <span style="color:#bd93f9;">2.718</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;result -= <span style="color:#bd93f9;">1</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">if</span> <span style="color:#bd93f9;">abs</span>(x - <span style="color:#bd93f9;">1</span>) < <span style="color:#bd93f9;">0.001</span>:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">break</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;x = <span style="color:#bd93f9;">sqrt</span>(x)  <span style="color:#6272a4;"># Approximation supplémentaire</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;result = result / <span style="color:#bd93f9;">2</span><br>
            &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">return</span> result
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Note :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En évaluation, l'algorithme pourra être donné en pseudo-code ou en français ; ici il est illustré en Python.</p>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">X. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre $\displaystyle \ln(a) + \ln(b)$ et $\displaystyle \ln(a + b)$ : on a $\displaystyle \ln(a) + \ln(b) = \ln(ab)$, pas $\displaystyle \ln(a + b)$ !</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier le numérateur dans $\displaystyle (\ln(u))' = \frac{u'}{u}$ : ce n'est pas $\displaystyle \frac{1}{u}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Croire que $\displaystyle \ln(x)$ est défini pour $\displaystyle x \leq 0$ : le logarithme n'existe que pour $\displaystyle x > 0$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Inverser le sens des inégalités : le logarithme est croissant donc conserve l'ordre</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier que $\displaystyle \ln(1) = 0$ (et non 1)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre $\displaystyle \ln(e^x)$ et $\displaystyle e^{\ln(x)}$ : les deux valent $\displaystyle x$ mais dans des contextes différents</li>
                <li style="margin:0; text-align:left;">Penser que $\displaystyle \ln(x^2) = 2\ln(x)$ sans vérifier le domaine : c'est vrai pour $\displaystyle x > 0$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Toujours utiliser les <strong>propriétés algébriques</strong> pour simplifier avant de résoudre</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les équations : ramener à une égalité de la forme $\displaystyle \ln(a) = \ln(b)$ ou $\displaystyle \ln(x) = k$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les inéquations : utiliser la croissance de la fonction logarithme</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier que les arguments des logarithmes sont <strong>strictement positifs</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">S'entraîner à reconnaître les formes indéterminées et savoir les lever</li>
                <li style="margin:0 0 12px 0; text-align:left;">Maîtriser les limites de référence (notamment $\displaystyle \lim_{x \to 0^+} x \ln(x) = 0$)</li>
                <li style="margin:0; text-align:left;">Penser à la relation bijective entre $\displaystyle \ln$ et $\displaystyle \exp$ : $\displaystyle y = \ln(x) \Leftrightarrow x = e^y$</li>
            </ul>
        </div>
