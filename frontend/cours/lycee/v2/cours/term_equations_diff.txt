Titre: Équations différentielles

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> comprendre ce qu’est une équation différentielle, résoudre $y' = ay$ et $y' = ay + b$, utiliser une condition initiale, trouver les solutions de $y' = ay + f$ à partir d’une solution particulière, et modéliser des phénomènes (refroidissement, charge d’un condensateur, population).</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> une <strong>équation différentielle</strong> est une équation dont l’inconnue est une fonction $y$ et qui fait intervenir sa dérivée $y'$. Une <strong>solution</strong> sur $I$ est une fonction dérivable sur $I$ qui vérifie l’équation.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> les solutions de $y' = 2x$ sont les primitives de $2x$ : $y = x^2 + C$.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Vérifier une solution :</strong> on calcule $y'$ et on remplace dans l’équation. Par exemple $y = e^{3x}$ vérifie $y' = 3y$ car $y' = 3e^{3x}$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. L’équation $y' = ay$</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Théorème (démonstration au programme) :</strong> les solutions sur $\mathbb{R}$ de $y' = ay$ sont les fonctions $x \mapsto Ce^{ax}$, $C$ réel. Pour $x_0$ et $y_0$ donnés, une seule solution vérifie $y(x_0) = y_0$.</p>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> si $f' = af$, la fonction $g(x) = f(x)e^{-ax}$ a pour dérivée $g'(x) = (f'(x) - af(x))e^{-ax} = 0$ ; $g$ est constante, égale à $C$, d’où $f(x) = Ce^{ax}$. Réciproquement, ces fonctions sont bien solutions.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $y' = 3y$ avec $y(0) = 2$ : $y = Ce^{3x}$ et $C = 2$, donc $y = 2e^{3x}$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. L’équation $y' = ay + b$</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Théorème :</strong> pour $a \neq 0$, l’équation $y' = ay + b$ admet la solution constante $y = -\frac{b}{a}$, et ses solutions sont les fonctions</p>
            <div style="text-align:center; margin:10px 0 0 0;">$x \mapsto Ce^{ax} - \frac{b}{a}$, $C$ réel.</div>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> $f$ est solution si et seulement si $f + \frac{b}{a}$ est solution de $y' = ay$.</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Exemple :</strong> $y' = -0{,}5y + 2$ avec $y(0) = 0$. La solution constante est $y = \frac{2}{0{,}5} = 4$, donc $y = Ce^{-0{,}5x} + 4$ ; $y(0) = C + 4 = 0$ donne $C = -4$ : $y = 4 - 4e^{-0{,}5x}$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. L’équation $y' = ay + f$</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété :</strong> si $y_p$ est une solution particulière de $y' = ay + f$, les solutions sont les fonctions $y_p + Ce^{ax}$ : « solution particulière + solutions de $y' = ay$ ».</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $y' = 2y - 4x$. On cherche une solution affine $y_p = \alpha x + \beta$ : $\alpha = 2(\alpha x + \beta) - 4x$ impose $2\alpha - 4 = 0$ et $\alpha = 2\beta$, soit $\alpha = 2$, $\beta = 1$. Les solutions sont $y = Ce^{2x} + 2x + 1$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> on utilise la condition initiale <strong>après</strong> avoir écrit la solution générale complète (avec la solution particulière), jamais sur la seule partie $Ce^{ax}$.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Modéliser</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;"><strong>Loi de refroidissement de Newton :</strong> un café à $90$ °C refroidit dans une pièce à $20$ °C selon $T' = -0{,}1(T - 20)$ ($t$ en minutes), soit $T' = -0{,}1T + 2$. La solution constante est $20$, donc $T(t) = 20 + Ce^{-0{,}1t}$ et $T(0) = 90$ donne $C = 70$.</p>
        [IMAGE_2]
        <p style="font-size:1em;">Le café atteint $40$ °C quand $70e^{-0{,}1t} = 20$, soit $t = 10\ln 3{,}5 \approx 12{,}5$ minutes ; sa température tend vers $20$ °C.</p>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $y' = ay \iff y = Ce^{ax}$ ; $y' = ay + b \iff y = Ce^{ax} - \frac{b}{a}$ ; $y' = ay + f$ : solution particulière $+ Ce^{ax}$ ; une condition initiale détermine $C$ et donc une unique solution. Fiche de synthèse dans l’onglet Fiches !</p>
    </div>
