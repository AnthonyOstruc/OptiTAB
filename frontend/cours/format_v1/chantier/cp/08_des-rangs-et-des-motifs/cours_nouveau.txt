Titre: Les nombres ordinaux : rangs et suites de motifs

<!-- optitab:1 -->
::: objectifs
Je trouve une position et je prolonge un motif.
:::

## I. Le rang

::: definition
Le rang indique une position. Je dois connaître le départ et le sens. Je touche chaque place en comptant.
:::

Le groupe A B se répète. La cinquième lettre est A.

## III. Prolonger un motif

::: propriete
Je cherche le petit groupe qui se répète. Dans A B A B A B, le groupe A B se répète. La cinquième lettre est A.
:::

::: methode Pour réussir
Je distingue le rang et la quantité. Le cinquième a quatre personnes devant lui.
:::

::: exemple
Dans A B C A B C, la quatrième lettre est A. Changer le départ peut changer le rang.
:::

::: attention
Le rang change si je change le départ.
:::

::: retenir
Dans A B C A B C, la quatrième lettre est A. Changer le départ peut changer le rang.
:::
