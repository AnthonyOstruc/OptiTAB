Titre: Résumé : Calculer avec les nombres relatifs

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : addition et soustraction, règle des signes, produit de plusieurs facteurs, division, priorités opératoires. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Addition et soustraction</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Même signe</strong> : on additionne les distances à zéro, on garde le signe : $(-7) + (-5) = -12$.</p>
<p style="margin:6px 0 0 0;">• <strong>Signes contraires</strong> : on soustrait les distances à zéro, signe du « plus loin de zéro » : $(-7) + 5 = -2$.</p>
<p style="margin:6px 0 0 0;">• <strong>Soustraire = ajouter l'opposé</strong> : $-4 - (-9) = -4 + 9 = 5$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Multiplication et division</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• <strong>Deux facteurs</strong> : même signe → positif ; signes contraires → négatif : $(-4) \times (-2{,}5) = 10$ ; $(-3) \times 5 = -15$.</p>
<p style="margin:6px 0 0 0;">• <strong>Plusieurs facteurs</strong> : nombre <strong>pair</strong> de facteurs négatifs → positif ; <strong>impair</strong> → négatif. Un facteur nul → produit nul.</p>
<p style="margin:6px 0 0 0;">• <strong>Quotient</strong> : même règle des signes : $(-54) : (-9) = 6$ ; $\displaystyle \frac{-35}{7} = -5$.</p>
<p style="margin:6px 0 0 0;">• <strong>Division par zéro</strong> : impossible. Mais $0 : (-12) = 0$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Priorités opératoires</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">• $6 - 2 \times (-3 + 7) = 6 - 2 \times 4 = 6 - 8 = -2$ : une ligne par étape.</p>
<p style="margin:6px 0 0 0;">• $24 : (-6) \times 2 = -4 \times 2 = -8$ : × et : <strong>de gauche à droite</strong>.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Appliquer la règle des signes du produit à une addition : $-4 - 3 = -7$ (et non $7$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier un facteur négatif en comptant les signes d'un long produit.</p>
<p style="margin:6px 0 0 0;">3️⃣ Calculer $24 : (-6) \times 2$ en commençant par le produit.</p>
<p style="margin:6px 0 0 0;">4️⃣ Écrire un résultat pour une division par zéro.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> avant de calculer un produit ou un quotient, je décide d'abord du <strong>signe</strong>, puis je calcule avec les distances à zéro ; dans un problème, valeur finale = valeur initiale + variation.</p>
</div>
