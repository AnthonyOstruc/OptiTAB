    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Représentation paramétrique d'une droite</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Représentation paramétrique d'une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une droite $\displaystyle (d)$ de l'espace est déterminée par un point $\displaystyle A(x_0, y_0, z_0)$ et un vecteur directeur $\displaystyle \vec{u} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$ non nul.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>représentation paramétrique</strong> de la droite $\displaystyle (d)$ est :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle (d) : \begin{cases} x = x_0 + at \\ y = y_0 + bt \\ z = z_0 + ct \end{cases} \quad , \quad t \in \mathbb{R}$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Remarques importantes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.6; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le paramètre $\displaystyle t$ parcourt $\displaystyle \mathbb{R}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour $\displaystyle t = 0$, on obtient le point $\displaystyle A$</li>
                <li style="margin:0; text-align:left;">Une droite admet une infinité de représentations paramétriques (on peut choisir n'importe quel point de la droite et n'importe quel vecteur directeur non nul)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Droite passant par $\displaystyle A(1, 2, -3)$ et de vecteur directeur $\displaystyle \vec{u} = \begin{pmatrix} 2 \\ -1 \\ 4 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (d) : \begin{cases} x = 1 + 2t \\ y = 2 - t \\ z = -3 + 4t \end{cases} \quad , \quad t \in \mathbb{R}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Déterminer une représentation paramétrique d'une droite</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer une représentation paramétrique d'une droite, on a besoin :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>D'un point de la droite</strong> : $\displaystyle A(x_0, y_0, z_0)$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>D'un vecteur directeur</strong> : $\displaystyle \vec{u} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$ (non nul)</li>
                <li style="margin:0; text-align:left;">On applique alors la formule : $\displaystyle \begin{cases} x = x_0 + at \\ y = y_0 + bt \\ z = z_0 + ct \end{cases}$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Avec deux points</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Déterminer une représentation paramétrique de la droite passant par $\displaystyle A(1, 2, 3)$ et $\displaystyle B(4, 5, 6)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Point : $\displaystyle A(1, 2, 3)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Vecteur directeur : $\displaystyle \overrightarrow{AB} = \begin{pmatrix} 4-1 \\ 5-2 \\ 6-3 \end{pmatrix} = \begin{pmatrix} 3 \\ 3 \\ 3 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Représentation paramétrique :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (d) : \begin{cases} x = 1 + 3t \\ y = 2 + 3t \\ z = 3 + 3t \end{cases} \quad , \quad t \in \mathbb{R}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Reconnaître une droite donnée par une représentation paramétrique</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour reconnaître une droite donnée par une représentation paramétrique :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Identifier le point $\displaystyle A$ (obtenu pour $\displaystyle t = 0$)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Identifier le vecteur directeur $\displaystyle \vec{u}$ (coefficients de $\displaystyle t$)</li>
                <li style="margin:0; text-align:left;">Vérifier qu'un point donné appartient à la droite en substituant ses coordonnées dans le système</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (d) : \begin{cases} x = 3 - 2t \\ y = 1 + t \\ z = -2 + 3t \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Point de la droite : $\displaystyle A(3, 1, -2)$ (pour $\displaystyle t = 0$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Vecteur directeur : $\displaystyle \vec{u} = \begin{pmatrix} -2 \\ 1 \\ 3 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Vérifier si $\displaystyle M(1, 2, 4)$ appartient à la droite :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">On résout : $\displaystyle \begin{cases} 1 = 3 - 2t \\ 2 = 1 + t \\ 4 = -2 + 3t \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">De la deuxième équation : $\displaystyle t = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle x = 3 - 2 \times 1 = 1$ ✓ et $\displaystyle z = -2 + 3 \times 1 = 1 \neq 4$ ✗</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle M$ n'appartient pas à la droite.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Équation cartésienne d'un plan</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Équation cartésienne d'un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un plan $\displaystyle \mathcal{P}$ de l'espace admet une <strong>équation cartésienne</strong> de la forme :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle ax + by + cz + d = 0$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle (a, b, c) \neq (0, 0, 0)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le vecteur $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$ est un <strong>vecteur normal</strong> au plan $\displaystyle \mathcal{P}$.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Équation cartésienne du plan normal au vecteur $\displaystyle \vec{n}$ et passant par le point $\displaystyle A$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \mathcal{P}$ un plan passant par le point $\displaystyle A(x_0, y_0, z_0)$ et de vecteur normal $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation cartésienne de $\displaystyle \mathcal{P}$ est :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$</p>
            </div>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration (exigible au Bac) :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un point $\displaystyle M(x, y, z)$ appartient au plan $\displaystyle \mathcal{P}$ si et seulement si le vecteur $\displaystyle \overrightarrow{AM}$ est orthogonal au vecteur normal $\displaystyle \vec{n}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Or $\displaystyle \overrightarrow{AM} = \begin{pmatrix} x - x_0 \\ y - y_0 \\ z - z_0 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La condition d'orthogonalité s'écrit :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \vec{n} \cdot \overrightarrow{AM} = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$ ✓</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En développant, on obtient la forme $\displaystyle ax + by + cz + d = 0$ avec $\displaystyle d = -(ax_0 + by_0 + cz_0)$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Déterminer l'équation cartésienne d'un plan</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode : Avec un point et un vecteur normal</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si le plan passe par $\displaystyle A(x_0, y_0, z_0)$ et admet $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$ comme vecteur normal :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Écrire : $\displaystyle a(x - x_0) + b(y - y_0) + c(z - z_0) = 0$</li>
                <li style="margin:0; text-align:left;">Développer pour obtenir la forme $\displaystyle ax + by + cz + d = 0$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Déterminer l'équation cartésienne du plan passant par $\displaystyle A(1, 2, -1)$ et de vecteur normal $\displaystyle \vec{n} = \begin{pmatrix} 3 \\ -1 \\ 2 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 3(x - 1) + (-1)(y - 2) + 2(z - (-1)) = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 3x - 3 - y + 2 + 2z + 2 = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 3x - y + 2z + 1 = 0$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Reconnaître un plan donné par une équation cartésienne</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour reconnaître un plan donné par une équation cartésienne $\displaystyle ax + by + cz + d = 0$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Identifier le vecteur normal : $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Trouver un point du plan (par exemple, si $\displaystyle a \neq 0$, prendre $\displaystyle y = z = 0$ et résoudre pour $\displaystyle x$)</li>
                <li style="margin:0; text-align:left;">Vérifier qu'un point donné appartient au plan en substituant ses coordonnées dans l'équation</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit le plan $\displaystyle \mathcal{P} : 2x - 3y + z - 5 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Vecteur normal : $\displaystyle \vec{n} = \begin{pmatrix} 2 \\ -3 \\ 1 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Point du plan : pour $\displaystyle y = z = 0$, on a $\displaystyle 2x - 5 = 0$, donc $\displaystyle x = \frac{5}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A\left(\frac{5}{2}, 0, 0\right)$ appartient au plan.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Projeté orthogonal d'un point</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Projeté orthogonal sur un plan</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Projeté orthogonal sur un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>projeté orthogonal</strong> d'un point $\displaystyle M$ sur un plan $\displaystyle \mathcal{P}$ est le point $\displaystyle H$ du plan tel que la droite $\displaystyle (MH)$ est perpendiculaire au plan.</p>
        </div>

        [IMAGE_4]

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode : Déterminer les coordonnées du projeté orthogonal</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer le projeté orthogonal $\displaystyle H$ d'un point $\displaystyle M$ sur un plan $\displaystyle \mathcal{P}$ d'équation $\displaystyle ax + by + cz + d = 0$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le vecteur $\displaystyle \overrightarrow{MH}$ est colinéaire au vecteur normal $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Il existe $\displaystyle t \in \mathbb{R}$ tel que $\displaystyle H = M + t\vec{n}$, donc :</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle H(x_M + ta, y_M + tb, z_M + tc)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle H$ appartient au plan, donc : $\displaystyle a(x_M + ta) + b(y_M + tb) + c(z_M + tc) + d = 0$</li>
                <li style="margin:0; text-align:left;">Résoudre cette équation pour trouver $\displaystyle t$, puis calculer les coordonnées de $\displaystyle H$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle M(2, 1, 3)$ et le plan $\displaystyle \mathcal{P} : x + 2y - z + 1 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Vecteur normal : $\displaystyle \vec{n} = \begin{pmatrix} 1 \\ 2 \\ -1 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Le projeté $\displaystyle H$ est de la forme : $\displaystyle H(2 + t, 1 + 2t, 3 - t)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Comme $\displaystyle H \in \mathcal{P}$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (2 + t) + 2(1 + 2t) - (3 - t) + 1 = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 2 + t + 2 + 4t - 3 + t + 1 = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 6t + 2 = 0 \Rightarrow t = -\frac{1}{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Donc $\displaystyle H\left(2 - \frac{1}{3}, 1 - \frac{2}{3}, 3 + \frac{1}{3}\right) = H\left(\frac{5}{3}, \frac{1}{3}, \frac{10}{3}\right)$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Projeté orthogonal sur une droite</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Projeté orthogonal sur une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>projeté orthogonal</strong> d'un point $\displaystyle M$ sur une droite $\displaystyle (d)$ passant par $\displaystyle A$ et de vecteur directeur $\displaystyle \vec{u}$ est le point $\displaystyle H$ de la droite tel que $\displaystyle \overrightarrow{MH}$ est orthogonal à $\displaystyle \vec{u}$.</p>
        </div>

        [IMAGE_5]

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode : Déterminer les coordonnées du projeté orthogonal</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer le projeté orthogonal $\displaystyle H$ d'un point $\displaystyle M$ sur une droite $\displaystyle (d)$ passant par $\displaystyle A$ et de vecteur directeur $\displaystyle \vec{u}$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle H$ appartient à la droite, donc il existe $\displaystyle t \in \mathbb{R}$ tel que :</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle H = A + t\vec{u}$, donc $\displaystyle H(x_A + tu_1, y_A + tu_2, z_A + tu_3)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le vecteur $\displaystyle \overrightarrow{MH} = \overrightarrow{AH} - \overrightarrow{AM}$ est orthogonal à $\displaystyle \vec{u}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Condition d'orthogonalité : $\displaystyle \overrightarrow{MH} \cdot \vec{u} = 0$</li>
                <li style="margin:0; text-align:left;">Résoudre cette équation pour trouver $\displaystyle t$, puis calculer les coordonnées de $\displaystyle H$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle M(3, 2, 1)$ et la droite $\displaystyle (d)$ passant par $\displaystyle A(1, 0, -1)$ et de vecteur directeur $\displaystyle \vec{u} = \begin{pmatrix} 2 \\ 1 \\ 1 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Le projeté $\displaystyle H$ est de la forme : $\displaystyle H(1 + 2t, t, -1 + t)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• On a $\displaystyle \overrightarrow{MH} = \begin{pmatrix} 1 + 2t - 3 \\ t - 2 \\ -1 + t - 1 \end{pmatrix} = \begin{pmatrix} 2t - 2 \\ t - 2 \\ t - 2 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Condition d'orthogonalité :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \overrightarrow{MH} \cdot \vec{u} = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 2(2t - 2) + 1(t - 2) + 1(t - 2) = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 4t - 4 + t - 2 + t - 2 = 0 \Rightarrow 6t - 8 = 0 \Rightarrow t = \frac{4}{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Donc $\displaystyle H\left(1 + \frac{8}{3}, \frac{4}{3}, -1 + \frac{4}{3}\right) = H\left(\frac{11}{3}, \frac{4}{3}, \frac{1}{3}\right)$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Systèmes d'équations linéaires et problèmes géométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Traduire des problèmes géométriques par des systèmes</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Capacité attendue au programme :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un cadre géométrique repéré, traduire par un système d'équations linéaires des problèmes de types suivants :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Décider si trois vecteurs forment une base</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Déterminer les coordonnées d'un vecteur dans une base</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Étudier une configuration dans l'espace</strong> : alignement, colinéarité, parallélisme, coplanarité, intersection et orthogonalité de droites ou de plans</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans des cas simples, résoudre le système obtenu et interpréter géométriquement les solutions.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Décider si trois vecteurs forment une base</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Trois vecteurs $\displaystyle \vec{u}$, $\displaystyle \vec{v}$, $\displaystyle \vec{w}$ forment une base de $\displaystyle \mathbb{R}^3$ si et seulement s'ils sont non coplanaires, c'est-à-dire si la seule solution de $\displaystyle \alpha\vec{u} + \beta\vec{v} + \gamma\vec{w} = \vec{0}$ est $\displaystyle \alpha = \beta = \gamma = 0$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 2 \\ 1 \end{pmatrix}$, $\displaystyle \vec{v} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$, $\displaystyle \vec{w} = \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle \alpha, \beta, \gamma$ tels que : $\displaystyle \alpha\vec{u} + \beta\vec{v} + \gamma\vec{w} = \vec{0}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela donne le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \begin{cases} \alpha + 2\beta + 3\gamma = 0 \\ 2\alpha - \beta + \gamma = 0 \\ \alpha + 3\beta + 4\gamma = 0 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En résolvant ce système (par substitution ou combinaison), on trouve que la seule solution est $\displaystyle \alpha = \beta = \gamma = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc les trois vecteurs forment une base de $\displaystyle \mathbb{R}^3$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Déterminer les coordonnées d'un vecteur dans une base</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour exprimer un vecteur $\displaystyle \vec{w}$ dans la base $\displaystyle (\vec{u}, \vec{v}, \vec{p})$, on cherche $\displaystyle \alpha, \beta, \gamma$ tels que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \vec{w} = \alpha\vec{u} + \beta\vec{v} + \gamma\vec{p}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela donne un système de trois équations à trois inconnues.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix}$, $\displaystyle \vec{v} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}$, $\displaystyle \vec{p} = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}$ et $\displaystyle \vec{w} = \begin{pmatrix} 3 \\ 2 \\ 1 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle \alpha, \beta, \gamma$ tels que : $\displaystyle \vec{w} = \alpha\vec{u} + \beta\vec{v} + \gamma\vec{p}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela donne :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \begin{cases} 3 = \alpha + 0\beta + \gamma = \alpha + \gamma \\ 2 = 0\alpha + \beta + \gamma = \beta + \gamma \\ 1 = \alpha + \beta + 0\gamma = \alpha + \beta \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En résolvant, on trouve : $\displaystyle \alpha = 1$, $\displaystyle \beta = 0$, $\displaystyle \gamma = 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle \vec{w} = \vec{u} + 2\vec{p}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Étudier des configurations dans l'espace</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Alignement de trois points</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle A(1, 2, 3)$, $\displaystyle B(2, 4, 5)$, $\displaystyle C(3, 6, 7)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les points sont alignés si et seulement si les vecteurs $\displaystyle \overrightarrow{AB}$ et $\displaystyle \overrightarrow{AC}$ sont colinéaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• $\displaystyle \overrightarrow{AB} = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}$ et $\displaystyle \overrightarrow{AC} = \begin{pmatrix} 2 \\ 4 \\ 4 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• On cherche $\displaystyle k \in \mathbb{R}$ tel que $\displaystyle \overrightarrow{AC} = k\overrightarrow{AB}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Cela donne : $\displaystyle \begin{cases} 2 = k \times 1 \\ 4 = k \times 2 \\ 4 = k \times 2 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• On trouve $\displaystyle k = 2$ qui vérifie toutes les équations</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Conclusion : $\displaystyle \overrightarrow{AC} = 2\overrightarrow{AB}$, donc les points sont alignés</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Parallélisme de deux droites</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (d_1)$ de vecteur directeur $\displaystyle \vec{u_1} = \begin{pmatrix} 2 \\ 1 \\ -1 \end{pmatrix}$ et $\displaystyle (d_2)$ de vecteur directeur $\displaystyle \vec{u_2} = \begin{pmatrix} 4 \\ 2 \\ -2 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les droites sont parallèles si et seulement si $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ sont colinéaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• On cherche $\displaystyle k \in \mathbb{R}$ tel que $\displaystyle \vec{u_2} = k\vec{u_1}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• On trouve $\displaystyle k = 2$ qui vérifie le système</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Conclusion : les droites sont parallèles</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Intersection de deux droites</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (d_1) : \begin{cases} x = 1 + 2t \\ y = 3 - t \\ z = -1 + t \end{cases}$ et $\displaystyle (d_2) : \begin{cases} x = 2 + s \\ y = 1 + 2s \\ z = 3s \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour trouver l'intersection, on cherche $\displaystyle t, s \in \mathbb{R}$ tels que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \begin{cases} 1 + 2t = 2 + s \\ 3 - t = 1 + 2s \\ -1 + t = 3s \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En résolvant ce système, on vérifie s'il admet une solution unique (droites sécantes), une infinité (confondues) ou aucune (non coplanaires).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Orthogonalité de deux vecteurs</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 2 \\ 3 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} 2 \\ -1 \\ 0 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs sont orthogonaux si et seulement si $\displaystyle \vec{u} \cdot \vec{v} = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• $\displaystyle \vec{u} \cdot \vec{v} = 1 \times 2 + 2 \times (-1) + 3 \times 0 = 2 - 2 + 0 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">• Conclusion : les vecteurs sont orthogonaux</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Positions relatives</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Positions relatives de deux droites</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Positions relatives de deux droites</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle (d_1)$ et $\displaystyle (d_2)$ deux droites de vecteurs directeurs respectifs $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Parallèles distinctes :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ colinéaires, aucun point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondues :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ colinéaires, au moins un point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Sécantes :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ non colinéaires, un point commun (unique)</li>
                <li style="margin:0; text-align:left;"><strong>Non coplanaires :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ non colinéaires, aucun point commun</li>
            </ul>
        </div>

        <h3 style="color:#34495e; margin-top:0;">Positions relatives d'une droite et d'un plan</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">

                <li style="margin:0; text-align:left;"><strong>Perpendiculaire :</strong> $\displaystyle \vec{u}$ et $\displaystyle \vec{n}$ colinéaires</li>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. 🌟 Approfondissements possibles</h2>

    <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:15px; margin:15px 0;">
        <p style="margin:0; text-align:left; font-size:1em;"><strong>🌟 Approfondissements :</strong> Les sections suivantes enrichissent votre culture mathématique mais ne sont pas strictement exigibles pour le Bac.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Déterminer l'intersection de deux plans</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer l'intersection de deux plans sécants $\displaystyle \mathcal{P}_1 : a_1x + b_1y + c_1z + d_1 = 0$ et $\displaystyle \mathcal{P}_2 : a_2x + b_2y + c_2z + d_2 = 0$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre le système des deux équations</li>
                <li style="margin:0 0 12px 0; text-align:left;">Exprimer deux variables en fonction d'une troisième (paramètre libre)</li>
                <li style="margin:0; text-align:left;">Obtenir une représentation paramétrique de la droite d'intersection</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \mathcal{P}_1 : x + y + z - 1 = 0$ et $\displaystyle \mathcal{P}_2 : 2x - y + z + 3 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Système : $\displaystyle \begin{cases} x + y + z = 1 \\ 2x - y + z = -3 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En soustrayant : $\displaystyle x - 2y = -4 \Rightarrow x = 2y - 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En remplaçant : $\displaystyle (2y - 4) + y + z = 1 \Rightarrow z = 5 - 3y$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Droite d'intersection : $\displaystyle \begin{cases} x = 2t - 4 \\ y = t \\ z = 5 - 3t \end{cases} \quad , \quad t \in \mathbb{R}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Déterminer un vecteur orthogonal à deux vecteurs non colinéaires</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Méthode : Produit vectoriel</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer un vecteur orthogonal à deux vecteurs non colinéaires $\displaystyle \vec{u} = \begin{pmatrix} u_1 \\ u_2 \\ u_3 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} v_1 \\ v_2 \\ v_3 \end{pmatrix}$, on peut utiliser le <strong>produit vectoriel</strong> :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \wedge \vec{v} = \begin{pmatrix} u_2v_3 - u_3v_2 \\ u_3v_1 - u_1v_3 \\ u_1v_2 - u_2v_1 \end{pmatrix}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce vecteur est orthogonal à $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 2 \\ 1 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{u} \wedge \vec{v} = \begin{pmatrix} 2 \times 3 - 1 \times (-1) \\ 1 \times 2 - 1 \times 3 \\ 1 \times (-1) - 2 \times 2 \end{pmatrix} = \begin{pmatrix} 7 \\ -1 \\ -5 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On vérifie : $\displaystyle \vec{u} \cdot (\vec{u} \wedge \vec{v}) = 1 \times 7 + 2 \times (-1) + 1 \times (-5) = 0$ ✓</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Et $\displaystyle \vec{v} \cdot (\vec{u} \wedge \vec{v}) = 2 \times 7 + (-1) \times (-1) + 3 \times (-5) = 0$ ✓</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Équation d'une sphère</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Équation d'une sphère</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>sphère</strong> de centre $\displaystyle \Omega(x_0, y_0, z_0)$ et de rayon $\displaystyle R$ a pour équation :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle (x - x_0)^2 + (y - y_0)^2 + (z - z_0)^2 = R^2$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En développant, on obtient : $\displaystyle x^2 + y^2 + z^2 - 2x_0x - 2y_0y - 2z_0z + (x_0^2 + y_0^2 + z_0^2 - R^2) = 0$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Sphère de centre $\displaystyle \Omega(1, -2, 3)$ et de rayon $\displaystyle R = 4$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (x - 1)^2 + (y + 2)^2 + (z - 3)^2 = 16$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">Développé : $\displaystyle x^2 + y^2 + z^2 - 2x + 4y - 6z - 2 = 0$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Intersection d'une sphère et d'une droite</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer l'intersection d'une sphère et d'une droite :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Remplacer les coordonnées paramétriques de la droite dans l'équation de la sphère</li>
                <li style="margin:0 0 12px 0; text-align:left;">Obtenir une équation du second degré en $\displaystyle t$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre cette équation</li>
                <li style="margin:0; text-align:left;">Interpréter géométriquement : 0 solution (pas d'intersection), 1 solution (tangente), 2 solutions (sécante)</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Sphère : $\displaystyle x^2 + y^2 + z^2 = 9$ (centre $\displaystyle O$, rayon $\displaystyle 3$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Droite : $\displaystyle \begin{cases} x = 1 + 2t \\ y = 2 + t \\ z = 1 + t \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Substitution : $\displaystyle (1 + 2t)^2 + (2 + t)^2 + (1 + t)^2 = 9$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 1 + 4t + 4t^2 + 4 + 4t + t^2 + 1 + 2t + t^2 = 9$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 6t^2 + 10t - 3 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le discriminant est $\displaystyle \Delta = 100 + 72 = 172 > 0$, donc deux points d'intersection (la droite est sécante à la sphère).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre vecteur directeur et vecteur normal</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier que deux vecteurs directeurs d'un plan doivent être non colinéaires</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas vérifier que $\displaystyle \vec{u} \cdot \vec{n} \neq 0$ avant de chercher une intersection droite-plan</li>
                <li style="margin:0 0 12px 0; text-align:left;">Penser qu'une représentation paramétrique est unique</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de vérifier la cohérence d'un système lors de la recherche d'intersection</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre parallélisme et orthogonalité</li>
                <li style="margin:0; text-align:left;">Se tromper dans le calcul du produit scalaire pour l'orthogonalité</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Toujours identifier clairement les vecteurs directeurs et normaux</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier systématiquement la non-colinéarité des vecteurs directeurs d'un plan</li>
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser le produit scalaire pour déterminer l'orthogonalité</li>
                <li style="margin:0 0 12px 0; text-align:left;">Faire des vérifications : un point connu doit vérifier les équations</li>
                <li style="margin:0 0 12px 0; text-align:left;">Bien distinguer les cas : parallèle/sécant/confondu selon le contexte</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les systèmes, toujours vérifier la cohérence des solutions</li>
                <li style="margin:0; text-align:left;">Interpréter géométriquement les résultats obtenus</li>
            </ul>
        </div>
    </div>
