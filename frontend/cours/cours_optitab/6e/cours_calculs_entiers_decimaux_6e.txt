    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. L'addition</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Addition de nombres entiers</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Technique posée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour additionner deux nombres entiers, on les pose l'un sous l'autre en <strong>alignant les chiffres</strong> (unités sous unités, dizaines sous dizaines, etc.).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : 234 + 567</strong>

                            <td style="width:30px; text-align:center; padding:2px 8px; color:#e67e22; font-size:0.75em; font-weight:700;">1</td>

            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On additionne les unités : 4 + 7 = 11 → on écrit 1 et on retient 1</li>
                <li style="margin:0 0 12px 0; text-align:left;">On additionne les dizaines : 3 + 6 + 1 (retenue) = 10 → on écrit 0 et on retient 1</li>
                <li style="margin:0; text-align:left;">On additionne les centaines : 2 + 5 + 1 (retenue) = 8</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Quand on obtient un résultat supérieur à 9 dans une colonne, on écrit le chiffre des unités et on <strong>retient</strong> le chiffre des dizaines pour l'ajouter à la colonne suivante.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Addition de nombres décimaux</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Technique posée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour additionner deux nombres décimaux, on les pose l'un sous l'autre en <strong>alignant les virgules</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut compléter avec des zéros si nécessaire pour avoir le même nombre de chiffres après la virgule.</p>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. La soustraction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Soustraction de nombres entiers</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Technique posée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour soustraire deux nombres entiers, on pose le <strong>plus petit sous le plus grand</strong> en alignant les chiffres.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : 567 - 234</strong>
            <div style="text-align:center; margin:15px 0;">
                <div style="background:#ffffff; border:2px solid #3498db; border-radius:8px; padding:20px; display:inline-block;">
                    <table style="margin:0 auto; font-family:'Courier New', monospace; font-size:1.4em; border-collapse:collapse;">

                        </tr>
                        <tr>
                            <td style="text-align:right; padding:5px 8px;">-</td>
                            <td style="text-align:center; padding:5px 8px;">2</td>
                            <td style="text-align:center; padding:5px 8px;">3</td>
                            <td style="text-align:center; padding:5px 8px;">4</td>
                        </tr>
                        <tr style="border-top:2px solid #3498db;">
                            <td style="text-align:right; padding:8px 8px 0 8px;">&nbsp;</td>
                            <td style="text-align:center; padding:8px 8px 0 8px;"><strong>3</strong></td>
                            <td style="text-align:center; padding:8px 8px 0 8px;"><strong>3</strong></td>
                            <td style="text-align:center; padding:8px 8px 0 8px;"><strong>3</strong></td>
                        </tr>
                    </table>
                </div>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On soustrait les unités : 7 - 4 = 3</li>
                <li style="margin:0 0 12px 0; text-align:left;">On soustrait les dizaines : 6 - 3 = 3</li>
                <li style="margin:0; text-align:left;">On soustrait les centaines : 5 - 2 = 3</li>
            </ul>
        </div>

        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. La multiplication</h2>

                        <tr style="border-top:2px solid #3498db;">

                            <td style="text-align:right; padding:8px 8px 0 8px;"><strong>8</strong></td>
                        </tr>
                    </table>
                </div>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On multiplie 234 par 2 (unités) : 234 × 2 = 468</li>
                <li style="margin:0 0 12px 0; text-align:left;">On multiplie 234 par 1 (dizaines) : 234 × 10 = 2 340 (on décale d'un rang vers la gauche)</li>
                <li style="margin:0; text-align:left;">On additionne les deux résultats : 468 + 2 340 = 2 808</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Quand on multiplie par les dizaines, centaines, etc., on décale le résultat d'un, deux, trois... rangs vers la gauche (on ajoute des zéros).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Calcul mental</h2>

        <h3 style="color:#34495e; margin-top:0;">Compléments à 10, 100, 1 000</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Compléments à 10</strong></p>

            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">

                <li style="margin:0 0 12px 0; text-align:left;">Complément à 10 de <strong>4</strong> : 4 + ? = 10 → <strong>6</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Complément à 10 de <strong>9</strong> : 9 + ? = 10 → <strong>1</strong></li>
                <li style="margin:0; text-align:left;">Complément à 10 de <strong>2</strong> : 2 + ? = 10 → <strong>8</strong></li>

        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Compléments à 100</strong></p>

                <li style="margin:0 0 12px 0; text-align:left;">Complément à 100 de <strong>90</strong> : 90 + ? = 100 → <strong>10</strong></li>
                <li style="margin:0; text-align:left;">Complément à 100 de <strong>67</strong> : 67 + ? = 100 → <strong>33</strong></li>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Doubles et moitiés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le double</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>double</strong> d'un nombre, c'est ce nombre multiplié par 2.</p>

                <li style="margin:0 0 12px 0; text-align:left;">Moitié de <strong>24</strong> : 24 ÷ 2 = <strong>12</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Moitié de <strong>50</strong> : 50 ÷ 2 = <strong>25</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Moitié de <strong>7</strong> : 7 ÷ 2 = <strong>3,5</strong></li>
                <li style="margin:0; text-align:left;">Moitié de <strong>25</strong> : 25 ÷ 2 = <strong>12,5</strong></li>
            </ul>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour trouver la moitié d'un nombre pair, on divise par 2. Pour un nombre impair, on obtient un nombre décimal.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Multiplier et diviser par 10, 100, 1 000</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Multiplier par 10, 100, 1 000</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour multiplier un nombre par <strong>10</strong>, <strong>100</strong> ou <strong>1 000</strong>, on <strong>déplace la virgule</strong> vers la droite d'1, 2 ou 3 rangs.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si le nombre est entier, on ajoute des zéros.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Multiplier par 10 :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5</strong> × 10 = <strong>50</strong> (on ajoute un zéro)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> × 10 = <strong>123,4</strong> (virgule déplacée d'1 rang à droite)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,5</strong> × 10 = <strong>5</strong> (virgule déplacée d'1 rang à droite)</li>
                <li style="margin:0; text-align:left;"><strong>234</strong> × 10 = <strong>2 340</strong> (on ajoute un zéro)</li>
            </ul>
        </div>

            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5</strong> × 100 = <strong>500</strong> (on ajoute deux zéros)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> × 100 = <strong>1 234</strong> (virgule déplacée de 2 rangs à droite)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,5</strong> × 100 = <strong>50</strong> (virgule déplacée de 2 rangs à droite)</li>
                <li style="margin:0; text-align:left;"><strong>2,5</strong> × 100 = <strong>250</strong> (virgule déplacée de 2 rangs à droite)</li>

            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Multiplier par 10, 100, 1 000 revient à <strong>déplacer la virgule vers la droite</strong> d'1, 2 ou 3 rangs (ou ajouter des zéros pour les nombres entiers).</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Diviser par 10, 100, 1 000</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour diviser un nombre par <strong>10</strong>, <strong>100</strong> ou <strong>1 000</strong>, on <strong>déplace la virgule</strong> vers la gauche d'1, 2 ou 3 rangs.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si nécessaire, on ajoute des zéros avant le nombre.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Diviser par 10 :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>50</strong> ÷ 10 = <strong>5</strong> (virgule déplacée d'1 rang à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>123,4</strong> ÷ 10 = <strong>12,34</strong> (virgule déplacée d'1 rang à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5</strong> ÷ 10 = <strong>0,5</strong> (on ajoute un zéro avant)</li>
                <li style="margin:0; text-align:left;"><strong>234</strong> ÷ 10 = <strong>23,4</strong> (virgule déplacée d'1 rang à gauche)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Diviser par 100 :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>500</strong> ÷ 100 = <strong>5</strong> (virgule déplacée de 2 rangs à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>1 234</strong> ÷ 100 = <strong>12,34</strong> (virgule déplacée de 2 rangs à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5</strong> ÷ 100 = <strong>0,05</strong> (on ajoute deux zéros avant)</li>
                <li style="margin:0; text-align:left;"><strong>250</strong> ÷ 100 = <strong>2,5</strong> (virgule déplacée de 2 rangs à gauche)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Diviser par 1 000 :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5 000</strong> ÷ 1 000 = <strong>5</strong> (virgule déplacée de 3 rangs à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12 340</strong> ÷ 1 000 = <strong>12,34</strong> (virgule déplacée de 3 rangs à gauche)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5</strong> ÷ 1 000 = <strong>0,005</strong> (on ajoute trois zéros avant)</li>
                <li style="margin:0; text-align:left;"><strong>2 050</strong> ÷ 1 000 = <strong>2,05</strong> (virgule déplacée de 3 rangs à gauche)</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Diviser par 10, 100, 1 000 revient à <strong>déplacer la virgule vers la gauche</strong> d'1, 2 ou 3 rangs. Si nécessaire, on ajoute des zéros avant le nombre.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Résoudre des problèmes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Problèmes avec plusieurs opérations</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre un problème, on suit ces étapes :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire</strong> attentivement l'énoncé</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Repérer</strong> les informations importantes (nombres, questions)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Choisir</strong> l'opération (ou les opérations) à effectuer</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Effectuer</strong> le calcul</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> que la réponse est cohérente</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Lucas a 25 €. Il achète un livre à 12,50 € et un stylo à 3,75 €. Combien lui reste-t-il ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Étape 1</strong> : Calculer le total des achats : 12,50 + 3,75 = 16,25 €</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Étape 2</strong> : Calculer ce qui reste : 25 - 16,25 = 8,75 €</li>
                <li style="margin:0; text-align:left;"><strong>Réponse</strong> : Il lui reste <strong>8,75 €</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un magasin vend des cahiers par paquets de 10. Chaque paquet coûte 12 €. Combien coûtent 5 paquets ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Opération</strong> : 12 × 5 = 60</li>
                <li style="margin:0; text-align:left;"><strong>Réponse</strong> : 5 paquets coûtent <strong>60 €</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une classe de 28 élèves part en sortie. Le bus coûte 350 € au total. Combien chaque élève doit-il payer ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Opération</strong> : 350 ÷ 28</li>
                <li style="margin:0 0 12px 0; text-align:left;">350 ÷ 28 = 12,5 (on peut poser la division)</li>
                <li style="margin:0; text-align:left;"><strong>Réponse</strong> : Chaque élève doit payer <strong>12,50 €</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Marie a acheté 3 boîtes de 12 œufs chacune. Combien d'œufs a-t-elle au total ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Opération</strong> : 12 × 3 = 36</li>
                <li style="margin:0; text-align:left;"><strong>Réponse</strong> : Elle a <strong>36 œufs</strong> au total</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conseil :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un problème avec plusieurs opérations, on effectue les calculs <strong>étape par étape</strong>. On peut noter les résultats intermédiaires pour ne pas se tromper.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les additions/soustractions</strong> : toujours bien aligner les chiffres (ou les virgules pour les décimaux)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les multiplications</strong> : bien décaler les résultats intermédiaires</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour × 10, 100, 1 000</strong> : déplacer la virgule vers la droite (ou ajouter des zéros)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour ÷ 10, 100, 1 000</strong> : déplacer la virgule vers la gauche (ajouter des zéros si nécessaire)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les problèmes</strong> : lire attentivement, repérer les informations, choisir les bonnes opérations</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> toujours que le résultat est cohérent (un prix ne peut pas être négatif, etc.)</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas <strong>aligner les chiffres</strong> ou les virgules correctement</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier les <strong>retenues</strong> dans les additions</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier d'<strong>emprunter</strong> dans les soustractions</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas <strong>décaler</strong> les résultats dans les multiplications</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de <strong>placer la virgule</strong> dans les multiplications de décimaux</li>
                <li style="margin:0 0 12px 0; text-align:left;">Déplacer la virgule dans le <strong>mauvais sens</strong> (gauche au lieu de droite pour × 10, etc.)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ne pas <strong>compléter avec des zéros</strong> pour les décimaux avant d'opérer</li>
                <li style="margin:0; text-align:left;">Se tromper dans le <strong>choix de l'opération</strong> dans un problème (addition au lieu de soustraction, etc.)</li>
            </ul>
        </div>
    </div>
