Titre: Résumé : Géométrie dans l'espace

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : volumes des solides usuels, aire de la sphère, sections planes, réductions, repérage dans un pavé et sur la Terre. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les formules de volume</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:520px;">
<p style="margin:0; font-weight:bold;">Prisme, cylindre : $\displaystyle V = \mathcal{B} \times h$ &nbsp;&nbsp; Pyramide, cône : $\displaystyle V = \frac{\mathcal{B} \times h}{3}$</p>
<p style="margin:6px 0 0 0; font-weight:bold;">Boule : $\displaystyle V = \frac{4}{3}\pi r^3$ &nbsp;&nbsp; Sphère : $\displaystyle \mathcal{A} = 4\pi r^2$</p>
</div>
<p style="margin:0;">• Cylindre : $\displaystyle \mathcal{B} = \pi r^2$ ; diamètre → diviser par 2 pour le rayon.</p>
<p style="margin:6px 0 0 0;">• Solide assemblé : additionner ; solide creusé : soustraire.</p>
<p style="margin:6px 0 0 0;">• $\displaystyle 1\ \text{dm}^3 = 1\ \text{L}$ ; $\displaystyle 1\ \text{cm}^3 = 1\ \text{mL}$ ; $\displaystyle 1\ \text{m}^3 = 1\,000\ \text{L}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Sections et réductions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Pavé ou prisme, plan parallèle à une face → polygone <strong>identique</strong> à la face.</p>
<p style="margin:6px 0 0 0;">• Pyramide ou cône, plan parallèle à la base → <strong>réduction</strong> de la base.</p>
<p style="margin:6px 0 0 0;">• Sphère → <strong>cercle</strong> de rayon $\displaystyle r$ avec $\displaystyle r^2 = R^2 - d^2$.</p>
<p style="margin:6px 0 0 0;">• Réduction de rapport $\displaystyle k$ : longueurs $\displaystyle \times k$, aires $\displaystyle \times k^2$, volumes $\displaystyle \times k^3$ (mi-hauteur → volume $\displaystyle \div 8$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Se repérer</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Dans un pavé : $\displaystyle (x\ ;\ y\ ;\ z)$ = abscisse, ordonnée, altitude.</p>
<p style="margin:6px 0 0 0;">• Sur la Terre : (latitude ; longitude). Latitude 0° à 90° N ou S (depuis l'équateur) ; longitude 0° à 180° E ou O (depuis Greenwich).</p>
<p style="margin:6px 0 0 0;">• Même latitude → même parallèle ; même longitude → même méridien.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Utiliser le diamètre à la place du rayon.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier de diviser par 3 pour une pyramide ou un cône.</p>
<p style="margin:6px 0 0 0;">3️⃣ Prendre une arête ou la hauteur d'une face à la place de la hauteur du solide.</p>
<p style="margin:6px 0 0 0;">4️⃣ Arrondir $\displaystyle \pi$ trop tôt : garder $\displaystyle \pi$ jusqu'au résultat final.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> décomposer le solide en solides usuels, écrire les volumes en valeur exacte (avec $\displaystyle \pi$), additionner ou soustraire, puis convertir (en L) et arrondir à la fin ; pour une longueur cachée, chercher un triangle rectangle et appliquer Pythagore.</p>
</div>
