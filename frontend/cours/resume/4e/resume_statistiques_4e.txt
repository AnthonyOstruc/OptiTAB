<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Organiser et représenter</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Fréquence $= \frac{\text{effectif}}{\text{effectif total}}$ (en % : $\times 100$) ; la somme des fréquences vaut $100$ %.</p>
<p style="margin:6px 0 0 0;">• Diagramme circulaire : angle $=$ fréquence $\times 360°$.</p>
[IMAGE_1]
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Indicateurs</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Moyenne</strong> : somme des valeurs : nombre de valeurs. <strong>Pondérée</strong> : $\displaystyle \frac{\sum \text{valeur} \times \text{effectif}}{\text{effectif total}}$.</p>
<p style="margin:6px 0 0 0;">• <strong>Médiane</strong> : on RANGE la série ; valeur du milieu (ou moyenne des deux valeurs du milieu).</p>
[IMAGE_2]
<p style="margin:6px 0 0 0;">• <strong>Étendue</strong> : max $-$ min.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Chercher la médiane sans avoir rangé la série.</p>
<p style="margin:6px 0 0 0;">2️⃣ Faire la moyenne des valeurs d'un tableau sans tenir compte des effectifs.</p>
<p style="margin:6px 0 0 0;">3️⃣ Calculer la moyenne de deux moyennes de groupes de tailles différentes.</p>
<p style="margin:6px 0 0 0;">4️⃣ Se laisser tromper par un axe qui ne commence pas à $0$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je contrôle mes résultats : la moyenne et la médiane sont comprises entre la plus petite et la plus grande valeur ; les fréquences font $100$ % ; les angles font $360°$.</p>
</div>
