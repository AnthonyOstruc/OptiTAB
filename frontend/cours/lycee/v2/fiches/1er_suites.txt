<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Arithmétique ou géométrique ?</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ Arithmétique : $u_{n+1} = u_n + r$, $u_n = u_0 + nr = u_p + (n - p)r$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Géométrique : $u_{n+1} = q u_n$, $u_n = u_0 q^n$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Variations : signe de $u_{n+1} - u_n$ (ou de $r$ ; ou position de $q$ par rapport à $1$ si $u_0 \gt 0$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Sommes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$1 + 2 + \cdots + n = \frac{n(n + 1)}{2}$</p>
</div>
[IMAGE_2]
<p style="margin:0;">• Pour $q \neq 1$ : $1 + q + \cdots + q^n = \frac{1 - q^{n+1}}{1 - q}$.</p>
<p style="margin:6px 0 0 0;">• Hausse de $t\,\%$ chaque année → suite géométrique de raison $1 + \frac{t}{100}$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre $u_{n+1}$ (terme suivant) et $u_n + 1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $u_n = u_1 + nr$ quand la suite commence à $u_1$ : c’est $u_n = u_1 + (n - 1)r$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Mal compter les termes d’une somme : de $q^0$ à $q^n$, il y en a $n + 1$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Prendre $q = 0{,}03$ pour une hausse de $3\,\%$ au lieu de $q = 1{,}03$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je calcule $u_{n+1} - u_n$ et $\frac{u_{n+1}}{u_n}$ : différence constante → arithmétique, quotient constant → géométrique.</p>
</div>
