## I. Longueurs {Primaire}

[IMAGE_1]

| km | hm | dam | m | dm | cm | mm |
|---|---|---|---|---|---|---|
| 1 | 0 | 0 | **0** | | | |
| | | | **3** | 4 | 5 | |
| | | | **0** | 0 | 1 | 2 |

Lecture des lignes : $1$ km $= 1\,000$ m ; $\quad 3{,}45$ m $= 345$ cm ; $\quad 12$ mm $= 0{,}012$ m.

| Correspondance | Valeur |
|---|---|
| Kilomètre | 1 km = 1 000 m |
| Mètre | 1 m = 10 dm = 100 cm = 1 000 mm |
| Centimètre | 1 cm = 10 mm = 0,01 m |

::: methode Utiliser le tableau
On place le chiffre des **unités** du nombre dans la colonne de l’unité de départ (un chiffre par colonne), puis on lit le nombre dans la colonne de l’unité d’arrivée, en complétant par des zéros.
:::

## II. Masses {Primaire}

| kg | hg | dag | g | dg | cg | mg |
|---|---|---|---|---|---|---|
| **1** | 0 | 0 | 0 | | | |
| **0** | 2 | 5 | 0 | | | |
| | | | **3** | 5 | 0 | 0 |

Lecture : $1$ kg $= 1\,000$ g ; $\quad 250$ g $= 0{,}25$ kg ; $\quad 3{,}5$ g $= 3\,500$ mg.

| Correspondance | Valeur |
|---|---|
| Tonne | 1 t = 1 000 kg |
| Quintal | 1 q = 100 kg |
| Kilogramme | 1 kg = 1 000 g |
| Gramme | 1 g = 1 000 mg |

## III. Contenances (litres) {Primaire}

| hL | daL | L | dL | cL | mL |
|---|---|---|---|---|---|
| | | **1** | 5 | 0 | |
| | | **0** | 3 | 3 | |
| 1 | 0 | **0** | | | |

Lecture : $1{,}5$ L $= 150$ cL ; $\quad 33$ cL $= 0{,}33$ L ; $\quad 1$ hL $= 100$ L.

| Correspondance | Valeur |
|---|---|
| Hectolitre | 1 hL = 100 L |
| Litre | 1 L = 10 dL = 100 cL = 1 000 mL |
| Avec les volumes | 1 L = 1 dm³ et 1 mL = 1 cm³ |

## IV. Aires {Collège}

[IMAGE_2]

D’une unité d’aire à la suivante, on multiplie (ou on divise) par $100$ : deux chiffres par unité.

| Unité | En m² |
|---|---|
| 1 km² | 1 000 000 m² |
| 1 hm² = 1 hectare (ha) | 10 000 m² |
| 1 dam² = 1 are (a) | 100 m² |
| 1 m² = 1 centiare (ca) | 1 m² |
| 1 dm² | 0,01 m² |
| 1 cm² | 0,000 1 m² |
| 1 mm² | 0,000 001 m² |

::: attention Erreur fréquente
$1$ m² $= 100$ dm², et non $10$ dm² : un carré de $1$ m de côté contient $10 \times 10$ carrés de $1$ dm de côté.
:::

## V. Volumes {Collège}

D’une unité de volume à la suivante, on multiplie (ou on divise) par $1\,000$ : trois chiffres par unité.

| Unité | En m³ | En litres |
|---|---|---|
| 1 m³ | 1 m³ | 1 000 L |
| 1 dm³ | 0,001 m³ | 1 L |
| 1 cm³ | 0,000 001 m³ | 1 mL |
| 1 mm³ | 0,000 000 001 m³ | 0,001 mL |

::: exemple
Une piscine de $50$ m³ contient $50 \times 1\,000 = 50\,000$ litres d’eau.
:::

## VI. Durées {Primaire}

| Durée | Équivalence |
|---|---|
| 1 minute | 60 secondes |
| 1 heure | 60 minutes = 3 600 secondes |
| 1 jour | 24 heures = 1 440 minutes |
| 1 semaine | 7 jours |
| 1 année | 365 jours (366 les années bissextiles) |
| 1 siècle | 100 ans |

| Heures décimales | Heures et minutes |
|---|---|
| 0,1 h | 6 min |
| 0,25 h | 15 min |
| 0,5 h | 30 min |
| 0,75 h | 45 min |
| 1,2 h | 1 h 12 min |
| 2,5 h | 2 h 30 min |

::: attention Les durées ne sont pas décimales
$1{,}5$ h $= 1$ h $30$ min, et non $1$ h $50$ min. Pour convertir, on multiplie la partie décimale par $60$ : $0{,}2$ h $= 0{,}2 \times 60 = 12$ min.
:::

## VII. Vitesses {Collège}

| Vitesse en km/h | Vitesse en m/s |
|---|---|
| 3,6 km/h | 1 m/s |
| 18 km/h | 5 m/s |
| 36 km/h | 10 m/s |
| 50 km/h | ≈ 13,9 m/s |
| 90 km/h | 25 m/s |
| 130 km/h | ≈ 36,1 m/s |

::: retenir
Des km/h aux m/s : on divise par $3{,}6$. Des m/s aux km/h : on multiplie par $3{,}6$ (car $1$ m/s $= 3\,600$ m/h $= 3{,}6$ km/h).
:::
