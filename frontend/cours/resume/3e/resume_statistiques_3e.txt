<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Graphiques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Bâtons</strong> : valeurs distinctes. <strong>Circulaire</strong> : angle $\displaystyle = 360^\circ \times$ fréquence. <strong>Histogramme</strong> : classes, rectangles accolés.</p>
<p style="margin:6px 0 0 0;">• Données en classes : médiane localisée dans une classe ; moyenne seulement <strong>estimée</strong> (centres de classes).</p>
<p style="margin:6px 0 0 0;">• <strong>Réunir deux groupes</strong> : additionner les SOMMES, pas faire la moyenne des moyennes.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Chercher la médiane sans avoir rangé la série.</p>
<p style="margin:6px 0 0 0;">2️⃣ Faire la moyenne de moyennes de groupes de tailles différentes.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier les effectifs (=MOYENNE au lieu d'une moyenne pondérée).</p>
<p style="margin:6px 0 0 0;">4️⃣ Se laisser tromper par un axe vertical qui ne commence pas à 0.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> comparer deux séries = un indicateur de position (moyenne, médiane) ET un de dispersion (étendue) ; une valeur extrême déplace la moyenne, pas (ou peu) la médiane.</p>
</div>
