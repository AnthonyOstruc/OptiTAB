Découverte - Trois points sur un même trait
Id: 5191
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe A, B et C. Tu peux imprimer ou reproduire le dessin pour contrôler avec la règle.

[IMAGE_1]

1. Quel outil permet de vérifier l’alignement ?
2. Comment places-tu la règle ?
3. Où se trouve B par rapport à ce bord ?
4. A, B et C sont-ils alignés ?
5. Si tu ajoutes D en dehors de ce trait, les quatre points sont-ils alignés ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel outil permet de vérifier l’alignement ?

::: methode
Choisis un bord bien droit.
:::

::: etape Raisonner
Le bord d’une règle permet de tester si les points suivent le même trait.
:::

::: resultat
Une règle.
:::

## Question 2 : Comment places-tu la règle ?

::: methode
Fais passer le bord par deux des points.
:::

::: etape Raisonner
Place le bord sur A et C.
:::

::: resultat
Contre A et C.
:::

## Question 3 : Où se trouve B par rapport à ce bord ?

::: methode
Regarde le troisième point.
:::

::: etape Raisonner
Il se trouve lui aussi sur le même bord droit.
:::

::: resultat
Sur le même bord.
:::

## Question 4 : A, B et C sont-ils alignés ?

::: methode
Les trois points doivent appartenir au même trait droit.
:::

::: etape Raisonner
Le bord de la règle passe par chacun.
:::

::: resultat
Oui.
:::

## Question 5 : Si tu ajoutes D en dehors de ce trait, les quatre points sont-ils alignés ?

::: methode
Un seul point hors du trait suffit à rompre cet alignement.
:::

::: etape Raisonner
Le même bord ne peut plus passer par les quatre points.
:::

::: resultat
Non.
:::

Solution:
<!-- optitab:1 -->
1. Une règle.
2. Contre A et C.
3. Sur le même bord.
4. Oui.
5. Non.

Découverte - Le milieu par pliage
Id: 5192
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Trace un segment AB de 6 cm sur une bande de papier.

1. Comment plies-tu pour retrouver le milieu ?
2. Comment nommes-tu le point où le pli coupe le segment ?
3. Quelle longueur sépare A de M ?
4. Quelle longueur sépare M de B ?
5. Vérifie en réunissant les deux parties.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment plies-tu pour retrouver le milieu ?

::: methode
Les deux extrémités doivent se superposer.
:::

::: etape Raisonner
Ramène A exactement sur B et marque le pli.
:::

::: resultat
En faisant coïncider A et B.
:::

## Question 2 : Comment nommes-tu le point où le pli coupe le segment ?

::: methode
Le pli partage la longueur en deux parties égales.
:::

::: etape Raisonner
Marque ce point M.
:::

::: resultat
Le milieu M.
:::

## Question 3 : Quelle longueur sépare A de M ?

::: methode
Partage six centimètres en deux longueurs égales.
:::

::: etape Raisonner
$6\div 2=3$
:::

::: resultat
3 cm.
:::

## Question 4 : Quelle longueur sépare M de B ?

::: methode
Les deux parties ont la même longueur.
:::

::: etape Raisonner
MB doit être aussi long que AM.
:::

::: resultat
3 cm.
:::

## Question 5 : Vérifie en réunissant les deux parties.

::: methode
Le segment entier doit être reconstitué.
:::

::: etape Raisonner
$3+3=6$ cm.
:::

::: etape Vérifier
[IMAGE_1]
:::

::: resultat
3 cm et 3 cm font bien 6 cm.
:::

Solution:
<!-- optitab:1 -->
1. En faisant coïncider A et B.
2. Le milieu M.
3. 3 cm.
4. 3 cm.
5. 3 cm et 3 cm font bien 6 cm.

Découverte - Un cercle passant par A
Id: 5193
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur une feuille, place O et A à 3 cm l’un de l’autre. Trace le cercle de centre O passant par A.

1. Où places-tu la pointe du compas ?
2. Jusqu’où ouvres-tu le compas ?
3. Que doit faire la pointe pendant le tour ?
4. Peux-tu changer l’ouverture pendant le tour ?
5. Comment contrôles-tu un point du contour ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Où places-tu la pointe du compas ?

::: methode
Le centre est le point fixe du tracé.
:::

::: etape Raisonner
Le point demandé est O.
:::

::: resultat
Sur O.
:::

## Question 2 : Jusqu’où ouvres-tu le compas ?

::: methode
Le crayon doit atteindre le point A.
:::

::: etape Raisonner
L’écartement est la longueur OA, soit trois centimètres.
:::

::: resultat
De O jusqu’à A, soit 3 cm.
:::

## Question 3 : Que doit faire la pointe pendant le tour ?

::: methode
Le centre du cercle doit rester le même.
:::

::: etape Raisonner
La pointe garde la même position pendant que le crayon tourne.
:::

::: resultat
Rester fixe sur O.
:::

## Question 4 : Peux-tu changer l’ouverture pendant le tour ?

::: methode
Tous les points du contour doivent rester à la même distance du centre.
:::

::: etape Raisonner
Changer l’ouverture changerait cette distance.
:::

::: resultat
Non.
:::

## Question 5 : Comment contrôles-tu un point du contour ?

::: methode
Mesure sa distance à O.
:::

::: etape Raisonner
Elle doit être la même que OA, soit 3 cm.
:::

::: resultat
Chaque point du cercle est à 3 cm de O.
:::

Solution:
<!-- optitab:1 -->
1. Sur O.
2. De O jusqu’à A, soit 3 cm.
3. Rester fixe sur O.
4. Non.
5. Chaque point du cercle est à 3 cm de O.

::: etape Raisonner

::: resultat

Problème - Le milieu de dix centimètres
Id: 5197
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un segment AB mesure 10 cm. M est son milieu.

1. Que signifie « milieu » ?
2. Quelle est la longueur AM ?
3. Quelle est la longueur MB ?
4. Comment contrôles-tu par une addition ?
5. Un point à 4 cm de A serait-il le milieu ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Que signifie « milieu » ?

::: methode
Le segment est partagé en deux longueurs égales.
:::

::: etape Raisonner
AM et MB ont la même longueur.
:::

::: resultat
Deux parties de même longueur.
:::

## Question 2 : Quelle est la longueur AM ?

::: methode
Partage dix en deux parts égales.
:::

::: etape Raisonner
$10\div 2=5$
:::

::: resultat
5 cm.
:::

## Question 3 : Quelle est la longueur MB ?

::: methode
Les deux parties doivent être égales.
:::

::: etape Raisonner
La seconde partie a la même mesure que la première.
:::

::: resultat
5 cm.
:::

## Question 4 : Comment contrôles-tu par une addition ?

::: methode
Rassemble les deux moitiés.
:::

::: etape Raisonner
$5+5=10$ cm.
:::

::: resultat
On retrouve 10 cm.
:::

## Question 5 : Un point à 4 cm de A serait-il le milieu ?

::: methode
Calcule ce qu’il resterait jusqu’à B.
:::

::: etape Raisonner
$10-4=6$ cm : les deux longueurs ne seraient pas égales.
:::

::: resultat
Non, 4 cm et 6 cm ne sont pas égaux.
:::

Solution:
<!-- optitab:1 -->
1. Deux parties de même longueur.
2. 5 cm.
3. 5 cm.
4. On retrouve 10 cm.
5. Non, 4 cm et 6 cm ne sont pas égaux.

Problème - Deux cercles de même centre
Id: 5198
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Sur une feuille, trace deux cercles de centre O : un avec une ouverture de 2 cm et l’autre avec une ouverture de 3 cm.

1. Quel point gardes-tu pour les deux tracés ?
2. Quelle ouverture utilises-tu en premier ?
3. Comment passes-tu au second cercle ?
4. Les deux contours se touchent-ils ?
5. Comment contrôles-tu les deux tracés ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel point gardes-tu pour les deux tracés ?

::: methode
Les deux cercles ont le même centre.
:::

::: etape Raisonner
La pointe du compas garde le point O comme repère.
:::

::: resultat
O.
:::

## Question 2 : Quelle ouverture utilises-tu en premier ?

::: methode
Lis l’une des deux longueurs proposées.
:::

::: etape Raisonner
Tu peux commencer par le petit cercle.
:::

::: resultat
2 cm.
:::

## Question 3 : Comment passes-tu au second cercle ?

::: methode
Change l’ouverture sans changer le centre.
:::

::: etape Raisonner
Ouvre ensuite jusqu’à trois centimètres et replace la pointe en O.
:::

::: resultat
Avec une ouverture de 3 cm, en gardant O.
:::

## Question 4 : Les deux contours se touchent-ils ?

::: methode
Ils gardent deux distances différentes au même centre.
:::

::: etape Raisonner
Un contour est à 2 cm de O ; l’autre est toujours à 3 cm.
:::

::: resultat
Non.
:::

## Question 5 : Comment contrôles-tu les deux tracés ?

::: methode
Mesure depuis le centre vers les deux contours.
:::

::: etape Raisonner
Les mesures doivent retrouver les deux ouvertures annoncées.
:::

::: resultat
2 cm pour le premier et 3 cm pour le second.
:::

Solution:
<!-- optitab:1 -->
1. O.
2. 2 cm.
3. Avec une ouverture de 3 cm, en gardant O.
4. Non.
5. 2 cm pour le premier et 3 cm pour le second.

1. Quel point devait rester fixe ?
2. Que change le déplacement de la pointe ?

4. Comment doit-il recommencer ?

<!-- optitab:1 -->

## Question 1 : Quel point devait rester fixe ?

::: methode
Le centre est le repère du compas.
:::

::: etape Raisonner
Le cercle demandé a pour centre O.
:::

::: resultat
O.
:::

::: methode

:::

::: etape Raisonner
La pointe n’est plus toujours sur O.
:::

::: resultat
Le centre du tracé change.
