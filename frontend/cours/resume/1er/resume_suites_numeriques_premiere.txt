<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Notations et définitions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Suite numérique</strong></p>
<p style="margin:5px 0 0 0;">Une suite numérique $\displaystyle (u_n)$ est une fonction définie sur $\displaystyle \mathbb{N}$ (ou une partie de $\displaystyle \mathbb{N}$) à valeurs dans $\displaystyle \mathbb{R}$. À chaque entier naturel $\displaystyle n$, on associe un nombre réel $\displaystyle u_n$ appelé <strong>terme de rang $\displaystyle n$</strong>.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Notation</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Signification</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle u(n)$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Notation fonctionnelle</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle u_n$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Notation indicielle (la plus courante)</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle (u_n)_{n \in \mathbb{N}}$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Notation complète avec ensemble d'indices</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Terme initial</td>
<td style="border:none; padding:18px 16px;">Premier terme donné ($\displaystyle u_0$ ou $\displaystyle u_1$ selon les contextes)</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; border-left:4px solid #f59e0b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>📐 Comment utiliser le graphique d'une suite explicite :</strong></p>
<p style="margin:5px 0 0 0;">Pour une suite définie explicitement $\displaystyle u_n = f(n)$ :</p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 5px 0;">Tracer la courbe $\displaystyle C_f$ de la fonction $\displaystyle f$</li>
<li style="margin:0 0 5px 0;">Pour chaque entier $\displaystyle n$, placer le point d'abscisse $\displaystyle n$ sur l'axe des abscisses</li>
<li style="margin:0 0 5px 0;">Tracer une verticale jusqu'à $\displaystyle C_f$ : l'ordonnée est $\displaystyle u_n = f(n)$</li>
<li style="margin:0;">Projeter horizontalement sur l'axe des ordonnées pour lire $\displaystyle u_n$</li>
</ol>
</div>
</div>

<div style="text-align:center; margin:20px 0;">

</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; border-left:4px solid #f59e0b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>📐 Comment utiliser le graphique d'une suite par récurrence (méthode "toile d'araignée") :</strong></p>
<p style="margin:5px 0 0 0;">Pour une suite définie par récurrence $\displaystyle u_{n+1} = f(u_n)$ :</p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 5px 0;">Tracer la courbe $\displaystyle C_f$ et la droite $\displaystyle y = x$</li>
<li style="margin:0 0 5px 0;">Placer $\displaystyle u_0$ sur l'axe des abscisses</li>
<li style="margin:0 0 5px 0;">Monter verticalement jusqu'à $\displaystyle C_f$ → $\displaystyle u_1 = f(u_0)$</li>
<li style="margin:0 0 5px 0;">Aller horizontalement jusqu'à $\displaystyle y = x$</li>
<li style="margin:0 0 5px 0;">Descendre verticalement jusqu'à l'axe des abscisses → on obtient $\displaystyle u_1$ sur l'axe</li>
<li style="margin:0;">Répéter pour $\displaystyle u_2, u_3, \ldots$ pour visualiser la convergence et identifier les points fixes</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Modes de génération d'une suite</h2>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Suites arithmétiques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Suite arithmétique</strong></p>
<p style="margin:5px 0 0 0;">Une suite $\displaystyle (u_n)$ est <strong>arithmétique</strong> s'il existe un nombre réel $\displaystyle r$ tel que :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle u_{n+1} = u_n + r$</p>
</div>
<p style="margin:5px 0 0 0;">Le nombre $\displaystyle r$ est appelé la <strong>raison</strong> de la suite arithmétique.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Formule</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Expression</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Terme général (commence à $\displaystyle u_0$)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle u_n = u_0 + nr$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Terme général (commence à $\displaystyle u_1$)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle u_n = u_1 + (n-1)r$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Terme général (connaît $\displaystyle u_p$)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle u_n = u_p + (n-p)r$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Somme des termes</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \sum_{k=0}^{n} u_k = (n+1) \times \frac{u_0 + u_n}{2}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Somme $\displaystyle 1 + 2 + \cdots + n$</td>
<td style="border:none; padding:18px 16px;">$\displaystyle \frac{n(n+1)}{2}$</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Interprétation :</strong> Une suite arithmétique modélise une évolution à <strong>accroissements constants</strong>. Entre deux termes consécutifs, la différence est toujours la même (égale à la raison $\displaystyle r$).</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Suites géométriques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Suite géométrique</strong></p>
<p style="margin:5px 0 0 0;">Une suite $\displaystyle (u_n)$ est <strong>géométrique</strong> s'il existe un nombre réel $\displaystyle q$ tel que :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle u_{n+1} = q \times u_n$</p>
</div>
<p style="margin:5px 0 0 0;">Le nombre $\displaystyle q$ est appelé la <strong>raison</strong> de la suite géométrique ($\displaystyle q \neq 0$).</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Formule</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Expression</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Terme général (commence à $\displaystyle u_0$)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle u_n = u_0 \times q^n$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Terme général (commence à $\displaystyle u_1$)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle u_n = u_1 \times q^{n-1}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Terme général (connaît $\displaystyle u_p$)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle u_n = u_p \times q^{n-p}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Somme ($\displaystyle q \neq 1$)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \sum_{k=0}^{n} u_k = u_0 \times \frac{1-q^{n+1}}{1-q}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Somme ($\displaystyle q = 1$)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \sum_{k=0}^{n} u_k = (n+1)u_0$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Somme $\displaystyle 1 + q + q^2 + \cdots + q^n$ ($\displaystyle q \neq 1$)</td>
<td style="border:none; padding:18px 16px;">$\displaystyle \frac{1-q^{n+1}}{1-q}$</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Interprétation :</strong> Une suite géométrique modélise une évolution à <strong>taux constant</strong> (multiplicatif). Entre deux termes consécutifs, le rapport est toujours le même (égal à la raison $\displaystyle q$).</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Sens de variation d'une suite</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #10b981; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(16,185,129,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #10b981 0%, #059669 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Type de variation</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Condition</th>
</tr>
</thead>
<tbody>
<tr style="background:#d1fae5;">
<td style="border:none; border-bottom:1px solid #a7f3d0; padding:18px 16px;">Strictement croissante</td>
<td style="border:none; border-bottom:1px solid #a7f3d0; padding:18px 16px;">$\displaystyle u_{n+1} > u_n$ pour tout $\displaystyle n$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Strictement décroissante</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle u_{n+1} < u_n$ pour tout $\displaystyle n$</td>
</tr>
<tr style="background:#d1fae5;">
<td style="border:none; border-bottom:1px solid #a7f3d0; padding:18px 16px;">Constante</td>
<td style="border:none; border-bottom:1px solid #a7f3d0; padding:18px 16px;">$\displaystyle u_{n+1} = u_n$ pour tout $\displaystyle n$</td>
</tr>
</tbody>
</table>
</div>

</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;"><strong>Méthode 2</strong><br/>Quotient (si $\displaystyle u_n > 0$)</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer $\displaystyle \frac{u_{n+1}}{u_n}$ :<br/>• Si $\displaystyle > 1$ : strictement croissante<br/>• Si $\displaystyle < 1$ : strictement décroissante<br/>• Si $\displaystyle = 1$ : constante</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; padding:18px 16px;"><strong>Méthode 3</strong><br/>Fonction associée</td>
<td style="border:none; padding:18px 16px;">Si $\displaystyle u_n = f(n)$ où $\displaystyle f$ est une fonction :<br/>• Si $\displaystyle f$ croissante → $\displaystyle (u_n)$ croissante<br/>• Si $\displaystyle f$ décroissante → $\displaystyle (u_n)$ décroissante</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Notion de limite (introduction intuitive)</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Limite finie</strong></p>
<p style="margin:5px 0 0 0;">On dit qu'une suite $\displaystyle (u_n)$ tend vers un nombre réel $\displaystyle \ell$ lorsque $\displaystyle n$ tend vers $\displaystyle +\infty$ si les termes $\displaystyle u_n$ se rapprochent indéfiniment de $\displaystyle \ell$ quand $\displaystyle n$ devient très grand.</p>
<p style="margin:5px 0 0 0;">On note : $\displaystyle \lim_{n \to +\infty} u_n = \ell$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Limite infinie</strong></p>
<p style="margin:5px 0 0 0;">• $\displaystyle (u_n)$ tend vers $\displaystyle +\infty$ si les termes deviennent arbitrairement grands quand $\displaystyle n$ devient très grand.</p>
<p style="margin:5px 0 0 0;">• $\displaystyle (u_n)$ tend vers $\displaystyle -\infty$ si les termes deviennent arbitrairement petits (négatifs) quand $\displaystyle n$ devient très grand.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \frac{1}{n}$</td>

</tr>
<tr style="background:#f8f9fa;">

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Piège fréquent</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Correction</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre arithmétique et géométrique</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Arithmétique : <strong>addition</strong> constante ($\displaystyle +r$)<br/>Géométrique : <strong>multiplication</strong> constante ($\displaystyle \times q$)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier le cas $\displaystyle q = 1$ dans la somme géométrique</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Si $\displaystyle q = 1$ : $\displaystyle \sum_{k=0}^{n} u_k = (n+1)u_0$<br/>Ne pas utiliser $\displaystyle \frac{1-q^{n+1}}{1-q}$ qui est indéfini</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Erreur dans les bornes</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Si la suite commence à $\displaystyle u_1$ :<br/>• Arithmétique : $\displaystyle u_n = u_1 + (n-1)r$ (et non $\displaystyle nr$)<br/>• Géométrique : $\displaystyle u_n = u_1 \times q^{n-1}$ (et non $\displaystyle q^n$)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Confondre limite et valeur</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \lim_{n \to +\infty} q^n = 0$ (si $\displaystyle |q| < 1$) ne signifie pas $\displaystyle q = 0$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Sens de variation des suites géométriques</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Attention au signe de $\displaystyle u_0$ !<br/>Si $\displaystyle u_0 < 0$ et $\displaystyle q > 1$, la suite est décroissante (négative)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Nombre de termes dans une somme</td>
<td style="border:none; padding:18px 16px;">De $\displaystyle u_0$ à $\displaystyle u_n$ : il y a $\displaystyle n+1$ termes (et non $\displaystyle n$)</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">X. Méthodologie — stratégie de résolution</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ffa500; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(255,165,0,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ffa500 0%, #ff8c00 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Type de problème</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Méthode recommandée</th>
</tr>
</thead>
<tbody>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Reconnaître une suite arithmétique</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer $\displaystyle u_{n+1} - u_n$ pour quelques valeurs. Si constant → arithmétique de raison $\displaystyle r$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Reconnaître une suite géométrique</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer $\displaystyle \frac{u_{n+1}}{u_n}$ pour quelques valeurs (si $\displaystyle u_n \neq 0$). Si constant → géométrique de raison $\displaystyle q$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Déterminer le sens de variation</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Calculer $\displaystyle u_{n+1} - u_n$ (ou $\displaystyle \frac{u_{n+1}}{u_n}$ si $\displaystyle u_n > 0$)<br/>2. Étudier le signe<br/>3. Conclure</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer une somme</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">1. Identifier le type de suite (arithmétique ou géométrique)<br/>2. Vérifier les bornes (nombre de termes)<br/>3. Appliquer la formule appropriée<br/>4. Attention au cas $\displaystyle q = 1$ pour les géométriques</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Conjecturer une limite</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer quelques termes avec de grandes valeurs de $\displaystyle n$ pour observer la tendance</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Modéliser un problème</td>
<td style="border:none; padding:18px 16px;">1. Identifier si l'évolution est linéaire (arithmétique) ou exponentielle (géométrique)<br/>2. Déterminer la raison $\displaystyle r$ ou $\displaystyle q$<br/>3. Identifier le terme initial $\displaystyle u_0$<br/>4. Écrire le terme général</td>
</tr>
</tbody>
</table>

<p style="margin:0;"><strong>💡 Points de vigilance :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">

<li style="margin:0 0 8px 0;">Compter correctement le nombre de termes dans une somme (de $\displaystyle u_0$ à $\displaystyle u_n$ : $\displaystyle n+1$ termes)</li>
