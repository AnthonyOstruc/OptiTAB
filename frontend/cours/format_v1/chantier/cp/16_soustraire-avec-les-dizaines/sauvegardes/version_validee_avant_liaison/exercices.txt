===
Découverte - Soustraire avec les dizaines : atelier 1
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Tu peux prendre des jetons. Explique tes gestes avec des mots.

[IMAGE_1]

1. Enlève 7 unités à 50. Aide-toi de l’échange.
2. Vérifie $50-7$ avec une addition.
3. Complète : $50-\ldots=43$.
4. Calcule $50-1$.
5. Calcule $50-10$.

Étapes:
<!-- optitab:1 -->

## Question 1 : Enlève 7 unités à 50. Aide-toi de l’échange.

::: methode
Manipuler et calculer dans l’ordre.
:::

::: etape Raisonner
J’échange une dizaine contre dix unités. $50=40+10$. J’enlève 0 dizaines et 7 unités. $40-0=40$. $10-7=3$. Je réunis : $40+3=43$.

[IMAGE_2]
:::

::: etape Vérifier
Je vérifie les calculs : $50-7=43$.
:::

::: resultat
50 = 40 + 10 ; 10 - 7 = 3. Donc 50 - 7 = 43.
:::

## Question 2 : Vérifie $50-7$ avec une addition.

::: methode
Remettre ce qui a été retiré.
:::

::: etape Raisonner
Je repars de 43. Je remets 7. $43+7=50$.
:::

::: resultat
$43+7=50$
:::

## Question 3 : Complète : $50-\ldots=43$.

::: methode
Chercher la quantité retirée.
:::

::: etape Raisonner
Le retrait est 7. $50-7=43$.
:::

::: resultat
Il manque 7.
:::

## Question 4 : Calcule $50-1$.

::: methode
Reculer d’un nombre.
:::

::: etape Raisonner
J’échange une dizaine contre dix unités. $50=40+10$. J’enlève 0 dizaines et 1 unités. $40-0=40$. $10-1=9$. Je réunis : $40+9=49$.
:::

::: resultat
$50-1=49$
:::

## Question 5 : Calcule $50-10$.

::: methode
Retirer une dizaine.
:::

::: etape Raisonner
J’enlève 1 dizaines. Les unités ne changent pas. $50-10=40$. Je vérifie : $40+10=50$.
:::

::: resultat
$50-10=40$
:::

Solution:
<!-- optitab:1 -->
1. 50 = 40 + 10 ; 10 - 7 = 3. Donc 50 - 7 = 43.
2. $43+7=50$
3. Il manque 7.
4. $50-1=49$
5. $50-10=40$
