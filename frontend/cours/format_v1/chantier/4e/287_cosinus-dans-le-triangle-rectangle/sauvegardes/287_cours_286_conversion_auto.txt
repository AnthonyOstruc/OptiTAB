Titre: Cosinus dans le triangle rectangle

<!-- optitab:1 -->
::: objectifs
Connaître la définition du cosinus d'un angle aigu dans un triangle rectangle, savoir l'utiliser pour calculer une longueur ou la mesure d'un angle avec la calculatrice, et résoudre des problèmes concrets.
:::

## I. Le vocabulaire

Dans le triangle $ABC$ rectangle en $A$, on s'intéresse à l'angle aigu $\widehat{B}$ :

• l'**hypoténuse** $[BC]$ est le côté opposé à l'angle droit (le plus long) ;

• le **côté adjacent** à $\widehat{B}$ est le côté de l'angle droit qui « touche » le sommet $B$ : $[BA]$ ;

• le **côté opposé** à $\widehat{B}$ est le troisième côté : $[AC]$.

[IMAGE_1]

::: attention
Le côté adjacent dépend de l'angle choisi. Pour l'angle $\widehat{C}$, le côté adjacent est $[CA]$ ; l'hypoténuse, elle, ne change pas.
:::

## II. Le cosinus d'un angle aigu

::: definition
Dans un triangle rectangle, le cosinus d'un angle aigu est le quotient de la longueur du côté adjacent par la longueur de l'hypoténuse :

$$
\begin{aligned}
\cos \widehat{B} &= \frac{\text{côté adjacent à } \widehat{B}}{\text{hypoténuse}} \\
&= \frac{BA}{BC}
\end{aligned}
$$
:::

::: exemple
Si $BA = 4$ cm et $BC = 5$ cm, alors $\cos \widehat{B} = \frac{4}{5} = 0{,}8$.
:::

::: remarque Le cosinus ne dépend que de l'angle
Pour un même angle de $35°$, tous les triangles rectangles donnent le même quotient (c'est le théorème de Thalès !). On peut donc parler de « $\cos 35°$ ».
:::

[IMAGE_2]

**Propriété :** le côté adjacent est plus court que l'hypoténuse, donc le cosinus d'un angle aigu est toujours **compris entre $0$ et $1$**. Plus l'angle est grand, plus son cosinus est petit.

## III. Avec la calculatrice

La calculatrice doit être réglée en **mode degrés** (symbole D ou DEG à l'écran).

[IMAGE_3]

• Touche **cos** : on connaît l'angle, on obtient son cosinus : $\cos 35° \approx 0{,}819$.

• Touche **cos⁻¹** (ou Arccos, souvent avec la touche « seconde ») : on connaît le cosinus, on retrouve l'angle : si $\cos \widehat{B} = 0{,}6$, alors $\widehat{B} \approx 53{,}1°$.

## IV. Calculer une longueur

**Le côté adjacent :** $ABC$ rectangle en $A$, $BC = 10$ cm et $\widehat{B} = 35°$.

::: definition
$\cos 35° = \frac{AB}{10}$ donc $AB = 10 \times \cos 35° \approx 8{,}2$ cm
:::

**L'hypoténuse :** $ABC$ rectangle en $A$, $AB = 6$ cm et $\widehat{B} = 50°$.

::: definition
$\cos 50° = \frac{6}{BC}$ donc $BC = \frac{6}{\cos 50°} \approx 9{,}3$ cm
:::

::: attention
Pour le côté adjacent on **multiplie** par le cosinus, pour l'hypoténuse on **divise**. Contrôle : l'hypoténuse doit rester le plus long côté.
:::

## V. Calculer un angle

$ABC$ rectangle en $A$, $AB = 4$ cm et $BC = 7$ cm :

::: definition
$\cos \widehat{B} = \frac{4}{7}$ donc $\widehat{B} \approx 55°$ (touche cos⁻¹)
:::

::: remarque Bonus
Les deux angles aigus d'un triangle rectangle sont complémentaires : $\widehat{C} = 90° - \widehat{B} \approx 35°$.
:::

## VI. Dans la vie courante

Une échelle de $5$ m posée contre un mur fait un angle de $70°$ avec le sol. Le mur et le sol forment un angle droit : la distance du pied de l'échelle au mur est le côté adjacent à l'angle de $70°$.

[IMAGE_4]

::: definition
$AC = 5 \times \cos 70° \approx 1{,}71$ m ; Pythagore : $BC = \sqrt{25 - AC^2} \approx 4{,}70$ m
:::

::: retenir
Dans un triangle rectangle, $\cos(\text{angle}) = \frac{\text{côté adjacent}}{\text{hypoténuse}}$ ; côté adjacent $= \text{hypoténuse} \times \cos$ ; hypoténuse $= \text{côté adjacent} : \cos$ ; angle : touche cos⁻¹ en mode degrés. Fiche de synthèse dans l'onglet Fiches !
:::
