=== Simplification - Avec Développement et Factorisation
Id: 1439
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes en développant puis en réduisant, ou en utilisant les identités remarquables.

1. Simplifier $\displaystyle (x+2)^2 - (x-1)^2$
2. Simplifier $\displaystyle (x+1)(x-1) + x^2 - 1$
3. Simplifier $\displaystyle 3(x+2) - 2(x-1) + x$
4. Simplifier $\displaystyle (x+3)^2 - (x-2)^2$
5. Simplifier $\displaystyle 4(x-1) + 2(x+3) - 3x$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle (x+2)^2 - (x-1)^2$

::: methode
Développer puis réduire
:::

::: etape Développer les carrés
- $\displaystyle (x+2)^2 = x^2 + 4x + 4$
- $\displaystyle (x-1)^2 = x^2 - 2x + 1$
:::

::: etape Substituer dans l'expression
- $\displaystyle (x+2)^2 - (x-1)^2 = (x^2 + 4x + 4) - (x^2 - 2x + 1)$
:::

::: etape Réduire
$$
\begin{aligned}
= x^2 + 4x + 4 - x^2 + 2x - 1 &= (x^2 - x^2) + (4x + 2x) + (4 - 1) \\
&= 6x + 3
\end{aligned}
$$
:::

::: resultat
$$(x+2)^2 - (x-1)^2 = 6x + 3$$
:::

## Question 2 : Simplifier $\displaystyle (x+1)(x-1) + x^2 - 1$

::: methode
Reconnaître une identité remarquable puis réduire
:::

::: etape Reconnaître une identité remarquable
- $\displaystyle (x+1)(x-1) = x^2 - 1$ (différence de carrés)
:::

::: etape Substituer dans l'expression
- $\displaystyle (x+1)(x-1) + x^2 - 1 = (x^2 - 1) + x^2 - 1$
:::

::: etape Réduire
- $\displaystyle = x^2 - 1 + x^2 - 1 = 2x^2 - 2$
:::

::: etape Factoriser si possible
- $\displaystyle = 2(x^2 - 1) = 2(x-1)(x+1)$
:::

::: resultat
$$(x+1)(x-1) + x^2 - 1 = 2x^2 - 2 = 2(x^2 - 1)$$
:::

## Question 3 : Simplifier $\displaystyle 3(x+2) - 2(x-1) + x$

::: methode
Développer puis réduire
:::

::: etape Développer les parenthèses
- $\displaystyle 3(x+2) = 3x + 6$
- $\displaystyle 2(x-1) = 2x - 2$
:::

::: etape Substituer dans l'expression
- $\displaystyle 3(x+2) - 2(x-1) + x = (3x + 6) - (2x - 2) + x$
:::

::: etape Réduire
$$
\begin{aligned}
= 3x + 6 - 2x + 2 + x &= (3x - 2x + x) + (6 + 2) \\
&= 2x + 8
\end{aligned}
$$
:::

::: resultat
$$3(x+2) - 2(x-1) + x = 2x + 8$$
:::

## Question 4 : Simplifier $\displaystyle (x+3)^2 - (x-2)^2$

::: methode
Développer puis réduire
:::

::: etape Développer les carrés
- $\displaystyle (x+3)^2 = x^2 + 6x + 9$
- $\displaystyle (x-2)^2 = x^2 - 4x + 4$
:::

::: etape Substituer dans l'expression
- $\displaystyle (x+3)^2 - (x-2)^2 = (x^2 + 6x + 9) - (x^2 - 4x + 4)$
:::

::: etape Réduire
$$
\begin{aligned}
= x^2 + 6x + 9 - x^2 + 4x - 4 &= (x^2 - x^2) + (6x + 4x) + (9 - 4) \\
&= 10x + 5
\end{aligned}
$$
:::

::: etape Factoriser si possible
- $\displaystyle = 5(2x + 1)$
:::

::: resultat
$$(x+3)^2 - (x-2)^2 = 10x + 5 = 5(2x + 1)$$
:::

## Question 5 : Simplifier $\displaystyle 4(x-1) + 2(x+3) - 3x$

::: methode
Développer puis réduire
:::

::: etape Développer les parenthèses
- $\displaystyle 4(x-1) = 4x - 4$
- $\displaystyle 2(x+3) = 2x + 6$
:::

::: etape Substituer dans l'expression
- $\displaystyle 4(x-1) + 2(x+3) - 3x = (4x - 4) + (2x + 6) - 3x$
:::

::: etape Réduire
$$
\begin{aligned}
= 4x - 4 + 2x + 6 - 3x &= (4x + 2x - 3x) + (-4 + 6) \\
&= 3x + 2
\end{aligned}
$$
:::

::: resultat
$$4(x-1) + 2(x+3) - 3x = 3x + 2$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (x+2)^2 - (x-1)^2 = 6x + 3$
2. $\displaystyle (x+1)(x-1) + x^2 - 1 = 2x^2 - 2 = 2(x^2 - 1)$
3. $\displaystyle 3(x+2) - 2(x-1) + x = 2x + 8$
4. $\displaystyle (x+3)^2 - (x-2)^2 = 10x + 5 = 5(2x + 1)$
5. $\displaystyle 4(x-1) + 2(x+3) - 3x = 3x + 2$

=== Simplification - Expressions avec Plusieurs Variables
Id: 1443
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes contenant plusieurs variables.

1. Simplifier $\displaystyle 3x + 2y - x + 5y$
2. Simplifier $\displaystyle 2ab + 3ab - 5ab + ab$
3. Simplifier $\displaystyle 4x^2y + 2xy^2 - x^2y + 3xy^2$
4. Simplifier $\displaystyle 5xy - 2xy + 3x - x + 2y - y$
5. Simplifier $\displaystyle 2a^2b + ab^2 - a^2b + 3ab^2 - ab^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle 3x + 2y - x + 5y$

::: methode
Réduction de termes semblables par variable
:::

::: etape Identifier les termes semblables par variable
- Termes en $x$ : $3x$ et $-x$
- Termes en $y$ : $2y$ et $5y$
:::

::: etape Grouper les termes semblables
- $\displaystyle (3x - x) + (2y + 5y)$
:::

::: etape Réduire les coefficients
- $\displaystyle = 2x + 7y$
:::

::: resultat
$$3x + 2y - x + 5y = 2x + 7y$$
:::

## Question 2 : Simplifier $\displaystyle 2ab + 3ab - 5ab + ab$

::: methode
Réduction de termes semblables
:::

::: etape Identifier les termes semblables
- Tous les termes ont la même partie littérale : $ab$
:::

::: etape Grouper les termes semblables
- $\displaystyle 2ab + 3ab - 5ab + ab$
:::

::: etape Réduire les coefficients
- $\displaystyle (2 + 3 - 5 + 1)ab = ab$
:::

::: resultat
$$2ab + 3ab - 5ab + ab = ab$$
:::

## Question 3 : Simplifier $\displaystyle 4x^2y + 2xy^2 - x^2y + 3xy^2$

Réduction de termes semblables par partie littérale
:::

::: etape Identifier les termes semblables

::: etape Grouper les termes semblables

=== Simplification - Expressions Complexes
Id: 1442
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions complexes suivantes nécessitant plusieurs étapes (développement, factorisation, réduction).

1. Simplifier $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4}$
2. Simplifier $\displaystyle (x+1)^2 - (x-1)^2 + 2x$
3. Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4}$
4. Simplifier $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2$
5. Simplifier $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4}$

::: methode
Développer, factoriser puis simplifier
:::

::: etape Développer le numérateur
- $\displaystyle (x+2)^2 - 4 = x^2 + 4x + 4 - 4 = x^2 + 4x$
:::

::: etape Factoriser le numérateur
- $\displaystyle x^2 + 4x = x(x + 4)$
:::

::: etape Factoriser le dénominateur
- $\displaystyle x^2 - 4 = x^2 - 2^2 = (x - 2)(x + 2)$ (différence de carrés)
:::

::: etape Simplifier
- $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$
:::

::: remarque
Il n'y a pas de facteur commun entre le numérateur et le dénominateur. L'expression est déjà simplifiée (si $x \neq 2$ et $x \neq -2$).
:::

::: resultat
$\dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$ (si $x \neq 2$ et $x \neq -2$)
:::

## Question 2 : Simplifier $\displaystyle (x+1)^2 - (x-1)^2 + 2x$

::: methode
Développer puis réduire
:::

::: etape Développer les carrés
- $\displaystyle (x+1)^2 = x^2 + 2x + 1$
- $\displaystyle (x-1)^2 = x^2 - 2x + 1$
:::

::: etape Substituer dans l'expression
- $\displaystyle (x+1)^2 - (x-1)^2 + 2x = (x^2 + 2x + 1) - (x^2 - 2x + 1) + 2x$
:::

::: etape Réduire
$$
\begin{aligned}
= x^2 + 2x + 1 - x^2 + 2x - 1 + 2x &= (x^2 - x^2) + (2x + 2x + 2x) + (1 - 1) \\
&= 6x
\end{aligned}
$$
:::

::: resultat
$$(x+1)^2 - (x-1)^2 + 2x = 6x$$
:::

## Question 3 : Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4}$

::: methode
Factoriser puis multiplier et simplifier
:::

::: etape Factoriser le numérateur de la première fraction
- $\displaystyle x^2 + 4x + 4 = (x + 2)^2$ (identité remarquable)
:::

::: etape Factoriser le dénominateur de la deuxième fraction
- $\displaystyle x^2 - 4 = (x - 2)(x + 2)$ (différence de carrés)
:::

::: etape Multiplier les fractions
- $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = \dfrac{(x + 2)^2}{x + 2} \times \dfrac{x - 2}{(x - 2)(x + 2)}$
:::

::: etape Simplifier les facteurs communs
- Facteurs communs : $(x + 2)$ et $(x - 2)$ (si $x \neq 2$ et $x \neq -2$)

$$
\begin{aligned}
= \dfrac{(x + 2)^2}{x + 2} \times \dfrac{x - 2}{(x - 2)(x + 2)} &= (x + 2) \times \dfrac{1}{(x + 2)} \\
&= 1
\end{aligned}
$$
:::

::: point Vérification
Pour $x = 0$ : $\dfrac{4}{2} \times \dfrac{-2}{-4} = 2 \times \dfrac{1}{2} = 1$
:::

::: resultat
$\dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = 1$ (si $x \neq 2$ et $x \neq -2$)
:::

## Question 4 : Simplifier $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2$

::: methode
Développer puis réduire
:::

::: etape Développer les parenthèses
- $\displaystyle 2(x+3) = 2x + 6$
- $\displaystyle 3(x-2) = 3x - 6$
:::

::: etape Substituer dans l'expression
- $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2 = (2x + 6) - (3x - 6) + x^2 - x^2$
:::

::: etape Réduire
$$
\begin{aligned}
= 2x + 6 - 3x + 6 + x^2 - x^2 &= (x^2 - x^2) + (2x - 3x) + (6 + 6) \\
&= -x + 12
\end{aligned}
$$
:::

::: resultat
$$2(x+3) - 3(x-2) + x^2 - x^2 = -x + 12$$
:::

## Question 5 : Simplifier $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9}$

::: methode
Développer, factoriser puis simplifier
:::

::: etape Développer le numérateur
- $\displaystyle (x-3)^2 - 9 = x^2 - 6x + 9 - 9 = x^2 - 6x$
:::

::: etape Factoriser le numérateur
- $\displaystyle x^2 - 6x = x(x - 6)$
:::

::: etape Factoriser le dénominateur
- $\displaystyle x^2 - 6x + 9 = (x - 3)^2$ (identité remarquable)
:::

::: etape Simplifier
- $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$
:::

::: remarque
Il n'y a pas de facteur commun entre le numérateur et le dénominateur. L'expression est déjà simplifiée (si $x \neq 3$).
:::

::: resultat
$\dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$ (si $x \neq 3$)
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$ (si $x \neq 2$ et $x \neq -2$)
2. $\displaystyle (x+1)^2 - (x-1)^2 + 2x = 6x$
3. $\dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = 1$ (si $x \neq 2$ et $x \neq -2$)
4. $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2 = -x + 12$
5. $\dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$ (si $x \neq 3$)

=== Simplification - Expressions Mixtes
Id: 1446
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions complexes suivantes nécessitant plusieurs techniques combinées.

1. Simplifier $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3$
2. Simplifier $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1}$ (avec $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)
3. Simplifier $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2$
4. Simplifier $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
5. Simplifier $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3$

::: methode
Utiliser l'identité remarquable, développer puis réduire
:::

::: etape Reconnaître une identité remarquable
- $\displaystyle (x+1)(x-1) = x^2 - 1$ (différence de carrés)
:::

::: etape Substituer dans l'expression
- $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3 = 3(x^2 - 1) + 2(x+1) - 3x^2 + 3$
:::

::: etape Développer
- $\displaystyle = 3x^2 - 3 + 2x + 2 - 3x^2 + 3$
:::

::: etape Réduire
$$= (3x^2 - 3x^2) + 2x + (-3 + 2 + 3) = 2x + 2$$
:::

::: etape Factoriser si possible
- $\displaystyle = 2(x + 1)$
:::

::: resultat
$$3(x+1)(x-1) + 2(x+1) - 3x^2 + 3 = 2x + 2 = 2(x + 1)$$
:::

## Question 2 : Simplifier $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1}$ (avec $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)

::: methode
Développer, factoriser puis multiplier et simplifier
:::

::: etape Développer le numérateur de la première fraction
- $\displaystyle (x+1)^2 - 1 = x^2 + 2x + 1 - 1 = x^2 + 2x = x(x + 2)$
:::

::: etape Factoriser le dénominateur de la deuxième fraction
- $\displaystyle x^2 + 2x + 1 = (x + 1)^2$ (identité remarquable)
:::

::: etape Multiplier les fractions
- $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1} = \dfrac{x(x + 2)}{x} \times \dfrac{x + 2}{(x + 1)^2}$

::: etape Simplifier les facteurs communs
- Facteur commun : $x$ (si $x \neq 0$ et $x \neq -1$)

$$
\begin{aligned}
= \dfrac{x(x + 2)}{x} \times \dfrac{x + 2}{(x + 1)^2} &= (x + 2) \times \dfrac{x + 2}{(x + 1)^2} \\
&= \dfrac{(x + 2)^2}{(x + 1)^2}
\end{aligned}
$$

::: point Vérification

::: resultat

## Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)

::: etape Simplifier les facteurs communs

$$
\begin{aligned}

&= \dfrac{x + 3}{x + 1}
\end{aligned}
$$
:::

::: point Vérification

## Question 5 : Simplifier $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5$

::: methode

\end{aligned}

5. $\displaystyle 4x^2 - 2x + 7 + x - 3x^2 = x^2 - x + 7$

=== Simplification - Produits et Quotients
Id: 1440
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes contenant des produits ou des quotients de fractions.

1. Simplifier $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x}$ (avec $\displaystyle x \neq 0$)
2. Simplifier $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
3. Simplifier $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x}$ (avec $\displaystyle x \neq 0$)
4. Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
5. Simplifier $\displaystyle \dfrac{6x}{5} \times \dfrac{10}{3x}$ (avec $\displaystyle x \neq 0$)

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x}$ (avec $\displaystyle x \neq 0$)

::: methode
Multiplier puis simplifier
:::

::: etape Multiplier les fractions
$$
\begin{aligned}
\dfrac{2x}{3} \times \dfrac{9}{4x} &= \dfrac{2x \times 9}{3 \times 4x} \\
&= \dfrac{18x}{12x}
\end{aligned}
$$
:::

::: etape Simplifier les facteurs communs
- Facteur commun : $6x$ (si $x \neq 0$)
- $\displaystyle \dfrac{18x}{12x} = \dfrac{18}{12} = \dfrac{3}{2}$
:::

::: point Vérification
Pour $x = 2$ : $\dfrac{4}{3} \times \dfrac{9}{8} = \dfrac{36}{24} = \dfrac{3}{2}$
:::

::: resultat
$\dfrac{2x}{3} \times \dfrac{9}{4x} = \dfrac{3}{2}$ (si $x \neq 0$)
:::

## Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)

::: methode
Factoriser puis multiplier et simplifier
:::

::: etape Factoriser le numérateur de la première fraction
- $\displaystyle x^2 - 1 = (x - 1)(x + 1)$ (différence de carrés)
:::

::: etape Multiplier les fractions
- $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = \dfrac{(x - 1)(x + 1)}{x + 1} \times \dfrac{x + 2}{x - 1}$
:::

::: etape Simplifier les facteurs communs
- Facteurs communs : $(x + 1)$ et $(x - 1)$ (si $x \neq 1$ et $x \neq -1$)

$$
\begin{aligned}
= \dfrac{(x - 1)(x + 1)}{x + 1} \times \dfrac{x + 2}{x - 1} &= \dfrac{(x + 2)}{1} \\
&= x + 2
\end{aligned}
$$
:::

::: point Vérification
Pour $x = 2$ : $\dfrac{4 - 1}{3} \times \dfrac{4}{1} = \dfrac{3}{3} \times 4 = 1 \times 4 = 4$ et $2 + 2 = 4$
:::

::: resultat
$\dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = x + 2$ (si $x \neq 1$ et $x \neq -1$)
:::

## Question 3 : Simplifier $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x}$ (avec $\displaystyle x \neq 0$)

::: methode
Multiplier puis simplifier
:::

::: etape Multiplier les fractions
$$
\begin{aligned}
\dfrac{3x}{2} \times \dfrac{4}{x} &= \dfrac{3x \times 4}{2 \times x} \\
&= \dfrac{12x}{2x}
\end{aligned}
$$
:::

::: etape Simplifier les facteurs communs
- Facteur commun : $2x$ (si $x \neq 0$)
- $\displaystyle \dfrac{12x}{2x} = \dfrac{12}{2} = 6$
:::

::: point Vérification
Pour $x = 2$ : $\dfrac{6}{2} \times \dfrac{4}{2} = 3 \times 2 = 6$
:::

::: resultat
$\dfrac{3x}{2} \times \dfrac{4}{x} = 6$ (si $x \neq 0$)
:::

## Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)

::: methode
Factoriser puis multiplier et simplifier
:::

::: etape Factoriser le numérateur de la première fraction
- $\displaystyle x^2 - 9 = x^2 - 3^2 = (x - 3)(x + 3)$ (différence de carrés)
:::

::: etape Multiplier les fractions
- $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3} = \dfrac{(x - 3)(x + 3)}{x + 3} \times \dfrac{x + 1}{x - 3}$
:::

::: etape Simplifier les facteurs communs
- Facteurs communs : $(x + 3)$ et $(x - 3)$ (si $x \neq 3$ et $x \neq -3$)

$$
\begin{aligned}
= \dfrac{(x - 3)(x + 3)}{x + 3} \times \dfrac{x + 1}{x - 3} &= \dfrac{x + 1}{1} \\
&= x + 1
\end{aligned}
$$
:::

::: point Vérification
Pour $x = 0$ : $\dfrac{-9}{3} \times \dfrac{1}{-3} = -3 \times \left(-\dfrac{1}{3}\right) = 1$ et $0 + 1 = 1$
:::

::: resultat
$\dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3} = x + 1$ (si $x \neq 3$ et $x \neq -3$)
:::

## Question 5 : Simplifier $\displaystyle \dfrac{6x}{5} \times \dfrac{10}{3x}$ (avec $\displaystyle x \neq 0$)

::: methode
Multiplier puis simplifier
:::

::: etape Multiplier les fractions

\begin{aligned}

=== Simplification - Réduction de Termes Semblables
Id: 1437
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes en réduisant les termes semblables.

1. Simplifier $\displaystyle 3x + 5x - 2x$
2. Simplifier $\displaystyle 2x^2 + 3x - x^2 + 5x$
3. Simplifier $\displaystyle 4ab + 3ab - 2ab$
4. Simplifier $\displaystyle 3x^2 - 2x + x^2 + 4x - 1$
5. Simplifier $\displaystyle 5y - 2y + 3y - y$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle 3x + 5x - 2x$

::: methode
Réduction de termes semblables
:::

::: etape Identifier les termes semblables
- Tous les termes ont la même partie littérale : $x$
:::

::: etape Grouper les termes semblables
- $\displaystyle 3x + 5x - 2x$
:::

::: etape Réduire les coefficients
- $\displaystyle (3 + 5 - 2)x = 6x$
:::

::: resultat
$$3x + 5x - 2x = 6x$$
:::

## Question 2 : Simplifier $\displaystyle 2x^2 + 3x - x^2 + 5x$

::: methode
Réduction de termes semblables
:::

::: etape Identifier les termes semblables
- Termes en $x^2$ : $2x^2$ et $-x^2$
- Termes en $x$ : $3x$ et $5x$
:::

::: etape Grouper les termes semblables
- $\displaystyle (2x^2 - x^2) + (3x + 5x)$
:::

::: etape Réduire les coefficients
- $\displaystyle (2 - 1)x^2 + (3 + 5)x = x^2 + 8x$
:::

::: resultat
$$2x^2 + 3x - x^2 + 5x = x^2 + 8x$$
:::

## Question 3 : Simplifier $\displaystyle 4ab + 3ab - 2ab$

::: methode
Réduction de termes semblables
:::

::: etape Identifier les termes semblables
- Tous les termes ont la même partie littérale : $ab$
:::

::: etape Grouper les termes semblables
- $\displaystyle 4ab + 3ab - 2ab$
:::

::: etape Réduire les coefficients
- $\displaystyle (4 + 3 - 2)ab = 5ab$
:::

::: resultat
$$4ab + 3ab - 2ab = 5ab$$
:::

## Question 4 : Simplifier $\displaystyle 3x^2 - 2x + x^2 + 4x - 1$

::: methode
Réduction de termes semblables
:::

::: etape Identifier les termes semblables
- Termes en $x^2$ : $3x^2$ et $x^2$
- Termes en $x$ : $-2x$ et $4x$
- Terme constant : $\displaystyle -1$
:::

::: etape Grouper les termes semblables
- $\displaystyle (3x^2 + x^2) + (-2x + 4x) - 1$
:::

::: etape Réduire les coefficients
- $\displaystyle (3 + 1)x^2 + (-2 + 4)x - 1 = 4x^2 + 2x - 1$
:::

::: resultat
$$3x^2 - 2x + x^2 + 4x - 1 = 4x^2 + 2x - 1$$
:::

## Question 5 : Simplifier $\displaystyle 5y - 2y + 3y - y$

Réduction de termes semblables

::: etape Grouper les termes semblables

::: etape Réduire les coefficients

$$5y - 2y + 3y - y = 5y$$
:::

5. $\displaystyle 5y - 2y + 3y - y = 5y$
