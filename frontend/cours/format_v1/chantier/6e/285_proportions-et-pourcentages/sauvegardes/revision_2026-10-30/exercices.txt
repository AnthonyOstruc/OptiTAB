=== Découverte - Proportions et pourcentages - 1. Une enquête à traduire en pourcentages
Id: 3314
Difficulté: easy
Image: pourcentages_6e_1_1_cc2e72b4440779563287.png,pourcentages_6e_1_1_corrige_582e5c6fc3600c456a8d.png

Énoncé:
<!-- optitab:1 -->
Une enquête porte sur 100 élèves. Parmi eux, 10 % choisissent un atelier de dessin ; les autres choisissent un autre atelier. Chaque élève choisit exactement un atelier.

[IMAGE_1]

1. Que représentent 100 % dans cette enquête ?
2. Écrire le pourcentage sous forme de fraction de dénominateur 100.
3. Donner aussi son écriture décimale.
4. Combien d’élèves choisissent le dessin ?
5. Quel pourcentage et combien d’élèves choisissent un autre atelier ?
6. Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Que représentent 100 % dans cette enquête ?

::: methode
Le tout de référence est l’ensemble des élèves interrogés ; un pourcentage exprime des parts de ce tout.
:::

::: resultat
Les 100 élèves interrogés.
:::

## Question 2 : Écrire le pourcentage sous forme de fraction de dénominateur 100.

::: methode
Le mot pour cent signifie pour cent parts égales.
:::

::: resultat
$\displaystyle \frac{10}{100}$.
:::

## Question 3 : Donner aussi son écriture décimale.

::: methode
Un centième vaut 0,01 ; écrire la fraction décimale avec une virgule.
:::

::: resultat
$\displaystyle 0{,}1$.
:::

## Question 4 : Combien d’élèves choisissent le dessin ?

::: methode
Calculer une part sur cent puis prendre autant de parts que le taux. Pour 50 %, on peut aussi prendre la moitié ; pour 25 %, le quart.
:::

::: etape $\displaystyle 100\div100\times 10=10$
:::

::: resultat
10 élèves.
:::

## Question 5 : Quel pourcentage et combien d’élèves choisissent un autre atelier ?

::: methode
Enlever du tout la part déjà comptée, en pourcentage puis en effectif.
:::

::: resultat
90 %, soit 90 élèves.
:::

## Question 6 : Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

::: methode
Le pourcentage reste identique mais le tout double ; la quantité correspondante double elle aussi.
:::

::: resultat
20 élèves. Le même pourcentage ne signifie donc pas le même effectif.
:::

[IMAGE_2]

**À retenir :** Nommer le tout de référence avant tout calcul. Pourcentage, écriture décimale et fraction peuvent représenter le même nombre.

Solution:
<!-- optitab:1 -->
1. Les 100 élèves interrogés.
2. $\displaystyle \frac{10}{100}$.
3. $\displaystyle 0{,}1$.
4. 10 élèves.
5. 90 %, soit 90 élèves.
6. 20 élèves. Le même pourcentage ne signifie donc pas le même effectif.

Image: pourcentages_6e_2_2_791662a4b464f710ef1f.png,pourcentages_6e_2_2_corrige_1638703fc4aa322357c6.png

Énoncé:
<!-- optitab:1 -->
Une enquête porte sur 140 élèves. Parmi eux, 25 % choisissent un atelier de dessin ; les autres choisissent un autre atelier. Chaque élève choisit exactement un atelier.

[IMAGE_1]

1. Que représentent 100 % dans cette enquête ?
2. Écrire le pourcentage sous forme de fraction de dénominateur 100.
3. Donner aussi son écriture décimale.
4. Combien d’élèves choisissent le dessin ?
5. Quel pourcentage et combien d’élèves choisissent un autre atelier ?
6. Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Que représentent 100 % dans cette enquête ?

::: methode
Le tout de référence est l’ensemble des élèves interrogés ; un pourcentage exprime des parts de ce tout.
:::

::: resultat
Les 140 élèves interrogés.
:::

## Question 2 : Écrire le pourcentage sous forme de fraction de dénominateur 100.

::: methode
Le mot pour cent signifie pour cent parts égales.
:::

::: resultat
$\displaystyle \frac{25}{100}$.
:::

## Question 3 : Donner aussi son écriture décimale.

::: methode
Un centième vaut 0,01 ; écrire la fraction décimale avec une virgule.
:::

::: resultat
$\displaystyle 0{,}25$.
:::

## Question 4 : Combien d’élèves choisissent le dessin ?

::: methode
Calculer une part sur cent puis prendre autant de parts que le taux. Pour 50 %, on peut aussi prendre la moitié ; pour 25 %, le quart.
:::

::: etape $\displaystyle 140\div100\times 25=35$
:::

::: resultat
35 élèves.
:::

## Question 5 : Quel pourcentage et combien d’élèves choisissent un autre atelier ?

::: methode
Enlever du tout la part déjà comptée, en pourcentage puis en effectif.
:::

::: resultat
75 %, soit 105 élèves.
:::

## Question 6 : Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

::: methode
Le pourcentage reste identique mais le tout double ; la quantité correspondante double elle aussi.
:::

::: resultat
70 élèves. Le même pourcentage ne signifie donc pas le même effectif.
:::

[IMAGE_2]

**À retenir :** Nommer le tout de référence avant tout calcul. Pourcentage, écriture décimale et fraction peuvent représenter le même nombre.

Solution:
<!-- optitab:1 -->
1. Les 140 élèves interrogés.
2. $\displaystyle \frac{25}{100}$.
3. $\displaystyle 0{,}25$.
4. 35 élèves.
5. 75 %, soit 105 élèves.
6. 70 élèves. Le même pourcentage ne signifie donc pas le même effectif.

Énoncé:
<!-- optitab:1 -->
Une enquête porte sur 180 élèves. Parmi eux, 50 % choisissent un atelier de dessin ; les autres choisissent un autre atelier. Chaque élève choisit exactement un atelier.

[IMAGE_1]

1. Que représentent 100 % dans cette enquête ?
2. Écrire le pourcentage sous forme de fraction de dénominateur 100.
3. Donner aussi son écriture décimale.
4. Combien d’élèves choisissent le dessin ?
5. Quel pourcentage et combien d’élèves choisissent un autre atelier ?
6. Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Que représentent 100 % dans cette enquête ?

::: methode
Le tout de référence est l’ensemble des élèves interrogés ; un pourcentage exprime des parts de ce tout.
:::

::: resultat
Les 180 élèves interrogés.
:::

## Question 2 : Écrire le pourcentage sous forme de fraction de dénominateur 100.

::: methode
Le mot pour cent signifie pour cent parts égales.
:::

::: resultat
$\displaystyle \frac{50}{100}$.
:::

## Question 3 : Donner aussi son écriture décimale.

::: methode
Un centième vaut 0,01 ; écrire la fraction décimale avec une virgule.
:::

::: resultat
$\displaystyle 0{,}5$.
:::

## Question 4 : Combien d’élèves choisissent le dessin ?

::: methode
Calculer une part sur cent puis prendre autant de parts que le taux. Pour 50 %, on peut aussi prendre la moitié ; pour 25 %, le quart.
:::

::: etape $\displaystyle 180\div100\times 50=90$
:::

::: resultat
90 élèves.
:::

## Question 5 : Quel pourcentage et combien d’élèves choisissent un autre atelier ?

::: methode
Enlever du tout la part déjà comptée, en pourcentage puis en effectif.
:::

::: resultat
50 %, soit 90 élèves.
:::

## Question 6 : Une seconde enquête porte sur deux fois plus d’élèves avec le même pourcentage. Combien choisissent le dessin ?

::: methode
Le pourcentage reste identique mais le tout double ; la quantité correspondante double elle aussi.
:::

::: resultat
180 élèves. Le même pourcentage ne signifie donc pas le même effectif.
:::

[IMAGE_2]

**À retenir :** Nommer le tout de référence avant tout calcul. Pourcentage, écriture décimale et fraction peuvent représenter le même nombre.

Solution:
<!-- optitab:1 -->
1. Les 180 élèves interrogés.
2. $\displaystyle \frac{50}{100}$.
3. $\displaystyle 0{,}5$.
4. 90 élèves.
5. 50 %, soit 90 élèves.
6. 180 élèves. Le même pourcentage ne signifie donc pas le même effectif.
