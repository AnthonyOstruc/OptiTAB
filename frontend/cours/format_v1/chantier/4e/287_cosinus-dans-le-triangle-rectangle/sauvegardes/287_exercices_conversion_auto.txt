=== Découverte - Cosinus - 1. Côté adjacent et hypoténuse
Id: 3650
Difficulté: easy
Image: cosinus_4e_trois_triangles.png,cosinus_4e_trois_triangles_solution.png

Énoncé:
<!-- optitab:1 -->
Voici trois triangles rectangles. Dans chacun, l'angle droit est codé et un angle aigu est marqué en orange : $\widehat{B}$ dans le triangle ①, $\widehat{E}$ dans le triangle ②, $\widehat{K}$ dans le triangle ③.

[IMAGE_1]

1. Dans le triangle ①, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{B}$ ?
2. Dans le triangle ②, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{E}$ ?
3. Dans le triangle ③, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{K}$ ?
4. Écrire $\displaystyle \cos \widehat{B}$, $\displaystyle \cos \widehat{E}$ et $\displaystyle \cos \widehat{K}$ sous forme de quotients de longueurs.
5. Dans le triangle ①, quel est le côté adjacent à l'angle $\displaystyle \widehat{C}$ ? Écrire $\displaystyle \cos \widehat{C}$.
6. Expliquer pourquoi le cosinus d'un angle aigu est toujours compris entre $0$ et $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle 1

::: methode
L'hypoténuse est en face de l'angle droit ; le côté adjacent est le côté de l'angle droit qui part du sommet de l'angle étudié.
:::

::: etape L'angle droit est en $\displaystyle A$
l'hypoténuse est $[BC]$. Les côtés de l'angle droit sont $[AB]$ et $[AC]$ ; celui qui touche $B$ est $[BA]$.
:::

::: resultat
Hypoténuse $[BC]$ ; côté adjacent à $\widehat{B}$ : $[BA]$.
:::

## Question 2 : Le triangle 2

::: etape L'angle droit est en $\displaystyle F$
l'hypoténuse est $[DE]$. Le côté de l'angle droit qui touche $E$ est $[EF]$.
:::

::: resultat
Hypoténuse $[DE]$ ; côté adjacent à $\widehat{E}$ : $[EF]$.
:::

## Question 3 : Le triangle 3

::: etape L'angle droit est en $\displaystyle H$
l'hypoténuse est $[GK]$. Le côté de l'angle droit qui touche $K$ est $[KH]$.
:::

::: resultat
Hypoténuse $[GK]$ ; côté adjacent à $\widehat{K}$ : $[KH]$.
:::

[IMAGE_2]

## Question 4 : Les trois cosinus

::: methode
$$\cos = \frac{\text{côté adjacent}}{\text{hypoténuse}}$$
:::

::: resultat
$\cos \widehat{B} = \frac{BA}{BC}$ ; $\cos \widehat{E} = \frac{EF}{ED}$ ; $\cos \widehat{K} = \frac{KH}{KG}$.
:::

## Question 5 : L'angle C

::: etape
Le côté de l'angle droit qui touche $C$ est $[CA]$ ; l'hypoténuse reste $[BC]$.
:::

::: resultat
Côté adjacent $[CA]$ et $\cos \widehat{C} = \frac{CA}{CB}$.
:::

**Erreur fréquente :** Garder le même côté adjacent pour les deux angles aigus : le côté adjacent dépend de l'angle choisi, seule l'hypoténuse ne change pas.

## Question 6 : Entre 0 et 1

::: etape Le cosinus est un quotient de deux longueurs, donc il est positif.
:::

::: etape
Le côté adjacent est plus court que l'hypoténuse (le plus long côté), donc le quotient est inférieur à $1$.
:::

::: resultat
$\displaystyle 0 < \cos(\text{angle aigu}) < 1$.
:::

**À retenir :** Si un calcul donne un cosinus supérieur à $1$, c'est qu'on a inversé le côté adjacent et l'hypoténuse.

Solution:
<!-- optitab:1 -->
1. $[BC]$ ; $[BA]$
2. $[DE]$ ; $[EF]$
3. $[GK]$ ; $[KH]$
4. $\frac{BA}{BC}$ ; $\frac{EF}{ED}$ ; $\frac{KH}{KG}$
5. $[CA]$ ; $\cos \widehat{C} = \frac{CA}{CB}$
6. Adjacent $\displaystyle <$ hypoténuse

=== Découverte - Cosinus - 2. Calculer deux cosinus
Id: 3651
Difficulté: easy
Image: cosinus_4e_d2.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle DEF$ est rectangle en $\displaystyle E$, avec $\displaystyle DE = 4$ cm, $\displaystyle EF = 3$ cm et $\displaystyle DF = 5$ cm.

[IMAGE_1]

1. Quelle est l'hypoténuse du triangle $\displaystyle DEF$ ?
2. Écrire $\displaystyle \cos \widehat{D}$ avec des longueurs.
3. Calculer $\displaystyle \cos \widehat{D}$.
4. Écrire $\displaystyle \cos \widehat{F}$ avec des longueurs.
5. Calculer $\displaystyle \cos \widehat{F}$.
6. Avec la calculatrice, donner les mesures des angles $\widehat{D}$ et $\widehat{F}$ au degré près. Calculer leur somme.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'hypoténuse

::: etape L'angle droit est en $E$ ; le côté opposé est $[DF]$.
:::

::: resultat
$$[DF]$$
:::

## Question 2 : Cosinus de D

::: etape Côté adjacent à $\displaystyle \widehat{D}$
$[DE]$ ; hypoténuse : $[DF]$.
:::

::: resultat
$$\cos \widehat{D} = \frac{DE}{DF}$$
:::

## Question 3 : Valeur de cos D

::: etape $\displaystyle \cos \widehat{D} = \frac{4}{5}$
:::

::: resultat
$$\cos \widehat{D} = 0{,}8$$
:::

## Question 4 : Cosinus de F

::: etape Côté adjacent à $\displaystyle \widehat{F}$
$[FE]$ ; hypoténuse : $[FD]$.
:::

::: resultat
$$\cos \widehat{F} = \frac{FE}{FD}$$
:::

## Question 5 : Valeur de cos F

::: etape $\displaystyle \cos \widehat{F} = \frac{3}{5}$
:::

::: resultat
$$\cos \widehat{F} = 0{,}6$$
:::

## Question 6 : Les angles

::: methode
Touche cos⁻¹ (ou Arccos), calculatrice en mode degrés.
:::

::: etape
cos⁻¹$(0{,}8) \approx 36{,}87$, donc $\widehat{D} \approx 37°$ ; cos⁻¹$(0{,}6) \approx 53{,}13$, donc $\widehat{F} \approx 53°$.
:::

::: resultat
$\widehat{D} \approx 37°$, $\widehat{F} \approx 53°$ et $37° + 53° = 90°$.
:::

**À retenir :** Dans un triangle rectangle, les deux angles aigus sont complémentaires : leur somme vaut $90°$ (car la somme des trois angles vaut $180°$).

Solution:
<!-- optitab:1 -->
1. $\displaystyle [DF]$
2. $\displaystyle \frac{DE}{DF}$
3. $\displaystyle 0{,}8$
4. $\displaystyle \frac{FE}{FD}$
5. $\displaystyle 0{,}6$
6. $37°$ et $53°$ ; somme $90°$

=== Découverte - Cosinus - 3. Calculer le côté adjacent
Id: 3652
Difficulté: easy
Image: cosinus_4e_d3.png,cosinus_4e_d3_solution.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle ABC$ est rectangle en $\displaystyle A$, avec $\displaystyle BC = 10$ cm et $\displaystyle \widehat{ABC} = 35°$.

[IMAGE_1]

1. Quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\displaystyle \widehat{B}$ ?
2. Écrire $\displaystyle \cos \widehat{B}$ avec des longueurs.
3. Remplacer par les valeurs connues.
4. Calculer $\displaystyle AB$ au millimètre près.
5. Calculer $\displaystyle AC$ au millimètre près, avec le théorème de Pythagore.
6. Calculer $\displaystyle \widehat{C}$, puis vérifier que $\displaystyle \cos \widehat{C} \approx \frac{AC}{BC}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les côtés

::: etape L'angle droit est en $\displaystyle A$
l'hypoténuse est $[BC]$ ; le côté de l'angle droit qui touche $B$ est $[BA]$.
:::

::: resultat
Hypoténuse $[BC]$ ; côté adjacent $[BA]$.
:::

## Question 2 : La formule

::: etape Côté adjacent sur hypoténuse.
:::

::: resultat
$$\cos \widehat{B} = \frac{BA}{BC}$$
:::

## Question 3 : Les valeurs

::: etape $\widehat{B} = 35°$ et $BC = 10$.
:::

::: resultat
$$\cos 35° = \frac{AB}{10}$$
:::

## Question 4 : Le calcul de AB

::: methode
On cherche le côté adjacent : on MULTIPLIE l'hypoténuse par le cosinus.
:::

::: etape $\displaystyle AB = 10 \times \cos 35° \approx 8{,}19$
:::

::: resultat
$\displaystyle AB \approx 8{,}2$ cm
:::

**Rédaction :** Dans le triangle $ABC$ rectangle en $A$ : $\cos \widehat{B} = \frac{AB}{BC}$, donc $\cos 35° = \frac{AB}{10}$ et $AB = 10 \times \cos 35° \approx 8{,}2$ cm.

## Question 5 : Le calcul de AC

::: etape $\displaystyle AC^2 = BC^2 - AB^2 = 100 - (10 \times \cos 35°)^2 \approx 32{,}9$
:::

::: resultat
$\displaystyle AC \approx 5{,}7$ cm
:::

[IMAGE_2]

**Erreur fréquente :** Arrondir $AB$ à $8{,}2$ avant de calculer : on garde la valeur affichée par la calculatrice jusqu'au bout.

## Question 6 : L'angle C

::: etape $\widehat{C} = 90° - 35° = 55°$ (angles aigus complémentaires).
:::

::: etape $\cos 55° \approx 0{,}574$ et $\frac{AC}{BC} \approx \frac{5{,}74}{10} = 0{,}574$.
:::

::: resultat
$\widehat{C} = 55°$ et $\cos \widehat{C} \approx 0{,}574 \approx \frac{AC}{BC}$
:::

Solution:
<!-- optitab:1 -->
1. $[BC]$ ; $[BA]$
2. $\displaystyle \cos \widehat{B} = \frac{BA}{BC}$
3. $\displaystyle \cos 35° = \frac{AB}{10}$
4. $\displaystyle \approx 8{,}2$ cm
5. $\displaystyle \approx 5{,}7$ cm
6. $55°$ ; $\cos 55° \approx 0{,}574$

=== Découverte - Cosinus - 4. Calculer l'hypoténuse
Id: 3653
Difficulté: easy
Image: cosinus_4e_d4.png,cosinus_4e_d4_solution.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle ABC$ est rectangle en $\displaystyle A$, avec $\displaystyle AB = 6$ cm et $\displaystyle \widehat{ABC} = 50°$.

[IMAGE_1]

1. Écrire $\displaystyle \cos \widehat{B}$ avec des longueurs.
2. Remplacer par les valeurs connues.
3. Expliquer pourquoi $\displaystyle BC = \frac{6}{\cos 50°}$.
4. Calculer $\displaystyle BC$ au millimètre près.
5. Vérifier que le résultat est cohérent.
6. Calculer $\displaystyle AC$ au millimètre près.

Étapes:
<!-- optitab:1 -->
## Question 1 : La formule

::: etape Côté adjacent à $\displaystyle \widehat{B}$
$[BA]$ ; hypoténuse : $[BC]$.
:::

::: resultat
$$\cos \widehat{B} = \frac{BA}{BC}$$
:::

## Question 2 : Les valeurs

::: etape $\widehat{B} = 50°$ et $BA = 6$.
:::

::: resultat
$$\cos 50° = \frac{6}{BC}$$
:::

## Question 3 : Isoler BC

::: methode
Produit en croix : on écrit $\displaystyle \cos 50° = \frac{\cos 50°}{1}$.
:::

::: etape $\frac{\cos 50°}{1} = \frac{6}{BC}$ donne $BC \times \cos 50° = 6$.
:::

::: resultat
$$BC = \frac{6}{\cos 50°}$$
:::

**Erreur fréquente :** Écrire $BC = 6 \times \cos 50°$ : on obtiendrait une hypoténuse plus courte que $AB$, ce qui est impossible.

## Question 4 : Le calcul de BC

::: etape $\displaystyle BC = \frac{6}{\cos 50°} \approx 9{,}334$
:::

::: resultat
$\displaystyle BC \approx 9{,}3$ cm
:::

## Question 5 : La cohérence

::: etape L'hypoténuse doit être le plus long côté
$\displaystyle 9{,}3 > 6$.
:::

::: resultat
Le résultat est cohérent.
:::

## Question 6 : Le calcul de AC

::: etape Pythagore
$AC^2 = BC^2 - AB^2 \approx 87{,}13 - 36 = 51{,}13$ (avec la valeur non arrondie de $BC$).
:::

::: resultat
$\displaystyle AC \approx 7{,}2$ cm
:::

[IMAGE_2]

**À retenir :** Avec $BC$ arrondi à $9{,}3$, on trouverait $AC \approx 7{,}1$ cm : les arrondis intermédiaires faussent le résultat.

Solution:
<!-- optitab:1 -->
1. $\displaystyle \frac{BA}{BC}$
2. $\displaystyle \cos 50° = \frac{6}{BC}$
3. $\displaystyle BC \times \cos 50° = 6$
4. $\displaystyle \approx 9{,}3$ cm
5. $\displaystyle 9{,}3 > 6$
6. $\displaystyle \approx 7{,}2$ cm

=== Découverte - Cosinus - 5. Calculer un angle
Id: 3654
Difficulté: easy
Image: cosinus_4e_d5.png,cosinus_4e_d5_solution.png

Énoncé:
<!-- optitab:1 -->
Le triangle $\displaystyle ABC$ est rectangle en $\displaystyle A$, avec $\displaystyle AB = 4$ cm et $\displaystyle BC = 7$ cm.

[IMAGE_1]

1. Écrire $\displaystyle \cos \widehat{B}$, puis le calculer sous forme de fraction.
2. Quelle touche de la calculatrice permet de retrouver l'angle ? Dans quel mode doit-elle être ?
3. Donner la mesure de $\displaystyle \widehat{B}$ au degré près.
4. En déduire la mesure de $\displaystyle \widehat{C}$ au degré près.
5. Calculer $\displaystyle AC$, puis $\displaystyle \cos \widehat{C}$, et retrouver $\displaystyle \widehat{C}$ avec la calculatrice.
6. Résumer la méthode pour calculer un angle avec le cosinus.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le cosinus de B

::: etape $\displaystyle \cos \widehat{B} = \frac{BA}{BC}$
:::

::: resultat
$$\cos \widehat{B} = \frac{4}{7}$$
:::

## Question 2 : La touche

::: etape cos⁻¹ fait le chemin inverse de cos
on donne le cosinus, elle renvoie l'angle.
:::

::: resultat
La touche cos⁻¹ (ou Arccos), en mode degrés.
:::

## Question 3 : L'angle B

::: etape cos⁻¹$\displaystyle \left(\frac{4}{7}\right) \approx 55{,}15$
:::

::: resultat
$$\widehat{B} \approx 55°$$
:::

## Question 4 : L'angle C

::: etape $\displaystyle \widehat{C} = 90° - \widehat{B} \approx 90° - 55{,}15° = 34{,}85°$
:::

::: resultat
$$\widehat{C} \approx 35°$$
:::

## Question 5 : Vérification par le cosinus

::: etape $AC^2 = 49 - 16 = 33$, donc $AC = \sqrt{33} \approx 5{,}74$ cm.
:::

::: etape
$\cos \widehat{C} = \frac{CA}{CB} = \frac{\sqrt{33}}{7} \approx 0{,}821$ et cos⁻¹$(0{,}821) \approx 34{,}85$.
:::

::: resultat
$\widehat{C} \approx 35°$ : les deux méthodes concordent.
:::

[IMAGE_2]

## Question 6 : La méthode

::: etape Exemple
$\cos \widehat{B} = \frac{4}{7}$, puis cos⁻¹ donne $\widehat{B} \approx 55°$.
:::

::: resultat
On écrit le cosinus de l'angle (adjacent sur hypoténuse), on le calcule, puis on applique la touche cos⁻¹.
:::

**À retenir :** Pour trouver un angle, il faut connaître le côté adjacent ET l'hypoténuse.

Solution:
<!-- optitab:1 -->
1. $\displaystyle \frac{4}{7}$
2. cos⁻¹, mode degrés
3. $\displaystyle \approx 55°$
4. $\displaystyle \approx 35°$
5. $\displaystyle \approx 35°$
6. $\displaystyle \cos = \frac{\text{adj}}{\text{hyp}}$ puis cos⁻¹

=== Découverte - Cosinus - 6. Un tableau de cosinus
Id: 3655
Difficulté: easy
Image: cosinus_4e_tableau.png,cosinus_4e_tableau_solution.png

Énoncé:
<!-- optitab:1 -->
On veut compléter le tableau ci-dessous avec la calculatrice (en mode degrés).

[IMAGE_1]

1. Calculer $\displaystyle \cos 60°$.
2. Calculer $\displaystyle \cos 20°$, $\displaystyle \cos 30°$ et $\displaystyle \cos 45°$ au millième.
3. Calculer $\displaystyle \cos 70°$ et $\displaystyle \cos 89°$ au millième.
4. Comment varie le cosinus quand l'angle augmente ?
5. Sans calculatrice, comparer $\displaystyle \cos 25°$ et $\displaystyle \cos 65°$.
6. Trouver, au degré près, l'angle dont le cosinus vaut $0{,}9$. Peut-on trouver un angle dont le cosinus vaut $1{,}2$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : cos 60°

::: etape La calculatrice affiche $\displaystyle 0{,}5$.
:::

::: resultat
$$\cos 60° = 0{,}5$$
:::

## Question 2 : Trois valeurs

::: etape
$\cos 20° \approx 0{,}9397$ ; $\cos 30° \approx 0{,}8660$ ; $\cos 45° \approx 0{,}7071$.
:::

::: resultat
$0{,}940$ ; $0{,}866$ ; $0{,}707$.
:::

## Question 3 : Deux autres valeurs

::: etape $\cos 70° \approx 0{,}3420$ ; $\cos 89° \approx 0{,}0175$.
:::

::: resultat
$0{,}342$ et $0{,}017$.
:::

[IMAGE_2]

## Question 4 : Le sens de variation

::: etape En lisant le tableau de gauche à droite, les cosinus diminuent
$\displaystyle 0{,}940 > 0{,}866 > \ldots > 0{,}017$.
:::

::: resultat
Quand l'angle augmente, son cosinus diminue.
:::

**À retenir :** Un grand angle aigu « couche » l'hypoténuse vers la verticale : le côté adjacent rétrécit, donc le cosinus diminue.

## Question 5 : Comparaison

::: etape $25° < 65°$ et le cosinus diminue quand l'angle augmente.
:::

::: resultat
$$\cos 25° > \cos 65°$$
:::

## Question 6 : Les angles cherchés

::: etape cos⁻¹$(0{,}9) \approx 25{,}8$, donc l'angle mesure environ $26°$.
:::

::: etape $\displaystyle 1{,}2 > 1$
un cosinus d'angle aigu est toujours inférieur à $1$.
:::

::: resultat
Environ $26°$ ; aucun angle n'a pour cosinus $1{,}2$ (la calculatrice affiche une erreur).
:::

**Erreur fréquente :** Croire que la calculatrice « bugue » : le message d'erreur signale ici un calcul impossible.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 0{,}5$
2. $0{,}940$ ; $0{,}866$ ; $0{,}707$
3. $0{,}342$ ; $0{,}017$
4. Il diminue
5. $\displaystyle \cos 25° > \cos 65°$
6. $\approx 26°$ ; impossible pour $1{,}2$

=== Découverte - Cosinus - 7. Vrai ou faux
Id: 3656
Difficulté: easy
Image: cosinus_4e_agrandissement.png

Énoncé:
<!-- optitab:1 -->
Dire si chaque affirmation est vraie ou fausse, en justifiant. La figure montre deux triangles rectangles, l'un étant l'agrandissement de l'autre.

[IMAGE_1]

1. « Le cosinus d'un angle aigu peut valoir $\displaystyle 1{,}5$. »
2. « Dans un triangle $\displaystyle ABC$ rectangle en $\displaystyle A$, $\displaystyle \cos \widehat{B} = \frac{AB}{BC}$. »
3. « $\displaystyle \cos 60° = 0{,}5$. »
4. « Si on double les longueurs d'un triangle rectangle, le cosinus de ses angles double aussi. »
5. « $\displaystyle \cos 60° = 2 \times \cos 30°$. »
6. « Si $\displaystyle \cos \widehat{B} = 0{,}5$, alors $\displaystyle \widehat{B} = 60°$. »

Étapes:
<!-- optitab:1 -->
## Question 1 : Affirmation 1

::: etape
Le côté adjacent est plus court que l'hypoténuse, donc le cosinus est inférieur à $1$.
:::

::: resultat
Faux.
:::

## Question 2 : Affirmation 2

::: etape
Le côté adjacent à $\widehat{B}$ est $[AB]$, l'hypoténuse est $[BC]$.
:::

::: resultat
Vrai.
:::

## Question 3 : Affirmation 3

::: etape La calculatrice donne $\displaystyle \cos 60° = 0{,}5$.
:::

::: resultat
Vrai.
:::

## Question 4 : Affirmation 4

::: etape Sur la figure
$\frac{4}{5} = 0{,}8$ et $\frac{8}{10} = 0{,}8$. Les deux longueurs du quotient doublent, le quotient ne change pas.
:::

::: resultat
Faux : le cosinus reste le même, il ne dépend que de l'angle.
:::

**À retenir :** Agrandir ou réduire un triangle conserve ses angles, donc leurs cosinus.

## Question 5 : Affirmation 5

::: etape $\cos 60° = 0{,}5$ et $2 \times \cos 30° \approx 2 \times 0{,}866 = 1{,}732$.
:::

::: resultat
Faux : le cosinus n'est pas proportionnel à l'angle.
:::

**Erreur fréquente :** Croire que doubler l'angle double le cosinus : c'est même l'inverse, le cosinus diminue.

## Question 6 : Affirmation 6

::: etape cos⁻¹$\displaystyle (0{,}5) = 60$.
:::

::: resultat
Vrai.
:::

Solution:
<!-- optitab:1 -->
1. Faux
2. Vrai
3. Vrai
4. Faux
5. Faux
6. Vrai

=== Entraînement - Cosinus - 1. L'échelle contre le mur
Id: 3657
Difficulté: medium
Image: cosinus_4e_echelle.png,cosinus_4e_echelle_solution.png

Énoncé:
<!-- optitab:1 -->
Une échelle $[AB]$ de $5$ m est posée contre un mur vertical ; le sol est horizontal. Elle fait avec le sol un angle $\widehat{BAC} = 70°$. Pour être stable et sûre, une échelle doit faire avec le sol un angle compris entre $65°$ et $75°$.

[IMAGE_1]

1. Pourquoi le triangle $\displaystyle ABC$ est-il rectangle ? Quelle est son hypoténuse ?
2. Calculer la distance $AC$ entre le pied de l'échelle et le mur, au centimètre près.
3. Calculer la hauteur $\displaystyle BC$ atteinte par l'échelle, au centimètre près.
4. On place le pied de l'échelle à $2$ m du mur. Quel angle fait-elle avec le sol, au degré près ?
5. On place le pied à $\displaystyle 1$ m du mur. L'échelle est-elle sûre ?
6. Entre quelles distances du mur faut-il placer le pied de l'échelle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle rectangle

::: etape Le mur est vertical et le sol horizontal
$\displaystyle (BC) \perp (AC)$.
:::

::: resultat
$ABC$ est rectangle en $C$ ; son hypoténuse est l'échelle $[AB]$.
:::

## Question 2 : La distance AC

::: methode
$AC$ est le côté adjacent à l'angle $\widehat{A}$ : on multiplie l'hypoténuse par le cosinus.
:::

::: etape $\cos 70° = \frac{AC}{5}$, donc $AC = 5 \times \cos 70° \approx 1{,}710$.
:::

::: resultat
$\displaystyle AC \approx 1{,}71$ m
:::

## Question 3 : La hauteur BC

::: etape Pythagore
$$
\begin{aligned}
BC^2 &= AB^2 - AC^2 \\
&= 25 - (5 \times \cos 70°)^2 \approx 22{,}08
\end{aligned}
$$
:::

::: resultat
$\displaystyle BC \approx 4{,}70$ m
:::

[IMAGE_2]

## Question 4 : Pied à 2 m

::: etape $\cos \widehat{A} = \frac{2}{5} = 0{,}4$, donc $\widehat{A} \approx 66{,}4°$.
:::

::: resultat
Environ $\displaystyle 66°$ : l'échelle est sûre.
:::

## Question 5 : Pied à 1 m

::: etape $\cos \widehat{A} = \frac{1}{5} = 0{,}2$, donc $\widehat{A} \approx 78{,}5°$.
:::

::: resultat
Environ $78°$ : c'est plus que $75°$, l'échelle est trop droite et risque de basculer en arrière.
:::

## Question 6 : Les distances limites

::: etape Pour $\displaystyle 65°$
$5 \times \cos 65° \approx 2{,}11$ m ; pour $75°$ : $5 \times \cos 75° \approx 1{,}29$ m.
:::

::: resultat
Le pied doit être entre $1{,}29$ m et $2{,}11$ m du mur.
:::

**À retenir :** Plus l'angle est grand, plus le pied est près du mur : le cosinus diminue quand l'angle augmente.

Solution:
<!-- optitab:1 -->
1. Rectangle en $C$ ; hypoténuse $[AB]$
2. $\displaystyle \approx 1{,}71$ m
3. $\displaystyle \approx 4{,}70$ m
4. $\displaystyle \approx 66°$
5. Non ($\displaystyle \approx 78°$)
6. Entre $1{,}29$ m et $2{,}11$ m

=== Entraînement - Cosinus - 2. Le cerf-volant
Id: 3658
Difficulté: medium
Image: cosinus_4e_cerf_volant.png,cosinus_4e_cerf_volant_solution.png

Énoncé:
<!-- optitab:1 -->

[IMAGE_1]

1. Quel est le triangle rectangle à utiliser ? Quelle est son hypoténuse ?
2. Calculer la distance horizontale $\displaystyle MH$, au dixième de mètre.
3. Calculer $\displaystyle HK$, au dixième de mètre.
4. À quelle hauteur au-dessus du sol vole le cerf-volant ?
5. Le vent forcit et la ficelle fait maintenant un angle de $60°$ avec l'horizontale. Calculer la nouvelle distance $MH$.
6. Avec une ficelle de $80$ m, le cerf-volant est à $40$ m de Léa à l'horizontale. Quel angle fait la ficelle avec l'horizontale ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle

::: etape $H$ est à la verticale de $K$ et à la hauteur de la main
$\displaystyle (MH) \perp (HK)$.
:::

::: resultat
Le triangle $MHK$, rectangle en $H$, d'hypoténuse la ficelle $[MK]$.
:::

## Question 2 : La distance MH

::: etape $\cos 40° = \frac{MH}{MK}$, donc $MH = 50 \times \cos 40° \approx 38{,}30$.
:::

::: resultat
$\displaystyle MH \approx 38{,}3$ m
:::

## Question 3 : La longueur HK

::: etape Pythagore
$$
\begin{aligned}
HK^2 &= 50^2 - MH^2 \approx 2\,500 - 1\,467{,}1 \\
&= 1\,032{,}9
\end{aligned}
$$
:::

::: resultat
$\displaystyle HK \approx 32{,}1$ m
:::

[IMAGE_2]

## Question 4 : La hauteur du cerf-volant

::: etape On ajoute la hauteur de la main
$\displaystyle 32{,}1 + 1$.
:::

::: resultat
Environ $\displaystyle 33{,}1$ m au-dessus du sol.
:::

**Erreur fréquente :** Oublier le mètre entre le sol et la main : le triangle rectangle commence à la hauteur de la main.

## Question 5 : Avec un angle de 60°

::: etape $\displaystyle MH = 50 \times \cos 60° = 50 \times 0{,}5$
:::

::: resultat
$\displaystyle MH = 25$ m
:::

**Vérification :** L'angle augmente, le cosinus diminue : le cerf-volant se rapproche à l'horizontale ($25 < 38{,}3$).

## Question 6 : L'angle avec 80 m

::: etape $\displaystyle \cos \widehat{M} = \frac{40}{80} = 0{,}5$
:::

::: resultat
L'angle mesure $\displaystyle 60°$.
:::

Étapes:
<!-- optitab:1 -->
## Question 1 : La diagonale

::: etape Le triangle $ABC$ est rectangle en $B$
$\displaystyle AC^2 = 8^2 + 6^2 = 100$.
:::

::: resultat
$\displaystyle AC = 10$ cm
:::

## Question 2 : Le cosinus

::: etape
Dans $ABC$ rectangle en $B$, le côté adjacent à $\widehat{CAB}$ est $[AB]$.
:::

::: resultat
$$
\begin{aligned}
\cos \widehat{CAB} &= \frac{AB}{AC} \\
&= \frac{8}{10} \\
&= 0{,}8
\end{aligned}
$$

## Question 3 : L'angle CAB

::: etape cos⁻¹$\displaystyle (0{,}8) \approx 36{,}87$
:::

::: resultat
$$\widehat{CAB} \approx 36{,}9°$$
:::

## Question 4 : L'angle ACB

::: etape Angles aigus complémentaires
$\displaystyle 90° - 36{,}87° = 53{,}13°$.
:::

::: resultat
$$\widehat{ACB} \approx 53{,}1°$$
:::

## Question 5 : L'angle entre les diagonales

::: methode
Les diagonales d'un rectangle ont la même longueur et se coupent en leur milieu : $OA = OB = 5$ cm, donc $AOB$ est isocèle en $O$.
:::

::: etape
$\widehat{OBA} = \widehat{OAB} \approx 36{,}87°$, donc $\widehat{AOB} \approx 180° - 2 \times 36{,}87° = 106{,}26°$.
:::

::: resultat
$$\widehat{AOB} \approx 106{,}3°$$
:::

[IMAGE_2]

## Question 6 : La feuille A4

$\displaystyle \sqrt{21^2 + 29{,}7^2} = \sqrt{1\,323{,}09} \approx 36{,}37$ cm.

::: etape
$\cos \alpha = \frac{29{,}7}{36{,}37} \approx 0{,}8165$, donc $\alpha \approx 35{,}3°$.
:::

::: resultat
Environ $\displaystyle 35{,}3°$.
:::

**À retenir :** Pour un angle formé par une diagonale, le rectangle se découpe en deux triangles rectangles : Pythagore donne la diagonale, le cosinus donne l'angle.

Solution:
<!-- optitab:1 -->
1. $\displaystyle 10$ cm
2. $\displaystyle 0{,}8$

=== Entraînement - Cosinus - 6. Corriger des erreurs

Énoncé:
<!-- optitab:1 -->
Le triangle $RST$ est rectangle en $S$, avec $RS = 5$ cm, $ST = 12$ cm et $RT = 13$ cm. Trois élèves calculent les angles $\widehat{R}$ (en orange) et $\widehat{T}$ (en vert).

[IMAGE_1]

1. Noé écrit : « $\displaystyle \cos \widehat{R} = \frac{RS}{ST} = \frac{5}{12}$ ». Quelle est son erreur ? Écrire le bon quotient.
2. Calculer $\displaystyle \widehat{R}$ au dixième de degré.
3. Inès trouve « $\displaystyle \widehat{R} \approx 1{,}176$ ». Que s'est-il passé ?
4. Sacha écrit : « $\displaystyle \cos \widehat{T} = \frac{RT}{ST} = \frac{13}{12}$ ». Pourquoi est-ce forcément faux ?
5. Calculer correctement $\displaystyle \widehat{T}$ au dixième de degré.
6. Vérifier les résultats avec la somme des angles.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'erreur de Noé

::: etape
Le dénominateur doit être l'hypoténuse $[RT]$, opposée à l'angle droit $S$ ; $[ST]$ est le côté opposé à $\widehat{R}$.
:::

::: resultat
$$\cos \widehat{R} = \frac{RS}{RT} = \frac{5}{13}$$
:::

## Question 2 : L'angle R

::: etape cos⁻¹$\displaystyle \left(\frac{5}{13}\right) \approx 67{,}38$
:::

::: resultat
$$\widehat{R} \approx 67{,}4°$$
:::

## Question 3 : Le résultat d'Inès

::: etape
$1{,}176$ n'est pas une mesure en degrés plausible pour cet angle (il est visiblement plus grand que $45°$).
:::

::: resultat
Sa calculatrice était en mode radians : il faut passer en mode degrés.
:::

**Erreur fréquente :** Ne pas vérifier le mode de la calculatrice : c'est l'erreur la plus fréquente avec cos et cos⁻¹.

## Question 4 : L'erreur de Sacha

::: etape $\displaystyle \frac{13}{12} > 1$
un cosinus d'angle aigu est toujours inférieur à $1$.
:::

::: resultat
Sacha a inversé : l'hypoténuse doit être au dénominateur. $\cos \widehat{T} = \frac{TS}{TR} = \frac{12}{13}$.
:::

## Question 5 : L'angle T

::: etape cos⁻¹$\displaystyle \left(\frac{12}{13}\right) \approx 22{,}62$
:::

::: resultat
$$\widehat{T} \approx 22{,}6°$$
:::

## Question 6 : La vérification

::: etape $\displaystyle 67{,}38° + 22{,}62° = 90°$
:::

::: resultat
Les deux angles aigus sont bien complémentaires : les résultats sont cohérents.
:::

**À retenir :** Trois contrôles rapides : le cosinus est entre $0$ et $1$, la calculatrice est en degrés, les deux angles aigus font $90°$.

Solution:
<!-- optitab:1 -->
1. $\displaystyle \frac{5}{13}$
2. $\displaystyle \approx 67{,}4°$
3. Mode radians au lieu de degrés
4. $\displaystyle \frac{13}{12} > 1$ impossible
5. $\displaystyle \approx 22{,}6°$
6. $\displaystyle 67{,}4° + 22{,}6° = 90°$

=== Problème - Cosinus - 2. Le décollage
Id: 3665
Difficulté: hard
Image: cosinus_4e_avion.png,cosinus_4e_avion_solution.png

Énoncé:
<!-- optitab:1 -->
Un avion décolle du point $O$ et monte en ligne droite en faisant un angle de $15°$ avec le sol horizontal. Une colline de $300$ m de haut se trouve à $2$ km du point $O$ (distance mesurée au sol).

[IMAGE_1]

1. Après $3$ km parcourus sur sa trajectoire, l'avion est en $P$. Calculer la distance au sol $OH$, au mètre près.
2. Calculer l'altitude $\displaystyle HP$ de l'avion, au mètre près.
3. Quand l'avion passe au-dessus de la colline, il est à $2\,000$ m de $O$ au sol. Quelle distance $OK$ a-t-il parcourue sur sa trajectoire ? (au mètre près)
4. Quelle est alors son altitude ? Passe-t-il au-dessus de la colline, et avec quelle marge ?
5. Pourquoi est-il important d'utiliser des valeurs non arrondies dans les calculs ?
6. Un autre avion doit atteindre $1\,000$ m d'altitude après $4$ km de trajectoire. Quel angle doit-il faire avec le sol, au dixième de degré ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La distance au sol

::: etape
Le triangle $OHP$ est rectangle en $H$, d'hypoténuse $[OP] = 3\,000$ m.
:::

::: etape $\displaystyle OH = 3\,000 \times \cos 15° \approx 2\,897{,}8$
:::

::: resultat
$\displaystyle OH \approx 2\,898$ m
:::

## Question 2 : L'altitude HP

::: etape Pythagore
$$HP^2 = 3\,000^2 - OH^2 \approx 602\,886$$
:::

::: resultat
$\displaystyle HP \approx 776$ m
:::

## Question 3 : La distance OK

::: methode
Cette fois, on connaît le côté adjacent ($2\,000$ m) et on cherche l'hypoténuse : on DIVISE par le cosinus.
:::

::: etape
$\cos 15° = \frac{2\,000}{OK}$, donc $OK = \frac{2\,000}{\cos 15°} \approx 2\,070{,}6$.
:::

::: resultat
$\displaystyle OK \approx 2\,071$ m
:::

## Question 4 : Au-dessus de la colline

::: etape Pythagore
altitude$^2 = OK^2 - 2\,000^2 \approx 287\,187$, donc l'altitude vaut environ $536$ m.
:::

::: etape $\displaystyle 536 - 300 = 236$
:::

::: resultat
Oui : l'avion passe à environ $536$ m d'altitude, soit environ $236$ m au-dessus de la colline.
:::

[IMAGE_2]

## Question 5 : Les arrondis

::: etape
Avec $OK$ arrondi à $2\,071$ m, on obtiendrait $\sqrt{2\,071^2 - 2\,000^2} \approx 537{,}6$ m au lieu de $535{,}9$ m.
:::

::: resultat
Les petits écarts d'arrondi sont amplifiés par Pythagore : on garde les valeurs exactes en mémoire.
:::

**Erreur fréquente :** Arrondir à chaque étape : le résultat final peut être faux de plusieurs unités.

## Question 6 : Le second avion

::: etape Distance au sol
$\displaystyle \sqrt{4\,000^2 - 1\,000^2} = \sqrt{15\,000\,000} \approx 3\,873$ m.
:::

::: etape
$\cos \alpha = \frac{3\,873}{4\,000} \approx 0{,}968$, donc $\alpha \approx 14{,}5°$.
:::

::: resultat
Il doit monter avec un angle d'environ $14{,}5°$.
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \approx 2\,898$ m
2. $\displaystyle \approx 776$ m
3. $\displaystyle \approx 2\,071$ m
4. Oui, à $\approx 536$ m (marge $\approx 236$ m)
5. Les arrondis s'accumulent
6. $\displaystyle \approx 14{,}5°$

=== Problème - Cosinus - 3. La pente d'un toit
Id: 3666
Difficulté: hard
Image: cosinus_4e_toit.png,cosinus_4e_toit_solution.png

Énoncé:
<!-- optitab:1 -->
La façade d'une maison de $9$ m de large est surmontée d'un toit symétrique $ABC$ dont les chevrons $[AB]$ et $[AC]$ mesurent $5{,}5$ m. $I$ est le milieu de $[BC]$.

[IMAGE_1]

1. Pourquoi le triangle $\displaystyle ABI$ est-il rectangle en $\displaystyle I$ ? Calculer $\displaystyle BI$.
2. Calculer l'angle $\widehat{ABC}$ que fait le toit avec l'horizontale, au dixième de degré.
3. Calculer la hauteur $\displaystyle AI$ du toit, au centimètre près.
4. Une autre maison de $10$ m de large a un toit symétrique incliné à $30°$. Calculer la longueur des chevrons, au centimètre près.
5. Calculer la hauteur de ce second toit, au centimètre près.
6. Ce second toit est long de $12$ m. Calculer l'aire de ses deux pans, puis le nombre de tuiles nécessaires à raison de $10$ tuiles par m².

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle ABI

::: etape $ABC$ est isocèle en $A$ ($AB = AC$) et $I$ est le milieu de $[BC]$
la médiane $(AI)$ est aussi la hauteur.
:::

::: resultat
$ABI$ est rectangle en $I$ et $BI = 9 : 2 = 4{,}5$ m.
:::

## Question 2 : L'angle du toit

::: etape $\displaystyle \cos \widehat{ABC} = \frac{BI}{BA} = \frac{4{,}5}{5{,}5} \approx 0{,}818$
:::

::: resultat
$$\widehat{ABC} \approx 35{,}1°$$
:::

## Question 3 : La hauteur AI

::: etape Pythagore
$$AI^2 = 5{,}5^2 - 4{,}5^2 = 30{,}25 - 20{,}25 = 10$$
:::

::: resultat
$\displaystyle AI = \sqrt{10} \approx 3{,}16$ m
:::

[IMAGE_2]

## Question 4 : Les chevrons du second toit

::: methode
On connaît le côté adjacent (la demi-largeur $5$ m) et l'angle : on cherche l'hypoténuse, on divise.
:::

::: etape $\cos 30° = \frac{5}{\ell}$, donc $\ell = \frac{5}{\cos 30°} \approx 5{,}774$.
:::

::: resultat
Les chevrons mesurent environ $5{,}77$ m.
:::

## Question 5 : La hauteur du second toit

::: etape Pythagore
$$h^2 = \ell^2 - 5^2 \approx 33{,}33 - 25 = 8{,}33$$
:::

::: resultat
$\displaystyle h \approx 2{,}89$ m
:::

## Question 6 : La surface et les tuiles

::: etape Chaque pan est un rectangle de $12$ m sur $\ell$
aire totale $\displaystyle 2 \times 12 \times \ell \approx 138{,}56$ m².
:::

::: etape $\displaystyle 138{,}56 \times 10 \approx 1\,385{,}6$
on arrondit à l'unité supérieure.
:::

::: resultat
Environ $138{,}6$ m² de toit et $1\,386$ tuiles.
:::

**À retenir :** Pour acheter du matériel, on arrondit toujours au-dessus : $1\,385$ tuiles ne suffiraient pas.

Solution:
<!-- optitab:1 -->
1. Rectangle en $I$ ; $BI = 4{,}5$ m
2. $\displaystyle \approx 35{,}1°$
3. $\displaystyle \approx 3{,}16$ m
4. $\displaystyle \approx 5{,}77$ m
5. $\displaystyle \approx 2{,}89$ m
6. $\approx 138{,}6$ m² ; $1\,386$ tuiles

=== Problème - Cosinus - 4. La route du bateau
Id: 3667
Difficulté: hard
Image: cosinus_4e_bateau.png,cosinus_4e_bateau_solution.png

Énoncé:
<!-- optitab:1 -->
Un bateau quitte le port $O$ et parcourt $12$ km en ligne droite dans une direction qui fait un angle de $40°$ avec la direction du nord, vers l'est. Il arrive en $P$, puis parcourt $5$ km plein est jusqu'en $Q$. $H$ est le point de l'axe nord tel que $(HP)$ soit dirigée vers l'est.

[IMAGE_1]

1. Pourquoi le triangle $\displaystyle OHP$ est-il rectangle en $\displaystyle H$ ? Quelle est son hypoténuse ?
2. Calculer $\displaystyle OH$ (distance parcourue vers le nord), au centième de km.
3. Calculer $\displaystyle HP$ (distance parcourue vers l'est), au centième de km.
4. Calculer la distance $\displaystyle OQ$ entre le bateau et le port, au dixième de km.
5. Quel angle la direction $\displaystyle (OQ)$ fait-elle avec le nord, au dixième de degré ?
6. Le bateau rentre directement au port à $20$ km/h. Combien de temps dure le retour, à la minute près ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle OHP

::: etape La direction nord et la direction est sont perpendiculaires
$\displaystyle (OH) \perp (HP)$.
:::

::: resultat
$OHP$ est rectangle en $H$ ; son hypoténuse est $[OP] = 12$ km.
:::

## Question 2 : La distance vers le nord

::: etape $[OH]$ est adjacent à l'angle de $40°$
$\displaystyle OH = 12 \times \cos 40° \approx 9{,}193$.
:::

::: resultat
$\displaystyle OH \approx 9{,}19$ km
:::

## Question 3 : La distance vers l'est

::: etape Pythagore
$$HP^2 = 144 - OH^2 \approx 59{,}50$$
:::

::: resultat
$\displaystyle HP \approx 7{,}71$ km
:::

## Question 4 : La distance OQ

::: etape $Q$ est sur $(HP)$
$HQ = HP + 5 \approx 12{,}71$ km, et $OHQ$ est rectangle en $H$.
:::

::: etape $\displaystyle OQ^2 = OH^2 + HQ^2 \approx 84{,}50 + 161{,}63 = 246{,}13$
:::

::: resultat
$\displaystyle OQ \approx 15{,}7$ km
:::

[IMAGE_2]

## Question 5 : L'angle avec le nord

::: etape $\displaystyle \cos \widehat{HOQ} = \frac{OH}{OQ} \approx \frac{9{,}193}{15{,}689} \approx 0{,}586$
:::

::: resultat
$$\widehat{HOQ} \approx 54{,}1°$$
:::

**Vérification :** L'angle a augmenté ($54{,}1° > 40°$) : normal, le bateau s'est encore décalé vers l'est.

## Question 6 : La durée du retour

::: etape $t = \frac{15{,}689}{20} \approx 0{,}784$ h et $0{,}784 \times 60 \approx 47$ min.
:::

::: resultat
Environ $\displaystyle 47$ minutes.
:::

**À retenir :** En navigation, on décompose un trajet selon le nord et l'est : chaque morceau est un côté d'un triangle rectangle.

Solution:
<!-- optitab:1 -->
1. Rectangle en $H$ ; hypoténuse $[OP]$
2. $\displaystyle \approx 9{,}19$ km
3. $\displaystyle \approx 7{,}71$ km
4. $\displaystyle \approx 15{,}7$ km
5. $\displaystyle \approx 54{,}1°$
6. $\displaystyle \approx 47$ min

=== Problème - Cosinus - 5. Le pendule
Id: 3668
Difficulté: hard
Image: cosinus_4e_pendule.png,cosinus_4e_pendule_solution.png

Énoncé:
<!-- optitab:1 -->
Un pendule est formé d'un fil $[OB]$ de $1{,}2$ m accroché en $O$. Au repos, la boule est en $B_0$, à la verticale de $O$. On écarte le fil d'un angle de $30°$ : la boule est en $B$, et $H$ est le point de $[OB_0]$ à la même hauteur que $B$.

[IMAGE_1]

1. Calculer $\displaystyle OH$ au centième de mètre.
2. De combien de centimètres la boule est-elle montée ? (distance $HB_0$, au centimètre)
3. Calculer l'écart horizontal $\displaystyle HB$.
4. On écarte le fil de $\displaystyle 60°$. De combien la boule monte-t-elle ?
5. De quel angle faut-il écarter le fil pour que la boule monte de $30$ cm ? (au dixième de degré)
6. Pourquoi la boule ne peut-elle pas monter de plus de $1{,}2$ m en restant sous le point $O$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La longueur OH

::: etape
$OHB$ est rectangle en $H$, d'hypoténuse le fil $[OB] = 1{,}2$ m ; $[OH]$ est adjacent à l'angle de $30°$.
:::

::: etape $\displaystyle OH = 1{,}2 \times \cos 30° \approx 1{,}039$
:::

::: resultat
$\displaystyle OH \approx 1{,}04$ m
:::

## Question 2 : La montée

::: etape $\displaystyle HB_0 = OB_0 - OH = 1{,}2 - 1{,}039 \approx 0{,}161$ m
:::

::: resultat
La boule est montée d'environ $16$ cm.
:::

**Erreur fréquente :** Répondre $1{,}04$ m : $OH$ est la distance au point d'accroche, pas la hauteur gagnée.

## Question 3 : L'écart horizontal

::: etape Pythagore
$$HB^2 = 1{,}2^2 - OH^2 = 1{,}44 - 1{,}08 = 0{,}36$$
:::

::: resultat
$\displaystyle HB = 0{,}6$ m
:::

[IMAGE_2]

## Question 4 : Avec 60°

::: etape
$OH = 1{,}2 \times \cos 60° = 0{,}6$ m, donc la montée vaut $1{,}2 - 0{,}6 = 0{,}6$ m.
:::

::: resultat
La boule monte de $\displaystyle 60$ cm.
:::

## Question 5 : Pour monter de 30 cm

::: etape
Il faut $OH = 1{,}2 - 0{,}3 = 0{,}9$ m, donc $\cos \alpha = \frac{0{,}9}{1{,}2} = 0{,}75$.
:::

::: resultat
$$\alpha \approx 41{,}4°$$
:::

## Question 6 : La limite

::: etape Sous $O$, l'angle reste inférieur à $90°$
$\displaystyle OH = 1{,}2 \times \cos \alpha$ reste positif.
:::

::: resultat
La montée $1{,}2 - OH$ est donc toujours inférieure à $1{,}2$ m ; elle atteindrait $1{,}2$ m pour un fil horizontal.
:::

**À retenir :** Le cosinus permet de passer d'un angle à une distance verticale : c'est l'outil de base des physiciens pour étudier les pendules.

Solution:
<!-- optitab:1 -->
1. $\displaystyle \approx 1{,}04$ m
2. $\displaystyle \approx 16$ cm
3. $\displaystyle 0{,}6$ m
4. $\displaystyle 60$ cm
5. $\displaystyle \approx 41{,}4°$
6. $\displaystyle OH > 0$ tant que l'angle est aigu

=== Problème - Cosinus - 6. Le losange
Id: 3669
Difficulté: hard
Image: cosinus_4e_losange.png,cosinus_4e_losange_solution.png

Énoncé:
<!-- optitab:1 -->
$\displaystyle ABCD$ est un losange de côté $\displaystyle 6$ cm avec $\displaystyle \widehat{DAB} = 70°$. Ses diagonales se coupent en $\displaystyle O$.

[IMAGE_1]

1. Justifier que le triangle $\displaystyle AOD$ est rectangle en $\displaystyle O$ et que $\displaystyle \widehat{OAD} = 35°$.
2. Calculer $\displaystyle AO$ au centième.
3. En déduire la longueur de la diagonale $\displaystyle [AC]$ au centième.
4. Calculer $\displaystyle OD$ au centième, puis la diagonale $\displaystyle [BD]$.
5. Calculer l'aire du losange au dixième.
6. Calculer $\displaystyle \widehat{ADC}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle AOD

::: etape Les diagonales d'un losange sont perpendiculaires
$\displaystyle (AC) \perp (BD)$.
:::

::: etape Ce sont aussi les bissectrices de ses angles
$\displaystyle \widehat{OAD} = 70° : 2$.
:::

::: resultat
$AOD$ est rectangle en $O$ et $\widehat{OAD} = 35°$.
:::

## Question 2 : La longueur AO

::: etape $[AO]$ est adjacent à l'angle de $35°$, l'hypoténuse est $[AD] = 6$ cm
$\displaystyle AO = 6 \times \cos 35°$.
:::

::: resultat
$\displaystyle AO \approx 4{,}91$ cm
:::

## Question 3 : La diagonale AC

::: etape Les diagonales se coupent en leur milieu
$\displaystyle AC = 2 \times AO \approx 9{,}830$.
:::

::: resultat
$\displaystyle AC \approx 9{,}83$ cm
:::

## Question 4 : OD et BD

::: etape Pythagore
$OD^2 = 36 - AO^2 \approx 11{,}84$, donc $OD \approx 3{,}44$ cm.
:::

::: etape $\displaystyle BD = 2 \times OD \approx 6{,}883$
:::

::: resultat
$OD \approx 3{,}44$ cm et $BD \approx 6{,}88$ cm.
:::

[IMAGE_2]

## Question 5 : L'aire

::: methode
Aire d'un losange : $\displaystyle \frac{\text{grande diagonale} \times \text{petite diagonale}}{2}$.
:::

::: etape $\displaystyle \frac{9{,}830 \times 6{,}883}{2} \approx 33{,}83$
:::

::: resultat
Environ $\displaystyle 33{,}8$ cm².
:::

## Question 6 : L'angle ADC

::: etape Dans $\displaystyle AOD$
$\widehat{ODA} = 90° - 35° = 55°$, et $(DB)$ est la bissectrice de $\widehat{ADC}$.
:::

::: resultat
$$\widehat{ADC} = 2 \times 55° = 110°$$
:::

**À retenir :** Dans un losange (comme dans tout parallélogramme), deux angles consécutifs sont supplémentaires : $70° + 110° = 180°$.

Solution:
<!-- optitab:1 -->
1. Diagonales perpendiculaires et bissectrices
2. $\displaystyle \approx 4{,}91$ cm
3. $\displaystyle \approx 9{,}83$ cm
4. $\approx 3{,}44$ cm ; $\approx 6{,}88$ cm
5. $\displaystyle \approx 33{,}8$ cm²
6. $\displaystyle 110°$

=== Problème - Cosinus - 7. L'escalator
Id: 3670
Difficulté: hard
Image: cosinus_4e_escalator.png,cosinus_4e_escalator_solution.png

Énoncé:
<!-- optitab:1 -->
Un escalator $[AB]$ de $15$ m relie le rez-de-chaussée au premier étage d'un magasin, situé $6$ m plus haut. $H$ est le point du sol à la verticale de $B$. Pour la sécurité, un escalator ne doit pas faire un angle de plus de $30°$ avec le sol.

[IMAGE_1]

1. Calculer la distance au sol $\displaystyle AH$, au centième.
2. Calculer l'angle $\displaystyle \widehat{BAH}$ de l'escalator avec le sol, au dixième de degré.
3. Cet escalator respecte-t-il la règle de sécurité ?
4. L'escalator avance à $\displaystyle 0{,}5$ m/s. Combien de temps dure la montée ?
5. Un second escalator est incliné à exactement $30°$ et occupe $12$ m au sol. Calculer sa longueur au centième.
6. Quelle hauteur ce second escalator permet-il de monter, au centième ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La distance au sol

::: etape $ABH$ est rectangle en $H$
$\displaystyle AH^2 = 15^2 - 6^2 = 225 - 36 = 189$.
:::

::: resultat
$\displaystyle AH = \sqrt{189} \approx 13{,}75$ m
:::

## Question 2 : L'angle

::: etape $\displaystyle \cos \widehat{BAH} = \frac{AH}{AB} = \frac{\sqrt{189}}{15} \approx 0{,}9165$
:::

::: resultat
$$\widehat{BAH} \approx 23{,}6°$$
:::

[IMAGE_2]

## Question 3 : La sécurité

::: etape $\displaystyle 23{,}6° < 30°$
:::

::: resultat
Oui, l'escalator respecte la règle.
:::

## Question 4 : La durée

::: etape $\displaystyle 15 : 0{,}5 = 30$
:::

::: resultat
La montée dure $\displaystyle 30$ secondes.
:::

**Erreur fréquente :** Utiliser la hauteur ($6$ m) ou la distance au sol : les marches avancent le long de $[AB]$.

## Question 5 : Le second escalator

::: methode
On connaît le côté adjacent ($12$ m) et l'angle : on cherche l'hypoténuse, on divise par le cosinus.
:::

::: etape $\displaystyle L = \frac{12}{\cos 30°} \approx 13{,}856$
:::

::: resultat
$\displaystyle L \approx 13{,}86$ m
:::

## Question 6 : La hauteur du second escalator

::: etape Pythagore
$$h^2 = L^2 - 12^2 \approx 192 - 144 = 48$$
:::

::: resultat
$\displaystyle h = \sqrt{48} \approx 6{,}93$ m
:::

**À retenir :** Choisir le bon calcul : longueur au sol $=$ hypoténuse $\times \cos$ ; hypoténuse $=$ longueur au sol $: \cos$.

Solution:
<!-- optitab:1 -->
1. $\displaystyle \approx 13{,}75$ m
2. $\displaystyle \approx 23{,}6°$
3. Oui
4. $\displaystyle 30$ s
5. $\displaystyle \approx 13{,}86$ m
6. $\displaystyle \approx 6{,}93$ m
