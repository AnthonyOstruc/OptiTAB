🎯 Objectifs du chapitre : décrire une expérience aléatoire (univers, issues, événements), définir une loi de probabilité, calculer la probabilité d’un événement, de son contraire, d’une réunion ou d’une intersection, et dénombrer les issues avec un arbre ou un tableau.

I. Vocabulaire

Définitions : une expérience aléatoire a plusieurs résultats possibles, appelés issues, sans qu’on puisse prévoir lequel sera obtenu. L’ensemble des issues est l’univers $\displaystyle \Omega$. Un événement est une partie de $\displaystyle \Omega$ ; un événement formé d’une seule issue est dit élémentaire.

Exemple : on lance un dé à six faces. $\displaystyle \Omega = \{1\,;2\,;3\,;4\,;5\,;6\}$ et l’événement $\displaystyle A$ « obtenir un nombre pair » est $\displaystyle A = \{2\,;4\,;6\}$.

II. Loi de probabilité

Définition : définir une loi de probabilité sur $\displaystyle \Omega = \{x_1, \ldots, x_n\}$, c’est associer à chaque issue $\displaystyle x_i$ un nombre $\displaystyle p_i \ge 0$, avec $\displaystyle p_1 + p_2 + \cdots + p_n = 1$. La probabilité d’un événement $\displaystyle A$ est la somme des probabilités des issues qui le composent.

Exemple : un dé truqué donne $\displaystyle 6$ avec la probabilité $\displaystyle 0{,}5$ et chacune des autres faces avec la probabilité $\displaystyle 0{,}1$ (la somme vaut bien $\displaystyle 5 \times 0{,}1 + 0{,}5 = 1$). Alors $\displaystyle p(A) = p(2) + p(4) + p(6) = 0{,}1 + 0{,}1 + 0{,}5 = 0{,}7$.

Équiprobabilité : si toutes les issues ont la même probabilité, alors $\displaystyle p(A) = \frac{\text{nombre d’issues de } A}{\text{nombre d’issues de } \Omega}$.

💡 Repère : les mots « équilibré », « au hasard », « indiscernable » signalent une situation d’équiprobabilité. Avec un dé équilibré, $\displaystyle p(A) = \frac{3}{6} = \frac{1}{2}$.

III. Opérations sur les événements

• $\displaystyle A \cap B$ (« $\displaystyle A$ et $\displaystyle B$ ») est réalisé quand $\displaystyle A$ et $\displaystyle B$ le sont tous les deux ; $\displaystyle A \cup B$ (« $\displaystyle A$ ou $\displaystyle B$ ») quand au moins l’un des deux l’est.

• Le contraire $\displaystyle \overline{A}$ est réalisé quand $\displaystyle A$ ne l’est pas : $\displaystyle p(\overline{A}) = 1 - p(A)$.

• $\displaystyle A$ et $\displaystyle B$ sont incompatibles si $\displaystyle A \cap B = \varnothing$.

[IMAGE_1]

Exemple : on tire une carte au hasard dans un jeu de $\displaystyle 32$ cartes. $\displaystyle A$ : « cœur » ($\displaystyle 8$ cartes), $\displaystyle B$ : « figure » ($\displaystyle 12$ cartes), $\displaystyle A \cap B$ : « figure de cœur » ($\displaystyle 3$ cartes). Donc $\displaystyle p(A \cup B) = \frac{8}{32} + \frac{12}{32} - \frac{3}{32} = \frac{17}{32}$.

⚠️ Attention : on ne peut écrire $\displaystyle p(A \cup B) = p(A) + p(B)$ que si $\displaystyle A$ et $\displaystyle B$ sont incompatibles. Sinon, les issues communes seraient comptées deux fois.

IV. Expériences à deux épreuves

Pour une expérience qui se déroule en deux étapes, un arbre ou un tableau à double entrée permet de lister toutes les issues sans en oublier.

[IMAGE_2]

Exemple : on lance deux fois une pièce équilibrée. Les $\displaystyle 4$ issues sont équiprobables, donc $\displaystyle p(\text{« obtenir au moins un pile »}) = \frac{3}{4}$, ou encore $\displaystyle 1 - p(F\,;F) = 1 - \frac{1}{4}$.

[IMAGE_3]

Exemple : on lance deux dés équilibrés et on fait la somme. Le tableau compte $\displaystyle 36$ issues équiprobables, dont $\displaystyle 6$ donnent une somme égale à $\displaystyle 7$ : $\displaystyle p = \frac{6}{36} = \frac{1}{6}$.

⚠️ Attention : les sommes $\displaystyle 2, 3, \ldots, 12$ ne sont pas équiprobables : la somme $\displaystyle 2$ n’apparaît qu’une fois sur $\displaystyle 36$, la somme $\displaystyle 7$ six fois.

🏆 L’essentiel : une loi de probabilité donne des $\displaystyle p_i \ge 0$ de somme $\displaystyle 1$ ; en cas d’équiprobabilité, $\displaystyle p(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$ ; $\displaystyle p(\overline{A}) = 1 - p(A)$ ; $\displaystyle p(A \cup B) = p(A) + p(B) - p(A \cap B)$ ; un arbre ou un tableau permet de compter les issues d’une expérience à deux épreuves.
