Titre: Équations du Premier Degré - Résolution et Applications

<!-- optitab:1 -->
## Introduction

Une **équation du premier degré** est une égalité de la forme $ax + b = 0$ (avec $a \neq 0$) ou plus généralement $ax + b = cx + d$.

::: definition Idée clé
: Résoudre une équation, c'est trouver la (ou les) valeur(s) de $x$ qui vérifient l'égalité. La solution d'une équation du premier degré est unique.
:::

## I. Résolution d'équations simples

### Principe

::: definition Forme générale
$ax + b = 0$ avec $a \neq 0$ **Solution :** $x = -\dfrac{b}{a}$
:::

::: methode
1. **Isoler :** regrouper tous les termes en $x$ d'un côté et les constantes de l'autre
2. **Réduire :** simplifier les termes semblables
3. **Diviser :** diviser par le coefficient de $x$
4. **Vérifier :** remplacer $x$ par la solution trouvée dans l'équation de départ
:::

::: exemple
Résoudre $\displaystyle 3x + 5 = 0$

::: etape
Isoler $x$ : $3x = -5$ **Étape 2 :** Diviser par $3$ : $x = -\dfrac{5}{3}$
:::

::: resultat
Solution : $x = -\dfrac{5}{3}$ **Vérification :** $3 \times \left(-\dfrac{5}{3}\right) + 5 = -5 + 5 = 0$
:::
:::

::: exemple
Résoudre $\displaystyle 2x - 7 = 3x + 1$

::: etape
Regrouper les termes en $x$ : $2x - 3x = 1 + 7$ **Étape 2 :** Simplifier : $-x = 8$ **Étape 3 :** Multiplier par $-1$ : $x = -8$
:::

::: resultat
Solution : $x = -8$ **Vérification :** $2 \times (-8) - 7 = -16 - 7 = -23$ et $3 \times (-8) + 1 = -24 + 1 = -23$
:::
:::

::: exemple
Résoudre $\displaystyle 4x + 3 = 4x - 2$

::: etape Regrouper : $4x - 4x = -2 - 3$ **Étape 2 :** Simplifier : $0 = -5$
:::

::: attention
Cette égalité est **fausse** ! L'équation n'a **aucune solution**.
:::
:::

::: exemple
Résoudre $\displaystyle 5x - 3 = 5x - 3$

::: etape Regrouper : $5x - 5x = -3 + 3$ **Étape 2 :** Simplifier : $0 = 0$
:::

::: resultat
Cette égalité est toujours **vraie** ! L'équation a une **infinité de solutions** (tout nombre réel est solution).
:::
:::

## II. Équations avec développements

### Principe

::: definition Stratégie
Quand l'équation contient des parenthèses, il faut d'abord **développer** avant de résoudre.
:::

::: exemple
Résoudre $\displaystyle 2(x + 3) = 4x - 1$

::: etape
Développer : $2x + 6 = 4x - 1$ **Étape 2 :** Regrouper : $2x - 4x = -1 - 6$ **Étape 3 :** Simplifier : $-2x = -7$
:::

::: resultat
Solution : $\displaystyle x = \dfrac{7}{2}$
:::
:::

::: exemple
Résoudre $\displaystyle 3(x - 2) - 2(x + 1) = x + 4$

::: etape
Développer : $3x - 6 - 2x - 2 = x + 4$ **Étape 2 :** Réduire : $x - 8 = x + 4$ **Étape 3 :** Regrouper : $x - x = 4 + 8$ **Étape 4 :** Simplifier : $0 = 12$
:::

::: attention
Cette égalité est **fausse** ! L'équation n'a **aucune solution**.
:::
:::

## III. Équations avec fractions

### Principe

::: methode
Pour résoudre une équation avec fractions, on peut :

- Multiplier les deux membres par le **dénominateur commun**
- Ou mettre au même dénominateur puis simplifier
:::

::: exemple
Résoudre $\displaystyle \dfrac{x}{2} + 3 = 5$

::: etape
Isoler la fraction : $\dfrac{x}{2} = 5 - 3 = 2$ **Étape 2 :** Multiplier par $2$ : $x = 2 \times 2 = 4$
:::

::: resultat
Solution : $\displaystyle x = 4$
:::
:::

::: exemple
Résoudre $\displaystyle \dfrac{x + 1}{3} = \dfrac{x - 2}{2}$

::: etape
Produit en croix : $2(x + 1) = 3(x - 2)$ **Étape 2 :** Développer : $2x + 2 = 3x - 6$ **Étape 3 :** Regrouper : $2x - 3x = -6 - 2$ **Étape 4 :** Simplifier : $-x = -8$
:::

::: resultat
Solution : $\displaystyle x = 8$
:::
:::

::: exemple
Résoudre $\displaystyle \dfrac{2x - 1}{4} + \dfrac{x}{3} = 1$

::: etape
Dénominateur commun : $12$ **Étape 2 :** Multiplier par $12$ : $12 \times \dfrac{2x - 1}{4} + 12 \times \dfrac{x}{3} = 12 \times 1$ **Étape 3 :** Simplifier : $3(2x - 1) + 4x = 12$ **Étape 4 :** Développer : $6x - 3 + 4x = 12$ **Étape 5 :** Réduire : $10x = 15$
:::

::: resultat
Solution : $\displaystyle x = \dfrac{15}{10} = \dfrac{3}{2}$
:::
:::

::: attention Important
Toujours vérifier que la solution trouvée n'annule **aucun dénominateur** de l'équation initiale !
:::

## IV. Cas particuliers

### Types de solutions

| Situation | Résultat après simplification | Type de solution |
|---|---|---|
| **Équation normale** | $\displaystyle ax = b$ avec $\displaystyle a \neq 0$ | Une unique solution : $\displaystyle x = \dfrac{b}{a}$ |
| **Équation impossible** | $\displaystyle 0 = b$ avec $\displaystyle b \neq 0$ | Aucune solution |
| **Équation indéterminée** | $\displaystyle 0 = 0$ | Infinité de solutions (tout réel est solution) |

## V. Problèmes et applications

### Mise en équation

::: methode
1. **Lire :** comprendre le problème et identifier l'inconnue
2. **Traduire :** mettre le problème sous forme d'équation
3. **Résoudre :** résoudre l'équation obtenue
4. **Vérifier :** vérifier que la solution répond au problème
5. **Conclure :** rédiger la réponse en français
:::

::: exemple Problème 1
Un nombre augmenté de 7 est égal au triple de ce nombre diminué de 5. Quel est ce nombre ?

::: etape
Soit $x$ le nombre cherché **Étape 2 :** Traduire : $x + 7 = 3x - 5$ **Étape 3 :** Résoudre : $x - 3x = -5 - 7$ donc $-2x = -12$ donc $x = 6$
:::

::: resultat Vérification
$6 + 7 = 13$ et $3 \times 6 - 5 = 18 - 5 = 13$ **Réponse :** Le nombre cherché est $6$.
:::
:::

::: exemple Problème 2
La somme de trois nombres consécutifs est égale à 24. Quels sont ces nombres ?

::: etape
Soit $x$ le premier nombre, alors les autres sont $x+1$ et $x+2$ **Étape 2 :** Traduire : $x + (x+1) + (x+2) = 24$ **Étape 3 :** Simplifier : $3x + 3 = 24$ donc $3x = 21$ donc $x = 7$
:::

::: resultat Vérification
$7 + 8 + 9 = 24$ **Réponse :** Les trois nombres sont $7$, $8$ et $9$.
:::
:::

## VI. Méthode générale et stratégie

::: methode Ordre de travail à suivre
1. **Développer :** supprimer les parenthèses si nécessaire
2. **Réduire :** simplifier les termes semblables de chaque côté
3. **Transposer :** mettre tous les termes en $x$ d'un côté et les constantes de l'autre
4. **Simplifier :** réduire chaque côté
5. **Diviser :** diviser par le coefficient de $x$
6. **Vérifier :** remplacer $x$ par la solution dans l'équation initiale
:::

::: exemple
Résoudre $\displaystyle 2(x - 3) + 5 = 3x - 1$

::: etape
Développer : $2x - 6 + 5 = 3x - 1$ **Étape 2 :** Réduire : $2x - 1 = 3x - 1$ **Étape 3 :** Transposer : $2x - 3x = -1 + 1$ **Étape 4 :** Simplifier : $-x = 0$
:::

::: resultat
Solution : $x = 0$ **Vérification :** $2(0 - 3) + 5 = 2 \times (-3) + 5 = -6 + 5 = -1$ et $3 \times 0 - 1 = -1$
:::
:::

## VII. Erreurs fréquentes et conseils

::: attention
- **Oublier de changer le signe :** quand on passe un terme de l'autre côté, il faut changer son signe
- **Confondre transposition et simplification :** $2x - x = x$ et non $2x$
- **Oublier de développer :** $2(x + 3) = 2x + 6$ et non $2x + 3$
- **Diviser seulement un côté :** si on divise par $a$, il faut diviser **tous les termes**
- **Oublier les valeurs interdites :** dans les équations avec fractions, vérifier les dénominateurs
- **Confondre « aucune solution » et « infinité de solutions »**
- **Oublier de vérifier :** toujours remplacer $x$ par la solution trouvée
:::

::: conseil
- Toujours **développer** les parenthèses avant de regrouper
- Pour les équations avec fractions, utiliser le **produit en croix** ou le **dénominateur commun**
- Faire une **vérification** systématique en remplaçant $x$ par la solution
- Attention aux cas particuliers : **aucune solution** si on obtient $0 = b$ ($b \neq 0$)
- Attention aux cas particuliers : **infinité de solutions** si on obtient $0 = 0$
- Pour les problèmes, bien **traduire** le texte en équation
- Dans les problèmes, toujours vérifier que la solution est **cohérente** avec le contexte
:::
