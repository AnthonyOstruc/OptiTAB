Titre: Résumé : Retrouver les premières tables

<!-- optitab:1 -->
::: objectifs
Retrouver la méthode essentielle et les points à vérifier.
:::

## I. La méthode
::: methode
Table de 2 : doubles. Table de 3 : ajoute 3. Table de 4 : double deux fois. Table de 5 : compte de 5 en 5. Table de 10 : compte les dizaines.
:::

[IMAGE_1]

## II. Un exemple
::: exemple
$9+9=18$.

$18+18=36$.

$4\times 9=36$.
:::

## III. Le contrôle
::: attention
Un groupe supplémentaire de 3 ajoute 3 objets, pas un seul.
:::

::: retenir
Pour un facteur manquant, retrouve le nombre de groupes qui reconstitue le total. Écris les calculs difficiles sur des cartes et explique comment les retrouver.
:::
