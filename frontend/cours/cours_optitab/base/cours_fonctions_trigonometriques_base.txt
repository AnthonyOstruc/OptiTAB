    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et cercle trigonométrique</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition géométrique</h3>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonctions trigonométriques</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les <strong>fonctions trigonométriques</strong> sont définies à partir du cercle trigonométrique (cercle unité de rayon 1 centré à l'origine).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour un angle $\displaystyle \theta$ en radians, on considère un point $\displaystyle M$ sur le cercle tel que l'angle entre l'axe positif des abscisses et $\displaystyle OM$ soit $\displaystyle \theta$.</p>
        </div>

        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>

                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Fonction</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Définition</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\sin(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">Ordonnée du point $M$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">Abscisse du point $M$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\tan(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\dfrac{\sin(\theta)}{\cos(\theta)}$ (si $\cos(\theta) \neq 0$)</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À retenir :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Toutes les fonctions trigonométriques sont définies pour tout angle réel $\displaystyle \theta \in \mathbb{R}$, sauf $\displaystyle \tan(\theta)$ qui n'est pas définie quand $\displaystyle \cos(\theta) = 0$ (c'est-à-dire en $\displaystyle \frac{\pi}{2} + k\pi$).</p>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Propriétés fondamentales</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Relation fondamentale</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Relation fondamentale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle \theta \in \mathbb{R}$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \sin^2(\theta) + \cos^2(\theta) = 1$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conséquences :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \sin(\theta) = \pm \sqrt{1 - \cos^2(\theta)}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \cos(\theta) = \pm \sqrt{1 - \sin^2(\theta)}$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Dérivées des fonctions trigonométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formules de dérivation</h3>

        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Fonction</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Dérivée</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\sin(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(u) \cdot u'(x)$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$-\sin(u) \cdot u'(x)$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\tan(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\dfrac{1}{\cos^2(u)} \cdot u'(x) = \sec^2(u) \cdot u'(x)$</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle \tan(u)$, la formule $\displaystyle \frac{1}{\cos^2(u)}$ n'est valable que si $\displaystyle \cos(u) \neq 0$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples de calculs de dérivées</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>À calculer :</strong> Dérivée de $\displaystyle f(x) = \sin(3x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle u(x) = 3x$, donc $\displaystyle u'(x) = 3$</li>
                <li style="margin:0; text-align:left;">$\displaystyle f'(x) = \cos(3x) \times u'(x) = \cos(3x) \times 3$</li>
            </ul>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Résultat :</strong> $\displaystyle f'(x) = 3\cos(3x)$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>À calculer :</strong> Dérivée de $\displaystyle f(x) = x^2 \cos(x)$ (produit)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle u(x) = x^2$ donc $\displaystyle u'(x) = 2x$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle v(x) = \cos(x)$ donc $\displaystyle v'(x) = -\sin(x)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle (uv)' = u'v + uv'$</li>
                <li style="margin:0; text-align:left;">$\displaystyle f'(x) = 2x \times \cos(x) + x^2 \times (-\sin(x))$</li>
            </ul>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Résultat :</strong> $\displaystyle f'(x) = 2x\cos(x) - x^2\sin(x)$
            </div>
        </div>

            <strong>Exemple 3 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>À calculer :</strong> Dérivée de $\displaystyle f(x) = \tan(x^2 + 1)$ (composée)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle u(x) = x^2 + 1$ donc $\displaystyle u'(x) = 2x$</li>

            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">

            </ul>
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">

        <h3 style="color:#34495e; margin-top:0;">Exemple complet : Étude d'une fonction trigonométrique</h3>
        <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Énoncé :</strong> Étudier la fonction $\displaystyle f(x) = \sin(x) + \cos(x)$ sur $\displaystyle \mathbb{R}$</p>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">

        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 2 :</strong> Résolution $\displaystyle f'(x) = 0$
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos(x) - \sin(x) = 0 \Rightarrow \cos(x) = \sin(x) \Rightarrow \tan(x) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solutions : $\displaystyle x = \frac{\pi}{4} + k\pi$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 3 :</strong> Signe de $\displaystyle f'(x)$
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f'(x) = \sqrt{2} \sin\left(x - \frac{\pi}{4}\right)$</p>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre $\displaystyle \sin^2(x) + \cos^2(x) = 1$ avec $\displaystyle \sin(x) + \cos(x) = 1$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier que $\displaystyle \tan(x)$ n'est pas définie en $\displaystyle \frac{\pi}{2} + k\pi$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Inverser les dérivées : $\displaystyle (\sin(x))' = \cos(x)$ et $\displaystyle (\cos(x))' = -\sin(x)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier la périodicité dans les équations : une équation a généralement une infinité de solutions</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre les périodes : $\displaystyle 2\pi$ pour sin/cos, $\displaystyle \pi$ pour tan</li>
                <li style="margin:0; text-align:left;">Oublier que $\displaystyle \sin(x)$ et $\displaystyle \cos(x)$ sont bornés par $\displaystyle [-1, 1]$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Mémoriser les <strong>valeurs remarquables</strong> aux angles $\displaystyle \frac{\pi}{6}$, $\displaystyle \frac{\pi}{4}$, $\displaystyle \frac{\pi}{3}$, $\displaystyle \frac{\pi}{2}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser la <strong>relation fondamentale</strong> $\displaystyle \sin^2 + \cos^2 = 1$ pour simplifier</li>
                <li style="margin:0 0 12px 0; text-align:left;">Penser en termes de <strong>périodicité</strong> pour généraliser les solutions</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les dérivées composées : identifier $\displaystyle u(x)$ et appliquer la règle de dérivation</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les équations : commencer par résoudre sur une période, puis généraliser</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier que les solutions trouvées sont dans le domaine de définition</li>
                <li style="margin:0; text-align:left;">S'entraîner à reconnaître les formes $\displaystyle \sin(x) \pm \cos(x) = k$ et utiliser les méthodes adaptées</li>
            </ul>
        </div>
