Titre: Calcul littéral et distributivité

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> écrire et calculer une expression littérale, réduire, développer (simple et double distributivité), factoriser, et utiliser une lettre pour démontrer qu'une propriété est toujours vraie ou trouver un contre-exemple.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Expressions littérales</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Conventions :</strong> on peut supprimer le signe $\displaystyle \times$ devant une lettre ou une parenthèse : $\displaystyle 3 \times x = 3x$ ; $\displaystyle 2 \times (x + 1) = 2(x + 1)$ ; $\displaystyle x \times x = x^2$ ; $\displaystyle 1 \times x = x$.</p>
        </div>
        <p style="font-size:1em;"><strong>Calculer la valeur d'une expression :</strong> on remplace la lettre par sa valeur, <strong>entre parenthèses</strong>, puis on applique les priorités.</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle A = 3x^2 - 2x + 5$ pour $\displaystyle x = -1$ : $\displaystyle A = 3 \times (-1)^2 - 2 \times (-1) + 5 = 3 + 2 + 5 = 10$
        </div>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Réduire :</strong> on regroupe les termes « de même famille » : $\displaystyle 7a - 2 + 3a + 9 = 10a + 7$ ; $\displaystyle 4x^2 + 3x - x^2 + x = 3x^2 + 4x$. On ne mélange jamais les $\displaystyle x$, les $\displaystyle x^2$ et les nombres : $\displaystyle 3x + 2$ ne se réduit pas.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Développer</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Simple distributivité :</strong> $\displaystyle k(a + b) = ka + kb$ et $\displaystyle k(a - b) = ka - kb$. Développer, c'est transformer un produit en somme.</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;"><strong>Exemples :</strong> $\displaystyle 5(2a - 3) = 10a - 15$ ; $\displaystyle -2(x - 6) = -2x + 12$ ; $\displaystyle x(x + 5) = x^2 + 5x$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Le signe « − » devant une parenthèse</strong> change le signe de TOUS les termes : $\displaystyle -(3x - 7) = -3x + 7$ ; $\displaystyle 5 - (2x - 3) = 5 - 2x + 3 = 8 - 2x$.
        </div>
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Double distributivité :</strong> $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$ : chaque terme de la première parenthèse multiplie chaque terme de la seconde.</p>
        </div>
        [IMAGE_2]
        <p style="font-size:1em;"><strong>Exemple rédigé :</strong> $\displaystyle (2x + 1)(x + 4) = 2x \times x + 2x \times 4 + 1 \times x + 1 \times 4 = 2x^2 + 8x + x + 4 = 2x^2 + 9x + 4$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Factoriser</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Factoriser</strong>, c'est transformer une somme en produit en repérant un <strong>facteur commun</strong> : $\displaystyle ka + kb = k(a + b)$.</p>
        </div>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            $\displaystyle 12a - 18 = 6 \times 2a - 6 \times 3 = 6(2a - 3)$ &nbsp; ; &nbsp; $\displaystyle 3x^2 - 6x = 3x \times x - 3x \times 2 = 3x(x - 2)$
        </div>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Vérification :</strong> on redéveloppe le résultat ; on doit retrouver l'expression de départ.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Prouver avec le calcul littéral</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;"><strong>Pour montrer qu'une égalité est FAUSSE</strong>, un seul <strong>contre-exemple</strong> suffit : pour $\displaystyle x = 1$, $\displaystyle (x + 3)^2 = 16$ mais $\displaystyle x^2 + 9 = 10$, donc $\displaystyle (x + 3)^2 \neq x^2 + 9$.</p>
        <p style="font-size:1em;"><strong>Pour montrer qu'une égalité est TOUJOURS VRAIE</strong>, des exemples ne suffisent pas : il faut un calcul avec la lettre.</p>
        <div style="text-align:center; margin:15px 0; padding:12px; background:#e8f4fd; border-radius:4px; border-left:6px solid #3498db;">
            Trois entiers consécutifs : $\displaystyle n + (n + 1) + (n + 2) = 3n + 3 = 3(n + 1)$, donc leur somme est toujours un multiple de $\displaystyle 3$.
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L'essentiel :</strong> remplacer une lettre = parenthèses ; réduire = regrouper les termes semblables ; développer : $\displaystyle k(a + b) = ka + kb$ et $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$ ; factoriser : $\displaystyle ka + kb = k(a + b)$ ; faux → un contre-exemple ; toujours vrai → une preuve littérale. Fiche de synthèse dans l'onglet Fiches !</p>
    </div>
