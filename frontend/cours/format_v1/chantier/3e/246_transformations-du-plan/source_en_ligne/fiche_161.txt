Titre: Résumé : Transformations du plan

<!-- optitab:1 -->
::: objectifs
L'essentiel sur les symétries, la translation, la rotation, l'homothétie, l'agrandissement-réduction, les frises, pavages et rosaces.
:::

## I. Les quatre isométries

[IMAGE_1]

| Transformation | Comment construire $A'$ |
|---|---|
| Symétrie axiale d'axe $(d)$ | $(d)$ est la médiatrice de $[AA']$ |
| Symétrie centrale de centre $O$ | $O$ est le milieu de $[AA']$ |
| Translation de $P$ vers $Q$ | même déplacement que de $P$ à $Q$ |
| Rotation de centre $O$, d'angle $\alpha$ | $OA' = OA$ et $\widehat{AOA'} = \alpha$ (sens donné) |

::: retenir
Elles conservent les longueurs, les angles, les aires, l'alignement et le parallélisme : la figure image est superposable à la figure de départ. Seule la symétrie axiale **retourne** la figure.
:::

## II. L'homothétie de centre $O$ et de rapport $k$

::: formule
$O$, $A$, $A'$ alignés et $OA' = |k| \times OA$
:::

- $k > 0$ : $A'$ du même côté que $A$ ; $k < 0$ : de l'autre côté de $O$.
- $|k| > 1$ : agrandissement ; $|k| < 1$ : réduction ; $k = -1$ : symétrie centrale.

[IMAGE_2]

## III. Agrandissement, réduction

| Grandeur | Multipliée par |
|---|---|
| Longueurs | $k$ |
| Aires | $k^2$ |
| Volumes | $k^3$ |
| Angles | inchangés |

Exemple : $k = 3$ → périmètre $\times 3$, aire $\times 9$, volume $\times 27$. Avec une homothétie de rapport $k < 0$, on utilise $|k|$.

## IV. Reconnaître une transformation

1. Taille différente → homothétie.
2. Figure retournée → symétrie axiale.
3. Même orientation, simple glissement → translation.
4. Figure « tête en bas » → symétrie centrale ; autre angle → rotation.

## V. Frises, pavages, rosaces

- **Frise** : motif répété par translation ; du motif 1 au motif $n$, il y a $n - 1$ décalages.
- **Rosace** de $n$ motifs : rotations de $\dfrac{360^\circ}{n}$ (8 motifs → $45^\circ$).
- **Pavage** : le plan est recouvert sans trou ni chevauchement.

::: attention Les erreurs classiques
1. Donner une longueur négative avec $k < 0$ : on multiplie par $|k|$.
2. Multiplier une aire par $k$ au lieu de $k^2$, un volume par $k^2$ au lieu de $k^3$.
3. Oublier le sens d'une rotation (horaire ou inverse).
4. Confondre symétrie centrale (demi-tour) et symétrie axiale (retournement).
:::

::: conseil Réflexe brevet
Maquette, plan, section d'une pyramide ou d'un cône par un plan parallèle à la base → réduction : trouver $k$ avec deux longueurs correspondantes, puis $k^2$ pour les aires et $k^3$ pour les volumes.
:::
