<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : loi, espérance, variance, écart type et transformation affine. Programme de Première.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Loi et indicateurs</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle E(X) = \sum p_ix_i$ ; $\displaystyle V(X) = E(X^2) - E(X)^2$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Loi : tableau des valeurs $\displaystyle x_i$ et des $\displaystyle P(X = x_i)$, de somme $\displaystyle 1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle V(X) = \sum p_i(x_i - E(X))^2$ et $\displaystyle \sigma(X) = \sqrt{V(X)}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Jeu équitable : $\displaystyle E(X) = 0$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Linéarité et simulation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\displaystyle E(aX + b) = aE(X) + b$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle V(aX + b) = a^2V(X)$ et $\displaystyle \sigma(aX + b) = |a|\sigma(X)$.</p>
<p style="margin:6px 0 0 0;">3️⃣ La moyenne de nombreuses simulations se rapproche de $\displaystyle E(X)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier de vérifier que la somme des probabilités vaut $\displaystyle 1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Compter la mise deux fois (ou l’oublier) dans les gains.</p>
<p style="margin:6px 0 0 0;">3️⃣ Écrire $\displaystyle V(aX + b) = aV(X) + b$ : c’est $\displaystyle a^2V(X)$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Donner $\displaystyle V(X)$ au lieu de $\displaystyle \sigma(X)$ (ou oublier la racine).</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je commence toujours par le tableau de la loi de $\displaystyle X$ ; tout le reste (espérance, variance) se calcule à partir de lui.</p>
</div>
