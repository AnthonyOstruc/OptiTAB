    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Cercle trigonométrique et radian</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition du cercle trigonométrique</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Cercle trigonométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>cercle trigonométrique</strong> est le cercle de centre $\displaystyle O$ (origine du repère) et de rayon $\displaystyle 1$, orienté dans le sens <strong>trigonométrique</strong> (sens inverse des aiguilles d'une montre).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il est muni d'un repère orthonormé $\displaystyle (O, \vec{i}, \vec{j})$ où :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Le point $\displaystyle I(1, 0)$ est le point d'intersection du cercle avec l'axe des abscisses positifs</li>
                <li style="margin:0; text-align:left;">Le point $\displaystyle J(0, 1)$ est le point d'intersection du cercle avec l'axe des ordonnées positifs</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Convention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>sens trigonométrique</strong> (ou sens positif) est le sens inverse des aiguilles d'une montre. C'est le sens dans lequel on mesure les angles positifs.</p>
        </div>

    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Longueur d'arc et radian</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Longueur d'arc</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur le cercle trigonométrique, la <strong>longueur d'arc</strong> entre deux points est la longueur de la portion de cercle qui les sépare, mesurée dans le sens trigonométrique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour un cercle de rayon $\displaystyle R$, la longueur totale du cercle (circonférence) est $\displaystyle 2\pi R$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour le cercle trigonométrique ($\displaystyle R = 1$), la circonférence est $\displaystyle 2\pi$.</p>
        </div>
      [IMAGE_2]
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Radian</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>radian</strong> est l'unité de mesure d'angle définie par :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un angle de $\displaystyle 1$ radian intercepte un arc de longueur $\displaystyle 1$ sur le cercle trigonométrique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle 180° = \pi$ radians</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle 1° = \frac{\pi}{180}$ radians et $\displaystyle 1$ radian $= \frac{180}{\pi}° \approx 57,3°$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de conversion :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 90° = \frac{\pi}{2}$ radians</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 45° = \frac{\pi}{4}$ radians</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 60° = \frac{\pi}{3}$ radians</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle 30° = \frac{\pi}{6}$ radians</li>
                <li style="margin:0; text-align:left;">$\displaystyle \pi$ radians $= 180°$</li>
            </ul>
        </div>

  
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Enroulement de la droite sur le cercle trigonométrique</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Principe de l'enroulement</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On enroule la droite numérique sur le cercle trigonométrique de la manière suivante :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">On place l'origine $\displaystyle 0$ de la droite au point $\displaystyle I(1, 0)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">On enroule la droite dans le sens trigonométrique pour les réels positifs</li>
                <li style="margin:0 0 18px 0; text-align:left;">On enroule dans le sens opposé (sens horaire) pour les réels négatifs</li>
                <li style="margin:0; text-align:left;">Chaque réel $\displaystyle x$ a une <strong>image unique</strong> sur le cercle, notée $\displaystyle M(x)$</li>
            </ol>
        </div>
      [IMAGE_3]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La longueur de l'arc $\displaystyle \overset{\frown}{IM}$ est égale à $\displaystyle |x|$ (valeur absolue de $\displaystyle x$).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle x > 0$, on parcourt l'arc dans le sens trigonométrique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle x < 0$, on parcourt l'arc dans le sens horaire.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle x = 2\pi$, on fait un tour complet et on revient au point $\displaystyle I$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de points remarquables :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x = 0$ → $\displaystyle M(0) = I(1, 0)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x = \frac{\pi}{2}$ → $\displaystyle M\left(\frac{\pi}{2}\right) = J(0, 1)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x = \pi$ → $\displaystyle M(\pi) = (-1, 0)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x = \frac{3\pi}{2}$ → $\displaystyle M\left(\frac{3\pi}{2}\right) = (0, -1)$</li>
                <li style="margin:0; text-align:left;">$\displaystyle x = 2\pi$ → $\displaystyle M(2\pi) = I(1, 0)$ (un tour complet)</li>
            </ul>
        </div>

  
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Cosinus et sinus d'un nombre réel</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition sur le cercle trigonométrique</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Cosinus et sinus</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout réel $\displaystyle x$, soit $\displaystyle M(x)$ le point image de $\displaystyle x$ sur le cercle trigonométrique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les coordonnées de $\displaystyle M(x)$ sont :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Cosinus :</strong> $\displaystyle \cos(x)$ est l'<strong>abscisse</strong> du point $\displaystyle M(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Sinus :</strong> $\displaystyle \sin(x)$ est l'<strong>ordonnée</strong> du point $\displaystyle M(x)$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a donc : $\displaystyle M(x) = (\cos(x), \sin(x))$</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Conséquence immédiate :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle M(x)$ est sur le cercle trigonométrique (de rayon $\displaystyle 1$ et de centre $\displaystyle O$), on a :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle OM = 1$, donc $\displaystyle \cos^2(x) + \sin^2(x) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est la <strong>relation fondamentale</strong> : $\displaystyle \cos^2(x) + \sin^2(x) = 1$ pour tout réel $\displaystyle x$.</p>
        </div>

        [IMAGE_4]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Lien avec le triangle rectangle</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Lien avec la géométrie</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un triangle rectangle, si $\displaystyle \alpha$ est la mesure en radians d'un angle aigu :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \cos(\alpha) = \frac{\text{côté adjacent}}{\text{hypoténuse}}$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \sin(\alpha) = \frac{\text{côté opposé}}{\text{hypoténuse}}$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette définition coïncide avec la définition sur le cercle trigonométrique : dans un triangle rectangle de côté adjacent $\displaystyle \cos(\alpha)$ et côté opposé $\displaystyle \sin(\alpha)$ à l'hypoténuse de longueur $\displaystyle 1$, le sommet de l'angle $\displaystyle \alpha$ coïncide avec le point $\displaystyle M(\alpha)$ sur le cercle trigonométrique.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un triangle rectangle avec un angle de $\displaystyle \frac{\pi}{6}$ (30°) :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$ et $\displaystyle \sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ces valeurs correspondent aux coordonnées du point sur le cercle trigonométrique associé à $\displaystyle \frac{\pi}{6}$.</p>
        </div>

    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Angles associés</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Formules des angles associés</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ces formules permettent de déterminer les valeurs de cosinus et sinus pour des angles associés aux valeurs remarquables :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Opposé :</strong> $\displaystyle \cos(-x) = \cos(x)$ et $\displaystyle \sin(-x) = -\sin(x)$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Supplémentaire :</strong> $\displaystyle \cos(\pi - x) = -\cos(x)$ et $\displaystyle \sin(\pi - x) = \sin(x)$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Complémentaire :</strong> $\displaystyle \cos\left(\frac{\pi}{2} - x\right) = \sin(x)$ et $\displaystyle \sin\left(\frac{\pi}{2} - x\right) = \cos(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Déphasage de $\displaystyle \pi$ :</strong> $\displaystyle \cos(\pi + x) = -\cos(x)$ et $\displaystyle \sin(\pi + x) = -\sin(x)$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples d'utilisation :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Calculer $\displaystyle \cos\left(\frac{5\pi}{6}\right)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \frac{5\pi}{6} = \pi - \frac{\pi}{6}$, donc :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos\left(\frac{5\pi}{6}\right) = \cos\left(\pi - \frac{\pi}{6}\right) = -\cos\left(\frac{\pi}{6}\right) = -\frac{\sqrt{3}}{2}$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Calculer $\displaystyle \sin\left(\frac{7\pi}{6}\right)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \frac{7\pi}{6} = \pi + \frac{\pi}{6}$, donc :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sin\left(\frac{7\pi}{6}\right) = \sin\left(\pi + \frac{\pi}{6}\right) = -\sin\left(\frac{\pi}{6}\right) = -\frac{1}{2}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démonstrations des valeurs remarquables</h3>

        <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:12px; margin:12px 0;">
            <p style="margin:0; text-align:left; font-size:0.95em;"><strong>🌟 Approfondissement (bonus) :</strong> Les démonstrations suivantes enrichissent votre culture mathématique mais ne sont pas strictement exigibles pour les évaluations. Il est important de connaître les valeurs remarquables, mais il n'est pas nécessaire de savoir refaire formellement toutes ces démonstrations.</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration (approfondissement) - Calcul de $\displaystyle \sin\left(\frac{\pi}{4}\right)$ et $\displaystyle \cos\left(\frac{\pi}{4}\right)$ :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle x = \frac{\pi}{4}$ (45°), le point $\displaystyle M\left(\frac{\pi}{4}\right)$ est sur la bissectrice du premier quadrant.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a donc : $\displaystyle \cos\left(\frac{\pi}{4}\right) = \sin\left(\frac{\pi}{4}\right)$ (notons cette valeur $\displaystyle a$).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">D'après la relation fondamentale : $\displaystyle \cos^2\left(\frac{\pi}{4}\right) + \sin^2\left(\frac{\pi}{4}\right) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle a^2 + a^2 = 1 \Leftrightarrow 2a^2 = 1 \Leftrightarrow a^2 = \frac{1}{2} \Leftrightarrow a = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle \cos\left(\frac{\pi}{4}\right) > 0$ et $\displaystyle \sin\left(\frac{\pi}{4}\right) > 0$, on a :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos\left(\frac{\pi}{4}\right) = \sin\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration (approfondissement) - Calcul de $\displaystyle \cos\left(\frac{\pi}{3}\right)$ et $\displaystyle \sin\left(\frac{\pi}{3}\right)$ :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle x = \frac{\pi}{3}$ (60°), considérons un triangle équilatéral de côté $\displaystyle 1$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En traçant une hauteur, on obtient un triangle rectangle avec un angle de $\displaystyle \frac{\pi}{3}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans ce triangle rectangle :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">- L'hypoténuse a pour longueur $\displaystyle 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">- Le côté adjacent à l'angle $\displaystyle \frac{\pi}{3}$ a pour longueur $\displaystyle \frac{1}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">- Le côté opposé a pour longueur $\displaystyle \frac{\sqrt{3}}{2}$ (par le théorème de Pythagore)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$ et $\displaystyle \sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$</p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration (approfondissement) - Calcul de $\displaystyle \sin\left(\frac{\pi}{3}\right)$ (complément) :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut aussi utiliser la formule du complémentaire :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sin\left(\frac{\pi}{3}\right) = \sin\left(\frac{\pi}{2} - \frac{\pi}{6}\right) = \cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Et de même : $\displaystyle \cos\left(\frac{\pi}{3}\right) = \cos\left(\frac{\pi}{2} - \frac{\pi}{6}\right) = \sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonctions cosinus et sinus</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonctions cosinus et sinus</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les fonctions <strong>cosinus</strong> et <strong>sinus</strong> sont les fonctions définies sur $\displaystyle \mathbb{R}$ par :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x \mapsto \cos(x)$ : fonction cosinus</li>
                <li style="margin:0; text-align:left;">$\displaystyle x \mapsto \sin(x)$ : fonction sinus</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout réel $\displaystyle x$, $\displaystyle (\cos(x), \sin(x))$ sont les coordonnées du point $\displaystyle M(x)$ sur le cercle trigonométrique.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Propriétés immédiates :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Pour tout réel $\displaystyle x$ : $\displaystyle -1 \leq \cos(x) \leq 1$ et $\displaystyle -1 \leq \sin(x) \leq 1$</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \cos(0) = 1$ et $\displaystyle \sin(0) = 0$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \cos\left(\frac{\pi}{2}\right) = 0$ et $\displaystyle \sin\left(\frac{\pi}{2}\right) = 1$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Parité</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Parité des fonctions trigonométriques</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout réel $\displaystyle x$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \cos(-x) = \cos(x)$ : la fonction cosinus est <strong>paire</strong></li>
                <li style="margin:0; text-align:left;">$\displaystyle \sin(-x) = -\sin(x)$ : la fonction sinus est <strong>impaire</strong></li>
            </ul>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Justification géométrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les points $\displaystyle M(x)$ et $\displaystyle M(-x)$ sur le cercle trigonométrique sont symétriques par rapport à l'axe des abscisses.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc ils ont la même abscisse (d'où $\displaystyle \cos(-x) = \cos(x)$) et des ordonnées opposées (d'où $\displaystyle \sin(-x) = -\sin(x)$).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Conséquence graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe de la fonction cosinus est <strong>symétrique par rapport à l'axe des ordonnées</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe de la fonction sinus est <strong>symétrique par rapport à l'origine</strong> du repère.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Périodicité</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Périodicité des fonctions trigonométriques</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les fonctions cosinus et sinus sont <strong>périodiques de période $\displaystyle 2\pi$</strong> :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout réel $\displaystyle x$ et tout entier relatif $\displaystyle k$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle \cos(x + 2k\pi) = \cos(x)$</li>
                <li style="margin:0; text-align:left;">$\displaystyle \sin(x + 2k\pi) = \sin(x)$</li>
            </ul>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Justification géométrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ajouter $\displaystyle 2\pi$ à $\displaystyle x$ revient à faire un tour complet sur le cercle trigonométrique.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle M(x + 2\pi)$ coïncide donc avec le point $\displaystyle M(x)$, d'où les égalités.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conséquence :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour étudier les fonctions cosinus et sinus, il suffit de les étudier sur un intervalle de longueur $\displaystyle 2\pi$, par exemple $\displaystyle [0, 2\pi[$ ou $\displaystyle [-\pi, \pi[$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe complète s'obtient ensuite par <strong>translations horizontales</strong> de $\displaystyle 2\pi$.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Lecture sur le cercle trigonométrique</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode pour déterminer cosinus et sinus</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Placer le point $\displaystyle M(x)$ sur le cercle trigonométrique en utilisant l'enroulement</li>
                <li style="margin:0 0 18px 0; text-align:left;">Déterminer le quadrant dans lequel se trouve $\displaystyle M(x)$ (premier, deuxième, troisième ou quatrième quadrant)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Utiliser les angles associés pour ramener l'angle à une valeur remarquable dans le premier quadrant</li>
                <li style="margin:0; text-align:left;">Appliquer les formules des angles associés pour déterminer $\displaystyle \cos(x)$ et $\displaystyle \sin(x)$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Déterminer $\displaystyle \cos\left(\frac{2\pi}{3}\right)$ et $\displaystyle \sin\left(\frac{2\pi}{3}\right)$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle \frac{2\pi}{3} = \pi - \frac{\pi}{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle M\left(\frac{2\pi}{3}\right)$ est dans le deuxième quadrant.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">D'après les formules des angles associés :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos\left(\frac{2\pi}{3}\right) = \cos\left(\pi - \frac{\pi}{3}\right) = -\cos\left(\frac{\pi}{3}\right) = -\frac{1}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sin\left(\frac{2\pi}{3}\right) = \sin\left(\pi - \frac{\pi}{3}\right) = \sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Algorithmes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Approximation de π par la méthode d'Archimède</h3>

        <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:12px; margin:12px 0;">
            <p style="margin:0; text-align:left; font-size:0.95em;"><strong>🌟 Approfondissement (bonus) :</strong> La méthode d'Archimède pour approcher π est un classique de l'histoire des mathématiques. Elle n'est pas strictement exigible au programme.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>📐 Algorithme - Méthode d'Archimède</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Principe :</strong> On approche le cercle unité par des polygones réguliers inscrits et circonscrits.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour un polygone régulier de $\displaystyle n$ côtés inscrit dans le cercle unité :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le périmètre du polygone est $\displaystyle p_n = 2n \sin\left(\frac{\pi}{n}\right)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Quand $\displaystyle n$ augmente, $\displaystyle p_n$ se rapproche de $\displaystyle 2\pi$ (circonférence du cercle).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc : $\displaystyle \pi \approx \frac{p_n}{2} = n \sin\left(\frac{\pi}{n}\right)$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Code Python :</strong></p>
            <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
                <span style="color:#ff79c6;">import</span> math<br>
                <br>
                n = <span style="color:#bd93f9;">6</span><br>
                <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">5</span>):<br>
                &nbsp;&nbsp;&nbsp;&nbsp;angle = math.pi / n<br>
                &nbsp;&nbsp;&nbsp;&nbsp;approx_pi = n * math.sin(angle)<br>
                &nbsp;&nbsp;&nbsp;&nbsp;erreur = abs(math.pi - approx_pi)<br>
                &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"n = {n}, π ≈ {approx_pi:.10f}, erreur = {erreur:.10f}"</span>)<br>

            </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes générales</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pratiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Placer un point sur le cercle :</strong> Utiliser l'enroulement de la droite numérique, compter les tours complets ($\displaystyle 2\pi$)</li>
                <li style="margin:0; text-align:left;"><strong>Déterminer cosinus et sinus :</strong> Identifier le quadrant, utiliser les angles associés pour revenir aux valeurs remarquables</li>
                <li style="margin:0; text-align:left;"><strong>Mémoriser les valeurs remarquables :</strong> Apprendre par cœur les valeurs pour $\displaystyle 0$, $\displaystyle \frac{\pi}{6}$, $\displaystyle \frac{\pi}{4}$, $\displaystyle \frac{\pi}{3}$, $\displaystyle \frac{\pi}{2}$</li>
                <li style="margin:0; text-align:left;"><strong>Utiliser la relation fondamentale :</strong> $\displaystyle \cos^2(x) + \sin^2(x) = 1$ pour vérifier ou compléter des calculs</li>
                <li style="margin:0; text-align:left;"><strong>Exploiter la parité :</strong> $\displaystyle \cos(-x) = \cos(x)$ et $\displaystyle \sin(-x) = -\sin(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Exploiter la périodicité :</strong> Ramener tout angle à un angle dans $\displaystyle [0, 2\pi[$ en ajoutant ou retirant des multiples de $\displaystyle 2\pi$</li>
                <li style="margin:0; text-align:left;"><strong>Lire sur le cercle :</strong> Visualiser le cercle trigonométrique pour déterminer rapidement les signes et valeurs</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Confondre cosinus et sinus :</strong> Cosinus = abscisse, Sinus = ordonnée</li>
                <li style="margin:0; text-align:left;"><strong>Oublier la relation fondamentale :</strong> $\displaystyle \cos^2(x) + \sin^2(x) = 1$ est toujours vraie</li>
                <li style="margin:0; text-align:left;"><strong>Confondre la parité :</strong> Cosinus est pair, sinus est impair</li>
                <li style="margin:0; text-align:left;"><strong>Oublier la périodicité :</strong> $\displaystyle \cos(x + 2\pi) = \cos(x)$ et $\displaystyle \sin(x + 2\pi) = \sin(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Erreur sur les signes :</strong> Dans le deuxième quadrant, cosinus est négatif et sinus positif</li>
                <li style="margin:0; text-align:left;"><strong>Confondre degrés et radians :</strong> Attention, $\displaystyle \pi = 180°$, pas $\displaystyle 90°$</li>
                <li style="margin:0; text-align:left;"><strong>Oublier les valeurs remarquables :</strong> Mémoriser $\displaystyle \cos\left(\frac{\pi}{4}\right) = \sin\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$</li>
            </ul>
