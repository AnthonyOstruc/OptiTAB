<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">III. Propriétés fondamentales</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<p style="margin:8px 0;"><strong>Relation fondamentale :</strong> $\displaystyle \sin^2(x) + \cos^2(x) = 1$ pour tout $\displaystyle x \in \mathbb{R}$</p>
<p style="margin:8px 0;"><strong>Tangente :</strong> $\displaystyle 1 + \tan^2(x) = \frac{1}{\cos^2(x)}$</p>
</div>

<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<p style="margin:8px 0;"><strong>Périodicité :</strong></p>
<ul style="margin:8px 0; padding-left:20px;">
<li>$\displaystyle \sin(x + 2\pi) = \sin(x)$ et $\displaystyle \cos(x + 2\pi) = \cos(x)$ (période $\displaystyle 2\pi$)</li>
<li>$\displaystyle \tan(x + \pi) = \tan(x)$ (période $\displaystyle \pi$)</li>
</ul>
</div>

<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<p style="margin:8px 0;"><strong>Parité :</strong></p>
<ul style="margin:8px 0; padding-left:20px;">
<li>$\displaystyle \sin(-x) = -\sin(x)$ (fonction impaire)</li>
<li>$\displaystyle \cos(-x) = \cos(x)$ (fonction paire)</li>
<li>$\displaystyle \tan(-x) = -\tan(x)$ (fonction impaire)</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VII. Résolution d'équations trigonométriques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
<strong>📐 Solutions générales :</strong>
<ul style="margin:10px 0; padding-left:20px;">
<li>$\displaystyle \sin(x) = \sin(a) \Rightarrow x = a + 2k\pi$ ou $\displaystyle x = \pi - a + 2k\pi$ (avec $\displaystyle k \in \mathbb{Z}$)</li>
<li>$\displaystyle \cos(x) = \cos(a) \Rightarrow x = \pm a + 2k\pi$ (avec $\displaystyle k \in \mathbb{Z}$)</li>
<li>$\displaystyle \tan(x) = \tan(a) \Rightarrow x = a + k\pi$ (avec $\displaystyle k \in \mathbb{Z}$)</li>
</ul>
</div>

<div style="background:#fff8dc; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #ffa500;">
<strong>⚠️ Méthode :</strong>
<ol style="margin:8px 0; padding-left:20px;">
<li>Identifier le type d'équation ($\displaystyle \sin$, $\displaystyle \cos$ ou $\displaystyle \tan$)</li>
<li>Trouver une solution particulière (avec valeurs remarquables)</li>
<li>Appliquer la formule générale correspondante</li>
<li>Si l'équation est sur un intervalle : restreindre les solutions</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IX. Limites trigonométriques fondamentales</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{\tan x}{x} = 1$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{\cos x - 1}{x} = 0$</p>
</div>

<div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #10b981;">
<strong>Équivalents usuels au voisinage de 0 :</strong>
<ul style="margin:8px 0; padding-left:20px;">
<li>$\displaystyle \sin x \sim x$</li>
<li>$\displaystyle \tan x \sim x$</li>
<li>$\displaystyle 1 - \cos x \sim \frac{x^2}{2}$</li>
</ul>
</div>
</div>

<div style="background:#e8f5e8; padding:15px; border-radius:6px; margin:15px 0; border-left:6px solid #10b981;">
<strong>✅ Points clés à retenir :</strong>
<ul style="margin:8px 0; padding-left:20px;">
<li><strong>Relation fondamentale</strong> : $\displaystyle \sin^2(x) + \cos^2(x) = 1$ (à connaître par cœur)</li>
<li><strong>Valeurs remarquables</strong> : mémoriser $\displaystyle 0$, $\displaystyle \frac{\pi}{6}$, $\displaystyle \frac{\pi}{4}$, $\displaystyle \frac{\pi}{3}$, $\displaystyle \frac{\pi}{2}$</li>
<li><strong>Périodes</strong> : $\displaystyle 2\pi$ pour sin/cos, $\displaystyle \pi$ pour tan</li>
<li><strong>Parité</strong> : sin et tan impaires, cos paire</li>
<li><strong>Dérivées</strong> : $\displaystyle (\sin)' = \cos$, $\displaystyle (\cos)' = -\sin$, $\displaystyle (\tan)' = \frac{1}{\cos^2}$</li>
<li><strong>Limite fondamentale</strong> : $\displaystyle \lim_{x \to 0} \frac{\sin x}{x} = 1$ (très utilisée)</li>
<li><strong>Domaine de tan</strong> : $\displaystyle \tan$ non définie en $\displaystyle \frac{\pi}{2} + k\pi$</li>
<li><strong>Angles associés</strong> : pour $\displaystyle \frac{\pi}{2} \pm x$, cos et sin s'échangent</li>
</ul>
</div>
