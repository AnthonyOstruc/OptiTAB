Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un entraîneur de basket hésite entre deux joueurs pour un match décisif. Voici les points marqués par chacun lors des 6 derniers matchs.

| Match | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| Joueur A | $12$ | $14$ | $15$ | $13$ | $16$ | $14$ |
| Joueur B | $5$ | $25$ | $8$ | $22$ | $6$ | $24$ |

1. Calculer la moyenne de points de chaque joueur.
2. Déterminer la médiane de chaque série.
3. Calculer l'étendue de chaque série.
4. Quel joueur est le plus régulier ? Justifier.
5. L'entraîneur veut un joueur sur lequel il peut compter. Lequel lui conseiller ? Argumenter avec les indicateurs.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les moyennes

::: methode
Moyenne = somme des points ÷ nombre de matchs ($6$).
:::

::: etape Joueur A
$$\frac{12 + 14 + 15 + 13 + 16 + 14}{6} = \frac{84}{6} = 14$$
:::

::: etape Joueur B
$$\frac{5 + 25 + 8 + 22 + 6 + 24}{6} = \frac{90}{6} = 15$$
:::

::: resultat
Moyenne de A : $14$ points ; moyenne de B : $15$ points.
:::

## Question 2 : Les médianes

::: methode
Ranger chaque série ; l'effectif $6$ est pair : la médiane est la moyenne des 3ᵉ et 4ᵉ valeurs.
:::

::: etape Joueur A rangé
$12\ ;\ 13\ ;\ 14\ ;\ 14\ ;\ 15\ ;\ 16$, donc médiane $= \dfrac{14 + 14}{2} = 14$.
:::

::: etape Joueur B rangé
$5\ ;\ 6\ ;\ 8\ ;\ 22\ ;\ 24\ ;\ 25$, donc médiane $= \dfrac{8 + 22}{2} = 15$.
:::

::: resultat
Médiane de A : $14$ ; médiane de B : $15$.
:::

::: attention
Pour B, la médiane $15$ n'est le score d'aucun match : avec un effectif pair, la médiane peut ne pas être une valeur de la série.
:::

## Question 3 : Les étendues

::: methode
Étendue = plus grand score − plus petit score.
:::

::: etape Calculs
- Joueur A : $16 - 12 = 4$.
- Joueur B : $25 - 5 = 20$.
:::

[IMAGE_1]

::: resultat
Étendue de A : $4$ points ; étendue de B : $20$ points.
:::

## Question 4 : Le joueur le plus régulier

::: methode
La régularité se mesure par la dispersion : plus l'étendue est petite, plus les scores sont proches.
:::

::: resultat
Le joueur A est le plus régulier : son étendue ($4$) est cinq fois plus petite que celle de B ($20$).
:::

## Question 5 : Le conseil à l'entraîneur

::: etape Comparer la position
B a une moyenne et une médiane légèrement supérieures ($15$ contre $14$) : un seul point d'écart.
:::

::: etape Comparer la dispersion
B a marqué moins de $10$ points dans $3$ matchs sur $6$, alors que A a toujours marqué entre $12$ et $16$ points.
:::

::: resultat
Pour un match décisif, il vaut mieux choisir **A** : presque le même niveau moyen, mais beaucoup plus fiable. B est un pari plus risqué.
:::

::: retenir
Pour comparer deux séries, on utilise un indicateur de position (moyenne, médiane) **et** un indicateur de dispersion (étendue).
:::

Solution:
<!-- optitab:1 -->
1. A : $14$ ; B : $15$
2. A : $14$ ; B : $15$
3. A : $4$ ; B : $20$
4. A (étendue plus petite)
5. A : niveau presque égal mais bien plus régulier
