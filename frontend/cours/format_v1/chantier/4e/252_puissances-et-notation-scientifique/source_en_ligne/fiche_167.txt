Titre: Résumé : Puissances et notation scientifique

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : puissances d'un nombre, puissances de 10, notation scientifique, préfixes. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Puissances d'un nombre</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $a^n = a \times a \times \dots \times a$ ($n$ facteurs) ; $a^1 = a$ ; $a^0 = 1$.</p>
<p style="margin:6px 0 0 0;">• $(-a)^n$ : <strong>positif si $n$ est pair</strong>, négatif si $n$ est impair : $(-2)^4 = 16$, $(-2)^3 = -8$.</p>
<p style="margin:6px 0 0 0;">• <strong>Priorité</strong> : $-3^2 = -9$ mais $(-3)^2 = 9$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Puissances de 10</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $10^n = 1$ suivi de $n$ zéros ; $10^{-n} = 0{,}0 \dots 01$ ($1$ au $n$-ième rang après la virgule).</p>
<p style="margin:6px 0 0 0;">• $10^n \times 10^p = 10^{n+p}$ ; $\displaystyle \frac{10^n}{10^p} = 10^{n-p}$ ; $(10^n)^p = 10^{np}$.</p>
[IMAGE_1]
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Notation scientifique et préfixes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $a \times 10^n$ avec <strong>$1 \leq a < 10$</strong> : $45\,000 = 4{,}5 \times 10^4$ ; $0{,}000\,72 = 7{,}2 \times 10^{-4}$.</p>
<p style="margin:6px 0 0 0;">• Calcul : nombres ensemble, puissances de 10 ensemble, puis on réajuste : $20 \times 10^{-4} = 2 \times 10^{-3}$.</p>
[IMAGE_2]
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ $2^3 = 6$ (faux : $2^3 = 8$).</p>
<p style="margin:6px 0 0 0;">2️⃣ $10^3 \times 10^4 = 10^{12}$ (faux : on ADDITIONNE les exposants, $10^7$).</p>
<p style="margin:6px 0 0 0;">3️⃣ Croire que $10^{-2}$ est négatif : $10^{-2} = 0{,}01 > 0$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Laisser $32 \times 10^4$ : ce n'est pas une notation scientifique ($3{,}2 \times 10^5$).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour un très grand ou un très petit nombre, je passe en notation scientifique, je calcule séparément nombres et puissances de 10, et je vérifie que $1 \leq a < 10$ à la fin.</p>
</div>
