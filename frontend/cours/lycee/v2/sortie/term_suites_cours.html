🎯 Objectifs du chapitre : rédiger un raisonnement par récurrence, définir la limite d’une suite, calculer des limites (opérations, formes indéterminées), utiliser les théorèmes de comparaison et des gendarmes, connaître la limite de $\displaystyle q^n$ et le théorème de convergence monotone.

I. Raisonnement par récurrence

Principe : soit $\displaystyle P(n)$ une propriété dépendant d’un entier $\displaystyle n$. Si

• initialisation : $\displaystyle P(n_0)$ est vraie,

• hérédité : pour tout $\displaystyle n \ge n_0$, si $\displaystyle P(n)$ est vraie, alors $\displaystyle P(n + 1)$ est vraie,

alors $\displaystyle P(n)$ est vraie pour tout entier $\displaystyle n \ge n_0$.

[IMAGE_1]

Inégalité de Bernoulli (démonstration au programme) : pour tout réel $\displaystyle a \gt 0$ et tout entier $\displaystyle n$, $\displaystyle (1 + a)^n \ge 1 + na$.

Preuve : pour $\displaystyle n = 0$, $\displaystyle 1 \ge 1$. Si $\displaystyle (1 + a)^n \ge 1 + na$, alors, comme $\displaystyle 1 + a \gt 0$, $\displaystyle (1 + a)^{n+1} \ge (1 + na)(1 + a) = 1 + (n + 1)a + na^2 \ge 1 + (n + 1)a$.

Exemple : $\displaystyle u_0 = 1$ et $\displaystyle u_{n+1} = 0{,}5\,u_n + 1$. Montrons $\displaystyle P(n)$ : « $\displaystyle 1 \le u_n \le u_{n+1} \le 2$ ». On a $\displaystyle u_0 = 1$ et $\displaystyle u_1 = 1{,}5$ : $\displaystyle P(0)$ est vraie. Si $\displaystyle P(n)$ est vraie, la fonction $\displaystyle x \mapsto 0{,}5x + 1$ étant croissante, on obtient $\displaystyle 1{,}5 \le u_{n+1} \le u_{n+2} \le 2$, donc $\displaystyle P(n + 1)$ est vraie.

II. Limite d’une suite

Définitions :

• $\displaystyle (u_n)$ converge vers $\displaystyle \ell$ si tout intervalle ouvert contenant $\displaystyle \ell$ contient tous les termes à partir d’un certain rang. On note $\displaystyle \lim u_n = \ell$.

• $\displaystyle (u_n)$ tend vers $\displaystyle +\infty$ si tout intervalle $\displaystyle ]A\,;+\infty[$ contient tous les termes à partir d’un certain rang.

• Une suite qui ne converge pas est dite divergente.

[IMAGE_2]
💡 Limites de référence : $\displaystyle \frac{1}{n}$, $\displaystyle \frac{1}{n^2}$, $\displaystyle \frac{1}{\sqrt{n}}$ tendent vers $\displaystyle 0$ ; $\displaystyle n$, $\displaystyle n^2$, $\displaystyle \sqrt{n}$ tendent vers $\displaystyle +\infty$.

III. Calculer une limite

Opérations : les limites se combinent « naturellement » pour les sommes, produits et quotients, sauf dans les quatre formes indéterminées : $\displaystyle \infty - \infty$, $\displaystyle 0 \times \infty$, $\displaystyle \frac{\infty}{\infty}$ et $\displaystyle \frac{0}{0}$.

💡 Lever une indétermination : on factorise par le terme « dominant ». Par exemple $\displaystyle n^2 - 5n = n^2\left(1 - \frac{5}{n}\right)$ tend vers $\displaystyle +\infty$, et $\displaystyle \frac{3n^2 + 1}{n^2 - 5n} = \frac{3 + \frac{1}{n^2}}{1 - \frac{5}{n}}$ tend vers $\displaystyle 3$.

IV. Comparaison et encadrement

Théorème de comparaison (démonstration au programme) : si $\displaystyle u_n \ge v_n$ à partir d’un certain rang et si $\displaystyle \lim v_n = +\infty$, alors $\displaystyle \lim u_n = +\infty$.

Preuve : pour tout $\displaystyle A$, il existe un rang à partir duquel $\displaystyle v_n \gt A$, donc $\displaystyle u_n \ge v_n \gt A$ (à partir du plus grand des deux rangs).

Théorème des gendarmes : si $\displaystyle v_n \le u_n \le w_n$ à partir d’un certain rang et si $\displaystyle (v_n)$ et $\displaystyle (w_n)$ convergent vers la même limite $\displaystyle \ell$, alors $\displaystyle (u_n)$ converge vers $\displaystyle \ell$.

[IMAGE_3]

Exemples : $\displaystyle -\frac{1}{n} \le \frac{(-1)^n}{n} \le \frac{1}{n}$, donc $\displaystyle \frac{(-1)^n}{n}$ tend vers $\displaystyle 0$ ; $\displaystyle n + \sin n \ge n - 1$, donc $\displaystyle n + \sin n$ tend vers $\displaystyle +\infty$.

V. Suites géométriques et suites monotones

Limite de $\displaystyle q^n$ : si $\displaystyle q \gt 1$, $\displaystyle \lim q^n = +\infty$ ; si $\displaystyle -1 \lt q \lt 1$, $\displaystyle \lim q^n = 0$ ; si $\displaystyle q = 1$, la suite est constante ; si $\displaystyle q \le -1$, elle n’a pas de limite.

Preuve pour $\displaystyle q \gt 1$ (au programme) : on écrit $\displaystyle q = 1 + a$ avec $\displaystyle a \gt 0$ ; par Bernoulli, $\displaystyle q^n \ge 1 + na$, qui tend vers $\displaystyle +\infty$, et on conclut par comparaison.

[IMAGE_4]

Convergence monotone : toute suite croissante et majorée converge ; toute suite décroissante et minorée converge. Une suite croissante non majorée tend vers $\displaystyle +\infty$ (démonstration au programme).

Exemple : la suite du I est croissante et majorée par $\displaystyle 2$, donc elle converge vers un réel $\displaystyle \ell$ qui vérifie $\displaystyle \ell = 0{,}5\ell + 1$, soit $\displaystyle \ell = 2$.

🏆 L’essentiel : récurrence = initialisation + hérédité ; formes indéterminées levées en factorisant ; comparaison et gendarmes pour encadrer ; $\displaystyle q^n \rightarrow +\infty$ si $\displaystyle q \gt 1$, $\displaystyle \rightarrow 0$ si $\displaystyle |q| \lt 1$ ; croissante et majorée $\displaystyle \Rightarrow$ convergente.
