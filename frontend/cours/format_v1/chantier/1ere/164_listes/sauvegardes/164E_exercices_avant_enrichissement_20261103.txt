=== Découverte - Indices et éléments d'une liste
Id: 1063
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Les températures relevées à midi (en °C) pendant une semaine, du lundi au dimanche, sont rangées dans la liste `T`.

```python
T = [14, 17, 12, 19, 16, 11, 15]
```

1. Combien la liste `T` contient-elle d’éléments ? Quels sont ses indices ?
2. Sans ordinateur, donner la valeur de :
   - a) `T[0]` ;
   - b) `T[3]` ;
   - c) `T[-1]` ;
   - d) `T[len(T) - 2]`.
3. Quel est l’indice de la température du jeudi ? Quel est l’indice de la plus basse température de la semaine ?
4. Le relevé du mercredi était faux : il fallait lire $13$. Écrire l’instruction qui corrige la liste, puis donner la liste obtenue.
5. Que se passe-t-il si l’on exécute `print(T[7])` ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Nombre d’éléments et indices

::: methode
Une liste de $n$ éléments a pour indices $0$, $1$, …, $n - 1$ : on commence à compter à $0$.
:::

::: etape Nombre d’éléments
La liste contient une température par jour de la semaine : `len(T)` vaut $7$.
:::

::: etape Indices
Les indices vont de $0$ (lundi) à $6$ (dimanche). En comptant depuis la fin, ils vont de $-7$ à $-1$.
:::

[IMAGE_1]

::: resultat
`T` contient $7$ éléments, d’indices $0$, $1$, $2$, $3$, $4$, $5$, $6$.
:::

## Question 2 : Lire des éléments

::: methode
`T[i]` est l’élément d’indice `i` ; `T[-1]` est le dernier élément.
:::

::: etape Indices positifs
- `T[0]` est le premier élément : $14$.
- `T[3]` est le **quatrième** élément (indices $0$, $1$, $2$, $3$) : $19$.
:::

::: etape Indices négatifs et calculés
- `T[-1]` est le dernier élément : $15$.
- `len(T) - 2` vaut $7 - 2 = 5$, donc `T[len(T) - 2]` est `T[5]`, c’est-à-dire $11$ (l’avant-dernier élément).
:::

On vérifie à la machine :

```python
T = [14, 17, 12, 19, 16, 11, 15]
print(T[0], T[3], T[-1])
print(T[len(T) - 2])
```

```console
14 19 15
11
```

::: attention
`T[3]` n’est pas le troisième élément mais le quatrième : on compte à partir de $0$.
:::

::: resultat
a) $14$ ; b) $19$ ; c) $15$ ; d) $11$.
:::

## Question 3 : Retrouver un indice

::: etape Jeudi
Lundi a l’indice $0$, mardi $1$, mercredi $2$, donc jeudi a l’indice $3$.
:::

::: etape Plus basse température
La plus petite valeur de la liste est $11$ ; elle est en sixième position, à l’indice $5$ (samedi).
:::

::: resultat
Le jeudi a l’indice $3$ ; la plus basse température, $11$ °C, a l’indice $5$.
:::

## Question 4 : Modifier un élément

::: methode
`T[i] = v` remplace l’élément d’indice `i` par `v`, sans changer la longueur.
:::

::: etape Instruction
Le mercredi est le troisième jour : son indice est $2$. On écrit `T[2] = 13`.
:::

```python
T = [14, 17, 12, 19, 16, 11, 15]
T[2] = 13
print(T)
```

```console
[14, 17, 13, 19, 16, 11, 15]
```

::: resultat
`T[2] = 13` ; la liste devient `[14, 17, 13, 19, 16, 11, 15]`.
:::

## Question 5 : Indice hors de la liste

::: etape Analyse
Les indices de `T` vont de $0$ à $6$ : l’indice $7$ n’existe pas. Python arrête le programme sur l’erreur `IndexError: list index out of range` (indice hors de la liste).
:::

::: resultat
`print(T[7])` provoque une erreur `IndexError`. Le dimanche, dernier jour, s’obtient par `T[6]` ou `T[-1]`.
:::

Solution:
<!-- optitab:1 -->
1. $7$ éléments, d’indices $0$ à $6$.
2. a) $14$ ; b) $19$ ; c) $15$ ; d) `T[5]`, soit $11$.
3. Jeudi : indice $3$ ; plus basse température ($11$ °C) : indice $5$.
4. `T[2] = 13`, d’où `[14, 17, 13, 19, 16, 11, 15]`.
5. Erreur `IndexError` : l’indice $7$ n’existe pas.

=== Entraînement - Générer une liste de trois façons
Id: 1065
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire **en extension** la liste `M` des multiples de $5$ compris entre $0$ et $30$ (inclus).
2. Le programme suivant doit construire la même liste **par ajouts successifs**. Remplacer les points de suspension par l’instruction qui convient.

```python
M = []
for k in range(7):
    ...
print(M)
```

3. Écrire la même liste **en compréhension**.
4. Donner, sans ordinateur, les listes `A`, `B` et `C` créées par les instructions suivantes.

```python
A = [2*k + 1 for k in range(5)]
B = [k**2 for k in range(1, 6)]
C = [x for x in B if x % 2 == 0]
```

5. On veut les cinq premiers termes de chacune des suites suivantes. Choisir la façon de générer la liste, écrire le programme et donner la liste obtenue.
   - a) $u_n = 3n - 1$ pour tout entier naturel $n$ ;
   - b) $v_0 = 2$ et $v_{n+1} = 3v_n - 2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : En extension

::: methode
On écrit toutes les valeurs entre crochets, séparées par des virgules.
:::

::: etape Valeurs
Les multiples de $5$ de $0$ à $30$ sont $0$, $5$, $10$, $15$, $20$, $25$, $30$ : il y en a $7$.
:::

::: resultat
`M = [0, 5, 10, 15, 20, 25, 30]`
:::

## Question 2 : Par ajouts successifs

::: methode
Dans la boucle, `k` prend les valeurs $0$ à $6$ : on ajoute $5k$ à la fin de la liste avec `append`.
:::

::: etape Instruction manquante
Au tour `k`, on ajoute le multiple $5 \times k$ : `M.append(5 * k)`.
:::

```python
M = []
for k in range(7):
    M.append(5 * k)
print(M)
```

```console
[0, 5, 10, 15, 20, 25, 30]
```

::: attention
On n’écrit pas `M = M.append(5 * k)` : `append` ne renvoie rien, `M` vaudrait `None`.
:::

::: resultat
L’instruction manquante est `M.append(5 * k)`.
:::

## Question 3 : En compréhension

::: methode
`[expression for k in range(n)]` : l’expression est le terme général $5k$, pour $k$ de $0$ à $6$.
:::

```python
M = [5 * k for k in range(7)]
print(M)
```

```console
[0, 5, 10, 15, 20, 25, 30]
```

::: resultat
`M = [5 * k for k in range(7)]`
:::

## Question 4 : Lire des listes en compréhension

::: etape Liste A
$k$ prend les valeurs $0$ à $4$ ; $2k + 1$ vaut $1$, $3$, $5$, $7$, $9$ : les cinq premiers entiers impairs.
:::

::: etape Liste B
`range(1, 6)` donne $k = 1$, $2$, $3$, $4$, $5$ ; leurs carrés sont $1$, $4$, $9$, $16$, $25$.
:::

::: etape Liste C
On garde les éléments `x` de `B` tels que `x % 2 == 0`, c’est-à-dire les éléments pairs (reste $0$ dans la division par $2$) : $4$ et $16$.
:::

```python
A = [2*k + 1 for k in range(5)]
B = [k**2 for k in range(1, 6)]
C = [x for x in B if x % 2 == 0]
print(A)
print(B)
print(C)
```

```console
[1, 3, 5, 7, 9]
[1, 4, 9, 16, 25]
[4, 16]
```

::: attention
`range(1, 6)` s’arrête à $5$ : la borne $6$ n’est pas atteinte.
:::

::: resultat
`A = [1, 3, 5, 7, 9]`, `B = [1, 4, 9, 16, 25]` et `C = [4, 16]`.
:::

## Question 5 : Choisir la bonne écriture

::: methode
Formule explicite $u_n = f(n)$ : compréhension. Relation de récurrence : ajouts successifs, en calculant le terme suivant à partir du dernier, `v[-1]`.
:::

::: etape a) Formule explicite
$u_n$ se calcule directement à partir de $n$ : `u = [3*n - 1 for n in range(5)]`. On obtient $u_0 = -1$, $u_1 = 2$, $u_2 = 5$, $u_3 = 8$, $u_4 = 11$.
:::

::: etape b) Relation de récurrence
Chaque terme se calcule à partir du précédent : on part de `[2]` et on fait $4$ tours.

$$
\begin{aligned}
v_1 &= 3 \times 2 - 2 = 4 \\
v_2 &= 3 \times 4 - 2 = 10 \\
v_3 &= 3 \times 10 - 2 = 28 \\
v_4 &= 3 \times 28 - 2 = 82
\end{aligned}
$$
:::

```python
u = [3*n - 1 for n in range(5)]
v = [2]
for k in range(4):
    v.append(3 * v[-1] - 2)
print(u)
print(v)
```

```console
[-1, 2, 5, 8, 11]
[2, 4, 10, 28, 82]
```

::: resultat
- a) En compréhension : `[-1, 2, 5, 8, 11]`.
- b) Par ajouts successifs ($4$ tours pour $5$ termes) : `[2, 4, 10, 28, 82]`.
:::

Solution:
<!-- optitab:1 -->
1. `M = [0, 5, 10, 15, 20, 25, 30]`
2. `M.append(5 * k)`
3. `M = [5 * k for k in range(7)]`
4. `A = [1, 3, 5, 7, 9]`, `B = [1, 4, 9, 16, 25]`, `C = [4, 16]`.
5. a) `[3*n - 1 for n in range(5)]` donne `[-1, 2, 5, 8, 11]` ; b) `v = [2]` puis $4$ fois `v.append(3 * v[-1] - 2)` : `[2, 4, 10, 28, 82]`.

=== Découverte - Suivre des ajouts successifs avec append
Id: 1064
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère le programme suivant.

```python
L = [3]
for k in range(4):
    L.append(L[-1] + 2*k)
print(L)
```

1. Recopier et compléter le tableau de suivi : à chaque tour de boucle, donner la valeur de `k`, le dernier élément `L[-1]` avant l’ajout et la valeur ajoutée.

| Tour | $k$ | Dernier élément avant | Valeur ajoutée |
|---|---|---|---|
| 1 | … | … | … |
| 2 | … | … | … |
| 3 | … | … | … |
| 4 | … | … | … |

2. Qu’affiche le programme ? Quelle est la longueur finale de `L` ?
3. La liste `L` contient les termes $u_0$, $u_1$, … d’une suite $(u_n)$. Donner $u_0$ et la relation entre $u_{n+1}$ et $u_n$. Quel élément de `L` est égal à $u_4$ ?
4. Modifier le programme pour qu’il affiche seulement $u_{10}$, puis calculer $u_{10}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Tableau de suivi

::: methode
À chaque tour, on lit le dernier élément `L[-1]`, on calcule `L[-1] + 2*k` et on l’ajoute **à la fin** de la liste : il devient le nouveau dernier élément.
:::

::: etape Premier tour
`k` vaut $0$ ; `L` est `[3]`, donc `L[-1]` vaut $3$ ; on ajoute $3 + 2 \times 0 = 3$.
:::

::: etape Tours suivants
- `k` vaut $1$ : `L[-1]` vaut $3$, on ajoute $3 + 2 = 5$.
- `k` vaut $2$ : `L[-1]` vaut $5$, on ajoute $5 + 4 = 9$.
- `k` vaut $3$ : `L[-1]` vaut $9$, on ajoute $9 + 6 = 15$.
:::

| Tour | $k$ | Dernier élément avant | Valeur ajoutée |
|---|---|---|---|
| 1 | $0$ | $3$ | $3$ |
| 2 | $1$ | $3$ | $5$ |
| 3 | $2$ | $5$ | $9$ |
| 4 | $3$ | $9$ | $15$ |

[IMAGE_1]

::: resultat
Valeurs ajoutées successivement : $3$, $5$, $9$, $15$.
:::

## Question 2 : Affichage

::: etape Liste finale
La liste de départ `[3]` reçoit $4$ éléments : elle en contient $1 + 4 = 5$.
:::

```python
L = [3]
for k in range(4):
    L.append(L[-1] + 2*k)
print(L)
print(len(L))
```

```console
[3, 3, 5, 9, 15]
5
```

::: attention
La boucle fait $4$ tours, mais la liste a $5$ éléments : le premier, $3$, était présent avant la boucle.
:::

::: resultat
Le programme affiche `[3, 3, 5, 9, 15]` ; la longueur finale est $5$.
:::

## Question 3 : La suite associée

::: etape Premier terme et relation
`L[0]` vaut $3$, donc $u_0 = 3$. Au tour où `k` vaut $n$, le dernier élément est $u_n$ et l’on ajoute $u_{n+1} = u_n + 2n$.
:::

::: etape Terme $u_4$
L’indice est le rang : $u_4$ est `L[4]`, c’est-à-dire $15$ (le dernier élément, `L[-1]`).
:::

::: resultat
$u_0 = 3$ et $u_{n+1} = u_n + 2n$ ; $u_4$ = `L[4]` $= 15$.
:::

## Question 4 : Calculer $u_{10}$

::: methode
Pour obtenir $u_0$, …, $u_{10}$, il faut $10$ ajouts, donc `range(10)` ; $u_{10}$ est alors le dernier élément.
:::

```python
L = [3]
for k in range(10):
    L.append(L[-1] + 2*k)
print(L[-1])
```

```console
93
```

::: etape Vérification par le calcul
On ajoute successivement $2 \times 0$, $2 \times 1$, …, $2 \times 9$ à $u_0 = 3$ :

$$
\begin{aligned}
u_{10} &= 3 + 2 \times (0 + 1 + \dots + 9) \\
&= 3 + 2 \times 45 \\
&= 93
\end{aligned}
$$
:::

::: resultat
On remplace `range(4)` par `range(10)` et `print(L)` par `print(L[-1])` (ou `print(L[10])`) : $u_{10} = 93$.
:::

Solution:
<!-- optitab:1 -->
1. Valeurs de `k` : $0$, $1$, $2$, $3$ ; dernier élément avant l’ajout : $3$, $3$, $5$, $9$ ; valeurs ajoutées : $3$, $5$, $9$, $15$.
2. `[3, 3, 5, 9, 15]` ; longueur $5$.
3. $u_0 = 3$, $u_{n+1} = u_n + 2n$ ; $u_4$ est `L[4]` $= 15$.
4. `range(10)` et `print(L[-1])` : $u_{10} = 93$.

=== Entraînement - Parcourir une liste : moyenne, fréquence, maximum
Id: 1067
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une station météo a mesuré les précipitations (en mm) pendant $10$ jours, numérotés de $1$ à $10$. Les mesures sont rangées dans la liste `P` : `P[0]` correspond au jour $1$.

```python
P = [12, 0, 5, 23, 0,
     8, 17, 0, 3, 9]
```

1. Écrire un programme qui calcule, à l’aide d’une boucle et sans utiliser `sum`, le total des précipitations, puis la moyenne journalière. Donner les résultats.
2. Écrire un programme qui compte les jours sans pluie et calcule leur fréquence.
3. À l’aide d’un parcours par indices, écrire un programme qui détermine la plus forte précipitation et l’indice correspondant. De quel jour s’agit-il ?
4. Construire par ajouts successifs la liste `J` des **numéros des jours** où il est tombé plus de $10$ mm.

Étapes:
<!-- optitab:1 -->
## Question 1 : Total et moyenne

::: methode
Accumulateur : une variable `s` initialisée à $0$, à laquelle on ajoute chaque élément ; la moyenne est `s / len(P)`.
:::

```python
P = [12, 0, 5, 23, 0,
     8, 17, 0, 3, 9]
s = 0
for x in P:
    s = s + x
print(s)
print(s / len(P))
```

```console
77
7.7
```

::: etape Vérification
$$
\begin{aligned}
s &= 12 + 0 + 5 + 23 + 0 \\
&\quad + 8 + 17 + 0 + 3 + 9 \\
&= 77
\end{aligned}
$$
La moyenne vaut $\dfrac{77}{10} = 7{,}7$ mm par jour.
:::

::: attention
Il faut initialiser `s` **avant** la boucle : écrit dans la boucle, `s = 0` effacerait le total à chaque tour.
:::

::: resultat
Total : $77$ mm ; moyenne : $7{,}7$ mm par jour.
:::

## Question 2 : Jours sans pluie

::: methode
Compteur : une variable `c` initialisée à $0$, augmentée de $1$ à chaque élément égal à $0$.
:::

```python
P = [12, 0, 5, 23, 0,
     8, 17, 0, 3, 9]
c = 0
for x in P:
    if x == 0:
        c = c + 1
print(c, c / len(P))
```

```console
3 0.3
```

::: resultat
$3$ jours sans pluie sur $10$ : la fréquence est $\dfrac{3}{10} = 0{,}3$.
:::

## Question 3 : Plus forte précipitation

::: methode
On retient l’indice `imax` du plus grand élément déjà rencontré et on le met à jour quand `P[i] > P[imax]`.
:::

```python
P = [12, 0, 5, 23, 0,
     8, 17, 0, 3, 9]
imax = 0
for i in range(len(P)):
    if P[i] > P[imax]:
        imax = i
print(P[imax], imax)
```

```console
23 3
```

::: etape De l’indice au jour
`P[0]` correspond au jour $1$ : l’indice $i$ correspond au jour $i + 1$. L’indice $3$ correspond donc au jour $4$.
:::

::: attention
Ne pas confondre l’indice ($3$), la valeur ($23$ mm) et le numéro du jour ($4$).
:::

::: resultat
La plus forte précipitation est $23$ mm, à l’indice $3$ : c’est le jour $4$.
:::

## Question 4 : Liste des jours de forte pluie

::: methode
On part de la liste vide ; on parcourt les indices et on ajoute le numéro `i + 1` quand `P[i] > 10`.
:::

```python
P = [12, 0, 5, 23, 0,

J = []
for i in range(len(P)):
```

```console
[1, 4, 7]
```

Les valeurs supérieures à $10$ sont $12$ (indice $0$), $23$ (indice $3$) et $17$ (indice $6$), soit les jours $1$, $4$ et $7$.
:::

::: resultat
`J = [1, 4, 7]`
:::

Solution:
<!-- optitab:1 -->
1. Total $77$ mm, moyenne $7{,}7$ mm par jour.
2. $3$ jours sans pluie, fréquence $0{,}3$.
3. Maximum $23$ mm, indice $3$, c’est-à-dire le jour $4$.
4. `J = [1, 4, 7]`

=== Entraînement - Liste des termes d'une suite
Id: 1066
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La suite $(u_n)$ est définie par $u_0 = 5$ et, pour tout entier naturel $n$, $u_{n+1} = 2u_n - 3$.

1. Calculer $u_1$, $u_2$ et $u_3$.
2. Compléter la fonction `termes` pour qu’elle renvoie la liste $[u_0, u_1, \dots, u_n]$, construite par ajouts successifs. Que renvoie `termes(5)` ?

```python
def termes(n):
    u = [5]
    for k in range(n):
        ...
    return u
```

3. On admet que, pour tout entier naturel $n$, $u_n = 2^{n+1} + 3$. Écrire **en compréhension** la liste des termes $u_0$ à $u_5$ à l’aide de cette formule, et vérifier qu’on retrouve la liste de la question 2.
4. Calculer la somme $u_0 + u_1 + \dots + u_5$ à l’aide de la liste.
5. Placer les points de coordonnées $(n \,;\, u_n)$ pour $n$ allant de $0$ à $5$ dans le repère ci-dessous. Que peut-on conjecturer sur le sens de variation de la suite ?

[IMAGE_1]

Étapes:
<!-- optitab:1 -->
## Question 1 : Premiers termes

::: methode
On applique la relation de récurrence avec $n = 0$, puis $n = 1$, puis $n = 2$.
:::

::: etape Calculs
$$
\begin{aligned}
u_1 &= 2u_0 - 3 = 2 \times 5 - 3 = 7 \\
u_2 &= 2u_1 - 3 = 2 \times 7 - 3 = 11 \\
u_3 &= 2u_2 - 3 = 2 \times 11 - 3 = 19
\end{aligned}
$$
:::

::: resultat
$u_1 = 7$, $u_2 = 11$, $u_3 = 19$.
:::

## Question 2 : Fonction `termes`

::: methode
Le dernier terme calculé est `u[-1]` : le suivant vaut `2 * u[-1] - 3`, que l’on ajoute avec `append`.
:::

```python
def termes(n):
    u = [5]
    for k in range(n):
        u.append(2 * u[-1] - 3)
    return u

print(termes(5))
```

```console
[5, 7, 11, 19, 35, 67]
```

::: etape Nombre de termes
La liste part de $u_0$ et la boucle fait $n$ tours : `termes(n)` contient $n + 1$ termes, de $u_0$ à $u_n$. Pour $n = 5$ : $u_4 = 2 \times 19 - 3 = 35$ et $u_5 = 2 \times 35 - 3 = 67$.
:::

::: resultat
`termes(5)` renvoie `[5, 7, 11, 19, 35, 67]`.
:::

## Question 3 : Avec la formule explicite

::: methode
Avec une formule explicite, la compréhension suffit : on écrit la formule dans une fonction `w`, puis `[w(n) for n in range(6)]`.
:::

```python
def termes(n):
    u = [5]
    for k in range(n):
        u.append(2 * u[-1] - 3)
    return u

def w(n):
    return 2**(n + 1) + 3

v = [w(n) for n in range(6)]
print(v)
print(v == termes(5))
```

```console
[5, 7, 11, 19, 35, 67]
True
```

::: etape Lecture
`v == termes(5)` vaut `True` : les deux listes ont les mêmes éléments, dans le même ordre. Par exemple $u_5 = 2^6 + 3 = 64 + 3 = 67$.
:::

::: attention
En Python, la puissance s’écrit `**` : `2**(n + 1)`. Le symbole `^` ne calcule pas une puissance.
:::

::: resultat
La liste en compréhension des $2^{n+1} + 3$, pour $n$ de $0$ à $5$, est `[5, 7, 11, 19, 35, 67]` : c’est la même liste.
:::

## Question 4 : Somme des termes

::: etape Calcul
`sum(termes(5))` additionne les éléments de la liste :
$$
\begin{aligned}
S &= 5 + 7 + 11 + 19 + 35 + 67 \\
&= 144
\end{aligned}
$$
:::

::: resultat
$u_0 + u_1 + \dots + u_5 = 144$.

=== Problème - Coefficients directeurs des sécantes et nombre dérivé
Id: 4948
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère la fonction $g$ définie sur $\mathbb{R}$ par $g(x) = x^2 - 3x$, sa courbe $\mathcal{C}_g$, le point $A$ de $\mathcal{C}_g$ d’abscisse $2$ et, pour $h \neq 0$, le point $M$ de $\mathcal{C}_g$ d’abscisse $2 + h$.

[IMAGE_1]

1. Calculer $g(2)$. Montrer que, pour $h \neq 0$, le coefficient directeur de la sécante $(AM)$ est égal à $1 + h$.
2. Sans ordinateur, donner l’affichage du programme suivant.

```python

    return x**2 - 3*x

def taux(h):
    return (g(2 + h) - g(2)) / h

H = [1, 0.5, 0.25, 0.125]

print(P)
```

3. Écrire la liste `H` en compréhension, à l’aide de puissances de $2$.
4. Quand $h$ se rapproche de $0$, de quel nombre les coefficients directeurs se rapprochent-ils ? Le vérifier avec la fonction dérivée de $g$, puis donner une équation de la tangente à $\mathcal{C}_g$ en $A$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Coefficient directeur de $(AM)$

::: methode
Le coefficient directeur de $(AM)$ est le taux de variation $\dfrac{g(2 + h) - g(2)}{h}$.
:::

::: etape Calcul de $g(2)$ et de $g(2 + h)$
$g(2) = 4 - 6 = -2$, donc $A(2 \,;\, -2)$.
$$
\begin{aligned}
g(2 + h) &= (2 + h)^2 - 3(2 + h) \\
&= 4 + 4h + h^2 - 6 - 3h \\
&= h^2 + h - 2
\end{aligned}
$$
:::

::: etape Taux de variation
$$
\begin{aligned}
\frac{g(2 + h) - g(2)}{h} &= \frac{h^2 + h - 2 + 2}{h} \\
&= \frac{h(h + 1)}{h} \\
&= 1 + h
\end{aligned}
$$
:::

::: resultat
$g(2) = -2$ et le coefficient directeur de $(AM)$ vaut $1 + h$.
:::

::: etape Valeurs
$1 + 1 = 2$, $1 + 0{,}5 = 1{,}5$, $1 + 0{,}25 = 1{,}25$, $1 + 0{,}125 = 1{,}125$. Une division `/` donne un nombre décimal : Python écrit `2.0` et non `2`.
:::


## Question 4 : Nombre dérivé et tangente

=== Entraînement - Parcours par indices et sens de variation d'une suite

Énoncé:

```python

    return n**2 - 7*n + 1
```

Étapes:
<!-- optitab:1 -->
## Question 1 : La liste `U`

::: methode
`[u(n) for n in range(8)]` est la liste des termes $u_0$, …, $u_7$ : l’indice est le rang.
:::

::: etape Calculs
$$
\begin{aligned}
u_3 &= 9 - 21 + 1 = -11 \\
u_4 &= 16 - 28 + 1 = -11 \\
u_7 &= 49 - 49 + 1 = 1
\end{aligned}
$$

## Question 2 : La liste `D` des différences

::: methode
`D[i]` est `U[i + 1] - U[i]`, c’est-à-dire $u_{i+1} - u_i$ : la différence entre un terme et le précédent.
:::

::: etape Dernier indice
`U[i + 1]` doit exister : $i + 1 \leqslant 7$, donc $i \leqslant 6$. Avec `range(len(U) - 1)`, c’est-à-dire `range(7)`, `i` va de $0$ à $6$ : `D` contient $7$ éléments.
:::

```python

    return n**2 - 7*n + 1
```

`D[i]` $= u_{i+1} - u_i$ ; `D = [-6, -4, -2, 0, 2, 4, 6]`.

## Question 3 : Démonstration et sens de variation

::: etape Calcul de la différence
$$
\begin{aligned}
u_{n+1} - u_n &= (n + 1)^2 - 7(n + 1) + 1 \\
&\quad - (n^2 - 7n + 1) \\
&= n^2 + 2n + 1 - 7n - 7 + 1 \\
&\quad - n^2 + 7n - 1 \\
&= 2n - 6
\end{aligned}
$$
On retrouve les éléments de `D` : $2 \times 0 - 6 = -6$, $2 \times 1 - 6 = -4$, etc.
:::

::: etape Signe
- Pour $n \leqslant 2$ : $2n - 6 < 0$, donc $u_{n+1} < u_n$.
- Pour $n = 3$ : $2n - 6 = 0$, donc $u_4 = u_3$.
- Pour $n \geqslant 4$ : $2n - 6 > 0$, donc $u_{n+1} > u_n$.
:::

[IMAGE_1]

::: resultat
La suite est décroissante de $u_0$ à $u_3$, $u_3 = u_4 = -11$, puis elle est croissante à partir du rang $3$ ($u_{n+1} \geqslant u_n$ pour $n \geqslant 3$).
:::
