<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Calculer un produit scalaire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\|\|\vec{v}\|\cos(\vec{u}, \vec{v}) = xx' + yy'$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Projection : $\displaystyle \overrightarrow{AB} \cdot \overrightarrow{AC} = AB \times AH$ (même sens) ou $\displaystyle -AB \times AH$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle \vec{u} \cdot \vec{u} = \|\vec{u}\|^2$ ; $\displaystyle \vec{u} \cdot \vec{v} = 0 \iff \vec{u} \perp \vec{v}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\displaystyle \|\vec{u} + \vec{v}\|^2 = \|\vec{u}\|^2 + 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Applications</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Al-Kashi : $\displaystyle a^2 = b^2 + c^2 - 2bc\cos\hat{A}$ (longueur ou angle d’un triangle quelconque).</p>
<p style="margin:6px 0 0 0;">2️⃣ Angle entre deux vecteurs : $\displaystyle \cos(\vec{u}, \vec{v}) = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\|\|\vec{v}\|}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB} = 0 \iff M$ sur le cercle de diamètre $\displaystyle [AB]$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire un produit scalaire comme un vecteur : c’est un nombre.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier le signe moins quand le projeté est « de l’autre côté » (angle obtus).</p>
<p style="margin:6px 0 0 0;">3️⃣ Utiliser $\displaystyle xx' + yy'$ dans un repère qui n’est pas orthonormé.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier le facteur $\displaystyle 2$ dans $\displaystyle \|\vec{u} + \vec{v}\|^2$ ou dans Al-Kashi.</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> pour prouver un angle droit, je calcule un produit scalaire et je montre qu’il est nul.</p>
