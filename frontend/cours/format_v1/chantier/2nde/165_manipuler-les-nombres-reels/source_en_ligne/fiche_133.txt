Titre: Résumé : Manipuler les nombres réels

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : les ensembles de nombres, les intervalles, la valeur absolue et l’encadrement.
:::

## I. Les ensembles de nombres

::: formule
$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$$
:::

[IMAGE_1]

- **Décimal** : $\dfrac{k}{10^n}$, écriture décimale finie ($0{,}125$).
- **Rationnel** : $\dfrac{p}{q}$, écriture décimale finie ou périodique ($\dfrac{1}{3} = 0{,}333\ldots$).
- **Irrationnel** : réel non rationnel ($\sqrt{2}$, $\pi$).

## II. Intervalles, distances, encadrements

[IMAGE_2]

| Inégalité | Intervalle |
|---|---|
| $a \le x \le b$ | $x \in [a\,;b]$ |
| $a \lt x \lt b$ | $x \in {]a\,;b[}$ |
| $x \ge a$ | $x \in {[a\,;+\infty[}$ |
| $x \lt b$ | $x \in {]{-\infty}\,;b[}$ |

- $|x|$ est la distance de $x$ à $0$ ; la distance entre $a$ et $b$ est $|b - a|$.
- Intervalle centré : $|x - a| \le r \iff x \in [a - r\,;a + r]$. Exemple : $|x - 3| \le 2 \iff x \in [1\,;5]$.
- Encadrement à $10^{-n}$ près : $a \le x \le b$ avec $b - a = 10^{-n}$, comme $1{,}41 \le \sqrt{2} \le 1{,}42$.

## III. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Fermer le crochet du côté de l’infini : on écrit ${[2\,;+\infty[}$.
2. Oublier qu’un crochet ouvert exclut la borne : $5 \notin {[2\,;5[}$.
3. Écrire une valeur absolue négative : $\lvert -7\rvert = 7$.
4. Croire qu’un nombre est irrationnel parce que la calculatrice affiche beaucoup de décimales : $\dfrac{1}{7}$ est rationnel.
:::

::: conseil Réflexe
- Une inégalité : je la dessine sur la droite graduée, puis je l’écris en intervalle.
- « $|x - a| \le r$ » se lit « $x$ est à une distance au plus $r$ de $a$ ».
:::
