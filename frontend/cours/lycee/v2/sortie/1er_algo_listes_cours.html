🎯 Objectifs du chapitre : créer une liste (en extension, avec range, par ajouts successifs ou en compréhension), accéder à ses éléments par leurs indices, la modifier, la parcourir, et l’utiliser pour stocker les termes d’une suite ou une série statistique.

I. Créer une liste

Définition : une liste est une suite ordonnée de valeurs, écrite entre crochets et séparées par des virgules. len(L) donne son nombre d’éléments.

• En extension : L = [3, 7, 1, 9, 4] ; liste vide : [].

• Avec range : list(range(5)) donne [0, 1, 2, 3, 4].

• En compréhension : [k * k for k in range(6)] donne [0, 1, 4, 9, 16, 25].

💡 Suite arithmétique : [2 + 3 * k for k in range(6)] donne [2, 5, 8, 11, 14, 17], les six premiers termes de $\displaystyle u_n = 2 + 3n$. On peut aussi filtrer : [x for x in L if x % 2 == 0] garde les valeurs paires.

II. Indices

Propriété : les éléments sont numérotés à partir de $\displaystyle 0$ : L[0] est le premier, L[len(L) - 1] le dernier, que l’on obtient aussi avec L[-1]. L[1:3] donne les éléments d’indices $\displaystyle 1$ et $\displaystyle 2$.

[IMAGE_1]
⚠️ Attention : une liste de $\displaystyle 5$ éléments a des indices de $\displaystyle 0$ à $\displaystyle 4$ : L[5] provoque une erreur IndexError.

III. Modifier une liste

• L[2] = 10 remplace l’élément d’indice $\displaystyle 2$ : L devient [3, 7, 10, 9, 4].

• L.append(5) ajoute $\displaystyle 5$ à la fin ; L.pop() retire et renvoie le dernier élément.

• L.remove(9) supprime la première occurrence de $\displaystyle 9$.

[IMAGE_2]
def termes(n): u = [2] for k in range(n - 1): u.append(0.5 * u[-1] + 2) return u

termes(4) renvoie [2, 3.0, 3.5, 3.75] : chaque nouveau terme est calculé à partir du dernier, u[-1].

IV. Parcourir une liste

• Par les valeurs : for x in L: ; par les indices : for i in range(len(L)): puis L[i].

• Fonctions utiles : sum(L), max(L), min(L), sorted(L) (copie triée).

def moyenne(L): s = 0 for x in L: s = s + x return s / len(L)

moyenne([12, 15, 9, 14]) renvoie $\displaystyle 12{,}5$ (on obtient le même résultat avec sum(L) / len(L)).

🏆 L’essentiel : une liste s’écrit entre crochets ; les indices commencent à $\displaystyle 0$ et L[-1] est le dernier élément ; append ajoute à la fin ; on crée une liste en compréhension avec [expression for k in range(n)] ; on la parcourt par valeurs ou par indices.
