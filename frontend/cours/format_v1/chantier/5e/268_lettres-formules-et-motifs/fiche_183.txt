Titre: Résumé : Lettres, formules et motifs

<!-- optitab:1 -->
::: objectifs
Retenir l'essentiel : écrire avec des lettres, produire une formule, calculer, tester une égalité, programme de calcul et tableur.
:::

## I. Écrire avec des lettres

| Écriture complète | Écriture simplifiée |
|---|---|
| $5 \times a$ ; $a \times 5$ | $5a$ |
| $a \times b$ | $ab$ |
| $2 \times (a + 1)$ | $2(a + 1)$ |
| $a \times a$ ; $a \times a \times a$ | $a^2$ ; $a^3$ |
| $1 \times a$ | $a$ |

- Jamais entre deux nombres : $4 \times 7 = 28$, pas $47$.
- $a^2 \neq 2a$ : pour $a = 6$, $a^2 = 36$ et $2a = 12$.

## II. Produire une formule

- Rectangle : $P = 2L + 2\ell$, $A = L\ell$. Carré : $P = 4c$, $A = c^2$ (même unité).
- Prix : adhésion $15$ € puis $4$ € par séance → $15 + 4n$.
- Motif : **découper** l'étape $n$ en parties qu'on sait compter, puis **vérifier** sur les premières étapes.

## III. Calculer et tester

::: methode Remplacer une lettre par un nombre
Remplacer chaque lettre, rétablir les $\times$, respecter les priorités (puissances, puis $\times$ et $\div$, puis $+$ et $-$). Pour $a = 3$ : $5a^2 - 2a + 1 = 45 - 6 + 1 = 40$.
:::

- **Tester une égalité** : calculer séparément les deux membres. $4x - 3 = 2x + 5$ est vraie pour $x = 4$ ($13 = 13$), fausse pour $x = 2$ ($5 \neq 9$).
- Un seul **contre-exemple** suffit pour montrer qu'une égalité n'est pas toujours vraie.

## IV. Programme de calcul et tableur

- « Ajouter $4$, puis multiplier par $5$ » → $5(x + 4)$ : parenthèses quand on multiplie une somme.
- Tableur : `=3*A2+1` calcule $3n + 1$ quand A2 contient $n$ ; recopiée vers le bas, elle devient `=3*A3+1`…

[IMAGE_2]

::: attention Les 5 erreurs classiques
1. Écrire $47$ pour $4 \times 7$.
2. Confondre $a^2$ et $2a$ ; calculer $5 \times 3^2$ comme $15^2$.
3. Oublier les parenthèses : « ajouter $4$ puis multiplier par $5$ » n'est pas $x + 4 \times 5$.
4. Conclure qu'une égalité est toujours vraie après un seul test réussi.
5. Oublier le `*` dans un tableur : `=3A2+1` est refusé.
:::
