=== Découverte - Repérer l'hypoténuse et le côté adjacent
Id: 3650
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Voici trois triangles rectangles. Dans chacun, l'angle droit est codé et un angle aigu est marqué : $\widehat{ABC}$ dans le triangle 1, $\widehat{DEF}$ dans le triangle 2 et $\widehat{GKH}$ dans le triangle 3.

[IMAGE_1]

1. Dans le triangle 1, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{ABC}$ ?
2. Dans le triangle 2, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{DEF}$ ?
3. Dans le triangle 3, quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{GKH}$ ?
4. Écrire $\cos \widehat{ABC}$, $\cos \widehat{DEF}$ et $\cos \widehat{GKH}$ sous forme de quotients de longueurs.
5. Dans le triangle 1, quel est le côté adjacent à l'autre angle aigu $\widehat{ACB}$ ? Écrire $\cos \widehat{ACB}$.
6. Expliquer pourquoi le cosinus d'un angle aigu est toujours compris entre $0$ et $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle 1

::: methode
L'hypoténuse est le côté en face de l'angle droit ; le côté adjacent est le côté de l'angle droit qui part du sommet de l'angle marqué.
:::

::: etape Trouver l'hypoténuse
L'angle droit est en $A$. Le côté qui ne passe pas par $A$ est $[BC]$ : c'est l'hypoténuse.
:::

::: etape Trouver le côté adjacent à $\widehat{ABC}$
Les côtés de l'angle droit sont $[AB]$ et $[AC]$. Celui qui part du sommet $B$ est $[AB]$.
:::

[IMAGE_2]

::: resultat
Hypoténuse : $[BC]$ ; côté adjacent à $\widehat{ABC}$ : $[AB]$.
:::

## Question 2 : Le triangle 2

::: etape Trouver l'hypoténuse
L'angle droit est en $F$ : l'hypoténuse est le côté $[DE]$, qui ne passe pas par $F$.
:::

::: etape Trouver le côté adjacent à $\widehat{DEF}$
Les côtés de l'angle droit sont $[FE]$ et $[FD]$. Celui qui part du sommet $E$ est $[EF]$.
:::

[IMAGE_3]

::: resultat
Hypoténuse : $[DE]$ ; côté adjacent à $\widehat{DEF}$ : $[EF]$.
:::

## Question 3 : Le triangle 3

::: etape Trouver l'hypoténuse
L'angle droit est en $H$ : l'hypoténuse est $[GK]$.
:::

::: etape Trouver le côté adjacent à $\widehat{GKH}$
Les côtés de l'angle droit sont $[HG]$ et $[HK]$. Celui qui part du sommet $K$ est $[HK]$.
:::

[IMAGE_4]

::: resultat
Hypoténuse : $[GK]$ ; côté adjacent à $\widehat{GKH}$ : $[HK]$.
:::

## Question 4 : Les trois cosinus

::: methode
$$\cos(\text{angle}) = \frac{\text{côté adjacent}}{\text{hypoténuse}}$$
:::

::: etape Appliquer la définition dans chaque triangle
On place le côté adjacent au numérateur et l'hypoténuse au dénominateur, avec les réponses des questions 1 à 3.
:::

::: resultat
$$\cos \widehat{ABC} = \frac{AB}{BC} \qquad \cos \widehat{DEF} = \frac{EF}{DE} \qquad \cos \widehat{GKH} = \frac{HK}{GK}$$
:::

## Question 5 : L'autre angle aigu du triangle 1

::: etape Changer d'angle
Le sommet de l'angle $\widehat{ACB}$ est $C$. Le côté de l'angle droit qui part de $C$ est $[AC]$ : c'est le nouveau côté adjacent. L'hypoténuse reste $[BC]$.
:::

[IMAGE_5]

::: resultat
Le côté adjacent à $\widehat{ACB}$ est $[AC]$ et $\cos \widehat{ACB} = \dfrac{AC}{BC}$.
:::

::: attention Erreur fréquente
Garder le même côté adjacent pour les deux angles aigus : le côté adjacent dépend de l'angle choisi, seule l'hypoténuse ne change pas.
:::

## Question 6 : Un cosinus entre $0$ et $1$

::: etape Le cosinus est positif
C'est un quotient de deux longueurs, qui sont des nombres positifs.
:::

::: etape Le cosinus est inférieur à $1$
L'hypoténuse est le plus long côté du triangle rectangle : le numérateur (côté adjacent) est plus petit que le dénominateur (hypoténuse), donc le quotient est inférieur à $1$.
:::

::: resultat
Pour tout angle aigu d'un triangle rectangle, $0 < \cos(\text{angle}) < 1$.
:::

::: retenir
Si un calcul donne un cosinus supérieur à $1$, on a inversé le côté adjacent et l'hypoténuse.
:::

Solution:
<!-- optitab:1 -->
1. Hypoténuse $[BC]$ ; côté adjacent $[AB]$.
2. Hypoténuse $[DE]$ ; côté adjacent $[EF]$.
3. Hypoténuse $[GK]$ ; côté adjacent $[HK]$.
4. $\cos \widehat{ABC} = \dfrac{AB}{BC}$ ; $\cos \widehat{DEF} = \dfrac{EF}{DE}$ ; $\cos \widehat{GKH} = \dfrac{HK}{GK}$.
5. $[AC]$ ; $\cos \widehat{ACB} = \dfrac{AC}{BC}$.
6. Le côté adjacent est plus court que l'hypoténuse, donc $0 < \cos < 1$.

=== Découverte - Les cosinus des deux angles aigus
Id: 3651
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $DEF$ est rectangle en $E$, avec $DE = 4$ cm, $EF = 3$ cm et $DF = 5$ cm.

[IMAGE_1]

1. Quelle est l'hypoténuse du triangle $DEF$ ?
2. Écrire $\cos \widehat{EDF}$ avec des longueurs.
3. Calculer $\cos \widehat{EDF}$.
4. Écrire $\cos \widehat{DFE}$ avec des longueurs.
5. Calculer $\cos \widehat{DFE}$.
6. Avec la calculatrice, donner la mesure des angles $\widehat{EDF}$ et $\widehat{DFE}$ au degré près. Calculer leur somme.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'hypoténuse

::: etape Repérer l'angle droit
L'angle droit est en $E$ ; l'hypoténuse est le côté qui ne passe pas par $E$.
:::

::: resultat
L'hypoténuse est $[DF]$ (c'est bien le plus long côté : $5$ cm).
:::

## Question 2 : Écrire $\cos \widehat{EDF}$

::: methode
$\cos(\text{angle}) = \dfrac{\text{côté adjacent}}{\text{hypoténuse}}$.
:::

::: etape Le côté adjacent à $\widehat{EDF}$
C'est le côté de l'angle droit qui part de $D$ : $[DE]$.
:::

::: resultat
$$\cos \widehat{EDF} = \frac{DE}{DF}$$
:::

## Question 3 : Calculer $\cos \widehat{EDF}$

::: etape Remplacer par les longueurs
$$\cos \widehat{EDF} = \frac{4}{5}$$
:::

[IMAGE_2]

::: resultat
$\cos \widehat{EDF} = 0{,}8$.
:::

## Question 4 : Écrire $\cos \widehat{DFE}$

::: etape Le côté adjacent à $\widehat{DFE}$
C'est le côté de l'angle droit qui part de $F$ : $[EF]$. L'hypoténuse reste $[DF]$.
:::

::: resultat
$$\cos \widehat{DFE} = \frac{EF}{DF}$$
:::

## Question 5 : Calculer $\cos \widehat{DFE}$

::: etape Remplacer par les longueurs
$$\cos \widehat{DFE} = \frac{3}{5}$$
:::

[IMAGE_3]

::: resultat
$\cos \widehat{DFE} = 0{,}6$.
:::

## Question 6 : Les mesures des angles

::: methode
On retrouve un angle à partir de son cosinus avec la touche $\cos^{-1}$ (calculatrice en mode degrés).
:::

::: etape L'angle $\widehat{EDF}$
$\cos^{-1}(0{,}8) \approx 36{,}87$, donc $\widehat{EDF} \approx 37^\circ$.
:::

::: etape L'angle $\widehat{DFE}$
$\cos^{-1}(0{,}6) \approx 53{,}13$, donc $\widehat{DFE} \approx 53^\circ$.
:::

::: etape La somme
$36{,}87^\circ + 53{,}13^\circ = 90^\circ$.
:::

::: resultat
$\widehat{EDF} \approx 37^\circ$, $\widehat{DFE} \approx 53^\circ$ et leur somme vaut $90^\circ$.
:::

::: attention Erreur fréquente
Prendre $DE$ comme côté adjacent pour les deux angles : pour $\widehat{DFE}$, le côté adjacent est $[EF]$.
:::

::: retenir
Dans un triangle rectangle, les deux angles aigus ont pour somme $90^\circ$ (la somme des trois angles vaut $180^\circ$).
:::

Solution:
<!-- optitab:1 -->
1. $[DF]$
2. $\cos \widehat{EDF} = \dfrac{DE}{DF}$
3. $0{,}8$
4. $\cos \widehat{DFE} = \dfrac{EF}{DF}$
5. $0{,}6$
6. $\widehat{EDF} \approx 37^\circ$ ; $\widehat{DFE} \approx 53^\circ$ ; somme : $90^\circ$.

=== Découverte - Calculer le côté adjacent
Id: 3652
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $BC = 10$ cm et $\widehat{ABC} = 35^\circ$.

[IMAGE_1]

1. Quelle est l'hypoténuse ? Quel est le côté adjacent à l'angle $\widehat{ABC}$ ?
2. Écrire $\cos \widehat{ABC}$ avec des longueurs.
3. Remplacer par les valeurs connues.
4. Calculer $AB$ au millimètre près.
5. Calculer $AC$ au millimètre près, avec le théorème de Pythagore.
6. Calculer la mesure de $\widehat{ACB}$, puis vérifier que $\cos \widehat{ACB} \approx \dfrac{AC}{BC}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les côtés

::: etape Repérer l'angle droit et le sommet de l'angle
L'angle droit est en $A$ : l'hypoténuse est $[BC]$. Le côté de l'angle droit qui part de $B$ est $[AB]$.
:::

::: resultat
Hypoténuse : $[BC]$ ; côté adjacent à $\widehat{ABC}$ : $[AB]$.
:::

## Question 2 : La formule

::: etape Côté adjacent sur hypoténuse
On écrit la définition avec les noms des côtés trouvés à la question 1.
:::

::: resultat
$$\cos \widehat{ABC} = \frac{AB}{BC}$$
:::

## Question 3 : Les valeurs

::: etape Remplacer
On remplace $\widehat{ABC}$ par $35^\circ$ et $BC$ par $10$ ; $AB$ reste inconnu.
:::

::: resultat
$$\cos 35^\circ = \frac{AB}{10}$$
:::

## Question 4 : Calculer $AB$

::: methode
On cherche le côté adjacent : on multiplie l'hypoténuse par le cosinus.
:::

::: etape Isoler $AB$
$$
\begin{aligned}
\cos 35^\circ &= \frac{AB}{10} \\
AB &= 10 \times \cos 35^\circ \approx 8{,}19
\end{aligned}
$$
:::

::: resultat
$AB \approx 8{,}2$ cm.
:::

## Question 5 : Calculer $AC$

::: etape Théorème de Pythagore dans $ABC$ rectangle en $A$
$$
\begin{aligned}
BC^2 &= AB^2 + AC^2 \\
AC^2 &= BC^2 - AB^2 \\
AC^2 &= 100 - (10 \times \cos 35^\circ)^2 \approx 32{,}90
\end{aligned}
$$
:::

::: etape Racine carrée
$AC \approx \sqrt{32{,}90} \approx 5{,}74$.
:::

[IMAGE_2]

::: resultat
$AC \approx 5{,}7$ cm.
:::

::: attention Erreur fréquente
Calculer avec $AB = 8{,}2$ (arrondi) : on garde la valeur de la calculatrice $10 \times \cos 35^\circ$ jusqu'au bout pour ne pas fausser le résultat.
:::

## Question 6 : L'angle $\widehat{ACB}$

::: etape Angles aigus complémentaires
$\widehat{ACB} = 90^\circ - 35^\circ = 55^\circ$.
:::

::: etape Vérification
$\cos 55^\circ \approx 0{,}574$ et $\dfrac{AC}{BC} \approx \dfrac{5{,}74}{10} = 0{,}574$.
:::

::: resultat
$\widehat{ACB} = 55^\circ$ et $\cos \widehat{ACB} \approx 0{,}574 \approx \dfrac{AC}{BC}$ : $[AC]$ est bien le côté adjacent à $\widehat{ACB}$.
:::

Solution:
<!-- optitab:1 -->
1. Hypoténuse $[BC]$ ; côté adjacent $[AB]$.
2. $\cos \widehat{ABC} = \dfrac{AB}{BC}$
3. $\cos 35^\circ = \dfrac{AB}{10}$
4. $AB = 10 \times \cos 35^\circ \approx 8{,}2$ cm
5. $AC \approx 5{,}7$ cm
6. $\widehat{ACB} = 55^\circ$ ; $\cos 55^\circ \approx 0{,}574 \approx \dfrac{AC}{BC}$.

=== Découverte - Calculer l'hypoténuse
Id: 3653
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $AB = 6$ cm et $\widehat{ABC} = 52^\circ$.

[IMAGE_1]

1. Écrire $\cos \widehat{ABC}$ avec des longueurs.
2. Remplacer par les valeurs connues.
3. Expliquer pourquoi $BC = \dfrac{6}{\cos 52^\circ}$.
4. Calculer $BC$ au millimètre près.
5. Vérifier que le résultat est cohérent.
6. Calculer $AC$ au millimètre près.

Étapes:
<!-- optitab:1 -->
## Question 1 : La formule

::: etape Nommer les côtés
L'angle droit est en $A$ : l'hypoténuse est $[BC]$. Le côté adjacent à $\widehat{ABC}$ est $[AB]$.
:::

::: resultat
$$\cos \widehat{ABC} = \frac{AB}{BC}$$
:::

## Question 2 : Les valeurs

::: etape Remplacer
On connaît $AB = 6$ et $\widehat{ABC} = 52^\circ$ ; l'inconnue $BC$ est au dénominateur.
:::

::: resultat
$$\cos 52^\circ = \frac{6}{BC}$$
:::

## Question 3 : Isoler $BC$

::: methode
L'inconnue est au dénominateur : on utilise le produit en croix.
:::

::: etape Produit en croix
$$
\begin{aligned}
\frac{\cos 52^\circ}{1} &= \frac{6}{BC} \\
BC \times \cos 52^\circ &= 6 \\
BC &= \frac{6}{\cos 52^\circ}
\end{aligned}
$$
:::

::: resultat
On divise le côté adjacent par le cosinus : $BC = \dfrac{6}{\cos 52^\circ}$.
:::

::: attention Erreur fréquente
Écrire $BC = 6 \times \cos 52^\circ \approx 3{,}7$ : on obtiendrait une hypoténuse plus courte que $AB$, ce qui est impossible.
:::

## Question 4 : Calculer $BC$

::: etape À la calculatrice
$BC = \dfrac{6}{\cos 52^\circ} \approx 9{,}746$.
:::

[IMAGE_2]

::: resultat
$BC \approx 9{,}7$ cm.
:::

## Question 5 : La cohérence

::: etape L'hypoténuse est le plus long côté
$9{,}7 > 6$ : l'hypoténuse est bien plus longue que le côté adjacent.
:::

::: resultat
Le résultat est cohérent.
:::

## Question 6 : Calculer $AC$

::: etape Théorème de Pythagore, avec la valeur non arrondie de $BC$
$$
\begin{aligned}
AC^2 &= BC^2 - AB^2 \\
&\approx 94{,}98 - 36 = 58{,}98
\end{aligned}
$$
:::

::: etape Racine carrée
$AC \approx \sqrt{58{,}98} \approx 7{,}68$.
:::

::: resultat
$AC \approx 7{,}7$ cm.
:::

::: retenir
Avec $BC$ arrondi à $9{,}7$, on trouverait $AC \approx 7{,}6$ cm : un arrondi intermédiaire fausse le résultat final.
:::

Solution:
<!-- optitab:1 -->
1. $\cos \widehat{ABC} = \dfrac{AB}{BC}$
2. $\cos 52^\circ = \dfrac{6}{BC}$
3. Produit en croix : $BC \times \cos 52^\circ = 6$.
4. $BC \approx 9{,}7$ cm
5. $9{,}7 > 6$ : cohérent.
6. $AC \approx 7{,}7$ cm

=== Découverte - Calculer un angle
Id: 3654
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $AB = 4$ cm et $BC = 7$ cm.

[IMAGE_1]

1. Écrire $\cos \widehat{ABC}$, puis le calculer sous forme de fraction.
2. Quelle touche de la calculatrice permet de retrouver l'angle ? Dans quel mode doit-elle être ?
3. Donner la mesure de $\widehat{ABC}$ au degré près.
4. En déduire la mesure de $\widehat{ACB}$ au degré près.
5. Calculer $AC$, puis $\cos \widehat{ACB}$, et retrouver $\widehat{ACB}$ avec la calculatrice.
6. Résumer en trois étapes la méthode pour calculer un angle avec le cosinus.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le cosinus de $\widehat{ABC}$

::: methode
On connaît le côté adjacent et l'hypoténuse : on calcule le cosinus, puis on retrouve l'angle avec la calculatrice.
:::

::: etape Nommer les côtés
L'hypoténuse est $[BC]$ ; le côté adjacent à $\widehat{ABC}$ est $[AB]$.
:::

::: resultat
$$\cos \widehat{ABC} = \frac{AB}{BC} = \frac{4}{7}$$
:::

## Question 2 : La touche

::: etape Le chemin inverse
La touche $\cos$ donne le cosinus d'un angle ; la touche $\cos^{-1}$ (Arccos, acos) fait le chemin inverse : on lui donne un cosinus, elle renvoie l'angle.
:::

::: resultat
La touche $\cos^{-1}$, calculatrice en mode degrés.
:::

## Question 3 : L'angle $\widehat{ABC}$

::: etape À la calculatrice
$\cos^{-1}\left(\dfrac{4}{7}\right) \approx 55{,}15$
:::

::: resultat
$\widehat{ABC} \approx 55^\circ$.
:::

## Question 4 : L'angle $\widehat{ACB}$

::: etape Angles aigus complémentaires
$$\widehat{ACB} = 90^\circ - \widehat{ABC} \approx 90^\circ - 55{,}15^\circ = 34{,}85^\circ$$
:::

::: resultat
$\widehat{ACB} \approx 35^\circ$.
:::

::: attention Erreur fréquente
Partir de la valeur arrondie $55^\circ$ sans réfléchir : ici on trouve aussi $35^\circ$, mais en général on calcule avec la valeur non arrondie.
:::

## Question 5 : Vérification par le cosinus

::: etape Théorème de Pythagore
$AC^2 = BC^2 - AB^2 = 49 - 16 = 33$, donc $AC = \sqrt{33} \approx 5{,}74$ cm.
:::

::: etape Le cosinus de $\widehat{ACB}$
Le côté adjacent à $\widehat{ACB}$ est $[AC]$ :
$$\cos \widehat{ACB} = \frac{AC}{BC} = \frac{\sqrt{33}}{7} \approx 0{,}821$$
:::

::: etape L'angle
$\cos^{-1}\left(\dfrac{\sqrt{33}}{7}\right) \approx 34{,}85$.
:::

[IMAGE_2]

::: resultat
$\widehat{ACB} \approx 35^\circ$ : les deux méthodes donnent le même résultat.
:::

## Question 6 : La méthode

::: resultat
1. Écrire le cosinus de l'angle : côté adjacent sur hypoténuse.
2. Calculer ce quotient avec les longueurs connues.
3. Appliquer la touche $\cos^{-1}$ (mode degrés) et arrondir comme demandé.
:::

::: retenir
Pour calculer un angle avec le cosinus, il faut connaître le côté adjacent **et** l'hypoténuse.
:::

Solution:
<!-- optitab:1 -->
1. $\cos \widehat{ABC} = \dfrac{4}{7}$
2. $\cos^{-1}$, en mode degrés.
3. $\widehat{ABC} \approx 55^\circ$
4. $\widehat{ACB} \approx 35^\circ$
5. $AC = \sqrt{33} \approx 5{,}74$ cm ; $\cos \widehat{ACB} \approx 0{,}821$ ; $\widehat{ACB} \approx 35^\circ$.
6. Cosinus de l'angle, calcul du quotient, touche $\cos^{-1}$.

=== Découverte - Le cosinus à la calculatrice
Id: 3655
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On complète le tableau ci-dessous avec la calculatrice, réglée en mode degrés.

| Angle | Cosinus |
|---|---|
| $20^\circ$ | … |
| $30^\circ$ | … |
| $45^\circ$ | … |
| $60^\circ$ | … |
| $70^\circ$ | … |
| $89^\circ$ | … |

1. Calculer $\cos 60^\circ$. À quoi sert ce calcul avant de commencer ?
2. Calculer $\cos 20^\circ$, $\cos 30^\circ$ et $\cos 45^\circ$ au millième.
3. Calculer $\cos 70^\circ$ et $\cos 89^\circ$ au millième.
4. Comment varie le cosinus quand l'angle augmente ?
5. Sans calculatrice, comparer $\cos 25^\circ$ et $\cos 65^\circ$.
6. Trouver, au degré près, l'angle dont le cosinus vaut $0{,}9$. Peut-on trouver un angle aigu dont le cosinus vaut $1{,}2$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : $\cos 60^\circ$

::: methode
La touche $\cos$ donne le cosinus d'un angle ; la touche $\cos^{-1}$ fait le chemin inverse. La calculatrice doit être en mode degrés.
:::

::: etape À la calculatrice
En mode degrés, la calculatrice affiche $0{,}5$.
:::

::: resultat
$\cos 60^\circ = 0{,}5$ : si la calculatrice n'affiche pas $0{,}5$, elle n'est pas en mode degrés.
:::

## Question 2 : Trois valeurs

::: etape Valeurs affichées
$\cos 20^\circ \approx 0{,}9397$ ; $\cos 30^\circ \approx 0{,}8660$ ; $\cos 45^\circ \approx 0{,}7071$.
:::

::: etape Arrondir au millième
On regarde le chiffre des dix-millièmes : $0{,}9397$ s'arrondit à $0{,}940$.
:::

::: resultat
$\cos 20^\circ \approx 0{,}940$ ; $\cos 30^\circ \approx 0{,}866$ ; $\cos 45^\circ \approx 0{,}707$.
:::

## Question 3 : Deux autres valeurs

::: etape Valeurs affichées
$\cos 70^\circ \approx 0{,}3420$ ; $\cos 89^\circ \approx 0{,}0175$.
:::

::: resultat
$\cos 70^\circ \approx 0{,}342$ ; $\cos 89^\circ \approx 0{,}017$.
:::

## Question 4 : Le sens de variation

::: etape Lire le tableau dans l'ordre des angles
$0{,}940 > 0{,}866 > 0{,}707 > 0{,}5 > 0{,}342 > 0{,}017$.
:::

::: etape Comprendre sur une figure
Pour une même hypoténuse de $10$ cm, plus l'angle est grand, plus le côté adjacent est court.
:::

[IMAGE_1]

::: resultat
Quand l'angle aigu augmente, son cosinus diminue.
:::

## Question 5 : Comparer sans calculatrice

::: etape Utiliser la question 4
$25^\circ < 65^\circ$ et le cosinus diminue quand l'angle augmente.
:::

::: resultat
$\cos 25^\circ > \cos 65^\circ$.
:::

## Question 6 : Retrouver un angle

::: etape Le cosinus vaut $0{,}9$
$\cos^{-1}(0{,}9) \approx 25{,}84$, donc l'angle mesure environ $26^\circ$.
:::

::: etape Le cosinus vaut $1{,}2$
$1{,}2 > 1$, or le cosinus d'un angle aigu est toujours inférieur à $1$.
:::

::: resultat
Environ $26^\circ$ ; aucun angle aigu n'a pour cosinus $1{,}2$ (la calculatrice affiche d'ailleurs une erreur).
:::

::: attention Erreur fréquente
Croire que la calculatrice « bugue » : le message d'erreur signale un calcul impossible, souvent un quotient inversé (hypoténuse au numérateur).
:::

Solution:
<!-- optitab:1 -->
1. $0{,}5$ : contrôle du mode degrés.
2. $0{,}940$ ; $0{,}866$ ; $0{,}707$
3. $0{,}342$ ; $0{,}017$
4. Le cosinus diminue quand l'angle augmente.
5. $\cos 25^\circ > \cos 65^\circ$
6. Environ $26^\circ$ ; impossible pour $1{,}2$.

=== Découverte - Vrai ou faux sur le cosinus
Id: 3656
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dire si chaque affirmation est vraie ou fausse, en justifiant. La figure montre deux triangles rectangles : $DEF$ est un agrandissement de $ABC$, toutes ses longueurs sont doublées.

[IMAGE_1]

1. « Le cosinus d'un angle aigu peut valoir $1{,}5$. »
2. « Dans un triangle $ABC$ rectangle en $A$, $\cos \widehat{ABC} = \dfrac{AB}{BC}$. »
3. « Un angle aigu de cosinus $0{,}9$ est plus grand qu'un angle aigu de cosinus $0{,}2$. »
4. « Si on double les longueurs d'un triangle rectangle, le cosinus de ses angles double aussi. »
5. « $\cos 60^\circ = 2 \times \cos 30^\circ$. »
6. « Si $\cos \widehat{ABC} = 0{,}5$, alors $\widehat{ABC} = 60^\circ$. »

Étapes:
<!-- optitab:1 -->
## Question 1 : Affirmation 1

::: methode
On revient à la définition (côté adjacent sur hypoténuse) ou on calcule. Un seul contre-exemple suffit à prouver qu'une affirmation est fausse.
:::

::: etape Comparer à $1$
Le côté adjacent est plus court que l'hypoténuse, donc le cosinus d'un angle aigu est inférieur à $1$. Or $1{,}5 > 1$.
:::

::: resultat
Faux.
:::

## Question 2 : Affirmation 2

::: etape Nommer les côtés
L'angle droit est en $A$ : l'hypoténuse est $[BC]$ et le côté adjacent à $\widehat{ABC}$ est $[AB]$.
:::

::: resultat
Vrai.
:::

## Question 3 : Affirmation 3

::: etape Calculer les deux angles
$\cos^{-1}(0{,}9) \approx 25{,}8^\circ$ et $\cos^{-1}(0{,}2) \approx 78{,}5^\circ$.
:::

::: resultat
Faux : c'est le contraire, le plus grand cosinus correspond au plus petit angle.
:::

## Question 4 : Affirmation 4

::: etape Calculer sur la figure
Dans $ABC$ : $\cos \widehat{ABC} = \dfrac{4}{5} = 0{,}8$. Dans $DEF$ : $\cos \widehat{DEF} = \dfrac{8}{10} = 0{,}8$.
:::

[IMAGE_2]

::: resultat
Faux : le numérateur et le dénominateur doublent tous les deux, le quotient ne change pas. Le cosinus ne dépend que de l'angle.
:::

::: retenir
Agrandir ou réduire un triangle conserve ses angles, donc leurs cosinus.
:::

## Question 5 : Affirmation 5

::: etape Calculer les deux membres
$\cos 60^\circ = 0{,}5$ et $2 \times \cos 30^\circ \approx 2 \times 0{,}866 = 1{,}732$.
:::

::: resultat
Faux : le cosinus n'est pas proportionnel à l'angle.
:::

::: attention Erreur fréquente
Croire que doubler l'angle double le cosinus : quand l'angle augmente, le cosinus diminue.
:::

## Question 6 : Affirmation 6

::: etape Touche $\cos^{-1}$
$\cos^{-1}(0{,}5) = 60$ (en mode degrés).
:::

::: resultat
Vrai.
:::

Solution:
<!-- optitab:1 -->
1. Faux : un cosinus d'angle aigu est inférieur à $1$.
2. Vrai.
3. Faux : $25{,}8^\circ < 78{,}5^\circ$.
4. Faux : $\dfrac{4}{5} = \dfrac{8}{10} = 0{,}8$.
5. Faux : $0{,}5 \neq 1{,}732$.
6. Vrai.

=== Entraînement - L'échelle contre le mur
Id: 3657
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Une échelle $[AB]$ de $5$ m est appuyée contre un mur vertical ; le sol est horizontal. Elle fait avec le sol un angle $\widehat{BAC} = 70^\circ$. Pour être stable et sûre, une échelle doit faire avec le sol un angle compris entre $65^\circ$ et $75^\circ$.

[IMAGE_1]

1. Pourquoi le triangle $ABC$ est-il rectangle ? Quelle est son hypoténuse ?
2. Calculer la distance $AC$ entre le pied de l'échelle et le mur, au centimètre près.
3. Calculer la hauteur $BC$ atteinte par l'échelle, au centimètre près.
4. On place le pied de l'échelle à $2$ m du mur. Quel angle fait-elle avec le sol, au degré près ? Est-elle sûre ?
5. On place le pied à $1$ m du mur. L'échelle est-elle sûre ?
6. Entre quelles distances du mur faut-il placer le pied de l'échelle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle rectangle

::: etape Le mur et le sol
Le mur est vertical et le sol horizontal : les droites $(BC)$ et $(AC)$ sont perpendiculaires.
:::

::: resultat
$ABC$ est rectangle en $C$ ; son hypoténuse est l'échelle $[AB]$.
:::

## Question 2 : La distance $AC$

::: methode
$[AC]$ est le côté adjacent à l'angle $\widehat{BAC}$ et l'hypoténuse est connue : on multiplie l'hypoténuse par le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{BAC} &= \frac{AC}{AB} \\
\cos 70^\circ &= \frac{AC}{5} \\
AC &= 5 \times \cos 70^\circ \approx 1{,}710
\end{aligned}
$$
:::

::: resultat
Le pied de l'échelle est à environ $1{,}71$ m du mur.
:::

## Question 3 : La hauteur $BC$

::: etape Théorème de Pythagore dans $ABC$ rectangle en $C$
$$
\begin{aligned}
BC^2 &= AB^2 - AC^2 \\
&= 25 - (5 \times \cos 70^\circ)^2 \approx 22{,}08
\end{aligned}
$$
:::

::: etape Racine carrée
$BC \approx \sqrt{22{,}08} \approx 4{,}698$.
:::

[IMAGE_2]

::: resultat
L'échelle atteint environ $4{,}70$ m de hauteur.
:::

## Question 4 : Pied à $2$ m du mur

::: etape Calculer l'angle
$$
\begin{aligned}
\cos \widehat{BAC} &= \frac{2}{5} = 0{,}4 \\
\widehat{BAC} &= \cos^{-1}(0{,}4) \approx 66{,}4^\circ
\end{aligned}
$$
:::

::: resultat
L'angle mesure environ $66^\circ$, entre $65^\circ$ et $75^\circ$ : l'échelle est sûre.
:::

## Question 5 : Pied à $1$ m du mur

::: etape Calculer l'angle
$\cos \widehat{BAC} = \dfrac{1}{5} = 0{,}2$, donc $\widehat{BAC} = \cos^{-1}(0{,}2) \approx 78{,}5^\circ$.
:::

::: resultat
L'angle mesure environ $78^\circ$, plus que $75^\circ$ : l'échelle est trop redressée, elle n'est pas sûre (elle risque de basculer en arrière).
:::

## Question 6 : Les distances limites

::: etape Pour un angle de $75^\circ$
$5 \times \cos 75^\circ \approx 1{,}294$ m.
:::

::: etape Pour un angle de $65^\circ$
$5 \times \cos 65^\circ \approx 2{,}113$ m.
:::

::: etape Arrondir du côté sûr
L'angle diminue quand le pied s'éloigne du mur. À $1{,}29$ m, l'angle dépasserait légèrement $75^\circ$ : on arrondit vers l'intérieur de l'intervalle.
:::

::: resultat
Le pied de l'échelle doit être placé entre environ $1{,}30$ m et $2{,}11$ m du mur.
:::

::: attention Erreur fréquente
Prendre la hauteur sur le mur comme côté adjacent : le côté adjacent à l'angle au sol est la distance au mur, le long du sol.
:::

Solution:
<!-- optitab:1 -->
1. Le mur est perpendiculaire au sol : $ABC$ est rectangle en $C$ ; hypoténuse $[AB]$.
2. $AC = 5 \times \cos 70^\circ \approx 1{,}71$ m
3. $BC \approx 4{,}70$ m
4. Environ $66^\circ$ : sûre.
5. Environ $78^\circ$ : pas sûre.
6. Entre environ $1{,}30$ m et $2{,}11$ m.

Énoncé:
<!-- optitab:1 -->

$HK \approx 32{,}1$ m.

[IMAGE_2]

Le cerf-volant vole à environ $33{,}1$ m au-dessus du sol.

\end{aligned}

:::

::: resultat
La ficelle fait un angle d'environ $51{,}3^\circ$ avec l'horizontale.
:::

Solution:
<!-- optitab:1 -->

=== Entraînement - Les angles d'un triangle isocèle
Id: 3659
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est isocèle en $A$ avec $AB = AC = 10$ cm et $BC = 12$ cm. Le point $H$ est le milieu de $[BC]$.

[IMAGE_1]

1. Pourquoi le triangle $ABH$ est-il rectangle en $H$ ? Calculer $BH$.
2. Calculer $\cos \widehat{ABC}$.
3. En déduire la mesure de $\widehat{ABC}$ au dixième de degré.
4. Quelle est la mesure de $\widehat{ACB}$ ? Justifier.
5. Calculer la mesure de $\widehat{BAC}$ au dixième de degré.
6. Un autre triangle $ABC$ est isocèle en $A$ avec $AB = AC = 10$ cm et $\widehat{ABC} = 70^\circ$. Calculer $BC$ au millimètre près.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle $ABH$

::: etape La médiane d'un triangle isocèle
$A$ est équidistant de $B$ et de $C$ : il est sur la médiatrice de $[BC]$. Cette médiatrice passe par le milieu $H$ de $[BC]$ : c'est la droite $(AH)$, perpendiculaire à $(BC)$.
:::

::: etape La longueur $BH$
$H$ est le milieu de $[BC]$ : $BH = 12 \div 2 = 6$.
:::

::: resultat
$ABH$ est rectangle en $H$ et $BH = 6$ cm.
:::

## Question 2 : Le cosinus de $\widehat{ABC}$

::: methode
On calcule le cosinus dans le triangle **rectangle** $ABH$ : hypoténuse $[AB]$, côté adjacent à $\widehat{ABH}$ : $[BH]$.
:::

::: etape Calcul
$$\cos \widehat{ABC} = \frac{BH}{AB} = \frac{6}{10} = 0{,}6$$
:::

::: resultat
$\cos \widehat{ABC} = 0{,}6$.
:::

::: attention Erreur fréquente
Écrire $\cos \widehat{ABC} = \dfrac{12}{10}$ : $ABC$ n'est pas rectangle, on travaille dans $ABH$ avec $BH = 6$ cm (et $\dfrac{12}{10} > 1$ est impossible pour un cosinus).
:::

## Question 3 : L'angle $\widehat{ABC}$

::: etape À la calculatrice
$\cos^{-1}(0{,}6) \approx 53{,}13$
:::

[IMAGE_2]

::: resultat
$\widehat{ABC} \approx 53{,}1^\circ$.
:::

## Question 4 : L'angle $\widehat{ACB}$

::: etape Propriété du triangle isocèle
Dans un triangle isocèle, les deux angles à la base sont égaux.
:::

::: resultat
$\widehat{ACB} = \widehat{ABC} \approx 53{,}1^\circ$.
:::

## Question 5 : L'angle $\widehat{BAC}$

::: etape Somme des angles du triangle
$$\widehat{BAC} = 180^\circ - 2 \times 53{,}13^\circ \approx 73{,}74^\circ$$
:::

::: resultat
$\widehat{BAC} \approx 73{,}7^\circ$.
:::

## Question 6 : Un autre triangle isocèle

::: etape Dans le triangle rectangle $ABH$
On cherche le côté adjacent $[BH]$, l'hypoténuse $AB = 10$ cm est connue :
$$BH = 10 \times \cos 70^\circ \approx 3{,}420$$
:::

::: etape La base
$H$ est le milieu de $[BC]$ : $BC = 2 \times BH \approx 6{,}840$.
:::

::: resultat
$BC \approx 6{,}8$ cm.
:::

::: retenir
Dans un triangle isocèle, on trace la hauteur issue du sommet principal : elle partage le triangle en deux triangles rectangles où l'on peut utiliser le cosinus.
:::

Solution:
<!-- optitab:1 -->
1. $(AH)$ est la médiatrice de $[BC]$ ; $BH = 6$ cm.
2. $\cos \widehat{ABC} = 0{,}6$
3. $\widehat{ABC} \approx 53{,}1^\circ$
4. $\widehat{ACB} \approx 53{,}1^\circ$ (angles à la base égaux).
5. $\widehat{BAC} \approx 73{,}7^\circ$
6. $BC \approx 6{,}8$ cm

=== Entraînement - L'angle de la diagonale d'un rectangle
Id: 3660
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
$ABCD$ est un rectangle avec $AB = 8$ cm et $BC = 6$ cm. Ses diagonales se coupent en $O$.

[IMAGE_1]

1. Calculer la longueur de la diagonale $AC$.

&= 64 + 36 = 100
\end{aligned}
$$
:::

::: resultat
$AC = \sqrt{100} = 10$ cm.
:::

## Question 2 : Le cosinus

::: etape Nommer les côtés
Dans $ABC$ rectangle en $B$, l'hypoténuse est $[AC]$ et le côté adjacent à $\widehat{BAC}$ est $[AB]$.

::: resultat

## Question 3 : L'angle $\widehat{BAC}$

:::

$\widehat{BAC} \approx 36{,}9^\circ$.

:::

::: resultat
$\widehat{ACB} \approx 53{,}1^\circ$.

Les diagonales d'un rectangle ont la même longueur et se coupent en leur milieu : $OA = OB = 10 \div 2 = 5$ cm, donc le triangle $AOB$ est isocèle en $O$.

$\widehat{OBA} = \widehat{OAB} = \widehat{BAC} \approx 36{,}87^\circ$.

[IMAGE_2]

$\widehat{AOB} \approx 106{,}3^\circ$.

::: attention Erreur fréquente

:::

Solution:
<!-- optitab:1 -->
1. $AC = 10$ cm
2. $\cos \widehat{BAC} = 0{,}8$
3. $\widehat{BAC} \approx 36{,}9^\circ$
4. $\widehat{ACB} \approx 53{,}1^\circ$

=== Entraînement - Une hauteur partage le triangle

Énoncé:

$$
\begin{aligned}
\cos \widehat{ABH} &= \frac{BH}{AB} \\

\end{aligned}
$$
:::

::: resultat
$BH \approx 7{,}66$ cm.
:::

## Question 2 : La longueur $AH$

::: etape Théorème de Pythagore dans $ABH$
$AH^2 = AB^2 - BH^2 \approx 100 - 58{,}68 = 41{,}32$, donc $AH \approx 6{,}428$.

$AH \approx 6{,}43$ cm.

$HC \approx 4{,}76$ cm.

$$\cos \widehat{ACB} = \frac{HC}{AC} \approx \frac{4{,}763}{8} \approx 0{,}5953$$

[IMAGE_2]

::: resultat
$\widehat{ACB} \approx 53{,}5^\circ$.

## Question 5 : La longueur $BC$

$BC = BH + HC \approx 7{,}660 + 4{,}763 = 12{,}423$.
:::

::: resultat
$BC \approx 12{,}4$ cm.

:::

::: resultat
Non : $\widehat{BAC} \approx 86{,}5^\circ$, ce n'est pas un angle droit.

::: attention Erreur fréquente
Écrire $\cos \widehat{ABC} = \dfrac{AB}{BC}$ dans le triangle $ABC$ : il n'est pas rectangle. On passe par les triangles rectangles $ABH$ et $AHC$.

Solution:
<!-- optitab:1 -->
1. $BH = 10 \times \cos 40^\circ \approx 7{,}66$ cm
2. $AH \approx 6{,}43$ cm

=== Entraînement - Trouver et corriger les erreurs

Énoncé:

<!-- optitab:1 -->
## Question 1 : L'erreur de Noé

Pour contrôler un calcul de cosinus, on vérifie que l'hypoténuse est au dénominateur, que le cosinus est entre $0$ et $1$ et que la calculatrice est en mode degrés.
:::

::: etape Repérer l'hypoténuse

$$\cos \widehat{SRT} = \frac{RS}{RT} = \frac{5}{13}$$

## Question 2 : L'angle $\widehat{SRT}$

$\cos^{-1}\left(\dfrac{5}{13}\right) \approx 67{,}38$
:::

::: resultat
$\widehat{SRT} \approx 67{,}4^\circ$.
:::

## Question 3 : Le résultat d'Inès

::: etape Un résultat invraisemblable
Sur la figure, l'angle en $R$ est grand (plus de $45^\circ$) : $1{,}176$ degré est impossible.
:::

::: resultat
La calculatrice d'Inès était en mode radians : il faut la passer en mode degrés.
:::

::: attention Erreur fréquente
Ne pas vérifier le mode de la calculatrice : c'est l'erreur la plus courante avec les touches $\cos$ et $\cos^{-1}$. Contrôle rapide : $\cos 60^\circ$ doit afficher $0{,}5$.
:::

## Question 4 : L'erreur de Sacha

::: etape Un cosinus supérieur à $1$
$\dfrac{13}{12} > 1$, or le cosinus d'un angle aigu est toujours inférieur à $1$. Sacha a placé l'hypoténuse au numérateur.
:::

::: etape Le bon quotient
Le côté adjacent à $\widehat{STR}$ est $[ST]$, l'hypoténuse est $[RT]$.
:::

::: resultat
$$\cos \widehat{STR} = \frac{ST}{RT} = \frac{12}{13}$$
:::

## Question 5 : L'angle $\widehat{STR}$

::: etape À la calculatrice
$\cos^{-1}\left(\dfrac{12}{13}\right) \approx 22{,}62$
:::

[IMAGE_2]

::: resultat
$\widehat{STR} \approx 22{,}6^\circ$.
:::

## Question 6 : La vérification

::: etape Somme des angles aigus
$67{,}38^\circ + 22{,}62^\circ = 90^\circ$.
:::

::: resultat
Les deux angles aigus sont bien complémentaires : les résultats sont cohérents.
:::

::: retenir
Trois contrôles rapides : le cosinus est entre $0$ et $1$, la calculatrice est en mode degrés, les deux angles aigus ont pour somme $90^\circ$.
:::

Solution:
<!-- optitab:1 -->
1. Le dénominateur doit être l'hypoténuse : $\cos \widehat{SRT} = \dfrac{5}{13}$.
2. $\widehat{SRT} \approx 67{,}4^\circ$
3. Calculatrice en mode radians.
4. $\dfrac{13}{12} > 1$ impossible ; $\cos \widehat{STR} = \dfrac{12}{13}$.
5. $\widehat{STR} \approx 22{,}6^\circ$
6. $67{,}4^\circ + 22{,}6^\circ = 90^\circ$ : cohérent.

=== Entraînement - Côté adjacent, hypoténuse ou angle
Id: 3663
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Dans chacun des trois triangles rectangles ci-dessous, on cherche une longueur ou un angle.

**Triangle 1.** $MNP$ est rectangle en $N$, $MP = 9$ cm et $\widehat{NMP} = 28^\circ$. On cherche $MN$.

[IMAGE_1]

**Triangle 2.** $RST$ est rectangle en $S$, $RS = 4{,}5$ cm et $\widehat{SRT} = 62^\circ$. On cherche $RT$.

[IMAGE_2]

**Triangle 3.** $UVW$ est rectangle en $V$, $UV = 6{,}3$ cm et $UW = 9$ cm. On cherche $\widehat{VUW}$.

[IMAGE_3]

1. Pour chaque triangle, nommer l'hypoténuse et le côté adjacent à l'angle utilisé, puis dire ce qui est connu et ce qui est cherché.
2. Calculer $MN$ au millimètre près.
3. Calculer $RT$ au millimètre près.
4. Calculer la mesure de $\widehat{VUW}$ au dixième de degré.
5. Dans le triangle 2, calculer $ST$ au millimètre près.
6. Dans le triangle 3, calculer la mesure de $\widehat{UWV}$ au dixième de degré.

Étapes:
<!-- optitab:1 -->
## Question 1 : Repérer les côtés

::: methode
Dans chaque triangle : l'hypoténuse est en face de l'angle droit, le côté adjacent part du sommet de l'angle utilisé.
:::

::: etape Triangle 1 (angle $\widehat{NMP}$)
Hypoténuse $[MP]$, côté adjacent $[MN]$. On connaît l'hypoténuse et l'angle ; on cherche le côté adjacent.
:::

::: etape Triangle 2 (angle $\widehat{SRT}$)
Hypoténuse $[RT]$, côté adjacent $[RS]$. On connaît le côté adjacent et l'angle ; on cherche l'hypoténuse.
:::

::: etape Triangle 3 (angle $\widehat{VUW}$)
Hypoténuse $[UW]$, côté adjacent $[UV]$. On connaît le côté adjacent et l'hypoténuse ; on cherche l'angle.
:::

::: resultat
Triangle 1 : on multiplie par le cosinus ; triangle 2 : on divise par le cosinus ; triangle 3 : on utilise la touche $\cos^{-1}$.
:::

## Question 2 : Calculer $MN$

::: etape Côté adjacent cherché
$$
\begin{aligned}
\cos \widehat{NMP} &= \frac{MN}{MP} \\
\cos 28^\circ &= \frac{MN}{9} \\
MN &= 9 \times \cos 28^\circ \approx 7{,}95
\end{aligned}
$$
:::

[IMAGE_4]

::: resultat
$MN \approx 7{,}9$ cm.
:::

## Question 3 : Calculer $RT$

::: etape Hypoténuse cherchée
$$
\begin{aligned}
\cos \widehat{SRT} &= \frac{RS}{RT} \\
\cos 62^\circ &= \frac{4{,}5}{RT} \\
RT &= \frac{4{,}5}{\cos 62^\circ} \approx 9{,}59
\end{aligned}
$$
:::

::: resultat
$RT \approx 9{,}6$ cm (c'est bien plus long que $RS = 4{,}5$ cm).
:::

::: attention Erreur fréquente
Écrire $RT = 4{,}5 \times \cos 62^\circ \approx 2{,}1$ cm : l'hypoténuse serait plus courte que le côté adjacent, ce qui est impossible.
:::

## Question 4 : Calculer $\widehat{VUW}$

::: etape Angle cherché
$$
\begin{aligned}
\cos \widehat{VUW} &= \frac{UV}{UW} = \frac{6{,}3}{9} = 0{,}7 \\
\widehat{VUW} &= \cos^{-1}(0{,}7) \approx 45{,}57^\circ
\end{aligned}
$$
:::

::: resultat
$\widehat{VUW} \approx 45{,}6^\circ$.
:::

## Question 5 : Calculer $ST$

::: etape Théorème de Pythagore dans $RST$ rectangle en $S$
On garde la valeur non arrondie de $RT$ :
$$
\begin{aligned}
ST^2 &= RT^2 - RS^2 \\
&\approx 91{,}88 - 20{,}25 = 71{,}63
\end{aligned}
$$
donc $ST \approx \sqrt{71{,}63} \approx 8{,}46$.
:::

[IMAGE_5]

::: resultat
$ST \approx 8{,}5$ cm.
:::

## Question 6 : Calculer $\widehat{UWV}$

::: etape Angles aigus complémentaires
$\widehat{UWV} = 90^\circ - 45{,}57^\circ = 44{,}43^\circ$.
:::

[IMAGE_6]

::: resultat
$\widehat{UWV} \approx 44{,}4^\circ$.
:::

::: retenir
Côté adjacent cherché : on multiplie. Hypoténuse cherchée : on divise. Angle cherché : touche $\cos^{-1}$.
:::

Solution:
<!-- optitab:1 -->
1. Triangle 1 : hypoténuse $[MP]$, adjacent $[MN]$ cherché ; triangle 2 : hypoténuse $[RT]$ cherchée, adjacent $[RS]$ ; triangle 3 : hypoténuse $[UW]$ et adjacent $[UV]$ connus, angle cherché.
2. $MN = 9 \times \cos 28^\circ \approx 7{,}9$ cm
3. $RT = \dfrac{4{,}5}{\cos 62^\circ} \approx 9{,}6$ cm
4. $\widehat{VUW} = \cos^{-1}(0{,}7) \approx 45{,}6^\circ$
5. $ST \approx 8{,}5$ cm
6. $\widehat{UWV} \approx 44{,}4^\circ$

=== Problème - Le téléphérique
Id: 3664
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Sur la carte, la gare de départ $D$ et la gare d'arrivée $A$ d'un téléphérique sont distantes de $1\,500$ m à l'horizontale. Le câble rectiligne $[DA]$ fait un angle de $25^\circ$ avec l'horizontale. La gare de départ est à $1\,350$ m d'altitude. Le point $H$ est à l'altitude de $D$, à la verticale de $A$.

[IMAGE_1]

1. Expliquer pourquoi le triangle $DHA$ est rectangle et nommer son hypoténuse.
2. Calculer la longueur du câble $DA$, au mètre près.
3. Calculer le dénivelé $HA$, au mètre près.
4. À quelle altitude se trouve la gare d'arrivée ?
5. La cabine avance à $5$ m/s le long du câble. Combien de temps dure le trajet, à la seconde près ? Donner la réponse en minutes et secondes.
6. Un autre téléphérique a un câble de $2\,000$ m pour un dénivelé de $700$ m. Quel angle son câble fait-il avec l'horizontale, au dixième de degré ? Lequel des deux est le plus pentu ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle rectangle

::: etape Horizontale et verticale
$(DH)$ est horizontale et $(HA)$ est verticale : elles sont perpendiculaires.
:::

::: resultat
Le triangle $DHA$ est rectangle en $H$ ; son hypoténuse est le câble $[DA]$.
:::

## Question 2 : La longueur du câble

::: methode
On connaît le côté adjacent $[DH]$ à l'angle de $25^\circ$ et on cherche l'hypoténuse : on divise par le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{HDA} &= \frac{DH}{DA} \\
\cos 25^\circ &= \frac{1\,500}{DA} \\
DA &= \frac{1\,500}{\cos 25^\circ} \approx 1\,655{,}07
\end{aligned}
$$
:::

::: resultat
Le câble mesure environ $1\,655$ m.
:::

::: attention Erreur fréquente
Calculer $1\,500 \times \cos 25^\circ \approx 1\,359$ m : le câble serait plus court que la distance horizontale, ce qui est impossible.
:::

## Question 3 : Le dénivelé

::: etape Théorème de Pythagore dans $DHA$ rectangle en $H$
$$
\begin{aligned}
HA^2 &= DA^2 - DH^2 \\
&\approx 2\,739\,246 - 2\,250\,000 = 489\,246
\end{aligned}
$$
:::

::: etape Racine carrée
$HA \approx \sqrt{489\,246} \approx 699{,}46$.
:::

::: resultat
Le dénivelé est d'environ $699$ m.
:::

## Question 4 : L'altitude d'arrivée

::: etape Ajouter le dénivelé à l'altitude de départ
$1\,350 + 699{,}46 = 2\,049{,}46$.
:::

[IMAGE_2]

::: resultat
La gare d'arrivée est à environ $2\,049$ m d'altitude.
:::

## Question 5 : La durée du trajet

::: etape La cabine parcourt le câble
$t = \dfrac{1\,655{,}07}{5} \approx 331$ s.
:::

::: etape Convertir
$331 = 5 \times 60 + 31$.
:::

::: resultat
Le trajet dure environ $331$ s, soit $5$ min $31$ s.
:::

## Question 6 : Le second téléphérique

::: etape La distance horizontale (Pythagore)
$d = \sqrt{2\,000^2 - 700^2} = \sqrt{3\,510\,000} \approx 1\,873{,}5$ m.
:::

::: etape L'angle
$$
\begin{aligned}
\cos \alpha &= \frac{d}{2\,000} \approx 0{,}9367 \\
\alpha &\approx 20{,}5^\circ
\end{aligned}
$$
:::

::: resultat
Le second câble fait un angle d'environ $20{,}5^\circ$ avec l'horizontale : le premier téléphérique ($25^\circ$) est le plus pentu.
:::

::: retenir
Le cosinus et le théorème de Pythagore se complètent : le cosinus relie un angle à deux côtés, Pythagore donne le troisième côté.
:::

Solution:
<!-- optitab:1 -->
1. $(DH)$ horizontale, $(HA)$ verticale : rectangle en $H$ ; hypoténuse $[DA]$.
2. $DA = \dfrac{1\,500}{\cos 25^\circ} \approx 1\,655$ m
3. $HA \approx 699$ m
4. Environ $2\,049$ m
5. Environ $331$ s, soit $5$ min $31$ s.
6. Environ $20{,}5^\circ$ : le premier est le plus pentu.

=== Problème - Une rampe de chargement
Id: 3665
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour charger un camion de déménagement, on pose une rampe $[AP]$ entre le sol et le plateau du camion. Le sol est horizontal et le point $H$ est au sol, à la verticale du bord $P$ du plateau. Pour pousser un chariot chargé sans danger, la rampe doit faire avec le sol un angle $\alpha$ d'au plus $20^\circ$.

[IMAGE_1]

1. Expliquer pourquoi le triangle $AHP$ est rectangle. Nommer son hypoténuse et le côté adjacent à l'angle $\alpha$.
2. Le plateau du premier camion est à $1$ m du sol et la rampe mesure $3$ m. Calculer $AH$ au centimètre près.
3. Calculer l'angle $\alpha$ au dixième de degré. La rampe est-elle utilisable sans danger ?
4. Le plateau d'un second camion est à $1{,}20$ m du sol. Avec la même rampe de $3$ m, la rampe est-elle utilisable sans danger ?
5. Pour le second camion, on prend une rampe de $4$ m. Calculer $AH$ au centimètre près et l'angle $\alpha$ au dixième de degré.
6. Derrière le second camion, il n'y a que $3{,}70$ m de place au sol. Peut-on installer la rampe de $4$ m ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle rectangle

::: etape Verticale et horizontale
$H$ est à la verticale de $P$ et le sol est horizontal : $(PH) \perp (AH)$.
:::

::: resultat
$AHP$ est rectangle en $H$ ; l'hypoténuse est la rampe $[AP]$ ; le côté adjacent à $\alpha$ est $[AH]$, le long du sol.
:::

## Question 2 : La distance au sol $AH$

::: methode
On connaît l'hypoténuse et le côté vertical $[HP]$, mais pas l'angle : on calcule $AH$ avec le théorème de Pythagore.
:::

::: etape Théorème de Pythagore dans $AHP$ rectangle en $H$
$$
\begin{aligned}
AH^2 &= AP^2 - HP^2 \\
&= 9 - 1 = 8
\end{aligned}
$$
:::

::: resultat
$AH = \sqrt{8} \approx 2{,}83$ m.
:::

## Question 3 : L'angle de la rampe

::: etape Le cosinus de $\alpha$
$$\cos \alpha = \frac{AH}{AP} = \frac{\sqrt{8}}{3} \approx 0{,}9428$$
:::

::: etape À la calculatrice
$$\alpha = \cos^{-1}\left(\dfrac{\sqrt{8}}{3}\right) \approx 19{,}47^\circ$$
:::

[IMAGE_2]

::: resultat
$\alpha \approx 19{,}5^\circ \leqslant 20^\circ$ : la rampe est utilisable sans danger.
:::

::: attention Erreur fréquente
Calculer avec $AH$ arrondi à $2{,}8$ m : $\cos^{-1}\left(\dfrac{2{,}8}{3}\right) \approx 21{,}0^\circ$, et on conclurait à tort que la rampe est dangereuse. On garde $\sqrt{8}$ jusqu'au bout.
:::

## Question 4 : Le second camion avec la rampe de $3$ m

::: etape La distance au sol
$AH^2 = 9 - 1{,}2^2 = 9 - 1{,}44 = 7{,}56$, donc $AH = \sqrt{7{,}56} \approx 2{,}750$ m.
:::

::: etape L'angle
$\cos \alpha = \dfrac{\sqrt{7{,}56}}{3} \approx 0{,}9165$, donc $\alpha \approx 23{,}6^\circ$.
:::

::: resultat
$\alpha \approx 23{,}6^\circ > 20^\circ$ : la rampe de $3$ m est trop raide pour le second camion.
:::

## Question 5 : La rampe de $4$ m

::: etape La distance au sol
$AH^2 = 16 - 1{,}44 = 14{,}56$, donc $AH = \sqrt{14{,}56} \approx 3{,}816$.
:::

::: etape L'angle
$\cos \alpha = \dfrac{\sqrt{14{,}56}}{4} \approx 0{,}9539$, donc $\alpha \approx 17{,}5^\circ$.
:::

[IMAGE_3]

::: resultat
$AH \approx 3{,}82$ m et $\alpha \approx 17{,}5^\circ \leqslant 20^\circ$ : cette rampe est utilisable sans danger.
:::

## Question 6 : La place disponible

::: etape Comparer
La rampe de $4$ m occupe environ $3{,}82$ m au sol, or il n'y a que $3{,}70$ m de place : $3{,}82 > 3{,}70$.
:::

::: resultat
Non : la rampe de $4$ m ne peut pas être installée derrière le second camion.
:::

::: retenir
Plus la rampe est longue pour une même hauteur, plus son angle avec le sol est petit, mais plus elle prend de place au sol.
:::

Solution:
<!-- optitab:1 -->
1. $(PH) \perp (AH)$ : rectangle en $H$ ; hypoténuse $[AP]$ ; côté adjacent $[AH]$.
2. $AH = \sqrt{8} \approx 2{,}83$ m
3. $\alpha \approx 19{,}5^\circ$ : sans danger.
4. $\alpha \approx 23{,}6^\circ > 20^\circ$ : trop raide.
5. $AH \approx 3{,}82$ m ; $\alpha \approx 17{,}5^\circ$
6. Non : $3{,}82$ m $> 3{,}70$ m.

=== Problème - La pente d'un toit
Id: 3666
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
La façade d'une maison de $9$ m de large est surmontée d'un toit symétrique $ABC$ dont les chevrons $[AB]$ et $[AC]$ mesurent $5{,}5$ m. Le point $I$ est le milieu de $[BC]$.

[IMAGE_1]

1. Pourquoi le triangle $ABI$ est-il rectangle en $I$ ? Calculer $BI$.
2. Calculer l'angle $\widehat{ABC}$ que fait le toit avec l'horizontale, au dixième de degré.
3. Calculer la hauteur $AI$ du toit, au centimètre près.
4. Une autre maison de $10$ m de large a un toit symétrique incliné à $30^\circ$. Calculer la longueur $\ell$ de ses chevrons, au centimètre près.
5. Calculer la hauteur $h$ de ce second toit, au centimètre près.
6. Ce second toit est long de $12$ m : ses deux pans sont des rectangles de $12$ m sur $\ell$. Calculer leur aire totale, puis le nombre de tuiles nécessaires, à raison de $10$ tuiles par m².

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle $ABI$

::: etape Le triangle $ABC$ est isocèle
$AB = AC$ : le point $A$ est sur la médiatrice de $[BC]$. Cette médiatrice passe par le milieu $I$ : c'est la droite $(AI)$, perpendiculaire à $(BC)$.
:::

::: etape La longueur $BI$
$BI = 9 \div 2 = 4{,}5$.
:::

::: resultat
$ABI$ est rectangle en $I$ et $BI = 4{,}5$ m.
:::

## Question 2 : L'angle du toit

::: etape Le cosinus dans $ABI$
L'hypoténuse est $[AB]$, le côté adjacent à $\widehat{ABI}$ est $[BI]$ :
$$\cos \widehat{ABC} = \frac{BI}{AB} = \frac{4{,}5}{5{,}5} \approx 0{,}8182$$
:::

::: etape À la calculatrice
$$\widehat{ABC} = \cos^{-1}\left(\dfrac{4{,}5}{5{,}5}\right) \approx 35{,}10^\circ$$
:::

::: resultat
$\widehat{ABC} \approx 35{,}1^\circ$.
:::

## Question 3 : La hauteur du toit

::: etape Théorème de Pythagore dans $ABI$
$$
\begin{aligned}
AI^2 &= AB^2 - BI^2 \\
&= 30{,}25 - 20{,}25 = 10
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$AI = \sqrt{10} \approx 3{,}16$ m.
:::

## Question 4 : Les chevrons du second toit

::: methode
La demi-largeur ($10 \div 2 = 5$ m) est le côté adjacent à l'angle de $30^\circ$ ; le chevron est l'hypoténuse : on divise par le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos 30^\circ &= \frac{5}{\ell} \\
\ell &= \frac{5}{\cos 30^\circ} \approx 5{,}774
\end{aligned}
$$
:::

::: resultat
Les chevrons mesurent environ $5{,}77$ m.
:::

::: attention Erreur fréquente
Prendre la largeur entière ($10$ m) comme côté adjacent : le triangle rectangle ne contient que la moitié de la largeur.
:::

## Question 5 : La hauteur du second toit

::: etape Théorème de Pythagore
$h^2 = \ell^2 - 5^2 \approx 33{,}33 - 25 = 8{,}33$, donc $h \approx 2{,}887$.
:::

[IMAGE_3]

::: resultat
$h \approx 2{,}89$ m.
:::

## Question 6 : La surface et les tuiles

::: etape L'aire des deux pans
$2 \times 12 \times \ell \approx 2 \times 12 \times 5{,}774 \approx 138{,}56$ m².
:::

::: etape Le nombre de tuiles
$138{,}56 \times 10 \approx 1\,385{,}6$ : on arrondit à l'unité supérieure.
:::

::: resultat
L'aire totale est d'environ $138{,}6$ m² ; il faut $1\,386$ tuiles.
:::

::: retenir
Pour acheter du matériel, on arrondit toujours au-dessus : $1\,385$ tuiles ne suffiraient pas.
:::

Solution:
<!-- optitab:1 -->
1. $(AI)$ est la médiatrice de $[BC]$ ; $BI = 4{,}5$ m.
2. $\widehat{ABC} \approx 35{,}1^\circ$
3. $AI = \sqrt{10} \approx 3{,}16$ m
4. $\ell = \dfrac{5}{\cos 30^\circ} \approx 5{,}77$ m
5. $h \approx 2{,}89$ m
6. Environ $138{,}6$ m² ; $1\,386$ tuiles.

=== Problème - La route d'un bateau
Id: 3667
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un bateau quitte le port $O$ et parcourt $12$ km en ligne droite, dans une direction qui fait un angle de $40^\circ$ avec la direction du nord, vers l'est. Il arrive en $P$, puis parcourt $5$ km plein est jusqu'en $Q$. Le point $H$ est sur l'axe nord issu de $O$, et la droite $(HP)$ est dirigée vers l'est.

[IMAGE_1]

1. Pourquoi le triangle $OHP$ est-il rectangle en $H$ ? Quelle est son hypoténuse ?
2. Calculer $OH$, la distance parcourue vers le nord, au centième de km.
3. Calculer $HP$, la distance parcourue vers l'est, au centième de km.
4. Calculer la distance $OQ$ entre le bateau et le port, au dixième de km.
5. Quel angle la direction $(OQ)$ fait-elle avec le nord, au dixième de degré ?
6. Le bateau rentre directement au port à $20$ km/h. Combien de temps dure le retour, à la minute près ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle $OHP$

::: etape Les directions nord et est
Les directions nord et est sont perpendiculaires : $(OH) \perp (HP)$.
:::

::: resultat
$OHP$ est rectangle en $H$ ; son hypoténuse est $[OP]$, qui mesure $12$ km.
:::

## Question 2 : La distance vers le nord

::: methode
L'hypoténuse $[OP]$ et l'angle de $40^\circ$ sont connus, on cherche le côté adjacent : on multiplie par le cosinus.
:::

::: etape $[OH]$ est le côté adjacent à l'angle de $40^\circ$
$$
\begin{aligned}
\cos \widehat{HOP} &= \frac{OH}{OP} \\
OH &= 12 \times \cos 40^\circ \approx 9{,}193
\end{aligned}
$$
:::

::: resultat
$OH \approx 9{,}19$ km.
:::

## Question 3 : La distance vers l'est

::: etape Théorème de Pythagore dans $OHP$
$HP^2 = OP^2 - OH^2 \approx 144 - 84{,}50 = 59{,}50$, donc $HP \approx 7{,}713$.
:::

::: resultat
$HP \approx 7{,}71$ km.
:::

## Question 4 : La distance $OQ$

::: etape Le triangle $OHQ$
$Q$ est sur la droite $(HP)$, plus à l'est : $HQ = HP + PQ \approx 7{,}713 + 5 = 12{,}713$ km, et $OHQ$ est rectangle en $H$.
:::

::: etape Théorème de Pythagore dans $OHQ$
$OQ^2 = OH^2 + HQ^2 \approx 84{,}50 + 161{,}63 = 246{,}13$, donc $OQ \approx 15{,}689$.
:::

[IMAGE_2]

::: resultat
$OQ \approx 15{,}7$ km.
:::

## Question 5 : L'angle avec le nord

::: etape Le cosinus dans $OHQ$
L'hypoténuse est $[OQ]$ et le côté adjacent à $\widehat{HOQ}$ est $[OH]$ :
$$\cos \widehat{HOQ} = \frac{OH}{OQ} \approx \frac{9{,}193}{15{,}689} \approx 0{,}5859$$
:::

::: etape À la calculatrice
$\widehat{HOQ} \approx 54{,}13^\circ$.
:::

::: resultat
La direction $(OQ)$ fait un angle d'environ $54{,}1^\circ$ avec le nord.
:::

::: attention Erreur fréquente
Additionner les angles ou les distances « en ligne droite » ($12 + 5 = 17$ km) : le bateau a changé de direction, il faut passer par le triangle rectangle $OHQ$.
:::

## Question 6 : La durée du retour

::: etape Durée $=$ distance $\div$ vitesse
$t = \dfrac{15{,}689}{20} \approx 0{,}7844$ h.
:::

::: etape Convertir en minutes
$0{,}7844 \times 60 \approx 47{,}1$ min.
:::

::: resultat
Le retour dure environ $47$ minutes.
:::

::: retenir
En navigation, on décompose un trajet selon le nord et l'est : chaque morceau est un côté d'un triangle rectangle.
:::

Solution:
<!-- optitab:1 -->
1. Nord et est sont perpendiculaires : rectangle en $H$ ; hypoténuse $[OP]$.
2. $OH = 12 \times \cos 40^\circ \approx 9{,}19$ km
3. $HP \approx 7{,}71$ km
4. $OQ \approx 15{,}7$ km
5. Environ $54{,}1^\circ$
6. Environ $47$ min

=== Problème - Le pendule
Id: 3668
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un pendule est formé d'un fil $[OB]$ de $1{,}2$ m accroché en $O$. Au repos, la boule est en $B_0$, à la verticale de $O$. On écarte le fil d'un angle de $30^\circ$ : la boule est en $B$, et $H$ est le point de $[OB_0]$ à la même hauteur que $B$.

[IMAGE_1]

1. Calculer $OH$ au centième de mètre.
2. De combien de centimètres la boule est-elle montée ? (distance $HB_0$, au centimètre près)
3. Calculer l'écart horizontal $HB$.
4. On écarte le fil de $60^\circ$. De combien la boule monte-t-elle ?
5. De quel angle faut-il écarter le fil pour que la boule monte de $30$ cm ? (au dixième de degré)
6. Expliquer pourquoi, tant que l'angle reste aigu, la boule monte toujours de moins de $1{,}2$ m.

Étapes:
<!-- optitab:1 -->
## Question 1 : La longueur $OH$

::: methode
On travaille dans le triangle rectangle $OHB$ : le fil est l'hypoténuse et $[OH]$ le côté adjacent à l'angle d'écart, donc $OH = OB \times \cos(\text{angle})$.
:::

::: etape Le triangle rectangle
$H$ est à la même hauteur que $B$ sur la verticale $(OB_0)$ : $OHB$ est rectangle en $H$, d'hypoténuse le fil $[OB]$. Le côté adjacent à l'angle de $30^\circ$ est $[OH]$.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{HOB} &= \frac{OH}{OB} \\
OH &= 1{,}2 \times \cos 30^\circ \approx 1{,}039
\end{aligned}
$$
:::

::: resultat
$OH \approx 1{,}04$ m.
:::

## Question 2 : La montée

::: etape Différence de longueurs sur la verticale
$HB_0 = OB_0 - OH \approx 1{,}2 - 1{,}039 = 0{,}161$ m.
:::

::: resultat
La boule est montée d'environ $16$ cm.
:::

::: attention Erreur fréquente
Répondre $1{,}04$ m : $OH$ est la distance au point d'accroche, pas la hauteur gagnée par la boule.
:::

## Question 3 : L'écart horizontal

::: etape Théorème de Pythagore dans $OHB$
$$
\begin{aligned}
HB^2 &= OB^2 - OH^2 \\
&= 1{,}44 - 1{,}08 = 0{,}36
\end{aligned}
$$
(en effet $OH^2 = 1{,}44 \times (\cos 30^\circ)^2 = 1{,}08$ exactement.)
:::

[IMAGE_2]

::: resultat
$HB = \sqrt{0{,}36} = 0{,}6$ m.
:::

## Question 4 : Avec $60^\circ$

::: etape Calcul
$OH = 1{,}2 \times \cos 60^\circ = 1{,}2 \times 0{,}5 = 0{,}6$ m, donc la montée vaut $1{,}2 - 0{,}6 = 0{,}6$ m.
:::

::: resultat
La boule monte de $60$ cm.
:::

## Question 5 : Pour monter de $30$ cm

::: etape La longueur $OH$ nécessaire
$OH = 1{,}2 - 0{,}3 = 0{,}9$ m.
:::

::: etape L'angle
$$
\begin{aligned}
\cos \alpha &= \frac{0{,}9}{1{,}2} = 0{,}75 \\
\alpha &= \cos^{-1}(0{,}75) \approx 41{,}41^\circ
\end{aligned}
$$
:::

::: resultat
Il faut écarter le fil d'environ $41{,}4^\circ$.
:::

## Question 6 : La limite

::: etape Un cosinus positif
Pour un angle aigu, $\cos \alpha > 0$, donc $OH = 1{,}2 \times \cos \alpha > 0$.
:::

::: resultat
La montée $1{,}2 - OH$ est donc toujours inférieure à $1{,}2$ m. Elle n'atteindrait $1{,}2$ m que pour un fil horizontal (angle de $90^\circ$).
:::

::: retenir
Le cosinus permet de passer d'un angle à une distance verticale : c'est un outil de base pour étudier les pendules en physique.
:::

Solution:
<!-- optitab:1 -->
1. $OH = 1{,}2 \times \cos 30^\circ \approx 1{,}04$ m
2. Environ $16$ cm
3. $HB = 0{,}6$ m
4. $60$ cm
5. Environ $41{,}4^\circ$
6. $OH > 0$ tant que l'angle est aigu, donc la montée $1{,}2 - OH$ est inférieure à $1{,}2$ m.

=== Type brevet - Le toboggan d'une aire de jeux
Id: 3669
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une commune installe un toboggan sur une aire de jeux. L'échelle $[HS]$ est verticale, le sol est horizontal et la glissière $[AS]$ est rectiligne. Le fabricant indique :

- longueur de la glissière : $AS = 4{,}5$ m ;
- angle de la glissière avec le sol : $\widehat{SAH} = 32^\circ$ ;
- pente conseillée : un angle compris entre $30^\circ$ et $40^\circ$ ;
- une zone libre de $2$ m doit être laissée au sol devant le bas $A$ de la glissière.

[IMAGE_1]

**Partie A : les dimensions du toboggan**

1. Justifier que le triangle $AHS$ est rectangle et nommer son hypoténuse.
2. Montrer que la distance au sol $AH$ est environ égale à $3{,}82$ m.
3. Calculer la hauteur $HS$ de la plateforme, au centimètre près.

**Partie B : l'emplacement**

4. L'emplacement prévu mesure $7$ m de long, du pied $H$ de l'échelle jusqu'à la clôture. La zone libre comprise, le toboggan tient-il ?

**Partie C : un second modèle**

5. Un second modèle a une plateforme à $2{,}1$ m de hauteur et occupe $3{,}5$ m au sol (distance $AH$). Calculer la longueur de sa glissière au centimètre près.
6. Calculer l'angle de sa glissière avec le sol, au dixième de degré. Respecte-t-il la pente conseillée ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle rectangle

::: etape Verticale et horizontale
L'échelle $[HS]$ est verticale et le sol est horizontal : $(HS) \perp (AH)$.
:::

::: resultat
Le triangle $AHS$ est rectangle en $H$ ; son hypoténuse est la glissière $[AS]$.
:::

## Question 2 : La distance au sol

::: methode
$[AH]$ est le côté adjacent à l'angle de $32^\circ$ et l'hypoténuse est connue : on multiplie par le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{SAH} &= \frac{AH}{AS} \\
\cos 32^\circ &= \frac{AH}{4{,}5} \\
AH &= 4{,}5 \times \cos 32^\circ \approx 3{,}816
\end{aligned}
$$
:::

::: resultat
$AH \approx 3{,}82$ m.
:::

## Question 3 : La hauteur de la plateforme

::: etape Théorème de Pythagore dans $AHS$ rectangle en $H$
$$
\begin{aligned}
HS^2 &= AS^2 - AH^2 \\
&\approx 20{,}25 - 14{,}564 = 5{,}686
\end{aligned}
$$
:::

::: etape Racine carrée
$HS \approx \sqrt{5{,}686} \approx 2{,}385$.
:::

[IMAGE_2]

::: resultat
La plateforme est à environ $2{,}38$ m de hauteur.
:::

::: attention Erreur fréquente
Écrire $HS = 4{,}5 \times \cos 32^\circ$ : le cosinus donne le côté **adjacent** à l'angle de $32^\circ$, c'est-à-dire la distance au sol $AH$, pas la hauteur $HS$. La hauteur s'obtient ici avec le théorème de Pythagore.
:::

## Question 4 : L'emplacement

::: etape Longueur nécessaire au sol
Du pied $H$ de l'échelle à l'extrémité de la zone libre : $AH + 2 \approx 3{,}82 + 2 = 5{,}82$ m.
:::

::: resultat
$5{,}82$ m $< 7$ m : le toboggan tient dans l'emplacement, zone libre comprise.
:::

## Question 5 : La glissière du second modèle

::: etape Théorème de Pythagore dans le triangle rectangle $AHS$
$$
\begin{aligned}
AS^2 &= AH^2 + HS^2 \\
&= 3{,}5^2 + 2{,}1^2 = 12{,}25 + 4{,}41 = 16{,}66
\end{aligned}
$$
:::

::: resultat
$AS = \sqrt{16{,}66} \approx 4{,}08$ m.
:::

## Question 6 : La pente du second modèle

::: etape Le cosinus de l'angle
$$\cos \widehat{SAH} = \frac{AH}{AS} = \frac{3{,}5}{\sqrt{16{,}66}} \approx 0{,}8575$$
:::

::: etape À la calculatrice
$\widehat{SAH} \approx 30{,}96^\circ$.
:::

[IMAGE_3]

::: resultat
L'angle mesure environ $31{,}0^\circ$ : il est compris entre $30^\circ$ et $40^\circ$, le second modèle respecte la pente conseillée.
:::

::: retenir
Dans un problème de type brevet, on justifie d'abord l'angle droit, on nomme l'hypoténuse, puis on choisit l'outil : cosinus (un angle en jeu) ou Pythagore (trois longueurs en jeu).
:::

Solution:
<!-- optitab:1 -->
1. $(HS) \perp (AH)$ : rectangle en $H$ ; hypoténuse $[AS]$.
2. $AH = 4{,}5 \times \cos 32^\circ \approx 3{,}82$ m
3. $HS \approx 2{,}38$ m
4. $5{,}82$ m $< 7$ m : le toboggan tient.
5. $AS = \sqrt{16{,}66} \approx 4{,}08$ m
6. Environ $31{,}0^\circ$ : pente conseillée respectée.

=== Type brevet - Réciproque de Pythagore et cosinus
Id: 3670
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère le triangle $ABC$ tel que $AB = 9$ cm, $AC = 12$ cm et $BC = 15$ cm. Le point $H$ est le pied de la hauteur issue de $A$. La figure n'est pas en vraie grandeur.

[IMAGE_1]

**Partie A : le triangle $ABC$**

1. Démontrer que le triangle $ABC$ est rectangle en $A$.
2. Calculer $\cos \widehat{ABC}$, puis la mesure de $\widehat{ABC}$ au degré près.
3. En déduire la mesure de $\widehat{ACB}$ au degré près.

**Partie B : la hauteur $[AH]$**

4. Dans le triangle $ABH$ rectangle en $H$, calculer la longueur $BH$.
5. Calculer la hauteur $AH$.
6. Calculer l'aire du triangle $ABC$ de deux façons différentes et vérifier que l'on obtient le même résultat.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle $ABC$ est rectangle

::: methode
On utilise la réciproque du théorème de Pythagore : on compare le carré du plus grand côté à la somme des carrés des deux autres.
:::

::: etape Le plus grand côté
$BC^2 = 15^2 = 225$.
:::

::: etape Les deux autres côtés
$AB^2 + AC^2 = 9^2 + 12^2 = 81 + 144 = 225$.
:::

::: resultat
$BC^2 = AB^2 + AC^2$ : d'après la réciproque du théorème de Pythagore, le triangle $ABC$ est rectangle en $A$.
:::

## Question 2 : L'angle $\widehat{ABC}$

::: etape Nommer les côtés
L'hypoténuse est $[BC]$ ; le côté adjacent à $\widehat{ABC}$ est $[AB]$.
:::

::: etape Le cosinus
$$\cos \widehat{ABC} = \frac{AB}{BC} = \frac{9}{15} = 0{,}6$$
:::

::: etape À la calculatrice
$\widehat{ABC} = \cos^{-1}(0{,}6) \approx 53{,}13^\circ$.
:::

::: resultat
$\cos \widehat{ABC} = 0{,}6$ et $\widehat{ABC} \approx 53^\circ$.
:::

## Question 3 : L'angle $\widehat{ACB}$

::: etape Angles aigus complémentaires
$\widehat{ACB} = 90^\circ - 53{,}13^\circ = 36{,}87^\circ$.
:::

::: resultat
$\widehat{ACB} \approx 37^\circ$.
:::

## Question 4 : La longueur $BH$

::: methode
Le même angle $\widehat{ABC}$ est aussi un angle du triangle rectangle $ABH$ : son cosinus vaut encore $0{,}6$. Dans $ABH$, l'hypoténuse est $[AB]$ et le côté adjacent est $[BH]$.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{ABH} &= \frac{BH}{AB} \\
0{,}6 &= \frac{BH}{9} \\
BH &= 9 \times 0{,}6 = 5{,}4
\end{aligned}
$$
:::

::: resultat
$BH = 5{,}4$ cm.
:::

::: attention Erreur fréquente
Utiliser l'angle arrondi $53^\circ$ : $9 \times \cos 53^\circ \approx 5{,}42$ au lieu de la valeur exacte $5{,}4$. Ici, on connaît le cosinus exact $0{,}6$ : on s'en sert directement.
:::

## Question 5 : La hauteur $AH$

::: etape Théorème de Pythagore dans $ABH$
$$
\begin{aligned}
AH^2 &= AB^2 - BH^2 \\
&= 81 - 29{,}16 = 51{,}84
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$AH = \sqrt{51{,}84} = 7{,}2$ cm.
:::

## Question 6 : L'aire de deux façons

::: etape Avec la base $[AB]$ et la hauteur $[AC]$ (angle droit en $A$)
$$\mathcal{A} = \frac{AB \times AC}{2} = \frac{9 \times 12}{2} = 54$$
:::

::: etape Avec la base $[BC]$ et la hauteur $[AH]$
$$\mathcal{A} = \frac{BC \times AH}{2} = \frac{15 \times 7{,}2}{2} = 54$$
:::

::: resultat
Les deux calculs donnent une aire de $54$ cm².
:::

::: retenir
Dans un triangle rectangle, la hauteur issue de l'angle droit crée deux nouveaux triangles rectangles qui ont chacun un angle aigu en commun avec le grand triangle : on peut y réutiliser le même cosinus.
:::

Solution:
<!-- optitab:1 -->
1. $BC^2 = 225 = AB^2 + AC^2$ : rectangle en $A$ (réciproque de Pythagore).
2. $\cos \widehat{ABC} = 0{,}6$ ; $\widehat{ABC} \approx 53^\circ$
3. $\widehat{ACB} \approx 37^\circ$
4. $BH = 5{,}4$ cm
5. $AH = 7{,}2$ cm
6. $\dfrac{9 \times 12}{2} = \dfrac{15 \times 7{,}2}{2} = 54$ cm².
