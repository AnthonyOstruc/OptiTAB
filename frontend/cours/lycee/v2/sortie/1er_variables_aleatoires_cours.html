I. Variable aléatoire et loi

Définition : une variable aléatoire $\displaystyle X$ associe un nombre réel à chaque issue d’une expérience aléatoire. L’événement « $\displaystyle X$ prend la valeur $\displaystyle a$ » est noté $\displaystyle \{X = a\}$.

La loi de probabilité de $\displaystyle X$ donne, pour chaque valeur $\displaystyle x_i$ prise par $\displaystyle X$, la probabilité $\displaystyle p_i = P(X = x_i)$ ; on a $\displaystyle p_1 + p_2 + \cdots + p_n = 1$.

Exemple : on lance un dé équilibré. On gagne $\displaystyle 5$ € si l’on obtient $\displaystyle 6$, $\displaystyle 1$ € pour $\displaystyle 2$ ou $\displaystyle 4$, et on perd $\displaystyle 2$ € sinon. Le gain $\displaystyle X$ suit la loi :

II. Espérance, variance, écart type

Définitions :

• Espérance : $\displaystyle E(X) = p_1x_1 + p_2x_2 + \cdots + p_nx_n$ (valeur moyenne de $\displaystyle X$).

• Variance : $\displaystyle V(X) = p_1(x_1 - E(X))^2 + \cdots + p_n(x_n - E(X))^2$, qui vaut aussi $\displaystyle E(X^2) - E(X)^2$.

• Écart type : $\displaystyle \sigma(X) = \sqrt{V(X)}$ (dispersion des valeurs autour de $\displaystyle E(X)$).

Exemple : $\displaystyle E(X) = \frac{1}{2} \times (-2) + \frac{1}{3} \times 1 + \frac{1}{6} \times 5 = \frac{-6 + 2 + 5}{6} = \frac{1}{6} \approx 0{,}17$ €. Ensuite $\displaystyle E(X^2) = \frac{1}{2} \times 4 + \frac{1}{3} \times 1 + \frac{1}{6} \times 25 = 6{,}5$, donc $\displaystyle V(X) = 6{,}5 - \frac{1}{36} = \frac{233}{36} \approx 6{,}47$ et $\displaystyle \sigma(X) \approx 2{,}54$ €.

💡 Interprétation : sur un grand nombre de parties, le joueur gagne en moyenne environ $\displaystyle 0{,}17$ € par partie. Un jeu est équitable si $\displaystyle E(X) = 0$, favorable au joueur si $\displaystyle E(X) \gt 0$.

III. Transformation affine

Propriétés : pour tous réels $\displaystyle a$ et $\displaystyle b$, $\displaystyle E(aX + b) = aE(X) + b$, $\displaystyle V(aX + b) = a^2V(X)$ et $\displaystyle \sigma(aX + b) = |a|\,\sigma(X)$.

Preuve pour l’espérance : $\displaystyle \sum p_i(ax_i + b) = a\sum p_ix_i + b\sum p_i = aE(X) + b$, puisque $\displaystyle \sum p_i = 1$.

Exemple : si tous les gains sont doublés puis augmentés d’un bonus de $\displaystyle 1$ €, le nouveau gain est $\displaystyle Y = 2X + 1$ : $\displaystyle E(Y) = \frac{2}{6} + 1 = \frac{4}{3}$ et $\displaystyle \sigma(Y) = 2\sigma(X) \approx 5{,}09$.

⚠️ Attention : la constante $\displaystyle b$ ne change pas la dispersion : $\displaystyle V(X + b) = V(X)$. Et le coefficient $\displaystyle a$ est au carré dans la variance.

🏆 L’essentiel : la loi de $\displaystyle X$ donne les $\displaystyle P(X = x_i)$, de somme $\displaystyle 1$ ; $\displaystyle E(X) = \sum p_ix_i$ ; $\displaystyle V(X) = \sum p_i(x_i - E(X))^2 = E(X^2) - E(X)^2$ ; $\displaystyle \sigma(X) = \sqrt{V(X)}$ ; $\displaystyle E(aX + b) = aE(X) + b$ et $\displaystyle V(aX + b) = a^2V(X)$ ; la moyenne observée sur de nombreuses simulations approche $\displaystyle E(X)$.
