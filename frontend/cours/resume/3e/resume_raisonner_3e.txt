===Résumé Raisonner et démontrer 3ème

Images: raisonner_3e_demarche.png

Titre: Résumé : Raisonner et démontrer

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : exemple, conjecture, preuve et contre-exemple ; démonstrations avec des lettres ; rédaction géométrique ; contrôle des résultats ; méthode du brevet. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Prouver ou réfuter</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Des exemples permettent de <strong>conjecturer</strong>, jamais de prouver.</p>
<p style="margin:6px 0 0 0;">• Un <strong>seul contre-exemple</strong> suffit à prouver qu'une affirmation est fausse.</p>
<p style="margin:6px 0 0 0;">• Une <strong>démonstration</strong> prouve qu'une affirmation est vraie dans tous les cas.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Démontrer avec des lettres</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:0 auto 12px auto; text-align:center; max-width:520px;">
<p style="margin:0; font-weight:bold;">pair : $\displaystyle 2n$ &nbsp;&nbsp; impair : $\displaystyle 2n + 1$ &nbsp;&nbsp; multiple de $\displaystyle d$ : $\displaystyle dn$</p>
<p style="margin:6px 0 0 0;">consécutifs : $\displaystyle n$ ; $\displaystyle n + 1$ ; $\displaystyle n + 2$</p>
</div>
<p style="margin:0;">• Deux nombres quelconques → deux lettres <strong>différentes</strong>.</p>
<p style="margin:6px 0 0 0;">• Disjonction de cas : traiter séparément chaque cas possible (pair / impair…).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Rédiger une démonstration</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• Vérifier <strong>toutes</strong> les hypothèses du théorème avant de l'appliquer.</p>
<p style="margin:6px 0 0 0;">• Réciproque : pour prouver une propriété (angle droit, parallélisme) ; contraposée : pour prouver qu'elle n'a pas lieu.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Contrôler et rédiger au brevet</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Unités converties, signes et ordres de grandeur plausibles, probabilité entre 0 et 1.</p>
<p style="margin:6px 0 0 0;">• Arrondi à l'entier supérieur pour couvrir un besoin.</p>
<p style="margin:6px 0 0 0;">• Remplacer la solution dans l'équation de départ.</p>
<p style="margin:6px 0 0 0;">• Brevet (session 2027) : 20 min sans calculatrice (6 points) puis 1 h 40 avec calculatrice (14 points).</p>
</div>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Croire que quelques exemples suffisent à démontrer.</p>
<p style="margin:6px 0 0 0;">2️⃣ Utiliser la même lettre pour deux nombres différents.</p>
<p style="margin:6px 0 0 0;">3️⃣ Appliquer un théorème sans en vérifier les hypothèses (« la figure a l'air rectangle »).</p>
<p style="margin:6px 0 0 0;">4️⃣ Rendre un résultat sans phrase de conclusion ni unité.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> données → propriété → conclusion, à chaque étape ; pour une affirmation douteuse, chercher d'abord un contre-exemple ; pour un programme de calcul, tester, conjecturer, puis démontrer avec une lettre.</p>
</div>
