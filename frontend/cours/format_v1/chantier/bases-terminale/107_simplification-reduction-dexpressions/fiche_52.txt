Titre: Résumé : Simplification & Réduction d'Expressions

## I. Réduction des termes semblables

| Notion | Description |
|---|---|
| **Termes semblables** | Termes qui ont la même partie littérale (mêmes variables avec mêmes exposants) |
| **Partie littérale** | Les variables avec leurs exposants (ex: $\displaystyle x^2$ dans $\displaystyle 3x^2$) |
| **Réduction** | Additionner ou soustraire les coefficients des termes semblables |
| **Exemple** | $\displaystyle 3x + 5x - 2x = 6x$ (termes semblables : même partie $\displaystyle x$) |

| Étape | Méthode de réduction |
|---|---|
| **1** | Identifier les termes semblables (même partie littérale) |
| **2** | Grouper les termes semblables ensemble |
| **3** | Additionner ou soustraire les coefficients |
| **4** | Ordonner par degrés décroissants |

::: attention
Les termes $x^2$ et $x$ ne sont **pas** semblables ! Seuls les termes avec la **même partie littérale exacte** peuvent être réduits.
:::

## II. Simplification de fractions algébriques

| Règle | Formule |
|---|---|
| **Règle fondamentale** | $\displaystyle \dfrac{ac}{bc} = \dfrac{a}{b}$ (si $\displaystyle b \neq 0$ et $\displaystyle c \neq 0$) |
| **Simplification** | Diviser le numérateur et le dénominateur par leur facteur commun |

| Étape | Méthode de simplification |
|---|---|
| **1** | Factoriser le numérateur et le dénominateur |
| **2** | Identifier les facteurs communs |
| **3** | Diviser par les facteurs communs |
| **4** | Vérifier les valeurs interdites (dénominateur ≠ 0) |

| Exemple |
|---|
| $\displaystyle \dfrac{x^2 - 4}{x + 2} = \dfrac{(x-2)(x+2)}{x+2} = x - 2$ (si $\displaystyle x \neq -2$) |

::: attention Important
Toujours vérifier les **valeurs interdites** avant de simplifier ! Ne jamais simplifier par $0$.
:::

## III. Simplification avec développement et factorisation

| Stratégie | Description |
|---|---|
| **Alternance** | Alterner entre développement et factorisation pour identifier les facteurs communs ou termes semblables |
| **Développer** | Supprimer les parenthèses pour faire apparaître les termes semblables |
| **Factoriser** | Mettre en évidence les facteurs communs pour simplifier |

| Exemple |
|---|
| **Simplifier $\displaystyle (x+2)^2 - (x-1)^2$ :** <br> Développer : $\displaystyle x^2 + 4x + 4 - (x^2 - 2x + 1) = 6x + 3$ |

## IV. Simplification de produits et quotients

| Opération | Règle |
|---|---|
| **Produit de fractions** | $\displaystyle \dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}$ puis simplifier les facteurs communs |
| **Méthode** | Multiplier puis identifier et simplifier les facteurs communs |

| Exemple |
|---|
| $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = \dfrac{(x-1)(x+1)}{x+1} \times \dfrac{x+2}{x-1} = x + 2$ <br> (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$) |

## V. Ordre et standardisation

| Principe | Description |
|---|---|
| **Forme standard** | Expression ordonnée par degrés décroissants avec coefficients réduits |
| **Ordre d'écriture** | Termes de degré supérieur → degrés intermédiaires → terme constant |

| Avant | Après (forme standard) |
|---|---|
| $\displaystyle 5 - 3x + 2x^2$ | $\displaystyle 2x^2 - 3x + 5$ |
| $\displaystyle 3x - x^2 + 5 - 2x + x^2$ | $\displaystyle x + 5$ |

## VI. Méthode générale

| Étape | Ordre de travail |
|---|---|
| **1** | **Développer :** supprimer les parenthèses si nécessaire |
| **2** | **Réduire :** grouper et réduire les termes semblables |
| **3** | **Factoriser :** identifier les facteurs communs si possible |
| **4** | **Simplifier :** diviser par les facteurs communs dans les fractions |
| **5** | **Ordonner :** écrire sous forme standard (degrés décroissants) |

## VII. Erreurs fréquentes et conseils

| ERREURS À ÉVITER |
|---|
| **Réduire des termes non semblables :** $\displaystyle x^2 + x \neq 2x$ (ce sont des termes différents !) <br> <br> **Simplifier par 0 :** ne jamais diviser par $\displaystyle 0$ ou simplifier quand le dénominateur est $\displaystyle 0$ <br> <br> **Oublier les valeurs interdites :** toujours vérifier que les dénominateurs ne sont pas nuls <br> <br> **Confondre réduction et développement :** réduire = simplifier, développer = distribuer <br> <br> **Oublier d'ordonner :** une expression simplifiée doit être ordonnée par degrés décroissants <br> <br> **Simplifier partiellement :** $\displaystyle \dfrac{x+2}{x+2} = 1$ et non $\displaystyle x+2$ |

| CONSEILS |
|---|
| Toujours identifier les **termes semblables** avant de réduire <br> <br> Pour les fractions, toujours **factoriser** le numérateur et le dénominateur avant de simplifier <br> <br> Vérifier les **valeurs interdites** avant de simplifier une fraction <br> <br> Ordonner l'expression finale par **degrés décroissants** <br> <br> Vérifier le résultat en **remplaçant** $\displaystyle x$ par une valeur simple <br> <br> Pour les expressions complexes, travailler **étape par étape** |

## VIII. Formules rapides — mémo

| Notion | Formule/Méthode |
|---|---|
| **Termes semblables** | Même partie littérale (ex: $\displaystyle 3x$ et $\displaystyle 5x$ sont semblables) |
| **Réduction** | $\displaystyle ax + bx = (a + b)x$ |
| **Simplification de fraction** | $\displaystyle \dfrac{ac}{bc} = \dfrac{a}{b}$ (si $\displaystyle b \neq 0$ et $\displaystyle c \neq 0$) |
| **Produit de fractions** | $\displaystyle \dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}$ puis simplifier |
| **Forme standard** | Termes ordonnés par degrés décroissants : $\displaystyle ax^n + bx^{n-1} + \cdots + d$ |
| **Méthode générale** | Développer → Réduire → Factoriser → Simplifier → Ordonner |
| **Valeurs interdites** | Dénominateur ≠ 0 (toujours vérifier avant simplification) |

## IX. Points clés à retenir

| Notion | À retenir |
|---|---|
| **Termes semblables** | Avoir la même partie littérale exacte. $\displaystyle x^2$ et $\displaystyle x$ ne sont **pas** semblables |
| **Réduction** | Additionner/soustraire les coefficients des termes semblables uniquement |
| **Simplification de fractions** | Toujours factoriser avant de simplifier. Vérifier les valeurs interdites |
| **Développement/Factorisation** | Alterner ces deux opérations pour identifier les facteurs communs ou termes semblables |
| **Ordre standard** | Expression simplifiée ordonnée par degrés décroissants : $\displaystyle ax^n + bx^{n-1} + \cdots + d$ |
| **Valeurs interdites** | Toujours vérifier que les dénominateurs ne sont pas nuls avant simplification |
| **Erreur fréquente** | Réduire $\displaystyle x^2 + x$ en $\displaystyle 2x$ (FAUX : termes non semblables) |
| **Vérification** | Remplacer $\displaystyle x$ par une valeur simple pour valider le résultat |
