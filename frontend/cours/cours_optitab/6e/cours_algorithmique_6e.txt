=== Initiation à l'algorithmique : Décrire une procédure, lire ou produire un pseudo-code - Programme 6ème
Difficulté: easy
Ordre: 11

Titre: Initiation à l'algorithmique : Décrire une procédure, lire ou produire un pseudo-code simple, donner des consignes pour dessiner une figure, utiliser la répétition
Description: Mini-cours sur l'initiation à l'algorithmique en 6ème : décrire une procédure (recette, méthode) étape par étape, lire ou produire un pseudo-code très simple, exercices de type "donne les consignes pour dessiner cette figure", comprendre les instructions séquentielles, utiliser la répétition (boucle "répéter … fois").

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6; font-size:1em;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce qu'une procédure ou un algorithme ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Procédure / Algorithme</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>procédure</strong> ou un <strong>algorithme</strong> est une série d'<strong>instructions dans un ordre précis</strong> pour réaliser une tâche.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est comme une <strong>recette de cuisine</strong> : il faut suivre les étapes une par une, dans l'ordre, pour obtenir le résultat souhaité.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Exemples de procédures dans la vie quotidienne :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Une <strong>recette de cuisine</strong> : "Mélanger les œufs, ajouter la farine, cuire au four..."</li>
                <li style="margin:0 0 12px 0; text-align:left;">Les <strong>consignes pour se brosser les dents</strong> : "Prendre la brosse, mettre du dentifrice, brosser..."</li>
                <li style="margin:0 0 12px 0; text-align:left;">Les <strong>instructions pour dessiner une figure</strong> : "Tracer un segment, tourner à droite, avancer de 5 cm..."</li>
                <li style="margin:0; text-align:left;">Un <strong>programme informatique</strong> : série d'instructions pour l'ordinateur</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Décrire une procédure</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Écrire des instructions claires</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment décrire une procédure ?</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Identifier</strong> le but de la procédure (que veut-on obtenir ?)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lister</strong> toutes les étapes nécessaires</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordonner</strong> les étapes dans le bon ordre</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Rédiger</strong> chaque instruction de manière claire et précise</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> que toutes les étapes sont présentes</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Procédure simple - Se laver les mains</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Décrire la procédure pour se laver les mains correctement.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Procédure :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Ouvrir le robinet</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mouiller les mains</li>
                <li style="margin:0 0 12px 0; text-align:left;">Prendre du savon</li>
                <li style="margin:0 0 12px 0; text-align:left;">Frotter les mains pendant 20 secondes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Rincer les mains</li>
                <li style="margin:0; text-align:left;">Sécher les mains</li>
            </ol>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ordre des étapes est très important ! Si on change l'ordre, la procédure ne fonctionne plus correctement.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple, si on met "Sécher les mains" avant "Rincer les mains", ça n'a pas de sens !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Donner des consignes pour dessiner une figure</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Instructions pour tracer des figures géométriques</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Vocabulaire pour dessiner</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour donner des consignes de dessin, on utilise des verbes d'action précis :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Tracer</strong> : dessiner une ligne droite ou courbe</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Placer</strong> : mettre un point à un endroit précis</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Relier</strong> : joindre deux points par un segment</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Mesurer</strong> : vérifier une longueur</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Tourner</strong> : changer de direction (à droite, à gauche)</li>
                <li style="margin:0; text-align:left;"><strong>Avancer</strong> / <strong>Reculer</strong> : se déplacer d'une certaine distance</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Dessiner un carré</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Donner les consignes pour dessiner un carré de côté 5 cm.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Consignes :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Placer un point A</li>
                <li style="margin:0 0 12px 0; text-align:left;">Tracer un segment horizontal [AB] de longueur 5 cm vers la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Depuis B, tracer un segment vertical [BC] de longueur 5 cm vers le haut</li>
                <li style="margin:0 0 12px 0; text-align:left;">Depuis C, tracer un segment horizontal [CD] de longueur 5 cm vers la gauche</li>
                <li style="margin:0; text-align:left;">Relier D à A pour fermer le carré</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Dessiner un rectangle</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Donner les consignes pour dessiner un rectangle de longueur 6 cm et largeur 4 cm.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Consignes :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Placer un point A</li>
                <li style="margin:0 0 12px 0; text-align:left;">Tracer un segment horizontal [AB] de longueur 6 cm vers la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Depuis B, tracer un segment vertical [BC] de longueur 4 cm vers le haut</li>
                <li style="margin:0 0 12px 0; text-align:left;">Depuis C, tracer un segment horizontal [CD] de longueur 6 cm vers la gauche</li>
                <li style="margin:0; text-align:left;">Relier D à A pour fermer le rectangle</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Dessiner un triangle</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Donner les consignes pour dessiner un triangle quelconque.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Consignes :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Placer un point A</li>
                <li style="margin:0 0 12px 0; text-align:left;">Tracer un segment [AB] de longueur 5 cm</li>
                <li style="margin:0 0 12px 0; text-align:left;">Depuis B, tracer un segment [BC] de longueur 4 cm</li>
                <li style="margin:0; text-align:left;">Relier C à A pour fermer le triangle</li>
            </ol>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour donner de bonnes consignes, imagine que tu donnes ces instructions à quelqu'un qui ne voit pas la figure finale. Chaque étape doit être <strong>précise</strong> et <strong>claire</strong> !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Lire ou produire un pseudo-code</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Pseudo-code simple</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Qu'est-ce que le pseudo-code ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>pseudo-code</strong> est une façon simplifiée d'écrire un algorithme en utilisant un langage qui ressemble au français, mais de manière structurée.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est un langage intermédiaire entre le français et le langage de programmation informatique.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Lire un pseudo-code simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Choisir un nombre</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Multiplier ce nombre par 3</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Ajouter 5 au résultat</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Afficher le résultat</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Si on choisit le nombre 4, quel résultat sera affiché ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Nombre choisi : 4</li>
                <li style="margin:0 0 12px 0; text-align:left;">Multiplier par 3 : 4 × 3 = 12</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ajouter 5 : 12 + 5 = 17</li>
                <li style="margin:0; text-align:left;"><strong>Résultat affiché : 17</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Produire un pseudo-code</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Écrire un pseudo-code pour calculer le périmètre d'un carré dont on connaît le côté.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Demander la longueur du côté</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Multiplier la longueur du côté par 4</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Afficher le résultat (le périmètre)</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Pseudo-code pour dessiner une figure</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Écrire un pseudo-code pour tracer un carré de 4 cm de côté.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Placer un point A</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Tracer un segment horizontal [AB] de 4 cm vers la droite</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Depuis B, tracer un segment vertical [BC] de 4 cm vers le haut</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Depuis C, tracer un segment horizontal [CD] de 4 cm vers la gauche</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Relier D à A</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Structure du pseudo-code :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>DÉBUT</strong> : marque le début de l'algorithme</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Instructions</strong> : écrites en français simple, une par ligne</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Indentation</strong> : les instructions sont légèrement décalées (pour la clarté)</li>
                <li style="margin:0; text-align:left;"><strong>FIN</strong> : marque la fin de l'algorithme</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. La répétition : "répéter … fois"</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Répéter une action plusieurs fois</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Qu'est-ce que la répétition ?</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Parfois, dans un algorithme, on doit <strong>répéter la même action plusieurs fois</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Au lieu d'écrire la même instruction plusieurs fois, on utilise la notation : <strong>"Répéter … fois"</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela permet de <strong>simplifier</strong> et de <strong>rendre plus clair</strong> l'algorithme.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Exemples de répétition dans la vie quotidienne :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Frotter les mains pendant 20 secondes = <strong>répéter</strong> l'action de frotter plusieurs fois</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour dessiner un carré, on <strong>répète 4 fois</strong> : avancer puis tourner à droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Compter jusqu'à 10 = <strong>répéter</strong> l'action "compter +1" plusieurs fois</li>
                <li style="margin:0; text-align:left;">Mélanger la pâte = <strong>répéter</strong> le mouvement de mélange plusieurs fois</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Répéter dans un pseudo-code simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Écrire un pseudo-code pour afficher 5 fois le mot "Bonjour".</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Répéter 5 fois :</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Afficher "Bonjour"</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résultat :</strong> Le mot "Bonjour" sera affiché 5 fois : Bonjour Bonjour Bonjour Bonjour Bonjour</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Répéter pour dessiner un carré (méthode simplifiée)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Dessiner un carré de 4 cm de côté en utilisant la répétition.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Observation :</strong> Un carré a 4 côtés égaux. Pour tracer chaque côté, on avance de 4 cm, puis on tourne à droite d'un angle de 90°.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Consignes :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Placer un point A</li>
                <li style="margin:0 0 12px 0; text-align:left;">Répéter 4 fois :</li>
                <li style="margin:0 0 12px 0; text-align:left; padding-left:20px;">Avancer de 4 cm</li>
                <li style="margin:0; text-align:left; padding-left:20px;">Tourner à droite d'un angle de 90°</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Placer un point A</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Répéter 4 fois :</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Avancer de 4 cm</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Tourner à droite de 90°</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>💡 Avantage :</strong> Au lieu d'écrire 8 instructions (4× "avancer" + 4× "tourner"), on écrit seulement 4 instructions avec une répétition !</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Répéter pour un calcul</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Écrire un pseudo-code pour calculer 3 × 5 en utilisant l'addition répétée.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Rappel :</strong> 3 × 5 signifie "ajouter 5, 3 fois".</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Résultat ← 0</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Répéter 3 fois :</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Résultat ← Résultat + 5</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Afficher Résultat</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Exécution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résultat = 0</li>
                <li style="margin:0 0 12px 0; text-align:left;">1<sup>ère</sup> fois : Résultat = 0 + 5 = 5</li>
                <li style="margin:0 0 12px 0; text-align:left;">2<sup>ème</sup> fois : Résultat = 5 + 5 = 10</li>
                <li style="margin:0 0 12px 0; text-align:left;">3<sup>ème</sup> fois : Résultat = 10 + 5 = 15</li>
                <li style="margin:0; text-align:left;"><strong>Résultat final : 15</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Répéter pour dessiner un triangle équilatéral</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Objectif :</strong> Dessiner un triangle équilatéral de 5 cm de côté en utilisant la répétition.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Observation :</strong> Un triangle équilatéral a 3 côtés égaux. Pour tracer chaque côté, on avance de 5 cm, puis on tourne à gauche d'un angle de 120°.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pseudo-code :</strong></p>
            <div style="background:#f0f0f0; padding:15px; border-radius:6px; border-left:4px solid #666; font-family:monospace; font-size:0.95em; margin:12px 0;">
                <p style="margin:4px 0; text-align:left;">DÉBUT</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Placer un point A</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;Répéter 3 fois :</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Avancer de 5 cm</p>
                <p style="margin:4px 0; text-align:left;">&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Tourner à gauche de 120°</p>
                <p style="margin:4px 0; text-align:left;">FIN</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Comment utiliser "répéter … fois" :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Identifier l'<strong>action à répéter</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Déterminer <strong>combien de fois</strong> la répéter</li>
                <li style="margin:0 0 12px 0; text-align:left;">Écrire : <strong>"Répéter [nombre] fois :"</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Indenter (décaler) les <strong>instructions à répéter</strong> sous cette ligne</li>
                <li style="margin:0; text-align:left;"><strong>Attention :</strong> toutes les instructions à répéter doivent être décalées de la même manière</li>
            </ul>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans la répétition, toutes les instructions à répéter doivent être <strong>à l'intérieur</strong> de la boucle (bien indentées).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on oublie d'indenter, l'instruction ne sera pas répétée et ne sera exécutée qu'une seule fois !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour décrire une procédure :</strong> toujours suivre l'ordre logique des étapes</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les consignes de dessin :</strong> être précis (dire la direction, la longueur, les points de départ et d'arrivée)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour le pseudo-code :</strong> utiliser des phrases courtes et claires</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour la répétition :</strong> utiliser "Répéter … fois" quand une même action doit être faite plusieurs fois</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérifier sa procédure :</strong> essayer de la suivre mentalement pour voir si elle fonctionne</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas oublier d'étapes</strong> : toutes les actions nécessaires doivent être mentionnées</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Utiliser un vocabulaire précis</strong> : "tracer", "placer", "relier", "mesurer", etc.</li>
                <li style="margin:0; text-align:left;"><strong>Structurer clairement</strong> : une instruction par ligne dans le pseudo-code, bien indenter les répétitions</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier l'ordre</strong> : ne pas respecter l'ordre des étapes</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Instructions imprécises</strong> : dire "tracer une ligne" au lieu de "tracer un segment horizontal de 5 cm vers la droite"</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier des détails</strong> : ne pas mentionner les longueurs, les directions, les points</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Instructions confuses</strong> : utiliser des mots vagues ou ambigus</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Dans le pseudo-code :</strong> oublier DÉBUT et FIN, ou ne pas structurer les instructions</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Dans la répétition :</strong> oublier d'indenter les instructions à répéter, ou mal indenter</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas utiliser la répétition</strong> : écrire plusieurs fois la même instruction au lieu d'utiliser "Répéter … fois"</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas tester</strong> : ne pas vérifier que la procédure fonctionne</li>
                <li style="margin:0; text-align:left;"><strong>Supposer que c'est évident</strong> : tout doit être expliqué clairement, même ce qui semble évident</li>
            </ul>
        </div>
    </div>
