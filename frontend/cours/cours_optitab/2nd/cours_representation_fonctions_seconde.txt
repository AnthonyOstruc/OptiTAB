    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Courbe représentative d'une fonction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Courbe représentative</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle f$ une fonction définie sur un ensemble $\displaystyle \mathcal{D}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un repère du plan, la <strong>courbe représentative</strong> de $\displaystyle f$, notée $\displaystyle \mathcal{C}_f$, est l'ensemble des points $\displaystyle M$ de coordonnées $\displaystyle (x; y)$ tels que :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">$\displaystyle x \in \mathcal{D}$ (l'abscisse est dans l'ensemble de définition)</li>
                <li style="margin:0; text-align:left;">$\displaystyle y = f(x)$ (l'ordonnée est l'image de $\displaystyle x$ par $\displaystyle f$)</li>
            </ul>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle M(x; y) \in \mathcal{C}_f \Longleftrightarrow y = f(x)$
            </div>
        </div>

        [IMAGE_1]

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple - Test d'appartenance :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle f$ définie sur $\displaystyle \mathbb{R}$ par $\displaystyle f(x) = x^2 - 3x + 1$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A(2; -1)$ appartient-il à $\displaystyle \mathcal{C}_f$ ?</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">On calcule l'image de l'abscisse : $\displaystyle f(2) = 2^2 - 3(2) + 1 = 4 - 6 + 1 = -1$.</li>
                <li style="margin:0; text-align:left;">On compare avec l'ordonnée de $\displaystyle A$ : $\displaystyle y_A = -1$.</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle f(x_A) = y_A$, le point $\displaystyle A$ <strong>appartient</strong> à la courbe.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Résolution graphique d'équations et inéquations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Équations du type $\displaystyle f(x) = k$ et inéquations $\displaystyle f(x) < k$</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode - Résolution graphique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre avec la courbe $\displaystyle \mathcal{C}_f$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle f(x) = k$ :</strong> Tracer la droite horizontale $\displaystyle y = k$. Les solutions sont les <strong>abscisses</strong> des points d'intersection entre $\displaystyle \mathcal{C}_f$ et la droite.</li>
                <li style="margin:0; text-align:left;"><strong>$\displaystyle f(x) < k$ :</strong> Repérer la partie de la courbe située <strong>strictement en dessous</strong> de la droite $\displaystyle y = k$. Les solutions sont les abscisses correspondantes (souvent des intervalles).</li>
            </ul>
        </div>

        [IMAGE_2]

        <h3 style="color:#34495e; margin-top:20px;">Positions relatives : $\displaystyle f(x) = g(x)$ et $\displaystyle f(x) < g(x)$</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode - Comparaison de deux courbes :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \mathcal{C}_f$ et $\displaystyle \mathcal{C}_g$ les courbes de $\displaystyle f$ et $\displaystyle g$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>$\displaystyle f(x) = g(x)$ :</strong> Les solutions sont les abscisses des <strong>points d'intersection</strong> des deux courbes.</li>
                <li style="margin:0; text-align:left;"><strong>$\displaystyle f(x) < g(x)$ :</strong> Les solutions sont les abscisses des points où $\displaystyle \mathcal{C}_f$ est située <strong>en dessous</strong> de $\displaystyle \mathcal{C}_g$.</li>
            </ul>
        </div>

        [IMAGE_3]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Parité d'une fonction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Prérequis indispensable :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour parler de parité, l'ensemble de définition $\displaystyle \mathcal{D}_f$ doit être <strong>symétrique par rapport à 0</strong> (si $\displaystyle x \in \mathcal{D}_f$, alors $\displaystyle -x \in \mathcal{D}_f$).</p>
        </div>

        <h3 style="color:#34495e; margin-top:0;">Fonction paire</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition & Propriété géométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ est <strong>paire</strong> si pour tout $\displaystyle x \in \mathcal{D}_f$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:200px; font-weight:bold;">
                $\displaystyle f(-x) = f(x)$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Traduction géométrique :</strong> La courbe $\displaystyle \mathcal{C}_f$ est symétrique par rapport à l'<strong>axe des ordonnées</strong>.</p>
        </div>

        [IMAGE_4]

        <h3 style="color:#34495e; margin-top:20px;">Fonction impaire</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition & Propriété géométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ est <strong>impaire</strong> si pour tout $\displaystyle x \in \mathcal{D}_f$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:200px; font-weight:bold;">
                $\displaystyle f(-x) = -f(x)$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Traduction géométrique :</strong> La courbe $\displaystyle \mathcal{C}_f$ est symétrique par rapport à l'<strong>origine du repère</strong> (symétrie centrale).</p>
        </div>

        [IMAGE_5]

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples algébriques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(x) = x^2$ sur $\displaystyle \mathbb{R}$. $\displaystyle f(-x) = (-x)^2 = x^2 = f(x)$. Fonction <strong>paire</strong>.</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle g(x) = x^3 - x$ sur $\displaystyle \mathbb{R}$. $\displaystyle g(-x) = (-x)^3 - (-x) = -x^3 + x = -(x^3 - x) = -g(x)$. Fonction <strong>impaire</strong>.</li>
                <li style="margin:0; text-align:left;">$\displaystyle h(x) = x^2 + x$. $\displaystyle h(-x) = x^2 - x$. Ce n'est ni $\displaystyle h(x)$ ni $\displaystyle -h(x)$. Fonction <strong>ni paire ni impaire</strong>.</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Résolution algébrique et Tableau de signes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Signe d'une expression affine $\displaystyle ax + b$</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour étudier le signe de $\displaystyle A(x) \times B(x)$ ou $\displaystyle \frac{A(x)}{B(x)}$, on utilise un <strong>tableau de signes</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Rappel : Le signe de $\displaystyle ax + b$ (avec $\displaystyle a \neq 0$) change en $\displaystyle x = -\frac{b}{a}$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;">Si $\displaystyle a > 0$ : négatif avant la racine, positif après ($\displaystyle - \quad 0 \quad +$).</li>
                <li style="margin:0; text-align:left;">Si $\displaystyle a < 0$ : positif avant la racine, négatif après ($\displaystyle + \quad 0 \quad -$).</li>
            </ul>
        </div>

        <h3 style="color:#34495e; margin-top:20px;">Méthode du tableau de signes</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>📐 Étapes à suivre :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 10px 0; text-align:left;"><strong>Tout passer d'un côté</strong> pour avoir $\displaystyle ... > 0$ ou $\displaystyle ... \leq 0$.</li>
                <li style="margin:0 0 10px 0; text-align:left;"><strong>Factoriser</strong> ou mettre au même dénominateur pour obtenir un produit ou un quotient.</li>
                <li style="margin:0 0 10px 0; text-align:left;">Trouver les <strong>valeurs d'annulation</strong> (racines) et les <strong>valeurs interdites</strong> (dénominateur nul).</li>
                <li style="margin:0 0 10px 0; text-align:left;">Dresser le tableau avec une ligne par facteur.</li>
                <li style="margin:0; text-align:left;">Appliquer la <strong>règle des signes</strong> pour la dernière ligne.</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Résoudre $\displaystyle (2x - 4)(3 - x) \geq 0$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">1. Racines : $\displaystyle 2x - 4 = 0 \iff x = 2$ et $\displaystyle 3 - x = 0 \iff x = 3$.</p>
