    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Rappels</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vecteurs : définition, notation, représentation</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Vecteur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>vecteur</strong> est un objet mathématique caractérisé par sa direction, son sens, sa norme et son point d'application.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un vecteur est défini par ses coordonnées dans une base donnée.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Notation</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle\vec{u}$, $\displaystyle\vec{v}$, $\displaystyle\vec{w}$ ou $\displaystyle\overrightarrow{AB}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle\vec{u} = \begin{pmatrix} x \\ y \end{pmatrix}$ dans le plan</li>
                <li style="margin:0; text-align:left;">$\displaystyle\vec{u} = \begin{pmatrix} x \\ y \\ z \end{pmatrix}$ dans l'espace</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Règles importantes</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Règle de Chasles :</strong> $\displaystyle\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$</li>
                <li style="margin:0; text-align:left;"><strong>Règle du parallélogramme :</strong> $\displaystyle\vec{u} + \vec{v}$ s'obtient en construisant le parallélogramme ayant $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$ comme côtés consécutifs</li>
            </ul>
        </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Calcul du vecteur $\overrightarrow{AB}$</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Calcul du vecteur $\displaystyle\overrightarrow{AB}$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer le vecteur $\displaystyle\overrightarrow{AB}$ à partir des coordonnées des points $\displaystyle A$ et $\displaystyle B$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = \begin{pmatrix} x_B - x_A \\ y_B - y_A \end{pmatrix}$ dans le plan</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = \begin{pmatrix} x_B - x_A \\ y_B - y_A \\ z_B - z_A \end{pmatrix}$ dans l'espace</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle A(2, 3)$ et $\displaystyle B(5, -1)$ dans le plan.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = \begin{pmatrix} 5 - 2 \\ -1 - 3 \end{pmatrix} = \begin{pmatrix} 3 \\ -4 \end{pmatrix}$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Vecteurs opposés</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = -\overrightarrow{BA}$ (vecteurs opposés)</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Combinaisons linéaires</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Combinaison linéaire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$ des vecteurs et $\displaystyle a_1, a_2, \ldots, a_n$ des scalaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le vecteur $\displaystyle\vec{v} = a_1\vec{u_1} + a_2\vec{u_2} + \ldots + a_n\vec{u_n}$ est appelé <strong>combinaison linéaire</strong> des vecteurs $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\vec{u} + 2\vec{v}$ est une combinaison linéaire de $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples concrets dans le plan et dans l'espace</h3>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 (Plan) :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle\vec{u} = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$ et $\displaystyle\vec{v} = \begin{pmatrix} 3 \\ -1 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exprimer $\displaystyle\vec{w} = \begin{pmatrix} 7 \\ 1 \end{pmatrix}$ comme combinaison linéaire de $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle a$ et $\displaystyle b$ tels que $\displaystyle\vec{w} = a\vec{u} + b\vec{v}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">C'est-à-dire : $\displaystyle\begin{pmatrix} 7 \\ 1 \end{pmatrix} = a\begin{pmatrix} 1 \\ 2 \end{pmatrix} + b\begin{pmatrix} 3 \\ -1 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{pmatrix} 7 \\ 1 \end{pmatrix} = \begin{pmatrix} a + 3b \\ 2a - b \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On obtient le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{cases} a + 3b = 7 \\ 2a - b = 1 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Résolution : $\displaystyle a = 2$ et $\displaystyle b = \dfrac{5}{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> $\displaystyle\vec{w} = 2\vec{u} + \dfrac{5}{3}\vec{v}$</p>
        </div>

        [IMAGE_2]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple 2 (Espace)</h3>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 (Espace) :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle\vec{u} = \begin{pmatrix} 1 \\ 0 \\ 2 \end{pmatrix}$, $\displaystyle\vec{v} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}$ et $\displaystyle\vec{w} = \begin{pmatrix} 2 \\ 1 \\ 5 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exprimer $\displaystyle\vec{w}$ comme combinaison linéaire de $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle a$ et $\displaystyle b$ tels que $\displaystyle\vec{w} = a\vec{u} + b\vec{v}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{pmatrix} 2 \\ 1 \\ 5 \end{pmatrix} = a\begin{pmatrix} 1 \\ 0 \\ 2 \end{pmatrix} + b\begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} a \\ b \\ 2a + b \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On obtient le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{cases} a = 2 \\ b = 1 \\ 2a + b = 5 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle 2 \times 2 + 1 = 5$ ✓</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> $\displaystyle\vec{w} = 2\vec{u} + \vec{v}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Indépendance des vecteurs</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Indépendance linéaire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Des vecteurs $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$ sont dits <strong>linéairement indépendants</strong> si la seule combinaison linéaire qui donne le vecteur nul est celle où tous les coefficients sont nuls.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle a_1\vec{u_1} + a_2\vec{u_2} + \ldots + a_n\vec{u_n} = \vec{0} \Rightarrow a_1 = a_2 = \ldots = a_n = 0$</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>⚠️ Attention :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on peut trouver des coefficients non tous nuls tels que la combinaison linéaire donne le vecteur nul, alors les vecteurs sont <strong>linéairement dépendants</strong>.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode de vérification</h3>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode - Vérifier l'indépendance linéaire</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer si des vecteurs sont linéairement indépendants :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Étape 1 :</strong> Écrire la combinaison linéaire égale au vecteur nul : $\displaystyle a_1\vec{u_1} + a_2\vec{u_2} + \ldots + a_n\vec{u_n} = \vec{0}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Étape 2 :</strong> Résoudre le système d'équations obtenu</li>
                <li style="margin:0; text-align:left;"><strong>Étape 3 :</strong> Conclure :
                    <ul style="margin:8px 0; padding-left:20px; line-height:1.6; font-size:0.95em;">
                        <li style="margin:0 0 8px 0; text-align:left;">Si la seule solution est $\displaystyle a_1 = a_2 = \ldots = a_n = 0$ : <strong>indépendants</strong></li>
                        <li style="margin:0; text-align:left;">Sinon : <strong>dépendants</strong></li>
                    </ul>
                </li>
            </ol>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple d'étude d'indépendance</h3>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Étudier l'indépendance linéaire de $\displaystyle\vec{u} = \begin{pmatrix} 1 \\ 2 \end{pmatrix}$ et $\displaystyle\vec{v} = \begin{pmatrix} 3 \\ 1 \end{pmatrix}$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle a$ et $\displaystyle b$ tels que $\displaystyle a\vec{u} + b\vec{v} = \vec{0}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a\begin{pmatrix} 1 \\ 2 \end{pmatrix} + b\begin{pmatrix} 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce qui donne le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{cases} a + 3b = 0 \\ 2a + b = 0 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Résolution : $\displaystyle a = 0$ et $\displaystyle b = 0$ (solution unique)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong> Les vecteurs $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$ sont <strong>linéairement indépendants</strong>.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Colinéarité</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Colinéarité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs sont <strong>colinéaires</strong> si leurs coordonnées sont proportionnelles.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\vec{u} \text{ et } \vec{v} \text{ sont colinéaires } \Leftrightarrow \vec{u} = k\vec{v} \text{ pour un certain } k \in \mathbb{R}$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation géométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs colinéaires ont la même direction (parallèles).</p>
        </div>

    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vérification pratique : déterminant nul en 2D</h3>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode - Vérifier la colinéarité</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour vérifier la colinéarité de deux vecteurs :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode 1 - Déterminant :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle\vec{u} = \begin{pmatrix} x_1 \\ y_1 \end{pmatrix}$ et $\displaystyle\vec{v} = \begin{pmatrix} x_2 \\ y_2 \end{pmatrix}$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\vec{u} \text{ et } \vec{v} \text{ sont colinéaires } \Leftrightarrow \det(\vec{u}, \vec{v}) = x_1y_2 - x_2y_1 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode 2 - Rapport des coordonnées :</strong></p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\vec{u} \text{ et } \vec{v} \text{ sont colinéaires } \Leftrightarrow \dfrac{x_1}{x_2} = \dfrac{y_1}{y_2} \text{ (si } x_2 \neq 0 \text{ et } y_2 \neq 0)$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Coplanarité (en 3D)</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Coplanarité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Trois vecteurs sont <strong>coplanaires</strong> s'ils appartiennent à un même plan.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation géométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Trois vecteurs coplanaires peuvent être représentés dans un même plan, même s'ils ont des points d'application différents.</p>
        </div>

        [IMAGE_4]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vérification pratique : déterminant 3×3 nul</h3>
        
        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode - Vérifier la coplanarité</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour vérifier la coplanarité de trois vecteurs :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode 1 - Déterminant :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle\vec{u} = \begin{pmatrix} x_1 \\ y_1 \\ z_1 \end{pmatrix}$, $\displaystyle\vec{v} = \begin{pmatrix} x_2 \\ y_2 \\ z_2 \end{pmatrix}$, $\displaystyle\vec{w} = \begin{pmatrix} x_3 \\ y_3 \\ z_3 \end{pmatrix}$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\det(\vec{u}, \vec{v}, \vec{w}) = 0 \Leftrightarrow \text{ les vecteurs sont coplanaires}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode 2 - Système d'équations :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs sont coplanaires s'il existe des réels $\displaystyle a$, $\displaystyle b$, $\displaystyle c$ non tous nuls tels que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a\vec{u} + b\vec{v} + c\vec{w} = \vec{0}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Méthodes pratiques</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Calcul des déterminants</h3>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Déterminant 2×2</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\det\begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$</p>
        </div>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\det\begin{pmatrix} 2 & 3 \\ 1 & 4 \end{pmatrix} = 2 \times 4 - 3 \times 1 = 8 - 3 = 5$</p>
        </div>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Déterminant 3×3</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Développement par la première ligne :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\det\begin{pmatrix} a & b & c \\ d & e & f \\ g & h & i \end{pmatrix} = a \begin{vmatrix} e & f \\ h & i \end{vmatrix} - b \begin{vmatrix} d & f \\ g & i \end{vmatrix} + c \begin{vmatrix} d & e \\ g & h \end{vmatrix}$</p>
        </div>
        
        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Méthode de calcul</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On développe par rapport à la première ligne avec alternance des signes + et -</p>
        </div>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">$\displaystyle\det\begin{pmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 9 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle = 1 \begin{vmatrix} 5 & 6 \\ 8 & 9 \end{vmatrix} - 2 \begin{vmatrix} 4 & 6 \\ 7 & 9 \end{vmatrix} + 3 \begin{vmatrix} 4 & 5 \\ 7 & 8 \end{vmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle = 1(5 \times 9 - 6 \times 8) - 2(4 \times 9 - 6 \times 7) + 3(4 \times 8 - 5 \times 7)$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle = 1(45 - 48) - 2(36 - 42) + 3(32 - 35) = -3 + 12 - 9 = 0$</p>
        </div>
        
        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Application</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si le déterminant est nul, les vecteurs sont liés (colinéaires ou coplanaires)</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Utilisation des déterminants en 2D et 3D</h3>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Déterminant 2×2</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\det(\vec{u}, \vec{v}) = \begin{vmatrix} x_1 & x_2 \\ y_1 & y_2 \end{vmatrix} = x_1y_2 - x_2y_1$</p>
        </div>
        
        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation du déterminant 2×2</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si $\displaystyle\det(\vec{u}, \vec{v}) = 0$ : $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$ sont <strong>colinéaires</strong></li>
                <li style="margin:0; text-align:left;">Si $\displaystyle\det(\vec{u}, \vec{v}) \neq 0$ : $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$ sont <strong>indépendants</strong></li>
            </ul>
        </div>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Déterminant 3×3</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\det(\vec{u}, \vec{v}, \vec{w}) = \begin{vmatrix} x_1 & x_2 & x_3 \\ y_1 & y_2 & y_3 \\ z_1 & z_2 & z_3 \end{vmatrix}$</p>
        </div>
        
        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation du déterminant 3×3</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si $\displaystyle\det(\vec{u}, \vec{v}, \vec{w}) = 0$ : les vecteurs sont <strong>coplanaires</strong></li>
                <li style="margin:0; text-align:left;">Si $\displaystyle\det(\vec{u}, \vec{v}, \vec{w}) \neq 0$ : les vecteurs sont <strong>indépendants</strong></li>
            </ul>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Erreurs fréquentes et conseils</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre "colinéaires" et "égaux" : deux vecteurs colinéaires peuvent avoir des normes différentes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de vérifier que les coefficients ne sont pas tous nuls dans le cas de dépendance</li>
                <li style="margin:0 0 12px 0; text-align:left;">Négliger le cas particulier du vecteur nul (toujours dépendant avec n'importe quel autre vecteur)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre "coplanaires" et "colinéaires" : la coplanarité concerne 3 vecteurs, la colinéarité 2 vecteurs</li>
                <li style="margin:0; text-align:left;">Oublier de simplifier les équations avant de résoudre le système</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser le déterminant pour deux vecteurs dans le plan (colinéarité)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser le déterminant 3×3 pour trois vecteurs dans l'espace (coplanarité)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier la cohérence des dimensions (on ne peut pas avoir plus de vecteurs indépendants que la dimension de l'espace)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les applications géométriques, bien identifier les vecteurs directeurs</li>
                <li style="margin:0; text-align:left;">S'entraîner sur des exemples concrets pour bien comprendre les concepts</li>
            </ul>
        </div>
