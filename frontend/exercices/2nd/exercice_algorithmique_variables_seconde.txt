Énoncé: On travaille sur les types de variables en Python (int, float, bool, str).
$\\$
**Question 1 :** Donner le type de chacune des valeurs suivantes : <code>42</code>, <code>3.14</code>, <code>True</code>, <code>"Bonjour"</code>.
$\\$
**Question 2 :** On exécute les instructions suivantes. Donner la valeur et le type de chaque variable.
$\\$

**Question 3 :** Quelle est la différence entre <code>3</code> et <code>3.0</code> en Python ?
$\\$

<code>age</code>, <code>2ndNom</code>, <code>ma_variable</code>, <code>for</code>, <code>moyenne_classe</code>.
$\\$
**Question 5 :** Quelle erreur se produit si on écrit <code>"Résultat : " + 5</code> ? Comment corriger ?

Étapes:

**Question 1 : Types des valeurs**

    ● **Méthode :** Identifier le type Python de chaque valeur en observant sa forme
    $\\$
    
    ● **Étape 1 :** Analyser chaque valeur
        $\qquad$• <code>42</code> → nombre entier, sans virgule → <code>int</code>
        $\\$
        $\qquad$• <code>3.14</code> → nombre avec un point décimal → <code>float</code>
        $\\$
        $\qquad$• <code>True</code> → valeur booléenne (vrai/faux) → <code>bool</code>
        $\\$
        $\qquad$• <code>"Bonjour"</code> → texte entre guillemets → <code>str</code>
    $\\$
    
    ● **Résultat :** <code>42</code> est un <code>int</code>, <code>3.14</code> est un <code>float</code>, <code>True</code> est un <code>bool</code>, <code>"Bonjour"</code> est un <code>str</code>
    $\\$

**Question 2 : Valeur et type de chaque variable**

    ● **Méthode :** Exécuter chaque instruction dans l'ordre et déterminer la valeur puis le type
    $\\$
    
    ● **Étape 1 :** <code>a = 7</code>
        $\qquad$• Valeur : <code>7</code>, Type : <code>int</code>
    $\\$
    
    ● **Étape 2 :** <code>b = 2.0</code>
        $\qquad$• Valeur : <code>2.0</code>, Type : <code>float</code>
    $\\$
    
    ● **Étape 3 :** <code>c = a > 10</code>
        $\qquad$• On compare : $\displaystyle 7 \gt  10$ est faux → <code>c = False</code>, Type : <code>bool</code>
    $\\$
    
    ● **Étape 4 :** <code>d = "maths"</code>
        $\qquad$• Valeur : <code>"maths"</code>, Type : <code>str</code>
    $\\$
    
    ● **Résultat :** <code>a = 7</code> (int), <code>b = 2.0</code> (float), <code>c = False</code> (bool), <code>d = "maths"</code> (str)
    $\\$

**Question 3 : Différence entre <code>3</code> et <code>3.0</code>**

    ● **Méthode :** Identifier le type de chaque écriture
    $\\$
    
    ● **Explication :**
        $\qquad$• <code>3</code> est un **entier** (<code>int</code>) : il est stocké exactement
        $\\$
        $\qquad$• <code>3.0</code> est un **flottant** (<code>float</code>) : il est stocké comme un nombre à virgule
        $\\$
        $\qquad$• Ils ont la même valeur mathématique, mais Python les distingue par leur type
    $\\$
    
    ● **Résultat :** <code>3</code> est de type <code>int</code>, <code>3.0</code> est de type <code>float</code>. Même valeur, types différents
    $\\$

**Question 4 : Noms de variables valides**

    ● **Méthode :** Un nom de variable Python doit commencer par une lettre ou <code>_</code>, ne pas être un mot réservé, et ne contenir que des lettres, chiffres et <code>_</code>
    $\\$
    
    ● **Étape 1 :** Vérifier chaque nom
        $\qquad$• <code>age</code> → ✅ valide
        $\\$
        $\qquad$• <code>2ndNom</code> → ❌ commence par un chiffre
        $\\$
        $\qquad$• <code>ma_variable</code> → ✅ valide
        $\\$
        $\qquad$• <code>for</code> → ❌ mot réservé de Python (boucle for)
        $\\$
        $\qquad$• <code>moyenne_classe</code> → ✅ valide
    $\\$
    
    ● **Résultat :** <code>age</code>, <code>ma_variable</code> et <code>moyenne_classe</code> sont valides. <code>2ndNom</code> et <code>for</code> ne le sont pas
    $\\$

**Question 5 : Erreur de concaténation**

    ● **Méthode :** En Python, on ne peut pas additionner une chaîne (<code>str</code>) et un entier (<code>int</code>)
    $\\$
    
    ● **Explication :**
        $\qquad$• <code>"Résultat : " + 5</code> provoque une erreur <code>TypeError</code> car on mélange <code>str</code> et <code>int</code>
        $\\$
        $\qquad$• Pour corriger, on convertit le nombre en chaîne : <code>"Résultat : " + str(5)</code>
    $\\$
    
    ● **Résultat :** Il faut écrire <code>"Résultat : " + str(5)</code> pour obtenir <code>"Résultat : 5"</code>
    $\\$

Solution:
1. <code>42</code> → int, <code>3.14</code> → float, <code>True</code> → bool, <code>"Bonjour"</code> → str
$\\$
2. <code>a = 7</code> (int), <code>b = 2.0</code> (float), <code>c = False</code> (bool), <code>d = "maths"</code> (str)
$\\$
3. <code>3</code> est int, <code>3.0</code> est float — même valeur, types différents
$\\$
4. Valides : <code>age</code>, <code>ma_variable</code>, <code>moyenne_classe</code>. Invalides : <code>2ndNom</code>, <code>for</code>
$\\$
5. <code>TypeError</code> → corriger avec <code>"Résultat : " + str(5)</code>
