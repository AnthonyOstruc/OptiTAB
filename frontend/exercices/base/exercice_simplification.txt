=== Simplification - Réduction de Termes Semblables
Difficulté: easy

Énoncé: Simplifier les expressions suivantes en réduisant les termes semblables.

**Question 1 : Simplifier $\displaystyle 3x + 5x - 2x$**
$\\$
**Question 2 : Simplifier $\displaystyle 2x^2 + 3x - x^2 + 5x$**
$\\$
**Question 3 : Simplifier $\displaystyle 4ab + 3ab - 2ab$**
$\\$
**Question 4 : Simplifier $\displaystyle 3x^2 - 2x + x^2 + 4x - 1$**
$\\$
**Question 5 : Simplifier $\displaystyle 5y - 2y + 3y - y$**

Étapes:

**Question 1 : Simplifier $\displaystyle 3x + 5x - 2x$**

    ● **Méthode :** Réduction de termes semblables
    $\\$
    
    ● **Étape 1 :** Identifier les termes semblables
        $\qquad$• Tous les termes ont la même partie littérale : $\displaystyle x$
    $\\$
    
    ● **Étape 2 :** Grouper les termes semblables
        $\qquad$• $\displaystyle 3x + 5x - 2x$
    $\\$
    
    ● **Étape 3 :** Réduire les coefficients
        $\qquad$• $\displaystyle (3 + 5 - 2)x = 6x$
    $\\$
    
    ● **Résultat :** $\displaystyle 3x + 5x - 2x = 6x$
    $\\$

**Question 2 : Simplifier $\displaystyle 2x^2 + 3x - x^2 + 5x$**

    ● **Méthode :** Réduction de termes semblables
    $\\$
    
    ● **Étape 1 :** Identifier les termes semblables
        $\qquad$• Termes en $\displaystyle x^2$ : $\displaystyle 2x^2$ et $\displaystyle -x^2$
        $\\$
        $\qquad$• Termes en $\displaystyle x$ : $\displaystyle 3x$ et $\displaystyle 5x$
    $\\$
    
    ● **Étape 2 :** Grouper les termes semblables
        $\qquad$• $\displaystyle (2x^2 - x^2) + (3x + 5x)$
    $\\$
    
    ● **Étape 3 :** Réduire les coefficients
        $\qquad$• $\displaystyle (2 - 1)x^2 + (3 + 5)x = x^2 + 8x$
    $\\$
    
    ● **Résultat :** $\displaystyle 2x^2 + 3x - x^2 + 5x = x^2 + 8x$
    $\\$

**Question 3 : Simplifier $\displaystyle 4ab + 3ab - 2ab$**

    ● **Méthode :** Réduction de termes semblables
    $\\$
    
    ● **Étape 1 :** Identifier les termes semblables
        $\qquad$• Tous les termes ont la même partie littérale : $\displaystyle ab$
    $\\$
    
    ● **Étape 2 :** Grouper les termes semblables
        $\qquad$• $\displaystyle 4ab + 3ab - 2ab$
    $\\$
    
    ● **Étape 3 :** Réduire les coefficients
        $\qquad$• $\displaystyle (4 + 3 - 2)ab = 5ab$
    $\\$
    
    ● **Résultat :** $\displaystyle 4ab + 3ab - 2ab = 5ab$
    $\\$

**Question 4 : Simplifier $\displaystyle 3x^2 - 2x + x^2 + 4x - 1$**

    ● **Méthode :** Réduction de termes semblables
    $\\$
    
    ● **Étape 1 :** Identifier les termes semblables
        $\qquad$• Termes en $\displaystyle x^2$ : $\displaystyle 3x^2$ et $\displaystyle x^2$
        $\\$
        $\qquad$• Termes en $\displaystyle x$ : $\displaystyle -2x$ et $\displaystyle 4x$
        $\\$
        $\qquad$• Terme constant : $\displaystyle -1$
    $\\$
    
    ● **Étape 2 :** Grouper les termes semblables
        $\qquad$• $\displaystyle (3x^2 + x^2) + (-2x + 4x) - 1$
    $\\$
    
    ● **Étape 3 :** Réduire les coefficients
        $\qquad$• $\displaystyle (3 + 1)x^2 + (-2 + 4)x - 1 = 4x^2 + 2x - 1$
    $\\$
    
    ● **Résultat :** $\displaystyle 3x^2 - 2x + x^2 + 4x - 1 = 4x^2 + 2x - 1$
    $\\$

**Question 5 : Simplifier $\displaystyle 5y - 2y + 3y - y$**

    ● **Méthode :** Réduction de termes semblables
    $\\$
    
    ● **Étape 1 :** Identifier les termes semblables
        $\qquad$• Tous les termes ont la même partie littérale : $\displaystyle y$
    $\\$
    
    ● **Étape 2 :** Grouper les termes semblables
        $\qquad$• $\displaystyle 5y - 2y + 3y - y$
    $\\$
    
    ● **Étape 3 :** Réduire les coefficients
        $\qquad$• $\displaystyle (5 - 2 + 3 - 1)y = 5y$
    $\\$
    
    ● **Résultat :** $\displaystyle 5y - 2y + 3y - y = 5y$
    $\\$

Solution:
1. $\displaystyle 3x + 5x - 2x = 6x$
$\\$
2. $\displaystyle 2x^2 + 3x - x^2 + 5x = x^2 + 8x$
$\\$
3. $\displaystyle 4ab + 3ab - 2ab = 5ab$
$\\$
4. $\displaystyle 3x^2 - 2x + x^2 + 4x - 1 = 4x^2 + 2x - 1$
$\\$
5. $\displaystyle 5y - 2y + 3y - y = 5y$

=== Simplification - Fractions Algébriques
Difficulté: medium

Énoncé: Simplifier les fractions algébriques suivantes après avoir factorisé le numérateur et le dénominateur.

**Question 1 : Simplifier $\displaystyle \dfrac{6x}{3x}$ (avec $\displaystyle x \neq 0$)**
$\\$
**Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 4}{x + 2}$ (avec $\displaystyle x \neq -2$)**
$\\$
**Question 3 : Simplifier $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)**
$\\$
**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x - 1}$ (avec $\displaystyle x \neq 1$)**
$\\$
**Question 5 : Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2}$ (avec $\displaystyle x \neq -2$)**

Étapes:

**Question 1 : Simplifier $\displaystyle \dfrac{6x}{3x}$ (avec $\displaystyle x \neq 0$)**

    ● **Méthode :** Simplification par facteur commun
    $\\$
    
    ● **Étape 1 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle x$ (si $\displaystyle x \neq 0$)
    $\\$
    
    ● **Étape 2 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{6x}{3x} = \dfrac{6}{3} = 2$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 2$ : $\displaystyle \dfrac{6 \times 2}{3 \times 2} = \dfrac{12}{6} = 2$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{6x}{3x} = 2$ (si $\displaystyle x \neq 0$)
    $\\$

**Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 4}{x + 2}$ (avec $\displaystyle x \neq -2$)**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 - 4 = x^2 - 2^2 = (x - 2)(x + 2)$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x + 2)$ (si $\displaystyle x \neq -2$)
    $\\$
    
    ● **Étape 3 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 - 4}{x + 2} = \dfrac{(x - 2)(x + 2)}{x + 2} = x - 2$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 3$ : $\displaystyle \dfrac{9 - 4}{3 + 2} = \dfrac{5}{5} = 1$ et $\displaystyle 3 - 2 = 1$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 4}{x + 2} = x - 2$ (si $\displaystyle x \neq -2$)
    $\\$

**Question 3 : Simplifier $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 + 6x + 9 = (x + 3)^2$ (identité remarquable : $\displaystyle a^2 + 2ab + b^2 = (a + b)^2$ avec $\displaystyle a = x$ et $\displaystyle b = 3$)
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur
        $\qquad$• $\displaystyle x^2 - 9 = x^2 - 3^2 = (x - 3)(x + 3)$ (différence de carrés)
    $\\$
    
    ● **Étape 3 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x + 3)$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
    $\\$
    
    ● **Étape 4 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9} = \dfrac{(x + 3)^2}{(x - 3)(x + 3)} = \dfrac{x + 3}{x - 3}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{9}{-9} = -1$ et $\displaystyle \dfrac{3}{-3} = -1$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9} = \dfrac{x + 3}{x - 3}$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
    $\\$

**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x - 1}$ (avec $\displaystyle x \neq 1$)**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 - 1 = x^2 - 1^2 = (x - 1)(x + 1)$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x - 1)$ (si $\displaystyle x \neq 1$)
    $\\$
    
    ● **Étape 3 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 - 1}{x - 1} = \dfrac{(x - 1)(x + 1)}{x - 1} = x + 1$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 2$ : $\displaystyle \dfrac{4 - 1}{2 - 1} = \dfrac{3}{1} = 3$ et $\displaystyle 2 + 1 = 3$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 1}{x - 1} = x + 1$ (si $\displaystyle x \neq 1$)
    $\\$

**Question 5 : Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2}$ (avec $\displaystyle x \neq -2$)**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 + 4x + 4 = (x + 2)^2$ (identité remarquable : $\displaystyle a^2 + 2ab + b^2 = (a + b)^2$ avec $\displaystyle a = x$ et $\displaystyle b = 2$)
    $\\$
    
    ● **Étape 2 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x + 2)$ (si $\displaystyle x \neq -2$)
    $\\$
    
    ● **Étape 3 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} = \dfrac{(x + 2)^2}{x + 2} = x + 2$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{4}{2} = 2$ et $\displaystyle 0 + 2 = 2$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} = x + 2$ (si $\displaystyle x \neq -2$)
    $\\$

Solution:
1. $\displaystyle \dfrac{6x}{3x} = 2$ (si $\displaystyle x \neq 0$)
$\\$
2. $\displaystyle \dfrac{x^2 - 4}{x + 2} = x - 2$ (si $\displaystyle x \neq -2$)
$\\$
3. $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9} = \dfrac{x + 3}{x - 3}$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
$\\$
4. $\displaystyle \dfrac{x^2 - 1}{x - 1} = x + 1$ (si $\displaystyle x \neq 1$)
$\\$
5. $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} = x + 2$ (si $\displaystyle x \neq -2$)

=== Simplification - Avec Développement et Factorisation
Difficulté: medium

Énoncé: Simplifier les expressions suivantes en développant puis en réduisant, ou en utilisant les identités remarquables.

**Question 1 : Simplifier $\displaystyle (x+2)^2 - (x-1)^2$**
$\\$
**Question 2 : Simplifier $\displaystyle (x+1)(x-1) + x^2 - 1$**
$\\$
**Question 3 : Simplifier $\displaystyle 3(x+2) - 2(x-1) + x$**
$\\$
**Question 4 : Simplifier $\displaystyle (x+3)^2 - (x-2)^2$**
$\\$
**Question 5 : Simplifier $\displaystyle 4(x-1) + 2(x+3) - 3x$**

Étapes:

**Question 1 : Simplifier $\displaystyle (x+2)^2 - (x-1)^2$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+2)^2 = x^2 + 4x + 4$
        $\\$
        $\qquad$• $\displaystyle (x-1)^2 = x^2 - 2x + 1$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+2)^2 - (x-1)^2 = (x^2 + 4x + 4) - (x^2 - 2x + 1)$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 + 4x + 4 - x^2 + 2x - 1$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (4x + 2x) + (4 - 1)$
        $\\$
        $\qquad$• $\displaystyle = 6x + 3$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+2)^2 - (x-1)^2 = 6x + 3$
    $\\$

**Question 2 : Simplifier $\displaystyle (x+1)(x-1) + x^2 - 1$**

    ● **Méthode :** Reconnaître une identité remarquable puis réduire
    $\\$
    
    ● **Étape 1 :** Reconnaître une identité remarquable
        $\qquad$• $\displaystyle (x+1)(x-1) = x^2 - 1$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+1)(x-1) + x^2 - 1 = (x^2 - 1) + x^2 - 1$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 - 1 + x^2 - 1 = 2x^2 - 2$
    $\\$
    
    ● **Étape 4 :** Factoriser si possible
        $\qquad$• $\displaystyle = 2(x^2 - 1) = 2(x-1)(x+1)$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+1)(x-1) + x^2 - 1 = 2x^2 - 2 = 2(x^2 - 1)$
    $\\$

**Question 3 : Simplifier $\displaystyle 3(x+2) - 2(x-1) + x$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les parenthèses
        $\qquad$• $\displaystyle 3(x+2) = 3x + 6$
        $\\$
        $\qquad$• $\displaystyle 2(x-1) = 2x - 2$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle 3(x+2) - 2(x-1) + x = (3x + 6) - (2x - 2) + x$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = 3x + 6 - 2x + 2 + x$
        $\\$
        $\qquad$• $\displaystyle = (3x - 2x + x) + (6 + 2)$
        $\\$
        $\qquad$• $\displaystyle = 2x + 8$
    $\\$
    
    ● **Résultat :** $\displaystyle 3(x+2) - 2(x-1) + x = 2x + 8$
    $\\$

**Question 4 : Simplifier $\displaystyle (x+3)^2 - (x-2)^2$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+3)^2 = x^2 + 6x + 9$
        $\\$
        $\qquad$• $\displaystyle (x-2)^2 = x^2 - 4x + 4$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+3)^2 - (x-2)^2 = (x^2 + 6x + 9) - (x^2 - 4x + 4)$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 + 6x + 9 - x^2 + 4x - 4$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (6x + 4x) + (9 - 4)$
        $\\$
        $\qquad$• $\displaystyle = 10x + 5$
    $\\$
    
    ● **Étape 4 :** Factoriser si possible
        $\qquad$• $\displaystyle = 5(2x + 1)$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+3)^2 - (x-2)^2 = 10x + 5 = 5(2x + 1)$
    $\\$

**Question 5 : Simplifier $\displaystyle 4(x-1) + 2(x+3) - 3x$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les parenthèses
        $\qquad$• $\displaystyle 4(x-1) = 4x - 4$
        $\\$
        $\qquad$• $\displaystyle 2(x+3) = 2x + 6$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle 4(x-1) + 2(x+3) - 3x = (4x - 4) + (2x + 6) - 3x$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = 4x - 4 + 2x + 6 - 3x$
        $\\$
        $\qquad$• $\displaystyle = (4x + 2x - 3x) + (-4 + 6)$
        $\\$
        $\qquad$• $\displaystyle = 3x + 2$
    $\\$
    
    ● **Résultat :** $\displaystyle 4(x-1) + 2(x+3) - 3x = 3x + 2$
    $\\$

Solution:
1. $\displaystyle (x+2)^2 - (x-1)^2 = 6x + 3$
$\\$
2. $\displaystyle (x+1)(x-1) + x^2 - 1 = 2x^2 - 2 = 2(x^2 - 1)$
$\\$
3. $\displaystyle 3(x+2) - 2(x-1) + x = 2x + 8$
$\\$
4. $\displaystyle (x+3)^2 - (x-2)^2 = 10x + 5 = 5(2x + 1)$
$\\$
5. $\displaystyle 4(x-1) + 2(x+3) - 3x = 3x + 2$

=== Simplification - Produits et Quotients
Difficulté: medium

Énoncé: Simplifier les expressions suivantes contenant des produits ou des quotients de fractions.

**Question 1 : Simplifier $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x}$ (avec $\displaystyle x \neq 0$)**
$\\$
**Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)**
$\\$
**Question 3 : Simplifier $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x}$ (avec $\displaystyle x \neq 0$)**
$\\$
**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)**
$\\$
**Question 5 : Simplifier $\displaystyle \dfrac{6x}{5} \times \dfrac{10}{3x}$ (avec $\displaystyle x \neq 0$)**

Étapes:

**Question 1 : Simplifier $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x}$ (avec $\displaystyle x \neq 0$)**

    ● **Méthode :** Multiplier puis simplifier
    $\\$
    
    ● **Étape 1 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x} = \dfrac{2x \times 9}{3 \times 4x} = \dfrac{18x}{12x}$
    $\\$
    
    ● **Étape 2 :** Simplifier les facteurs communs
        $\qquad$• Facteur commun : $\displaystyle 6x$ (si $\displaystyle x \neq 0$)
        $\\$
        $\qquad$• $\displaystyle \dfrac{18x}{12x} = \dfrac{18}{12} = \dfrac{3}{2}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 2$ : $\displaystyle \dfrac{4}{3} \times \dfrac{9}{8} = \dfrac{36}{24} = \dfrac{3}{2}$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x} = \dfrac{3}{2}$ (si $\displaystyle x \neq 0$)
    $\\$

**Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)**

    ● **Méthode :** Factoriser puis multiplier et simplifier
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur de la première fraction
        $\qquad$• $\displaystyle x^2 - 1 = (x - 1)(x + 1)$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = \dfrac{(x - 1)(x + 1)}{x + 1} \times \dfrac{x + 2}{x - 1}$
    $\\$
    
    ● **Étape 3 :** Simplifier les facteurs communs
        $\qquad$• Facteurs communs : $\displaystyle (x + 1)$ et $\displaystyle (x - 1)$ (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
        $\\$
        $\qquad$• $\displaystyle = \dfrac{(x - 1)(x + 1)}{x + 1} \times \dfrac{x + 2}{x - 1} = \dfrac{(x + 2)}{1} = x + 2$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 2$ : $\displaystyle \dfrac{4 - 1}{3} \times \dfrac{4}{1} = \dfrac{3}{3} \times 4 = 1 \times 4 = 4$ et $\displaystyle 2 + 2 = 4$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = x + 2$ (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
    $\\$

**Question 3 : Simplifier $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x}$ (avec $\displaystyle x \neq 0$)**

    ● **Méthode :** Multiplier puis simplifier
    $\\$
    
    ● **Étape 1 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x} = \dfrac{3x \times 4}{2 \times x} = \dfrac{12x}{2x}$
    $\\$
    
    ● **Étape 2 :** Simplifier les facteurs communs
        $\qquad$• Facteur commun : $\displaystyle 2x$ (si $\displaystyle x \neq 0$)
        $\\$
        $\qquad$• $\displaystyle \dfrac{12x}{2x} = \dfrac{12}{2} = 6$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 2$ : $\displaystyle \dfrac{6}{2} \times \dfrac{4}{2} = 3 \times 2 = 6$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{3x}{2} \times \dfrac{4}{x} = 6$ (si $\displaystyle x \neq 0$)
    $\\$

**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3}$ (avec $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)**

    ● **Méthode :** Factoriser puis multiplier et simplifier
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur de la première fraction
        $\qquad$• $\displaystyle x^2 - 9 = x^2 - 3^2 = (x - 3)(x + 3)$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3} = \dfrac{(x - 3)(x + 3)}{x + 3} \times \dfrac{x + 1}{x - 3}$
    $\\$
    
    ● **Étape 3 :** Simplifier les facteurs communs
        $\qquad$• Facteurs communs : $\displaystyle (x + 3)$ et $\displaystyle (x - 3)$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
        $\\$
        $\qquad$• $\displaystyle = \dfrac{(x - 3)(x + 3)}{x + 3} \times \dfrac{x + 1}{x - 3} = \dfrac{x + 1}{1} = x + 1$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{-9}{3} \times \dfrac{1}{-3} = -3 \times \left(-\dfrac{1}{3}\right) = 1$ et $\displaystyle 0 + 1 = 1$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 9}{x + 3} \times \dfrac{x + 1}{x - 3} = x + 1$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
    $\\$

**Question 5 : Simplifier $\displaystyle \dfrac{6x}{5} \times \dfrac{10}{3x}$ (avec $\displaystyle x \neq 0$)**

    ● **Méthode :** Multiplier puis simplifier
    $\\$
    
    ● **Étape 1 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{6x}{5} \times \dfrac{10}{3x} = \dfrac{6x \times 10}{5 \times 3x} = \dfrac{60x}{15x}$
    $\\$
    
    ● **Étape 2 :** Simplifier les facteurs communs
        $\qquad$• Facteur commun : $\displaystyle 15x$ (si $\displaystyle x \neq 0$)
        $\\$

=== Simplification - Expressions Complexes
Difficulté: hard

Énoncé: Simplifier les expressions complexes suivantes nécessitant plusieurs étapes (développement, factorisation, réduction).

**Question 1 : Simplifier $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4}$**
$\\$
**Question 2 : Simplifier $\displaystyle (x+1)^2 - (x-1)^2 + 2x$**
$\\$
**Question 3 : Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4}$**
$\\$
**Question 4 : Simplifier $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2$**
$\\$
**Question 5 : Simplifier $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9}$**

Étapes:

**Question 1 : Simplifier $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4}$**

    ● **Méthode :** Développer, factoriser puis simplifier
    $\\$
    
    ● **Étape 1 :** Développer le numérateur
        $\qquad$• $\displaystyle (x+2)^2 - 4 = x^2 + 4x + 4 - 4 = x^2 + 4x$
    $\\$
    
    ● **Étape 2 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 + 4x = x(x + 4)$
    $\\$
    
    ● **Étape 3 :** Factoriser le dénominateur
        $\qquad$• $\displaystyle x^2 - 4 = x^2 - 2^2 = (x - 2)(x + 2)$ (différence de carrés)
    $\\$
    
    ● **Étape 4 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$
    $\\$
    
    ● **Note :** Il n'y a pas de facteur commun entre le numérateur et le dénominateur. L'expression est déjà simplifiée (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$).
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$ (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$)
    $\\$

**Question 2 : Simplifier $\displaystyle (x+1)^2 - (x-1)^2 + 2x$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+1)^2 = x^2 + 2x + 1$
        $\\$
        $\qquad$• $\displaystyle (x-1)^2 = x^2 - 2x + 1$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+1)^2 - (x-1)^2 + 2x = (x^2 + 2x + 1) - (x^2 - 2x + 1) + 2x$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 + 2x + 1 - x^2 + 2x - 1 + 2x$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (2x + 2x + 2x) + (1 - 1)$
        $\\$
        $\qquad$• $\displaystyle = 6x$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+1)^2 - (x-1)^2 + 2x = 6x$
    $\\$

**Question 3 : Simplifier $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4}$**

    ● **Méthode :** Factoriser puis multiplier et simplifier
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur de la première fraction
        $\qquad$• $\displaystyle x^2 + 4x + 4 = (x + 2)^2$ (identité remarquable)
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur de la deuxième fraction
        $\qquad$• $\displaystyle x^2 - 4 = (x - 2)(x + 2)$ (différence de carrés)
    $\\$
    
    ● **Étape 3 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = \dfrac{(x + 2)^2}{x + 2} \times \dfrac{x - 2}{(x - 2)(x + 2)}$
    $\\$
    
    ● **Étape 4 :** Simplifier les facteurs communs
        $\qquad$• Facteurs communs : $\displaystyle (x + 2)$ et $\displaystyle (x - 2)$ (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$)
        $\\$
        $\qquad$• $\displaystyle = \dfrac{(x + 2)^2}{x + 2} \times \dfrac{x - 2}{(x - 2)(x + 2)} = (x + 2) \times \dfrac{1}{(x + 2)} = 1$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{4}{2} \times \dfrac{-2}{-4} = 2 \times \dfrac{1}{2} = 1$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = 1$ (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$)
    $\\$

**Question 4 : Simplifier $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les parenthèses
        $\qquad$• $\displaystyle 2(x+3) = 2x + 6$
        $\\$
        $\qquad$• $\displaystyle 3(x-2) = 3x - 6$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2 = (2x + 6) - (3x - 6) + x^2 - x^2$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = 2x + 6 - 3x + 6 + x^2 - x^2$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (2x - 3x) + (6 + 6)$
        $\\$
        $\qquad$• $\displaystyle = -x + 12$
    $\\$
    
    ● **Résultat :** $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2 = -x + 12$
    $\\$

**Question 5 : Simplifier $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9}$**

    ● **Méthode :** Développer, factoriser puis simplifier
    $\\$
    
    ● **Étape 1 :** Développer le numérateur
        $\qquad$• $\displaystyle (x-3)^2 - 9 = x^2 - 6x + 9 - 9 = x^2 - 6x$
    $\\$
    
    ● **Étape 2 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 - 6x = x(x - 6)$
    $\\$
    
    ● **Étape 3 :** Factoriser le dénominateur
        $\qquad$• $\displaystyle x^2 - 6x + 9 = (x - 3)^2$ (identité remarquable)
    $\\$
    
    ● **Étape 4 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$
    $\\$
    
    ● **Note :** Il n'y a pas de facteur commun entre le numérateur et le dénominateur. L'expression est déjà simplifiée (si $\displaystyle x \neq 3$).
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$ (si $\displaystyle x \neq 3$)
    $\\$

Solution:
1. $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x + 4)}{(x - 2)(x + 2)}$ (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$)
$\\$
2. $\displaystyle (x+1)^2 - (x-1)^2 + 2x = 6x$
$\\$
3. $\displaystyle \dfrac{x^2 + 4x + 4}{x + 2} \times \dfrac{x - 2}{x^2 - 4} = 1$ (si $\displaystyle x \neq 2$ et $\displaystyle x \neq -2$)
$\\$
4. $\displaystyle 2(x+3) - 3(x-2) + x^2 - x^2 = -x + 12$
$\\$
5. $\displaystyle \dfrac{(x-3)^2 - 9}{x^2 - 6x + 9} = \dfrac{x(x - 6)}{(x - 3)^2}$ (si $\displaystyle x \neq 3$)

=== Simplification - Fractions Algébriques Avancées

**Question 3 : Simplifier $\displaystyle \dfrac{x^2 - 5x + 6}{x^2 - 4x + 4}$**

**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 8x + 16}{x^2 - 16}$**

**Question 5 : Simplifier $\displaystyle \dfrac{x^2 - 7x + 12}{x^2 - 9}$**

Étapes:

**Question 1 : Simplifier $\displaystyle \dfrac{x^2 + 5x + 6}{x^2 + 3x + 2}$**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• Chercher deux nombres dont la somme est $\displaystyle 5$ et le produit est $\displaystyle 6$
        $\\$
        $\qquad$• Les nombres sont $\displaystyle 2$ et $\displaystyle 3$ (car $\displaystyle 2 + 3 = 5$ et $\displaystyle 2 \times 3 = 6$)
        $\\$
        $\qquad$• $\displaystyle x^2 + 5x + 6 = (x + 2)(x + 3)$
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur
        $\qquad$• Chercher deux nombres dont la somme est $\displaystyle 3$ et le produit est $\displaystyle 2$
        $\\$
        $\qquad$• Les nombres sont $\displaystyle 1$ et $\displaystyle 2$ (car $\displaystyle 1 + 2 = 3$ et $\displaystyle 1 \times 2 = 2$)
        $\\$
        $\qquad$• $\displaystyle x^2 + 3x + 2 = (x + 1)(x + 2)$
    $\\$
    
    ● **Étape 3 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x + 2)$ (si $\displaystyle x \neq -1$ et $\displaystyle x \neq -2$)
    $\\$
    
    ● **Étape 4 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 + 5x + 6}{x^2 + 3x + 2} = \dfrac{(x + 2)(x + 3)}{(x + 1)(x + 2)} = \dfrac{x + 3}{x + 1}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{6}{2} = 3$ et $\displaystyle \dfrac{3}{1} = 3$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 + 5x + 6}{x^2 + 3x + 2} = \dfrac{x + 3}{x + 1}$ (si $\displaystyle x \neq -1$ et $\displaystyle x \neq -2$)
    $\\$

**Question 2 : Simplifier $\displaystyle \dfrac{x^2 - 6x + 9}{x^2 - 9}$**

    ● **Méthode :** Factorisation puis simplification
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur
        $\qquad$• $\displaystyle x^2 - 6x + 9 = (x - 3)^2$ (identité remarquable : $\displaystyle a^2 - 2ab + b^2 = (a - b)^2$ avec $\displaystyle a = x$ et $\displaystyle b = 3$)
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur
        $\qquad$• $\displaystyle x^2 - 9 = x^2 - 3^2 = (x - 3)(x + 3)$ (différence de carrés)
    $\\$
    
    ● **Étape 3 :** Identifier le facteur commun
        $\qquad$• Facteur commun : $\displaystyle (x - 3)$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)
    $\\$
    
    ● **Étape 4 :** Simplifier
        $\qquad$• $\displaystyle \dfrac{x^2 - 6x + 9}{x^2 - 9} = \dfrac{(x - 3)^2}{(x - 3)(x + 3)} = \dfrac{x - 3}{x + 3}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{9}{-9} = -1$ et $\displaystyle \dfrac{-3}{3} = -1$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 6x + 9}{x^2 - 9} = \dfrac{x - 3}{x + 3}$ (si $\displaystyle x \neq 3$ et $\displaystyle x \neq -3$)

**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 8x + 16}{x^2 - 16}$**

=== Simplification - Avec Identités Remarquables
Difficulté: medium

Énoncé: Simplifier les expressions suivantes en utilisant les identités remarquables.

**Question 1 : Simplifier $\displaystyle (x+5)^2 - (x-5)^2$**
$\\$
**Question 2 : Simplifier $\displaystyle (2x+1)^2 - (2x-1)^2$**
$\\$
**Question 3 : Simplifier $\displaystyle (x+3)(x-3) - x^2 + 9$**
$\\$
**Question 4 : Simplifier $\displaystyle (x+4)^2 - (x-2)^2$**
$\\$
**Question 5 : Simplifier $\displaystyle (3x+2)^2 - (3x-2)^2$**

Étapes:

**Question 1 : Simplifier $\displaystyle (x+5)^2 - (x-5)^2$**

    ● **Méthode :** Développer les identités remarquables puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+5)^2 = x^2 + 10x + 25$
        $\\$
        $\qquad$• $\displaystyle (x-5)^2 = x^2 - 10x + 25$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+5)^2 - (x-5)^2 = (x^2 + 10x + 25) - (x^2 - 10x + 25)$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 + 10x + 25 - x^2 + 10x - 25$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (10x + 10x) + (25 - 25)$
        $\\$
        $\qquad$• $\displaystyle = 20x$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+5)^2 - (x-5)^2 = 20x$
    $\\$

**Question 2 : Simplifier $\displaystyle (2x+1)^2 - (2x-1)^2$**

    ● **Méthode :** Développer les identités remarquables puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (2x+1)^2 = 4x^2 + 4x + 1$
        $\\$
        $\qquad$• $\displaystyle (2x-1)^2 = 4x^2 - 4x + 1$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (2x+1)^2 - (2x-1)^2 = (4x^2 + 4x + 1) - (4x^2 - 4x + 1)$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = 4x^2 + 4x + 1 - 4x^2 + 4x - 1$
        $\\$
        $\qquad$• $\displaystyle = (4x^2 - 4x^2) + (4x + 4x) + (1 - 1)$
        $\\$
        $\qquad$• $\displaystyle = 8x$
    $\\$
    
    ● **Résultat :** $\displaystyle (2x+1)^2 - (2x-1)^2 = 8x$
    $\\$

**Question 3 : Simplifier $\displaystyle (x+3)(x-3) - x^2 + 9$**

    ● **Méthode :** Utiliser l'identité remarquable puis réduire
    $\\$
    
    ● **Étape 1 :** Reconnaître une identité remarquable
        $\qquad$• $\displaystyle (x+3)(x-3) = x^2 - 9$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+3)(x-3) - x^2 + 9 = (x^2 - 9) - x^2 + 9$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 - 9 - x^2 + 9$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (-9 + 9)$
        $\\$
        $\qquad$• $\displaystyle = 0$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+3)(x-3) - x^2 + 9 = 0$
    $\\$

**Question 4 : Simplifier $\displaystyle (x+4)^2 - (x-2)^2$**

    ● **Méthode :** Développer les identités remarquables puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+4)^2 = x^2 + 8x + 16$
        $\\$
        $\qquad$• $\displaystyle (x-2)^2 = x^2 - 4x + 4$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+4)^2 - (x-2)^2 = (x^2 + 8x + 16) - (x^2 - 4x + 4)$

    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 + 8x + 16 - x^2 + 4x - 4$
        $\\$
        $\qquad$• $\displaystyle = (x^2 - x^2) + (8x + 4x) + (16 - 4)$
        $\\$
        $\qquad$• $\displaystyle = 12x + 12$
    $\\$
    
    ● **Étape 4 :** Factoriser si possible
        $\qquad$• $\displaystyle = 12(x + 1)$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+4)^2 - (x-2)^2 = 12x + 12 = 12(x + 1)$
    $\\$

**Question 5 : Simplifier $\displaystyle (3x+2)^2 - (3x-2)^2$**

    ● **Méthode :** Développer les identités remarquables puis réduire

    ● **Étape 1 :** Développer les carrés

=== Simplification - Expressions Mixtes
Difficulté: hard

Énoncé: Simplifier les expressions complexes suivantes nécessitant plusieurs techniques combinées.

**Question 1 : Simplifier $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3$**
$\\$
**Question 2 : Simplifier $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1}$ (avec $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)**
$\\$
**Question 3 : Simplifier $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2$**
$\\$
**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)**
$\\$
**Question 5 : Simplifier $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5$**

Étapes:

**Question 1 : Simplifier $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3$**

    ● **Méthode :** Utiliser l'identité remarquable, développer puis réduire
    $\\$
    
    ● **Étape 1 :** Reconnaître une identité remarquable
        $\qquad$• $\displaystyle (x+1)(x-1) = x^2 - 1$ (différence de carrés)
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3 = 3(x^2 - 1) + 2(x+1) - 3x^2 + 3$
    $\\$
    
    ● **Étape 3 :** Développer
        $\qquad$• $\displaystyle = 3x^2 - 3 + 2x + 2 - 3x^2 + 3$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = (3x^2 - 3x^2) + 2x + (-3 + 2 + 3)$
        $\\$
        $\qquad$• $\displaystyle = 2x + 2$
    $\\$
    
    ● **Étape 5 :** Factoriser si possible
        $\qquad$• $\displaystyle = 2(x + 1)$
    $\\$
    
    ● **Résultat :** $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3 = 2x + 2 = 2(x + 1)$
    $\\$

**Question 2 : Simplifier $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1}$ (avec $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)**
$\\$
    ● **Méthode :** Développer, factoriser puis multiplier et simplifier
    $\\$
    
    ● **Étape 1 :** Développer le numérateur de la première fraction
        $\qquad$• $\displaystyle (x+1)^2 - 1 = x^2 + 2x + 1 - 1 = x^2 + 2x = x(x + 2)$
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur de la deuxième fraction
        $\qquad$• $\displaystyle x^2 + 2x + 1 = (x + 1)^2$ (identité remarquable)
    $\\$
    
    ● **Étape 3 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1} = \dfrac{x(x + 2)}{x} \times \dfrac{x + 2}{(x + 1)^2}$
    $\\$
    
    ● **Étape 4 :** Simplifier les facteurs communs
        $\qquad$• Facteur commun : $\displaystyle x$ (si $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)
        $\\$
        $\qquad$• $\displaystyle = \dfrac{x(x + 2)}{x} \times \dfrac{x + 2}{(x + 1)^2} = (x + 2) \times \dfrac{x + 2}{(x + 1)^2} = \dfrac{(x + 2)^2}{(x + 1)^2}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 1$ : $\displaystyle \dfrac{4 - 1}{1} \times \dfrac{3}{4} = 3 \times \dfrac{3}{4} = \dfrac{9}{4}$ et $\displaystyle \dfrac{9}{4} = \dfrac{9}{4}$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1} = \dfrac{(x + 2)^2}{(x + 1)^2}$ (si $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)
    $\\$

**Question 3 : Simplifier $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer les carrés
        $\qquad$• $\displaystyle (x+2)^2 = x^2 + 4x + 4$
        $\\$
        $\qquad$• $\displaystyle (x-1)^2 = x^2 - 2x + 1$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2 = 2(x^2 + 4x + 4) - 3(x^2 - 2x + 1) + x^2 - x^2$
    $\\$
    
    ● **Étape 3 :** Développer
        $\qquad$• $\displaystyle = 2x^2 + 8x + 8 - 3x^2 + 6x - 3 + x^2 - x^2$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = (2x^2 - 3x^2 + x^2 - x^2) + (8x + 6x) + (8 - 3)$
        $\\$
        $\qquad$• $\displaystyle = -x^2 + 14x + 5$
    $\\$
    
    ● **Résultat :** $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2 = -x^2 + 14x + 5$
    $\\$

**Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1}$ (avec $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)**
$\\$
    ● **Méthode :** Factoriser puis multiplier et simplifier
    $\\$
    
    ● **Étape 1 :** Factoriser le numérateur de la première fraction
        $\qquad$• $\displaystyle x^2 - 2x + 1 = (x - 1)^2$ (identité remarquable)
    $\\$
    
    ● **Étape 2 :** Factoriser le dénominateur de la deuxième fraction
        $\qquad$• $\displaystyle x^2 - 1 = (x - 1)(x + 1)$ (différence de carrés)
    $\\$
    
    ● **Étape 3 :** Multiplier les fractions
        $\qquad$• $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1} = \dfrac{(x - 1)^2}{x - 1} \times \dfrac{x + 3}{(x - 1)(x + 1)}$
    $\\$
    
    ● **Étape 4 :** Simplifier les facteurs communs
        $\qquad$• Facteurs communs : $\displaystyle (x - 1)$ (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
        $\\$
        $\qquad$• $\displaystyle = \dfrac{(x - 1)^2}{x - 1} \times \dfrac{x + 3}{(x - 1)(x + 1)} = (x - 1) \times \dfrac{x + 3}{(x - 1)(x + 1)} = \dfrac{x + 3}{x + 1}$
    $\\$
    
    ● **Vérification :** Pour $\displaystyle x = 0$ : $\displaystyle \dfrac{1}{-1} \times \dfrac{3}{-1} = -1 \times (-3) = 3$ et $\displaystyle \dfrac{3}{1} = 3$ ✓
    $\\$
    
    ● **Résultat :** $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1} = \dfrac{x + 3}{x + 1}$ (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
    $\\$

**Question 5 : Simplifier $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5$**

    ● **Méthode :** Utiliser les identités remarquables puis réduire
    $\\$
    
    ● **Étape 1 :** Reconnaître les identités remarquables
        $\qquad$• $\displaystyle (x+2)(x-2) = x^2 - 4$ (différence de carrés)
        $\\$
        $\qquad$• $\displaystyle (x+1)^2 = x^2 + 2x + 1$
    $\\$
    
    ● **Étape 2 :** Substituer dans l'expression
        $\qquad$• $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5 = (x^2 - 4) + (x^2 + 2x + 1) - x^2 - 5$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = x^2 - 4 + x^2 + 2x + 1 - x^2 - 5$
        $\\$
        $\qquad$• $\displaystyle = (x^2 + x^2 - x^2) + 2x + (-4 + 1 - 5)$
        $\\$
        $\qquad$• $\displaystyle = x^2 + 2x - 8$
    $\\$
    
    ● **Résultat :** $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5 = x^2 + 2x - 8$
    $\\$

Solution:
1. $\displaystyle 3(x+1)(x-1) + 2(x+1) - 3x^2 + 3 = 2x + 2 = 2(x + 1)$
$\\$
2. $\displaystyle \dfrac{(x+1)^2 - 1}{x} \times \dfrac{x + 2}{x^2 + 2x + 1} = \dfrac{(x + 2)^2}{(x + 1)^2}$ (si $\displaystyle x \neq 0$ et $\displaystyle x \neq -1$)
$\\$
3. $\displaystyle 2(x+2)^2 - 3(x-1)^2 + x^2 - x^2 = -x^2 + 14x + 5$
$\\$
4. $\displaystyle \dfrac{x^2 - 2x + 1}{x - 1} \times \dfrac{x + 3}{x^2 - 1} = \dfrac{x + 3}{x + 1}$ (si $\displaystyle x \neq 1$ et $\displaystyle x \neq -1$)
$\\$
5. $\displaystyle (x+2)(x-2) + (x+1)^2 - x^2 - 5 = x^2 + 2x - 8$
