Titre: Carrés et racines carrées

<!-- optitab:1 -->
::: objectifs
- Calculer le carré d'un nombre (entier, décimal, fraction, nombre négatif) en respectant les priorités.
- Connaître les carrés parfaits de $1$ à $144$ et les reconnaître.
- Définir la racine carrée d'un nombre positif et la calculer : valeur exacte ou valeur approchée à la calculatrice.
- Encadrer une racine carrée entre deux entiers consécutifs, puis plus finement ; comparer des racines carrées.
- Passer de l'aire d'un carré à son côté et résoudre une équation du type $x^2 = a$.
- Préparer le théorème de Pythagore : additionner des aires de carrés.
:::

## I. Le carré d'un nombre

::: definition Carré d'un nombre
Le **carré** d'un nombre $a$ est le produit de ce nombre par lui-même :
$$a^2 = a \times a$$
On lit « $a$ au carré ». Si $a$ est une longueur, $a^2$ est l'**aire** d'un carré de côté $a$.
:::

::: exemple
- $7^2 = 7 \times 7 = 49$
- $0{,}3^2 = 0{,}3 \times 0{,}3 = 0{,}09$
- $\left(\dfrac{2}{3}\right)^2 = \dfrac{2}{3} \times \dfrac{2}{3} = \dfrac{4}{9}$
- $(-6)^2 = (-6) \times (-6) = 36$
:::

::: propriete Signe d'un carré
Un carré est toujours **positif ou nul** : le produit de deux nombres de même signe est positif. Un nombre et son opposé ont le même carré : $(-6)^2 = 6^2 = 36$.
:::

::: attention Parenthèses et priorités
- $(-6)^2 = 36$, mais $-6^2 = -(6 \times 6) = -36$ : sans parenthèses, le carré ne porte que sur $6$.
- $2 \times 3^2 = 2 \times 9 = 18$, mais $(2 \times 3)^2 = 6^2 = 36$.
- $3^2 + 4^2 = 9 + 16 = 25$, mais $(3 + 4)^2 = 7^2 = 49$.
- $5^2 = 25$ : ne pas confondre avec $2 \times 5 = 10$.
:::

### Les carrés parfaits

::: definition Carré parfait
Un **carré parfait** est le carré d'un nombre entier : $0$ ; $1$ ; $4$ ; $9$ ; $16$ ; $25$… Avec des petits carreaux, on peut en faire un carré.
:::

[IMAGE_1]

::: retenir Les carrés parfaits à connaître par cœur
| $n$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|
| $n^2$ | $1$ | $4$ | $9$ | $16$ |

| $n$ | $5$ | $6$ | $7$ | $8$ |
|---|---|---|---|---|
| $n^2$ | $25$ | $36$ | $49$ | $64$ |

| $n$ | $9$ | $10$ | $11$ | $12$ |
|---|---|---|---|---|
| $n^2$ | $81$ | $100$ | $121$ | $144$ |

Utiles aussi : $13^2 = 169$ ; $14^2 = 196$ ; $15^2 = 225$.
:::

## II. La racine carrée d'un nombre positif

::: definition Racine carrée
Soit $a$ un nombre **positif ou nul**. La **racine carrée** de $a$, notée $\sqrt{a}$, est le nombre **positif** dont le carré est égal à $a$ :
$$\left(\sqrt{a}\right)^2 = a \qquad \text{et} \qquad \sqrt{a} \geq 0$$
Le symbole $\sqrt{\phantom{a}}$ s'appelle le **radical**.
:::

::: exemple
- $\sqrt{49} = 7$ car $7^2 = 49$ et $7 \geq 0$.
- $\sqrt{0} = 0$ et $\sqrt{1} = 1$.
- $\sqrt{0{,}25} = 0{,}5$ car $0{,}5^2 = 0{,}25$.
- $\sqrt{\dfrac{9}{16}} = \dfrac{3}{4}$ car $\left(\dfrac{3}{4}\right)^2 = \dfrac{9}{16}$.
:::

::: propriete Racine carrée d'un carré
Pour tout nombre $a$ positif ou nul :
$$\sqrt{a^2} = a \qquad \text{et} \qquad \left(\sqrt{a}\right)^2 = a$$
La racine carrée « défait » le carré. Par exemple $\sqrt{13^2} = 13$ et $\left(\sqrt{5}\right)^2 = 5$.
:::

### Racine carrée et aire d'un carré

::: propriete Côté d'un carré
Un carré d'aire $A$ a pour côté $\sqrt{A}$ (dans l'unité de longueur correspondante).
:::

[IMAGE_2]

::: exemple
- Un carré d'aire $25$ cm² a un côté de $\sqrt{25} = 5$ cm.
- Un carré d'aire $20$ cm² a un côté de $\sqrt{20}$ cm : ce n'est pas un nombre entier, la calculatrice donne $\sqrt{20} \approx 4{,}47$.
:::

::: attention
- $\sqrt{-4}$ **n'existe pas** : aucun nombre n'a un carré négatif.
- La racine carrée n'est **pas** la moitié : $\sqrt{16} = 4$, mais $\sqrt{36} = 6$, et non $18$.
- La racine d'une somme n'est pas la somme des racines : $\sqrt{9 + 16} = \sqrt{25} = 5$, alors que $\sqrt{9} + \sqrt{16} = 3 + 4 = 7$.
:::

## III. Encadrer et approcher une racine carrée

::: propriete Comparer avec les carrés
Deux nombres **positifs** sont rangés dans le même ordre que leurs carrés. Pour comparer deux nombres positifs, on peut donc comparer leurs carrés.
:::

::: methode Encadrer une racine carrée entre deux entiers
1. Chercher les deux carrés parfaits consécutifs qui entourent le nombre $a$.
2. Prendre leurs racines : elles encadrent $\sqrt{a}$.
:::

::: exemple Encadrer $\sqrt{20}$
$20$ est entre les carrés parfaits $16$ et $25$ :
$$4^2 = 16 < 20 < 25 = 5^2$$
donc :
$$4 < \sqrt{20} < 5$$
:::

::: methode Affiner l'encadrement au dixième
On essaie les nombres $4{,}1$ ; $4{,}2$ ; … et on calcule leurs carrés jusqu'à dépasser $20$ :
$$4{,}4^2 = 19{,}36 < 20 < 20{,}25 = 4{,}5^2$$
donc :
$$4{,}4 < \sqrt{20} < 4{,}5$$
:::

[IMAGE_3]

### Valeur exacte et valeur approchée

::: definition
$\sqrt{20}$ est la **valeur exacte** du côté du carré d'aire $20$. La calculatrice affiche $4{,}472\,135\ldots$ : c'est une **valeur approchée**. On écrit $\sqrt{20} \approx 4{,}47$ (arrondi au centième) ou $\sqrt{20} \approx 4{,}5$ (arrondi au dixième).
:::

::: attention Ne pas écrire « $=$ » avec une valeur approchée
$4{,}47^2 = 19{,}980\,9$ : ce n'est pas $20$. On écrit donc $\sqrt{20} \approx 4{,}47$, jamais $\sqrt{20} = 4{,}47$. Dans un calcul, on garde la valeur exacte et on n'arrondit qu'à la fin.
:::

::: exemple Comparer $\sqrt{30}$ et $5{,}5$
Ces deux nombres sont positifs. On compare leurs carrés : $\left(\sqrt{30}\right)^2 = 30$ et $5{,}5^2 = 30{,}25$. Comme $30 < 30{,}25$, on a $\sqrt{30} < 5{,}5$.
:::

## IV. Les nombres qui ont un carré donné

::: propriete Équation $x^2 = a$
- Si $a > 0$ : l'équation $x^2 = a$ a **deux solutions**, $\sqrt{a}$ et $-\sqrt{a}$.
- Si $a = 0$ : une seule solution, $0$.
- Si $a < 0$ : **aucune solution**, car un carré n'est jamais négatif.
:::

::: exemple
- $x^2 = 49$ : deux solutions, $x = 7$ ou $x = -7$.
- $x^2 = 7$ : deux solutions, $x = \sqrt{7}$ ou $x = -\sqrt{7}$ ; valeurs approchées $\approx 2{,}65$ et $\approx -2{,}65$.
- $x^2 = -3$ : aucune solution.
:::

::: methode Se ramener à $x^2 = a$
On isole $x^2$, puis on applique la propriété.
$$
\begin{aligned}
3x^2 &= 75 \\
x^2 &= 75 \div 3 \\
x^2 &= 25
\end{aligned}
$$
Les solutions sont $x = 5$ et $x = -5$.
:::

::: attention Une longueur est positive
Si $c$ est le côté d'un carré d'aire $64$ cm², alors $c^2 = 64$. L'équation a deux solutions, $8$ et $-8$, mais une longueur est positive : on garde seulement $c = 8$ cm.
:::

## V. Vers le théorème de Pythagore

On construit un carré sur chaque côté d'un triangle dont les côtés mesurent $3$ cm, $4$ cm et $5$ cm. Les deux petits carrés ont pour aires $9$ cm² et $16$ cm², et le grand carré a pour aire $25$ cm² : c'est exactement la somme des deux autres.

[IMAGE_4]

::: remarque À suivre
Quand deux carrés ont pour aires $9$ et $16$, le carré dont l'aire est leur somme a pour côté :
$$\sqrt{9 + 16} = \sqrt{25} = 5 \qquad \text{et non} \qquad 3 + 4 = 7$$
Le **théorème de Pythagore** (chapitre suivant) explique dans quels triangles on retrouve cette égalité entre aires : on calculera alors des longueurs avec des racines carrées.
:::

::: retenir
- $a^2 = a \times a$ est toujours positif ou nul ; $(-a)^2 = a^2$.
- Carrés parfaits : $1$ ; $4$ ; $9$ ; $16$ ; $25$ ; $36$ ; $49$ ; $64$ ; $81$ ; $100$ ; $121$ ; $144$.
- Pour $a \geq 0$, $\sqrt{a}$ est le nombre **positif** dont le carré vaut $a$ ; $\sqrt{a}$ n'existe pas si $a < 0$.
- Côté d'un carré d'aire $A$ : $\sqrt{A}$.
- On encadre $\sqrt{a}$ avec les carrés parfaits ; on garde la valeur exacte et on arrondit à la fin avec $\approx$.
- $x^2 = a$ avec $a > 0$ : deux solutions $\sqrt{a}$ et $-\sqrt{a}$ (une longueur : seulement $\sqrt{a}$).
- $\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$ en général.
:::
