=== Découverte - Développer, réduire et démontrer - 1. Les rectangles découpés
Id: 2873
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un rectangle a une hauteur de 2 cm et une largeur de $(x+2)$ cm, avec $x$ strictement positif. On le partage en deux rectangles de largeurs $x$ cm et 2 cm.

Pour lire le schéma de principe, prendre $k=2$ et $b=2$.

[IMAGE_1]

1. Exprimer l’aire du grand rectangle avec des parenthèses.
2. Exprimer séparément les aires des deux petits rectangles.
3. En déduire une expression développée de l’aire totale.
4. Calculer l’aire lorsque $x=3$, avec les deux expressions.
5. Un élève propose 2x + 2. Expliquer son erreur.
6. Si x augmente de 1 cm, de combien l’aire augmente-t-elle ? Justifier pour toute valeur de $x$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Exprimer l’aire du grand rectangle avec des parenthèses.

::: methode
Multiplier toute la largeur par la hauteur.
:::

::: etape L’aire du rectangle entier
La largeur vaut $(x+2)$ cm et la hauteur 2 cm.
:::

::: resultat
L’aire vaut $2(x+2)$ cm².
:::

## Question 2 : Exprimer séparément les aires des deux petits rectangles.

::: methode
Utiliser la hauteur commune et la largeur de chaque morceau.
:::

::: etape Les aires des deux morceaux
$$
\begin{aligned}
A_1&=2\times x=2x \\
A_2&=2\times2=4
\end{aligned}
$$
:::

::: resultat
Les deux aires sont $2x$ cm² et $4$ cm².
:::

## Question 3 : En déduire une expression développée de l’aire totale.

::: methode
Additionner les aires des deux morceaux.
:::

::: etape Utiliser l’additivité des aires
Les rectangles recouvrent exactement la figure, sans chevauchement.
$$2(x+2)=2x+4$$
:::

::: resultat
La forme développée de l’aire est $2x+4$ cm².
:::

## Question 4 : Calculer l’aire lorsque $x=3$, avec les deux expressions.

::: methode
Calculer séparément les deux expressions pour la même valeur.
:::

::: etape Deux calculs indépendants
$$
\begin{aligned}
2(3+2)&=2\times5=10 \\
2\times3+4&=6+4=10
\end{aligned}
$$
:::

::: resultat
Les deux expressions donnent 10 cm².
:::

## Question 5 : Un élève propose 2x + 2. Expliquer son erreur.

::: methode
Contrôler que le facteur multiplie chaque terme.
:::

::: etape Repérer le facteur oublié
Le morceau fixe a une largeur de 2 cm et une hauteur de 2 cm. Son aire est $2\times2=4$ cm².
:::

::: resultat
Le terme constant est $4$, car $2$ doit aussi être multiplié par $2$.
:::

## Question 6 : Si x augmente de 1 cm, de combien l’aire augmente-t-elle ? Justifier pour toute valeur de $x$.

::: methode
Raisonner sur la bande ajoutée pour toute valeur de la lettre.
:::

::: etape Raisonner sur la bande ajoutée
Lorsque $x$ augmente de 1, on ajoute une bande de largeur 1 cm et de hauteur 2 cm. Son aire vaut $2\times1=2$ cm².
:::

::: resultat
L’aire augmente de 2 cm², quelle que soit la valeur initiale de $x$.
:::

::: retenir Le bon réflexe
Le facteur multiplie chaque terme de la parenthèse. Une preuve avec une lettre explique le cas général ; un test ne le remplace pas.
:::

[IMAGE_2]

Solution:
<!-- optitab:1 -->
1. L’aire vaut $2(x+2)$ cm².
2. Les deux aires sont $2x$ cm² et $4$ cm².
3. La forme développée de l’aire est $2x+4$ cm².
4. Les deux expressions donnent 10 cm².
5. Le terme constant est $4$, car $2$ doit aussi être multiplié par $2$.
6. L’aire augmente de 2 cm², quelle que soit la valeur initiale de $x$.

=== Découverte - Calcul littéral - Somme ou produit
Id: 2875
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Repérer la dernière opération, puis appliquer la distributivité lorsque c’est utile.

1. Préciser la nature de $3(x+2)$, $3x+2$, $5x-4$ et $7x$.
2. Développer $3(x+2)$.
3. Pour x = 4, vérifier que les deux écritures précédentes donnent le même résultat.
4. Pourquoi $3x+2$ n’est-il pas le développement de $3(x+2)$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Préciser la nature de $3(x+2)$, $3x+2$, $5x-4$ et $7x$.

::: methode
La dernière opération donne la nature de l’expression.
:::

::: etape Regarder la structure extérieure
$3(x+2)$ et $7x$ sont des produits ; $3x+2$ est une somme ; $5x-4$ est une différence.
:::

::: resultat
Produit ; somme ; différence ; produit.
:::

## Question 2 : Développer $3(x+2)$.

::: methode
Multiplier chacun des termes par 3.
:::

::: etape Distribuer le facteur
$3(x+2)=3\times x+3\times2$.
:::

::: etape Calculer les produits
$3(x+2)=3x+6$.
:::

::: resultat
$3x+6$.
:::

## Question 3 : Pour x = 4, vérifier que les deux écritures précédentes donnent le même résultat.

::: methode
Calculer chaque écriture indépendamment.
:::

::: etape Avec les parenthèses
$3(4+2)=3\times6=18$.
:::

::: etape Avec la forme développée
$3\times4+6=12+6=18$.
:::

::: resultat
Les deux valeurs sont 18.
:::

## Question 4 : Pourquoi $3x+2$ n’est-il pas le développement de $3(x+2)$ ?

::: methode
Contrôler aussi le terme constant.
:::

::: etape Repérer le facteur oublié
Le nombre 2 est lui aussi multiplié par 3, ce qui donne 6.
:::

::: etape Un test qui distingue les expressions
Pour x = 4, $3x+2=14$, et non 18.
:::

::: resultat
Le terme constant doit être 6, pas 2.
:::

::: retenir Le bon réflexe
Dans un développement, aucun terme de la parenthèse ne doit être oublié.
:::

Solution:
<!-- optitab:1 -->
1. Produit ; somme ; différence ; produit.
2. $3x+6$.
3. Les deux valeurs sont 18.
4. Le terme constant doit être 6, pas 2.

=== Découverte - Calcul littéral - Réduire sans mélanger
Id: 2877
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Regrouper uniquement des termes de même nature.

1. Réduire $2x+5x$.
2. Réduire $3x+4+x+2$.
3. Réduire $7x-2x+3$.
4. Un élève remplace $4x+3$ par $7x$. Trouver un contre-exemple.

Étapes:
<!-- optitab:1 -->
## Question 1 : Réduire $2x+5x$.

::: methode
Additionner les coefficients des mêmes multiples de x.
:::

::: etape Compter les multiples
$2x+5x=(2+5)x=7x$.
:::

::: resultat
$7x$.
:::

## Question 2 : Réduire $3x+4+x+2$.

::: methode
Regrouper les multiples de x et les nombres constants.
:::

::: etape Former les deux groupes
$(3x+x)+(4+2)$.
:::

::: etape Réduire
$4x+6$.
:::

::: resultat
$4x+6$.
:::

## Question 3 : Réduire $7x-2x+3$.

::: methode
Soustraire les coefficients et garder le terme constant.
:::

::: etape Réunir les termes de même nature
$(7-2)x+3=5x+3$.
:::

::: resultat
$5x+3$.
:::

## Question 4 : Un élève remplace $4x+3$ par $7x$. Trouver un contre-exemple.

::: methode
Choisir une valeur simple et comparer.
:::

::: etape Prendre x = 2
$4\times2+3=11$, tandis que $7\times2=14$.
:::

::: etape Conclure
$11\ne14$ : les deux expressions ne sont pas identiques.
:::

::: resultat
Pour $x=2$, on obtient 11 et 14 : la réduction proposée est fausse.
:::

::: retenir Le bon réflexe
On ne peut pas additionner un nombre de fois x et un nombre constant comme s’ils avaient la même nature.
:::

Solution:
<!-- optitab:1 -->
1. $7x$.
2. $4x+6$.
3. $5x+3$.
4. Pour $x=2$, on obtient 11 et 14 : la réduction proposée est fausse.

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer $5(x-2)$.

::: methode
Distribuer le facteur sur la différence.
:::

::: etape Multiplier chaque terme

::: etape Écrire la forme développée
$5x-10$.
:::

::: etape Distribuer
$2{,}5x+2{,}5\times4$.
:::

::: etape Calculer le terme constant
$2{,}5\times4=10$, donc $2{,}5x+10$.
:::

::: resultat
$2{,}5x+10$.

::: etape Réduire

::: resultat
$7x+3$.

::: etape Développer

::: resultat

=== Entraînement - Calcul littéral - Retrouver un facteur commun
Id: 2882
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser signifie écrire une expression sous la forme d’un produit.

1. Factoriser $6x+18$.
2. Factoriser $15x-10$.
3. Réduire puis factoriser $4x+12+2x+6$.
4. Pour x = 5, vérifier la factorisation de $6x+18$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Factoriser $6x+18$.

::: methode
Repérer le facteur 6 dans les deux termes.
:::

::: etape Rendre le facteur visible
$6x+18=6\times x+6\times3$.
:::

::: etape Mettre en facteur
$6(x+3)$.
:::

::: resultat
$6(x+3)$.
:::

## Question 2 : Factoriser $15x-10$.

::: methode
Repérer le facteur 5.
:::

::: etape Décomposer les coefficients
$15x-10=5\times3x-5\times2$.
:::

::: etape Mettre en facteur
$5(3x-2)$.
:::

::: resultat
$5(3x-2)$.
:::

## Question 3 : Réduire puis factoriser $4x+12+2x+6$.

::: methode
Regrouper avant de chercher un facteur commun.
:::

::: etape Réduire la somme
$4x+2x+12+6=6x+18$.
:::

::: etape Factoriser
$6x+18=6(x+3)$.
:::

::: resultat
$6(x+3)$.
:::

## Question 4 : Pour x = 5, vérifier la factorisation de $6x+18$.

::: methode
Calculer séparément la somme et le produit.
:::

::: etape Dans la somme
$6\times5+18=30+18=48$.
:::

::: etape Dans le produit
$6(5+3)=6\times8=48$.
:::

::: resultat
Les deux écritures donnent 48.
:::

::: retenir Le bon réflexe
Le facteur mis devant la parenthèse doit multiplier tout ce qui reste à l’intérieur. Redévelopper permet de contrôler une factorisation.
:::

Solution:
<!-- optitab:1 -->
1. $6(x+3)$.
2. $5(3x-2)$.
3. $6(x+3)$.
4. Les deux écritures donnent 48.

=== Problème - Calcul littéral - Démontrer et réfuter
Id: 2887
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Les lettres n, p et q désignent des entiers positifs ou nuls.

1. Écrire un nombre pair et un nombre impair à l’aide de n.
2. Montrer que la somme de deux entiers consécutifs est impaire.
3. Montrer que la somme de trois entiers consécutifs est un multiple de 3.
4. « La somme de deux carrés est toujours un carré. » Donner un contre-exemple.
5. Pourquoi les écritures avec n prouvent-elles les deux propriétés, alors que quelques exemples ne suffisent pas ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Écrire un nombre pair et un nombre impair à l’aide de n.

::: methode
Traduire pair par multiple de 2.
:::

::: etape Un nombre pair
Un multiple de 2 s’écrit $2n$.
:::

::: etape Un nombre impair
Le nombre suivant s’écrit $2n+1$.
:::

::: resultat
Pair : $2n$ ; impair : $2n+1$.
:::

## Question 2 : Montrer que la somme de deux entiers consécutifs est impaire.

::: methode
Écrire les deux entiers avec une même lettre.
:::

::: etape Écrire la somme
Les entiers sont n et n+1 ; leur somme est $n+(n+1)$.
:::

::: etape Reconnaître un impair
$n+n+1=2n+1$, forme d’un nombre impair.
:::

::: resultat
La somme vaut $2n+1$, donc elle est impaire.
:::

## Question 3 : Montrer que la somme de trois entiers consécutifs est un multiple de 3.

::: methode
Faire apparaître un facteur 3.
:::

::: etape Réduire la somme
$n+(n+1)+(n+2)=3n+3$.
:::

::: etape Factoriser et interpréter
$3n+3=3(n+1)$. Comme n+1 est entier, la somme est un multiple de 3.
:::

::: resultat
La somme vaut $3(n+1)$.
:::

## Question 4 : « La somme de deux carrés est toujours un carré. » Donner un contre-exemple.

::: methode
Un seul cas faux suffit à réfuter une affirmation universelle.
:::

::: etape Choisir deux carrés simples
$1^2+2^2=1+4=5$.
:::

::: etape Montrer que 5 n’est pas un carré entier
$2^2=4<5<9=3^2$.
:::

::: resultat
Faux : $1^2+2^2=5$ n’est pas un carré entier.
:::

## Question 5 : Pourquoi les écritures avec n prouvent-elles les deux propriétés, alors que quelques exemples ne suffisent pas ?

::: methode
Distinguer un calcul général et des tests particuliers.
:::

::: etape Préciser la portée du raisonnement
Aucune valeur particulière n’a été imposée à n dans les deux démonstrations. Les transformations valent pour tout entier n du domaine annoncé.
:::

::: resultat
Les démonstrations s’appliquent à tous les entiers concernés ; les tests ne portent que sur les valeurs choisies.
:::

::: attention Le bon réflexe
Pour prouver une affirmation générale, expliquer pourquoi elle vaut pour toutes les valeurs. Pour la réfuter, un seul contre-exemple bien justifié suffit.
:::

Solution:
<!-- optitab:1 -->
1. Pair : $2n$ ; impair : $2n+1$.
2. La somme vaut $2n+1$, donc elle est impaire.
3. La somme vaut $3(n+1)$.
4. Faux : $1^2+2^2=5$ n’est pas un carré entier.
5. Les démonstrations s’appliquent à tous les entiers concernés ; les tests ne portent que sur les valeurs choisies.

## Question 6 : Si x augmente de 1 cm, de combien l’aire augmente-t-elle ? Justifier pour toute valeur de $x$.

::: methode
Raisonner sur la bande ajoutée pour toute valeur de la lettre.
:::

::: etape Raisonner sur la bande ajoutée
Lorsque $x$ augmente de 1, on ajoute une bande de largeur 1 cm et de hauteur 4 cm. Son aire vaut $4\times1=4$ cm².
:::

::: resultat
L’aire augmente de 4 cm², quelle que soit la valeur initiale de $x$.
:::

::: retenir Le bon réflexe
Le facteur multiplie chaque terme de la parenthèse. Une preuve avec une lettre explique le cas général ; un test ne le remplace pas.
:::

[IMAGE_2]

Solution:
<!-- optitab:1 -->
1. L’aire vaut $4(x+7)$ cm².
2. Les deux aires sont $4x$ cm² et $28$ cm².
3. La forme développée de l’aire est $4x+28$ cm².
4. Les deux expressions donnent 68 cm².
5. Le terme constant est $28$, car $7$ doit aussi être multiplié par $4$.
6. L’aire augmente de 4 cm², quelle que soit la valeur initiale de $x$.

=== Problème - Calcul littéral - Deux programmes équivalents
Id: 2893
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On choisit un nombre positif x. Programme A : multiplier par 3, ajouter 4, puis multiplier le résultat par 2. Programme B : ajouter 1, multiplier le résultat par 6, puis ajouter 2.

1. Écrire une expression du résultat de chaque programme.
2. Développer et réduire chaque expression.
3. Contrôler les résultats pour x = 2 en suivant les programmes.
4. Les deux programmes donnent-ils toujours le même résultat ? Justifier.
5. Un troisième programme multiplie x par 6 puis ajoute 6. Est-il équivalent aux deux premiers ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Écrire une expression du résultat de chaque programme.

::: methode
Traduire les opérations dans leur ordre, en gardant les parenthèses.
:::

::: etape Programme A
Après les deux premières opérations, on a $3x+4$ ; le résultat final est $2(3x+4)$.
:::

::: etape Programme B
Le résultat est $6(x+1)+2$.
:::

::: resultat
A : $2(3x+4)$ ; B : $6(x+1)+2$.
:::

## Question 2 : Développer et réduire chaque expression.

::: methode
Utiliser la distributivité sur les deux parenthèses.
:::

::: etape Développer A
$2(3x+4)=6x+8$.
:::

::: etape Développer B
$6(x+1)+2=6x+6+2=6x+8$.
:::

::: resultat
Les deux expressions se réduisent à $6x+8$.
:::

## Question 3 : Contrôler les résultats pour x = 2 en suivant les programmes.

::: methode
Refaire les opérations sans utiliser la forme réduite.
:::

::: etape Suivre A
$2\times3=6$, puis $6+4=10$, puis $10\times2=20$.
:::

::: etape Suivre B
$2+1=3$, puis $3\times6=18$, puis $18+2=20$.
:::

::: resultat
Les deux programmes donnent 20.
:::

## Question 4 : Les deux programmes donnent-ils toujours le même résultat ? Justifier.

::: methode
S’appuyer sur l’identité littérale, pas seulement sur le test.
:::

::: etape Utiliser la forme commune
Pour toute valeur autorisée de x, les deux programmes produisent l’expression $6x+8$. Ce sont donc deux façons de calculer le même nombre.
:::

::: resultat
Oui, car les deux expressions sont identiques pour tout x positif.
:::

## Question 5 : Un troisième programme multiplie x par 6 puis ajoute 6. Est-il équivalent aux deux premiers ?

::: methode
Chercher une valeur qui distingue les résultats.
:::

::: etape Tester avec x = 2
Le troisième donne $6\times2+6=18$, alors que A et B donnent 20.
:::

::: etape Conclure
$18\ne20$ : les programmes ne sont pas équivalents.
:::

::: resultat
Non : x = 2 donne un contre-exemple.
:::

::: attention Le bon réflexe
Un test peut montrer que deux programmes diffèrent. Pour démontrer qu’ils sont toujours équivalents, on transforme leurs expressions littérales.
:::

Solution:
<!-- optitab:1 -->
1. A : $2(3x+4)$ ; B : $6(x+1)+2$.
2. Les deux expressions se réduisent à $6x+8$.
3. Les deux programmes donnent 20.
4. Oui, car les deux expressions sont identiques pour tout x positif.
5. Non : x = 2 donne un contre-exemple.
