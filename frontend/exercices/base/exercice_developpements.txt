=== Développements - Distributivité Simple
Difficulté: easy

Énoncé: Développer les expressions suivantes en utilisant la distributivité simple.

**Question 1 : Développer $\displaystyle 3(x + 4)$**
$\\$
**Question 2 : Développer $\displaystyle -2(3x - 5)$**
$\\$
**Question 3 : Développer $\displaystyle 5(2x + 1)$**
$\\$
**Question 4 : Développer $\displaystyle 4(x^2 - 2x + 3)$**
$\\$
**Question 5 : Développer $\displaystyle -3(4x - 7)$**

Étapes:

**Question 1 : Développer $\displaystyle 3(x + 4)$**

    ● **Méthode :** Distributivité simple $\displaystyle k(a + b) = ka + kb$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• Facteur extérieur : $\displaystyle k = 3$
        $\\$
        $\qquad$• Termes dans la parenthèse : $\displaystyle a = x$ et $\displaystyle b = 4$
    $\\$
    
    ● **Étape 2 :** Appliquer la distributivité
        $\qquad$• $\displaystyle 3(x + 4) = 3 \times x + 3 \times 4$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = 3x + 12$
    $\\$
    
    ● **Résultat :** $\displaystyle 3(x + 4) = 3x + 12$
    $\\$

**Question 2 : Développer $\displaystyle -2(3x - 5)$**

    ● **Méthode :** Distributivité simple avec attention aux signes
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• Facteur extérieur : $\displaystyle k = -2$
        $\\$
        $\qquad$• Termes dans la parenthèse : $\displaystyle a = 3x$ et $\displaystyle b = -5$
    $\\$
    
    ● **Étape 2 :** Appliquer la distributivité
        $\qquad$• $\displaystyle -2(3x - 5) = (-2) \times 3x + (-2) \times (-5)$
    $\\$
    
    ● **Étape 3 :** Calculer en faisant attention aux signes
        $\qquad$• $\displaystyle = -6x + 10$
        $\\$
        $\qquad$• Attention : $\displaystyle (-2) \times (-5) = +10$ (moins par moins = plus)
    $\\$
    
    ● **Résultat :** $\displaystyle -2(3x - 5) = -6x + 10$
    $\\$

**Question 3 : Développer $\displaystyle 5(2x + 1)$**

    ● **Méthode :** Distributivité simple
    $\\$
    
    ● **Étape 1 :** Appliquer la distributivité
        $\qquad$• $\displaystyle 5(2x + 1) = 5 \times 2x + 5 \times 1$
    $\\$
    
    ● **Étape 2 :** Calculer
        $\qquad$• $\displaystyle = 10x + 5$
    $\\$
    
    ● **Résultat :** $\displaystyle 5(2x + 1) = 10x + 5$
    $\\$

**Question 4 : Développer $\displaystyle 4(x^2 - 2x + 3)$**

    ● **Méthode :** Distributivité simple avec plusieurs termes
    $\\$
    
    ● **Étape 1 :** Appliquer la distributivité
        $\qquad$• $\displaystyle 4(x^2 - 2x + 3) = 4 \times x^2 + 4 \times (-2x) + 4 \times 3$
    $\\$
    
    ● **Étape 2 :** Calculer
        $\qquad$• $\displaystyle = 4x^2 - 8x + 12$
    $\\$
    
    ● **Résultat :** $\displaystyle 4(x^2 - 2x + 3) = 4x^2 - 8x + 12$
    $\\$

**Question 5 : Développer $\displaystyle -3(4x - 7)$**

    ● **Méthode :** Distributivité simple avec facteur négatif
    $\\$
    
    ● **Étape 1 :** Appliquer la distributivité
        $\qquad$• $\displaystyle -3(4x - 7) = (-3) \times 4x + (-3) \times (-7)$
    $\\$
    
    ● **Étape 2 :** Calculer en faisant attention aux signes
        $\qquad$• $\displaystyle = -12x + 21$
        $\\$
        $\qquad$• Attention : $\displaystyle (-3) \times (-7) = +21$
    $\\$
    
    ● **Résultat :** $\displaystyle -3(4x - 7) = -12x + 21$
    $\\$

Solution:
1. $\displaystyle 3(x + 4) = 3x + 12$
$\\$
2. $\displaystyle -2(3x - 5) = -6x + 10$
$\\$
3. $\displaystyle 5(2x + 1) = 10x + 5$
$\\$
4. $\displaystyle 4(x^2 - 2x + 3) = 4x^2 - 8x + 12$
$\\$
5. $\displaystyle -3(4x - 7) = -12x + 21$

=== Développements - Double Distributivité
Difficulté: easy

Énoncé: Développer les expressions suivantes en utilisant la double distributivité.

**Question 1 : Développer $\displaystyle (x + 3)(x + 5)$**
$\\$
**Question 2 : Développer $\displaystyle (2x - 1)(x + 4)$**
$\\$
**Question 3 : Développer $\displaystyle (3x + 2)(2x - 5)$**
$\\$
**Question 4 : Développer $\displaystyle (x - 2)(x - 3)$**
$\\$
**Question 5 : Développer $\displaystyle (4x + 1)(3x - 2)$**

Étapes:

**Question 1 : Développer $\displaystyle (x + 3)(x + 5)$**

    ● **Méthode :** Double distributivité $\displaystyle (a + b)(c + d) = ac + ad + bc + bd$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• Première parenthèse : $\displaystyle a = x$, $\displaystyle b = 3$
        $\\$
        $\qquad$• Deuxième parenthèse : $\displaystyle c = x$, $\displaystyle d = 5$
    $\\$
    
    ● **Étape 2 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (x + 3)(x + 5) = x \times x + x \times 5 + 3 \times x + 3 \times 5$
    $\\$
    
    ● **Étape 3 :** Calculer chaque produit
        $\qquad$• $\displaystyle = x^2 + 5x + 3x + 15$
    $\\$
    
    ● **Étape 4 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = x^2 + 8x + 15$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 3)(x + 5) = x^2 + 8x + 15$
    $\\$

**Question 2 : Développer $\displaystyle (2x - 1)(x + 4)$**

    ● **Méthode :** Double distributivité avec attention aux signes
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (2x - 1)(x + 4) = 2x \times x + 2x \times 4 + (-1) \times x + (-1) \times 4$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = 2x^2 + 8x - x - 4$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 2x^2 + 7x - 4$
    $\\$
    
    ● **Résultat :** $\displaystyle (2x - 1)(x + 4) = 2x^2 + 7x - 4$
    $\\$

**Question 3 : Développer $\displaystyle (3x + 2)(2x - 5)$**

    ● **Méthode :** Double distributivité
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (3x + 2)(2x - 5) = 3x \times 2x + 3x \times (-5) + 2 \times 2x + 2 \times (-5)$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = 6x^2 - 15x + 4x - 10$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 6x^2 - 11x - 10$
    $\\$
    
    ● **Résultat :** $\displaystyle (3x + 2)(2x - 5) = 6x^2 - 11x - 10$
    $\\$

**Question 4 : Développer $\displaystyle (x - 2)(x - 3)$**

    ● **Méthode :** Double distributivité
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (x - 2)(x - 3) = x \times x + x \times (-3) + (-2) \times x + (-2) \times (-3)$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = x^2 - 3x - 2x + 6$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = x^2 - 5x + 6$
    $\\$
    
    ● **Résultat :** $\displaystyle (x - 2)(x - 3) = x^2 - 5x + 6$
    $\\$

**Question 5 : Développer $\displaystyle (4x + 1)(3x - 2)$**

    ● **Méthode :** Double distributivité
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (4x + 1)(3x - 2) = 4x \times 3x + 4x \times (-2) + 1 \times 3x + 1 \times (-2)$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = 12x^2 - 8x + 3x - 2$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 12x^2 - 5x - 2$
    $\\$
    
    ● **Résultat :** $\displaystyle (4x + 1)(3x - 2) = 12x^2 - 5x - 2$
    $\\$

Solution:
1. $\displaystyle (x + 3)(x + 5) = x^2 + 8x + 15$
$\\$
2. $\displaystyle (2x - 1)(x + 4) = 2x^2 + 7x - 4$
$\\$
3. $\displaystyle (3x + 2)(2x - 5) = 6x^2 - 11x - 10$
$\\$
4. $\displaystyle (x - 2)(x - 3) = x^2 - 5x + 6$
$\\$
5. $\displaystyle (4x + 1)(3x - 2) = 12x^2 - 5x - 2$

=== Développements - Identités Remarquables
Difficulté: medium

Énoncé: Développer les expressions suivantes en utilisant les identités remarquables.

**Question 1 : Développer $\displaystyle (x + 4)^2$**
$\\$
**Question 2 : Développer $\displaystyle (2x - 3)^2$**
$\\$
**Question 3 : Développer $\displaystyle (x + 7)(x - 7)$**
$\\$
**Question 4 : Développer $\displaystyle (3x + 5)^2$**
$\\$
**Question 5 : Développer $\displaystyle (4x - 1)(4x + 1)$**

Étapes:

**Question 1 : Développer $\displaystyle (x + 4)^2$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = x$ et $\displaystyle b = 4$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (x + 4)^2 = x^2 + 2 \times x \times 4 + 4^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^2 + 8x + 16$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 4)^2 = x^2 + 8x + 16$
    $\\$

**Question 2 : Développer $\displaystyle (2x - 3)^2$**

    ● **Méthode :** Identité remarquable $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = 2x$ et $\displaystyle b = 3$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (2x - 3)^2 = (2x)^2 - 2 \times 2x \times 3 + 3^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = 4x^2 - 12x + 9$
    $\\$
    
    ● **Résultat :** $\displaystyle (2x - 3)^2 = 4x^2 - 12x + 9$
    $\\$

**Question 3 : Développer $\displaystyle (x + 7)(x - 7)$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)(a - b) = a^2 - b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = x$ et $\displaystyle b = 7$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (x + 7)(x - 7) = x^2 - 7^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^2 - 49$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 7)(x - 7) = x^2 - 49$
    $\\$

**Question 4 : Développer $\displaystyle (3x + 5)^2$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = 3x$ et $\displaystyle b = 5$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (3x + 5)^2 = (3x)^2 + 2 \times 3x \times 5 + 5^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = 9x^2 + 30x + 25$
    $\\$
    
    ● **Résultat :** $\displaystyle (3x + 5)^2 = 9x^2 + 30x + 25$
    $\\$

**Question 5 : Développer $\displaystyle (4x - 1)(4x + 1)$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)(a - b) = a^2 - b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = 4x$ et $\displaystyle b = 1$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (4x - 1)(4x + 1) = (4x)^2 - 1^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = 16x^2 - 1$
    $\\$
    
    ● **Résultat :** $\displaystyle (4x - 1)(4x + 1) = 16x^2 - 1$
    $\\$

Solution:
1. $\displaystyle (x + 4)^2 = x^2 + 8x + 16$
$\\$
2. $\displaystyle (2x - 3)^2 = 4x^2 - 12x + 9$
$\\$
3. $\displaystyle (x + 7)(x - 7) = x^2 - 49$
$\\$
4. $\displaystyle (3x + 5)^2 = 9x^2 + 30x + 25$
$\\$
5. $\displaystyle (4x - 1)(4x + 1) = 16x^2 - 1$

=== Développements - Développer puis Réduire
Difficulté: medium

Énoncé: Développer et réduire les expressions suivantes.

**Question 1 : Développer et réduire $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5)$**
$\\$
**Question 2 : Développer et réduire $\displaystyle (x + 1)^2 - (x - 2)^2$**
$\\$
**Question 3 : Développer et réduire $\displaystyle 3(x + 2) - 2(x - 1) + x$**
$\\$
**Question 4 : Développer et réduire $\displaystyle (x + 3)^2 - (x - 1)(x + 1)$**
$\\$
**Question 5 : Développer et réduire $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4)$**

Étapes:

**Question 1 : Développer et réduire $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5)$**

    ● **Méthode :** Développer chaque produit puis réduire
    $\\$
    
    ● **Étape 1 :** Développer le premier produit
        $\qquad$• $\displaystyle (x + 2)(x + 3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$
    $\\$
    
    ● **Étape 2 :** Développer le deuxième produit
        $\qquad$• $\displaystyle (x - 1)(x + 5) = x^2 + 5x - x - 5 = x^2 + 4x - 5$
    $\\$
    
    ● **Étape 3 :** Additionner les deux résultats
        $\qquad$• $\displaystyle (x^2 + 5x + 6) + (x^2 + 4x - 5) = x^2 + x^2 + 5x + 4x + 6 - 5$
    $\\$
    
    ● **Étape 4 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 2x^2 + 9x + 1$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5) = 2x^2 + 9x + 1$
    $\\$

**Question 2 : Développer et réduire $\displaystyle (x + 1)^2 - (x - 2)^2$**

    ● **Méthode :** Utiliser les identités remarquables puis soustraire
    $\\$
    
    ● **Étape 1 :** Développer chaque carré
        $\qquad$• $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
        $\\$
        $\qquad$• $\displaystyle (x - 2)^2 = x^2 - 4x + 4$
    $\\$
    
    ● **Étape 2 :** Soustraire (attention aux signes !)
        $\qquad$• $\displaystyle (x^2 + 2x + 1) - (x^2 - 4x + 4) = x^2 + 2x + 1 - x^2 + 4x - 4$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 6x - 3$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 1)^2 - (x - 2)^2 = 6x - 3$
    $\\$

**Question 3 : Développer et réduire $\displaystyle 3(x + 2) - 2(x - 1) + x$**

    ● **Méthode :** Distributivité puis réduction
    $\\$
    
    ● **Étape 1 :** Développer chaque terme
        $\qquad$• $\displaystyle 3(x + 2) = 3x + 6$
        $\\$
        $\qquad$• $\displaystyle -2(x - 1) = -2x + 2$
    $\\$
    
    ● **Étape 2 :** Regrouper tous les termes
        $\qquad$• $\displaystyle 3x + 6 - 2x + 2 + x = (3x - 2x + x) + (6 + 2)$
    $\\$
    
    ● **Étape 3 :** Réduire
        $\qquad$• $\displaystyle = 2x + 8$
    $\\$
    
    ● **Résultat :** $\displaystyle 3(x + 2) - 2(x - 1) + x = 2x + 8$
    $\\$

**Question 4 : Développer et réduire $\displaystyle (x + 3)^2 - (x - 1)(x + 1)$**

    ● **Méthode :** Identités remarquables puis réduction
    $\\$
    
    ● **Étape 1 :** Développer le carré
        $\qquad$• $\displaystyle (x + 3)^2 = x^2 + 6x + 9$
    $\\$
    
    ● **Étape 2 :** Utiliser l'identité remarquable pour le produit
        $\qquad$• $\displaystyle (x - 1)(x + 1) = x^2 - 1$
    $\\$
    
    ● **Étape 3 :** Soustraire
        $\qquad$• $\displaystyle (x^2 + 6x + 9) - (x^2 - 1) = x^2 + 6x + 9 - x^2 + 1$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = 6x + 10$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 3)^2 - (x - 1)(x + 1) = 6x + 10$
    $\\$

**Question 5 : Développer et réduire $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4)$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer le carré
        $\qquad$• $\displaystyle (x - 3)^2 = x^2 - 6x + 9$
        $\\$
        $\qquad$• $\displaystyle 2(x - 3)^2 = 2(x^2 - 6x + 9) = 2x^2 - 12x + 18$
    $\\$
    
    ● **Étape 2 :** Développer le produit
        $\qquad$• $\displaystyle (x + 1)(x - 4) = x^2 - 4x + x - 4 = x^2 - 3x - 4$
    $\\$
    
    ● **Étape 3 :** Soustraire
        $\qquad$• $\displaystyle (2x^2 - 12x + 18) - (x^2 - 3x - 4) = 2x^2 - 12x + 18 - x^2 + 3x + 4$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = x^2 - 9x + 22$
    $\\$
    
    ● **Résultat :** $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4) = x^2 - 9x + 22$
    $\\$

Solution:
1. $\displaystyle (x + 2)(x + 3) + (x - 1)(x + 5) = 2x^2 + 9x + 1$
$\\$
2. $\displaystyle (x + 1)^2 - (x - 2)^2 = 6x - 3$
$\\$
3. $\displaystyle 3(x + 2) - 2(x - 1) + x = 2x + 8$
$\\$
4. $\displaystyle (x + 3)^2 - (x - 1)(x + 1) = 6x + 10$
$\\$
5. $\displaystyle 2(x - 3)^2 - (x + 1)(x - 4) = x^2 - 9x + 22$

=== Développements - Expressions Complexes
Difficulté: hard

Énoncé: Développer et réduire les expressions suivantes.

**Question 1 : Développer $\displaystyle (x + 2)(x - 3)(x + 1)$**
$\\$
**Question 2 : Développer et réduire $\displaystyle (x + 1)^3$**
$\\$
**Question 3 : Développer et réduire $\displaystyle (x + 2)^2(x - 1) - (x - 1)^2(x + 2)$**
$\\$
**Question 4 : Développer et réduire $\displaystyle 2(x + 1)^2 - 3(x - 2)(x + 2)$**
$\\$
**Question 5 : Développer et réduire $\displaystyle (x + 3)(x - 3)(x^2 + 9)$**

Étapes:

**Question 1 : Développer $\displaystyle (x + 2)(x - 3)(x + 1)$**

    ● **Méthode :** Développer deux parenthèses à la fois
    $\\$
    
    ● **Étape 1 :** Développer les deux premières parenthèses
        $\qquad$• $\displaystyle (x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6$
    $\\$
    
    ● **Étape 2 :** Multiplier le résultat par $\displaystyle (x + 1)$
        $\qquad$• $\displaystyle (x^2 - x - 6)(x + 1) = x^2 \times x + x^2 \times 1 - x \times x - x \times 1 - 6 \times x - 6 \times 1$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^3 + x^2 - x^2 - x - 6x - 6$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = x^3 - 7x - 6$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 2)(x - 3)(x + 1) = x^3 - 7x - 6$
    $\\$

**Question 2 : Développer et réduire $\displaystyle (x + 1)^3$**

    ● **Méthode :** Utiliser $\displaystyle (x + 1)^3 = (x + 1)^2(x + 1)$
    $\\$
    
    ● **Étape 1 :** Développer $\displaystyle (x + 1)^2$
        $\qquad$• $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
    $\\$
    
    ● **Étape 2 :** Multiplier par $\displaystyle (x + 1)$
        $\qquad$• $\displaystyle (x^2 + 2x + 1)(x + 1) = x^2 \times x + x^2 \times 1 + 2x \times x + 2x \times 1 + 1 \times x + 1 \times 1$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^3 + x^2 + 2x^2 + 2x + x + 1$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = x^3 + 3x^2 + 3x + 1$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 1)^3 = x^3 + 3x^2 + 3x + 1$
    $\\$

**Question 3 : Développer et réduire $\displaystyle (x + 2)^2(x - 1) - (x - 1)^2(x + 2)$**

    ● **Méthode :** Factoriser d'abord puis développer
    $\\$
    
    ● **Étape 1 :** Factoriser le facteur commun $\displaystyle (x + 2)(x - 1)$
        $\qquad$• $\displaystyle (x + 2)^2(x - 1) - (x - 1)^2(x + 2) = (x + 2)(x - 1)[(x + 2) - (x - 1)]$
    $\\$
    
    ● **Étape 2 :** Simplifier à l'intérieur des crochets
        $\qquad$• $\displaystyle (x + 2) - (x - 1) = x + 2 - x + 1 = 3$
    $\\$
    
    ● **Étape 3 :** Développer $\displaystyle (x + 2)(x - 1)$
        $\qquad$• $\displaystyle (x + 2)(x - 1) = x^2 - x + 2x - 2 = x^2 + x - 2$
    $\\$
    
    ● **Étape 4 :** Multiplier par $\displaystyle 3$
        $\qquad$• $\displaystyle = 3(x^2 + x - 2) = 3x^2 + 3x - 6$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 2)^2(x - 1) - (x - 1)^2(x + 2) = 3x^2 + 3x - 6$
    $\\$

**Question 4 : Développer et réduire $\displaystyle 2(x + 1)^2 - 3(x - 2)(x + 2)$**

    ● **Méthode :** Développer puis réduire
    $\\$
    
    ● **Étape 1 :** Développer $\displaystyle (x + 1)^2$
        $\qquad$• $\displaystyle (x + 1)^2 = x^2 + 2x + 1$
        $\\$

        $\qquad$• $\displaystyle (x^2 + 2x + 1)(x - 1) = x^2 \times x + x^2 \times (-1) + 2x \times x + 2x \times (-1) + 1 \times x + 1 \times (-1)$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^3 - x^2 + 2x^2 - 2x + x - 1$
    $\\$
    
    ● **Étape 4 :** Réduire
        $\qquad$• $\displaystyle = x^3 + x^2 - x - 1$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + 1)^2(x - 1) = x^3 + x^2 - x - 1$
    $\\$

Solution:
1. $\displaystyle (x + 3)(x - 3)(x^2 + 9) = x^4 - 81$
$\\$
2. $\displaystyle (2x + 1)^2 - (2x - 1)^2 = 8x$
$\\$
3. $\displaystyle (x + 2)^3 = x^3 + 6x^2 + 12x + 8$
$\\$
4. $\displaystyle (x - 1)^3 = x^3 - 3x^2 + 3x - 1$
$\\$
5. $\displaystyle (x + 1)^2(x - 1) = x^3 + x^2 - x - 1$

=== Développements - Expressions avec Plusieurs Variables
Difficulté: hard

Énoncé: Développer les expressions suivantes contenant plusieurs variables.

**Question 1 : Développer $\displaystyle 3(x + 2y)$**
$\\$
**Question 2 : Développer $\displaystyle (x + y)(x - y)$**
$\\$
**Question 3 : Développer $\displaystyle (x + y)^2$**
$\\$
**Question 4 : Développer $\displaystyle (2x + 3y)(x - y)$**
$\\$
**Question 5 : Développer $\displaystyle (x + y)(x + 2y)$**

Étapes:

**Question 1 : Développer $\displaystyle 3(x + 2y)$**

    ● **Méthode :** Distributivité simple avec plusieurs variables
    $\\$
    
    ● **Étape 1 :** Appliquer la distributivité
        $\qquad$• $\displaystyle 3(x + 2y) = 3 \times x + 3 \times 2y$
    $\\$
    
    ● **Étape 2 :** Calculer
        $\qquad$• $\displaystyle = 3x + 6y$
    $\\$
    
    ● **Résultat :** $\displaystyle 3(x + 2y) = 3x + 6y$
    $\\$

**Question 2 : Développer $\displaystyle (x + y)(x - y)$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)(a - b) = a^2 - b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = x$ et $\displaystyle b = y$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (x + y)(x - y) = x^2 - y^2$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + y)(x - y) = x^2 - y^2$
    $\\$

**Question 3 : Développer $\displaystyle (x + y)^2$**

    ● **Méthode :** Identité remarquable $\displaystyle (a + b)^2 = a^2 + 2ab + b^2$
    $\\$
    
    ● **Étape 1 :** Identifier les éléments
        $\qquad$• $\displaystyle a = x$ et $\displaystyle b = y$
    $\\$
    
    ● **Étape 2 :** Appliquer l'identité remarquable
        $\qquad$• $\displaystyle (x + y)^2 = x^2 + 2 \times x \times y + y^2$
    $\\$
    
    ● **Étape 3 :** Calculer
        $\qquad$• $\displaystyle = x^2 + 2xy + y^2$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + y)^2 = x^2 + 2xy + y^2$
    $\\$

**Question 4 : Développer $\displaystyle (2x + 3y)(x - y)$**

    ● **Méthode :** Double distributivité avec plusieurs variables
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (2x + 3y)(x - y) = 2x \times x + 2x \times (-y) + 3y \times x + 3y \times (-y)$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = 2x^2 - 2xy + 3xy - 3y^2$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = 2x^2 + (-2xy + 3xy) - 3y^2 = 2x^2 + xy - 3y^2$
    $\\$
    
    ● **Résultat :** $\displaystyle (2x + 3y)(x - y) = 2x^2 + xy - 3y^2$
    $\\$

**Question 5 : Développer $\displaystyle (x + y)(x + 2y)$**

    ● **Méthode :** Double distributivité
    $\\$
    
    ● **Étape 1 :** Appliquer la double distributivité
        $\qquad$• $\displaystyle (x + y)(x + 2y) = x \times x + x \times 2y + y \times x + y \times 2y$
    $\\$
    
    ● **Étape 2 :** Calculer chaque produit
        $\qquad$• $\displaystyle = x^2 + 2xy + xy + 2y^2$
    $\\$
    
    ● **Étape 3 :** Réduire les termes semblables
        $\qquad$• $\displaystyle = x^2 + (2xy + xy) + 2y^2 = x^2 + 3xy + 2y^2$
    $\\$
    
    ● **Résultat :** $\displaystyle (x + y)(x + 2y) = x^2 + 3xy + 2y^2$
    $\\$

Solution:
1. $\displaystyle 3(x + 2y) = 3x + 6y$
$\\$
2. $\displaystyle (x + y)(x - y) = x^2 - y^2$
$\\$
3. $\displaystyle (x + y)^2 = x^2 + 2xy + y^2$
$\\$
4. $\displaystyle (2x + 3y)(x - y) = 2x^2 + xy - 3y^2$
$\\$
5. $\displaystyle (x + y)(x + 2y) = x^2 + 3xy + 2y^2$
