<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Proportionnalité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Reconnaître :</strong> quotients tous égaux (le coefficient) ; graphique = <strong>droite passant par l'origine</strong>.</p>
</div>
[IMAGE_1]
<p style="margin:0;">4 méthodes : passage à l'unité, coefficient, linéarité, produit en croix.</p>
<p style="margin:6px 0 0 0;"><strong>Piège :</strong> un forfait fixe ($5 + 2n$) casse la proportionnalité.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Ratios et échelles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Ratio $\displaystyle a:b$</strong> → $\displaystyle a+b$ parts égales. Ex. : 56 billes en $3:5$ → 8 parts de 7 → 21 et 35.</p>
<p style="margin:6px 0 0 0;">• <strong>Échelle</strong> $\displaystyle = \frac{\text{plan}}{\text{réel}}$ (même unité !). Au $\displaystyle \frac{1}{500}$ : 1 cm ↔ 5 m.</p>
</div>

<p style="margin:0;"><strong>Taux d'évolution :</strong> $\displaystyle t = \frac{V_f - V_i}{V_i}$ ; <strong>évolutions successives :</strong> on MULTIPLIE les coefficients ($+20\ \%$ puis $-20\ \%$ → $\displaystyle 1{,}2 \times 0{,}8 = 0{,}96$ → $-4\ \%$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Additionner les taux d'évolutions successives (les coefficients se multiplient !).</p>
<p style="margin:6px 0 0 0;">2️⃣ Retirer $\displaystyle t\ \%$ de la valeur finale pour retrouver l'initiale (il faut diviser).</p>
<p style="margin:6px 0 0 0;">3️⃣ Confondre points de pourcentage (12 % → 15 % : +3 points) et hausse relative (+25 %).</p>
<p style="margin:6px 0 0 0;">4️⃣ Calculer une échelle avec des unités différentes.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> toute évolution se code par un coefficient multiplicateur ; toute comparaison d'offres passe par le prix à l'unité ; toujours nommer la référence d'un pourcentage.</p>
</div>
