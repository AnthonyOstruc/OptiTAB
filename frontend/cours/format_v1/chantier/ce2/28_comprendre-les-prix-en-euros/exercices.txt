===
Découverte - Écrire les euros et les centimes
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Écris les prix de deux objets : une règle à 3 euros et 8 centimes ; une boîte à 12 euros et 50 centimes.

1. Combien de centimes font un euro ?
2. Écris le prix de la règle avec une virgule.
3. Écris le prix de la boîte avec une virgule.
4. 3,80 € conviendraient-ils pour la règle ?
5. Quel objet coûte le moins cher ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de centimes font un euro ?

::: methode
Rappelle l’échange entre les deux unités.
:::

::: etape Raisonner
Cent pièces de un centime font un euro.
:::

::: resultat
100 centimes.
:::

## Question 2 : Écris le prix de la règle avec une virgule.

::: methode
Écris deux chiffres pour les centimes.
:::

::: etape Raisonner
8 centimes s’écrivent 08 après la virgule.
:::

::: resultat
$3{,}08$ €.
:::

## Question 3 : Écris le prix de la boîte avec une virgule.

::: methode
Place les euros avant la virgule et les centimes après.
:::

::: etape Raisonner
12 euros et 50 centimes donnent deux parties du prix.
:::

::: resultat
$12{,}50$ €.
:::

## Question 4 : 3,80 € conviendraient-ils pour la règle ?

::: methode
Lis les deux chiffres des centimes.
:::

::: etape Raisonner
3,80 € représentent 3 euros et 80 centimes.
:::

::: resultat
Non : il faut écrire 3,08 €.
:::

## Question 5 : Quel objet coûte le moins cher ?

::: methode
Compare d’abord les euros entiers.
:::

::: etape Raisonner
$3<12$ ; les centimes ne changent pas cet ordre.
:::

::: resultat
La règle à 3,08 €.
:::

Solution:
<!-- optitab:1 -->
1. 100 centimes.
2. $3{,}08$ €.
3. $12{,}50$ €.
4. Non : il faut écrire 3,08 €.
5. La règle à 3,08 €.

Découverte - Convertir trois prix en centimes
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Trois articles coûtent 4,25 € ; 7,03 € ; 10 €.

1. Combien de centimes représentent les quatre euros du premier prix ?
2. Convertis 4,25 € en centimes.
3. Convertis 7,03 € en centimes.
4. Convertis 10 € en centimes.
5. Pourquoi 7,03 € ne font-ils pas 730 centimes ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de centimes représentent les quatre euros du premier prix ?

::: methode
Chaque euro vaut cent centimes.
:::

::: etape Raisonner
$4\times100=400$ centimes.
:::

::: resultat
400 centimes.
:::

## Question 2 : Convertis 4,25 € en centimes.

::: methode
Ajoute les centimes aux euros convertis.
:::

::: etape Raisonner
$400+25=425$.
:::

::: resultat
425 centimes.
:::

## Question 3 : Convertis 7,03 € en centimes.

::: methode
Convertis les sept euros et ajoute seulement trois centimes.
:::

::: etape Raisonner
$700+3=703$.
:::

::: resultat
703 centimes.
:::

## Question 4 : Convertis 10 € en centimes.

::: methode
Utilise dix groupes de cent.
:::

::: etape Raisonner
$10\times100=1000$.
:::

::: resultat
1 000 centimes.
:::

## Question 5 : Pourquoi 7,03 € ne font-ils pas 730 centimes ?

::: methode
Décompose le prix proposé.
:::

::: etape Raisonner
730 centimes font 7 euros et 30 centimes.
:::

::: resultat
Parce que 03 signifie 3 centimes, pas 30.
:::

Solution:
<!-- optitab:1 -->
1. 400 centimes.
2. 425 centimes.
3. 703 centimes.
4. 1 000 centimes.
5. Parce que 03 signifie 3 centimes, pas 30.

Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une trousse coûte 508 centimes et une petite lampe 1 260 centimes.

1. Combien d’euros entiers contient le prix de la trousse ?
2. Combien de centimes restent pour la trousse ?
3. Écris le prix de la trousse en euros.
4. Écris le prix de la lampe en euros.
5. La lampe coûte-t-elle plus de dix euros ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien d’euros entiers contient le prix de la trousse ?

::: methode
Forme des groupes de cent centimes.
:::

::: etape Raisonner
508 centimes contiennent cinq groupes de cent.
:::

::: resultat
5 euros.
:::

## Question 2 : Combien de centimes restent pour la trousse ?

::: methode
Retire les cinq euros.
:::

::: etape Raisonner
$508-500=8$.
:::

::: resultat
8 centimes.
:::

## Question 3 : Écris le prix de la trousse en euros.

::: methode
Garde deux chiffres après la virgule.
:::

::: etape Raisonner
5 euros et 8 centimes s’écrivent 5,08 €.
:::

::: resultat
$5{,}08$ €.
:::

## Question 4 : Écris le prix de la lampe en euros.

::: methode
Décompose en euros entiers et reste.
:::

::: etape Raisonner
$1260=1200+60$ : cela fait 12 euros et 60 centimes.
:::

::: resultat
$12{,}60$ €.
:::

## Question 5 : La lampe coûte-t-elle plus de dix euros ?

::: methode
Compare les nombres de centimes.
:::

::: etape Raisonner
Dix euros valent 1 000 centimes ; $1260>1000$.
:::

::: resultat
Oui, elle coûte 12,60 €.
:::

Solution:
<!-- optitab:1 -->
1. 5 euros.
2. 8 centimes.
3. $5{,}08$ €.
4. $12{,}60$ €.
5. Oui, elle coûte 12,60 €.

1. Que signifie 6,05 € ?
2. Que signifie 6,50 € ?
3. Quel prix est le plus petit dans la première paire ?
4. Convertis 4,80 € en centimes.
5. Compare 4,80 € et 480 centimes.

Étapes:
<!-- optitab:1 -->

## Question 1 : Que signifie 6,05 € ?

::: methode
Sépare euros et centimes.
:::

::: etape Raisonner
Les deux chiffres après la virgule sont 05.
:::

::: resultat
6 euros et 5 centimes.
:::

## Question 2 : Que signifie 6,50 € ?

::: methode
Lis les centimes comme un nombre à deux chiffres.
:::

::: etape Raisonner
50 après la virgule signifie cinquante centimes.
:::

::: resultat
6 euros et 50 centimes.
:::

## Question 3 : Quel prix est le plus petit dans la première paire ?

::: methode
Les euros sont égaux : compare les centimes.
:::

::: etape Raisonner
$5<50$.
:::

::: resultat
6,05 € < 6,50 €.
:::

## Question 4 : Convertis 4,80 € en centimes.

::: methode
Convertis les euros, puis ajoute quatre-vingts centimes.
:::

::: etape Raisonner
$400+80=480$.
:::

::: resultat
480 centimes.
:::

::: methode
Écris les deux prix dans la même unité.
:::

::: etape Raisonner
Les deux étiquettes indiquent 480 centimes.
:::

::: resultat
4,80 € = 480 centimes.
:::

Solution:
<!-- optitab:1 -->
1. 6 euros et 5 centimes.
2. 6 euros et 50 centimes.
3. 6,05 € < 6,50 €.
4. 480 centimes.
5. 4,80 € = 480 centimes.

Entraînement - Composer 3,75 euros
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Avec les pièces usuelles de 1, 2, 5, 10, 20 et 50 centimes, de 1 € et de 2 €, on veut payer exactement 3,75 €. Voici une proposition.

[IMAGE_1]

1. Quelle somme donnent les deux pièces en euros ?
2. Combien de centimes reste-t-il à compléter ?
3. Vérifie les trois petites pièces proposées.
4. Combien de pièces utilise cette proposition ?
5. Remplace la pièce de 20 c par deux pièces de 10 c. Quelle somme obtiens-tu et combien de pièces utilises-tu ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle somme donnent les deux pièces en euros ?

::: methode
Réunis les pièces de 2 € et de 1 €.
:::

::: etape Raisonner
$2+1=3$.
:::

::: resultat
3 €.
:::

## Question 2 : Combien de centimes reste-t-il à compléter ?

::: methode
Sépare les euros et les centimes du prix.
:::

::: etape Raisonner
Le prix est de 3 euros et 75 centimes.
:::

::: resultat
75 centimes.
:::

## Question 3 : Vérifie les trois petites pièces proposées.

::: methode
Additionne leurs valeurs.
:::

::: etape Raisonner
$50+20+5=75$.
:::

::: resultat
75 centimes.
:::

## Question 4 : Combien de pièces utilise cette proposition ?

::: methode
Compte chaque pièce une seule fois.
:::

::: etape Raisonner
Il y a deux pièces en euros et trois pièces en centimes.
:::

::: resultat
5 pièces.
:::

## Question 5 : Remplace la pièce de 20 c par deux pièces de 10 c. Quelle somme obtiens-tu et combien de pièces utilises-tu ?

::: methode
Échange une pièce contre deux pièces de même valeur totale.
:::

::: etape Raisonner
$10+10=20$ centimes : la somme reste 3,75 €. Une pièce est remplacée par deux ; on utilise donc une pièce de plus.
:::

::: resultat
Toujours 3,75 €, avec 6 pièces.
:::
Solution:
<!-- optitab:1 -->
1. 3 €.
2. 75 centimes.
3. 75 centimes.
4. 5 pièces.
5. Toujours 3,75 €, avec 6 pièces.

Entraînement - La monnaie sur cinq euros
Id: nouveau-6
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un cahier coûte 4,65 €. On donne un billet de 5 €.

1. Exprime le prix en centimes.
2. Exprime la somme donnée en centimes.
3. Quelle monnaie doit-on rendre ?
4. Propose trois pièces pour rendre cette monnaie.
5. Vérifie le paiement.

Étapes:
<!-- optitab:1 -->

## Question 1 : Exprime le prix en centimes.

::: methode
Convertis les euros et ajoute les centimes.
:::

::: etape Raisonner
$400+65=465$.
:::

::: resultat
465 centimes.
:::

## Question 2 : Exprime la somme donnée en centimes.

::: methode
Un euro vaut cent centimes.
:::

::: etape Raisonner
$5\times100=500$.
:::

::: resultat
500 centimes.
:::

## Question 3 : Quelle monnaie doit-on rendre ?

::: methode
Retire le prix de la somme donnée.
:::

::: etape Raisonner
$500-465=35$.
:::

::: resultat
35 centimes, soit 0,35 €.
:::

## Question 4 : Propose trois pièces pour rendre cette monnaie.

::: methode
Cherche des valeurs qui font trente-cinq.
:::

::: etape Raisonner
$20+10+5=35$.
:::

::: resultat
Une pièce de 20 c, une de 10 c et une de 5 c.
:::

## Question 5 : Vérifie le paiement.

::: methode
Rassemble le prix et la monnaie.
:::

::: etape Raisonner
$465+35=500$.
:::

::: resultat
4,65 € et 0,35 € font bien 5 €.
:::

Solution:
<!-- optitab:1 -->
1. 465 centimes.
2. 500 centimes.
3. 35 centimes, soit 0,35 €.
4. Une pièce de 20 c, une de 10 c et une de 5 c.
5. 4,65 € et 0,35 € font bien 5 €.

Problème - Compléter jusqu’à dix euros
Id: nouveau-7
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un livre coûte 7,85 €. On paie avec 10 €.

1. Combien manque-t-il pour passer de 7,85 € à 8 € ?
2. Combien manque-t-il ensuite pour passer de 8 € à 10 € ?
3. Quelle monnaie faut-il rendre en tout ?
4. Vérifie en calculant en centimes.
5. Une seule pièce de 2 € suffirait-elle pour la monnaie ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien manque-t-il pour passer de 7,85 € à 8 € ?

::: methode
Complète les centimes jusqu’à cent.
:::

::: etape Raisonner
$100-85=15$.
:::

::: resultat
15 centimes.
:::

## Question 2 : Combien manque-t-il ensuite pour passer de 8 € à 10 € ?

::: methode
Complète les euros entiers.
:::

::: etape Raisonner
$10-8=2$.
:::

::: resultat
2 €.
:::

## Question 3 : Quelle monnaie faut-il rendre en tout ?

::: methode
Réunis les deux compléments.
:::

::: etape Raisonner
2 euros et 15 centimes forment 2,15 €.
:::

::: resultat
2,15 €.
:::

## Question 4 : Vérifie en calculant en centimes.

::: methode
Soustrais le prix du paiement.
:::

::: etape Raisonner
$1000-785=215$.
:::

::: resultat
215 centimes, soit 2,15 €.
:::

## Question 5 : Une seule pièce de 2 € suffirait-elle pour la monnaie ?

::: methode
Compare la monnaie complète avec deux euros.
:::

::: etape Raisonner
Il manque encore les 15 centimes du premier complément.
:::

::: resultat
Non : il faut aussi 15 centimes.
:::

Solution:
<!-- optitab:1 -->
1. 15 centimes.
2. 2 €.
3. 2,15 €.
4. 215 centimes, soit 2,15 €.
5. Non : il faut aussi 15 centimes.

Problème - Ranger quatre prix
Id: nouveau-8
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Quatre jeux coûtent 8,09 € ; 8,90 € ; 8,50 € ; 8,05 €.

1. Quelle partie des quatre prix est identique ?
2. Quels sont les quatre nombres de centimes ?
3. Quel jeu coûte le moins cher ?
4. Range les quatre prix du moins cher au plus cher.
5. Quel est l’écart entre le prix le plus grand et le plus petit ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quelle partie des quatre prix est identique ?

::: methode
Observe les euros avant la virgule.
:::

::: etape Raisonner
Chaque prix commence par 8 euros.
:::

::: resultat
Les huit euros entiers.
:::

## Question 2 : Quels sont les quatre nombres de centimes ?

::: methode
Lis les deux chiffres après la virgule.
:::

::: etape Raisonner
09, 90, 50 et 05 sont les centimes.
:::

::: resultat
9 ; 90 ; 50 ; 5 centimes.
:::

## Question 3 : Quel jeu coûte le moins cher ?

::: methode
Compare seulement les centimes puisque les euros sont égaux.
:::

::: etape Raisonner
$5<9<50<90$.
:::

::: resultat
Le jeu à 8,05 €.
:::

## Question 4 : Range les quatre prix du moins cher au plus cher.

::: methode
Conserve le même ordre que pour les centimes.
:::

::: etape Raisonner
On commence par 5 c, puis 9 c, 50 c et 90 c.
:::

::: resultat
8,05 € < 8,09 € < 8,50 € < 8,90 €.
:::

## Question 5 : Quel est l’écart entre le prix le plus grand et le plus petit ?

::: methode
Les huit euros se compensent : soustrais les centimes.
:::

::: etape Raisonner
$90-5=85$.
:::

::: resultat
85 centimes, soit 0,85 €.
:::

Solution:
<!-- optitab:1 -->
1. Les huit euros entiers.
2. 9 ; 90 ; 50 ; 5 centimes.
3. Le jeu à 8,05 €.
4. 8,05 € < 8,09 € < 8,50 € < 8,90 €.
5. 85 centimes, soit 0,85 €.

4. Écris le prix que Lina a réellement annoncé.
5. Quel écart y a-t-il entre les deux prix ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien d’euros entiers indique 9,06 € ?

::: methode
Lis avant la virgule.
:::

::: etape Raisonner
La partie avant la virgule est 9.
:::

::: resultat
9 euros.
:::

::: methode
Lis 06 comme le nombre six.
:::

::: etape Raisonner
Le zéro garde la place des dizaines de centimes.
:::

::: resultat
6 centimes.
:::

::: methode
Réunis les euros et les bons centimes.

::: etape Raisonner

::: resultat

::: etape Raisonner

9,60 €.

## Question 5 : Quel écart y a-t-il entre les deux prix ?
