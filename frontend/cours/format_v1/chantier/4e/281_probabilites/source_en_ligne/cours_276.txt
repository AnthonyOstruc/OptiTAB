        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🎯 Objectifs du chapitre :</strong> utiliser le vocabulaire des probabilités, calculer une probabilité dans une situation où les issues ont la même chance de se produire, utiliser l'événement contraire, faire le lien entre fréquence observée et probabilité, et étudier des expériences à deux épreuves.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Vocabulaire</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définitions :</strong> une <strong>expérience aléatoire</strong> a plusieurs résultats possibles, appelés <strong>issues</strong>, et l'on ne peut pas savoir à l'avance lequel se produira. Un <strong>événement</strong> est un ensemble d'issues. Un événement <strong>impossible</strong> ne se produit jamais ; un événement <strong>certain</strong> se produit toujours.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> on tire une boule au hasard dans l'urne ci-dessous. Les issues sont les $\displaystyle 10$ boules ; « tirer une boule rouge » est un événement réalisé par $\displaystyle 5$ issues.</p>
        [IMAGE_1]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calculer une probabilité</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété :</strong> quand toutes les issues ont la même chance de se produire (<strong>équiprobabilité</strong>), la probabilité d'un événement $\displaystyle A$ est :</p>
            <div style="text-align:center; margin:10px 0 0 0;">$\displaystyle P(A) = \frac{\text{nombre d'issues favorables à } A}{\text{nombre total d'issues}}$</div>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> $\displaystyle P(\text{rouge}) = \frac{5}{10} = \frac{1}{2}$ ; $\displaystyle P(\text{bleue}) = \frac{3}{10}$ ; $\displaystyle P(\text{verte}) = \frac{2}{10} = \frac{1}{5}$.</p>
        <p style="font-size:1em;">Une probabilité est toujours comprise entre $\displaystyle 0$ (impossible) et $\displaystyle 1$ (certain). La somme des probabilités de toutes les issues vaut $\displaystyle 1$.</p>
        [IMAGE_2]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. L'événement contraire</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Propriété :</strong> l'événement contraire de $\displaystyle A$, noté « non $\displaystyle A$ », est réalisé quand $\displaystyle A$ ne l'est pas : $\displaystyle P(\text{non } A) = 1 - P(A)$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> avec un dé équilibré, $\displaystyle P(\text{obtenir } 6) = \frac{1}{6}$, donc $\displaystyle P(\text{ne pas obtenir } 6) = 1 - \frac{1}{6} = \frac{5}{6}$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Fréquence et probabilité</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">Quand on répète une expérience un grand nombre de fois, la <strong>fréquence</strong> d'un événement se rapproche de sa <strong>probabilité</strong>. On peut donc estimer une probabilité inconnue (dé truqué, punaise lancée…) par une fréquence observée sur beaucoup d'essais.</p>
        [IMAGE_3]
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> sur peu d'essais, la fréquence peut être très éloignée de la probabilité. Obtenir trois « pile » de suite ne rend pas « face » plus probable au lancer suivant : la pièce n'a pas de mémoire.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Expériences à deux épreuves</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">Pour deux épreuves (lancer deux dés, deux pièces…), on liste toutes les issues dans un <strong>tableau à double entrée</strong>. Avec deux dés, il y a $\displaystyle 6 \times 6 = 36$ issues équiprobables.</p>
        [IMAGE_4]
        <p style="font-size:1em;"><strong>Exemple :</strong> la somme $\displaystyle 7$ apparaît dans $\displaystyle 6$ cases : $\displaystyle P(\text{somme} = 7) = \frac{6}{36} = \frac{1}{6}$. La somme $\displaystyle 2$ n'apparaît qu'une fois : $\displaystyle P = \frac{1}{36}$.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conseil :</strong> les $\displaystyle 11$ sommes possibles ($\displaystyle 2$ à $\displaystyle 12$) ne sont PAS équiprobables ; ce sont les $\displaystyle 36$ cases du tableau qui le sont.
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L'essentiel :</strong> $\displaystyle P(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$ (si équiprobabilité) ; $\displaystyle 0 \leq P(A) \leq 1$ ; $\displaystyle P(\text{non } A) = 1 - P(A)$ ; sur un grand nombre d'essais, la fréquence approche la probabilité ; deux épreuves : tableau à double entrée. Fiche de synthèse dans l'onglet Fiches !</p>
    </div>
