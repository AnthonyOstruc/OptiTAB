📚 Objectif pédagogique : retenir l’essentiel : définition, règles de calcul, dérivée, limites, résolution d’équations et de seuils. Programme de Terminale.

I. Définition et règles

$\displaystyle y = \ln x \iff e^y = x$ ($\displaystyle x \gt 0$) ; $\displaystyle \ln(ab) = \ln a + \ln b$

[IMAGE_1]

1️⃣ $\displaystyle \ln 1 = 0$, $\displaystyle \ln e = 1$, $\displaystyle e^{\ln x} = x$, $\displaystyle \ln(e^x) = x$.

2️⃣ $\displaystyle \ln\frac{a}{b} = \ln a - \ln b$ ; $\displaystyle \ln(a^n) = n\ln a$ ; $\displaystyle \ln\sqrt{a} = \frac{1}{2}\ln a$.

3️⃣ $\displaystyle \ln a \lt \ln b \iff a \lt b$ (pour $\displaystyle a, b \gt 0$).

II. Étude

[IMAGE_2]

1️⃣ $\displaystyle (\ln x)' = \frac{1}{x}$ ; $\displaystyle (\ln u)' = \frac{u'}{u}$.

2️⃣ $\displaystyle \lim\limits_{0^+} \ln x = -\infty$ ; $\displaystyle \lim\limits_{+\infty} \ln x = +\infty$ ; $\displaystyle \frac{\ln x}{x} \to 0$ ; $\displaystyle x\ln x \to 0$ en $\displaystyle 0^+$.

3️⃣ Seuil : $\displaystyle q^n \gt A \iff n\ln q \gt \ln A$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Oublier le domaine : $\displaystyle \ln u$ exige $\displaystyle u \gt 0$.

2️⃣ Écrire $\displaystyle \ln(a + b) = \ln a + \ln b$.

3️⃣ Diviser par $\displaystyle \ln q \lt 0$ sans changer le sens de l’inégalité.

4️⃣ Oublier de vérifier que la solution trouvée appartient au domaine.

🏆 Réflexe : inconnue en exposant → je « prends le ln » ; inconnue dans un ln → domaine, puis j’applique l’exponentielle.
