<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition du produit scalaire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Produit scalaire</strong></p>
<p style="margin:5px 0 0 0;">Soient $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ deux vecteurs non nuls.</p>
<p style="margin:5px 0 0 0;">Le <strong>produit scalaire</strong> de $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$, noté $\displaystyle \vec{u} \cdot \vec{v}$ ou $\displaystyle \langle \vec{u}, \vec{v} \rangle$, est défini par :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\| \times \|\vec{v}\| \times \cos(\widehat{\vec{u}, \vec{v}})$</p>
</div>
<p style="margin:5px 0 0 0;">où $\displaystyle \widehat{\vec{u}, \vec{v}}$ est l'angle orienté entre les vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$.</p>
<p style="margin:5px 0 0 0;">Si $\displaystyle H$ est le projeté orthogonal de l'extrémité de $\displaystyle \vec{v}$ sur la droite portée par $\displaystyle \vec{u}$, alors :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\| \times \mathrm{proj}_{\vec{u}}(\vec{v})$</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_1]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>⚠️ Cas particuliers :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Si $\displaystyle \vec{u} = \vec{0}$ ou $\displaystyle \vec{v} = \vec{0}$, alors $\displaystyle \vec{u} \cdot \vec{v} = 0$</li>
<li style="margin:0 0 8px 0;">Si les vecteurs sont de même sens ($\displaystyle \cos(\widehat{\vec{u}, \vec{v}}) = 1$), alors $\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\| \times \|\vec{v}\|$</li>
<li style="margin:0 0 8px 0;">Si les vecteurs sont de sens opposés ($\displaystyle \cos(\widehat{\vec{u}, \vec{v}}) = -1$), alors $\displaystyle \vec{u} \cdot \vec{v} = -\|\vec{u}\| \times \|\vec{v}\|$</li>
<li style="margin:0;">Si les vecteurs sont perpendiculaires ($\displaystyle \cos(\widehat{\vec{u}, \vec{v}}) = 0$), alors $\displaystyle \vec{u} \cdot \vec{v} = 0$</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Orthogonalité et caractérisation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Caractérisation de l'orthogonalité</strong></p>
<p style="margin:5px 0 0 0;">Deux vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ sont <strong>orthogonaux</strong> si et seulement si leur produit scalaire est nul :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \perp \vec{v} \Leftrightarrow \vec{u} \cdot \vec{v} = 0$</p>
</div>
<p style="margin:5px 0 0 0;">On convient que $\displaystyle \vec{0}$ est orthogonal à tout vecteur.</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_3]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#f8f9fa; border-left:4px solid #6c757d; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Exemple :</strong></p>
<p style="margin:5px 0 0 0;">Montrer que les vecteurs $\displaystyle \vec{u}(3, 4)$ et $\displaystyle \vec{v}(-4, 3)$ sont orthogonaux.</p>
<p style="margin:5px 0 0 0;">$\displaystyle \vec{u} \cdot \vec{v} = 3 \times (-4) + 4 \times 3 = -12 + 12 = 0$</p>
<p style="margin:5px 0 0 0;">Donc $\displaystyle \vec{u} \perp \vec{v}$.</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Propriétés du produit scalaire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Propriétés du produit scalaire</strong></p>
<p style="margin:5px 0 0 0;">Pour tous vecteurs $\displaystyle \vec{u}$, $\displaystyle \vec{v}$, $\displaystyle \vec{w}$ et tout réel $\displaystyle \lambda$ :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;"><strong>Symétrie :</strong> $\displaystyle \vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$</li>
<li style="margin:0 0 8px 0;"><strong>Linéarité :</strong> $\displaystyle (\lambda \vec{u}) \cdot \vec{v} = \lambda (\vec{u} \cdot \vec{v})$ et $\displaystyle \vec{u} \cdot (\lambda \vec{v}) = \lambda (\vec{u} \cdot \vec{v})$</li>
<li style="margin:0 0 8px 0;"><strong>Distributivité :</strong> $\displaystyle \vec{u} \cdot (\vec{v} + \vec{w}) = \vec{u} \cdot \vec{v} + \vec{u} \cdot \vec{w}$</li>
<li style="margin:0;"><strong>Bilinéarité :</strong> Le produit scalaire est linéaire par rapport à chacune de ses deux variables</li>
</ul>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Expression en base orthonormée</strong></p>
<p style="margin:5px 0 0 0;">Dans une base orthonormée $\displaystyle (\vec{i}, \vec{j})$, si $\displaystyle \vec{u}(x_1, y_1)$ et $\displaystyle \vec{v}(x_2, y_2)$, alors :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = x_1 x_2 + y_1 y_2$</p>
</div>
<p style="margin:5px 0 0 0;">Dans l'espace, avec une base orthonormée $\displaystyle (\vec{i}, \vec{j}, \vec{k})$, si $\displaystyle \vec{u}(x_1, y_1, z_1)$ et $\displaystyle \vec{v}(x_2, y_2, z_2)$, alors :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \vec{u} \cdot \vec{v} = x_1 x_2 + y_1 y_2 + z_1 z_2$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e0f2f1; border-left:4px solid #00897b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Expression de la norme</strong></p>
<p style="margin:5px 0 0 0;">Dans une base orthonormée, si $\displaystyle \vec{u}(x, y)$, alors :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \|\vec{u}\| = \sqrt{x^2 + y^2}$ et $\displaystyle \|\vec{u}\|^2 = \vec{u} \cdot \vec{u}$</p>
<p style="margin:5px 0 0 0;">Dans l'espace, si $\displaystyle \vec{u}(x, y, z)$, alors :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \|\vec{u}\| = \sqrt{x^2 + y^2 + z^2}$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Identité remarquable</strong></p>
<p style="margin:5px 0 0 0;">Pour tous vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \|\vec{u} + \vec{v}\|^2 = \|\vec{u}\|^2 + 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$</p>
</div>
<p style="margin:5px 0 0 0;">Autres identités :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">$\displaystyle \|\vec{u} - \vec{v}\|^2 = \|\vec{u}\|^2 - 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$</li>
<li style="margin:0;">$\displaystyle (\vec{u} + \vec{v}) \cdot (\vec{u} - \vec{v}) = \|\vec{u}\|^2 - \|\vec{v}\|^2$</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Formule d'Al-Kashi</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Formule d'Al-Kashi</strong></p>
<p style="margin:5px 0 0 0;">Dans un triangle $\displaystyle ABC$, on a :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle a^2 = b^2 + c^2 - 2bc \cos(\widehat{A})$</p>
</div>
<p style="margin:5px 0 0 0;">où $\displaystyle a = BC$, $\displaystyle b = CA$, $\displaystyle c = AB$ et $\displaystyle \widehat{A}$ est l'angle au sommet $\displaystyle A$.</p>
<p style="margin:5px 0 0 0;">De même : $\displaystyle b^2 = a^2 + c^2 - 2ac \cos(\widehat{B})$ et $\displaystyle c^2 = a^2 + b^2 - 2ab \cos(\widehat{C})$</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_4]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Cas particulier - Théorème de Pythagore :</strong></p>
<p style="margin:5px 0 0 0;">Si $\displaystyle \widehat{A} = 90°$ (triangle rectangle en $\displaystyle A$), alors $\displaystyle \cos(\widehat{A}) = 0$.</p>
<p style="margin:5px 0 0 0;">La formule d'Al-Kashi devient : $\displaystyle a^2 = b^2 + c^2$, ce qui est le <strong>théorème de Pythagore</strong>.</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Transformation de l'expression $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB}$</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Propriété - Transformation avec un point fixe</strong></p>
<p style="margin:5px 0 0 0;">Pour transformer l'expression $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB}$, on utilise la relation de Chasles :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \overrightarrow{MA} = \overrightarrow{MO} + \overrightarrow{OA}$ et $\displaystyle \overrightarrow{MB} = \overrightarrow{MO} + \overrightarrow{OB}$</p>
<p style="margin:5px 0 0 0;">où $\displaystyle O$ est un point fixe choisi judicieusement (par exemple le milieu de $\displaystyle [AB]$).</p>
</div>
</div>

<div style="text-align:center; margin:20px 0;">
[IMAGE_5]
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Ensemble des points M</strong></p>
<p style="margin:5px 0 0 0;">L'ensemble des points $\displaystyle M$ du plan tels que $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB} = 0$ est le <strong>cercle de diamètre $\displaystyle [AB]$</strong>.</p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle I$ le milieu de $\displaystyle [AB]$, alors :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB} = 0 \Leftrightarrow MI^2 = \left(\frac{AB}{2}\right)^2 \Leftrightarrow MI = \frac{AB}{2}$</p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Erreurs fréquentes</h2>

<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre produit scalaire et produit de nombres</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;"><strong>$\displaystyle \vec{u} \cdot \vec{v}$ est un nombre</strong>, pas un vecteur<br/>Le résultat est toujours un scalaire (nombre réel)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier la symétrie</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$<br/>L'ordre des vecteurs n'a pas d'importance</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Erreur sur la distributivité</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">$\displaystyle (\vec{u} + \vec{v}) \cdot \vec{w} = \vec{u} \cdot \vec{w} + \vec{v} \cdot \vec{w}$<br/>Attention : $\displaystyle \vec{u} \cdot (\vec{v} + \vec{w}) = \vec{u} \cdot \vec{v} + \vec{u} \cdot \vec{w}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier l'orthogonalité</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \vec{u} \perp \vec{v} \Leftrightarrow \vec{u} \cdot \vec{v} = 0$<br/>C'est la caractérisation principale de l'orthogonalité</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Base non orthonormée</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Vérifier que la base est bien <strong>orthonormée</strong> avant d'utiliser $\displaystyle \vec{u} \cdot \vec{v} = x_1 x_2 + y_1 y_2$<br/>Cette formule n'est valable que dans une base orthonormée</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Confondre norme au carré</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \|\vec{u}\|^2 = \vec{u} \cdot \vec{u}$ existe<br/>Mais $\displaystyle \|\vec{u}^2\|$ n'existe pas (on ne peut pas élever un vecteur au carré)</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; padding:18px 16px;">Erreur sur l'angle</td>
<td style="border:none; padding:18px 16px;">L'angle dans la formule du produit scalaire est l'angle <strong>géométrique</strong> ($\displaystyle 0 \leq \theta \leq \pi$)<br/>Pas l'angle orienté</td>
</tr>
</tbody>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Formules essentielles — mémo rapide</h2>

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">

<tr style="background:#f8f9fa;">

<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \|\vec{u}\| = \sqrt{\vec{u} \cdot \vec{u}} = \sqrt{x^2 + y^2}$</td>

<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Identité remarquable</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \|\vec{u} + \vec{v}\|^2 = \|\vec{u}\|^2 + 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Orthogonalité</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \vec{u} \perp \vec{v} \Leftrightarrow \vec{u} \cdot \vec{v} = 0$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Formule d'Al-Kashi</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle a^2 = b^2 + c^2 - 2bc \cos(\widehat{A})$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Transformation $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB}$</td>
<td style="border:none; padding:18px 16px;">$\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB} = MI^2 - \left(\frac{AB}{2}\right)^2$<br/>où $\displaystyle I$ est le milieu de $\displaystyle [AB]$</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Méthodologie — stratégie de résolution</h2>

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ffa500; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(255,165,0,0.15); table-layout:fixed;">

<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer un produit scalaire</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Si base orthonormée : utiliser $\displaystyle \vec{u} \cdot \vec{v} = x_1 x_2 + y_1 y_2$<br/>2. Si normes et angle connus : $\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\| \times \|\vec{v}\| \times \cos(\theta)$<br/>3. Si normes uniquement : utiliser l'identité remarquable</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Démontrer une orthogonalité</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer $\displaystyle \vec{u} \cdot \vec{v}$<br/>Si $\displaystyle \vec{u} \cdot \vec{v} = 0$, alors $\displaystyle \vec{u} \perp \vec{v}$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer un angle</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Calculer $\displaystyle \vec{u} \cdot \vec{v}$, $\displaystyle \|\vec{u}\|$ et $\displaystyle \|\vec{v}\|$<br/>2. Utiliser : $\displaystyle \cos(\theta) = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\| \times \|\vec{v}\|}$<br/>3. Déterminer $\displaystyle \theta$ à partir de $\displaystyle \cos(\theta)$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Calculer une longueur</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Utiliser la formule d'Al-Kashi ou calculer directement :<br/>$\displaystyle AB = \|\overrightarrow{AB}\| = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2}$</td>
</tr>

<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Transformer $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB}$</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Choisir un point fixe $\displaystyle O$ (souvent le milieu de $\displaystyle [AB]$)<br/>2. Utiliser la relation de Chasles<br/>3. Développer et simplifier</td>

<td style="border:none; padding:18px 16px;">Déterminer un ensemble de points</td>
<td style="border:none; padding:18px 16px;">1. Transformer l'expression avec un point fixe<br/>2. Identifier la condition géométrique<br/>3. Conclure sur la nature de l'ensemble (cercle, droite, etc.)</td>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#f8f9fa; border-left:4px solid #6c757d; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Exemple - Calculer un produit scalaire :</strong></p>
<p style="margin:5px 0 0 0;"><strong>Calculer $\displaystyle \vec{u}(3, 4) \cdot \vec{v}(-1, 2)$</strong></p>
<p style="margin:5px 0 0 0;">Dans une base orthonormée :</p>
<p style="margin:5px 0 0 0;">$\displaystyle \vec{u} \cdot \vec{v} = 3 \times (-1) + 4 \times 2 = -3 + 8 = 5$</p>
<p style="margin:5px 0 0 0;">Vérification : $\displaystyle \|\vec{u}\| = \sqrt{3^2 + 4^2} = 5$ et $\displaystyle \|\vec{v}\| = \sqrt{(-1)^2 + 2^2} = \sqrt{5}$</p>
<p style="margin:5px 0 0 0;">$\displaystyle \cos(\theta) = \frac{5}{5 \times \sqrt{5}} = \frac{1}{\sqrt{5}} = \frac{\sqrt{5}}{5}$</p>
</div>

<p style="margin:0;"><strong>💡 Points de vigilance :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Toujours vérifier que la base est orthonormée avant d'utiliser la formule avec coordonnées</li>
<li style="margin:0 0 8px 0;">Choisir la méthode la plus adaptée selon les données disponibles (coordonnées, normes, angle)</li>
<li style="margin:0 0 8px 0;">Utiliser la symétrie et la distributivité pour simplifier les calculs</li>
<li style="margin:0 0 8px 0;">Pour transformer $\displaystyle \overrightarrow{MA} \cdot \overrightarrow{MB}$, choisir judicieusement le point fixe (souvent le milieu)</li>
<li style="margin:0;">Se rappeler que le produit scalaire est un nombre, pas un vecteur</li>
</ul>
