    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">I. Définition et création</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Liste :</strong> Structure de données qui permet de stocker une collection ordonnée d'éléments modifiables
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Syntaxe :</strong> <code>ma_liste = [élément1, élément2, élément3]</code>
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Caractéristiques :</strong> Ordonnée, modifiable, peut contenir différents types, accepte les doublons
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">II. Indexation - Accès aux éléments</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Indexation positive (de gauche à droite)</h3>
        <div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>L'index commence à 0</strong></p>
            <p style="margin:8px 0; font-family:monospace;">ma_liste = ["A", "B", "C", "D"]</p>
            <ul style="margin:8px 0; padding-left:20px;">
                <li><code>ma_liste[0]</code> → "A" (premier élément)</li>
                <li><code>ma_liste[1]</code> → "B" (deuxième élément)</li>
                <li><code>ma_liste[2]</code> → "C" (troisième élément)</li>
                <li><code>ma_liste[3]</code> → "D" (quatrième élément)</li>
            </ul>
        </div>
        
        <h3 style="color:#34495e; margin-top:15px;">Indexation négative (de droite à gauche)</h3>
        <div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>L'index -1 donne le dernier élément</strong></p>
            <p style="margin:8px 0; font-family:monospace;">ma_liste = ["A", "B", "C", "D"]</p>
            <ul style="margin:8px 0; padding-left:20px;">
                <li><code>ma_liste[-1]</code> → "D" (dernier élément)</li>
                <li><code>ma_liste[-2]</code> → "C" (avant-dernier)</li>
                <li><code>ma_liste[-3]</code> → "B"</li>
                <li><code>ma_liste[-4]</code> → "A"</li>
            </ul>
        </div>
        
        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #f59e0b;">
            <strong>⚠️ À retenir :</strong> Index 0 = premier élément, Index -1 = dernier élément
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">III. Modification des listes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Opération</th>
                    <th style="border:1px solid #ddd; padding:12px;">Méthode</th>
                    <th style="border:1px solid #ddd; padding:12px;">Exemple</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><strong>Modifier un élément</strong></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>liste[index] = valeur</code></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>notes[1] = 25</code></td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;"><strong>Ajouter à la fin</strong></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>append()</code></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>fruits.append("orange")</code></td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><strong>Insérer à une position</strong></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>insert(index, valeur)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>lettres.insert(1, "B")</code></td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;"><strong>Supprimer un élément</strong></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>remove(valeur)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>couleurs.remove("bleu")</code></td>
                </tr>
            </tbody>
        </table>
        
        <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #f59e0b;">
            <strong>⚠️ Attention :</strong> <code>remove()</code> supprime la première occurrence et provoque une erreur si l'élément n'existe pas
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IV. Méthodes utiles des listes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Informations sur la liste</h3>
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Méthode</th>
                    <th style="border:1px solid #ddd; padding:12px;">Description</th>
                    <th style="border:1px solid #ddd; padding:12px;">Exemple</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>len(liste)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Nombre d'éléments</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>len([1, 2, 3])</code> → 3</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>index(valeur)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Position d'un élément</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>[5, 2, 8].index(8)</code> → 2</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>count(valeur)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Nombre d'occurrences</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>[1, 2, 2, 3].count(2)</code> → 2</td>
                </tr>
            </tbody>
        </table>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Tri et organisation</h3>
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Méthode</th>
                    <th style="border:1px solid #ddd; padding:12px;">Description</th>
                    <th style="border:1px solid #ddd; padding:12px;">Exemple</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>sort()</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Trie par ordre croissant</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>[3, 1, 2].sort()</code> → [1, 2, 3]</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>reverse()</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Inverse l'ordre</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>[1, 2, 3].reverse()</code> → [3, 2, 1]</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>max(liste)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Élément le plus grand</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>max([5, 2, 8])</code> → 8</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;"><code>min(liste)</code></td>
                    <td style="border:1px solid #ddd; padding:10px;">Élément le plus petit</td>
                    <td style="border:1px solid #ddd; padding:10px;"><code>min([5, 2, 8])</code> → 2</td>
                </tr>
            </tbody>
        </table>
        
        <div style="background:#e8f5e8; padding:10px; border-radius:4px; margin:10px 0;">
            <strong>💡 Note :</strong> <code>sort()</code> et <code>reverse()</code> modifient la liste directement
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">V. Parcourir une liste</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Parcours direct (FOR... IN)</h3>
        <div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>Syntaxe :</strong></p>
            <div style="background:#2c3e50; color:#ffffff; padding:10px; border-radius:4px; font-family:monospace; margin:8px 0;">
                couleurs = [<span style="color:#f1fa8c;">"rouge"</span>, <span style="color:#f1fa8c;">"vert"</span>, <span style="color:#f1fa8c;">"bleu"</span>]<br>
                <br>
                <span style="color:#ff79c6;">for</span> couleur <span style="color:#ff79c6;">in</span> couleurs:<br>
                &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(couleur)
            </div>
            <p style="margin:8px 0;"><strong>Principe :</strong> Parcourt chaque élément directement</p>
        </div>
        
        <h3 style="color:#34495e; margin-top:15px;">Parcours avec index (FOR... RANGE)</h3>
        <div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>Syntaxe :</strong></p>
            <div style="background:#2c3e50; color:#ffffff; padding:10px; border-radius:4px; font-family:monospace; margin:8px 0;">
                fruits = [<span style="color:#f1fa8c;">"pomme"</span>, <span style="color:#f1fa8c;">"banane"</span>, <span style="color:#f1fa8c;">"orange"</span>]<br>
                <br>
                <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#50fa7b;">len</span>(fruits)):<br>
                &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"</span><span style="color:#8be9fd;">{i}</span><span style="color:#f1fa8c;"> : </span><span style="color:#8be9fd;">{fruits[i]}</span><span style="color:#f1fa8c;">"</span>)
            </div>
            <p style="margin:8px 0;"><strong>Principe :</strong> Utilise les index pour accéder aux éléments</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VI. Exemples pratiques</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple 1 : Création et accès</h3>
        <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
            notes = [<span style="color:#bd93f9;">15</span>, <span style="color:#bd93f9;">12</span>, <span style="color:#bd93f9;">18</span>, <span style="color:#bd93f9;">10</span>, <span style="color:#bd93f9;">16</span>]<br>
            <br>
            <span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"Première note : </span><span style="color:#8be9fd;">{notes[0]}</span><span style="color:#f1fa8c;">"</span>)<br>
            <span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"Dernière note : </span><span style="color:#8be9fd;">{notes[-1]}</span><span style="color:#f1fa8c;">"</span>)
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Résultat :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li><code>notes[0]</code> → 15 (premier élément)</li>
                <li><code>notes[-1]</code> → 16 (dernier élément)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple 2 : Modification de liste</h3>
        <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
            fruits = [<span style="color:#f1fa8c;">"pomme"</span>, <span style="color:#f1fa8c;">"banane"</span>]<br>
            fruits.append(<span style="color:#f1fa8c;">"orange"</span>)<br>
            fruits.insert(<span style="color:#bd93f9;">1</span>, <span style="color:#f1fa8c;">"kiwi"</span>)<br>
            fruits[<span style="color:#bd93f9;">0</span>] = <span style="color:#f1fa8c;">"cerise"</span>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Évolution :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Début : <code>["pomme", "banane"]</code></li>
                <li>Après append : <code>["pomme", "banane", "orange"]</code></li>
                <li>Après insert : <code>["pomme", "kiwi", "banane", "orange"]</code></li>
                <li>Après modification : <code>["cerise", "kiwi", "banane", "orange"]</code></li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple 3 : Gestion de notes</h3>
        <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
            notes = [<span style="color:#bd93f9;">14</span>, <span style="color:#bd93f9;">12</span>, <span style="color:#bd93f9;">16</span>, <span style="color:#bd93f9;">10</span>, <span style="color:#bd93f9;">18</span>, <span style="color:#bd93f9;">15</span>]<br>
            <br>
            <span style="color:#6272a4;"># Calcul de la moyenne</span><br>
            somme = <span style="color:#bd93f9;">0</span><br>
            <span style="color:#ff79c6;">for</span> note <span style="color:#ff79c6;">in</span> notes:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;somme = somme + note<br>
            moyenne = somme / <span style="color:#50fa7b;">len</span>(notes)<br>
            <br>
            <span style="color:#6272a4;"># Meilleure et pire note</span><br>
            meilleure = <span style="color:#50fa7b;">max</span>(notes)<br>
            pire = <span style="color:#50fa7b;">min</span>(notes)
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Résultats :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Somme : 14 + 12 + 16 + 10 + 18 + 15 = 85</li>
                <li>Moyenne : 85 / 6 = 14.2</li>
                <li>Meilleure note : 18</li>
                <li>Pire note : 10</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemple 4 : Filtrer une liste</h3>
        <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
            notes = [<span style="color:#bd93f9;">15</span>, <span style="color:#bd93f9;">8</span>, <span style="color:#bd93f9;">18</span>, <span style="color:#bd93f9;">10</span>, <span style="color:#bd93f9;">16</span>, <span style="color:#bd93f9;">14</span>]<br>
            bonnes_notes = []<br>
            <br>
            <span style="color:#ff79c6;">for</span> note <span style="color:#ff79c6;">in</span> notes:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">if</span> note > <span style="color:#bd93f9;">12</span>:<br>
            &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;bonnes_notes.append(note)<br>
            <br>
            <span style="color:#50fa7b;">print</span>(bonnes_notes)
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Résultat :</strong> <code>[15, 18, 16, 14]</code>
        </div>
    </div>

        <td style="border:1px solid #ddd; padding:10px;"><code>ma_liste = [élément1, élément2]</code></td>

        <tr style="background:#f8f9fa;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Longueur</strong></td>
        <td style="border:1px solid #ddd; padding:10px;"><code>len(ma_liste)</code> donne le nombre d'éléments</td>
        </tr>
        <tr style="background:#ffffff;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Ajouter</strong></td>
        <td style="border:1px solid #ddd; padding:10px;"><code>append()</code> à la fin, <code>insert()</code> à une position</td>
        </tr>
        <tr style="background:#f8f9fa;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Supprimer</strong></td>
        <td style="border:1px solid #ddd; padding:10px;"><code>remove()</code> supprime la première occurrence</td>
        </tr>
        <tr style="background:#ffffff;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Parcourir</strong></td>
        <td style="border:1px solid #ddd; padding:10px;"><code>for élément in ma_liste:</code> ou <code>for i in range(len(ma_liste)):</code></td>
        </tr>
        <tr style="background:#f8f9fa;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Trier</strong></td>
        <td style="border:1px solid #ddd; padding:10px;"><code>sort()</code> et <code>reverse()</code> modifient la liste directement</td>
        </tr>
        <tr style="background:#ffffff;">
        <td style="border:1px solid #ddd; padding:10px;"><strong>Caractéristiques</strong></td>
        <td style="border:1px solid #ddd; padding:10px;">Ordonnée, modifiable, types mixtes, accepte les doublons</td>
        </tr>
        </tbody>
        </table>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VIII. Erreurs fréquentes à éviter</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fdf2f2; padding:15px; border-radius:6px; margin-bottom:15px;">
            <strong>❌ Pièges à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; font-size:1em;">
                <li><strong>Index out of range :</strong> Accéder à un index qui n'existe pas (ex: <code>ma_liste[10]</code> sur une liste de 3 éléments)</li>
                <li><strong>remove() sur élément inexistant :</strong> <code>remove()</code> provoque une erreur si l'élément n'est pas trouvé</li>
                <li><strong>Confondre index et position :</strong> Le premier élément est à l'index 0, pas 1</li>
                <li><strong>Modifier pendant le parcours :</strong> Éviter de modifier une liste pendant qu'on la parcourt</li>
                <li><strong>Oublier les crochets :</strong> <code>ma_liste = 1, 2, 3</code> crée un tuple, pas une liste</li>
                <li><strong>Confondre sort() et sorted() :</strong> <code>sort()</code> modifie la liste, <code>sorted()</code> retourne une nouvelle liste</li>
            </ul>
        </div>

        <div style="background:#f0f9f0; padding:15px; border-radius:6px;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; font-size:1em;">
                <li>Toujours vérifier la longueur avec <code>len()</code> avant d'accéder à un index</li>
                <li>Utiliser <code>in</code> pour vérifier si un élément existe : <code>if "pomme" in fruits:</code></li>
                <li>Utiliser des noms de variables explicites : <code>liste_notes</code> plutôt que <code>l</code></li>
                <li>Initialiser les listes vides avec <code>[]</code> pour les remplir progressivement</li>
                <li>Utiliser <code>append()</code> pour ajouter un élément, <code>extend()</code> pour plusieurs</li>
                <li>Vérifier l'index : <code>if index < len(ma_liste):</code> avant <code>ma_liste[index]</code></li>
            </ul>
        </div>
