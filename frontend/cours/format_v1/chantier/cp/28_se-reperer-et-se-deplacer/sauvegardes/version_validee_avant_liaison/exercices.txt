Découverte - Être entre deux objets
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe la rangée d’objets A,B,C.

[IMAGE_1]

1. Quel objet est entre A et C ?
2. Quel objet est à gauche de B sur le dessin ?
3. Quel objet est à droite de B ?
4. Combien d’objets forment cette rangée ?
5. Si tu échanges A et C, qui reste entre les deux ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel objet est entre A et C ?

::: methode
Cherche l’objet au milieu.
:::

::: etape Raisonner
B a A d’un côté et C de l’autre.
:::

::: resultat
B.
:::

## Question 2 : Quel objet est à gauche de B sur le dessin ?

::: methode
Regarde la rangée comme elle est présentée.
:::

::: etape Raisonner
A se trouve à gauche de B.
:::

::: resultat
A.
:::

## Question 3 : Quel objet est à droite de B ?

::: methode
Observe l’autre côté de B.
:::

::: etape Raisonner
C est à droite de B.
:::

::: resultat
C.
:::

## Question 4 : Combien d’objets forment cette rangée ?

::: methode
Compte chacun une seule fois.
:::

::: etape Raisonner
A,B,C font trois objets.
:::

::: resultat
3 objets.
:::

## Question 5 : Si tu échanges A et C, qui reste entre les deux ?

::: methode
L’objet du milieu ne bouge pas.
:::

::: etape Raisonner
B conserve sa place au milieu.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
B.
:::

Solution:
<!-- optitab:1 -->
1. B.
2. A.
3. C.
4. 3 objets.
5. B.

3. Les deux formes doivent-elles se superposer ?
4. Complète ton dessin.
5. Comment contrôles-tu la position ?

<!-- optitab:1 -->

## Question 1 : Où prépares-tu le carré ?

::: methode

:::

::: etape Raisonner
Tu peux placer le carré dans la zone de droite.
:::

::: resultat
À droite du rond à dessiner.
:::

## Question 2 : Où dessines-tu le rond ?

::: methode
Utilise la gauche du lecteur qui regarde la feuille.
:::

::: etape Raisonner
Il doit être à gauche du carré.
:::

::: resultat
À gauche du carré.
:::

## Question 3 : Les deux formes doivent-elles se superposer ?

::: methode
La consigne demande une position l’une par rapport à l’autre.
:::

::: etape Raisonner
On peut laisser un espace entre elles.
:::

::: resultat
Non.
:::

## Question 4 : Complète ton dessin.

::: methode

:::

::: etape Raisonner

:::

::: etape Vérifier

:::

::: resultat

## Question 5 : Comment contrôles-tu la position ?
