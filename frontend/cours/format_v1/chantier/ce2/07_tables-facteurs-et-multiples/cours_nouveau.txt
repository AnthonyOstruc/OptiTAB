Titre: Tables, facteurs et multiples
<!-- optitab:1 -->

::: objectifs
Je retrouve les produits et je reconnais des multiples.

- Expliquer les étapes avec des mots simples.
- Contrôler le résultat obtenu.
:::

## I. Comprendre

::: propriete Repère 1
Les nombres multipliés sont les facteurs. Le résultat est le produit.
:::

::: propriete Repère 2
Un multiple de 6 est le résultat de 6 multiplié par un entier : 0, 6, 12, 18…
:::

::: propriete Repère 3
Les tables se lisent dans les deux sens : 7 × 8 = 56, donc 7 × … = 56 se complète par 8.
:::

## II. Faire pas à pas

::: methode Je cherche avant de calculer
Je lis la consigne. Je repère les nombres et ce qu’ils comptent. Je choisis une méthode puis je garde les étapes utiles sur mon ardoise.
:::

[IMAGE_1]

::: exemple Un calcul expliqué
Je retrouve le résultat dans la table de multiplication.

$$
8\times 7 = 56
$$
:::

### À toi, avec de l’aide

Complète 9 × … = 63 et nomme les facteurs.

::: exemple Je vérifie ma recherche
Je retrouve le résultat dans la table de multiplication.

$$
9\times 7 = 63
$$

7 ; les facteurs sont 9 et 7, le produit est 63.
:::

## III. Vérifier et choisir

::: attention Le piège à éviter
Multiplier par zéro donne zéro. Les deux facteurs jouent des rôles différents dans une histoire même si le produit est commutatif.
:::

::: conseil Si je bloque
Je dessine des groupes égaux. Je retrouve un produit oublié grâce à un produit que je connais.
:::

::: retenir
Je retrouve les produits et je reconnais des multiples.
:::
