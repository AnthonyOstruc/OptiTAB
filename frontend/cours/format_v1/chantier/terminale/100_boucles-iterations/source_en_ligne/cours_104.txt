## I. Boucles et fonction `range`

Une **boucle** répète un bloc d'instructions. Python en propose deux :

- la boucle **bornée** `for`, quand le nombre de répétitions est connu à l'avance ;
- la boucle **non bornée** `while`, quand on répète tant qu'une condition est vraie.

La fonction `range` fournit les valeurs parcourues par une boucle `for`.

::: definition La fonction `range`
- `range(n)` produit les entiers $0$, $1$, …, $n-1$ : il y en a $n$.
- `range(a, b)` produit les entiers de $a$ à $b-1$ : la borne $b$ est **exclue** et il y a $b-a$ valeurs.
- `range(a, b, p)` produit $a$, $a+p$, $a+2p$, … en s'arrêtant avant $b$ ; le pas $p$ peut être négatif.
:::

| Instruction | Valeurs produites | Nombre |
|---|---|---|
| `range(5)` | $0$, $1$, $2$, $3$, $4$ | $5$ |
| `range(2, 6)` | $2$, $3$, $4$, $5$ | $4$ |
| `range(1, 10, 3)` | $1$, $4$, $7$ | $3$ |
| `range(10, 0, -2)` | $10$, $8$, $6$, $4$, $2$ | $5$ |
| `range(5, 2)` | aucune | $0$ |

::: exemple Afficher les valeurs avec `list`
```python
print(list(range(2, 6)))
print(list(range(10, 0, -2)))
```

```console
[2, 3, 4, 5]
[10, 8, 6, 4, 2]
```
:::

::: attention Aller jusqu'à $n$ inclus
`range(1, n)` s'arrête à $n-1$. Pour parcourir les entiers de $1$ à $n$, on écrit `range(1, n + 1)`.
:::

## II. La boucle bornée `for`

::: definition Boucle bornée
L'instruction `for i in range(…):` répète le **bloc indenté** qui la suit pour chaque valeur produite par `range`, dans l'ordre : la variable `i` prend successivement chacune de ces valeurs. Le nombre de tours est connu à l'avance.
:::

::: exemple Un premier programme
```python
for i in range(1, 6):
    print(i, i**2)
print("Fin")
```

```console
1 1
2 4
3 9
4 16
5 25
Fin
```

L'instruction `print(i, i**2)` est indentée : elle est exécutée à chaque tour, soit $5$ fois (`i**2` désigne $i^2$). L'instruction `print("Fin")` n'est pas indentée : elle est exécutée une seule fois, après la boucle.
:::

::: remarque Syntaxe
La ligne `for` se termine par deux-points `:` et le bloc répété est décalé de $4$ espaces. C'est l'**indentation** qui délimite ce qui est répété.
:::

### Parcourir une chaîne de caractères

Une boucle `for` peut aussi parcourir directement les caractères d'une chaîne, ou les éléments d'une liste (voir la notion « Listes »).

```python
for lettre in "PYTHON":
    print(lettre, end=" ")
```

```console
P Y T H O N
```

L'option `end=" "` remplace le retour à la ligne par une espace : tout s'affiche sur une seule ligne.

## III. Accumulateurs et tableau d'état

::: definition Accumulateur
Un **accumulateur** est une variable qui construit un résultat au fil des tours :

1. on l'**initialise** avant la boucle ($0$ pour une somme, $1$ pour un produit) ;
2. on le **met à jour** à chaque tour ;
3. on l'**utilise** après la boucle.
:::

::: exemple Calculer $1 + 2 + 3 + 4$
```python
s = 0
for k in range(1, 5):
    s = s + k
print(s)
```

```console
10
```

Le **tableau d'état** donne les valeurs des variables à la fin de chaque tour :

| Étape | `k` | `s` |
|---|---|---|
| avant la boucle | — | $0$ |
| tour 1 | $1$ | $1$ |
| tour 2 | $2$ | $3$ |
| tour 3 | $3$ | $6$ |
| tour 4 | $4$ | $10$ |
:::

::: methode Calculer un produit : la factorielle
Pour $n \ge 1$, $n! = 1 \times 2 \times \dots \times n$. L'accumulateur d'un produit s'initialise à $1$ : avec $0$, le produit resterait nul.

```python
def factorielle(n):
    p = 1
    for k in range(1, n + 1):
        p = p * k
    return p

print(factorielle(5))
print(factorielle(10))
```

```console
120
3628800
```
:::

::: exemple Moyenne d'une liste de notes
```python
notes = [14, 12, 16, 10, 18]
somme = 0
for note in notes:
    somme = somme + note
print(somme / len(notes))
```

```console
14.0
```

`len(notes)` est le nombre d'éléments de la liste : la moyenne vaut $\dfrac{70}{5} = 14$.
:::

::: methode Calculer un terme d'une suite définie par récurrence
Pour $u_0 = 3$ et $u_{n+1} = 2u_n - 1$, on part de $u_0$ et on applique $n$ fois la relation de récurrence : la boucle fait $n$ tours, la variable `k` ne sert qu'à les compter.

```python
def terme(n):
    u = 3
    for k in range(n):
        u = 2 * u - 1
    return u

for n in range(6):
    print(n, terme(n))
```

```console
0 3
1 5
2 9
3 17
4 33
5 65
```

On conjecture, puis on démontre par récurrence, que $u_n = 2^{n+1} + 1$ pour tout entier naturel $n$.
:::

::: remarque Écritures raccourcies
`s += k` signifie `s = s + k` ; `p *= k` signifie `p = p * k` ; `n += 1` signifie `n = n + 1`.
:::

## IV. La boucle non bornée `while`

::: definition Boucle non bornée
L'instruction `while condition:` répète le bloc indenté **tant que** la condition est vraie. La condition est testée **avant** chaque tour : si elle est fausse dès le départ, le bloc n'est jamais exécuté. Le nombre de tours n'est pas connu à l'avance.
:::

[IMAGE_1]

::: exemple Doubler tant que le nombre est inférieur à $100$
```python
n = 1
while n < 100:
    n = 2 * n
print(n)
```

```console
128
```

`n` prend les valeurs $1$, $2$, $4$, $8$, $16$, $32$, $64$ puis $128$. Pour $n = 128$, le test `n < 100` est faux : la boucle s'arrête et le programme affiche $128$.
:::

::: attention Boucle infinie
Le bloc doit modifier une variable de la condition, sinon la condition reste vraie et la boucle ne s'arrête jamais. Sans la ligne `n = 2 * n`, le programme ci-dessus tournerait indéfiniment (on l'interrompt avec Ctrl + C).
:::

::: methode Algorithme de seuil
On cherche le plus petit entier $n$ tel que $1{,}5^n \gt 100$. On répète la multiplication **tant que** le seuil n'est pas dépassé, en comptant les tours.

```python
u = 1
n = 0
while u <= 100:
    u = 1.5 * u
    n = n + 1
print(n)
```

```console
12
```

La condition de la boucle est le **contraire** de la condition d'arrêt : on veut s'arrêter dès que $u \gt 100$, on répète donc tant que $u \le 100$. À la sortie de la boucle, $u = 1{,}5^n$.

**Vérification :** comme $\ln(1{,}5) \gt 0$,

$$
\begin{aligned}
&1{,}5^n \gt 100 \\
\iff\ &n\ln(1{,}5) \gt \ln(100) \\
\iff\ &n \gt \frac{\ln(100)}{\ln(1{,}5)} \approx 11{,}36
\end{aligned}
$$

donc $n = 12$.
:::

[IMAGE_2]

::: remarque S'assurer que le seuil est atteint
Avant d'écrire un algorithme de seuil, on vérifie que le seuil sera dépassé : ici $\lim\limits_{n \to +\infty} 1{,}5^n = +\infty$ car $1{,}5 \gt 1$. Pour une suite croissante qui converge vers $15$, la condition « $u \le 16$ » resterait toujours vraie : la boucle ne s'arrêterait jamais.
:::

## V. Les instructions `break` et `continue`

::: definition
- `break` interrompt **immédiatement** la boucle ; le programme reprend après la boucle.
- `continue` interrompt le tour en cours et passe **directement au tour suivant**.
:::

::: exemple `break` : premier carré supérieur à $500$
```python
for n in range(1, 100):
    if n**2 > 500:
        break
print(n)
```

```console
23
```

$22^2 = 484 \le 500$ et $23^2 = 529 \gt 500$ : la boucle est interrompue pour $n = 23$, les valeurs suivantes ne sont pas parcourues.
:::

::: exemple `continue` : sauter les nombres pairs
```python
for i in range(1, 16):
    if i % 2 == 0:
        continue
    print(i, end=" ")
```

```console
1 3 5 7 9 11 13 15
```

`i % 2` est le reste de la division euclidienne de `i` par $2$ : le test `i % 2 == 0` signifie « `i` est pair ». Pour un nombre pair, `continue` fait sauter l'affichage.
:::

::: remarque
`break` et `continue` ne sont jamais indispensables : une boucle `while` avec une condition bien choisie, ou un simple test `if`, donne le même résultat, souvent de façon plus lisible.
:::

## VI. Boucles imbriquées

::: propriete
Une boucle placée dans une autre est exécutée **entièrement** à chaque tour de la boucle extérieure : si la boucle extérieure fait $n$ tours et la boucle intérieure $p$ tours, le bloc intérieur est exécuté $n \times p$ fois.
:::

::: exemple Dénombrer avec deux dés
On lance deux dés équilibrés. Combien d'issues donnent une somme égale à $7$ ?

```python
nb = 0
for d1 in range(1, 7):
    for d2 in range(1, 7):
        if d1 + d2 == 7:
            nb = nb + 1
print(nb, "sur 36")
```

```console
6 sur 36
```

Les deux boucles parcourent les $6 \times 6 = 36$ couples $(d_1\,;d_2)$ : pour chaque valeur de `d1`, la variable `d2` prend les $6$ valeurs. La probabilité d'obtenir une somme égale à $7$ est $\dfrac{6}{36} = \dfrac{1}{6}$.
:::

## VII. Deux algorithmes classiques

### 1. La méthode de dichotomie

La fonction $f : x \mapsto x^3 + x - 1$ est continue et strictement croissante sur $[0\,;1]$, avec $f(0) = -1 \lt 0$ et $f(1) = 1 \gt 0$ : l'équation $f(x) = 0$ admet une unique solution $\alpha$ dans $[0\,;1]$. À chaque tour, on coupe l'intervalle en deux et on garde la moitié où $f$ change de signe.

```python
def f(x):
    return x**3 + x - 1

def dichotomie(a, b, e):
    while b - a > e:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:
            b = m
        else:
            a = m
    return a, b

print(dichotomie(0, 1, 0.001))
```

```console
(0.681640625, 0.6826171875)
```

[IMAGE_4]

La longueur de l'intervalle est divisée par $2$ à chaque tour : après $n$ tours, elle vaut $\dfrac{1}{2^n}$. Comme $\dfrac{1}{2^9} \gt 0{,}001$ et $\dfrac{1}{2^{10}} = \dfrac{1}{1024} \le 0{,}001$, la boucle fait $10$ tours. On obtient l'encadrement $0{,}6816 \le \alpha \le 0{,}6827$.

### 2. Simuler une expérience aléatoire

La fonction `randint(1, 6)` du module `random` simule le lancer d'un dé équilibré. On compte les « $6$ » obtenus en $n$ lancers.

```python
from random import randint

def frequence_six(n):
    nb = 0
    for i in range(n):
        if randint(1, 6) == 6:
            nb = nb + 1
    return nb / n

print(frequence_six(10000))
```

Un affichage possible (le résultat change à chaque exécution) :

```console
0.1671
```

Pour $n$ grand, la fréquence obtenue est proche de la probabilité $\dfrac{1}{6} \approx 0{,}1667$ : c'est la loi des grands nombres.

::: remarque Les boucles dans tout le programme
Ces schémas reviennent dans toute l'année : boucle `for` pour la méthode des rectangles (intégrales), la méthode d'Euler (équations différentielles) ou la liste des coefficients binomiaux ; boucle `while` pour les seuils, la dichotomie ou la méthode de Newton.
:::

## VIII. Bien choisir sa boucle

| Situation | Instruction |
|---|---|
| nombre de tours connu | `for i in range(n):` |
| parcourir une chaîne, une liste | `for x in liste:` |
| répéter tant qu'une condition est vraie | `while condition:` |
| sortir immédiatement de la boucle | `break` |
| passer au tour suivant | `continue` |

::: attention Pièges fréquents
- `range(1, n)` s'arrête à $n-1$ : pour aller jusqu'à $n$, on écrit `range(1, n + 1)`.
- L'accumulateur s'initialise **avant** la boucle : placé dans la boucle, il serait remis à zéro à chaque tour.
- L'indentation décide de ce qui est répété : un `print` indenté s'exécute à chaque tour, sinon une seule fois, après la boucle.
- Oublier les deux-points `:` à la fin de la ligne `for` ou `while` provoque une erreur de syntaxe.
- Une boucle `while` dont la condition reste toujours vraie ne s'arrête jamais.
- Dans un algorithme de seuil, la condition du `while` est le **contraire** de la condition cherchée.
:::

::: retenir
- `range(a, b)` : entiers de $a$ à $b-1$, soit $b-a$ valeurs.
- `for` : nombre de tours connu ; `while` : tant qu'une condition est vraie.
- Accumulateur : initialiser, mettre à jour, utiliser ; $0$ pour une somme, $1$ pour un produit.
- Seuil : boucle `while` et compteur, puis vérification par le calcul (logarithme).
- Boucles imbriquées : le bloc intérieur est exécuté $n \times p$ fois.
