    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et cercle trigonométrique</h2>
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition géométrique</h3>
        
        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;">Les <strong>fonctions trigonométriques</strong> sont définies à partir du cercle trigonométrique (cercle unité de rayon 1 centré à l'origine).</p>
            <p style="margin:8px 0;">Pour un angle $\theta$ en radians, on considère un point $M$ sur le cercle tel que l'angle entre l'axe positif des abscisses et $OM$ soit $\theta$.</p>
        </div>

        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">

                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Définition</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\sin(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">Ordonnée du point $M$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">Abscisse du point $M$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\tan(\theta)$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\dfrac{\sin(\theta)}{\cos(\theta)}$ (si $\cos(\theta) \neq 0$)</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À retenir :</strong> Toutes les fonctions trigonométriques sont définies pour tout angle réel $\theta \in \mathbb{R}$, sauf $\tan(\theta)$ qui n'est pas définie quand $\cos(\theta) = 0$ (c'est-à-dire en $\dfrac{\pi}{2} + k\pi$).

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Propriétés fondamentales</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Relation fondamentale</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Relation fondamentale :</strong></p>
            <p style="margin:8px 0; text-align:center;">$\sin^2(\theta) + \cos^2(\theta) = 1$ pour tout $\theta \in \mathbb{R}$</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">

                <li style="margin:0; text-align:left;">$\sin(\theta) = \pm \sqrt{1 - \cos^2(\theta)}$</li>
                <li style="margin:0; text-align:left;">$\cos(\theta) = \pm \sqrt{1 - \sin^2(\theta)}$</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Dérivées des fonctions trigonométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Formules de dérivation</h3>

        <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
            <thead>
                <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Fonction</th>
                    <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Dérivée</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\sin(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(u) \cdot u'(x)$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\cos(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$-\sin(u) \cdot u'(x)$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\tan(u(x))$</td>
                    <td style="border:1px solid #ddd; padding:12px; text-align:center;">$\dfrac{1}{\cos^2(u)} \cdot u'(x) = \sec^2(u) \cdot u'(x)$</td>
                </tr>
            </tbody>
        </table>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> Pour $\tan(u)$, la formule $\dfrac{1}{\cos^2(u)}$ n'est valable que si $\cos(u) \neq 0$.
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples de calculs de dérivées</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Exemple 1</strong></p>
            <p style="margin:8px 0;"><strong>À calculer :</strong> Dérivée de $f(x) = \sin(3x)$</p>
            
            <div style="margin:12px 0;">
                <p style="margin:8px 0;"><strong>Résolution :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                    <li style="margin:0; text-align:left;">$u(x) = 3x$, donc $u'(x) = 3$</li>
                    <li style="margin:0; text-align:left;">$f'(x) = \cos(3x) \cdot u'(x) = \cos(3x) \cdot 3$</li>
                </ul>
            </div>
            
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Résultat :</strong> $f'(x) = 3\cos(3x)$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Exemple 2</strong></p>
            <p style="margin:8px 0;"><strong>À calculer :</strong> Dérivée de $f(x) = x^2 \cos(x)$ (produit)</p>
            
            <div style="margin:12px 0;">
                <p style="margin:8px 0;"><strong>Résolution :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                    <li style="margin:0; text-align:left;">$u(x) = x^2$ donc $u'(x) = 2x$</li>
                    <li style="margin:0; text-align:left;">$v(x) = \cos(x)$ donc $v'(x) = -\sin(x)$</li>
                    <li style="margin:0; text-align:left;">$(uv)' = u'v + uv'$</li>
                    <li style="margin:0; text-align:left;">$f'(x) = 2x \cdot \cos(x) + x^2 \cdot (-\sin(x))$</li>
                </ul>
            </div>
            
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Résultat :</strong> $f'(x) = 2x\cos(x) - x^2\sin(x)$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Exemple 3</strong></p>
            <p style="margin:8px 0;"><strong>À calculer :</strong> Dérivée de $f(x) = \tan(x^2 + 1)$ (composée)</p>
            
            <div style="margin:12px 0;">
                <p style="margin:8px 0;"><strong>Résolution :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                    <li style="margin:0 0 18px 0; text-align:left;">$u(x) = x^2 + 1$ donc $u'(x) = 2x$</li>
                    <li style="margin:0 0 18px 0; text-align:left;">$(\tan(u))' = \dfrac{1}{\cos^2(u)} \cdot u'$</li>
                    <li style="margin:0; text-align:left;">$f'(x) = \dfrac{1}{\cos^2(x^2 + 1)} \cdot 2x$</li>
                </ul>
            </div>
            
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Résultat :</strong> $f'(x) = \dfrac{2x}{\cos^2(x^2 + 1)}$
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Équations trigonométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de résolution</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode générale :</strong> Utiliser les formules d'addition et les valeurs remarquables
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <strong>Équations élémentaires :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2;">
                <li style="margin:0; text-align:left;">$\sin(x) = \sin(a) \Rightarrow x = a + 2k\pi$ ou $x = \pi - a + 2k\pi$</li>
                <li style="margin:0; text-align:left;">$\cos(x) = \cos(a) \Rightarrow x = \pm a + 2k\pi$</li>
                <li style="margin:0; text-align:left;">$\tan(x) = \tan(a) \Rightarrow x = a + k\pi$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples de résolution d'équations</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Exemple 1</strong></p>
            <p style="margin:8px 0;"><strong>Équation :</strong> Résoudre $\sin(x) = \dfrac{1}{2}$ sur $[0, 2\pi[$</p>
            
            <div style="margin:12px 0;">
                <p style="margin:8px 0;"><strong>Résolution :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 1 :</strong> Solutions générales : $x = \dfrac{\pi}{6} + 2k\pi$ ou $x = \pi - \dfrac{\pi}{6} + 2k\pi = \dfrac{5\pi}{6} + 2k\pi$</li>
                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 2 :</strong> Sur $[0, 2\pi[$ : pour $k=0$, on a $x = \dfrac{\pi}{6}$ et $x = \dfrac{5\pi}{6}$</li>
                    <li style="margin:0; text-align:left;"><strong>Étape 3 :</strong> Vérification : $\sin(\dfrac{\pi}{6}) = \dfrac{1}{2}$ ✓ et $\sin(\dfrac{5\pi}{6}) = \dfrac{1}{2}$ ✓</li>
                </ul>
            </div>
            
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $S = \left\{\dfrac{\pi}{6}, \dfrac{5\pi}{6}\right\}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <p style="margin:0 0 8px 0;"><strong>Exemple 2</strong></p>
            <p style="margin:8px 0;"><strong>Équation :</strong> Résoudre $2\cos^2(x) - 3\cos(x) + 1 = 0$</p>
            
            <div style="margin:12px 0;">
                <p style="margin:8px 0;"><strong>Résolution :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 1 :</strong> Poser $X = \cos(x)$, l'équation devient $2X^2 - 3X + 1 = 0$</li>
                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 2 :</strong> $\Delta = 9 - 8 = 1$, donc $X_1 = \dfrac{3+1}{4} = 1$ et $X_2 = \dfrac{3-1}{4} = \dfrac{1}{2}$</li>
                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 3 :</strong> Résoudre $\cos(x) = 1$ → $x = 2k\pi$ et $\cos(x) = \dfrac{1}{2}$ → $x = \pm\dfrac{\pi}{3} + 2k\pi$</li>
                    <li style="margin:0; text-align:left;"><strong>Étape 4 :</strong> Réunir toutes les solutions</li>
                </ul>
            </div>
            
            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">
                <strong>✅ Solution :</strong> $S = \left\{2k\pi\right\} \cup \left\{\pm\dfrac{\pi}{3} + 2k\pi\right\}, k \in \mathbb{Z}$
            </div>
        </div>
    </div>

                    <li style="margin:0 0 18px 0; text-align:left;"><strong>Étape 1 :</strong> Sur $[0, 2\pi[$ : $\sin(x) > \dfrac{1}{2}$ pour $x \in ]\dfrac{\pi}{6}, \dfrac{5\pi}{6}[$</li>

            <div style="background:#ecfdf5; border-radius:4px; padding:10px; margin:10px 0;">

        <h3 style="color:#34495e; margin-top:0;">Exemple complet : Étude d'une fonction trigonométrique</h3>
        <p style="margin:8px 0;"><strong>Énoncé :</strong> Étudier la fonction $f(x) = \sin(x) + \cos(x)$ sur $\mathbb{R}$</p>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">

                <p style="margin:8px 0;">$f'(x) = \cos(x) - \sin(x)$</p>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 2 :</strong> Résolution $f'(x) = 0$
            <div style="margin:10px 0; text-align:left;">
                <p style="margin:8px 0;">$\cos(x) - \sin(x) = 0 \Rightarrow \cos(x) = \sin(x) \Rightarrow \tan(x) = 1$</p>
                <p style="margin:8px 0;">Solutions : $x = \dfrac{\pi}{4} + k\pi$</p>
            </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Étape 3 :</strong> Signe de $f'(x)$
            <div style="margin:10px 0; text-align:left;">
                <p style="margin:8px 0;">$f'(x) = \sqrt{2} \sin\left(x - \dfrac{\pi}{4}\right)$</p>

            </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef2f2; border-radius:6px; border-left:6px solid #ef4444; padding:15px; margin:12px 0;">
            <strong>❌ Pièges à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">Confondre $\sin^2(x) + \cos^2(x) = 1$ avec $\sin(x) + \cos(x) = 1$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Oublier que $\tan(x)$ n'est pas définie en $\dfrac{\pi}{2} + k\pi$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Inverser les dérivées : $(\sin(x))' = \cos(x)$ et $(\cos(x))' = -\sin(x)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Oublier la périodicité dans les équations : une équation a généralement une infinité de solutions</li>
                <li style="margin:0 0 18px 0; text-align:left;">Confondre les périodes : $2\pi$ pour sin/cos, $\pi$ pour tan</li>
                <li style="margin:0; text-align:left;">Oublier que $\sin(x)$ et $\cos(x)$ sont bornés par $[-1, 1]$</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.2;">
                <li style="margin:0 0 18px 0; text-align:left;">Mémoriser les <strong>valeurs remarquables</strong> aux angles $\dfrac{\pi}{6}$, $\dfrac{\pi}{4}$, $\dfrac{\pi}{3}$, $\dfrac{\pi}{2}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Utiliser la <strong>relation fondamentale</strong> $\sin^2 + \cos^2 = 1$ pour simplifier</li>
                <li style="margin:0 0 18px 0; text-align:left;">Penser en termes de <strong>périodicité</strong> pour généraliser les solutions</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour les dérivées composées : identifier $u(x)$ et appliquer la règle de dérivation</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour les équations : commencer par résoudre sur une période, puis généraliser</li>
                <li style="margin:0 0 18px 0; text-align:left;">Vérifier que les solutions trouvées sont dans le domaine de définition</li>
                <li style="margin:0; text-align:left;">S'entraîner à reconnaître les formes $\sin(x) \pm \cos(x) = k$ et utiliser les méthodes adaptées</li>
            </ul>
