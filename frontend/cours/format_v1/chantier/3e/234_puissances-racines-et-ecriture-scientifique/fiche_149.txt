## I. Puissances

- $a^n = a \times \cdots \times a$ ($n$ facteurs) ; $a^0 = 1$ ; $a^{-n} = \dfrac{1}{a^n}$ ($a \neq 0$).
- $(-5)^2 = 25$ mais $-5^2 = -25$ ; $2^{-3} = \dfrac{1}{8}$ est positif.

| Règle | Exemple |
|---|---|
| $a^m \times a^n = a^{m+n}$ | $3^4 \times 3^2 = 3^6$ |
| $\dfrac{a^m}{a^n} = a^{m-n}$ | $\dfrac{5^7}{5^3} = 5^4$ |
| $(a^m)^n = a^{mn}$ | $(2^3)^4 = 2^{12}$ |

## II. Puissances de 10 et notation scientifique

::: formule
$$a \times 10^n$$
:::

Notation scientifique : $1 \le a \lt 10$ et $n$ entier relatif.

- $74\,000\,000 = 7{,}4 \times 10^7$ ; $0{,}000\,092 = 9{,}2 \times 10^{-5}$.
- Calcul : on regroupe, puis on normalise : $(3 \times 10^5) \times (4 \times 10^{-2}) = 12 \times 10^3 = 1{,}2 \times 10^4$.
- Préfixes : G $10^9$ ; M $10^6$ ; k $10^3$ ; m $10^{-3}$ ; µ $10^{-6}$ ; n $10^{-9}$.

## III. Racine carrée

- $\sqrt{a}$ ($a \ge 0$) est le nombre **positif** dont le carré vaut $a$ : $\left(\sqrt{a}\right)^2 = a$.
- Carré d’aire $A$ : côté $\sqrt{A}$.
- Carrés parfaits : $1$ ; $4$ ; $9$ ; $16$ ; $25$ ; $36$ ; $49$ ; $64$ ; $81$ ; $100$ ; $121$ ; $144$.
- Encadrer : $36 \lt 37 \lt 49$ donc $6 \lt \sqrt{37} \lt 7$.
- $x^2 = a$ : deux solutions $\sqrt{a}$ et $-\sqrt{a}$ si $a \gt 0$ ; aucune si $a \lt 0$.

## IV. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. $2^3 + 2^2 \neq 2^5$ : les règles des exposants ne concernent pas les sommes.
2. $\sqrt{9 + 16} = 5 \neq \sqrt{9} + \sqrt{16} = 7$.
3. Oublier de normaliser : $24 \times 10^3$ n’est pas une notation scientifique ($2{,}4 \times 10^4$).
4. Confondre $(-5)^2 = 25$ et $-5^2 = -25$.
:::

::: conseil Réflexe brevet
Très grand ou très petit nombre : notation scientifique et contrôle de l’ordre de grandeur. Aire d’un carré : racine carrée. On garde les valeurs exactes et on arrondit à la fin avec $\approx$.
:::
