===
Découverte - Mener une enquête
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Fais ta propre enquête auprès de 6 à 12 personnes. Pose la même question : « Préfères-tu chat ou chien ? » Note une réponse par personne.

Exemple autonome : huit personnes ont répondu, une seule fois chacune.

Relevé : chat, chien, chat, chat, chien, chat, chien, chat.

[IMAGE_1]

Grille pour l’exemple autonome.

1. Écris la question et les deux choix pour ton enquête.
2. Interroge 6 à 12 personnes. Note les réponses dans l’ordre.
3. Dans l’exemple, combien de personnes ont répondu ?
4. Dans l’exemple, compte les votes pour chaque animal.
5. Vérifie ton relevé personnel. Puis vérifie le total de l’exemple.

Étapes:
<!-- optitab:1 -->

## Question 1 : Écris la question et les deux choix pour ton enquête.

::: methode
Garder une question identique.
:::

::: etape Raisonner
Je demande à chacun de choisir un seul animal.
:::

::: resultat
Question : « Préfères-tu chat ou chien ? » Choix : chat, chien.
:::

## Question 2 : Interroge 6 à 12 personnes. Note les réponses dans l’ordre.

::: methode
Écrire un mot à chaque réponse.
:::

::: etape Raisonner
Tes réponses dépendent des personnes. Écris un seul choix par personne.
:::

::: resultat
Réponse personnelle : une liste de 6 à 12 choix, un par personne.
:::

## Question 3 : Dans l’exemple, combien de personnes ont répondu ?

::: methode
Compter les mots du relevé.
:::

::: etape Raisonner
Le relevé contient huit réponses.
:::

::: resultat
8 personnes ont répondu.
:::

## Question 4 : Dans l’exemple, compte les votes pour chaque animal.

::: methode
Pointer chaque réponse une seule fois.
:::

::: etape Raisonner
Chat apparaît 5 fois. Chien apparaît 3 fois.

| Choix | Nombre de réponses |
|---|---|
| chat | 5 |
| chien | 3 |
:::

::: resultat
Chat : 5. Chien : 3.
:::

## Question 5 : Vérifie ton relevé personnel. Puis vérifie le total de l’exemple.

::: methode
Comparer nombre de réponses et nombre de personnes.
:::

::: etape Raisonner
Dans ton enquête, chaque personne donne une réponse. Pour l’exemple, $5+3=8$.

[IMAGE_2]
:::

::: resultat
Le nombre de tes réponses doit égaler celui des personnes. Dans l’exemple : 8.
:::

Solution:
<!-- optitab:1 -->
1. Question : « Préfères-tu chat ou chien ? » Choix : chat, chien.
2. Réponse personnelle : une liste de 6 à 12 choix, un par personne.
3. 8 personnes ont répondu.
4. Chat : 5. Chien : 3.
5. Le nombre de tes réponses doit égaler celui des personnes. Dans l’exemple : 8.

Découverte - Construire le tableau
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Reprends les réponses de ton enquête personnelle sur chat et chien. Recopie et complète ce tableau.

| Choix | Nombre de réponses |
|---|---|
| chat | … |
| chien | … |

Exemple autonome : huit personnes ont répondu, une seule fois chacune.

Relevé : chat, chien, chat, chat, chien, chat, chien, chat.

[IMAGE_1]

Grille pour l’exemple autonome.

1. Compte tes réponses « chat ». Complète la ligne chat.
2. Compte tes réponses « chien ». Complète la ligne chien.
3. Vérifie le total de ton tableau.
4. Complète un autre tableau pour l’exemple fourni.
5. Représente le tableau de l’exemple avec des cases.

Étapes:
<!-- optitab:1 -->

## Question 1 : Compte tes réponses « chat ». Complète la ligne chat.

::: methode
Faire une marque par réponse chat.
:::

::: etape Raisonner
Ton nombre dépend de ton enquête. Ne compte pas les réponses chien.
:::

::: resultat
La ligne chat contient ton nombre de votes chat.
:::

## Question 2 : Compte tes réponses « chien ». Complète la ligne chien.

::: methode
Compter seulement les réponses chien.
:::

::: etape Raisonner
Chaque réponse chien remplit une marque.
:::

::: resultat
La ligne chien contient ton nombre de votes chien.
:::

## Question 3 : Vérifie le total de ton tableau.

::: methode
Réunir les deux nombres.
:::

::: etape Raisonner
Additionne les deux nombres de ton tableau. Compare avec le nombre de personnes interrogées.
:::

::: resultat
Le total doit être le nombre de personnes de ton enquête.
:::

## Question 4 : Complète un autre tableau pour l’exemple fourni.

::: methode
Compter les mots du relevé.
:::

::: etape Raisonner
Je trouve cinq chats et trois chiens.

| Choix | Nombre de réponses |
|---|---|
| chat | 5 |
| chien | 3 |
:::

::: resultat
Exemple : chat 5 ; chien 3.
:::

## Question 5 : Représente le tableau de l’exemple avec des cases.

::: methode
Prendre une case par personne.
:::

::: etape Raisonner
Je colorie 5 cases pour chat et 3 pour chien.

[IMAGE_2]
:::

::: resultat
Le diagramme a une barre de 5 cases et une de 3 cases.
:::

Solution:
<!-- optitab:1 -->
1. La ligne chat contient ton nombre de votes chat.
2. La ligne chien contient ton nombre de votes chien.
3. Le total doit être le nombre de personnes de ton enquête.
4. Exemple : chat 5 ; chien 3.
5. Le diagramme a une barre de 5 cases et une de 3 cases.

Énoncé:
<!-- optitab:1 -->
Compare les résultats de ton enquête personnelle. Tu peux trouver un gagnant ou une égalité.

Exemple autonome : huit personnes ont répondu, une seule fois chacune.

Relevé : chat, chien, chat, chat, chien, chat, chien, chat.

[IMAGE_1]

Grille pour l’exemple autonome.

1. Dans ton enquête, quel animal a le plus de votes ?
2. Dans l’exemple, quel animal a le plus de votes ?
3. Combien chat a-t-il de votes en plus dans l’exemple ?
4. Dessine les barres de l’exemple pour vérifier.
5. Avec 3 votes chat et 3 votes chien, qui gagne ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Dans ton enquête, quel animal a le plus de votes ?

::: methode
Comparer les deux nombres de ton tableau.
:::

::: etape Raisonner
Le plus grand nombre indique le plus de votes. Si les nombres sont égaux, il y a égalité.
:::

::: resultat
Réponse personnelle : chat, chien, ou égalité, selon ton tableau.
:::

## Question 2 : Dans l’exemple, quel animal a le plus de votes ?

::: methode
Compter les deux catégories.
:::

::: etape Raisonner
Chat a 5 votes. Chien a 3 votes. 5 est plus grand que 3.
:::

::: resultat
Chat a le plus de votes.
:::

## Question 3 : Combien chat a-t-il de votes en plus dans l’exemple ?

::: methode
Chercher l’écart.
:::

::: etape Raisonner
$5-3=2$.
:::

::: resultat
Chat a 2 votes de plus.
:::

## Question 4 : Dessine les barres de l’exemple pour vérifier.

::: methode
Comparer les hauteurs.
:::

::: etape Raisonner
La barre chat a 5 cases. La barre chien a 3 cases.

[IMAGE_2]
:::

::: resultat
La barre chat dépasse la barre chien de 2 cases.
:::

## Question 5 : Avec 3 votes chat et 3 votes chien, qui gagne ?

::: methode
Comparer deux nombres égaux.
:::

::: etape Raisonner
Les deux nombres sont 3. Les barres auraient la même hauteur.
:::

::: resultat
Il y a égalité.
:::

Solution:
<!-- optitab:1 -->
1. Réponse personnelle : chat, chien, ou égalité, selon ton tableau.
2. Chat a le plus de votes.
3. Chat a 2 votes de plus.
4. La barre chat dépasse la barre chien de 2 cases.
5. Il y a égalité.

Entraînement - Lire les deux entrées
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Recopie ce tableau à double entrée. Dans chaque case, dessine la forme de la ligne avec le décor de la colonne.

| Forme | Bleu | Hachuré |
|---|---|---|
| Rond | … | … |
| Carré | … | … |

1. Que faut-il dessiner dans la case rond et bleu ?
2. Que faut-il dessiner dans la case rond et hachuré ?
3. Que faut-il dessiner dans la case carré et bleu ?
4. Que faut-il dessiner dans la case carré et hachuré ?
5. Combien de cases as-tu remplies ? Compare les deux formes d’une même ligne.

Étapes:
<!-- optitab:1 -->

## Question 1 : Que faut-il dessiner dans la case rond et bleu ?

::: methode
Croiser la ligne et la colonne.
:::

::: etape Raisonner
La ligne dit rond. La colonne dit bleu.
:::

::: resultat
Un rond bleu : $\color{#1B3C8E}{\Large\bullet}$.
:::

## Question 2 : Que faut-il dessiner dans la case rond et hachuré ?

::: methode
Lire les deux indications.
:::

::: etape Raisonner
Je garde la forme ronde. Je trace des hachures dedans.
:::

::: resultat
Un rond hachuré : ◍.
:::

## Question 3 : Que faut-il dessiner dans la case carré et bleu ?

::: methode
Croiser carré et bleu.
:::

::: etape Raisonner
La ligne donne un carré. La colonne demande du bleu.
:::

::: resultat
Un carré bleu : $\color{#1B3C8E}{\blacksquare}$.
:::

## Question 4 : Que faut-il dessiner dans la case carré et hachuré ?

::: methode
Croiser carré et hachuré.
:::

::: etape Raisonner
Je dessine un carré avec des hachures à l’intérieur.
:::

::: resultat
Un carré hachuré : ▨.
:::

## Question 5 : Combien de cases as-tu remplies ? Compare les deux formes d’une même ligne.

::: methode
Compter les croisements.
:::

::: etape Raisonner
| Forme | Bleu | Hachuré |
|---|---|---|
| Rond | $\color{#1B3C8E}{\Large\bullet}$ | ◍ (rond hachuré) |
| Carré | $\color{#1B3C8E}{\blacksquare}$ | ▨ (carré hachuré) |

Deux cases par ligne : $2+2=4$. Sur une ligne, la forme reste la même.
:::

::: resultat
4 cases. Sur une même ligne, seule la décoration change.
:::

Solution:
<!-- optitab:1 -->
1. Un rond bleu : $\color{#1B3C8E}{\Large\bullet}$.
2. Un rond hachuré : ◍.
3. Un carré bleu : $\color{#1B3C8E}{\blacksquare}$.
4. Un carré hachuré : ▨.
5. 4 cases. Sur une même ligne, seule la décoration change.

Id: nouveau-6
Difficulté: medium

Énoncé:
<!-- optitab:1 -->

Relevé avec le doublon : chat, chien, chat, chat, chien, chat, chien, chat, chien.

La dernière réponse chien est la deuxième réponse de cette personne. On garde seulement sa première réponse.

Exemple autonome : huit personnes ont répondu, une seule fois chacune.

Relevé : chat, chien, chat, chat, chien, chat, chien, chat.

[IMAGE_1]

Grille pour l’exemple autonome.

1. Combien de réponses compte le relevé avec le doublon ?
2. Quelle réponse faut-il supprimer ?
3. Compte les votes après la correction.
4. Construis les deux barres corrigées.
5. Vérifie que le total convient.

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de réponses compte le relevé avec le doublon ?

::: methode
Compter tous les mots, même le doublon.
:::

::: etape Raisonner
Il y a les huit réponses du premier relevé et une réponse en trop. $8+1=9$.
:::

::: resultat
Il y a 9 réponses écrites.
:::

## Question 2 : Quelle réponse faut-il supprimer ?

::: methode
Garder un seul vote par personne.
:::

::: etape Raisonner
La dernière réponse chien est celle qui a été donnée une deuxième fois.
:::

::: resultat
Il faut supprimer la dernière réponse chien.
:::

## Question 3 : Compte les votes après la correction.

::: methode
Recompter le relevé sans le doublon.
:::

::: etape Raisonner
On retrouve le relevé de huit personnes.

| Choix | Nombre de réponses |
|---|---|
| chat | 5 |
| chien | 3 |
:::

::: resultat
Chat : 5. Chien : 3.
:::

## Question 4 : Construis les deux barres corrigées.

::: methode
Prendre une case par vote gardé.
:::

::: etape Raisonner
Je colorie 5 cases chat et 3 cases chien.

[IMAGE_2]
:::

::: resultat
Barres corrigées : 5 cases et 3 cases.
:::

## Question 5 : Vérifie que le total convient.

::: methode
Comparer votes et personnes.
:::

::: etape Raisonner
$5+3=8$. Il y a bien huit personnes.
:::

::: resultat
8 votes pour 8 personnes.
:::

Solution:
<!-- optitab:1 -->
1. Il y a 9 réponses écrites.
2. Il faut supprimer la dernière réponse chien.
3. Chat : 5. Chien : 3.
4. Barres corrigées : 5 cases et 3 cases.
5. 8 votes pour 8 personnes.
