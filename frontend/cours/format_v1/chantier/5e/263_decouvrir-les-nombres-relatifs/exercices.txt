=== Découverte - Des nombres relatifs dans la vie courante
Id: 2747
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Un jour de janvier, on a relevé la température à Gap à $7$ h et à $14$ h.

[IMAGE_1]

1. Lire la température à $7$ h, puis à $14$ h. Laquelle est sous zéro ?
2. Traduire chaque information par un nombre relatif, avec son unité.
   - a) Le sommet du mont Blanc est à environ $4\,805$ m au-dessus du niveau de la mer.
   - b) Une épave repose à $35$ m sous le niveau de la mer.
   - c) Le parking de l'hôpital est au 3e sous-sol.
   - d) La bataille d'Alésia a eu lieu en $52$ avant J.-C.
3. On donne les nombres : $-7$ ; $12$ ; $0$ ; $-0{,}5$ ; $+3{,}2$ ; $-15$ ; $8$.
   - a) Citer les nombres strictement négatifs.
   - b) Citer les nombres strictement positifs.
   - c) Quel nombre n'a été cité ni en a) ni en b) ? Pourquoi ?
4. Écrire chaque date comme un nombre relatif, puis ranger les événements du plus ancien au plus récent.
   - Fondation de Rome (selon la légende) : $753$ avant J.-C.
   - Fin de l'Empire romain d'Occident : $476$ après J.-C.
   - Bataille d'Alésia : $52$ avant J.-C.
   - Couronnement de Charlemagne : $800$ après J.-C.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire le thermomètre

::: methode
Trouver la valeur d'une petite graduation, puis compter les graduations à partir de $0$ : vers le haut pour une température positive, vers le bas pour une température négative.
:::

::: etape Valeur d'une graduation
Les nombres écrits vont de $2$ en $2$ ($0$ ; $2$ ; $4$…) et il y a $2$ intervalles entre deux nombres écrits : une graduation vaut $2 \div 2 = 1$ °C.
:::

::: etape Lire les deux repères
- Le repère de $7$ h est $3$ graduations **sous** le $0$ : $-3$ °C.
- Le repère de $14$ h est $5$ graduations **au-dessus** du $0$ : $5$ °C.

[IMAGE_2]
:::

::: resultat
À $7$ h, il fait $-3$ °C (sous zéro) ; à $14$ h, il fait $5$ °C.
:::

## Question 2 : Traduire par un nombre relatif

::: methode
Repérer la référence (niveau de la mer, rez-de-chaussée, naissance de J.-C.) : « au-dessus » ou « après » donne un nombre positif, « sous » ou « avant » donne un nombre négatif.
:::

::: etape Choisir le signe
- a) Au-dessus du niveau de la mer : positif.
- b) Sous le niveau de la mer : négatif.
- c) Sous le rez-de-chaussée (étage $0$) : négatif.
- d) Avant J.-C. : négatif.
:::

::: resultat
a) $+4\,805$ m ; b) $-35$ m ; c) étage $-3$ ; d) année $-52$.
:::

## Question 3 : Trier selon le signe

::: methode
Un nombre précédé du signe $-$ (et différent de $0$) est strictement négatif ; un nombre précédé de $+$ ou sans signe (et différent de $0$) est strictement positif.
:::

::: etape Classer les sept nombres
- Avec le signe $-$ : $-7$ ; $-0{,}5$ ; $-15$.
- Avec le signe $+$ ou sans signe : $12$ ; $+3{,}2$ ; $8$.
- Il reste $0$.
:::

::: resultat
a) $-7$ ; $-0{,}5$ ; $-15$. b) $12$ ; $3{,}2$ ; $8$. c) $0$ : il est à la fois positif et négatif, il n'est donc ni strictement positif ni strictement négatif.
:::

## Question 4 : Ranger des dates

::: methode
Écrire « avant J.-C. » avec le signe $-$ et « après J.-C. » sans signe. Plus une date est ancienne, plus elle est à gauche sur une frise : c'est le plus petit nombre.
:::

::: etape Écrire les dates
Rome : $-753$ ; Empire romain d'Occident : $476$ ; Alésia : $-52$ ; Charlemagne : $800$.
:::

::: etape Ranger du plus petit au plus grand
Entre deux dates avant J.-C., la plus ancienne est la plus éloignée de J.-C. : $753 > 52$, donc $-753 < -52$. Puis les dates après J.-C. : $476 < 800$.
$$-753 < -52 < 476 < 800$$
:::

::: resultat
Fondation de Rome ($-753$), Alésia ($-52$), fin de l'Empire romain d'Occident ($476$), couronnement de Charlemagne ($800$).
:::

::: attention Erreur fréquente
Penser que $-753$ est « plus grand » que $-52$ parce que $753 > 52$. Pour les dates avant J.-C., plus le nombre est éloigné de zéro, plus l'événement est **ancien** : $-753$ est la plus petite des deux dates.
:::

Solution:
<!-- optitab:1 -->
1. À $7$ h : $-3$ °C (sous zéro) ; à $14$ h : $5$ °C.
2. a) $+4\,805$ m ; b) $-35$ m ; c) étage $-3$ ; d) année $-52$.
3. a) $-7$ ; $-0{,}5$ ; $-15$. b) $12$ ; $3{,}2$ ; $8$. c) $0$, qui est à la fois positif et négatif.
4. $-753 < -52 < 476 < 800$ : Rome, Alésia, fin de l'Empire romain d'Occident, Charlemagne.

=== Découverte - Lire et placer des points sur une droite graduée
Id: 2752
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur la droite graduée ci-dessous, les graduations sont régulières et seules les abscisses $0$ et $1$ sont écrites.

[IMAGE_1]

1. Combien d'intervalles séparent les graduations $0$ et $1$ ? Quelle longueur, en unités, représente un intervalle ?
2. Lire les abscisses des points $A$, $B$ et $C$.
3. Placer les points $E(-3)$, $F(2)$ et $G(-1{,}5)$.
4. Parmi les points $A$, $B$, $C$, $E$, $F$ et $G$, quel est le point le plus proche de l'origine ? Quel est le point le plus éloigné de l'origine ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Valeur d'un intervalle

::: methode
Compter les **intervalles** (les espaces entre deux traits) entre deux nombres écrits, puis partager l'écart entre ces nombres.
:::

::: etape Compter les intervalles
Entre $0$ et $1$, il y a $3$ traits mais seulement $2$ intervalles.
:::

::: etape Partager l'unité
$$1 \div 2 = 0{,}5$$
:::

::: resultat
$2$ intervalles ; un intervalle représente $0{,}5$ unité.
:::

## Question 2 : Lire les abscisses

::: methode
Compter les intervalles entre l'origine et le point, multiplier par $0{,}5$, puis mettre le signe : $-$ à gauche de $0$.
:::

::: etape Le point $A$
$A$ est à $5$ intervalles à gauche de $0$ : $5 \times 0{,}5 = 2{,}5$. Son abscisse est $-2{,}5$.
:::

::: etape Le point $B$
$B$ est à $1$ intervalle à gauche de $0$ : son abscisse est $-0{,}5$.
:::

::: etape Le point $C$
$C$ est à $3$ intervalles à droite de $0$ : $3 \times 0{,}5 = 1{,}5$. Son abscisse est $1{,}5$.
:::

::: resultat
$A(-2{,}5)$ ; $B(-0{,}5)$ ; $C(1{,}5)$.
:::

## Question 3 : Placer les points

::: methode
Un intervalle vaut $0{,}5$ : une unité correspond donc à $2$ intervalles. Se déplacer depuis $0$ vers la gauche pour un nombre négatif, vers la droite pour un nombre positif.
:::

::: etape Calculer le nombre d'intervalles
- $E(-3)$ : $3$ unités, soit $3 \times 2 = 6$ intervalles à gauche de $0$.
- $F(2)$ : $2$ unités, soit $2 \times 2 = 4$ intervalles à droite de $0$.
- $G(-1{,}5)$ : $1$ unité et demie, soit $2 + 1 = 3$ intervalles à gauche de $0$.
:::

::: etape Placer sur la droite
Les points lus sont au-dessus ; les points placés, en vert, sont sous la droite.
:::

[IMAGE_2]

::: resultat
$E$ est à $6$ intervalles à gauche de $0$, $F$ à $4$ intervalles à droite, $G$ à $3$ intervalles à gauche.
:::

## Question 4 : Le plus proche, le plus éloigné

::: methode
La distance d'un point à l'origine est la distance à zéro de son abscisse : le nombre sans son signe.
:::

::: etape Distances à l'origine
| Point | $A$ | $B$ | $C$ | $E$ | $F$ | $G$ |
|---|---|---|---|---|---|---|
| Distance à $O$ | $2{,}5$ | $0{,}5$ | $1{,}5$ | $3$ | $2$ | $1{,}5$ |
:::

::: resultat
Le plus proche de l'origine est $B$ (distance $0{,}5$) ; le plus éloigné est $E$ (distance $3$).
:::

::: attention Erreur fréquente
Compter les traits au lieu des intervalles : on trouverait $3$ graduations entre $0$ et $1$, donc des abscisses fausses. Un intervalle est l'**espace** entre deux traits voisins.
:::

Solution:
<!-- optitab:1 -->
1. $2$ intervalles ; un intervalle vaut $0{,}5$.
2. $A(-2{,}5)$ ; $B(-0{,}5)$ ; $C(1{,}5)$.
3. $E$ : $6$ intervalles à gauche de $0$ ; $F$ : $4$ à droite ; $G$ : $3$ à gauche.
4. Le plus proche : $B$ ; le plus éloigné : $E$.

=== Découverte - Distance à zéro et opposé
Id: 2748
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Recopier et compléter le tableau.

| Nombre | $-6$ | $4{,}5$ | $-0{,}8$ | $13$ | $-2{,}75$ |
|---|---|---|---|---|---|
| Signe | | | | | |
| Distance à zéro | | | | | |
| Opposé | | | | | |

2. On considère la droite graduée ci-dessous.
   - a) Lire les abscisses des points $M$ et $N$.
   - b) Placer le point $P$ dont l'abscisse est l'opposé de celle de $M$, et le point $Q$ dont l'abscisse est l'opposé de celle de $N$.

[IMAGE_1]

3. Vrai ou faux ? Justifier.
   - a) La distance à zéro de $-9$ est $-9$.
   - b) $-2{,}5$ et $2{,}5$ sont des nombres opposés.
   - c) L'opposé d'un nombre strictement négatif est un nombre strictement positif.
   - d) Si deux nombres ont la même distance à zéro, alors ils sont égaux.

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter le tableau

::: methode
La distance à zéro est le nombre sans son signe ; l'opposé a la même distance à zéro et le signe contraire.
:::

::: etape Signe et distance à zéro
- $-6$ : signe $-$, distance $6$ ; $4{,}5$ : signe $+$, distance $4{,}5$ ; $-0{,}8$ : signe $-$, distance $0{,}8$.
- $13$ : signe $+$, distance $13$ ; $-2{,}75$ : signe $-$, distance $2{,}75$.
:::

::: etape Opposé : on change seulement le signe
| Nombre | $-6$ | $4{,}5$ | $-0{,}8$ | $13$ | $-2{,}75$ |
|---|---|---|---|---|---|
| Signe | $-$ | $+$ | $-$ | $+$ | $-$ |
| Distance à zéro | $6$ | $4{,}5$ | $0{,}8$ | $13$ | $2{,}75$ |
| Opposé | $6$ | $-4{,}5$ | $0{,}8$ | $-13$ | $2{,}75$ |
:::

::: resultat
Les opposés sont $6$ ; $-4{,}5$ ; $0{,}8$ ; $-13$ ; $2{,}75$, et chaque nombre a la même distance à zéro que son opposé.
:::

## Question 2 : Opposés sur la droite graduée

::: methode
Lire l'abscisse en comptant les unités depuis $0$, puis reporter la même distance de l'autre côté de l'origine.
:::

::: etape Lire les abscisses
$M$ est à $5$ unités à gauche de $0$ : $M(-5)$. $N$ est à $2$ unités à droite de $0$ : $N(2)$.
:::

::: etape Placer les opposés
- L'opposé de $-5$ est $5$ : $P$ est à $5$ unités à **droite** de $0$.
- L'opposé de $2$ est $-2$ : $Q$ est à $2$ unités à **gauche** de $0$.
:::

[IMAGE_2]

::: resultat
$M(-5)$, $N(2)$, $P(5)$ et $Q(-2)$.
:::

## Question 3 : Vrai ou faux

::: methode
Revenir aux définitions ; pour montrer qu'une phrase est fausse, un seul contre-exemple suffit.
:::

::: etape Phrases a) et b)
- a) Une distance est toujours positive : la distance à zéro de $-9$ est $9$. **Faux.**
- b) $-2{,}5$ et $2{,}5$ ont la même distance à zéro, $2{,}5$, et des signes contraires. **Vrai.**
:::

::: etape Phrases c) et d)
- c) Changer le signe $-$ d'un nombre strictement négatif donne le signe $+$ : par exemple, l'opposé de $-4$ est $4$. **Vrai.**
- d) $5$ et $-5$ ont la même distance à zéro, $5$, mais ne sont pas égaux. **Faux.**
:::

::: resultat
a) Faux ; b) Vrai ; c) Vrai ; d) Faux (contre-exemple : $5$ et $-5$).
:::

::: retenir
Deux nombres différents qui ont la même distance à zéro sont **opposés**. L'opposé de $0$ est $0$.
:::

Solution:
<!-- optitab:1 -->
1. Distances à zéro : $6$ ; $4{,}5$ ; $0{,}8$ ; $13$ ; $2{,}75$. Opposés : $6$ ; $-4{,}5$ ; $0{,}8$ ; $-13$ ; $2{,}75$.
2. a) $M(-5)$ et $N(2)$. b) $P(5)$ et $Q(-2)$.
3. a) Faux ($9$) ; b) Vrai ; c) Vrai ; d) Faux ($5$ et $-5$).

=== Entraînement - Lire et placer des points dans un repère
Id: 2749
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le plan est muni du repère ci-dessous, d'origine $O$.

[IMAGE_1]

1. Lire les coordonnées des points $A$, $B$, $C$, $D$, $E$ et $F$.
2. Placer les points $G(-1\,;\,4)$, $H(2\,;\,-4)$ et $K(-5\,;\,-2)$.
3. Parmi les points $A$ à $F$ :
   - a) lesquels ont une abscisse strictement négative ?
   - b) lesquels ont une ordonnée strictement négative ?
4. Les points $E$ et $F$ sont sur un axe du repère. Que remarque-t-on sur leurs coordonnées ?
5. Placer le point $M$ dont l'abscisse est l'opposé de celle de $A$ et dont l'ordonnée est égale à celle de $A$. Donner ses coordonnées.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire des coordonnées

::: methode
Depuis le point, rejoindre verticalement l'axe horizontal : on lit l'**abscisse**. Puis rejoindre horizontalement l'axe vertical : on lit l'**ordonnée**. On écrit (abscisse ; ordonnée).
:::

::: etape Points dans les quatre zones du repère
- $A$ : $3$ à droite, $2$ en haut : $A(3\,;\,2)$.
- $B$ : $4$ à gauche, $3$ en haut : $B(-4\,;\,3)$.
- $C$ : $2$ à gauche, $3$ en bas : $C(-2\,;\,-3)$.
- $D$ : $4$ à droite, $1$ en bas : $D(4\,;\,-1)$.
:::

::: etape Points sur les axes
- $E$ est sur l'axe vertical, $3$ en haut : $E(0\,;\,3)$.
- $F$ est sur l'axe horizontal, $3$ à gauche : $F(-3\,;\,0)$.
:::

[IMAGE_2]

::: resultat
$A(3\,;\,2)$, $B(-4\,;\,3)$, $C(-2\,;\,-3)$, $D(4\,;\,-1)$, $E(0\,;\,3)$, $F(-3\,;\,0)$.
:::

## Question 2 : Placer des points

::: methode
Partir de $O$ : se déplacer horizontalement de l'abscisse (à gauche si elle est négative), puis verticalement de l'ordonnée (vers le bas si elle est négative).
:::

::: etape Les trois déplacements
- $G(-1\,;\,4)$ : $1$ vers la gauche, puis $4$ vers le haut.
- $H(2\,;\,-4)$ : $2$ vers la droite, puis $4$ vers le bas.
- $K(-5\,;\,-2)$ : $5$ vers la gauche, puis $2$ vers le bas.
:::

::: resultat
Les points $G$, $H$ et $K$ sont placés en vert sur la figure de la question 1.
:::

## Question 3 : Signe des coordonnées

::: methode
Regarder le premier nombre (abscisse), puis le second (ordonnée), dans les coordonnées trouvées à la question 1.
:::

::: etape Abscisses strictement négatives
$B$ ($-4$), $C$ ($-2$) et $F$ ($-3$). L'abscisse de $E$ est $0$ : elle n'est pas strictement négative.
:::

::: etape Ordonnées strictement négatives
$C$ ($-3$) et $D$ ($-1$).
:::

::: resultat
a) $B$, $C$ et $F$ ; b) $C$ et $D$.
:::

## Question 4 : Points sur les axes

::: methode
Un point de l'axe vertical n'est ni à gauche ni à droite de $O$ ; un point de l'axe horizontal n'est ni en haut ni en bas.
:::

::: etape Observer
$E(0\,;\,3)$ est sur l'axe des ordonnées : son abscisse est $0$. $F(-3\,;\,0)$ est sur l'axe des abscisses : son ordonnée est $0$.
:::

::: resultat
Un point de l'axe des ordonnées a une abscisse nulle ; un point de l'axe des abscisses a une ordonnée nulle.
:::

## Question 5 : Le point $M$

::: methode
L'abscisse de $A$ est $3$ et son ordonnée $2$ : on change le signe de l'abscisse seulement.
:::

::: etape Coordonnées de $M$
L'opposé de $3$ est $-3$ ; l'ordonnée reste $2$. Donc $M(-3\,;\,2)$ : $3$ vers la gauche, $2$ vers le haut. $M$ est placé en vert sur la figure : il est à la même hauteur que $A$, de l'autre côté de l'axe des ordonnées.
:::

::: resultat
$M(-3\,;\,2)$.
:::

::: attention Erreur fréquente
Inverser abscisse et ordonnée : $C(-2\,;\,-3)$ et le point $(-3\,;\,-2)$ sont deux points différents. L'abscisse (déplacement horizontal) s'écrit **toujours en premier**.
:::

Solution:
<!-- optitab:1 -->
1. $A(3\,;\,2)$, $B(-4\,;\,3)$, $C(-2\,;\,-3)$, $D(4\,;\,-1)$, $E(0\,;\,3)$, $F(-3\,;\,0)$.
2. Voir la figure corrigée.
3. a) $B$, $C$, $F$ ; b) $C$, $D$.
4. $E$ a une abscisse nulle, $F$ une ordonnée nulle.
5. $M(-3\,;\,2)$.

=== Entraînement - Comparer et ranger des températures
Id: 2751
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Voici les températures relevées dans sept villes, un matin de janvier.

| Ville | Température (°C) |
|---|---|
| Paris | $2{,}5$ |
| Oslo | $-4{,}5$ |
| Montréal | $-12$ |
| Rome | $5$ |
| Moscou | $-9{,}5$ |
| Berlin | $-1$ |
| Helsinki | $-7$ |

1. Recopier et compléter avec le symbole $<$ ou $>$.
   - a) $-4{,}3 \;\ldots\; -4{,}7$
   - b) $-0{,}8 \;\ldots\; 0{,}2$
   - c) $-9{,}5 \;\ldots\; -12$
   - d) $-1{,}05 \;\ldots\; -1{,}5$
2. Ranger les sept températures dans l'ordre croissant. Quelle ville est la plus froide ? la plus chaude ?
3. Ranger dans l'ordre décroissant les températures strictement négatives.
4. Lina affirme : « Il fait plus chaud à Helsinki qu'à Oslo, car $7 > 4{,}5$. » A-t-elle raison ?
5. Encadrer et intercaler.
   - a) Encadrer $-9{,}5$ par deux nombres entiers consécutifs.
   - b) Donner une température comprise entre $-4{,}7$ °C et $-4{,}3$ °C.

Étapes:
<!-- optitab:1 -->
## Question 1 : Comparer deux nombres

::: methode
Un négatif est plus petit qu'un positif. Entre deux négatifs, le plus petit est le plus éloigné de zéro.
:::

::: etape a) et b)
- a) $4{,}3 < 4{,}7$ : $-4{,}7$ est plus éloigné de zéro, donc $-4{,}3 > -4{,}7$.
- b) $-0{,}8$ est négatif et $0{,}2$ positif : $-0{,}8 < 0{,}2$.
:::

::: etape c) et d)
- c) $9{,}5 < 12$ : $-12$ est plus éloigné de zéro, donc $-9{,}5 > -12$.
- d) $1{,}05 < 1{,}50$ : $-1{,}5$ est plus éloigné de zéro, donc $-1{,}05 > -1{,}5$.
:::

::: resultat
a) $-4{,}3 > -4{,}7$ ; b) $-0{,}8 < 0{,}2$ ; c) $-9{,}5 > -12$ ; d) $-1{,}05 > -1{,}5$.
:::

## Question 2 : Ordre croissant

::: methode
D'abord les négatifs, du plus éloigné de zéro au plus proche ; ensuite les positifs, du plus petit au plus grand.
:::

::: etape Les négatifs
Distances à zéro : $12 > 9{,}5 > 7 > 4{,}5 > 1$, donc $-12 < -9{,}5 < -7 < -4{,}5 < -1$.
:::

::: etape Les positifs, puis le rangement complet
$2{,}5 < 5$. Sur un thermomètre, les villes se lisent de bas en haut :

[IMAGE_1]

$$-12 < -9{,}5 < -7 < -4{,}5 < -1 < 2{,}5 < 5$$
:::

::: resultat
Montréal, Moscou, Helsinki, Oslo, Berlin, Paris, Rome. La plus froide est Montréal ($-12$ °C), la plus chaude Rome ($5$ °C).
:::

## Question 3 : Ordre décroissant

::: methode
Ordre décroissant : du plus grand au plus petit, avec le symbole $>$. On lit le rangement précédent à l'envers.
:::

::: etape Ranger les cinq négatifs
$$-1 > -4{,}5 > -7 > -9{,}5 > -12$$
:::

::: resultat
$-1 > -4{,}5 > -7 > -9{,}5 > -12$.
:::

## Question 4 : L'affirmation de Lina

::: methode
Comparer les températures elles-mêmes, avec leur signe, et non leurs distances à zéro.
:::

::: etape Comparer $-7$ et $-4{,}5$
$7 > 4{,}5$ : $-7$ est plus éloigné de zéro, donc $-7 < -4{,}5$. Sur le thermomètre de la question 2, Helsinki est plus bas qu'Oslo.
:::

::: resultat
Non : $-7 < -4{,}5$, il fait plus **froid** à Helsinki qu'à Oslo.
:::

## Question 5 : Encadrer et intercaler

::: methode
Situer le nombre entre les deux entiers qui l'entourent, en se souvenant qu'entre deux négatifs le plus éloigné de zéro est le plus petit.
:::

::: etape a) Encadrer $-9{,}5$
$9 < 9{,}5 < 10$, donc $-9{,}5$ est entre $-10$ et $-9$, plus éloigné de zéro que $-9$ :
$$-10 < -9{,}5 < -9$$
:::

::: etape b) Intercaler une température
$-4{,}4$ convient : $4{,}3 < 4{,}4 < 4{,}7$, donc $-4{,}7 < -4{,}4 < -4{,}3$.
:::

::: resultat
a) $-10 < -9{,}5 < -9$. b) Par exemple $-4{,}4$ °C (ou $-4{,}5$ °C, $-4{,}6$ °C…).
:::

::: attention Erreur fréquente
Comparer des négatifs comme des positifs : $-7$ n'est pas plus grand que $-4{,}5$. Sur un thermomètre, $-7$ °C est **plus bas** que $-4{,}5$ °C.
:::

Solution:
<!-- optitab:1 -->
1. a) $>$ ; b) $<$ ; c) $>$ ; d) $>$.

=== Entraînement - Positions et distances à zéro
Id: 2759
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur une droite graduée, on considère les points $A(-4{,}5)$, $B(3{,}2)$, $C(-3{,}2)$ et $D(0{,}7)$.

1. Ranger les abscisses de ces points dans l'ordre croissant. En déduire l'ordre des points de gauche à droite.
2. Donner la distance à zéro de chaque abscisse, puis ranger les points du plus éloigné au plus proche de l'origine. Y a-t-il des égalités ?
3. Quels points ont des abscisses opposées ? Justifier.
4. Le point $E$ a pour abscisse l'opposé de celle de $D$. Quelle est son abscisse ? Le point $E$ est-il à gauche ou à droite du point $C$ ?
5. Ranger dans l'ordre décroissant : $-3{,}25$ ; $-3{,}2$ ; $-3{,}52$ ; $-0{,}7$ ; $-3$.

Étapes:
<!-- optitab:1 -->
## Question 1 : De gauche à droite

::: methode
Ranger les abscisses dans l'ordre croissant revient à lire les points de gauche à droite.
:::

::: etape Comparer
- Les négatifs : $4{,}5 > 3{,}2$, donc $-4{,}5 < -3{,}2$.
- Les positifs : $0{,}7 < 3{,}2$.
$$-4{,}5 < -3{,}2 < 0{,}7 < 3{,}2$$
:::

[IMAGE_1]

::: resultat
De gauche à droite : $A$, $C$, $D$, $B$.
:::

## Question 2 : Du plus éloigné au plus proche de l'origine

::: methode
On compare cette fois les distances à zéro, sans tenir compte du signe.
:::

::: etape Tableau des distances
| Point | $A$ | $B$ | $C$ | $D$ |
|---|---|---|---|---|
| Distance à zéro | $4{,}5$ | $3{,}2$ | $3{,}2$ | $0{,}7$ |
:::

::: etape Ranger
$4{,}5 > 3{,}2 > 0{,}7$ ; $B$ et $C$ ont la même distance à zéro.
:::

::: resultat
$A$, puis $B$ et $C$ à égalité, puis $D$.
:::

## Question 3 : Abscisses opposées

::: methode
Deux nombres sont opposés s'ils ont la même distance à zéro **et** des signes contraires.
:::

::: etape Vérifier les deux conditions
$B$ et $C$ ont la même distance à zéro ($3{,}2$), et leurs abscisses $3{,}2$ et $-3{,}2$ ont des signes contraires.
:::

::: resultat
$B$ et $C$ ont des abscisses opposées.
:::

## Question 4 : Le point $E$

::: methode
Changer le signe de l'abscisse de $D$, puis comparer avec celle de $C$.
:::

::: etape Abscisse de $E$
L'opposé de $0{,}7$ est $-0{,}7$ : $E(-0{,}7)$.
:::

::: etape Comparer avec $C$
$0{,}7 < 3{,}2$ : $-0{,}7$ est plus proche de zéro que $-3{,}2$, donc $-3{,}2 < -0{,}7$. Le point $E$ est à droite de $C$ (voir la figure de la question 1).
:::

::: resultat
$E(-0{,}7)$ ; $E$ est à droite de $C$.
:::

## Question 5 : Ordre décroissant

::: methode
Tous les nombres sont négatifs : du plus grand au plus petit, on va du plus proche de zéro au plus éloigné. On écrit les distances avec deux décimales pour les comparer.
:::

::: etape Distances à zéro
$0{,}70 < 3{,}00 < 3{,}20 < 3{,}25 < 3{,}52$
:::

::: etape Inverser pour les négatifs
$$-0{,}7 > -3 > -3{,}2 > -3{,}25 > -3{,}52$$
:::

::: resultat
$-0{,}7 > -3 > -3{,}2 > -3{,}25 > -3{,}52$.
:::

::: attention Erreur fréquente
Ne pas confondre les deux classements : $A$ est le point le plus **à gauche** (la plus petite abscisse) **et** le plus **éloigné** de l'origine. Pour les négatifs, « plus petit » veut dire « plus loin de zéro ».
:::

Solution:
<!-- optitab:1 -->
1. $-4{,}5 < -3{,}2 < 0{,}7 < 3{,}2$ : $A$, $C$, $D$, $B$.
2. $A$ ($4{,}5$), puis $B$ et $C$ à égalité ($3{,}2$), puis $D$ ($0{,}7$).
3. $B$ et $C$.
4. $E(-0{,}7)$, à droite de $C$.
5. $-0{,}7 > -3 > -3{,}2 > -3{,}25 > -3{,}52$.

=== Problème - L'ascenseur de la tour
Id: 2750
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une tour compte $8$ étages au-dessus du rez-de-chaussée et $3$ niveaux de parking en sous-sol. Sur le tableau de l'ascenseur, le rez-de-chaussée est noté $0$ et les sous-sols $-1$, $-2$ et $-3$.

[IMAGE_1]

Ce matin, l'ascenseur s'est arrêté successivement aux étages : $5$ ; $-2$ ; $0$ ; $3$ ; $-3$ ; $7$.

1. Lors de quels arrêts l'ascenseur était-il en sous-sol ?
2. Ranger les étages de ces arrêts du plus bas au plus haut.
3. À l'aide du schéma, déterminer de combien d'étages l'ascenseur est monté pour aller de l'étage $-2$ à l'étage $3$.
4. Le gardien affirme : « Le niveau $-3$ est plus haut que le niveau $-2$, car $3$ est plus grand que $2$. » A-t-il raison ?
5. Un deuxième ascenseur est à l'étage $4$, pendant que le premier est à l'étage $-2$. Lequel est le plus proche du rez-de-chaussée ?
6. La salle de sport est au 3e étage. Le local à vélos est au niveau opposé. À quel niveau se trouve-t-il ? Combien d'étages séparent ces deux salles ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Les arrêts en sous-sol

::: methode
Les sous-sols sont sous le rez-de-chaussée : ce sont les étages notés par un nombre négatif.
:::

::: etape Repérer les nombres négatifs
Parmi $5$ ; $-2$ ; $0$ ; $3$ ; $-3$ ; $7$, les nombres négatifs sont $-2$ et $-3$ ($0$ est le rez-de-chaussée).
:::

::: resultat
Aux arrêts des niveaux $-2$ et $-3$.
:::

## Question 2 : Du plus bas au plus haut

::: methode
Plus un étage est bas, plus son numéro est petit : on range dans l'ordre croissant.
:::

::: etape Ranger
Les sous-sols d'abord, du plus profond au moins profond : $-3 < -2$ ; puis $0$ ; puis $3 < 5 < 7$.
$$-3 < -2 < 0 < 3 < 5 < 7$$
:::

::: resultat
$-3$ ; $-2$ ; $0$ ; $3$ ; $5$ ; $7$.
:::

## Question 3 : De l'étage $-2$ à l'étage $3$

::: methode
Compter les étages sur le schéma, en passant par le rez-de-chaussée.
:::

::: etape Deux trajets
- De $-2$ jusqu'au rez-de-chaussée $0$ : $2$ étages (la distance à zéro de $-2$).
- Du rez-de-chaussée jusqu'à $3$ : $3$ étages.
:::

::: etape Total

[IMAGE_2]

$$2 + 3 = 5$$
:::

::: resultat
L'ascenseur est monté de $5$ étages.
:::

## Question 4 : L'affirmation du gardien

::: methode
Comparer deux nombres négatifs : le plus petit est le plus éloigné de zéro, donc ici le plus bas.
:::

::: etape Comparer $-3$ et $-2$
$3 > 2$ : $-3$ est plus éloigné de zéro, donc $-3 < -2$. Le niveau $-3$ est sous le niveau $-2$.
:::

::: resultat
Non : $-3 < -2$, le niveau $-3$ est **plus bas** que le niveau $-2$.
:::

## Question 5 : Le plus proche du rez-de-chaussée

::: methode
La distance au rez-de-chaussée, en étages, est la distance à zéro du numéro de l'étage.
:::

::: etape Comparer les distances à zéro
Distance à zéro de $-2$ : $2$ ; distance à zéro de $4$ : $4$. Comme $2 < 4$, le premier ascenseur est plus proche.
:::

::: resultat
Le premier ascenseur (étage $-2$), à $2$ étages du rez-de-chaussée.
:::

## Question 6 : Le niveau opposé

::: methode
L'opposé de $3$ a la même distance à zéro, de l'autre côté du rez-de-chaussée.
:::

::: etape Trouver le niveau
L'opposé de $3$ est $-3$ : le local à vélos est au niveau $-3$.
:::

::: etape Compter les étages
$3$ étages de $-3$ à $0$, puis $3$ étages de $0$ à $3$ : $3 + 3 = 6$.
:::

::: resultat
Niveau $-3$ ; $6$ étages séparent les deux salles.
:::

::: attention Erreur fréquente
Compter les étages entre $-2$ et $3$ en faisant $3 - 2 = 1$ : les deux étages sont **de part et d'autre** du rez-de-chaussée, il faut ajouter leurs distances à zéro, $2 + 3 = 5$.
:::

Solution:
<!-- optitab:1 -->
1. Aux niveaux $-2$ et $-3$.
2. $-3 < -2 < 0 < 3 < 5 < 7$.
3. $2 + 3 = 5$ étages.
4. Non : $-3 < -2$, le niveau $-3$ est plus bas.
5. Le premier ascenseur (étage $-2$).
6. Niveau $-3$ ; $6$ étages.

=== Problème - Altitudes et profondeurs
Id: 2753
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Le schéma représente une scène au bord de la mer. Les altitudes sont mesurées en mètres par rapport au niveau de la mer, qui a pour altitude $0$ m.

[IMAGE_1]

1. Donner l'altitude de chaque élément par un nombre relatif.
2. Ranger ces altitudes dans l'ordre croissant.
3. Quel élément est à la même distance du niveau de la mer que le sommet de la falaise ? Que peut-on dire de leurs altitudes ?
4. La plongeuse remonte à la surface. De combien de mètres monte-t-elle ?
5. Quel est l'écart de hauteur entre la mouette et la plongeuse ?
6. Un poisson nage entre la plongeuse et l'épave, plus près de l'épave que de la plongeuse. Donner une altitude possible pour ce poisson, en justifiant.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire les altitudes

::: methode
Sur l'axe, une graduation vaut $10$ m. Au-dessus du niveau de la mer, l'altitude est positive ; en dessous, elle est négative.
:::

::: etape Au-dessus du niveau de la mer
Sommet de la falaise : $70$ m ; mouette : $40$ m ; bateau : $0$ m (à la surface).
:::

::: etape Sous le niveau de la mer
Plongeuse : $-30$ m ; épave : $-50$ m ; sous-marin : $-70$ m.
:::

[IMAGE_2]

::: resultat
Falaise $70$ m ; mouette $40$ m ; bateau $0$ m ; plongeuse $-30$ m ; épave $-50$ m ; sous-marin $-70$ m.
:::

## Question 2 : Ordre croissant

::: methode
Du plus bas au plus haut : les négatifs du plus éloigné de zéro au plus proche, puis $0$, puis les positifs.
:::

::: etape Ranger
$$-70 < -50 < -30 < 0 < 40 < 70$$
:::

::: resultat
Sous-marin, épave, plongeuse, bateau, mouette, sommet de la falaise.
:::

## Question 3 : Même distance au niveau de la mer

::: methode
La distance au niveau de la mer est la distance à zéro de l'altitude.
:::

::: etape Chercher la même distance
Le sommet de la falaise est à $70$ m au-dessus ; le sous-marin, d'altitude $-70$ m, est à $70$ m en dessous.
:::

::: resultat
Le sous-marin : les altitudes $70$ et $-70$ sont **opposées**.
:::

## Question 4 : La remontée de la plongeuse

::: methode
Remonter de $-30$ m jusqu'à $0$ m, c'est parcourir la distance à zéro de $-30$.
:::

::: etape Distance à zéro
La distance à zéro de $-30$ est $30$.
:::

::: resultat
Elle monte de $30$ m.
:::

## Question 5 : Écart entre la mouette et la plongeuse

::: methode
Les deux sont de part et d'autre du niveau de la mer : on ajoute la distance de chacune au niveau de la mer.
:::

::: etape Ajouter les distances
Mouette : $40$ m au-dessus ; plongeuse : $30$ m en dessous.
$$40 + 30 = 70$$
:::

::: resultat
L'écart est de $70$ m.
:::

## Question 6 : L'altitude du poisson

::: methode
Encadrer l'altitude entre celles de l'épave et de la plongeuse, puis chercher le milieu pour savoir de quel côté se placer.
:::

::: etape Encadrement
Entre l'épave et la plongeuse : l'altitude est comprise entre $-50$ et $-30$.
:::

::: etape Plus près de l'épave
De $-50$ à $-30$, il y a $20$ m ; le milieu est à $10$ m de chacun : c'est $-40$. Plus près de l'épave, le poisson est entre $-50$ et $-40$ :
$$-50 < \text{altitude} < -40$$
:::

::: resultat
Par exemple $-45$ m (toute altitude strictement comprise entre $-50$ m et $-40$ m convient).
:::

::: attention Erreur fréquente
Écrire que la plongeuse monte de $-30$ m : une distance parcourue est toujours positive. Elle monte de $30$ m, la distance à zéro de $-30$.
:::

Solution:
<!-- optitab:1 -->
1. Falaise $70$ m ; mouette $40$ m ; bateau $0$ m ; plongeuse $-30$ m ; épave $-50$ m ; sous-marin $-70$ m.
2. $-70 < -50 < -30 < 0 < 40 < 70$.
3. Le sous-marin : altitudes opposées ($70$ et $-70$).
4. $30$ m.
5. $70$ m.
6. Par exemple $-45$ m (entre $-50$ m et $-40$ m).

=== Problème - Retrouver un nombre à partir d'indices
Id: 2765
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un nombre $x$ vérifie les quatre indices suivants.

- **Indice 1** : $x$ est strictement négatif.
- **Indice 2** : la distance à zéro de $x$ est comprise entre $2{,}4$ et $2{,}6$ ($2{,}4$ et $2{,}6$ exclus).
- **Indice 3** : $x$ est plus grand que $-2{,}5$.
- **Indice 4** : $x$ s'écrit avec deux chiffres après la virgule, et son chiffre des centièmes est $5$.

1. À l'aide des indices 1 et 2, écrire un encadrement de $x$.
2. À l'aide de l'indice 3, préciser cet encadrement.
3. Donner trois nombres qui vérifient les indices 1, 2 et 3. Peut-on déjà connaître $x$ ?
4. À l'aide de l'indice 4, trouver $x$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Indices 1 et 2

::: methode
$x$ est négatif : il est à gauche de zéro. Sa distance à zéro donne sa position ; entre deux négatifs, le plus éloigné de zéro est le plus petit.
:::

::: etape Les bornes
Le nombre négatif de distance à zéro $2{,}4$ est $-2{,}4$ ; celui de distance à zéro $2{,}6$ est $-2{,}6$. Comme $2{,}6 > 2{,}4$, on a $-2{,}6 < -2{,}4$.
:::

::: etape Encadrer
$x$ est entre ces deux nombres, bornes exclues :
$$-2{,}6 < x < -2{,}4$$
:::

::: resultat
$-2{,}6 < x < -2{,}4$.
:::

## Question 2 : Indice 3

::: methode
Ne garder que les nombres qui vérifient en même temps l'encadrement et la nouvelle condition.
:::

::: etape Comparer les bornes de gauche
$x > -2{,}5$ et $-2{,}5 > -2{,}6$ : la condition $x > -2{,}5$ est plus exigeante que $x > -2{,}6$.
:::

::: etape Nouvel encadrement
La borne de droite ne change pas :
$$-2{,}5 < x < -2{,}4$$
:::

[IMAGE_1]

::: resultat
$-2{,}5 < x < -2{,}4$.
:::

## Question 3 : Des nombres possibles

::: methode
Écrire les bornes avec deux décimales, $-2{,}50$ et $-2{,}40$, puis choisir des nombres entre les deux.
:::

::: etape Trois exemples
$-2{,}45$ ; $-2{,}42$ ; $-2{,}48$ conviennent. Par exemple pour $-2{,}48$ : sa distance à zéro $2{,}48$ est entre $2{,}4$ et $2{,}6$, et $2{,}48 < 2{,}50$ donc $-2{,}48 > -2{,}5$.
:::

::: resultat
Par exemple $-2{,}45$ ; $-2{,}42$ ; $-2{,}48$. On ne peut pas encore connaître $x$ : il y a une infinité de nombres possibles.
:::

## Question 4 : Indice 4

::: methode
Écrire la forme du nombre cherché, puis utiliser l'encadrement $-2{,}50 < x < -2{,}40$.
:::

::: etape Forme du nombre
$x$ est entre $-2{,}50$ et $-2{,}40$, donc il s'écrit $-2{,}4\ldots$ : son chiffre des dixièmes est $4$.
:::

::: etape Chiffre des centièmes
Avec deux chiffres après la virgule et le chiffre des centièmes égal à $5$ : $x = -2{,}45$. Vérification : $-2{,}50 < -2{,}45 < -2{,}40$.
:::

::: resultat
$x = -2{,}45$.
:::

::: attention Erreur fréquente
Écrire $-2{,}4 < x < -2{,}6$ : on a recopié les distances à zéro dans le même ordre. Pour des nombres négatifs, l'ordre s'**inverse** : $-2{,}6$ est le plus petit.
:::

Solution:
<!-- optitab:1 -->
1. $-2{,}6 < x < -2{,}4$.
2. $-2{,}5 < x < -2{,}4$.
3. Par exemple $-2{,}45$ ; $-2{,}42$ ; $-2{,}48$ : $x$ n'est pas encore connu.
4. $x = -2{,}45$.

=== Synthèse - Une journée à la station de ski
Id: 2754
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une classe de 5e passe une journée dans une station de ski.

**Partie A : les températures**

Voici les températures relevées au pied des pistes.

| Heure | Température (°C) |
|---|---|
| 6 h | $-7$ |
| 9 h | $-4{,}5$ |
| 12 h | $1{,}5$ |
| 15 h | $3$ |
| 18 h | $-2$ |
| 21 h | $-5{,}5$ |

1. À quelles heures la température est-elle strictement négative ?
2. Ranger ces températures dans l'ordre croissant. À quelle heure fait-il le plus froid ?
3. Vrai ou faux : « À $21$ h, il fait plus froid qu'à $9$ h. » Justifier.
4. À quelle heure la température est-elle la plus proche de $0$ °C ?

**Partie B : le plan de la station**

Sur le plan, muni d'un repère, on a placé le chalet $C$, le départ du télésiège $T$, le restaurant $R$ et le parking $P$.

[IMAGE_1]

5. Lire les coordonnées des points $C$, $T$, $R$ et $P$.
6. Le poste de secours $S$ a pour coordonnées $(-2\,;\,-1)$. Le placer.
7. La fontaine $F$ a pour abscisse l'opposé de l'abscisse du restaurant, et la même ordonnée que le restaurant. Donner ses coordonnées et la placer.
8. Parmi $C$, $T$, $R$, $P$, $S$ et $F$, quels lieux ont une ordonnée strictement négative ?

Étapes:
<!-- optitab:1 -->
## Partie A : les températures

## Question 1 : Températures strictement négatives

::: methode
Une température strictement négative est écrite avec le signe $-$.
:::

::: etape Repérer le signe $-$
$-7$ (6 h), $-4{,}5$ (9 h), $-2$ (18 h) et $-5{,}5$ (21 h).
:::

::: resultat
À $6$ h, $9$ h, $18$ h et $21$ h.
:::

## Question 2 : Ordre croissant

::: methode
Les négatifs d'abord, du plus éloigné de zéro au plus proche, puis les positifs.
:::

::: etape Les négatifs
Distances à zéro : $7 > 5{,}5 > 4{,}5 > 2$, donc $-7 < -5{,}5 < -4{,}5 < -2$.
:::

::: etape Le rangement complet

[IMAGE_2]

$$-7 < -5{,}5 < -4{,}5 < -2 < 1{,}5 < 3$$
:::

::: resultat
$-7 < -5{,}5 < -4{,}5 < -2 < 1{,}5 < 3$ : il fait le plus froid à $6$ h.
:::

## Question 3 : $21$ h ou $9$ h ?

::: methode
Comparer $-5{,}5$ et $-4{,}5$ : entre deux négatifs, le plus petit est le plus éloigné de zéro.
:::

::: etape Comparer
$5{,}5 > 4{,}5$, donc $-5{,}5 < -4{,}5$.
:::

::: resultat
Vrai : $-5{,}5 < -4{,}5$, il fait plus froid à $21$ h qu'à $9$ h.
:::

## Question 4 : La plus proche de $0$ °C

::: methode
Comparer les distances à zéro, sans tenir compte du signe.
:::

::: etape Distances à zéro
| Heure | 6 h | 9 h | 12 h | 15 h | 18 h | 21 h |
|---|---|---|---|---|---|---|
| Distance à zéro | $7$ | $4{,}5$ | $1{,}5$ | $3$ | $2$ | $5{,}5$ |
:::

::: resultat
À $12$ h ($1{,}5$ °C, à $1{,}5$ degré de zéro).
:::

## Partie B : le plan de la station

## Question 5 : Lire des coordonnées

::: methode
Abscisse : déplacement horizontal depuis $O$ ; ordonnée : déplacement vertical. On écrit (abscisse ; ordonnée).
:::

::: etape Lire les quatre points
- $C$ : $3$ vers la gauche, $2$ vers le haut ; $T$ : $2$ vers la droite, $4$ vers le haut.
- $R$ : $4$ vers la droite, $1$ vers le bas ; $P$ : $4$ vers la gauche, $3$ vers le bas.
:::

::: resultat
$C(-3\,;\,2)$, $T(2\,;\,4)$, $R(4\,;\,-1)$, $P(-4\,;\,-3)$.
:::

## Question 6 : Placer le poste de secours

::: methode
Partir de $O$ : d'abord l'abscisse (horizontalement), puis l'ordonnée (verticalement).
:::

::: etape Déplacements
$S(-2\,;\,-1)$ : $2$ vers la gauche, puis $1$ vers le bas.
:::

[IMAGE_3]

::: resultat
$S$ est placé en vert sur le plan.
:::

## Question 7 : La fontaine

::: methode
Changer le signe de l'abscisse de $R$ et garder son ordonnée.
:::

::: etape Coordonnées de $F$
$R(4\,;\,-1)$ : l'opposé de $4$ est $-4$, l'ordonnée reste $-1$. Donc $F(-4\,;\,-1)$ : $4$ vers la gauche, $1$ vers le bas.
:::

::: resultat
$F(-4\,;\,-1)$, placé en vert sur le plan.
:::

## Question 8 : Ordonnées strictement négatives

::: methode
Regarder le second nombre des coordonnées.
:::

::: etape Trier
$C$ ($2$) et $T$ ($4$) ont une ordonnée positive ; $R$ ($-1$), $P$ ($-3$), $S$ ($-1$) et $F$ ($-1$) ont une ordonnée strictement négative : ils sont sous l'axe des abscisses.
:::

::: resultat
$R$, $P$, $S$ et $F$.
