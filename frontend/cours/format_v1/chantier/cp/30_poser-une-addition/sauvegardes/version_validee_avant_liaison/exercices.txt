===
Découverte - Poser une addition : atelier 1
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Tu peux prendre des jetons. Explique tes gestes avec des mots.

[IMAGE_1]

1. Pose et calcule 32 + 24.
2. Autre calcul : $32+23$. Combien font les unités ensemble ?
3. Pour $32+23$, faut-il une retenue ? Explique.
4. Pour $32+23$, combien de dizaines as-tu après l’échange ?
5. Calcule le total de $32+23$. Vérifie de tête.

Étapes:
<!-- optitab:1 -->

## Question 1 : Pose et calcule 32 + 24.

::: methode
Manipuler et calculer dans l’ordre.
:::

::: etape Raisonner
J’aligne les unités. Je commence à droite : $2 + 4=6$. J’écris 6 unités. Il n’y a pas de retenue. Je compte ensuite 5 dizaines. Le total est 56.

[IMAGE_2]
:::

::: etape Vérifier
Je vérifie les calculs : $32+24=56$.
:::

::: resultat
6 unités et 5 dizaines : 56.
:::

## Question 2 : Autre calcul : $32+23$. Combien font les unités ensemble ?

::: methode
Ajouter seulement les unités.
:::

::: etape Raisonner
$2+3=5$. Je n’ajoute pas encore les dizaines.
:::

::: resultat
J’obtiens 5 unités.
:::

## Question 3 : Pour $32+23$, faut-il une retenue ? Explique.

::: methode
Chercher un groupe de dix unités.
:::

::: etape Raisonner
Je peux former 0 groupe de dix unités. Il reste 5 unités.
:::

::: resultat
Il n’y a pas de retenue.
:::

## Question 4 : Pour $32+23$, combien de dizaines as-tu après l’échange ?

::: methode
Ajouter les dizaines et la retenue.
:::

::: etape Raisonner
$3+2+0=5$. Une retenue compte comme une dizaine.
:::

::: resultat
J’ai 5 dizaines.
:::

## Question 5 : Calcule le total de $32+23$. Vérifie de tête.

::: methode
Décomposer les nombres.
:::

::: etape Raisonner
Je sépare dizaines et unités. $30+20=50$. $2+3=5$. Je réunis : $50+5=55$.
:::

::: resultat
$32+23=55$
:::

Solution:
<!-- optitab:1 -->
1. 6 unités et 5 dizaines : 56.
2. J’obtiens 5 unités.
3. Il n’y a pas de retenue.
4. J’ai 5 dizaines.
5. $32+23=55$
