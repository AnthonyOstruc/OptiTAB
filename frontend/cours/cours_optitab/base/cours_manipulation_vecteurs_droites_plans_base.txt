    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Vecteurs de l'espace et translations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et notation</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Vecteur de l'espace</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>vecteur</strong> de l'espace est un objet mathématique caractérisé par sa direction, son sens, sa norme et son point d'application.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un vecteur est défini par ses coordonnées dans une base donnée :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\vec{u} = \begin{pmatrix} x \\ y \\ z \end{pmatrix}$ dans l'espace</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Notation</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle\vec{u}$, $\displaystyle\vec{v}$, $\displaystyle\vec{w}$ ou $\displaystyle\overrightarrow{AB}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle\vec{u} = \begin{pmatrix} x \\ y \\ z \end{pmatrix}$ dans l'espace</li>
                <li style="margin:0; text-align:left;">Le vecteur nul : $\displaystyle\vec{0} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Translation</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Translation</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>translation</strong> de vecteur $\displaystyle\vec{u}$ est la transformation qui à tout point $\displaystyle M$ associe le point $\displaystyle M'$ tel que $\displaystyle\overrightarrow{MM'} = \vec{u}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note : $\displaystyle M' = t_{\vec{u}}(M)$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Règles importantes</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Règle de Chasles :</strong> $\displaystyle\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Règle du parallélogramme :</strong> Dans un parallélogramme $\displaystyle ABCD$, on a $\displaystyle\overrightarrow{AB} + \overrightarrow{AD} = \overrightarrow{AC}$ où $\displaystyle\overrightarrow{AC}$ est la diagonale issue de $\displaystyle A$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Relation fondamentale :</strong> $\displaystyle\overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA}$ où $\displaystyle O$ est l'origine du repère</li>
                <li style="margin:0; text-align:left;"><strong>Vecteurs opposés :</strong> $\displaystyle\overrightarrow{AB} = -\overrightarrow{BA}$</li>
            </ul>
        </div>

        [IMAGE_1]

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle A(1, 2, 3)$ et $\displaystyle B(4, -1, 5)$ dans l'espace.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = \begin{pmatrix} 4 - 1 \\ -1 - 2 \\ 5 - 3 \end{pmatrix} = \begin{pmatrix} 3 \\ -3 \\ 2 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La translation de vecteur $\displaystyle\overrightarrow{AB}$ transforme le point $\displaystyle A$ en $\displaystyle B$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Combinaisons linéaires de vecteurs</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Combinaison linéaire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$ des vecteurs de l'espace et $\displaystyle a_1, a_2, \ldots, a_n$ des scalaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le vecteur $\displaystyle\vec{v} = a_1\vec{u_1} + a_2\vec{u_2} + \ldots + a_n\vec{u_n}$ est appelé <strong>combinaison linéaire</strong> des vecteurs $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation géométrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une combinaison linéaire permet de construire un vecteur à partir d'autres vecteurs en utilisant des multiplications et des additions.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une figure, on peut représenter une combinaison linéaire en construisant le vecteur résultant étape par étape.</p>
        </div>

        [IMAGE_2]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples concrets</h3>
        
        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle\vec{u} = \begin{pmatrix} 1 \\ 0 \\ 2 \end{pmatrix}$, $\displaystyle\vec{v} = \begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix}$ et $\displaystyle\vec{w} = \begin{pmatrix} 2 \\ 1 \\ 5 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exprimer $\displaystyle\vec{w}$ comme combinaison linéaire de $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle a$ et $\displaystyle b$ tels que $\displaystyle\vec{w} = a\vec{u} + b\vec{v}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{pmatrix} 2 \\ 1 \\ 5 \end{pmatrix} = a\begin{pmatrix} 1 \\ 0 \\ 2 \end{pmatrix} + b\begin{pmatrix} 0 \\ 1 \\ 1 \end{pmatrix} = \begin{pmatrix} a \\ b \\ 2a + b \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On obtient le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\begin{cases} a = 2 \\ b = 1 \\ 2a + b = 5 \end{cases}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle 2 \times 2 + 1 = 5$ ✓</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> $\displaystyle\vec{w} = 2\vec{u} + \vec{v}$</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Capacité attendue :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exploiter une figure pour exprimer un vecteur comme combinaison linéaire de vecteurs.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une figure géométrique (cube, pavé, tétraèdre), identifier les relations vectorielles et les exprimer sous forme de combinaisons linéaires.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Indépendance linéaire</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Indépendance linéaire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Des vecteurs $\displaystyle\vec{u_1}, \vec{u_2}, \ldots, \vec{u_n}$ sont dits <strong>linéairement indépendants</strong> si la seule combinaison linéaire qui donne le vecteur nul est celle où tous les coefficients sont nuls.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle a_1\vec{u_1} + a_2\vec{u_2} + \ldots + a_n\vec{u_n} = \vec{0} \Rightarrow a_1 = a_2 = \ldots = a_n = 0$</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>⚠️ Attention :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on peut trouver des coefficients non tous nuls tels que la combinaison linéaire donne le vecteur nul, alors les vecteurs sont <strong>linéairement dépendants</strong>.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Intérêt et interprétation de l'indépendance linéaire :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">L'indépendance linéaire est fondamentale pour caractériser les objets géométriques :</p>
            
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #10b981; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#d1fae5; border-bottom:2px solid #10b981;">
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50; width:35%;">Situation</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Signification</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Application</th>
                    </tr>
                </thead>
                <tbody>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;"><strong>2 vecteurs indépendants dans le plan</strong></td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils ne sont <strong>pas colinéaires</strong></td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils forment une base du plan → caractérisent un plan</td>
                    </tr>
                    <tr style="background:#ffffff;">
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;"><strong>3 vecteurs indépendants dans l'espace</strong></td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils ne sont <strong>pas coplanaires</strong></td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils forment une base de l'espace → caractérisent l'espace entier</td>
                    </tr>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;"><strong>3 vecteurs coplanaires</strong></td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils sont <strong>linéairement dépendants</strong> (non indépendants)</td>
                        <td style="border:1px solid #ddd; padding:10px; text-align:left;">Ils sont tous dans un même plan</td>
                    </tr>
                </tbody>
            </table>

            <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
                <p style="text-align:left; font-size:1em;"><strong>📐 Règle pratique à retenir :</strong></p>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                    <li style="margin:0 0 12px 0; text-align:left;">Pour caractériser un <strong>plan</strong> : besoin de 2 vecteurs <strong>non colinéaires</strong> (indépendants dans le plan)</li>
                    <li style="margin:0; text-align:left;">Pour caractériser l'<strong>espace</strong> : besoin de 3 vecteurs <strong>non coplanaires</strong> (indépendants dans l'espace)</li>
                </ul>
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Coplanarité de vecteurs</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>🔹 Définition - Coplanarité de vecteurs</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Trois vecteurs de l'espace sont dits <strong>coplanaires</strong> s'il existe un plan qui contient leurs représentants.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>En algèbre :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\vec{u}$, $\displaystyle\vec{v}$, $\displaystyle\vec{w}$ sont coplanaires $\displaystyle\Longleftrightarrow$ ils sont linéairement dépendants</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">c'est-à-dire qu'il existe des réels $\displaystyle a$, $\displaystyle b$, $\displaystyle c$, non tous nuls, tels que :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:600;">$\displaystyle a\vec{u} + b\vec{v} + c\vec{w} = \vec{0}$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Lien avec le plan :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si deux vecteurs $\displaystyle\vec{u}$, $\displaystyle\vec{v}$ sont <strong>non colinéaires</strong>, ils définissent un plan.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un troisième vecteur $\displaystyle\vec{w}$ est coplanaire à $\displaystyle\vec{u}$ et $\displaystyle\vec{v}$ s'il peut s'écrire comme combinaison linéaire :</p>
            <div style="background:#ecfdf5; border:3px solid #10b981; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:600;">$\displaystyle\vec{w} = \alpha\vec{u} + \beta\vec{v}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">pour certains réels $\displaystyle\alpha$, $\displaystyle\beta$.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Droites de l'espace</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Vecteurs directeurs et colinéarité</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Vecteur directeur d'une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>vecteur directeur</strong> d'une droite $\displaystyle (d)$ est un vecteur non nul qui a la même direction que la droite.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tous les vecteurs directeurs d'une même droite sont colinéaires entre eux.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Colinéarité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs sont <strong>colinéaires</strong> si leurs coordonnées sont proportionnelles.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle\vec{u} \text{ et } \vec{v} \text{ sont colinéaires } \Leftrightarrow \vec{u} = k\vec{v} \text{ pour un certain } k \in \mathbb{R}$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Interprétation géométrique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs colinéaires ont la même direction (parallèles).</p>
        </div>

        [IMAGE_3]

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Vérifier si $\displaystyle\vec{u} = \begin{pmatrix} 2 \\ 1 \\ -1 \end{pmatrix}$ et $\displaystyle\vec{v} = \begin{pmatrix} 4 \\ 2 \\ -2 \end{pmatrix}$ sont colinéaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On observe que $\displaystyle\vec{v} = 2\vec{u}$, donc les vecteurs sont colinéaires.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Plans de l'espace</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Direction d'un plan</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Direction d'un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>direction</strong> d'un plan $\displaystyle \mathcal{P}$ est l'ensemble des vecteurs qui sont parallèles au plan.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un plan est déterminé par deux vecteurs non colinéaires de sa direction.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Remarque :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs non colinéaires d'un plan forment une base de la direction du plan.</p>
        </div>

        [IMAGE_4]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Bases et repères de l'espace</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Base de l'espace</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Base de l'espace</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>base</strong> de l'espace est un triplet de vecteurs $\displaystyle(\vec{i}, \vec{j}, \vec{k})$ linéairement indépendants.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tout vecteur de l'espace peut s'écrire de manière unique comme combinaison linéaire des vecteurs de la base.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Base orthonormée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une base $\displaystyle(\vec{i}, \vec{j}, \vec{k})$ est dite <strong>orthonormée</strong> si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Les vecteurs sont unitaires : $\displaystyle\|\vec{i}\| = \|\vec{j}\| = \|\vec{k}\| = 1$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Les vecteurs sont deux à deux orthogonaux : $\displaystyle\vec{i} \cdot \vec{j} = \vec{j} \cdot \vec{k} = \vec{k} \cdot \vec{i} = 0$</li>
            </ul>
        </div>

        [IMAGE_5]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Repère de l'espace</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Repère de l'espace</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>repère</strong> de l'espace est constitué d'un point origine $\displaystyle O$ et d'une base $\displaystyle(\vec{i}, \vec{j}, \vec{k})$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note : $\displaystyle\mathcal{R} = (O, \vec{i}, \vec{j}, \vec{k})$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Coordonnées d'un point</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un repère $\displaystyle\mathcal{R} = (O, \vec{i}, \vec{j}, \vec{k})$, tout point $\displaystyle M$ admet des coordonnées uniques $\displaystyle(x, y, z)$ telles que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{OM} = x\vec{i} + y\vec{j} + z\vec{k}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Décomposition d'un vecteur sur une base</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Décomposition d'un vecteur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle(\vec{i}, \vec{j}, \vec{k})$ une base de l'espace. Tout vecteur $\displaystyle\vec{u}$ s'écrit de manière unique :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle\vec{u} = x\vec{i} + y\vec{j} + z\vec{k}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les réels $\displaystyle x$, $\displaystyle y$, $\displaystyle z$ sont les <strong>coordonnées</strong> de $\displaystyle\vec{u}$ dans la base $\displaystyle(\vec{i}, \vec{j}, \vec{k})$.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Capacité attendue :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Lire sur une figure si deux vecteurs d'un plan, trois vecteurs de l'espace, forment une base.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Lire sur une figure la décomposition d'un vecteur dans une base.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Dans la base canonique $\displaystyle(\vec{i}, \vec{j}, \vec{k})$ de l'espace, le vecteur $\displaystyle\vec{u} = \begin{pmatrix} 3 \\ -2 \\ 5 \end{pmatrix}$ se décompose comme :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\vec{u} = 3\vec{i} - 2\vec{j} + 5\vec{k}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Positions relatives et configurations géométriques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Positions relatives de deux droites</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Positions relatives de deux droites</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle (d_1)$ et $\displaystyle (d_2)$ deux droites de vecteurs directeurs respectifs $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Parallèles distinctes :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ colinéaires, aucun point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondues :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ colinéaires, un point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Sécantes :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ non colinéaires, un point commun</li>
                <li style="margin:0; text-align:left;"><strong>Non coplanaires :</strong> $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ non colinéaires, aucun point commun</li>
            </ul>
        </div>

        [IMAGE_6]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Position relative d'une droite et d'un plan</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Positions relatives d'une droite et d'un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (d)$ une droite de vecteur directeur $\displaystyle \vec{u}$ et $\displaystyle \mathcal{P}$ un plan de vecteurs directeurs $\displaystyle \vec{v_1}$ et $\displaystyle \vec{v_2}$ (non colinéaires).</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Parallèle au plan :</strong> $\displaystyle \vec{u}$ est combinaison linéaire de $\displaystyle \vec{v_1}$ et $\displaystyle \vec{v_2}$, aucun point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Incluse dans le plan :</strong> $\displaystyle \vec{u}$ est combinaison linéaire de $\displaystyle \vec{v_1}$ et $\displaystyle \vec{v_2}$, un point commun</li>
                <li style="margin:0; text-align:left;"><strong>Sécante :</strong> $\displaystyle \vec{u}$ n'est pas combinaison linéaire de $\displaystyle \vec{v_1}$ et $\displaystyle \vec{v_2}$ (un point d'intersection)</li>
            </ul>
        </div>

        [IMAGE_7]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Position relative de deux plans</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Positions relatives de deux plans</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \mathcal{P}_1$ et $\displaystyle \mathcal{P}_2$ deux plans de directions respectives engendrées par $\displaystyle(\vec{u_1}, \vec{v_1})$ et $\displaystyle(\vec{u_2}, \vec{v_2})$.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Parallèles distincts :</strong> les directions sont identiques, aucun point commun</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondus :</strong> les directions sont identiques, un point commun</li>
                <li style="margin:0; text-align:left;"><strong>Sécants :</strong> les directions sont différentes (intersection = une droite)</li>
            </ul>
        </div>

        [IMAGE_8]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Loi des toits</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Loi des toits</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \mathcal{P}_1$ et $\displaystyle \mathcal{P}_2$ deux plans sécants selon une droite $\displaystyle (d)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle (d_1)$ est une droite de $\displaystyle \mathcal{P}_1$ parallèle à $\displaystyle (d)$, et si $\displaystyle (d_2)$ est une droite de $\displaystyle \mathcal{P}_2$ parallèle à $\displaystyle (d)$, alors les droites $\displaystyle (d_1)$ et $\displaystyle (d_2)$ sont <strong>parallèles</strong> entre elles.</p>
        </div>

        [IMAGE_9]

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Interprétation géométrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La loi des toits tire son nom de la configuration géométrique qui ressemble à un toit : deux plans sécants (les deux pans du toit) et des droites parallèles à la faîtière (la droite d'intersection des deux plans).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette propriété est très utile pour démontrer le parallélisme de droites dans des configurations spatiales complexes, notamment dans des solides comme les cubes, pavés ou tétraèdres.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Caractérisation vectorielle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ les vecteurs directeurs respectifs de $\displaystyle (d_1)$ et $\displaystyle (d_2)$, et $\displaystyle \vec{u}$ un vecteur directeur de $\displaystyle (d)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ sont tous les deux colinéaires à $\displaystyle \vec{u}$, alors $\displaystyle \vec{u_1}$ et $\displaystyle \vec{u_2}$ sont colinéaires entre eux, donc $\displaystyle (d_1)$ et $\displaystyle (d_2)$ sont parallèles.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Dans un cube $\displaystyle ABCDEFGH$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Les plans $\displaystyle (ABCD)$ et $\displaystyle (BCGF)$ sont <strong>sécants</strong> selon la droite $\displaystyle (BC)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Dans le plan $\displaystyle (ABCD)$, la droite $\displaystyle (AD)$ est <strong>parallèle</strong> à $\displaystyle (BC)$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Dans le plan $\displaystyle (BCGF)$, la droite $\displaystyle (FG)$ est <strong>parallèle</strong> à $\displaystyle (BC)$</li>
            </ul>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong> Par la loi des toits, les droites $\displaystyle (AD)$ et $\displaystyle (FG)$ sont <strong>parallèles</strong> entre elles.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En effet, puisque $\displaystyle (AD)$ et $\displaystyle (FG)$ sont toutes les deux parallèles à la droite d'intersection $\displaystyle (BC)$ des deux plans sécants, elles sont parallèles entre elles.</p>
        </div>

        [IMAGE_10]

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>⚠️ Attention :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La loi des toits nécessite que les deux plans soient <strong>sécants</strong>. Si les plans sont parallèles, la propriété ne s'applique pas directement.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">De plus, il faut que les droites soient parallèles à la droite d'intersection des deux plans pour que la conclusion soit valable.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Étude géométrique de configurations simples</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>🔹 Définition - Coplanarité</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Pour les vecteurs :</strong> Trois vecteurs $\displaystyle\vec{u}$, $\displaystyle\vec{v}$, $\displaystyle\vec{w}$ de l'espace sont dits <strong>coplanaires</strong> s'il existe un plan qui contient leurs représentants, c'est-à-dire s'ils sont linéairement dépendants :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:600;">$\displaystyle a\vec{u} + b\vec{v} + c\vec{w} = \vec{0}$ avec $a$, $b$, $c$ non tous nuls</p>
            </div>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Pour les points :</strong> Quatre points $A$, $B$, $C$, $D$ de l'espace sont dits <strong>coplanaires</strong> s'ils appartiennent à un même plan. Cela revient à vérifier que les vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ (formés à partir d'un point de référence, par exemple $A$) sont coplanaires.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Capacité attendue :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Étudier géométriquement des problèmes simples de configurations dans l'espace :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Alignement :</strong> trois points $A$, $B$, $C$ sont alignés si les vecteurs $\displaystyle\overrightarrow{AB}$ et $\displaystyle\overrightarrow{AC}$ sont colinéaires <strong>et partagent un point commun</strong> (ici le point $A$)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Coplanarité de points :</strong> quatre points $A$, $B$, $C$, $D$ sont coplanaires si les vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ (qui partagent tous le point $A$) sont coplanaires, c'est-à-dire linéairement dépendants</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Colinéarité :</strong> deux vecteurs sont colinéaires si leurs coordonnées sont proportionnelles</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Parallélisme :</strong> deux droites sont parallèles si leurs vecteurs directeurs sont colinéaires</li>
                <li style="margin:0; text-align:left;"><strong>Coplanarité de vecteurs :</strong> trois vecteurs sont coplanaires s'ils sont linéairement dépendants</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Alignement de trois points</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle A(1, 2, 3)$, $\displaystyle B(2, 4, 5)$, $\displaystyle C(3, 6, 7)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les points $A$, $B$, $C$ sont alignés si et seulement si les vecteurs $\displaystyle \overrightarrow{AB}$ et $\displaystyle \overrightarrow{AC}$ sont colinéaires <strong>et partagent le point commun $A$</strong>.</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \overrightarrow{AB} = \begin{pmatrix} 1 \\ 2 \\ 2 \end{pmatrix}$ et $\displaystyle \overrightarrow{AC} = \begin{pmatrix} 2 \\ 4 \\ 4 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On observe que $\displaystyle \overrightarrow{AC} = 2\overrightarrow{AB}$, donc les vecteurs sont colinéaires. De plus, ils partagent tous les deux le point $A$ comme origine, donc les trois points sont alignés.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Coplanarité de trois vecteurs</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 2 \\ 1 \end{pmatrix}$, $\displaystyle \vec{v} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$, $\displaystyle \vec{w} = \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs sont coplanaires s'il existe des réels $\displaystyle a$, $\displaystyle b$, $\displaystyle c$ non tous nuls tels que $\displaystyle a\vec{u} + b\vec{v} + c\vec{w} = \vec{0}$.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle a$, $\displaystyle b$, $\displaystyle c$ tels que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a\begin{pmatrix} 1 \\ 2 \\ 1 \end{pmatrix} + b\begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix} + c\begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En développant, on obtient le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \begin{cases} a + 2b + 3c = 0 \quad (1) \\ 2a - b + c = 0 \quad (2) \\ a + 3b + 4c = 0 \quad (3) \end{cases}$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 1 :</strong> De l'équation (1), on exprime $\displaystyle a$ en fonction de $\displaystyle b$ et $\displaystyle c$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a = -2b - 3c$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 2 :</strong> On substitue dans l'équation (2) :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle 2(-2b - 3c) - b + c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle -4b - 6c - b + c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle -5b - 5c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle b = -c$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 3 :</strong> On substitue dans l'équation (3) :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (-2b - 3c) + 3b + 4c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle -2b - 3c + 3b + 4c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle b + c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle b = -c$ (cohérent avec l'étape 2)</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 4 :</strong> On détermine $\displaystyle a$ en fonction de $\displaystyle c$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a = -2(-c) - 3c = 2c - 3c = -c$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 5 :</strong> Vérification dans l'équation (1) :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (-c) + 2(-c) + 3c = -c - 2c + 3c = 0$ ✓</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a trouvé une solution non triviale : $\displaystyle a = -c$, $\displaystyle b = -c$ pour tout $\displaystyle c \in \mathbb{R}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple, pour $\displaystyle c = 1$, on a $\displaystyle a = -1$ et $\displaystyle b = -1$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérification : $\displaystyle -1 \times \begin{pmatrix} 1 \\ 2 \\ 1 \end{pmatrix} + (-1) \times \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix} + 1 \times \begin{pmatrix} 3 \\ 1 \\ 4 \end{pmatrix} = \begin{pmatrix} -1-2+3 \\ -2+1+1 \\ -1-3+4 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}$ ✓</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> Les trois vecteurs sont <strong>coplanaires</strong> car il existe une relation non triviale : $\displaystyle -\vec{u} - \vec{v} + \vec{w} = \vec{0}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Coplanarité de quatre points</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Vérifier si les points $\displaystyle A(1, 0, 0)$, $\displaystyle B(2, 1, 0)$, $\displaystyle C(0, 1, 1)$ et $\displaystyle D(3, 2, 1)$ sont coplanaires.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode :</strong> Quatre points $A$, $B$, $C$, $D$ sont coplanaires si et seulement si les trois vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ (qui partagent tous le point $A$ comme origine) sont coplanaires, c'est-à-dire linéairement dépendants.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 1 :</strong> Calcul des vecteurs à partir du point de référence $A$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AB} = \begin{pmatrix} 2-1 \\ 1-0 \\ 0-0 \end{pmatrix} = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AC} = \begin{pmatrix} 0-1 \\ 1-0 \\ 1-0 \end{pmatrix} = \begin{pmatrix} -1 \\ 1 \\ 1 \end{pmatrix}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle\overrightarrow{AD} = \begin{pmatrix} 3-1 \\ 2-0 \\ 1-0 \end{pmatrix} = \begin{pmatrix} 2 \\ 2 \\ 1 \end{pmatrix}$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 2 :</strong> Vérification de la coplanarité des trois vecteurs</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ sont coplanaires s'il existe des réels $\displaystyle a$, $\displaystyle b$, $\displaystyle c$ non tous nuls tels que :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a\overrightarrow{AB} + b\overrightarrow{AC} + c\overrightarrow{AD} = \vec{0}$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a\begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix} + b\begin{pmatrix} -1 \\ 1 \\ 1 \end{pmatrix} + c\begin{pmatrix} 2 \\ 2 \\ 1 \end{pmatrix} = \begin{pmatrix} 0 \\ 0 \\ 0 \end{pmatrix}$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 3 :</strong> Résolution du système linéaire</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En développant, on obtient le système :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle \begin{cases} a - b + 2c = 0 \quad (1) \\ a + b + 2c = 0 \quad (2) \\ b + c = 0 \quad (3) \end{cases}$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 4 :</strong> De l'équation (3), on exprime $\displaystyle b$ en fonction de $\displaystyle c$ :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle b = -c$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 5 :</strong> On substitue dans l'équation (1) :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a - (-c) + 2c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a + c + 2c = 0$</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle a = -3c$</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 6 :</strong> Vérification dans l'équation (2) :</p>
            <p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle (-3c) + (-c) + 2c = -3c - c + 2c = -2c$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour que l'équation (2) soit vérifiée, il faut $\displaystyle -2c = 0$, donc $\displaystyle c = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle c = 0$, alors $\displaystyle a = 0$ et $\displaystyle b = 0$, ce qui donne la solution triviale.</p>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le système n'admet que la solution triviale $\displaystyle a = b = c = 0$. Les trois vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ (qui partagent tous le point $A$) sont donc <strong>linéairement indépendants</strong>, ce qui signifie qu'ils ne sont <strong>pas coplanaires</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong> Les quatre points $A$, $B$, $C$ et $D$ sont <strong>non coplanaires</strong> car les vecteurs $\displaystyle\overrightarrow{AB}$, $\displaystyle\overrightarrow{AC}$ et $\displaystyle\overrightarrow{AD}$ (formés à partir du point $A$) sont linéairement indépendants, donc les points ne peuvent pas tous appartenir à un même plan.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. 🌟 Bonus - Approfondissements possibles</h2>

    <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:15px; margin:15px 0;">
        <p style="margin:0; text-align:left; font-size:1em;"><strong>🌟 Approfondissement :</strong> Les sections suivantes enrichissent votre culture mathématique et vous permettent d'explorer des thèmes avancés.</p>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Barycentre d'un système pondéré</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>⚠️ Important :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le barycentre est un concept important souvent vu en cours d'algèbre. Cette section est un approfondissement qui enrichit votre culture mathématique.</p>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Barycentre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (A_1, \alpha_1), (A_2, \alpha_2), \ldots, (A_n, \alpha_n)$ un système de points pondérés avec $\displaystyle \alpha_1 + \alpha_2 + \ldots + \alpha_n \neq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>barycentre</strong> $\displaystyle G$ de ce système est l'unique point tel que :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \alpha_1\overrightarrow{GA_1} + \alpha_2\overrightarrow{GA_2} + \ldots + \alpha_n\overrightarrow{GA_n} = \vec{0}$</p>
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Associativité du barycentre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si on regroupe certains points en un barycentre partiel, le barycentre global reste inchangé.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette propriété permet de simplifier les calculs dans des problèmes géométriques complexes.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Barycentre de deux points : $\displaystyle G$ est le barycentre de $\displaystyle (A, \alpha)$ et $\displaystyle (B, \beta)$ avec $\displaystyle \alpha + \beta \neq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle \alpha\overrightarrow{GA} + \beta\overrightarrow{GB} = \vec{0}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle \alpha = \beta = 1$, alors $\displaystyle G$ est le milieu de $\displaystyle [AB]$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Fonction vectorielle de Leibniz</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>⚠️ Important :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction vectorielle de Leibniz n'apparaît pas dans tous les cursus de mathématiques. Cette section constitue un approfondissement culturel intéressant pour explorer des concepts avancés.</p>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction vectorielle de Leibniz</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle (A_1, \alpha_1), (A_2, \alpha_2), \ldots, (A_n, \alpha_n)$ un système de points pondérés avec $\displaystyle \alpha_1 + \alpha_2 + \ldots + \alpha_n \neq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>fonction vectorielle de Leibniz</strong> associe à tout point $\displaystyle M$ le vecteur :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle f(M) = \alpha_1\overrightarrow{MA_1} + \alpha_2\overrightarrow{MA_2} + \ldots + \alpha_n\overrightarrow{MA_n}$</p>
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Caractérisation du barycentre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le barycentre $\displaystyle G$ est l'unique point tel que $\displaystyle f(G) = \vec{0}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout point $\displaystyle M$, on a : $\displaystyle f(M) = (\alpha_1 + \alpha_2 + \ldots + \alpha_n)\overrightarrow{MG}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple d'application :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">La fonction vectorielle de Leibniz permet de résoudre des problèmes de géométrie en utilisant des relations vectorielles.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Elle est particulièrement utile pour démontrer des propriétés de configurations géométriques complexes.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre "colinéaires" et "égaux" : deux vecteurs colinéaires peuvent avoir des normes différentes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de vérifier que les vecteurs directeurs d'un plan sont non colinéaires</li>
                <li style="margin:0 0 12px 0; text-align:left;">Négliger le cas particulier du vecteur nul (toujours dépendant avec n'importe quel autre vecteur)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre "coplanaires" et "colinéaires" : la coplanarité concerne 3 vecteurs, la colinéarité 2 vecteurs</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier que dans l'espace, deux droites peuvent être non coplanaires (ni parallèles, ni sécantes)</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la cohérence des dimensions (on ne peut pas avoir plus de vecteurs indépendants que la dimension de l'espace)</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser des figures (cube, pavé, tétraèdre) pour visualiser les configurations</li>
                <li style="margin:0 0 12px 0; text-align:left;">Toujours vérifier la non-colinéarité des vecteurs directeurs d'un plan</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les combinaisons linéaires, bien identifier les vecteurs de base</li>
                <li style="margin:0 0 12px 0; text-align:left;">Sur une figure, repérer les relations vectorielles (règle de Chasles, parallélisme, etc.)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les positions relatives, analyser d'abord les vecteurs directeurs, puis les points communs</li>
                <li style="margin:0; text-align:left;">S'entraîner sur des exemples concrets avec des solides usuels pour développer la vision dans l'espace</li>
            </ul>
        </div>
