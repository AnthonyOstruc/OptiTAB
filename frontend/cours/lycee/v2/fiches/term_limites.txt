<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Limites et asymptotes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ $\lim\limits_{x \to \pm\infty} f(x) = \ell$ : asymptote horizontale $y = \ell$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\lim\limits_{x \to a} f(x) = \pm\infty$ : asymptote verticale $x = a$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Polynôme ou fraction rationnelle en $\pm\infty$ : termes de plus haut degré.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Outils de calcul</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\lim\limits_{x \to +\infty} \frac{e^x}{x^n} = +\infty$ ; $\lim\limits_{x \to -\infty} x^ne^x = 0$</p>
</div>
[IMAGE_2]
<p style="margin:0;">• Composition : limite de $u$, puis limite de $g$ en ce point.</p>
<p style="margin:6px 0 0 0;">• Comparaison et gendarmes pour les fonctions oscillantes ($\sin$, $\cos$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Conclure directement sur une forme indéterminée.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier le signe du dénominateur en $a^+$ et $a^-$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Utiliser les croissances comparées sur une somme sans factoriser.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre asymptote horizontale ($y = \ell$) et verticale ($x = a$).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> forme indéterminée → je factorise par le terme qui « domine » ($e^x$ devant $x^n$, $x^n$ devant $x^{n-1}$).</p>
</div>
