=== Découverte - Additionner sur une droite graduée
Id: 2772
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur une droite graduée, ajouter un nombre positif fait avancer vers la droite ; ajouter un nombre négatif fait reculer vers la gauche. Sur chaque droite ci-dessous, le point bleu marque le premier terme de la somme.

[IMAGE_1]

1. À l'aide des droites graduées, calculer :
   - a) $(-3) + (+5)$ ;
   - b) $(+2) + (-6)$ ;
   - c) $(-1) + (-4)$.
2. Calculer $(-7) + (+7)$. Comment appelle-t-on deux nombres dont la somme est nulle ?
3. Sans droite graduée, calculer en indiquant la règle utilisée :
   - a) $(-12) + (-9)$ ;
   - b) $(+15) + (-23)$ ;
   - c) $(-3{,}5) + (+8{,}2)$.
4. Tom affirme : « $(-6) + (-4) = 10$, car deux signes moins donnent un signe plus. » Expliquer son erreur.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer avec les droites graduées

::: methode
On part du premier terme, puis on se déplace de la distance à zéro du second terme : vers la droite s'il est positif, vers la gauche s'il est négatif.
:::

::: etape a) $(-3) + (+5)$
On part de $-3$ et on **avance** de $5$ graduations : $-2$, $-1$, $0$, $1$, $2$. On arrive à $2$.
:::

::: etape b) $(+2) + (-6)$
On part de $2$ et on **recule** de $6$ graduations : on passe par $0$ après $2$ graduations, puis on recule encore de $4$. On arrive à $-4$.
:::

::: etape c) $(-1) + (-4)$
On part de $-1$ et on **recule** de $4$ graduations. On arrive à $-5$.
:::

[IMAGE_2]

::: resultat
- a) $(-3) + (+5) = 2$
- b) $(+2) + (-6) = -4$
- c) $(-1) + (-4) = -5$
:::

## Question 2 : Calculer $(-7) + (+7)$

::: etape Le déplacement
On part de $-7$ et on avance de $7$ : on arrive exactement à $0$.
:::

::: resultat
$(-7) + (+7) = 0$. Deux nombres dont la somme est nulle sont des nombres **opposés**.
:::

## Question 3 : Calculer sans droite graduée

::: methode
Même signe : on additionne les distances à zéro et on garde le signe. Signes contraires : on soustrait les distances à zéro et on prend le signe du nombre le plus éloigné de zéro.
:::

::: etape a) $(-12) + (-9)$ : même signe
Les deux termes sont négatifs. On additionne les distances à zéro : $12 + 9 = 21$. On garde le signe $-$.
:::

::: etape b) $(+15) + (-23)$ : signes contraires
On soustrait les distances à zéro : $23 - 15 = 8$. C'est $-23$ qui est le plus éloigné de zéro : le résultat est négatif.
:::

::: etape c) $(-3{,}5) + (+8{,}2)$ : signes contraires
On soustrait les distances à zéro : $8{,}2 - 3{,}5 = 4{,}7$. C'est $+8{,}2$ qui est le plus éloigné de zéro : le résultat est positif.
:::

::: resultat
- a) $(-12) + (-9) = -21$
- b) $(+15) + (-23) = -8$
- c) $(-3{,}5) + (+8{,}2) = 4{,}7$
:::

## Question 4 : L'erreur de Tom

::: etape Refaire le calcul
On part de $-6$ et on **recule** encore de $4$ : on s'éloigne de zéro du côté négatif. Les deux termes sont négatifs : on additionne les distances à zéro ($6 + 4 = 10$) et on garde le signe $-$.
:::

::: resultat
$(-6) + (-4) = -10$. La phrase « deux signes moins donnent un signe plus » n'est pas une règle de l'addition : la somme de deux nombres négatifs est toujours négative.
:::

::: attention Erreur fréquente
Pour additionner, on ne « multiplie » pas les signes : on regarde si les deux termes ont le même signe ou des signes contraires.
:::

Solution:
<!-- optitab:1 -->
1. a) $2$ ; b) $-4$ ; c) $-5$.
2. $0$ : ce sont des nombres opposés.
3. a) $-21$ (même signe) ; b) $-8$ (signes contraires) ; c) $4{,}7$ (signes contraires).
4. $(-6) + (-4) = -10$ : la somme de deux négatifs est négative.

=== Découverte - Soustraire, c'est ajouter l'opposé
Id: 2773
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pour soustraire un nombre relatif, on ajoute son opposé.

1. Recopier et compléter :
   - a) l'opposé de $-4$ est … ; l'opposé de $+9$ est … ;
   - b) $7 - (-4) = 7 + \ldots = \ldots$ ;
   - c) $-6 - (+2) = -6 + \ldots = \ldots$.
2. Transformer chaque soustraction en addition, puis calculer :
   - a) $-3 - (-8)$ ;
   - b) $2{,}5 - (+6)$ ;
   - c) $-1{,}2 - (-1{,}2)$ ;
   - d) $0 - (+5)$.
3. Sur les droites graduées ci-dessous, le point bleu a pour abscisse $1$. Représenter les calculs $1 - (-4)$ et $1 - (+4)$ par un déplacement, puis donner leurs résultats.

[IMAGE_1]

4. Calculer $4 - 9$ et $9 - 4$. Que remarque-t-on ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compléter

::: methode
L'opposé d'un nombre a la même distance à zéro et le signe contraire. On remplace la soustraction par l'addition de l'opposé.
:::

::: etape a) Les opposés
L'opposé de $-4$ est $+4$ ; l'opposé de $+9$ est $-9$.
:::

::: etape b) Transformer, puis calculer
$$
\begin{aligned}
7 - (-4) &= 7 + (+4) \\
&= 11
\end{aligned}
$$
:::

::: etape c) Transformer, puis calculer
$$
\begin{aligned}
-6 - (+2) &= -6 + (-2) \\
&= -8
\end{aligned}
$$
:::

::: resultat
$7 - (-4) = 7 + 4 = 11$ et $-6 - (+2) = -6 + (-2) = -8$.
:::

## Question 2 : Transformer, puis calculer

::: etape a) $-3 - (-8)$
$$
\begin{aligned}
-3 - (-8) &= -3 + (+8) \\
&= 5
\end{aligned}
$$
Signes contraires : $8 - 3 = 5$, et $+8$ l'emporte.
:::

::: etape b) $2{,}5 - (+6)$
$$
\begin{aligned}
2{,}5 - (+6) &= 2{,}5 + (-6) \\
&= -3{,}5
\end{aligned}
$$
Signes contraires : $6 - 2{,}5 = 3{,}5$, et $-6$ l'emporte.
:::

::: etape c) $-1{,}2 - (-1{,}2)$
$$
\begin{aligned}
-1{,}2 - (-1{,}2) &= -1{,}2 + (+1{,}2) \\
&= 0
\end{aligned}
$$
On ajoute deux opposés : la somme est nulle.
:::

::: etape d) $0 - (+5)$
$$
\begin{aligned}
0 - (+5) &= 0 + (-5) \\
&= -5
\end{aligned}
$$
:::

::: resultat
a) $5$ ; b) $-3{,}5$ ; c) $0$ ; d) $-5$.
:::

::: attention Erreur fréquente
Dans $-3 - (-8)$, il faut changer **les deux** signes : la soustraction devient une addition **et** $-8$ devient $+8$. Écrire $-3 - 8$ ou $-3 + (-8)$ est faux.
:::

## Question 3 : Les déplacements

::: methode
Soustraire $-4$ revient à ajouter $+4$ : on avance de $4$. Soustraire $+4$ revient à ajouter $-4$ : on recule de $4$.
:::

::: etape Représenter les deux calculs
- $1 - (-4) = 1 + 4$ : on part de $1$ et on avance de $4$ ; on arrive à $5$.
- $1 - (+4) = 1 + (-4)$ : on part de $1$ et on recule de $4$ ; on arrive à $-3$.
:::

[IMAGE_2]

::: resultat
$1 - (-4) = 5$ et $1 - (+4) = -3$.
:::

## Question 4 : Calculer $4 - 9$ et $9 - 4$

::: etape Calculer
$$
\begin{aligned}
4 - 9 &= 4 + (-9) \\
&= -5
\end{aligned}
$$
$$9 - 4 = 5$$
:::

::: resultat
$4 - 9 = -5$ et $9 - 4 = 5$ : les deux résultats sont **opposés**. En changeant l'ordre d'une soustraction, on obtient l'opposé du résultat.
:::

::: retenir
$a - b = a + (\text{opposé de } b)$. Soustraire un nombre négatif fait augmenter ; soustraire un nombre positif fait diminuer.
:::

Solution:
<!-- optitab:1 -->
1. a) $+4$ ; $-9$. b) $7 + 4 = 11$. c) $-6 + (-2) = -8$.
2. a) $5$ ; b) $-3{,}5$ ; c) $0$ ; d) $-5$.
3. $1 - (-4) = 5$ ; $1 - (+4) = -3$.
4. $4 - 9 = -5$ et $9 - 4 = 5$ : résultats opposés.

=== Découverte - Les températures d'une journée
Id: 2768
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le thermomètre ci-dessous indique la température à 6 h. Ensuite, la température augmente de $7$ °C jusqu'à midi, puis baisse de $5$ °C jusqu'à 18 h.

[IMAGE_1]

1. Lire la température à 6 h.
2. Traduire la hausse du matin et la baisse de l'après-midi par deux nombres relatifs.
3. Calculer la température à midi, puis à 18 h.
4. Calculer la variation de température entre 6 h et 18 h. Est-ce une hausse ou une baisse ?
5. Pendant la nuit, la température descend jusqu'à $-6$ °C. Calculer la variation entre 18 h et ce minimum.
6. Calculer l'écart entre la température la plus haute et la température la plus basse de cette journée et de cette nuit.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire la température à 6 h

::: etape Lire le thermomètre
Chaque graduation vaut $1$ °C. Le niveau est sous le $0$ et arrive exactement sur la graduation $-4$.
:::

::: resultat
À 6 h, il fait $-4$ °C.
:::

## Question 2 : Traduire par des nombres relatifs

::: methode
Une hausse se traduit par un nombre positif, une baisse par un nombre négatif.
:::

::: resultat
Hausse du matin : $+7$ °C. Baisse de l'après-midi : $-5$ °C.
:::

## Question 3 : Les températures à midi et à 18 h

::: methode
Température atteinte $=$ température de départ $+$ variation.
:::

::: etape À midi
$$(-4) + (+7) = 3$$
Signes contraires : $7 - 4 = 3$, et $+7$ l'emporte.
:::

::: etape À 18 h
$$3 + (-5) = -2$$
Signes contraires : $5 - 3 = 2$, et $-5$ l'emporte.
:::

[IMAGE_2]

::: resultat
À midi, il fait $3$ °C ; à 18 h, il fait $-2$ °C.
:::

## Question 4 : La variation entre 6 h et 18 h

::: methode
Variation $=$ valeur finale $-$ valeur initiale.
:::

::: etape Calculer
$$
\begin{aligned}
(-2) - (-4) &= -2 + 4 \\
&= 2
\end{aligned}
$$
:::

::: etape Contrôler avec les deux variations
$(+7) + (-5) = 2$ : on retrouve le même résultat.
:::

::: resultat
La variation vaut $+2$ °C : c'est une **hausse** de $2$ °C.
:::

## Question 5 : La variation pendant la nuit

::: etape Calculer
$$
\begin{aligned}
(-6) - (-2) &= -6 + 2 \\
&= -4
\end{aligned}
$$
:::

::: resultat
La variation vaut $-4$ °C : la température a baissé de $4$ °C.
:::

## Question 6 : L'écart entre la plus haute et la plus basse température

::: etape Repérer les extrêmes
La température la plus haute est $3$ °C (midi) ; la plus basse est $-6$ °C (la nuit).
:::

::: etape Calculer l'écart
$$
\begin{aligned}
3 - (-6) &= 3 + 6 \\
&= 9
\end{aligned}
$$
:::

::: resultat
L'écart est de $9$ °C.
:::

::: attention Erreur fréquente
Ne pas confondre une **température** ($-2$ °C à 18 h) et une **variation** ($+2$ °C entre 6 h et 18 h). Un écart, lui, est toujours positif : on soustrait la plus petite valeur de la plus grande.
:::

Solution:
<!-- optitab:1 -->
1. $-4$ °C.
2. $+7$ °C et $-5$ °C.
3. Midi : $3$ °C ; 18 h : $-2$ °C.
4. $+2$ °C : une hausse.
5. $-4$ °C.
6. $3 - (-6) = 9$ °C.

=== Entraînement - Calculer des sommes algébriques
Id: 2779
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
1. Écrire chaque expression sans les parenthèses (écriture simplifiée), puis la calculer :
   - a) $A = (+5) + (-8) - (-3)$ ;
   - b) $B = (-4) - (+6) + (-2) - (-9)$ ;
   - c) $C = (+2{,}5) - (+4) + (-1{,}5) - (-7)$.
2. Calculer en regroupant les termes positifs et les termes négatifs :
$$D = -7 + 4 - 9 + 12 - 3 + 1$$
3. Calculer astucieusement en repérant des termes opposés :
$$E = 13{,}6 - 8 + 5 - 13{,}6 + 8 - 11$$
4. Mila écrit : $(-3) - (-5) = -3 - 5 = -8$. Trouver son erreur et corriger le calcul.

Étapes:
<!-- optitab:1 -->
## Question 1 : Écriture simplifiée, puis calcul

::: methode
On garde un seul signe devant chaque terme : $+(+5) = +5$ ; $+(-8) = -8$ ; $-(-3) = +3$ ; $-(+6) = -6$. Puis on calcule de gauche à droite.
:::

::: etape a) Calculer $A$
$$
\begin{aligned}
A &= 5 - 8 + 3 \\
&= -3 + 3 \\
&= 0
\end{aligned}
$$
:::

::: etape b) Calculer $B$
$$
\begin{aligned}
B &= -4 - 6 - 2 + 9 \\
&= -10 - 2 + 9 \\
&= -12 + 9 \\
&= -3
\end{aligned}
$$
:::

::: etape c) Calculer $C$
$$
\begin{aligned}
C &= 2{,}5 - 4 - 1{,}5 + 7 \\
&= -1{,}5 - 1{,}5 + 7 \\
&= -3 + 7 \\
&= 4
\end{aligned}
$$
:::

::: resultat
$A = 0$ ; $B = -3$ ; $C = 4$.
:::

## Question 2 : Regrouper les positifs et les négatifs

::: methode
Chaque terme se déplace **avec son signe**. On additionne les termes positifs, puis les termes négatifs, et on termine par une seule addition.
:::

::: etape Les deux groupes
- Termes positifs : $4 + 12 + 1 = 17$.
- Termes négatifs : $-7 - 9 - 3 = -19$.
:::

::: etape Le calcul final
$$
\begin{aligned}
D &= 17 + (-19) \\
&= -2
\end{aligned}
$$
:::

::: resultat
$D = -2$.
:::

## Question 3 : Repérer les opposés

::: etape Regrouper les opposés
$13{,}6$ et $-13{,}6$ sont opposés ; $-8$ et $+8$ aussi : leurs sommes sont nulles.
$$
\begin{aligned}
E &= (13{,}6 - 13{,}6) + (-8 + 8) + 5 - 11 \\
&= 0 + 0 + 5 - 11 \\
&= -6
\end{aligned}
$$
:::

::: resultat
$E = -6$.
:::

## Question 4 : L'erreur de Mila

::: etape Repérer l'erreur
Mila a remplacé $-(-5)$ par $-5$. Or soustraire $-5$, c'est ajouter son opposé $+5$ : $-(-5)$ s'écrit $+5$.
:::

::: etape Corriger
$$
\begin{aligned}
(-3) - (-5) &= -3 + 5 \\
&= 2
\end{aligned}
$$
:::

::: resultat
$(-3) - (-5) = 2$, et non $-8$.
:::

::: retenir
Écriture simplifiée : deux signes identiques donnent $+$ ($-(-5) = +5$), deux signes différents donnent $-$ ($+(-8) = -8$). Dans une somme algébrique, chaque terme garde son signe quand on le déplace.
:::

Solution:
<!-- optitab:1 -->
1. $A = 5 - 8 + 3 = 0$ ; $B = -4 - 6 - 2 + 9 = -3$ ; $C = 2{,}5 - 4 - 1{,}5 + 7 = 4$.
2. $D = 17 + (-19) = -2$.
3. $E = -6$.
4. $-(-5)$ devient $+5$ : $(-3) - (-5) = 2$.

=== Entraînement - Calculer avec des parenthèses
Id: 2780
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On calcule d'abord ce qui est entre parenthèses.

1. Calculer $F = 8 - (3 - 5)$.
2. Calculer $G = (-4 + 9) - (2 - 10)$.
3. Calculer $H = -6{,}5 + (1{,}5 - 4) - (-3)$.
4. On pose $K = 15 - 7 - 3$ et $L = 15 - (7 - 3)$.
   - a) Calculer $K$ et $L$.
   - b) Les résultats sont-ils égaux ? Que peut-on en conclure ?
5. Lucas a calculé $F$ ainsi : $8 - 3 - 5 = 0$. Expliquer son erreur.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $F = 8 - (3 - 5)$

::: methode
On calcule la parenthèse, puis on soustrait le résultat en ajoutant son opposé.
:::

::: etape La parenthèse
$3 - 5 = 3 + (-5) = -2$.
:::

::: etape Le calcul de $F$
$$
\begin{aligned}
F &= 8 - (-2) \\
&= 8 + 2 \\
&= 10
\end{aligned}
$$
:::

::: resultat
$F = 10$.
:::

## Question 2 : Calculer $G = (-4 + 9) - (2 - 10)$

::: etape Les deux parenthèses
$-4 + 9 = 5$ et $2 - 10 = -8$.
:::

::: etape Le calcul de $G$
$$
\begin{aligned}
G &= 5 - (-8) \\
&= 5 + 8 \\
&= 13
\end{aligned}
$$
:::

::: resultat
$G = 13$.
:::

## Question 3 : Calculer $H = -6{,}5 + (1{,}5 - 4) - (-3)$

::: etape La parenthèse
$1{,}5 - 4 = -2{,}5$ (signes contraires : $4 - 1{,}5 = 2{,}5$, et $-4$ l'emporte).
:::

::: etape Le calcul de $H$
$$
\begin{aligned}
H &= -6{,}5 + (-2{,}5) - (-3) \\
&= -6{,}5 - 2{,}5 + 3 \\
&= -9 + 3 \\
&= -6
\end{aligned}
$$
:::

::: resultat
$H = -6$.
:::

## Question 4 : Comparer $K$ et $L$

::: etape a) Les deux calculs
Sans parenthèses, on calcule de gauche à droite ; avec parenthèses, on commence par la parenthèse :
$$
\begin{aligned}
K &= 8 - 3 \\
&= 5
\end{aligned}
$$
$$
\begin{aligned}
L &= 15 - 4 \\
&= 11
\end{aligned}
$$
:::

::: resultat
b) $K = 5$ et $L = 11$ : les résultats sont différents. Dans une suite de soustractions, on ne peut pas ajouter des parenthèses n'importe où : cela change le résultat.
:::

## Question 5 : L'erreur de Lucas

::: etape Comparer avec le bon calcul
Lucas a enlevé les parenthèses sans rien changer. Il a donc soustrait $5$, alors que le nombre soustrait est la parenthèse entière, qui vaut $-2$.
:::

::: resultat
Il fallait calculer la parenthèse d'abord : $F = 8 - (-2) = 10$, et non $0$.
:::

::: attention Erreur fréquente
Une parenthèse précédée d'un signe $-$ ne se supprime pas sans précaution : on calcule d'abord ce qu'elle contient, puis on soustrait le résultat.
:::

Solution:
<!-- optitab:1 -->
1. $F = 8 - (-2) = 10$.
2. $G = 5 - (-8) = 13$.
3. $H = -6{,}5 + (-2{,}5) + 3 = -6$.
4. $K = 5$ et $L = 11$ : on ne peut pas ajouter de parenthèses librement.
5. Il a supprimé la parenthèse sans la calculer : $F = 10$.

=== Entraînement - Pyramides et termes manquants
Id: 2769
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Dans ces pyramides, le nombre écrit dans une case est la **somme** des nombres des deux cases situées juste en dessous.

[IMAGE_1]

1. Recopier et compléter la pyramide 1.
2. Recopier et compléter la pyramide 2. Expliquer comment trouver la case vide de la base.
3. Dans la pyramide 1, on remplace le $2$ de la base par $-2$. Calculer le nouveau nombre du sommet, puis la variation du sommet.
4. Compléter avec un nombre relatif :
   - a) $(-5) + \ldots = 2$ ;
   - b) $\ldots + (-8) = -3$ ;
   - c) $\ldots - 6 = -10$.

Étapes:
<!-- optitab:1 -->
## Question 1 : La pyramide 1

::: methode
On remonte étage par étage : chaque case est la somme des deux cases du dessous.
:::

::: etape Deuxième étage
- $(-3) + 5 = 2$
- $5 + (-8) = -3$
- $(-8) + 2 = -6$
:::

::: etape Troisième étage et sommet
- $2 + (-3) = -1$
- $(-3) + (-6) = -9$
- Sommet : $(-1) + (-9) = -10$
:::

::: resultat
Deuxième étage : $2$, $-3$, $-6$ ; troisième étage : $-1$, $-9$ ; sommet : $-10$.
:::

## Question 2 : La pyramide 2

::: methode
On connaît une somme et un de ses termes : le terme manquant est la **différence** entre la somme et le terme connu.
:::

::: etape La case vide de la base
On cherche le nombre qui, ajouté à $4$, donne $-2$ :
$$
\begin{aligned}
-2 - 4 &= -2 + (-4) \\
&= -6
\end{aligned}
$$
Vérification : $4 + (-6) = -2$.
:::

::: etape La suite de la pyramide
- Deuxième étage : $(-6) + (-7) = -13$
- Sommet : $(-2) + (-13) = -15$
:::

[IMAGE_2]

::: resultat
Base : $4$ ; $-6$ ; $-7$. Deuxième étage : $-2$ ; $-13$. Sommet : $-15$.
:::

## Question 3 : La pyramide 1 modifiée

::: etape Recalculer les cases qui changent
- Deuxième étage : $(-8) + (-2) = -10$ (les cases $2$ et $-3$ ne changent pas).
- Troisième étage : $(-3) + (-10) = -13$ (la case $-1$ ne change pas).
- Sommet : $(-1) + (-13) = -14$.
:::

[IMAGE_3]

::: etape La variation du sommet
$$
\begin{aligned}
-14 - (-10) &= -14 + 10 \\
&= -4
\end{aligned}
$$
:::

::: resultat
Le nouveau sommet vaut $-14$ : il a diminué de $4$ (variation $-4$).
:::

## Question 4 : Les termes manquants

::: etape a) $(-5) + \ldots = 2$
Le terme manquant est $2 - (-5) = 2 + 5 = 7$. Vérification : $(-5) + 7 = 2$.
:::

::: etape b) $\ldots + (-8) = -3$
Le terme manquant est $-3 - (-8) = -3 + 8 = 5$. Vérification : $5 + (-8) = -3$.
:::

::: etape c) $\ldots - 6 = -10$
Soustraire $6$, c'est ajouter $-6$ : on cherche le nombre qui, ajouté à $-6$, donne $-10$. C'est $-10 - (-6) = -10 + 6 = -4$. Vérification : $-4 - 6 = -10$.
:::

::: resultat
a) $7$ ; b) $5$ ; c) $-4$.
:::

::: retenir
Pour trouver un terme manquant dans une somme, on soustrait le terme connu de la somme. On vérifie toujours en refaisant l'addition.
:::

Solution:
<!-- optitab:1 -->
1. $2$, $-3$, $-6$ ; $-1$, $-9$ ; sommet $-10$.
2. Case de la base : $-2 - 4 = -6$ ; puis $-13$ ; sommet $-15$.
3. Nouveau sommet $-14$ : variation $-4$.
4. a) $7$ ; b) $5$ ; c) $-4$.

=== Problème - La plongée du sous-marin
Id: 2787
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
L'altitude $0$ correspond au niveau de la mer. Un sous-marin d'exploration se trouve à l'altitude $-15$ m. Il descend de $12$ m, remonte de $7$ m, puis descend de $18$ m. Pendant ce temps, un goéland vole à l'altitude $8$ m, juste au-dessus du sous-marin.

[IMAGE_1]

1. Traduire chacun des trois déplacements du sous-marin par un nombre relatif.
2. Calculer l'altitude du sous-marin après chaque déplacement.
3. Calculer de deux façons la variation d'altitude du sous-marin entre le départ et la fin.
4. Quelle distance verticale le sous-marin a-t-il parcourue en tout ? Pourquoi ce nombre est-il différent de la réponse à la question 3 ?
5. À la fin, quel est l'écart d'altitude entre le goéland et le sous-marin ?
6. Le sous-marin remonte ensuite à la surface. Quelle est la variation d'altitude de cette remontée ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Traduire les déplacements

::: methode
Une montée se traduit par un nombre positif, une descente par un nombre négatif.
:::

::: resultat
Descente de $12$ m : $-12$ ; remontée de $7$ m : $+7$ ; descente de $18$ m : $-18$.
:::

## Question 2 : Les altitudes successives

::: methode
Nouvelle altitude $=$ altitude précédente $+$ déplacement.
:::

::: etape Après chaque déplacement
$$
\begin{aligned}
(-15) + (-12) &= -27 \\
(-27) + (+7) &= -20 \\
(-20) + (-18) &= -38
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
Le sous-marin passe à $-27$ m, puis $-20$ m, puis $-38$ m.
:::

## Question 3 : La variation totale

::: etape Première façon : valeur finale moins valeur initiale
$$
\begin{aligned}
(-38) - (-15) &= -38 + 15 \\
&= -23
\end{aligned}
$$
:::

::: etape Deuxième façon : somme des déplacements
$$
\begin{aligned}
&(-12) + (+7) + (-18) \\
&= -12 + 7 - 18 \\
&= -5 - 18 \\
&= -23
\end{aligned}
$$
:::

::: resultat
La variation d'altitude vaut $-23$ m : le sous-marin est $23$ m plus bas qu'au départ.
:::

## Question 4 : La distance parcourue

::: etape Ajouter les longueurs des trajets
Chaque trajet compte pour sa longueur, qu'il monte ou qu'il descende :
$$12 + 7 + 18 = 37$$
:::

::: resultat
Le sous-marin a parcouru $37$ m à la verticale. La variation ($-23$ m) ne compte que la différence entre l'arrivée et le départ : la remontée de $7$ m « annule » une partie des descentes, alors qu'elle s'ajoute à la distance parcourue.
:::

## Question 5 : L'écart avec le goéland

::: methode
Écart $=$ plus grande altitude $-$ plus petite altitude.
:::

::: etape Calculer
$$
\begin{aligned}
8 - (-38) &= 8 + 38 \\
&= 46
\end{aligned}
$$
:::

::: resultat
Le goéland est $46$ m au-dessus du sous-marin.
:::

## Question 6 : La remontée à la surface

::: etape Calculer la variation
La surface est à l'altitude $0$ :
$$
\begin{aligned}
0 - (-38) &= 0 + 38 \\
&= 38
\end{aligned}
$$
:::

::: resultat
La variation est de $+38$ m : le sous-marin doit monter de $38$ m.
:::

::: attention Erreur fréquente
Ne pas confondre l'altitude ($-38$ m), la variation ($-23$ m) et la distance parcourue ($37$ m) : ce sont trois réponses différentes.
:::

Solution:
<!-- optitab:1 -->
1. $-12$ ; $+7$ ; $-18$.
2. $-27$ m ; $-20$ m ; $-38$ m.
3. $(-38) - (-15) = -23$ et $-12 + 7 - 18 = -23$ : variation de $-23$ m.
4. $37$ m : la distance compte chaque trajet, montée ou descente.
5. $8 - (-38) = 46$ m.
6. $0 - (-38) = +38$ m.

=== Problème - Le compte du club de théâtre
Id: 2786
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Le 1er mars, le compte du club de théâtre présente un solde de $-12{,}50$ € : le club doit de l'argent à la banque. Voici les opérations du mois.

| Date | Opération | Montant |
|---|---|---|
| 3 mars | versement des cotisations | $18{,}75$ € |
| 5 mars | achat de maquillage | $9{,}40$ € |
| 9 mars | location de costumes | $14{,}60$ € |
| 12 mars | vente de gâteaux | $6{,}25$ € |

1. Traduire chaque opération par un nombre relatif.
2. Calculer le solde du compte après chaque opération.
3. À quelle date le solde a-t-il été le plus bas ?
4. Calculer la variation du solde entre le 1er mars et le 12 mars. Vérifier le résultat avec les opérations.
5. Quel versement minimal faudrait-il faire le 12 mars pour que le solde ne soit plus négatif ?
6. La trésorière souhaite un solde de $20$ € pour le spectacle. Quel versement doit-elle faire le 12 mars ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Traduire les opérations

::: methode
Ce qui entre sur le compte est positif ; ce qui en sort est négatif.
:::

::: resultat
$+18{,}75$ ; $-9{,}40$ ; $-14{,}60$ ; $+6{,}25$.
:::

## Question 2 : Les soldes successifs

::: methode
Nouveau solde $=$ ancien solde $+$ opération.
:::

::: etape Les 3 et 5 mars
$$
\begin{aligned}
(-12{,}50) + (+18{,}75) &= 6{,}25 \\
6{,}25 + (-9{,}40) &= -3{,}15
\end{aligned}
$$
:::

::: etape Les 9 et 12 mars
$$
\begin{aligned}
(-3{,}15) + (-14{,}60) &= -17{,}75 \\
(-17{,}75) + (+6{,}25) &= -11{,}50
\end{aligned}
$$
:::

::: resultat
| Date | Solde (€) |
|---|---|
| 3 mars | $6{,}25$ |
| 5 mars | $-3{,}15$ |
| 9 mars | $-17{,}75$ |
| 12 mars | $-11{,}50$ |
:::

## Question 3 : Le solde le plus bas

::: etape Comparer les soldes
Parmi des nombres négatifs, le plus petit est le plus éloigné de zéro. On range les soldes négatifs :
$$-17{,}75 < -12{,}50 < -11{,}50 < -3{,}15$$
:::

::: resultat
Le solde a été le plus bas le 9 mars : $-17{,}75$ €.
:::

## Question 4 : La variation du solde

::: etape Valeur finale moins valeur initiale
$$
\begin{aligned}
&(-11{,}50) - (-12{,}50) \\
&= -11{,}50 + 12{,}50 \\
&= 1
\end{aligned}
$$
:::

::: etape Vérifier avec les opérations
La variation est aussi la somme des quatre opérations : $18{,}75 - 9{,}40 - 14{,}60 + 6{,}25$.
- Ce qui entre : $18{,}75 + 6{,}25 = 25$.
- Ce qui sort : $9{,}40 + 14{,}60 = 24$.

Au total : $25 - 24 = 1$.
:::

::: resultat
La variation vaut $+1$ € : en un mois, le solde a augmenté de $1$ €.
:::

## Question 5 : Le versement minimal

::: etape Revenir à zéro
Pour passer de $-11{,}50$ à $0$, la variation nécessaire est $0 - (-11{,}50) = 11{,}50$.
:::

::: resultat
Il faut verser au moins $11{,}50$ €.
:::

## Question 6 : Atteindre un solde de 20 €

::: etape Calculer la variation nécessaire
$$
\begin{aligned}
20 - (-11{,}50) &= 20 + 11{,}50 \\
&= 31{,}50
\end{aligned}
$$
Vérification : $-11{,}50 + 31{,}50 = 20$.
:::

::: resultat
La trésorière doit verser $31{,}50$ €.
:::

::: attention Erreur fréquente
Calculer $20 - 11{,}50 = 8{,}50$ € est faux : $8{,}50$ € ne ferait que rapprocher le solde de zéro, jusqu'à $-3$ €. Il faut d'abord combler la dette de $11{,}50$ €, puis ajouter $20$ €.
:::

Solution:
<!-- optitab:1 -->
1. $+18{,}75$ ; $-9{,}40$ ; $-14{,}60$ ; $+6{,}25$.
2. $6{,}25$ € ; $-3{,}15$ € ; $-17{,}75$ € ; $-11{,}50$ €.
3. Le 9 mars ($-17{,}75$ €).
4. $+1$ €.
5. $11{,}50$ €.
6. $31{,}50$ €.

=== Synthèse - Une semaine à la station de ski
Id: 2770
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une station de ski relève chaque jour la température minimale et la température maximale (en °C).

| Jour | Minimale | Maximale |
|---|---|---|
| lundi | $-8$ | $3$ |
| mardi | $-11{,}5$ | $-1$ |
| mercredi | $-5$ | $4{,}5$ |
| jeudi | $-2{,}5$ | $6$ |
| vendredi | ? | $2$ |

La température minimale de vendredi est indiquée par le thermomètre ci-dessous.

[IMAGE_1]

1. Lire la température minimale de vendredi.
2. L'**amplitude** d'une journée est l'écart entre sa maximale et sa minimale. Calculer l'amplitude de chaque jour.
3. Quel jour la température a-t-elle le plus varié ?
4. Calculer la variation de la température minimale entre lundi et mardi, puis entre mardi et mercredi.
5. Un skieur affirme : « Mardi, il a gelé toute la journée. » A-t-il raison ? Justifier. (L'eau gèle en dessous de $0$ °C.)
6. Samedi, la minimale est $4{,}5$ °C plus basse que celle de vendredi et l'amplitude est de $9$ °C. Calculer la minimale et la maximale de samedi.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire le thermomètre

::: etape Lire les graduations
Chaque graduation vaut $1$ °C. Le niveau est sous le $0$ et arrive exactement sur la graduation $-6$.
:::

::: resultat
La minimale de vendredi est $-6$ °C.
:::

## Question 2 : Les amplitudes

::: methode
Amplitude $=$ maximale $-$ minimale. C'est un écart : elle est toujours positive.
:::

::: etape Lundi, mardi, mercredi
$$
\begin{aligned}
3 - (-8) &= 3 + 8 = 11 \\
-1 - (-11{,}5) &= -1 + 11{,}5 = 10{,}5 \\
4{,}5 - (-5) &= 4{,}5 + 5 = 9{,}5
\end{aligned}
$$
:::

::: etape Jeudi, vendredi
$$
\begin{aligned}
6 - (-2{,}5) &= 6 + 2{,}5 = 8{,}5 \\
2 - (-6) &= 2 + 6 = 8
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
| Jour | Amplitude (°C) |
|---|---|
| lundi | $11$ |
| mardi | $10{,}5$ |
| mercredi | $9{,}5$ |
| jeudi | $8{,}5$ |
| vendredi | $8$ |
:::

## Question 3 : Le jour qui a le plus varié

::: resultat
C'est **lundi**, avec la plus grande amplitude : $11$ °C.
:::

## Question 4 : Les variations de la minimale

::: methode
Variation $=$ valeur finale $-$ valeur initiale.
:::

::: etape De lundi à mardi
$$
\begin{aligned}
-11{,}5 - (-8) &= -11{,}5 + 8 \\
&= -3{,}5
\end{aligned}
$$
:::

::: etape De mardi à mercredi
$$
\begin{aligned}
-5 - (-11{,}5) &= -5 + 11{,}5 \\
&= 6{,}5
\end{aligned}
$$
:::

::: resultat
La minimale a baissé de $3{,}5$ °C (variation $-3{,}5$ °C), puis a augmenté de $6{,}5$ °C (variation $+6{,}5$ °C).
:::

## Question 5 : A-t-il gelé toute la journée mardi ?

::: etape Regarder la maximale
Mardi, la température la plus haute est $-1$ °C. Toutes les températures de la journée sont entre $-11{,}5$ °C et $-1$ °C : elles sont toutes négatives.
:::

::: resultat
Le skieur a raison : la température est restée en dessous de $0$ °C toute la journée.
:::

## Question 6 : Les températures de samedi

::: etape La minimale de samedi
« $4{,}5$ °C plus basse » correspond à une variation de $-4{,}5$ :
$$
\begin{aligned}
-6 + (-4{,}5) &= -10{,}5
\end{aligned}
$$
:::

::: etape La maximale de samedi
La maximale est $9$ °C au-dessus de la minimale :
$$
\begin{aligned}
-10{,}5 + 9 &= -1{,}5
\end{aligned}
$$
Vérification : $-1{,}5 - (-10{,}5) = -1{,}5 + 10{,}5 = 9$.
:::

::: resultat
Samedi : minimale $-10{,}5$ °C, maximale $-1{,}5$ °C.
:::

::: attention Erreur fréquente
Pour une amplitude, on soustrait **la minimale** : $2 - (-6) = 8$, et non $2 - 6 = -4$. Une amplitude négative est forcément fausse.
:::

Solution:
<!-- optitab:1 -->
1. $-6$ °C.
2. $11$ ; $10{,}5$ ; $9{,}5$ ; $8{,}5$ ; $8$ (en °C).
3. Lundi ($11$ °C).
4. $-3{,}5$ °C puis $+6{,}5$ °C.
5. Oui : la maximale de mardi est $-1$ °C, donc toutes les températures sont négatives.
6. Minimale $-10{,}5$ °C ; maximale $-1{,}5$ °C.

=== Synthèse - Le jeu de la piste graduée
Id: 2771
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Anaïs et Bastien jouent sur une piste graduée. Chaque pion part de la case $0$. À chaque tour, le joueur tire une carte : une carte positive fait avancer le pion vers la droite, une carte négative le fait reculer vers la gauche. Après quatre cartes, le gagnant est celui dont le pion est **le plus proche de la case $0$**.

[IMAGE_1]

- Cartes d'Anaïs, dans l'ordre : $+4$ ; $-7$ ; $-2$ ; $+6$.
- Cartes de Bastien, dans l'ordre : $-3$ ; $+5$ ; $-8$ ; une quatrième carte cachée.

1. Donner les cases successives du pion d'Anaïs.
2. Écrire une somme qui donne la case de Bastien après trois cartes, puis la calculer.
3. Le pion de Bastien termine sur la case $-2$. Quelle est sa quatrième carte ?
4. Quelle est la distance entre les deux pions à la fin de la partie ?
5. Qui a gagné ? Justifier.
6. Anaïs affirme : « Si j'avais tiré mes quatre cartes dans un autre ordre, mon pion serait arrivé sur la même case. » A-t-elle raison ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le parcours d'Anaïs

::: methode
Nouvelle case $=$ case précédente $+$ carte tirée.
:::

::: etape Les quatre déplacements
$$
\begin{aligned}
0 + (+4) &= 4 \\
4 + (-7) &= -3 \\
(-3) + (-2) &= -5 \\
(-5) + (+6) &= 1
\end{aligned}
$$
:::

::: resultat
Le pion d'Anaïs passe par les cases $4$, $-3$, $-5$, puis termine sur la case $1$.
:::

## Question 2 : Bastien après trois cartes

::: etape Écrire et calculer la somme
$$
\begin{aligned}
(-3) + (+5) + (-8) &= -3 + 5 - 8 \\
&= 2 - 8 \\
&= -6
\end{aligned}
$$
:::

::: resultat
Après trois cartes, le pion de Bastien est sur la case $-6$.
:::

## Question 3 : La carte cachée

::: methode
On cherche le terme manquant de $-6 + \ldots = -2$ : c'est la différence entre la case d'arrivée et la case de départ.
:::

::: etape Calculer
$$
\begin{aligned}
-2 - (-6) &= -2 + 6 \\
&= 4
\end{aligned}
$$
Vérification : $-6 + 4 = -2$.
:::

[IMAGE_2]

::: resultat
La quatrième carte de Bastien est $+4$.
:::

## Question 4 : La distance entre les pions

::: methode
La distance entre deux cases est l'écart entre leurs nombres : le plus grand moins le plus petit.
:::

::: etape Calculer
$$
\begin{aligned}
1 - (-2) &= 1 + 2 \\
&= 3
\end{aligned}
$$
:::

::: resultat
Les deux pions sont à $3$ cases l'un de l'autre.
:::

## Question 5 : Le gagnant

::: etape Comparer les distances à zéro
Le pion d'Anaïs est sur la case $1$ : il est à $1$ case de $0$. Le pion de Bastien est sur la case $-2$ : il est à $2$ cases de $0$.
:::

::: resultat
Anaïs a gagné, car $1 < 2$ : son pion est plus proche de la case $0$.
:::

## Question 6 : L'ordre des cartes

::: etape Écrire la case d'arrivée comme une somme
La case d'arrivée d'Anaïs est la somme $0 + 4 - 7 - 2 + 6$. Dans une somme, on peut changer l'ordre des termes, chacun gardant son signe :
$$
\begin{aligned}
-7 - 2 + 4 + 6 &= -9 + 10 \\
&= 1
\end{aligned}
$$
:::

::: resultat
Anaïs a raison : quel que soit l'ordre des cartes, la case d'arrivée est la somme des quatre cartes, $1$.
:::

::: retenir
Une suite de déplacements se calcule par une somme algébrique ; la case d'arrivée ne dépend pas de l'ordre des déplacements, mais seulement de leur somme.
:::

Solution:
<!-- optitab:1 -->
1. $4$ ; $-3$ ; $-5$ ; $1$.
2. $(-3) + (+5) + (-8) = -6$.
3. $-2 - (-6) = +4$.
4. $1 - (-2) = 3$ cases.
5. Anaïs (distance $1$ à zéro, contre $2$ pour Bastien).
6. Oui : la case d'arrivée est la somme des cartes, qui ne dépend pas de l'ordre.
