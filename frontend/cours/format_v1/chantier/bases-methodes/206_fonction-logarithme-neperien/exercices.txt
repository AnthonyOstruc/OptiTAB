=== Découverte - Fonction Logarithme - Calculs avec Puissances et Racines
Id: 1613
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Calculer les valeurs exactes des expressions logarithmiques suivantes.

1. Calculer $\displaystyle \ln(\sqrt{e})$
2. Calculer $\displaystyle \ln(e^5)$
3. Calculer $\displaystyle \ln\left(\frac{1}{e^2}\right)$
4. Calculer $\displaystyle \ln(\sqrt[3]{e})$
5. Calculer $\displaystyle \ln(e^{2x-1})$ pour $\displaystyle x = 3$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle \ln(\sqrt{e})$

::: methode
Utilisation des propriétés de puissance et de racine
:::

::: etape Exprimer la racine carrée comme une puissance
- $\displaystyle \sqrt{e} = e^{1/2}$
:::

::: etape Appliquer la propriété $\displaystyle \ln(e^x) = x$
- $\displaystyle \ln(\sqrt{e}) = \ln(e^{1/2}) = \frac{1}{2}$
:::

::: resultat
$$\ln(\sqrt{e}) = \frac{1}{2}$$
:::

## Question 2 : Calculer $\displaystyle \ln(e^5)$

::: methode
Application directe de la propriété fondamentale
:::

::: etape Appliquer la propriété $\displaystyle \ln(e^x) = x$
- $\displaystyle \ln(e^5) = 5$
:::

::: resultat
$$\ln(e^5) = 5$$
:::

## Question 3 : Calculer $\displaystyle \ln\left(\frac{1}{e^2}\right)$

::: methode
Utilisation des propriétés de puissance et de quotient
:::

::: etape Appliquer la propriété du quotient
$$
\begin{aligned}
\ln\left(\frac{1}{e^2}\right) &= \ln(1) - \ln(e^2) \\
&= 0 - \ln(e^2) \\
&= -\ln(e^2)
\end{aligned}
$$
:::

::: etape Simplifier $\displaystyle \ln(e^2)$
- $\ln(e^2) = 2$, donc $-\ln(e^2) = -2$
:::

::: resultat
$$\ln\left(\frac{1}{e^2}\right) = -2$$
:::

## Question 4 : Calculer $\displaystyle \ln(\sqrt[3]{e})$

::: methode
Utilisation des propriétés de racine cubique
:::

::: etape Exprimer la racine cubique comme une puissance
- $\displaystyle \sqrt[3]{e} = e^{1/3}$
:::

::: etape Appliquer la propriété $\displaystyle \ln(e^x) = x$
- $\displaystyle \ln(\sqrt[3]{e}) = \ln(e^{1/3}) = \frac{1}{3}$
:::

::: resultat
$$\ln(\sqrt[3]{e}) = \frac{1}{3}$$
:::

## Question 5 : Calculer $\displaystyle \ln(e^{2x-1})$ pour $\displaystyle x = 3$

::: methode
Substitution et application des propriétés
:::

::: etape Remplacer $x$ par $3$
$$
\begin{aligned}
\ln(e^{2x-1}) &= \ln(e^{2(3)-1}) \\
&= \ln(e^{6-1}) \\
&= \ln(e^5)
\end{aligned}
$$
:::

::: etape Appliquer la propriété $\displaystyle \ln(e^x) = x$
- $\displaystyle \ln(e^5) = 5$
:::

::: resultat
$\ln(e^{2x-1}) = 5$ pour $x = 3$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \ln(\sqrt{e}) = \frac{1}{2}$
2. $\displaystyle \ln(e^5) = 5$
3. $\displaystyle \ln\left(\frac{1}{e^2}\right) = -2$
4. $\displaystyle \ln(\sqrt[3]{e}) = \frac{1}{3}$
5. $\ln(e^{2x-1}) = 5$ pour $x = 3$

=== Découverte - Fonction Logarithme - Propriétés Algébriques et Calculs
Id: 1612
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions logarithmiques suivantes en utilisant les propriétés du logarithme népérien.

1. Simplifier $\displaystyle \ln(8) + \ln(2)$
2. Simplifier $\displaystyle \ln(27) - \ln(3)$
3. Simplifier $\displaystyle 2\ln(5) + 3\ln(2)$
4. Simplifier $\displaystyle \ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right)$
5. Simplifier $\displaystyle \ln(e^3) + \ln(e^{-2}) - \ln(e)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \ln(8) + \ln(2)$

::: methode
Utilisation de la propriété du produit
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) + \ln(b) = \ln(ab)$
- $\displaystyle \ln(8) + \ln(2) = \ln(8 \times 2) = \ln(16)$
:::

::: etape Simplifier $\displaystyle \ln(16)$
- $16 = 2^4$, donc $\ln(16) = \ln(2^4) = 4\ln(2)$
:::

::: resultat
$$\ln(8) + \ln(2) = 4\ln(2)$$
:::

## Question 2 : Simplifier $\displaystyle \ln(27) - \ln(3)$

::: methode
Utilisation de la propriété du quotient
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) - \ln(b) = \ln\left(\frac{a}{b}\right)$
$$
\begin{aligned}
\ln(27) - \ln(3) &= \ln\left(\frac{27}{3}\right) \\
&= \ln(9)
\end{aligned}
$$
:::

::: etape Simplifier $\displaystyle \ln(9)$
- $9 = 3^2$, donc $\ln(9) = \ln(3^2) = 2\ln(3)$
:::

::: resultat
$$\ln(27) - \ln(3) = 2\ln(3)$$
:::

## Question 3 : Simplifier $\displaystyle 2\ln(5) + 3\ln(2)$

::: methode
Utilisation des propriétés de puissance et de produit
:::

::: etape Appliquer la propriété $\displaystyle k\ln(a) = \ln(a^k)$
- $\displaystyle 2\ln(5) = \ln(5^2) = \ln(25)$
- $\displaystyle 3\ln(2) = \ln(2^3) = \ln(8)$
:::

::: etape Appliquer la propriété du produit
- $\displaystyle \ln(25) + \ln(8) = \ln(25 \times 8) = \ln(200)$
:::

::: resultat
$$2\ln(5) + 3\ln(2) = \ln(200)$$
:::

## Question 4 : Simplifier $\displaystyle \ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right)$

::: methode
Utilisation de la propriété du produit
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) + \ln(b) = \ln(ab)$
- $\displaystyle \ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right) = \ln\left(\frac{16}{9} \times \frac{3}{4}\right)$
:::

::: etape Simplifier le produit
$$
\begin{aligned}
\frac{16}{9} \times \frac{3}{4} &= \frac{16 \times 3}{9 \times 4} \\
&= \frac{48}{36} \\
&= \frac{4}{3}
\end{aligned}
$$
:::

::: resultat
$$\ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right) = \ln\left(\frac{4}{3}\right)$$
:::

## Question 5 : Simplifier $\displaystyle \ln(e^3) + \ln(e^{-2}) - \ln(e)$

::: methode
Utilisation des propriétés de l'exponentielle et du logarithme
:::

::: etape Simplifier chaque terme
- $\ln(e^3) = 3$ (car $\ln(e^x) = x$)
- $\displaystyle \ln(e^{-2}) = -2$
- $\displaystyle \ln(e) = 1$
:::

::: etape Calculer l'expression
- $\displaystyle 3 + (-2) - 1 = 3 - 2 - 1 = 0$
:::

::: resultat
$$\ln(e^3) + \ln(e^{-2}) - \ln(e) = 0$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \ln(8) + \ln(2) = 4\ln(2)$
2. $\displaystyle \ln(27) - \ln(3) = 2\ln(3)$
3. $\displaystyle 2\ln(5) + 3\ln(2) = \ln(200)$
4. $\displaystyle \ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right) = \ln\left(\frac{4}{3}\right)$
5. $\displaystyle \ln(e^3) + \ln(e^{-2}) - \ln(e) = 0$

=== Entraînement - Fonction Logarithme - Dérivées et Calculs
Id: 1614
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer les dérivées des fonctions suivantes.

1. Dériver $\displaystyle f(x) = \ln(3x + 1)$
2. Dériver $\displaystyle g(x) = \ln(x^2 - 4)$
3. Dériver $\displaystyle h(x) = x^2 \ln(x)$
4. Dériver $\displaystyle k(x) = \frac{\ln(x)}{x}$
5. Dériver $\displaystyle m(x) = \ln(\sqrt{x^2 + 1})$

Étapes:
<!-- optitab:1 -->
## Question 1 : Dériver $\displaystyle f(x) = \ln(3x + 1)$

::: methode
Dérivée d'une fonction composée
:::

::: point Domaine de définition
$3x + 1 > 0 \Leftrightarrow x > -\frac{1}{3}$, donc $D_f = \left]-\frac{1}{3}, +\infty\right[$
:::

::: etape Identifier la fonction composée
- $f(x) = \ln(u(x))$ avec $u(x) = 3x + 1$
:::

::: etape Calculer $\displaystyle u'(x)$
- $\displaystyle u'(x) = 3$
:::

::: etape Appliquer la formule $\displaystyle (\ln(u))' = \frac{u'}{u}$
- $\displaystyle f'(x) = \frac{3}{3x + 1}$
:::

::: resultat
$$f'(x) = \frac{3}{3x + 1}$$
:::

## Question 2 : Dériver $\displaystyle g(x) = \ln(x^2 - 4)$

::: methode
Dérivée d'une fonction composée
:::

::: point Domaine de définition
$x^2 - 4 > 0 \Leftrightarrow (x-2)(x+2) > 0$, donc $D_g = ]-\infty, -2[ \cup ]2, +\infty[$
:::

::: etape Identifier la fonction composée
- $g(x) = \ln(u(x))$ avec $u(x) = x^2 - 4$
:::

::: etape Calculer $\displaystyle u'(x)$
- $\displaystyle u'(x) = 2x$
:::

::: etape Appliquer la formule $\displaystyle (\ln(u))' = \frac{u'}{u}$
- $\displaystyle g'(x) = \frac{2x}{x^2 - 4}$
:::

::: resultat
$$g'(x) = \frac{2x}{x^2 - 4}$$
:::

## Question 3 : Dériver $\displaystyle h(x) = x^2 \ln(x)$

::: methode
Dérivée d'un produit
:::

::: point Domaine de définition
$x > 0$ (nécessaire pour $\ln(x)$), donc $D_h = ]0, +\infty[$
:::

::: etape Identifier les fonctions du produit
- $h(x) = u(x) \times v(x)$ avec $u(x) = x^2$ et $v(x) = \ln(x)$
:::

::: etape Calculer les dérivées
- $u'(x) = 2x$ et $v'(x) = \frac{1}{x}$
:::

::: etape Appliquer la formule du produit $(uv)' = u'v + uv'$
$$
\begin{aligned}
h'(x) &= 2x \times \ln(x) + x^2 \times \frac{1}{x} \\
&= 2x\ln(x) + x \\
&= x(2\ln(x) + 1)
\end{aligned}
$$
:::

::: resultat
$$h'(x) = x(2\ln(x) + 1)$$
:::

## Question 4 : Dériver $\displaystyle k(x) = \frac{\ln(x)}{x}$

::: methode
Dérivée d'un quotient
:::

::: point Domaine de définition
$x > 0$ (nécessaire pour $\ln(x)$) et $x \neq 0$, donc $D_k = ]0, +\infty[$
:::

::: etape Identifier les fonctions du quotient
- $k(x) = \frac{u(x)}{v(x)}$ avec $u(x) = \ln(x)$ et $v(x) = x$
:::

::: etape Calculer les dérivées
- $u'(x) = \frac{1}{x}$ et $v'(x) = 1$
:::

::: etape Appliquer la formule du quotient $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
$$
\begin{aligned}
k'(x) &= \frac{\frac{1}{x} \times x - \ln(x) \times 1}{x^2} \\
&= \frac{1 - \ln(x)}{x^2}
\end{aligned}
$$
:::

::: resultat
$$k'(x) = \frac{1 - \ln(x)}{x^2}$$
:::

## Question 5 : Dériver $\displaystyle m(x) = \ln(\sqrt{x^2 + 1})$

::: methode
Dérivée d'une fonction composée avec racine
:::

::: etape Simplifier l'expression
$$
\begin{aligned}
\ln(\sqrt{x^2 + 1}) &= \ln((x^2 + 1)^{1/2}) \\
&= \frac{1}{2}\ln(x^2 + 1)
\end{aligned}
$$
:::

::: etape Dériver $\displaystyle \frac{1}{2}\ln(x^2 + 1)$
$$
\begin{aligned}
m'(x) &= \frac{1}{2} \times \frac{2x}{x^2 + 1} \\
&= \frac{x}{x^2 + 1}
\end{aligned}
$$
:::

::: resultat
$$m'(x) = \frac{x}{x^2 + 1}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle f'(x) = \frac{3}{3x + 1}$
2. $\displaystyle g'(x) = \frac{2x}{x^2 - 4}$
3. $\displaystyle h'(x) = x(2\ln(x) + 1)$
4. $\displaystyle k'(x) = \frac{1 - \ln(x)}{x^2}$
5. $\displaystyle m'(x) = \frac{x}{x^2 + 1}$

=== Entraînement - Fonction Logarithme - Équations Logarithmiques

Difficulté: medium
Image: exercice_logarithme_equations_question1.png,exercice_logarithme_equations_question2.png,exercice_logarithme_equations_question3.png,exercice_logarithme_equations_question4.png,exercice_logarithme_equations_question5.png

Énoncé:
<!-- optitab:1 -->
Résoudre les équations logarithmiques suivantes.

1. Résoudre $\displaystyle \ln(x + 2) = \ln(3x - 1)$
2. Résoudre $\displaystyle \ln(x) = 2$
3. Résoudre $\displaystyle \ln(x^2 - 4) - \ln(x - 2) = 1$
4. Résoudre $\displaystyle \ln(x + 1) + \ln(x - 1) = \ln(8)$
5. Résoudre $\displaystyle 2\ln(x) = \ln(x^2 + 3)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle \ln(x + 2) = \ln(3x - 1)$

::: methode
Égalité de deux logarithmes
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) = \ln(b) \Leftrightarrow a = b$
$$
\begin{aligned}
\ln(x + 2) = \ln(3x - 1) &\Leftrightarrow x + 2 = 3x - 1
\end{aligned}
$$
:::

::: etape Résoudre l'équation
$$
\begin{aligned}
x + 2 = 3x - 1 &\Leftrightarrow 2 + 1 = 3x - x \\
&\Leftrightarrow 3 = 2x \\
&\Leftrightarrow x = \frac{3}{2}
\end{aligned}
$$
:::

::: etape Vérifier les conditions d'existence
- $x + 2 > 0 \Leftrightarrow x > -2$ et $3x - 1 > 0 \Leftrightarrow x > \frac{1}{3}$
- $\displaystyle x = \frac{3}{2} > \frac{1}{3}$
:::

::: resultat
$$S = \left\{\frac{3}{2}\right\}$$
:::

## Question 2 : Résoudre $\displaystyle \ln(x) = 2$

::: methode
Logarithme égal à un nombre
:::

::: etape Appliquer la propriété $\displaystyle \ln(x) = k \Leftrightarrow x = e^k$
- $\displaystyle \ln(x) = 2 \Leftrightarrow x = e^2$
:::

::: etape Vérifier la condition d'existence
- $\displaystyle x = e^2 > 0$
:::

::: resultat
$$S = \{e^2\}$$
:::

## Question 3 : Résoudre $\displaystyle \ln(x^2 - 4) - \ln(x - 2) = 1$

::: methode
Utilisation des propriétés des logarithmes
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) - \ln(b) = \ln\left(\frac{a}{b}\right)$
$$
\begin{aligned}
\ln(x^2 - 4) - \ln(x - 2) &= \ln\left(\frac{x^2 - 4}{x - 2}\right) \\
&= 1
\end{aligned}
$$
:::

::: etape Simplifier l'expression
- $\frac{x^2 - 4}{x - 2} = \frac{(x-2)(x+2)}{x-2} = x + 2$ (pour $x \neq 2$)

$$
\begin{aligned}
\ln(x + 2) = 1 &\Leftrightarrow x + 2 = e \\
&\Leftrightarrow x = e - 2
\end{aligned}
$$
:::

::: etape Vérifier les conditions d'existence
- **Conditions nécessaires :**
  - Pour $\ln(x^2 - 4)$ : il faut $x^2 - 4 > 0$ soit $(x-2)(x+2) > 0$
  - Donc $\displaystyle x 2$
  - Pour $\ln(x - 2)$ : il faut $x - 2 > 0$ soit $x > 2$
- **Condition finale :** Les deux logarithmes existent si et seulement si $x > 2$
- **Vérification de la solution :** $x = e - 2 \approx 0,718$
- Or $0,718 \not> 2$, donc la solution ne satisfait pas la condition d'existence
- **Conclusion :** Pas de solution valide
:::

::: resultat
$$S = \emptyset$$
:::

## Question 4 : Résoudre $\displaystyle \ln(x + 1) + \ln(x - 1) = \ln(8)$

::: methode
Utilisation de la propriété du produit
:::

::: etape Appliquer la propriété $\displaystyle \ln(a) + \ln(b) = \ln(ab)$
$$
\begin{aligned}
\ln(x + 1) + \ln(x - 1) &= \ln((x+1)(x-1)) \\
&= \ln(x^2 - 1) \\
&= \ln(8)
\end{aligned}
$$
:::

::: etape Résoudre l'équation
$$
\begin{aligned}
\ln(x^2 - 1) = \ln(8) &\Leftrightarrow x^2 - 1 = 8 \\
&\Leftrightarrow x^2 = 9 \\
&\Leftrightarrow x = \pm 3
\end{aligned}
$$
:::

::: etape Vérifier les conditions d'existence
- $x + 1 > 0$ et $x - 1 > 0$ donc $x > 1$
- $x = 3$ satisfait $x > 1$
- $x = -3$ ne satisfait pas $x > 1$
:::

::: resultat
$$S = \{3\}$$
:::

## Question 5 : Résoudre $\displaystyle 2\ln(x) = \ln(x^2 + 3)$

::: methode
Utilisation des propriétés de puissance
:::

::: etape Appliquer la propriété $\displaystyle k\ln(a) = \ln(a^k)$
- $\displaystyle 2\ln(x) = \ln(x^2)$
- $\displaystyle \ln(x^2) = \ln(x^2 + 3) \Leftrightarrow x^2 = x^2 + 3$
:::

::: etape Résoudre l'équation
- $\displaystyle x^2 = x^2 + 3 \Leftrightarrow 0 = 3$ (impossible)
:::

::: resultat
$$S = \emptyset$$
:::

[IMAGE_5]

Solution:

=== Entraînement - Fonction Logarithme - Inéquations Logarithmiques
Id: 1617
Difficulté: medium
Image: exercice_logarithme_inequations_question1.png,exercice_logarithme_inequations_question2.png,exercice_logarithme_inequations_question3.png,exercice_logarithme_inequations_question4.png,exercice_logarithme_inequations_question5.png

Énoncé:
<!-- optitab:1 -->
Résoudre les inéquations logarithmiques suivantes.

1. Résoudre $\displaystyle \ln(x + 1) < \ln(2x)$
2. Résoudre $\displaystyle \ln(x) \geq -1$
3. Résoudre $\displaystyle \ln(2x + 3) \leq 0$
4. Résoudre $\displaystyle \ln(x^2 - 1) > \ln(3)$
5. Résoudre $\displaystyle \ln(x) + \ln(x - 2) \leq \ln(8)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle \ln(x + 1) < \ln(2x)$

::: methode
Utilisation de la croissance du logarithme
:::

::: etape Conditions d'existence
- $x + 1 > 0 \Leftrightarrow x > -1$ et $2x > 0 \Leftrightarrow x > 0$
- Donc $\displaystyle x > 0$
:::

::: etape Appliquer la propriété de croissance
- $\ln(x + 1) < \ln(2x) \Leftrightarrow x + 1 < 2x$ (car $\ln$ est croissante)
- $\displaystyle x + 1 < 2x \Leftrightarrow 1 < x$
:::

::: etape Intersection des conditions
- $x > 0$ et $x > 1$, donc $x > 1$
:::

::: resultat
$$S = ]1, +\infty[$$
:::

[IMAGE_1]

## Question 2 : Résoudre $\displaystyle \ln(x) \geq -1$

::: methode
Application de la fonction exponentielle
:::

::: etape Condition d'existence
- $\displaystyle x > 0$
:::

::: etape Appliquer la fonction exponentielle (croissante)
$$
\begin{aligned}
\ln(x) \geq -1 &\Leftrightarrow x \geq e^{-1} = \frac{1}{e}
\end{aligned}
$$
:::

::: etape Intersection des conditions
- $x > 0$ et $x \geq \frac{1}{e}$, donc $x \geq \frac{1}{e}$
:::

::: resultat
$$S = \left[\frac{1}{e}, +\infty\right[$$
:::

[IMAGE_2]

## Question 3 : Résoudre $\displaystyle \ln(2x + 3) \leq 0$

::: methode
Application de la fonction exponentielle
:::

::: etape Condition d'existence
- $\displaystyle 2x + 3 > 0 \Leftrightarrow x > -\frac{3}{2}$
:::

::: etape Appliquer la fonction exponentielle
- $\displaystyle \ln(2x + 3) \leq 0 \Leftrightarrow 2x + 3 \leq e^0 = 1$

$$
\begin{aligned}
2x + 3 \leq 1 &\Leftrightarrow 2x \leq -2 \\
&\Leftrightarrow x \leq -1
\end{aligned}
$$
:::

::: etape Intersection des conditions
- $x > -\frac{3}{2}$ et $x \leq -1$, donc $x \in \left]-\frac{3}{2}, -1\right]$
:::

::: resultat
$$S = \left]-\frac{3}{2}, -1\right]$$
:::

[IMAGE_3]

## Question 4 : Résoudre $\displaystyle \ln(x^2 - 1) > \ln(3)$

::: methode
Utilisation de la croissance du logarithme
:::

::: etape Conditions d'existence
$$
\begin{aligned}
x^2 - 1 > 0 &\Leftrightarrow (x-1)(x+1) > 0 \\
&\Leftrightarrow x \in ]-\infty, -1[ \cup ]1, +\infty[
\end{aligned}
$$
:::

::: etape Appliquer la propriété de croissance
- $\displaystyle \ln(x^2 - 1) > \ln(3) \Leftrightarrow x^2 - 1 > 3$

$$
\begin{aligned}
x^2 - 1 > 3 &\Leftrightarrow x^2 > 4 \\
&\Leftrightarrow |x| > 2
\end{aligned}
$$
:::

::: point Tableau de signes
| $x$ | $-\infty$ | $-2$ | $-1$ | $1$ | $2$ | $+\infty$ |
| $x^2 - 1$ | $+$ | $+$ | $0$ | $-$ | $0$ | $+$ |
| $x^2 - 4$ | $+$ | $0$ | $-$ | $-$ | $0$ | $+$ |
:::

::: etape Intersection des conditions
- Domaine : $\displaystyle x \in ]-\infty, -1[ \cup ]1, +\infty[$
- Inéquation : $\displaystyle x^2 > 4 \Leftrightarrow x \in ]-\infty, -2[ \cup ]2, +\infty[$
- Intersection : $\displaystyle x \in ]-\infty, -2[ \cup ]2, +\infty[$
:::

::: resultat
$$S = ]-\infty, -2[ \cup ]2, +\infty[$$
:::

[IMAGE_4]

## Question 5 : Résoudre $\displaystyle \ln(x) + \ln(x - 2) \leq \ln(8)$

::: methode
Utilisation de la propriété du produit
:::

::: etape Conditions d'existence
- $x > 0$ et $x - 2 > 0 \Leftrightarrow x > 2$
:::

::: etape Appliquer la propriété du produit
- $\displaystyle \ln(x) + \ln(x - 2) = \ln(x(x-2)) = \ln(x^2 - 2x)$
- $\displaystyle \ln(x^2 - 2x) \leq \ln(8) \Leftrightarrow x^2 - 2x \leq 8$
:::

::: etape Résoudre l'inéquation
- $\displaystyle x^2 - 2x - 8 \leq 0$
- Racines : $x^2 - 2x - 8 = 0 \Leftrightarrow (x-4)(x+2) = 0 \Leftrightarrow x = 4$ ou $x = -2$
:::

::: point Tableau de signes de $\displaystyle x^2 - 2x - 8$

=== Entraînement - Fonction Logarithme - Limites et Continuité
Id: 1618
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer les limites suivantes.

1. Calculer $\displaystyle\lim_{x \to 0^+} x \ln(x)$
2. Calculer $\displaystyle\lim_{x \to +\infty} \frac{\ln(x)}{x}$
3. Calculer $\displaystyle\lim_{x \to 0} \frac{\ln(1 + x)}{x}$
4. Calculer $\displaystyle\lim_{x \to +\infty} \frac{x}{\ln(x)}$
5. Calculer $\displaystyle\lim_{x \to 1} \frac{\ln(x)}{x - 1}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle\lim_{x \to 0^+} x \ln(x)$

::: point Forme indéterminée
$$0 \times (-\infty)$$
:::

::: point Limite de référence
$$\lim_{x \to 0^+} x \ln(x) = 0$$
:::

## Question 2 : Calculer $\displaystyle\lim_{x \to +\infty} \frac{\ln(x)}{x}$

::: point Forme indéterminée
$$\frac{+\infty}{+\infty}$$
:::

::: point Croissance comparée
Le logarithme croît infiniment plus lentement que toute puissance positive

Pour tout $\alpha > 0$ : $\lim_{x \to +\infty} \frac{\ln(x)}{x^\alpha} = 0$
:::

::: point Application
Avec $\alpha = 1$ : $\lim_{x \to +\infty} \frac{\ln(x)}{x} = 0$
:::

## Question 3 : Calculer $\displaystyle\lim_{x \to 0} \frac{\ln(1 + x)}{x}$

::: point Forme indéterminée
$$\frac{0}{0}$$
:::

::: point Règle de l'Hôpital
$$
\begin{aligned}
\lim_{x \to 0} \frac{\ln(1 + x)}{x} &= \lim_{x \to 0} \frac{\frac{1}{1+x}}{1} \\
&= \frac{1}{1+0} \\
&= 1
\end{aligned}
$$
:::

## Question 4 : Calculer $\displaystyle\lim_{x \to +\infty} \frac{x}{\ln(x)}$

::: point Forme indéterminée
$$\frac{+\infty}{+\infty}$$
:::

::: point Croissance comparée
Toute puissance positive croît infiniment plus vite que le logarithme

Pour tout $\alpha > 0$ : $\lim_{x \to +\infty} \frac{x^\alpha}{\ln(x)} = +\infty$
:::

::: point Application
Avec $\alpha = 1$ : $\lim_{x \to +\infty} \frac{x}{\ln(x)} = +\infty$
:::

## Question 5 : Calculer $\displaystyle\lim_{x \to 1} \frac{\ln(x)}{x - 1}$

::: point Forme indéterminée
$$\frac{0}{0}$$
:::

::: point Changement de variable
Poser $h = x - 1$, alors $\frac{\ln(x)}{x - 1} = \frac{\ln(1 + h)}{h}$
:::

::: point Limite fondamentale
$$\lim_{h \to 0} \frac{\ln(1 + h)}{h} = 1$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle\lim_{x \to 0^+} x \ln(x) = 0$
2. $\displaystyle\lim_{x \to +\infty} \frac{\ln(x)}{x} = 0$
3. $\displaystyle\lim_{x \to 0} \frac{\ln(1 + x)}{x} = 1$
4. $\displaystyle\lim_{x \to +\infty} \frac{x}{\ln(x)} = +\infty$
5. $\displaystyle\lim_{x \to 1} \frac{\ln(x)}{x - 1} = 1$

=== Problème - Fonction Logarithme - Applications et Modélisation

Résoudre les problèmes d'application suivants.

1. Une population de bactéries suit la loi $P(t) = P_0 e^{kt}$. Si la population double en 3 heures et qu'on a $P_0 = 100$ bactéries au temps $t = 0$, combien de temps faut-il pour atteindre 10000 bactéries ?

5. L'intensité sonore $L$ (en décibels) est liée à l'intensité $I$ par la formule $L = 10 \ln\left(\frac{I}{I_0}\right)$ où $I_0$ est l'intensité de référence. Si $L = 80$ dB, exprimer $I$ en fonction de $I_0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Population de bactéries

::: etape Déterminer la constante $k$
- Condition : la population double en 3h

$$
\begin{aligned}
P(3) = 2P_0 &\Leftrightarrow P_0 e^{3k} = 2P_0 \\
&\Leftrightarrow e^{3k} = 2
\end{aligned}
$$

- $\displaystyle 3k = \ln(2) \Leftrightarrow k = \frac{\ln(2)}{3}$
:::

::: etape Résoudre $\displaystyle P(t) = 10000$
- $\displaystyle 100 e^{kt} = 10000 \Leftrightarrow e^{kt} = 100$

$$
\begin{aligned}
kt = \ln(100) &\Leftrightarrow t = \frac{\ln(100)}{k} = \frac{\ln(100)}{\frac{\ln(2)}{3}} = \frac{3\ln(100)}{\ln(2)}
\end{aligned}
$$

- $\displaystyle t = \frac{3 \times 4,605}{0,693} \approx 19,9$ heures
:::

::: resultat
Environ 20 heures
:::

## Question 2 : Capital et intérêts composés

::: etape Modèle mathématique
- Capital après $t$ ans : $C(t) = 1000 \times (1,05)^t$
- On cherche $t$ tel que $C(t) = 2000$
:::

::: etape Résoudre l'équation
$$
\begin{aligned}
1000 \times (1,05)^t = 2000 &\Leftrightarrow (1,05)^t = 2
\end{aligned}
$$

$$
\begin{aligned}
\ln((1,05)^t) = \ln(2) &\Leftrightarrow t \ln(1,05) = \ln(2)
\end{aligned}
$$

- $\displaystyle t = \frac{\ln(2)}{\ln(1,05)} \approx \frac{0,693}{0,049} \approx 14,2$ ans
:::

::: resultat
Environ 14,2 ans
:::

## Question 3 : Loi de refroidissement de Newton

::: etape Utiliser la condition $\displaystyle T(10) = 60$
- $\displaystyle 60 = 20 + (100 - 20)e^{-10k}$
- $\displaystyle 40 = 80e^{-10k}$
- $\displaystyle e^{-10k} = \frac{40}{80} = \frac{1}{2}$
:::

::: etape Résoudre pour $k$
- $\displaystyle -10k = \ln\left(\frac{1}{2}\right) = -\ln(2)$
- $k = \frac{\ln(2)}{10} \approx \frac{0,693}{10} \approx 0,0693$ min$^{-1}$
:::

::: resultat
$k = \frac{\ln(2)}{10} \approx 0,0693$ min$^{-1}$
:::

## Question 4 : Décroissance radioactive

::: etape Déterminer $\lambda$ avec la demi-vie
- Demi-vie = 30 ans signifie : $\displaystyle Q(30) = \frac{Q_0}{2}$

$$
\begin{aligned}
Q_0 e^{-30\lambda} = \frac{Q_0}{2} &\Leftrightarrow e^{-30\lambda} = \frac{1}{2}
\end{aligned}
$$

$$
\begin{aligned}
-30\lambda = \ln\left(\frac{1}{2}\right) = -\ln(2) &\Leftrightarrow \lambda = \frac{\ln(2)}{30}
\end{aligned}
$$
:::

::: etape Calculer la fraction après 100 ans
$$
\begin{aligned}
\frac{Q(100)}{Q_0} &= e^{-100\lambda} \\
&= e^{-100 \times \frac{\ln(2)}{30}} \\
&= e^{-\frac{100\ln(2)}{30}} \\
&= e^{-\frac{10\ln(2)}{3}} \\
&= e^{\ln(2^{-10/3})} \\
&= 2^{-10/3} \\
&= \frac{1}{2^{10/3}} \approx 0,099
\end{aligned}
$$

::: resultat
Environ 9,9% de l'élément reste (ou $\frac{1}{2^{10/3}}$)

## Question 5 : Intensité sonore

- $\displaystyle I = I_0 \times e^8$
:::

::: resultat
$I = I_0 e^8$ (environ $I_0 \times 2981$)
:::

Solution:

## Question 2 : Étudier $\displaystyle g(x) = x \ln(x)$

::: point Domaine de définition
- $x > 0$ (nécessaire pour $\ln(x)$)
- $\displaystyle D_g = ]0, +\infty[$
:::

::: point Dérivée
$$
\begin{aligned}

\begin{aligned}

## Question 4 : Étudier $\displaystyle k(x) = \frac{\ln(x)}{x^2}$

## Question 2 : Système d'équations logarithmiques

::: methode
Utilisation des propriétés des logarithmes puis résolution de système
:::

::: etape Transformer le système avec les propriétés
$$
\begin{aligned}
\ln(x) + \ln(y) = \ln(12) &\Leftrightarrow \ln(xy) = \ln(12) \\
&\Leftrightarrow xy = 12
\end{aligned}
$$

$$
\begin{aligned}
\ln(x) - \ln(y) = \ln(3) &\Leftrightarrow \ln\left(\frac{x}{y}\right) = \ln(3) \\
&\Leftrightarrow \frac{x}{y} = 3
\end{aligned}
$$
:::

::: etape Le système devient
$$\begin{cases} xy = 12 \\ \frac{x}{y} = 3 \end{cases}$$
:::

::: etape De la deuxième équation
$$x = 3y$$
:::

::: etape Substitution dans la première équation
- $\displaystyle (3y) \times y = 12$
- $\displaystyle 3y^2 = 12$
- $\displaystyle y^2 = 4$
- $\displaystyle y = \pm 2$
:::

::: etape Vérification des solutions
- Si $y = 2$ : $x = 3 \times 2 = 6$ (car $x, y > 0$)
- Si $y = -2$ : $x = 3 \times (-2) = -6$ (rejeté car $x, y$ doivent être $> 0$)
:::

::: resultat
$$(x, y) = (6, 2)$$
:::

## Question 3 : Inégalité $\displaystyle \ln(1 + x) \leq x$

::: methode
Étude de fonction auxiliaire
:::

::: etape Définir la fonction auxiliaire
- On pose $g(x) = x - \ln(1 + x)$ pour $x > -1$
- On veut montrer $g(x) \geq 0$ pour $x > -1$
:::

::: etape Calculer $\displaystyle g'(x)$
- $\displaystyle g'(x) = 1 - (\ln(1 + x))'$
- **Méthode :** $(\ln(u))' = \frac{u'}{u}$ avec $u = 1 + x$ donc $u' = 1$

$$
\begin{aligned}
g'(x) &= 1 - \frac{1}{1 + x} \\
&= \frac{1 + x - 1}{1 + x} \\
&= \frac{x}{1 + x}
\end{aligned}
$$
:::

::: point Tableau de signes de $\displaystyle g'(x) = \frac{x}{1 + x}$
::: tableau
x : -1, 0, +\infty
x : , -, z, +,
(1+x) : , +, , +,
g'(x) : , -, z, +,
:::
:::

::: etape Limite aux bornes du domaine
$$
\begin{aligned}
\lim_{x \to -1^+} g(x) &= \lim_{x \to -1^+} [x - \ln(1 + x)] \\
&= -1 - \ln(0^+) \\
&= -1 - (-\infty) \\
&= +\infty
\end{aligned}
$$

$$
\begin{aligned}
\lim_{x \to +\infty} g(x) &= \lim_{x \to +\infty} [x - \ln(1 + x)] \\
&= +\infty - \ln(+\infty) \\
&= +\infty
\end{aligned}
$$
:::

::: etape Tableau de variations de $g$
::: tableau
x : -1, 0, +\infty
g'(x) : , -, z, +,
g(x) : +/+\infty, -/0, +/+\infty
:::
:::

::: etape Conclusion
- $g$ admet un minimum global en $x = 0$ : $g(0) = 0$
- Donc $g(x) \geq 0$ pour tout $x > -1$
- D'où $\displaystyle x - \ln(1 + x) \geq 0 \Leftrightarrow \ln(1 + x) \leq x$
:::

## Question 4 : Limite $\displaystyle\lim_{x \to +\infty} \frac{\ln(x^2 + 1)}{x}$

::: methode
Croissance comparée
:::

::: etape Factoriser
$$
\begin{aligned}
\frac{\ln(x^2 + 1)}{x} &= \frac{\ln(x^2(1 + \frac{1}{x^2}))}{x} \\
&= \frac{\ln(x^2) + \ln(1 + \frac{1}{x^2})}{x}
\end{aligned}
$$
:::

::: etape Simplifier
- $\displaystyle \frac{2\ln(x) + \ln(1 + \frac{1}{x^2})}{x} = 2 \cdot \frac{\ln(x)}{x} + \frac{\ln(1 + \frac{1}{x^2})}{x}$
:::

::: etape Calculer les limites
- $\lim_{x \to +\infty} \frac{\ln(x)}{x} = 0$ (croissance comparée : $\ln$ croît moins vite que $x$)
- $\lim_{x \to +\infty} \frac{1}{x^2} = 0$, donc $\lim_{x \to +\infty} \ln(1 + \frac{1}{x^2}) = \ln(1) = 0$

$$
\begin{aligned}
\lim_{x \to +\infty} \frac{\ln(1 + \frac{1}{x^2})}{x} &= \frac{0}{+\infty} \\
&= 0
\end{aligned}
$$
:::

::: resultat
$$
\begin{aligned}
\lim_{x \to +\infty} \frac{\ln(x^2 + 1)}{x} &= 2 \times 0 + 0 \\
&= 0
\end{aligned}
$$
:::

## Question 5 : Déterminer les valeurs de $a$ pour lesquelles l'équation $\ln(x) = ax$ admet exactement une solution

::: methode
Étude de fonction auxiliaire
:::

::: etape Définir la fonction auxiliaire
- On pose $h(x) = \ln(x) - ax$ pour $x > 0$
- On cherche le nombre de solutions de $h(x) = 0$
:::

::: etape Calculer $\displaystyle h'(x)$
- $\displaystyle h'(x) = \frac{1}{x} - a = \frac{1 - ax}{x}$
:::

::: etape Analyser le cas $\displaystyle a \leq 0$
- Si $a \leq 0$ : $h'(x) = \frac{1 - ax}{x} > 0$ sur $]0, +\infty[$ (car $1 - ax \geq 1 > 0$)
- Donc $h$ est strictement croissante sur $]0, +\infty[$
- **Limites :** $\displaystyle\lim_{x \to 0^+} h(x) = \lim_{x \to 0^+} (\ln(x) - ax) = -\infty - 0 = -\infty$

et $\lim_{x \to +\infty} h(x) = +\infty$ (car $\ln$ tend vers $+\infty$)

- Par le **théorème des valeurs intermédiaires**, $h$ s'annule exactement une fois
- **Conclusion :** Une solution si $a \leq 0$
:::

::: etape Analyser le cas $\displaystyle a > 0$
$$
\begin{aligned}
h'(x) = 0 &\Leftrightarrow 1 - ax = 0 \\
&\Leftrightarrow x = \frac{1}{a}
\end{aligned}
$$

- Pour $0 0$, donc $h'(x) > 0$ (croissante)
- Pour $x > \frac{1}{a}$ : $1 - ax < 0$, donc $h'(x) < 0$ (décroissante)
- Donc $h$ admet un **maximum** en $x = \frac{1}{a}$
:::

::: point Tableau de signes de $h'(x) = \frac{1-ax}{x}$ (cas $a > 0$)
::: tableau
x : 0, \frac{1}{a}, +\infty
(1-ax) : , +, z, -,
x : , +, , +,
h'(x) : , +, z, -,
:::
:::

::: etape Valeur du maximum
$$
\begin{aligned}
h\left(\frac{1}{a}\right) &= \ln\left(\frac{1}{a}\right) - a \cdot \frac{1}{a} \\
&= \ln\left(\frac{1}{a}\right) - 1 \\
&= \ln(1) - \ln(a) - 1 \\
&= -\ln(a) - 1
\end{aligned}
$$
:::

::: point Limites (cas $\displaystyle a > 0$)
$$
\begin{aligned}
\lim_{x \to 0^+} h(x) &= \lim_{x \to 0^+} (\ln(x) - ax) \\
&= -\infty - 0 \\
&= -\infty
\end{aligned}
$$

- $\lim_{x \to +\infty} h(x) = \lim_{x \to +\infty} (\ln(x) - ax) = -\infty$ (croissance comparée : $ax$ l'emporte sur $\ln(x)$)
:::

::: point Tableau de variations de $h$ (cas $a > 0$)
::: tableau
x : 0, \frac{1}{a}, +\infty
h'(x) : , +, z, -,
h(x) : -/-\infty, +/-\ln(a)-1, -/-\infty
:::
:::

::: etape Condition pour une solution unique
- Pour qu'il y ait exactement une solution, il faut que $h\left(\frac{1}{a}\right) = 0$

$$
\begin{aligned}
-\ln(a) - 1 = 0 &\Leftrightarrow -\ln(a) = 1 \\
&\Leftrightarrow \ln(a) = -1 \\
&\Leftrightarrow a = e^{-1} = \frac{1}{e}
\end{aligned}
$$

- **Interprétation graphique :**
  - Si $-\ln(a) - 1 > 0$ (soit $a < \frac{1}{e}$) : le maximum est positif, donc **2 solutions** (TVI)
  - Si $-\ln(a) - 1 = 0$ (soit $a = \frac{1}{e}$) : le maximum touche l'axe, donc **1 solution**
  - Si $-\ln(a) - 1 \frac{1}{e}$) : le maximum est négatif, donc **0 solution**
:::

::: point Résultat final
Une solution exactement si $a \leq 0$ ou $a = \frac{1}{e}$
:::

[IMAGE_3]

Solution:
<!-- optitab:1 -->
1. $f$ décroissante sur $]-\infty, 1[$, croissante sur $]3, +\infty[$, asymptotes verticales en $x = 1$ et $x = 3$
2. $\displaystyle (x, y) = (6, 2)$
3. $\ln(1 + x) \leq x$ pour tout $x > -1$
4. $\displaystyle\lim_{x \to +\infty} \frac{\ln(x^2 + 1)}{x} = 0$
5. Une solution si $a \leq 0$ ou $a = \frac{1}{e}$

=== Problème - Fonction Logarithme - Problèmes de Synthèse 2

Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère la fonction $\displaystyle f(x) = \ln(x) - x + 2$ définie sur $\displaystyle ]0, +\infty[$.

1. Calculer la dérivée $\displaystyle f'(x)$ et étudier son signe
2. Dresser le tableau de variations de $f$ et déterminer ses extremums
3. Calculer les limites de $f$ en $0^+$ et $+\infty$
4. Déterminer le nombre de solutions de l'équation $\displaystyle \ln(x) = x - 2$
5. Résoudre l'inéquation $\displaystyle \ln(x) \geq x - 2$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer la dérivée $\displaystyle f'(x)$ et étudier son signe

::: methode
Dérivation et étude de signe
:::

::: point Calcul de la dérivée
$$f'(x) = \frac{1}{x} - 1 = \frac{1 - x}{x}$$
:::

::: point Étude du signe
$$
\begin{aligned}
f'(x) = 0 &\Leftrightarrow 1 - x = 0 \\
&\Leftrightarrow x = 1
\end{aligned}
$$

- Pour $0 0$ donc $f'(x) > 0$ (croissante)
- Pour $x > 1$ : $1 - x < 0$ donc $f'(x) < 0$ (décroissante)
:::

::: point Tableau de signes de $\displaystyle f'(x) = \frac{1-x}{x}$
::: tableau

(1-x) : , +, z, -,
x : , +, , +,

## Question 2 : Dresser le tableau de variations de $f$ et déterminer ses extremums

::: methode
Tableau de variations complet
:::

::: point Calcul de $\displaystyle f(1)$
$$f(1) = \ln(1) - 1 + 2 = 0 - 1 + 2 = 1$$
:::

::: point Tableau de variations

x : 0^+, 1, +\infty
f'(x) : , +, z, -,
f(x) : -/-\infty, +/1, -/-\infty

- $f$ est croissante sur $]0, 1]$
- $f$ est décroissante sur $[1, +\infty[$
- $f$ admet un **maximum** en $x = 1$ : $f(1) = 1$
:::

## Question 3 : Calculer les limites de $f$ en $0^+$ et $+\infty$

::: methode
Calcul de limites avec formes indéterminées
:::

::: point Limite en $0^+$
$\displaystyle\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} (\ln(x) - x + 2)$

- $\lim_{x \to 0^+} \ln(x) = -\infty$ et $\lim_{x \to 0^+} (-x + 2) = 2$
- Donc $\displaystyle\lim_{x \to 0^+} f(x) = -\infty$
:::

::: point Limite en $+\infty$
$\displaystyle\lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} (\ln(x) - x + 2)$

- $\lim_{x \to +\infty} \ln(x) = +\infty$ et $\lim_{x \to +\infty} (-x + 2) = -\infty$
- Forme indéterminée $\displaystyle +\infty - \infty$
- En factorisant : $\displaystyle f(x) = \ln(x)\left(1 - \frac{x - 2}{\ln(x)}\right)$
- Comme $\lim_{x \to +\infty} \frac{x}{\ln(x)} = +\infty$, on a $\lim_{x \to +\infty} f(x) = -\infty$
:::

## Question 4 : Déterminer le nombre de solutions de $\displaystyle \ln(x) = x - 2$

::: point Analyse
- Résoudre $\ln(x) = x - 2$ équivaut à résoudre $f(x) = 0$
- D'après l'étude précédente : $f$ est croissante sur $]0, 1]$ puis décroissante sur $[1, +\infty[$
- Maximum : $\displaystyle f(1) = 1 > 0$
- Limites : $\lim_{x \to 0^+} f(x) = -\infty$ et $\lim_{x \to +\infty} f(x) = -\infty$
:::

::: point Conclusion par le théorème des valeurs intermédiaires
- Sur $]0, 1]$ : $f$ passe de $-\infty$ à $1 > 0$ → **1 solution**
- Sur $[1, +\infty[$ : $f$ passe de $1 > 0$ à $-\infty$ → **1 solution**
- Total : **2 solutions**
:::

## Question 5 : Résoudre l'inéquation $\displaystyle \ln(x) \geq x - 2$

::: point Analyse
- Résoudre $\ln(x) \geq x - 2$ équivaut à résoudre $f(x) \geq 0$
:::

::: point D'après l'étude de $f$
- $f$ admet un maximum en $x = 1$ : $f(1) = 1 > 0$
- $f$ s'annule en deux points : $x_1 \in ]0, 1[$ et $x_2 \in ]1, +\infty[$
- $f(x) \geq 0$ sur $[x_1, x_2]$
:::

::: point Valeurs numériques
- En résolvant numériquement : $x_1 \approx 0,16$ et $x_2 \approx 3,15$
:::

::: resultat
$S = [x_1, x_2]$ où $x_1 \approx 0,16$ et $x_2 \approx 3,15$
:::
