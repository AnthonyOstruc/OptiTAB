===
Découverte - Compter les groupes
Id: 5417
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe les groupes dessinés.

[IMAGE_1]

1. Combien de groupes faut-il compter ou dessiner ?
2. Combien d’objets faut-il dans chaque groupe ?
3. Écris l’addition qui réunit tous les groupes.
4. Trouve le nombre total d’objets. Complète ton dessin si besoin.
5. Que devient le total si on retire un groupe ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de groupes faut-il compter ou dessiner ?

::: methode
Compter les groupes dessinés.
:::

::: etape Raisonner
Il y a 4 groupes dans cette situation.
:::

::: resultat
Il y a 4 groupes.
:::

## Question 2 : Combien d’objets faut-il dans chaque groupe ?

::: methode
Lire le contenu d’un seul groupe.
:::

::: etape Raisonner
Chaque groupe contient 3 objets. Tous les groupes ont la même taille.
:::

::: resultat
Chaque groupe contient 3 objets.
:::

## Question 3 : Écris l’addition qui réunit tous les groupes.

::: methode
Écrire une quantité par groupe.
:::

::: etape Raisonner
Je répète 3, une fois pour chacun des 4 groupes.
:::

::: resultat
$3+3+3+3$.
:::

## Question 4 : Trouve le nombre total d’objets. Complète ton dessin si besoin.

::: methode
Compter tous les objets sans en oublier.
:::

::: etape Raisonner
$3+3+3+3=12$.

[IMAGE_2]
:::

::: resultat
Il y a 12 objets en tout.
:::

## Question 5 : Que devient le total si on retire un groupe ?

::: methode
Enlever seulement le contenu d’un groupe.
:::

::: etape Raisonner
$12-3=9$. Les autres groupes restent.
:::

::: resultat
Il reste 9 objets.
:::

Solution:
<!-- optitab:1 -->
1. Il y a 4 groupes.
2. Chaque groupe contient 3 objets.
3. $3+3+3+3$.
4. Il y a 12 objets en tout.
5. Il reste 9 objets.

===
Problème - Des groupes différents
Id: 5425
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Trois boîtes contiennent 3, 3 et 4 jetons.

[IMAGE_1]

1. Combien y a-t-il de boîtes ?
2. Les boîtes ont-elles autant de jetons ?
3. Peut-on dire « trois groupes de trois » ?
4. Combien y a-t-il de jetons en tout ?
5. Comment obtenir trois groupes de trois ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien y a-t-il de boîtes ?

::: methode
Compter les contours.
:::

::: etape Raisonner
Chaque contour montre une boîte. Il y en a trois.
:::

::: resultat
Il y a 3 boîtes.
:::

## Question 2 : Les boîtes ont-elles autant de jetons ?

::: methode
Comparer les contenus.
:::

::: etape Raisonner
Les deux premières ont 3 jetons. La dernière en a 4.
:::

::: resultat
Non, les contenus sont différents.
:::

## Question 3 : Peut-on dire « trois groupes de trois » ?

::: methode
Vérifier chaque groupe.
:::

::: etape Raisonner
La dernière boîte n’a pas 3 jetons.
:::

::: resultat
Non : la dernière contient 4 jetons.
:::

## Question 4 : Combien y a-t-il de jetons en tout ?

::: methode
Additionner les contenus.
:::

::: etape Raisonner
$3+3=6$, puis $6+4=10$.

[IMAGE_2]
:::

::: resultat
Il y a 10 jetons.
:::

## Question 5 : Comment obtenir trois groupes de trois ?

::: methode
Retirer seulement le jeton en trop.
:::

::: etape Raisonner
Je retire 1 jeton de la dernière boîte. $4-1=3$.

$3+3+3=9$.

[IMAGE_3]
:::

::: resultat
Je retire 1 jeton. Il reste 9 jetons.
:::

Solution:
<!-- optitab:1 -->
1. Il y a 3 boîtes.
2. Non, les contenus sont différents.
3. Non : la dernière contient 4 jetons.
4. Il y a 10 jetons.
5. Je retire 1 jeton. Il reste 9 jetons.
