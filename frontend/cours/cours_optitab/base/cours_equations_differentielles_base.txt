    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce qu'une équation différentielle ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Équation différentielle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>équation différentielle</strong> est une équation qui met en relation une fonction inconnue $\displaystyle y(x)$ avec sa dérivée $\displaystyle y'(x)$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y' = f(x, y)$</p>
            </div>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 À savoir :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La forme générale d'une équation différentielle linéaire du premier ordre est <strong>$\displaystyle y' + p(x)y = q(x)$</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans ce cours, nous étudions le cas particulier à coefficients constants : <strong>$\displaystyle y' = a y + b$</strong> où $\displaystyle a$ et $\displaystyle b$ sont des constantes.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y' = 2y$ (croissance exponentielle)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y' = -3y + 5$ (équation complète)</li>
                <li style="margin:0; text-align:left;">$\displaystyle y' = y - 2$ (décroissance avec terme constant)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Méthodes de résolution</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Résolution générale de y' = a y + b</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Solution générale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour l'équation différentielle $\displaystyle y' = a y + b$ avec $\displaystyle a \neq 0$, la solution générale est :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x) = C e^{a x} - \frac{b}{a}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle C$ est une constante réelle déterminée par la condition initiale.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre l'équation homogène $\displaystyle y' = a y$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Trouver une solution particulière de $\displaystyle y' = a y + b$</li>
                <li style="margin:0; text-align:left;">Additionner les deux solutions</li>
            </ol>
            <p style="margin:12px 0 0 0; text-align:left; font-size:0.95em;"><strong>⚠️ Cas particulier :</strong> Si $\displaystyle a = 0$, l'équation devient $\displaystyle y' = b$, donc $\displaystyle y(x) = bx + C$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2y + 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Équation homogène :</strong> $\displaystyle y' - 2y = 0 \Rightarrow y_h = C e^{2x}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Solution particulière :</strong> On cherche une solution constante $\displaystyle y_p = k$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle 0 = 2k + 4 \Rightarrow k = -2$</li>
                <li style="margin:0; text-align:left;"><strong>Solution générale :</strong> $\displaystyle y = C e^{2x} - 2$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = -y + 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Équation homogène :</strong> $\displaystyle y' + y = 0 \Rightarrow y_h = C e^{-x}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Solution particulière :</strong> On cherche une solution constante $\displaystyle y_p = k$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle 0 = -k + 3 \Rightarrow k = 3$</li>
                <li style="margin:0; text-align:left;"><strong>Solution générale :</strong> $\displaystyle y = C e^{-x} + 3$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conditions initiales</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Condition initiale</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La constante $\displaystyle C$ est déterminée par une <strong>condition initiale</strong> :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:200px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x_0) = y_0$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2y + 4$ avec $\displaystyle y(0) = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Solution générale : $\displaystyle y = C e^{2x} - 2$</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle y(0) = 1 \Rightarrow 1 = C - 2 \Rightarrow C = 3$</li>
                <li style="margin:0; text-align:left;"><strong>Solution particulière :</strong> $\displaystyle y = 3 e^{2x} - 2$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Méthode de séparation des variables</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Principe général</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Séparation des variables</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour les équations de la forme $\displaystyle y' = g(x) h(y)$, on sépare les variables :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \frac{dy}{h(y)} = g(x) \, dx$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On intègre chaque membre pour obtenir la solution générale.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Résoudre $\displaystyle y' = 2 x y$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \frac{dy}{y} = 2x \, dx$ (pour $\displaystyle y \neq 0$)</li>
                <li style="margin:0 0 12px 0; text-align:left;">$\displaystyle \ln|y| = x^2 + C'$</li>
                <li style="margin:0; text-align:left;">$\displaystyle y = \pm e^{x^2 + C'} = K e^{x^2}$ où $\displaystyle K = \pm e^{C'}$</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Applications concrètes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation de la croissance</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Croissance exponentielle :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle P' = k P$ (population, capital, réactions chimiques)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle P(t) = P_0 e^{k t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Exemple :</strong> Population : $\displaystyle P' = 0,05 P$, $\displaystyle P(0) = 1000$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle P(t) = 1000 e^{0,05 t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle P(10) = 1000 e^{0,5} \approx 1649$ individus</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Décroissance radioactive :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle N' = -\lambda N$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle N(t) = N_0 e^{-\lambda t}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Demi-vie :</strong> $\displaystyle T_{1/2} = \frac{\ln 2}{\lambda}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Exemple :</strong> Carbone 14 : $\displaystyle \lambda = 0,00012$, $\displaystyle T_{1/2} \approx 5770$ ans</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modélisation physique</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Refroidissement d'un corps :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle T' = -k (T - T_a)$ où $\displaystyle T_a$ est la température ambiante</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle T(t) = T_a + (T_0 - T_a) e^{-k t}$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Circuit électrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation : $\displaystyle i' + \frac{R}{L} i = \frac{E}{L}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Courant : $\displaystyle i(t) = \frac{E}{R} \left(1 - e^{-\frac{R}{L} t}\right)$</p>
        </div>
    </div>


    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Vérification des solutions</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode de vérification</h3>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dériver la solution proposée et vérifier si elle satisfait l'équation différentielle.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Vérifier que $\displaystyle y = 2 e^{2x} - 2$ satisfait $\displaystyle y' = 2y + 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle y' = 4 e^{2x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 2y + 4 = 2(2 e^{2x} - 2) + 4 = 4 e^{2x} - 4 + 4 = 4 e^{2x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em; color:#2e7d32;">✅ Solution correcte !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Exercices d'application</h2>

            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Oublier la constante d'intégration $\displaystyle C$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mauvais signe pour l'équation homogène</li>
                <li style="margin:0 0 12px 0; text-align:left;">Erreur dans le calcul de la solution particulière</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier d'appliquer la condition initiale</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier la solution obtenue</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">

                <li style="margin:0 0 12px 0; text-align:left;">Identifier la forme $\displaystyle y' = a y + b$ avec $\displaystyle a$ et $\displaystyle b$ constantes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Résoudre d'abord l'équation homogène $\displaystyle y' = a y$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Trouver une solution particulière constante</li>
                <li style="margin:0 0 12px 0; text-align:left;">Appliquer la condition initiale pour trouver $\displaystyle C$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Vérifier toujours en dérivant la solution</li>
                <li style="margin:0; text-align:left;">Être attentif aux unités dans les applications</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Équations du second ordre (Introduction)</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Forme générale</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Équation du second ordre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>équation différentielle du second ordre</strong> fait intervenir la dérivée seconde $\displaystyle y''(x)$ :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:350px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y'' + ay' + by = c$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle a$, $\displaystyle b$ et $\displaystyle c$ sont des constantes.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>📝 Équation caractéristique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle y'' + ay' + by = 0$, on pose l'<strong>équation caractéristique</strong> :</p>
            <div style="background:#ecfdf5; border:3px solid #10b981; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:250px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle r^2 + ar + b = 0$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution dépend du discriminant $\displaystyle \Delta = a^2 - 4b$ :</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Cas 1 : Deux racines réelles distinctes ($\displaystyle \Delta > 0$)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle r_1$ et $\displaystyle r_2$ sont les deux racines :</p>
            <div style="background:#ffffff; border:2px solid #6c757d; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.05em; font-weight:bold;">$\displaystyle y(x) = C_1 e^{r_1 x} + C_2 e^{r_2 x}$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Cas 2 : Racine double ($\displaystyle \Delta = 0$)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle r$ est la racine double :</p>
            <div style="background:#ffffff; border:2px solid #6c757d; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.05em; font-weight:bold;">$\displaystyle y(x) = (C_1 + C_2 x) e^{rx}$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Cas 3 : Racines complexes conjuguées ($\displaystyle \Delta < 0$)</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle r = \alpha \pm i\beta$ :</p>
            <div style="background:#ffffff; border:2px solid #6c757d; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:450px;">
                <p style="margin:0; font-size:1.05em; font-weight:bold;">$\displaystyle y(x) = e^{\alpha x}(C_1 \cos(\beta x) + C_2 \sin(\beta x))$</p>
            </div>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>💡 Exemple classique : oscillateur harmonique</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation $\displaystyle y'' + \omega^2 y = 0$ modélise un oscillateur harmonique (ressort, pendule).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Équation caractéristique : $\displaystyle r^2 + \omega^2 = 0$ → $\displaystyle r = \pm i\omega$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution générale :</p>
            <div style="background:#fff3cd; border:2px solid #ffc107; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.05em; font-weight:bold;">$\displaystyle y(x) = A\cos(\omega x) + B\sin(\omega x)$</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Structures connues à savoir</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples types d'équations différentielles</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <strong>1️⃣ Croissance exponentielle : $\displaystyle y' = ky$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle y(x) = Ce^{kx}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : croissance d'une population, désintégration radioactive ($\displaystyle k < 0$)</em></p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>2️⃣ Refroidissement de Newton : $\displaystyle y' = -k(y - T_0)$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle y(t) = T_0 + (y_0 - T_0)e^{-kt}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : refroidissement d'un corps, température ambiante $\displaystyle T_0$</em></p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>3️⃣ Croissance logistique : $\displaystyle y' = ky(1 - \frac{y}{L})$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle y(t) = \frac{L}{1 + Ae^{-kt}}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : population avec capacité limite $\displaystyle L$, épidémiologie</em></p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>4️⃣ Circuit RC : $\displaystyle \tau y' + y = E$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Solution : $\displaystyle y(t) = E + (y_0 - E)e^{-t/\tau}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : charge d'un condensateur, constante de temps $\displaystyle \tau = RC$</em></p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>5️⃣ Oscillateur amorti : $\displaystyle y'' + 2\lambda y' + \omega_0^2 y = 0$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Selon les valeurs de $\displaystyle \lambda$ et $\displaystyle \omega_0$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">$\displaystyle \lambda < \omega_0$ : régime pseudo-périodique (oscillations amorties)</li>
                <li style="margin:0 0 8px 0; text-align:left;">$\displaystyle \lambda = \omega_0$ : régime critique</li>
                <li style="margin:0; text-align:left;">$\displaystyle \lambda > \omega_0$ : régime apériodique (pas d'oscillations)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : amortisseur, pendule avec frottement</em></p>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>6️⃣ Équation de Bernoulli : $\displaystyle y' + p(x)y = q(x)y^n$</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Changement de variable : $\displaystyle z = y^{1-n}$ ramène à une équation linéaire.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><em>Applications : croissance avec effets non linéaires</em></p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode générale de résolution</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Démarche systématique :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Identifier le type</strong> d'équation (ordre, linéaire/non linéaire, homogène/avec second membre)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Résoudre l'équation homogène</strong> (second membre = 0) pour trouver la solution générale</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Trouver une solution particulière</strong> de l'équation complète (si second membre ≠ 0)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Solution générale</strong> = solution homogène + solution particulière</li>
                <li style="margin:0; text-align:left;"><strong>Appliquer les conditions initiales</strong> pour déterminer les constantes</li>
            </ol>
        </div>
    </div>
