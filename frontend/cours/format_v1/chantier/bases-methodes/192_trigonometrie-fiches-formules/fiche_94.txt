## I. Cercle trigonométrique et définitions

| Notion | Définition |
|---|---|
| **Radian** | $\displaystyle \pi$ rad $\displaystyle = 180°$ donc $\displaystyle 1$ rad $\displaystyle = \dfrac{180°}{\pi} \approx 57,3°$ |
| **Cercle trigonométrique** | Cercle de rayon $\displaystyle 1$ centré à l'origine, orienté dans le sens direct (anti-horaire) |
| **Cosinus** | $\displaystyle \cos(x)$ est l'abscisse du point sur le cercle |
| **Sinus** | $\displaystyle \sin(x)$ est l'ordonnée du point sur le cercle |
| **Tangente** | $\displaystyle \tan(x) = \dfrac{\sin(x)}{\cos(x)}$ (définie si $\displaystyle \cos(x) \neq 0$) |
| **Cotangente** | $\displaystyle \cot(x) = \dfrac{\cos(x)}{\sin(x)} = \dfrac{1}{\tan(x)}$ (définie si $\displaystyle \sin(x) \neq 0$) |

## IV. Relations fondamentales

### 1. Relations pythagoriciennes

| Relation | Domaine |
|---|---|
| $\displaystyle \cos^2(x) + \sin^2(x) = 1$ | $\displaystyle \mathbb{R}$ |
| $\displaystyle 1 + \tan^2(x) = \dfrac{1}{\cos^2(x)}$ | $\displaystyle x \neq \dfrac{\pi}{2} + k\pi$ |
| $\displaystyle 1 + \cot^2(x) = \dfrac{1}{\sin^2(x)}$ | $\displaystyle x \neq k\pi$ |

### 2. Parité et périodicité

| Fonction | Parité | Période |
|---|---|---|
| $\displaystyle \cos(x)$ | Paire : $\displaystyle \cos(-x) = \cos(x)$ | $\displaystyle 2\pi$ |
| $\displaystyle \sin(x)$ | Impaire : $\displaystyle \sin(-x) = -\sin(x)$ | $\displaystyle 2\pi$ |
| $\displaystyle \tan(x)$ | Impaire : $\displaystyle \tan(-x) = -\tan(x)$ | $\displaystyle \pi$ |

### 3. Relations de symétrie

| Relation | Description |
|---|---|
| $\displaystyle \cos(\pi - x) = -\cos(x)$ | Symétrie par rapport à $\displaystyle x = \dfrac{\pi}{2}$ |
| $\displaystyle \sin(\pi - x) = \sin(x)$ | Symétrie par rapport à $\displaystyle x = \dfrac{\pi}{2}$ |
| $\displaystyle \cos(\pi + x) = -\cos(x)$ | Symétrie par rapport à l'origine (translation) |
| $\displaystyle \sin(\pi + x) = -\sin(x)$ | Symétrie par rapport à l'origine (translation) |
| $\displaystyle \cos\left(\dfrac{\pi}{2} - x\right) = \sin(x)$ | Angles complémentaires |
| $\displaystyle \sin\left(\dfrac{\pi}{2} - x\right) = \cos(x)$ | Angles complémentaires |
| $\displaystyle \cos\left(\dfrac{\pi}{2} + x\right) = -\sin(x)$ | Translation de $\displaystyle \dfrac{\pi}{2}$ |
| $\displaystyle \sin\left(\dfrac{\pi}{2} + x\right) = \cos(x)$ | Translation de $\displaystyle \dfrac{\pi}{2}$ |

## V. Formules d'addition et de soustraction

| Formule |
|---|
| $\displaystyle \cos(a + b) = \cos(a)\cos(b) - \sin(a)\sin(b)$ |
| $\displaystyle \cos(a - b) = \cos(a)\cos(b) + \sin(a)\sin(b)$ |
| $\displaystyle \sin(a + b) = \sin(a)\cos(b) + \cos(a)\sin(b)$ |
| $\displaystyle \sin(a - b) = \sin(a)\cos(b) - \cos(a)\sin(b)$ |
| $\displaystyle \tan(a + b) = \dfrac{\tan(a) + \tan(b)}{1 - \tan(a)\tan(b)}$ |
| $\displaystyle \tan(a - b) = \dfrac{\tan(a) - \tan(b)}{1 + \tan(a)\tan(b)}$ |

## VI. Formules de duplication

| Formule |
|---|
| $\displaystyle \cos(2x) = \cos^2(x) - \sin^2(x) = 2\cos^2(x) - 1 = 1 - 2\sin^2(x)$ |
| $\displaystyle \sin(2x) = 2\sin(x)\cos(x)$ |
| $\displaystyle \tan(2x) = \dfrac{2\tan(x)}{1 - \tan^2(x)}$ |

## VII. Formules de linéarisation

| Expression | Linéarisée |
|---|---|
| $\displaystyle \cos^2(x)$ | $\displaystyle \dfrac{1 + \cos(2x)}{2}$ |
| $\displaystyle \sin^2(x)$ | $\displaystyle \dfrac{1 - \cos(2x)}{2}$ |
| $\displaystyle \cos^3(x)$ | $\displaystyle \dfrac{\cos(3x) + 3\cos(x)}{4}$ |
| $\displaystyle \sin^3(x)$ | $\displaystyle \dfrac{3\sin(x) - \sin(3x)}{4}$ |
| $\displaystyle \cos(x)\sin(x)$ | $\displaystyle \dfrac{\sin(2x)}{2}$ |
| $\displaystyle \cos(a)\cos(b)$ | $\displaystyle \dfrac{\cos(a-b) + \cos(a+b)}{2}$ |
| $\displaystyle \sin(a)\sin(b)$ | $\displaystyle \dfrac{\cos(a-b) - \cos(a+b)}{2}$ |
| $\displaystyle \sin(a)\cos(b)$ | $\displaystyle \dfrac{\sin(a+b) + \sin(a-b)}{2}$ |

## VIII. Formules de factorisation

| Formule |
|---|
| $\displaystyle \cos(p) + \cos(q) = 2\cos\left(\dfrac{p+q}{2}\right)\cos\left(\dfrac{p-q}{2}\right)$ |
| $\displaystyle \cos(p) - \cos(q) = -2\sin\left(\dfrac{p+q}{2}\right)\sin\left(\dfrac{p-q}{2}\right)$ |
| $\displaystyle \sin(p) + \sin(q) = 2\sin\left(\dfrac{p+q}{2}\right)\cos\left(\dfrac{p-q}{2}\right)$ |
| $\displaystyle \sin(p) - \sin(q) = 2\cos\left(\dfrac{p+q}{2}\right)\sin\left(\dfrac{p-q}{2}\right)$ |
| $\displaystyle \tan(p) + \tan(q) = \dfrac{\sin(p+q)}{\cos(p)\cos(q)}$ |
| $\displaystyle \tan(p) - \tan(q) = \dfrac{\sin(p-q)}{\cos(p)\cos(q)}$ |

## IX. Formules de l'angle moitié

| Formule |
|---|
| $\displaystyle \cos\left(\dfrac{x}{2}\right) = \pm\sqrt{\dfrac{1 + \cos(x)}{2}}$ |
| $\displaystyle \sin\left(\dfrac{x}{2}\right) = \pm\sqrt{\dfrac{1 - \cos(x)}{2}}$ |
| $\displaystyle \tan\left(\dfrac{x}{2}\right) = \dfrac{\sin(x)}{1 + \cos(x)} = \dfrac{1 - \cos(x)}{\sin(x)}$ |

::: attention
Le signe $\pm$ dépend du quadrant dans lequel se trouve $\dfrac{x}{2}$
:::

## X. Transformation par la tangente de l'angle moitié

| Formule (avec $\displaystyle t = \tan\left(\dfrac{x}{2}\right)$) |
|---|
| $\displaystyle \cos(x) = \dfrac{1 - t^2}{1 + t^2}$ |
| $\displaystyle \sin(x) = \dfrac{2t}{1 + t^2}$ |
| $\displaystyle \tan(x) = \dfrac{2t}{1 - t^2}$ |

::: definition Utilité
Ces formules sont très utiles pour résoudre certaines équations trigonométriques et calculer des intégrales
:::

## XI. Équations trigonométriques

### 1. Équations de base

| Équation | Solutions |
|---|---|
| $\displaystyle \cos(x) = \cos(\alpha)$ | $\displaystyle x = \alpha + 2k\pi$ ou $\displaystyle x = -\alpha + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \sin(x) = \sin(\alpha)$ | $\displaystyle x = \alpha + 2k\pi$ ou $\displaystyle x = \pi - \alpha + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \tan(x) = \tan(\alpha)$ | $\displaystyle x = \alpha + k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \cos(x) = a$ ($\displaystyle |a| \leq 1$) | $\displaystyle x = \pm \arccos(a) + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \sin(x) = a$ ($\displaystyle |a| \leq 1$) | $\displaystyle x = \arcsin(a) + 2k\pi$ ou $\displaystyle x = \pi - \arcsin(a) + 2k\pi$ |
| $\displaystyle \tan(x) = a$ | $\displaystyle x = \arctan(a) + k\pi$, $\displaystyle k \in \mathbb{Z}$ |

### 2. Cas particuliers

| Équation | Solutions |
|---|---|
| $\displaystyle \cos(x) = 0$ | $\displaystyle x = \dfrac{\pi}{2} + k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \cos(x) = 1$ | $\displaystyle x = 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \cos(x) = -1$ | $\displaystyle x = \pi + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \sin(x) = 0$ | $\displaystyle x = k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \sin(x) = 1$ | $\displaystyle x = \dfrac{\pi}{2} + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \sin(x) = -1$ | $\displaystyle x = -\dfrac{\pi}{2} + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \tan(x) = 0$ | $\displaystyle x = k\pi$, $\displaystyle k \in \mathbb{Z}$ |
| $\displaystyle \tan(x) = 1$ | $\displaystyle x = \dfrac{\pi}{4} + k\pi$, $\displaystyle k \in \mathbb{Z}$ |

## XII. Fonctions trigonométriques inverses

### 1. Définitions et propriétés

| Fonction | Domaine | Image |
|---|---|---|
| $\displaystyle \arcsin(x)$ | $\displaystyle [-1, 1]$ | $\displaystyle \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ |
| $\displaystyle \arccos(x)$ | $\displaystyle [-1, 1]$ | $\displaystyle [0, \pi]$ |
| $\displaystyle \arctan(x)$ | $\displaystyle \mathbb{R}$ | $\displaystyle \left]-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right[$ |

### 2. Relations entre fonctions inverses

| Formule |
|---|
| $\displaystyle \arcsin(x) + \arccos(x) = \dfrac{\pi}{2}$ |
| $\displaystyle \arctan(x) + \arctan\left(\dfrac{1}{x}\right) = \dfrac{\pi}{2}$ (si $\displaystyle x > 0$) |
| $\displaystyle \arcsin(-x) = -\arcsin(x)$ |
| $\displaystyle \arccos(-x) = \pi - \arccos(x)$ |
| $\displaystyle \arctan(-x) = -\arctan(x)$ |
| $\displaystyle \arctan(a) + \arctan(b) = \arctan\left(\dfrac{a+b}{1-ab}\right)$ (si $\displaystyle ab < 1$) |

## XIII. Fonctions hyperboliques

### 1. Définitions

| Fonction | Définition |
|---|---|
| $\displaystyle \sinh(x)$ | $\displaystyle \sinh(x) = \dfrac{e^x - e^{-x}}{2}$ |
| $\displaystyle \cosh(x)$ | $\displaystyle \cosh(x) = \dfrac{e^x + e^{-x}}{2}$ |
| $\displaystyle \tanh(x)$ | $\displaystyle \tanh(x) = \dfrac{\sinh(x)}{\cosh(x)} = \dfrac{e^x - e^{-x}}{e^x + e^{-x}}$ |

### 2. Relations fondamentales

| Formule |
|---|
| $\displaystyle \cosh^2(x) - \sinh^2(x) = 1$ |
| $\displaystyle 1 - \tanh^2(x) = \dfrac{1}{\cosh^2(x)}$ |
| $\displaystyle \sinh(-x) = -\sinh(x)$ (fonction impaire) |
| $\displaystyle \cosh(-x) = \cosh(x)$ (fonction paire) |
| $\displaystyle \tanh(-x) = -\tanh(x)$ (fonction impaire) |

### 3. Formules d'addition

| Formule |
|---|
| $\displaystyle \sinh(a + b) = \sinh(a)\cosh(b) + \cosh(a)\sinh(b)$ |
| $\displaystyle \cosh(a + b) = \cosh(a)\cosh(b) + \sinh(a)\sinh(b)$ |
| $\displaystyle \tanh(a + b) = \dfrac{\tanh(a) + \tanh(b)}{1 + \tanh(a)\tanh(b)}$ |
| $\displaystyle \sinh(2x) = 2\sinh(x)\cosh(x)$ |
| $\displaystyle \cosh(2x) = \cosh^2(x) + \sinh^2(x) = 2\cosh^2(x) - 1 = 1 + 2\sinh^2(x)$ |

### 4. Fonctions hyperboliques inverses

| Fonction | Expression logarithmique |
|---|---|
| $\displaystyle \text{argsinh}(x)$ | $\displaystyle \ln(x + \sqrt{x^2 + 1})$ |
| $\displaystyle \text{argcosh}(x)$ | $\displaystyle \ln(x + \sqrt{x^2 - 1})$ ($\displaystyle x \geq 1$) |
| $\displaystyle \text{argtanh}(x)$ | $\displaystyle \dfrac{1}{2}\ln\left(\dfrac{1+x}{1-x}\right)$ ($\displaystyle |x| < 1$) |

## XIV. Développements limités (Prépa/Master)

| Fonction | Développement au voisinage de 0 |
|---|---|
| $\displaystyle \cos(x)$ | $\displaystyle 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \dfrac{x^6}{6!} + \cdots = \sum_{n=0}^{+\infty} \dfrac{(-1)^n x^{2n}}{(2n)!}$ |
| $\displaystyle \sin(x)$ | $\displaystyle x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \dfrac{x^7}{7!} + \cdots = \sum_{n=0}^{+\infty} \dfrac{(-1)^n x^{2n+1}}{(2n+1)!}$ |
| $\displaystyle \tan(x)$ | $\displaystyle x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + \dfrac{17x^7}{315} + \cdots = \sum_{n=1}^{+\infty} \dfrac{(-1)^{n-1} 2^{2n}(2^{2n}-1)B_{2n}}{(2n)!} x^{2n-1}$ <br> (où $\displaystyle B_{2n}$ sont les nombres de Bernoulli) |
| $\displaystyle \arcsin(x)$ | $\displaystyle x + \dfrac{x^3}{6} + \dfrac{3x^5}{40} + \dfrac{5x^7}{112} + \cdots = \sum_{n=0}^{+\infty} \dfrac{(2n)!}{2^{2n}(n!)^2(2n+1)} x^{2n+1}$ |
| $\displaystyle \arccos(x)$ | $\displaystyle \dfrac{\pi}{2} - x - \dfrac{x^3}{6} - \dfrac{3x^5}{40} - \dfrac{5x^7}{112} - \cdots = \dfrac{\pi}{2} - \sum_{n=0}^{+\infty} \dfrac{(2n)!}{2^{2n}(n!)^2(2n+1)} x^{2n+1}$ |
| $\displaystyle \arctan(x)$ | $\displaystyle x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \dfrac{x^7}{7} + \cdots = \sum_{n=0}^{+\infty} \dfrac{(-1)^n x^{2n+1}}{2n+1}$ |

## XVII. Erreurs fréquentes à éviter

| Erreur fréquente | Correction |
|---|---|
| $\displaystyle \cos(a+b) = \cos(a) + \cos(b)$ | $\displaystyle \cos(a+b) = \cos(a)\cos(b) - \sin(a)\sin(b)$ |
| $\displaystyle \sin(2x) = 2\sin(x)$ | $\displaystyle \sin(2x) = 2\sin(x)\cos(x)$ |
| $\displaystyle \sin^2(x) + \cos^2(x) = 0$ | $\displaystyle \sin^2(x) + \cos^2(x) = 1$ |
| $\displaystyle \tan(x) = \dfrac{\cos(x)}{\sin(x)}$ | $\displaystyle \tan(x) = \dfrac{\sin(x)}{\cos(x)}$ |
| $\displaystyle \arcsin(\sin(x)) = x$ pour tout $\displaystyle x$ | $\displaystyle \arcsin(\sin(x)) = x$ seulement si $\displaystyle x \in \left[-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right]$ |
| Oublier la période dans les solutions d'équations | Toujours ajouter $\displaystyle + 2k\pi$ ou $\displaystyle + k\pi$ selon le cas |
| $\displaystyle \cos^{-1}(x) = \dfrac{1}{\cos(x)}$ | $\displaystyle \cos^{-1}(x) = \arccos(x)$ ; $\displaystyle \dfrac{1}{\cos(x)} = \sec(x)$ |

## XVIII. Méthode de résolution d'équations

| Type d'équation | Méthode |
|---|---|
| **$\displaystyle \cos(x) = a$** | 1. Vérifier $\displaystyle |a| \leq 1$ <br> 2. Utiliser $\displaystyle x = \pm \arccos(a) + 2k\pi$ |
| **Avec puissances** | Utiliser les formules de linéarisation pour transformer en équation linéaire |
| **Type $\displaystyle a\cos(x) + b\sin(x) = c$** | Transformer en $\displaystyle A\cos(x + \varphi) = c$ avec $\displaystyle A = \sqrt{a^2 + b^2}$ |
| **Équations polynomiales** | Poser $\displaystyle t = \cos(x)$ ou $\displaystyle t = \sin(x)$ ou $\displaystyle t = \tan(x)$ |

| Exemple : Résoudre $\displaystyle 2\sin^2(x) + \cos(x) - 2 = 0$ |
|---|
| **Étape 1 :** Utiliser $\displaystyle \sin^2(x) = 1 - \cos^2(x)$ <br> $\displaystyle 2(1-\cos^2(x)) + \cos(x) - 2 = 0$ <br> <br> **Étape 2 :** Simplifier <br> $\displaystyle -2\cos^2(x) + \cos(x) = 0$ <br> <br> **Étape 3 :** Factoriser <br> $\displaystyle \cos(x)(-2\cos(x) + 1) = 0$ <br> <br> **Étape 4 :** Résoudre <br> $\displaystyle \cos(x) = 0$ ou $\displaystyle \cos(x) = \dfrac{1}{2}$ <br> <br> **Solutions :** <br> $\displaystyle x = \dfrac{\pi}{2} + k\pi$ ou $\displaystyle x = \pm\dfrac{\pi}{3} + 2k\pi$, $\displaystyle k \in \mathbb{Z}$ |
