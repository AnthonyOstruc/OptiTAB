🎯 Objectifs du chapitre : calculer un taux de variation et un nombre dérivé, déterminer l’équation d’une tangente, connaître les dérivées usuelles et les règles de calcul, puis utiliser le signe de la dérivée pour étudier les variations et les extremums d’une fonction.

I. Nombre dérivé

Définition : le taux de variation de $\displaystyle f$ entre $\displaystyle a$ et $\displaystyle a + h$ ($\displaystyle h \neq 0$) est $\displaystyle \frac{f(a + h) - f(a)}{h}$ : c’est la pente de la sécante $\displaystyle (AM)$. Si ce taux tend vers un nombre réel quand $\displaystyle h$ tend vers $\displaystyle 0$, $\displaystyle f$ est dérivable en $\displaystyle a$ et ce nombre est le nombre dérivé $\displaystyle f'(a)$.

[IMAGE_1]

Exemple : pour $\displaystyle f(x) = x^2$ et $\displaystyle a = 1$ : $\displaystyle \frac{(1 + h)^2 - 1}{h} = \frac{2h + h^2}{h} = 2 + h$, qui tend vers $\displaystyle 2$. Donc $\displaystyle f'(1) = 2$.

II. Tangente à une courbe

Propriété (démonstration au programme) : la tangente à la courbe de $\displaystyle f$ au point d’abscisse $\displaystyle a$ est la droite passant par $\displaystyle A(a\,;f(a))$ de pente $\displaystyle f'(a)$. Son équation est :

$\displaystyle y = f'(a)(x - a) + f(a)$

Preuve : cette droite a une équation $\displaystyle y = f'(a)x + p$ ; elle passe par $\displaystyle A$, donc $\displaystyle f(a) = f'(a)a + p$, d’où $\displaystyle p = f(a) - f'(a)a$ et le résultat.

[IMAGE_2]

Exemple : pour $\displaystyle f(x) = x^2$ en $\displaystyle a = 1$ : $\displaystyle f(1) = 1$ et $\displaystyle f'(1) = 2$, donc $\displaystyle T : y = 2(x - 1) + 1 = 2x - 1$.

III. Fonctions dérivées usuelles

Formules :

• $\displaystyle f(x) = k$ (constante) : $\displaystyle f'(x) = 0$ ; $\displaystyle f(x) = mx + p$ : $\displaystyle f'(x) = m$.

• $\displaystyle f(x) = x^n$ ($\displaystyle n \ge 1$ entier) : $\displaystyle f'(x) = nx^{n-1}$ ; par exemple $\displaystyle (x^2)' = 2x$ et $\displaystyle (x^3)' = 3x^2$.

• $\displaystyle f(x) = \frac{1}{x}$ sur $\displaystyle ]-\infty\,;0[$ ou $\displaystyle ]0\,;+\infty[$ : $\displaystyle f'(x) = -\frac{1}{x^2}$.

• $\displaystyle f(x) = \sqrt{x}$ sur $\displaystyle ]0\,;+\infty[$ : $\displaystyle f'(x) = \frac{1}{2\sqrt{x}}$.

Démonstrations au programme :

• Carré : $\displaystyle \frac{(x + h)^2 - x^2}{h} = 2x + h \rightarrow 2x$.

• Inverse : $\displaystyle \frac{1}{h}\left(\frac{1}{x + h} - \frac{1}{x}\right) = \frac{-1}{x(x + h)} \rightarrow -\frac{1}{x^2}$.

• Racine carrée en $\displaystyle 0$ : $\displaystyle \frac{\sqrt{h} - \sqrt{0}}{h} = \frac{1}{\sqrt{h}}$ devient aussi grand que l’on veut, donc $\displaystyle \sqrt{\phantom{x}}$ n’est pas dérivable en $\displaystyle 0$.

IV. Règles de calcul

Opérations : $\displaystyle (u + v)' = u' + v'$ ; $\displaystyle (ku)' = ku'$ ; $\displaystyle (uv)' = u'v + uv'$ ; $\displaystyle \left(\frac{1}{v}\right)' = -\frac{v'}{v^2}$ ; $\displaystyle \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$ ; et $\displaystyle \big(g(ax + b)\big)' = a\,g'(ax + b)$.

Preuve pour le produit (au programme) : $\displaystyle \frac{u(x + h)v(x + h) - u(x)v(x)}{h} = \frac{u(x + h) - u(x)}{h}\,v(x + h) + u(x)\,\frac{v(x + h) - v(x)}{h}$, qui tend vers $\displaystyle u'(x)v(x) + u(x)v'(x)$.

Exemples :

• $\displaystyle f(x) = (2x + 1)(x^2 - 3)$ : $\displaystyle f'(x) = 2(x^2 - 3) + (2x + 1) \times 2x = 6x^2 + 2x - 6$.

• $\displaystyle g(x) = \frac{3x - 1}{x + 2}$ : $\displaystyle g'(x) = \frac{3(x + 2) - (3x - 1) \times 1}{(x + 2)^2} = \frac{7}{(x + 2)^2}$.

• $\displaystyle h(x) = \sqrt{4x + 1}$ : $\displaystyle h'(x) = 4 \times \frac{1}{2\sqrt{4x + 1}} = \frac{2}{\sqrt{4x + 1}}$.

⚠️ Attention : la dérivée d’un produit n’est pas le produit des dérivées : $\displaystyle (uv)' \neq u'v'$. Dans un quotient, l’ordre compte : c’est $\displaystyle u'v - uv'$ au numérateur.

V. Dérivée et variations

Théorème : soit $\displaystyle f$ dérivable sur un intervalle $\displaystyle I$. Si $\displaystyle f' \ge 0$ sur $\displaystyle I$, $\displaystyle f$ est croissante sur $\displaystyle I$ ; si $\displaystyle f' \le 0$ sur $\displaystyle I$, $\displaystyle f$ est décroissante sur $\displaystyle I$. Si $\displaystyle f'$ s’annule en $\displaystyle a$ en changeant de signe, $\displaystyle f$ admet un extremum local en $\displaystyle a$.

Exemple : $\displaystyle f(x) = x^3 - 3x$. On a $\displaystyle f'(x) = 3x^2 - 3 = 3(x - 1)(x + 1)$, positif à l’extérieur de $\displaystyle [-1\,;1]$ et négatif entre $\displaystyle -1$ et $\displaystyle 1$.
