Titre: Probabilités

<!-- optitab:1 -->
::: objectifs
- Utiliser le vocabulaire : expérience aléatoire, issue, événement, événement contraire, événements incompatibles.
- Calculer une probabilité dans une situation d'équiprobabilité.
- Représenter une expérience à deux épreuves par un arbre ou un tableau à double entrée.
- Faire le lien entre fréquence observée et probabilité.
:::

## I. Vocabulaire des probabilités

::: definition Expérience aléatoire, issue, événement
- Une **expérience aléatoire** est une expérience dont on connaît tous les résultats possibles, mais dont on ne peut pas prévoir le résultat.
- Chaque résultat possible est une **issue**.
- Un **événement** est un ensemble d'issues. Une issue qui le réalise est une issue **favorable**.
:::

::: exemple Lancer d'un dé
On lance un dé à six faces. Les issues sont $1$, $2$, $3$, $4$, $5$ et $6$.

L'événement $A$ : « obtenir un nombre pair » est réalisé par les issues $2$, $4$ et $6$.
:::

::: definition Événement contraire, événements incompatibles
- L'**événement contraire** de $A$, noté « non $A$ », est formé de toutes les issues qui ne réalisent pas $A$.
- Deux événements sont **incompatibles** s'ils ne peuvent pas se réaliser en même temps (aucune issue commune).
:::

::: exemple
Avec le dé : le contraire de « obtenir un nombre pair » est « obtenir un nombre impair » ($1$, $3$, $5$).

« Obtenir $1$ » et « obtenir un nombre pair » sont incompatibles. « Obtenir $2$ » et « obtenir un nombre pair » ne le sont pas : l'issue $2$ réalise les deux.
:::

## II. Calculer une probabilité

::: definition Probabilité
La **probabilité** d'un événement $A$, notée $P(A)$, est un nombre qui mesure la chance que $A$ se réalise :

$$0 \leqslant P(A) \leqslant 1$$

- un événement **impossible** a une probabilité égale à $0$ ;
- un événement **certain** a une probabilité égale à $1$ ;
- la somme des probabilités de toutes les issues vaut $1$.
:::

::: propriete Situation d'équiprobabilité
Quand toutes les issues ont la même probabilité (dé équilibré, boules indiscernables au toucher, secteurs de même angle…) :

$$P(A) = \frac{\text{nombre d'issues favorables à } A}{\text{nombre total d'issues}}$$
:::

::: methode Calculer une probabilité en situation d'équiprobabilité
1. Justifier que les issues sont équiprobables.
2. Compter toutes les issues, puis les issues favorables.
3. Écrire le quotient et le simplifier.
:::

[IMAGE_1]

::: exemple Le sac de boules
Le sac contient $5$ boules rouges, $3$ bleues et $2$ vertes, indiscernables au toucher : les $10$ boules sont équiprobables.

$$P(\text{rouge}) = \frac{5}{10} = \frac{1}{2} \qquad P(\text{verte}) = \frac{2}{10} = \frac{1}{5}$$
:::

::: attention Compter les objets, pas les catégories
Il y a trois couleurs, mais $P(\text{rouge}) \neq \frac{1}{3}$ : ce sont les **boules** qui sont équiprobables, pas les couleurs.
:::

::: propriete Événement contraire
$$P(\text{non } A) = 1 - P(A)$$
:::

::: exemple
$P(\text{non rouge}) = 1 - \frac{1}{2} = \frac{1}{2}$.
:::

::: propriete Événements incompatibles
Si $A$ et $B$ sont incompatibles, la probabilité que $A$ **ou** $B$ se réalise est :

$$P(A \text{ ou } B) = P(A) + P(B)$$
:::

::: exemple
$P(\text{bleue ou verte}) = \frac{3}{10} + \frac{2}{10} = \frac{5}{10} = \frac{1}{2}$.
:::

::: attention
On n'additionne que des probabilités d'événements **incompatibles**. Pour un tirage dans un jeu de $32$ cartes, $P(\text{pique ou as}) \neq \frac{8}{32} + \frac{4}{32}$ : l'as de pique serait compté deux fois.
:::

## III. Expériences à deux épreuves

Une expérience à deux épreuves enchaîne deux expériences aléatoires (deux lancers, deux tirages…). Pour ne rien oublier, on organise les issues dans un **arbre** ou dans un **tableau à double entrée**.

### 1. Le tableau à double entrée

::: methode Utiliser un tableau à double entrée
On écrit les issues de la première épreuve en ligne, celles de la seconde en colonne : chaque case est une issue de l'expérience. Si les cases sont équiprobables, on compte les cases favorables.
:::

[IMAGE_2]

::: exemple Somme de deux dés équilibrés
Le tableau a $6 \times 6 = 36$ cases équiprobables. La somme vaut $7$ dans $6$ cases (en vert) :

$$P(\text{somme } 7) = \frac{6}{36} = \frac{1}{6}$$
:::

::: attention
Les sommes de $2$ à $12$ ne sont **pas** équiprobables : la somme $7$ occupe $6$ cases, la somme $2$ une seule. Ce sont les **cases** (couples) qui sont équiprobables.
:::

### 2. L'arbre des possibles

::: methode Utiliser un arbre
- Chaque chemin de l'arbre, de la racine à une extrémité, correspond à une issue.
- On inscrit sur chaque branche la probabilité correspondante.
- La probabilité d'une issue est le **produit** des probabilités rencontrées le long de son chemin.
- La probabilité d'un événement est la **somme** des probabilités des chemins qui le réalisent.
:::

[IMAGE_3]

::: exemple Deux tirages avec remise
Un sac contient $3$ boules rouges ($R$) et $2$ bleues ($B$). On tire une boule, on la remet, puis on en tire une seconde : le sac est le même aux deux tirages.

$$P(RR) = \frac{3}{5} \times \frac{3}{5} = \frac{9}{25}$$

Deux couleurs différentes : chemins $RB$ et $BR$ (en vert).

$$P(RB) + P(BR) = \frac{6}{25} + \frac{6}{25} = \frac{12}{25}$$
:::

::: attention Tirage sans remise
Si la première boule n'est pas remise, le sac change : il ne reste que $4$ boules. Après une rouge, il reste $2$ rouges sur $4$ :

$$P(RR) = \frac{3}{5} \times \frac{2}{4} = \frac{3}{10}$$
:::

::: conseil Contrôle
La somme des probabilités de toutes les extrémités de l'arbre (ou de toutes les cases du tableau) vaut toujours $1$.
:::

## IV. Fréquence et probabilité

::: definition Fréquence observée
On répète une expérience $n$ fois. Si l'événement $A$ se réalise $k$ fois, sa **fréquence** observée est $\dfrac{k}{n}$.
:::

::: propriete Stabilisation des fréquences
Quand on répète un très grand nombre de fois une expérience aléatoire dans les mêmes conditions, la fréquence de $A$ se **stabilise** autour de la probabilité de $A$.
:::

[IMAGE_4]

::: exemple
Sur $100$ lancers d'une pièce équilibrée, on obtient $46$ « face » : la fréquence $0{,}46$ est proche de la probabilité $0{,}5$ sans lui être égale. Sur $2\,000$ lancers, l'écart devient en général bien plus petit.
:::

::: attention
- La fréquence varie d'une série à l'autre ; la probabilité, elle, est fixe.
- Le hasard n'a pas de mémoire : après cinq « pile », la probabilité d'obtenir « face » au lancer suivant reste $\frac{1}{2}$.
:::

::: retenir
- $0 \leqslant P(A) \leqslant 1$ ; équiprobabilité : $P(A) = \dfrac{\text{issues favorables}}{\text{issues possibles}}$.
- $P(\text{non } A) = 1 - P(A)$ ; si $A$ et $B$ sont incompatibles : $P(A \text{ ou } B) = P(A) + P(B)$.
- Deux épreuves : tableau ou arbre ; on **multiplie** le long d'un chemin, on **additionne** les chemins.
- Sur un grand nombre d'essais, la fréquence se stabilise autour de la probabilité.
:::
