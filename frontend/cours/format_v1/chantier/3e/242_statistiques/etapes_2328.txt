## Question 1 : La somme des quatre notes

::: methode
Si la moyenne de $4$ notes vaut $12{,}5$, alors somme = nombre de notes × moyenne.
:::

::: etape Calculer
$$4 \times 12{,}5 = 50$$
:::

::: resultat
La somme des quatre notes vaut $50$.
:::

## Question 2 : La note $x$

::: etape Écrire l'égalité des sommes
$$8 + 12 + 14 + x = 50$$
:::

::: etape Résoudre
$$
\begin{aligned}
34 + x &= 50 \\
x &= 50 - 34 = 16
\end{aligned}
$$
:::

::: resultat
La note manquante est $x = 16$.
:::

## Question 3 : La vérification

::: etape Recalculer la moyenne
$$\frac{8 + 12 + 14 + 16}{4} = \frac{50}{4} = 12{,}5$$
:::

::: resultat
On retrouve bien la moyenne $12{,}5$ : $x = 16$ est correct.
:::

## Question 4 : Pour une moyenne de 13

::: etape Somme nécessaire
$$4 \times 13 = 52$$
:::

::: etape Note nécessaire
$$x = 52 - 34 = 18$$
:::

::: resultat
Il faudrait la note $18$.
:::

## Question 5 : Pour une moyenne de 15

::: etape Somme nécessaire
$$4 \times 15 = 60$$
:::

::: etape Note nécessaire
$$x = 60 - 34 = 26$$
:::

::: resultat
Impossible : il faudrait $26$, alors que la note maximale est $20$.
:::

::: attention Erreur fréquente
Raisonner directement sur les moyennes (par exemple « il manque $0{,}5$ point ») : on passe toujours par les **sommes** (somme = moyenne × nombre de notes).
:::

::: retenir
Une moyenne connue se traduit en SOMME : c'est la clé des problèmes de note manquante.
:::

Solution:
<!-- optitab:1 -->
1. $50$
2. $x = 16$
3. $\dfrac{50}{4} = 12{,}5$
4. $18$
5. Non : il faudrait $26 > 20$
