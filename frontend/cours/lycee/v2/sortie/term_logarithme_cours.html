🎯 Objectifs du chapitre : définir le logarithme népérien à partir de l’exponentielle, utiliser ses propriétés algébriques, connaître sa dérivée, ses variations, ses limites et les croissances comparées, et résoudre des équations, inéquations et problèmes de seuil.

I. Définition

Définition : pour tout réel $\displaystyle x \gt 0$, l’équation $\displaystyle e^y = x$ admet une unique solution, notée $\displaystyle \ln x$ (logarithme népérien de $\displaystyle x$). Ainsi, pour $\displaystyle x \gt 0$ et $\displaystyle y$ réel : $\displaystyle y = \ln x \iff e^y = x$.

Conséquences : $\displaystyle \ln 1 = 0$ ; $\displaystyle \ln e = 1$ ; $\displaystyle e^{\ln x} = x$ pour $\displaystyle x \gt 0$ ; $\displaystyle \ln(e^x) = x$ pour tout réel $\displaystyle x$.

II. Propriétés algébriques

Propriété fondamentale (démonstration au programme) : pour tous réels $\displaystyle a \gt 0$ et $\displaystyle b \gt 0$, $\displaystyle \ln(ab) = \ln a + \ln b$.

Preuve : $\displaystyle e^{\ln a + \ln b} = e^{\ln a}e^{\ln b} = ab = e^{\ln(ab)}$, et l’exponentielle est injective.

Conséquences : $\displaystyle \ln\frac{1}{a} = -\ln a$ ; $\displaystyle \ln\frac{a}{b} = \ln a - \ln b$ ; $\displaystyle \ln(a^n) = n\ln a$ ; $\displaystyle \ln\sqrt{a} = \frac{1}{2}\ln a$.

Exemples : $\displaystyle \ln 8 = 3\ln 2$ ; $\displaystyle \ln\frac{1}{9} = -2\ln 3$ ; $\displaystyle \ln\sqrt{e} = \frac{1}{2}$.

⚠️ Attention : $\displaystyle \ln(a + b) \neq \ln a + \ln b$, et $\displaystyle \ln x$ n’existe que pour $\displaystyle x \gt 0$ : on commence toujours par déterminer le domaine.

III. Étude de la fonction ln

Dérivée (démonstration au programme) : $\displaystyle \ln$ est dérivable sur $\displaystyle ]0\,;+\infty[$ et $\displaystyle (\ln x)' = \frac{1}{x}$. Preuve : en dérivant $\displaystyle e^{\ln x} = x$, on obtient $\displaystyle (\ln x)'\,e^{\ln x} = 1$, soit $\displaystyle (\ln x)' \times x = 1$.

Conséquences : $\displaystyle \ln$ est strictement croissante sur $\displaystyle ]0\,;+\infty[$ ; $\displaystyle \ln a = \ln b \iff a = b$ et $\displaystyle \ln a \lt \ln b \iff a \lt b$ ; $\displaystyle \ln x \lt 0$ sur $\displaystyle ]0\,;1[$ et $\displaystyle \ln x \gt 0$ sur $\displaystyle ]1\,;+\infty[$.

Limites : $\displaystyle \lim\limits_{x \to +\infty} \ln x = +\infty$ ; $\displaystyle \lim\limits_{x \to 0^+} \ln x = -\infty$ ; $\displaystyle \lim\limits_{x \to 0} \frac{\ln(1 + x)}{x} = 1$.

[IMAGE_2]

Croissances comparées : $\displaystyle \lim\limits_{x \to +\infty} \frac{\ln x}{x} = 0$ et $\displaystyle \lim\limits_{x \to 0^+} x\ln x = 0$ ; plus généralement $\displaystyle \frac{\ln x}{x^n} \to 0$ en $\displaystyle +\infty$.

[IMAGE_3]
💡 Fonction $\displaystyle \ln u$ : si $\displaystyle u$ est dérivable et strictement positive, $\displaystyle (\ln u)' = \frac{u'}{u}$. Par exemple $\displaystyle \big(\ln(x^2 + 1)\big)' = \frac{2x}{x^2 + 1}$.

IV. Équations, inéquations et seuils

Exemples :

• $\displaystyle e^{x} = 5 \iff x = \ln 5$ ; $\displaystyle \ln x \le 2 \iff 0 \lt x \le e^2$.

• $\displaystyle \ln(2x - 1) = \ln(x + 3)$ : domaine $\displaystyle x \gt \frac{1}{2}$ ; alors $\displaystyle 2x - 1 = x + 3$, d’où $\displaystyle x = 4$, qui convient.

• Seuil : $\displaystyle 2^n \gt 1\,000 \iff n\ln 2 \gt \ln 1\,000 \iff n \gt \frac{\ln 1\,000}{\ln 2} \approx 9{,}97$, donc $\displaystyle n \ge 10$. De même $\displaystyle 0{,}8^n \lt 0{,}001 \iff n \gt \frac{\ln 0{,}001}{\ln 0{,}8} \approx 30{,}96$, donc $\displaystyle n \ge 31$.

⚠️ Attention : diviser par $\displaystyle \ln q$ change le sens de l’inégalité quand $\displaystyle 0 \lt q \lt 1$, car alors $\displaystyle \ln q \lt 0$.
[IMAGE_4]

Demi-vie : le carbone 14 suit $\displaystyle N(t) = N_0\,e^{-\lambda t}$. La quantité est divisée par deux au bout de $\displaystyle T$ tel que $\displaystyle e^{-\lambda T} = \frac{1}{2}$, soit $\displaystyle T = \frac{\ln 2}{\lambda}$. Avec $\displaystyle T = 5\,730$ ans, $\displaystyle \lambda = \frac{\ln 2}{5\,730} \approx 1{,}21 \times 10^{-4}$ par an.

🏆 L’essentiel : $\displaystyle y = \ln x \iff e^y = x$ ($\displaystyle x \gt 0$) ; $\displaystyle \ln(ab) = \ln a + \ln b$, $\displaystyle \ln(a^n) = n\ln a$ ; $\displaystyle (\ln x)' = \frac{1}{x}$, $\displaystyle (\ln u)' = \frac{u'}{u}$ ; $\displaystyle \ln$ croissante, $\displaystyle \lim\limits_{0^+} \ln = -\infty$, $\displaystyle \lim\limits_{+\infty} \ln = +\infty$, $\displaystyle \frac{\ln x}{x} \to 0$ ; on « prend le ln » pour résoudre $\displaystyle q^n \gt A$.
