## I. Vocabulaire

| Mot | Sens | Exemple (dé à 6 faces) |
|---|---|---|
| Issue | résultat possible | $4$ |
| Événement | ensemble d'issues | « pair » : $2$, $4$, $6$ |
| Contraire de $A$ | issues qui ne réalisent pas $A$ | « impair » : $1$, $3$, $5$ |
| Incompatibles | pas d'issue commune | « obtenir $1$ » et « pair » |

## II. Calculer une probabilité

::: formule
$0 \leqslant P(A) \leqslant 1 \qquad P(\text{impossible}) = 0 \qquad P(\text{certain}) = 1$
:::

::: formule
Équiprobabilité : $\displaystyle P(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$
:::

::: formule
$P(\text{non } A) = 1 - P(A)$
:::

- Si $A$ et $B$ sont **incompatibles** : $P(A \text{ ou } B) = P(A) + P(B)$.
- Justifier l'équiprobabilité (dé équilibré, boules indiscernables, secteurs égaux).
- Compter les **objets** (boules, cartes), pas les catégories (couleurs).
- « Au moins un » : passer par le contraire « aucun ».

## III. Deux épreuves : tableau ou arbre

[IMAGE_1]

- **Tableau** : chaque case est une issue ; deux dés donnent $36$ cases équiprobables ; $P(\text{somme } 7) = \frac{6}{36} = \frac{1}{6}$.
- **Arbre** : on **multiplie** le long d'un chemin, on **additionne** les chemins favorables.

| $3$ R et $2$ B | $P(RR)$ |
|---|---|
| Avec remise | $\frac{3}{5} \times \frac{3}{5} = \frac{9}{25}$ |
| Sans remise | $\frac{3}{5} \times \frac{2}{4} = \frac{3}{10}$ |

## IV. Fréquence et probabilité

Fréquence $= \dfrac{\text{nombre de succès}}{\text{nombre d'essais}}$. Sur un **grand** nombre d'essais, elle se stabilise autour de la probabilité ; elle ne prédit pas le prochain résultat.

::: attention Les erreurs classiques
1. Croire que des catégories d'effectifs différents sont équiprobables.
2. Oublier de mettre à jour le sac dans un tirage sans remise.
3. Additionner les probabilités d'événements compatibles (double comptage).
4. Confondre fréquence observée et probabilité ; croire que le hasard a une mémoire.
:::

::: retenir Réflexe brevet
Justifier l'équiprobabilité, donner le résultat en fraction irréductible, vérifier que le total des probabilités vaut $1$.
:::
