<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. La racine carrée</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Pour $a \geq 0$ : $\sqrt{a}$ est le nombre <strong>positif</strong> tel que $\left(\sqrt{a}\right)^2 = a$. Exemples : $\sqrt{144} = 12$ ; $\sqrt{0{,}09} = 0{,}3$.</p>
<p style="margin:6px 0 0 0;">• $\sqrt{a}$ n'existe pas si $a < 0$.</p>
<p style="margin:6px 0 0 0;">• Côté d'un carré d'aire $A$ : $c = \sqrt{A}$.</p>
<p style="margin:6px 0 0 0;">• <strong>Encadrer</strong> : $16 < 20 < 25$ donc $4 < \sqrt{20} < 5$.</p>
[IMAGE_2]
<p style="margin:6px 0 0 0;">• Les nombres de carré $a > 0$ : $\sqrt{a}$ et $-\sqrt{a}$ (une longueur : seulement $\sqrt{a}$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ $\sqrt{9 + 16} = 3 + 4$ (faux : $\sqrt{25} = 5$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Confondre $a^2$ et $2a$ : $5^2 = 25$, pas $10$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Arrondir $\sqrt{20}$ trop tôt dans un calcul.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier la solution négative de $x^2 = 64$ (sauf pour une longueur).</p>
</div>
