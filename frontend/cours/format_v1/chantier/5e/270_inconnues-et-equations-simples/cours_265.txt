Titre: Inconnues et équations simples

<!-- optitab:1 -->
::: objectifs
- Désigner par une lettre un nombre que l'on cherche : la lettre devient une **inconnue**.
- Tester si un nombre est **solution** d'une égalité.
- Résoudre des équations du type $x + b = c$ et $ax = c$ (ainsi que $\frac{x}{a} = c$) grâce aux **opérations inverses**.
- Mettre en équation un problème simple, le résoudre, vérifier la réponse et conclure.
:::

## I. Équation, inconnue, solution

### 1. Une lettre pour le nombre cherché

« Je pense à un nombre. Si je lui ajoute $8$, j'obtiens $20$. Quel est ce nombre ? »

Le nombre cherché est inconnu : on le désigne par une lettre, par exemple $x$. La phrase se traduit alors par l'égalité
$$x + 8 = 20$$

::: definition Inconnue, équation
- Une **inconnue** est un nombre que l'on cherche ; on la désigne par une lettre ($x$, $n$, $t$…).
- Une **équation** est une égalité dans laquelle figure une inconnue.
- Ce qui est écrit à gauche du signe $=$ est le **membre de gauche** ; ce qui est écrit à droite est le **membre de droite**.
:::

::: exemple
- $x + 8 = 20$ est une équation d'inconnue $x$.
- $3n = 21$ est une équation d'inconnue $n$ ; rappel : $3n$ signifie $3 \times n$.
- $5 + 8 = 13$ n'est pas une équation : il n'y a aucune inconnue.
:::

### 2. Tester une égalité

::: definition Solution d'une équation
Un nombre est une **solution** d'une équation si, en remplaçant l'inconnue par ce nombre, l'égalité est **vraie**.
:::

::: methode Tester si un nombre est solution
1. Remplacer la lettre par le nombre dans **chaque membre**.
2. Calculer **séparément** le membre de gauche et le membre de droite, en respectant les priorités.
3. Si les deux résultats sont égaux, le nombre est solution ; sinon, il ne l'est pas.
:::

::: exemple Le nombre $4$ est-il solution de $5x - 3 = 2x + 9$ ?
- Membre de gauche : $5 \times 4 - 3 = 20 - 3 = 17$.
- Membre de droite : $2 \times 4 + 9 = 8 + 9 = 17$.

Les deux membres valent $17$ : **$4$ est solution**.

Avec $x = 2$ : $5 \times 2 - 3 = 7$ et $2 \times 2 + 9 = 13$. Comme $7 \neq 13$, **$2$ n'est pas solution**.
:::

::: attention Erreurs fréquentes
- Remplacer $x$ par $4$ dans $5x$ donne $5 \times 4 = 20$, et non « $54$ ».
- On ne calcule pas « à travers » le signe $=$ : chaque membre se calcule seul, puis on compare.
:::

## II. Résoudre avec les opérations inverses

**Résoudre** une équation, c'est trouver sa (ou ses) solution(s).

### 1. Défaire une addition : $x + b = c$

Une balance en équilibre traduit une égalité. Si l'on enlève la même masse sur les deux plateaux, elle reste en équilibre.

[IMAGE_1]

::: propriete Addition à trou
Le nombre qui, ajouté à $b$, donne $c$ s'obtient par une **soustraction** :
$$x + b = c \quad \text{donne} \quad x = c - b$$
:::

::: exemple
- $x + 5 = 12$ donne $x = 12 - 5 = 7$. Vérification : $7 + 5 = 12$.
- $x + 3{,}6 = 10$ donne $x = 10 - 3{,}6 = 6{,}4$. Vérification : $6{,}4 + 3{,}6 = 10$.
- $x + 9 = 4$ donne $x = 4 - 9 = -5$. Vérification : $-5 + 9 = 4$. Une solution peut être négative.
- $x + \frac{1}{3} = 1$ donne $x = 1 - \frac{1}{3} = \frac{3}{3} - \frac{1}{3} = \frac{2}{3}$.
:::

::: remarque Le même raisonnement pour une soustraction
$x - 6 = 11$ : le nombre auquel on a retiré $6$ s'obtient en rajoutant $6$, donc $x = 11 + 6 = 17$.
:::

### 2. Défaire une multiplication : $ax = c$

Si les trois boîtes pèsent ensemble $12$ g, une seule pèse le tiers de $12$ g.

[IMAGE_2]

::: propriete Multiplication à trou
Pour $a \neq 0$, le nombre qui, multiplié par $a$, donne $c$ s'obtient par une **division** :
$$ax = c \quad \text{donne} \quad x = c \div a = \frac{c}{a}$$
:::

::: exemple
- $3x = 12$ donne $x = 12 \div 3 = 4$. Vérification : $3 \times 4 = 12$.
- $4x = 7$ donne $x = 7 \div 4 = 1{,}75$. Vérification : $4 \times 1{,}75 = 7$.
- $0{,}5x = 4$ donne $x = 4 \div 0{,}5 = 8$. Vérification : $0{,}5 \times 8 = 4$.
- $3x = 2$ : la division $2 \div 3$ ne s'arrête pas. La solution s'écrit avec le **quotient** $\frac{2}{3}$, le nombre qui, multiplié par $3$, donne $2$ : $3 \times \frac{2}{3} = 2$.
:::

### 3. Défaire une division : $\frac{x}{a} = c$

::: propriete Division à trou
Pour $a \neq 0$, si un nombre partagé en $a$ parts égales donne $c$, ce nombre vaut $c \times a$ :
$$\frac{x}{a} = c \quad \text{donne} \quad x = c \times a$$
:::

::: exemple
- $\frac{x}{3} = 1$ : un nombre partagé en $3$ parts égales donne des parts de $1$, donc $x = 1 \times 3 = 3$. Vérification : $\frac{3}{3} = 1$.
- $\frac{x}{4} = 2{,}5$ donne $x = 2{,}5 \times 4 = 10$. Vérification : $10 \div 4 = 2{,}5$.
:::

### 4. Les cas avec zéro

::: propriete
- $2x = 0$ a pour solution $0$ : $0$ est le seul nombre dont le double est nul.
- $\frac{x}{2} = 0$ a pour solution $0$ : $x = 0 \times 2 = 0$.
:::

::: attention Erreurs fréquentes
- Pour $x + 5 = 12$, ajouter au lieu de soustraire donne $17$ ; la vérification le détecte : $17 + 5 = 22 \neq 12$.
- Pour $3x = 12$, soustraire $3$ donne $9$ : faux, car $3x$ est un **produit** ($3 \times 9 = 27 \neq 12$).
- Pour $3x = 2$, la solution est $\frac{2}{3}$ et non $\frac{3}{2}$ : le nombre à partager ($2$) s'écrit au numérateur.
:::

## III. Résoudre un problème

### 1. La méthode

::: methode Mettre un problème en équation
1. **Choisir l'inconnue** : écrire ce que représente la lettre, avec son unité.
2. **Traduire** l'énoncé par une égalité ; un schéma en barres aide à voir l'opération.
3. **Résoudre** grâce à l'opération inverse.
4. **Vérifier** la réponse dans l'énoncé, puis **conclure** par une phrase avec l'unité.
:::

### 2. Deux exemples

::: exemple Le prix d'un livre
Noé avait $40$ €. Il achète un livre et il lui reste $12{,}50$ €. Quel est le prix du livre ?

[IMAGE_3]

1. Soit $x$ le prix du livre, en euros.
2. Le prix du livre et l'argent restant font $40$ € : $x + 12{,}50 = 40$.
3. $x = 40 - 12{,}50 = 27{,}50$.
4. Vérification : $27{,}50 + 12{,}50 = 40$. Le livre coûte $27{,}50$ €.
:::

::: exemple Des étagères bien remplies
Un libraire range $168$ livres sur $7$ étagères qui contiennent toutes le même nombre de livres. Combien de livres y a-t-il par étagère ?

[IMAGE_4]

1. Soit $n$ le nombre de livres sur une étagère.
2. Les $7$ étagères contiennent $168$ livres : $7n = 168$.
3. $n = 168 \div 7 = 24$.
4. Vérification : $7 \times 24 = 168$. Il y a $24$ livres par étagère.
:::

::: attention La réponse doit avoir un sens
Une fois l'égalité vérifiée, on contrôle la réponse dans la situation : un prix ou une longueur ne peut pas être négatif, un nombre de personnes ou d'objets doit être un nombre entier.
:::

### 3. Remonter deux opérations

Certains problèmes enchaînent deux opérations. On les défait **une par une, en partant de la dernière**.

::: exemple Des cahiers et une règle
Lou achète $3$ cahiers identiques et une règle à $2$ €. Elle paie $11$ €. Quel est le prix d'un cahier ?

[IMAGE_5]

- Sans la règle, les $3$ cahiers coûtent $11 - 2 = 9$ €.
- Un cahier coûte donc $9 \div 3 = 3$ €.
- Vérification : $3 \times 3 + 2 = 9 + 2 = 11$. Un cahier coûte $3$ €.

On peut aussi procéder **par essais** : avec $2$ €, on paierait $3 \times 2 + 2 = 8$ € (trop peu) ; avec $3$ €, on paie $11$ € : c'est la réponse.
:::

::: remarque Pour aller plus loin
La situation de Lou se traduit par l'équation $3x + 2 = 11$. La résolution méthodique de ce type d'équation sera étudiée en 4e.

Vers l'an $820$, à Bagdad, le savant al-Khwarizmi appelait le nombre cherché « la chose ». Le mot « algèbre » vient du titre de son livre (*al-jabr*).
:::

::: retenir
- Une **équation** est une égalité contenant une inconnue ; une **solution** est un nombre qui rend l'égalité vraie.
- $x + b = c$ donne $x = c - b$ ; $ax = c$ donne $x = \frac{c}{a}$ ; $\frac{x}{a} = c$ donne $x = c \times a$.
- On **vérifie** toujours en remplaçant la lettre par la valeur trouvée, puis on répond avec l'unité.
:::
