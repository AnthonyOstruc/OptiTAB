<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Cercle trigonométrique et radian</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Cercle trigonométrique</strong></p>
<p style="margin:5px 0 0 0;">Le <strong>cercle trigonométrique</strong> est le cercle de centre $\displaystyle O$ (origine du repère) et de rayon $\displaystyle 1$, orienté dans le sens <strong>trigonométrique</strong> (sens inverse des aiguilles d'une montre).</p>
<p style="margin:5px 0 0 0;">Il est muni d'un repère orthonormé $\displaystyle (O, \vec{i}, \vec{j})$ où :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Le point $\displaystyle I(1, 0)$ est le point d'intersection du cercle avec l'axe des abscisses positifs</li>
<li style="margin:0;">Le point $\displaystyle J(0, 1)$ est le point d'intersection du cercle avec l'axe des ordonnées positifs</li>
</ul>
</div>
</div>

<div style="text-align:center; margin:20px 0;">

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Radian</strong></p>
<p style="margin:5px 0 0 0;">Le <strong>radian</strong> est l'unité de mesure d'angle définie par :</p>
<p style="margin:5px 0 0 0;">Un angle de $\displaystyle 1$ radian intercepte un arc de longueur $\displaystyle 1$ sur le cercle trigonométrique.</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle 180° = \pi$ radians</p>
</div>
<p style="margin:5px 0 0 0;">Donc : $\displaystyle 1° = \frac{\pi}{180}$ radians et $\displaystyle 1$ radian $= \frac{180}{\pi}° \approx 57,3°$</p>
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>⚠️ Important :</strong> Sauf indication contraire, les angles sont exprimés en <strong>radians</strong> dans ce cours.</p>
</div>

<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Principe de l'enroulement</strong></p>
<p style="margin:5px 0 0 0;">On enroule la droite numérique sur le cercle trigonométrique :</p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">On place l'origine $\displaystyle 0$ de la droite au point $\displaystyle I(1, 0)$</li>
<li style="margin:0 0 8px 0;">On enroule la droite dans le sens trigonométrique pour les réels positifs</li>
<li style="margin:0 0 8px 0;">On enroule dans le sens opposé (sens horaire) pour les réels négatifs</li>
<li style="margin:0;">Chaque réel $\displaystyle x$ a une <strong>image unique</strong> sur le cercle, notée $\displaystyle M(x)$</li>
</ol>
<p style="margin:5px 0 0 0;">La longueur de l'arc $\displaystyle \overset{\frown}{IM}$ est égale à $\displaystyle |x|$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Cosinus et sinus d'un nombre réel</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Cosinus et sinus</strong></p>
<p style="margin:5px 0 0 0;">Pour tout réel $\displaystyle x$, soit $\displaystyle M(x)$ le point image de $\displaystyle x$ sur le cercle trigonométrique.</p>
<p style="margin:5px 0 0 0;">Les coordonnées de $\displaystyle M(x)$ sont :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;"><strong>Cosinus :</strong> $\displaystyle \cos(x)$ est l'<strong>abscisse</strong> du point $\displaystyle M(x)$</li>
<li style="margin:0;"><strong>Sinus :</strong> $\displaystyle \sin(x)$ est l'<strong>ordonnée</strong> du point $\displaystyle M(x)$</li>
</ul>
<p style="margin:5px 0 0 0;">On a donc : $\displaystyle M(x) = (\cos(x), \sin(x))$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e0f2f1; border-left:4px solid #00897b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Relation fondamentale</strong></p>
<p style="margin:5px 0 0 0;">Comme $\displaystyle M(x)$ est sur le cercle trigonométrique (de rayon $\displaystyle 1$), on a :</p>
<div style="background:#e0f2f1; border:3px solid #00897b; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \cos^2(x) + \sin^2(x) = 1$</p>
</div>
<p style="margin:5px 0 0 0;">Cette relation est vraie pour tout réel $\displaystyle x$.</p>
</div>
</div>

<li style="margin:0 0 8px 0;"><strong>Supplémentaire :</strong> $\displaystyle \cos(\pi - x) = -\cos(x)$ et $\displaystyle \sin(\pi - x) = \sin(x)$</li>
<li style="margin:0 0 8px 0;"><strong>Complémentaire :</strong> $\displaystyle \cos\left(\frac{\pi}{2} - x\right) = \sin(x)$ et $\displaystyle \sin\left(\frac{\pi}{2} - x\right) = \cos(x)$</li>
<li style="margin:0;"><strong>Déphasage de $\displaystyle \pi$ :</strong> $\displaystyle \cos(\pi + x) = -\cos(x)$ et $\displaystyle \sin(\pi + x) = -\sin(x)$</li>
</ul>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonctions cosinus et sinus</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Fonctions cosinus et sinus</strong></p>
<p style="margin:5px 0 0 0;">Les fonctions <strong>cosinus</strong> et <strong>sinus</strong> sont les fonctions définies sur $\displaystyle \mathbb{R}$ par :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">$\displaystyle x \mapsto \cos(x)$ : fonction cosinus</li>
<li style="margin:0;">$\displaystyle x \mapsto \sin(x)$ : fonction sinus</li>
</ul>
<p style="margin:5px 0 0 0;">Pour tout réel $\displaystyle x$ : $\displaystyle -1 \leq \cos(x) \leq 1$ et $\displaystyle -1 \leq \sin(x) \leq 1$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Propriété</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Cosinus et Sinus</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;"><strong>Parité</strong></td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \cos(-x) = \cos(x)$ : <strong>paire</strong><br/>$\displaystyle \sin(-x) = -\sin(x)$ : <strong>impaire</strong></td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;"><strong>Périodicité</strong></td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Période : $\displaystyle 2\pi$<br/>$\displaystyle \cos(x + 2k\pi) = \cos(x)$<br/>$\displaystyle \sin(x + 2k\pi) = \sin(x)$ pour tout $\displaystyle k \in \mathbb{Z}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;"><strong>Image</strong></td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle [-1, 1]$ pour les deux fonctions</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;"><strong>Zéros</strong></td>
<td style="border:none; padding:18px 16px;">$\displaystyle \cos(x) = 0 \Leftrightarrow x = \frac{\pi}{2} + k\pi$<br/>$\displaystyle \sin(x) = 0 \Leftrightarrow x = k\pi$<br/>avec $\displaystyle k \in \mathbb{Z}$</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Conséquence de la périodicité :</strong></p>
<p style="margin:5px 0 0 0;">Pour étudier les fonctions cosinus et sinus, il suffit de les étudier sur un intervalle de longueur $\displaystyle 2\pi$, par exemple $\displaystyle [0, 2\pi[$ ou $\displaystyle [-\pi, \pi[$.</p>
<p style="margin:5px 0 0 0;">La courbe complète s'obtient ensuite par <strong>translations horizontales</strong> de $\displaystyle 2\pi$.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Courbe représentative de la fonction cosinus</strong></p>
<p style="margin:5px 0 0 0;"><strong>Période :</strong> $\displaystyle 2\pi$ (la courbe se répète tous les $\displaystyle 2\pi$)</p>
<p style="margin:5px 0 0 0;"><strong>Caractéristiques :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Passe par le point $\displaystyle (0, 1)$</li>
<li style="margin:0 0 8px 0;">Symétrique par rapport à l'axe des ordonnées (fonction paire)</li>
<li style="margin:0 0 8px 0;">Décroissante sur $\displaystyle [0, \pi]$ et croissante sur $\displaystyle [\pi, 2\pi]$</li>
<li style="margin:0;">Minimum en $\displaystyle (\pi, -1)$ et maximum en $\displaystyle (0, 1)$ et $\displaystyle (2\pi, 1)$</li>
</ul>
</div>
</div>

<div style="text-align:center; margin:20px 0;">

</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Courbe représentative de la fonction sinus</strong></p>
<p style="margin:5px 0 0 0;"><strong>Période :</strong> $\displaystyle 2\pi$ (la courbe se répète tous les $\displaystyle 2\pi$)</p>
<p style="margin:5px 0 0 0;"><strong>Caractéristiques :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Passe par l'origine $\displaystyle (0, 0)$</li>
<li style="margin:0 0 8px 0;">Symétrique par rapport à l'origine du repère (fonction impaire)</li>
<li style="margin:0 0 8px 0;">Croissante sur $\displaystyle \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ et décroissante sur $\displaystyle \left[\frac{\pi}{2}, \frac{3\pi}{2}\right]$</li>
<li style="margin:0;">Maximum en $\displaystyle \left(\frac{\pi}{2}, 1\right)$ et minimum en $\displaystyle \left(-\frac{\pi}{2}, -1\right)$ et $\displaystyle \left(\frac{3\pi}{2}, -1\right)$</li>
</ul>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Lecture sur le cercle trigonométrique</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Méthode pour déterminer cosinus et sinus :</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Placer le point $\displaystyle M(x)$ sur le cercle trigonométrique en utilisant l'enroulement</li>
<li style="margin:0 0 8px 0;">Déterminer le quadrant dans lequel se trouve $\displaystyle M(x)$</li>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">

<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre cosinus et sinus</td>

<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre la parité</td>

</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Confondre degrés et radians</td>

</tr>

<p style="margin:5px 0 0 0;">Le cosinus est positif dans le premier et quatrième quadrant.</p>
<p style="margin:5px 0 0 0;">Solutions dans $\displaystyle [0, 2\pi[$ :</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">

</ul>
<p style="margin:5px 0 0 0;">Solutions générales : $\displaystyle x = \frac{\pi}{3} + 2k\pi$ ou $\displaystyle x = \frac{5\pi}{3} + 2k\pi$ avec $\displaystyle k \in \mathbb{Z}$</p>
