<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Proportionnalité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Tableau</strong> : tous les quotients sont égaux (coefficient de proportionnalité).</p>
<p style="margin:6px 0 0 0;">• <strong>Graphique</strong> : points alignés avec l'origine.</p>
[IMAGE_1]
<p style="margin:6px 0 0 0;">• <strong>Quatrième proportionnelle</strong> : $\displaystyle \frac{6}{9{,}60} = \frac{9}{?}$ donne $? = \frac{9 \times 9{,}60}{6} = 14{,}40$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Pourcentages et évolutions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $t$ % de $A$ $= \frac{t}{100} \times A$ ; part en % $= \frac{\text{partie}}{\text{total}} \times 100$.</p>
[IMAGE_2]
<p style="margin:6px 0 0 0;">• Hausse de $t$ % : $\times \left(1 + \frac{t}{100}\right)$ ; baisse : $\times \left(1 - \frac{t}{100}\right)$.</p>
<p style="margin:6px 0 0 0;">• Prix initial : on <strong>divise</strong> par le coefficient.</p>
<p style="margin:6px 0 0 0;">• <strong>Échelle</strong> = longueur plan : longueur réelle (même unité).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Croire qu'une droite est toujours proportionnelle : il faut qu'elle passe par l'origine.</p>
<p style="margin:6px 0 0 0;">2️⃣ Additionner des pourcentages successifs : $-30$ % puis $-20$ % donnent $-44$ %, pas $-50$ %.</p>
<p style="margin:6px 0 0 0;">3️⃣ Retrouver un prix avant une baisse de $15$ % en ajoutant $15$ % : il faut diviser par $0{,}85$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Calculer une échelle avec des unités différentes.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> une évolution en pourcentage, c'est une multiplication par un coefficient : je l'écris d'abord ($\times 1{,}08$, $\times 0{,}7$…), puis je calcule.</p>
</div>
