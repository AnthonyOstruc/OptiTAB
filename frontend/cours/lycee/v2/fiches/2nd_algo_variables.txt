<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Variables et affectation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ Types : <code>int</code>, <code>float</code>, <code>str</code>, <code>bool</code>.</p>
<p style="margin:6px 0 0 0;">2️⃣ <code>=</code> affecte une valeur ; <code>==</code> teste une égalité.</p>
<p style="margin:6px 0 0 0;">3️⃣ <code>//</code> quotient entier, <code>%</code> reste, <code>&#42;&#42;</code> puissance.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Conditions et boucles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ <code>if</code> … <code>elif</code> … <code>else</code> : choisir selon une condition.</p>
<p style="margin:6px 0 0 0;">2️⃣ <code>for i in range(n)</code> : $n$ répétitions, <code>i</code> de $0$ à $n - 1$.</p>
<p style="margin:6px 0 0 0;">3️⃣ <code>while condition</code> : répéter tant que la condition est vraie.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire <code>=</code> au lieu de <code>==</code> dans une condition.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier les deux-points ou l’indentation après <code>if</code>, <code>for</code>, <code>while</code>.</p>
<p style="margin:6px 0 0 0;">3️⃣ Croire que <code>range(5)</code> va jusqu’à $5$ : il s’arrête à $4$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Écrire une boucle <code>while</code> dont la condition reste toujours vraie.</p>
</div>
