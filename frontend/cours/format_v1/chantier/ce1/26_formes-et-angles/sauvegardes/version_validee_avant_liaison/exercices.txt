===
Découverte - Trois ouvertures d’angles
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Compare les angles au coin d’une feuille ou à ton équerre.

[IMAGE_1]

1. Quel est le type de l’angle A ?
2. Quel est le type de l’angle B ?
3. Quel est le type de l’angle C ?
4. Un angle devient-il plus grand si on allonge seulement ses traits ?
5. Quel petit signe peut coder un angle droit après vérification ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel est le type de l’angle A ?

::: methode
Compare son ouverture au coin droit de l’équerre.
:::

::: etape Raisonner
Les deux bords peuvent coïncider avec ceux de l’équerre.
:::

::: resultat
A est droit.
:::

## Question 2 : Quel est le type de l’angle B ?

::: methode
Compare les ouvertures, pas les longueurs des traits.
:::

::: etape Raisonner
Son ouverture est plus petite que celle du coin droit.
:::

::: resultat
B est aigu.
:::

## Question 3 : Quel est le type de l’angle C ?

::: methode
Cherche s’il dépasse le coin droit.
:::

::: etape Raisonner
Son ouverture est plus grande que celle d’un angle droit.
:::

::: resultat
C est obtus.
:::

## Question 4 : Un angle devient-il plus grand si on allonge seulement ses traits ?

::: methode
L’angle dépend de l’ouverture entre les deux directions.
:::

::: etape Raisonner
Allonger les traits ne change pas leur ouverture.
:::

::: resultat
Non.
:::

## Question 5 : Quel petit signe peut coder un angle droit après vérification ?

::: methode
Utilise le codage de l’angle droit.
:::

::: etape Raisonner
On trace un petit carré dans le coin, sans écrire sur les côtés.
:::

::: resultat
Un petit carré.
:::

Solution:
<!-- optitab:1 -->
1. A est droit.
2. B est aigu.
3. C est obtus.
4. Non.
5. Un petit carré.

===
Découverte - Reconnaître une figure tournée
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe les figures A, B et C. Vérifie avec le coin d’une feuille et compare les longueurs sur une copie du dessin.

[IMAGE_1]

1. Comment s’appelle A ?
2. Comment s’appelle B ?
3. Comment s’appelle C ?
4. Pourquoi A est-il encore un carré alors qu’il est penché ?
5. Quel instrument sert à contrôler les angles droits ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment s’appelle A ?

::: methode
Cherche quatre côtés égaux et quatre angles droits.
:::

::: etape Raisonner
A possède ces deux propriétés, même en étant tournée.
:::

::: resultat
Un carré.
:::

## Question 2 : Comment s’appelle B ?

::: methode
Observe ses quatre angles droits et ses côtés opposés.
:::

::: etape Raisonner
Deux côtés voisins sont de longueurs différentes.
:::

::: resultat
Un rectangle qui n’est pas carré.
:::

## Question 3 : Comment s’appelle C ?

::: methode
Compte ses côtés et repère son angle droit.
:::

::: etape Raisonner
La figure a trois côtés et un angle droit.
:::

::: resultat
Un triangle rectangle.
:::

## Question 4 : Pourquoi A est-il encore un carré alors qu’il est penché ?

::: methode
Tourner ne change pas les longueurs ni les angles.
:::

::: etape Raisonner
Les quatre côtés égaux et les quatre angles droits sont conservés.
:::

::: resultat
Parce que ses propriétés n’ont pas changé.
:::

## Question 5 : Quel instrument sert à contrôler les angles droits ?

::: methode
Choisis l’outil qui possède un coin droit.
:::

::: etape Raisonner
L’équerre permet de comparer les ouvertures au coin droit.
:::

::: resultat
Une équerre.
:::

Solution:
<!-- optitab:1 -->
1. Un carré.
2. Un rectangle qui n’est pas carré.
3. Un triangle rectangle.
4. Parce que ses propriétés n’ont pas changé.
5. Une équerre.

===
Découverte - Décrire un rectangle
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Imagine ou trace un rectangle sur une feuille.

1. Combien de côtés a-t-il ?
2. Combien de sommets a-t-il ?
3. Combien d’angles droits a-t-il ?
4. Quels côtés ont la même longueur ?
5. Un carré est-il aussi un rectangle ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de côtés a-t-il ?

::: methode
Suis tout le bord de la figure.
:::

::: etape Raisonner
Le contour comporte quatre segments.
:::

::: resultat
4 côtés.
:::

## Question 2 : Combien de sommets a-t-il ?

::: methode
Compte les coins sans compter deux fois le départ.
:::

::: etape Raisonner
Chaque rencontre de deux côtés forme un sommet.
:::

::: resultat
4 sommets.
:::

## Question 3 : Combien d’angles droits a-t-il ?

::: methode
Contrôle les quatre coins avec l’équerre.
:::

::: etape Raisonner
Chaque coin du rectangle est droit.
:::

::: resultat
4 angles droits.
:::

## Question 4 : Quels côtés ont la même longueur ?

::: methode
Observe les côtés qui se font face.
:::

::: etape Raisonner
Les deux grands côtés sont égaux et les deux petits aussi.
:::

::: resultat
Les côtés opposés.
:::

## Question 5 : Un carré est-il aussi un rectangle ?

::: methode
Vérifie les propriétés du rectangle.
:::

::: etape Raisonner
Un carré possède bien quatre angles droits.
:::

::: resultat
Oui, c’est un rectangle particulier.
:::

Solution:
<!-- optitab:1 -->
1. 4 côtés.
2. 4 sommets.
3. 4 angles droits.
4. Les côtés opposés.
5. Oui, c’est un rectangle particulier.

===
Entraînement - Tracer et coder un angle droit
Id: nouveau-4
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Prépare une règle, une équerre et une feuille.

1. Comment traces-tu le premier côté de l’angle ?
2. Où places-tu le coin droit de l’équerre ?
3. Comment alignes-tu l’équerre ?
4. Comment traces-tu le second côté ?
5. Quel codage ajoutes-tu après contrôle ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment traces-tu le premier côté de l’angle ?

::: methode
Commence par un trait droit avec un point de départ A.
:::

::: etape Raisonner
Place le bord de la règle et trace un premier segment à partir de A.
:::

::: resultat
Avec une règle, à partir de A.
:::

## Question 2 : Où places-tu le coin droit de l’équerre ?

::: methode
Les deux côtés de l’angle doivent se rencontrer en A.
:::

::: etape Raisonner
Pose le coin droit sur le point A.
:::

::: resultat
Sur A.
:::

## Question 3 : Comment alignes-tu l’équerre ?

::: methode
Un bord doit suivre le premier segment.
:::

::: etape Raisonner
Garde un bord de l’équerre contre le trait déjà dessiné.
:::

::: resultat
Un bord sur le premier segment.
:::

## Question 4 : Comment traces-tu le second côté ?

::: methode
Utilise l’autre bord du coin droit.
:::

::: etape Raisonner
Trace depuis A le long de ce second bord, puis vérifie la coïncidence des deux côtés.
:::

::: resultat
Le long de l’autre bord de l’équerre.
:::

## Question 5 : Quel codage ajoutes-tu après contrôle ?

::: methode
Indique que l’angle a été vérifié droit.
:::

::: etape Raisonner
Un petit carré dans le coin est le codage adapté.
:::

::: resultat
Un petit carré dans l’angle.
:::

Solution:
<!-- optitab:1 -->
1. Avec une règle, à partir de A.
2. Sur A.
3. Un bord sur le premier segment.
4. Le long de l’autre bord de l’équerre.
5. Un petit carré dans l’angle.

===
Entraînement - Quatre côtés égaux ne suffisent pas
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un quadrilatère a quatre côtés de même longueur, mais aucun de ses angles n’est droit.

1. Combien de côtés possède un quadrilatère ?
2. Quelle propriété du carré possède cette figure ?
3. Quelle propriété du carré manque-t-il ?
4. Peut-on l’appeler un carré ?
5. Comment vérifies-tu ce qui manque avec un outil ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de côtés possède un quadrilatère ?

::: methode
Le mot désigne une figure à quatre côtés.
:::

::: etape Raisonner
On compte quatre segments sur son contour.
:::

::: resultat
4 côtés.
:::

## Question 2 : Quelle propriété du carré possède cette figure ?

::: methode
Regarde les longueurs données.
:::

::: etape Raisonner
Tous ses côtés ont la même longueur.
:::

::: resultat
Quatre côtés égaux.
:::

## Question 3 : Quelle propriété du carré manque-t-il ?

::: methode
Un carré a aussi des coins droits.
:::

::: etape Raisonner
Les angles de la figure ne sont pas droits.
:::

::: resultat
Les quatre angles droits.
:::

## Question 4 : Peut-on l’appeler un carré ?

::: methode
Les deux propriétés doivent être vérifiées ensemble.
:::

::: etape Raisonner
Avoir quatre côtés égaux ne remplace pas le contrôle des angles.
:::

::: resultat
Non.
:::

## Question 5 : Comment vérifies-tu ce qui manque avec un outil ?

::: methode
Compare les coins au gabarit d’un angle droit.
:::

::: etape Raisonner
Pose l’équerre sur chaque sommet ; les deux bords ne coïncident pas avec ceux de l’angle.
:::

::: resultat
Avec l’équerre, à chaque sommet.
:::

Solution:
<!-- optitab:1 -->
1. 4 côtés.
2. Quatre côtés égaux.
3. Les quatre angles droits.
4. Non.
5. Avec l’équerre, à chaque sommet.

Entraînement - Dessiner un triangle rectangle
Id: nouveau-6
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur une feuille, trace un triangle ABC rectangle en A : AB mesure 4 cm et AC mesure 3 cm.

1. Par quel segment peux-tu commencer ?
2. Où places-tu le coin droit de l’équerre ?
3. Comment places-tu C ?
4. Comment fermes-tu le triangle ?
5. Comment contrôles-tu puis codes-tu l’angle droit ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Par quel segment peux-tu commencer ?

::: methode
Choisis un côté de l’angle droit.
:::

::: etape Raisonner
Trace AB avec une règle et marque les deux extrémités.
:::

::: resultat
Par AB de 4 cm.
:::

## Question 2 : Où places-tu le coin droit de l’équerre ?

::: methode
L’angle droit demandé est en A.
:::

::: etape Raisonner
Le coin doit coïncider avec A et un bord doit suivre AB.
:::

::: resultat
En A.
:::

## Question 3 : Comment places-tu C ?

::: methode
Trace trois centimètres sur l’autre bord du coin droit.
:::

::: etape Raisonner
C est à 3 cm de A sur la direction perpendiculaire à AB.
:::

::: resultat
À 3 cm de A, sur l’autre bord de l’équerre.
:::

## Question 4 : Comment fermes-tu le triangle ?

::: methode
Relie les deux extrémités libres.
:::

::: etape Raisonner
Trace le segment BC.
:::

::: resultat
En reliant B à C.
:::

## Question 5 : Comment contrôles-tu puis codes-tu l’angle droit ?

::: methode
Replace l’équerre dans le coin A.
:::

::: etape Raisonner
Les deux côtés doivent suivre les deux bords du coin droit ; ajoute alors un petit carré en A.
:::

::: etape Vérifier
[IMAGE_1]
:::

::: resultat
L’angle A est droit et se code par un petit carré.
:::

Solution:
<!-- optitab:1 -->
1. Par AB de 4 cm.
2. En A.
3. À 3 cm de A, sur l’autre bord de l’équerre.
4. En reliant B à C.
5. L’angle A est droit et se code par un petit carré.

Problème - Cinq côtés et des sommets
Id: nouveau-7
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une forme fermée a cinq côtés droits, qui ne se croisent pas.

[IMAGE_1]

1. Combien de côtés comptes-tu ?
2. Combien de sommets comptes-tu ?
3. Quel est le nom d’un polygone à cinq côtés ?
4. Le nombre de sommets change-t-il si tu tournes la feuille ?
5. Comment évites-tu de compter deux fois le même sommet ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de côtés comptes-tu ?

::: methode
Suis le bord une seule fois.
:::

::: etape Raisonner
Tu rencontres cinq segments avant de revenir au départ.
:::

::: resultat
5 côtés.
:::

## Question 2 : Combien de sommets comptes-tu ?

::: methode
Compte le coin entre chaque paire de côtés voisins.
:::

::: etape Raisonner
Les cinq rencontres de côtés donnent cinq sommets.
:::

::: resultat
5 sommets.
:::

## Question 3 : Quel est le nom d’un polygone à cinq côtés ?

::: methode
Utilise le nom lié au nombre de côtés.
:::

::: etape Raisonner
Une figure à cinq côtés s’appelle un pentagone.
:::

::: resultat
Un pentagone.
:::

## Question 4 : Le nombre de sommets change-t-il si tu tournes la feuille ?

::: methode
Tourner n’ajoute aucun coin.
:::

::: etape Raisonner
La figure garde tous ses segments et tous ses coins.
:::

::: resultat
Non, il reste cinq sommets.
:::

## Question 5 : Comment évites-tu de compter deux fois le même sommet ?

::: methode
Garde un point de départ.
:::

::: etape Raisonner
Marque le premier coin puis arrête le comptage lorsque tu y reviens.
:::

::: resultat
En marquant le départ et en suivant le contour dans l’ordre.
:::

Solution:
<!-- optitab:1 -->
1. 5 côtés.
2. 5 sommets.
3. Un pentagone.
4. Non, il reste cinq sommets.
5. En marquant le départ et en suivant le contour dans l’ordre.

===
Problème - Chercher des angles autour de soi
Id: nouveau-8
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Cherche dans ta classe ou chez toi deux angles droits et un angle qui ne soit pas droit. Utilise le coin d’une feuille comme gabarit.

1. Quel objet peut fournir un premier angle droit ?
2. Quel objet peut fournir un autre angle droit ?
3. Comment cherches-tu un angle non droit ?
4. Comment sais-tu si cet angle est aigu ou obtus ?
5. Pourquoi faut-il utiliser le gabarit même si le coin semble droit ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel objet peut fournir un premier angle droit ?

::: methode
Pense à une feuille rectangulaire.
:::

::: etape Raisonner
Un coin de feuille peut coïncider avec le gabarit droit.
:::

::: resultat
Par exemple un coin de feuille, après vérification.
:::

## Question 2 : Quel objet peut fournir un autre angle droit ?

::: methode
Observe un cahier ou un meuble rectangulaire.
:::

::: etape Raisonner
Un coin de couverture de cahier peut aussi coïncider avec le gabarit.
:::

::: resultat
Par exemple un coin de cahier, après vérification.
:::

## Question 3 : Comment cherches-tu un angle non droit ?

::: methode
Essaie une ouverture de ciseaux, avec un adulte si nécessaire.
:::

::: etape Raisonner
Une ouverture plus petite ou plus grande que le coin de la feuille ne coïncide pas avec lui.
:::

::: resultat
Une ouverture de ciseaux qui ne coïncide pas avec le gabarit.
:::

## Question 4 : Comment sais-tu si cet angle est aigu ou obtus ?

::: methode
Compare seulement l’ouverture.
:::

::: etape Raisonner
Plus petite que le coin droit : aigu ; plus grande : obtus.
:::

::: resultat
Aigu s’il est moins ouvert ; obtus s’il est plus ouvert.
:::

## Question 5 : Pourquoi faut-il utiliser le gabarit même si le coin semble droit ?

::: methode
L’apparence peut tromper.
:::

::: etape Raisonner
Le gabarit permet de vérifier les deux directions de l’angle.
:::

::: resultat
Pour contrôler au lieu de se fier seulement au regard.
:::

Solution:
<!-- optitab:1 -->
1. Par exemple un coin de feuille, après vérification.
2. Par exemple un coin de cahier, après vérification.
3. Une ouverture de ciseaux qui ne coïncide pas avec le gabarit.
4. Aigu s’il est moins ouvert ; obtus s’il est plus ouvert.
5. Pour contrôler au lieu de se fier seulement au regard.

===
Problème - Un rectangle reste un rectangle
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Lina dit : « Ce rectangle est penché, donc ce n’est plus un rectangle ».

1. Tourner la feuille change-t-il les côtés de la figure ?
2. Les angles droits changent-ils ?
3. Quel nom garde la figure ?
4. Que deviennent les longueurs des côtés opposés ?
5. Corrige la phrase de Lina.

Étapes:
<!-- optitab:1 -->

## Question 1 : Tourner la feuille change-t-il les côtés de la figure ?

::: methode
Aucun morceau n’est coupé ou étiré.
:::

::: etape Raisonner
Les côtés restent exactement les mêmes.
:::

::: resultat
Non.
:::

## Question 2 : Les angles droits changent-ils ?

::: methode
Tourne aussi ton équerre pour comparer.
:::

::: etape Raisonner
Le coin droit coïncide encore avec chaque angle.
:::

::: resultat
Non, ils restent droits.
:::

## Question 3 : Quel nom garde la figure ?

::: methode
Utilise ses propriétés conservées.
:::

::: etape Raisonner
Elle a toujours quatre angles droits.
:::

::: resultat
Un rectangle.
:::

## Question 4 : Que deviennent les longueurs des côtés opposés ?

::: methode
La rotation ne change aucune longueur.
:::

::: etape Raisonner
Les côtés qui se font face restent de même longueur.
:::

::: resultat
Elles restent égales.
:::

## Question 5 : Corrige la phrase de Lina.

::: methode
Explique pourquoi l’orientation ne change pas le nom.
:::

::: etape Raisonner
Pour reconnaître un rectangle, il faut vérifier ses propriétés, quelle que soit sa position.
:::

::: resultat
Un rectangle tourné reste un rectangle.
:::

Solution:
<!-- optitab:1 -->
1. Non.
2. Non, ils restent droits.
3. Un rectangle.
4. Elles restent égales.
5. Un rectangle tourné reste un rectangle.
