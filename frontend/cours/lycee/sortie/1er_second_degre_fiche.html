📚 Objectif pédagogique : retenir l’essentiel : les trois formes d’un trinôme, le discriminant, les racines et le signe. Programme de Première.

I. Les trois formes d’un trinôme

$\displaystyle ax^2+bx+c \;=\; a(x-\alpha)^2+\beta \;=\; a(x-x_1)(x-x_2)$

[IMAGE_1]

• Développée : calculer une image ; $\displaystyle f(0)=c$.

• Canonique : sommet $\displaystyle S(\alpha\,;\beta)$ avec $\displaystyle \alpha=-\frac{b}{2a}$, $\displaystyle \beta=f(\alpha)$ → extremum et variations.

• Factorisée : racines $\displaystyle x_1$ et $\displaystyle x_2$ → équations et signe.

II. Discriminant, racines et signe

$\displaystyle \Delta=b^2-4ac$

[IMAGE_2]

1️⃣ $\displaystyle \Delta>0$ : $\displaystyle x_1=\frac{-b-\sqrt{\Delta}}{2a}$ et $\displaystyle x_2=\frac{-b+\sqrt{\Delta}}{2a}$.

2️⃣ $\displaystyle \Delta=0$ : une racine double $\displaystyle x_0=-\frac{b}{2a}$ ; $\displaystyle \Delta<0$ : aucune racine réelle.

3️⃣ Signe : $\displaystyle f(x)$ a le signe de $\displaystyle a$ partout, sauf entre les racines.

4️⃣ Contrôle : $\displaystyle x_1+x_2=-\frac{b}{a}$ et $\displaystyle x_1x_2=\frac{c}{a}$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Oublier le coefficient $\displaystyle a$ dans la forme factorisée : $\displaystyle 2x^2+4x-6=2(x-1)(x+3)$, pas $\displaystyle (x-1)(x+3)$.

2️⃣ Mal calculer $\displaystyle b^2$ quand $\displaystyle b<0$ : $\displaystyle (-5)^2=25$, pas $\displaystyle -25$.

3️⃣ Conclure « aucune racine » quand $\displaystyle \Delta=0$ : il y a une racine double.

4️⃣ Se tromper de signe : pour $\displaystyle a>0$, le trinôme est négatif entre les racines.

🏆 Réflexe : équation $\displaystyle ax^2+bx+c=0$ → racine évidente ou $\displaystyle \Delta$ ; inéquation → forme factorisée et signe de $\displaystyle a$ ; maximum ou minimum → forme canonique (sommet).
