    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Fonction définie sur un intervalle ou une réunion d'intervalles</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction à valeurs réelles</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>fonction à valeurs réelles</strong> est définie sur un ensemble $\displaystyle D$ (appelé <strong>domaine de définition</strong>) qui peut être :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Un <strong>intervalle</strong> de $\displaystyle \mathbb{R}$ (par exemple : $\displaystyle [0; 5]$, $\displaystyle ]-\infty; 3[$, $\displaystyle \mathbb{R}$)</li>
                <li style="margin:0; text-align:left;">Une <strong>réunion finie d'intervalles</strong> (par exemple : $\displaystyle ]-\infty; -2] \cup [3; +\infty[$ ou $\displaystyle [-1; 0] \cup [2; 5[$)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">À chaque réel $\displaystyle x$ de $\displaystyle D$, la fonction associe un unique réel noté $\displaystyle f(x)$.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Notation</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note : $\displaystyle f : D \to \mathbb{R}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle x \mapsto f(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle D$ est le domaine de définition de la fonction.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle f(x) = x^2$ définie sur $\displaystyle \mathbb{R}$ (intervalle)</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle g(x) = \sqrt{x}$ définie sur $\displaystyle [0; +\infty[$ (intervalle)</li>
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle h(x) = \frac{1}{x-1}$ définie sur $\displaystyle ]-\infty; 1[ \cup ]1; +\infty[$ (réunion de deux intervalles)</li>
                <li style="margin:0; text-align:left;">$\displaystyle k(x) = \sqrt{x-2}$ définie sur $\displaystyle [2; +\infty[$ (intervalle)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Courbe représentative</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Courbe représentative</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>courbe représentative</strong> d'une fonction $\displaystyle f$ définie sur un domaine $\displaystyle D$ est l'ensemble des points du plan dont les coordonnées $\displaystyle (x; y)$ vérifient :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:300px; font-weight:bold;">
                $\displaystyle y = f(x)$
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note cette courbe $\displaystyle \mathcal{C}_f$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation $\displaystyle y = f(x)$ est appelée <strong>équation de la courbe</strong>.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Caractérisation</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un point $\displaystyle M(x; y)$ appartient à la courbe $\displaystyle \mathcal{C}_f$ si et seulement si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">$\displaystyle x$ appartient au domaine de définition $\displaystyle D$ de $\displaystyle f$</li>
                <li style="margin:0; text-align:left;">$\displaystyle y = f(x)$</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction $\displaystyle f(x) = x^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative a pour équation $\displaystyle y = x^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A(2; 4)$ appartient à $\displaystyle \mathcal{C}_f$ car $\displaystyle 4 = 2^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle B(3; 8)$ n'appartient pas à $\displaystyle \mathcal{C}_f$ car $\displaystyle 8 \neq 3^2 = 9$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction $\displaystyle g(x) = 2x + 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative a pour équation $\displaystyle y = 2x + 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle C(1; 3)$ appartient à $\displaystyle \mathcal{C}_g$ car $\displaystyle 3 = 2 \times 1 + 1$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exploiter l'équation y = f(x)</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Vérifier l'appartenance d'un point :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour vérifier si un point $\displaystyle A(x_A; y_A)$ appartient à la courbe $\displaystyle \mathcal{C}_f$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Vérifier que $\displaystyle x_A$ appartient au domaine de définition $\displaystyle D$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Calculer $\displaystyle f(x_A)$</li>
                <li style="margin:0; text-align:left;">Vérifier que $\displaystyle y_A = f(x_A)$</li>
            </ol>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Calculer une coordonnée manquante :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Cas 1 :</strong> L'abscisse est connue, on cherche l'ordonnée</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle A(x_A; ?)$ appartient à $\displaystyle \mathcal{C}_f$, alors l'ordonnée est $\displaystyle y_A = f(x_A)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Cas 2 :</strong> L'ordonnée est connue, on cherche l'abscisse</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle A(?; y_A)$ appartient à $\displaystyle \mathcal{C}_f$, alors on résout l'équation $\displaystyle f(x) = y_A$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction $\displaystyle f(x) = x^2 - 3x + 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A(2; ?)$ appartient à $\displaystyle \mathcal{C}_f$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ordonnée est : $\displaystyle y_A = f(2) = 2^2 - 3 \times 2 + 2 = 4 - 6 + 2 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle A(2; 0)$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction $\displaystyle g(x) = 2x - 5$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle B(?; 3)$ appartient à $\displaystyle \mathcal{C}_g$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On résout : $\displaystyle 2x - 5 = 3 \Longleftrightarrow 2x = 8 \Longleftrightarrow x = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle B(4; 3)$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonctions paires et impaires</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction paire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ définie sur un domaine $\displaystyle D$ est dite <strong>paire</strong> si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Pour tout $\displaystyle x \in D$, on a $\displaystyle -x \in D$ (le domaine est symétrique par rapport à 0)</li>
                <li style="margin:0; text-align:left;">Pour tout $\displaystyle x \in D$, on a $\displaystyle f(-x) = f(x)$</li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction impaire</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ définie sur un domaine $\displaystyle D$ est dite <strong>impaire</strong> si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Pour tout $\displaystyle x \in D$, on a $\displaystyle -x \in D$ (le domaine est symétrique par rapport à 0)</li>
                <li style="margin:0; text-align:left;">Pour tout $\displaystyle x \in D$, on a $\displaystyle f(-x) = -f(x)$</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Traduction géométrique</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Fonction paire :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative $\displaystyle \mathcal{C}_f$ d'une fonction paire est <strong>symétrique par rapport à l'axe des ordonnées</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle M(x; f(x))$ appartient à $\displaystyle \mathcal{C}_f$, alors $\displaystyle M'(-x; f(x))$ appartient aussi à $\displaystyle \mathcal{C}_f$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Fonction impaire :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La courbe représentative $\displaystyle \mathcal{C}_f$ d'une fonction impaire est <strong>symétrique par rapport à l'origine</strong> du repère.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle M(x; f(x))$ appartient à $\displaystyle \mathcal{C}_f$, alors $\displaystyle M'(-x; -f(x))$ appartient aussi à $\displaystyle \mathcal{C}_f$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction carré $\displaystyle f(x) = x^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}$ : $\displaystyle f(-x) = (-x)^2 = x^2 = f(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction carré est <strong>paire</strong>. Sa courbe est symétrique par rapport à l'axe des ordonnées.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction cube $\displaystyle g(x) = x^3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}$ : $\displaystyle g(-x) = (-x)^3 = -x^3 = -g(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction cube est <strong>impaire</strong>. Sa courbe est symétrique par rapport à l'origine.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Fonction inverse $\displaystyle h(x) = \frac{1}{x}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}^*$ : $\displaystyle h(-x) = \frac{1}{-x} = -\frac{1}{x} = -h(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction inverse est <strong>impaire</strong>. Sa courbe est symétrique par rapport à l'origine.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Résoudre f(x) = k et f(x) < k</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de résolution</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Choisir une méthode adaptée :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) = k$ ou $\displaystyle f(x) < k$, on peut utiliser :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Méthode graphique :</strong> Tracer la courbe $\displaystyle \mathcal{C}_f$ et la droite horizontale $\displaystyle y = k$, puis lire les solutions</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Méthode algébrique :</strong> Résoudre directement l'équation ou l'inéquation par le calcul</li>
                <li style="margin:0; text-align:left;"><strong>Méthode logicielle :</strong> Utiliser un logiciel de calcul formel ou une calculatrice graphique</li>
            </ul>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode graphique - Résoudre f(x) = k :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la courbe $\displaystyle \mathcal{C}_f$ représentative de $\displaystyle f$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la droite horizontale d'équation $\displaystyle y = k$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les points d'intersection entre $\displaystyle \mathcal{C}_f$ et la droite</li>
                <li style="margin:0; text-align:left;">Lire les abscisses de ces points d'intersection : ce sont les solutions</li>
            </ol>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode graphique - Résoudre f(x) < k :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la courbe $\displaystyle \mathcal{C}_f$ représentative de $\displaystyle f$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la droite horizontale d'équation $\displaystyle y = k$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les parties de $\displaystyle \mathcal{C}_f$ situées <strong>en dessous</strong> de la droite</li>
                <li style="margin:0; text-align:left;">Lire les abscisses correspondantes : ce sont les solutions</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle f(x) > k$, repérer les parties de $\displaystyle \mathcal{C}_f$ situées <strong>au-dessus</strong> de la droite.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Résoudre $\displaystyle x^2 = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode algébrique :</strong> $\displaystyle x^2 = 4 \Longleftrightarrow x = 2$ ou $\displaystyle x = -2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les solutions sont $\displaystyle S = \{-2; 2\}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode graphique :</strong> Tracer $\displaystyle y = x^2$ et $\displaystyle y = 4$, les intersections sont aux abscisses $\displaystyle -2$ et $\displaystyle 2$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Résoudre $\displaystyle 2x + 1 < 5$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode algébrique :</strong> $\displaystyle 2x + 1 < 5 \Longleftrightarrow 2x < 4 \Longleftrightarrow x < 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = ]-\infty; 2[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode graphique :</strong> Tracer $\displaystyle y = 2x + 1$ et $\displaystyle y = 5$, la partie de la droite en dessous de $\displaystyle y = 5$ correspond à $\displaystyle x < 2$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Équations et inéquations produit ou quotient</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Tableau de signes</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Construire un tableau de signes :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre une équation ou une inéquation produit ou quotient, on utilise un <strong>tableau de signes</strong> :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Identifier les valeurs qui annulent chaque facteur (valeurs interdites pour les quotients)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Placer ces valeurs dans l'ordre croissant sur la première ligne</li>
                <li style="margin:0 0 18px 0; text-align:left;">Étudier le signe de chaque facteur sur chaque intervalle</li>
                <li style="margin:0 0 18px 0; text-align:left;">Déterminer le signe du produit ou du quotient en utilisant la règle des signes</li>
                <li style="margin:0; text-align:left;">Conclure selon l'équation ou l'inéquation à résoudre</li>
            </ol>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Règle des signes</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Produit :</strong> Le produit de deux nombres de même signe est positif, de signes opposés est négatif</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Quotient :</strong> Le quotient a le même signe que le produit (même règle que pour le produit)</li>
                <li style="margin:0; text-align:left;"><strong>Attention :</strong> Un quotient n'est pas défini lorsque le dénominateur est nul</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> Résoudre $\displaystyle (x - 2)(x + 3) \geq 0$
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les valeurs qui annulent les facteurs sont : $\displaystyle x = 2$ et $\displaystyle x = -3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tableau de signes :</p>
            <table style="width:100%; border-collapse:collapse; margin:12px 0; border:1px solid #ddd; font-size:0.9em;">
                <tr style="background:#e8f4fd;">
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">x</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">-∞</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">-3</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">2</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">+∞</th>
                </tr>
                <tr>
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">x - 2</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#c62828;">-</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#c62828;">-</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center;">0</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32;">+</td>
                </tr>
                <tr>
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">x + 3</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#c62828;">-</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center;">0</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32;">+</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32;">+</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">(x - 2)(x + 3)</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32;">+</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center;">0</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center;">0</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32;">+</td>
                </tr>
            </table>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le produit est positif ou nul sur $\displaystyle ]-\infty; -3] \cup [2; +\infty[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = ]-\infty; -3] \cup [2; +\infty[$</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> Résoudre $\displaystyle \frac{x - 1}{x + 2} < 0$
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les valeurs qui annulent sont : $\displaystyle x = 1$ (numérateur) et $\displaystyle x = -2$ (dénominateur, valeur interdite)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tableau de signes :</p>
            <table style="width:100%; border-collapse:collapse; margin:12px 0; border:1px solid #ddd; font-size:0.9em;">
                <tr style="background:#e8f4fd;">

                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">(x - 1)/(x + 2)</td>

            <p style="margin:8px 0; text-align:left; font-size:1em;">Le quotient est négatif sur $\displaystyle ]-2; 1[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = ]-2; 1[$ (on exclut $\displaystyle -2$ car c'est une valeur interdite)</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Résoudre f(x) = g(x) et f(x) < g(x)</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de résolution</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode graphique - Résoudre f(x) = g(x) :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer les courbes représentatives $\displaystyle \mathcal{C}_f$ et $\displaystyle \mathcal{C}_g$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les points d'intersection entre les deux courbes</li>
                <li style="margin:0; text-align:left;">Lire les abscisses de ces points d'intersection : ce sont les solutions</li>
            </ol>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode graphique - Résoudre f(x) < g(x) :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer les courbes représentatives $\displaystyle \mathcal{C}_f$ et $\displaystyle \mathcal{C}_g$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer les parties où $\displaystyle \mathcal{C}_f$ est située <strong>en dessous</strong> de $\displaystyle \mathcal{C}_g$</li>
                <li style="margin:0; text-align:left;">Lire les abscisses correspondantes : ce sont les solutions</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour $\displaystyle f(x) > g(x)$, repérer les parties où $\displaystyle \mathcal{C}_f$ est située <strong>au-dessus</strong> de $\displaystyle \mathcal{C}_g$.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode algébrique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) = g(x)$ algébriquement, on résout l'équation $\displaystyle f(x) - g(x) = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour résoudre $\displaystyle f(x) < g(x)$ algébriquement, on résout l'inéquation $\displaystyle f(x) - g(x) < 0$.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode avec outil numérique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut utiliser :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Une calculatrice graphique pour visualiser les courbes et lire les intersections</li>
                <li style="margin:0 0 18px 0; text-align:left;">Un logiciel de géométrie dynamique (GeoGebra, Desmos, etc.)</li>
                <li style="margin:0; text-align:left;">Un tableur pour créer un tableau de valeurs et identifier les solutions</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Résoudre $\displaystyle x^2 = 2x + 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode algébrique :</strong> $\displaystyle x^2 = 2x + 3 \Longleftrightarrow x^2 - 2x - 3 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On factorise : $\displaystyle x^2 - 2x - 3 = (x - 3)(x + 1) = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle x = 3$ ou $\displaystyle x = -1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les solutions sont $\displaystyle S = \{-1; 3\}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode graphique :</strong> Tracer $\displaystyle y = x^2$ et $\displaystyle y = 2x + 3$, les intersections sont aux abscisses $\displaystyle -1$ et $\displaystyle 3$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Résoudre $\displaystyle x^2 < 2x + 3$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode algébrique :</strong> $\displaystyle x^2 < 2x + 3 \Longleftrightarrow x^2 - 2x - 3 < 0 \Longleftrightarrow (x - 3)(x + 1) < 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">D'après un tableau de signes, le produit est négatif sur $\displaystyle ]-1; 3[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La solution est $\displaystyle S = ]-1; 3[$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Méthode graphique :</strong> Tracer les deux courbes, la parabole est en dessous de la droite sur $\displaystyle ]-1; 3[$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Modélisation et approfondissements</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modéliser par des fonctions</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Modélisation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour modéliser une situation par une fonction :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Identifier les variables (quantité qui varie, résultat recherché)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Déterminer le domaine de définition (valeurs possibles de la variable)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Établir la relation mathématique entre les variables</li>
                <li style="margin:0; text-align:left;">Vérifier que la fonction modélise bien la situation</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de modélisation :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Aire d'un rectangle</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle a une longueur fixe de 10 cm. On note $\displaystyle x$ la largeur (en cm) et $\displaystyle A(x)$ l'aire (en cm²).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Modèle : $\displaystyle A(x) = 10x$ pour $\displaystyle x > 0$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Distance parcourue</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un véhicule roule à vitesse constante de 60 km/h. On note $\displaystyle t$ le temps (en heures) et $\displaystyle d(t)$ la distance parcourue (en km).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Modèle : $\displaystyle d(t) = 60t$ pour $\displaystyle t \geq 0$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> Coût de production</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une entreprise a un coût fixe de 1000 € et un coût variable de 5 € par unité produite. On note $\displaystyle x$ le nombre d'unités et $\displaystyle C(x)$ le coût total (en €).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Modèle : $\displaystyle C(x) = 1000 + 5x$ pour $\displaystyle x \geq 0$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Approfondissement : Étudier la parité d'une fonction</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Étudier la parité :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour étudier la parité d'une fonction $\displaystyle f$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Vérifier que le domaine $\displaystyle D$ est symétrique par rapport à 0 (si $\displaystyle x \in D$, alors $\displaystyle -x \in D$)</li>
                <li style="margin:0 0 18px 0; text-align:left;">Calculer $\displaystyle f(-x)$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Comparer avec $\displaystyle f(x)$ :</li>
                <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                    <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle f(-x) = f(x)$ pour tout $\displaystyle x \in D$, alors $\displaystyle f$ est <strong>paire</strong></li>
                    <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle f(-x) = -f(x)$ pour tout $\displaystyle x \in D$, alors $\displaystyle f$ est <strong>impaire</strong></li>
                    <li style="margin:0; text-align:left;">Sinon, $\displaystyle f$ n'est ni paire ni impaire</li>
                </ul>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> $\displaystyle f(x) = x^4 - 3x^2 + 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le domaine est $\displaystyle \mathbb{R}$ (symétrique)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(-x) = (-x)^4 - 3(-x)^2 + 1 = x^4 - 3x^2 + 1 = f(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f$ est <strong>paire</strong>.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> $\displaystyle g(x) = x^3 - 2x$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le domaine est $\displaystyle \mathbb{R}$ (symétrique)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle g(-x) = (-x)^3 - 2(-x) = -x^3 + 2x = -(x^3 - 2x) = -g(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle g$ est <strong>impaire</strong>.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 3 :</strong> $\displaystyle h(x) = x^2 + x$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le domaine est $\displaystyle \mathbb{R}$ (symétrique)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle h(-x) = (-x)^2 + (-x) = x^2 - x$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a $\displaystyle h(-x) \neq h(x)$ et $\displaystyle h(-x) \neq -h(x)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle h$ n'est <strong>ni paire ni impaire</strong>.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes générales</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pratiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Domaine de définition :</strong> Toujours déterminer le domaine avant de travailler sur une fonction</li>
                <li style="margin:0; text-align:left;"><strong>Courbe représentative :</strong> Un point $\displaystyle M(x; y)$ appartient à $\displaystyle \mathcal{C}_f$ si et seulement si $\displaystyle y = f(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Fonction paire :</strong> Courbe symétrique par rapport à l'axe des ordonnées, $\displaystyle f(-x) = f(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Fonction impaire :</strong> Courbe symétrique par rapport à l'origine, $\displaystyle f(-x) = -f(x)$</li>
                <li style="margin:0; text-align:left;"><strong>Résolution graphique :</strong> Utiliser les intersections de courbes ou les positions relatives</li>
                <li style="margin:0; text-align:left;"><strong>Tableau de signes :</strong> Toujours identifier les valeurs qui annulent et les valeurs interdites</li>
                <li style="margin:0; text-align:left;"><strong>Règle des signes :</strong> Même signe → positif, signes opposés → négatif</li>
                <li style="margin:0; text-align:left;"><strong>Modélisation :</strong> Identifier les variables, le domaine, et établir la relation mathématique</li>
                <li style="margin:0; text-align:left;"><strong>Choix de méthode :</strong> Graphique pour visualiser, algébrique pour précision, logicielle pour complexité</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Domaine :</strong> Ne pas oublier de vérifier le domaine de définition avant de résoudre</li>
                <li style="margin:0; text-align:left;"><strong>Valeurs interdites :</strong> Pour les quotients, exclure les valeurs qui annulent le dénominateur</li>
                <li style="margin:0; text-align:left;"><strong>Parité :</strong> Vérifier d'abord que le domaine est symétrique avant d'étudier la parité</li>
                <li style="margin:0; text-align:left;"><strong>Tableau de signes :</strong> Ne pas oublier de placer les valeurs dans l'ordre croissant</li>
                <li style="margin:0; text-align:left;"><strong>Règle des signes :</strong> Attention : $\displaystyle - \times - = +$ et $\displaystyle + \times - = -$</li>
                <li style="margin:0; text-align:left;"><strong>Résolution graphique :</strong> Pour $\displaystyle f(x) < k$, repérer les parties en dessous de la droite $\displaystyle y = k$</li>
                <li style="margin:0; text-align:left;"><strong>Intersection :</strong> Pour $\displaystyle f(x) = g(x)$, les solutions sont les abscisses des points d'intersection</li>
                <li style="margin:0; text-align:left;"><strong>Modélisation :</strong> Vérifier que le modèle correspond bien à la situation réelle</li>
                <li style="margin:0; text-align:left;"><strong>Coordonnées manquantes :</strong> Si l'abscisse est connue, calculer $\displaystyle f(x)$ ; si l'ordonnée est connue, résoudre $\displaystyle f(x) = y$</li>
            </ul>
        </div>
