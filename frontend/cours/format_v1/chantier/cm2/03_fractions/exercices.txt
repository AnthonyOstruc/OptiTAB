=== Découverte - La bande de huit parts
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Une unité est partagée en 8 parts égales, dont 5 sont colorées. Quelle fraction est colorée ?
2. Quelle fraction n’est pas colorée ?
3. La même réponse reste-t-elle valable si les morceaux ont des aires différentes ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Le dénominateur compte les parts de l’unité ; le numérateur compte celles choisies.
:::

::: etape Raisonner avec les données
Il y a 8 parts dans le tout et 5 parts colorées.
:::

::: resultat 
$\frac{5}{8}$.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Retirer les parts colorées du nombre total de parts.
:::

::: etape Raisonner avec les données
$8-5=3$ parts restent sans couleur. Elles ont toujours la taille d’un 8-ième.
:::

::: resultat 
$\frac{3}{8}$.
:::

## Question 3 : Vérifier et conclure

::: methode 
Vérifier la condition de parts égales.
:::

::: etape Raisonner avec les données
Compter 5 morceaux sur 8 ne suffit pas quand leurs tailles diffèrent. Une fraction d’aire compte des parts de même aire.
:::

::: resultat 
Non : il faut des parts de même aire.
:::

Solution:
<!-- optitab:1 -->
1. $\frac{5}{8}$.
2. $\frac{3}{8}$.
3. Non : il faut des parts de même aire.

=== Découverte - Onze quarts à regrouper
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Combien d’unités complètes contient $\frac{11}{4}$ ?
2. Écrire la fraction comme un entier plus une fraction inférieure à 1.
3. Quelle distance manque-t-il pour atteindre l’entier suivant, en unité ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Former des paquets du dénominateur.
:::

::: etape Raisonner avec les données
$11=2\times4+3$. Chaque paquet de 4 parts forme une unité.
:::

::: resultat 
2 unités complètes.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Garder les parts qui restent après les regroupements.
:::

::: etape Raisonner avec les données
Les 2 unités utilisent 8 parts. Il reste $11-8=3$ parts de taille $\frac{1}{4}$.
:::

::: resultat 
$\frac{11}{4}=2+\frac{3}{4}$.
:::

## Question 3 : Vérifier et conclure

::: methode 
Compléter le dernier groupe de parts.
:::

::: etape Raisonner avec les données
Il faut $4-3=1$ parts supplémentaires pour former l’unité suivante.
:::

::: resultat 
$\frac{1}{4}$ unité.
:::

Solution:
<!-- optitab:1 -->
1. 2 unités complètes.
2. $\frac{11}{4}=2+\frac{3}{4}$.
3. $\frac{1}{4}$ unité.

[IMAGE_1]

La droite garde partout le même pas : 4 intervalles dans une unité. La fenêtre commence à 0.

1. Quelle est la valeur d’un petit pas, en unité ?
2. Le point est au 7e petit pas après 0. Donner son abscisse sous forme d’une fraction.
3. Donner une écriture entier plus fraction, puis encadrer l’abscisse.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Compter les intervalles dans une unité.
:::

::: etape Raisonner avec les données
Chaque unité est partagée en 4 intervalles égaux.
:::

::: resultat 
$\frac{1}{4}$ unité.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Compter aussi les parts avant le début de la fenêtre.
:::

::: etape Raisonner avec les données

3. $\frac{7}{4}=1+\frac{3}{4}$ et $1<\frac{7}{4}<2$.

=== Découverte - La fraction qui est un entier
Id: nouveau-6
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Calculer $\frac{8}{4}$ en regroupant les parts.
2. Un élève dit « Toute fraction est inférieure à 1 ». Donner ici un contre-exemple.
3. Que vaut $\frac{9}{4}$ ? Donner une écriture avec un entier.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Compter les groupes complets du dénominateur.
:::

::: etape Raisonner avec les données
$8=2\times4$. Il n’y a aucune part restante.
:::

::: resultat

:::

## Question 2 : Expliquer le raisonnement

::: methode 
Comparer numérateur et dénominateur.
:::

::: etape Raisonner avec les données
$8>4$, donc les 8 parts occupent plusieurs unités. Le nombre trouvé est 2.
:::

::: resultat 
$\frac{8}{4}=2>1$.
:::

## Question 3 : Vérifier et conclure

::: methode 
Ajouter une seule part à l’entier déjà obtenu.
:::

::: etape Raisonner avec les données
$9=2\times4+1$. Le partage reste en 4-ièmes.
:::

::: resultat 
$2+\frac{1}{4}$.
:::

Solution:
<!-- optitab:1 -->
1. $\frac{8}{4}=2$.
2. $\frac{8}{4}=2>1$.
3. $2+\frac{1}{4}$.

=== Problème - Composer puis raccourcir une longueur
Id: nouveau-21
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. Une bande mesure $\frac{11}{12}$ unité. Combien manque-t-il pour faire une unité ?
2. On ajoute une bande de $\frac{35}{12}$ unité. Quelle est la longueur totale ?
3. Combien d’unités complètes peut-on reporter dans cette longueur ? Que reste-t-il ?
4. Après l’assemblage, on retire une unité. Quelle longueur reste-t-il ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Compléter le nombre de parts du tout.
:::

::: etape Raisonner avec les données
Une unité contient 12 parts et la bande en contient 11 ; il manque $12-11=1$ part.
:::

::: resultat 
$\frac{1}{12}$ unité.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Compter des parts de même taille.
:::

::: etape Raisonner avec les données
Les 11 parts et les 35 parts font $11+35=46$ parts de même taille.
:::

::: resultat 
$\frac{46}{12}$ unités.
:::

## Question 3 : Vérifier et conclure

::: methode 
Regrouper les parts en unités complètes.
:::

::: etape Raisonner avec les données
$46=3\times12+10$.
:::

::: resultat 
3 unités et $\frac{10}{12}$ unité.
:::

## Question 4 : Chercher et justifier

::: methode 
Une unité correspond à douze douzièmes.
:::

::: etape Raisonner avec les données
La longueur assemblée est $\frac{46}{12}$. Après retrait d’une unité : $\frac{46}{12}-\frac{12}{12}=\frac{34}{12}=2+\frac{10}{12}$.
:::

::: resultat 
$2+\frac{10}{12}$ unités.
:::

Solution:
<!-- optitab:1 -->
1. $\frac{1}{12}$ unité.
2. $\frac{46}{12}$ unités.
3. 3 unités et $\frac{10}{12}$ unité.
4. $2+\frac{10}{12}$ unités.
