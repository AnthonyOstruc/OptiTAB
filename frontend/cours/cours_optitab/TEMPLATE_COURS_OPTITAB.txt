MÉTADONNÉES (HEADER)
================================================================================

Format exact :
=== [Titre] - Programme [Niveau]
Difficulté: [easy/medium/hard]
Ordre: [numéro d'ordre dans la séquence]
Images: [liste des images séparées par des virgules]

Titre: [Titre affiché]
Description: [Résumé du cours en 1-2 phrases]

Exemple :
=== Variables aléatoires réelles - Programme Première
Difficulté: medium
Ordre: 9
Images: tableau_loi_de.png, esperance_geometrique.png, variance_interpretation.png

Titre: Variables aléatoires réelles
Description: Cours complet sur les variables aléatoires en première : définition, loi de probabilité, espérance, variance, écart type, algorithmes de simulation, estimation et loi des grands nombres.

================================================================================
FORMULES MATHÉMATIQUES
================================================================================

Inline (dans le texte) :
$\displaystyle expression$

Exemple : $\displaystyle P(X = x_i)$

---

Formule encadrée importante (définition/théorème) :
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px;">
    <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle formule$</p>
</div>

Variantes de couleurs selon le contexte :
- Bleu : background #e8f4fd, border #3498db (définitions)
- Rouge : background #fff1f2, border #e11d48 (théorèmes)

================================================================================
LISTES
================================================================================

Listes à puces (ul) :
<ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
    <li style="margin:0 0 12px 0; text-align:left;">Élément 1</li>
    <li style="margin:0 0 12px 0; text-align:left;">Élément 2</li>
    <li style="margin:0; text-align:left;">Dernier élément (sans margin-bottom)</li>
</ul>

Listes numérotées (ol) :
<ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
    <li style="margin:0 0 12px 0; text-align:left; color:#000;">Étape 1</li>
    <li style="margin:0 0 12px 0; text-align:left; color:#000;">Étape 2</li>
    <li style="margin:0; text-align:left; color:#000;">Dernière étape</li>
</ol>

Caractéristiques :
- Margin : 8px 0
- Padding-left : 20px
- Line-height : 1.8
- Li margin : 0 0 12px 0 (sauf dernier : 0)
- Text-align : left

Listes avec espacement élargi (conseils, récapitulatif) :
- Line-height : 2.2 au lieu de 1.8

================================================================================
PARAGRAPHES
================================================================================

Paragraphe standard :
<p style="margin:8px 0; text-align:left; font-size:1em;">Texte</p>

Paragraphe sans margin en haut (premier dans un div) :
<p style="margin:0; text-align:left; font-size:1em;">Texte</p>

Paragraphe avec padding-left (formule développée) :
<p style="margin:8px 0; padding-left:0; text-align:left; font-size:1em;">$\displaystyle formule$</p>

Paragraphe avec indentation (continuation de calcul) :
<p style="margin:8px 0; padding-left:80px; text-align:left; font-size:1em;">$\displaystyle = résultat$</p>

Sous-titre dans un exemple :
<p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Étape 1 :</strong></p>

================================================================================
CODE PYTHON
================================================================================

Bloc de code :
<div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
    <span style="color:#ff79c6;">def</span> fonction():<br>
    &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#6272a4;"># Commentaire</span><br>
    &nbsp;&nbsp;&nbsp;&nbsp;variable = <span style="color:#bd93f9;">10</span><br>
    &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">return</span> variable
</div>

Couleurs du code :
- Background : #2c3e50 (bleu-gris foncé)
- Texte : #ffffff (blanc)
- Mots-clés (def, return, for, if, etc.) : #ff79c6 (rose)
- Commentaires : #6272a4 (gris-bleu)
- Nombres : #bd93f9 (violet)
- Fonctions built-in (print, len, range, sum) : #50fa7b (vert)
- Strings : #f1fa8c (jaune)

Indentation : &nbsp;&nbsp;&nbsp;&nbsp; (4 espaces)
Retour à la ligne : <br>

Note sous le code :
<p style="margin:8px 0; text-align:left; font-size:0.9em; color:#7f8c8d;"><em>Note explicative</em></p>

================================================================================
STYLES DE TEXTE
================================================================================

Texte en gras :
<strong>Texte</strong>

Texte en italique :
<em>Texte</em>

Texte en code inline :
<code>variable</code>

Mise en évidence (dans tableaux ou exemples) :
<strong style="color:#c62828;">Texte important</strong>

Couleur rouge pour méthodes : #c62828

================================================================================
ESPACEMENT ET MARGES
================================================================================

Espacement standard :
- Margin entre sections : 15px 0
- Margin entre paragraphes : 8px 0
- Padding dans les encadrés : 15px
- Padding dans conteneurs : 15px à 20px

Espacement spécial :
- Premier paragraphe d'un encadré : margin:0
- Sous-titre avec espace avant : margin:12px 0 8px 0
- Dernier élément de liste : margin:0
