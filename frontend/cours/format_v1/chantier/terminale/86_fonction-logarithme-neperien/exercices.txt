=== Découverte - Calculs avec puissances et racines
Id: 1244
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Calculer les valeurs exactes suivantes.

1. $\ln\sqrt{e}$
2. $\ln\left(e^5\right)$
3. $\ln\left(\dfrac{1}{e^2}\right)$
4. $\ln\sqrt[3]{e}$, où $\sqrt[3]{e} = e^{\frac{1}{3}}$ désigne la racine cubique de $e$
5. $\ln\left(e^{2x - 1}\right)$ pour $x = 3$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\ln\sqrt{e}$

::: methode
Écrire le nombre comme une puissance de $e$, puis utiliser $\ln\left(e^a\right) = a$.
:::

::: etape Écrire la racine carrée comme une puissance
$$\sqrt{e} = e^{\frac{1}{2}}$$
:::

::: etape Appliquer $\ln\left(e^a\right) = a$
$$\ln\sqrt{e} = \ln\left(e^{\frac{1}{2}}\right) = \frac{1}{2}$$
:::

::: resultat
$$\ln\sqrt{e} = \frac{1}{2}$$
:::

::: retenir
Pour tout réel $a$, $\ln\left(e^a\right) = a$ : le logarithme « annule » l’exponentielle.
:::

## Question 2 : Calculer $\ln\left(e^5\right)$

::: methode
Application directe de $\ln\left(e^a\right) = a$.
:::

::: etape Appliquer la propriété avec $a = 5$
$$\ln\left(e^5\right) = 5$$
:::

::: resultat
$$\ln\left(e^5\right) = 5$$
:::

## Question 3 : Calculer $\ln\left(\dfrac{1}{e^2}\right)$

::: methode
Écrire $\dfrac{1}{e^2}$ comme une puissance de $e$.
:::

::: etape Écrire l’inverse comme une puissance
$$\frac{1}{e^2} = e^{-2}$$
:::

::: etape Appliquer $\ln\left(e^a\right) = a$
$$\ln\left(\frac{1}{e^2}\right) = \ln\left(e^{-2}\right) = -2$$
:::

::: etape Vérification avec la règle de l’inverse
$$\ln\left(\frac{1}{e^2}\right) = -\ln\left(e^2\right) = -2$$
:::

::: resultat
$$\ln\left(\frac{1}{e^2}\right) = -2$$
:::

## Question 4 : Calculer $\ln\sqrt[3]{e}$

::: methode
Utiliser l’écriture $\sqrt[3]{e} = e^{\frac{1}{3}}$ donnée par l’énoncé.
:::

::: etape Appliquer $\ln\left(e^a\right) = a$ avec $a = \frac{1}{3}$
$$\ln\sqrt[3]{e} = \ln\left(e^{\frac{1}{3}}\right) = \frac{1}{3}$$
:::

::: resultat
$$\ln\sqrt[3]{e} = \frac{1}{3}$$
:::

## Question 5 : Calculer $\ln\left(e^{2x - 1}\right)$ pour $x = 3$

::: methode
Simplifier d’abord l’expression pour tout réel $x$, puis remplacer $x$ par $3$.
:::

::: etape Simplifier pour tout réel $x$
$$\ln\left(e^{2x - 1}\right) = 2x - 1$$
:::

::: etape Remplacer $x$ par $3$
$$2 \times 3 - 1 = 5$$
:::

::: resultat
Pour $x = 3$ : $\ln\left(e^{2x - 1}\right) = 5$.
:::

Solution:
<!-- optitab:1 -->
1. $\ln\sqrt{e} = \dfrac{1}{2}$
2. $\ln\left(e^5\right) = 5$
3. $\ln\left(\dfrac{1}{e^2}\right) = -2$
4. $\ln\sqrt[3]{e} = \dfrac{1}{3}$
5. Pour $x = 3$ : $\ln\left(e^{2x - 1}\right) = 2 \times 3 - 1 = 5$

=== Découverte - Propriétés algébriques et calculs
Id: 1243
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Simplifier les expressions suivantes à l’aide des propriétés du logarithme népérien.

1. $\ln 8 + \ln 2$
2. $\ln 27 - \ln 3$
3. $2\ln 5 + 3\ln 2$ (écrire sous la forme d’un seul logarithme)
4. $\ln\left(\dfrac{16}{9}\right) + \ln\left(\dfrac{3}{4}\right)$
5. $\ln\left(e^3\right) + \ln\left(e^{-2}\right) - \ln e$

Étapes:
<!-- optitab:1 -->
## Question 1 : Simplifier $\ln 8 + \ln 2$

::: methode
Regrouper avec $\ln a + \ln b = \ln(ab)$, puis écrire le résultat comme une puissance de $2$.
:::

::: etape Appliquer la règle du produit
$$\ln 8 + \ln 2 = \ln(8 \times 2) = \ln 16$$
:::

::: etape Écrire $16$ comme une puissance de $2$
$$\ln 16 = \ln\left(2^4\right) = 4\ln 2$$
:::

::: resultat
$$\ln 8 + \ln 2 = 4\ln 2$$
:::

::: attention
La règle porte sur le logarithme d’un **produit** : $\ln 8 + \ln 2 = \ln 16$, et surtout pas $\ln 10$.
:::

## Question 2 : Simplifier $\ln 27 - \ln 3$

::: methode
Regrouper avec $\ln a - \ln b = \ln\dfrac{a}{b}$.
:::

::: etape Appliquer la règle du quotient
$$\ln 27 - \ln 3 = \ln\left(\frac{27}{3}\right) = \ln 9$$
:::

::: etape Écrire $9$ comme une puissance de $3$
$$\ln 9 = \ln\left(3^2\right) = 2\ln 3$$
:::

::: resultat
$$\ln 27 - \ln 3 = 2\ln 3$$
:::

## Question 3 : Écrire $2\ln 5 + 3\ln 2$ sous la forme d’un seul logarithme

::: methode
Faire « rentrer » les coefficients avec $n\ln a = \ln\left(a^n\right)$, puis regrouper.
:::

::: etape Règle de la puissance
- $2\ln 5 = \ln\left(5^2\right) = \ln 25$
- $3\ln 2 = \ln\left(2^3\right) = \ln 8$
:::

::: etape Règle du produit
$$\ln 25 + \ln 8 = \ln(25 \times 8) = \ln 200$$
:::

::: resultat
$$2\ln 5 + 3\ln 2 = \ln 200$$
:::

## Question 4 : Simplifier $\ln\left(\dfrac{16}{9}\right) + \ln\left(\dfrac{3}{4}\right)$

::: methode
Regrouper avec $\ln a + \ln b = \ln(ab)$, puis simplifier la fraction.
:::

::: etape Règle du produit
$$\ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right) = \ln\left(\frac{16}{9} \times \frac{3}{4}\right)$$
:::

::: etape Simplifier le produit
$$
\begin{aligned}
\frac{16}{9} \times \frac{3}{4} &= \frac{16 \times 3}{9 \times 4} \\
&= \frac{4 \times 4 \times 3}{3 \times 3 \times 4} \\
&= \frac{4}{3}
\end{aligned}
$$
:::

::: resultat
$$\ln\left(\frac{16}{9}\right) + \ln\left(\frac{3}{4}\right) = \ln\left(\frac{4}{3}\right)$$
:::

## Question 5 : Simplifier $\ln\left(e^3\right) + \ln\left(e^{-2}\right) - \ln e$

::: methode
Simplifier chaque terme avec $\ln\left(e^a\right) = a$.
:::

::: etape Simplifier chaque terme
- $\ln\left(e^3\right) = 3$
- $\ln\left(e^{-2}\right) = -2$
- $\ln e = 1$
:::

::: etape Calculer
$$3 + (-2) - 1 = 0$$
:::

::: resultat
$$\ln\left(e^3\right) + \ln\left(e^{-2}\right) - \ln e = 0$$
:::

Solution:
<!-- optitab:1 -->
1. $\ln 8 + \ln 2 = \ln 16 = 4\ln 2$
2. $\ln 27 - \ln 3 = \ln 9 = 2\ln 3$
3. $2\ln 5 + 3\ln 2 = \ln 200$
4. $\ln\left(\dfrac{16}{9}\right) + \ln\left(\dfrac{3}{4}\right) = \ln\left(\dfrac{4}{3}\right)$
5. $\ln\left(e^3\right) + \ln\left(e^{-2}\right) - \ln e = 0$

=== Entraînement - Ensembles de définition et dérivées
Id: 1245
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Pour chacune des fonctions suivantes, préciser l’ensemble de définition puis calculer la dérivée.

1. $f(x) = \ln(3x + 1)$
2. $g(x) = \ln\left(x^2 - 4\right)$
3. $h(x) = x^2\ln x$
4. $k(x) = \dfrac{\ln x}{x}$
5. $m(x) = \ln\sqrt{x^2 + 1}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Dériver $f(x) = \ln(3x + 1)$

::: methode
Dérivée de $\ln u$ : $\big(\ln u\big)' = \dfrac{u'}{u}$, avec $u \gt 0$.
:::

::: etape Ensemble de définition
$3x + 1 \gt 0 \iff x \gt -\frac{1}{3}$, donc $D_f = \left]-\frac{1}{3}\,;+\infty\right[$.
:::

::: etape Identifier $u$ et calculer $u'$
$f = \ln u$ avec $u(x) = 3x + 1$, donc $u'(x) = 3$.
:::

::: etape Appliquer la formule
$$f'(x) = \frac{u'(x)}{u(x)} = \frac{3}{3x + 1}$$
:::

::: resultat
Pour tout $x \gt -\frac{1}{3}$ : $f'(x) = \dfrac{3}{3x + 1}$.
:::

## Question 2 : Dériver $g(x) = \ln\left(x^2 - 4\right)$

::: methode
Ensemble de définition par le signe de $x^2 - 4$, puis $\big(\ln u\big)' = \dfrac{u'}{u}$.
:::

::: etape Ensemble de définition
$x^2 - 4 = (x - 2)(x + 2)$ est strictement positif à l’extérieur des racines $-2$ et $2$ :

$$D_g = ]-\infty\,;-2[ \cup ]2\,;+\infty[$$

La courbe de $g$ est formée de deux branches, une de chaque côté de l’intervalle $[-2\,;2]$ où $g$ n’est pas définie (voir la figure ci-dessous).
:::

[IMAGE_1]

::: etape Identifier $u$ et calculer $u'$
$g = \ln u$ avec $u(x) = x^2 - 4$, donc $u'(x) = 2x$.
:::

::: etape Appliquer la formule
$$g'(x) = \frac{2x}{x^2 - 4}$$
:::

::: resultat
Pour tout $x \in D_g$ : $g'(x) = \dfrac{2x}{x^2 - 4}$.
:::

## Question 3 : Dériver $h(x) = x^2\ln x$

::: methode
Dérivée d’un produit : $(uv)' = u'v + uv'$.
:::

::: etape Ensemble de définition
$\ln x$ existe pour $x \gt 0$ : $D_h = ]0\,;+\infty[$.
:::

::: etape Identifier $u$ et $v$
$u(x) = x^2$ et $v(x) = \ln x$, donc $u'(x) = 2x$ et $v'(x) = \frac{1}{x}$.
:::

::: etape Appliquer la formule et factoriser
$$
\begin{aligned}
h'(x) &= 2x \times \ln x + x^2 \times \frac{1}{x} \\
&= 2x\ln x + x \\
&= x(2\ln x + 1)
\end{aligned}
$$
:::

::: resultat
Pour tout $x \gt 0$ : $h'(x) = x(2\ln x + 1)$.
:::

## Question 4 : Dériver $k(x) = \dfrac{\ln x}{x}$

::: methode
Dérivée d’un quotient : $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$.
:::

::: etape Ensemble de définition
$\ln x$ existe pour $x \gt 0$, et alors $x \neq 0$ : $D_k = ]0\,;+\infty[$.
:::

::: etape Identifier $u$ et $v$
$u(x) = \ln x$ et $v(x) = x$, donc $u'(x) = \frac{1}{x}$ et $v'(x) = 1$.
:::

::: etape Appliquer la formule
$$
\begin{aligned}
k'(x) &= \frac{\frac{1}{x} \times x - \ln x \times 1}{x^2} \\
&= \frac{1 - \ln x}{x^2}
\end{aligned}
$$
:::

::: resultat
Pour tout $x \gt 0$ : $k'(x) = \dfrac{1 - \ln x}{x^2}$.
:::

## Question 5 : Dériver $m(x) = \ln\sqrt{x^2 + 1}$

::: methode
Simplifier d’abord avec $\ln\sqrt{a} = \dfrac{1}{2}\ln a$, puis dériver $\ln u$.
:::

::: etape Ensemble de définition
$x^2 + 1 \ge 1 \gt 0$ pour tout réel $x$ : $D_m = \mathbb{R}$.
:::

::: etape Simplifier l’expression
$$m(x) = \ln\left(\left(x^2 + 1\right)^{\frac{1}{2}}\right) = \frac{1}{2}\ln\left(x^2 + 1\right)$$
:::

::: etape Dériver avec $u(x) = x^2 + 1$, $u'(x) = 2x$
$$
\begin{aligned}
m'(x) &= \frac{1}{2} \times \frac{2x}{x^2 + 1} \\
&= \frac{x}{x^2 + 1}
\end{aligned}
$$
:::

::: resultat
Pour tout réel $x$ : $m'(x) = \dfrac{x}{x^2 + 1}$.
:::

Solution:
<!-- optitab:1 -->
1. Sur $\left]-\frac{1}{3}\,;+\infty\right[$ : $f'(x) = \dfrac{3}{3x + 1}$
2. Sur $]-\infty\,;-2[ \cup ]2\,;+\infty[$ : $g'(x) = \dfrac{2x}{x^2 - 4}$
3. Sur $]0\,;+\infty[$ : $h'(x) = x(2\ln x + 1)$
4. Sur $]0\,;+\infty[$ : $k'(x) = \dfrac{1 - \ln x}{x^2}$
5. Sur $\mathbb{R}$ : $m'(x) = \dfrac{x}{x^2 + 1}$

=== Entraînement - Équations avec logarithme
Id: 1247
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les équations suivantes, après avoir déterminé l’ensemble des réels pour lesquels elles ont un sens.

1. $\ln(x + 2) = \ln(3x - 1)$
2. $\ln x = 2$
3. $\ln\left(x^2 - 4\right) - \ln(x - 2) = 1$
4. $\ln(x + 1) + \ln(x - 1) = \ln 8$
5. $2\ln x = \ln\left(x^2 + 3\right)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\ln(x + 2) = \ln(3x - 1)$

::: methode
Domaine d’abord, puis $\ln a = \ln b \iff a = b$.
:::

::: etape Ensemble de résolution
Il faut $x + 2 \gt 0$ et $3x - 1 \gt 0$, soit $x \gt -2$ et $x \gt \frac{1}{3}$. On résout donc sur $I = \left]\frac{1}{3}\,;+\infty\right[$.
:::

::: etape Résoudre l’équation sur $I$
$$
\begin{aligned}
\ln(x + 2) = \ln(3x - 1) &\iff x + 2 = 3x - 1 \\
&\iff 3 = 2x \\
&\iff x = \frac{3}{2}
\end{aligned}
$$
:::

::: etape Vérifier l’appartenance au domaine
$\frac{3}{2} \gt \frac{1}{3}$ : la valeur convient.
:::

::: resultat
$$S = \left\{\frac{3}{2}\right\}$$
:::

[IMAGE_1]

## Question 2 : Résoudre $\ln x = 2$

::: methode
Pour tout réel $k$ : $\ln x = k \iff x = e^k$.
:::

::: etape Ensemble de résolution
$\ln x$ existe pour $x \gt 0$.
:::

::: etape Appliquer l’exponentielle
$$\ln x = 2 \iff x = e^2$$

et $e^2 \approx 7{,}39 \gt 0$ convient.
:::

::: resultat
$$S = \left\{e^2\right\}$$
:::

[IMAGE_2]

## Question 3 : Résoudre $\ln\left(x^2 - 4\right) - \ln(x - 2) = 1$

::: methode
Domaine d’abord (les deux logarithmes doivent exister), puis règle du quotient.
:::

::: etape Ensemble de résolution
- $\ln(x - 2)$ existe si $x \gt 2$ ;
- $\ln\left(x^2 - 4\right)$ existe si $x^2 - 4 \gt 0$, soit $x \lt -2$ ou $x \gt 2$.

Les deux existent si et seulement si $x \gt 2$ : on résout sur $I = ]2\,;+\infty[$.
:::

::: etape Transformer l’équation sur $I$
$$
\begin{aligned}
&\ln\left(x^2 - 4\right) - \ln(x - 2) \\
&= \ln\left(\frac{x^2 - 4}{x - 2}\right) \\
&= \ln\left(\frac{(x - 2)(x + 2)}{x - 2}\right) \\
&= \ln(x + 2)
\end{aligned}
$$
:::

::: etape Résoudre
$$
\begin{aligned}
\ln(x + 2) = 1 &\iff x + 2 = e \\
&\iff x = e - 2
\end{aligned}
$$
:::

::: etape Vérifier l’appartenance au domaine
$e - 2 \approx 0{,}72$ et $0{,}72 \lt 2$ : cette valeur n’appartient pas à $I$, elle est rejetée.
:::

::: resultat
$$S = \varnothing$$
:::

::: attention
Sans l’étude préalable du domaine, on conclurait à tort $S = \{e - 2\}$. Sur $I$, l’expression vaut $\ln(x + 2) \gt \ln 4 \approx 1{,}39$ : elle ne peut pas valoir $1$.
:::

[IMAGE_3]

## Question 4 : Résoudre $\ln(x + 1) + \ln(x - 1) = \ln 8$

::: methode
Domaine d’abord, puis règle du produit et $\ln a = \ln b \iff a = b$.
:::

::: etape Ensemble de résolution
Il faut $x + 1 \gt 0$ et $x - 1 \gt 0$, soit $x \gt 1$ : $I = ]1\,;+\infty[$.
:::

::: etape Regrouper les logarithmes sur $I$
$$
\begin{aligned}
\ln(x + 1) + \ln(x - 1) &= \ln\big((x + 1)(x - 1)\big) \\
&= \ln\left(x^2 - 1\right)
\end{aligned}
$$
:::

::: etape Résoudre
$$
\begin{aligned}
\ln\left(x^2 - 1\right) = \ln 8 &\iff x^2 - 1 = 8 \\
&\iff x^2 = 9 \\
&\iff x = 3 \text{ ou } x = -3
\end{aligned}
$$
:::

::: etape Vérifier l’appartenance au domaine
$3 \in I$ convient ; $-3 \notin I$ est rejeté.
:::

::: resultat
$$S = \{3\}$$
:::

[IMAGE_4]

## Question 5 : Résoudre $2\ln x = \ln\left(x^2 + 3\right)$

::: methode
Domaine d’abord, puis $2\ln x = \ln\left(x^2\right)$ (valable pour $x \gt 0$).
:::

::: etape Ensemble de résolution
$\ln x$ existe pour $x \gt 0$ et $x^2 + 3 \gt 0$ toujours : $I = ]0\,;+\infty[$.
:::

::: etape Transformer et résoudre
$$
\begin{aligned}
& 2\ln x = \ln\left(x^2 + 3\right) \\
\iff\; & \ln\left(x^2\right) = \ln\left(x^2 + 3\right) \\
\iff\; & x^2 = x^2 + 3 \\
\iff\; & 0 = 3
\end{aligned}
$$

La dernière égalité est fausse : l’équation n’a aucune solution.
:::

::: resultat
$$S = \varnothing$$
:::

::: remarque
Graphiquement, la courbe de $y = \ln\left(x^2 + 3\right)$ est toujours au-dessus de celle de $y = 2\ln x$ : l’écart vaut $\ln\left(1 + \frac{3}{x^2}\right) \gt 0$.
:::

[IMAGE_5]

Solution:
<!-- optitab:1 -->
1. Sur $\left]\frac{1}{3}\,;+\infty\right[$ : $S = \left\{\dfrac{3}{2}\right\}$
2. $S = \left\{e^2\right\}$
3. Sur $]2\,;+\infty[$, la seule valeur trouvée, $e - 2 \approx 0{,}72$, est rejetée : $S = \varnothing$
4. Sur $]1\,;+\infty[$ : $S = \{3\}$ ($-3$ est rejeté)
5. $S = \varnothing$

=== Entraînement - Inéquations avec logarithme
Id: 1248
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les inéquations suivantes, après avoir déterminé l’ensemble des réels pour lesquels elles ont un sens.

1. $\ln(x + 1) \lt \ln(2x)$
2. $\ln x \ge -1$
3. $\ln(2x + 3) \le 0$
4. $\ln\left(x^2 - 1\right) \gt \ln 3$
5. $\ln x + \ln(x - 2) \le \ln 8$

Étapes:
<!-- optitab:1 -->
## Question 1 : Résoudre $\ln(x + 1) \lt \ln(2x)$

::: methode
Domaine d’abord, puis $\ln a \lt \ln b \iff a \lt b$ (la fonction $\ln$ est strictement croissante).
:::

::: etape Ensemble de résolution
Il faut $x + 1 \gt 0$ et $2x \gt 0$, soit $x \gt -1$ et $x \gt 0$ : $I = ]0\,;+\infty[$.
:::

::: etape Résoudre sur $I$
$$
\begin{aligned}
\ln(x + 1) \lt \ln(2x) &\iff x + 1 \lt 2x \\
&\iff 1 \lt x
\end{aligned}
$$
:::

::: etape Intersection avec $I$
$x \gt 0$ et $x \gt 1$ donnent $x \gt 1$.
:::

::: resultat
$$S = ]1\,;+\infty[$$
:::

[IMAGE_1]

## Question 2 : Résoudre $\ln x \ge -1$

::: methode
Écrire $-1 = \ln\left(e^{-1}\right)$, puis utiliser la croissance de $\ln$.
:::

::: etape Ensemble de résolution
$\ln x$ existe pour $x \gt 0$.
:::

::: etape Résoudre
$$
\begin{aligned}
\ln x \ge -1 &\iff \ln x \ge \ln\left(e^{-1}\right) \\
&\iff x \ge e^{-1} = \frac{1}{e}
\end{aligned}
$$
:::

::: etape Intersection avec $]0\,;+\infty[$
Comme $\frac{1}{e} \gt 0$, la condition $x \ge \frac{1}{e}$ suffit.
:::

::: resultat
$$S = \left[\frac{1}{e}\,;+\infty\right[$$
:::

[IMAGE_2]

## Question 3 : Résoudre $\ln(2x + 3) \le 0$

::: methode
Écrire $0 = \ln 1$, puis utiliser la croissance de $\ln$.
:::

::: etape Ensemble de résolution
$2x + 3 \gt 0 \iff x \gt -\frac{3}{2}$ : $I = \left]-\frac{3}{2}\,;+\infty\right[$.
:::

::: etape Résoudre sur $I$
$$
\begin{aligned}
\ln(2x + 3) \le \ln 1 &\iff 2x + 3 \le 1 \\
&\iff 2x \le -2 \\
&\iff x \le -1
\end{aligned}
$$
:::

::: etape Intersection avec $I$
$x \gt -\frac{3}{2}$ et $x \le -1$ donnent $-\frac{3}{2} \lt x \le -1$.
:::

::: resultat
$$S = \left]-\frac{3}{2}\,;-1\right]$$
:::

::: attention
Ne pas oublier la borne $-\frac{3}{2}$, exclue : $\ln(2x + 3) \le 0$ signifie $0 \lt 2x + 3 \le 1$, et pas seulement $2x + 3 \le 1$.
:::

[IMAGE_3]

## Question 4 : Résoudre $\ln\left(x^2 - 1\right) \gt \ln 3$

::: methode
Domaine par le signe de $x^2 - 1$, puis croissance de $\ln$ et signe de $x^2 - 4$.
:::

::: etape Ensemble de résolution
$x^2 - 1 = (x - 1)(x + 1) \gt 0$ à l’extérieur des racines : $I = ]-\infty\,;-1[ \cup ]1\,;+\infty[$.
:::

::: etape Se ramener à une inéquation du second degré
$$
\begin{aligned}
\ln\left(x^2 - 1\right) \gt \ln 3 &\iff x^2 - 1 \gt 3 \\
&\iff x^2 - 4 \gt 0 \\
&\iff (x - 2)(x + 2) \gt 0
\end{aligned}
$$
:::

::: point Signe de $x^2 - 4$
::: tableau
x : -\infty, -2, 2, +\infty
x^2 - 4 : , +, z, -, z, +,
:::
:::

::: etape Intersection avec $I$
$x^2 - 4 \gt 0$ pour $x \in ]-\infty\,;-2[ \cup ]2\,;+\infty[$. Cet ensemble est contenu dans $I$ (car $x^2 \gt 4$ entraîne $x^2 \gt 1$).
:::

::: resultat
$$S = ]-\infty\,;-2[ \cup ]2\,;+\infty[$$
:::

[IMAGE_4]

## Question 5 : Résoudre $\ln x + \ln(x - 2) \le \ln 8$

::: methode
Domaine d’abord, puis règle du produit, croissance de $\ln$ et signe d’un trinôme.
:::

::: etape Ensemble de résolution
Il faut $x \gt 0$ et $x - 2 \gt 0$, soit $x \gt 2$ : $I = ]2\,;+\infty[$.
:::

::: etape Regrouper et appliquer la croissance de $\ln$ sur $I$
$$
\begin{aligned}
& \ln x + \ln(x - 2) \le \ln 8 \\
\iff\; & \ln\big(x(x - 2)\big) \le \ln 8 \\
\iff\; & x^2 - 2x \le 8 \\
\iff\; & x^2 - 2x - 8 \le 0
\end{aligned}
$$
:::

::: etape Factoriser le trinôme
$\Delta = (-2)^2 - 4 \times 1 \times (-8) = 36$, racines $\frac{2 - 6}{2} = -2$ et $\frac{2 + 6}{2} = 4$ :

$$x^2 - 2x - 8 = (x + 2)(x - 4)$$
:::

::: point Signe de $x^2 - 2x - 8$
::: tableau
x : -\infty, -2, 4, +\infty
x + 2 : , -, z, +, t, +,
x - 4 : , -, t, -, z, +,
x^2 - 2x - 8 : , +, z, -, z, +,
:::
:::

::: etape Intersection avec $I$
$x^2 - 2x - 8 \le 0$ pour $x \in [-2\,;4]$ ; avec $x \gt 2$, on obtient $2 \lt x \le 4$.
:::

::: resultat
$$S = ]2\,;4]$$
:::

[IMAGE_5]

Solution:
<!-- optitab:1 -->
1. $S = ]1\,;+\infty[$
2. $S = \left[\dfrac{1}{e}\,;+\infty\right[$
3. $S = \left]-\dfrac{3}{2}\,;-1\right]$
4. $S = ]-\infty\,;-2[ \cup ]2\,;+\infty[$
5. $S = ]2\,;4]$

=== Entraînement - Limites et croissances comparées
Id: 1249
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer les limites suivantes.

1. $\lim\limits_{x \to 0^+} x\ln x$
2. $\lim\limits_{x \to +\infty} \dfrac{\ln x}{x}$
3. $\lim\limits_{x \to 0} \dfrac{\ln(1 + x)}{x}$
4. $\lim\limits_{x \to +\infty} \dfrac{x}{\ln x}$
5. $\lim\limits_{x \to 1} \dfrac{\ln x}{x - 1}$

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $\lim\limits_{x \to 0^+} x\ln x$

::: methode
Repérer la forme indéterminée, puis utiliser une croissance comparée du cours.
:::

::: etape Identifier la forme
Quand $x \to 0^+$ : $x \to 0$ et $\ln x \to -\infty$. C’est une forme indéterminée « $0 \times \infty$ ».
:::

::: etape Croissance comparée
D’après le cours, $\lim\limits_{x \to 0^+} x\ln x = 0$ : au voisinage de $0$, $x$ « l’emporte » sur $\ln x$.
:::

[IMAGE_1]

::: resultat
$$\lim_{x \to 0^+} x\ln x = 0$$
:::

## Question 2 : Calculer $\lim\limits_{x \to +\infty} \dfrac{\ln x}{x}$

::: methode
Forme indéterminée, levée par la croissance comparée du cours.
:::

::: etape Identifier la forme
Quand $x \to +\infty$, $\ln x \to +\infty$ et $x \to +\infty$ : forme indéterminée « $\frac{\infty}{\infty}$ ».
:::

::: etape Croissance comparée
En $+\infty$, $x$ croît beaucoup plus vite que $\ln x$ : $\lim\limits_{x \to +\infty} \dfrac{\ln x}{x} = 0$.
:::

[IMAGE_2]

::: resultat
$$\lim_{x \to +\infty} \frac{\ln x}{x} = 0$$
:::

## Question 3 : Calculer $\lim\limits_{x \to 0} \dfrac{\ln(1 + x)}{x}$

::: methode
Reconnaître un taux d’accroissement : la limite est un nombre dérivé.
:::

::: etape Identifier la forme
Quand $x \to 0$, $\ln(1 + x) \to \ln 1 = 0$ et $x \to 0$ : forme indéterminée « $\frac{0}{0}$ ».
:::

::: etape Reconnaître un taux d’accroissement
On pose $u(x) = \ln(1 + x)$, définie et dérivable sur $]-1\,;+\infty[$, avec $u(0) = 0$. Alors

$$\frac{\ln(1 + x)}{x} = \frac{u(x) - u(0)}{x - 0}$$

qui tend vers $u'(0)$ quand $x \to 0$.
:::

::: etape Calculer $u'(0)$
$u'(x) = \dfrac{1}{1 + x}$, donc $u'(0) = 1$.
:::

Graphiquement, $1$ est la pente de la tangente en $0$ à la courbe de $x \mapsto \ln(1 + x)$ ; cette tangente est la droite d’équation $y = x$ :

[IMAGE_3]

::: resultat
$$\lim_{x \to 0} \frac{\ln(1 + x)}{x} = 1$$
:::

::: retenir
Une forme « $\frac{0}{0}$ » du type $\dfrac{u(x) - u(a)}{x - a}$ se calcule comme un nombre dérivé : sa limite en $a$ vaut $u'(a)$.
:::

## Question 4 : Calculer $\lim\limits_{x \to +\infty} \dfrac{x}{\ln x}$

::: methode
Écrire le quotient comme l’inverse de $\dfrac{\ln x}{x}$.
:::

::: etape Écrire l’inverse
Pour $x \gt 1$, $\ln x \gt 0$ et

$$\frac{x}{\ln x} = \frac{1}{\frac{\ln x}{x}}$$
:::

::: etape Passer à la limite
D’après la question 2, $\dfrac{\ln x}{x} \to 0$ en $+\infty$, avec $\dfrac{\ln x}{x} \gt 0$ pour $x \gt 1$ : le dénominateur tend vers $0^+$, donc le quotient tend vers $+\infty$.
:::

::: resultat
$$\lim_{x \to +\infty} \frac{x}{\ln x} = +\infty$$
:::

## Question 5 : Calculer $\lim\limits_{x \to 1} \dfrac{\ln x}{x - 1}$

::: methode
Reconnaître le taux d’accroissement de $\ln$ en $1$.
:::

::: etape Identifier la forme
Quand $x \to 1$, $\ln x \to 0$ et $x - 1 \to 0$ : forme indéterminée « $\frac{0}{0}$ ».
:::

::: etape Reconnaître un taux d’accroissement
Comme $\ln 1 = 0$ :

$$\frac{\ln x}{x - 1} = \frac{\ln x - \ln 1}{x - 1}$$

qui tend vers $\ln'(1)$ quand $x \to 1$.
:::

::: etape Calculer $\ln'(1)$
$\ln'(x) = \dfrac{1}{x}$, donc $\ln'(1) = 1$.
:::

::: resultat
$$\lim_{x \to 1} \frac{\ln x}{x - 1} = 1$$
:::

Solution:
<!-- optitab:1 -->
1. $\lim\limits_{x \to 0^+} x\ln x = 0$ (croissance comparée)
2. $\lim\limits_{x \to +\infty} \dfrac{\ln x}{x} = 0$ (croissance comparée)
3. $\lim\limits_{x \to 0} \dfrac{\ln(1 + x)}{x} = 1$ (nombre dérivé de $x \mapsto \ln(1 + x)$ en $0$)
4. $\lim\limits_{x \to +\infty} \dfrac{x}{\ln x} = +\infty$
5. $\lim\limits_{x \to 1} \dfrac{\ln x}{x - 1} = 1$ (nombre dérivé de $\ln$ en $1$)

=== Problème - Applications et modélisation
Id: 1250
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre les problèmes suivants à l’aide du logarithme népérien.

1. Une population de bactéries suit la loi $P(t) = P_0\,e^{kt}$ ($t$ en heures). Elle double en $3$ heures et $P_0 = 100$ bactéries. Déterminer $k$, puis le temps nécessaire pour atteindre $10\,000$ bactéries.
2. Un capital de $1\,000$ € est placé à intérêts composés au taux de $5\,\%$ par an (les intérêts sont versés en fin d’année). Au bout de combien d’années le capital aura-t-il doublé ?
3. La température d’un objet suit la loi de refroidissement de Newton : $T(t) = T_a + (T_0 - T_a)\,e^{-kt}$ ($t$ en minutes), où $T_a = 20$ °C est la température ambiante. On a $T_0 = 100$ °C et $T(10) = 60$ °C. Déterminer $k$.
4. Une substance radioactive se désintègre selon $Q(t) = Q_0\,e^{-\lambda t}$ ($t$ en années). Sa demi-vie est de $30$ ans. Calculer $\lambda$, puis la proportion de substance restante après $100$ ans.
5. Juste après une injection, la concentration d’un médicament dans le sang vaut $50$ mg/L ; elle diminue ensuite de $20\,\%$ chaque heure. Au bout de $n$ heures, elle vaut donc $C_n = 50 \times 0{,}8^n$ (en mg/L). Au bout de combien d’heures la concentration devient-elle inférieure à $5$ mg/L ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Population de bactéries

::: methode
Traduire « double en 3 heures » par une équation, puis isoler l’exposant en prenant le logarithme.
:::

::: etape Déterminer $k$
La population double en $3$ heures : $P(3) = 2P_0$.

$$
\begin{aligned}
P_0\,e^{3k} = 2P_0 &\iff e^{3k} = 2 \\
&\iff 3k = \ln 2 \\
&\iff k = \frac{\ln 2}{3}
\end{aligned}
$$
:::

::: etape Résoudre $P(t) = 10\,000$
$$
\begin{aligned}
& 100\,e^{kt} = 10\,000 \\
\iff\; & e^{kt} = 100 \\
\iff\; & kt = \ln 100 \\
\iff\; & t = \frac{\ln 100}{k} = \frac{3\ln 100}{\ln 2}
\end{aligned}
$$
:::

::: etape Valeur approchée
$$t = \frac{3\ln 100}{\ln 2} \approx 19{,}93$$
:::

::: resultat
$k = \dfrac{\ln 2}{3}$ ; la population atteint $10\,000$ bactéries au bout d’environ $19{,}9$ heures, soit à peu près $20$ heures.
:::

## Question 2 : Doublement d’un capital

::: methode
Modéliser par une suite géométrique, puis résoudre une inéquation de seuil avec $\ln$.
:::

::: etape Modèle
Chaque année, le capital est multiplié par $1{,}05$. Après $n$ années : $C_n = 1\,000 \times 1{,}05^n$. On cherche le plus petit entier $n$ tel que $C_n \ge 2\,000$.
:::

::: etape Résoudre l’inéquation
$$
\begin{aligned}
& 1\,000 \times 1{,}05^n \ge 2\,000 \\
\iff\; & 1{,}05^n \ge 2 \\
\iff\; & n\ln 1{,}05 \ge \ln 2 \\
\iff\; & n \ge \frac{\ln 2}{\ln 1{,}05} \approx 14{,}2
\end{aligned}
$$

On a divisé par $\ln 1{,}05 \gt 0$ : le sens de l’inégalité est conservé.
:::

::: etape Conclure avec un entier
Le plus petit entier $n$ qui convient est $15$. Vérification : $C_{14} \approx 1\,979{,}93$ € et $C_{15} \approx 2\,078{,}93$ €.
:::

::: resultat
Le capital aura doublé au bout de $15$ ans.
:::

::: attention
Les intérêts étant versés une fois par an, la réponse est un nombre **entier** d’années : $14{,}2$ ans n’a pas de sens ici, on arrondit à l’entier supérieur.
:::

## Question 3 : Loi de refroidissement de Newton

::: methode
Remplacer par les données, isoler l’exponentielle, puis prendre le logarithme.
:::

::: etape Utiliser $T(10) = 60$
$$
\begin{aligned}
& 20 + (100 - 20)\,e^{-10k} = 60 \\
\iff\; & 80\,e^{-10k} = 40 \\
\iff\; & e^{-10k} = \frac{1}{2}
\end{aligned}
$$
:::

::: etape Prendre le logarithme
$$
\begin{aligned}
-10k = \ln\frac{1}{2} = -\ln 2 &\iff k = \frac{\ln 2}{10}
\end{aligned}
$$
:::

La température passe de $100$ °C à $60$ °C en $10$ minutes, puis se rapproche de la température ambiante :

[IMAGE_1]

::: resultat
$k = \dfrac{\ln 2}{10} \approx 0{,}069$ min$^{-1}$
:::

## Question 4 : Décroissance radioactive

::: methode
La demi-vie $T$ vérifie $Q(T) = \dfrac{Q_0}{2}$.
:::

::: etape Déterminer $\lambda$
$$
\begin{aligned}
Q_0\,e^{-30\lambda} = \frac{Q_0}{2} &\iff e^{-30\lambda} = \frac{1}{2} \\
&\iff -30\lambda = -\ln 2 \\
&\iff \lambda = \frac{\ln 2}{30}
\end{aligned}
$$

soit $\lambda \approx 0{,}0231$ par an.
:::

::: etape Proportion restante après $100$ ans
$$
\begin{aligned}
\frac{Q(100)}{Q_0} &= e^{-100\lambda} \\
&= e^{-\frac{100\ln 2}{30}} \\
&= e^{-\frac{10}{3}\ln 2} \\
&= 2^{-\frac{10}{3}} \approx 0{,}099
\end{aligned}
$$

On a utilisé $e^{a\ln 2} = \left(e^{\ln 2}\right)^a = 2^a$.
:::

::: resultat
$\lambda = \dfrac{\ln 2}{30} \approx 0{,}0231$ an$^{-1}$ ; après $100$ ans, il reste environ $9{,}9\,\%$ de la substance.
:::

## Question 5 : Seuil de concentration

::: methode
Inéquation de seuil : on applique $\ln$, puis on divise par $\ln 0{,}8$ en faisant attention à son signe.
:::

::: etape Appliquer le logarithme
$\ln$ est strictement croissante sur $]0\,;+\infty[$ :

$$
\begin{aligned}
50 \times 0{,}8^n \lt 5 &\iff 0{,}8^n \lt 0{,}1 \\
&\iff n\ln 0{,}8 \lt \ln 0{,}1
\end{aligned}
$$
:::

::: etape Diviser par $\ln 0{,}8$
Comme $0 \lt 0{,}8 \lt 1$, on a $\ln 0{,}8 \lt 0$ : en divisant par ce nombre négatif, on change le sens de l’inégalité.

$$n \gt \frac{\ln 0{,}1}{\ln 0{,}8} \approx 10{,}32$$
:::

::: etape Conclure avec un entier
Le plus petit entier qui convient est $n = 11$. Vérification : $C_{10} \approx 5{,}37$ mg/L et $C_{11} \approx 4{,}29$ mg/L.
:::

[IMAGE_2]

::: resultat
La concentration devient inférieure à $5$ mg/L au bout de $11$ heures.
:::

::: attention
Diviser par $\ln 0{,}8$, qui est négatif, inverse le sens de l’inégalité : c’est l’erreur la plus fréquente dans les problèmes de seuil.
:::

Solution:
<!-- optitab:1 -->
1. $k = \dfrac{\ln 2}{3}$ ; $t = \dfrac{3\ln 100}{\ln 2} \approx 19{,}9$ heures, soit environ $20$ heures
2. $n \ge \dfrac{\ln 2}{\ln 1{,}05} \approx 14{,}2$ : le capital double au bout de $15$ ans
3. $k = \dfrac{\ln 2}{10} \approx 0{,}069$ min$^{-1}$
4. $\lambda = \dfrac{\ln 2}{30} \approx 0{,}0231$ an$^{-1}$ ; il reste $2^{-\frac{10}{3}} \approx 9{,}9\,\%$ après $100$ ans
5. $n \gt \dfrac{\ln 0{,}1}{\ln 0{,}8} \approx 10{,}3$ : la concentration passe sous $5$ mg/L au bout de $11$ heures

=== Problème - Étude de fonctions
Id: 1246
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Pour chacune des fonctions suivantes : déterminer l’ensemble de définition, calculer la dérivée, étudier le sens de variation, calculer les limites aux bornes et dresser le tableau de variations.

1. $f(x) = \ln(2x - 1)$
2. $g(x) = x\ln x$
3. $h(x) = \ln\left(x^2 - 3x + 2\right)$
4. $k(x) = \dfrac{\ln x}{x^2}$
5. $m(x) = \ln\left(\dfrac{x + 1}{x - 1}\right)$

Étapes:
<!-- optitab:1 -->
## Question 1 : Étudier $f(x) = \ln(2x - 1)$

::: methode
Fonction $\ln u$ : domaine $u \gt 0$, dérivée $\dfrac{u'}{u}$, limites par composition.
:::

::: etape Ensemble de définition
$2x - 1 \gt 0 \iff x \gt \frac{1}{2}$ : $D_f = \left]\frac{1}{2}\,;+\infty\right[$.
:::

::: etape Dérivée et signe
Avec $u(x) = 2x - 1$ et $u'(x) = 2$ :

$$f'(x) = \frac{2}{2x - 1}$$

Sur $D_f$, $2x - 1 \gt 0$, donc $f'(x) \gt 0$ : $f$ est strictement croissante sur $D_f$.
:::

::: etape Limites aux bornes
- Quand $x \to \frac{1}{2}^+$, $2x - 1 \to 0^+$ et $\lim\limits_{X \to 0^+} \ln X = -\infty$, donc $\lim\limits_{x \to \frac{1}{2}^+} f(x) = -\infty$.
- Quand $x \to +\infty$, $2x - 1 \to +\infty$ et $\lim\limits_{X \to +\infty} \ln X = +\infty$, donc $\lim\limits_{x \to +\infty} f(x) = +\infty$.
:::

::: point Tableau de variations
::: tableau
x : \frac{1}{2}, +\infty
f'(x) : d, +,
f(x) : D-/-\infty, +/+\infty
:::
:::

::: resultat
$f$ est strictement croissante sur $\left]\frac{1}{2}\,;+\infty\right[$, de $-\infty$ à $+\infty$ ; la droite d’équation $x = \frac{1}{2}$ est asymptote verticale.
:::

[IMAGE_1]

## Question 2 : Étudier $g(x) = x\ln x$

::: methode
Dérivée d’un produit, puis signe de $\ln x + 1$ ; croissance comparée en $0^+$.
:::

::: etape Ensemble de définition
$\ln x$ existe pour $x \gt 0$ : $D_g = ]0\,;+\infty[$.
:::

::: etape Dérivée
$$
\begin{aligned}
g'(x) &= 1 \times \ln x + x \times \frac{1}{x} \\
&= \ln x + 1
\end{aligned}
$$
:::

::: etape Signe de la dérivée
$$
\begin{aligned}
\ln x + 1 \gt 0 &\iff \ln x \gt -1 \\
&\iff x \gt e^{-1} = \frac{1}{e}
\end{aligned}
$$

Donc $g'(x) \lt 0$ sur $\left]0\,;\frac{1}{e}\right[$, $g'\left(\frac{1}{e}\right) = 0$ et $g'(x) \gt 0$ sur $\left]\frac{1}{e}\,;+\infty\right[$.
:::

::: etape Valeur du minimum
$$g\left(\frac{1}{e}\right) = \frac{1}{e} \times \ln\left(\frac{1}{e}\right) = \frac{1}{e} \times (-1) = -\frac{1}{e}$$
:::

::: etape Limites aux bornes
- $\lim\limits_{x \to 0^+} x\ln x = 0$ (croissance comparée).
- Quand $x \to +\infty$, $x \to +\infty$ et $\ln x \to +\infty$, donc $\lim\limits_{x \to +\infty} g(x) = +\infty$.
:::

::: point Tableau de variations
::: tableau
x : 0, \frac{1}{e}, +\infty
g'(x) : d, -, z, +,
g(x) : D+/0, -/-\frac{1}{e}, +/+\infty
:::
:::

::: resultat
$g$ est décroissante sur $\left]0\,;\frac{1}{e}\right]$ et croissante sur $\left[\frac{1}{e}\,;+\infty\right[$ ; elle admet un minimum égal à $-\frac{1}{e} \approx -0{,}37$ en $x = \frac{1}{e}$.
:::

[IMAGE_2]

## Question 3 : Étudier $h(x) = \ln\left(x^2 - 3x + 2\right)$

::: methode
Domaine par le signe du trinôme, dérivée $\dfrac{u'}{u}$, puis étude sur chacun des deux intervalles.
:::

::: etape Ensemble de définition
$x^2 - 3x + 2 = (x - 1)(x - 2)$ (racines $1$ et $2$) est strictement positif à l’extérieur des racines :

$$D_h = ]-\infty\,;1[ \cup ]2\,;+\infty[$$
:::

::: etape Dérivée
Avec $u(x) = x^2 - 3x + 2$ et $u'(x) = 2x - 3$ :

$$h'(x) = \frac{2x - 3}{x^2 - 3x + 2}$$
:::

::: etape Signe de la dérivée
Sur $D_h$, le dénominateur est strictement positif : $h'(x)$ a le signe de $2x - 3$, qui s’annule en $\frac{3}{2} \notin D_h$.
- Sur $]-\infty\,;1[$ : $2x - 3 \lt 0$, donc $h'(x) \lt 0$.
- Sur $]2\,;+\infty[$ : $2x - 3 \gt 0$, donc $h'(x) \gt 0$.
:::

::: etape Limites aux bornes
- En $1^-$ et en $2^+$ : $x^2 - 3x + 2 \to 0^+$, donc $h(x) \to -\infty$.
- En $-\infty$ et en $+\infty$ : $x^2 - 3x + 2 \to +\infty$, donc $h(x) \to +\infty$.
:::

::: point Tableau de variations
::: tableau
x : -\infty, 1, 2, +\infty
h'(x) : , -, d, h, d, +,
h(x) : +/+\infty, -D/-\infty, D-/-\infty, +/+\infty
:::
:::

::: resultat
$h$ est strictement décroissante sur $]-\infty\,;1[$ et strictement croissante sur $]2\,;+\infty[$ ; les droites d’équations $x = 1$ et $x = 2$ sont asymptotes verticales.
:::

::: remarque
$h(3 - x) = h(x)$ : la courbe est symétrique par rapport à la droite d’équation $x = \frac{3}{2}$.
:::

## Question 4 : Étudier $k(x) = \dfrac{\ln x}{x^2}$

::: methode
Dérivée d’un quotient, signe de $1 - 2\ln x$ ; croissance comparée en $+\infty$.
:::

::: etape Ensemble de définition
$\ln x$ existe pour $x \gt 0$, et alors $x^2 \neq 0$ : $D_k = ]0\,;+\infty[$.
:::

::: etape Dérivée
$$
\begin{aligned}
k'(x) &= \frac{\frac{1}{x} \times x^2 - \ln x \times 2x}{x^4} \\
&= \frac{x(1 - 2\ln x)}{x^4} \\
&= \frac{1 - 2\ln x}{x^3}
\end{aligned}
$$
:::

::: etape Signe de la dérivée
Sur $]0\,;+\infty[$, $x^3 \gt 0$ : $k'(x)$ a le signe de $1 - 2\ln x$.

$$
\begin{aligned}
1 - 2\ln x \gt 0 &\iff \ln x \lt \frac{1}{2} \\
&\iff x \lt e^{\frac{1}{2}} = \sqrt{e}
\end{aligned}
$$
:::

::: etape Valeur du maximum
$$k\left(\sqrt{e}\right) = \frac{\ln\sqrt{e}}{\left(\sqrt{e}\right)^2} = \frac{\frac{1}{2}}{e} = \frac{1}{2e}$$
:::

::: etape Limites aux bornes
- En $0^+$ : $\ln x \to -\infty$ et $\frac{1}{x^2} \to +\infty$, donc $k(x) = \ln x \times \frac{1}{x^2} \to -\infty$.
- En $+\infty$ : $k(x) = \dfrac{\ln x}{x} \times \dfrac{1}{x}$, avec $\dfrac{\ln x}{x} \to 0$ et $\dfrac{1}{x} \to 0$, donc $k(x) \to 0$.
:::

::: point Tableau de variations
::: tableau
x : 0, \sqrt{e}, +\infty
k'(x) : d, +, z, -,
k(x) : D-/-\infty, +/\frac{1}{2e}, -/0
:::
:::

::: resultat
$k$ est croissante sur $\left]0\,;\sqrt{e}\right]$ et décroissante sur $\left[\sqrt{e}\,;+\infty\right[$ ; maximum $\frac{1}{2e} \approx 0{,}18$ en $x = \sqrt{e}$ ; asymptotes $x = 0$ et $y = 0$.
:::

## Question 5 : Étudier $m(x) = \ln\left(\dfrac{x + 1}{x - 1}\right)$

::: methode
Domaine par un tableau de signes du quotient, dérivée $\dfrac{u'}{u}$, limites par composition.
:::

::: etape Ensemble de définition
Il faut $\dfrac{x + 1}{x - 1} \gt 0$ (avec $x \neq 1$).

::: tableau
x : -\infty, -1, 1, +\infty
x + 1 : , -, z, +, t, +,
x - 1 : , -, t, -, z, +,
\frac{x + 1}{x - 1} : , +, z, -, d, +,
:::

Donc $D_m = ]-\infty\,;-1[ \cup ]1\,;+\infty[$.
:::

::: etape Dérivée
Avec $u(x) = \dfrac{x + 1}{x - 1}$ :

$$
\begin{aligned}
u'(x) &= \frac{1 \times (x - 1) - (x + 1) \times 1}{(x - 1)^2} \\
&= \frac{-2}{(x - 1)^2}
\end{aligned}
$$

$$
\begin{aligned}
m'(x) &= \frac{u'(x)}{u(x)} = \frac{-2}{(x - 1)^2} \times \frac{x - 1}{x + 1} \\
&= \frac{-2}{(x - 1)(x + 1)} = \frac{-2}{x^2 - 1}
\end{aligned}
$$
:::

::: etape Signe de la dérivée
Sur $D_m$, $x^2 - 1 \gt 0$, donc $m'(x) \lt 0$ : $m$ est strictement décroissante sur chacun des deux intervalles.
:::

::: etape Limites aux bornes
- En $-\infty$ et en $+\infty$ : $\dfrac{x + 1}{x - 1} \to 1$, donc $m(x) \to \ln 1 = 0$.
- En $-1^-$ : $x + 1 \to 0^-$ et $x - 1 \to -2$, donc $\dfrac{x + 1}{x - 1} \to 0^+$ et $m(x) \to -\infty$.
- En $1^+$ : $x + 1 \to 2$ et $x - 1 \to 0^+$, donc $\dfrac{x + 1}{x - 1} \to +\infty$ et $m(x) \to +\infty$.
:::

::: point Tableau de variations
::: tableau
x : -\infty, -1, 1, +\infty
m'(x) : , -, d, h, d, -,
m(x) : +/0, -D/-\infty, D+/+\infty, -/0
:::
:::

::: resultat
$m$ est strictement décroissante sur $]-\infty\,;-1[$ et sur $]1\,;+\infty[$ ; asymptotes verticales $x = -1$ et $x = 1$, asymptote horizontale $y = 0$ en $-\infty$ et en $+\infty$.
:::

::: remarque
$m(-x) = \ln\left(\dfrac{x - 1}{x + 1}\right) = -m(x)$ : $m$ est impaire, sa courbe est symétrique par rapport à l’origine.
:::

[IMAGE_5]

Solution:
<!-- optitab:1 -->
1. $D_f = \left]\frac{1}{2}\,;+\infty\right[$, $f'(x) = \dfrac{2}{2x - 1} \gt 0$ : $f$ croît de $-\infty$ à $+\infty$ ; asymptote $x = \frac{1}{2}$.
2. $D_g = ]0\,;+\infty[$, $g'(x) = \ln x + 1$ : $g$ décroît sur $\left]0\,;\frac{1}{e}\right]$, croît ensuite ; minimum $-\frac{1}{e}$ ; limites $0$ en $0^+$ et $+\infty$ en $+\infty$.
3. $D_h = ]-\infty\,;1[ \cup ]2\,;+\infty[$, $h'(x) = \dfrac{2x - 3}{x^2 - 3x + 2}$ : $h$ décroît sur $]-\infty\,;1[$, croît sur $]2\,;+\infty[$ ; limites $+\infty$ en $\pm\infty$, $-\infty$ en $1^-$ et $2^+$.
4. $D_k = ]0\,;+\infty[$, $k'(x) = \dfrac{1 - 2\ln x}{x^3}$ : maximum $\frac{1}{2e}$ en $\sqrt{e}$ ; limites $-\infty$ en $0^+$ et $0$ en $+\infty$.
5. $D_m = ]-\infty\,;-1[ \cup ]1\,;+\infty[$, $m'(x) = \dfrac{-2}{x^2 - 1} \lt 0$ : $m$ décroît sur chaque intervalle ; limites $0$ en $\pm\infty$, $-\infty$ en $-1^-$, $+\infty$ en $1^+$.

=== Problème - Synthèse en cinq questions indépendantes
Id: 1251
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Les cinq questions sont indépendantes.

1. Étudier complètement la fonction $f(x) = \ln\left(x^2 - 4x + 3\right)$ : ensemble de définition, dérivée, variations, limites.
2. Résoudre le système $\begin{cases} \ln x + \ln y = \ln 12 \\ \ln x - \ln y = \ln 3 \end{cases}$
3. Montrer que $\ln(1 + x) \le x$ pour tout réel $x \gt -1$.
4. Calculer $\lim\limits_{x \to +\infty} \dfrac{\ln\left(x^2 + 1\right)}{x}$.
5. Déterminer les valeurs du réel $a$ pour lesquelles l’équation $\ln x = ax$ admet exactement une solution dans $]0\,;+\infty[$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Étude complète de $f(x) = \ln\left(x^2 - 4x + 3\right)$

::: methode
Domaine par le signe du trinôme, dérivée $\dfrac{u'}{u}$, puis variations et limites sur chaque intervalle.
:::

::: etape Racines du trinôme
$\Delta = (-4)^2 - 4 \times 1 \times 3 = 4$, racines $x_1 = \frac{4 - 2}{2} = 1$ et $x_2 = \frac{4 + 2}{2} = 3$ :

$$x^2 - 4x + 3 = (x - 1)(x - 3)$$
:::

::: point Signe de $x^2 - 4x + 3$
::: tableau
x : -\infty, 1, 3, +\infty
x - 1 : , -, z, +, t, +,
x - 3 : , -, t, -, z, +,
x^2 - 4x + 3 : , +, z, -, z, +,
:::
:::

::: etape Ensemble de définition
$x^2 - 4x + 3 \gt 0$ pour $x \in ]-\infty\,;1[ \cup ]3\,;+\infty[$ :

$$D_f = ]-\infty\,;1[ \cup ]3\,;+\infty[$$
:::

::: etape Dérivée
Avec $u(x) = x^2 - 4x + 3$ et $u'(x) = 2x - 4$ :

$$
\begin{aligned}
f'(x) &= \frac{2x - 4}{x^2 - 4x + 3} \\
&= \frac{2(x - 2)}{(x - 1)(x - 3)}
\end{aligned}
$$
:::

::: etape Signe de la dérivée
Sur $D_f$, le dénominateur est strictement positif : $f'(x)$ a le signe de $x - 2$, qui s’annule en $2 \notin D_f$.
- Sur $]-\infty\,;1[$ : $x - 2 \lt 0$, donc $f'(x) \lt 0$.
- Sur $]3\,;+\infty[$ : $x - 2 \gt 0$, donc $f'(x) \gt 0$.
:::

::: etape Limites aux bornes
- En $1^-$ et en $3^+$ : $x^2 - 4x + 3 \to 0^+$, donc $f(x) \to -\infty$.
- En $-\infty$ et en $+\infty$ : $x^2 - 4x + 3 \to +\infty$, donc $f(x) \to +\infty$.
:::

::: point Tableau de variations
::: tableau
x : -\infty, 1, 3, +\infty
f'(x) : , -, d, h, d, +,
f(x) : +/+\infty, -D/-\infty, D-/-\infty, +/+\infty
:::
:::

::: resultat
$f$ est strictement décroissante sur $]-\infty\,;1[$ et strictement croissante sur $]3\,;+\infty[$ ; asymptotes verticales $x = 1$ et $x = 3$. Comme $f(4 - x) = f(x)$, la courbe est symétrique par rapport à la droite $x = 2$.
:::

[IMAGE_1]

## Question 2 : Résoudre le système

::: methode
Domaine ($x \gt 0$ et $y \gt 0$), puis règles du produit et du quotient pour se ramener à un système sans logarithme.
:::

::: etape Domaine
$\ln x$ et $\ln y$ existent si et seulement si $x \gt 0$ et $y \gt 0$.
:::

::: etape Éliminer les logarithmes
$$
\begin{aligned}
\ln x + \ln y = \ln 12 &\iff \ln(xy) = \ln 12 \\
&\iff xy = 12 \\
\ln x - \ln y = \ln 3 &\iff \ln\left(\frac{x}{y}\right) = \ln 3 \\
&\iff \frac{x}{y} = 3
\end{aligned}
$$
:::

::: etape Résoudre le système obtenu
La deuxième équation donne $x = 3y$. En remplaçant dans la première : $3y^2 = 12$, soit $y^2 = 4$, donc $y = 2$ ou $y = -2$.
:::

::: etape Tenir compte du domaine
$y \gt 0$ impose $y = 2$, puis $x = 3 \times 2 = 6$. Vérification : $\ln 6 + \ln 2 = \ln 12$ et $\ln 6 - \ln 2 = \ln 3$.
:::

::: resultat
$$(x\,;y) = (6\,;2)$$
:::

## Question 3 : Montrer que $\ln(1 + x) \le x$ pour tout $x \gt -1$

::: methode
Étudier le signe de la différence $g(x) = x - \ln(1 + x)$ grâce à ses variations.
:::

::: etape Fonction auxiliaire
On pose $g(x) = x - \ln(1 + x)$ pour $x \gt -1$. Il s’agit de montrer que $g(x) \ge 0$.
:::

::: etape Dérivée
$$
\begin{aligned}
g'(x) &= 1 - \frac{1}{1 + x} \\
&= \frac{1 + x - 1}{1 + x} \\
&= \frac{x}{1 + x}
\end{aligned}
$$

Sur $]-1\,;+\infty[$, $1 + x \gt 0$ : $g'(x)$ a le signe de $x$.
:::

::: etape Limites aux bornes
- En $-1^+$ : $\ln(1 + x) \to -\infty$, donc $g(x) \to -1 + \infty = +\infty$.
- En $+\infty$ (forme « $\infty - \infty$ ») : avec $X = 1 + x$,

$$g(x) = X - 1 - \ln X = X\left(1 - \frac{\ln X}{X}\right) - 1$$

Comme $\dfrac{\ln X}{X} \to 0$ quand $X \to +\infty$, on obtient $g(x) \to +\infty$.
:::

::: point Tableau de variations
::: tableau
x : -1, 0, +\infty
g'(x) : d, -, z, +,
g(x) : D+/+\infty, -/0, +/+\infty
:::
:::

::: etape Conclusion
$g$ admet un minimum égal à $g(0) = 0 - \ln 1 = 0$. Donc $g(x) \ge 0$ pour tout $x \gt -1$, c’est-à-dire $\ln(1 + x) \le x$.
:::

::: resultat
Pour tout réel $x \gt -1$ : $\ln(1 + x) \le x$, avec égalité seulement pour $x = 0$.
:::

::: remarque
La droite d’équation $y = x$ est la tangente en $0$ à la courbe de $x \mapsto \ln(1 + x)$ : la courbe est sous sa tangente.
:::

[IMAGE_2]

## Question 4 : Calculer $\lim\limits_{x \to +\infty} \dfrac{\ln\left(x^2 + 1\right)}{x}$

::: methode
Factoriser par le terme dominant $x^2$ dans le logarithme, puis utiliser $\dfrac{\ln x}{x} \to 0$.
:::

::: etape Factoriser dans le logarithme
Pour $x \gt 0$ : $x^2 + 1 = x^2\left(1 + \frac{1}{x^2}\right)$, donc

$$
\begin{aligned}
\ln\left(x^2 + 1\right) &= \ln\left(x^2\right) + \ln\left(1 + \frac{1}{x^2}\right) \\
&= 2\ln x + \ln\left(1 + \frac{1}{x^2}\right)
\end{aligned}
$$
:::

::: etape Séparer le quotient
$$\frac{\ln\left(x^2 + 1\right)}{x} = 2 \times \frac{\ln x}{x} + \frac{1}{x}\ln\left(1 + \frac{1}{x^2}\right)$$
:::

::: etape Limites des deux termes
- $\dfrac{\ln x}{x} \to 0$ (croissance comparée).
- $1 + \dfrac{1}{x^2} \to 1$, donc $\ln\left(1 + \dfrac{1}{x^2}\right) \to 0$ ; et $\dfrac{1}{x} \to 0$ : le produit tend vers $0$.
:::

::: resultat
$$\lim_{x \to +\infty} \frac{\ln\left(x^2 + 1\right)}{x} = 2 \times 0 + 0 = 0$$
:::

## Question 5 : Nombre de solutions de $\ln x = ax$ selon $a$

::: methode
Étudier $h(x) = \ln x - ax$ sur $]0\,;+\infty[$ et compter ses annulations (corollaire du théorème des valeurs intermédiaires).
:::

::: etape Fonction auxiliaire et dérivée
On pose $h(x) = \ln x - ax$ pour $x \gt 0$ : $\ln x = ax \iff h(x) = 0$.

$$h'(x) = \frac{1}{x} - a = \frac{1 - ax}{x}$$
:::

::: etape Cas $a \le 0$
Pour $x \gt 0$, $1 - ax \ge 1 \gt 0$, donc $h'(x) \gt 0$ : $h$ est continue et strictement croissante.
- En $0^+$ : $\ln x \to -\infty$ et $ax \to 0$, donc $h(x) \to -\infty$.
- En $+\infty$ : $\ln x \to +\infty$ et $-ax \ge 0$, donc $h(x) \to +\infty$.

D’après le corollaire du théorème des valeurs intermédiaires, $h$ s’annule **exactement une fois**.
:::

::: etape Cas $a \gt 0$ : variations
$h'(x)$ a le signe de $1 - ax$ : positif sur $\left]0\,;\frac{1}{a}\right[$, négatif sur $\left]\frac{1}{a}\,;+\infty\right[$. Maximum :

$$
\begin{aligned}
h\left(\frac{1}{a}\right) &= \ln\left(\frac{1}{a}\right) - a \times \frac{1}{a} \\
&= -\ln a - 1
\end{aligned}
$$
:::

::: etape Cas $a \gt 0$ : limites
- En $0^+$ : $h(x) \to -\infty$.
- En $+\infty$ : $h(x) = x\left(\dfrac{\ln x}{x} - a\right)$ avec $\dfrac{\ln x}{x} - a \to -a \lt 0$, donc $h(x) \to -\infty$.
:::

::: point Tableau de variations (cas $a \gt 0$)
::: tableau
x : 0, \frac{1}{a}, +\infty
h'(x) : d, +, z, -,
h(x) : D-/-\infty, +/-\ln a - 1, -/-\infty
:::
:::

::: etape Cas $a \gt 0$ : discussion selon le signe du maximum
- Si $-\ln a - 1 \gt 0$, soit $0 \lt a \lt \frac{1}{e}$ : une solution sur $\left]0\,;\frac{1}{a}\right[$ et une sur $\left]\frac{1}{a}\,;+\infty\right[$, donc **deux** solutions.
- Si $-\ln a - 1 = 0$, soit $a = \frac{1}{e}$ : le maximum vaut $0$, atteint seulement en $x = e$ : **une** solution.
- Si $-\ln a - 1 \lt 0$, soit $a \gt \frac{1}{e}$ : $h(x) \lt 0$ partout, **aucune** solution.
:::

::: resultat
L’équation $\ln x = ax$ admet exactement une solution si et seulement si $a \le 0$ ou $a = \dfrac{1}{e}$.
:::

::: remarque Interprétation graphique
Les solutions sont les abscisses des points communs à la courbe de $\ln$ et à la droite $y = ax$, qui passe par l’origine. Pour $a = \frac{1}{e}$, cette droite est tangente à la courbe au point $(e\,;1)$.
:::

[IMAGE_3]

Solution:
<!-- optitab:1 -->
1. $D_f = ]-\infty\,;1[ \cup ]3\,;+\infty[$, $f'(x) = \dfrac{2(x - 2)}{(x - 1)(x - 3)}$ : $f$ décroît sur $]-\infty\,;1[$, croît sur $]3\,;+\infty[$ ; limites $+\infty$ en $\pm\infty$, $-\infty$ en $1^-$ et $3^+$ (asymptotes $x = 1$ et $x = 3$).
2. $(x\,;y) = (6\,;2)$
3. $g(x) = x - \ln(1 + x)$ a pour minimum $g(0) = 0$, donc $\ln(1 + x) \le x$ pour tout $x \gt -1$.
4. $\lim\limits_{x \to +\infty} \dfrac{\ln\left(x^2 + 1\right)}{x} = 0$
5. Exactement une solution si et seulement si $a \le 0$ ou $a = \dfrac{1}{e}$ (deux si $0 \lt a \lt \frac{1}{e}$, aucune si $a \gt \frac{1}{e}$).

=== Problème - Étude de ln x − x + 2
Id: 1252
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie sur $]0\,;+\infty[$ par $f(x) = \ln x - x + 2$.

1. Calculer $f'(x)$ et étudier son signe.
2. Dresser le tableau de variations de $f$ et déterminer ses extremums.
3. Calculer les limites de $f$ en $0^+$ et en $+\infty$.
4. Déterminer le nombre de solutions de l’équation $\ln x = x - 2$.
5. Résoudre l’inéquation $\ln x \ge x - 2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $f'(x)$ et étudier son signe

::: methode
Dériver terme à terme, réduire au même dénominateur, puis étudier le signe du numérateur.
:::

::: etape Dérivée
$$
\begin{aligned}
f'(x) &= \frac{1}{x} - 1 \\
&= \frac{1 - x}{x}
\end{aligned}
$$
:::

::: etape Signe
Sur $]0\,;+\infty[$, $x \gt 0$ : $f'(x)$ a le signe de $1 - x$.

::: tableau
x : 0, 1, +\infty
1 - x : , +, z, -,
x : z, +, t, +,
f'(x) : d, +, z, -,
:::
:::

::: resultat
$f'(x) = \dfrac{1 - x}{x}$ : $f'(x) \gt 0$ sur $]0\,;1[$, $f'(1) = 0$ et $f'(x) \lt 0$ sur $]1\,;+\infty[$.
:::

## Question 2 : Tableau de variations et extremums

::: methode
Lire les variations sur le signe de $f'$ et calculer la valeur en $1$.
:::

::: etape Valeur en $1$
$$f(1) = \ln 1 - 1 + 2 = 1$$
:::

::: point Tableau de variations
::: tableau
x : 0, 1, +\infty
f'(x) : d, +, z, -,
f(x) : D-/-\infty, +/1, -/-\infty
:::
:::

::: remarque
Les limites inscrites dans le tableau sont justifiées à la question 3.
:::

::: resultat
$f$ est croissante sur $]0\,;1]$ et décroissante sur $[1\,;+\infty[$ ; elle admet un **maximum** égal à $1$ en $x = 1$, et aucun minimum.
:::

[IMAGE_1]

## Question 3 : Limites en $0^+$ et en $+\infty$

::: methode
En $0^+$, pas d’indétermination ; en $+\infty$, factoriser par $x$ pour lever la forme « $\infty - \infty$ ».
:::

::: etape Limite en $0^+$
$\ln x \to -\infty$ et $-x + 2 \to 2$, donc

$$\lim_{x \to 0^+} f(x) = -\infty$$
:::

::: etape Limite en $+\infty$
$\ln x \to +\infty$ et $-x + 2 \to -\infty$ : forme indéterminée. Pour $x \gt 0$ :

$$f(x) = x\left(\frac{\ln x}{x} - 1 + \frac{2}{x}\right)$$

Or $\dfrac{\ln x}{x} \to 0$ et $\dfrac{2}{x} \to 0$ : la parenthèse tend vers $-1$, donc

$$\lim_{x \to +\infty} f(x) = -\infty$$
:::

::: resultat
$\lim\limits_{x \to 0^+} f(x) = -\infty$ et $\lim\limits_{x \to +\infty} f(x) = -\infty$.
:::

## Question 4 : Nombre de solutions de $\ln x = x - 2$

::: methode
$\ln x = x - 2 \iff f(x) = 0$ ; appliquer le corollaire du théorème des valeurs intermédiaires sur chaque intervalle de monotonie.
:::

::: etape Sur $]0\,;1]$
$f$ est continue et strictement croissante, $\lim\limits_{x \to 0^+} f(x) = -\infty$ et $f(1) = 1 \gt 0$ : l’équation $f(x) = 0$ a une unique solution $\alpha$ dans $]0\,;1[$.
:::

::: etape Sur $[1\,;+\infty[$
$f$ est continue et strictement décroissante, $f(1) = 1 \gt 0$ et $\lim\limits_{x \to +\infty} f(x) = -\infty$ : une unique solution $\beta$ dans $]1\,;+\infty[$.
:::

::: etape Encadrements à la calculatrice
- $f(0{,}15) \approx -0{,}047 \lt 0$ et $f(0{,}16) \approx 0{,}007 \gt 0$, donc $0{,}15 \lt \alpha \lt 0{,}16$.
- $f(3{,}14) \approx 0{,}004 \gt 0$ et $f(3{,}15) \approx -0{,}003 \lt 0$, donc $3{,}14 \lt \beta \lt 3{,}15$.
:::

::: resultat
L’équation $\ln x = x - 2$ admet exactement **deux** solutions : $\alpha \approx 0{,}16$ et $\beta \approx 3{,}15$.
:::

## Question 5 : Résoudre $\ln x \ge x - 2$

::: methode
$\ln x \ge x - 2 \iff f(x) \ge 0$ : lire le signe de $f$ sur son tableau de variations.
:::

::: etape Signe de $f$
- Sur $]0\,;\alpha[$ : $f$ croissante et $f(\alpha) = 0$, donc $f(x) \lt 0$.
- Sur $[\alpha\,;\beta]$ : $f(x) \ge 0$ ($f$ croît de $0$ à $1$, puis décroît de $1$ à $0$).
- Sur $]\beta\,;+\infty[$ : $f$ décroissante et $f(\beta) = 0$, donc $f(x) \lt 0$.
:::

::: resultat
$$S = [\alpha\,;\beta] \quad \text{avec } \alpha \approx 0{,}16 \text{ et } \beta \approx 3{,}15$$
:::

::: remarque Interprétation graphique
Sur $[\alpha\,;\beta]$, la courbe de $\ln$ est au-dessus de la droite d’équation $y = x - 2$.
:::

[IMAGE_2]

Solution:
<!-- optitab:1 -->
1. $f'(x) = \dfrac{1 - x}{x}$ : positive sur $]0\,;1[$, nulle en $1$, négative sur $]1\,;+\infty[$.
2. $f$ croît sur $]0\,;1]$ et décroît sur $[1\,;+\infty[$ ; maximum $f(1) = 1$.
3. $\lim\limits_{x \to 0^+} f(x) = -\infty$ et $\lim\limits_{x \to +\infty} f(x) = -\infty$.
4. Deux solutions : $\alpha \approx 0{,}16$ et $\beta \approx 3{,}15$.
5. $S = [\alpha\,;\beta]$, avec $\alpha \approx 0{,}16$ et $\beta \approx 3{,}15$.
