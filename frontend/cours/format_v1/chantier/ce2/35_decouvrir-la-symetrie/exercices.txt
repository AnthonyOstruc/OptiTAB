=== Découverte - Plier un rectangle
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dessine et découpe un rectangle de 6 cm sur 4 cm. Il n’est pas carré.

1. Teste un pli vertical passant au milieu. Les parties se superposent-elles ?
2. Teste un pli horizontal passant au milieu.
3. Teste une diagonale comme pli.
4. Combien d’axes as-tu trouvés ?
5. Que faut-il regarder pour reconnaître un axe ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Teste un pli vertical passant au milieu. Les parties se superposent-elles ?

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Ramène le côté gauche sur le côté droit, en faisant coïncider les coins. Le pli passe au milieu du haut et du bas.
:::

::: resultat
Oui, le pli vertical du milieu est un axe de symétrie.
:::

## Question 2 : Teste un pli horizontal passant au milieu.

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Ramène le bas sur le haut. Les bords et les coins coïncident.
:::

::: resultat
Le pli horizontal du milieu est aussi un axe de symétrie.
:::

## Question 3 : Teste une diagonale comme pli.

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Ramène un côté de 6 cm contre un côté de 4 cm. Leurs extrémités ne coïncident pas.
:::

::: resultat
Une diagonale n’est pas un axe de ce rectangle.
:::

## Question 4 : Combien d’axes as-tu trouvés ?

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Les deux plis du milieu fonctionnent ; les diagonales ne fonctionnent pas.
:::

::: resultat
Le rectangle non carré possède 2 axes de symétrie.
:::

## Question 5 : Que faut-il regarder pour reconnaître un axe ?

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Après pliage, tous les bords doivent se poser les uns sur les autres, pas seulement deux coins.
:::

::: resultat
Les deux parties doivent se superposer entièrement.
:::

Solution:
<!-- optitab:1 -->
1. Oui, le pli vertical du milieu est un axe de symétrie.
2. Le pli horizontal du milieu est aussi un axe de symétrie.
3. Une diagonale n’est pas un axe de ce rectangle.
4. Le rectangle non carré possède 2 axes de symétrie.
5. Les deux parties doivent se superposer entièrement.

1. Teste le pli vertical du milieu.
2. Teste le pli horizontal du milieu.

4. Teste l’autre diagonale.
5. Combien d’axes le carré possède-t-il ?

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier

:::

::: resultat
Le pli vertical du milieu est un axe.

::: methode
Essayer le pli et vérifier la superposition de tous les bords.
:::

::: etape Observer et vérifier
Plie le bas sur le haut. Les bords coïncident sur toute leur longueur.
:::

::: resultat
Le pli horizontal du milieu est un axe.
:::

## Question 3 : Teste une première diagonale.

::: methode
Utiliser le pliage, le calque ou le report du même nombre de carreaux.
:::

::: etape Observer et vérifier
Plie selon un trait qui relie deux coins opposés. Les deux triangles obtenus se superposent.
:::

::: resultat
La première diagonale est un axe.
:::

## Question 4 : Teste l’autre diagonale.

::: methode
Utiliser le pliage, le calque ou le report du même nombre de carreaux.
:::

::: etape Observer et vérifier
Recommence avec les deux autres coins opposés. Les deux morceaux se superposent encore.
:::

::: resultat

Essayer le pli et vérifier la superposition de tous les bords.

::: etape Observer et vérifier

::: resultat

2. Le pli horizontal du milieu est un axe.

=== Entraînement - De part et d’autre d’un pli horizontal
Id: nouveau-4
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Dessine un axe horizontal sur un quadrillage. Place A à 2 carreaux au-dessus, B à 1 carreau au-dessus et C à 3 carreaux au-dessous.

1. Où se place le point correspondant à A ?
2. Où se place le point correspondant à B ?
3. Où se place le point correspondant à C ?
4. Où se place le point correspondant à un point sur l’axe ?
5. Faut-il compter les lignes ou les intervalles ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Où se place le point correspondant à A ?

::: methode
Garder la ligne ou la colonne et reporter la même distance de l’autre côté du pli.
:::

::: etape Observer et vérifier
Garde la même colonne ; reporte deux intervalles de l’autre côté du trait horizontal.
:::

::: resultat
À 2 carreaux au-dessous de l’axe, dans la même colonne que A.
:::

## Question 2 : Où se place le point correspondant à B ?

::: methode
Garder la ligne ou la colonne et reporter la même distance de l’autre côté du pli.
:::

::: etape Observer et vérifier
Garde la colonne de B et reporte un intervalle sous le trait.
:::

::: resultat
À 1 carreau au-dessous de l’axe, dans la même colonne que B.
:::

## Question 3 : Où se place le point correspondant à C ?

::: methode
Garder la ligne ou la colonne et reporter la même distance de l’autre côté du pli.
:::

::: etape Observer et vérifier
C est sous l’axe ; son point correspondant est donc au-dessus, à la même distance.
:::

::: resultat
À 3 carreaux au-dessus de l’axe, dans la même colonne que C.
:::

## Question 4 : Où se place le point correspondant à un point sur l’axe ?

::: methode
Garder la ligne ou la colonne et reporter la même distance de l’autre côté du pli.
:::

::: etape Observer et vérifier
Le point est dans le pli : il ne bouge pas quand on replie.
:::

::: resultat
Il reste au même endroit sur l’axe.
:::

## Question 5 : Faut-il compter les lignes ou les intervalles ?

::: methode
Utiliser le pliage, le calque ou le report du même nombre de carreaux.
:::

::: etape Observer et vérifier
Un carreau est l’espace entre deux lignes voisines ; compter la ligne de départ ajouterait un carreau à tort.
:::

::: resultat
Il faut compter les intervalles entre les lignes.
:::

Solution:
<!-- optitab:1 -->
1. À 2 carreaux au-dessous de l’axe, dans la même colonne que A.
2. À 1 carreau au-dessous de l’axe, dans la même colonne que B.
3. À 3 carreaux au-dessus de l’axe, dans la même colonne que C.
4. Il reste au même endroit sur l’axe.
5. Il faut compter les intervalles entre les lignes.

::: methode
Utiliser le pliage, le calque ou le report du même nombre de carreaux.

::: etape Observer et vérifier
