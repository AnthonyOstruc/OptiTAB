===Résumé Équations Différentielles Terminal

Titre: Résumé : Équations Différentielles

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> Maîtriser les équations différentielles linéaires du premier ordre : résolution de $\displaystyle y' = a y + b$, conditions initiales, applications. Ce résumé couvre les notions exigibles au programme de Terminale.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Équation différentielle</strong></p>
<p style="margin:5px 0 0 0;">Une équation différentielle est une équation qui met en relation une fonction inconnue $\displaystyle y(x)$ avec sa dérivée $\displaystyle y'(x)$ :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y' = f(x, y)$</p>
</div>
<p style="margin:5px 0 0 0;"><em style="font-size:0.9em;">Au programme : équations linéaires du premier ordre de la forme $\displaystyle y' = a y + b$</em></p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Résolution de $\displaystyle y' = a y + b$</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Solution générale</strong></p>
<p style="margin:5px 0 0 0;">Pour l'équation différentielle $\displaystyle y' = a y + b$ avec $\displaystyle a \neq 0$, la solution générale est :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x) = C e^{a x} - \frac{b}{a}$</p>
</div>
<p style="margin:5px 0 0 0;"><em style="font-size:0.9em;">où $\displaystyle C$ est une constante réelle déterminée par la condition initiale</em></p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Méthode - Résolution</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px;">
<li style="margin:5px 0;">Résoudre l'équation homogène $\displaystyle y' = a y$ : $\displaystyle y_h = C e^{a x}$</li>
<li style="margin:5px 0;">Trouver une solution particulière constante : $\displaystyle y_p = -\frac{b}{a}$</li>
<li style="margin:5px 0;">Solution générale : $\displaystyle y = y_h + y_p = C e^{a x} - \frac{b}{a}$</li>
</ol>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Équation</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Solution générale</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle y' = a y$ (homogène)</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle y(x) = C e^{a x}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">$\displaystyle y' = a y + b$ (avec $\displaystyle a \neq 0$)</td>
<td style="border:none; padding:18px 16px;">$\displaystyle y(x) = C e^{a x} - \frac{b}{a}$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Conditions initiales</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Condition initiale</strong></p>
<p style="margin:5px 0 0 0;">La constante $\displaystyle C$ est déterminée par une condition initiale :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:200px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y(x_0) = y_0$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Méthode - Déterminer la constante</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px;">
<li style="margin:5px 0;">Écrire la solution générale : $\displaystyle y(x) = C e^{a x} - \frac{b}{a}$</li>
<li style="margin:5px 0;">Remplacer $\displaystyle x$ par $\displaystyle x_0$ et $\displaystyle y$ par $\displaystyle y_0$</li>
<li style="margin:5px 0;">Résoudre l'équation pour trouver $\displaystyle C$</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Applications</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Application</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Équation et solution</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Croissance exponentielle</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle P' = k P$<br>$\displaystyle P(t) = P_0 e^{k t}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Décroissance radioactive</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle N' = -\lambda N$<br>$\displaystyle N(t) = N_0 e^{-\lambda t}$<br><em style="font-size:0.9em;">Demi-vie : $\displaystyle T_{1/2} = \frac{\ln 2}{\lambda}$</em></td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Refroidissement</td>
<td style="border:none; padding:18px 16px;">$\displaystyle T' = -k(T - T_a)$<br>$\displaystyle T(t) = T_a + (T_0 - T_a) e^{-k t}$</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Piège fréquent</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Correction</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Oublier la constante $\displaystyle C$</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Toujours inclure $\displaystyle C$ dans la solution générale</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Mauvais signe pour l'équation homogène</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Pour $\displaystyle y' = a y$, la solution est $\displaystyle C e^{a x}$ (attention au signe de $\displaystyle a$)</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Erreur dans la solution particulière</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Pour $\displaystyle y' = a y + b$, la solution particulière constante est $\displaystyle -\frac{b}{a}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier d'appliquer la condition initiale</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Toujours utiliser $\displaystyle y(x_0) = y_0$ pour déterminer $\displaystyle C$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; padding:18px 16px;">Ne pas vérifier la solution</td>
<td style="border:none; padding:18px 16px;">Dériver la solution et vérifier qu'elle satisfait l'équation</td>
</tr>
</tbody>
</table>
</div>
