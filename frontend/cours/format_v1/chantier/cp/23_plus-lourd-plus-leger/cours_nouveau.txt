Titre: Les masses : comparer des objets
<!-- optitab:1 -->
::: objectifs
Je compare des masses en manipulant.
:::

## I. J’observe et je manipule

::: methode Avec le matériel
Soupèse deux boîtes de même forme mais de masses différentes. Vérifie ensuite avec une balance.
:::

[IMAGE_1]

## II. Je comprends

::: definition Les repères
Une masse se compare avec les mains ou une balance.

Sur une balance à plateaux, le côté le plus bas porte la masse la plus grande.

Deux plateaux au même niveau indiquent des masses égales si la balance est réglée.
:::

## III. Je fais pas à pas

::: methode
1. Je soupèse les objets pour faire une première comparaison.
2. Je vérifie avec une balance bien réglée.
3. Le plateau le plus bas porte l’objet le plus lourd.
4. Si les plateaux restent au même niveau, les masses sont égales.
:::
::: exemple
Le plateau A est plus bas que le plateau B : A est plus lourd que B.
:::

## IV. À toi de jouer

::: exemple
Sur la balance de l’exemple, quelle boîte est la plus légère ?
:::
::: resultat Je vérifie
B, puisque son plateau est plus haut.
:::
::: attention
La taille ne donne pas la masse : une grosse boîte vide peut être plus légère qu’une petite boîte pleine.
:::
::: retenir
Plateau plus bas : objet plus lourd.

Plateaux au même niveau : masses égales, si la balance est réglée.
:::
