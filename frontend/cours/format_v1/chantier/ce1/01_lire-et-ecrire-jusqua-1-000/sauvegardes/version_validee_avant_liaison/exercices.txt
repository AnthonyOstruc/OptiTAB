===
Découverte - Des plaques et des barres
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le matériel contient 3 plaques de 100, 2 barres de 10 et 5 cubes unités.

[IMAGE_1]

1. Écris le nombre en chiffres et en lettres.
2. Quelle quantité le chiffre des centaines représente-t-il ?
3. Décompose le nombre en centaines, dizaines et unités.
4. Écris le nombre obtenu en ajoutant une dizaine.
5. Écris les deux nombres qui encadrent immédiatement le nombre de départ.

Étapes:
<!-- optitab:1 -->

## Question 1 : Écris le nombre en chiffres et en lettres.

::: methode
Réunis les centaines, les dizaines et les unités avant de lire le nombre.
:::

::: etape Raisonner
3 centaines valent 300, 2 dizaines valent 20 et les unités valent 5. $325=300+20+5$.
:::

::: resultat
$325$ : trois-cent-vingt-cinq.
:::

## Question 2 : Quelle quantité le chiffre des centaines représente-t-il ?

::: methode
Une centaine représente cent objets.
:::

::: etape Raisonner
Le chiffre 3 occupe le rang des centaines : $3\times100=300$.
:::

::: resultat
$300$ unités.
:::

## Question 3 : Décompose le nombre en centaines, dizaines et unités.

::: methode
Garde les rangs dans l’ordre ; un zéro signifie que ce rang est vide.
:::

::: etape Raisonner
On lit 3 centaines, 2 dizaines et 5 unités. La somme doit redonner le nombre.
:::

::: resultat
$325=300+20+5$.
:::

## Question 4 : Écris le nombre obtenu en ajoutant une dizaine.

::: methode
Ajoute dix unités ; échange dix dizaines contre une centaine si nécessaire.
:::

::: etape Raisonner
Une dizaine vaut 10 unités. $325+10=335$.
:::

::: resultat
$335$.
:::

## Question 5 : Écris les deux nombres qui encadrent immédiatement le nombre de départ.

::: methode
Retire une unité pour le précédent ; ajoute une unité pour le suivant.
:::

::: etape Raisonner
$325-1=324$ et $325+1=326$. Les trois nombres se suivent.
:::

::: resultat
$324<325<326$.
:::

Solution:
<!-- optitab:1 -->
1. $325$ : trois-cent-vingt-cinq.
2. $300$ unités.
3. $325=300+20+5$.
4. $335$.
5. $324<325<326$.

===
Entraînement - Passer une centaine
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Voici une suite de nombres qui avancent d’une unité : 397 ; 398 ; … ; … ; 401.

1. Quels nombres manquent ?
2. Quel nombre est juste avant 397 ?
3. Décompose 399.
4. Combien de centaines et d’unités isolées contient 400 ?
5. Continue la suite de deux nombres après 401.

Étapes:
<!-- optitab:1 -->

## Question 1 : Quels nombres manquent ?

::: methode
Ajoute une unité à chaque fois ; après 399, échange dix dizaines contre une centaine.
:::

::: etape Raisonner
$398+1=399$ puis $399+1=400$.
:::

::: resultat
$399$ et $400$.
:::

## Question 2 : Quel nombre est juste avant 397 ?

::: methode
Recule d’une unité.
:::

::: etape Raisonner
$397-1=396$.
:::

::: resultat
$396$.
:::

## Question 3 : Décompose 399.

::: methode
Lis chaque rang.
:::

::: etape Raisonner
Le 3 représente 300, le premier 9 représente 90 et le dernier 9 représente 9.
:::

::: resultat
$399=300+90+9$.
:::

## Question 4 : Combien de centaines et d’unités isolées contient 400 ?

::: methode
Regroupe les 400 unités en plaques de cent.
:::

::: etape Raisonner
$4\times100=400$ ; aucune dizaine ni unité ne reste.
:::

::: resultat
4 centaines et 0 unité isolée.
:::

## Question 5 : Continue la suite de deux nombres après 401.

::: methode
Ajoute encore une unité à chaque étape.
:::

::: etape Raisonner
$401+1=402$ ; $402+1=403$.
:::

::: resultat
$402$ ; $403$.
:::

Solution:
<!-- optitab:1 -->
1. $399$ et $400$.
2. $396$.
3. $399=300+90+9$.
4. 4 centaines et 0 unité isolée.
5. $402$ ; $403$.

===
Entraînement - Avancer de cent en cent
Id: nouveau-6
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La suite commence par 250 ; 350 ; … ; … ; …

1. Quel est le pas de cette suite ?
2. Complète les trois places vides.
3. Quels chiffres ne changent pas dans cette suite ?
4. Quel nombre précède 250 avec le même pas ?
5. Combien d’ajouts de 100 séparent 250 et 650 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel est le pas de cette suite ?

::: methode
Cherche ce qui est ajouté entre les deux premiers nombres.
:::

::: etape Raisonner
$350-250=100$.
:::

::: resultat
On ajoute $100$.
:::

## Question 2 : Complète les trois places vides.

::: methode
Ajoute une centaine à chaque nombre.
:::

::: etape Raisonner
$350+100=450$, $450+100=550$, $550+100=650$.
:::

::: resultat
$450$ ; $550$ ; $650$.
:::

## Question 3 : Quels chiffres ne changent pas dans cette suite ?

::: methode
Compare les rangs des cinq nombres.
:::

::: etape Raisonner
250, 350, 450, 550 et 650 ont tous 5 dizaines et 0 unité.
:::

::: resultat
Le chiffre des dizaines reste 5 ; celui des unités reste 0.
:::

## Question 4 : Quel nombre précède 250 avec le même pas ?

::: methode
Retire une centaine.
:::

::: etape Raisonner
$250-100=150$.
:::

::: resultat
$150$.
:::

## Question 5 : Combien d’ajouts de 100 séparent 250 et 650 ?

::: methode
Compte les passages : 250 vers 350, puis 450, 550, 650.
:::

::: etape Raisonner
Il y a quatre passages ; $250+4\times100=650$.
:::

::: resultat
4 ajouts de 100.
:::

Solution:
<!-- optitab:1 -->
1. On ajoute $100$.
2. $450$ ; $550$ ; $650$.
3. Le chiffre des dizaines reste 5 ; celui des unités reste 0.
4. $150$.
5. 4 ajouts de 100.

Problème - Construire mille
Id: nouveau-8
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Tu prépares des plaques de 100 cubes pour atteindre 1 000 cubes.

1. Combien de plaques faut-il ?
2. Combien de cubes contiennent 9 plaques ?
3. Combien manque-t-il alors pour obtenir 1 000 cubes ?
4. Combien de barres de 10 remplace une plaque ?
5. Avec 8 plaques et 20 barres de 10, atteint-on 1 000 cubes ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Combien de plaques faut-il ?

::: methode
Compte de cent en cent jusqu’à mille.
:::

::: etape Raisonner
100, 200, 300, 400, 500, 600, 700, 800, 900, 1 000 : dix plaques.
:::

::: resultat
10 plaques de 100.
:::

## Question 2 : Combien de cubes contiennent 9 plaques ?

::: methode
Une plaque contient 100 cubes ; répète cette quantité neuf fois.
:::

::: etape Raisonner


$9\times100=900$.
:::

::: resultat
$900$ cubes.
:::

## Question 3 : Combien manque-t-il alors pour obtenir 1 000 cubes ?

::: methode
Cherche le complément de 900 à 1 000.
:::

::: etape Raisonner


$1000-900=100$.
:::

::: resultat
$100$ cubes.
:::

## Question 4 : Combien de barres de 10 remplace une plaque ?

::: methode
Dix dizaines forment une centaine.
:::

::: etape Raisonner
$10\times10=100$.
:::

::: resultat
10 barres de 10.
:::

## Question 5 : Avec 8 plaques et 20 barres de 10, atteint-on 1 000 cubes ?

::: methode
Échange les vingt dizaines contre deux centaines.
:::

::: etape Raisonner
$8\times100=800$, $20\times10=200$ et $800+200=1000$.
:::

::: resultat
Oui : $1000$ cubes.
:::

Solution:
<!-- optitab:1 -->
1. 10 plaques de 100.
2. $900$ cubes.
3. $100$ cubes.
4. 10 barres de 10.
5. Oui : $1000$ cubes.
