Description: Cours complet sur les angles en 6ème : reconnaître un angle droit, aigu, obtus, mesurer un angle simple avec le rapporteur, tracer un angle donné, manipulation de l'équerre et du rapporteur, et exercices de classification d'angles.

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce qu'un angle ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 L'angle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>angle</strong> est une figure géométrique formée par deux demi-droites (ou segments) qui partent du même point.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point commun s'appelle le <strong>sommet</strong> de l'angle.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les deux demi-droites s'appellent les <strong>côtés</strong> de l'angle. Les côtés d'un angle sont des demi-droites qui ont la même origine (le sommet).</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Mesure d'un angle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On mesure les angles en <strong>degrés</strong>, notés <strong>°</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : un angle droit mesure <strong>90°</strong>, un angle aigu peut mesurer <strong>30°</strong>, un angle obtus <strong>120°</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tout autour d'un point, on a un tour complet de <strong>360°</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">L'angle formé par les demi-droites <strong>[OA)</strong> et <strong>[OB)</strong> se note <strong>AÔB</strong> ou <strong>angle AOB</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Le sommet est le point <strong>O</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les côtés sont <strong>[OA)</strong> et <strong>[OB)</strong>.</li>
                <li style="margin:0; text-align:left;">On peut écrire : <strong>AÔB = 45°</strong> pour dire « l'angle AOB mesure 45 degrés ».</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_1]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Les différents types d'angles</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Classification des angles</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 L'angle droit</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>angle droit</strong> mesure exactement <strong>90°</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On le reconnaît avec une <strong>équerre</strong> ou en voyant un petit carré au sommet.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 L'angle aigu</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>angle aigu</strong> mesure <strong>moins de 90°</strong> (entre 0° et 90°).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il est plus petit qu'un angle droit.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 L'angle obtus</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>angle obtus</strong> mesure <strong>plus de 90°</strong> mais <strong>moins de 180°</strong> (entre 90° et 180°).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il est plus grand qu'un angle droit.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 L'angle plat</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>angle plat</strong> mesure <strong>180°</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ses deux côtés sont dans le même alignement mais pointent en sens contraire.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Angle droit</strong> : 90° (coin d'une feuille, coin d'une table).</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Angle aigu</strong> : 30°, 45°, 60° (plus petit qu'un angle droit).</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Angle obtus</strong> : 120°, 150° (plus grand qu'un angle droit mais moins de 180°).</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Angle plat</strong> : 180° (forme une ligne droite).</li>
                <li style="margin:0; text-align:left;">Dans la vie courante : l'angle entre les aiguilles d'une horloge à <strong>3h</strong> (90°), à <strong>2h</strong> (60°), à <strong>4h</strong> (120°).</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_2]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Le rapporteur</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Présentation du rapporteur</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le rapporteur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>rapporteur</strong> est un instrument qui permet de <strong>mesurer</strong> et de <strong>tracer</strong> des angles.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il a la forme d'un <strong>demi-cercle</strong> ou d'un <strong>cercle complet</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur le rapporteur, on lit les mesures en <strong>degrés (°)</strong> de 0° à 180° (demi-cercle) ou de 0° à 360° (cercle complet).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Les parties du rapporteur :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Le <strong>centre</strong> : point au milieu du bord droit (marqué souvent par un petit trou ou une croix).</li>
                <li style="margin:0 0 8px 0; text-align:left;">La <strong>ligne de base</strong> : le bord droit du rapporteur.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les <strong>graduations</strong> : les marques de 0° à 180° (ou 360°).</li>
                <li style="margin:0; text-align:left;">Deux <strong>échelles</strong> : une de 0° à 180° (de gauche à droite) et une de 180° à 0° (de droite à gauche).</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_3]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Mesurer un angle avec le rapporteur</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode pour mesurer un angle</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Méthode pour mesurer un angle :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer le <strong>centre</strong> du rapporteur sur le <strong>sommet</strong> de l'angle.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Aligner la <strong>ligne de base</strong> du rapporteur avec l'un des <strong>côtés</strong> de l'angle.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Lire la mesure sur la graduation où passe l'autre côté de l'angle.</li>
                <li style="margin:0; text-align:left;">Attention : choisir la bonne échelle (celle qui commence à 0° sur le côté aligné).</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour mesurer l'angle <strong>AÔB</strong> :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer le centre du rapporteur sur le point <strong>O</strong> (sommet).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Aligner la ligne de base avec <strong>[OA)</strong> (un côté).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Lire la mesure sur la graduation où passe <strong>[OB)</strong> (l'autre côté).</li>
                <li style="margin:0; text-align:left;">Si <strong>[OB)</strong> passe par 45°, alors l'angle mesure <strong>45°</strong>.</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_4]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Tracer un angle donné</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode pour tracer un angle</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Méthode pour tracer un angle de mesure donnée :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Tracer une demi-droite <strong>[OA)</strong> (premier côté).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Placer le <strong>centre</strong> du rapporteur sur le point <strong>O</strong> (sommet).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Aligner la <strong>ligne de base</strong> du rapporteur avec <strong>[OA)</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Repérer la graduation correspondant à la mesure souhaitée (par exemple 60°).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Faire une petite marque à cette graduation.</li>
                <li style="margin:0; text-align:left;">Retirer le rapporteur et tracer la demi-droite <strong>[OB)</strong> qui passe par le point <strong>O</strong> et la marque.</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Tracer un angle de 60°</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut tracer l'angle <strong>AÔB = 60°</strong> :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Tracer la demi-droite <strong>[OA)</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Placer le centre du rapporteur sur <strong>O</strong> et aligner avec <strong>[OA)</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Repérer la graduation <strong>60°</strong> et faire une marque.</li>
                <li style="margin:0; text-align:left;">Tracer <strong>[OB)</strong> passant par <strong>O</strong> et la marque.</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_5]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Utiliser l'équerre pour reconnaître un angle droit</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Reconnaître un angle droit</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Avec l'équerre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'<strong>équerre</strong> a un angle droit (90°). On peut l'utiliser pour <strong>vérifier</strong> si un angle est droit.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Méthode pour vérifier un angle droit :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer l'angle droit de l'équerre sur le sommet de l'angle à vérifier.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Aligner un côté de l'équerre avec un côté de l'angle.</li>
                <li style="margin:0; text-align:left;">Vérifier si l'autre côté de l'angle est aligné avec l'autre côté de l'équerre. Si oui, l'angle est droit (90°).</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Les coins d'une feuille de papier sont des angles droits.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les coins d'une table rectangulaire sont des angles droits.</li>
                <li style="margin:0; text-align:left;">Un angle droit se marque souvent avec un petit carré au sommet.</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_6]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Comparer des angles sans mesurer</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthodes de comparaison</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comparer des angles</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut comparer des angles sans utiliser le rapporteur de plusieurs façons :</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <strong>Méthodes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Superposer</strong> deux angles (en transparence ou en découpant sur une feuille).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Utiliser un <strong>gabarit d'angle</strong> (un angle modèle découpé dans du papier).</li>
                <li style="margin:0; text-align:left;">Comparer à un <strong>angle droit</strong> : plus petit → aigu, plus grand → obtus.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Pour comparer deux angles, on peut découper l'un et le superposer sur l'autre.</li>
                <li style="margin:0 0 8px 0; text-align:left;">On peut créer un gabarit d'angle droit (90°) et l'utiliser comme référence.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Si un angle est plus petit qu'un angle droit, c'est un angle aigu. S'il est plus grand, c'est un angle obtus.</li>
                <li style="margin:0; text-align:left;">On peut parfois décomposer un angle en deux angles plus simples pour le tracer (exemple : 30° + 30° = 60°).</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Exercices de classification et de mesure</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Situations pratiques</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 1 : Classification d'angles</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une figure, identifier et classer les angles :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Quels sont les angles droits ? (marqués d'un petit carré)</li>
                <li style="margin:0 0 8px 0; text-align:left;">Quels sont les angles aigus ? (plus petits qu'un angle droit)</li>
                <li style="margin:0; text-align:left;">Quels sont les angles obtus ? (plus grands qu'un angle droit mais moins de 180°)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 2 : Mesurer des angles</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Avec le rapporteur, mesurer les angles suivants :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">L'angle <strong>AÔB</strong></li>
                <li style="margin:0 0 8px 0; text-align:left;">L'angle <strong>BÔC</strong></li>
                <li style="margin:0; text-align:left;">L'angle <strong>CÔD</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour chaque angle, indiquer s'il est aigu, droit ou obtus.</p>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_7]</div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Solutions :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">L'angle <strong>AÔB</strong> mesure <strong>30°</strong> → c'est un <strong>angle aigu</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">L'angle <strong>BÔC</strong> mesure <strong>90°</strong> → c'est un <strong>angle droit</strong>.</li>
                <li style="margin:0; text-align:left;">L'angle <strong>CÔD</strong> mesure <strong>135°</strong> → c'est un <strong>angle obtus</strong>.</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_8]</div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 3 : Tracer des angles</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tracer les angles suivants avec le rapporteur :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Un angle de <strong>45°</strong> (angle aigu)</li>
                <li style="margin:0 0 8px 0; text-align:left;">Un angle de <strong>90°</strong> (angle droit)</li>
                <li style="margin:0 0 8px 0; text-align:left;">Un angle de <strong>120°</strong> (angle obtus)</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour chaque angle, vérifier avec l'équerre s'il est droit, ou estimer s'il est aigu ou obtus.</p>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">X. Erreurs courantes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs courantes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Ne pas bien placer le centre</strong> du rapporteur sur le sommet de l'angle.</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Choisir la mauvaise échelle</strong> sur le rapporteur (il y a deux échelles de 0° à 180°).</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Confondre angle aigu et angle obtus</strong> : se rappeler qu'un angle aigu est plus petit qu'un angle droit.</li>
                <li style="margin:0; text-align:left;"><strong>Oublier de vérifier</strong> avec l'équerre pour un angle droit.</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Conseils :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Toujours vérifier que le <strong>centre</strong> du rapporteur est bien sur le <strong>sommet</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Pour choisir la bonne échelle, regarder celle qui commence à <strong>0°</strong> sur le côté aligné.</li>
                <li style="margin:0 0 8px 0; text-align:left;">S'entraîner à <strong>estimer</strong> visuellement si un angle est aigu, droit ou obtus avant de mesurer.</li>
                <li style="margin:0; text-align:left;">Utiliser l'<strong>équerre</strong> pour vérifier rapidement les angles droits.</li>
            </ul>
