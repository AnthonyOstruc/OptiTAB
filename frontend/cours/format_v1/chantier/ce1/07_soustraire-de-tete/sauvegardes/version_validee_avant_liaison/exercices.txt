Énoncé:
<!-- optitab:1 -->
Travaille les calculs suivants et garde les étapes utiles pour expliquer tes réponses.

[IMAGE_1]

1. Explique les deux retraits du schéma.
2. Vérifie le résultat de départ par l’addition $425+7$.
3. Retire un objet de plus que dans le calcul de départ : $432-8$.
4. Complète $425+\ldots=432$.
5. Retire un objet de moins que dans le calcul de départ : $432-6$.

Étapes:
<!-- optitab:1 -->

## Question 1 : Explique les deux retraits du schéma.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare 7 en 2 et 5. Le premier retrait atteint une dizaine entière.

$432-2=430$.

$430-5=425$.

$432-7=425$.
:::

::: resultat
$432-7=425$.
:::

## Question 2 : Vérifie le résultat de départ par l’addition $425+7$.

::: methode
Je décompose le nombre ajouté ou je passe par la dizaine suivante en corrigeant l’unité de trop.
:::

::: etape Calculer et expliquer
Je décompose 7 : $7=7$.

J’ajoute 7 : $425+7=432$.

Je conclus : $425+7=432$.
:::

::: resultat
$425+7=432$.
:::

## Question 3 : Retire un objet de plus que dans le calcul de départ : $432-8$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare 8 en 2 et 6. Le premier retrait atteint une dizaine entière.

$432-2=430$.

$430-6=424$.

$432-8=424$.
:::

::: resultat
$432-8=424$.
:::

## Question 4 : Complète $425+\ldots=432$.

::: methode
Je cherche la quantité retirée en comparant le départ et ce qui reste.
:::

::: etape Calculer et expliquer
Il faut passer de 425 à 432. Je calcule l’écart entre ces deux nombres.

Je sépare le retrait 425 en centaines, dizaines et unités : $400+20+5=425$.

Je retire 400 : $432-400=32$.

Je retire 20 : $32-20=12$.

Je retire 5 : $12-5=7$.

Je vérifie en ajoutant cet écart : $425+7=432$.
:::

::: resultat
Il manque 7.
:::

## Question 5 : Retire un objet de moins que dans le calcul de départ : $432-6$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.

$432-2=430$.

$430-4=426$.

$432-6=426$.
:::

::: resultat
$432-6=426$.
:::

Solution:
<!-- optitab:1 -->
1. $432-7=425$.
2. $425+7=432$.

## Question 1 : Un carton contient 389 feuilles. On prend 9 feuilles. Combien restent ?

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Retirer 10 enlève une unité de trop : je rends cette unité.

$389-10=379$.

$379+1=380$.

$389-9=380$.
:::

::: resultat
$389-9=380$ : 380 feuilles.
:::

## Question 2 : Vérifie le résultat de départ par l’addition $380+9$.

::: methode
Je décompose le nombre ajouté ou je passe par la dizaine suivante en corrigeant l’unité de trop.
:::

::: etape Calculer et expliquer
Je remplace $9$ par $10$, ce qui ajoute une unité de trop. Je la retire ensuite.

$380+10=390$.

$390-1=389$.

$380+9=389$.
:::

::: resultat
$380+9=389$.
:::

## Question 3 : Retire un objet de plus que dans le calcul de départ : $389-10$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare le retrait 10 en centaines, dizaines et unités : $10=10$.

Je retire 10 : $389-10=379$.
:::

::: resultat
$389-10=379$.
:::

## Question 4 : Complète $380+\ldots=389$.

::: methode
Je cherche la quantité retirée en comparant le départ et ce qui reste.
:::

::: etape Calculer et expliquer
Il faut passer de 380 à 389. Je calcule l’écart entre ces deux nombres.

Je sépare le retrait 380 en centaines, dizaines et unités : $300+80=380$.

Je retire 300 : $389-300=89$.

Je retire 80 : $89-80=9$.

Je vérifie en ajoutant cet écart : $380+9=389$.
:::

::: resultat
Il manque 9.
:::

## Question 5 : Retire un objet de moins que dans le calcul de départ : $389-8$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare le retrait 8 en centaines, dizaines et unités : $8=8$.

Je retire 8 : $389-8=381$.
:::

::: resultat
$389-8=381$.
:::

Solution:

1. $389-9=380$ : 380 feuilles.
2. $380+9=389$.
3. $389-10=379$.
4. Il manque 9.
5. $389-8=381$.

===
Problème - Contrôler le sens d’un retrait
Id: nouveau-9
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Travaille les calculs suivants et garde les étapes utiles pour expliquer tes réponses.

1. Lina annonce un résultat de 405 pour le retrait $402-7$. Vérifie puis corrige.
2. Vérifie le résultat de départ par l’addition $395+7$.
3. Retire un objet de plus que dans le calcul de départ : $402-8$.
4. Complète $395+\ldots=402$.
5. Retire un objet de moins que dans le calcul de départ : $402-6$.

Étapes:
<!-- optitab:1 -->

## Question 1 : Lina annonce un résultat de 405 pour le retrait $402-7$. Vérifie puis corrige.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Un retrait de 7 doit donner moins que 402. Le résultat annoncé 405 est donc impossible.

Je sépare 7 en 2 et 5. Le premier retrait atteint une dizaine entière.

$402-2=400$.

$400-5=395$.

$402-7=395$.
:::

::: resultat
$402-7=395$.
:::

## Question 2 : Vérifie le résultat de départ par l’addition $395+7$.

::: methode
Je décompose le nombre ajouté ou je passe par la dizaine suivante en corrigeant l’unité de trop.
:::

::: etape Calculer et expliquer
Je décompose 7 : $7=7$.

J’ajoute 7 : $395+7=402$.

Je conclus : $395+7=402$.
:::

::: resultat
$395+7=402$.
:::

## Question 3 : Retire un objet de plus que dans le calcul de départ : $402-8$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare 8 en 2 et 6. Le premier retrait atteint une dizaine entière.

$402-2=400$.

$400-6=394$.

$402-8=394$.
:::

::: resultat
$402-8=394$.
:::

## Question 4 : Complète $395+\ldots=402$.

::: methode
Je cherche la quantité retirée en comparant le départ et ce qui reste.
:::

::: etape Calculer et expliquer
Il faut passer de 395 à 402. Je calcule l’écart entre ces deux nombres.

Je sépare le retrait 395 en centaines, dizaines et unités : $300+90+5=395$.

Je retire 300 : $402-300=102$.

Je retire 90 : $102-90=12$.

Je retire 5 : $12-5=7$.

Je vérifie en ajoutant cet écart : $395+7=402$.
:::

::: resultat
Il manque 7.
:::

## Question 5 : Retire un objet de moins que dans le calcul de départ : $402-6$.

::: methode
Je retire les dizaines ou les centaines séparément ; pour un petit retrait, je passe par une dizaine.
:::

::: etape Calculer et expliquer
Je sépare 6 en 2 et 4. Le premier retrait atteint une dizaine entière.

$402-2=400$.

$400-4=396$.

$402-6=396$.
:::

::: resultat
$402-6=396$.
:::

Solution:
<!-- optitab:1 -->
1. $402-7=395$.
2. $395+7=402$.
3. $402-8=394$.
4. Il manque 7.
5. $402-6=396$.
