# Couverture pédagogique — Quadrilatères

Programme de cycle 3, annexe officielle, géométrie de sixième, page 23 : [programme](https://www.education.gouv.fr/sites/default/files/ensel620_annexe2-v2.pdf). Ce chapitre entretient les acquis du cours moyen ; le trapèze réinvestit parallélisme et perpendicularité, avec convention explicitée. Le cours, la fiche et les exercices utilisent les mêmes notations.

Chaque exercice comporte trois questions, trois méthodes, six étapes explicites et trois résultats ; les solutions reprennent les conclusions.
