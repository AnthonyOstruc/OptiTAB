Titre: Les nombres entiers : de 60 à 100

<!-- optitab:1 -->
::: objectifs
Je lis, je représente et je compare jusqu’à 100.
:::

## I. Des paquets de dix

::: definition
74 contient sept dizaines et quatre unités. 74 = 70 + 4. Le nom peut être irrégulier, mais les dizaines et les unités ne changent pas.
:::

Voici quatre-vingt-six cubes : huit dizaines et six unités.

[IMAGE_1]

## II. Les noms à connaître

::: propriete
60 : soixante ; 70 : soixante-dix ; 71 : soixante-et-onze ; 80 : quatre-vingts ; 81 : quatre-vingt-un ; 90 : quatre-vingt-dix ; 100 : cent. 86 se lit « quatre-vingt-six » ; 93 se lit « quatre-vingt-treize ».
:::

## III. Atteindre cent

::: propriete
100, c’est dix dizaines. Après 99 vient 100. Pour comparer, je regarde les dizaines puis les unités. 89 < 98 < 100.
:::

::: methode Pour réussir
Je peux dire le nom à voix haute et montrer les paquets de dix pour vérifier.
:::

::: exemple
93 = 90 + 3. Huit dizaines et douze unités donnent neuf dizaines et deux unités : 92.
:::

::: attention
Le nom oral est parfois irrégulier. Je vérifie avec les paquets de dix.
:::

::: retenir
93 = 90 + 3. Huit dizaines et douze unités donnent neuf dizaines et deux unités : 92.
:::
