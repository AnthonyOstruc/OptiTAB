Titre: Résumé : Équations différentielles

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : solutions de $y' = ay$, $y' = ay + b$ et $y' = ay + f$, condition initiale et modélisation. Programme de Terminale.
:::

## I. Les équations à connaître

| Équation | Solutions sur $\mathbb{R}$ |
|---|---|
| $y' = f$ ($f$ continue) | les primitives de $f$ |
| $y' = ay$ | $x \mapsto Ce^{ax}$, $C \in \mathbb{R}$ |
| $y' = ay + b$, $a \neq 0$ | $x \mapsto Ce^{ax} - \dfrac{b}{a}$, $C \in \mathbb{R}$ |
| $y' = ay + f$ | $x \mapsto y_p(x) + Ce^{ax}$, $y_p$ solution particulière |

::: formule
Solution constante de $y' = ay + b$ : $\quad y = -\dfrac{b}{a}$
:::

1. Une condition initiale $y(x_0) = y_0$ fixe la valeur de $C$ : il y a une **unique** solution, dont la courbe passe par le point $(x_0\,;y_0)$.
2. Vérifier qu’une fonction est solution : calculer sa dérivée et comparer avec l’autre membre.

[IMAGE_1]

## II. La méthode

::: methode Résoudre $y' = ay + b$ avec $y(x_0) = y_0$
1. Mettre l’équation sous la forme $y' = ay + b$ ; lire $a$ et $b$.
2. Calculer la solution constante $-\frac{b}{a}$.
3. Écrire $y(x) = Ce^{ax} - \frac{b}{a}$.
4. Utiliser $y(x_0) = y_0$ pour trouver $C$.
:::

[IMAGE_2]

## III. Modéliser

[IMAGE_3]

1. « Variation proportionnelle à la quantité » : $y' = ky$.
2. « Variation proportionnelle à l’écart avec une valeur $L$ » : $y' = k(y - L)$, de solution constante $L$.
3. Si $a \lt 0$, toutes les solutions tendent vers la solution constante (état d’équilibre).
4. Seuil atteint : on résout $y(t) = s$ à l’aide du logarithme.
5. Décroissance $N' = -\lambda N$ : demi-vie $T = \dfrac{\ln 2}{\lambda}$.

## IV. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Écrire $y = Ce^{ax} + \frac{b}{a}$ : c’est $-\frac{b}{a}$.
2. Utiliser la condition initiale avant d’avoir écrit la solution complète.
3. Oublier la constante $C$ : il y a une infinité de solutions.
4. Mal identifier $a$ et $b$ : $T' = -0{,}1(T - 20)$ s’écrit $T' = -0{,}1T + 2$, donc $a = -0{,}1$ et $b = 2$.
:::

::: remarque Réflexe
Forme $y' = ay + b$ → solution constante → $+\,Ce^{ax}$ → condition initiale → interprétation.
:::
