Titre: Simplification & Réduction d'Expressions

<!-- optitab:1 -->
## Introduction

La **simplification** et la **réduction** consistent à transformer une expression algébrique en une forme plus simple et plus lisible, sans changer sa valeur.

::: definition Idée clé
: Simplifier, c'est **réduire** les termes semblables, **factoriser** les facteurs communs et **ordonner** l'expression de manière standard.
:::

## I. Réduction des termes semblables

### Principe

::: definition Termes semblables
Ce sont des termes qui ont la **même partie littérale** (mêmes variables avec mêmes exposants)
:::

::: methode
1. **Identifier :** repérer les termes semblables (même partie littérale)
2. **Grouper :** mettre ensemble les termes semblables
3. **Réduire :** additionner ou soustraire les coefficients
4. **Ordonner :** écrire les termes par ordre décroissant des degrés
:::

::: exemple
Simplifier $\displaystyle 3x + 5x - 2x$

::: exemple
Tous les termes sont semblables (partie littérale : $x$)
:::

$$\displaystyle 3x + 5x - 2x = (3 + 5 - 2)x = 6x$$
:::

::: exemple
Simplifier $\displaystyle 2x^2 + 3x - x^2 + 5x$

::: etape
Identifier les termes semblables - Termes en $x^2$ : $2x^2$ et $-x^2$ - Termes en $x$ : $3x$ et $5x$
:::

$$\displaystyle 2x^2 + 3x - x^2 + 5x = (2x^2 - x^2) + (3x + 5x) = x^2 + 8x$$
:::

::: exemple
Simplifier $\displaystyle 4ab + 3ab - 2ab$

::: exemple
Tous les termes sont semblables (partie littérale : $ab$)
:::

$$\displaystyle 4ab + 3ab - 2ab = (4 + 3 - 2)ab = 5ab$$
:::

::: attention
Les termes $x^2$ et $x$ ne sont **pas** semblables ! Seuls les termes avec la **même partie littérale exacte** peuvent être réduits.
:::

## II. Simplification de fractions algébriques

### Principe

::: definition Règle fondamentale
$\dfrac{ac}{bc} = \dfrac{a}{b}$ (si $b \neq 0$ et $c \neq 0$)
:::

::: methode
1. **Factoriser :** factoriser le numérateur et le dénominateur
2. **Identifier :** repérer les facteurs communs
3. **Simplifier :** diviser par les facteurs communs
4. **Vérifier :** s'assurer que le dénominateur n'est pas nul
:::

::: exemple
Simplifier $\displaystyle \dfrac{6x}{3x}$

::: exemple
Facteur commun : $x$ (si $x \neq 0$)
:::

$$\displaystyle \dfrac{6x}{3x} = \dfrac{6}{3} = 2$$
:::

::: exemple
Simplifier $\displaystyle \dfrac{x^2 - 4}{x + 2}$

::: etape
Factoriser le numérateur : $x^2 - 4 = (x-2)(x+2)$ (différence de carrés) **Étape 2 :** Facteur commun : $(x+2)$ (si $x \neq -2$)
:::

$$\displaystyle \dfrac{x^2 - 4}{x + 2} = \dfrac{(x-2)(x+2)}{x+2} = x - 2$$
:::

::: exemple
Simplifier $\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9}$

::: etape
Factoriser le numérateur : $x^2 + 6x + 9 = (x+3)^2$ **Étape 2 :** Factoriser le dénominateur : $x^2 - 9 = (x-3)(x+3)$ **Étape 3 :** Facteur commun : $(x+3)$ (si $x \neq 3$ et $x \neq -3$)
:::

$$\displaystyle \dfrac{x^2 + 6x + 9}{x^2 - 9} = \dfrac{(x+3)^2}{(x-3)(x+3)} = \dfrac{x+3}{x-3}$$
:::

::: attention Important
Toujours vérifier les **valeurs interdites** avant de simplifier ! Ne jamais simplifier par $0$.
:::

## III. Simplification avec développement et factorisation

### Principe

::: definition Stratégie
Pour simplifier une expression complexe, on peut alterner entre **développement** et **factorisation** pour identifier les facteurs communs ou les termes semblables.
:::

::: exemple
Simplifier $\displaystyle (x+2)^2 - (x-1)^2$

::: etape
Développer les carrés $(x+2)^2 = x^2 + 4x + 4$ $(x-1)^2 = x^2 - 2x + 1$
:::

$$\displaystyle (x+2)^2 - (x-1)^2 = (x^2 + 4x + 4) - (x^2 - 2x + 1) = x^2 + 4x + 4 - x^2 + 2x - 1 = 6x + 3$$
:::

::: exemple
Simplifier $\displaystyle (x+1)(x-1) + x^2 - 1$

::: etape
Reconnaître : $(x+1)(x-1) = x^2 - 1$ **Étape 2 :** Remplacer et réduire
:::

$$\displaystyle (x+1)(x-1) + x^2 - 1 = (x^2 - 1) + x^2 - 1 = 2x^2 - 2 = 2(x^2 - 1)$$
:::

::: exemple
Simplifier $\displaystyle 3(x+2) - 2(x-1) + x$

::: etape Développer les parenthèses $3(x+2) = 3x + 6$ $-2(x-1) = -2x + 2$
:::

$$\displaystyle 3(x+2) - 2(x-1) + x = 3x + 6 - 2x + 2 + x = (3x - 2x + x) + (6 + 2) = 2x + 8$$
:::

## IV. Simplification de produits et quotients

### Principe

::: definition Règles
$\dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}$ puis simplifier les facteurs communs
:::

::: exemple
Simplifier $\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x}$

::: exemple
Multiplier puis simplifier (si $x \neq 0$)
:::

$$\displaystyle \dfrac{2x}{3} \times \dfrac{9}{4x} = \dfrac{2x \times 9}{3 \times 4x} = \dfrac{18x}{12x} = \dfrac{3}{2}$$
:::

::: exemple
Simplifier $\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1}$

::: etape
Factoriser : $x^2 - 1 = (x-1)(x+1)$ **Étape 2 :** Simplifier les facteurs communs (si $x \neq 1$ et $x \neq -1$)
:::

$$\displaystyle \dfrac{x^2 - 1}{x + 1} \times \dfrac{x + 2}{x - 1} = \dfrac{(x-1)(x+1)}{x+1} \times \dfrac{x+2}{x-1} = \dfrac{x+2}{1} = x + 2$$
:::

## V. Ordre et standardisation

### Principe

::: definition Forme standard
Une expression simplifiée doit être écrite avec les termes ordonnés par **degré décroissant** et les coefficients réduits.
:::

::: methode Ordre d'écriture
1. **Termes de degré supérieur :** $ax^n$ (avec $n$ le plus grand)
2. **Termes de degré intermédiaire :** $bx^{n-1}$, $cx^{n-2}$, etc.
3. **Terme constant :** $d$ (degré $0$)
:::

::: exemple
Ordonner $\displaystyle 5 - 3x + 2x^2$

::: resultat
Forme standard : $\displaystyle 2x^2 - 3x + 5$
:::
:::

::: exemple
Simplifier et ordonner $\displaystyle 3x - x^2 + 5 - 2x + x^2$

::: etape
Réduire les termes semblables - Termes en $x^2$ : $-x^2 + x^2 = 0$ - Termes en $x$ : $3x - 2x = x$
:::

$$\displaystyle 3x - x^2 + 5 - 2x + x^2 = x + 5$$
:::

## VI. Méthode générale et stratégie

::: methode Ordre de travail à suivre
1. **Développer :** supprimer les parenthèses si nécessaire
2. **Réduire :** grouper et réduire les termes semblables
3. **Factoriser :** identifier les facteurs communs si possible
4. **Simplifier :** diviser par les facteurs communs dans les fractions
5. **Ordonner :** écrire sous forme standard (degrés décroissants)
:::

::: exemple
Simplifier $\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4}$

::: etape
Développer le numérateur : $(x+2)^2 - 4 = x^2 + 4x + 4 - 4 = x^2 + 4x$ **Étape 2 :** Factoriser le numérateur : $x^2 + 4x = x(x+4)$ **Étape 3 :** Factoriser le dénominateur : $x^2 - 4 = (x-2)(x+2)$
:::

$$\displaystyle \dfrac{(x+2)^2 - 4}{x^2 - 4} = \dfrac{x(x+4)}{(x-2)(x+2)} = \dfrac{x(x+4)}{(x-2)(x+2)}$$

::: attention
Il n'y a pas de facteur commun entre le numérateur et le dénominateur. L'expression est déjà simplifiée (si $x \neq 2$ et $x \neq -2$).
:::
:::

## VII. Erreurs fréquentes et conseils

::: attention
- **Réduire des termes non semblables :** $x^2 + x \neq 2x$ (ce sont des termes différents !)
- **Simplifier par 0 :** ne jamais diviser par $0$ ou simplifier quand le dénominateur est $0$
- **Oublier les valeurs interdites :** toujours vérifier que les dénominateurs ne sont pas nuls
- **Confondre réduction et développement :** réduire = simplifier, développer = distribuer
- **Oublier d'ordonner :** une expression simplifiée doit être ordonnée par degrés décroissants
- **Simplifier partiellement :** $\dfrac{x+2}{x+2} = 1$ et non $x+2$
:::

::: conseil
- Toujours identifier les **termes semblables** avant de réduire
- Pour les fractions, toujours **factoriser** le numérateur et le dénominateur avant de simplifier
- Vérifier les **valeurs interdites** avant de simplifier une fraction
- Ordonner l'expression finale par **degrés décroissants**
- Vérifier le résultat en **remplaçant** $x$ par une valeur simple
- Pour les expressions complexes, travailler **étape par étape**
:::
