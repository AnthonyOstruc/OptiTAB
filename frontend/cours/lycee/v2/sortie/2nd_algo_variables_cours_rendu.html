🎯 Objectifs du chapitre : utiliser des variables et leurs types, comprendre l’affectation, écrire des calculs en Python, programmer une instruction conditionnelle, une boucle bornée (for) et une boucle non bornée (while), et suivre l’exécution d’un programme pas à pas.

I. Variables, types et affectation

Définition : une variable est une case mémoire repérée par un nom, qui contient une valeur. Ses principaux types sont : entier (int, ex. 7), flottant (float, ex. 2.5), chaîne de caractères (str, ex. "bonjour") et booléen (bool : True ou False).

L’affectation a = 5 range la valeur $\displaystyle 5$ dans la variable a ; l’ancienne valeur est perdue.

⚠️ Attention : le signe = de Python n’est pas une égalité mathématique : a = a + 3 signifie « la nouvelle valeur de a est l’ancienne plus $\displaystyle 3$ ». Pour tester une égalité, on écrit ==.

Exemple (échanger deux variables) : on passe par une variable auxiliaire.

a = 3 b = 8 c = a a = b b = c print(a, b) # affiche 8 3

II. Calculer avec Python

Opérations : +, -, * (produit), / (quotient décimal), // (quotient entier), % (reste) et ** (puissance).

Exemples : 7 / 2 donne 3.5 ; 7 // 2 donne 3 ; 7 % 2 donne 1 ; 2 ** 3 donne 8.

💡 Astuce : n % 2 == 0 teste si $\displaystyle n$ est pair ; pour la racine carrée, on écrit from math import sqrt puis sqrt(2). En Python, la virgule décimale s’écrit avec un point : 2.5.

III. Instruction conditionnelle

Syntaxe : if condition : puis le bloc indenté exécuté si la condition est vraie ; else : introduit le bloc exécuté sinon ; elif ajoute d’autres cas. Comparaisons : ==, !=, <, <=, >, >= ; on combine avec and, or, not.

age = 15 if age >= 18: print("majeur") else: print("mineur")
⚠️ Attention : les deux-points en fin de ligne et l’indentation (décalage de 4 espaces) sont obligatoires : ils délimitent les blocs d’instructions.

IV. Boucle bornée : for

Syntaxe : for i in range(n): répète le bloc $\displaystyle n$ fois, avec i prenant les valeurs $\displaystyle 0, 1, \ldots, n - 1$. range(a, b) donne les entiers de $\displaystyle a$ à $\displaystyle b - 1$.

Un tableau de suivi donne l’état des variables après chaque passage dans la boucle : ici, le programme calcule $\displaystyle 1 + 2 + 3 + 4 = 10$.

V. Boucle non bornée : while

Syntaxe : while condition : répète le bloc tant que la condition est vraie. On l’utilise quand on ne connaît pas à l’avance le nombre de répétitions.

Exemple : plus petit entier $\displaystyle n$ tel que $\displaystyle 2^n \gt 1\,000$.

n = 0 p = 1 while p <= 1000: p = 2 * p n = n + 1 print(n) # affiche 10, car 2 puissance 10 = 1024
⚠️ Attention : la condition doit finir par devenir fausse, sinon le programme tourne sans fin (boucle infinie). Ici, p double à chaque tour, donc finit par dépasser $\displaystyle 1\,000$.

🏆 L’essentiel : une variable a un nom, un type et une valeur ; = affecte, == compare ; if / elif / else pour choisir ; for quand on connaît le nombre de répétitions, while sinon ; deux-points et indentation délimitent les blocs ; un tableau de suivi permet de comprendre un programme.
