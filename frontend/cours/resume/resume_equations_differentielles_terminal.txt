Résumé Équations Différentielles - Terminal
Difficulté: medium

Titre: Résumé : Équations Différentielles - Formules et Méthodes Essentielles
Description: Résumé professionnel des équations différentielles linéaires du premier ordre avec toutes les formules essentielles, méthodes de résolution et applications pour le niveau Terminal.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Équation différentielle :</strong> Une équation qui relie une fonction $\displaystyle y(x)$ et sa dérivée $\displaystyle y'(x)$
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Forme générale (programme bac) :</strong> $\displaystyle y' = a y + b$ où $\displaystyle a$ et $\displaystyle b$ sont des constantes
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Équation homogène :</strong> $\displaystyle y' = a y$ (cas particulier avec $\displaystyle b = 0$)
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">II. Formules de résolution - Tableau récapitulatif</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Type d'équation</th>
                    <th style="border:1px solid #ddd; padding:12px;">Solution générale</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y' = a y$ (homogène)</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y(x) = C e^{a x}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y' = a y + b$ (avec $\displaystyle a \neq 0$)</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y(x) = C e^{a x} - \dfrac{b}{a}$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y' = b$ (cas $\displaystyle a = 0$)</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle y(x) = b x + C$</td>
                </tr>
            </tbody>
        </table>
        
        <div style="background:#fff8dc; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #ffa500;">
            <strong>⚠️ Note :</strong> La constante $\displaystyle C$ est déterminée par une <strong>condition initiale</strong> $\displaystyle y(x_0) = y_0$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">III. Méthode de résolution complète</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
            <strong>📐 Démarche pour résoudre $\displaystyle y' = a y + b$ :</strong>
            <ol style="margin:10px 0; padding-left:20px;">
                <li><strong>Résoudre l'équation homogène :</strong> $\displaystyle y' - a y = 0 \Rightarrow y_h = C e^{a x}$</li>
                <li><strong>Trouver une solution particulière :</strong> chercher une constante $\displaystyle y_p = k$ telle que $\displaystyle 0 = a k + b$</li>
                <li><strong>Solution générale :</strong> $\displaystyle y = y_h + y_p = C e^{a x} - \dfrac{b}{a}$</li>
                <li><strong>Appliquer la condition initiale :</strong> utiliser $\displaystyle y(x_0) = y_0$ pour déterminer $\displaystyle C$</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IV. Exemples types</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple 1 :</strong> $\displaystyle y' = 2y + 4$ avec $\displaystyle y(0) = 1$
            <div style="margin:10px 0; padding-left:15px;">
                <p style="margin:5px 0;">• Équation homogène : $\displaystyle y_h = C e^{2x}$</p>
                <p style="margin:5px 0;">• Solution particulière : $\displaystyle k = -2$</p>
                <p style="margin:5px 0;">• Solution générale : $\displaystyle y = C e^{2x} - 2$</p>
                <p style="margin:5px 0;">• Condition initiale : $\displaystyle 1 = C - 2 \Rightarrow C = 3$</p>
                <p style="margin:5px 0; color:#2e7d32; font-weight:600;">✅ Solution : $\displaystyle y = 3 e^{2x} - 2$</p>
            </div>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple 2 :</strong> $\displaystyle y' = -y + 3$ avec $\displaystyle y(0) = 5$
            <div style="margin:10px 0; padding-left:15px;">
                <p style="margin:5px 0;">• Équation homogène : $\displaystyle y_h = C e^{-x}$</p>
                <p style="margin:5px 0;">• Solution particulière : $\displaystyle k = 3$</p>
                <p style="margin:5px 0;">• Solution générale : $\displaystyle y = C e^{-x} + 3$</p>
                <p style="margin:5px 0;">• Condition initiale : $\displaystyle 5 = C + 3 \Rightarrow C = 2$</p>
                <p style="margin:5px 0; color:#2e7d32; font-weight:600;">✅ Solution : $\displaystyle y = 2 e^{-x} + 3$</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">V. Applications concrètes</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modèles de croissance et décroissance</h3>
        
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Phénomène</th>
                    <th style="border:1px solid #ddd; padding:12px;">Équation</th>
                    <th style="border:1px solid #ddd; padding:12px;">Solution</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Croissance exponentielle</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle P' = k P$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle P(t) = P_0 e^{k t}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;">Décroissance radioactive</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle N' = -\lambda N$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle N(t) = N_0 e^{-\lambda t}$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Refroidissement</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle T' = -k(T - T_a)$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$\displaystyle T(t) = T_a + (T_0 - T_a)e^{-kt}$</td>
                </tr>
            </tbody>
        </table>
        
        <div style="background:#eef6ff; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #3b82f6;">
            <strong>Demi-vie (décroissance radioactive) :</strong> $\displaystyle T_{1/2} = \dfrac{\ln 2}{\lambda}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VI. Méthode alternative : séparation des variables</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>Pour les équations de la forme :</strong> $\displaystyle y' = g(x) h(y)$</p>
            <p style="margin:8px 0;"><strong>Méthode :</strong> On sépare les variables : $\displaystyle \dfrac{dy}{h(y)} = g(x) \, dx$</p>
            <p style="margin:8px 0;"><strong>Puis :</strong> On intègre de chaque côté</p>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple :</strong> $\displaystyle y' = 2xy$ avec $\displaystyle y > 0$
            <div style="margin:10px 0; padding-left:15px;">
                <p style="margin:5px 0;">$\displaystyle \dfrac{dy}{y} = 2x \, dx$</p>
                <p style="margin:5px 0;">$\displaystyle \ln y = x^2 + C$</p>
                <p style="margin:5px 0; color:#2e7d32; font-weight:600;">✅ $\displaystyle y = K e^{x^2}$ avec $\displaystyle K > 0$</p>
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VII. Vérification d'une solution</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
            <strong>📐 Méthode de vérification :</strong>
            <ol style="margin:10px 0; padding-left:20px;">
                <li>Calculer $\displaystyle y'(x)$ en dérivant la solution proposée</li>
                <li>Calculer $\displaystyle a y(x) + b$ avec les valeurs de $\displaystyle a$ et $\displaystyle b$</li>
                <li>Vérifier que $\displaystyle y'(x) = a y(x) + b$</li>
                <li>Vérifier la condition initiale si elle est donnée</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IX. Formules essentielles - Mémo</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
            <p style="margin:8px 0; font-size:1.05em;"><strong>Solution de $\displaystyle y' = ay$ :</strong> $\displaystyle y = Ce^{ax}$</p>
            <p style="margin:8px 0; font-size:1.05em;"><strong>Solution de $\displaystyle y' = ay + b$ :</strong> $\displaystyle y = Ce^{ax} - \dfrac{b}{a}$</p>
            <p style="margin:8px 0; font-size:1.05em;"><strong>Croissance exponentielle :</strong> $\displaystyle P(t) = P_0 e^{kt}$ (si $\displaystyle k > 0$)</p>
            <p style="margin:8px 0; font-size:1.05em;"><strong>Décroissance exponentielle :</strong> $\displaystyle N(t) = N_0 e^{-\lambda t}$ (si $\displaystyle \lambda > 0$)</p>
            <p style="margin:8px 0; font-size:1.05em;"><strong>Demi-vie :</strong> $\displaystyle T_{1/2} = \dfrac{\ln 2}{\lambda}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fdf2f2; padding:15px; border-radius:6px; margin-bottom:15px;">
            <strong>❌ Erreurs fréquentes :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>Oublier la constante $\displaystyle C$ dans la solution générale</li>
                <li>Se tromper de signe dans l'équation homogène</li>
                <li>Erreur de calcul pour la solution particulière $\displaystyle -\dfrac{b}{a}$</li>
                <li>Oublier d'appliquer la condition initiale</li>
                <li>Ne pas vérifier la solution obtenue</li>
                <li>Confondre $\displaystyle e^{ax}$ et $\displaystyle e^{-ax}$</li>
            </ul>
        </div>

        <div style="background:#e8f5e8; padding:15px; border-radius:6px;">
            <strong>✅ Points clés à retenir :</strong>
            <ul style="margin:8px 0; padding-left:20px;">
                <li>L'équation $\displaystyle y' = ay + b$ se résout en <strong>3 étapes</strong> : homogène + particulière + condition initiale</li>
                <li>La solution homogène est toujours de la forme $\displaystyle Ce^{ax}$</li>
                <li>Pour une constante $\displaystyle b \neq 0$, la solution particulière est $\displaystyle y_p = -\dfrac{b}{a}$</li>
                <li><strong>Toujours vérifier</strong> la solution en la réinjectant dans l'équation</li>
                <li>Dans les applications : identifier le type (croissance/décroissance) selon le signe de $\displaystyle a$</li>
                <li>La <strong>séparation des variables</strong> est utile pour $\displaystyle y' = g(x)h(y)$</li>
                <li>Faire attention aux <strong>unités</strong> dans les problèmes concrets</li>
            </ul>
        </div>
    </div>
