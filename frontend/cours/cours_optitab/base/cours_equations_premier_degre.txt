=== Équations 1er Degré - Cours Complet
Difficulty: easy
Ordre: 6

Titre: Équations du Premier Degré - Résolution et Applications
Description: Cours complet sur la résolution des équations du premier degré : méthode, équations avec fractions, problèmes et applications avec exemples détaillés.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">Introduction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">Une <strong>équation du premier degré</strong> est une égalité de la forme $\displaystyle ax + b = 0$ (avec $\displaystyle a \neq 0$) ou plus généralement $\displaystyle ax + b = cx + d$.</p>

        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:15px; border-radius:6px; margin:15px 0; font-size:1em; text-align:center;">
            <strong>Idée clé</strong> : Résoudre une équation, c'est trouver la (ou les) valeur(s) de $\displaystyle x$ qui vérifient l'égalité. La solution d'une équation du premier degré est unique.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Résolution d'équations simples</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0; border-left:4px solid #3498db; padding-left:10px;">Principe</h3>

        <div style="text-align:left; font-size:1em; margin:15px 0; padding:15px; background:#e8f4fd; border-left:6px solid #3498db; border-radius:6px;">
            <strong>Forme générale :</strong> $\displaystyle ax + b = 0$ avec $\displaystyle a \neq 0$<br>
            <strong>Solution :</strong> $\displaystyle x = -\dfrac{b}{a}$
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0; font-size:1em;">
            <strong>📋 Méthode de résolution :</strong>
            <ol style="margin:10px 0; padding-left:25px; line-height:2.5;">
                <li><strong>Isoler :</strong> regrouper tous les termes en $\displaystyle x$ d'un côté et les constantes de l'autre</li>
                <li><strong>Réduire :</strong> simplifier les termes semblables</li>
                <li><strong>Diviser :</strong> diviser par le coefficient de $\displaystyle x$</li>
                <li><strong>Vérifier :</strong> remplacer $\displaystyle x$ par la solution trouvée dans l'équation de départ</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> Résoudre $\displaystyle 3x + 5 = 0$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Isoler $\displaystyle x$ : $\displaystyle 3x = -5$<br>
                <strong>Étape 2 :</strong> Diviser par $\displaystyle 3$ : $\displaystyle x = -\dfrac{5}{3}$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = -\dfrac{5}{3}$<br>
                <strong>Vérification :</strong> $\displaystyle 3 \times \left(-\dfrac{5}{3}\right) + 5 = -5 + 5 = 0$ ✓
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> Résoudre $\displaystyle 2x - 7 = 3x + 1$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Regrouper les termes en $\displaystyle x$ : $\displaystyle 2x - 3x = 1 + 7$<br>
                <strong>Étape 2 :</strong> Simplifier : $\displaystyle -x = 8$<br>
                <strong>Étape 3 :</strong> Multiplier par $\displaystyle -1$ : $\displaystyle x = -8$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = -8$<br>
                <strong>Vérification :</strong> $\displaystyle 2 \times (-8) - 7 = -16 - 7 = -23$ et $\displaystyle 3 \times (-8) + 1 = -24 + 1 = -23$ ✓
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 3 :</strong> Résoudre $\displaystyle 4x + 3 = 4x - 2$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Regrouper : $\displaystyle 4x - 4x = -2 - 3$<br>
                <strong>Étape 2 :</strong> Simplifier : $\displaystyle 0 = -5$
            </div>
            <div style="background:#fff8dc; border-radius:6px; border-left:4px solid #ffa500; padding:15px; margin:10px 0; font-size:1em;">
                <strong>⚠️ Attention :</strong> Cette égalité est <strong>fausse</strong> ! L'équation n'a <strong>aucune solution</strong>.
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 4 :</strong> Résoudre $\displaystyle 5x - 3 = 5x - 3$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Regrouper : $\displaystyle 5x - 5x = -3 + 3$<br>
                <strong>Étape 2 :</strong> Simplifier : $\displaystyle 0 = 0$
            </div>
            <div style="background:#f0f9f0; padding:15px; border-radius:6px; margin:10px 0; font-size:1em;">
                <strong>✅ Conclusion :</strong> Cette égalité est toujours <strong>vraie</strong> ! L'équation a une <strong>infinité de solutions</strong> (tout nombre réel est solution).
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Équations avec développements</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0; border-left:4px solid #3498db; padding-left:10px;">Principe</h3>

        <div style="text-align:left; font-size:1em; margin:15px 0; padding:15px; background:#e8f4fd; border-left:6px solid #3498db; border-radius:6px;">
            <strong>Stratégie :</strong> Quand l'équation contient des parenthèses, il faut d'abord <strong>développer</strong> avant de résoudre.
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> Résoudre $\displaystyle 2(x + 3) = 4x - 1$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Développer : $\displaystyle 2x + 6 = 4x - 1$<br>
                <strong>Étape 2 :</strong> Regrouper : $\displaystyle 2x - 4x = -1 - 6$<br>
                <strong>Étape 3 :</strong> Simplifier : $\displaystyle -2x = -7$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = \dfrac{7}{2}$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> Résoudre $\displaystyle 3(x - 2) - 2(x + 1) = x + 4$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Développer : $\displaystyle 3x - 6 - 2x - 2 = x + 4$<br>
                <strong>Étape 2 :</strong> Réduire : $\displaystyle x - 8 = x + 4$<br>
                <strong>Étape 3 :</strong> Regrouper : $\displaystyle x - x = 4 + 8$<br>
                <strong>Étape 4 :</strong> Simplifier : $\displaystyle 0 = 12$
            </div>
            <div style="background:#fff8dc; border-radius:6px; border-left:4px solid #ffa500; padding:15px; margin:10px 0; font-size:1em;">
                <strong>⚠️ Attention :</strong> Cette égalité est <strong>fausse</strong> ! L'équation n'a <strong>aucune solution</strong>.
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Équations avec fractions</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0; border-left:4px solid #3498db; padding-left:10px;">Principe</h3>

        <div style="text-align:left; font-size:1em; margin:15px 0; padding:15px; background:#e8f4fd; border-left:6px solid #3498db; border-radius:6px;">
            <strong>Méthode :</strong> Pour résoudre une équation avec fractions, on peut :
            <ul style="margin:10px 0; padding-left:25px; line-height:2;">
                <li>Multiplier les deux membres par le <strong>dénominateur commun</strong></li>
                <li>Ou mettre au même dénominateur puis simplifier</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 1 :</strong> Résoudre $\displaystyle \dfrac{x}{2} + 3 = 5$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Isoler la fraction : $\displaystyle \dfrac{x}{2} = 5 - 3 = 2$<br>
                <strong>Étape 2 :</strong> Multiplier par $\displaystyle 2$ : $\displaystyle x = 2 \times 2 = 4$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = 4$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 2 :</strong> Résoudre $\displaystyle \dfrac{x + 1}{3} = \dfrac{x - 2}{2}$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Produit en croix : $\displaystyle 2(x + 1) = 3(x - 2)$<br>
                <strong>Étape 2 :</strong> Développer : $\displaystyle 2x + 2 = 3x - 6$<br>
                <strong>Étape 3 :</strong> Regrouper : $\displaystyle 2x - 3x = -6 - 2$<br>
                <strong>Étape 4 :</strong> Simplifier : $\displaystyle -x = -8$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = 8$
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple 3 :</strong> Résoudre $\displaystyle \dfrac{2x - 1}{4} + \dfrac{x}{3} = 1$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Dénominateur commun : $\displaystyle 12$<br>
                <strong>Étape 2 :</strong> Multiplier par $\displaystyle 12$ : $\displaystyle 12 \times \dfrac{2x - 1}{4} + 12 \times \dfrac{x}{3} = 12 \times 1$<br>
                <strong>Étape 3 :</strong> Simplifier : $\displaystyle 3(2x - 1) + 4x = 12$<br>
                <strong>Étape 4 :</strong> Développer : $\displaystyle 6x - 3 + 4x = 12$<br>
                <strong>Étape 5 :</strong> Réduire : $\displaystyle 10x = 15$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = \dfrac{15}{10} = \dfrac{3}{2}$
            </div>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:4px solid #ffa500; padding:15px; margin:12px 0; font-size:1em;">
            <strong>⚠️ Important :</strong> Toujours vérifier que la solution trouvée n'annule <strong>aucun dénominateur</strong> de l'équation initiale !
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Cas particuliers</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0; border-left:4px solid #3498db; padding-left:10px;">Types de solutions</h3>

        <table style="width:100%; margin-top:15px; border-collapse:collapse; font-size:1em;">
            <thead>
                <tr style="background:#3498db; color:#ffffff;">
                    <th style="padding:10px; border:1px solid #2980b9; text-align:left;">Situation</th>
                    <th style="padding:10px; border:1px solid #2980b9; text-align:left;">Résultat après simplification</th>
                    <th style="padding:10px; border:1px solid #2980b9; text-align:left;">Type de solution</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="padding:10px; border:1px solid #dee2e6; text-align:left;"><strong>Équation normale</strong></td>
                    <td style="padding:10px; border:1px solid #dee2e6; text-align:left;">$\displaystyle ax = b$ avec $\displaystyle a \neq 0$</td>
                    <td style="padding:10px; border:1px solid #dee2e6; text-align:left;">Une unique solution : $\displaystyle x = \dfrac{b}{a}$</td>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Problèmes et applications</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0; border-left:4px solid #3498db; padding-left:10px;">Mise en équation</h3>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0; font-size:1em;">
            <strong>📋 Méthode :</strong>
            <ol style="margin:10px 0; padding-left:25px; line-height:2.5;">
                <li><strong>Lire :</strong> comprendre le problème et identifier l'inconnue</li>
                <li><strong>Traduire :</strong> mettre le problème sous forme d'équation</li>
                <li><strong>Résoudre :</strong> résoudre l'équation obtenue</li>
                <li><strong>Vérifier :</strong> vérifier que la solution répond au problème</li>
                <li><strong>Conclure :</strong> rédiger la réponse en français</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Problème 1 :</strong> Un nombre augmenté de 7 est égal au triple de ce nombre diminué de 5. Quel est ce nombre ?
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Soit $\displaystyle x$ le nombre cherché<br>
                <strong>Étape 2 :</strong> Traduire : $\displaystyle x + 7 = 3x - 5$<br>
                <strong>Étape 3 :</strong> Résoudre : $\displaystyle x - 3x = -5 - 7$ donc $\displaystyle -2x = -12$ donc $\displaystyle x = 6$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                <strong>Vérification :</strong> $\displaystyle 6 + 7 = 13$ et $\displaystyle 3 \times 6 - 5 = 18 - 5 = 13$ ✓<br>
                <strong>Réponse :</strong> Le nombre cherché est $\displaystyle 6$.
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Problème 2 :</strong> La somme de trois nombres consécutifs est égale à 24. Quels sont ces nombres ?
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Soit $\displaystyle x$ le premier nombre, alors les autres sont $\displaystyle x+1$ et $\displaystyle x+2$<br>
                <strong>Étape 2 :</strong> Traduire : $\displaystyle x + (x+1) + (x+2) = 24$<br>
                <strong>Étape 3 :</strong> Simplifier : $\displaystyle 3x + 3 = 24$ donc $\displaystyle 3x = 21$ donc $\displaystyle x = 7$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                <strong>Vérification :</strong> $\displaystyle 7 + 8 + 9 = 24$ ✓<br>
                <strong>Réponse :</strong> Les trois nombres sont $\displaystyle 7$, $\displaystyle 8$ et $\displaystyle 9$.
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Méthode générale et stratégie</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0; font-size:1em;">
            <strong>📋 Ordre de travail à suivre :</strong>
            <ol style="margin:10px 0; padding-left:25px; line-height:2.5;">
                <li><strong>Développer :</strong> supprimer les parenthèses si nécessaire</li>
                <li><strong>Réduire :</strong> simplifier les termes semblables de chaque côté</li>
                <li><strong>Transposer :</strong> mettre tous les termes en $\displaystyle x$ d'un côté et les constantes de l'autre</li>
                <li><strong>Simplifier :</strong> réduire chaque côté</li>
                <li><strong>Diviser :</strong> diviser par le coefficient de $\displaystyle x$</li>
                <li><strong>Vérifier :</strong> remplacer $\displaystyle x$ par la solution dans l'équation initiale</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>Exemple complet :</strong> Résoudre $\displaystyle 2(x - 3) + 5 = 3x - 1$
            <div style="margin:10px 0; padding:10px; background:#fef3c7; font-size:1em;">
                <strong>Étape 1 :</strong> Développer : $\displaystyle 2x - 6 + 5 = 3x - 1$<br>
                <strong>Étape 2 :</strong> Réduire : $\displaystyle 2x - 1 = 3x - 1$<br>
                <strong>Étape 3 :</strong> Transposer : $\displaystyle 2x - 3x = -1 + 1$<br>
                <strong>Étape 4 :</strong> Simplifier : $\displaystyle -x = 0$
            </div>
            <div style="margin:10px 0; padding:10px; background:#e8f5e8; border-left:4px solid #6c757d; text-align:left; font-size:1em;">
                Solution : $\displaystyle x = 0$<br>
                <strong>Vérification :</strong> $\displaystyle 2(0 - 3) + 5 = 2 \times (-3) + 5 = -6 + 5 = -1$ et $\displaystyle 3 \times 0 - 1 = -1$ ✓
            </div>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#ffeaea; border-radius:6px; border-left:4px solid #ef4444; padding:15px; margin:12px 0; font-size:1em;">
            <strong>❌ ERREURS À ÉVITER</strong>
            <ul style="margin:10px 0; padding-left:25px; line-height:2.2;">
                <li><strong>Oublier de changer le signe :</strong> quand on passe un terme de l'autre côté, il faut changer son signe</li>
                <li><strong>Confondre transposition et simplification :</strong> $\displaystyle 2x - x = x$ et non $\displaystyle 2x$</li>
                <li><strong>Oublier de développer :</strong> $\displaystyle 2(x + 3) = 2x + 6$ et non $\displaystyle 2x + 3$</li>
                <li><strong>Diviser seulement un côté :</strong> si on divise par $\displaystyle a$, il faut diviser <strong>tous les termes</strong></li>
                <li><strong>Oublier les valeurs interdites :</strong> dans les équations avec fractions, vérifier les dénominateurs</li>
                <li><strong>Confondre "aucune solution" et "infinité de solutions"</strong></li>
                <li><strong>Oublier de vérifier :</strong> toujours remplacer $\displaystyle x$ par la solution trouvée</li>
            </ul>
        </div>

        <div style="background:#f0f9f0; padding:15px; border-radius:6px; font-size:1em;">
            <strong>✅ CONSEILS</strong>
            <ul style="margin:10px 0; padding-left:25px; line-height:2.2;">
                <li>Toujours <strong>développer</strong> les parenthèses avant de regrouper</li>
                <li>Pour les équations avec fractions, utiliser le <strong>produit en croix</strong> ou le <strong>dénominateur commun</strong></li>
                <li>Faire une <strong>vérification</strong> systématique en remplaçant $\displaystyle x$ par la solution</li>
                <li>Attention aux cas particuliers : <strong>aucune solution</strong> si on obtient $\displaystyle 0 = b$ ($\displaystyle b \neq 0$)</li>
                <li>Attention aux cas particuliers : <strong>infinité de solutions</strong> si on obtient $\displaystyle 0 = 0$</li>
                <li>Pour les problèmes, bien <strong>traduire</strong> le texte en équation</li>
                <li>Dans les problèmes, toujours vérifier que la solution est <strong>cohérente</strong> avec le contexte</li>
            </ul>
        </div>
    </div>
