    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définir et appeler une fonction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définition :</strong> une <strong>fonction</strong> Python est un bloc d’instructions nommé, qui reçoit des <strong>arguments</strong> et <strong>renvoie</strong> un résultat avec <code>return</code>. On la définit avec <code>def nom(arguments):</code> suivi d’un bloc indenté, puis on l’<strong>appelle</strong> en écrivant <code>nom(valeurs)</code>.</p>
        </div>
        [IMAGE_1]
        <p style="font-size:1em;">La fonction Python <code>f</code> ci-dessus traduit la fonction mathématique $f(x) = 3x + 2$ : l’appel <code>f(4)</code> renvoie $14$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> <code>print</code> se contente d’afficher une valeur, alors que <code>return</code> la renvoie pour qu’on puisse la réutiliser (dans un calcul, une variable, une autre fonction). Après un <code>return</code>, la fonction s’arrête.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Plusieurs arguments, plusieurs instructions</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">def prix_ttc(ht, taux):
    return ht &#42; (1 + taux / 100)

def est_pair(n):
    return n % 2 == 0

def tarif(age):
    if age &lt; 12:
        return 5
    elif age &lt; 18:
        return 8
    else:
        return 11</div>
        <p style="font-size:1em;"><strong>Appels :</strong> <code>prix_ttc(50, 20)</code> renvoie <code>60.0</code> ; <code>est_pair(7)</code> renvoie <code>False</code> ; <code>tarif(15)</code> renvoie <code>8</code>.</p>
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong> pour écrire une fonction, on se demande : quelles données en entrée (les arguments) ? quel résultat en sortie (ce qui suit <code>return</code>) ? On teste ensuite la fonction sur un exemple dont on connaît la réponse.
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Simuler le hasard</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Fonctions aléatoires</strong> (après <code>from random import randint, random</code>) : <code>randint(a, b)</code> renvoie un entier au hasard entre $a$ et $b$ inclus ; <code>random()</code> renvoie un nombre au hasard dans $[0\,;1[$.</p>
        </div>
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">from random import randint

def lancer():
    return randint(1, 6)

def frequence_six(n):
    k = 0
    for i in range(n):
        if lancer() == 6:
            k = k + 1
    return k / n</div>
        [IMAGE_2]
        <p style="font-size:1em;">En répétant l’expérience un grand nombre de fois, les fréquences obtenues se rapprochent de la probabilité $\frac{1}{6}$ : <code>frequence_six(10000)</code> renvoie une valeur proche de $0{,}167$.</p>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Moyenne et écart type d’un échantillon</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <p style="font-size:1em;">Sans stocker les valeurs, on accumule leur somme et la somme de leurs carrés, puis on utilise $\sigma^2 = \text{moyenne des carrés} - \text{carré de la moyenne}$.</p>
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">from random import randint
from math import sqrt

def moyenne_ecart_type(n):
    s = 0
    s2 = 0
    for i in range(n):
        x = randint(1, 6)
        s = s + x
        s2 = s2 + x &#42; x
    m = s / n
    return m, sqrt(s2 / n - m &#42; m)</div>
        <p style="font-size:1em;"><strong>Exemple :</strong> pour $n = 10\,000$ lancers, on obtient une moyenne proche de $3{,}5$ et un écart type proche de $1{,}7$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> les variables qui accumulent (<code>s</code>, <code>s2</code>, <code>k</code>) s’initialisent à $0$ <strong>avant</strong> la boucle, jamais à l’intérieur.
        </div>
    </div>
