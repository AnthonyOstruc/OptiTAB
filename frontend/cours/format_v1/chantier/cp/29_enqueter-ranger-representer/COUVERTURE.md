# Couverture des neuf activités sources

1. Source 1 → exercice nouveau-1 : Mener une enquête.
2. Source 2 → exercice nouveau-2 : Construire le tableau.
3. Source 3 → exercice nouveau-3 : Construire les deux barres.
4. Source 4 → exercice nouveau-4 : Comparer les résultats.
5. Source 5 → exercice nouveau-5 : Lire les deux entrées.
6. Source 6 → exercice nouveau-6 : Corriger un double vote.
7. Source 7 → exercice nouveau-7 : Trois choix de jeux.
8. Source 8 → exercice nouveau-8 : Construire les tours.
9. Source 9 → exercice nouveau-9 : Passer des tours au diagramme.

Chaque exercice comporte cinq questions liées, une méthode, une démarche et une réponse pour chaque question.

Contrôle final : les neuf activités du chapitre source ont été confrontées aux neuf énoncés et à leurs cinq réponses. Les exemples du cours et de la fiche, les modèles des énoncés et les dessins corrigés ont également été relus. Les empreintes des sources sont vérifiées par validation_cp.
