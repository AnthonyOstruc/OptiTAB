I. Proportion et pourcentage

Définitions

Définition - Proportion

Soit une population de taille $\displaystyle N$ et une sous-population de taille $\displaystyle n$.

La proportion de la sous-population dans la population est :

$\displaystyle p = \frac{n}{N}$

Définition - Pourcentage

Le pourcentage est la proportion exprimée en centièmes :

$\displaystyle \% = p \times 100 = \frac{n}{N} \times 100$
💡 Propriété - Relations entre effectifs, proportions et pourcentages
  • $\displaystyle n = p \times N = \frac{\%}{100} \times N$
  • $\displaystyle p = \frac{n}{N} = \frac{\%}{100}$
  • $\displaystyle \% = p \times 100 = \frac{n}{N} \times 100$
Exemples :
  • 30 élèves dont 12 filles : $\displaystyle p=\frac{12}{30}=0,4$ soit 40%.
  • 25% d'une population de 200 : $\displaystyle n=\frac{25}{100}\times 200 = 50$.

Pourcentage de pourcentage

Définition - Pourcentage de pourcentage

Lorsque des ensembles de référence sont inclus les uns dans les autres, on peut calculer un pourcentage de pourcentage.

Si $\displaystyle A$ représente $\displaystyle p_1\%$ de $\displaystyle B$ et que $\displaystyle B$ représente $\displaystyle p_2\%$ de $\displaystyle C$, alors $\displaystyle A$ représente $\displaystyle \frac{p_1 \times p_2}{100}\%$ de $\displaystyle C$.

💡 Méthode pratique - Calculer un pourcentage de pourcentage :

Pour calculer un pourcentage de pourcentage :

  1. Convertir les pourcentages en proportions (diviser par 100)
  2. Multiplier les proportions
  3. Convertir le résultat en pourcentage (multiplier par 100)
Exemple :

Dans un lycée de 1000 élèves :

  • 40% sont en Seconde
  • Parmi les élèves de Seconde, 30% font allemand

Quel pourcentage des élèves du lycée sont en Seconde et font allemand ?

Proportion de Seconde : $\displaystyle p_1 = \frac{40}{100} = 0,4$

Proportion d'allemand parmi les Seconde : $\displaystyle p_2 = \frac{30}{100} = 0,3$

Proportion recherchée : $\displaystyle p = 0,4 \times 0,3 = 0,12$

Pourcentage : $\displaystyle 0,12 \times 100 = 12\%$

Donc 12% des élèves du lycée sont en Seconde et font allemand.

II. Évolutions

Variation absolue et variation relative

Définition - Variation absolue

Soit une valeur initiale $\displaystyle V_0$ et une valeur finale $\displaystyle V_1$.

La variation absolue est :

$\displaystyle \Delta V = V_1 - V_0$

Définition - Variation relative (taux d'évolution)

La variation relative (ou taux d'évolution) est :

$\displaystyle t = \frac{V_1 - V_0}{V_0} = \frac{\Delta V}{V_0}$

Le taux d'évolution est souvent exprimé en pourcentage : $\displaystyle t\% = t \times 100$.

💡 Propriété - Relation entre deux valeurs successives et taux d'évolution

Si $\displaystyle t$ est le taux d'évolution, alors :

$\displaystyle V_1 = V_0(1 + t)$

Le nombre $\displaystyle 1 + t$ est appelé coefficient multiplicateur.

Exemples :
  • 50 € → 60 € : $\displaystyle \Delta V=+10$ ; $\displaystyle t=+20\%$ ; $\displaystyle C=1,2$.
  • 80 € → 64 € : $\displaystyle \Delta V=-16$ ; $\displaystyle t=-20\%$ ; $\displaystyle C=0,8$.

Évolutions successives

💡 Propriété - Coefficient multiplicateur global

Si une valeur subit plusieurs évolutions successives de taux $\displaystyle t_1$, $\displaystyle t_2$, ..., $\displaystyle t_n$, alors le coefficient multiplicateur global est le produit des coefficients multiplicateurs :

$\displaystyle C_{\text{global}} = (1 + t_1)(1 + t_2) \cdots (1 + t_n)$

Le taux d'évolution global est : $\displaystyle t_{\text{global}} = C_{\text{global}} - 1$

Exemple :

Un prix subit une hausse de 20% puis une baisse de 15%.

Coefficient multiplicateur de la hausse : $\displaystyle C_1 = 1 + 0,20 = 1,2$

Coefficient multiplicateur de la baisse : $\displaystyle C_2 = 1 + (-0,15) = 0,85$

Coefficient multiplicateur global : $\displaystyle C_{\text{global}} = 1,2 \times 0,85 = 1,02$

Taux d'évolution global : $\displaystyle t_{\text{global}} = 1,02 - 1 = 0,02 = 2\%$

Le prix a finalement augmenté de 2%.

Évolution réciproque

💡 Propriété - Coefficient multiplicateur réciproque

Si une valeur passe de $\displaystyle V_0$ à $\displaystyle V_1$ avec un coefficient multiplicateur $\displaystyle C$, alors pour revenir de $\displaystyle V_1$ à $\displaystyle V_0$, le coefficient multiplicateur réciproque est :

$\displaystyle C_{\text{réciproque}} = \frac{1}{C}$

Le taux d'évolution réciproque est : $\displaystyle t_{\text{réciproque}} = \frac{1}{C} - 1 = \frac{1 - C}{C}$

💡 Méthode pratique - Calculer un taux d'évolution réciproque :
  • Calculer $\displaystyle C = 1 + t$.
  • Puis $\displaystyle C_{\text{réciproque}}=\frac{1}{C}$ et $\displaystyle t_{\text{réciproque}}=C_{\text{réciproque}}-1$.
Exemple :

Un prix augmente de 25%.

Coefficient multiplicateur : $\displaystyle C = 1 + 0,25 = 1,25$

Pour revenir au prix initial, il faut appliquer :

Coefficient réciproque : $\displaystyle C_{\text{réciproque}} = \frac{1}{1,25} = 0,8$

Taux réciproque : $\displaystyle t_{\text{réciproque}} = 0,8 - 1 = -0,2 = -20\%$

Il faut donc une baisse de 20% pour revenir au prix initial.

Remarque : Une hausse de 25% suivie d'une baisse de 25% ne revient pas au prix initial !

III. Statistique descriptive : effectifs, fréquences, cumulés

Vocabulaire et tableau statistique

Définitions

  • Série statistique : ensemble des valeurs observées d'un caractère (ex : notes, tailles, durées).
  • Effectif $n_i$ d'une valeur $x_i$ : nombre de fois où $x_i$ apparaît.
  • Effectif total : $\displaystyle N = \sum n_i$ (nombre total de données).
  • Fréquence : $\displaystyle f_i = \frac{n_i}{N}$ (entre 0 et 1).
  • Pourcentage : $\displaystyle f_i \times 100$.

Remarque : une proportion est une fréquence (exprimée sous forme décimale) ; un pourcentage est la même information, en %.

💡 Méthode - Lire une information dans un tableau
  • Entre $a$ et $b$ (bornes incluses) : additionner les effectifs des valeurs $x$ telles que $a \le x \le b$.
  • Strictement inférieur à $b$ : prendre $x < b$ (ne pas inclure $b$).
  • Pourcentage : $\displaystyle \frac{\text{effectif}}{N}\times 100$.

Séries regroupées en classes (valeur continue)

Quand un caractère est continu (durée, taille, longueur...), on regroupe souvent les données en intervalles appelés classes (ex : $\displaystyle [200;400[$).

  • $\displaystyle [a;b[$ signifie $a \le x < b$.
  • Les classes sont choisies pour couvrir toutes les valeurs, sans chevauchement.

Effectifs cumulés et fréquences cumulées

Définitions

Pour des valeurs rangées dans l'ordre croissant $x_1 < x_2 < \cdots < x_k$ :

$\displaystyle N_i = n_1 + n_2 + \cdots + n_i \quad\text{(effectif cumulé croissant)}$

La fréquence cumulée est : $\displaystyle F_i = \frac{N_i}{N}$ (ou $F_i \times 100$ en %).

💡 Méthode - Compléter une colonne "effectifs cumulés"
  1. Le premier cumulé vaut $\displaystyle N_1=n_1$.
  2. Puis $\displaystyle N_2=N_1+n_2$, etc. : on ajoute l'effectif de la nouvelle valeur (ou de la nouvelle classe).
  3. Vérification : le dernier cumulé doit être $\displaystyle N$ (l'effectif total).
💡 À quoi ça sert ?
  • Répondre rapidement à des questions du type "au plus", "au moins", "strictement inférieur"…
  • Déterminer médiane et quartiles dans un tableau d'effectifs.
  • Tracer une courbe des effectifs cumulés (ogive), surtout pour des classes.

IV. Moyenne pondérée et linéarité

Moyenne pondérée

Définition - Moyenne pondérée

Soit une série statistique avec des valeurs $\displaystyle x_1, x_2, \ldots, x_k$ et des effectifs (ou coefficients de pondération) $\displaystyle n_1, n_2, \ldots, n_k$.

La moyenne pondérée est :

$\displaystyle \bar{x} = \frac{n_1 x_1 + n_2 x_2 + \cdots + n_k x_k}{n_1 + n_2 + \cdots + n_k} = \frac{\sum_{i=1}^{k} n_i x_i}{\sum_{i=1}^{k} n_i}$

où $\displaystyle N = n_1 + n_2 + \cdots + n_k$ est l'effectif total.

💡 Propriété - Cas particulier : moyenne simple

Si tous les effectifs sont égaux à 1, on retrouve la moyenne simple :

$\displaystyle \bar{x} = \frac{x_1 + x_2 + \cdots + x_k}{k}$

Exemple :

Notes d'un élève : 12 (coefficient 2), 15 (coefficient 3), 10 (coefficient 1)

Moyenne pondérée : $\displaystyle \bar{x} = \frac{2 \times 12 + 3 \times 15 + 1 \times 10}{2 + 3 + 1} = \frac{24 + 45 + 10}{6} = \frac{79}{6} \approx 13,17$

💡 Application - Moyenne d'une classe à partir de sous-groupes

Si une classe est composée de deux sous-groupes de tailles $n_1$ et $n_2$, de moyennes $m_1$ et $m_2$, alors la moyenne globale vaut :

$\displaystyle m = \frac{n_1 m_1 + n_2 m_2}{n_1 + n_2}$

C'est une moyenne pondérée : chaque moyenne est pondérée par l'effectif du groupe.

Moyenne approchée d'une série en classes

Si les données sont regroupées par classes, on ne connaît pas chaque valeur exacte. On approche la moyenne en remplaçant chaque classe par son centre :

  • Centre d'une classe $\displaystyle [a;b[$ : $\displaystyle c=\frac{a+b}{2}$.
  • $\displaystyle \bar{x}\approx \frac{\sum n_i c_i}{N}$.

Linéarité de la moyenne

💡 Propriété - Linéarité de la moyenne

Soit une série statistique de moyenne $\displaystyle \bar{x}$.

Si on transforme chaque valeur $\displaystyle x_i$ en $\displaystyle y_i = ax_i + b$ (où $\displaystyle a$ et $\displaystyle b$ sont des constantes), alors :

$\displaystyle \bar{y} = a\bar{x} + b$

C'est la linéarité de la moyenne.

Exemple :

Série de notes : 8, 12, 16 → moyenne 12. Si on ajoute 2 points à chaque note (10, 14, 18), la moyenne devient 14 : elle a augmenté de 2.

V. Indicateurs de dispersion

Étendue

Définition - Étendue

L'étendue mesure l'écart entre la valeur la plus grande et la valeur la plus petite :

$\displaystyle E = x_{\max} - x_{\min}$

Attention : l'étendue dépend beaucoup des valeurs extrêmes.

Écart interquartile

Définition - Quartiles

Pour une série statistique ordonnée :

  • Le premier quartile $\displaystyle Q_1$ est la valeur qui sépare les 25% des valeurs les plus petites des 75% restantes
  • La médiane $\displaystyle Q_2$ (ou deuxième quartile) est la valeur qui sépare la série en deux parties égales
  • Le troisième quartile $\displaystyle Q_3$ est la valeur qui sépare les 75% des valeurs les plus petites des 25% restantes
💡 Méthode - Trouver médiane et quartiles (liste ou tableau)
  1. Ordonner la série (ou compléter les effectifs cumulés).
  2. Quartiles : $\displaystyle r_1=\left\lceil\frac{N}{4}\right\rceil$ pour $Q_1$ et $\displaystyle r_3=\left\lceil\frac{3N}{4}\right\rceil$ pour $Q_3$.
  3. Médiane : si $N$ est impair, rang $\displaystyle \frac{N+1}{2}$ ; si $N$ est pair, moyenne des valeurs de rangs $\displaystyle \frac{N}{2}$ et $\displaystyle \frac{N}{2}+1$.
  4. Dans un tableau, on cherche la première valeur dont l'effectif cumulé est ≥ au rang demandé.

Définition - Écart interquartile

L'écart interquartile est la différence entre le troisième et le premier quartile :

$\displaystyle \text{EIQ} = Q_3 - Q_1$

L'écart interquartile mesure la dispersion des 50% des valeurs centrales de la série.

💡 Propriété - Interprétation
  • Un écart interquartile petit indique que les valeurs sont concentrées autour de la médiane
  • Un écart interquartile grand indique que les valeurs sont dispersées
  • L'écart interquartile est moins sensible aux valeurs extrêmes que l'étendue
Exemple :

Série de notes : 8, 10, 12, 13, 14, 15, 16, 18

Effectif total : 8

$\displaystyle Q_1$ : rang $\displaystyle r_1=\left\lceil\frac{8}{4}\right\rceil=2$ → $\displaystyle Q_1 = 10$

$\displaystyle Q_2$ (médiane) : $N$ pair → moyenne des valeurs de rangs $\displaystyle 4$ et $\displaystyle 5$ : $\displaystyle Q_2 = \frac{13+14}{2} = 13,5$

$\displaystyle Q_3$ : rang $\displaystyle r_3=\left\lceil\frac{3\times 8}{4}\right\rceil=6$ → $\displaystyle Q_3 = 15$

Écart interquartile : $\displaystyle \text{EIQ} = 15 - 10 = 5$

Écart type

Définition - Variance

Soit une série statistique de valeurs $\displaystyle x_1, x_2, \ldots, x_k$ avec des effectifs $\displaystyle n_1, n_2, \ldots, n_k$ et de moyenne $\displaystyle \bar{x}$.

La variance est :

$\displaystyle V = \frac{\sum_{i=1}^{k} n_i (x_i - \bar{x})^2}{\sum_{i=1}^{k} n_i}$

Définition - Écart type

L'écart type est la racine carrée de la variance :

$\displaystyle \sigma = \sqrt{V}$

L'écart type mesure la dispersion des valeurs autour de la moyenne.

💡 Propriété - Interprétation
  • Un écart type petit indique que les valeurs sont proches de la moyenne
  • Un écart type grand indique que les valeurs sont dispersées autour de la moyenne
  • L'écart type a la même unité que les valeurs de la série
Exemple :

Série : 10, 12, 14, 16, 18 (effectif 1 pour chaque valeur)

Moyenne : $\displaystyle \bar{x} = \frac{10 + 12 + 14 + 16 + 18}{5} = 14$

Variance : $\displaystyle V = \frac{(10-14)^2 + (12-14)^2 + (14-14)^2 + (16-14)^2 + (18-14)^2}{5}$

$\displaystyle V = \frac{16 + 4 + 0 + 4 + 16}{5} = \frac{40}{5} = 8$

Écart type : $\displaystyle \sigma = \sqrt{8} \approx 2,83$

VI. Décrire les différences entre deux séries statistiques

Méthode

💡 Méthode pratique - Comparer deux séries statistiques :

Pour décrire verbalement les différences entre deux séries statistiques, on s'appuie sur :

  1. Indicateurs de tendance centrale : Comparer les moyennes et les médianes
  2. Indicateurs de dispersion : Comparer les écarts interquartiles et les écarts types
  3. Représentations graphiques : Comparer les histogrammes, diagrammes en boîtes, etc.
  4. Formuler des conclusions : Décrire en termes clairs les différences observées
Exemple :

Comparaison de deux classes :

Classe Moyenne Médiane Écart type EIQ
Classe A 13,5 14 2,1 3
Classe B 12,8 13 3,5 5

Analyse :

  • La classe A a une moyenne et une médiane plus élevées que la classe B
  • La classe B a un écart type et un écart interquartile plus grands, donc les notes sont plus dispersées
  • Conclusion : La classe A a de meilleurs résultats en moyenne et des résultats plus homogènes que la classe B

VII. Fonctions Python pour les statistiques

Fonction renvoyant moyenne, écart type et proportion

Fonction Python - Statistiques descriptives :
def statistiques_descriptives(donnees):
    n = len(donnees)

    # 1) moyenne
    somme = 0
    for x in donnees:
        somme = somme + x
    m = somme / n

    # 2) variance puis écart type
    somme_carres = 0
    for x in donnees:
        somme_carres = somme_carres + (x - m) * (x - m)
    variance = somme_carres / n
    s = variance ** 0.5

    # 3) proportion dans [m-2s ; m+2s]
    borne_inf = m - 2 * s
    borne_sup = m + 2 * s
    compteur = 0
    for x in donnees:
        if borne_inf <= x <= borne_sup:
            compteur = compteur + 1
    proportion = compteur / n

    return (m, s, proportion)

Exemple : m, s, prop = statistiques_descriptives(notes).

Explication de la fonction :
  • Moyenne m : Somme des valeurs divisée par l'effectif total
  • Variance : Moyenne des carrés des écarts à la moyenne
  • Écart type s : Racine carrée de la variance
  • Intervalle [m - 2s, m + 2s] : Intervalle centré sur la moyenne de largeur 4s
  • Proportion : Nombre d'éléments dans l'intervalle divisé par l'effectif total
Exemple d'exécution :

Pour la série : $\displaystyle [10, 12, 14, 15, 16, 18, 20, 12, 14, 16]$

On obtient environ : $\displaystyle m=14,7$ et $\displaystyle s\approx 2,87$.

Intervalle $\displaystyle [m - 2s, m + 2s] \approx [8,96; 20,44]$.

VIII. Conseils méthodologiques

Méthode type (exercice)

✅ En exercice, fais toujours :
  1. Construire le tableau (effectifs, fréquences / %, cumulés) et noter $\displaystyle N$.
  2. Si c'est une proportion / % : utiliser $\displaystyle p=\frac{n}{N}$, $\displaystyle n=pN$.
  3. Si c'est une évolution : calculer $\displaystyle t$ puis $\displaystyle C=1+t$ (successives → on multiplie les $\displaystyle C$).
  4. Terminer par les indicateurs : moyenne / médiane / quartiles puis dispersion (étendue, EIQ, écart type) et une phrase de conclusion.
⚠️ Erreurs à éviter :
  • Confondre effectif, fréquence et pourcentage.
  • Pour une baisse de 20% : $\displaystyle C=0,8$ (pas $\displaystyle -0,2$).
  • Évolutions successives : on multiplie les coefficients (on n'additionne pas les taux).
  • Histogramme : si les classes n'ont pas la même largeur, comparer les aires (densités).
  • Quartiles : série ordonnée, puis rangs.
📌 Formules essentielles
  • Proportion : $\displaystyle p=\frac{n}{N}$ ; pourcentage : $\displaystyle p\times 100$ ; effectif : $\displaystyle n=pN$.
  • Évolution : $\displaystyle \Delta V=V_1-V_0$ ; $\displaystyle t=\frac{V_1-V_0}{V_0}$ ; $\displaystyle C=1+t$ ; $\displaystyle V_1=V_0C$.
  • Successives : $\displaystyle C_{\text{global}}=C_1C_2\cdots$ ; réciproque : $\displaystyle \frac{1}{C}$.
  • Fréquence : $\displaystyle f_i=\frac{n_i}{N}$ ; cumulés : $\displaystyle N_i$ et $\displaystyle F_i=\frac{N_i}{N}$.
  • Moyenne pondérée : $\displaystyle \bar{x}=\frac{\sum n_ix_i}{\sum n_i}$ ; en classes : $\displaystyle \bar{x}\approx\frac{\sum n_ic_i}{N}$.
  • Quartiles : $\displaystyle r_1=\left\lceil\frac{N}{4}\right\rceil$, $\displaystyle r_3=\left\lceil\frac{3N}{4}\right\rceil$ ; $\displaystyle \text{EIQ}=Q_3-Q_1$ ; $\displaystyle \sigma=\sqrt{V}$.
