    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les éléments de base : point, segment, droite, demi-droite</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Le point</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le point</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>point</strong> est représenté par une petite croix ou un petit rond. Il n'a pas de dimension (ni longueur, ni largeur, ni hauteur).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On le nomme avec une lettre majuscule : <strong>A</strong>, <strong>B</strong>, <strong>C</strong>, etc.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Le point <strong>A</strong>, le point <strong>B</strong>, le point <strong>M</strong>.</li>
                <li style="margin:0; text-align:left;">On écrit : « le point A » ou simplement « A ».</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_1]</div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Le segment</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le segment</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>segment</strong> est une portion de droite limitée par deux points. Ces deux points sont appelés les <strong>extrémités</strong> du segment.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On le note entre crochets : <strong>[AB]</strong> (segment d'extrémités A et B).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un segment a une <strong>longueur</strong> qu'on peut mesurer avec une règle.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Le segment <strong>[AB]</strong> : portion de droite entre les points A et B.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Le segment <strong>[CD]</strong> : portion de droite entre les points C et D.</li>
                <li style="margin:0; text-align:left;">La longueur du segment [AB] se note <strong>AB</strong> (sans crochets).</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_2]</div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">La droite et la demi-droite</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 La droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>droite</strong> est une ligne illimitée des deux côtés. Elle passe par une infinité de points.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On la note entre parenthèses : <strong>(AB)</strong> ou <strong>(d)</strong> (droite passant par A et B, ou droite d).</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 La demi-droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>demi-droite</strong> est une portion de droite limitée d'un seul côté par un point (son <strong>origine</strong>).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On la note avec un crochet et une parenthèse : <strong>[AB)</strong> (demi-droite d'origine A passant par B).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">La droite <strong>(AB)</strong> : droite passant par A et B, illimitée des deux côtés.</li>
                <li style="margin:0 0 8px 0; text-align:left;">La demi-droite <strong>[AB)</strong> : demi-droite d'origine A passant par B, limitée en A mais illimitée vers B.</li>
                <li style="margin:0; text-align:left;">La demi-droite <strong>[BA)</strong> : demi-droite d'origine B passant par A, limitée en B mais illimitée vers A.</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_3]</div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Points alignés et appartenance</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Trois points sont <strong>alignés</strong> s'ils appartiennent à la <strong>même droite</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut écrire : <strong>A ∈ (d)</strong> pour dire « le point A appartient à la droite (d) ».</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On écrit <strong>A ∉ (d)</strong> pour dire « le point A n'appartient pas à la droite (d) ».</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Si A, B et C sont sur la même droite (d), alors <strong>A ∈ (d)</strong>, <strong>B ∈ (d)</strong> et <strong>C ∈ (d)</strong>.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les points A, B et C sont <strong>alignés</strong>.</li>
                <li style="margin:0; text-align:left;">Si le point D n'est pas sur (d), alors <strong>D ∉ (d)</strong>.</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Droites parallèles</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et reconnaissance</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Droites parallèles</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux droites sont <strong>parallèles</strong> si elles ne se coupent jamais, même si on les prolonge.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note : <strong>(d) // (d')</strong> (la droite d est parallèle à la droite d').</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Les rails d'un train sont parallèles.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les lignes d'un cahier sont parallèles.</li>
                <li style="margin:0; text-align:left;">Si (d) // (d'), alors (d') // (d) (le parallélisme est symétrique).</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_4]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Droites perpendiculaires</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition et reconnaissance</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Droites perpendiculaires</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux droites sont <strong>perpendiculaires</strong> si elles se coupent en formant un angle droit (90°).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On note : <strong>(d) ⊥ (d')</strong> (la droite d est perpendiculaire à la droite d').</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Les bords d'une feuille de papier sont perpendiculaires.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les lignes verticales et horizontales d'un quadrillage sont perpendiculaires.</li>
                <li style="margin:0; text-align:left;">Si (d) ⊥ (d'), alors (d') ⊥ (d) (la perpendicularité est symétrique).</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_5]</div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Utilisation des instruments : règle et équerre</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">La règle</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Utiliser la règle</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La <strong>règle</strong> sert à :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Tracer</strong> des segments et des droites.</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Mesurer</strong> la longueur d'un segment.</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> si des points sont alignés.</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Méthode pour tracer un segment :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer la règle le long des deux points.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Tracer un trait en reliant les deux points.</li>
                <li style="margin:0; text-align:left;">Nommer le segment [AB].</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_6]</div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">L'équerre</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Utiliser l'équerre</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'<strong>équerre</strong> sert à :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Tracer</strong> des droites perpendiculaires.</li>
                <li style="margin:0 0 8px 0; text-align:left;"><strong>Vérifier</strong> si deux droites sont perpendiculaires.</li>
                <li style="margin:0; text-align:left;"><strong>Construire</strong> des angles droits.</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Méthode pour tracer une perpendiculaire :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer l'équerre le long de la droite de référence.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Faire glisser l'équerre jusqu'au point où on veut tracer la perpendiculaire.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Tracer la droite perpendiculaire le long du bord de l'équerre.</li>
                <li style="margin:0; text-align:left;">Marquer l'angle droit avec un petit carré.</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_7]</div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Exercices de repérage et de tracé</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Situations pratiques</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 1 : Repérage</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une figure, identifier :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Les points (A, B, C…).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les segments ([AB], [CD]…).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Les droites ((AB), (d)…).</li>
                <li style="margin:0; text-align:left;">Les droites parallèles et perpendiculaires.</li>
            </ul>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_8]</div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 2 : Tracé d'un segment</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tracer le segment [AB] de longueur 5 cm :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer le point A.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Mesurer 5 cm avec la règle à partir de A.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Placer le point B.</li>
                <li style="margin:0; text-align:left;">Tracer le segment [AB] avec la règle.</li>
            </ol>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 3 : Tracé de droites parallèles</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tracer une droite (d') parallèle à la droite (d) :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer la règle le long de (d).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Faire glisser la règle jusqu'à la position souhaitée.</li>
                <li style="margin:0; text-align:left;">Tracer (d') en gardant la même direction.</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_10]</div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 4 : Tracé de droites perpendiculaires</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tracer une droite (d') perpendiculaire à la droite (d) passant par le point A :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Placer l'équerre le long de (d).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Faire glisser l'équerre jusqu'à ce que le bord perpendiculaire passe par A.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Tracer (d') le long du bord perpendiculaire de l'équerre.</li>
                <li style="margin:0; text-align:left;">Marquer l'angle droit avec un petit carré.</li>
            </ol>
        </div>

        <div style="text-align:center; margin:10px 0;">[IMAGE_11]</div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 5 : Points alignés et appartenance</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur la figure, dire si les points A, B, C sont alignés.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Compléter : <strong>A ∈ (d)</strong> ou <strong>A ∉ (d)</strong>.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exercice 6 : Bien utiliser les notations</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Compléter avec <strong>[AB]</strong>, <strong>(AB)</strong> ou <strong>[AB)</strong> :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">La droite qui passe par A et B : …</li>
                <li style="margin:0 0 8px 0; text-align:left;">Le segment d'extrémités A et B : …</li>
                <li style="margin:0; text-align:left;">La demi-droite d'origine A passant par B : …</li>

                    <li style="margin:0 0 8px 0; text-align:left;">La droite qui passe par A et B : <strong>(AB)</strong></li>
                    <li style="margin:0 0 8px 0; text-align:left;">Le segment d'extrémités A et B : <strong>[AB]</strong></li>
                    <li style="margin:0; text-align:left;">La demi-droite d'origine A passant par B : <strong>[AB)</strong></li>

                    </tr>

                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Droite</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>(AB)</strong> ou <strong>(d)</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Ligne illimitée des deux côtés</td>
                    </tr>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Demi-droite</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>[AB)</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Portion de droite limitée d'un seul côté</td>
                    </tr>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Parallèles</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>(d) // (d')</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Ne se coupent jamais</td>
                    </tr>
                    <tr>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Perpendiculaires</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;"><strong>(d) ⊥ (d')</strong></td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Se coupent en formant un angle droit</td>
                    </tr>
                </tbody>
            </table>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Points clés :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Un <strong>point</strong> se note avec une lettre majuscule : A, B, C…</li>
                <li style="margin:0 0 8px 0; text-align:left;">Un <strong>segment</strong> se note entre crochets : [AB]</li>
                <li style="margin:0 0 8px 0; text-align:left;">Une <strong>droite</strong> se note entre parenthèses : (AB) ou (d)</li>
                <li style="margin:0 0 8px 0; text-align:left;">Une <strong>demi-droite</strong> se note avec un crochet et une parenthèse : [AB)</li>
                <li style="margin:0 0 8px 0; text-align:left;">Deux droites <strong>parallèles</strong> ne se coupent jamais : (d) // (d')</li>
                <li style="margin:0; text-align:left;">Deux droites <strong>perpendiculaires</strong> forment un angle droit : (d) ⊥ (d')</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Pour réussir</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Toujours <strong>nommer</strong> les points, segments et droites avec des lettres claires.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Utiliser la <strong>règle</strong> pour tracer des segments et des droites droites.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Utiliser l'<strong>équerre</strong> pour tracer des perpendiculaires et vérifier les angles droits.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Pour tracer des <strong>parallèles</strong>, garder la même direction avec la règle.</li>
                <li style="margin:0; text-align:left;">Marquer les <strong>angles droits</strong> avec un petit carré pour les repérer facilement.</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">Confondre <strong>[AB]</strong> (segment) et <strong>(AB)</strong> (droite).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Confondre <strong>[AB)</strong> (demi-droite) et <strong>[AB]</strong> (segment).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Oublier de <strong>nommer</strong> les points et les droites.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Tracer des droites <strong>pas assez droites</strong> (utiliser la règle !).</li>
                <li style="margin:0 0 8px 0; text-align:left;">Confondre <strong>parallèles</strong> et <strong>perpendiculaires</strong>.</li>
                <li style="margin:0; text-align:left;">Oublier de <strong>marquer l'angle droit</strong> quand on trace des perpendiculaires.</li>
            </ul>
        </div>
    </div>
