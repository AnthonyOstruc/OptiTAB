=== Programmes de calcul : Suivre un programme, retrouver le nombre de départ - Programme 6ème
Difficulté: easy
Ordre: 9

Titre: Programmes de calcul : Suivre un programme étape par étape, retrouver le nombre de départ
Description: Mini-cours sur les programmes de calcul en 6ème : suivre un programme de calcul écrit étape par étape, déterminer le résultat final, retrouver un nombre de départ dans des cas simples, exercices "mystère" pour deviner le nombre de départ.

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6; font-size:1em;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce qu'un programme de calcul ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Programme de calcul</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>programme de calcul</strong> est une série d'opérations à effectuer dans un ordre précis, étape par étape.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On part d'un <strong>nombre de départ</strong>, on applique chaque opération une par une, et on obtient un <strong>résultat final</strong>.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un programme de calcul, c'est comme une recette : il faut suivre les étapes dans l'ordre, une par une !</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Suivre un programme de calcul</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Appliquer un programme étape par étape</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire</strong> le programme de calcul attentivement</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Partir</strong> du nombre de départ</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Appliquer</strong> chaque opération dans l'ordre, une par une</li>
                <li style="margin:0; text-align:left;"><strong>Noter</strong> le résultat de chaque étape</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Programme simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Programme :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Choisir un nombre de départ</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ajouter 5</li>
                <li style="margin:0 0 12px 0; text-align:left;">Multiplier le résultat par 2</li>
                <li style="margin:0; text-align:left;">Soustraire 4</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Si le nombre de départ est <strong>3</strong>, quel est le résultat final ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Nombre de départ : <strong>3</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Étape 1 : <strong>3 + 5 = 8</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Étape 2 : <strong>8 × 2 = 16</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Étape 3 : <strong>16 - 4 = 12</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le résultat final est <strong>12</strong></li>
            </ul>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Retrouver le nombre de départ (exercices "mystère")</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Faire le programme à l'envers</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Problème "mystère"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un exercice "mystère", on connaît le <strong>résultat final</strong> et on doit retrouver le <strong>nombre de départ</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il faut faire le programme <strong>à l'envers</strong>, en inversant chaque opération :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Addition</strong> devient <strong>soustraction</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Soustraction</strong> devient <strong>addition</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Multiplication</strong> devient <strong>division</strong></li>
                <li style="margin:0; text-align:left;"><strong>Division</strong> devient <strong>multiplication</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Retrouver le nombre de départ</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Programme :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Choisir un nombre de départ</li>
                <li style="margin:0 0 12px 0; text-align:left;">Multiplier par 3</li>
                <li style="margin:0; text-align:left;">Ajouter 7</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résultat final :</strong> <strong>19</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quel était le nombre de départ ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On fait le programme à l'envers :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résultat final : <strong>19</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Dernière opération : "Ajouter 7", donc on fait l'inverse : <strong>19 - 7 = 12</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Avant-dernière opération : "Multiplier par 3", donc on fait l'inverse : <strong>12 ÷ 3 = 4</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le nombre de départ était <strong>4</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 4 → 4 × 3 = 12 → 12 + 7 = 19 ✓</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Autre exercice mystère</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Programme :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Choisir un nombre de départ</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ajouter 10</li>
                <li style="margin:0 0 12px 0; text-align:left;">Multiplier par 2</li>
                <li style="margin:0; text-align:left;">Soustraire 6</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résultat final :</strong> <strong>20</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quel était le nombre de départ ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On fait le programme à l'envers :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résultat final : <strong>20</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Dernière opération : "Soustraire 6", donc on fait l'inverse : <strong>20 + 6 = 26</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Avant-dernière opération : "Multiplier par 2", donc on fait l'inverse : <strong>26 ÷ 2 = 13</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Première opération : "Ajouter 10", donc on fait l'inverse : <strong>13 - 10 = 3</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le nombre de départ était <strong>3</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 3 → 3 + 10 = 13 → 13 × 2 = 26 → 26 - 6 = 20 ✓</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Exercice mystère avec division</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Programme :</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Choisir un nombre de départ</li>
                <li style="margin:0 0 12px 0; text-align:left;">Multiplier par 2</li>
                <li style="margin:0; text-align:left;">Ajouter 5</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Résultat final :</strong> <strong>23</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Question :</strong> Quel était le nombre de départ ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On fait le programme à l'envers :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Résultat final : <strong>23</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Dernière opération : "Ajouter 5", donc on fait l'inverse : <strong>23 - 5 = 18</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Première opération : "Multiplier par 2", donc on fait l'inverse : <strong>18 ÷ 2 = 9</strong></li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> Le nombre de départ était <strong>9</strong></li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> 9 → 9 × 2 = 18 → 18 + 5 = 23 ✓</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pour les exercices mystère :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Partir</strong> du résultat final</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Remonter</strong> le programme étape par étape (de la fin vers le début)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Inverser</strong> chaque opération (addition ↔ soustraction, multiplication ↔ division)</li>
                <li style="margin:0; text-align:left;"><strong>Vérifier</strong> en refaisant le programme dans le bon sens</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire attentivement</strong> le programme de calcul avant de commencer</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Respecter l'ordre</strong> des opérations : il faut les faire une par une, dans l'ordre indiqué</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Noter chaque résultat</strong> d'étape pour ne rien oublier et vérifier</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour retrouver le nombre de départ</strong> : partir du résultat final et remonter le programme étape par étape à l'envers</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Bien inverser les opérations</strong> : addition ↔ soustraction, multiplication ↔ division</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Toujours vérifier</strong> en refaisant le programme dans le bon sens avec le nombre trouvé</li>
                <li style="margin:0; text-align:left;"><strong>Travailler proprement</strong> : écrire clairement chaque étape pour éviter les erreurs de calcul</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Changer l'ordre des opérations</strong> : faire les opérations dans le désordre donne un résultat faux !</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier une étape</strong> : il faut faire TOUTES les opérations du programme, une par une</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Mauvais inversement des opérations</strong> : confondre l'opération inverse (par exemple, diviser au lieu de multiplier quand on remonte le programme)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas vérifier</strong> : toujours vérifier en refaisant le programme dans le bon sens</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Erreurs de calcul</strong> : faire attention aux additions, soustractions, multiplications et divisions</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Partir du nombre de départ</strong> au lieu du résultat final quand on fait un exercice "mystère"</li>
                <li style="margin:0; text-align:left;"><strong>Confondre les opérations inverses</strong> : addition et soustraction sont inverses, multiplication et division sont inverses (mais pas addition et multiplication !)</li>
            </ul>
        </div>
