    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Produit scalaire dans l'espace</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Produit scalaire dans l'espace</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ deux vecteurs de l'espace. Le <strong>produit scalaire</strong> de $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$, noté $\displaystyle \vec{u} \cdot \vec{v}$, est défini par :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = \|\vec{u}\| \times \|\vec{v}\| \times \cos(\theta)$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle \theta$ est l'angle orienté entre les vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Bilinéarité et symétrie</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le produit scalaire dans l'espace possède les mêmes propriétés que dans le plan :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Symétrie :</strong> $\displaystyle \vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Bilinéarité :</strong> $\displaystyle (k\vec{u}) \cdot \vec{v} = k(\vec{u} \cdot \vec{v})$ et $\displaystyle \vec{u} \cdot (k\vec{v}) = k(\vec{u} \cdot \vec{v})$</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Distributivité :</strong> $\displaystyle \vec{u} \cdot (\vec{v} + \vec{w}) = \vec{u} \cdot \vec{v} + \vec{u} \cdot \vec{w}$</li>
                <li style="margin:0; text-align:left;"><strong>Carré scalaire :</strong> $\displaystyle \vec{u} \cdot \vec{u} = \|\vec{u}\|^2$</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Base orthonormée et repère orthonormé</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Base orthonormée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une base $\displaystyle (\vec{i}, \vec{j}, \vec{k})$ de l'espace est <strong>orthonormée</strong> si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Les vecteurs sont <strong>orthogonaux deux à deux</strong> : $\displaystyle \vec{i} \cdot \vec{j} = \vec{i} \cdot \vec{k} = \vec{j} \cdot \vec{k} = 0$</li>
                <li style="margin:0; text-align:left;">Les vecteurs sont <strong>unitaires</strong> : $\displaystyle \|\vec{i}\| = \|\vec{j}\| = \|\vec{k}\| = 1$</li>
            </ul>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Repère orthonormé</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>repère orthonormé</strong> de l'espace est un repère $\displaystyle (O, \vec{i}, \vec{j}, \vec{k})$ où $\displaystyle (\vec{i}, \vec{j}, \vec{k})$ est une base orthonormée.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Le repère canonique $\displaystyle (O, \vec{i}, \vec{j}, \vec{k})$ avec :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{i} = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}, \quad \vec{j} = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}, \quad \vec{k} = \begin{pmatrix} 0 \\ 0 \\ 1 \end{pmatrix}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">est un repère orthonormé de l'espace.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Coordonnées et expressions dans une base orthonormée</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Expression du produit scalaire</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Produit scalaire en coordonnées</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans une base orthonormée, si $\displaystyle \vec{u} = \begin{pmatrix} x_1 \\ y_1 \\ z_1 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} x_2 \\ y_2 \\ z_2 \end{pmatrix}$, alors :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = x_1x_2 + y_1y_2 + z_1z_2$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \vec{u} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} 1 \\ 4 \\ -2 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{u} \cdot \vec{v} = 2 \times 1 + (-1) \times 4 + 3 \times (-2) = 2 - 4 - 6 = -8$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Expression de la norme</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Norme d'un vecteur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans une base orthonormée, si $\displaystyle \vec{u} = \begin{pmatrix} x \\ y \\ z \end{pmatrix}$, alors :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:350px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \|\vec{u}\| = \sqrt{x^2 + y^2 + z^2}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">et donc :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \|\vec{u}\|^2 = \vec{u} \cdot \vec{u} = x^2 + y^2 + z^2$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Pour $\displaystyle \vec{u} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \|\vec{u}\| = \sqrt{2^2 + (-1)^2 + 3^2} = \sqrt{4 + 1 + 9} = \sqrt{14}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Distance entre deux points</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Distance entre deux points</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un repère orthonormé, si $\displaystyle A(x_A, y_A, z_A)$ et $\displaystyle B(x_B, y_B, z_B)$ sont deux points de l'espace, alors :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle AB = \|\overrightarrow{AB}\| = \sqrt{(x_B - x_A)^2 + (y_B - y_A)^2 + (z_B - z_A)^2}$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle A(1, 2, 3)$ et $\displaystyle B(4, 6, 8)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle AB = \sqrt{(4-1)^2 + (6-2)^2 + (8-3)^2} = \sqrt{9 + 16 + 25} = \sqrt{50} = 5\sqrt{2}$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Angle entre deux vecteurs</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Angle entre deux vecteurs</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'angle $\displaystyle \theta$ entre deux vecteurs non nuls $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ est donné par :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \cos(\theta) = \frac{\vec{u} \cdot \vec{v}}{\|\vec{u}\| \times \|\vec{v}\|}$</p>
            </div>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Expression en coordonnées</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans une base orthonormée, si $\displaystyle \vec{u} = \begin{pmatrix} x_1 \\ y_1 \\ z_1 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} x_2 \\ y_2 \\ z_2 \end{pmatrix}$, alors :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:600px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \cos(\theta) = \frac{x_1x_2 + y_1y_2 + z_1z_2}{\sqrt{x_1^2 + y_1^2 + z_1^2} \times \sqrt{x_2^2 + y_2^2 + z_2^2}}$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soient $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}$ et $\displaystyle \vec{v} = \begin{pmatrix} 1 \\ 1 \\ 0 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{u} \cdot \vec{v} = 1 \times 1 + 0 \times 1 + 0 \times 0 = 1$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \|\vec{u}\| = 1$, $\displaystyle \|\vec{v}\| = \sqrt{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \cos(\theta) = \frac{1}{1 \times \sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle \theta = 45°$.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Application :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette formule est très utilisée pour calculer l'angle entre deux droites (en utilisant leurs vecteurs directeurs) ou pour déterminer si un triangle est aigu, droit ou obtus.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Développement de $\|\vec{u} + \vec{v}\|^2$</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Développement du carré de la norme</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Développement de $\|\vec{u} + \vec{v}\|^2$</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour deux vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ de l'espace :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:450px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \|\vec{u} + \vec{v}\|^2 = \|\vec{u}\|^2 + 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$</p>
            </div>
        </div>

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>Démonstration (niveau Terminale, possible à l'écrit) :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \|\vec{u} + \vec{v}\|^2 = (\vec{u} + \vec{v}) \cdot (\vec{u} + \vec{v})$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle = \vec{u} \cdot \vec{u} + \vec{u} \cdot \vec{v} + \vec{v} \cdot \vec{u} + \vec{v} \cdot \vec{v}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle = \|\vec{u}\|^2 + 2\vec{u} \cdot \vec{v} + \|\vec{v}\|^2$ (car $\displaystyle \vec{u} \cdot \vec{v} = \vec{v} \cdot \vec{u}$) ✓</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Si $\displaystyle \|\vec{u}\| = 3$, $\displaystyle \|\vec{v}\| = 4$ et $\displaystyle \|\vec{u} + \vec{v}\| = 5$, alors :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \|\vec{u} + \vec{v}\|^2 = 25 = 9 + 2\vec{u} \cdot \vec{v} + 16$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 2\vec{u} \cdot \vec{v} = 0 \Rightarrow \vec{u} \cdot \vec{v} = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs sont donc orthogonaux.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Formules de polarisation</h3>

        <div style="background:#fef3c7; border:2px solid #f59e0b; border-radius:6px; padding:15px; margin:12px 0;">
            <p style="margin:0; text-align:left; font-size:1em;"><strong>🌟 Approfondissement :</strong> Les formules de polarisation permettent d'exprimer le produit scalaire en fonction des normes. Cette section est un approfondissement utile mais n'est pas strictement exigible au Bac.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Propriété - Formules de polarisation</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les formules de polarisation permettent d'exprimer le produit scalaire en fonction des normes :</p>
            <div style="background:#f3e5f5; border:3px solid #9c27b0; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:450px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = \frac{1}{2}\left(\|\vec{u} + \vec{v}\|^2 - \|\vec{u}\|^2 - \|\vec{v}\|^2\right)$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">ou encore :</p>
            <div style="background:#f3e5f5; border:3px solid #9c27b0; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:450px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = \frac{1}{4}\left(\|\vec{u} + \vec{v}\|^2 - \|\vec{u} - \vec{v}\|^2\right)$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Si $\displaystyle \|\vec{u}\| = 3$, $\displaystyle \|\vec{v}\| = 4$ et $\displaystyle \|\vec{u} + \vec{v}\| = 5$, alors :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{u} \cdot \vec{v} = \frac{1}{2}(5^2 - 3^2 - 4^2) = \frac{1}{2}(25 - 9 - 16) = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les vecteurs sont donc orthogonaux.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Orthogonalité dans l'espace</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Orthogonalité de deux vecteurs</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Vecteurs orthogonaux</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux vecteurs $\displaystyle \vec{u}$ et $\displaystyle \vec{v}$ de l'espace sont <strong>orthogonaux</strong> si et seulement si :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:250px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} \cdot \vec{v} = 0$</p>
            </div>
        </div>

        [IMAGE_2]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Orthogonalité de deux droites</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Droites orthogonales</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux droites $\displaystyle \mathcal{D}_1$ et $\displaystyle \mathcal{D}_2$ de l'espace sont <strong>orthogonales</strong> si leurs vecteurs directeurs respectifs $\displaystyle \vec{u}_1$ et $\displaystyle \vec{u}_2$ sont orthogonaux :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u}_1 \cdot \vec{u}_2 = 0$</p>
            </div>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Deux droites orthogonales dans l'espace ne sont pas nécessairement sécantes (elles peuvent être non coplanaires).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Les droites $\displaystyle \mathcal{D}_1$ de vecteur directeur $\displaystyle \vec{u}_1 = \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix}$ et $\displaystyle \mathcal{D}_2$ de vecteur directeur $\displaystyle \vec{u}_2 = \begin{pmatrix} 0 \\ 1 \\ 0 \end{pmatrix}$ sont orthogonales car :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{u}_1 \cdot \vec{u}_2 = 1 \times 0 + 0 \times 1 + 0 \times 0 = 0$</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Orthogonalité d'une droite et d'un plan</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Droite orthogonale à un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une droite $\displaystyle \mathcal{D}$ est <strong>orthogonale à un plan</strong> $\displaystyle \mathcal{P}$ si et seulement si elle est orthogonale à <strong>toutes les droites</strong> du plan $\displaystyle \mathcal{P}$.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Caractérisation par le vecteur normal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une droite $\displaystyle \mathcal{D}$ de vecteur directeur $\displaystyle \vec{u}$ est orthogonale à un plan $\displaystyle \mathcal{P}$ de vecteur normal $\displaystyle \vec{n}$ si et seulement si :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \vec{u} = k\vec{n}$ avec $\displaystyle k \neq 0$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">c'est-à-dire si $\displaystyle \vec{u}$ est colinéaire à $\displaystyle \vec{n}$.</p>
        </div>

        [IMAGE_3]

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si $\displaystyle \vec{u} \cdot \vec{n} = 0$, alors la droite est <strong>parallèle au plan</strong> (ou contenue dans le plan), pas orthogonale au plan !</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Une droite de vecteur directeur $\displaystyle \vec{u} = \begin{pmatrix} 2 \\ -1 \\ 3 \end{pmatrix}$ est orthogonale au plan de vecteur normal $\displaystyle \vec{n} = \begin{pmatrix} 4 \\ -2 \\ 6 \end{pmatrix}$ car :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \vec{n} = 2\vec{u}$ (les vecteurs sont colinéaires).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Vecteur normal à un plan</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Vecteur normal à un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un vecteur $\displaystyle \vec{n}$ non nul est <strong>normal à un plan</strong> $\displaystyle \mathcal{P}$ si et seulement si $\displaystyle \vec{n}$ est orthogonal à <strong>tous les vecteurs</strong> du plan $\displaystyle \mathcal{P}$.</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Plan passant par un point et normal à un vecteur</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Étant donnés un point $\displaystyle A(x_A, y_A, z_A)$ et un vecteur non nul $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$, il existe un unique plan $\displaystyle \mathcal{P}$ passant par $\displaystyle A$ et normal à $\displaystyle \vec{n}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation cartésienne de ce plan est :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle ax + by + cz + d = 0$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle d = -ax_A - by_A - cz_A$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Déterminer l'équation du plan passant par $\displaystyle A(1, 2, 3)$ et normal à $\displaystyle \vec{n} = \begin{pmatrix} 2 \\ -1 \\ 4 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation est de la forme : $\displaystyle 2x - y + 4z + d = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A$ appartient au plan : $\displaystyle 2 \times 1 - 2 + 4 \times 3 + d = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 2 - 2 + 12 + d = 0 \Rightarrow d = -12$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'équation du plan est : $\displaystyle 2x - y + 4z - 12 = 0$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Projection orthogonale et distances</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Projeté orthogonal d'un point sur une droite</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Projeté orthogonal sur une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>projeté orthogonal</strong> d'un point $\displaystyle M$ sur une droite $\displaystyle \mathcal{D}$ est le point $\displaystyle H$ de $\displaystyle \mathcal{D}$ tel que $\displaystyle \overrightarrow{MH}$ est orthogonal à $\displaystyle \mathcal{D}$.</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode : Calculer le projeté orthogonal</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer le projeté orthogonal $\displaystyle H$ d'un point $\displaystyle M$ sur une droite $\displaystyle \mathcal{D}$ passant par $\displaystyle A$ et de vecteur directeur $\displaystyle \vec{u}$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle H$ appartient à $\displaystyle \mathcal{D}$, donc il existe $\displaystyle t \in \mathbb{R}$ tel que $\displaystyle H = A + t\vec{u}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le vecteur $\displaystyle \overrightarrow{MH}$ est orthogonal à $\displaystyle \vec{u}$, donc $\displaystyle \overrightarrow{MH} \cdot \vec{u} = 0$</li>
                <li style="margin:0; text-align:left;">Résoudre cette équation pour trouver $\displaystyle t$, puis calculer les coordonnées de $\displaystyle H$</li>
            </ol>
        </div>

        [IMAGE_4]

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle M(2, 3, 1)$ et la droite $\displaystyle \mathcal{D}$ passant par $\displaystyle A(0, 0, 0)$ de vecteur directeur $\displaystyle \vec{u} = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle H = A + t\vec{u} = (t, t, t)$ tel que $\displaystyle \overrightarrow{MH} \cdot \vec{u} = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \overrightarrow{MH} = (t-2, t-3, t-1)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle (t-2) + (t-3) + (t-1) = 0 \Rightarrow 3t = 6 \Rightarrow t = 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle H(2, 2, 2)$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Projeté orthogonal d'un point sur un plan</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Projeté orthogonal sur un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>projeté orthogonal</strong> d'un point $\displaystyle A$ sur un plan $\displaystyle \mathcal{P}$ est le point $\displaystyle H$ de $\displaystyle \mathcal{P}$ tel que $\displaystyle \overrightarrow{AH}$ est orthogonal à $\displaystyle \mathcal{P}$ (c'est-à-dire colinéaire au vecteur normal $\displaystyle \vec{n}$).</p>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Le projeté orthogonal est le point le plus proche</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le projeté orthogonal $\displaystyle H$ d'un point $\displaystyle A$ sur un plan $\displaystyle \mathcal{P}$ est le point de $\displaystyle \mathcal{P}$ <strong>le plus proche</strong> de $\displaystyle A$.</p>
        </div>

        [IMAGE_5]

        <div style="background:#e0f2f1; border-radius:6px; border-left:6px solid #00897b; padding:15px; margin:12px 0;">
            <strong>🌟 Démonstration (niveau Terminale, possible à l'écrit) :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle H$ le projeté orthogonal de $\displaystyle A$ sur $\displaystyle \mathcal{P}$ et $\displaystyle P$ un autre point de $\displaystyle \mathcal{P}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a : $\displaystyle \overrightarrow{AP} = \overrightarrow{AH} + \overrightarrow{HP}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle \overrightarrow{AH}$ est orthogonal à $\displaystyle \mathcal{P}$ et $\displaystyle \overrightarrow{HP}$ est dans $\displaystyle \mathcal{P}$, on a :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \|\overrightarrow{AP}\|^2 = \|\overrightarrow{AH}\|^2 + \|\overrightarrow{HP}\|^2 \geq \|\overrightarrow{AH}\|^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle AP \geq AH$ avec égalité si et seulement si $\displaystyle P = H$. ✓</p>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode : Calculer le projeté orthogonal sur un plan</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour déterminer le projeté orthogonal $\displaystyle H$ d'un point $\displaystyle A$ sur un plan $\displaystyle \mathcal{P}$ d'équation $\displaystyle ax + by + cz + d = 0$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le vecteur $\displaystyle \overrightarrow{AH}$ est colinéaire au vecteur normal $\displaystyle \vec{n} = \begin{pmatrix} a \\ b \\ c \end{pmatrix}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Il existe $\displaystyle t \in \mathbb{R}$ tel que $\displaystyle H = A + t\vec{n}$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle H$ appartient à $\displaystyle \mathcal{P}$, donc ses coordonnées vérifient l'équation du plan</li>
                <li style="margin:0; text-align:left;">Résoudre pour trouver $\displaystyle t$, puis calculer les coordonnées de $\displaystyle H$</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Soit $\displaystyle A(1, 2, 3)$ et le plan $\displaystyle \mathcal{P} : x + y + z - 1 = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche $\displaystyle H = A + t\vec{n} = (1+t, 2+t, 3+t)$ avec $\displaystyle \vec{n} = \begin{pmatrix} 1 \\ 1 \\ 1 \end{pmatrix}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle H$ appartient à $\displaystyle \mathcal{P}$ : $\displaystyle (1+t) + (2+t) + (3+t) - 1 = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle 6 + 3t - 1 = 0 \Rightarrow t = -\frac{5}{3}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle H\left(-\frac{2}{3}, \frac{1}{3}, \frac{4}{3}\right)$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Distance d'un point à une droite</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Distance d'un point à une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance d'un point $\displaystyle M$ à une droite $\displaystyle \mathcal{D}$ est égale à la distance entre $\displaystyle M$ et son projeté orthogonal $\displaystyle H$ sur $\displaystyle \mathcal{D}$ :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle d(M, \mathcal{D}) = MH$</p>
            </div>
        </div>

        <div style="background:#fef3c7; border-radius:6px; border-left:6px solid #f59e0b; padding:15px; margin:12px 0;">
            <strong>📐 Méthode principale pour le Bac :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour calculer la distance d'un point $\displaystyle M$ à une droite $\displaystyle \mathcal{D}$ :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Déterminer le projeté orthogonal $\displaystyle H$ de $\displaystyle M$ sur $\displaystyle \mathcal{D}$ (voir méthode ci-dessus)</li>
                <li style="margin:0; text-align:left;">Calculer la distance $\displaystyle MH = \|\overrightarrow{MH}\|$</li>
            </ol>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Rappel (plan) - Distance d'un point à une droite</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans le plan, la distance du point $\displaystyle A(x_0, y_0)$ à la droite $\displaystyle ax + by + c = 0$ est :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:420px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle d(A, \text{droite }) = \dfrac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$</p>
            </div>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>🌟 Bonus - Formule avec produit vectoriel :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance d'un point $\displaystyle M$ à une droite $\displaystyle \mathcal{D}$ passant par $\displaystyle A$ et de vecteur directeur $\displaystyle \vec{u}$ peut aussi s'exprimer par :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle d(M, \mathcal{D}) = \frac{\|\overrightarrow{AM} \wedge \vec{u}\|}{\|\vec{u}\|}$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">où $\displaystyle \wedge$ désigne le produit vectoriel (hors programme Terminale). Cette formule est donnée à titre culturel.</p>
        </div>

    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Distance d'un point à un plan</h3>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Théorème - Distance d'un point à un plan</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance d'un point $\displaystyle A(x_0, y_0, z_0)$ à un plan $\displaystyle \mathcal{P}$ d'équation $\displaystyle ax + by + cz + d = 0$ est :</p>
            <div style="background:#fee2e2; border:3px solid #dc2626; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:500px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle d(A, \mathcal{P}) = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$</p>
            </div>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Distance du point $\displaystyle A(1, 2, 3)$ au plan $\displaystyle \mathcal{P} : 2x - y + 4z - 12 = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle d(A, \mathcal{P}) = \frac{|2 \times 1 - 2 + 4 \times 3 - 12|}{\sqrt{2^2 + (-1)^2 + 4^2}} = \frac{|2 - 2 + 12 - 12|}{\sqrt{4 + 1 + 16}} = \frac{0}{\sqrt{21}} = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le point $\displaystyle A$ appartient au plan $\displaystyle \mathcal{P}$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Distance du point $\displaystyle A(0, 0, 0)$ au plan $\displaystyle \mathcal{P} : x + y + z - 1 = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle d(A, \mathcal{P}) = \frac{|0 + 0 + 0 - 1|}{\sqrt{1^2 + 1^2 + 1^2}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$</p>
        </div>


    </div>

        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Intersection d'une sphère et d'un plan</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Problème :</strong> Déterminer l'intersection d'une sphère de centre $\displaystyle O$ et de rayon $\displaystyle R$ avec un plan $\displaystyle \mathcal{P}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On calcule la distance $\displaystyle d(O, \mathcal{P})$ du centre à le plan :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si $\displaystyle d(O, \mathcal{P}) > R$ : pas d'intersection</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si $\displaystyle d(O, \mathcal{P}) = R$ : le plan est tangent à la sphère (un seul point de contact)</li>
                <li style="margin:0; text-align:left;">Si $\displaystyle d(O, \mathcal{P}) < R$ : l'intersection est un cercle de rayon $\displaystyle \sqrt{R^2 - d(O, \mathcal{P})^2}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Plan tangent à une sphère</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition :</strong> Un plan $\displaystyle \mathcal{P}$ est <strong>tangent à une sphère</strong> de centre $\displaystyle O$ et de rayon $\displaystyle R$ en un point $\displaystyle M$ si :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le point $\displaystyle M$ appartient à la sphère et au plan</li>
                <li style="margin:0; text-align:left;">Le vecteur $\displaystyle \overrightarrow{OM}$ est normal au plan $\displaystyle \mathcal{P}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Sphère circonscrite à un tétraèdre</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Problème :</strong> Déterminer la sphère passant par les quatre sommets d'un tétraèdre.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On cherche le centre $\displaystyle O$ et le rayon $\displaystyle R$ de la sphère tels que les quatre sommets soient équidistants de $\displaystyle O$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">🌟 Bonus - Fonction scalaire de Leibniz</h3>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition :</strong> Pour un point $\displaystyle M$ et un point fixe $\displaystyle A$, la <strong>fonction scalaire de Leibniz</strong> est définie par :</p>
            <div style="background:#fff8dc; border:3px solid #ffa500; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
                <p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle f(M) = \|\overrightarrow{AM}\|^2$</p>
            </div>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette fonction permet d'étudier des problèmes de minimisation de distances.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Erreurs fréquentes et conseils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre "orthogonal" et "perpendiculaire" : dans l'espace, deux droites orthogonales ne sont pas nécessairement sécantes</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier la valeur absolue dans la formule de distance d'un point à un plan</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre vecteur normal et vecteur directeur : un vecteur normal est orthogonal au plan</li>
                <li style="margin:0 0 12px 0; text-align:left;">Penser que si $\displaystyle \vec{u} \cdot \vec{n} = 0$, alors la droite est orthogonale au plan (c'est l'inverse : la droite est parallèle au plan)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier le terme $\displaystyle z$ dans les calculs de produit scalaire ou de norme en 3D</li>
                <li style="margin:0; text-align:left;">Ne pas vérifier que les vecteurs sont non nuls avant d'étudier l'orthogonalité</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils méthodologiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Toujours vérifier que les vecteurs sont non nuls avant d'étudier l'orthogonalité</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour un plan, identifier clairement le vecteur normal (orthogonal au plan)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Utiliser la définition analytique du produit scalaire en 3D : $\displaystyle x_1x_2 + y_1y_2 + z_1z_2$</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les distances, toujours utiliser la valeur absolue au numérateur</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour calculer un projeté orthogonal, utiliser la méthode systématique avec le paramètre $\displaystyle t$</li>
                <li style="margin:0; text-align:left;">S'entraîner régulièrement sur les formules de base pour les avoir en réflexe</li>
            </ul>
        </div>
