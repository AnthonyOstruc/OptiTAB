=== Équations Différentielles - Croissance Démographique
Difficulté: medium

Énoncé: On considère une population dont le taux de croissance est proportionnel à la population actuelle selon l'équation différentielle : $P' = 0,03 P$.

**Question 1 : Résoudre l'équation différentielle générale**

**Question 2 : Déterminer la population après 10 ans (avec P(0) = 5000)**

**Question 3 : Calculer quand la population atteindra 10 000 habitants**

Étapes:

**Question 1 : Résoudre l'équation différentielle générale**
    ● Équation : $P' = 0,03 P$
    ● Forme : $y' = a y + b$ avec $a = 0,03$, $b = 0$
    ● Solution générale : $y(t) = C e^{a t} - \frac{b}{a} = C e^{0,03 t} - 0 = C e^{0,03 t}$
    $\\$
**Question 2 : Déterminer la population après 10 ans**
    ● Condition initiale : $P(0) = 5000$
    ● $5000 = K e^{0} \Rightarrow K = 5000$
    ● $P(t) = 5000 e^{0,03 t}$
    ● $P(10) = 5000 e^{0,3} \approx 5000 \times 1,34986 = 6749$ habitants
    $\\$
**Question 3 : Quand la population atteindra-t-elle 10 000 habitants ?**
    ● $5000 e^{0,03 t} = 10000$
    ● $e^{0,03 t} = 2$
    ● $0,03 t = \ln 2$
    ● $t = \dfrac{\ln 2}{0,03} \approx \dfrac{0,693}{0,03} \approx 23,1$ ans

Solution:
1. $P(t) = 5000 e^{0,03 t}$
2. $P(10) \approx 6749$ habitants
3. $t \approx 23,1$ ans

=== Équations Différentielles - Mélange de Solutions
Difficulté: hard

Énoncé: Un réservoir contient 100 litres d'eau pure. On y ajoute une solution saline à raison de 2 L/min avec une concentration de 0,5 kg/L. Le mélange est agité uniformément et s'écoule à raison de 2 L/min.

**Question 1 : Établir l'équation différentielle pour la quantité de sel Q(t)**

**Question 2 : Résoudre l'équation différentielle (avec Q(0) = 0)**

**Question 3 : Déterminer la quantité de sel après 30 minutes**

**Question 4 : Étudier le comportement à long terme**

Étapes:

**Question 1 : Établir l'équation différentielle**
    ● **Principe général :** $\dfrac{dQ}{dt} = \text{flux entrant de sel} - \text{flux sortant de sel}$
    ● Taux d'entrée de sel : $2 \text{ L/min} \times 0,5 \text{ kg/L} = 1 \text{ kg/min}$
    ● Taux de sortie de sel : $\dfrac{Q(t)}{100} \text{ kg/L} \times 2 \text{ L/min} = \dfrac{Q(t)}{50} \text{ kg/min}$
    ● Équation : $Q'(t) = 1 - \dfrac{Q(t)}{50}$
    ● Ou : $Q'(t) + \dfrac{1}{50} Q = 1$
    $\\$
**Question 2 : Résoudre l'équation différentielle**
    ● Forme : $y' = a y + b$ avec $a = -\frac{1}{50}$, $b = 1$
    ● Solution générale : $y(t) = C e^{a t} - \frac{b}{a} = C e^{-\frac{t}{50}} - 1 / (-\frac{1}{50}) = C e^{-\frac{t}{50}} + 50$
    ● Condition initiale : $Q(0) = 0$
    ● $0 = C + 50 \Rightarrow C = -50$
    ● $Q(t) = 50 (1 - e^{-\frac{t}{50}})$
    $\\$
**Question 3 : Déterminer la quantité de sel après 30 minutes**
    ● $Q(30) = 50 (1 - e^{-\frac{30}{50}}) = 50 (1 - e^{-0,6})$
    ● $e^{-0,6} \approx 0,5488$
    ● $Q(30) \approx 50 (1 - 0,5488) = 50 \times 0,4512 \approx 22,56$ kg
    $\\$
**Question 4 : Étudier le comportement à long terme**
    ● $\displaystyle\lim_{t \to +\infty} Q(t) = \lim_{t \to +\infty} 50 (1 - e^{-\frac{t}{50}}) = 50 (1 - e^{-\infty}) = 50 (1 - 0) = 50$ kg
    ● À long terme, la quantité de sel tend vers 50 kg (équilibre entrée = sortie)

Solution:
1. $Q'(t) = 1 - \dfrac{Q(t)}{50}$
2. $Q(t) = 50 (1 - e^{-\frac{t}{50}})$
3. $Q(30) \approx 22,56$ kg
4. $\displaystyle\lim_{t \to +\infty} Q(t) = 50$ kg

=== Équations Différentielles - Refroidissement de Newton

Énoncé: Un corps chaud à 80°C est placé dans une pièce à 20°C. La loi de refroidissement de Newton stipule que le taux de refroidissement est proportionnel à la différence de température : $T' = -k (T - 20)$.

Sachant que $k = 0,1$ min⁻¹ et que la température baisse à 60°C après 5 minutes :

**Question 1 : Résoudre l'équation différentielle générale**

**Question 2 : Déterminer la constante d'intégration**

**Question 3 : Déterminer la température après 10 minutes**

**Question 4 : Calculer quand la température atteindra 25°C**


Étapes:

**Question 1 : Résoudre l'équation différentielle générale**
    ● Équation : $T' = -0,1 (T - 20)$
    ● Forme : $y' = a y + b$ avec $a = -0,1$, $b = 2$
    ● Solution générale : $y(t) = C e^{a t} - \frac{b}{a} = C e^{-0,1 t} - 2 / (-0,1) = C e^{-0,1 t} + 20$
    $\\$
**Question 2 : Déterminer la constante d'intégration**
    ● Condition initiale à t = 5 min : $T(5) = 60$
    ● $60 = C e^{-0,1 \times 5} + 20$
    ● $60 = C e^{-0,5} + 20$
    ● $40 = C \times 0,6065$
    ● $C \approx 65,96$
    ● $T(t) = 65,96 e^{-0,1 t} + 20$
    $\\$
**Question 3 : Déterminer la température après 10 minutes**
    ● $T(10) = 65,96 e^{-0,1 \times 10} + 20$
    ● $T(10) = 65,96 e^{-1} + 20$
    ● $T(10) = 65,96 \times 0,3679 + 20$
    ● $T(10) \approx 24,26 + 20 = 44,26$°C
    $\\$
**Question 4 : Quand la température atteindra-t-elle 25°C ?**
    ● $65,96 e^{-0,1 t} + 20 = 25$
    ● $65,96 e^{-0,1 t} = 5$
    ● $e^{-0,1 t} = 5/65,96 \approx 0,0758$
    ● $-0,1 t = \ln 0,0758 \approx -2,579$
    ● $t = 25,79$ minutes
    $\\$


Solution:
1. $T(t) = C e^{-0,1 t} + 20$
2. $C \approx 65,96$
3. $T(10) \approx 44,26$°C
4. $t \approx 25,79$ minutes

=== Équations Différentielles - Croissance de Population

**Question 1 : Résoudre l'équation différentielle générale**

**Question 2 : Déterminer la population après 5 ans (avec P(0) = 1000)**

**Question 3 : Calculer quand la population atteindra 2000 habitants**

**Question 1 : Résoudre l'équation différentielle générale**
    ● Équation : $P' = 0,02 P + 50$
    ● Forme : $y' = a y + b$ avec $a = 0,02$, $b = 50$
    ● Solution générale : $y(t) = C e^{a t} - \frac{b}{a} = C e^{0,02 t} - 50 / 0,02 = C e^{0,02 t} - 2500$
    $\\$
**Question 2 : Déterminer la population après 5 ans**
    ● Condition initiale : P(0) = 1000
    ● $1000 = C - 2500 \Rightarrow C = 3500$
    ● $P(t) = 3500 e^{0,02 t} - 2500$
    ● $P(5) = 3500 e^{0,1} - 2500 \approx 3500 \times 1,1052 - 2500 \approx 3868 - 2500 = 1368$ habitants
    $\\$
**Question 3 : Quand la population atteindra 2000 habitants**
    ● $3500 e^{0,02 t} - 2500 = 2000$
    ● $3500 e^{0,02 t} = 4500$
    ● $e^{0,02 t} = 4500/3500 = 1,2857$
    ● $0,02 t = \ln 1,2857 \approx 0,2518$

    $\\$

    ● Le terme $-2500$ reste constant
    ● Donc $\displaystyle\lim_{t \to +\infty} P(t) = +\infty$ (croissance exponentielle due au terme positif)
    ● La population croît indéfiniment à cause de l'apport constant

=== Équations Différentielles - Circuit Électrique RC

Énoncé: Un circuit RC est composé d'une résistance R = 1000 Ω et d'un condensateur C = 10 μF. Une tension E = 5 V est appliquée. L'équation différentielle régissant la tension u(t) aux bornes du condensateur est : $R C \frac{du}{dt} + u = E$.

**Question 1 : Résoudre l'équation différentielle avec la condition initiale**

**Question 2 : Déterminer la tension après 0,02 seconde**

**Question 3 : Calculer la constante de temps du circuit**

**Question 4 : Étudier le comportement à long terme**

Étapes:

**Question 1 : Résoudre l'équation différentielle avec la condition initiale**
    ● Équation : $1000 \times 10^{-5} u' + u = 5$
    ● $0,01 u' + u = 5$
    ● Ou : $u' + 100 u = 500$
    ● Forme : $y' = a y + b$ avec $a = -100$, $b = 500$
    ● Solution générale : $y(t) = C e^{a t} - \frac{b}{a} = C e^{-100 t} + 5$
    ● Condition initiale : u(0) = 0
    ● $0 = C + 5 \Rightarrow C = -5$
    ● $u(t) = 5 (1 - e^{-100 t})$
    $\\$
**Question 2 : Déterminer la tension après 0,02 seconde**
    ● $u(0,02) = 5 (1 - e^{-100 \times 0,02}) = 5 (1 - e^{-2}) \approx 5 (1 - 0,1353) = 5 \times 0,8647 \approx 4,3235$ V
    $\\$
**Question 3 : Calculer la constante de temps**
    ● Constante de temps : $\tau = R C = 1000 \times 10^{-5} = 0,01$ seconde
    ● Après 5τ : $u(0,05) = 5 (1 - e^{-5}) \approx 5 (1 - 0,0067) \approx 4,9665$ V
    ● Le condensateur se charge à 99,33% de la tension finale
    $\\$
**Question 4 : Étudier le comportement à long terme**
    ● Solution : $u(t) = 5 (1 - e^{-100 t})$
    ● Quand $t \to +\infty$, le terme $e^{-100 t} \to 0$ (puisque -100t → -∞)
    ● Donc $u(t) \to 5 (1 - 0) = 5$ V
    ● $\displaystyle\lim_{t \to +\infty} u(t) = 5$ V
    ● La tension tend vers la tension d'alimentation

Solution:
1. $u(t) = 5 (1 - e^{-100 t})$
2. $u(0,02) \approx 4,3235$ V
3. Constante de temps τ = 0,01 s
4. $\displaystyle\lim_{t \to +\infty} u(t) = 5$ V

=== Équations Différentielles - Décroissance Radioactive (Uranium)
Difficulté: medium

Énoncé: Un échantillon d'uranium-238 suit la loi de décroissance radioactive : $N' = -\lambda N$, avec $\lambda = 4,9 \times 10^{-18}$ s⁻¹ (demi-vie ≈ 4,5 milliards d'années).

**Question 1 : Résoudre l'équation différentielle avec la condition initiale**

**Question 2 : Déterminer la quantité restante après 1 milliard d'années**

**Question 3 : Calculer la demi-vie théorique**

**Question 4 : Comparer avec la demi-vie expérimentale de 4,5 milliards d'années**

Étapes:

**Question 1 : Résoudre l'équation différentielle avec la condition initiale**
    ● Équation : $\frac{dN}{dt} = -\lambda N$
    ● Séparation des variables : $\frac{dN}{N} = -\lambda dt$
    ● $\ln N = -\lambda t + C$
    ● $N(t) = K e^{-\lambda t}$
    ● Condition initiale : N(0) = 1000
    ● $1000 = K e^{0} \Rightarrow K = 1000$
    ● $N(t) = 1000 e^{-\lambda t}$
    $\\$
**Question 2 : Déterminer la quantité restante après 1 milliard d'années**
    ● $t = 10^9$ ans = $10^9 \times 3,156 \times 10^7$ s ≈ $3,156 \times 10^{16}$ s
    ● $\lambda t = 4,9 \times 10^{-18} \times 3,156 \times 10^{16} \approx 1,546 \times 10^{-1} = 0,1546$
    ● $N(10^9) = 1000 e^{-0,1546} \approx 1000 \times 0,8567 = 856,7$ atomes
    $\\$
**Question 3 : Calculer la demi-vie théorique**
    ● Demi-vie : N(t) = 500
    ● $1000 e^{-\lambda t} = 500$
    ● $e^{-\lambda t} = 0,5$
    ● $-\lambda t = \ln 0,5 = -0,6931$
    ● $t = 0,6931 / \lambda = 0,6931 / 4,9 \times 10^{-18} \approx 1,414 \times 10^{17}$ s
    ● En années : $1,414 \times 10^{17} / 3,156 \times 10^7 \approx 4,48 \times 10^9$ ans
    $\\$
**Question 4 : Comparer avec la demi-vie expérimentale**
    ● Demi-vie expérimentale : 4,5 milliards d'années
    ● Demi-vie théorique : ≈ 4,48 milliards d'années
    ● Très bonne concordance (différence due aux approximations)

Solution:
1. $N(t) = 1000 e^{-\lambda t}$
2. $N(10^9) \approx 856,7$ atomes
3. Demi-vie théorique ≈ 4,48 milliards d'années
4. Concordance excellente avec l'expérience

=== Équations Différentielles - Croissance Logistique
Difficulté: medium

Énoncé: Une population suit la loi logistique $P' = 0,1 P (1 - P/1000)$, où 1000 est la capacité maximale.

**Question 1 : Résoudre l'équation différentielle par séparation des variables**

**Question 2 : Déterminer P(t) (avec P(0) = 100)**

**Question 3 : Calculer la population après 20 unités de temps**

**Question 4 : Étudier le comportement à long terme**

Étapes:

**Question 1 : Résoudre par séparation des variables**

<u>Étape 1 : Séparation des variables</u>
    ● Équation différentielle : $\dfrac{dP}{dt} = 0,1 P (1 - P/1000)$
    ● Séparons : $\dfrac{dP}{P(1 - P/1000)} = 0,1 \, dt$
    $\\$
<u>Étape 2 : Réécriture de la fraction</u>
    ● $\dfrac{1}{P(1 - P/1000)} = \dfrac{1000}{P(1000 - P)}$
    ● Facteur de conversion : $\dfrac{1}{1 - P/1000} = \dfrac{1000}{1000 - P}$
    $\\$
<u>Étape 3 : Décomposition en fractions partielles</u>
    ● $\dfrac{1000}{P(1000 - P)} = \dfrac{A}{P} + \dfrac{B}{1000 - P}$
    ● Résolvons : $A(1000 - P) + B P = 1000$
    ● Pour $A (P=0) $: $A = 1$
    ● Pour $B (P=1000) $: $B = 1$
    $\\$
<u>Étape 4 : Intégration</u>
    ● $\dfrac{1}{P} + \dfrac{1}{1000 - P} = 0,1 \, dt$
    ● $\int \frac{dP}{P} + \int \frac{dP}{1000 - P} = 0,1 \int dt$
    ● $\ln|P| - \ln|1000 - P| = 0,1 \, t + C$
    ● $\ln \left| \frac{P}{1000 - P} \right| = 0,1 t + C$
    $\\$
<u>Étape 5 : Forme exponentielle</u>
    ● $\dfrac{P}{1000 - P} = K e^{0,1 t}$ (où K = e^C)
    ● $P = K e^{0,1 t} (1000 - P)$
    $\\$
<u>Étape 6 : Résolution pour P(t)</u>
    ● $P = 1000 K e^{0,1 t} - K e^{0,1 t} P$
    ● $P + K e^{0,1 t} P = 1000 K e^{0,1 t}$
    ● $P (1 + K e^{0,1 t}) = 1000 K e^{0,1 t}$
    ● $P(t) = \dfrac{1000 K e^{0,1 t}}{1 + K e^{0,1 t}}$
    $\\$
**Question 2 : Déterminer P(t)**
    ● Condition initiale : P(0) = 100
    ● $100 = \dfrac{1000 K}{1 + K}$
    ● $100 (1 + K) = 1000 K$
    ● $100 + 100 K = 1000 K$
    ● $100 = 900 K$
    ● $K = 100/900 = 1/9$
    ● $\displaystyle P(t) = \dfrac{1000 \times (1/9) e^{0,1 t}}{1 + (1/9) e^{0,1 t}} = \dfrac{(1000/9) e^{0,1 t}}{1 + (1/9) e^{0,1 t}} = \dfrac{1000 e^{0,1 t}}{9 + e^{0,1 t}}$
    $\\$
**Question 3 : Population après 20 unités de temps**
    ● $\displaystyle P(20) = \dfrac{1000 e^{0,1 \times 20}}{9 + e^{2}} = \dfrac{1000 e^{2}}{9 + e^{2}} = \dfrac{1000 \times 7,389}{9 + 7,389} = \dfrac{7389}{16,389} \approx 450,9$
    $\\$
**Question 4 : Comportement à long terme**
    ● $\displaystyle\lim_{t \to +\infty} P(t) = \dfrac{1000 \times \infty}{9 + \infty} = 1000$
    ● La population tend vers la capacité maximale de 1000

Solution:
1. $P(t) = \dfrac{1000 e^{0,1 t}}{9 + e^{0,1 t}}$
2. $P(t) = \dfrac{1000 e^{0,1 t}}{9 + e^{0,1 t}}$
3. $P(20) \approx 450,9$
4. $\lim_{t \to +\infty} P(t) = 1000$

=== Équations Différentielles - Vérification de Solutions
Difficulté: easy

Énoncé: Vérifier que les fonctions suivantes sont des solutions des équations différentielles données.

**Question 1 : Vérifier que $y = 3 e^{2x} - 2$ est solution de $y' = 2y + 4$**

**Question 2 : Vérifier que $T = 20 + 80 e^{-0,1 t}$ est solution de $T' = -0,1 (T - 20)$**

**Question 3 : Vérifier que $P = 100 e^{0,05 t}$ est solution de $P' = 0,05 P$**

**Question 4 : Expliquer pourquoi la vérification est importante**

Étapes:

**Question 1 : Vérifier $y = 3 e^{2x} - 2$**
    ● Dérivée : $y' = 3 \times 2 e^{2x} = 6 e^{2x}$
    ● Droite : $2y + 4 = 2(3 e^{2x} - 2) + 4 = 6 e^{2x} - 4 + 4 = 6 e^{2x}$
    ● $y' = 2y + 4$ ✓ Solution correcte
    $\\$
**Question 2 : Vérifier $T = 20 + 80 e^{-0,1 t}$**
    ● Dérivée : $T' = 80 \times (-0,1) e^{-0,1 t} = -8 e^{-0,1 t}$
    ● Droite : $-0,1 (T - 20) = -0,1 (20 + 80 e^{-0,1 t} - 20) = -0,1 (80 e^{-0,1 t}) = -8 e^{-0,1 t}$
    ● $T' = -0,1 (T - 20)$ ✓ Solution correcte
    $\\$
**Question 3 : Vérifier $P = 100 e^{0,05 t}$**
    ● Dérivée : $P' = 100 \times 0,05 e^{0,05 t} = 5 e^{0,05 t}$
    ● Droite : $0,05 P = 0,05 \times 100 e^{0,05 t} = 5 e^{0,05 t}$
    ● $P' = 0,05 P$ ✓ Solution correcte
    $\\$
**Question 4 : Importance de la vérification**
    ● Permet de détecter les erreurs de calcul
    ● Confirme la validité de la solution obtenue
    ● Essentiel dans les applications pratiques
    ● Méthode simple et rapide à appliquer

Solution:
1. $y = 3 e^{2x} - 2$ est solution de $y' = 2y + 4$
2. $T = 20 + 80 e^{-0,1 t}$ est solution de $T' = -0,1 (T - 20)$
3. $P = 100 e^{0,05 t}$ est solution de $P' = 0,05 P$
4. La vérification est cruciale pour valider les solutions
