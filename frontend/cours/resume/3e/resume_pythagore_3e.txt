Titre: Résumé : Théorème de Pythagore et distances

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : théorème de Pythagore, réciproque, contraposée, distances dans un repère et problèmes concrets. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Le théorème</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle ABC$ rectangle en $\displaystyle A$ ⟹ $\displaystyle BC^2 = AB^2 + AC^2$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• <strong>Hypoténuse</strong> = côté opposé à l'angle droit = plus long côté.</p>
<p style="margin:6px 0 0 0;">• Chercher l'hypoténuse : <strong>additionner</strong> ($6^2 + 8^2 = 100 \Rightarrow 10$).</p>
<p style="margin:6px 0 0 0;">• Chercher un côté de l'angle droit : <strong>soustraire</strong> ($13^2 - 5^2 = 144 \Rightarrow 12$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Réciproque et contraposée</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">Calculer séparément le carré du <strong>plus grand côté</strong> et la somme des deux autres carrés :</p>
<p style="margin:6px 0 0 0;">• égaux → triangle <strong>rectangle</strong>, angle droit opposé au plus grand côté (réciproque) ;</p>
<p style="margin:6px 0 0 0;">• différents → triangle <strong>non rectangle</strong> (contraposée).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Distances et situations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Repère orthonormé :</strong> $\displaystyle AB = \sqrt{(\text{écart des } x)^2 + (\text{écart des } y)^2}$.</p>
<p style="margin:6px 0 0 0;">• <strong>Angles droits concrets :</strong> mur/sol, mât/sol, coins de rectangle, est/nord, hauteur d'un triangle isocèle.</p>
<p style="margin:6px 0 0 0;">• <strong>Espace :</strong> diagonale d'un pavé = Pythagore deux fois (face, puis intérieur).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Appliquer Pythagore sans angle droit justifié.</p>
<p style="margin:6px 0 0 0;">2️⃣ Additionner au lieu de soustraire pour un côté de l'angle droit.</p>
<p style="margin:6px 0 0 0;">3️⃣ Écrire $\sqrt{a^2 + b^2} = a + b$ (faux !).</p>
<p style="margin:6px 0 0 0;">4️⃣ Placer l'angle droit au mauvais sommet dans la réciproque.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> « calculer une longueur » + angle droit → Pythagore ; « le triangle est-il rectangle ? » → réciproque ; valeur exacte $\sqrt{\ }$ puis arrondi demandé.</p>
</div>
