<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Priorités et signes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Ordre des priorités :</strong> parenthèses → puissances → multiplications et divisions → additions et soustractions. À priorité égale : de gauche à droite.</p>
</div>
<p style="margin:8px 0 0 0;"><strong>Signes :</strong> un produit ou un quotient de deux nombres de même signe est positif ; de signes contraires, négatif. Attention : $\displaystyle (-3)^2 = 9$ mais $\displaystyle -3^2 = -9$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fraction d'une quantité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;">« Prendre $\displaystyle \frac{3}{5}$ de 40 » $\displaystyle = 40 \times \frac{3}{5} = 24$. <strong>« Fraction de » = multiplication.</strong></p>
</div>

<p style="margin:8px 0 0 0;"><strong>Ensembles emboîtés :</strong> « $\displaystyle \frac{1}{3}$ du reste » → calculer d'abord le reste ; une fraction d'une fraction se calcule par un <strong>produit</strong>.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Comparer et arrondir</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Comparer : réduire au <strong>même dénominateur positif</strong>, comparer les numérateurs.</p>
<p style="margin:6px 0 0 0;">• Négatifs : le plus éloigné de zéro est le plus petit ($\displaystyle -\frac{5}{6} < -\frac{3}{4}$).</p>
<p style="margin:6px 0 0 0;">• Valeur exacte $\displaystyle \frac{9}{7}$ ≠ arrondi $\displaystyle 1{,}29$ : garder la fraction pendant le calcul, arrondir à la fin avec $\displaystyle \approx$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Simplifier un terme isolé d'une somme : $\displaystyle \frac{8+4}{4} = 3$, pas $\displaystyle 8+1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier la priorité du produit : $\displaystyle \frac{2}{3} - \frac{1}{4} \times \frac{8}{3} = 0$, pas $\displaystyle \frac{5}{12} \times \frac{8}{3}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Additionner des fractions qui n'ont pas le même tout de référence.</p>
<p style="margin:6px 0 0 0;">4️⃣ Diviser par zéro ou inverser la mauvaise fraction dans une division.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> estimer le signe et l'ordre de grandeur avant de calculer ; donner une fraction <strong>irréductible</strong> ou l'unité demandée ; vérifier qu'un partage redonne bien le tout.</p>
</div>
