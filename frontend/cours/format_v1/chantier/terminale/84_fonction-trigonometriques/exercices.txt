=== Découverte - Valeurs remarquables sur le cercle
Id: 1198
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On utilise le cercle trigonométrique ci-dessous, gradué tous les $\frac{\pi}{6}$ et tous les $\frac{\pi}{4}$.

[IMAGE_1]

1. Donner les valeurs exactes de $\cos\left(\frac{2\pi}{3}\right)$ et de $\sin\left(\frac{2\pi}{3}\right)$.
2. Donner les valeurs exactes de $\cos\left(-\frac{\pi}{4}\right)$ et de $\sin\left(-\frac{\pi}{4}\right)$.
3. Donner les valeurs exactes de $\cos\left(\frac{7\pi}{6}\right)$ et de $\sin\left(\frac{7\pi}{6}\right)$.
4. Calculer $\cos\left(\frac{13\pi}{3}\right)$.
5. On sait que $\cos x = \frac{3}{5}$ et que $x$ appartient à $\left[-\frac{\pi}{2}\,;0\right]$. Calculer $\sin x$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $\cos\left(\frac{2\pi}{3}\right)$ et $\sin\left(\frac{2\pi}{3}\right)$

::: methode
On se ramène à un angle du premier quart de cercle par une symétrie.
:::

::: etape Symétrie par rapport à l’axe des ordonnées
$\frac{2\pi}{3} = \pi - \frac{\pi}{3}$ : le point $M\left(\frac{2\pi}{3}\right)$ est le symétrique de $M\left(\frac{\pi}{3}\right)$ par rapport à l’axe des ordonnées. Il a donc la même ordonnée et une abscisse opposée.
:::

::: resultat
$$\cos\left(\frac{2\pi}{3}\right) = -\frac{1}{2} \qquad \sin\left(\frac{2\pi}{3}\right) = \frac{\sqrt{3}}{2}$$
:::

## Question 2 : $\cos\left(-\frac{\pi}{4}\right)$ et $\sin\left(-\frac{\pi}{4}\right)$

::: methode
On utilise la parité : $\cos(-a) = \cos a$ et $\sin(-a) = -\sin a$.
:::

::: etape Symétrie par rapport à l’axe des abscisses
$M\left(-\frac{\pi}{4}\right)$ est le symétrique de $M\left(\frac{\pi}{4}\right)$ par rapport à l’axe des abscisses : même abscisse, ordonnée opposée.
:::

::: resultat
$$\cos\left(-\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} \qquad \sin\left(-\frac{\pi}{4}\right) = -\frac{\sqrt{2}}{2}$$
:::

## Question 3 : $\cos\left(\frac{7\pi}{6}\right)$ et $\sin\left(\frac{7\pi}{6}\right)$

::: methode
On utilise la symétrie par rapport à l’origine $O$.
:::

::: etape Symétrie de centre $O$
$\frac{7\pi}{6} = \pi + \frac{\pi}{6}$ : le point $M\left(\frac{7\pi}{6}\right)$ est le symétrique de $M\left(\frac{\pi}{6}\right)$ par rapport à $O$. Ses deux coordonnées sont opposées à celles de $M\left(\frac{\pi}{6}\right)$, qui sont $\frac{\sqrt{3}}{2}$ et $\frac{1}{2}$.
:::

::: resultat
$$\cos\left(\frac{7\pi}{6}\right) = -\frac{\sqrt{3}}{2} \qquad \sin\left(\frac{7\pi}{6}\right) = -\frac{1}{2}$$
:::

Les trois points placés, avec leurs coordonnées (en vert) :

[IMAGE_2]

## Question 4 : $\cos\left(\frac{13\pi}{3}\right)$

::: methode
On enlève des tours complets : la fonction $\cos$ est périodique de période $2\pi$.
:::

::: etape Réduction
$$\frac{13\pi}{3} = \frac{12\pi}{3} + \frac{\pi}{3} = \frac{\pi}{3} + 2 \times 2\pi$$

Les réels $\frac{13\pi}{3}$ et $\frac{\pi}{3}$ repèrent donc le même point du cercle.
:::

::: resultat
$$\cos\left(\frac{13\pi}{3}\right) = \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$$
:::

## Question 5 : calculer $\sin x$

::: methode
On utilise la relation $\cos^2 x + \sin^2 x = 1$, puis le signe de $\sin x$.
:::

::: etape Calcul de $\sin^2 x$
$$
\begin{aligned}
\sin^2 x &= 1 - \cos^2 x \\
&= 1 - \frac{9}{25} \\
&= \frac{16}{25}
\end{aligned}
$$

Donc $\sin x = \frac{4}{5}$ ou $\sin x = -\frac{4}{5}$.
:::

::: etape Choix du signe
Pour $x \in \left[-\frac{\pi}{2}\,;0\right]$, le point $M(x)$ est dans le quart de cercle situé sous l’axe des abscisses : $\sin x \le 0$.
:::

[IMAGE_3]

::: resultat
$$\sin x = -\frac{4}{5}$$
:::

::: attention
La relation $\cos^2 x + \sin^2 x = 1$ donne deux valeurs possibles : c’est la position du point sur le cercle qui permet de choisir.
:::

Solution:
<!-- optitab:1 -->
1. $\cos\left(\frac{2\pi}{3}\right) = -\frac{1}{2}$ et $\sin\left(\frac{2\pi}{3}\right) = \frac{\sqrt{3}}{2}$.
2. $\cos\left(-\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}$ et $\sin\left(-\frac{\pi}{4}\right) = -\frac{\sqrt{2}}{2}$.
3. $\cos\left(\frac{7\pi}{6}\right) = -\frac{\sqrt{3}}{2}$ et $\sin\left(\frac{7\pi}{6}\right) = -\frac{1}{2}$.
4. $\cos\left(\frac{13\pi}{3}\right) = \frac{1}{2}$.
5. $\sin x = -\frac{4}{5}$.

=== Entraînement - Dérivées et tangente
Id: 1199
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Les fonctions suivantes sont dérivables sur l’intervalle indiqué. Calculer leurs dérivées.

1. $f(x) = \sin(3x)$ sur $\mathbb{R}$
2. $g(x) = x^2\cos x$ sur $\mathbb{R}$
3. $h(x) = \cos\left(x^2 + 1\right)$ sur $\mathbb{R}$
4. $k(x) = \sin x\cos x$ sur $\mathbb{R}$
5. $m(x) = \dfrac{\sin x}{x}$ sur $\left]0\,;+\infty\right[$
6. Déterminer une équation de la tangente $T$ à la courbe de la fonction sinus au point d’abscisse $\frac{\pi}{3}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $f(x) = \sin(3x)$

::: methode
Forme $\sin(ax + b)$, de dérivée $a\cos(ax + b)$.
:::

::: etape Application avec $a = 3$ et $b = 0$
$$f'(x) = 3\cos(3x)$$
:::

::: resultat
$$f'(x) = 3\cos(3x)$$
:::

## Question 2 : $g(x) = x^2\cos x$

::: methode
Dérivée d’un produit : $(uv)' = u'v + uv'$.
:::

::: etape Identification
$u(x) = x^2$ et $v(x) = \cos x$, donc $u'(x) = 2x$ et $v'(x) = -\sin x$.
:::

::: etape Calcul
$$
\begin{aligned}
g'(x) &= 2x\cos x + x^2 \times (-\sin x) \\
&= 2x\cos x - x^2\sin x
\end{aligned}
$$
:::

::: resultat
$$g'(x) = 2x\cos x - x^2\sin x$$
:::

## Question 3 : $h(x) = \cos\left(x^2 + 1\right)$

::: methode
Dérivée d’une composée : $\big(\cos(u)\big)' = -u'\sin(u)$.
:::

::: etape Identification
$u(x) = x^2 + 1$, donc $u'(x) = 2x$.
:::

::: resultat
$$h'(x) = -2x\sin\left(x^2 + 1\right)$$
:::

## Question 4 : $k(x) = \sin x\cos x$

::: methode
Dérivée d’un produit, avec $u(x) = \sin x$ et $v(x) = \cos x$.
:::

::: etape Calcul
$u'(x) = \cos x$ et $v'(x) = -\sin x$, donc

$$
\begin{aligned}
k'(x) &= \cos x \times \cos x + \sin x \times (-\sin x) \\
&= \cos^2 x - \sin^2 x
\end{aligned}
$$
:::

::: resultat
$$k'(x) = \cos^2 x - \sin^2 x$$
:::

## Question 5 : $m(x) = \dfrac{\sin x}{x}$

::: methode
Dérivée d’un quotient : $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$.
:::

::: etape Identification
$u(x) = \sin x$ et $v(x) = x$, donc $u'(x) = \cos x$ et $v'(x) = 1$.
:::

::: etape Calcul
$$m'(x) = \frac{x\cos x - \sin x}{x^2}$$
:::

::: resultat
$$m'(x) = \frac{x\cos x - \sin x}{x^2}$$
:::

## Question 6 : tangente au point d’abscisse $\frac{\pi}{3}$

::: methode
La tangente au point d’abscisse $a$ a pour équation $y = f'(a)(x - a) + f(a)$.
:::

::: etape Valeurs utiles
Avec $f = \sin$ et $a = \frac{\pi}{3}$ :
- $\sin\left(\frac{\pi}{3}\right) = \frac{\sqrt{3}}{2}$ ;
- $\sin'\left(\frac{\pi}{3}\right) = \cos\left(\frac{\pi}{3}\right) = \frac{1}{2}$.
:::

::: etape Équation
$$
\begin{aligned}
y &= \frac{1}{2}\left(x - \frac{\pi}{3}\right) + \frac{\sqrt{3}}{2} \\
&= \frac{1}{2}x + \frac{\sqrt{3}}{2} - \frac{\pi}{6}
\end{aligned}
$$
:::

[IMAGE_1]

::: resultat
$$T : y = \frac{1}{2}x + \frac{\sqrt{3}}{2} - \frac{\pi}{6}$$
:::

::: attention
La pente de la tangente est le nombre dérivé $\cos\left(\frac{\pi}{3}\right)$, et non $\sin\left(\frac{\pi}{3}\right)$.
:::

Solution:
<!-- optitab:1 -->
1. $f'(x) = 3\cos(3x)$
2. $g'(x) = 2x\cos x - x^2\sin x$
3. $h'(x) = -2x\sin\left(x^2 + 1\right)$
4. $k'(x) = \cos^2 x - \sin^2 x$
5. $m'(x) = \dfrac{x\cos x - \sin x}{x^2}$
6. $T : y = \frac{1}{2}x + \frac{\sqrt{3}}{2} - \frac{\pi}{6}$

=== Entraînement - Équations sur le cercle
Id: 1200
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Résoudre les équations suivantes sur l’intervalle indiqué.

1. $\sin x = \frac{1}{2}$ sur $\left[0\,;2\pi\right[$
2. $\cos x = -\frac{\sqrt{2}}{2}$ sur $\left]-\pi\,;\pi\right]$
3. $\cos x = \sin x$ sur $\left[0\,;2\pi\right[$
4. $2\sin^2 x - 3\sin x + 1 = 0$ sur $\left[0\,;2\pi\right[$
5. $\sin(2x) = \sin x$ sur $\left[0\,;2\pi\right[$

Étapes:
<!-- optitab:1 -->
## Question 1 : $\sin x = \frac{1}{2}$ sur $\left[0\,;2\pi\right[$

::: methode
On trace la droite horizontale d’équation $y = \frac{1}{2}$ : elle coupe le cercle en deux points.
:::

::: etape Valeur remarquable
$\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$, donc $\sin x = \sin\left(\frac{\pi}{6}\right)$, c’est-à-dire

$$x = \frac{\pi}{6} + 2k\pi \quad \text{ou} \quad x = \pi - \frac{\pi}{6} + 2k\pi$$

avec $k \in \mathbb{Z}$, et $\pi - \frac{\pi}{6} = \frac{5\pi}{6}$.
:::

::: etape Solutions dans $\left[0\,;2\pi\right[$
Seul $k = 0$ convient.
:::

[IMAGE_1]

::: resultat
$$S = \left\{\frac{\pi}{6}\,;\frac{5\pi}{6}\right\}$$
:::

## Question 2 : $\cos x = -\frac{\sqrt{2}}{2}$ sur $\left]-\pi\,;\pi\right]$

::: methode
On trace la droite verticale d’équation $x = -\frac{\sqrt{2}}{2}$.
:::

::: etape Valeur remarquable
$\cos\left(\frac{3\pi}{4}\right) = -\frac{\sqrt{2}}{2}$, donc $x = \frac{3\pi}{4} + 2k\pi$ ou $x = -\frac{3\pi}{4} + 2k\pi$ ($k \in \mathbb{Z}$).
:::

::: etape Solutions dans $\left]-\pi\,;\pi\right]$
Avec $k = 0$ : $\frac{3\pi}{4}$ et $-\frac{3\pi}{4}$, qui appartiennent bien à l’intervalle.
:::

[IMAGE_2]

::: resultat
$$S = \left\{-\frac{3\pi}{4}\,;\frac{3\pi}{4}\right\}$$
:::

## Question 3 : $\cos x = \sin x$ sur $\left[0\,;2\pi\right[$

::: methode
On cherche les points du cercle dont l’abscisse est égale à l’ordonnée : ils sont sur la droite d’équation $y = x$.
:::

::: etape Valeurs possibles
Si $\cos x = \sin x$, alors $\cos^2 x + \sin^2 x = 2\cos^2 x = 1$, donc $\cos x = \frac{\sqrt{2}}{2}$ ou $\cos x = -\frac{\sqrt{2}}{2}$, avec $\sin x = \cos x$.
:::

::: etape Lecture sur le cercle
- $\cos x = \sin x = \frac{\sqrt{2}}{2}$ : $x = \frac{\pi}{4}$.
- $\cos x = \sin x = -\frac{\sqrt{2}}{2}$ : $x = \frac{5\pi}{4}$.
:::

[IMAGE_3]

::: resultat
$$S = \left\{\frac{\pi}{4}\,;\frac{5\pi}{4}\right\}$$
:::

## Question 4 : $2\sin^2 x - 3\sin x + 1 = 0$ sur $\left[0\,;2\pi\right[$

::: methode
On pose $X = \sin x$ : on obtient une équation du second degré.
:::

::: etape Équation en $X$
$2X^2 - 3X + 1 = 0$. Son discriminant vaut $\Delta = (-3)^2 - 4 \times 2 \times 1 = 1$, donc

$$X_1 = \frac{3 - 1}{4} = \frac{1}{2} \qquad X_2 = \frac{3 + 1}{4} = 1$$
:::

::: etape Retour à $x$
- $\sin x = \frac{1}{2}$ : $x = \frac{\pi}{6}$ ou $x = \frac{5\pi}{6}$ (question 1).
- $\sin x = 1$ : $x = \frac{\pi}{2}$.
:::

[IMAGE_4]

::: resultat
$$S = \left\{\frac{\pi}{6}\,;\frac{\pi}{2}\,;\frac{5\pi}{6}\right\}$$
:::

## Question 5 : $\sin(2x) = \sin x$ sur $\left[0\,;2\pi\right[$

::: methode
$\sin A = \sin B \iff A = B + 2k\pi$ ou $A = \pi - B + 2k\pi$ ($k \in \mathbb{Z}$).
:::

::: etape Premier cas
$$2x = x + 2k\pi \iff x = 2k\pi$$

Dans $\left[0\,;2\pi\right[$, seul $x = 0$ convient.
:::

::: etape Second cas
$$
\begin{aligned}
2x = \pi - x + 2k\pi &\iff 3x = \pi + 2k\pi \\
&\iff x = \frac{\pi}{3} + \frac{2k\pi}{3}
\end{aligned}
$$

Dans $\left[0\,;2\pi\right[$ : $k = 0$ donne $\frac{\pi}{3}$, $k = 1$ donne $\pi$, $k = 2$ donne $\frac{5\pi}{3}$ ($k = 3$ donne $\frac{7\pi}{3} \gt 2\pi$).
:::

[IMAGE_5]

::: resultat
$$S = \left\{0\,;\frac{\pi}{3}\,;\pi\,;\frac{5\pi}{3}\right\}$$
:::

::: retenir
Graphiquement, les solutions sont les abscisses des points d’intersection des courbes de $x \mapsto \sin(2x)$ et de $\sin$.
:::

Solution:
<!-- optitab:1 -->
1. $S = \left\{\frac{\pi}{6}\,;\frac{5\pi}{6}\right\}$
2. $S = \left\{-\frac{3\pi}{4}\,;\frac{3\pi}{4}\right\}$
3. $S = \left\{\frac{\pi}{4}\,;\frac{5\pi}{4}\right\}$
4. $S = \left\{\frac{\pi}{6}\,;\frac{\pi}{2}\,;\frac{5\pi}{6}\right\}$
5. $S = \left\{0\,;\frac{\pi}{3}\,;\pi\,;\frac{5\pi}{3}\right\}$

=== Problème - Étude d'une fonction trigonométrique
Id: 1201
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie sur $\mathbb{R}$ par

$$f(x) = \cos^2 x + \sin x$$

et on note $\mathcal{C}_f$ sa courbe représentative dans un repère orthogonal.

1. Montrer que $f$ est périodique de période $2\pi$. Sur quel intervalle peut-on se contenter d’étudier $f$ ?
2. Montrer que, pour tout réel $x$, $f(\pi - x) = f(x)$. Interpréter graphiquement ce résultat.
3. Montrer que, pour tout réel $x$, $f'(x) = \cos x\,(1 - 2\sin x)$.
4. Étudier le signe de $f'(x)$ sur $[0\,;2\pi]$, puis dresser le tableau de variations de $f$ sur $[0\,;2\pi]$.
5. Résoudre l’équation $f(x) = 1$ sur $[0\,;2\pi]$.
6. Déterminer le maximum et le minimum de $f$ sur $\mathbb{R}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : périodicité

::: methode
On calcule $f(x + 2\pi)$ en utilisant la périodicité de $\cos$ et de $\sin$.
:::

::: etape Calcul
$$
\begin{aligned}
f(x + 2\pi) &= \cos^2(x + 2\pi) + \sin(x + 2\pi) \\
&= \cos^2 x + \sin x \\
&= f(x)
\end{aligned}
$$
:::

::: resultat
$f$ est périodique de période $2\pi$ : il suffit de l’étudier sur un intervalle de longueur $2\pi$, par exemple $[0\,;2\pi]$. La courbe complète s’obtient ensuite par des translations.
:::

## Question 2 : symétrie

::: etape Calcul
Comme $\cos(\pi - x) = -\cos x$ et $\sin(\pi - x) = \sin x$ :

$$
\begin{aligned}
f(\pi - x) &= (-\cos x)^2 + \sin x \\
&= \cos^2 x + \sin x \\
&= f(x)
\end{aligned}
$$
:::

::: etape Interprétation
Les points de $\mathcal{C}_f$ d’abscisses $x$ et $\pi - x$ ont la même ordonnée, et le milieu de leurs abscisses vaut $\frac{x + (\pi - x)}{2} = \frac{\pi}{2}$.
:::

::: resultat
La droite d’équation $x = \frac{\pi}{2}$ est un axe de symétrie de $\mathcal{C}_f$.
:::

## Question 3 : dérivée

::: methode
$\cos^2 x = \left(\cos x\right)^2$ est de la forme $u^2$, de dérivée $2u'u$.
:::

::: etape Calcul
$$
\begin{aligned}
f'(x) &= 2 \times (-\sin x) \times \cos x + \cos x \\
&= -2\sin x\cos x + \cos x \\
&= \cos x\,(1 - 2\sin x)
\end{aligned}
$$
:::

::: resultat
$$f'(x) = \cos x\,(1 - 2\sin x)$$
:::

## Question 4 : signe de $f'$ et variations

::: methode
On étudie le signe de chaque facteur sur $[0\,;2\pi]$, puis on applique la règle des signes.
:::

::: etape Signe de $\cos x$
$\cos x \ge 0$ sur $\left[0\,;\frac{\pi}{2}\right]$ et sur $\left[\frac{3\pi}{2}\,;2\pi\right]$ ; $\cos x \le 0$ sur $\left[\frac{\pi}{2}\,;\frac{3\pi}{2}\right]$.
:::

::: etape Signe de $1 - 2\sin x$
$1 - 2\sin x \ge 0 \iff \sin x \le \frac{1}{2}$. Sur $[0\,;2\pi]$, la droite $y = \frac{1}{2}$ coupe le cercle en $M\left(\frac{\pi}{6}\right)$ et $M\left(\frac{5\pi}{6}\right)$ : $\sin x \le \frac{1}{2}$ sur $\left[0\,;\frac{\pi}{6}\right]$ et sur $\left[\frac{5\pi}{6}\,;2\pi\right]$.
:::

::: etape Valeurs aux points remarquables
$$
\begin{aligned}
f(0) &= 1 \\
f\left(\frac{\pi}{6}\right) &= \frac{3}{4} + \frac{1}{2} = \frac{5}{4} \\
f\left(\frac{\pi}{2}\right) &= 0 + 1 = 1 \\
f\left(\frac{5\pi}{6}\right) &= \frac{3}{4} + \frac{1}{2} = \frac{5}{4} \\
f\left(\frac{3\pi}{2}\right) &= 0 - 1 = -1 \\
f(2\pi) &= 1
\end{aligned}
$$
:::

::: point Tableau de signes et de variations
::: tableau
x : 0, \frac{\pi}{6}, \frac{\pi}{2}, \frac{5\pi}{6}, \frac{3\pi}{2}, 2\pi
\cos x : , +, t, +, z, -, t, -, z, +,
1 - 2\sin x : , +, z, -, t, -, z, +, t, +,
f'(x) : , +, z, -, z, +, z, -, z, +,
f(x) : -/1, +/\frac{5}{4}, -/1, +/\frac{5}{4}, -/-1, +/1
:::
:::

[IMAGE_1]

::: resultat
$f$ est croissante sur $\left[0\,;\frac{\pi}{6}\right]$, $\left[\frac{\pi}{2}\,;\frac{5\pi}{6}\right]$ et $\left[\frac{3\pi}{2}\,;2\pi\right]$, décroissante sur $\left[\frac{\pi}{6}\,;\frac{\pi}{2}\right]$ et $\left[\frac{5\pi}{6}\,;\frac{3\pi}{2}\right]$.
:::

## Question 5 : équation $f(x) = 1$

::: methode
On remplace $\cos^2 x$ par $1 - \sin^2 x$ pour n’avoir que des $\sin x$.
:::

::: etape Transformation
$$
\begin{aligned}
f(x) = 1 &\iff 1 - \sin^2 x + \sin x = 1 \\
&\iff \sin x - \sin^2 x = 0 \\
&\iff \sin x\,(1 - \sin x) = 0
\end{aligned}
$$
:::

::: etape Résolution sur $[0\,;2\pi]$
- $\sin x = 0$ : $x = 0$, $x = \pi$ ou $x = 2\pi$.
- $\sin x = 1$ : $x = \frac{\pi}{2}$.
:::

[IMAGE_2]

::: resultat
$$S = \left\{0\,;\frac{\pi}{2}\,;\pi\,;2\pi\right\}$$
:::

## Question 6 : extremums sur $\mathbb{R}$

::: etape Lecture du tableau
Sur $[0\,;2\pi]$, le maximum de $f$ vaut $\frac{5}{4}$ (atteint en $\frac{\pi}{6}$ et en $\frac{5\pi}{6}$) et le minimum vaut $-1$ (atteint en $\frac{3\pi}{2}$).
:::

::: etape Périodicité
$f$ prend sur $\mathbb{R}$ les mêmes valeurs que sur $[0\,;2\pi]$.
:::

::: resultat
Sur $\mathbb{R}$, le maximum de $f$ vaut $\frac{5}{4}$ et le minimum vaut $-1$.
:::

Solution:
<!-- optitab:1 -->
1. $f(x + 2\pi) = f(x)$ : on étudie $f$ sur $[0\,;2\pi]$.
2. $f(\pi - x) = f(x)$ : la droite d’équation $x = \frac{\pi}{2}$ est un axe de symétrie de $\mathcal{C}_f$.
3. $f'(x) = \cos x\,(1 - 2\sin x)$.
4. $f$ croît sur $\left[0\,;\frac{\pi}{6}\right]$, $\left[\frac{\pi}{2}\,;\frac{5\pi}{6}\right]$, $\left[\frac{3\pi}{2}\,;2\pi\right]$ et décroît sur $\left[\frac{\pi}{6}\,;\frac{\pi}{2}\right]$, $\left[\frac{5\pi}{6}\,;\frac{3\pi}{2}\right]$.
5. $S = \left\{0\,;\frac{\pi}{2}\,;\pi\,;2\pi\right\}$.
6. Maximum $\frac{5}{4}$, minimum $-1$.

=== Problème - Aire maximale d'un trapèze
Id: 1202
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Dans un repère orthonormé d’origine $O$, on considère le demi-cercle de centre $O$ et de rayon $1$ situé au-dessus de l’axe des abscisses, ainsi que les points $A(-1\,;0)$ et $B(1\,;0)$.

Pour $\theta \in \left[0\,;\frac{\pi}{2}\right]$, on place sur le demi-cercle les points $C(\cos\theta\,;\sin\theta)$ et $D(-\cos\theta\,;\sin\theta)$. On note $H$ le projeté orthogonal de $C$ sur $[AB]$.

[IMAGE_1]

1. Exprimer la longueur $CD$ et la hauteur $CH$ du trapèze $ABCD$ en fonction de $\theta$.
2. Montrer que l’aire du trapèze vaut $\mathcal{A}(\theta) = (1 + \cos\theta)\sin\theta$.
3. Montrer que, pour tout $\theta$ de $\left[0\,;\frac{\pi}{2}\right]$, $\mathcal{A}'(\theta) = (2\cos\theta - 1)(\cos\theta + 1)$.
4. Étudier le signe de $\mathcal{A}'(\theta)$, puis dresser le tableau de variations de $\mathcal{A}$ sur $\left[0\,;\frac{\pi}{2}\right]$.
5. En déduire la position du point $C$ pour laquelle l’aire du trapèze est maximale, ainsi que cette aire maximale. Que remarque-t-on sur les triangles $OBC$, $OCD$ et $ODA$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : longueurs $CD$ et $CH$

::: etape Longueur $CD$
$C$ et $D$ ont la même ordonnée et des abscisses opposées, avec $\cos\theta \ge 0$ :

$$CD = \cos\theta - (-\cos\theta) = 2\cos\theta$$
:::

::: etape Hauteur $CH$
$H$ a pour coordonnées $(\cos\theta\,;0)$, donc $CH = \sin\theta$ (positif sur $\left[0\,;\frac{\pi}{2}\right]$).
:::

::: resultat
$CD = 2\cos\theta$ et $CH = \sin\theta$.
:::

## Question 2 : aire du trapèze

::: methode
Aire d’un trapèze : $\dfrac{\text{grande base} + \text{petite base}}{2} \times \text{hauteur}$.
:::

::: etape Calcul
$$
\begin{aligned}
\mathcal{A}(\theta) &= \frac{AB + CD}{2} \times CH \\
&= \frac{2 + 2\cos\theta}{2} \times \sin\theta \\
&= (1 + \cos\theta)\sin\theta
\end{aligned}
$$
:::

::: resultat
$$\mathcal{A}(\theta) = (1 + \cos\theta)\sin\theta$$
:::

## Question 3 : dérivée

::: methode
Dérivée d’un produit, puis $\sin^2\theta = 1 - \cos^2\theta$ pour n’avoir que des cosinus.
:::

::: etape Dérivée du produit
Avec $u(\theta) = 1 + \cos\theta$ et $v(\theta) = \sin\theta$ : $u'(\theta) = -\sin\theta$ et $v'(\theta) = \cos\theta$.

$$
\begin{aligned}
\mathcal{A}'(\theta) &= -\sin\theta \times \sin\theta + (1 + \cos\theta)\cos\theta \\
&= -\left(1 - \cos^2\theta\right) + \cos\theta + \cos^2\theta \\
&= 2\cos^2\theta + \cos\theta - 1
\end{aligned}
$$
:::

::: etape Vérification de la factorisation
$$
\begin{aligned}
&(2\cos\theta - 1)(\cos\theta + 1) \\
&= 2\cos^2\theta + 2\cos\theta - \cos\theta - 1 \\
&= 2\cos^2\theta + \cos\theta - 1
\end{aligned}
$$
:::

::: resultat
$$\mathcal{A}'(\theta) = (2\cos\theta - 1)(\cos\theta + 1)$$
:::

## Question 4 : variations de $\mathcal{A}$

::: etape Signe de chaque facteur
- $\cos\theta + 1 \gt 0$ sur $\left[0\,;\frac{\pi}{2}\right]$.
- $2\cos\theta - 1 \ge 0 \iff \cos\theta \ge \frac{1}{2}$, c’est-à-dire $\theta \in \left[0\,;\frac{\pi}{3}\right]$, car $\cos$ est décroissante sur $\left[0\,;\frac{\pi}{2}\right]$ et $\cos\frac{\pi}{3} = \frac{1}{2}$.
:::

::: etape Valeurs
$$
\begin{aligned}
\mathcal{A}(0) &= 0 \\
\mathcal{A}\left(\frac{\pi}{3}\right) &= \left(1 + \frac{1}{2}\right) \times \frac{\sqrt{3}}{2} = \frac{3\sqrt{3}}{4} \\
\mathcal{A}\left(\frac{\pi}{2}\right) &= 1
\end{aligned}
$$
:::

::: point Tableau de variations
::: tableau
\theta : 0, \frac{\pi}{3}, \frac{\pi}{2}
\mathcal{A}'(\theta) : , +, z, -,
\mathcal{A}(\theta) : -/0, +/\frac{3\sqrt{3}}{4}, -/1
:::
:::

[IMAGE_3]

## Question 5 : aire maximale

::: etape Position de $C$
L’aire est maximale pour $\theta = \frac{\pi}{3}$, c’est-à-dire pour $C\left(\frac{1}{2}\,;\frac{\sqrt{3}}{2}\right)$.
:::

::: etape Les trois triangles
Pour $\theta = \frac{\pi}{3}$ : $OB = OC = 1$ et $\widehat{BOC} = \frac{\pi}{3}$, donc $OBC$ est équilatéral. De même, $CD = 2\cos\frac{\pi}{3} = 1$, donc $OCD$ est équilatéral, et par symétrie $ODA$ aussi.
:::

[IMAGE_2]

::: resultat
L’aire maximale vaut $\frac{3\sqrt{3}}{4} \approx 1{,}30$ unité d’aire : le trapèze optimal est un demi-hexagone régulier.
:::

Solution:
<!-- optitab:1 -->
1. $CD = 2\cos\theta$ et $CH = \sin\theta$.
2. $\mathcal{A}(\theta) = (1 + \cos\theta)\sin\theta$.
3. $\mathcal{A}'(\theta) = 2\cos^2\theta + \cos\theta - 1$, soit $\mathcal{A}'(\theta) = (2\cos\theta - 1)(\cos\theta + 1)$.
4. $\mathcal{A}$ croît sur $\left[0\,;\frac{\pi}{3}\right]$ et décroît sur $\left[\frac{\pi}{3}\,;\frac{\pi}{2}\right]$.
5. Aire maximale $\frac{3\sqrt{3}}{4}$ pour $C\left(\frac{1}{2}\,;\frac{\sqrt{3}}{2}\right)$ ; les trois triangles sont équilatéraux.

=== Entraînement - Limites avec sinus et cosinus
Id: 1203
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer les limites suivantes.

1. $\displaystyle \lim_{x \to 0} \frac{\sin x}{x}$
2. $\displaystyle \lim_{x \to 0} \frac{\sin(3x)}{x}$
3. $\displaystyle \lim_{x \to 0} \frac{1 - \cos x}{x^2}$ (on pourra multiplier le numérateur et le dénominateur par $1 + \cos x$)
4. $\displaystyle \lim_{x \to +\infty} \frac{\sin x}{x}$
5. $\displaystyle \lim_{x \to +\infty} \left(x + 2\cos x\right)$

Étapes:
<!-- optitab:1 -->
## Question 1 : $\displaystyle \lim_{x \to 0} \frac{\sin x}{x}$

::: methode
On reconnaît un taux d’accroissement en $0$.
:::

::: etape Taux d’accroissement
Pour $x \ne 0$ : $\dfrac{\sin x}{x} = \dfrac{\sin x - \sin 0}{x - 0}$. Comme $\sin$ est dérivable en $0$, ce taux tend vers $\sin'(0) = \cos 0 = 1$.
:::

[IMAGE_1]

::: resultat
$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
:::

## Question 2 : $\displaystyle \lim_{x \to 0} \frac{\sin(3x)}{x}$

::: methode
Même idée avec la fonction $g : x \mapsto \sin(3x)$.
:::

::: etape Nombre dérivé de $g$ en $0$
$g(0) = 0$ et $g'(x) = 3\cos(3x)$, donc $g'(0) = 3$. Or $\dfrac{\sin(3x)}{x} = \dfrac{g(x) - g(0)}{x - 0}$.
:::

::: resultat
$$\lim_{x \to 0} \frac{\sin(3x)}{x} = 3$$
:::

::: attention
On ne « simplifie » pas par $x$ : $\frac{\sin(3x)}{x}$ n’est pas égal à $\sin 3$.
:::

## Question 3 : $\displaystyle \lim_{x \to 0} \frac{1 - \cos x}{x^2}$

::: methode
On fait apparaître $1 - \cos^2 x = \sin^2 x$, puis on utilise la question 1.
:::

::: etape Transformation
Pour $x$ proche de $0$ et non nul, $1 + \cos x \gt 0$ et

$$
\begin{aligned}
\frac{1 - \cos x}{x^2} &= \frac{(1 - \cos x)(1 + \cos x)}{x^2(1 + \cos x)} \\
&= \frac{\sin^2 x}{x^2(1 + \cos x)} \\
&= \left(\frac{\sin x}{x}\right)^2 \times \frac{1}{1 + \cos x}
\end{aligned}
$$
:::

::: etape Limite
$\left(\dfrac{\sin x}{x}\right)^2 \to 1^2 = 1$ et $\dfrac{1}{1 + \cos x} \to \dfrac{1}{2}$.
:::

[IMAGE_2]

::: resultat
$$\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}$$
:::

## Question 4 : $\displaystyle \lim_{x \to +\infty} \frac{\sin x}{x}$

::: methode
$\sin x$ n’a pas de limite en $+\infty$ : on l’encadre, puis on applique le théorème des gendarmes.
:::

::: etape Encadrement
Pour tout $x \gt 0$, $-1 \le \sin x \le 1$, donc

$$-\frac{1}{x} \le \frac{\sin x}{x} \le \frac{1}{x}$$
:::

::: etape Gendarmes
$\lim\limits_{x \to +\infty} \left(-\dfrac{1}{x}\right) = \lim\limits_{x \to +\infty} \dfrac{1}{x} = 0$.
:::

[IMAGE_3]

::: resultat
$$\lim_{x \to +\infty} \frac{\sin x}{x} = 0$$
:::

## Question 5 : $\displaystyle \lim_{x \to +\infty} \left(x + 2\cos x\right)$

::: methode
Théorème de comparaison : si $f(x) \ge g(x)$ et $\lim g = +\infty$, alors $\lim f = +\infty$.
:::

::: etape Minoration
Pour tout réel $x$, $\cos x \ge -1$, donc $x + 2\cos x \ge x - 2$.
:::

::: etape Comparaison
$\lim\limits_{x \to +\infty} (x - 2) = +\infty$.
:::

[IMAGE_4]

::: resultat
$$\lim_{x \to +\infty} \left(x + 2\cos x\right) = +\infty$$
:::

Solution:
<!-- optitab:1 -->
1. $1$
2. $3$
3. $\frac{1}{2}$
4. $0$
5. $+\infty$

=== Entraînement - Parité, périodicité et courbes
Id: 1204
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
1. Montrer que la fonction $f : x \mapsto \cos(3x)$ est périodique de période $\frac{2\pi}{3}$.
2. Étudier la parité de la fonction $g : x \mapsto x\sin x$, puis celle de $h : x \mapsto x + \cos x$.
3. On considère la fonction $k : x \mapsto \sin^2 x$. Montrer que $k$ est paire et périodique de période $\pi$.
4. La courbe de $k$ est tracée ci-dessous sur $\left[0\,;\frac{\pi}{2}\right]$. Expliquer comment la compléter sur $[-\pi\,;\pi]$.
5. En déduire, sans calcul de dérivée, le tableau de variations de $k$ sur $[-\pi\,;\pi]$.

[IMAGE_1]

Étapes:
<!-- optitab:1 -->
## Question 1 : période de $f$

::: etape Calcul
$$
\begin{aligned}
f\left(x + \frac{2\pi}{3}\right) &= \cos\left(3x + 3 \times \frac{2\pi}{3}\right) \\
&= \cos(3x + 2\pi) \\
&= \cos(3x) = f(x)
\end{aligned}
$$
:::

::: resultat
$f$ est périodique de période $\frac{2\pi}{3}$.
:::

::: retenir
$x \mapsto \cos(ax)$ et $x \mapsto \sin(ax)$ (avec $a \gt 0$) sont périodiques de période $\frac{2\pi}{a}$.
:::

## Question 2 : parité de $g$ et de $h$

::: methode
On compare $\varphi(-x)$ avec $\varphi(x)$ et $-\varphi(x)$. Pour prouver qu’une fonction n’est ni paire ni impaire, un contre-exemple suffit.
:::

::: etape Fonction $g$
Pour tout réel $x$ :

$$
\begin{aligned}
g(-x) &= (-x)\sin(-x) \\
&= (-x)(-\sin x) \\
&= x\sin x = g(x)
\end{aligned}
$$

donc $g$ est paire.
:::

::: etape Fonction $h$
- $h(\pi) = \pi - 1$ et $h(-\pi) = -\pi - 1$ : $h(-\pi) \ne h(\pi)$, donc $h$ n’est pas paire.
- $h(0) = 1 \ne 0$ : une fonction impaire définie en $0$ vérifie $h(0) = -h(0)$, donc $h(0) = 0$. Ainsi $h$ n’est pas impaire.
:::

::: resultat
$g$ est paire ; $h$ n’est ni paire ni impaire.
:::

## Question 3 : parité et période de $k$

::: etape Parité
$k(-x) = \left(\sin(-x)\right)^2 = (-\sin x)^2$, donc $k(-x) = \sin^2 x = k(x)$.
:::

::: etape Période $\pi$
Comme $\sin(x + \pi) = -\sin x$ : $k(x + \pi) = (-\sin x)^2 = \sin^2 x = k(x)$.
:::

::: resultat
$k$ est paire et périodique de période $\pi$.
:::

## Question 4 : compléter la courbe

::: etape Par parité
La courbe est symétrique par rapport à l’axe des ordonnées : on obtient la partie sur $\left[-\frac{\pi}{2}\,;0\right]$ par cette symétrie.
:::

::: etape Par périodicité
La courbe sur $\left[-\frac{\pi}{2}\,;\frac{\pi}{2}\right]$ couvre un intervalle de longueur $\pi$ : on la translate de $\pi$ vers la droite (partie sur $\left[\frac{\pi}{2}\,;\pi\right]$) et de $\pi$ vers la gauche (partie sur $\left[-\pi\,;-\frac{\pi}{2}\right]$).
:::

[IMAGE_2]

::: resultat
La courbe complète sur $[-\pi\,;\pi]$ est formée de deux « bosses » identiques, de hauteur $1$, qui touchent l’axe des abscisses en $-\pi$, $0$ et $\pi$.
:::

## Question 5 : variations de $k$ sur $[-\pi\,;\pi]$

::: etape Lecture
$k$ est croissante sur $\left[0\,;\frac{\pi}{2}\right]$ (courbe donnée). Par parité, elle est décroissante sur $\left[-\frac{\pi}{2}\,;0\right]$ ; par périodicité, elle est décroissante sur $\left[\frac{\pi}{2}\,;\pi\right]$ et croissante sur $\left[-\pi\,;-\frac{\pi}{2}\right]$.
:::

::: point Tableau de variations
::: tableau
x : -\pi, -\frac{\pi}{2}, 0, \frac{\pi}{2}, \pi
k(x) : -/0, +/1, -/0, +/1, -/0
:::
:::

::: resultat
$k$ admet le maximum $1$ en $-\frac{\pi}{2}$ et $\frac{\pi}{2}$, et le minimum $0$ en $-\pi$, $0$ et $\pi$.
:::

Solution:
<!-- optitab:1 -->
1. $f\left(x + \frac{2\pi}{3}\right) = \cos(3x + 2\pi) = f(x)$.
2. $g$ est paire ; $h$ n’est ni paire ni impaire.
3. $k(-x) = k(x)$ et $k(x + \pi) = k(x)$.
4. Symétrie par rapport à l’axe des ordonnées, puis translations de $\pi$ et de $-\pi$.
5. $k$ croît sur $\left[-\pi\,;-\frac{\pi}{2}\right]$ et $\left[0\,;\frac{\pi}{2}\right]$, décroît sur $\left[-\frac{\pi}{2}\,;0\right]$ et $\left[\frac{\pi}{2}\,;\pi\right]$.

=== Problème - Inéquations et signe d'un produit
Id: 1205
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. Résoudre l’inéquation $\sin x \ge \frac{\sqrt{3}}{2}$ sur $[0\,;2\pi]$.
2. Résoudre l’inéquation $\cos x \le \frac{1}{2}$ sur $[-\pi\,;\pi]$.
3. Résoudre l’inéquation $\cos(2x) \lt \frac{1}{2}$ sur $[0\,;\pi]$.
4. Dresser le tableau de signes de $P(x) = (2\cos x - 1)\sin x$ sur $[0\,;2\pi]$.
5. En déduire les solutions de l’inéquation $(2\cos x - 1)\sin x \ge 0$ sur $[0\,;2\pi]$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $\sin x \ge \frac{\sqrt{3}}{2}$ sur $[0\,;2\pi]$

::: methode
On trace la droite d’équation $y = \frac{\sqrt{3}}{2}$ et on lit l’arc des points situés au-dessus.
:::

::: etape Points d’intersection
$\sin\left(\frac{\pi}{3}\right) = \sin\left(\frac{2\pi}{3}\right) = \frac{\sqrt{3}}{2}$ : la droite coupe le cercle en $M\left(\frac{\pi}{3}\right)$ et $M\left(\frac{2\pi}{3}\right)$.
:::

::: etape Lecture de l’arc
Les points d’ordonnée supérieure ou égale à $\frac{\sqrt{3}}{2}$ forment l’arc vert, de $M\left(\frac{\pi}{3}\right)$ à $M\left(\frac{2\pi}{3}\right)$.
:::

[IMAGE_1]

::: resultat
$$S = \left[\frac{\pi}{3}\,;\frac{2\pi}{3}\right]$$
:::

## Question 2 : $\cos x \le \frac{1}{2}$ sur $[-\pi\,;\pi]$

::: methode
On trace la droite d’équation $x = \frac{1}{2}$ et on lit l’arc des points situés à sa gauche.
:::

::: etape Points d’intersection
$\cos\left(\frac{\pi}{3}\right) = \cos\left(-\frac{\pi}{3}\right) = \frac{1}{2}$.
:::

::: etape Lecture de l’arc
L’arc des points d’abscisse inférieure ou égale à $\frac{1}{2}$ va de $M\left(\frac{\pi}{3}\right)$ à $M\left(-\frac{\pi}{3}\right)$ en passant par $M(\pi)$. Sur $[-\pi\,;\pi]$, il correspond à deux intervalles.
:::

[IMAGE_2]

::: resultat
$$S = \left[-\pi\,;-\frac{\pi}{3}\right] \cup \left[\frac{\pi}{3}\,;\pi\right]$$
:::

::: attention
Le point $M(\pi)$ correspond à la fois à $-\pi$ et à $\pi$ : l’arc lu sur le cercle se « coupe » en deux intervalles de $[-\pi\,;\pi]$.
:::

## Question 3 : $\cos(2x) \lt \frac{1}{2}$ sur $[0\,;\pi]$

::: methode
On pose $X = 2x$ : quand $x$ décrit $[0\,;\pi]$, $X$ décrit $[0\,;2\pi]$.
:::

::: etape Inéquation en $X$
Sur $[0\,;2\pi]$ : $\cos X \lt \frac{1}{2} \iff X \in \left]\frac{\pi}{3}\,;\frac{5\pi}{3}\right[$.
:::

::: etape Retour à $x$
$$\frac{\pi}{3} \lt 2x \lt \frac{5\pi}{3} \iff \frac{\pi}{6} \lt x \lt \frac{5\pi}{6}$$
:::

[IMAGE_3]

::: resultat
$$S = \left]\frac{\pi}{6}\,;\frac{5\pi}{6}\right[$$
:::

## Question 4 : signe de $P(x) = (2\cos x - 1)\sin x$

::: etape Signe de $\sin x$
Sur $[0\,;2\pi]$ : $\sin x$ s’annule en $0$, $\pi$ et $2\pi$ ; il est positif sur $[0\,;\pi]$ et négatif sur $[\pi\,;2\pi]$.
:::

::: etape Signe de $2\cos x - 1$
$2\cos x - 1 \ge 0 \iff \cos x \ge \frac{1}{2}$. Avec la droite $x = \frac{1}{2}$ sur le cercle, cela équivaut à $x \in \left[0\,;\frac{\pi}{3}\right] \cup \left[\frac{5\pi}{3}\,;2\pi\right]$.
:::

::: point Tableau de signes
::: tableau
x : 0, \frac{\pi}{3}, \pi, \frac{5\pi}{3}, 2\pi
\sin x : z, +, t, +, z, -, t, -, z
2\cos x - 1 : , +, z, -, t, -, z, +,
P(x) : z, +, z, -, z, +, z, -, z
:::
:::

## Question 5 : $P(x) \ge 0$

::: etape Lecture du tableau
$P(x) \ge 0$ sur $\left[0\,;\frac{\pi}{3}\right]$, sur $\left[\pi\,;\frac{5\pi}{3}\right]$, et en $x = 2\pi$ où $P(2\pi) = 0$.
:::

[IMAGE_4]

::: resultat
$$S = \left[0\,;\frac{\pi}{3}\right] \cup \left[\pi\,;\frac{5\pi}{3}\right] \cup \{2\pi\}$$
:::

::: attention
Ne pas oublier les valeurs isolées où le produit s’annule, comme $x = 2\pi$ ici.
:::

Solution:
<!-- optitab:1 -->
1. $S = \left[\frac{\pi}{3}\,;\frac{2\pi}{3}\right]$
2. $S = \left[-\pi\,;-\frac{\pi}{3}\right] \cup \left[\frac{\pi}{3}\,;\pi\right]$
3. $S = \left]\frac{\pi}{6}\,;\frac{5\pi}{6}\right[$
4. $P(x) \ge 0$ sur $\left[0\,;\frac{\pi}{3}\right]$ et $\left[\pi\,;\frac{5\pi}{3}\right]$, $P(x) \le 0$ sur $\left[\frac{\pi}{3}\,;\pi\right]$ et $\left[\frac{5\pi}{3}\,;2\pi\right]$.
5. $S = \left[0\,;\frac{\pi}{3}\right] \cup \left[\pi\,;\frac{5\pi}{3}\right] \cup \{2\pi\}$

=== Problème - Suites et fonctions trigonométriques
Id: 1206
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Les questions sont indépendantes.

1. On pose $u_n = \cos\left(\frac{\pi}{2^n}\right)$ pour tout entier naturel $n$. Calculer $u_0$, $u_1$ et $u_2$, puis déterminer la limite de la suite $(u_n)$.
2. On pose $v_n = \sin\left(\frac{n\pi}{4}\right)$ pour tout entier naturel $n$. Montrer que la suite $(v_n)$ est périodique de période $8$. Est-elle convergente ?
3. On pose $w_n = \dfrac{2n + \sin n}{n}$ pour tout entier $n \ge 1$. Montrer que $2 - \frac{1}{n} \le w_n \le 2 + \frac{1}{n}$, puis déterminer la limite de $(w_n)$.
4. On pose $t_n = \displaystyle\sum_{k=0}^{n} \cos\left(\frac{k\pi}{3}\right)$. Calculer $t_1$, $t_2$ et $t_6$, puis montrer que $t_{n+6} = t_n$ pour tout entier naturel $n$.
5. On pose $z_n = n\sin\left(\frac{1}{n}\right)$ pour tout entier $n \ge 1$. Déterminer la limite de $(z_n)$.

Étapes:
<!-- optitab:1 -->
## Question 1 : la suite $(u_n)$

::: etape Premiers termes
$$
\begin{aligned}
u_0 &= \cos(\pi) = -1 \\
u_1 &= \cos\left(\frac{\pi}{2}\right) = 0 \\
u_2 &= \cos\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2}
\end{aligned}
$$
:::

::: etape Limite
$\lim\limits_{n \to +\infty} 2^n = +\infty$, donc $\lim\limits_{n \to +\infty} \frac{\pi}{2^n} = 0$. La fonction $\cos$ est continue en $0$, donc $\cos\left(\frac{\pi}{2^n}\right)$ tend vers $\cos 0 = 1$.
:::

::: resultat
$u_0 = -1$, $u_1 = 0$, $u_2 = \frac{\sqrt{2}}{2}$ et $\lim\limits_{n \to +\infty} u_n = 1$.
:::

## Question 2 : la suite $(v_n)$

::: etape Périodicité
$$
\begin{aligned}
v_{n+8} &= \sin\left(\frac{n\pi}{4} + \frac{8\pi}{4}\right) \\
&= \sin\left(\frac{n\pi}{4} + 2\pi\right) \\
&= v_n
\end{aligned}
$$
:::

::: etape Les huit valeurs
Les points $M\left(\frac{n\pi}{4}\right)$ font le tour du cercle par pas de $\frac{\pi}{4}$ ; $v_n$ est leur ordonnée :

| $n$ | $0$ | $1$ | $2$ | $3$ |
|---|---|---|---|---|
| $v_n$ | $0$ | $\dfrac{\sqrt{2}}{2}$ | $1$ | $\dfrac{\sqrt{2}}{2}$ |

| $n$ | $4$ | $5$ | $6$ | $7$ |
|---|---|---|---|---|
| $v_n$ | $0$ | $-\dfrac{\sqrt{2}}{2}$ | $-1$ | $-\dfrac{\sqrt{2}}{2}$ |
:::

[IMAGE_1]

::: etape Convergence
La suite prend une infinité de fois la valeur $0$ (pour $n = 8p$) et une infinité de fois la valeur $1$ (pour $n = 8p + 2$) : elle ne peut pas se rapprocher d’un seul nombre.
:::

::: resultat
$(v_n)$ est périodique de période $8$ et n’est pas convergente.
:::

## Question 3 : la suite $(w_n)$

::: methode
On encadre $\sin n$ entre $-1$ et $1$, puis on applique le théorème des gendarmes.
:::

::: etape Encadrement
Pour $n \ge 1$, $-1 \le \sin n \le 1$, donc $2n - 1 \le 2n + \sin n \le 2n + 1$. En divisant par $n \gt 0$ :

$$2 - \frac{1}{n} \le w_n \le 2 + \frac{1}{n}$$
:::

::: etape Gendarmes
$\lim\limits_{n \to +\infty} \left(2 - \frac{1}{n}\right) = \lim\limits_{n \to +\infty} \left(2 + \frac{1}{n}\right) = 2$.
:::

[IMAGE_2]

::: resultat
$$\lim_{n \to +\infty} w_n = 2$$
:::

## Question 4 : la suite $(t_n)$

::: etape Valeurs de $\cos\left(\frac{k\pi}{3}\right)$
| $k$ | $\cos\left(\dfrac{k\pi}{3}\right)$ |
|---|---|
| $0$ | $1$ |
| $1$ | $\dfrac{1}{2}$ |
| $2$ | $-\dfrac{1}{2}$ |
| $3$ | $-1$ |
| $4$ | $-\dfrac{1}{2}$ |
| $5$ | $\dfrac{1}{2}$ |
| $6$ | $1$ |
:::

::: etape Calculs
$$t_1 = 1 + \frac{1}{2} = \frac{3}{2} \qquad t_2 = \frac{3}{2} - \frac{1}{2} = 1$$

$$t_6 = 1 + \frac{1}{2} - \frac{1}{2} - 1 - \frac{1}{2} + \frac{1}{2} + 1 = 1$$
:::

::: etape Six termes consécutifs
La suite $k \mapsto \cos\left(\frac{k\pi}{3}\right)$ est périodique de période $6$, car $\frac{(k + 6)\pi}{3} = \frac{k\pi}{3} + 2\pi$. La somme de six termes consécutifs est donc toujours égale à $1 + \frac{1}{2} - \frac{1}{2} - 1 - \frac{1}{2} + \frac{1}{2} = 0$.
:::

::: etape Conclusion
$$t_{n+6} = t_n + \sum_{k=n+1}^{n+6} \cos\left(\frac{k\pi}{3}\right) = t_n + 0 = t_n$$
:::

::: resultat
$t_1 = \frac{3}{2}$, $t_2 = 1$, $t_6 = 1$, et $(t_n)$ est périodique de période $6$.
:::

## Question 5 : la suite $(z_n)$

::: methode
On fait apparaître $\dfrac{\sin X}{X}$ avec $X = \dfrac{1}{n}$.
:::

::: etape Réécriture
$$z_n = n\sin\left(\frac{1}{n}\right) = \frac{\sin\left(\frac{1}{n}\right)}{\frac{1}{n}}$$
:::

::: etape Limite
$X = \frac{1}{n}$ tend vers $0$ et $\lim\limits_{X \to 0} \frac{\sin X}{X} = 1$ : par composition, $z_n$ tend vers $1$.
:::

::: resultat
$$\lim_{n \to +\infty} z_n = 1$$
:::

Solution:
<!-- optitab:1 -->
1. $u_0 = -1$, $u_1 = 0$, $u_2 = \frac{\sqrt{2}}{2}$ ; $\lim u_n = 1$.
2. $v_{n+8} = v_n$ ; $(v_n)$ n’est pas convergente.
3. $2 - \frac{1}{n} \le w_n \le 2 + \frac{1}{n}$ ; $\lim w_n = 2$.
4. $t_1 = \frac{3}{2}$, $t_2 = 1$, $t_6 = 1$ ; $t_{n+6} = t_n$.
5. $\lim z_n = 1$.

=== Problème - Intégrales et aires avec sinus et cosinus
Id: 1207
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. Calculer $\displaystyle\int_0^{\pi} \sin x \, \mathrm{d}x$ et interpréter graphiquement ce résultat.
2. À l’aide d’une intégration par parties, calculer $\displaystyle\int_0^{\pi} x\sin x \, \mathrm{d}x$.
3. Déterminer une primitive sur $\mathbb{R}$ de la fonction $x \mapsto \sin x\cos x$.
4. Calculer $\displaystyle\int_0^{\pi} \sin(2x) \, \mathrm{d}x$ et interpréter graphiquement ce résultat.
5. On note $\mathcal{D}$ le domaine compris entre les courbes des fonctions $\sin$ et $\cos$ pour $x$ compris entre $\frac{\pi}{4}$ et $\frac{5\pi}{4}$ (figure ci-dessous). Calculer l’aire de $\mathcal{D}$ en unités d’aire.

[IMAGE_1]

Étapes:
<!-- optitab:1 -->
::: rappel Calcul d’une intégrale
$\displaystyle\int_a^b f(x)\, \mathrm{d}x = F(b) - F(a)$, où $F$ est une primitive de $f$ sur $[a\,;b]$. Primitives utiles : $-\cos$ pour $\sin$, $\sin$ pour $\cos$, $-\frac{1}{a}\cos(ax)$ pour $\sin(ax)$.
:::

## Question 1 : $\displaystyle\int_0^{\pi} \sin x \, \mathrm{d}x$

::: etape Calcul
$$
\begin{aligned}
\int_0^{\pi} \sin x\, \mathrm{d}x &= \Big[-\cos x\Big]_0^{\pi} \\
&= -\cos\pi - (-\cos 0) \\
&= 1 + 1 = 2
\end{aligned}
$$
:::

::: etape Interprétation
$\sin x \ge 0$ sur $[0\,;\pi]$ : l’intégrale est l’aire du domaine compris entre la courbe de $\sin$ et l’axe des abscisses sur $[0\,;\pi]$.
:::

[IMAGE_2]

::: resultat
$$\int_0^{\pi} \sin x\, \mathrm{d}x = 2$$
:::

## Question 2 : $\displaystyle\int_0^{\pi} x\sin x \, \mathrm{d}x$

::: methode
Intégration par parties : $\displaystyle\int_a^b u v' = \Big[uv\Big]_a^b - \int_a^b u' v$.
:::

::: etape Choix de $u$ et $v$
$u(x) = x$ et $v'(x) = \sin x$, donc $u'(x) = 1$ et $v(x) = -\cos x$. Ces fonctions sont dérivables à dérivées continues sur $[0\,;\pi]$.
:::

::: etape Calcul
$$
\begin{aligned}
&\int_0^{\pi} x\sin x\, \mathrm{d}x \\
&= \Big[-x\cos x\Big]_0^{\pi} - \int_0^{\pi} (-\cos x)\, \mathrm{d}x \\
&= \Big[-x\cos x\Big]_0^{\pi} + \Big[\sin x\Big]_0^{\pi} \\
&= (-\pi\cos\pi - 0) + (\sin\pi - \sin 0) \\
&= \pi + 0 = \pi
\end{aligned}
$$
:::

::: resultat
$$\int_0^{\pi} x\sin x\, \mathrm{d}x = \pi$$
:::

## Question 3 : primitive de $\sin x\cos x$

::: methode
On reconnaît la forme $u'u$, dont une primitive est $\frac{u^2}{2}$.
:::

::: etape Identification
Avec $u(x) = \sin x$ : $u'(x) = \cos x$ et $\sin x\cos x = u'(x)\,u(x)$.
:::

::: etape Vérification
$\left(\dfrac{\sin^2 x}{2}\right)' = \dfrac{2\sin x\cos x}{2} = \sin x\cos x$.
:::

::: resultat
$F(x) = \dfrac{\sin^2 x}{2}$ est une primitive de $x \mapsto \sin x\cos x$ sur $\mathbb{R}$.
:::

## Question 4 : $\displaystyle\int_0^{\pi} \sin(2x) \, \mathrm{d}x$

::: etape Calcul
Une primitive de $\sin(2x)$ est $-\frac{1}{2}\cos(2x)$ :

$$
\begin{aligned}
\int_0^{\pi} \sin(2x)\, \mathrm{d}x &= \left[-\frac{1}{2}\cos(2x)\right]_0^{\pi} \\
&= -\frac{1}{2}\cos(2\pi) + \frac{1}{2}\cos 0 \\
&= -\frac{1}{2} + \frac{1}{2} = 0
\end{aligned}
$$
:::

::: etape Interprétation
Sur $\left[0\,;\frac{\pi}{2}\right]$, $\sin(2x) \ge 0$ et l’intégrale vaut $1$ ; sur $\left[\frac{\pi}{2}\,;\pi\right]$, $\sin(2x) \le 0$ et l’intégrale vaut $-1$. Les deux domaines ont la même aire et se compensent.
:::

[IMAGE_3]

::: resultat
$$\int_0^{\pi} \sin(2x)\, \mathrm{d}x = 0$$
:::

::: attention
Une intégrale nulle ne signifie pas que la fonction est nulle : les parties au-dessus et au-dessous de l’axe se compensent.
:::

## Question 5 : aire du domaine $\mathcal{D}$

::: methode
Si $f \ge g$ sur $[a\,;b]$, l’aire entre les deux courbes vaut $\displaystyle\int_a^b \big(f(x) - g(x)\big)\, \mathrm{d}x$.
:::

::: etape Position des courbes
Sur le cercle, les points $M(x)$ tels que $\sin x \ge \cos x$ sont au-dessus de la droite d’équation $y = x$ : ils correspondent à $x \in \left[\frac{\pi}{4}\,;\frac{5\pi}{4}\right]$. Sur cet intervalle, la courbe de $\sin$ est donc au-dessus de celle de $\cos$.
:::

::: etape Calcul
Une primitive de $\sin x - \cos x$ est $-\cos x - \sin x$ :

$$
\begin{aligned}
\mathcal{A} &= \int_{\frac{\pi}{4}}^{\frac{5\pi}{4}} (\sin x - \cos x)\, \mathrm{d}x \\
&= \Big[-\cos x - \sin x\Big]_{\frac{\pi}{4}}^{\frac{5\pi}{4}} \\
&= \left(\frac{\sqrt{2}}{2} + \frac{\sqrt{2}}{2}\right) - \left(-\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}\right) \\
&= \sqrt{2} + \sqrt{2} = 2\sqrt{2}
\end{aligned}
$$
:::

[IMAGE_4]

::: resultat
L’aire de $\mathcal{D}$ vaut $2\sqrt{2} \approx 2{,}83$ unités d’aire.
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle\int_0^{\pi} \sin x\, \mathrm{d}x = 2$ : aire sous une arche de la sinusoïde.
2. $\displaystyle\int_0^{\pi} x\sin x\, \mathrm{d}x = \pi$
3. $F(x) = \dfrac{\sin^2 x}{2}$
4. $\displaystyle\int_0^{\pi} \sin(2x)\, \mathrm{d}x = 0$ : les deux arches se compensent.
5. $\mathcal{A} = 2\sqrt{2}$ unités d’aire.
