<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">I. Définition et propriété fondamentale</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
<strong>Définition :</strong> Le logarithme népérien est la fonction réciproque de l'exponentielle : $\displaystyle \ln : ]0, +\infty[ \to \mathbb{R}$
</div>
<div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
<strong>Propriété caractéristique :</strong> $\displaystyle \ln(e^x) = x$ et $\displaystyle e^{\ln(x)} = x$ (relation bijective)
</div>
<div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
<strong>Valeurs remarquables :</strong> $\displaystyle \ln(1) = 0$ et $\displaystyle \ln(e) = 1$
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IV. Domaine, image et variations</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
<thead>
<tr style="background:#3498db; color:white;">
<th style="border:1px solid #ddd; padding:12px;">Propriété</th>
<th style="border:1px solid #ddd; padding:12px;">Valeur</th>
</tr>
</thead>
<tbody>
<tr style="background:#f8f9fa;">
<td style="border:1px solid #ddd; padding:10px;"><strong>Domaine de définition</strong></td>
<td style="border:1px solid #ddd; padding:10px;">$\displaystyle ]0, +\infty[$</td>
</tr>
<tr style="background:#ffffff;">
<td style="border:1px solid #ddd; padding:10px;"><strong>Ensemble image</strong></td>
<td style="border:1px solid #ddd; padding:10px;">$\displaystyle \mathbb{R}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:1px solid #ddd; padding:10px;"><strong>Sens de variation</strong></td>
<td style="border:1px solid #ddd; padding:10px;">Strictement croissante sur $\displaystyle ]0, +\infty[$</td>
</tr>
<tr style="background:#ffffff;">
<td style="border:1px solid #ddd; padding:10px;"><strong>Signe</strong></td>
<td style="border:1px solid #ddd; padding:10px;">$\displaystyle \ln(x) > 0$ si $\displaystyle x > 1$, $\displaystyle \ln(x) < 0$ si $\displaystyle 0 < x < 1$</td>
</tr>
</tbody>
</table>

<div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0;">
<strong>📐 Propriétés importantes :</strong>
<ul style="margin:8px 0; padding-left:20px;">
<li>La fonction logarithme est <strong>strictement croissante</strong> sur $\displaystyle ]0, +\infty[$</li>
<li>Elle n'est définie que pour les nombres <strong>strictement positifs</strong></li>
<li>$\displaystyle f'(x) = \frac{1}{x} > 0$ pour tout $\displaystyle x > 0$</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">V. Limites fondamentales</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0^+} \ln(x) = -\infty$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to +\infty} \ln(x) = +\infty$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{\ln(1+x)}{x} = 1$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0^+} x \ln(x) = 0$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to +\infty} \frac{\ln(x)}{x} = 0$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to +\infty} \frac{x}{\ln(x)} = +\infty$</p>
</div>

<div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #10b981;">
<strong>Propriété clé :</strong> Le logarithme croît <strong>moins vite</strong> que n'importe quelle puissance positive : $\displaystyle \ln(x)$ est "écrasé" par les puissances de $\displaystyle x$.
</div>

<div style="background:#fff8dc; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #ffa500;">
<strong>⚠️ Asymptote :</strong> L'axe des ordonnées ($\displaystyle x = 0$) est une <strong>asymptote verticale</strong>.
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VI. Équations logarithmiques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
<strong>📐 Méthodes de résolution :</strong>
<ul style="margin:10px 0; padding-left:20px;">
<li><strong>Égalité de logarithmes :</strong> $\displaystyle \ln(a) = \ln(b) \Leftrightarrow a = b$ (avec $\displaystyle a, b > 0$)</li>
<li><strong>Logarithme égal à un nombre :</strong> $\displaystyle \ln(x) = k \Leftrightarrow x = e^k$</li>
<li><strong>Vérification :</strong> Toujours vérifier que les arguments sont strictement positifs</li>
<li><strong>Utilisation des propriétés :</strong> Simplifier avec $\displaystyle \ln(xy) = \ln(x) + \ln(y)$, etc.</li>
</ul>
</div>

<div style="background:#fff8dc; padding:12px; border-radius:4px; margin:10px 0; border-left:4px solid #ffa500;">
<strong>⚠️ Méthode :</strong>
<ol style="margin:8px 0; padding-left:20px;">
<li>Simplifier l'équation avec les propriétés algébriques</li>
<li>Ramener à une forme $\displaystyle \ln(A) = \ln(B)$ ou $\displaystyle \ln(x) = k$</li>
<li>Appliquer la méthode correspondante</li>
<li>Vérifier que les solutions sont valides (arguments > 0)</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VII. Inéquations logarithmiques</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
<strong>Propriété fondamentale :</strong> La fonction logarithme est <strong>strictement croissante</strong>, donc elle <strong>conserve l'ordre</strong> :
<ul style="margin:10px 0; padding-left:20px;">
<li>$\displaystyle \ln(a) < \ln(b) \Leftrightarrow a < b$ (avec $\displaystyle a, b > 0$)</li>
<li>$\displaystyle \ln(a) \leq \ln(b) \Leftrightarrow a \leq b$</li>
<li>$\displaystyle \ln(a) > \ln(b) \Leftrightarrow a > b$</li>
</ul>
</div>

<div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #10b981;">
<strong>💡 Méthode :</strong> Pour résoudre une inéquation logarithmique, on compare les arguments en <strong>conservant le sens de l'inégalité</strong> (car la fonction est croissante).
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IX. Équivalents et limites usuelles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="margin:15px 0; padding:15px; background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db;">
<strong>Au voisinage de 0 :</strong>
<p style="margin:8px 0;">$\displaystyle \ln(1+x) \sim x$</p>
<p style="margin:8px 0;">$\displaystyle \lim_{x \to 0} \frac{\ln(1+x)}{x} = 1$</p>
</div>

<div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #10b981;">
<strong>Croissances comparées :</strong>
<ul style="margin:8px 0; padding-left:20px;">
<li>En $\displaystyle +\infty$ : $\displaystyle x^n \gg \ln(x)$ (puissance l'emporte sur logarithme)</li>
<li>$\displaystyle \lim_{x \to +\infty} \frac{\ln(x)}{x^n} = 0$</li>
<li>$\displaystyle \lim_{x \to +\infty} \frac{x^n}{\ln(x)} = +\infty$</li>
</ul>
</div>
</div>
