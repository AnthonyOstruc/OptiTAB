<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : conversions (longueurs, aires, volumes, durées, masses), vitesses, débits, masses volumiques, énergie et cohérence des unités. Programme de 3ème.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Conversions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Aires :</strong> facteur au carré : $\displaystyle 1$ m² $= 10\,000$ cm². <strong>Volumes :</strong> au cube : $\displaystyle 1$ m³ $= 10^6$ cm³.</p>
<p style="margin:6px 0 0 0;">• <strong>Contenances :</strong> $\displaystyle 1$ L $= 1$ dm³ ; $\displaystyle 1$ mL $= 1$ cm³ ; $\displaystyle 1$ m³ $= 1000$ L.</p>
<p style="margin:6px 0 0 0;">• <strong>Durées :</strong> base 60 ! $\displaystyle 2{,}4$ h $= 2$ h $24$ min ; 1 h 30 $= 1{,}5$ h (jamais 1,30 h !).</p>
<p style="margin:6px 0 0 0;">• <strong>Masses :</strong> $\displaystyle 1$ t $= 1000$ kg $= 10^6$ g.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Vitesse, débit, masse volumique, énergie</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle v = \frac{d}{t}$ &nbsp;&nbsp; $\displaystyle q = \frac{V}{t}$ &nbsp;&nbsp; $\displaystyle \rho = \frac{m}{V}$ &nbsp;&nbsp; $E$ (kWh) $=$ $P$ (kW) $\times$ $t$ (h)</p>
</div>
[IMAGE_1]
<p style="margin:0;">• km/h ↔ m/s : <strong>÷ 3,6</strong> dans un sens, <strong>× 3,6</strong> dans l'autre ($72$ km/h $= 20$ m/s).</p>
<p style="margin:6px 0 0 0;">• <strong>Vitesse moyenne d'un trajet</strong> = distance TOTALE ÷ durée TOTALE (jamais la moyenne des vitesses !).</p>
<p style="margin:6px 0 0 0;">• Travail à plusieurs (robinets…) : on additionne les <strong>parts par minute</strong>, pas les durées.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ 1 h 30 = 1,30 h (c'est 1,5 h : base 60 !).</p>
<p style="margin:6px 0 0 0;">2️⃣ Convertir une aire avec le facteur des longueurs (m² → cm² : × 10 000, pas × 100).</p>
<p style="margin:6px 0 0 0;">3️⃣ Faire la moyenne de deux vitesses pour un aller-retour.</p>
<p style="margin:6px 0 0 0;">4️⃣ Mélanger les unités dans une formule (cm avec m, kg avec g/cm³…).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> nommer la grandeur ET l'unité à chaque étape ; convertir AVANT de calculer ; pour un achat, arrondir à l'entier supérieur ; donner un ordre de grandeur pour contrôler.</p>
</div>
