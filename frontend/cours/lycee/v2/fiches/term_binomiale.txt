<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Loi binomiale</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$P(X = k) = \binom{n}{k}\,p^k\,(1 - p)^{n - k}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Conditions : $n$ épreuves à deux issues, identiques et indépendantes.</p>
<p style="margin:6px 0 0 0;">2️⃣ $E(X) = np$ ; $V(X) = np(1 - p)$ ; $\sigma(X) = \sqrt{np(1 - p)}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Loi de Bernoulli : $E = p$, $V = p(1 - p)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calculs</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $P(X \le k)$ : fonction de répartition (calculatrice ou Python).</p>
<p style="margin:6px 0 0 0;">2️⃣ $P(X \ge k) = 1 - P(X \le k - 1)$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Seuil : plus petit $k$ tel que $P(X \le k) \ge 1 - \alpha$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Ne pas justifier les conditions (identiques, indépendantes, deux issues).</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $P(X \ge k) = 1 - P(X \le k)$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Utiliser la loi binomiale pour des tirages sans remise dans une petite urne.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier le coefficient $\binom{n}{k}$ (nombre de chemins).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> « au moins un succès » → $P(X \ge 1) = 1 - P(X = 0) = 1 - (1 - p)^n$.</p>
</div>
