=== Découverte - Comparer un programme à une prédiction - Parcours 1
Id: 3828
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Programme : multiplier par 2, ajouter 6, puis diviser le résultat par 2.

1. Exécuter le programme avec le départ 3.
2. Exécuter avec le départ 4.
3. Proposer un programme plus court donnant le même résultat pour ces départs.
4. Expliquer pourquoi le programme court fonctionne pour tout nombre de départ positif.

Étapes:

<!-- optitab:1 -->

## Question 1 : Exécuter le programme avec le départ 3.

::: methode
Noter chaque résultat intermédiaire.
:::

::: etape Raisonnement et calcul
$3\times2=6$ ; $6+6=12$ ; $12\div2=6$
:::

::: resultat
$6$.
:::

## Question 2 : Exécuter avec le départ 4.

::: methode
Appliquer les mêmes instructions.
:::

::: etape Raisonnement et calcul
$((4\times2)+6)\div2=7$
:::

::: resultat
$7$.
:::

## Question 3 : Proposer un programme plus court donnant le même résultat pour ces départs.

::: methode
Observer la quantité ajoutée à chaque nombre de départ.
:::

::: etape Raisonnement et calcul
Le résultat dépasse chaque nombre choisi de 3.
:::

::: resultat
Ajouter 3 au nombre de départ.
:::

## Question 4 : Expliquer pourquoi le programme court fonctionne pour tout nombre de départ positif.

::: methode
Partager la somme en deux parts lors de la division.
:::

::: etape Raisonnement et calcul
La multiplication par 2, suivie de la division par 2, redonne le nombre initial. La quantité 6, divisée par 2, fournit 3.
:::

::: resultat
On retrouve toujours le nombre de départ augmenté de 3.
:::

::: retenir
Tester plusieurs cas suggère une règle ; expliquer le fonctionnement permet de la justifier.
:::

Solution:
<!-- optitab:1 -->
1. $6$.
2. $7$.
3. Ajouter 3 au nombre de départ.
4. On retrouve toujours le nombre de départ augmenté de 3.

3. Écrire le programme qui calcule le prix à partir du nombre de séances.

Étapes:

<!-- optitab:1 -->

## Question 1 : Calculer le prix des séances seules.

::: methode
Multiplier le prix unitaire par le nombre de séances.
:::

::: etape Raisonnement et calcul
$2\times8=16$
:::

16 €.
:::

## Question 2 : Calculer le prix total.

::: methode

:::

::: etape Raisonnement et calcul

2. Quel nombre obtient-on après la multiplication ?
3. Donner le résultat final.
4. Écrire le calcul en une expression avec des parenthèses.

Étapes:

<!-- optitab:1 -->

## Question 1 : Quel nombre obtient-on après l’addition ?

::: methode
Partir du nombre choisi.
:::

::: etape Raisonnement et calcul
$3+3=6$
:::

::: resultat
$6$.
:::

## Question 2 : Quel nombre obtient-on après la multiplication ?

::: methode
Multiplier le résultat précédent, pas seulement le nombre initial.
:::

::: etape Raisonnement et calcul
$6\times2=12$
:::

::: resultat
$12$.
:::

## Question 3 : Donner le résultat final.

::: methode
Appliquer la dernière consigne.
:::

::: etape Raisonnement et calcul
$12-4=8$
:::

::: resultat
$8$.
:::

## Question 4 : Écrire le calcul en une expression avec des parenthèses.

::: etape Raisonnement et calcul
$(3+3)\times2-4=8$
:::

::: resultat
$(3+3)\times2-4$.
:::

::: retenir
Chaque instruction agit sur le résultat de l’étape précédente.
:::

Solution:
<!-- optitab:1 -->
1. $6$.
2. $12$.
3. $8$.
4. $(3+3)\times2-4$.

=== Découverte - Trouver l’étape oubliée - Parcours 1
Id: 3826
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Programme : ajouter 3, puis multiplier par 2. Pour le départ 6, un élève calcule 6 fois 2, puis ajoute 3.

1. Quel résultat l’élève obtient-il ?
2. Pourquoi son calcul ne suit-il pas le programme ?
3. Corriger le calcul.
4. Calculer l’écart entre les deux résultats et expliquer son origine.

Étapes:

<!-- optitab:1 -->

## Question 1 : Quel résultat l’élève obtient-il ?

::: methode
Exécuter exactement son calcul.
:::

::: etape Raisonnement et calcul
$6\times2+3=15$
:::

::: resultat
$15$.
:::

## Question 2 : Pourquoi son calcul ne suit-il pas le programme ?

::: methode
Comparer l’ordre des opérations.
:::

::: etape Raisonnement et calcul
Le programme commence par une addition ; l’élève commence par une multiplication.
:::

::: resultat
Il a interverti les deux instructions.
:::

## Question 3 : Corriger le calcul.

::: methode
Revenir à l’ordre annoncé.
:::

::: etape Raisonnement et calcul
$(6+3)\times2=18$
:::

::: resultat
$18$.
:::

## Question 4 : Calculer l’écart entre les deux résultats et expliquer son origine.

::: methode
Comparer le traitement de la quantité ajoutée.
:::

::: etape Raisonnement et calcul
$18-15=3$ : dans le bon programme, les 3 unités ajoutées sont aussi multipliées par 2.
:::

::: resultat
$3$.
:::

::: retenir
Un résultat numérique ne suffit pas : la suite des opérations doit traduire toutes les consignes.
:::

Solution:
<!-- optitab:1 -->
1. $15$.
2. Il a interverti les deux instructions.
3. $18$.
4. $3$.
