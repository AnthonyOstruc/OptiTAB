<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Conditionnement et arbres</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle P_A(B) = \frac{P(A \cap B)}{P(A)}$ et $\displaystyle P(A \cap B) = P(A) \times P_A(B)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Branches d’un même nœud : somme $\displaystyle 1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Chemin : produit des probabilités.</p>
<p style="margin:6px 0 0 0;">3️⃣ Événement : somme des chemins qui y mènent.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Probabilités totales et indépendance</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $\displaystyle P(B) = P(A)P_A(B) + P(\overline{A})P_{\overline{A}}(B)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\displaystyle P_B(A) = \frac{P(A \cap B)}{P(B)}$ pour « remonter » l’arbre.</p>
<p style="margin:6px 0 0 0;">3️⃣ Indépendants : $\displaystyle P(A \cap B) = P(A)P(B)$, ou $\displaystyle P_A(B) = P(B)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre $\displaystyle P_A(B)$, $\displaystyle P_B(A)$ et $\displaystyle P(A \cap B)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Lire $\displaystyle P(B)$ directement sur une branche de second niveau.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier un chemin dans les probabilités totales.</p>
<p style="margin:6px 0 0 0;">4️⃣ Confondre incompatibles et indépendants.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je traduis chaque donnée de l’énoncé en $\displaystyle P(\ldots)$ ou $\displaystyle P_{\ldots}(\ldots)$ avant de dessiner l’arbre.</p>
</div>
