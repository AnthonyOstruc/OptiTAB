Titre: Multiplier par 4 et par 8
<!-- optitab:1 -->

::: objectifs
Je calcule par doubles successifs quand cette méthode est utile.

- Expliquer les étapes avec des mots simples.
- Contrôler le résultat obtenu.
:::

## I. Comprendre

::: propriete Repère 1
Multiplier par 4 revient à prendre le double du double.
:::

::: propriete Repère 2
Multiplier par 8 revient à doubler trois fois de suite.
:::

::: propriete Repère 3
Si un produit est connu par une table ou par les dizaines, je peux utiliser directement ce résultat.
:::

## II. Faire pas à pas

::: methode Je cherche avant de calculer
Je lis la consigne. Je repère les nombres et ce qu’ils comptent. Je choisis une méthode puis je garde les étapes utiles sur mon ardoise.
:::

[IMAGE_1]

::: exemple Un calcul expliqué
Je double : $27+27 = 54$.

Je double : $54+54 = 108$.

Je double : $108+108 = 216$.

$$
27\times 8 = 216
$$
:::

### À toi, avec de l’aide

Calcule 45 × 4 en deux doubles.

::: exemple Je vérifie ma recherche
Je double : $45+45 = 90$.

Je double : $90+90 = 180$.

$$
45\times 4 = 180
$$

45 → 90 → 180 ; produit : 180.
:::

## III. Vérifier et choisir

::: attention Le piège à éviter
La procédure n’est pas imposée quand une table ou les unités de numération donnent le résultat plus directement.
:::

::: conseil Si je bloque
Je note chaque double et je compte les groupes : deux, puis quatre, puis huit.
:::

::: retenir
Je calcule par doubles successifs quand cette méthode est utile.
:::
