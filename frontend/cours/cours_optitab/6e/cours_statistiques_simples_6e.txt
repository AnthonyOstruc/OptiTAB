=== Statistiques très simples : Effectif, total, moyenne - Programme 6ème
Difficulté: easy
Ordre: 13

Titre: Statistiques très simples : Comprendre l'effectif, calculer un total et une moyenne
Description: Mini-cours de statistiques pour la 6ème. Objectifs: comprendre la notion d'effectif, lire et compléter de petits tableaux de données, calculer un total et une moyenne arithmétique simple. Données concrètes: tailles de la classe, nombre d'animaux domestiques, points à un jeu, etc.

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Mots-clés et idées de base</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Série statistique</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ensemble de <strong>valeurs</strong> (ou de <strong>réponses</strong>) recueillies sur un groupe (par exemple: nombre d'animaux par élève).</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Effectif</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour une valeur donnée, l'<strong>effectif</strong> est le <strong>nombre</strong> de fois où cette valeur apparaît.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Total</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le <strong>total</strong> est la <strong>somme</strong> de toutes les valeurs (ou de tous les effectifs, selon le contexte).</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Moyenne arithmétique simple</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Moyenne</strong> = (somme des valeurs) ÷ (nombre de valeurs).</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Idée-clé :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La moyenne est une <strong>valeur centrale</strong> qui résume toutes les données par un seul nombre.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>📌 Effectif d'une valeur et effectif total</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">
                    L'<strong>effectif d'une valeur</strong>, c'est le <strong>nombre de fois</strong> où cette valeur apparaît.<br>
                    Exemple : si 8 élèves ont 1 animal, l'effectif de la valeur "1 animal" est 8.
                </li>
                <li style="margin:0 0 8px 0; text-align:left;">
                    L'<strong>effectif total</strong>, c'est le <strong>nombre total d'élèves</strong> (ou de réponses).<br>
                    Exemple : si les effectifs sont 6 ; 8 ; 5 ; 3 ; 2, alors l'effectif total est :<br>
                    6 + 8 + 5 + 3 + 2 = <strong>24 élèves</strong>.
                </li>
            </ul>
        </div>
    </div>

    <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
        <strong>💡 À savoir sur la moyenne :</strong>
        <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
            <li style="margin:0 0 8px 0; text-align:left;">
                La <strong>moyenne</strong> n'est pas forcément une valeur qui apparaît dans le tableau.<br>
                Exemple : si trois élèves mesurent 140 cm, 150 cm et 160 cm, la moyenne est :<br>
                (140 + 150 + 160) ÷ 3 = 450 ÷ 3 = <strong>150 cm</strong> (ici, elle apparaît),<br>
                mais avec 140 cm, 145 cm et 160 cm, la moyenne est :<br>
                (140 + 145 + 160) ÷ 3 = 445 ÷ 3 ≈ <strong>148,3 cm</strong>, qui n'est la taille de personne.
            </li>
            <li style="margin:0; text-align:left;">
                La moyenne est une <strong>valeur "au centre"</strong> des données, mais elle ne décrit pas tout : 
                deux classes peuvent avoir la même moyenne et des répartitions très différentes.
            </li>
        </ul>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <strong>✔️ Exemple corrigé : moyenne de scores</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">
                Scores : 12 ; 15 ; 9 ; 18 ; 16
            </p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 8px 0; text-align:left;">On calcule la <strong>somme</strong> : 12 + 15 + 9 + 18 + 16 = <strong style="color:#27ae60;">70</strong></li>
                <li style="margin:0 0 8px 0; text-align:left;">Il y a <strong>5</strong> parties.</li>
                <li style="margin:0 0 8px 0; text-align:left;">Moyenne = somme ÷ nombre de parties = 70 ÷ 5 = <strong style="color:#27ae60;">14</strong></li>
                <li style="margin:0; text-align:left;">La moyenne des scores est <strong>14 points</strong>.</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Bien raisonner en statistiques simples</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Lire <strong>l'intitulé</strong> du tableau: que représentent les colonnes/lignes ?</li>
                <li style="margin:0 0 12px 0; text-align:left;">Distinguer <strong>valeur</strong> et <strong>effectif</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour la <strong>somme</strong>, penser "valeur × effectif" puis additionner.</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour la <strong>moyenne</strong>, diviser la somme totale par le <strong>nombre de valeurs</strong>.</li>
                <li style="margin:0; text-align:left;">Toujours faire une <strong>vérification</strong> rapide des totaux.</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">

            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
