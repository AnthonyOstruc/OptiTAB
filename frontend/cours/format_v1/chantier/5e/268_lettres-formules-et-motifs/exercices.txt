=== Découverte - Écrire avec des lettres
Id: 2854
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dans tout l'exercice, les lettres $x$, $y$, $a$ et $b$ désignent des nombres.

1. Traduire chaque phrase par une expression.
   - a) Le double de $x$.
   - b) Le nombre $x$ diminué de $4$.
   - c) Le triple de $x$, augmenté de $1$.
   - d) Le carré de $x$.
   - e) Le quart de $x$.
2. Écrire chaque expression sans signe $\times$ lorsque c'est possible.
   - a) $6 \times x$
   - b) $x \times 9$
   - c) $a \times b$
   - d) $5 \times (x + 2)$
   - e) $1 \times y$
   - f) $4 \times 7$
3. Rétablir les signes $\times$ sous-entendus.
   - a) $7y$
   - b) $3ab$
   - c) $2x^2$
   - d) $4(y + 1)$
4. Décrire par une phrase chacune des expressions $2(x + 5)$ et $2x + 5$, puis les calculer pour $x = 3$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Traduire des phrases

::: methode
Repérer l'opération : « double » et « triple » sont des multiplications, « diminué de » une soustraction, « augmenté de » une addition, « quart » une division par $4$, « carré » le produit du nombre par lui-même.
:::

::: etape Écrire chaque expression
- a) Le double de $x$ : $2 \times x$, soit $2x$.
- b) $x$ diminué de $4$ : $x - 4$.
- c) On prend d'abord le triple de $x$, soit $3x$, puis on ajoute $1$ : $3x + 1$.
- d) Le carré de $x$ : $x \times x$, soit $x^2$.
- e) Le quart de $x$ : $x \div 4$.
:::

::: resultat
a) $2x$ ; b) $x - 4$ ; c) $3x + 1$ ; d) $x^2$ ; e) $x \div 4$.
:::

## Question 2 : Supprimer les signes $\times$

::: methode
On peut supprimer le signe $\times$ devant une lettre ou une parenthèse ; le nombre s'écrit devant la lettre. On ne le supprime jamais entre deux nombres.
:::

::: etape Appliquer les conventions
- a) $6 \times x = 6x$.
- b) $x \times 9 = 9x$ : le nombre passe devant la lettre.
- c) $a \times b = ab$.
- d) $5 \times (x + 2) = 5(x + 2)$.
- e) $1 \times y = y$ : multiplier par $1$ ne change pas le nombre.
- f) $4 \times 7$ : ce sont deux nombres, on ne peut pas supprimer le signe $\times$. On calcule : $4 \times 7 = 28$.
:::

::: resultat
a) $6x$ ; b) $9x$ ; c) $ab$ ; d) $5(x + 2)$ ; e) $y$ ; f) $28$ (et surtout pas $47$).
:::

## Question 3 : Rétablir les signes $\times$

::: methode
Remettre un signe $\times$ entre un nombre et une lettre, entre deux lettres et devant une parenthèse ; $x^2$ signifie $x \times x$.
:::

::: etape Écrire les produits
- a) $7y = 7 \times y$.
- b) $3ab = 3 \times a \times b$.
- c) $2x^2 = 2 \times x \times x$ : seul $x$ est au carré.
- d) $4(y + 1) = 4 \times (y + 1)$.
:::

::: resultat
a) $7 \times y$ ; b) $3 \times a \times b$ ; c) $2 \times x \times x$ ; d) $4 \times (y + 1)$.
:::

## Question 4 : Deux expressions qui se ressemblent

::: methode
Repérer la **dernière** opération effectuée : elle donne le nom de l'expression (somme, produit…).
:::

::: etape Décrire les deux expressions
- $2(x + 5)$ : on calcule d'abord $x + 5$, puis on multiplie par $2$. C'est **le double de la somme de $x$ et de $5$**.
- $2x + 5$ : on calcule d'abord $2x$, puis on ajoute $5$. C'est **le double de $x$, augmenté de $5$**.
:::

::: etape Calculer pour $x = 3$
$$
\begin{aligned}
2(x + 5) &= 2 \times (3 + 5) = 2 \times 8 = 16 \\
2x + 5 &= 2 \times 3 + 5 = 6 + 5 = 11
\end{aligned}
$$
:::

::: resultat
$2(x + 5)$ est le double de la somme de $x$ et de $5$ : il vaut $16$ pour $x = 3$. $2x + 5$ est le double de $x$ augmenté de $5$ : il vaut $11$ pour $x = 3$. Ce ne sont pas les mêmes nombres.
:::

::: attention Erreur fréquente
Confondre $x^2$ et $2x$ : $x^2 = x \times x$ alors que $2x = 2 \times x$. Pour $x = 3$, $x^2 = 9$ mais $2x = 6$.
:::

Solution:
<!-- optitab:1 -->
1. a) $2x$ ; b) $x - 4$ ; c) $3x + 1$ ; d) $x^2$ ; e) $x \div 4$.
2. a) $6x$ ; b) $9x$ ; c) $ab$ ; d) $5(x + 2)$ ; e) $y$ ; f) $28$.
3. a) $7 \times y$ ; b) $3 \times a \times b$ ; c) $2 \times x \times x$ ; d) $4 \times (y + 1)$.
4. $2(x + 5)$ : le double de la somme de $x$ et de $5$, il vaut $16$ ; $2x + 5$ : le double de $x$ augmenté de $5$, il vaut $11$.

=== Découverte - Remplacer une lettre par un nombre
Id: 2861
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère les expressions :
$$A = 3x + 5 \qquad B = x^2 + 2 \qquad C = 2(x - 1) \qquad D = 5x^2$$

1. Calculer $A$, $B$, $C$ et $D$ pour $x = 4$.
2. Calculer $A$ et $B$ pour $x = 2{,}5$.
3. Pour calculer $D$ avec $x = 4$, Paul écrit : « $5 \times 4 = 20$, puis $20^2 = 400$ ». Expliquer son erreur.
4. On considère l'égalité $3x + 5 = x^2 + 1$.
   - a) Est-elle vraie pour $x = 4$ ?
   - b) Est-elle vraie pour $x = 2$ ?
5. Zoé affirme : « L'égalité $3x + 5 = x^2 + 1$ est vraie pour tous les nombres $x$. » A-t-elle raison ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer pour $x = 4$

::: methode
Remplacer $x$ par $4$, rétablir les signes $\times$, puis calculer en respectant les priorités : puissances, puis multiplications, puis additions et soustractions.
:::

::: etape Les expressions $A$ et $B$
$$
\begin{aligned}
A &= 3 \times 4 + 5 = 12 + 5 = 17 \\
B &= 4^2 + 2 = 16 + 2 = 18
\end{aligned}
$$
:::

::: etape Les expressions $C$ et $D$
$$
\begin{aligned}
C &= 2 \times (4 - 1) = 2 \times 3 = 6 \\
D &= 5 \times 4^2 = 5 \times 16 = 80
\end{aligned}
$$
:::

::: resultat
Pour $x = 4$ : $A = 17$, $B = 18$, $C = 6$ et $D = 80$.
:::

## Question 2 : Calculer pour $x = 2{,}5$

::: methode
Même méthode avec un nombre décimal ; $2{,}5^2 = 2{,}5 \times 2{,}5$.
:::

::: etape Remplacer et calculer
$$
\begin{aligned}
A &= 3 \times 2{,}5 + 5 = 7{,}5 + 5 = 12{,}5 \\
B &= 2{,}5^2 + 2 = 6{,}25 + 2 = 8{,}25
\end{aligned}
$$
:::

::: resultat
Pour $x = 2{,}5$ : $A = 12{,}5$ et $B = 8{,}25$.
:::

## Question 3 : L'erreur de Paul

::: methode
Rétablir les signes $\times$ de $D = 5x^2$ pour voir ce qui est au carré.
:::

::: etape Ce qui est au carré
$D = 5x^2 = 5 \times x \times x$ : seul $x$ est au carré, pas le produit $5x$. Paul a calculé $(5 \times 4)^2$ au lieu de $5 \times 4^2$.
:::

::: etape Le bon calcul
La puissance est prioritaire : $4^2 = 16$, puis $5 \times 16 = 80$.
:::

::: resultat
Paul a élevé $5 \times 4$ au carré, alors que seul $x$ est au carré : $D = 5 \times 16 = 80$, et non $400$.
:::

## Question 4 : Tester l'égalité

::: methode
Remplacer $x$ par la valeur choisie et calculer **séparément** les deux membres, puis les comparer.
:::

::: etape Pour $x = 4$
- Membre de gauche : $3 \times 4 + 5 = 12 + 5 = 17$.
- Membre de droite : $4^2 + 1 = 16 + 1 = 17$.
:::

::: etape Pour $x = 2$
- Membre de gauche : $3 \times 2 + 5 = 6 + 5 = 11$.
- Membre de droite : $2^2 + 1 = 4 + 1 = 5$.
:::

::: resultat
a) Pour $x = 4$, les deux membres valent $17$ : l'égalité est vraie. b) Pour $x = 2$, $11 \neq 5$ : l'égalité est fausse.
:::

## Question 5 : L'affirmation de Zoé

::: methode
Pour montrer qu'une égalité n'est pas vraie pour tous les nombres, il suffit d'un contre-exemple.
:::

::: etape Utiliser la question 4
Pour $x = 2$, l'égalité est fausse. Le nombre $2$ est donc un contre-exemple.
:::

::: resultat
Zoé a tort : l'égalité est vraie pour $x = 4$, mais fausse pour $x = 2$.
:::

::: attention Erreur fréquente
Conclure qu'une égalité est toujours vraie parce qu'elle est vraie pour une valeur. Un test réussi ne suffit pas ; un seul test raté suffit pour dire « pas toujours vraie ».
:::

Solution:
<!-- optitab:1 -->
1. $A = 17$, $B = 18$, $C = 6$, $D = 80$.
2. $A = 12{,}5$ et $B = 8{,}25$.
3. Seul $x$ est au carré : $D = 5 \times 4^2 = 5 \times 16 = 80$, et non $(5 \times 4)^2 = 400$.
4. a) Vraie ($17 = 17$). b) Fausse ($11 \neq 5$).
5. Non : $x = 2$ est un contre-exemple.

=== Découverte - Un motif de triangles en allumettes
Id: 2852
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Avec des allumettes, Lina construit une bande de triangles. À l'étape $n$, la bande contient $n$ triangles.

[IMAGE_1]

1. Compter les allumettes des étapes $1$, $2$ et $3$. Combien d'allumettes ajoute-t-on d'une étape à la suivante ?
2. Recopier et compléter le tableau.

| Étape | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|
| Allumettes | | | | | |

3. Lina explique : « Je pose une première allumette, puis $2$ allumettes pour chaque triangle. » Écrire une formule donnant le nombre $N$ d'allumettes à l'étape $n$.
4. Calculer le nombre d'allumettes à l'étape $10$, puis à l'étape $50$.
5. Tom affirme : « À l'étape $20$, il faut deux fois plus d'allumettes qu'à l'étape $10$. » A-t-il raison ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Compter les premières étapes

::: methode
Compter les allumettes sur le dessin, puis comparer deux étapes qui se suivent.
:::

::: etape Compter
Étape $1$ : $3$ allumettes. Étape $2$ : $5$ allumettes. Étape $3$ : $7$ allumettes.
:::

::: etape Ce qui s'ajoute
$5 - 3 = 2$ et $7 - 5 = 2$ : chaque nouveau triangle s'appuie sur une allumette déjà posée et n'en demande que $2$ de plus.
:::

::: resultat
$3$, $5$ et $7$ allumettes ; on ajoute $2$ allumettes à chaque étape.
:::

## Question 2 : Compléter le tableau

::: methode
Ajouter $2$ allumettes d'une étape à la suivante.
:::

::: etape Continuer le motif
Étape $4$ : $7 + 2 = 9$. Étape $5$ : $9 + 2 = 11$.

| Étape | $1$ | $2$ | $3$ | $4$ | $5$ |
|---|---|---|---|---|---|
| Allumettes | $3$ | $5$ | $7$ | $9$ | $11$ |
:::

::: resultat
$3$ ; $5$ ; $7$ ; $9$ ; $11$ allumettes.
:::

## Question 3 : Écrire la formule

::: methode
Découper le motif de l'étape $n$ comme Lina : une première allumette, puis $2$ allumettes par triangle.
:::

::: etape Découper l'étape 3
En orange, la première allumette ; en vert, les $2$ allumettes de chacun des $3$ triangles.

[IMAGE_2]
:::

::: etape Généraliser à l'étape $n$
À l'étape $n$, il y a $n$ triangles, donc $1 + 2 \times n$ allumettes. Avec les conventions d'écriture : $N = 2n + 1$.
:::

::: etape Vérifier sur le tableau
$2 \times 1 + 1 = 3$ ; $2 \times 2 + 1 = 5$ ; $2 \times 3 + 1 = 7$ : la formule redonne bien les valeurs comptées.
:::

::: resultat
$N = 2n + 1$.
:::

## Question 4 : Les étapes $10$ et $50$

::: methode
Remplacer $n$ par le numéro de l'étape dans la formule.
:::

::: etape Calculer
- Étape $10$ : $2 \times 10 + 1 = 21$.
- Étape $50$ : $2 \times 50 + 1 = 101$.
:::

::: resultat
$21$ allumettes à l'étape $10$ et $101$ allumettes à l'étape $50$.
:::

## Question 5 : L'affirmation de Tom

::: methode
Calculer le nombre d'allumettes à l'étape $20$ et le comparer au double de celui de l'étape $10$.
:::

::: etape Comparer
- Étape $20$ : $2 \times 20 + 1 = 41$ allumettes.
- Double de l'étape $10$ : $2 \times 21 = 42$ allumettes.
:::

::: resultat
Tom a tort : il faut $41$ allumettes à l'étape $20$, et non $42$. La première allumette n'est posée qu'une fois.
:::

::: attention Erreur fréquente
Confondre le numéro de l'étape ($n$) et le nombre d'allumettes ($N$). Doubler l'étape double le nombre de triangles, mais pas la première allumette.
:::

Solution:
<!-- optitab:1 -->
1. $3$, $5$ et $7$ allumettes ; on en ajoute $2$ à chaque étape.
2. $3$ ; $5$ ; $7$ ; $9$ ; $11$.
3. $N = 2n + 1$.
4. $21$ allumettes à l'étape $10$ ; $101$ à l'étape $50$.
5. Non : $41$ allumettes à l'étape $20$, et non $2 \times 21 = 42$.

=== Entraînement - Formules de périmètre et d'aire
Id: 2856
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Les côtés de même longueur sont codés de la même façon.

[IMAGE_1]

1. Écrire une formule du périmètre $P$ de chacune des quatre figures.
2. Écrire une formule de l'aire $A$ du carré et du rectangle.
3. Calculer les périmètres des quatre figures et les aires du carré et du rectangle avec $c = 6$ cm, $L = 8{,}5$ cm, $\ell = 4$ cm, $a = 7$ cm et $b = 3{,}5$ cm.
4. Un carré de $4$ cm de côté a un périmètre de $16$ cm et une aire de $16$ cm$^2$.
   - a) Tester l'égalité $4c = c^2$ pour $c = 4$, puis pour $c = 6$.
   - b) Peut-on additionner le périmètre et l'aire d'une figure ? Expliquer.

Étapes:
<!-- optitab:1 -->
## Question 1 : Formules des périmètres

::: methode
Le périmètre est la longueur du tour de la figure : on additionne les longueurs de tous les côtés, puis on regroupe les côtés égaux.
:::

::: etape Compter les côtés
- Carré : $4$ côtés de longueur $c$, donc $P = c + c + c + c = 4 \times c$.
- Rectangle : $2$ longueurs $L$ et $2$ largeurs $\ell$, donc $P = 2 \times L + 2 \times \ell$.
- Triangle équilatéral : $3$ côtés de longueur $a$, donc $P = 3 \times a$.
- Hexagone régulier : $6$ côtés de longueur $b$, donc $P = 6 \times b$.
:::

[IMAGE_2]

::: resultat
Carré : $P = 4c$ ; rectangle : $P = 2L + 2\ell$ ; triangle équilatéral : $P = 3a$ ; hexagone régulier : $P = 6b$.
:::

## Question 2 : Formules des aires

::: methode
L'aire d'un rectangle est le produit de sa longueur par sa largeur ; un carré est un rectangle dont la longueur et la largeur valent $c$.
:::

::: etape Écrire les produits
- Rectangle : $A = L \times \ell = L\ell$.
- Carré : $A = c \times c = c^2$.
:::

::: resultat
Carré : $A = c^2$ ; rectangle : $A = L\ell$.
:::

## Question 3 : Calculer avec les mesures données

::: methode
Remplacer chaque lettre par sa valeur, rétablir les signes $\times$ et respecter les priorités.
:::

::: etape Le carré ($c = 6$ cm)
$$
\begin{aligned}
P &= 4 \times 6 = 24 \text{ cm} \\
A &= 6^2 = 6 \times 6 = 36 \text{ cm}^2
\end{aligned}
$$
:::

::: etape Le rectangle ($L = 8{,}5$ cm et $\ell = 4$ cm)
$$
\begin{aligned}
P &= 2 \times 8{,}5 + 2 \times 4 = 17 + 8 = 25 \text{ cm} \\
A &= 8{,}5 \times 4 = 34 \text{ cm}^2
\end{aligned}
$$
:::

::: etape Le triangle ($a = 7$ cm) et l'hexagone ($b = 3{,}5$ cm)
- Triangle : $P = 3 \times 7 = 21$ cm.
- Hexagone : $P = 6 \times 3{,}5 = 21$ cm.
:::

::: resultat
Carré : $P = 24$ cm et $A = 36$ cm$^2$. Rectangle : $P = 25$ cm et $A = 34$ cm$^2$. Triangle : $P = 21$ cm. Hexagone : $P = 21$ cm.
:::

## Question 4 : Périmètre et aire du carré

::: methode
a) Calculer séparément les deux membres de l'égalité pour chaque valeur. b) Regarder les unités.
:::

::: etape Tester l'égalité $4c = c^2$
- Pour $c = 4$ : $4 \times 4 = 16$ et $4^2 = 16$. Les deux membres sont égaux : l'égalité est **vraie**.
- Pour $c = 6$ : $4 \times 6 = 24$ et $6^2 = 36$. Comme $24 \neq 36$, l'égalité est **fausse**.
:::

::: etape Comparer les unités
Le périmètre est une **longueur** (en cm) ; l'aire est une **surface** (en cm$^2$). Ce sont deux grandeurs de natures différentes.
:::

::: resultat
a) Vraie pour $c = 4$ ($16 = 16$) ; fausse pour $c = 6$ ($24 \neq 36$). b) Non : on n'additionne pas des centimètres et des centimètres carrés, ce ne sont pas des grandeurs de même nature.
:::

::: attention Erreur fréquente
Écrire $P = 4 + c$ pour le carré : on n'ajoute pas $4$, on prend **$4$ fois** la longueur du côté, $P = 4 \times c = 4c$.
:::

Solution:
<!-- optitab:1 -->
1. Carré : $P = 4c$ ; rectangle : $P = 2L + 2\ell$ ; triangle : $P = 3a$ ; hexagone : $P = 6b$.
2. Carré : $A = c^2$ ; rectangle : $A = L\ell$.
3. Carré : $24$ cm et $36$ cm$^2$ ; rectangle : $25$ cm et $34$ cm$^2$ ; triangle : $21$ cm ; hexagone : $21$ cm.
4. a) Vraie pour $c = 4$, fausse pour $c = 6$. b) Non : une longueur et une aire ne s'additionnent pas.

=== Entraînement - Traduire un programme de calcul
Id: 2853
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Voici deux programmes de calcul.

[IMAGE_1]

1. Appliquer chaque programme au nombre $5$.
2. Appliquer chaque programme au nombre $2{,}5$.
3. On choisit un nombre $x$. Écrire, en fonction de $x$, le résultat de chaque programme.
4. Écrire un programme de calcul en deux étapes qui donne l'expression $5x - 2$, puis un autre qui donne $5(x - 2)$.
5. Programme C : « Choisir un nombre ; le multiplier par lui-même ; ajouter $6$. » Écrire l'expression obtenue avec le nombre $x$, puis calculer le résultat pour $x = 1{,}5$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Avec le nombre $5$

::: methode
Effectuer les étapes dans l'ordre, en partant du nombre choisi.
:::

::: etape Programme A
$5 \times 4 = 20$, puis $20 + 3 = 23$.
:::

::: etape Programme B
$5 + 3 = 8$, puis $8 \times 4 = 32$.
:::

::: resultat
Programme A : $23$ ; programme B : $32$.
:::

## Question 2 : Avec le nombre $2{,}5$

::: methode
Même méthode avec un nombre décimal.
:::

::: etape Calculer
- Programme A : $2{,}5 \times 4 = 10$, puis $10 + 3 = 13$.
- Programme B : $2{,}5 + 3 = 5{,}5$, puis $5{,}5 \times 4 = 22$.
:::

::: resultat
Programme A : $13$ ; programme B : $22$.
:::

## Question 3 : Avec le nombre $x$

::: methode
Écrire l'expression étape par étape. Quand on multiplie une somme, on la met entre parenthèses.
:::

::: etape Programme A
On multiplie $x$ par $4$ : $4x$. On ajoute $3$ : $4x + 3$.

[IMAGE_2]
:::

::: etape Programme B
On ajoute $3$ à $x$ : $x + 3$. On multiplie **toute** cette somme par $4$ : $(x + 3) \times 4$, soit $4(x + 3)$.

[IMAGE_3]
:::

::: etape Vérifier avec la question 1
Pour $x = 5$ : $4 \times 5 + 3 = 23$ et $4 \times (5 + 3) = 4 \times 8 = 32$ : on retrouve les résultats de la question 1.
:::

::: resultat
Programme A : $4x + 3$. Programme B : $4(x + 3)$.
:::

## Question 4 : Du calcul au programme

::: methode
Repérer l'ordre des calculs dans l'expression : la multiplication passe avant la soustraction, sauf si des parenthèses imposent de soustraire d'abord.
:::

::: etape L'expression $5x - 2$
On calcule d'abord $5x$, puis on soustrait $2$ : « Choisir un nombre ; multiplier par $5$ ; soustraire $2$. »
:::

::: etape L'expression $5(x - 2)$
On calcule d'abord la parenthèse $x - 2$, puis on multiplie par $5$ : « Choisir un nombre ; soustraire $2$ ; multiplier par $5$. »
:::

::: resultat
$5x - 2$ : multiplier par $5$, puis soustraire $2$. $5(x - 2)$ : soustraire $2$, puis multiplier par $5$.
:::

## Question 5 : Le programme C

::: methode
« Multiplier un nombre par lui-même », c'est calculer son carré.
:::

::: etape Écrire l'expression
$x \times x = x^2$, puis on ajoute $6$ : $x^2 + 6$.
:::

::: etape Calculer pour $x = 1{,}5$
$$1{,}5^2 + 6 = 1{,}5 \times 1{,}5 + 6 = 2{,}25 + 6 = 8{,}25$$
:::

::: resultat
Le programme C donne $x^2 + 6$ ; pour $x = 1{,}5$, le résultat est $8{,}25$.
:::

::: attention Erreur fréquente
Traduire le programme B par $x + 3 \times 4$ : avec les priorités, seul $3$ serait multiplié par $4$. Pour $x = 5$, on trouverait $17$ au lieu de $32$. La parenthèse $(x + 3)$ est indispensable.
:::

Solution:
<!-- optitab:1 -->
1. A : $23$ ; B : $32$.
2. A : $13$ ; B : $22$.
3. A : $4x + 3$ ; B : $4(x + 3)$.
4. $5x - 2$ : multiplier par $5$, puis soustraire $2$. $5(x - 2)$ : soustraire $2$, puis multiplier par $5$.
5. $x^2 + 6$ ; pour $x = 1{,}5$ : $8{,}25$.

=== Entraînement - Des formules dans un tableur
Id: 2859
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Nina veut calculer les expressions $3x + 4$ et $x^2$ pour plusieurs valeurs de $x$. Elle prépare cette feuille de tableur : les valeurs de $x$ sont dans la colonne A.

[IMAGE_1]

1. Quelle formule Nina doit-elle écrire dans la cellule B2 pour calculer $3x + 4$ ?
2. Quelle formule peut-elle écrire dans la cellule C2 pour calculer $x^2$ ?
3. Nina recopie la formule de B2 vers le bas. Quelle formule obtient-elle dans la cellule B5 ?
4. Quels nombres s'affichent dans les colonnes B et C ?
5. Pour quelle valeur de $x$ du tableau l'égalité $3x + 4 = x^2$ est-elle vraie ?
6. Sami a tapé `=3A2+4` dans la cellule B2. Le tableur affiche une erreur. Pourquoi ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La formule de B2

::: methode
Une formule de tableur commence par $=$ ; la cellule A2 remplace la lettre $x$ ; le signe $\times$ s'écrit `*`.
:::

::: etape Traduire $3x + 4$
$3x + 4 = 3 \times x + 4$. En remplaçant $x$ par A2 et $\times$ par `*` : `=3*A2+4`.
:::

::: resultat
En B2 : `=3*A2+4`.
:::

## Question 2 : La formule de C2

::: methode
$x^2 = x \times x$.
:::

::: etape Traduire $x^2$
On multiplie A2 par lui-même : `=A2*A2`. On peut aussi écrire `=A2^2` (le symbole `^` sert à écrire une puissance).
:::

::: resultat
En C2 : `=A2*A2` (ou `=A2^2`).
:::

## Question 3 : Recopier vers le bas

::: methode
Quand on recopie une formule vers le bas, le numéro de ligne des cellules utilisées augmente de $1$ à chaque ligne.
:::

::: etape Suivre la recopie
B2 : `=3*A2+4` ; B3 : `=3*A3+4` ; B4 : `=3*A4+4` ; B5 : `=3*A5+4`.
:::

::: resultat
En B5 : `=3*A5+4`. Elle calcule $3x + 4$ avec la valeur de $x$ écrite en A5, c'est-à-dire $3$.
:::

## Question 4 : Les nombres affichés

::: methode
Pour chaque ligne, remplacer $x$ par la valeur de la colonne A.
:::

::: etape Calculer ligne par ligne
- $x = 0$ : $3 \times 0 + 4 = 4$ et $0^2 = 0$.
- $x = 1$ : $3 \times 1 + 4 = 7$ et $1^2 = 1$.
- $x = 2$ : $3 \times 2 + 4 = 10$ et $2^2 = 4$.
- $x = 3$ : $3 \times 3 + 4 = 13$ et $3^2 = 9$.
- $x = 4$ : $3 \times 4 + 4 = 16$ et $4^2 = 16$.
- $x = 5$ : $3 \times 5 + 4 = 19$ et $5^2 = 25$.
:::

[IMAGE_2]

::: resultat
Colonne B : $4$ ; $7$ ; $10$ ; $13$ ; $16$ ; $19$. Colonne C : $0$ ; $1$ ; $4$ ; $9$ ; $16$ ; $25$.
:::

## Question 5 : Tester l'égalité avec la feuille

::: methode
L'égalité est vraie pour une valeur de $x$ quand les colonnes B et C affichent le même nombre sur la même ligne.
:::

::: etape Lire la feuille
Seule la ligne 6 (surlignée en vert) affiche deux nombres égaux : pour $x = 4$, $3 \times 4 + 4 = 16$ et $4^2 = 16$.
:::

::: resultat
Parmi les valeurs du tableau, l'égalité $3x + 4 = x^2$ est vraie seulement pour $x = 4$.
:::

## Question 6 : L'erreur de Sami

::: methode
Dans un tableur, aucun signe $\times$ n'est sous-entendu.
:::

::: etape Repérer l'oubli
En mathématiques, on écrit $3x$ pour $3 \times x$. Mais le tableur ne comprend pas `3A2` : il faut écrire le signe `*`.
:::

::: resultat
Sami a oublié le signe `*` : la bonne formule est `=3*A2+4`.
:::

::: attention Erreur fréquente
Oublier le signe $=$ au début : le tableur affiche alors le texte `3*A2+4` sans faire le calcul.
:::

Solution:
<!-- optitab:1 -->
1. `=3*A2+4`.
2. `=A2*A2` (ou `=A2^2`).
3. `=3*A5+4`.
4. B : $4$ ; $7$ ; $10$ ; $13$ ; $16$ ; $19$. C : $0$ ; $1$ ; $4$ ; $9$ ; $16$ ; $25$.
5. Pour $x = 4$ ($16 = 16$).
6. Le signe `*` est obligatoire dans un tableur : `=3*A2+4`.

=== Problème - Comparer deux tarifs
Id: 2872
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
La piscine municipale propose deux tarifs.
- **Tarif Libre** : $5$ € l'entrée.
- **Tarif Carte** : une carte annuelle à $12$ €, puis $3$ € l'entrée.

1. Calculer le prix payé avec chaque tarif pour $4$ entrées.
2. On note $n$ le nombre d'entrées. Écrire une formule donnant le prix $L$ payé avec le tarif Libre, puis le prix $C$ payé avec le tarif Carte.
3. Recopier et compléter le tableau.

| Nombre d'entrées $n$ | $2$ | $4$ | $6$ | $8$ | $10$ |
|---|---|---|---|---|---|
| Prix $L$ (€) | | | | | |
| Prix $C$ (€) | | | | | |

4. Tester l'égalité $5n = 3n + 12$ pour $n = 6$. Que signifie le résultat pour la piscine ?
5. Emma affirme : « Le tarif Carte est toujours le plus avantageux. » A-t-elle raison ?
6. Emma prévoit d'aller $15$ fois à la piscine cette année. Quel tarif doit-elle choisir ? Combien économise-t-elle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le prix de $4$ entrées

::: methode
Tarif Libre : on paie seulement les entrées. Tarif Carte : on paie la carte, puis les entrées.
:::

::: etape Calculer
- Tarif Libre : $5 \times 4 = 20$ €.
- Tarif Carte : $12 + 3 \times 4 = 12 + 12 = 24$ €.
:::

::: resultat
Pour $4$ entrées : $20$ € avec le tarif Libre, $24$ € avec le tarif Carte.
:::

## Question 2 : Les formules

::: methode
Refaire le calcul de la question 1 en remplaçant $4$ par la lettre $n$.
:::

::: etape Tarif Libre
$n$ entrées à $5$ € : $L = 5 \times n = 5n$.
:::

::: etape Tarif Carte
La carte ($12$ €), puis $n$ entrées à $3$ € : $C = 12 + 3 \times n = 12 + 3n$, que l'on écrit aussi $C = 3n + 12$.
:::

::: resultat
$L = 5n$ et $C = 3n + 12$ (en euros).
:::

## Question 3 : Le tableau des prix

::: methode
Remplacer $n$ par chaque valeur dans les deux formules.
:::

::: etape Calculer les prix
- $L$ : $5 \times 2 = 10$ ; $5 \times 4 = 20$ ; $5 \times 6 = 30$ ; $5 \times 8 = 40$ ; $5 \times 10 = 50$.
- $C$ : $3 \times 2 + 12 = 18$ ; $3 \times 4 + 12 = 24$ ; $3 \times 6 + 12 = 30$ ; $3 \times 8 + 12 = 36$ ; $3 \times 10 + 12 = 42$.
:::

::: resultat
| Nombre d'entrées $n$ | $2$ | $4$ | $6$ | $8$ | $10$ |
|---|---|---|---|---|---|
| Prix $L$ (€) | $10$ | $20$ | $30$ | $40$ | $50$ |
| Prix $C$ (€) | $18$ | $24$ | $30$ | $36$ | $42$ |
:::

## Question 4 : Tester l'égalité pour $n = 6$

::: methode
Calculer séparément les deux membres pour $n = 6$.
:::

::: etape Calculer
- Membre de gauche : $5 \times 6 = 30$.
- Membre de droite : $3 \times 6 + 12 = 18 + 12 = 30$.
:::

::: etape Interpréter
$5n$ est le prix avec le tarif Libre et $3n + 12$ le prix avec le tarif Carte : les deux tarifs coûtent la même chose pour $6$ entrées.
:::

::: resultat
L'égalité est vraie pour $n = 6$ : pour $6$ entrées, les deux tarifs coûtent $30$ €.
:::

## Question 5 : L'affirmation d'Emma

::: methode
Chercher dans le tableau un nombre d'entrées pour lequel le tarif Carte n'est pas le moins cher : ce serait un contre-exemple.
:::

::: etape Trouver un contre-exemple
Pour $2$ entrées : tarif Libre $10$ €, tarif Carte $18$ €. Le tarif Carte est plus cher.
:::

::: resultat
Emma a tort : pour $2$ entrées, le tarif Libre ($10$ €) est moins cher que le tarif Carte ($18$ €). D'après le tableau, la carte devient avantageuse au-delà de $6$ entrées.
:::

## Question 6 : $15$ entrées

::: methode
Calculer les deux prix pour $n = 15$, puis leur différence.
:::

::: etape Calculer les deux prix
$$
\begin{aligned}
L &= 5 \times 15 = 75 \text{ €} \\
C &= 3 \times 15 + 12 = 45 + 12 = 57 \text{ €}
\end{aligned}
$$
:::

::: etape L'économie
$75 - 57 = 18$ €.
:::

::: resultat
Emma doit choisir le tarif Carte : elle paie $57$ € au lieu de $75$ €, et économise $18$ €.
:::

::: attention Erreur fréquente
Oublier le prix de la carte et écrire $C = 3n$ : les $12$ € se paient une seule fois, quel que soit le nombre d'entrées, mais ils se paient toujours.
:::

Solution:
<!-- optitab:1 -->
1. Libre : $20$ € ; Carte : $24$ €.
2. $L = 5n$ et $C = 3n + 12$.
3. $L$ : $10$ ; $20$ ; $30$ ; $40$ ; $50$. $C$ : $18$ ; $24$ ; $30$ ; $36$ ; $42$.
4. Vraie ($30 = 30$) : pour $6$ entrées, les deux tarifs coûtent $30$ €.
5. Non : pour $2$ entrées, Libre coûte $10$ € et Carte $18$ €.
6. Le tarif Carte : $57$ € au lieu de $75$ €, soit $18$ € d'économie.

=== Problème - Une bordure de carreaux
Id: 2866
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un carreleur entoure un carré de carreaux blancs par une bordure de carreaux gris. À l'étape $n$, le carré blanc a $n$ carreaux de côté.

[IMAGE_1]

1. Compter les carreaux gris aux étapes $1$, $2$ et $3$.
2. À l'étape $n$, chaque côté du carré blanc est bordé par $n$ carreaux gris, et il y a en plus un carreau gris dans chaque coin. En déduire une formule donnant le nombre $G$ de carreaux gris à l'étape $n$.
3. Vérifier la formule pour les étapes $1$, $2$ et $3$.
4. Combien de carreaux gris faut-il à l'étape $10$ ? à l'étape $25$ ?
5. Le carreleur a exactement $64$ carreaux gris. À quelle étape les utilise-t-il tous ?
6. Peut-on construire une bordure qui utilise exactement $50$ carreaux gris ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Compter les premières étapes

::: methode
Compter les carreaux gris de chaque bordure, en n'oubliant pas les coins.
:::

::: etape Compter
- Étape $1$ : $3$ carreaux en haut, $3$ en bas, $1$ à gauche et $1$ à droite, soit $8$.
- Étape $2$ : $4 + 4 + 2 + 2 = 12$.
- Étape $3$ : $5 + 5 + 3 + 3 = 16$.
:::

::: resultat
$8$, $12$ et $16$ carreaux gris.
:::

## Question 2 : La formule

::: methode
Découper la bordure en parties faciles à compter : les $4$ côtés (en vert) et les $4$ coins (en orange).
:::

::: etape Découper l'étape 3
[IMAGE_2]
:::

::: etape Généraliser à l'étape $n$
- Les $4$ côtés : $4$ fois $n$ carreaux, soit $4 \times n$.
- Les $4$ coins : $4$ carreaux.

Donc $G = 4 \times n + 4 = 4n + 4$.
:::

::: resultat
$G = 4n + 4$.
:::

## Question 3 : Vérifier la formule

::: methode
Remplacer $n$ par $1$, $2$ et $3$ et comparer avec les comptages de la question 1.
:::

::: etape Calculer
$$
\begin{aligned}
4 \times 1 + 4 &= 8 \\
4 \times 2 + 4 &= 12 \\
4 \times 3 + 4 &= 16
\end{aligned}
$$
:::

::: resultat
La formule redonne $8$, $12$ et $16$ : elle est cohérente avec les dessins.
:::

## Question 4 : Les étapes $10$ et $25$

::: methode
Remplacer $n$ par le numéro de l'étape.
:::

::: etape Calculer
- Étape $10$ : $4 \times 10 + 4 = 40 + 4 = 44$.
- Étape $25$ : $4 \times 25 + 4 = 100 + 4 = 104$.
:::

::: resultat
$44$ carreaux gris à l'étape $10$ et $104$ à l'étape $25$.
:::

## Question 5 : Utiliser $64$ carreaux

::: methode
Remonter le calcul : on retire les $4$ coins, puis on partage le reste entre les $4$ côtés.
:::

::: etape Remonter le calcul
- Sans les coins : $64 - 4 = 60$ carreaux pour les $4$ côtés.
- Sur chaque côté : $60 \div 4 = 15$ carreaux, donc $n = 15$.
:::

::: etape Vérifier
$4 \times 15 + 4 = 60 + 4 = 64$.
:::

::: resultat
Les $64$ carreaux gris forment la bordure de l'étape $15$.
:::

## Question 6 : Exactement $50$ carreaux ?

::: methode
Remonter le calcul comme à la question 5 : le nombre de carreaux par côté doit être un nombre entier.
:::

::: etape Remonter le calcul
Sans les coins : $50 - 4 = 46$. Mais $46$ n'est pas divisible par $4$ ($4 \times 11 = 44$ et $4 \times 12 = 48$) : on ne peut pas répartir $46$ carreaux sur $4$ côtés égaux.
:::

::: etape Contrôler avec la formule
Étape $11$ : $4 \times 11 + 4 = 48$ ; étape $12$ : $4 \times 12 + 4 = 52$. On passe de $48$ à $52$ sans obtenir $50$.
:::

::: resultat
Non : aucune étape n'utilise exactement $50$ carreaux gris ($48$ à l'étape $11$, $52$ à l'étape $12$).
:::

::: attention Erreur fréquente
Compter $4$ côtés de $n + 2$ carreaux, soit $4(n + 2)$ : chaque coin serait alors compté deux fois. Pour l'étape $3$, on trouverait $20$ au lieu de $16$. Il faut toujours vérifier une formule sur un dessin.
:::

Solution:
<!-- optitab:1 -->
1. $8$, $12$ et $16$ carreaux gris.
2. $G = 4n + 4$.
3. $4 \times 1 + 4 = 8$ ; $4 \times 2 + 4 = 12$ ; $4 \times 3 + 4 = 16$.
4. $44$ à l'étape $10$ ; $104$ à l'étape $25$.
5. À l'étape $15$.
6. Non : $50 - 4 = 46$ n'est pas divisible par $4$ ($48$ à l'étape $11$, $52$ à l'étape $12$).

=== Synthèse - Les tables de la cantine
Id: 2867
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour un repas de fête, on place des tables carrées côte à côte, en une seule rangée. On met une chaise de chaque côté libre d'une table.

[IMAGE_1]

**Partie A : le motif**

1. Combien faut-il de chaises pour $1$, $2$, $3$ et $4$ tables ?
2. Écrire une formule donnant le nombre $C$ de chaises pour $n$ tables. Expliquer la formule à l'aide du dessin.

**Partie B : le programme du cuisinier**

Le cuisinier calcule le nombre de chaises avec ce programme.

[IMAGE_2]

3. Traduire ce programme par une expression en fonction de $n$.
4. Appliquer le programme pour $3$ tables. Le programme du cuisinier est-il correct ?

**Partie C : le tableur et la grande fête**

5. Dans une feuille de tableur, le nombre de tables est écrit en A2. Quelle formule écrire en B2 pour calculer le nombre de chaises ?
6. Pour la grande fête, on aligne $30$ tables. Combien faut-il de chaises ?
7. On dispose de $50$ chaises. Combien faut-il aligner de tables pour qu'aucune chaise ne manque et qu'aucune ne reste ?

Étapes:
<!-- optitab:1 -->
## Partie A : le motif

## Question 1 : Compter les chaises

::: methode
Compter sur le dessin, puis repérer ce qui s'ajoute avec une table de plus.
:::

::: etape Compter
$1$ table : $4$ chaises. $2$ tables : $6$ chaises. $3$ tables : $8$ chaises. Chaque table ajoutée apporte $2$ chaises (une en haut, une en bas) : pour $4$ tables, $8 + 2 = 10$ chaises.
:::

::: resultat
$4$, $6$, $8$ et $10$ chaises.
:::

## Question 2 : La formule

::: methode
Découper le motif : les chaises le long des tables (en vert) et les chaises des deux bouts (en orange).
:::

::: etape Découper le motif pour $3$ tables
[IMAGE_3]
:::

::: etape Généraliser à $n$ tables
- En haut : $n$ chaises ; en bas : $n$ chaises ; soit $2 \times n$ chaises.
- Aux deux bouts : $2$ chaises.

Donc $C = 2 \times n + 2 = 2n + 2$. Vérification : $2 \times 1 + 2 = 4$ ; $2 \times 2 + 2 = 6$ ; $2 \times 3 + 2 = 8$.
:::

::: resultat
$C = 2n + 2$ : deux chaises par table (en haut et en bas), plus une chaise à chaque bout.
:::

## Partie B : le programme du cuisinier

## Question 3 : Traduire le programme

::: methode
Écrire l'expression étape par étape ; quand on multiplie une somme, on la met entre parenthèses.
:::

::: etape Étape par étape
On part de $n$, on ajoute $2$ : $n + 2$. On multiplie cette somme par $2$ : $(n + 2) \times 2 = 2(n + 2)$.

[IMAGE_4]
:::

::: resultat
Le programme du cuisinier donne $2(n + 2)$.
:::

## Question 4 : Le programme est-il correct ?

::: methode
Tester le programme pour $3$ tables et comparer avec le nombre de chaises compté sur le dessin.
:::

::: etape Tester pour $n = 3$
$3 + 2 = 5$, puis $5 \times 2 = 10$. Or il faut $8$ chaises pour $3$ tables.
:::

::: resultat
Le programme du cuisinier n'est pas correct : pour $3$ tables, il donne $10$ chaises au lieu de $8$. Un seul contre-exemple suffit.
:::

## Partie C : le tableur et la grande fête

## Question 5 : La formule du tableur

::: methode
Traduire $C = 2n + 2$ en remplaçant $n$ par A2 et le signe $\times$ par `*`, sans oublier le signe $=$.
:::

::: etape Écrire la formule
$2n + 2 = 2 \times n + 2$ devient `=2*A2+2`.
:::

::: resultat
En B2 : `=2*A2+2`.
:::

## Question 6 : $30$ tables

::: methode
Remplacer $n$ par $30$ dans la formule.
:::

::: etape Calculer
$C = 2 \times 30 + 2 = 60 + 2 = 62$.
:::

::: resultat
Pour $30$ tables, il faut $62$ chaises.
:::

## Question 7 : Exactement $50$ chaises

::: methode
Remonter le calcul : retirer les $2$ chaises des bouts, puis partager le reste entre le haut et le bas.
:::

::: etape Remonter le calcul
- Sans les bouts : $50 - 2 = 48$ chaises le long des tables.
- Il y a $2$ chaises par table : $48 \div 2 = 24$ tables.
:::

::: etape Vérifier
$2 \times 24 + 2 = 48 + 2 = 50$.
:::

::: resultat
Il faut aligner $24$ tables.
:::

::: attention Erreur fréquente
Penser qu'une table compte toujours $4$ chaises et écrire $C = 4n$ : quand deux tables sont collées, les côtés accolés n'ont pas de chaise. Pour $3$ tables, $4 \times 3 = 12$ est faux : il en faut $8$.
:::

Solution:
<!-- optitab:1 -->
1. $4$, $6$, $8$ et $10$ chaises.
2. $C = 2n + 2$ : $n$ chaises en haut, $n$ en bas, et $2$ aux bouts.
3. $2(n + 2)$.
4. Non : pour $3$ tables, le programme donne $10$ au lieu de $8$.
5. `=2*A2+2`.
6. $62$ chaises.
7. $24$ tables.

=== Synthèse - Le potager de Léo
Id: 2868
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Léo veut aménager un potager rectangulaire. Sa largeur mesure $x$ mètres et sa longueur mesure $5$ mètres de plus que sa largeur. Il entourera le potager d'un grillage.

[IMAGE_1]

1. Écrire une formule donnant la longueur du grillage, c'est-à-dire le périmètre $P$ du potager, en fonction de $x$.
2. Écrire une formule donnant l'aire $A$ du potager en fonction de $x$.
3. Calculer $P$ et $A$ pour $x = 4$.
4. Léo utilise un tableur. La formule de la cellule B2 est donnée.
   - a) Quelle formule écrire dans la cellule C2 pour calculer l'aire ?
   - b) Quels nombres s'affichent dans les colonnes B et C ?

[IMAGE_2]

5. Léo a acheté $34$ mètres de grillage. Pour quelle valeur de $x$ du tableau utilise-t-il tout le grillage ? Tester l'égalité $2x + 2(x + 5) = 34$ pour cette valeur.
6. Sa sœur affirme : « Pour $x = 5$, l'aire en m$^2$ et le périmètre en m sont égaux. » Tester cette affirmation.

Étapes:
<!-- optitab:1 -->
## Question 1 : La formule du périmètre

::: methode
Un rectangle a deux longueurs et deux largeurs : $P = 2 \times \text{longueur} + 2 \times \text{largeur}$.
:::

::: etape Remplacer par les expressions
La largeur est $x$ et la longueur est $x + 5$ (on la met entre parenthèses pour la multiplier) :
$$
\begin{aligned}
P &= 2 \times x + 2 \times (x + 5) \\
&= 2x + 2(x + 5)
\end{aligned}
$$
:::

::: resultat
$P = 2x + 2(x + 5)$, en mètres.
:::

## Question 2 : La formule de l'aire

::: methode
Aire d'un rectangle : longueur $\times$ largeur.
:::

::: etape Écrire le produit
$A = (x + 5) \times x$, que l'on écrit $A = x(x + 5)$.
:::

::: resultat
$A = x(x + 5)$, en m$^2$.
:::

## Question 3 : Pour $x = 4$

::: methode
Remplacer $x$ par $4$ dans les deux formules, en commençant par les parenthèses.
:::

::: etape Calculer
La longueur vaut $4 + 5 = 9$ m.
$$
\begin{aligned}
P &= 2 \times 4 + 2 \times (4 + 5) \\
&= 8 + 18 \\
&= 26 \text{ m}
\end{aligned}
$$
$$
\begin{aligned}
A &= 4 \times (4 + 5) \\
&= 4 \times 9 \\
&= 36 \text{ m}^2
\end{aligned}
$$

[IMAGE_3]
:::

::: resultat
Pour $x = 4$ : $P = 26$ m et $A = 36$ m$^2$.
:::

## Question 4 : Le tableur

::: methode
Traduire $x(x + 5)$ en remplaçant $x$ par A2, puis calculer chaque ligne.
:::

::: etape a) La formule de C2
$x(x + 5) = x \times (x + 5)$ devient `=A2*(A2+5)`.
:::

::: etape b) Les nombres affichés
- $x = 3$ : $P = 6 + 16 = 22$ ; $A = 3 \times 8 = 24$.

## Question 5 : $34$ mètres de grillage

::: methode
Chercher $34$ dans la colonne B, puis tester l'égalité en calculant son membre de gauche.
:::

::: etape Lire la feuille
Le périmètre vaut $34$ m sur la ligne de $x = 6$.
:::

::: etape Tester l'égalité pour $x = 6$
$$2 \times 6 + 2 \times (6 + 5) = 12 + 22 = 34$$
Le membre de gauche vaut $34$, comme le membre de droite : l'égalité est vraie pour $x = 6$.
:::

::: resultat
Pour $x = 6$ : le potager mesure $6$ m sur $11$ m et utilise exactement les $34$ m de grillage.
:::

## Question 6 : L'affirmation de la sœur

::: methode
Calculer l'aire et le périmètre pour $x = 5$, puis comparer les nombres.
:::

::: etape Calculer pour $x = 5$
$P = 2 \times 5 + 2 \times (5 + 5) = 10 + 20 = 30$ m et $A = 5 \times (5 + 5) = 5 \times 10 = 50$ m$^2$.
:::

::: resultat
L'affirmation est fausse : pour $x = 5$, l'aire vaut $50$ m$^2$ et le périmètre $30$ m ; $50 \neq 30$.
:::

::: attention Erreur fréquente
Écrire $2 \times x + 5$ pour « le double de la longueur » : c'est toute la longueur $x + 5$ qu'il faut doubler, d'où les parenthèses $2(x + 5)$. Pour $x = 4$, on trouverait $13$ au lieu de $18$.
:::

Solution:
<!-- optitab:1 -->
1. $P = 2x + 2(x + 5)$.
2. $A = x(x + 5)$.
3. $P = 26$ m et $A = 36$ m$^2$.
4. a) `=A2*(A2+5)`. b) B : $22$ ; $26$ ; $30$ ; $34$. C : $24$ ; $36$ ; $50$ ; $66$.
5. $x = 6$ : $2 \times 6 + 2 \times 11 = 34$, l'égalité est vraie.
6. Fausse : $A = 50$ m$^2$ et $P = 30$ m.
