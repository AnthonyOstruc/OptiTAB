Énoncé:

Observe les formes A,B,C,D.

[IMAGE_1]

1. Comment s’appelle A ?
2. Comment s’appelle B ?
3. Comment s’appelle C ?
4. Comment s’appelle D ?
5. Tourner A lui ferait-il perdre son nom ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comment s’appelle A ?

::: methode
Observe ses quatre côtés égaux et ses coins droits.
:::

::: etape Raisonner
La figure est tournée, mais garde les propriétés du carré.
:::

::: resultat
Un carré.
:::

## Question 2 : Comment s’appelle B ?

::: methode
Compte les côtés.
:::

::: etape Raisonner
B a trois côtés et trois sommets.
:::

::: resultat
Un triangle.
:::

## Question 3 : Comment s’appelle C ?

::: methode
Observe la forme plate et ronde.
:::

::: etape Raisonner
Le dessin représente une surface ronde, sans côté droit.
:::

::: resultat
Un disque.
:::

## Question 4 : Comment s’appelle D ?

::: methode
Observe ses quatre coins droits.
:::

::: etape Raisonner
Deux côtés voisins sont de longueurs différentes.
:::

::: resultat
Un rectangle.
:::

## Question 5 : Tourner A lui ferait-il perdre son nom ?

::: methode
Tourner ne change ni les côtés ni les coins.
:::

::: etape Raisonner
Les propriétés du carré restent les mêmes.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Non, un carré tourné reste un carré.
:::

Solution:
<!-- optitab:1 -->
1. Un carré.
2. Un triangle.
3. Un disque.
4. Un rectangle.
5. Non, un carré tourné reste un carré.

[IMAGE_1]

1. Quel outil utilises-tu ?
2. Où places-tu le bord de la règle ?
3. Comment tiens-tu la règle pendant le tracé ?
4. Quel trait traces-tu ?
5. Comment vérifies-tu ?

<!-- optitab:1 -->

## Question 1 : Quel outil utilises-tu ?

::: methode

:::

:::

:::

::: etape Raisonner
Place le bord contre A et B.
:::

::: resultat
Sur A et B.

::: methode

:::

::: etape Raisonner

:::

::: resultat
Sans la déplacer.

## Question 4 : Quel trait traces-tu ?

::: methode

::: etape Raisonner

[IMAGE_2]
