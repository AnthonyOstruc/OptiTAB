<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6; font-size:1em;">

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce qu'un nombre décimal ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Nombre décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>nombre décimal</strong> est un nombre qui peut s'écrire avec une <strong>virgule</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il est composé de deux parties :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">La <strong>partie entière</strong> (avant la virgule)</li>
                <li style="margin:0; text-align:left;">La <strong>partie décimale</strong> (après la virgule)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> : partie entière = <strong>12</strong>, partie décimale = <strong>34</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5,7</strong> : partie entière = <strong>5</strong>, partie décimale = <strong>7</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,25</strong> : partie entière = <strong>0</strong>, partie décimale = <strong>25</strong></li>
                <li style="margin:0; text-align:left;"><strong>125,008</strong> : partie entière = <strong>125</strong>, partie décimale = <strong>008</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Remarque importante :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un nombre entier peut aussi être considéré comme un nombre décimal. Par exemple, <strong>5</strong> peut s'écrire <strong>5,0</strong> ou <strong>5,00</strong>.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Les chiffres dans un nombre décimal</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Les ordres dans un nombre décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un nombre décimal, chaque chiffre a une position précise :</p>
            
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Position</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Valeur</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Exemple dans 12,34</th>
                    </tr>
                </thead>

                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Dizaines</td>

                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">Le chiffre <strong>1</strong></td>
                    </tr>
                    <tr style="background:#ffffff;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Unités</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:center;">1</td>

                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700;">Dixièmes</td>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Analyser le nombre 12,34</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Le chiffre <strong>1</strong> est le chiffre des <strong>dizaines</strong> (1 dizaine = 10)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le chiffre <strong>2</strong> est le chiffre des <strong>unités</strong> (2 unités = 2)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le chiffre <strong>3</strong> est le chiffre des <strong>dixièmes</strong> (3 dixièmes = 0,3)</li>
                <li style="margin:0; text-align:left;">Le chiffre <strong>4</strong> est le chiffre des <strong>centièmes</strong> (4 centièmes = 0,04)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Écrire et lire les nombres décimaux</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Écriture à virgule</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règle d'écriture</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour écrire un nombre décimal, on utilise une <strong>virgule</strong> pour séparer la partie entière de la partie décimale.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En France, on utilise la <strong>virgule</strong> (pas le point) comme séparateur décimal.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> : douze virgule trente-quatre</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5,7</strong> : cinq virgule sept</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,25</strong> : zéro virgule vingt-cinq</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125,008</strong> : cent vingt-cinq virgule zéro zéro huit</li>
                <li style="margin:0; text-align:left;"><strong>3,05</strong> : trois virgule zéro cinq</li>
            </ul>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On utilise une <strong>virgule</strong> (pas un point) en France</li>
                <li style="margin:0 0 12px 0; text-align:left;">On ne met <strong>pas d'espace</strong> autour de la virgule</li>
                <li style="margin:0; text-align:left;">Exemple : <strong>12,34</strong> (correct) et non <strong>12 , 34</strong> (incorrect)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Lien avec les fractions décimales</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Fractions décimales</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un nombre décimal peut s'écrire sous forme de <strong>fraction décimale</strong> (fraction dont le dénominateur est 10, 100, 1 000...).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,1</strong> = <strong>1/10</strong> (un dixième)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,01</strong> = <strong>1/100</strong> (un centième)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,3</strong> = <strong>3/10</strong> (trois dixièmes)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,25</strong> = <strong>25/100</strong> (vingt-cinq centièmes)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5,7</strong> = <strong>57/10</strong> (cinq unités et sept dixièmes)</li>
                <li style="margin:0; text-align:left;"><strong>12,34</strong> = <strong>1234/100</strong> (douze unités et trente-quatre centièmes)</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour écrire un nombre décimal sous forme de fraction décimale :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Compter le nombre de chiffres après la virgule</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le dénominateur est 10, 100, 1 000... selon le nombre de chiffres</li>
                <li style="margin:0; text-align:left;">Le numérateur est le nombre sans la virgule</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Exemple : <strong>12,34</strong> a 2 chiffres après la virgule, donc <strong>12,34 = 1234/100</strong></p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Décomposer un nombre décimal</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Décomposition additive</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Décomposition d'un nombre décimal</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Décomposer un nombre décimal, c'est l'écrire comme une <strong>somme</strong> de sa partie entière et de sa partie décimale.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de décomposition :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> = 12 + 0,3 + 0,04</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> = 10 + 2 + 0,3 + 0,04</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5,7</strong> = 5 + 0,7</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>0,25</strong> = 0 + 0,2 + 0,05</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125,008</strong> = 125 + 0,008</li>
                <li style="margin:0; text-align:left;"><strong>3,05</strong> = 3 + 0,05</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour décomposer un nombre décimal :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Séparer la partie entière et la partie décimale</li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposer la partie décimale en dixièmes, centièmes, millièmes...</li>
                <li style="margin:0; text-align:left;">Écrire la somme de toutes les parties</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Comparer et ranger des nombres décimaux</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Comparer deux nombres décimaux</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode de comparaison</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer deux nombres décimaux, on compare d'abord les <strong>parties entières</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si les parties entières sont égales, on compare les <strong>parties décimales</strong> chiffre par chiffre, en commençant par les dixièmes.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📐 Technique : Aligner les chiffres</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer facilement, on peut <strong>aligner les virgules</strong> et <strong>compléter avec des zéros</strong> si nécessaire.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>12,34</strong> et <strong>12,5</strong> :</li>
                <li style="margin:0 0 12px 0; text-align:left;">Parties entières égales (12 = 12), on compare les dixièmes : 3 < 5</li>
                <li style="margin:0 0 12px 0; text-align:left;">Donc <strong>12,34 < 12,5</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>5,7</strong> et <strong>5,70</strong> :</li>
                <li style="margin:0 0 12px 0; text-align:left;">On complète : <strong>5,70</strong> = <strong>5,7</strong>, donc <strong>5,7 = 5,70</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3,25</strong> et <strong>3,2</strong> :</li>
                <li style="margin:0 0 12px 0; text-align:left;">On complète : <strong>3,2</strong> = <strong>3,20</strong>, on compare : 20 < 25</li>
                <li style="margin:0; text-align:left;">Donc <strong>3,2 < 3,25</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce pratique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer <strong>12,34</strong> et <strong>12,5</strong>, on peut écrire :</p>
            <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:6px; padding:12px; margin:10px 0; text-align:center;">
                <p style="margin:0; font-size:1em;">12,34</p>
                <p style="margin:0; font-size:1em;">12,50</p>
                <p style="margin:0; font-size:1em; margin-top:8px;">On compare : 34 < 50, donc 12,34 < 12,5</p>
            </div>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Ranger une liste de nombres décimaux</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Ordre croissant et décroissant</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre croissant</strong> : du plus petit au plus grand (↗)</li>
                <li style="margin:0; text-align:left;"><strong>Ordre décroissant</strong> : du plus grand au plus petit (↘)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre croissant</strong> : 3,2 < 3,25 < 5,7 < 12,34</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre décroissant</strong> : 12,34 > 5,7 > 3,25 > 3,2</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ranger en ordre croissant : <strong>5,7</strong>, <strong>3,2</strong>, <strong>12,34</strong>, <strong>3,25</strong></li>
                <li style="margin:0; text-align:left;">Résultat : <strong>3,2</strong> < <strong>3,25</strong> < <strong>5,7</strong> < <strong>12,34</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Comparer d'abord les parties entières</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si les parties entières sont égales, comparer les parties décimales</li>
                <li style="margin:0; text-align:left;">Compléter avec des zéros si nécessaire pour faciliter la comparaison</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. La droite graduée avec des nombres décimaux</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Droite graduée avec graduations en 0,1 (dixièmes)</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Graduation de 0,1 en 0,1</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une droite graduée avec des graduations de <strong>0,1</strong> en <strong>0,1</strong>, chaque petite graduation représente <strong>0,1</strong> (un dixième).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres entiers sont marqués : 0, 1, 2, 3, 4, 5...</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Entre deux nombres entiers, il y a <strong>10</strong> graduations de 0,1.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Sur une droite de 0 à 5 (graduation de 0,1 en 0,1), on repère : 0, 0,1, 0,2, 0,3... 1, 1,1, 1,2... 2, 2,1...</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour placer <strong>2,5</strong> : on repère 2, puis on compte 5 graduations de 0,1</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour placer <strong>3,7</strong> : on repère 3, puis on compte 7 graduations de 0,1</li>
                <li style="margin:0; text-align:left;">Pour lire un point entre 2 et 3 : on compte les graduations depuis 2</li>
            </ul>
        </div>
        [IMAGE_1]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Droite graduée avec graduations en 0,01 (centièmes)</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Graduation de 0,01 en 0,01</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une droite graduée avec des graduations de <strong>0,01</strong> en <strong>0,01</strong>, chaque petite graduation représente <strong>0,01</strong> (un centième).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les nombres entiers et les dixièmes sont marqués : 0, 0,1, 0,2, 0,3... 1, 1,1, 1,2...</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Entre deux dixièmes, il y a <strong>10</strong> graduations de 0,01.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Sur une droite de 0 à 1 (graduation de 0,01 en 0,01), on repère : 0, 0,01, 0,02, 0,03... 0,1, 0,11, 0,12... 0,2...</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour placer <strong>0,25</strong> : on repère 0,2, puis on compte 5 graduations de 0,01</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour placer <strong>0,34</strong> : on repère 0,3, puis on compte 4 graduations de 0,01</li>
                <li style="margin:0; text-align:left;">Pour lire un point entre 0,2 et 0,3 : on compte les graduations depuis 0,2</li>
            </ul>
        </div>
        [IMAGE_2]
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Placer et lire un nombre décimal sur une droite graduée</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode pour placer</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer la partie entière sur la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Compter les graduations pour la partie décimale</li>
                <li style="margin:0 0 12px 0; text-align:left;">Placer le point à la bonne position</li>
            </ol>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode pour lire</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer le point marqué sur la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Lire la partie entière (le nombre entier juste avant)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Compter les graduations pour déterminer la partie décimale</li>
                <li style="margin:0; text-align:left;">Écrire le nombre décimal complet</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Placer 2,5</strong> sur une droite de 0 à 5 (graduation de 0,1) : on repère 2, puis on compte 5 graduations → 2,5</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Placer 0,25</strong> sur une droite de 0 à 1 (graduation de 0,01) : on repère 0,2, puis on compte 5 graduations → 0,25</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire un point</strong> : si un point est entre 2 et 3, à la 7ème graduation de 0,1, alors c'est <strong>2,7</strong></li>
                <li style="margin:0; text-align:left;"><strong>Lire un point</strong> : si un point est entre 0,2 et 0,3, à la 4ème graduation de 0,01, alors c'est <strong>0,24</strong></li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Applications pratiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples concrets</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Prix en euros</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un livre coûte <strong>12,99 €</strong>.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>douze euros et quatre-vingt-dix-neuf centimes</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 12 + 0,99 = 12 + 0,9 + 0,09</li>
                <li style="margin:0 0 12px 0; text-align:left;">En fraction décimale : <strong>12,99</strong> = <strong>1299/100</strong></li>
                <li style="margin:0; text-align:left;">Comparaison : <strong>12,99 €</strong> < <strong>13,00 €</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Longueur en mètres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une règle mesure <strong>0,30 m</strong> (30 centimètres).</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>zéro virgule trente mètres</strong> ou <strong>trente centimètres</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 0 + 0,3 = 0 + 0,30</li>
                <li style="margin:0 0 12px 0; text-align:left;">En fraction décimale : <strong>0,30</strong> = <strong>30/100</strong></li>
                <li style="margin:0; text-align:left;">Équivalence : <strong>0,30 m</strong> = <strong>30 cm</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Masse en kilogrammes</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un paquet pèse <strong>2,5 kg</strong>.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>deux virgule cinq kilogrammes</strong> ou <strong>deux kilogrammes et cinq hectogrammes</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 2 + 0,5</li>
                <li style="margin:0 0 12px 0; text-align:left;">En fraction décimale : <strong>2,5</strong> = <strong>25/10</strong></li>
                <li style="margin:0; text-align:left;">Équivalence : <strong>2,5 kg</strong> = <strong>2500 g</strong></li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Comparaison de prix</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comparer les prix : <strong>5,99 €</strong>, <strong>6,00 €</strong>, <strong>5,90 €</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On complète : <strong>5,99</strong>, <strong>6,00</strong>, <strong>5,90</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">On compare les parties entières : 5 < 6</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour 5,99 et 5,90 : parties entières égales, on compare les centièmes : 90 < 99</li>
                <li style="margin:0; text-align:left;">Ordre croissant : <strong>5,90 €</strong> < <strong>5,99 €</strong> < <strong>6,00 €</strong></li>
            </ul>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour comparer</strong> : toujours aligner les virgules et compléter avec des zéros si nécessaire</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour décomposer</strong> : séparer clairement la partie entière et la partie décimale</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour la droite graduée</strong> : bien repérer l'unité de graduation (0,1 ou 0,01)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les fractions décimales</strong> : compter le nombre de chiffres après la virgule pour déterminer le dénominateur</li>
                <li style="margin:0; text-align:left;"><strong>Pour lire un nombre</strong> : lire d'abord la partie entière, puis "virgule", puis la partie décimale chiffre par chiffre</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre <strong>virgule</strong> et <strong>point</strong> : en France, on utilise la virgule (12,34 et non 12.34)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier de <strong>compléter avec des zéros</strong> pour comparer (ex: 3,2 = 3,20)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Comparer sans <strong>aligner les virgules</strong> : toujours aligner les virgules avant de comparer</li>
                <li style="margin:0 0 12px 0; text-align:left;">Confondre <strong>dixièmes</strong> et <strong>centièmes</strong> : 0,3 = 3/10 (dixièmes) et 0,03 = 3/100 (centièmes)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier la <strong>partie entière</strong> dans la décomposition (ex: 12,34 = 12 + 0,34 et non seulement 0,34)</li>
                <li style="margin:0; text-align:left;">Se tromper dans le <strong>comptage des graduations</strong> sur la droite graduée : bien compter depuis le nombre entier ou le dixième précédent</li>
            </ul>
        </div>
