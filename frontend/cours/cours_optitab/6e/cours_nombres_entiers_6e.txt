    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Écrire et lire les nombres entiers</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Écriture en chiffres</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règle d'écriture</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour écrire un nombre en chiffres, on utilise les chiffres de <strong>0 à 9</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En France, on sépare les classes (groupes de 3 chiffres) par un <strong>espace</strong> pour faciliter la lecture.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45</strong> : quarante-cinq</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> : trois mille quatre cent deux</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> : cent vingt-cinq mille six cent soixante-dix-huit</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>7 654 321</strong> : sept millions six cent cinquante-quatre mille trois cent vingt-et-un</li>
                <li style="margin:0; text-align:left;"><strong>12 345 678</strong> : douze millions trois cent quarante-cinq mille six cent soixante-dix-huit</li>
            </ul>
        </div>

        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">On utilise un <strong>espace</strong> (pas un point ni une virgule) pour séparer les classes</li>
                <li style="margin:0 0 12px 0; text-align:left;">On ne met <strong>pas d'espace</strong> pour les nombres à 4 chiffres ou moins</li>
                <li style="margin:0; text-align:left;">Exemple : <strong>3402</strong> (pas d'espace) mais <strong>3 402</strong> (avec espace) est aussi accepté</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Écriture en lettres</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Règles importantes</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Les mots "million" et "milliard" prennent un <strong>s</strong> au pluriel</li>
                <li style="margin:0 0 12px 0; text-align:left;">Le mot "mille" est <strong>invariable</strong> (ne prend jamais de s)</li>
                <li style="margin:0; text-align:left;">On utilise des <strong>traits d'union</strong> pour les nombres composés (ex: vingt-et-un, soixante-dix)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45</strong> → <strong>quarante-cinq</strong> (avec trait d'union)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> → <strong>trois mille quatre cent deux</strong> (mille invariable)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>7 654 321</strong> → <strong>sept millions six cent cinquante-quatre mille trois cent vingt-et-un</strong></li>
                <li style="margin:0; text-align:left;"><strong>2 000 000</strong> → <strong>deux millions</strong> (million prend un s au pluriel)</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Décomposition d'un nombre</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Décomposition additive</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Décomposer un nombre, c'est l'écrire comme une <strong>somme</strong> de ses différentes unités (milliers, centaines, dizaines, unités).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples de décomposition :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> = 3 000 + 400 + 2</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> = 100 000 + 20 000 + 5 000 + 600 + 70 + 8</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>7 654 321</strong> = 7 000 000 + 600 000 + 50 000 + 4 000 + 300 + 20 + 1</li>
                <li style="margin:0; text-align:left;"><strong>45</strong> = 40 + 5</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Comparer et ranger des nombres entiers</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Comparer deux nombres</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode de comparaison</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour comparer deux nombres entiers, on compare leurs chiffres en commençant par le <strong>chiffre de gauche</strong> (le plus à gauche).</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Si les nombres n'ont pas le même nombre de chiffres, le plus grand est celui qui a <strong>le plus de chiffres</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Si les nombres ont le même nombre de chiffres, on compare les chiffres de gauche à droite</li>
                <li style="margin:0; text-align:left;">Dès qu'on trouve une différence, on peut conclure</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45 678</strong> et <strong>12 345</strong> : 45 678 > 12 345 (car 4 > 1)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> et <strong>3 502</strong> : 3 402 < 3 502 (même nombre de chiffres, on compare : 3 = 3, puis 4 < 5)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> et <strong>125 679</strong> : 125 678 < 125 679 (mêmes chiffres jusqu'aux dizaines, puis 8 < 9)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>999</strong> et <strong>1 000</strong> : 999 < 1 000 (999 a 3 chiffres, 1 000 en a 4)</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📐 Symboles de comparaison</strong></p>
            <table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden;">
                <thead>
                    <tr style="background:#e8f4f8; border-bottom:2px solid #3498db;">
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Symbole</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Signification</th>
                        <th style="border:1px solid #ddd; padding:12px; text-align:center; font-weight:700; color:#2c3e50;">Exemple</th>
                    </tr>
                </thead>
                <tbody>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-size:1.3em; font-weight:700;">&lt;</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">est plus petit que</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">12 &lt; 45</td>
                    </tr>
                    <tr style="background:#ffffff;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-size:1.3em; font-weight:700;">&gt;</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">est plus grand que</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">45 &gt; 12</td>
                    </tr>
                    <tr style="background:#f8f9fa;">
                        <td style="border:1px solid #ddd; padding:12px; text-align:center; font-size:1.3em; font-weight:700;">=</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">est égal à</td>
                        <td style="border:1px solid #ddd; padding:12px; text-align:left;">25 = 25</td>
                    </tr>
                </tbody>
            </table>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Ranger une liste de nombres</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Ordre croissant et décroissant</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre croissant</strong> : du plus petit au plus grand (↗)</li>
                <li style="margin:0; text-align:left;"><strong>Ordre décroissant</strong> : du plus grand au plus petit (↘)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre croissant</strong> : 12 345 &lt; 23 456 &lt; 45 678</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ordre décroissant</strong> : 45 678 &gt; 23 456 &gt; 12 345</li>
                <li style="margin:0 0 12px 0; text-align:left;">Ranger en ordre croissant : <strong>67 890</strong>, <strong>12 345</strong>, <strong>45 678</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Résultat : <strong>12 345</strong> &lt; <strong>45 678</strong> &lt; <strong>67 890</strong></li>
                <li style="margin:0; text-align:left;">Ranger en ordre décroissant : <strong>125</strong>, <strong>3 402</strong>, <strong>45</strong>, <strong>1 234</strong></li>
                <li style="margin:0; text-align:left;">Résultat : <strong>3 402</strong> &gt; <strong>1 234</strong> &gt; <strong>125</strong> &gt; <strong>45</strong></li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer le nombre qui a le plus de chiffres (c'est souvent le plus grand)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour les nombres avec le même nombre de chiffres, comparer chiffre par chiffre de gauche à droite</li>
                <li style="margin:0; text-align:left;">Vérifier en relisant la liste dans l'ordre</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. La droite graduée</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce qu'une droite graduée ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Définition</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>droite graduée</strong> est une droite sur laquelle on a placé des points régulièrement espacés, chacun correspondant à un nombre entier.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Elle permet de <strong>visualiser</strong> et de <strong>comparer</strong> les nombres entiers.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>Caractéristiques d'une droite graduée :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Elle a une <strong>origine</strong> (le point 0)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Elle a un <strong>sens</strong> (généralement de gauche à droite, les nombres augmentent)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Elle a une <strong>unitaire</strong> (la distance entre deux nombres consécutifs)</li>
                <li style="margin:0; text-align:left;">Les nombres sont placés de manière <strong>régulière</strong> et <strong>croissante</strong></li>
            </ul>
        </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Placer un nombre sur une droite graduée</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer l'<strong>origine</strong> (le 0) et l'<strong>unitaire</strong> (la distance entre deux nombres)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Identifier les nombres déjà placés sur la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Compter à partir de l'origine ou d'un nombre connu</li>
                <li style="margin:0; text-align:left;">Placer le point correspondant au nombre recherché</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Placer 25 sur une droite de 0 à 100</strong> (graduation de 10 en 10) : on repère 0, 10, 20, 30... Le 25 se trouve entre 20 et 30</p>
            [IMAGE_2]
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Placer 350 sur une droite de 0 à 1 000</strong> (graduation de 100 en 100) : on repère 0, 100, 200, 300, 400... Le 350 se trouve entre 300 et 400</p>
            [IMAGE_3]
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Lire un nombre sur une droite graduée</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Méthode</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Repérer le point marqué sur la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Identifier les nombres entiers les plus proches (avant et après)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Déterminer la position exacte du point</li>
                <li style="margin:0; text-align:left;">Lire le nombre correspondant</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur une droite graduée de 0 à 100 (de 10 en 10), si un point est entre 20 et 30, on lit le nombre le plus proche</p>
            [IMAGE_4]
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;">Sur une droite graduée de 0 à 1 000 (de 100 en 100), si un point est entre 300 et 400, on lit le nombre correspondant</p>
            [IMAGE_5]
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Utilisation pratique :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La droite graduée permet de :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Comparer</strong> visuellement deux nombres (le plus à droite est le plus grand)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Encadrer</strong> un nombre entre deux entiers</li>
                <li style="margin:0; text-align:left;"><strong>Visualiser</strong> l'ordre des nombres</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Encadrer un nombre</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Encadrement entre deux nombres</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Définition</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Encadrer</strong> un nombre, c'est le situer entre deux autres nombres, l'un plus petit et l'autre plus grand.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On écrit : <strong>nombre plus petit &lt; nombre à encadrer &lt; nombre plus grand</strong></p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> peut être encadré : <strong>3 000 &lt; 3 402 &lt; 4 000</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> peut être encadré : <strong>125 000 &lt; 125 678 &lt; 126 000</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45</strong> peut être encadré : <strong>40 &lt; 45 &lt; 50</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>7 654 321</strong> peut être encadré : <strong>7 000 000 &lt; 7 654 321 &lt; 8 000 000</strong></li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Encadrement plus précis</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Encadrement entre nombres proches</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On peut aussi encadrer un nombre de manière plus précise, entre deux nombres plus proches.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples d'encadrements plus précis :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> : <strong>3 400 &lt; 3 402 &lt; 3 410</strong> (encadrement à la dizaine près)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> : <strong>125 000 &lt; 125 678 &lt; 126 000</strong> (encadrement au millier près)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45</strong> : <strong>40 &lt; 45 &lt; 50</strong> (encadrement à la dizaine près)</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Ordre de grandeur</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Qu'est-ce que l'ordre de grandeur ?</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Définition</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'<strong>ordre de grandeur</strong> d'un nombre est une <strong>approximation</strong> qui donne une idée de sa "taille".</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On arrondit le nombre à un nombre "rond" proche.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> ≈ <strong>3 400</strong> (approximation à la dizaine près)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>3 402</strong> ≈ <strong>3 000</strong> (approximation au millier près)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>125 678</strong> ≈ <strong>125 000</strong> ou <strong>126 000</strong> (approximation au millier près)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>45</strong> ≈ <strong>50</strong> (approximation à la dizaine près)</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Utilisation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ordre de grandeur permet d'<strong>estimer</strong> rapidement une quantité ou de <strong>comparer</strong> rapidement deux nombres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On utilise le symbole <strong>≈</strong> (environ égal à) pour indiquer une approximation.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Applications pratiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Exemples concrets</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Population d'une ville</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une ville compte <strong>3 402 156</strong> habitants.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>trois millions quatre cent deux mille cent cinquante-six</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 3 000 000 + 400 000 + 2 000 + 100 + 50 + 6</li>
                <li style="margin:0 0 12px 0; text-align:left;">Encadrement : <strong>3 000 000 &lt; 3 402 156 &lt; 4 000 000</strong></li>
                <li style="margin:0; text-align:left;">Ordre de grandeur : environ <strong>3 400 000</strong> habitants</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Distance entre deux villes</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La distance entre Paris et Lyon est de <strong>462</strong> kilomètres.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>quatre cent soixante-deux</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 4 × 100 + 6 × 10 + 2 × 1 = 400 + 60 + 2</li>
                <li style="margin:0 0 12px 0; text-align:left;">Encadrement : <strong>400 &lt; 462 &lt; 500</strong></li>
                <li style="margin:0; text-align:left;">Ordre de grandeur : environ <strong>500</strong> kilomètres</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Nombre de spectateurs</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un stade a accueilli <strong>78 923</strong> spectateurs lors d'un match.</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">En lettres : <strong>soixante-dix-huit mille neuf cent vingt-trois</strong></li>
                <li style="margin:0 0 12px 0; text-align:left;">Décomposition : 70 000 + 8 000 + 900 + 20 + 3</li>
                <li style="margin:0 0 12px 0; text-align:left;">Encadrement : <strong>70 000 &lt; 78 923 &lt; 80 000</strong></li>
                <li style="margin:0; text-align:left;">Ordre de grandeur : environ <strong>80 000</strong> spectateurs</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour lire un grand nombre</strong> : séparer en groupes de 3 chiffres en partant de la droite</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour comparer</strong> : toujours commencer par le chiffre le plus à gauche</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour encadrer</strong> : choisir des nombres "ronds" (multiples de 10, 100, 1 000...)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour l'ordre de grandeur</strong> : arrondir au nombre "rond" le plus proche</li>
                <li style="margin:0; text-align:left;"><strong>Pour la droite graduée</strong> : bien repérer l'origine (0) et l'unité (distance entre deux nombres)</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Confondre <strong>chiffre</strong> et <strong>nombre</strong> : un chiffre est un symbole (0-9), un nombre est composé de chiffres</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier le <strong>s</strong> à "millions" et "milliards" au pluriel</li>
                <li style="margin:0 0 12px 0; text-align:left;">Mettre un <strong>s</strong> à "mille" (qui est invariable)</li>
                <li style="margin:0 0 12px 0; text-align:left;">Se tromper dans la comparaison en comparant de droite à gauche au lieu de gauche à droite</li>
                <li style="margin:0 0 12px 0; text-align:left;">Oublier les <strong>traits d'union</strong> dans les nombres composés (ex: vingt-et-un, soixante-dix)</li>
                <li style="margin:0; text-align:left;">Confondre <strong>encadrement</strong> et <strong>ordre de grandeur</strong> : l'encadrement donne deux bornes, l'ordre de grandeur donne une approximation</li>
            </ul>
        </div>
    </div>
