===Résumé Pyramides, cônes et volumes 4ème

Titre: Résumé : Pyramides, cônes et volumes

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : le vocabulaire des pyramides et des cônes, la formule du volume et les conversions. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. La formule</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$V = \dfrac{\text{aire de la base} \times \text{hauteur}}{3}$ ; cône : $V = \dfrac{\pi r^2 h}{3}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">• Une pyramide occupe le tiers du prisme de même base et de même hauteur.</p>
<p style="margin:6px 0 0 0;">• Exemple : base carrée de $6$ cm, hauteur $5$ cm : $V = \dfrac{36 \times 5}{3} = 60$ cm³.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Vocabulaire et conversions</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">1️⃣ Pyramide : base polygonale, faces latérales triangulaires, sommet, hauteur $[SO]$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Cône : base en disque, hauteur $[SO]$, génératrice $[SA]$ avec $SA^2 = SO^2 + OA^2$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $1$ m³ $= 1\,000$ dm³ $= 1\,000$ L ; $1$ dm³ $= 1$ L ; $1$ cm³ $= 1$ mL.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier de diviser par $3$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Prendre une arête ou une génératrice à la place de la hauteur.</p>
<p style="margin:6px 0 0 0;">3️⃣ Utiliser le diamètre au lieu du rayon dans $\pi r^2$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Convertir les volumes comme des longueurs (un facteur $1\,000$, pas $10$).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> « volume d'un solide pointu » → aire de la base × hauteur, puis : 3 ; hauteur inconnue → Pythagore dans le triangle rectangle formé avec une arête ou une génératrice.</p>
</div>
