    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Croissance, décroissance et monotonie</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction croissante</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ est dite <strong>croissante</strong> sur un intervalle $\displaystyle I$ si :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tous réels $\displaystyle a$ et $\displaystyle b$ de $\displaystyle I$ tels que $\displaystyle a < b$, on a $\displaystyle f(a) \leq f(b)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si de plus $\displaystyle f(a) < f(b)$ lorsque $\displaystyle a < b$, on dit que $\displaystyle f$ est <strong>strictement croissante</strong>.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction décroissante</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ est dite <strong>décroissante</strong> sur un intervalle $\displaystyle I$ si :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tous réels $\displaystyle a$ et $\displaystyle b$ de $\displaystyle I$ tels que $\displaystyle a < b$, on a $\displaystyle f(a) \geq f(b)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Si de plus $\displaystyle f(a) > f(b)$ lorsque $\displaystyle a < b$, on dit que $\displaystyle f$ est <strong>strictement décroissante</strong>.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Fonction monotone</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ est dite <strong>monotone</strong> sur un intervalle $\displaystyle I$ si elle est soit croissante, soit décroissante sur $\displaystyle I$.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Interprétation graphique</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction croissante :</strong> La courbe "monte" quand on la parcourt de gauche à droite</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Fonction décroissante :</strong> La courbe "descend" quand on la parcourt de gauche à droite</li>
                <li style="margin:0; text-align:left;"><strong>Fonction constante :</strong> La courbe est horizontale (à la fois croissante et décroissante)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">La fonction $\displaystyle f(x) = 2x + 3$ est strictement croissante sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">La fonction $\displaystyle g(x) = -x + 5$ est strictement décroissante sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">La fonction $\displaystyle h(x) = x^2$ est décroissante sur $\displaystyle ]-\infty; 0]$ et croissante sur $\displaystyle [0; +\infty[$</li>
                <li style="margin:0; text-align:left;">La fonction $\displaystyle k(x) = 7$ est constante (et donc monotone) sur $\displaystyle \mathbb{R}$</li>
            </ul>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Tableau de variations</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Tableau de variations</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un <strong>tableau de variations</strong> d'une fonction $\displaystyle f$ résume les variations de $\displaystyle f$ sur son domaine de définition.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il indique :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Les intervalles sur lesquels $\displaystyle f$ est croissante ou décroissante</li>
                <li style="margin:0 0 18px 0; text-align:left;">Les valeurs de $\displaystyle f$ aux bornes des intervalles</li>
                <li style="margin:0; text-align:left;">Les extremums (maximums et minimums) de $\displaystyle f$</li>
            </ul>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Construire un tableau de variations :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Déterminer le domaine de définition de $\displaystyle f$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Identifier les intervalles sur lesquels $\displaystyle f$ est monotone</li>
                <li style="margin:0 0 18px 0; text-align:left;">Calculer les valeurs de $\displaystyle f$ aux bornes des intervalles et aux points où la monotonie change</li>
                <li style="margin:0; text-align:left;">Construire le tableau avec des flèches indiquant la croissance (↗) ou la décroissance (↘)</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple :</strong> Fonction $\displaystyle f(x) = x^2$ sur $\displaystyle \mathbb{R}$
            <p style="margin:8px 0; text-align:left; font-size:1em;">Tableau de variations :</p>
            <table style="width:100%; border-collapse:collapse; margin:12px 0; border:2px solid #3498db; font-size:0.9em;">
                <tr style="background:#e8f4fd;">
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">x</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">-∞</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">0</th>
                    <th style="border:1px solid #ddd; padding:8px; text-align:center;">+∞</th>
                </tr>
                <tr style="background:#f8f9fa; height:90px;">
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">f(x)</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; vertical-align:top; color:#2e7d32; font-size:3.5em; line-height:0.8;">+∞</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; vertical-align:bottom; color:#c62828; font-size:2em; line-height:0.8;">0</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; vertical-align:top; color:#2e7d32; font-size:3.5em; line-height:0.8;">+∞</td>
                </tr>
                <tr>
                    <td style="border:1px solid #ddd; padding:8px; font-weight:bold;">Variation</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#c62828; font-size:1.2em;">↘</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; font-size:2em; line-height:0.8;">min</td>
                    <td style="border:1px solid #ddd; padding:8px; text-align:center; color:#2e7d32; font-size:1.2em;">↗</td>
                </tr>
            </table>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction est décroissante sur $\displaystyle ]-\infty; 0]$, admet un minimum en $\displaystyle 0$ (valeur : $\displaystyle 0$), et est croissante sur $\displaystyle [0; +\infty[$.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Maximum et minimum d'une fonction</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définitions</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Maximum d'une fonction</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ admet un <strong>maximum</strong> sur un intervalle $\displaystyle I$ s'il existe un réel $\displaystyle a \in I$ tel que :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in I$, on a $\displaystyle f(x) \leq f(a)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le nombre $\displaystyle f(a)$ est appelé le <strong>maximum</strong> de $\displaystyle f$ sur $\displaystyle I$.</p>
        </div>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Minimum d'une fonction</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une fonction $\displaystyle f$ admet un <strong>minimum</strong> sur un intervalle $\displaystyle I$ s'il existe un réel $\displaystyle a \in I$ tel que :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in I$, on a $\displaystyle f(x) \geq f(a)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le nombre $\displaystyle f(a)$ est appelé le <strong>minimum</strong> de $\displaystyle f$ sur $\displaystyle I$.</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Extremum</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On appelle <strong>extremum</strong> d'une fonction sur un intervalle un maximum ou un minimum.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un extremum peut être atteint :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">En un point où la fonction change de sens de variation</li>
                <li style="margin:0 0 18px 0; text-align:left;">Aux bornes de l'intervalle (si elles appartiennent à l'intervalle)</li>
            </ul>
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pratique - Déterminer graphiquement un extremum :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Tracer la courbe représentative $\displaystyle \mathcal{C}_f$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Repérer le point le plus haut (maximum) ou le plus bas (minimum) sur l'intervalle considéré</li>
                <li style="margin:0 0 18px 0; text-align:left;">Lire l'abscisse et l'ordonnée de ce point</li>
                <li style="margin:0; text-align:left;">Vérifier que ce point correspond bien à un extremum (changement de sens de variation ou borne de l'intervalle)</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction $\displaystyle f(x) = x^2$ sur $\displaystyle \mathbb{R}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}$, on a $\displaystyle f(x) = x^2 \geq 0 = f(0)$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction $\displaystyle g(x) = -x^2 + 4$ sur $\displaystyle [-2; 2]$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction admet un <strong>maximum</strong> en $\displaystyle x = 0$ : $\displaystyle g(0) = 4$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Aux bornes : $\displaystyle g(-2) = g(2) = 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le maximum sur $\displaystyle [-2; 2]$ est $\displaystyle 4$, atteint en $\displaystyle 0$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Fonction affine : taux d'accroissement et variations</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Taux d'accroissement</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Définition - Taux d'accroissement</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour une fonction $\displaystyle f$ et deux réels distincts $\displaystyle a$ et $\displaystyle b$ du domaine de définition, le <strong>taux d'accroissement</strong> de $\displaystyle f$ entre $\displaystyle a$ et $\displaystyle b$ est :</p>
            <div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:15px auto; text-align:center; max-width:400px; font-weight:bold;">
                $\displaystyle \tau(a, b) = \frac{f(b) - f(a)}{b - a}$
            </div>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Fonction affine</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour une fonction affine $\displaystyle f(x) = mx + p$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le taux d'accroissement entre deux réels distincts $\displaystyle a$ et $\displaystyle b$ est constant et égal au coefficient directeur $\displaystyle m$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \tau(a, b) = \frac{f(b) - f(a)}{b - a} = \frac{(mb + p) - (ma + p)}{b - a} = \frac{m(b - a)}{b - a} = m$</p>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations selon le signe du coefficient directeur</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle m > 0$ : la fonction affine est <strong>strictement croissante</strong> sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Si $\displaystyle m < 0$ : la fonction affine est <strong>strictement décroissante</strong> sur $\displaystyle \mathbb{R}$</li>
                <li style="margin:0; text-align:left;">Si $\displaystyle m = 0$ : la fonction est <strong>constante</strong> (égale à $\displaystyle p$)</li>
            </ul>
        </div>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Lien avec la droite représentative</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le coefficient directeur $\displaystyle m$ d'une fonction affine $\displaystyle f(x) = mx + p$ représente :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Le <strong>taux d'accroissement</strong> de la fonction (variation de $\displaystyle f$ par unité de variation de $\displaystyle x$)</li>
                <li style="margin:0 0 18px 0; text-align:left;">La <strong>pente</strong> de la droite représentative</li>
                <li style="margin:0; text-align:left;">Le <strong>sens de variation</strong> : $\displaystyle m > 0$ implique croissance, $\displaystyle m < 0$ implique décroissance</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemples :</strong>
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 1 :</strong> Fonction $\displaystyle f(x) = 3x - 2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Coefficient directeur : $\displaystyle m = 3 > 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Taux d'accroissement : $\displaystyle \tau(1, 4) = \frac{f(4) - f(1)}{4 - 1} = \frac{10 - 1}{3} = 3 = m$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction est <strong>strictement croissante</strong> sur $\displaystyle \mathbb{R}$</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Exemple 2 :</strong> Fonction $\displaystyle g(x) = -2x + 5$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Coefficient directeur : $\displaystyle m = -2 < 0$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Taux d'accroissement : $\displaystyle \tau(0, 3) = \frac{g(3) - g(0)}{3 - 0} = \frac{-1 - 5}{3} = -2 = m$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction est <strong>strictement décroissante</strong> sur $\displaystyle \mathbb{R}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Variations des fonctions de référence</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Fonction carré</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Variations de la fonction carré</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">La fonction $\displaystyle f(x) = x^2$ est :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Strictement décroissante</strong> sur $\displaystyle ]-\infty; 0]$</li>
                <li style="margin:0 0 18px 0; text-align:left;"><strong>Strictement croissante</strong> sur $\displaystyle [0; +\infty[$</li>
                <li style="margin:0; text-align:left;">Elle admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$</li>
            </ul>
        </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Démonstrations : Variations des fonctions de référence</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démonstration : Variations de la fonction carré</h3>

        <div style="background:#e0f7fa; border-radius:6px; border-left:6px solid #00bcd4; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Démonstration - Fonction carré</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle f(x) = x^2$ définie sur $\displaystyle \mathbb{R}$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>1. Variations sur $\displaystyle ]-\infty; 0]$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle a$ et $\displaystyle b$ deux réels tels que $\displaystyle a < b \leq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a $\displaystyle a < 0$ et $\displaystyle b \leq 0$, donc $\displaystyle a + b < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(b) - f(a) = b^2 - a^2 = (b - a)(b + a)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle b - a > 0$ et $\displaystyle b + a < 0$, on a $\displaystyle f(b) - f(a) < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) < f(a)$, ce qui prouve que $\displaystyle f$ est <strong>strictement décroissante</strong> sur $\displaystyle ]-\infty; 0]$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>2. Variations sur $\displaystyle [0; +\infty[$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle a$ et $\displaystyle b$ deux réels tels que $\displaystyle 0 \leq a < b$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a $\displaystyle a \geq 0$ et $\displaystyle b > 0$, donc $\displaystyle a + b > 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(b) - f(a) = b^2 - a^2 = (b - a)(b + a)$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle b - a > 0$ et $\displaystyle b + a > 0$, on a $\displaystyle f(b) - f(a) > 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) > f(a)$, ce qui prouve que $\displaystyle f$ est <strong>strictement croissante</strong> sur $\displaystyle [0; +\infty[$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>3. Minimum :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in \mathbb{R}$, on a $\displaystyle x^2 \geq 0$ et $\displaystyle 0^2 = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f$ admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démonstration : Variations de la fonction inverse</h3>

        <div style="background:#e0f7fa; border-radius:6px; border-left:6px solid #00bcd4; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Démonstration - Fonction inverse</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle f(x) = \frac{1}{x}$ définie sur $\displaystyle \mathbb{R}^*$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>1. Variations sur $\displaystyle ]0; +\infty[$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle a$ et $\displaystyle b$ deux réels strictement positifs tels que $\displaystyle 0 < a < b$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(b) - f(a) = \frac{1}{b} - \frac{1}{a} = \frac{a - b}{ab}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle a < b$, on a $\displaystyle a - b < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle a > 0$ et $\displaystyle b > 0$, on a $\displaystyle ab > 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) - f(a) = \frac{a - b}{ab} < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) < f(a)$, ce qui prouve que $\displaystyle f$ est <strong>strictement décroissante</strong> sur $\displaystyle ]0; +\infty[$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>2. Variations sur $\displaystyle ]-\infty; 0[$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle a$ et $\displaystyle b$ deux réels strictement négatifs tels que $\displaystyle a < b < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle f(b) - f(a) = \frac{1}{b} - \frac{1}{a} = \frac{a - b}{ab}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle a < b$, on a $\displaystyle a - b < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle a < 0$ et $\displaystyle b < 0$, on a $\displaystyle ab > 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) - f(a) = \frac{a - b}{ab} < 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) < f(a)$, ce qui prouve que $\displaystyle f$ est <strong>strictement décroissante</strong> sur $\displaystyle ]-\infty; 0[$.</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Démonstration : Variations de la fonction racine carrée</h3>

        <div style="background:#e0f7fa; border-radius:6px; border-left:6px solid #00bcd4; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Démonstration - Fonction racine carrée</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle f(x) = \sqrt{x}$ définie sur $\displaystyle [0; +\infty[$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Variations sur $\displaystyle [0; +\infty[$ :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soient $\displaystyle a$ et $\displaystyle b$ deux réels positifs tels que $\displaystyle 0 \leq a < b$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On veut montrer que $\displaystyle \sqrt{b} > \sqrt{a}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme $\displaystyle a < b$ et que $\displaystyle a, b \geq 0$, on peut élever au carré :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle (\sqrt{b})^2 = b > a = (\sqrt{a})^2$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Comme la fonction carré est croissante sur $\displaystyle [0; +\infty[$ et que $\displaystyle \sqrt{a}, \sqrt{b} \geq 0$, on en déduit :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">$\displaystyle \sqrt{b} > \sqrt{a}$</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f(b) > f(a)$, ce qui prouve que $\displaystyle f$ est <strong>strictement croissante</strong> sur $\displaystyle [0; +\infty[$.</p>
            
            <p style="margin:12px 0 8px 0; text-align:left; font-size:1em;"><strong>Minimum :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Pour tout $\displaystyle x \in [0; +\infty[$, on a $\displaystyle \sqrt{x} \geq 0$ et $\displaystyle \sqrt{0} = 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle f$ admet un <strong>minimum</strong> en $\displaystyle x = 0$ : $\displaystyle f(0) = 0$.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Algorithmes</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Algorithme 1 : Approximation d'un extremum par balayage</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Objectif :</strong> Pour une fonction dont le tableau de variations est donné, trouver une approximation d'un extremum (minimum ou maximum) par balayage.
        </div>

        <div style="background:#f0f0f0; border-radius:6px; padding:15px; margin:12px 0; font-family:monospace; font-size:0.9em;">
            <strong>Algorithme Python - Balayage pour un minimum :</strong>
            <pre style="background:#ffffff; padding:12px; border-radius:4px; overflow-x:auto; margin:8px 0; border:1px solid #ddd;">
def extremum_balayage(f, a, b, pas):
    """
    Trouve une approximation d'un extremum de f sur [a, b] par balayage.
    f : fonction
    a, b : bornes de l'intervalle
    pas : pas de balayage (précision)
    """
    x_min = a
    f_min = f(a)
    
    x = a
    while x <= b:
        if f(x) < f_min:
            f_min = f(x)
            x_min = x
        x = x + pas
    
    print(f"Minimum approximatif : f({x_min}) = {f_min}")
    return x_min, f_min

# Exemple d'utilisation
def f(x):
    return x**2 - 4*x + 3

extremum_balayage(f, 0, 5, 0.1)

        <h3 style="color:#34495e; margin-top:0;">Algorithme 2 : Approximation d'un extremum par dichotomie</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Objectif :</strong> Pour une fonction dont on sait qu'elle admet un extremum sur un intervalle, trouver une approximation plus précise par dichotomie (méthode plus efficace que le balayage).
        </div>

        <div style="background:#f0f0f0; border-radius:6px; padding:15px; margin:12px 0; font-family:monospace; font-size:0.9em;">
            <strong>Algorithme Python - Dichotomie pour un minimum :</strong>
            <pre style="background:#ffffff; padding:12px; border-radius:4px; overflow-x:auto; margin:8px 0; border:1px solid #ddd;">
def extremum_dichotomie(f, a, b, epsilon):
    """
    Trouve une approximation d'un minimum de f sur [a, b] par dichotomie.
    On suppose que f est décroissante puis croissante (minimum unique).
    epsilon : précision souhaitée
    """
    while b - a > epsilon:
        m = (a + b) / 2
        m_gauche = (a + m) / 2
        m_droite = (m + b) / 2
        
        if f(m_gauche) < f(m_droite):
            b = m_droite
        else:
            a = m_gauche
    
    x_min = (a + b) / 2
    print(f"Minimum approximatif : f({x_min}) = {f(x_min)}")
    return x_min, f(x_min)

# Exemple d'utilisation
def f(x):
    return x**2 - 4*x + 3

extremum_dichotomie(f, 0, 5, 0.001)
</pre>

        <h3 style="color:#34495e; margin-top:0;">Algorithme 3 : Calcul approché de longueur d'une portion de courbe</h3>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Objectif :</strong> Calculer une approximation de la longueur d'une portion de courbe représentative d'une fonction entre deux points.
        </div>

        <div style="background:#fef3c7; border-radius:6px; padding:15px; margin:12px 0;">
            <strong>💡 Principe :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On approche la courbe par une ligne polygonale (suite de segments) et on calcule la somme des longueurs de ces segments.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Plus le nombre de segments est grand, plus l'approximation est précise.</p>
        </div>

        <div style="background:#f0f0f0; border-radius:6px; padding:15px; margin:12px 0; font-family:monospace; font-size:0.9em;">
            <strong>Algorithme Python :</strong>
            <pre style="background:#ffffff; padding:12px; border-radius:4px; overflow-x:auto; margin:8px 0; border:1px solid #ddd;">
import math

def longueur_courbe(f, a, b, n):
    """
    Calcule une approximation de la longueur de la courbe y = f(x)
    entre x = a et x = b en utilisant n segments.
    """
    longueur = 0
    pas = (b - a) / n
    
    for i in range(n):
        x1 = a + i * pas
        x2 = a + (i + 1) * pas
        y1 = f(x1)
        y2 = f(x2)
        
        # Longueur du segment entre (x1, y1) et (x2, y2)
        segment = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
        longueur = longueur + segment
    
    print(f"Longueur approximative de la courbe : {longueur}")
    return longueur

# Exemple d'utilisation
def f(x):
    return x**2

longueur_courbe(f, 0, 2, 100)  # Approximation avec 100 segments

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Approfondissements et conseils méthodologiques</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Approfondissement : Relation entre les courbes de la fonction racine carrée et de la fonction carré</h3>

        <div style="background:#f3e5f5; border-radius:6px; border-left:6px solid #9c27b0; padding:15px; margin:12px 0;">
            <strong>💡 Propriété - Symétrie par rapport à la droite y = x</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Sur $\displaystyle \mathbb{R}^+$, les courbes représentatives de $\displaystyle y = x^2$ et $\displaystyle y = \sqrt{x}$ sont <strong>symétriques par rapport à la droite d'équation $\displaystyle y = x$</strong>.</p>
        </div>

        <div style="background:#e0f7fa; border-radius:6px; border-left:6px solid #00bcd4; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>Démonstration - Symétrie</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Soit $\displaystyle M(a; a^2)$ un point de la courbe $\displaystyle y = x^2$ avec $\displaystyle a \geq 0$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le symétrique de $\displaystyle M$ par rapport à la droite $\displaystyle y = x$ est $\displaystyle M'(a^2; a)$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Vérifions que $\displaystyle M'$ appartient à la courbe $\displaystyle y = \sqrt{x}$ :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'abscisse de $\displaystyle M'$ est $\displaystyle a^2 \geq 0$ (domaine de définition de $\displaystyle \sqrt{x}$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">L'ordonnée de $\displaystyle M'$ est $\displaystyle a = \sqrt{a^2}$ (car $\displaystyle a \geq 0$)</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Donc $\displaystyle M'(a^2; \sqrt{a^2})$ appartient bien à la courbe $\displaystyle y = \sqrt{x}$.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Conclusion :</strong> Les deux courbes sont symétriques par rapport à la droite $\displaystyle y = x$ sur $\displaystyle \mathbb{R}^+$.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Interprétation :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette symétrie s'explique par le fait que les fonctions carré et racine carrée sont <strong>réciproques</strong> l'une de l'autre sur $\displaystyle \mathbb{R}^+$ :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.5; font-size:1em;">
                <li style="margin:0 0 18px 0; text-align:left;">Pour $\displaystyle x \geq 0$ : $\displaystyle \sqrt{x^2} = x$</li>
                <li style="margin:0 0 18px 0; text-align:left;">Pour $\displaystyle x \geq 0$ : $\displaystyle (\sqrt{x})^2 = x$</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les courbes se "reflètent" l'une dans l'autre par rapport à la première bissectrice (droite $\displaystyle y = x$).</p>
        </div>
    </div>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils méthodologiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pratiques :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Tableau de variations :</strong> Toujours placer les valeurs dans l'ordre croissant, utiliser des flèches ↗ (croissante) et ↘ (décroissante)</li>
                <li style="margin:0; text-align:left;"><strong>Extremums :</strong> Repérer les changements de sens de variation (minimum si ↘ puis ↗, maximum si ↗ puis ↘)</li>
                <li style="margin:0; text-align:left;"><strong>Fonction affine :</strong> Le coefficient directeur $\displaystyle m$ est égal au taux d'accroissement et détermine le sens de variation</li>
                <li style="margin:0; text-align:left;"><strong>Fonction carré :</strong> Décroissante sur $\displaystyle ]-\infty; 0]$, croissante sur $\displaystyle [0; +\infty[$, minimum en 0</li>
                <li style="margin:0; text-align:left;"><strong>Fonction inverse :</strong> Décroissante sur chaque intervalle $\displaystyle ]-\infty; 0[$ et $\displaystyle ]0; +\infty[$</li>
                <li style="margin:0; text-align:left;"><strong>Fonction racine carrée :</strong> Croissante sur $\displaystyle [0; +\infty[$, minimum en 0</li>
                <li style="margin:0; text-align:left;"><strong>Fonction cube :</strong> Croissante sur tout $\displaystyle \mathbb{R}$</li>
                <li style="margin:0; text-align:left;"><strong>Graphique → Tableau :</strong> Observer où la courbe monte (↗) ou descend (↘), repérer les extremums</li>
                <li style="margin:0; text-align:left;"><strong>Tableau → Graphique :</strong> Placer les points clés, tracer en respectant les flèches du tableau</li>
                <li style="margin:0; text-align:left;"><strong>Outils numériques :</strong> Utiliser pour visualiser, vérifier ou compléter une analyse manuelle</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:2.2; font-size:1em;">
                <li style="margin:0; text-align:left;"><strong>Flèches :</strong> Ne pas confondre ↗ (croissante) et ↘ (décroissante)</li>
                <li style="margin:0; text-align:left;"><strong>Fonction inverse :</strong> Ne pas dire qu'elle est décroissante sur $\displaystyle \mathbb{R}^*$ (car $\displaystyle f(-1) < f(1)$ alors que $\displaystyle -1 < 1$)</li>
                <li style="margin:0; text-align:left;"><strong>Extremums :</strong> Un extremum peut être atteint aux bornes de l'intervalle, pas seulement aux changements de variation</li>
                <li style="margin:0; text-align:left;"><strong>Taux d'accroissement :</strong> Attention à l'ordre : $\displaystyle \tau(a, b) = \frac{f(b) - f(a)}{b - a}$ (et non $\displaystyle \frac{f(a) - f(b)}{b - a}$)</li>
                <li style="margin:0; text-align:left;"><strong>Tableau de variations :</strong> Ne pas oublier de placer les valeurs aux bornes et aux points d'extremum</li>
                <li style="margin:0; text-align:left;"><strong>Fonction constante :</strong> Une fonction constante est à la fois croissante et décroissante (mais pas strictement)</li>
                <li style="margin:0; text-align:left;"><strong>Balayage :</strong> Plus le pas est petit, plus l'approximation est précise, mais le calcul est plus long</li>
                <li style="margin:0; text-align:left;"><strong>Dichotomie :</strong> Plus efficace que le balayage, mais nécessite de connaître le comportement de la fonction</li>
                <li style="margin:0; text-align:left;"><strong>Longueur de courbe :</strong> L'approximation s'améliore avec le nombre de segments, mais nécessite plus de calculs</li>
            </ul>
        </div>
