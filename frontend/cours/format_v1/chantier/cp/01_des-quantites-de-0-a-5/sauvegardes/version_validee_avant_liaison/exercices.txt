Découverte - La boîte vide
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une boîte vide ne contient aucun jeton.

1. Une boîte est vide. Quel nombre de jetons écris-tu ?
2. Une boîte contient 3 jetons. Retire les 3. Combien reste-t-il ?
3. Dans la boîte vide, pose 1 jeton. Combien y en a-t-il ?
4. Écris en chiffres : « zéro ».
5. Complète avec <, > ou = : 0 … 1.

Étapes:
<!-- optitab:1 -->

## Question 1 : Une boîte est vide. Quel nombre de jetons écris-tu ?

::: methode
Reconnaître une quantité nulle.
:::

::: etape Raisonner
Il n’y a aucun jeton. Aucun se note 0.
:::

::: resultat
0 jeton.
:::

## Question 2 : Une boîte contient 3 jetons. Retire les 3. Combien reste-t-il ?

::: methode
Enlever tous les objets.
:::

::: etape Raisonner
Je retire un jeton, puis un autre, puis le dernier. La boîte est vide.
:::

::: resultat
0 jeton.
:::

## Question 3 : Dans la boîte vide, pose 1 jeton. Combien y en a-t-il ?

::: methode
Vérifier que la boîte n’est plus vide.
:::

::: etape Raisonner
Un jeton est maintenant dans la boîte.
:::

::: resultat
1 jeton.
:::

## Question 4 : Écris en chiffres : « zéro ».

::: methode
Relier le mot au nombre.
:::

::: etape Raisonner
Je dis « zéro ». Je cherche son écriture avec des chiffres.
:::

::: resultat
0
:::

## Question 5 : Complète avec <, > ou = : 0 … 1.

::: methode
Comparer les deux nombres.
:::

::: etape Raisonner
Je mets les objets par deux, un de chaque groupe. Je regarde si un groupe en a encore.
:::

::: resultat
$0 < 1$.
:::

Solution:
<!-- optitab:1 -->
1. 0 jeton.
2. 0 jeton.
3. 1 jeton.
4. 0
5. $0 < 1$.
