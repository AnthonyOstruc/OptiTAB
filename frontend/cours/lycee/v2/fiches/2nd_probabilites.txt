<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Calculer une probabilité</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$p(A \cup B) = p(A) + p(B) - p(A \cap B)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ Loi de probabilité : $p_i \ge 0$ et $p_1 + \cdots + p_n = 1$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Équiprobabilité : $p(A) = \frac{\text{issues favorables}}{\text{issues possibles}}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Contraire : $p(\overline{A}) = 1 - p(A)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Compter les issues</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ Arbre : une branche par résultat possible à chaque étape.</p>
<p style="margin:6px 0 0 0;">2️⃣ Tableau à double entrée : pratique pour deux dés ou deux tirages.</p>
<p style="margin:6px 0 0 0;">3️⃣ « Au moins un » → passer par l’événement contraire « aucun ».</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Additionner $p(A)$ et $p(B)$ sans retirer $p(A \cap B)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Supposer l’équiprobabilité alors qu’elle n’est pas justifiée (sommes de deux dés).</p>
<p style="margin:6px 0 0 0;">3️⃣ Donner une probabilité négative ou supérieure à $1$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier des issues : utiliser un arbre ou un tableau.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je décris d’abord $\Omega$, je vérifie si les issues sont équiprobables, puis je compte les issues favorables.</p>
</div>
