===Résumé Combinatoire et Dénombrement

Titre: Résumé : Combinatoire et Dénombrement

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> Maîtriser les outils de dénombrement : principes additif et multiplicatif, permutations, arrangements, combinaisons, coefficients binomiaux.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Principes fondamentaux</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Principe additif</strong></p>
<p style="margin:5px 0 0 0;">Si $\displaystyle A_1, A_2, \ldots, A_k$ sont des ensembles <strong>deux à deux disjoints</strong> :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle |A_1 \cup A_2 \cup \cdots \cup A_k| = |A_1| + |A_2| + \cdots + |A_k|$</p>
</div>
<p style="margin:5px 0 0 0;"><em style="font-size:0.9em;">⚠️ Condition : les ensembles doivent être disjoints</em></p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Principe multiplicatif</strong></p>
<p style="margin:5px 0 0 0;">Le nombre d'éléments du produit cartésien $\displaystyle A_1 \times A_2 \times \cdots \times A_k$ est :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle |A_1 \times A_2 \times \cdots \times A_k| = |A_1| \times |A_2| \times \cdots \times |A_k|$</p>
</div>
<p style="margin:5px 0 0 0;">Pour un ensemble $\displaystyle A$ à $\displaystyle n$ éléments : $\displaystyle |A^k| = n^k$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Nombre de parties</strong></p>
<p style="margin:5px 0 0 0;">Un ensemble à $\displaystyle n$ éléments possède exactement $\displaystyle 2^n$ parties.</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:250px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle |\mathcal{P}(A)| = 2^n$</p>
</div>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Permutations et arrangements</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Permutation</strong></p>
<p style="margin:5px 0 0 0;">Une <strong>permutation</strong> d'un ensemble fini $\displaystyle A$ est un arrangement de <strong>tous les éléments</strong> de $\displaystyle A$ dans un certain ordre.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Factorielle</strong></p>
<p style="margin:5px 0 0 0;">Pour un entier naturel $\displaystyle n$ :</p>
<ul style="margin:5px 0 0 0; padding-left:20px;">
<li style="margin:5px 0;">$\displaystyle 0! = 1$</li>
<li style="margin:5px 0;">$\displaystyle n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1$ pour $\displaystyle n \geq 1$</li>
</ul>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Nombre de permutations</strong></p>
<p style="margin:5px 0 0 0;">Le nombre de permutations d'un ensemble à $\displaystyle n$ éléments est :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:200px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle n!$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Arrangement</strong></p>
<p style="margin:5px 0 0 0;">Un <strong>arrangement</strong> de $\displaystyle k$ éléments d'un ensemble à $\displaystyle n$ éléments est un k-uplet d'éléments <strong>distincts</strong> (l'ordre compte).</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Nombre d'arrangements</strong></p>
<p style="margin:5px 0 0 0;">Le nombre d'arrangements de $\displaystyle k$ éléments parmi $\displaystyle n$ est :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:550px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle A_n^k = \frac{n!}{(n-k)!} = n \times (n-1) \times \cdots \times (n-k+1)$</p>
</div>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Combinaisons et coefficients binomiaux</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Combinaison</strong></p>
<p style="margin:5px 0 0 0;">Une <strong>combinaison</strong> de $\displaystyle k$ éléments d'un ensemble à $\displaystyle n$ éléments est une <strong>partie à $\displaystyle k$ éléments</strong> (l'ordre n'a pas d'importance).</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Coefficient binomial</strong></p>
<p style="margin:5px 0 0 0;">Le <strong>coefficient binomial</strong> $\displaystyle \binom{n}{k}$ est le nombre de combinaisons de $\displaystyle k$ éléments parmi $\displaystyle n$ :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \binom{n}{k} = \frac{n!}{k!(n-k)!}$</p>
</div>
<p style="margin:5px 0 0 0;">pour $\displaystyle 0 \leq k \leq n$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Propriété</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Valeur</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \binom{n}{0}$ et $\displaystyle \binom{n}{n}$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle 1$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \binom{n}{1}$ et $\displaystyle \binom{n}{n-1}$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle n$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \binom{n}{2}$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \frac{n(n-1)}{2}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Symétrie</td>
<td style="border:none; padding:18px 16px;">$\displaystyle \binom{n}{k} = \binom{n}{n-k}$</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Relation arrangements / combinaisons</strong></p>
<p style="margin:5px 0 0 0;">Le nombre d'arrangements de $\displaystyle k$ éléments parmi $\displaystyle n$ est égal au nombre de combinaisons multiplié par le nombre de permutations de $\displaystyle k$ éléments :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle A_n^k = \binom{n}{k} \times k!$</p>
</div>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Triangle de Pascal</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Relation de Pascal</strong></p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle 1 \leq k \leq n-1$ :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:350px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Somme des coefficients binomiaux</strong></p>
<p style="margin:5px 0 0 0;">Pour tout entier naturel $\displaystyle n$ :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \sum_{k=0}^{n} \binom{n}{k} = 2^n$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Triangle de Pascal</strong></p>
<p style="margin:5px 0 0 0;">Chaque ligne $\displaystyle n$ contient les coefficients $\displaystyle \binom{n}{0}, \binom{n}{1}, \ldots, \binom{n}{n}$. Chaque coefficient (sauf les bords) est la somme des deux coefficients situés au-dessus.</p>
</div>
<div style="background:#f8f9fa; border:2px solid #3498db; border-radius:8px; padding:20px; margin:15px auto; text-align:center; max-width:600px;">
<p style="margin:0; font-size:1.2em; font-weight:bold; color:#2c3e50; margin-bottom:15px;">Triangle de Pascal (premières lignes)</p>
<table style="margin:0 auto; border-collapse:separate; border-spacing:8px;">
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 0 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1$</td>
</tr>
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 1 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1 \quad 1$</td>
</tr>
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 2 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1 \quad 2 \quad 1$</td>
</tr>
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 3 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1 \quad 3 \quad 3 \quad 1$</td>
</tr>
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 4 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1 \quad 4 \quad 6 \quad 4 \quad 1$</td>
</tr>
<tr>
<td style="text-align:center; font-weight:bold; color:#2c3e50; padding:8px;">Ligne 5 :</td>
<td style="text-align:center; font-size:1.1em; padding:8px;">$\displaystyle 1 \quad 5 \quad 10 \quad 10 \quad 5 \quad 1$</td>
</tr>
</table>
<p style="margin:15px 0 0 0; font-size:0.9em; color:#666;"><em>Exemple : $\displaystyle \binom{4}{2} = 6 = 3 + 3 = \binom{3}{1} + \binom{3}{2}$</em></p>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Quel outil utiliser ?</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Méthode - Choisir l'outil adapté</strong></p>
<p style="margin:5px 0 0 0;">Pour déterminer quel outil utiliser, posez-vous deux questions :</p>
<ol style="margin:5px 0 0 0; padding-left:20px;">
<li style="margin:5px 0;">L'ordre est-il important ?</li>
<li style="margin:5px 0;">Les répétitions sont-elles autorisées ?</li>
</ol>
</div>
</div>

</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;">Tous les éléments, ordre important</td>

</tr>
</tbody>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Piège fréquent</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Correction</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre arrangement et combinaison</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Arrangement : ordre important. Combinaison : ordre non important</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier que le principe additif nécessite des ensembles disjoints</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Vérifier que $\displaystyle A_i \cap A_j = \emptyset$ pour $\displaystyle i \neq j$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Confondre $\displaystyle \binom{n}{k}$ et $\displaystyle \binom{k}{n}$</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">$\displaystyle \binom{n}{k}$ avec $\displaystyle n \geq k$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Oublier que $\displaystyle 0! = 1$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Par convention : $\displaystyle 0! = 1$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; padding:18px 16px;">Ne pas vérifier $\displaystyle 0 \leq k \leq n$</td>
<td style="border:none; padding:18px 16px;">Toujours vérifier que $\displaystyle 0 \leq k \leq n$ avant de calculer $\displaystyle \binom{n}{k}$</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Formules essentielles — mémo rapide</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Notion</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Formule essentielle</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Principe additif</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle |A_1 \cup \cdots \cup A_k| = |A_1| + \cdots + |A_k|$ (ensembles disjoints)</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Principe multiplicatif</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle |A_1 \times \cdots \times A_k| = |A_1| \times \cdots \times |A_k|$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Nombre de parties</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle |\mathcal{P}(A)| = 2^n$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Factorielle</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle 0! = 1$, $\displaystyle n! = n \times (n-1) \times \cdots \times 2 \times 1$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Permutations</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle n!$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Arrangements</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle A_n^k = \frac{n!}{(n-k)!}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Combinaisons</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \binom{n}{k} = \frac{n!}{k!(n-k)!}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Symétrie</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \binom{n}{k} = \binom{n}{n-k}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">Relation de Pascal</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Somme des coefficients</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \sum_{k=0}^{n} \binom{n}{k} = 2^n$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:18px 16px;">Relation arrangements / combinaisons</td>
<td style="border:none; padding:18px 16px;">$\displaystyle A_n^k = \binom{n}{k} \times k!$</td>
</tr>

</table>
