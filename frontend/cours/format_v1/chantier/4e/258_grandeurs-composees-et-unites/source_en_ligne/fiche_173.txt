<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : durées, vitesse moyenne, conversions, débit, masse volumique, énergie, volumes. Programme de 4ème.</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Durées et vitesses</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $0{,}25$ h $= 15$ min ; $0{,}5$ h $= 30$ min ; $0{,}75$ h $= 45$ min ; $0{,}1$ h $= 6$ min.</p>
[IMAGE_1]
<p style="margin:6px 0 0 0;">• $1$ m/s $= 3{,}6$ km/h : de km/h vers m/s, on divise par $3{,}6$.</p>
<p style="margin:6px 0 0 0;">• Vitesse moyenne = distance totale : durée totale (pas la moyenne des vitesses).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Autres grandeurs et volumes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Débit $=$ volume : durée (L/min, m³/s).</p>
<p style="margin:6px 0 0 0;">• Masse volumique $\rho = \frac{m}{V}$ ; l'eau : $1$ kg/L ; un objet de masse volumique inférieure à $1$ g/cm³ flotte sur l'eau.</p>
<p style="margin:6px 0 0 0;">• Énergie (kWh) $=$ puissance (kW) $\times$ durée (h).</p>
[IMAGE_2]
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Lire $1{,}5$ h comme $1$ h $50$ min (c'est $1$ h $30$ min).</p>
<p style="margin:6px 0 0 0;">2️⃣ Mélanger les unités : km avec m, minutes avec heures.</p>
<p style="margin:6px 0 0 0;">3️⃣ Faire la moyenne de deux vitesses au lieu de diviser distance totale par durée totale.</p>
<p style="margin:6px 0 0 0;">4️⃣ Convertir $1$ m³ en $100$ L (c'est $1\,000$ L).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> avant tout calcul, j'écris les unités et je les rends cohérentes (km et h ensemble, m et s ensemble) ; le résultat porte alors la bonne unité.</p>
</div>
