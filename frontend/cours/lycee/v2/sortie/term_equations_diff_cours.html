🎯 Objectifs du chapitre : comprendre ce qu’est une équation différentielle, résoudre $\displaystyle y' = ay$ et $\displaystyle y' = ay + b$, utiliser une condition initiale, trouver les solutions de $\displaystyle y' = ay + f$ à partir d’une solution particulière, et modéliser des phénomènes (refroidissement, charge d’un condensateur, population).

I. Définition

Définition : une équation différentielle est une équation dont l’inconnue est une fonction $\displaystyle y$ et qui fait intervenir sa dérivée $\displaystyle y'$. Une solution sur $\displaystyle I$ est une fonction dérivable sur $\displaystyle I$ qui vérifie l’équation.

Exemple : les solutions de $\displaystyle y' = 2x$ sont les primitives de $\displaystyle 2x$ : $\displaystyle y = x^2 + C$.

💡 Vérifier une solution : on calcule $\displaystyle y'$ et on remplace dans l’équation. Par exemple $\displaystyle y = e^{3x}$ vérifie $\displaystyle y' = 3y$ car $\displaystyle y' = 3e^{3x}$.

II. L’équation $\displaystyle y' = ay$

Théorème (démonstration au programme) : les solutions sur $\displaystyle \mathbb{R}$ de $\displaystyle y' = ay$ sont les fonctions $\displaystyle x \mapsto Ce^{ax}$, $\displaystyle C$ réel. Pour $\displaystyle x_0$ et $\displaystyle y_0$ donnés, une seule solution vérifie $\displaystyle y(x_0) = y_0$.

Preuve : si $\displaystyle f' = af$, la fonction $\displaystyle g(x) = f(x)e^{-ax}$ a pour dérivée $\displaystyle g'(x) = (f'(x) - af(x))e^{-ax} = 0$ ; $\displaystyle g$ est constante, égale à $\displaystyle C$, d’où $\displaystyle f(x) = Ce^{ax}$. Réciproquement, ces fonctions sont bien solutions.

Exemple : $\displaystyle y' = 3y$ avec $\displaystyle y(0) = 2$ : $\displaystyle y = Ce^{3x}$ et $\displaystyle C = 2$, donc $\displaystyle y = 2e^{3x}$.

III. L’équation $\displaystyle y' = ay + b$

Théorème : pour $\displaystyle a \neq 0$, l’équation $\displaystyle y' = ay + b$ admet la solution constante $\displaystyle y = -\frac{b}{a}$, et ses solutions sont les fonctions

$\displaystyle x \mapsto Ce^{ax} - \frac{b}{a}$, $\displaystyle C$ réel.

Preuve : $\displaystyle f$ est solution si et seulement si $\displaystyle f + \frac{b}{a}$ est solution de $\displaystyle y' = ay$.

[IMAGE_1]

Exemple : $\displaystyle y' = -0{,}5y + 2$ avec $\displaystyle y(0) = 0$. La solution constante est $\displaystyle y = \frac{2}{0{,}5} = 4$, donc $\displaystyle y = Ce^{-0{,}5x} + 4$ ; $\displaystyle y(0) = C + 4 = 0$ donne $\displaystyle C = -4$ : $\displaystyle y = 4 - 4e^{-0{,}5x}$.

IV. L’équation $\displaystyle y' = ay + f$

Propriété : si $\displaystyle y_p$ est une solution particulière de $\displaystyle y' = ay + f$, les solutions sont les fonctions $\displaystyle y_p + Ce^{ax}$ : « solution particulière + solutions de $\displaystyle y' = ay$ ».

Exemple : $\displaystyle y' = 2y - 4x$. On cherche une solution affine $\displaystyle y_p = \alpha x + \beta$ : $\displaystyle \alpha = 2(\alpha x + \beta) - 4x$ impose $\displaystyle 2\alpha - 4 = 0$ et $\displaystyle \alpha = 2\beta$, soit $\displaystyle \alpha = 2$, $\displaystyle \beta = 1$. Les solutions sont $\displaystyle y = Ce^{2x} + 2x + 1$.

⚠️ Attention : on utilise la condition initiale après avoir écrit la solution générale complète (avec la solution particulière), jamais sur la seule partie $\displaystyle Ce^{ax}$.

V. Modéliser

Loi de refroidissement de Newton : un café à $\displaystyle 90$ °C refroidit dans une pièce à $\displaystyle 20$ °C selon $\displaystyle T' = -0{,}1(T - 20)$ ($\displaystyle t$ en minutes), soit $\displaystyle T' = -0{,}1T + 2$. La solution constante est $\displaystyle 20$, donc $\displaystyle T(t) = 20 + Ce^{-0{,}1t}$ et $\displaystyle T(0) = 90$ donne $\displaystyle C = 70$.

[IMAGE_2]

Le café atteint $\displaystyle 40$ °C quand $\displaystyle 70e^{-0{,}1t} = 20$, soit $\displaystyle t = 10\ln 3{,}5 \approx 12{,}5$ minutes ; sa température tend vers $\displaystyle 20$ °C.

🏆 L’essentiel : $\displaystyle y' = ay \iff y = Ce^{ax}$ ; $\displaystyle y' = ay + b \iff y = Ce^{ax} - \frac{b}{a}$ ; $\displaystyle y' = ay + f$ : solution particulière $\displaystyle + Ce^{ax}$ ; une condition initiale détermine $\displaystyle C$ et donc une unique solution.
