=== Découverte - Sommes et échanges — premiers pas
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Calculer en posant si nécessaire ; expliquer les échanges.

1. Calculer $348+275$.
2. Calculer $348+275+125$.
3. Vérifier la somme précédente par un retrait de 125.

Étapes:
<!-- optitab:1 -->

## Question 1 : Calculer $348+275$

::: methode
Aligner unités, dizaines et centaines.
:::

::: etape Raisonnement
On compte dans la même unité : $348$ et $275$ unités. $8+5=13$ : on écrit 3 et on retient 1 au rang suivant. $4+7+1=12$ : on écrit 2 et on retient 1 au rang suivant. $3+2+1=6$ : on écrit 6. La somme vaut $623$ unités, soit $623$.
:::

::: resultat
$348+275=623$.
:::


## Question 2 : Calculer $348+275+125$

::: methode
Regrouper les sommes.
:::

::: etape Raisonnement
Les deux premiers nombres donnent $623$ ; ajouter 125 donne $748$.
:::

::: resultat
$348+275+125=748$.
:::


## Question 3 : Vérifier la somme précédente par un retrait de 125

::: methode
Utiliser une opération inverse.
:::

::: etape Raisonnement
$748-125=623$. On retrouve la somme des deux premiers nombres.
:::

::: resultat
Le contrôle donne $623$ : la somme est cohérente.
:::

Solution:
<!-- optitab:1 -->
1. $348+275=623$.
2. $348+275+125=748$.
3. Le contrôle donne $623$ : la somme est cohérente.

Effectuer les différences et contrôler.

1. Calculer $623-275$.

3. Comment vérifier la deuxième réponse ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Calculer $623-275$

::: methode
Soustraire en alignant les rangs.
:::

::: etape Raisonnement
On cherche ce qui manque à $275$ pour obtenir $623$. Comme $275+348=623$, la différence vaut $348$.
:::

::: resultat
$623-275=348$.
:::


## Question 2 : Calculer $1002-785$

::: methode
Échanger à travers les zéros.
:::

::: etape Raisonnement
On effectue les échanges depuis le premier rang disponible ; le retrait de 785 donne $217$.
:::

::: resultat
$1002-785=217$.
:::


## Question 3 : Comment vérifier la deuxième réponse ?

::: methode
Ajouter ce qui a été retiré.
:::

::: etape Raisonnement
$217+785=1002$. Le nombre de départ est retrouvé.
:::

::: resultat
Le contrôle par addition confirme la différence.
:::

Solution:
<!-- optitab:1 -->
1. $623-275=348$.
2. $1002-785=217$.
3. Le contrôle par addition confirme la différence.

=== Découverte - Produits et décomposition — premiers pas
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Décomposer le second facteur en dizaines et unités.

1. Calculer $24\times13$.
2. Calculer $24\times23$.
3. Un élève écrit $24\times13=96$. Expliquer son erreur.

Étapes:
<!-- optitab:1 -->

## Question 1 : Calculer $24\times13$

::: methode
Séparer dizaines et unités.
:::

::: etape Raisonnement
$24\times10=240$ et $24\times3=72$. On additionne ces deux produits : $240+72=312$.
:::

::: resultat
$24\times13=312$.
:::


## Question 2 : Calculer $24\times23$

::: methode
Ajouter dix groupes.
:::

::: etape Raisonnement
$24\times13=312$. Dix groupes supplémentaires valent $240$ ; le total est $312+240=552$.
:::

::: resultat
$24\times23=552$.
:::


## Question 3 : Un élève écrit $24\times13=96$. Expliquer son erreur

::: methode
Donner leur valeur aux dizaines.
:::

::: etape Raisonnement
Il a utilisé $1$ au lieu de $10$. La ligne des dizaines représente $10$ groupes.
:::

::: resultat
Le produit correct est $312$ ; la valeur des dizaines a été oubliée.
:::

Solution:
<!-- optitab:1 -->
1. $24\times13=312$.
2. $24\times23=552$.
3. Le produit correct est $312$ ; la valeur des dizaines a été oubliée.
