=== Découverte - La dictée des trois classes
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire en chiffres « sept-millions-huit-mille-trente ».
2. Lire $7\,008\,030$ en nommant les classes.
3. Peut-on supprimer les zéros de la classe des milliers ? Expliquer.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Séparer les classes et garder trois chiffres dans les classes intérieures.
:::

::: etape Raisonner avec les données
Les classes millions, milliers, unités sont 7, 008, 030. Les zéros occupent les rangs non prononcés.
:::

::: resultat 
$7\,008\,030$.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Lire de gauche à droite et omettre les classes nulles.
:::

::: etape Raisonner avec les données
La classe de gauche compte 7 millions. On lit ensuite 8 milliers puis 30 unités, sans prononcer les zéros de position.
:::

::: resultat 
« sept-millions-huit-mille-trente ».
:::

## Question 3 : Vérifier et conclure

::: methode 
Comparer la valeur des rangs avant toute suppression.
:::

::: etape Raisonner avec les données
Cette classe s’écrit 008 sur trois rangs. Enlever un zéro intérieur déplacerait les chiffres ; les espaces de classes ne sont pas des chiffres.
:::

::: resultat 
Non : ces zéros gardent les positions des chiffres.
:::

Solution:
<!-- optitab:1 -->
1. $7\,008\,030$.
2. « sept-millions-huit-mille-trente ».
3. Non : ces zéros gardent les positions des chiffres.
