## I. Compter une collection

::: definition
Pour savoir combien il y a d’objets, je touche chaque objet une seule fois. Le dernier nombre dit donne la quantité.
:::

## II. Zéro

::: propriete
Une boîte vide contient 0 objet. Je dis « zéro ». Je compte : 0 ; 1 ; 2 ; 3 ; 4 ; 5.
:::

## III. Représenter et conserver une quantité

::: propriete
Je peux dessiner autant de ronds que d’objets. Si je déplace les objets sans en ajouter ni en enlever, leur nombre ne change pas.
:::

::: methode Pour réussir
Je déplace les objets déjà comptés. Je ne compte pas deux fois le même.
:::

::: exemple
4 jetons déplacés restent 4 jetons. Une boîte vide contient 0 jeton.
:::

::: attention
Réciter les nombres ne suffit pas. Je touche chaque objet une seule fois.
:::

::: retenir
4 jetons déplacés restent 4 jetons. Une boîte vide contient 0 jeton.
:::
