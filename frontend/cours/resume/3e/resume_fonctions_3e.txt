Titre: Résumé : Fonctions, images et antécédents

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : vocabulaire des fonctions, calculs d'images et d'antécédents, tableaux, courbes et modélisation. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Le vocabulaire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$\displaystyle f(3) = 8$ : 8 est l'<span style="color:#e67e22;">image</span> de 3 ; 3 est un <span style="color:#2e7d32;">antécédent</span> de 8</p>
</div>
<p style="margin:0;">• Chaque entrée a <strong>une seule image</strong> ; un nombre peut avoir <strong>0, 1 ou plusieurs antécédents</strong>.</p>
<p style="margin:6px 0 0 0;">• <strong>Image</strong> → substituer dans la formule ; <strong>antécédent</strong> → résoudre l'équation $\displaystyle f(x) = b$.</p>
<p style="margin:6px 0 0 0;">• Ex. : $\displaystyle f(x) = x^2 + 1$ : 5 a deux antécédents ($\pm 2$), 0 n'en a aucun.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Tableaux et courbes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• <strong>Point sur la courbe :</strong> $\displaystyle A(a\ ;\ b)$ appartient à la courbe de $\displaystyle f$ ⟺ $\displaystyle f(a) = b$ (calcul, pas lecture !).</p>
[IMAGE_1]
<p style="margin:0;">• <strong>Lire une image :</strong> abscisse → courbe → ordonnée. <strong>Lire des antécédents :</strong> horizontale depuis l'ordonnée → TOUTES les intersections.</p>
<p style="margin:6px 0 0 0;">• Un tableau partiel ne donne ni les valeurs absentes, ni la forme de la courbe.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Modéliser</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">① Nommer la variable et son unité ; ② exprimer la quantité ($V(h) = 0{,}8h$…) ; ③ préciser le <strong>domaine de validité</strong> (longueur positive, durée bornée, nombre entier…).</p>
<p style="margin:6px 0 0 0;">• Intersection de deux courbes = entrées donnant la <strong>même image</strong> → résoudre $\displaystyle f(x) = g(x)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Confondre image et antécédent dans $\displaystyle f(a) = b$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Croire que $\displaystyle f(2)$ signifie $\displaystyle f \times 2$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier des antécédents lors d'une lecture (parcourir TOUTE la courbe).</p>
<p style="margin:6px 0 0 0;">4️⃣ Utiliser une lecture graphique approchée comme preuve exacte.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> « calculer l'image » → substituer ; « déterminer l'antécédent » → équation ; « le point appartient-il à la courbe ? » → calculer $\displaystyle f(a)$ et comparer à $\displaystyle b$.</p>
</div>
