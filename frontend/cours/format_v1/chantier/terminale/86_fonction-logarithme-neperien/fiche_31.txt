Titre: Résumé : Fonction logarithme népérien

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : définition, règles de calcul, dérivée, limites, résolution d’équations et de seuils. Programme de Terminale.
:::

## I. Définition et règles

::: formule
$y = \ln x \iff e^y = x \quad (x \gt 0)$
:::

1. $\ln 1 = 0$, $\ln e = 1$, $e^{\ln x} = x$ pour $x \gt 0$, $\ln\left(e^x\right) = x$ pour tout réel $x$.
2. $\ln(ab) = \ln a + \ln b$ ; $\ln\dfrac{a}{b} = \ln a - \ln b$ ; $\ln\left(a^n\right) = n\ln a$ ; $\ln\sqrt{a} = \dfrac{1}{2}\ln a$.
3. Courbes de $\exp$ et $\ln$ symétriques par rapport à la droite $y = x$.

## II. Étude de la fonction ln

::: tableau
x : 0, 1, +\infty
\ln'(x) = \frac{1}{x} : d, +, t, +,
\ln x : D-/-\infty, =/0, +/+\infty
:::

1. $(\ln x)' = \dfrac{1}{x}$ ; $(\ln u)' = \dfrac{u'}{u}$ (avec $u \gt 0$).
2. $\ln a \lt \ln b \iff a \lt b$ ; $\ln x \lt 0$ sur $]0\,;1[$, $\ln x \gt 0$ sur $]1\,;+\infty[$.
3. $\lim\limits_{x \to 0^+} \ln x = -\infty$ ; $\lim\limits_{x \to +\infty} \ln x = +\infty$.
4. Croissances comparées : $\dfrac{\ln x}{x} \to 0$ en $+\infty$ ; $x\ln x \to 0$ en $0^+$ ; $\dfrac{\ln(1 + x)}{x} \to 1$ en $0$.

[IMAGE_2]

## III. Équations et seuils

1. Ensemble de définition d’abord, puis $\ln A = \ln B \iff A = B$ et $\ln A \lt \ln B \iff A \lt B$.
2. Seuil : $q^n \gt A \iff n\ln q \gt \ln A$, puis on divise par $\ln q$ (sens inversé si $0 \lt q \lt 1$).

## IV. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Oublier le domaine : $\ln u$ exige $u \gt 0$.
2. Écrire $\ln(a + b) = \ln a + \ln b$.
3. Diviser par $\ln q \lt 0$ sans changer le sens de l’inégalité.
4. Oublier de vérifier que la solution trouvée appartient au domaine.
:::

::: remarque Réflexe
Inconnue en exposant → je « prends le logarithme » ; inconnue dans un $\ln$ → domaine, puis j’applique l’exponentielle.
:::
