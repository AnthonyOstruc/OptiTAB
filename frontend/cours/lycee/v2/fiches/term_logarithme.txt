<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Définition et règles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$y = \ln x \iff e^y = x$ ($x \gt 0$) ; $\ln(ab) = \ln a + \ln b$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $\ln 1 = 0$, $\ln e = 1$, $e^{\ln x} = x$, $\ln(e^x) = x$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\ln\frac{a}{b} = \ln a - \ln b$ ; $\ln(a^n) = n\ln a$ ; $\ln\sqrt{a} = \frac{1}{2}\ln a$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\ln a \lt \ln b \iff a \lt b$ (pour $a, b \gt 0$).</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Étude</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $(\ln x)' = \frac{1}{x}$ ; $(\ln u)' = \frac{u'}{u}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $\lim\limits_{0^+} \ln x = -\infty$ ; $\lim\limits_{+\infty} \ln x = +\infty$ ; $\frac{\ln x}{x} \to 0$ ; $x\ln x \to 0$ en $0^+$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Seuil : $q^n \gt A \iff n\ln q \gt \ln A$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Oublier le domaine : $\ln u$ exige $u \gt 0$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $\ln(a + b) = \ln a + \ln b$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Diviser par $\ln q \lt 0$ sans changer le sens de l’inégalité.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier de vérifier que la solution trouvée appartient au domaine.</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> inconnue en exposant → je « prends le ln » ; inconnue dans un ln → domaine, puis j’applique l’exponentielle.</p>
