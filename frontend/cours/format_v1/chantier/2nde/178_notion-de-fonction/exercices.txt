=== Entraînement - Fonctions pour un jeu de dé : gain, moyenne et fréquence
Id: 1942
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Dans un jeu, on mise une somme puis on lance un dé équilibré à six faces : si le dé donne $4$, $5$ ou $6$, on gagne la mise ; sinon, on la perd. On modélise ce jeu par la fonction suivante.

```python
from random import randint

def gain_jeu(mise):
    de = randint(1, 6)
    if de >= 4:
        return mise
    else:
        return -mise
```

1. Quel est l’argument de `gain_jeu` ? Que renvoie l’appel `gain_jeu(4)` si le dé donne $4$ ? si le dé donne $2$ ?
2. Écrire une fonction `gain_total` qui prend une mise `mise` et un nombre de parties `n`, et renvoie la somme des gains obtenus sur les `n` parties.
3. Compléter la fonction suivante pour qu’elle renvoie la moyenne de `n` lancers de dé, sans utiliser de liste.

   ```python
   def moyenne_des(n):
       s = 0
       for i in range(n):
           ...
       return ...
   ```

4. Cinq lancers donnent $3$, $1$, $6$, $2$, $3$. Calculer à la main la moyenne $m$, la variance $V$ et l’écart type $\sigma$ de cette série (arrondi au centième).

   Rappel :

   $$m = \frac{x_1 + \cdots + x_n}{n}$$

   $$V = \frac{x_1^2 + \cdots + x_n^2}{n} - m^2$$

5. Écrire une fonction `frequence_pair` qui prend un entier `n` et renvoie la **fréquence** d’apparition d’un nombre pair sur `n` lancers de dé.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire la fonction `gain_jeu`

::: methode
Repérer l’argument (entre parenthèses après `def`), puis suivre le test `if` pour savoir quel `return` est exécuté.
:::

::: etape Argument et valeur renvoyée
L’argument est `mise`. La fonction tire un entier `de` entre $1$ et $6$, puis renvoie `mise` (gain) si `de >= 4`, et `-mise` (perte) sinon.
:::

::: etape Si le dé donne 4
`mise` vaut $4$ et le test `4 >= 4` est **vrai** : la fonction exécute `return mise` et renvoie $4$.
:::

::: etape Si le dé donne 2
Le test `2 >= 4` est **faux** : la fonction exécute `return -mise` et renvoie $-4$.
:::

::: resultat
L’argument est `mise`. `gain_jeu(4)` renvoie $4$ si le dé donne $4$ (gain de $4$ €) et $-4$ si le dé donne $2$ (perte de $4$ €).
:::

::: attention
`>=` signifie « supérieur **ou égal** » : le cas `de` égal à $4$ est bien un gain.
:::

## Question 2 : Écrire `gain_total`

::: methode
Répéter `n` fois la partie avec une boucle `for` et ajouter chaque gain à un total initialisé à $0$.
:::

::: etape Entrées et sortie
Deux arguments : `mise` et `n`. Sortie : la somme des `n` gains.
:::

::: etape Accumuler les gains
On crée `total = 0` **avant** la boucle ; à chaque tour, on appelle `gain_jeu(mise)` et on ajoute son résultat à `total`.
:::

::: resultat
```python
def gain_total(mise, n):
    total = 0
    for i in range(n):
        g = gain_jeu(mise)
        total = total + g
    return total
```
:::

::: attention
Le `return total` est aligné avec le `for` : placé dans la boucle, il arrêterait la fonction après une seule partie.
:::

## Question 3 : Compléter `moyenne_des`

::: methode
Additionner les `n` lancers dans `s`, puis diviser par `n` après la boucle.
:::

::: etape Dans la boucle
À chaque tour, on lance le dé et on ajoute le résultat : `s = s + randint(1, 6)`.
:::

::: etape Après la boucle
La moyenne est la somme divisée par le nombre de lancers : `return s / n`.
:::

::: resultat
```python
def moyenne_des(n):
    s = 0
    for i in range(n):
        s = s + randint(1, 6)
    return s / n
```
:::

## Question 4 : Moyenne, variance et écart type à la main

::: methode
Calculer la somme des valeurs et la somme de leurs carrés, puis appliquer les formules du rappel avec $n = 5$.
:::

::: etape Moyenne
$$
\begin{aligned}
m &= \frac{3 + 1 + 6 + 2 + 3}{5} \\
&= \frac{15}{5} \\
&= 3
\end{aligned}
$$
:::

::: etape Somme des carrés
$$
\begin{aligned}
3^2 + 1^2 + 6^2 + 2^2 + 3^2 &= 9 + 1 + 36 + 4 + 9 \\
&= 59
\end{aligned}
$$
:::

::: etape Variance
$$
\begin{aligned}
V &= \frac{59}{5} - 3^2 \\
&= 11{,}8 - 9 \\
&= 2{,}8
\end{aligned}
$$
:::

::: etape Écart type
$$\sigma = \sqrt{2{,}8} \approx 1{,}67$$
:::

::: resultat
$m = 3$, $V = 2{,}8$ et $\sigma \approx 1{,}67$.
:::

::: attention
On soustrait le **carré de la moyenne** ($3^2 = 9$), pas la moyenne elle-même.
:::

## Question 5 : Écrire `frequence_pair`

::: methode
Compter les lancers pairs avec un compteur, puis diviser par `n`.
:::

::: etape Tester la parité
Un entier `de` est pair lorsque le reste de sa division par $2$ est nul : `de % 2 == 0`.
:::

::: etape Compter puis diviser
Compteur `k = 0` avant la boucle ; on ajoute $1$ à chaque lancer pair ; on renvoie `k / n`.
:::

::: resultat
```python
def frequence_pair(n):
    k = 0
    for i in range(n):
        de = randint(1, 6)
        if de % 2 == 0:
            k = k + 1
    return k / n
```
:::

::: point Ce que renvoie la fonction
Chaque point de la courbe ci-dessous est la valeur renvoyée par un appel `frequence_pair(n)`, pour $n = 10$, $20$, …, $3\,000$ : les valeurs fluctuent beaucoup pour $n$ petit, puis se resserrent autour de $0{,}5$.
:::

[IMAGE_1]

::: retenir
La probabilité d’obtenir un nombre pair est $\frac{3}{6} = 0{,}5$ : pour $n$ grand, `frequence_pair(n)` renvoie une valeur proche de $0{,}5$.
:::

Solution:
<!-- optitab:1 -->
1. Argument : `mise`. `gain_jeu(4)` renvoie $4$ si le dé donne $4$, et $-4$ si le dé donne $2$.
2. Boucle de `n` tours qui ajoute `gain_jeu(mise)` à `total` (initialisé à $0$), puis `return total`.
3. Dans la boucle : `s = s + randint(1, 6)` ; après la boucle : `return s / n`.
4. $m = 3$, $V = 2{,}8$, $\sigma \approx 1{,}67$.
5. Compteur des lancers vérifiant `de % 2 == 0`, puis `return k / n`.

Énoncé:

On écrit et on utilise des fonctions Python à un seul argument.

1. Écrire une fonction `triple` qui prend un nombre `x` en argument et renvoie son triple.
2. Que renvoie l’appel `triple(4)` ? Que vaut `y` après l’instruction `y = triple(4) + 1` ?
3. Un élève écrit la fonction ci-dessous. Il exécute `y = triple_b(4)` : l’écran affiche `12`. Que contient la variable `y` ? Expliquer la différence entre `return` et `print`.

   ```python
   def triple_b(x):
   ```

4. On considère la fonction suivante. Que renvoie `suivant(10)` ?

   ```python
   def suivant(n):
   ```

## Question 1 : Écrire la fonction `triple`

En-tête `def nom(argument):`, puis un bloc indenté qui se termine par `return`.

La fonction s’appelle `triple` et reçoit un nombre `x` : `def triple(x):`.

Le triple de `x` s’écrit `3 * x` ; on le renvoie avec `return`.

```python
def triple(x):
```

## Question 2 : Appeler `triple`

::: etape Ce que fait triple_b(4)

::: etape Contenu de y
`y` reçoit la valeur renvoyée, donc `None`. Le calcul `triple_b(4) + 1` provoquerait une erreur.

[IMAGE_2]

`y` contient `None`. `return` renvoie une valeur réutilisable (variable, calcul) ; `print` ne fait que l’afficher.

Une fonction qui calcule un résultat doit le **renvoyer** avec `return`.

## Question 4 : Que renvoie `suivant(10)` ?

## Question 5 : Écrire la fonction `carre`

```python
def carre(x):
```

=== Découverte - Écrire et appeler une fonction à plusieurs arguments
Id: 1937
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On travaille avec des fonctions Python à plusieurs arguments.

1. Écrire une fonction `somme` qui prend deux nombres `a` et `b` et renvoie leur somme. Que renvoie `somme(7, 5)` ?
2. On considère la fonction suivante. Que renvoie `affine(3, -1, 4)` ?

   ```python
   def affine(a, b, x):
       return a * x + b
   ```

3. Que renvoie `affine(-1, 4, 3)` ? Pourquoi le résultat est-il différent de celui de la question 2, alors que ce sont les mêmes nombres ?
4. Écrire l’appel de `affine` qui calcule l’image de $5$ par la fonction $g : x \mapsto 2x - 7$, puis donner le résultat.
5. Écrire une fonction `aire_rectangle` qui prend la longueur `L` et la largeur `l` d’un rectangle et renvoie son aire. Que renvoie `aire_rectangle(8, 2.5)` ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Écrire et appeler `somme`

::: methode
Les arguments sont séparés par des virgules, dans l’en-tête comme dans l’appel.
:::

::: etape Écrire la fonction
```python
def somme(a, b):
    return a + b
```
:::

::: etape Appel somme(7, 5)
`a` prend la valeur $7$ et `b` la valeur $5$ : la fonction renvoie $7 + 5 = 12$.
:::

::: resultat
`somme(7, 5)` renvoie $12$.
:::

## Question 2 : Appel `affine(3, -1, 4)`

::: methode
Affecter les valeurs aux arguments **dans l’ordre** : premier argument `a`, deuxième `b`, troisième `x`.
:::

::: etape Affectation des arguments
`a` vaut $3$, `b` vaut $-1$ et `x` vaut $4$.
:::

::: etape Calcul
$$3 \times 4 + (-1) = 12 - 1 = 11$$
:::

::: resultat
`affine(3, -1, 4)` renvoie $11$.
:::

## Question 3 : Appel `affine(-1, 4, 3)`

::: methode
Même méthode : on affecte les valeurs dans l’ordre des arguments.
:::

::: etape Affectation des arguments
Cette fois, `a` vaut $-1$, `b` vaut $4$ et `x` vaut $3$.
:::

::: etape Calcul
$$(-1) \times 3 + 4 = -3 + 4 = 1$$
:::

::: resultat
`affine(-1, 4, 3)` renvoie $1$, et non $11$ : chaque valeur va à l’argument de **même position**. En changeant l’ordre, on calcule une autre expression.
:::

[IMAGE_1]

::: attention
Python ne « devine » pas quel nombre est `a`, `b` ou `x` : seule la position dans l’appel compte.
:::

## Question 4 : Image de 5 par $g$

::: methode
Identifier $a$ et $b$ dans l’écriture $g(x) = ax + b$, puis respecter l’ordre `affine(a, b, x)`.
:::

::: etape Identifier a et b
$g(x) = 2x - 7 = 2x + (-7)$ : $a = 2$ et $b = -7$ ; on veut l’image de $x = 5$.
:::

::: etape Appel et calcul
L’appel est `affine(2, -7, 5)`, qui calcule $2 \times 5 - 7 = 3$.
:::

::: resultat
`affine(2, -7, 5)` renvoie $3$ : l’image de $5$ par $g$ est $3$.
:::

## Question 5 : Écrire `aire_rectangle`

::: methode
L’aire d’un rectangle est longueur $\times$ largeur.
:::

::: etape Écrire la fonction
```python
def aire_rectangle(L, l):
    return L * l
```
:::

::: etape Appel aire_rectangle(8, 2.5)
$8 \times 2{,}5 = 20$ ; Python l’affiche `20.0` car $2{,}5$ s’écrit `2.5` (nombre décimal).
:::

::: resultat
`aire_rectangle(8, 2.5)` renvoie $20$ (affiché `20.0`).
:::

Solution:
<!-- optitab:1 -->
1. `def somme(a, b):` puis `return a + b` ; `somme(7, 5)` renvoie $12$.
2. `affine(3, -1, 4)` renvoie $3 \times 4 - 1 = 11$.
3. `affine(-1, 4, 3)` renvoie $-3 + 4 = 1$ : les valeurs sont affectées aux arguments dans l’ordre, l’ordre compte.
4. `affine(2, -7, 5)` renvoie $3$.
5. `def aire_rectangle(L, l):` puis `return L * l` ; `aire_rectangle(8, 2.5)` renvoie `20.0`.

=== Découverte - Exécuter une fonction à la main
Id: 1938
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On exécute « à la main » des fonctions Python, ligne par ligne.

1. On donne la fonction ci-dessous. Que renvoie `mystere(2)` ?

   ```python
   def mystere(x):
       y = x + 5
       y = y * 3
       return y
   ```

2. Quelle fonction mathématique la fonction `mystere` programme-t-elle ? Donner son expression développée.
3. On donne la fonction ci-dessous. Que renvoie `calcul(7, 3)` ?

   ```python
   def calcul(a, b):
       s = a + b
       d = a - b
       return s * d
   ```

4. Quelle expression de $a$ et $b$ la fonction `calcul` renvoie-t-elle ? La simplifier et vérifier avec la question 3.
5. On propose la fonction ci-dessous. Que renvoie `double_puis_ajoute(4, 10)` ?

   ```python
   def double_puis_ajoute(x, y):
       x = x * 2
       return x + y
   ```

Étapes:
<!-- optitab:1 -->
## Question 1 : Exécuter `mystere(2)`

::: methode
Suivre les instructions dans l’ordre en notant la valeur de chaque variable.
:::

::: etape Ligne y = x + 5
`x` vaut $2$, donc `y` vaut $2 + 5 = 7$.
:::

::: etape Ligne y = y * 3
La nouvelle valeur de `y` est l’ancienne multipliée par $3$ : $7 \times 3 = 21$.
:::

::: resultat
`mystere(2)` renvoie $21$.

## Question 2 : Expression mathématique de `mystere`

Traduire chaque instruction en calcul, puis enchaîner les calculs.

::: etape Enchaîner les opérations
On ajoute $5$ à $x$, puis on multiplie le résultat par $3$ : on obtient $3(x + 5)$.

::: etape Développer
$$3(x + 5) = 3x + 15$$
Vérification : pour $x = 2$, $3 \times 2 + 15 = 21$.

|---|---|
| $-6$ | $-3$ |
| $-5$ | $0$ |

| $-2$ | $9$ |

| $0$ | $15$ |

`mystere` programme la fonction $x \mapsto 3(x + 5) = 3x + 15$.

Remplacer `s` et `d` par leurs expressions, puis reconnaître une identité remarquable.

## Question 5 : Exécuter `double_puis_ajoute(4, 10)`

Une affectation peut modifier un argument à l’intérieur de la fonction.

`x` vaut d’abord $4$ ; après cette ligne, `x` vaut $4 \times 2 = 8$.

   ```python
   def aire_triangle(b, h):
   ```

   ```python
   def f(x):
   ```

<!-- optitab:1 -->
## Question 1 : Compléter `perimetre`

::: methode
Traduire la formule $P = 2\pi r$ avec `*` pour chaque produit.
:::

::: etape Écrire le return
$2\pi r$ s’écrit `2 * pi * r` ; `pi` est disponible grâce à `from math import pi`.
:::

::: etape Tester avec r = 5
$2 \times \pi \times 5 = 10\pi \approx 31{,}42$.
:::

::: resultat
```python
from math import pi

def perimetre(r):
    return 2 * pi * r
```

`perimetre(5)` renvoie environ $31{,}42$.
:::

## Question 2 : Corriger `aire_triangle`

::: methode
Comparer avec la formule $\mathcal{A} = \dfrac{b \times h}{2}$ et avec un cas connu.
:::

::: etape Repérer l’erreur
Pour $b = 4$ et $h = 3$, l’aire vaut $\dfrac{4 \times 3}{2} = 6$, mais la fonction renvoie $12$ : la division par $2$ manque.
:::

::: resultat
```python
def aire_triangle(b, h):
    return b * h / 2
```

`aire_triangle(4, 3)` renvoie alors `6.0`.

Tester une fonction sur un cas dont on connaît la réponse permet de détecter ce type d’erreur.

## Question 3 : Exécuter `f` et trouver son expression

::: methode
Remplacer `x` par la valeur et suivre les trois affectations de `y`.

=== Entraînement - Comprendre une fonction qui renvoie une moyenne et un écart type
Id: 1941
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La fonction suivante simule `n` lancers d’un dé et renvoie la moyenne et l’écart type des résultats, **sans utiliser de liste**.

```python

    s = 0
    s2 = 0
    for i in range(n):
        x = randint(1, 6)

        s2 = s2 + x * x
    m = s / n
    v = s2 / n - m * m
    e = v ** 0.5
    return m, e
```

1. Quel est le rôle de chacune des variables `s`, `s2`, `x`, `m`, `v` et `e` ?
2. Pourquoi n’a-t-on pas besoin de liste pour calculer la moyenne et l’écart type ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Rôle des variables

::: methode
Regarder où chaque variable est créée et comment elle est modifiée.
:::

::: etape Avant et pendant la boucle
- `s` : somme des résultats, augmentée de `x` à chaque tour ;
- `s2` : somme des carrés des résultats, augmentée de `x * x` ;
- `x` : résultat du lancer en cours (entier de $1$ à $6$).
:::

::: etape Après la boucle
- `m` : moyenne $\dfrac{s}{n}$ ;
- `v` : variance $\dfrac{s_2}{n} - m^2$ ;
- `e` : écart type $\sqrt{v}$ (`** 0.5` calcule une racine carrée).

::: resultat
`s` et `s2` accumulent la somme et la somme des carrés, `x` est le lancer, `m` la moyenne, `v` la variance, `e` l’écart type.

## Question 2 : Pourquoi pas de liste ?

::: methode
Regarder de quoi ont besoin les formules de la moyenne et de la variance.
:::

::: etape Ce qu’utilisent les formules
$$m = \frac{x_1 + \cdots + x_n}{n}$$

$$V = \frac{x_1^2 + \cdots + x_n^2}{n} - m^2$$

Ces formules n’utilisent que **deux sommes** et le nombre $n$.
:::

::: resultat
Il suffit d’accumuler la somme et la somme des carrés au fil de la boucle : inutile de conserver chaque résultat dans une liste.

## Question 5 : Ajouter un argument `p`

::: methode
Remplacer la valeur fixe $0{,}7$ par un argument `p`, et transmettre `p` d’une fonction à l’autre.
:::

::: etape Lancer de probabilité p
```python
def lancer_franc(p):
    if random() < p:
        return 1
    return 0
```
:::

::: etape Répétition
```python
def nb_reussites(n, p):
    k = 0
    for i in range(n):
        r = lancer_franc(p)
        k = k + r
    return k
```
:::

::: resultat
L’appel `nb_reussites(500, 0.85)` simule $500$ lancers de la seconde joueuse ; il renvoie un entier proche de $500 \times 0{,}85 = 425$.
:::

::: attention
Dans le code, la virgule décimale s’écrit avec un point : `0.85`. Avec `0,85`, Python verrait deux arguments `0` et `85`, et l’appel provoquerait une erreur.
:::

Solution:
<!-- optitab:1 -->
1. `random()` tombe dans ${[0\,;0{,}7[}$, de longueur $0{,}7$, avec la probabilité $0{,}7$.
2. `if random() < 0.7:` `return 1`, sinon `return 0`.
3. Boucle de `n` tours qui ajoute `lancer_franc()` à `k`, puis `return k`.
4. `return nb_reussites(n) / n` ; pour `n` égal à $3\,000$, valeur proche de $0{,}7$.
5. `lancer_franc(p)` teste `random() < p` ; `nb_reussites(n, p)` appelle `lancer_franc(p)` ; appel : `nb_reussites(500, 0.85)`.

=== Découverte - Repérer et corriger les erreurs classiques
Id: 3742
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Chacune des fonctions suivantes contient **une** erreur. Pour chacune, expliquer ce qui se passe lors de l’appel indiqué, puis corriger la fonction. On suppose que `randint` a été importée, sauf à la question 4.

1. On exécute `y = double(5) + 1`.

   ```python
   def double(x):
       print(2 * x)
   ```

2. On appelle `nb_six(600)` pour compter les $6$ obtenus en $600$ lancers.

   ```python
   def nb_six(n):
       for i in range(n):
           k = 0
           if randint(1, 6) == 6:
               k = k + 1
       return k
   ```

3. On appelle `somme_des(10)` pour additionner $10$ lancers de dé.

   ```python
   def somme_des(n):
       s = 0
       for i in range(n):
           s = s + randint(1, 6)
           return s
   ```

4. Dans un fichier qui ne contient aucune ligne `import`, on appelle `de()`.

   ```python
   def de():
       return randint(1, 6)
   ```

5. On appelle `moyenne(4, 6)`.

   ```python
   def moyenne(a, b):
       return a + b / 2
   ```

Étapes:
<!-- optitab:1 -->
## Question 1 : `print` au lieu de `return`

::: methode
Se demander ce que la fonction **renvoie**, pas ce qu’elle affiche.
:::

::: etape Ce qui se passe
`double(5)` affiche `10`, mais ne renvoie rien (la valeur `None`). Le calcul `None + 1` provoque une erreur.
:::

[IMAGE_1]

::: resultat
```python
def double(x):
    return 2 * x
```

Alors `y` vaut $11$.
:::

## Question 2 : Compteur dans la boucle

::: methode
Suivre la valeur de `k` d’un tour à l’autre.
:::

::: etape Ce qui se passe
La ligne `k = 0` est exécutée **à chaque tour** : le compteur repart de $0$. À la fin, `k` vaut $1$ si le dernier lancer est un $6$, et $0$ sinon.
:::

::: resultat
```python
def nb_six(n):
    k = 0
    for i in range(n):
        if randint(1, 6) == 6:
            k = k + 1
    return k
```

`k = 0` est placé **avant** la boucle ; `nb_six(600)` renvoie alors un entier proche de $100$.
:::

## Question 3 : `return` dans la boucle

::: methode
Regarder l’indentation du `return` : est-il dans la boucle ou après ?
:::

::: etape Ce qui se passe
Le `return s` est indenté sous le `for` : il est exécuté dès le premier tour, et la fonction s’arrête. `somme_des(10)` renvoie le résultat d’**un seul** lancer.
:::

::: resultat
```python
def somme_des(n):
    s = 0
    for i in range(n):
        s = s + randint(1, 6)
    return s
```

Le `return` est aligné avec le `for` : il est exécuté une fois la boucle terminée.
:::

## Question 4 : Import oublié

::: methode
Toute fonction d’un module doit être importée avant d’être utilisée.
:::

::: etape Ce qui se passe
Python ne connaît pas `randint` : l’appel `de()` provoque une erreur `NameError`, accompagnée du message « name 'randint' is not defined » (le nom `randint` n’est pas défini).
:::

::: resultat
```python
from random import randint

def de():
    return randint(1, 6)
```
:::

## Question 5 : Priorités opératoires

::: methode
En Python comme en mathématiques, la division est prioritaire sur l’addition.
:::

::: etape Ce qui se passe
`a + b / 2` calcule $a + \dfrac{b}{2}$ : `moyenne(4, 6)` renvoie `7.0` ($4 + 3 = 7$) au lieu de $\dfrac{4 + 6}{2} = 5$.
:::

::: resultat
```python
def moyenne(a, b):
    return (a + b) / 2
```

`moyenne(4, 6)` renvoie alors `5.0`.
:::

::: retenir
Toujours tester une fonction sur un cas simple dont on connaît la réponse : les cinq erreurs ci-dessus se repèrent ainsi immédiatement.
:::

Solution:
<!-- optitab:1 -->
1. `double` affiche mais renvoie `None` : remplacer `print(2 * x)` par `return 2 * x`.
2. `k = 0` est dans la boucle : le placer avant le `for`.
3. `return s` est dans la boucle : l’aligner avec le `for`.
4. `randint` n’est pas importée : ajouter `from random import randint`.
5. Priorité de la division : écrire `return (a + b) / 2`.
