=== Découverte - Nommer les côtés par rapport à un angle
Id: 2380
Difficulté: easy
Image: trigonometrie_3e_angle.png

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$.

[IMAGE_1]

1. Quel est le nom de l'hypoténuse ? Pourquoi ?
2. Pour l'angle $\widehat{ABC}$, nommer le côté adjacent et le côté opposé.
3. Pour l'angle $\widehat{ACB}$, nommer le côté adjacent et le côté opposé.
4. Que remarque-t-on en comparant les réponses aux questions 2 et 3 ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'hypoténuse

::: methode
L'hypoténuse est le côté situé en face de l'angle droit.
:::

::: etape Repérer l'angle droit
L'angle droit est en $A$. Le côté qui ne passe pas par $A$ est $[BC]$.
:::

::: resultat
L'hypoténuse est $[BC]$ : c'est le côté opposé à l'angle droit, le plus long du triangle.
:::

## Question 2 : Pour l'angle $\widehat{ABC}$

::: methode
Les deux autres côtés sont les côtés de l'angle droit : celui qui passe par le sommet $B$ est adjacent, l'autre est opposé.
:::

::: etape Regarder le sommet $B$
- $[AB]$ passe par $B$ : il est **adjacent** à $\widehat{ABC}$.
- $[AC]$ ne passe pas par $B$ : il est **opposé** à $\widehat{ABC}$.
:::

[IMAGE_2]

::: resultat
Pour $\widehat{ABC}$ : côté adjacent $[AB]$, côté opposé $[AC]$.
:::

## Question 3 : Pour l'angle $\widehat{ACB}$

::: etape Regarder le sommet $C$
- $[AC]$ passe par $C$ : il est **adjacent** à $\widehat{ACB}$.
- $[AB]$ ne passe pas par $C$ : il est **opposé** à $\widehat{ACB}$.
:::

[IMAGE_3]

::: resultat
Pour $\widehat{ACB}$ : côté adjacent $[AC]$, côté opposé $[AB]$.
:::

## Question 4 : Comparaison

::: resultat
Le côté adjacent et le côté opposé s'échangent quand on change d'angle ; l'hypoténuse $[BC]$ reste la même.
:::

::: attention Erreur fréquente
Dire « $[AB]$ est le côté adjacent » sans préciser l'angle : cette phrase n'a de sens que pour un angle donné.
:::

Solution:
<!-- optitab:1 -->
1. $[BC]$, le côté opposé à l'angle droit.
2. Adjacent : $[AB]$ ; opposé : $[AC]$.
3. Adjacent : $[AC]$ ; opposé : $[AB]$.
4. Adjacent et opposé s'échangent ; l'hypoténuse ne change pas.

=== Découverte - Écrire les trois rapports
Id: 2381
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $DEF$ est rectangle en $E$, avec $DE = 8$ cm, $EF = 6$ cm et $DF = 10$ cm.

[IMAGE_1]

1. Pour l'angle $\widehat{EDF}$, nommer l'hypoténuse, le côté adjacent et le côté opposé.
2. Écrire $\cos \widehat{EDF}$, $\sin \widehat{EDF}$ et $\tan \widehat{EDF}$ sous forme de fractions, puis en écriture décimale.
3. En déduire la mesure de l'angle $\widehat{EDF}$, arrondie au degré.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les côtés pour l'angle $\widehat{EDF}$

::: etape Nommer les côtés
- L'angle droit est en $E$ : l'hypoténuse est $[DF]$.
- $[DE]$ passe par $D$ : c'est le côté adjacent.
- $[EF]$ ne passe pas par $D$ : c'est le côté opposé.
:::

[IMAGE_2]

::: resultat
Hypoténuse $[DF]$, côté adjacent $[DE]$, côté opposé $[EF]$.
:::

## Question 2 : Les trois rapports

::: methode
CAH SOH TOA : cosinus = adjacent sur hypoténuse, sinus = opposé sur hypoténuse, tangente = opposé sur adjacent.
:::

::: etape Cosinus
$$\cos \widehat{EDF} = \frac{DE}{DF} = \frac{8}{10} = 0{,}8$$
:::

::: etape Sinus
$$\sin \widehat{EDF} = \frac{EF}{DF} = \frac{6}{10} = 0{,}6$$
:::

::: etape Tangente
$$\tan \widehat{EDF} = \frac{EF}{DE} = \frac{6}{8} = 0{,}75$$
:::

::: resultat
$\cos \widehat{EDF} = 0{,}8$ ; $\sin \widehat{EDF} = 0{,}6$ ; $\tan \widehat{EDF} = 0{,}75$.
:::

## Question 3 : La mesure de l'angle

::: methode
On utilise la touche $\cos^{-1}$ de la calculatrice, en mode degrés.
:::

::: etape Calcul
$\widehat{EDF} = \cos^{-1}(0{,}8) \approx 36{,}87^\circ$.

On obtient la même valeur avec $\sin^{-1}(0{,}6)$ ou $\tan^{-1}(0{,}75)$ : les trois rapports décrivent le même angle.
:::

::: resultat
$\widehat{EDF} \approx 37^\circ$.
:::

::: attention Erreur fréquente
Écrire $\tan \widehat{EDF} = \dfrac{DE}{EF}$ : la tangente est l'opposé **sur** l'adjacent, pas l'inverse.
:::

Solution:
<!-- optitab:1 -->
1. Hypoténuse $[DF]$, adjacent $[DE]$, opposé $[EF]$.
2. $\cos \widehat{EDF} = \frac{8}{10} = 0{,}8$ ; $\sin \widehat{EDF} = \frac{6}{10} = 0{,}6$ ; $\tan \widehat{EDF} = \frac{6}{8} = 0{,}75$.
3. $\widehat{EDF} \approx 37^\circ$.

=== Découverte - Calculer un côté opposé avec le sinus
Id: 2382
Difficulté: easy
Image: trigonometrie_3e_30.png

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $\widehat{ABC} = 40^\circ$ et $BC = 8$ cm.

[IMAGE_1]

1. Pour l'angle $\widehat{ABC}$, le côté $[AC]$ est-il adjacent ou opposé ? Et $[BC]$ ?
2. Quel rapport trigonométrique relie $AC$ et $BC$ ?
3. Calculer $AC$, arrondi au millimètre.
4. Calculer $AB$, arrondi au millimètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Nommer les côtés

::: etape Par rapport à $\widehat{ABC}$
- $[AC]$ ne passe pas par $B$ : c'est le côté **opposé**.
- $[BC]$ est en face de l'angle droit : c'est l'**hypoténuse**.
:::

::: resultat
$[AC]$ est le côté opposé à $\widehat{ABC}$ et $[BC]$ est l'hypoténuse.
:::

## Question 2 : Choisir le rapport

::: methode
Opposé et hypoténuse : SOH, c'est le sinus.
:::

::: resultat
$$\sin \widehat{ABC} = \frac{AC}{BC}$$
:::

## Question 3 : Calculer $AC$

::: etape Remplacer puis isoler $AC$
$$
\begin{aligned}
\sin 40^\circ &= \frac{AC}{8} \\
AC &= 8 \times \sin 40^\circ \\
AC &\approx 5{,}142
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$AC \approx 5{,}1$ cm.
:::

## Question 4 : Calculer $AB$

::: methode
$[AB]$ est le côté adjacent à $\widehat{ABC}$ : avec l'hypoténuse, on utilise le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos 40^\circ &= \frac{AB}{8} \\
AB &= 8 \times \cos 40^\circ \approx 6{,}128
\end{aligned}
$$
:::

::: resultat
$AB \approx 6{,}1$ cm.
:::

::: attention Erreur fréquente
Calculatrice en mode radians : elle affiche alors $8 \times \sin 40 \approx 5{,}96$. Vérifier le mode **degrés** avant tout calcul.
:::

Solution:
<!-- optitab:1 -->
1. $[AC]$ est opposé, $[BC]$ est l'hypoténuse.
2. $\sin \widehat{ABC} = \frac{AC}{BC}$
3. $AC = 8 \times \sin 40^\circ \approx 5{,}1$ cm
4. $AB = 8 \times \cos 40^\circ \approx 6{,}1$ cm

=== Découverte - Calculer un côté adjacent avec le cosinus
Id: 2383
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $EFG$ est rectangle en $F$, avec $\widehat{FEG} = 52^\circ$ et $EG = 7{,}5$ cm.

[IMAGE_1]

1. Pour l'angle $\widehat{FEG}$, nommer l'hypoténuse, le côté adjacent et le côté opposé.
2. Calculer $EF$, arrondi au millimètre.
3. Calculer $FG$, arrondi au millimètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Nommer les côtés

::: etape Par rapport à $\widehat{FEG}$
- L'angle droit est en $F$ : l'hypoténuse est $[EG]$.
- $[EF]$ passe par $E$ : c'est le côté adjacent.
- $[FG]$ ne passe pas par $E$ : c'est le côté opposé.
:::

::: resultat
Hypoténuse $[EG]$, adjacent $[EF]$, opposé $[FG]$.
:::

## Question 2 : Calculer $EF$

::: methode
Adjacent et hypoténuse : CAH, c'est le cosinus.
:::

::: etape Calcul
$$
\begin{aligned}
\cos \widehat{FEG} &= \frac{EF}{EG} \\
\cos 52^\circ &= \frac{EF}{7{,}5} \\
EF &= 7{,}5 \times \cos 52^\circ \approx 4{,}617
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$EF \approx 4{,}6$ cm.
:::

## Question 3 : Calculer $FG$

::: methode
Opposé et hypoténuse : SOH, c'est le sinus.
:::

::: etape Calcul
$$
\begin{aligned}
\sin 52^\circ &= \frac{FG}{7{,}5} \\
FG &= 7{,}5 \times \sin 52^\circ \approx 5{,}910
\end{aligned}
$$
:::

::: resultat
$FG \approx 5{,}9$ cm.
:::

::: retenir
Contrôle : les deux côtés de l'angle droit ($4{,}6$ cm et $5{,}9$ cm) sont bien plus courts que l'hypoténuse ($7{,}5$ cm).
:::

::: attention Erreur fréquente
Utiliser le sinus pour $EF$ : $[EF]$ touche le sommet $E$ de l'angle, il est adjacent, donc c'est le cosinus.
:::

Solution:
<!-- optitab:1 -->
1. Hypoténuse $[EG]$, adjacent $[EF]$, opposé $[FG]$.
2. $EF = 7{,}5 \times \cos 52^\circ \approx 4{,}6$ cm
3. $FG = 7{,}5 \times \sin 52^\circ \approx 5{,}9$ cm

=== Découverte - Calculer l'hypoténuse
Id: 2384
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $KLM$ est rectangle en $K$, avec $\widehat{KLM} = 34^\circ$ et $KL = 6$ cm.

[IMAGE_1]

1. Quel rapport trigonométrique relie $KL$ et l'hypoténuse $LM$ ?
2. Calculer $LM$, arrondi au millimètre.
3. Calculer $KM$, arrondi au millimètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Choisir le rapport

::: etape Nommer les côtés par rapport à $\widehat{KLM}$
$[KL]$ passe par $L$ : c'est le côté adjacent. $[LM]$ est l'hypoténuse.
:::

::: resultat
Adjacent et hypoténuse : on utilise le cosinus, $\cos \widehat{KLM} = \dfrac{KL}{LM}$.
:::

## Question 2 : Calculer $LM$

::: methode
La longueur cherchée est au **dénominateur** : on multiplie en croix, puis on divise.
:::

::: etape Calcul
$$
\begin{aligned}
\cos 34^\circ &= \frac{6}{LM} \\
LM \times \cos 34^\circ &= 6 \\
LM &= \frac{6}{\cos 34^\circ} \approx 7{,}237
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$LM \approx 7{,}2$ cm.
:::

## Question 3 : Calculer $KM$

::: methode
$[KM]$ est opposé à $\widehat{KLM}$ et on connaît le côté adjacent $KL$ : c'est la tangente.
:::

::: etape Calcul
$$
\begin{aligned}
\tan 34^\circ &= \frac{KM}{6} \\
KM &= 6 \times \tan 34^\circ \approx 4{,}047
\end{aligned}
$$
:::

::: resultat
$KM \approx 4{,}0$ cm.
:::

::: attention Erreur fréquente
Écrire $LM = 6 \times \cos 34^\circ \approx 5{,}0$ : on trouverait une hypoténuse plus courte que $KL$, ce qui est impossible. Quand l'inconnue est au dénominateur, on **divise**.
:::

Solution:
<!-- optitab:1 -->
1. Le cosinus : $\cos \widehat{KLM} = \frac{KL}{LM}$.
2. $LM = \frac{6}{\cos 34^\circ} \approx 7{,}2$ cm
3. $KM = 6 \times \tan 34^\circ \approx 4{,}0$ cm

=== Découverte - Calculer un angle avec le cosinus
Id: 2385
Difficulté: easy
Image: trigonometrie_3e_angle.png

Énoncé:
<!-- optitab:1 -->
Le triangle $IJK$ est rectangle en $J$, avec $IJ = 5$ cm et $IK = 8$ cm.

[IMAGE_1]

1. Calculer $\cos \widehat{JIK}$.
2. En déduire la mesure de l'angle $\widehat{JIK}$, arrondie au degré.
3. Calculer la mesure de l'angle $\widehat{IKJ}$, arrondie au degré.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le cosinus de $\widehat{JIK}$

::: etape Nommer les côtés par rapport à $\widehat{JIK}$
$[IJ]$ passe par $I$ : c'est le côté adjacent. $[IK]$, en face de l'angle droit, est l'hypoténuse.
:::

::: resultat
$$\cos \widehat{JIK} = \frac{IJ}{IK} = \frac{5}{8} = 0{,}625$$
:::

## Question 2 : La mesure de $\widehat{JIK}$

::: methode
On connaît le cosinus : on retrouve l'angle avec la touche $\cos^{-1}$ (mode degrés).
:::

::: etape Calculatrice
$\widehat{JIK} = \cos^{-1}(0{,}625) \approx 51{,}32^\circ$.
:::

[IMAGE_2]

::: resultat
$\widehat{JIK} \approx 51^\circ$.
:::

## Question 3 : La mesure de $\widehat{IKJ}$

::: methode
Les deux angles aigus d'un triangle rectangle ont pour somme $90^\circ$. On part de la valeur non arrondie.
:::

::: etape Calcul
$\widehat{IKJ} \approx 90^\circ - 51{,}32^\circ = 38{,}68^\circ$.

Contrôle : $[IJ]$ est opposé à $\widehat{IKJ}$, donc $\sin \widehat{IKJ} = \dfrac{5}{8}$ et $\sin^{-1}(0{,}625) \approx 38{,}68^\circ$.
:::

::: resultat
$\widehat{IKJ} \approx 39^\circ$.
:::

::: attention Erreur fréquente
Taper $\cos(0{,}625)$ au lieu de $\cos^{-1}(0{,}625)$ : on cherche l'angle dont le cosinus vaut $0{,}625$, il faut la touche inverse.
:::

Solution:
<!-- optitab:1 -->
1. $\cos \widehat{JIK} = \frac{5}{8} = 0{,}625$
2. $\widehat{JIK} \approx 51^\circ$
3. $\widehat{IKJ} \approx 39^\circ$

=== Découverte - Choisir le bon rapport
Id: 2386
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Le triangle $RST$ est rectangle en $S$ et $\widehat{SRT} = 28^\circ$.

[IMAGE_1]

Pour chaque cas, indiquer le rapport trigonométrique à utiliser, puis calculer la longueur demandée, arrondie au millimètre.

1. On sait que $RT = 9$ cm. Calculer $ST$.
2. On sait que $RS = 7$ cm. Calculer $ST$.
3. On sait que $RS = 7$ cm. Calculer $RT$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $RT$ connu, $ST$ cherché

::: methode
Pour l'angle $\widehat{SRT}$ : hypoténuse $[RT]$, côté adjacent $[RS]$, côté opposé $[ST]$.
:::

[IMAGE_2]

::: etape Opposé et hypoténuse : le sinus
$$
\begin{aligned}
\sin 28^\circ &= \frac{ST}{9} \\
ST &= 9 \times \sin 28^\circ \approx 4{,}225
\end{aligned}
$$
:::

::: resultat
Sinus ; $ST \approx 4{,}2$ cm.
:::

## Question 2 : $RS$ connu, $ST$ cherché

::: etape Opposé et adjacent : la tangente
$$
\begin{aligned}
\tan 28^\circ &= \frac{ST}{7} \\
ST &= 7 \times \tan 28^\circ \approx 3{,}722
\end{aligned}
$$
:::

::: resultat
Tangente ; $ST \approx 3{,}7$ cm.
:::

## Question 3 : $RS$ connu, $RT$ cherché

::: etape Adjacent et hypoténuse : le cosinus
$$
\begin{aligned}
\cos 28^\circ &= \frac{7}{RT} \\
RT &= \frac{7}{\cos 28^\circ} \approx 7{,}928
\end{aligned}
$$
:::

::: resultat
Cosinus ; $RT \approx 7{,}9$ cm.
:::

::: retenir
On choisit le rapport qui contient **le côté connu et le côté cherché**, et seulement eux : c'est tout l'intérêt de CAH SOH TOA.
:::

::: attention Erreur fréquente
Au cas 3, $RT$ est au dénominateur : $RT = 7 \times \cos 28^\circ$ est faux.
:::

Solution:
<!-- optitab:1 -->
1. Sinus : $ST = 9 \times \sin 28^\circ \approx 4{,}2$ cm
2. Tangente : $ST = 7 \times \tan 28^\circ \approx 3{,}7$ cm
3. Cosinus : $RT = \frac{7}{\cos 28^\circ} \approx 7{,}9$ cm

=== Entraînement - Calculer un angle avec la tangente
Id: 2387
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $AB = 7$ cm et $AC = 4{,}5$ cm.

[IMAGE_1]

1. Pour l'angle $\widehat{ABC}$, nommer les côtés $[AB]$ et $[AC]$.
2. Calculer la mesure de l'angle $\widehat{ABC}$, arrondie au dixième de degré.
3. En déduire la mesure de l'angle $\widehat{ACB}$, arrondie au dixième de degré.
4. Calculer $BC$, arrondi au millimètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Nommer les côtés

::: resultat
Pour $\widehat{ABC}$ : $[AB]$ est le côté adjacent (il passe par $B$) et $[AC]$ le côté opposé.
:::

## Question 2 : L'angle $\widehat{ABC}$

::: methode
On connaît l'opposé et l'adjacent, pas l'hypoténuse : TOA, c'est la tangente.
:::

::: etape Calculer la tangente
$$\tan \widehat{ABC} = \frac{AC}{AB} = \frac{4{,}5}{7}$$
:::

::: etape Retrouver l'angle
$\widehat{ABC} = \tan^{-1}\left(\dfrac{4{,}5}{7}\right) \approx 32{,}735^\circ$.
:::

[IMAGE_2]

::: resultat
$\widehat{ABC} \approx 32{,}7^\circ$.
:::

## Question 3 : L'angle $\widehat{ACB}$

::: etape Angles complémentaires
$\widehat{ACB} = 90^\circ - \widehat{ABC} \approx 90^\circ - 32{,}735^\circ = 57{,}265^\circ$.
:::

::: resultat
$\widehat{ACB} \approx 57{,}3^\circ$.
:::

## Question 4 : La longueur $BC$

::: methode
On connaît les deux côtés de l'angle droit : le théorème de Pythagore donne l'hypoténuse sans utiliser d'angle arrondi.
:::

::: etape Théorème de Pythagore
$$
\begin{aligned}
BC^2 &= AB^2 + AC^2 \\
&= 7^2 + 4{,}5^2 = 49 + 20{,}25 = 69{,}25 \\
BC &= \sqrt{69{,}25} \approx 8{,}322
\end{aligned}
$$
:::

::: resultat
$BC \approx 8{,}3$ cm.
:::

::: attention Erreur fréquente
Écrire $\tan \widehat{ABC} = \dfrac{7}{4{,}5}$ : on trouverait l'autre angle ($57{,}3^\circ$). La tangente est l'opposé sur l'adjacent **pour l'angle étudié**.
:::

Solution:
<!-- optitab:1 -->
1. $[AB]$ adjacent, $[AC]$ opposé.
2. $\widehat{ABC} = \tan^{-1}\left(\frac{4{,}5}{7}\right) \approx 32{,}7^\circ$
3. $\widehat{ACB} \approx 57{,}3^\circ$
4. $BC = \sqrt{69{,}25} \approx 8{,}3$ cm

=== Entraînement - Travailler avec l'autre angle aigu
Id: 2388
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $AB = 5$ cm et $\widehat{ACB} = 25^\circ$.

[IMAGE_1]

1. Pour l'angle $\widehat{ACB}$, le côté $[AB]$ est-il adjacent ou opposé ?
2. Calculer $BC$, arrondi au millimètre.
3. Calculer $AC$, arrondi au millimètre.
4. Quelle est la mesure de $\widehat{ABC}$ ? Vérifier le résultat de la question 2 avec $\cos \widehat{ABC}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Nommer $[AB]$

::: etape Regarder le sommet $C$
L'angle étudié a pour sommet $C$. Le côté $[AB]$ ne passe pas par $C$.
:::

::: resultat
$[AB]$ est le côté **opposé** à $\widehat{ACB}$ (alors qu'il serait adjacent à $\widehat{ABC}$).
:::

## Question 2 : Calculer $BC$

::: methode
Opposé connu, hypoténuse cherchée : le sinus, avec l'inconnue au dénominateur.
:::

::: etape Calcul
$$
\begin{aligned}
\sin \widehat{ACB} &= \frac{AB}{BC} \\
\sin 25^\circ &= \frac{5}{BC} \\
BC &= \frac{5}{\sin 25^\circ} \approx 11{,}831
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$BC \approx 11{,}8$ cm.
:::

## Question 3 : Calculer $AC$

::: methode
$[AC]$ est adjacent à $\widehat{ACB}$ ; avec l'opposé connu, c'est la tangente.
:::

::: etape Calcul
$$
\begin{aligned}
\tan 25^\circ &= \frac{5}{AC} \\
AC &= \frac{5}{\tan 25^\circ} \approx 10{,}723
\end{aligned}
$$
:::

::: resultat
$AC \approx 10{,}7$ cm.
:::

## Question 4 : L'angle $\widehat{ABC}$ et la vérification

::: etape Angles complémentaires
$\widehat{ABC} = 90^\circ - 25^\circ = 65^\circ$.
:::

::: etape Vérification
Pour $\widehat{ABC}$, $[AB]$ est adjacent : $\cos 65^\circ = \dfrac{5}{BC}$ donne $BC = \dfrac{5}{\cos 65^\circ} \approx 11{,}831$, la même valeur.
:::

::: resultat
$\widehat{ABC} = 65^\circ$ et l'on retrouve $BC \approx 11{,}8$ cm.
:::

::: attention Erreur fréquente
Garder les rôles de l'angle $\widehat{ABC}$ alors qu'on travaille avec $\widehat{ACB}$ : on écrirait $\cos 25^\circ = \dfrac{5}{BC}$, ce qui est faux.
:::

Solution:
<!-- optitab:1 -->
1. Opposé.
2. $BC = \frac{5}{\sin 25^\circ} \approx 11{,}8$ cm
3. $AC = \frac{5}{\tan 25^\circ} \approx 10{,}7$ cm
4. $\widehat{ABC} = 65^\circ$ ; $\frac{5}{\cos 65^\circ} \approx 11{,}8$ cm.

=== Entraînement - Une échelle contre un mur
Id: 2389
Difficulté: medium
Image: trigonometrie_3e_cable.png

Énoncé:
<!-- optitab:1 -->
Une échelle de $6$ m est appuyée contre un mur vertical, sur un sol horizontal. Pour être sûre, une échelle doit faire avec le sol un angle compris entre $65^\circ$ et $75^\circ$.

[IMAGE_1]

1. L'échelle fait un angle de $70^\circ$ avec le sol. À quelle hauteur du sol son sommet touche-t-il le mur ? Arrondir au centimètre.
2. Dans cette position, à quelle distance du mur se trouve le pied de l'échelle ? Arrondir au centimètre.
3. On place maintenant le pied de l'échelle à $1{,}5$ m du mur. Calculer l'angle entre l'échelle et le sol, au dixième de degré. L'échelle est-elle sûre ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La hauteur atteinte

::: methode
Le mur est perpendiculaire au sol : le mur, le sol et l'échelle forment un triangle rectangle dont l'échelle est l'hypoténuse.
:::

::: etape Nommer les côtés par rapport à l'angle au sol
La hauteur $h$ sur le mur est le côté **opposé** à l'angle de $70^\circ$ ; l'échelle ($6$ m) est l'hypoténuse : c'est le sinus.
:::

::: etape Calcul
$$
\begin{aligned}
\sin 70^\circ &= \frac{h}{6} \\
h &= 6 \times \sin 70^\circ \approx 5{,}638
\end{aligned}

=== Entraînement - Trouver et corriger les erreurs
Id: 2390
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Le triangle $ABC$ est rectangle en $A$, avec $AB = 6$ cm et $\widehat{ABC} = 40^\circ$. On cherche l'hypoténuse $BC$.

[IMAGE_1]

Lina a écrit : « $\sin 40^\circ = \dfrac{AB}{BC}$, donc $BC = \dfrac{6}{\sin 40^\circ} \approx 9{,}3$ cm. »

Tom a écrit : « $\cos 40^\circ = \dfrac{AB}{BC}$, donc $BC = \dfrac{6}{\cos 40^\circ}$. » Sa calculatrice affiche $-9{,}00$.

2. Le raisonnement de Tom est juste, mais pas son résultat. Que s'est-il passé ?
3. Calculer correctement $BC$, arrondi au millimètre.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'erreur de Lina

::: etape Nommer $[AB]$ par rapport à $\widehat{ABC}$
$[AB]$ passe par le sommet $B$ : c'est le côté **adjacent**, pas le côté opposé.
:::

::: resultat
Lina a confondu adjacent et opposé : avec le côté adjacent et l'hypoténuse, il faut le **cosinus**, pas le sinus.

Une longueur ne peut pas être négative. En mode radians, la calculatrice calcule le cosinus de $40$ radians : $\cos 40 \approx -0{,}667$, et $\dfrac{6}{-0{,}667} \approx -9{,}00$.
:::

::: resultat
La calculatrice de Tom est en mode **radians** : il faut la passer en mode degrés.
:::

## Question 3 : Le bon calcul

::: etape Cosinus, inconnue au dénominateur
$$
\begin{aligned}
\cos 40^\circ &= \frac{6}{BC} \\
BC &= \frac{6}{\cos 40^\circ} \approx 7{,}832
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$BC \approx 7{,}8$ cm.
:::

::: retenir
Deux réflexes de contrôle : un résultat négatif signale le mode radians ; l'hypoténuse doit rester plus longue que les deux autres côtés.
:::

Solution:
<!-- optitab:1 -->
1. $[AB]$ est adjacent à $\widehat{ABC}$ : il fallait le cosinus.
2. Calculatrice en mode radians.
3. $BC = \frac{6}{\cos 40^\circ} \approx 7{,}8$ cm

\end{aligned}

\begin{aligned}

\alpha &= \tan^{-1}(1{,}172) \approx 49{,}5^\circ
\end{aligned}

::: attention Erreur fréquente
Donner $23{,}4$ m comme hauteur de l'immeuble : la tangente donne la hauteur **au-dessus des yeux**, il faut ajouter $1{,}6$ m.

Solution:
<!-- optitab:1 -->

Image: trigonometrie_3e_toit.png

Énoncé:
<!-- optitab:1 -->
La façade d'une maison est surmontée d'un toit symétrique. Le triangle $ABC$ représente ce toit : $AC = 10$ m et chaque pente fait un angle de $35^\circ$ avec l'horizontale. Le point $H$ est le milieu de $[AC]$.

[IMAGE_1]

1. Expliquer pourquoi le triangle $AHB$ est rectangle en $H$ et donner la longueur $AH$.
2. Calculer la hauteur $BH$ du toit, arrondie au centimètre.
3. Calculer la longueur $AB$ d'un pan du toit, arrondie au centimètre.
4. Calculer l'angle $\widehat{ABC}$ au sommet du toit.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le triangle $AHB$

::: etape Symétrie
Le toit est symétrique : $ABC$ est isocèle en $B$. Dans un triangle isocèle, la droite qui joint le sommet principal au milieu de la base est perpendiculaire à cette base.
:::

::: resultat
$(BH) \perp (AC)$, donc $AHB$ est rectangle en $H$, et $AH = \dfrac{10}{2} = 5$ m.
:::

## Question 2 : La hauteur $BH$

::: methode
Pour l'angle $\widehat{BAH} = 35^\circ$ : $[AH]$ est adjacent, $[BH]$ opposé. C'est la tangente.
:::

::: etape Calcul
$$
\begin{aligned}
\tan 35^\circ &= \frac{BH}{5} \\
BH &= 5 \times \tan 35^\circ \approx 3{,}501
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$BH \approx 3{,}50$ m.
:::

## Question 3 : Le pan du toit $AB$

::: etape Cosinus, inconnue au dénominateur
$$
\begin{aligned}
\cos 35^\circ &= \frac{5}{AB} \\
AB &= \frac{5}{\cos 35^\circ} \approx 6{,}104
\end{aligned}
$$
:::

::: resultat
$AB \approx 6{,}10$ m.
:::

## Question 4 : L'angle au sommet

::: etape Somme des angles du triangle $ABC$
$\widehat{BAC} = \widehat{BCA} = 35^\circ$, donc $\widehat{ABC} = 180^\circ - 2 \times 35^\circ = 110^\circ$.
:::

::: resultat
$\widehat{ABC} = 110^\circ$.
:::

::: attention Erreur fréquente
Travailler dans le triangle $ABC$ entier, qui n'est pas rectangle : la trigonométrie ne s'applique que dans un triangle **rectangle**, ici $AHB$, avec $AH = 5$ m et non $10$ m.
:::

Solution:
<!-- optitab:1 -->
1. $ABC$ est isocèle en $B$ et $H$ milieu de $[AC]$ : $(BH) \perp (AC)$ ; $AH = 5$ m.
2. $BH = 5 \times \tan 35^\circ \approx 3{,}50$ m
3. $AB = \frac{5}{\cos 35^\circ} \approx 6{,}10$ m
4. $\widehat{ABC} = 110^\circ$

[IMAGE_2]

::: resultat
Le bateau est à environ $320$ m du pied du phare.

$320{,}19 - 211{,}71 = 108{,}48$.

:::

::: attention Erreur fréquente
Placer les $8^\circ$ au sommet du phare dans le triangle $SPB$ : l'angle de dépression est mesuré depuis l'**horizontale**, pas depuis le phare vertical. Dans le triangle, l'angle en $S$ vaut $90^\circ - 8^\circ = 82^\circ$.
:::

Solution:
<!-- optitab:1 -->
1. Angles alternes-internes (horizontale parallèle à la mer) : $\widehat{PBS} = 8^\circ$.
2. $PB = \frac{45}{\tan 8^\circ} \approx 320$ m
3. $\frac{45}{\tan 12^\circ} \approx 212$ m : rapproché d'environ $108$ m.

=== Type brevet - La pente d'une route
Id: 2399
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un panneau routier indique une pente de $10\ \%$ : la route monte de $10$ m pour $100$ m parcourus à l'horizontale. Une portion de cette route s'étend sur $2{,}5$ km à l'horizontale. Le schéma n'est pas à l'échelle.

[IMAGE_1]

1. Calculer le dénivelé $h$ de cette portion de route.
2. Calculer la longueur $L$ de la portion de route avec le théorème de Pythagore, arrondie au mètre.
3. Calculer l'angle $\alpha$ entre la route et l'horizontale, arrondi au dixième de degré.
4. Retrouver la longueur $L$ avec le cosinus de $\alpha$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le dénivelé

::: methode
$2{,}5$ km $= 2\,500$ m. Une pente de $10\ \%$ : le dénivelé vaut $10\ \%$ de la distance horizontale.
:::

::: etape Calcul
$h = 2\,500 \times \dfrac{10}{100} = 250$.
:::

::: resultat
Le dénivelé est de $250$ m.
:::

## Question 2 : La longueur par le théorème de Pythagore

::: etape Triangle rectangle
L'horizontale et la verticale sont perpendiculaires ; la route est l'hypoténuse.
$$
\begin{aligned}
L^2 &= 2\,500^2 + 250^2 \\
&= 6\,250\,000 + 62\,500 = 6\,312\,500 \\
L &= \sqrt{6\,312\,500} \approx 2\,512{,}47
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$L \approx 2\,512$ m.
:::

## Question 3 : L'angle $\alpha$

::: etape Tangente
$$
\begin{aligned}
\tan \alpha &= \frac{250}{2\,500} = 0{,}1 \\
\alpha &= \tan^{-1}(0{,}1) \approx 5{,}7^\circ
\end{aligned}
$$
:::

::: resultat
$\alpha \approx 5{,}7^\circ$ : une pente de $10\ \%$ ne correspond pas à un angle de $10^\circ$.
:::

## Question 4 : Retrouver $L$ avec le cosinus

::: etape Cosinus, avec la valeur non arrondie de $\alpha$
$$L = \frac{2\,500}{\cos \alpha} \approx 2\,512{,}47$$

On utilise la valeur de $\alpha$ gardée en mémoire dans la calculatrice.
:::

::: resultat
On retrouve $L \approx 2\,512$ m.
:::

::: attention Erreur fréquente
Confondre pourcentage de pente et angle : $10\ \%$ signifie $\tan \alpha = 0{,}1$, et non $\alpha = 10^\circ$.
:::

Solution:
<!-- optitab:1 -->
1. $h = 250$ m
2. $L = \sqrt{6\,312\,500} \approx 2\,512$ m
3. $\alpha = \tan^{-1}(0{,}1) \approx 5{,}7^\circ$
4. $L = \frac{2\,500}{\cos \alpha} \approx 2\,512$ m

=== Type brevet - Pythagore, trigonométrie et Thalès
Id: 2400
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Sur la figure ci-dessous, qui n'est pas en vraie grandeur :

- le triangle $ABC$ est rectangle en $B$, avec $AB = 8$ cm et $BC = 6$ cm ;
- le point $E$ appartient au segment $[AB]$ et $AE = 5$ cm ;
- le point $F$ appartient au segment $[AC]$ et la droite $(EF)$ est perpendiculaire à $(AB)$.

[IMAGE_1]

1. Calculer la longueur $AC$.
2. Calculer la mesure de l'angle $\widehat{BAC}$, arrondie au dixième de degré.
3. Démontrer que les droites $(EF)$ et $(BC)$ sont parallèles.
4. Calculer $EF$ et $AF$.
5. Retrouver $EF$ à l'aide de la tangente de l'angle $\widehat{BAC}$.

Étapes:
<!-- optitab:1 -->
## Question 1 : La longueur $AC$

::: methode
$ABC$ est rectangle en $B$ et on connaît les deux côtés de l'angle droit : théorème de Pythagore.
:::

::: etape Calcul
$$
\begin{aligned}
AC^2 &= AB^2 + BC^2 \\
&= 8^2 + 6^2 = 64 + 36 = 100 \\
AC &= \sqrt{100} = 10
\end{aligned}
$$
:::

::: resultat
$AC = 10$ cm.
:::

## Question 2 : L'angle $\widehat{BAC}$

::: methode
Pour l'angle $\widehat{BAC}$ : $[AB]$ est adjacent et $[BC]$ opposé. On peut utiliser la tangente avec les deux longueurs données.
:::

::: etape Calcul
$$
\begin{aligned}
\tan \widehat{BAC} &= \frac{BC}{AB} = \frac{6}{8} = 0{,}75 \\
\widehat{BAC} &= \tan^{-1}(0{,}75) \approx 36{,}9^\circ
\end{aligned}
$$
:::

::: resultat
$\widehat{BAC} \approx 36{,}9^\circ$.
:::

## Question 3 : Les droites $(EF)$ et $(BC)$

::: etape Deux perpendiculaires à une même droite
$(EF) \perp (AB)$ par hypothèse et $(BC) \perp (AB)$ car $ABC$ est rectangle en $B$.
:::

::: resultat
Si deux droites sont perpendiculaires à une même droite, alors elles sont parallèles : $(EF) \parallel (BC)$.
:::

## Question 4 : Les longueurs $EF$ et $AF$

::: methode
Les points $A$, $E$, $B$ et $A$, $F$, $C$ sont alignés dans le même ordre et $(EF) \parallel (BC)$ : théorème de Thalès.
:::

::: etape Égalité des rapports
$$\frac{AE}{AB} = \frac{AF}{AC} = \frac{EF}{BC}$$

soit, en remplaçant par les longueurs connues :

$$\frac{5}{8} = \frac{AF}{10} = \frac{EF}{6}$$
:::

::: etape Calculs
$$
\begin{aligned}
EF &= \frac{5 \times 6}{8} = 3{,}75 \\
AF &= \frac{5 \times 10}{8} = 6{,}25
\end{aligned}
$$
:::

[IMAGE_2]

::: resultat
$EF = 3{,}75$ cm et $AF = 6{,}25$ cm.
:::

## Question 5 : Retrouver $EF$ avec la tangente

::: etape Dans le triangle $AEF$ rectangle en $E$
Pour l'angle $\widehat{EAF} = \widehat{BAC}$, $[AE]$ est adjacent et $[EF]$ opposé :
$$EF = AE \times \tan \widehat{BAC} = 5 \times 0{,}75 = 3{,}75$$
:::

::: resultat
On retrouve $EF = 3{,}75$ cm : on a utilisé la valeur exacte $\tan \widehat{BAC} = 0{,}75$, pas l'angle arrondi.
:::

::: attention Erreur fréquente
Écrire $\dfrac{AE}{AB} = \dfrac{EF}{AC}$ : dans le théorème de Thalès, $EF$ se compare au côté **parallèle** $BC$, pas à $AC$.
:::

Solution:
<!-- optitab:1 -->
1. $AC = 10$ cm
2. $\widehat{BAC} = \tan^{-1}(0{,}75) \approx 36{,}9^\circ$
3. $(EF)$ et $(BC)$ sont perpendiculaires à $(AB)$ : elles sont parallèles.
4. $EF = 3{,}75$ cm ; $AF = 6{,}25$ cm
5. $EF = 5 \times \tan \widehat{BAC} = 3{,}75$ cm
