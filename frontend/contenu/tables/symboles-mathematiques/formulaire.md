## I. Logique {Lycée}

[IMAGE_1]

| Symbole | Lecture et exemple |
|---|---|
| $\forall$ | se lit **« pour tout »**. Exemple : $\forall x \in \mathbb{R},\ x^2 \geqslant 0$ |
| $\exists$ | se lit **« il existe »**. Exemple : $\exists x \in \mathbb{R},\ x^2 = 2$ |
| $\exists!$ | se lit **« il existe un unique »** : un seul élément convient |
| $\Rightarrow$ | se lit **« implique »**. Exemple : $x = 2 \Rightarrow x^2 = 4$ (la réciproque est fausse) |
| $\Leftrightarrow$ | se lit **« équivaut à »** ou « si et seulement si ». Exemple : $2x = 6 \Leftrightarrow x = 3$ |
| $\neg$ | se lit **« non »** : négation d’une proposition (on écrit aussi « non ») |

::: attention Ne pas confondre
$\Rightarrow$ ne marche que dans un sens : $x = 2 \Rightarrow x^2 = 4$ est vrai, mais $x^2 = 4$ n’implique pas $x = 2$ (on peut avoir $x = -2$).
:::

## II. Ensembles {Lycée}

| Symbole | Lecture et exemple |
|---|---|
| $\in$ | se lit **« appartient à »**. Exemple : $3 \in \mathbb{N}$ |
| $\notin$ | se lit **« n’appartient pas à »**. Exemple : $-1 \notin \mathbb{N}$ |
| $\subset$ | se lit **« est inclus dans »** : relie deux ensembles. Exemple : $\mathbb{N} \subset \mathbb{Z}$ |
| $\cup$ | **réunion** : les éléments de $A$ ou de $B$ (ou des deux) |
| $\cap$ | **intersection** : les éléments communs à $A$ et à $B$ |
| $\varnothing$ | **ensemble vide** : l’ensemble qui ne contient aucun élément |
| $A \setminus B$ | se lit **« $A$ privé de $B$ »** : les éléments de $A$ qui ne sont pas dans $B$ |
| $\{\ \}$ | **accolades** : liste les éléments d’un ensemble. Exemple : $\{1\,;2\,;3\}$ |

::: retenir $\in$ ou $\subset$ ?
$\in$ relie un **élément** à un ensemble ($2 \in \mathbb{N}$) ; $\subset$ relie deux **ensembles** ($\mathbb{N} \subset \mathbb{Z}$).
:::

## III. Ensembles de nombres {Collège}

| Symbole | Lecture et exemple |
|---|---|
| $\mathbb{N}$ | les **entiers naturels** : $0$, $1$, $2$, $3$… |
| $\mathbb{Z}$ | les **entiers relatifs** : $\dots$, $-2$, $-1$, $0$, $1$, $2$… |
| $\mathbb{D}$ | les **nombres décimaux** : écriture à virgule finie, comme $0{,}25$ |
| $\mathbb{Q}$ | les **nombres rationnels** : quotients d’entiers, comme $\dfrac{1}{3}$ |
| $\mathbb{R}$ | les **nombres réels** : tous les nombres de la droite graduée, comme $\sqrt{2}$ ou $\pi$ |
| $\mathbb{C}$ | les **nombres complexes** : de la forme $a + \mathrm{i}b$, avec $\mathrm{i}^2 = -1$ |
| $\mathbb{R}^*$ | l’étoile signifie **« privé de $0$ »** ; $\mathbb{R}^+$ désigne les réels positifs |

::: retenir Inclusions
$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$
:::

## IV. Relations {Collège}

| Symbole | Lecture et exemple |
|---|---|
| $\neq$ | se lit **« différent de »**. Exemple : $2 + 2 \neq 5$ |
| $\approx$ | se lit **« environ égal à »** : valeur approchée. Exemple : $\pi \approx 3{,}14$ |
| $\leqslant$ | se lit **« inférieur ou égal à »** ; $\geqslant$ se lit « supérieur ou égal à » |
| $<$ | se lit **« strictement inférieur à »** ; $>$ se lit « strictement supérieur à » |
| $\equiv$ | se lit **« congru à »** (arithmétique). Exemple : $17 \equiv 2 \pmod{5}$ |
| $\sim$ | se lit **« équivalent à »** (analyse). Exemple : $\sin x \sim x$ en $0$ |
| $\propto$ | se lit **« proportionnel à »**, surtout en physique |

## V. Opérations {Collège}

| Symbole | Lecture et exemple |
|---|---|
| $\pm$ | se lit **« plus ou moins »**. Exemple : $x = \pm 3$ signifie $x = 3$ ou $x = -3$ |
| $\sqrt{\ }$ | **racine carrée** : $\sqrt{9} = 3$ ; $\sqrt[n]{\ }$ désigne la racine $n$-ième |
| $\lvert x \rvert$ | **valeur absolue** : distance à $0$. Exemple : $\lvert -5 \rvert = 5$ |
| $n!$ | se lit **« factorielle $n$ »** : $n! = 1 \times 2 \times \dots \times n$, et $4! = 24$ |
| $\sum$ | **somme** de plusieurs termes. Exemple : $\displaystyle\sum_{k=1}^{3} k = 1 + 2 + 3$ |
| $\prod$ | **produit** de plusieurs termes. Exemple : $\displaystyle\prod_{k=1}^{3} k = 1 \times 2 \times 3$ |
| $\binom{n}{k}$ | se lit **« $k$ parmi $n$ »** : nombre de façons de choisir $k$ éléments parmi $n$ |
| $g \circ f$ | se lit **« $g$ rond $f$ »** : composée, $(g \circ f)(x) = g\big(f(x)\big)$ |

## VI. Analyse {Lycée}

| Symbole | Lecture et exemple |
|---|---|
| $\infty$ | **l’infini** : $+\infty$ et $-\infty$ ne sont pas des nombres réels |
| $\lim$ | **limite**. Exemple : $\lim\limits_{x \to +\infty} \dfrac{1}{x} = 0$ |
| $\mapsto$ | se lit **« associe »**. Exemple : $f : x \mapsto x^2$ |
| $f'$ | se lit **« $f$ prime »** : dérivée de $f$, notée aussi $\dfrac{\mathrm{d}f}{\mathrm{d}x}$ |
| $\int$ | **intégrale**. Exemple : $\displaystyle\int_0^1 x\,\mathrm{d}x = \dfrac{1}{2}$ |
| $\Delta$ | **delta** : discriminant ou variation, comme $\Delta t$ pour une durée |
| $\partial$ | **dérivée partielle** (supérieur) : dérivée par rapport à une seule variable |

## VII. Géométrie {Collège}

| Symbole | Lecture et exemple |
|---|---|
| $(AB)$ | la **droite** passant par $A$ et $B$ |
| $[AB]$ | le **segment** d’extrémités $A$ et $B$ ; $AB$ désigne sa longueur |
| $[AB)$ | la **demi-droite** d’origine $A$ passant par $B$ |
| $\overrightarrow{AB}$ | le **vecteur** allant de $A$ vers $B$ ; $\lVert \vec{u} \rVert$ est la norme |
| $\widehat{ABC}$ | l’**angle** de sommet $B$ formé par les demi-droites $[BA)$ et $[BC)$ |
| $\parallel$ | se lit **« est parallèle à »**. Exemple : $(AB) \parallel (CD)$ |
| $\perp$ | se lit **« est perpendiculaire à »**. Exemple : $(AB) \perp (BC)$ |

## VIII. Probabilités {Lycée}

| Symbole | Lecture et exemple |
|---|---|
| $P(A)$ | **probabilité** de l’événement $A$, comprise entre $0$ et $1$ |
| $\overline{A}$ | l’**événement contraire** de $A$ : $P(\overline{A}) = 1 - P(A)$ |
| $P_A(B)$ | probabilité **de $B$ sachant $A$** (probabilité conditionnelle) |
| $E(X)$ | **espérance** de la variable aléatoire $X$ : sa valeur moyenne |
| $V(X)$ | **variance** de $X$ ; $\sigma(X) = \sqrt{V(X)}$ est son écart type |
