## I. Définitions {Collège}

[IMAGE_1]

| Notion | Définition |
|---|---|
| Carré de $n$ | $n^2 = n \times n$ : l’aire d’un carré de côté $n$ |
| Cube de $n$ | $n^3 = n \times n \times n$ : le volume d’un cube d’arête $n$ |
| Racine carrée de $a$ ($a \geqslant 0$) | le nombre positif $\sqrt{a}$ dont le carré vaut $a$ |

::: methode Encadrer une racine carrée
On cherche les carrés parfaits qui entourent le nombre : $49 < 50 < 64$, donc $7 < \sqrt{50} < 8$.
:::

::: attention
$\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$, mais $\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$ pour $a$ et $b$ positifs. Par exemple, $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$.
:::
