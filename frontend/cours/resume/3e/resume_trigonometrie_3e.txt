<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les côtés et les rapports</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:500px;">
<p style="margin:0; font-weight:bold;">$\displaystyle \cos \widehat{B} = \frac{\text{adj}}{\text{hyp}}$ &nbsp;&nbsp; $\displaystyle \sin \widehat{B} = \frac{\text{opp}}{\text{hyp}}$ &nbsp;&nbsp; $\displaystyle \tan \widehat{B} = \frac{\text{opp}}{\text{adj}}$</p>
<p style="margin:6px 0 0 0;">SOH CAH TOA</p>
</div>
<p style="margin:0;">• Opposé et adjacent dépendent de l'angle choisi ; l'hypoténuse, non.</p>
<p style="margin:6px 0 0 0;">• Pour un angle aigu : $\displaystyle 0 < \sin, \cos < 1$ ; la tangente peut dépasser 1.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Calculer</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;"><strong>Une longueur :</strong> choisir le rapport avec le côté connu et le côté cherché.</p>
<p style="margin:6px 0 0 0;">• inconnue au numérateur → multiplier : $\displaystyle AC = BC \sin \widehat{B}$ ;</p>
<p style="margin:6px 0 0 0;">• inconnue au dénominateur → diviser : $\displaystyle BC = \frac{AB}{\cos \widehat{B}}$.</p>
<p style="margin:10px 0 0 0;"><strong>Un angle :</strong> calculer le rapport, puis $\displaystyle \cos^{-1}$, $\displaystyle \sin^{-1}$ ou $\displaystyle \tan^{-1}$ (mode DEGRÉS). Contrôle : $\displaystyle \widehat{B} + \widehat{C} = 90^\circ$.</p>
<p style="margin:10px 0 0 0;"><strong>Pente :</strong> pente (%) $= \tan \times 100$ ; 8 % ≈ 4,6°, et 100 % = 45°.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Calculatrice en radians au lieu de degrés (test : $\cos 60^\circ = 0{,}5$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Multiplier au lieu de diviser quand l'inconnue est l'hypoténuse.</p>
<p style="margin:6px 0 0 0;">3️⃣ Confondre $\cos^{-1}$ (angle) et $\frac{1}{\cos}$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier la hauteur de l'appareil (ou des yeux) dans une mesure indirecte.</p>
</div>
