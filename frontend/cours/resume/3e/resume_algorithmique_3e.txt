Titre: Résumé : Algorithmique et programmation

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : variables, tests, boucles, lutin et stylo, blocs personnalisés, messages, simulation et tableur. Programme de 3ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Variables et tests</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• « mettre x à … » <strong>remplace</strong> la valeur ; « ajouter … à x » la <strong>modifie</strong>.</p>
<p style="margin:6px 0 0 0;">• « demander » range la saisie dans <strong>réponse</strong> ; « dire » affiche un résultat.</p>
<p style="margin:6px 0 0 0;">• « si … alors … sinon » : une seule branche est exécutée. Tester la valeur <strong>frontière</strong>.</p>
<p style="margin:6px 0 0 0;">• « n modulo d = 0 » teste si n est <strong>divisible</strong> par d.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Les boucles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• « répéter n fois » : exactement n tours.</p>
<p style="margin:6px 0 0 0;">• « répéter jusqu'à » : test vérifié <strong>avant</strong> chaque tour, arrêt dès qu'il est vrai ; boucle infinie si la variable ne progresse pas.</p>
<p style="margin:6px 0 0 0;">• Exécuter à la main : un tableau, une colonne par variable, une ligne par tour.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Lutin, blocs et messages</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Orientation 90 = droite, 0 = haut ; « tourner ↺ » = sens inverse des aiguilles d'une montre.</p>
<p style="margin:6px 0 0 0;">• Polygone régulier à n côtés : répéter n fois « avancer ; tourner de $\displaystyle \frac{360}{n}$ » (carré 90°, triangle 120°, hexagone 60°).</p>
<p style="margin:6px 0 0 0;">• Bloc personnalisé : instructions réutilisables avec des <strong>paramètres</strong>.</p>
<p style="margin:6px 0 0 0;">• « envoyer à tous … et attendre » : attend la fin des scripts déclenchés.</p>
<p style="margin:6px 0 0 0;">• Simulation : compteur à 0 <strong>avant</strong> la boucle, +1 à chaque succès, division <strong>après</strong>.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Le tableur</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Une formule commence par = ; recopiée vers le bas, A2 devient A3, A4…</p>
<p style="margin:6px 0 0 0;">• Une référence absolue comme \$D\$2 reste fixe lors de la recopie.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Exécuter une seule fois un bloc placé DANS la boucle (ou plusieurs fois un bloc placé APRÈS).</p>
<p style="margin:6px 0 0 0;">2️⃣ Croire qu'une boucle « jusqu'à x > 20 » s'arrête à 20.</p>
<p style="margin:6px 0 0 0;">3️⃣ Tourner de l'angle intérieur d'un polygone au lieu de l'angle extérieur.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier les dollars devant une cellule qui doit rester fixe au tableur.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> pour un script, noter pas à pas la valeur des variables (ou la position et l'orientation du lutin) dans un tableau ; pour un programme de calcul, tester quelques nombres, conjecturer, puis démontrer avec une lettre.</p>
</div>
