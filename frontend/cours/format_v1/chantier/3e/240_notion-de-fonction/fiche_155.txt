## I. Vocabulaire

::: formule
$$f(a) = b$$
:::

- $b$ est **l'image** de $a$ par $f$ ; $a$ est **un antécédent** de $b$ par $f$.
- $f : x \longmapsto 2x + 1$ se lit « $f$ est la fonction qui à $x$ associe $2x + 1$ ».
- Un nombre a **une seule image** ; un nombre peut avoir **0, 1 ou plusieurs antécédents**.

## II. Calculer

| On cherche | Méthode |
|---|---|
| l'image de $a$ | calculer $f(a)$ |
| un antécédent de $b$ | résoudre $f(x) = b$ |
| $M(a\ ;\ b) \in \mathcal{C}_f$ ? | comparer $f(a)$ et $b$ |

Exemples avec $f(x) = 2x + 1$ :
- $f(3) = 7$ : l'image de $3$ est $7$ ;
- $2x + 1 = 9$ donne $x = 4$ : l'antécédent de $9$ est $4$ ;
- $f(1) = 3$ : le point $M(1\ ;\ 3)$ appartient à $\mathcal{C}_f$.

## III. Lire un graphique

[IMAGE_1]

- **Image de $a$** : abscisse $a$ → courbe → ordonnée.
- **Antécédents de $b$** : horizontale $y = b$ → **tous** les points d'intersection → leurs abscisses.
- Une lecture graphique est approchée ; le calcul donne la valeur exacte.

## IV. Tableau de valeurs et modélisation

- Ligne 1 : des valeurs de $x$ ; ligne 2 : leurs images. Un tableau ne dit rien des valeurs absentes.
- Tableur : en B2, `=2*A2+1`, puis étirer vers le bas.
- Modéliser : variable et unité, expression $f(x)$, valeurs possibles de $x$.

::: attention Les erreurs classiques
1. Confondre image et antécédent : dans $f(a) = b$, l'image est $b$.
2. Lire $f(2)$ comme « $f \times 2$ ».
3. Oublier des antécédents lors d'une lecture graphique.
4. Croire que $f(3) = 8$ entraîne $f(8) = 3$.
:::
