=== Découverte - Trois quadrilatères
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe les figures. Contrôle les angles avec le coin d’une feuille et les côtés en reportant une même longueur sur une bande de papier.

[IMAGE_1]

1. Nomme la figure A.
2. Nomme la figure B.
3. Nomme la figure C.
4. Combien A a-t-il de sommets ?
5. Quelle propriété A et C partagent-ils ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Nomme la figure A.

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Les quatre côtés ont la même longueur. Les quatre coins coïncident avec le coin droit du papier, même si la figure est tournée.
:::

::: resultat
A est un carré.
:::

## Question 2 : Nomme la figure B.

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Les quatre angles sont droits. Deux côtés voisins ont des longueurs différentes.
:::

::: resultat
B est un rectangle qui n’est pas un carré.
:::

## Question 3 : Nomme la figure C.

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Les quatre côtés ont la même longueur ; aucun angle ne coïncide avec le coin droit.
:::

::: resultat
C est un losange qui n’est pas un carré.
:::

## Question 4 : Combien A a-t-il de sommets ?

::: methode
Faire le tour de la figure en comptant chaque élément une seule fois.
:::

::: etape Observer et vérifier
Pars d’un coin et suis le contour. Compte chaque coin une seule fois.
:::

::: resultat
A a 4 sommets.
:::

## Question 5 : Quelle propriété A et C partagent-ils ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Reporte la longueur d’un côté sur les trois autres côtés de chaque figure.
:::

::: resultat
A et C ont chacun 4 côtés de même longueur.
:::

Solution:
<!-- optitab:1 -->
1. A est un carré.
2. B est un rectangle qui n’est pas un carré.
3. C est un losange qui n’est pas un carré.
4. A a 4 sommets.
5. A et C ont chacun 4 côtés de même longueur.

=== Découverte - Comparer des angles
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Compare chaque angle au coin droit d’une feuille. Les lettres désignent les trois angles, pas des points.

[IMAGE_1]

1. L’angle A est-il aigu, droit ou obtus ?
2. Nomme l’angle B.
3. Nomme l’angle C.
4. Quel instrument permet de contrôler B sur une copie ?
5. Quel angle est le plus ouvert ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L’angle A est-il aigu, droit ou obtus ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Le coin droit est plus ouvert que A. Les deux bords de A sont plus rapprochés.
:::

::: resultat
A est un angle aigu.
:::

## Question 2 : Nomme l’angle B.

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Les deux bords du coin droit se posent exactement sur les deux côtés de B.
:::

::: resultat
B est un angle droit.
:::

## Question 3 : Nomme l’angle C.

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
C est plus ouvert que le coin droit.
:::

::: resultat
C est un angle obtus.
:::

## Question 4 : Quel instrument permet de contrôler B sur une copie ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Pose le sommet de l’angle droit de l’équerre sur le sommet de B ; aligne un bord et regarde l’autre.
:::

::: resultat
On utilise une équerre.
:::

## Question 5 : Quel angle est le plus ouvert ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Compare les ouvertures, sans comparer la longueur des traits. C est plus ouvert que B et A.
:::

::: resultat
C est le plus ouvert.
:::

Solution:
<!-- optitab:1 -->
1. A est un angle aigu.
2. B est un angle droit.
3. C est un angle obtus.
4. On utilise une équerre.
5. C est le plus ouvert.

=== Entraînement - Tracer un triangle rectangle
Id: nouveau-4
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Sur une feuille, trace un triangle ABC rectangle en A. Les côtés AB et AC mesurent 4 cm et 3 cm.

1. Trace AB. Quelle longueur doit-il avoir ?
2. Comment placer AC ?
3. Termine le triangle. Quel segment manque ?
4. Où places-tu le petit carré ?
5. Combien la figure a-t-elle de côtés et de sommets ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Trace AB. Quelle longueur doit-il avoir ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Place A devant le zéro de la règle. Place B devant 4 cm puis relie les deux points.
:::

::: resultat
AB mesure 4 cm.
:::

## Question 2 : Comment placer AC ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Place le coin droit de l’équerre en A, un bord sur AB. Trace AC le long de l’autre bord et place C à 3 cm de A.
:::

::: resultat
AC mesure 3 cm et l’angle en A est droit.
:::

## Question 3 : Termine le triangle. Quel segment manque ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
A et B sont déjà reliés, A et C aussi. La règle permet de fermer le contour en reliant B à C.
:::

::: resultat
Il faut tracer BC.
:::

## Question 4 : Où places-tu le petit carré ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Contrôle le coin en A avec l’équerre, puis dessine le code à l’intérieur du triangle contre AB et AC.
:::

::: resultat
Le petit carré se place en A.
:::

## Question 5 : Combien la figure a-t-elle de côtés et de sommets ?

::: methode
Faire le tour de la figure en comptant chaque élément une seule fois.
:::

::: etape Observer et vérifier
Le contour est formé de AB, BC et CA. Les coins sont A, B et C.
:::

::: resultat
Le triangle a 3 côtés et 3 sommets.
:::

Modèle de contrôle du tracé :

[IMAGE_1]

Solution:
<!-- optitab:1 -->
1. AB mesure 4 cm.
2. AC mesure 3 cm et l’angle en A est droit.
3. Il faut tracer BC.
4. Le petit carré se place en A.
5. Le triangle a 3 côtés et 3 sommets.

=== Entraînement - Le carré dans deux familles
Id: nouveau-5
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On découpe un carré puis on le tourne. Utilise ses propriétés.

1. Combien le carré a-t-il d’angles droits ?
2. Pourquoi est-il aussi un rectangle ?
3. Combien ses côtés de même longueur sont-ils ?
4. Pourquoi est-il aussi un losange ?
5. Le nom du carré change-t-il si on le tourne ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien le carré a-t-il d’angles droits ?

::: methode
Faire le tour de la figure en comptant chaque élément une seule fois.
:::

::: etape Observer et vérifier
Le coin de l’équerre coïncide avec chacun des quatre coins.
:::

::: resultat
Le carré a 4 angles droits.
:::

## Question 2 : Pourquoi est-il aussi un rectangle ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Un rectangle est un quadrilatère à quatre angles droits ; le carré respecte cette règle.
:::

::: resultat
Le carré est un rectangle car il a 4 angles droits.
:::

## Question 3 : Combien ses côtés de même longueur sont-ils ?

::: methode
Faire le tour de la figure en comptant chaque élément une seule fois.
:::

::: etape Observer et vérifier
Reporte un côté sur chacun des autres : la longueur reste la même.
:::

::: resultat
Ses 4 côtés ont la même longueur.
:::

## Question 4 : Pourquoi est-il aussi un losange ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Un losange est un quadrilatère à quatre côtés de même longueur ; le carré respecte cette règle.
:::

::: resultat
Le carré est un losange car ses 4 côtés ont la même longueur.
:::

## Question 5 : Le nom du carré change-t-il si on le tourne ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Tourner le morceau de papier ne coupe aucun côté et ne déforme aucun angle.
:::

::: resultat
Non, il reste un carré.
:::

Solution:
<!-- optitab:1 -->
1. Le carré a 4 angles droits.
2. Le carré est un rectangle car il a 4 angles droits.
3. Ses 4 côtés ont la même longueur.
4. Le carré est un losange car ses 4 côtés ont la même longueur.
5. Non, il reste un carré.

=== Entraînement - Les longueurs ne disent pas tout
Id: nouveau-7
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un quadrilatère a des côtés successifs de 4 cm, 6 cm, 4 cm et 6 cm.

1. Combien a-t-il de côtés ?
2. Ses côtés opposés ont-ils la même longueur ?
3. Peut-on déjà affirmer que c’est un rectangle ?
4. Quel contrôle manque-t-il ?
5. Peut-il être un carré ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Combien a-t-il de côtés ?

::: methode
Faire le tour de la figure en comptant chaque élément une seule fois.
:::

::: etape Observer et vérifier
Le mot quadrilatère désigne un polygone à quatre côtés.
:::

::: resultat
Il a 4 côtés.
:::

## Question 2 : Ses côtés opposés ont-ils la même longueur ?

::: methode
Repérer les sommets qui ne sont pas voisins sur le contour.
:::

::: etape Observer et vérifier
Le premier et le troisième mesurent 4 cm ; le deuxième et le quatrième mesurent 6 cm.
:::

::: resultat
Oui, les côtés opposés ont la même longueur.
:::

## Question 3 : Peut-on déjà affirmer que c’est un rectangle ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Les longueurs n’indiquent pas si les coins sont droits. Un quadrilatère penché peut avoir ces mêmes longueurs.
:::

::: resultat
Non, les longueurs seules ne suffisent pas.
:::

## Question 4 : Quel contrôle manque-t-il ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Pose l’équerre dans chacun des quatre coins. Pour un rectangle, les deux bords doivent coïncider à chaque coin.
:::

::: resultat
Il faut vérifier les 4 angles droits.
:::

## Question 5 : Peut-il être un carré ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Un carré exige quatre côtés de même longueur. Ici 4 cm et 6 cm sont différents.
:::

::: resultat
Non, ce quadrilatère n’est pas un carré.
:::

Solution:
<!-- optitab:1 -->
1. Il a 4 côtés.
2. Oui, les côtés opposés ont la même longueur.
3. Non, les longueurs seules ne suffisent pas.
4. Il faut vérifier les 4 angles droits.
5. Non, ce quadrilatère n’est pas un carré.

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.

Le trait délimite la forme mais ne remplit pas son intérieur.
:::

::: resultat

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.

La forme comprend tous les points du milieu jusqu’au bord.

::: resultat
Le contour et son intérieur forment un disque.

Distinguer les points du contour et les points de la surface intérieure.

=== Problème - Le carré tourné de Noé
Id: nouveau-9
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Noé tourne son carré sans le déformer et dit : « Il n’a plus d’angle droit ! »

1. Que deviennent les longueurs des côtés ?
2. Que deviennent les angles droits ?
3. Quel est toujours le nom précis de la figure ?
4. Est-elle encore aussi un losange ?
5. Corrige la phrase de Noé.

Étapes:
<!-- optitab:1 -->
## Question 1 : Que deviennent les longueurs des côtés ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Le papier n’a été ni coupé ni étiré ; chaque côté garde sa longueur.
:::

::: resultat
Les 4 côtés gardent la même longueur.
:::

## Question 2 : Que deviennent les angles droits ?

::: methode
Comparer l’ouverture avec le coin droit de l’équerre.
:::

::: etape Observer et vérifier
Pose l’équerre en tournant aussi l’instrument. Le coin droit coïncide encore avec chaque coin.
:::

::: resultat
Les 4 angles restent droits.
:::

## Question 3 : Quel est toujours le nom précis de la figure ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Elle possède encore quatre côtés égaux et quatre angles droits.
:::

::: resultat
La figure reste un carré.
:::

## Question 4 : Est-elle encore aussi un losange ?

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
Un losange a quatre côtés de même longueur. Cette propriété est conservée.
:::

::: resultat
Oui, elle reste aussi un losange.
:::

## Question 5 : Corrige la phrase de Noé.

::: methode
Compter les éléments et vérifier les propriétés avec les instruments.
:::

::: etape Observer et vérifier
L’orientation change, mais les propriétés ne changent pas. On contrôle les coins plutôt que de se fier à leur direction.
:::

::: resultat
Le carré tourné a toujours 4 angles droits.
:::

Solution:
<!-- optitab:1 -->
1. Les 4 côtés gardent la même longueur.
2. Les 4 angles restent droits.
3. La figure reste un carré.
4. Oui, elle reste aussi un losange.
5. Le carré tourné a toujours 4 angles droits.
