=== Découverte - Lire trois unités et des millièmes
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Donner la partie entière de $3{,}205$ et nommer les trois rangs après la virgule.
2. Donner le chiffre de chaque rang décimal et sa contribution.
3. Lire le nombre en unités et millièmes.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Séparer les unités entières des parts d’unité.
:::

::: etape Raisonner avec les données
Avant la virgule, on lit 3. Après viennent les dixièmes, centièmes et millièmes.
:::

::: resultat 
Partie entière : 3 ; dixièmes, centièmes, millièmes.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Un chiffre indique combien de parts de son rang sont présentes.
:::

::: etape Raisonner avec les données
Les chiffres sont 2, 0, 5. Leurs contributions sont $\frac{2}{10}$, $\frac{0}{100}$ et $\frac{5}{1000}$.
:::

::: resultat 
2 dixièmes, 0 centièmes et 5 millièmes.
:::

## Question 3 : Vérifier et conclure

::: methode 
Tout exprimer dans le rang des millièmes.
:::

::: etape Raisonner avec les données
La partie décimale compte 205 millièmes, en plus des 3 unités entières.
:::

::: resultat 
3 unités et 205 millièmes.
:::

Solution:
<!-- optitab:1 -->
1. Partie entière : 3 ; dixièmes, centièmes, millièmes.
2. 2 dixièmes, 0 centièmes et 5 millièmes.
3. 3 unités et 205 millièmes.

=== Découverte - Des centièmes à la virgule
Id: nouveau-2
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire $\frac{237}{100}$ avec une virgule.
2. Écrire le nombre comme entier plus une fraction décimale inférieure à 1.
3. Décomposer avec des dixièmes, centièmes et, si besoin, millièmes de numérateurs inférieurs à 10.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Le dénominateur fixe le rang du dernier chiffre.
:::

::: etape Raisonner avec les données
Le dénominateur 100 impose deux chiffres décimaux. On place 2 unités avant la virgule.
:::

::: resultat 
$2{,}37$.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Séparer les groupes complets et le reste.
:::

::: etape Raisonner avec les données
$237=2\times100+37$.
:::

::: resultat 
$2+\frac{37}{100}$.
:::

## Question 3 : Vérifier et conclure

::: methode 
Lire chaque rang et omettre les contributions nulles.
:::

::: etape Raisonner avec les données
Chaque chiffre occupe son rang : 2,37. Les zéros intérieurs ne changent pas la place des autres chiffres.
:::

::: resultat 
$2+\frac{3}{10}+\frac{7}{100}$.
:::

Solution:
<!-- optitab:1 -->
1. $2{,}37$.
2. $2+\frac{37}{100}$.
3. $2+\frac{3}{10}+\frac{7}{100}$.

=== Découverte - Le zéro final ou le zéro intérieur
Id: nouveau-3
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Comparer $\frac{35}{10}$ et $\frac{350}{100}$.
2. Écrire leur valeur commune avec une virgule.
3. Comparer cette valeur à $3{,}05$.

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Exprimer les deux nombres dans le même rang.
:::

::: etape Raisonner avec les données
$35\times10=350$ et $10\times10=100$. Les fractions ont la même valeur.
:::

::: resultat 
$\frac{35}{10}=\frac{350}{100}$.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Placer les chiffres selon les rangs du dénominateur.
:::

::: etape Raisonner avec les données
$35$ parts de taille $\frac{1}{10}$ donnent $3{,}5$.
:::

::: resultat 
$3{,}5$.
:::

## Question 3 : Vérifier et conclure

::: methode 
Aligner les rangs avec un zéro final.
:::

::: etape Raisonner avec les données
La valeur commune est $3{,}50$. Au même rang, $350>305$.
:::

::: resultat 
$3{,}5>3{,}05$.
:::

Solution:
<!-- optitab:1 -->
1. $\frac{35}{10}=\frac{350}{100}$.
2. $3{,}5$.
3. $3{,}5>3{,}05$.

=== Découverte - Cinq étiquettes décimales
Id: nouveau-4
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Nombres à comparer : $5{,}800$, $5{,}790$, $5{,}080$, $5{,}780$, $5{,}805$.

1. Ranger les cinq nombres dans l’ordre croissant.
2. Donner le plus grand nombre et sa partie entière.
3. Un élève compare seulement les nombres formés après la virgule, sans aligner les rangs. Cette méthode est-elle fiable ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Comprendre et répondre

::: methode 
Comparer rang par rang, avec trois décimales pour s’aider.
:::

::: etape Raisonner avec les données
Les parties entières sont d’abord comparées. À égalité, on compare les dixièmes, puis les centièmes, puis les millièmes.
:::

::: resultat 
$5{,}080<5{,}780<5{,}790<5{,}800<5{,}805$.
:::

## Question 2 : Expliquer le raisonnement

::: methode 
Lire la dernière valeur du rangement et ses unités entières.
:::

::: etape Raisonner avec les données
Le plus grand est $5{,}805$. Les chiffres avant la virgule donnent 5.
:::

::: resultat 
$5{,}805$ ; partie entière 5.
:::

## Question 3 : Vérifier et conclure

::: methode 
Les chiffres n’ont pas la même valeur selon leur rang.
:::

::: etape Raisonner avec les données
Par exemple $5{,}8=5{,}800$ dépasse $5{,}79=5{,}790$, bien que $8<79$. Il faut comparer des rangs identiques.
:::

::: resultat 
Non : il faut aligner les rangs décimaux.
:::

Solution:
<!-- optitab:1 -->
1. $5{,}080<5{,}780<5{,}790<5{,}800<5{,}805$.
2. $5{,}805$ ; partie entière 5.
3. Non : il faut aligner les rangs décimaux.
