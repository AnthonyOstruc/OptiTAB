Titre: Découvrir les nombres relatifs

<!-- optitab:1 -->
::: objectifs
- Utiliser des nombres relatifs pour décrire des situations : températures, altitudes, étages, dates.
- Connaître le signe, la distance à zéro et l'opposé d'un nombre relatif.
- Lire et placer des points sur une droite graduée.
- Lire et placer des points dans un repère du plan : abscisse et ordonnée.
- Comparer, ranger et encadrer des nombres relatifs.
:::

## I. Des nombres pour aller « sous zéro »

Les nombres connus jusqu'ici ne suffisent pas pour dire qu'il fait $4$ degrés **sous** zéro, qu'un plongeur est $20$ m **sous** le niveau de la mer ou qu'un parking est au **2e sous-sol**. On utilise alors des nombres précédés d'un signe.

[IMAGE_1]

::: definition Nombres relatifs
- Un **nombre positif** s'écrit avec le signe $+$ ou sans signe : $+6 = 6$ ; $+2{,}5 = 2{,}5$.
- Un **nombre négatif** s'écrit toujours avec le signe $-$ : $-4$ ; $-0{,}5$ ; $-120$.
- Les nombres positifs et les nombres négatifs forment les **nombres relatifs**.
:::

::: remarque Le cas de zéro
$0$ est le seul nombre qui est à la fois positif et négatif : on l'écrit sans signe. Un nombre **strictement négatif** est un nombre négatif différent de $0$.
:::

::: exemple Traduire une situation par un nombre relatif
| Situation | Nombre relatif |
|---|---|
| Il fait $4$ degrés sous zéro. | $-4$ °C |
| Un aigle vole à $1\,200$ m d'altitude. | $+1\,200$ m |
| Un plongeur est à $20$ m sous le niveau de la mer. | $-20$ m |
| L'ascenseur s'arrête au 2e sous-sol. | étage $-2$ |
| Une ville est fondée en l'an $300$ avant J.-C. | année $-300$ |
| Un compte bancaire a un découvert de $45$ €. | solde de $-45$ € |
:::

::: retenir
Le signe $-$ indique « en dessous » d'une référence (zéro degré, niveau de la mer, rez-de-chaussée, naissance de J.-C.) ; le signe $+$ indique « au-dessus ».
:::

## II. Se repérer sur une droite graduée

::: definition Droite graduée et abscisse
Une **droite graduée** est une droite sur laquelle on a choisi :
- un point $O$, l'**origine**, qui représente le nombre $0$ ;
- un **sens** (indiqué par la flèche) ;
- une **unité** de longueur, reportée régulièrement à partir de l'origine.

Chaque point de la droite est repéré par un nombre relatif, son **abscisse**. On écrit $E(-4)$ pour dire que le point $E$ a pour abscisse $-4$.
:::

[IMAGE_2]

Sur cette droite, $E(-4)$, $F(-1{,}5)$ et $G(2{,}5)$ : les points d'abscisse négative sont à gauche de l'origine, ceux d'abscisse positive à droite.

::: methode Lire l'abscisse d'un point
1. Trouver ce que représente **un intervalle** entre deux graduations : diviser l'écart entre deux nombres écrits par le nombre d'intervalles qui les séparent.
2. Compter les intervalles entre l'origine (ou une graduation connue) et le point.
3. Mettre le signe : $-$ à gauche de l'origine, $+$ (ou rien) à droite.
:::

::: exemple
Entre $0$ et $1$, on compte $2$ intervalles : un intervalle représente $1 \div 2 = 0{,}5$. Le point $F$ est à $3$ intervalles à gauche de $0$, soit à $3 \times 0{,}5 = 1{,}5$ unité de l'origine, du côté gauche : son abscisse est $-1{,}5$.
:::

::: methode Placer un point d'abscisse donnée
Partir de l'origine et se déplacer de la distance à zéro du nombre : vers la **droite** si le nombre est positif, vers la **gauche** s'il est négatif.
:::

::: attention Erreurs fréquentes
- Compter les **traits** au lieu des **intervalles** : entre $0$ et $1$, il y a $3$ traits mais seulement $2$ intervalles.
- Oublier le signe $-$ d'un point situé à gauche de l'origine.
:::

## III. Distance à zéro et opposé

::: definition Distance à zéro
La **distance à zéro** d'un nombre relatif est la distance entre l'origine et le point qui a ce nombre pour abscisse. C'est le nombre « sans son signe » : elle est toujours positive.
:::

::: exemple
- La distance à zéro de $-6{,}5$ est $6{,}5$.
- La distance à zéro de $+9$ est $9$.
- La distance à zéro de $0$ est $0$.
:::

::: definition Nombres opposés
Deux nombres sont **opposés** s'ils ont la **même distance à zéro** et des **signes contraires**. Sur une droite graduée, les points correspondants sont de part et d'autre de l'origine, à la même distance de celle-ci.
:::

[IMAGE_3]

::: exemple
- L'opposé de $3{,}5$ est $-3{,}5$ ; l'opposé de $-3{,}5$ est $3{,}5$.
- L'opposé de $-12$ est $12$.
- L'opposé de $0$ est $0$.
:::

::: attention Erreur fréquente
Une distance n'est jamais négative : la distance à zéro de $-7$ est $7$, et non $-7$.
:::

## IV. Se repérer dans le plan

::: definition Repère du plan
Un **repère du plan** est formé de deux droites graduées perpendiculaires qui se coupent en leur origine commune $O$ :
- l'**axe des abscisses**, horizontal, orienté vers la droite ;
- l'**axe des ordonnées**, vertical, orienté vers le haut.
:::

::: definition Coordonnées d'un point
Tout point $M$ du plan est repéré par deux nombres relatifs, ses **coordonnées** : son **abscisse** (lue sur l'axe horizontal) puis son **ordonnée** (lue sur l'axe vertical). On écrit $M(\text{abscisse}\,;\,\text{ordonnée})$.
:::

[IMAGE_4]

::: methode Lire les coordonnées d'un point
1. Depuis le point, descendre (ou monter) verticalement jusqu'à l'axe des abscisses : on lit l'**abscisse**.
2. Depuis le point, aller horizontalement jusqu'à l'axe des ordonnées : on lit l'**ordonnée**.
3. Écrire les deux nombres dans l'ordre, séparés par un point-virgule.
:::

::: exemple
Sur la figure, $P(2\,;\,3)$ : on avance de $2$ vers la droite, puis on monte de $3$ (pointillés verts). De même, $Q(-4\,;\,1)$, $R(-3\,;\,-2)$ et $S(4\,;\,-2)$. Les points $R$ et $S$ ont la même ordonnée : ils sont sur une même ligne horizontale.
:::

::: methode Placer un point de coordonnées données
Pour placer $M(-1\,;\,4)$ : partir de $O$, se déplacer de $1$ unité vers la **gauche** (abscisse $-1$), puis de $4$ unités vers le **haut** (ordonnée $4$).
:::

::: remarque
- Un point de l'axe des abscisses a une ordonnée nulle : par exemple $(5\,;\,0)$.
- Un point de l'axe des ordonnées a une abscisse nulle : par exemple $(0\,;\,-3)$.
- L'origine a pour coordonnées $(0\,;\,0)$.
:::

::: attention Erreur fréquente
Inverser l'ordre des coordonnées : $(2\,;\,3)$ et $(3\,;\,2)$ ne sont pas le même point. On donne **toujours l'abscisse en premier**.
:::

## V. Comparer et ranger des nombres relatifs

::: propriete Comparer sur une droite graduée
Sur une droite graduée orientée vers la droite, de deux nombres, le plus petit est celui qui est le plus **à gauche**.
:::

[IMAGE_5]

::: propriete Règles de comparaison
- Un nombre négatif est plus petit qu'un nombre positif : $-15 < 2$.
- Deux nombres positifs se rangent dans l'ordre de leurs distances à zéro : $3{,}7 < 5$.
- Deux nombres négatifs se rangent dans l'ordre **inverse** de leurs distances à zéro : le plus petit est le **plus éloigné de zéro**. $-8 < -3$, car $8 > 3$.
:::

::: methode Comparer deux nombres négatifs décimaux
Comparer leurs distances à zéro (en complétant si besoin avec des zéros), puis inverser le sens.

Pour $-4{,}7$ et $-4{,}15$ : $4{,}70 > 4{,}15$, donc $-4{,}7 < -4{,}15$.
:::

::: definition Ordre croissant, ordre décroissant
- Ranger dans l'**ordre croissant**, c'est ranger du plus petit au plus grand (avec le symbole $<$).
- Ranger dans l'**ordre décroissant**, c'est ranger du plus grand au plus petit (avec le symbole $>$).
:::

::: exemple Ranger six nombres
Les nombres $1{,}8$ ; $-5$ ; $0$ ; $-0{,}5$ ; $-5{,}2$ ; $2$ rangés dans l'ordre croissant :
$$-5{,}2 < -5 < -0{,}5 < 0 < 1{,}8 < 2$$
:::

::: methode Encadrer un nombre relatif
Encadrer $-3{,}6$ par deux entiers consécutifs : $-3{,}6$ est entre $-4$ et $-3$, et il est plus éloigné de zéro que $-3$. Donc :
$$-4 < -3{,}6 < -3$$
:::

::: attention Erreurs fréquentes
- Écrire $-9 > -2$ « parce que $9 > 2$ » : c'est faux, $-9$ est plus à gauche, donc $-9 < -2$.
- Confondre les deux classements : $-6$ est **plus petit** que $4$, mais il est **plus loin de zéro** que $4$.
:::

::: retenir
- Un nombre relatif a un **signe** et une **distance à zéro**.
- Deux nombres **opposés** ont la même distance à zéro et des signes contraires.
- Sur une droite graduée, un point est repéré par son **abscisse** ; dans un repère du plan, par son **abscisse puis son ordonnée**.
- Pour comparer : le plus petit est le plus à gauche ; entre deux négatifs, le plus petit est le plus éloigné de zéro.
:::
