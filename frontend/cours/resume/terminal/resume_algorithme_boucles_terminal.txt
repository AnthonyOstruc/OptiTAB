===Résumé Boucles et Itérations en Python

Titre: Résumé : Boucles et Itérations en Python

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. La fonction range()</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <p>La fonction <code>range()</code> génère une séquence de nombres. La borne de fin est <strong>toujours exclue</strong>.</p>
    
    <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
        <thead>
            <tr style="background:#3498db; color:white;">
                <th style="border:1px solid #ddd; padding:12px;">Syntaxe</th>
                <th style="border:1px solid #ddd; padding:12px;">Génère</th>
                <th style="border:1px solid #ddd; padding:12px;">Exemple</th>
            </tr>
        </thead>
        <tbody>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;"><code>range(n)</code></td>
                <td style="border:1px solid #ddd; padding:10px;">De 0 à n-1</td>
                <td style="border:1px solid #ddd; padding:10px;"><code>range(5)</code> → 0, 1, 2, 3, 4</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;"><code>range(début, fin)</code></td>
                <td style="border:1px solid #ddd; padding:10px;">De début à fin-1</td>
                <td style="border:1px solid #ddd; padding:10px;"><code>range(2, 7)</code> → 2, 3, 4, 5, 6</td>
            </tr>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;"><code>range(début, fin, pas)</code></td>
                <td style="border:1px solid #ddd; padding:10px;">Avec un incrément</td>
                <td style="border:1px solid #ddd; padding:10px;"><code>range(0, 10, 2)</code> → 0, 2, 4, 6, 8</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;"><code>range(fin, début, -pas)</code></td>
                <td style="border:1px solid #ddd; padding:10px;">Décompte (pas négatif)</td>
                <td style="border:1px solid #ddd; padding:10px;"><code>range(10, 0, -1)</code> → 10, 9, 8, ..., 1</td>
            </tr>
        </tbody>
    </table>
    
    <div style="background:#fef3c7; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #f59e0b;">
        <strong>⚠️ Important :</strong> <code>range(10)</code> génère 0 à 9 (pas jusqu'à 10 !)
    </div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. La boucle FOR</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
        <strong>Utilisation :</strong> Parcourt une séquence ou répète un nombre connu de fois
    </div>
    
    <h3 style="color:#34495e; margin-top:15px;">1. Avec range()</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">5</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(i)
    </div>
    <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
        <strong>Résultat :</strong> Affiche 0, 1, 2, 3, 4
    </div>

    <h3 style="color:#34495e; margin-top:15px;">2. Parcourir une liste</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        <span style="color:#ff79c6;">for</span> element <span style="color:#ff79c6;">in</span> [<span style="color:#f1fa8c;">"a"</span>, <span style="color:#f1fa8c;">"b"</span>, <span style="color:#f1fa8c;">"c"</span>]:<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(element)
    </div>
    <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
        <strong>Résultat :</strong> Affiche a, b, c
    </div>

    <div style="background:#fef3c7; padding:10px; border-radius:4px; margin:10px 0; border-left:6px solid #f59e0b;">
        <strong>⚠️ Syntaxe obligatoire :</strong><br>
        • Deux-points <code>:</code> après <code>in sequence</code><br>
        • Indentation de 4 espaces pour le bloc
    </div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. La boucle WHILE</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
        <strong>Utilisation :</strong> Répète <strong>tant qu'une condition est vraie</strong>
    </div>
    
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        compteur = <span style="color:#bd93f9;">1</span><br>
        <br>
        <span style="color:#ff79c6;">while</span> compteur <= <span style="color:#bd93f9;">5</span>:<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(compteur)<br>
        &nbsp;&nbsp;&nbsp;&nbsp;compteur = compteur + <span style="color:#bd93f9;">1</span>
    </div>
    <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
        <strong>Résultat :</strong> Affiche 1, 2, 3, 4, 5
    </div>

    <div style="background:#fdf2f2; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #e74c3c;">
        <strong>⚠️ Attention - Boucle infinie !</strong><br>
        Si la condition reste toujours vraie, la boucle ne s'arrête jamais.<br>
        Toujours s'assurer que la condition deviendra fausse à un moment donné.
    </div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Différence FOR vs WHILE</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <table style="width:100%; border-collapse:collapse; border:2px solid #3498db;">
        <thead>
            <tr style="background:#3498db; color:white;">
                <th style="border:1px solid #ddd; padding:12px; width:20%;">Boucle</th>
                <th style="border:1px solid #ddd; padding:12px;">Quand l'utiliser</th>
                <th style="border:1px solid #ddd; padding:12px;">Exemple d'usage</th>
            </tr>
        </thead>
        <tbody>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;"><strong><code>for</code></strong></td>
                <td style="border:1px solid #ddd; padding:10px;">Nombre d'itérations <strong>connu à l'avance</strong></td>
                <td style="border:1px solid #ddd; padding:10px;">Répéter n fois, parcourir une liste</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;"><strong><code>while</code></strong></td>
                <td style="border:1px solid #ddd; padding:10px;">Répéter <strong>tant qu'une condition</strong> est vraie</td>
                <td style="border:1px solid #ddd; padding:10px;">Saisie utilisateur, jeu, recherche</td>
            </tr>
        </tbody>
    </table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Instructions break et continue</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <h3 style="color:#34495e; margin-top:0;">1. Instruction <code>break</code></h3>
    <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
        <strong>Effet :</strong> Sort <strong>immédiatement</strong> de la boucle
    </div>
    
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">10</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">if</span> i == <span style="color:#bd93f9;">5</span>:<br>
        &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">break</span><br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(i)
    </div>
    <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
        <strong>Résultat :</strong> Affiche 0, 1, 2, 3, 4 (s'arrête quand i = 5)
    </div>

    <h3 style="color:#34495e; margin-top:20px;">2. Instruction <code>continue</code></h3>
    <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
        <strong>Effet :</strong> Passe à l'<strong>itération suivante</strong> (saute le reste du bloc)
    </div>
    
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, <span style="color:#bd93f9;">6</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">if</span> i % <span style="color:#bd93f9;">2</span> == <span style="color:#bd93f9;">0</span>:<br>
        &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">continue</span><br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(i)
    </div>
    <div style="background:#e8f5e8; padding:8px; border-radius:4px; margin:10px 0;">
        <strong>Résultat :</strong> Affiche 1, 3, 5 (saute les nombres pairs)
    </div>

    <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
        <thead>
            <tr style="background:#3498db; color:white;">
                <th style="border:1px solid #ddd; padding:10px;">Instruction</th>
                <th style="border:1px solid #ddd; padding:10px;">Action</th>
            </tr>
        </thead>
        <tbody>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:8px;"><code>break</code></td>
                <td style="border:1px solid #ddd; padding:8px;">Arrête la boucle complètement</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:8px;"><code>continue</code></td>
                <td style="border:1px solid #ddd; padding:8px;">Passe à l'itération suivante</td>
            </tr>
        </tbody>
    </table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Exemples types</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <h3 style="color:#34495e; margin-top:0;">1. Calculer une somme</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        somme = <span style="color:#bd93f9;">0</span><br>
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, <span style="color:#bd93f9;">11</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;somme = somme + i<br>
        <span style="color:#50fa7b;">print</span>(somme) <span style="color:#6272a4;"># Affiche 55</span>
    </div>

    <h3 style="color:#34495e; margin-top:15px;">2. Table de multiplication</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        nombre = <span style="color:#bd93f9;">7</span><br>
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, <span style="color:#bd93f9;">11</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"</span><span style="color:#8be9fd;">{nombre}</span><span style="color:#f1fa8c;"> × </span><span style="color:#8be9fd;">{i}</span><span style="color:#f1fa8c;"> = </span><span style="color:#8be9fd;">{nombre*i}</span><span style="color:#f1fa8c;">"</span>)
    </div>

    <h3 style="color:#34495e; margin-top:15px;">3. Calcul de factorielle</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        n = <span style="color:#bd93f9;">5</span><br>
        factorielle = <span style="color:#bd93f9;">1</span><br>
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, n + <span style="color:#bd93f9;">1</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;factorielle = factorielle * i<br>
        <span style="color:#50fa7b;">print</span>(factorielle) <span style="color:#6272a4;"># Affiche 120</span>
    </div>

    <h3 style="color:#34495e; margin-top:15px;">4. Moyenne d'une liste</h3>
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        notes = [<span style="color:#bd93f9;">14</span>, <span style="color:#bd93f9;">12</span>, <span style="color:#bd93f9;">16</span>, <span style="color:#bd93f9;">10</span>, <span style="color:#bd93f9;">18</span>]<br>
        somme = <span style="color:#bd93f9;">0</span><br>
        <span style="color:#ff79c6;">for</span> note <span style="color:#ff79c6;">in</span> notes:<br>
        &nbsp;&nbsp;&nbsp;&nbsp;somme = somme + note<br>
        moyenne = somme / <span style="color:#50fa7b;">len</span>(notes)<br>
        <span style="color:#50fa7b;">print</span>(moyenne) <span style="color:#6272a4;"># Affiche 14.0</span>
    </div>

    <div style="background:#e8f5e8; padding:10px; border-radius:4px; margin:10px 0;">
        <strong>💡 Astuce :</strong> Toujours <strong>initialiser</strong> les variables (somme, compteur, produit) avant la boucle
    </div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Boucles imbriquées</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <p>Une boucle à l'intérieur d'une autre boucle.</p>
    
    <div style="background:#2c3e50; color:#ffffff; padding:15px; border-radius:6px; margin:10px 0; font-family:monospace;">
        <span style="color:#ff79c6;">for</span> i <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, <span style="color:#bd93f9;">4</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#ff79c6;">for</span> j <span style="color:#ff79c6;">in</span> <span style="color:#50fa7b;">range</span>(<span style="color:#bd93f9;">1</span>, <span style="color:#bd93f9;">4</span>):<br>
        &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;<span style="color:#50fa7b;">print</span>(<span style="color:#f1fa8c;">f"</span><span style="color:#8be9fd;">{i}</span><span style="color:#f1fa8c;"> × </span><span style="color:#8be9fd;">{j}</span><span style="color:#f1fa8c;"> = </span><span style="color:#8be9fd;">{i*j}</span><span style="color:#f1fa8c;">"</span>)
    </div>

    <div style="background:#fef3c7; padding:10px; border-radius:4px; margin:10px 0; border-left:6px solid #f59e0b;">
        <strong>⚠️ Fonctionnement :</strong><br>
        • Pour chaque valeur de <code>i</code> (boucle externe), la boucle interne <code>j</code> s'exécute <strong>complètement</strong><br>
        • Attention à l'indentation : 4 espaces pour la première boucle, 8 espaces pour la seconde
    </div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <table style="width:100%; border-collapse:collapse; border:2px solid #3498db;">
        <thead>
            <tr style="background:#3498db; color:white;">
                <th style="border:1px solid #ddd; padding:12px;">Erreur</th>
                <th style="border:1px solid #ddd; padding:12px;">Explication</th>
            </tr>
        </thead>
        <tbody>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;">Boucle infinie avec <code>while</code></td>
                <td style="border:1px solid #ddd; padding:10px;">❌ Oublier d'incrémenter le compteur ou de modifier la condition</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;"><code>range(10)</code> génère 0 à 10</td>
                <td style="border:1px solid #ddd; padding:10px;">❌ Faux ! Génère 0 à 9 (la borne de fin est exclue)</td>
            </tr>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;">Oublier l'initialisation</td>
                <td style="border:1px solid #ddd; padding:10px;">❌ Toujours initialiser <code>somme = 0</code> avant la boucle</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;">Mauvaise indentation</td>
                <td style="border:1px solid #ddd; padding:10px;">❌ Les instructions dans la boucle doivent avoir 4 espaces</td>
            </tr>
            <tr style="background:#f8f9fa;">
                <td style="border:1px solid #ddd; padding:10px;">Modifier une liste pendant le parcours</td>
                <td style="border:1px solid #ddd; padding:10px;">❌ Ne pas ajouter/supprimer des éléments dans une liste qu'on parcourt</td>
            </tr>
            <tr style="background:#ffffff;">
                <td style="border:1px solid #ddd; padding:10px;">Oublier les deux-points</td>
                <td style="border:1px solid #ddd; padding:10px;">❌ <code>for i in range(5)</code> → doit être <code>for i in range(5):</code></td>
            </tr>
        </tbody>
    </table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IX. Méthodologie générale</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
    <div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
        <strong>📐 Démarche pour créer une boucle :</strong>
        <ol style="margin:10px 0; padding-left:20px;">
            <li><strong>Identifier</strong> ce qui doit être répété</li>
            <li><strong>Choisir</strong> le type de boucle (<code>for</code> ou <code>while</code>)</li>
            <li><strong>Initialiser</strong> les variables nécessaires (somme, compteur, etc.)</li>
            <li><strong>Écrire</strong> le corps de la boucle avec la bonne indentation</li>
            <li><strong>Vérifier</strong> que la condition d'arrêt existe (pour <code>while</code>)</li>
            <li><strong>Tester</strong> avec de petites valeurs</li>
        </ol>
    </div>
    
    <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
        <strong>Choix de la boucle :</strong>
        <ul style="margin:8px 0; padding-left:20px;">
            <li><strong><code>for</code></strong> : Nombre d'itérations connu, parcours de liste</li>
            <li><strong><code>while</code></strong> : Condition d'arrêt, nombre d'itérations inconnu</li>
        </ul>
    </div>
</div>

<div style="background:#ffffff; padding:15px; border-radius:6px; margin:15px 0; border:1px solid #e1e8ed;">
    <h3 style="color:#2c3e50; margin-top:0;">✅ Points clés à retenir</h3>

    <thead>
    <tr style="background:#3498db; color:white;">
    <th style="border:1px solid #ddd; padding:12px; width:30%;">Notion</th>

    </tr>
    </thead>
    <tbody>

    </tr>
    <tr style="background:#ffffff;">
    <td style="border:1px solid #ddd; padding:10px;"><strong>Boucle <code>while</code></strong></td>
    <td style="border:1px solid #ddd; padding:10px;">Pour répéter <strong>tant qu'une condition est vraie</strong></td>

    <tr style="background:#f8f9fa;">

    <td style="border:1px solid #ddd; padding:10px;">Génère 0, 1, 2, ..., n-1 (la borne de fin est <strong>exclue</strong>)</td>
    </tr>
    <tr style="background:#ffffff;">
    <td style="border:1px solid #ddd; padding:10px;"><strong><code>range(a, b)</code></strong></td>
    <td style="border:1px solid #ddd; padding:10px;">Génère a, a+1, ..., b-1 (b est exclu)</td>
    </tr>
    <tr style="background:#f8f9fa;">
    <td style="border:1px solid #ddd; padding:10px;"><strong><code>range(a, b, pas)</code></strong></td>
    <td style="border:1px solid #ddd; padding:10px;">Génère avec un incrément (peut être négatif pour décompter)</td>
    </tr>
    <tr style="background:#ffffff;">
    <td style="border:1px solid #ddd; padding:10px;"><strong><code>break</code></strong></td>
    <td style="border:1px solid #ddd; padding:10px;">Sort <strong>immédiatement</strong> de la boucle</td>
    </tr>
    <tr style="background:#f8f9fa;">
    <td style="border:1px solid #ddd; padding:10px;"><strong><code>continue</code></strong></td>

    <tr style="background:#ffffff;">
    <td style="border:1px solid #ddd; padding:10px;"><strong>Initialisation</strong></td>
    <td style="border:1px solid #ddd; padding:10px;">Toujours initialiser les variables (<code>somme = 0</code>, <code>produit = 1</code>) <strong>avant</strong> la boucle</td>
    </tr>
    <tr style="background:#f8f9fa;">
    <td style="border:1px solid #ddd; padding:10px;"><strong>Indentation</strong></td>

    </tr>
    <tr style="background:#ffffff;">
    <td style="border:1px solid #ddd; padding:10px;"><strong>Boucle infinie</strong></td>

    <td style="border:1px solid #ddd; padding:10px;"><strong>Syntaxe</strong></td>
