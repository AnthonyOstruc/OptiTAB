=== Découverte - Reconnaître un tableau de proportionnalité
Id: 2621
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Voici quatre tableaux.

**Tableau A** : masse et prix de cerises.

| Masse (kg) | $2$ | $5$ | $8$ |
|---|---|---|---|
| Prix (€) | $7$ | $17{,}5$ | $28$ |

**Tableau B** : âge et taille d'un enfant.

| Âge (ans) | $2$ | $6$ | $10$ |
|---|---|---|---|
| Taille (cm) | $86$ | $116$ | $138$ |

**Tableau C** : côté et périmètre d'un carré.

| Côté (cm) | $1{,}5$ | $4$ | $7$ |
|---|---|---|---|
| Périmètre (cm) | $6$ | $16$ | $28$ |

**Tableau D** : côté et aire d'un carré.

| Côté (cm) | $1$ | $3$ | $5$ |
|---|---|---|---|
| Aire (cm²) | $1$ | $9$ | $25$ |

1. Le tableau A est-il un tableau de proportionnalité ? Justifier par des calculs.
2. Même question pour les tableaux B, C et D.
3. Que représente le coefficient de proportionnalité du tableau A ?
4. Avec les données du tableau A, calculer le prix de $12$ kg de cerises, puis la masse de cerises que l'on peut acheter avec $49$ €.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le tableau A

::: methode
On calcule le quotient « prix $\div$ masse » pour chaque colonne : s'ils sont tous égaux, le tableau est un tableau de proportionnalité.
:::

::: etape Calculer les trois quotients
$$\frac{7}{2} = 3{,}5 \qquad \frac{17{,}5}{5} = 3{,}5 \qquad \frac{28}{8} = 3{,}5$$
:::

::: resultat
Les trois quotients sont égaux : le tableau A est un tableau de proportionnalité, de coefficient $3{,}5$.
:::

## Question 2 : Les tableaux B, C et D

::: etape Tableau B
$\dfrac{86}{2} = 43$ et $\dfrac{116}{6} \approx 19{,}3$. Deux quotients différents suffisent : inutile de calculer le troisième.
:::

::: etape Tableau C
$\dfrac{6}{1{,}5} = 4$, $\dfrac{16}{4} = 4$ et $\dfrac{28}{7} = 4$ : les quotients sont égaux.
:::

::: etape Tableau D
$\dfrac{1}{1} = 1$ et $\dfrac{9}{3} = 3$ : les quotients sont différents.
:::

::: resultat
- B : non, la taille d'un enfant n'est pas proportionnelle à son âge.
- C : oui, le périmètre d'un carré est proportionnel à son côté (coefficient $4$).
- D : non, l'aire d'un carré n'est pas proportionnelle à son côté.
:::

::: attention Erreur fréquente
Conclure « proportionnel » parce que les deux lignes augmentent ensemble (tableaux B et D) : il faut que les quotients soient **égaux**.
:::

## Question 3 : Le sens du coefficient

::: etape Lire le quotient avec ses unités
$\dfrac{7 \text{ €}}{2 \text{ kg}} = 3{,}5$ € par kg.
:::

::: resultat
Le coefficient $3{,}5$ est le prix d'un kilogramme de cerises : $3{,}50$ € le kg.
:::

## Question 4 : Utiliser le coefficient

::: methode
Pour passer de la masse au prix, on multiplie par $3{,}5$ ; pour passer du prix à la masse, on divise par $3{,}5$.
:::

::: etape Prix de $12$ kg
$12 \times 3{,}5 = 42$.
:::

::: etape Masse pour $49$ €
$49 \div 3{,}5 = 14$.
:::

[IMAGE_1]

::: resultat
$12$ kg de cerises coûtent $42$ € ; avec $49$ €, on achète $14$ kg de cerises.
:::

::: retenir
On multiplie par le coefficient pour passer de la première ligne à la seconde, on divise pour faire le chemin inverse.
:::

Solution:
<!-- optitab:1 -->
1. Oui : $\dfrac{7}{2} = \dfrac{17{,}5}{5} = \dfrac{28}{8} = 3{,}5$
2. B : non ; C : oui (coefficient $4$) ; D : non
3. Le prix d'un kilogramme : $3{,}50$ €
4. $42$ € ; $14$ kg

=== Découverte - Calculer une quatrième proportionnelle
Id: 2622
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Dans une papeterie, $6$ cahiers identiques coûtent $9{,}60$ €. Le prix payé est proportionnel au nombre de cahiers.

1. Calculer le prix d'un cahier, puis le prix de $15$ cahiers.
2. Combien de cahiers peut-on acheter au maximum avec $40$ € ?
3. Sans calculer le prix d'un cahier, trouver le prix de $3$ cahiers.
4. Calculer le prix de $9$ cahiers à l'aide d'un produit en croix.
5. Retrouver le prix de $15$ cahiers à partir des prix de $6$ et de $9$ cahiers.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le prix d'un cahier, puis de $15$ cahiers

::: methode
Passage à l'unité : on divise le prix par le nombre de cahiers, puis on multiplie.
:::

::: etape Le prix d'un cahier
$9{,}60 \div 6 = 1{,}60$.
:::

::: etape Le prix de $15$ cahiers
$15 \times 1{,}60 = 24$.
:::

::: resultat
Un cahier coûte $1{,}60$ € ; $15$ cahiers coûtent $24$ €.
:::

## Question 2 : Avec $40$ €

::: etape Combien de fois $1{,}60$ € dans $40$ € ?
$40 \div 1{,}60 = 25$.
:::

::: resultat
On peut acheter $25$ cahiers.
:::

## Question 3 : Le prix de $3$ cahiers

::: methode
Linéarité : $3$ cahiers, c'est la moitié de $6$ cahiers, donc le prix est divisé par $2$.
:::

::: etape Diviser par $2$
$9{,}60 \div 2 = 4{,}80$.
:::

::: resultat
$3$ cahiers coûtent $4{,}80$ €.
:::

## Question 4 : Le produit en croix

::: methode
Le prix est proportionnel au nombre de cahiers, donc les quotients sont égaux : $\dfrac{9{,}60}{6} = \dfrac{?}{9}$. Les produits en croix sont alors égaux.
:::

::: etape Écrire l'égalité des produits en croix
$$6 \times ? = 9 \times 9{,}60$$
:::

::: etape Calculer
$$? = \frac{9 \times 9{,}60}{6} = \frac{86{,}4}{6} = 14{,}40$$
:::

[IMAGE_1]

::: resultat
$9$ cahiers coûtent $14{,}40$ €.
:::

::: attention Erreur fréquente
Écrire $? = \dfrac{6 \times 9}{9{,}60}$ : on multiplie les deux nombres **en diagonale** l'un de l'autre ($9$ et $9{,}60$), puis on divise par le troisième ($6$).
:::

## Question 5 : Additionner deux colonnes

::: etape Décomposer $15$
$15 = 6 + 9$, donc le prix de $15$ cahiers est la somme des prix de $6$ et de $9$ cahiers.
:::

::: etape Calculer
$9{,}60 + 14{,}40 = 24$.
:::

::: resultat
$15$ cahiers coûtent $24$ € : on retrouve le résultat de la question 1.
:::

::: retenir
En situation de proportionnalité, on peut multiplier une colonne par un nombre ou additionner deux colonnes : c'est souvent plus rapide que le produit en croix.
:::

Solution:
<!-- optitab:1 -->
1. $1{,}60$ € ; $24$ €
2. $25$ cahiers
3. $4{,}80$ €
4. $6 \times ? = 9 \times 9{,}60$, donc $14{,}40$ €
5. $9{,}60 + 14{,}40 = 24$ €

=== Découverte - Appliquer un pourcentage
Id: 2623
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Prendre $t\ \%$ d'une quantité, c'est la multiplier par $\dfrac{t}{100}$.

1. Calculer $20\ \%$ de $80$.
2. Calculer $15\ \%$ de $240$ €, puis vérifier le résultat par un calcul mental.
3. Calculer $7{,}5\ \%$ de $1\,200$ €.
4. Calculer mentalement $50\ \%$ de $86$, $25\ \%$ de $60$ et $10\ \%$ de $37$.
5. Un collège compte $650$ élèves ; $42\ \%$ d'entre eux sont demi-pensionnaires. Combien y a-t-il de demi-pensionnaires ?
6. Calculer $120\ \%$ de $50$. Que remarque-t-on ?

Étapes:
<!-- optitab:1 -->
## Question 1 : $20\ \%$ de $80$

::: methode
On multiplie $80$ par $\dfrac{20}{100} = 0{,}2$.
:::

::: etape Calculer
$$\frac{20}{100} \times 80 = 0{,}2 \times 80 = 16$$
:::

::: resultat
$20\ \%$ de $80$ font $16$.
:::

## Question 2 : $15\ \%$ de $240$ €

::: etape Calculer
$$0{,}15 \times 240 = 36$$
:::

::: etape Vérifier mentalement
$10\ \%$ de $240$, c'est $24$ ; $5\ \%$, c'est la moitié, $12$. Donc $15\ \%$ font $24 + 12 = 36$.
:::

::: resultat
$15\ \%$ de $240$ € font $36$ €.
:::

## Question 3 : $7{,}5\ \%$ de $1\,200$ €

::: etape Calculer
$$\frac{7{,}5}{100} \times 1\,200 = 0{,}075 \times 1\,200 = 90$$
:::

::: resultat
$7{,}5\ \%$ de $1\,200$ € font $90$ €.
:::

::: attention Erreur fréquente
Écrire $7{,}5\ \% = 0{,}75$ : on divise par $100$, donc $7{,}5\ \% = 0{,}075$.
:::

## Question 4 : Calcul mental

::: etape Pourcentages simples
- $50\ \%$, c'est la moitié : $86 \div 2 = 43$.
- $25\ \%$, c'est le quart : $60 \div 4 = 15$.
- $10\ \%$, c'est le dixième : $37 \div 10 = 3{,}7$.
:::

::: resultat
$43$ ; $15$ ; $3{,}7$.
:::

## Question 5 : Les demi-pensionnaires

::: etape Calculer $42\ \%$ de $650$
$$0{,}42 \times 650 = 273$$
:::

::: resultat
Il y a $273$ demi-pensionnaires.
:::

## Question 6 : Plus de $100\ \%$

::: etape Calculer
$$\frac{120}{100} \times 50 = 1{,}2 \times 50 = 60$$
:::

::: resultat
$120\ \%$ de $50$ font $60$ : un pourcentage supérieur à $100\ \%$ donne un résultat plus grand que la quantité de départ.
:::

::: retenir
$100\ \%$ est la quantité entière ; $50\ \%$ la moitié ; $25\ \%$ le quart ; $10\ \%$ le dixième.
:::

Solution:
<!-- optitab:1 -->
1. $16$
2. $36$ € ($24 + 12$)
3. $90$ €
4. $43$ ; $15$ ; $3{,}7$
5. $273$ demi-pensionnaires
6. $60$ : plus que $50$

=== Découverte - Lire la proportionnalité sur un graphique
Id: 2624
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Trois représentations graphiques $\mathcal{G}_1$, $\mathcal{G}_2$ et $\mathcal{G}_3$ donnent le prix de trois produits en fonction de la masse achetée. Le point $A$ appartient à $\mathcal{G}_1$.

[IMAGE_1]

1. Lequel de ces graphiques représente une situation de proportionnalité ? Justifier.
2. Lire les coordonnées du point $A$. En déduire le coefficient de proportionnalité de $\mathcal{G}_1$.
3. Lire sur $\mathcal{G}_1$ le prix de $4$ kg, puis le vérifier par un calcul.
4. Expliquer pourquoi $\mathcal{G}_2$ ne représente pas une situation de proportionnalité. Le confirmer avec les points de $\mathcal{G}_2$ d'abscisses $2$ et $4$.
5. $\mathcal{G}_3$ passe par l'origine. Représente-t-il une situation de proportionnalité ? Utiliser les points de $\mathcal{G}_3$ de coordonnées $(2\,;1{,}4)$ et $(4\,;5{,}6)$.
6. Avec le produit $\mathcal{G}_1$, quelle masse peut-on acheter avec $18$ € ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le graphique proportionnel

::: methode
Une situation de proportionnalité est représentée par des points alignés sur une **droite** qui passe par l'**origine**.
:::

::: etape Examiner chaque graphique
- $\mathcal{G}_1$ est une droite qui passe par l'origine.
- $\mathcal{G}_2$ est une droite qui ne passe pas par l'origine.
- $\mathcal{G}_3$ passe par l'origine mais ce n'est pas une droite.
:::

::: resultat
Seul $\mathcal{G}_1$ représente une situation de proportionnalité.
:::

## Question 2 : Le coefficient de $\mathcal{G}_1$

::: etape Lire les coordonnées de $A$
$A(5\,;12)$ : $5$ kg coûtent $12$ €.
:::

::: etape Calculer le quotient
$$\frac{12}{5} = 2{,}4$$
:::

::: resultat
Le coefficient est $2{,}4$ : ce produit coûte $2{,}40$ € le kilogramme.
:::

## Question 3 : Le prix de $4$ kg

::: etape Lecture graphique
On part de $4$ sur l'axe des masses, on monte jusqu'à $\mathcal{G}_1$, puis on lit l'ordonnée : un peu moins de $10$ €.
:::

::: etape Calcul
$$4 \times 2{,}4 = 9{,}6$$
:::

[IMAGE_2]

::: resultat
$4$ kg coûtent $9{,}60$ €.
:::

## Question 4 : Le graphique $\mathcal{G}_2$

::: etape Lire l'ordonnée à l'origine
$\mathcal{G}_2$ coupe l'axe des ordonnées en $6$ : pour $0$ kg, on paierait $6$ €. La droite ne passe pas par l'origine.
:::

::: etape Comparer deux quotients
Les points d'abscisses $2$ et $4$ sont $(2\,;9)$ et $(4\,;12)$ : $\dfrac{9}{2} = 4{,}5$ et $\dfrac{12}{4} = 3$.
:::

::: resultat
Les quotients sont différents : $\mathcal{G}_2$ ne représente pas une situation de proportionnalité.
:::

::: attention Erreur fréquente
Croire que toute droite représente une situation de proportionnalité : il faut qu'elle passe par l'origine.
:::

## Question 5 : Le graphique $\mathcal{G}_3$

::: etape Comparer deux quotients
$\dfrac{1{,}4}{2} = 0{,}7$ et $\dfrac{5{,}6}{4} = 1{,}4$.
:::

::: resultat
Non : les quotients sont différents, les points ne sont pas alignés avec l'origine. Passer par l'origine ne suffit pas.
:::

## Question 6 : La masse pour $18$ €

::: etape Diviser par le coefficient
$$18 \div 2{,}4 = 7{,}5$$
:::

::: resultat
Avec $18$ €, on peut acheter $7{,}5$ kg de ce produit.
:::

::: retenir
Les deux conditions sont nécessaires : une **droite** et qui **passe par l'origine**.
:::

Solution:
<!-- optitab:1 -->
1. $\mathcal{G}_1$ : droite passant par l'origine
2. $A(5\,;12)$ ; coefficient $2{,}4$
3. $9{,}60$ €
4. Elle ne passe pas par l'origine ; $4{,}5 \neq 3$
5. Non ($0{,}7 \neq 1{,}4$)
6. $7{,}5$ kg

=== Découverte - Augmenter ou diminuer d'un pourcentage
Id: 2625
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Augmenter de $t\ \%$, c'est multiplier par $1 + \dfrac{t}{100}$ ; diminuer de $t\ \%$, c'est multiplier par $1 - \dfrac{t}{100}$.

1. Une veste à $60$ € est soldée à $-30\ \%$. Calculer le montant de la réduction, puis le nouveau prix.
2. Retrouver le nouveau prix de la veste en un seul calcul, avec un coefficient multiplicateur.
3. Un loyer de $250$ € augmente de $8\ \%$. Calculer le nouveau loyer.
4. Donner le coefficient multiplicateur d'une hausse de $25\ \%$, puis d'une baisse de $40\ \%$.
5. Après une réduction de $15\ \%$, un article coûte $68$ €. Quel était son prix avant la réduction ?
6. Un prix de $100$ € augmente de $10\ \%$, puis le nouveau prix baisse de $10\ \%$. Revient-on à $100$ € ?

Étapes:
<!-- optitab:1 -->
## Question 1 : La réduction de la veste

::: etape Le montant de la réduction
$30\ \%$ de $60$ € : $0{,}3 \times 60 = 18$.
:::

::: etape Le nouveau prix
$60 - 18 = 42$.
:::

::: resultat
La réduction est de $18$ € ; la veste coûte $42$ €.
:::

## Question 2 : Avec le coefficient multiplicateur

::: methode
Après une baisse de $30\ \%$, il reste $100\ \% - 30\ \% = 70\ \%$ du prix : on multiplie par $0{,}7$.
:::

::: etape Calculer
$$60 \times 0{,}7 = 42$$
:::

::: resultat
On retrouve $42$ € en un seul calcul.
:::

## Question 3 : Le nouveau loyer

::: etape Le coefficient
$1 + \dfrac{8}{100} = 1{,}08$.
:::

::: etape Calculer
$$250 \times 1{,}08 = 270$$
:::

::: resultat
Le nouveau loyer est de $270$ €.
:::

## Question 4 : Deux coefficients

::: etape Hausse de $25\ \%$
$1 + 0{,}25 = 1{,}25$.
:::

::: etape Baisse de $40\ \%$
$1 - 0{,}40 = 0{,}6$.
:::

::: resultat
Les coefficients sont $1{,}25$ et $0{,}6$.
:::

## Question 5 : Le prix avant la réduction

::: methode
Après une réduction de $15\ \%$, il reste $85\ \%$ du prix de départ. Le prix payé est proportionnel au prix de départ : on utilise un tableau de proportionnalité.
:::

::: etape Le tableau
| Pourcentage | $85$ | $100$ |
|---|---|---|
| Prix (€) | $68$ | ? |
:::

::: etape Produit en croix
$$? = \frac{68 \times 100}{85} = 80$$
:::

::: resultat
L'article coûtait $80$ € avant la réduction.
:::

::: attention Erreur fréquente
Ajouter $15\ \%$ à $68$ € ($68 \times 1{,}15 = 78{,}20$ €) : les $15\ \%$ portent sur le prix **de départ**, pas sur $68$ €. Vérification : $80 \times 0{,}85 = 68$.
:::

## Question 6 : Une hausse puis une baisse

::: etape La hausse
$100 \times 1{,}1 = 110$.
:::

::: etape La baisse
$110 \times 0{,}9 = 99$.
:::

[IMAGE_1]

::: resultat
Non : on obtient $99$ €. La baisse de $10\ \%$ porte sur $110$ €, elle vaut $11$ €, plus que la hausse de $10$ €.
:::

::: retenir
Une évolution en pourcentage, c'est une multiplication par un coefficient. Deux évolutions qui se suivent ne se compensent pas forcément.
:::

Solution:
<!-- optitab:1 -->
1. $18$ € ; $42$ €
2. $60 \times 0{,}7 = 42$ €
3. $250 \times 1{,}08 = 270$ €
4. $1{,}25$ ; $0{,}6$
5. $\dfrac{68 \times 100}{85} = 80$ €
6. Non : $99$ €

=== Découverte - Utiliser une échelle
Id: 2626
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Sur un plan, les longueurs sont proportionnelles aux longueurs réelles. L'échelle est le quotient « longueur sur le plan $\div$ longueur réelle », les deux longueurs étant dans la même unité.

1. Sur un plan à l'échelle $\dfrac{1}{200}$, un mur mesure $3$ cm. Quelle est sa longueur réelle ?
2. Sur ce plan, quelle longueur représente une pièce de $4{,}5$ m de long ?
3. Sur une carte au $\dfrac{1}{25\,000}$, quelle distance réelle représentent $4$ cm ?
4. Sur cette carte, quelle longueur représente un chemin de $3{,}5$ km ?
5. Sur un autre plan, $6$ cm représentent $12$ m. Quelle est l'échelle de ce plan ?
6. Une maquette de voiture est à l'échelle $\dfrac{1}{43}$. La voiture réelle mesure $4{,}30$ m. Quelle est la longueur de la maquette ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Du plan à la réalité

::: methode
À l'échelle $\dfrac{1}{200}$, $1$ cm sur le plan représente $200$ cm dans la réalité : on multiplie par $200$.
:::

::: etape Calculer
$3 \times 200 = 600$ cm.
:::

::: resultat
Le mur mesure $600$ cm, soit $6$ m.
:::

## Question 2 : De la réalité au plan

::: etape Convertir en cm
$4{,}5$ m $= 450$ cm.
:::

::: etape Diviser par $200$
$450 \div 200 = 2{,}25$.
:::

::: resultat
La pièce mesure $2{,}25$ cm sur le plan.
:::

::: attention Erreur fréquente
Diviser $4{,}5$ par $200$ sans convertir : on obtient $0{,}022\,5$… en mètres. On convertit d'abord tout en centimètres.
:::

## Question 3 : Sur la carte

::: etape Multiplier par $25\,000$
$4 \times 25\,000 = 100\,000$ cm.
:::

::: etape Convertir
$100\,000$ cm $= 1\,000$ m $= 1$ km.
:::

::: resultat
$4$ cm sur la carte représentent $1$ km.
:::

## Question 4 : Le chemin sur la carte

::: etape Convertir en cm
$3{,}5$ km $= 3\,500$ m $= 350\,000$ cm.
:::

::: etape Diviser par $25\,000$
$350\,000 \div 25\,000 = 14$.
:::

::: resultat
Le chemin mesure $14$ cm sur la carte.
:::

## Question 5 : Trouver l'échelle

::: methode
On écrit les deux longueurs dans la même unité, puis on calcule le quotient « plan $\div$ réel ».
:::

::: etape Convertir
$12$ m $= 1\,200$ cm.
:::

::: etape Calculer le quotient
$$\frac{6}{1\,200} = \frac{1}{200}$$
:::

::: resultat
L'échelle du plan est $\dfrac{1}{200}$.
:::

## Question 6 : La maquette

::: etape Convertir
$4{,}30$ m $= 430$ cm.
:::

::: etape Diviser par $43$
$430 \div 43 = 10$.
:::

::: resultat
La maquette mesure $10$ cm.
:::

::: retenir
À l'échelle $\dfrac{1}{n}$ : longueur réelle $= n \times$ longueur sur le plan, les deux dans la même unité.
:::

Solution:
<!-- optitab:1 -->
1. $600$ cm $= 6$ m
2. $2{,}25$ cm
3. $1$ km
4. $14$ cm
5. $\dfrac{1}{200}$
6. $10$ cm

=== Découverte - Calculer une distance à vitesse constante
Id: 2627
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Une voiture roule à la vitesse constante de $90$ km/h : la distance parcourue est proportionnelle à la durée du trajet.

1. Quelle distance parcourt-elle en $30$ min ?
2. Convertir $2$ h $20$ min en heures, puis calculer la distance parcourue pendant cette durée.
3. Quelle distance parcourt-elle en $1$ h $40$ min ?
4. Combien de temps lui faut-il pour parcourir $270$ km ?
5. Quel est le coefficient de proportionnalité ? Que représente-t-il ?
6. Si la voiture s'arrête $15$ minutes en route, la distance reste-t-elle proportionnelle à la durée totale du trajet ?

Étapes:
<!-- optitab:1 -->
## Question 1 : En $30$ minutes

::: methode
Distance $=$ vitesse $\times$ durée, la durée étant exprimée en heures.
:::

::: etape Convertir et calculer
$30$ min $= 0{,}5$ h, donc $90 \times 0{,}5 = 45$.
:::

::: resultat
En $30$ min, la voiture parcourt $45$ km.
:::

## Question 2 : En $2$ h $20$ min

::: etape Convertir la durée
$20$ min $= \dfrac{20}{60}$ h $= \dfrac{1}{3}$ h, donc $2$ h $20$ min $= 2 + \dfrac{1}{3} = \dfrac{7}{3}$ h.
:::

::: etape Calculer la distance
$$90 \times \frac{7}{3} = \frac{630}{3} = 210$$
:::

::: resultat
En $2$ h $20$ min, la voiture parcourt $210$ km.
:::

::: attention Erreur fréquente

=== Entraînement - Comparer des offres de yaourts
Id: 2630
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Au supermarché, les yaourts sont vendus par lots de $3$ à $2{,}10$ € ou par lots de $8$ à $5{,}20$ €.

1. Calculer le prix d'un yaourt dans chaque lot. Quel lot est le plus avantageux ?

$2{,}10 \div 3 = 0{,}70$ €.

::: retenir
Pour comparer des offres, on ramène tout au prix d'un article, ou au même nombre d'articles.
:::

Solution:
<!-- optitab:1 -->

=== Entraînement - Calculer un taux en pourcentage
Id: 2632
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Pour calculer un pourcentage, on divise la partie par le total, puis on multiplie par $100$.

1. Dans une classe de $25$ élèves, $9$ sont externes. Quel est le pourcentage d'externes ? Faire le calcul de deux façons : avec un quotient, puis avec un tableau de proportionnalité.

3. Un vélo à $120$ € est vendu avec une remise de $18$ €. Quel est le pourcentage de réduction ?
4. Un prix passe de $40$ € à $46$ €. De quel pourcentage a-t-il augmenté ?

<!-- optitab:1 -->
## Question 1 : Les externes

::: methode

::: etape Avec un quotient
$$\frac{9}{25} = 0{,}36 = \frac{36}{100}$$
:::

::: etape Avec un tableau de proportionnalité
| Élèves externes | $9$ | $t$ |
|---|---|---|
| Effectif total | $25$ | $100$ |

Produit en croix : $t = \dfrac{9 \times 100}{25} = 36$.
:::

::: resultat
$36\ \%$ des élèves de la classe sont externes.
:::

## Question 2 : Le taux de réussite d'Inès

::: etape Calculer
$$\frac{12}{40} \times 100 = 0{,}3 \times 100 = 30$$
:::

::: resultat
Le taux de réussite d'Inès est de $30\ \%$.
:::

## Question 3 : Le pourcentage de réduction

::: etape Diviser la remise par le prix de départ
$$\frac{18}{120} \times 100 = 0{,}15 \times 100 = 15$$
:::

::: resultat
La réduction est de $15\ \%$.
:::

## Question 4 : Le pourcentage d'augmentation

::: etape L'augmentation
$46 - 40 = 6$ €.
:::

::: etape Diviser par le prix de départ
$$\frac{6}{40} \times 100 = 15$$
:::

::: resultat
Le prix a augmenté de $15\ \%$.

Diviser par le nouveau prix : $\dfrac{6}{46} \approx 13\ \%$ est faux. Une augmentation se compare toujours à la valeur **de départ**.

## Question 5 : Le taux de remplissage

:::

::: resultat
La salle est remplie à $82\ \%$.
:::

## Question 6 : Comparer deux classes

Les effectifs sont différents : on ne compare pas $18$ et $21$, mais les pourcentages.

::: etape Classe A
$\dfrac{18}{24} = 0{,}75$, soit $75\ \%$.

|---|---|---|---|
| Prix TTC (€) | $120$ | ? | $96$ |

Ajouter $20\ \%$, c'est multiplier par $1 + \dfrac{20}{100} = 1{,}2$.

$150 \times 1{,}2 = 180$.
:::

::: resultat
Le casque coûte $180$ € TTC.
:::

## Question 2 : La TVA du casque

::: etape Deux calculs possibles
$180 - 150 = 30$ €, ou directement $20\ \%$ de $150$ € : $0{,}2 \times 150 = 30$ €.
:::

::: resultat
La TVA sur le casque est de $30$ €.

$100$ € HT donnent $120$ € TTC : le tableau est un tableau de proportionnalité de coefficient $1{,}2$. On cherche une quatrième proportionnelle.
:::

::: etape Compléter la colonne $150$
$150 \times 1{,}2 = 180$.
:::

::: etape Produit en croix pour la montre

:::

[IMAGE_1]

::: resultat
La montre coûte $80$ € HT.
:::

Retirer $20\ \%$ de $96$ € ($96 \times 0{,}8 = 76{,}80$ €) : la TVA est calculée sur le prix **HT**, pas sur le prix TTC. Vérification : $80 \times 1{,}2 = 96$.

::: etape Calculer
$96 - 80 = 16$ €, et l'on vérifie : $20\ \%$ de $80$ € font bien $16$ €.
:::

::: resultat
La TVA sur la montre est de $16$ €.

:::

::: resultat

:::

## Question 6 : L'autre livre

::: etape Tableau de proportionnalité
$100$ € HT donnent $105{,}5$ € TTC ; on cherche le prix HT qui donne $31{,}65$ € TTC.
$$? = \frac{31{,}65 \times 100}{105{,}5} = 30$$
:::

::: resultat
Ce livre coûte $30$ € HT.
:::

::: retenir
Du HT au TTC, on multiplie par le coefficient ($1{,}2$ ou $1{,}055$) ; du TTC au HT, on fait le calcul inverse : on divise par ce coefficient.
:::

Solution:
<!-- optitab:1 -->

2. $30$ €

4. $16$ €
5. $21{,}10$ € TTC

<!-- optitab:1 -->
Le périmètre d'un cercle de diamètre $d$ est $\pi \times d$ ; l'aire d'un disque de rayon $r$ est $\pi \times r^2$.

1. Calculer, au centième, le périmètre de cercles de diamètres $1$ cm, $2$ cm, $5$ cm et $10$ cm.
2. Le périmètre d'un cercle est-il proportionnel à son diamètre ? Si oui, donner le coefficient.
3. Calculer l'aire de disques de rayons $1$ cm, $2$ cm et $3$ cm, en fonction de $\pi$.
4. L'aire d'un disque est-elle proportionnelle à son rayon ? Justifier.
5. Le périmètre d'un carré est-il proportionnel à son côté ? Et son aire ? Justifier par un tableau de valeurs.

Étapes:
<!-- optitab:1 -->
## Question 1 : Les périmètres

::: etape Multiplier le diamètre par $\pi$
- $\pi \times 1 \approx 3{,}14$ ;
- $\pi \times 2 \approx 6{,}28$ ;
- $\pi \times 5 \approx 15{,}71$ ;
- $\pi \times 10 \approx 31{,}42$.
:::

::: resultat
Les périmètres sont environ $3{,}14$ cm, $6{,}28$ cm, $15{,}71$ cm et $31{,}42$ cm.
:::

## Question 2 : Proportionnalité du périmètre

::: etape Écrire la relation
Périmètre $= \pi \times d$ : on passe du diamètre au périmètre en multipliant toujours par le même nombre $\pi$.
:::

::: resultat
Oui, le périmètre est proportionnel au diamètre, de coefficient $\pi$.
:::

## Question 3 : Les aires

::: etape Calculer $\pi \times r^2$
- $r = 1$ : $\pi \times 1^2 = \pi$ ;
- $r = 2$ : $\pi \times 2^2 = 4\pi$ ;
- $r = 3$ : $\pi \times 3^2 = 9\pi$.
:::

::: resultat
Les aires sont $\pi$ cm², $4\pi$ cm² et $9\pi$ cm².
:::

## Question 4 : Proportionnalité de l'aire

::: etape Comparer deux quotients
$\dfrac{\pi}{1} = \pi$ et $\dfrac{4\pi}{2} = 2\pi$ : les quotients sont différents.
:::

::: resultat
Non : l'aire d'un disque n'est pas proportionnelle à son rayon. Quand le rayon double, l'aire est multipliée par $4$.
:::

::: attention Erreur fréquente
Penser que « si le rayon double, l'aire double » : le rayon intervient **deux fois** dans $\pi \times r \times r$.
:::

## Question 5 : Le carré

::: etape Tableau de valeurs
| Côté (cm) | $1$ | $2$ | $3$ |
|---|---|---|---|
| Périmètre (cm) | $4$ | $8$ | $12$ |
| Aire (cm²) | $1$ | $4$ | $9$ |
:::

::: etape Comparer les quotients
- Périmètre : $\dfrac{4}{1} = \dfrac{8}{2} = \dfrac{12}{3} = 4$.
- Aire : $\dfrac{1}{1} = 1$ et $\dfrac{4}{2} = 2$.
:::

[IMAGE_1]

::: resultat
Le périmètre d'un carré est proportionnel à son côté (coefficient $4$) ; son aire ne l'est pas. Sur le graphique, le périmètre donne une droite passant par l'origine, l'aire une courbe.
:::

::: retenir
Une grandeur qui dépend du **carré** d'une autre (comme une aire) n'est pas proportionnelle à celle-ci.
:::

Solution:
<!-- optitab:1 -->
1. $3{,}14$ ; $6{,}28$ ; $15{,}71$ ; $31{,}42$ cm
2. Oui, coefficient $\pi$
3. $\pi$ ; $4\pi$ ; $9\pi$ cm²
4. Non ($\pi \neq 2\pi$)
5. Périmètre : oui (coefficient $4$) ; aire : non

=== Problème - Le budget d'un voyage en voiture
Id: 2635
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une famille de $4$ personnes part en vacances à $780$ km de chez elle.
- La voiture consomme $6{,}5$ L de carburant aux $100$ km ; la consommation est proportionnelle à la distance parcourue.
- Le carburant coûte $1{,}85$ € le litre ; le réservoir contient $45$ L.
- Sur l'autoroute ($600$ km du trajet), le péage coûte $0{,}09$ € par kilomètre.

1. Quelle quantité de carburant faut-il pour le trajet ?
2. Combien coûte ce carburant ? Arrondir au centime.
3. Avec un plein, quelle distance peut-on parcourir ? Arrondir au kilomètre. Faudra-t-il s'arrêter pour refaire le plein ?
4. Combien coûte le péage ?
5. Quel est le coût total du trajet ? Combien chaque personne paie-t-elle si l'on partage à parts égales ?
6. En roulant moins vite, la consommation baisse de $12\ \%$. Quelle est la nouvelle consommation aux $100$ km ?
7. Quelle économie de carburant cela représente-t-il sur le trajet, en litres puis en euros (au centime) ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le carburant nécessaire

::: methode
La consommation est proportionnelle à la distance : $6{,}5$ L pour $100$ km. On cherche combien de fois $100$ km il y a dans $780$ km.
:::

::: etape Nombre de fois $100$ km
$780 \div 100 = 7{,}8$.
:::

::: etape Consommation
$7{,}8 \times 6{,}5 = 50{,}7$ L.
:::

::: resultat
Il faut $50{,}7$ L de carburant pour le trajet.
:::

## Question 2 : Le coût du carburant

::: etape Calculer
$50{,}7 \times 1{,}85 = 93{,}795$.
:::

::: resultat
Le carburant coûte environ $93{,}80$ €.
:::

## Question 3 : L'autonomie

::: etape Produit en croix
$6{,}5$ L pour $100$ km, donc $45$ L pour $\dfrac{45 \times 100}{6{,}5} \approx 692{,}3$ km.
:::

::: resultat
Avec un plein, on parcourt environ $692$ km. Comme $780 > 692$, il faudra s'arrêter une fois pour refaire le plein.
:::

## Question 4 : Le péage

::: etape Calculer
$600 \times 0{,}09 = 54$.
:::

::: resultat
Le péage coûte $54$ €.
:::

## Question 5 : Le coût total

::: etape Additionner
$93{,}80 + 54 = 147{,}80$ €.
:::

::: etape Partager en $4$
$147{,}80 \div 4 = 36{,}95$ €.
:::

::: resultat
Le trajet coûte $147{,}80$ €, soit $36{,}95$ € par personne.
:::

## Question 6 : La nouvelle consommation

::: methode
Baisser de $12\ \%$, c'est multiplier par $1 - \dfrac{12}{100} = 0{,}88$.
:::

::: etape Calculer
$6{,}5 \times 0{,}88 = 5{,}72$.
:::

::: resultat
La nouvelle consommation est de $5{,}72$ L aux $100$ km.
:::

## Question 7 : L'économie

::: etape Nouvelle consommation sur le trajet
$7{,}8 \times 5{,}72 = 44{,}616$ L.
:::

::: etape Économie en litres
$50{,}7 - 44{,}616 = 6{,}084$ L. On retrouve $12\ \%$ de $50{,}7$ L : $0{,}12 \times 50{,}7 = 6{,}084$.
:::

::: etape Économie en euros
$6{,}084 \times 1{,}85 = 11{,}255\,4$.
:::

::: resultat
L'économie est d'environ $6{,}08$ L, soit environ $11{,}26$ €.
:::

::: attention Erreur fréquente
Multiplier $780$ par $6{,}5$ : la consommation est donnée pour $100$ km, pas pour $1$ km. On obtiendrait $5\,070$ L, un résultat absurde. On vérifie toujours l'ordre de grandeur.
:::

Solution:
<!-- optitab:1 -->
1. $50{,}7$ L
2. Environ $93{,}80$ €
3. Environ $692$ km ; oui, un arrêt
4. $54$ €
5. $147{,}80$ € ; $36{,}95$ € par personne
6. $5{,}72$ L aux $100$ km
7. Environ $6{,}08$ L, soit $11{,}26$ €

=== Problème - Comparer les résultats de deux collèges
Id: 2636
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Voici les résultats au brevet de deux collèges.

| Collège | Candidats | Reçus |
|---|---|---|
| A | $160$ | $136$ |
| B | $250$ | $205$ |

1. Quel collège a le plus d'élèves reçus ?
2. Calculer le taux de réussite (pourcentage de reçus parmi les candidats) de chaque collège.
3. Quel collège a le mieux réussi ? Expliquer pourquoi on compare les taux et non les nombres de reçus.
4. Dans le collège A, $25\ \%$ des reçus ont obtenu la mention « très bien ». Combien d'élèves cela représente-t-il ? Quel pourcentage des candidats du collège A cela représente-t-il ?
5. L'année suivante, le collège A présente $180$ candidats et vise un taux de réussite de $90\ \%$. Combien d'élèves doivent être reçus ?
6. On représente les deux taux de réussite par un diagramme en barres, la hauteur d'une barre étant proportionnelle au taux : $100\ \%$ correspond à $5$ cm. Calculer la hauteur de chaque barre.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le nombre de reçus

::: etape Comparer les effectifs
$205 > 136$.
:::

::: resultat
Le collège B a le plus d'élèves reçus.
:::

## Question 2 : Les taux de réussite

::: methode
Taux de réussite $= \dfrac{\text{reçus}}{\text{candidats}} \times 100$.
:::

::: etape Collège A
$$\frac{136}{160} \times 100 = 0{,}85 \times 100 = 85$$
:::

::: etape Collège B
$$\frac{205}{250} \times 100 = 0{,}82 \times 100 = 82$$
:::

::: resultat
Le taux de réussite est de $85\ \%$ dans le collège A et de $82\ \%$ dans le collège B.
:::

## Question 3 : Quel collège a le mieux réussi ?

::: etape Comparer les taux
$85\ \% > 82\ \%$.
:::

::: resultat
Le collège A a le mieux réussi. Les deux collèges n'ont pas le même nombre de candidats : comparer les nombres de reçus n'a pas de sens, il faut comparer des proportions.
:::

::: attention Erreur fréquente
Conclure que le collège B réussit mieux parce qu'il a plus de reçus : il a aussi beaucoup plus de candidats.
:::

## Question 4 : La mention « très bien »

::: etape Nombre d'élèves
$25\ \%$ de $136$, c'est le quart : $136 \div 4 = 34$.
:::

::: etape Pourcentage des candidats
$$\frac{34}{160} \times 100 = 21{,}25$$
:::

::: resultat
$34$ élèves ont obtenu la mention « très bien », soit $21{,}25\ \%$ des candidats du collège A.
:::

::: attention Erreur fréquente
Répondre $25\ \%$ : ce pourcentage est calculé sur les **reçus** ($136$), pas sur les **candidats** ($160$). Le total de référence change le pourcentage.
:::

## Question 5 : L'objectif de l'année suivante

::: etape Calculer $90\ \%$ de $180$
$0{,}9 \times 180 = 162$.
:::

::: resultat
$162$ élèves doivent être reçus.
:::

## Question 6 : Les hauteurs des barres

::: methode
La hauteur est proportionnelle au taux : $100\ \%$ donnent $5$ cm, donc $1\ \%$ donne $5 \div 100 = 0{,}05$ cm.
:::

::: etape Collège A
$85 \times 0{,}05 = 4{,}25$ cm.
:::

::: etape Collège B
$82 \times 0{,}05 = 4{,}1$ cm.
:::

[IMAGE_1]

::: resultat
La barre du collège A mesure $4{,}25$ cm et celle du collège B $4{,}1$ cm.
:::

Solution:
<!-- optitab:1 -->
1. Le collège B ($205$ reçus)
2. A : $85\ \%$ ; B : $82\ \%$
3. Le collège A : effectifs différents, on compare les taux
4. $34$ élèves ; $21{,}25\ \%$ des candidats
5. $162$ élèves
6. $4{,}25$ cm et $4{,}1$ cm

=== Problème - Préparer une randonnée sur une carte
Id: 2637
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Sur une carte au $\dfrac{1}{25\,000}$, le sentier qui relie le parking au refuge mesure $18$ cm. Le refuge est $450$ m plus haut que le parking. Un randonneur compte $1$ h pour $4$ km de marche, plus $1$ h pour $300$ m de montée. Il part à $9$ h $15$.

[IMAGE_1]

1. Quelle longueur réelle représentent $4$ cm sur cette carte ? Vérifier avec l'échelle graphique.
2. Calculer la longueur réelle du sentier, en km.
3. Calculer le temps de marche pour cette distance, en heures et minutes.
4. Calculer le temps supplémentaire dû à la montée.
5. À quelle heure le randonneur arrivera-t-il au refuge ?
6. À vol d'oiseau, le parking et le refuge sont distants de $11$ cm sur la carte. Quelle est la distance réelle ? Combien de kilomètres de plus fait-on par le sentier ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'échelle graphique

::: etape Multiplier par $25\,000$
$4 \times 25\,000 = 100\,000$ cm $= 1\,000$ m $= 1$ km.
:::

::: resultat
$4$ cm sur la carte représentent $1$ km : c'est bien ce qu'indique l'échelle graphique.
:::

## Question 2 : La longueur du sentier

::: etape Multiplier par $25\,000$
$18 \times 25\,000 = 450\,000$ cm.
:::

::: etape Convertir
$450\,000$ cm $= 4\,500$ m $= 4{,}5$ km.
:::

::: resultat
Le sentier mesure $4{,}5$ km. Vérification avec la question 1 : $18$ cm $= 4{,}5 \times 4$ cm, donc $4{,}5$ km.
:::

## Question 3 : Le temps de marche

::: methode
La durée est proportionnelle à la distance : $1$ h pour $4$ km.
:::

::: etape En heures
$4{,}5 \div 4 = 1{,}125$ h.
:::

::: etape En heures et minutes
$0{,}125$ h $= 0{,}125 \times 60$ min $= 7{,}5$ min $= 7$ min $30$ s.
:::

::: resultat
Le temps de marche est de $1$ h $7$ min $30$ s.
:::

::: attention Erreur fréquente
Lire $1{,}125$ h comme « $1$ h $12$ min » : la partie décimale d'heure se convertit en multipliant par $60$.
:::

## Question 4 : Le temps de montée

::: etape Proportionnalité
$1$ h pour $300$ m, donc $\dfrac{450}{300} = 1{,}5$ h pour $450$ m.
:::

::: resultat
La montée ajoute $1$ h $30$ min.
:::

## Question 5 : L'heure d'arrivée

::: etape Durée totale
$1$ h $7$ min $30$ s $+ 1$ h $30$ min $= 2$ h $37$ min $30$ s.
:::

::: etape Heure d'arrivée
$9$ h $15$ min $+ 2$ h $37$ min $30$ s $= 11$ h $52$ min $30$ s.
:::

::: resultat
Le randonneur arrivera au refuge à $11$ h $52$ min $30$ s, soit vers $11$ h $53$.
:::

## Question 6 : À vol d'oiseau

::: etape La distance réelle
$11 \times 25\,000 = 275\,000$ cm $= 2{,}75$ km.
:::

::: etape La différence
$4{,}5 - 2{,}75 = 1{,}75$ km.
:::

[IMAGE_2]

::: resultat
À vol d'oiseau, le refuge est à $2{,}75$ km du parking ; le sentier fait $1{,}75$ km de plus.
:::

::: retenir
Sur une carte au $\dfrac{1}{n}$, $1$ cm représente $n$ cm dans la réalité ; on convertit ensuite en m ou en km.
:::

Solution:
<!-- optitab:1 -->
1. $1$ km
2. $4{,}5$ km
3. $1$ h $7$ min $30$ s
4. $1$ h $30$ min
5. $11$ h $52$ min $30$ s (vers $11$ h $53$)
6. $2{,}75$ km ; $1{,}75$ km de plus

=== Problème - Comparer deux cyclistes sur un graphique
Id: 2638
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Léa et Tom partent ensemble pour une sortie à vélo de $54$ km. Le graphique donne la distance parcourue par chacun en fonction de la durée écoulée depuis le départ.

[IMAGE_1]

1. Lire la distance parcourue par chacun au bout de $1$ h.
2. La distance parcourue par Léa est-elle proportionnelle à la durée ? Justifier. Donner le coefficient de proportionnalité et préciser ce qu'il représente.
3. Calculer la distance parcourue par Léa en $2$ h $30$ min.
4. Que fait Tom entre $1$ h et $1$ h $30$ min ? La distance parcourue par Tom est-elle proportionnelle à la durée ?
5. Au bout de combien de temps Léa rattrape-t-elle Tom ? Lire la réponse sur le graphique, puis la retrouver par le calcul.
6. Calculer la vitesse moyenne de Tom sur toute la sortie, puis sa vitesse après la pause. Comparer avec Léa.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lecture à $1$ h

::: etape Lire les ordonnées
On part de $1$ sur l'axe des durées et on lit l'ordonnée de chaque tracé : $18$ pour Léa, $24$ pour Tom.
:::

::: resultat
Au bout de $1$ h, Léa a parcouru $18$ km et Tom $24$ km.
:::

## Question 2 : La distance de Léa

::: methode
Une situation de proportionnalité est représentée par une droite qui passe par l'origine.
:::

::: etape Examiner le tracé
Le tracé de Léa est une droite qui passe par l'origine.
:::

::: etape Le coefficient
$\dfrac{18}{1} = 18$ : Léa parcourt $18$ km en $1$ h.
:::

::: resultat
Oui, la distance parcourue par Léa est proportionnelle à la durée. Le coefficient $18$ est sa vitesse : $18$ km/h.
:::

## Question 3 : En $2$ h $30$ min

::: etape Convertir et calculer
$2$ h $30$ min $= 2{,}5$ h, donc $18 \times 2{,}5 = 45$.
:::

::: resultat
En $2$ h $30$ min, Léa parcourt $45$ km.
:::

## Question 4 : La pause de Tom

::: etape Lire le palier
Entre $1$ h et $1{,}5$ h, le tracé de Tom est horizontal : sa distance reste égale à $24$ km.
:::

::: etape Comparer deux quotients
À $1$ h : $\dfrac{24}{1} = 24$ ; à $1{,}5$ h : $\dfrac{24}{1{,}5} = 16$. Les quotients sont différents.
:::

::: resultat
Tom fait une pause de $30$ min. Sa distance n'est pas proportionnelle à la durée : son tracé n'est pas une droite.
:::

## Question 5 : Léa rattrape Tom

::: etape Lecture graphique
Les deux tracés se coupent pendant la pause de Tom, à $24$ km, un peu après $1$ h $15$ min.
:::

::: etape Calcul
Léa atteint $24$ km quand $18 \times t = 24$, soit $t = \dfrac{24}{18} = \dfrac{4}{3}$ h $= 1$ h $+ \dfrac{1}{3} \times 60$ min $= 1$ h $20$ min.
:::

[IMAGE_2]

::: resultat
Léa rattrape Tom au bout de $1$ h $20$ min, à $24$ km du départ.
:::

## Question 6 : Les vitesses de Tom

::: methode
Vitesse moyenne $= \dfrac{\text{distance}}{\text{durée}}$, la durée étant en heures (pauses comprises).
:::

::: etape Sur toute la sortie
Tom parcourt $54$ km en $3$ h : $54 \div 3 = 18$ km/h.
:::

::: etape Après la pause
De $1{,}5$ h à $3$ h, il parcourt $54 - 24 = 30$ km en $1{,}5$ h : $30 \div 1{,}5 = 20$ km/h.
:::

::: resultat
La vitesse moyenne de Tom est de $18$ km/h, comme celle de Léa : ils arrivent ensemble au bout de $3$ h. Après la pause, Tom roule à $20$ km/h.
:::

::: attention Erreur fréquente
Calculer la vitesse moyenne de Tom en oubliant la pause ($54 \div 2{,}5 = 21{,}6$ km/h) : la vitesse moyenne se calcule sur la durée **totale**.
:::

Solution:
<!-- optitab:1 -->
1. Léa : $18$ km ; Tom : $24$ km
2. Oui (droite passant par l'origine) ; coefficient $18$ : la vitesse, $18$ km/h
3. $45$ km
4. Une pause ; non
5. $1$ h $20$ min
6. $18$ km/h sur la sortie, $20$ km/h après la pause ; même vitesse moyenne que Léa

=== Type brevet - Mélanger deux jus de fruits
Id: 2639
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une boisson A contient $30\ \%$ de jus de fruits ; un jus B contient $80\ \%$ de jus de fruits. On mélange $1$ L de boisson A et $0{,}5$ L de jus B.

1. Quel volume de jus de fruits contient $1$ L de boisson A ?
2. Quel volume de jus de fruits contient $0{,}5$ L de jus B ?
3. Quel est le pourcentage de jus de fruits du mélange ? Arrondir au dixième.
4. Ce pourcentage est-il la moyenne de $30\ \%$ et de $80\ \%$ ? Expliquer.
5. On note $x$ le volume de jus B, en litres, ajouté à $1$ L de boisson A. Quel volume $x$ faut-il ajouter pour obtenir un mélange à $50\ \%$ de jus de fruits ?
6. Vérifier le résultat de la question 5.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le jus dans la boisson A

::: etape $30\ \%$ de $1$ L
$0{,}3 \times 1 = 0{,}3$.
:::

::: resultat
$1$ L de boisson A contient $0{,}3$ L de jus de fruits.
:::

## Question 2 : Le jus dans le jus B

::: etape $80\ \%$ de $0{,}5$ L
$0{,}8 \times 0{,}5 = 0{,}4$.
:::

::: resultat
$0{,}5$ L de jus B contient $0{,}4$ L de jus de fruits.
:::

## Question 3 : Le pourcentage du mélange

::: methode
On additionne les **volumes** de jus de fruits, puis on divise par le volume total du mélange.
:::

::: etape Les volumes
Jus de fruits : $0{,}3 + 0{,}4 = 0{,}7$ L ; volume total : $1 + 0{,}5 = 1{,}5$ L.
:::

::: etape Le pourcentage
$$\frac{0{,}7}{1{,}5} \times 100 \approx 46{,}7$$
:::

[IMAGE_1]

::: resultat
Le mélange contient environ $46{,}7\ \%$ de jus de fruits.
:::

## Question 4 : Pas une simple moyenne

::: etape La moyenne des pourcentages
$\dfrac{30 + 80}{2} = 55$.
:::

::: resultat
Non : $46{,}7 \neq 55$. On a mis deux fois plus de boisson A (à $30\ \%$) que de jus B, donc le mélange est plus proche de $30\ \%$.
:::

::: attention Erreur fréquente
Faire la moyenne des pourcentages : elle n'est juste que si l'on mélange des volumes **égaux**. Dans un mélange, on additionne les quantités, jamais les pourcentages.
:::

## Question 5 : Viser $50\ \%$

::: methode
Le jus de fruits doit représenter la moitié du volume total : on écrit une équation.
:::

::: etape Exprimer les volumes
Jus de fruits : $0{,}3 + 0{,}8x$ ; volume total : $1 + x$.
:::

::: etape Écrire et résoudre l'équation
$$
\begin{aligned}
0{,}3 + 0{,}8x &= 0{,}5 \times (1 + x) \\
0{,}3 + 0{,}8x &= 0{,}5 + 0{,}5x \\
0{,}3x &= 0{,}2 \\
x &= \frac{0{,}2}{0{,}3} = \frac{2}{3}
\end{aligned}
$$
:::

::: resultat
Il faut ajouter $\dfrac{2}{3}$ L de jus B, soit environ $0{,}67$ L.
:::

## Question 6 : La vérification

::: etape Le jus de fruits
$0{,}3 + 0{,}8 \times \dfrac{2}{3} = \dfrac{0{,}9}{3} + \dfrac{1{,}6}{3} = \dfrac{2{,}5}{3} = \dfrac{5}{6}$ L.
:::

::: etape Le volume total
$1 + \dfrac{2}{3} = \dfrac{5}{3}$ L, et la moitié de $\dfrac{5}{3}$ est $\dfrac{5}{6}$.
:::

::: resultat
Le jus de fruits représente exactement la moitié du mélange : on obtient bien $50\ \%$.
:::

Solution:
<!-- optitab:1 -->
1. $0{,}3$ L
2. $0{,}4$ L
3. Environ $46{,}7\ \%$
4. Non ($46{,}7 \neq 55$) : volumes différents
5. $x = \dfrac{2}{3}$ L, environ $0{,}67$ L
6. $\dfrac{5}{6}$ L de jus pour $\dfrac{5}{3}$ L : $50\ \%$

=== Type brevet - Agrandir une photo
Id: 2640
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une photo mesure $10$ cm de large et $15$ cm de haut. On veut l'agrandir sans la déformer : la hauteur doit rester proportionnelle à la largeur.

[IMAGE_1]

1. On veut une largeur de $25$ cm. Quelle sera la hauteur ?
2. Quel est le coefficient d'agrandissement ?
3. Une autre impression mesure $45$ cm de haut. Quelle est sa largeur ?
4. Le format $13$ cm sur $18$ cm est-il un agrandissement du format $10 \times 15$ ? Justifier.
5. On imprime la photo, sans la déformer, avec une largeur de $13$ cm. Quelle est sa hauteur ? Tient-elle sur un papier de format $13 \times 18$ ?
6. Quelle longueur faut-il couper (rogner) en hauteur pour qu'elle tienne sur ce papier ? Quel pourcentage de la hauteur cela représente-t-il ? Arrondir au dixième.

Étapes:
<!-- optitab:1 -->
## Question 1 : La hauteur

::: methode
La hauteur est proportionnelle à la largeur : on calcule le coefficient « hauteur $\div$ largeur ».
:::

::: etape Le rapport hauteur sur largeur
$\dfrac{15}{10} = 1{,}5$ : la hauteur vaut $1{,}5$ fois la largeur.
:::

::: etape Calculer
$25 \times 1{,}5 = 37{,}5$.
:::

::: resultat
La photo agrandie mesure $37{,}5$ cm de haut.
:::

## Question 2 : Le coefficient d'agrandissement

::: etape Comparer les largeurs
$25 \div 10 = 2{,}5$ (et $37{,}5 \div 15 = 2{,}5$).
:::

::: resultat
Le coefficient d'agrandissement est $2{,}5$ : toutes les longueurs sont multipliées par $2{,}5$.
:::

## Question 3 : Une hauteur de $45$ cm

::: etape Diviser par $1{,}5$
$45 \div 1{,}5 = 30$.
:::

::: resultat
Cette impression mesure $30$ cm de large.
:::

## Question 4 : Le format $13 \times 18$

::: etape Comparer les coefficients
$\dfrac{13}{10} = 1{,}3$ et $\dfrac{18}{15} = 1{,}2$.
:::

::: resultat
Non : la largeur et la hauteur ne sont pas multipliées par le même nombre. Le format $13 \times 18$ n'est pas un agrandissement du format $10 \times 15$.
:::

## Question 5 : Une largeur de $13$ cm

::: etape Calculer la hauteur
$13 \times 1{,}5 = 19{,}5$ cm.
:::

[IMAGE_2]

::: resultat
La photo mesure $19{,}5$ cm de haut : elle ne tient pas sur le papier de $18$ cm de haut.
:::

## Question 6 : Rogner la photo

::: etape La longueur à couper
$19{,}5 - 18 = 1{,}5$ cm.
:::

::: etape Le pourcentage
$$\frac{1{,}5}{19{,}5} \times 100 \approx 7{,}7$$
:::

::: resultat
Il faut couper $1{,}5$ cm en hauteur (par exemple $0{,}75$ cm en haut et en bas), soit environ $7{,}7\ \%$ de la hauteur.
:::

::: attention Erreur fréquente
Ajouter $3$ cm aux deux dimensions ($10 \times 15$ devient $13 \times 18$) en pensant agrandir : un agrandissement **multiplie** les longueurs par un même nombre, il ne les augmente pas d'une même quantité.
:::

Solution:
<!-- optitab:1 -->
1. $37{,}5$ cm
2. $2{,}5$
3. $30$ cm
4. Non ($1{,}3 \neq 1{,}2$)
5. $19{,}5$ cm ; non
6. $1{,}5$ cm, environ $7{,}7\ \%$

=== Type brevet - Choisir un forfait de ski
Id: 2641
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Une station de ski propose les forfaits suivants.

| Durée | $1$ jour | $2$ jours | $3$ jours | $6$ jours |
|---|---|---|---|---|
| Prix (€) | $45$ | $85$ | $120$ | $210$ |

1. Le prix est-il proportionnel au nombre de jours ? Justifier.
2. Calculer le prix moyen d'une journée pour chaque forfait. Arrondir au centime si nécessaire.
3. Pour $6$ jours, quelle économie réalise-t-on avec le forfait $6$ jours par rapport à $6$ forfaits d'un jour ? Quel pourcentage cela représente-t-il ? Arrondir au dixième.
4. Pour $6$ jours, vaut-il mieux prendre un forfait $6$ jours ou deux forfaits $3$ jours ?
5. Une famille de $4$ personnes achète $4$ forfaits $6$ jours et bénéficie de $10\ \%$ de réduction sur le total. Combien paie-t-elle ?
6. L'année suivante, tous les prix augmentent de $4\ \%$. Quel est le nouveau prix du forfait $6$ jours ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Proportionnel ?

::: etape Comparer deux quotients
$\dfrac{45}{1} = 45$ et $\dfrac{85}{2} = 42{,}5$ : les quotients sont différents.
:::

::: resultat
Non, le prix n'est pas proportionnel au nombre de jours.
:::

## Question 2 : Le prix moyen d'une journée

::: etape Diviser chaque prix par le nombre de jours
- $1$ jour : $45$ € ;
- $2$ jours : $85 \div 2 = 42{,}50$ € ;
- $3$ jours : $120 \div 3 = 40$ € ;
- $6$ jours : $210 \div 6 = 35$ €.
:::

[IMAGE_1]

::: resultat
Le prix moyen d'une journée est de $45$ €, $42{,}50$ €, $40$ € et $35$ € : il baisse quand la durée augmente (tarif dégressif).
:::

## Question 3 : L'économie sur $6$ jours

::: etape Six forfaits d'un jour
$6 \times 45 = 270$ €.
:::

::: etape L'économie
$270 - 210 = 60$ €.
:::

::: etape Le pourcentage
$$\frac{60}{270} \times 100 \approx 22{,}2$$
:::

::: resultat
On économise $60$ €, soit environ $22{,}2\ \%$ du prix de $6$ forfaits d'un jour.
:::

## Question 4 : $6$ jours ou deux fois $3$ jours ?

::: etape Deux forfaits $3$ jours
$2 \times 120 = 240$ €.
:::

::: resultat
Le forfait $6$ jours est moins cher : $210$ € contre $240$ €.
:::

::: attention Erreur fréquente
Penser que $6$ jours coûtent deux fois le prix de $3$ jours : ce serait vrai seulement si le prix était proportionnel à la durée, ce qui n'est pas le cas.
:::

## Question 5 : La famille

::: etape Le prix total
$4 \times 210 = 840$ €.
:::

::: etape Appliquer la réduction de $10\ \%$
$840 \times 0{,}9 = 756$ €.
:::

::: resultat
La famille paie $756$ €.
:::

## Question 6 : L'augmentation de $4\ \%$

::: etape Le coefficient
$1 + \dfrac{4}{100} = 1{,}04$.
:::

::: etape Calculer
$210 \times 1{,}04 = 218{,}40$.
:::

::: resultat
Le forfait $6$ jours coûtera $218{,}40$ €.
:::

Solution:
<!-- optitab:1 -->
1. Non ($45 \neq 42{,}5$)
2. $45$ € ; $42{,}50$ € ; $40$ € ; $35$ €
3. $60$ €, environ $22{,}2\ \%$
4. Le forfait $6$ jours ($210$ € contre $240$ €)
5. $756$ €
6. $218{,}40$ €
