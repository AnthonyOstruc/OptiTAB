🎯 Objectifs du chapitre : utiliser le cercle trigonométrique et le radian, définir le cosinus et le sinus d’un nombre réel, connaître les valeurs remarquables et les angles associés, résoudre des équations simples et connaître les courbes des fonctions cosinus et sinus.

I. Cercle trigonométrique et radian

Définitions : dans un repère orthonormé $\displaystyle (O\,;I\,;J)$, le cercle trigonométrique est le cercle de centre $\displaystyle O$ et de rayon $\displaystyle 1$, orienté dans le sens direct (inverse des aiguilles d’une montre). En « enroulant » la droite des réels sur ce cercle à partir de $\displaystyle I$, on associe à chaque réel $\displaystyle t$ un unique point $\displaystyle M(t)$.

Le radian est la mesure de l’angle $\displaystyle \widehat{IOM}$ qui intercepte un arc de longueur $\displaystyle 1$ : $\displaystyle \pi$ radians $\displaystyle = 180°$.

[IMAGE_1]

Exemples : $\displaystyle 45° = \frac{\pi}{4}$ rad ; $\displaystyle 120° = \frac{2\pi}{3}$ rad ; $\displaystyle \frac{\pi}{5}$ rad $\displaystyle = 36°$.

💡 Un tour complet mesure $\displaystyle 2\pi$ : les réels $\displaystyle t$ et $\displaystyle t + 2k\pi$ ($\displaystyle k$ entier) donnent le même point. Ainsi $\displaystyle \frac{17\pi}{3} = -\frac{\pi}{3} + 3 \times 2\pi$, donc $\displaystyle M\left(\frac{17\pi}{3}\right) = M\left(-\frac{\pi}{3}\right)$.

II. Cosinus et sinus d’un réel

Définition : le cosinus et le sinus de $\displaystyle t$ sont l’abscisse et l’ordonnée du point $\displaystyle M(t)$ : $\displaystyle M(t)\,(\cos t\,;\sin t)$.

Propriétés : $\displaystyle -1 \le \cos t \le 1$ ; $\displaystyle -1 \le \sin t \le 1$ ; $\displaystyle \cos^2 t + \sin^2 t = 1$ ; $\displaystyle \cos(t + 2\pi) = \cos t$ et $\displaystyle \sin(t + 2\pi) = \sin t$.

$\displaystyle \cos t$$\displaystyle 1$$\displaystyle \frac{\sqrt{3}}{2}$$\displaystyle \frac{\sqrt{2}}{2}$$\displaystyle \frac{1}{2}$$\displaystyle 0$$\displaystyle -1$
$\displaystyle \sin t$$\displaystyle 0$$\displaystyle \frac{1}{2}$$\displaystyle \frac{\sqrt{2}}{2}$$\displaystyle \frac{\sqrt{3}}{2}$$\displaystyle 1$$\displaystyle 0$

Démonstrations au programme :

• $\displaystyle \frac{\pi}{4}$ : le point est sur la bissectrice, donc $\displaystyle \cos = \sin$ ; avec $\displaystyle \cos^2 + \sin^2 = 1$, on obtient $\displaystyle 2\cos^2\frac{\pi}{4} = 1$, d’où $\displaystyle \cos\frac{\pi}{4} = \sin\frac{\pi}{4} = \frac{\sqrt{2}}{2}$.

• $\displaystyle \frac{\pi}{3}$ : le triangle $\displaystyle OIM$ est isocèle en $\displaystyle O$ avec un angle de $\displaystyle 60°$, donc équilatéral ; le projeté de $\displaystyle M$ est le milieu de $\displaystyle [OI]$, d’où $\displaystyle \cos\frac{\pi}{3} = \frac{1}{2}$ puis $\displaystyle \sin\frac{\pi}{3} = \sqrt{1 - \frac{1}{4}} = \frac{\sqrt{3}}{2}$.

III. Angles associés

Propriétés : pour tout réel $\displaystyle x$,

• $\displaystyle \cos(-x) = \cos x$ et $\displaystyle \sin(-x) = -\sin x$ ;

• $\displaystyle \cos(\pi - x) = -\cos x$ et $\displaystyle \sin(\pi - x) = \sin x$ ;

• $\displaystyle \cos(\pi + x) = -\cos x$ et $\displaystyle \sin(\pi + x) = -\sin x$ ;

• $\displaystyle \cos\left(\frac{\pi}{2} - x\right) = \sin x$ et $\displaystyle \sin\left(\frac{\pi}{2} - x\right) = \cos x$.

[IMAGE_3]

Exemples : $\displaystyle \cos\frac{5\pi}{6} = \cos\left(\pi - \frac{\pi}{6}\right) = -\frac{\sqrt{3}}{2}$ ; $\displaystyle \sin\frac{7\pi}{6} = \sin\left(\pi + \frac{\pi}{6}\right) = -\frac{1}{2}$.

💡 Équations : on lit les solutions sur le cercle. Dans $\displaystyle ]-\pi\,;\pi]$, $\displaystyle \cos x = \frac{1}{2} \iff x = -\frac{\pi}{3}$ ou $\displaystyle x = \frac{\pi}{3}$ (deux points symétriques par rapport à l’axe des abscisses). Dans $\displaystyle [0\,;2\pi[$, $\displaystyle \sin x = \frac{\sqrt{2}}{2} \iff x = \frac{\pi}{4}$ ou $\displaystyle x = \frac{3\pi}{4}$.

IV. Fonctions cosinus et sinus

Propriétés : les fonctions $\displaystyle x \mapsto \cos x$ et $\displaystyle x \mapsto \sin x$ sont définies sur $\displaystyle \mathbb{R}$ et périodiques de période $\displaystyle 2\pi$. La fonction cosinus est paire (courbe symétrique par rapport à l’axe des ordonnées), la fonction sinus est impaire (courbe symétrique par rapport à l’origine).

[IMAGE_4]
⚠️ Attention : la calculatrice doit être en mode radian pour ces fonctions. Et $\displaystyle \cos(a + b) \neq \cos a + \cos b$ : par exemple $\displaystyle \cos\left(\frac{\pi}{3} + \frac{\pi}{3}\right) = -\frac{1}{2}$ alors que $\displaystyle \cos\frac{\pi}{3} + \cos\frac{\pi}{3} = 1$.

🏆 L’essentiel : $\displaystyle \pi$ rad $\displaystyle = 180°$ ; $\displaystyle M(t)\,(\cos t\,;\sin t)$ sur le cercle de rayon $\displaystyle 1$ ; $\displaystyle \cos^2 t + \sin^2 t = 1$ ; valeurs remarquables en $\displaystyle \frac{\pi}{6}$, $\displaystyle \frac{\pi}{4}$, $\displaystyle \frac{\pi}{3}$ ; angles associés par symétries ; $\displaystyle \cos$ paire, $\displaystyle \sin$ impaire, toutes deux $\displaystyle 2\pi$-périodiques.
