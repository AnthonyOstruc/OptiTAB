# Couverture des neuf activités sources

1. Source 1 → exercice nouveau-1 : Compter les groupes.
2. Source 2 → exercice nouveau-2 : Dessiner trois groupes.
3. Source 3 → exercice nouveau-3 : Deux additions répétées.
4. Source 4 → exercice nouveau-4 : Les paquets de cartes.
5. Source 5 → exercice nouveau-5 : Les paniers de balles.
6. Source 6 → exercice nouveau-6 : Deux rangées de points.
7. Source 7 → exercice nouveau-7 : Les voitures remplies.
8. Source 8 → exercice nouveau-8 : Les fleurs identiques.
9. Source 9 → exercice nouveau-9 : Des groupes différents.

Chaque exercice comporte cinq questions liées, une méthode, une démarche et une réponse pour chaque question.

Contrôle final : les neuf activités du chapitre source ont été confrontées aux neuf énoncés et à leurs cinq réponses. Les exemples du cours et de la fiche, les modèles des énoncés et les dessins corrigés ont également été relus. Les empreintes des sources sont vérifiées par validation_cp.
