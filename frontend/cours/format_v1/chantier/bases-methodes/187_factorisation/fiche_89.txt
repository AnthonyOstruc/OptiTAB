Titre: Résumé : Factorisation & Mise en Forme Factorisée

## I. Factorisation par facteur commun

| Principe | Méthode |
|---|---|
| **Définition** | Identifier un facteur commun à tous les termes et le mettre en évidence |
| **Facteur commun** | PGCD des coefficients + lettres communes avec le plus petit exposant |

| Étape | Démarche |
|---|---|
| **1** | **Observer :** tous les termes ont-ils un facteur commun ? (nombre, lettre, expression) |
| **2** | **Identifier :** trouver le PGCD des coefficients et les lettres communes avec le plus petit exposant |
| **3** | **Factoriser :** mettre le facteur commun devant une parenthèse |
| **4** | **Vérifier :** développer pour valider le résultat |

| Exemples |
|---|
| $\displaystyle 3x + 6 = 3(x + 2)$ <br> $\displaystyle 5x^2 - 10x = 5x(x - 2)$ <br> $\displaystyle 4x^3 + 8x^2 - 12x = 4x(x^2 + 2x - 3)$ |

## II. Factorisation par groupement

| Principe | Méthode |
|---|---|
| **Groupement** | Grouper les termes par paires qui ont un facteur commun, puis factoriser chaque groupe |

| Exemple |
|---|
| **Factoriser $\displaystyle ax + ay + bx + by$ :** <br> Grouper : $\displaystyle (ax + ay) + (bx + by)$ <br> Facteur commun : $\displaystyle a(x+y) + b(x+y)$ <br> Résultat : $\displaystyle (x+y)(a+b)$ |

## III. Factorisation avec les identités remarquables

| Forme à reconnaître | Factorisation |
|---|---|
| **$\displaystyle a^2 + 2ab + b^2$** | $\displaystyle (a+b)^2$ |
| **$\displaystyle a^2 - 2ab + b^2$** | $\displaystyle (a-b)^2$ |
| **$\displaystyle a^2 - b^2$** | $\displaystyle (a+b)(a-b)$ |

| Exemples |
|---|
| $\displaystyle x^2 + 6x + 9 = (x + 3)^2$ (avec $\displaystyle a=x$, $\displaystyle b=3$) <br> $\displaystyle 4x^2 - 12x + 9 = (2x - 3)^2$ (avec $\displaystyle a=2x$, $\displaystyle b=3$) <br> $\displaystyle 25x^2 - 16 = (5x - 4)(5x + 4)$ (avec $\displaystyle a=5x$, $\displaystyle b=4$) |

| Astuce |
|---|
| Pour une différence de carrés $\displaystyle a^2 - b^2$, penser à $(a-b)(a+b)$. Pour reconnaître $\displaystyle a^2 \pm 2ab + b^2$, vérifier que le terme du milieu est bien le double produit. |

## IV. Factorisation de trinômes du second degré

| Forme générale | Description |
|---|---|
| **Trinôme** | $\displaystyle ax^2 + bx + c$ avec $\displaystyle a \neq 0$ |

| Méthode | Description |
|---|---|
| **1. Recherche** | Trouver deux nombres $\displaystyle \alpha$ et $\displaystyle \beta$ tels que : <br> $\displaystyle \alpha + \beta = \dfrac{b}{a}$ (somme) <br> $\displaystyle \alpha \times \beta = \dfrac{c}{a}$ (produit) <br> Alors : $\displaystyle ax^2 + bx + c = a(x-\alpha)(x-\beta)$ |
| **2. Discriminant** | $\displaystyle \Delta = b^2 - 4ac$ <br> Si $\displaystyle \Delta \geq 0$, calculer les racines et factoriser |

| Condition | Nature des racines | Factorisation |
|---|---|---|
| **$\displaystyle \Delta > 0$** | Deux racines $\displaystyle x_1$ et $\displaystyle x_2$ | $\displaystyle ax^2+bx+c = a(x-x_1)(x-x_2)$ |
| **$\displaystyle \Delta = 0$** | Racine double $\displaystyle x_0$ | $\displaystyle ax^2+bx+c = a(x-x_0)^2$ |
| **$\displaystyle \Delta < 0$** | Pas de racines réelles | Pas de factorisation réelle |

| Exemple |
|---|
| **Factoriser $\displaystyle x^2 + 5x + 6$ :** <br> Chercher deux nombres dont la somme est $\displaystyle 5$ et le produit est $\displaystyle 6$ <br> Les nombres sont $\displaystyle 2$ et $\displaystyle 3$ (car $\displaystyle 2 + 3 = 5$ et $\displaystyle 2 \times 3 = 6$) <br> $\displaystyle x^2 + 5x + 6 = (x + 2)(x + 3)$ |

::: attention
Si le trinôme a un coefficient $a \neq 1$, ne pas oublier de factoriser par $a$ avant de chercher les racines !
:::

## V. Mise en forme factorisée

| Principe | Objectif |
|---|---|
| **Forme factorisée** | Écrire une expression sous la forme $\displaystyle k(x-\alpha_1)(x-\alpha_2)\cdots(x-\alpha_n)$ où $\displaystyle k$ est un facteur constant et les $\displaystyle \alpha_i$ sont les racines |

| Étape | Méthode |
|---|---|
| **1** | **Factoriser :** utiliser les méthodes précédentes (facteur commun, identités, etc.) |
| **2** | **Identifier les racines :** valeurs de $\displaystyle x$ qui annulent chaque facteur |
| **3** | **Ordonner :** mettre la forme factorisée avec facteur constant en premier |
| **4** | **Simplifier :** réduire les expressions dans les facteurs |

| Exemples |
|---|
| $\displaystyle 3x^2 - 12x = 3x(x - 4)$ (racines : $\displaystyle x = 0$ et $\displaystyle x = 4$) <br> $\displaystyle x^2 - 9 = (x - 3)(x + 3)$ (racines : $\displaystyle x = 3$ et $\displaystyle x = -3$) <br> $\displaystyle x^3 - 4x = x(x - 2)(x + 2)$ (racines : $\displaystyle x = 0$, $\displaystyle x = 2$, $\displaystyle x = -2$) |

## VI. Méthode générale et stratégie

| Ordre | Ordre de recherche à suivre |
|---|---|
| **1** | **Facteur commun :** y a-t-il un facteur commun à tous les termes ? |
| **2** | **Identités remarquables :** reconnaître $\displaystyle a^2 \pm 2ab + b^2$ ou $\displaystyle a^2 - b^2$ |
| **3** | **Groupement :** peut-on grouper les termes par paires ? |
| **4** | **Trinôme :** pour $\displaystyle ax^2 + bx + c$, chercher deux nombres dont la somme et le produit sont connus |
| **5** | **Combinaison :** utiliser plusieurs méthodes successivement |

## VII. Cas particuliers

| Cas | Factorisation |
|---|---|
| **$\displaystyle x^n - 1$ (n pair)** | $\displaystyle x^4 - 1 = (x^2 - 1)(x^2 + 1) = (x-1)(x+1)(x^2 + 1)$ |
| **Avec $\displaystyle \sqrt{x}$** | $\displaystyle x\sqrt{x} + 2\sqrt{x} = \sqrt{x}(x + 2)$ (facteur commun $\displaystyle \sqrt{x}$) |

## VIII. Erreurs fréquentes et conseils

| ERREURS À ÉVITER |
|---|
| **Oublier le facteur commun :** écrire $\displaystyle 2x + 4 = 2(x + 2)$ et non $\displaystyle 2x + 4 = 2x + 2$ <br> <br> **Mauvais signe :** $\displaystyle x^2 - 9 = (x-3)(x+3)$ et non $\displaystyle (x-3)(x-3)$ <br> <br> **Facteur commun partiel :** dans $\displaystyle 2x + 3x$, le facteur commun est $\displaystyle x$, pas $\displaystyle 2x$ <br> <br> **Oublier de factoriser complètement :** $\displaystyle 4x^2 - 8x = 4x(x-2)$ et non $\displaystyle 2(2x^2 - 4x)$ <br> <br> **Confondre factorisation et développement :** factoriser transforme une somme en produit <br> <br> **Oublier le coefficient :** dans $\displaystyle 2x^2 + 4x$, factoriser par $\displaystyle 2x$ donne $\displaystyle 2x(x+2)$ |

| CONSEILS |
|---|
| Toujours vérifier en **développant** le résultat obtenu <br> <br> Pour le facteur commun, prendre le **PGCD** des coefficients et les lettres communes avec le **plus petit exposant** <br> <br> Dans une différence de carrés $\displaystyle a^2 - b^2$, penser à $(a-b)(a+b)$ <br> <br> Pour les trinômes, lister les **diviseurs** du terme constant pour trouver plus rapidement <br> <br> La forme factorisée permet de **lire directement les racines** de l'expression <br> <br> Si une expression ne se factorise pas dans $\displaystyle \mathbb{R}$, elle peut parfois se factoriser dans $\displaystyle \mathbb{C}$ |

## IX. Formules rapides — mémo

| Méthode | Formule/Méthode |
|---|---|
| **Facteur commun** | PGCD des coefficients + lettres communes (plus petit exposant) |
| **Identité : carré parfait** | $\displaystyle a^2 + 2ab + b^2 = (a+b)^2$ ou $\displaystyle a^2 - 2ab + b^2 = (a-b)^2$ |
| **Identité : différence de carrés** | $\displaystyle a^2 - b^2 = (a+b)(a-b)$ |
| **Trinôme (méthode recherche)** | Trouver $\displaystyle \alpha$ et $\displaystyle \beta$ : $\displaystyle \alpha + \beta = \dfrac{b}{a}$, $\displaystyle \alpha \times \beta = \dfrac{c}{a}$ <br> $\displaystyle ax^2 + bx + c = a(x-\alpha)(x-\beta)$ |
| **Trinôme (discriminant)** | $\displaystyle \Delta = b^2 - 4ac$ <br> Si $\displaystyle \Delta \geq 0$ : $\displaystyle ax^2+bx+c = a(x-x_1)(x-x_2)$ ou $\displaystyle a(x-x_0)^2$ |
| **Groupement** | Grouper par paires qui ont un facteur commun |
| **Forme factorisée** | $\displaystyle k(x-\alpha_1)(x-\alpha_2)\cdots(x-\alpha_n)$ où $\displaystyle k$ est constant |

## X. Points clés à retenir

| Notion | À retenir |
|---|---|
| **Factorisation** | Transformer une somme ou différence en produit de facteurs (opération inverse du développement) |
| **Facteur commun** | Identifier un facteur commun à tous les termes : PGCD des coefficients + lettres communes avec plus petit exposant |
| **Identités remarquables** | Reconnaître $\displaystyle a^2 + 2ab + b^2 = (a+b)^2$, $\displaystyle a^2 - 2ab + b^2 = (a-b)^2$, $\displaystyle a^2 - b^2 = (a+b)(a-b)$ |
| **Groupement** | Grouper les termes par paires qui ont un facteur commun, puis factoriser chaque groupe |
| **Trinômes** | Pour $\displaystyle ax^2 + bx + c$, trouver deux nombres dont la somme est $\displaystyle \dfrac{b}{a}$ et le produit est $\displaystyle \dfrac{c}{a}$. Ou utiliser le discriminant $\displaystyle \Delta = b^2 - 4ac$ |
| **Discriminant** | $\displaystyle \Delta > 0$ : deux racines, $\displaystyle \Delta = 0$ : racine double, $\displaystyle \Delta < 0$ : pas de factorisation réelle |
| **Forme factorisée** | $\displaystyle k(x-\alpha_1)(x-\alpha_2)\cdots$ permet de lire directement les racines de l'expression |
| **Ordre de recherche** | Facteur commun → Identités remarquables → Groupement → Trinôme → Combinaison |
| **Vérification** | Toujours vérifier en développant le résultat obtenu |
| **Erreur fréquente** | Oublier le facteur commun : $\displaystyle 2x + 4 \neq 2x + 2$ (il faut $\displaystyle 2(x + 2)$) |
| **Cas particuliers** | $\displaystyle x^n - 1$, expressions avec $\displaystyle \sqrt{x}$, factorisations en plusieurs étapes |
