=== Découverte - Le discriminant : outil pour déterminer le nombre de racines réelles
Id: 1314
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Pour chaque fonction polynôme du second degré, calculer le discriminant $\Delta$ et en déduire le nombre de racines réelles. Lorsque c’est possible, donner les racines.

1. $f(x) = x^2 - 4x + 3$
2. $g(x) = x^2 - 4x + 4$
3. $h(x) = x^2 - 4x + 5$
4. $k(x) = 2x^2 + 8x + 6$
5. $m(x) = -x^2 + 2x - 1$

Étapes:

<!-- optitab:1 -->
## Question 1 : $f(x) = x^2 - 4x + 3$

::: methode
Identifier $a$, $b$, $c$, calculer $\Delta = b^2 - 4ac$, puis conclure selon le signe de $\Delta$.
:::

::: etape Identifier les coefficients
$a = 1$, $b = -4$, $c = 3$.
:::

::: etape Calculer le discriminant
$$
\begin{aligned}
\Delta &= b^2 - 4ac \\
&= (-4)^2 - 4 \times 1 \times 3 \\
&= 16 - 12 = 4
\end{aligned}
$$
:::

::: etape Conclure
$\Delta = 4 \gt 0$ : deux racines distinctes, avec $\sqrt{\Delta} = 2$ :

$$x_1 = \frac{4 - 2}{2} = 1$$

$$x_2 = \frac{4 + 2}{2} = 3$$
:::

::: resultat
$\Delta = 4 \gt 0$ : $f$ a deux racines, $1$ et $3$.
:::

::: attention
$b = -4$, donc $b^2 = (-4)^2 = 16$ et non $-16$ : on met toujours $b$ entre parenthèses quand il est négatif.
:::

## Question 2 : $g(x) = x^2 - 4x + 4$

::: methode
Même méthode : calcul de $\Delta$.
:::

::: etape Calculer le discriminant
$a = 1$, $b = -4$, $c = 4$ :

$$\Delta = (-4)^2 - 4 \times 1 \times 4 = 16 - 16 = 0$$
:::

::: etape Conclure
$\Delta = 0$ : une seule racine (racine double) $x_0 = -\dfrac{b}{2a} = \dfrac{4}{2} = 2$. On reconnaît d’ailleurs l’identité remarquable $x^2 - 4x + 4 = (x - 2)^2$.
:::

::: resultat
$\Delta = 0$ : $g$ a une racine double, $x_0 = 2$.
:::

## Question 3 : $h(x) = x^2 - 4x + 5$

::: methode
Même méthode : calcul de $\Delta$.
:::

::: etape Calculer le discriminant
$a = 1$, $b = -4$, $c = 5$ :

$$\Delta = (-4)^2 - 4 \times 1 \times 5 = 16 - 20 = -4$$
:::

::: resultat
$\Delta = -4 \lt 0$ : $h$ n’a aucune racine réelle (sa parabole ne coupe pas l’axe des abscisses).
:::

## Question 4 : $k(x) = 2x^2 + 8x + 6$

::: methode
Même méthode : calcul de $\Delta$.
:::

::: etape Calculer le discriminant
$a = 2$, $b = 8$, $c = 6$ :

$$\Delta = 8^2 - 4 \times 2 \times 6 = 64 - 48 = 16$$
:::

::: etape Calculer les racines
$\sqrt{\Delta} = 4$ :

$$x_1 = \frac{-8 - 4}{2 \times 2} = -3$$

$$x_2 = \frac{-8 + 4}{2 \times 2} = -1$$
:::

::: resultat
$\Delta = 16 \gt 0$ : $k$ a deux racines, $-3$ et $-1$.
:::

## Question 5 : $m(x) = -x^2 + 2x - 1$

::: methode
Même méthode, en faisant attention aux signes de $a$ et de $c$.
:::

::: etape Calculer le discriminant
$a = -1$, $b = 2$, $c = -1$ :

$$\Delta = 2^2 - 4 \times (-1) \times (-1) = 4 - 4 = 0$$
:::

::: etape Conclure
Racine double $x_0 = -\dfrac{b}{2a} = -\dfrac{2}{2 \times (-1)} = 1$. En effet, $-x^2 + 2x - 1 = -(x^2 - 2x + 1) = -(x - 1)^2$.
:::

::: resultat
$\Delta = 0$ : $m$ a une racine double, $x_0 = 1$.
:::

::: retenir
$\Delta \gt 0$ : deux racines ; $\Delta = 0$ : une racine double ; $\Delta \lt 0$ : aucune racine réelle.
:::

Solution:
<!-- optitab:1 -->
1. $\Delta = 4$ : deux racines, $1$ et $3$.
2. $\Delta = 0$ : une racine double, $2$.
3. $\Delta = -4$ : aucune racine réelle.
4. $\Delta = 16$ : deux racines, $-3$ et $-1$.
5. $\Delta = 0$ : une racine double, $1$.

=== Découverte - Lire une parabole : signe de a, sommet et racines
Id: 4284
Difficulté: easy
Image: v1_n154_ex4284_1_lecture_paraboles.png

Énoncé: <!-- optitab:1 -->
Les courbes $\mathcal{C}_1$, $\mathcal{C}_2$, $\mathcal{C}_3$ et $\mathcal{C}_4$ représentent quatre fonctions polynômes du second degré $f_1$, $f_2$, $f_3$ et $f_4$. Sur chaque courbe, le sommet et un autre point à coordonnées entières sont marqués.

[IMAGE_1]

1. Pour chaque courbe, donner le signe du coefficient $a$ et les coordonnées du sommet.
2. Pour chaque fonction, donner le nombre de racines et le signe du discriminant.
3. En utilisant le sommet et le second point marqué, déterminer la forme canonique de chaque fonction.
4. Développer $f_1(x)$ et retrouver ses racines par le calcul.
5. Résoudre graphiquement $f_1(x) \lt 0$ et $f_4(x) \ge 0$.

Étapes:

<!-- optitab:1 -->
## Question 1 : Signe de $a$ et sommet

::: methode
Parabole « tournée vers le haut » : $a \gt 0$ (le sommet est un minimum) ; « tournée vers le bas » : $a \lt 0$ (le sommet est un maximum).
:::

::: resultat
| Courbe | Signe de $a$ | Sommet |
|---|---|---|
| $\mathcal{C}_1$ | $a \gt 0$ | $(1\,;-4)$ |
| $\mathcal{C}_2$ | $a \lt 0$ | $(2\,;0)$ |
| $\mathcal{C}_3$ | $a \gt 0$ | $(-1\,;1)$ |
| $\mathcal{C}_4$ | $a \lt 0$ | $(-1\,;4)$ |
:::

## Question 2 : Racines et discriminant

::: methode
Les racines sont les abscisses des points d’intersection avec l’axe des abscisses ; deux, une ou zéro intersection correspond à $\Delta \gt 0$, $\Delta = 0$ ou $\Delta \lt 0$.
:::

::: resultat
- $f_1$ : deux racines ($-1$ et $3$), $\Delta \gt 0$.
- $f_2$ : une racine double ($2$), $\Delta = 0$ : le sommet est sur l’axe.
- $f_3$ : aucune racine, $\Delta \lt 0$ : la parabole est entièrement au-dessus de l’axe.
- $f_4$ : deux racines ($-3$ et $1$), $\Delta \gt 0$.
:::

## Question 3 : Formes canoniques

::: methode
Écrire $f(x) = a(x - \alpha)^2 + \beta$ avec le sommet lu, puis trouver $a$ grâce au second point.
:::

::: etape $f_1$ : sommet $(1\,;-4)$ et point $(3\,;0)$
$f_1(x) = a(x - 1)^2 - 4$ et $f_1(3) = 0$ : $4a - 4 = 0$, donc $a = 1$.
:::

::: etape $f_2$ : sommet $(2\,;0)$ et point $(0\,;-4)$
$f_2(x) = a(x - 2)^2$ et $f_2(0) = -4$ : $4a = -4$, donc $a = -1$.
:::

::: etape $f_3$ : sommet $(-1\,;1)$ et point $(1\,;3)$
$f_3(x) = a(x + 1)^2 + 1$ et $f_3(1) = 3$ : $4a + 1 = 3$, donc $a = \dfrac{1}{2}$.
:::

::: etape $f_4$ : sommet $(-1\,;4)$ et point $(1\,;0)$
$f_4(x) = a(x + 1)^2 + 4$ et $f_4(1) = 0$ : $4a + 4 = 0$, donc $a = -1$.
:::

::: resultat
$f_1(x) = (x - 1)^2 - 4$ ; $f_2(x) = -(x - 2)^2$ ; $f_3(x) = \dfrac{1}{2}(x + 1)^2 + 1$ ; $f_4(x) = -(x + 1)^2 + 4$.
:::

::: attention
Le sommet $(-1\,;1)$ donne $(x + 1)^2$ : dans la forme canonique, le signe devant $\alpha$ est un « $-$ », et $x - (-1) = x + 1$.
:::

## Question 4 : Racines de $f_1$ par le calcul

::: methode
Développer, puis calculer le discriminant.
:::

::: etape Développer
$$f_1(x) = x^2 - 2x + 1 - 4 = x^2 - 2x - 3$$
:::

::: etape Résoudre $f_1(x) = 0$
$\Delta = 4 + 12 = 16$ : $x = \dfrac{2 \pm 4}{2}$, soit $-1$ ou $3$.
:::

::: resultat
$f_1(x) = x^2 - 2x - 3$ ; racines $-1$ et $3$, comme lu sur le graphique.
:::

## Question 5 : Inéquations graphiques

::: methode
$f(x) \lt 0$ : abscisses des points de la courbe situés **sous** l’axe des abscisses ; $f(x) \ge 0$ : sur l’axe ou au-dessus.
:::

::: etape $f_1(x) \lt 0$
$\mathcal{C}_1$ est sous l’axe entre ses racines $-1$ et $3$, exclues (inégalité stricte).
:::

::: etape $f_4(x) \ge 0$
$\mathcal{C}_4$ est au-dessus de l’axe, ou dessus, entre $-3$ et $1$, inclus.
:::

::: resultat
$f_1(x) \lt 0 \iff x \in {]-1\,;3[}$ ; $f_4(x) \ge 0 \iff x \in [-3\,;1]$.
:::

Solution:
<!-- optitab:1 -->
1. $\mathcal{C}_1$ : $a \gt 0$, $S(1\,;-4)$ ; $\mathcal{C}_2$ : $a \lt 0$, $S(2\,;0)$ ; $\mathcal{C}_3$ : $a \gt 0$, $S(-1\,;1)$ ; $\mathcal{C}_4$ : $a \lt 0$, $S(-1\,;4)$.
2. $f_1$ : deux racines ; $f_2$ : une racine double ; $f_3$ : aucune ; $f_4$ : deux racines.
3. $f_1(x) = (x - 1)^2 - 4$ ; $f_2(x) = -(x - 2)^2$ ; $f_3(x) = \dfrac{1}{2}(x + 1)^2 + 1$ ; $f_4(x) = -(x + 1)^2 + 4$.
4. $f_1(x) = x^2 - 2x - 3$, racines $-1$ et $3$.
5. $f_1(x) \lt 0 \iff x \in {]-1\,;3[}$ ; $f_4(x) \ge 0 \iff x \in [-3\,;1]$.

=== Découverte - Notions fondamentales sur les polynômes du second degré
Id: 1313
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Questions de base sur les trinômes.

1. Identifier les coefficients $a$, $b$ et $c$ de $f(x) = 3x^2 - 5x + 2$.
2. Déterminer les racines de $g(x) = (x - 2)(x + 3)$.
3. Calculer le discriminant de $h(x) = x^2 - 6x + 9$ et interpréter le résultat.
4. Résoudre l’équation $x^2 - 5x + 6 = 0$.
5. Écrire $p(x) = 2(x - 1)(x + 4)$ sous forme développée.

Étapes:

<!-- optitab:1 -->
## Question 1 : Coefficients de $f(x) = 3x^2 - 5x + 2$

::: methode
Comparer avec la forme développée $ax^2 + bx + c$, en gardant les signes.
:::

::: etape Identifier
- coefficient de $x^2$ : $a = 3$ ;
- coefficient de $x$ : $b = -5$ (le signe « $-$ » fait partie du coefficient) ;
- terme constant : $c = 2$.
:::

::: resultat
$a = 3$, $b = -5$, $c = 2$.
:::

## Question 2 : Racines de $g(x) = (x - 2)(x + 3)$

::: methode
Forme factorisée : un produit est nul si et seulement si l’un de ses facteurs est nul.
:::

::: etape Résoudre $g(x) = 0$
$(x - 2)(x + 3) = 0 \iff x - 2 = 0$ ou $x + 3 = 0$, c’est-à-dire $x = 2$ ou $x = -3$.
:::

::: resultat
Les racines de $g$ sont $-3$ et $2$ (aucun calcul de $\Delta$ n’est nécessaire).
:::

## Question 3 : Discriminant de $h(x) = x^2 - 6x + 9$

::: methode
Calculer $\Delta = b^2 - 4ac$ avec $a = 1$, $b = -6$, $c = 9$.
:::

::: etape Calculer
$$\Delta = (-6)^2 - 4 \times 1 \times 9 = 36 - 36 = 0$$
:::

::: etape Interpréter
$\Delta = 0$ : $h$ a une seule racine, $x_0 = -\dfrac{-6}{2} = 3$. On reconnaît $h(x) = (x - 3)^2$.
:::

::: resultat
$\Delta = 0$ : racine double $3$, et $h(x) = (x - 3)^2$.
:::

## Question 4 : Résoudre $x^2 - 5x + 6 = 0$

::: methode
Calcul du discriminant, puis formules des racines ; vérification par substitution.
:::

::: etape Calculer le discriminant
$$\Delta = (-5)^2 - 4 \times 1 \times 6 = 25 - 24 = 1 \gt 0$$
:::

::: etape Calculer les solutions
$$x_1 = \frac{5 - 1}{2} = 2$$

$$x_2 = \frac{5 + 1}{2} = 3$$
:::

::: etape Vérifier
$2^2 - 5 \times 2 + 6 = 0$ et $3^2 - 5 \times 3 + 6 = 0$.
:::

::: resultat
$\mathcal{S} = \{2\,;3\}$.
:::

## Question 5 : Développer $p(x) = 2(x - 1)(x + 4)$

::: methode
Développer d’abord le produit des parenthèses (double distributivité), puis multiplier par $2$.
:::

::: etape Double distributivité
$$
\begin{aligned}
(x - 1)(x + 4) &= x^2 + 4x - x - 4 \\
&= x^2 + 3x - 4
\end{aligned}
$$
:::

::: etape Multiplier par $2$
$$p(x) = 2(x^2 + 3x - 4) = 2x^2 + 6x - 8$$
:::

::: resultat
$p(x) = 2x^2 + 6x - 8$.
:::

::: attention
Le coefficient $2$ multiplie **tous** les termes : écrire $2x^2 + 3x - 4$ est une erreur fréquente.
:::

Solution:
<!-- optitab:1 -->
1. $a = 3$, $b = -5$, $c = 2$.
2. Les racines de $g$ sont $-3$ et $2$.
3. $\Delta = 0$ : racine double $3$ ; $h(x) = (x - 3)^2$.
4. $\mathcal{S} = \{2\,;3\}$.
5. $p(x) = 2x^2 + 6x - 8$.

=== DS - Polynômes du second degré - Type 1
Id: 1324
Difficulté: hard

Énoncé: <!-- optitab:1 -->
Devoir surveillé portant sur l’ensemble du chapitre.

**Partie A — Étude d’un trinôme**

On considère la fonction $f$ définie sur $\mathbb{R}$ par $f(x) = 2x^2 - 8x + 6$.

**A1.** Calculer le discriminant de $f$ et en déduire le nombre de racines réelles.

**A2.** Déterminer les racines $x_1$ et $x_2$ de $f$, avec $x_1 \lt x_2$.

**A3.** Écrire $f(x)$ sous forme factorisée.

**A4.** Écrire $f(x)$ sous forme canonique et en déduire les coordonnées du sommet $S$ de la parabole.

**A5.** Dresser le tableau de signes de $f(x)$, puis résoudre l’inéquation $f(x) \ge 0$.

**Partie B — Rectangle d’aire maximale**

Un rectangle $ABCD$ vérifie $AB = x$ et $BC = 8 - x$, où $x$ est un réel tel que $0 \lt x \lt 8$.

**B1.** Montrer que l’aire du rectangle est $\mathcal{A}(x) = -x^2 + 8x$.

**B2.** Écrire $\mathcal{A}(x)$ sous forme canonique.

**B3.** En déduire la valeur de $x$ pour laquelle l’aire est maximale, et cette aire maximale. Quelle est alors la nature du rectangle ?

**Partie C — Trinôme à paramètre**

Pour tout réel $m$, on pose $P_m(x) = x^2 - (m + 2)x + 2m$.

**C1.** Montrer que le discriminant de $P_m$ est $\Delta_m = (m - 2)^2$.

**C2.** Pour quelle valeur de $m$ le trinôme $P_m$ a-t-il une racine double ? Donner cette racine.

**C3.** Pour quelles valeurs de $m$ le trinôme $P_m$ a-t-il deux racines distinctes ? Vérifier que ces racines sont $2$ et $m$.

Étapes:

<!-- optitab:1 -->
## Partie A : Étude d’un trinôme

## Question A1 : Discriminant

::: methode
$\Delta = b^2 - 4ac$ avec $a = 2$, $b = -8$, $c = 6$.
:::

::: etape Calculer
$$\Delta = (-8)^2 - 4 \times 2 \times 6 = 64 - 48 = 16$$
:::

::: resultat
$\Delta = 16 \gt 0$ : $f$ a deux racines distinctes.
:::

## Question A2 : Racines

::: methode
Formules $x_{1,2} = \dfrac{-b \pm \sqrt{\Delta}}{2a}$ avec $\sqrt{\Delta} = 4$.
:::

::: etape Calculer
$$x_1 = \frac{8 - 4}{2 \times 2} = 1$$

$$x_2 = \frac{8 + 4}{2 \times 2} = 3$$
:::

::: resultat
$x_1 = 1$ et $x_2 = 3$.
:::

## Question A3 : Forme factorisée

::: methode
$f(x) = a(x - x_1)(x - x_2)$, sans oublier le coefficient $a$.
:::

::: resultat
$f(x) = 2(x - 1)(x - 3)$.
:::

::: attention
$(x - 1)(x - 3) = x^2 - 4x + 3$ : sans le facteur $2$, on n’obtient pas $f(x)$.
:::

## Question A4 : Forme canonique et sommet

::: methode
$\alpha = -\dfrac{b}{2a}$, $\beta = f(\alpha)$, puis $f(x) = a(x - \alpha)^2 + \beta$.
:::

::: etape Calculer $\alpha$ et $\beta$
$$
\begin{aligned}
\alpha &= -\frac{-8}{2 \times 2} = 2 \\
\beta &= f(2) = 2 \times 4 - 16 + 6 = -2
\end{aligned}
$$
:::

::: etape Contrôler en développant
$2(x - 2)^2 - 2 = 2(x^2 - 4x + 4) - 2 = 2x^2 - 8x + 6$.
:::

::: resultat
$f(x) = 2(x - 2)^2 - 2$ ; sommet $S(2\,;-2)$.
:::

## Question A5 : Signe et inéquation

::: methode
$a = 2 \gt 0$ : $f(x)$ est positif à l’extérieur des racines et négatif entre elles.
:::

::: tableau Signe de $f(x) = 2(x - 1)(x - 3)$
x : -\infty, 1, 3, +\infty
f(x) : , +, z, -, z, +,
:::

::: etape Lire le tableau
$f(x) \ge 0$ là où le signe est « $+$ » ou « $0$ » : on garde les racines (crochets fermés).
:::

::: resultat
$f(x) \ge 0 \iff x \in {]-\infty\,;1]} \cup {[3\,;+\infty[}$.
:::

## Partie B : Rectangle d’aire maximale

## Question B1 : Expression de l’aire

::: methode
Aire d’un rectangle : longueur $\times$ largeur.
:::

::: etape Calculer
$$\mathcal{A}(x) = AB \times BC = x(8 - x) = -x^2 + 8x$$

La condition $0 \lt x \lt 8$ assure que les deux côtés sont strictement positifs.
:::

::: resultat
$\mathcal{A}(x) = -x^2 + 8x$ pour $x \in {]0\,;8[}$.
:::

## Question B2 : Forme canonique

::: methode
$\alpha = -\dfrac{b}{2a}$ et $\beta = \mathcal{A}(\alpha)$, avec $a = -1$ et $b = 8$.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{8}{2 \times (-1)} = 4 \\
\beta &= \mathcal{A}(4) = -16 + 32 = 16
\end{aligned}
$$
:::

::: resultat
$\mathcal{A}(x) = -(x - 4)^2 + 16$.
:::

## Question B3 : Aire maximale

::: methode
Pour tout $x$, $(x - 4)^2 \ge 0$, donc $\mathcal{A}(x) \le 16$, avec égalité pour $x = 4$.
:::

::: etape Conclure
Le maximum vaut $16$, atteint pour $x = 4$, qui appartient bien à ${]0\,;8[}$. Alors $AB = 4$ et $BC = 8 - 4 = 4$.
:::

::: resultat
Aire maximale $16$ (unités d’aire) pour $x = 4$ : le rectangle est un **carré** de côté $4$.
:::

## Partie C : Trinôme à paramètre

## Question C1 : Discriminant

::: methode
Appliquer $\Delta = b^2 - 4ac$ avec $a = 1$, $b = -(m + 2)$, $c = 2m$, puis reconnaître une identité remarquable.
:::

::: etape Calculer
$$
\begin{aligned}
\Delta_m &= (m + 2)^2 - 4 \times 1 \times 2m \\
&= m^2 + 4m + 4 - 8m \\
&= m^2 - 4m + 4 \\
&= (m - 2)^2
\end{aligned}
$$
:::

::: resultat
$\Delta_m = (m - 2)^2$.
:::

## Question C2 : Racine double

::: methode
Racine double $\iff \Delta_m = 0$.
:::

::: etape Résoudre
$(m - 2)^2 = 0 \iff m = 2$. Alors $P_2(x) = x^2 - 4x + 4 = (x - 2)^2$.
:::

::: resultat
$m = 2$ ; la racine double est $x_0 = 2$.
:::

## Question C3 : Deux racines distinctes

::: methode
Deux racines distinctes $\iff \Delta_m \gt 0$ ; vérifier les racines en substituant.
:::

::: etape Condition
$(m - 2)^2 \gt 0 \iff m \neq 2$.
:::

::: etape Vérifier les racines
$P_m(2) = 4 - 2(m + 2) + 2m = 0$ et $P_m(m) = m^2 - (m + 2)m + 2m = 0$. Donc $P_m(x) = (x - 2)(x - m)$.
:::

::: resultat
Deux racines distinctes pour tout $m \neq 2$ : ce sont $2$ et $m$.
:::

Solution:
<!-- optitab:1 -->
**Partie A.** A1 : $\Delta = 16$, deux racines. A2 : $x_1 = 1$, $x_2 = 3$. A3 : $f(x) = 2(x - 1)(x - 3)$. A4 : $f(x) = 2(x - 2)^2 - 2$, $S(2\,;-2)$. A5 : $f(x) \ge 0 \iff x \in {]-\infty\,;1]} \cup {[3\,;+\infty[}$.

**Partie B.** B1 : $\mathcal{A}(x) = x(8 - x) = -x^2 + 8x$. B2 : $\mathcal{A}(x) = -(x - 4)^2 + 16$. B3 : aire maximale $16$ pour $x = 4$ (carré de côté $4$).

**Partie C.** C1 : $\Delta_m = (m - 2)^2$. C2 : $m = 2$, racine double $2$. C3 : $m \neq 2$, racines $2$ et $m$.

=== DS - Polynômes du second degré - Type 2
Id: 1325
Difficulté: hard
Image: v1_n154_ex1325_1_projectile_ds2.png

Énoncé: <!-- optitab:1 -->
Devoir surveillé portant sur l’ensemble du chapitre.

**Partie A — Équations et inéquations**

**A1.** Résoudre dans $\mathbb{R}$ l’équation $x^2 - 6x + 8 = 0$.

**A2.** Résoudre dans $\mathbb{R}$ l’inéquation $-2x^2 + 10x - 12 \ge 0$.

**A3.** On pose $P(x) = x^2 - 5x + 6$ et $Q(x) = x^2 - 3x + 2$. Dresser dans un même tableau le signe de $P(x)$ et celui de $Q(x)$, puis déterminer les réels $x$ pour lesquels $P(x)$ et $Q(x)$ sont non nuls et de même signe.

**Partie B — Étude d’une fonction**

Soit $f$ la fonction définie sur $\mathbb{R}$ par $f(x) = -x^2 + 4x - 3$.

**B1.** Calculer $f(0)$, $f(1)$ et $f(3)$. Que représentent $1$ et $3$ pour $f$ ?

**B2.** En déduire la forme factorisée de $f(x)$.

**B3.** Écrire $f(x)$ sous forme canonique ; en déduire le maximum de $f$ et la valeur de $x$ où il est atteint.

**B4.** Dresser le tableau de signes de $f(x)$.

**Partie C — Lancer de poids**

## Question A3 : Signes de $P(x)$ et $Q(x)$

::: methode
Trouver les racines de chaque trinôme (racines évidentes), puis appliquer la règle du signe à chacun.
:::

::: etape Racines

:::

x : -\infty, 1, 2, +\infty
Q(x) : , +, z, -, z, +,

::: etape Comparer les signes
- sur ${]-\infty\,;1[}$ : $P(x) \gt 0$ et $Q(x) \gt 0$, même signe ;

=== Entraînement - Changement de variable : équations bicarrées
Id: 4286
Difficulté: medium

Énoncé: <!-- optitab:1 -->
*Pour aller plus loin.* Certaines équations se ramènent au second degré grâce à un changement d’inconnue. Résoudre dans $\mathbb{R}$ :

1. $x^4 - 5x^2 + 4 = 0$ (on pourra poser $X = x^2$) ;
2. $x^4 - x^2 - 12 = 0$ ;
3. $x^4 + 3x^2 + 2 = 0$ ;
4. $x - 5\sqrt{x} + 6 = 0$, pour $x \ge 0$ (on pourra poser $X = \sqrt{x}$).

Étapes:

<!-- optitab:1 -->
## Question 1 : $x^4 - 5x^2 + 4 = 0$

::: methode
Poser $X = x^2$ (avec $X \ge 0$) : $x^4 = X^2$, et l’équation devient du second degré en $X$.
:::

::: etape Équation en $X$
$X^2 - 5X + 4 = 0$ : $1$ est racine évidente et le produit des racines vaut $4$, donc $X = 1$ ou $X = 4$.
:::

::: etape Revenir à $x$
$x^2 = 1 \iff x = -1$ ou $x = 1$ ; $x^2 = 4 \iff x = -2$ ou $x = 2$.
:::

::: resultat
$\mathcal{S} = \{-2\,;-1\,;1\,;2\}$.
:::

## Question 2 : $x^4 - x^2 - 12 = 0$

::: methode
Même changement de variable ; on rejette les valeurs de $X$ négatives, car $X = x^2 \ge 0$.
:::

::: etape Équation en $X$
$X^2 - X - 12 = 0$ : $\Delta = 1 + 48 = 49$, d’où $X = \dfrac{1 \pm 7}{2}$, soit $4$ ou $-3$.
:::

::: etape Revenir à $x$
$x^2 = 4 \iff x = \pm 2$ ; $x^2 = -3$ est impossible.
:::

::: resultat
$\mathcal{S} = \{-2\,;2\}$.
:::

## Question 3 : $x^4 + 3x^2 + 2 = 0$

::: methode
Même changement de variable.
:::

::: etape Équation en $X$
$X^2 + 3X + 2 = 0$ : $-1$ est racine évidente et le produit vaut $2$, donc $X = -1$ ou $X = -2$.
:::

::: etape Revenir à $x$
Les deux valeurs sont strictement négatives : $x^2 = -1$ et $x^2 = -2$ sont impossibles. (On pouvait le voir directement : $x^4 + 3x^2 + 2 \ge 2 \gt 0$.)
:::

::: resultat
$\mathcal{S} = \varnothing$.
:::

## Question 4 : $x - 5\sqrt{x} + 6 = 0$

::: methode
Poser $X = \sqrt{x}$ (avec $X \ge 0$) : $x = X^2$.
:::

::: etape Équation en $X$
$X^2 - 5X + 6 = 0$ : somme $5$, produit $6$, donc $X = 2$ ou $X = 3$ (tous deux positifs).
:::

::: etape Revenir à $x$
$\sqrt{x} = 2 \iff x = 4$ ; $\sqrt{x} = 3 \iff x = 9$. Contrôle : $4 - 10 + 6 = 0$ et $9 - 15 + 6 = 0$.
:::

::: resultat
$\mathcal{S} = \{4\,;9\}$.
:::

::: retenir
Après un changement de variable, on vérifie toujours que les valeurs trouvées pour la nouvelle inconnue sont possibles ($X = x^2 \ge 0$, $X = \sqrt{x} \ge 0$), puis on revient à l’inconnue de départ.
:::

Solution:
<!-- optitab:1 -->
1. $\mathcal{S} = \{-2\,;-1\,;1\,;2\}$.
2. $\mathcal{S} = \{-2\,;2\}$.
3. $\mathcal{S} = \varnothing$.
4. $\mathcal{S} = \{4\,;9\}$.

=== Entraînement - Étude du signe d'une fonction polynôme du second degré
Id: 1318
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Étudier le signe des fonctions polynômes suivantes, définies sur $\mathbb{R}$ (on présentera un tableau de signes).

1. $f(x) = x^2 - 5x + 6$
2. $g(x) = -x^2 + 4x - 4$
3. $h(x) = x^2 + 2x + 3$
4. $k(x) = 2x^2 - 8x + 6$
5. $m(x) = -3x^2 + 6x - 3$
6. En déduire les solutions des inéquations $k(x) \le 0$ et $g(x) \lt 0$.

Étapes:

<!-- optitab:1 -->
## Question 1 : Signe de $f(x) = x^2 - 5x + 6$

::: methode
Chercher les racines, puis appliquer la règle : signe de $a$ à l’extérieur des racines, signe contraire entre elles.
:::

::: etape Racines
$\Delta = 25 - 24 = 1$, donc $x_1 = \dfrac{5 - 1}{2} = 2$ et $x_2 = \dfrac{5 + 1}{2} = 3$.
:::

::: tableau Signe de $f(x)$ ($a = 1 \gt 0$)
x : -\infty, 2, 3, +\infty
f(x) : , +, z, -, z, +,
:::

::: resultat
$f(x) \gt 0$ sur ${]-\infty\,;2[} \cup {]3\,;+\infty[}$, $f(x) \lt 0$ sur ${]2\,;3[}$, $f(2) = f(3) = 0$.
:::

## Question 2 : Signe de $g(x) = -x^2 + 4x - 4$

::: methode
Calculer $\Delta$ ; s’il est nul, le trinôme est du signe de $a$ partout, sauf à la racine où il s’annule.
:::

::: etape Racine
$\Delta = 16 - 4 \times (-1) \times (-4) = 16 - 16 = 0$ ; racine double $x_0 = -\dfrac{4}{2 \times (-1)} = 2$. En effet, $g(x) = -(x^2 - 4x + 4) = -(x - 2)^2$.
:::

::: tableau Signe de $g(x)$ ($a = -1 \lt 0$)
x : -\infty, 2, +\infty
g(x) : , -, z, -,
:::

::: resultat
$g(x) \lt 0$ pour tout $x \neq 2$, et $g(2) = 0$.
:::

## Question 3 : Signe de $h(x) = x^2 + 2x + 3$

::: methode
Si $\Delta \lt 0$, le trinôme garde le signe de $a$ sur $\mathbb{R}$.
:::

::: etape Discriminant
$\Delta = 4 - 12 = -8 \lt 0$ : pas de racine. Contrôle : $h(x) = (x + 1)^2 + 2 \ge 2$.
:::

::: resultat
$h(x) \gt 0$ pour tout réel $x$.
:::

## Question 4 : Signe de $k(x) = 2x^2 - 8x + 6$

::: methode
Mettre $2$ en facteur et chercher les racines de $x^2 - 4x + 3$.
:::

::: etape Racines
$k(x) = 2(x^2 - 4x + 3)$ ; $1$ est racine évidente et le produit des racines vaut $3$, d’où les racines $1$ et $3$ : $k(x) = 2(x - 1)(x - 3)$.

::: tableau Signe de $k(x)$ ($a = 2 \gt 0$)
x : -\infty, 1, 3, +\infty
k(x) : , +, z, -, z, +,
:::

::: resultat
$k(x) \gt 0$ sur ${]-\infty\,;1[} \cup {]3\,;+\infty[}$, $k(x) \lt 0$ sur ${]1\,;3[}$, $k(1) = k(3) = 0$.
:::

## Question 5 : Signe de $m(x) = -3x^2 + 6x - 3$

::: methode
Mettre $-3$ en facteur et reconnaître une identité remarquable.
:::

::: etape Factoriser
$m(x) = -3(x^2 - 2x + 1) = -3(x - 1)^2$ (on retrouve $\Delta = 36 - 36 = 0$).
:::

::: tableau Signe de $m(x)$ ($a = -3 \lt 0$)
x : -\infty, 1, +\infty
m(x) : , -, z, -,
:::

::: resultat
$m(x) \lt 0$ pour tout $x \neq 1$, et $m(1) = 0$.
:::

## Question 6 : Inéquations

::: methode
Lire les tableaux des questions 4 et 2 en faisant attention aux crochets.
:::

::: etape $k(x) \le 0$
$k(x)$ est négatif ou nul sur $[1\,;3]$ : les racines sont incluses car l’inégalité est large.
:::

::: etape $g(x) \lt 0$
$g(x) \lt 0$ pour tout $x \neq 2$ ; en $2$, $g(2) = 0$ ne convient pas (inégalité stricte).
:::

::: resultat
$k(x) \le 0 \iff x \in [1\,;3]$ ; $g(x) \lt 0 \iff x \in \mathbb{R} \setminus \{2\}$.
:::

::: retenir
Signe de $a$ partout, sauf entre les racines. Si $\Delta = 0$ ou $\Delta \lt 0$, le trinôme ne change jamais de signe.
:::

Solution:
<!-- optitab:1 -->
1. $f(x) \gt 0$ sur ${]-\infty\,;2[} \cup {]3\,;+\infty[}$ ; $f(x) \lt 0$ sur ${]2\,;3[}$ ; $f(2) = f(3) = 0$.
2. $g(x) = -(x - 2)^2$ : $g(x) \lt 0$ pour $x \neq 2$ ; $g(2) = 0$.
3. $h(x) \gt 0$ pour tout réel $x$ ($\Delta = -8$).
4. $k(x) \gt 0$ sur ${]-\infty\,;1[} \cup {]3\,;+\infty[}$ ; $k(x) \lt 0$ sur ${]1\,;3[}$ ; $k(1) = k(3) = 0$.

=== Entraînement - Factoriser un trinôme : choisir la bonne stratégie
Id: 1316
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Factoriser chaque trinôme en choisissant la stratégie la plus rapide : identité remarquable, racine évidente, somme et produit des racines, ou discriminant.

1. $f(x) = x^2 - 9$
2. $g(x) = 4x^2 - 12x + 9$
3. $h(x) = x^2 - 5x + 6$
4. $k(x) = 2x^2 + 3x - 5$
5. $m(x) = 3x^2 + 6x - 9$
6. $p(x) = x^2 - 2x - 4$
7. $q(x) = x^2 + x + 1$

Étapes:

<!-- optitab:1 -->
## Question 1 : $f(x) = x^2 - 9$

::: methode
Identité remarquable $A^2 - B^2 = (A - B)(A + B)$.
:::

::: resultat
$f(x) = x^2 - 3^2 = (x - 3)(x + 3)$.
:::

## Question 2 : $g(x) = 4x^2 - 12x + 9$

::: methode
Identité remarquable $A^2 - 2AB + B^2 = (A - B)^2$ avec $A = 2x$ et $B = 3$.
:::

::: etape Reconnaître
$(2x)^2 = 4x^2$, $3^2 = 9$ et $2 \times 2x \times 3 = 12x$.
:::

::: resultat
$g(x) = (2x - 3)^2$ (racine double $\dfrac{3}{2}$).
:::

## Question 3 : $h(x) = x^2 - 5x + 6$

::: methode
Somme et produit : chercher deux nombres de somme $5$ et de produit $6$.
:::

::: etape Trouver les racines
$2 + 3 = 5$ et $2 \times 3 = 6$ : les racines sont $2$ et $3$.
:::

::: resultat
$h(x) = (x - 2)(x - 3)$.
:::

## Question 4 : $k(x) = 2x^2 + 3x - 5$

::: methode
Racine évidente : la somme des coefficients est nulle ($2 + 3 - 5 = 0$), donc $1$ est racine.
:::

::: etape Autre racine
$1 \times x_2 = \dfrac{c}{a} = -\dfrac{5}{2}$, donc $x_2 = -\dfrac{5}{2}$.
:::

::: resultat
$k(x) = 2(x - 1)\left(x + \dfrac{5}{2}\right) = (x - 1)(2x + 5)$.
:::

::: attention
Avec $a = 2$, on écrit $2(x - 1)\left(x + \dfrac{5}{2}\right)$ : sans le $2$, le développement ne redonne pas $k(x)$.
:::

## Question 5 : $m(x) = 3x^2 + 6x - 9$

::: methode
Mettre $3$ en facteur, puis chercher une racine évidente de $x^2 + 2x - 3$.
:::

::: etape Factoriser
$m(x) = 3(x^2 + 2x - 3)$ ; $1$ est racine ($1 + 2 - 3 = 0$) et le produit des racines vaut $-3$, donc l’autre racine est $-3$.
:::

::: resultat
$m(x) = 3(x - 1)(x + 3)$.
:::

## Question 6 : $p(x) = x^2 - 2x - 4$

::: methode
Aucune racine évidente : on calcule le discriminant.
:::

::: etape Discriminant
$\Delta = 4 + 16 = 20$ et $\sqrt{20} = 2\sqrt{5}$.
:::

::: etape Racines
$$x_{1,2} = \frac{2 \pm 2\sqrt{5}}{2} = 1 \pm \sqrt{5}$$
:::

::: resultat
$p(x) = \left(x - 1 - \sqrt{5}\right)\left(x - 1 + \sqrt{5}\right)$.
:::

## Question 7 : $q(x) = x^2 + x + 1$

::: methode
Calculer $\Delta$ : s’il est négatif, aucune factorisation n’est possible.
:::

::: etape Discriminant
$\Delta = 1 - 4 = -3 \lt 0$.
:::

::: resultat
$q$ n’a pas de racine réelle : $q(x)$ ne se factorise pas en produit de facteurs du premier degré.
:::

::: retenir
Ordre des réflexes : identité remarquable, racine évidente ($1$, $-1$, $2$…) avec le produit $\dfrac{c}{a}$, somme et produit, et en dernier recours le discriminant.
:::

Solution:
<!-- optitab:1 -->
1. $f(x) = (x - 3)(x + 3)$.
2. $g(x) = (2x - 3)^2$.
3. $h(x) = (x - 2)(x - 3)$.
4. $k(x) = (x - 1)(2x + 5)$.
5. $m(x) = 3(x - 1)(x + 3)$.
6. $p(x) = \left(x - 1 - \sqrt{5}\right)\left(x - 1 + \sqrt{5}\right)$.
7. $q(x)$ ne se factorise pas ($\Delta = -3$).

=== Entraînement - Forme canonique et détermination du sommet d'une parabole
Id: 1317
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Pour chaque fonction, écrire $f(x)$ sous forme canonique, donner les coordonnées du sommet de la parabole et préciser si ce sommet correspond à un minimum ou à un maximum.

1. $f(x) = x^2 - 4x + 1$
2. $g(x) = 2x^2 - 8x + 5$
3. $h(x) = -x^2 + 6x - 8$
4. $k(x) = 3x^2 + 6x + 2$
5. $m(x) = -2x^2 + 4x - 1$

Étapes:

<!-- optitab:1 -->
## Question 1 : $f(x) = x^2 - 4x + 1$

::: methode
Compléter le carré : $x^2 - 4x$ est le début du développement de $(x - 2)^2 = x^2 - 4x + 4$.
:::

::: etape Faire apparaître le carré
$$
\begin{aligned}
f(x) &= (x^2 - 4x + 4) - 4 + 1 \\
&= (x - 2)^2 - 3
\end{aligned}
$$
:::

::: etape Contrôler avec les formules
$\alpha = -\dfrac{-4}{2} = 2$ et $\beta = f(2) = 4 - 8 + 1 = -3$ : même résultat.
:::

::: resultat
$f(x) = (x - 2)^2 - 3$ ; sommet $S(2\,;-3)$ ; $a = 1 \gt 0$ : **minimum** $-3$.
:::

## Question 2 : $g(x) = 2x^2 - 8x + 5$

::: methode
Formules : $\alpha = -\dfrac{b}{2a}$ et $\beta = g(\alpha)$, puis $g(x) = a(x - \alpha)^2 + \beta$.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{-8}{2 \times 2} = 2 \\
\beta &= g(2) = 8 - 16 + 5 = -3
\end{aligned}
$$
:::

::: etape Contrôler en développant
$2(x - 2)^2 - 3 = 2x^2 - 8x + 8 - 3 = 2x^2 - 8x + 5$.
:::

::: resultat
$g(x) = 2(x - 2)^2 - 3$ ; sommet $S(2\,;-3)$ ; $a = 2 \gt 0$ : **minimum** $-3$.
:::

::: remarque
$f$ et $g$ ont le même sommet mais pas la même parabole : le coefficient $a$ règle l’« ouverture » de la parabole.
:::

## Question 3 : $h(x) = -x^2 + 6x - 8$

::: methode
Mêmes formules, avec $a = -1$ et $b = 6$.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{6}{2 \times (-1)} = 3 \\
\beta &= h(3) = -9 + 18 - 8 = 1
\end{aligned}
$$
:::

::: resultat
$h(x) = -(x - 3)^2 + 1$ ; sommet $S(3\,;1)$ ; $a = -1 \lt 0$ : **maximum** $1$.
:::

## Question 4 : $k(x) = 3x^2 + 6x + 2$

::: methode
Mêmes formules, avec $a = 3$ et $b = 6$.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{6}{2 \times 3} = -1 \\
\beta &= k(-1) = 3 - 6 + 2 = -1
\end{aligned}
$$
:::

::: resultat
$k(x) = 3(x + 1)^2 - 1$ ; sommet $S(-1\,;-1)$ ; $a = 3 \gt 0$ : **minimum** $-1$.
:::

::: attention
$\alpha = -1$, donc $(x - \alpha)^2 = (x - (-1))^2 = (x + 1)^2$ : le signe dans la parenthèse est l’opposé de celui de $\alpha$.
:::

## Question 5 : $m(x) = -2x^2 + 4x - 1$

::: methode
Mêmes formules, avec $a = -2$ et $b = 4$.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{4}{2 \times (-2)} = 1 \\
\beta &= m(1) = -2 + 4 - 1 = 1
\end{aligned}
$$
:::

::: resultat
$m(x) = -2(x - 1)^2 + 1$ ; sommet $S(1\,;1)$ ; $a = -2 \lt 0$ : **maximum** $1$.
:::

Solution:
<!-- optitab:1 -->
1. $f(x) = (x - 2)^2 - 3$ ; $S(2\,;-3)$ ; minimum.
2. $g(x) = 2(x - 2)^2 - 3$ ; $S(2\,;-3)$ ; minimum.
3. $h(x) = -(x - 3)^2 + 1$ ; $S(3\,;1)$ ; maximum.
4. $k(x) = 3(x + 1)^2 - 1$ ; $S(-1\,;-1)$ ; minimum.
5. $m(x) = -2(x - 1)^2 + 1$ ; $S(1\,;1)$ ; maximum.

=== Entraînement - Paraboles et translations : du sommet à la forme canonique
Id: 1426
Difficulté: medium
Image: v1_n154_ex1426_1_paraboles_translations.png

Énoncé: <!-- optitab:1 -->
La parabole $\mathcal{P}_A$ représente la fonction carré $f : x \mapsto x^2$. Les paraboles $\mathcal{P}_B$, $\mathcal{P}_C$ et $\mathcal{P}_D$ s’obtiennent à partir de $\mathcal{P}_A$ par une translation ; leur sommet est marqué d’un point.

[IMAGE_1]

1. Lire les coordonnées du sommet de chacune des quatre paraboles.
2. $\mathcal{P}_B$ représente une fonction $g$. Préciser la translation qui transforme $\mathcal{P}_A$ en $\mathcal{P}_B$, puis donner $g(x)$.
3. $\mathcal{P}_C$ représente une fonction $h$. Préciser la translation, puis donner $h(x)$ en fonction de $f$.
4. $\mathcal{P}_D$ représente une fonction $p$. Préciser la translation, puis donner $p(x)$ sous forme canonique.
5. Développer $h(x)$ et $p(x)$, puis vérifier les valeurs $h(0)$ et $p(0)$ sur le graphique.
6. Sans tracer, donner le sommet de la parabole d’équation $y = (x - 3)^2 - 1$ et la translation qui la déduit de $\mathcal{P}_A$.

Étapes:

<!-- optitab:1 -->
## Question 1 : Lire les sommets

::: methode
Le sommet est le point le plus bas de chaque parabole (ici, toutes sont tournées vers le haut).
:::

::: resultat
$\mathcal{P}_A$ : $(0\,;0)$ ; $\mathcal{P}_B$ : $(0\,;-3)$ ; $\mathcal{P}_C$ : $(2\,;0)$ ; $\mathcal{P}_D$ : $(-1\,;2)$.
:::

## Question 2 : Parabole $\mathcal{P}_B$

::: methode
Le sommet passe de $(0\,;0)$ à $(0\,;-3)$ : on lit le vecteur de la translation.
:::

::: etape Translation
Translation de vecteur $\vec{u}\begin{pmatrix} 0 \\ -3 \end{pmatrix}$ : chaque point descend de $3$ unités, donc chaque ordonnée diminue de $3$.
:::

::: resultat
$g(x) = x^2 - 3$.
:::

## Question 3 : Parabole $\mathcal{P}_C$

::: methode
Le sommet passe de $(0\,;0)$ à $(2\,;0)$ : décalage horizontal de $2$ vers la droite.
:::

::: etape Translation
Translation de vecteur $\vec{u}\begin{pmatrix} 2 \\ 0 \end{pmatrix}$. Le point d’abscisse $x$ de $\mathcal{P}_C$ a la même ordonnée que le point d’abscisse $x - 2$ de $\mathcal{P}_A$ : $h(x) = f(x - 2)$.
:::

::: resultat
$h(x) = f(x - 2) = (x - 2)^2$.
:::

::: attention
Un décalage vers la **droite** de $2$ unités donne $(x - 2)^2$, avec un signe « $-$ » : $(x + 2)^2$ correspondrait à un décalage vers la gauche.
:::

## Question 4 : Parabole $\mathcal{P}_D$

::: methode
Le sommet passe de $(0\,;0)$ à $(-1\,;2)$ ; une parabole de sommet $(\alpha\,;\beta)$ obtenue par translation de $y = x^2$ a pour équation $y = (x - \alpha)^2 + \beta$.
:::

::: etape Translation
Translation de vecteur $\vec{u}\begin{pmatrix} -1 \\ 2 \end{pmatrix}$ : $1$ unité vers la gauche et $2$ vers le haut. Avec $\alpha = -1$ et $\beta = 2$ : $p(x) = (x - (-1))^2 + 2$.
:::

::: resultat
$p(x) = (x + 1)^2 + 2$.
:::

## Question 5 : Formes développées et contrôle

::: methode
Développer avec les identités remarquables, puis calculer l’image de $0$ (le terme constant).
:::

::: etape Développer
$$
\begin{aligned}
h(x) &= (x - 2)^2 = x^2 - 4x + 4 \\
p(x) &= (x + 1)^2 + 2 = x^2 + 2x + 3
\end{aligned}
$$
:::

::: etape Contrôler sur le graphique
$h(0) = 4$ : $\mathcal{P}_C$ coupe l’axe des ordonnées au point $(0\,;4)$. $p(0) = 3$ : $\mathcal{P}_D$ coupe l’axe des ordonnées au point $(0\,;3)$. Les lectures concordent.
:::

::: resultat
$h(x) = x^2 - 4x + 4$, $h(0) = 4$ ; $p(x) = x^2 + 2x + 3$, $p(0) = 3$.
:::

## Question 6 : Parabole $y = (x - 3)^2 - 1$

::: methode
Forme canonique $(x - \alpha)^2 + \beta$ : on lit $\alpha$ et $\beta$.
:::

::: resultat
Sommet $(3\,;-1)$ ; translation de vecteur $\vec{u}\begin{pmatrix} 3 \\ -1 \end{pmatrix}$ ($3$ vers la droite, $1$ vers le bas).
:::

::: retenir
La parabole $y = (x - \alpha)^2 + \beta$ se déduit de $y = x^2$ par la translation de vecteur $\vec{u}\begin{pmatrix} \alpha \\ \beta \end{pmatrix}$ ; son sommet est $(\alpha\,;\beta)$.
:::

Solution:
<!-- optitab:1 -->
1. Sommets : $(0\,;0)$, $(0\,;-3)$, $(2\,;0)$, $(-1\,;2)$.
2. Translation de vecteur $(0\,;-3)$ ; $g(x) = x^2 - 3$.
3. Translation de vecteur $(2\,;0)$ ; $h(x) = f(x - 2) = (x - 2)^2$.
4. Translation de vecteur $(-1\,;2)$ ; $p(x) = (x + 1)^2 + 2$.
5. $h(x) = x^2 - 4x + 4$ et $h(0) = 4$ ; $p(x) = x^2 + 2x + 3$ et $p(0) = 3$.
6. Sommet $(3\,;-1)$ ; translation de vecteur $(3\,;-1)$.

=== Entraînement - Polynômes du second degré - Synthèse avancée
Id: 1322
Difficulté: hard

Énoncé: <!-- optitab:1 -->
1. On considère $f(x) = -2x^2 + 12x - 16$.
   - a) Calculer le discriminant et déterminer les racines de $f$.
   - b) Écrire $f(x)$ sous forme factorisée, puis sous forme canonique.
   - c) Donner le maximum de $f$ et la valeur de $x$ où il est atteint.
   - d) Résoudre $f(x) \gt 0$.
2. Déterminer la fonction polynôme du second degré $f$ telle que $f(2) = 0$, $f(3) = 0$ et $f(0) = 6$.
3. Pour tout réel $m$, on pose $P_m(x) = x^2 - (m + 1)x + m$.
   - a) Calculer le discriminant de $P_m$ et l’écrire comme un carré.
   - b) Pour quelle valeur de $m$ le trinôme a-t-il une racine double ?
   - c) Justifier que $P_m$ a toujours au moins une racine réelle.
4. Résoudre le système $\begin{cases} x + y = 8 \\ x^2 + y^2 = 34 \end{cases}$
5. Un triangle rectangle a un périmètre de $24$ cm et une aire de $24$ cm². Déterminer les longueurs de ses côtés.

Étapes:

<!-- optitab:1 -->
## Question 1 : Étude de $f(x) = -2x^2 + 12x - 16$

::: methode
$a = -2$, $b = 12$, $c = -16$ : discriminant, racines, puis les deux autres formes.
:::

::: etape a) Discriminant et racines
$$
\begin{aligned}
\Delta &= 12^2 - 4 \times (-2) \times (-16) \\
&= 144 - 128 = 16
\end{aligned}
$$

$$x_1 = \frac{-12 + 4}{-4} = 2$$

$$x_2 = \frac{-12 - 4}{-4} = 4$$
:::

::: etape b) Forme factorisée et forme canonique
$f(x) = -2(x - 2)(x - 4)$. Puis $\alpha = -\dfrac{12}{2 \times (-2)} = 3$ (milieu des racines) et $\beta = f(3) = -18 + 36 - 16 = 2$, donc $f(x) = -2(x - 3)^2 + 2$.
:::

::: etape c) Maximum
$a = -2 \lt 0$ : $f$ admet un maximum $\beta = 2$, atteint en $\alpha = 3$.
:::

::: tableau Signe de $f(x)$ ($a \lt 0$)
x : -\infty, 2, 4, +\infty
f(x) : , -, z, +, z, -,
:::

::: resultat
Racines $2$ et $4$ ; $f(x) = -2(x - 2)(x - 4) = -2(x - 3)^2 + 2$ ; maximum $2$ en $x = 3$ ; $f(x) \gt 0 \iff x \in {]2\,;4[}$.
:::

## Question 2 : Trinôme connaissant ses racines

::: methode
Un trinôme qui s’annule en $2$ et en $3$ s’écrit $f(x) = a(x - 2)(x - 3)$ avec $a \neq 0$ ; la condition $f(0) = 6$ donne $a$.
:::

::: etape Trouver $a$
$f(0) = a \times (-2) \times (-3) = 6a$, donc $6a = 6$ et $a = 1$.
:::

::: resultat
$f(x) = (x - 2)(x - 3) = x^2 - 5x + 6$.
:::

## Question 3 : Trinôme à paramètre

::: methode
$a = 1$, $b = -(m + 1)$, $c = m$ : calculer $\Delta_m$ et reconnaître une identité remarquable.
:::

::: etape a) Discriminant
$$
\begin{aligned}
\Delta_m &= (m + 1)^2 - 4m \\
&= m^2 - 2m + 1 = (m - 1)^2
\end{aligned}
$$
:::

::: etape b) Racine double
$\Delta_m = 0 \iff m = 1$ ; alors $P_1(x) = x^2 - 2x + 1 = (x - 1)^2$, racine double $1$.
:::

::: etape c) Toujours une racine
Un carré est positif : $\Delta_m \ge 0$ pour tout $m$. De plus $P_m(1) = 1 - (m + 1) + m = 0$ : $1$ est toujours racine, et l’autre est $m$ (produit des racines égal à $m$).
:::

::: resultat
$\Delta_m = (m - 1)^2$ ; racine double pour $m = 1$ ; pour tout $m$, $P_m(x) = (x - 1)(x - m)$ a au moins la racine $1$.
:::

## Question 4 : Système somme et carrés

::: methode
Calculer le produit $xy$ à partir de $(x + y)^2 = x^2 + y^2 + 2xy$, puis utiliser la somme et le produit.
:::

::: etape Calculer le produit
$64 = 34 + 2xy$, donc $xy = 15$.
:::

::: etape Trinôme associé
$x$ et $y$ ont pour somme $8$ et pour produit $15$ : ce sont les racines de $X^2 - 8X + 15$. $\Delta = 64 - 60 = 4$, d’où $X = \dfrac{8 \pm 2}{2}$, soit $3$ ou $5$.
:::

::: resultat
$(x\,;y) = (3\,;5)$ ou $(5\,;3)$.
:::

## Question 5 : Triangle rectangle

::: methode
Notons $a$ et $b$ les côtés de l’angle droit et $c$ l’hypoténuse : $a + b + c = 24$, $\dfrac{ab}{2} = 24$ et $a^2 + b^2 = c^2$ (Pythagore).
:::

::: etape Calculer l’hypoténuse
$ab = 48$ et $a + b = 24 - c$. Or $(a + b)^2 = a^2 + b^2 + 2ab = c^2 + 96$, donc

$$
\begin{aligned}
(24 - c)^2 &= c^2 + 96 \\
576 - 48c &= 96 \\
c &= 10
\end{aligned}
$$
:::

::: etape Somme et produit
$a + b = 14$ et $ab = 48$ : $a$ et $b$ sont les racines de $X^2 - 14X + 48$. $\Delta = 196 - 192 = 4$, d’où $X = \dfrac{14 \pm 2}{2}$, soit $6$ ou $8$.
:::

::: etape Vérifier
$6 + 8 + 10 = 24$, $\dfrac{6 \times 8}{2} = 24$ et $6^2 + 8^2 = 100 = 10^2$.
:::

::: resultat
Les côtés mesurent $6$ cm, $8$ cm et $10$ cm.
:::

Solution:
<!-- optitab:1 -->
1. $\Delta = 16$, racines $2$ et $4$ ; $f(x) = -2(x - 2)(x - 4) = -2(x - 3)^2 + 2$ ; maximum $2$ en $x = 3$ ; $f(x) \gt 0 \iff x \in {]2\,;4[}$.
2. $f(x) = x^2 - 5x + 6$.
3. $\Delta_m = (m - 1)^2$ ; racine double pour $m = 1$ ; $P_m(x) = (x - 1)(x - m)$ admet toujours la racine $1$.
4. $(x\,;y) = (3\,;5)$ ou $(5\,;3)$.
5. $6$ cm, $8$ cm et $10$ cm.

=== Entraînement - Relations entre coefficients et racines d'un polynôme du second degré
Id: 1319
Difficulté: medium

Énoncé: <!-- optitab:1 -->
On rappelle que, si le trinôme $ax^2 + bx + c$ a deux racines $x_1$ et $x_2$, alors $x_1 + x_2 = -\dfrac{b}{a}$ et $x_1x_2 = \dfrac{c}{a}$.

1. Déterminer deux nombres dont la somme vaut $7$ et le produit $12$.
2. On note $x_1$ et $x_2$ les racines de $x^2 - 5x + 6$. Calculer $x_1^2 + x_2^2$ sans calculer les racines.
3. Déterminer tous les trinômes dont les racines sont $2$ et $-3$.
4. On note $x_1$ et $x_2$ les racines de $2x^2 + 8x + 6$. Calculer $\dfrac{1}{x_1} + \dfrac{1}{x_2}$ sans calculer les racines.
5. Déterminer les valeurs de $m$ pour lesquelles $x^2 - mx + 9$ a une racine double, et donner cette racine.
6. Vérifier que $1$ est racine de $5x^2 - 3x - 2$, puis en déduire l’autre racine sans calculer $\Delta$.

Étapes:

<!-- optitab:1 -->
## Question 1 : Somme $7$ et produit $12$

::: methode
Deux nombres de somme $S$ et de produit $P$ sont les racines du trinôme $X^2 - SX + P$.
:::

::: etape Trinôme associé
Les nombres cherchés sont les racines de $X^2 - 7X + 12$ : $\Delta = 49 - 48 = 1$, d’où $X = \dfrac{7 \pm 1}{2}$, soit $3$ ou $4$.
:::

::: resultat
Les deux nombres sont $3$ et $4$ ($3 + 4 = 7$ et $3 \times 4 = 12$).
:::

## Question 2 : Calculer $x_1^2 + x_2^2$

::: methode
Exprimer $x_1^2 + x_2^2$ avec la somme $S$ et le produit $P$ : $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2$.
:::

::: etape Somme et produit
$\Delta = 25 - 24 = 1 \gt 0$, donc les racines existent. $S = -\dfrac{-5}{1} = 5$ et $P = \dfrac{6}{1} = 6$.
:::

::: etape Calculer
$$x_1^2 + x_2^2 = S^2 - 2P = 25 - 12 = 13$$
:::

::: resultat
$x_1^2 + x_2^2 = 13$ (contrôle : les racines sont $2$ et $3$, et $4 + 9 = 13$).
:::

## Question 3 : Trinômes de racines $2$ et $-3$

::: methode
Les trinômes qui s’annulent en $2$ et $-3$ sont les fonctions $x \mapsto a(x - 2)(x + 3)$ avec $a \neq 0$.
:::

::: etape Développer pour $a = 1$
$(x - 2)(x + 3) = x^2 + x - 6$.
:::

::: resultat
Les trinômes cherchés sont $a(x - 2)(x + 3) = a(x^2 + x - 6)$ avec $a \neq 0$ ; par exemple $x^2 + x - 6$.
:::

## Question 4 : Calculer $\dfrac{1}{x_1} + \dfrac{1}{x_2}$

::: methode
Réduire au même dénominateur : $\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{x_1 + x_2}{x_1x_2}$.
:::

::: etape Somme et produit
$\Delta = 64 - 48 = 16 \gt 0$. $S = -\dfrac{8}{2} = -4$ et $P = \dfrac{6}{2} = 3$ (non nul, donc aucune racine n’est nulle).
:::

::: resultat
$\dfrac{1}{x_1} + \dfrac{1}{x_2} = \dfrac{S}{P} = -\dfrac{4}{3}$ (contrôle : racines $-1$ et $-3$, et $-1 - \dfrac{1}{3} = -\dfrac{4}{3}$).
:::

## Question 5 : Racine double de $x^2 - mx + 9$

::: methode
Racine double $\iff \Delta = 0$ ; la racine double vaut alors $-\dfrac{b}{2a}$.
:::

::: etape Résoudre $\Delta = 0$
$\Delta = (-m)^2 - 4 \times 1 \times 9 = m^2 - 36$, et $m^2 - 36 = 0 \iff m = 6$ ou $m = -6$.
:::

::: etape Racine double
$x_0 = -\dfrac{-m}{2} = \dfrac{m}{2}$ : $x_0 = 3$ si $m = 6$ (car $x^2 - 6x + 9 = (x - 3)^2$) et $x_0 = -3$ si $m = -6$ (car $x^2 + 6x + 9 = (x + 3)^2$).
:::

::: resultat
$m = 6$ (racine double $3$) ou $m = -6$ (racine double $-3$).
:::

## Question 6 : Racine évidente

::: methode
Vérifier que $1$ annule le trinôme, puis utiliser le produit des racines $x_1x_2 = \dfrac{c}{a}$.
:::

::: etape Vérifier
$5 \times 1^2 - 3 \times 1 - 2 = 0$ : $1$ est racine.
:::

::: etape Autre racine
$1 \times x_2 = \dfrac{c}{a} = -\dfrac{2}{5}$, donc $x_2 = -\dfrac{2}{5}$. Contrôle par la somme : $1 - \dfrac{2}{5} = \dfrac{3}{5} = -\dfrac{b}{a}$.
:::

::: resultat
L’autre racine est $-\dfrac{2}{5}$ et $5x^2 - 3x - 2 = 5(x - 1)\left(x + \dfrac{2}{5}\right) = (x - 1)(5x + 2)$.
:::

Solution:
<!-- optitab:1 -->
1. Les nombres $3$ et $4$.
2. $x_1^2 + x_2^2 = 13$.
3. $a(x - 2)(x + 3) = a(x^2 + x - 6)$ avec $a \neq 0$, par exemple $x^2 + x - 6$.
4. $\dfrac{1}{x_1} + \dfrac{1}{x_2} = -\dfrac{4}{3}$.
5. $m = 6$ (racine double $3$) ou $m = -6$ (racine double $-3$).
6. L’autre racine est $-\dfrac{2}{5}$.

=== Entraînement - Résolution d'équations du second degré par la méthode du discriminant
Id: 1315
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les équations suivantes.

1. $x^2 - 7x + 12 = 0$
2. $2x^2 - 8x + 8 = 0$
3. $x^2 + 2x + 5 = 0$
4. $3x^2 - 12x + 9 = 0$
5. $-x^2 + 6x - 9 = 0$
6. $2x^2 + x - 6 = 0$
7. $x^2 = 5x$

Étapes:

<!-- optitab:1 -->
## Question 1 : $x^2 - 7x + 12 = 0$

::: methode
Calculer $\Delta = b^2 - 4ac$, puis appliquer les formules selon son signe.
:::

::: etape Discriminant
$a = 1$, $b = -7$, $c = 12$ : $\Delta = 49 - 48 = 1$, $\sqrt{\Delta} = 1$.
:::

::: etape Solutions
$$x_1 = \frac{7 - 1}{2} = 3$$

$$x_2 = \frac{7 + 1}{2} = 4$$
:::

::: resultat
$\mathcal{S} = \{3\,;4\}$.
:::

## Question 2 : $2x^2 - 8x + 8 = 0$

::: methode
Même méthode (on pourrait aussi diviser par $2$ et reconnaître $(x - 2)^2$).
:::

::: etape Discriminant
$\Delta = 64 - 4 \times 2 \times 8 = 64 - 64 = 0$.
:::

::: etape Solution
$x_0 = -\dfrac{b}{2a} = \dfrac{8}{4} = 2$. Contrôle : $2x^2 - 8x + 8 = 2(x - 2)^2$.
:::

::: resultat
$\mathcal{S} = \{2\}$.
:::

## Question 3 : $x^2 + 2x + 5 = 0$

::: methode
Calcul de $\Delta$.
:::

::: etape Discriminant
$\Delta = 4 - 20 = -16 \lt 0$.
:::

::: resultat
$\mathcal{S} = \varnothing$ (aucune solution réelle).
:::

## Question 4 : $3x^2 - 12x + 9 = 0$

::: methode
Calcul de $\Delta$ avec $a = 3$, $b = -12$, $c = 9$.
:::

::: etape Discriminant
$\Delta = 144 - 108 = 36$, $\sqrt{\Delta} = 6$.
:::

::: etape Solutions
$$x_1 = \frac{12 - 6}{6} = 1$$

$$x_2 = \frac{12 + 6}{6} = 3$$
:::

::: resultat
$\mathcal{S} = \{1\,;3\}$.
:::

## Question 5 : $-x^2 + 6x - 9 = 0$

::: methode
Calcul de $\Delta$ avec $a = -1$, $b = 6$, $c = -9$.
:::

::: etape Discriminant
$\Delta = 36 - 4 \times (-1) \times (-9) = 36 - 36 = 0$.
:::

::: etape Solution
$x_0 = -\dfrac{6}{2 \times (-1)} = 3$. Contrôle : $-x^2 + 6x - 9 = -(x - 3)^2$.
:::

::: resultat
$\mathcal{S} = \{3\}$.
:::

## Question 6 : $2x^2 + x - 6 = 0$

::: methode
Calcul de $\Delta$ avec $a = 2$, $b = 1$, $c = -6$.
:::

::: etape Discriminant
$\Delta = 1 - 4 \times 2 \times (-6) = 1 + 48 = 49$, $\sqrt{\Delta} = 7$.
:::

::: etape Solutions
$$x_1 = \frac{-1 - 7}{4} = -2$$

$$x_2 = \frac{-1 + 7}{4} = \frac{3}{2}$$
:::

::: resultat
$\mathcal{S} = \left\{-2\,;\dfrac{3}{2}\right\}$.
:::

## Question 7 : $x^2 = 5x$

::: methode
Pas besoin de $\Delta$ : tout passer dans un membre et factoriser par $x$.
:::

::: etape Factoriser
$$x^2 = 5x \iff x^2 - 5x = 0 \iff x(x - 5) = 0$$
:::

::: etape Produit nul
$x = 0$ ou $x - 5 = 0$.
:::

::: resultat
$\mathcal{S} = \{0\,;5\}$.
:::

::: attention
Diviser les deux membres par $x$ fait perdre la solution $x = 0$ : on factorise, on ne divise pas par une inconnue.
:::

Solution:
<!-- optitab:1 -->
1. $\mathcal{S} = \{3\,;4\}$.
2. $\mathcal{S} = \{2\}$.
3. $\mathcal{S} = \varnothing$.
4. $\mathcal{S} = \{1\,;3\}$.
5. $\mathcal{S} = \{3\}$.
6. $\mathcal{S} = \left\{-2\,;\dfrac{3}{2}\right\}$.
7. $\mathcal{S} = \{0\,;5\}$.

=== Entraînement - Synthèse complète : maîtrise des polynômes du second degré
Id: 1321
Difficulté: hard

Énoncé: <!-- optitab:1 -->
1. On considère $f(x) = 2x^2 - 8x + 6$.
   - a) Donner les coefficients $a$, $b$, $c$ et calculer le discriminant.
   - b) Déterminer les racines et la forme factorisée.
   - c) Déterminer la forme canonique et le sommet de la parabole.
   - d) Étudier le signe de $f(x)$, puis résoudre $f(x) \lt 0$.
2. Résoudre le système $\begin{cases} x + y = 5 \\ xy = 6 \end{cases}$
3. Écrire sous forme développée le trinôme $g(x) = 3(x - 2)^2 - 12$, puis en déduire ses racines.
4. Pour quelles valeurs de $k$ le trinôme $x^2 + kx + 4$ a-t-il une racine double ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Étude de $f(x) = 2x^2 - 8x + 6$

::: methode
Discriminant, racines, puis forme canonique et règle du signe.
:::

::: etape a) Coefficients et discriminant
$a = 2$, $b = -8$, $c = 6$ ; $\Delta = 64 - 48 = 16$.
:::

::: etape b) Racines et forme factorisée
$x_1 = \dfrac{8 - 4}{4} = 1$ et $x_2 = \dfrac{8 + 4}{4} = 3$, donc $f(x) = 2(x - 1)(x - 3)$.
:::

::: etape c) Forme canonique
$\alpha = \dfrac{8}{4} = 2$ et $\beta = f(2) = 8 - 16 + 6 = -2$ : $f(x) = 2(x - 2)^2 - 2$, sommet $S(2\,;-2)$.
:::

::: tableau Signe de $f(x)$ ($a = 2 \gt 0$)
x : -\infty, 1, 3, +\infty
f(x) : , +, z, -, z, +,
:::

::: resultat
$\Delta = 16$ ; $f(x) = 2(x - 1)(x - 3) = 2(x - 2)^2 - 2$ ; $S(2\,;-2)$ ; $f(x) \lt 0 \iff x \in {]1\,;3[}$.
:::

## Question 2 : Système somme-produit

::: methode
$x$ et $y$ ont pour somme $5$ et pour produit $6$ : ce sont les racines de $X^2 - 5X + 6$.
:::

::: etape Résoudre
$\Delta = 25 - 24 = 1$, d’où $X = \dfrac{5 \pm 1}{2}$, soit $2$ ou $3$.
:::

::: resultat
$(x\,;y) = (2\,;3)$ ou $(3\,;2)$.
:::

## Question 3 : Développer $g(x) = 3(x - 2)^2 - 12$

::: methode
Développer le carré, puis multiplier par $3$ ; pour les racines, factoriser la forme développée.
:::

::: etape Développer
$$
\begin{aligned}
g(x) &= 3(x^2 - 4x + 4) - 12 \\
&= 3x^2 - 12x
\end{aligned}
$$
:::

::: etape Racines
$g(x) = 3x(x - 4)$, donc $g(x) = 0 \iff x = 0$ ou $x = 4$.
:::

::: resultat
$g(x) = 3x^2 - 12x$ ; racines $0$ et $4$.
:::

## Question 4 : Racine double de $x^2 + kx + 4$

::: methode
Racine double $\iff \Delta = 0$.
:::

::: etape Résoudre
$\Delta = k^2 - 16 = 0 \iff k = 4$ ou $k = -4$.
:::

::: resultat
$k = 4$ (racine double $-2$) ou $k = -4$ (racine double $2$).
:::

Solution:
<!-- optitab:1 -->
1. $\Delta = 16$ ; racines $1$ et $3$ ; $f(x) = 2(x - 1)(x - 3) = 2(x - 2)^2 - 2$ ; $S(2\,;-2)$ ; $f(x) \lt 0 \iff x \in {]1\,;3[}$.
2. $(x\,;y) = (2\,;3)$ ou $(3\,;2)$.
3. $g(x) = 3x^2 - 12x$ ; racines $0$ et $4$.
4. $k = 4$ ou $k = -4$.

=== Problème - Optimisation et applications concrètes des polynômes du second degré
Id: 1320
Difficulté: hard

Énoncé: <!-- optitab:1 -->
1. Un rectangle a un périmètre de $20$ cm. On note $x$ la longueur d’un de ses côtés. Déterminer les dimensions qui rendent son aire maximale.
2. La hauteur (en mètres) d’un projectile à l’instant $t$ (en secondes) est $h(t) = -5t^2 + 20t + 10$. Quelle est la hauteur maximale atteinte, et à quel instant ?
3. Un théâtre vend ses places $20$ € et accueille alors $300$ spectateurs. Une étude montre que chaque baisse de $1$ € du prix attire $25$ spectateurs de plus. On note $x$ le montant de la baisse, en euros ($0 \le x \le 20$).
   - a) Montrer que la recette (en euros) est $R(x) = -25x^2 + 200x + 6\,000$.
   - b) Quel prix de la place rend la recette maximale ? Quelle est cette recette ?
4. Un jardin rectangulaire a une aire de $24$ m². Si l’on augmente sa longueur de $2$ m et sa largeur de $1$ m, son aire devient $40$ m². Déterminer les dimensions initiales du jardin.

Étapes:

<!-- optitab:1 -->
## Question 1 : Rectangle de périmètre $20$ cm

::: methode
Exprimer l’autre côté puis l’aire en fonction de $x$, et chercher le sommet de la parabole.
:::

::: etape Mettre en équation
Le demi-périmètre vaut $10$ : l’autre côté mesure $10 - x$, avec $0 \lt x \lt 10$. L’aire est

$$\mathcal{A}(x) = x(10 - x) = -x^2 + 10x$$
:::

::: etape Forme canonique
$\alpha = -\dfrac{10}{2 \times (-1)} = 5$ et $\mathcal{A}(5) = 25$ : $\mathcal{A}(x) = -(x - 5)^2 + 25 \le 25$.
:::

::: resultat
L’aire est maximale pour $x = 5$ : le rectangle est un carré de $5$ cm de côté, d’aire $25$ cm².
:::

## Question 2 : Hauteur maximale du projectile

::: methode
$a = -5 \lt 0$ : la hauteur maximale est l’ordonnée du sommet.
:::

::: etape Calculer
$$
\begin{aligned}
\alpha &= -\frac{20}{2 \times (-5)} = 2 \\
h(2) &= -20 + 40 + 10 = 30
\end{aligned}
$$
:::

::: resultat
Hauteur maximale $30$ m, atteinte à $t = 2$ s.
:::

## Question 3 : Recette du théâtre

::: methode
Recette = prix d’une place $\times$ nombre de spectateurs, puis recherche du maximum.
:::

::: etape a) Expression de la recette
Après une baisse de $x$ euros, la place coûte $20 - x$ euros et le théâtre accueille $300 + 25x$ spectateurs :

$$
\begin{aligned}
R(x) &= (20 - x)(300 + 25x) \\
&= 6\,000 + 500x - 300x - 25x^2 \\
&= -25x^2 + 200x + 6\,000
\end{aligned}
$$
:::

::: etape b) Maximum
$a = -25 \lt 0$ : maximum en $\alpha = -\dfrac{200}{2 \times (-25)} = 4$, qui appartient à $[0\,;20]$.

$R(4) = 16 \times 400 = 6\,400$.
:::

::: resultat
Avec une baisse de $4$ €, soit une place à $16$ €, la recette est maximale : $6\,400$ € ($400$ spectateurs).
:::

## Question 4 : Dimensions du jardin

::: methode
Écrire deux équations, exprimer une inconnue en fonction de l’autre, et se ramener à une équation du second degré.
:::

::: etape Mettre en équation
Notons $L$ la longueur et $\ell$ la largeur (en mètres) : $L\ell = 24$ et $(L + 2)(\ell + 1) = 40$.

En développant : $L\ell + L + 2\ell + 2 = 40$, donc $24 + L + 2\ell + 2 = 40$, soit $L = 14 - 2\ell$.
:::

::: etape Équation du second degré
En remplaçant $L$ par $14 - 2\ell$ dans $L\ell = 24$, on obtient successivement les équations équivalentes :

$$
\begin{aligned}
(14 - 2\ell)\ell &= 24 \\
2\ell^2 - 14\ell + 24 &= 0 \\
\ell^2 - 7\ell + 12 &= 0
\end{aligned}
$$

$\Delta = 49 - 48 = 1$, d’où $\ell = 3$ ou $\ell = 4$.
:::

::: etape Conclure et vérifier
- $\ell = 3$ : $L = 8$ ; $8 \times 3 = 24$ et $10 \times 4 = 40$.
- $\ell = 4$ : $L = 6$ ; $6 \times 4 = 24$ et $8 \times 5 = 40$.
:::

::: resultat
Deux jardins conviennent : $8$ m sur $3$ m, ou $6$ m sur $4$ m.
:::

Solution:
<!-- optitab:1 -->
1. Carré de $5$ cm de côté (aire maximale $25$ cm²).
2. Hauteur maximale $30$ m à $t = 2$ s.
3. a) $R(x) = (20 - x)(300 + 25x) = -25x^2 + 200x + 6\,000$. b) Place à $16$ € ; recette maximale $6\,400$ €.
4. $8$ m sur $3$ m, ou $6$ m sur $4$ m.

=== Problème - Parabole et droite : intersections et position relative
Id: 4285
Difficulté: medium
Image: v1_n154_ex4285_1_parabole_droite.png

Énoncé: <!-- optitab:1 -->
Dans un repère, on considère la parabole $\mathcal{P}$ d’équation $y = x^2 - 2x - 1$ et la droite $\mathcal{D}$ d’équation $y = x + 3$.

1. Déterminer les coordonnées des points d’intersection $A$ et $B$ de $\mathcal{P}$ et $\mathcal{D}$ (on notera $A$ celui d’abscisse la plus petite).
2. Étudier la position relative de $\mathcal{P}$ et $\mathcal{D}$.
3. Pour tout réel $m$, on note $\mathcal{D}_m$ la droite d’équation $y = 2x + m$.
   - a) Montrer que les abscisses des points communs à $\mathcal{P}$ et $\mathcal{D}_m$ sont les solutions de $x^2 - 4x - 1 - m = 0$.
   - b) Selon les valeurs de $m$, déterminer le nombre de points communs à $\mathcal{P}$ et $\mathcal{D}_m$.
   - c) Pour la valeur de $m$ où il y a un seul point commun, donner ses coordonnées.

Étapes:

<!-- optitab:1 -->
## Question 1 : Points d’intersection

::: methode
Un point commun a ses coordonnées qui vérifient les deux équations : on résout $x^2 - 2x - 1 = x + 3$.
:::

::: etape Équation du second degré
$$x^2 - 2x - 1 = x + 3 \iff x^2 - 3x - 4 = 0$$
:::

::: etape Résoudre
$\Delta = 9 + 16 = 25$ : $x = \dfrac{3 \pm 5}{2}$, soit $-1$ ou $4$.
:::

::: etape Ordonnées
On les calcule avec l’équation de la droite (plus simple) : pour $x = -1$, $y = 2$ ; pour $x = 4$, $y = 7$.
:::

::: resultat
$A(-1\,;2)$ et $B(4\,;7)$.
:::

## Question 2 : Position relative

::: methode
Étudier le signe de la différence $d(x) = (x^2 - 2x - 1) - (x + 3)$ : si $d(x) \gt 0$, la parabole est au-dessus de la droite.
:::

::: etape Factoriser la différence
$d(x) = x^2 - 3x - 4 = (x + 1)(x - 4)$, de coefficient $1 \gt 0$.
:::

::: tableau Signe de $d(x) = (x + 1)(x - 4)$
x : -\infty, -1, 4, +\infty
d(x) : , +, z, -, z, +,
:::

[IMAGE_1]

::: resultat
$\mathcal{P}$ est au-dessus de $\mathcal{D}$ sur ${]-\infty\,;-1[}$ et sur ${]4\,;+\infty[}$, en dessous sur ${]-1\,;4[}$ (zone colorée), et elles se coupent en $A$ et $B$.
:::

## Question 3 : Droites $\mathcal{D}_m$

::: methode
Même démarche : équation aux abscisses des points communs, puis discussion selon le signe de son discriminant.
:::

::: etape a) Équation
$$x^2 - 2x - 1 = 2x + m \iff x^2 - 4x - 1 - m = 0$$
:::

::: etape b) Discriminant
$$
\begin{aligned}
\Delta_m &= (-4)^2 - 4 \times 1 \times (-1 - m) \\
&= 16 + 4 + 4m = 4m + 20
\end{aligned}
$$

$\Delta_m \gt 0 \iff m \gt -5$ ; $\Delta_m = 0 \iff m = -5$ ; $\Delta_m \lt 0 \iff m \lt -5$.
:::

::: etape c) Cas $m = -5$
L’équation devient $x^2 - 4x + 4 = (x - 2)^2 = 0$, d’où $x = 2$ et $y = 2 \times 2 - 5 = -1$. La droite $\mathcal{D}_{-5}$ touche la parabole en un seul point : elle lui est **tangente**.
:::

::: resultat
Deux points communs si $m \gt -5$ ; un seul si $m = -5$, le point $(2\,;-1)$ ; aucun si $m \lt -5$.
:::

Solution:
<!-- optitab:1 -->
1. $A(-1\,;2)$ et $B(4\,;7)$.
2. $\mathcal{P}$ est au-dessus de $\mathcal{D}$ sur ${]-\infty\,;-1[} \cup {]4\,;+\infty[}$, en dessous sur ${]-1\,;4[}$.
3. a) $x^2 - 4x - 1 - m = 0$. b) $\Delta_m = 4m + 20$ : deux points si $m \gt -5$, un si $m = -5$, aucun si $m \lt -5$. c) Le point $(2\,;-1)$.

=== Problème - Second degré : quatre situations d'optimisation et de mise en équation

Image: v1_n154_ex1323_1_parterre_allee.png,v1_n154_ex1323_2_fenetre.png

Énoncé: <!-- optitab:1 -->
1. Le produit de deux entiers naturels consécutifs vaut $506$. Quels sont ces entiers ?

   - a) Quelle est la hauteur maximale atteinte ?
   - b) À quel instant le projectile retombe-t-il au sol ?
   - c) Pendant combien de temps est-il à plus de $40$ m de hauteur ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Entiers consécutifs

::: methode
Nommer le plus petit entier $n$ : l’autre vaut $n + 1$, et on résout une équation du second degré.
:::

::: etape Mettre en équation
$$n(n + 1) = 506 \iff n^2 + n - 506 = 0$$
:::

::: etape Résoudre
$\Delta = 1 + 4 \times 506 = 2\,025 = 45^2$, d’où $n = \dfrac{-1 + 45}{2} = 22$ ou $n = \dfrac{-1 - 45}{2} = -23$.

$-23$ n’est pas un entier naturel : on garde $n = 22$.
:::

::: resultat
Les entiers sont $22$ et $23$ ($22 \times 23 = 506$).
:::

## Question 2 : Projectile

::: methode
Forme canonique pour le maximum, forme factorisée pour le sol, inéquation pour la durée.
:::

::: etape a) Hauteur maximale
$\alpha = -\dfrac{30}{2 \times (-5)} = 3$ et $h(3) = -45 + 90 = 45$.
:::

::: etape b) Retour au sol
$h(t) = -5t(t - 6) = 0 \iff t = 0$ (lancer) ou $t = 6$.
:::

::: etape c) Au-dessus de $40$ m
$$
\begin{aligned}
h(t) \gt 40 &\iff -5t^2 + 30t - 40 \gt 0 \\
&\iff t^2 - 6t + 8 \lt 0 \\
&\iff (t - 2)(t - 4) \lt 0
\end{aligned}
$$

(division par $-5$ : le sens change). Le trinôme $t^2 - 6t + 8$ est négatif entre ses racines : $t \in {]2\,;4[}$, soit une durée de $2$ s.
:::

::: resultat
Hauteur maximale $45$ m (à $t = 3$ s) ; retour au sol à $t = 6$ s ; plus de $40$ m pendant $2$ s.
:::

## Question 3 : Largeur de l’allée

::: methode
Les dimensions totales sont $8 + 2x$ et $6 + 2x$ (l’allée est des deux côtés).
:::

::: etape Mettre en équation
On obtient successivement les équations équivalentes (la dernière en divisant par $4$) :

$$
\begin{aligned}
(8 + 2x)(6 + 2x) &= 80 \\
4x^2 + 28x + 48 &= 80 \\
x^2 + 7x - 8 &= 0
\end{aligned}
$$
:::

::: etape Résoudre
$1$ est racine évidente ($1 + 7 - 8 = 0$) et le produit des racines vaut $-8$ : l’autre racine est $-8$, impossible pour une largeur.
:::

::: resultat
L’allée mesure $1$ m de large (contrôle : $10 \times 8 = 80$).
:::

::: attention
L’allée borde le parterre des deux côtés : la longueur totale est $8 + 2x$, et non $8 + x$.
:::

## Question 4 : Fenêtre d’aire maximale

::: methode
Le demi-cercle a pour rayon $\dfrac{x}{2}$, donc pour longueur $\dfrac{\pi x}{2}$ et pour aire $\dfrac{\pi x^2}{8}$.
:::

::: etape a) Hauteur
Pourtour : $x + 2h + \dfrac{\pi x}{2} = 6$, donc

$$h = 3 - \frac{x}{2} - \frac{\pi x}{4}$$
:::

::: etape b) Aire
$$
\begin{aligned}
\mathcal{A}(x) &= xh + \frac{\pi x^2}{8} \\
&= 3x - \frac{x^2}{2} - \frac{\pi x^2}{4} + \frac{\pi x^2}{8} \\
&= 3x - \frac{4 + \pi}{8}x^2
\end{aligned}
$$
:::

::: etape c) Maximum
Trinôme avec $a = -\dfrac{4 + \pi}{8} \lt 0$ et $b = 3$ : maximum en

$$\alpha = -\frac{3}{2a} = \frac{12}{4 + \pi} \approx 1{,}68$$

Alors $\mathcal{A}(\alpha) = 3\alpha - \dfrac{4 + \pi}{8}\alpha^2 = \dfrac{36}{4 + \pi} - \dfrac{18}{4 + \pi} = \dfrac{18}{4 + \pi} \approx 2{,}52$, et $h = \dfrac{6}{4 + \pi} \approx 0{,}84 \gt 0$.
:::

::: resultat
Aire maximale $\dfrac{18}{4 + \pi} \approx 2{,}52$ m² pour $x = \dfrac{12}{4 + \pi} \approx 1{,}68$ m (et $h \approx 0{,}84$ m).
:::

3. $x = 1$ m.

:::

::: resultat
L’autre côté mesure $12 - x$, avec $0 \lt x \lt 12$.
:::

## Question 2.2 : Aire et forme canonique

::: methode
Aire $= x(12 - x)$, puis $\alpha = -\dfrac{b}{2a}$.
:::

::: etape Calculer
$\mathcal{A}(x) = x(12 - x) = -x^2 + 12x$ ; $\alpha = 6$ et $\mathcal{A}(6) = 36$.
:::

::: resultat
$\mathcal{A}(x) = -(x - 6)^2 + 36$.
:::

## Question 2.3 : Aire maximale

::: methode
$(x - 6)^2 \ge 0$, donc $\mathcal{A}(x) \le 36$, avec égalité pour $x = 6$.
:::

::: resultat
Le rectangle d’aire maximale est un carré de $6$ cm de côté ; son aire vaut $36$ cm².
:::

## Partie 3 : Trinôme à paramètre

## Question 3.1 : Discriminant

::: methode
Coefficients : $1$, $-2m$ et $m + 2$.
:::

::: etape Calculer
$$
\begin{aligned}
\Delta_m &= (-2m)^2 - 4(m + 2) \\
&= 4m^2 - 4m - 8 \\
&= 4(m^2 - m - 2)
\end{aligned}
$$
:::

::: etape Factoriser $m^2 - m - 2$
$-1$ est racine évidente ($1 + 1 - 2 = 0$) et le produit des racines vaut $-2$, donc l’autre racine est $2$ : $m^2 - m - 2 = (m + 1)(m - 2)$.
:::

::: resultat
$\Delta_m = 4(m + 1)(m - 2)$.
:::

## Question 3.2 : Signe de $\Delta_m$

::: methode
$\Delta_m$ est un trinôme en $m$, de coefficient $4 \gt 0$ et de racines $-1$ et $2$.
:::

::: tableau
m : -\infty, -1, 2, +\infty
\Delta_m : , +, z, -, z, +,
:::

::: resultat
$\Delta_m \gt 0$ pour $m \lt -1$ ou $m \gt 2$ ; $\Delta_m = 0$ pour $m = -1$ ou $m = 2$ ; $\Delta_m \lt 0$ pour $-1 \lt m \lt 2$.
:::

## Question 3.3 : Nombre de racines

::: methode
Lire le signe de $\Delta_m$ ; en cas de racine double, $x_0 = -\dfrac{b}{2a} = m$.
:::

::: etape Racines doubles
- $m = -1$ : $P_{-1}(x) = x^2 + 2x + 1 = (x + 1)^2$, racine double $-1$.
- $m = 2$ : $P_2(x) = x^2 - 4x + 4 = (x - 2)^2$, racine double $2$.
:::

::: resultat
Deux racines si $m \in {]-\infty\,;-1[} \cup {]2\,;+\infty[}$ ; une racine double si $m = -1$ (racine $-1$) ou $m = 2$ (racine $2$) ; aucune racine si $m \in {]-1\,;2[}$.
:::

Solution:
<!-- optitab:1 -->
**Exercice 1.** 1.1 : $\{3\,;5\}$. 1.2 : $[1\,;3]$. 1.3 : $f(x) = (x - 1)(x - 3) = (x - 2)^2 - 1$ ; $f(x) \lt 0$ sur ${]1\,;3[}$, $f(x) \gt 0$ à l’extérieur.

**Exercice 2.** 2.1 : $12 - x$, avec $0 \lt x \lt 12$. 2.2 : $\mathcal{A}(x) = -(x - 6)^2 + 36$. 2.3 : carré de $6$ cm de côté, aire $36$ cm².

**Exercice 3.** 3.1 : $\Delta_m = 4(m + 1)(m - 2)$. 3.2 : $\Delta_m \gt 0$ hors de $[-1\,;2]$, négatif sur ${]-1\,;2[}$. 3.3 : deux racines si $m \lt -1$ ou $m \gt 2$ ; racine double $-1$ (pour $m = -1$) ou $2$ (pour $m = 2$) ; aucune si $-1 \lt m \lt 2$.

=== Type examen - Polynômes du second degré - Type 4
Id: 1330
Difficulté: hard
Image: v1_n154_ex1330_1_enclos_mur.png

Énoncé: <!-- optitab:1 -->
**Partie A — Cours et applications**

**A1.** Énoncer le théorème donnant la forme factorisée d’un trinôme $ax^2 + bx + c$ selon le signe de son discriminant.

**A2.** Soit $f(x) = 2x^2 - 2x - 12$. Calculer le discriminant, déterminer les racines, factoriser $f(x)$ et résoudre $f(x) \lt 0$.

**A3.** Déterminer la fonction polynôme du second degré dont les racines sont $1$ et $4$ et qui vaut $-6$ en $0$.

**Partie B — Étude d’une fonction**

On considère la fonction $g$ définie sur $\mathbb{R}$ par $g(x) = -x^2 + 2x + 3$.

**B1.** Calculer le discriminant de $g$ et déterminer ses racines ; en déduire la forme factorisée.

**B2.** Écrire $g(x)$ sous forme canonique et en déduire le maximum de $g$.

**B3.** Étudier le signe de $g(x)$ et résoudre l’inéquation $g(x) \ge 0$.

**Partie C — Enclos le long d’un mur**

Un jardinier dispose de $28$ m de grillage pour fermer un enclos rectangulaire adossé à un mur (le mur forme un côté). On note $x$ la longueur (en mètres) de chacun des deux côtés perpendiculaires au mur et $y$ celle du côté parallèle au mur.

[IMAGE_1]

**C1.** Exprimer $y$ en fonction de $x$ et montrer que l’aire de l’enclos est $\mathcal{A}(x) = -2x^2 + 28x$, pour $0 \lt x \lt 14$.

**C2.** Écrire $\mathcal{A}(x)$ sous forme canonique.

**C3.** En déduire les dimensions de l’enclos d’aire maximale et cette aire.

Étapes:

<!-- optitab:1 -->
## Partie A : Cours et applications

## Question A1 : Théorème de factorisation

::: methode
Restituer le cours, avec $\Delta = b^2 - 4ac$.
:::

::: resultat
- Si $\Delta \gt 0$ : $ax^2 + bx + c = a(x - x_1)(x - x_2)$, où $x_{1,2} = \dfrac{-b \pm \sqrt{\Delta}}{2a}$.
- Si $\Delta = 0$ : $ax^2 + bx + c = a(x - x_0)^2$, où $x_0 = -\dfrac{b}{2a}$.
- Si $\Delta \lt 0$ : pas de factorisation en produit de facteurs du premier degré.
:::

## Question A2 : Étude de $f(x) = 2x^2 - 2x - 12$

::: methode
$a = 2$, $b = -2$, $c = -12$ : discriminant, racines, puis règle du signe.
:::

::: etape Discriminant et racines
$\Delta = 4 + 96 = 100$, $\sqrt{\Delta} = 10$ :

$$x_1 = \frac{2 - 10}{4} = -2$$

$$x_2 = \frac{2 + 10}{4} = 3$$
:::

::: tableau Signe de $f(x) = 2(x + 2)(x - 3)$
x : -\infty, -2, 3, +\infty
f(x) : , +, z, -, z, +,
:::

::: resultat
$\Delta = 100$ ; racines $-2$ et $3$ ; $f(x) = 2(x + 2)(x - 3)$ ; $f(x) \lt 0 \iff x \in {]-2\,;3[}$.
:::

## Question A3 : Trinôme de racines $1$ et $4$

::: methode
$f(x) = a(x - 1)(x - 4)$ avec $a \neq 0$, puis $f(0) = -6$.
:::

::: etape Trouver $a$
$f(0) = a \times (-1) \times (-4) = 4a$, donc $4a = -6$ et $a = -\dfrac{3}{2}$.
:::

::: etape Développer
$$
\begin{aligned}
f(x) &= -\frac{3}{2}(x^2 - 5x + 4) \\
&= -\frac{3}{2}x^2 + \frac{15}{2}x - 6
\end{aligned}
$$
:::

::: resultat
$f(x) = -\dfrac{3}{2}(x - 1)(x - 4) = -\dfrac{3}{2}x^2 + \dfrac{15}{2}x - 6$.
:::

## Partie B : Étude d’une fonction

## Question B1 : Racines et forme factorisée

::: methode
$a = -1$, $b = 2$, $c = 3$.
:::

::: etape Calculer
$\Delta = 4 + 12 = 16$, $\sqrt{\Delta} = 4$ :

$$x_1 = \frac{-2 + 4}{-2} = -1$$

$$x_2 = \frac{-2 - 4}{-2} = 3$$
:::

::: resultat
Racines $-1$ et $3$ ; $g(x) = -(x + 1)(x - 3)$.
:::

## Question B2 : Forme canonique et maximum

::: methode
$\alpha = -\dfrac{b}{2a}$ (milieu des racines) et $\beta = g(\alpha)$ ; $a \lt 0$ donne un maximum.
:::

::: etape Calculer
$\alpha = -\dfrac{2}{2 \times (-1)} = 1$ et $\beta = g(1) = -1 + 2 + 3 = 4$.
:::

::: resultat
$g(x) = -(x - 1)^2 + 4$ ; le maximum de $g$ vaut $4$, atteint en $x = 1$.
:::

## Question B3 : Signe et inéquation

::: methode
$a = -1 \lt 0$ : positif entre les racines.
:::

::: tableau Signe de $g(x)$
x : -\infty, -1, 3, +\infty
g(x) : , -, z, +, z, -,
:::

::: resultat
$g(x) \ge 0 \iff x \in [-1\,;3]$.
:::

## Partie C : Enclos le long d’un mur

## Question C1 : Mise en équation

::: methode
Le grillage couvre deux côtés de longueur $x$ et un côté de longueur $y$.
:::

::: etape Calculer
$2x + y = 28$, donc $y = 28 - 2x$ ; il faut $x \gt 0$ et $y \gt 0$, soit $0 \lt x \lt 14$. Alors

$$\mathcal{A}(x) = x(28 - 2x) = -2x^2 + 28x$$
:::

::: resultat
$y = 28 - 2x$ et $\mathcal{A}(x) = -2x^2 + 28x$ pour $x \in {]0\,;14[}$.
:::

## Question C2 : Forme canonique

::: methode
$\alpha = -\dfrac{28}{2 \times (-2)} = 7$ et $\beta = \mathcal{A}(7)$.
:::

::: etape Calculer
$\mathcal{A}(7) = -98 + 196 = 98$.
:::

::: resultat
$\mathcal{A}(x) = -2(x - 7)^2 + 98$.
:::

## Question C3 : Enclos d’aire maximale

::: methode
$-2(x - 7)^2 \le 0$, donc $\mathcal{A}(x) \le 98$, avec égalité pour $x = 7$.
:::

::: resultat
Aire maximale $98$ m² pour $x = 7$ m et $y = 28 - 14 = 14$ m.
:::

Solution:
<!-- optitab:1 -->
**Partie A.** A1 : voir le théorème du cours. A2 : $\Delta = 100$, racines $-2$ et $3$, $f(x) = 2(x + 2)(x - 3)$, $f(x) \lt 0 \iff x \in {]-2\,;3[}$. A3 : $f(x) = -\dfrac{3}{2}x^2 + \dfrac{15}{2}x - 6$.

**Partie B.** B1 : $\Delta = 16$, racines $-1$ et $3$, $g(x) = -(x + 1)(x - 3)$. B2 : $g(x) = -(x - 1)^2 + 4$, maximum $4$ en $1$. B3 : $g(x) \ge 0 \iff x \in [-1\,;3]$.

**Partie C.** C1 : $y = 28 - 2x$, $\mathcal{A}(x) = -2x^2 + 28x$. C2 : $\mathcal{A}(x) = -2(x - 7)^2 + 98$. C3 : enclos de $7$ m sur $14$ m, aire $98$ m².
