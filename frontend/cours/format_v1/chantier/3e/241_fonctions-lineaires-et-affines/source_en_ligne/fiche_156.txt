Titre: Résumé : Fonctions linéaires et affines

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les deux familles</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="overflow-x:auto; margin:15px 0;">

<th style="border:1px solid #2b7bb9; padding:10px 12px; text-align:center; vertical-align:middle; background:#3498db; color:#ffffff; font-weight:700;">Forme et graphique</th>

<tr style="background:#f4f8fc;"><td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;"><strong>Linéaire</strong></td><td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">$\displaystyle f(x) = ax$ : droite par l'<strong>origine</strong> (proportionnalité)</td></tr>
<tr style="background:#ffffff;"><td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;"><strong>Affine</strong></td><td style="border:1px solid #b6c8da; padding:10px 12px; text-align:center; vertical-align:middle; color:#2c3e50;">$\displaystyle g(x) = ax + b$ : droite de pente $\displaystyle a$ coupant l'axe des ordonnées en $\displaystyle b$</td></tr>

</div>
[IMAGE_1]
<p style="margin:0;">• $\displaystyle a > 0$ : droite montante ; $\displaystyle a < 0$ : descendante ; $\displaystyle a = 0$ : constante.</p>
<p style="margin:6px 0 0 0;">• $\displaystyle a$ = variation de l'image quand $\displaystyle x$ augmente de 1 ; $\displaystyle b = g(0)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Retrouver une expression</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:420px;">
<p style="margin:0; font-weight:bold;">$\displaystyle a = \frac{y_2 - y_1}{x_2 - x_1}$ puis $\displaystyle b = y_1 - ax_1$</p>
</div>
<p style="margin:0;"><strong>Exemple :</strong> par $\displaystyle (1\ ;\ 5)$ et $\displaystyle (4\ ;\ 11)$ : $\displaystyle a = 2$, $\displaystyle b = 3$, donc $\displaystyle f(x) = 2x + 3$.</p>
<p style="margin:6px 0 0 0;"><strong>Linéaire :</strong> un seul point suffit ($f(6) = 21 \Rightarrow f(x) = 3{,}5x$). <strong>Affine :</strong> il en faut deux.</p>
<p style="margin:6px 0 0 0;"><strong>Droites parallèles</strong> ⟺ même pente.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Comparer deux tarifs</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">① Résoudre l'<strong>égalité</strong> → seuil ; ② tester de part et d'autre ; ③ revenir aux <strong>entiers</strong> si besoin.</p>
<p style="margin:6px 0 0 0;"><strong>Exemple :</strong> $\displaystyle 20 + 3n = 8 + 5n \Rightarrow n = 6$ : avant, l'offre au petit forfait gagne ; après, celle au petit prix unitaire gagne.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Croire qu'une affine est proportionnelle (il faut $b = 0$).</p>
<p style="margin:6px 0 0 0;">2️⃣ Inverser l'ordre dans la pente ($y_2 - y_1$ en haut, $x_2 - x_1$ en bas, dans le même ordre).</p>
<p style="margin:6px 0 0 0;">3️⃣ Erreurs de signe avec des coordonnées négatives : $2 - (-1) = 3$.</p>
<p style="margin:6px 0 0 0;">4️⃣ Appliquer un modèle hors de son domaine (volume négatif, durée non entière…).</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe brevet :</strong> forfait + prix unitaire → affine ; « déterminer la fonction » → pente puis ordonnée à l'origine ; « quelle offre choisir ? » → égalité, puis comparaison de part et d'autre.</p>
</div>
