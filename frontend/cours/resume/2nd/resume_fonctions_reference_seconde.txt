<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Les fonctions à connaître</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Fonction</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Domaine + propriétés</th>
</tr>
</thead>
<tbody>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:14px 16px;">$\displaystyle f(x)=ax+b$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:14px 16px;">Domaine : $\mathbb{R}$ • croissante si $a&gt;0$, décroissante si $a&lt;0$ • droite.</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">$\displaystyle f(x)=x^2$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">Domaine : $\mathbb{R}$ • $f(x)\ge 0$ • paire • décroît sur $]-\infty,0]$ puis croît sur $[0,+\infty[$.</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:14px 16px;">$\displaystyle f(x)=x^3$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:14px 16px;">Domaine : $\mathbb{R}$ • impaire • croissante sur $\mathbb{R}$.</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">$\displaystyle f(x)=\frac{1}{x}$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">Domaine : $\mathbb{R}\setminus\{0\}$ • impaire • décroissante sur $]-\infty,0[$ et sur $]0,+\infty[$.</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; padding:14px 16px;">$\displaystyle f(x)=\sqrt{x}$</td>
<td style="border:none; padding:14px 16px;">Domaine : $[0,+\infty[$ • croissante • $f(x)\ge 0$.</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Équations / inéquations simples (réflexes)</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #9333ea; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(147,51,234,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #9333ea 0%, #7c3aed 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Problème</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Réflexe</th>
</tr>
</thead>
<tbody>
<tr style="background:#f3e8ff;">
<td style="border:none; border-bottom:1px solid #e9d5ff; padding:14px 16px;">$\displaystyle x^2=a$</td>
<td style="border:none; border-bottom:1px solid #e9d5ff; padding:14px 16px;">Si $a&gt;0$ : deux solutions $\pm\sqrt{a}$ ; si $a=0$ : $x=0$ ; si $a&lt;0$ : aucune solution réelle.</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">$\displaystyle \sqrt{x}=a$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:14px 16px;">Impose $a\ge 0$ puis $x=a^2$ (et $x\ge 0$).</td>
</tr>
<tr style="background:#f3e8ff;">
<td style="border:none; padding:14px 16px;">$\displaystyle \frac{1}{x}=a$</td>
<td style="border:none; padding:14px 16px;">Impose $x\ne 0$ ; solution $\displaystyle x=\frac{1}{a}$ si $a\ne 0$.</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Comparer deux courbes (idée clé)</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #f59e0b; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(245,158,11,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #f59e0b 0%, #d97706 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Comparer</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Méthode</th>
</tr>
</thead>
<tbody>
<tr style="background:#fff9e6;">
<td style="border:none; border-bottom:1px solid #fde68a; padding:14px 16px;">$\displaystyle f(x)$ et $\displaystyle g(x)$</td>
<td style="border:none; border-bottom:1px solid #fde68a; padding:14px 16px;">Résoudre $\displaystyle f(x)=g(x)$ pour les points de rencontre, puis regarder qui est au-dessus.</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:14px 16px;">Ex : $\displaystyle x^2$ et $\displaystyle \sqrt{x}$ sur $[0,+\infty[$</td>
<td style="border:none; padding:14px 16px;">Elles se coupent en $\displaystyle x=0$ et $\displaystyle x=1$ ; entre 0 et 1 : $\sqrt{x}&gt;x^2$ ; après 1 : $\displaystyle x^2&gt;\sqrt{x}$.</td>
</tr>
</tbody>
</table>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Erreurs à éviter</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">

<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">❌ Erreur</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">✅ Bon réflexe</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:12px 16px;">Oublier les valeurs interdites</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:12px 16px;">Pour $\displaystyle \frac{1}{x}$ : $\displaystyle x\ne 0$ ; pour $\sqrt{x}$ : $\displaystyle x\ge 0$.</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:12px 16px;">Oublier le “$\pm$” sur un carré</td>
<td style="border:none; padding:12px 16px;">$\displaystyle x^2=a$ (avec $a&gt;0$) donne $\displaystyle x=\pm\sqrt{a}$.</td>
</tr>
</tbody>
</table>
