Titre: Résumé : Racines et Racines n-ièmes

<!-- optitab:1 -->
## I. Définitions fondamentales

| Notation | Définition |
|---|---|
| $\displaystyle \sqrt{a}$ | Nombre positif tel que $\displaystyle (\sqrt{a})^2 = a$ pour $\displaystyle a \geq 0$ |
| $\displaystyle \sqrt[3]{a}$ | Nombre tel que $\displaystyle (\sqrt[3]{a})^3 = a$ pour tout $\displaystyle a \in \mathbb{R}$ |
| $\displaystyle \sqrt[n]{a}$ | $\displaystyle a^{1/n}$ tel que $\displaystyle (\sqrt[n]{a})^n = a$ |
| $\displaystyle \sqrt{a^2}$ | $\displaystyle |a|$ (valeur absolue de $\displaystyle a$) |

::: attention Domaine
Si $n$ est **pair**, $\sqrt[n]{a}$ existe seulement pour $a \geq 0$ • Si $n$ est **impair**, $\sqrt[n]{a}$ existe pour tout réel $a$
:::

## II. Propriétés des racines carrées

| Propriété | Formule | Conditions |
|---|---|---|
| **Racine d'un produit** | $\displaystyle \sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$ | $\displaystyle a \geq 0$, $\displaystyle b \geq 0$ |
| **Racine d'un quotient** | $\displaystyle \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$ | $\displaystyle a \geq 0$, $\displaystyle b > 0$ |
| **Racine d'un carré** | $\displaystyle \sqrt{a^2} = |a|$ | Pour tout $\displaystyle a$ réel |

::: methode
Pour **multiplier** : on met sous une seule racine • Pour **diviser** : on met sous une seule racine • Pour **additionner** : les racines doivent être identiques
:::

## III. Propriétés des racines n-ièmes

| Propriété | Formule | Conditions |
|---|---|---|
| **Racine d'un produit** | $\displaystyle \sqrt[n]{a \times b} = \sqrt[n]{a} \times \sqrt[n]{b}$ | $\displaystyle a \geq 0$, $\displaystyle b \geq 0$ |
| **Racine d'un quotient** | $\displaystyle \sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}}$ | $\displaystyle a \geq 0$, $\displaystyle b > 0$ |
| **Racine d'une puissance** | $\displaystyle \sqrt[n]{a^m} = a^{m/n}$ | $\displaystyle a \geq 0$ |
| **Racine de racine** | $\displaystyle \sqrt[m]{\sqrt[n]{a}} = \sqrt[m \times n]{a}$ | $\displaystyle a \geq 0$ |

::: remarque
Si $n$ est impair, ces propriétés restent valables pour $a$ et $b$ réels (avec $b \neq 0$ pour le quotient).
:::

## IV. Simplification et opérations

| Opération | Formule / Méthode |
|---|---|
| **Simplification** | Décomposer en facteurs premiers et extraire les carrés parfaits <br> Ex: $\displaystyle \sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}$ |
| **Addition/Soustraction** | $\displaystyle a\sqrt{c} + b\sqrt{c} = (a + b)\sqrt{c}$ (racines identiques uniquement) |
| **Multiplication** | $\displaystyle \sqrt{a} \times \sqrt{b} = \sqrt{a \times b}$ <br> Ex: $\displaystyle 2\sqrt{3} \times 5\sqrt{2} = 10\sqrt{6}$ |
| **Division** | $\displaystyle \frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ pour $\displaystyle a \geq 0$, $\displaystyle b > 0$ |

## V. Rationalisation du dénominateur

| Type | Méthode |
|---|---|
| **Dénominateur $\displaystyle \sqrt{a}$** | Multiplier par $\displaystyle \frac{\sqrt{a}}{\sqrt{a}}$ <br> Ex: $\displaystyle \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$ |
| **Dénominateur $\displaystyle a + \sqrt{b}$** | Multiplier par le conjugué $\displaystyle \frac{a - \sqrt{b}}{a - \sqrt{b}}$ <br> Ex: $\displaystyle \frac{1}{\sqrt{3} + 1} = \frac{\sqrt{3} - 1}{2}$ |
| **Identité remarquable** | $\displaystyle (a + \sqrt{b})(a - \sqrt{b}) = a^2 - b$ |

## VI. Racines importantes à connaître

### Racines carrées essentielles

| $\displaystyle \sqrt{1} = 1$ | $\displaystyle \sqrt{4} = 2$ | $\displaystyle \sqrt{9} = 3$ | $\displaystyle \sqrt{16} = 4$ |
| $\displaystyle \sqrt{25} = 5$ | $\displaystyle \sqrt{36} = 6$ | $\displaystyle \sqrt{49} = 7$ | $\displaystyle \sqrt{64} = 8$ |
| $\displaystyle \sqrt{81} = 9$ | $\displaystyle \sqrt{100} = 10$ | $\displaystyle \sqrt{121} = 11$ | $\displaystyle \sqrt{144} = 12$ |

### Racines cubiques essentielles

| $\displaystyle \sqrt[3]{1} = 1$ | $\displaystyle \sqrt[3]{8} = 2$ | $\displaystyle \sqrt[3]{27} = 3$ |
| $\displaystyle \sqrt[3]{64} = 4$ | $\displaystyle \sqrt[3]{125} = 5$ | $\displaystyle \sqrt[3]{216} = 6$ |
| $\displaystyle \sqrt[3]{-8} = -2$ | $\displaystyle \sqrt[3]{-27} = -3$ |  |

## VII. Erreurs fréquentes

| Erreur | Correct |
|---|---|
| $\displaystyle \sqrt{a + b} = \sqrt{a} + \sqrt{b}$ | $\displaystyle \sqrt{a + b}$ ne se simplifie pas ! |
| $\displaystyle \sqrt{x^2} = x$ | $\displaystyle \sqrt{x^2} = |x|$ (valeur absolue) |
| $\displaystyle \sqrt{-4} = -2$ | $\displaystyle \sqrt{-4}$ n'existe pas dans $\displaystyle \mathbb{R}$ |
| $\displaystyle \sqrt{4} = \pm 2$ | $\displaystyle \sqrt{4} = 2$ (toujours positif) |
| $\displaystyle \sqrt[3]{-8}$ n'existe pas | $\displaystyle \sqrt[3]{-8} = -2$ (existe !) |
| $\displaystyle \frac{\sqrt{a}}{\sqrt{b}} = \frac{a}{b}$ | $\displaystyle \frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ |

## VIII. Méthode de simplification

| Étape | Méthode |
|---|---|
| **1** | Décomposer le nombre sous la racine en facteurs premiers |
| **2** | Identifier les carrés parfaits (pour $\displaystyle \sqrt{}$) ou cubes parfaits (pour $\displaystyle \sqrt[3]{}$) |
| **3** | Extraire les carrés (ou cubes) hors de la racine |
| **4** | Simplifier si possible (produit, quotient, addition de termes similaires) |
| **5** | Rationaliser le dénominateur si nécessaire |

### Points clés à retenir

| Notion | À retenir |
|---|---|
| **Domaine** | Racines d'ordre pair : $\displaystyle a \geq 0$ uniquement • Racines d'ordre impair : tout réel |
| **Racine positive** | $\displaystyle \sqrt{a}$ est **toujours** positif ou nul (jamais négatif) |
| **Produit/Quotient** | $\displaystyle \sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$ • $\displaystyle \sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}}$ |
| **Simplification** | Extraire les carrés parfaits : $\displaystyle \sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}$ |
| **Addition** | $\displaystyle a\sqrt{c} + b\sqrt{c} = (a+b)\sqrt{c}$ (racines identiques uniquement !) |
| **Rationalisation** | Multiplier par $\displaystyle \frac{\sqrt{a}}{\sqrt{a}}$ (cas simple) ou par le conjugué (cas complexe) |
| **Lien avec puissances** | $\displaystyle \sqrt[n]{a} = a^{1/n}$ et $\displaystyle \sqrt[n]{a^m} = a^{m/n}$ |
| **Racine cubique** | $\displaystyle \sqrt[3]{a}$ existe même pour $\displaystyle a < 0$ : $\displaystyle \sqrt[3]{-8} = -2$ |
| **ERREUR à éviter** | $\displaystyle \sqrt{a+b} \neq \sqrt{a} + \sqrt{b}$ ! Ne JAMAIS distribuer la racine sur une somme |
