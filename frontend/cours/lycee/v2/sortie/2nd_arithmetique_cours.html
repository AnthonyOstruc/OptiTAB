🎯 Objectifs du chapitre : utiliser les notions de multiple et de diviseur, raisonner sur les nombres pairs et impairs, reconnaître un nombre premier, décomposer un entier en produit de facteurs premiers et l’utiliser pour simplifier une fraction ou résoudre un problème.

I. Multiples et diviseurs

Définition : soient $\displaystyle a$ et $\displaystyle b$ deux entiers relatifs, avec $\displaystyle b \neq 0$. On dit que $\displaystyle a$ est un multiple de $\displaystyle b$, ou que $\displaystyle b$ est un diviseur de $\displaystyle a$, s’il existe un entier $\displaystyle k$ tel que $\displaystyle a = k \times b$.

Exemples : $\displaystyle 36 = 4 \times 9$, donc $\displaystyle 36$ est un multiple de $\displaystyle 4$ et $\displaystyle 4$ est un diviseur de $\displaystyle 36$. Les multiples de $\displaystyle 7$ sont $\displaystyle \ldots, -14, -7, 0, 7, 14, 21, \ldots$

[IMAGE_1]

Propriété (démonstration au programme) : la somme de deux multiples d’un entier $\displaystyle a$ est un multiple de $\displaystyle a$.

Preuve : si $\displaystyle m = k \times a$ et $\displaystyle n = k' \times a$, alors $\displaystyle m + n = (k + k') \times a$, et $\displaystyle k + k'$ est un entier.

💡 Critères de divisibilité : un entier est divisible par $\displaystyle 2$ s’il se termine par $\displaystyle 0, 2, 4, 6$ ou $\displaystyle 8$ ; par $\displaystyle 5$ s’il se termine par $\displaystyle 0$ ou $\displaystyle 5$ ; par $\displaystyle 10$ s’il se termine par $\displaystyle 0$ ; par $\displaystyle 3$ (ou par $\displaystyle 9$) si la somme de ses chiffres est divisible par $\displaystyle 3$ (ou par $\displaystyle 9$). Ainsi $\displaystyle 4\,512$ est divisible par $\displaystyle 3$ car $\displaystyle 4 + 5 + 1 + 2 = 12$.

II. Nombres pairs et impairs

Définition : un entier $\displaystyle n$ est pair s’il s’écrit $\displaystyle n = 2k$, et impair s’il s’écrit $\displaystyle n = 2k + 1$, avec $\displaystyle k$ entier.

Propriété (démonstration au programme) : le carré d’un nombre impair est impair.

Preuve : si $\displaystyle n = 2k + 1$, alors $\displaystyle n^2 = 4k^2 + 4k + 1 = 2(2k^2 + 2k) + 1$, qui est de la forme $\displaystyle 2k' + 1$.

💡 Méthode : pour prouver qu’un résultat est vrai pour tous les entiers, on écrit l’entier sous la forme $\displaystyle 2k$ ou $\displaystyle 2k + 1$ et on calcule. Un exemple ne suffit pas : il ne fait que vérifier un cas.

III. Nombres premiers

Définition : un entier naturel est premier s’il admet exactement deux diviseurs positifs : $\displaystyle 1$ et lui-même.

[IMAGE_2]
⚠️ Attention : $\displaystyle 1$ n’est pas premier (il n’a qu’un seul diviseur) ; $\displaystyle 2$ est le seul nombre premier pair.
💡 Tester si $\displaystyle n$ est premier : il suffit d’essayer de le diviser par les nombres premiers $\displaystyle p$ tels que $\displaystyle p^2 \le n$. Pour $\displaystyle n = 97$ : ni $\displaystyle 2$, ni $\displaystyle 3$, ni $\displaystyle 5$, ni $\displaystyle 7$ ne divisent $\displaystyle 97$, et $\displaystyle 11^2 = 121 \gt 97$ : donc $\displaystyle 97$ est premier.

Propriété (décomposition) : tout entier supérieur ou égal à $\displaystyle 2$ s’écrit comme un produit de nombres premiers, de façon unique à l’ordre près.

IV. Applications

Rendre une fraction irréductible : on décompose le numérateur et le dénominateur, puis on simplifie par les facteurs communs.

$\displaystyle \frac{84}{126} = \frac{2^2 \times 3 \times 7}{2 \times 3^2 \times 7} = \frac{2}{3}$

Résoudre un problème : un fleuriste a $\displaystyle 84$ roses et $\displaystyle 126$ tulipes. Il veut faire le plus grand nombre de bouquets identiques en utilisant toutes les fleurs. Le nombre de bouquets doit diviser $\displaystyle 84$ et $\displaystyle 126$ ; le plus grand diviseur commun est $\displaystyle 2 \times 3 \times 7 = 42$. Il fait donc $\displaystyle 42$ bouquets de $\displaystyle 2$ roses et $\displaystyle 3$ tulipes.

💡 Algorithme : une fonction qui teste si un entier $\displaystyle n \ge 2$ est premier, avec l’opérateur % (reste de la division euclidienne).
def est_premier(n): d = 2 while d * d <= n: if n % d == 0: return False d = d + 1 return True

🏆 L’essentiel : $\displaystyle a$ est un multiple de $\displaystyle b$ si $\displaystyle a = k \times b$ ; la somme de deux multiples de $\displaystyle a$ est un multiple de $\displaystyle a$ ; pair $\displaystyle = 2k$, impair $\displaystyle = 2k + 1$, et le carré d’un impair est impair ; un nombre premier a exactement deux diviseurs ($\displaystyle 1$ n’est pas premier) ; tout entier $\displaystyle \ge 2$ se décompose en facteurs premiers, ce qui permet de simplifier les fractions.
