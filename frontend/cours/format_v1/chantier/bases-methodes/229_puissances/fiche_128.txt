Titre: Résumé : Puissances

<!-- optitab:1 -->
## I. Définitions fondamentales

| Notation | Définition |
|---|---|
| $\displaystyle a^n$ ($\displaystyle n \geq 1$) | $\displaystyle a \times a \times a \times \cdots \times a$ ($\displaystyle n$ fois) |
| $\displaystyle a^0$ | $\displaystyle 1$ (si $\displaystyle a \neq 0$) |
| $\displaystyle a^{-n}$ | $\displaystyle \frac{1}{a^n}$ (si $\displaystyle a \neq 0$) |
| $\displaystyle a^1$ | $\displaystyle a$ |

::: attention
$0^0$ n'est **pas défini** ! Tout nombre non nul élevé à la puissance 0 vaut 1.
:::

## II. Propriétés des puissances

| Propriété | Formule |
|---|---|
| **Produit de puissances (même base)** | $\displaystyle a^m \times a^n = a^{m+n}$ |
| **Quotient de puissances (même base)** | $\displaystyle \frac{a^m}{a^n} = a^{m-n}$ |
| **Puissance de puissance** | $\displaystyle (a^m)^n = a^{m \times n}$ |
| **Puissance d'un produit** | $\displaystyle (a \times b)^n = a^n \times b^n$ |
| **Puissance d'un quotient** | $\displaystyle \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$ |

::: methode
Pour **multiplier** : on additionne les exposants • Pour **diviser** : on soustrait les exposants • Pour une **puissance de puissance** : on multiplie les exposants
:::

## III. Notation scientifique

| Élément | Description |
|---|---|
| **Forme générale** | $\displaystyle a \times 10^n$ avec $\displaystyle 1 \leq a < 10$ et $\displaystyle n \in \mathbb{Z}$ |
| **Grand nombre** | Exposant positif (ex: $\displaystyle 3\,500 = 3{,}5 \times 10^3$) |
| **Petit nombre** | Exposant négatif (ex: $\displaystyle 0{,}0042 = 4{,}2 \times 10^{-3}$) |
| **Produit** | $\displaystyle (a \times 10^m) \times (b \times 10^n) = (a \times b) \times 10^{m+n}$ |
| **Quotient** | $\displaystyle \frac{a \times 10^m}{b \times 10^n} = \frac{a}{b} \times 10^{m-n}$ |

## IV. Signe d'une puissance

| Base | Exposant | Résultat |
|---|---|---|
| Positive | Quelconque | **Positif** |
| Négative | Pair | **Positif** (ex: $\displaystyle (-2)^4 = 16$) |
| Négative | Impair | **Négatif** (ex: $\displaystyle (-2)^3 = -8$) |

::: attention
$-2^4 = -(2^4) = -16$ mais $(-2)^4 = 16$ ! Les parenthèses changent tout.
:::

## V. Préfixes et ordres de grandeur

| Préfixe | Symbole | Puissance de 10 |
|---|---|---|
| Giga | G | $\displaystyle 10^9$ (1 milliard) |
| Méga | M | $\displaystyle 10^6$ (1 million) |
| Kilo | k | $\displaystyle 10^3$ (1 mille) |
| Milli | m | $\displaystyle 10^{-3}$ (1 millième) |
| Micro | μ | $\displaystyle 10^{-6}$ (1 millionième) |
| Nano | n | $\displaystyle 10^{-9}$ (1 milliardième) |

## VI. Erreurs fréquentes

| Erreur | Correct |
|---|---|
| $\displaystyle a^m \times a^n = a^{mn}$ | $\displaystyle a^m \times a^n = a^{m+n}$ |
| $\displaystyle (a^m)^n = a^{m+n}$ | $\displaystyle (a^m)^n = a^{m \times n}$ |
| $\displaystyle (a + b)^n = a^n + b^n$ | Il faut développer ! (sauf cas particuliers) |
| $\displaystyle a^{-n} = -a^n$ | $\displaystyle a^{-n} = \frac{1}{a^n}$ |
| $\displaystyle 2^3 = 6$ | $\displaystyle 2^3 = 8$ (c'est $\displaystyle 2 \times 3 = 6$) |
| $\displaystyle -2^2 = 4$ | $\displaystyle -2^2 = -4$ (c'est $\displaystyle (-2)^2 = 4$) |

## VII. Méthode de calcul

| Étape | Méthode |
|---|---|
| **1** | Identifier les bases et les exposants |
| **2** | Appliquer les propriétés adaptées (produit, quotient, puissance de puissance) |
| **3** | Simplifier les exposants (additionner, soustraire ou multiplier selon le cas) |
| **4** | Calculer le résultat final si possible |
| **5** | Vérifier les signes (attention aux bases négatives) |

### Points clés à retenir

| Notion | À retenir |
|---|---|
| **Définition** | $\displaystyle a^n$ = produit de $\displaystyle n$ facteurs égaux à $\displaystyle a$ ; $\displaystyle a^0 = 1$ ; $\displaystyle a^{-n} = \frac{1}{a^n}$ |
| **Produit** | $\displaystyle a^m \times a^n = a^{m+n}$ (on additionne les exposants) |
| **Quotient** | $\displaystyle \frac{a^m}{a^n} = a^{m-n}$ (on soustrait les exposants) |
| **Puissance de puissance** | $\displaystyle (a^m)^n = a^{m \times n}$ (on multiplie les exposants) |
| **Distribution** | $\displaystyle (ab)^n = a^n b^n$ et $\displaystyle \left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$ |
| **Notation scientifique** | $\displaystyle a \times 10^n$ avec $\displaystyle 1 \leq a < 10$ et $\displaystyle n \in \mathbb{Z}$ |
| **Signes** | Base négative avec exposant pair → positif ; exposant impair → négatif |
| **Attention parenthèses** | $\displaystyle -a^n \neq (-a)^n$ ! Les parenthèses sont essentielles |
