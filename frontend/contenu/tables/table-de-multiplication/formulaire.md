## IV. Astuces pour les retenir {Primaire}

[IMAGE_2]

Multiplier, c’est compter des rangées : $7$ rangées de $8$ points, c’est $7 \times 8 = 56$ points.

| Table | Astuce |
|---|---|
| Table de 1 | le nombre ne change pas : $1 \times 7 = 7$ |
| Table de 2 | on double : $2 \times 8 = 8 + 8 = 16$ |
| Table de 4 | on double deux fois : $4 \times 7 = 14 \times 2 = 28$ |
| Table de 5 | la moitié de la table de 10 ; le résultat finit par $0$ ou $5$ |
| Table de 8 | on double trois fois : $8 \times 6 = 12 \to 24 \to 48$ |
| Table de 9 | pour $9 \times n$, le chiffre des dizaines est $n - 1$ et les deux chiffres ont pour somme $9$ : $9 \times 7 = 63$ |
| Table de 10 | on écrit un $0$ à droite : $10 \times 7 = 70$ |
| Table de 11 (jusqu’à 9) | on répète le chiffre : $11 \times 7 = 77$ |

::: retenir L’ordre ne compte pas
$7 \times 8 = 8 \times 7$ : quand on connaît une table, on connaît déjà une partie des autres. Il suffit d’apprendre la moitié de la table de Pythagore.
:::

::: attention Les résultats les plus souvent oubliés
$6 \times 7 = 42$, $\quad 6 \times 8 = 48$, $\quad 7 \times 7 = 49$, $\quad 7 \times 8 = 56$, $\quad 7 \times 9 = 63$, $\quad 8 \times 8 = 64$, $\quad 8 \times 9 = 72$.

Moyen mnémotechnique : « 5, 6, 7, 8 » donne $56 = 7 \times 8$.
:::
