Titre: Résumé : Fonction Logarithme Népérien

<!-- optitab:1 -->
::: objectifs
Maîtriser la fonction logarithme népérien : définition, propriétés algébriques, dérivée, variations, limites, équations et inéquations.
:::

## I. Définition

::: definition Fonction logarithme népérien
La fonction logarithme népérien, notée $\ln$, est la fonction réciproque de la fonction exponentielle.

Pour tout $x > 0$, $\ln(x)$ est l'unique réel tel que :

::: formule
$$e^{\ln(x)} = x$$
:::

*Pour tout $x \in \mathbb{R}$ : $\ln(e^x) = x$*
:::

| Propriété | Valeur |
|---|---|
| Domaine de définition | $\displaystyle ]0, +\infty[$ |
| Ensemble image | $\displaystyle \mathbb{R}$ |

## II. Propriétés algébriques

::: theoreme
Pour tous réels $x, y > 0$ et tout rationnel $q$ :
:::

| Propriété | Formule |
|---|---|
| Produit | $\displaystyle \ln(xy) = \ln(x) + \ln(y)$ |
| Quotient | $\displaystyle \ln\left(\frac{x}{y}\right) = \ln(x) - \ln(y)$ |
| Puissance | $\displaystyle \ln(x^q) = q \ln(x)$ |
| Valeurs particulières | $\displaystyle \ln(1) = 0$ et $\displaystyle \ln(e) = 1$ |

## III. Dérivée et variations

::: theoreme Dérivée du logarithme népérien
::: formule
$$(\ln(x))' = \frac{1}{x}$$
:::
:::

| Fonction | Dérivée |
|---|---|
| $\displaystyle \ln(x)$ | $\displaystyle \frac{1}{x}$ |
| $\displaystyle \ln(u(x))$ | $\displaystyle \frac{u'(x)}{u(x)}$ |

::: propriete Variations
La fonction logarithme népérien est **strictement croissante** sur $]0, +\infty[$.
:::

## IV. Limites

| Limite | Valeur |
|---|---|
| $\displaystyle \lim_{x \to 0^+} \ln(x)$ | $\displaystyle -\infty$ |
| $\displaystyle \lim_{x \to +\infty} \ln(x)$ | $\displaystyle +\infty$ |
| $\displaystyle \lim_{x \to 0^+} x \ln(x)$ | $\displaystyle 0$ |

## V. Croissance comparée

::: theoreme Croissance comparée
Pour tout entier naturel $\displaystyle n \geq 1$ :
:::

| Limite | Valeur |
|---|---|
| En $\displaystyle +\infty$ | $\displaystyle \lim_{x \to +\infty} \frac{\ln(x)}{x^n} = 0$ |
| En $\displaystyle 0^+$ | $\displaystyle \lim_{x \to 0^+} x^n \ln(x) = 0$ |

*Le logarithme croît moins vite que toute puissance de $x$*

## VI. Équations et inéquations

::: methode Résoudre les équations et inéquations logarithmiques
| Type | Résolution |
|---|---|
| Équation : $\displaystyle \ln(a) = \ln(b)$ | $\displaystyle a = b$ (avec $\displaystyle a, b > 0$) |
| Équation : $\displaystyle \ln(x) = k$ | $\displaystyle x = e^k$ |
| Inéquation : $\displaystyle \ln(a) < \ln(b)$ | $\displaystyle a < b$ (avec $\displaystyle a, b > 0$) |
:::

## VII. Erreurs fréquentes

| Piège fréquent | Correction |
|---|---|
| $\displaystyle \ln(a) + \ln(b) \neq \ln(a + b)$ | C'est $\displaystyle \ln(ab)$ (produit, pas somme) |
| Oublier le numérateur dans la dérivée | $\displaystyle (\ln(u))' = \frac{u'}{u}$, pas $\displaystyle \frac{1}{u}$ |
| Penser que $\displaystyle \ln(x)$ existe pour $\displaystyle x \leq 0$ | Le logarithme n'existe que pour $\displaystyle x > 0$ |
| Oublier que $\displaystyle \ln(1) = 0$ | $\displaystyle \ln(1) = 0$ (et non 1) |

## VIII. Formules essentielles — mémo rapide

| Notion | Formule essentielle |
|---|---|
| Produit | $\displaystyle \ln(xy) = \ln(x) + \ln(y)$ |
| Quotient | $\displaystyle \ln\left(\frac{x}{y}\right) = \ln(x) - \ln(y)$ |
| Puissance | $\displaystyle \ln(x^q) = q \ln(x)$ |
| Dérivée | $\displaystyle (\ln(x))' = \frac{1}{x}$ |
| Relation avec exp | $\displaystyle \ln(e^x) = x$ et $\displaystyle e^{\ln(x)} = x$ |

## IX. Méthodologie — stratégie de résolution

| Type de problème | Méthode recommandée |
|---|---|
| Simplifier une expression | Utiliser $\displaystyle \ln(xy) = \ln(x) + \ln(y)$ et $\displaystyle \ln\left(\frac{x}{y}\right) = \ln(x) - \ln(y)$ |
| Résoudre une équation | Ramener à $\displaystyle \ln(a) = \ln(b)$ ou $\displaystyle \ln(x) = k$ |
| Résoudre une inéquation | Utiliser la croissance : $\displaystyle \ln(a) < \ln(b) \Leftrightarrow a < b$ |
| Dériver une fonction | Pour $\displaystyle \ln(u(x))$ : dérivée = $\displaystyle \frac{u'(x)}{u(x)}$ |
| Calculer une limite | Retenir : $\displaystyle \lim_{x \to 0^+} \ln(x) = -\infty$ et $\displaystyle \lim_{x \to +\infty} \ln(x) = +\infty$ |
