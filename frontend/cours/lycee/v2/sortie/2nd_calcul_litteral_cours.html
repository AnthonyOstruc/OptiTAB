🎯 Objectifs du chapitre : calculer avec des puissances et des racines carrées, développer et factoriser à l’aide des identités remarquables, résoudre des équations et des inéquations, et étudier le signe d’un produit à l’aide d’un tableau de signes.

I. Puissances

Règles de calcul : pour $\displaystyle a \neq 0$, $\displaystyle b \neq 0$ et $\displaystyle n$, $\displaystyle m$ entiers relatifs :

$\displaystyle a^n \times a^m = a^{n+m}$ ; $\displaystyle \frac{a^n}{a^m} = a^{n-m}$ ; $\displaystyle (a^n)^m = a^{n \times m}$ ; $\displaystyle (ab)^n = a^n b^n$ ; $\displaystyle a^{-n} = \frac{1}{a^n}$ ; $\displaystyle a^0 = 1$

Exemple : $\displaystyle \frac{2^5 \times 2^{-2}}{2^4} = 2^{5 - 2 - 4} = 2^{-1} = \frac{1}{2}$.

⚠️ Attention : $\displaystyle (-3)^2 = 9$ mais $\displaystyle -3^2 = -9$ ; et $\displaystyle 2^3 + 2^4$ ne se simplifie pas en $\displaystyle 2^7$ (la règle concerne les produits, pas les sommes).

II. Racines carrées

Définition : pour $\displaystyle a \ge 0$, $\displaystyle \sqrt{a}$ est le nombre positif dont le carré vaut $\displaystyle a$ : $\displaystyle (\sqrt{a})^2 = a$. Par exemple $\displaystyle \sqrt{49} = 7$.

Propriétés (démonstrations au programme) :

• Pour $\displaystyle a \ge 0$ et $\displaystyle b \ge 0$ : $\displaystyle \sqrt{ab} = \sqrt{a} \times \sqrt{b}$. Preuve : $\displaystyle \sqrt{a}\sqrt{b}$ est positif et $\displaystyle (\sqrt{a}\sqrt{b})^2 = (\sqrt{a})^2(\sqrt{b})^2 = ab$ ; c’est donc la racine carrée de $\displaystyle ab$.

• Pour $\displaystyle a \gt 0$ et $\displaystyle b \gt 0$ : $\displaystyle \sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$. Preuve : $\displaystyle (\sqrt{a} + \sqrt{b})^2 = a + b + 2\sqrt{a}\sqrt{b} \gt a + b = (\sqrt{a + b})^2$, et deux nombres positifs sont rangés comme leurs carrés.

Exemple : $\displaystyle \sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$ ; $\displaystyle \sqrt{\frac{9}{16}} = \frac{3}{4}$.

⚠️ Attention : $\displaystyle \sqrt{9 + 16} = \sqrt{25} = 5$ alors que $\displaystyle \sqrt{9} + \sqrt{16} = 7$ : la racine d’une somme n’est pas la somme des racines.

III. Développer et factoriser

Identités remarquables : pour tous réels $\displaystyle a$ et $\displaystyle b$,

$\displaystyle (a + b)^2 = a^2 + 2ab + b^2$ ; $\displaystyle (a - b)^2 = a^2 - 2ab + b^2$ ; $\displaystyle (a + b)(a - b) = a^2 - b^2$
[IMAGE_1]

Développer transforme un produit en somme : $\displaystyle (2x - 3)^2 = 4x^2 - 12x + 9$. Factoriser transforme une somme en produit, avec un facteur commun ou une identité :

$\displaystyle (x + 1)(2x - 5) + (x + 1)(x + 2) = (x + 1)(3x - 3)$ ; $\displaystyle \quad 9x^2 - 25 = (3x - 5)(3x + 5)$
💡 Contrôle : on vérifie une factorisation en redéveloppant, ou en remplaçant $\displaystyle x$ par une valeur simple ($\displaystyle x = 0$, $\displaystyle x = 1$) dans les deux écritures.

IV. Résoudre des équations

• Premier degré : $\displaystyle ax + b = 0$ avec $\displaystyle a \neq 0$ donne $\displaystyle x = -\frac{b}{a}$.

Équation produit nul : un produit est nul si et seulement si l’un de ses facteurs est nul : $\displaystyle A \times B = 0 \iff A = 0$ ou $\displaystyle B = 0$.

Exemple : $\displaystyle (2x - 4)(x + 1) = 0 \iff x = 2$ ou $\displaystyle x = -1$.

Équation $\displaystyle x^2 = a$ : si $\displaystyle a \gt 0$, deux solutions $\displaystyle \sqrt{a}$ et $\displaystyle -\sqrt{a}$ ; si $\displaystyle a = 0$, une solution $\displaystyle 0$ ; si $\displaystyle a \lt 0$, aucune solution.

[IMAGE_2]
💡 Méthode : devant une équation du second degré, on ramène tout d’un même côté, on factorise, puis on applique la règle du produit nul. Exemple : $\displaystyle x^2 = 5x \iff x^2 - 5x = 0 \iff x(x - 5) = 0 \iff x = 0$ ou $\displaystyle x = 5$.

V. Inéquations et tableaux de signes

Règle : on peut ajouter un même nombre aux deux membres d’une inégalité ; si l’on multiplie ou divise par un nombre négatif, on change le sens de l’inégalité.

Exemple : $\displaystyle -2x + 6 \le 0 \iff -2x \le -6 \iff x \ge 3$ (division par $\displaystyle -2$, le sens change).

[IMAGE_3]

Signe de $\displaystyle ax + b$ : il s’annule en $\displaystyle -\frac{b}{a}$ ; il est du signe de $\displaystyle a$ à droite de cette valeur et du signe contraire à gauche.

Pour un produit, on dresse un tableau de signes : une ligne par facteur, puis on applique la règle des signes. Ici $\displaystyle (2x - 4)(-x + 3) \gt 0 \iff x \in \,]2\,;3[$.

[IMAGE_4]
⚠️ Attention : pour un quotient $\displaystyle \frac{A}{B}$, la valeur qui annule $\displaystyle B$ est interdite : on la marque d’une double barre dans le tableau et elle n’est jamais solution.

🏆 L’essentiel : $\displaystyle a^n \times a^m = a^{n+m}$ et $\displaystyle a^{-n} = \frac{1}{a^n}$ ; $\displaystyle \sqrt{ab} = \sqrt{a}\sqrt{b}$ mais $\displaystyle \sqrt{a + b} \lt \sqrt{a} + \sqrt{b}$ ; $\displaystyle (a \pm b)^2 = a^2 \pm 2ab + b^2$ et $\displaystyle (a + b)(a - b) = a^2 - b^2$ ; produit nul : un des facteurs est nul ; $\displaystyle x^2 = a$ a deux solutions si $\displaystyle a \gt 0$ ; multiplier par un négatif change le sens d’une inégalité ; signe d’un produit : tableau de signes.
