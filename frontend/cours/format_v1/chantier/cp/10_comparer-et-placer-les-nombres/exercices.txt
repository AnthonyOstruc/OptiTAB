Découverte - Lire une ligne graduée
Id: 5345
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Les traits sont régulièrement espacés. Chaque espace vaut un.

[IMAGE_1]

1. Quel nombre manque 2 intervalles après 30 ?
2. Quel nombre manque 5 intervalles après 30 ?
3. Quel nombre manque 8 intervalles après 30 ?
4. Combien vaut un intervalle sur cette ligne ?
5. Combien d’intervalles séparent 30 et 40 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Quel nombre manque 2 intervalles après 30 ?

::: methode
Compter les espaces entre les traits.
:::

::: etape Raisonner
Chaque intervalle vaut 1. Depuis 30, je fais 2 pas : j’arrive à 32.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
32
:::

## Question 2 : Quel nombre manque 5 intervalles après 30 ?

::: methode
Compter les espaces entre les traits.
:::

::: etape Raisonner
Chaque intervalle vaut 1. Depuis 30, je fais 5 pas : j’arrive à 35.
:::

::: resultat
35
:::

## Question 3 : Quel nombre manque 8 intervalles après 30 ?

::: methode
Compter les espaces entre les traits.
:::

::: etape Raisonner
Chaque intervalle vaut 1. Depuis 30, je fais 8 pas : j’arrive à 38.
:::

::: resultat
38
:::

## Question 4 : Combien vaut un intervalle sur cette ligne ?

::: methode
Lire deux graduations voisines.
:::

::: etape Raisonner
Les deux premiers traits portent 30 et 31. L’écart est 1.
:::

::: resultat
1.
:::

## Question 5 : Combien d’intervalles séparent 30 et 40 ?

::: methode
Compter les espaces, sans compter le point de départ.
:::

::: etape Raisonner

:::

::: resultat

:::

Solution:
<!-- optitab:1 -->

2. 35
3. 38
4. 1.
5. 10 intervalles.

Problème - Vérifier les espaces
Id: 5353
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Tous les espaces ont la même valeur : un.

[IMAGE_1]

1. Tom place 25 trois intervalles après 22. Est-ce correct ?
2. Où arrive-t-on 3 intervalles après 20 ?
3. Où arrive-t-on 2 intervalles après 21 ?
4. Où arrive-t-on 3 intervalles après 23 ?
5. Où arrive-t-on 2 intervalles après 22 ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Tom place 25 trois intervalles après 22. Est-ce correct ?

::: methode
Compter les intervalles depuis 22.
:::

::: etape Raisonner
Depuis 22, je passe par 23, puis 24, puis 25. Cela fait trois pas.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Oui : 22 + 3 = 25.
:::

## Question 2 : Où arrive-t-on 3 intervalles après 20 ?

::: methode
Ne pas compter le départ comme un pas.
:::

::: etape Raisonner
J’avance de 3 espaces. $20+3=23$.
:::

::: resultat
23
:::

## Question 3 : Où arrive-t-on 2 intervalles après 21 ?

::: methode
Ne pas compter le départ comme un pas.
:::

::: etape Raisonner

:::

::: resultat
23
:::

## Question 4 : Où arrive-t-on 3 intervalles après 23 ?

::: methode
Ne pas compter le départ comme un pas.
:::

::: etape Raisonner
J’avance de 3 espaces. $23+3=26$.
:::

::: resultat
26
:::

## Question 5 : Où arrive-t-on 2 intervalles après 22 ?

::: methode
Ne pas compter le départ comme un pas.
:::

::: etape Raisonner

:::

::: resultat

:::

Solution:
<!-- optitab:1 -->
1. Oui : 22 + 3 = 25.
2. 23
3. 23
4. 26
