===
Découverte - Les cartes des quatre enfants
Id: 5101
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On partage équitablement 36 cartes entre 4 enfants. Combien chaque part contient-elle ?

[IMAGE_1]

1. Cherche-t-on le nombre de groupes ou le contenu d’une part ?
2. Quel produit donne le total, ou le plus grand total qui ne le dépasse pas ?
3. Combien d’objets restent après ces groupes ?
4. Réponds à la question de départ.
5. Vérifie que tous les objets sont comptés.

Étapes:
<!-- optitab:1 -->

## Question 1 : Cherche-t-on le nombre de groupes ou le contenu d’une part ?

::: methode
Distingue le nombre de parts du nombre d’objets dans chaque part.
:::

::: etape Raisonner
Le nombre de parts est connu ; on cherche le contenu de chaque part.
:::

::: resultat
Le contenu d’une part.
:::

## Question 2 : Quel produit donne le total, ou le plus grand total qui ne le dépasse pas ?

::: methode
Utilise les multiples de 4 et arrête-toi avant de dépasser le total.
:::

::: etape Raisonner
$9\times4=36$ ; $10\times4=40$ dépasserait 36.
:::

::: resultat
$9\times4=36$.
:::

## Question 3 : Combien d’objets restent après ces groupes ?

::: methode
Retire du total les objets déjà placés.
:::

::: etape Raisonner
$36-36=0$.
:::

[IMAGE_2]

::: resultat
0 cartes restent.
:::

## Question 4 : Réponds à la question de départ.

::: methode
Relis si tous les objets doivent être rangés ou si seuls les groupes complets comptent.
:::

::: etape Raisonner
Le partage est exact : chaque part a le même contenu.
:::

::: resultat
9 cartes par part.
:::

## Question 5 : Vérifie que tous les objets sont comptés.

::: methode
Réunis les objets des groupes complets et les objets restants.
:::

::: etape Raisonner
$9\times4+0=36$. Aucun objet ne reste hors du partage.
:::

::: resultat
$9\times4+0=36$.
:::

Solution:
<!-- optitab:1 -->
1. Le contenu d’une part.
2. $9\times4=36$.
3. 0 cartes restent.
4. 9 cartes par part.
5. $9\times4+0=36$.
