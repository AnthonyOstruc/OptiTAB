Titre: Résumé : Utiliser l’information chiffrée et la statistique descriptive

<!-- optitab:1 -->
::: objectifs
L’essentiel : proportions, évolutions, indicateurs de position et de dispersion.
:::

## I. Information chiffrée

- Proportion : $p = \dfrac{n_A}{n_E}$ ; effectif : $n_A = p \times n_E$.
- Proportion de proportion ($A \subset B \subset E$) : $p = p_1 \times p_2$.

::: formule
$$t = \frac{V_1 - V_0}{V_0} \qquad CM = \frac{V_1}{V_0} = 1 + t$$
:::

[IMAGE_1]

- Évolutions successives : on **multiplie** les coefficients.
- Évolution réciproque : coefficient $\dfrac{1}{CM}$.

## II. Statistique descriptive

| Position | Calcul |
|---|---|
| Moyenne $\bar{x}$ | $\dfrac{n_1x_1 + \cdots + n_px_p}{N}$ |
| Médiane $\mathrm{Me}$ | milieu de la série rangée |
| $Q_1$ | rang : 1er entier $\geqslant \dfrac{N}{4}$ |
| $Q_3$ | rang : 1er entier $\geqslant \dfrac{3N}{4}$ |

| Dispersion | Calcul |
|---|---|
| Écart interquartile | $Q_3 - Q_1$ |
| Écart type $\sigma$ | calculatrice ou tableur |

[IMAGE_2]

- Linéarité : si $x$ devient $ax + b$, la moyenne devient $a\bar{x} + b$.
- On associe moyenne et écart type, médiane et écart interquartile.

## III. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Additionner des taux d’évolution : $+10\,\%$ puis $-10\,\%$ donne $-1\,\%$.
2. Croire que la réciproque d’une hausse de $25\,\%$ est une baisse de $25\,\%$ : c’est $-20\,\%$.
3. Chercher la médiane ou les quartiles sans avoir rangé les valeurs.
4. Oublier les effectifs dans une moyenne pondérée.
:::

::: remarque Réflexe
Une évolution en pourcentage : je passe au coefficient multiplicateur. Une série : je donne un indicateur de position **et** un indicateur de dispersion.
:::
