===Résumé Équations différentielles Terminale

Titre: Résumé : Équations différentielles

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l’essentiel : solutions de $y' = ay$, $y' = ay + b$, $y' = ay + f$ et condition initiale. Programme de Terminale.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Résoudre</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$y' = ay + b$ : $y = Ce^{ax} - \frac{b}{a}$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $y' = ay$ : $y = Ce^{ax}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $y' = ay + f$ : $y = y_p + Ce^{ax}$ avec $y_p$ solution particulière.</p>
<p style="margin:6px 0 0 0;">3️⃣ Condition $y(x_0) = y_0$ → une seule valeur de $C$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Modéliser</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ « Variation proportionnelle à la quantité » → $y' = ay$.</p>
<p style="margin:6px 0 0 0;">2️⃣ « Variation proportionnelle à l’écart avec une valeur $L$ » → $y' = a(y - L)$, solution constante $L$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Si $a \lt 0$, les solutions tendent vers la solution constante.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Écrire $y = Ce^{ax} + \frac{b}{a}$ : c’est $-\frac{b}{a}$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Utiliser la condition initiale avant d’avoir la solution complète.</p>
<p style="margin:6px 0 0 0;">3️⃣ Oublier la constante $C$ (il y a une infinité de solutions).</p>
<p style="margin:6px 0 0 0;">4️⃣ Mal identifier $a$ et $b$ : $T' = -0{,}1(T - 20)$ donne $a = -0{,}1$ et $b = 2$.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> je mets l’équation sous la forme $y' = ay + b$, je cherche la solution constante, puis j’ajoute $Ce^{ax}$ et j’utilise la condition initiale.</p>
</div>
