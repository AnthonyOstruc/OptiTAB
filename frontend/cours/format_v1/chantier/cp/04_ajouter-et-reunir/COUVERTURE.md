# Couverture des activités sources

Chaque ligne conserve l’activité entière dans la question 1. Les questions 2 à 5 renforcent le même savoir-faire.

| Source | Exercice final | Activité conservée |
|---|---|---|
| 1 | nouveau-1 | Compte les deux groupes réunis. Complète : 4 + 3 = … |
| 2 | nouveau-2 | Calcule : 2 + 1 ; 3 + 3 ; 5 + 2. |
| 3 | nouveau-3 | Dessine 2 ronds et encore 4. Écris une addition. |
| 4 | nouveau-4 | Calcule : 6 + 0 ; 0 + 4 ; 7 + 1. |
| 5 | nouveau-5 | Complète : 5 = 3 + … ; 8 = 4 + … |
| 6 | nouveau-6 | Compare les résultats : 2 + 5 et 5 + 2. |
| 7 | nouveau-7 | Aya a 3 billes. Elle en reçoit 4. Combien en a-t-elle maintenant ? |
| 8 | nouveau-8 | Dans une trousse, il y a 2 crayons rouges et 6 bleus. Combien de crayons y a-t-il ? |
| 9 | nouveau-9 | Sam écrit : 4 + 2 = 5 + 1. Est-ce vrai ? |

La manipulation, les trois points de leçon, l’exemple, le guidage et la vigilance sont repris dans le cours.
