Titre: Résoudre des problèmes : réunir des groupes de même taille
<!-- optitab:1 -->
::: objectifs 
Reconnaître des groupes de même taille. Dessiner les groupes. Trouver le total.
:::

## I. Des groupes identiques

::: definition 
Chaque groupe contient autant d’objets que les autres.
:::

::: exemple Trois boîtes
Il y a 3 boîtes de 4 jetons.

[IMAGE_1]

Je compte $4+4+4=12$ jetons. Je peux dire « trois fois quatre ».
:::

## II. Dessiner et compter

::: methode 
Je dessine un contour par groupe. Je mets autant de points dans chaque contour.

J’écris une quantité par groupe. Je les additionne dans l’ordre.
:::

## III. À toi de manipuler

::: methode Deux groupes de cinq
Prends deux boîtes. Mets 5 jetons dans chacune.

$5+5=10$. Compte tous les jetons pour vérifier.
:::

::: attention 
Avec 3, 3 et 4 jetons, les groupes sont différents. Je ne dis pas « trois groupes de trois ».
:::

::: retenir 
Une addition répétée réunit des groupes de même taille. Je compte tous les groupes.
:::
