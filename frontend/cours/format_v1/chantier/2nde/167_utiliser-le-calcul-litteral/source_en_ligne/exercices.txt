=== Découverte - Calcul Littéral - Réduire et substituer
Id: 1900
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Simplifier chaque expression, puis calculer sa valeur en remplaçant la variable par la valeur donnée.

1. Simplifier puis calculer $\displaystyle A = 3x + 5x - 7$ pour $\displaystyle x = 2$
2. Simplifier puis calculer $\displaystyle B = 2(x - 3) - 4(x + 2)$ pour $\displaystyle x = -1$
3. Simplifier puis calculer $\displaystyle C = 5a - 2(3a - 4) + a$ pour $\displaystyle a = 3$
4. Simplifier puis calculer $\displaystyle D = (x + 1)^2 - (x^2 + 1)$ pour $\displaystyle x = 0$
5. Simplifier puis calculer $\displaystyle E = \dfrac{2x + 6}{x + 3}$ pour $\displaystyle x = 3$

Étapes:

<!-- optitab:1 -->
## Question 1 : Simplifier puis calculer $\displaystyle A = 3x + 5x - 7$ pour $\displaystyle x = 2$

::: methode
Réduire les termes semblables puis substituer
:::

::: etape Regrouper les termes en $\displaystyle x$
- $\displaystyle 3x + 5x = (3+5)x = 8x$
:::

::: etape Écrire l'expression simplifiée
- $\displaystyle A = 8x - 7$
:::

::: etape Substituer $\displaystyle x = 2$
- $\displaystyle A = 8\times 2 - 7 = 16 - 7 = 9$
:::

::: resultat
$A = 8x - 7$ et pour $x=2$, $A = 9$
:::

## Question 2 : Simplifier puis calculer $\displaystyle B = 2(x - 3) - 4(x + 2)$ pour $\displaystyle x = -1$

::: methode
Développer puis réduire, puis substituer
:::

::: etape Développer
- $\displaystyle 2(x-3)=2x-6$
- $\displaystyle -4(x+2)=-4x-8$
:::

::: etape Réduire
- $\displaystyle B=(2x-6)+(-4x-8)= -2x-14$
:::

::: etape Substituer $\displaystyle x=-1$
- $\displaystyle B=-2\times(-1)-14=2-14=-12$
:::

::: resultat
$B=-2x-14$ et pour $x=-1$, $B=-12$
:::

## Question 3 : Simplifier puis calculer $\displaystyle C = 5a - 2(3a - 4) + a$ pour $\displaystyle a = 3$

::: methode
Développer, réduire, puis substituer
:::

::: etape Développer le terme entre parenthèses
- $\displaystyle -2(3a-4) = -6a+8$
:::

::: etape Réduire
- $\displaystyle C=5a+(-6a+8)+a = (5-6+1)a+8 = 0\times a+8 = 0+8=8$
:::

::: etape Substituer $\displaystyle a=3$
- $\displaystyle C=8$
:::

::: resultat
$C=8$ (indépendant de $a$)
:::

## Question 4 : Simplifier puis calculer $\displaystyle D = (x + 1)^2 - (x^2 + 1)$ pour $\displaystyle x = 0$

::: methode
Développer puis réduire, puis substituer
:::

::: etape Développer le carré
- $\displaystyle (x+1)^2 = x^2 + 2x + 1$
:::

::: etape Soustraire et réduire
- $\displaystyle D=(x^2+2x+1)-(x^2+1)=2x$
:::

::: etape Substituer $\displaystyle x=0$
- $\displaystyle D=2\times 0 = 0$
:::

::: resultat
$D=2x$ et pour $x=0$, $D=0$
:::

## Question 5 : Simplifier puis calculer $\displaystyle E = \dfrac{2x + 6}{x + 3}$ pour $\displaystyle x = 3$

::: methode
Factoriser puis simplifier, puis substituer
:::

::: etape Factoriser le numérateur
- $\displaystyle 2x+6 = 2(x+3)$
:::

::: etape Simplifier (pour $x \neq -3$)
- $\displaystyle E=\dfrac{2(x+3)}{x+3}=2$
:::

::: attention
La simplification par $x+3$ n’est permise que si $x+3 \neq 0$ : l’expression $E$ n’est pas définie pour $x=-3$.
:::

::: etape Substituer $\displaystyle x=3$
- $\displaystyle E=2$
:::

::: resultat
$E=2$ (pour $x\neq -3$), et pour $x=3$, $E=2$
:::

Solution:
<!-- optitab:1 -->
1. $A = 8x - 7$ et pour $x=2$, $A=9$
2. $B = -2x - 14$ et pour $x=-1$, $B=-12$
3. $\displaystyle C = 8$
4. $D = 2x$ et pour $x=0$, $D=0$
5. $E = 2$ (pour $x\neq -3$)

=== Découverte - Exprimer une variable - Isoler une inconnue
Id: 1906
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Dans chaque cas, exprimer la variable demandée en fonction des autres.

1. Dans $\displaystyle P = 2(L + \ell)$, exprimer $\displaystyle L$ en fonction de $\displaystyle P$ et $\displaystyle \ell$
2. Dans $\displaystyle S = \pi r^2$ (avec $\displaystyle r>0$), exprimer $\displaystyle r$ en fonction de $\displaystyle S$
3. Dans $\displaystyle I = \dfrac{U}{R}$ (avec $\displaystyle R\neq 0$), exprimer $\displaystyle R$ en fonction de $\displaystyle U$ et $\displaystyle I$
4. Dans $\displaystyle 3x + 5y = 20$, exprimer $\displaystyle y$ en fonction de $\displaystyle x$
5. Dans $\displaystyle d = vt$ (avec $\displaystyle v\neq 0$), exprimer $\displaystyle t$ en fonction de $\displaystyle d$ et $\displaystyle v$

Étapes:

<!-- optitab:1 -->
## Question 1 : Dans $\displaystyle P = 2(L + \ell)$, exprimer $\displaystyle L$ en fonction de $\displaystyle P$ et $\displaystyle \ell$

::: methode
Isoler $L$ en appliquant les opérations inverses
:::

::: etape Diviser par $\displaystyle 2$
- $\displaystyle \dfrac{P}{2}=L+\ell$
:::

::: etape Soustraire $\displaystyle \ell$
- $\displaystyle L=\dfrac{P}{2}-\ell$
:::

::: resultat
$$L=\dfrac{P}{2}-\ell$$
:::

## Question 2 : Dans $\displaystyle S = \pi r^2$ (avec $\displaystyle r>0$), exprimer $\displaystyle r$ en fonction de $\displaystyle S$

::: methode
Isoler $r$ (division puis racine carrée)
:::

::: etape Diviser par $\displaystyle \pi$
- $\displaystyle r^2=\dfrac{S}{\pi}$
:::

::: etape Prendre la racine carrée (car $\displaystyle r>0$)
- $\displaystyle r=\sqrt{\dfrac{S}{\pi}}$
:::

::: resultat
$$r=\sqrt{\dfrac{S}{\pi}}$$
:::

## Question 3 : Dans $\displaystyle I = \dfrac{U}{R}$ (avec $\displaystyle R\neq 0$), exprimer $\displaystyle R$ en fonction de $\displaystyle U$ et $\displaystyle I$

::: methode
Isoler $R$ dans une relation de quotient
:::

::: etape Multiplier par $\displaystyle R$
- $\displaystyle IR = U$
:::

::: etape Diviser par $I$ (avec $I \neq 0$)
- $\displaystyle R=\dfrac{U}{I}$
:::

::: resultat
$R=\dfrac{U}{I}$ (avec $I\neq 0$)
:::

## Question 4 : Dans $\displaystyle 3x + 5y = 20$, exprimer $\displaystyle y$ en fonction de $\displaystyle x$

::: methode
Isoler $\displaystyle y$
:::

::: etape Transposer $\displaystyle 3x$
- $\displaystyle 5y = 20 - 3x$
:::

::: etape Diviser par $\displaystyle 5$
- $\displaystyle y=\dfrac{20-3x}{5}$
:::

::: resultat
$$y=\dfrac{20-3x}{5}$$
:::

## Question 5 : Dans $\displaystyle d = vt$ (avec $\displaystyle v\neq 0$), exprimer $\displaystyle t$ en fonction de $\displaystyle d$ et $\displaystyle v$

::: methode
Isoler $t$ dans une relation produit
:::

::: etape Diviser par $\displaystyle v$
- $\displaystyle t=\dfrac{d}{v}$
:::

::: resultat
$t=\dfrac{d}{v}$ (avec $v\neq 0$)
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle L=\dfrac{P}{2}-\ell$
2. $\displaystyle r=\sqrt{\dfrac{S}{\pi}}$
3. $R=\dfrac{U}{I}$ (avec $I\neq 0$)
4. $\displaystyle y=\dfrac{20-3x}{5}$
5. $t=\dfrac{d}{v}$ (avec $v\neq 0$)

=== Découverte - Puissances - Propriétés essentielles
Id: 1901
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Simplifier les expressions suivantes en utilisant les propriétés des puissances (et donner le résultat sous une forme sans exposant négatif si possible).

1. Simplifier $\displaystyle 2^4 \times 2^{-6}$
2. Simplifier $\displaystyle \dfrac{5^7}{5^3}$
3. Simplifier $\displaystyle (3^{-2})^3$
4. Simplifier $\displaystyle (2x^3)^2$
5. Simplifier $\displaystyle \left(\dfrac{2}{3}\right)^{-4}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle 2^4 \times 2^{-6}$

::: methode
Produit de puissances de même base $a^m\times a^n=a^{m+n}$
:::

::: etape Additionner les exposants
- $\displaystyle 2^4 \times 2^{-6} = 2^{4+(-6)}=2^{-2}$
:::

::: etape Écrire sans exposant négatif
- $\displaystyle 2^{-2}=\dfrac{1}{2^2}=\dfrac{1}{4}$
:::

::: resultat
$$2^4 \times 2^{-6}=\dfrac{1}{4}$$
:::

## Question 2 : Simplifier $\displaystyle \dfrac{5^7}{5^3}$

::: methode
Quotient de puissances de même base $\dfrac{a^m}{a^n}=a^{m-n}$
:::

::: etape Soustraire les exposants
- $\displaystyle \dfrac{5^7}{5^3}=5^{7-3}=5^4$
:::

::: etape Calculer si nécessaire
- $\displaystyle 5^4=625$
:::

::: resultat
$$\dfrac{5^7}{5^3}=5^4=625$$
:::

## Question 3 : Simplifier $\displaystyle (3^{-2})^3$

::: methode
Puissance d'une puissance $\displaystyle (a^m)^n=a^{mn}$
:::

::: etape Multiplier les exposants
- $\displaystyle (3^{-2})^3=3^{-2\times 3}=3^{-6}$
:::

::: etape Écrire sans exposant négatif
- $\displaystyle 3^{-6}=\dfrac{1}{3^6}=\dfrac{1}{729}$
:::

::: resultat
$$(3^{-2})^3=\dfrac{1}{729}$$
:::

## Question 4 : Simplifier $\displaystyle (2x^3)^2$

::: methode
Puissance d'un produit $\displaystyle (ab)^n=a^n b^n$
:::

::: etape Appliquer la propriété
- $\displaystyle (2x^3)^2 = 2^2 \times (x^3)^2$
:::

::: etape Simplifier chaque partie
- $\displaystyle 2^2=4$
- $\displaystyle (x^3)^2=x^{3\times 2}=x^6$
:::

::: resultat
$$(2x^3)^2=4x^6$$
:::

## Question 5 : Simplifier $\displaystyle \left(\dfrac{2}{3}\right)^{-4}$

::: methode
Exposant négatif $\displaystyle \left(\dfrac{a}{b}\right)^{-n}=\left(\dfrac{b}{a}\right)^n$
:::

::: etape Inverser la fraction et changer le signe
- $\displaystyle \left(\dfrac{2}{3}\right)^{-4}=\left(\dfrac{3}{2}\right)^4$
:::

::: etape Calculer
$$
\begin{aligned}
\left(\dfrac{3}{2}\right)^4 &= \dfrac{3^4}{2^4} \\
&= \dfrac{81}{16}
\end{aligned}
$$
:::

::: resultat
$$\left(\dfrac{2}{3}\right)^{-4}=\dfrac{81}{16}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle 2^4 \times 2^{-6}=\dfrac{1}{4}$
2. $\displaystyle \dfrac{5^7}{5^3}=5^4=625$
3. $\displaystyle (3^{-2})^3=\dfrac{1}{729}$
4. $\displaystyle (2x^3)^2=4x^6$
5. $\displaystyle \left(\dfrac{2}{3}\right)^{-4}=\dfrac{81}{16}$

=== Entraînement - Comparaison - Différence ou quotient
Id: 1907
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Dans les questions 1 à 4, comparer les deux quantités en étudiant le signe de leur différence, puis conclure selon les valeurs du réel $x$. Dans la question 5, comparer à l’aide d’un quotient.

1. Comparer $\displaystyle A=(x+1)^2$ et $\displaystyle B=x^2+3$
2. Comparer $\displaystyle A=2x+5$ et $\displaystyle B=5x-1$
3. Comparer $\displaystyle A=(3x-4)^2$ et $\displaystyle B=9x^2$
4. Comparer $\displaystyle A=(x-2)(x+2)$ et $\displaystyle B=x^2-3$
5. Comparer les nombres positifs $\displaystyle A=3^{20}$ et $\displaystyle B=2^{30}$ en calculant $\dfrac{A}{B}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Comparer $\displaystyle A=(x+1)^2$ et $\displaystyle B=x^2+3$

::: methode
Étudier le signe de $\displaystyle A-B$
:::

::: etape Calculer $\displaystyle A-B$
$$
\begin{aligned}
A-B &= (x+1)^2-(x^2+3) \\
&= (x^2+2x+1)-x^2-3 \\
&= 2x-2 \\
&= 2(x-1)
\end{aligned}
$$
:::

::: etape Étudier le signe
- $\displaystyle A-B>0 \iff x>1$
- $\displaystyle A-B=0 \iff x=1$
- $\displaystyle A-B<0 \iff x<1$
:::

::: resultat
$A>B$ si $x>1$, $A=B$ si $x=1$, $A<B$ si $x<1$
:::

## Question 2 : Comparer $\displaystyle A=2x+5$ et $\displaystyle B=5x-1$

::: methode
Étudier $\displaystyle A-B$
:::

::: etape Calculer la différence
$$
\begin{aligned}
A-B &= (2x+5)-(5x-1) \\
&= 2x+5-5x+1 \\
&= -3x+6
\end{aligned}
$$
:::

::: etape Étudier le signe
$-3x+6$ s’annule en $x=2$ ; son coefficient $-3$ est négatif, donc :
- $-3x+6>0 \iff x<2$
- $-3x+6=0 \iff x=2$
- $-3x+6 \lt 0 \iff x \gt 2$
:::

::: attention
Le signe moins devant la parenthèse change tous les signes : $-(5x-1)=-5x+1$.
:::

::: resultat
$A \gt B$ si $x \lt 2$, $A=B$ si $x=2$, $A \lt B$ si $x \gt 2$
:::

## Question 3 : Comparer $\displaystyle A=(3x-4)^2$ et $\displaystyle B=9x^2$

::: methode
Étudier $\displaystyle A-B$
:::

::: etape Développer puis soustraire
- $\displaystyle (3x-4)^2=9x^2-24x+16$
- $\displaystyle A-B=(9x^2-24x+16)-9x^2=-24x+16=8(2-3x)$
:::

::: etape Étudier le signe
$8 > 0$, donc $A-B$ a le signe de $2-3x$ :
- $A-B>0 \iff 2-3x>0 \iff x<\dfrac{2}{3}$
- $A-B=0 \iff x=\dfrac{2}{3}$
- $A-B \lt 0 \iff x \gt \dfrac{2}{3}$
:::

::: resultat
$A \gt B$ si $x \lt \dfrac{2}{3}$, $A=B$ si $x=\dfrac{2}{3}$, $A \lt B$ si $x \gt \dfrac{2}{3}$
:::

## Question 4 : Comparer $\displaystyle A=(x-2)(x+2)$ et $\displaystyle B=x^2-3$

::: methode
Étudier $\displaystyle A-B$
:::

::: etape Simplifier $\displaystyle A$
- $\displaystyle (x-2)(x+2)=x^2-4$
:::

::: etape Calculer la différence
- $\displaystyle A-B=(x^2-4)-(x^2-3)=-1$
:::

::: resultat
$A-B=-1<0$ donc $A<B$ pour tout $x$
:::

## Question 5 : Comparer $\displaystyle A=3^{20}$ et $\displaystyle B=2^{30}$ en calculant $\dfrac{A}{B}$

::: methode
Pour deux nombres strictement positifs : $A>B \iff \dfrac{A}{B}>1$
:::

::: etape Faire apparaître un même exposant
- $3^{20}=3^{2\times 10}=(3^2)^{10}=9^{10}$
- $2^{30}=2^{3\times 10}=(2^3)^{10}=8^{10}$
:::

::: etape Calculer le quotient
$$
\begin{aligned}
\frac{A}{B} &= \frac{9^{10}}{8^{10}} \\
&= \left(\frac{9}{8}\right)^{10}
\end{aligned}
$$
:::

::: etape Comparer à 1
$\dfrac{9}{8}>1$, et un produit de nombres tous supérieurs à $1$ est supérieur à $1$ : $\left(\dfrac{9}{8}\right)^{10}>1$.
:::

::: retenir
La différence $A-B$ serait ici difficile à calculer à la main ; le quotient, lui, se simplifie grâce aux règles sur les puissances.
:::

::: resultat
$\dfrac{A}{B}>1$ et $B>0$, donc $3^{20}>2^{30}$
:::

Solution:
<!-- optitab:1 -->
1. $A>B$ si $x>1$, $A=B$ si $x=1$, $A<B$ si $x<1$
2. $A \gt B$ si $x \lt 2$, $A=B$ si $x=2$, $A \lt B$ si $x \gt 2$
3. $A \gt B$ si $x \lt \dfrac{2}{3}$, $A=B$ si $x=\dfrac{2}{3}$, $A \lt B$ si $x \gt \dfrac{2}{3}$
4. $A-B=-1$, donc $(x-2)(x+2) < x^2-3$ pour tout $x$
5. $\dfrac{A}{B}=\left(\dfrac{9}{8}\right)^{10}>1$, donc $3^{20}>2^{30}$

=== Entraînement - Équations quotients - Résoudre sur les réels
Id: 1913
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Résoudre sur $\mathbb{R}$ les équations suivantes (en précisant les valeurs interdites).

1. Résoudre $\displaystyle \dfrac{3}{x-2} + \dfrac{5}{x+2} = \dfrac{4x}{x^2-4}$
2. Résoudre $\displaystyle \dfrac{x+1}{x-3} = \dfrac{x-1}{x-2}$
3. Résoudre $\displaystyle \dfrac{2}{x+1} = \dfrac{5}{2x-1}$
4. Résoudre $\displaystyle \dfrac{x^2-9}{x-3} + \dfrac{2}{x} = x+4$
5. Résoudre $\displaystyle \dfrac{1}{x-1} - \dfrac{1}{x+1} = \dfrac{1}{2}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre $\displaystyle \dfrac{3}{x-2} + \dfrac{5}{x+2} = \dfrac{4x}{x^2-4}$

::: methode
Déterminer les valeurs interdites puis multiplier par le dénominateur commun
:::

::: etape Valeurs interdites
- $x^2-4\neq 0 \Rightarrow x\neq 2$ et $x\neq -2$
:::

::: etape Multiplier par $\displaystyle x^2-4=(x-2)(x+2)$
- $\displaystyle 3(x+2)+5(x-2)=4x$
:::

::: etape Résoudre
- $\displaystyle 3x+6+5x-10=4x$
- $\displaystyle 8x-4=4x \Rightarrow 4x=4 \Rightarrow x=1$
:::

::: resultat
$$S=\{1\}$$
:::

## Question 2 : Résoudre $\displaystyle \dfrac{x+1}{x-3} = \dfrac{x-1}{x-2}$

::: methode
Produit en croix, valable seulement en dehors des valeurs interdites
:::

::: etape Valeurs interdites
- $x-3\neq 0 \iff x\neq 3$
- $x-2\neq 0 \iff x\neq 2$
:::

::: etape Produit en croix
Pour $x \neq 2$ et $x \neq 3$, deux fractions sont égales si et seulement si leurs produits en croix sont égaux :
$$(x+1)(x-2)=(x-1)(x-3)$$
:::

::: etape Développer et réduire
$$
\begin{aligned}
x^2-2x+x-2 &= x^2-3x-x+3 \\
x^2-x-2 &= x^2-4x+3 \\
-x+4x &= 3+2 \\
3x &= 5
\end{aligned}
$$
Les termes en $x^2$ s’éliminent : on obtient $x=\dfrac{5}{3}$.
:::

::: etape Vérifier la solution
$\dfrac{5}{3}$ n’est ni $2$ ni $3$ : ce n’est pas une valeur interdite, la solution est acceptée.
:::

::: attention
Toujours comparer les solutions trouvées aux valeurs interdites : une valeur interdite n’est jamais solution.
:::

::: resultat
$$S=\left\{\frac{5}{3}\right\}$$
:::

## Question 3 : Résoudre $\displaystyle \dfrac{2}{x+1} = \dfrac{5}{2x-1}$

::: methode
Produit en croix
:::

::: etape Valeurs interdites
- $\displaystyle x+1\neq 0 \Rightarrow x\neq -1$
- $\displaystyle 2x-1\neq 0 \Rightarrow x\neq \dfrac{1}{2}$
:::

::: etape Produit en croix
- $\displaystyle 2(2x-1)=5(x+1)$
:::

::: etape Résoudre
- $\displaystyle 4x-2=5x+5$
- $\displaystyle -x=7 \Rightarrow x=-7$
:::

::: resultat
$$S=\{-7\}$$
:::

## Question 4 : Résoudre $\displaystyle \dfrac{x^2-9}{x-3} + \dfrac{2}{x} = x+4$

::: methode
Simplifier la fraction puis résoudre (en gardant les valeurs interdites)
:::

::: etape Valeurs interdites
- $\displaystyle x-3\neq 0 \Rightarrow x\neq 3$
- $\displaystyle x\neq 0$
:::

::: etape Simplifier $\displaystyle \dfrac{x^2-9}{x-3}$
- $\displaystyle x^2-9=(x-3)(x+3)$
- $\dfrac{x^2-9}{x-3}=x+3$ pour $x\neq 3$
:::

::: etape Résoudre
- $\displaystyle (x+3)+\dfrac{2}{x}=x+4$

$$
\begin{aligned}
3+\dfrac{2}{x}=4 &\Rightarrow \dfrac{2}{x}=1 \\
&\Rightarrow x=2
\end{aligned}
$$
:::

::: resultat
$$S=\{2\}$$
:::

## Question 5 : Résoudre $\displaystyle \dfrac{1}{x-1} - \dfrac{1}{x+1} = \dfrac{1}{2}$

::: methode
Mettre au même dénominateur puis résoudre
:::

::: etape Valeurs interdites
- $x\neq 1$ et $x\neq -1$
:::

::: etape Mettre au même dénominateur
$$
\begin{aligned}
\dfrac{1}{x-1}-\dfrac{1}{x+1} &= \dfrac{(x+1)-(x-1)}{(x-1)(x+1)} \\
&= \dfrac{2}{x^2-1}
\end{aligned}
$$
:::

::: etape Résoudre
$$
\begin{aligned}
\dfrac{2}{x^2-1}=\dfrac{1}{2} &\Rightarrow 4=x^2-1 \\
&\Rightarrow x^2=5
\end{aligned}
$$

- $x=-\sqrt{5}$ ou $x=\sqrt{5}$
:::

::: resultat
$$S=\{-\sqrt{5};\sqrt{5}\}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle S=\{1\}$
2. $\displaystyle S=\left\{\frac{5}{3}\right\}$
3. $\displaystyle S=\{-7\}$
4. $\displaystyle S=\{2\}$
5. $\displaystyle S=\{-\sqrt{5};\sqrt{5}\}$

=== Entraînement - Équations x² = a - Résoudre et lire sur la parabole
Id: 3737
Difficulté: easy
Image: v1_n167_ex3737_1_ex_x2_enonce.png,v1_n167_ex3737_2_ex_x2_corrige.png,v1_n167_ex3737_3_ex_x2_q3_corrige.png

Énoncé: <!-- optitab:1 -->
1. Résoudre dans $\mathbb{R}$ les équations suivantes.
   - a) $x^2=49$
   - b) $x^2=7$
   - c) $x^2=-4$
   - d) $(x-1)^2=9$
2. On a tracé la parabole d’équation $y=x^2$ et la droite d’équation $y=9$. Résoudre graphiquement :
   - a) $x^2<9$
   - b) $x^2\ge 9$
3. En s’inspirant de la question 2, résoudre $x^2\le 2$.

[IMAGE_1]

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre les équations du type $x^2=a$

::: methode
$x^2=a$ a deux solutions $-\sqrt{a}$ et $\sqrt{a}$ si $a>0$, une seule ($0$) si $a=0$, aucune si $a<0$
:::

::: etape a) $x^2=49$
$49>0$, donc $x=-\sqrt{49}$ ou $x=\sqrt{49}$, c’est-à-dire $x=-7$ ou $x=7$.
:::

::: etape b) $x^2=7$
$7>0$, donc $x=-\sqrt{7}$ ou $x=\sqrt{7}$ ($7$ n’est pas un carré parfait : on garde les racines).
:::

::: etape c) $x^2=-4$
Un carré est toujours positif ou nul : il ne peut pas valoir $-4$. Pas de solution.
:::

::: etape d) $(x-1)^2=9$
On pose $X=x-1$ : $X^2=9 \iff X=-3$ ou $X=3$.
- $x-1=-3 \iff x=-2$
- $x-1=3 \iff x=4$
:::

::: attention
Oublier la solution négative est l’erreur la plus fréquente : $x^2=49$ ne donne pas seulement $x=7$, car $(-7)^2=49$ aussi.
:::

::: resultat
- a) $S=\{-7\,;7\}$
- b) $S=\{-\sqrt{7}\,;\sqrt{7}\}$
- c) $S=\varnothing$
- d) $S=\{-2\,;4\}$
:::

## Question 2 : Résoudre graphiquement $x^2<9$ et $x^2\ge 9$

::: methode
On cherche les abscisses des points de la parabole situés sous la droite $y=9$ (ou sur et au-dessus)
:::

::: etape Points d’intersection
La parabole coupe la droite $y=9$ aux points d’abscisses $-3$ et $3$ (car $(-3)^2=3^2=9$).
:::

::: etape Lecture
La partie de la parabole située **strictement sous** la droite (en vert) correspond aux abscisses comprises strictement entre $-3$ et $3$.
:::

[IMAGE_2]

::: resultat
- a) $x^2 \lt 9 \iff x\in{]-3\,;3[}$
- b) $x^2\ge 9 \iff x\in{]-\infty\,;-3]}\cup{[3\,;+\infty[}$
:::

## Question 3 : Résoudre $x^2\le 2$

::: methode
Même raisonnement avec la droite $y=2$, qui coupe la parabole en $-\sqrt{2}$ et $\sqrt{2}$
:::

::: etape Solutions de $x^2=2$
$2>0$, donc $x^2=2 \iff x=-\sqrt{2}$ ou $x=\sqrt{2}$.
:::

::: etape Lecture sur la parabole
La parabole est sous la droite $y=2$, ou sur elle, pour les abscisses comprises entre $-\sqrt{2}$ et $\sqrt{2}$, bornes incluses (inégalité large).
:::

[IMAGE_3]

::: attention
$x^2\le 2$ ne se résout pas en « $x\le\sqrt{2}$ » : $x=-5$ vérifie $x\le\sqrt{2}$, mais $(-5)^2=25>2$.
:::

::: resultat
$$S=\left[-\sqrt{2}\,;\sqrt{2}\right]$$
:::

Solution:

2. a) $S={]-3\,;3[}$ ; b) $S={]-\infty\,;-3]}\cup{[3\,;+\infty[}$

=== Entraînement - Expressions fractionnaires - Simplifier et additionner
Id: 1905
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Simplifier les fractions algébriques suivantes (en précisant les conditions d'existence).

1. Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3}$
2. Simplifier $\displaystyle \dfrac{2x^2 + 4x}{2x}$
3. Calculer $\displaystyle \dfrac{1}{x} + \dfrac{2}{x+1}$
4. Simplifier $\displaystyle \dfrac{x^2 - 1}{x^2 - 2x + 1}$
5. Simplifier $\displaystyle \dfrac{x^2 + 5x + 6}{x^2 - 4}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \dfrac{x^2 - 9}{x + 3}$

::: methode
Factoriser puis simplifier
:::

::: etape Factoriser le numérateur
- $\displaystyle x^2-9=(x-3)(x+3)$
:::

::: etape Simplifier (pour $x \neq -3$)
- $\displaystyle \dfrac{(x-3)(x+3)}{x+3}=x-3$
:::

::: resultat
$\dfrac{x^2 - 9}{x + 3}=x-3$ pour $x\neq -3$
:::

## Question 2 : Simplifier $\displaystyle \dfrac{2x^2 + 4x}{2x}$

::: methode
Mettre en facteur puis simplifier
:::

::: etape Factoriser le numérateur
- $\displaystyle 2x^2+4x=2x(x+2)$
:::

::: etape Simplifier (pour $x \neq 0$)
- $\displaystyle \dfrac{2x(x+2)}{2x}=x+2$
:::

::: resultat
$\dfrac{2x^2 + 4x}{2x}=x+2$ pour $x\neq 0$
:::

## Question 3 : Calculer $\displaystyle \dfrac{1}{x} + \dfrac{2}{x+1}$

::: methode
Réduction au même dénominateur
:::

::: etape Conditions d'existence
- $x\neq 0$ et $x\neq -1$
:::

::: etape Dénominateur commun
- $\displaystyle x(x+1)$
:::

::: etape Mettre au même dénominateur
- $\displaystyle \dfrac{1}{x}=\dfrac{x+1}{x(x+1)}$
- $\displaystyle \dfrac{2}{x+1}=\dfrac{2x}{x(x+1)}$
:::

::: etape Additionner
- $\displaystyle \dfrac{x+1}{x(x+1)}+\dfrac{2x}{x(x+1)}=\dfrac{3x+1}{x(x+1)}$
:::

::: resultat
$\dfrac{1}{x} + \dfrac{2}{x+1}=\dfrac{3x+1}{x(x+1)}$ pour $x\neq 0$ et $x\neq -1$
:::

## Question 4 : Simplifier $\displaystyle \dfrac{x^2 - 1}{x^2 - 2x + 1}$

::: methode
Factoriser numérateur et dénominateur
:::

::: etape Factoriser
- $\displaystyle x^2-1=(x-1)(x+1)$
- $\displaystyle x^2-2x+1=(x-1)^2$
:::

::: etape Simplifier (pour $x \neq 1$)
- $\displaystyle \dfrac{(x-1)(x+1)}{(x-1)^2}=\dfrac{x+1}{x-1}$
:::

::: attention
On ne simplifie que par un **facteur** commun : écrire $\dfrac{x^2-1}{x^2-2x+1}=\dfrac{-1}{-2x+1}$ en « barrant » les $x^2$ est faux.
:::

::: resultat
$\dfrac{x^2 - 1}{x^2 - 2x + 1}=\dfrac{x+1}{x-1}$ pour $x\neq 1$
:::

## Question 5 : Simplifier $\displaystyle \dfrac{x^2 + 5x + 6}{x^2 - 4}$

::: methode
Factoriser puis simplifier
:::

::: etape Factoriser
- $\displaystyle x^2+5x+6=(x+2)(x+3)$
- $\displaystyle x^2-4=(x-2)(x+2)$
:::

::: etape Simplifier (pour $x\neq 2$ et $x\neq -2$)
- $\displaystyle \dfrac{(x+2)(x+3)}{(x-2)(x+2)}=\dfrac{x+3}{x-2}$
:::

::: resultat
$\dfrac{x^2 + 5x + 6}{x^2 - 4}=\dfrac{x+3}{x-2}$ pour $x\neq \pm 2$
:::

Solution:
<!-- optitab:1 -->
1. $\dfrac{x^2 - 9}{x + 3}=x-3$ pour $x\neq -3$
2. $\dfrac{2x^2 + 4x}{2x}=x+2$ pour $x\neq 0$
3. $\dfrac{1}{x} + \dfrac{2}{x+1}=\dfrac{3x+1}{x(x+1)}$ pour $x\neq 0$ et $x\neq -1$
4. $\dfrac{x^2 - 1}{x^2 - 2x + 1}=\dfrac{x+1}{x-1}$ pour $x\neq 1$
5. $\dfrac{x^2 + 5x + 6}{x^2 - 4}=\dfrac{x+3}{x-2}$ pour $x\neq \pm 2$

=== Entraînement - Fractions - Calculer sous forme irréductible
Id: 1910
Difficulté: easy

Énoncé: <!-- optitab:1 -->
Calculer chaque expression et donner le résultat sous forme de fraction irréductible.

1. Calculer $\displaystyle A = 1 + \dfrac{3}{4}\times\dfrac{2}{9}$
2. Calculer $\displaystyle B = \dfrac{4}{5} + \dfrac{3}{10}\div\dfrac{9}{4}$
3. Calculer $\displaystyle C = \dfrac{\dfrac{3}{7}}{\dfrac{5}{14}}$
4. Calculer $\displaystyle D = \dfrac{1}{2}\left(1-\dfrac{1}{3}\right)^2$
5. Calculer $\displaystyle E = \dfrac{\dfrac{5}{12}+\dfrac{1}{8}}{\dfrac{7}{6}}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Calculer $\displaystyle A = 1 + \dfrac{3}{4}\times\dfrac{2}{9}$

::: methode
Effectuer la multiplication puis l'addition
:::

::: etape Calculer le produit
$$
\begin{aligned}
\dfrac{3}{4}\times\dfrac{2}{9} &= \dfrac{3\times 2}{4\times 9} \\
&= \dfrac{6}{36} \\
&= \dfrac{1}{6}
\end{aligned}
$$
:::

::: etape Ajouter 1
$$
\begin{aligned}
A &= 1+\dfrac{1}{6} \\
&= \dfrac{6}{6}+\dfrac{1}{6} \\
&= \dfrac{7}{6}
\end{aligned}
$$
:::

::: resultat
$$A=\dfrac{7}{6}$$
:::

## Question 2 : Calculer $\displaystyle B = \dfrac{4}{5} + \dfrac{3}{10}\div\dfrac{9}{4}$

::: methode
Transformer la division en multiplication par l'inverse puis additionner
:::

::: etape Remplacer la division
- $\displaystyle \dfrac{3}{10}\div\dfrac{9}{4}=\dfrac{3}{10}\times\dfrac{4}{9}$
:::

::: etape Calculer et simplifier
$$
\begin{aligned}
\dfrac{3}{10}\times\dfrac{4}{9} &= \dfrac{12}{90} \\
&= \dfrac{2}{15}
\end{aligned}
$$
:::

::: etape Mettre au même dénominateur et additionner
- $\displaystyle \dfrac{4}{5}=\dfrac{12}{15}$
- $\displaystyle B=\dfrac{12}{15}+\dfrac{2}{15}=\dfrac{14}{15}$
:::

::: resultat
$$B=\dfrac{14}{15}$$
:::

## Question 3 : Calculer $\displaystyle C = \dfrac{\dfrac{3}{7}}{\dfrac{5}{14}}$

::: methode
Diviser par une fraction = multiplier par son inverse
:::

::: etape Remplacer la division
$$
\begin{aligned}
C &= \dfrac{3}{7}\div\dfrac{5}{14} \\
&= \dfrac{3}{7}\times\dfrac{14}{5}
\end{aligned}
$$
:::

::: etape Simplifier avant de multiplier
- $\dfrac{14}{7}=2$ donc $C=3\times\dfrac{2}{5}=\dfrac{6}{5}$
:::

::: resultat
$$C=\dfrac{6}{5}$$
:::

## Question 4 : Calculer $\displaystyle D = \dfrac{1}{2}\left(1-\dfrac{1}{3}\right)^2$

::: methode
Calculer dans la parenthèse, puis élever au carré
:::

::: etape Calculer $\displaystyle \left(1-\dfrac{1}{3}\right)$
- $\displaystyle 1-\dfrac{1}{3}=\dfrac{3}{3}-\dfrac{1}{3}=\dfrac{2}{3}$
:::

::: etape Élever au carré
- $\displaystyle \left(\dfrac{2}{3}\right)^2=\dfrac{4}{9}$
:::

::: etape Multiplier par $\displaystyle \dfrac{1}{2}$
$$
\begin{aligned}
D &= \dfrac{1}{2}\times\dfrac{4}{9} \\
&= \dfrac{4}{18} \\
&= \dfrac{2}{9}
\end{aligned}
$$
:::

::: resultat
$$D=\dfrac{2}{9}$$
:::

## Question 5 : Calculer $\displaystyle E = \dfrac{\dfrac{5}{12}+\dfrac{1}{8}}{\dfrac{7}{6}}$

::: methode
Additionner au numérateur puis diviser par une fraction
:::

::: etape Additionner au numérateur
$$
\begin{aligned}
\dfrac{5}{12}+\dfrac{1}{8} &= \dfrac{10}{24}+\dfrac{3}{24} \\
&= \dfrac{13}{24}
\end{aligned}
$$
:::

::: etape Diviser par $\dfrac{7}{6}$ (multiplier par l'inverse)
$$
\begin{aligned}
E &= \dfrac{13}{24}\div\dfrac{7}{6} \\
&= \dfrac{13}{24}\times\dfrac{6}{7}
\end{aligned}
$$
:::

::: etape Simplifier
- $\dfrac{6}{24}=\dfrac{1}{4}$ donc $E=\dfrac{13}{4\times 7}=\dfrac{13}{28}$
:::

::: resultat
$$E=\dfrac{13}{28}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle A=\dfrac{7}{6}$
2. $\displaystyle B=\dfrac{14}{15}$
3. $\displaystyle C=\dfrac{6}{5}$
4. $\displaystyle D=\dfrac{2}{9}$
5. $\displaystyle E=\dfrac{13}{28}$

- $\displaystyle x \geq 3$

## Question 1 : Simplifier $\displaystyle -3\sqrt{50} + 2\sqrt{8} + \sqrt{72}$

::: methode
Simplifier chaque racine puis réduire les termes semblables
:::

::: etape Simplifier les racines
- $\displaystyle \sqrt{50}=\sqrt{25\times 2}=5\sqrt{2}$
- $\displaystyle \sqrt{8}=\sqrt{4\times 2}=2\sqrt{2}$
- $\displaystyle \sqrt{72}=\sqrt{36\times 2}=6\sqrt{2}$
:::

::: etape Remplacer et réduire
$$
\begin{aligned}
-3\sqrt{50}+2\sqrt{8}+\sqrt{72} &= -3\cdot 5\sqrt{2}+2\cdot 2\sqrt{2}+6\sqrt{2} \\
&= (-15+4+6)\sqrt{2} \\
&= -5\sqrt{2}
\end{aligned}
$$
:::

::: resultat
$$-3\sqrt{50} + 2\sqrt{8} + \sqrt{72}=-5\sqrt{2}$$
:::

## Question 2 : Simplifier $\displaystyle \sqrt{12}\times\sqrt{27}\times\sqrt{3}$

::: methode
Simplifier les racines puis multiplier
:::

::: etape Simplifier $\sqrt{12}$ et $\sqrt{27}$
- $\displaystyle \sqrt{12}=\sqrt{4\times 3}=2\sqrt{3}$
- $\displaystyle \sqrt{27}=\sqrt{9\times 3}=3\sqrt{3}$
:::

::: etape Multiplier
$$
\begin{aligned}
\sqrt{12}\times\sqrt{27}\times\sqrt{3} &= (2\sqrt{3})(3\sqrt{3})(\sqrt{3}) \\
&= 6(\sqrt{3})^3 \\
&= 6\cdot 3\sqrt{3} \\
&= 18\sqrt{3}
\end{aligned}
$$
:::

::: resultat
$$\sqrt{12}\times\sqrt{27}\times\sqrt{3}=18\sqrt{3}$$
:::

## Question 3 : Développer et simplifier $\displaystyle (3\sqrt{2} - 2\sqrt{3})^2$

::: methode
Utiliser $\displaystyle (a-b)^2=a^2-2ab+b^2$
:::

::: etape Identifier $a$ et $b$
- $a=3\sqrt{2}$ et $b=2\sqrt{3}$
:::

::: etape Calculer $a^2$ et $b^2$
- $\displaystyle a^2=(3\sqrt{2})^2=9\cdot 2=18$
- $\displaystyle b^2=(2\sqrt{3})^2=4\cdot 3=12$
:::

::: etape Calculer $\displaystyle 2ab$
- $\displaystyle 2ab=2\cdot (3\sqrt{2})\cdot(2\sqrt{3})=12\sqrt{6}$
:::

::: etape Conclure
- $\displaystyle (3\sqrt{2}-2\sqrt{3})^2=18-12\sqrt{6}+12=30-12\sqrt{6}$
:::

::: resultat
$$(3\sqrt{2} - 2\sqrt{3})^2=30-12\sqrt{6}$$
:::

## Question 4 : Calculer $\displaystyle (5-2\sqrt{6})(5+2\sqrt{6})$

::: methode
Utiliser $\displaystyle (a-b)(a+b)=a^2-b^2$
:::

::: etape Identifier $a$ et $b$
- $a=5$ et $b=2\sqrt{6}$
:::

::: etape Calculer $a^2$ et $b^2$
- $\displaystyle a^2=25$
- $\displaystyle b^2=(2\sqrt{6})^2=4\cdot 6=24$
:::

::: etape Soustraire
- $\displaystyle (5-2\sqrt{6})(5+2\sqrt{6})=25-24=1$
:::

::: resultat
$$(5-2\sqrt{6})(5+2\sqrt{6})=1$$
:::

## Question 5 : Simplifier $\displaystyle \dfrac{20\sqrt{45}}{12\sqrt{5}}$

::: methode
Simplifier la racine puis réduire la fraction
:::

::: etape Simplifier $\displaystyle \sqrt{45}$
- $\displaystyle \sqrt{45}=\sqrt{9\times 5}=3\sqrt{5}$
:::

::: etape Remplacer et simplifier
$$
\begin{aligned}
\dfrac{20\sqrt{45}}{12\sqrt{5}} &= \dfrac{20\cdot 3\sqrt{5}}{12\sqrt{5}} \\
&= \dfrac{60\sqrt{5}}{12\sqrt{5}} \\

\end{aligned}
$$
:::

::: resultat

=== Entraînement - Racines carrées - Simplifier et rationaliser
Id: 1902
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Simplifier les expressions suivantes (extraire les carrés parfaits) et rationaliser quand c'est nécessaire.

1. Simplifier $\displaystyle \sqrt{72}$
2. Simplifier $\displaystyle \sqrt{18} + \sqrt{8}$
3. Simplifier $\displaystyle \sqrt{\dfrac{50}{8}}$
4. Rationaliser $\displaystyle \dfrac{3}{\sqrt{5}}$
5. Rationaliser $\displaystyle \dfrac{2}{\sqrt{3}}$

Étapes:

<!-- optitab:1 -->
## Question 1 : Simplifier $\displaystyle \sqrt{72}$

::: methode
Extraire un carré parfait : $\displaystyle \sqrt{ab}=\sqrt{a}\sqrt{b}$
:::

::: etape Décomposer 72
- $\displaystyle 72 = 36\times 2$
:::

::: etape Extraire $\displaystyle 36$
$$
\begin{aligned}
\sqrt{72} &= \sqrt{36\times 2} \\
&= \sqrt{36}\sqrt{2} \\
&= 6\sqrt{2}
\end{aligned}
$$
:::

::: resultat
$$\sqrt{72}=6\sqrt{2}$$
:::

## Question 2 : Simplifier $\displaystyle \sqrt{18} + \sqrt{8}$

::: methode
Simplifier chaque racine puis réduire
:::

::: etape Simplifier $\displaystyle \sqrt{18}$
- $18=9\times 2$ donc $\sqrt{18}=3\sqrt{2}$
:::

::: etape Simplifier $\displaystyle \sqrt{8}$
- $8=4\times 2$ donc $\sqrt{8}=2\sqrt{2}$
:::

::: etape Réduire
- $\displaystyle \sqrt{18}+\sqrt{8}=3\sqrt{2}+2\sqrt{2}=5\sqrt{2}$
:::

::: resultat
$$\sqrt{18}+\sqrt{8}=5\sqrt{2}$$

## Question 3 : Simplifier $\displaystyle \sqrt{\dfrac{50}{8}}$

::: methode
Simplifier la fraction puis prendre la racine
:::

::: etape Simplifier la fraction
- $\displaystyle \dfrac{50}{8}=\dfrac{25}{4}$
:::

::: etape Prendre la racine
$$
\begin{aligned}
\sqrt{\dfrac{25}{4}} &= \dfrac{\sqrt{25}}{\sqrt{4}} \\
&= \dfrac{5}{2}
\end{aligned}
$$
:::

::: resultat
$$\sqrt{\dfrac{50}{8}}=\dfrac{5}{2}$$
:::

## Question 4 : Rationaliser $\displaystyle \dfrac{3}{\sqrt{5}}$

::: methode
Multiplier numérateur et dénominateur par $\sqrt{5}$
:::

::: etape Multiplier par $\displaystyle \dfrac{\sqrt{5}}{\sqrt{5}}$
$$
\begin{aligned}
\dfrac{3}{\sqrt{5}} &= \dfrac{3}{\sqrt{5}}\times\dfrac{\sqrt{5}}{\sqrt{5}} \\
&= \dfrac{3\sqrt{5}}{(\sqrt{5})^2}
\end{aligned}
$$
:::

::: etape Simplifier le dénominateur
- $\displaystyle (\sqrt{5})^2=5$
:::

::: resultat
$$\dfrac{3}{\sqrt{5}}=\dfrac{3\sqrt{5}}{5}$$
:::

## Question 5 : Rationaliser $\displaystyle \dfrac{2}{\sqrt{3}}$

Multiplier numérateur et dénominateur par $\sqrt{3}$

::: etape Multiplier par $\displaystyle \dfrac{\sqrt{3}}{\sqrt{3}}$

\begin{aligned}
\dfrac{2}{\sqrt{3}} &= \dfrac{2}{\sqrt{3}}\times\dfrac{\sqrt{3}}{\sqrt{3}} \\
&= \dfrac{2\sqrt{3}}{(\sqrt{3})^2}
\end{aligned}
$$
:::

::: etape Simplifier
- $(\sqrt{3})^2=3$ donc $\dfrac{2\sqrt{3}}{3}$
:::

::: resultat
$$\dfrac{2}{\sqrt{3}}=\dfrac{2\sqrt{3}}{3}$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle \sqrt{72}=6\sqrt{2}$
2. $\displaystyle \sqrt{18}+\sqrt{8}=5\sqrt{2}$
3. $\displaystyle \sqrt{\dfrac{50}{8}}=\dfrac{5}{2}$
4. $\displaystyle \dfrac{3}{\sqrt{5}}=\dfrac{3\sqrt{5}}{5}$
5. $\displaystyle \dfrac{2}{\sqrt{3}}=\dfrac{2\sqrt{3}}{3}$

=== Entraînement - Tableau de signes - Équations et inéquations produit ou quotient
Id: 3736
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Résoudre dans $\mathbb{R}$ les équations et inéquations suivantes. Pour les inéquations, utiliser un tableau de signes et donner l’ensemble des solutions sous forme d’intervalle.

1. $(3x-6)(x+4)=0$
2. $(3x-6)(x+4)<0$
3. $\dfrac{x+1}{2-x}\ge 0$
4. $x^2\le 4x$

Étapes:

<!-- optitab:1 -->
## Question 1 : Résoudre $(3x-6)(x+4)=0$

::: methode
Un produit est nul si et seulement si l’un de ses facteurs est nul
:::

::: etape Annuler chaque facteur
- $3x-6=0 \iff 3x=6 \iff x=2$
- $x+4=0 \iff x=-4$
:::

::: resultat
$$S=\{-4\,;2\}$$
:::

## Question 2 : Résoudre $(3x-6)(x+4)<0$

::: methode
Tableau de signes : une ligne par facteur, puis la règle des signes
:::

::: etape Signe de chaque facteur
- $3x-6$ s’annule en $2$ ; son coefficient $3$ est positif : il est négatif avant $2$ et positif après.
- $x+4$ s’annule en $-4$ ; son coefficient $1$ est positif : il est négatif avant $-4$ et positif après.
:::

::: etape Tableau de signes
Les valeurs $-4$ et $2$ sont rangées dans l’ordre croissant sur la première ligne ; la dernière ligne applique la règle des signes au produit $(3x-6)(x+4)$.
:::

::: tableau
x : -\infty, -4, 2, +\infty
3x-6 : , -, t, -, z, +,
x+4 : , -, z, +, t, +,
Produit : , +, z, -, z, +,
:::

::: etape Lire le tableau
On cherche où le produit est **strictement négatif** : entre $-4$ et $2$, bornes exclues (le produit y vaut $0$).
:::

::: resultat
$$S={]-4\,;2[}$$
:::

## Question 3 : Résoudre $\dfrac{x+1}{2-x}\ge 0$

::: methode
Tableau de signes du quotient, avec une double barre pour la valeur interdite
:::

::: etape Valeur interdite
$2-x=0 \iff x=2$ : le quotient n’existe pas pour $x=2$.
:::

::: etape Signe de chaque terme
- $x+1$ s’annule en $-1$ ; coefficient $1>0$ : négatif avant $-1$, positif après.
- $2-x$ s’annule en $2$ ; coefficient $-1<0$ : positif avant $2$, négatif après.
:::

::: etape Tableau de signes
La dernière ligne donne le signe du quotient $\dfrac{x+1}{2-x}$ ; la double barre marque la valeur interdite $2$.
:::

::: tableau
x : -\infty, -1, 2, +\infty
x+1 : , -, z, +, t, +,
2-x : , +, t, +, z, -,
Quotient : , -, z, +, d, -,
:::

::: etape Lire le tableau
Le quotient est positif ou nul sur $[-1\,;2[$ : $-1$ est inclus (le quotient y vaut $0$), $2$ est exclu (valeur interdite).
:::

::: attention
Erreur fréquente : fermer le crochet en $2$. Une valeur interdite n’est jamais solution, même avec « $\ge$ ».
:::

::: resultat
$$S={[-1\,;2[}$$
:::

## Question 4 : Résoudre $x^2\le 4x$

::: methode
Tout ramener dans un membre, factoriser, puis tableau de signes
:::

::: etape Se ramener à une comparaison à 0
$$
\begin{aligned}
x^2 \le 4x &\iff x^2-4x \le 0 \\
&\iff x(x-4) \le 0
\end{aligned}
$$
:::

::: etape Tableau de signes
Deux facteurs : $x$ (nul en $0$) et $x-4$ (nul en $4$). La dernière ligne donne le signe du produit $x(x-4)$.
:::

::: tableau
x : -\infty, 0, 4, +\infty
Facteur $x$ : , -, z, +, t, +,
x-4 : , -, t, -, z, +,
Produit : , +, z, -, z, +,
:::

::: etape Lire le tableau
Le produit est négatif ou nul entre $0$ et $4$, bornes incluses (le produit y vaut $0$).
:::

::: attention
Diviser les deux membres par $x$ pour obtenir « $x\le 4$ » est faux : on ne connaît pas le signe de $x$, et l’on perdrait toutes les solutions négatives ou nulles comme $x=0$.
:::

::: resultat
$$S=[0\,;4]$$
:::

Solution:
<!-- optitab:1 -->
1. $S=\{-4\,;2\}$
2. $S={]-4\,;2[}$
3. $S={[-1\,;2[}$ (la valeur interdite $2$ est exclue)
4. $x^2\le 4x \iff x(x-4)\le 0$, donc $S=[0\,;4]$

=== Maîtrise - Calcul sur expressions - Développer, réduire et factoriser
Id: 1904
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Développer/réduire ou factoriser selon la consigne.

1. Développer et réduire $\displaystyle (2x + 3)(x - 5) + (x + 1)^2$
2. Factoriser $\displaystyle 9x^2 - 16 + (3x + 4)(x - 2)$
3. Simplifier $\displaystyle (x-2)(x+2) - (x-2)^2$
4. Développer et réduire $\displaystyle (x+2)(x+5) - (x+3)(x+4)$
5. Factoriser $\displaystyle (x+1)(x+4) + (x+1)(2x-3)$

Étapes:

<!-- optitab:1 -->
## Question 1 : Développer et réduire $\displaystyle (2x + 3)(x - 5) + (x + 1)^2$

::: methode
Double distributivité + identité remarquable + réduction
:::

::: etape Développer $\displaystyle (2x+3)(x-5)$
$$
\begin{aligned}
(2x+3)(x-5) &= 2x\cdot x +2x\cdot(-5)+3\cdot x+3\cdot(-5) \\
&= 2x^2-10x+3x-15 \\
&= 2x^2-7x-15
\end{aligned}
$$
:::

::: etape Développer $\displaystyle (x+1)^2$
- $\displaystyle (x+1)^2=x^2+2x+1$
:::

::: etape Additionner et réduire
- $\displaystyle (2x^2-7x-15)+(x^2+2x+1)=3x^2-5x-14$
:::

::: resultat
$$(2x + 3)(x - 5) + (x + 1)^2 = 3x^2 - 5x - 14$$
:::

## Question 2 : Factoriser $\displaystyle 9x^2 - 16 + (3x + 4)(x - 2)$

::: methode
Différence de carrés + factorisation par facteur commun
:::

::: etape Factoriser $\displaystyle 9x^2-16$
- $\displaystyle 9x^2-16=(3x)^2-4^2=(3x-4)(3x+4)$
:::

::: etape Mettre $\displaystyle (3x+4)$ en facteur
- $\displaystyle (3x-4)(3x+4)+(3x+4)(x-2)=(3x+4)\big((3x-4)+(x-2)\big)$
:::

::: etape Simplifier
- $\displaystyle (3x-4)+(x-2)=4x-6=2(2x-3)$
:::

::: resultat
$$9x^2 - 16 + (3x + 4)(x - 2)=2(3x+4)(2x-3)$$
:::

## Question 3 : Simplifier $\displaystyle (x-2)(x+2) - (x-2)^2$

::: methode
Développer ou utiliser des identités remarquables puis réduire
:::

::: etape Utiliser la différence de carrés
- $\displaystyle (x-2)(x+2)=x^2-4$
:::

::: etape Développer $\displaystyle (x-2)^2$
- $\displaystyle (x-2)^2=x^2-4x+4$
:::

::: etape Soustraire et réduire
- $\displaystyle (x^2-4)-(x^2-4x+4)=4x-8=4(x-2)$
:::

::: resultat
$$(x-2)(x+2) - (x-2)^2 = 4(x-2)$$
:::

## Question 4 : Développer et réduire $\displaystyle (x+2)(x+5) - (x+3)(x+4)$

::: methode
Développer puis réduire
:::

::: etape Développer chaque produit
- $\displaystyle (x+2)(x+5)=x^2+7x+10$
- $\displaystyle (x+3)(x+4)=x^2+7x+12$
:::

::: etape Soustraire
- $\displaystyle (x^2+7x+10)-(x^2+7x+12)=-2$
:::

::: resultat
$$(x+2)(x+5) - (x+3)(x+4) = -2$$
:::

## Question 5 : Factoriser $\displaystyle (x+1)(x+4) + (x+1)(2x-3)$

::: methode
Mettre le facteur commun en évidence
:::

::: etape Identifier le facteur commun
- Les deux termes contiennent $\displaystyle (x+1)$
:::

::: etape Factoriser
- $\displaystyle (x+1)(x+4)+(x+1)(2x-3)=(x+1)\big((x+4)+(2x-3)\big)$
:::

::: etape Simplifier l'intérieur
- $\displaystyle (x+4)+(2x-3)=3x+1$
:::

::: resultat
$$(x+1)(x+4) + (x+1)(2x-3)=(x+1)(3x+1)$$
:::

Solution:
<!-- optitab:1 -->
1. $\displaystyle (2x + 3)(x - 5) + (x + 1)^2 = 3x^2 - 5x - 14$
2. $\displaystyle 9x^2 - 16 + (3x + 4)(x - 2)=2(3x+4)(2x-3)$
3. $\displaystyle (x-2)(x+2) - (x-2)^2 = 4(x-2)$
4. $\displaystyle (x+2)(x+5) - (x+3)(x+4) = -2$
5. $\displaystyle (x+1)(x+4) + (x+1)(2x-3)=(x+1)(3x+1)$

=== Problème - Choisir la forme adaptée - Trois écritures d’une même expression
Id: 3738
Difficulté: hard

Énoncé: <!-- optitab:1 -->
Pour tout réel $x$, on pose $f(x)=(x-1)^2-4$.

1. Montrer que, pour tout réel $x$ :
   - a) $f(x)=x^2-2x-3$ (forme développée) ;
   - b) $f(x)=(x-3)(x+1)$ (forme factorisée).
2. En choisissant à chaque fois la forme la plus adaptée :
   - a) calculer $f(0)$ ;
   - b) résoudre $f(x)=0$ ;
   - c) résoudre $f(x)=-3$ ;
   - d) résoudre $f(x)=5$.
3. Montrer que $f(x)\ge -4$ pour tout réel $x$. Pour quelle valeur de $x$ a-t-on $f(x)=-4$ ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Établir les trois écritures

::: methode
a) développer avec $(a-b)^2$ ; b) factoriser avec $a^2-b^2$
:::

::: etape a) Forme développée
$$
\begin{aligned}
f(x) &= (x-1)^2-4 \\
&= x^2-2x+1-4 \\
&= x^2-2x-3
\end{aligned}
$$
:::

::: etape b) Forme factorisée
On reconnaît $a^2-b^2$ avec $a=x-1$ et $b=2$ (car $4=2^2$) :
$$
\begin{aligned}
f(x) &= (x-1)^2-2^2 \\
&= (x-1-2)(x-1+2) \\
&= (x-3)(x+1)
\end{aligned}
$$
:::

::: point Vérification
Pour $x=0$ : $(0-1)^2-4=-3$, $0^2-0-3=-3$ et $(0-3)(0+1)=-3$. Les trois écritures concordent.
:::

::: resultat
$f(x)=(x-1)^2-4=x^2-2x-3=(x-3)(x+1)$
:::

## Question 2 : Choisir la forme adaptée

::: methode
Forme développée pour $f(0)$ ; forme factorisée pour $f(x)=0$ ; forme qui fait disparaître la constante ou qui isole un carré pour les autres équations
:::

::: etape a) Calcul de $f(0)$ : forme développée
$f(0)=0^2-2\times 0-3=-3$
:::

::: etape b) $f(x)=0$ : forme factorisée
$$(x-3)(x+1)=0 \iff x-3=0 \text{ ou } x+1=0$$
donc $x=3$ ou $x=-1$.
:::

::: etape c) $f(x)=-3$ : forme développée
$$
\begin{aligned}
x^2-2x-3=-3 &\iff x^2-2x=0 \\
&\iff x(x-2)=0
\end{aligned}
$$
donc $x=0$ ou $x=2$.
:::

::: etape d) $f(x)=5$ : forme de départ
$$
\begin{aligned}
(x-1)^2-4=5 &\iff (x-1)^2=9 \\
&\iff x-1=-3 \text{ ou } x-1=3
\end{aligned}
$$
donc $x=-2$ ou $x=4$.
:::

::: attention
Avec la forme factorisée, $f(x)=5$ donnerait $(x-3)(x+1)=5$ : la règle du produit nul ne s’applique **pas** quand le second membre n’est pas $0$.
:::

::: resultat
- a) $f(0)=-3$
- b) $S=\{-1\,;3\}$
- c) $S=\{0\,;2\}$
- d) $S=\{-2\,;4\}$
:::

## Question 3 : Montrer que $f(x)\ge -4$

::: methode
Étudier le signe de la différence $f(x)-(-4)$
:::

::: etape Calculer la différence
$$
\begin{aligned}
f(x)-(-4) &= (x-1)^2-4+4 \\
&= (x-1)^2
\end{aligned}
$$
:::

::: etape Conclure
Un carré est toujours positif ou nul : $(x-1)^2\ge 0$, donc $f(x)\ge -4$ pour tout réel $x$. L’égalité a lieu lorsque $(x-1)^2=0$, c’est-à-dire $x=1$.
:::

::: resultat
$f(x)\ge -4$ pour tout réel $x$, et $f(x)=-4$ uniquement pour $x=1$ : $-4$ est le minimum de $f$.
:::

Solution:
<!-- optitab:1 -->
1. a) $(x-1)^2-4=x^2-2x+1-4=x^2-2x-3$ ; b) $(x-1)^2-2^2=(x-3)(x+1)$
2. a) $f(0)=-3$ ; b) $S=\{-1\,;3\}$ ; c) $S=\{0\,;2\}$ ; d) $S=\{-2\,;4\}$
3. $f(x)-(-4)=(x-1)^2\ge 0$ ; $f(x)=-4$ pour $x=1$

=== Problème - Modéliser par une inéquation - Abonnement
Id: 1909
Difficulté: medium
Image: v1_n167_ex1909_1_ex_abonnement.png

Énoncé: <!-- optitab:1 -->
Un club de sport propose deux formules pour l’année :

- formule A : un abonnement de 30 € puis 5 € par séance ;
- formule B : 8 € par séance, sans abonnement.

On note $x$ le nombre de séances suivies dans l’année ($x$ est un entier naturel).

1. Exprimer, en euros, le coût $C_A(x)$ de la formule A et le coût $C_B(x)$ de la formule B.
2. Résoudre l’équation $C_A(x)=C_B(x)$ et interpréter le résultat.
3. Résoudre l’inéquation $C_A(x)<C_B(x)$.
4. Calculer les coûts des deux formules pour $12$ séances et vérifier la cohérence avec la question 3.
5. À partir de combien de séances la formule A est-elle la moins chère ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Exprimer les coûts $C_A(x)$ et $C_B(x)$

::: methode
Traduire l’énoncé : partie fixe + prix d’une séance $\times$ nombre de séances
:::

::: etape Formule A
- Partie fixe : $30$ €.
- $x$ séances à $5$ € coûtent $5x$ €.
- Donc $C_A(x)=30+5x$.
:::

::: etape Formule B
- Pas de partie fixe ; $x$ séances à $8$ € coûtent $8x$ €.
- Donc $C_B(x)=8x$.
:::

::: resultat
$C_A(x)=30+5x$ et $C_B(x)=8x$
:::

## Question 2 : Résoudre l’équation $C_A(x)=C_B(x)$ et interpréter

::: methode
Regrouper les termes en $x$ dans un même membre, puis isoler $x$
:::

::: etape Écrire l’équation
$$30+5x=8x$$
:::

::: etape Isoler $x$
$$
\begin{aligned}
30 &= 8x-5x \\
30 &= 3x \\
x &= 10
\end{aligned}
$$
Vérification : $C_A(10)=30+50=80$ et $C_B(10)=80$.
:::

::: resultat
Les deux formules coûtent pareil pour $x=10$ séances
:::

## Question 3 : Résoudre l’inéquation $C_A(x)<C_B(x)$

::: methode
Mêmes opérations que pour l’équation ; on divise par $3>0$, donc le sens est conservé
:::

::: etape Écrire l’inéquation
$$30+5x<8x$$
:::

::: etape Résoudre
$$
\begin{aligned}
30 &< 8x-5x \\
30 &< 3x \\
10 &< x
\end{aligned}
$$
:::

::: etape Lecture graphique
La droite de la formule A (en bleu) passe sous celle de la formule B (en vert) à droite du point d’intersection d’abscisse $10$.
:::

[IMAGE_1]

::: resultat
$C_A(x) \lt C_B(x) \iff x \gt 10$
:::

## Question 4 : Calculer les coûts pour $12$ séances

::: methode
Substitution
:::

::: etape Calculer $\displaystyle C_A(12)$
- $\displaystyle C_A(12)=30+5\times 12=30+60=90$
:::

::: etape Calculer $\displaystyle C_B(12)$
- $\displaystyle C_B(12)=8\times 12=96$
:::

::: resultat
Pour $12$ séances : $90$ € avec A et $96$ € avec B. A est moins chère, ce qui est cohérent avec $12>10$.
:::

## Question 5 : À partir de combien de séances A est-elle la moins chère ?

::: methode
Traduire $x>10$ pour un nombre entier de séances
:::

::: etape Passer aux entiers
$x$ est un entier naturel : $x>10$ signifie $x\ge 11$.
:::

::: etape Contrôle autour de la valeur frontière
- $9$ séances : $C_A(9)=75$ € et $C_B(9)=72$ € : B est moins chère.
- $11$ séances : $C_A(11)=85$ € et $C_B(11)=88$ € : A est moins chère.
:::

::: attention
Pour $10$ séances, les deux formules coûtent $80$ € : A n’est pas **moins** chère. La réponse n’est donc pas « à partir de 10 séances ».
:::

::: resultat
La formule A est la moins chère à partir de $11$ séances.
:::

Solution:
<!-- optitab:1 -->
1. $C_A(x)=30+5x$ et $C_B(x)=8x$
2. $x=10$ : pour $10$ séances, les deux formules coûtent $80$ €.
3. $C_A(x) \lt C_B(x) \iff x \gt 10$
4. $C_A(12)=90$ € et $C_B(12)=96$ € : A est moins chère.
5. À partir de $11$ séances.
