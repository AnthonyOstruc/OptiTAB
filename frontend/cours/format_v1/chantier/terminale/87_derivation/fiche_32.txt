Titre: Résumé : Dérivation et convexité

<!-- optitab:1 -->
::: objectifs
Retenir l’essentiel : dérivée d’une composée, dérivée seconde, convexité, point d’inflexion, inégalités de convexité. Programme de Terminale.
:::

## I. Fonctions composées

::: formule
$$(v \circ u)'(x) = v'\big(u(x)\big) \times u'(x)$$
:::

[IMAGE_1]

| Fonction | Dérivée | Condition |
|---|---|---|
| $g(ax + b)$ | $a\,g'(ax + b)$ |  |
| $u^n$ | $n\,u'\,u^{n-1}$ |  |
| $\dfrac{1}{u}$ | $-\dfrac{u'}{u^2}$ | $u \neq 0$ |
| $\sqrt{u}$ | $\dfrac{u'}{2\sqrt{u}}$ | $u \gt 0$ |
| $e^u$ | $u'\,e^u$ |  |
| $\ln u$ | $\dfrac{u'}{u}$ | $u \gt 0$ |

## II. Convexité et point d’inflexion

1. **Convexe** sur $I$ : courbe sous ses sécantes $\iff$ au-dessus de ses tangentes $\iff$ $f'$ croissante $\iff$ $f'' \ge 0$ sur $I$.
2. **Concave** sur $I$ : courbe au-dessus de ses sécantes $\iff$ en dessous de ses tangentes $\iff$ $f'' \le 0$ sur $I$.
3. **Point d’inflexion** : $f''$ s’annule **en changeant de signe** ; la courbe traverse sa tangente.

::: tableau Exemple : $f(x) = x^3 - 3x$, $f''(x) = 6x$
x : -\infty, 0, +\infty
f''(x) : , -, z, +,
Convexité de $f$ : , concave, t, convexe,
:::

## III. Inégalités de convexité

::: methode Réflexe
Inégalité du type « $f(x) \ge$ une droite » → convexité de $f$ et tangente : une fonction convexe est au-dessus de ses tangentes, une fonction concave en dessous.
:::

::: retenir
$e^x \ge x + 1$ pour tout réel $x$ (exp convexe, tangente en $0$) ; $\ln x \le x - 1$ pour tout $x \gt 0$ ($\ln$ concave, tangente en $1$).
:::

## IV. Les pièges à éviter

::: attention Les 4 erreurs classiques
1. Oublier le facteur $u'$ : $\left(e^{3x}\right)' = 3e^{3x}$, pas $e^{3x}$.
2. Étudier le signe de $f'$ au lieu de celui de $f''$ pour la convexité.
3. Conclure à un point d’inflexion dès que $f''(a) = 0$ : pour $x^4$, $f''(0) = 0$ mais pas d’inflexion.
4. Confondre convexe (« en creux ») et croissante.
:::
