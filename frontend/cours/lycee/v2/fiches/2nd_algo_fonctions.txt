<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Écrire une fonction</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">1️⃣ <code>def nom(arguments):</code> puis un bloc indenté.</p>
<p style="margin:6px 0 0 0;">2️⃣ <code>return</code> renvoie le résultat et arrête la fonction.</p>
<p style="margin:6px 0 0 0;">3️⃣ Appel : <code>nom(valeurs)</code>, dans le même ordre que les arguments.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Simuler et répéter</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ <code>randint(a, b)</code> : entier au hasard entre $a$ et $b$ inclus.</p>
<p style="margin:6px 0 0 0;">2️⃣ <code>random()</code> : nombre au hasard dans $[0\,;1[$ ; <code>random() &lt; p</code> est vrai avec la probabilité $p$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Compteur initialisé à $0$ avant la boucle, fréquence = compteur $/ n$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Utiliser <code>print</code> au lieu de <code>return</code> : le résultat n’est pas réutilisable.</p>
<p style="margin:6px 0 0 0;">2️⃣ Oublier d’importer <code>randint</code>, <code>random</code> ou <code>sqrt</code>.</p>
<p style="margin:6px 0 0 0;">3️⃣ Initialiser un compteur à l’intérieur de la boucle.</p>
<p style="margin:6px 0 0 0;">4️⃣ Placer le <code>return</code> dans la boucle : la fonction s’arrête dès le premier tour.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> entrée → arguments, sortie → <code>return</code> ; je teste toujours ma fonction sur un cas dont je connais la réponse.</p>
</div>
