Titre: Résumé : Équations Différentielles

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">I. Définition et forme générale</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Définition :</strong> Une équation différentielle met en relation une fonction $y(x)$ avec sa dérivée $y'(x)$
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Forme au bac :</strong> $\displaystyle y' = ay + b$ où $a$ et $b$ sont des constantes
        </div>
        <div style="background:#e8f4fd; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #3498db;">
            <strong>Solution générale :</strong> $\displaystyle y(x) = Ce^{ax} - \frac{b}{a}$ (si $a \neq 0$)
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">II. Méthode de résolution</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
            <strong>📐 Étapes de résolution :</strong>
            <ol style="margin:10px 0; padding-left:20px;">
                <li><strong>Résoudre l'équation homogène</strong> : $y' = ay$ → $y_h = Ce^{ax}$</li>
                <li><strong>Trouver une solution particulière</strong> : chercher une constante $y_p = k$</li>
                <li><strong>Additionner les solutions</strong> : $y = y_h + y_p$</li>
                <li><strong>Appliquer la condition initiale</strong> : déterminer $C$ avec $y(x_0) = y_0$</li>
            </ol>
        </div>
        
        <div style="background:#f8f9fa; padding:15px; border-radius:6px; margin:15px 0;">
            <strong>Exemple :</strong> Résoudre $y' = 2y + 4$ avec $y(0) = 1$
            <p style="margin:8px 0; font-size:1em;">• Équation homogène : $y' = 2y$ → $y_h = Ce^{2x}$</p>
            <p style="margin:8px 0; font-size:1em;">• Solution particulière : $y_p = k$, donc $0 = 2k + 4$ → $k = -2$</p>
            <p style="margin:8px 0; font-size:1em;">• Solution générale : $y = Ce^{2x} - 2$</p>
            <p style="margin:8px 0; font-size:1em;">• Condition initiale : $y(0) = 1$ → $1 = C - 2$ → $C = 3$</p>
            <p style="margin:8px 0; font-size:1em;"><strong>Solution finale :</strong> $y = 3e^{2x} - 2$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">IV. Applications classiques</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Modèles de croissance et décroissance</h3>
        
        <table style="width:100%; border-collapse:collapse; margin:15px 0; border:2px solid #3498db;">
            <thead>
                <tr style="background:#3498db; color:white;">
                    <th style="border:1px solid #ddd; padding:12px;">Phénomène</th>
                    <th style="border:1px solid #ddd; padding:12px;">Équation</th>
                    <th style="border:1px solid #ddd; padding:12px;">Solution</th>
                </tr>
            </thead>
            <tbody>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Croissance exponentielle</td>
                    <td style="border:1px solid #ddd; padding:10px;">$P' = kP$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$P(t) = P_0 e^{kt}$</td>
                </tr>
                <tr style="background:#ffffff;">
                    <td style="border:1px solid #ddd; padding:10px;">Décroissance radioactive</td>
                    <td style="border:1px solid #ddd; padding:10px;">$N' = -\lambda N$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$N(t) = N_0 e^{-\lambda t}$</td>
                </tr>
                <tr style="background:#f8f9fa;">
                    <td style="border:1px solid #ddd; padding:10px;">Refroidissement</td>
                    <td style="border:1px solid #ddd; padding:10px;">$T' = -k(T - T_a)$</td>
                    <td style="border:1px solid #ddd; padding:10px;">$T(t) = T_a + (T_0 - T_a)e^{-kt}$</td>
                </tr>
            </tbody>
        </table>
        
        <div style="background:#f0f9f0; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #10b981;">
            <strong>💡 Demi-vie :</strong> Pour la décroissance radioactive, $\displaystyle T_{1/2} = \frac{\ln 2}{\lambda}$
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">V. Vérification d'une solution</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#fef3c7; padding:15px; border-radius:6px; margin:10px 0;">
            <strong>📐 Méthode de vérification :</strong>
            <ol style="margin:10px 0; padding-left:20px;">
                <li><strong>Dériver</strong> la solution proposée $y(x)$</li>
                <li><strong>Calculer</strong> $ay + b$ avec la solution proposée</li>
                <li><strong>Vérifier</strong> que $y' = ay + b$</li>
                <li><strong>Vérifier</strong> la condition initiale si elle est donnée</li>
            </ol>
        </div>
        
        <div style="background:#f8f9fa; padding:15px; border-radius:6px; margin:15px 0;">
            <strong>Exemple :</strong> Vérifier que $y = 3e^{2x} - 2$ est solution de $y' = 2y + 4$ avec $y(0) = 1$
            <p style="margin:8px 0; font-size:1em;">• Dérivée : $y' = 6e^{2x}$</p>
            <p style="margin:8px 0; font-size:1em;">• Calcul : $2y + 4 = 2(3e^{2x} - 2) + 4 = 6e^{2x} - 4 + 4 = 6e^{2x}$ ✅</p>
            <p style="margin:8px 0; font-size:1em;">• Condition : $y(0) = 3e^0 - 2 = 3 - 2 = 1$ ✅</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VI. Séparation des variables (hors programme bac)</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; padding:15px; border-radius:6px; margin:10px 0; border-left:6px solid #3498db;">
            <p style="margin:8px 0;"><strong>Méthode :</strong> Pour $y' = g(x)h(y)$, on sépare : $\displaystyle\frac{dy}{h(y)} = g(x)dx$</p>
        </div>
        
        <div style="background:#f8f9fa; padding:15px; border-radius:6px; margin:15px 0;">
            <strong>Exemple :</strong> $y' = 2xy$
            <p style="margin:8px 0; font-size:1em;">$\displaystyle\frac{dy}{y} = 2x \, dx$</p>
            <p style="margin:8px 0; font-size:1em;">$\displaystyle\ln|y| = x^2 + C$</p>
            <p style="margin:8px 0; font-size:1em;">$\displaystyle y = Ke^{x^2}$</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:3px solid #3498db; padding-bottom:8px;">VII. Exemples résolus</h2>
    
    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple 1 :</strong> $y' = -y + 3$ avec $y(0) = 5$
            <p style="margin:8px 0; font-size:1em;">Solution : $y = 3 + 2e^{-x}$</p>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple 2 :</strong> $y' = 3y - 6$ avec $y(0) = 4$
            <p style="margin:8px 0; font-size:1em;">Solution : $y = 2 + 2e^{3x}$</p>
        </div>
        
        <div style="background:#f8f9fa; padding:12px; border-radius:4px; margin:10px 0; border-left:6px solid #6c757d;">
            <strong>Exemple 3 :</strong> Population avec $P' = 0.05P$ et $P(0) = 1000$
            <p style="margin:8px 0; font-size:1em;">Solution : $P(t) = 1000e^{0.05t}$</p>
            <p style="margin:8px 0; font-size:1em;">Après 10 ans : $P(10) = 1000e^{0.5} \approx 1649$ individus</p>
        </div>
    </div>
