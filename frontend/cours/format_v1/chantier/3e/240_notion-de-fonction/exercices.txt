=== Découverte - Calculer des images
Id: 2275
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f : x \longmapsto 3x - 4$.

1. Calculer $f(0)$ et $f(2)$.
2. Calculer $f(-3)$.
3. Calculer $f\left(\dfrac{1}{3}\right)$.
4. Compléter la phrase : « … est l'image de $-3$ par $f$ ».

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $f(0)$ et $f(2)$

::: methode
Pour calculer une image, on remplace $x$ par le nombre dans $3x - 4$.
:::

::: etape Remplacer $x$ par $0$, puis par $2$
$$
\begin{aligned}
f(0) &= 3 \times 0 - 4 = -4 \\
f(2) &= 3 \times 2 - 4 = 6 - 4 = 2
\end{aligned}
$$
:::

::: resultat
$f(0) = -4$ et $f(2) = 2$.
:::

## Question 2 : Calculer $f(-3)$

::: etape Remplacer $x$ par $(-3)$, entre parenthèses
$$
\begin{aligned}
f(-3) &= 3 \times (-3) - 4 \\
&= -9 - 4 \\
&= -13
\end{aligned}
$$
:::

::: resultat
$f(-3) = -13$
:::

## Question 3 : Calculer $f\left(\dfrac{1}{3}\right)$

::: etape Simplifier le produit
$$
\begin{aligned}
f\left(\dfrac{1}{3}\right) &= 3 \times \dfrac{1}{3} - 4 \\
&= 1 - 4 \\
&= -3
\end{aligned}
$$
:::

::: resultat
$f\left(\dfrac{1}{3}\right) = -3$
:::

## Question 4 : Compléter la phrase

::: methode
L'image de $-3$ est le nombre $f(-3)$, calculé à la question 2.
:::

::: resultat
« $-13$ est l'image de $-3$ par $f$ ».
:::

::: attention Erreur fréquente
Écrire $3 \times -3$ sans parenthèses, ou calculer $3 - 3 - 4$ : le nombre négatif se met **entre parenthèses** avant de calculer.
:::

Solution:
<!-- optitab:1 -->
1. $f(0) = -4$ et $f(2) = 2$.
2. $f(-3) = -13$.
3. $f\left(\dfrac{1}{3}\right) = -3$.
4. $-13$ est l'image de $-3$ par $f$.

=== Découverte - Lire un tableau de valeurs
Id: 2276
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Voici un tableau de valeurs d'une fonction $f$.

| $x$ | $-2$ | $0$ | $1$ | $3$ | $4$ |
|---|---|---|---|---|---|
| $f(x)$ | $5$ | $1$ | $-1$ | $1$ | $5$ |

1. Donner $f(-2)$.
2. Donner l'image de $1$.
3. Donner les antécédents de $1$ qui figurent dans le tableau.
4. Écrire deux égalités qui montrent que $5$ a au moins deux antécédents.
5. Le tableau permet-il de connaître $f(2)$ ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Donner $f(-2)$

::: methode
$f(-2)$ est l'image de $-2$ : on lit la case située **sous** $-2$.
:::

::: resultat
$f(-2) = 5$
:::

## Question 2 : L'image de $1$

::: etape Lire la colonne de $x = 1$
Dans la colonne où $x = 1$, on lit $f(x) = -1$.
:::

::: resultat
L'image de $1$ est $-1$ : $f(1) = -1$.
:::

## Question 3 : Les antécédents de $1$

::: methode
Les antécédents de $1$ sont les nombres $x$ dont l'image vaut $1$ : on cherche $1$ dans la **seconde** ligne.
:::

::: etape Repérer les cases où $f(x) = 1$
On trouve $1$ sous $x = 0$ et sous $x = 3$ : $f(0) = 1$ et $f(3) = 1$.
:::

::: resultat
Les antécédents de $1$ présents dans le tableau sont $0$ et $3$.
:::

## Question 4 : Deux antécédents de $5$

::: etape Chercher $5$ dans la seconde ligne
$5$ apparaît sous $x = -2$ et sous $x = 4$.
:::

::: resultat
$f(-2) = 5$ et $f(4) = 5$ : $-2$ et $4$ sont deux antécédents de $5$.
:::

## Question 5 : Peut-on connaître $f(2)$ ?

::: etape Chercher $2$ dans la première ligne
Le nombre $2$ n'est pas dans la ligne des $x$.
:::

::: resultat
Non : le tableau ne donne pas l'image de $2$. Il faudrait connaître la formule de $f$ (ou sa courbe).
:::

::: attention Erreur fréquente
Chercher l'antécédent dans la mauvaise ligne : on cherche une **image** dans la ligne des $x$, mais un **antécédent** se trouve en partant de la ligne des $f(x)$.
:::

Solution:
<!-- optitab:1 -->
1. $f(-2) = 5$.
2. $f(1) = -1$.
3. $0$ et $3$.
4. $f(-2) = 5$ et $f(4) = 5$.
5. Non : $2$ n'est pas dans le tableau.

=== Découverte - Traduire des phrases
Id: 2277
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire avec la notation $g(\ldots) = \ldots$ : « $7$ est l'image de $-1$ par la fonction $g$ ».
2. Écrire en deux phrases différentes ce que signifie l'égalité $g(4) = 7$.
3. Les égalités $g(-1) = 7$ et $g(4) = 7$ peuvent-elles être vraies pour la même fonction $g$ ?
4. Écrire avec la notation $h(\ldots) = \ldots$ : « $-5$ est un antécédent de $2$ par la fonction $h$ ».
5. Peut-on avoir à la fois $h(2) = 3$ et $h(2) = 6$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Traduire la première phrase

::: methode
Dans $g(a) = b$, le nombre de départ $a$ est dans la parenthèse et l'image $b$ est après le signe $=$.
:::

::: etape Repérer le nombre de départ et l'image
Le nombre de départ est $-1$ ; son image est $7$.
:::

::: resultat
$g(-1) = 7$
:::

## Question 2 : Le sens de $g(4) = 7$

::: etape Lire l'égalité dans les deux sens
- De gauche à droite : le nombre $4$ a pour image $7$.
- De droite à gauche : $7$ est obtenu à partir de $4$, donc $4$ est un antécédent de $7$.
:::

::: resultat
« $7$ est l'image de $4$ par $g$ » et « $4$ est un antécédent de $7$ par $g$ ».
:::

## Question 3 : Les deux égalités ensemble

::: etape Ce que disent les deux égalités
Les nombres $-1$ et $4$ auraient la même image $7$ : le nombre $7$ aurait deux antécédents.
:::

::: resultat
Oui : un nombre peut avoir plusieurs antécédents.
:::

## Question 4 : Traduire la seconde phrase

::: etape Repérer le nombre de départ et l'image
« $-5$ est un antécédent de $2$ » : le nombre de départ est $-5$ et son image est $2$.
:::

::: resultat
$h(-5) = 2$
:::

## Question 5 : Deux images pour $2$ ?

::: etape Revenir à la définition
Une fonction associe à chaque nombre **une seule** image.
:::

::: resultat
Non : $2$ ne peut pas avoir deux images différentes.
:::

::: attention Erreur fréquente
Écrire $g(7) = -1$ pour la question 1 : l'**image** se place toujours après le signe $=$, jamais dans la parenthèse.
:::

Solution:
<!-- optitab:1 -->
1. $g(-1) = 7$.
2. $7$ est l'image de $4$ par $g$ ; $4$ est un antécédent de $7$ par $g$.
3. Oui : $7$ a alors deux antécédents.
4. $h(-5) = 2$.
5. Non : un nombre a une seule image.

=== Découverte - Un point sur une courbe
Id: 2278
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie par $f(x) = x^2 - 2$ et sa courbe représentative $\mathcal{C}_f$.

1. Calculer $f(3)$. Le point $A(3\ ;\ 7)$ appartient-il à $\mathcal{C}_f$ ?
2. Calculer $f(-2)$. Le point $B(-2\ ;\ 1)$ appartient-il à $\mathcal{C}_f$ ?
3. Déterminer l'ordonnée du point de $\mathcal{C}_f$ d'abscisse $5$.
4. Le point $C(-3\ ;\ 7)$ appartient-il à $\mathcal{C}_f$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le point $A(3\ ;\ 7)$

::: methode
$M(a\ ;\ b)$ appartient à $\mathcal{C}_f$ si et seulement si $f(a) = b$ : on calcule l'image de l'abscisse et on la compare à l'ordonnée.
:::

::: etape Calculer l'image de l'abscisse $3$
$$f(3) = 3^2 - 2 = 9 - 2 = 7$$
:::

::: etape Comparer avec l'ordonnée de $A$
$f(3) = 7$ et l'ordonnée de $A$ vaut $7$ : les deux nombres sont égaux.
:::

::: resultat
$f(3) = 7$, donc $A(3\ ;\ 7)$ appartient à $\mathcal{C}_f$.
:::

## Question 2 : Le point $B(-2\ ;\ 1)$

::: etape Calculer l'image de l'abscisse $-2$
$$f(-2) = (-2)^2 - 2 = 4 - 2 = 2$$
:::

::: etape Comparer
$f(-2) = 2$ alors que l'ordonnée de $B$ vaut $1$ : $2 \neq 1$.
:::

::: resultat
$B(-2\ ;\ 1)$ n'appartient pas à $\mathcal{C}_f$.
:::

## Question 3 : Le point d'abscisse $5$

::: etape L'ordonnée est l'image de l'abscisse
$$f(5) = 5^2 - 2 = 25 - 2 = 23$$
:::

::: resultat
L'ordonnée cherchée est $23$ : le point $(5\ ;\ 23)$ est sur $\mathcal{C}_f$.
:::

## Question 4 : Le point $C(-3\ ;\ 7)$

::: etape Calculer $f(-3)$
$$f(-3) = (-3)^2 - 2 = 9 - 2 = 7$$
:::

::: resultat
$f(-3) = 7$ : $C$ appartient à $\mathcal{C}_f$. Les points $A$ et $C$ ont la même ordonnée : $3$ et $-3$ sont deux antécédents de $7$.
:::

::: attention Erreur fréquente
Écrire $-3^2 = -9$ : il faut calculer $(-3)^2 = 9$, avec les parenthèses.
:::

Solution:
<!-- optitab:1 -->
1. $f(3) = 7$ : $A$ appartient à $\mathcal{C}_f$.
2. $f(-2) = 2 \neq 1$ : $B$ n'appartient pas à $\mathcal{C}_f$.
3. $23$.
4. $f(-3) = 7$ : $C$ appartient à $\mathcal{C}_f$.

=== Découverte - Chercher un antécédent par le calcul
Id: 2279
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère la fonction $h$ définie par $h(x) = 5x + 2$.

1. Écrire l'équation qui permet de trouver l'antécédent de $17$.
2. Résoudre cette équation, puis vérifier le résultat.
3. Déterminer l'antécédent de $-8$.
4. Déterminer l'antécédent de $0$ (sous forme de fraction).

Étapes:
<!-- optitab:1 -->
## Question 1 : L'équation

::: methode
Chercher un antécédent de $17$, c'est chercher $x$ tel que $h(x) = 17$.
:::

::: resultat
$5x + 2 = 17$
:::

## Question 2 : Résoudre et vérifier

::: etape Isoler $x$
$$
\begin{aligned}
5x + 2 &= 17 \\
5x &= 15 \\
x &= 3
\end{aligned}
$$
:::

::: etape Vérifier
$h(3) = 5 \times 3 + 2 = 15 + 2 = 17$ : le résultat est juste.
:::

::: resultat
L'antécédent de $17$ par $h$ est $3$.
:::

## Question 3 : L'antécédent de $-8$

::: etape Résoudre $h(x) = -8$
$$
\begin{aligned}
5x + 2 &= -8 \\
5x &= -10 \\
x &= -2
\end{aligned}
$$
Vérification : $h(-2) = -10 + 2 = -8$.
:::

::: resultat
L'antécédent de $-8$ par $h$ est $-2$.
:::

## Question 4 : L'antécédent de $0$

::: etape Résoudre $h(x) = 0$
$$
\begin{aligned}
5x + 2 &= 0 \\
5x &= -2 \\
x &= -\dfrac{2}{5}
\end{aligned}
$$
:::

::: resultat
L'antécédent de $0$ par $h$ est $-\dfrac{2}{5}$, soit $-0{,}4$.
:::

::: retenir
Image : on **calcule** $h(a)$. Antécédent : on **résout** $h(x) = b$, puis on vérifie.
:::

::: attention Erreur fréquente
Calculer $h(17) = 87$ à la question 1 : on cherche le nombre de départ qui **donne** $17$, pas l'image de $17$.
:::

Solution:
<!-- optitab:1 -->
1. $5x + 2 = 17$.
2. $x = 3$ ; $h(3) = 17$.
3. $-2$.
4. $-\dfrac{2}{5}$.

=== Découverte - Lire images et antécédents sur une courbe
Id: 2280
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
La courbe ci-dessous représente une fonction $f$ définie pour $x$ compris entre $-2$ et $4$.

[IMAGE_1]

Répondre par lecture graphique.

1. Lire l'image de $1$.
2. Lire $f(4)$.
3. Lire les antécédents de $3$.
4. Lire les antécédents de $0$.
5. Combien le nombre $5$ a-t-il d'antécédents ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'image de $1$

::: methode
On part de $1$ sur l'axe des abscisses, on monte jusqu'à la courbe, puis on lit l'ordonnée.
:::

::: etape Lecture
Le point de la courbe d'abscisse $1$ est le sommet de la courbe ; son ordonnée est $4$.
:::

::: resultat
$f(1) = 4$
:::

## Question 2 : Lire $f(4)$

::: etape Lecture (pointillés verts)
On descend de $4$ sur l'axe des abscisses jusqu'au point de la courbe, puis on rejoint l'axe des ordonnées : on lit $-5$.
:::

[IMAGE_2]

::: resultat
$f(4) = -5$
:::

## Question 3 : Les antécédents de $3$

::: methode
On trace la droite horizontale $y = 3$ et on repère **tous** ses points d'intersection avec la courbe.
:::

::: etape Lecture (droite verte $y = 3$)
La droite $y = 3$ coupe la courbe en deux points, d'abscisses $0$ et $2$.
:::

::: resultat
Les antécédents de $3$ sont $0$ et $2$.
:::

## Question 4 : Les antécédents de $0$

::: etape Les points d'ordonnée $0$
Ce sont les points où la courbe coupe l'axe des abscisses : leurs abscisses sont $-1$ et $3$.
:::

::: resultat
Les antécédents de $0$ sont $-1$ et $3$.
:::

## Question 5 : Les antécédents de $5$

::: etape Comparer avec le point le plus haut
Le point le plus haut de la courbe a pour ordonnée $4$ : la droite $y = 5$ passe au-dessus de la courbe et ne la coupe pas.
:::

::: resultat
Le nombre $5$ n'a aucun antécédent.
:::

::: attention Erreur fréquente
Ne donner qu'un seul antécédent de $3$ : il faut suivre la droite horizontale sur **toute** la largeur du graphique.
:::

Solution:
<!-- optitab:1 -->
1. $f(1) = 4$.
2. $f(4) = -5$.
3. $0$ et $2$.
4. $-1$ et $3$.
5. Aucun.

=== Découverte - Vrai, faux ou on ne peut pas savoir
Id: 2281
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On sait seulement que $f(3) = 8$. Pour chaque affirmation, dire si elle est vraie, fausse, ou si on ne peut pas savoir. Justifier.

1. $8$ est l'image de $3$ par $f$.
2. $3$ est un antécédent de $8$ par $f$.
3. $f(8) = 3$.
4. Le nombre $3$ peut avoir une autre image que $8$.
5. Le nombre $8$ peut avoir un autre antécédent que $3$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $8$ est l'image de $3$

::: etape Lire $f(3) = 8$ de gauche à droite
L'image du nombre $3$ est $8$.
:::

::: resultat
Vrai.
:::

## Question 2 : $3$ est un antécédent de $8$

::: etape Lire la même égalité dans l'autre sens
$3$ est un nombre de départ qui donne $8$.
:::

::: resultat
Vrai : c'est la même information.
:::

## Question 3 : $f(8) = 3$

::: etape Ce que dit l'égalité $f(3) = 8$
Elle parle de l'image de $3$, pas de l'image de $8$. Par exemple, avec $f(x) = x + 5$, on a $f(3) = 8$ mais $f(8) = 13$.
:::

::: resultat
On ne peut pas savoir.
:::

## Question 4 : Une autre image pour $3$

::: etape Revenir à la définition
Une fonction associe à chaque nombre **une seule** image.
:::

::: resultat
Faux.
:::

## Question 5 : Un autre antécédent pour $8$

::: etape Un exemple
Avec $f(x) = x^2 - 1$, on a $f(3) = 8$ et aussi $f(-3) = 8$ : $8$ a deux antécédents. Mais avec $f(x) = x + 5$, $3$ est le seul antécédent de $8$.
:::

::: resultat
Vrai : c'est possible (mais pas obligatoire).
:::

::: attention Erreur fréquente
« Retourner » l'égalité : $f(3) = 8$ n'entraîne **pas** $f(8) = 3$.
:::

Solution:
<!-- optitab:1 -->
1. Vrai.
2. Vrai.
3. On ne peut pas savoir.
4. Faux : une seule image.
5. Vrai : c'est possible.

=== Entraînement - Un programme de calcul
Id: 2282
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère le programme de calcul ci-dessous.

[IMAGE_1]

On note $f$ la fonction qui, au nombre choisi $x$, associe le résultat du programme.

1. Appliquer le programme au nombre $1$, puis au nombre $-3$.
2. Exprimer $f(x)$ en fonction de $x$.
3. Lucas affirme : « $f(x) = x^2 + 3$ ». Montrer qu'il a tort.
4. Calculer $f(-5)$.
5. Quels nombres faut-il choisir pour obtenir $25$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Appliquer le programme

::: etape Avec $1$
$1 + 3 = 4$, puis $4^2 = 16$.
:::

::: etape Avec $-3$
$-3 + 3 = 0$, puis $0^2 = 0$.
:::

::: resultat
Le programme donne $16$ avec $1$ et $0$ avec $-3$.
:::

## Question 2 : Exprimer $f(x)$

::: methode
On applique les étapes du programme à la lettre $x$, dans l'ordre (expressions en vert).
:::

[IMAGE_2]

::: resultat
$f(x) = (x + 3)^2$
:::

## Question 3 : La formule de Lucas

::: methode
Pour montrer qu'une formule est fausse, un seul contre-exemple suffit.
:::

::: etape Comparer pour $x = 1$
Avec la formule de Lucas : $1^2 + 3 = 4$. Avec le programme : $16$. Or $4 \neq 16$.
:::

::: resultat
Lucas a tort : sa formule élève $x$ au carré **avant** d'ajouter $3$, l'ordre des étapes est inversé.
:::

## Question 4 : Calculer $f(-5)$

::: etape Remplacer $x$ par $(-5)$
$$f(-5) = (-5 + 3)^2 = (-2)^2 = 4$$
:::

::: resultat
$f(-5) = 4$
:::

## Question 5 : Obtenir $25$

::: methode
On cherche les antécédents de $25$ : $(x + 3)^2 = 25$.
:::

::: etape Les nombres dont le carré vaut $25$
$(x + 3)^2 = 25$ signifie que $x + 3 = 5$ ou $x + 3 = -5$.
:::

::: etape Résoudre les deux équations
$x + 3 = 5$ donne $x = 2$ ; $x + 3 = -5$ donne $x = -8$.

Vérification : $(2 + 3)^2 = 25$ et $(-8 + 3)^2 = (-5)^2 = 25$.
:::

::: resultat
Il faut choisir $2$ ou $-8$.
:::

::: attention Erreur fréquente
Oublier la solution négative : $25$ est le carré de $5$ **et** de $-5$.
:::

Solution:
<!-- optitab:1 -->
1. $16$ et $0$.
2. $f(x) = (x + 3)^2$.
3. Pour $x = 1$ : $1^2 + 3 = 4 \neq 16$.
4. $f(-5) = 4$.
5. $2$ ou $-8$.

=== Entraînement - Lire une ligne brisée
Id: 2283
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La courbe d'une fonction $f$, définie pour $x$ compris entre $-4$ et $3$, est la ligne brisée de sommets $(-4\ ;\ 0)$, $(-1\ ;\ 3)$, $(1\ ;\ -1)$ et $(3\ ;\ 1)$.

[IMAGE_1]

1. Lire $f(-1)$ et $f(1)$.
2. Déterminer graphiquement tous les antécédents de $1$.
3. Combien le nombre $3$ a-t-il d'antécédents ? Et le nombre $4$ ?
4. Entre $x = -1$ et $x = 1$, on admet que $f(x) = 1 - 2x$. Calculer $f(0)$ et vérifier la réponse de la question 2.

Étapes:
<!-- optitab:1 -->
## Question 1 : Lire $f(-1)$ et $f(1)$

::: etape Lire les sommets
Le sommet d'abscisse $-1$ a pour ordonnée $3$ ; celui d'abscisse $1$ a pour ordonnée $-1$.
:::

::: resultat
$f(-1) = 3$ et $f(1) = -1$.
:::

## Question 2 : Les antécédents de $1$

::: methode
On trace la droite horizontale $y = 1$ et on lit les abscisses de **tous** les points d'intersection avec la ligne brisée.
:::

[IMAGE_2]

::: etape Lecture (en vert)
La droite $y = 1$ coupe la ligne brisée trois fois : sur le premier segment en $x = -3$, sur le segment central en $x = 0$ et à l'extrémité droite en $x = 3$.
:::

::: resultat
Les antécédents de $1$ sont $-3$, $0$ et $3$.
:::

## Question 3 : Les antécédents de $3$ et de $4$

::: etape Le point le plus haut
Le point le plus haut de la courbe est le sommet $(-1\ ;\ 3)$ : la droite $y = 3$ ne touche la courbe qu'en ce point, et la droite $y = 4$ passe au-dessus.
:::

::: resultat
$3$ a un seul antécédent ($-1$) ; $4$ n'a aucun antécédent.
:::

## Question 4 : Vérifier par le calcul

::: etape Calculer $f(0)$
$$f(0) = 1 - 2 \times 0 = 1$$
:::

::: etape Comparer
$f(0) = 1$ : $0$ est bien un antécédent de $1$, ce qui confirme la lecture de la question 2. On peut aussi contrôler la formule aux sommets : $f(-1) = 1 + 2 = 3$ et $f(1) = 1 - 2 = -1$.
:::

::: resultat
$f(0) = 1$ : la lecture graphique est confirmée.
:::

::: attention Erreur fréquente
Oublier l'antécédent $3$, situé à l'extrémité de la courbe : un point d'extrémité compte aussi.
:::

Solution:
<!-- optitab:1 -->
1. $f(-1) = 3$ et $f(1) = -1$.
2. $-3$, $0$ et $3$.
3. $3$ : un antécédent ($-1$) ; $4$ : aucun.
4. $f(0) = 1$ : confirmé.

=== Entraînement - Zéro, un ou deux antécédents
Id: 2284
Difficulté: medium

Énoncé:
<!-- optitab:1 -->

=== Entraînement - Deux droites qui se croisent
Id: 2285
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Les fonctions $f : x \longmapsto x + 2$ et $g : x \longmapsto 2x - 1$ sont représentées ci-dessous par les droites $\mathcal{C}_f$ et $\mathcal{C}_g$.

[IMAGE_1]

2. Quelle équation ce point permet-il de résoudre ?
3. Résoudre cette équation par le calcul.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le point d'intersection

::: etape Lecture (en vert)
Les deux droites se coupent au point d'abscisse $3$ et d'ordonnée $5$.
:::

[IMAGE_2]

::: resultat
Le point d'intersection a pour coordonnées $(3\ ;\ 5)$.
:::

## Question 2 : L'équation

::: methode
Au point d'intersection, les deux fonctions donnent **la même image** pour la même valeur de $x$.
:::

::: resultat
Ce point donne la solution de l'équation $f(x) = g(x)$, soit $x + 2 = 2x - 1$.
:::

## Question 3 : Résoudre par le calcul

::: etape Regrouper les $x$ d'un côté
$$
\begin{aligned}
x + 2 &= 2x - 1 \\
2 + 1 &= 2x - x \\
3 &= x
\end{aligned}
$$
:::

::: etape Vérifier
$f(3) = 3 + 2 = 5$ et $g(3) = 2 \times 3 - 1 = 5$ : même image, comme sur le graphique.

$9 > 7$ : pour $x = 5$, c'est $g$ qui donne la plus grande image (sa droite est au-dessus).
:::

::: attention Erreur fréquente
Répondre « $x = 5$ » à la question 3 : $5$ est l'**ordonnée** du point (l'image commune), la solution est l'**abscisse** $3$.

Solution:
<!-- optitab:1 -->
1. $(3\ ;\ 5)$.
2. $x + 2 = 2x - 1$.
3. $x = 3$.
4. $f(5) = 7$ et $g(5) = 9$ : c'est $g$.

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie par $f(x) = 4 - x^2$.

1. Recopier et compléter le tableau de valeurs.

| $x$ | $f(x)$ |
|---|---|
| $-3$ |  |
| $-2$ |  |
| $-1$ |  |

f(-2) &= 4 - (-2)^2 = 4 - 4 = 0 \\
f(-1) &= 4 - (-1)^2 = 4 - 1 = 3 \\

\end{aligned}

De même, $f(1) = 3$, $f(2) = 0$ et $f(3) = -5$.

| $x$ | $f(x)$ |
|---|---|
| $-3$ | $-5$ |
| $-2$ | $0$ |
| $-1$ | $3$ |
| $0$ | $4$ |
| $1$ | $3$ |
| $2$ | $0$ |

::: resultat
En B2 : `=4-A2^2`, puis on étire la formule vers le bas.

::: etape Placer les points $(x\ ;\ f(x))$
On place $(-3\ ;\ -5)$, $(-2\ ;\ 0)$, $(-1\ ;\ 3)$, $(0\ ;\ 4)$, $(1\ ;\ 3)$, $(2\ ;\ 0)$ et $(3\ ;\ -5)$, puis on les relie par une courbe régulière, sans angle.
:::

[IMAGE_1]

::: resultat
La courbe obtenue est symétrique par rapport à l'axe des ordonnées : $x$ et $-x$ ont la même image.

## Question 4 : Les antécédents de $0$

:::

::: resultat
Les antécédents de $0$ présents dans le tableau sont $-2$ et $2$.
:::

$$f(0{,}5) = 4 - 0{,}5^2 = 4 - 0{,}25 = 3{,}75$$
:::

::: etape Comparer avec un segment

::: resultat

::: attention Erreur fréquente
Calculer $4 - (-3)^2$ comme $4 + 9$ : on calcule d'abord le carré, $(-3)^2 = 9$, puis on le soustrait.

Solution:

2. `=4-A2^2`.

4. $-2$ et $2$.

Difficulté: medium

Énoncé:
<!-- optitab:1 -->
1. Expliquer pourquoi la courbe d'une fonction ne peut pas contenir deux points différents de même abscisse.
2. Un cercle peut-il être la courbe représentative d'une fonction ?
3. Une droite verticale peut-elle être la courbe représentative d'une fonction ?
4. La droite horizontale passant par le point $(0\ ;\ 2)$ est-elle la courbe d'une fonction ? Si oui, laquelle ?
5. Les points $(1\ ;\ 4)$ et $(1\ ;\ 5)$ peuvent-ils appartenir à la courbe d'une même fonction ? Et les points $(1\ ;\ 4)$ et $(2\ ;\ 4)$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux points de même abscisse

::: methode
Les points de la courbe sont les points $(x\ ;\ f(x))$ : l'ordonnée est l'image de l'abscisse.
:::

::: etape Raisonner
Deux points différents de même abscisse $a$ auraient deux ordonnées différentes : le nombre $a$ aurait deux images.
:::

::: resultat
C'est impossible : un nombre a une seule image.
:::

## Question 2 : Un cercle

::: etape Tracer une verticale
Une droite verticale qui traverse le cercle le coupe en **deux** points de même abscisse.
:::

::: resultat
Non : un cercle n'est pas la courbe d'une fonction.
:::

## Question 3 : Une droite verticale

::: etape Les points d'une verticale
Tous ses points ont la même abscisse et des ordonnées différentes.
:::

::: resultat
Non : ce nombre aurait une infinité d'images.
:::

## Question 4 : La droite horizontale $y = 2$

::: etape Les points de cette droite
Ce sont les points $(x\ ;\ 2)$ : chaque nombre $x$ a une seule image, $2$.
:::

::: resultat
Oui : c'est la courbe de la fonction constante $f : x \longmapsto 2$.
:::

## Question 5 : Deux couples de points

Même abscisse $1$, ordonnées différentes : $1$ aurait deux images, $4$ et $5$.

Abscisses différentes et même ordonnée : $4$ aurait deux antécédents, $1$ et $2$, ce qui est permis.

::: resultat
Non pour $(1\ ;\ 4)$ et $(1\ ;\ 5)$ ; oui pour $(1\ ;\ 4)$ et $(2\ ;\ 4)$.
:::

::: retenir
Toute droite **verticale** coupe la courbe d'une fonction en un point au plus. Une droite **horizontale** peut la couper plusieurs fois.
:::

Solution:
<!-- optitab:1 -->
1. Le nombre aurait deux images.
2. Non.
3. Non.
4. Oui : la fonction constante $x \longmapsto 2$.
5. Non ; oui.

=== Entraînement - Lecture graphique puis calcul exact

Difficulté: medium

Énoncé:
<!-- optitab:1 -->
La courbe ci-dessous représente la fonction $f$ définie pour $x$ compris entre $-2$ et $4$ par $f(x) = x^2 - 2x - 3$.

On part de $4$ sur l'axe des abscisses, on rejoint la courbe, puis l'axe des ordonnées : on lit $5$.

[IMAGE_2]

## Question 2 : Les antécédents de $-3$

::: etape Lecture (droite verte $y = -3$)
La droite $y = -3$ coupe la courbe en deux points, d'abscisses $0$ et $2$.
:::

::: etape Vérification par le calcul
$f(0) = 0 - 0 - 3 = -3$ et $f(2) = 4 - 4 - 3 = -3$.

::: resultat
Les antécédents de $-3$ sont $0$ et $2$.

La courbe coupe l'axe des abscisses en deux points (en vert), d'abscisses environ $-1$ et $3$.

Par lecture, les antécédents de $0$ sont environ $-1$ et $3$.

Donc $f(x) = (x + 1)(x - 3)$.

=== Problème - Le volume d'un réservoir
Id: 2289
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un réservoir cylindrique a une base d'aire $0{,}8$ m² et une hauteur de $1{,}5$ m. On note $h$ la hauteur d'eau, en mètres, et $V(h)$ le volume d'eau, en m³.

1. Exprimer $V(h)$ en fonction de $h$.
2. Quelles sont les valeurs possibles de $h$ ?
3. Calculer $V(1{,}2)$. Donner le résultat en m³ puis en litres.
4. Quelle hauteur d'eau correspond à $600$ L ?
5. Le réservoir peut-il contenir $1\,500$ L ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Exprimer $V(h)$

::: methode
Volume d'un cylindre = aire de la base $\times$ hauteur.
:::

::: resultat
$V(h) = 0{,}8h$ (en m³).
:::

## Question 2 : Les valeurs possibles de $h$

::: etape Les contraintes
La hauteur d'eau est positive et ne dépasse pas la hauteur du réservoir.
:::

::: resultat
$0 \leqslant h \leqslant 1{,}5$
:::

## Question 3 : Calculer $V(1{,}2)$

::: etape Calcul
$$V(1{,}2) = 0{,}8 \times 1{,}2 = 0{,}96$$
:::

::: etape Conversion
$1$ m³ $= 1\,000$ L, donc $0{,}96$ m³ $= 960$ L.
:::

::: resultat
$V(1{,}2) = 0{,}96$ m³, soit $960$ L.
:::

## Question 4 : La hauteur pour $600$ L

::: methode
On cherche l'antécédent de $600$ L par $V$ : on convertit en m³, puis on résout $V(h) = 0{,}6$.
:::

::: etape Résoudre
$600$ L $= 0{,}6$ m³.
$$
\begin{aligned}
0{,}8h &= 0{,}6 \\
h &= \dfrac{0{,}6}{0{,}8} = 0{,}75
\end{aligned}
$$
:::

::: resultat
Pour $600$ L, la hauteur d'eau est $0{,}75$ m.
:::

## Question 5 : $1\,500$ L ?

::: etape Volume maximal
$$V(1{,}5) = 0{,}8 \times 1{,}5 = 1{,}2 \text{ m}^3 = 1\,200 \text{ L}$$
:::

::: resultat
Non : le réservoir contient au plus $1\,200$ L, ce qui est moins que $1\,500$ L.
:::

::: attention Erreur fréquente
Résoudre $0{,}8h = 600$ sans convertir : on obtient $h = 750$ m, ce qui est absurde. Les unités doivent être cohérentes (m³ avec m²).
:::

Solution:
<!-- optitab:1 -->
1. $V(h) = 0{,}8h$.
2. $0 \leqslant h \leqslant 1{,}5$.
3. $0{,}96$ m³ $= 960$ L.
4. $0{,}75$ m.
5. Non : au plus $1\,200$ L.

=== Problème - Un tarif de parking plafonné
Id: 2290
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un parking fait payer $2$ € par heure commencée, avec un maximum de $10$ € par jour. On note $P(n)$ le prix payé, en euros, pour $n$ heures ($n$ entier entre $0$ et $12$).

1. Calculer $P(3)$, $P(5)$ et $P(8)$.
2. À partir de combien d'heures paie-t-on $10$ € ?
3. Compléter le tableau de valeurs.

| $n$ | $1$ | $2$ | $4$ | $6$ | $10$ |
|---|---|---|---|---|---|
| $P(n)$ | | | | | |

4. Quels sont les antécédents de $10$ ? Et de $7$ ?
5. Le prix est-il proportionnel à la durée sur toute la journée ? Justifier.

Étapes:
<!-- optitab:1 -->
## Question 1 : Calculer $P(3)$, $P(5)$ et $P(8)$

::: methode
On calcule $2 \times n$, puis on remplace le résultat par $10$ s'il dépasse $10$.
:::

::: etape Calculs
- $P(3) = 2 \times 3 = 6$.
- $P(5) = 2 \times 5 = 10$.
- $2 \times 8 = 16 > 10$, donc $P(8) = 10$.
:::

::: resultat
$P(3) = 6$ €, $P(5) = 10$ € et $P(8) = 10$ €.
:::

## Question 2 : Le plafond

::: etape Chercher quand $2n$ atteint $10$
$2n = 10$ pour $n = 5$ ; au-delà, $2n$ dépasse $10$.
:::

::: resultat
On paie $10$ € à partir de $5$ heures.
:::

## Question 3 : Le tableau

::: resultat
| $n$ | $1$ | $2$ | $4$ | $6$ | $10$ |
|---|---|---|---|---|---|
| $P(n)$ | $2$ | $4$ | $8$ | $10$ | $10$ |
:::

## Question 4 : Les antécédents de $10$ et de $7$

::: etape Antécédents de $10$
Tous les entiers $n$ de $5$ à $12$ donnent $P(n) = 10$.
:::

::: etape Antécédents de $7$
Les prix possibles sont $0$, $2$, $4$, $6$, $8$ et $10$ : $7$ n'est jamais obtenu.
:::

::: resultat
$10$ a huit antécédents : $5$, $6$, $7$, $8$, $9$, $10$, $11$ et $12$. Le nombre $7$ n'a aucun antécédent.
:::

## Question 5 : Proportionnalité ?

::: etape Comparer les quotients
$\dfrac{P(4)}{4} = \dfrac{8}{4} = 2$ mais $\dfrac{P(10)}{10} = \dfrac{10}{10} = 1$ : les quotients ne sont pas égaux.
:::

::: resultat
Non : le prix est proportionnel à la durée seulement jusqu'à $5$ heures ; ensuite il reste constant.
:::

::: attention Erreur fréquente
Calculer $P(8) = 16$ en oubliant le plafond : il faut toujours relire les conditions de l'énoncé.
:::

Solution:
<!-- optitab:1 -->
1. $6$ € ; $10$ € ; $10$ €.
2. À partir de $5$ heures.
3. $2$ ; $4$ ; $8$ ; $10$ ; $10$.
4. $10$ : les entiers de $5$ à $12$ ; $7$ : aucun.
5. Non : le prix est constant après $5$ heures.

=== Problème - Les aires d'un rectangle de périmètre fixé
Id: 2291
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un rectangle a un périmètre de $40$ cm. On note $x$ la longueur d'un de ses côtés, en cm, et $A(x)$ son aire, en cm².

1. Exprimer la longueur de l'autre côté en fonction de $x$.
2. En déduire $A(x)$.
3. Quelles sont les valeurs possibles de $x$ ?
4. Calculer $A(3)$ et $A(17)$. Que remarque-t-on ? Expliquer.
5. Calculer $A(10)$. Quelle est alors la forme du rectangle ?

Étapes:
<!-- optitab:1 -->
## Question 1 : L'autre côté

::: methode
Le périmètre est égal à $2 \times (\text{côté 1} + \text{côté 2})$ : la somme des deux côtés vaut $40 \div 2 = 20$ cm.
:::

::: resultat
L'autre côté mesure $20 - x$ cm.
:::

## Question 2 : L'aire

::: resultat
$A(x) = x(20 - x)$
:::

## Question 3 : Les valeurs possibles de $x$

::: etape Les deux côtés doivent être strictement positifs
$x > 0$ et $20 - x > 0$, c'est-à-dire $x < 20$.
:::

::: resultat
$0 < x < 20$
:::

## Question 4 : $A(3)$ et $A(17)$

::: etape Calculs
$$
\begin{aligned}
A(3) &= 3 \times (20 - 3) = 3 \times 17 = 51 \\
A(17) &= 17 \times (20 - 17) = 17 \times 3 = 51
\end{aligned}
$$
:::

::: resultat
$A(3) = A(17) = 51$ cm² : le nombre $51$ a deux antécédents. C'est le même rectangle ($3$ cm sur $17$ cm), simplement tourné.
:::

## Question 5 : $A(10)$

::: etape Calcul
$$A(10) = 10 \times (20 - 10) = 10 \times 10 = 100$$
:::

::: resultat
$A(10) = 100$ cm² : les deux côtés mesurent $10$ cm, le rectangle est un **carré**.
:::

::: attention Erreur fréquente
Écrire $40 - x$ pour l'autre côté : le périmètre compte **deux** fois chaque côté.
:::

Solution:
<!-- optitab:1 -->
1. $20 - x$.
2. $A(x) = x(20 - x)$.
3. $0 < x < 20$.
4. $A(3) = A(17) = 51$ : deux antécédents de $51$.
5. $A(10) = 100$ : un carré.

3. À quels instants Inès est-elle à $300$ m du départ ?
4. Calculer la distance totale parcourue.
5. Calculer sa vitesse en m/min à l'aller, puis au retour. Convertir la vitesse de l'aller en km/h.

Étapes:
<!-- optitab:1 -->
## Question 1 : Au bout de $10$ minutes

::: etape Lecture
Le point d'abscisse $10$ a pour ordonnée $600$.
:::

::: resultat
Au bout de $10$ minutes, Inès est à $600$ m du départ.
:::

## Question 2 : Entre $10$ et $15$ minutes

::: etape Lecture
La distance reste égale à $600$ m : le segment est horizontal.
:::

::: resultat
Inès s'arrête : elle fait une pause de $5$ minutes.
:::

## Question 3 : Les instants où $d = 300$ m

::: methode
On cherche les antécédents de $300$ : la droite horizontale $d = 300$ coupe la courbe deux fois, une fois à l'aller et une fois au retour (lecture en vert).
:::

[IMAGE_2]

::: etape À l'aller
Elle parcourt $600$ m en $10$ min, régulièrement : $300$ m est la moitié du trajet, atteinte à $t = 5$ min.
:::

::: etape Au retour
Le retour dure de $15$ à $27$ min, soit $12$ min. La moitié du retour est atteinte au bout de $6$ min, à $t = 15 + 6 = 21$ min.
:::

::: resultat
Inès est à $300$ m du départ à $t = 5$ min et à $t = 21$ min.
:::

## Question 4 : La distance totale

::: etape Additionner l'aller et le retour
$600 + 600 = 1\,200$ m.
:::

::: resultat
Inès a parcouru $1\,200$ m.
:::

## Question 5 : Les vitesses

::: methode
Vitesse = distance $\div$ durée.
:::

::: etape À l'aller et au retour
- Aller : $600 \div 10 = 60$ m/min.
- Retour : $600 \div 12 = 50$ m/min.
:::

::: etape Conversion de la vitesse de l'aller
$60$ m/min $= 60 \times 60$ m/h $= 3\,600$ m/h $= 3{,}6$ km/h.
:::

::: resultat
$60$ m/min à l'aller (soit $3{,}6$ km/h) et $50$ m/min au retour : l'aller est plus rapide.
:::

::: attention Erreur fréquente
Répondre $600$ m à la question 4 : le graphique donne la distance **au départ**, pas la distance parcourue ; le retour compte aussi.
:::

Solution:
<!-- optitab:1 -->
1. $600$ m.
2. Une pause de $5$ min.
3. $t = 5$ min et $t = 21$ min.
4. $1\,200$ m.
5. $60$ m/min ($3{,}6$ km/h) à l'aller ; $50$ m/min au retour.

=== Problème - Antécédents et produit nul
Id: 2293
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère la fonction $f$ définie par $f(x) = (x - 2)(3x + 6)$.

1. Calculer $f(0)$ et $f(-1)$.
2. Développer et réduire $f(x)$.
3. Vérifier le résultat de la question 1 avec la forme développée.
4. Déterminer les antécédents de $0$.
5. Déterminer les antécédents de $-12$ en utilisant la forme développée.

Étapes:
<!-- optitab:1 -->
## Question 1 : $f(0)$ et $f(-1)$

::: etape Avec la forme donnée
$$
\begin{aligned}
f(0) &= (0 - 2)(3 \times 0 + 6) = (-2) \times 6 = -12 \\
f(-1) &= (-1 - 2)(3 \times (-1) + 6) = (-3) \times 3 = -9
\end{aligned}
$$
:::

::: resultat
$f(0) = -12$ et $f(-1) = -9$.
:::

## Question 2 : Développer

::: etape Double distributivité
$$
\begin{aligned}
f(x) &= x \times 3x + x \times 6 - 2 \times 3x - 2 \times 6 \\
&= 3x^2 + 6x - 6x - 12 \\
&= 3x^2 - 12
\end{aligned}
$$
:::

::: resultat
$f(x) = 3x^2 - 12$
:::

## Question 3 : Vérifier

::: etape Avec la forme développée
$f(0) = 3 \times 0 - 12 = -12$ et $f(-1) = 3 \times 1 - 12 = -9$.
:::

::: resultat
On retrouve les mêmes images : le développement est cohérent.
:::

## Question 4 : Les antécédents de $0$

::: methode
On résout $f(x) = 0$ avec la forme **factorisée** : un produit est nul si l'un de ses facteurs est nul.
:::

::: etape Équation produit nul
$(x - 2)(3x + 6) = 0$ équivaut à $x - 2 = 0$ ou $3x + 6 = 0$, soit $x = 2$ ou $x = -2$.
:::

::: resultat
Les antécédents de $0$ sont $2$ et $-2$.
:::

## Question 5 : Les antécédents de $-12$

::: methode
Avec la forme **développée**, l'équation $f(x) = -12$ se simplifie.
:::

::: etape Résoudre
$$
\begin{aligned}
3x^2 - 12 &= -12 \\
3x^2 &= 0 \\
x^2 &= 0
\end{aligned}
$$
donc $x = 0$.
:::

::: resultat
Le nombre $-12$ a un seul antécédent : $0$.
:::

::: retenir
On choisit la forme adaptée : la forme factorisée pour résoudre $f(x) = 0$, la forme développée pour $f(x) = -12$.
:::

::: attention Erreur fréquente
Écrire $3x + 6 = 0$ donne $x = 2$ : on obtient $3x = -6$, donc $x = -2$.
:::

Solution:
<!-- optitab:1 -->
1. $f(0) = -12$ et $f(-1) = -9$.
2. $f(x) = 3x^2 - 12$.
3. Mêmes résultats.
4. $2$ et $-2$.
5. $0$.

=== Type brevet - La chute d'une balle
Id: 2294
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On lâche une balle du haut d'une tour de $80$ m. Dans un modèle simplifié, sa hauteur au-dessus du sol, en mètres, $t$ secondes après le lâcher, est $h(t) = 80 - 5t^2$.

1. Calculer $h(0)$ et interpréter le résultat.
2. Calculer $h(2)$. De combien de mètres la balle est-elle tombée pendant les $2$ premières secondes ?
3. Recopier et compléter le tableau.

| $t$ (s) | $0$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|---|
| $h(t)$ (m) | | | | | |

4. Au bout de combien de temps la balle touche-t-elle le sol ?
5. Calculer $h(5)$. Ce résultat a-t-il un sens ? Préciser les valeurs de $t$ pour lesquelles le modèle convient.

Étapes:
<!-- optitab:1 -->
## Question 1 : $h(0)$

::: etape Calcul
$$h(0) = 80 - 5 \times 0^2 = 80$$
:::

::: resultat
$h(0) = 80$ : au moment du lâcher, la balle est à $80$ m du sol (en haut de la tour).
:::

## Question 2 : $h(2)$

::: etape Calcul
$$h(2) = 80 - 5 \times 2^2 = 80 - 20 = 60$$
:::

::: etape Hauteur perdue
$80 - 60 = 20$ m.
:::

::: resultat
$h(2) = 60$ m : la balle est tombée de $20$ m en $2$ secondes.
:::

## Question 3 : Le tableau

::: etape Calculs
$h(1) = 80 - 5 = 75$ ; $h(3) = 80 - 45 = 35$ ; $h(4) = 80 - 80 = 0$.
:::

::: resultat
| $t$ (s) | $0$ | $1$ | $2$ | $3$ | $4$ |
|---|---|---|---|---|---|
| $h(t)$ (m) | $80$ | $75$ | $60$ | $35$ | $0$ |
:::

## Question 4 : L'arrivée au sol

::: methode
La balle touche le sol quand sa hauteur est nulle : on résout $h(t) = 0$.
:::

::: etape Résoudre
$$
\begin{aligned}
80 - 5t^2 &= 0 \\
5t^2 &= 80 \\
t^2 &= 16
\end{aligned}
$$
donc $t = 4$ ou $t = -4$. Une durée est positive : $t = 4$.
:::

::: resultat
La balle touche le sol au bout de $4$ secondes.
:::

## Question 5 : $h(5)$ et validité du modèle

::: etape Calcul
$$h(5) = 80 - 5 \times 25 = 80 - 125 = -45$$
:::

::: resultat
$h(5) = -45$ : une hauteur négative n'a pas de sens, la balle est déjà au sol. Le modèle convient pour $0 \leqslant t \leqslant 4$.
:::

::: attention Erreur fréquente
Calculer $5 \times 2^2$ comme $10^2 = 100$ : la puissance est prioritaire, $5 \times 2^2 = 5 \times 4 = 20$.
:::

Solution:
<!-- optitab:1 -->
1. $h(0) = 80$ : hauteur de départ.
2. $h(2) = 60$ : chute de $20$ m.
3. $80$ ; $75$ ; $60$ ; $35$ ; $0$.
4. $4$ s.
5. $h(5) = -45$ : pas de sens ; modèle valable pour $0 \leqslant t \leqslant 4$.

=== Type brevet - Deux offres à comparer
Id: 2295
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un magasin de location propose deux offres pour louer des jeux vidéo.
- Offre A : $3$ € d'inscription, puis $2$ € par jeu loué.
- Offre B : $7$ € d'inscription, puis $1$ € par jeu loué.

On note $x$ le nombre de jeux loués, $f(x)$ le prix avec l'offre A et $g(x)$ le prix avec l'offre B, en euros.

1. Exprimer $f(x)$ et $g(x)$ en fonction de $x$.
2. Calculer $f(4)$ et $g(4)$. Que remarque-t-on ?
3. Résoudre l'équation $f(x) = g(x)$ et interpréter.
4. Comparer les deux offres pour $2$ jeux, puis pour $10$ jeux.
5. Léa a un budget de $15$ €. Avec quelle offre peut-elle louer le plus de jeux ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Exprimer les prix

::: methode
Prix = inscription + prix d'un jeu $\times$ nombre de jeux.
:::

::: resultat
$f(x) = 2x + 3$ et $g(x) = x + 7$.
:::

## Question 2 : $f(4)$ et $g(4)$

::: etape Calculs
$f(4) = 2 \times 4 + 3 = 11$ et $g(4) = 4 + 7 = 11$.
:::

::: resultat
$f(4) = g(4) = 11$ : pour $4$ jeux, les deux offres coûtent $11$ €.
:::

## Question 3 : Résoudre $f(x) = g(x)$

::: etape Résoudre
$$
\begin{aligned}
2x + 3 &= x + 7 \\
2x - x &= 7 - 3 \\
x &= 4
\end{aligned}
$$
:::

::: resultat
La seule solution est $x = 4$ : c'est le seul nombre de jeux pour lequel les deux offres coûtent le même prix.
:::

## Question 4 : Comparer pour $2$ et $10$ jeux

::: etape Pour $2$ jeux
$f(2) = 7$ € et $g(2) = 9$ € : l'offre A est moins chère.
:::

::: etape Pour $10$ jeux
$f(10) = 23$ € et $g(10) = 17$ € : l'offre B est moins chère.
:::

::: resultat
Pour $2$ jeux, l'offre A est meilleure ; pour $10$ jeux, l'offre B est meilleure.
:::

## Question 5 : Un budget de $15$ €

::: etape Offre A
$2x + 3 = 15$ donne $2x = 12$, soit $x = 6$ : $6$ jeux pour $15$ €.
:::

::: etape Offre B
$x + 7 = 15$ donne $x = 8$ : $8$ jeux pour $15$ €.
:::

::: resultat
Avec l'offre B, Léa peut louer $8$ jeux (contre $6$ avec l'offre A).
:::

::: retenir
Avant $4$ jeux, l'offre A est la moins chère ; pour $4$ jeux, les deux se valent ; au-delà, l'offre B est la moins chère.
:::

::: attention Erreur fréquente
Conclure à partir d'une seule valeur : l'offre la moins chère **dépend** du nombre de jeux.
:::

Solution:
<!-- optitab:1 -->
1. $f(x) = 2x + 3$ et $g(x) = x + 7$.
2. $f(4) = g(4) = 11$.
3. $x = 4$ : même prix pour $4$ jeux.
4. $2$ jeux : A ($7$ € contre $9$ €) ; $10$ jeux : B ($17$ € contre $23$ €).
5. L'offre B : $8$ jeux.
