📚 Objectif pédagogique : retenir l’essentiel : échantillon, fluctuation, stabilisation des fréquences et précision $\displaystyle \frac{1}{\sqrt{n}}$. Programme de Seconde.

I. Fréquence et probabilité

[IMAGE_1]

1️⃣ Échantillon de taille $\displaystyle n$ : $\displaystyle n$ répétitions indépendantes ; fréquence $\displaystyle f = \frac{k}{n}$.

2️⃣ Fluctuation : $\displaystyle f$ change d’un échantillon à l’autre.

3️⃣ Loi des grands nombres : $\displaystyle f$ se rapproche de $\displaystyle p$ quand $\displaystyle n$ grandit.

II. Précision

$\displaystyle |f - p| \le \frac{1}{\sqrt{n}}$ dans environ $\displaystyle 95\,\%$ des cas

[IMAGE_2]

• $\displaystyle n = 100$ : écart $\displaystyle 0{,}1$ ; $\displaystyle n = 400$ : écart $\displaystyle 0{,}05$ ; $\displaystyle n = 10\,000$ : écart $\displaystyle 0{,}01$.

• Si $\displaystyle |f - p| \gt \frac{1}{\sqrt{n}}$, on peut douter du modèle (avec un risque d’erreur d’environ $\displaystyle 5\,\%$).

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Confondre la fréquence (observée) et la probabilité (théorique).

2️⃣ Tirer une conclusion d’un tout petit échantillon.

3️⃣ Présenter la conclusion comme certaine alors qu’elle comporte un risque.

4️⃣ Croire qu’après plusieurs « pile », « face » devient plus probable : les lancers sont indépendants.

🏆 Réflexe : je calcule $\displaystyle f$, puis $\displaystyle \frac{1}{\sqrt{n}}$, puis je compare $\displaystyle |f - p|$ à $\displaystyle \frac{1}{\sqrt{n}}$ avant de conclure.
