<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Somme de deux variables</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:12px; margin:12px auto; text-align:center; max-width:460px;">
<p style="margin:0; font-weight:bold;">$E(X + Y) = E(X) + E(Y)$</p>
</div>
[IMAGE_1]
<p style="margin:0;">1️⃣ $E(aX + b) = aE(X) + b$ ; $V(aX + b) = a^2V(X)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ Indépendantes : $V(X + Y) = V(X) + V(Y)$ (et $V(X - Y) = V(X) + V(Y)$).</p>
<p style="margin:6px 0 0 0;">3️⃣ Binomiale = somme de $n$ Bernoulli : $E = np$, $V = np(1 - p)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Échantillons</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_2]
<p style="margin:0;">1️⃣ $S_n = X_1 + \cdots + X_n$ : $E(S_n) = nE(X)$, $V(S_n) = nV(X)$.</p>
<p style="margin:6px 0 0 0;">2️⃣ $M_n = \frac{S_n}{n}$ : $E(M_n) = E(X)$, $V(M_n) = \frac{V(X)}{n}$.</p>
<p style="margin:6px 0 0 0;">3️⃣ $\sigma(M_n) = \frac{\sigma(X)}{\sqrt{n}}$ : la moyenne se concentre quand $n$ grandit.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ Ajouter les variances de variables non indépendantes.</p>
<p style="margin:6px 0 0 0;">2️⃣ Écrire $V(X - Y) = V(X) - V(Y)$.</p>
<p style="margin:6px 0 0 0;">3️⃣ Ajouter les écarts types au lieu des variances.</p>
<p style="margin:6px 0 0 0;">4️⃣ Oublier le carré dans $V(aX) = a^2V(X)$.</p>
</div>

<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> variable compliquée → je l’écris comme une somme de variables simples, puis j’additionne espérances (et variances si indépendantes).</p>
</div>
