Description: Mini-cours sur la logique et les démarches en 6ème : expliquer une démarche de résolution étape par étape, utiliser "si... alors..." dans des raisonnements simples, résoudre des problèmes où on doit justifier (pas seulement calculer), exercices vrai/faux avec justification.

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Qu'est-ce qu'une démarche de résolution ?</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Définition</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Démarche de résolution</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Une <strong>démarche de résolution</strong> est une façon organisée de résoudre un problème en expliquant <strong>chaque étape</strong> de son raisonnement.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce n'est pas seulement donner la réponse, mais <strong>expliquer pourquoi</strong> et <strong>comment</strong> on l'a trouvée.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Pourquoi expliquer sa démarche ?</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Pour <strong>comprendre</strong> ce qu'on fait</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour <strong>vérifier</strong> qu'on n'a pas fait d'erreur</li>
                <li style="margin:0 0 12px 0; text-align:left;">Pour <strong>communiquer</strong> sa façon de penser</li>
                <li style="margin:0; text-align:left;">Pour <strong>apprendre</strong> des méthodes de résolution</li>
            </ul>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Expliquer une démarche de résolution</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Méthode étape par étape</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Comment expliquer sa démarche ?</strong></p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire</strong> attentivement le problème</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Identifier</strong> ce qui est connu et ce qui est cherché</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Choisir</strong> la méthode ou la formule à utiliser</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Calculer</strong> étape par étape en expliquant chaque calcul</li>
                <li style="margin:0; text-align:left;"><strong>Conclure</strong> en donnant la réponse avec une phrase</li>
            </ol>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Problème avec périmètre</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Un rectangle a un périmètre de <strong>24 cm</strong>. Sa longueur est de <strong>8 cm</strong>. Quelle est sa largeur ?</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Démarche de résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ce que je sais :</strong> Périmètre P = 24 cm, Longueur L = 8 cm</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ce que je cherche :</strong> La largeur l</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>La formule que j'utilise :</strong> P = 2 × (L + l)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Je remplace :</strong> 24 = 2 × (8 + l)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Je calcule :</strong> 24 = 16 + 2l, donc 24 - 16 = 2l, donc 8 = 2l</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Je divise par 2 :</strong> l = 8 ÷ 2 = 4 cm</li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> La largeur du rectangle est de <strong>4 cm</strong>.</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Vérification :</strong> P = 2 × (8 + 4) = 2 × 12 = 24 cm ✓</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Problème avec conversion</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On a mesuré une distance de <strong>250 cm</strong>. Exprime cette distance en mètres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Démarche de résolution :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ce que je sais :</strong> 1 m = 100 cm</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour convertir cm en m :</strong> Je divise par 100</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Je calcule :</strong> 250 ÷ 100 = 2,5</li>
                <li style="margin:0; text-align:left;"><strong>Réponse :</strong> 250 cm = <strong>2,5 m</strong>.</li>
            </ul>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Justification :</strong> Comme 1 m = 100 cm, pour passer des cm aux m, je dois diviser par 100. Donc 250 cm = 250 ÷ 100 = 2,5 m.</p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il ne suffit pas de donner juste la réponse ! Il faut expliquer <strong>comment</strong> et <strong>pourquoi</strong> on a fait chaque étape.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Utiliser "si…, alors…" dans des raisonnements</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Le raisonnement logique</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 "Si…, alors…"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">"<strong>Si…, alors…</strong>" est une façon de dire qu'une chose <strong>implique</strong> une autre chose.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">On utilise "si…, alors…" pour faire des raisonnements logiques : si une condition est vraie, alors une conséquence suit.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Raisonnement simple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Complète le raisonnement :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> un nombre est divisible par 10, <strong>alors</strong> il se termine par ...</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> un nombre est divisible par 10, <strong>alors</strong> il se termine par <strong>0</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Justification :</strong> Tous les multiples de 10 (10, 20, 30, 40, …) se terminent par 0.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Raisonnement avec figures géométriques</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Complète le raisonnement :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> une figure est un carré, <strong>alors</strong> elle a ...</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> une figure est un carré, <strong>alors</strong> elle a <strong>4 côtés égaux et 4 angles droits</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Justification :</strong> C'est la définition d'un carré : un quadrilatère avec 4 côtés de même longueur et 4 angles droits.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Raisonnement avec calcul</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Complète le raisonnement :</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> un nombre est pair, <strong>alors</strong> il est divisible par ...</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Solution :</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Si</strong> un nombre est pair, <strong>alors</strong> il est divisible par <strong>2</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Justification :</strong> Un nombre pair est un nombre qui peut s'écrire 2 × k (par exemple : 8 = 2 × 4), donc il est divisible par 2.</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Astuce :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Quand on utilise "si…, alors…", on fait un raisonnement logique. La partie "si" est la <strong>condition</strong>, la partie "alors" est la <strong>conséquence</strong>.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Exercices "vrai/faux" avec justification</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Justifier ses réponses</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Exercices "vrai/faux"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Dans un exercice "vrai/faux", il faut :</p>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Dire</strong> si l'affirmation est vraie ou fausse</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Justifier</strong> sa réponse avec un calcul ou un raisonnement</li>
            </ol>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il ne suffit <strong>pas</strong> de cocher "vrai" ou "faux" : il faut <strong>expliquer pourquoi</strong> !</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Vrai/faux avec calcul</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "Le périmètre d'un carré de côté 6 cm est égal à 24 cm."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">C'est <strong>VRAI</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Justification :</strong> Le périmètre d'un carré se calcule avec P = 4 × c.</li>
                <li style="margin:0 0 12px 0; text-align:left;">Si c = 6 cm, alors P = 4 × 6 = 24 cm.</li>
                <li style="margin:0; text-align:left;">Donc l'affirmation est vraie.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Vrai/faux avec comparaison</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "150 cm est égal à 1,5 m."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">C'est <strong>VRAI</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Justification :</strong> On sait que 1 m = 100 cm, donc 1,5 m = 1,5 × 100 = 150 cm.</li>
                <li style="margin:0; text-align:left;">Donc 150 cm = 1,5 m, l'affirmation est vraie.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Vrai/faux avec raisonnement</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "Si un nombre se termine par 5, alors il est divisible par 5."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">C'est <strong>VRAI</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Justification :</strong> Les nombres qui se terminent par 5 sont : 5, 15, 25, 35, 45, 55, …</li>
                <li style="margin:0 0 12px 0; text-align:left;">On peut vérifier : 15 ÷ 5 = 3, 25 ÷ 5 = 5, 35 ÷ 5 = 7, …</li>
                <li style="margin:0; text-align:left;">Tous ces nombres sont bien divisibles par 5. Donc l'affirmation est vraie.</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Vrai/faux - Faux avec contre-exemple</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "Si un nombre est divisible par 4, alors il est divisible par 8."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Réponse :</strong></p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">C'est <strong>FAUX</strong>.</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Justification :</strong> Le nombre 12 est divisible par 4 (car 12 ÷ 4 = 3), mais 12 n'est pas divisible par 8 (car 12 ÷ 8 = 1,5 qui n'est pas un nombre entier).</li>
                <li style="margin:0; text-align:left;">Donc l'affirmation est fausse. Un <strong>contre-exemple</strong> permet de prouver qu'une affirmation est fausse.</li>
            </ul>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Méthode pour les exercices vrai/faux :</strong>
            <ol style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Lire</strong> attentivement l'affirmation</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Essayer</strong> de vérifier avec un exemple ou un calcul</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Si c'est vrai :</strong> expliquer pourquoi avec un calcul ou un raisonnement</li>
                <li style="margin:0; text-align:left;"><strong>Si c'est faux :</strong> donner un <strong>contre-exemple</strong> (un exemple qui montre que c'est faux)</li>
            </ol>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Les connecteurs logiques : et, ou, non</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Utiliser les mots logiques</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Connecteurs logiques</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En mathématiques, on utilise des mots pour relier des phrases ou des conditions. Ces mots sont appelés des <strong>connecteurs logiques</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Les trois principaux connecteurs sont : <strong>et</strong>, <strong>ou</strong>, <strong>non</strong>.</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le connecteur "et"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le mot "<strong>et</strong>" signifie que <strong>les deux conditions</strong> doivent être vraies en même temps.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Le connecteur "et"</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">"Un nombre est pair <strong>et</strong> divisible par 5."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela signifie : le nombre doit être <strong>à la fois</strong> pair <strong>ET</strong> divisible par 5.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : 10 (car 10 est pair ET 10 ÷ 5 = 2), 20, 30, …</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le connecteur "ou"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le mot "<strong>ou</strong>" signifie qu'<strong>au moins une des deux conditions</strong> doit être vraie (ou les deux).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Le connecteur "ou"</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">"Un nombre est pair <strong>ou</strong> divisible par 5."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela signifie : le nombre peut être pair <strong>OU</strong> divisible par 5 (ou les deux).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : 4 (pair), 15 (divisible par 5), 10 (les deux), 8 (pair), 25 (divisible par 5), …</p>
        </div>

        <div style="background:#f3e8ff; border-radius:6px; border-left:6px solid #9333ea; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Le connecteur "non"</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Le mot "<strong>non</strong>" signifie qu'on prend <strong>l'opposé</strong> ou le contraire d'une condition.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Le connecteur "non"</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">"Un nombre qui est <strong>non</strong> pair" signifie "un nombre qui n'est pas pair", c'est-à-dire un nombre <strong>impair</strong>.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : 3, 5, 7, 9, 11, … sont des nombres non pairs (impairs).</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple : Combinaisons de connecteurs</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">"Un nombre est pair <strong>et</strong> <strong>non</strong> divisible par 4."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cela signifie : le nombre doit être pair <strong>ET</strong> ne doit pas être divisible par 4.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : 2 (pair mais pas divisible par 4), 6, 10, 14, 18, …</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par contre, 4, 8, 12, 16 ne conviennent pas car ils sont divisibles par 4.</p>
        </div>

        <div style="background:#fff3cd; border-radius:6px; border-left:6px solid #ffc107; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;">En mathématiques, le mot "<strong>ou</strong>" signifie "<strong>ou bien</strong>" : au moins une condition est vraie, mais les deux peuvent être vraies aussi.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Ce n'est pas "ou exclusif" (soit l'un soit l'autre, mais pas les deux).</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Vrai pour un exemple vs vrai pour tous les nombres</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Différence importante</h3>

        <div style="background:#e8f4fd; border-radius:6px; border-left:6px solid #3498db; padding:15px; margin:12px 0;">
            <p style="text-align:left; font-size:1em;"><strong>📌 Une distinction importante</strong></p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Il y a une grande différence entre :</p>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;">Une affirmation qui est <strong>vraie pour un exemple</strong> (ou quelques exemples)</li>
                <li style="margin:0; text-align:left;">Une affirmation qui est <strong>vraie pour tous les nombres</strong> (toujours vraie)</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 1 : Vrai pour un exemple seulement</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "Le nombre 6 est pair."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette affirmation est <strong>vraie pour l'exemple 6</strong> (car 6 = 2 × 3).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Mais cela ne signifie <strong>pas</strong> que tous les nombres sont pairs !</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Par exemple : 7 n'est pas pair, 9 n'est pas pair, etc.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 2 : Vrai pour tous les nombres</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation :</strong> "Si un nombre est pair, alors il est divisible par 2."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette affirmation est <strong>vraie pour tous les nombres pairs</strong>, sans exception !</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Peu importe quel nombre pair on choisit (4, 10, 28, 100, …), il sera toujours divisible par 2.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Justification :</strong> Par définition, un nombre pair est un nombre de la forme 2 × k, donc il est toujours divisible par 2.</p>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 3 : Confusion à éviter</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation fausse :</strong> "Tous les nombres divisibles par 4 sont divisibles par 8."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">Cette affirmation est <strong>fausse</strong> !</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Contre-exemple :</strong> Le nombre 12 est divisible par 4 (car 12 ÷ 4 = 3), mais 12 n'est pas divisible par 8 (car 12 ÷ 8 = 1,5).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Attention :</strong> Le fait que certains nombres soient divisibles par 4 ET par 8 (comme 8, 16, 24, …) ne suffit pas pour dire que c'est vrai pour TOUS les nombres !</p>
        </div>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Comment savoir si c'est vrai pour tous ?</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour prouver que c'est vrai pour tous :</strong> expliquer avec un raisonnement général (définition, propriété, formule)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour prouver que c'est faux :</strong> donner <strong>un seul contre-exemple</strong> suffit</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Des exemples qui marchent</strong> ne prouvent pas que c'est vrai pour tous !</li>
                <li style="margin:0; text-align:left;"><strong>Un seul exemple qui ne marche pas</strong> prouve que c'est faux pour tous</li>
            </ul>
        </div>

        <div style="background:#f8f9fa; border-radius:6px; border-left:6px solid #6c757d; padding:15px; margin:12px 0;">
            <strong>Exemple 4 : Comparaison</strong>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation A :</strong> "Le nombre 10 est divisible par 5."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">→ C'est <strong>vrai pour cet exemple</strong> (10 ÷ 5 = 2), mais cela ne dit rien sur les autres nombres.</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Affirmation B :</strong> "Si un nombre se termine par 0 ou 5, alors il est divisible par 5."</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;">→ C'est <strong>vrai pour TOUS les nombres</strong> qui se terminent par 0 ou 5 (5, 10, 15, 20, 25, 30, …).</p>
            <p style="margin:8px 0; text-align:left; font-size:1em;"><strong>Différence :</strong> L'affirmation A parle d'un nombre précis (10), l'affirmation B parle de tous les nombres qui vérifient une condition.</p>
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VII. Conseils et erreurs à éviter</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <h3 style="color:#34495e; margin-top:0;">Conseils pratiques</h3>

        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>✅ Conseils pour réussir :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Toujours expliquer</strong> sa démarche étape par étape, même si cela semble évident</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Utiliser des phrases</strong> pour expliquer : "Je sais que...", "J'utilise la formule...", "Je calcule..."</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour "si…, alors…" :</strong> bien identifier la condition (après "si") et la conséquence (après "alors")</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les connecteurs logiques :</strong> bien comprendre la différence entre "et" (les deux conditions), "ou" (au moins une), "non" (le contraire)</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour les exercices vrai/faux :</strong> toujours justifier, ne jamais répondre juste "vrai" ou "faux" sans explication</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Si c'est faux :</strong> donner un <strong>contre-exemple</strong> pour prouver que c'est faux</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Différence importante :</strong> ne pas confondre "vrai pour un exemple" et "vrai pour tous les nombres"</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Vérifier</strong> sa réponse en refaisant le calcul ou le raisonnement</li>
                <li style="margin:0; text-align:left;"><strong>Écrire clairement</strong> : une bonne présentation aide à comprendre la démarche</li>
            </ul>
        </div>

        <div style="background:#fee2e2; border-radius:6px; border-left:6px solid #dc2626; padding:15px; margin:12px 0;">
            <strong>⚠️ Erreurs fréquentes à éviter :</strong>
            <ul style="margin:8px 0; padding-left:20px; line-height:1.8; font-size:1em;">
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Donner juste la réponse</strong> sans expliquer comment on l'a trouvée</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Oublier de justifier</strong> dans les exercices vrai/faux</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondre "si…, alors…"</strong> : bien identifier la condition et la conséquence</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Confondre "et" et "ou"</strong> : "et" signifie les deux conditions, "ou" signifie au moins une</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Penser qu'un exemple suffit</strong> pour prouver qu'une affirmation est vraie pour tous les nombres</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Ne pas vérifier</strong> ses calculs ou son raisonnement</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Pour prouver qu'une affirmation est fausse :</strong> donner juste "c'est faux" sans contre-exemple</li>
                <li style="margin:0 0 12px 0; text-align:left;"><strong>Écrire trop vite</strong> sans structurer sa démarche</li>
                <li style="margin:0; text-align:left;"><strong>Oublier les unités</strong> dans les réponses (cm, m, etc.)</li>
            </ul>
        </div>
    </div>
