📚 Objectif pédagogique : retenir l’essentiel : définition, règles de calcul, signe, variations et dérivée de l’exponentielle. Programme de Première.

I. Définition et règles

$\displaystyle \exp' = \exp$, $\displaystyle e^0 = 1$, $\displaystyle e^{a + b} = e^a \times e^b$

[IMAGE_1]

1️⃣ $\displaystyle e^{-a} = \frac{1}{e^a}$ ; $\displaystyle e^{a - b} = \frac{e^a}{e^b}$ ; $\displaystyle (e^a)^n = e^{na}$.

2️⃣ $\displaystyle e^x \gt 0$ pour tout $\displaystyle x$ ; $\displaystyle \exp$ strictement croissante ; tangente en $\displaystyle 0$ : $\displaystyle y = x + 1$.

3️⃣ $\displaystyle e^a = e^b \iff a = b$ ; $\displaystyle e^a \lt e^b \iff a \lt b$.

II. Dériver et étudier

[IMAGE_2]

1️⃣ $\displaystyle \left(e^{ax + b}\right)' = a\,e^{ax + b}$ ; $\displaystyle e^{kx}$ croissante si $\displaystyle k \gt 0$, décroissante si $\displaystyle k \lt 0$.

2️⃣ Dans $\displaystyle f'(x) = (\ldots)\,e^{x}$, le signe est celui de la parenthèse.

3️⃣ $\displaystyle (e^{na})$ est géométrique de raison $\displaystyle e^a$.

III. Les pièges à éviter

⚠️ Les 4 erreurs classiques :

1️⃣ Écrire $\displaystyle e^{a + b} = e^a + e^b$ : c’est un produit.

2️⃣ Chercher une solution à $\displaystyle e^x = 0$ ou $\displaystyle e^x \lt 0$ : il n’y en a pas.

3️⃣ Oublier le facteur $\displaystyle a$ en dérivant $\displaystyle e^{ax + b}$.

4️⃣ Étudier le signe de $\displaystyle e^x$ dans un tableau : il est toujours positif.

🏆 Réflexe : équation avec des exponentielles → je mets chaque membre sous la forme $\displaystyle e^{\ldots}$ puis je compare les exposants.
