Titre: Statistiques et diagrammes

<!-- optitab:1 -->
::: objectifs
- Organiser des données : effectifs, effectif total, fréquences (en écriture décimale et en pourcentage).
- Calculer une moyenne simple et une moyenne pondérée (par des effectifs ou des coefficients).
- Déterminer une médiane et une étendue, et les interpréter.
- Lire et construire un diagramme en bâtons ou en barres, un diagramme circulaire, un histogramme simple, une courbe.
- Utiliser un tableur et comparer deux séries avec un regard critique.
:::

## I. Effectifs et fréquences

::: definition Vocabulaire
- On étudie un **caractère** (le nombre de livres lus, le sport préféré, la taille…) sur une **population** (les élèves d'une classe, les habitants d'une ville…).
- Les données recueillies forment une **série statistique**.
- L'**effectif** d'une valeur est le nombre de fois où elle apparaît ; l'**effectif total** $N$ est la somme de tous les effectifs.
:::

::: definition Fréquence
La **fréquence** d'une valeur est le quotient de son effectif par l'effectif total :

$$\text{fréquence} = \frac{\text{effectif de la valeur}}{\text{effectif total}}$$

On l'écrit sous forme de fraction, de nombre décimal ou de pourcentage.
:::

::: propriete
Une fréquence est toujours comprise entre $0$ et $1$, c'est-à-dire entre $0\ \%$ et $100\ \%$. La somme de toutes les fréquences vaut $1$, soit $100\ \%$.
:::

::: exemple Les livres lus en un mois
On a demandé aux $25$ élèves d'une classe combien de livres ils ont lus le mois dernier.

| Livres lus | Effectif | Fréquence |
|---|---|---|
| $0$ | $2$ | $8\ \%$ |
| $1$ | $6$ | $24\ \%$ |
| $2$ | $9$ | $36\ \%$ |
| $3$ | $5$ | $20\ \%$ |
| $4$ | $3$ | $12\ \%$ |
| Total | $25$ | $100\ \%$ |

Par exemple, $9$ élèves ont lu $2$ livres : fréquence $\dfrac{9}{25} = 0{,}36$, soit $36\ \%$. Contrôle : $8 + 24 + 36 + 20 + 12 = 100$.
:::

::: methode Passer d'une fréquence à un pourcentage
On calcule le quotient, puis on multiplie par $100$ : $\dfrac{9}{25} = 0{,}36$ et $0{,}36 \times 100 = 36$, soit $36\ \%$.
:::

## II. La moyenne

::: definition Moyenne simple
La **moyenne** d'une série est la somme de toutes les valeurs divisée par l'effectif total :

$$\text{moyenne} = \frac{\text{somme des valeurs}}{\text{effectif total}}$$
:::

::: exemple
Notes : $11$ ; $15$ ; $8$ ; $14$ ; $12$. Somme : $11 + 15 + 8 + 14 + 12 = 60$ ; moyenne : $\dfrac{60}{5} = 12$.
:::

::: definition Moyenne pondérée
Quand chaque valeur a un **effectif** (ou un **coefficient**), on multiplie chaque valeur par son effectif, on additionne ces produits, puis on divise par l'effectif total (ou par la somme des coefficients) :

$$\text{moyenne} = \frac{\text{somme des produits}}{\text{effectif total}}$$

où chaque produit est « valeur $\times$ effectif ».
:::

::: exemple Les livres lus (tableau du I)
On ajoute au tableau une colonne « valeur $\times$ effectif » :

| Livres lus | Effectif | Valeur $\times$ effectif |
|---|---|---|
| $0$ | $2$ | $0 \times 2 = 0$ |
| $1$ | $6$ | $1 \times 6 = 6$ |
| $2$ | $9$ | $2 \times 9 = 18$ |
| $3$ | $5$ | $3 \times 5 = 15$ |
| $4$ | $3$ | $4 \times 3 = 12$ |
| Total | $25$ | $51$ |

$$\text{moyenne} = \frac{51}{25} = 2{,}04$$

En moyenne, un élève a lu $2{,}04$ livres : une moyenne n'est pas forcément une valeur de la série.
:::

::: exemple Des notes avec coefficients
Notes $12$ (coefficient $2$), $15$ (coefficient $1$) et $9$ (coefficient $3$) :

- produits : $12 \times 2 = 24$ ; $15 \times 1 = 15$ ; $9 \times 3 = 27$ ;
- somme des coefficients : $2 + 1 + 3 = 6$.

$$\text{moyenne} = \frac{24 + 15 + 27}{6} = \frac{66}{6} = 11$$
:::

::: propriete Retrouver une somme
Puisque moyenne $= \dfrac{\text{somme}}{\text{effectif}}$, on a : **somme $=$ moyenne $\times$ effectif total**. Cela permet de retrouver une valeur manquante ou de réunir deux groupes.
:::

::: attention Erreurs fréquentes
- Faire la moyenne des valeurs d'un tableau **sans tenir compte des effectifs** : avec le tableau du I, $\dfrac{0 + 1 + 2 + 3 + 4}{5} = 2$, et non $2{,}04$.
- Diviser par le nombre de valeurs différentes au lieu de l'effectif total (ou de la somme des coefficients).
- Pour réunir deux groupes d'effectifs différents, on ne fait pas la moyenne des deux moyennes : on additionne les **sommes** et les **effectifs**.
:::

## III. La médiane et l'étendue

::: definition Médiane
La **médiane** d'une série **rangée dans l'ordre croissant** est un nombre qui partage la série en deux groupes de même effectif : la moitié des valeurs lui sont inférieures ou égales, l'autre moitié lui sont supérieures ou égales.
:::

::: methode Déterminer une médiane
1. **Ranger** la série dans l'ordre croissant (en gardant les valeurs répétées).
2. Si l'effectif $N$ est **impair**, la médiane est la valeur du milieu, de rang $\dfrac{N+1}{2}$.
3. Si l'effectif $N$ est **pair**, la médiane est la moyenne des deux valeurs du milieu, de rangs $\dfrac{N}{2}$ et $\dfrac{N}{2} + 1$.
:::

[IMAGE_1]

::: exemple Effectif impair, effectif pair
- Série $13$ ; $8$ ; $17$ ; $10$ ; $12$ ; $8$ ; $15$. Rangée : $8$ ; $8$ ; $10$ ; $12$ ; $13$ ; $15$ ; $17$. $N = 7$ : la médiane est la 4ᵉ valeur, $12$.
- Série rangée $4$ ; $7$ ; $7$ ; $9$ ; $12$ ; $14$ ; $15$ ; $20$. $N = 8$ : la médiane est la moyenne des 4ᵉ et 5ᵉ valeurs, $\dfrac{9 + 12}{2} = 10{,}5$.
:::

::: methode Médiane d'un tableau d'effectifs
On compte les valeurs dans l'ordre en ajoutant les effectifs. Tableau du I ($N = 25$) : la médiane est la 13ᵉ valeur. Les valeurs $0$ occupent les rangs $1$ à $2$, les valeurs $1$ les rangs $3$ à $8$, les valeurs $2$ les rangs $9$ à $17$ : la 13ᵉ valeur est $2$, donc la médiane vaut $2$.
:::

::: definition Étendue
L'**étendue** d'une série est la différence entre la plus grande et la plus petite valeur :

$$\text{étendue} = \text{max} - \text{min}$$

(« max » : la plus grande valeur ; « min » : la plus petite.)

Elle mesure la **dispersion** des valeurs : plus elle est grande, plus les valeurs sont éparpillées.
:::

::: exemple
Pour la série rangée $4$ ; $7$ ; $7$ ; $9$ ; $12$ ; $14$ ; $15$ ; $20$ : étendue $20 - 4 = 16$.
:::

::: remarque Moyenne ou médiane ?
La moyenne est sensible aux **valeurs extrêmes**, la médiane non. Dans la série précédente, la moyenne vaut $\dfrac{88}{8} = 11$. Si l'on remplace $20$ par $60$, la moyenne passe à $\dfrac{128}{8} = 16$, mais la médiane reste $10{,}5$.
:::

::: attention Erreurs fréquentes
- Chercher la médiane **sans avoir rangé** la série.
- Avec un effectif pair, prendre une seule des deux valeurs du milieu.
- Calculer l'étendue avec les effectifs au lieu des valeurs.
:::

## IV. Lire et construire des diagrammes

### Diagramme en bâtons ou en barres

Chaque valeur (ou chaque catégorie) est représentée par un bâton ou une barre dont la **hauteur est proportionnelle à l'effectif**. Le diagramme ci-dessous représente le tableau des livres lus (partie I).

[IMAGE_2]

::: methode Construire un diagramme en bâtons
1. Placer les valeurs sur l'axe horizontal, régulièrement espacées.
2. Graduer l'axe vertical **à partir de $0$**, avec un pas régulier adapté au plus grand effectif.
3. Tracer pour chaque valeur un bâton de hauteur égale à son effectif ; donner un titre aux axes.
:::

### Diagramme circulaire

::: methode Construire un diagramme circulaire
L'angle de chaque secteur est **proportionnel à l'effectif** : l'effectif total correspond à $360^\circ$.

$$\text{angle} = \frac{\text{effectif}}{\text{effectif total}} \times 360^\circ$$

C'est-à-dire : angle $=$ fréquence $\times 360^\circ$.

On vérifie que la somme des angles vaut $360^\circ$, puis on trace les secteurs au rapporteur.
:::

::: exemple L'activité préférée du mercredi
Sur $36$ élèves : sport $15$, jeux vidéo $9$, lecture $6$, musique $6$. Comme $36$ élèves correspondent à $360^\circ$, un élève correspond à $10^\circ$ :

| Activité | Effectif | Angle |
|---|---|---|
| Sport | $15$ | $15 \times 10^\circ = 150^\circ$ |
| Jeux vidéo | $9$ | $9 \times 10^\circ = 90^\circ$ |
| Lecture | $6$ | $6 \times 10^\circ = 60^\circ$ |
| Musique | $6$ | $6 \times 10^\circ = 60^\circ$ |
| Total | $36$ | $360^\circ$ |
:::

[IMAGE_3]

::: remarque
$1\ \%$ correspond à $3{,}6^\circ$ ; $25\ \%$ à un quart de disque ($90^\circ$) ; $50\ \%$ à un demi-disque ($180^\circ$).
:::

### Histogramme

Quand les données sont regroupées en **classes** de même largeur, on les représente par un **histogramme** : des rectangles **accolés**, dont la hauteur donne l'effectif de chaque classe. La classe $[150\ ;\ 160[$ contient $150$ mais pas $160$.

[IMAGE_4]

::: attention Données en classes
On ne connaît plus les valeurs exactes : on peut seulement dire dans quelle **classe** se trouve la médiane, et **estimer** la moyenne en remplaçant chaque classe par son centre (par exemple $155$ pour $[150\ ;\ 160[$).
:::

### Courbe

Pour suivre l'**évolution** d'une grandeur (dans le temps, par exemple), on place les points de coordonnées (instant ; valeur) et on les relie par des segments.

[IMAGE_5]

::: exemple Températures relevées toutes les deux heures
Sur la courbe, on lit : la température maximale est $21$ °C à $14$ h, la minimale $8$ °C à $6$ h ; l'étendue des relevés est $21 - 8 = 13$ °C. La température augmente de $6$ h à $14$ h, puis diminue.
:::

::: remarque
Entre deux relevés, les segments ne donnent qu'une **estimation** : la température n'a pas été mesurée à $9$ h.
:::

## V. Tableur, comparaison et regard critique

::: methode Avec un tableur
Les valeurs sont saisies dans la plage A2:A20 :
- somme : `=SOMME(A2:A20)` ; moyenne : `=MOYENNE(A2:A20)` ;
- médiane : `=MEDIANE(A2:A20)` ;
- étendue : `=MAX(A2:A20)-MIN(A2:A20)`.

Pour un tableau d'effectifs (valeurs en A, effectifs en B), on calcule les produits en C avec `=A2*B2` recopiée vers le bas, puis la moyenne avec :

`=SOMME(C2:C6)/SOMME(B2:B6)`
:::

::: attention
`=MOYENNE(A2:A6)` sur la colonne des valeurs d'un tableau d'effectifs donne la moyenne **sans les effectifs** : le résultat est faux.
:::

::: methode Comparer deux séries
On compare un indicateur de **position** (moyenne ou médiane) **et** un indicateur de **dispersion** (l'étendue). Deux séries de même moyenne peuvent être très différentes.
:::

[IMAGE_6]

::: exemple
Série A : $9$ ; $10$ ; $10$ ; $10$ ; $11$. Série B : $2$ ; $6$ ; $11$ ; $14$ ; $17$. Les deux moyennes valent $\dfrac{50}{5} = 10$, mais l'étendue de A est $11 - 9 = 2$ et celle de B est $17 - 2 = 15$ : les valeurs de B sont bien plus dispersées.
:::

::: remarque Lecture critique d'un graphique
Avant de comparer des hauteurs, on lit les **graduations** : un axe vertical qui ne commence pas à $0$ peut faire paraître énorme une petite différence. On vérifie aussi les unités et la taille des groupes comparés (on compare des **fréquences**, pas des effectifs, quand les groupes n'ont pas la même taille).
:::

::: retenir
- Fréquence $=$ effectif $\div$ effectif total ; la somme des fréquences vaut $100\ \%$.
- Moyenne pondérée $=$ somme des (valeur $\times$ effectif) $\div$ effectif total.
- Médiane : on **range** d'abord la série ; valeur du milieu, ou moyenne des deux valeurs du milieu.
- Étendue $=$ plus grande valeur $-$ plus petite valeur (dispersion).
- Diagramme circulaire : angle $=$ fréquence $\times 360^\circ$ ; somme des angles $= 360^\circ$.
- Pour comparer deux séries : position (moyenne, médiane) **et** dispersion (étendue).
:::
