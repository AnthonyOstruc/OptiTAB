🎯 Objectifs du chapitre : comprendre la notion d’échantillon et la fluctuation d’échantillonnage, utiliser la stabilisation des fréquences pour estimer une probabilité, connaître l’ordre de grandeur $\displaystyle \frac{1}{\sqrt{n}}$ de l’écart entre fréquence et probabilité, et simuler des échantillons en Python.

I. Échantillon et fluctuation

Définition : un échantillon de taille $\displaystyle n$ est la liste des résultats obtenus en répétant $\displaystyle n$ fois, de façon indépendante, la même expérience aléatoire. Si un événement $\displaystyle A$ est réalisé $\displaystyle k$ fois, sa fréquence dans l’échantillon est $\displaystyle f = \frac{k}{n}$.

Exemple : on lance $\displaystyle 50$ fois une pièce et on obtient $\displaystyle 27$ fois « pile » : la fréquence de « pile » est $\displaystyle f = \frac{27}{50} = 0{,}54$. Un autre échantillon de $\displaystyle 50$ lancers donnera en général une autre fréquence : c’est la fluctuation d’échantillonnage.

II. Stabilisation des fréquences

Loi des grands nombres : lorsque la taille $\displaystyle n$ de l’échantillon devient grande, la fréquence $\displaystyle f$ d’un événement se rapproche de sa probabilité $\displaystyle p$.

[IMAGE_1]
💡 Estimer une probabilité : quand $\displaystyle p$ est inconnue (punaise qui tombe sur la pointe, dé déformé…), on l’estime par la fréquence observée sur un grand nombre d’expériences.

III. Précision d’une estimation

Propriété (observée par simulation) : pour des échantillons de taille $\displaystyle n$ assez grande, dans environ $\displaystyle 95\,\%$ des cas, la fréquence $\displaystyle f$ vérifie $\displaystyle |f - p| \le \frac{1}{\sqrt{n}}$, c’est-à-dire $\displaystyle p - \frac{1}{\sqrt{n}} \le f \le p + \frac{1}{\sqrt{n}}$.

[IMAGE_2]

Exemple : pour $\displaystyle n = 400$, $\displaystyle \frac{1}{\sqrt{400}} = 0{,}05$ : dans environ $\displaystyle 95\,\%$ des échantillons, la fréquence est à moins de $\displaystyle 0{,}05$ de $\displaystyle p$. Pour diviser cet écart par $\displaystyle 2$, il faut multiplier la taille de l’échantillon par $\displaystyle 4$.

Application : on lance $\displaystyle 1\,000$ fois un dé et le $\displaystyle 6$ sort $\displaystyle 210$ fois. Ici $\displaystyle f = 0{,}21$, $\displaystyle p = \frac{1}{6} \approx 0{,}167$ et $\displaystyle \frac{1}{\sqrt{1\,000}} \approx 0{,}032$. Comme $\displaystyle |f - p| \approx 0{,}043 \gt 0{,}032$, on peut douter que le dé soit équilibré.

⚠️ Attention : ce n’est pas une certitude. Même avec un dé équilibré, environ $\displaystyle 5\,\%$ des échantillons s’écartent de plus de $\displaystyle \frac{1}{\sqrt{n}}$ : la conclusion comporte toujours un risque d’erreur.

IV. Simuler en Python

L’instruction random() renvoie un nombre au hasard dans $\displaystyle [0\,;1[$ : le test « random() < p » est donc vrai avec la probabilité $\displaystyle p$.

from random import random from math import sqrt def frequence(n, p): k = 0 for i in range(n): if random() < p: k = k + 1 return k / n def proportion_proches(N, n, p): c = 0 for j in range(N): if abs(frequence(n, p) - p) <= 1 / sqrt(n): c = c + 1 return c / N

Exemple : proportion_proches(1000, 100, 0.5) renvoie une valeur proche de $\displaystyle 0{,}95$.

🏆 L’essentiel : la fréquence $\displaystyle f = \frac{k}{n}$ varie d’un échantillon à l’autre (fluctuation) ; quand $\displaystyle n$ augmente, $\displaystyle f$ se stabilise autour de $\displaystyle p$ (loi des grands nombres) ; dans environ $\displaystyle 95\,\%$ des cas, $\displaystyle |f - p| \le \frac{1}{\sqrt{n}}$ ; une simulation en Python permet de le vérifier.
