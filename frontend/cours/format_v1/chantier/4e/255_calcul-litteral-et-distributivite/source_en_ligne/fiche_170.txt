Titre: Résumé : Calcul littéral et distributivité

<div style="background:#f9f9f9; padding:20px; border-radius:12px; font-family:Arial, sans-serif; line-height:1.6;">

<div style="background:#e8f4fd; border:2px solid #3498db; border-radius:8px; padding:15px; margin-bottom:20px;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>📚 Objectif pédagogique :</strong> retenir l'essentiel : écrire, calculer, réduire, développer, factoriser, prouver. Programme de 4ème.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Écrire, calculer, réduire</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• $3 \times x = 3x$ ; $x \times x = x^2$ ; $2 \times (x + 1) = 2(x + 1)$.</p>
<p style="margin:6px 0 0 0;">• <strong>Remplacer</strong> la lettre par sa valeur <strong>entre parenthèses</strong> : pour $x = -2$, $x^2 = (-2)^2 = 4$.</p>
<p style="margin:6px 0 0 0;">• <strong>Réduire</strong> : $7a - 2 + 3a + 9 = 10a + 7$ ; mais $3x + 2$ et $x^2 + x$ ne se réduisent pas.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Développer et factoriser</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
[IMAGE_1]
<p style="margin:0;">• $k(a + b) = ka + kb$ ; $-(a - b) = -a + b$.</p>
[IMAGE_2]
<p style="margin:6px 0 0 0;">• $(a + b)(c + d) = ac + ad + bc + bd$ : $(x + 3)(x + 2) = x^2 + 5x + 6$.</p>
<p style="margin:6px 0 0 0;">• <strong>Factoriser</strong> : $ka + kb = k(a + b)$ ; $3x^2 - 6x = 3x(x - 2)$.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Prouver</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<p style="margin:0;">• Égalité <strong>fausse</strong> : un contre-exemple suffit.</p>
<p style="margin:6px 0 0 0;">• Égalité <strong>toujours vraie</strong> : on développe ou on réduit avec la lettre.</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Les pièges à éviter</h2>

<div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
<p style="margin:0;"><strong>⚠️ Les 4 erreurs classiques :</strong></p>
<p style="margin:6px 0 0 0;">1️⃣ $x + x = x^2$ (faux : $2x$) et $3x + 2x = 5x^2$ (faux : $5x$).</p>
<p style="margin:6px 0 0 0;">2️⃣ $-(3x - 7) = -3x - 7$ (faux : $-3x + 7$).</p>
<p style="margin:6px 0 0 0;">3️⃣ $(x + 3)^2 = x^2 + 9$ (faux : $x^2 + 6x + 9$).</p>
<p style="margin:6px 0 0 0;">4️⃣ Croire qu'un exemple qui marche prouve une égalité.</p>
</div>

<div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
<p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 Réflexe :</strong> après un développement, je teste avec une valeur simple ($x = 1$ ou $x = 10$) : les deux expressions doivent donner le même nombre.</p>
</div>
