=== Algorithmique - Lire et écrire une fonction de simulation (fréquence)
Id: 2009
Difficulté: medium

Énoncé: <!-- optitab:1 -->
On considère la fonction Python suivante.

```python
from random import random

def freq(n, p):
    k = 0
    for i in range(n):
        if random() < p:
            k = k + 1
    return k / n
```

L’instruction `random()` renvoie un nombre décimal au hasard dans $[0\,;1[$.

1. Que représentent `n`, `p` et `k` ? Pourquoi le test `random() < p` est-il vrai avec la probabilité $p$ ?
2. On appelle `freq(10, 0.3)`. Les nombres renvoyés successivement par `random()` sont : $0{,}12$ ; $0{,}77$ ; $0{,}05$ ; $0{,}31$ ; $0{,}29$ ; $0{,}90$ ; $0{,}18$ ; $0{,}33$ ; $0{,}02$ ; $0{,}60$. Donner la valeur finale de `k` et la valeur renvoyée.
3. Un appel `freq(50, p)` renvoie $0{,}62$. Combien de succès ont été obtenus ?
4. Expliquer pourquoi la valeur renvoyée est toujours comprise entre $0$ et $1$.
5. Écrire une fonction `nb_six(n)` qui simule $n$ lancers d’un dé équilibré à $6$ faces et renvoie le **nombre** de $6$ obtenus. On utilisera `randint(1, 6)` du module `random`, qui renvoie un entier au hasard entre $1$ et $6$.

Étapes:

<!-- optitab:1 -->
## Question 1 : Rôle des variables et du test

::: methode
Lire la boucle et repérer ce qui change à chaque passage.
:::

::: etape Les variables
- `n` est le nombre de répétitions de l’expérience : la taille de l’échantillon.
- `p` est la probabilité du succès.
- `k` part de $0$ et augmente de $1$ à chaque succès : c’est le **nombre de succès**.
:::

::: etape Le test `random() < p`
Le nombre `random()` est pris au hasard dans $[0\,;1[$, intervalle de longueur $1$. Il tombe dans $[0\,;p[$, de longueur $p$, avec la probabilité $p$.
:::

::: resultat
`n` : taille de l’échantillon ; `p` : probabilité du succès ; `k` : nombre de succès. Le test `random() < p` simule un succès de probabilité $p$.
:::

## Question 2 : Exécution « à la main » de `freq(10, 0.3)`

::: methode
Pour chaque tirage, tester s’il est strictement inférieur à $0{,}3$ et mettre `k` à jour.
:::

::: etape Tableau de suivi
| Passage | `random()` | Inférieur à $0{,}3$ ? | `k` |
|---|---|---|---|
| $1$ | $0{,}12$ | oui | $1$ |
| $2$ | $0{,}77$ | non | $1$ |
| $3$ | $0{,}05$ | oui | $2$ |
| $4$ | $0{,}31$ | non | $2$ |
| $5$ | $0{,}29$ | oui | $3$ |
| $6$ | $0{,}90$ | non | $3$ |
| $7$ | $0{,}18$ | oui | $4$ |
| $8$ | $0{,}33$ | non | $4$ |
| $9$ | $0{,}02$ | oui | $5$ |
| $10$ | $0{,}60$ | non | $5$ |
:::

::: etape Valeur renvoyée
$$f = \frac{k}{n} = \frac{5}{10} = 0{,}5$$
:::

::: resultat
À la fin, `k` vaut $5$ et la fonction renvoie $0{,}5$.
:::

::: attention
$0{,}31$ et $0{,}33$ ne sont **pas** des succès : le test est strict, et $0{,}31 \gt 0{,}3$. Bien comparer les décimales.
:::

## Question 3 : Retrouver le nombre de succès

::: methode
$f = \frac{k}{n}$ donc $k = f \times n$.
:::

::: etape Calcul
$$k = 0{,}62 \times 50 = 31$$
:::

::: resultat
$31$ succès ont été obtenus.
:::

## Question 4 : Valeur entre $0$ et $1$

::: methode
Encadrer le nombre de succès.
:::

::: etape Encadrement
Le nombre de succès `k` est compris entre $0$ (aucun succès) et $n$ (que des succès) : $0 \le k \le n$. En divisant par $n \gt 0$ :
$$0 \le \frac{k}{n} \le 1$$
:::

::: resultat
La valeur renvoyée est une fréquence : elle est toujours comprise entre $0$ et $1$.
:::

## Question 5 : Écrire la fonction `nb_six`

::: methode
Reprendre la structure de `freq` : un compteur, une boucle, un test ; renvoyer le compteur (et non la fréquence).
:::

::: etape Le test
Un lancer de dé est simulé par `randint(1, 6)`. Le succès est « obtenir $6$ » : le test est `randint(1, 6) == 6`.
:::

::: etape La fonction
```python
from random import randint

def nb_six(n):
    k = 0
    for i in range(n):
        if randint(1, 6) == 6:
            k = k + 1
    return k
```
:::

::: resultat
La fonction `nb_six` ci-dessus renvoie le nombre de $6$ obtenus en $n$ lancers.
:::

::: attention
- On demande le **nombre** de $6$ : on renvoie `k`, pas `k / n`.
- Le `return` doit être **en dehors** de la boucle (même retrait que `for`) ; sinon la fonction s’arrête après le premier lancer.
- Le test d’égalité s’écrit `==` (et non `=`).
:::

Solution:
<!-- optitab:1 -->
1. `n` : taille de l’échantillon ; `p` : probabilité du succès ; `k` : nombre de succès. `random()` tombe dans $[0\,;p[$ avec la probabilité $p$.
2. `k` vaut $5$ ; la fonction renvoie $0{,}5$.
3. $k = 0{,}62 \times 50 = 31$ succès.
4. $0 \le k \le n$ donc $0 \le \frac{k}{n} \le 1$.
5. Boucle de $n$ lancers, test `randint(1, 6) == 6`, compteur `k` renvoyé après la boucle.

=== Algorithmique - Simuler N échantillons et mesurer la proportion de cas « proches »
Id: 2010
Difficulté: medium

Énoncé: <!-- optitab:1 -->
On considère le programme suivant.

```python
from random import random
from math import sqrt

def freq(n, p):
    k = 0
    for i in range(n):
        if random() < p:
            k = k + 1
    return k / n

def proche(N, n, p):
    e = 1 / sqrt(n)
    c = 0
    for j in range(N):
        f = freq(n, p)
        if abs(f - p) <= e:
            c = c + 1
    return c / N
```

1. Lors de l’appel `proche(500, 100, 0.5)`, combien d’échantillons sont simulés ? Combien de tirages au total ?
2. Que compte la variable `c` ? Que renvoie la fonction `proche` ?
3. Pour $n = 100$ et $p = 0{,}5$, calculer `e`, puis traduire la condition $|f - 0{,}5| \le e$ par un encadrement de $f$.
4. L’appel `proche(500, 100, 0.5)` renvoie $0{,}964$. Combien d’échantillons vérifient la condition ?
5. On exécute plusieurs fois `proche(1000, 400, 0.3)` et on obtient : $0{,}971$ ; $0{,}963$ ; $0{,}979$. Pourquoi les résultats sont-ils différents ? Interpréter ces résultats.

Étapes:

<!-- optitab:1 -->
## Question 1 : Nombre d’échantillons et de tirages

::: methode
Compter les passages dans chaque boucle.
:::

::: etape Boucle de `proche`
La boucle `for j in range(N)` est exécutée $N = 500$ fois : à chaque passage, `freq(n, p)` simule **un** échantillon.
:::

::: etape Boucle de `freq`
Chaque échantillon demande $n = 100$ tirages, d’où au total
$$500 \times 100 = 50\,000 \text{ tirages.}$$
:::

::: resultat
$500$ échantillons de taille $100$, soit $50\,000$ tirages.
:::

## Question 2 : Rôle de `c` et valeur renvoyée

::: methode
Regarder quand `c` augmente, puis lire le `return`.
:::

::: etape Le compteur
`c` augmente de $1$ chaque fois que $|f - p| \le e$ : `c` est le nombre d’échantillons dont la fréquence est « proche » de $p$.
:::

::: resultat
`c` compte les échantillons qui vérifient $|f - p| \le \frac{1}{\sqrt{n}}$ ; la fonction renvoie leur **proportion** $\frac{c}{N}$ parmi les $N$ échantillons.
:::

## Question 3 : Valeur de `e` et encadrement

::: methode
$|f - a| \le e$ équivaut à $a - e \le f \le a + e$.
:::

::: etape Calcul de `e`
$$e = \frac{1}{\sqrt{100}} = \frac{1}{10} = 0{,}1$$
:::

::: etape Encadrement
$$
\begin{aligned}
|f - 0{,}5| \le 0{,}1 &\iff 0{,}5 - 0{,}1 \le f \le 0{,}5 + 0{,}1 \\
&\iff 0{,}4 \le f \le 0{,}6
\end{aligned}
$$
:::

::: resultat
$e = 0{,}1$ et la condition signifie $f \in [0{,}4\,;0{,}6]$.
:::

## Question 4 : Nombre d’échantillons « proches »

::: methode
La fonction renvoie $\frac{c}{N}$, donc $c = \frac{c}{N} \times N$.
:::

::: etape Calcul
$$c = 0{,}964 \times 500 = 482$$
:::

::: resultat
$482$ échantillons sur $500$ vérifient la condition.
:::

## Question 5 : Interpréter plusieurs exécutions

::: methode
Une simulation utilise le hasard ; comparer les résultats à $95\,\%$.
:::

::: etape Pourquoi des résultats différents ?
Chaque exécution simule de nouveaux tirages au hasard : les $1\,000$ échantillons ne sont pas les mêmes, donc la proportion change (fluctuation).
:::

::: etape Interprétation
Ici $\frac{1}{\sqrt{400}} = 0{,}05$. Les résultats valent environ $97\,\%$ : dans environ $97\,\%$ des échantillons de taille $400$, la fréquence est comprise entre $0{,}25$ et $0{,}35$. C’est conforme au cours : au moins $95\,\%$ environ.
:::

::: resultat
Les résultats diffèrent car chaque simulation est aléatoire, mais tous sont proches de $97\,\%$, au-dessus de $95\,\%$ : $|f - p| \le \frac{1}{\sqrt{n}}$ dans la grande majorité des échantillons.
:::

Solution:
<!-- optitab:1 -->
1. $500$ échantillons, $50\,000$ tirages.
2. `c` compte les échantillons tels que $|f - p| \le \frac{1}{\sqrt{n}}$ ; la fonction renvoie leur proportion $\frac{c}{N}$.
3. $e = 0{,}1$ ; $0{,}4 \le f \le 0{,}6$.
4. $0{,}964 \times 500 = 482$ échantillons.
5. Chaque simulation est différente (hasard) ; environ $97\,\%$ des échantillons ont une fréquence dans $[0{,}25\,;0{,}35]$, ce qui est conforme au constat « au moins $95\,\%$ ».

=== Découverte - Échantillon et fréquence - Calculs de base
Id: 2004
Difficulté: easy

Énoncé: <!-- optitab:1 -->
On répète une expérience aléatoire à deux issues (succès / échec). Pour chaque situation, identifier $n$ (taille de l’échantillon) et $k$ (nombre de succès), puis répondre.

1. On lance une pièce $20$ fois et on obtient $11$ fois « pile » (succès). Calculer la fréquence $f$.
2. On contrôle $50$ ampoules : $3$ sont défectueuses (succès = « défectueuse »). Calculer $f$.
3. Dans un sondage, $72$ élèves sur $200$ déclarent venir en bus (succès = « bus »). Calculer $f$, puis donner le pourcentage.
4. Dans un échantillon de taille $n = 80$, la fréquence observée est $f = 0{,}375$. Déterminer $k$.
5. Sur $120$ réponses, $18$ sont favorables. Calculer $f$ sous forme de fraction irréductible, puis sous forme décimale.

Étapes:

<!-- optitab:1 -->
## Question 1 : Pièce lancée $20$ fois

::: methode
La fréquence est $f = \frac{k}{n}$ : nombre de succès divisé par la taille de l’échantillon.
:::

::: etape Identifier $n$ et $k$
$n = 20$ lancers et $k = 11$ « pile ».
:::

::: etape Calculer
$$f = \frac{11}{20} = 0{,}55$$
:::

::: resultat
$f = 0{,}55$
:::

## Question 2 : Ampoules défectueuses

::: methode
Ici le « succès » est d’avoir une ampoule défectueuse : un succès n’est pas forcément une bonne nouvelle.
:::

::: etape Calculer
$n = 50$ et $k = 3$ :
$$f = \frac{3}{50} = \frac{6}{100} = 0{,}06$$
:::

::: resultat
$f = 0{,}06$, soit $6\,\%$ d’ampoules défectueuses.
:::

## Question 3 : Sondage

::: methode
Calculer $f$, puis multiplier par $100$ pour obtenir un pourcentage.
:::

::: etape Fréquence
$$f = \frac{72}{200} = \frac{36}{100} = 0{,}36$$
:::

::: etape Pourcentage
$0{,}36 = \frac{36}{100} = 36\,\%$
:::

::: resultat
$f = 0{,}36$, soit $36\,\%$ des élèves interrogés.
:::

## Question 4 : Retrouver $k$

::: methode
$f = \frac{k}{n}$ donc $k = f \times n$.
:::

::: etape Calculer
$$k = 0{,}375 \times 80 = 30$$
:::

::: point Vérification
$\frac{30}{80} = \frac{3}{8} = 0{,}375$ : c’est bien la fréquence donnée.
:::

::: resultat
$k = 30$ succès.
:::

## Question 5 : Fraction irréductible

::: methode
Simplifier la fraction $\frac{k}{n}$ par le plus grand diviseur commun.
:::

::: etape Simplifier
Le plus grand diviseur commun de $18$ et $120$ est $6$ :
$$f = \frac{18}{120} = \frac{18 \div 6}{120 \div 6} = \frac{3}{20}$$
:::

::: etape Forme décimale
$$\frac{3}{20} = \frac{15}{100} = 0{,}15$$
:::

::: resultat
$f = \frac{3}{20} = 0{,}15$
:::

::: retenir
Une fréquence est toujours comprise entre $0$ et $1$ ; si l’on trouve plus de $1$, on a sans doute divisé $n$ par $k$ au lieu de $k$ par $n$.
:::

Solution:
<!-- optitab:1 -->
1. $f = \frac{11}{20} = 0{,}55$
2. $f = \frac{3}{50} = 0{,}06$ (soit $6\,\%$)
3. $f = \frac{72}{200} = 0{,}36$, soit $36\,\%$
4. $k = 0{,}375 \times 80 = 30$
5. $f = \frac{18}{120} = \frac{3}{20} = 0{,}15$

=== Découverte - Observer la stabilisation des fréquences
Id: 3752
Difficulté: easy

Énoncé: <!-- optitab:1 -->
On lance une punaise : le succès est « la punaise retombe pointe en haut ». Sa probabilité $p$ est inconnue. On a effectué $10\,000$ lancers et noté, au fur et à mesure, le nombre total $k$ de succès.

| Nombre $n$ de lancers | $10$ | $50$ | $100$ | $500$ | $1\,000$ | $5\,000$ | $10\,000$ |
|---|---|---|---|---|---|---|---|
| Nombre $k$ de succès | $9$ | $37$ | $66$ | $321$ | $642$ | $3\,099$ | $6\,196$ |

1. Calculer la fréquence $f = \frac{k}{n}$ pour chaque valeur de $n$ (arrondir au millième si besoin).
2. Décrire l’évolution de la fréquence quand $n$ augmente. Quelle propriété du cours retrouve-t-on ?
3. Proposer une estimation de $p$.
4. À l’aide des $10\,000$ lancers, donner un intervalle d’estimation de $p$.
5. Après $10$ lancers, Léa affirmait : « $p = 0{,}9$ ». Commenter.

Étapes:

<!-- optitab:1 -->
## Question 1 : Fréquences

::: methode
Diviser chaque nombre de succès par le nombre de lancers correspondant.
:::

::: etape Calculs
| $n$ | $10$ | $50$ | $100$ | $500$ | $1\,000$ | $5\,000$ | $10\,000$ |
|---|---|---|---|---|---|---|---|
| $f$ | $0{,}9$ | $0{,}74$ | $0{,}66$ | $0{,}642$ | $0{,}642$ | $0{,}620$ | $0{,}620$ |

Par exemple $\frac{3\,099}{5\,000} = 0{,}6198 \approx 0{,}620$ et $\frac{6\,196}{10\,000} = 0{,}6196 \approx 0{,}620$.
:::

::: resultat
Fréquences : $0{,}9$ ; $0{,}74$ ; $0{,}66$ ; $0{,}642$ ; $0{,}642$ ; $0{,}620$ ; $0{,}620$.
:::

## Question 2 : Évolution de la fréquence

::: methode
Comparer les fréquences au début et à la fin du tableau.
:::

::: etape Observation
- Pour de petites valeurs de $n$, la fréquence varie beaucoup : de $0{,}9$ à $0{,}66$.
- Pour de grandes valeurs de $n$, elle ne bouge presque plus : elle reste voisine de $0{,}62$.
:::

::: resultat
La fréquence se stabilise autour de $0{,}62$ quand $n$ augmente : c’est la **loi des grands nombres**.
:::

## Question 3 : Estimation de $p$

::: methode
La fréquence observée sur un grand nombre de lancers est une estimation de $p$.
:::

::: resultat
$p \approx 0{,}62$
:::

## Question 4 : Intervalle d’estimation

::: methode
Avec $n = 10\,000$ et $f = 0{,}6196$, utiliser l’intervalle $\left[f - \frac{1}{\sqrt{n}}\,;\, f + \frac{1}{\sqrt{n}}\right]$.
:::

::: etape Écart
$$\frac{1}{\sqrt{10\,000}} = \frac{1}{100} = 0{,}01$$
:::

::: etape Bornes
$$0{,}6196 - 0{,}01 = 0{,}6096 \quad \text{et} \quad 0{,}6196 + 0{,}01 = 0{,}6296$$
:::

::: resultat
Dans au moins $95\,\%$ des cas environ, $p \in [0{,}6096\,;0{,}6296]$ : $p$ est voisin de $0{,}61$ à $0{,}63$.
:::

## Question 5 : L’affirmation de Léa

::: methode
Regarder la taille de l’échantillon utilisé.
:::

::: etape Un échantillon trop petit
Avec $n = 10$, la fréquence fluctue beaucoup : le tableau montre qu’elle est passée de $0{,}9$ à $0{,}62$ ensuite. L’écart $\frac{1}{\sqrt{10}} \approx 0{,}32$ est énorme.
:::

::: resultat
Léa a conclu trop vite : $10$ lancers ne suffisent pas pour estimer $p$. Avec $10\,000$ lancers, on estime $p \approx 0{,}62$, et non $0{,}9$.
:::

Solution:
<!-- optitab:1 -->
1. $0{,}9$ ; $0{,}74$ ; $0{,}66$ ; $0{,}642$ ; $0{,}642$ ; $0{,}620$ ; $0{,}620$
2. La fréquence fluctue beaucoup au début puis se stabilise autour de $0{,}62$ : loi des grands nombres.
3. $p \approx 0{,}62$
4. $p \in [0{,}6096\,;0{,}6296]$ (dans au moins $95\,\%$ des cas environ).
5. $10$ lancers ne suffisent pas : la fréquence fluctue trop ; $p \approx 0{,}62$.

=== Entraînement - Estimation d'une proportion par une fréquence
Id: 2007
Difficulté: medium

Énoncé: <!-- optitab:1 -->
On observe $k$ succès dans un échantillon de taille $n$ prélevé au hasard dans une grande population, et on calcule la fréquence $f = \frac{k}{n}$. D’après le cours, dans au moins $95\,\%$ des cas environ, la proportion inconnue $p$ appartient à l’**intervalle d’estimation**
$$\left[f - \frac{1}{\sqrt{n}}\,;\, f + \frac{1}{\sqrt{n}}\right].$$
Une proportion étant comprise entre $0$ et $1$, on ramène si besoin l’intervalle dans $[0\,;1]$. Les bornes non décimales sont arrondies au millième, la borne de gauche par défaut et celle de droite par excès.

1. $n = 100$ et $k = 42$ : calculer $f$, puis l’intervalle d’estimation.
2. $n = 900$ et $k = 468$ : calculer $f$, puis l’intervalle d’estimation.
3. $n = 25$ et $k = 2$ : calculer $f$, puis l’intervalle d’estimation. Que penser de sa précision ?
4. $n = 1\,600$ et $k = 256$ : calculer $f$, puis l’intervalle d’estimation.
5. Dans la situation de la question 4, un fabricant affirme que $p = 0{,}20$. Cette valeur est-elle plausible ?

Étapes:

<!-- optitab:1 -->
## Question 1 : $n = 100$ et $k = 42$

::: methode
Calculer $f = \frac{k}{n}$, puis $\frac{1}{\sqrt{n}}$, puis les deux bornes.
:::

::: etape Fréquence
$$f = \frac{42}{100} = 0{,}42$$
:::

::: etape Écart
$$\frac{1}{\sqrt{100}} = \frac{1}{10} = 0{,}1$$
:::

::: etape Bornes
$$0{,}42 - 0{,}1 = 0{,}32 \quad \text{et} \quad 0{,}42 + 0{,}1 = 0{,}52$$
:::

::: resultat
$f = 0{,}42$ et $p \in [0{,}32\,;0{,}52]$ (dans au moins $95\,\%$ des cas environ).
:::

## Question 2 : $n = 900$ et $k = 468$

::: methode
Même démarche ; ici $\frac{1}{\sqrt{n}}$ n’est pas décimal : on arrondit les bornes vers l’extérieur.
:::

::: etape Fréquence
$$f = \frac{468}{900} = 0{,}52$$
:::

::: etape Écart
$$\frac{1}{\sqrt{900}} = \frac{1}{30} \approx 0{,}0333$$
:::

::: etape Bornes
$$
\begin{aligned}
0{,}52 - \frac{1}{30} &\approx 0{,}48667 \text{, arrondi par défaut : } 0{,}486 \\
0{,}52 + \frac{1}{30} &\approx 0{,}55333 \text{, arrondi par excès : } 0{,}554
\end{aligned}
$$
:::

::: resultat
$f = 0{,}52$ et $p \in [0{,}486\,;0{,}554]$.
:::

::: attention
Arrondir « vers l’extérieur » garantit que l’intervalle arrondi contient l’intervalle exact. Arrondir la borne de gauche à $0{,}487$ l’aurait rétréci.
:::

## Question 3 : $n = 25$ et $k = 2$

::: methode
Calculer l’intervalle, puis le ramener dans $[0\,;1]$ car $p$ ne peut pas être négative.
:::

::: etape Fréquence et écart
$$f = \frac{2}{25} = 0{,}08 \qquad \frac{1}{\sqrt{25}} = \frac{1}{5} = 0{,}2$$
:::

::: etape Bornes
$$0{,}08 - 0{,}2 = -0{,}12 \quad \text{et} \quad 0{,}08 + 0{,}2 = 0{,}28$$
La borne de gauche est négative : on la remplace par $0$.
:::

::: etape Précision
L’intervalle $[0\,;0{,}28]$ a une amplitude de $0{,}28$ : $p$ pourrait valoir $1\,\%$ comme $28\,\%$. L’estimation est très peu précise, car l’échantillon est petit.
:::

::: resultat
$f = 0{,}08$ et $p \in [0\,;0{,}28]$ : estimation peu précise ($n = 25$ est petit).
:::

## Question 4 : $n = 1\,600$ et $k = 256$

::: methode
Même démarche.
:::

::: etape Fréquence
$$f = \frac{256}{1\,600} = 0{,}16$$
:::

::: etape Écart
$\sqrt{1\,600} = 40$, donc
$$\frac{1}{\sqrt{1\,600}} = \frac{1}{40} = 0{,}025$$
:::

::: etape Bornes
$$0{,}16 - 0{,}025 = 0{,}135 \quad \text{et} \quad 0{,}16 + 0{,}025 = 0{,}185$$
:::

::: resultat
$f = 0{,}16$ et $p \in [0{,}135\,;0{,}185]$.
:::

## Question 5 : La valeur $p = 0{,}20$ est-elle plausible ?

::: methode
Regarder si $0{,}20$ appartient à l’intervalle d’estimation de la question 4.
:::

::: etape Comparaison
$0{,}20 \gt 0{,}185$ : la valeur $0{,}20$ est en dehors de l’intervalle $[0{,}135\,;0{,}185]$.
:::

::: resultat
$p = 0{,}20$ n’est pas une valeur plausible au vu de cet échantillon : on peut douter de l’affirmation du fabricant (avec un risque d’erreur d’environ $5\,\%$ au plus).
:::

Solution:
<!-- optitab:1 -->
1. $f = 0{,}42$ ; $p \in [0{,}32\,;0{,}52]$
2. $f = 0{,}52$ ; $p \in [0{,}486\,;0{,}554]$
3. $f = 0{,}08$ ; $p \in [0\,;0{,}28]$ : estimation peu précise car $n$ est petit.
4. $f = 0{,}16$ ; $p \in [0{,}135\,;0{,}185]$
5. $0{,}20 \notin [0{,}135\,;0{,}185]$ : valeur peu plausible, on peut douter de l’affirmation.

=== Entraînement - Intervalle autour de $p$
Id: 2006
Difficulté: medium

Énoncé: <!-- optitab:1 -->
On connaît la probabilité $p$ du succès. Pour un échantillon de taille $n$, on considère l’intervalle
$$\left[p - \frac{1}{\sqrt{n}}\,;\, p + \frac{1}{\sqrt{n}}\right],$$
qui contient la fréquence observée dans au moins $95\,\%$ des échantillons environ.

Dans chaque cas, calculer cet intervalle, puis dire si la fréquence observée $f$ lui appartient.

1. $p = 0{,}5$ ; $n = 400$ ; $f = 0{,}58$
2. $p = 0{,}3$ ; $n = 100$ ; $f = 0{,}39$
3. $p = 0{,}12$ ; $n = 2\,500$ ; $f = 0{,}15$
4. $p = 0{,}65$ ; $n = 225$ ; $f = 0{,}60$
5. $p = 0{,}8$ ; $n = 25$ ; $f = 0{,}55$

Étapes:

<!-- optitab:1 -->
## Question 1 : $p = 0{,}5$ ; $n = 400$ ; $f = 0{,}58$

::: methode
Calculer $\frac{1}{\sqrt{n}}$, puis les bornes $p - \frac{1}{\sqrt{n}}$ et $p + \frac{1}{\sqrt{n}}$, puis situer $f$.
:::

::: etape Écart
$$\frac{1}{\sqrt{400}} = \frac{1}{20} = 0{,}05$$
:::

::: etape Intervalle
$$[0{,}5 - 0{,}05\,;\,0{,}5 + 0{,}05] = [0{,}45\,;\,0{,}55]$$
:::

::: etape Situer $f$
$0{,}58 \gt 0{,}55$, donc $f \notin [0{,}45\,;0{,}55]$.
:::

::: resultat
Intervalle $[0{,}45\,;0{,}55]$ : $f = 0{,}58$ n’y appartient pas.
:::

## Question 2 : $p = 0{,}3$ ; $n = 100$ ; $f = 0{,}39$

::: methode
Même démarche.
:::

::: etape Écart et intervalle
$\frac{1}{\sqrt{100}} = 0{,}1$, d’où l’intervalle $[0{,}3 - 0{,}1\,;\,0{,}3 + 0{,}1] = [0{,}2\,;0{,}4]$.
:::

::: etape Situer $f$
$0{,}2 \le 0{,}39 \le 0{,}4$.
:::

::: resultat
Intervalle $[0{,}2\,;0{,}4]$ : $f = 0{,}39$ y appartient.
:::

## Question 3 : $p = 0{,}12$ ; $n = 2\,500$ ; $f = 0{,}15$

::: methode
Même démarche.
:::

::: etape Écart et intervalle
$\sqrt{2\,500} = 50$, donc $\frac{1}{\sqrt{2\,500}} = 0{,}02$, d’où l’intervalle $[0{,}10\,;0{,}14]$.
:::

::: etape Situer $f$
$0{,}15 \gt 0{,}14$.
:::

::: resultat
Intervalle $[0{,}10\,;0{,}14]$ : $f = 0{,}15$ n’y appartient pas.
:::

## Question 4 : $p = 0{,}65$ ; $n = 225$ ; $f = 0{,}60$

::: methode
$\frac{1}{\sqrt{225}}$ n’est pas décimal : on garde la valeur exacte, puis on arrondit vers l’extérieur.
:::

::: etape Écart
$\sqrt{225} = 15$, donc $\frac{1}{\sqrt{225}} = \frac{1}{15} \approx 0{,}0667$.
:::

::: etape Intervalle
$$
\begin{aligned}
0{,}65 - \frac{1}{15} &\approx 0{,}5833 \\
0{,}65 + \frac{1}{15} &\approx 0{,}7167
\end{aligned}
$$
L’intervalle est environ $[0{,}583\,;0{,}717]$.
:::

::: etape Situer $f$
$0{,}583 \le 0{,}60 \le 0{,}717$.
:::

::: resultat
Intervalle $\approx [0{,}583\,;0{,}717]$ : $f = 0{,}60$ y appartient.
:::

## Question 5 : $p = 0{,}8$ ; $n = 25$ ; $f = 0{,}55$

::: methode
Même démarche.
:::

::: etape Écart et intervalle
$\frac{1}{\sqrt{25}} = 0{,}2$, d’où l’intervalle $[0{,}8 - 0{,}2\,;\,0{,}8 + 0{,}2] = [0{,}6\,;1]$.
:::

::: etape Situer $f$
$0{,}55 \lt 0{,}6$.
:::

::: resultat
Intervalle $[0{,}6\,;1]$ : $f = 0{,}55$ n’y appartient pas.
:::

::: retenir
Quand $f$ sort de l’intervalle $\left[p - \frac{1}{\sqrt{n}}\,;\, p + \frac{1}{\sqrt{n}}\right]$, le résultat est rare si la probabilité est bien $p$ : on peut douter de la valeur $p$, avec un risque d’erreur.
:::

Solution:
<!-- optitab:1 -->
1. $[0{,}45\,;0{,}55]$ : $f = 0{,}58$ n’y appartient pas.
2. $[0{,}2\,;0{,}4]$ : $f = 0{,}39$ y appartient.
3. $[0{,}10\,;0{,}14]$ : $f = 0{,}15$ n’y appartient pas.
4. $\left[0{,}65 - \frac{1}{15}\,;\, 0{,}65 + \frac{1}{15}\right] \approx [0{,}583\,;0{,}717]$ : $f = 0{,}60$ y appartient.
5. $[0{,}6\,;1]$ : $f = 0{,}55$ n’y appartient pas.

=== Entraînement - Lire le nuage des fréquences de N échantillons
Id: 3753
Difficulté: medium
Image: v1_n176_ex3753_1_n2_nuage.png,v1_n176_ex3753_2_n2_nuage_corrige.png

Énoncé: <!-- optitab:1 -->
Une urne contient $2$ boules rouges et $3$ boules blanches. On tire une boule au hasard, on note sa couleur et on la remet dans l’urne ; le succès est « obtenir une boule rouge ». Un échantillon est formé de $n = 100$ tirages.

On a simulé $N = 50$ échantillons. Chaque point de la figure donne la fréquence $f$ des boules rouges dans un échantillon.

[IMAGE_1]

1. Calculer la probabilité $p$ du succès et $\frac{1}{\sqrt{n}}$. Justifier les valeurs $0{,}3$ et $0{,}5$ des deux droites vertes.
2. Combien d’échantillons ont une fréquence située en dehors de la bande verte ?
3. Calculer la proportion des échantillons pour lesquels $|f - p| \le \frac{1}{\sqrt{n}}$.
4. Ce résultat est-il conforme au cours ?
5. Un élève réalise réellement $100$ tirages avec une urne qu’on lui a présentée comme celle-ci, et obtient $55$ boules rouges. Qu’en penser ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Probabilité et bande verte

::: methode
Probabilité d’un événement en situation d’équiprobabilité : nombre de cas favorables divisé par le nombre de cas possibles.
:::

::: etape Probabilité
$2$ boules rouges sur $5$ boules :
$$p = \frac{2}{5} = 0{,}4$$
:::

::: etape Bande verte
$$\frac{1}{\sqrt{100}} = 0{,}1 \qquad p - 0{,}1 = 0{,}3 \qquad p + 0{,}1 = 0{,}5$$
:::

::: resultat
$p = 0{,}4$ et $\frac{1}{\sqrt{n}} = 0{,}1$ : la bande verte représente l’intervalle $[0{,}3\,;0{,}5]$.
:::

## Question 2 : Points hors de la bande

::: methode
Repérer les points situés au-dessous de $0{,}3$ ou au-dessus de $0{,}5$.
:::

::: etape Lecture
Les points hors de la bande sont en orange : deux échantillons ont une fréquence de $0{,}28$ (au-dessous de $0{,}3$) et un échantillon a une fréquence de $0{,}54$ (au-dessus de $0{,}5$).

[IMAGE_2]
:::

::: resultat
$3$ échantillons sur $50$ sont en dehors de la bande.
:::

## Question 3 : Proportion d’échantillons dans la bande

::: methode
Proportion $= \dfrac{\text{nombre d’échantillons dans la bande}}{\text{nombre total d’échantillons}}$.
:::

::: etape Calcul
$50 - 3 = 47$ échantillons sont dans la bande, d’où
$$\frac{47}{50} = \frac{94}{100} = 0{,}94$$
:::

::: resultat
La proportion cherchée est $0{,}94$, soit $94\,\%$.
:::

## Question 4 : Conformité au cours

::: methode
Comparer à « au moins $95\,\%$ environ », en tenant compte de la taille de la simulation.
:::

::: etape Comparaison
$94\,\%$ est très proche de $95\,\%$. Avec seulement $N = 50$ échantillons, un échantillon de plus ou de moins hors de la bande change la proportion de $2\,\%$ : la proportion simulée fluctue elle aussi.
:::

::: resultat
Oui : $94\,\%$ est conforme au constat du cours ; la petite différence vient de la fluctuation de la simulation.
:::

## Question 5 : $55$ boules rouges sur $100$

::: methode
Calculer $f$, puis comparer $|f - p|$ à $\frac{1}{\sqrt{n}}$.
:::

::: etape Calcul
$$f = \frac{55}{100} = 0{,}55 \qquad |0{,}55 - 0{,}4| = 0{,}15$$
:::

::: etape Comparaison
$0{,}15 \gt 0{,}1$ : ce résultat serait un point hors de la bande verte, ce qui n’arrive que rarement avec cette urne.
:::

::: resultat
On peut douter que l’urne contienne vraiment $2$ boules rouges sur $5$ (avec un risque d’erreur de l’ordre de $5\,\%$ au plus).
:::

Solution:
<!-- optitab:1 -->
1. $p = \frac{2}{5} = 0{,}4$ ; $\frac{1}{\sqrt{100}} = 0{,}1$ ; bande $[0{,}4 - 0{,}1\,;0{,}4 + 0{,}1] = [0{,}3\,;0{,}5]$.
2. $3$ échantillons ($0{,}28$ ; $0{,}28$ ; $0{,}54$).
3. $\frac{47}{50} = 0{,}94$, soit $94\,\%$.
4. Oui, proche de $95\,\%$ (fluctuation de la simulation).
5. $|0{,}55 - 0{,}4| = 0{,}15 \gt 0{,}1$ : on peut douter de la composition de l’urne.

=== Entraînement - Une fréquence observée est-elle compatible avec le modèle ?
Id: 2005
Difficulté: medium

Énoncé: <!-- optitab:1 -->
Dans chaque situation, on connaît la probabilité $p$ annoncée par un modèle et on observe un échantillon. Dire si le résultat est compatible avec le modèle, en comparant $|f - p|$ à $\frac{1}{\sqrt{n}}$.

1. Un fabricant annonce $10\,\%$ de pièces défectueuses. Sur $400$ pièces contrôlées au hasard, $52$ sont défectueuses.
2. On lance $900$ fois un dé censé être équilibré : le $6$ sort $185$ fois.
3. Dans une ville, $52\,\%$ des adultes sont des femmes. Un jury de $100$ personnes, censé être tiré au sort parmi les adultes, compte $30$ femmes.
4. On lance $2\,500$ fois une pièce : on obtient $1\,290$ « pile ».
5. Au vu de la question 4, peut-on affirmer que la pièce est équilibrée ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Pièces défectueuses

::: methode
Calculer $f$, puis $\frac{1}{\sqrt{n}}$, puis comparer l’écart $|f - p|$ à $\frac{1}{\sqrt{n}}$.
:::

::: etape Données
$p = 0{,}1$ ; $n = 400$ ; $k = 52$, donc
$$f = \frac{52}{400} = 0{,}13$$
:::

::: etape Écart et comparaison
$$\frac{1}{\sqrt{400}} = 0{,}05 \qquad |0{,}13 - 0{,}1| = 0{,}03$$
et $0{,}03 \le 0{,}05$.
:::

::: resultat
Le résultat est compatible avec l’annonce du fabricant.
:::

## Question 2 : Le dé

::: methode
Ici $p = \frac{1}{6}$ n’est pas décimal : calculer avec des fractions pour comparer exactement.
:::

::: etape Données
$p = \frac{1}{6}$ ; $n = 900$ ; $k = 185$, donc $f = \frac{185}{900}$.
:::

::: etape Écart exact
$$
\begin{aligned}
|f - p| &= \frac{185}{900} - \frac{150}{900} = \frac{35}{900} \\
\frac{1}{\sqrt{900}} &= \frac{1}{30} = \frac{30}{900}
\end{aligned}
$$
:::

::: etape Comparaison
$\frac{35}{900} \gt \frac{30}{900}$ : l’écart dépasse $\frac{1}{\sqrt{n}}$.
:::

::: resultat
Le résultat n’est pas compatible avec un dé équilibré : on peut douter que le dé soit équilibré.
:::

::: attention
Ne pas arrondir trop tôt. Avec $f \approx 0{,}2$ et $p \approx 0{,}17$, on trouverait $|0{,}2 - 0{,}17| = 0{,}03 \le 0{,}033$ : conclusion **fausse** ! Les fractions évitent ce piège.
:::

## Question 3 : Le jury

::: methode
Même démarche, puis conclure dans le contexte.
:::

::: etape Calculs
$p = 0{,}52$ ; $n = 100$ ; $f = \frac{30}{100} = 0{,}3$.
$$\frac{1}{\sqrt{100}} = 0{,}1 \qquad |0{,}3 - 0{,}52| = 0{,}22$$
:::

::: etape Comparaison
$0{,}22 \gt 0{,}1$, et l’écart est plus de deux fois plus grand que $0{,}1$.
:::

::: resultat
Le résultat n’est pas compatible avec un tirage au sort : on peut douter que le jury ait été tiré au hasard.
:::

## Question 4 : La pièce

::: methode
Même démarche avec $p = 0{,}5$.
:::

::: etape Calculs
$n = 2\,500$ ; $f = \frac{1\,290}{2\,500} = 0{,}516$.
$$\frac{1}{\sqrt{2\,500}} = \frac{1}{50} = 0{,}02 \qquad |0{,}516 - 0{,}5| = 0{,}016$$
:::

::: etape Comparaison
$0{,}016 \le 0{,}02$.
:::

::: resultat
Le résultat est compatible avec une pièce équilibrée.
:::

## Question 5 : Peut-on affirmer que la pièce est équilibrée ?

::: methode
Distinguer « compatible avec le modèle » et « prouve le modèle ».
:::

::: etape Ce que dit le test
Le test dit seulement que $1\,290$ « pile » sur $2\,500$ n’est pas un résultat surprenant pour une pièce équilibrée. Une pièce légèrement déséquilibrée (par exemple avec $p = 0{,}51$) donnerait facilement le même résultat.
:::

::: resultat
Non : le résultat est compatible avec une pièce équilibrée, mais ne le **prouve** pas.
:::

::: retenir
- $|f - p| \gt \frac{1}{\sqrt{n}}$ : on peut douter du modèle (risque d’erreur de l’ordre de $5\,\%$ au plus).
- $|f - p| \le \frac{1}{\sqrt{n}}$ : on n’a pas de raison de douter, mais ce n’est pas une preuve.
:::

Solution:
<!-- optitab:1 -->
1. $|0{,}13 - 0{,}1| = 0{,}03 \le 0{,}05$ : compatible.
2. $|f - p| = \frac{35}{900} \gt \frac{30}{900} = \frac{1}{30}$ : non compatible, on peut douter que le dé soit équilibré.
3. $|0{,}3 - 0{,}52| = 0{,}22 \gt 0{,}1$ : non compatible, on peut douter du tirage au sort.
4. $|0{,}516 - 0{,}5| = 0{,}016 \le 0{,}02$ : compatible.
5. Non : compatible ne veut pas dire prouvé.

=== Maîtrise - Choisir une taille d'échantillon
Id: 2008
Difficulté: hard

Énoncé: <!-- optitab:1 -->
Un institut de sondage veut que l’écart $\frac{1}{\sqrt{n}}$ soit inférieur ou égal à une précision $e$ donnée. Il faut donc résoudre l’inéquation $\frac{1}{\sqrt{n}} \le e$, où $n$ est un entier naturel non nul.

Dans chaque cas, déterminer la plus petite taille d’échantillon $n$ qui convient.

1. $e = 0{,}1$
2. $e = 0{,}05$
3. $e = 0{,}03$
4. $e = 0{,}02$
5. $e = 0{,}01$
6. Comparer les réponses 2 et 5 : par combien faut-il multiplier $n$ pour rendre l’écart $5$ fois plus petit ?

Étapes:

<!-- optitab:1 -->
## Question 1 : $\frac{1}{\sqrt{n}} \le 0{,}1$

::: methode
Les deux membres sont positifs : on passe aux inverses (l’inégalité change de sens), puis on élève au carré (elle garde son sens).
:::

::: etape Passer aux inverses
$$\frac{1}{\sqrt{n}} \le 0{,}1 \iff \sqrt{n} \ge \frac{1}{0{,}1} = 10$$
:::

::: etape Élever au carré
$$\sqrt{n} \ge 10 \iff n \ge 10^2 = 100$$
:::

::: resultat
$n = 100$
:::

## Question 2 : $\frac{1}{\sqrt{n}} \le 0{,}05$

::: methode
Même démarche.
:::

::: etape Calcul
$$\sqrt{n} \ge \frac{1}{0{,}05} = 20 \iff n \ge 20^2 = 400$$
:::

::: resultat
$n = 400$
:::

## Question 3 : $\frac{1}{\sqrt{n}} \le 0{,}03$

::: methode
Ici $\frac{1}{0{,}03}$ n’est pas entier : calculer exactement $n \ge \frac{1}{0{,}03^2}$, puis prendre l’entier immédiatement supérieur.
:::

::: etape Inéquation sur $n$
$$n \ge \frac{1}{0{,}03^2} = \frac{1}{0{,}0009} = \frac{10\,000}{9} \approx 1\,111{,}1$$
:::

::: etape Plus petit entier
$n$ est entier et doit dépasser $1\,111{,}1$ : le plus petit est $1\,112$.

Vérification : $\frac{1}{\sqrt{1\,111}} \approx 0{,}030\,001 \gt 0{,}03$ ne convient pas, alors que $\frac{1}{\sqrt{1\,112}} \approx 0{,}029\,988 \le 0{,}03$ convient.
:::

::: resultat
$n = 1\,112$
:::

::: attention
Ne pas arrondir à l’entier le plus proche ($1\,111$) : il faut l’entier **supérieur**, sinon la précision voulue n’est pas atteinte.
:::

## Question 4 : $\frac{1}{\sqrt{n}} \le 0{,}02$

::: methode
Même démarche qu’aux questions 1 et 2.
:::

::: etape Calcul
$$\sqrt{n} \ge \frac{1}{0{,}02} = 50 \iff n \ge 50^2 = 2\,500$$
:::

::: resultat
$n = 2\,500$
:::

## Question 5 : $\frac{1}{\sqrt{n}} \le 0{,}01$

::: methode
Même démarche.
:::

::: etape Calcul
$$\sqrt{n} \ge \frac{1}{0{,}01} = 100 \iff n \ge 100^2 = 10\,000$$
:::

::: resultat
$n = 10\,000$
:::

## Question 6 : Écart $5$ fois plus petit

::: methode
Comparer les tailles obtenues pour $e = 0{,}05$ et $e = 0{,}01$.
:::

::: etape Comparaison
$0{,}01 = \frac{0{,}05}{5}$ : l’écart est $5$ fois plus petit, et
$$\frac{10\,000}{400} = 25 = 5^2$$
:::

::: resultat
Pour rendre l’écart $5$ fois plus petit, il faut un échantillon $25$ fois plus grand.
:::

::: retenir
Diviser l’écart $\frac{1}{\sqrt{n}}$ par $a$ demande de multiplier $n$ par $a^2$ : la précision coûte cher.
:::

Solution:
<!-- optitab:1 -->
1. $n = 100$
2. $n = 400$
3. $n = 1\,112$ (car $n \ge \frac{10\,000}{9} \approx 1\,111{,}1$)
4. $n = 2\,500$
5. $n = 10\,000$
6. $\frac{10\,000}{400} = 25$ : il faut multiplier $n$ par $25 = 5^2$.

=== Problème - Pièce équilibrée ? Influence de la taille de l'échantillon
Id: 2011
Difficulté: hard
Image: v1_n176_ex2011_1_e2011_intervalles.png

Énoncé: <!-- optitab:1 -->
On veut savoir si une pièce est équilibrée (succès = « pile »). Si elle l’est, $p = 0{,}5$. On réalise deux séries de lancers :

| Série | Nombre de lancers | Nombre de « pile » |
|---|---|---|
| A | $n_A = 25$ | $k_A = 16$ |
| B | $n_B = 400$ | $k_B = 236$ |

1. Calculer les fréquences $f_A$ et $f_B$.
2. Calculer $\frac{1}{\sqrt{n_A}}$ et $\frac{1}{\sqrt{n_B}}$.
3. Pour la série A, comparer $|f_A - 0{,}5|$ à $\frac{1}{\sqrt{n_A}}$.
4. Pour la série B, comparer $|f_B - 0{,}5|$ à $\frac{1}{\sqrt{n_B}}$.
5. Les deux séries semblent se contredire. Que peut-on conclure sur l’équilibre de la pièce ? Quelle série faut-il privilégier ?

Étapes:

<!-- optitab:1 -->
## Question 1 : Fréquences

::: methode
$f = \frac{k}{n}$ pour chaque série.
:::

::: etape Calculs
$$f_A = \frac{16}{25} = 0{,}64 \qquad f_B = \frac{236}{400} = 0{,}59$$
:::

::: resultat
$f_A = 0{,}64$ et $f_B = 0{,}59$.
:::

## Question 2 : Écarts $\frac{1}{\sqrt{n}}$

::: methode
Calculer $\sqrt{n}$, puis son inverse.
:::

::: etape Calculs
$$\frac{1}{\sqrt{25}} = \frac{1}{5} = 0{,}2 \qquad \frac{1}{\sqrt{400}} = \frac{1}{20} = 0{,}05$$
:::

::: resultat
$\frac{1}{\sqrt{n_A}} = 0{,}2$ et $\frac{1}{\sqrt{n_B}} = 0{,}05$.
:::

## Question 3 : Série A

::: methode
Comparer l’écart observé à $\frac{1}{\sqrt{n_A}}$.
:::

::: etape Comparaison
$|0{,}64 - 0{,}5| = 0{,}14$ et $0{,}14 \le 0{,}2$.
:::

::: resultat
Série A : résultat compatible avec une pièce équilibrée.
:::

## Question 4 : Série B

::: methode
Même comparaison avec $\frac{1}{\sqrt{n_B}}$.
:::

::: etape Comparaison
$|0{,}59 - 0{,}5| = 0{,}09$ et $0{,}09 \gt 0{,}05$.
:::

::: resultat
Série B : résultat non compatible avec une pièce équilibrée.
:::

## Question 5 : Conclusion

::: methode
Tenir compte de la taille des échantillons : plus $n$ est grand, plus l’intervalle $[p - \frac{1}{\sqrt{n}}\,;\, p + \frac{1}{\sqrt{n}}]$ est étroit.
:::

::: etape Représenter les deux situations
En bleu, l’intervalle $\left[0{,}5 - \frac{1}{\sqrt{n}}\,;\, 0{,}5 + \frac{1}{\sqrt{n}}\right]$ de chaque série ; le point est la fréquence observée.

[IMAGE_1]
:::

::: etape Série A : peu informative
Avec $25$ lancers, l’intervalle $[0{,}3\,;0{,}7]$ est très large : presque n’importe quelle pièce donnerait un résultat « compatible ». La série A ne permet pas de conclure.
:::

::: etape Série B : plus fiable
Avec $400$ lancers, l’intervalle $[0{,}45\,;0{,}55]$ est étroit et $f_B = 0{,}59$ en sort nettement. Les deux séries ne se contredisent pas vraiment : elles vont dans le même sens ($f_A$ et $f_B$ dépassent toutes deux $0{,}5$), mais seule la série B est assez grande pour le détecter.
:::

::: resultat
On privilégie la série B (échantillon plus grand) : on peut douter que la pièce soit équilibrée ; elle semble favoriser « pile ». Cette conclusion comporte un risque d’erreur (de l’ordre de $5\,\%$ au plus).
:::

::: attention
La série A ne prouve pas que la pièce est équilibrée : un résultat « compatible » obtenu sur un petit échantillon n’apporte presque aucune information.
:::

Solution:
<!-- optitab:1 -->
1. $f_A = 0{,}64$ et $f_B = 0{,}59$
2. $\frac{1}{\sqrt{25}} = 0{,}2$ et $\frac{1}{\sqrt{400}} = 0{,}05$
3. $|0{,}64 - 0{,}5| = 0{,}14 \le 0{,}2$ : compatible.
4. $|0{,}59 - 0{,}5| = 0{,}09 \gt 0{,}05$ : non compatible.
5. On privilégie la série B (plus grande, donc plus précise) : on peut douter que la pièce soit équilibrée, avec un risque d’erreur.
