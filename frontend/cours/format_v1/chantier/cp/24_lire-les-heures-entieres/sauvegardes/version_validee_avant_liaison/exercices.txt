Découverte - Lire deux heures
Id: nouveau-1
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Observe les horloges A et B.

[IMAGE_1]

1. Sur quel nombre est la grande aiguille des deux horloges ?
2. Quelle heure indique A ?
3. Quelle heure indique B ?
4. Quelle aiguille utilises-tu pour lire l’heure entière ?
5. Comment vérifies-tu qu’il s’agit d’heures entières ?

Étapes:
<!-- optitab:1 -->

## Question 1 : Sur quel nombre est la grande aiguille des deux horloges ?

::: methode
Repère l’aiguille la plus longue.
:::

::: etape Raisonner
Les deux grandes aiguilles pointent vers le haut.
:::

::: resultat
Sur 12.
:::

## Question 2 : Quelle heure indique A ?

::: methode
Lis la petite aiguille.
:::

::: etape Raisonner
Elle pointe sur 4.
:::

::: resultat
4 heures.
:::

## Question 3 : Quelle heure indique B ?

::: methode
Lis la petite aiguille de B.
:::

::: etape Raisonner
Elle pointe sur 9.
:::

::: resultat
9 heures.
:::

## Question 4 : Quelle aiguille utilises-tu pour lire l’heure entière ?

::: methode
La grande reste sur 12 pour ces heures.
:::

::: etape Raisonner
Le nombre de l’heure est montré par la plus petite.
:::

::: resultat
La petite aiguille.
:::

## Question 5 : Comment vérifies-tu qu’il s’agit d’heures entières ?

::: methode
Regarde la grande aiguille.
:::

::: etape Raisonner
Dans chaque cadran elle est exactement sur 12.
:::

::: etape Vérifier
[IMAGE_2]
:::

::: resultat
Grande aiguille sur 12.
:::

Solution:
<!-- optitab:1 -->
1. Sur 12.
2. 4 heures.
3. 9 heures.
4. La petite aiguille.
5. Grande aiguille sur 12.
