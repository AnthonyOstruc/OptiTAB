Titre: Résumé : Entiers et décimaux

<!-- optitab:1 -->
::: objectifs
Retenir l'essentiel : classes des grands nombres, chiffre et nombre de, dixièmes, centièmes, millièmes, écritures d'un nombre décimal.
:::

## I. Les grands nombres

- Classes de trois chiffres, en partant de la droite : **unités, mille, millions, milliards**.
- Un million $= 1\,000$ milliers ; un milliard $= 1\,000$ millions.
- $4\,207\,350\,018$ : « quatre milliards deux-cent-sept millions trois-cent-cinquante-mille-dix-huit ».
- Écriture en lettres : traits d'union entre les mots-nombres ; **million** et **milliard** sont des noms (« s » au pluriel) ; **mille** est invariable.
- **Chiffre des millions** : $7$ (un seul chiffre). **Nombre de millions** : $4\,207$ (tous les chiffres jusqu'à ce rang).

## II. Unités de numération

$$1 = \frac{10}{10} = \frac{100}{100} = \frac{1\,000}{1\,000}$$
$$\frac{1}{10} = 0{,}1 \qquad \frac{1}{100} = 0{,}01 \qquad \frac{1}{1\,000} = 0{,}001$$

[IMAGE_1]

Chaque rang vaut dix fois le rang de droite : $1$ dixième $= 10$ centièmes ; $1$ centième $= 10$ millièmes.

## III. Écritures d'un nombre décimal

[IMAGE_2]

| Écriture | Exemple |
|---|---|
| à virgule | $63{,}507$ |
| fraction décimale | $\frac{63\,507}{1\,000}$ |
| nombre mixte | $63 + \frac{507}{1\,000}$ |
| décomposition | $60 + 3 + \frac{5}{10} + \frac{7}{1\,000}$ |

- Partie entière $63$ ; partie décimale $0{,}507$.
- Virgule → fraction : le rang du dernier chiffre donne le dénominateur : $7{,}04 = \frac{704}{100}$.
- Fraction → virgule : $\frac{4\,127}{100} = 41{,}27$ ; $\frac{9}{100} = 0{,}09$.
- Un entier est décimal : $12 = \frac{120}{10}$. Un pourcentage aussi : $7\,\% = \frac{7}{100} = 0{,}07$.
- Mesures : $1$ mL $= \frac{1}{1\,000}$ L, $1$ g $= \frac{1}{1\,000}$ kg, $1$ cm $= \frac{1}{100}$ m : $4$ kg $60$ g $= 4{,}06$ kg.

::: attention Les 5 erreurs classiques
1. Oublier les zéros d'une classe : « cinq milliards quarante millions » s'écrit $5\,040\,000\,000$.
2. Confondre chiffre et nombre : dans $4\,207\,350\,018$, il y a $4\,207$ millions, pas $7$.
3. Écrire $\frac{7}{100} = 0{,}7$ : sept centièmes, c'est $0{,}07$.
4. Supprimer un zéro intérieur : $3{,}05 \neq 3{,}5$ (mais $3{,}5 = 3{,}50$).
5. Lire $63{,}507$ comme « $63$ et $507$ unités » : $507$ compte des millièmes.
:::
