=== Découverte - Calculer la valeur d'une expression
Id: 2160
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
On considère les expressions $A = 2x^2 - 3x + 1$ et $B = 5x - x^2$.

1. Calculer $A$ pour $x = -2$.
2. Calculer $A$ pour $x = 3$, puis pour $x = 0$.
3. Calculer $B$ pour $x = -1$.
4. Calculer $B$ pour $x = 2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $A$ pour $x = -2$

::: methode
On remplace $x$ par $-2$ **entre parenthèses**, puis on calcule dans l'ordre : puissances, produits, sommes.
:::

::: etape Remplacer
$$A = 2 \times (-2)^2 - 3 \times (-2) + 1$$
:::

::: etape Calculer
$$
\begin{aligned}
A &= 2 \times 4 + 6 + 1 \\
&= 8 + 6 + 1 \\
&= 15
\end{aligned}
$$
:::

::: resultat
Pour $x = -2$ : $A = 15$.
:::

## Question 2 : $A$ pour $x = 3$ et pour $x = 0$

::: etape Pour $x = 3$
$$A = 2 \times 3^2 - 3 \times 3 + 1 = 18 - 9 + 1 = 10$$
:::

::: etape Pour $x = 0$
$$A = 2 \times 0^2 - 3 \times 0 + 1 = 0 - 0 + 1 = 1$$
:::

::: resultat
Pour $x = 3$ : $A = 10$ ; pour $x = 0$ : $A = 1$.
:::

## Question 3 : $B$ pour $x = -1$

::: etape Remplacer et calculer
$$
\begin{aligned}
B &= 5 \times (-1) - (-1)^2 \\
&= -5 - 1 \\
&= -6
\end{aligned}
$$
:::

::: resultat
Pour $x = -1$ : $B = -6$.
:::

## Question 4 : $B$ pour $x = 2$

::: etape Remplacer et calculer
$$B = 5 \times 2 - 2^2 = 10 - 4 = 6$$
:::

::: resultat
Pour $x = 2$ : $B = 6$.
:::

::: attention Erreur fréquente
Écrire $-(-1)^2 = +1$. Le carré se calcule d'abord : $(-1)^2 = 1$, puis on prend l'opposé : $-(-1)^2 = -1$.
:::

Solution:
<!-- optitab:1 -->
1. $A = 15$
2. $A = 10$ pour $x = 3$ ; $A = 1$ pour $x = 0$.
3. $B = -6$
4. $B = 6$

=== Découverte - Réduire une expression
Id: 2197
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Réduire chaque expression.

1. $7x - 4 + 3x + 9 - 2x$
2. $5x + 3 - x - 8$
3. $2x^2 + 3x - x^2 + x$
4. $4 - 2x + 7x - 9$
5. Un élève écrit $8x + 5 = 13x$. Montrer qu'il a tort.

Étapes:
<!-- optitab:1 -->
## Question 1 : $7x - 4 + 3x + 9 - 2x$

::: methode
On regroupe les termes en $x$ entre eux, puis les nombres entre eux.
:::

::: etape Regrouper
$$
\begin{aligned}
7x - 4 + 3x + 9 - 2x &= (7 + 3 - 2)x + (-4 + 9) \\
&= 8x + 5
\end{aligned}
$$
:::

::: resultat
$8x + 5$
:::

## Question 2 : $5x + 3 - x - 8$

::: etape Regrouper
$(5 - 1)x = 4x$ et $3 - 8 = -5$.
:::

::: resultat
$4x - 5$
:::

## Question 3 : $2x^2 + 3x - x^2 + x$

::: etape Termes en $x^2$
$2x^2 - x^2 = x^2$
:::

::: etape Termes en $x$
$3x + x = 4x$
:::

::: resultat
$x^2 + 4x$
:::

## Question 4 : $4 - 2x + 7x - 9$

::: etape Regrouper
$-2x + 7x = 5x$ et $4 - 9 = -5$.
:::

::: resultat
$5x - 5$
:::

## Question 5 : L'erreur de l'élève

::: methode
Pour prouver qu'une égalité est fausse, il suffit de trouver une valeur de $x$ pour laquelle les deux membres sont différents.
:::

::: etape Contre-exemple avec $x = 2$
$8 \times 2 + 5 = 21$ et $13 \times 2 = 26$ : $21 \neq 26$.
:::

::: resultat
$8x + 5 \neq 13x$ : $8x$ est un terme en $x$ et $5$ est un nombre, ils ne se regroupent pas.
:::

::: attention Erreur fréquente
Tester avec $x = 1$ ne détecte pas l'erreur ($8 + 5 = 13$) : une égalité vraie pour une valeur n'est pas forcément vraie pour toutes.
:::

Solution:
<!-- optitab:1 -->
1. $8x + 5$
2. $4x - 5$
3. $x^2 + 4x$
4. $5x - 5$
5. Pour $x = 2$ : $21 \neq 26$.

=== Découverte - Supprimer des parenthèses précédées d'un signe moins
Id: 2162
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Supprimer les parenthèses de $-(4x - 7)$.
2. Développer $2(3 - x)$.
3. En déduire la forme réduite de $C = -(4x - 7) + 2(3 - x)$.
4. Supprimer les parenthèses de $-(-2x + 5)$.
5. Contrôler la forme réduite de $C$ en remplaçant $x$ par $0$, puis par $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $-(4x - 7)$

::: methode
$-(a - b) = -a + b$ : le signe « $-$ » devant la parenthèse change le signe de chaque terme.
:::

::: etape Changer les signes
$4x$ devient $-4x$ et $-7$ devient $+7$.
:::

::: resultat
$-(4x - 7) = -4x + 7$
:::

## Question 2 : $2(3 - x)$

::: etape Distribuer
$$2(3 - x) = 2 \times 3 - 2 \times x = 6 - 2x$$
:::

::: resultat
$2(3 - x) = 6 - 2x$
:::

## Question 3 : Réduire $C$

::: etape Remplacer
$$C = -4x + 7 + 6 - 2x$$
:::

::: etape Regrouper
$-4x - 2x = -6x$ et $7 + 6 = 13$.
:::

::: resultat
$C = -6x + 13$
:::

## Question 4 : $-(-2x + 5)$

::: etape Changer les signes
$-2x$ devient $+2x$ et $+5$ devient $-5$.
:::

::: resultat
$-(-2x + 5) = 2x - 5$
:::

## Question 5 : Contrôle

::: etape Pour $x = 0$
Forme de départ : $-(0 - 7) + 2(3 - 0) = 7 + 6 = 13$. Forme réduite : $-6 \times 0 + 13 = 13$.
:::

::: etape Pour $x = 1$
Forme de départ : $-(4 - 7) + 2(3 - 1) = 3 + 4 = 7$. Forme réduite : $-6 + 13 = 7$.
:::

::: resultat
Les deux formes donnent les mêmes valeurs : aucune erreur détectée.
:::

::: attention Erreur fréquente
Ne changer que le premier signe : $-(4x - 7) = -4x - 7$ est faux. **Tous** les signes de la parenthèse changent.
:::

Solution:
<!-- optitab:1 -->
1. $-4x + 7$
2. $6 - 2x$
3. $C = -6x + 13$
4. $2x - 5$
5. $13 = 13$ pour $x = 0$ ; $7 = 7$ pour $x = 1$.

=== Découverte - Développer avec la double distributivité
Id: 2163
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
1. Écrire les quatre produits du développement de $(3x + 2)(x - 5)$, puis réduire.
2. Développer et réduire $(x + 4)(x + 2)$.
3. Développer et réduire $(2x - 1)(x + 3)$.
4. Contrôler le résultat de la question 3 en remplaçant $x$ par $1$.

Étapes:
<!-- optitab:1 -->
## Question 1 : $(3x + 2)(x - 5)$

::: methode
$(a + b)(c + d) = ac + ad + bc + bd$ : chaque terme de la première parenthèse multiplie chaque terme de la seconde.
:::

::: etape Les quatre produits
$$3x \times x + 3x \times (-5) + 2 \times x + 2 \times (-5)$$
:::

::: etape Calculer et réduire
$$
\begin{aligned}
(3x + 2)(x - 5) &= 3x^2 - 15x + 2x - 10 \\
&= 3x^2 - 13x - 10
\end{aligned}
$$
:::

::: resultat
$(3x + 2)(x - 5) = 3x^2 - 13x - 10$
:::

## Question 2 : $(x + 4)(x + 2)$

::: etape Développer et réduire
$$
\begin{aligned}
(x + 4)(x + 2) &= x^2 + 2x + 4x + 8 \\
&= x^2 + 6x + 8
\end{aligned}
$$
:::

::: resultat
$(x + 4)(x + 2) = x^2 + 6x + 8$
:::

## Question 3 : $(2x - 1)(x + 3)$

::: etape Développer et réduire
$$
\begin{aligned}
(2x - 1)(x + 3) &= 2x^2 + 6x - x - 3 \\
&= 2x^2 + 5x - 3
\end{aligned}
$$
:::

::: resultat
$(2x - 1)(x + 3) = 2x^2 + 5x - 3$
:::

## Question 4 : Contrôle avec $x = 1$

::: etape Forme de départ
$(2 \times 1 - 1)(1 + 3) = 1 \times 4 = 4$
:::

::: etape Forme développée
$2 \times 1^2 + 5 \times 1 - 3 = 2 + 5 - 3 = 4$
:::

::: resultat
Les deux formes donnent $4$ : le développement est cohérent.
:::

::: attention Erreur fréquente
Oublier un des quatre produits, ou le signe d'un terme : dans $(3x + 2)(x - 5)$, le dernier produit est $2 \times (-5) = -10$.
:::

Solution:
<!-- optitab:1 -->
1. $3x^2 - 15x + 2x - 10 = 3x^2 - 13x - 10$
2. $x^2 + 6x + 8$
3. $2x^2 + 5x - 3$
4. $4 = 4$

=== Découverte - Factoriser avec un facteur commun
Id: 2164
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Factoriser chaque expression.

1. $14x + 21$
2. $12x^2 - 8x$, puis vérifier en redéveloppant.
3. $5x + 5$
4. $x^2 + 7x$

Étapes:
<!-- optitab:1 -->
## Question 1 : $14x + 21$

::: methode
On cherche le plus grand facteur commun aux deux termes, puis on l'écrit devant la parenthèse.
:::

::: etape Facteur commun
$14x = 7 \times 2x$ et $21 = 7 \times 3$ : le facteur commun est $7$.
:::

::: resultat
$14x + 21 = 7(2x + 3)$
:::

## Question 2 : $12x^2 - 8x$

::: etape Facteur commun
$12x^2 = 4x \times 3x$ et $8x = 4x \times 2$ : le facteur commun est $4x$.
:::

::: etape Vérification
$$4x(3x - 2) = 4x \times 3x - 4x \times 2 = 12x^2 - 8x$$
:::

::: resultat
$12x^2 - 8x = 4x(3x - 2)$
:::

## Question 3 : $5x + 5$

::: etape Faire apparaître le facteur
$5x + 5 = 5 \times x + 5 \times 1$
:::

::: resultat
$5x + 5 = 5(x + 1)$
:::

## Question 4 : $x^2 + 7x$

::: etape Facteur commun
$x^2 = x \times x$ et $7x = x \times 7$ : le facteur commun est $x$.
:::

::: resultat
$x^2 + 7x = x(x + 7)$
:::

::: attention Erreur fréquente
Dans $5x + 5$, il reste $1$ et non $0$ dans la parenthèse : $5(x + 0) = 5x$, ce qui ne redonne pas l'expression. Redévelopper permet de le voir.
:::

Solution:
<!-- optitab:1 -->
1. $7(2x + 3)$
2. $4x(3x - 2)$ ; $4x \times 3x - 4x \times 2 = 12x^2 - 8x$.
3. $5(x + 1)$
4. $x(x + 7)$

=== Découverte - Reconnaître une somme ou un produit
Id: 2165
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Pour chaque expression, dire si c'est une somme ou un produit, en précisant la dernière opération à effectuer.

1. $3(x + 2)$
2. $3x + 2$
3. $(x + 1)(x - 5)$
4. $x^2 - 9$
5. Développer $5(2x - 3)$. L'expression obtenue est-elle une somme ou un produit ?

Étapes:
<!-- optitab:1 -->
## Question 1 : $3(x + 2)$

::: methode
On cherche la **dernière** opération à effectuer quand on calcule l'expression pour une valeur de $x$.
:::

::: etape Ordre des calculs
On calcule d'abord $x + 2$, puis on multiplie par $3$.
:::

::: resultat
C'est un **produit** : l'expression est factorisée.
:::

## Question 2 : $3x + 2$

::: etape Ordre des calculs
On calcule d'abord $3x$, puis on ajoute $2$.
:::

::: resultat
C'est une **somme**.
:::

## Question 3 : $(x + 1)(x - 5)$

::: etape Ordre des calculs
On calcule $x + 1$ et $x - 5$, puis on multiplie les deux résultats.
:::

::: resultat
C'est un **produit** de deux facteurs.
:::

## Question 4 : $x^2 - 9$

::: etape Ordre des calculs
On calcule $x^2$, puis on soustrait $9$.
:::

::: resultat
C'est une **somme** (une différence est une somme : $x^2 + (-9)$).
:::

## Question 5 : Développer $5(2x - 3)$

::: etape Distribuer
$$5(2x - 3) = 5 \times 2x - 5 \times 3 = 10x - 15$$
:::

::: resultat
$10x - 15$ est une **somme** : développer transforme un produit en somme.
:::

::: attention Erreur fréquente
Croire que $3x + 2$ est un produit parce qu'il contient $3x$. C'est la **dernière** opération qui compte : ici, une addition.
:::

Solution:
<!-- optitab:1 -->
1. Produit
2. Somme
3. Produit
4. Somme
5. $10x - 15$ : une somme.

=== Découverte - Développer avec la simple distributivité
Id: 2166
Difficulté: easy

Énoncé:
<!-- optitab:1 -->
Développer et réduire chaque expression.

1. $4(3x + 7)$
2. $-2(5x - 3)$
3. $x(x + 6)$
4. $3x(2x - 5)$
5. $-(x^2 - 4x + 1)$

Étapes:
<!-- optitab:1 -->
## Question 1 : $4(3x + 7)$

::: methode
$k(a + b) = ka + kb$ : le facteur multiplie **chaque** terme de la parenthèse.
:::

::: etape Distribuer
$$4(3x + 7) = 4 \times 3x + 4 \times 7$$
:::

::: resultat
$4(3x + 7) = 12x + 28$
:::

## Question 2 : $-2(5x - 3)$

::: etape Distribuer avec les signes
$-2 \times 5x = -10x$ et $-2 \times (-3) = +6$.
:::

::: resultat
$-2(5x - 3) = -10x + 6$
:::

## Question 3 : $x(x + 6)$

::: etape Distribuer
$x \times x + x \times 6$
:::

::: resultat
$x(x + 6) = x^2 + 6x$
:::

## Question 4 : $3x(2x - 5)$

::: etape Distribuer
$3x \times 2x = 6x^2$ et $3x \times (-5) = -15x$.
:::

::: resultat
$3x(2x - 5) = 6x^2 - 15x$
:::

## Question 5 : $-(x^2 - 4x + 1)$

::: etape Changer tous les signes
$x^2$ devient $-x^2$, $-4x$ devient $+4x$, $+1$ devient $-1$.
:::

::: resultat
$-(x^2 - 4x + 1) = -x^2 + 4x - 1$
:::

::: attention Erreur fréquente
$-2 \times (-3) = +6$ et non $-6$ : le produit de deux nombres négatifs est positif.
:::

Solution:
<!-- optitab:1 -->
1. $12x + 28$
2. $-10x + 6$
3. $x^2 + 6x$
4. $6x^2 - 15x$
5. $-x^2 + 4x - 1$

=== Entraînement - Factoriser une différence de deux carrés
Id: 2167
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser à l'aide de l'identité $a^2 - b^2 = (a - b)(a + b)$.

1. $x^2 - 81$
2. $25x^2 - 4$, puis vérifier en redéveloppant.
3. $49 - x^2$
4. $36x^2 - 1$

Étapes:
<!-- optitab:1 -->
## Question 1 : $x^2 - 81$

::: methode
On écrit chaque terme comme un carré : $a^2 - b^2$, puis on applique $(a - b)(a + b)$.
:::

::: etape Les deux carrés
$x^2 = x^2$ et $81 = 9^2$ : $a = x$ et $b = 9$.
:::

::: resultat
$x^2 - 81 = (x - 9)(x + 9)$
:::

## Question 2 : $25x^2 - 4$

::: etape Les deux carrés
$25x^2 = (5x)^2$ et $4 = 2^2$ : $a = 5x$ et $b = 2$.
:::

::: etape Vérification
$$
\begin{aligned}
(5x - 2)(5x + 2) &= 25x^2 + 10x - 10x - 4 \\
&= 25x^2 - 4
\end{aligned}
$$
Les termes $10x$ et $-10x$ s'annulent.
:::

::: resultat
$25x^2 - 4 = (5x - 2)(5x + 2)$
:::

## Question 3 : $49 - x^2$

::: etape Les deux carrés
$49 = 7^2$ : $a = 7$ et $b = x$ (l'ordre compte).
:::

::: resultat
$49 - x^2 = (7 - x)(7 + x)$
:::

## Question 4 : $36x^2 - 1$

::: etape Les deux carrés
$36x^2 = (6x)^2$ et $1 = 1^2$.
:::

::: resultat
$36x^2 - 1 = (6x - 1)(6x + 1)$
:::

::: attention Erreur fréquente
Écrire $25x^2 - 4 = (25x - 4)(25x + 4)$ : il faut prendre les nombres dont les carrés sont $25x^2$ et $4$, c'est-à-dire $5x$ et $2$.
:::

Solution:
<!-- optitab:1 -->
1. $(x - 9)(x + 9)$
2. $(5x - 2)(5x + 2)$
3. $(7 - x)(7 + x)$
4. $(6x - 1)(6x + 1)$

=== Entraînement - Développer avec les identités remarquables
Id: 2198
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Développer à l'aide des identités remarquables.

1. $(x + 6)^2$
2. $(2x - 3)^2$
3. $(3x + 1)^2$
4. Un élève écrit $(x + 6)^2 = x^2 + 36$. Montrer que c'est faux en remplaçant $x$ par $1$, puis expliquer son erreur.

Étapes:
<!-- optitab:1 -->
## Question 1 : $(x + 6)^2$

::: methode
$(a + b)^2 = a^2 + 2ab + b^2$, ici avec $a = x$ et $b = 6$.
:::

::: etape Les trois termes
$a^2 = x^2$ ; $2ab = 2 \times x \times 6 = 12x$ ; $b^2 = 36$.
:::

[IMAGE_1]

::: resultat
$(x + 6)^2 = x^2 + 12x + 36$
:::

## Question 2 : $(2x - 3)^2$

::: methode
$(a - b)^2 = a^2 - 2ab + b^2$, avec $a = 2x$ et $b = 3$.
:::

::: etape Les trois termes
$(2x)^2 = 4x^2$ ; $2 \times 2x \times 3 = 12x$ ; $3^2 = 9$.
:::

::: resultat
$(2x - 3)^2 = 4x^2 - 12x + 9$
:::

## Question 3 : $(3x + 1)^2$

::: etape Les trois termes
$(3x)^2 = 9x^2$ ; $2 \times 3x \times 1 = 6x$ ; $1^2 = 1$.
:::

::: resultat
$(3x + 1)^2 = 9x^2 + 6x + 1$
:::

## Question 4 : L'erreur de l'élève

::: etape Test avec $x = 1$
$(1 + 6)^2 = 7^2 = 49$, mais $1^2 + 36 = 37$ : $49 \neq 37$.
:::

::: etape L'erreur
L'élève a oublié le double produit $12x$, qui vaut $12$ pour $x = 1$ : $37 + 12 = 49$. Sur la figure, ce sont les deux rectangles de $6x$.
:::

::: resultat
L'égalité est fausse : $(x + 6)^2 = x^2 + 12x + 36$.
:::

::: attention Erreur fréquente
$(2x)^2 = 4x^2$ et non $2x^2$ : le carré porte sur le $2$ et sur le $x$.
:::

Solution:
<!-- optitab:1 -->
1. $x^2 + 12x + 36$
2. $4x^2 - 12x + 9$
3. $9x^2 + 6x + 1$
4. $49 \neq 37$ : le double produit $12x$ manque.

=== Entraînement - Calculer astucieusement
Id: 2169
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Calculer sans calculatrice, à l'aide des identités remarquables.

1. $103 \times 97$
2. $49^2$
3. $101^2$
4. $1\,002 \times 998$
5. $55^2 - 45^2$

Étapes:
<!-- optitab:1 -->
## Question 1 : $103 \times 97$

::: methode
On écrit les deux nombres autour d'un nombre rond : $(a + b)(a - b) = a^2 - b^2$.
:::

::: etape Calcul
$$
\begin{aligned}
103 \times 97 &= (100 + 3)(100 - 3) \\
&= 100^2 - 3^2 \\
&= 10\,000 - 9
\end{aligned}
$$
:::

::: resultat
$103 \times 97 = 9\,991$
:::

## Question 2 : $49^2$

::: etape Avec $(a - b)^2$
$$
\begin{aligned}
49^2 &= (50 - 1)^2 \\
&= 50^2 - 2 \times 50 \times 1 + 1^2 \\
&= 2\,500 - 100 + 1
\end{aligned}
$$
:::

::: resultat
$49^2 = 2\,401$
:::

## Question 3 : $101^2$

::: etape Avec $(a + b)^2$
$$
\begin{aligned}
101^2 &= (100 + 1)^2 \\
&= 10\,000 + 200 + 1
\end{aligned}
$$
:::

::: resultat
$101^2 = 10\,201$
:::

## Question 4 : $1\,002 \times 998$

::: etape Avec $(a + b)(a - b)$
$$
\begin{aligned}
1\,002 \times 998 &= (1\,000 + 2)(1\,000 - 2) \\
&= 1\,000\,000 - 4
\end{aligned}
$$
:::

::: resultat
$1\,002 \times 998 = 999\,996$
:::

## Question 5 : $55^2 - 45^2$

::: methode
On utilise l'identité dans l'autre sens : $a^2 - b^2 = (a - b)(a + b)$.
:::

::: etape Calcul
$$
\begin{aligned}
55^2 - 45^2 &= (55 - 45)(55 + 45) \\
&= 10 \times 100
\end{aligned}
$$
:::

::: resultat
$55^2 - 45^2 = 1\,000$
:::

::: attention Erreur fréquente
$49^2 \neq 50^2 - 1^2$ : le double produit $2 \times 50 \times 1 = 100$ ne doit pas être oublié.
:::

Solution:
<!-- optitab:1 -->
1. $9\,991$
2. $2\,401$
3. $10\,201$
4. $999\,996$
5. $1\,000$

=== Entraînement - Factoriser en deux temps
Id: 2170
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser chaque expression.

1. $3x(x - 2) + 5(x - 2)$, puis vérifier en développant les deux formes.
2. $9x^2 - 36$
3. $(x + 1)(2x - 3) + (x + 1)(x + 7)$
4. $2x^2 - 50$

Étapes:
<!-- optitab:1 -->
## Question 1 : $3x(x - 2) + 5(x - 2)$

::: methode
Le facteur commun est la parenthèse entière $(x - 2)$.
:::

::: etape Factoriser
$$3x(x - 2) + 5(x - 2) = (x - 2)(3x + 5)$$
:::

::: etape Vérifier
Forme factorisée : $(x - 2)(3x + 5) = 3x^2 + 5x - 6x - 10 = 3x^2 - x - 10$.

Forme de départ : $3x^2 - 6x + 5x - 10 = 3x^2 - x - 10$.
:::

::: resultat
$3x(x - 2) + 5(x - 2) = (x - 2)(3x + 5)$
:::

## Question 2 : $9x^2 - 36$

::: etape Facteur commun $9$
$$9x^2 - 36 = 9(x^2 - 4)$$
:::

::: etape Différence de deux carrés
$x^2 - 4 = x^2 - 2^2 = (x - 2)(x + 2)$
:::

::: resultat
$9x^2 - 36 = 9(x - 2)(x + 2)$
:::

## Question 3 : $(x + 1)(2x - 3) + (x + 1)(x + 7)$

::: etape Facteur commun $(x + 1)$
$$(x + 1)\left[(2x - 3) + (x + 7)\right]$$
:::

::: etape Réduire le crochet
$(2x - 3) + (x + 7) = 3x + 4$
:::

::: resultat
$(x + 1)(2x - 3) + (x + 1)(x + 7) = (x + 1)(3x + 4)$
:::

## Question 4 : $2x^2 - 50$

::: etape Facteur commun $2$
$2x^2 - 50 = 2(x^2 - 25)$
:::

::: etape Différence de deux carrés
$x^2 - 25 = (x - 5)(x + 5)$
:::

::: resultat
$2x^2 - 50 = 2(x - 5)(x + 5)$
:::

::: attention Erreur fréquente
S'arrêter à $9(x^2 - 4)$ : la parenthèse peut encore se factoriser. On cherche d'abord un facteur commun, puis une identité.
:::

Solution:
<!-- optitab:1 -->
1. $(x - 2)(3x + 5)$ ; les deux formes valent $3x^2 - x - 10$.
2. $9(x - 2)(x + 2)$
3. $(x + 1)(3x + 4)$
4. $2(x - 5)(x + 5)$

=== Entraînement - Développer à l'aide d'une figure
Id: 2199
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Un rectangle a pour longueur $2x + 3$ et pour largeur $x + 5$ (en cm, avec $x > 0$). Il est partagé en quatre rectangles.

[IMAGE_1]

1. Exprimer l'aire du grand rectangle sous la forme d'un produit.
2. Exprimer l'aire de chacun des quatre petits rectangles.
3. En déduire la forme développée et réduite de $(2x + 3)(x + 5)$.
4. Calculer l'aire du grand rectangle pour $x = 4$ avec les deux formes.

Étapes:
<!-- optitab:1 -->
## Question 1 : L'aire sous forme de produit

::: methode
Aire d'un rectangle $=$ longueur $\times$ largeur.
:::

::: resultat
L'aire du grand rectangle est $(2x + 3)(x + 5)$ cm².
:::

## Question 2 : Les quatre petits rectangles

::: etape Les aires
- $2x$ sur $x$ : $2x \times x = 2x^2$ ;
- $3$ sur $x$ : $3 \times x = 3x$ ;
- $2x$ sur $5$ : $2x \times 5 = 10x$ ;
- $3$ sur $5$ : $3 \times 5 = 15$.
:::

[IMAGE_2]

::: resultat
Les quatre aires sont $2x^2$, $3x$, $10x$ et $15$ (en cm²).
:::

## Question 3 : La forme développée

::: etape Somme des quatre aires
L'aire du grand rectangle est la somme des quatre aires, et $3x + 10x = 13x$.
$$
\begin{aligned}
(2x + 3)(x + 5) &= 2x^2 + 3x + 10x + 15 \\
&= 2x^2 + 13x + 15
\end{aligned}
$$
:::

::: resultat
$(2x + 3)(x + 5) = 2x^2 + 13x + 15$ : ce sont les quatre produits de la double distributivité.
:::

## Question 4 : Pour $x = 4$

::: etape Forme produit
$(2 \times 4 + 3)(4 + 5) = 11 \times 9 = 99$
:::

::: etape Forme développée
$2 \times 4^2 + 13 \times 4 + 15$, c'est-à-dire $32 + 52 + 15 = 99$.
:::

::: resultat
Pour $x = 4$, l'aire vaut $99$ cm² avec les deux formes.
:::

::: attention Erreur fréquente
Ne garder que deux morceaux ($2x \times x$ et $3 \times 5$) : le rectangle est formé de **quatre** parties, d'où les quatre produits.
:::

Solution:
<!-- optitab:1 -->
1. $(2x + 3)(x + 5)$
2. $2x^2$, $3x$, $10x$, $15$
3. $2x^2 + 13x + 15$
4. $99$ cm².

=== Entraînement - Développer puis simplifier
Id: 2172
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
On considère $E = (2x + 1)(3x - 4) - 6x^2$.

1. Développer le produit $(2x + 1)(3x - 4)$.
2. En déduire la forme réduite de $E$.
3. Calculer $E$ pour $x = 10$ avec la forme réduite, puis vérifier avec la forme de départ.
4. Calculer $E$ pour $x = -2$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Le produit

::: etape Double distributivité
$$
\begin{aligned}
(2x + 1)(3x - 4) &= 6x^2 - 8x + 3x - 4 \\
&= 6x^2 - 5x - 4
\end{aligned}
$$
:::

::: resultat
$(2x + 1)(3x - 4) = 6x^2 - 5x - 4$
:::

## Question 2 : La forme réduite de $E$

::: etape Remplacer
$$E = 6x^2 - 5x - 4 - 6x^2$$
Les termes $6x^2$ et $-6x^2$ s'annulent.
:::

::: resultat
$E = -5x - 4$
:::

## Question 3 : Pour $x = 10$

::: etape Forme réduite
$E = -5 \times 10 - 4 = -54$
:::

::: etape Forme de départ
$(2 \times 10 + 1)(3 \times 10 - 4) - 6 \times 10^2 = 21 \times 26 - 600 = 546 - 600 = -54$
:::

::: resultat
Pour $x = 10$ : $E = -54$ avec les deux formes.
:::

## Question 4 : Pour $x = -2$

::: etape Forme réduite
$E = -5 \times (-2) - 4 = 10 - 4 = 6$
:::

::: etape Contrôle
$(-4 + 1)(-6 - 4) - 6 \times 4 = (-3) \times (-10) - 24 = 30 - 24 = 6$
:::

::: resultat
Pour $x = -2$ : $E = 6$.
:::

::: attention Erreur fréquente
Oublier la parenthèse autour du produit développé quand il est précédé d'un signe moins. Ici le produit est en premier, mais avec $6x^2 - (2x + 1)(3x - 4)$, il faudrait changer tous les signes.
:::

Solution:
<!-- optitab:1 -->
1. $6x^2 - 5x - 4$
2. $E = -5x - 4$
3. $E = -54$
4. $E = 6$

=== Entraînement - Choisir la bonne factorisation
Id: 2173
Difficulté: medium

Énoncé:
<!-- optitab:1 -->
Factoriser chaque expression en choisissant la méthode adaptée.

1. $8x + 12$
2. $25 - x^2$
3. $3x^2 - 27$
4. $x^2 + 10x + 25$ (on pourra reconnaître une identité remarquable)
5. $x^2 - 12x + 36$

Étapes:
<!-- optitab:1 -->
## Question 1 : $8x + 12$

::: methode
Premier réflexe : chercher un facteur commun.
:::

::: etape Facteur commun $4$
$8x = 4 \times 2x$ et $12 = 4 \times 3$.
:::

::: resultat
$8x + 12 = 4(2x + 3)$
:::

## Question 2 : $25 - x^2$

::: etape Différence de deux carrés
$25 = 5^2$ : $25 - x^2 = 5^2 - x^2$.
:::

::: resultat
$25 - x^2 = (5 - x)(5 + x)$
:::

## Question 3 : $3x^2 - 27$

::: etape Facteur commun $3$
$3x^2 - 27 = 3(x^2 - 9)$
:::

::: etape Différence de deux carrés
$x^2 - 9 = (x - 3)(x + 3)$
:::

::: resultat
$3x^2 - 27 = 3(x - 3)(x + 3)$
:::

## Question 4 : $x^2 + 10x + 25$

::: methode
On reconnaît la forme $a^2 + 2ab + b^2 = (a + b)^2$.
:::

::: etape Identifier $a$ et $b$
$x^2 = a^2$ avec $a = x$ ; $25 = 5^2$ avec $b = 5$ ; et $2ab = 2 \times x \times 5 = 10x$ : c'est bien le terme du milieu.
:::

::: resultat
$x^2 + 10x + 25 = (x + 5)^2$
:::

## Question 5 : $x^2 - 12x + 36$

::: etape Identifier $a$ et $b$
$a = x$, $b = 6$ et $2ab = 12x$, avec un signe moins : forme $a^2 - 2ab + b^2$.
:::

::: resultat
$x^2 - 12x + 36 = (x - 6)^2$
:::

::: attention Erreur fréquente
Vérifier le terme du milieu : $x^2 + 10x + 36$ n'est pas $(x + 6)^2$, car $2 \times x \times 6 = 12x \neq 10x$.
:::

Solution:
<!-- optitab:1 -->
1. $4(2x + 3)$
2. $(5 - x)(5 + x)$
3. $3(x - 3)(x + 3)$
4. $(x + 5)^2$
5. $(x - 6)^2$

=== Problème - Comparer deux programmes de calcul
Id: 2174
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère les deux programmes de calcul ci-dessous.

[IMAGE_1]

1. Appliquer les deux programmes au nombre $3$, puis au nombre $-5$.
2. Quelle conjecture peut-on faire ?
3. On choisit un nombre $x$. Exprimer en fonction de $x$ le résultat de chaque programme.
4. Démontrer la conjecture.
5. Quel nombre faut-il choisir pour obtenir $100$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Avec $3$ et avec $-5$

::: etape Programme A
- Avec $3$ : $3 + 5 = 8$ ; $8 \times 4 = 32$ ; $32 - 8 = 24$.
- Avec $-5$ : $-5 + 5 = 0$ ; $0 \times 4 = 0$ ; $0 - 8 = -8$.
:::

::: etape Programme B
- Avec $3$ : $3 \times 4 = 12$ ; $12 + 12 = 24$.
- Avec $-5$ : $-5 \times 4 = -20$ ; $-20 + 12 = -8$.
:::

::: resultat
Avec $3$, les deux programmes donnent $24$ ; avec $-5$, ils donnent $-8$.
:::

## Question 2 : La conjecture

::: resultat
Il semble que les deux programmes donnent toujours le même résultat.
:::

## Question 3 : Traduire avec $x$

::: methode
On traduit chaque ligne du programme, en gardant des parenthèses autour du résultat précédent.
:::

::: etape Programme A
$x \to x + 5 \to 4(x + 5) \to 4(x + 5) - 8$
:::

::: etape Programme B
$x \to 4x \to 4x + 12$
:::

::: resultat
Programme A : $4(x + 5) - 8$ ; programme B : $4x + 12$.
:::

## Question 4 : La démonstration

::: etape Développer le programme A
$$
\begin{aligned}
4(x + 5) - 8 &= 4x + 20 - 8 \\
&= 4x + 12
\end{aligned}
$$
:::

::: resultat
Pour tout nombre $x$, les deux programmes donnent $4x + 12$ : ils donnent toujours le même résultat.
:::

## Question 5 : Obtenir $100$

::: etape Résoudre
$4x + 12 = 100$, donc $4x = 88$, donc $x = 22$.
:::

::: etape Vérifier
Programme B : $22 \times 4 = 88$ ; $88 + 12 = 100$.
:::

::: resultat
Il faut choisir le nombre $22$.
:::

::: attention Erreur fréquente
Écrire $x + 5 \times 4$ au lieu de $(x + 5) \times 4$ : sans parenthèses, seul le $5$ est multiplié par $4$.
:::

Solution:
<!-- optitab:1 -->
1. Avec $3$ : $24$ et $24$ ; avec $-5$ : $-8$ et $-8$.
2. Les deux programmes donnent toujours le même résultat.
3. A : $4(x + 5) - 8$ ; B : $4x + 12$.
4. $4(x + 5) - 8 = 4x + 12$ pour tout $x$.
5. $22$

=== Problème - L'aire d'une bordure
Id: 2175
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Un carré de côté $x$ cm est entouré, à l'extérieur, d'une bordure de largeur $2$ cm.

[IMAGE_1]

1. Exprimer le côté du grand carré en fonction de $x$.
2. Montrer que l'aire de la bordure vaut $8x + 16$ cm².
3. Retrouver ce résultat en découpant la bordure en rectangles et en carrés.
4. Calculer l'aire de la bordure pour $x = 7$, et vérifier par un calcul direct.
5. Pour quelle valeur de $x$ l'aire de la bordure vaut-elle $56$ cm² ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Le côté du grand carré

::: methode
La bordure ajoute $2$ cm de **chaque** côté du petit carré.
:::

::: resultat
Le grand carré a pour côté $x + 2 + 2 = x + 4$ cm.
:::

## Question 2 : L'aire de la bordure

::: methode
Aire de la bordure $=$ aire du grand carré $-$ aire du petit carré.
:::

::: etape Développer
$$
\begin{aligned}
(x + 4)^2 - x^2 &= x^2 + 8x + 16 - x^2 \\
&= 8x + 16
\end{aligned}
$$
:::

::: resultat
L'aire de la bordure vaut $8x + 16$ cm².
:::

## Question 3 : Par découpage

::: etape Découper
La bordure se découpe en $4$ rectangles de $x$ cm sur $2$ cm (le long des côtés) et $4$ carrés de $2$ cm de côté (dans les coins).
:::

[IMAGE_2]

::: etape Additionner
$$4 \times 2x + 4 \times 2^2 = 8x + 16$$
:::

::: resultat
On retrouve $8x + 16$ cm².
:::

## Question 4 : Pour $x = 7$

::: etape Avec la formule
$8 \times 7 + 16 = 56 + 16 = 72$
:::

::: etape Calcul direct
Grand carré : $11^2 = 121$ ; petit carré : $7^2 = 49$ ; $121 - 49 = 72$.
:::

::: resultat
Pour $x = 7$, la bordure mesure $72$ cm².
:::

## Question 5 : Une bordure de $56$ cm²

::: etape Résoudre
$8x + 16 = 56$, donc $8x = 40$, donc $x = 5$.
:::

::: etape Vérifier
$9^2 - 5^2 = 81 - 25 = 56$.
:::

::: resultat
La bordure mesure $56$ cm² pour $x = 5$ cm.
:::

::: attention Erreur fréquente
Écrire $x + 2$ pour le côté du grand carré : la bordure est présente des **deux** côtés.
:::

Solution:
<!-- optitab:1 -->
1. $x + 4$
2. $(x + 4)^2 - x^2 = 8x + 16$
3. $4 \times 2x + 4 \times 4 = 8x + 16$
4. $72$ cm² ($121 - 49 = 72$).
5. $x = 5$

=== Problème - Démontrer avec des nombres pairs et impairs
Id: 2176
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Dans cet exercice, $n$ désigne un nombre entier.

1. Vérifier que les carrés de $3$ et de $7$ sont impairs.
2. Comment s'écrit un nombre impair ? un nombre pair ?
3. Démontrer que le carré de tout nombre impair est impair.
4. Démontrer que le carré de tout nombre pair est un multiple de $4$.
5. Démontrer que le produit de deux nombres entiers consécutifs est pair.

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux exemples

::: etape Calculs
$3^2 = 9$ et $7^2 = 49$ : ce sont deux nombres impairs.
:::

::: resultat
Les exemples suggèrent la propriété, mais ne la démontrent pas.
:::

## Question 2 : Écritures générales

::: resultat
Un nombre pair s'écrit $2n$ et un nombre impair s'écrit $2n + 1$, avec $n$ entier.
:::

## Question 3 : Le carré d'un impair

::: methode
On développe $(2n + 1)^2$ et on cherche à l'écrire sous la forme $2k + 1$, avec $k$ entier.
:::

::: etape Développer
$$
\begin{aligned}
(2n + 1)^2 &= 4n^2 + 4n + 1 \\
&= 2(2n^2 + 2n) + 1
\end{aligned}
$$
:::

::: etape Conclure
$k = 2n^2 + 2n$ est un entier : $(2n + 1)^2 = 2k + 1$.
:::

::: resultat
Le carré de tout nombre impair est impair.
:::

## Question 4 : Le carré d'un pair

::: etape Calcul
$(2n)^2 = 4n^2 = 4 \times n^2$, et $n^2$ est un entier.
:::

::: resultat
Le carré de tout nombre pair est un multiple de $4$.
:::

## Question 5 : Deux entiers consécutifs

::: methode
Deux entiers consécutifs s'écrivent $n$ et $n + 1$ ; on distingue deux cas.
:::

::: etape Si $n$ est pair
$n = 2k$, et $n(n + 1) = 2k(n + 1) = 2 \times k(n + 1)$ : c'est un nombre pair.
:::

::: etape Si $n$ est impair
$n + 1$ est pair : $n + 1 = 2k$ et $n(n + 1) = 2 \times nk$ : c'est un nombre pair.
:::

::: resultat
Dans tous les cas, $n(n + 1)$ est pair.
:::

::: attention Erreur fréquente
Écrire deux nombres impairs quelconques sous la forme $2n + 1$ et $2n + 3$ : ce sont deux impairs **consécutifs**. Pour deux impairs quelconques, il faut deux lettres : $2n + 1$ et $2p + 1$.
:::

Solution:
<!-- optitab:1 -->
1. $9$ et $49$ sont impairs.
2. Pair : $2n$ ; impair : $2n + 1$.
3. $(2n + 1)^2 = 2(2n^2 + 2n) + 1$ : impair.
4. $(2n)^2 = 4n^2$ : multiple de $4$.
5. L'un des deux entiers est pair, donc le produit est pair.

=== Problème - Une différence d'aires
Id: 2177
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Deux carrés ont pour côtés $x + 3$ cm et $x$ cm, avec $x > 0$.

1. Montrer que la différence de leurs aires vaut $6x + 9$ cm².
2. Cette différence peut-elle valoir $9$ cm² ? Justifier.
3. Peut-elle valoir $39$ cm² ? Si oui, donner les côtés des deux carrés et vérifier.
4. Peut-elle valoir $100$ cm² ? Donner la valeur exacte de $x$.

Étapes:
<!-- optitab:1 -->
## Question 1 : La différence des aires

::: methode
On développe $(x + 3)^2$ avec l'identité $(a + b)^2 = a^2 + 2ab + b^2$.
:::

::: etape Développer et réduire
$$
\begin{aligned}
(x + 3)^2 - x^2 &= x^2 + 6x + 9 - x^2 \\
&= 6x + 9
\end{aligned}
$$
:::

::: resultat
La différence des aires vaut $6x + 9$ cm².
:::

## Question 2 : $9$ cm² ?

::: etape Résoudre
$6x + 9 = 9$ donne $6x = 0$, soit $x = 0$.
:::

::: resultat
Impossible : il faudrait $x = 0$, alors que $x > 0$ (le petit carré n'existerait pas).
:::

## Question 3 : $39$ cm² ?

::: etape Résoudre
$6x + 9 = 39$ donne $6x = 30$, soit $x = 5$.
:::

::: etape Vérifier
Côtés $5$ cm et $8$ cm : $8^2 - 5^2 = 64 - 25 = 39$.
:::

::: resultat
Oui, avec des carrés de $5$ cm et $8$ cm de côté.
:::

## Question 4 : $100$ cm² ?

::: etape Résoudre
$6x + 9 = 100$ donne $6x = 91$, soit $x = \dfrac{91}{6}$.
:::

::: etape Contrôler le signe
$\dfrac{91}{6} \approx 15{,}17 > 0$ : la valeur convient.
:::

::: resultat
Oui, pour $x = \dfrac{91}{6}$ cm (une longueur n'a pas besoin d'être entière).
:::

::: attention Erreur fréquente
Écrire $(x + 3)^2 - x^2 = 9$ en oubliant le double produit $6x$ : on conclurait à tort que la différence vaut toujours $9$.
:::

Solution:
<!-- optitab:1 -->
1. $(x + 3)^2 - x^2 = 6x + 9$
2. Non : il faudrait $x = 0$.
3. Oui : $x = 5$, côtés $5$ cm et $8$ cm ($64 - 25 = 39$).
4. Oui : $x = \dfrac{91}{6}$ cm.

=== Problème - Une différence toujours constante
Id: 2178
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
Pour tout nombre $x$, on pose $A = (x + 1)^2$ et $B = x(x + 2)$.

1. Calculer $A$ et $B$ pour $x = 5$, puis pour $x = -3$.
2. Quelle conjecture peut-on formuler ?
3. Démontrer cette conjecture.
4. Application : sans calculatrice, calculer $1\,001^2 - 1\,000 \times 1\,002$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux essais

::: etape Pour $x = 5$
$A = 6^2 = 36$ et $B = 5 \times 7 = 35$.
:::

::: etape Pour $x = -3$
$A = (-2)^2 = 4$ et $B = (-3) \times (-1) = 3$.
:::

::: resultat
$A = 36$, $B = 35$ pour $x = 5$ ; $A = 4$, $B = 3$ pour $x = -3$.
:::

## Question 2 : La conjecture

::: resultat
Il semble que $A - B = 1$ pour tout nombre $x$.
:::

## Question 3 : La démonstration

::: methode
Pour comparer deux expressions, on calcule leur différence et on la réduit.
:::

::: etape Développer
$A = (x + 1)^2 = x^2 + 2x + 1$ et $B = x(x + 2) = x^2 + 2x$.
:::

::: etape Calculer la différence
$$
\begin{aligned}
A - B &= x^2 + 2x + 1 - (x^2 + 2x) \\
&= x^2 + 2x + 1 - x^2 - 2x \\
&= 1
\end{aligned}
$$
:::

::: resultat
Pour tout nombre $x$ : $A - B = 1$.
:::

## Question 4 : Application

::: etape Choisir $x$
Avec $x = 1\,000$ : $A = 1\,001^2$ et $B = 1\,000 \times 1\,002$.
:::

::: resultat
$1\,001^2 - 1\,000 \times 1\,002 = 1$.
:::

::: attention Erreur fréquente
Oublier les parenthèses en soustrayant $B$ : $- (x^2 + 2x) = -x^2 - 2x$, les deux signes changent.
:::

Solution:
<!-- optitab:1 -->
1. $36$ et $35$ ; $4$ et $3$.
2. $A - B = 1$
3. $A - B = x^2 + 2x + 1 - x^2 - 2x = 1$
4. $1$

=== Type brevet - Choisir la forme adaptée
Id: 2179
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
On considère l'expression $F = (x - 2)(x + 5) + 3(x - 2)$.

1. Développer et réduire $F$.
2. Factoriser $F$.
3. Calculer $F$ pour $x = 0$, puis pour $x = 2$, en choisissant à chaque fois la forme la plus adaptée.
4. Résoudre l'équation $F = 0$.

Étapes:
<!-- optitab:1 -->
## Question 1 : Développer

::: etape Développer chaque produit
$(x - 2)(x + 5) = x^2 + 5x - 2x - 10 = x^2 + 3x - 10$ et $3(x - 2) = 3x - 6$.
:::

::: etape Réduire
$$
\begin{aligned}
F &= x^2 + 3x - 10 + 3x - 6 \\
&= x^2 + 6x - 16
\end{aligned}
$$
:::

::: resultat
$F = x^2 + 6x - 16$
:::

## Question 2 : Factoriser

::: methode
Le facteur commun aux deux termes est la parenthèse $(x - 2)$.
:::

::: etape Mettre en facteur
$$
\begin{aligned}
F &= (x - 2)\left[(x + 5) + 3\right] \\
&= (x - 2)(x + 8)
\end{aligned}
$$
:::

::: etape Contrôle
$(x - 2)(x + 8) = x^2 + 8x - 2x - 16 = x^2 + 6x - 16$ : on retrouve la forme développée.
:::

::: resultat
$F = (x - 2)(x + 8)$
:::

## Question 3 : Calculer avec la bonne forme

::: etape Pour $x = 0$ : forme développée
$F = 0^2 + 6 \times 0 - 16 = -16$
:::

::: etape Pour $x = 2$ : forme factorisée
$F = (2 - 2)(2 + 8) = 0 \times 10 = 0$
:::

::: resultat
$F = -16$ pour $x = 0$ et $F = 0$ pour $x = 2$.
:::

## Question 4 : Résoudre $F = 0$

::: methode
Un produit est nul si et seulement si l'un de ses facteurs est nul : on utilise la forme factorisée.
:::

::: etape Équation produit nul
$(x - 2)(x + 8) = 0$ équivaut à $x - 2 = 0$ ou $x + 8 = 0$.
:::

::: resultat
L'équation $F = 0$ a deux solutions : $x = 2$ et $x = -8$.
:::

::: attention Erreur fréquente
Oublier le $+3$ dans le crochet : $(x - 2)\left[(x + 5) + 3\right]$, et non $(x - 2)(x + 5) \times 3$.
:::

Solution:
<!-- optitab:1 -->
1. $F = x^2 + 6x - 16$
2. $F = (x - 2)(x + 8)$
3. $F = -16$ pour $x = 0$ ; $F = 0$ pour $x = 2$.
4. $x = 2$ ou $x = -8$.

=== Type brevet - Sommes d'entiers consécutifs
Id: 2200
Difficulté: hard

Énoncé:
<!-- optitab:1 -->
1. Calculer $4 + 5 + 6$ et $11 + 12 + 13$. Que remarque-t-on ?
2. Démontrer que la somme de trois entiers consécutifs est toujours un multiple de $3$.
3. Que vaut le quotient de cette somme par $3$ ?
4. Affirmation : « la somme de deux entiers consécutifs est toujours paire ». Vraie ou fausse ?
5. La somme de cinq entiers consécutifs est-elle toujours un multiple de $5$ ?

Étapes:
<!-- optitab:1 -->
## Question 1 : Deux exemples

::: etape Calculs
$4 + 5 + 6 = 15 = 3 \times 5$ et $11 + 12 + 13 = 36 = 3 \times 12$.
:::

::: resultat
Les deux sommes sont des multiples de $3$.
:::

## Question 2 : La démonstration

::: methode
On note $n$ le plus petit des trois entiers : les suivants sont $n + 1$ et $n + 2$.
:::

::: etape Somme
$$
\begin{aligned}
n + (n + 1) + (n + 2) &= 3n + 3 \\
&= 3(n + 1)
\end{aligned}
$$
:::

::: resultat
La somme s'écrit $3 \times (n + 1)$ avec $n + 1$ entier : c'est un multiple de $3$.
:::

## Question 3 : Le quotient

::: etape Calcul
$3(n + 1) \div 3 = n + 1$
:::

::: resultat
Le quotient est $n + 1$, l'entier du milieu ($5$ et $12$ dans les exemples).
:::

## Question 4 : Deux entiers consécutifs

::: etape Somme
$n + (n + 1) = 2n + 1$
:::

::: resultat
Faux : $2n + 1$ est toujours impair (exemple : $4 + 5 = 9$).
:::

## Question 5 : Cinq entiers consécutifs

::: etape Somme
On note $S$ la somme des cinq entiers $n$, $n + 1$, $n + 2$, $n + 3$, $n + 4$.
$$
\begin{aligned}
S &= n + (n + 1) + (n + 2) \\
&\quad + (n + 3) + (n + 4) \\
&= 5n + 10 \\
&= 5(n + 2)
\end{aligned}
$$
:::

::: resultat
Oui : la somme vaut $5(n + 2)$, un multiple de $5$ (et $n + 2$ est encore l'entier du milieu).
:::

::: attention Erreur fréquente
Vérifier sur plusieurs exemples ne démontre pas une propriété « toujours vraie ». Il faut écrire les entiers avec une lettre.
:::

Solution:
<!-- optitab:1 -->
1. $15 = 3 \times 5$ et $36 = 3 \times 12$ : multiples de $3$.
2. $n + (n + 1) + (n + 2) = 3(n + 1)$.
3. $n + 1$, l'entier du milieu.
4. Faux : $2n + 1$ est impair.
5. Oui : $5(n + 2)$.
