<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Point de vue local : taux de variation et nombre dérivé</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Taux de variation</strong></p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle f$ une fonction définie sur un intervalle $\displaystyle I$ et $\displaystyle a$ un point de $\displaystyle I$.</p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle h \neq 0$ tel que $\displaystyle a + h \in I$, le <strong>taux de variation</strong> de $\displaystyle f$ entre $\displaystyle a$ et $\displaystyle a + h$ est :</p>
<div style="background:#e8f4fd; border:3px solid #3498db; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:300px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle \tau(a, h) = \frac{f(a+h) - f(a)}{h}$</p>
</div>
<p style="margin:5px 0 0 0;">Ce taux représente la <strong>pente de la sécante</strong> à la courbe passant par $\displaystyle A(a, f(a))$ et $\displaystyle M(a+h, f(a+h))$.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Nombre dérivé</strong></p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle f$ une fonction définie sur un intervalle $\displaystyle I$ et $\displaystyle a$ un point de $\displaystyle I$.</p>
<p style="margin:5px 0 0 0;">On dit que $\displaystyle f$ est <strong>dérivable en $\displaystyle a$</strong> si le taux de variation admet une limite finie lorsque $\displaystyle h$ tend vers $\displaystyle 0$.</p>
<p style="margin:5px 0 0 0;">Cette limite est appelée le <strong>nombre dérivé</strong> de $\displaystyle f$ en $\displaystyle a$ :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:400px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$</p>
</div>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Interprétations du nombre dérivé :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;"><strong>Géométrique :</strong> $\displaystyle f'(a)$ est la <strong>pente de la tangente</strong> à la courbe au point d'abscisse $\displaystyle a$</li>
<li style="margin:0 0 8px 0;"><strong>Physique :</strong> Si $\displaystyle f(t)$ représente la position, alors $\displaystyle f'(a)$ est la <strong>vitesse instantanée</strong> à l'instant $\displaystyle a$</li>
<li style="margin:0 0 8px 0;"><strong>Variation :</strong> Le signe de $\displaystyle f'(a)$ indique si la fonction est croissante ($\displaystyle f'(a) > 0$) ou décroissante ($\displaystyle f'(a) < 0$)</li>
</ul>
</div>
</div>

<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Équation de la tangente</strong></p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle f$ une fonction dérivable en $\displaystyle a$.</p>
<p style="margin:5px 0 0 0;">La <strong>tangente</strong> à la courbe au point d'abscisse $\displaystyle a$ a pour équation :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:350px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle y = f(a) + f'(a)(x - a)$</p>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Point de vue global : fonction dérivée</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Définition - Fonction dérivée</strong></p>
<p style="margin:5px 0 0 0;">Une fonction $\displaystyle f$ est dite <strong>dérivable sur un intervalle $\displaystyle I$</strong> si elle est dérivable en tout point de $\displaystyle I$.</p>
<p style="margin:5px 0 0 0;">La <strong>fonction dérivée</strong> de $\displaystyle f$, notée $\displaystyle f'$, est la fonction qui à tout $\displaystyle x$ de $\displaystyle I$ associe le nombre dérivé $\displaystyle f'(x)$.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#f3e5f5; border-left:4px solid #9c27b0; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Notations de la dérivée :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;"><strong>Notation de Lagrange :</strong> $\displaystyle f'(x)$ (la plus courante)</li>
<li style="margin:0 0 8px 0;"><strong>Notation de Leibniz :</strong> $\displaystyle \frac{df}{dx}$ ou $\displaystyle \frac{d}{dx}[f(x)]$</li>
<li style="margin:0;"><strong>Notation opérateur :</strong> $\displaystyle Df$ ou $\displaystyle D[f]$</li>
</ul>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Opérations sur les fonctions dérivables</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #3498db; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(52,152,219,0.15); table-layout:fixed;">

<tr style="background:linear-gradient(135deg, #3498db 0%, #2980b9 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Opération</th>

<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;"><strong>Somme</strong></td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle (u + v)' = u' + v'$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;"><strong>Produit</strong></td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle (uv)' = u'v + uv'$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;"><strong>Inverse</strong></td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle \left(\frac{1}{u}\right)' = -\frac{u'}{u^2}$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;"><strong>Quotient</strong></td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$</td>
</tr>
<tr style="background:#e8f4fd;">
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;"><strong>Composée</strong><br/>$\displaystyle f(g(x))$</td>
<td style="border:none; border-bottom:1px solid #d1e7f0; padding:18px 16px;">$\displaystyle (f \circ g)'(x) = f'(g(x)) \times g'(x)$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; padding:18px 16px;"><strong>Cas particulier</strong><br/>$\displaystyle g(ax + b)$</td>
<td style="border:none; padding:18px 16px;">$\displaystyle f'(x) = a \times g'(ax + b)$</td>
</tr>
</tbody>
</table>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#e8f4fd; border-left:4px solid #3498db; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Fonction valeur absolue</strong></p>
<p style="margin:5px 0 0 0;">La fonction valeur absolue $\displaystyle f(x) = |x|$ n'est <strong>pas dérivable en $\displaystyle 0$</strong>.</p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle x > 0$ : $\displaystyle f'(x) = 1$</p>
<p style="margin:5px 0 0 0;">Pour $\displaystyle x < 0$ : $\displaystyle f'(x) = -1$</p>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">IV. Variations et extremums</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Lien entre signe de la dérivée et variations</strong></p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle f$ une fonction dérivable sur un intervalle $\displaystyle I$.</p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Si $\displaystyle f'(x) > 0$ pour tout $\displaystyle x \in I$, alors $\displaystyle f$ est <strong>strictement croissante</strong> sur $\displaystyle I$</li>
<li style="margin:0 0 8px 0;">Si $\displaystyle f'(x) < 0$ pour tout $\displaystyle x \in I$, alors $\displaystyle f$ est <strong>strictement décroissante</strong> sur $\displaystyle I$</li>
<li style="margin:0 0 8px 0;">Si $\displaystyle f'(x) = 0$ pour tout $\displaystyle x \in I$, alors $\displaystyle f$ est <strong>constante</strong> sur $\displaystyle I$</li>
</ul>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fee2e2; border-left:4px solid #ef4444; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Théorème - Condition nécessaire pour un extremum</strong></p>
<p style="margin:5px 0 0 0;">Si $\displaystyle f$ est dérivable sur un intervalle $\displaystyle I$ et admet un extremum local en un point $\displaystyle a$ de l'intérieur de $\displaystyle I$, alors :</p>
<div style="background:#fee2e2; border:3px solid #ef4444; border-radius:8px; padding:15px; margin:12px auto; text-align:center; max-width:200px;">
<p style="margin:0; font-size:1.1em; font-weight:bold;">$\displaystyle f'(a) = 0$</p>
</div>
<p style="margin:5px 0 0 0;">La tangente à la courbe au point d'abscisse $\displaystyle a$ est alors <strong>horizontale</strong>.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fff8dc; border-left:4px solid #ffa500; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>⚠️ Attention :</strong></p>
<p style="margin:5px 0 0 0;">La réciproque est <strong>fausse</strong> ! Si $\displaystyle f'(a) = 0$, cela ne garantit pas que $\displaystyle a$ soit un extremum.</p>
<p style="margin:5px 0 0 0;">Exemple : $\displaystyle f(x) = x^3$ vérifie $\displaystyle f'(0) = 0$ mais $\displaystyle 0$ n'est pas un extremum.</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; border-left:4px solid #f59e0b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Méthode pour déterminer les extremums :</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Calculer $\displaystyle f'(x)$</li>
<li style="margin:0 0 8px 0;">Résoudre $\displaystyle f'(x) = 0$ pour trouver les points critiques</li>
<li style="margin:0 0 8px 0;">Étudier le signe de $\displaystyle f'(x)$ autour de chaque point critique</li>
<li style="margin:0;">Si $\displaystyle f'$ change de signe de $\displaystyle +$ à $\displaystyle -$ : maximum local. Si $\displaystyle f'$ change de signe de $\displaystyle -$ à $\displaystyle +$ : minimum local</li>
</ol>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#fef3c7; border-left:4px solid #f59e0b; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Étude d'une fonction polynôme du second degré</strong></p>
<p style="margin:5px 0 0 0;">Soit $\displaystyle f(x) = ax^2 + bx + c$ avec $\displaystyle a \neq 0$.</p>
<p style="margin:5px 0 0 0;">On a : $\displaystyle f'(x) = 2ax + b$</p>
<p style="margin:5px 0 0 0;">Résolvons $\displaystyle f'(x) = 0$ : $\displaystyle x = -\frac{b}{2a}$</p>
</div>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin-bottom:15px;">
<p style="margin:0;"><strong>Cas 1 : $\displaystyle a > 0$ (parabole $\displaystyle \cup$)</strong></p>
</div>
<table style="width:100%; max-width:600px; border-collapse:collapse; margin:8px auto; border:2px solid #3498db;">
<tr style="background:#e8f4f8;">

</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">V. Problèmes d'optimisation</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#f8f9fa; border-left:4px solid #6c757d; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>Méthode générale :</strong></p>
<ol style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Modéliser le problème (identifier la fonction à optimiser et les contraintes)</li>
<li style="margin:0 0 8px 0;">Dériver la fonction</li>
<li style="margin:0 0 8px 0;">Trouver les extremums (résoudre $\displaystyle f'(x) = 0$ et étudier le signe)</li>
<li style="margin:0;">Vérifier que les extremums correspondent au problème (vérifier les contraintes)</li>
</ol>
</div>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VI. Erreurs fréquentes</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ef4444; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(239,68,68,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ef4444 0%, #dc2626 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Piège fréquent</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Correction</th>
</tr>
</thead>
<tbody>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Dérivée d'un produit : $\displaystyle (uv)' = u'v'$</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;"><strong>Faux !</strong> C'est $\displaystyle (uv)' = u'v + uv'$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Dérivée d'un quotient : confondre avec le produit</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">$\displaystyle \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$<br/>Attention au signe moins et à l'ordre</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Dérivée de $\displaystyle \frac{1}{u}$ : oublier le signe moins</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">$\displaystyle \left(\frac{1}{u}\right)' = -\frac{u'}{u^2}$<br/><strong>Ne pas oublier le signe moins !</strong></td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Dérivée d'une composée : oublier $\displaystyle g'(x)$</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Pour $\displaystyle f(g(x))$ : $\displaystyle (f \circ g)'(x) = f'(g(x)) \times g'(x)$<br/>Ne pas oublier de multiplier par $\displaystyle g'(x)$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;">Extremum : $\displaystyle f'(a) = 0$ garantit un extremum</td>
<td style="border:none; border-bottom:1px solid #fecaca; padding:18px 16px;"><strong>Faux !</strong> Il faut vérifier le changement de signe de $\displaystyle f'$ autour de $\displaystyle a$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Tangente : confondre avec la sécante</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">La tangente passe par $\displaystyle (a, f(a))$ avec la pente $\displaystyle f'(a)$<br/>Équation : $\displaystyle y = f(a) + f'(a)(x - a)$</td>
</tr>
<tr style="background:#fee2e2;">
<td style="border:none; padding:18px 16px;">Domaine de dérivabilité : ne pas vérifier</td>
<td style="border:none; padding:18px 16px;">Vérifier que la fonction est définie et dérivable sur l'intervalle considéré<br/>Exemple : $\displaystyle \sqrt{x}$ n'est pas dérivable en $\displaystyle 0$</td>
</tr>
</tbody>
</table>
</div>

<h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">VIII. Méthodologie — stratégie de résolution</h2>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<table style="width:100%; border-collapse:separate; border-spacing:0; margin:15px 0; border:2px solid #ffa500; border-radius:8px; overflow:hidden; box-shadow:0 2px 8px rgba(255,165,0,0.15); table-layout:fixed;">
<thead>
<tr style="background:linear-gradient(135deg, #ffa500 0%, #ff8c00 100%); color:white;">
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Type de problème</th>
<th style="border:none; padding:14px 16px; text-align:left; font-weight:600; font-size:1.05em; width:50%;">Méthode recommandée</th>
</tr>
</thead>
<tbody>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Calculer un nombre dérivé</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Utiliser la définition $\displaystyle f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$ ou les formules de dérivation</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Équation de tangente</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Toujours utiliser $\displaystyle y = f(a) + f'(a)(x - a)$</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">Étudier les variations</td>
<td style="border:none; border-bottom:1px solid #ffe4b5; padding:18px 16px;">1. Calculer $\displaystyle f'(x)$<br/>2. Étudier le signe de $\displaystyle f'(x)$<br/>3. En déduire les variations de $\displaystyle f$</td>
</tr>
<tr style="background:#f8f9fa;">
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">Trouver les extremums</td>
<td style="border:none; border-bottom:1px solid #e9ecef; padding:18px 16px;">1. Résoudre $\displaystyle f'(x) = 0$<br/>2. Vérifier le changement de signe de $\displaystyle f'$ autour de chaque solution<br/>3. Calculer les valeurs aux extremums</td>
</tr>
<tr style="background:#fff8dc;">
<td style="border:none; padding:18px 16px;">Problème d'optimisation</td>
<td style="border:none; padding:18px 16px;">1. Modéliser le problème (fonction à optimiser)<br/>2. Dériver et trouver les extremums<br/>3. Vérifier que les solutions correspondent au problème</td>
</tr>
</tbody>
</table>
</div>

<div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
<div style="background:#ecfdf5; border-left:4px solid #10b981; padding:12px; margin:10px 0;">
<p style="margin:0;"><strong>💡 Points de vigilance :</strong></p>
<ul style="margin:5px 0 0 0; padding-left:20px; line-height:1.8;">
<li style="margin:0 0 8px 0;">Toujours vérifier le domaine de dérivabilité avant d'appliquer les formules</li>
<li style="margin:0 0 8px 0;">Pour les variations, faire un tableau de signes de $\displaystyle f'$</li>
<li style="margin:0 0 8px 0;">Vérifier les extremums en calculant les valeurs de la fonction</li>
<li style="margin:0;">Pour l'optimisation, vérifier que les solutions respectent les contraintes du problème</li>
</ul>
