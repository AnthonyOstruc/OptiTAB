 I. Définitions et formes d'un polynôme du second degré 
 Qu'est-ce qu'une fonction polynôme du second degré ? 
 Définition 
 Une fonction polynôme du second degré (ou fonction trinôme ) est une fonction définie sur $\displaystyle \mathbb{R}$ par : 
 $\displaystyle f(x) = ax^2 + bx + c$ 
 où $\displaystyle a$, $\displaystyle b$ et $\displaystyle c$ sont des nombres réels avec $\displaystyle a \neq 0$. 
 Les nombres $\displaystyle a$, $\displaystyle b$ et $\displaystyle c$ sont appelés respectivement coefficient dominant , coefficient de degré 1 et terme constant . 
 Exemples : 
 $\displaystyle f(x) = 2x^2 - 3x + 1$ : $\displaystyle a = 2$, $\displaystyle b = -3$, $\displaystyle c = 1$ 
 $\displaystyle g(x) = -x^2 + 5x - 2$ : $\displaystyle a = -1$, $\displaystyle b = 5$, $\displaystyle c = -2$ 
 $\displaystyle h(x) = x^2 - 4$ : $\displaystyle a = 1$, $\displaystyle b = 0$, $\displaystyle c = -4$ 
 $\displaystyle k(x) = 3x^2$ : $\displaystyle a = 3$, $\displaystyle b = 0$, $\displaystyle c = 0$ 
 💡 Remarque importante : 
 Si $\displaystyle a = 0$, alors $\displaystyle f(x) = bx + c$ est une fonction affine (polynôme du premier degré), pas du second degré ! 
 Les trois formes d'un polynôme du second degré : 
 Un polynôme du second degré peut s'écrire sous trois formes différentes : 
 Forme développée réduite : $\displaystyle f(x) = ax^2 + bx + c$ (la plus courante pour définir la fonction) 
 Forme canonique : $\displaystyle f(x) = a(x - \alpha)^2 + \beta$ où $\displaystyle \alpha$ et $\displaystyle \beta$ sont des réels 
 Forme factorisée : $\displaystyle f(x) = a(x - x_1)(x - x_2)$ si le polynôme admet deux racines distinctes, ou $\displaystyle f(x) = a(x - x_0)^2$ si une racine double 
 Chaque forme est adaptée à un type de problème spécifique. 
 II. Forme factorisée et racines 
 Racines d'un polynôme 
 Définition d'une racine 
 Un nombre réel $\displaystyle x_0$ est une racine (ou un zéro ) d'un polynôme $\displaystyle f$ si $\displaystyle f(x_0) = 0$. 
 Résoudre l'équation $\displaystyle f(x) = 0$ revient à trouver toutes les racines de $\displaystyle f$. 
 Exemples : 
 Pour $\displaystyle f(x) = (x-2)(x+1)$ : $\displaystyle f(2) = 0$ et $\displaystyle f(-1) = 0$, donc les racines sont $\displaystyle x_1 = 2$ et $\displaystyle x_2 = -1$ 
 Pour $\displaystyle g(x) = 2(x-3)^2$ : $\displaystyle g(3) = 0$, donc $\displaystyle x_0 = 3$ est une racine (double) 
 Pour $\displaystyle h(x) = x^2 + 1$ : $\displaystyle h(x) = 0 \Leftrightarrow x^2 = -1$, donc aucune racine réelle 
 Forme factorisée 
 Forme factorisée d'un polynôme 
 Si un polynôme $\displaystyle f(x) = ax^2 + bx + c$ admet deux racines distinctes $\displaystyle x_1$ et $\displaystyle x_2$, alors il peut s'écrire sous la forme : 
 $\displaystyle f(x) = a(x - x_1)(x - x_2)$ 
 Si $\displaystyle f$ admet une racine double $\displaystyle x_0$, alors : 
 $\displaystyle f(x) = a(x - x_0)^2$ 
 Exemples : 
 $\displaystyle f(x) = 2(x-1)(x+3)$ : racines $\displaystyle x_1 = 1$ et $\displaystyle x_2 = -3$ 
 En développant : $\displaystyle f(x) = 2(x^2 + 2x - 3) = 2x^2 + 4x - 6$ 
 $\displaystyle g(x) = -3(x-2)^2 = -3(x^2 - 4x + 4) = -3x^2 + 12x - 12$ : racine double $\displaystyle x_0 = 2$ 
 $\displaystyle h(x) = (x-5)(x+5) = x^2 - 25$ : racines $\displaystyle x_1 = 5$ et $\displaystyle x_2 = -5$ (identité remarquable) 
 Somme et produit des racines 
 Relations entre coefficients et racines 
 Si un polynôme $\displaystyle f(x) = ax^2 + bx + c$ admet deux racines distinctes $\displaystyle x_1$ et $\displaystyle x_2$, alors : 
 $\displaystyle x_1 + x_2 = -\frac{b}{a}$ (somme des racines) 
 $\displaystyle x_1 \times x_2 = \frac{c}{a}$ (produit des racines) 
 Démonstration : 
 Si $\displaystyle f(x) = ax^2 + bx + c$ admet deux racines $\displaystyle x_1$ et $\displaystyle x_2$, alors : 
 $\displaystyle f(x) = a(x - x_1)(x - x_2) = a[x^2 - (x_1 + x_2)x + x_1x_2] = ax^2 - a(x_1 + x_2)x + ax_1x_2$ 
 Par identification avec $\displaystyle f(x) = ax^2 + bx + c$ : 
 $\displaystyle -a(x_1 + x_2) = b$ donc $\displaystyle x_1 + x_2 = -\frac{b}{a}$ 
 $\displaystyle ax_1x_2 = c$ donc $\displaystyle x_1 \times x_2 = \frac{c}{a}$ 
 Exemples : 
 Pour $\displaystyle f(x) = x^2 - 5x + 6$ : $\displaystyle x_1 + x_2 = 5$ et $\displaystyle x_1 \times x_2 = 6$ 
 On trouve facilement : $\displaystyle x_1 = 2$ et $\displaystyle x_2 = 3$ (car $\displaystyle 2 + 3 = 5$ et $\displaystyle 2 \times 3 = 6$) 
 Pour $\displaystyle g(x) = 2x^2 + 4x - 6$ : $\displaystyle x_1 + x_2 = -2$ et $\displaystyle x_1 \times x_2 = -3$ 
 On trouve : $\displaystyle x_1 = 1$ et $\displaystyle x_2 = -3$ (car $\displaystyle 1 + (-3) = -2$ et $\displaystyle 1 \times (-3) = -3$) 
 III. Forme canonique et discriminant 
 Forme canonique 
 Théorème - Forme canonique 
 Tout polynôme du second degré $\displaystyle f(x) = ax^2 + bx + c$ peut s'écrire sous la forme canonique : 
 $\displaystyle f(x) = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a}$ 
 On pose : 
 $\displaystyle \alpha = -\frac{b}{2a}$ (abscisse du sommet de la parabole) 
 $\displaystyle \beta = f(\alpha) = -\frac{b^2 - 4ac}{4a}$ (ordonnée du sommet) 
 On écrit alors : $\displaystyle f(x) = a(x - \alpha)^2 + \beta$ 
 Démonstration - Méthode de complétion du carré : 
 On part de : $\displaystyle f(x) = ax^2 + bx + c$ 
 On met $\displaystyle a$ en facteur : $\displaystyle f(x) = a\left(x^2 + \frac{b}{a}x\right) + c$ 
 On complète le carré : $\displaystyle f(x) = a\left(x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} - \frac{b^2}{4a^2}\right) + c$ 
 $\displaystyle f(x) = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a}$ 
 Exemple : 
 Pour $\displaystyle f(x) = 2x^2 - 4x + 1$ : 
 $\displaystyle \alpha = -\frac{-4}{2 \times 2} = \frac{4}{4} = 1$ 
 $\displaystyle \beta = f(1) = 2 \times 1^2 - 4 \times 1 + 1 = 2 - 4 + 1 = -1$ 
 Forme canonique : $\displaystyle f(x) = 2(x - 1)^2 - 1$ 
 Le sommet de la parabole est le point $\displaystyle S(\alpha, \beta) = (1, -1)$.

 Discriminant 
 Définition du discriminant 
 Pour un polynôme $\displaystyle f(x) = ax^2 + bx + c$, on appelle discriminant le nombre réel : 
 $\displaystyle \Delta = b^2 - 4ac$ 
 Le discriminant permet de déterminer le nombre de racines réelles du polynôme. 
 Propriété - Nombre de racines selon le discriminant : 
 Si $\displaystyle \Delta > 0$ : le polynôme admet deux racines distinctes $\displaystyle x_1$ et $\displaystyle x_2$ 
 Si $\displaystyle \Delta = 0$ : le polynôme admet une racine double $\displaystyle x_0 = -\frac{b}{2a}$ 
 Si $\displaystyle \Delta aucune racine réelle 
 Exemples : 
 $\displaystyle f(x) = x^2 - 5x + 6$ : $\displaystyle \Delta = (-5)^2 - 4 \times 1 \times 6 = 25 - 24 = 1 > 0$ → deux racines distinctes 
 $\displaystyle g(x) = x^2 - 4x + 4$ : $\displaystyle \Delta = (-4)^2 - 4 \times 1 \times 4 = 16 - 16 = 0$ → une racine double 
 $\displaystyle h(x) = x^2 + x + 1$ : $\displaystyle \Delta = 1^2 - 4 \times 1 \times 1 = 1 - 4 = -3 
 IV. Résolution d'une équation du second degré 
 Formule générale 
 Théorème - Résolution de l'équation $\displaystyle ax^2 + bx + c = 0$ 
 Soit l'équation $\displaystyle ax^2 + bx + c = 0$ avec $\displaystyle a \neq 0$. 
 On calcule le discriminant : $\displaystyle \Delta = b^2 - 4ac$

 Si $\displaystyle \Delta = 0$ : l'équation admet une solution double : 
 $\displaystyle x_0 = -\frac{b}{2a}$

 On utilise la forme canonique : $\displaystyle f(x) = a\left(x + \frac{b}{2a}\right)^2 - \frac{\Delta}{4a}$ 
 Résoudre $\displaystyle f(x) = 0$ équivaut à : $\displaystyle a\left(x + \frac{b}{2a}\right)^2 = \frac{\Delta}{4a}$ 
 Soit : $\displaystyle \left(x + \frac{b}{2a}\right)^2 = \frac{\Delta}{4a^2}$

 VI. Factorisation avec diverses stratégies 
 Stratégies de factorisation 
 📐 Stratégie 1 : Racine évidente 
 On teste des valeurs simples ($\displaystyle 0, 1, -1, 2, -2, \ldots$) pour trouver une racine évidente. 
 Exemple : Factoriser $\displaystyle f(x) = x^2 - 5x + 6$ 
 On teste $\displaystyle f(2) = 4 - 10 + 6 = 0$ → $\displaystyle 2$ est une racine 
 On teste $\displaystyle f(3) = 9 - 15 + 6 = 0$ → $\displaystyle 3$ est une racine 
 Donc : $\displaystyle f(x) = (x-2)(x-3)$ 
 📐 Stratégie 2 : Détection des racines par somme et produit 
 Si $\displaystyle x_1 + x_2 = s$ et $\displaystyle x_1 \times x_2 = p$, alors $\displaystyle x_1$ et $\displaystyle x_2$ sont les racines de $\displaystyle x^2 - sx + p = 0$. 
 Exemple : Factoriser $\displaystyle f(x) = x^2 - 5x + 6$ 
 Somme : $\displaystyle 5$, Produit : $\displaystyle 6$ → on cherche deux nombres dont la somme est $\displaystyle 5$ et le produit $\displaystyle 6$ 
 On trouve : $\displaystyle 2 + 3 = 5$ et $\displaystyle 2 \times 3 = 6$ 
 Donc : $\displaystyle f(x) = (x-2)(x-3)$ 
 📐 Stratégie 3 : Identité remarquable 
 Reconnaître une identité remarquable permet de factoriser directement. 
 $\displaystyle a^2 - b^2 = (a-b)(a+b)$ (différence de deux carrés) 
 $\displaystyle a^2 + 2ab + b^2 = (a+b)^2$ (carré d'une somme) 
 $\displaystyle a^2 - 2ab + b^2 = (a-b)^2$ (carré d'une différence) 
 Exemples : 
 $\displaystyle x^2 - 25 = (x-5)(x+5)$ (différence de carrés) 
 $\displaystyle x^2 - 4x + 4 = (x-2)^2$ (carré d'une différence)

 Si $\displaystyle \Delta = 0$ : $\displaystyle f(x) = a(x-x_0)^2$ avec $\displaystyle x_0 = -\frac{b}{2a}$ 
 Si $\displaystyle \Delta 
 Exemple : Factoriser $\displaystyle f(x) = 2x^2 - 4x - 6$ 
 $\displaystyle \Delta = (-4)^2 - 4 \times 2 \times (-6) = 16 + 48 = 64$ 
 $\displaystyle x_1 = \frac{4-8}{4} = -1$ et $\displaystyle x_2 = \frac{4+8}{4} = 3$ 
 Donc : $\displaystyle f(x) = 2(x+1)(x-3)$ 
 VII. Choix de la forme adaptée 
 Quand utiliser quelle forme ? 
 Guide de choix de la forme : 
 Forme développée réduite $\displaystyle f(x) = ax^2 + bx + c$ : 
 → Pour calculer l'image d'une valeur, pour additionner ou soustraire des polynômes 
 Forme canonique $\displaystyle f(x) = a(x-\alpha)^2 + \beta$ : 
 → Pour déterminer les variations, le minimum/maximum (sommet de la parabole en $\displaystyle (\alpha, \beta)$) 
 Forme factorisée $\displaystyle f(x) = a(x-x_1)(x-x_2)$ : 
 → Pour résoudre une équation $\displaystyle f(x) = 0$, pour étudier le signe, pour déterminer les racines 
 Exemple 1 - Résoudre une équation : 
 Résoudre $\displaystyle 2x^2 - 8x + 6 = 0$ 
 Méthode : On factorise (forme factorisée) ou on utilise le discriminant 
 $\displaystyle 2x^2 - 8x + 6 = 2(x^2 - 4x + 3) = 2(x-1)(x-3)$ 
 Solutions : $\displaystyle x = 1$ ou $\displaystyle x = 3$ 
 Exemple 2 - Résoudre une inéquation : 
 Résoudre $\displaystyle x^2 - 5x + 6 \geq 0$ 
 Méthode : On utilise la forme factorisée pour étudier le signe 
 $\displaystyle x^2 - 5x + 6 = (x-2)(x-3)$ 
 Tableau de signes : $\displaystyle f(x) \geq 0$ sur $\displaystyle ]-\infty, 2] \cup [3, +\infty[$ 
 Exemple 3 - Optimisation (minimum/maximum) : 
 Trouver le minimum de $\displaystyle f(x) = 2x^2 - 4x + 1$ 
 Méthode : On utilise la forme canonique 
 $\displaystyle f(x) = 2(x-1)^2 - 1$ 
 Le minimum est atteint en $\displaystyle x = 1$ et vaut $\displaystyle f(1) = -1$ 
 VIII. Applications et problèmes 
 Problèmes types 
 Problème 1 - Déterminer un polynôme connaissant ses racines : 
 Déterminer les fonctions polynômes du second degré s'annulant en $\displaystyle 2$ et $\displaystyle -3$. 
 Solution : Toute fonction polynôme du second degré s'annulant en $\displaystyle 2$ et $\displaystyle -3$ s'écrit : 
 $\displaystyle f(x) = a(x-2)(x+3)$ où $\displaystyle a \in \mathbb{R}^*$ 
 En développant : $\displaystyle f(x) = ax^2 + ax - 6a$ 
 Il existe une infinité de polynômes (un pour chaque valeur de $\displaystyle a \neq 0$) 
 Problème 2 - Optimisation : 
 Un projectile est lancé. Sa hauteur (en mètres) au temps $\displaystyle t$ (en secondes) est donnée par : 
 $\displaystyle h(t) = -5t^2 + 20t + 10$ 
 Quelle est la hauteur maximale atteinte et à quel instant ? 
 Solution : On met sous forme canonique 
 $\displaystyle h(t) = -5(t^2 - 4t) + 10 = -5[(t-2)^2 - 4] + 10 = -5(t-2)^2 + 30$ 
 Le maximum est atteint en $\displaystyle t = 2$ s et vaut $\displaystyle h(2) = 30$ m 
 Problème 3 - Inéquation avec paramètre : 
 Pour quelles valeurs de $\displaystyle m$ l'équation $\displaystyle x^2 - mx + 1 = 0$ admet-elle deux solutions distinctes ? 
 Solution : On calcule le discriminant : $\displaystyle \Delta = m^2 - 4$ 
 L'équation admet deux solutions distinctes si $\displaystyle \Delta > 0$, soit $\displaystyle m^2 - 4 > 0$ 
 Cela équivaut à $\displaystyle m^2 > 4$, donc $\displaystyle m 2$

 1. Factorisation d'un polynôme du troisième degré 
 Si un polynôme du troisième degré $\displaystyle P(x) = ax^3 + bx^2 + cx + d$ admet une racine $\displaystyle x_0$, alors on peut le factoriser sous la forme : 
 $\displaystyle P(x) = (x - x_0)(ax^2 + Bx + C)$ 
 où $\displaystyle ax^2 + Bx + C$ est un polynôme du second degré que l'on peut factoriser par identification ou division polynomiale. 
 Exemple : Factoriser $\displaystyle P(x) = x^3 - 6x^2 + 11x - 6$ 
 On teste $\displaystyle P(1) = 1 - 6 + 11 - 6 = 0$ → $\displaystyle 1$ est une racine 
 Par identification : $\displaystyle P(x) = (x-1)(x^2 - 5x + 6) = (x-1)(x-2)(x-3)$ 
 Les racines sont : $\displaystyle 1, 2, 3$ 
 2. Factorisations particulières 
 Factorisation de $\displaystyle x^n - 1$ 
 Pour tout entier naturel $\displaystyle n \geq 1$ : 
 $\displaystyle x^n - 1 = (x-1)(x^{n-1} + x^{n-2} + \cdots + x + 1)$ 
 Exemples : 
 $\displaystyle x^2 - 1 = (x-1)(x+1)$ 
 $\displaystyle x^3 - 1 = (x-1)(x^2 + x + 1)$ 
 $\displaystyle x^4 - 1 = (x-1)(x^3 + x^2 + x + 1) = (x-1)(x+1)(x^2+1)$ 
 Factorisation de $\displaystyle x^n - a^n$ 
 Pour tout entier naturel $\displaystyle n \geq 1$ et tout réel $\displaystyle a$ : 
 $\displaystyle x^n - a^n = (x-a)(x^{n-1} + ax^{n-2} + a^2x^{n-3} + \cdots + a^{n-2}x + a^{n-1})$ 
 Exemples : 
 $\displaystyle x^2 - a^2 = (x-a)(x+a)$ (identité remarquable connue) 
 $\displaystyle x^3 - a^3 = (x-a)(x^2 + ax + a^2)$ 
 $\displaystyle x^4 - 16 = (x-2)(x^3 + 2x^2 + 4x + 8)$ (avec $\displaystyle a = 2$, donc $\displaystyle a^4 = 16$)

 X. Conseils méthodologiques 
 Méthodes générales 
 ✅ Conseils pratiques : 
 Choisir la bonne forme : Développée pour calculer, canonique pour variations/extrema, factorisée pour équations/signe 
 Vérifier le discriminant : Toujours calculer $\displaystyle \Delta = b^2 - 4ac$ avant de chercher les racines 
 Racine évidente : Toujours tester $\displaystyle 0, 1, -1, 2, -2$ pour trouver une racine rapidement 
 Somme et produit : Utiliser $\displaystyle x_1 + x_2 = -\frac{b}{a}$ et $\displaystyle x_1 \times x_2 = \frac{c}{a}$ pour vérifier les racines 
 Identités remarquables : Reconnaître $\displaystyle a^2 - b^2$, $\displaystyle (a+b)^2$, $\displaystyle (a-b)^2$ pour factoriser directement 
 Signe : Utiliser la forme factorisée et faire un tableau de signes, attention au signe de $\displaystyle a$ 
 Vérification : Toujours vérifier les racines en remplaçant dans l'équation initiale 
 ⚠️ Erreurs fréquentes à éviter : 
 Oublier le coefficient $\displaystyle a$ dans la forme factorisée : $\displaystyle f(x) = a(x-x_1)(x-x_2)$, pas $\displaystyle (x-x_1)(x-x_2)$ 
 Erreur de signe dans le discriminant : $\displaystyle \Delta = b^2 - 4ac$ (attention au signe moins) 
 Confondre $\displaystyle x_1$ et $\displaystyle x_2$ : Par convention, $\displaystyle x_1 = \frac{-b-\sqrt{\Delta}}{2a}$ et $\displaystyle x_2 = \frac{-b+\sqrt{\Delta}}{2a}$ (donc $\displaystyle x_1 
 Oublier le cas $\displaystyle \Delta = 0$ : Il y a une racine double, pas "aucune racine" 
 Signe incorrect : Pour $\displaystyle a > 0$, le polynôme est négatif entre les racines, positif à l'extérieur 
 Forme canonique : Ne pas oublier le signe moins : $\displaystyle \alpha = -\frac{b}{2a}$ 
 Division par zéro : Vérifier que $\displaystyle a \neq 0$ avant d'appliquer les formules
