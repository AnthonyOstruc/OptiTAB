    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">I. Épreuve et schéma de Bernoulli</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Définitions :</strong> une <strong>épreuve de Bernoulli</strong> a deux issues : succès (probabilité $p$) et échec ($1 - p$). La variable qui vaut $1$ en cas de succès et $0$ sinon suit la <strong>loi de Bernoulli</strong> : $E = p$ et $V = p(1 - p)$.</p>
            <p style="margin:6px 0 0 0;">Un <strong>schéma de Bernoulli</strong> est la répétition de $n$ épreuves de Bernoulli identiques et indépendantes.</p>
        </div>
        [IMAGE_1]
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">II. Loi binomiale</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Théorème (démonstration au programme) :</strong> le nombre $X$ de succès dans un schéma de Bernoulli de paramètres $n$ et $p$ suit la <strong>loi binomiale</strong> $\mathcal{B}(n\,;p)$ : pour $0 \le k \le n$,</p>
            <div style="text-align:center; margin:10px 0 0 0;">$P(X = k) = \binom{n}{k}\,p^k\,(1 - p)^{n - k}$</div>
            <p style="margin:6px 0 0 0;"><em>Preuve :</em> chaque chemin de l’arbre comportant $k$ succès et $n - k$ échecs a pour probabilité $p^k(1 - p)^{n - k}$, et il y a $\binom{n}{k}$ tels chemins (choix des $k$ rangs des succès).</p>
            <p style="margin:6px 0 0 0;"><strong>Espérance et variance :</strong> $E(X) = np$, $V(X) = np(1 - p)$, $\sigma(X) = \sqrt{np(1 - p)}$.</p>
        </div>
        [IMAGE_2]
        <p style="font-size:1em;"><strong>Exemple :</strong> un QCM de $10$ questions à $4$ choix, répondu au hasard. Le nombre $X$ de bonnes réponses suit $\mathcal{B}(10\,;0{,}25)$ : $P(X = 5) = \binom{10}{5}\,0{,}25^5\,0{,}75^5 \approx 0{,}058$, $E(X) = 2{,}5$ et $\sigma(X) \approx 1{,}37$.</p>
        [IMAGE_3]
        <div style="background:#ecfdf5; border-radius:6px; border-left:6px solid #10b981; padding:15px; margin:12px 0;">
            <strong>💡 Rédaction type :</strong> « On répète $n$ fois, de façon identique et indépendante, une épreuve à deux issues dont le succès a la probabilité $p$. $X$ compte les succès, donc $X$ suit $\mathcal{B}(n\,;p)$. »
        </div>
    </div>

    <h2 style="color:#2c3e50; border-bottom:2px solid #3498db; padding-bottom:8px;">III. Probabilités cumulées et seuils</h2>

    <div style="background:#ffffff; border:1px solid #e1e8ed; padding:15px; margin:15px 0; border-radius:6px;">
        <div style="background:#e8f4fd; border-left:6px solid #3498db; padding:12px; margin:10px 0; border-radius:4px;">
            <p style="margin:0;"><strong>Méthodes :</strong> $P(X \le k)$ s’obtient avec la fonction de répartition de la calculatrice (« binomFRép » ou « BinomialCD ») ; $P(X \ge k) = 1 - P(X \le k - 1)$ ; $P(a \le X \le b) = P(X \le b) - P(X \le a - 1)$.</p>
        </div>
        <p style="font-size:1em;"><strong>Exemple :</strong> pour le QCM, $P(X \ge 5) = 1 - P(X \le 4) \approx 0{,}078$ : obtenir la moyenne au hasard est peu probable.</p>
        [IMAGE_4]
        <div style="background:#2c3e50; color:#ecf0f1; padding:12px; border-radius:6px; margin:10px 0 0 0; font-family:monospace; white-space:pre; overflow-x:auto;">from math import comb

def binom_cumul(n, p, k):
    return sum(comb(n, i) &#42; p &#42;&#42; i &#42; (1 - p) &#42;&#42; (n - i) for i in range(k + 1))

def seuil(n, p, alpha):
    k = 0
    while binom_cumul(n, p, k) &lt; 1 - alpha:
        k = k + 1
    return k</div>
        <p style="font-size:1em;"><code>seuil(10, 0.3, 0.05)</code> renvoie $5$ : c’est le plus petit $k$ tel que $P(X \le k) \ge 0{,}95$.</p>
        <div style="background:#fff8dc; border-radius:6px; border-left:6px solid #ffa500; padding:15px; margin:12px 0;">
            <strong>⚠️ Attention :</strong> $P(X \ge 5) \neq 1 - P(X \le 5)$ ; c’est $1 - P(X \le 4)$. Et les épreuves doivent être <strong>indépendantes</strong> (tirages avec remise, ou population très grande).
        </div>
    </div>

    <div style="background:#ecfdf5; border:2px solid #10b981; border-radius:8px; padding:15px; margin:20px 0 0 0;">
        <p style="margin:0; font-size:1.05em; color:#2c3e50;"><strong>🏆 L’essentiel :</strong> $n$ épreuves de Bernoulli identiques et indépendantes, $X$ = nombre de succès : $X \sim \mathcal{B}(n\,;p)$ ; $P(X = k) = \binom{n}{k}p^k(1 - p)^{n - k}$ ; $E(X) = np$ ; $V(X) = np(1 - p)$ ; $P(X \ge k) = 1 - P(X \le k - 1)$. Fiche de synthèse dans l’onglet Fiches !</p>
